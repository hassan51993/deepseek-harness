# إعداد مقابل قاعدة

[English](rules.md) | العربية

هذه قاعدة قيد كل وثيقة إعداد مقابل العربية مقابل جانب.

## أولوية درجة

| درجة آخر | يحتوي معنى |
|---|---|
| MUST | إعداد مقابل بوابة سوف رفض لا رمز دمج اشتراط إعداد مقابل. |
| SHOULD | فقط في شرح إدارة من بعد انحراف مغادرة. |

- إبقاء مصدر نص كل أمر عنوان.
- شفرة قطعة مقطع أصل مثال إبقاء.
