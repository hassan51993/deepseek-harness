# قواعد الاقتران

[English](rules.md) | العربية

تحكم هذه القواعد الجانبَ العربي من كل اقتران توثيقي.

## مستويات الإلزام

| المستوى | المعنى |
|---|---|
| MUST | ترفض بوابة الاقتران كل اقتران غير مطابق. |
| SHOULD | لا تخالف إلا بسبب معلن. |

- احفظ كل معنى في المصدر.
- أبقِ code spans بنصها الأصلي.
