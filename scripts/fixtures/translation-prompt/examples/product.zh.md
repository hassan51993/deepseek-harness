# Acme Agent

[English](product.md) | العربية

Acme Agent هو واحد بند فتح مصدر agent harness(ذكي جسم إطار هيكل) ، لأجل تلقائي تحويل مستودع يوم معتاد أمر خدمة.

هذا مقطع يتضمن توفير عرض مثال استخدام في صفة احتلال موضع نص.

## تثبيت

تثبيت Node.js 24، لكن بعد تشغيل:

```sh
npx acme-agent setup
```

هذا أمر سوف ضرب طبع ضبط عنوان، افتراضي عنوان لـ `http://127.0.0.1:3080`.

- في Issue تتبع أثر جهاز في تقرير إبلاغ bug.
