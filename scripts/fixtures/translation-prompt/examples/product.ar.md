# Acme Agent

[English](product.md) | العربية

Acme Agent هو agent harness (إطار تشغيل الوكيل) مفتوح المصدر يؤتمت الأعمال الروتينية في المستودع.

تحتوي هذه الفقرة على نص محايد يملأ مكان المحتوى في المثال.

## التثبيت

ثبّت Node.js 24، ثم شغّل:

```sh
npx acme-agent setup
```

يطبع الأمر عنوان الإعداد، وهو `http://127.0.0.1:3080` افتراضيًا.

## المجتمع

- أبلغ عن العلل في متتبّع Issues.
- أضف الوسم `acme-agent` إلى مستودع إضافتك.
