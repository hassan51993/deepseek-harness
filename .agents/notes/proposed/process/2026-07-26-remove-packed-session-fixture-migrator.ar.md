# Agent Note: إزالة تحزيم جلسة fixture فرع ترحيل جهاز

Status: proposed

[English](2026-07-26-remove-packed-session-fixture-migrator.md) | العربية

## مشكلة

مستودع افتراضي كتابة جهاز و لقطة فحص سوف جعل جلسة fixture(اختبار قبل وضع بيانات) إبقاء مواصفة تحزيم سطر تخطيط. في دائم دائم قوي صنع آلية خارج ما زال إبقاء `pnpm run migrate:packed-session-fixtures`، وحيد سبب هو يجعل يحمل قديم إصدار fixture تعديل في طريق فرع يمكن دمج حالي `master`، و في لا إعادة تسجيل صنع نموذج إخراج حال حال تحت عبر آلة آلة تحويل استلام جمع.

واحد حالما كل هذا صنف فرع متساو قد دمج، إغلاق أو رمز دمج مواصفة، كتابة أمر و ذلك فرع استلام جمع إشارة جذب سهل لم يعد لديه حمل متابعة صيانة من. مرور عبور انتهاء بعد متابعة إبقاء سوف تعديل مستودع محتوى أمر، سوف في دائم دائم فقط قراءة لقطة فحص جانب زيادة ثاني بند نظر يشبه صالح صيانة مسار.

## رفع سجل

في فوري بيان تأكيد لم يعد لديه أي فتح وضع PR(Pull Request) حاجة تحويل جلسة صيغة JSONL بعد، إزالة مؤقت CLI `scripts/migrate-packed-session-fixtures.ts`، و أصل حزمة توفير `migrate:packed-session-fixtures` أمر. في نفس تغيير في، إزالة اختبار سياسة سياسة،ACP لقطة README و قد تنفيذ تحزيم سطر Agent Note في إشارة نحو هذا مرور عبور أمر رابط، و سوف `scripts/session-fixture-layout.snapshot.ts` في فقط ملائم لأجل هذا أمر إصلاح إشارة جذب استبدال لـ و أداة جسم أمر غير متصل مواصفة تخطيط إشارة جذب.

إبقاء `scripts/session-fixture-layout.ts`، ذلك اختبار وحدة و `scripts/session-fixture-layout.snapshot.ts`. هو جمع تعريف و قوي صنع تنفيذ دائم دائم مواصفة تخطيط؛ فقط لديه موجه إلى فرع كتابة جهاز هو مؤقت آلية.

إزالة أمر قبل، كل تلقي أثر فرع كل يلزم دمج حالي `master`، تشغيل مرة ترحيل جهاز، سوف من هذا إنتاج كما فقط يتضمن fixture إعادة كتابة تعديل مفرد وحيد إيداع، و تحقق مستودع درجة لقطة تخطيط فحص عبر. قد إغلاق أو يتم يحل محل فرع بلا حاجة ترحيل.

## سبق اعتبار بديل خطة

**بلا حد مدة إبقاء هذا أمر.** هذا سوف يجعل قديم fixture تحويل أكثر جهة سهل، لكن أيضا سوف في وحيد معروف ترحيل نافذة إغلاق بعد، إبقاء تحت واحد مستودع درجة كتابة أداة. فقط قراءة بوابة قد توفير يمكن طويل مدة إبقاء سلوك و تشخيص.

**مع CLI واحد نفس إزالة مواصفة تخطيط تحويل وحدة.** هذا وحدة لا هو مرور عبور ناقص إبقاء: لقطة CI استخدام هو اكتشاف لم قدوم fixture، حل رمز خلط دمج شيء إدارة سجل، و و مواصفة تحزيم يمثل إجراء مقارنة مقارنة. إزالة هذا وحدة أيضا سوف إزالة قوي صنع آلية.

**تحزيم سطر دخول `master` بعد قيام أي حذف أمر.** مقارنة قديم فتح وضع فرع في ضبط كامل هدف فرع بعد، فقط قدرة استخدام مؤقت نص برمجي أو يد حركة إعادة توليد لقطة، هذا سوف زيادة اندفاع مفاجئ ريح خطر، أيضا سوف يجعل حل رمز حدث حفظ حق درجة أكثر صعب مراجعة.

## تحقق استلام معيار

- فوري فتح وضع PR بيان لم اكتشاف أي ما زال اعتماد مؤقت ترحيل أمر معالجة جلسة صيغة JSONL تعديل فرع.
- مؤقت CLI، أصل حزمة أمر، كل فرع استلام جمع رابط و فقط ملائم لأجل هذا أمر بوابة تشخيص متساو لا وجود؛ دائم دائم مواصفة تخطيط تحويل جهاز، اختبار وحدة و لقطة فحص ما زال إبقاء.
- `pnpm run test:snapshot`،`pnpm run doc-sync`،lint و فارغ أبيض تحقق في لا يوجد مؤقت أمر حال حال تحت عبر.
- حالي وثيقة فقط وصف تحزيم قيمة افتراضية و دائم دائم مواصفة تخطيط قوي صنع آلية.

## ريح خطر

إذا فتح وضع فرع بيان لا كامل، أمر إزالة فقد بعد، مساهمة من ممكن سوف وقوع دخول كبير قاعدة نموذج غير تحزيم fixture اندفاع مفاجئ. لذلك، إزالة عملية أخذ قرار في فوري PR دليل، بينما لا هو مرور مرور وقت. إبقاء أمر مرور دائم تشغيل صيانة صار هذا مقارنة منخفض، لكن سوف نموذج غامض أي واحد نوع آلية عندئذ هو دائم دائم آلية.
