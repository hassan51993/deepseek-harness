# Agent Note: بـ تلقي جمهور لـ أولا وثيقة جودة كمية معيار

Status: proposed

[English](2026-08-20-audience-first-documentation-quality.md) | العربية

## مشكلة

وثيقة نظام يملك سليم كل وضع وضع، جديد طازج درجة، رابط، مزدوج لغة و مصدر انتظار قيمة صفة فحص، لكن لا يوجد يأخذ «بسيط قصير، مباشر مراقبة، صديق جيد» تعريف صار يمكن توفير مستخدم، جديد شخص، تطوير من و agent(ذكي جسم) مراجعة نتيجة. الكل `doc-sync`(وثيقة تزامن بوابة) فحص و الكل قلب ترجمة إعداد مقابل متساو عبر، لكن ما زال وجود التالي تصميم مشكلة. قبل ثلاثة بند اكتشاف هو تصميم إعادة نقطة؛ سعة كمية مشكلة فإن حل تفسير لـ ماذا زيادة أكثر كثير معتاد إقامة قاعدة لا يمكن حل قرار هو جمع.

### دلالة صحيح تأكيد صفة يمكن في لا يوجد الآن سطر ملكية من حال حال تحت عبر فحص

هذه بوابة إثبات بنية و توليد محتوى جديد طازج درجة، لكن لا يستطيع إثبات صيانة في متن ما زال إشارة نحو فعلي آلية. بـ قبل `dsh-doc-site-sync` تقنية قدرة سبق اشتراط عمل من إعادة استخدام و لا وجود `en-docs` الشريط الجانبي، أيضا اشتراط يأخذ فصل عقدة إضافة دخول قد إزالة `sectionOrder`؛[website/docs.ts](../../../../website/docs.ts) فعلي يملك `en-guide`،`en-develop`،`en-reference` و `sections`. قد تنفيذ[منتج أولوية README قرار](../../archived/process/2026-07-22-product-first-root-readme.md) وصف داخلي اختبار شرح، و ACP،Python و JSON-RPC واجهة فصل عقدة، لكن[أصل README](../../../../README.ar.md) و بلا هذه محتوى؛ و هذا معا، قد تنفيذ Agent Note يجب تتبع مع قد تسليم واقع.

ميزانية سياسة أيضا وجود نفسه قسم شق.[docs/AGENTS.md](../../../../docs/AGENTS.md#wordcount-budgets) لـ `architecture.md` قاعدة تحديد 1,800 كلمة هدف و 5% بقية كمية، لكن[ميزانية manifest(بيانات وصفية بيان)](../../../../scripts/doc-budgets.manifest.json) سماح 2,400 كلمة، بينما هذا ملف فعلي يتضمن 1,313 كلمة. ميزانية بوابة لـ الذي بـ عبر، هو لأن هو فقط فحص manifest حد أعلى، لا فحص هدف أو شائك جولة قاعدة. لذلك، عال أثر متن حاجة واحد أداة اسم حق مصدر أو إزالة استهلاك حق مصدر تجمع تركيز فحص؛ ثاني نسخة يد كتابة فرعي هذا لا هو جديد طازج درجة آلية.

### قراءة من نجاح و لا هو خفي يحتوي حكم قطع، بينما لا هو يمكن اختبار نتيجة

معيار يأخذ صفحة قسم صار تعليم مسار و مشاركة اعتبار، و اشتراط عمل من خاص تحت حكم قطع تعليم مسار قراءة من بدء بداية ماء مستو. معيار لا يوجد اشتراط إبقاء تحت يمكن توفير مراجعة قراءة من بدء بداية حالة، مسبق مدة نتيجة، الأكثر قصير نجاح مسار، معتاد رؤية فشل أو تحت واحد مقالة لديه استخدام صفحة. لذلك، واحد نسخة وثيقة يمكن ممتلئ كاف طبقة درجة وضع وضع، رابط، كلمة عدد حد و Markdown بنية، لكن لا يوجد إثبات هدف قراءة من قدرة إتمام مهمة.

عام مشترك محطة نقطة مباشر مراقبة عرض هذا نوع ضغط قوة. كل نوع لغة إصدار 84 عدد صفحة:3 عدد إشارة جنوب صفحة،17 عدد تطوير صفحة و 63 عدد مشاركة اعتبار صفحة.`docs/user/` تحت 13 عدد إنجليزي نص ملف مشترك لديه 7,540 كلمة، بينما 47 عدد فرعي نظام صفحة مشترك لديه 100,759 كلمة. بسيط قصير Web سريع سرعة بدء هو جيد جيد منتج مدخل، لكن كل لغة مادة لا يوجد معيار قدوم تحقق أول مرة استخدام من، إضافة جديد شخص و صيانة من هل كل قدرة امتداد واحد بند واضح مسار من مدخل مشي إلى نتيجة و لذا عائق استعادة.

### توليد محتوى دقيق تأكيد صفة و فحص بحث جودة كمية خلط لـ واحد حديث

مستودع يتضمن 19 عدد تماما توليد إنجليزي نص Markdown ملف، مشترك 49,611 كلمة.47 عدد فرعي نظام صفحة في لديه 44 عدد أيضا يتضمن توليد Cordis منطقة مجال؛ هذه منطقة مجال احتلال فرعي نظام طبقة درجة 100,759 كلمة في 34,622 كلمة.`config-catalog.md` لديه 14,807 كلمة،`tool-catalog.md` لديه 10,599 كلمة، الأكثر كبير خلط دمج فرعي نظام صفحة فإن لديه 5,600–7,781 كلمة.

هذه محتوى هو صحيح عند نفاد كل صيغة مشاركة اعتبار، لذلك موحد واحد كلمة عدد حد عكس بينما سوف حذف قيمة قيمة. توليد جهاز إثبات كامل صفة و جديد طازج درجة، لكن معيار لا يوجد لـ سياق نافذة لديه حد agent، أو فقط بحث بحث واحد جواب سجل شخص صنف قراءة من آخر ضبط فحص بحث معيار. توليد مشاركة اعتبار حاجة ضيق تجميع مدخل طبقة، مستقر قسم مجموعة، مباشر مرساة نقطة، و أصل حسب استعلام صار هذا إطلاق تفكيك قسم قاعدة؛ نفاد كل صيغة دقيق عقدة يمكن في هذا مدخل طبقة بعد متابعة إبقاء نفاد كل.

### معيار لا يوجد سعة قبول تحت واحد بند قاعدة فضاء

معتاد إقامة وثيقة معيار لديه 1,320 كلمة، انتظار في 1,320 كلمة حد أعلى، و تجاوز مرور إعلان 1,250 كلمة هدف. أصل `AGENTS.md` لديه 1,936 كلمة، هدف لـ 1,600؛`packages/AGENTS.md` لديه 672 كلمة، هدف لـ 650؛`packages/README.md` لديه 969 كلمة، هدف لـ 600. تجميد ربط حد أعلى قدرة منع توقف دخول واحد خطوة زيادة طويل، لكن لا يوجد لـ تلقي جمهور و نتيجة معيار إنشاء صنع موضع. متابعة زيادة معتاد إقامة متن سوف إضافة عميق هذا معيار هذا ينبغي منع توقف مشكلة.

### أساس خط

هذا مرة مراجعة حساب ترتيب حذف `vendor/`، تجميد ربط `.agents/notes/archived/`، تسجيل صنع لقطة و fixture(اختبار قبل وضع بيانات). تلقي صيانة لغة مادة يتضمن 1,042 عدد إنجليزي نص Markdown ملف و 986 عدد العربية مقابل جانب ملف، مشترك 1,106,138 عدد إنجليزي نص كلمة. نشط وثب Agent Note احتلال 580 عدد ملف و 637,850 كلمة؛`packages/` تحت Markdown احتلال 276 عدد ملف و 225,630 كلمة؛`docs/` احتلال 112 عدد ملف و 193,456 كلمة. هذه عدد كمية وصف صيانة و فحص بحث ضغط قوة، ذاته و لا بنية صار نقص وقوع.

نظام الأكثر قوي صفة جودة ينبغي إعطاء إبقاء: حسب طبقة درجة لـ كل بند واقع إشارة تحديد واحد ملكية من؛ يأخذ مواصفة Markdown إسقاط إلى محطة نقطة بينما لا إنشاء فرعي هذا؛ كامل مزدوج لغة إعداد مقابل؛ مصدر تغيير وقت سريع سرعة فشل توليد دليل؛ مصدر انتظار قيمة إعلان؛ يمكن تحرير ترجمة TypeScript عرض مثال؛ تلقي فحص رابط و مرساة نقطة؛ و حزمة نطاق جزء تجربة النموذج و حد اتفاق. رفع سجل تغيير هو جودة كمية معيار و مدخل بنية، بينما لا هو هذه حفظ إثبات.

## رفع سجل

اعتماد واحد طقم بـ تلقي جمهور لـ أولا جودة كمية اتفاق، و إعطاء خروج خمسة بند تعريف:

- **بسيط قصير**يمثل معتاد استخدام مسار فقط يتضمن بلوغ صار نتيجة الذي يحتاج واقع. نفاد كل صيغة اتفاق ما زال يمكن عبر مباشر رابط أو توليد دقيق عقدة وصول؛ بسيط قصير أبدا معنى طعم حال حذف لا بد يلزم سلوك، فشل، كل حق أو حد.
- **مباشر مراقبة**يمثل صفحة سوف تحديد قراءة من بدء بداية حالة، في اعتماد عام فكرة قبل وسيط تعريف قبل وضع معرفة تعرف، توفير واحد واضح تحت واحد خطوة عملية، و استخدام قراءة من سوف بحث منتج أو مجال فن لغة.
- **صديق جيد**يمثل قراءة من قدرة تعرف آخر نجاح، في عملية قبل إدارة حل فعلي جودة ريح خطر، من معتاد رؤية فشل في استعادة، و في بلا حاجة أولا تعلم تعود غير متصل هيكل بنية حال حال تحت دخول تحت واحد طبقة متبادل صلة دقيق عقدة.
- **دقيق تأكيد**يمثل كل بند حمل دائم واقع كل لديه واحد ملكية من و و ريح خطر متبادل تسمية تحقق مسار. توليد واقع قدوم ذاتي مصدر؛ يد كتابة سير العمل قيمة رابط أو إزالة استهلاك ذلك ملكية من، بينما لا هو نسخ قطعة رفع و مسار.
- **سهل في agent قراءة قراءة**يمثل عنوان، مرساة نقطة، فن لغة، كل حق و حالي و رفع اقتراح حالة كاف كاف واضح، بلا حاجة تحميل كامل لغة مادة أو إعادة بناء مراجعة تاريخ يكفي فحص بحث الذي يحتاج فصل عقدة.

### أصل نوع قاعدة

[dsh-doc skill](../../../skills/dsh-doc/SKILL.md) مسؤول هذه قاعدة أول عدد يمكن تنفيذ إصدار.`session-persistence-jsonl` README مقابل بـ قد تسليم إلحاق، استعادة و تحرير رمز سلوك لـ دليل، بينما لا يأخذ ذلك قديم إصدار متن عند عمل مرجعي.

- كل تأليف كتابة نوع حزمة README كل بـ يمكن بحث YAML فتح رأس.Skill ريح إطار `description` و حسب آلية دفع توجيه `kind` لـ لا بد ملء حقل. أربعة نوع kind و أربعة عدد تقنية قدرة نموذج لوح واحد واحد مقابل:`package-group`(مجموعة أرض رسم) ،`package-reference`(إضافة أو خدمة حزمة) ،`package-library`(صاف وحدة مدخل) و `package-bundle`(`dsh.bundle.patch`). مقابل وفق ملف مسار، ها أمل و شيء إدارة سطر مقابل متساو من دعم حمل تلقائي دمج sidecar و ذلك بوابة مسؤول، لذلك README frontmatter لا يتضمن `i18n` كتلة. اسم قد من عنوان أو حزمة manifest ملكية، تلقي جمهور قد من وثيقة مسؤولية جدول بلوغ؛ في تلقي معالجة إدارة وسم تصنيف و بحث مستهلك إثبات ذلك قيمة قيمة تجاوز مرور كل نص فحص بحث قبل، لا إضافة دخول وسم.
- تأليف كتابة نوع صفحة أولا كتابة ثلاثة حتى خمسة جملة `Summary`، مجددا كتابة حمل رابط `Table of Contents`. إنجليزي نص حزمة README Summary لا تجاوز مرور 100 عدد حسب `wc -w` دلالة موحد حساب كلمة. هو وصف قراءة من مرئي قدرة، بينما لا هو Cordis زاوية لون، تسجيل بند أو داخلي مكون؛ حذف غير قراءة من سوف في إعداد، أمر أو عام API في مباشر استخدام بعض عدد شفرة المصدر معرف رمز، لا فإن لا نيل كتابة هذا معرف رمز. من صيغة قيد Agent Note، أمر لذا تكرار قرص، توليد قطعة مقطع و آلة جهاز ملف إبقاء ذلك مطلوب هيكل هيكل.
- كل فعلي جودة فصل عقدة في فرعي فصل عقدة، جدول إطار أو شفرة قبل أولا إعطاء خروج بسيط قصير جذب توجيه، صفحة فإن من أساس أساس مستخدم استخدام قاعدة تدريجي خطوة دخول عال درجة تطوير من و صيانة من دقيق عقدة.
- إنجليزي نص تقنية فن متن اعتماد تلقي ASD-STE100 بدء إرسال لكن لا إعلان تسمية إقرار إثبات صاف واضح درجة مراجعة: واضح سطر حركة من و حركة عمل، مستقر استخدام فن لغة، استخدام مباشر حركة كلمة، تفكيك قسم إشارة أمر و شرط، و كامل إبقاء حال حالة، مثال خارج، وقت ترتيب و عدد قيمة. إشارة أمر 20 كلمة و وصف 25 كلمة حد فقط عمل مراجعة تلميح. دقيق تأكيد صفة عال في جملة طويل.
- حزمة اتفاق إبقاء في شفرة جانب. عبر حزمة مادة مادة لديه خطة أرض نحو `docs/learn/overview/`،`docs/learn/cordis/`،`docs/learn/practices/`،`docs/user/`،`docs/developer/`،`docs/developer/discussion/`،`docs/scratch/` و مستو سطر `docs/subsystems/` طبقة درجة ترحيل.
- إنجليزي نص و العربية صفحة إبقاء نفس انتظار مرجعي، و في بنية، رابط، شفرة،frontmatter تخطيط و دقيق شيء إدارة سطر عدد فوق واحد واحد مقابل.
- داخل ربط إعداد مقابل بيانات وصفية هو مرافق مع ملف هدف بديل خطة. في تحقق جهاز، دمج قيادة، استعادة مسار، توليد منطقة مجال سجل جهاز و عودة ملف فحص إزالة استهلاك غير ذاتي مرجع إعداد مقابل ملخص قبل، أصل نوع يمكن معا إبقاء اثنان من.
- مستودع أصل درجة داخلي رابط هو هدف تأليف كتابة نموذج. أصل نوع إبقاء مصير متاح متبادل مقابل رابط، لأن قبل توجيه `/` حالي سوف في GitHub فوق مغادرة فتح مستودع، التفاف مرور `verify-md-links`، و كما لن من محطة نقطة إسقاط.
- `Further Exploration` هو اختياري جديد شخص مسار، رابط ثلاثة حتى سبعة عدد متبادل مجاور صفحة.
- كل تأليف كتابة نوع صفحة كل بـ `Dev Note` ربط ذيل، بصفة نشط وثب خشن اختصار سياق وحيد موضع. هو إبقاء غير مرجعي حالة، فقط رابط بينما لا نسخ مهمة حالة، و في عمل انتهاء وقت إتمام رفع رفع أو تنظيف.
- يمكن مستقل بحث قاعدة، فعلي ممارسة، عرض مثال و قرار في يملك مختلف ملكية من أو تغيير عقدة عزف وقت، استخدام وصف صفة دليل تحت صغير ملف؛ ضيق سري اقتران دمج معنى خدمة إبقاء في واحد بدء.

هذا جدول ينبغي ملكية واحد نسخة مواصفة جودة كمية مشاركة اعتبار.`docs/AGENTS.md` فقط إبقاء كل مرة تحرير وثيقة كل حاجة بسيط قصير معتاد إقامة قاعدة، و رابط إلى هذا مشاركة اعتبار. هذا مثال يمكن إنشاء صنع ميزانية بقية كمية، بينما لا هو يأخذ آخر نسخة كامل معيار وضع دخول agent سياق.

### توليد مشاركة اعتبار مدخل طبقة و دقيق عقدة طبقة

كل نسخة توليد مشاركة اعتبار كل ينبغي في نفاد كل صيغة إخراج قبل توفير ضيق تجميع مدخل طبقة: نطاق، مسبق مدة استعلام، قسم مجموعة أو بحث جذب، عام فكرة إشارة جنوب مباشر رابط، و توليد جهاز أو فحص أمر. توليد جهاز ينبغي تقرير إبلاغ صفحة كلمة عدد، بند عدد، عنوان عدد و الأكثر كبير فصل عقدة. عند مرة استعلام حاجة مسح غير متصل قسم مجموعة، أو مفرد صفحة رئيسي توجيه agent سياق وقت، هذا صفحة سهل عبر مرور مراجعة عتبة قيمة؛ مع بعد، ملكية من حسب وفق مصدر بيانات وصفية في قد لديه مستقر مجال تفكيك قسم صفحة، بينما لا هو حسب مهمة معنى كلمة عدد مقتطعة.

أول عدد أصل نوع ينبغي اختيار واحد كبير نوع دليل و واحد خلط دمج فرعي نظام صفحة. في إجراء كل لغة مادة تفكيك قسم قبل، هو ينبغي مقارنة مقارنة استعلام خطوة، توليد diff كبير صغير، بناء وقت، توجيه مستقر صفة، و بديل جدول صفة مشكلة الذي يحتاج agent سياق. توجيه نقل حركة وقت، قائم مرساة نقطة حاجة إبقاء آخر اسم.

### تنفيذ مقتطعة

1. إنشاء و تحقق `dsh-doc`، مجددا يأخذ واحد مجموعة package README مقابل تعديل كتابة لـ سطر مقابل متساو، حمل بيانات وصفية أصل نوع، معا لا تغيير وقت التشغيل واقع.
2. استخدام جديد شخص، مستخدم، تطوير من و agent مهمة مراجعة تصيير بعد أصل نوع؛ أولا إصلاح حجز skill، مجددا في أخرى موضع قوي صنع تنفيذ هذا صيغة.
3. إضافة تجمع تركيز بيانات وصفية،Summary طويل درجة، فصل عقدة ترتيب، سطر مقابل متساو، رابط تحليل و إعداد مقابل fixture. ترحيل كل مخالفة عكس قد قبول مدخل حد أعلى قائم حزمة Summary؛ في كل دمج و استعادة مستهلك كل لديه بديل دعم حمل قبل، إبقاء مرافق مع ملف.
4. يأخذ قد قبول معتاد إقامة قاعدة رفع أخذ إلى واحد نسخة مواصفة جودة كمية مشاركة اعتبار، سوف `docs/AGENTS.md` دقيق بسيط إلى هدف التالي، و كما مرة فقط مجموعة نسج واحد داخل تجمع `docs/` رئيسي عنوان، معا أصل فرعي أرض إصلاح رابط و تنقل.
5. في `config-catalog.md` و `docs/subsystems/core.md` فوق صنع عمل توليد مشاركة اعتبار مدخل طبقة و دقيق عقدة طبقة قسم مغادرة أصل نوع؛ فقط لديه فعلي قياس استعلام صار هذا تحت خفض كما لا يوجد فقد فقد واقع أو صنع صار توجيه إزعاج حركة، عندئذ يأخذ تأكيد بعد نمط تطبيق إلى أخرى موضع.

هذا ترتيب جعل كل بند تغيير كل قدرة مستقل مراجعة. قبل ثلاثة عدد مقتطعة تعديل دخول معيار و حزمة مدخل، بينما لا تغيير أكثر واسع معلومة هيكل بنية؛ توليد وثيقة أصل نوع فإن في أكثر واسع بنية تغيير قبل توفير دليل.

مقتطعة 1–3 قد حسب هذا شكل صيغة تسليم:`dsh-doc` يصبح دمج بعد معيار (`dsh-doc-standards` و `dsh-doc-site-sync` قد و دخول منها، محطة نقطة سير العمل يحمل إصلاح صحيح بعد الشريط الجانبي قيمة) ،`session-persistence-jsonl` README مقابل هو مشاركة اعتبار عرض مثال،`pnpm run test:docs` قوي صنع تنفيذ بيانات وصفية، إعداد مقابل و سريع سرعة وثيقة فحص. مقتطعة 4–5 ما زال انتظار إتمام.

### غير هدف

هذا رفع سجل لا تقليص نقص نفاد كل صيغة واقع، لا دمج تلقي جمهور طبقة درجة، لا إصدار داخلي قرار سجل، لا استعادة Agent Note بحث جذب، لا لـ ملف عدد مقابل تسمية بينما تفكيك قسم ضيق سري اقتران دمج قاعدة، أيضا لا يأخذ هذا مرة مراجعة حساب عند أثر مستخدم بحث بحث. في بديل خطة عبر انتظار قيمة استعادة و تصيير فحص قبل، هذا رفع سجل لا حذف قائم إعداد مقابل أو رابط أساس أساس ضبط تطبيق.

## اعتبار مرور تجهيز اختيار خطة

**لـ كل نسخة وثيقة ضبط موحد واحد كلمة عدد حد أعلى.**غير مقبول، لأن نفاد كل صيغة مشاركة اعتبار بند، عام اتفاق و قرار إدارة من يمكن حيث طويل أيضا صحيح تأكيد. مقابل هذه وثيقة مسؤولية بينما قول، مدخل مسار طويل درجة و استعلام صار هذا عندئذ هو متبادل صلة قيد.

**قوي صنع استخدام موحد واحد صفحة نموذج لوح أو تلقي جمهور قبل وضع بيانات وصفية.**غير مقبول، لأن هذا سوف إعطاء توليد صفحة، حزمة مشاركة اعتبار و بسيط قصير إشارة أمر زيادة شكل صيغة، لكن لا يستطيع إثبات قراءة من نجاح. معيار حسب وثيقة مسؤولية تعريف نتيجة، فقط في `kind` قدرة اختيار أداة جسم حزمة وثيقة معيار وقت استخدام هو، و كما فقط إضافة تجمع تركيز فحص أو مراجعة سوف إزالة استهلاك حقل.

**يأخذ يمكن قراءة صفة قسم عدد بصفة جودة كمية بوابة.**غير مقبول، لأن عام صيغة سوف عقاب عقوبة دقيق تقنية فن فن لغة، لكن لا يمكن اكتشاف خطأ كل حق، متروك تسرب فشل سلوك، قديم قديم أمر أو كسر ضرر قراءة من مسار.

**قيام أي إعادة كتابة أو تفكيك قسم الكل وثيقة لغة مادة.**غير مقبول، لأن قائم نظام في آلية فوق سليم سليم، سماح كثير طويل مشاركة اعتبار أيضا تأكيد فعلي ينبغي إبقاء نفاد كل. نطاق تلقي حد حزمة Summary ترحيل لن تغيير توجيه أو نفاد كل صيغة مشاركة اعتبار محتوى؛ أكثر كبير بنية تغيير ما زال يحتاج فعلي قياس دليل.

**إبقاء قائم بوابة، يجعل مراجعة مسؤول صديق جيد مسار درجة.**غير مقبول، لأن قديم قديم سير العمل قيمة و ميزانية سياسة لا متسق شرح، فقط سند مراجعة لا يمكن إبقاء نسخ دلالة واقع، بينما قائم بوابة أيضا لا استفسار سؤال قراءة من هل قدرة إتمام مهمة.

## تحقق استلام معيار

- واحد نسخة مواصفة جودة كمية مشاركة اعتبار حسب وثيقة مسؤولية تعريف بسيط قصير، مباشر مراقبة، صديق جيد، دقيق تأكيد و سهل في agent قراءة قراءة وثيقة.
- `.agents/skills/dsh-doc` عبر تحقق، و مباشر رابط ذلك بيانات وصفية، بنية أو طبقة درجة و مراجعة أو أصل نوع مشاركة اعتبار، بينما لا في `SKILL.md` في نسخ هذه مشاركة اعتبار تفصيل دقيق قاعدة.
- `session-persistence-jsonl` README مقابل عرض يمكن بحث YAML،Summary،Table of Contents، من مستخدم إلى تطوير من تدريجي دخول بنية،Further Exploration، ربط ذيل Dev Note، بنية متسق صفة و دقيق سطر عدد متبادل انتظار، معا إبقاء قد تحقق حزمة اتفاق.
- كل إنجليزي نص حزمة README Summary كل لا تجاوز مرور 100 عدد حسب `wc -w` دلالة موحد حساب كلمة؛ تجمع تركيز بوابة تقرير إبلاغ فعلي قياس كلمة عدد، و جذب توجيه فشل بند قراءة قراءة `dsh-doc` و الذي اختيار kind نموذج لوح.
- `docs/AGENTS.md` رابط هذا مشاركة اعتبار، ما زال كاف بـ ملء عند معتاد إقامة إشارة أمر، و منخفض في ذلك هدف كما حتى قليل إبقاء 5% بقية كمية.
- أصل درجة مستخدم مسار،Web سريع سرعة بدء، رقم واحد إضافة تعليم مسار، مساهمة من ضبط و هيكل بنية عام تصفح كل منها إعطاء خروج واحد يمكن مراقبة نتيجة و تحقق ملكية من، معا لا نسخ تنفيذ دقيق عقدة.
- ميزانية manifest معا سجل هدف و مؤقت حد أعلى، ذلك فحص سوف تقرير إبلاغ أو رفض مخالفة عكس بقية كمية أو شائك جولة قاعدة حالة.
- وثيقة محطة سير العمل لم يعد يتضمن نسخ بلا فاعلية الشريط الجانبي اسم أو فصل عقدة ملكية إعلان، و لديه تجمع تركيز اختبار منع توقف تكرار إرسال.
- sidecar متابعة بصفة وحيد متسق صفة سجل، لأن هو قدرة إبقاء نفس انتظار مرجعي، فوق مرة تأكيد نص استعادة، تلقائي دمج أمان، توليد منطقة مجال سجل و عودة ملف غلاف تخزين، معا لن في متن ملف في صنع صنع اندفاع مفاجئ.
- واحد قد قبول مستودع أصل درجة رابط صيغة في ترحيل متبادل مقابل رابط قبل قدرة في GitHub و وثيقة محطة صحيح تأكيد تصيير، و متابعة قبول محلي هدف أو مرساة نقطة فحص.
- واحد كبير نوع مستقل توليد دليل صفحة و واحد خلط دمج فرعي نظام صفحة عرض ضيق تجميع مدخل طبقة و أكثر منخفض فعلي قياس استعلام صار هذا، معا إبقاء نفاد كل صيغة توليد واقع، مستقر رابط، مزدوج لغة إعداد مقابل و تحديد صفة جديد طازج درجة.
- `pnpm run doc-sync`،`pnpm run lint`، تجمع تركيز جديد فحص و `git diff --check` متساو عبر.

## ريح خطر

- بيانات وصفية ممكن سقوط لـ مثال لوح؛ لذلك حزمة README فحص فقط سماح أداة لديه الآن سطر فحص بحث، نموذج لوح اختيار أو مزدوج لغة متسق صفة مستهلك حقل.
- صلب صفة جملة طويل حد ممكن قطع شق شرح، أو يأخذ شرط و عاقبة قسم فتح. تلقي تحكم إنجليزي لغة جملة طويل فقط عمل مراجعة تلميح؛ مفرد وحيد 100 كلمة حزمة Summary حد أعلى فقط قيد مدخل مقطع سقوط، دقيق اتفاق ما زال إبقاء في ذلك ملكية فصل عقدة.
- دقيق سطر مقابل متساو ممكن إجبار جعل ترجمة من كتابة خروج لا ذاتي لكن متن؛ مراجعة يجب حفظ حماية يحتوي معنى، و يمكن معا إصلاح حجز اثنان جانب، بينما لا هو تقليل ضعيف منها واحد جانب.
- تفكيك قسم توليد مشاركة اعتبار ممكن زيادة توجيه و رابط صيانة؛ أصل نوع يجب إبقاء آخر اسم و توازن كمية أخذ ترك.
- دلالة فحص ممكن تمدد انتفاخ صار منع سد صحيح عند تغيير مستودع توسيع اندفاع مسح جهاز؛ فحص ينبغي تغطية عال ريح خطر نسخ قيمة و بديل جدول صفة مسار، بينما متن يحتوي معنى ما زال من مراجعة مسؤول.
- حزمة README سريع سرعة مشاركة اعتبار جدول سوف يد عمل تكرار جزء إعداد قيمة افتراضية؛ في مصدر قيادة فحص وصل إدارة قبل، مراجعة من يجب مقابل وفق شفرة المصدر و توليد إعداد دليل تحقق تغيير قيمة، و يجعل هذه جدول إبقاء دقيق اختيار بينما غير نفاد كل.
- لـ تقليص قصير agent سياق بينما أفضل تحويل ممكن جعل شخص صنف مشاركة اعتبار تغيير نيل تفتيت قطعة تحويل؛ كل مرة تفكيك قسم كل حاجة واحد مستقر عام فكرة ملكية من و واحد بند واضح تنقل مسار.
- دائم دائم Dev Note ممكن تغيير صار ثاني نسخة طابور صف أو قديم قديم تاريخ كومة تراكم؛ إتمام عمل وقت يجب رفع رفع حمل دائم واقع و حذف قد حل قرار مرور مسار محتوى.
- هذا مرة مراجعة حساب استخدام مستودع بنية، بوابة و بديل جدول صفة صفحة، بينما لا هو مستخدم بحث بحث. في واسع عام دفع واسع قبل، صيانة من ينبغي عبر حقيقي جديد شخص، مستخدم، تطوير من و agent مهمة تحقق رفع اقتراح قراءة من نتيجة.
