# Agent Note: API extractor تقرير إبلاغ

Status: proposed

[English](2026-06-11-api-extractor-reports.md) | العربية

> وثيقة كتلة نوع فحص و حدث تصنيف جسم نظام اثنان جزء قد تسليم ([doc-sync(وثيقة تزامن بوابة) قوي صنع](../../archived/process/2026-06-11-doc-sync-enforcement.md)) ؛ باق بقية API تقرير إبلاغ جزء بصفة مستقل رفع سجل يتم دفع متأخر.

## مشكلة

عام API تغيير هو غير ممكن رؤية: لا يوجد أي آلية سوف «هذا مرة إيداع تغيير عام واجهة» تغيير لـ واحد صريح، يمكن مراجعة واقع. مراجعة من قراءة قراءة diff وقت ممكن متروك تسرب بعض عدد تصدير نوع إضافة جديدة حقل، أو بعض عدد طريقة توقيع حدوث تغير.

## رفع سجل

استخدام api-extractor(أو `tsc --emitDeclarationOnly` إضافة واحد نسخة مواصفة تحويل عام API بيان) لـ كل حزمة توليد واحد نسخة توقيع دخول مستودع `etc/<pkg>.api.md`؛CI في إعادة توليد نتيجة و قد توقيع دخول تقرير إبلاغ لا متسق وقت فشل. هذا مثال، كل مرة عام API تغيير كل سوف يصبح مراجعة من (أو مراجعة agent(ذكي جسم)) يجب يرى واحد سطر diff.

## سبق اعتبار بديل خطة

**`tsc --emitDeclarationOnly` إضافة مواصفة تحويل عام API بيان**: إذا api-extractor مرور في أخرق إعادة، هذا هو أكثر خفيف كمية آلية؛ اثنان من كل قدرة ممتلئ كاف رفع سجل الذي يحتاج «توقيع دخول مستودع، يمكن diff» تقرير إبلاغ شكل.

## تحقق استلام معيار

- كل حزمة كل لديه واحد نسخة توقيع دخول مستودع `etc/<pkg>.api.md`؛CI في إعادة توليد نتيجة و قد إيداع تقرير إبلاغ لا متسق وقت فشل.
- عام API تغيير (إضافة جديدة تصدير، حقل وضع عرض، توقيع تغير) في مراجعة في بـ تقرير إبلاغ diff سطر شكل صيغة مرئي.

## ريح خطر

هذا اعتماد أخرق إعادة كما صعب بـ ضبط تعليم (هذا صحيح هو هو يتم دفع متأخر سبب) ، كما تقرير إبلاغ صيغة سوف مع تحرير ترجمة جهاز ترقية بينما تغيير حركة، زيادة واحد صيانة وجه؛ في كل حزمة بعد لم إصدار مرحلة مقطع، استلام فائدة لديه حد.

## دفع متأخر سبب

في doc-sync سقوط أرض وقت يتم دفع متأخر: مقابل في واحد داخلي monorepo، مراجعة من قد قدرة يرى شفرة المصدر diff، قيمة قيمة لا عال؛ كما اعتماد أخرق إعادة، صعب بـ ضبط تعليم. إذا كل حزمة سوف قدوم مقابل خارج إصدار، مجددا إعادة تقييم تقدير——دورة وقت واحد نسخة مستقر، يمكن diff عام واجهة تقرير إبلاغ عندئذ قيمة نيل ذلك صيانة صار هذا.
