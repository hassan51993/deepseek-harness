# Agent Note: إزالة Desktop و إبقاء Harness رئيسي دليل

Status: proposed

[English](2026-09-08-desktop-uninstall-preserve-dsh-home.md) | العربية

## مشكلة

مستخدم حاجة Desktop إزالة حذف تطبيق ملف و خارجي تطبيق حالة، معا إبقاء كامل Harness رئيسي دليل. حذف تطبيق دليل و لا يستطيع تغطية متصفح تخزين، تثبيت جهاز ذاكرة مؤقتة أو أصلي تحديث جهاز حالة. متصفح تخزين أيضا يتضمن لم إرسال مسودة مسودة و واجهة انحراف جيد، لذلك تنظيف هو لا فقط هو تحرير مغناطيس قرص ذاكرة مؤقتة.

[تحزيم إعداد](../../../../apps/desktop/electron-builder.config.mjs) ،[طاولة وجه مدخل](../../../../apps/desktop/src/main.ts) و[تحديث تنسيق ضبط جهاز](../../../../apps/desktop/src/update-coordinator.ts) هو شفرة فحص اعتماد حسب. شفرة المصدر فحص لأجل تعرف آخر تنظيف مرشح بند؛ تنفيذ تحقق استلام قبل، يجب عبر قد تثبيت ناتج مراقبة تحديد تلقي دعم حمل كامل بيان. هدف قبل بعد لم عبر إزالة فعلي تحقق بناء قيام كامل Windows أو macOS بيان.

## رفع سجل

توفير إزالة عملية: نجاح بعد إبقاء كامل افتراضي `~/.dsh` و قد إعداد `DSH_HOME`، حذف هذه رئيسي دليل خارج من Desktop يملك ملف، و إزالة اختيار تحديد تطبيق تثبيت. إبقاء رئيسي دليل داخل إضافة ملف، حزمة إدارة جهاز حالة، جلسة، ضبط و اعتماد. تنظيف خلال لا نيل بدء أو إصلاح Desktop profile.

Windows تحكم وجه لوح و ضبط في إزالة سوف عبر NSIS تنفيذ هذا عملية.macOS سوف توفير محلي تحويل**إزالة و إبقاء Harness بيانات**عملية، من توقيع تنظيف مساعد مساعدة برنامج إتمام؛ مفرد صاف عبر Finder سحب دخول ملغى ورق سلة لا يستطيع استدعاء هذا عملية، وثيقة يجب شرح هذا واحد حد، و سوف نفس مساعد مساعدة برنامج بصفة توقيع مستقل إزالة جهاز توفير إعطاء قد حذف تطبيق مستخدم. لا نيل يأخذ مفرد صاف سحب جر إعلان نقل لـ كامل تنظيف.

مستخدم إنشاء مشروع، مفرد وحيد تثبيت CLI(أمر سطر واجهة) لين عنصر، مستخدم حفظ تحت تحميل ملف و توجيه خروج ملف، مهمة معنى رقم ثلاثة جهة إضافة أو أداة إخراج، و عملية نظام صيانة مراجعة حساب و أمان سجل، لا يخص تطبيق تنظيف نطاق. لا نيل حسب ملف اسم يتضمن `dsh` أو `DeepSeek` كل قرص بحث. نجاح تحمل وعد إبرة مقابل استخدام يملك حالة، لا يشمل حذف مستخدم عمل صار نتيجة أو مسح حذف نظام تاريخ.

### 1. تحديد ملكية و فعلي مسار

استخدام مرة صفة Windows و macOS حساب مستخدم، سجل تثبيت، أول مرة بدء، تحرير مسودة مسودة، تثبيت إضافة، تحت تحميل تحديث، تثبيت تحديث و إزالة قبل بعد نظام الملفات و متبادل صلة تسجيل معلومة فرق مختلف. فحص تحزيم بعد `package.json`،macOS `Info.plist`،`app-update.yml` و وقت التشغيل `app.getPath()` قيمة. تغطية تحديث فشل و في قطع. سوف اكتشاف ملكية و تنظيف موضع سجل في طاولة وجه تنفيذ مرفق قريب، توفير fixture(اختبار قبل وضع بيانات) دليل، لا اعتماد حركة حالة استقبال مهمة معنى قطعا مقابل مسار بيان.

| مرشح بند | Windows | macOS | معالجة اشتراط |
|---|---|---|---|
| Electron مستخدم و جلسة بيانات | وقت التشغيل `userData` و `sessionData`، عبر معتاد يقع في `%APPDATA%` تحت | وقت التشغيل `userData` و `sessionData`، عبر معتاد يقع في `~/Library/Application Support` تحت | حذف متصفح تخزين، انحراف جيد، ذاكرة مؤقتة و `.updaterId`؛ شرح لم إرسال مسودة مسودة سوف فقد فقد. |
| تثبيت جهاز و تحديث ذاكرة مؤقتة | `%LOCALAPPDATA%/<updaterCacheDirName>` | `~/Library/Caches/<updaterCacheDirName>` | حذف تثبيت جهاز فرعي هذا،ZIP،blockmap، انتظار معالجة تحت تحميل و بيانات وصفية؛ يشمل NSIS تثبيت خلال إنشاء تثبيت جهاز ذاكرة مؤقتة فرعي هذا. |
| أصلي تحديث جهاز حالة | عبر فعلي تثبيت NSIS مسار إثبات فعلي أخرى مسار | تطبيق مخصص تابع Squirrel و `<appId>.ShipIt` ذاكرة مؤقتة، حالة و سجل دليل | إيقاف الذي تابع تحديث مهمة، انتظار خروج بعد حذف ناقص إبقاء حالة. |
| أخرى أصلي تطبيق حالة | مراقبة إثبات فعلي من تطبيق يملك ملف و تسجيل معلومة | مراقبة إثبات فعلي تطبيق مخصص تابع انحراف جيد، نافذة استعادة حالة، سجل أو تشخيص بيانات | فقط إضافة دخول ملكية قد تحديد مشروع؛ وجود Electron مسار API لا كاف بـ إثبات ملف سوف إنتاج. |
| تطبيق و نظام تجميع صار | تثبيت دليل، تثبيت سريع سريع طريقة، تثبيت و إزالة تسجيل معلومة | اختيار تحديد `.app` و مساعد مساعدة برنامج يملك نظام تجميع صار | استخدام أصلي إزالة مسار، و تحقق اختيار تحديد تثبيت هوية. |
| Harness رئيسي دليل | افتراضي `.dsh` و قد إعداد `DSH_HOME` | افتراضي `.dsh` و قد إعداد `DSH_HOME` | إبقاء كامل دليل شجرة، يشمل Desktop مخصص تابع فرعي دليل. |

بناء قيام واحد نسخة دقيق بسيط تطبيق تنظيف بيان، من تحزيم و تنظيف تنفيذ مشترك نفس استخدام. تطبيق هوية و تحديث ذاكرة مؤقتة اسم من إصدار بيانات وصفية دفع توجيه. نفس بيان يجب مقابل اختبار مدة نظر. إضافة دخول قديم مسار قبل أولا نواة فحص فعلي قد توزيع إصدار، لا لـ لم إصدار تطوير تخطيط زيادة ترحيل.

### 2. تنفيذ مشترك استخدام إبقاء و تنظيف قاعدة

حسب تثبيت الذي تابع مستخدم تحليل هدف، لا يستطيع استخدام رفع حق إدارة عضو رئيسي دليل. أي جعل تغطية مسار قد تفعيل، أيضا إبقاء افتراضي رئيسي دليل؛ معا حفظ حماية Desktop قد سجل إعداد رئيسي دليل و حالي تغطية مسار. حفظ دائم سجل في ملف حد إجراء تحقق؛ سجل يمكن حفظ حماية موضع، لكن أبدا قدرة تخويل حذف مهمة معنى موضع.

رفض حذف تلقي حفظ حماية رئيسي دليل، ذلك أصل أولا دليل أو ذلك محتوى. معالجة مسار كبير صغير كتابة لا حساس شعور، رمز رقم رابط،Windows junction/reparse point، و تنظيف خلال مسار يتم استبدال حال حال. لا نيل امتداد رابط دخول أخرى دليل شجرة. إذا تثبيت أو ذاكرة مؤقتة دليل يتضمن تلقي حفظ حماية رئيسي دليل، فإن نظر لـ اندفاع مفاجئ: تمرير عودة حذف قبل إيقاف، و تقرير إبلاغ باق بقية مسار. هذه فحص يجب يقع في فعلي أصلي حذف مسار في، لا يستطيع فقط وضع في معاينة مرحلة مقطع.

منع توقف جديد نافذة، تحديث و إضافة تغيير؛ إتمام أو أمان إيقاف صحيح في إجراء عملية؛ إيقاف الذي تابع Host و عملية شجرة؛ انتظار عملية خروج و تحرير ملف بعد مجددا حذف. لا نيل فقط سند يمكن تنفيذ ملف اسم إنهاء عملية. كسر تالف صفة خطوة قبل أولا فحص ملكية و مسار. هدف لا وجود نظر لـ نجاح، جزء تنظيف بعد سماح إعادة محاولة. واضح تقرير إبلاغ يتم احتلال استخدام أو لا يمكن وصول مسار؛ قد أمان ترتيب إعادة بدء بعد حذف أو جزء إتمام، لا انتظار في كامل تنظيف.

لا نيل في `.dsh` كتابة تنظيف سجل أو عودة تنفيذ. مؤقت مساعد مساعدة برنامج و حالة يجب يقع في خاص مؤقت دليل، تجنب تجنب عبر يمكن تنفيذ ملف بحث مسار بحث بحث برنامج، و أداة لديه محدود ذاتي سطر تنظيف مسار. تحقق تنظيف لن في حذف بعد إعادة إنشاء Electron مستخدم بيانات. حذف بدء قبل إلغاء عملية ينبغي إبقاء تثبيت متاح.

### 3. Windows تنفيذ

إبقاء نحو توجيه صيغة NSIS تثبيت جهاز (`oneClick: false`). توسيع ذاتي تعريف إزالة خطاف و حذف ترتيب، لا استبدال كامل تثبيت جهاز. لا نيل اعتماد `deleteAppDataOnUninstall` تغطية تحديث ذاكرة مؤقتة، ذاتي تعريف مسار أو رئيسي دليل حفظ حماية. في افتراضي تثبيت دليل حذف و مقدار خارج تنظيف قبل كل تطبيق إبقاء فحص.

صحيح معتاد تحكم وجه لوح، ضبط، مباشر تشغيل إزالة جهاز و ساكن صامت إزالة يجب مشترك استخدام تنظيف قاعدة، و إرجاع لديه استخدام خروج حالة. تلقائي تحديث أو استبدال تثبيت يجب قفز مرور كسر تالف صفة مستخدم حالة تنظيف؛ عبر فعلي ترقية تحقق electron-updater معامل و NSIS تحديث شرط. ترقية فشل يجب إبقاء متصفح بيانات و `.dsh`.

حسب مستخدم تثبيت إزالة تنظيف هذا تثبيت الذي تابع مستخدم Desktop حالة. كل مستخدم إزالة يجب تعرف آخر كل تلقي أثر محلي مستخدم إعداد دليل، في أداة تجهيز الذي يحتاج Windows إذن حال حال تحت تنظيف منها من Desktop يملك حالة، و إبقاء كل Harness رئيسي دليل. لا يستطيع استخدام مرة `$APPDATA` توسيع بديل جدول كل مستخدم. إذا تلقي أثر مستخدم دليل لا يمكن وصول، أو آخر عدد تثبيت ما زال يملك مشترك مسار، ينبغي تقرير إبلاغ هذا حال حال، لا نيل حذف مشترك حالة أو إعلان تسمية كامل تنظيف. إزالة واجهة و ساكن صامت تنفيذ نتيجة كل يلزم جسم الآن هذا واحد منطقة آخر.

من NSIS حذف تطبيق، تثبيت سريع سريع طريقة و تثبيت تسجيل معلومة. صريح حذف بيان في تطبيق ذاكرة مؤقتة و مستخدم بيانات، يشمل ذاكرة مؤقتة تثبيت جهاز فرعي هذا. صيانة حمل تثبيت جهاز، إزالة جهاز و إضافة جديدة يمكن تنفيذ ملف توقيع اشتراط. زيادة بناء مدة فحص، إثبات ذاتي تعريف خطاف و تنظيف بيان تأكيد فعلي دخول ناتج.

### 4. macOS تنفيذ

في Electron يملك قائمة مفرد و استعادة واجهة إضافة دخول محلي تحويل إزالة عملية، حفظ إثبات Host لا يمكن بدء وقت ما زال يمكن استخدام. تنفيذ قبل شرح إبقاء `.dsh`، و حذف رئيسي دليل خارج لم إرسال مسودة مسودة و واجهة انحراف جيد. كامل تنظيف يجب يشمل إزالة اختيار تحديد تطبيق حزمة؛ إذا فقط هو نقل دخول ملغى ورق سلة، ينبغي شرح صاف فارغ ملغى ورق سلة قبل ما زال احتلال استخدام مغناطيس قرص.

استخدام توقيع مساعد مساعدة برنامج، في Electron و Host خروج بعد إتمام تنظيف. حذف قبل تحقق تطبيق حزمة هوية و اختيار تحديد مسار؛ تغطية `/Applications`،`~/Applications` و نقل حركة بعد يمكن كتابة تطبيق حزمة. فقط مقابل حاجة إذن مسار طلب تخويل. تنسيق ضبط Squirrel/ShipIt، فقط إزالة هذا تطبيق تحديث مهمة و حالة، مجددا حذف قد تعرف آخر خارجي تطبيق دليل و انحراف جيد. إتمام تحقق يجب يشمل مساعد مساعدة برنامج مؤقت ملف.

يأخذ نفس تنظيف تنفيذ تحزيم لـ توقيع، عام إثبات مستقل إزالة جهاز، دعم حمل تطبيق قد يتم حذف حال حال. هو لا يستطيع اعتماد قد حذف تطبيق حزمة أو يمكن بدء `.dsh` profile. فقط قراءة تركيب DMG لا يخص قد تثبيت يمكن كتابة تطبيق؛ ينبغي إعطاء خروج يمكن عملية نتيجة، لا يستطيع محاولة تجربة تعديل هو. مشترك تطبيق تثبيت و Windows واحد مثال حاجة معالجة تلقي أثر مستخدم و إذن، و تقرير إبلاغ لم قدرة تنظيف حالة.

### 5. تحقق و وثيقة

زيادة إبرة مقابل صفة اختبار، تغطية هدف ملكية، تلقي حفظ حماية رئيسي دليل إعادة تراكم، رابط و reparse point مرة تاريخ، هوية لا مطابقة، مهمة معنى مسار رفض، ذاتي تعريف أو لم ضبط `DSH_HOME`، آخر تثبيت مشترك بيانات، و لا يمكن وصول مستخدم إعداد دليل. تغطية إلغاء، نشط وثب Host/تحديث/إضافة عملية، حذف خطوة بين في قطع، إعادة محاولة و ذاتي سطر تنظيف، منع توقف استخدام تطوير من حقيقي رئيسي دليل. تنفيذ عملية و نظام الملفات اختبار وقت التزام دوران [CI يمكن اعتماد صفة سير العمل](../../../skills/dsh-ci-test-reliability/SKILL.md).

في Windows و اثنان عدد قد إصدار macOS هيكل بنية فوق تنفيذ قد تثبيت ناتج e2e فحص. تغطية أول مرة تثبيت كما لم تحديث، تحت تحميل و تثبيت مرة تحديث، تحديث فشل، حسب مستخدم أو مشترك تثبيت، نقل حركة تطبيق، و سحب جر حذف بعد مستقل macOS تنظيف. مستقل مقارنة مقارنة نظام الملفات و تسجيل معلومة بيان، لا بـ إزالة جهاز نجاح استجابة بديل بديل تحقق. تطبيق و CLI ساكن توقف بعد، حذف قبل مقابل إبقاء `.dsh` محتوى حساب حساب ها أمل؛ اشتراط حذف بعد محتوى، مسار و رابط بند تماما متسق. تطبيق هدف يتم حذف بعد، لا اشتراط إبقاء وقت التشغيل رابط ما زال يمكن تحليل.

لـ إزالة واجهة و فشل نتيجة زيادة ملكية وحدة جانب مسبق مدة إخراج. زيادة بلا مفتاح تسجيل صنع جلسة مشهد، إثبات قد لديه جلسة قدرة عبر إزالة و إعادة تركيب إبقاء؛ صاف تثبيت جهاز أو واجهة مسبق مدة لا وضع دخول قمة طبقة Session شجرة. لـ تنفيذ PR(Pull Request) تسجيل صنع قاعدة اشتراط حقيقي خادم و نموذج GUI GIF. تنفيذ تسليم وقت تحديث [Desktop README](../../../../apps/desktop/README.zh.md) ، إنجليزي نص مقابل وثيقة، مستخدم شرح، لغة حرف قاموس،JSDoc و هذا رفع سجل دورة الحياة. عبر [dsh-pre-push-checks](../../../skills/dsh-pre-push-checks/SKILL.md) اختيار إبرة مقابل صفة فحص؛ توقيع تحزيم و حقيقي عملية نظام إزالة دليل لـ مطلوب بند، لا يستطيع من اختبار وحدة بديل.

## اعتبار مرور بديل خطة

**صيانة حمل افتراضي إزالة جهاز.** هو جمع لا يستطيع إثبات تطبيق دليل خارج تطبيق حالة قد يتم إزالة، لذلك لا ممتلئ كاف اشتراط.

**يأخذ الكل Electron و تحديث بيانات نقل إلى `.dsh`.** هذا قدرة بسيط تحويل ملف موضع، لكن سوف إبقاء ذاكرة مؤقتة و متصفح حالة بينما لا هو تنظيف هو جمع، بينما كما ذاته لا يستطيع تغطية Squirrel/أصلي حالة أو قد لديه خارجي ملف. هذا رفع سجل لا اعتماد هو بصفة تنظيف خطة.

**عبر معتاد إقامة خلفية مراقبة نظر جهاز فحص قياس Finder حذف.** هذا سوف زيادة واحد ذاته أيضا حاجة إزالة معتاد إقامة مكون، و كما لا يستطيع يمكن اعتماد تغطية مراقبة نظر جهاز إيقاف خلال حدوث حذف. اعتماد صريح إزالة عملية.

**حذف `.dsh/desktop` أو `.dsh/profiles/desktop`.** هذه مسار يتضمن Desktop مخصص تابع حالة، لكن اشتراط إبقاء هو كامل Harness رئيسي دليل، بينما لا فقط هو جلسة.

## تحقق استلام معيار

- تلقي دعم حمل إزالة نجاح بعد، اختيار تحديد تطبيق، هو يملك تسجيل معلومة، و قد تثبيت ناتج بيان تحديد كل خارجي تطبيق مسار متساو قد إزالة؛ لا يوجد تنظيف مساعد مساعدة برنامج أو تحديث جهاز عملية ناقص إبقاء.
- ساكن توقف بعد، افتراضي و قد إعداد Harness رئيسي دليل محتوى و رابط تماما إبقاء. مستخدم مشروع و مستقل CLI تثبيت إبقاء كامل.
- Windows تحكم وجه لوح، ضبط و ساكن صامت إزالة ممتلئ كاف نفس إبقاء قاعدة. فعلي تلقائي ترقية إبقاء متصفح حالة و Harness بيانات.
- macOS صريح عملية و مستقل إزالة جهاز ممتلئ كاف تنظيف قاعدة. وثيقة دقيق تأكيد منطقة قسم هو جمع و Finder سحب جر حذف، و فقط نقل دخول ملغى ورق سلة حال حال.
- كل لم إزالة الذي تابع مسار كل تقرير إبلاغ إعادة محاولة أو استعادة طريقة. إذن لا كاف، مستخدم إعداد دليل غير ممكن وصول و مشترك ملكية متساو لا نيل إنتاج وهمي زائف كامل نجاح نتيجة.
- أول مرة تثبيت و إزالة إعادة تركيب اختبار إثبات، لا يوجد لم قبول دخول بيان رئيسي دليل خارج تطبيق حالة ناقص إبقاء، كما قدرة إعادة فتح إبقاء جلسة. عبر أصلي عملية نظام بيان تحقق إتمام، لا يستطيع فقط اعتماد نموذج محاكاة API استدعاء.

## ريح خطر

حذف متصفح تخزين سوف فقد فقد لم إرسال مسودة مسودة و واجهة انحراف جيد. كامل إبقاء رئيسي دليل معنى طعم حال متعمد إبقاء Desktop إضافة،pnpm حالة، و ممكن في إعادة تركيب إصلاح قبل معلق فارغ رابط. ذاتي تعريف بيانات مسار و مشترك تثبيت ممكن حاجة مقدار خارج إذن أو نقل حركة مسار عندئذ قدرة كامل حذف؛ عملية يجب تقرير إبلاغ حد، لا يستطيع مخالفة عكس إبقاء قاعدة.

عملية نظام يملك أمان و مراجعة حساب تاريخ، و مستخدم إنشاء ملف، لا يستطيع يتم “مسح حذف كل أثر أثر” تحمل وعد تغطية.[Desktop تحزيم قرار](../../implemented/architecture/2026-08-25-electron-desktop-packaging-and-updates.zh.md) و[داخل وضع وقت التشغيل و خارجي إضافة قرار](../../implemented/architecture/2026-09-08-desktop-bundled-runtime-and-external-plugins.zh.md) متابعة قسم آخر يملك تحزيم و بيانات ملكية قاعدة؛ هذا رفع سجل لا يحل محل هذا اثنان نسخة سجل، أيضا لا عودة ملف أي نشط وثب سجل.
