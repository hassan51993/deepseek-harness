# Agent Note: لأجل بنية تحويل جلسة تفاعل Task Surface

Status: proposed

[English](2026-08-04-task-surface.md) | العربية

## مشكلة

لديه بعض مهمة جدا صعب عبر تسليم بديل إرسال نص رسالة قدوم إتمام. مقارنة مقارنة كثير عدد خيار، ضبط كامل حساب تخطيط ترتيب، مراجعة قراءة جدول إطار، أو ملء كتابة واحد صغير مجموعة صلة ربط حقل، كل أكثر ملائم دمج في مرة بنية تحويل تفاعل في معالجة.agent(ذكي جسم) يمكن وصف هذا صنف تفاعل، لكن إذا لا زيادة دائم دائم منتج مكون أو توليد يمكن تنفيذ عميل إضافة شفرة، حينئذ لا يمكن اشتراط Web عميل تصيير هذا صنف تفاعل.

هذا اثنان نوع تغيير عبر خطة مسؤولية ملكية كل لا دمج إدارة. منتج مخصص استخدام مكون اشتراط كل نوع مهمة شكل كل إضافة جديدة إطلاق طريقة تزامن نشر جديد إصدار. مقابل في فقط يحتاج واحد جولة جدول مفرد، توليد شفرة الذي يملك إذن و دورة الحياة صار هذا كل بعيد تجاوز فعلي حاجة. هذا مثال فعل أيضا سوف يأخذ عرض واجهة بينما غير مستخدم ربط نقاش تغيير صار حمل دائم ناتج.

هدف قبل نقص قليل هذا مثال واحد نسخة اتفاق: استخدام محدود، يمكن إعادة تشغيل وصف قدوم تعريف مؤقت UI، و يجعل هو فقط يخص واحد جلسة و مرة أداة استدعاء نسخة. منتج ينبغي عند مسؤول تحقق، وضع وضع، تفاعل آلية و إيداع؛agent ينبغي عند مسؤول خاص تحديد مهمة نص سجل، بيانات، و من تلقي دعم حمل مكون في عمل خروج اختيار.

## رفع سجل

إضافة جديدة **Task Surface**: واحد نوع من عادي Web عميل إضافة تصيير، حمل إصدار إعلان صيغة نموذج. موجه إلى نموذج توفير واحد مستقر أداة `show_task_surface`، لأجل إصدار هذا نموذج. استدعاء نجاح بعد، حالي جولة انتهاء. مستخدم تحرير و إيداع تصيير خروج وجه لوح؛Host سوف إيداع محتوى سجل لـ واحد بند عادي مرئي مستخدم رسالة، و بدء تحت واحد جولة.

معا ممتلئ كاف التالي شرط وقت،Task Surface هو افتراضي بنية تحويل UI مسار:

- تفاعل يخص حالي جلسة و حالي مهمة؛
- سلوك يمكن من قد إعلان مكون تجميع دمج جدول بلوغ؛
- لا حاجة خلفية تنفيذ أو إضافة جديدة وقت التشغيل إذن؛
- لديه قيمة قيمة حمل دائم نتيجة هو مستخدم إيداع ربط نقاش، بينما لا هو وجه لوح ذاته.

هذا داخل تعريف هو واحد إطلاق طريقة، لا هو واحد مجموعة منتج بدء إرسال صيغة قاعدة.agent سوف صريح استدعاء `show_task_surface`. مستخدم يمكن عبر عادي لغة اشتراط agent استخدام Task Surface. منتج لن أصل حسب أداة اسم أو مهمة رئيسي عنوان فتح مخصص استخدام وجه لوح؛ تكرار استخدام أيضا لن تلقائي يأخذ Task Surface تحويل لـ إضافة.

بسيط قصير منع سد صيغة مشكلة ما زال من [`ask_user_question`](../../archived/feature/2026-07-29-ask-question-web-presentation.md) معالجة. صاف نص شرح ما زال إبقاء في حديث يوم في. عبر جلسة تنقل، خلفية سلوك، جديد خدمة أو حمل دائم ذاتي تعريف UI فإن يخص Generated Client Plugin سير العمل.

## إعلان صيغة نموذج

`TaskSurfaceModelV1` استخدام JSON. هو يتضمن محتوى كتلة، إدخال حقل و واحد إيداع وسم؛ لا يتضمن شفرة، عودة ضبط، اختيار جهاز،HTML،CSS، يمكن تنفيذ ناتج URL، أيضا لا يتضمن جدول بلوغ صيغة لغة. هذا نوع و نواة قلب جلسة في قائم `SurfaceManager`/`SurfaceOp` رسالة عودة نحو نوع غير متصل؛Task Surface هو واحد طقم منتج تفاعل بروتوكول.

```ts
interface TaskSurfaceModelV1 {
  version: 1
  title: string
  description?: string
  sections: TaskSurfaceSection[]
  fields?: TaskSurfaceField[]
  submit: { label: string }
}

interface TaskSurfaceSection {
  id: string
  title?: string
  layout?: TaskSurfaceLayout
  blocks: TaskSurfaceBlock[]
}

type TaskSurfaceLayout =
  | { kind: 'stack' }
  | { kind: 'grid'; columns: 2 | 3 }

type TaskSurfaceBlock =
  | { kind: 'markdown'; text: string }
  | { kind: 'metrics'; items: { label: string; value: string; detail?: string }[] }
  | { kind: 'table'; columns: { id: string; label: string }[]; rows: Record<string, string | number | boolean | null>[] }
  | { kind: 'diff'; path?: string; before: string | null; after: string; language?: string }
  | { kind: 'notice'; tone: 'neutral' | 'info' | 'warning'; text: string }

type TaskSurfaceField =
  | { kind: 'text'; id: string; label: string; multiline?: boolean; required?: boolean; initial?: string }
  | { kind: 'choice'; id: string; label: string; options: TaskSurfaceOption[]; initial?: string }
  | { kind: 'multi-choice'; id: string; label: string; options: TaskSurfaceOption[]; initial?: string[] }
  | { kind: 'toggle'; id: string; label: string; initial?: boolean }
  | { kind: 'order'; id: string; label: string; options: TaskSurfaceOption[]; initial?: string[] }

interface TaskSurfaceOption { id: string; label: string; detail?: string }
```

مصير تحكم حرف جسم ترتيب طبع، بين مسافة، استجابة صيغة تخطيط، تركيز نقطة ترتيب، مفتاح قرص سلوك و رئيسي عنوان token. لم إشارة تحديد تخطيط وقت استخدام `stack`؛`grid` تخطيط ذاتي حمل صف عدد، متاح عرض درجة لا يمكن سعة قبول وقت سوف طي. لقاء إلى لم معرفة إصدار أو ربط دمج نوع فرع وقت، نظام استخدام عام أداة نتيجة رجوع، بينما لا هو فقط حل تفسير منها واحد جزء.

`markdown` كتلة إعادة استخدام `MarkdownText`، و صريح إشارة تحديد نموذج URL سياسة.`MarkdownText` إضافة جديدة `remoteImages: 'render' | 'alt-only'`، عادي مشهد ما زال افتراضي استخدام `render`؛Task Surface بداية نهاية نقل دخول `alt-only`، لذلك صورة لغة قاعدة فقط تصيير بديل نص. أصلي HTML و تضمين دخول صيغة وسيط جسم ما زال سوف يتم حذف، لا توليد تلقائي رابط معاينة؛ لم مرور مستخدم صريح عملية، لن حل مرجع نموذج توفير أي URL. عادي HTTP(S) رابط ما زال يمكن في مستخدم اختيار بعد تنقل. لغة قاعدة عال مضيء قسم قطعة انتظار ثابت تطبيق مورد متابعة التزام دوران منتج معتاد قاعدة تحميل سياسة.

إصدار 1 متعمد لا دعم حمل شرط حقل، عميل بيانات نيل أخذ، رسم جدول، ملف فوق نقل و مهمة معنى حدث معالج. إضافة جديدة أي كتلة أو حقل نوع كل يخص بروتوكول تغيير، يجب في نفس تغيير في إضافة دخول محلل، مصير، بلا عائق عائق سلوك، رجوع طريقة و إعادة تشغيل fixture(اختبار قبل وضع بيانات).

Task Surface خدمة عبر تلقي schema تحقق إعداد تعريف حد. ابتدائي قيمة افتراضية لـ: مواصفة تحويل نموذج لا تجاوز مرور 64 KiB، كتلة لا تجاوز مرور 64 عدد، حقل لا تجاوز مرور 32 عدد، جدول إطار سطر لا تجاوز مرور 200 سطر، إيداع محتوى لا تجاوز مرور 32 KiB. نموذج داخل ID يجب وحيد؛ حقل قيمة يجب رمز دمج ذلك إعلان؛ لم معرفة حقل سوف يتم رفض. هذه حد قيد سجل،DOM و نص التوجيه صار هذا، لكن لا تغيير بروتوكول.

## أداة و عرض اتفاق

`show_task_surface` استقبال `{ model: TaskSurfaceModelV1 }`.Host تحليل و مواصفة تحويل كامل نموذج؛ إذا هذا جلسة قد لديه واحد فتح Task Surface، فإن رفض استدعاء؛ لا فإن توليد `surfaceId`، و إرجاع حمل مواصفة تحويل نموذج مواصفة قيمة `{ surfaceId, model }`.`presentationMeta` حفظ دائم `value.model`، جعل إسقاط جهاز و منفذ لن مقابل مواصفة تحويل نتيجة إنتاج قسم اختلاف.Native نتيجة سوف إشارة واضح هذا Surface، و شرح عميل لا يمكن تصيير وجه لوح وقت، يمكن عبر عادي رسالة التفاف مرور هو. مع بعد أداة استدعاء `exec.concludeTurn()`، منع توقف agent تجاوز مرور الذي اشتراط شخص عمل فحص نقطة متابعة تنفيذ.

أداة تعريف حذف `isConcurrencySafe`. أصل حسب قائم أداة سجل التسجيل اتفاق، حذف هذا حقل سوف سوف كل مرة استدعاء عودة صنف لـ وحيد احتلال ترتيب ترتيب شاشة عائق، بلا حاجة إضافة جديدة `ToolDefinition` حقل. هذا أداة فقط سوف تجميع إلى معا تركيب Host خدمة و Web مصير Web profile في. إصدار 1 دعم حمل `native` و `both` أداة نمط؛ فقط دعم حمل `ptc` profile لن نحو نموذج عام نشر هذا أداة، لأن PTC mode توزيع يخص تضمين طقم استدعاء، لا يمكن يأخذ عرض بيانات وصفية نقل إلى خارج طبقة نتيجة.

متصفح أمان مجال حزمة من `@deepseek-ai/dsh-brand` بـ فقط نوع طريقة استيراد `Branded` أصل لغة، و يملك الكل ثلاثة عدد Task Surface ID. أصل حسب[مواصفة أداة إخراج اتفاق](../../implemented/architecture/2026-07-20-canonical-tool-output-contract.zh.md) ، مواصفة قيمة فقط وجود في هذا مرة تنفيذ في. لذلك، إعادة تشغيل عبر `output.presentationMeta(args, value)` سوف التالي حمل وسم تحميل حمل مع `tool/result.meta` واحد و حفظ دائم:

```ts
import type { Branded } from '@deepseek-ai/dsh-brand'

type TaskSurfaceId = Branded<'TaskSurfaceId'>
type TaskSurfaceSubmissionId = Branded<'TaskSurfaceSubmissionId'>
type TaskSurfaceDismissalId = Branded<'TaskSurfaceDismissalId'>

interface TaskSurfacePresentationMeta {
  kind: 'dsh/task-surface'
  version: 1
  surfaceId: TaskSurfaceId
  model: TaskSurfaceModelV1
}
```

هذا أداة إبقاء عام [render intent](../../implemented/architecture/2026-07-02-tool-render-intent-union.zh.md). حمل key Web سطر قراءة `ToolResultNode` فوق قد إبقاء حمل وسم بيانات وصفية، بلا حاجة إضافة جديدة render-intent فرع أو عرض سجل التسجيل. لا دعم حمل Task Surface عميل سوف تصيير عادي نتيجة محتوى.

Web إضافة حسب وفق [toolview](../../archived/architecture/2026-07-23-toolview-dissolution.md) و [slot تسجيل](../../implemented/architecture/2026-07-22-slot-type-chain-implementation.zh.md) اتفاق، توفير اثنان عدد ساكن حالة جلسة أثر مجال تسجيل بند. واحد بـ `show_task_surface` لـ key `conversation.chat.toolview` بند سوف حمل دائم transcript(نص سجل) استدعاء نسخة تصيير لـ بسيط نظيف ملخص و فقط قراءة إعادة تشغيل. قائم `conversation.input.dock` في واحد `TaskSurfaceDock` بند هو وحيد يمكن عملية تركيب نقطة: هو قراءة نشط حركة إسقاط، إبرة مقابل تأكيد قطع هوية استدعاء `getActive`، و يملك حقل، مسودة مسودة، إيداع و إغلاق عملية.Dock و transcript قسم صفحة متبادل متبادل مستقل، لذلك أي جعل `ToolResultNode` يقع في قد تحميل تاريخ نافذة خارج، نشط حركة Surface ما زال يمكن عملية.

Dock التزام دوران قائم composer chain رجوع دلالة. أي `conversation.composer` وصل إدارة كل سوف إخفاء يشمل `TaskSurfaceDock` في داخل رجوع composer مكدس، لكن لن سوف ذلك إزالة؛ وصل إدارة انتهاء بعد، نفس عدد مسودة مسودة كل من سوف إعادة ظهور. وصل إدارة جهة لن نيل نيل Task Surface عملية، أيضا لن إنشاء آخر عدد تحرير جهاز.

نموذج لا يستطيع اختيار جلسة وسم صفحة،Dock ترتيب، تفصيل حال شريط، نموذج حالة إطار، مثل عنصر موضع أو z-index. بـ بعد أي جعل تغيير وضع وضع موضع، أيضا فقط هو مصير قرار، لن تغيير سجل في سجل نموذج.transcript سطر أبدا سوف يصبح ثاني عدد تحرير جهاز، لذلك نفس عدد Surface لن ظهور متبادل متبادل تنافس تنازع مسودة مسودة أو إيداع كل من.

## إيداع اتفاق

Task Surface مجال عبر Host نقل طبقة عام ثلاثة عدد عملية. فقط لديه `submit` سوف وصل قبول مستخدم رسالة:

```ts ignore-check
type TaskSurfaceSubmissionPhase = 'queued' | 'claiming'

interface TaskSurfacePendingSubmission {
  submissionId: TaskSurfaceSubmissionId
  messageId: MessageId
  phase: TaskSurfaceSubmissionPhase
}

interface TaskSurfaceService {
  getActive(input: { sessionId: SessionId; surfaceId: TaskSurfaceId }): Promise<GetActiveTaskSurfaceResult>
  submit(input: SubmitTaskSurfaceRequest): Promise<SubmitTaskSurfaceResult>
  dismiss(input: DismissTaskSurfaceRequest): Promise<DismissTaskSurfaceResult>
}

interface SubmitTaskSurfaceRequest {
  sessionId: SessionId
  surfaceId: TaskSurfaceId
  submissionId: TaskSurfaceSubmissionId
  values: Record<string, JsonValue>
  note?: string
}

type SubmitTaskSurfaceResult =
  | { accepted: true; messageId: MessageId; phase: 'queued' }
  | { accepted: false; reason: 'not-open' | 'stale' | 'invalid-submission' | 'submission-pending' }

type GetActiveTaskSurfaceResult =
  | {
      active: true
      callId: ToolCallId
      surfaceId: TaskSurfaceId
      model: TaskSurfaceModelV1
      pending: TaskSurfacePendingSubmission | null
    }
  | { active: false; reason: 'not-open' }

interface DismissTaskSurfaceRequest {
  sessionId: SessionId
  surfaceId: TaskSurfaceId
  dismissalId: TaskSurfaceDismissalId
}

type DismissTaskSurfaceResult =
  | { dismissed: true; eventSeq: number }
  | { dismissed: false; reason: 'not-open' | 'stale' | 'submission-pending' }
```

Host تحليل خروج `show_task_surface` تأكيد قطع نجاح استدعاء نسخة، اعتماد حسب ذلك قد حفظ دائم نموذج إعادة تحقق إيداع قيمة، و عبر عادي جلسة طابور صف وصل قبول استجابة. هذا استجابة يصبح واحد بند مستخدم زاوية لون رسالة، و استخدام يمكن دمج توسيع رسالة مصدر:

```ts ignore-check
interface TaskSurfaceCorrelation {
  version: 1
  submissionId: TaskSurfaceSubmissionId
  callId: ToolCallId
  surfaceId: TaskSurfaceId
  values: Record<string, JsonValue>
}

interface TaskSurfaceUserMessageSource {
  kind: 'user'
  rpcId: RpcId
  taskSurface: TaskSurfaceCorrelation
}
```

معيار `inbox` إسقاط قد في أصلي `next-turn` أو `next-step` قائمة في يحمل كل بند كامل `UserMessage`، يشمل `MessageId`،source و content. عميل سوف يأخذ هذا قيمة حفظ في عام projection store في، لذلك هذا رفع سجل لا حاجة توسيع queue نقل، أيضا لا حاجة ثاني نوع انتظار معالجة رسالة نوع.

متصفح أمان مجال حزمة يملك `TaskSurfaceId`، إيداع و إغلاق ID،`TaskSurfaceCorrelation`، و انتظار معالجة إيداع شكل.ApiProxy يملك نقل توسيع، مسؤول سوف صلة ربط معلومة و `rpcId` تركيب. إبقاء `kind: 'user'` يمكن صيانة حمل عادي مستخدم رسالة هواء فقاعة و نص التوجيه دلالة، مقدار خارج حقل فإن توفير حمل دائم صلة ربط معلومة. رسالة محتوى هو من منتج صيغة تحويل يمكن قراءة ملخص، يشمل وجه لوح عنوان، وسم و إيداع قيمة، و اختياري ملاحظة. نموذج استقبال نفسه نص. بنية تحويل مصدر لا هو ثاني بند إخفاء إشارة أمر.

منتج خارج قشرة مسؤول استلام بدء و إغلاق. استلام بدء يخص محلي عرض حالة، لن إرسال أي محتوى. لا يوجد انتظار معالجة إيداع وقت،`taskSurface.dismiss({ sessionId, surfaceId, dismissalId })` سوف إلحاق واحد `task-surface/dismissed` جلسة حدث، لكن لا بدء جولة؛ هذا دقيق حدث سوف إغلاق إسقاط، و تحديث Dock و transcript سطر. إعادة محاولة سوف إعادة استخدام `dismissalId` و إرجاع أصلي نتيجة، لن مجددا إلحاق حدث. إيداع موضع في `queued` أو `claiming` مرحلة مقطع وقت، إغلاق عملية سوف يتم منع استخدام،Host أيضا سوف بـ `submission-pending` رفض هذا صنف طلب.

عميل حد فوق إيداع أداة لديه أمر خدمة صفة. وصل قبول نجاح سوف إرجاع موضع في `queued` مرحلة مقطع تأكيد قطع `messageId`؛ في `queued` و `claiming` اثنان عدد مرحلة مقطع في،Dock سوف منع استخدام كل تغيير، و كما فقط لديه مطابقة مستخدم رسالة حفظ دائم بعد، عندئذ سوف صاف حذف قد حفظ دائم مسودة مسودة. إذا طلب يتم رفض، فإن إبقاء قيمة توفير مستخدم متابعة تحرير، و عرض إرجاع سبب. مزدوج ضرب و نقل إعادة محاولة سوف إعادة استخدام `submissionId` و إرجاع رقم مرة استدعاء نتيجة؛ فقط يلزم رقم مرة إيداع ما زال في معالجة في، آخر عدد إيداع ID حينئذ سوف استلام إلى `submission-pending`. مقابل في واحد قد قبول Surface،Host فقط سوف وصل قبول واحد بند مستخدم رسالة.

Task Surface خدمة سوف قد قبول إيداع تنسيق ضبط حالة سجل لـ `pending.phase: 'queued'`، عميل فإن يمكن عبر ما زال في طابور صف في سطر الذي إبقاء `source` صلة ربط هو. عند Agent لـ عادي نص التوجيه وصل قبول إقرار قيادة هذا رسالة وقت، خدمة سوف أولا تزامن يأخذ نفس نسخة انتظار معالجة سجل تعديل لـ `claiming`، مع بعد حمل دائم حذف splice عندئذ سوف من عام `inbox` إسقاط إزالة هذا رسالة. خدمة سوف في مختلف خطوة وصل قبول و إعادة اتصال خلال واحد مباشر إبقاء هذا نسخة عملية داخل إقرار قيادة حالة، مباشر إلى مطابقة حمل دائم `user/message` إصدار، أو Agent تقرير إبلاغ نهاية حالة إسقاط.

مطابقة `user/message` سوف إغلاق حمل دائم إسقاط و صاف حذف إقرار قيادة حالة. في حفظ دائم قبل حدوث رفض، إلغاء أو dispose(مورد تحرير) وقت، نظام سوف تقرير إبلاغ إسقاط، صاف حذف إقرار قيادة حالة، و يجعل Surface إبقاء فتح.Dock أبدا سوف يأخذ طابور صف سطر إزالة فقد حل قراءة لـ منها مهمة واحد نتيجة، بينما سوف إعادة قراءة `getActive`:`pending.phase: 'claiming'` سوف صيانة حمل منع استخدام حالة،`pending: null` سوف استعادة مسودة مسودة،`not-open` سوف إغلاق Dock.`getActive` سوف يأخذ من سجل دفع توجيه نشط حركة استدعاء نسخة و هذا وحيد واحد نسخة عملية داخل انتظار معالجة سجل دمج. هذا سجل يخص تنسيق ضبط حالة، لا هو ثاني عدد حمل دائم مرجعي مصدر؛Host إعادة بدء بعد، لم إيداع إقرار قيادة حالة لا تكرار وجود، سجل في ما زال فتح Surface سوف استعادة لـ يمكن تحرير حالة.

مقابل في حمل لديه Task Surface صلة ربط معلومة سطر،`session.updateQueue` سوف رفض `edit` و `steer`. تحرير سوف يجعل صيغة تحويل محتوى و رسالة مصدر الذي يحمل بنية تحويل قيمة انفصال عقدة، بينما steering(في طريق جذب توجيه) سوف حفظ دائم واحد بند لا رمز دمج إيداع دورة الحياة `steering/message`. هذا سطر ما زال في طابور صف في وقت سماح `remove`؛ هو سوف تقرير إبلاغ إسقاط و استعادة لـ فتح Surface. سطر يتم إقرار قيادة بعد أي قد مغادرة فتح عام طابور صف، طابور صف تغيير سوف إرجاع `queue-item-not-found`.Task Surface خدمة سوف يحتفظ واحد نسخة single-flight انتظار معالجة سجل، مباشر حتى إيداع أو إسقاط.

## دورة الحياة و استعادة

جلسة سجل هو حق مصدر. قائم[جلسة إسقاط نظام](../architecture/2026-07-27-session-projection-and-command-log.zh.md) في واحد صغير نوع `taskSurface` وحدة سوف طي نجاح استدعاء Surface نتيجة بيانات وصفية و لاحق مستخدم رسالة مصدر، نيل إلى التالي حالة:

```ts ignore-check
interface TaskSurfaceProjection {
  active: { callId: ToolCallId; surfaceId: TaskSurfaceId } | null
}
```

واحد جلسة الأكثر كثير فقط قدرة لديه واحد فتح Task Surface. نجاح نتيجة سوف فتح هو؛ مطابقة Task Surface مستخدم رسالة أو إغلاق حدث سوف سوف ذلك إغلاق. لاحق عادي مستخدم رسالة أيضا سوف سوف ذلك إغلاق، هذا هو واحد بند صريح التفاف مرور مسار؛ في بـ فوق مهمة واحد حدث إغلاق نشط حركة استدعاء نسخة قبل، مجددا مرة استدعاء `show_task_surface` كل سوف فشل. رجوع و fork سوف عبر طي متبادل ينبغي سجل دفع توجيه خروج نشط حركة استدعاء نسخة؛ لحظة حالة طابور صف مرحلة مقطع لن يتم نسخ، أيضا لن لديه مستقل Surface قاعدة بيانات مشاركة و منها.

كامل نموذج ما زال تخزين وضع في مقابل `tool/result.meta` في؛ إسقاط فقط يحمل نشط حركة هوية.`TaskSurfaceDock` مستقل في تاريخ سطر وجود، و سوف استجابة هذا هوية.`taskSurface.getActive({ sessionId, surfaceId })` سوف من جلسة سجل في قراءة تأكيد قطع استدعاء نسخة، إعادة تحقق ذلك بيانات وصفية، دمج Task Surface خدمة انتظار معالجة تنسيق ضبط سجل، و إرجاع `{ callId, surfaceId, model, pending }`. استدعاء نسخة لا وجود أو قد إغلاق وقت إرجاع `not-open`. لذلك، أي جعل نتيجة يقع في تاريخ ذيل مقطع خارج، تحديث جديد و إعادة اتصال ما زال قدرة استعادة يمكن عملية Surface و ذلك نفس عملية انتظار معالجة مرحلة مقطع، بينما بلا حاجة يأخذ نموذج نسخ إلى كل واحد إسقاط أساس خط في.

Web إضافة سوف لم إيداع قيمة حفظ في واحد محدود، حسب جلسة حفظ دائم slot store في، و بـ `surfaceId` لـ key؛ هذه قيمة دائم بعيد لن دخول جلسة سجل، نص التوجيه أو طويل مدة تسجيل ذاكرة. قد إيداع قيمة تخزين وضع في وصل قبول مستخدم رسالة في، لذلك أي جعل متصفح مسودة مسودة فقد فقد، أيضا لن مسح ذهاب ربط نقاش.

## حزمة حد و اعتماد

هذا قدرة في مسؤولية تغير موضع تفكيك قسم لـ كثير عدد حزمة:

| حزمة | مسؤولية |
|---|---|
| `packages/core/agent` و `packages/core/agent-loop` | لـ قد إقرار قيادة تحت واحد جولة inbox بند توفير عام نهاية حالة نتيجة، يجعل Host مراقبة جهة بلا حاجة استخدام Task Surface مخصص استخدام نوع، يكفي منطقة قسم حمل دائم وصل قبول و إسقاط |
| `packages/task-surface/task-surface` | متصفح أمان نموذج، حمل صنف لوحة نوع ID، صلة ربط و انتظار معالجة نوع، محلل، حد، إيداع تحقق جهاز/صيغة تحويل جهاز، جلسة حدث توسيع، إسقاط وحدة، و Host خدمة اتفاق |
| `packages/task-surface/tool-task-surface` | `show_task_surface`، مواصفة إخراج، عرض بيانات وصفية، عام render intent، نشط حركة Surface فحص و `concludeTurn()` سلوك |
| `packages/client/runtime` | عام ترتيب طابور رسالة `source` إسقاط و جلسة أثر مجال نشط حركة إسقاط وصول |
| `packages/client/ui-primitives` | و Task Surface غير متصل `MarkdownText.remoteImages` سياسة، يشمل `alt-only` صورة فرع و URL سياسة اختبار |
| `packages/client/ui-task-surface` | ساكن حالة كما يمكن عملية `TaskSurfaceDock`، حمل key فقط قراءة transcript سطر، إزالة استهلاك Task Surface نموذج و بـ `alt-only` نمط استخدام `MarkdownText` إعلان صيغة Web مصير، حسب جلسة تخطيط قسم مسودة مسودة store، و إيداع عميل |
| `packages/host/apiproxy` | نوع تحويل نشط حركة Surface قراءة/إيداع/إغلاق نقل، مستخدم رسالة مصدر توسيع و نقل تمرير، طابور صف عملية حد، و إقرار قيادة و نهاية حالة نتيجة توجيه؛ سوف تحقق، انتظار معالجة تنسيق ضبط و وصل قبول تفويض حمل إعطاء Task Surface خدمة |

`ui-task-surface` اعتماد متصفح أمان Task Surface مجال حزمة، عميل اتصال و وقت التشغيل،locale،`ui-conversation` الذي إعلان slot اتفاق، لأجل تسجيل `ui-slots`، و `ui-primitives`؛`ui-primitives` لا عكس نحو اعتماد Task Surface.ApiProxy اعتماد Task Surface خدمة اتفاق و عام AgentLoop نهاية حالة نتيجة. نواة قلب Agent حزمة لا استيراد Task Surface نوع.

هذا تنفيذ اعتماد قائم رسالة سجل، مواصفة أداة إخراج، حمل وسم render intent، جلسة إسقاط، حسب جلسة أثر مجال إعلان slot store و slot دورة الحياة، لا اعتماد في وقت التشغيل إنشاء عميل إضافة.Generated Client Plugin سير العمل يمكن استخدام Task Surface عرض مراجعة قراءة جدول مفرد، لكن اثنان عدد بروتوكول كل لا يملك أو تنشيط آخر عدد بروتوكول.

## تسليم مرحلة مقطع

1. تنفيذ نموذج/محلل،`MarkdownText` نموذج URL سياسة، إسقاط وحدة،`show_task_surface`، عرض بيانات وصفية، فقط قراءة Web سطر، ساكن حالة `TaskSurfaceDock`، نشط حركة Surface قراءة، و حمل فقط قراءة كتلة عام رجوع.
2. زيادة حقل، حفظ دائم مسودة مسودة، مرور Host تحقق إيداع/إغلاق، حمل صنف لوحة نوع صلة ربط معلومة، عميل ترتيب طابور مصدر نقل تمرير،Task Surface `queued`/`claiming` تنسيق ضبط، قد إقرار قيادة استدعاء نسخة نهاية حالة تقرير إبلاغ، طابور صف عملية حد، و مرئي مستخدم رسالة وصل قبول.
3. فقط زيادة لديه فعلي مهمة اعتماد حسب، و كما يملك حتى قليل اثنان عدد مستهلك أو واضح عام رجوع مكون نوع. واحد مفرد وحيد صريح مستخدم عملية يمكن بدء توليد عميل إضافة تحرير كتابة سير العمل، لكن فقط سوف إنشاء واحد مرشح خطة، أبدا سوف مباشر سوف شفرة تحويل لـ صحيح صيغة تنفيذ.

## اعتبار مرور بديل خطة

**زيادة منتج مخصص استخدام إطلاق طريقة و وجه لوح.**لا إعطاء اعتماد، لأن كل نوع جديد مهمة شكل كل سوف يأخذ agent سلوك و قد إصدار منتج مكون اقتران دمج. منتج شفرة ينبغي عند تعريف واحد طقم وصل قبول مكون مفردات و وضع وضع سياسة؛agent فإن صريح أرض من في اختيار.

**من أداة استدعاء في تصيير مهمة معنى HTML،CSS أو JavaScript.**لا إعطاء اعتماد، لأن هذا سوف يأخذ مؤقت تفاعل تغيير صار يمكن تنفيذ عميل إضافة شفرة، لكن لا أداة تجهيز شفرة الذي يحتاج بناء، معاينة، تقييم تقدير، دفعة دقيق أو تراجع دورة الحياة.

**استخدام كبير نوع جدول مفرد توسيع `userInteraction.ask()`.**هذا اتفاق لا اعتماد هذا نوع فعل قاعدة.`ask()` هو واحد نوع منع سد صيغة طلب/استجابة عملية، ملائم لأجل صحيح في تشغيل أداة يجب أولا نيل نيل بسيط قصير جواب سجل عندئذ قدرة متابعة تنفيذ حال حال.Task Surface سوف انتهاء حالي جولة، يمكن في تحديث جديد بعد متابعة إبقاء فتح، و يأخذ نتيجة إيداع لـ تحت واحد بند مرئي مستخدم رسالة.

**كل مرة استدعاء كل تسجيل واحد حركة حالة `conversation.view`.**لا إعطاء اعتماد، لأن عرض حساب هذا هو عام، بينما ذلك تصيير أثر مجال حسب جلسة تخطيط قسم؛ معا، مؤقت مهمة هوية سوف تغيير صار تسجيل هوية. واحد ساكن حالة جلسة أثر مجال Dock مسؤول تفاعل، واحد ساكن حالة حمل key سطر عام وصف قد سجل استدعاء نسخة؛ اثنان عدد تسجيل بند كل لا استخدام استدعاء نسخة هوية.

**فقط في مواصفة أداة قيمة في إبقاء نموذج.**لا إعطاء اعتماد، لأن مواصفة قيمة لن حفظ دائم. إعادة تشغيل اشتراط سوف مواصفة تحويل نموذج كتابة `presentationMeta`.

**سوف وجه لوح تخزين دخول طويل مدة تسجيل ذاكرة.**لا إعطاء اعتماد، لأن تخطيط و مسودة مسودة حالة لا هو يمكن إعادة استخدام واقع. قائم تسجيل ذاكرة سياسة يمكن إبقاء مستخدم إيداع ربط نقاش.

## تحقق استلام معيار

- في `native` أو `both` أداة نمط تحت، حقيقي نموذج يمكن استدعاء واحد مستقر `show_task_surface` schema؛ استدعاء انتهاء حالي جولة؛ أداة تجهيز متبادل ينبغي قدرة Web عميل في فوري تشغيل و إعادة تشغيل بعد كل قدرة تصيير نفس نسخة مواصفة تحويل نموذج؛ فقط دعم حمل `ptc` نمط لن نحو نموذج عام نشر هذا أداة.
- ساكن حالة `TaskSurfaceDock` هو وحيد تحرير جهاز، أي جعل نشط حركة نتيجة يقع في قد تحميل تاريخ نافذة خارج أيضا ما زال يمكن عملية؛ حمل key toolview بداية نهاية هو transcript فقط قراءة ملخص و إعادة تشغيل.composer وصل إدارة سوف إخفاء ما زال موضع في تركيب حالة Dock، إبقاء ذلك مسودة مسودة، و في وصل إدارة تحرير بعد إعادة عرض نفس عدد كل من.
- كل `submissionId` إيداع عملية تماما جيد توليد واحد بند مرئي مستخدم رسالة، عبر عادي طابور صف وصل قبول بدء تحت واحد جولة، و في إبقاء `source.kind: 'user'` معا صيانة حمل حمل صنف لوحة نوع تأكيد قطع استدعاء نسخة صلة ربط؛ إغلاق عملية سجل واحد بند سجل حدث، كما لا بدء جولة.
- عميل ترتيب طابور سطر إبقاء قد صلة ربط رسالة مصدر.`getActive` يمكن في نفس عملية إعادة اتصال قبل بعد عام `queued` أو `claiming`؛ حفظ دائم إتمام بعد سوف إغلاق إسقاط، صريح إسقاط فإن سوف صاف حذف انتظار معالجة حالة و يجعل Surface إبقاء فتح. طابور صف سطر إزالة فقد ذاته لن تغيير أي UI حالة. نظام سوف رفض تحرير و steering، كما إزالة عملية فقط قدرة في إقرار قيادة قبل نجاح.
- تحديث جديد، إعادة اتصال، جلسة تبديل،fork و رجوع كل توليد سجل الذي قرار دورة الحياة حالة؛`getActive` يمكن استعادة تاريخ ذيل مقطع خارج نموذج و انتظار معالجة مرحلة مقطع، أي وجه لوح، انتظار معالجة حالة أو مسودة مسودة كل لن تسرب تسرب إلى أخرى جلسة.
- لا تلقي دعم حمل إصدار، صيغة خطأ بيانات وصفية و عميل قدرة ناقص وقت، نظام رجوع إلى حمل عادي رسالة التفاف مرور مسار يمكن قراءة أداة نتيجة محتوى؛ تضمين طقم استدعاء و قد لديه آخر عدد نشط حركة Surface وقت إرسال بدء استدعاء كل لا يمكن فتح Surface، و بـ فشل انتهاء.
- بروتوكول schema سوف تحقق ID نص، مجال API بداية نهاية عام حمل صنف لوحة نوع ID. نموذج محلل سوف في وجه لوح يمكن تفاعل قبل قوي صنع تحقق حمل وسم تخطيط شكل، حقل قيمة، و إعداد بايت عدد و عدد كمية حد. متصفح اختبار إثبات: صورة لغة قاعدة سوف تغيير صار بديل نص، أصلي HTML و تضمين دخول صيغة وسيط جسم لن تصيير، بينما كما في مستخدم صريح عملية قبل لن طلب نموذج توفير URL.
- مكون اختبار تغطية صاف مفتاح قرص عملية، تركيز نقطة استعادة، بلا عائق عائق اسم، ضيق شاشة تخطيط، اثنان نوع رئيسي عنوان، و في إنجليزي نص منتج واجهة.
- بلا مفتاح متصفح تركيب اختبار تغطية عرض،Dock و فقط قراءة سطر مسؤولية ملكية، نافذة خارج استعادة، تحرير، وصل قبول يتم رفض بعد إعادة محاولة، من `queued` إلى `claiming` تحويل، إسقاط، لا يوجد يمكن تحرير فارغ ملف حمل دائم تسليم وصل، منع توقف طابور صف عملية، إغلاق، إعادة اتصال و مزدوج إعادة إيداع قوة انتظار صفة.
- بادئة لقطة جدول واضح: بلا نقاش مهمة خاص تحديد نموذج مثل أي تغير، كل فقط وجود واحد مستقر أداة تعريف؛ فقط لديه استدعاء معامل و لاحق مستخدم ربط نقاش حدوث تغير.
- إزالة Web إضافة وقت، ذلك الذي تابع Fiber سوف مقابل Dock، أداة سطر و مسودة مسودة store تنفيذ dispose، لكن لن تغيير حمل دائم transcript.

## ريح خطر

رقم واحد دفعة مكون ممكن صغير إلى لا يمكن ممتلئ كاف فعلي مهمة، أيضا ممكن كبير إلى كاف بـ عرض تغيير صار واحد خشن خشن تطبيق إطار هيكل. هل إضافة جديدة مكون ينبغي من استخدام دليل قرار؛ ابتدائي مكون تجميع لا توفير جدول بلوغ صيغة لغة أو شبكة شبكة سلوك.

Task Surface Markdown سياسة ترك ترك سطر داخل صورة، وسيط جسم و تلقائي رابط معاينة. عادي رابط ما زال لديه استخدام، لكن فقط لديه مستخدم صريح عملية بعد، عندئذ يمكن تنقل أو إرسال بدء طلب.

أي جعل ضبط بايت حد، كبير نوع جدول إطار و Markdown ما زال ممكن توليد فتح إلغاء مقارنة عال DOM. مصير يجب حسب يحتاج وهمي محاكاة تحويل أو قطع قطع محتوى، معا إبقاء يمكن قراءة رجوع و واضح حساب عدد.

ملء كتابة حقل مقارنة كثير وقت، من منتج صيغة تحويل إيداع رسالة ممكن مرور طويل. صيغة تحويل جهاز حاجة استخدام تحديد صفة ضيق تجميع صيغة، إبقاء كل واحد إيداع قيمة، معا تجنب تجنب تكرار كامل عرض نموذج.

في إتمام حمل دائم تسليم وصل قبل واحد مباشر يحتفظ عملية داخل إقرار قيادة حالة، سوف إضافة جديدة واحد بند نهاية حالة ثابت كمية. كل بند وصل قبول خروج مسار كل يجب إنتاج مطابقة `user/message` أو صريح إسقاط، لا فإن إعادة اتصال ممكن سوف يجعل Dock دائم دائم موضع في منع استخدام حالة.

متصفح محلي حفظ دائم مسودة مسودة ممكن إبقاء حساس شعور لم إيداع نص.store حاجة التزام حراسة قاعدة تحديد بايت حد أعلى، استخدام حسب جلسة تخطيط قسم key، في إيداع نجاح بعد صريح صاف حذف، و اعتماد و قائم جلسة مسودة مسودة نفسه تخزين سياسة.

Dock و transcript سطر بـ مختلف زاوية لون عرض نفس عدد استدعاء نسخة. سوف أداة سطر إبقاء لـ فقط قراءة، و يجعل Dock يصبح وحيد تغيير كل من، يمكن تجنب تجنب مسودة مسودة اندفاع مفاجئ، لكن بديل قيمة هو Surface نشط حركة خلال سوف ظهور ثاني نسخة بسيط نظيف يمثل.
