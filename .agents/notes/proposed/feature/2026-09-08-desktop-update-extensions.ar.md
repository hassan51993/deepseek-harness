# Agent Note: Desktop تحديث لاحق توسيع

Status: proposed

[English](2026-09-08-desktop-update-extensions.md) | العربية

## مشكلة

عال تردد إصدار لاحق ممكن حاجة Desktop مستقل إصلاح حجز، مستقر إصدار حجز قراءة، تحت مرة بدء تثبيت أو استبدال مقارنة قديم انتظار تثبيت تحديث. هذه اختيار جذب دخول مقدار خارج إصدار و تثبيت جهاز حالة، أول مدة ثابت Nightly، واضح تأكيد تثبيت مسار و لا حاجة هو جمع.

## رفع سجل

سوف هذه مرشح و[واحد مدة تحديث تصميم](2026-09-08-desktop-update-policy-and-installation.ar.md) قسم فتح. هو جمع لا هو واحد مدة تحقق استلام اشتراط، أيضا لا تخويل تعديل اعتماد؛ تنفيذ قبل حاجة منتج دفعة دقيق و منصة تحقق.[قوي صنع تحديث واجهة](2026-09-08-desktop-mandatory-update-api.ar.md) متابعة مستقل، تلقائي تثبيت لا نحو منها زيادة تثبيت جهاز حقل.

### مستقل إصلاح حجز

مسبق إصدار خط فوق تأكيد لديه Desktop مستقل إصلاح يحتاج طلب وقت، تقييم تقدير مسبق إبقاء `.dsk.N` صيغة. إبقاء كامل SemVer مقارنة مقارنة، جعل جذب دخول هذا صيغة لا حاجة ذاتي تعريف إصدار محلل. مسبق مدة ترتيب لـ:

```text
0.1.3-rc.2
< 0.1.3-rc.2.dsk.1
< 0.1.3-rc.2.dsk.2
< 0.1.3-rc.3
```

هذا صنف إصدار سوف Desktop `0.1.3-rc.2.dsk.1` و داخل وضع dsh `0.1.3-rc.2` قسم آخر سجل. فقط لديه معا تكملة متساو بناء، وقت التشغيل وصف،profile تدقيق دقيق، إصدار أداة و خلفية سياسة تحقق، عندئذ جذب دخول مستقل `desktopVersion`،`bundledDshVersion` و `releaseChannel` سجل. واحد مدة بناء متابعة اشتراط إصدار متبادل انتظار.

لا يستطيع استخدام `0.1.3-dsk.1` إصلاح مستقر إصدار `0.1.3`، لأن SemVer سوف ذلك ترتيب في مستقر إصدار قبل. مستقر إصدار إصلاح حاجة أكثر عال مشترك استخدام dsh/Desktop رقعة إصدار، مثال مثل `0.1.4`. مستقل مسبق إصدار إصلاح حجز هو خاص خاص إصدار مسار، لا هو كل مرة بناء معتاد قاعدة حساب عدد جهاز.

### مستقر إصدار حجز قراءة و عبر طريق تبديل

| مستخدم خيار | Feed | إصدار محتوى |
|---|---|---|
| مستقر إصدار | `latest.yml` / `latest-mac.yml` | فقط مستقر إصدار |
| Nightly | `nightly.yml` / `nightly-mac.yml` | alpha،rc و مستقر إصدار |

[واحد مدة إصدار قاعدة](2026-09-08-desktop-update-policy-and-installation.ar.md) في مشترك استخدام مستقر إصدار ظهور وقت زيادة مستقر feed، لا تبديل ثابت Nightly عميل. موجه إلى مستخدم مستقر إصدار حجز قراءة و اختيار جهاز ما زال تأخير بعد. تفعيل بعد حفظ دائم الذي اختيار عبر طريق، لا من قد تثبيت إصدار عكس دفع. ضبط updater عبر طريق وقت إبقاء `allowDowngrade = false`. من Nightly قطع إلى مستقر إصدار وقت، مقارنة عال قد تثبيت Nightly حمل متابعة تشغيل، مباشر إلى ظهور أكثر عال مستقر إصدار؛ لا نيل تخفيض Desktop أو داخل وضع dsh.

تبديل عبر طريق يمكن قيام أي فحص، تحت تحميل سلوك يجب التزام دوران نيل دقيق ضبط. تجاهل اختصار قديم عبر طريق استجابة، تثبيت قبل حسب جديد عبر طريق إعادة تأكيد قد تحت تحميل ناتج. عبر طريق تغيير لا يستطيع في نقص قليل جديد شرط صالح سياسة استجابة وقت حل حذف قوي صنع منع قطع. اختيار جهاز تحت جهة معتاد إقامة Nightly شرح، مرشح العربية لـ “رفع قبل تجربة جديد وظيفة، إصدار ممكن لا مستقر.” ؛ اختيار مستقر إصدار بعد إخفاء، لا بد يلزم وقت آخر سطر شرح يحتاج انتظار أكثر عال مستقر إصدار.

فقط لـ فعلي توزيع مرور Desktop تثبيت حزمة تصميم توافق. لاحق ترحيل إذا وجود قراءة `alpha.yml` أو `rc.yml` حقيقي عميل، ينبغي نحو قديم feed و Nightly إصدار أكثر عال جسر وصل إصدار، مباشر إلى يمكن تصفية استبعاد قديم مدخل. واحد مدة لا حاجة هذا صنف جسر وصل.

### تلقائي تثبيت ضبط

مرشح ضبط لـ تلقائي تثبيت؛ فقط في منتج دفعة دقيق و منصة فعلي قياس بعد اعتبار افتراضي فتح بدء. مرشح العربية مساعد مساعدة نص سجل لـ “إغلاق بعد ما زال سوف تلميح تحديث، يحتاج يد حركة ترقية.” إذا تحت مرة بدء تثبيت تجربة لا ممتلئ كاف اشتراط، فإن تقييم تقدير فقط تلقائي تحت تحميل ضبط، و إبقاء واضح تثبيت تأكيد.

| ضبط | اكتشاف أكثر عال إصدار | لاحق كامل بدء تطبيق |
|---|---|---|
| فتح بدء | تلقائي تحت تحميل و دقيق تجهيز، يتضمن يد حركة فحص اكتشاف إصدار | تثبيت شرط ممتلئ كاف وقت تطبيق صالح انتظار تثبيت تحديث |
| إغلاق | متابعة فحص و تلميح، انتظار واضح تحت تحميل عملية | لا تلقائي تثبيت، إبقاء يد حركة مدخل |

جدول في تلقائي تحت تحميل و تثبيت هو لاحق منتج اختيار؛ واحد مدة كل مرة تحت تحميل كل حاجة مستخدم عملية، تثبيت آخر سطر تأكيد. إغلاق لم قدوم تلقائي ضبط بعد لا إرسال بدء جديد تلقائي تحت تحميل و تثبيت؛ في طريق تحت تحميل يمكن إتمام، لا إضافة جديدة إلغاء حسب زر. تحمل وعد قيام أي توليد فاعلية قبل يحتاج تأكيد قدرة لا إلغاء منصة قد مؤقت تخزين تثبيت. لا نيل رئيسي حركة خروج استخدام في تطبيق أو التفاف مرور مهمة أثر تأكيد. امتداد استخدام واحد مدة فحص إطلاق و ملاحظات، لا إضافة جديدة شبكة استعادة فحص أو لم مرور تأكيد عام تلميح.

### تحت مرة بدء تثبيت

هدف هو كامل عملية بدء، لا هو إعادة فتح نافذة أو تحديث جديد تصيير طبقة. أولوية في استعادة عمل خدمة مهمة أو بدء محلي dsh قبل تثبيت؛ ما زال تخزين نشط تلقي إدارة مورد حاجة واضح إغلاق تأكيد. قد ذاكرة مؤقتة ZIP أو تثبيت جهاز لا إثبات أصلي دقيق تجهيز إتمام. مثل فعلي عرض حل ضغط، تحقق و دقيق تجهيز، لا زائف صنع دخول درجة.

استخدام قد دقيق تجهيز جيد هدف، لا لـ تحت تحميل جديد حزمة تأخير متأخر بدء. حد وقت فحص إذا اكتشاف أكثر عال مرشح، كما منصة ما زال سماح وضع ترك مؤقت تخزين هدف، يمكن دفع متأخر هذا مرة تثبيت و فتح حالي تطبيق؛ أصلي تثبيت جهاز وصل إدارة بعد ممكن لا يمكن إلغاء أو تعديل تبديل هدف، لا نيل عبر حذف أصلي مؤقت تخزين دليل نموذج محاكاة. قسم آخر قياس كمية تحت تحميل إلى حينئذ خيط، نقر إلى خروج، تطبيق استبدال، و جديد إصدار profile تدقيق دقيق و Host بدء استهلاك وقت.

### updater اعتماد تحقق

واحد مدة اعتماد إعلان ما زال من [Desktop حزمة بيانات وصفية](../../../../apps/desktop/package.json) مسؤول.electron-builder 27 / electron-updater 7 إعداد طقم ترحيل هو تقييم تقدير مرشح، لا هو هذا نص تخويل اعتماد ترقية. التالي API و منصة مشروع يحتاج إبرة مقابل اختيار تحديد إصدار و حقيقي تثبيت حزمة نواة تحقق؛ هذا رفع سجل لا إعلان تسمية قد في هذا آلة تنفيذ تحقق.

| مرشح مشروع | مطلوب تحقق |
|---|---|
| `autoInstallEvent` | نواة تحقق `manual`،`onQuit` و `onNextLaunch`؛ فقط ترحيل اعتماد يجب إبقاء يد حركة تثبيت |
| كائن معامل شكل صيغة `quitAndInstall` | نواة تحقق `isSilent`،`isForceRunAfter` و macOS خاص تحديد دلالة |
| تحت مرة بدء ذاكرة مؤقتة | تثبيت قبل إعادة قراءة بيانات وصفية، تحقق ناتج ها أمل و منصة توقيع |
| Windows كل مستخدم NSIS | تحقق بلا حاجة UAC تحت مرة بدء سلوك؛ لا زائف تحديد كل آلة جهاز تثبيت يمكن ساكن صامت |
| Windows جلسة انتهاء | تحقق صلة آلة/إعادة بدء/ملاحظة إلغاء لا بدء لا أمان خروج تثبيت؛ لا زائف تحديد NSIS أصل فرعي صفة |
| macOS Squirrel مؤقت تخزين | تحقق أصلي دقيق تجهيز، خروج/إعادة بدء استبدال، توقيع، عام إثبات و اثنان نوع هيكل بنية |
| بيانات وصفية و أمان قيمة افتراضية | فحص الآن بديل `files[]`، قديم `path`/`sha512` إزالة استهلاك من،`sha2` تصفية استبعاد و NSIS Web Installer قيمة افتراضية |
| بناء أداة ترحيل | نواة تحقق Node جذب محرك اشتراط، يشمل مرشح 22.12 تحت حد، و أصلي ESM، إعداد، توقيع hook و إصدار أداة توافق |
| قد توزيع قديم عميل | تعديل بيانات وصفية قبل فعلي قياس ذلك حقيقي feed و تحميل حمل، لا فقط حسب اعتماد إصدار دفع قطع توافق |

### كثير عدد انتظار تثبيت إصدار

مرشح سياسة تتبع مع الأكثر جديد ملائم استخدام إصدار، لا نحو مستخدم توفير تثبيت حزمة تجميع دمج إدارة. نفس وقت لحظة فقط يحتفظ واحد صالح تحت تحميل/تثبيت هدف؛ مؤقت تخزين ملف لا تحمل وعد يمكن تثبيت قديم إصدار التقاط قاع.

| مشهد | مرشح سلوك |
|---|---|
| A تحت تحميل وقت اكتشاف C | لا عكس تكرار إلغاء A، لاحق فحص معالجة تحديث مرشح |
| A حينئذ خيط، تلقائي ضبط فتح بدء، اكتشاف C | دقيق تجهيز C، استخدام C دخول درجة استبدال A تثبيت مدخل |
| A حينئذ خيط، تلقائي ضبط إغلاق، اكتشاف C | عرض C، فقط في مستخدم عملية بعد بدء تحت تحميل |
| C تحت تحميل وقت ظهور D | لا ضرب قطع C، بعد مجددا اعتبار D |
| قد تأكيد تثبيت و مهمة إغلاق | قفل تحديد الذي اختيار هدف، خلفية لا يستطيع استبدال |
| استبدال A بعد دقيق تجهيز C فشل | متابعة تشغيل قد تثبيت تطبيق، عرض خطأ إعادة محاولة، لا تحمل وعد تثبيت A |

وضع ترك قد دقيق تجهيز هدف قبل إعادة تأكيد منصة دعم حمل. ذاكرة مؤقتة هوية يتضمن ناتج بيانات وصفية و ها أمل، لا فقط هو إصدار نص. حينئذ خيط بعد استبدال هو تطبيق تنسيق ضبط منطق، لا هو زائف تحديد updater مكتبة تلقائي توفير قدرة؛ يجب ربط دمج عبر طريق تغير، جديد إصدار، إعادة محاولة و تثبيت جهاز تسليم وصل مفرد وحيد اختبار.

### ذاكرة مؤقتة بطلان و سحب عودة

إعادة استخدام قد تحقق كامل ذاكرة مؤقتة، لا تحمل وعد جزء تحت تحميل متابعة نقل أو إبقاء قديم يمكن تثبيت حزمة. مشكلة إصدار عبر إصدار أكثر عال إصلاح إصدار و تحديث feed معالجة. بيانات وصفية لا مطابقة ممكن جعل جزء ذاكرة مؤقتة بطلان، لكن لا هو صارم إطار سحب عودة: قد مؤقت تخزين أو تثبيت في ناتج ما زال ممكن يتم تطبيق. فشل بعد متابعة تشغيل قد تثبيت تطبيق مختلف في تثبيت قديم ذاكرة مؤقتة. لا تنفيذ مستقل تثبيت حزمة سحب عودة بيان أو تثبيت قبل سحب عودة اعتراض قطع. قوي صنع API حكم تحديد هل يجب ترقية، لا قرار تثبيت أو عمل ملغى أي عدد updater ناتج.

## اعتبار مرور بديل خطة

**أول إصدار تفعيل الكل توسيع.** في بعد بلا Desktop توزيع وقت زيادة لم مرور تحقق تثبيت و إصدار مسار. ثابت Nightly، واضح تأكيد تثبيت توفير مقارنة صغير واحد مدة نطاق.

**سوف تعديل ضبط نظر عمل إلغاء.** أصلي مؤقت تخزين ممكن قد يحتفظ تثبيت عملية. منتج نص سجل و حالة تحويل يجب عكس عكس مرور مرور تحقق إلغاء قدرة.

## تحقق استلام معيار

- مستقل دفعة دقيق كل بند توسيع؛ ممتلئ كاف مقابل تحقق استلام قبل إبقاء واحد مدة سلوك.
- إصدار `.dsk.N` قبل اختبار مستقل إصلاح حجز ترتيب و كل إصدار تفكيك قسم إزالة استهلاك من.
- تحقق اثنان عدد عبر طريق إصدار، اختيار حفظ دائم، رفض قديم قديم استجابة، إعادة تحقق ذاكرة مؤقتة و منع توقف تخفيض.
- فعلي قياس Windows كل مستخدم تثبيت و macOS x64/arm64 تحديث دقيق تجهيز، إنهاء، تحت مرة بدء، أصلي مؤقت تخزين،profile تدقيق دقيق و Host بدء.
- تحمل وعد أي وقت سحب إلغاء قبل إثبات إغلاق ضبط مقابل في طريق و مؤقت تخزين تحديث فعلي أثر.
- تغطية A استبدال لـ C،C فشل، خلال ظهور D، عبر طريق تبديل و تثبيت هدف قفل تحديد.
- إبقاء مهمة تأكيد، حقيقي دخول درجة، تلقائي فحص فشل ساكن صامت و استعادة إلى متاح قد تثبيت تطبيق سلوك؛ لا بسبب شبكة فشل منع قطع صحيح معتاد بدء.

## ريح خطر

أصلي تثبيت جهاز ملكية حد إلغاء و استبدال.API وجود ذاته لا يستطيع حفظ إثبات بدء أكثر سريع، بيانات وصفية استبدال أيضا لا هو عام تراجع آلية. مكتبة API مرشح، أمان قيمة افتراضية، بناء جذب محرك و قديم عميل توافق صفة حاجة حسب إصدار إصدار نواة تحقق؛ كتابة هذا رفع سجل لا بديل جدول قد تحقق لـ منتج قدرة.
