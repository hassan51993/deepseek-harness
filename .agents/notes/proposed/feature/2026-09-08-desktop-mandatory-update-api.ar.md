# Agent Note: Desktop قوي صنع تحديث واجهة

Status: proposed

[English](2026-09-08-desktop-mandatory-update-api.md) | العربية

## مشكلة

Desktop في عمل خدمة server لـ محلي عملية، مستخدم بعد لم تسجيل تسجيل وقت أيضا حاجة نيل أخذ قوي صنع تحديث حكم تحديد. نقل حركة طرف عادي تحديث استجابة لا تعريف Desktop ناتج تثبيت. خلفية و Desktop حاجة واحد نسخة ذاتي يتضمن بروتوكول، واضح نجاح، منع قطع و خطأ دلالة، و updater ناتج اختيار قسم فتح.

## رفع سجل

استخدام لم تسجيل تسجيل يمكن وصول سياسة واجهة. هذا نص مسؤول Desktop طلب استجابة حقل،[واحد مدة تحديث رفع سجل](2026-09-08-desktop-update-policy-and-installation.ar.md) مسؤول عميل ضبط درجة، واجهة، إصدار ترتيب و تثبيت. خلفية صحيح في وصل دخول؛API عنوان و شبكة صلة دقيق عقدة هو نشر إدخال، لا يمثل خدمة قد متاح. إدارة حل هذا بروتوكول لا اعتماد جانب حافة مستودع أو هذا آلة وثيقة.

### واجهة و وصول

[عميل قرار](../../implemented/feature/2026-09-11-desktop-mandatory-update-client.ar.md) مسؤول قد تنفيذ جولة استفسار و منع سد واجهة. هذا واجهة رفع سجل ما زال مسؤول خلفية نشر و حقيقي ربط ضبط؛ محلي fixture(اختبار قبل وضع بيانات) لا يستطيع إقرار إثبات خدمة.

```http
GET /api/v0/check_client_update
```

استعلام واجهة ذاته يجب إرجاع كامل قوي صنع استجابة، لا يستطيع اعتماد اعتراض قطع أخرى عمل خدمة واجهة. إبقاء Android و iOS قائم سلوك، لا اشتراط قديم نقل حركة طرف تكملة نقل Desktop جديد حقل.Desktop فقط استقبال قوي صنع سياسة، لا استقبال عادي تحديث تلميح، تثبيت حزمة بيانات وصفية،updater هدف إصدار، ضبط تجهيز ID، تثبيت نسخة ID أو حسب نسخة رمادي درجة قسم إعداد.

### طلب

```http
GET /api/v0/check_client_update?scenario=launch
x-client-platform: desktop-win
x-client-version: 0.1.3-rc.2
x-client-bundle-id: com.deepseek.dsh
x-client-locale: ar-SA
x-client-arch: x64
x-client-update-channel: nightly
x-client-bundled-dsh-version: 0.1.3-rc.2
```

بـ فوق header مقابل Desktop متساو لـ لا بد ملء. وصف قد تثبيت لين عنصر قيمة قدوم ذاتي تطبيق و إصدار بيانات وصفية، لا قدوم ذاتي يمكن تحرير UI حقل.

| Header | يحتوي معنى و أخذ قيمة |
|---|---|
| `x-client-platform` | `desktop-win` أو `desktop-mac` |
| `x-client-version` | كامل Desktop SemVer، إبقاء مسبق إصدار معرف؛ واحد مدة انتظار في داخل وضع dsh |
| `x-client-bundle-id` | تطبيق هوية، مثال مثل `com.deepseek.dsh`، منطقة قسم Harness و Chat |
| `x-client-locale` | UI لغة، مثال مثل `ar-SA`؛ اختيار محلي تحويل محتوى، لا بديل جدول منطقة مجال |
| `x-client-arch` | Windows لـ `x64`؛macOS لـ `x64` أو `arm64` |
| `x-client-update-channel` | واحد مدة ثابت `nightly`، مستقل في إصدار بعد لاحقة |
| `x-client-bundled-dsh-version` | إصدار بيانات وصفية في كامل داخل وضع dsh إصدار |

| Query | عميل سلوك | خلفية واحد مدة سلوك |
|---|---|---|
| `scenario` | يحمل استعلام مصدر؛`launch` هو بدء عرض مثال | تجاهل اختصار؛ طاولة وجه نهائي قطعة رفع لا منع سد وصل دخول |
| `region` | اختياري؛ فقط في لديه يمكن معلومة منطقة مجال معلومة وقت يحمل | تجاهل اختصار؛ لا من UI لغة دفع قطع |

اثنان عدد query كل لا مشاركة و واحد مدة سياسة مطابقة أو معامل تحقق. أخرى عميل شرط نفسه وقت، تغيير أو حذف مهمة واحد query لا نيل تغيير حكم تحديد. دورة الحياة إطلاق نقطة و query قطعة رفع لا لا بد واحد واحد مقابل؛ خلفية تفعيل استخدام قبل مجددا اتفاق قطعة رفع و موحد حساب.

### بلا حاجة قوي صنع تحديث

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "biz_code": 0,
    "biz_msg": "",
    "biz_data": null
  }
}
```

هذا يمثل حالي عميل بلا حاجة قوي صنع تحديث، لا يمثل قد تثبيت إصدار الأكثر جديد. إبرة مقابل حالي عميل شرط جديد طازج صالح استجابة يمكن صاف حذف قد لديه منع قطع.Desktop لا إزالة استهلاك هذا استجابة في نقل حركة طرف عادي تحديث تحميل حمل.

### حاجة قوي صنع تحديث

```json
{
  "code": 40005,
  "msg": "Client version too low",
  "data": {
    "show_content": {
      "title": "طلب تحديث DeepSeek Harness",
      "detail": "حالي إصدار قد إيقاف دعم حمل، طلب تحت تحميل و تثبيت جديد إصدار."
    },
    "desktop_app_link": "https://example.com/harness/download"
  }
}
```

عرض مثال URL هو احتلال موضع رمز، لا هو نيل دقيق نشر هدف عنوان.Desktop استخدام التقاط مستو `data` حقل، لا حزمة لف `alt_app` أو `biz_data`. بعد بلا قد توزيع Desktop، لذلك لا حاجة توافق مقارنة مبكر تضمين طقم رفع سجل محلل. نقل حركة طرف `alt_app`،Android رابط و iOS تطبيق معرف إبقاء قائم صيغة.

| حقل | اشتراط |
|---|---|
| `code` | `40005` هو استجابة جسم رمز خطأ، لا هو HTTP حالة |
| `msg` | فقط لأجل تشخيص، لا عمل نابض نافذة نص سجل |
| `data.show_content.title` | لا بد ملء، محلي تحويل صاف نص عنوان |
| `data.show_content.detail` | لا بد ملء، محلي تحويل صاف نص متن |
| `data.desktop_app_link` | لا بد ملء، مطابقة منتج، منصة، هيكل بنية و عبر طريق HTTPS صفحة، يجب رمز دمج عميل سماح قائمة |

واحد مدة لا زيادة `mode`،`force_update`،`show_key`،`target_version`، حسب زر نص سجل أو updater بيانات وصفية.`40005` قرار يجب ترقية، فعلي إصدار و تثبيت حزمة من updater بيانات وصفية قرار. عميل لا اعتماد حسب هذا واجهة آخر فعل قوي صنع هدف إصدار تحقق. عميل حالة قرار محلي تحويل عملية، كل مرة تحت تحميل ما زال يحتاج مستخدم عملية. وصل دخول تطبيق داخل updater بعد، صفحة ما زال بصفة التقاط قاع.HTTP حالة خريطة حسب شبكة صلة ربط ضبط تأكيد؛ شبكة صلة يجب إبقاء JSON خطأ جسم، لا يستطيع استبدال لـ عام نص أو HTML.

### خطأ و سياسة مطابقة

نقص قليل لا بد ملء header، غير قاعدة SemVer أو لا دعم حمل منصة/هيكل بنية/عبر طريق تركيب إرجاع واضح معامل خطأ، لا يستطيع زائف تركيب لـ بلا قوي صنع نجاح أو قوي صنع سياسة. أولوية امتداد استخدام `biz_code = 1` يمثل نقص قليل إصدار،`biz_code = 2` يمثل إصدار غير قاعدة قائم عمل خدمة يحتوي معنى؛ نهائي رمز خطأ قسم إعداد من خلفية مسؤول. خدمة استثناء لا نيل زائف تركيب صار نجاح، لأن نجاح ممكن حل حذف قد لديه منع قطع.

حسب تطبيق هوية، منصة، هيكل بنية،Desktop إصدار، داخل وضع dsh إصدار و عبر طريق مطابقة، من خدمة طرف صيانة إصدار نطاق و أولوية درجة. استخدام كامل SemVer، لا حسب نص ترتيب ترتيب أو قطع قطع مسبق إصدار جزء. واحد مدة اثنان عدد إصدار متبادل انتظار، عبر طريق ثابت Nightly، مستقل إصلاح حجز و عبر طريق تبديل تأخير بعد. لا نيل اشتراط تخفيض، أيضا لا نيل فقط بسبب عميل سبق استعلام أو عرض مرور حينئذ إيقاف إرجاع `40005`.

### سياسة إصدار و حالي حكم تحديد

كل بند توليد فاعلية سياسة حاجة يمكن تحديد مطابقة شرط، محلي تحويل عنوان متن و صالح هدف صفحة. خدمة طرف كل مرة استعلام متساو حكم تحديد حالي عميل شرط. هذه هو خدمة طرف إعداد اشتراط، لا زيادة استجابة حقل، أيضا لا هو تثبيت حزمة سحب عودة آلية.

- تفعيل سياسة قبل إصدار و تحقق قدرة حل حذف قوي صنع اشتراط أكثر عال إصدار، تأكيد حفظ مطابقة صفحة و منصة تثبيت حزمة متاح.
- مقابل تفعيل تطبيق داخل قوي صنع تحديث عميل، أولا نحو ذلك updater feed إصدار قدرة حل حذف اشتراط إصدار، مجددا تفعيل قوي صنع اشتراط. إصدار مسؤول شخص تنسيق ضبط هذا ترتيب؛API لا توفير مستقل تثبيت هدف، ناتج ملائم استخدام صفة استجابة أو عادي تحديث رمادي درجة.
- رابط مطابقة منتج، منصة، هيكل بنية و عبر طريق؛ نقص قليل نص سجل أو نيل دقيق HTTPS هدف وقت رفض تفعيل سياسة.
- حالي عميل لم يعد أمر في وقت إرجاع بلا قوي صنع نجاح استجابة، يشمل ترقية بعد؛ ما زال أمر في وقت حمل متابعة إرجاع قوي صنع سياسة.

مشكلة إصدار عبر إصدار أكثر عال إصلاح إصدار و تحديث updater بيانات وصفية معالجة. لا نحو هذا واجهة زيادة عمل ملغى إصدار بيان، تثبيت قبل ناتج سحب عودة استعلام أو هدف إصدار تحقق. جديد طازج بلا قوي صنع استجابة يمكن حل حذف UI منع قطع، لكن لا اختيار، استبدال أو عمل ملغى updater تثبيت حزمة. ناتج ها أمل/توقيع تحقق ما زال مستقل في قوي صنع حكم تحديد تنفيذ.

### سعة كمية و ذاكرة مؤقتة

سعة كمية و حد تدفق يحتاج تغطية حمل متابعة لم تسجيل تسجيل طلب، و اعتبار عميل دمج و فشل تراجع تجنب. سياسة لمس بلوغ لا اعتماد حديث يوم طلب أو SSE(Server-Sent Events). في خط لمس بلوغ تأخير متأخر تلقي جولة استفسار و شبكة شبكة أثر، مغادرة خط عميل لا يمكن قيام أي نيل معرفة جديد سياسة. بناء اقتراح `Cache-Control: no-store`. شبكة صلة لا نيل فقط حسب URL عبر عميل إصدار، منصة، هيكل بنية أو عبر طريق مشترك استخدام استجابة؛ لاحق ذاكرة مؤقتة يجب تعريف كل سياسة و نص سجل صيانة درجة و حكم تحديد جديد طازج درجة.

## اعتبار مرور بديل خطة

**اعتماد بعيد مسار عمل خدمة اعتراض قطع.** محلي dsh طلب لا واحد تحديد وصول بعيد مسار شبكة صلة، حاجة مستقل لم تسجيل تسجيل استعلام.

**Desktop إعادة استخدام نقل حركة طرف تضمين طقم تحميل حمل.** خلفية اتفاق التقاط مستو Desktop حقل. حسب منصة إبقاء نقل حركة طرف توافق، لا يجعل جديد Desktop دعم حمل من لم توزيع تضمين طقم تغيير جسم.

**زيادة تثبيت هوية و عادي تحديث بيانات وصفية.** أول مدة سياسة لا حاجة حسب تثبيت نسخة رمادي درجة أو ثاني عدد تثبيت جهاز feed. ناتج اكتشاف متابعة من updater مسؤول.

## تحقق استلام معيار

| حالة استخدام | مسبق مدة نتيجة |
|---|---|
| لم تسجيل تسجيل Desktop | بلا حاجة عمل خدمة تسجيل تسجيل يكفي استعلام |
| Windows x64،macOS x64 و arm64 | صحيح تأكيد منصة سياسة و صفحة |
| لا أمر في سياسة | `code = 0`،`biz_code = 0`،`biz_data = null` |
| أمر في سياسة | قمة طبقة `40005`، نص سجل و صفحة مباشر يقع في `data` تحت |
| تغيير أو حذف query معامل | أخرى شرط نفسه وقت حكم تحديد متسق |
| متبادل انتظار Desktop/dsh مسبق إصدار إصدار، ثابت Nightly | كامل SemVer مطابقة، لا اشتراط تخفيض أو تبديل عبر طريق |
| عميل لم يعد أمر في، يشمل ترقية بعد | إرجاع بلا قوي صنع نجاح، لا عمل ملغى updater ناتج |
| يمكن حل حذف اشتراط إصدار، صفحة أو ملائم استخدام feed غير ممكن استخدام | رفض تفعيل سياسة |
| لا بد ملء حقل غير قاعدة أو خدمة فشل | واضح خطأ، لا زائف تركيب لـ بلا قوي صنع نجاح |
| مختلف عميل شرط وصل متابعة طلب | لا عبر عميل سلسلة استخدام ذاكرة مؤقتة |
| قائم نقل حركة طرف طلب | إبقاء قائم اشتراط و استجابة بنية |

## ريح خطر

خلفية يحتاج توفير اختبار/إنتاج عنوان، لم تسجيل تسجيل شبكة صلة وصول، نهائي HTTP/رمز خطأ خريطة، حد تدفق، حقيقي صفحة، سماح مجال اسم، التقاط قاع لغة و سياسة إعداد مسؤول شخص. إصدار مسؤول شخص يحتاج تدريجي منصة تنسيق ضبط updater إصدار متاح و قوي صنع سياسة تفعيل. هذه إدخال ما زال انتظار توفير، لا نيل استخدام تطوير من اعتماد أو تخمين قياس URL ملء ملء.
