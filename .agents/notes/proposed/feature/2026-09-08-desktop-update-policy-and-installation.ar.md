# Agent Note: Desktop تحديث سياسة و تثبيت

Status: proposed

[English](2026-09-08-desktop-update-policy-and-installation.md) | العربية

## مشكلة

Desktop عبر معتاد تشغيل محلي dsh server، لا يمكن اعتماد اعتماد بعيد مسار عمل خدمة خطأ يمكن اعتماد لمس بلوغ قوي صنع تحديث سياسة. مستخدم حاجة تلقائي اكتشاف، رئيسي حركة تحت تحميل، مرئي دقيق تجهيز حالة، و اعتبار تشغيل في مهمة أثر مستقل إعادة بدء تأكيد.

### إصدار و خلفية تحقق استلام

إصدار مسؤول شخص يجب طرف إلى طرف تحقق استلام حقيقي توقيع Windows x64 و macOS x64/arm64 ترقية: اكتشاف، تحت تحميل، ها أمل و توقيع فحص، مهمة أمان إغلاق، تثبيت، إعادة بدء، جديد إصدار Host بدء و profile تدقيق دقيق. أولا إصدار غير ممكن تغيير تثبيت حزمة و blockmap، مجددا إصدار متغير Nightly بيان.[تحزيم قرار](../../implemented/architecture/2026-08-25-electron-desktop-packaging-and-updates.ar.md) مسؤول إصدار و ناتج قاعدة.[واجهة رفع سجل](2026-09-08-desktop-mandatory-update-api.ar.md) مسؤول سياسة حقل؛ إنتاج ربط ضبط يجب تحقق تنقل عميل وصول، قوي صنع/بلا حاجة قوي أكثر استجابة، خطأ، منصة اختيار، نيل دقيق مصدر محطة و سرعة معدل حد. تفعيل قوي أكثر سياسة قبل أولا إصدار قدرة حل حذف اشتراط updater إصدار.

### لم قرار منتج اختيار

نفس إصدار مغادرة خط إعادة بدء بعد حمل دائم إبقاء قوي أكثر منع قطع ما زال يحتاج منتج تأكيد. إذا A صحيح في تحت تحميل أو انتظار تثبيت وقت ظهور جديد إصدار C، في منتج مسؤول شخص دفعة دقيق استبدال قبل إبقاء A؛ لا يستطيع يأخذ تثبيت A تخويل ساكن صامت تعديل لـ تثبيت C. قد تثبيت Windows و macOS رفع تنبيه ما زال تلقي إشعار إذن، مخصص ملاحظة نمط، الأكثر صغير تحويل نافذة و مرور مدة نقر أثر.[لاحق توسيع](2026-09-08-desktop-update-extensions.ar.md) مسؤول تلقائي استبدال و تثبيت.

### CDN و سعة كمية تحقق استلام

التالي إصدار و تشغيل صيانة اختيار بعد انتظار تأكيد، لا بديل جدول قد توليد فاعلية CDN إعداد أو قد إتمام سالب تحميل تحقق استلام.

- [ ] تشغيل صيانة: قسم آخر إعداد `/dsh-desk/feeds/*` و `/dsh-desk/bin/*`، إنتاج كبير ملف تحت تحميل لا ينبغي طويل مدة امتداد استخدام كل مسار التفاف مرور ذاكرة مؤقتة. بيان بناء اقتراح تقييم تقدير عميل عبر `max-age=0` إعادة تحقق،CDN عقدة ذاكرة مؤقتة 30~60 ثانية، إصدار وقت تحديث جديد. اتفاق الأكثر طويل نقل بث تأخير متأخر، و عبر منطقة مجال قياس كمية ثابت URL تغطية بعد مرئي وقت؛ تحديث جديد لا حفظ إثبات كل كرة قيام يكفي رؤية.
- [ ] تشغيل صيانة و إصدار مسؤول شخص: مقابل حمل رقم الإصدار أو ها أمل تثبيت حزمة و blockmap، تقييم تقدير 30 يوم حتى واحد سنة عقدة ذاكرة مؤقتة، لا تغطية ذلك URL. أولا فوق نقل و تحقق تثبيت حزمة، إتمام مسبق حار، مجددا إصدار بيان؛ تأكيد إبقاء دورة مدة تغطية قديم عميل فرق قسم تحديث الذي يحتاج إدخال.
- [ ] تشغيل صيانة و Desktop صيانة من: سوف عقدة TTL و عميل Cache-Control قسم فتح تحقق، فحص تكرار طلب ذاكرة مؤقتة حالة، أمر في معدل و COS عودة مصدر إشارة علامة. تأكيد updater مرفق إضافة استعلام معامل هل قسم تفرق ذاكرة مؤقتة مفتاح أو التفاف مرور ذاكرة مؤقتة؛ فقط تجاهل اختصار قد إثبات لا أثر محتوى معامل. عبر فعلي updater تحقق Range/206،Content-Range، كامل ملف ها أمل و بيان و وقت تحديث. مشاركة قراءة نهوض خبر سحابة[عقدة TTL](https://cloud.tencent.com/document/product/1552/70777) ،[متصفح TTL](https://cloud.tencent.com/document/product/1552/70758) و[ذاكرة مؤقتة إعداد](https://cloud.tencent.com/document/product/1552/95263) وثيقة.
- [ ] Desktop صيانة من و منتج مسؤول شخص: تأكيد بدء و إلى مدة استعادة مفاجئ إرسال طلب معالجة. دورة مدة اهتزاز حركة و لديه حد أعلى فشل تراجع تجنب قد تنفيذ و اختبار؛ بدء و إلى مدة نداء تنبيه ما زال قيام أي فحص. لـ هذه إطلاق زيادة قصير مؤقت مع آلة تأخير متأخر حاجة منتج تأكيد. قوي أكثر سياسة جولة استفسار ما زال استخدام مستقل API و ضبط درجة سياسة.
- [ ] تشغيل صيانة و إصدار مسؤول شخص: اعتماد حسب في خط عميل عدد، بدء/يد حركة/إعادة محاولة ذروة قيمة، تثبيت حزمة كبير صغير و مسبق حساب تحت تحميل مقارنة مثال صنع تحديد طلب كمية و حمل عرض ميزانية. حسب متساو متساو قسم نشر عشرة قسم ساعة جولة استفسار،10 ألف في خط عميل مستو متساو نحو 167 مرة فحص/ثانية،100 ألف نحو 1667 مرة، بعد لم حساب دخول مقدار خارج إطلاق.CDN ذاكرة مؤقتة نقص قليل عودة مصدر ضغط قوة، لا إزالة حذف عميل تحت تحميل تدفق كمية استهلاك استخدام؛ وظيفة استكشاف قياس لا هو سالب تحميل اختبار.
- [ ] تشغيل صيانة: إعداد ذاكرة مؤقتة أمر في معدل، عودة مصدر QPS، خطأ معدل، حمل عرض و استهلاك استخدام إبلاغ تحذير، اتفاق عتبة قيمة و قيمة مجموعة مسؤول شخص. تحقق استثناء طلب منع حماية لن كسر تالف updater طلب أو خطأ إصابة مشترك NAT عميل؛updater طرف نقطة لا يستطيع اشتراط تفاعل صيغة متصفح تحقق. فوق خط قبل سجل لذا عائق موضع وضع مسار.

## اعتبار مرور بديل خطة

**تلقائي مسبق تحت تحميل تثبيت حزمة.** سوف في مستخدم طلب تحت تحميل قبل إزالة استهلاك تدفق كمية. إبقاء تلقائي اكتشاف، لكن واحد مدة كل مرة نقل و إعادة محاولة كل حاجة مستخدم عملية، و لاحق تثبيت تخويل قسم فتح.

**تلقائي إعادة بدء أو عادي خروج وقت تثبيت.** سوف التفاف مرور واضح مهمة أثر تأكيد. تلقائي تثبيت حاجة مفرد وحيد منتج تخويل و منصة تحقق.

**واحد بعيد مسار واجهة تحكم الكل تحديث.** قوي صنع سياسة و عادي ناتج اكتشاف مسؤولية مختلف. سياسة صفحة و updater بيانات وصفية قسم مغادرة، تحقق عبر بعد فقط إعادة استخدام تثبيت تنسيق ضبط جهاز.

## تحقق استلام معيار

- حقيقي توقيع Windows x64 و macOS x64/arm64 تثبيت إصدار ترقية عبر، يشمل جديد إصدار Host بدء و بيانات إبقاء.
- قد نشر سياسة خدمة عبر واجهة رفع سجل تنقل عميل، قوي صنع/بلا حاجة قوي أكثر، خطأ و منصة مستطيل دفعة، لا بـ محلي fixture بديل.
- إصدار مسؤول شخص سجل CDN و وقت تحديث،Range و ها أمل سلوك، طلب و حمل عرض ميزانية، إبلاغ تحذير عتبة قيمة و لذا عائق مسؤول شخص.
- منتج مسؤول شخص في تحمل وعد مغادرة خط قوي أكثر حفظ دائم أو هدف استبدال قبل عمل خروج قرار.

## ريح خطر

محلي updater و واجهة فحص لا يستطيع إثبات قد تثبيت ترقية توافق صفة، خط فوق سياسة متاح صفة أو CDN صفة قدرة. إذا في قدرة حل حذف اشتراط ناتج متاح قبل تفعيل قوي أكثر سياسة، مستخدم ممكن يتم منع قطع كما لا يمكن في تطبيق داخل ترقية.
