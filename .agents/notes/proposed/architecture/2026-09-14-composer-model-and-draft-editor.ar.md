# Agent Note: Composer و DraftEditor عزل اثنان مرحلة مقطع إعادة بنية

Status: proposed

[English](2026-09-14-composer-model-and-draft-editor.md) | العربية

## مشكلة

نفس عدد Client حاجة في مختلف عرض في تحرير نفس عدد Session مسودة مسودة و انتظار إرسال مرفق عنصر.Lexical واحد editor فقط قدرة ربط واحد DOM root؛ كثير عدد عرض موضع حاجة كثير عدد تحرير نسخة، لكن لا يستطيع كل منها يملك متبادل لا متبادل جاف مسودة مسودة و فوق نقل مهمة، أيضا لا يستطيع يجعل Session Controller إدارة حل ضوء علامة، إدخال قاعدة أو DOM.

حالي [SessionInputShell](../../../../packages/client/ui-conversation/src/client/input/facade.ts) معا يتضمن Lexical عملية، مسودة مسودة إسقاط، إيداع حالة آلة و فشل استعادة.[InputBar](../../../../packages/client/ui-conversation/src/client/skeleton/InputBar.tsx) معا يتضمن تحرير منطقة عرض،DOM ربط، مرفق عنصر مدخل و إرسال تحكم عنصر. مباشر في هذا اثنان عدد ملف في تنفيذ كثير نسخة سوف يجعل شفرة رفع أخذ و سلوك فرق مختلف خلط في واحد بدء.

مرفق عنصر فعلي جسم و فوق نقل مهمة قد من [ConversationController](../../../../packages/client/ui-conversation/src/client/service.ts) تجميع في إدارة،shell فقط إبقاء لديه ترتيب مرفق عنصر IDs.skill(تقنية قدرة) اختيار إدراج دخول عادي `/name` نص، عال مضيء من كلمة جدول إرسال توليد؛ ملف و Session أصل فرعي مرجع فإن استخدام حمل مصدر هوية chip. مشترك مسودة مسودة لا يستطيع فقط تزامن نص حرف بينما فقد فقد هذه مرجع، أيضا لا حاجة نسخ مرفق عنصر فعلي جسم.

هذا رفع سجل دقيق تحويل [#3951](https://github.com/deepseek-ai/deepseek-harness/pull/3951) تحرير جهاز عزل، التزام دوران [Client Session و UI كل حق](../../implemented/architecture/2026-08-20-client-session-conversation-ownership.ar.md).Session نشط وثب عرض، إقامة إبقاء حالة و عودة استلام سياسة مستقل تصميم؛[#4138](https://github.com/deepseek-ai/deepseek-harness/pull/4138) فقط بصفة Host دورة الحياة مشاركة اعتبار. هذا رفع سجل لا تنفيذ هذه وظيفة، أيضا لا تكرار #3984 Conversation مكون تفكيك قسم.

## رفع سجل

اعتماد اثنان عدد مستقل PR(Pull Request). رقم واحد مرحلة مقطع تجميع في قائم تحرير تنفيذ، لـ سلوك تعديل دقيق تجهيز واضح موضع؛ ثاني مرحلة مقطع فقط تعديل سلوك.`DraftEditor` مخصص إشارة مسودة مسودة تحرير منطقة،Composer إشارة يتضمن مرفق عنصر و إرسال تحكم عنصر كامل تحرير كتابة منطقة مجال. إبقاء `input/`،`skeleton/`،`InputBar`،`InputHub` و `SessionInputShell`، لا بـ تعديل دليل أو تعديل اسم بصفة إعادة بنية صار نتيجة.

### رقم واحد مرحلة مقطع: خمسة موضع آلة آلة مسؤولية رفع أخذ

التالي ui-conversation مسار متبادل مقابل `packages/client/ui-conversation/src/client/`. كل جديد ملف يجب تحمل تحميل حالي قد تنفيذ منطق، لا بناء قيام احتلال موضع واجهة أو لم قدوم وظيفة.

| أصل موضع | رفع أخذ موضع | لاحق سلوك تعديل سقوط نقطة |
|---|---|---|
| `input/facade.ts` Lexical إنشاء، تسجيل، إسقاط، عقدة عملية و تنظيف | `input/editor/runtime.ts` | مفرد عدد editor تنفيذ و ذلك إنشاء، ربط و تحرير |
| `skeleton/InputBar.tsx` نص حرف منطقة مجال JSX | `input/editor/DraftEditor.tsx` | مفرد نسخة تحرير منطقة عرض، لا يتضمن مرفق عنصر شريط و إيداع تحرير ترتيب |
| `InputBar.tsx` focus،selection reveal،wheel،keymap،picker ربط دالة | `input/editor/view-binding.ts` | مفرد عدد تركيب عرض DOM تفاعل و تحرير جهاز ربط |
| `contract/input.ts` نطاق، مرجع، مفتاح قرص واجهة نوع | `contract/draft-editor.ts` | تحرير جهاز مقابل خارج بيانات و عملية نوع؛ إيداع و مشترك حالة ما زال إبقاء أصل ملف |
| `ui-attachment/src/client/ComposerAttachments.tsx` document drop effect تنفيذ | `ui-attachment/src/client/drop-events.ts` | document سحب وضع استماع تسجيل، توجيه و تنظيف |

`runtime.ts` داخلي كائن من قائم shell إنشاء و تفويض حمل استدعاء. هو حفظ إدارة أصل editor،NodeKey خريطة، إسقاط و Lexical تسجيل؛ لا نسخ هذه حالة، أيضا لا مستقل قرار قدرة لا تحرير أو إيداع.shell متابعة يحتفظ SubmitMachine،draft revision، مرفق عنصر IDs، إشعار،attempt، تسلسل تحويل و نجاح/فشل استعادة قرار.

معا تعلق و حكم قطع و عقدة عملية طريقة في أصل موضع إبقاء حكم قطع. مثال مثل beginCommand span/phase فحص، عقدة استبدال،machine dispatch ترتيب ثابت؛ فشل استعادة دفعة مرة ترتيب ترتيب،revision حفظ حماية، استعادة علامة سجل و history تنظيف وقت نقطة ثابت.editor تحديث ما زال في أصل تزامن موضع عودة ضبط shell إصدار حالة، لا زيادة Promise،effect أو إشعار جولة.

`DraftEditor.tsx` هو بلا مقدار خارج DOM حزمة تركيب عرض رفع أخذ. كل قائم React خطاف،refs، اعتماد عدد مجموعة و effect متبادل مقابل ترتيب ما زال إبقاء في InputBar؛effect فقط في أصل استدعاء موضع تفويض حمل عادي دالة.CSS ملف،class keys،React keys،placeholder و decorator ترتيب متساو ثابت. جديد مكون لا وصل إدارة editor إنشاء أو يحتفظ آخر نسخة مسودة مسودة.

`contract/draft-editor.ts` نقل دخول `TokenSpan`،`ReferenceInsert`،`ArbitrateKey`،`ArbitrateOutcome`،`ComposerKeyboard`،`EditSelection` و `Occurrence`. اسم و عضو ثابت، كل مستهلك من فعلي إعلان موضع استيراد؛ قائم عام خروج فتحة إبقاء أصل اسم و مرئي تجميع دمج.`ComposerKeyboard` ما زال مؤقت وقت اعتماد مشترك `InputState`، هذا لا هو مستقل تلقي تحكم تحرير بروتوكول.

#### رقم واحد مرحلة مقطع ثابت بند

- InputHub ما زال حسب Session إنشاء واحد shell و واحد editor، إنشاء، إعادة استخدام،dispose(مورد تحرير) وقت نقطة و مرة عدد ثابت.
- مسودة مسودة حق قيمة ما زال في Lexical،Undo/Redo،NodeKey هوية،span فحص و revision قاعدة ثابت؛ لا زيادة ثاني نسخة وثيقة أو تخزين.
- `useInput`،`inputActions`،Slot، حدث،inject و عام API اسم، تحميل حمل و سلوك ثابت؛ لا تعديل Host بروتوكول و حفظ دائم صيغة.
- مرفق عنصر اختيار، فوق نقل وقت آلة، صورة معاينة، إيداع دفعة مرة، نجاح صاف فارغ، فشل استعادة و إشعار قاعدة ثابت.
- document drop ما زال في كل أصل مكون نفس effect في تسجيل؛ مفرد picker، تكرار drop، مفرد editor/root حد أصل مثال إبقاء.
- اختبار فقط تعديل فعلي حاجة نوع استيراد؛ لا تعديل اختبار ملف اسم، تأكيد، تسجيل صنع Session أو مسبق مدة إخراج، لا تحديث جديد لقطة.
- لا نقل قد لديه ملف، لا تعديل قد لديه خاص اسم حرف، لا تعديل CSS، لا زيادة حزمة، اعتماد،renderer scope أو عام حالة إطار هيكل.

#### رقم واحد مرحلة مقطع فعلي عزل مسار درجة

| محتوى | إتمام بعد حالة |
|---|---|
| تحرير جهاز تنفيذ | عقدة و إسقاط عملية عودة runtime، عرض عودة DraftEditor،DOM ربط عودة view-binding |
| إيداع و مرفق عنصر تحرير ترتيب | ما زال من أصل shell و ConversationController إدارة، لا سقوط دخول DraftEditor |
| مختلف Session حالة | متابعة حسب أصل قاعدة عزل |
| نفس Session مشترك حالة | متابعة إعادة استخدام أصل shell؛ لا يوجد مزدوج نسخة مرفق عنصر أو فوق نقل مهمة |
| نفس Session مستقل تحرير نسخة | لم تنفيذ، ما زال مشترك واحد Lexical editor |
| مستقل selection،IME،Undo و قائمة مفرد مصدر | لم تنفيذ؛ شفرة موضع قسم فتح لا بديل جدول وقت التشغيل ملكية قد تغيير |
| picker،focus،document drop كثير عرض توجيه | لم تنفيذ؛ ربط شفرة قد لديه مفرد وحيد تعديل موضع |

### ثاني مرحلة مقطع: فقط ضبط كامل سلوك

ثاني مرحلة مقطع مباشر في فوق وصف موضع تنفيذ مشترك مسودة مسودة و كثير تحرير نسخة. منع توقف نقل حركة قد لديه ملف أو دليل، صاف تعديل اسم، صاف رفع أخذ helper/class/component، إعادة ترتيب قد لديه اختبار، و صيغة أو ملاحظة تفسير تنظيف. إضافة جديدة سلوك حاجة جديد نوع، تنفيذ و اختبار يمكن زيادة، لكن لا نيل نسخ قديم شفرة إلى جديد ملف بعد حذف أصل نص قدوم قاعدة تجنب قيد.

إذا سلوك تنفيذ ما زال حاجة بنية دقيق تجهيز، يجب أولا تكملة رقم واحد مرحلة مقطع: لم دمج دخول وقت تعديل رقم واحد مرحلة مقطع PR؛ قد دمج دخول وقت مفرد وحيد زيادة آلة آلة قبل وضع PR. سلوك PR بـ هذا آلة آلة نتيجة لـ base، لا يستطيع مشبك حمل آلة آلة دقيق تجهيز.

#### نهائي حالة ملكية

مشترك Composer نموذج هو قائم SessionInputShell مسؤولية عرض دخول، لا اشتراط مجددا مرة تعديل اسم.Session Controller متابعة فقط إدارة جلسة عمل خدمة، لا import DraftEditor،Lexical أو مشترك مسودة مسودة وثيقة.

| حالة | نهائي owner | كثير عرض اشتراط |
|---|---|---|
| مسودة مسودة متن، دلالة مرجع، محتوى revision | Session صلة ربط مشترك Composer نموذج | مهمة واحد موضع تحرير بعد، عبر نفس عدد استجابة صيغة مصدر إصدار إعطاء كل عرض |
| لديه ترتيب مرفق عنصر IDs، إقرار قيادة، إيداع attempt و فشل استعادة | مشترك Composer نموذج | كل إيداع فقط تسوية مرة، مهمة واحد عرض عملية أثر في نفس دفعة إدخال |
| File،Blob URL، فوق نقل مهمة، دخول درجة و سند إثبات | قائم مرفق عنصر إدارة owner | لا مع عرض نسخ؛ إزالة واحد عرض لا إلغاء أخرى عرض الذي استخدام مورد |
| Lexical،DOM،NodeKey خريطة،selection،IME preedit | كل DraftEditor نسخة | اثنان عدد مستقل editor/root؛ إزالة واحد موضع لا حل ربط آخر موضع |
| قائمة مفرد مرساة نقطة، ملف محادثة إطار و تركيز نقطة | إرسال بدء عملية عرض | حسب عملية مصدر توجيه، لا بـ Session وحيد picker بديل بديل مصدر |
| Session تاريخ،running،queue | Session Controller | متابعة قراءة قائم مصدر، لا نسخ دخول مسودة مسودة نموذج |

React خطاف ما زال من renderer من عار observable ربط، عمل خدمة مكون عبر قائم معيار props قراءة كتابة. مشترك نموذج لا استقبال DOM،Lexical NodeKey أو إدخال قاعدة في بين حالة؛DraftEditor لا استقبال Session/Context أو فوق نقل خدمة، فقط استقبال مسودة مسودة بيانات، عرض بيانات و تحرير/معنى رسم عودة ضبط.

#### مشترك محتوى و تزامن اشتراط

مسودة مسودة محتوى يجب قدرة مستقل في Lexical يمثل عادي نص، تبديل سطر و حمل كامل `ReferenceInsert` معلومة أصل فرعي مرجع. مرجع مشترك هوية لا يستطيع اعتماد بعض عدد editor NodeKey؛ كل نسخة خاص خريطة إلى ذاتي ذات عقدة.skill إبقاء عادي `/name` نص، اثنان موضع من نفس نص و كلمة جدول إرسال توليد عال مضيء، لا جذب دخول مقدار خارج قد اختيار skill قائمة أو تغيير Host تعرف آخر قاعدة.

مسودة مسودة نص كمية صغير، يمكن استخدام كامل دلالة وثيقة تزامن، لا اشتراط تنسيق نفس تحرير حساب قاعدة. مشترك نموذج مسؤول قبول تحرير، قسم إعداد revision و إصدار، تحرير جهاز منطقة قسم محلي إنتاج تغير و خارجي عرض، تجنب تجنب عودة صوت حلقة. قديم revision، قديم نموذج دورة الحياة و قد إزالة عرض عودة ضبط لا يستطيع تغطية جديد محتوى. إيداع تجميد ربط، نجاح صاف فارغ، فشل استعادة و مرفق عنصر تغير يجب عبر نفس مشترك مصدر وصول كل عرض.

IME preedit يخص محلي نسخة، بعيد طرف عرض تحديث لا يستطيع مباشر كسر تالف صحيح في تركيب نص. قدوم ذاتي آخر عرض تعديل، إرسال صاف فارغ و نموذج تحرير مثل أي و تركيب حالة متبادل لقاء، يجب في ثاني مرحلة مقطع تعريف و تحقق.Undo/Redo أيضا يجب أثر في نفس نسخة منطق مسودة مسودة، لا يستطيع يجعل اثنان نسخة Lexical history متبادل متبادل استعادة قديم قديم كامل مقالة وثيقة؛ أداة جسم تزامن و تاريخ تنفيذ لا يخص آلة آلة مرحلة مقطع.

برنامج تحويل إدراج دخول، قائمة مفرد اختيار، ملف اختيار جهاز و تركيز نقطة استعادة يلزم يحمل إرسال بدء عرض مؤقت هوية. عرض إغلاق بعد لا يستطيع يأخذ متأخر إلى UI عملية تحويل إرسال إعطاء آخر عدد نفس Session عرض.document drop يجب واضح مرة سحب وضع اختيار أي عدد هدف و حفظ إثبات فقط معالجة مرة؛ مصدر توجيه و ذهاب إعادة متساو هو ثاني مرحلة مقطع سلوك.

تحديث جديد بعد قائم نص حرف مسودة مسودة استعادة ينبغي إبقاء، لكن لا افتراضي إضافة جديدة بنية تحويل مرجع،File أو عبر متصفح تنسيق عمل حفظ دائم تحمل وعد.Session نشط وثب عرض و LRU/وقت حد سياسة لا و هذا نسخة تحرير بروتوكول ربط.

## اعتبار مرور بديل خطة

**فقط يأخذ input تعديل اسم أو مستو نقل إلى composer.** لا يستطيع قسم مغادرة Lexical عملية، عرض ربط و إيداع قرار، لاحق سلوك تنفيذ ما زال يحتاج من كبير ملف في رفع أخذ قديم شفرة، لذلك لا بصفة رقم واحد مرحلة مقطع صار نتيجة.

**يجعل واحد Lexical editor معا تعليق اثنان عدد DOM root.** و Lexical مفرد root نموذج اندفاع مفاجئ، لا يستطيع استخدام React نسخ عرض قدوم نيل نيل اثنان عدد يمكن مستقل تفاعل تحرير جهاز.

**كل Composer مستقل مسودة مسودة و مرفق عنصر.** لا ممتلئ كاف نفس Session مشترك تحرير اشتراط، أيضا سوف جذب دخول مرفق عنصر و إيداع كل حق قسم اختلاف.

**آلة آلة مرحلة مقطع مباشر تنفيذ مشترك DraftDocument،Undo أو drop ذهاب إعادة.** تغيير حق قيمة، دورة الحياة أو حدث معالجة مرة عدد، لا يمكن بصفة سلوك ثابت قبل وضع تعديل مراجعة فحص.

## تحقق استلام معيار

رقم واحد مرحلة مقطع يجب إتمام خمسة موضع رفع أخذ و لا بد يلزم استيراد،JSDoc و README تحديث؛ تدريجي بند نواة مقابل أصل طريقة جسم، فرع، عودة ضبط مرة ترتيب،Hooks،DOM و تنظيف. قائم تحرير، مرجع، إقرار قيادة، مرفق عنصر، إيداع، فشل استعادة و إزالة اختبار متابعة عبر؛ استخدام بناء ناتج تشغيل إبرة مقابل صفة متصفح ارتداد، مسبق مدة إخراج ثابت. نوع و وثيقة فحص تغطية نقل حركة بعد إعلان و مزدوج لغة إعداد مقابل. لا بـ جديد مزدوج نسخة وظيفة بصفة رقم واحد مرحلة مقطع تحقق استلام شرط.

ثاني مرحلة مقطع يجب استخدام نفس Session اثنان عدد حقيقي تركيب Composer تحقق مزدوج نحو نص حرف و chip تزامن،skill عال مضيء، مشترك مرفق عنصر و دخول درجة، إرسال صاف فارغ/فشل استعادة،IME/Undo، مصدر توجيه، و مهمة واحد عرض إزالة بعد آخر موضع متابعة عمل. ذلك فرق مختلف يجب فقط يتضمن سلوك تنفيذ و متبادل ينبغي اختبار، لا يتضمن آلة آلة كامل إدارة.

## ريح خطر

بلا حالة JSX رفع أخذ ما زال ممكن تغيير ref أو effect وقت ترتيب؛ لذلك Hook و ref مضيف إبقاء ثابت،DOM لا زيادة حزمة تركيب.Lexical رفع أخذ ممكن تغيير تضمين طقم update،projection ذاكرة مؤقتة أو history تنظيف ترتيب؛ لذلك إبقاء أصل عملية جسم و مقابل وفق تنفيذ مرة ترتيب، بينما غير إعادة كتابة حساب قاعدة.

رقم واحد مرحلة مقطع ما زال لا يستطيع معا تركيب نفس Session اثنان عدد تحرير جهاز، كما إبقاء أصل picker/drop حد. لاحق إذا خطأ يأخذ دليل عزل عند صار حالة عزل، سوف صنع صار root متبادل متبادل حل ربط، تكرار مرفق عنصر استقبال أو خطأ تركيز نقطة توجيه؛ هذه حد يجب من ثاني مرحلة مقطع مزدوج نسخة سلوك اختبار إغلاق.
