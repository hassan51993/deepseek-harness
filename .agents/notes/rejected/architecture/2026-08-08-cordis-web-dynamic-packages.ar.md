# Agent Note: Cordis Host/Client حركة حالة إضافة تشغيل جسم نظام

Status: rejected — closed as a proposal: the shipped packages/extensions runtime and its READMEs own the design

[English](2026-08-08-cordis-web-dynamic-packages.md) | العربية

## Problem

نموذج حاجة في لا تعديل مستودع شفرة المصدر، لا إعادة بناء تطبيق، لا تحديث جديد متصفح قبل رفع تحت، مؤقت توسيع حالي DSH عملية. توسيع حيث ممكن تشغيل في Host Node.js عملية، أيضا ممكن تشغيل في Client متصفح صفحة، أيضا ممكن من Host أخذ عدد،Client عرض، مشترك نفس مجموعة صار واحد إضافة.

هذا بند قدرة لا يستطيع فقط هو “تنفيذ واحد مقطع شفرة”. نموذج حاجة في كتابة شفرة قبل اكتشاف اثنان طرف سماح استخدام Service،Event،Builtin،Slot و رئيسي عنوان token؛ مستخدم حاجة أولا معاينة شفرة، مجددا قرار هل سماح Client شفرة دخول صفحة؛ نفس عدد إضافة حاجة إلحاق غير ممكن تغيير إصدار، فشل بعد إعادة محاولة أو رجوع؛ تشغيل بعد مختلف خطوة خطأ حاجة عودة إلى نموذج، بينما لا هو فقط إبقاء في خدمة طرف سجل أو متصفح تحكم منصة.

إذا يأخذ تعريف، مراجعة دفعة، تشغيل، إصدار تبديل، قدرة اكتشاف و UI حالة سد دخول واحد حركة عمل، سوف إنتاج لا يمكن مستقر حل تفسير حالة: تعريف نجاح هل انتظار في تشغيل نجاح، ترقية فشل بعد أي عدد إصدار ما زال هو نجاح إصدار، صفحة لا يوجد استجابة وقت Tool ينبغي انتظار كثير دائم، نفس عدد Package كثير مرة وقت التشغيل أي ورقة تاريخ بطاقة تحمل تحميل عمل خدمة UI، و Client صفحة نطاق جزء تركيب تحميل حالة هل قدرة بديل جدول Host عملية درجة حالة.

## Proposal

### نواة قلب أصل فإن

- Host حفظ Plugin،Package،Run، مراجعة دفعة و إصدار إشارة إبرة وحيد عملية درجة مرجعي حالة.
- Client فقط حفظ حالي صفحة مراجعة دفعة تفاعل، تركيب تحميل نتيجة،Slot مساهمة، عمل خدمة عرض و صفحة نطاق جزء خطأ.
- Define فقط إنشاء غير ممكن تغيير شفرة إصدار؛Run فقط تنشيط واحد قد تعريف إصدار.
- إصدار تبديل فقط لديه في هدف Package إتمام اشتراط Host/Client تنشيط بعد عندئذ إيداع `currentPackageId`.
- نموذج كتابة شفرة قبل عبر Inspect Provider استعلام قدرة؛Inspect نتيجة فقط مساعد مساعدة تحرير رمز، لا بصفة إضافة وقت التشغيل عمل خدمة بيانات.
- Host و Client حركة حالة شفرة كل استخدام تلقي حد plain JavaScript سياق، و يأخذ يمكن سحب إلغاء فرعي أثر تعليق إلى Cordis دورة الحياة.
- Client شفرة دخول صفحة قبل حاجة مستخدم تخويل؛ تخويل نطاق يمكن هو مفرد عدد Package، أيضا يمكن هو نفس Plugin لاحق إصدار.
- Tool استدعاء لا انتظار حالي جولة انتهاء بعد عندئذ ممكن حدوث مراجعة دفعة أو متصفح عملية؛ مختلف خطوة ربط نطاق عبر حالة تخزين و نموذج steering ملاحظات.

### حزمة مسؤولية و اعتماد جهة نحو

حركة حالة تشغيل جسم نظام من `packages/self-modification/` تحت أربعة عدد حزمة مجموعة صار:

| حزمة | npm حزمة اسم | مسؤولية |
| --- | --- | --- |
| `tool-cordis` | `@deepseek-ai/dsh-tool-cordis` | تسجيل System Prompt، سبعة عدد نموذج Tool،Host Inspect Provider،`@pluginId` سياق حقن و Tool عرض بيانات وصفية |
| `cordis-host-runner` | `@deepseek-ai/dsh-cordis-host-runner` | حفظ مرجعي Registry، قسم إعداد ID، تنفيذ Host شفرة، إدارة إصدار، مراجعة دفعة،Run، خاص handler،Inspect توجيه و نموذج ملاحظات |
| `cordis-client-runner` | `@deepseek-ai/dsh-cordis-client-runner` | في متصفح تزامن Inspect manifest، تحرير ترتيب مراجعة دفعة بعد Host→Client تنشيط، طلب قيمة Client شفرة، إدارة Guard،Loader/Fiber،timer، مثال صيغة و teardown |
| `ui-cordis` | `@deepseek-ai/dsh-client-ui-cordis` | عرض Define/Run Tool بطاقة، عام Cordis وجه لوح، مراجعة دفعة تحكم عنصر، إصدار اختيار، تشغيل حالة و Package ذاتي تعريف عمل خدمة عرض |

`tool-cordis` فقط اعتماد Host Runner عملية داخل خدمة، لا استيراد Client تنفيذ.`ui-cordis` فقط إزالة استهلاك Client Runner face و Client-safe wire نوع، لا استيراد Host تنفيذ.Host و Client تشغيل تحكم عبر قد لديه توليد Remote وجه و تحويل إرسال حدث اتصال، شبكة صلة لا يملك حركة حالة Plugin مجال منطق.

### مجال كائن

#### Plugin

Plugin هو يمكن حمل متابعة تعديل حركة حالة إضافة نسخة، من صنف لوحة نوع `CordisDynamicPluginId` معرف، مثال مثل `clock-1`. جديد بناء Plugin وقت، نموذج فقط إيداع 3 حتى 6 موضع صغير كتابة إنجليزي نص دلالة بادئة؛Host إضافة عملية داخل وحيد عدد حرف بعد لاحقة. كامل `pluginId` لا يستطيع من نموذج إشارة تحديد.

Plugin يخص تعريف هو Session. نموذج Tool فقط قدرة قراءة و عملية حالي Session Plugin؛ عام Client وجه لوح يمكن صف خروج كل Session Plugin، لكن كل حركة عمل ما زال استخدام هذا سطر يحمل owner Session تنفيذ.

#### Package

Package هو Plugin تحت غير ممكن تغيير شفرة إصدار، من `CordisDynamicPackageId` معرف، مثال مثل `pkg-2`. هو يتضمن اسم، استخدام طريق، اختياري Host شفرة و اختياري Client شفرة، كما حتى قليل يتضمن واحد جانب. كل مرة `cordis_define` كل إنشاء جديد Package؛ قد لديه Package لا سماح أصل أرض تعديل.

نفس عدد Plugin يمكن يملك كثير عدد Package، لكن نفس وقت لحظة الأكثر كثير فقط لديه واحد شيء إدارة Run.Package هل يحتوي Host أو Client نصف فقط قرار تنشيط خطوة، لا تغيير إصدار هوية.

#### Plugin Run

Plugin Run هو مرة أداة جسم تنشيط محاولة تجربة، من `CordisDynamicPluginRunId` معرف، مثال مثل `run-3`. كل مرة جديد تنشيط محاولة تجربة كل سوف قسم إعداد جديد ID، يشمل مراجعة دفعة بعد فشل، إعادة محاولة نفس Package و إصدار تحديث.`pluginRunId` يأخذ مراجعة دفعة،Host تنشيط،Client تركيب تحميل، خاص RPC،Tool بطاقة و خطأ صلة ربط إلى نفس مرة محاولة تجربة.

Host قسم فتح حفظ حالي شيء إدارة Run و `latestRun`. شيء إدارة Run يمثل هذا لحظة ما زال يمكن استدعاء و سحب إلغاء تنشيط؛`latestRun` يمثل الأكثر قريب مرة محاولة تجربة مراجعة دفعة، مرحلة مقطع، اثنان جانب حالة و تشخيص. مرة فشل يمكن لا يوجد تخزين نشط شيء إدارة Run، لكن ما زال إبقاء تحت يمكن استعلام attempt.

#### إصدار إشارة إبرة

- `currentPackageId` هو الأكثر قريب مرة إتمام اشتراط تنشيط مسار Package. إيقاف إضافة، بدء تحديث أو تحديث فشل كل لا صاف حذف هو.
- `nextPackageId` هو جارٍ انتظار مراجعة دفعة، جارٍ تنشيط، انتظار Client، أو الأكثر قريب فشل هدف Package. هدف نجاح إيداع لـ current بعد صاف حذف.

Host-only Package في Host نجاح بناء قيام Fiber بعد إيداع current. يتضمن Client Package في Host تنشيط نجاح كما حتى قليل واحد Client نجاح بناء قيام مقابل تركيب تحميل بعد إيداع current. بسبب صلب اعتماد ناقص بينما يتم Cordis park لـ waiting Fiberما زال هو نجاح بناء قيام دورة الحياة كائن، لا انتظار نفس في تحليل أو `apply` فشل.

تحديث هدف فشل وقت لا تلقائي إعادة بدء قديم شيء إدارة Run. قديم `currentPackageId` متابعة يمثل الأكثر بعد نجاح إصدار، فشل هدف إبقاء لـ `nextPackageId`. مستخدم أو نموذج يمكن إعادة محاولة next، أيضا يمكن بـ `mode: "run"` إعادة تنشيط current إتمام رجوع.

### Host مرجعي حالة و حمل دائم صفة

`DynamicCordisRunnerService` و ذلك داخلي Registry هو حالي DSH عملية داخل وحيد مرجعي، حفظ:

- Plugin Session ملكية و غير ممكن تغيير Package تجميع دمج؛
- `currentPackageId`،`nextPackageId`، شيء إدارة Run و `latestRun`؛
- مفرد Package تخويل و Plugin عبر إصدار تخويل؛
- انتظار معالجة Client تنشيط طلب؛
- Host Fiber،Package خاص handler، انتظار في Service و الأكثر قريب تشخيص؛
- Host و Client Inspect Registry دليل و استعلام توجيه.

هذه كائن لا كتابة إعداد أو مغناطيس قرص، أيضا لا في عملية إعادة بدء بعد استعادة.Session Log يمكن إبقاء Tool استدعاء، نتيجة و بطاقة الذي يحتاج بيانات وصفية، لكن لن إعادة وضع حركة حالة شفرة قدوم استعادة Registry. عملية إعادة بدء بعد تاريخ بطاقة ما زال يمكن بصفة محادثة سجل وجود، أصل `pluginId` و `packageId` لم يعد يمكن تشغيل.

تشغيل حالة لا بصفة يمكن استعادة حالة كتابة Session projection. صفحة تحديث جديد أو جديد صفحة فتح لن تلقائي استعادة Client نصف؛ تلقائي استعادة سوف إعادة جذب دخول اتصال هوية، بدء مدة baseline و عبر صفحة متسق صفة بروتوكول، لا يخص حالي تصميم.

### Define،Run و إصدار تبديل

`cordis_define` لديه اثنان نوع نمط: جديد بناء Plugin وقت إيداع `idPrefix`؛ تعديل قائم Plugin وقت إيداع دقيق `pluginId`. شفرة موحد واحد لـ `code: { host?, client? }`.Define فقط تحقق معامل و plain JavaScript لغة قاعدة، سجل غير ممكن تغيير شفرة المصدر و إرجاع نهائي ID. هو لا تنفيذ `apply`، لا إنتاج مراجعة دفعة، لا تغيير إصدار إشارة إبرة، أيضا لا خفي صيغة تشغيل.

لا توفير مستقل `cordis_update`.`cordis_run` عبر `mode` جدول بلوغ تنشيط معنى رسم:

| إصدار علاقة | `mode` |
| --- | --- |
| بعد بلا `currentPackageId` | `run` |
| هدف انتظار في current، يشمل إعادة بدء، إعادة محاولة أو رجوع | `run` |
| هدف و قد لديه current مختلف | `update` |
| تحديث فشل بعد إعادة محاولة `nextPackageId` | `update` |

Run أولا تحقق Plugin/Package ملكية، إصدار علاقة و هل قد لديه تحويل في إجراء، مجددا إنشاء `pluginRunId`، كتابة `latestRun` و `nextPackageId`.

Host-only Package في Tool استدعاء داخل إتمام Host تنشيط، و تزامن إرجاع `running` أو فشل. يتضمن Client Packageلا في Tool استدعاء داخل انتظار متصفح نهاية نطاق: لم تخويل وقت تسجيل تسجيل مراجعة دفعة و إرجاع `awaiting-approval`؛ قد تخويل وقت تسجيل تسجيل تلقائي Client تنشيط و إرجاع `starting`. هذا اثنان نوع إرجاع كل يمثل طلب قد بناء قيام، لا يمثل كامل تنشيط نجاح.

هدف حق صحيح بدء تنشيط وقت،Host أولا إيقاف قديم شيء إدارة Run، مجددا تنفيذ هدف Host نصف.Host نجاح بعد عندئذ سماح Client نيل أخذ دقيق `pluginRunId` مقابل شفرة المصدر و تركيب تحميل.Client نجاح بعد Host إيداع إصدار إشارة إبرة؛ أي مرحلة مقطع فشل كل سجل إلى هذا attempt، لا يأخذ قديم إصدار إعادة بدء زائف تركيب صار هدف نجاح.

`cordis_stop` سحب إلغاء حالي Host/Client Run و انتظار مراجعة دفعة طلب، لكن إبقاء Plugin،Package، تخويل و إصدار إشارة إبرة.`cordis_undefine` أولا إيقاف، مجددا حذف Plugin،Package، تخويل و إصدار إشارة إبرة؛ حذف بعد تاريخ بطاقة فقط عرض “إضافة قد إزالة”.

### Client مراجعة دفعة و تخويل

يتضمن Client شفرة Package في رقم مرة تنشيط قبل حاجة مستخدم تخويل، لأن هو سوف في مستخدم صفحة في تشغيل نموذج توليد شفرة. مراجعة دفعة وجه لوح توفير ثلاثة عدد حركة عمل:

- مفرد ربط سماح حالي Package؛ نفس Package لاحق إعادة ركض لم يعد مراجعة دفعة، جديد Package ما زال يحتاج مراجعة دفعة.
- مزدوج ربط سماح حالي Plugin لاحق إصدار؛ جديد Package، تحديث، إعادة محاولة و رجوع لم يعد تدريجي إصدار مراجعة دفعة.
- رفض انتهاء حالي طلب، لا تنفيذ Host أو Client شفرة؛ نموذج لا نيل في مستخدم لا يوجد جديد اشتراط وقت قيام أي تكرار تقديم طلب.

تخويل في مستخدم سماح وقت كتابة Host Registry، أي جعل مع بعد حدوث تقنية فن فشل أيضا إبقاء. وجه لوح مباشر تشغيل Package وقت، مستخدم نقر ذاته تخويل هذا Package.

انتظار مراجعة دفعة سطر فقط عرض مفرد مرة سماح، عبر إصدار سماح و رفض، مختلف وقت توفير تشغيل، إيقاف أو حذف. اكتشاف جديد مراجعة دفعة وقت وجه لوح تلقائي توسيع؛ تلقائي توسيع فشل أو يتم طي وقت، ثابت مدخل و سطر حالة ما زال عرض انتظار مراجعة دفعة عدد كمية و حالة.

### Client تنشيط تحرير ترتيب

Host عبر `cordis/request-run` إرسال Client تنشيط طلب. طلب فقط يتضمن طلب هوية،Session،Plugin،Package،mode، اسم، استخدام طريق و هل حاجة مراجعة دفعة، لا واسع بث شفرة المصدر.

نيل نيل تخويل صفحة حسب ثابت ترتيب تنفيذ:

1. استدعاء `runHostHalf`، بدء هدف Host نصف أو ربط نفس مرة attempt قد بدء Host Run.
2. Host نجاح بعد، بـ `pluginId + pluginRunId` استدعاء `getClientCode`، فقط أخذ نيل حالي دقيق Run Client شفرة المصدر.
3. Client Runner في صفحة طلب قيمة إضافة، بناء قيام Loader entry/Fiber، تثبيت Guard، مثال صيغة،Slot و صفحة نطاق جزء حالة.
4. صفحة استدعاء `resolveRequestRun` أو `settleUserRun` عودة تقرير نجاح،waiting أو فشل.
5. Host قبول ما زال صالح دقيق Run عودة تقرير، إيداع current أو حفظ تشخيص، و واسع بث طلب انتهاء، أخرى صفحة تنظيف نشط حركة.

Host تنشيط أولا في Client، تجنب تجنب Client في الذي يحتاج Host handler بعد لم وجود وقت بدء. فقط لديه هذا مرة طلب فعلي إنشاء Host Run عندئذ قدرة بسبب هذا صفحة Client فشل بينما سحب إلغاء؛ فقط هو ربط قائم Run صفحة لا يوجد ذلك كل حق.

Client Orchestrator حسب `pluginId` حفظ انتظار مراجعة دفعة و جارٍ تحرير ترتيب نشط حركة، نفس عدد Plugin لا تزامن تنفيذ اثنان مرة صفحة تنشيط.Host inventory يمكن إعادة بناء متروك تسرب انتظار مراجعة دفعة بند و بلا حاجة مراجعة دفعة تلقائي تنشيط طلب.

Client تركيب تحميل حالة هو صفحة نطاق جزء واقع.Host active لا بديل جدول حالي صفحة قد تركيب تحميل Client نصف.UI استخدام ثلاثة نوع رئيسي يلزم حالة: بلا شيء إدارة Runلـ رمادي لون “انتظار تنشيط” ،Host قد تشغيل لكن حالي صفحة Client لم نجاح تركيب تحميل لـ أصفر لون “Client انتظار تنشيط” ، حالي صفحة اثنان جانب متاح لـ أخضر لون “تشغيل في”. مراجعة دفعة في و فشل بصفة مقدار خارج حالة عرض.

حالي إصدار لا بناء قيام per-connection هوية أو كثير صفحة قاعدة تحديد شخص عدد. رقم واحد ما زال صالح Client نجاح عودة تقرير يمكن إيداع عملية درجة current؛ أخرى صفحة هل تركيب تحميل من كل منها صفحة store يمثل.

### Package خاص Client→Host عبر معلومة

حركة حالة Package عبر خاص JSON عبر طريق من Client استدعاء Host:Host استخدام `harness.handle(method, handler)` تسجيل حالي Run طريقة،Client استخدام `host.call(method, args)` استدعاء. كل مرة استدعاء صلة ربط `pluginId + pluginRunId`،Host رفض قد إيقاف أو مرور مدة Run. معامل و قيمة راجعة يجب هو بلا ضرر JSON، لا سماح دالة،React عنصر عنصر،Context،Service نسخة أو صنف كائن.

هذا عبر طريق فقط خدمة نفس Package Client→Host استدعاء، لا استخدام عام Remote Service أو حركة حالة شفرة في `ctx.remote`. عام Remote وجه فقط تحمل تحميل Runner ذاتي ذات تحكم بروتوكول، لا نحو حركة حالة Package كشف.

### حركة حالة شفرة،Guard و دورة الحياة

Host و Client كل فقط تنفيذ plain JavaScript دالة جسم، لا مرور مرور TypeScript،JSX أو bundler تحويل ترجمة.Host تشغيل في `node:vm`،Client في تلقي حد إغلاق حزمة في طلب قيمة. اثنان طرف سياق لأجل نقص قليل خطأ استخدام و توفير تعليم تعلم خطأ، لا هو سيئ معنى شفرة أمان حد.

نموذج افتراضي عبر `ctx.get('serviceName')` قراءة اختياري Service و حكم قطع `undefined`. فقط لديه Service هو صلب اعتماد، ناقص وقت Package يجب waiting و في Service ظهور بعد إعادة تنشيط وقت، عندئذ في إضافة كائن إعلان `inject`. مباشر وصول `ctx.serviceName` فقط في نفس إضافة إعلان مقابل inject وقت سماح.

Host و Client `timer` كل هو نفس اسم Cordis Service، استخدام متسق واجهة، لا هو عام Builtin. حاجة timer إضافة يجب إعلان `inject: ['timer']`؛React effect في إنشاء timer يأخذ disposer بصفة cleanup إرجاع.

كل تسجيل و يمكن سحب إلغاء فرعي أثر من حالي Fiber يملك.Event listener،Service،Tool،handler،timer،Slot، مثال صيغة و رئيسي عنوان تغطية عبر `ctx.effect()`،`ctx.on()` أو إرجاع disposer رسمي جهة API تسجيل. إيقاف، تحديث، فشل تراجع أو undefine وقت سحب إلغاء اثنان طرف مساهمة.Theme override يجب حسب source قسم طبقة و إرجاع disposer، جعل إزالة بعد استعادة هذا قبل رئيسي عنوان قيمة.

مضيف،DSH،Cordis و ذلك Service،Event payload،Slot props،Session/Conversation Snapshot،Tool حالة و أخرى وقت التشغيل كائن هو داخلي live data. حركة حالة شفرة لا نيل مقابل هذه كائن أو ذلك فرعي كائن تنفيذ `JSON.stringify`،`structuredClone`، تمرير عودة قطعة رفع، كل كمية نسخ أو كامل جسم عرض؛ فقط قدرة قراءة حالي مهمة الذي يحتاج ورقة فرعي حقل، بنية صنع لا يحتوي مضيف مرجع الأكثر صغير ذاتي لديه بيانات.

### Inspect Provider و Catalog

قدرة اكتشاف قسم لـ ثلاثة عدد Tool:`cordis_inspect_list` صف Host/Client Provider manifest؛`cordis_inspect_query` تنفيذ إشارة تحديد منصة صريح فقط قراءة استعلام؛`cordis_inspect_self` استعلام حالي Session Plugin،Package، شفرة المصدر، إصدار إشارة إبرة و تشغيل تشخيص.

Host و Client كل منها يملك `CordisInspectRegistry`.Provider تسجيل منصة داخل وحيد ID، شرح،method، إدخال schema و إخراج schema.Provider method هو صريح أبيض اسم مفرد استعلام، لا هو مهمة معنى Service طريقة نفاذ نقل؛Registry لا صيانة قسم طبقة target، أيضا لا تلقائي يأخذ عمل خدمة Service طريقة تغيير صار يمكن تنفيذ Inspect method.

أول دفعة Provider لـ:

| Platform | Provider.method | بيانات مصدر |
| --- | --- | --- |
| Host / Client | `Service.listService` | كل منصة Service ساكن حالة Catalog |
| Host / Client | `Event.listEvents` | كل منصة Event ساكن حالة Catalog |
| Host / Client | `Builtin.listBuiltins` | evaluator/Guard مرفق قريب يد عمل تعريف |
| Host | `Tool.listTools` | حالي Agent حق صحيح مرئي Tool Registry |
| Client | `Slots.listSubTree` | Slot ساكن حالة Catalogو صفحة live subtree/occupants |
| Client | `Theme.listTokens` | ThemeService فقط قراءة inspect export |

Client Registry تغير بعد نحو Host تزامن كامل manifest، لا حسب Session حفظ تكرار دليل.Host query محلي تنفيذ؛Client query من Host واسع بث request ID، صفحة استدعاء محلي Provider بعد عودة إرسال.Host فقط قبول رقم واحد عبر إخراج schema تحقق نجاح نتيجة؛ فشل صفحة لا انتزاع احتلال طلب. لا يوجد صفحة نجاح عودة جواب وقت Tool إبقاء pending، مباشر إلى لاحق نجاح أو Tool call إلغاء.

Inspect بيانات فقط لأجل كتابة شفرة قبل تأكيد قدرة، توقيع، نوع و تركيب بروتوكول. إضافة وقت التشغيل حاجة عمل خدمة بيانات وقت يجب استدعاء فعلي Service أو استماع فعلي Event، لا يستطيع ذاكرة مؤقتة، عرض أو اعتماد Inspect/Catalog قيمة راجعة.

`CordisCatalogProjector` استخدام TypeRT قسم آخر توليد Host/Client Service و Event Catalog؛Slot AST توليد جهاز مسح `SlotMap`، تسجيل خيار،standard props،owner props و مرجع نوع؛Slots Provider استعلام وقت دمج ساكن حالة Catalog و live tree.Theme token من ThemeService تصدير،Builtin في evaluator/Guard مرفق قريب يد عمل صيانة،Tool schema قدوم ذاتي Registry.

Catalog مسح حقيقي شفرة المصدر توقيع، مجددا تطبيق model-visible أبيض اسم مفرد. أبيض اسم مفرد يمكن إخفاء Service، عضو،`@deprecated` API،Runner ذاته خدمة و `cordis/*` تحكم Event، لكن لا يستطيع تعديل كتابة باق بقية API طريقة اسم، معامل و إرجاع نوع.Guard يمكن رفض معامل، ثابت مصدر أو شاشة حجب عضو، لكن يجب احترام إعادة شفرة المصدر توقيع.

نموذج مرئي owner JSDoc فقط اشتراط كامل description، كل معامل `@param`، غير void إرجاع `@returns`،Event `@mode`، و Slot/props حقل شرح. استدعاء دفع ترشيح، عكس مثال و عبر قدرة اختيار وضع دخول Skill، لا في Catalog زيادة تكرار example حقل.

### نموذج إشارة توجيه قسم طبقة

نموذج إشارة توجيه قسم لـ أربعة طبقة:

- System Prompt حفظ مستقر تشغيل نموذج، اثنان طرف حد، دورة الحياة، مراجعة دفعة، إصدار إشارة إبرة، الأكثر منخفض شفرة مواصفة و سبعة عدد Tool استخدام أرض رسم.Skill غير ممكن استخدام وقت هو ما زال يجب دعم حمل الأكثر منخفض حد درجة صحيح تأكيد تنفيذ.
- `cordis-plugin-development` Skill حفظ يحتاج طلب تنقل، قدرة تركيب، دفع ترشيح و عكس مثال، لا نسخ كامل schema.
- كل Tool description فقط شرح هذا حركة عمل قبل وضع شرط، معامل دلالة، تزامن/مختلف خطوة نتيجة و تحت واحد خطوة.
- Provider/Catalog إرجاع حالي دقيق اسم، توقيع، معامل،Slot props،token و وقت التشغيل استعلام نتيجة.

System Prompt اشتراط أولا تحميل Skill، مجددا list/query، بعد define/run.Skill في React عرض مثال يجب تسجيل إلى Slot، لا يستطيع من `apply()` مباشر إرجاع React Element؛ عرض مثال استخدام `React.createElement`، صحيح تأكيد `ctx.get()`/`inject`، يمكن عكس effect و الأكثر صغير JSON RPC.

### `@pluginId` و Tool UI

إدخال نظام لـ حالي Session تسجيل `@pluginId` mention. اختيار بعد فقط حقن Plugin هوية، افتراضي أساس دقيق Package، إصدار إشارة إبرة، نشط حركة Run و الأكثر قريب حالة، لا حقن شفرة المصدر. افتراضي أساس دقيق اعتماد مرة اختيار next،current، الأكثر قريب تعريف Package. نموذج يجب أولا استخدام `cordis_inspect_self` قراءة شفرة المصدر، مجددا بـ existing نمط إلحاق Package؛ مرجع بطلان وقت لا يستطيع ساكن صامت إنشاء بديل Plugin.

`cordis_define` بطاقة بـ Host/Client اثنان عدد فرعي صفحة توقيع عرض شفرة.`cordis_run` بطاقة من `pluginRunId` صلة ربط دقيق attempt، و قراءة Client store عرض انتظار مراجعة دفعة،Client انتظار تنشيط، تشغيل في، فشل، قد يتم لاحق Run بديل أو Plugin قد إزالة.

Package يمكن نحو `tool.view.cordis` تسجيل `key: "self"`. وقت التشغيل يأخذ self ربط لـ `pluginId + packageId`؛ عمل خدمة Slot key لا يحتوي `pluginRunId`، لكن owner props ما زال توفير دقيق Run هوية. نفس Package الأكثر جديد Run بطاقة تحمل تحميل عمل خدمة UI، أكثر مبكر بطاقة عرض قد لديه تحديث تشغيل. بطاقة عبر store استجابة تغير، لا مسح لاحق Session Log، أيضا لا متبادل متبادل إشعار.

عام Cordis وجه لوح استخدام واحد ثابت مدخل، حسب حالي جلسة و أخرى جلسة قسم مجموعة. وجه لوح عنوان و طي عملية ثابت، فقط لديه قائمة تمرير. عادي سطر اختياري اختيار Packageو تشغيل، إيقاف أو حذف؛ فشل تحديث يمكن إعادة محاولة next أو اختيار current رجوع؛ انتظار مراجعة دفعة سطر فقط توفير اثنان عدد سماح حركة عمل و رفض.

### خطأ و نموذج ملاحظات

عبر Host/Client تقنية فن خطأ إبقاء أصلي `message`، و في خطأ كائن توفير وقت إبقاء `stack`. بنية تحويل تشخيص يتضمن `pluginId`،`packageId`،`pluginRunId` و مرحلة مقطع:approval،host-load،host-apply،client-load،client-apply أو client-render.

Host/Client Guard،Host طلب قيمة و handler،Client طلب قيمة و apply،Slot `onEntryError` و React ErrorBoundary كل يأخذ خطأ عودة إلى owning Agent.Client تحكم منصة معا بـ `console.error` ضرب طبع أصلي error كائن. تصيير خطأ يخص دقيق Run، لا تلوث صبغ غير ممكن تغيير Package.

نموذج إرسال بدء مختلف خطوة Run في نجاح، رفض أو تقنية فن فشل بعد استخدام `agent.steer` نداء تنبيه owning Agent. تقنية فن فشل اشتراط قراءة تشخيص، في نفس Plugin إصلاح صحيح و ذاتي رئيسي إعادة محاولة؛ مستخدم رفض فإن منع توقف تلقائي تكرار تقديم طلب. مستخدم في وجه لوح يد حركة تشغيل، إيقاف أو إزالة عبر context injection إبلاغ معرفة تحت واحد step، لكن لا رئيسي حركة نداء تنبيه نموذج.

## Alternatives considered

**Define و Run دمج.** هذا سوف فقد ذهاب “قد تعريف لكن لم تشغيل” يمكن معاينة حالة، يأخذ لغة قاعدة خطأ، مراجعة دفعة، تشغيل خطأ و إعادة محاولة خلط صار واحد حركة عمل، لذلك تفكيك لـ غير ممكن تغيير Define و مستقل Run.

**Package ID معا بصفة Plugin ID.** مفرد طبقة ID لا يمكن جدول بلوغ مستقر نسخة تحت إلحاق غير ممكن تغيير إصدار، تحديث فقط قدرة stop،undefine، إعادة define، تاريخ بطاقة و `@` مرجع أيضا لا يمكن إبقاء نفس كائن، لذلك اعتماد Plugin،Package،Run ثلاثة طبقة هوية.

**توفير مستقل `cordis_update`.** Update تركيب تحميل، مراجعة دفعة،UI، تشخيص و Run نفسه، مستقل Tool فقط نسخ بروتوكول، لذلك دمج إلى `cordis_run mode:"update"`.

**تحديث فشل بعد تلقائي استعادة قديم شيء إدارة Run.** تلقائي استعادة سوف يأخذ “هدف فشل” و “قديم إصدار إعادة نجاح” خلط صار واحد نتيجة. حالي تصميم إبقاء قديم current إشارة إبرة لكن لا تلقائي إعادة بدء، يجعل مستخدم واضح اختيار إعادة محاولة next أو run current.

**يجعل `cordis_run` منع سد إلى مستخدم مراجعة دفعة و Client نهاية نطاق.** مراجعة دفعة أو صفحة عملية ممكن فقط قدرة في حالي نموذج جولة انتهاء بعد حدوث، منع سد سوف شكل صار ميت قفل، و في بلا صفحة وقت بلا حد احتلال استخدام Tool. حالي تصميم قيام أي إرجاع، عبر store،Inspect و steering تقرير إبلاغ نهاية نطاق.

**Host واسع بث شفرة المصدر و استخدام مهلة انتظار Client ack.** واسع بث سوف في تخويل قبل يأخذ شفرة إرسال إعطاء كل صفحة؛ مهلة لا يمكن منطقة قسم لا يوجد صفحة، صفحة بطيء و مستخدم لم عملية؛Host أيضا يلزم صيانة تكملة تعويض صيغة تراجع. حالي بروتوكول فقط واسع بث بيانات وصفية، من نيل دقيق صفحة حسب دقيق Run سحب أخذ شفرة المصدر.

**صفحة بدء وقت تلقائي استعادة كل Host active Package.** هذا اشتراط اتصال هوية، بدء مدة baseline و عبر صفحة متسق صفة. حالي تصميم قبول صفحة نطاق جزء Client حالة، مستخدم يمكن في وجه لوح إعادة تركيب تحميل.

**عبر عام Remote Service أو `ctx.remote` اتصال Package اثنان نصف.** هذا سوف يأخذ حركة حالة Package كشف إلى منتج درجة RPC وجه.Package خاص `harness.handle`/`host.call` كاف بـ تحمل تحميل Client→Host JSON استدعاء، و قدرة حسب `pluginRunId` رفض قديم قديم طلب.

**يأخذ كل Service طريقة تلقائي كشف صار Inspect query.** هذا سوف يأخذ قدرة اكتشاف تغيير صار عمل خدمة استدعاء بديل إدارة، التفاف مرور إضافة مراجعة دفعة و دورة الحياة.Provider فقط كشف سياسة عرض فقط قراءة استعلام،Service Catalog فقط وصف عمل خدمة طريقة توقيع.

**يأخذ كامل API كتابة دخول System Prompt أو Skill.** ثابت تحويل نص سوف عائم نقل و احتلال استخدام سياق.System Prompt إبقاء مستقر قاعدة،Skill مسؤول يحتاج طلب تنقل، دقيق توقيع و وقت التشغيل دليل من Provider/Catalog إرجاع.

**اشتراط Slot owner في وقت التشغيل تسجيل props schema.** Slot props قد وجود في TypeScript نوع و JSDoc في، تكرار تسجيل سوف صنع صنع ثاني نسخة مرجعي. حالي تصميم استخدام Slot AST Catalog رفع أخذ ساكن حالة بروتوكول، فقط في استعلام وقت دمج live tree.

**يأخذ تشغيل حالة كتابة Session Log و في replay استعادة.** حركة حالة شفرة و Fiber هو عملية نطاق جزء كائن، استعادة اشتراط إعادة تنفيذ تاريخ شفرة و إعادة حل تفسير مراجعة دفعة.Session فقط إبقاء نموذج مرئي سجل،Registry و صفحة Run لا استعادة.

**يجعل تاريخ Run بطاقة مسح لاحق Session Log.** هذا سوف يجعل Tool view اعتماد كل كمية سجل ترتيب و لاحق رسالة بنية. صفحة card index/store قد قدرة حسب Package إبلاغ معرفة قديم بطاقة يتم بديل أو Plugin يتم حذف.

## Acceptance criteria

- جديد Plugin فقط قدرة من 3 حتى 6 موضع صغير كتابة إنجليزي نص بادئة إنشاء، نهائي Plugin،Package و Run ID من Host قسم إعداد و استخدام صنف لوحة نوع.
- `cordis_define` فقط فعل معامل و plain JavaScript لغة قاعدة فحص، إرجاع غير ممكن تغيير Package؛ نفس Plugin يمكن إلحاق إصدار، قديم شفرة المصدر إبقاء يمكن inspect.
- `cordis_run` صارم إطار تحقق run/update؛Host-only تزامن إتمام،Client-bearing إرجاع `awaiting-approval` أو `starting`، لا انتظار صفحة نهاية نطاق.
- مفرد ربط فقط تخويل حالي Package، مزدوج ربط تخويل نفس Plugin لاحق إصدار؛ تخويل في تقنية فن فشل بعد ما زال إبقاء، رفض لا تنفيذ اثنان جانب شفرة.
- Host أولا تنشيط،Client بعد أخذ دقيق Run شفرة المصدر؛Client نجاح قبل لا إيداع Client-bearing Package current، فشل بعد current/next متاح في إعادة محاولة و رجوع.
- واحد Plugin معا الأكثر كثير واحد شيء إدارة Run؛stop سحب إلغاء اثنان طرف مساهمة لكن إبقاء تعريف و إشارة إبرة،undefine حذف الكل Package، تخويل و حالة.
- حالي صفحة قدرة منطقة قسم “انتظار تنشيط”“Client انتظار تنشيط” و “تشغيل في” ، انتظار مراجعة دفعة وقت فقط عرض مراجعة دفعة حركة عمل.
- `tool.view.cordis` self ربط Plugin + Package؛ نفس Package الأكثر جديد Run بطاقة وحيد احتلال عمل خدمة UI، قديم بطاقة و قد حذف Plugin لديه واضح تراجع تحويل حالة.
- Host/Client Guard رفض import،JSX، لم إعلان Service و غير ممكن استخدام عام؛Service،timer،Slot، مثال صيغة،Tool،handler و رئيسي عنوان تغطية مع Run teardown.
- Package خاص RPC فقط سماح Client→Host بلا ضرر JSON، و رفض قديم قديم `pluginRunId`.
- Inspect list مرة إرجاع Host/Client manifest؛query فقط استدعاء صريح فقط قراءة طريقة،Client استعلام انتظار أول عدد schema-valid نجاح نتيجة أو إلغاء.
- Service/Event Catalog قسم Host/Client توليد و تطبيق أبيض اسم مفرد،`@deprecated` API،Runner ذاته خدمة و `cordis/*` تحكم Event لا نحو نموذج كشف؛Slot query دمج ساكن حالة props و live subtree.
- `cordis_inspect_self` قسم طبقة إرجاع قائمة،Package ملخص و دقيق شفرة المصدر/تشخيص؛`@pluginId` لا مباشر حقن شفرة المصدر كما تحديث إبقاء في نفس Plugin.
- مختلف خطوة تقنية فن فشل،Host handler،Client Guard و React تصيير خطأ إبقاء message/stack و steering owning Agent؛ مستخدم وجه لوح عملية فقط حقن تحت واحد step context.
- System Prompt،Skill،Tool description و Provider/Catalog حسب هذا Note قسم طبقة،Skill غير ممكن استخدام وقت Prompt ما زال كاف بـ توليد الأكثر منخفض حد درجة صحيح تأكيد إضافة.
- متبادل صلة مساحة العمل `pnpm run build` عبر؛ تنفيذ مرحلة مقطع تكملة متساو Host/Client lifecycle، إصدار، مراجعة دفعة،Inspect،Guard،Tool بطاقة و حقيقي تطبيق لقطة تغطية.

## Risks

- **عملية إعادة بدء فقد فقد الكل حركة حالة كائن.** تاريخ Tool بطاقة ما زال في، لكن Registry لا استعادة؛ مستخدم يجب إعادة define.
- **كثير صفحة حالة لا هو قوي متسق نظام.** رقم واحد صالح Client نجاح نتيجة يمكن إيداع current، كل صفحة Client تركيب تحميل و تصيير حالة ما زال ممكن مختلف؛ حالي لا جذب دخول اتصال هوية، قاعدة تحديد شخص عدد أو صفحة تجمع دمج.
- **Client Inspect ممكن طويل مدة pending.** Host حفظ الأكثر قريب manifest، لكن لا يوجد صفحة نجاح تنفيذ Provider وقت لا يستطيع استخدام قديم بيانات زائف تركيب live نتيجة؛ كثير عدد صفحة كل فشل وقت طلب انتظار إلى إلغاء.
- **عبر إصدار تخويل توسيع كبير معلومة مهمة نطاق.** مزدوج ربط سماح نفس Plugin لاحق Package بلا حاجة مجددا مرة مراجعة دفعة؛UI يجب صاف واضح منطقة قسم مفرد مرة و عبر إصدار تخويل.
- **فشل تحديث ممكن إبقاء تحت current إشارة نحو قديم إصدار لكن قديم إصدار لم تشغيل.** current يمثل الأكثر بعد نجاح إصدار، لا يمثل حالي شيء إدارة Run؛UI،Inspect و تلميح يجب معا عرض active،current و next.
- **تلقي حد سياق لا هو أمان صندوق رملي.** Host Service، ملف، أمر، شبكة و Client UI كل هو حقيقي قدرة؛ أبيض اسم مفرد و مراجعة دفعة خفض منخفض خطأ استخدام، لا عزل سيئ معنى شفرة.
- **Catalog،Guard و شفرة المصدر ممكن عائم نقل.** توليد جهاز، أبيض اسم مفرد و owner JSDoc يجب مشترك نفس صيانة؛Guard إخفاء سياسة لا يستطيع إنتاج آخر طقم توقيع.
- **Builtin اعتماد يد عمل إعلان.** React،harness،host،styles و Context طريقة لا يوجد موحد واحد يمكن مسح مدخل، حقن تنفيذ و Provider تعريف يجب وضع في نفس صيانة موضع.
- **Provider إخراج schema حالي سماح مقارنة عرض JSON.** أول إصدار أولوية إتمام Provider كل حق، إدخال تحقق و Host/Client توجيه؛ أكثر ضيق إخراج schema لاحق مجددا استلام ضيق.
- **Host و Client Guard وجود مستو سطر تنفيذ.** اثنان جانب فتح وضع بيئة و Cordis نوع وجه مختلف، حالي إبقاء كل منها تنفيذ؛ عام مشترك قاعدة إطار فقط لديه في قدرة نقص قليل شفرة كما لا إخفاء أمان سياسة وقت مجددا رفع أخذ.
