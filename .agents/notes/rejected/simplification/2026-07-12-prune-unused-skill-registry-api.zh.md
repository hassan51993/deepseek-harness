# Agent Note: قطع قص skill سجل التسجيل في لم استخدام واجهة

Status: rejected — مباشر في وقت التشغيل تسجيل skill هو لـ رقم ثلاثة جهة إضافة إبقاء متعمد توسيع مسار.

[English](2026-07-12-prune-unused-skill-registry-api.md) | العربية

## مشكلة

skill(تقنية قدرة) خدمة تضمين دخول صيغة وقت التشغيل فرعي نظام في،`ctx.skills.register()` لا يوجد أي إنتاج استدعاء جهة. هو جذب دخول واحد إبقاء `runtime` مزود اسم، واحد طقم وقت التشغيل map/rank/source، تكرار سياسة، ذاكرة مؤقتة مفتاح في ثاني عدد revision، مواصفة تحويل منطق،dispose(مورد تحرير) دالة و متبادل ينبغي اختبار——بينما كل قد تسليم skill كل استخدام مزود اتفاق.`SkillSummary.whenToUse` و candidate/definition `path` يتم تحليل و نسخ، لكن لا يوجد أي إنتاج مستهلك قراءة هو جمع: نموذج دليل فقط تصيير name/description، مورد تحميل استخدام `resourceBase`، مزود ذاتي سطر إدارة ذلك تحديد موضع جهاز. متعمد فتح وضع `metadata` نقطة توسيع إبقاء لا حركة.

## رفع سجل

إزالة `SkillRegistry.register()`،`SkillRegistration`، وقت التشغيل زائف مزود و إبقاء اسم قاعدة، وقت التشغيل revision/ذاكرة مؤقتة فرع، و فقط لأجل وقت التشغيل source/rank مواصفة تحويل منطق. حاجة تضمين دخول صيغة skill اختبار تعديل لـ تسجيل واحد صغير نوع حقيقي مزود. إبقاء `providerRevision` بصفة إجراء في اكتشاف عملية epoch، لكن قد إتمام دليل ذاكرة مؤقتة فقط بـ cwd لـ مفتاح: كل مرة مزود تغيير تزامن صاف حذف ذاكرة مؤقتة،await بعد revision مقارنة مقارنة قد قدرة منع توقف إدراج دخول قديم قديم نتيجة. من skill اتفاق و محلي مزود فرعي هذا في إزالة `whenToUse`،`SkillCandidate.path` و `SkillDefinition.path`، معا إبقاء مزود locator/root مسار؛ إبقاء `metadata`،`disableModelInvocation`،`source`،`provider`،`locator` و `resourceBase`، لأن هو جمع يلزم ما هو متعمد فتح وضع توسيع مفردات، يلزم ما هو إنتاج إزالة استهلاك حقل.

تزامن إصلاح حجز skill نظام Agent Note،README،JSDoc، دليل ملف و اختبار.agent(ذكي جسم) أثر مجال توجيه النظام مقطع، أداة مزود و متغير واضح لا في هذا رفع سجل نطاق داخل:[agent أثر مجال مساهمة من اتفاق](../../implemented/architecture/2026-07-08-agent-scope-contexts.zh.md) متعمد سماح في `setup(agentCtx)` خلال عبر agent يملك سياق تسجيل هذا ثلاثة من، لذلك مستودع داخل لا يوجد ثابت أثر مجال تسجيل و لا يستطيع إثبات هو جمع لم يتم استخدام.

## سبق اعتبار بديل خطة

**إبقاء موجه إلى تضمين دخول جهة وقت التشغيل skill تسجيل.** هذا هو قد تنفيذ skill Agent Note في متعمد توفير تزامن مباشر تعريف سهل فائدة واجهة. واحد صغير نوع مزود حزمة تركيب طبقة يمكن في effect يملك دورة الحياة تحت كشف نفسه تضمين دخول بيانات، لكن هو يجب تنفيذ مختلف خطوة `list()`/`get()`، يحمل مزود هوية، و قبول مزود معالجة تكرار بند دلالة. هذا رفع سجل اختيار فقط إبقاء واحد بند موحد واحد مزود مسار، بينما غير صيانة ثاني طقم ترتيب ترتيب، تحقق، ذاكرة مؤقتة بطلان و فحص بحث مسار.

## تحقق استلام معيار

- skill استلام تجميع فقط لديه واحد بند مزود قيادة مسار، قد إتمام ذاكرة مؤقتة فقط بـ cwd لـ مفتاح،revision epoch فقط لأجل جعل إجراء في اكتشاف عملية بطلان؛ إبقاء skill حقل يلزم ما لديه إنتاج قراءة جهة، يلزم ما لديه سجل في سجل متعمد توسيع اتفاق.
- agent أثر مجال توجيه النظام مقطع، متغير، أداة مزود، أداة حراسة حماية، و أصلي نمط و PTC mode تحت structured-output إيداع سلوك إبقاء ثابت.
- نوع فحص، نسبة التغطية، لقطة،doc-sync(وثيقة تزامن بوابة) ،module-graph تحقق، بناء و hygiene الكل عبر.

## ريح خطر

هذا هو مقابل مسبق إصدار skill سجل التسجيل تحرير ترجمة مرئي استلام تقليص. خارجي تحرير مسار صيغة `list()`/`get()` مستهلك سوف فقد ذهاب `whenToUse` توجيه تلميح و candidate/definition `path`؛ قد تسليم نموذج دليل من لم تصيير هو جمع، مورد تحليل إبقاء صريح `resourceBase` إضافة فوق مزود ذاتي لديه لا نفاذ واضح locator، لكن هذه حقل و غير مراقبة قياس انتظار قيمة.skill محلي frontmatter تحليل يجب متابعة إبقاء و تحقق الذي دعم حمل metadata schema، خارجي مزود ما زال يمكن توفير تضمين دخول صيغة، نظام الملفات، بعيد مسار أو أخرى skill مصدر.
