# Agent Note: استخدام node:timers/promises بديل يد كتابة يمكن إلغاء راحة نوم

## مشكلة

ثلاثة عدد حزمة يد كتابة استخدام promise حزمة تركيب تحديد وقت جهاز، بينما `node:timers/promises` داخل وضع وحدة مبكر قد توفير نفس انتظار قدرة؛ أخرى حزمة (`dsh-llm-mock-server` `pause()`،`dsh-lsp-stdio`،`dsh-acp-snapshot`) قد في استخدام هذا داخل وضع وحدة، لذلك هذه يد كتابة فرعي هذا معا أيضا هو واحد موضع متسق صفة نقص فتحة:

- `packages/llm/llm-retry/src/index.ts` `cancellableDelay()`(نحو 14 سطر):`new Promise` + `setTimeout` + يد حركة إضافة و إزالة في توقف مستمع، تحديد وقت جهاز إطلاق وقت resolve لـ `true`، يتم في توقف وقت resolve لـ `false`، فقط في تراجع تجنب انتظار موضع إزالة استهلاك مرة.
- أصل `workflow-worker-thread` host `sleep()`(نحو 7 سطر، في PR #679 في تقييم تقدير):promise حزمة تركيب، قد unref `setTimeout`، استخدام عمل dispose(مورد تحرير) عرض حد وقت فوق حد.
- `packages/terminal/terminal-bash/src/session.ts` `delay()`(نحو 4 سطر): بسيط عنصر promise حزمة تركيب `setTimeout`، لأجل جولة استفسار و تفكيك إزالة انتظار.

## رفع سجل

استخدام `import { setTimeout } from 'node:timers/promises'` استبدال هذا ثلاثة موضع تنفيذ:

- llm-retry:`try { await setTimeout(delayMs, undefined, { signal }); /* retry */ } catch { /* abort → fail */ }`. نقل دخول signal بعد، هذا promise فقط سوف بسبب في توقف خطأ بينما رفض، قد رفع قبل في توقف signal فإن قيام أي رفض؛ سلوك تماما متسق، يشمل في توقف وقت صاف حذف تحديد وقت جهاز. حسب مستودع فارغ catch قاعدة، هذا عدد فارغ `catch` ملاحظة واضح ذلك ابتلاع تحت هو abort رفض.
- workflow-worker-thread:`setTimeout(ms, undefined, { ref: false })`، دلالة تماما انتظار قيمة، يشمل لن يجعل حدث حلقة إبقاء تخزين نشط.
- terminal-bash:`import { setTimeout as delay } from 'node:timers/promises'`، توقيع تماما نفسه، استدعاء نقطة بلا حاجة تعديل.

لا يوجد مخصص تابع اختبار ثابت هذه مساعد مساعدة دالة ذاته؛ كل حزمة سلوك اختبار طقم عنصر متابعة عبر.

## سبق اعتبار بديل خطة

- **`p-timeout`/`p-defer` واحد صنف حزمة.** غير مقبول: داخل وضع وحدة تماما جيد دقيق تغطية هذه استدعاء نقطة؛ لـ واحد سطر await جذب دخول خارجي حزمة هو سالب استلام فائدة.
- **صيانة حمل الآن حالة.** غير مقبول، لكن إدارة من مقارنة ضعيف: صار هذا تأكيد فعلي جدا صغير، لكن مستودع أخرى أرض جهة قد في استخدام هذا واحد داخل وضع معتاد استخدام قاعدة، بينما نفس داخل وضع قدرة وجود اثنان عدد يد كتابة تغيير جسم، حينئذ سوف استدعاء قدوم رقم ثلاثة عدد.

## تحقق استلام معيار

- هذا ثلاثة عدد حزمة كل لم يعد كل منها تعريف promise حزمة تركيب `setTimeout` مساعد مساعدة دالة، بينما هو كل من `node:timers/promises` استيراد.
- `llm-retry`،`workflow-worker-thread` و `terminal-bash` اختبار طقم عنصر أصل مثال عبر (سلوك انتظار قيمة).

## ريح خطر

أساس هذا لا يوجد ريح خطر: لا تعلق و نموذج مرئي إخراج، لا يوجد منصة اعتبار اعتبار، أيضا لا إضافة جديدة اعتماد.llm-retry تعديل كتابة يأخذ واحد إرجاع قيمة منطقية مساعد مساعدة دالة تغيير صار try/catch تحكم تدفق، هذا هو واحد بند نطاق جزء يمكن قراءة صفة حكم قطع، من فعلي تطبيق PR(Pull Request) قطع كمية.
