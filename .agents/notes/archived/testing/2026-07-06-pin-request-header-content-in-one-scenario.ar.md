# Agent Note: في مفرد عدد لقطة مشهد في ثابت طلب رأس محتوى

Status: implemented
Archived: 2026-07-26

[English](2026-07-06-pin-request-header-content-in-one-scenario.md) | العربية

## مشكلة

واحد ACP(Agent Client Protocol) لقطة اختبار طقم عنصر حاجة إثبات كل `request/header` في فعلي إرسال تركيب توجيه النظام و أداة schema قائمة، لكن إذا في كل `session.jsonl` في تكرار هذه محتوى، مرة نص التوجيه أو schema تحرير حينئذ سوف تعديل كتابة عدد عشرة بند ضخم كبير مفرد سطر JSON سجل. إبقاء واحد نسخة أصلي header يمكن تجنب تجنب تكرار، لكن نص التوجيه مراجعة تجربة ما زال جدا فرق: سطر نص يتم JSON تحويل معنى إلى واحد سطر في، و عدد ألف محرف أداة schema خلط في واحد بدء.

## قرار

كل نوع طلب رأس تركيب صنف آخر تماما جيد لديه واحد مشهد علامة لـ `pinsHeader`. ذلك دليل حسب مراجعة صيغة تفكيك قسم ثابت محتوى:`system-prompt.expected.md` بـ عادي Markdown يتضمن مواصفة تحويل كامل نص التوجيه تسلسل؛`tool-schemas.expected.json` بـ بنية تحويل JSON يتضمن مقابل كامل schema تسلسل؛`session.jsonl` إبقاء config،reason و كل نموذج مرئي بادئة، معا سوف `header.system` و `header.tools` تخزين لـ `"{{system}}"` / `"{{tools}}"`. أخرى كل نسخة JSONL كل استخدام نفسه نص التوجيه و أداة token، و نفس مثال سوف جلسة بادئة محتوى token تحويل. ثابت آلية يقع في [`dsh-acp-snapshot`](../../../../packages/support/acp-snapshot/README.md) ، ذلك طقم عنصر factory قوي صنع كل نوع صنف آخر تماما جيد لديه واحد ثابت مشهد.

صاف `scrubSystemPrompts` و `scrubToolSchemas` مواصفة تحويل جهاز سوف قسم آخر سوف كل قد تخزين كامل طلب رأس token تحويل.`scrubRequestHeaders` أيضا سوف لـ غير ثابت مشهد يأخذ جلسة بادئة محتوى token تحويل، معا إبقاء طلب رأس عدد كمية، حقل وجود،config،reason و بادئة رسالة عدد كمية. سجل و تحديث جديد كتابة عودة سوف في كتابة JSONL قبل تطبيق ملائم عند تنظيف، و أصل حسب مواصفة تحويل فوري كامل طلب رأس تسلسل إعادة توليد اثنان عدد sidecar، لذلك اثنان بند مسار كل لا يمكن يأخذ كبير مقطع نص التوجيه/schema إعادة جذب دخول JSONL، أيضا لن إبقاء تحت قديم قديم مراجعة ناتج.

حراسة حماية جعل هذا نوع تفكيك قسم قدرة كاف ذاتي أنا قوي صنع. في مغناطيس قرص فوق، كل `session*.jsonl` كل هو نص التوجيه و schema تنظيف جهاز ثابت نقطة؛ فقط لديه غير ثابت fixture(اختبار قبل وضع بيانات) يجب هو كامل طلب رأس تنظيف ثابت نقطة؛ اثنان عدد sidecar تماما جيد يقع في ثابت fixture جانب، و اعتماد مواصفة، بـ تبديل سطر رمز ربط ذيل صيغة؛ كل نوع صنف آخر كل لديه واحد ثابت مشهد. في فوري تشغيل في، من أب بند،spawn فرعي بند،fork فرعي بند، ابتدائي طلب، استعادة أو نسخة داخل تغير إنتاج كل `request/header`، كل يجب في سهل تغيير قيمة مواصفة تحويل بعد و إعادة بناء صنف آخر تسلسل مطابقة. طلب رأس إذا لا يوجد نص نص التوجيه، لا يوجد عدد مجموعة قيمة أداة قائمة، أو تجاوز مرور ثابت مشهد إعلان تغيير طلب رأس عدد كمية، حينئذ سوف صدى مضيء فشل.

واحد ثابت مشهد تغطية كامل طقم عنصر، لأن كل جلسة (parent،spawn فرعي جلسة،fork فرعي جلسة) تركيب خروج أداة قائمة تماما نفسه، نص التوجيه حذف cwd خارج تماما نفسه، بينما متسق صفة حراسة حماية سوف في هذا واحد قبل رفع لم يعد صار قيام وقت قيام أي جعل طقم عنصر فشل. إذا header تركيب سوف قدوم في تصميم فوق تغيير لـ جلسة متبادل صلة (مثال مثل تلقي حد subagent أداة تجميع) ، ذلك ما قسم اختلاف شكل سوف نيل نيل ذاتي ذات ثابت مشهد.

## سبق اعتبار بديل خطة

- **كل مرة تغيير إعادة تسجيل صنع أو يد حركة تحرير كل fixture**: إبقاء دقيق header، لكن سلوك فرق مختلف يتم تكرار نص التوجيه و schema محتوى إغراق لا.
- **فقط في مقارنة مقارنة وقت scrub،fixture إبقاء أصلي محتوى**: مقارنة مقارنة قدرة عبر، لكن قد إيداع fixture إبقاء حال قديم قديم تكرار محتوى، تحت مرة تسجيل صنع وقت سوف كامل جسم إعادة كتابة. تخزين token صدق فعلي أرض جدول واضح كل JSONL لا يوجد ثابت ماذا.
- **الكل scrub، لا فعل أي ثابت**: فقد فقد تركيب header فعلي إرسال محتوى (نص التوجيه تجميع، قد تسجيل أداة ترتيب، كامل schema) وحيد طرف إلى طرف سجل. توليد أداة دليل فقط منعزل قيام أرض سجل كل أداة؛ فقط لديه حقيقي fixture عندئذ قدرة ثابت تركيب بعد كامل تجميع دمج.
- **سوف كامل ثابت محتوى الكل إبقاء في JSONL في**: إزالة حذف طقم عنصر نطاق تكرار، لكن نص التوجيه و schema تغيير ما زال هو واحد سطر تحويل معنى نص.Markdown و بنية تحويل JSON لـ كل نوع محتوى توفير ذلك ذاتي لكن مراجعة صيغة، معا لا تقليل ضعيف إعادة بناء header تأكيد.
- **استلام ضيق جلسة سجل ذاته (سجل محتوى digest، يأخذ طلب رأس تخزين إلى أخرى موضع)**——مخالفة عكس يمكن إعادة بناء صفة عقد نحو: منتج سجل يجب تدريجي bit تكرار الآن كل طلب ([يمكن إعادة بناء طلب Agent Note(agent قرار سجل)](../architecture/2026-07-05-reconstructable-requests.md)). طلب رأس جسم تراكم هو اختبار ناتج مشكلة، ينبغي في اختبار مواصفة تحويل في حل قرار؛ فوري سجل إبقاء ثابت.

## تحقق

هذا طقم عنصر إبرة مقابل تفكيك قسم بعد ثابت محتوى إعادة تشغيل كل مشهد. وحدة نسبة التغطية سوف تغطية مستقل و كامل تنظيف جهاز، اثنان نوع كامل طلب رأس sidecar صيغة، سجل/تحديث جديد إعادة توليد، مواصفة تحويل نص التوجيه/schema رفع أخذ، ثابت نقطة قوي صنع، مطلوب ملف مقابل تسمية صفة، إعادة بناء طلب رأس متسق صفة، و تغيير طلب رأس عدد كمية رفض.

## عاقبة

توجيه النظام تغيير في كل تلقي أثر تركيب صنف آخر في إنتاج واحد موجه إلى سطر Markdown diff؛ أداة وصف تغيير في كل صنف آخر في إنتاج واحد بنية تحويل JSON diff؛ عادي سلوك fixture لا تلقي أثر. جلسة fixture مقابل حذف محتوى عرض token، وقت التشغيل متسق صفة حراسة حماية جعل كل تفكيك قسم ثابت مشهد مقابل ذلك صنف آخر داخل كل جلسة أداة لديه مرجعي صفة. كل ثابت مشهد يحمل اثنان عدد توليد، تبديل سطر مواصفة تحويل sidecar ملف.
