# Agent Note: مطلوب Python وقت التشغيل سحب أخذ طلب تحقق

Status: implemented
Archived: 2026-08-23

[English](2026-08-12-required-python-runtime-pull-request-ci.md) | العربية

## مشكلة

عادي سحب أخذ طلب CI سوف إبرة مقابل fake وقت التشغيل مقابل طرف تنفيذ كامل Python SDK pytest طقم عنصر، بينما Node لقطة استخدام مختلف عميل و مسبق مدة إخراج. حقيقي Python عميل، تحزيم بعد JSON-RPC يمكن تنفيذ ملف،exe مخصص استخدام لقطة، إصدار شكل wheel حزمة و جاف صاف تثبيت فقط في اختياري مفرد ملف يمكن تنفيذ برنامج سير العمل أو Python إصدار سير العمل في تجميع دمج. لذلك، وقت التشغيل حدث أو إغلاق حزمة حدوث تغير بعد، قديم قديم Python إسقاط أو ضرر تالف wheel حزمة مسار ما زال ممكن دمج، مباشر إلى لاحق لديه شخص بناء Python إصدار مرشح إصدار وقت عندئذ فشل.

## قرار

كل سحب أخذ طلب كل في [CI](../../../../.github/workflows/ci.yml) في تشغيل مطلوب `python-runtime` عمل عمل. هذا عمل عمل لا استخدام مسار مرور ترشيح، استدعاء مشترك[مفرد ملف يمكن تنفيذ برنامج بناء جهاز](../../../../.github/workflows/build-exe-for-python-sdk.yml) بناء `node24-linux-x64`، و مشاركة و `all checks passed`. يتم استدعاء سير العمل سوف بناء حقيقي يمكن تنفيذ ملف، تشغيل الكل بلا مفتاح Python كامل جولة و مباشر اثنان دخول صنع مشهد (يشمل اثنان نسخة فحص دخول لقطة) ، بناء SDK و وقت التشغيل wheel حزمة، سوف اثنان من تثبيت دخول جاف صاف وهمي محاكاة بيئة، فحص يمكن تنفيذ ملف و أصلي addon GLIBC اعتماد، و في manylinux 2.28 حاوية في تشغيل قد تثبيت wheel حزمة.

مطلوب عمل عمل و [Python إصدار سير العمل](../process/2026-08-11-python-publication-workflow.zh.md) مشترك استخدام نفس بناء جهاز. ذلك تزامن مفتاح يتضمن استدعاء جهة سير العمل، لذلك نفس ref فوق مطلوب CI و صريح كامل إصدار تحقق لن متبادل متبادل إلغاء. كامل linux-x64،linux-arm64 و macos-arm64 مستطيل دفعة ما زال يخص إصدار تحقق: منصة غير متصل وقت التشغيل،SDK و لقطة سلوك فقط حاجة واحد منع قطع دمج أصلي تحميل جسم، بينما هيكل بنية متبادل صلة يمكن تنفيذ ملف،addon،wheel حزمة وسم و نشر هدف سلوك في إصدار قبل ما زال حاجة الكل إصدار هدف تحقق.

دخول مرحلة exe لقطة سوف في مقارنة مقارنة قبل مواصفة تحويل لا نفاذ واضح جلسة، رسالة،subagent و سير العمل تشغيل معرف رمز. لذلك، إضافة جديدة حفظ دائم سير العمل حدث سوف تغيير مرور مرور مراجعة قراءة مسبق مدة إخراج، لكن لن يأخذ مع آلة تشغيل معرف رمز كتابة منها. أقصى بسيط مشهد[نموذج مرئي لقطة](2026-08-13-python-minimal-model-visible-snapshot.zh.md) تغطية هذا نسخة لقطة الذي احتلال موضع تحويل قد تجميع توجيه النظام، أداة schema و رسالة قائمة.

## سبق اعتبار بديل خطة

**كل سحب أخذ طلب كل تشغيل كامل أصلي مستطيل دفعة.** هذا سوف في ثلاثة عدد عمل عمل في تكرار منصة غير متصل كامل جولة و لقطة سلوك، و يجعل كل بند تعديل كل إزالة استهلاك ARM64 Linux و macOS سعة كمية.Python إصدار سير العمل في حاجة الكل ثلاثة عدد ناتج حلقة عقدة إبقاء هذا جزء دليل.

**إبرة مقابل تطوير استخدام Node تحميل جسم تشغيل لقطة.** هذا يمكن التقاط بروتوكول و حدث إسقاط عائم نقل، لكن لا يستطيع إثبات pkg تجميع، نشر بعد وقت التشغيل إغلاق حزمة، أصلي addon مؤقت تخزين،wheel حزمة بناء، دقيق اعتماد إصدار و جاف صاف تثبيت. مطلوب Linux exe مسار مباشر تغطية إصدار مسار.

**عبر مسار مرور ترشيح أو وسم اختيار هذا عمل عمل.** Python سلوك اعتماد `python/` خارج مشترك agent، جلسة، سير العمل،subagent، إضافة تحميل و تحزيم شفرة. لا كامل اعتماد مرور ترشيح سوف مجددا مرة صنع صار تأخير متأخر اكتشاف، وسم فإن سوف يجعل دليل إبقاء اختياري.

## عاقبة

كل سحب أخذ طلب كل سوف تحمل تحمل مرة معيار حمل إدارة Linux exe و wheel حزمة بناء،`all checks passed` أيضا سوف انتظار هذا عمل عمل. هذا جعل رقم واحد جهة Python توزيع يصبح دمج وقت اتفاق، و إعادة استخدام إصدار تنفيذ، بينما لا صيانة واحد بند أكثر صغير بديل خط الإنتاج.

مفرد واحد مطلوب هيكل بنية لا يمكن فحص قياس macOS أو Linux ARM64 تحزيم ارتداد. إصدار قبل ما زال يجب تنفيذ صريح كامل إصدار تحقق، و من هذا تحقق مسؤول هذه منصة خاص تحديد نتيجة.
