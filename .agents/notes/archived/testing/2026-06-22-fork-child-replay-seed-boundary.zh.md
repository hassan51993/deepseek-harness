# Agent Note: حفظ دائم seed حد بـ تأكيد حفظ fork فرعي جلسة إعادة تشغيل صحيح تأكيد توجيه

Status: implemented
Archived: 2026-09-04

[English](2026-06-22-fork-child-replay-seed-boundary.md) | العربية

## مشكلة

[تدريجي جلسة لقطة إعادة تشغيل Agent Note](2026-06-22-subagent-snapshot-replay.zh.md) جعل لقطة طبقة قدرة كاف جدول بلوغ تضمين طقم agent(ذكي جسم) شكل حالة: واحد أب بند إضافة فوق كل عملية داخل subagent واحد نسخة سجل سجل، كل نسخة سجل كل حسب استدعاء جلسة بصفة مفتاح، بـ مستقل نص برمجي إعادة تشغيل. هو سبق إشارة خروج (§ نطاق، الأكثر بعد واحد مشروع رمز رقم) ،fork لقطة «فقط هو لم قدوم جدا سعة سهل إضافة واحد بند، و غير مفتاح تحكم نقص فتحة». هذا واحد حكم قطع مقابل fork فرعي جلسة بينما قول هو خطأ——مشكلة لا في مفتاح تحكم، بينما في*نص برمجي إرسال توليد*.

subagent نص برمجي من [`deriveReplayScript`](../../../../packages/test-support/llm-replay) من قد تسجيل صنع Session log دفع توجيه: هو يأخذ كل حمل دائم `assistant/message` أو `assistant/attempt` settlement توسيع لـ كل مرة `stream()` استدعاء مقابل واحد بند replay entry. مقابل **spawn** فرعي Session بينما قول هذا هو صحيح تأكيد، لأن ذلك log فقط يتضمن ذاته نموذج استدعاء.

**fork** فرعي Session مختلف.fork backend استخدام*أب log واحد مقطع مستو توازن قد إتمام turn بادئة*([`dsh-subagent-in-process-driver`](../../../../packages/subagent/subagent-in-process-driver)) بث نوع فرعي Session، هذا seed سوف يصبح فرعي Session حفظ دائم `log`(`Session` بنية صنع دالة يأخذ seed نسخ دخول `this.log`). لذلك fork فرعي Session `.jsonl` بـ**أب Session** event فتح رأس——يشمل ذلك Assistant settlement——بعد عندئذ هو فرعي Session ذاتي ذات turn.

من fork فرعي جلسة كامل سجل دفع توجيه نص برمجي، سوف يأخذ**أب جلسة**قد تسجيل صنع استجابة عند عمل**فرعي جلسة**نموذج استدعاء قدوم إعادة تشغيل: فعلي تشغيل fork فرعي جلسة رقم مرة استدعاء `stream()` وقت، سوف استلام إلى أب جلسة رقم واحد مقطع قسم قطعة تسلسل بينما غير ذاته. كل قد تسجيل صنع مشهد كل استخدام spawn، الذي بـ هذا من لم إطلاق——لكن fork لقطة سوف ساكن صامت أرض خطأ توجيه، تماما جيد يخص لقطة طبقة وجود معنى معنى الذي يلزم التقاط ذلك صنف bug.

## قرار

سجل جلسة**وراثة**بادئة انتهاء موضع، سوف ذلك حفظ دائم، و يجعل إعادة تشغيل harness فقط من فرعي جلسة**ذاته**حدث دفع توجيه نص برمجي.

### 1. جدول نظام metadata و متن يملك دقيق cut

`SessionHeader.isSeeded` سجل Session هل أداة لديه وراثة جدول نظام، بينما لا نحو فقط header reader كشف متن جلوس علامة. دقيق قبل توجيه حدث عدد كمية هو مفرد وحيد صنف لوحة تحويل لـ `SessionLogOffset` `inheritedEventCount`؛fork معا توفير `isSeeded: true` و نسخ بادئة طويل درجة، كل جديد spawn فإن توفير unseeded header و صفر cut. هذا cut مرور `CreateSessionOptions`،`CreateAgentOptions`، حفظ دائم inspection و استعادة بعد Session حالة نقل تمرير.

`inheritedEventCount` هو**صريح**، أبدا من `seed.length` دفع قطع. استعادة/تحميل وقت استخدام جلسة كامل قد تخزين سجل بصفة seed، هذا وقت `seed.length` هو كل طويل بينما غير أصلي حد——استعادة مسار تعديل لـ في logical header خارج نقل تمرير حل رمز بعد cut.

### 2. JSONL كامل نحو إرجاع

v2 JSONL header يحمل `isSeeded`، بينما `session/end-seed { inherited: true }` سوف في متن في علامة دقيق cut؛ حل رمز استخدام الأكثر بعد واحد tagged marker. تجميد ربط v0 header لـ إبقاء بايت توافق بينما متابعة يحمل اختياري عدد قيمة `seedLength`، ذلك codec سوف يأخذ هذا تاريخ حقل تحويل لـ نفسه منطق قيمة مقابل.

### 3. إعادة تشغيل من حد بعد دفع توجيه فرعي جلسة نص برمجي

`dsh-llm-replay` عبر ساكن حالة صيغة catalog تحليل اختيار تحديد generation، و إبقاء حل رمز بعد `inheritedEventCount`.`loadSessionScripts` من `fixture.events.slice(inheritedEventCount)` دفع توجيه فرعي Session entry——أي boundary و بعد event، أيضا حينئذ هو فرعي Session ذاتي ذات نموذج استدعاء. مقابل spawn فرعي Session بينما قول cut لـ 0، لذلك هذا عملية لـ فارغ عملية.

هذا سد تكملة توجيه صحيح تأكيد صفة نقص فتحة، اثنان عدد قد تسجيل صنع fork مشهد مقابل ذلك إجراء طرف إلى طرف تحقق——رؤية[سجل fork و خلط دمج spawn+fork لقطة مشهد](../../archived/testing/2026-06-22-fork-snapshot-scenarios.md).

## سبق اعتبار بديل خطة

- **في `llm-replay` في بدء إرسال صيغة دفع توجيه حد**(بث نوع بادئة هو وصل متابعة أب حدث، توقف في فرعي جلسة رقم واحد بند `user/message` قبل الأكثر بعد واحد `turn/end`). مرفوض: في اختبار harness في استخدام هش ضعيف بدء إرسال صيغة إعادة دفع توجيه واحد إنتاج من قد معرفة طريق واقع. في مصدر رأس (fork خلفية) حفظ دائم حد، هو «في حزمة حد موضع صريح أفضل في خفي صيغة» هذا بند قاعدة عبر تجاوز حفظ دائم حد تطبيق——فرعي جلسة fixture(اختبار قبل وضع بيانات) قراءة من دائم بعيد لا حاجة إعادة بناء وراثة في أي داخل انتهاء.

## عاقبة

- جدول نظام bit أفقي عبر logical Session metadata، دقيق cut فإن فقط أفقي عبر يحتوي متن core، حفظ دائم،query و replay قيمة؛v0 شيء إدارة header إبقاء ثابت.
- spawn إعادة تشغيل ثابت (cut لـ 0).fork إعادة تشغيل سوف فرعي جلسة توجيه إلى ذاته نص برمجي؛ من `llm-replay` اختبار في واحد ارتداد حالة استخدام تغطية (واحد فرعي جلسة fixture، ذلك بث نوع بادئة يتضمن أب جلسة قسم قطعة——دفع توجيه خروج فرعي جلسة نص برمجي يجب ترتيب حذف هو، لا فعل slice وقت هذا حالة استخدام سوف فشل) ، و عبر مشترك coordinator اتفاق تنفيذ JSONL حفظ دائم نحو إرجاع اختبار.
