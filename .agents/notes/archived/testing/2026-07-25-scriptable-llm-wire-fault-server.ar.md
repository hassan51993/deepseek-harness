# Agent Note: يمكن نص برمجي تحكم LLM بروتوكول طبقة لذا عائق خادم

Status: implemented
Archived: 2026-09-04

[English](2026-07-25-scriptable-llm-wire-fault-server.md) | العربية

## مشكلة

مهايئ اختبار وحدة استخدام محلي HTTP خادم مقابل كل صنف مزود لذا عائق تدريجي واحد تصنيف، إعادة محاولة اختبار فإن استخدام عملية داخل نص برمجي تحويل `LlmAdapter` إثبات قد إغلاق خطوة استعادة قدرة. هذا اثنان عدد حد كل لا يمكن توفير يمكن إعادة استخدام خادم، بـ سهل معا تشغيل تسليم إصدار HTTP مهايئ،agent loop(ذكي جسم حلقة) و إعادة محاولة سياسة؛ تطوير من أيضا لا يمكن فقط تعديل قائم تطبيق base URL و API key، حينئذ يجعل تطبيق اتصال إلى تحديد صفة نقل لذا عائق.

اتصال تعرض رفض، أول عدد حدث قبل اتصال يتم إعادة وضع، لم استلام إلى `[DONE]` أي صحيح معتاد EOF، دمج قاعدة لكن بلا محتوى إتمام، و إخراج جزء محتوى بعد اتصال يتم إعادة وضع، سوف إنتاج مختلف مهايئ و استعادة نتيجة. يأخذ هو جمع موحد واحد نظر لـ عادي mock لذا عائق، سوف إخفاء غطاء مزود حد هل إبقاء هذه منطقة آخر، و فشل طلب قسم قطعة هل تأكيد فعلي لا يوجد دخول قد إيداع نموذج تاريخ.

## قرار

`@deepseek-ai/dsh-llm-mock-server` هو واحد خاص دعم حمل حزمة، توفير يمكن استيراد Node HTTP خادم. مستودع داخل `pnpm run mock:llm` شفرة المصدر مدخل توفير واحد لأجل يد حركة لذا عائق حقن مستقل عملية؛ هذا حزمة لا عام يمكن تثبيت اثنان دخول صنع أمر. هو قبول توافق OpenAI أصل مسار و `/v1` chat-completions مسار، تحقق اختياري bearer token، التقاط طلب، و مقابل كل قد قبول طلب إزالة استهلاك واحد صريح سلوك. نص برمجي استهلاك كل وقت سوف واضح تقرير خطأ؛ فقط لديه ضبط `repeatLast` عندئذ سوف تكرار الأكثر بعد واحد سلوك.

طلب سلوك تغطية socket إعادة وضع، إرسال header بعد قطع فتح، إرسال جزء محتوى بعد قطع فتح، توقف ركود، دمج قاعدة فارغ إتمام، صحيح معتاد إغلاق لكن يتم قطع قطع تدفق، شاذ شكل payload، قاموس نوع HTTP لذا عائق، كامل نص/دفع إدارة/أداة استدعاء استجابة، بطيء سرعة تدفق صيغة إخراج و بلوغ إلى token حد أعلى إتمام. حق صحيح `connection_refused` من CLI(أمر سطر واجهة) مستمع دورة الحياة مرحلة مقطع تنفيذ، لأن قد ربط طرف فتحة طلب معالج لا يمكن رفض ذاته TCP اتصال.

نص برمجي بند `random` سوف لـ كل طلب إعادة تنفيذ مرة إضافة حق اختيار. خادم عام و سجل ذلك بلا رمز رقم 32 موضع seed، سماح استدعاء جهة توفير متبادل مقابل حق إعادة، و داخل وضع واحد طقم انحراف إعادة نجاح نتيجة ضغط قوة اختبار إعداد، سوف نقل، بروتوكول، مزود، مهلة و دلالة فارغ نتيجة خلط دمج في واحد بدء. هذا إعداد لأجل توفير يمكن ضبط اختبار ضغط قوة، و غير مقابل إنتاج أمر لذا حدوث تردد معدل تقدير حساب؛`connection_refused` ما زال لا دخول طلب درجة مع آلة حوض.

خادم فقط تقرير إبلاغ بروتوكول طبقة واقع، لا حكم قطع هل يمكن إعادة محاولة. حقيقي تركيب اختبار يجعل طلب اعتماد مرة مرور مرور `dsh-llm-deepseek`،`dsh-agent-loop` و `dsh-llm-retry`: في قائم افتراضي سياسة تحت، اتصال تعرض رفض، صلب قطع فتح، جزء إخراج بعد إعادة وضع، فارغ خامل مهلة و دمج قاعدة بلا محتوى إتمام متساو يمكن استعادة؛ صحيح معتاد إغلاق جزء إخراج EOF ما زال عودة صنف لـ `STREAM_CLOSED`، افتراضي لا إعادة محاولة. هذا حزمة لن تغيير هذه سياسة.

## تحقق

حزمة اختبار تغطية كل طلب سلوك، عبر قسم قطعة UTF-8 طلب حل رمز، لا إزالة استهلاك نص برمجي HTTP تحقق، نص برمجي استهلاك كل و تكرار، توقف ركود اتصال تنظيف،CLI تحليل و تأخير متأخر حد،IPv6 base URL، مع آلة seed يمكن تكرار الآن صفة، حق إعادة تحقق، مفرد نتيجة بعيد قياس، دورة الحياة تنظيف، و تدريجي ملف نسبة التغطية بوابة تحت إعداد طقم ثابت صيغة إضافة. إعادة محاولة تجميع صار طقم عنصر عبر حقيقي HTTP/SSE(Server-Sent Events) مهايئ، تحقق دقيق تأكيد طلب مرة عدد، حمل تحرير رقم إعادة محاولة خطوة، طلب جسم تماما متسق، فشل جزء قسم قطعة لن تسرب تسرب، دلالة فارغ نتيجة استعادة، صحيح معتاد EOF تصنيف، مهلة استعادة، مستمع تأخير متأخر بدء بعد من حقيقي اتصال تعرض رفض في استعادة، و محدود إعادة محاولة استهلاك كل.

## سبق اعتبار بديل خطة

**استخدام Python تنفيذ خادم**: غير مقبول.Node معيار HTTP و socket API كاف بـ كشف كل الذي يحتاج لذا عائق، بينما TypeScript يمكن يجعل خادم،CLI محلل، اختبار، حزمة بناء،lint و نسبة التغطية الكل إبقاء في مستودع قائم أداة سلسلة في. جذب دخول ثاني طقم وقت التشغيل سوف زيادة بيئة و عملية فرعية اعتماد، لكن لا يستطيع زيادة قوي بروتوكول عزل.

**في مهايئ اختبار في متابعة استخدام كل منها مستقل داخل ربط mock خادم**: غير مقبول. هذه fixture(اختبار قبل وضع بيانات) لا يمكن بصفة مستقل خادم بدء و توفير قائم تطبيق اتصال، أيضا سوف يجعل مختلف اختبار طقم عنصر تكرار تنفيذ سلوك تحرير ترتيب، مع آلة تحويل، بعيد قياس و اتصال تنظيف. دعم حمل حزمة يجعل اختبار مشترك نفس طقم تنفيذ، أيضا لن سوف ذلك رفع رفع لـ منتج API.

**فقط استخدام عملية داخل `LlmAdapter` mock**: غير مقبول. هو سوف التفاف مرور fetch،HTTP حالة و header تحليل،SSE قسم لقطة،socket إنهاء و مهايئ فارغ خامل نظر باب كلب، بينما هذا صحيح هو هذا طقم اختبار أساس أساس ضبط تطبيق يلزم تغطية حد.

**عام يمكن تثبيت workspace اثنان دخول صنع أمر**: غير مقبول.pnpm سوف في مستودع بناء ناتج وجود قبل رابط اعتماد اثنان دخول صنع أمر، من بينما يجعل جاف صاف تثبيت و فقط توفير اختبار ناتج إنتاج اقتران دمج. مستودع داخل شفرة المصدر أمر دعم حمل نفسه يد حركة لذا عائق حقن، بينما لن إضافة جديدة حزمة تثبيت واجهة.

**مع خادم واحد بدء تعديل افتراضي إعادة محاولة سياسة**: غير مقبول. خادم لأجل كشف عرض قائم دلالة، بينما غير قرار سياسة. هل سوف استعادة قدرة توسيع إلى `STREAM_CLOSED`، حاجة مفرد وحيد قرار، و حق توازن صار هذا، تأخير متأخر و تكرار توليد ريح خطر.

## عاقبة

تطوير من فقط يحتاج تعديل مزود URL/key إعداد يكفي تكرار الآن لذا عائق تسلسل؛ تلقائي تحويل اختبار فإن يمكن عبر صريح نص برمجي و seed، يجعل socket طبقة لذا عائق إبقاء تحديد صفة. نفس طقم بروتوكول fixture الآن يمكن كشف صلب إعادة وضع، صحيح معتاد قطع قطع و استعادة بعد فارغ إتمام بين فرق مختلف، بينما لن تجميع وصل كثير مرة محاولة تجربة محتوى أو تعديل نموذج تاريخ.

خادم إضافة جديدة واحد خاص دعم حمل حزمة و واحد طقم سلوك مفردات، اثنان من يجب معا توافق مباشر اختبار و مستودع داخل CLI عرض مثال. حسب طلب وصول ترتيب تنفيذ نص برمجي متعمد من كل عميل مشترك؛ مع آلة نمط قيمة افتراضية بديل جدول ضغط قوة اختبار حق إعادة، بينما غير فعلي تشغيل قاعدة قاعدة؛ دقيق نموذج محاكاة اتصال تعرض رفض وقت، حاجة يجعل عميل محاولة تجربة و استماع بدء قبل وقت منطقة بين تنسيق ضبط متسق.
