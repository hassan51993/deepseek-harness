# Agent Note: Python أقصى بسيط تركيب نموذج مرئي لقطة

Status: implemented
Archived: 2026-09-04

[English](2026-08-13-python-minimal-model-visible-snapshot.md) | العربية

## مشكلة

Python عبر طريق حاجة دقيق سجل مستقل أقصى بسيط profile فعلي عرض إعطاء نموذج محتوى. وظيفة صفة أداة تأكيد يمكن إثبات تنفيذ، لكن لا يمكن اكتشاف إضافة جديدة نظام قسم مقطع، أداة وصف أو user زاوية لون سياق رسالة؛ بينما دخول مرحلة يمكن تنفيذ ملف لقطة سوف يأخذ كل طلب رأس في قد تجميع توجيه النظام تبديل صار احتلال موضع رمز، و يأخذ كل أداة schema تبديل صار ذلك اسم.

## قرار

[تحزيم وقت التشغيل خطر دخان اختبار](../../../../scripts/smoke-python-runtime.py) `sdk-minimal` مشهد سوف بدء مع مرفق profile، و تسجيل صنع `scripts/snapshots/python-sdk-single-exe/minimal/model-visible.json`: مقابل هذا عودة دمج كل نموذج طلب، تدريجي حرف سجل مقابل خارج عام نشر أداة schema و رسالة قائمة.system و user رسالة إبقاء كل نص، فقط سوف مشهد مؤقت دليل استبدال لـ احتلال موضع رمز؛assistant و tool رسالة فقط إبقاء استدعاء معرف، لأن هو جمع PTY و نظام الملفات نص في كل إعادة تشغيل منصة فوق و لا نفسه. هذا profile حذف حركة حالة وقت التشغيل سياق، لذلك هو إرسال خروج كل بند رسالة كل سوف مشاركة و مقارنة مقابل.

أقصى بسيط مشهد أداة و توجيه النظام من لقطة يملك، بينما لا هو من mock نموذج داخل ربط تأكيد؛ لقطة سوف إعطاء خروج ذلك كامل فرق مختلف. لقطة مقارنة مقابل بـ دليل و ملف تجميع دمج لـ معامل، لذلك `minimal` و `advanced` اثنان نسخة مدة نظر إخراج مشترك استخدام واحد طقم تنفيذ، كما `--update-snapshots` قبول `sdk-minimal`.

## سبق اعتبار بديل خطة

**مثل دخول مرحلة مشهد ذلك مثال مقابل أقصى بسيط جلسة سجل فعل لقطة.** أقصى بسيط عودة دمج قيادة حقيقي PTY و تحرير جهاز، حفظ دائم أداة نتيجة حمل لديه منصة متبادل صلة نص. مدة نظر إخراج سوف بسبب و نموذج مرئي تجميع غير متصل سبب تغيير أحمر؛ بينما يأخذ هذه نص عودة واحد تحويل إسقاط بعد، سجل الذي تحمل تحميل محتوى أيضا حينئذ الذي باق بلا بضعة.

**توسيع mock نموذج في داخل ربط تأكيد.** كل إضافة جديدة واحد بند نموذج مرئي مساهمة كل يلزم مجددا يد كتابة واحد بند مدة نظر، كما فشل فقط سوف إشارة خروج واحد موضع لا مطابقة بينما غير كامل وجه. أداة وصف أيضا سوف من تركيب نسخ دخول نص برمجي، شكل صار تكرار.

**اعتماد TypeScript SDK لقطة.** ذلك `persistent-tools` مشهد عبر إعادة وضع نموذج استجابة و source أو `lib` وقت التشغيل ثابت واحد طقم متبادل يشبه مزدوج أداة تركيب، كما يقع في آخر عدد مطلوب مهمة في. هو لا يمكن جسم الآن قد نشر يمكن تنفيذ ملف مع مرفق profile لـ Python استدعاء جهة تجميع خروج ماذا.

## عاقبة

أقصى بسيط تركيب نموذج مرئي وجه تعديل——نظام قسم مقطع، أداة، أداة وصف أو إضافة جديدة user رسالة——الآن سوف يجعل `python-runtime` حمل حال دقيق فرق مختلف فشل؛ يلزم يجعل هو سقوط أرض، حينئذ يجب إعادة تشغيل `--scenario sdk-minimal --update-snapshots` و مراجعة قراءة هذا فرق مختلف. أقصى بسيط تركيب أداة وصف من هذا يصبح مرور مرور مراجعة قراءة مدة نظر إخراج.

assistant و tool رسالة نص لا مشاركة و مقارنة مقابل. حمل دائم shell حالة، تحرير جهاز إخراج و نهائي استجابة ما زال من هذا مشهد ذاته تأكيد يملك؛ لقطة مسؤول هذا profile إرسال خروج كل بند نموذج مرئي رسالة.

[AGENTS.md](../../../../AGENTS.md) و[اختبار سياسة سياسة](../../../../docs/testing.zh.md) الآن قد نقطة واضح اثنان عدد SDK كل هو agent loop، جلسة دورة الحياة و `SessionEventMap` مستقل إسقاط، لذلك تعديل منها أي واحد بند كل يلزم وصل حمل تحديث اثنان جانب مدة نظر إخراج، بينما لا فقط هو مساهمة من تماما جيد سوف تشغيل ذلك واحد جانب.
