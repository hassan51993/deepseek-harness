# Agent Note: في Vitest في سوف متصفح تخزين تسليم من jsdom إدارة

Status: implemented
Archived: 2026-09-04

[English](2026-07-30-vitest-jsdom-webstorage-ownership.md) | العربية

## مشكلة

تلقي دعم حمل Node إصدار نطاق يتضمن سوف مسبق إبقاء عملية درجة `globalThis.localStorage` إصدار. لم ضبط `--localstorage-file` وقت،Node 26 سوف هذا خاصية كشف لـ `undefined`؛Vitest فحص قياس إلى هذا عدد مسبق إبقاء مفتاح بعد، لن استخدام jsdom عزل `Storage` كائن تغطية هذا خاصية. لذلك، مكون اختبار طقم عنصر بعد لم تحقق منتج سلوك سهل سوف فشل، بينما رئيسي يلزم Node 24 نسبة التغطية عبر طريق ما زال قدرة عبر، لأن هذا وقت التشغيل افتراضي لن مسبق إبقاء هذا مفتاح.

## قرار

عند وقت التشغيل إعلان دعم حمل `--webstorage` علامة سجل وقت،Vitest worker سوف منع استخدام Node عملية درجة Web Storage. إعداد عبر كل اختبار مشروع `execArgv` نقل دخول `--no-webstorage`؛ لم إعلان هذا علامة سجل وقت التشغيل فإن لا نقل دخول هذا معامل. لذلك،Node بيئة اختبار طقم عنصر لا تحميل متصفح بيئة، بينما عبر `@vitest-environment jsdom` اختيار jsdom ملف سوف نيل نيل jsdom عزل `localStorage`.

Node توافق صفة تجميع مجموع مهمة سوف في كل بند إعلان دعم حمل توافق إصدار خط فوق تشغيل مخصص استخدام jsdom خطر دخان اختبار. هذا اختبار معا تأكيد worker معامل حسب شرط نقل دخول كما تخزين متاح، لذلك لم قدوم Node أو Vitest تغير لن يجعل رئيسي يلزم Node 24 اختبار طقم عنصر يصبح وحيد فحص قياس إشارة.

## سبق اعتبار بديل خطة

- **في حزمة نص برمجي أو CI في ضبط `NODE_OPTIONS=--no-webstorage`.** مرفوض: هذا سوف سوف اختبار تشغيل جهاز سياسة نقل بث إلى عملية فرعية، أيضا لا يمكن تغطية مباشر استدعاء `pnpm exec vitest` حال حال.
- **نحو Node نقل دخول `--localstorage-file`.** مرفوض: مفرد عدد عملية درجة حفظ دائم تخزين و كل jsdom بيئة قسم آخر إنشاء متصفح تخزين أداة لديه مختلف ملكية و عزل دلالة.
- **في ابتدائي تحويل شفرة في تعديل `globalThis.localStorage`، أو لـ كل مكون اختبار زيادة حفظ حماية منطق.** مرفوض: ابتدائي تحويل منطق سوف اعتماد Vitest خاص jsdom خريطة دقيق عقدة، بينما تدريجي اختبار إضافة حفظ حماية منطق سوف إخفاء غطاء متصفح بيئة ضرر تالف، و في كثير عدد اختبار طقم عنصر في تكرار هذا سياسة.
- **سوف اختبار ثابت في Node 24.** مرفوض: حزمة جذب محرك نطاق إعلان دعم حمل تحديث أحيانا عدد Node إصدار خط، بينما توافق صفة مستطيل دفعة صحيح هو لـ كشف هذه إصدار وقت التشغيل تغير.

## عاقبة

نفس بند `pnpm test` أمر في لديه بلا داخل وضع Web Storage Node إصدار فوق متساو يمكن تشغيل. اختبار worker يتم متعمد منع توقف استخدام Node عملية درجة Web Storage؛ لم قدوم إذا منتج حاجة هذا API، يجب استخدام مستقل كما صريح اختبار إعداد، بينما لا يستطيع تقليل ضعيف jsdom عزل. توافق صفة عبر طريق فقط زيادة واحد مخصص بند Vitest عملية، بلا حاجة في كل Node إصدار فوق تكرار كامل طقم اختبار وحدة.
