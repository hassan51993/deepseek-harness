# Agent Note: CI اختبار يمكن اعتماد صفة Skill

Status: implemented
Archived: 2026-09-04

[English](2026-08-28-ci-test-reliability-skill.md) | العربية

## مشكلة

DeepSeek Harness سوف في تزامن Vitest ملف،worker عملية، مستودع gate و Actions job في تشغيل اختبار. عملية عزل لن عزل مضيف آلة طرف فتحة، يمكن مسبق قياس مسار، خارجي نطاق الأسماء أو وراثة عملية فرعية، بينما عملية عام حالة تغيير و لم إتمام teardown ممكن تلوث صبغ لاحق اختبار. أي جعل اختبار اختيار صحيح تأكيد طبقة درجة، أيضا ممكن فقط في وحيد احتلال وقت التشغيل عبر.

اختبار سياسة سياسة مسؤول اختبار طبقة درجة، منع صد صفة نمط مسؤول وقت التشغيل دورة الحياة قاعدة،pre-push إشارة جذب مسؤول اختيار أمر، شفرة review مسؤول فحص قد إتمام diff. هو جمع كل لا يوجد لـ agent توفير واحد تجمع تركيز مسار، لأجل حسب وفق حقيقي CI توسيع اندفاع تصميم سوف احتلال استخدام مورد اختبار، أو في تعديل شفرة قبل مقابل قد لديه عام معدل صفة فشل إجراء تصنيف.

## قرار

[dsh-ci-test-reliability](../../../skills/dsh-ci-test-reliability/SKILL.md) مسؤول اختبار عزل و CI عام معدل صفة فشل تشخيص إشارة جذب. اختبار أو fixture احتلال استخدام مضيف آلة مورد، تعديل عملية عام حالة، اعتماد مختلف خطوة حينئذ خيط، يحتفظ عملية فرعية أو شبكة شبكة listener، أو ظهور عام معدل صفة CI فشل وقت، استخدام هذا Skill.

هذا Skill اشتراط agent بناء نموذج مفرد عدد Vitest عملية خارج تزامن، أصل فرعي قسم إعداد فوري مورد، يأخذ مستقر fixture معرف و مؤقت نقل عنوان قسم فتح، حسب يمكن مراقبة حالة تزامن، دقيق استعادة عام تغيير، و انتظار teardown بلوغ إلى ساكن توقف حالة. ارتداد دليل و الذي يحتفظ ريح خطر مطابقة:guard استخدام سالب نحو تحكم، تنافس حالة استخدام تحديد صفة barrier، مضيف آلة مورد عزل استخدام تزامن مستقل عملية، و بـ خارجي مراقبة بديل بديل مكون ذاتي وصف.

آخر لديه اثنان بند قاعدة تغطية مستودع قد دفع خروج مرور بديل قيمة فشل. عملية نظام يملك قيمة لا حفظ إثبات حسب كتابة مثال فرعي إرجاع، لذلك فقط لديه في تأكيد سعة تحمل كتابة عودة فشل وقت، اختبار عندئذ يمكن يأخذ هو كتابة عودة ذهاب؛ تأكيد اعتماد كتابة عودة نجاح وقت، مدة نظر قيمة أخذ ذاتي إعادة قراءة. و طقم عنصر درجة timeout تغطية بينما لا هو يجعل يقع في runner flag، لذلك تلقي عملية إنشاء قيد طقم عنصر أخذ lane ميزانية، وصل نفس hook ميزانية واحد بدء رفع عال، و يجعل خارج طبقة انتظار بعيد كبير في أي يتم قياس مهلة. حسب هذا، استعادة قد يتم منح إعطاء ميزانية، أو حسب فعلي قياس تنازع انتزاع علامة تحديد واحد محدود إعادة محاولة، كل لا يخص إخفاء غطاء صيغة إصلاح.

فقط لأجل تشخيص مسار وضع في مفرد وحيد reference في، لذلك عادي تحرير كتابة مهمة لن تحميل Actions قسم تشخيص خطوة. هو سوف أولا مقارنة مقارنة نجاح و فشل دليل، مجددا مقابل مضيف آلة اندفاع مفاجئ، لم إتمام دورة الحياة، عام حالة تلوث صبغ، سالب تحميل حساس شعور تزامن، منصة أو مدخل مسار فشل، منتج تنافس حالة،provider لحظة وقت لذا عائق أو runner أساس أساس ضبط تطبيق إجراء تصنيف.

[dsh-pre-push-checks](../../../skills/dsh-pre-push-checks/SKILL.md) في اختيار أمر قبل حسب شرط مرجع يمكن اعتماد صفة Skill،[dsh-code-review](../../../skills/dsh-code-review/SKILL.md) فإن في review عال ريح خطر اختبار وقت تطبيق هو. أمر اختيار و عام PR review ما زال من هذه قائم Skill مسؤول.

هذا قرار و[تحديد صفة و ضغط قوة اختبار رفع سجل](../../proposed/testing/2026-06-11-deterministic-and-stress-testing.zh.md) جزء إعادة دمج. هذا Skill تسليم اختبار تحرير كتابة و تشخيص إشارة جذب، لكن لا يوجد تنفيذ رفع سجل في lint قاعدة، عام إعادة تشغيل fixture أو nightly stress job، لذلك رفع سجل إبقاء نشط وثب.

## اعتبار مرور بديل خطة

**توسيع dsh-pre-push-checks.** Pre-push إشارة جذب في اختبار تصميم بعد تشغيل، مسؤول اختيار دليل. إذا هو أيضا مسؤول مورد قسم إعداد، تزامن،teardown و CI تشخيص، حينئذ سوف خلط دمج اثنان نوع مختلف قرار، و يجعل عادي push أيضا تحميل يمكن اعتماد صفة مسار.

**توسيع dsh-code-review.** Review إشارة جذب يمكن في diff قد وجود بعد اكتشاف غير ممكن اعتماد اختبار، لكن لا يمكن في fixture تصميم مرور مسار في إشارة توجيه agent، أيضا لا يمكن في لا يوجد PR وقت إشارة توجيه لذا عائق تشخيص.

**يأخذ كامل مسار وضع دخول معتاد إقامة اختبار سياسة سياسة.** اختبار سياسة سياسة حاجة إبقاء لـ اختبار طبقة درجة و وضع وضع قاعدة بسيط نظيف مرجعي مصدر. يجعل كل اختبار مهمة كل تحميل تفصيل دقيق Actions تشخيص و مورد مخصص بند مسار، سوف تكرار حال بيئة صفة إشارة جذب، أيضا سوف خفض منخفض سياسة سياسة يمكن مسح صفة.

**قيام أي زيادة عام stress runner أو صحيح فإن gate.** تكرار تشغيل إبقاء أخضر لون لا يستطيع إثبات تنافس حالة قد تلقي تحكم، بينما حرف وجه طرف فتحة، مسار،sleep و URL ممكن هو دمج قاعدة parser إدخال أو مدة نظر قيمة. لم قدوم إذا ظهور عال إشارة نقص وقوع نوع، يمكن زيادة ضيق نطاق يمكن تنفيذ فحص، بينما لا لا بد يأخذ عرض عام نص مطابقة عند صار سياسة سياسة.

## عاقبة

Agent في تصميم أو تشخيص تأكيد فعلي حاجة هذه قاعدة اختبار وقت نيل نيل يمكن اعتماد صفة إشارة جذب،pre-push و review مسار أيضا قدرة مشترك استخدام نفس طقم معيار بينما لا نسخ خطوة. صاف تحديد صفة اختبار متابعة اعتماد عادي تجمع تركيز دليل مسار.

هذا Skill يخص إشارة توجيه صفة قاعدة، لا يمكن آلة آلة منع توقف كل مورد اندفاع مفاجئ. إذا بعض نوع نقص وقوع عكس تكرار ظهور كما قدرة يتم ساكن حالة تعرف آخر، ما زال يمكن زيادة يمكن تنفيذ مستودع فحص. مستودع أيضا سوف كثير صيانة واحد نشط وثب Skill و reference، ذلك رابط و قديم وصف يجب و حقيقي CI توسيع اندفاع إبقاء متسق.

قائم تحديد صفة و ضغط قوة اختبار رفع سجل متابعة فتح وضع، هذا تغيير أيضا لن مراجعة حساب أو إعادة كتابة حالي اختبار لغة مادة مكتبة.
