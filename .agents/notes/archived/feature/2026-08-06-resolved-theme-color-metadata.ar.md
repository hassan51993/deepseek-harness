# Agent Note: أساس في تحليل بعد رئيسي عنوان لون لون بيانات وصفية

Status: implemented
Archived: 2026-09-04

[English](2026-08-06-resolved-theme-color-metadata.md) | العربية

## مشكلة

Web عميل يمكن مستقل في عملية نظام انحراف جيد تحليل رئيسي عنوان، لذلك manifest(بيانات وصفية بيان) في مفرد واحد `theme_color` قيمة أو حمل وسيط جسم شرط ساكن حالة بيانات وصفية ممكن و صريح اختيار Light أو Dark لا متسق. هذا وقت، بلا نقاش هو قد تثبيت صفحة أيضا هو عادي صفحة، ذلك دورة محيط متصفح واجهة كل لم لا بد و تطبيق واجهة متسق، كل إدارة تخطيط عرض جهاز قد يملك تحليل بعد document ضبط لون لوح.

## قرار

ui-layout `ThemePresenter` يملك واحد `<meta name="theme-color">`، و أصل عنصر عنصر فوق `color-scheme`، عميق لون ضبط لون لوح خاصية و داخل ربط token كتابة و صف. في تطبيق تحليل بعد لقطة ضبط لون لوح و token تغطية قيمة بعد، عرض جهاز قراءة body حساب حساب مثال صيغة في `background-color`، كتابة هذا بيانات وصفية عنصر عنصر، مجددا سوف هذا عقدة إدراج دخول document head. لاحق لقطة سوف تحديث نفس عقدة، مورد تحرير وقت فإن إزالة هو.

تصيير بعد body خلف مشهد ما زال هو لون لون حق مصدر.PWA manifest لا يتضمن ساكن حالة `theme_color` أو `background_color`،`ThemeDefinition` أيضا لا إضافة جديدة ممكن و token ضبط لون لوح انحراف مغادرة ثاني عدد لون لون حقل. هذا مثال واحد قدوم، تسجيل رئيسي عنوان أساس أساس خلف مشهد token أيضا قدرة عبر صفحة واجهة استخدام نفس بند تطبيق مسار أثر في متصفح واجهة.

## تحقق

عرض جهاز اختبار وحدة اتفاق تغطية ضحل لون و عميق لون نمط تحت حساب حساب لون لون، عقدة إعادة استخدام و مورد تحرير.ui-layout تركيب اختبار تغطية ابتدائي إدراج دخول، حدث قيادة إعادة استخدام و fiber تنظيف.Web متصفح ضبط مشهد عبر فعلي تسليم تركيب اعتماد مرة قيادة Light،Dark،System، عملية نظام انحراف جيد تغير و إعادة تحميل، و تأكيد صفحة بداية نهاية فقط لديه واحد بيانات وصفية عنصر عنصر، ذلك محتوى انتظار في حساب حساب بعد body خلف مشهد كما تحكم منصة بلا خطأ. هذا بند بيانات وصفية تغيير لن ظهور في تصيير بعد بلا عائق عائق شجرة إخراج في، لذلك مشهد قائم مسبق مدة إخراج إبقاء ثابت.

## سبق اعتبار بديل خطة

**في manifest في ضبط `theme_color`.** manifest فقط قدرة توفير واحد ملائم لأجل كامل تطبيق قيمة، لذلك مهمة واحد داخل وضع ضبط لون لوح كل ممكن و لـ لا متسق؛manifest متعمد حذف هذا حقل.

**استخدام `prefers-color-scheme` وسيط جسم استعلام إعلان ضحل لون و عميق لون بيانات وصفية.** وسيط جسم استعلام تتبع مع عملية نظام، بينما غير تطبيق داخل صريح اختيار، لذلك لا يمكن يمثل تحليل بعد انحراف جيد.

**لـ كل `ThemeDefinition` إضافة `themeColor` حقل.** مفرد وحيد قيمة يمكن يجعل ذاتي تعريف رئيسي عنوان مستقل اختيار متصفح واجهة إعداد لون، لكن سوف نسخ أساس أساس خلف مشهد لون، و سماح صفحة و دورة محيط متصفح واجهة حدوث انحراف مغادرة. إذا تلقي دعم حمل رئيسي عنوان حاجة هذا نوع متعمد فرق مختلف، يمكن مجددا جذب دخول مستقل حقل.

## عاقبة

دعم حمل هذا بيانات وصفية متصفح سوف في عميل تطبيق ابتدائي تحليل بعد لقطة و بعد كل مرة رئيسي عنوان تغير وقت تحديث دورة محيط واجهة؛ لا دعم حمل `theme-color` متصفح سوف تجاهل اختصار هذا بند بيانات وصفية. من في هذا قيمة قدوم ذاتي حساب حساب بعد عرض نتيجة، عميل يجب تأكيد حفظ body بداية نهاية لديه واضح خلف مشهد لون. عرض جهاز سوف إنشاء و إزالة ذاتي ذات عقدة،head في غير متصل بيانات وصفية فإن إبقاء ثابت.
