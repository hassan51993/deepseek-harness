# Agent Note: صريح إشارة تحديد Web ربط عنوان

Status: implemented
Archived: 2026-09-04

[English](2026-07-22-web-bind-address.md) | العربية

## مشكلة

Web تطبيق يمكن استخدام Host مستخدم authority تشغيل أمر. نفس آلة استخدام فقط حاجة loopback يمكن بلوغ صفة؛CLI إذا توفير كل واجهة نمط، حينئذ سوف في لا يوجد TLS أو واضح بديل إدارة اتفاق وقت داكن عرض دعم حمل شبكة شبكة نشر.

HTTP تحمل تحميل طبقة أيضا يأخذ ربط عنوان إخفاء في `startWebServer()` داخلي، توجيه يؤدي أخرى قشرة طبقة لا يمكن في حزمة حد واضح جدول بلوغ ذاتي ذات شبكة شبكة سياسة.

## قرار

`dsh web` ربط `127.0.0.1` و رفض `--host 0.0.0.0`؛CLI لا فتح وضع شبكة شبكة نمط. عملية أمر لوحة و متصفح cookie إقرار إثبات لا توسيع كبير هذا نشر اتفاق ([قرار](../architecture/2026-08-24-browser-token-authentication.zh.md)).

`WebServer` ما زال اشتراط `host: '127.0.0.1' | '0.0.0.0'`، و في لا يوجد fallback حال حال تحت نقل إعطاء `node:http`. عام تحمل تحميل طبقة يجعل ذاتي تعريف تركيب سياسة صريح إبقاء في حزمة واجهة فوق؛ منتج CLI يحتفظ أكثر صارم إطار loopback اختيار.

## سبق اعتبار بديل خطة

**إبقاء بـ `0.0.0.0` بصفة قيمة افتراضية.** غير مقبول، لأن عادي نفس آلة استخدام لا حاجة في كل شبكة نطاق داخل يمكن بلوغ، أيضا لا ينبغي خفي صيغة نيل نيل هذا نوع يمكن بلوغ صفة.

**استخدام نشر ذلك نوع كشف علامة سجل.** غير مقبول، لأن `--host 0.0.0.0` مباشر شرح نهائي طقم وصل حرف سلوك، و و قاع طبقة خادم خيار متسق، بلا حاجة مجددا جذب دخول ثاني طقم فن لغة.

**إبقاء صريح `--host 0.0.0.0` نمط.** غير مقبول، لأن فقط لديه إقرار إثبات و لا يستطيع لـ أداة نوع Host توفير TLS، تحويل إرسال دلالة أو تلقي دعم حمل بعيد مسار نشر اتفاق.

**في `startWebServer()` داخل ضبط قيمة افتراضية.** غير مقبول، لأن تحمل تحميل طبقة ممكن من كثير نوع قشرة طبقة استدعاء، لا يوجد اعتماد حسب بديل هو جمع اختيار نشر سياسة. اشتراط نقل دخول `host`، يمكن جعل كل مرة تركيب إعداد استدعاء كل واضح عمل خروج هذا واحد اختيار.

## عاقبة

`dsh web` محلي بدء ما زال يمكن عبر `http://127.0.0.1:3080` وصول.CLI لا فتح وضع ذاتي تعريف واجهة، كل واجهة أو IPv6 نمط؛ ذاتي تعريف WebServer تركيب إبقاء تحمل تحميل طبقة اثنان عدد عنوان اختيار و ذاتي سطر تحمل تحمل الكل عاقبة. خادم اختبار ثابت اثنان عدد تحمل تحميل قيمة كل سوف دخول Node listen،CLI اختبار فإن ثابت كل واجهة flag يتم رفض.
