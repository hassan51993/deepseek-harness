# Agent Note: Web جولة مرور مسار طي

Status: implemented
Archived: 2026-09-04

[English](2026-08-14-web-turn-process-folding.md) | العربية

## مشكلة

واحد نموذج جولة ممكن سوف في نهائي متن قبل عرض توجيه النظام، سياق حقن، دفع إدارة، كثير بند Assistant عودة تكرار، أداة استدعاء و إعادة محاولة سطر. كامل عرض كامل بند مسار أثر سوف إغراق لا متن، بينما يأخذ مستقل Chat Node نقل دخول واحد أب درجة disclosure سوف إعادة تركيب لديه حالة أداة renderer، و إزعاج فوضى حسب وقت ترتيب صف دليل. ضيق تجميع عرض يجب استلام بدء قد إتمام مرور مسار عمل، معا في جولة ما زال موضع في دفع إدارة، استخدام أداة، إعادة محاولة أو لا يوجد متن سهل انتهاء وقت، إبقاء عند تحت وحيد متاح دليل.

## قرار

من Host دعم دعم `ui-chat.transcriptView` انحراف جيد توفير `normal` و `compact` اثنان نوع نمط، قيمة افتراضية لـ `compact`.Normal إبقاء كل مرور مسار سطر مرئي كما لا تصيير جولة مرور مسار تحكم عنصر؛Compact تطبيق تحت وصف disclosure قاعدة. تبديل نمط فقط تغيير wrapper مرئي صفة، لن إعادة تعليق وصل أو إزالة Chat Node renderer؛ هذا انحراف جيد لا كتابة Session log.

في Compact نمط تحت، جولة فتح خلال بداية نهاية كامل توسيع. إلى `turn/end` وقت، فقط لديه عند الأكثر قريب خطوة يتضمن موجه إلى مستخدم Assistant عودة تكرار محتوى——غير فارغ نص، صورة أو لم معرفة مرئي كتلة——و كما لا يحتوي أداة استدعاء كتلة وقت، هذا خطوة عندئذ يصبح نهائي متن حد. متن إبقاء مرئي. حد قبل سياق حقن، دفع إدارة، مقارنة مبكر Assistant محتوى، أداة سطر و إعادة محاولة سطر موحد واحد دخول واحد بند مرور مسار disclosure. توجيه النظام، مستخدم رسالة و steering رسالة إبقاء مستقل، أبدا إضافة دخول مرور مسار مجموعة. قد إتمام، قد إلغاء، قد في قطع، فشل و بلوغ إلى الأكثر كبير token جولة استخدام نفس نهاية حالة إسقاط؛ خطأ، الأكثر كبير token و turn-tail سطر إبقاء في مرور مسار مجموعة خارج. إغلاق وقت لا يوجد نهائي متن جولة سوف إبقاء الكل مرور مسار دليل.

جولة أثر مجال `turn-process` Definition أصل حسب سجل حدث و خطوة Location data دفع توجيه أول بند نموذج أو أداة دليل، الأكثر قريب خطوة قد تحديد مسودة متن حد، هذا متن قبل حمل عودة تكرار محتوى حمل دائم Assistant رسالة عدد و أداة استدعاء حساب عدد. مع منتج تسليم subagent تفويض إرسال اسم (`subagent` و `subagent_*`) فقط زيادة subagent حساب عدد، لا زيادة عادي أداة استدعاء حساب عدد، لذلك اثنان صنف لن إعادة تراكم. سياق حقن ما زال هو مرور مسار دليل لكن لا زيادة ملخص حساب عدد؛ توجيه النظام إبقاء مستقل، حمل متابعة مرئي، و بداية نهاية يقع في فتح ساحة User فوق جهة.Definition يأخذ نفس نسخة غير ممكن تغيير `TurnProcessSpec` مباشر إصدار إلى Turn Location data و مستقر تحكم Chat Node؛ حمل متابعة open stream تحديث في حقل ثابت وقت إعادة استخدام اثنان نسخة قيمة.Chat target من أول مرة إسقاط بدء حينئذ يأخذ فتح ساحة User أو steering إدخال وضع في مرور مسار مرشح قبل، مجددا يأخذ دمج صار تحكم سطر إدراج دخول هذا إدخال و مرور مسار سطر بين. لا يوجد فتح ساحة شخص عمل إدخال وقت، تحكم سطر من أول مرة ظهور بدء حينئذ يقع في الأكثر مبكر مرور مسار مرشح قبل. لذلك متن تحديد مسودة،Retry، لاحق خطوة، إتمام حالة و يد حركة توسيع فقط تغيير مرئي صفة، لا تغيير قائم عقدة متبادل مقابل ترتيب، أداة جسم قاعدة من[مستقر جولة مرور مسار ترتيب ترتيب](../bug-fix/2026-08-26-stable-turn-process-order.ar.md) شرح.

`ChatTurnProcessProjector` يملك عبر Node عرض واقع. فقط لديه Node بنية،`TurnProcessSpec` أو Turn حالة تغير وقت، هو عندئذ مسح تلقي أثر Turn؛ متبادل انتظار عرض سوف حسب مرجع إبقاء، كما فقط لديه تغير Turn داخل Seat سوف استلام إلى مستقر process source إصدار. كل Seat من مشترك عرض حكم قطع ذاته مرور مسار عضو و متن زاوية لون، بلا حاجة قراءة عام Chat snapshot، مسح Turn أو تحرير رمز مجددا حل رمز توقيع.Turn حالة و قد تحميل نافذة هل كامل مشترك نفس قرار قدرة لا طي: فتح في Turn أبدا طي، تاريخ لا كامل وقت أيضا حيث لا عرض تحكم عنصر أيضا لا إخفاء عضو. تحكم Node من أول بند مرور مسار دليل ظهور بدء واحد مباشر وجود، لكن ذلك Seat سوف إبقاء إخفاء، مباشر حتى إغلاق Turn يملك نهائي متن كما تاريخ كامل؛ عرض بعد، هو سوف حذف كل قيمة لـ 0 قسم مقطع، ثلاثة بند كل لـ 0 وقت استخدام «قد تفكير اعتبار»(إنجليزي نص لـ `Thought for a while`) ، و في ملخص تحت جهة رسم صنع عبر شريط قسم فصل خط.

Chat target عبر مشترك settings scope ربط حفظ دائم transcript انحراف جيد، و يأخذ تدريجي جولة تفاعل حالة حفظ في جلسة أثر مجال Chat store في.`ChatView` عبر مستقر keyed `ChatNodeSeat` مباشر تصيير كل عمل خدمة Node؛ إضافة دخول مرور مسار تحكم عنصر لن إعادة ترتيب قائم key،Compact نمط فقط تغيير Seat wrapper `hidden` خاصية، لن إعادة تعليق وصل أو إزالة أداة،Assistant، سياق أو إعادة محاولة renderer.Seat عبر `ChatNodeOwnerProps` نقل تمرير نفس نسخة مرور مسار حالة، لذلك نهائي Assistant renderer سوف إخفاء ذاته خطوة في دفع إدارة كتلة، معا إبقاء عودة تكرار كتلة؛wrapper مرئي صفة و سطر داخل دفع إدارة مشترك استخدام واحد UI حالة حق مصدر.

استلام بدء مرور مسار عضو استخدام `hidden="until-found"`. في دعم حمل هذا قدرة متصفح في، مهمة واحد عضو إطلاق `beforematch` كل سوف فتح مشترك مرور مسار مجموعة. من في hidden-until-found عضو سوف إبقاء يمكن بحث صفر عال درجة box،Chat صف فقط في مرئي متبادل مجاور عضو بين ضبط بين مسافة؛ تحكم عنصر قسم فصل خط أفقي عبر محتوى عرض درجة، فقط لديه في بين لا يوجد مستقل إدخال وقت، استلام بدء مرور مسار تحكم عنصر عندئذ و متن متبادل فصل 8px، توسيع بعد استعادة عادي 16px سطر بين مسافة. استلام بدء Think سطر عبر CSS تتبع مع الأكثر جديد تدفق صيغة نص سطر، أداة لديه مع حرف رقم محور تغير مفرد سطر ثابت عال درجة، و تفعيل size و layout containment؛ توسيع وقت إزالة containment، متن استعادة ذاتي لكن عال درجة. في Compact نمط تحت، لا حفظ دائم جلسة store فقط حفظ مستخدم يد حركة توسيع «Turn + متن Step»generation؛ لا يوجد سجل أي لـ استلام بدء، مختلف متن generation افتراضي استلام بدء. لذلك، كل دمج إطار قد إغلاق Turn كل استخدام نفسه افتراضي حالة، لا منطقة قسم فوري إتمام، في «تحميل أكثر مبكر» بعد ظهور، أو في قراءة من مغادرة فتح ذيل جزء وقت انتهاء. هذا ممكن في Turn إغلاق أو تاريخ تغيير كامل وقت يجعل قراءة من فوق جهة محتوى إعادة ترتيب. إذا تلقائي استلام بدء سوف إخفاء مرور مسار عضو في مفتاح قرص تركيز نقطة، فإن تعديل لـ فتح مشترك مرور مسار مجموعة و يأخذ تركيز نقطة إبقاء في أصل موضع؛ يد حركة استلام بدء سوف أولا يأخذ تركيز نقطة نقل إلى مرور مسار تحكم عنصر، مجددا إخفاء عضو. وجود «تحميل أكثر مبكر» وقت، كل مرور مسار إبقاء توسيع كما تحكم عنصر إخفاء؛ تاريخ تحميل كامل بعد، دمج إطار مرور مسار قيام أي استخدام افتراضي استلام بدء حالة. صفحة إعادة تحميل سوف استعادة حفظ دائم Normal أو Compact انحراف جيد؛ تدريجي Turn يد حركة توسيع فقط في نفس صفحة دورة الحياة داخل view remount بين إبقاء. تبديل إلى Normal سوف عرض كل مرور مسار سطر، قطع عودة Compact وقت سوف في افتراضي استلام بدء حالة فوق إعادة تطبيق حالي صفحة دورة الحياة داخل يد حركة توسيع سجل.

هذا بند عرض و [Conversation Node تجميع](../architecture/2026-08-09-client-conversation-node-assembly.ar.md) مشترك نفس صار قيام:Definition يحتفظ تحديد صفة مرور مسار واقع،Seat يحتفظ مشترك تفاعل حالة،keyed renderer إبقاء مستقل.[حسب سجل ترتيب إسقاط شخص عمل transcript](../bug-fix/2026-07-30-web-transcript-log-ordered-projection.ar.md) إبقاء كامل، لأن طي لا تغيير أي جلسة حدث أو نموذج إدخال.

## سبق اعتبار بديل خطة

**فقط طي مقارنة مبكر Assistant عودة تكرار.** لا اعتماد: معتاد رؤية `Think → Tool → متن` جولة فقط لديه واحد عودة تكرار خطوة، لن ظهور ضيق تجميع تحكم عنصر، مستخدم اشتراط استلام بدء مرور مسار محتوى ما زال سوف كامل توسيع.

**يأخذ سياق حقن إبقاء في مرور مسار مجموعة خارج.** لا اعتماد: حقن وقت التشغيل سياق يخص متن قبل مسار أثر، و لا هو واحد بند جديد شخص صنف إشارة أمر؛ توسيع مرور مسار بعد، ذلك ذاته disclosure و وسم ما زال كامل إبقاء. توجيه النظام فإن إبقاء في مرور مسار مجموعة خارج، لأن نقل حركة أو إخفاء كامل مرة طلب استخدام إشارة أمر سوف تغيير فتح ساحة User دورة محيط مرئي إطار هيكل.

**يأخذ كامل جولة إعادة تعليق وصل إلى واحد بند ملخص سطر تحت.** لا اعتماد: طي مورد إطار سوف في جولة تشغيل خلال تغير، بينما يأخذ قائم Chat Node نقل مرور React أب عقدة سوف إعادة تركيب لديه حالة أداة عرض. مستقر Seat يمكن توفير واحد disclosure، معا لا نقل حركة ذلك فرعي عقدة.

**يأخذ يد حركة توسيع حالة تخزين دخول جولة Location data.** لا اعتماد:Location data هو جلسة حدث تحديد صفة إسقاط، لا وجود متصفح حركة عمل كتابة مسار.UI يد اتجاه يخص قد إعلان كما لا حفظ دائم store.

**إعادة استخدام `DisclosureRow` و إزالة استلام بدء عضو.** لا اعتماد: متصفح فحص بحث لا يمكن اكتشاف ذلك نص، إعادة فتح أيضا سوف إعادة بناء لديه حالة renderer فرعي شجرة.

**في `turn/end` قبل طي فوري متن مرشح.** لا اعتماد: تدفق صيغة نص بعد ما زال ممكن ظهور أداة استدعاء، إعادة محاولة أو لاحق فقط دفع إدارة خطوة. انتظار نهاية حالة حد يمكن تجنب تجنب تلقائي استلام بدء—توسيع—مجددا مرة استلام بدء و ذلك صنع صار تخطيط قفز حركة.

**قراءة من مغادرة فتح ذيل جزء وقت مؤقت مؤقت للتو نيل نيل مورد إطار استلام بدء.** لا اعتماد: هذا خطة حاجة لحظة وقت إتمام فحص قياس و deferred حالة، و جعل نفسه قد إغلاق جولة أصل حسب دخول نظر فتحة مسار نيل نيل مختلف ابتدائي حالة. قد إغلاق جولة موحد واحد استخدام تحديد صفة قيمة افتراضية؛ تمرير مرساة تحديد مسؤول إبقاء موضع، تركيز نقطة حفظ حماية مسؤول إبقاء صحيح في إجراء تفاعل.

## عاقبة

Compact نمط سوف في جولة متن قبل فقط لديه حقن سياق، دفع إدارة أو أداة وقت ما زال مفاجئ خروج نهائي متن، توسيع بعد كل بند مرور مسار سطر حسب أصل ترتيب استعادة؛Normal نمط فإن إبقاء كامل transcript كما لا عرض جولة مرور مسار تحكم عنصر. إخفاء wrapper و Markdown فرعي شجرة إبقاء تركيب، استخدام واحد تحديد متصفح داخل تخزين تبديل أخذ مستقر أداة حالة، عبر عرض إعادة تركيب يد حركة توسيع حالة و متصفح فحص بحث استعادة. فقط لديه Compact نمط تحت عادي عبر رسالة اختيار سوف ترتيب حذف ما زال استلام بدء عضو؛ مستخدم يمكن أولا توسيع مرور مسار مجموعة، أو تبديل إلى Normal. لا دعم حمل `hidden="until-found"` و `beforematch` متصفح ما زال يمكن يد حركة توسيع، لكن لا يمكن عبر صفحة داخل فحص بحث كشف عرض استلام بدء مرور مسار نص. وحدة تغطية ثابت قد تحديد مسودة متن حد، إعادة محاولة و في قطع، عبر kind مشترك توسيع، نهائي خطوة دفع إدارة، نمط تبديل، يد حركة توسيع، تاريخ تكملة كل بعد قيام أي استلام بدء، مغادرة ذيل استلام بدء، تركيز نقطة إبقاء و نهائي قسم صفحة صاف بيانات تحديث؛ تجميع بعد متصفح لقطة ثابت تشغيل في، قد إلغاء، قد إتمام، قسم صفحة تاريخ و حفظ دائم ضبط مسار أثر.
