# Agent Note: PTC mode لغة توزيع و Python SDK مصير

Status: implemented
Archived: 2026-09-04

[English](2026-07-31-ptc-language-dispatch.md) | العربية

## مشكلة

PTC mode فقط توليد واحد نوع SDK شكل:TypeScript.`ToolRuntime` لـ `tools:sdk` مقطع صلب تحرير رمز `renderToolsSdk`، كما `requireCodeRuntime` سوف رفض أي `ctx.codeRuntime.language !== 'typescript'`. جذب دخول CPython خلفية بعد، برنامج مصدر لغة لم يعد ثابت: نفس عدد مرئي أداة سجل التسجيل في تحميل Python وقت التشغيل وقت يجب إلقاء إطلاق خروج Python SDK، بينما موجه إلى نموذج `run_code` schema نص ("Execute a Python program …") أيضا يجب و SDK مقطع لغة متسق، نموذج عندئذ لن في Python وقت التشغيل تحت يرى TypeScript إشارة أمر.

هذا هو كثير لغة PTC mode تفكيك قسم في موجه إلى أداة ذلك واحد نصف؛[شفرة وقت التشغيل seam](../../../../packages/code-runtime/code-runtime/README.ar.md) قد يحمل `CodeRuntime.language`. هذا Note فقط مسؤول `dsh-tools` مثل أي في هذا حقل فوق توزيع. تنفيذ `language: 'python'` خلفية من هو ذاتي ذات Note مسؤول، مفرد وحيد تسليم.

## قرار

لغة اختيار حينئذ هو مقابل `ctx.codeRuntime.language` فحص جدول، في نص التوجيه تركيب إعداد وقت كسول صفة تحليل، فحص `dsh-tools` داخل اثنان ورقة مستو سطر جدول:

- `SDK_RENDERERS`(index.ts) يأخذ لغة خريطة إلى هو `tools:sdk` مصير——`typescript → renderToolsSdk`،`python → renderToolsSdkPy`.`tools:sdk` مقطع قراءة الذي تحميل وقت التشغيل لغة و اختيار خروج مصير؛`requireCodeRuntime` رفض ذلك لغة لا في جدول في `mode: ptc`/`both` وقت التشغيل، و صف خروج معروف لغة.
- `RUN_CODE_FLAVORS`(ptc.ts) يأخذ لغة خريطة إلى هو ذلك اثنان بند موجه إلى نموذج `run_code` نص (أداة `description` و `code` معامل وصف) ، جعل واحد نوع لغة SDK مقطع و هو نقل schema بداية نهاية متسق.

اثنان ورقة جدول في استخدام قبل كل بـ `Object.hasOwn` قراءة، هذا مثال اسم لـ `toString`/`constructor` لغة لن يأخذ وراثة ذاتي `Object.prototype` عضو تحليل صار مصير. اثنان عدد حراسة حماية يمكن بلوغ صفة مختلف:`SDK_RENDERERS` عودة ضبط داخل حراسة حماية غير ممكن بلوغ، لأن `requireCodeRuntime` قد في نفس عودة ضبط أكثر مبكر موضع تحقق مرور نفس ورقة `const` جدول (هو حمل `/* v8 ignore */`) ؛ بينما `RUN_CODE_FLAVORS` حراسة حماية هو رئيسي يلزم، يمكن عام وصول رفض مسار——أي نقص مقعد flavor جدول لغة كل مرور `run_code` لغة شعور معرفة getter وصول هو، بينما عام مشترك `schemas()` مقاومة بلوغ ذلك بعض getter وقت و لم أولا مرور `requireCodeRuntime`؛ اختبار مباشر قراءة definition فوق منها واحد getter، استخدام هو مقابل اثنان ورقة جدول كل نقص مقعد لغة.«في `SDK_RENDERERS` داخل لكن لا في `RUN_CODE_FLAVORS` داخل» هذا نوع عائم نقل قد من مشترك `CodeSdkLanguage` `satisfies` في `typecheck` موضع رفض، اثنان عدد حراسة حماية كل نظر لا إلى هذا نوع إدخال؛ هو جمع مثل اليوم مسؤول هو الذي تركيب وقت التشغيل تقرير إبلاغ واحد باب اثنان ورقة جدول كل نقص مقعد لغة.schema إرسال إطلاق عبر `peekRuntime()` بينما غير `requireRuntime()` قراءة وقت التشغيل:`undefined`(بلا وقت التشغيل، من مباشر قراءة definition قراءة من و `schemas()` وصول، منها doc-catalog أخذ تجميع هو وحيد قد تسليم واحد، بينما هو جمع كل لن تغذية إعطاء نموذج، لأن تجميع مسار أولا مرور `requireCodeRuntime`) تخفيض إلى TypeScript flavor، بينما تركيب لم معرفة لغة فإن fail loud——هذا لا هو تحت جهة يتم مرفوض ساكن صامت رجوع، ذلك إشارة هو لـ حقيقي وقت التشغيل إرسال خروج خطأ لغة SDK. إضافة جديدة واحد باب خلفية لغة هو ثلاثة موضع و صف تحرير——واحد `CodeSdkLanguage` عضو إضافة اثنان بند جدول بند——مجددا إضافة هو مصير، و نقطة اسم معروف قيمة بينما غير من في إرسال توليد تفرق نص (seam جانب `dsh-code-runtime` README مزدوج لغة مقابل، هو `CodeRuntime.language` JSDoc و `docs/subsystems/code-runtime.md` مزدوج لغة مقابل؛ هذه الحزمة ذاتي ذات README مزدوج لغة مقابل و هو `Config.mode` JSDoc، بلا أي gate فحص منها أي واحد موضع) ، لا حركة `agent-loop`، أيضا لا حركة سجل التسجيل بنية.

`ptc.ts` فقط اعتماد وقت التشغيل Service Definition(`@deepseek-ai/dsh-code-runtime`) ، أبدا اعتماد أداة جسم خلفية؛ توزيع في وقت التشغيل حسب `runtime.language` إجراء. لذلك أداة طبقة مستقل في Python بروتوكول و خلفية——هو فقط حاجة خدمة `language` حقل.

### Python SDK مصير

`py-types.ts` تصيير `jsonSchemaToTs` الذي تغطية نفس طقم موحد واحد أداة schema مفردات، هدف لـ Python:`jsonSchemaToPy` لـ كل JSON-schema عقدة إرسال خروج واحد نوع جدول بلوغ صيغة،`renderToolsSdkPy` لـ كل مرئي أداة معامل و مواصفة إخراج تركيب إعداد أداة اسم `TypedDict`، مجددا إضافة واحد حمل استخدام قاعدة شرح `tools` كائن، و TypeScript شكل انتظار قيمة. لا دعم حمل أصلي بنية صنع في تركيب إعداد وقت تخفيض بينما غير رمي خطأ، و TypeScript مصير اتفاق متسق. إخراج هو تحديد صفة——أداة حسب حرف قاموس ترتيب ترتيب صف، أداة تجميع ثابت وقت نص تدريجي بايت نفسه——لذلك نص التوجيه إبقاء prefix-cache صديق جيد. حرف قاموس ترتيب معنى طعم حال مفرد واحد لديه ترتيب عضو تدفق: اسم حرف لا هو دمج قاعدة خاصية أداة بـ `tools[name]` ملاحظة تفسير ظهور في هو ترتيب ترتيب بعد موضع فوق، بينما لا هو يتم قسم انتقاء إلى نهاية ذيل، و TypeScript شكل حينئذ أرض لـ استثناء مفتاح إضافة جذب رقم فعل قاعدة متسق. هذا عدد عضو تدفق مباشر قرار واحد عنصر أمر: ملاحظة تفسير سطر لا هو لغة جملة، الذي بـ واحد لا إرسال خروج أي طريقة أداة تجميع ما زال يحتاج صريح `pass`. آخر لديه ثلاثة بند قاعدة و غير مصدر ذاتي ترتيب ترتيب، بينما هو Python خاص لديه. ذلك واحد، استخدام قاعدة اتفاق إعلان هذه إعلان فقط هو ساكن حالة تخزين أصل، معامل لـ عادي `dict`/`list` قيمة:`TypedDict` قراءة بدء قدوم مثل واحد يمكن بنية صنع صنف، نموذج إذا كتابة `FooArgs(field=1)` سوف نيل إلى `NameError`——TypeScript `interface` واحد عين حينئذ هو نوع، كما TS شكل «runs type-stripped» واحد جملة قد تغطية هو. ذلك اثنان، وصف سوف يصبح طريقة docstring، كما يجب بصفة طريقة جسم**رقم واحد بند لغة جملة**إرسال خروج: وضع في `async def` لـ فوق، رقم واحد بند سوف تغيير صار `Tools` صنف وثيقة، ذلك بقية كل هو بلا فاعلية نتيجة جدول بلوغ صيغة، توجيه يؤدي كل طريقة كل لا يوجد وثيقة. ذلك ثلاثة،`list[…]` سلسلة تجاوز مرور `MAX_LIST_NESTING` بعد تخفيض لـ `Any`، لأن CPython tokenizer رفض واحد سطر في تجاوز مرور 200 عدد معا لم إغلاق دمج تضمين رقم، بينما هذا عدد كتلة يجب هو يمكن تحليل Python——و `docLines` تحويل معنى جذب رقم و عكس مائل عمود هو نفس عدد إدارة من.`ts-types` اثنان من كل لا حاجة:TypeScript سوف يأخذ قبل وضع `/** … */` مرفق حال إلى ذلك بعد عضو فوق، ذلك لغة قاعدة أيضا لا مقابل تضمين طقم ضبط حد.

هذا حد أعلى خدمة معيار هو**لغة قاعدة دمج قاعدة صفة**، هذا بند حد هو متعمد تخطيط تحديد: طويل `A | B | …` union في أي طويل درجة تحت كل هو دمج قاعدة Python، لذا لا ضبط حد أعلى——كل إدارة CPython `compile()` في امتداد يسار تضمين طقم `BinOp` عمود عمود تحت خفض وقت سوف استهلاك كل C تمرير عودة (في 3.9 فوق فعلي قياس:1,000 عدد فرع يمكن تحرير ترجمة،5,000 عدد رمي `RecursionError`). لا يوجد أي شرق غرب سوف تحرير ترجمة هذا عدد كتلة——هو هو نص التوجيه نص——الذي بـ ذلك بند حد في هذا داخل لا يوجد بديل قيمة؛ بينما إعطاء union طويل درجة غلاف قمة سوف عمل ملغى ذلك بضعة عدد تثبيت إقامة walk خط صفة وقت و صنف اسم نقل بث حد أعلى عميق سلسلة اختبار. سوف قدوم إذا لديه مصير تأكيد فعلي حاجة يمكن تحرير ترجمة إخراج، ينبغي عند يأخذ union التقاط مستو، بينما لا هو قطع قطع.

`renderType` أولا استخدام `assertSupportedJsonSchema` كامل شجرة تحقق مرة، مع بعد معلومة مهمة هو، استخدام مفرد عدد `try/catch` يأخذ كامل مرة تاريخ التقاط إقامة و تخفيض لـ `Any`——و أخت شقيقة مصير `ts-types` في هذا عدد typed نفس عملية حد فوق أخذ أخذ «تحقق بعد معلومة مهمة» وضع حالة متسق ([Trust TypeScript at typed same-process boundaries](../../../../AGENTS.md)). هو متعمد لا ضبط أي إبرة مقابل «وصول جهاز في كثير مرة قراءة بين تغيير قيمة» منع صد (تحقق بعد صار حلقة،`const`/`enum` TOCTOU، ذاتي مرجع دالة): إدخال هو رقم واحد جهة تسجيل (`defineTool` حرف وجه كمية أو raw تسجيل) أو من wire جسر وصل بينما قدوم صاف JSON schema——قبل من حسب AGENTS.md تلقي معلومة مهمة، بعد من هو `JSON.parse` ناتج، شيء إدارة فوق غير ممكن قدرة يحمل وصول جهاز، كما كل مرة استدعاء `renderType` كل سوف كامل شجرة إعادة تحقق——هذا صنف إدخال غير ممكن بلوغ، بينما في هذا إضافة تدريجي شكل حراسة حماية سوف لـ ساكن حالة واجهة الذي منع توقف قيمة كسر تالف و `ts-types`(لا يوجد هذا صنف حراسة حماية) مقابل تسمية.`jsonSchemaToPy(schema: unknown)` قبول `unknown` و مقابل شاذ شكل schema إرجاع `Any`——TypeScript شكل `unknown` مقابل شيء——لكن هو اتفاق هو «تخفيض لا دعم حمل schema» ، بينما غير «حمل إقامة مقابل مقاومة صفة متغير schema».

## اعتبار مرور بديل خطة

- **في `ToolRuntime` فوق إضافة واحد `language` إعداد حقل.** ذلك مثال نشر جهة حينئذ سوف لديه اثنان موضع تسمية لغة (الذي تحميل وقت التشغيل و tools إعداد) كما ممكن متبادل متبادل تناقض درع؛ الذي تحميل وقت التشغيل هو وحيد حق مصدر، لذا سجل التسجيل قراءة هو بينما لا نسخ هو.
- **يأخذ Python خلفية import دخول `ptc.ts` قدوم فحص قياس هو.** ذلك سوف يأخذ أداة طبقة اقتران دمج إلى أداة جسم خلفية، و إجبار جعل بروتوكول/خلفية PR(Pull Request) أولا سقوط أرض. حسب `language` وقت التشغيل توزيع جعل هذا طبقة إبقاء خلفية غير متصل، يمكن مستقل إصدار.
- **لـ لم معرفة لغة توفير افتراضي مصير.** ساكن صامت رجوع سوف في مقارنة مثل Ruby وقت التشغيل فوق إرسال خروج TypeScript SDK——نموذج سوف يرى خطأ لغة إشارة أمر. في تركيب إعداد موضع fail loud هو هذا مستودع مقابل خطأ إعداد قيام ساحة.

## عاقبة

إضافة جديدة واحد باب خلفية لغة هو ثلاثة موضع و صف تحرير——واحد `CodeSdkLanguage` عضو، واحد `SDK_RENDERERS` جدول بند، واحد `RUN_CODE_FLAVORS` جدول بند——مجددا إضافة ثاني موضع الذي إشارة نحو مصير دالة، لا حركة `agent-loop`، أيضا لا حركة سجل التسجيل بنية. اثنان ورقة جدول (`SDK_RENDERERS`،`RUN_CODE_FLAVORS`) يجب تزامن، كما هذا بند ثابت صيغة من ساكن حالة فحص يأخذ صلة، بينما غير تسليم إعطاء review: اثنان ورقة جدول كل بـ `satisfies` مقابل فوق وصف نفس عدد union تحقق، لذلك فقط إضافة ذلك واحد بينما تسرب إسقاط آخر سوف في `typecheck` موضع فشل. هذا صحيح هو هذا عائم نقل ريح خطر ينبغي لديه آلة آلة شكل صيغة——وقت التشغيل `Object.hasOwn` حراسة حماية نفس مثال قدرة التقاط، لكن يلزم انتظار إلى لديه خلفية تقرير إبلاغ هذا لغة بعد: إطلاق نقطة في مستهلك تجميع صار موضع بينما غير عائم نقل جذب دخول موضع——بينما فقط يلزم لا وجود ثاني عدد خلفية، حينئذ دائم بعيد لن إطلاق. اثنان ورقة جدول إعلان نوع ما زال هو `Record<string, …>`، لأن `CodeRuntime.language` هو لا تلقي قيد `string`:union تثبيت إقامة harness تسليم ماذا، حراسة حماية رفض وقت التشغيل تقرير إبلاغ ماذا. سقوط في هذا بند فحص خارج هو نقطة اسم معروف قيمة بينما غير من في إرسال توليد تفرق نص:seam جانب `dsh-code-runtime` README مزدوج لغة مقابل، هو `CodeRuntime.language` JSDoc و `docs/subsystems/code-runtime.md` مزدوج لغة مقابل، مجددا إضافة هذه الحزمة ذاتي ذات README مزدوج لغة مقابل و هو `Config.mode` JSDoc. أكثر مبكر note نقطة اسم هذه قيمة وقت تسجيل هو عند وقت حالة، لا في هذا صف. يجعل هو بلا gate هو اثنان بند مستقل إدارة من. ذلك واحد، تفرق نص أصل هذا لا تلقي نوع فحص،union وضع في أي داخل كل واحد مثال. ذلك اثنان، نوع درجة بديل في هذا داخل أيضا غير ممكن استخدام:Service Definition حزمة لا نيل import ذلك مستهلك جدول، بينما `CodeRuntime.language` حسب تصميم إبقاء لا تلقي قيد `string`، أي سهل يأخذ union نقل دخول Service Definition أيضا لن أثر إلى هو. استخدام واحد تأكيد اثنان ورقة جدول مفتاح تجميع متبادل انتظار unit test خطة يتم مرفوض: هو شراء إلى هو نفس بند فحص، بديل قيمة لكن هو يأخذ اثنان ورقة خاص جدول فعل اختبار مخصص استخدام توجيه خروج، كما وقت التشغيل آلة متأخر في تحرير ترجمة جهاز. مقابل اثنان ورقة جدول كل نقص مقعد لغة، اثنان نوع وقت التشغيل فشل في تقرير خروج أي واحد بند مع مدخل بينما مختلف: تجميع مسار تقرير نقص مصير، لأن `wireSchemas` في إسقاط قبل أولا ضبط `requireCodeRuntime`؛ بينما عام مشترك `schemas()` أولا مرور مرور `run_code` لغة شعور معرفة getter، تقرير هو نقص flavor جدول بند. أداة طبقة لا اعتماد أي أداة جسم خلفية، لذلك هو قدرة أولا في Python بروتوكول و خلفية تسليم و يمكن قياس.

بديل قيمة هو اثنان ورقة جدول Python فرع في قد تسليم شفرة شجرة في غير ممكن بلوغ:`CodeRuntime.language` من الذي تحميل خلفية ضبط تحديد، قد إصدار خلفية فقط لديه `dsh-code-runtime-worker-thread`(`'typescript'`) ، بينما سجل التسجيل قراءة هو الذي تحميل وقت التشغيل بينما غير بعض عدد إعداد حقل، لذلك لا يوجد أي واحد نسخة تجميع جيد تطبيق قدرة اختيار في `renderToolsSdkPy` أو `PYTHON_FLAVOR`. أيضا حينئذ هو قول، في تقرير إبلاغ `'python'` خلفية إصدار قبل، هذا note عمل لا تغيير نموذج مرئي جدول وجه، هذا تغيير تغطية لذلك هو unit درجة——مصير إخراج إضافة توزيع و رفض مسار.Python نموذج واجهة keyless لقطة ملكية في إصدار هذا خلفية ذلك عدد تغيير، لأن فقط لديه في ذلك داخل، واحد نسخة أساس في قد إصدار إضافة حقيقي `cordis.yml` عندئذ سوف إنتاج خروج Python تجميع؛ في هذا موضع تركيب fixture(اختبار قبل وضع بيانات) وقت التشغيل لقطة عرض مثال تأكيد هو اختبار بديل ذات، بينما [docs/testing.md](../../../../docs/testing.ar.md) واضح رفض بـ هذا بديل تجميع جيد تطبيق transcript(نص سجل).

Python SDK نص تأكيد اثنان بند وقت التشغيل اتفاق نفس مثال ملكية ذلك عدد خلفية PR. ذلك واحد، شرح نص حرف إبلاغ إبلاغ نموذج وقت التشغيل تماما جيد ربط `tools` و `ToolCallError` اثنان عدد اسم حرف، الذي إعلان `TypedDict` صنف لا ربط، لذلك خلفية يجب حقن هذا اثنان عدد اسم حرف (و حسب seam `errorClass` اتفاق ملء ملء `ToolCallError.toolName`) ، كما**لا نيل**يأخذ الذي إعلان صنف اسم ربط عملية ترتيب عام——«جيد قلب» حقن سوف جعل هذا مقطع SDK نص تغيير صار زائف كلام. ذلك اثنان، لغة يجب ربط إلى طلب فوق:`requireCodeRuntime` في تجميع وقت و `run_code` تنفيذ وقت قسم آخر تحليل `ctx.codeRuntime`، إذا في هذا اثنان نقطة بين حدوث إعادة تحميل و تبديل إسقاط وقت التشغيل، حينئذ سوف يأخذ إبرة مقابل واحد نوع شكل كتابة صار برنامج تسليم إعطاء آخر نوع شكل تنفيذ. قسم شق مقارنة هذا اثنان نقطة أكثر دقيق——`run_code` `description` و `parameters` اثنان عدد getter كل منها استدعاء `resolveFlavor(peekRuntime())`، بينما `schemaOf` سوف حل بنية هذا اثنان عدد حقل، لذلك مرة إسقاط قراءة اثنان مرة وقت التشغيل؛ اثنان مرة كل يخص `run_code` ذاتي ذات schema، لأن هذا اثنان عدد getter فقط تركيب في ذلك واحد definition فوق، ذلك بقية definition يحمل كل هو عادي بيانات خاصية. في هذا اثنان مرة قراءة بين إعادة تحميل سوف إنتاج خروج مفرد عدد schema اثنان نصف قسم تابع مختلف لغة. اثنان من في هذا موضع كل غير ممكن بلوغ——فقط لديه واحد قد إصدار خلفية معنى طعم حال اثنان مرة قراءة إرجاع نفس شكل، كما لا يوجد أي برنامج سوف إبرة مقابل هذا مصير إخراج تشغيل——بينما عبر لغة رفض في ثاني باب لغة وجود قبل أيضا لا يمكن اختبار.

عدد جهة نحو——جذب محرك إرسال خروج محرف يتم ذلك tokenizer رفض استلام، كامل كتلة مع لـ غير ممكن تحليل——بينما هو مرور ثلاثة بند مستقل مسار مقاومة بلوغ. مرور حكم حسب مقاومة بلوغ هو لا إضافة جذب رقم إرسال
