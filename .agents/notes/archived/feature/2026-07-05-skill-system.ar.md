# Agent Note: Skill نظام——موجه إلى agent تدريجي دخول صيغة إشارة أمر كشف كشف

Status: implemented
Archived: 2026-09-04

[English](2026-07-05-skill-system.md) | العربية

## مشكلة

agent(ذكي جسم) منتج قد اتجاه نفس في واحد نوع skill(تقنية قدرة) نمط: إبقاء طلب نص التوجيه دقيق بسيط، فقط صف خروج متاح إشارة أمر حزمة، عند نموذج حكم تحديد بعض مهمة مطابقة وقت مجددا تحميل كامل متن.Codex،Claude Code،OpenCode و Kimi Code في دقيق عقدة فوق كل لديه مختلف، لكن كل سوف اكتشاف بيانات وصفية و كامل إشارة أمر قسم مغادرة، جعل مساحة العمل قدرة تحمل تحميل يمكن إعادة استخدام سلوك بينما بلا حاجة في كل جولة دعم دفع كل كمية نص التوجيه فتح إلغاء.

DeepSeek Harness استخدام نفس أصل لغة، جعل مشروع خاص تحديد مراجعة، إضافة تحرير كتابة و أداة استخدام إشارة جنوب تخزين وضع في مساحة العمل أو مستخدم agent إعداد جانب، بينما غير صلب تحرير رمز إلى agent loop(ذكي جسم حلقة) في.

## قرار

`@deepseek-ai/dsh-skill` هو صاف مزود سجل التسجيل (`ctx.skills`) ،`@deepseek-ai/dsh-skill-filesystem` هو مع مرفق محلي نظام الملفات مزود،`@deepseek-ai/dsh-tool-skill` مسؤول حفظ دائم جلسة دليل و موجه إلى نموذج loader أداة.`dsh-base` سوف سجل التسجيل، محلي مزود و مستهلك بصفة مستقل إعداد سطر تحميل، جعل ذلك كل profile نيل نيل نفسه سلوك، معا تضمين دخول صيغة أو بعيد مسار مزود يمكن في لا تعديل سجل التسجيل أو مستهلك قبل رفع تحت مساهمة skill. كل إعداد سطر فقط كشف ذلك الذي تابع حزمة إعداد.

مخصص استخدام مع حزمة مزود يمكن مساهمة غير ممكن تغيير skill، بلا حاجة نظام الملفات اكتشاف. تسليم CLI(أمر سطر واجهة) افتراضي سوف `@deepseek-ai/dsh-skill-badge` إعلان لـ منع استخدام؛ تفعيل ذلك تركيب إعداد سطر، حينئذ سوف عبر نفس عدد سجل التسجيل و مستهلك مساهمة رسمي جهة شعار فصل إشارة أمر (رؤية[حزمة اتفاق](../../../../packages/skill/skill-badge/README.ar.md)).

مزود إضافة في `apply()` خلال تزامن تسجيل. مزود عضو مورد إطار هو من مباشر effect يحتفظ حالة: تسجيل و dispose(مورد تحرير) تزامن أرض جعل قد إتمام دليل بطلان، اكتشاف عملية حسب يحتاج قراءة حالي مزود خريطة بينما غير استماع سجل التسجيل تغيير حدث. مزود دليل من انتظار `list()` استدعاء إرجاع ترتيب ترتيب بعد مرشح بند، بعيد مسار مزود في هذا مرور مسار في تنفيذ ابتدائي تحويل، إقرار إثبات و اكتشاف، معا التزام حراسة فحص بحث abort إشارة. سجل التسجيل تحقق كل مرشح بند، حسب ترتيب اسم، مزود تسجيل ترتيب و مزود داخلي ترتيب بـ أولا إلى أولا نيل طريقة حل قرار نفس اسم skill اندفاع مفاجئ، لكن بعد حسب skill اسم ترتيب ترتيب ملخص بـ حفظ إثبات مستهلك نيل نيل تحديد صفة نتيجة. هو فقط ذاكرة مؤقتة قد إتمام دليل لقطة، و في اكتشاف مرور مسار في مزود/وقت التشغيل إصلاح حجز إصدار حدوث تغير وقت إعادة محاولة، لذلك إزالة عملية لن سوف واحد قديم قديم كما غير ممكن تحليل skill تجميد ربط إلى جلسة دليل في. وقت التشغيل `ctx.skills.register(...)` ما زال بصفة تضمين دخول صيغة عملية داخل skill سهل سريع طريقة إبقاء، استخدام project أولوية في user أولوية درجة؛`runtime` إبقاء لـ سجل التسجيل يملك مزود اسم.

محلي مزود حسب أولا إلى أولا نيل ترتيب اسم ترتيب مسح cwd حساس شعور مشروع أصل دليل، ذاتي تعريف أصل دليل و مستخدم أصل دليل: مشروع `.dsh`، مشروع `.agents`،`customSkillDirs`، مستخدم `.dsh`، لكن بعد هو مستخدم `.agents`. مستخدم `.dsh/skills` مسح قفز مرور `.system`، بـ تجنب نظام يملك دليل يتم عند عمل عادي مستخدم محتوى معالجة. محلي مزود لن دمج صار داخل وضع نظام skill؛ قد إعداد bundled أصل دليل و مخصص استخدام مزود سوف توفير مقدار خارج skill.

كل skill هو حمل YAML frontmatter `<name>/SKILL.md` أو `<name>.md`.`name` و `description` لـ لا بد ملء؛`whenToUse`،`metadata`،`disable-model-invocation` و `user-invocable` لـ اختياري. اسم اعتماد kebab-case. استدعاء حقل سوف إسقاط إلى نوع تحويل تضمين طقم سياسة في، أداة جسم من[نموذج و مستخدم مستقل استدعاء قرار](2026-07-28-skill-invocation-policy.ar.md) تعريف؛ محلل سوف رفض قديم حدبة ذروة تجميع كتابة.YAML frontmatter استخدام `yaml` حزمة تحليل، بينما غير `js-yaml` أو يد كتابة محلل:`yaml` هو هذه الحزمة قد إعلان الآن بديل محلل، كاف بـ ممتلئ كاف لديه حد frontmatter يحتاج طلب، ضيق محلل يلزم ما رفض مستخدم مسبق مدة متاح دمج قاعدة YAML، يلزم ما تمدد انتفاخ لـ واحد لم مرور مراجعة YAML فرعي تجميع.

محلي skill نظام الملفات I/O في تحميل نظام الملفات خدمة وقت عبر `ctx.fs` إجراء: مشروع أصل دليل فحص بحث استخدام `resolve` و `stat` استكشاف قياس `.git`، أصل دليل اكتشاف استخدام `listDir`،skill قراءة استخدام `readText`.Node نظام الملفات بصفة بعد تجهيز، توفير في لا تركيب fs seam الأكثر صغير سياق في تحميل `dsh-skill-filesystem` وقت استخدام. ناقص أصل دليل، غير ممكن قراءة أو صيغة خطأ skill ملف، و مزود `list()` لحظة حالة فشل متساو تخفيض لـ تحذير إبلاغ و قفز مرور، جعل واحد تالف مصدر لن توجيه يؤدي كل agent طلب فشل؛ صيغة خطأ مرشح بند ما زال سريع سرعة فشل، لأن هو جمع مخالفة عكس مزود اتفاق.

`dsh-tool-skill` في جلسة رقم واحد `agent/pre-step` حقن واحد حفظ دائم user-role `<system-reminder>` دليل، بصفة حمل مصدر `user/message`، كما فقط عند هذا agent أداة عرض تحليل إلى هذا إضافة دقيق `skill` تسجيل وقت عندئذ حقن. هذا دليل فقط يتضمن ترتيب ترتيب بعد skill اسم و وصف؛ لا يتضمن متن، مسار، مصدر، مزود و توجيه تلميح. وصف مرور مرور فارغ أبيض مواصفة تحويل،XML تحويل معنى، و تلقي `catalogDescriptionMaxLength` حد أعلى قيد، ذلك قيمة افتراضية لـ `500`، الأكثر صغير قيمة لـ `3`. كامل skill متن من لا يتضمن في دليل في.(دليل الأكثر أول عبر فقط طلب[جلسة بادئة نقطة توسيع](../../archived/feature/2026-07-07-session-prefix.md)(قد عودة ملف) نقل تمرير؛[موحد واحد حمل مصدر رسالة قرار](../architecture/2026-07-22-unified-send-and-coalesced-user-messages.ar.md) سوف ذلك نقل دخول حفظ دائم تاريخ.)

سجل التسجيل `list()` إرجاع الكل فوز خروج ملخص، بينما نموذج و مستخدم مستهلك تطبيق[مستقل استدعاء سياسة قرار](2026-07-28-skill-invocation-policy.ar.md) تعريف استدعاء حكم تحديد.`skill({ name })` أداة لـ حالي agent cwd تحميل واحد نموذج يمكن استدعاء skill، إرجاع يتضمن `<skill_content name="...">`،`<skill_resources>` و `<skill_instructions>` أداة نتيجة.`resourceBase` توفير واحد دليل،URL أو لا نفاذ واضح مزود إدارة أساس مسار، لأجل صريح مرجع نص برمجي، مشاركة اعتبار مورد مادة و مورد إنتاج؛ مورد فقط حسب يحتاج تحميل، لا إجراء دليل قطعة رفع. لا يمكن تحليل اسم تقرير إبلاغ هذا skill لم معرفة أو لم يعد متاح؛ بلا فاعلية اسم و `invocation.modelInvocable` لـ `false` skill إبقاء مختلف أداة خطأ. أداة نتيجة هو موجه إلى نموذج مرئي كشف كشف مسار.

بيانات بنية و دليل/أداة اتفاق سجل في [skills.md](../../../../docs/subsystems/skills.ar.md) في، خدمة توقيع رؤية توليد[خدمة دليل](../../../../docs/subsystems/skills.ar.md#cordis-surface).

## سبق اعتبار بديل خطة

**سوف كامل skill متن حقن كل بند توجيه النظام.** مرفوض، لأن هذا كسر تالف تدريجي دخول صيغة كشف كشف، جعل كل طلب كل لـ ممكن لا ملائم استخدام إشارة أمر دفع خروج بديل قيمة.

**فقط بـ مائل عمود أمر كشف skill.** مرفوض، لأن نموذج رئيسي حركة تحميل هو نواة قلب قدرة؛ موجه إلى شخص صنف أمر واسع بث لا تغيير اكتشاف آلية.

**سوف محلي نظام الملفات مسح مباشر وضع دخول `ctx.skills`.** مرفوض، لأن تحرير رمز agent،Web agent و لم قدوم إضافة توليد حالة حاجة مختلف skill مصدر. مزود سجل التسجيل و subagent seam مرآة مثل: سجل التسجيل يملك اندفاع مفاجئ حل قرار و مستهلك، تنفيذ مسؤول تحميل.

**استخدام توجيه النظام مقطع سقوط.** مرفوض، لأن تصيير بعد توجيه النظام هو مفرد واحد نص، بينما دليل هو واحد بند user-role `<system-reminder>` رسالة.[فقط طلب جلسة بادئة نقطة توسيع](../../archived/feature/2026-07-07-session-prefix.md)(قد عودة ملف) هو الأكثر أول آلية؛ موحد واحد حمل مصدر رسالة قرار إزالة هذا نقطة توسيع بعد، دليل تعديل لـ أداة لديه نفسه رسالة شكل حالة حفظ دائم حمل مصدر حقن.

**في `~/.dsh/skills/.system` تحت شيء تحويل داخل وضع DSH تحرير كتابة skill.** مرفوض، لأن تحزيم skill لن في بدء وقت كتابة مستخدم رئيسي دليل، تضمين دخول صيغة أو بعيد مسار مزود في إعداد بعد توفير skill.

**تمرير عودة اكتشاف تضمين طقم `**/SKILL.md`.** مرفوض. مسطح مستو ملف و واحد درجة دليل حزمة تغطية إعداد أصل دليل، معا جعل تكرار معالجة و دليل ترتيب سهل في دفع إدارة.

**يد كتابة frontmatter محلل.** مرفوض، لأن قد قبول schema يتضمن واحد فتح وضع `metadata` كائن. ضيق محلل يلزم ما رفض مستخدم مسبق مدة متاح دمج قاعدة YAML، يلزم ما تمدد انتفاخ لـ واحد لم مرور مراجعة YAML فرعي تجميع.

## عاقبة

agent-core رئيسي جاف يتضمن واحد دليل مساهمة من، واحد محلي مزود و واحد موجه إلى نموذج أداة.skill اكتشاف هو cwd حساس شعور، لذلك بـ مختلف جلسة cwd قيمة إنشاء agent استدعاء جهة يمكن حسب تصميم مراقبة إلى مختلف مشروع skill تغطية.

دليل مقابل في ثابت أصل دليل تجميع دمج و وقت التشغيل تسجيل إصلاح حجز إصدار هو تحديد صفة. محلي مزود سوف مراقبة نظر قد إعداد أصل دليل، و في حدوث متبادل صلة مغناطيس قرص تغير بعد جعل قد إتمام دليل بطلان؛ وقت التشغيل تسجيل و مزود تحرير أيضا سوف جعل ذلك بطلان.

## تأخير بعد

fork skill سياق (`context: fork`) ، معامل إعلان و تلميح (`arguments` و `argument-hint`) ، و تدريجي skill أداة قيد (`allowed-tools` و `disallowed-tools`) لا في قد تسليم اتفاق نطاق داخل. سجل التسجيل، محلي مزود و موجه إلى نموذج أداة لا تحليل، لا واسع بث، أيضا لا قوي صنع تنفيذ هذه حقل. مباشر مستخدم استدعاء قد بصفة TUI وظيفة تسليم، أساس في مشترك استدعاء سياسة و تلقي معلومة `get()` أصل لغة؛ رؤية[قد عودة ملف TUI skill مائل عمود أمر](../../archived/feature/2026-07-21-tui-skill-slash-command.md).
