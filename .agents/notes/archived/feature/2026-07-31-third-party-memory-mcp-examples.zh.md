# Agent Note: رقم ثلاثة جهة تسجيل ذاكرة MCP عرض مثال

Status: implemented
Archived: 2026-09-04

[English](2026-07-31-third-party-memory-mcp-examples.md) | العربية

## مشكلة

مباشر تجميع صار بعض عدد مزود سوف جعل هذا مزود API، إعداد، سليم سليم حالة سلوك و أداة دلالة يصبح DSH واحد جزء. مقابل في قد يمكن عبر MCP جدول بلوغ وظيفة، هذا سوف يجعل منتج واجهة مرور في ضخم كبير، بينما كما كل وصل دخول واحد تسجيل ذاكرة نظام كل حاجة تكرار نفس مثال ملائم إعداد عمل. مستخدم حاجة هو واحد نوع دقيق بسيط، يمكن فحص طريقة، في إبقاء عام MCP حد معا، اختيار تفعيل واحد خارجي تسجيل ذاكرة خادم.

تحقق استلام معيار لا توقف في «طقم وصل حرف يمكن اتصال»: كل نسخة مشاركة اعتبار إعداد كل يجب دعم حمل DSH في جلسة A في فعلي كتابة، في جديد DSH جلسة B في من مزود استدعاء عودة، و استخدام استدعاء عودة قيمة. و هذا معا، مزود تحت تحميل، حساب مستخدم، نموذج،embedding، تخزين ابتدائي تحويل و مستقل HTTP عملية ما زال من فوق تنقل مسؤول.

## قرار

في `apps/cli/config/examples/mcp-memory` تحت تسليم ثلاثة نسخة افتراضي إغلاق Cordis overlay عرض مثال:Memorix،MCP Reference Memory و Engram. كل ملف فقط إدراج دخول واحد `@deepseek-ai/dsh-mcp-client` بند إعداد. افتراضي تركيب لن مرجع هذه ملف؛CLI(أمر سطر واجهة) إعلان عام جسر وصل جهاز، جعل صريح اختيار overlay قدرة في تثبيت بعد و شفرة المصدر بدء في تحليل.[تسجيل ذاكرة MCP إشارة جنوب](../../../../docs/user/guide/mcp-memory.zh.md) مسؤول تثبيت و تحقق خطوة.

هذه رقم ثلاثة جهة إعداد فقط بصفة متبادل عملية مشاركة اعتبار؛ استلام تسجيل لا بديل جدول DeepSeek إقرار يمكن، دفع ترشيح، دمج عمل علاقة أو حمل متابعة دعم حمل تحمل وعد. نظام لا يوجد تسجيل ذاكرة مسبق ضبط سجل التسجيل، مزود مخصص تابع DSH إضافة، عام تسجيل ذاكرة خدمة، تثبيت UI، ترحيل طبقة، سليم سليم فحص جهاز أو إعادة وصل تحكم جهاز. أخرى تسجيل ذاكرة MCP خادم يمكن استخدام نفس نسخة وثيقة في stdio أو Streamable HTTP بند إعداد.

## مسؤولية حد

| أمر بند | DSH | فوق تنقل مزود أو مستخدم |
|---|---|---|
| تحليل اختيار في overlay | هو | اختيار واحد ملف |
| بدء stdio أمر، و في إضافة dispose(مورد تحرير) وقت سوف ذلك إيقاف | هو | تثبيت ثابت إصدار يمكن تنفيذ ملف |
| اتصال Streamable HTTP تزامن الآن أداة | هو | تشغيل و مراقبة إدارة HTTP خدمة |
| بـ `mcp__<serverName>__<rawName>` تسجيل أداة | هو | تعريف أداة schema و سلوك |
| حساب مستخدم، إقرار إثبات، نموذج،embedding، تخزين ابتدائي تحويل | لا | هو |
| مزود بيانات ترحيل، إعادة محاولة، انهيار انهيار استعادة | لا | هو |

عام stdio نقل سوف صاف حذف بيئة في اسم صنف يشبه اعتماد متغير و `DSH_*` متغير، معا وراثة أخرى بيئة متغير. أساس خط عرض مثال فقط إضافة مطلوب تغطية بند؛ اختياري مزود مفتاح يجب إضافة إلى `config.env`، أو إعداد في مزود ذاتي ذات ملف في.

## إصدار ثابت، تخزين و هوية

| مزود | قد اختبار اتفاق |
|---|---|
| Memorix | npm `1.3.0`،tag commit `500792cad3144142293bfbb20acb4841c9f7fcfa` |
| MCP Reference Memory | npm `2026.7.4`،package commit `6dd0a683e198783e30feabf7abaf42f925bd18b1` |
| Engram | tag `v1.20.0`،commit `ba9e46ced152c37a7cb9e576153c41995873e2fc` |

تخزين ما زال من مزود مسؤول.Memorix افتراضي استخدام `~/.memorix/data`،Engram افتراضي استخدام `~/.engram`.Reference Memory عرض مثال ضبط مستقر `$HOME/.dsh-mcp-reference-memory.jsonl` مسار، بينما لا هو كتابة قد تثبيت npm حزمة دليل. كل مزود ذاتي ذات بيئة متغير كل يمكن في DSH بدء قبل تغطية هذه موضع.

مشروع هوية ما زال من مزود مسؤول:Memorix و Engram استخدام DSH عمل دليل في Git مشروع، منها Engram أيضا يمكن اختيار قبول `ENGRAM_PROJECT`.

## نموذج إشارة توجيه

عرض مثال لن تعديل `@deepseek-ai/dsh-system-prompt`: إعداد patch سوف استبدال بعض عدد بند إعداد كامل إعداد، ممكن مسح حذف قد لديه persona.README تعديل لـ توفير واحد بند اختياري مرفق إضافة إشارة أمر:

> عند مستخدم اشتراط أنت تسجيل إقامة بعض عنصر أمر وقت، استدعاء تسجيل ذاكرة كتابة أداة. عند تاريخ معلومة ممكن متبادل صلة وقت، بحث تسجيل ذاكرة و استخدام متبادل صلة نتيجة.

مزود أداة وصف ما زال هو مرجعي تعريف.

## تحقق اتفاق

بعيد مسار CI لن وصول رقم ثلاثة جهة خدمة أو إزالة استهلاك مفتاح. بلا مفتاح طقم عنصر تحليل الكل ثلاثة نسخة overlay ملف، فحص ذلك عام جسر وصل جهاز و مفتاح حد، سوف فوق تنقل طرف نقطة استبدال لـ حزمة ذاتي حمل MCP fixture(اختبار قبل وضع بيانات) خادم، عبر حقيقي Cordis Loader بدء، و تحقق أداة اكتشاف.

دمج قبل، كل ثابت إصدار مزود كل يجب قسم آخر توفير التالي شخص عمل دليل:

1. DSH جلسة A استدعاء كتابة أداة، لـ واحد وحيد قيمة كتابة تسجيل ذاكرة، و استلام إلى نجاح نتيجة.
2. جديد DSH جلسة B في نفسه مزود تخزين نطاق تحت استدعاء بحث أو استدعاء عودة، لا استعارة مساعدة جلسة A transcript(نص سجل) سهل يمكن إرجاع هذا قيمة.
3. جلسة B في لاحق عودة جواب في استخدام هذا استدعاء عودة قيمة.

«جديد جلسة» هو إشارة نفس عدد Host في جديد بناء DSH جلسة، لا حاجة إعادة بدء Host. عام MCP عميل بـ مختلف خطوة طريقة اكتشاف أداة، عملية فرعية أو HTTP نقل إغلاق بعد لن تلقائي إعادة وصل؛ تحقق سوف في رقم واحد جولة قبل انتظار أداة ظهور، و كما فقط في انهيار انهيار بعد استخدام HMR أو إعادة بدء Host.

## اعتبار مرور بديل خطة

**كل مزود استخدام واحد DSH إضافة.** غير مقبول، لأن هذا سوف تكرار MCP قد معيار تحويل إقرار إثبات، إعداد، دورة الحياة و أداة حزمة تركيب طبقة، و مع حال كل زيادة واحد مزود بينما توسيع كبير صيانة نطاق.

**تسجيل ذاكرة مزود مسبق ضبط سجل التسجيل.** غير مقبول، لأن سجل التسجيل سوف يجعل رقم ثلاثة جهة إصدار و دفع ترشيح نظر بدء قدوم مثل تلقي دعم حمل DSH منتج واجهة. يمكن نسخ overlay يجعل كل حق و إصدار انحراف نقل إبقاء مرئي.

**في MCP بند إعداد داخل تشغيل `npx` أو `go run`.** غير مقبول، لأن استكشاف قياس جدول واضح أول مرة npm تحت تحميل ممكن تجاوز مرور MCP ابتدائي تحويل مهلة، بينما في قطع `npx` ذاكرة مؤقتة ممكن تغيير نيل غير ممكن استخدام.DSH مسؤول بدء خادم عملية، لا هو مزود حزمة إدارة جهاز. ثابت إصدار تثبيت أمر يخص صريح قبل وضع شرط.

**من عام MCP عميل حقن مشترك استخدام إشارة أمر.** غير مقبول، لأن هذا جسر وصل جهاز أيضا خدمة في غير تسجيل ذاكرة صنف MCP خادم، بينما كما عام نص التوجيه تغيير سوف يأخذ مزود دلالة إعادة حمل دخول مشترك وقت التشغيل شفرة.

## عاقبة

اختيار واحد ملف بعد، نموذج يمكن استخدام مزود اكتشاف إلى كامل MCP أداة واجهة؛ أداة schema و token صار هذا من مزود قرار. إزالة `--config` حينئذ سوف إزالة تسجيل ذاكرة خادم. مستخدم مباشر قبول كل فوق تنقل سماح يمكن إثبات، بيانات سياسة سياسة، سحابة خدمة استهلاك استخدام و تشغيل صيانة نمط.

عام خطة يحل محل مبكر مدة إبرة مقابل خاص تحديد مزود تعديل. لم قدوم ظهور مزود إصدار انحراف نقل وقت، فقط يحتاج تحديث و إعادة تحقق واحد نسخة صغير نوع عرض مثال ثابت إصدار، لا لا بد نحو DSH إضافة وقت التشغيل فرع.
