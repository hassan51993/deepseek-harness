# Agent Note: System prompt expands into the opaque context body

Status: implemented
Archived: 2026-09-04

[English](2026-08-17-web-system-prompt-opaque-body.md) | العربية

## Problem

Chat `توجيه النظام` سطر و سياق حقن مشترك استخدام `DisclosureRow` خارج قشرة، ذلك توسيع محتوى منطقة حاجة عرض طلب system حقل. إذا يأخذ هذا حقل تصيير صار Markdown——عنوان، قوي ضبط، قائمة——قراءة من يرى سوف هو نموذج من لم استلام إلى ترتيب إصدار وثيقة. سياق حقن قد استخدام 141px شفرة كتلة تمرير منطقة و إبقاء نموذج الذي رؤية بايت و تبديل سطر `<pre>` نص حل قرار نفس عنصر أمر، لذلك هذا سطر حاجة إعادة استخدام هذا واحد عرض، بينما لا هو مجددا صنع واحد طقم.

## Decision

`SystemPromptRow` توسيع بعد تركيب و لا نفاذ واضح سياق حقن نفسه محتوى منطقة. هو إعادة استخدام `ContextInjectionRow.module.css` Figma 10:2482 141px تمرير منطقة، و يأخذ حمل دائم `request/header` system نص بصفة واحد كتلة نص تسليم إعطاء `OpaqueBody`، لذلك توسيع بعد يرى هو حمل حقيقي تبديل سطر نموذج مرئي نص، و نفسه 20_000 محرف عرض حد أعلى. هذا سطر افتراضي طي، ما زال لا يوجد تدفق صيغة مسار. هو لا زيادة إنتاج من وسم،form علامة أو source حقل قائمة:system حقل هو header فوق واحد مقطع تجميع وصل نص، لا هو حمل source `user/message`.

## Alternatives considered

**في بطاقة صيغة محتوى منطقة داخل تصيير تسوية بعد Markdown.** خارج قشرة يمكن مقابل متساو، لكن Markdown سوف تعديل كتابة نموذج قراءة إلى محتوى. عنوان أو إضافة خشن هو آخر نسخة وثيقة، لا هو طلب داخل بايت.

**يأخذ تجميع وصل بعد system نص تفكيك صار snapshot قسم مقطع.** حمل دائم header فقط حفظ تجميع بعد نص. عميل ظن صنع قسم مقطع حد سوف يأخذ سجل لم تسمية متن عودة إلى بعض عدد فرعي نظام، استعادة أو خارج قدوم header أيضا لا يمكن إعادة بناء هذه قسم مقطع.

**مباشر مشي `ContextInjectionRow`.** ذلك واحد سطر موجه إلى حمل source user-role رسالة: هو علامة زاوية لون، عرض إنتاج من، و حسب form اختيار محتوى منطقة.system حقل هو آخر عنصر حمل دائم واقع، لا يوجد هذه حقل.

## Consequences

اثنان موضع توسيع الآن مشترك استخدام نفس طقم محتوى منطقة خارج قشرة و نفس طقم نص عرض، لذلك بعد تعديل 141px تمرير منطقة أو لا نفاذ واضح عرض حد أعلى سوف معا أثر إلى اثنان حافة. بديل قيمة هو مقارنة طويل توجيه النظام في 141px بينما لا هو 360px داخل تمرير، نص التوجيه داخل Markdown علامة سوف بـ محرف شكل صيغة مرئي.

## Testing
