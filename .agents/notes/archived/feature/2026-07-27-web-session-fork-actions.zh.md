# Agent Note: Web session fork عملية

Status: implemented
Archived: 2026-09-04

[English](2026-07-27-web-session-fork-actions.md) | العربية

## Problem

Session store قد توفير حسب إتمام جولة بادئة إنشاء فرعي جلسة fork أصل لغة، لكن Web طرف لا يوجد واحد نسخة موحد واحد تفاعل اتفاق.Session سطر قائمة مفرد فقط قدرة جدول بلوغ «من الأكثر جديد إتمام جولة فرع» ، رسالة IconActions أيضا حاجة جدول بلوغ «من هذا بند رسالة الذي في جولة فرع» ؛ إذا اثنان موضع كل منها حل تفسير حد، تبديل و فشل سلوك، نفس عدد مستخدم حركة عمل سوف شكل صار اثنان طقم دلالة. يأخذ fork فرعي جلسة تضمين طقم في مصدر جلسة تحت أيضا سوف يجعل جديد اختيار في فرعي جلسة اعتماد أصل أولا توسيع حالة عندئذ قدرة نظر رؤية، و تقليل ضعيف workspace يد حركة ترتيب ترتيب نموذج.

## Decision

هذا قرار في رسالة مورد إطار جزء من[قد إتمام جولة ذيل جزء قرار](../bug-fix/2026-08-02-message-fork-actions-require-completed-turn-tail.zh.md) استلام ضيق؛ مشترك وقت التشغيل عملية، حقن ملكية، عنوان معالجة و نفس درجة قائمة قرار ما زال صالح.

Web session سطر قائمة مفرد و رسالة IconActions مشترك استخدام client runtime `sessions.fork` عملية.Session سطر نقل `{ sessionId, increaseTitle: true }`، لذلك في مصدر جلسة الأكثر بعد واحد قد إتمام جولة موضع فرع؛ رمز دمج شرط كما يقع في قد إتمام جولة ذيل جزء رسالة نقل `{ sessionId, atSeq: node.seq, increaseTitle: true }`، لذلك في بـ هذا رسالة انتهاء جولة موضع فرع.`increaseTitle` فقط من client إزالة استهلاك: فرعي جلسة دخول محلي قائمة بعد،client يأخذ مصدر جلسة حفظ دائم عنوان ذيل جزء `(N)` أو `(N)` تمرير زيادة و إبقاء تضمين رقم مثال صيغة، بلا تحرير رقم وقت إلحاق ` (1)`، لا يوجد حفظ دائم عنوان وقت لا تعديل اسم؛Host fork طلب ما زال فقط لديه `sessionId` و اختياري `atSeq`. تعديل اسم نجاح بعد استدعاء جهة عندئذ فتح فرعي جلسة؛fork أو تعديل اسم فشل وقت إبقاء مصدر جلسة و حالي اختيار ثابت، تعديل اسم فشل وقت قد إنشاء فرعي جلسة ما زال إبقاء في قائمة في.

`forkAt(seq)` فقط في ui-conversation apply حقن طبقة وصل لمس session خدمة، رسالة مكون فقط عودة نقل حدث `seq`.Session سطر نفس إدارة فقط عبر ui-workspace حقن عودة ضبط إرسال بدء عملية؛ اثنان عدد عرض حزمة كل لا يحتفظ session mutation حالة، أيضا لا نسخ host حد طلب قيمة.

Session lineage لا إسقاط صار قائمة طبقة درجة.WorkSpace نمط حسب `WorkspaceView.sessionIds` يد حركة ترتيب يأخذ مصدر جلسة و كل fork فرعي جلسة عرض لـ نفس درجة سطر، كل سطر كل يمكن مستقل فتح، بحث و سحب جر؛In one list نمط متابعة حسب `updatedAt` صارم إطار ترتيب ترتيب؛Ungrouped مجموعة في لا يوجد workspace حساب هذا وقت أيضا حسب recency ترتيب ترتيب.`parentId` ما زال لأجل lineage و لاحق استعلام، لكن لا تحكم session قائمة مرئي صفة.

## Alternatives considered

**فقط وصل session سطر قائمة مفرد.** مرفوض: مستخدم في رسالة موضع قد اختيار أكثر دقيق سياق، قوي إجبار ذلك عودة إلى قائمة فقط قدرة تراجع تحويل لـ الأكثر جديد إتمام جولة، كما قد عرض رسالة فرع رسم علامة سوف يصبح بلا استجابة تحكم عنصر.

**فقط سماح مستخدم رسالة فرع.** مرفوض: قد تحديد مسودة assistant محتوى نفس مثال لديه مستقر حدث `seq`،host سوف يأخذ هو عودة دخول الذي تابع إتمام جولة؛ يجعل اثنان عدد خارج مراقبة نفسه فرع حسب زر فقط لديه واحد متاح سوف صنع صنع غير ممكن رؤية سلوك فرق مختلف.

**حسب `parentId` يأخذ fork فرعي جلسة تضمين طقم في مصدر جلسة تحت.** مرفوض:lineage لا هو تنقل كل حق؛ تضمين طقم اشتراط تلقائي توسيع أصل أولا عندئذ قدرة نظر رؤية حالي بند، و يجعل فرعي جلسة لا يمكن مشاركة و workspace نفس درجة يد حركة ترتيب ترتيب.

**من رسالة مكون مباشر استدعاء session خدمة.** مرفوض:client مكون لا نيل وصل لمس `ctx` أو عمل خدمة خدمة؛ حقن عودة ضبط يجعل mutation إبقاء في apply عالم حد، مكون إبقاء صاف props.

## Consequences

مستخدم يمكن من session سطر أو رمز دمج شرط قد إتمام جولة ذيل جزء رسالة إنشاء فرع، اثنان موضع نهائي مشي نفس عدد runtime/host عملية؛ رسالة نقطة موضع إبقاء دقيق حدث حد، قائمة نقطة موضع إبقاء «الأكثر جديد إتمام جولة» سريع سريع دلالة. وصل متابعة fork عنوان حسب `(1)`،`(2)` تمرير زيادة، بينما لا هو تكرار إلحاق `(1)`؛ كل زاوية تضمين رقم عنوان إبقاء كل زاوية مثال صيغة. كل fork فرعي جلسة قيام أي بصفة عادي نفس درجة سطر ظهور، قائمة لم يعد حاجة session توسيع حالة، تمرير عودة عقدة أو twist تحكم عنصر.

Fork و فرعي جلسة تعديل اسم فشل كل إبقاء ساكن صامت و إبقاء مصدر اختيار، تجنب تجنب واحد إرسال توليد عملية كسر تالف حالي قراءة قراءة موضع؛ هذا أخذ ترك أيضا معنى طعم حال UI مؤقت لا توفير فشل سبب أو إعادة محاولة مدخل. حزمة درجة اختبار ثابت رمز دمج شرط رسالة `seq` تحويل إرسال، عنوان تمرير زيادة و نفس درجة قائمة إرسال توليد،`apps/web/tests/message-actions.e2e.ts` عبر تركيب إعداد بعد تطبيق تنفيذ assistant رسالة فرع و session سطر قائمة مفرد فرع.
