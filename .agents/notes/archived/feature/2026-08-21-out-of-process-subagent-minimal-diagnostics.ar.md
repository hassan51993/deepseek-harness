# Agent Note: عملية خارج subagent عام الأكثر صغير يمكن سطر حركة تشخيص

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-out-of-process-subagent-minimal-diagnostics.md) | العربية

## Problem

ACP أو DSH SDK عملية فرعية ممكن لأن بلوغ إلى بعيد طرف حد، رفض مطلوب إذن، بـ غير إتمام فرعي جولة انتهاء، فقد ذهاب بروتوكول نقل أو عملية خروج بينما إيقاف. مشترك نتيجة بـ نحو فقط يأخذ هذه نتيجة ضغط صار `error` انتظار انتهاء سبب، بينما بدء و تنظيف رفض رسالة أيضا ممكن كشف أصلي استثناء. أب agent إذا لا قراءة Host سجل، حينئذ لا يمكن قرار ينبغي تقليص صغير مهمة، ضبط كامل إذن سياسة أيضا هو إصلاح فرعي وقت التشغيل نشر.

إذا يأخذ استثناء،stderr، مهمة محتوى، أداة إدخال، مسار، بيئة قيمة، سند إثبات أو بروتوكول payload نسخ دخول `SubagentResult.diagnostic`، لا تلقي معلومة مهمة عملية فرعية نص حينئذ سوف تغيير صار نموذج مرئي محتوى. إذا إعادة استخدام كامل منتج مخصص تابع خطأ ربط دمج، أيضا سوف في مزود غير متصل [subagent seam](2026-06-21-subagent-capability-seam.ar.md) في نسخ ذاك هذا مستقل إصدار تحويل مرجعي.

## Decision

كل عملية خارج مزود قسم آخر يملك واحد نسخة صغير نوع خريطة، يأخذ ذلك بروتوكول و عملية دورة الحياة موضع قد استلام إلى واقع تحويل صار ثابت أمان عرض نص.ACP مزود استخدام إغلاق تجميع انتهاء سبب، حالي عملية، إغلاق تجميع أداة نوع صنف، قد إعداد إذن سياسة، اختيار في إذن نتيجة، و تلقي إدارة عملية فرعية خروج رمز أو إشارة قدوم إرسال توليد.DSH SDK مزود استخدام فرعي `turn/end` سبب، حالي SDK عملية و توجيه خروج SDK خطأ class قدوم إرسال توليد. مستهلك متابعة استخدام قائم اختياري `SubagentResult.diagnostic`، كما لا تحليل ذلك علامة نقطة أو مزود خاص category اسم.

### أمان فشل نص

عام error تشخيص اعتماد التالي ثابت حقل ترتيب:

```text
Subagent failure (provider: <provider>; stage: <stage>; category: <category>; stop reason: <reason>; exit code: <code>; signal: <signal>)
```

غير ممكن استخدام اختياري حقل سوف يتم حذف. مشترك تسوية حد سوف يأخذ كامل نتيجة حد في 4096 عدد UTF-8 بايت بـ داخل. نجاح نتيجة و محلي إلغاء لا يحمل فشل تشخيص. جزء assistant إخراج متابعة إبقاء في `SubagentResult.output` في، و و تشخيص قسم فتح عرض.

عند ACP إذن طلب مشاركة و غير إتمام نتيجة وقت، واحد ثابت سطر سوف سجل `policy`،ACP إغلاق تجميع أداة `request` نوع صنف و `decision`. أداة عنوان،raw input، موضع، خيار اسم و metadata متساو يتم ترتيب حذف. مقابل في `max-tokens`،`refusal` أو بعيد طرف `aborted`، عام مشترك انتهاء سبب قد يحمل نهاية حالة واقع، لذلك إذن سطر حينئذ هو كامل تشخيص؛ عام error مسار فإن يأخذ هو مرفق في فشل سطر بعد. حمل تشخيص بعيد طرف `aborted` نتيجة ما زال إبقاء عام مشترك انتهاء سبب؛ مرة صفة Job adapter سوف يأخذ هو حكم لـ failed، بينما لا حمل تشخيص محلي إلغاء ما زال هو killed.

### ACP واقع

| Stage | ملكية عملية | أمان category و واقع |
| --- | --- | --- |
| `initialize` | أب مساحة العمل تحليل و ACP initialize | `configuration`،`transport` أو `process-exit` |
| `new-session` | ACP `session/new` و إرجاع session id تحقق | `protocol`،`transport` أو `process-exit` |
| `prompt` | ACP prompt طلب، بعيد طرف انتهاء سبب و إذن عودة ضبط | `remote-limit`،`transport`،`unknown` أو فقط إذن تشخيص |
| `process` | عملية فرعية spawn فشل، أو تلقي إدارة عملية فرعية أولا في prompt نهاية حالة استجابة خروج | `process-start`، أو `process-exit` و قسم آخر مراقبة قياس إلى خروج رمز و إشارة |
| `teardown` | EOF توقف مستقر و تلقي إدارة عملية شجرة إنهاء | ثابت teardown واقع؛ أصلي تنظيف فشل ما زال إبقاء في داخلي |

`max_turn_requests` متابعة خريطة إلى مشترك `error`، و مرفق إضافة `remote-limit`. لم معرفة انتهاء سبب متابعة خريطة إلى `error`،category ثابت لـ `unknown`، لن نسخ أصل قيمة.`max_tokens`،`refusal` و `cancelled` إبقاء قائم مشترك انتهاء سبب؛ فقط لديه حاجة حل تفسير إذن قرار وقت عندئذ سوف مرفق إضافة تشخيص.

### DSH SDK واقع

| Stage | ملكية عملية | أمان category و واقع |
| --- | --- | --- |
| `initialize` | أب مساحة العمل تحليل،SDK وقت التشغيل spawn و initialize إمساك يد | `configuration`،`protocol`،`transport` أو `unknown` |
| `session-run` | prompt قبول، جلسة إشعار و نهائي فرعي جولة سبب | `child-error`،`child-disposed`،`child-unknown`،`missing-terminal`،`protocol`،`transport` أو `unknown` |
| `shutdown` | محدود SDK shutdown و وقت التشغيل عملية تحرير | `unknown`؛ بروتوكول shutdown فشل ما زال إبقاء في SDK عميل Host تشخيص في |

فرعي `completed`،`max-tokens` و عادي `aborted` نتيجة إبقاء قائم مشترك انتهاء سبب، لا مرفق إضافة نص. إغلاق تجميع سبب هو `disposed` `aborted` جولة ما زال إبقاء `aborted`، و مرفق إضافة `child-disposed`.`blocked` إعادة استخدام `refusal`؛`error` مرفق إضافة `child-error`. فقط لديه حفظ دائم إصلاح سوف إنتاج `interrupted`، لذلك هذا كل جديد جلسة مزود يأخذ هو إبقاء لـ لا حمل تشخيص عام `error`. ناقص نهاية حالة حدث سوف مرفق إضافة `missing-terminal`؛ لم معرفة سبب استخدام `child-unknown`، كما لا نسخ أصل قيمة أو عملية فرعية بنية تحويل فشل رسالة.

في initialize أو session run خلال،`SdkProtocolError` و JSON-RPC خطأ استجابة خريطة لـ `protocol`،`TransportClosedError` خريطة لـ `transport`؛ مزود أبدا قراءة ذلك رسالة. أخرى استثناء و shutdown رفض استخدام `unknown`. من في هذا مزود لا يوجد إعداد أو نقل بث request timeout، طلب مهلة تصنيف متابعة دفع متأخر.

### كل حق و دورة الحياة

| واقع أو مورد | Owner | مستهلك سلوك |
| --- | --- | --- |
| بروتوكول نهاية حالة واقع | ACP server أو فرعي Harness Session | كل مزود فقط خريطة ذاته يملك إغلاق تجميع قيمة، و استخدام ثابت unknown رجوع |
| حالي فشل stage و operation-local دقيق عقدة | مفرد مرة مزود تشغيل | فقط في فشل نقطة إرسال توليد، و مع تشغيل إسقاط؛ تزامن تشغيل لا مشترك تشخيص حالة |
| خروج رمز و إشارة | ACP `dsh-subprocess` جملة مقبض | فقط في مراقبة قياس إلى تلقي إدارة نتيجة بعد عرض؛ أبدا تحليل stderr |
| SDK خطأ category | TypeScript SDK عميل خطأ class | فقط عبر `instanceof` تصنيف؛Error رسالة و stderr tail إبقاء في داخلي |
| تشخيص بايت و عرض | `dsh-subagent`، قبل منصة أداة و Job وقت التشغيل | قبل منصة و مرة صفة خلفية نمط كل يأخذ نفس نسخة محدود نص و assistant إخراج قسم فتح |
| أصلي فشل | فرعي وقت التشغيل،Error cause سلسلة و Host logger | فقط توفير Host ترتيب عائق، أبدا نسخ دخول أب نموذج نتيجة |

بدء فقط لديه في مزود إمساك يد إتمام بعد عندئذ إصدار تشغيل. بدء تنظيف نجاح وقت، خاص عملية فرعية سوف أولا تراجع إلى تماما توقف مستقر مجددا رفض. تنظيف فشل وقت، عادي فشل سوف إبقاء بدء و teardown/shutdown، إلغاء بعد فقط إبقاء تنظيف واقع، كما لن إعلان تسمية تلقي إدارة عملية قد تماما توقف مستقر. قد إصدار تشغيل نتيجة لن رفض، بينما `dispose()` سوف مستقل تقرير إبلاغ أمان teardown أو shutdown واقع، و متابعة استخدام خلفية قائم عملية تنظيف مرحلة سلم.

## Verification

ACP حزمة اختبار عبر حقيقي stdio بروتوكول عملية فرعية ثابت الكل انتهاء سبب خريطة، بعيد طرف حد و unknown رجوع، إذن allow/deny واقع،configuration،initialize،new-session،prompt،process و teardown stage، بدء تراجع، نجاح نتيجة و محلي إلغاء حذف، جزء إخراج، تزامن تشغيل عزل، فقط Host مرئي أصلي خطأ، عملية تماما توقف مستقر، و مشترك كثير بايت تشخيص حد.DSH SDK حزمة اختبار عبر حقيقي SDK عميل قيادة ذلك stdio زائف وقت التشغيل، ثابت الكل يمكن بلوغ فرعي جولة سبب، حالي typed SDK category،initialize/session-run/shutdown stage،SDK ذاتي لديه فشل بدء تنظيف، محلي إلغاء تنظيف، جزء إخراج، تزامن، انفصال حساس و توقف مستقر.Loader تركيب إثبات اثنان عدد حقيقي إعداد مزود كل قدرة وصول نموذج مرئي قبل منصة نتيجة. بلا مفتاح ACP و JSON-RPC snapshot سوف ثابت كل منها مزود دقيق تأكيد قبل منصة و مرة صفة خلفية تشخيص نص.

## Alternatives considered

**إرجاع أصلي استثناء،stderr أو بروتوكول payload.** هذه قيمة ممكن يتضمن مهمة محتوى، أداة إدخال، مسار، بيئة قيمة، سند إثبات و فوق تنقل نص. ثابت أبيض اسم مفرد واقع قدرة كاف إبقاء يمكن سطر حركة فرق مختلف، بينما لا توسيع كبير نموذج مرئي معلومة مهمة حد.

**زيادة مشترك بنية تحويل خطأ enum.** ACP و أخرى عملية خارج مزود يملك مختلف دورة الحياة موضع و إغلاق تجميع إنهاء مفردات. مشترك enum سوف صنع صنع وهمي زائف موحد واحد، و إجبار جعل غير متصل مستهلك تتبع مع مزود إصدار.

**تحليل استثناء رسالة أو stderr قدوم تصنيف.** ذاتي من نص حيث لا مستقر أيضا لا أمان. فقط لديه إغلاق تجميع بروتوكول قيمة،typed خطأ، حالي استدعاء موضع و تلقي إدارة عملية نتيجة يمكن يصبح تشخيص إدخال.

**تعديل قائم انتهاء سبب.** انتهاء سبب متابعة يمثل مزود غير متصل نهاية حالة نتيجة. اختياري تشخيص شرح غير إتمام نتيجة لـ أي اشتراط مختلف تحت واحد خطوة، بينما لا زيادة جديد عام مشترك نتيجة حالة.

**زيادة إعادة محاولة، استعادة حالة أو تفاعل مراجعة دفعة.** تشخيص فقط مسؤول تقرير إبلاغ فشل، لا يملك إصلاح حركة عمل. إعادة محاولة سياسة، جلسة استعادة و شخص عمل تفاعل حاجة مستقل مستخدم اتفاق و دورة الحياة مسؤولية مهمة جهة.

## Consequences

أب agent يمكن منطقة قسم ACP بعيد طرف حد أو إذن قرار، و DSH فرعي جولة، بروتوكول، نقل أو shutdown فشل، معا لن استقبال عملية فرعية تحكم نص. بدء و تنظيف خطأ و قد إصدار نتيجة استخدام نفس طقم أمان واقع، بينما Host مراقبة قياس ما زال إبقاء أصلي cause.

تشخيص ما زال هو عرض نص، لا هو عام مشترك بروتوكول. مستهلك يمكن عرض هو، لكن لا نيل حسب صيغة فرع. هذا قرار لا زيادة إعادة محاولة سياسة، استعادة تحكم جهاز، مشترك مزود خطأ enum،stderr تصنيف جهاز، إقرار إثبات تصنيف، جلسة حفظ دائم، دخول درجة تدفق أو جديد ACP قدرة.
