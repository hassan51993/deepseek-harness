# Agent Note: `dsh web` فتح قد حينئذ خيط صفحة

Status: implemented
Archived: 2026-09-04

[English](2026-08-12-open-ready-web-ui.md) | العربية

## Problem

`dsh web` سوف ربط HTTP خادم و ضرب طبع مواصفة محلي URL، لكن ما زال اشتراط مستخدم يأخذ URL نسخ إلى متصفح، كل إدارة أصل README قد يأخذ هذا أمر وصف لـ سوف فتح Web UI. متصفح تسليم وصل أيضا لا يستطيع فقط بـ خادم ربط عودة ضبط لـ وقت آلة:API توجيه، متصفح إضافة اسم تسجيل و ساكن حالة رجوع ممكن ما زال في تركيب، رقم مرة صفحة طلب ممكن يرى واحد بعد لم كامل كما أي سوف يتم عملية حكم تحديد لـ بدء فشل تطبيق.

## Decision

Web تطبيق أمر مزود لـ عادي استدعاء تحليل خروج `openBrowser: true`، لـ `--no-open` تحليل خروج `false`. تركيب حزمة يأخذ هذا قيمة نقل إعطاء ذاتي ذات `web-runtime` سطر؛ نشر ما زال يمكن صريح استبدال هذا سطر كامل إعداد. وقت التشغيل في تنشيط خلال مقابل وراثة `SSH_CONNECTION` و `SSH_TTY` أخذ مثال مرة، فقط يلزم منها واحد بند غير فارغ حينئذ سوف قفز مرور متصفح تسليم وصل، لأن هذا وقت عملية توفير هو بعيد طرف مضيف آلة loopback، بينما مستخدم محلي تحويل إرسال عنوان من SSH عميل أو تحرير جهاز يحتفظ.

Web وقت التشغيل يأخذ URL ضرب طبع و متصفح فتح بصفة نفس حينئذ خيط نقطة فوق اثنان عدد مستقل حركة عمل. هو انتظار كامل Loader إعداد شجرة تسوية، و تأكيد `webServer` ما زال في خط، لكن بعد ضرب طبع قد إعداد URL سطر؛ غير SSH بيئة تحت أيضا سوف في يأخذ مواصفة loopback URL تسليم إعطاء عملية نظام افتراضي متصفح قبل قيام أي ضرب طبع إنجليزي نص تلميح `dsh web: opening the default browser; pass --no-open to disable`.SSH بدء سوف إبقاء مضيف آلة URL سطر، بـ سهل عملية من تعرف آخر بعيد طرف طرف فتحة، لكن عملية لا يمكن دفع توجيه أو فتح تحويل إرسال يحتفظ جهة محلي عنوان. نشر صريح ربط كل شبكة شبكة واجهة وقت، هذا آلة ما زال فتح loopback، ضرب طبع خروج LAN URL فقط لأجل إبلاغ معرفة؛CLI سوف رفض `--host 0.0.0.0`.`openBrowser` و `printUrl` يمكن قسم آخر إغلاق.

تسليم وصل استخدام صيانة في `open` حزمة معالجة macOS،Windows،Linux، حاوية و WSL. واحد قصير دورة الحياة Node helper استخدام مواصفة انفصال حساس عملية فرعية بيئة استدعاء هذا حزمة، لذلك Harness اعتماد و `DSH_*` حالة لن دخول عملية نظام بدء جهاز أو جديد بدء متصفح.`BROWSER` هو فقط قدرة قدوم ذاتي بدء بيئة أمر اختيار جهاز: تطبيق بدء مرور مسار سوف رفض يتم اكتشاف `.env` في هذا متغير، فقط لديه وراثة قيمة عندئذ قدرة مقاومة بلوغ سوف قراءة هذا متغير توافق opener مسار. في Windows فوق،helper سوف انتظار قصير دورة الحياة PowerShell launcher خروج، لأن `open` سوف في هذا عملية spawn وقت، بعد لم يأخذ URL تسليم إعطاء shell قبل إرجاع؛ أخرى منصة فإن في opener قبول spawn بعد انتهاء. وقت التشغيل أبدا انتظار متصفح خروج. أب عملية سوف قراءة helper stderr، لذلك فشل وقت فقط نحو stderr كتابة واحد بند يتضمن أداة جسم سبب و يد حركة وصول URL إنجليزي نص تشخيص، لن dispose قد حينئذ خيط خادم؛ متصفح بعد خروج لا يخص هذا مرة تسليم وصل نتيجة.

وحدة تغطية تثبيت إقامة أمر قيمة افتراضية،`--no-open`،SSH كبح صنع، حينئذ خيط ترتيب، مورد تحرير و فشل كبح صنع،helper نتيجة،stderr سبب نقل بث،Windows launcher دورة الحياة،helper انفصال حساس بيئة،`BROWSER` فقط يمكن وراثة قاعدة، تسليم وصل قبل opt-out تلميح و يتضمن سبب غير يؤدي أمر تشخيص. حقيقي Loader تركيب سوف ربط من عملية نظام قسم إعداد طرف فتحة، توفير فعلي ساكن حالة رجوع، فقط استبدال عملية نظام تسليم وصل، و قيام أي طلب يتم تسليم وصل URL، بـ إثبات صفحة هذا وقت قد يمكن وصول. بلا مفتاح كامل جسم لقطة سوف قسم آخر في هذا آلة بيئة،opener فشل بيئة، حمل VS Code و SSH علامة بيئة، و إعلان `BROWSER` مشروع في تشغيل بناء بعد `dsh web` أمر: هذا آلة حالة استخدام تحقق يتم تسليم وصل صفحة حينئذ هو ضرب طبع خروج، قد يمكن وصول كما يتضمن بدء بيان صفحة، معا opener في لا وجود اعتماد و Harness حالة متغير؛ فشل حالة استخدام تحقق حينئذ خيط بعد stderr سبب و يد حركة URL؛ بعيد طرف حالة استخدام تحقق مضيف آلة URL ما زال مرئي، لكن لن بدء متصفح؛ ملف طبقة أمر حالة استخدام فإن في حينئذ خيط أو تسليم وصل قبل فشل. مستودع داخل متصفح و تحزيم اختبار سوف نقل دخول `--no-open`، لأن هو جمع ذاتي سطر يحتفظ متصفح أو في بلا شخص قيمة حراسة بيئة تشغيل.

## Alternatives considered

**من CLI بدء جهاز فتح** — مرفوض، لأن بدء جهاز لحظة معنى فقط حل profile اختيار، لا يمكن أخذ نيل عملية نظام قسم إعداد طرف فتحة أو تطبيق ذاتي لديه Loader تسوية نقطة؛ يجعل هو حل هذه واقع سوف دفع قلب تطبيق ذاتي لديه أمر سطر قرار.

**في `dsh-host-webserver` ربط socket وقت فتح** — مرفوض، لأن هذا حزمة هو لا حل shell و قبل طرف عام توجيه تحميل جسم، بينما كما socket حينئذ خيط مبكر في تطبيق حينئذ خيط.

**أصل حسب TTY،CI، تحرير جهاز، عرض، حاوية أو WSL بيئة متغير دفع قطع هل فتح** — مرفوض، لأن هذه إشارة لا يستطيع إثبات مضيف آلة و متصفح قسم مغادرة، و سوف خطأ حكم قسم مغادرة طرفية و طاولة وجه بدء. غير فارغ `SSH_CONNECTION` أو `SSH_TTY` هو أكثر ضيق دليل: هو جدول واضح بعيد طرف مضيف آلة loopback URL و لا هو تحويل إرسال يحتفظ جهة محلي URL. غير SSH بدء ما زال إبقاء افتراضي فتح و توفير صريح `--no-open`.

**فتح متصفح قبل اشتراط حسب تحت Enter** — لا بصفة هذا آلة افتراضي سلوك، لأن هو سوف يأخذ عادي خادم بدء تغيير صار من stdin يحتفظ ثاني مرة تفاعل، و ترتيب حذف لا يوجد متاح طرفية طاولة وجه بدء أو تلقي مراقبة إشراف بدء. استدعاء جهة ذاتي سطر يحتفظ متصفح أو فقط حاجة خادم وقت، ما زال عبر `--no-open` صريح خروج.

**يد كتابة كل منصة أمر** — مرفوض، لأن URL فتح في macOS،Windows،Linux، حاوية و WSL فوق كل لديه مختلف. صيانة في اعتماد يحتفظ هذه منصة فرع، هذه الحزمة فقط إبقاء حينئذ خيط و فشل دلالة.

## Consequences

عادي هذا آلة `dsh web` استدعاء سوف أولا عام إبلاغ تلقائي تسليم وصل و ذلك `--no-open` خروج طريقة، مجددا فتح واحد قد حينئذ خيط صفحة، معا لن يجعل عام HTTP تحميل جسم شعور معرفة طاولة وجه بيئة، أيضا لن نحو طاولة وجه بدء جهاز كشف بيئة اعتماد.SSH استدعاء سوف ضرب طبع بعيد طرف مضيف آلة URL، لكن من SSH عميل أو تحرير جهاز مسؤول فتح تحويل إرسال بعد محلي عنوان. يتم اكتشاف `.env` إذا ضبط `BROWSER`، بدء حينئذ سوف فشل، بينما لا هو اختيار واحد يمكن تنفيذ ملف؛ سوف قراءة هذا متغير منصة opener فقط لديه في عملية من من بدء shell في export وقت عندئذ قدرة أخذ نيل هو. أخرى بلا شخص قيمة حراسة مستهلك يجب نقل دخول `--no-open`؛ تسليم وصل فشل وقت سوف نحو stderr كتابة سبب و يد حركة وصول URL، معا إبقاء متاح خادم.Web تطبيق إضافة جديدة قفل تحديد `open` اعتماد، مشترك عملية فرعية بيئة انفصال حساس جهاز و opener نقل تمرير منصة مساعد مساعدة حزمة؛ عملية نظام تسليم وصل نجاح بعد، هذا تطبيق لا يحتفظ، لا انتظار أيضا لا إنهاء متصفح.
