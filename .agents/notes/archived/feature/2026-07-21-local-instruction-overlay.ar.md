# Agent Note: افتراضي محلي إشارة أمر تغطية طبقة

Status: implemented
Archived: 2026-09-04

[English](2026-07-21-local-instruction-overlay.md) | العربية

## مشكلة

يتم git تجاهل اختصار عدد شخص إشارة توجيه ملف (`AGENTS.local.md` / `CLAUDE.local.md`) هو Claude Code واحد بند اتفاق، لأجل تخزين وضع لحظة معنى لا إيداع، كل موضع تطوير من كل منها تغطية محتوى.[agent-instructions إضافة](2026-06-24-workspace-context.ar.md) كل دليل فقط تحميل واحد مرشح، لذلك فقط لديه يأخذ بعض عدد `.local.` اسم حرف إضافة دخول `instructionFileCandidates` عندئذ قدرة قراءة إلى هو؛ بينما من في واحد دليل فقط لديه واحد فوز خروج من، هذا مثال فعل فقط سوف يجعل هو*حجب حجب*قد إيداع أساس أساس ملف، بينما لا هو تكملة ملء هو. هذا و هذه اسم حرف الذي داكن عرض «أساس أساس ملف إضافة عدد شخص تغطية طبقة» تراكم إضافة نموذج صحيح جيد متبادل عكس، بينما كما هو افتراضي هو إغلاق.

## قرار

إضافة لـ كل مشروع دليل مقدار خارج تحميل ثاني عدد مستقل مرشح قائمة.`localInstructionFileCandidates` افتراضي لـ `['AGENTS.local.md', 'CLAUDE.local.md']`، و و `instructionFileCandidates` اعتماد نفسه نفس دليل تحقق قدوم تحليل. في من مشروع أصل إلى جلسة cwd كل مشروع دليل في، إضافة أولا تحميل أساس أساس مرشح، لكن بعد تراكم إضافة تحميل محلي مرشح؛ محلي ملف ترتيب في أساس أساس ملف بعد، لذلك في بايت ميزانية لـ داخل ذلك محتوى أولوية درجة أكثر عال. اثنان عدد قائمة كل سوف في[حسب دليل محتوى ذهاب إعادة](2026-07-21-instruction-load-all-dedup.ar.md) لـ تحت كامل تحميل. سوف `localInstructionFileCandidates` وضع فارغ يكفي إغلاق هذا تغطية طبقة.

هذا قيمة افتراضية تعريف في إضافة `Config` schema في، بينما غير بعض عدد منتج `cordis.yml` داخل، لذلك كل تضمين دخول جهة (TUI،ACP،headless) قراءة `.local.` ملف سلوك متسق، نشر جهة أيضا يمكن في واحد موضع تغطية أو إغلاق هذا سلوك. هذا و إضافة ذاته يحتفظ `instructionFileCandidates` قيمة افتراضية إبقاء مقابل تسمية.

ثابت مستخدم عام ملف `$DSH_HOME/AGENTS.md` لا يوجد محلي تغطية طبقة، بداية نهاية فقط لديه أساس أساس ملف.

## كل مرشح كل منها مستقل scope

نفس دليل تحت أساس أساس مرشح و محلي مرشح، في أساس خط تجميد ربط، انتظار تحديد نافذة، إصدار ذاكرة مؤقتة و تنسيق ضبط مرور مسار في كل يجب ذاك هذا مستقل، لذلك مقابل منها واحد تعديل أبدا قدرة كبح صنع آخر عدد. الآن كل `(directory, candidateName)` مقابل كل هو كل منها مستقل scope مفتاح——مشاركة رؤية[حسب مرشح تخطيط قسم scope مفتاح](2026-07-21-instruction-load-all-dedup.ar.md) ، هو يحل محل هذا قبل أساس أساس/محلي طبقة درجة مراقبة جندي. اكتشاف مرور مسار في كل مشروع دليل في أولا مرة تاريخ أساس أساس قائمة، مجددا مرة تاريخ محلي قائمة،`reconcileInstructionContext` لـ كل دليل قطعة رفع كل إعداد مرشح،`probeScopeInstruction` فإن حل رمز مرشح اسم بـ دقيق قراءة هذا ملف. موجه إلى نموذج نص التوجيه من ملف عرض مسار دفع توجيه خروج توفير شخص قراءة قراءة دليل وسم، لذلك scope مفتاح دائم بعيد لن وصول نموذج.

## تجهيز اختيار خطة

**أكثر عال أولوية درجة أولا إلى أولا نيل (تحميل `.local.` بينما غير أساس أساس ملف).** مرفوض: واحد سوف استبدال قد إيداع ملف عدد شخص تغطية طبقة، سوف في تغطية طبقة وجود وقت إسقاط مشترك مشروع إشارة توجيه، هذا و Claude Code تراكم إضافة نموذج صحيح جيد متبادل عكس.

**عبر `instructionFileCandidates` إبقاء حسب يحتاج فتح بدء.** مرفوض: واحد دليل فقط لديه واحد فوز خروج من، لذلك إضافة دخول هذا قائمة `.local.` اسم حرف سوف حجب حجب أساس أساس ملف، بينما غير تكملة ملء هو.packages إشارة جذب اشتراط يأخذ حسب يحتاج فتح بدء بند ترتيب حذف في خروج مصنع افتراضي خارج، لكن هذا موضع قوي لديه قوة قائم فعلي ممارسة، و مستخدم مقابل `.local.` ملف مجموع سوف يتم قراءة مسبق مدة، ضغط مرور هذا واحد اعتبار كمية.

**في منتج `cordis.yml` طبقة وجه ضبط افتراضي، بينما غير في إضافة schema في.** مرفوض: هذا مثال فقط سوف لـ تسجيل نيل فتح بدء هذا وظيفة ذلك عدد منتج مدخل تفعيل `.local.`، من بينما في TUI/ACP/headless بين قطع شق سلوك، و تكرار واحد هذا ينبغي و قائم مرشح قيمة افتراضية وضع في واحد بدء أخذ قيمة.

**اثنان عدد طبقة درجة إعادة استخدام أصلي دليل بصفة scope مفتاح.** مرفوض: نفس دليل تحت أساس أساس ملف و محلي ملف سوف في كل بـ scope لـ مفتاح خريطة في اندفاع مفاجئ، في هو مقابل منها واحد تعديل سوف كبح صنع أو تغطية آخر عدد. لـ كل مرشح ضبط كل منها مستقل scope مفتاح يجعل اثنان من إبقاء مستقل، كما بلا حاجة توسيع حفظ دائم بيانات وصفية بنية.

**سوف تغطية طبقة توسيع إلى مستخدم عام scope.** مؤقت مؤقت:`$DSH_HOME` هو مفرد عدد ثابت `AGENTS.md`، لا يوجد يمكن توفير تكملة ملء قد إيداع أساس أساس ملف، لذلك في ظهور أداة جسم يحتاج طلب قبل بداية نهاية فقط لديه أساس أساس ملف.

## عاقبة

`.local.` إشارة توجيه في كل منتج في افتراضي يتم قراءة، بلا حاجة حسب نشر مفرد وحيد إعداد، و مجاور قريب أداة إبقاء متسق. كل مشروع دليل يمكن لـ كل وجود مرشح مساهمة واحد حمل دائم scope بينما غير فقط واحد، لذلك حركة حالة اكتشاف، تحرير و إزالة سوف قسم آخر مستقل أرض تنسيق ضبط أساس أساس ملف و محلي ملف. قد إصدار v0 أساس خط قد سجل[حسب مرشح تخطيط قسم](2026-07-21-instruction-load-all-dedup.ar.md) scope مفتاح. مستخدم عام scope ما زال فقط لديه أساس أساس ملف، هذا واحد نقطة بصفة معروف حد سجل في حزمة README في.
