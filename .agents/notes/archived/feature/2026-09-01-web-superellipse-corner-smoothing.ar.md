# Agent Note: Web superellipse corner smoothing

Status: implemented
Archived: 2026-09-04

[English](2026-09-01-web-superellipse-corner-smoothing.md) | العربية

## Problem

Web عميل داخل كل دائرة زاوية جدول وجه——بطاقة، إدخال إطار، حسب زر، طفو طبقة——كل بـ عادي دائرة قوس رسم صنع دائرة زاوية، مراقبة شعور واضح إظهار صلب في حالي طاولة وجه حديث يوم UI عام مرة اعتماد مستو انزلاق (صنف squircle) دائرة زاوية. هذا نوع مستو انزلاق شعور قدوم ذاتي في `@supports` حراسة حماية داخل تطبيق CSS `corner-shape: superellipse(1.5)`، بينما غير أكثر كبير نصف مسار أو حجب غطاء تقنية بارع؛ أداة صنف جسم نظام تنفيذ يأخذ هو تعليق إلى حذف صحيح دائرة خارج كل دائرة زاوية أداة صنف فوق. هذا عميل لا يوجد أداة صنف:`border-radius` بـ px حرف وجه كمية تفرق نشر في كل عميل حزمة CSS Modules في، لا يوجد يمكن موحد واحد تركيب هذا خاصية صنف قائمة؛ بينما صحيح دائرة شكل حالة (`border-radius: 50%` دائرة،999px لاصق كيس) يجب إبقاء دائرة قوس——تجاوز درجة بيضوي دائرة سوف يأخذ دائرة تغيير شكل لـ squircle، استخدام border رسم صنع تحميل حلقة دوران تحويل وقت سوف واضح إظهار تأرجح حركة، لاصق كيس اثنان طرف أيضا سوف تغيير جهة.

## Decision

`packages/client/ui-theme/src/styles/corner-shape.css` هو من ui-theme عميل entry تركيب عام مثال صيغة جدول (يقع في `base.css` بعد). هو في `@supports (corner-shape: superellipse(1.5))` داخل في `:root` تعريف `--dsw-corner-shape: superellipse(1.5)`، و عبر `*, *::before, *::after` تطبيق `corner-shape: var(--dsw-corner-shape)`——`corner-shape` لا وراثة، عبر إعداد اختيار جهاز صحيح هو في لا يوجد أداة صنف نظام قبل رفع تحت لمس بلوغ كل دائرة زاوية جدول وجه آلية. اثنان بند إعلان كل في حراسة حماية داخل، لذلك لا دعم حمل `corner-shape` جذب محرك إبقاء عادي دائرة قوس.`superellipse(1.5)` وسيط في `round`(`superellipse(1)`) و `squircle`(`superellipse(2)`) بين، و حالي طاولة وجه حديث يوم UI مستو انزلاق درجة متسق.

صحيح دائرة شكل حالة في ذلك إعلان موضع خروج: كل أخذ قيمة لـ `50%`،`100%` أو لاصق كيس نصف مسار (≥ 99px) `border-radius`، كل في الذي تابع مكون مثال صيغة جدول نفس قاعدة داخل إعداد مقابل `corner-shape: round`. هذا إعداد مقابل من `packages/client/ui-theme/tests/corner-shape-styles.client.spec.ts` قوي صنع، هو مسح `packages/` تحت الكل مثال صيغة جدول (مشترك مسح مساعد مساعدة دالة يقع في `tests/stylesheet-scan.ts`، ذاتي scrollbar spec سحب خروج) ؛ نفس spec أيضا تثبيت إقامة `corner-shape.css` حراسة حماية و عبر إعداد تطبيق. مكون نطاق جزء نصف مسار متغير (`--dsl-*-radius`) أخذ قيمة كل بعيد منخفض في لاصق كيس عتبة قيمة، لذلك كلمة قاعدة مسح تغطية حالي استخدام قاعدة.

أساس في token تنفيذ سوف في تغيير منحنى خط معا يأخذ نصف مسار token ركوب بـ 1.25؛ هذا عميل لا يوجد نصف مسار token(كل مكون px حرف وجه كمية) ، لذا نصف مسار ثابت، فقط تغيير دائرة زاوية منحنى معدل.

## Alternatives considered

**أولا بناء نصف مسار token نظام، مجددا حسب token تطبيق.** أكثر وفي فعلي، لكن يأخذ كل عميل حزمة نحو 130 موضع px حرف وجه كمية نصف مسار تعديل صنع صار token هو لا يوجد أخرى الآن فعلي يحتاج طلب كبير إعادة بنية؛ عبر إعداد اختيار جهاز استخدام واحد بند قاعدة لمس بلوغ نفس مثال جدول وجه.

**مقابل صحيح دائرة شكل حالة أيضا تطبيق تجاوز درجة بيضوي دائرة (لا ضبط إعفاء تجنب).** إعلان أكثر قليل، لكن استخدام `border-radius: 50%` border رسم صنع تحميل حلقة في شكل حالة لا هو دائرة وقت دوران تحويل سوف تأرجح حركة، لاصق كيس اثنان طرف سوف تغيير جهة.

**استخدام فرعي شجرة درجة `--dsw-corner-shape: round` بديل تدريجي إعلان `corner-shape: round` إعفاء تجنب.** ذاتي تعريف خاصية سوف وراثة، لاصق كيس دائرة زاوية بعد بديل سوف ساكن صامت فقد ذهاب مستو انزلاق؛ تدريجي قاعدة صريح إعلان يجعل إعفاء تجنب نطاق تماما جيد انتظار في صحيح دائرة شكل حالة ذاته، أيضا هو إعداد مقابل spec قدرة فحص شكل صيغة.

**في تغيير منحنى معدل معا يأخذ نصف مسار ركوب 1.25.** حاجة فوق وصف token نظام؛ فقط منحنى معدل تغير قد حمل قدوم مستو انزلاق شعور، نصف مسار صيانة حمل تصميم قيمة.

## Consequences

- في دعم حمل `corner-shape` جذب محرك (Chromium ≥ 139، بلا حاجة flag) فوق، عميل كل دائرة زاوية كل امتداد `superellipse(1.5)` انحناء منحنى؛ أخرى جذب محرك تصيير و قبل تماما متسق، لا يوجد رجوع شفرة.
- إضافة جديدة صحيح دائرة شكل حالة يجب إعداد مقابل `corner-shape: round`، لا فإن ui-theme corner-shape spec فشل؛ هذا قاعدة سجل في [docs/web-styling.md](../../../../docs/web-styling.ar.md) ، كل دائرة أو لاصق كيس كثير دفع واحد بند إعلان.
- عبر إعداد اختيار جهاز إعطاء كل عنصر عنصر زيادة واحد لا وراثة خاصية؛ إعلان هو معتاد كمية، في حالي شجرة قاعدة نموذج تحت صفة قدرة اعتبار اعتبار يخص إدارة نقاش طبقة وجه.
- نصف مسار انتظار في ذاته عال درجة واحد نصف دائرة زاوية صندوق (منخفض في 99px خفي صيغة لاصق كيس) ما زال سوف نيل إلى تجاوز درجة بيضوي دائرة؛ مسح نظر لا إلى حساب حساب بعد بضعة أي، هذا صنف طرف جزء قراءة عمل متعمد مستو انزلاق بينما غير تغيير شكل.
