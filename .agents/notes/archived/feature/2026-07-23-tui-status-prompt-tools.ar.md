# Agent Note: TUI حالة فحص نموذج طلب إدخال

Status: implemented
Archived: 2026-08-04

[English](2026-07-23-tui-status-prompt-tools.md) | العربية

## مشكلة

جلسة حساب عدد جهاز يمكن وصف نشط حركة حال حال، لكن لا يمكن عرض تحت مرة نموذج طلب سوف استلام إلى إشارة أمر و قدرة. إذا يلزم تشخيص حسب أثر مجال مساهمة نص التوجيه و أداة حد، مستخدم فقط قدرة مغادرة فتح TUI، أو أصل حسب ملف إعداد إجراء دفع قطع.

## قرار

`/status` عبر `ctx.systemPrompt` لـ حالي agent(ذكي جسم) تجميع توجيه النظام، و استخدام و agent loop(ذكي جسم حلقة) نفسه مصير إتمام تصيير. في حمل حافة إطار تشخيص بطاقة بعد، مستقل كما بلا حافة إطار `System prompt` و `Registered tools` منطقة مجال قسم آخر عرض تصيير بعد نص التوجيه و assembly في حسب ترتيب ترتيب صف أداة اسم؛ هذه اسم مقابل حالي agent و عرض نمط نحو نموذج عام schema.

تجميع استخدام أمر إلغاء إشارة و حالي agent أثر مجال، لذلك حسب أثر مجال تسجيل section، متغير، أداة حد و assembly listener و هذا وقت إرسال بدء طلب إبقاء متسق. نص التوجيه و أداة قيمة في عرض قبل مرور مرور TUI طرفية تحكم محرف صاف تحويل. فارغ نص التوجيه و فارغ أداة قائمة قسم آخر عرض لـ `(empty)` و `(none)`.

## سبق اعتبار بديل خطة

**قسم آخر قراءة نص التوجيه section و أداة سجل التسجيل.** قد مرفوض: هذا فعل قاعدة سوف التفاف مرور نص التوجيه تجميع waterfall(شلال نشر صيغة حدث) ، أداة ترتيب ترتيب، عرض نمط و حسب agent حد، لذلك تشخيص نتيجة ممكن و تحت مرة طلب لا متسق.

**عرض كامل أداة schema.** قد مرفوض: أداة اسم كاف بـ عودة جواب تسجيل أي بعض قدرة، معا تجنب تجنب معامل JSON احتلال حسب كبير جزء حالة بطاقة؛schema تفصيل حال ما زال يمكن في توليد أداة دليل و مصدر شفرة تعريف في فحص نظر.

## عاقبة

هذا أمر ممكن مثل طلب دقيق تجهيز واحد مثال تشغيل نص التوجيه مزود و assembly listener، و عبر قائم أمر خطأ تلميح تقرير إبلاغ فشل. نتيجة هو واحد وقت نقطة لقطة: لاحق تسجيل، حد، نمط تغيير أو حركة حالة مزود كل ممكن تغيير تحت مرة طلب.

## اختبار

حزمة (package) سلوك اختبار ثابت حسب أثر مجال تجميع إخراج، أداة اسم ترتيب، فارغ قيمة وسم و طرفية تحكم محرف تحويل معنى. حزمة درجة دلالة لقطة في صحيح معتاد عرض درجة و ضيق عرض درجة تحت تنفيذ `/status`؛ تسليم TUI نشر مسؤول ذلك تجميع بعد عملية تحقق استلام.
