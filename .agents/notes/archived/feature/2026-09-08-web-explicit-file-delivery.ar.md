# Agent Note: Web صريح تسليم ملف لقطة

Status: implemented
Archived: 2026-09-08

[English](2026-09-08-web-explicit-file-delivery.md) | العربية

## مشكلة

مساحة العمل رابط قراءة حالي مسار، لذلك تحرير أو حذف سوف جعل نهائي تسليم ملف بطلان. عبر shell أمر إنشاء ملف أيضا لا يوجد رقم واحد جهة تحرير جهاز تعديل سجل. تسليم حاجة صريح عملية و حفظ بايت، معا لا توسيع كبير Session ZIP توجيه خروج محتوى.

## قرار

[present أداة](../../../../packages/fs/tool-present/README.ar.md) يملك تنفيذ، غير ممكن تغيير لقطة، تسليم نوع و حمل دائم حدث.[تسليم إضافة](../../../../packages/client/ui-deliverables/README.ar.md) يملك إقرار إثبات لقطة عملية و متصفح تصيير، فقط من أداة `./types` مدخل استيراد نوع.`standard`،`ptc` و `cordis` preset تركيب أداة حزمة؛`minimal` إبقاء مزدوج أداة تدريب تدريب إعداد. قائم attachment خدمة حفظ غير ممكن تغيير بايت؛ نجاح نهائي `tools/result` إشعار سوف `deliverables/presented` إلحاق إلى استدعاء جهة Session. أصلي و تضمين طقم استدعاء استخدام نفس عدد سجل جهاز. خارج طبقة برنامج مع بعد فشل لن سحب إلغاء قد إتمام تضمين طقم تسليم. يتم منع توقف أداة نتيجة لا إصدار تسليم.

تحت تحميل و أصلي فتح طلب عبر حالي فحص نظر Session، حدث ترتيب رقم و ملف بحث جذب تخويل مرجع. حدث لا حفظ Session ID، لذلك fork تاريخ استخدام فرعي Session ذاتي ذات سجل. قائم إنتاج خروج ملف سطر إبقاء ذلك اسم و سلوك.Session ZIP إبقاء تسليم حدث، لكن لا استلام تجميع منها مرجع attachment بايت.

بطاقة و استلام ذيل مرجع عملية عبر قائم native-command أداة، في افتراضي تطبيق في فتح مرور مرور تحقق خاص فرعي هذا.POST جدول بلوغ طاولة وجه فرعي أثر؛GET ما زال فقط قراءة بايت. كل مرة عملية إنشاء جديد فرعي هذا، تجنب تجنب تطبيق داخل تحرير ضرر تالف غير ممكن تغيير attachment أو تغيير لاحق فتح محتوى. نجاح فرعي هذا إبقاء إلى إضافة تحرير، بـ دعم حمل تأخير متأخر قراءة تطبيق؛ فشل فرعي هذا قيام أي حذف، تحرير وقت أولا انتظار إلغاء عملية انتهاء مجددا تنظيف.

## قد اعتبار بديل خطة

**في UI حزمة في توفير Host أداة فرعي مسار**سوف سوف preset تثبيت و متصفح تحزيم اقتران دمج، و اشتراط مقدار خارج إصدار مدخل. عادي أداة حزمة عبر مستودع peer dependency قاعدة إبقاء مشترك نظام الملفات و أداة خطأ صنف.

**فوري مساحة العمل رابط**لا يمكن في تحرير أو حذف بعد إبقاء قد تسليم إصدار. مباشر فتح attachment تخزين مسار فإن سوف جعل غير ممكن تغيير حفظ بايت كشف في تطبيق كتابة.

**في أداة،dispatch و Session في زيادة عام artifact حقل**سوف لـ مفرد عدد Web وظيفة توسيع كبير غير متصل API. إضافة يملك حدث استخدام قائم نقطة توسيع، و حذف ذهاب أب استدعاء نتيجة تحويل إرسال.

**سوف أداة نص بصفة حمل دائم بحث جذب**و غير ممكن اعتماد، لأن بعد معالجة و spill يمكن استبدال عادي أو تضمين طقم نتيجة نص. كل إضافة نسخة حسب تنفيذ كائن إبقاء ذاته قد إتمام لقطة، فقط في نهائي نتيجة نجاح وقت إصدار. نفس اسم أثر مجال بديل أداة لا يستطيع إنشاء أو تكرار أخرى نسخة تسليم سجل.

**أساس في ملف وصف رمز نظام الملفات توسيع**سوف تعديل كثير عدد قدرة مزود. هذا وظيفة استخدام قائم محدود قراءة، و فحص مسار يتضمن علاقة و قراءة قبل بعد إصدار. هذه تحقق سوف رفض عادي تزامن تغير، لكن لا حفظ إثبات مقابل استبدال بعد تكرار أصل توفير أصل فرعي مسار حد؛ أكثر قوي نظام الملفات حفظ إثبات يخص نظام الملفات مزود.

## أثر

تنفيذ لا زيادة artifact خدمة أو attachment صيغة. جزء فشل بعد ممكن إبقاء تحت بلا مرجع لقطة؛attachment إبقاء سياسة ما زال من خدمة يملك. تحت تنقل بناء يجب إدارة حل جديد مطلوب حدث عندئذ قدرة قراءة سجل. توليد Session حدث بيان سجل هذا اشتراط، لا تعديل قد إصدار صيغة بديل حد.

تسليم حدث اشتراط قراءة طرف تعرف آخر، لأن هو هو حفظ بايت تخويل بحث جذب، لا فقط هو عرض بيانات وصفية. قفز مرور حدث سوف يجعل قديم قراءة طرف في إعادة بناء أو قسم تقاطع Session وقت فقد فقد قد إتمام تسليم. لا دعم حمل هذا حدث قراءة طرف رفض قراءة، تجنب تجنب ساكن صامت إسقاط مرجع.

تحديد نحو اختبار تغطية لقطة بايت، بلا فاعلية إدخال، يتم منع توقف نتيجة،HTTP كامل صفة، أصلي فتح فرعي هذا عزل، إعادة محاولة و تحرير،turn عزل و استخدام fork عنوان عملية. تسجيل صنع Web مشهد تغطية تضمين طقم استدعاء إتمام بعد خارج طبقة فشل، مصدر ملف حذف، إعادة تحميل، لا إطلاق متصفح تحت تحميل أصلي فتح عملية و ZIP ترتيب حذف.
