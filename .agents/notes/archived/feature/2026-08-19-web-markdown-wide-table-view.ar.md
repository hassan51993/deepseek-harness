# Agent Note: Web markdown جدول إطار حسب صف عدد ملء ملء رسالة صف، عرض جدول مفاجئ كسر صف عرض

Status: implemented
Archived: 2026-09-04

[English](2026-08-19-web-markdown-wide-table-view.md) | العربية

## مشكلة

`MarkdownText` يأخذ كل GFM جدول إطار كل حسب ذاتي لكن عرض درجة تصيير (`.tableScroll table { width: max-content; max-width: max-content }`،`packages/client/ui-primitives/src/markdown/MarkdownText.module.css`) ، في هو أي مقارنة 748px رسالة صف أكثر عرض جدول إطار كل فقط قدرة اعتماد أفقي نحو تمرير قراءة قراءة. وحدة إطار هذا يمكن مريح ملائم تبديل سطر ثلاثة قائمة إطار أيضا يتم إجبار تمرير؛ بينما حق صحيح عرض جدول إطار أي سهل تحويل تسجيل منطقة دورة محيط لديه بضعة مئة مثل عنصر فارغ بقية، أيضا دائم بعيد فقط قدرة استخدام رسالة صف ذلك ما عرض.Issue #1761(يحتوي خارجي عكس تغذية dsh-external/issues#520) اشتراط أولا تبديل سطر ملائم ينبغي، و لـ حاجة جدول إطار توفير أكثر عرض عرض.deepsuite chat منتج قد استخدام CSS أولوية طريقة حل قرار نفس مشكلة؛ حسب مراجعة جهة نحو، هذا تغيير مقابل متساو هذا خطة، استبدال هذا قبل بدء مسودة تفاعل صيغة توسيع محادثة إطار خطة.

## قرار

**صف عدد في مصير داخل ساكن حالة قرار مقياس قياس فرع.**`renderTable` قراءة تحليل خروج صف عدد (`align` عدد مجموعة، نقص حذف رجوع جدول رأس سطر): لا كاف أربعة صف جدول إطار——و blockquote داخل أي جدول إطار (تصيير سياق `inBlockquote` علامة سجل)——نيل نيل وحدة `tableFill` صنف،`table { width: 100%; max-width: none }`، ملء ممتلئ رسالة صف، وحدة إطار حسب قائم `min-width: 100px` تحت حد تبديل سطر. أربعة صف و بـ فوق جدول إطار إبقاء ذاتي لكن عرض درجة قاعدة، تعديل تعليق مستقر عام خطاف صنف `md-table-wide`(امتداد استخدام `md-code-block` أولا مثال) ، توفير مضيف تخطيط إضافة عرض. هذا صحيح هو deepsuite chat حكم آخر صيغة (`.wrapper:not(:has(th:nth-child(4), td:nth-child(4)))` و ذلك blockquote إعفاء تجنب) ، فقط هو نقل إلى قد كف إمساك صف عدد مصير داخل حساب حساب. كل مسار لا يوجد قياس كمية،observer أو تفاعل حالة.

**حديث يوم تحويل تسجيل منطقة استخدام حاوية استعلام CSS إضافة عرض تعليق خطاف جدول إطار.**ChatView `.scroll` إعلان `container-type: inline-size`،`AssistantMarkdown.module.css` إعطاء `.body :global(.md-table-wide)` تعريف مفاجئ كسر:`--dsh-table-spare` هو مفرد جانب فارغ بقية عرض درجة `max(0px, (100cqw - --dsh-chat-content-width) / 2)`،`--dsh-table-lead` مجددا إضافة فوق حزمة لف طبقة ذاته تقليص دخول (`min(--dsh-chat-content-width, 100cqw) - 100%`) ، عرض درجة/سالب margin/قبل توجيه padding تركيب بدء قدوم، يجعل حزمة لف طبقة تمرير منطقة أفقي عبر كامل تحويل تسجيل منطقة، بينما جدول إطار محتوى ما زال من رسالة صف يسار حافة بدء ترتيب.`100cqw` هو deepsuite chat استخدام JS قياس كمية `--dsl-virtual-list-width` CSS انتظار قيمة شيء؛`max(0px, …)` ملقط صنع يحل محل ذلك below-SM JS فتح صلة، تحويل تسجيل منطقة ضيق في رسالة صف وقت وصل متابعة تراجع تحويل لـ عادي صف داخل تمرير. قاعدة حد تحديد في `AssistantMarkdown .body` لـ تحت، أداة بطاقة، ضغط سطر انتظار أخرى `MarkdownText` جدول وجه إبقاء عادي صف داخل سلوك.

**متسق صفة fixture تغير هو متعمد.**يحتوي جدول إطار markdown-dom fixture pin إقامة حكم آخر نتيجة: ضيق جدول و blockquote جدول لـ `tableScroll tableFill`، عرض جدول لـ `tableScroll md-table-wide`؛ إضافة جديدة `table-wide-and-blockquote` لغة مادة وثيقة معا pin إقامة blockquote إعفاء تجنب اثنان عدد فرع.

## سبق اعتبار بديل خطة

**فعلي قياس فيض خروج تفاعل عنصر:ResizeObserver باب تحكم توسيع مدخل، استخدام `Modal` فتح عرض عرض.**أولا سطر تنفيذ، بعد حسب مراجعة جهة نحو مرفوض، تعديل لـ مقابل متساو deepsuite chat:CSS خطة لا حاجة تدريجي جدول observer، لا يوجد سوف يتم تدفق صيغة تحديد مسودة استبدال إسقاط محادثة إطار حالة، لا استخدام اختراق مرور cordis-free حزمة نص سجل إدارة طريق، كما عرض عرض هو معتاد إقامة بينما غير إخفاء في تفاعل بعد وجه.

**مثل deepsuite chat ذلك مثال استخدام `:has()` في CSS داخل عدد صف.**مرفوض: هو جمع حزمة لف طبقة هو عام مكون، بينما هذا مصير هذا قدوم حينئذ في مرة تاريخ جدول إطار عقدة، صف عدد هو ساكن حالة يمكن نيل؛ صنف اسم مقارنة مع DOM تغير عكس تكرار طلب قيمة `:has()` اختيار جهاز أكثر سهل مناسب، أيضا يأخذ قرار ثابت تحويل دخول DOM توفير fixture pin إقامة.

**مفاجئ كسر إلى نظر فتحة عرض بينما لا هو تحويل تسجيل منطقة عرض.**مرفوض: جلسة صف pin ميت `overflow-x: hidden`(`apps/web/tests/conversation-column-overflow.e2e.ts` مفرد محور عقد نحو) ، تجاوز خروج تحويل تسجيل منطقة صندوق فرعي جزء سوف يتم قطع قص؛ تحويل تسجيل منطقة عرض درجة صحيح هو تخطيط فعلي يملك فضاء.

## عاقبة

عادي عرض جدول أصل أرض تبديل سطر قراءة قراءة؛ كثير قائمة إطار إبقاء يمكن قراءة ذاتي لكن عرض درجة، في تخطيط لديه فارغ بقية موضع أفقي عبر كامل تحويل تسجيل منطقة، باق بقية جزء تمرير——بلا حاجة أي تفاعل، أيضا لا يوجد حالة يلزم استعادة. عرض جدول أفقي نحو تمرير بند معلق توقف عندئذ ظهور، لم يعد معتاد إقامة:Chromium من لا إعادة رسم حالة شرط تحويل تمرير بند مثال صيغة (معلق توقف شرط تحويل `::-webkit-scrollbar*` قاعدة و `:hover` تحت `scrollbar-color` تغير كل إلى لا قد رسم صنع تمرير بند——لديه رأس و بلا رأس نمط متساو قد فعلي قياس) ، لذلك إظهار خفي تبديل هو `overflow-x` ذاته (ساكن توقف `hidden`، معلق توقف أو تجمع تركيز `auto`) ، ساكن توقف وقت `padding-bottom` و رئيسي عنوان تمرير بند عال درجة متسق، ظهور تمرير بند تماما جيد قمة بديل هو، تحت جهة محتوى لا حركة. ساكن توقف `overflow-x: hidden` سوف فقد ذهاب Chromium مقابل تمرير حاوية خفي صيغة يمكن تجمع تركيز صفة، لذلك عرض جدول حزمة لف طبقة حمل صريح `tabindex="0"`(`:focus-visible` لديه تركيز نقطة حلقة، تجمع تركيز بعد جهة نحو مفتاح يمكن تدحرج). اثنان عدد حاجة معرفة طريق نقطة:ChatView `.scroll` فوق `container-type: inline-size` جعل هو يصبح تحويل تسجيل منطقة داخل لاحق استخدام حاوية مفرد موضع الأكثر قريب استعلام حاوية؛ لا كاف أربعة صف جدول إطار الآن مجموع هو سحب امتداد إلى كامل صف عرض (deepsuite chat سلوك) ، بينما لا هو حسب محتوى استلام تقليص.

## اختبار

markdown-dom متسق صفة fixture حسب فرع pin إقامة حزمة لف طبقة صنف اسم، يحتوي إضافة جديدة `table-wide-and-blockquote` وثيقة؛`markdown-render-units.client.spec.tsx` تغطية يد عمل شجرة بلا سطر بلا align التقاط قاع.`apps/web/tests/markdown-wide-table.e2e.ts` seed واحد يحتوي ثلاثة عدد جدول إطار قد إغلاق جولة (ثلاثة صف ملء ملء جدول، عشرة اثنان صف عرض جدول، طويل token/العربية طويل وحدة إطار جدول) ، في حقيقي Chromium في عبر نظر فتحة ملف pin علاقة golden——ملء ملء جدول و طويل وحدة إطار جدول في كل واحد ملف كل ملء ممتلئ رسالة صف، بلا ناقص بقية تمرير، مع صف تغيير ضيق بينما تغيير عال؛ عرض جدول بداية نهاية تمرير، تماما جيد في تحويل تسجيل منطقة عرض في رسالة صف ملف موضع مفاجئ كسر صف عرض، مفاجئ كسر وقت محتوى و ملء ملء جدول يسار مقابل متساو، ضيق ملف ملقط صنع لـ في صفة——خارج إضافة تجمع تركيز حزمة لف طبقة جهة نحو مفتاح تمرير، تقليص وضع فرع، و يجب تقرير إبلاغ نفسه علاقة deviceScaleFactor-2 فرع.
