# Agent Note: ask-user رفع سؤال قدرة

Status: implemented
Archived: 2026-07-27

[English](2026-06-25-ask-user-question.md) | العربية

## مشكلة

agent(ذكي جسم) لديه وقت فقط سند نموذج دفع إدارة (inference) لا يمكن أمان أرض متابعة تنفيذ: هو حاجة شخص صنف اختيار مسار، تأكيد لديه ريح خطر أو افتراضي عملية، أو من توفير ناقص معلومة. في هذا تغيير قبل، نيل أخذ جواب سجل وحيد طريقة هو نموذج في assistant نص في رفع سؤال لكن بعد إيقاف، هذا ضرب قطع صحيح معتاد أداة استدعاء حلقة:agent لا يوجد بنية تحويل مؤقت توقف طريقة، لا يوجد توفير UI استخدام خيار بيانات وصفية، لا يوجد في توقف/خطأ تصنيف جسم نظام، أيضا لا يوجد يجعل غير stdio قبل طرف متسق أرض عرض مشكلة طريق مسار.

هذا هو واحد موجه إلى مستخدم قدرة، لكن هو أيضا عبر تجاوز حزمة (package) حد. موجه إلى نموذج أداة حاجة واحد طقم مزود غير متصل طلب مفردات؛ كل UI واجهة حاجة قرار مثل أي عرض و استلام تجميع جواب سجل؛agent loop(ذكي جسم حلقة) ينبغي إبقاء ثابت، لأن أداة استدعاء ذاته قد أداة تجهيز صحيح تأكيد مختلف خطوة شكل حالة.

## قرار

جذب دخول `dsh-user-interaction` بصفة `ctx.userInteraction` مزود غير متصل واجهة حزمة، و موجه إلى نموذج مستهلك `dsh-tool-ask-user` واحد نفس وضع في `packages/ui` تحت. هذا واحد قسم مجموعة هو متعمد لـ لـ: نحو شخص صنف رفع سؤال هو واحد نوع من UI دعم دعم منتج وظيفة، لا يخص بلا مزود نواة قلب رئيسي جاف.seam ما زال يملك مستقر طلب/ينبغي جواب/خطأ مفردات، بينما UI منتج واجهة توفير استلام تجميع جواب سجل أداة جسم مزود. هذا أداة تسجيل `ask_user_question`، تحويل إرسال `{ questions, agent, signal }`، و سوف مزود حساب حساب خروج بنية تحويل جواب سجل بصفة أداة نتيجة إرجاع.

موجه إلى نموذج طلب مفردات متعمد و منتج ضبط بحث schema مقابل متساو:`ask_user_question({ questions: [{ id, question, header?, options?: [{ label, description? }], multi_select? }] })`.`id` حسب مشكلة توفير و في نتيجة في عودة نقل، جعل دفعة كمية طلب بلا حاجة اعتماد مشكلة نص يكفي توجيه.`label` حيث هو موجه إلى مستخدم عرض نص، أيضا هو إرجاع إعطاء نموذج اختيار في قيمة؛ لا يوجد مفرد وحيد `value`، لا يوجد `recommended`، لا يوجد `allow_custom`، أيضا لا يوجد `desc` آخر اسم.

مزود إرجاع `{ answers: [{ id, selected, custom? }] }`.`selected` بداية نهاية هو اختيار في خيار label عدد مجموعة، لذلك مفرد اختيار و `multi_select` جواب سجل مشترك نفس نوع نتيجة شكل حالة.`custom` تحمل تحميل ذاتي من نص «أخرى» جواب سجل؛ بلا خيار مشكلة مباشر استلام تجميع `custom`. عند `custom` وجود وقت، هو تغطية أي قد اختيار خيار،`selected` لـ فارغ. دعم حمل جزء إتمام مزود استخدام قائم `{ id, selected: [] }` شكل حالة يمثل بعض بند يتم متعمد قفز مرور، في لا توسيع أداة نتيجة مفردات قبل رفع تحت إبقاء أخرى جواب سجل.

`UserInteractionError` وراثة `HarnessError`، لذلك `NO_PROVIDER`،`ASK_ABORTED` أو طلب ملكية ناقص انتظار فشل سوف بـ آلة جهاز يمكن توجيه `{ name, code }` أداة خطأ شكل صيغة عبر `ctx.tools.execute()` نقل خروج. هذا و بنية تحويل خطأ تصنيف جسم نظام متسق، جعل نموذج أو حزمة تركيب إضافة قدرة كاف منطقة قسم «مستخدم إلغاء» و واحد عام رمي خروج استثناء.

## UI خريطة

`dsh web` تركيب `dsh-client-ui-question`: ذلك host جانب جعل Web منتج اختيار صفة تحميل موجه إلى نموذج أداة، متصفح جانب فإن في conversation يملك أداة اسم إدخال منطقة slot في تسجيل `question` بند.`createApiProxy` استخدام بـ host توليد rpcId لـ مفتاح عملية داخل pending جدول تنفيذ Web مزود. هو أولا تسجيل انتظار بند، مجددا واسع بث `question/requested`؛ كل مرة mux إعادة فتح وقت بـ نفسه id إعادة وضع؛ في تلقي إدارة قبل تحقق جلسة و كامل جواب سجل دفعة مرة؛ و في عودة جواب، إلغاء، في توقف أو مورد تحرير بعد واسع بث `question/resolved`. تلقي إدارة سوف تزامن حذف هذا بند، لذلك أول عدد صالح استجابة فوز خروج، تكرار أو متأخر إلى استجابة إرجاع `not-pending`.

Web إدخال منطقة مرة عرض واحد مشكلة، معا في جلسة كائن طبقة إبقاء كل طلب. هو دعم حمل مفرد اختيار، كثير اختيار، بلا خيار مشكلة أو صريح ذاتي تعريف جواب سجل، وصف نص و يمكن نظر تحويل دفع ترشيح علامة، لكن لن تلقائي اختيار في دفع ترشيح بند. اختيار مفرد خيار بعد سوف قيام أي دخول تحت واحد بند؛ عند كل بند كل قد عودة جواب أو صريح قفز مرور وقت، حسب Enter إيداع؛IME مجموعة حرف خلال حسب Enter فقط سوف تأكيد إدخال مرشح بند. صفحة قدم فقط قفز مرور حالي بند و إبقاء أولا قبل مسودة مسودة؛ إغلاق تحكم عنصر بـ `ASK_CANCELLED` رفض كامل أداة استدعاء. معتاد قاعدة إدخال منطقة فقط لديه في host resolved لقطة إزالة انتظار معالجة بند بعد عندئذ سوف استعادة.

`dsh-tui` سوف كل مشكلة تصيير لـ مفتاح قرص تراكم طبقة، عرض خيار وصف، دعم حمل مفرد اختيار، كثير اختيار و ذاتي من صيغة ذاتي تعريف جواب سجل، و في في توقف، مزود dispose(مورد تحرير) أو طرفية إغلاق وقت رفض انتظار معالجة مشكلة. دفعة كمية طلب و تزامن طلب كل سوف ترتيب طابور، تأكيد حفظ نفس وقت لحظة فقط لديه واحد تراكم طبقة احتلال استخدام مفتاح قرص تركيز نقطة.

في جسر وصل طبقة أيضا هو تحرير جهاز UI وقت سبق وجود واحد ACP(Agent Client Protocol)elicitation خريطة؛[ACP بصفة فقط موجه إلى تلقائي تحويل بروتوكول](../simplification/2026-07-23-acp-automation-only-protocol.md) إزالة هذا رقم ثلاثة عدد خريطة.

## سبق اعتبار بديل خطة

**Assistant نص بعد تتبع واحد إيقاف جولة.** نموذج يمكن في صاف assistant نص في نحو مستخدم رفع سؤال لكن بعد إيقاف. هذا سوف فقد فقد بنية تحويل خيار بيانات وصفية،UI لا يوجد مزود غير متصل طريقة قدوم تصيير اختيار، كما تحت واحد بند شخص صنف عودة جواب فقط قدرة بصفة جديد user نص التوجيه وصول، بينما غير بصفة حاجة جواب سجل ذلك مرة عملية نتيجة.

**نواة قلب يملك ask-user حزمة.** الأكثر أول تنفيذ سوف seam و موجه إلى نموذج أداة قسم آخر وضع في `packages/core` و `packages/ui`، لكن اثنان من وصف هو نفس عدد من UI دعم دعم شخص آلة تفاعل وظيفة.seam ما زال هو مزود غير متصل، لكن هو لا هو مثل جلسة، أداة أو agent سجل التسجيل ذلك مثال بلا مزود نواة قلب أساس أساس ضبط تطبيق. سوف `dsh-user-interaction` و `dsh-tool-ask-user` واحد بدء وضع في `packages/ui` تحت، جعل حزمة تخطيط قسم و منتج حد متسق: تطبيق و bridge توفير شخص صنف جواب سجل مزود،stdio تطبيق اختيار صفة تحميل موجه إلى نموذج أداة.

**استخدام إذن طلب معالجة عام رفع سؤال.** إذن طلب هو مقابل أداة تنفيذ تخويل؛`ask_user_question` هو حمل اختياري ذاتي من صيغة جواب سجل معلومة استلام تجميع. إعادة استخدام إذن عبر طريق سوف خلط خلط اثنان عدد مختلف منتج عام فكرة.

**حلقة درجة آخر مؤقت توقف أصل لغة.** agent loop قد معرفة طريق مثل أي انتظار أداة استدعاء و من أداة نتيجة استعادة. إضافة جديد حلقة خاص خاص فرع سوف تكرار هذا واحد مختلف خطوة شكل حالة، و إجبار جعل كل حلقة تنفيذ كل حل واحد UI صلة ملاحظة نقطة.

## عاقبة

هذا وظيفة منح إعطاء نموذج واحد قوي كبير مؤقت توقف أصل لغة، لذلك نص التوجيه جذب توجيه جدا إعادة يلزم. أداة وصف إبلاغ إبلاغ نموذج: رفع سؤال يلزم بسيط نظيف، كل ممكن استخدام خيار. منتج سياسة لاحق يمكن حزمة تركيب `tools/execute` قدوم حد أداة أي وقت متاح، لكن حلقة لا ينبغي مقابل ذلك فعل خاص خاص معالجة.

`dsh-user-interaction` و `dsh-tool-ask-user` كل يقع في `packages/ui`، لأن هو جمع مشترك نفس بنية صار واحد موجه إلى منتج شخص آلة تفاعل قدرة.`agent-core` لا تحميل أداة أو مزود.`dsh-tui-demo` اختيار صفة تحميل seam،TUI مزود و موجه إلى نموذج أداة.`dsh web` في host وقت التشغيل بدء seam/مزود، و عبر اختيار تحديد Web question إضافة كشف هذا أداة.ACP تلقائي تحويل تطبيق حيث لا تركيب seam أيضا لا تركيب هذا أداة.

## اختبار

وحدة نسبة التغطية ثابت التالي مشهد: مزود تسجيل/تحرير، تكرار مزود رفض، مزود حينئذ خيط قبل في توقف، فارغ مشكلة رفض، عبر `ctx.tools.execute()` نقل خروج بنية تحويل أداة خطأ، دفعة كمية جواب سجل، كثير اختيار جواب سجل، ذاتي تعريف جواب سجل، صريح حسب بند قفز مرور، و نموذج schema(يشمل إزالة `value`،`recommended`،`allow_custom` و `desc`).TUI اختبار تغطية خيار وصف، ترتيب طابور طلب، إغلاق/في توقف تنظيف، بلا خيار ذاتي من صيغة إدخال، بلا فاعلية اختيار، تكرار كثير اختيار و دفعة كمية مشكلة تدفق.Web اختبار ثابت مستقر id إعادة وضع، استجابة تحقق، أول عدد استجابة فوز خروج تسوية، تكرار و متأخر إلى استجابة، كامل طلب إلغاء و يملك جهة في توقف منطقة آخر، مفرد اختيار بعد قبل دخول،IME أمان Enter إيداع، حسب بند قفز مرور إبقاء، إدخال منطقة وصل إدارة، بنية تحويل دفعة كمية إيداع، و معتاد قاعدة إدخال منطقة استعادة.
