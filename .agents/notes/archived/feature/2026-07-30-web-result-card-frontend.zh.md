# Agent Note: Web result بطاقة قبل طرف —— في متصفح تصيير web تصيير معنى رسم

Status: implemented
Archived: 2026-09-04

[English](2026-07-30-web-result-card-frontend.md) | العربية

## Problem

`web_search` و `web_fetch` أداة إعلان `card: 'web'` result view([web result card](2026-07-30-web-result-card.zh.md)): واحد `kind` وسم ربط دمج,يحمل بنية تحويل يتم مرجع sources إضافة اختياري provider answer(`kind: 'search'`),أو إمساك أخذ URL و ذلك HTTP حالة (`kind: 'fetch'`). هذا عرض مبكر قد مقاومة بلوغ متصفح —— host،connection،runtime سوف هو بصفة `resultView` إلقاء تمرير إلى `ConversationSnapshot` —— لكن Web عميل تجاهل اختصار هو: مرة قد إتمام web استدعاء فقط تصيير لـ توزيع مستو نموذج مرئي نص,صحيح هو اتفاق قلم تسجيل الذي حل تفسير، بنية تحويل عرض يلزم بديل ذلك نوع لديه ضرر تصيير.`web_search` وصول قراءة من وقت هو كل source واحد سطر ذاتي من نص markdown,بينما غير يمكن نقر source مرجع قائمة;`web_fetch` هو هو markdown متن,لا يوجد فحص بحث ملخص.

## Decision

`WebBlock` هو واحد `ui-primitives` مكون,تصيير مرة قد إتمام web فحص بحث,web استدعاء كل Web تصيير نقطة كل عبر هو إزالة استهلاك `web` تصيير معنى رسم: مفتاح تحكم chat أداة سطر (`web_search`/`web_fetch`) ،`GenericToolCard` تصيير نقطة التقاط قاع,و تفصيل حال وجه لوح Output منطقة.`ui-tool/src/client/tool/models/web-card-model.ts` هو وحيد يأخذ لقطة `resultView` تحويل صار مكون props أرض جهة,مرآة مثل `terminal-card-model.ts`,لذلك لا يوجد اثنان عدد تصيير نقطة سوف مقابل مرة web استدعاء عرض إنتاج قسم اختلاف. هو إرجاع null —— مشي عام مسار —— مقابل تشغيل في استدعاء (web بطاقة هو result-only ,لأن أداة إبقاء generic pending عرض) ، مقابل result view لا هو web بطاقة قد تسوية استدعاء (يشمل هذا عميل إصدار لا إقرار تعرف `card` قيمة,هو مرور wire مقاومة بلوغ بسبب بينما لا يستطيع يتم معلومة مهمة لـ قد تحرير ترجمة تغيير جسم) ، مقابل generic result view(web أداة خطأ مسار إرجاع generic بطاقة,ذلك نص من عام مسار إبقاء) ، و مقابل هذا عميل إصدار لا إقرار تعرف `kind` web بطاقة (تحديث host مرور wire إرسال قدوم قيمة,قراءة عمل fetch سوف رسم خروج فارغ URL و `HTTP undefined`).

واحد مكون رسم صنع اثنان نوع kind,من `kind` حكم آخر.`search` يأخذ answer بصفة markdown عرض في مرجع قائمة فوق جهة;كل source هو واحد أمان خارج سلسلة,بـ ذلك عنوان لـ وسم,provider لم إعطاء عنوان وقت بـ ذلك رئيسي آلة اسم لـ وسم,تحت جهة هو snippet و إصدار يوم مدة,أداة قطع قطع قائمة وقت عرض `مصدر قائمة قد قطع قطع` تلميح.`fetch` عرض واحد ضيق تجميع ملخص: حمل رابط نهائي URL، ذلك HTTP حالة، و `محتوى قد قطع قطع` تلميح. استخدام واحد مكون بينما غير اثنان عدد,لأن اثنان من كل هو تصيير لـ نفس بطاقة عائلة web فحص بحث —— هذا صحيح هو اتفاق يأخذ هو جمع وضع في واحد `card` وسم تحت، استخدام `kind` حكم آخر سبب.

**رابط أمان صفة امتداد استخدام MarkdownText مقابل لا تلقي معلومة مهمة assistant رابط الذي استخدام allowlist http(s) فرعي تجميع.** MarkdownText أيضا سماح `mailto:`، هذا موضع لحظة معنى ترتيب حذف، لأن فحص بحث URL أبدا سوف هو بريد عنصر عنوان. واحد source أو fetch URL فقط عند ذلك بروتوكول لـ `http:` أو `https:` وقت عندئذ يصبح يمكن تنقل مرساة نقطة، حمل `target="_blank"` و `rel="noopener noreferrer"`؛`javascript:`/`data:`/`file:`/`mailto:` URL أو لا يمكن تحليل نص تصيير لـ صاف نص، بلا href.web أداة إرجاع result content هو نموذج إنشاء عمل,لم مرور تحقق مقاومة بلوغ هذا مكون,لذلك مثل assistant markdown واحد مثال يتم عند عمل لا تلقي معلومة مهمة معالجة. وسم من عنوان رجوع إلى رئيسي آلة اسم مجددا رجوع إلى أصلي URL,لذلك أي سهل عنوان ناقص كما URL لا يمكن تحليل,source أيضا مجموع قدرة قراءة عمل بعض عدد شرق غرب.

**بضعة أي مرآة مثل CodeBlock/TerminalBlock**(12px دائرة زاوية،code-block جدول وجه،16px تدلي مباشر خارج حافة مسافة),جعل web بطاقة و هو جمع قراءة عمل واحد بيت. كامل نسخة source قائمة تصيير في مفرد عدد `<ol>` داخل,من `max-height: 320px` و `overflow-y: auto` قيد,لذلك عال في هذا قيمة قائمة في أصل أرض رأسي نحو تمرير,بينما لا هو يأخذ بطاقة دعم عال ([مصدر تمرير](2026-08-03-web-search-source-scroll.zh.md)).source قائمة هو تفرق نص بينما غير حسب صف مقابل متساو إخراج,الذي بـ هو صحيح معتاد تبديل سطر,بينما لا مثل طرفية بطاقة إخراج ذلك مثال أفقي نحو تمرير —— هذا هو و TerminalBlock وحيد لحظة معنى قسم اختلاف.

بطاقة في chat سطر في**معتاد إقامة**في ملخص سطر لـ تحت,و `BashRow` الذي استخدام نفس معتاد إقامة وضع حالة. اثنان عدد تصيير نقطة عرض نفس نسخة كامل source قائمة,فقط من بطاقة ذاته تمرير عال درجة قيد,بينما لا يوجد سطر و وجه لوح اثنان درجة source حد أعلى. مفتاح تحكم سطر يأخذ واحد `WebRow` مكون تسجيل في `web_search` و `web_fetch` اثنان عدد مفتاح تحت;سطر فقط أصل حسب أداة اسم حكم آخر بـ اختيار أخذ ذلك رسم علامة (search مقابل browse) و عنوان (`Search`/`Fetch`). لا يوجد ذاتي ذات مفتاح تحكم سطر web إعلان أداة سقوط إلى `GenericToolCard`,هو طويل خروج نفس ورقة معتاد إقامة بطاقة. تفصيل حال وجه لوح تصيير هذا بطاقة,و في ذلك تحت جهة تصيير توزيع مستو نموذج مرئي نتيجة محتوى:`web_fetch` بطاقة فقط يحمل URL و حالة,لذلك ذلك إمساك أخذ متن فقط في هذا موضع يمكن قراءة.

## Consequences

`WebBlock` فقط قراءة web view حقل,لذلك هو هو تصيير معنى رسم الذي يحمل محتوى صاف دالة —— بلا جلسة فحص بحث,و إنتاج خروج هذا عرض presenter واحد مثال إعادة تشغيل أمان,كما مختلف في طرفية بطاقة هو لا حاجة cwd تحليل,لأن web view لا يحمل مسار. لا يوجد `web` قدرة UI(TUI) ما زال نيل إلى اتفاق رجوع `content`;أداة result شكل حالة لا يوجد أي تغيير.answer إعادة استخدام `MarkdownText`,لذلك answer ذاته لا تلقي معلومة مهمة رابط معالجة و GFM تصيير تجنب استهلاك نيل نيل.

كل ورقة معتاد إقامة بطاقة (terminal،diff،web) مشترك استخدام كامل سطر طي/توسيع تفاعل عودة[موحد واحد توسيع و فحص نظر note](2026-07-30-web-tool-row-unified-expand-and-inspect.zh.md) كل;هذا بطاقة التزام دوران معتاد إقامة اتفاق,بينما غير انتزاع أولا فعل ذلك طقم تفاعل.

## Alternatives considered

**اثنان عدد مكون,كل نوع kind واحد.** رفض: اثنان نوع شكل حالة مشترك بطاقة خارج إطار، أمان رابط معالجة، قطع قطع تلميح,بينما اتفاق قد يأخذ هو جمع فرق مختلف جدول بلوغ لـ واحد `card` وسم تحت `kind` حكم آخر;اثنان عدد مكون سوف تكرار مشترك جدول وجه و تفكيك قسم أمان رابط منطق.

**إعادة تحليل نموذج مرئي تصيير نص,بينما غير إزالة استهلاك بنية تحويل عرض.** بسبب اتفاق قلم تسجيل إعطاء خروج نفس إدارة من رفض:`web_search` تصيير يأخذ كل source حقل ضغط صار واحد سطر ذاتي من نص، بـ عنوان أو رئيسي آلة اسم لـ وسم,الذي بـ إعادة تحليل لا يمكن استعادة `{url, title?, snippet?, publishedAt?}`. بنية تحويل `resultView` هو وحيد وفي فعلي مصدر,هذا صحيح هو خلفية اتفاق إضافة هو سبب.

**لا إضافة بروتوكول allowlist مباشر تصيير عار مرساة نقطة.** رفض:URL في هذا عرض حد موضع هو نموذج إنشاء عمل، لم مرور تحقق,الذي بـ لم مرور ترشيح href سوف يجعل `javascript:` URL في نقر وقت تنفيذ. هذا allowlist هو MarkdownText allowlist(هو أيضا سماح `mailto:`) http(s) فرعي تجميع,لذلك لا تلقي معلومة مهمة فحص بحث رابط بلا نقاش في أي موضع تصيير كل سلوك نفسه.

## Testing

`packages/client/ui-primitives/tests/web-block.client.spec.tsx` يأخذ مكون تثبيت إلى per-file 100% باب عتبة: اثنان نوع kind;عنوان-أو-رئيسي آلة اسم-أو-أصلي URL وسم رجوع;اثنان نوع kind فوق أمان رابط خاصية (http(s) URL يصبح حمل `target`/`rel` خارج سلسلة,`javascript:`/`file:`/لا يمكن تحليل URL تصيير لـ بلا href صاف span);snippet و يوم مدة في وجود/لـ فارغ/ناقص وقت عرض أو حذف;من علامة سجل موضع تحكم قطع قطع تلميح;و كامل source قائمة تصيير في مفرد عدد تمرير حاوية داخل، بلا توسيع تحكم عنصر،`<li value>` من 1 بدء لـ كل بند source وصل متابعة تحرير رقم.

`packages/client/ui-tool/tests/web-card.client.spec.tsx` في كل وصل خط حد مرآة مثل `terminal-card.spec.tsx`:`webCardModel` إرسال توليد إسقاط كل source حقل، ذلك قطع قطع و ناقص answer دعم مسار،fetch إرسال توليد، و كل null دعم مسار (تشغيل في،null result view،generic result view، لم معرفة card وسم، لم معرفة web `kind`);مفتاح تحكم `WebRow` مقابل اثنان نوع kind معتاد إقامة بطاقة، ذلك فقط ملخص سطر تشغيل في و فشل دعم مسار;`GenericToolCard` التقاط قاع لـ web إعلان أداة طويل خروج معتاد إقامة بطاقة، و لـ غير web استدعاء إبقاء صاف سطر;تفصيل حال وجه لوح Output منطقة مقابل اثنان نوع kind —— يحتوي `web_fetch` متن توزيع مستو في ذلك URL/حالة بطاقة تحت جهة —— و ذلك مقابل غير web نتيجة توزيع مستو رجوع;و في `web_search` و `web_fetch` اثنان مفتاح تحت استخدام واحد مكون مفتاح تحكم تسجيل. هذا ملف يقع في نسبة التغطية `exclude` قائمة (`ui-tool/src/*`),لذلك نسبة التغطية تشغيل لا درجة كمية هو.

fixture(`packages/client/connection/src/client/fixture.ts`) إضافة turn 66(`web_search`) و 67(`web_fetch`),داخل ربط تأليف كتابة,لأن عميل fixture لا يمكن import web أداة:turn 66 result view يحمل واحد answer و ثلاثة عدد source,عرض تدريب مرجع قائمة (واحد حمل snippet و يوم مدة لديه عنوان source، واحد بلا عنوان بسبب بينما بـ رئيسي آلة اسم علامة ملاحظة رابط source، واحد لديه يوم مدة بلا snippet source) و فتح بدء قطع قطع تلميح;turn 67 يحمل إمساك أخذ URL و واحد 200 حالة. اثنان من كل إبقاء generic pending call view,فقط في result وقت إضافة `web` بطاقة,مطابقة اتفاق result-only web شكل حالة,كما بـ حقيقي أداة تسمية,جعل ذلك أمر في مفتاح تحكم `WebRow`. هو جمع يتم ترتيب في todo turn(إعادة تحرير رقم لـ 68) قبل,إدارة من و طرفية turn نفسه: انتظار تحديد حساب تخطيط في تحت واحد `turn/start` تراجع راحة,الذي بـ ترتيب في ذلك بعد turn سوف صاف فارغ dock plan strip. هذا قيادة built-boot snapshot و واحد فوري `?fixture` خدمة.
