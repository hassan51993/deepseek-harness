# Agent Note: لم اختيار Workspace وقت من تحرير جهاز فتح قائم اختيار جهاز

Status: implemented
Archived: 2026-08-22

[English](2026-08-07-workspace-picker-composer-entry.md) | العربية

## مشكلة

[Session scope قرار](../architecture/2026-07-25-web-client-session-scope-and-provide-channel.ar.md) سوف في Workspace وجود قبل إبقاء نفس عدد معتاد إقامة تحرير جهاز، لكن textarea موضع في منع استخدام حالة، فقط لديه مقارنة صغير Workspace chip قدرة فتح اختيار جهاز. مستخدم أول مرة نقر الأكثر إظهار عين، أيضا الأكثر ناضج معرفة إدخال منطقة مجال وقت، واجهة لن استجابة، كل إدارة نفس واجهة قد لديه متابعة عملية مدخل.

## قرار

جديد جلسة بعد لم ملكية أي Workspace وقت، كامل ورقة إدخال بطاقة كل يمكن عبر فأرة علامة نقر تنشيط قائم `conversation.hero.workspace` اختيار جهاز——نقر معالج عودة بطاقة كل، ذلك منع استخدام تحكم عنصر وضع سطر إشارة إبرة حدث، لذلك كامل لاصق كيس هو نفس عدد هدف؛ فقط قراءة معتاد إقامة textarea أيضا يمكن مرور Enter أو Space تنشيط.`aria-haspopup="menu"` و `aria-expanded` في مشترك اختيار جهاز قائمة مفرد تركيب وقت وصف ذلك توسيع حالة. كل جديد تثبيت لا يوجد Workspace سطر وقت، اختيار جهاز سوف قيام أي تحويل تسليم دليل محادثة إطار و صاف حذف ذاته توسيع حالة؛ هذا محادثة إطار استخدام ذاتي ذات يمكن وصول صفة دلالة. وهمي خط l4 وصف حافة (SVG dash ring، لأن أصلي `dashed` بين مسافة غير ممكن ضبط) إعداد دمج hover وقت business أزرق، يأخذ بطاقة علامة لـ اختيار مدخل. بطاقة سوف اعتراض تحت `pointerdown`، جعل قد فتح اختيار جهاز خارج نقطة إغلاق لا يمكن و نقر إعادة فتح تنافس حالة——أولا صلة بعد فتح سوف يجعل chip توسيع عودة إظهار وميض حركة. رسالة إيداع، أمر، إذن، نموذج و أخرى Session أثر مجال تحكم عنصر سوف إبقاء قفل تحديد، مباشر إلى مستخدم اختيار Workspace و إنشاء أو إعادة اتصال حقيقي Session.

Workspace اختيار متابعة استخدام قائم owner و مسار.`ConversationRoot` فتح اختيار جهاز،`WorkspacePicker` صف خروج أو إنشاء Workspace؛Session وصول بعد، نفس عدد textarea DOM عقدة تغيير لـ يمكن تحرير حالة.

## اعتبار مرور بديل خطة

**إبقاء textarea منع استخدام و مفاجئ خروج Workspace chip.** هذا مثال قدرة إبقاء أصل لديه تحكم عنصر حد، لكن أول مرة عملية وقت الأكثر رئيسي يلزم تحرير جهاز منطقة مجال ما زال لا يوجد استجابة.

**في textarea فوق جهة وضع وضع نفاذ واضح حسب زر.** حسب زر أداة تجهيز مباشر إطلاق جهاز دلالة، لكن هو سوف في معتاد إقامة textarea فوق جهة زيادة ثاني عدد يمكن تجمع تركيز عنصر عنصر، و جعل إبقاء تركيز نقطة، إدخال قاعدة و مسودة مسودة سلوك DOM identity مرور عبور أكثر تكرار مختلط.

**في اختيار Workspace قبل استقبال مسودة مسودة.** هذا حاجة من client يملك مسودة مسودة Session أو آخر بند Session قبل حالة محور. هذا وظيفة فقط حاجة توفير واحد أكثر سعة سهل اكتشاف قائم اختيار جهاز مدخل.

## عاقبة

مستخدم أول مرة نقر تحرير جهاز يكفي متابعة لا بد يلزم ضبط مسار، مفتاح قرص مستخدم أيضا قدرة تنشيط نفس مسار.textarea سوف مثل فعلي تقرير إبلاغ فقط قراءة حالة، مباشر إلى Session وجود؛ متبادل مجاور تحكم عنصر ما زال موضع في منع استخدام حالة. واجهة لا يوجد جذب دخول جديد Workspace حالة، نقل أو دليل اختيار مسار.

مكون اختبار سوف ثابت فأرة علامة و مفتاح قرص تنشيط، تغطية كامل بطاقة نقر هدف، يتم اعتراض تحت `pointerdown`، متبادل مجاور تحكم عنصر قفل تحديد، اختيار جهاز توسيع، و نفس عقدة تغيير لـ يمكن تحرير textarea مرور عبور. تجميع بعد Web helper سوف عبر textarea بدء كل جديد Workspace ضبط، لذلك إعادة وضع متصفح مشهد سوف تغطية فعلي تسليم مسار.
