# Agent Note: `dsh run` مسؤول مرة صفة headless تنفيذ

Status: implemented
Archived: 2026-08-10

[English](2026-08-08-dsh-run-headless-command.md) | العربية

> **أمر لغة قاعدة قد يتم يحل محل.** [تطبيق الآن يحتفظ ذاتي ذات أمر سطر](../architecture/2026-08-06-app-owned-command-line.md):headless بدء سطر من `dsh --profile headless <task...>` تحليل مهمة، بدء جهاز لم يعد يتضمن `run` استدعاء، أيضا لم يعد يأخذ مهمة نص patch دخول إعداد سطر. هذا قلم تسجيل إبقاء يتم مرفوض بدء جهاز يحتفظ تصميم خلف مشهد؛ هو اختيار تحديد مباشر تنفيذ و إتمام اتفاق ما زال من [headless هو مباشر core مدخل](../architecture/2026-08-09-headless-direct-core-entry-point.md) يحتفظ.

## مشكلة

عام profile بدء و مرة صفة مهمة تنفيذ أداة لديه مختلف دورة الحياة اتفاق. إذا أصل لغة قاعدة قبول اختياري مهمة نص، نفس نوع argv شكل سوف يمثل معتاد إقامة عملية أو إنهاء صيغة مهمة، أداة جسم يحتوي معنى أخذ قرار في تركيب إتمام بعد عندئذ اكتشاف إضافة إعداد سطر. هو أيضا سوف يأخذ profile تنفيذ دقيق عقدة كشف صار رئيسي يلزم مستخدم أمر، و جعل ذاتي تعريف profile نقص قليل واضح مرة صفة مدخل.

`run` حركة كلمة يجب فقط لديه واحد نوع قمة طبقة يحتوي معنى. و تطبيق ملف تنفيذ مشترك استخدام هذا حركة كلمة، أو أصل حسب موضع معامل شكل دفع قطع يحتوي معنى، كل سوف إنتاج نفسه اختلاف معنى.

## قرار

مرة صفة تنفيذ اعتماد التالي لغة قاعدة:

```text
dsh run [--profile <name>] [--patch <path>...] <task...>
```

`--profile` افتراضي لـ `headless`، و دعم حمل ذاتي تعريف مرة صفة تركيب.`--patch` يمكن تكرار استخدام، و احتلال حسب صحيح معتاد overlay طبقة.Commander استخدام فارغ إطار تجميع وصل متغير عدد كمية مهمة معامل، و في بدء قبل رفض ناقص أو فارغ أبيض مهمة.

`RunInvocation` هو مفرد وحيد `DshInvocation` عضو. عام profile استدعاء لا يحمل مهمة حالة، أيضا لا قبول موضع معامل. اثنان بند قسم إرسال مسار كل استخدام `runProfile`:profile بدء حذف `task`، بينما `run` توفير هذا حقل. نقص قليل `headless-runner` مرة صفة profile سوف إطلاق تركيب سطر فحص؛ إذا بدء profile يتضمن هذا سطر لكن لم توفير مهمة، خطأ سوف إشارة نحو `dsh run --profile <name> "<task>"`.

[profile إضافة تركيب حزمة قرار](../architecture/2026-08-05-profile-plugin-bundles.md) مسؤول تركيب.[Headless هو مباشر core مدخل](../architecture/2026-08-09-headless-direct-core-entry-point.md) مسؤول تنفيذ اتفاق: واحد جديد حفظ دائم جلسة،stdout فوق نهائي assistant نص،completed/غير completed خروج حالة خريطة، نجاح وقت لـ فارغ stderr، بلا استماع طرف فتحة، و Agent تماما توقف مستقر كما جلسة flush بعد محدود إشارة إغلاق.

`run` حركة كلمة فقط مسؤول مرة صفة مهمة تنفيذ. تطبيق ملف بدء حاجة مختلف أمر اسم.

## اعتبار مرور بديل خطة

| بديل خطة | اتفاق لا مطابقة لـ موضع |
|---|---|
| يأخذ مهمة نص وضع في أصل profile بدء أمر فوق | دورة الحياة يحتوي معنى اعتماد تحليل بعد عندئذ اكتشاف إضافة إعداد سطر. |
| قبول `dsh -p` انتظار أصل أمر آخر اسم | مسبق إصدار لغة قاعدة نيل نيل لا يخص أي حالي أمر توافق فرع. |
| اشتراط إشارة تحديد `--profile headless` | مع مرفق مرة صفة surface فقد ذهاب الأكثر قصير مواصفة كتابة قاعدة. |
| سوف `dsh run` لأجل تطبيق ملف | واحد قمة طبقة حركة كلمة أداة لديه اثنان نوع يحتوي معنى، رئيسي يلزم مهمة أمر أيضا تغيير نيل بين وصل. |
| إضافة فقط تحويل إرسال `apps/cli/src/run.ts` | أمر ملكية يتم تفكيك قسم، لكن لا يوجد إخفاء أي تكرار مختلط درجة. |

## عاقبة

مساعدة مساعدة معلومة، وثيقة، محلل اختبار، بناء بعد اثنان دخول صنع تحقق استلام،PTY إغلاق تغطية و تجميع تطبيق بلا مفتاح لقطة متساو استخدام `dsh run`. ذاتي تعريف مرة صفة profile استخدام `--profile`؛ معتاد إقامة profile بدء و إعداد dump استخدام أصل profile لغة قاعدة. تطبيق ملف تنفيذ هو مستقل أمر صلة ملاحظة نقطة.
