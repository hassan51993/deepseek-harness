# Agent Note: Ask-question Web عرض

Status: implemented
Archived: 2026-09-04

[English](2026-07-29-ask-question-web-presentation.md) | العربية

## مشكلة

Web GUI قد يمكن عبر `QuestionComposer` إدخال منطقة وصل إدارة استلام تجميع عودة جواب، لكن ذلك دورة حافة جلسة سجل عرض في ثلاثة عدد جهة وجه هو خطأ. انتظار عودة جواب مشكلة سوف تصيير اثنان مرة: مرة هو إدخال منطقة وصل إدارة، مرة هو مبكر في وصل إدارة وجود فقط قراءة `PendingCard` احتلال موضع بطاقة. قد تسوية `ask_user_question` استدعاء تصيير لـ عام "Tool call" سطر و مباشر ميل قلب أصلي args JSON، لذلك اثنان نوع إدخال منطقة قطع قرار —— مستخدم وضع ترك كامل مجموعة مشكلة (`ASK_CANCELLED`) و مشكلة انتظار عودة جواب خلال جولة يتم ضرب قطع (`ASK_ABORTED`)—— كل عرض لـ بلا اسم أحمر نقطة فشل. بينما كما إدخال منطقة ذاته واجهة نص سجل (قسم صفحة، حسب زر، احتلال موضع رمز، تحقق عكس تغذية) هو صلب تحرير رمز العربية، بينما دورة حافة عميل قد عبر `dsh-client-locale` تنفيذ مزدوج لغة.

آخر خارج، إدخال منطقة نظر شعور أيضا انحراف مغادرة حالي تصميم: ذاتي تعريف عودة جواب يحتاج توسيع عندئذ قدرة إدخال، كثير اختيار حذف ذيل جزء مقابل ربط خارج لا يوجد مرئي معرف، قسم صفحة تعليق في رأس جزء، أيضا لديه من نموذج نص داخل تحليل `(يمكن كثير اختيار)` عنوان بعد لاحقة اتفاق.

## قرار

واحد انتظار عودة جواب مشكلة تماما جيد يملك اثنان عدد واجهة: إدخال منطقة وصل إدارة استلام تجميع عودة جواب، جلسة سجل في واحد مخصص باب `ask_user_question` toolview سطر قديم وصف تفاعل نتيجة. هذا سطر و `todo_write` تماما واحد مثال تسجيل دخول حمل key `tool.call.toolview` مجرى موضع، و إعادة استخدام مشترك `ToolRow`(خارج مراقبة، تشغيل مسح ضوء، قبل توجيه توسيع). ذلك ملخص هو تفاعل قطع قرار بينما غير معامل: تشغيل في عرض `waiting`، تسوية بعد من نتيجة JSON نيل خروج `N/M answered`(يتم قفز مرور عودة جواب —— `selected` لـ فارغ كما بلا `custom` —— لا حساب دخول) ،`ASK_CANCELLED` عرض `cancelled`،`ASK_ABORTED` عرض `interrupted` و امتداد استخدام مشترك كهرمان عنبر لون stopped دلالة. شاذ شكل أو قطع قطع نتيجة رجوع إلى عام ملخص.`PendingCard` سبق استلام ضيق لـ `PendingWait<'approval'>`،`ChatView` سبق سوف انتظار معالجة قائمة مرور ترشيح لـ فقط مراجعة دفعة انتظار، جعل احتلال موضع بطاقة فقط خدمة في مراجعة دفعة؛ ذلك بعد مراجعة دفعة إدخال منطقة وصل إدارة ([Web إذن و مراجعة دفعة](2026-07-23-web-permission-and-approval.ar.md)) قد سوف هو تام قاع إزالة.

نجاح مشكلة سطر ما زال يجعل طي بعد جلسة سجل فقط عرض مفرد سطر قطع قرار، و في توسيع محتوى في استخدام فقط قراءة سؤال جواب سجل يحل محل عام JSON.presenter تحقق استدعاء معامل في مشكلة و نتيجة محتوى في عودة جواب، حسب عودة إظهار مستقر `id` إعداد مقابل، إبقاء استدعاء ترتيب، و سوف كل مقطع نموذج تأليف كتابة مشكلة عرض لـ ضعيف تحويل وسم، تحت جهة استخدام رئيسي يلزم نص حرف عرض قد خيار و ذاتي تعريف عودة جواب. يتم قفز مرور مشكلة عرض محلي تحويل `لم عودة جواب` قطع قرار. بطاقة حد الأكثر كبير عال درجة و في داخلي تمرير. بلا فاعلية JSON، تكرار id، نقص قليل id، عدد كمية لا رمز، لم معرفة عودة جواب id و بلا فاعلية مرئي حقل كل إبقاء عام إدخال/إخراج بطاقة، لا عرض لا كامل أو خطأ إعداد مقابل سجل.

قد إلغاء أو قد في قطع مشكلة سطر لا يوجد يمكن توفير إعداد مقابل عودة جواب تحميل حمل. ذلك توسيع بطاقة أولا عرض محلي تحويل كامل مجموعة قطع قرار، شرح لم إيداع عودة جواب، مجددا صف خروج نموذج تأليف كتابة أصلي مشكلة؛ هو لن يأخذ إلغاء علامة صار تدريجي عنوان قفز مرور، أيضا لن وهمي بنية عودة جواب سجل. بلا فاعلية استدعاء معامل إبقاء عام تشخيص بطاقة. إلغاء هو مستخدم رئيسي حركة اختيار، استخدام في صفة settled حالة؛ في قطع إبقاء كهرمان عنبر لون stopped حالة.

إدخال منطقة إعادة تصميم سوف قسم صفحة نقل إلى قاع جزء عملية منطقة جانب، كثير اختيار خيار تصيير صريح تكرار اختيار إطار، مفرد اختيار إبقاء تحرير رقم سطر، و استخدام بداية نهاية مرئي ذاتي تعريف إدخال سطر يحل محل توسيع صيغة ذاتي تعريف مدخل (بلا خيار مشكلة استخدام كثير سطر نص إطار). حذف `parseQuestionTitle` كثير اختيار بعد لاحقة اتفاق؛`multi_select` قد هو بنية تحويل بيانات وصفية، عنوان أصل مثال تصيير.

إدخال منطقة واجهة نص سجل تنفيذ مزدوج لغة: إضافة في `dsh-client-locale` `question` نطاق الأسماء تحت تسجيل في إنجليزي كلمة قاموس، و عبر slot inject face نحو بند توفير ربط نطاق الأسماء قلب ترجمة جهاز و بصفة hooks compartment مصدر locale لقطة، لغة تبديل وقت قد تركيب إدخال منطقة سوف إعادة تصيير. تحقق عكس تغذية بـ كلمة قاموس key تخزين، تبديل وقت إعادة قلب ترجمة؛ تحميل جسم فشل رسالة و كل نموذج تأليف كتابة مشكلة/خيار نص أصل مثال تصيير.

اثنان عدد متبادل مجاور إصلاح مع سطر. كل عام toolview قبل توجيه رسم علامة (يحتوي معلق توقف سهم رأس) الآن موحد واحد وراثة ثلاثة درجة وسم لون —— حذف others تغيير جسم اثنان درجة لون تغطية و مستقل سهم رأس لون لون قاعدة، فقط إبقاء متعمد لـ لـ cordis عمل خدمة رئيسي لون قوي ضبط. عميل dev-watch تحزيم جهاز استخدام `addWatchFile` تسجيل كل CSS وحدة، لأن وهمي محاكاة وحدة بين وصل طبقة هذا قبل جعل فقط تعديل CSS تحرير مقابل watcher غير ممكن رؤية.

## سبق اعتبار بديل خطة

**متابعة عبر `PendingCard` تصيير مشكلة.** مرفوض: هذا بطاقة هو وصل إدارة وجود قبل فقط قراءة احتلال موضع، توجيه يؤدي نفس محتوى عرض اثنان نسخة كما منها واحد نسخة غير ممكن عمل جواب.toolview سطر إضافة وصل إدارة معا تغطية سجل و استلام تجميع اثنان عدد وجه.

**في طي جلسة سجل سطر عرض مشكلة أو عودة جواب.** مرفوض: إدخال منطقة وصل إدارة يملك عودة جواب استلام تجميع، بينما سطر اتفاق (`todo_write`) يجعل طي مفرد سطر إبقاء سهل مسح. لذلك هذا سطر في توسيع قبل فقط تقرير إبلاغ نتيجة، توسيع محتوى يملك فقط قراءة سؤال جواب سجل.

**في توسيع محتوى في إبقاء أصلي إدخال و إخراج JSON.** مرفوض: تحميل حمل إبقاء الكل معلومة، لكن يجعل مستخدم ذاتي ذات عودة جواب أو قد إلغاء مشكلة صعب بـ تصفح تصفح. بنية تحويل عرض عرض نفسه عمل من نص؛ مشكلة تحليل أو عودة جواب إعداد مقابل غير ممكن معلومة وقت ما زال بـ أصلي JSON بصفة fail-closed رجوع.

**استخدام عام خطأ شكل تصيير `ASK_CANCELLED`/`ASK_ABORTED`.** مرفوض: وضع ترك هو مستخدم ذاتي ذات رئيسي حركة عملية، ضرب قطع هو مشترك إيقاف يد اتجاه؛ اثنان من كل هو مسبق مدة نتيجة بينما غير أداة فشل. تسمية قطع قرار (كما في توقف إبقاء كهرمان عنبر لون stopped دلالة) و أخرى يتم ضرب قطع أداة استدعاء عرض متسق.

**يجعل سطر داخل قطع قرار إبقاء إنجليزي نص.** الأكثر أول تأجيل، مع بعد في Client UI نص سجل تعديل من locale إدارة وقت يتم يحل محل: حالي conversation كلمة قاموس محلي تحويل سطر داخل قطع قرار و توسيع بطاقة لم عودة جواب وسم، بينما نموذج تأليف كتابة مشكلة و عودة جواب إبقاء أصل مثال.

**إبقاء عنوان بعد لاحقة كثير اختيار اتفاق.** مرفوض:`multi_select` هو بنية تحويل طلب بيانات وصفية كما تكرار اختيار إطار معرف قد تحمل تحميل هذا إشارة، من نموذج نص تحليل `(يمكن كثير اختيار)` هو هش ضعيف تكرار عبر طريق.

## عاقبة

`ask_user_question` و `todo_write` الآن مشترك نفس عرض نطاق مسبق مدة toolview نمط: إعادة استخدام `ToolRow`، من استدعاء معامل أو نتيجة JSON فعل حمل شكل حالة تحقق رجوع ملخص، عبر حمل key slot تسجيل. مخصص استخدام `todo-row.module.css` قد حذف.

توسيع سؤال جواب سجل لـ مشترك `ToolRow` زيادة نوع تحويل صاف بيانات مشكلة بطاقة نموذج؛ أخرى أداة عرض إبقاء أصل لديه عام أو مخصص استخدام بطاقة. مشكلة سطر فقط قراءة قد حفظ دائم استدعاء و نتيجة حقل، لا زيادة Host عرض حقل. مراجعة دفعة إدخال منطقة وصل إدارة قد تسليم ([Web إذن و مراجعة دفعة](2026-07-23-web-permission-and-approval.ar.md) ، و حسب[مراجعة دفعة وجه لوح Agent Note](../bug-fix/2026-07-30-approval-panel-command-cap.ar.md) تطبيق إضافة عال درجة حد أعلى) ،`PendingCard` قد لا تكرار وجود.

`ui-user-questions` إضافة جديدة `dsh-client-locale` اعتماد و هذا قبل لا يوجد inject face؛ ذلك اتفاق (`QuestionComposerInjected`) و مستهلك واحد بدء وضع في `contract/slots.ts`.

## تحقق

`ui-tool` اختبار تثبيت إقامة سطر waiting/answered/skipped/cancelled/interrupted مستطيل دفعة، يمكن قراءة id إعداد مقابل، قد خيار و ذاتي تعريف عودة جواب سطر، بلا عودة جواب قطع قرار و fail-closed رجوع. بلا مفتاح تجميع Web لقطة قسم آخر توسيع نجاح و إلغاء مشكلة سطر و سجل ذلك يمكن قراءة محتوى.`ui-user-questions` اختبار تثبيت إقامة إعادة تصميم إدخال منطقة (تكرار اختيار إطار كثير اختيار، بداية نهاية مرئي ذاتي تعريف سطر، قاع جزء صفحة، كلمة قاموس key عكس تغذية إعادة قلب ترجمة،IME أمان Enter) و إضافة كلمة قاموس تسجيل و inject face؛`ui-primitives` اختبار تثبيت إقامة رسم علامة تجميع. تجميع بعد Web GUI في حقيقي جلسة في عرض تدريب عودة جواب، إلغاء و جولة ضرب قطع مسار.
