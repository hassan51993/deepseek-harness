# Agent Note: PTC mode UI أساس أساس——run_code description معامل، و و أصلي نفس انتظار حفظ حق توزيع سجل

Status: implemented
Archived: 2026-09-04

[English](2026-07-26-ptc-dispatch-ui-foundation.md) | العربية

> نطاق: يجعل UI قدرة بـ و أصلي أداة استدعاء نفسه حفظ حق درجة تصيير PTC mode جولة مضيف جانب اتفاق تغيير، أي أخرى PTC mode UI Agent Note اعتماد بـ بناء أساس أساس. نقل تصميم عودة [PTC mode أساس أساس](2026-06-15-ptc.zh.md) كل؛ نموذج مرئي `description` معامل، يحمل كامل محتوى `tool/code-dispatch` تحميل حمل، و `dsh` إعداد شجرة فوق مؤقت `DSH_TOOLS_MODE` تفعيل فتح صلة، عودة هذا مقالة كل.

## مشكلة

`run_code` جولة مرور ذهاب في كل منتج واجهة فوق كل لا نفاذ واضح. استدعاء بطاقة عنوان حينئذ هو أصلي برنامج نص، في سطر عرض داخل لا يمكن قراءة قراءة؛ بينما كما مختلف في `bash`(ذلك لا بد ملء `description` استخدام عمل بطاقة وسم، أمر ذاته وضع في توسيع بعد إدخال داخل) ،`run_code` تماما لا يوجد نموذج تأليف كتابة وسم.`tool/code-dispatch` حدث مرور ذهاب فقط يحمل كل فرعي استدعاء `resultSummary`(حد أعلى 200 محرف، مرور cwd عودة واحد تحويل) ، لذلك أي UI كل بلا من عرض فرعي استدعاء فعلي إرجاع محتوى:Web محادثة عرض ([chat فرعي استدعاء سطر](2026-07-26-ptc-chat-subcall-rows.zh.md)) سوف استخدام تصيير أصلي `tool/result` بطاقة نفس دفعة مكون قدوم تصيير فرعي استدعاء، بينما محدود ملخص لا يمكن دعم دعم واحد ورقة و أصلي نفس انتظار حفظ حق بطاقة. معا،`dsh web` تركيب هذا قبل أصل هذا لا يمكن تفعيل PTC mode:`tools` سطر تثبيت ميت في schema قيمة افتراضية فوق، إعداد شجرة داخل أيضا تماما لا يوجد هذا وقت التشغيل.

## قرار

ثلاثة بند تغيير، كل بند مقابل واحد عائق عائق:

1. **`run_code` إضافة جديدة لا بد ملء `description` معامل**(و bash تماما نفسه اتفاق: رئيسي حركة لغة حالة،5-10 عدد كلمة، عرض في UI في؛ فقط يحتوي فارغ أبيض أخذ قيمة في تنفيذ وقت يتم رفض).`presentCall` الآن بـ هذا description بصفة بطاقة عنوان، و يأخذ برنامج نص نقل دخول `rawInput`. نص التوجيه جانب صار هذا هو كل مرة استدعاء كثير خروج بضعة عدد token؛ تبديل قدوم هو كل واجهة——TUI بطاقة،ACP(Agent Client Protocol) عنوان،Web سطر——كل بلا حاجة تحليل TypeScript حينئذ قدرة نيل نيل يمكن توفير شخص قراءة قراءة وسم.
2. **`tool/code-dispatch` سجل فرعي استدعاء موجه إلى نموذج كامل نتيجة**(`content: ContentBlock[]` إضافة `isError`، أي `tool/result` مفردات) ، يحل محل `resultSummary`، و يأخذ ملخص و cwd عودة واحد تحويل آلية تام قاع حذف.UI تصيير فرعي استدعاء مشي شفرة مسار و تصيير أصلي نتيجة تماما نفسه، يشمل خطأ نص و غير نص كتلة. هذا حدث ما زال فقط لأجل سجل (`deriveMessages()` تجاهل اختصار هو): نموذج سياق لا يوجد أي تغير.
3. **`dsh` إعداد شجرة فوق `DSH_TOOLS_MODE` بيئة متغير**(`native`|`ptc`|`both`؛ لم ضبط وقت إبقاء schema قيمة افتراضية):`tools` سطر عبر `!!js` قراءة هو،worker شفرة وقت التشغيل فإن بلا شرط تركيب (هذا بند تسليم وقت loader بيانات وصفية ما زال هو ساكن حالة، لذلك لا وجود شرط سطر؛ بعد قدوم [`disabled` إدراج قيمة قرار](../architecture/2026-08-11-loader-entry-disabled-interpolation.zh.md) يجعل شرط سطر يصبح ممكن، لكن هذا موضع ثابت——native بدء فقط هو تسجيل هذا خدمة،worker يلزم إلى كل مرة وقت التشغيل عندئذ spawn). هذا هو واحد واضح علامة ملاحظة لـ مؤقت إعداد خطاف: تصميم هدف هو يجعل Web UI يملك حسب جلسة أداة نمط اختيار، هذا هدف سقوط أرض بعد، هذا عدد بيئة متغير مع أي تراجع دور.

## سبق اعتبار بديل خطة

**إبقاء محدود ملخص (رفع عال حد أعلى، أو حد أعلى إضافة `truncated` علامة سجل).** مرفوض: هذا كومة تراكم PR(Pull Request) سلسلة قد طرق تحديد اشتراط هو، فرعي استدعاء سطر و تفصيل حال يجب و أصلي استدعاء تصيير نيل*تماما متسق*؛ أي حد أعلى كل سوف قوي صنع جذب دخول ثاني بند تخفيض تصيير مسار، خارج إضافة قطع قطع UI. تحويل بينما قبول بديل قيمة هو: قراءة كبير ملف برنامج سوف يأخذ تصيير بعد محتوى أصل مثال سجل في توزيع حدث فوق، لا ضبط حد أعلى، يقع في spill سياسة خارج، و بـ نفس مثال بايت عدد زيادة كبير جلسة سجل. حفظ دائم فرعي هذا spill تجميع صار قد بصفة [ptc-dispatch سجل spill](2026-07-26-ptc-dispatch-log-spill.zh.md) تسليم.

**واحد `--tools-mode` CLI(أمر سطر واجهة) علامة سجل أو profile إعداد مفتاح.** دفع متأخر، بينما غير مرفوض: علامة سجل لغة قاعدة داكن عرض دائم دائم صفة،profile JSON أيضا هو مستخدم إعداد؛ اثنان من كل سوف ثابت تحويل هذا عدد seam، بينما حسب جلسة اختيار تصميم هذا حينئذ ضرب حساب إزالة هو. بيئة متغير فإن مثل فعلي عرض هو حق مناسب لـ حساب هذا جودة.

**سجل مواصفة `value`، بينما غير تصيير بعد `content`.** مرفوض:`tool/result` حفظ دائم هو محتوى بينما غير قيمة (رؤية[مواصفة إخراج اتفاق](../architecture/2026-07-20-canonical-tool-output-contract.zh.md)) ، و أصلي نفس انتظار حفظ حق معنى طعم حال و لـ دقيق مقابل متساو؛ قيمة بداية نهاية فقط وجود في تنفيذ مدة محلي.

## عاقبة

هذا UI تغيير ذاته لا اشتراط بنية صفة Session صيغة تمرير زيادة. قد إصدار v0 حافة الآن تجميد ربط يمكن قبول تاريخ توزيع payload و سوف ذلك إبقاء إلى v1؛ شاذ شكل خلط دمج بنية سوف في إصدار قبل يتم رفض. قائم PTC mode لقطة fixture(اختبار قبل وضع بيانات) قد إعادة تسجيل صنع. نموذج مرئي نطاق توسيع كبير:`run_code` schema(إضافة جديدة واحد لا بد ملء معامل) و كل واحد نسخة PTC mode توجيه النظام/أداة schema لقطة كل حدوث تغير.Web UI عمل مباشر بناء في جديد حدث تحميل حمل لـ فوق؛ كل فرعي استدعاء فوري تشغيل حالة قد يأخذ هذا حدث إعادة تشكيل لـ واحد مقابل توزيع start/end حدث ([فوري و سطر توزيع](2026-07-26-ptc-live-parallel-dispatch.zh.md)).
