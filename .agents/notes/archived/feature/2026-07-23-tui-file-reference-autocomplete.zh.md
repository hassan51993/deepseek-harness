# Agent Note: TUI ملف مرجع تلقائي تكملة كل

Status: implemented
Archived: 2026-08-04

[English](2026-07-23-tui-file-reference-autocomplete.md) | العربية

## مشكلة

TUI توفير بنية تحويل `@session` مرجع، لكن مستخدم في تحرير نص التوجيه وقت لا يمكن يمكن اعتماد أرض اكتشاف مساحة العمل مسار. اشتراط مستخدم تسجيل إقامة دقيق تأكيد مسار سوف إعطاء موجه إلى ملف طلب حمل قدوم لا لا بد يلزم مزعج إزعاج؛ إذا مباشر مرفق إضافة كل اختيار العربية عنصر، فإن سوف في نموذج حكم قطع ذلك محتوى هل متبادل صلة قبل احتلال استخدام سياق، و في أداة transcript(نص سجل) في إخفاء معتاد قاعدة `read` مراقبة نتيجة.

## قرار

TUI صيانة واحد لديه سعة كمية حد أعلى كما يمكن إلغاء رئيسي آلة مساحة العمل مسار بحث جذب، بـ نشط وثب جلسة عمل دليل لـ أصل. في token حد إدخال `@` سوف مقابل ملف و دليل إجراء نموذج غامض مطابقة؛ استعلام يتضمن `/` وقت سوف مباشر صف خروج إشارة تحديد دليل، قبول دليل بعد سوف متابعة تكملة كل، يتضمن فارغ أبيض مسار اعتماد `@"path with spaces"` شكل صيغة. بند إعداد تحكم نتيجة عدد كمية، بحث جذب كبير صغير و ترتيب حذف دليل أساس اسم. افتراضي ترتيب حذف `.git` و `node_modules`؛ مرة تاريخ حيث لا تتبع مع دليل رمز رقم رابط، أيضا لا تحليل تجاهل اختصار ملف.

اختيار ملف فقط سوف تغيير تحرير جهاز نص. إيداع مستخدم رسالة إبقاء ذاتي لكن `@path` كتابة قاعدة، لا يحمل حقن محتوى، إخفاء سياق أو مرجع كائن. تسجيل موجه إلى نموذج `read` أداة وقت،TUI سوف إضافة دخول واحد مستقر توجيه النظام مقطع، شرح `@` مسار هو مستخدم صريح مرجع، إشارة عرض نموذج في حاجة محتوى وقت استدعاء `read`، و منع توقف نموذج في استدعاء قبل صوت تسمية قد فحص ملف. أداة نتيجة سوف جعل يمكن إعادة استخدام نموذج غامض بحث جذب بطلان، لاحق تفاعل بسبب بينما قدرة يرى مساحة العمل في ممكن حدوث تغيير.

بنية تحويل جلسة رفع و إبقاء قائم لقطة دقيق تجهيز طريقة. و ملف مختلف، يتم مرجع جلسة لا يوجد عام نموذج جانب فحص بحث أداة؛ إذا يأخذ `@session` بسيط تحويل لـ صنف يشبه مسار وسم، نموذج سوف لا يمكن نيل أخذ ذلك محتوى.

## تجهيز اختيار خطة

**مباشر حقن اختيار العربية عنصر محتوى.** هذا نوع طريقة سوف في تحديد متبادل صلة صفة قبل إزالة استهلاك token، ممكن في تنفيذ إلى هذا مرجع قبل التقاط إلى قديم قديم محتوى، و التفاف مرور يمكن مراجعة حساب `read` استدعاء و نتيجة تسلسل.

**اشتراط استخدام خارجي ملف فحص بحث جهاز.** اعتماد `fd`،`rg --files` أو أخرى يمكن تنفيذ ملف، سوف جعل أساس أساس تكملة كل سلوك مع رئيسي آلة تثبيت حال حال بينما تغير، أيضا سوف زيادة إلغاء معالجة و عبر منصة دعم حمل تكرار مختلط درجة.

**استخدام نظام الملفات خدمة معتاد قاعدة دليل قائمة عملية إجراء اكتشاف.** هذا seam إبرة مقابل موجه إلى نموذج دقيق تأكيد نظام الملفات عملية إجراء أفضل تحويل، و كما ممكن يمثل بعيد مسار نطاق الأسماء؛ تمرير عودة نموذج غامض بحث جذب سوف زيادة مزود نحو إرجاع مرة عدد، و جعل تحرير جهاز تأخير متأخر و أداة سياسة اقتران دمج. رئيسي آلة جانب اكتشاف يجعل طرفية تفاعل إبقاء في محلي، معا وثيقة ما زال واضح شرح غير محلي نشر في نطاق الأسماء مقابل متساو حد.

**إضافة جديدة عبر حزمة ملف بحث وظيفة.** TUI هو هدف قبل وحيد مستهلك، بينما كما هذا سلوك يخص تحرير جهاز عرض بينما غير نموذج وظيفة؛ إضافة جديدة واحد مجموعة واجهة، تنفيذ و مستهلك حزمة سوف مرور مبكر تفكيك قسم هذا بند seam.

## أثر

مستخدم يمكن اكتشاف و إدراج دخول مسار، بينما اختيار عملية ذاته لن حمل قدوم عال فتح إلغاء، مقابل نموذج مرئي محتوى أيضا فقط حد مسار. نموذج ما زال يمكن ذاتي سطر قرار هل فحص ملف، أي فحص كل قدرة عبر قد سجل أداة transcript إعادة بناء. وجود `read` وقت، ثابت إشارة أمر سوف اختصار دقيق زيادة كبير TUI توجيه النظام؛ حاجة ملف محتوى طلب أيضا سوف زيادة مرة أداة نحو إرجاع.

تكملة كل متعمد اعتماد محدود تلميح صفة تصميم: تجاوز كبير نوع مساحة العمل ممكن حذف تجاوز مرور إعداد بحث جذب حد أعلى مسار، يتم تجاهل اختصار ملف ما زال ممكن ظهور، بعيد مسار أو وهمي محاكاة نظام الملفات نشر يجب يجعل TUI رئيسي آلة عمل دليل و `read` نطاق الأسماء مقابل متساو، لا فإن حاجة توفير مختلف تكملة كل واجهة. حزمة (package) اختبار ثابت token لغة قاعدة، ترتيب ترتيب، حد، إلغاء، بطلان، فقط إيداع مسار سلوك، مرئي قائمة مفرد و مفتاح قرص تكملة كل؛ تسليم TUI نشر مسؤول ذلك Loader و PTY تحقق استلام.
