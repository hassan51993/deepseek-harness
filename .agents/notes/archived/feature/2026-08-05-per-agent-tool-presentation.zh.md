# Agent Note: حسب agent أداة عرض طريقة، و `ptc` مسبق ضبط

Status: implemented
Archived: 2026-09-04

[English](2026-08-05-per-agent-tool-presentation.md) | العربية

## مشكلة

agent preset قد قدرة حسب جلسة تجميع واحد agent أداة، لكن إدارة لا هذه أداة بـ أي نوع**شكل**مقاومة بلوغ نموذج.PTC mode——واحد `run_code` أداة إضافة واحد نسخة توليد TypeScript SDK، استخدام واحد مقطع برنامج بديل واحد سلسلة استدعاء——هذا قبل هو مضيف `dsh-tools` ذلك واحد سطر فوق نشر درجة `mode` حقل. واحد نشر يلزم ما كل جلسة كل ركض PTC mode، يلزم ما واحد كل لا ركض، في هو ذلك عدد إظهار بينما سهل رؤية منتج شكل (مسبق ضبط اختيار جهاز داخل «شفرة نمط» و معيار/أقصى بسيط/إنشاء صنع و صف) بلا موضع أمان وضع.

«يأخذ tools تحت غرق إلى agent مستو وجه» هذا عدد حرف وجه قراءة قاعدة سطر لا عبر.`ctx.tools` لديه واحد دفعة تتبع لا تحت قدوم مضيف مستو وجه إزالة استهلاك من:`dsh-agent-loop` قراءة هو خاص مجدول seam،`dsh-apiproxy` قراءة هو presenter قدوم تصيير أداة بطاقة، كل أداة إضافة كل نحو داخل تسجيل. حسب هذا stack ذاتي ذات قاعدة——فقط لديه**كل**إزالة استهلاك من واحد بدء تحت غرق، خدمة عندئذ قدرة تحت غرق——سجل التسجيل يجب إبقاء في أصل أرض.

## قرار

يأخذ سجل التسجيل و هو إسقاط تفكيك فتح. سجل التسجيل إبقاء في مضيف مستو وجه؛**عرض طريقة**تغيير صار هو داخلي حسب scope حالة، و قد إقامة في ذلك داخل أثر مجال حد و حراسة حماية و صف.

`ToolRuntime.presentAs(mode)` فقط قبول scoped سياق، شكل حالة وفق نسخ `restrict()`: هو عبر `ScopedLayers.effect` في استدعاء جهة scope `ToolLayer` فوق كتابة واحد وحدة، لذلك سوف مع إعلان هو ذلك عدد scope واحد بدء إزالة. في مع مرفق Web واجهة داخل ذلك عدد scope هو بعض عدد agent preset معتاد إقامة تركيب——`ptc` preset يحمل `tool-presentation` سطر——لذلك واحد نسخة إعلان تغطية إضافة دخول هذا preset كل agent، بينما `modeFor(scope)` أخذ أثر مجال سلسلة فوق الأكثر قريب ذلك نسخة إعلان. هو و config `mode` واحد و تحليل، بعد من في هو يصبح «لم عمل إعلان scope» قيمة افتراضية، بينما لم يعد هو عملية درجة واقع. أصل أولا قرار عرض طريقة ثلاثة موضع قراءة——wire schema، مرئي صفة عرض داخل `run_code` بند، و توليد SDK مقطع——تعديل لـ قراءة هذا scope نمط، بينما غير خدمة.

لديه اثنان عدد مع لـ بينما قدوم نتيجة، كما كل هو تحمل إعادة:

- **`run_code` حسب scope إلحاق.** هذا قبل فقط يلزم نقل وجود، هو حينئذ دخول كل واحد عرض. حسب agent بعد، واحد native agent لا يستطيع لأن عملية داخل آخر agent عرض هو، حينئذ في ذاتي ذات توزيع جدول داخل يرى `run_code`——لذلك هذا مرة إلحاق بـ هذا scope ذاته نمط لـ شرط، نقل أيضا تعديل لـ أول مرة حاجة وقت عندئذ بناء.
- **إبقاء اسم الآن بلا شرط توليد فاعلية.** `run_code` هذا قبل فقط في إعداد PTC نمط وقت عندئذ يتم رفض تسجيل. مثل اليوم أي agent كل ممكن اختيار PTC نمط، لذلك واحد في native نشر تحت يمكن مع سهل احتلال استخدام اسم حرف، سوف في بعض عدد preset تركيب ذلك واحد لحظة تغيير صار اندفاع مفاجئ.

SDK نص التوجيه مقطع من PTC نمط نشر عام تسجيل (ثابت) ، و من `presentAs` مقدار خارج حسب scope تسجيل واحد نسخة، بعد من حسب اسم حرف حجب حجب قبل من. هو متن مقابل native scope تصيير لـ فارغ، بينما نص التوجيه مصير سوف إسقاط فارغ مقطع——صحيح هو هذا واحد نقطة يجعل «في PTC نمط نشر تحت اختيار خروج» agent لا حمل SDK مقطع.

preset استخدام واحد سطر قدوم جدول بلوغ هذا عدد اختيار:`@deepseek-ai/dsh-agent-tool-presentation`، ذلك الكل محتوى حينئذ هو مرة `presentAs` استدعاء.code صنف نمط عبر `ctx.inject` انتظار `ctx.codeRuntime` بينما غير زائف تحديد هو وجود: وقت التشغيل في مضيف مستو وجه، بينما واحد pending سطر صحيح هو `dsh-agent-presets` قد سوف تقرير إبلاغ «غير ممكن استخدام تركيب» و سوف إشارة اسم هذا سطر——في هو في بلا وقت التشغيل نشر فوق اختيار PTC mode preset، سوف في عملية من قدرة كاف حركة يد أرض جهة فشل.

## اعتبار مرور بديل خطة

**في preset isolate realm داخل مجددا بدء واحد `ToolRuntime`.** مرفوض:`dsh-agent-loop` عبر واحد خاص symbol من مضيف سياق مرة صفة تحليل سجل التسجيل، لذلك حسب agent سجل التسجيل مقابل مجدول غير ممكن رؤية. يأخذ loop تعديل صار حسب agent تحليل سجل التسجيل، بعيد مقارنة يأخذ واحد حقل تغيير صار scope شعور معرفة تعديل كبير.

**في preset ذاتي ذات YAML داخل إضافة واحد قمة طبقة مفتاح.** مرفوض، إدارة من و preset عرض بيانات وصفية سقوط إلى مستقل `preset.yml` نفسه: تجميع هو واحد قمة طبقة إضافة سطر قائمة، تركيب لا تحت و صف مفتاح.

**يأخذ حزمة تسمية لـ `dsh-tool-mode`.** يتم واحد طريق gate مرفوض، بينما كما هو هو مقابل.`gen-tool-catalog` بـ `packages/*/tool-*` عبر إعداد، و اشتراط كل أمر في بند إصدار واحد موجه إلى نموذج أداة schema——لأن في هذا مستودع داخل هذا عدد بادئة حينئذ معنى طعم حال «حمل أداة». بينما هذا واحد سطر لا حمل أي أداة.

**في بنية صنع دالة داخل بلا شرط تسجيل SDK مقطع.** تجربة مرور بعد مرفوض:`renderPrompt` سوف إسقاط فارغ مقطع، لكن `PromptAssembly.sections` سوف إبقاء هو جمع، في هو كل native نشر كل سوف يحمل واحد ماذا أيضا لا تصيير `tools:sdk` بند، بينما اثنان موضع قائم تأكيد لا نيل لا لـ هذا وضع عرض.

**استخدام include مشترك `standard` تجميع.** حسب هذا stack ذاتي ذات معتاد مثال مرفوض:`cordis` قد نسخ واحد نسخة `standard`، بينما preset قيمة قيمة تماما في في كامل نسخة تجميع قدرة في واحد ملف داخل قراءة تمام. بديل قيمة——رقم ثلاثة نسخة نحو 240 سطر، كما يجب تزامن عرض دخول فرعي هذا——هو حقيقي، أيضا صحيح هو لم قدوم جذب دخول include آلية الأكثر لديه قوة نقاش حسب.

## عاقبة

نفس عملية داخل اثنان عدد جلسة الآن يمكن لديه مختلف عرض طريقة، لذلك «نموذج يرى أي بعض أداة» لم يعد قدرة فقط سند نشر إعداد عودة جواب، يجب إعطاء خروج agent. كل هو مرجع نمط تشخيص معلومة، الآن مرجع كل هو هذا scope ، بينما لا هو خدمة.

`ctx.tools.schemas(agent)` ما زال هو هذا agent **قدرة**بيان، لا تلقي عرض طريقة أثر——انهيار تقليص فقط هو assembly داخل أداة. تأكيد «نموذج استلام إلى ماذا» اختبار يجب قراءة assembly؛`web-agent-presets.spec.ts` مقابل مع مرفق `ptc` مسبق ضبط معا تأكيد هذا عدد منطقة قسم اثنان جانب.

مع مرفق اسم مفرد تغيير صار أربعة عدد مسبق ضبط (معيار/شفرة/أقصى بسيط/إنشاء صنع) ، لذلك أي صف خروج هو جمع golden كل سوف تغيير حركة. لم تجميع code وقت التشغيل نشر لا يمكن تجميع أي PTC نمط preset؛ مع مرفق Web overlay حمل واحد،base تجميع لا يوجد.
