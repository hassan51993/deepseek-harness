# Agent Note: Web تثبيت manifest بيانات وصفية

Status: implemented
Archived: 2026-09-04

[English](2026-08-06-web-install-manifest.md) | العربية

## مشكلة

Web بناء ناتج قد لديه وثيقة عنوان و favicon، لكن لا يوجد يمكن توفير متصفح اكتشاف مستقر تثبيت هوية، بدء حد أو تثبيت بعد عرض طريقة manifest(بيانات وصفية بيان). إضافة هذا صنف بيانات وصفية أيضا ممكن داكن عرض تطبيق و لا أداة تجهيز قدرة:service worker سوف يجعل شخص بـ لـ تطبيق توفير مغادرة خط اتفاق، بينما مفرد واحد لغة أو ضبط لون لوح أخذ قيمة سوف خطأ وصف هذا عدد قدرة كاف تحليل ضحل لون و عميق لون رئيسي عنوان مزدوج لغة UI.

## قرار

Web مدخل رابط `/manifest.webmanifest`،Vite سوف سوف ذلك من `apps/web/public/` نسخ إلى إنتاج بناء ناتج.manifest سوف منتج تسمية لـ `DeepSeek Harness`، لـ تثبيت بعد متصفح واجهة توفير بسيط تسمية `DSH`، و يأخذ `id`،`start_url` و `scope` ثابت لـ `/`. هو طلب `display: "fullscreen"`، جعل دعم حمل هذا واحد نمط متصفح قدرة كاف يأخذ متاح عرض منطقة مجال تسليم إعطاء تثبيت بعد تحرير جهاز صيغة واجهة، معا لا تغيير عادي وسم صفحة؛ متصفح يمكن تطبيق مستخدم تغطية ضبط، أو رجوع إلى أخرى عرض نمط. ذلك رسم علامة بند إعادة استخدام `/favicon.svg`، سوف هو بصفة مقياس قياس لـ `any`، استخدام طريق لـ `any` SVG.

هذا واحد اختيار امتداد استخدام code-server كل شاشة خطة، لكن لا يوجد وفق نقل ذلك `window-controls-overlay` عرض تغطية بند.DSH لا يوجد ذاتي تعريف عنوان شريط، أيضا لا يوجد محيط التفاف أصلي نافذة تحكم عنصر أمان ترتيب تخطيط، لذلك استخدام هذا صنف تغطية بند سوف في لم سقوط فعلي الذي يحتاج أمان تخطيط حال حال تحت يحل محل كل شاشة نمط.

manifest متعمد لا يتضمن `lang`،`theme_color` أو `background_color`. منتج واجهة دعم حمل مزدوج لغة، و لا من manifest في مفرد واحد لغة تعريف؛ مهمة واحد ساكن حالة لون لون قيمة كل ممكن و تطبيق تحليل بعد واحد طقم ضبط لون لوح لا متسق. لذلك، رئيسي عنوان بيانات وصفية ما زال وضع في تثبيت manifest خارج.

هذا وظيفة لا إضافة service worker، ذاكرة مؤقتة سياسة أو مغادرة خط رجوع.manifest فقط توفير تثبيت بيانات وصفية؛ هل أداة تجهيز تثبيت مورد إطار، هل توفير تثبيت مدخل ما زال من متصفح سياسة قرار. فعلي تسليم [`dsh-host-frontend-static`](../../../../packages/host/frontend-static/README.zh.md) رجوع سوف `.webmanifest` تعرف آخر لـ `application/manifest+json`، لذلك نفس مورد إنتاج مرور فعلي تسليم HTTP تركيب توفير وقت نفس مثال صالح، بينما لا فقط في Vite إخراج دليل في صالح.

## تحقق

Web بناء ناتج اختبار تحليل إخراج manifest، و ثابت كامل بيانات وصفية كائن، يشمل موجه إلى مستخدم عرض اسم، بسيط تسمية، رسم علامة، أصل مسار هوية، بدء حد و عرض نمط، معا تحقق إنتاج بناء `index.html` ما زال إبقاء هذا رابط.`dsh-host-frontend-static` حقيقي Loader تركيب اختبار توفير واحد `.webmanifest` fixture(اختبار قبل وضع بيانات) ، و ثابت ذلك `application/manifest+json` وسيط جسم نوع.

## سبق اعتبار بديل خطة

**إضافة service worker، و إعلان تسمية تطبيق دعم حمل مغادرة خط.** غير مقبول، لأن فقط ذاكرة مؤقتة تطبيق خارج قشرة، لكن لا تعريف جلسة نقل، بطلان سياسة، فشل سلوك و ترقية دلالة، سوف شكل صار أداة لديه خطأ توجيه صفة لا كامل مغادرة خط اتفاق.

**إعلان مفرد واحد `lang`.** غير مقبول، لأن لا يوجد أي واحد نوع لغة كاف بـ وصف مزدوج لغة منتج واجهة؛ حذف هذا حقل يمكن تجنب تجنب صوت تسمية تثبيت بعد تجربة من بعض واحد نوع منطقة مجال ضبط وحيد احتلال.

**اختيار واحد مجموعة ساكن حالة خلف مشهد لون و رئيسي عنوان لون.** غير مقبول، لأن تطبيق سوف في وقت التشغيل تحليل ضحل لون و عميق لون ضبط لون لوح، لذلك اختيار مهمة واحد ثابت قيمة، كل هو واضح معرفة هو و منها واحد نوع تلقي دعم حمل حالة لا رمز.

**قيام أي تسليم ضوء شبكة و يمكن حجب غطاء رسم علامة تغيير جسم.** في بعض عدد تلقي دعم حمل تثبيت هدف إثبات قائم يمكن تقليص وضع favicon لا يمكن ممتلئ كاف ذلك اشتراط قبل، غير مقبول. جديد تغيير جسم فقط هو مقابل manifest زيادة كمية توسيع، و غير عام حالي هوية قبل رفع.

**فقط تأكيد بناء ناتج في أصل مسار حقل و عرض حقل.** غير مقبول، لأن منتج اسم، بسيط تسمية أو رسم علامة يتم حذف أو أكثر تعديل، نفس مثال يخص قد تسليم تثبيت تجربة ارتداد. أي manifest بيانات وصفية حدوث تغير وقت، اختبار كل متعمد اشتراط صريح تعديل.

## عاقبة

دعم حمل هذا واحد آلية متصفح يمكن اكتشاف بـ أصل مسار لـ أثر مجال مستقر تثبيت هوية و كل شاشة انحراف جيد، بينما تطبيق بلا حاجة تحمل وعد مغادرة خط سلوك. في مسار بادئة تحت نشر هذا بناء ناتج وقت، يجب معا إعادة مراجعة نظر قطعا مقابل مسار manifest رابط، و هوية، بدء، أثر مجال و رسم علامة URL. يوم بعد ممكن بسبب متصفح خاص لديه رسم علامة اشتراط بينما إضافة جديدة تغيير جسم؛ كل واحد بند متعمد بيانات وصفية تغيير كل سوف تزامن تحديث دقيق بناء ناتج اتفاق.
