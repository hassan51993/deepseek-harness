# Agent Note: من Bash دعم حمل grep و glob اكتشاف أداة

Status: implemented
Archived: 2026-07-27

[English](2026-07-09-bash-backed-grep-glob-discovery.md) | العربية

## مشكلة

harness حاجة موجه إلى نموذج `glob` و `grep` أداة، لكن إذا سوف هو جمع تنفيذ لـ `ctx.fs` مزود طريقة، حينئذ سوف يأخذ محلي منتج سهل فائدة وظيفة تغيير صار كل نظام الملفات خلفية كل يجب تنفيذ عقد نحو. محلي مساحة العمل اكتشاف يوم لكن ملائم دمج من عملية دعم حمل `rg` سير العمل؛ بعيد مسار أو وهمي محاكاة نظام الملفات خلفية ممكن عام ذاتي ذات بحث API، ممكن لا يمكن مشترك محلي `ripgrep` عرض، أيضا ممكن تماما لا دعم حمل اكتشاف. ملف قراءة/كتابة/تحرير seam بعد لم إثبات هذا يحتاج طلب قبل،v1 لا ينبغي اشتراط كل نظام الملفات خلفية كل تنفيذ بحث.

بحث إخراج أيضا تلقي إلى اثنان طبقة مختلف ميزانية قيد. أداة حاجة كاف كاف كثير أصلي `rg` إخراج، عندئذ قدرة حساب حساب مستقر منطق نتيجة؛ نموذج فإن فقط قدرة استلام إلى محدود معاينة، و في صيغة تحويل نتيجة تجاوز خروج داخل ربط ميزانية وقت نيل نيل استعادة مسار. عام سقوط قرص سياسة فقط قدرة يرى نهائي أداة نتيجة، لذلك لا يمكن استعادة بحث أداة قد حذف مطابقة بند. بحث أداة يجب ذاتي سطر مسؤول إبقاء، و كل قوة سقوط قرص صيغة تحويل نتيجة.

## قرار

`glob` و `grep` هو `@deepseek-ai/dsh-tool-fs-search` في شرط صيغة موجه إلى نموذج أداة، من bash seam دعم حمل، لن يصبح جديد `ctx.fs` مزود طريقة. تحميل إضافة وقت، هذا حزمة (package) تنفيذ `command -v rg >/dev/null 2>&1`: أولا عبر `ctx.bash.resolve(request)` تحليل طلب، مجددا عبر `ctx.bash.run(spec)` تشغيل؛ إذا أمر بـ غير صفر حالة خروج، هذا حزمة سوف سجل تحذير إبلاغ، و كما حيث لا تسجيل أداة، أيضا لا تسجيل نص التوجيه فصل عقدة. إذا استكشاف إبرة لا يمكن بدء، مهلة، في توقف، يتم إنهاء، أو لا يوجد إنتاج خروج رمز، إضافة تحميل سوف واضح فشل، لأن هذا معنى طعم حال bash منفذ ضرر تالف، بينما لا هو اختياري اثنان دخول صنع ملف ناقص. تسجيل بعد، تنفيذ مسار نفس مثال اعتماد مرة استدعاء `ctx.bash.resolve(request)` و `ctx.bash.run(spec)`، و استخدام أداة تجميع ثابت `rg` أمر نموذج لوح. أداة طبقة مسؤول schema، معامل تحقق،shell مرجع، نتيجة تحليل، نتيجة صيغة تحويل، إبقاء، صيغة تحويل نتيجة سقوط قرص تسليم وصل، و مهلة إعلان.bash منفذ مسؤول طلب قيمة افتراضية تحليل و حد أعلى تحكم، عملية فرعية تنفيذ، عملية مجموعة إنهاء، بيئة تنظيف، أصلي إخراج التقاط، و في محلي، صندوق رملي أو بعيد مسار bash تنفيذ بين استبدال خلفية.

هذه أداة لا استخدام `ctx.bash.start()`، أيضا لا إنشاء نموذج مرئي خلفية مهمة. من agent loop(ذكي جسم حلقة) نظر زاوية نظر، هو جمع هو عادي قبل منصة أداة: فقط لديه عند `rg` أمر خروج، مهلة، في توقف أو فشل بعد، أداة استدعاء عندئذ إرجاع.`defineTool({ timeoutMs })` إعلان تنسيق عمل صيغة أداة استدعاء ميزانية،`@deepseek-ai/dsh-timeout-policy` عبر `exec.signal` قوي صنع تنفيذ؛ أداة سوف في `resolve()`/`run()` قبل سوف هذا إشارة تحويل إرسال إعطاء bash طلب.bash خلفية ذاته مهلة ما زال بصفة ثاني طبقة أمان حد أعلى؛ أولا إطلاق في توقف توليد فاعلية.

هذه أداة جعل `path` و Claude Code بحث أداة إبقاء متسق، لكن سوف تحليل ربط إلى bash workdir، بينما لا هو `ctx.fs`. أداة من `exec.agent?.session.header.cwd` إرسال توليد bash طلب workdir، و `dsh-tool-bash` و `dsh-tool-fs` متسق؛ إذا جلسة لا يوجد cwd، هو سوف حذف `request.workdir`، من bash تنفيذ عبر `resolve()` تطبيق ذلك إعداد cwd أو عملية cwd. مقابل في `grep`،`path` هو اختياري ripgrep هدف، يمكن هو ملف أو دليل؛ حذف وقت استخدام قد تحليل bash workdir. مقابل في `glob`،`path` هو اختياري دليل بحث أصل؛ حذف وقت نفس مثال استخدام قد تحليل bash workdir. متبادل مقابل `path` قيمة أساس في هذا workdir تحليل. فقط يلزم يمكن سطر، إرجاع مسار حينئذ سوف عرض لـ متبادل مقابل في قد تحليل bash workdir شكل صيغة؛ فقط لديه في مشترك وضع نشر في،bash workdir و نظام الملفات `read` أصل إشارة نحو نفس عدد مساحة العمل وقت، هذه مسار عندئذ حفظ إثبات يمكن متابعة قراءة.v1 سوف سجل هذا بند نشر اشتراط، لكن لا تنفيذ عبر خدمة وقت التشغيل تحقق. في شكل صار مشترك مساحة العمل/أصل عقد نحو أو مزود مخصص استخدام بحث خلفية قبل، بعيد مسار أو وهمي محاكاة نظام الملفات بحث إبقاء مؤقت مؤقت.

هذا حزمة لا حقن `fs`، بينما هو حقن `tools`،`systemPrompt` و `bash`؛ هو متعمد قراءة `spillStore` وقت استخدام `ctx.get('spillStore')`، بينما لا استخدام ساكن حالة حقن، لأن صيغة تحويل نتيجة سقوط قرص هو اختياري وظيفة. قائم `@deepseek-ai/dsh-tool-fs` نشر إذا فقط حاجة `read`/`write`/`edit`، فإن بلا حاجة تحميل bash. تحميل بحث وظيفة نشر فإن يجب يجعل bash منفذ بيئة يمكن استخدام `rg`، هذه أداة عندئذ سوف دخول نموذج مرئي schema.

### حزمة بنية

v1 حزمة إبقاء دقيق بسيط.`@deepseek-ai/dsh-tool-fs-search` داخلي مصدر شفرة تخطيط مثل تحت:

```text
src/index.ts
src/glob.ts
src/grep.ts
src/search-core.ts
src/shell-quote.ts
```

`glob.ts` و `grep.ts` كل منها مسؤول معامل تحقق، أمر بنية صنع، نتيجة تحليل، صيغة تحويل و تسجيل.`shell-quote.ts` هو واحد مشترك مساعد مساعدة وحدة، لأن shell مرجع هو اثنان عدد أداة كل يجب مرور مرور أمان حد؛`search-core.ts` هو آخر عدد مشترك وحدة (تنفيذ وقت مقابل أصل أربعة ملف خطة الذي عمل إصلاح حجز):`SEARCH_*` خطأ مفردات،bash تشغيل و أصلي إخراج نيل أخذ، صيغة تحويل نتيجة سقوط قرص تسليم وصل، و workdir متبادل مقابل عرض، في اثنان عدد أداة في تماما نفسه. إذا في كل أداة في تكرار هذا طقم دقيق دقيق إدارة طريق، صحيح هو مقابل تسمية صفة اتفاق الذي إشارة خروج تسرب رفع أخذ مشكلة. أمر منشئ منع توقف ذاتي سطر تجميع تجميع مرجع، أيضا لا يستطيع يأخذ لم مرور مرجع، من نموذج تحكم قيمة مباشر اتصال إلى shell أمر في.

### Schema و إعداد

`glob` عام دقيق بسيط اكتشاف شكل حالة:

```ts
interface GlobArgs {
  pattern: string
  path?: string
}
```

`grep` عام OpenCode ريح إطار الأكثر صغير شكل حالة:

```ts
interface GrepArgs {
  pattern: string
  path?: string
  include?: string
}
```

معتاد قاعدة ميزانية لن دخول موجه إلى نموذج schema.`@deepseek-ai/dsh-tool-fs-search` يملك التالي حمل قيمة افتراضية و مرور مرور تحقق إعداد حقل:

| حقل | قيمة افتراضية | أثر |
|---|---:|---|
| `globMaxResults` | `100` | داخل ربط إبقاء الأكثر كبير مسار عدد؛ و Claude Code افتراضي `GlobTool` نتيجة حد أعلى متسق. |
| `grepMaxMatches` | `250` | داخل ربط إبقاء الأكثر كبير مسطح مستو مطابقة عدد؛ و Claude Code افتراضي `GrepTool` `head_limit` متسق. |
| `grepMaxLineBytes` | `2000` | كل بند مطابقة سطر معاينة إبقاء الأكثر كبير بايت عدد، عبر `TextRetainer({ kind: 'head', maxBytes: grepMaxLineBytes })` تطبيق. |
| `rawOutputMaxBytes` | `20000000` | أداة سوف تحليل كامل أصلي `rg` stdout الأكثر كبير بايت عدد؛ و Claude Code ripgrep أصلي مؤقت اندفاع منطقة متسق. |
| `timeoutMs` | `30000` | مرفق إضافة إلى اثنان عدد أداة تعريف و من `@deepseek-ai/dsh-timeout-policy` قوي صنع تنفيذ أداة استدعاء مهلة. |

`globMaxResults` و `grepMaxMatches` استخدام `ItemRetainer({ kind: 'head' })`.`grepMaxLineBytes` إبرة مقابل كل بند مطابقة سطر استخدام `TextRetainer({ kind: 'head', maxBytes: grepMaxLineBytes })`، جعل معاينة قطع قطع إبقاء UTF-8 حد. هذا التزام دوران[أداة نتيجة إبقاء مكتبة](../architecture/2026-07-06-tool-result-retention-library.md) مقابل اكتشاف بند خريطة: استلام تجميع كامل نتيجة، في داخل ربط نتيجة في إبقاء رأس جزء بند، و سوف مسار خريطة، قسم مجموعة و تدريجي سطر معاينة وضع في إبقاء جهاز خارجي.v1 `grep` لا عام `case_insensitive`،`head_limit`،`offset`،`count`، كثير سطر، سياق سطر، إخراج نمط أو ملف نوع مرور ترشيح جهاز. نموذج مثل يحتاج دورة حافة سياق، يمكن استخدام `read` قراءة مطابقة ملف؛ مثل يحتاج لاحق نتيجة، فإن التزام دوران إرجاع سقوط قرص تحديد موضع رمز الذي إعطاء خروج فحص بحث تلميح.

Claude Code عدد قيمة فقط هو اثنان طبقة ميزانية مشاركة اعتبار نقطة، و غير موجه إلى نموذج schema أولا مثال. ذلك مخصص استخدام بحث أداة سوف مؤقت اندفاع الأكثر كثير 20 MB أصلي ripgrep إخراج لأجل داخلي معالجة؛ في غير WSL منصة فوق استخدام 20 ثانية ripgrep مهلة، في WSL فوق استخدام 60 ثانية، بعد عندئذ في نموذج يرى نتيجة قبل تطبيق بحث مخصص استخدام حد أعلى:`GrepTool` افتراضي `head_limit = 250`، و حفظ دائم تجاوز مرور 20,000 عدد محرف صيغة تحويل نتيجة؛`GlobTool` افتراضي الأكثر كثير 100 بند مسار، و حفظ دائم تجاوز مرور 100,000 عدد محرف صيغة تحويل نتيجة. هذا Agent Note اعتماد نفس مثال أصلي مؤقت اندفاع منطقة و داخل ربط عدد كمية قيمة افتراضية، سوف افتراضي بحث مهلة ضبط لـ 30 ثانية، و عبر هذا harness `ctx.spillStore.saveText()` مسار استعادة صيغة تحويل نتيجة.

`path` حقل امتداد استخدام و Claude Code نفسه منطقة قسم طريقة:`grep.path` هو ملف أو دليل شكل صيغة ripgrep هدف،`glob.path` فإن هو دليل بحث أصل.v1 لا لـ هذه أداة عام مفرد وحيد cwd/workdir معامل.

`include` هو واحد صحيح نحو glob مرور ترشيح جهاز، لا هو قائمة، أيضا لا هو ترتيب حذف لغة قاعدة. نظام سوف مسبق أولا رفض فاصلة رقم قسم فصل أو أخذ عكس include نمط، و إرجاع بنية تحويل معامل خطأ.shell أمر في استخدام كل نموذج تحكم قيمة، يشمل `pattern`،`path` و `include`، كل يجب مرور مرور حزمة خاص shell مرجع مساعد مساعدة وحدة.

### تنفيذ

`glob` بناء ثابت `rg --files` أمر، و بـ تحليل بعد دليل بحث أصل لـ أصل (توفير `path` وقت استخدام هذا قيمة، لا فإن استخدام bash workdir):`rg --files --glob <pattern> --sort=modified --no-ignore --hidden`، آخر إضافة إبرة مقابل `.git`،`.svn`،`.hg`،`.bzr`،`.jj` و `.sl` VCS بيانات وصفية ترتيب حذف بند. هذا مثال حيث و Claude Code إخفاء/تجاهل اختصار ملف اكتشاف و تعديل وقت ترتيب ترتيب إبقاء متسق، أيضا تجنب تجنب عرض عام بحث يتضمن VCS داخلي ملف. أداة تدريجي سطر تحليل مسار، فقط يلزم يمكن سطر حينئذ سوف نتيجة خريطة لـ متبادل مقابل في bash workdir مسار، سوف كل بند مسار دفع دخول `ItemRetainer({ kind: 'head', maxItems: globMaxResults })`؛ عند إبقاء نتيجة بلوغ إلى حد أعلى وقت، هو سوف صيغة تحويل كامل قد ترتيب ترتيب مسار قائمة، بصفة سقوط قرص ناتج.

`grep` بناء ثابت تدريجي سطر `rg --json` أمر، أثر في الذي توفير ملف/دليل هدف (توفير `path` وقت استخدام هذا قيمة، لا فإن استخدام bash workdir) ، من بينما بلا حاجة حسب خطر رقم تفكيك قسم، حينئذ قدرة تحليل ملف مسار، سطر رقم و سطر نص. هو إزالة استهلاك `match` سجل، سوف صيغة خطأ JSON أو مطابقة سجل نظر لـ `SEARCH_FAILED`؛ فقط يلزم يمكن سطر، حينئذ سوف نتيجة مسار خريطة لـ متبادل مقابل في bash workdir مسار؛ عبر `grepMaxLineBytes` تطبيق تدريجي سطر معاينة إبقاء، سوف كل مطابقة دفع دخول `ItemRetainer({ kind: 'head', maxItems: grepMaxMatches })`، لكن بعد فقط حسب ملف قسم مجموعة داخل ربط إخراج في إبقاء معاينة مطابقة. سقوط قرص ناتج حفظ كامل صيغة تحويل مطابقة قائمة، بينما لا هو فقط حفظ حذف ذيل جزء، لذلك فحص بحث تلميح إشارة نحو نموذج قد يرى نفس منطق نتيجة.

أصلي `rg` stdout هو داخلي نقل دقيق عقدة. أداة طلب `stdoutMaxBytes: rawOutputMaxBytes`، و عبر `ctx.bash.resolve()` تحليل؛ فقط لديه عند منفذ في هذا حد أعلى داخل إرجاع لم قطع قطع stdout وقت، أداة عندئذ تحليل `stdout.text`. إذا stdout تجاوز مرور `rawOutputMaxBytes`، أو من منفذ ما زال إرجاع `stdout.truncated`، أداة سوف بـ واضح بحث خطأ فشل، اشتراط نموذج تقليص صغير `pattern`،`path` أو `include`. أداة أبدا نحو نموذج عام أصلي `rg` إخراج أو bash أصلي سقوط قرص مسار.

فقط لديه stdout هو تحليل مصدر. مقابل في بلا فاعلية نمط، تسجيل بعد وقت التشغيل `rg` إزالة فقد، و بحث فشل،stderr بصفة تشخيص نص؛ إذا bash قطع قطع stderr، أداة سوف استخدام إبقاء stderr ذيل جزء و مرفق إضافة قطع قطع شرح، لن قراءة `stderr.spillPath`.

إذا `ctx.bash.run()` بسبب أداة مهلة أو استدعاء جهة إلغاء إطلاق بينما تقرير إبلاغ `aborted`، أداة سوف إرجاع بنية تحويل فشل، بينما لا هو زائف تركيب لا يوجد مطابقة بند. إذا bash ذاته مهلة أولا إطلاق، أداة نفس مثال سوف بـ واضح مهلة رسالة فشل. غير صفر ripgrep خروج دلالة من أداة مسؤول: خروج رمز 0 يمثل وجود مطابقة و نجاح؛ خروج رمز 1 يمثل لا يوجد مطابقة لكن نجاح؛ بلا فاعلية نمط، وقت التشغيل `rg` إزالة فقد أو لا يمكن وصول بحث workdir فإن يمثل فشل.

بحث فشل استخدام حزمة ذاتي لديه `HarnessError` فرعي صنف و `SEARCH_*` شفرة، بينما لا استخدام `FsErrorCode`، لأن هذه أداة لا هو `ctx.fs` مزود عملية.v1 مفردات يشمل `SEARCH_INVALID_PATTERN`،`SEARCH_FAILED`،`SEARCH_RAW_OUTPUT_OVERFLOW` و `SEARCH_ABORTED`. نقص قليل لا بد ملء حقل، فارغ نص أو لا دعم حمل أخذ عكس/قائمة صيغة `include` قيمة انتظار نموذج معامل تحقق فشل، ما زال بصفة عادي أداة معامل خطأ معالجة.

### صيغة تحويل نتيجة سقوط قرص

`ctx.spillStore` هو اختياري خدمة، فقط لأجل موجه إلى نموذج صيغة تحويل نتيجة. هذا هو شفرة مكتبة في أول عدد أداة ذاتي لديه سقوط قرص استدعاء نمط؛ هذا تصميم متعمد لـ لـ، لأن بحث إبقاء يخص بند درجة سياسة:`globMaxResults` حد مسار عدد،`grepMaxMatches` حد مطابقة عدد، بينما أداة هذا وقت ما زال يحتفظ كامل منطق نتيجة. عام `dsh-spill-policy` سوف في `tools/post-execute` مرحلة مقطع حد نهائي نص بايت عدد؛ إلى ذلك وقت بحث أداة قد حذف لاحق مسار أو مطابقة، سياسة لا يمكن استعادة هو جمع.

عند بحث إنتاج منطق نتيجة عدد تجاوز مرور داخل ربط حد أعلى، كما `ctx.spillStore` وجود وقت، أداة سوف عبر `saveText()` حفظ كامل صيغة تحويل نتيجة. سقوط قرص كل من هو استدعاء agent جلسة رأس id(`exec.agent?.session.header.id`) ؛ نقص قليل هذا كل من وقت، بحث سوف إبقاء داخل ربط نتيجة، و تقرير إبلاغ كامل نتيجة لا يمكن حفظ. سقوط قرص مصدر هو أداة تنفيذ هوية:`{ toolName: exec.name, callId: exec.callId, label: 'result' }`. بناء اقتراح ملف اسم لـ `grep-results.txt` و `glob-results.txt`؛ سقوط قرص خلفية ما زال سوف هو جمع نظر لـ تلميح، بينما لا هو مسار.

إذا سقوط قرص تخزين لا وجود، استدعاء لا يوجد جلسة كل من، أو حفظ فشل، أداة ما زال إرجاع داخل ربط صفحة و صفحة قدم، شرح كامل نتيجة لا يمكن حفظ. صيغة تحويل نتيجة سقوط قرص تخزين غير ممكن استخدام ذاته أبدا قدرة يأخذ بحث نجاح تغيير لـ `isError` نتيجة.

bash أصلي إخراج تدفق و صيغة تحويل بحث سقوط قرص ناتج هو اثنان عدد مختلف ناتج. أصلي `rg` stdout فقط سوف في الذي طلب bash stdout حد أعلى داخل في داخل تخزين في تحليل؛ صيغة تحويل سقوط قرص ناتج فإن هو `ctx.spillStore.saveText()` توليد مستقر، موجه إلى نموذج استعادة تحديد موضع رمز.

### نتيجة شكل حالة

حمل لديه نجاح صيغة تحويل سقوط قرص تلقي حد `glob` نتيجة سوف إرجاع داخل ربط صفحة و سقوط قرص إشعار:

```text
<first N paths>

(Showing N of M paths. Full sorted result stored at: /.../session-abc123/9f8e7d-glob-results.txt. Use read with offset/limit, or grep this path to search within it.)
```

حمل لديه نجاح صيغة تحويل سقوط قرص تلقي حد `grep` نتيجة سوف إرجاع قسم مجموعة بعد معاينة مطابقة و سقوط قرص إشعار:

```text
Found N of M matches

<file>
Line 12: ...

(Full grep result stored at: /.../session-abc123/9f8e7d-grep-results.txt. Use read with offset/limit, or grep this path to search within it.)
```

إذا كامل منطق نتيجة لم تجاوز مرور داخل ربط حد أعلى، نظام لن إنشاء صيغة تحويل سقوط قرص ناتج. إذا كامل منطق نتيجة مرور كبير لكن لا يمكن صيغة تحويل سقوط قرص، صفحة قدم سوف شرح نتيجة قد تلقي حد، كامل نتيجة لا يمكن حفظ.`truncated`/حذف حساب عدد هو ميزانية واقع، و لا يمثل بحث لا كامل؛ مهلة، بلا فاعلية صحيح فإن جدول بلوغ صيغة، وقت التشغيل `rg` إزالة فقد، لا يمكن وصول workdir، أصلي إخراج فيض خروج، قفز مرور اثنان دخول صنع ملف و تحليل فشل، ما زال يخص أداة مجال خطأ أو لا كامل حقل.

## اعتبار مرور بديل خطة

**سوف `glob`/`grep` وضع في `ctx.fs` فوق.** v1 لا اعتماد: هذا سوف إجبار جعل كل نظام الملفات خلفية زيادة بحث API، و جعل محلي ripgrep سلوك يصبح مزود seam واحد جزء. بحث هو لديه استخدام منتج سلوك، لكن لا مثل `readText` أو `writeText` ذلك مثال يخص عام نص تخزين أصل لغة.

**مباشر من `dsh-fs-local` spawn ripgrep.** هذا Agent Note v1 لا اعتماد: مباشر spawn توفير الأكثر بسيط نظيف argv حد،stdout/stderr تحكم و رفع قبل إيقاف تحكم، لكن سوف تكرار bash seam قد مسؤول عملية تنفيذ أمر بند، يشمل بيئة تنظيف، عملية مجموعة إنهاء، مهلة نقل بث، صندوق رملي/بعيد مسار منفذ استبدال، و محدود إخراج التقاط. إذا bash دعم حمل بحث يتم إثبات مرور في اعتماد shell نص، أو يجب دعم حمل قبل منصة تدفق صيغة إخراج، هذا خطة ما زال هو دمج إدارة أفضل تحويل.

**عبر `ctx.bash.start()` تنفيذ تدفق صيغة رفع قبل إيقاف.** لا اعتماد:`start()` سوف إنشاء نموذج مرئي خلفية مهمة دلالة، يشمل task id، كل من token،`bash_output`،`bash_kill`، إتمام إشعار، و كما لا يوجد داخل وضع مهلة.`grep` حاجة قبل منصة أداة نتيجة، بينما لا هو خلفية bash سير العمل. إذا سوف قدوم يجب تدفق صيغة بحث، صحيح تأكيد سحب كائن هو في bash/عملية seam فوق زيادة قبل منصة تدفق صيغة عملية جملة مقبض، بينما لا هو استعارة استخدام عام خلفية مهمة API.

**نحو نموذج عام bash أصلي سقوط قرص مسار.** لا اعتماد:bash أصلي سقوط قرص مسار يتضمن أصلي `rg` stdout(مقابل في grep أي `rg --json` سجل) ، و غير مستقر صيغة تحويل بحث نتيجة. بحث فقط يأخذ أصلي stdout عند عمل داخلي نقل؛ نموذج استعادة استخدام عبر `ctx.spillStore.saveText()` حفظ صيغة تحويل نتيجة.

**أولا لـ bash إخراج مواصفة تحويل زيادة `spillStore.saveFile()`.** هذا Agent Note v1 لا اعتماد: لم قدوم مواصفة تحويل bash وقت،`saveFile()` يمكن مساعدة مساعدة سوف قائم منفذ سقوط قرص ملف نقل حركة إلى جلسة نطاق سقوط قرص تخزين، لكن بحث فقط يحتاج في توليد موجه إلى نموذج ناتج قبل، في داخل تخزين في نيل أخذ محدود أصلي `rg` stdout.`saveText()` كاف بـ حفظ صيغة تحويل بحث نتيجة.

**اعتماد عام `dsh-spill-policy`.** لا اعتماد: عام post-execute سقوط قرص فقط قدرة يرى نهائي أداة نتيجة. إذا `grep`/`glob` داخل ربط إرجاع رقم واحد صفحة، عام سياسة لا يمكن استعادة حذف نتيجة. بحث أداة يجب في إرجاع محدود موجه إلى نموذج نص قبل، ذاتي سطر حفظ كامل صيغة تحويل نتيجة.

**عام Claude Code كامل `GrepTool` schema.** v1 لا اعتماد:`output_mode`، سياق علامة سجل، كثير سطر،`head_limit`،`offset`،`case_insensitive` و نوع مرور ترشيح جهاز سوف جعل موجه إلى نموذج واجهة تغيير صار ripgrep حزمة تركيب طبقة. هذا harness سوف معتاد قاعدة ميزانية و متابعة نقل آلية إبقاء في نشر سياسة و سقوط قرص ناتج في.

**إبقاء رفع قبل إيقاف بحث، و حذف صيغة تحويل سقوط قرص ناتج.** هذا رفع سجل لا اعتماد: رفع قبل إيقاف فاعلية معدل أكثر عال، لكن لا إعطاء نموذج فحص لاحق نتيجة مسار. الذي اختيار v1 أولوية حفظ إثبات نتيجة يمكن استعادة صفة و تنفيذ بسيط نظيف صفة، و بـ `timeoutMs`،`rawOutputMaxBytes`،bash خلفية حد أعلى و صيغة تحويل سقوط قرص ناتج بصفة أمان بعد تجهيز.

**أولا توسيع bash seam، زيادة أصلي إخراج قراءة جهاز.** لا اعتماد: يمكن نقل غرس `readRawOutput(ref, maxBytes)` API سوف زيادة مرجع دورة الحياة، إذن و خلفية تخزين دلالة. تدريجي مرة تشغيل `stdoutMaxBytes` طلب هو أكثر ضيق seam: بحث يلزم ما في `rawOutputMaxBytes` داخل استلام إلى كامل stdout، يلزم ما واضح فشل.

**بداية نهاية تسجيل، فقط لديه تنفيذ وقت عندئذ تقرير إبلاغ نقص قليل `rg`.** لا اعتماد: نموذج مرئي أداة schema هو نشر قدرة كاف محاولة تجربة هذا قدرة تحمل وعد. إذا bash منفذ في تحميل وقت بحث لا إلى ripgrep، أكثر أمان واجهة هو تماما لا يوجد `glob`/`grep` أداة أو نص التوجيه إشارة جذب. مقابل في تسجيل بعد حدوث بيئة تغير حال حال، تنفيذ وقت `rg` ناقص تصنيف ما زال بصفة منع صد صفة رجوع.

## اختبار

- اختبار تغطية تسجيل وقت `rg` استكشاف قياس (استكشاف قياس نجاح سوف تسجيل اثنان عدد أداة و نص التوجيه فصل عقدة؛ غير صفر استكشاف قياس سوف قفز مرور أداة و نص التوجيه فصل عقدة تزامن خروج تحذير إبلاغ؛ أساس أساس ضبط تطبيق استكشاف قياس فشل سوف رفض إضافة تحميل) ، إثبات في توقف `exec.signal` سوف وصول bash خلفية (عبر نفس مرجع spec تأكيد و `SEARCH_ABORTED` نتيجة) ، و تغطية أمر بنية صنع/مرجع (سيئ معنى نمط، حمل فارغ إطار مسار، بـ قصير أفقي خط فتح رأس قيمة، جذب رقم، تبديل سطر،glob عنصر محرف: قائم وحدة تأكيد، أيضا إبرة مقابل كل سيئ معنى قيمة تنفيذ حقيقي `bash -c` نحو إرجاع) ، سوف `grep.path` استخدام عمل ملف و دليل هدف، سوف `glob.path` استخدام عمل دليل بحث أصل، بلا فاعلية نمط معالجة، بلا مطابقة، صيغة خطأ `rg --json` إخراج، مطابقة سطر معاينة قطع قطع، أصلي إخراج فيض خروج، مهلة/في توقف، صيغة تحويل سقوط قرص نجاح/فشل، حزمة ذاتي لديه `SEARCH_*` خطأ شفرة، و بلا خلفية مهمة ثابت كمية.
- مباشر تغطية رقم واحد جهة أداة ذاتي لديه سقوط قرص أولا مثال: سقوط قرص خلفية وجود، سقوط قرص خلفية ناقص،`saveText()` فشل، و نقص قليل سقوط قرص كل من.
- هذا حزمة عبر حقيقي Loader مسار تغطية نطاق الأسماء إضافة توجيه خروج شكل حالة (`name`،`inject`،`Config` و `apply`، كما لا يوجد افتراضي توجيه خروج).
- حقيقي منفذ اختبار تكامل (`dsh-bash-local` + حقيقي `rg`) تحقق خارجي عالم حد: سيئ معنى نمط إبقاء كسول صفة، تدريجي جلسة cwd تحليل،VCS بيانات وصفية ترتيب حذف، حسب تعديل وقت ترتيب ترتيب، و حقيقي ripgrep stderr تصنيف. إذا اختبار عملية PATH في لا يوجد `rg`، هذا اختبار سوف ذاتي سطر قفز مرور (هذا هو و بلا مفتاح e2e قفز مرور متبادل يشبه CI توافق إجراء تطبيق) ؛ زائف منفذ اختبار تغطية تسجيل و تنفيذ وقت نقص قليل `rg`، و من تدريجي ملف 100% نسبة التغطية بوابة التقاط قاع.
- transcript مرئي سقوط قرص إشعار ما زال لديه لقطة نقص فتحة: هذا وظيفة دمج دخول وقت سجل نقص فتحة شرح، لا يوجد لقطة. لقطة طبقة سوف إعادة تشغيل acp-agent شجرة؛ في منها إضافة دخول بحث إضافة سوف تغيير تجميع توجيه النظام، يجب استخدام حقيقي مفتاح إعادة تسجيل صنع كل واحد نسخة مسبق مدة إخراج، بينما تنفيذ بيئة لا يوجد مفتاح. سقوط قرص إشعار تأكيد قطع transcript نص من اختبار وحدة ثابت (`formatGlobOutput`/`formatGrepOutput` و عبر سجل التسجيل تنفيذ سقوط قرص اختبار) ؛ تحت مرة يملك مفتاح جلسة ينبغي يأخذ إضافة وصل دخول acp-agent شجرة، و تشغيل مرة `test:snapshot:record`.

## عاقبة

- `glob` و `grep` هو `@deepseek-ai/dsh-tool-fs-search` في شرط صيغة موجه إلى نموذج أداة، لا هو `ctx.fs` مزود طريقة، أيضا لا يخص قائم `@deepseek-ai/dsh-tool-fs` أصل إضافة. فقط لديه bash منفذ قدرة بحث إلى `rg` وقت عندئذ سوف تسجيل؛ هذا حزمة حقن `tools`،`systemPrompt` و `bash`، لا حقن `fs`، و جعل `ctx.spillStore` إبقاء اختياري، قراءة وقت استخدام `ctx.get('spillStore')`.
- Schema صارم إطار لـ `glob(pattern, path?)` و `grep(pattern, path?, include?)`؛ بحث حد أعلى و مهلة هو حمل قيمة افتراضية و مرور مرور تحقق Config حقل (`globMaxResults`،`grepMaxMatches`،`grepMaxLineBytes`،`rawOutputMaxBytes`،`timeoutMs`).
- أداة عبر `ctx.bash.resolve(request)` → `ctx.bash.run(spec)` تنفيذ، تحويل إرسال `exec.signal`، أبدا استدعاء `ctx.bash.start()`، أيضا أبدا عام bash task id. إذا وجود `exec.agent?.session.header.cwd`،bash طلب workdir قدوم ذاتي هذا قيمة؛ تحليل بعد `spec.workdir` قرار تنفيذ و متبادل مقابل مسار عرض.
- أداة نحو bash seam طلب `stdoutMaxBytes: rawOutputMaxBytes`، فقط تحليل حد أعلى داخل لم قطع قطع stdout، و سوف تجاوز حد أو ما زال يتم قطع قطع أصلي إخراج نظر لـ واضح بحث فشل؛ أبدا نحو نموذج عام أصلي `rg` إخراج.
- فقط يلزم متاح، مرور كبير كامل صيغة تحويل نتيجة سوف عبر `ctx.spillStore.saveText()` حفظ، بينما داخل ربط نتيجة إبقاء محدود؛ سقوط قرص فشل، خلفية ناقص أو كل من ناقص وقت، نظام إبقاء داخل ربط نتيجة و تقرير إبلاغ لم حفظ باق بقية محتوى، أبدا سوف إرجاع `isError`.
- حزمة README، توليد إعداد دليل و توجيه خروج JSDoc سوف سجل Config حقل و `SEARCH_*` شفرة؛tui-agent عرض مثال سوف توفير شرط صيغة أداة إضافة (acp-agent شجرة انتظار إتمام فوق وصف لقطة إعادة تسجيل صنع) ؛fs مجموعة README سوف سجل `rg` متاح صفة و bash/نظام الملفات مشترك وضع نشر اشتراط.

## ريح خطر

في عرض عام نمط تحت، كامل تشغيل `grep` ممكن مقارنة رفع قبل إيقاف بحث أكثر بطيء.v1 لـ بسيط تحويل تنفيذ و استعادة كامل نتيجة بينما قبول هذا بند صار هذا، معا عبر أداة مهلة،bash مهلة،`rawOutputMaxBytes` و إخراج حد أعلى إضافة بـ قيد. إذا فعلي تشغيل مرور بطيء، ما زال يمكن اعتماد مباشر ripgrep أو قبل منصة تدفق صيغة بديل خطة.

Shell أمر بنية صنع هو الأكثر حاد حاد أمان حد.`ctx.bash` قبول أمر نص بينما لا هو argv نحو كمية، لذلك تنفيذ يجب تجميع في معالجة shell مرجع، و اختبار سيئ معنى نمط، حمل فارغ إطار مسار، بـ قصير أفقي خط فتح رأس نمط، جذب رقم، تبديل سطر و glob عنصر محرف.

v1 زائف ضبط bash و نظام الملفات مشترك وضع نشر. إذا bash بحث واحد مساحة العمل، بينما `read` أداة أساس في آخر عدد أصل تحليل مسار، إرجاع مسار ممكن لا يمكن متابعة قراءة. هذا حزمة سوف سجل هذا بند اشتراط، لكن لا في وقت التشغيل تحقق.

سقوط قرص تحديد موضع رمز من خلفية مسؤول. حالي محلي خلفية إرجاع محلي نظام الملفات مسار، ملائم لأجل `read`/`grep` قدرة فتح هذه ملف نشر؛ بعيد مسار أو مساحة العمل تلقي حد نشر يمكن استخدام آخر نوع خلفية، يجعل ذلك تحديد موضع رمز و فحص بحث تلميح إشارة نحو تلقي دعم حمل فحص بحث آلية.
