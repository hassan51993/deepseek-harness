# Agent Note: Web ملف و جلسة مرجع

Status: implemented
Archived: 2026-09-04

[English](2026-07-27-web-file-and-session-references.md) | العربية

## مشكلة

Web إدخال إطار قد لديه يمكن إعادة استخدام مائل عمود أمر/مرجع إطلاق خط الإنتاج، لكن هو `@` source فقط هو لن إنتاج فعلي أثر subagent وسم نص.Web حاجة من مضيف توفير مساحة العمل مسار اكتشاف و بنية تحويل عبر جلسة لقطة، معا تجنب تجنب في متصفح في مسح مضيف نظام الملفات أو يأخذ جلسة هوية ربط إلى عرض وسم.

## قرار

Web عبر `@deepseek-ai/dsh-client-ui-reference` كشف واحد دمج `@file` و `@session` قائمة مفرد. كل مرة معالجة لم إضافة جذب رقم استعلام وقت، هو سوف تزامن بدء اثنان بند Remote اكتشاف استدعاء، بـ تحديد صفة ترتيب يأخذ ملف ترتيب في جلسة قبل، و استخدام تسجيل في locale حرف قاموس في وسم؛ غير ممكن اختيار ملف و جلسة قسم مجموعة عنوان سوف منطقة قسم اثنان عدد وصل متابعة مرشح قسم مجموعة، كما لن دخول مفتاح قرص اختيار بحث جذب. هذا source في تحميل و قد تسوية حالة تحت كل سوف إخفاء أصلي مجموعة عنوان، لأن مرئي قسم مجموعة من هذه قسم مجموعة عنوان يملك. بعد لم إغلاق دمج حمل جذب رقم token فقط بحث ملف. مهمة واحد مرشح مجال كل يمكن مستقل فشل، لن إخفاء آخر مجال نجاح إرجاع سطر.

ملف وظيفة التزام دوران من ثلاثة عدد حزمة بنية صار seam:`@deepseek-ai/dsh-file-reference` يملك `ctx.fileReferences`، مشترك `@path` token لغة قاعدة، مرشح شكل حالة و مستقر نموذج إشارة جذب؛`@deepseek-ai/dsh-file-reference-local` يملك كل agent(ذكي جسم) محدود مضيف نظام الملفات بحث جذب، بطلان معالجة و أثر مجال داخل نص التوجيه تثبيت؛`dsh-client-ui-reference` إزالة استهلاك توليد Remote نطاق الأسماء و مشترك لغة قاعدة. اختيار ملف سوف إنشاء حمل ملف رسم علامة و ملف اسم أصل فرعي إدخال إطار مرجع، ذلك تسلسل تحويل شكل صيغة ما زال فقط هو مسار نص التوجيه نص. دليل إبقاء لـ حمل ملف مشبك رسم علامة يمكن تحرير مسار نص، و في ذيل جزء مائل عمود بعد إعادة إطلاق تكملة كل.

اختيار جلسة سوف إنشاء واحد بنية تحويل إدخال إطار مرجع. مرئي شكل صيغة استخدام حديث يوم هواء فقاعة رسم علامة و عمل خدمة لون جلسة عنوان، لا استخدام لاصق كيس حاوية؛ قص لصق لوح و نموذج شكل صيغة فإن هو مضيف توليد مواصفة `@[label](dsh-session:…)` mention. كامل `@label` عرض نص سوف إبقاء في نفاذ واضح textarea في، نفس مقياس قياس backdrop سوف لـ هذا مقطع نطاق حال لون، و يأخذ فتح رأس marker استبدال لـ مقابل مجال رسم علامة. لذلك عرض درجة، تبديل سطر، اختيار منطقة و ضوء علامة موضع كل من أصلي حرف شكل درجة كمية قرار، لن قطع قطع.occurrence نطاق سوف إبقاء مرجع هوية بـ توفير تسلسل تحويل؛ في حد حسب Backspace أو Delete سوف كامل مقطع حذف مرجع، في نطاق داخلي تحرير فإن سوف يأخذ باق بقية محرف تحويل لـ عادي نص. عادي `session.prompt` إلقاء تمرير سوف أصل مثال يحمل مواصفة mention.session-reference خدمة سوف في `agent/pre-step` تحليل قد قبول مباشر مستخدم رسالة، التقاط كل مصدر، في إبقاء مباشر رسالة id معا يأخذ مواصفة mention استبدال لـ يمكن قراءة نص، و يأخذ تجميد ربط لقطة إدراج دخول إلى هذا رسالة ضيق بعد. استدعاء عودة سياق سطر استخدام نفس عدد حديث يوم رسم علامة، أخرى سياق إبقاء وثيقة رسم علامة.API Proxy لا يتضمن مرجع مخصص استخدام توجيه، اعتماد أو رمز خطأ.

إدخال حالة آلة في افتراضي sink تقرير إبلاغ مضيف قد قبول قبل، سوف إبقاء عادي مسودة مسودة نص و أصل فرعي مرجع. هو كتابة جلسة store مرآة مثل سوف حفظ دائم كل occurrence مواصفة قص لصق لوح إسقاط، لذلك في occurrence جدول ناقص حال حال تحت إعادة تركيب وقت، ما زال سوف إبقاء يمكن تحليل مرجع، بينما لا هو فقط توفير عرض وسم. تسلسل تحويل أو نص التوجيه نقل فشل بعد، نفس مسودة مسودة سوف عودة إلى يمكن تحرير حالة. قبول بعد، مرجع دقيق تجهيز يخص agent جولة؛ صيغة خطأ mention، مصدر قراءة فشل، إلغاء أو ميزانية فشل سوف إنهاء هذا جولة. قد سجل نص التوجيه ما زال هو إعادة تشغيل مرجعي. حديث يوم واجهة حسب وفق حمل دائم مباشر رسالة بعد وصل استدعاء عودة سطر ترتيب تصيير، و كما فقط من ضيق مع ذلك بعد حمل مصدر استدعاء عودة في صلة ربط دقيق تأكيد جلسة وسم، لذلك حيث قدرة إبقاء كثير كلمة عنوان، أيضا قدرة يجعل وصل متابعة مرجع ذاك هذا مستقل. هو سوف يأخذ تعرف آخر إلى ملف و جلسة mention تركيب زينة صار رسم علامة إضافة نص حرف مرجع، يأخذ يشمل بلا توسيع اسم basename في داخل لم إضافة جذب رقم `@path` token نظر لـ ملف، سوف جملة نهاية علامة نقطة إبقاء في مرجع نطاق خارج، و يأخذ لقطة JSON إبقاء في افتراضي استلام بدء استدعاء عودة سطر في.

## مرجع أمر خدمة

```text
type @ → parallel file/session Remote calls → pick folder text or atomic file/session reference
       → serialize draft → ordinary session.prompt enqueue
       → agent/pre-step parses mentions → capture sources → readable prompt + context
```

ملف استعلام فقط توفير مشاركة اعتبار كما يمكن إلغاء؛ اختيار عملية ذاته لن قراءة ملف. جلسة دقيق تجهيز إبرة مقابل واحد قد قبول نموذج خطوة إبقاء كل لديه أو كل بلا.queued رسالة يتم قيادة أخذ وقت سوف التقاط كل مصدر، لذلك طابور صف تحرير و من queue نقل حركة إلى steer استخدام نفس مسار، بلا حاجة شبكة صلة تنسيق ضبط.

## تجهيز اختيار خطة

**في Web عميل داخلي تنفيذ ملف اكتشاف و لغة قاعدة.** غير مقبول، لأن متصفح جانب شفرة لا يمكن أمان وصول مضيف مساحة العمل، بينما كما تكرار لغة قاعدة، ترتيب ترتيب، حد و بطلان معالجة سوف و مضيف مزود إنتاج انحراف فرق.

**عبر عادي نظام الملفات أداة RPC مسح ملف.** غير مقبول، لأن تمرير عودة نموذج غامض اكتشاف يخص تحرير جهاز منخفض تأخير متأخر عمل، بينما لا هو موجه إلى نموذج دقيق نظام الملفات عملية؛ هذا خطة أيضا سوف يأخذ قائمة مفرد و أداة سياسة و مزود نحو إرجاع ربط.

**اختيار ملف وقت قيام أي مرفق إضافة ذلك محتوى.** غير مقبول، لأن هذا خطة سوف في بعد لم تحديد متبادل صلة صفة وقت إزالة استهلاك سياق، و التفاف مرور يمكن من سجل إعادة بناء، يمكن مراجعة حساب `read` استدعاء/نتيجة تسلسل.

**استخدام عادي `@label` نص يمثل جلسة.** غير مقبول، لأن وسم حيث لا مستقر أيضا لا وحيد، لا يمكن معرف مصدر لقطة. مضيف توليد مواصفة رفع و علامة حيث قدرة إبقاء لا نفاذ واضح جلسة هوية، أيضا قدرة إبقاء عرض محتوى سهل قراءة.

**نص التوجيه دقيق دخول تسوية قبل صاف فارغ إدخال إطار.** غير مقبول، لأن نقل أو دقيق دخول فشل سوف فقد فقد طلب وحيد يمكن تحرير فرعي هذا، و في نظر شعور فوق خطأ يمثل واحد من لم نجاح قبول عملية.

## تحقق

حزمة (package) اختبار ثابت مشترك ملف لغة قاعدة و ترتيب ترتيب، ذاكرة مؤقتة بطلان و دورة الحياة تنظيف،Web و سطر استعلام، حمل جذب رقم مسار، مرشح بند مستقل فشل، إلغاء، في pending و ready حالة تحت إخفاء source عنوان، لا تغيير مرشح بند بحث جذب قسم مجموعة عنوان، ملف/دليل متابعة تكملة كل، بنية تحويل ملف و جلسة مرجع، كامل سطر داخل وسم، مجال رسم علامة، منع استخدام حالة تحت طبقة درجة ملكية، عبر إعادة تركيب مواصفة مسودة مسودة حفظ دائم، متبادل مجاور مرجع و متبادل مجاور نص شرط تحت مرجع إسقاط، بلا توسيع اسم ملف و جملة نهاية علامة نقطة تصيير،codec بلا ضرر نحو إرجاع، توليد Remote نوع دفع قطع،pre-step في مباشر رسالة أولا في استدعاء عودة دقيق تجهيز، تحت تنقل رفض، و كثير كلمة و وصل متابعة وسم بعد استمرار استدعاء عودة صلة ربط. بلا مفتاح تركيب إعداد Web لقطة سوف في لا عرض أصلي source عنوان حال حال تحت تصيير متاح مرجع قسم مجموعة، عبر حقيقي عميل تركيب اعتماد مرة اختيار ملف و جلسة مرجع، و حسب مباشر رسالة أولا في استدعاء عودة ترتيب إعادة تشغيل كثير كلمة جلسة وسم.

## عاقبة

Web الآن استخدام مشترك `@file` اكتشاف seam و بنية تحويل جلسة مرجع هوية، مضيف خدمة ما زال هو نظام الملفات و جلسة وصول مرجعي مصدر. ملف و جلسة اكتشاف كل هو الذي تابع خدمة فوق واحد عنصر Remote عقد نحو، لذلك توليد عميل نوع سوف بديل يد كتابة RPC واجهة، متصفح bundle في أيضا لا يتضمن Node API. مرشح استعلام فشل ما زال سوف يجعل قائمة مفرد ساكن صامت تخفيض. مرجع دقيق تجهيز فشل حدوث في نص التوجيه قد قبول بعد، و سوف انتهاء agent جولة. ملف مرجع فقط إنتاج مسار نص و مستقر شرط صيغة إشارة جذب صار هذا، بينما جلسة مرجع ما زال إبقاء `dsh-session-reference` الذي يملك محدود لقطة فتح إلغاء و معلومة مهمة حد تحديد نص.
