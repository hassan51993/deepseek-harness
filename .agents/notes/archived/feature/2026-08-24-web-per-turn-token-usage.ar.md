# Agent Note: Web مفرد جولة دقيق token استخدام كمية

Status: implemented
Archived: 2026-09-04

[English](2026-08-24-web-per-turn-token-usage.md) | العربية

## Problem

Web Chat في تحرير إطار مرفق قريب عرض جلسة تراكم حساب token استخدام كمية، لكن هذا قيمة لا يمكن حل تفسير واحد قد إتمام جولة إزالة استهلاك. قسم صفحة تاريخ نافذة ممكن من جولة في بين بدء، إعادة محاولة ممكن إزالة استهلاك كثير مرة نموذج استدعاء، تدفق صيغة حدث و نهائي حدث ممكن تكرار يحمل نفس مرة attempt استخدام كمية، بينما اختياري cache حقل أيضا لا يستطيع إثبات دقيق مجموع كمية. سوف نطاق جزء صغير حساب عرض صار جولة استخدام كمية، سوف يجعل قد سجل مزود واقع إظهار نيل مقارنة فعلي أكثر كامل.

## Decision

مشترك `TokenUsage` قيمة لـ مرة نموذج استدعاء يحمل اختياري `totalTokens`. مهايئ فقط من مزود دقيق مجموع كمية، أو مرجعي نص التوجيه و إخراج تجمع دمج حساب عدد إصدار هذا حقل.DeepSeek سوف سوف نص التوجيه إضافة إخراج تجمع دمج قيمة و بروتوكول توفير مجموع كمية نواة مقابل،pi-ai فإن إبقاء ذلك توفير مجموع كمية.

token-meter يملك واحد نسخة يمكن أمان لأجل متصفح صاف جولة نطاق جزء fold، و و ذلك أداة تجهيز إعادة محاولة شعور معرفة قدرة تراكم حساب استخدام كمية إسقاط مشترك تسجيل حساب كل حق.`step/start` و `llm/retry-started` فتح حقيقي attempt؛ نهائي assistant رسالة استبدال نفس attempt تدفق صيغة مثال هذا؛ إنهاء فشل، إعادة محاولة و خطوة حد إغلاق attempt، كما لن تكرار حساب عدد. كل قد بدء attempt كل يجب بـ أمان غير سالب كامل عدد استخدام كمية و دقيق مجموع كمية إغلاق. فقط لديه كل مشاركة و تجمع دمج attempt كل تقرير إبلاغ وقت، عندئذ سوف عرض اختياري cache، دفع إدارة و توجيه تجمع دمج قيمة؛ دفع إدارة ما زال هو إخراج فرعي تجميع.

Web Chat فقط اختيار قد تحميل مطابقة نافذة يتضمن `turn/start` Turn، سوف هذا كامل حمل دائم حدث نافذة تسليم إعطاء token-meter fold، مجددا تصيير نتيجة. كامل كما دقيق نتيجة عبر قائم actions فوق جهة، فقط إبقاء محلي حالة `DisclosureRow` عرض؛ دليل لا كامل أو تناقض درع وقت لا عرض هذا سطر.Chat لا يملك token تسجيل حساب حالة آلة.

## Alternatives considered

**مقابل متبادل مجاور جلسة تراكم حساب قيمة فعل نقص قاعدة.** لا اعتماد، لأن قسم صفحة، ضغط، إعادة محاولة تغطية نطاق و إسقاط كامل صفة ممكن يجعل متبادل مجاور قيمة لا يمكن مقارنة مقارنة؛ نقص قاعدة سوف دفع قطع أي استدعاء كل لم تقرير إبلاغ بيانات.

**عبر جديد عميل جلسة إسقاط إصدار تاريخ مفرد جولة قيمة.** لا اعتماد، لأن قد تحميل مفرد جولة عرض قد يملك الذي يحتاج حمل دائم attempt حدث، بينما مع تاريخ زيادة طويل إسقاط سوف زيادة نقل، حفظ دائم و إصدار صار هذا. إعادة استخدام token-meter صاف fold، يمكن في لا إضافة جديدة wire قيمة قبل رفع تحت إبقاء وحيد تسجيل حساب كل جهة.

**نقص قليل دقيق مجموع كمية وقت ما زال عرض معروف bucket.** لا اعتماد، لأن في قد إتمام جولة footer في عرض تحت حد صغير حساب و كامل حساب مفرد لا يمكن منطقة قسم.

## Consequences

جديد مزود سجل بلا حاجة إضافة جديدة نقل واجهة أو حفظ دائم UI حالة، يكفي عرض دقيق مفرد جولة تسجيل حساب. دليل لا كاف قديم جلسة و مهايئ فقط سوف حذف disclosure. مهمة واحد حساب استهلاك attempt نقص قليل ملكية وقت، نموذج توجيه سوف كامل جسم إزالة فقد، يمكن معلومة token مجموع كمية ما زال يمكن عرض.

تحديد نحو مهايئ،token-meter fold/إسقاط، مكون، قسم صفحة و تجميع Web إعادة تشغيل اختبار ثابت مجموع كمية إبقاء، إعادة محاولة attempt قسم مغادرة،fail-closed تحقق، اختياري حقل حذف، تفاعل و كامل نافذة إصدار. تراكم حساب إسقاط و دقيق Turn fold الآن نفس عودة token-meter كل؛ إسقاط ما زال هو كامل سجل bucket عرض، فقط لديه fold سوف عمل خروج disclosure الذي يحتاج أكثر صارم إطار دقيق صفة و كامل صفة إعلان.
