# Agent Note: Subagent دورة الحياة وفير غني تحويل——lastAssistantMessage(فقط مراقبة)

Status: implemented
Archived: 2026-07-26

[English](2026-06-30-subagent-observe-enrich.md) | العربية

## مشكلة

خطاف فرعي نظام ([اعتراض قطع seam Agent Note](2026-06-30-interception-seams.md)) سماح إضافة في دورة الحياة عقدة مراقبة و اعتراض قطع agent(ذكي جسم).Claude Code و Codex كل كشف **SubagentStart / SubagentStop** خطاف، كما CC خطاف يحمل subagent نهائي رسالة.harness قد إرسال خروج `subagent/start` و `subagent/end` دورة الحياة حدث ([subagent قدرة seam](2026-06-21-subagent-capability-seam.md)) ، لكن ذلك تحميل حمل أقصى لـ دقيق بسيط (`provider`،`id`، و end وقت `stopReason`) ، لا كاف بـ يجعل خطاف جسر وصل طبقة في لا مفرد وحيد وصول نشط وثب run حال حال تحت تقرير إبلاغ subagent إنتاج خروج ماذا.

هذا Agent Note وفير غني end تحميل حمل. هو لحظة معنى حد تحديد لـ**فقط مراقبة**: لا تغيير تحكم تدفق، لا جذب دخول waterfall(شلال نشر صيغة حدث). أثر run subagent-stop قرار (متابعة سطر، تغيير run حقن) يخص آخر عدد أكثر كبير إعادة تصميم، لا في هذا Agent Note نطاق داخل.

## قرار

**في `SubagentRunEndInfo` في إضافة `lastAssistantMessage`——فرعي agent نهائي إخراج.** في صحيح معتاد انتهاء مسار فوق، هو هو فقط قراءة نوع تحويل `SubagentResult.output`، مراقبة من بلا حاجة يحتفظ run يكفي يرى فرعي agent إنتاج خروج ماذا. في أساس أساس ضبط تطبيق رفض (لا وجود `SubagentResult`) حال حال تحت، هذا حقل ناقص، حدث تقرير إبلاغ `stopReason: 'error'`. مزود و استماع جهة هو تلقي معلومة مهمة نفس عملية تنسيق عمل من، التزام حراسة استعارة استخدام غير ممكن تغيير تحميل حمل عقد نحو.

اثنان عدد حدث ما زال لـ عادي **`emit`**. مختلف خطوة `SubagentService.start()` سوف نتيجة مراقبة مرفق إضافة إلى حينئذ خيط مزود run فوق، إرسال خروج `subagent/start`، لكن بعد إرجاع هذا run؛ عملية داخل استماع جهة لذلك يمكن عبر `ctx.agents.get(info.id)` وصول قد إصدار فرعي agent، بينما بعيد مسار مزود بلا حاجة في محلي سجل التسجيل في لديه مقابل بند. مزود بدء يتم رفض وقت لا إرسال خروج أي حدث. عودة ضبط إبقاء فقط مراقبة، كما تدريجي استماع جهة عزل تأكيد حفظ واحد استثناء حجز قراءة من لن منع سد نشط وثب run أو جوع ميت لاحق استماع جهة.

## سبق اعتبار بديل خطة

**`agentType` subagent صنف آخر وسم**(CC `subagent_type` في harness في مقابل شيء) ، وضع في طلب و اثنان عدد دورة الحياة تحميل حمل فوق. مبكر مدة مسودة سجل سبق يتضمن هو؛ مراجعة في إزالة، لأن هو هو Claude Code عام فكرة، لا ملائم دمج أنا جمع ذاتي ذات seam(هذا موضع لا يوجد أي منطق حل تفسير هو، وحيد مستهلك هو CC جهة قول جسر وصل طبقة).CC جسر وصل طبقة تعديل لـ مباشر لـ ذلك SubagentStart/Stop `agent_type` matcher ملء دخول Claude Code ذاته قيمة افتراضية `"general-purpose"`، لذلك هذا Agent Note فقط تسليم**واحد بند**وفير غني تحويل:`lastAssistantMessage`.

**تحكم تدفق صيغة `subagent/end`**: دفع متأخر؛ رؤية تحت نص.

## لـ أي فقط مراقبة، و دفع متأخر ماذا

تحكم تدفق صيغة `subagent/end`(واحد يتم await waterfall، إرجاع إيقاف/متابعة قرار، و أخرى اعتراض قطع seam متسق) حاجة: سوف `subagent/end` من emit تعديل لـ waterfall، إعادة بنية `SubagentService.start` جعل ذلك في تسوية قبل await استماع جهة، في عملية داخل مزود في تنفيذ `resume` قدرة بـ سهل «متابعة» قدرة حق صحيح إعادة تشغيل فرعي agent. هذا يخص[قدرة seam Agent Note](2026-06-21-subagent-capability-seam.md) قد دفع متأخر خلفية/steering(في طريق جذب توجيه)subagent إعادة تصميم (نفس عدد إعادة تصميم أيضا سوف موحد واحد subagent و bash بين طويل وقت تشغيل أداة معالجة). هذا Agent Note تسليم خطاف جسر وصل طبقة حالي الذي يحتاج فقط مراقبة وفير غني تحويل؛`FIXME(subagent-continuation)` / `TODO` مرساة نقطة علامة تحكم تدفق إصدار في إعادة تصميم حدوث وقت سقوط نقطة.

## عاقبة

خطاف جسر وصل طبقة (أو أصلي إضافة) الآن يمكن عبر حجز قراءة قائم emit سوف فرعي agent `lastAssistantMessage` تحويل إرسال إعطاء SubagentStop معالج، بلا حاجة جديد تحكم تدفق واجهة. مفردات إضافة جديدة سجل في [docs/core-data-structures/subagent.md](../../../../docs/core-data-structures/subagent.md)(حدث سطر نص جزء) و اثنان عدد subagent README في؛catalog قد إعادة توليد. إنتاج سلوك بلا تغير——حدث إطلاق طريقة و قبل تماما متسق،end تحميل حمل فوق كثير واحد اختياري حقل——لذلك بلا حاجة تحديث لقطة أو e2e اختبار.
