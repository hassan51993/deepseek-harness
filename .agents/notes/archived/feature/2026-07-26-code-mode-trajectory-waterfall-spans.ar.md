# Agent Note: trajectory و waterfall عرض في Code Mode فرعي استدعاء

Status: implemented
Archived: 2026-07-28

[English](2026-07-26-code-mode-trajectory-waterfall-spans.md) | العربية

> نطاق:Code Mode UI كومة تراكم PR(Pull Request) سلسلة الأكثر بعد واحد PR، شمول غطاء اثنان عدد غير chat عرض في فرعي توزيع تصيير.chat تضمين طقم عودة[فرعي استدعاء سطر Agent Note](2026-07-26-code-mode-chat-subcall-rows.md) كل؛ هذا مقالة الذي إزالة استهلاك حساب وقت أي[فوري و سطر Agent Note](2026-07-26-code-mode-live-parallel-dispatch.md) start/settle حدث مقابل.

## مشكلة

trajectory مرور ذهاب ما زال يأخذ واحد `run_code` جولة تصيير لـ مفرد عدد لا نفاذ واضح Tool وحدة إطار،waterfall فإن تصيير لـ واحد أصل عقدة حساب عدد بند.chat عرض في هذا قبل بضعة عدد PR في قد نيل نيل تضمين طقم فرعي سطر، لكن هذا اثنان عدد قسم تحليل عرض (ذلك الكل معنى معنى تماما تماما هو بنية و حساب وقت) مرور ذهاب حيث لا عرض أي فرعي استدعاء بنية، أيضا لا عرض توزيع حدث مقابل مثل اليوم قد سجل تدريجي فرعي استدعاء جدار ساعة وقت.waterfall فرعي استدعاء span سبق يتم لحظة معنى دفع متأخر إلى هذا حدث مقابل وجود بعد: لا يوجد حقيقي حساب وقت span حينئذ هو في نثر كذب.

## قرار

**trajectory:`subtool` وحدة إطار اختراق إدراج في ذلك أب Tool وحدة إطار بعد.waterfall: الذي تابع جولة سطر لـ تحت، حمل حقيقي حساب وقت فرعي سباحة طريق (sub-lane).**

- **trajectory**: تخطيط fold استقبال لقطة `codeDispatches` بحث جذب؛ كل بعض عدد Tool وحدة إطار `callId` اسم تحت وجود توزيع (assistant كتلة داخل استدعاء، منعزل طفل نتيجة و تشغيل في استدعاء واحد نظر نفس لب) ،fold حينئذ في هذا وحدة إطار بعد حسب بدء ترتيب لـ كل فرعي توزيع اختراق إدراج واحد `subtool` وحدة إطار، بحث جذب في كامل اختراق إدراج تسلسل في إبقاء وصل متابعة تحرير رقم. قد تسوية فرعي استدعاء استهلاك وقت قدوم ذاتي ذلك start/settle حدث مقابل (`durationSeconds(sub.time, sub.callTime)`) ؛ تشغيل في فرعي استدعاء فإن عرض كسر طي رقم، و أصلي إجراء في اتفاق تماما متسق. إضافة جديدة وحدة إطار نوع حمل لديه `Sub` وسم (business لون ضبط) و 28px تقليص دخول، تضمين طقم علاقة واحد عين يمكن تمييز.
- **waterfall**:`deriveSubSpans` يأخذ توزيع بحث جذب طي صار حمل حقيقي حساب وقت تدريجي جولة سباحة طريق: كل أب استدعاء توزيع نافذة لـ أول عدد start → الأكثر بعد واحد settle، كل بند سباحة طريق انحراف نقل/عرض درجة أي ذلك في هذا نافذة في احتلال مقارنة، لذلك و سطر فرعي استدعاء (PR3) سوف لحم عين مرئي أرض إعادة تراكم. كل بند سباحة طريق حمل لديه `timing` مصدر علامة:`measured`(مراقبة إلى صار مقابل حدث) ،`running`(settle لم إلى — بـ مقارنة منخفض لا نفاذ واضح درجة تأخير امتداد حتى نافذة نهاية طرف) أو `unknown`(إعادة تشغيل نافذة فقط يحتوي settle،`callTime: null` — رسم صار فارغ قلب و بـ «duration unknown» لـ معلق توقف عنوان، أبدا زائف صنع 0 ms). سباحة طريق رسم صنع في الذي تابع جولة بند شكل سطر لـ تحت، و تقليص وضع دخول ثابت سباحة طريق ميزانية.
- اثنان عدد عرض كل مرور من معيار لقطة hook قراءة `codeDispatches`: لا يوجد جديد wire بيانات، أيضا لا يوجد جديد store؛ إعادة تشغيل تصيير من بنية صنع حفظ إثبات و فوري تماما متسق.

## سبق اعتبار بديل خطة

**يأخذ فرعي استدعاء طي دخول جولة span عقدة حساب عدد (إعطاء قائم بند إضافة حق).** مرفوض: هو إخفاء تماما تماما هو هذا كومة تراكم PR سلسلة وجود حينئذ هو لـ عرض بنية، بينما كما عقدة حساب عدد إضافة حق هذا حينئذ قد يتم علامة لـ احتلال موضع (انحراف فرق حساب هذا #3).

**استخدام مخصص استخدام فرعي استدعاء وجه لوح يحل محل عرض داخل تضمين طقم.** مرفوض: هذا كومة تراكم PR سلسلة قد طرق تحديد UX هو موضع موضع تضمين طقم في أب درجة لـ تحت؛ مستقل وجه لوح سوف و chat حدوث انحراف فرق، أيضا سوف يجعل اختيار في وصل خط قلب ضعف.

**يأخذ waterfall سباحة طريق دفع متأخر إلى P-III وقت طويل سباحة طريق إعادة تصميم.** مرفوض: فرعي سباحة طريق حساب وقت مثل اليوم قد هو حقيقي (أي ذلك مقابل حدث) ، بينما حسب نافذة احتلال مقارنة تصيير و جولة درجة سباحة طريق سوف قدوم شكل غير متصل؛ دفع متأخر فقط سوف يجعل هذا كومة تراكم PR سلسلة حساب وقت استلام فائدة وضع ضحل.

## عاقبة

waterfall تحمل تحميل client في رقم واحد موضع حقيقي جدار ساعة وقت تصيير (جولة بند ما زال هو عقدة حساب عدد احتلال موضع؛ هذا واحد عكس فرق هو متعمد لـ لـ، و من معلق توقف عنوان علامة ملاحظة).trajectory وحدة إطار بحث جذب الآن سوف يأخذ فرعي استدعاء حساب دخول، لذلك Code Mode جولة فوق `#N` مجموع عدد سوف مع لـ زيادة كبير.spec قفل تحديد اختراق إدراج ترتيب و استهلاك وقت، تشغيل في كسر طي رقم فرع، نافذة احتلال مقارنة (انحراف نقل/عرض درجة) ، تشغيل في سباحة طريق تأخير امتداد،unknown حساب وقت (فقط settle) سباحة طريق، و جولة سطر لـ تحت فعلي تصيير خروج سباحة طريق؛ بناء ناتج درجة Code Mode fixture لقطة آخر سطر قفل تحديد اثنان عدد وسم صفحة تجميع بعد تصيير (حمل حقيقي +0.8s استهلاك وقت فرعي وحدة إطار،measured سباحة طريق).
