# Agent Note: رئيسي صفحة حوت سمك hover تنقل حركة تغيير شكل

Status: implemented
Archived: 2026-09-04

[English](2026-08-12-hero-fish-hover-swim-morph.md) | العربية

## مشكلة

hover New Session رئيسي صفحة حوت سمك (`dsh-client-ui-conversation` `EmptyHero.tsx`) أصل هذا فقط بث وضع مرة كامل svg للتو صفة CSS هز وضع. مستخدم أمل نظر حوت سمك لديه حقيقي تنقل حركة شعور——ذيل با وضع حركة، فم با منحنى خط فوق رفع، هذا اشتراط مقابل مسار بضعة أي ذاته فعل تغيير شكل.CSS transform لا يمكن انحناء منحنى مسار في جزء منحنى خط، كما logo بـ مفرد واحد `FISH_LOGO_PATH` نص تخزين وضع في `dsh-client-ui-primitives`.

## قرار

عبر SMIL `<animate attributeName="d">` فعل حقيقي منحنى خط تغيير شكل، حسب و CSS هز وضع نفسه 1.6s دورة مدة حلقة `ساكن توقف → ذيل فوق وضع → ساكن توقف → ذيل تحت ضغط → ساكن توقف`؛CSS هز وضع تعديل لـ حمل متابعة حلقة (`infinite`) ، إشارة إبرة توقف إبقاء كثير دائم حينئذ تنقل كثير دائم. اثنان عدد تغيير شكل هدف من برنامج توليد (في `/tmp` تشغيل نص برمجي، لم دخول مكتبة): تحليل `FISH_LOGO_PATH` قطعا مقابل M/C/L/Z أمر، ذيل جزء منطقة مجال التفاف دعم نقطة فعل حمل smoothstep ضعف نقص حق إعادة دوران تحويل، فم با/زعنفة داخل جانب منحنى خط بـ مسافة ذات جسم مرساة نقطة حق إعادة مستو جهة فعل عمودي مباشر انحناء منحنى (دقيق ضحك صيغة فوق رفع، بينما غير للتو صفة وضع حركة——للتو صفة دوران تحويل نظر بدء قدوم و ذات جسم انفصال عقدة) ، و إخراج بنية تماما متسق،SMIL يمكن إدراج قيمة أمر سلسلة. تجفيف خبز خروج مسار معتاد كمية و مكون وضع في واحد بدء، و في ملاحظة تفسير في سجل توليد معامل.SMIL لا يمكن استجابة CSS وسيط جسم استعلام، لذلك استخدام مرور `matchMedia('(prefers-reduced-motion: reduce)')` حكم تحديد `hovering` حالة تحكم تغيير شكل تركيب،CSS هز وضع فإن في `@media (hover: hover) and (prefers-reduced-motion: no-preference)` لـ تحت.

تغيير شكل حوت سمك بـ `conversation.hero.brand.mark` slot fallback هوية دخول رئيسي صفحة؛ لا يوجد أي إصدار حزمة احتلال حسب هذا slot——`dsh-client-ui-brand-official` فقط ملء ملء جانب شريط مجرى موضع، لأن feature إضافة لا نيل عبر حزمة value-import `HeroFish`([client عبر حزمة قاعدة](../process/2026-08-23-client-cross-package-value-dependencies.zh.md)) ، بينما fallback ذاته حينئذ هو رسمي جهة علامة سجل.`FISH_LOGO_PATH` و `FISH_LOGO_VIEWBOX` من `dsh-client-ui-primitives` توجيه خروج، توفير محيط التفاف نفس بضعة أي ذاتي سطر تجميع svg مستهلك استخدام.

## اعتبار مرور بديل خطة

**استخدام سهم كمية أداة تحرير مسار فعل تغيير شكل.** مسار في لا يوجد يمكن تفاعل أداة؛ اختيار برنامج تحويل إضافة حق تغيير شكل، لأن هو حفظ إثبات SMIL `d` إدراج قيمة الذي اشتراط تماما متسق أمر بنية، كما اهتزاز عرض هو يمكن مراجعة عدد حرف.

**hover هواء ثقب رش ماء.** حسب مستخدم اشتراط إزالة؛hover فقط إبقاء شكل حالة تغيير شكل و هز وضع.

**يجعل رسمي جهة علامة سجل احتلال حسب رئيسي صفحة slot.** أي أولا قبل أمان ترتيب؛ مرفوض، لأن ساكن حالة occupant سوف حجب إقامة حركة رسم fallback، بينما إعطاء occupant إضافة حركة رسم أيضا حاجة يتم منع توقف عبر حزمة value import.

## أثر

hover تنقل حركة هو صاف تركيب زينة (`aria-hidden`) كما مقابل reduced-motion أمان (hover إبقاء ساكن حالة logo). هز وضع CSS أثر في خارج طبقة ساكن توقف `.fishHitbox`، لذلك تبديل صار slot occupant أيضا سوف هز وضع؛ ذات جسم تغيير شكل فقط وجود في fallback `HeroFish` في. تغطية من `skeleton.client.spec.tsx` تأكيد slot دمج نحو (اسم،owner props،fallback وجود) ؛keyless لقطة جسم نظام سجل محادثة تحويل تسجيل بينما غير متصفح حركة رسم، تغيير شكل نظر شعور تحقق ما زال يحتاج شخص عمل. إعادة توليد تغيير شكل هدف حاجة مقابل `FISH_LOGO_PATH` إعادة ركض (لم دخول مكتبة) تغيير شكل نص برمجي؛ إذا logo بضعة أي سوف قدوم تغير، تجفيف خبز معتاد كمية يجب مع لـ إعادة توليد.
