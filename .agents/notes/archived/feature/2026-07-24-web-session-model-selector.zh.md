# Agent Note: Web محادثة إدخال منطقة جلسة نموذج اختيار

Status: implemented
Archived: 2026-09-04

[English](2026-07-24-web-session-model-selector.md) | العربية

## مشكلة

Web محادثة حاجة واحد بند من Host توفير، مرئي كما يمكن أكثر تعديل جلسة نموذج اختيار. إذا وفق نقل TUI عرض طريقة، أو في متصفح في صلب تحرير رمز DeepSeek نموذج، حينئذ سوف يجعل نموذج اكتشاف منطق و خطوة حد دلالة قسم تفرق إلى مختلف قبل طرف في. استجابة تشغيل خلال حدوث تبديل أيضا حاجة واحد أصل فرعي حد: نص التوجيه متغير و طلب توجيه لا يستطيع مراقبة قياس إلى مختلف اختيار.

## قرار

Web Host لـ كل جديد بناء أو استعادة Agent تثبيت `ModelSelection`. إذا جلسة قد استخدام مرور نموذج، مزود/نموذج/دفع إدارة (reasoning) اختيار قدوم ذاتي الأكثر جديد `request/header`؛ لا فإن قدوم ذاتي `ctx.agentDefaultModel`.`session.selectModel` سوف منح قيمة جلسة درجة اختيار، نص التوجيه تجميع فإن سوف هو و طلب توجيه واحد و التقاط، لذلك تشغيل في خطوة حدوث تبديل سوف تطبيق في تحت واحد تجميع خطوة. تحت واحد فعلي اعتماد اختيار عبر كامل `request/header` لقطة حفظ دائم؛ بعد لم دخول طلب اختيار فإن فقط حفظ في حالي عملية في.

جلسة RPC مجال عام `session.models` نموذج دليل و `session.selectModel`. هذا دليل من LLM(كبير لغة نموذج) سجل التسجيل حركة حالة بناء، و حسب مزود قسم مجموعة؛ كل قد صف خروج نموذج دقيق بيانات وصفية أيضا سوف إضافة دخول من مهايئ يحتفظ دفع إدارة قوي درجة ID، اسم، شرح و اختياري قيمة افتراضية. كل مزود دليل و دقيق بيانات وصفية سوف حسب مزود تزامن تحميل، كما ذاك هذا مستقل فشل، لذلك نجاح تحميل قسم مجموعة ما زال يمكن و يمكن إعادة محاولة فشل سجل واحد نفس استخدام. نموذج هل يقع في دليل فقط توفير مشاركة اعتبار:`session.models.current` مستقل إرجاع، أي جعل لا في أي قسم مجموعة في أيضا ما زال يمكن توجيه، لكن مزود إيقاف عام نشر هذا نموذج بعد،Host لن دمج صار لم صف خروج سطر. اثنان عدد قبل طرف مقابل هذا واحد حالة إعطاء خروج مختلف عودة جواب:TUI يأخذ لم صف خروج حالي نموذج تصيير لـ مستقل واحد سطر،Web فإن عرض لم ضبط حالة إطلاق جهاز وسم و اشتراط اختيار بديل نموذج.Web هو تحرير دليل الذي في قبل طرف، لذلك نقص مقعد دليل سطر بديل جدول واحد بند انتظار عمل خروج اختيار؛TUI فقط من قائم سطر في اختيار. عرض لم ضبط وسم Web composer ما زال يمكن استخدام حالي يمكن توجيه اختيار إرسال رسالة. دقيق تحليل قرار مزود/نموذج تركيب و صريح دفع إدارة قوي درجة هل متاح. اختيار عملية عبر `resolveCallConfig` رفض لا دعم حمل دفع إدارة قوي درجة ID، و في منح قيمة هذا اختيار قبل أداة جسم تحويل مهايئ إعداد قيمة افتراضية.

متصفح في `ModelDirectoryResolver` لـ كل فوري جلسة يحتفظ واحد `ModelDirectory`. ذلك لقطة يتضمن حالي كامل `ModelSelection`، قسم مجموعة دليل، مزود فشل سجل، عملية خطأ، و `idle`،`loading`،`ready`،`selecting`،`error` حالة. تركيب وقت سوف مسبق أولا ملء ملء إطلاق جهاز وسم، هذا بعد كل مرة فتح قائمة مفرد كل سوف تحديث جديد دليل. دليل و اختيار استدعاء مشترك استخدام عملية بديل مرة، منع توقف مقارنة مبكر استجابة تغطية مقارنة جديد نتيجة؛ اتصال إعادة وضع سوف أولا إسقاط حالي عملية في إسقاط، مجددا استعادة Host اختيار. فشل وقت إبقاء أولا قبل اختيار و متاح قسم مجموعة.

`@deepseek-ai/dsh-client-ui-conversation` سوف جلسة أثر مجال مفرد نسخة slot `conversation.input.model` إعلان لـ ذلك إدخال شريط entry فرعي slot.InputBar في ذيل جزء تحكم عنصر منطقة سوف هذا seat تصيير في pending إشارة عرض جهاز و رئيسي حسب زر قبل؛ هذا seat استقبال إدخال شريط `locked` owner prop و جلسة أثر مجال.`@deepseek-ai/dsh-client-ui-model-selection` احتلال استخدام هذا seat، و في نفس دليل فوق توفير `/model`. ذلك ضيق تجميع نوع إطلاق جهاز عرض دليل في تأكيد قطع نموذج اسم و توليد فاعلية دفع إدارة قوي درجة وسم. حالي اختيار لا في قسم مجموعة في وقت، إطلاق جهاز عرض `Select model`، نموذج قائمة لا علامة أي نشط حركة سطر،Effort سطر أيضا إبقاء إخفاء؛ اختيار واحد قد صف خروج نموذج، سوف عبر مشترك اختيار مسار منح قيمة كامل اختيار. حذف هذا حال شكل خارج، نحو فوق توسيع قائمة مفرد سوف أول أولا توفير Model و Effort؛Model يمكن عميق دخول مزود قسم مجموعة،Effort يمكن عميق دخول مهايئ ترتيب ترتيب درجة آخر. فقط عند مهايئ لا يوجد إعداد نموذج قيمة افتراضية وقت، عندئذ عرض مزود قيمة افتراضية سطر.

إنتاج بيئة متصفح اسم سجل من `apps/cli/config/base.cordis.yml` و `apps/cli/config/web.cordis.yml` مشترك نفس تجميع؛ نموذج وظيفة مقابل منها واحد سطر `dsh.client` بند إعداد، بينما لا هو Web boot شفرة في صلب تحرير رمز حزمة. ذلك حزمة manifest(بيانات وصفية بيان) سوف تحميل ترتيب وضع في وقت التشغيل و أمر وظيفة بعد؛Cordis خدمة حقن فإن انتظار conversation slot متاح، مجددا تسجيل composer احتلال استخدام جهة.

## اعتبار مرور بديل خطة

**قسم آخر استخدام مزود و نموذج تحت سحب إطار.** نموذج قائمة اعتماد مزود، كل مرة أكثر تعديل كل حاجة مرور مرور اثنان مرحلة مقطع تفاعل. مفرد عدد قسم مجموعة قائمة مفرد ما زال بـ مزود مجموعة نسج نموذج، معا لن زيادة إطلاق جهاز أو كل سطر عرض طويل درجة.

**في Web عميل في صلب تحرير رمز حالي DeepSeek دليل.** هذا دليل سوف و قد تسجيل مهايئ حدوث انحراف مغادرة، أيضا سوف ترتيب حذف نشر ذاتي لديه مزود.LLM سجل التسجيل متابعة بصفة مزود و نموذج بيانات وصفية حق مصدر، أيضا شمول غطاء جزء استعلام فشل معلومة.

**سوف `High`/`Max` إبقاء لـ عميل محلي UI حالة.** ساكن حالة DeepSeek وسم لا يمكن تغطية `off`،pi-ai مزود مفردات، مهايئ قيمة افتراضية و تحقق، أيضا لا يستطيع مشاركة و استعادة أو تحت مرة مزود طلب. دقيق نموذج بيانات وصفية يملك اختياري مفردات، جلسة اختيار فإن يملك قد اختيار ID.

**فقط استخدام عام قيمة افتراضية.** قيمة افتراضية تغيير سوف معنى خارج تعديل طريق فارغ أبيض محادثة. جلسة اختيار فقط يخص واحد فوري جلسة؛ مقابل في لا يوجد قد سجل طلب جلسة،`ctx.agentDefaultModel` توفير رجوع قيمة.

**Agent تشغيل خلال رفض أكثر تعديل.** أصل فرعي اختيار لقطة سوف حالي تجميع خطوة و تحت مرة اختيار قسم مغادرة. إبقاء اختيار جهاز متاح، يمكن يجعل مستخدم لـ تحت واحد خطوة مسبق أولا اختيار نموذج، بينما لن تغيير صحيح في تنفيذ طلب.

**سوف كل مرة نقر بصفة جديد جلسة حدث حفظ دائم.** فقط لديه نص التوجيه تجميع اعتماد بعض بند اختيار بعد، هذا اختيار عندئذ مقابل نموذج مرئي. حفظ دائم بعد لم استخدام UI معنى رسم، سوف زيادة واحد لا يمكن إعادة بناء نموذج طلب حمل دائم حدث؛ قائم `request/header` سوف سجل أول مرة فعلي استخدام هذا توجيه طلب.

## أثر

أي من Host دعم دعم Web محادثة (يشمل فارغ أبيض جلسة) كل يمكن في حركة حالة اكتشاف مزود قسم مجموعة و مهايئ يحتفظ دفع إدارة درجة آخر بين تبديل، بينما بلا حاجة عرض تكرار `provider/model` وسم. فعلي اعتماد اختيار سوف في استعادة و إعادة وصل بعد إبقاء؛ دليل اسم فقط لأجل عرض، بينما اختيار و حفظ دائم استخدام مزود/نموذج/دفع إدارة قوي درجة ID. بعض عدد مزود دليل أو دقيق بيانات وصفية غير ممكن استخدام وقت، فقط لديه متبادل ينبغي قسم مجموعة سوف تخفيض. مزود/نموذج تغيير ممكن خفض منخفض مزود جانب ذاكرة مؤقتة إعادة استخدام معدل، لكن اختيار جهاز لن إضافة أي نص التوجيه محتوى، أيضا لن جاف إزعاج صحيح في تنفيذ خطوة. لا يوجد دفع إدارة بيانات وصفية نموذج لا عرض Effort سطر.

## اختبار

Host اختبار ثابت قسم مجموعة اكتشاف، دليل و دقيق بيانات وصفية فشل عزل، قد سجل دفع إدارة قوي درجة استعادة كما لا حقن قديم قديم سطر، لا تلقي دليل قيد لم صف خروج نموذج اختيار، لا دعم حمل دفع إدارة قوي درجة رفض، قيمة افتراضية أداة جسم تحويل، و تبديل فقط أثر تحت مرة تجميع. عميل اختبار ثابت مشترك دليل، إعادة وصل استعادة و كامل اختيار إيداع. مكون اختبار ثابت حركة حالة دفع إدارة قوي درجة وسم، شرح، مزود قيمة افتراضية عرض، دفع إدارة قوي درجة إيداع، و نقص مقعد نموذج سطر `Select model` رجوع. بلا مفتاح built-app fixture(اختبار قبل وضع بيانات) تحميل إنتاج نموذج إضافة، اختيار OpenAI GPT-5 و ذلك Max دفع إدارة قوي درجة، إرسال بدء واحد جولة، و تحقق تحت واحد بند توليد استجابة سوف تقرير إبلاغ اثنان عدد ID؛DeepSeek إعداد fixture سوف حذف نشط حركة دليل سطر، في اختيار بديل نموذج قبل ثابت هذا رجوع.
