# Agent Note: Web جولة و نافذة درجة تأخير متأخر/ابتلاع إخراج إشارة علامة

Status: implemented
Archived: 2026-09-04

[English](2026-08-04-web-latency-throughput-metrics.md) | العربية

## مشكلة

Web حديث يوم قد سجل تدريجي خطوة LLM(كبير لغة نموذج) حساب وقت (`stepStartTime`/`firstTokenTime`/`completedTime`) و تدريجي خطوة usage،trajectory عرض أيضا حسب خطوة عرض هو جمع، لكن حديث يوم واجهة حيث عودة جواب لا «هذا واحد جولة استجابة لديه كثير سريع» ، أيضا عودة جواب لا «هذا عدد جلسة ركض نيل لديه كثير سريع»:assistant صفحة قدم فقط عرض جولة فعلي استهلاك وقت، موحد حساب سطر أيضا فقط طي حساب جدار ساعة وقت مجموع كمية.

## قرار

`ui-conversation` حزمة داخل طي حساب منطق `chat/turn-metrics.ts` هو من assistant عقدة دفع توجيه تأخير متأخر/ابتلاع إخراج قراءة عدد وحيد موضع.`assistantStepReading` يأخذ واحد عقدة تحويل صار مرة خطوة قراءة عدد:TTFT(أول token تأخير متأخر) حاجة `stepStartTime` و `firstTokenTime` معا وجود، حل رمز وقت طويل حاجة `firstTokenTime`، سالب وقت طويل ملقط صنع لـ صفر، إخراج token عدد فقط في غير ممكن معلومة `usage` قيمة لديه حد كما غير سالب وقت عندئذ قبول.`deriveTurnMetrics` حسب جولة طي حساب قراءة عدد: تحرير رقم الأكثر صغير خطوة يملك هذا جولة TTFT مجرى موضع، ابتلاع إخراج استخدام «معا يحمل اثنان من ذلك بعض خطوة» إخراج token مجموع و حذف بـ حل رمز وقت طويل مجموع و، لذلك نقص أخذ مثال خطوة مباشر خروج بينما لا هو يجعل مقارنة قيمة فقد حق؛ اثنان عدد عدد حرف كل لا يوجد جولة لا إنتاج بند.

assistant صفحة قدم يأخذ قراءة عدد إلحاق إلى قائم hover عرض وقت مرفق تابع عنصر عنصر في،`استخدام وقت` بعد، شكل مثل `أول token {s}ثانية · {tps} tok/s`، لم سجل عدد حرف كل منها حذف.ChatView فقط في هذا جولة `turnTimings` بند حمل لديه `endTime` وقت عندئذ عرض قراءة عدد: قد تحميل نافذة هو سجل وصل متابعة بعد لاحقة، لذلك نافذة داخل قد تسوية جولة لا بد لكن حمل حال هو الكل خطوة، أول خطوة TTFT هو حقيقي قيمة بينما غير نافذة قطع قطع ناتج.`formatLatencySeconds` لا حمل مفرد موضع، كل لغة نموذج لوح كل منها يملك ثانية بعد لاحقة (`TTFT {seconds}s`/`أول token {seconds}ثانية`).

موحد حساب سطر في ذلك نافذة طي حساب في إعادة استخدام نفس نسخة خطوة قراءة عدد:`deriveStats` تراكم حساب TTFT مجموع و/حساب عدد و حل رمز وقت طويل/token عدد، في LLM/أداة جدار ساعة وقت جانب تصيير مرور `conversation` locale نطاق الأسماء محلي تحويل تأخير متأخر/ابتلاع إخراج قسم مجموعة (العربية لـ `أول token مستو متساو … · … tok/s`). جولة حساب عدد، خطوة حساب عدد، استهلاك وقت، ذاكرة مؤقتة و token كل بند وسم أيضا استخدام نفس نطاق الأسماء. و ذلك بعض جدار ساعة وقت واحد مثال، هذا قسم مجموعة هو نافذة أثر مجال، لا طي حساب أي حساب استهلاك؛token حساب هدف ما زال عودة token-meter إسقاط.

## اعتبار مرور بديل خطة

**حمل دائم جلسة إسقاط (token-meter شكل).** في host جانب استخدام `ProjectionDefinition` طي حساب خطوة حساب وقت يمكن عبر تجاوز ضغط (compaction) و نافذة قسم صفحة، تغطية كامل سجل. هو مؤقت مؤقت بينما غير مرفوض: إسقاط حالة يجب إبقاء O(1)(فقط قدرة متساو قيمة، لا يستطيع قسم موضع عدد) ، هو حاجة host تعديل إضافة schema، بينما حديث يوم موحد حساب سطر استهلاك وقت واقع يتم سجل لـ نافذة أثر مجال. حمل دائم إسقاط يمكن في لا نقل حركة هذه قراءة عدد حال حال تحت تكملة فوق.

**تدريجي خطوة صفحة قدم مرفق تابع عنصر عنصر.** يجعل كل بند assistant رسالة عرض ذاتي ذات TTFT، سوف إعطاء جولة في مقطع سرد وصف عقدة تعليق فوق مرفق تابع عنصر عنصر، بينما صفحة قدم تصميم لحظة معنى يجعل هو جمع إبقاء بلا chrome؛trajectory عرض قد كشف تدريجي خطوة حساب وقت دقيق عقدة.

**استخدام عقدة هل في ساحة بينما غير `turn/end` حساب وقت فعل صفحة قدم باب تحكم.** مباشر تصيير اصطدام بارع تحميل إلى خطوة، سوف عرض واحد مظهر يشبه دمج إدارة، فعلي لـ قسم صفحة بعد «أول عدد قد تحميل خطوة» TTFT.`endTime` باب تحكم إضافة فوق بعد لاحقة نافذة ثابت كمية، جعل عرض عدد حرف يلزم ما هو هذا جولة حقيقي أول خطوة تأخير متأخر، يلزم ما ماذا كل لا عرض.

## عاقبة

نافذة داخل قد تسوية جولة صفحة قدم في hover وقت في فعلي استهلاك وقت بعد عرض `أول token`/`tok/s`، موحد حساب سطر في جدار ساعة وقت جانب بـ محلي تحويل وسم عرض نافذة مستو متساو تأخير متأخر و ابتلاع إخراج، كل مسار لا إضافة جديدة جلسة حدث، لا تعديل host. إشارة علامة بـ حذف طريقة تراجع تحويل: لا يوجد حساب وقت أو usage أخذ مثال مزود أو خطوة فقط هو فقد إسقاط مقابل عدد حرف، بينما لن تصيير صار صفر. قد تحميل نافذة خارج أكثر مبكر تاريخ ما زال لا حساب دخول، قد سجل في حزمة README موحد حساب سطر حد في.

اثنان عدد قراءة عدد كل قدوم ذاتي فعلي قياس جدار ساعة وقت، لذلك كل غير ممكن تكرار الآن:TTFT هو `firstTokenTime - stepStartTime` وقت فرق، ابتلاع إخراج فإن بـ `completedTime - firstTokenTime` حل رمز جدار ساعة وقت طويل لـ قسم أم. نفس عدد إعادة تشغيل مشهد في هذا آلة وصل متابعة اثنان مرة ركض خروج 69 و 70 tok/s، بينما واحد مقطع 3 جزء ثانية إعادة تشغيل تدفق سوف قراءة صار 26333 tok/s. لذلك Web aria golden في قائم `{{duration}}` خارج، يأخذ ابتلاع إخراج عودة واحد تحويل لـ `{{throughput}}`؛ صفحة قدم تركيب زينة صفة قسم فصل رمز أيضا تكملة فوق اثنان جانب فارغ إطار——لا يوجد هو جمع، هذه قراءة عدد سوف وصل صار واحد كامل سلسلة بلا عائق عائق نص (`Ran for 13sTTFT 0.2s12 tok/s`) ، حيث يجعل شاشة ستار قراءة قراءة جهاز فقد ذهاب قراءة عدد بين حد، أيضا يجعل `{{duration}}` فقد ذهاب هو اعتماد بـ مطابقة كلمة حد.
