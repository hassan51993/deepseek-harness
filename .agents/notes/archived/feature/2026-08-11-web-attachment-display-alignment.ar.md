# Agent Note: Web مرفق عنصر عرض مرور مرفق عنصر أصل فرعي مكون مقابل متساو DeepSeek Chat

Status: implemented
Archived: 2026-09-04

[English](2026-08-11-web-attachment-display-alignment.md) | العربية

## مشكلة

Web إدخال إطار صورة واجهة نقص نقص أساس هذا متاح صفة (مستخدم عكس تغذية،issue #2248). حذف حسب زر بـ `top/right: -6px` تعليق في 72px تقليص اختصار رسم خارج جانب، يتم مرفق عنصر شريط `overflow-x` صندوق فرعي قطع قطع، نقر مرور معتاد سقوط فارغ؛ معاينة فقط قدرة مزدوج ضرب فتح، حذف tooltip لا يوجد أي تلميح هذا عدد عملية؛ مرفق عنصر شريط تجاوز خروج إدخال إطار عرض درجة وقت في لاصق كيس داخلي مباشر ظهور أصلي أفقي نحو تمرير بند؛ صورة استقبال يتم رفض و إرسال فشل (مثال مثل الذي اختيار نموذج لا دعم حمل صورة إدخال وقت `attachment-error`) بـ معتاد إقامة داخل ربط أحمر بند عرض في بطاقة فوق جهة. هذه واجهة في DeepSeek Chat داخل كل لديه مستخدم ناضج معرفة حيث تحديد تصميم: مفرد ضرب معاينة، بطاقة داخلي معلق توقف عرض حذف حسب زر، إخفاء تمرير بند سهم رأس قلب صفحة، قمة جزء إقامة في قصير وقت toast.

أول عدد كثير نموذج حالة إصدار يأخذ هذه واجهة سجل في[Web كثير نموذج حالة Note](2026-07-22-web-multimodal-image-input-and-durable-attachments.ar.md) في؛ هذا Note يحل محل منها عرض و تفاعل دقيق عقدة (تقليص اختصار رسم بضعة أي، نقر طريقة، خطأ عرض) ، ذلك مرفق عنصر خدمة حد، دقيق دخول و حفظ دائم قرار متابعة صالح.

هذه UI أيضا الكل إقامة في `dsh-client-ui-conversation` داخل——مرفق عنصر شريط داخل ربط في 700 سطر `InputBar` في، تاريخ صورة و مصباح صندوق قسم تفرق في `chat/` و `skeleton/`——لا يوجد أخرى واجهة يمكن إعادة استخدام وصل شق، صاف props سجل قاعدة أيضا بلا من قيد.

## قرار

مرفق عنصر عرض يقع في `@deepseek-ai/dsh-client-ui-attachment`(`packages/client/ui-attachment`):`AttachmentRail`(64px،16px دائرة زاوية تقليص اختصار رسم، مفرد ضرب `onOpen`، بطاقة داخلي حذف حسب زر معلق توقف أو تجمع تركيز عرض،`pointer: coarse` تحت معتاد إظهار، إخفاء تمرير بند إعداد اثنان طرف دائرة شكل سهم رأس و اعتماد تمرير بضعة أي إعادة حساب، رأسي نحو تدحرج جولة تحويل أفقي نحو مستو نقل كما مفرد مرة ملقط صنع 60px، إضافة جديدة بند تدحرج إلى شريط ذيل) ،`MessageImage`/`ImageGallery`(مفرد ضرب معاينة) ، و `ImageLightbox`. هذه مكون ما زال هو حزمة داخل صاف props مكون.`ui-conversation` إعلان إدخال إطار مرفق عنصر و رسالة صورة slot، و توفير مسودة مسودة id، صورة تحميل، استقبال عودة ضبط و ذلك locale seat؛ حركة حالة ui-attachment عميل entry انتظار هذه إعلان و تسجيل عرض.[حركة حالة تصيير و مرفق عنصر ملكية Note](../architecture/2026-08-17-dynamic-client-render-and-attachment-ownership.ar.md) مسؤول هذا بند حزمة تجميع صار قرار؛ هذا Note سجل نظر شعور سلوك إبقاء ثابت.

اثنان عدد طفو طبقة كل portal إلى body: من حديث يوم رسالة فتح مصباح صندوق يقع في حمل transform أصل أولا لـ تحت،`position: fixed` سوف يتم صعب في أصل أولا صندوق فرعي داخل (حجب غطاء فقط غطاء إقامة حديث يوم صف) ، لذلك `ImageLightbox` و `Toast` مرور `createPortal(document.body)` تصيير، من أي فتح موضع كل تغطية كامل نظر فتحة. قصير وقت أفقي عرض هو `ui-primitives` `Toast` أصل فرعي (مسافة نظر فتحة قمة جزء 120px، ماء مستو في قلب تتبع مع اختياري مرساة نقطة——composer بطاقة، لذلك أفقي عرض في حديث يوم صف فوق إقامة في——`role="alert"`،`pointer-events: none`، توقف إبقاء ثلاثة ثانية مجددا واحد ثانية باهت خروج،`onDone` إزالة، حسب عرض ترتيب رقم عمل key جعل نفسه نص سجل إعادة بث تقرير).`InputBar` يأخذ استقبال رفض (`addImages` إرجاع سبب) و `promptError` كل تعديل مشي toast، استبدال داخل ربط أحمر بند،`ModelSelect` نموذج اختيار يتم رفض أيضا مشي نفس أصل فرعي، ذلك قائمة مفرد داخل حمل Retry خطأ بند ما زال هو دليل تحميل عرض وجه؛ حالة آلة notice بند لا تلقي أثر.DeepSeek Chat شفرة المصدر (محلي مشاركة اعتبار فرعي هذا) توفير هدف سلوك: ذلك `ImageThumbnailInInput`(64px بطاقة، نفاذ واضح درجة مرور عبور حذف زر) ،`ScrollArrows`(مراقبة جندي قيادة قلب صفحة) و `useToast` استخدام قاعدة.

## تجهيز اختيار خطة

**مكون إبقاء في `ui-conversation` داخل فقط تعديل مثال صيغة.** يتم مستخدم مرفوض: مرفق عنصر وجه مسبق مدة أيضا سوف طويل (ملف بطاقة، فوق نقل دخول درجة) ، بينما مستودع إضافة سجل قاعدة منع توقف أخرى إضافة import `ui-conversation` داخلي تنفيذ، في إضافة داخل توليد طويل فقط سوف كومة خروج لا يمكن إعادة استخدام واحد كتلة. أصل فرعي مكون حزمة إعطاء نفس مثال مكون واحد بند يتم سماح import مسار.

**توجيه خروج مرفق عنصر أصل فرعي مكون و من `ui-conversation` مباشر استيراد.** يتم حزمة تجميع صار قرار مرفوض: مباشر استيراد مكون سوف التفاف مرور حركة حالة إضافة دورة الحياة و عبر إضافة slot تركيب.conversation حزمة ما زال يحتفظ بيانات و تصيير موضع،ui-attachment فإن يحتفظ منها اختياري عرض entry.

**Toast وضع في `ui-conversation`.** مرفوض: قصير وقت أفقي عرض لا يوجد أي جلسة خاص لديه شرق غرب،`ui-primitives` هو صفر cordis أصل فرعي مكون حيث تحديد ملكية، أخرى واجهة أيضا ممكن إعادة استخدام.

**إبقاء داخل ربط أحمر بند، فقط إعطاء صورة استقبال إضافة toast.** مرفوض:`promptError`(issue قطع رسم داخل `attachment-error`) تماما هو مستخدم فعلي احتضان شكوى واجهة، واحد إدخال إطار داخل وجود اثنان نوع خطأ عرض سوف يجعل أحمر بند يصبح منعزل مثال.

## نتيجة

إدخال إطار و تاريخ صورة واجهة تفاعل نموذج و DeepSeek Chat متسق، صاف props مكون عبر conversation slot locale seat تصيير، بلا حاجة لمس بلوغ تطبيق حالة. بديل قيمة هو واحد حقيقي حركة حالة حزمة حد:`ui-attachment` حمل لديه معيار إضافة قدم يد هيكل (عميل bundle،invariant مرافق توليد، مزدوج لغة README،tsconfig face، تدريجي ملف 100% نسبة التغطية) ، حذف هذا إضافة سوف يجعل اثنان عدد اختياري مرفق عنصر slot إبقاء لـ فارغ. خطأ أفقي عرض هو قصير وقت——مستخدم نقل فتح نظر خط أربعة ثانية حينئذ سوف خطأ مرور رسالة، هذا صحيح هو DeepSeek Chat ذاتي ذات فعل أخذ ترك. غير صورة مرفق عنصر ما زال لا دعم حمل؛ مرفق عنصر شريط بطاقة نموذج قد حينئذ خيط، لكن إدخال إطار استقبال ما زال فقط إقرار صورة (سجل في حزمة README حد واحد عقدة).
