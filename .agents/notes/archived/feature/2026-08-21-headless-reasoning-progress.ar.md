# Agent Note: headless سوف مزود دفع إدارة تدفق صيغة كتابة stderr

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-headless-reasoning-progress.md) | العربية

## مشكلة

مرة صفة headless runner سوف انتظار Agent(ذكي جسم) تماما توقف مستقر، مجددا ضرب طبع نهائي Assistant نص. أداة تجهيز دفع إدارة قدرة provider سوف عبر فوري `agent/assistant-stream` chunk frame و نهائي حمل دائم settlement كشف reasoning، لكن إذا runner فقط مراقبة قد تسوية تاريخ، استهلاك وقت مقارنة طويل reasoning response سوف يجعل طرفية بداية نهاية ساكن صامت. نهائي جواب سجل يجب متابعة بصفة stdout في وحيد payload، جعل أمر استبدال و أخرى مستهلك إبقاء مستقر نتيجة عبر طريق.

هذا قبل[مباشر استخدام نواة قلب خدمة مدخل قرار](../architecture/2026-08-09-headless-direct-core-entry-point.ar.md) اشتراط كل مرة نجاح تشغيل كل إبقاء stderr لـ فارغ. هذا بند بند سوف منع توقف فوري دفع إدارة دخول درجة، لذلك من هذا Agent Note يحل محل؛ منها صلة في نقل، حمل دائم صفة و إتمام حالة أخرى قرار إبقاء ثابت.

## قرار

`headless-runner` في بدء عمل تماما توقف مستقر بعد، إيداع مهمة قبل، لـ ذلك إنشاء دقيق Agent مراقبة `agent/assistant-stream`. ذاته يحتفظ منطقة بين بـ `turn/start` فتح بعد، كل غير فارغ `reasoning-delta` chunk frame كل سوف قيام أي كتابة stderr. واحد مقطع وصل متابعة reasoning بـ وحيد احتلال واحد سطر `dsh: reasoning:` بدء؛ كل delta إبقاء provider ترتيب، لا إضافة token حد تركيب زينة.Reasoning block boundary و usage metadata سوف إبقاء هذا مقطع فتح؛ بعد ظهور غير reasoning block أو output delta،stream end، جديد turn أو listener dispose وقت، إذا provider لا يوجد إخراج نهاية ذيل تبديل سطر،runner سوف استخدام واحد تبديل سطر إنهاء هذا مقطع.

هذا إخراج هو عملية محلي Assistant stream لحظة حالة إسقاط.runner ما زال من flush بعد حمل دائم Session settlement بينما غير دخول درجة عرض حالة دفع توجيه نهائي نص و خروج حالة.SDK إسقاط لا عام live frame.

دفع إدارة دخول درجة لا حسب TTY تفعيل، أيضا لا يوجد مفرد وحيد flag. إعادة تحديد نحو stderr تدفق و مراقبة إشراف عملية سوف استلام إلى و قد اتصال طرفية نفسه مزود تقرير إبلاغ محتوى. لا يوجد دفع إدارة محتوى نجاح تشغيل ما زال لن كتابة stderr؛ إنهاء حالة نموذج خطأ و مشغل خطأ متابعة في أي قد فتح دفع إدارة مقطع إنهاء بعد إخراج قائم `dsh:` تشخيص.

## تحقق

حزمة اختبار في reasoning frame بعد إبقاء Agent نشط وثب، و في idle قبل مراقبة stderr؛ اختبار معا ثابت من provider إنهاء و لم إنهاء reasoning مقطع تبديل سطر ملكية، و terminal error. منتج ذاتي لديه مدة نظر عبر يتضمن reasoning و أداة استدعاء turn قيادة مع مرفق headless profile، و ثابت stderr و حمل دائم Session. تسجيل صنع Session replay عبر توسيع تضمين دخول صيغة Assistant stream إعادة بناء مسبق مدة stderr، في text و tool-call output موضع إغلاق reasoning مقطع، و في record mode تحت في fixture path tokenization قبل استخدام أصلي run log. بناء بعد اثنان دخول صنع acceptance عبر أصلي DeepSeek SSE adapter إرسال `reasoning_content`، اشتراط reasoning ظهور في stderr، معا stdout ما زال فقط يتضمن نهائي جواب سجل.

## اعتبار مرور بديل خطة

**تماما توقف مستقر بعد مجددا إخراج دفع إدارة.** من حفظ دائم سجل طي دفع إدارة قدرة كاف إبقاء محتوى، لكن في توجيه يؤدي هذا وظيفة إنتاج طويل وقت تشغيل منطقة بين داخل، طرفية ما زال سوف إبقاء ساكن صامت.

**حزمة تركيب LLM stream.** قطع أخذ `ctx.llm.stream()` سوف يأخذ عرض مسؤولية وضع دخول طلب مسار، و تكرار معالجة agent loop قد إصدار scoped frame.

**ضرب طبع spinner أو دورة مدة صفة قلب قفز.** تحديد وقت جهاز تقرير إبلاغ هو عملية تخزين نشط حالة، بينما لا هو مزود دخول درجة؛ هو أيضا سوف إضافة جديدة بين فصل سياسة، و متابعة إخفاء مزود قد إعطاء خروج دفع إدارة. أول عدد دفع إدارة قسم قطعة قبل وقت ما زال إبقاء ساكن صامت؛ إذا مزود سوف مؤقت اندفاع أول عدد token، يمكن آخر سطر معالجة.

**فقط في TTY أو صريح flag تحت تفعيل إخراج.** CI و مراقبة إشراف عملية في headless تشغيل حاجة نفسه دخول درجة إشارة، بينما خفي صيغة اعتماد TTY سوف يجعل إعادة تحديد نحو تشغيل و تفاعل صيغة تشغيل إنتاج فرق مختلف. لا حاجة دفع إدارة سجل استدعاء جهة يمكن إعادة تحديد نحو stderr.

## عاقبة

أداة تجهيز دفع إدارة قدرة نجاح تشغيل سوف يأخذ مزود تقرير إبلاغ محتوى كتابة stderr، لذلك سجل استلام تجميع جهاز ممكن إبقاء واضح إظهار أكثر كثير كما ممكن حساس شعور نموذج إخراج.stdout ما زال فقط يتضمن واحد نهائي assistant نتيجة، لا يوجد دفع إدارة محتوى نجاح تشغيل إبقاء stderr لـ فارغ، خطأ متابعة و دفع إدارة محتوى قسم سطر، و كما هذا قرار لا جذب دخول جديد إعداد أو حفظ دائم صيغة. مزود إرسال خروج أول عدد غير فارغ دفع إدارة قسم قطعة قبل إبقاء ساكن صامت، هذا هو واضح حد.
