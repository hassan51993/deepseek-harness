# Agent Note: تدفق صيغة محيط شريط شفرة زيادة كمية عال مضيء

Status: implemented
Archived: 2026-09-04

[English](2026-08-20-web-streaming-fence-highlight.md) | العربية

## Problem

عودة تكرار تدفق صيغة إخراج خلال،`MarkdownText` في `CodeBlock` يرى محيط شريط لغة قبل حينئذ يأخذ هو تقشير إسقاط، شفرة لذلك بـ بلا عال مضيء انتظار عرض صاف نص عرض، لغة أفقي عرض لـ فارغ، مباشر إلى تحديد مسودة تبديل مرة صفة إعادة حال لون كامل عودة تكرار ([#1499](https://github.com/deepseek-harness/deepseek-harness/issues/1499)). صاف نص ذراع هو واحد طريق لحظة معنى صار هذا منع خط، سجل في [assistant-markdown قلم تسجيل](2026-07-23-web-assistant-markdown.zh.md):shiki من وثيقة قمة جزء بدء tokenize، بسيط عنصر أرض عال مضيء واحد زيادة طويل في محيط شريط معنى طعم حال كل قسم قطعة كل إعادة tokenize كامل محيط شريط——مع تدفق صيغة مرور مسار مقابل محيط شريط طويل درجة عرض مستو جهة درجة، و[زيادة كمية markdown محلل](../architecture/2026-08-06-web-markdown-incremental-ast-renderer.zh.md) لـ كتلة تحليل إزالة حذف هو نفس صنف صار هذا. إصلاح يجب في تدفق صيغة خلال إعطاء خروج عال مضيء، معا لا إعادة جذب دخول هذا صار هذا، لا في info string بعد في قسم قطعة في طريق وقت بـ خطأ لغة قاعدة قصير مؤقت حال لون، أيضا لا تغيير تحديد مسودة تصيير.

## Decision

تدفق صيغة محيط شريط من إبقاء تحليل،tokenize و reconcile قبل امتداد متابعة دفع دخول؛ تحديد مسودة إخراج إبقاء ثابت.

- **`IncrementalMarkdownParser`**(`packages/client/ui-primitives/src/markdown/incremental.ts`) سوف في عادي ذيل جزء تحليل بعد تعرف آخر مرور parser تأكيد، يقع في نهاية ذيل كما لم إغلاق دمج قمة طبقة fence. قد إتمام محتوى إبقاء في قائم `code` node في؛ فقط لديه الأكثر بعد واحد قد إتمام سطر و حالي لم إتمام سطر مجددا مرة دخول استدعاء جهة GFM grammar، لذلك بلا حاجة إعادة تحليل fence بادئة، أيضا قدرة إبقاء ذلك تبديل سطر، تقليص دخول،CRLF و value دلالة. ظهور إغلاق دمج قسم فصل رمز، غير إلحاق إدخال، تضمين طقم/حاوية داخل fence أو لا يمكن واضح إعادة بناء وقت، سوف عودة إلى عادي ذيل جزء تحليل.
- **`StreamingHighlightSession`**(`packages/client/ui-primitives/src/markdown/highlight.ts`) فائدة استخدام TextMate tokenize حسب سطر، كما فقط نحو قبل دفع دخول صفة جودة: واحد سطر token فقط أخذ قرار في هذا سطر نص و دخول هذا سطر وقت grammar state، لذلك إلحاق نص دائم بعيد لن تغيير قد إتمام سطر token. جلسة ذاكرة مؤقتة قد إتمام سطر span و ذلك بعد shiki `GrammarState`(`getLastGrammarState`) ؛`updateFrame` فقط إصدار جديد إتمام سطر و ما زال في زيادة طويل الأكثر بعد واحد سطر، توافق طريقة `update` فإن شيء تحويل كامل نتيجة. كل قسم قطعة tokenize صار هذا لا يتضمن قد إتمام بادئة؛ نتيجة و من رأس tokenize تدريجي token متسق. غير إلحاق إدخال و تحليل بعد لغة قاعدة تغير سوف إعادة وضع ذاكرة مؤقتة و كامل إعادة tokenize. كل run يحمل shiki HTML ذراع سوف منح إعطاء هو مثال صيغة——css-variables لون لون إضافة فوق رئيسي عنوان وضع سطر markup حرف جسم موضع (bold/italic/underline؛markdown محيط شريط سوف يحمل هو جمع) ؛ صاف فارغ أبيض run و دخول ذلك بعد token، و shiki افتراضي `mergeWhitespaces` متسق (ذلك مقابل حمل تحت تخطيط خط/حذف خط فارغ أبيض إعفاء تجنب في هذا رئيسي عنوان تحت غير ممكن قدرة ظهور: رئيسي عنوان وحيد underline قاعدة أثر في inline-link scope، ذلك يحتوي فارغ إطار نص كامل جسم صار واحد run) ؛CRLF قطع قطع نقطة `\r` أبدا دخول الأكثر بعد واحد قد إتمام سطر، و shiki ذاته سطر قطع قسم متسق.
- **`CodeBlock`** يأخذ زيادة كمية frame تصيير لـ حمل لديه shiki HTML نفس بند خاصية و token span `pre.shiki.css-variables` React شجرة. قد إتمام سطر سوف غلاف دخول ثابت كبير صغير React fragment؛ لاحق تحديث إعادة استخدام هذه fragment element، فقط reconcile واحد محدود انتظار إتمام قسم مجموعة و متغير ذيل جزء. لم معرفة أو ناقص لغة إبقاء بضعة أي متسق صاف نص ذراع؛ كسول تحميل لغة قاعدة في تسجيل قبل تصيير صاف نص، تسجيل بعد من قائم `useSyncExternalStore` تحميل إشارة إطلاق إعادة تصيير دخول عال مضيء——فقط لديه مرة صاف نص→عال مضيء تحويل، لن وميض عودة. قسم مجموعة كبير صغير فقط هو داخلي reconcile وحدة، لا هو نشر سياسة أو محتوى حد أعلى.
- **`render.tsx` و `MarkdownText`** نحو محيط شريط نقل تمرير `lang` و `context.streaming`، و يجعل تدفق صيغة و تحديد مسودة قمة طبقة block كل حسب مصدر انحراف نقل ضبط key. خطأ لغة قاعدة لحظة وقت حال لون في بنية فوق غير ممكن قدرة ظهور:info string بعد في قسم قطعة في طريق محيط شريط (`` ```py `` تكملة كل لـ `` ```python ``) أيضا لا يوجد محتوى——محتوى فقط في info سطر تبديل سطر بعد عندئذ وجود، بينما هذا تبديل سطر تماما تماما تحديد إطار لغة——فارغ قيمة محيط شريط إبقاء أصلي `<pre>`.`` ```math `` محيط شريط و TeX في تحديد مسودة قبل إبقاء حرف وجه كمية؛ لغة أفقي عرض في تدفق صيغة خلال عرض محيط شريط لغة.

نهائي كل كمية وثيقة تحليل ما زال سوف حل قرار عبر وثيقة مرجع و عدد تعلم لغة قاعدة. عند هذا تحليل إنتاج نفسه fence شفرة و لغة وقت، مصدر انحراف نقل key سوف إبقاء ذلك `CodeBlock` نسخة، مكون فإن إعادة استخدام كامل تدفق صيغة React شجرة؛ بارد بدء تحديد مسودة fence متابعة استخدام `highlightToHtml`.

## Testing

حزمة اختبار سوف قيد 800 سطر لم إغلاق دمج fence تراكم حساب grammar إدخال كمية، تدريجي مرة مقارنة مقارنة زيادة كمية نتيجة و كل كمية تحليل، و تغطية تقليص دخول قسم فصل رمز، عبر قسم قطعة CRLF، إغلاق دمج رجوع و غير إلحاق إعادة وضع. عال مضيء اختبار تغطية عبر كثير سطر grammar state، فارغ سطر،CRLF و markup مثال صيغة زيادة كمية/من رأس انتظار قيمة صفة،delta معرف و إعادة وضع/كسول تحميل مسار، ثابت قسم مجموعة DOM إبقاء، من تدفق صيغة إلى تحديد مسودة DOM معرف، و صاف نص و math رجوع. تجميع بعد Web متصفح لقطة سوف بدء حقيقي Web تركيب، يجعل TypeScript محيط شريط مرور مرور Host و SSE مسار تدفق صيغة نقل، في عودة تكرار ما زال نشط وثب وقت مؤقت توقف تحديد صفة LLM مهايئ و مقابل Chromium في Shiki token شجرة فعل لقطة، لكن بعد تحقق تحديد مسودة إبقاء هذا token شجرة.`tests/fixtures/markdown-dom/*.streaming.txt` fixture قفل تحديد متبادل مقابل react-markdown مصدر واحد بند متعمد قسم تقاطع:Shiki span شجرة و مرئي لغة أفقي عرض يحل محل صاف نص ذراع.

## Alternatives considered

**مباشر نفاذ نقل `lang`، كل قسم قطعة إعادة tokenize كامل محيط شريط.** واحد سطر تعديل، لكن في لا عودة ينبغي حال حال تحت دفع قلب قد سجل صاف نص ذراع إدارة من: طويل تدفق صيغة محيط شريط في كامل تدفق صيغة مرور مسار دفع خروج مستو جهة درجة tokenize صار هذا، تماما تماما في عال مضيء الأكثر لديه قيمة قيمة طويل شفرة عودة تكرار فوق إنتاج بطاقة توقف.

**تدفق صيغة خلال فقط عال مضيء قد تجميد ربط (إغلاق دمج كما موضع تحديد إطار) محيط شريط.** صار هذا محدود، لكن لم إغلاق دمج محيط شريط سوف تثبيت إقامة زيادة كمية محلل ذيل جزء، في هو صحيح في زيادة طويل محيط شريط——شاشة ستار فوق ذلك عدد——يلزم انتظار عودة تكرار انتهاء عندئذ عال مضيء، لا ممتلئ كاف issue "تعرف آخر لغة بعد يكفي زيادة كمية عال مضيء".

**فقط إبقاء ثابت نافذة داخل عال مضيء سطر، و يأخذ أكثر مبكر بادئة تحويل صار صاف نص.** هذا قدرة حد تدفق صيغة token DOM و دخول واحد خطوة خفض منخفض تخطيط صار هذا، لكن سوف تغيير قد تصيير محتوى، يجعل عبر نافذة حد اختيار أكثر تكرار مختلط، أيضا سوف يأخذ يمكن ضبط عرض سياسة سد دخول `CodeBlock`. إبقاء تحليل،tokenize و React قبل امتداد يمكن في لا فقد لون لون حال حال تحت إزالة حذف يمكن تجنب تجنب تكرار عمل؛ كامل token DOM يتم واضح سجل لـ حد، بينما لا هو إخفاء دلالة تغير.

**يأخذ عال مضيء نقل إلى worker أو مختلف خطوة مسار.** قبول shiki وقت قد مرفوض ([تزامن عال مضيء قلم تسجيل](../process/2026-07-26-web-syntax-highlighting-shiki.zh.md)) ؛ مختلف خطوة تبديل دخول أيضا سوف إعادة جذب دخول هذا تغيير يجب تجنب تجنب صاف نص→لون لون→صاف نص وميض وميض صنف مشكلة.

**زيادة كمية تجميع وصل تحديد مسودة HTML نص و متابعة استخدام `dangerouslySetInnerHTML`.** أبيض نيل تحديد مسودة متسق صفة، لكن React كل قسم قطعة كل سوف كامل جسم استبدال `innerHTML`، متصفح كل مرة إعادة تحليل و إعادة بناء كل سطر DOM——O(محيط شريط) DOM قلب خلط، مقاومة إزالة جلسة في token طبقة استلام فائدة.

## Consequences

تدفق صيغة شفرة مع وصول يكفي قراءة: لغة واحد مرور تعرف آخر token أي حال لون؛ قمة طبقة fence قد إتمام محتوى لم يعد إعادة تحليل أو tokenize؛ غلاف تخزين React قسم مجموعة إبقاء ذلك element و DOM؛ تحديد مسودة أيضا سوف إبقاء عال مضيء شجرة. هذا حزمة يحتفظ واحد صغير نسخة shiki HTML ذراع اتفاق مرآة مثل——`pre` خاصية و فارغ أبيض طي——من مزدوج ذراع متسق صفة اختبار قفل تحديد،shiki ترقية إذا تغيير مهمة واحد موضع سوف في هذا اختبار موضع صدى مضيء فشل، بينما لا هو يجعل اثنان ذراع صامت لكن عائم نقل. تدفق صيغة DOM متسق صفة fixture قفل تحديد Shiki span شجرة، هذا هو متبادل مقابل ذلك react-markdown مصدر واحد بند متعمد قسم تقاطع. إبقاء DOM ما زال مع نهائي token عدد زيادة طويل، لذلك متصفح style و layout عمل كمية و غير و طويل درجة غير متصل. تضمين طقم/حاوية داخل fence استخدام عادي ذيل جزء محلل، ما زال في زيادة طويل الأكثر بعد واحد سطر فإن سوف كل قسم قطعة إعادة tokenize؛ مرض حالة مفرد سطر تجاوز طويل fence بسبب بينما ما زال هو الأكثر تالف حال حال.
