# Agent Note: حمل دائم Bash و نص استبدال تحرير جهاز أداة

Status: implemented
Archived: 2026-09-04

[English](2026-07-29-persistent-bash-str-replace-editor.md) | العربية

## مشكلة

جزء نشر حاجة فقط استدعاء مرة Bash schema، معا اشتراط shell حالة عبر نموذج جولة إبقاء؛ آخر بعض نشر حاجة و طرفية اختيار غير متصل Claude ريح إطار `str_replace_editor`. يأخذ اثنان عدد أداة ربط في واحد بدء أو حسب بعض عدد أساس دقيق تسمية، سوف منع عائق إعادة استخدام و نموذج غامض إعداد ملكية.

## قرار

`@deepseek-ai/dsh-tool-bash-persistent` إزالة استهلاك `ctx.terminals` و تسجيل واحد `bash(command)` أداة. هو لـ كل دقيق Agent كسول صفة إنشاء واحد تفاعل صيغة shell، و سلسلة سطر تحويل هذا كل من استدعاء.Cwd، توجيه خروج متغير، قد تنشيط بيئة، دالة و خلفية مهمة سوف إبقاء. مع آلة خاص علامة تخطيط قسم أمر إخراج؛ إبقاء scrollback سوف نحو قبل قسم صفحة، بـ استعادة أمر حق صحيح إخراج بادئة، إذا بادئة قد يتم إسقاط فإن واضح إبلاغ معرفة. مرور غلاف تركيب أمر بـ غير صفر حالة انتهاء وقت، سوف إلحاق `[exit code: N]`؛ إذا shell في تقرير إبلاغ هذا حالة قبل إنهاء، فإن تعديل لـ إلحاق `[shell exited: code N]`،`[shell killed by signal: SIG]`، أو في خلفية حيث لم توفير خروج رمز أيضا لم توفير إشارة وقت إلحاق `[shell exited]`.`maxOutputChars` حد إبقاء أمر إخراج، بينما ثابت تشخيص ممكن جعل إرجاع نص أكثر طويل. مهلة أو إلغاء سوف أولا إغلاق shell، تجنب تجنب تحت مرة استدعاء إعادة استخدام حالة لا تحديد جلسة، نموذج مرئي مهلة/خروج نتيجة أيضا سوف شرح هذا إعادة وضع. إلغاء بداية نهاية سوف إعادة وضع shell و إسقاط نتيجة، أي جعل قد قدرة مراقبة إلى كامل حالة علامة أيضا هو مثل هذا، من بينما لن يجعل نموذج لم سبق يرى حالة تغيير نيل بـ إبقاء. يمكن إعداد وصف افتراضي فقط إعلان حمل دائم صفة واقع، لذلك شبكة شبكة و لين عنصر حزمة مرآة مثل انتظار إعلان ما زال عودة نشر كل.

`@deepseek-ai/dsh-tool-str-replace-editor` مستقل إزالة استهلاك `ctx.fs`، تسجيل يتضمن `view`،`create`،`str_replace` و `insert` `str_replace_editor`. هو توفير حمل سطر رقم نص فحص نظر، مرور ترشيح بعد اثنان طبقة دليل قائمة، وحيد حرف وجه كمية استبدال، مواصفة إدراج دخول حد و محدود إخراج. مسار يجب لـ قطعا مقابل مسار؛ ملف فحص نظر سوف إبقاء محتوى في صنع جدول رمز، لذلك نسخ نص ما زال يمكن بصفة صالح حرف وجه كمية استبدال إدخال؛ تغيير سوف إبقاء طلب تحرير نطاق خارج صنع جدول رمز؛ عام schema و خطأ فإن فقط استخدام `old_str`. أمر مخصص تابع حقل قبول `null` احتلال موضع معامل: حالي أمر لا استخدام هذا حقل وقت، تنفيذ سوف سوف ذلك نظر لـ لم توفير؛ لا بد ملء فحص إبقاء ثابت؛`view_range: null` يمثل فحص نظر كامل ملف؛`str_replace.new_str: null` سوف يتم رفض، فقط لديه حذف هذا حقل عندئذ يمثل حذف. هو يمكن و حمل دائم Bash، مرة صفة Bash، صندوق رملي Bash أو بلا shell تركيب.

`dsh-system-prompt` قبول `includeHarnessIdentity: false`،profile تركيب معا يملك هذا إعداد سطر و الذي اختيار shell أداة إعداد سطر.`sdk-minimal` سوف هذا قيمة ضبط لـ `false`، كما فقط تركيب حسب منصة اختيار حمل دائم shell، لذلك نشر يمكن يملك دقيق persona، بينما لن تكرار تسجيل نص التوجيه أو أداة. قائم قيمة افتراضية ثابت.

اثنان عدد إضافة كل دخول Python runtime إغلاق حزمة. حمل دائم Bash إغلاق حزمة أيضا يتضمن PTY خدمة/محلي خلفية، و هذا خلفية اشتراط صندوق رملي خدمة. من في `node-pty` في macOS فوق سوف تنفيذ أصلي `spawn-helper`، كل تحزيم بعد macOS وقت التشغيل يمكن تنفيذ ملف كل سوف يحمل واحد `-spawn-helper` مرافق مع ملف؛Linux مباشر استخدام `forkpty`. ثابت إصدار `node-pty` رقعة سوف أولا فحص `DSH_NODE_PTY_SPAWN_HELPER`، لذلك مقابل حالي توفير غير مرافق مع helper خارجي مستهلك بينما قول، هذا متغير ما زال هو حق صحيح تغطية بند. لم ضبط هذا تغطية وقت، رقعة سوف في تحزيم يمكن تنفيذ ملف مرافق مع ملف وجود وقت تحليل هو، لا فإن في عادي Node تشغيل في إبقاء فوق تنقل فحص بحث طريقة. إذا helper ناقص أو غير ممكن تنفيذ،macOS بناء جهاز سوف في إصدار قبل فشل.

مع مرفق [`minimal` agent preset](../../../../packages/preset/agent-presets/presets/minimal/agent.cordis.yml) سوف تركيب هذا اثنان عدد إضافة، بـ ممتلئ كاف و Claude SWE توافق RL اتفاق. ذلك entry محلي PTY realm يحتفظ سجل التسجيل، محلي خلفية و حمل دائم Bash أداة؛ تحرير جهاز في هذا realm جانب تسجيل، و استخدام مضيف نظام الملفات.preset سوف ثابت كامل توجيه النظام، تتبع مع نشر أداة عرض نمط، حذف أخرى كل موجه إلى نموذج مستهلك، و سوف متصفح،Workspace، حفظ دائم، صندوق رملي و إذن خدمة إبقاء في مشترك Web مضيف فوق. محلي PTY خلفية سوف في إنشاء shell وقت تحليل جلسة صالح صندوق رملي نمط. فقط يلزم هذا كل من ما زال لديه فتح shell أو ما زال في إجراء في spawn، آخر نوع إذن نمط حينئذ سوف في مقابل جلسة حدث إيداع قبل تعرض إلى رفض؛ تحرير جهاز فإن متابعة مرور من Web نظام الملفات صندوق رملي تشغيل. هذا واحد تركيب حد من [minimal-preset قرار](../bug-fix/2026-08-10-minimal-preset-owns-rl-composition.ar.md) مسؤول شرح.

## اعتبار مرور بديل خطة

**مفرد واحد تركيب توافق إضافة.** يتم رفض، لأن اثنان عدد أداة متبادل لا اعتماد، تركيب تسمية أيضا سوف يأخذ يمكن إعادة استخدام قدرة ربط إلى بعض عدد أساس دقيق.

**إعادة استخدام مرة صفة Bash.** يتم رفض، لأن `bash -c` لا يمكن عبر استدعاء إبقاء cwd أو بيئة حالة.

**كشف طرفية إدارة أداة.** يتم رفض، لأن open/send/read/close و مفرد عدد حمل دائم `bash` استدعاء هو مختلف نموذج حركة عمل فضاء.

**تعديل أصلي read/write/edit.** يتم رفض، لأن هذا سوف لي منحنى ذلك عام اتفاق، بينما لا هو زيادة واحد يمكن مستقل تركيب تحرير جهاز.

**رفض كل قد توفير `null` أمر حقل.** يتم رفض، لأن نموذج توليد استدعاء ممكن لـ حالي أمر لا استخدام اختياري حقل تسلسل تحويل احتلال موضع معامل. حالي أمر ما زال سوف رفض لا بد ملء حقل و مقابل حذف عملية لديه أثر `str_replace.new_str` حقل لـ `null`.

## عاقبة

Profile يمكن عبر إعداد persona و وصف تكرار الآن خارجي Agent، بينما قاع طبقة حزمة إبقاء عام. حمل دائم Bash حاجة يملك هو Agent و حقيقي PTY خلفية؛shell خروج، مهلة أو إلغاء سوف فقد فقد حالة. تحرير جهاز يأخذ أمان و تغيير سياسة تفويض حمل إعطاء تركيب نظام الملفات مكدس. يمكن لـ `null` فرع زيادة أمر مخصص تابع حقل schema صار هذا، جعل لم استخدام احتلال موضع معامل لن إجبار جعل نموذج إعادة محاولة؛ تنفيذ ما زال واضح إبقاء حالي أمر لا بد ملء و حذف دلالة.minimal Web agent إبقاء Web إذن، لكن يجب أولا إغلاق حمل دائم shell عندئذ قدرة أكثر تعديل إذن نمط. وقت التشغيل wheel حزمة مستهلك ما زال بلا حاجة تثبيت Node؛Linux wheel حزمة يتضمن واحد يمكن تنفيذ ملف،macOS wheel حزمة أيضا يتضمن ذلك خاص أصلي helper.
