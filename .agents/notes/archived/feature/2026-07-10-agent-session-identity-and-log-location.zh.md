# Agent Note: نحو أداة و خطاف عام agent جلسة معرف

Status: implemented
Archived: 2026-09-04

[English](2026-07-10-agent-session-identity-and-log-location.md) | العربية

## مشكلة

agent(ذكي جسم) يمكن عبر `session.header.cwd` تعرف آخر ذلك مساحة العمل، لكن استخدام bash نموذج لا يمكن يمكن اعتماد تعرف آخر حالي استدعاء الذي تابع جلسة. استعادة،fork و تزامن تشغيل أب فرعي agent سوف يجعل أي قدوم ذاتي بيئة تخمين قياس كل غير ممكن اعتماد، بينما لم قدوم إضافة أيضا ممكن حاجة نحو shell أمر عام أخرى من harness كل بيئة واقع.

هذا بند حد يجب صيانة حمل اثنان عدد خاصية: واقع كل من قرار مثل أي تحليل هذا واقع؛ كل عملية فرعية استقبال كل مرة تنفيذ لقطة، بينما لا هو عملية درجة متغير عام حالة. خاصة ذلك هو تضمين طقم harness لا يستطيع يأخذ بيئة في `DSH_*` قيمة تسرب تسرب إعطاء حالي agent، حفظ دائم خلفية أو إعداد متساو ممكن مختلف عملية فرعية.

## قرار

موجه إلى نموذج bash حزمة يملك واحد `ctx.shellEnv` سجل التسجيل. مساهمة جهة إعلان مستقر اسم، هو ممكن إرجاع كل `DSH_*` مفتاح، كل مفتاح شرح، و `resolve(execution: ToolExecution)`. مساهمة جهة اسم تكرار، مفتاح كل حق تكرار، استخدام إبقاء مفتاح، إعلان صيغة خطأ، وقت التشغيل إخراج لم إعلان أو إخراج لا هو نص وقت، نظام كل سوف واضح فشل. تسجيل يخص Cordis effect، و مع مساهمة إضافة fiber واحد نفس إزالة.`list()` بلا حاجة تشغيل محلل يكفي عام إعلان، من بينما يجعل بيئة API يمكن توفير تشخيص أداة و لم قدوم نص التوجيه/UI مستهلك قطعة رفع.

سجل التسجيل سوف لـ كل مرة قبل منصة و خلفية bash `ToolExecution` إعادة بناء تلقي معلومة مهمة تغطية طبقة:

- `DSH_HOME` بداية نهاية هو إعداد Harness home قطعا مقابل مسار. مستقل [`@deepseek-ai/dsh-home-paths`](../../../../packages/util/home-paths/README.zh.md) أداة مكتبة قاعدة تحديد ذلك أولوية درجة: صريح `dshHome`، ذلك مرة هو بيئة في `$DSH_HOME`، الأكثر بعد هو `~/.dsh`.
- `DSH_SHELL=1` بداية نهاية وجود، لأجل معرف من DeepSeek Harness إدارة، موجه إلى نموذج bash عملية فرعية.
- تنفيذ أداة لديه صلة ربط agent وقت،`DSH_SESSION_ID` وجود و انتظار في `agent.session.header.id`.

transcript(نص سجل) موضع واقع يتم متعمد حذف. هذا قرار مبكر مدة شكل صيغة أيضا في حفظ دائم seam فوق زيادة `locate()` مسار استعلام، لـ `DSH_SESSION_JSONL` متغير و خطاف جسر وصل طبقة `transcript_path` توفير مصدر؛[حفظ دائم توجيه خروج و مسبق إصدار دقيق بسيط](../simplification/2026-08-27-persistence-export-and-pre-release-trims.zh.md) Note مسؤول إزالة هذا واحد نصف——هذه مسار فقط لديه في منع استخدام ضغط وقت عندئذ يمكن قراءة، هذا seam أيضا لم يعد عام ناتج موضع.

حاجة نحو shell عام واقع إضافة اعتماد هذا سجل التسجيل، و تسجيل كل منها مفتاح؛ هو جمع لا تعديل `process.env`.

bash seam توجيه خروج `DSH_ENV_PREFIX` بصفة وحيد نطاق الأسماء مصدر، و إرسال توليد `DshEnvironmentKey`، ذلك مصدر هو هذا معتاد كمية `typeof`.tool-bash من هذا معتاد كمية إرسال توليد داخل وضع اسم و نموذج إشارة جذب، منفذ فإن استخدام هذا معتاد كمية مرور ترشيح بيئة في قد لديه قيمة.seam عبر `ShellExecRequest.dshEnv`/`ShellExecSpec.dshEnv` مفرد وحيد نقل تمرير تلقي إدارة تغطية طبقة: عادي `env` ما زال هو خطاف الذي استخدام عام عملية داخل إضافة واجهة،`dshEnv` فإن بـ نوع قيد لـ تلقي إدارة مفتاح. محلي منفذ إزالة بيئة في وراثة الكل تلقي إدارة مفتاح، اعتماد مرة تطبيق عادي تنظيف، طرفية بيئة و صريح `env`، الأكثر بعد دمج تلقي معلومة مهمة `dshEnv` لقطة، لذلك `env` بند دائم بعيد لا يمكن قمة إسقاط تلقي إدارة قيمة. هذا حفظ إثبات قيمة ناقص يمثل هو حالي تأكيد فعلي لا وجود، بينما لا هو من خارج طبقة أو أولا قبل harness وراثة بينما قدوم. موجه إلى نموذج أداة ما زال تجاهل اختصار نموذج توفير `env`/`stdin` معامل.

bash أداة شرح فقط شرح حل حمل دائم اتفاق: حالي harness بيئة واقع عبر تلقي إدارة `$DSH_*` متغير توفير، يمكن في حاجة وقت فحص نظر. هو لن قطعة رفع حفظ دائم مخصص استخدام مفتاح، أيضا لن إضافة دائم دائم توجيه النظام فصل عقدة. أداة schema قد سجل في طلب header في، أداة إخراج فإن سجل لـ `tool/result`، لذلك بلا حاجة إضافة جديدة جلسة حدث.

[Claude Code و Codex خطاف جسر وصل طبقة](2026-06-30-hook-bridges.zh.md) لـ إبقاء بروتوكول صيغة، ما زال في خط فوق payload في إبقاء `transcript_path` حقل، لكن بداية نهاية إرسال `''`(Claude Code)/`null`(Codex) ؛ هذا بند تخفيض من[حفظ دائم توجيه خروج و مسبق إصدار دقيق بسيط](../simplification/2026-08-27-persistence-export-and-pre-release-trims.zh.md) Note مسؤول.

## نفس صنف منتج ضبط بحث

نفس صنف منتج يأخذ مستقر معرف و شيء إدارة تخزين قسم فتح معالجة.Codex نحو spawn shell حقن مستقر `CODEX_THREAD_ID`، بينما recorder و خطاف واجهة مسؤول توفير transcript مسار.Claude Code عبر بنية تحويل خطاف/حالة إدخال توفير `session_id` و `transcript_path`.OpenCode في بنية تحويل أداة سياق في يحمل معرف؛Kimi Code توسيع جلسة احتلال موضع رمز؛Reasonix فإن يأخذ نشط حركة جلسة مسار حفظ في تحكم جهاز فوق. يمكن نقل غرس قاعدة هو: في استدعاء حد حقن معرف، من تخزين طبقة تحليل موضع، أبدا في تزامن harness في استخدام عملية درجة حالي جلسة عام متغير.

## دورة الحياة و حفظ دائم دلالة

جديد جلسة في رقم واحد جولة قبل نيل نيل id، لذلك هو أول مرة bash استدعاء يكفي قراءة `DSH_SESSION_ID`. استعادة عملية إعادة استخدام قد تحميل header، لذلك id ثابت.fork و spawn سوف إنشاء جديد جلسة id. أب فرعي استدعاء قسم آخر من ذاتي ذات `ToolExecution.agent` تحليل واقع؛ أي جعل استدعاء إعادة تراكم، كل بند أمر أيضا سوف استلام إلى غير ممكن تغيير لقطة. سجل التسجيل تلقي effect أثر مجال قيد، و كما يمكن أمان لأجل HMR(حار وحدة استبدال).

`dshHome` هو و جلسة غير متصل نشر سياق.agent-core عبر `@deepseek-ai/dsh-home-paths` تحليل خروج واحد قيمة، و سوف ذلك معا نقل إعطاء tool-bash و محلي skill(تقنية قدرة) اكتشاف؛ مستقل مستهلك استدعاء نفس محلل. إذا قمة طبقة `dshHome` و `skills.local.dshHome` متساو قد توفير لكن تحليل نتيجة مختلف، تركيب سوف فشل، بينما لن عام متبادل متبادل تناقض درع home. حفظ دائم يمكن مستقل تغيير، بلا حاجة يأخذ ذلك واقع تجميد ربط إلى جلسة بادئة في.

## اختبار

اختبار وحدة تغطية سجل التسجيل إعلان تحقق،effect تحرير، تدريجي مرة تنفيذ استلام تجميع،`dshHome` أولوية درجة، و محلي منفذ تنظيف و إعادة بناء `DSH_*` ترتيب. طلب تسجيل صنع اختبار تغطية قبل منصة/خلفية لقطة، بلا agent استدعاء، تجاهل اختصار نموذج `env`، و أب فرعي عزل. اثنان طقم خطاف جسر وصل اختبار متساو قفل تحديد ثابت تحديد تخفيض transcript جهة قول.

واحد بند بلا مفتاح كامل حلقة اختبار تكامل سوف في رقم واحد جولة قيادة حقيقي agent loop،JSONL حفظ دائم،tool-bash و bash-local. عملية فرعية ضرب طبع `DSH_HOME`،`DSH_SHELL`، جلسة id و وراثة قديم قديم مراقبة جندي قيمة؛ اختبار تحقق حالي قيمة، قديم قديم متغير لا وجود، و نهائي فحص حفظ دائم header. لقطة اختبار سوف ثابت تسجيل صنع طلب header في عام bash شرح. هذا اتفاق يخص تحديد صفة محلي تنفيذ، لا تعلق و نموذج اختيار، لذلك بلا حاجة حمل مفتاح اختبار.

## اعتبار مرور بديل خطة

**فقط توفير id، مجددا استخدام `find`.** بحث لا يمكن نيل معرفة ذاتي تعريف أصل دليل أو خلفية تخطيط، و كما في كثير جلسة بيئة تحت وجود تنافس حالة.

**استخدام عام `process.env`.** تزامن agent سوف متبادل متبادل تغطية، تضمين طقم harness أيضا سوف وراثة قديم قديم حالي جلسة قيمة.

**استخدام نوع تحويل waterfall حدث.** مستمع لا تشغيل حينئذ لا يمكن إعلان كل حق، بينما لاحق مستمع يمكن بلا تلميح أرض تغطية مفتاح. سجل التسجيل قدرة في تسجيل وقت فحص قياس مفتاح اندفاع مفاجئ، و كما إبقاء يمكن قطعة رفع.

**يجعل كل حفظ دائم خلفية مباشر تسجيل bash بيئة.** هذا سوف عكس تحويل اعتماد جهة نحو، يجعل تخزين طبقة اعتماد بعض واحد مستهلك، و إجبار جعل لم استخدام bash نشر أيضا جذب دخول هو.

**زيادة موجه إلى نموذج `session_info` أداة.** bash قد توفير استعلام API، إضافة جديدة أداة فقط سوف كثير خروج schema و مرة استدعاء؛ سجل التسجيل يمكن توسيع حتى لم قدوم بيئة واقع، بلا حاجة لـ كل بند واقع زيادة واحد أداة.

## أثر

كل موجه إلى نموذج bash عملية فرعية كل سوف استلام إلى حالي Harness home و shell معرف، صلة ربط agent استدعاء أيضا سوف استلام إلى مستقر جلسة معرف. هذه عملية فرعية في تلقي إدارة `DSH_*` واقع قدوم ذاتي harness: نظام إزالة بيئة في قد لديه تلقي إدارة قيمة، في الأكثر بعد إعادة إضافة دخول حالي تلقي معلومة مهمة قيمة، عادي استدعاء جهة `env` بند لا يمكن قمة إسقاط هو جمع.

هذا نطاق الأسماء يمكن يتم اكتشاف، لكن و غير سري سري.`DSH_HOME` ممكن تسرب كشف إعداد أصل دليل، بينما كما أمر يمكن في ذاتي ذات shell لغة قاعدة في تغطية متغير. مستهلك ينبغي يأخذ هذه قيمة نظر لـ صلة ربط معلومة و بيئة واقع، و اعتماد اعتماد صندوق رملي/نظام الملفات سياسة بينما لا هو متغير حفظ سري صفة قدوم إتمام تخويل.
