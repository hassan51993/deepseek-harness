# Agent Note: Chat في حمل دائم سير العمل تشغيل

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-durable-workflow-runs-in-chat.md) | العربية

## مشكلة

عادي سير العمل أداة سطر يملك نموذج استدعاء و نهائي أداة نتيجة، لكن هذا اثنان بند سجل لا يمكن شرح أي بعض عضو حق صحيح بدء، مثل أي قسم مجموعة، كل عضو هو إتمام، فشل أيضا هو إلغاء، أيضا لا يمكن شرح عملية إيقاف وقت أي بعض عمل بعد لم انتهاء. فوري `workflow/*` حدث فقط وجود في حالي عملية، لذلك تحديث جديد أو قليلا بعد إعادة فتح Session سوف فقد فقد تشغيل تاريخ.

Web Client قد قدرة كاف من حمل دائم Session حدث تجميع من عمل خدمة يملك Conversation Node. سير العمل تاريخ لذلك حاجة: قدرة كاف يأخذ مرة قد قبول تشغيل صلة ربط إلى استدعاء Session إنتاج جهة، بصفة بادئة أيضا بداية نهاية متعمد معنى الأكثر صغير حمل دائم بروتوكول، و لا انتزاع مشي قائم أداة بطاقة كل حق مستقل renderer.

## قرار

`dsh-tool-workflow` يأخذ كل قد قبول قمة طبقة تشغيل إسقاط إلى استدعاء Agent Session.`tool-workflow/run-start` سجل مستقر `runId` و قد تحقق اسم؛ مطابقة سير العمل عضو حدث سجل عضو ترتيب رقم، دقيق وسم، اختياري دقيق مرحلة مقطع، فرعي Session id و نتيجة؛ فقط لديه في نتيجة قد أخذ نيل كما `run.dispose()` تماما توقف مستقر بعد،`tool-workflow/run-end` عندئذ سجل إيقاف سبب. تضمين طقم transport تنفيذ وفق معتاد تشغيل، لكن لن كتابة سير العمل سجل، لأن هو لا يملك مستقل Chat سطر.

سجل فقط توفير مراقبة. مهمة مرة Session append أول مرة فشل بعد، هذا تشغيل سوف إيقاف كل لاحق كتابة، فقط سجل مرة إبلاغ تحذير، و كما أبدا تغيير إلغاء، نتيجة خريطة أو dispose. كل نوع فشل موضع كل إبقاء تحت فارغ سجل أو دمج قاعدة وصل متابعة بادئة: قد بدء تشغيل يمكن نقص قليل لاحق عضو أو تشغيل نهاية نقطة، قد بدء عضو أيضا يمكن نقص قليل عضو نهاية نقطة. حزمة invariant سوف في بارد تحميل و فوري append وقت رفض تكرار تشغيل start، بلا فاعلية أو إعادة استخدام صحيح عضو ترتيب رقم، بلا إعداد مقابل أو تكرار عضو end، ما زال لديه فتح وضع عضو وقت انتهاء تشغيل، و تشغيل انتهاء بعد أي تحديث.

workflow حزمة عبر `@deepseek-ai/dsh-workflow/types` توفير متصفح أمان تشغيل و مراقبة مفردات؛ يتضمن نشط وثب `Agent` طلب و تحكم جملة مقبض متابعة فقط يخص Host.`@deepseek-ai/dsh-tool-workflow/types` يملك أربعة صنف Session حدث.Client فقط استيراد هذه نوع face، لذلك Host و Client TypeScript برنامج مشترك حمل دائم دمج نفس، بينما لن دمج Host Cordis Context.

`ui-workflow-run` تسجيل واحد `workflow-run` Conversation Definition و واحد keyed Chat renderer. كل بند حدث كل قدرة مستقل إعطاء خروج نفس `runId`؛run-start ابتدائي تحويل State، لاحق حدث حسب سجل ترتيب تحديث؛ فقط لديه update تاريخ ذيل صفحة سوف إبقاء pending، مباشر إلى prepend تكملة دخول وحيد start. نهائي عقدة إبقاء جذب محرك يملك key، و بـ run-start مرساة تحديد في أصل أداة استدعاء بعد، من تشغيل في إلى نهاية حالة بداية نهاية إبقاء نفس عدد React أب درجة.

renderer لـ كل واحد طبقة قسم إعداد مختلف نظر شعور مسؤولية. تشغيل استخدام 32 مثل عنصر module-platform خلف مشهد سطر، معتاد إقامة نحو يمين/نحو تحت chevron، و بـ داخل ربط حالة نقطة إضافة حالة نص حرف جدول بلوغ ربط نطاق، لا استخدام لاصق كيس. مرحلة مقطع استخدام 32 مثل عنصر disclosure سطر، في يمكن امتداد تقليص رئيسي منطقة عرض عنوان و عضو عدد، في ثابت ذيل جزء دقيق عرض تجمع دمج حالة كما لا تكرار حالة نقطة. عضو استخدام 16 مثل عنصر حالة نقطة مجرى، يمكن حذف اسم منطقة و ثابت 64 مثل عنصر حالة صف. مرحلة مقطع فقط في عضو حق صحيح بدء وقت ظهور، و حسب دقيق مرحلة مقطع نص قسم مجموعة؛ حقل نقص حذف و فارغ نص إبقاء مختلف هوية و محلي تحويل اسم. عضو تسوية فقط تغيير حالة، لا حذف أو إعادة ترتيب عضو. الذي تابع Turn أو Step إغلاق وقت، نقص قليل تشغيل أو عضو نهاية نقطة سوف عرض لـ قد في قطع؛ وجود حمل دائم نهاية نقطة وقت ما زال بـ هو لـ مرجعي.[حالة قيادة سير العمل disclosure](2026-08-11-workflow-run-status-driven-disclosure.ar.md) يملك هذه واقع تغير وقت تشغيل و مرحلة مقطع محتوى مرئي صفة.

تنقل من اثنان عدد حالي مرجعي إرسال توليد، لا كتابة حمل دائم سجل. فقط لديه حمل دائم عضو حالة ما زال لـ تشغيل في، كما حالي عادي Session قائمة يتضمن نفس id،`origin: 'subagent'`،`parentId` انتظار في حالي أب Session،`running: true` وقت، عضو سطر عندئذ يمكن تفاعل. حمل تحت تخطيط خط عضو نص حرف هو وحيد مرئي تلميح؛ مفتاح قرص تجمع تركيز وقت، اسم منطقة عرض 2 مثل عنصر business-primary تركيز نقطة حلقة، ثابت حالة صف متابعة فقط جدول بلوغ دورة الحياة، بينما لا كتابة حركة عمل شرح.renderer فقط استدعاء حقن عادي `sessions.open(id)` عودة ضبط. فقط عنوان تحويل، بعيد مسار، أب درجة لا رمز أو نهاية حالة عضو متابعة مرئي، لكن إبقاء ساكن حالة.

[سبعة حالة Figma مشاركة اعتبار](https://www.figma.com/design/tguwzZRmHCjbq58mfsqT0M?node-id=5-2) ثابت تشغيل توسيع/استلام بدء، إتمام تاريخ/توسيع، فشل و إلغاء، استعادة بعد في قطع و داكن لون ضيق صف معلومة طبقة درجة. مستودع `DisclosureRow`،`StateDot`، رسم علامة، دلالة token و keyed-node سلوك ما زال هو تنفيذ مرجعي؛ مشاركة اعتبار مسودة لا جذب دخول وقت التشغيل حقل أو حالة owner.

## تحقق

حزمة اختبار تغطية قمة طبقة و تضمين طقم دقيق دخول، صفر عضو و تزامن تشغيل، أولا dispose بعد كتابة نهاية نقطة ترتيب، أربعة عدد append فشل بادئة، و بارد/فوري invariant رفض.Conversation اختبار مقارنة مقارنة كامل replace، فقط لديه update prepend و فوري append، و تغطية دقيق مرحلة مقطع هوية، نهاية حالة و في قطع حالة،disclosure حالة، قائمة واقع تنقل،HMR إزالة و إعادة تسجيل.shipped Web replay إعادة استخدام قائم سير العمل أب/فرعي نموذج fixture، قيادة حقيقي worker،spawn provider،Session حفظ دائم، متصفح bundle، تشغيل في فرعي درجة تنقل، نهاية حالة إبقاء، أصل أداة سطر و تخزين، داكن لون ضيق صف token و تحديث جديد إعادة بناء.

## سبق اعتبار بديل خطة

**يأخذ سير العمل محتوى مرفق إضافة إلى قائم أداة بطاقة.** رفض، لأن `ui-tool` و أداة تعريف يملك هذا سطر عرض و تفاعل. سير العمل مخصص تابع appendix سوف اقتران دمج اثنان عدد مستقل keyed عمل خدمة دورة الحياة، و استعادة قد إزالة أداة بعد مرفق إضافة نموذج.

**حفظ دائم خدمة طرف projection أو إضافة جديدة workflow wire عبر طريق.** رفض، لأن Session حدث قد توفير حفظ دائم، فوري نقل، قسم صفحة و gap repair. آخر عدد service،cache أو transport سوف نسخ نفس واقع و بناء قيام ثاني عدد دورة الحياة owner.

**عرض إعلان مرحلة مقطع، أو من نص برمجي نص دفع قطع ساكن حالة سير العمل رسم.** رفض، لأن فقط لديه عضو start حدث قدرة إثبات عمل حق صحيح حدوث.`meta.phases`،`phase()` سرد وصف، فرع و نص برمجي لغة قاعدة كل لا هو مرة تشغيل مرجعي توسيع اندفاع.

**إبقاء نهاية حالة فرعي درجة تنقل.** رفض، لأن سير العمل سجل إثبات تاريخ هوية، لا إثبات حالي يمكن وصول صفة. بارد Session أو بعيد مسار Session فتح حاجة مستقل دليل و تخويل دمج نفس؛ هذا عقدة لا عمل هذا نوع تحمل وعد.

## عاقبة

سير العمل دخول درجة و أب محادثة حفظ في نفس سجل في، قدرة عبر تحديث جديد و عملية استعادة؛ تنفيذ كل حق ما زال يخص سير العمل run holder، أصل أداة بطاقة إبقاء ثابت. حمل دائم بروتوكول زيادة أربعة صنف صغير حدث و واحد حزمة كل invariant؛ أول مرة كتابة فشل سوف لحظة معنى تضحية قربان لاحق مراقبة، بينما لا هو تضحية قربان سير العمل صحيح تأكيد صفة. متصفح State حسب قد تحميل نافذة إرسال توليد، حالة قيادة disclosure دورة الحياة يأخذ تكرار قرص اختيار إبقاء في محلي، تنقل سوف مع قائمة واقع إزالة فقد. تصميم فقط عرض حقيقي تشغيل عضو و حالة، و وضع ترك ساكن حالة رسم، إخراج، سجل، تحكم عملية و نهاية حالة عضو فتح.
