# Agent Note: منتج one-shot subagent استخدام عام خلفية Job

Status: implemented
Archived: 2026-09-04

[English](2026-08-12-product-subagent-one-shot-background-tasks.md) | العربية

## مشكلة

Codex و Claude Code مزود قد قدرة كاف تشغيل واحد بند ذاتي يتضمن مهمة و إرجاع واحد نهائي عودة جواب، بينما `dsh-tool-subagent` أيضا قد قدرة كاف يأخذ مهمة معنى one-shot مزود وصل دخول عام خلفية Job وقت التشغيل. مع مرفق منتج أداة سطر منع استخدام هذا بند مسار، لذلك أي جعل تفويض حمل و agent تحت واحد خطوة عملية ذاك هذا مستقل،agent أيضا فقط قدرة انتظار منتج عودة جواب.

عام خلفية تنفيذ لا نيل زيادة منتج جلسة، منتج مخصص تابع عمل عمل حالة، آخر إلغاء مسؤولية مهمة جهة أو آخر نتيجة بروتوكول. نفس عدد مزود تشغيل يجب متابعة مسؤول واحد أصلي عملية أو query و واحد نهائي عودة جواب، بينما قائم عمل عمل سجل التسجيل متابعة مسؤول id، استلام تجميع، إلغاء،owner تنظيف و إتمام إشعار.

## قرار

إنتاج `dsh` لا تثبيت اختياري منتج مزود. اختيار تفعيل منتج تجميع صار Profile سوف تثبيت الذي يحتاج `dsh-subagent-codex` أو `dsh-subagent-claude-code` حزمة، و في host plane(مضيف مستو وجه) تركيب الذي يحتاج مزود نسخة.`standard`،`code` و `cordis` Agent Preset استخدام `backgroundMode: one-shot` إعداد متبادل ينبغي راحة نوم أداة سطر؛ حذف بعض واحد سطر `disabled` حقل بعد، قائم اختياري معامل `run_in_background` سوف نحو من هذا preset تجميع agent عام. حذف هذا معامل أو نقل دخول `false` وقت سوف في قبل منصة انتظار؛ صريح نقل دخول `true` وقت سوف في تزامن إتمام Job مسبق فحص و تسجيل تسجيل بعد إرجاع من أب درجة يملك Job id، بينما لن انتظار مزود بدء أو إتمام.

[تسمية نسخة قرار](2026-08-18-product-subagent-named-instances.zh.md) سماح اثنان عدد منتج قسم آخر يملك كثير عدد بند إعداد. كل إضافة جديدة مضيف مزود بند إعداد كل لديه مستقل `providerName`، كل عام preset أداة بند إعداد كل عبر `provider` ربط هذا اسم و إبقاء وحيد `toolName`؛ قبل منصة أو خلفية ضبط درجة اختيار لن حد نسخة عدد كمية.

[عام one-shot خلفية مهايئ](2026-07-08-background-subagent-tasks.zh.md) مسؤول خلفية تسجيل تسجيل و تسوية. هو سوف بدء نفس عدد [`SubagentRun`](2026-06-21-subagent-capability-seam.zh.md) ، يجعل Job ذاتي لديه إلغاء إشارة تغطية مزود بدء و تنفيذ، انتظار `run.result` و `run.dispose()`، يأخذ نهاية حالة نتيجة و اختياري أمان تشخيص خريطة دخول Job، و من `job_output`،`job_list`،`job_kill` و قائم إتمام إشعار عام هذا حالة.[منتج مزود قرار](2026-08-04-claude-code-and-codex-subagent-backends.zh.md) متابعة مسؤول أصلي بروتوكول، جواب سجل اختيار، محلي إلغاء و عملية شجرة تماما توقف مستقر؛[غير تفاعل إذن قرار](2026-08-15-product-subagent-noninteractive-permissions.zh.md) مسؤول كل منتج مزود Profile إعداد و تشخيص إنتاج.

هذا ضبط درجة قرار لا إضافة جديدة مزود إعداد، خدمة واجهة، حدث، بروتوكول حقل، حفظ دائم صيغة أو منتج معرف رمز. مزود يمكن مستقل تعريف ذاتي ذات Profile إعداد؛ قبل منصة و خلفية منطقة آخر ما زال فقط في في من أي عدد قائم مستهلك انتظار نفس عدد one-shot تشغيل.

### ملكية و دورة الحياة

```text
product tool call
  -> omitted / false: tool call waits -> final answer or error -> run disposal
  -> true: Job preflight + owner cleanup
           -> starter begins provider startup under Job-owned signal
           -> Job record/id published and returned (startup remains pending)
           -> provider result + run disposal -> Job settlement + notice
                                              -> job_output reads / job_kill cancels
  -> parent disposal: Job owner cleanup cancels -> run disposal -> process exit
```

| واقع أو مورد | مسؤولية مهمة جهة | منتج أداة مسؤولية | يمكن مراقبة نتيجة |
| --- | --- | --- | --- |
| منتج مزود تثبيت و تسجيل تسجيل | صريح Profile | تثبيت اختياري مزود حزمة، و في host plane تركيب الذي يحتاج تسمية نسخة | مزود اسم متاح، لكن لن يجعل كل مرة إنتاج `dsh` تثبيت كل يتضمن هذا حزمة |
| منتج اختيار و عام | Agent Preset | يأخذ واحد ثابت أداة اسم ربط إلى واحد ثابت مزود | تفعيل واحد سطر فقط سوف عام مقابل منتج أداة |
| قبل منصة أو خلفية اختيار | `dsh-tool-subagent` | حسب `one-shot` سياسة تحليل `run_in_background` | حذف معامل وقت في قبل منصة تشغيل؛ صريح نقل دخول `true` وقت إرجاع Job id |
| Job id، حالة، إخراج، إلغاء و إشعار | `ctx.jobs` و `dsh-tool-jobs` | تسجيل تسجيل و عرض قائم one-shot تشغيل | عام عمل عمل أداة لـ دقيق تأكيد أب درجة استلام تجميع أو إيقاف تشغيل |
| أصلي نتيجة، اختياري تشخيص و عملية تماما توقف مستقر | منتج مزود و `dsh-subprocess` | إنتاج واحد نهائي نتيجة و تحرير واحد شجرة عملية شجرة | Job تسوية و قبل منصة إرجاع إزالة استهلاك نفس نتيجة، كما كل سوف انتظار مورد تحرير |

## إصدار تجميع

إنتاج base لا يجعل اثنان عدد اختياري منتج مزود دخول اعتماد إغلاق حزمة. اختيار تفعيل منتج تجميع صار Profile سوف تثبيت الذي يحتاج حزمة، و في host plane تركيب الذي يحتاج مزود نسخة. كل كامل preset يجعل اثنان عدد منتج أداة سطر إبقاء منع استخدام، و يأخذ عام Job تحكم أداة مساهمة إلى ذاته agent أثر مجال؛base host مسؤول مشترك Job سجل التسجيل.Profile مزود نسخة وجود بعد، مستخدم نسخ واحد preset، مجددا من مقابل منتج سطر حذف `disabled`؛ تجميع خلال لن بدء منتج عملية.

مستقل ذاتي تعريف تجميع إذا تفعيل one-shot خلفية تنفيذ، حينئذ يجب معا توفير منتج مزود و كامل عام Job قدرة: من `dsh-jobs-local` ملء عند Job مزود، من `dsh-tool-jobs` ملء عند موجه إلى نموذج مستهلك. أساس في `dsh-base` Profile قد أداة تجهيز Job قدرة، فقط يحتاج في تفعيل preset أداة سطر قبل إضافة جديدة اختياري منتج مزود. لا يوجد Job وقت التشغيل منتج أداة ما زال يمكن في قبل منصة تنفيذ، لكن صريح خلفية طلب سوف في قائم Job مسبق فحص في فشل، لن إصدار لا يمكن استلام تجميع id.

ACP منتج تجميع استخدام نفسه ثابت منتج سطر و عام عمل عمل تحكم أداة. ذلك بلا مفتاح schema لقطة سوف لـ كل قد تفعيل منتج أداة عام `description`،`prompt` و اختياري `run_in_background`، بينما لن استدعاء Codex،Claude Code أو خارجي نموذج.

## تحقق

Web تجميع اختبار سوف من مستودع examples اعتماد مرساة نقطة صريح تركيب اثنان عدد اختياري مزود، مجددا بدء أربعة نوع مستخدم preset تغيير جسم——لا تفعيل منتج، فقط تفعيل Codex، فقط تفعيل Claude Code، و معا تفعيل اثنان من——و فحص كل قد تفعيل منتج أداة كل سوف و `job_output`،`job_list` و `job_kill` واحد بدء عام `run_in_background`. اثنان عدد من حزمة مسؤول Loader تجميع سوف في فارغ `PATH` تحت تشغيل، فحص نفسه schema و تحكم أداة، و إثبات صريح تحميل مزود لن بدء منتج عملية.ACP بلا مفتاح لقطة سوف ثابت صريح تجميع بعد منتج schema، بينما قائم `dsh-tool-subagent` و عمل عمل اختبار طقم عنصر سوف ثابت قبل منصة قيمة افتراضية،Job تسجيل تسجيل، نهائي إخراج استلام تجميع، مشترك تشخيص عرض، إلغاء، إتمام إشعار،owner مورد تحرير و مزود مورد تحرير. اثنان عدد حقيقي منتج مزود اختبار طقم عنصر أيضا سوف قسم آخر إثبات كل منها أصلي إذن فشل أولا دخول نفس عدد مشترك نتيجة، مجددا من مهمة واحد ضبط درجة مسار إزالة استهلاك.

## سبق اعتبار بديل خطة

**يجعل منتج أداة متابعة فقط دعم حمل قبل منصة تشغيل.** هذا نوع خطة إبقاء الأكثر صغير schema، لكن سوف منع توقف agent ضبط درجة مستقل منتج عمل، أي جعل عام one-shot Job مهايئ قد مسؤول الذي يحتاج دورة الحياة.

**يجعل منتج تفويض حمل افتراضي في خلفية تشغيل.** one-shot Job حاجة لاحق استلام تجميع، هذا مختلف في يملك ذاته حمل دائم جلسة id و تسوية تسليم يمكن متابعة وصل فرعي درجة. قبل منصة متابعة بصفة توافق قيمة افتراضية، خلفية متابعة بصفة صريح ضبط درجة اختيار.

**يجعل Codex أو Claude Code أصلي جلسة حالة مسؤول خلفية دورة الحياة.** هذا سوف في عام عمل عمل سجل التسجيل خارج بناء قيام مزود مخصص تابع id، حالة، إلغاء و استعادة دلالة. مزود متابعة فقط إنتاج one-shot نتيجة، و يأخذ أصلي id إبقاء لـ خاص واقع.

**زيادة منتج مخصص تابع output،wait أو kill أداة.** مستقل تحكم أداة سوف نسخ عام عمل عمل بروتوكول، و لـ كل مزود تعليم منح مختلف استلام تجميع سير العمل. قائم `job_*` أداة قد تغطية الذي يحتاج عملية.

**معا زيادة يمكن متابعة وصل منتج جلسة.** استعادة، لاحق تفاعل، دخول درجة و حفظ دائم منتج جلسة حاجة جديد منتج اتفاق و دورة الحياة ملكية. هذا قرار فقط عام قد تنفيذ one-shot خلفية مسار.

## عاقبة

agent يمكن في Codex أو Claude Code معالجة مستقل one-shot مهمة وقت متابعة دفع دخول أخرى عمل، مع بعد عبر أخرى خلفية producer مشترك استخدام Job تحكم أداة استلام تجميع نهائي عودة جواب أو إلغاء تشغيل. إذا فشل نتيجة توفير أمان مزود تشخيص، قبل منصة و مرة صفة خلفية مستهلك سوف عرض نفس محتوى.

كل مرة منتج تفويض حمل ما زال سوف بدء واحد كل جديد أصلي عملية أو query، يأخذ نهائي assistant نص بصفة وحيد assistant تحميل حمل، و بـ مزود مورد تحرير و كامل شجرة عملية شجرة خروج انتهاء. فشل نتيجة يمكن آخر سطر يحمل أمان تشخيص. خلفية استدعاء أيضا سوف مقدار خارج عام عام Job id، حالة، إتمام إشعار و استلام تجميع أو إلغاء نتيجة. خلفية Job فقط وجود في حالي عملية كما من أب درجة يملك: هو لن في أب درجة مورد تحرير بعد متابعة تخزين نشط، لن عام منتج في بين نشط حركة، أيضا لن يجعل منتج محادثة تغيير نيل يمكن استعادة. فقط لديه Profile صريح تثبيت منتج تجميع صار وقت، إنتاج تثبيت عندئذ تحمل تحمل مقابل صار هذا؛ عام خلفية معامل أي تجميع أيضا يجب يجعل عام Job مزود و تحكم أداة إبقاء متاح.
