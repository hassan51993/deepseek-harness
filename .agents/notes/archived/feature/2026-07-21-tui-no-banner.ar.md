# Agent Note: إزالة بدء أفقي عرض

Status: implemented
Archived: 2026-07-26

[English](2026-07-21-tui-no-banner.md) | العربية

> **قد يتم يحل محل**، رؤية[بلا حافة إطار أفقي عرض Agent Note](2026-07-21-tui-borderless-banner.md): أفقي عرض و ذلك مسح دخول حركة رسم ارتداد، فقط هو ذهاب إسقاط صندوق فرعي. هذا note لـ نموذج ضبط قيام صفحة قدم عودة مضيف نيل بـ إبقاء.

## Problem

TUI بدء وقت عرض واحد حمل إطار منتج أفقي عرض ("DEEPSEEK HARNESS" + نموذج/جلسة تفصيل حال) ، الأكثر قريب واحد إصدار أيضا حمل مسح دخول حركة رسم ([أفقي عرض مسح دخول Agent Note](2026-07-21-tui-banner-sweep.md)). مستخدم قطع قرار: حذف إسقاط هو. كل مرة بدء كل يتم إعادة قراءة منتج عنوان هو تركيب زينة، صندوق فرعي في أي محتوى قبل أولا احتلال إسقاط أربعة سطر، بينما هو تحمل تحميل تعرف آخر معلومة (نموذج، جلسة) لديه أكثر جيد ذهاب موضع.

## Decision

- حذف `HeaderComponent`، مسح دخول حركة رسم و ذلك دورة الحياة وصل خط.TUI مباشر تركيب دخول transcript؛ بدء وقت قسم فصل خط لـ فوق لا تصيير أي شرق غرب.
- نموذج اسم نقل دخول صفحة قدم حالة سطر يسار مقطع (`<model> <cwd> ↑tokens ↓tokens`) ، جلسة استخدام نموذج لذلك بداية نهاية مرئي، بينما لا فقط هو بدء وقت. جلسة id لم يعد عرض——هو وجود في جلسة سجل و `./.sessions` ملف اسم في،`dsh --resume <id>` و `/resume` اختيار جهاز سوف من في نيل أخذ هذا id.
- إعداد `welcome` وقت، هو بصفة transcript رقم واحد سطر (واحد بند ضعيف تحويل إشعار) في `rebuildTranscript` داخل تصيير، لذلك ضبط لون لوح تبديل سوف إبقاء هو. لم ضبط فإن ماذا أيضا لا تصيير.fixture إبقاء كل منها إعداد فرح استقبال لغة؛PTY خطر دخان اختبار بدء علامة تعديل لـ صفحة قدم نموذج اسم——بلا نقاش cwd كثير طويل كل حفظ إثبات تصيير وحيد تركيب بعد نص.

هذا note تماما يحل محل[أفقي عرض مسح دخول Agent Note](2026-07-21-tui-banner-sweep.md): مسح دخول حركة رسم و هو الذي حركة رسم أفقي عرض كل قد إزالة.

## Alternatives considered

**إبقاء مفرد سطر رأس جزء (ذهاب إسقاط صندوق فرعي).** مرفوض: وحيد لديه تحمل تحميل قيمة قيمة معلومة هو نموذج اسم، بينما صفحة قدم قد تجمع دمج جلسة حالة؛ لـ واحد بند معلومة إبقاء مخصص استخدام رأس جزء سطر ما زال هو نفس نوع تركيب زينة، فقط هو صغير واحد نقطة.

**يأخذ جلسة id أيضا وضع دخول صفحة قدم.** مرفوض:36 محرف UUID سوف احتلال ممتلئ 100 صف صفحة قدم و قطع إسقاط حالة مقطع؛ هو استخدام طريق هو استعادة جلسة معرف، يخص سجل/نظام الملفات صلة ملاحظة نقطة، لا هو حاجة واحد لمحة مرئي معلومة.

**يأخذ فرح استقبال لغة تصيير في transcript خارج (قسم فصل خط فوق جهة).** مرفوض:transcript فوق جهة أي ثابت منطقة مجال كل سوف مجددا مرة تغيير صار أفقي عرض؛ بصفة transcript سطر هو ذاتي لكن تدحرج مشي، و عبر و أخرى transcript عنصر عنصر نفسه مسار في إعادة بناء بعد إبقاء.

## Consequences

- بدء إخراج مجددا مرة تماما تحديد——لا يوجد أي حركة رسم لقطة؛ اثنان جولة حركة رسم تكرار بديل إبقاء تحت تحديد وقت جهاز دورة الحياة آلية الكل إزالة.
- الكل 26 عدد pi-tui طرفية لقطة إعادة تسجيل صنع (`test:snapshot:refresh`): أفقي عرض سطر إزالة فقد، صفحة قدم سطر زيادة نموذج بادئة.
- مرساة تحديد أفقي عرض نص (`DEEPSEEK`، صندوق فرعي زاوية) محتوى تعديل لـ مرساة تحديد صفحة قدم نموذج اسم؛ بدء إخراج في لم يعد ظهور `main-session-`.
- `/clear` الآن أيضا سوف صاف إسقاط فرح استقبال سطر: هو هو عادي transcript سطر، بينما `/clear` صاف فارغ transcript(قديم أفقي عرض قدرة في `/clear` بعد تخزين نشط فقط لأن هو في transcript خارج).
- صفحة قدم يسار مقطع تغيير عرض؛ ضيق طرفية فوق يمين جانب حالة مقطع أكثر مبكر يتم قطع قص.

## Testing

`packages/ui/tui/tests/tui.spec.ts` ثابت:`welcome` لم ضبط وقت بلا صندوق فرعي زاوية/منتج عنوان،transcript لـ فارغ، نموذج في صفحة قدم؛ إعداد فرح استقبال لغة بصفة transcript رقم واحد سطر كما بلا أفقي عرض؛ فرح استقبال لغة في ضبط لون لوح تبديل transcript إعادة بناء بعد إبقاء.PTY خطر دخان اختبار بـ صفحة قدم نموذج اسم لـ بدء علامة و تأكيد `DEEPSEEK HARNESS` لا ظهور. لقطة تحقق كامل لقطة.
