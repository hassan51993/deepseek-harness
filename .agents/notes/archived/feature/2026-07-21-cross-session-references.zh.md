# Agent Note: عبر جلسة مرجع

Status: implemented
Archived: 2026-09-04

[English](2026-07-21-cross-session-references.md) | العربية

## مشكلة

Web مستخدم حاجة يأخذ آخر ساحة محادثة في متبادل صلة عمل حمل دخول واحد بند جديد رسالة، لكن لا استعادة، لا fork، أيضا لا يجعل مصدر transcript(نص سجل) مقابل حالي جلسة يملك مرجعي صفة.harness قد توفير دقيق تأكيد جلسة قطعة رفع و أصلي حدث فحص، لكن إذا كل مضيف كل مستقل تحليل سجل، حينئذ سوف تكرار تنفيذ ضغط (compaction) طي، مصدر مرور ترشيح، كبير صغير حد، خطأ سلوك و حفظ دائم. يأخذ مضيف علامة مباشر تحرير رمز دخول agent(ذكي جسم) رسالة اتفاق، أيضا سوف يجعل نواة قلب حلقة ربط بعض واحد نوع UI لغة قاعدة.

## قرار

`@deepseek-ai/dsh-session-reference` هو تسجيل في `ctx.sessionReferenceResolver` فوق مفرد واحد سياق إزالة استهلاك خدمة. هو خارج طبقة `agent/pre-step` مستمع سوف تحليل قد قبول مباشر مستخدم رسالة في مواصفة mention، و استدعاء `prepare()`، مضيف شبكة صلة بلا حاجة إضافة مرجع سلوك. هذا خدمة إرجاع قسم مغادرة يمكن قراءة محتوى و واحد نسخة اختياري، حمل معرف كما تجميد ربط `UserMessage` لقطة؛ نواة قلب agent حزمة حيث لا تحليل جلسة URI، أيضا لا قراءة أخرى سجل.

`dsh-session:<base64url(JSON.stringify(sessionId))>` هو و مضيف غير متصل مواصفة معرف رمز. نظام أولا تنفيذ JSON نص تحرير رمز، مجددا تنفيذ base64url تحرير رمز، لذلك جذب رقم، صحيح مائل عمود، عكس مائل عمود،Unicode، تبديل سطر رمز و أخرى مهمة معنى JavaScript نص قيمة كل قدرة بلا ضرر نحو إرجاع، لن بسبب قسم فصل رمز إنتاج اختلاف معنى.Web استقبال من Host توليد، يتضمن هذا URI `@[label](uri)` رفع و علامة، و يأخذ هو غلاف تركيب لـ أصل فرعي session chip؛ صاف نص عميل يمكن استخدام نفس نوع سطر داخل رفع و علامة. صريح Markdown رفع و علامة سوف رفض صيغة خطأ URI. عار نص فقط لديه في سالب تحميل غير فارغ كما شكل حالة رمز دمج base64url وقت عندئذ سوف يصبح مرجع، بينما كما حل رمز مرور مسار ما زال يجب عبر مواصفة صفة تحقق؛ فارغ سالب تحميل أو فقط يحتوي علامة نقطة رمز رقم استخدام قاعدة ما زال حسب عادي نقاش نقاش نص معالجة.

هذا خدمة استخدام `ctx.sessionQuery.readSurface(sessionId)`: هو أولوية من فوري جلسة تحميل مرة لغة مادة مراقبة نتيجة، استخدام جلسة حزمة مواصفة جدول طبقة حساب قاعدة تنفيذ طي، و إرجاع و مصدر بيانات قسم مغادرة جلسة رأس، التقاط ترتيب رقم و حالي عقدة.FTS لا هو اعتماد: مرشح اكتشاف سوف مطابقة id،cwd أو الأكثر جديد طي بعد عنوان، بينما رسالة رئيسي جسم لا دخول مرشح طبقة. غير فارغ استعلام سوف مقابل مرئي لغة مادة في عنوان مراقبة نتيجة تنفيذ دفعة معالجة، بـ محدود تزامن قراءة حفظ دائم سجل، و دعم حمل إلغاء؛ مخصص استخدام عنوان بحث جذب يمكن استبدال هذا بند اكتشاف مسار، بينما بلا حاجة تغيير مرجع معرف أو دقيق تجهيز مرور مسار.

## لقطة و إسقاط

دقيق تجهيز مرور مسار حسب أول مرة ظهور ترتيب ذهاب إعادة، رفض هدف جلسة ذاته id، و كما تنفيذ يمكن إعداد عدد كمية حد، لكن مرجع صلب حد أعلى لـ ثلاثة عدد، كل قراءة متساو و سطر تنفيذ. هذا مرور مسار لن إرجاع جزء سياق: أي قراءة، إلغاء، تحقق أو ميزانية خطأ كل سوف في قد قبول رسالة دخول موجه إلى نموذج تاريخ قبل انتهاء هذا جولة. إلغاء سوف و إجراء في مرشح اكتشاف و دقيق قراءة تنافس سرعة، لذلك أي جعل حفظ دائم خلفية لا يمكن في قطع انتظار معالجة عملية، مستمع أيضا قدرة و وقت انتهاء انتظار.queued رسالة وصول `agent/pre-step` وقت سوف التقاط كل مصدر؛ هذا بعد مصدر جلسة إضافة جديدة رسالة، تنفيذ ضغط، يتم حذف أو استبدال حفظ دائم محتوى، كل لا يمكن تغيير هدف جلسة في سجل سياق.

إسقاط سوف إبقاء مباشر مستخدم رسالة و steering(في طريق جذب توجيه) ، قد إتمام assistant نص، و يحمل من `dsh-compaction` توجيه خروج مواصفة مصدر علامة فحص نقطة مستخدم رسالة. هذا علامة يخص ضغط قدرة اتفاق واحد جزء، بينما غير بعض عدد خلفية حزمة اسم. مرجع لقطة بداية نهاية هو مستقل كما حمل مصدر `user/message` حدث، لذلك إسقاط سوف يأخذ هو جمع بصفة حقن سياق ترتيب حذف، أبدا تمرير عودة نقل بث مبكر أولا لقطة. إسقاط أيضا سوف ترتيب حذف ضغط قبل قد يتم حجب حجب عقدة، أداة و ذلك نتيجة، دفع إدارة (reasoning) ، أخرى إضافة مستخدم رسالة، فقط لأجل سجل سجل، و بعد لم إتمام assistant قسم قطعة. لذلك، تكرار ضغط فقط سوف كشف حالي جدول طبقة ما زال إبقاء الأكثر جديد طي فحص نقطة جدول نظام و ذلك ذيل جزء رسالة؛ نظام لا توفير raw/current فتح صلة، أيضا لا استعادة يتم حجب حجب محتوى.

نظام يأخذ واحد تجمع دمج سياق تسلسل تحويل لـ JSON، و وضع في ثابت غير ممكن معلومة خلف مشهد تحذير إبلاغ بعد. هذا تحذير إبلاغ اشتراط نموذج لا يلزم التزام دوران يتم مرجع جلسة في إشارة أمر، إذن إعلان أو أداة طلب، حذف غير حالي مستخدم مجددا مرة رفع خروج هذه محتوى. وسم أمان تسلسل تحويل سوف يأخذ بيانات في كل `<` بلا ضرر تحويل معنى لـ JSON `\u003c`؛ لذلك مصدر نص لا يمكن تجميع خروج خارج محيط صنف يشبه XML وسم، أيضا لا يمكن هروب هروب بيانات منطقة مجال. نفس عدد تسلسل تحويل جهاز سوف مستقل نواة حساب كل مصدر بايت عدد.AgentLoop سوف يأخذ لقطة حفظ دائم لـ واحد بند حمل مصدر معلومة `user/message`، ضيق وصل في مباشر `user/message` بعد. لذلك، هدف إعادة تشغيل بلا حاجة إضافة جديدة حدث نوع، وضع وضع نمط أو نص التوجيه غلاف طقم، أيضا قدرة ممتلئ كاف «نموذج مرئي/سجل يمكن إعادة بناء» ثابت كمية.

## رسالة كل حق

هذا خدمة خارج طبقة `agent/pre-step` مستمع سوف أولا استدعاء تحت تنقل مستمع، و كما فقط معالجة `enter` قرار. هو سوف تحليل كل بند قد قبول مباشر مستخدم رسالة، في يأخذ مواصفة mention استبدال لـ يمكن قراءة وسم وقت إبقاء رسالة id، و يأخذ تجميد ربط لقطة إدراج دخول إلى هذا رسالة ضيق بعد. نهائي قيادة أخذ رسالة هو دقيق تجهيز مرور مسار إدخال، لذلك طابور صف تحرير و من queue نقل حركة إلى steer لا حاجة مرجع مخصص استخدام حالة.[سياق قسم مغادرة قرار](../architecture/2026-07-24-separate-context-injection-from-turn-execution.zh.md) قاعدة تحديد هذا واحد سياق ترتيب.

مرجع دقيق تجهيز مرور مسار لا هو جديد إلقاء تمرير بروتوكول، ذاته أيضا لن إنشاء جولة. دقيق تجهيز فشل سوف عبر agent loop قائم إضافة فشل مسار إنهاء قد قبول جولة.

## مضيف مهايئ

موحد واحد Web `@` source يأخذ جلسة مرشح و Host دعم حمل ملف اكتشاف تركيب في واحد بدء. جلسة مرشح استعلام سوف مقابل session id،cwd أو الأكثر جديد طي بعد عنوان تنفيذ لا منطقة قسم كبير صغير كتابة فرعي سلسلة مطابقة، عرض هذا عنوان، و في لا يوجد عنوان مراقبة نتيجة أو عنوان مراقبة فشل وقت رجوع إلى session id. استعلام التزام دوران طلب إلغاء إشارة؛session id،cwd و رفع و وسم في خارجي تحكم محرف سوف يتم تحويل معنى، لكن مواصفة URI ما زال إبقاء أصلي id.

Web عبر الذي تابع خدمة فوق توليد Remote طريقة توفير ملف و جلسة اكتشاف، تفصيل رؤية [Web ملف و جلسة مرجع](2026-07-27-web-file-and-session-references.zh.md).session اختيار بند هو من Host توليد مواصفة mention دعم دعم أصل فرعي chip. عادي `session.prompt` إلقاء تمرير سوف يحمل هذا mention، بلا حاجة مرجع مخصص استخدام API Proxy توجيه. إعادة تشغيل سوف يأخذ مستقل session-reference سياق و ضيق مجاور ذلك قبل مباشر رسالة صلة ربط بدء قدوم، و تصيير دقيق بسيط مصدر ملخص، بينما لا كشف لقطة JSON.

[فقط موجه إلى تلقائي تحويل ACP(Agent Client Protocol) نقل طبقة](../simplification/2026-07-23-acp-automation-only-protocol.zh.md) متعمد لا تركيب جلسة استعلام أو جلسة مرجع خدمة.

## ميزانية و إبقاء سياسة

الأكثر كثير ثلاثة عدد مرجع في كل واحد افتراضي مستقل حد في 65,536 عدد UTF-8 بايت بـ داخل. إبقاء سياسة سوف أولوية إبقاء حالي ضغط فحص نقطة و الأكثر جديد محادثة وحدة، مجددا إسقاط مقارنة قديم غير فحص نقطة رسالة. إذا إبقاء نص مرور كبير، نظام استخدام `dsh-output-retention` إجراء أول ذيل قطع قطعة و سجل دقيق تأكيد حذف بايت عدد؛ إذا بعض عدد مصدر ثابت تسلسل تحويل حقل لا يمكن تركيب دخول ذلك حد أعلى، كامل دقيق تجهيز مرور مسار سوف فشل، لن إخراج جزء سياق.

## اعتبار مرور بديل خطة

- **انتظار SQLite FTS5**: غير مقبول، لأن لقطة صحيح تأكيد صفة اعتماد حسب دقيق تأكيد id قراءة و مواصفة جدول طبقة طي، بينما لا هو محتوى بحث.FTS فقط تعديل دخول مرشح اكتشاف.
- **يأخذ رفع و علامة لغة قاعدة وضع دخول agent إلقاء تمرير طريقة**: غير مقبول، لأن هذا سوف إجبار جعل نواة قلب بروتوكول تحليل بعض عدد مضيف عرض لغة قاعدة، و منع توقف حمل نوع غير نص مضيف إعادة استخدام نفس دلالة طبقة.
- **في كل مضيف في قسم آخر تنفيذ مرجع**: غير مقبول، لأن إسقاط، أمان تحذير إبلاغ، إبقاء سياسة و حفظ دائم سوف في مختلف مضيف بين تدريجي تدريجي انحراف مغادرة.
- **يأخذ سياق مرفق إضافة إلى `SendOptions` و مباشر نص التوجيه استلام عنصر صندوق سجل**: غير مقبول، لأن عام إلقاء تمرير سوف لا نيل لا مسؤول اختراق اختراق دقيق دخول،steering، إلغاء و مراقبة مجال أمر خدمة. مجال مستمع يمكن دقيق تجهيز نهائي قيادة أخذ رسالة، بلا حاجة توسيع كبير كل بند مباشر نص التوجيه.
- **في استدعاء `followup()` قبل من مضيف دمج بادئة**: غير مقبول، لأن `agent/pre-step` يجب فقط فحص و تعديل كتابة مباشر نص التوجيه. سوف لقطة إبقاء لـ مستقل حمل مصدر رسالة، يمكن صيانة حمل هذا حد، و يجعل Web من مباشر مستخدم هواء فقاعة في إخفاء خلف مشهد بايت.
- **إعادة تشغيل أصلي مصدر سجل أو استعادة يتم حجب حجب حدث**: غير مقبول، لأن ضغط تعريف حالي نموذج جدول طبقة، و كما ممكن متعمد تصفية استبعاد حساس شعور أو فتح إلغاء عال مرتفع تاريخ محتوى.
- **استعادة أو fork مصدر جلسة**: غير مقبول، لأن هذا وظيفة فقط لـ واحد بند علامة رسالة توفير فقط قراءة خلف مشهد، لا توفير هوية أو دورة الحياة وصل متابعة صفة.
- **نموذج خطوة دخول بعد إعادة قراءة مصدر جلسة**: غير مقبول، لأن هدف إعادة تشغيل سوف اعتماد متغير خارجي حالة، بينما لا هو قد سجل لقطة.

## تحقق

وحدة و اختبار تكامل تغطية URI بلا ضرر نحو إرجاع و نص حد علامة نقطة، صريح صيغة خطأ مرجع، حسب id/cwd/عنوان إجراء مرشح مطابقة و ترتيب ترتيب، عنوان مراقبة فشل وقت رجوع، مرشح استعلام إلغاء، تحكم محرف تحويل معنى، إسقاط ترتيب حذف قاعدة، لقطة غير تمرير عودة إسقاط، و خلفية غير متصل ضغط فحص نقطة، وسم أمان غلاف طقم، ذهاب إعادة، ذاتي مرجع، عدد كمية حد، قراءة كل لديه أو كل بلا، تخزين قراءة لا انتهاء وقت إلغاء، تدريجي مصدر مستقل بايت إبقاء، تجميد ربط رسالة كل حق،pre-step تحليل و إدراج دخول، تحت تنقل رفض،Chat إسقاط بعد استمرار استدعاء عودة صلة ربط، عنوان عزل، و توليد Remote اكتشاف واجهة. واحد بلا مفتاح Web لقطة سوف ثابت تجميع بعد مرجع اختيار مسار.

## عاقبة

جديد إضافة بنية صار مستقر دلالة حد، لن إضافة جديدة حفظ دائم schema، حدث نوع،FTS اعتماد، مصدر جلسة حجز قراءة أو مقابل ضغط الذي حجب حجب محتوى وصول. معيار CLI تركيب سوف لـ Web صريح تركيب هو، و في إعداد في كشف مرجع عدد كمية و تدريجي مصدر بايت حد أعلى؛ ذاتي تعريف مضيف في تركيب هذا خدمة و ملائم إعداد إدخال قبل إبقاء ثابت. مرجع سياق سوف في إعداد حد حد داخل زيادة كبير هدف تاريخ، مع بعد يمكن من هدف جلسة عادي ضغط إجراء ملخص؛ إتمام ضغط بعد، مصدر جلسة سهل لم يعد متبادل صلة.
