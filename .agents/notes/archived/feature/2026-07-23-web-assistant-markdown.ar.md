# Agent Note: Web محادثة في أمان assistant Markdown

Status: implemented
Archived: 2026-09-04

[English](2026-07-23-web-assistant-markdown.md) | العربية

## مشكلة

Web محادثة عبر جلسة حدث، تاريخ إعادة تشغيل و تدفق صيغة تراكم تراكم إبقاء assistant Markdown مصدر نص، لكن ذلك الأكثر نهاية طرف نص أصل لغة سوف حسب حرف وجه تصيير مصدر نص. إذا تعديل مشترك أصل لغة، مستخدم رسالة و steering(في طريق جذب توجيه) رسالة أيضا سوف يتم صيغة تحويل؛ إذا في وقت التشغيل في تحليل، فإن سوف يأخذ عرض حالة خلط دخول لا اعتماد React جلسة إسقاط.

## قرار

`@deepseek-ai/dsh-client-ui-primitives` توجيه خروج `MarkdownText`، استخدام عمل لا تلقي معلومة مهمة assistant نص مصير؛`ui-conversation` فقط لـ assistant `text` كتلة اختيار هذا مصير. قد إتمام تاريخ رسالة، تدفق صيغة إخراج ذيل جزء و يتم في قطع جزء إخراج قد مشترك استخدام `AssistantMarkdown`، لذلك بلا حاجة أكثر تعديل حدث أو لقطة، هو جمع سهل سوف اعتماد نفس مصير. مستخدم رسالة و steering رسالة مرور `projectUserText` تصيير (سطر داخل عادي قطعة مقطع إضافة مرجع chip) ، و إبقاء حسب حرف وجه تصيير.

`MarkdownText` بـ `mdast-util-from-markdown` إضافة GFM micromark توسيع تحليل، و مرور حزمة داخل ذاتي لديه مصير تصيير mdast شجرة، جولة تدفق صيغة إخراج خلال زيادة كمية تحليل ([زيادة كمية AST مصير Note](../architecture/2026-08-06-web-markdown-incremental-ast-renderer.ar.md) يملك هذا آلية و ذلك DOM متسق صفة اتفاق). هو تغطية CommonMark كتلة، و GFM جدول إطار، مهمة قائمة، حذف خط و تلقائي رابط، كما لا تحليل أصلي HTML. واحد micromark attention توسيع إعادة استخدام CommonMark resolver، معا سماح حتى قليل اثنان عدد نجم رقم مجموعة صار وصل متابعة تسلسل في Unicode علامة نقطة بعد إغلاق دمج، قبل رفع هو ذلك بعد ضيق مجاور CJK نص. هذا واحد مثال خارج شمول غطاء تدفق صيغة إخراج خلال و إتمام بعد بلا فارغ إطار CJK نص في بـ علامة نقطة ربط ذيل خشن جسم؛ مفرد نجم رقم قوي ضبط، ضيق مجاور غير CJK نص حال حال، قد تحويل معنى مصدر نص، شفرة و عدد تعلم عام صيغة ما زال امتداد استخدام فوق تنقل تحليل سلوك. محيط شريط شفرة مرور مشترك `CodeBlock` توجيه؛ هذا مكون استخدام عميل shiki مفرد مثال (`--shiki-*` token) عال مضيء قد تسجيل لغة قاعدة، لا فإن رجوع لـ صاف انتظار عرض نص. جولة تدفق صيغة إخراج خلال، محيط شريط زيادة كمية عال مضيء: كل قسم قطعة من حفظ grammar state خروج إرسال tokenize جديد إتمام نص و ما زال في زيادة طويل الأكثر بعد واحد سطر، لا تكرار معالجة قد إتمام بادئة ([تدفق صيغة محيط شريط عال مضيء Note](2026-08-20-web-streaming-fence-highlight.ar.md) يملك هذا آلية).

نظر شعور بين مسافة، جدول إطار، رابط، مرجع كتلة، سطر داخل شفرة و شفرة كتلة خارج إطار التزام دوران deepsuite `@deepseek/md`(`markdown.css` / `code-block.css`) ، و استخدام نفس طقم `--dsw-alias-markdown-*`،`--dsw-font-markdown-*`،`--dsw-alias-border-l*` و `--dsw-alias-label-*` token. رابط استخدام `--dsw-alias-state-business-primary`(deepsuite مثال صيغة جدول استخدام `--dsw-alias-brand-text`، فقط في newDesign تحت لـ أزرق لون؛design-platform سوف brand-text إبقاء لـ قريب أسود لون، هذا موضع لا فعل إعادة ضبط لون). عند مفرد عدد سطر داخل شفرة token تماما من قطعا مقابل HTTP(S) URL بنية صار وقت، ذلك شفرة خارج إطار سوف يتضمن واحد و عادي رابط نفسه، يمكن عبر مفتاح قرص تجمع تركيز أمان خارج سلسلة مرساة نقطة؛ طرف فتحة، مسار و استعلام نص إبقاء ثابت، بينما أمر، غير كامل URL، أخرى scheme و محيط شريط شفرة ما زال لن يصبح رابط.`CodeBlock` توفير لغة أفقي عرض و نسخ تحكم عنصر (`نسخ` / `نسخ نجاح`). قد إتمام نص عبر تحديد مسودة لغة قاعدة عدد تعلم توسيع تصيير KaTeX؛`mathCompatibility` سوف `\(...\)`،`\[...\]` و كتلة درجة نفس سطر `$$...$$` خريطة لـ نفس طقم معيار عدد تعلم AST عقدة. هذا هو واحد طبقة صغير نطاق محلل توافق طبقة، لا هو صحيح فإن إعادة كتابة، أيضا لا إصلاح صيغة خطأ نموذج إخراج. تدفق صيغة إخراج في إتمام قبل إبقاء حسب حرف وجه تصيير، تجنب تجنب لا كامل عام صيغة وميض الآن خطأ. مرجع لاصق كيس، عنوان مرساة نقطة،thinking-small markdown تغيير جسم، و ذاتي تعريف □/☑ مهمة علامة ما زال لا في نطاق داخل؛GFM مهمة قائمة متابعة استخدام أصلي تكرار اختيار إطار.

هذا اعتماد في `ui-primitives` في صريح إعلان؛ من في هذا واحد صاف مكتبة من Web shell مسبق وضع، محلل و عال مضيء جهاز سوف يصبح ابتدائي متصفح bundle واحد جزء.

## لا تلقي معلومة مهمة إخراج سياسة

assistant توليد رابط هدف عنوان فقط حد قطعا مقابل HTTP،HTTPS و mailto URL.HTTP(S) رابط سوف في جديد وسم صفحة في فتح، و حمل لديه `rel="noopener noreferrer"`؛ متبادل مقابل هدف عنوان و أخرى بروتوكول سوف تصيير لـ غير ممكن تنقل نص.Markdown صورة التزام دوران مستقل[بعيد مسار صورة سياسة](2026-07-30-web-remote-markdown-images.ar.md). من في خط الإنتاج في لم جذب دخول HTML محلل، أصلي HTML ما زال هو لن توليد فاعلية مصدر نص.Shiki إخراج هو من محيط شريط نص توليد ساكن حالة span شجرة (لا يحتوي نص برمجي أو مستخدم HTML).

محيط شريط شفرة و GFM جدول إطار كل منها معالجة أفقي نحو فيض خروج، لذلك مقارنة طويل محتوى لا يمكن دعم عرض محادثة شريط.

## اعتبار مرور بديل خطة

**سوف قائم mdast و micromark تطوير اعتماد رفع رفع لـ صحيح صيغة اعتماد، و صيانة ذاتي تعريف React walker.**هذا خطة تجنب تجنب جذب دخول جديد محلل جسم نظام، لكن منتج حاجة ذاتي سطر مسؤول كل نوع عقدة خريطة،GFM توسيع و أمان حساس شعور تصيير فرع. مخصص استخدام React مصير سوف هذا طقم مرة تاريخ تسليم من فوق تنقل صيانة، معا إبقاء AST إلى React معالجة مسار.*بعد بسبب جديد دليل يتم دفع قلب——زيادة كمية تدفق صيغة تحليل حاجة صاف نص غلاف تركيب لا يمكن توفير AST درجة إدخال؛ هذا قرار من[زيادة كمية AST مصير Note](../architecture/2026-08-06-web-markdown-incremental-ast-renderer.ar.md) يملك.*

**يأخذ مستخدم نص التوجيه و steering أيضا حسب Markdown تصيير.**هذا سوف إنتاج صيغة تحويل مستخدم إدخال فرعي أثر. في منتج واضح اختيار هذا سلوك قبل، هذه إدخال ما زال حسب حرف وجه تصيير.

**سوف Markdown تحليل لـ جلسة لقطة.**هذا سوف يجعل React عقدة أو عرض طبقة AST يصبح حمل دائم وقت التشغيل حالة، و إعادة جذب دخول نهائي إخراج و تدفق صيغة إخراج بين نمط حد. تحليل ما زال إبقاء في عرض طبقة ورقة عقدة في.

**عبر صاف تحويل تفعيل أصلي HTML.** أصلي HTML حالي لا يوجد منتج يحتاج طلب، و كما سوف توسيع كبير يمكن تنفيذ محتوى حد، لذلك إبقاء منع استخدام، بلا حاجة زيادة صاف تحويل جهاز اعتماد. بعيد مسار صورة من لاحق[صورة سياسة](2026-07-30-web-remote-markdown-images.ar.md) قيد.

**نقل غرس deepsuite Prism `highlight.css` و mdast إدارة خط.**خارج مراقبة متسق صفة من CSS Modules و مشترك `--dsw-*` token مسؤول؛ عال مضيء ما زال مشي قائم shiki سماح قائمة، جعل عميل لا لا بد جذب دخول ثاني طقم عال مضيء جهاز أو Prism class اتفاق.

**لـ معالجة CJK علامة نقطة حد بينما مسبق معالجة Markdown مصدر نص، أو في تحليل بعد إصلاح نص عقدة.**مصدر نص إعادة كتابة يجب في محلل كف إمساك هذه منطقة آخر قبل تكرار الآن تحويل معنى، شفرة، عدد تعلم عام صيغة و تحديد حد رمز قاعدة؛ نص عقدة إصلاح فإن قد فقد فقد جزء مصدر نص معنى رسم، أيضا لا يمكن و قد تحليل سطر داخل عقدة تركيب. في قسم كلمة جهاز حد توسيع attention يمكن إبقاء فوق تنقل resolver، و سوف فرق مختلف حد في تحديد حد رمز ملائم استخدام شرط فوق.

**اشتراط نموذج إخراج معيار رابط، و يجعل URL شكل سطر داخل شفرة إبقاء غير ممكن تفاعل.**إخراج إشارة جذب لا يمكن موحد واحد قد حفظ دائم عودة تكرار و رقم ثلاثة جهة نموذج عودة تكرار، بينما سطر داخل شفرة هو سوف طرف نقطة علامة لـ حرف وجه قيمة معتاد رؤية طريقة. فقط في سطر داخل شفرة تصيير حد تعرف آخر كامل قطعا مقابل HTTP(S) قيمة، يمكن في تطبيق قائم لا تلقي معلومة مهمة رابط سياسة معا إبقاء شفرة دلالة.

## عاقبة

assistant عودة تكرار في تدفق صيغة إخراج و إعادة تشغيل خلال كل سوف متسق أرض تصيير لـ دلالة تحويل Markdown، بينما أداة بطاقة، دفع إدارة سطر، تفاعل، مستخدم هواء فقاعة و مضيف بروتوكول إبقاء ثابت. كل مرة تراكم تراكم تحديث بعد، تدفق صيغة إخراج فقط إعادة تحليل لا مستقر ذيل جزء؛ لم إتمام Markdown ممكن مؤقت وقت تغيير ذيل جزء بنية، لكن مستقل ذيل جزء سوف حد تحديد React بطلان نطاق، نهائي حدث أيضا لن تبديل مصير.URL شكل سطر داخل شفرة سوف في لا تغيير ذلك مرئي حرف وجه نص حال حال تحت تغيير نيل يمكن تنقل، بينما اعتماد لا أمان scheme أو خلط لديه أخرى محتوى شفرة ما زال غير ممكن تفاعل. شفرة محيط شريط و أداة و تفصيل حال جدول طبقة مشترك استخدام نفس خارج إطار و نسخ مسار. ابتدائي Web shell يتضمن Markdown محلل،GFM وقت التشغيل،KaTeX و shiki سماح قائمة؛citation،anchor و thinking-small جدول طبقة ما زال مؤقت مؤقت.
