# Agent Note: Goal أمر إدخال إسقاط

Status: implemented
Archived: 2026-09-04

[English](2026-08-01-goal-command-input-projection.md) | العربية

## مشكلة

موجه إلى مستخدم أمر في نموذج جولة خارج تنفيذ، و حفظ دائم لـ `command/run` و `command/done`.Web transcript(نص سجل) هذا قبل فقط تصيير نتيجة سطر. لذلك، في جديد جلسة في،`/goal` سوف صاف فارغ تحرير جهاز و نجاح إتمام، لكن صفحة ما زال توقف إبقاء في فارغ أبيض Hero؛ فقط لديه لاحق محادثة محتوى تنشيط Chat بعد، نتيجة عندئذ سوف عرض. إذا معالج إلحاق عادي `user/message`، سوف تغيير نموذج مرئي تاريخ و أمر دلالة.

## قرار

أمر سجل التسجيل و حمل دائم أمر دورة الحياة إبقاء ثابت.`command/run` سجل من محلل توفير اسم، اختياري أصل مثال معامل، مصدر و استدعاء id؛`command/done` سجل تسوية. اثنان بند حدث كل لا يحمل متصفح عرض معنى رسم.

`ui-goal` عميل إضافة سوف في عام أمر Definition خارج تسجيل واحد عودة Goal كل Conversation Definition. اثنان من كل مطابقة نفس بند `/goal` `command/run`: عام Definition إبقاء حمل دائم نتيجة سطر،Goal Definition فإن في أكثر مبكر قسم عدد مرساة نقطة بناء مستقل `command-input` Chat Node.Goal إضافة أيضا لـ هذا Node تسجيل keyed React renderer. هو محلي مكون فقط إعادة استخدام مستخدم هواء فقاعة يمين مقابل متساو بضعة أي شكل و دلالة token، استخدام 14px/22px انتظار عرض حرف جسم نص، و كما لا تركيب ختم الوقت، نسخ أو فرع عملية.

`Session.composerPhase` يأخذ مرئي غير أمر Chat Node نظر لـ محادثة محتوى، لذلك `command-input` سوف تنشيط حالي محادثة، بينما فقط لديه عام أمر سطر وقت لن.Host `summary.blank` موضع ما زال بـ جولة لـ أساس أساس، لذلك قائمة إخفاء و فارغ أبيض جلسة إعادة استخدام إبقاء ثابت.

Goal Definition أصل حسب بنية تحويل run إرسال توليد `/<name><args.trimEnd()>`: قسم فصل رمز و داخلي كثير سطر إدخال إبقاء ثابت؛ في قد إقرار قيادة عار أمر شكل صيغة في، معامل فقط لديه واحد فارغ إطار وقت عرض `/goal`. فقط يتضمن `command/done` تاريخ نافذة لا يوجد مطابقة Goal Context، لذلك سوف إبقاء عام نتيجة سطر، بينما لن وهمي بنية إدخال هواء فقاعة؛ تحميل يتضمن أكثر مبكر run صفحة بعد، اثنان عدد Node كل سوف استعادة.

نموذج حد إبقاء ثابت.Goal إسقاط لن إنشاء `user/message`،`turn/start`،`step/start` أو `request/header`. قد قبول goal تغيير فقط سوف عبر goal مجال قائم `<goal_state>` لقطة أو clear tombstone وصول نموذج، و `command-input` Node غير متصل.

## تحقق

Goal عميل اختبار ثابت مزدوج Definition إخراج، ترتيب، ترتيب حذف أخرى أمر، عار أمر و كثير سطر نص، فقط يحتوي done قطع قسم نافذة،renderer دلالة، مورد تحرير و جديد جلسة phase اختيار. بلا مفتاح كامل تجميع Web مشهد في لا يحتوي نموذج مهايئ جديد جلسة في إيداع عار `/goal`، تحقق اثنان سطر كل عرض كما لا وجود موجه إلى نموذج حدث، لكن بعد إعادة تحميل و تحقق حفظ دائم بعد transcript.

## تجهيز اختيار خطة

**في `/goal` معالج في إلحاق `user/message`.**غير مقبول، لأن هذا أمر سوف تغيير صار نموذج إدخال، و ممكن إطلاق أو تغيير لاحق طلب.

**نحو أمر سجل التسجيل و حمل دائم حدث إضافة عرض معنى رسم.**غير مقبول، لأن واحد Goal عرض سوف توسيع كبير عام أمر واجهة، و اشتراط Session،Chat و كل أمر fixture(اختبار قبل وضع بيانات) كل يحمل متصفح عرض حالة. قائم `command/run` اسم و معامل قد كاف بـ يجعل تركيب بعد Goal عميل إعادة بناء ذاتي لديه عرض.

**يجعل عام أمر renderer تعرف آخر `/goal`.**غير مقبول، لأن أمر مخصص استخدام عرض بناء عودة Goal عميل إضافة كل. في تركيب في إزالة هذا إضافة بعد، هواء فقاعة يجب مع لـ إزالة فقد، كما أمر تنفيذ و عام نتيجة سطر لا يستطيع تغيير.

**يأخذ كل بند أمر إدخال كل تصيير لـ مستخدم هواء فقاعة.**غير مقبول، لأن قائم تحكم أمر سوف متعمد يجعل جديد جلسة توقف إبقاء في Hero؛ هذا مثال تعديل سوف في لا يوجد وظيفة ذاتي لديه Conversation Definition حال حال تحت توسيع كبير تفاعل دلالة.

## عاقبة

واحد بند حمل دائم `/goal` run سوف نحو اثنان عدد كل منها مستقل ملكية عرض Context توفير بيانات، بينما لا تغيير أمر قدرة. في تركيب في إزالة `ui-goal` بعد، عادي أمر تنفيذ و ذلك نتيجة سطر إبقاء ثابت. فوري وسم صفحة و بارد إعادة تحميل سوف نيل إلى متسق نتيجة، لأن اثنان عدد عرض كل إرسال توليد ذاتي نفس بند run. صفحة قطع قسم فقط إبقاء `command/done` وقت، سوف مؤقت وقت فقط عرض نتيجة سطر؛ إذا هذا أمر هو جلسة في وحيد محتوى،Hero سوف إخفاء هذا سطر، مباشر إلى تحميل أكثر مبكر صفحة استعادة run. من في Host blank دلالة ما زال بـ جولة لـ أساس أساس، جلسة في نموذج جولة بدء قبل ما زال من قائمة في إخفاء، و كما يمكن إعادة استخدام.
