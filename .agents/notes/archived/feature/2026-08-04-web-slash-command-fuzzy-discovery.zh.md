# Agent Note: Web مائل عمود أمر نموذج غامض اكتشاف

Status: implemented
Archived: 2026-09-04

[English](2026-08-04-web-slash-command-fuzzy-discovery.md) | العربية

## مشكلة

Web أمر قائمة مفرد اشتراط حسب أمر اسم بادئة مطابقة، لذلك مستخدم فقط تسجيل نيل صلة مفتاح حرف أم لكن لا تسجيل نيل ذلك دقيق تأكيد موضع وقت، حينئذ لا يمكن اكتشاف أمر. نفس `/` قائمة مفرد skill source بعد قدوم ما زال إبقاء منطقة قسم كبير صغير كتابة بادئة مرور ترشيح، نفس قائمة مفرد اثنان عدد قسم مجموعة مقابل نفس مثال حسب مفتاح إعطاء خروج مختلف جواب سجل. توسيع كبير قائمة مفرد مطابقة نطاق يمكن جعل أمر أكثر سهل اكتشاف، لكن أمر تنفيذ ما زال يجب إبقاء دقيق مطابقة و تحديد صفة: قريب يشبه إدخال سطر أبدا قدرة تنفيذ متبادل قريب أمر.

## قرار

`/` قائمة مفرد أمر source و skill source سوف مفتاح دخول استعلام بصفة لا منطقة قسم كبير صغير كتابة لديه ترتيب فرعي تسلسل، و مرشح اسم إجراء نموذج غامض مطابقة، اثنان من مشترك استخدام واحد ترتيب ترتيب جهاز:ui-primitives في `rankByName`، أي مشترك متصفح شفرة ضيق ساكن حالة ملكية جهة ([client قاعدة](../../../../packages/client/AGENTS.md)). دقيق بادئة بنية صار ترتيب اسم الأكثر عال واحد صنف مطابقة. في كل صنف مطابقة في، مقابل متساو قسم عدد تجاوز عال تجاوز أولوية: قسم فصل رمز حد و متبادل مجاور محرف سوف رفع عال قسم عدد، قبل توجيه محرف و بين فصل سوف خفض منخفض قسم عدد؛ قسم عدد نفسه فإن إبقاء host دليل و client contribution ترتيب. موضع مرور ترشيح ما زال سوف في ترتيب اسم قبل من سطر داخل قائمة مفرد في إزالة استقبال معامل أمر.

تقييم قسم جهاز مقابل كل مرشح بند استخدام حركة حالة قاعدة تخطيط، وقت تكرار مختلط درجة لـ `O(query length × name length)`، فضاء تكرار مختلط درجة لـ `O(name length)`. مرشح بند تقييم قسم فقط في عميل إجراء كما فقط فحص أمر اسم؛ أمر وصف لا أثر مطابقة. قائمة مفرد اختيار ما زال إرسال إرسال الذي اختيار دقيق اسم،skill source ما زال سقوط تحت من مضيف دقيق تحليل حرف وجه `/name ` نص، بينما فارغ إطار مفتاح و Enter مفتاح حكم تحديد منطق ما زال اشتراط أمر token دقيق مطابقة.

## اعتبار مرور بديل خطة

**إبقاء فقط بادئة مطابقة.** مرفوض، لأن هذا وظيفة يلزم حل قرار مستخدم لا يمكن دقيق تأكيد عودة ذاكرة بادئة مشكلة اعتماد لكن وجود:`/cpt` لا يمكن اكتشاف `/compact`.

**مطابقة بلا ترتيب محرف أو وصف.** مرفوض، لأن بلا ترتيب مطابقة صعب بـ مسبق قياس، بينما وصف مطابقة ممكن عرض أمر، لكن أمر مرئي اسم لا يمكن حل تفسير ذلك ترتيب اسم.

**استخدام عام نموذج غامض بحث اعتماد.** مرفوض، لأن هذا واجهة فقط يحتاج مقابل صغير نوع أمر دليل استخدام واحد نوع تلقي حد فرعي تسلسل قاعدة؛ يمكن إعداد بحث بحث جذب سوف زيادة bundle جسم تراكم، و جذب دخول منتج لم استخدام ترتيب اسم سلوك.

**من أمر إضافة أو إطلاق إدارة خط توجيه خروج ترتيب ترتيب جهاز.** مرفوض، لأن خاص صفة إضافة حذف cordis تحميل الذي يحتاج خارج لا توجيه خروج أي قيمة، أيضا أبدا وقت التشغيل استيراد آخر عدد خاص صفة إضافة؛ في أمر و skill بين مشترك استخدام واحد مطابقة جهاز نفس سطر منتج (Claude Code،Pi،Kimi Code) خروج في نفس مثال سبب يأخذ هو وضع في مشترك مكتبة في.

## عاقبة

مستخدم يمكن سند حسب ترتيب تسجيل نيل حرف أم اكتشاف أمر أو skill؛ فقط يلزم دليل نفسه، ترتيب اسم حينئذ إبقاء مستقر. تقييم قسم لحظة معنى اعتماد بدء إرسال صيغة قاعدة: و قسم فصل رمز مقابل متساو مطابقة ممكن ترتيب في أصلي عبر درجة أكثر قصير مطابقة قبل.ui-primitives اختبار ثابت كل بند ترتيب اسم بسبب عنصر و نفس قسم وقت مستقر ترتيب، أمر source و skill source اختبار ثابت اثنان من مرور مشترك ترتيب ترتيب جهاز ترتيب اسم، تجميع بعد Web golden ثابت `/cpt` تحليل لـ `/compact`، و واحد فرعي تسلسل استعلام تحليل لـ وحيد skill سلوك. دقيق تنفيذ دلالة إبقاء ثابت.
