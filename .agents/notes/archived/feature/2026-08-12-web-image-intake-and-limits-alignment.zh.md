# Agent Note: كامل صفحة صورة سحب وضع، حد أعلى إسقاط مسبق فحص و تقليص اختصار رسم مستو فرش

## مشكلة

issue #2248 ثاني خطوة مقابل متساو، وصل في[مرفق عنصر عرض note](2026-08-11-web-attachment-display-alignment.zh.md) بعد (ذلك مرفق عنصر شريط،toast و أصل فرعي مكون حزمة قرار متابعة صالح؛ هذا note يحل محل منها تاريخ رسم ممر بضعة أي و مصباح صندوق backdrop أداة جسم قاعدة إطار). و DeepSeek Chat متبادل مقارنة باق تحت فرق مسافة: صورة فقط قدرة سحب إلى composer بطاقة فوق——سحب إلى حديث يوم سجل منطقة سوف يجعل متصفح مباشر تنقل إلى ملف؛ مصباح صندوق إغلاق زر هو عار `×` نص محرف (button لا وراثة حرف جسم، كما هذا حرف شكل حبر أثر في سطر إطار في قلب لـ فوق، لذلك واضح إظهار انحراف مائل) ،backdrop استخدام `color-mix(label-primary 74%)`،dark تحت عكس تحويل صار وخز عين أبيض لون تغطية طبقة؛ واحد بند رسالة كثير ورقة رسم كل منها بـ الأكثر كبير 240px كتلة عمودي حال كومة تراكم، لأن رسم ممر حاوية ذاته يتم تثبيت في 240px؛ عميل تماما لا تنفيذ أيضا لا عرض صورة حد مقدار——مستخدم يمكن تجميع 50 ورقة رسم، مباشر إلى إيداع بعد استلام إلى أصلي `attachment-error (TOO_MANY_IMAGES)` toast، عين نظر مرفق عنصر شريط صاف فارغ أيضا تراجع.

## قرار

**كامل صفحة سحب وضع.** InputBar في document فوق ربط `dragenter`/`dragover`/`dragleave`/`drop`(enter/leave عميق درجة حساب عدد، نظر فتحة حافة حافة و `dragend` تكرار موضع، حسب `Files` نوع باب تحكم جعل نص سحب جر إبقاء أصلي textarea مسار) ، و تصيير `ui-attachment` إضافة جديدة `DropOverlay` أصل فرعي مكون: مرور body portal، لا استقبال إشارة إبرة حدث كل نظر فتحة طبقة (DeepSeek Chat DragMask نظر شعور——أبيض لون 70% إضافة 10px نموذج غامض،dark لـ `rgba(39,39,48,0.7)`، إدراج رسم، عنوان، حد أعلى سطر) ،`disabled` تغيير جسم إعلان إبلاغ قفل تحديد أو مشغول مشغول composer. إشارة إبرة كسول صفة هو تحمل إعادة: سحب جر حدث متابعة أمر في تحت جهة صفحة، عميق درجة حساب عدد دائم بعيد نظر لا إلى حجب غطاء ذاتي ذات.document درجة استماع حالة هو أمان، لأن composer-bar slot لـ `kind: 'single'`.

**مصباح صندوق.** إغلاق زر تبديل صار `ui-primitives` `IconCloseOutline16`(Modal أولا مثال——في viewBox داخل إقامة في SVG لا اعتماد حرف جسم درجة كمية).backdrop استخدام مشترك محادثة إطار حجب غطاء (`--dsw-alias-bg-mask-1` إضافة `--dsw-mask-blur`، اثنان عدد رئيسي عنوان كل هو أسود أساس لون) ، رسم في مستقل أخ أخ رسم طبقة فوق، لأن `backdrop-filter` رسم في حاوية فوق سوف يأخذ معاينة رسم ذاتي ذات أيضا نموذج غامض إسقاط.

**تاريخ تقليص اختصار رسم (DeepSeek Chat قاعدة).** واحد بند رسالة فقط لديه واحد ورقة رسم طويل حافة 240px، عرض مقارنة مثال ملقط صنع في [0.25, 4]،`cover` قطع قطع، خاص آخر عال رسم مرساة تحديد قمة جزء، خاص آخر عرض مرساة تحديد يسار جانب، من لا وضع كبير؛ كثير ورقة رسم تصيير لـ ثابت 64px جهة كتلة، مفرد عدد يمكن تبديل سطر أفقي ترتيب (10px بين مسافة، مستخدم رسالة يمين مقابل متساو).assistant وصل متابعة `image` كتلة دمج دخول نفس عدد رسم ممر، مستو فرش بينما لا هو كل احتلال واحد سطر.

**حد أعلى مقابل متساو و إسقاط.** إدخال قيمة افتراضية هو كل بند رسالة 20 ورقة، كل مصدر ملف 32 MiB، مصدر ملف مجموع كمية 100 MiB، كل ورقة صورة واحد مليار حل رمز مثل عنصر، و مصدر ملف مهمة واحد حافة 16384px. مرفق عنصر خلفية آخر سطر توليد طويل حافة 2048px، مستقل أمان حد أعلى 4 MiB حمل دائم رئيسي إصدار. نموذج طلب استخدام كل توجيه ذاتي ذات مثل عنصر و تحرير رمز بايت ميزانية، لذلك مصدر ملف دقيق دخول لا اعتماد مزود طلب حد.HTTP تحميل جسم موحد واحد استخدام `DEFAULT_MAX_REQUEST_BODY_BYTES = 160 MiB`، ممتلئ كاف 100 MiB مجموع كمية مرور مرور base64 و طلب غلاف تركيب توسيع ورقة بعد تحميل وقت سعة كمية تأكيد.512 MiB مجموع كمية لا يمكن عبر حالي نقل، لأن base64 دخول JSON بعد سوف حاجة واحد وصل قريب V8 نص كبير صغير حد أعلى JSON نص. إدخال حد أعلى عبر `imageLimits` جلسة إسقاط وصول عميل. هو هو كل مرة بدء ثابت تحديد وحدة، من **apiproxy** بينما غير attachment Service Definition تسجيل.`dsh-llm` اعتماد `dsh-attachment`، بينما `dsh-session-projection` مرور `dsh-session` وصول `dsh-llm`؛ في seam حزمة تسجيل إسقاط سوف شكل صار project-reference حلقة. كل بند رسالة عدد كمية و مجموع كمية قاعدة أيضا من proxy قوي صنع تنفيذ.`SessionProjectionMap` دمج متابعة وضع في proxy sessions بروتوكول ملف في، عميل قد عبر تحميل جسم نوع مجددا توجيه خروج استخدام هو.

**إضافة دخول مسبق فحص و خطأ نص سجل.** اثنان نوع إضافة دخول يد اتجاه تجميع دمج إلى InputBar واحد `intakeImages` حزمة تركيب: في `addImages` قبل حسب إسقاط فحص عدد كمية، مفرد رسم بايت و مجموع بايت، مخالفة قاعدة واحد دفعة كامل جسم رفض استلام (DeepSeek Chat دلالة) و قيام لحظة نابض خروج نقطة اسم حد أعلى أفقي عرض——لم يعد لديه إيداع وقت تراجع لعب رمز. مضيف فحص إبقاء، التقاط قاع التفاف مرور composer استدعاء جهة. أفقي عرض نص سجل التزام دوران مستخدم تحديد تحت واحد بند أصل فإن: مستخدم قدرة حل قرار سبب (نموذج لا دعم حمل نظر شعور، عدد كمية، كبير صغير، قسم تمييز معدل، صيغة——صيغة تعديل لـ صحيح وجه صف خروج دعم حمل قائمة بينما لا هو عودة إظهار يتم رفض MIME نوع) استخدام نقطة واضح خروج مسار منتج جملة فرعي؛ مستخدم لا يمكن حل قرار سبب (base64 ضرر تالف، مرجع فقد فقد، قراءة فشل) طي لـ واحد بند إبقاء سبب رمز إرسال فشل جملة فرعي، لأن منتج حالي موجه إلى تطوير من، يمكن فوق تقرير رمز جيد مرور ميت عشوائي نفس. غير مرفق عنصر رمز خطأ إبقاء أصل نص إضافة رمز خطأ عرض.

## تجهيز اختيار خطة

**في attachment Service Definition بنية صنع دالة داخل تسجيل إسقاط وحدة.** يوم لكن seam ملكية، أيضا هو رقم واحد إصدار تنفيذ——يتم اعتماد رسم (فوق وصف حلقة) و واحد اختبار أساس بناء تفاعل مرفوض: أساس صنف بنية صنع دالة استدعاء `ctx.inject` جعل نيل spec في مباشر بنية صنع store إطلاق عام invariant مضيف، بعد من نحو نفس root تكرار تركيب `attachments` خدمة.

**مصباح صندوق استخدام `--dsw-alias-bg-mask-photo`(0.88 أسود، رئيسي عنوان ثابت تحديد، بلا شخص استخدام).** تصميم نظام وفق قطعة فحص نظر جهاز token، أيضا ممكن هو dsweb مصباح صندوق فعلي تغطية طبقة؛ مستخدم اختيار و settings محادثة إطار حجب غطاء متسق (`bg-mask-1` إضافة نموذج غامض)——اثنان من كل قدرة إصلاح dark عكس تحويل.

**في `apply.ts` `addImages` inject داخل مسبق فحص.** seam صاف درجة فوق موضع، بسبب إدارة خط صار هذا مرفوض: إسقاط مستودع لا يوجد كشف إعطاء inject عمل مصنع غير React وجه، بينما InputBar قد بـ معتاد استخدام طريقة إزالة استهلاك إسقاط، كما هو اثنان نوع يد اتجاه وحيد استدعاء جهة.

**استخدام `host.describe` حقل بديل بديل إسقاط.** و جلسة غير متصل كما أكثر سهل مناسب، لكن يلزم مرور حقن prop سلسلة بينما غير `useProjection` إرسال بلوغ، بينما إسقاط مفتاح نقص مقعد دلالة ("لم تركيب attachment خدمة → لا مسبق فحص") هو أبيض أخذ.

## عاقبة

سحب إلى نافذة أي موضع كل قدرة دخول مرفق عنصر شريط، تجاوز حد إضافة دخول في يد اتجاه حدوث ذلك واحد لحظة حينئذ بـ نقطة اسم حد أعلى نص سجل فشل، تاريخ صورة مثل DeepSeek Chat واحد مثال مستو فرش. تحميل جسم افتراضي طلب جسم ميزانية توسيع كبير نحو 5 ضعف، و كما ما زال هو مفرد طلب إقامة إبقاء داخل تخزين فوق حد (جسر يأخذ طلب جسم كامل جسم مؤقت اندفاع؛ قد سجل في connection README حد عقدة).fixture نقل استخدام صلب تحرير رمز افتراضي عدد حرف مرآة مثل هذا إسقاط——تعديل إعداد نشر سوف و fixture نمط نص سجل قسم تقاطع، مقابل keyless عرض عرض عبر طريق يمكن قبول. رسم ممر يسار يمين تبديل، مصباح صندوق تقليص وضع و تحت تحميل، غير صورة ملف بطاقة ما زال دفع متأخر (#2248).
