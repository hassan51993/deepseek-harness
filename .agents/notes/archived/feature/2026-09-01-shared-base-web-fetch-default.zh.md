# Agent Note: مشترك base Web إمساك أخذ قيمة افتراضية

Status: implemented
Archived: 2026-09-04

[English](2026-09-01-shared-base-web-fetch-default.md) | العربية

هذا قرار جزء يحل محل[قد تسليم تركيب في افتراضي Web بحث](2026-07-31-web-default-search.zh.md) داخل صلة في إمساك أخذ حسب يحتاج تفعيل اختيار. هذا سجل متابعة مسؤول بحث مزود اختيار، اعتماد، طرف نقطة، مهلة، و مزود متاح صفة و نموذج أداة تسجيل بين منطقة قسم؛ لا يوجد أي active Agent Note يتم تماما يحل محل أو رمز دمج عودة ملف شرط.

## مشكلة

كل مع مرفق كامل agent منتج كل قبول مجهول اسم عام Web إمساك أخذ، لكن `dsh-base` سوف منع استخدام `web_fetch`، اشتراط كل تطبيق تركيب حزمة تكرار نفسه تغطية. تكرار إعداد متروك تسرب ACP، جعل جديد base-backed profile افتراضي فقط لديه بحث قدرة، حذف غير عمل من ملاحظة معنى إلى هذا عدد مثال خارج، أيضا إجبار جعل منتج بين أصل هذا نفسه snapshot header قسم فتح صيانة.

## قرار

`packages/bundle/base/cordis.patch.yml` بـ `fetch: true` و مع مرفق 60 ثانية بحث مهلة تركيب `dsh-tool-web`.Headless، كامل SDK،ACP و فقط استخدام base ذاتي تعريف profile سوف وراثة `web_search` و `web_fetch`، بلا حاجة تطبيق درجة تغطية.Web app سوف منع استخدام base أداة بند إعداد، و حسب agent preset تركيب نفسه واحد مقابل أداة. مستقل `sdk-minimal` profile لا استخدام base، لذلك إبقاء ثابت.

base HTTP مزود فقط سماح مجهول اسم طلب مرور مرور تحقق عام `http:` و `https:` هدف عنوان. إمساك أخذ في shell و نظام الملفات sandbox أو مراجعة دفعة preset خارج تنفيذ، بلا حاجة تدريجي مرة مراجعة دفعة؛ عام هدف عنوان تحقق لن منع توقف نحو عام شبكة إرسال بيانات. حاجة مختلف شبكة شبكة سياسة منتج ينبغي في لاحق تركيب حزمة أو profile patch في تغطية كامل `tool-web` إعداد.

## اعتبار مرور بديل خطة

**في base في منع استخدام إمساك أخذ، مجددا من كل منتج قسم آخر تفعيل.** غير مقبول: كل مع مرفق كامل منتج كل اختيار نفسه قدرة، تكرار إعداد لا يوجد جدول بلوغ منتج فرق مختلف، أيضا ممكن متروك تسرب لم قدوم base-backed profile.

**فقط زيادة ACP تغطية.** غير مقبول: هذا نوع طريقة قدرة إصلاح حالي متروك تسرب، لكن سوف إبقاء ثلاثة موضع تكرار تطبيق درجة ضبط، أيضا سوف يجعل لم قدوم profile وجه قرب نفسه مشكلة.

## عاقبة

أساس في base نموذج طلب افتراضي كشف إمساك أخذ schema و prompt إشارة جذب، يشمل ACP تلقائي تحويل و فقط صف خروج `dsh-base` ذاتي تعريف profile. تلقي حد نشر يجب صريح إغلاق.Headless،SDK و ACP يمكن مشترك نفسه نموذج header snapshot مصدر، تجمع تركيز حقيقي profile اختبار سوف ثابت مع مرفق أداة تجميع دمج.
