# Agent Note: TUI إخفاء نمط يأخذ واحد جولة assistant خطوة طي لـ واحد بند رسالة

Status: implemented
Archived: 2026-08-04

[English](2026-07-29-tui-hidden-mode-assistant-fold.md) | العربية

## مشكلة

Ctrl+O إخفاء مرحلة مقطع ([كامل دمج TUI عرض](../architecture/2026-07-28-consolidated-tui-presentation.md)) ذهاب إسقاط أداة بطاقة، يجعل transcript(نص سجل) قراءة عمل واحد مقطع محادثة، لكن كل نموذج خطوة ما زال تصيير ذاتي ذات `Assistant` عنوان. لذلك واحد كثير خطوة جولة (نص → أداة → نص) سوف عرض كثير عدد وصل متابعة، بين فارغ بلا واحد شيء `Assistant` منطقة كتلة——يتم إزالة أداة بطاقة صحيح هو تكرار عنوان سبق مرور وحيد إدارة من.Codex ريح إطار صاف محادثة قراءة قراءة حاجة كل جولة واحد بند assistant رسالة.

## قرار

إخفاء نمط معا أيضا هو واحد بند طي قاعدة، كما صاف خالص بصفة TUI عرض تنفيذ: في كل جولة داخل، رقم واحد تصيير محتوى مرئي (لديه نص، أو في reasoning عرض فتح بدء وقت لديه reasoning) خطوة يملك هذا جولة وحيد `Assistant` عنوان؛ ذلك بقية خطوة تصيير لـ بلا عنوان متابعة مقطع، لا يوجد مرئي متن خطوة فإن تماما لا تصيير——فقط لديه أداة استدعاء خطوة حيث لا احتلال استخدام عنوان، أيضا لا إبقاء تحت فارغ أبيض مقطع. طي و توسيع مرحلة مقطع إبقاء كل خطوة كل منها عنوان؛ مغادرة فتح إخفاء مرحلة مقطع سوف استعادة هو جمع.

آلية:`StreamingAssistantComponent` يحمل ذاتي ذات `StepPosition` و واحد `setFoldedContinuation` عرض علامة سجل؛`createTuiChat` صيانة كل جولة خطوة مكون قائمة، و في Ctrl+O، كل تدفق صيغة text/reasoning chunk، رسالة تسوية، و فشل تدفق يتم سحب عودة (ممكن يأخذ عنوان نقل تسليم إعطاء تحت واحد خطوة) وقت إعادة دفع توجيه طي.transcript إعادة بناء سوف صاف فارغ هذا خريطة و إعادة وضع سجل، لذلك استعادة، ضغط استبدال، ضبط كامل مقياس قياس و رئيسي عنوان تبديل استلام جمع إلى نفس طي نتيجة. خطوة حساب وقت صفحة قدم إبقاء حسب خطوة ملكية، لا تلقي أثر.

## اعتبار مرور بديل خطة

- **يأخذ كثير عدد خطوة دمج لـ واحد مكون**——و حسب خطوة تدفق صيغة دورة الحياة، إعادة محاولة سحب عودة و حساب وقت صفحة قدم اندفاع مفاجئ؛ في قائم مكون فوق إضافة علامة سجل فقط تغيير عنوان و قبل توجيه بين مسافة.
- **في جلسة سجل أو `deriveMessages` في طي**——لـ واحد نوع UI قراءة قراءة نمط تغيير حمل دائم / نموذج مرئي تاريخ؛ سجل إبقاء حسب خطوة شكل حالة.
- **كل مرئي صفة مرحلة مقطع كل طي**——طي / توسيع مرحلة مقطع في خطوة بين اختراق إدراج أداة بطاقة، هذا وقت كل خطوة عنوان استخدام قدوم تخطيط قسم أي مقطع إخراج يخص أي عدد خطوة.

## عاقبة

إخفاء نمط الآن كل جولة قراءة عمل واحد بند assistant رسالة؛ جولة بين ما زال من كل منها عنوان قسم فصل. طي هو إعادة حساب حساب حالة، من لا تخزين، لذلك جلسة و حفظ دائم صيغة لا يوجد تغير. تغطية:TUI اختبار وحدة تغطية Ctrl+O حلقة عنوان حساب عدد، فقط أداة أول خطوة عنوان نقل تسليم، حسب جولة قسم فصل، و فوري تدفق صيغة + إعادة بناء استلام جمع؛ بلا مفتاح لقطة `tool-cards-hidden-folded` ثابت طي بعد لقطة.
