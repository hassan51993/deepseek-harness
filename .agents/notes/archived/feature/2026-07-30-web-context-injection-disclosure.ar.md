# Agent Note: Web سياق حقن توسيع بند

Status: implemented
Archived: 2026-08-07

[English](2026-07-30-web-context-injection-disclosure.md) | العربية

## مشكلة

Web جلسة أصل هذا عبر عام `JsonBlock` تصيير كل بند قد سجل غير مستخدم رسالة. هذا نوع عرض استخدام نص ثلاثة زاوية رمز رقم، ضيق تجميع وسم حرف جسم، لديه حافة إطار JSON وجه لوح و آخر طقم بين مسافة، لذلك سياق حقن و منتج تصميم في Tool calls توسيع بند لا متسق. تعديل عام أصل لغة مثال صيغة أيضا سوف أثر لم معرفة حدث و مرفق عنصر التقاط قاع عرض.

## قرار

`MessageItem` سوف سياق عقدة توجيه حتى `ContextInjectionRow`. هذا سطر ابتدائي طي، عنوان لـ `سياق حقن`، استخدام قائم تصفح تصفح رسم علامة، و جعل كامل 24px عنوان شريط يصبح يمكن عبر إشارة إبرة و مفتاح قرص عملية توسيع هدف. ذلك توسيع رئيسي جسم من عنوان شريط تحت جهة 4px موضع بدء، و مشترك استخدام 22px محتوى تقليص دخول مقابل متساو، و تصيير تصميم قاعدة تحديد 141px تمرير منطقة؛ تمرير منطقة اعتماد 8px دائرة زاوية، شفرة كتلة خلف مشهد،11/16 شفرة نص كما بلا حافة إطار.

`ContextInjectionRow` سوف قد سجل `content` و `source` تسلسل تحويل لـ واحد داخل ربط JSON قيمة، في نموذج مرئي محتوى جانب إبقاء مصدر معلومة. عرض محتوى متابعة تلقي قائم 20,000 محرف قطع قطع سياسة قيد. هذا تغيير لا تعديل أي جلسة حدث، وقت التشغيل طي منطق أو سياق توليد إضافة.

حزمة داخلي `DisclosureRow` مسؤول سياق سطر و `ToolRow` مشترك استخدام عنوان شريط بضعة أي، رسم علامة حتى طي سهم رأس مرور عبور، تلقي تحكم فتح حالة، و Enter/Space عملية.`ToolRow` ما زال هو أداة حالة، ملخص، ملف رابط و توسيع بعد أداة رئيسي جسم دلالة owner. كل سياق مصدر مشترك استخدام نفس طقم عرض؛ سياق لن دخول مفتاح تحكم toolview slot، أيضا لن نيل نيل سياق مخصص استخدام slot.

## تحقق

جلسة مكون اختبار ثابت تحقق ابتدائي طي حالة، تصفح تصفح رسم علامة، كامل سطر إشارة إبرة و مفتاح قرص تبديل، داخل ربط JSON شكل حالة، قطع قطع، و عام لم معرفة حدث تصيير إبقاء ثابت. بلا مفتاح تجميع بعد Web تاريخ مشهد عبر حقيقي Agent API حقن سياق، في ARIA مسبق مدة إخراج في سجل طي سطر، و في Chromium في قياس كمية تصميم قاعدة تحديد رسم علامة، عنوان شريط، تقليص دخول، بين فجوة، تمرير منطقة، داخل حافة مسافة، دائرة زاوية، حرف جسم ترتيب إصدار، لون لون و فيض خروج سلوك.

## اعتبار مرور بديل خطة

**عام إعادة ضبط `JsonBlock` مثال صيغة.** لـ الذي بـ مرفوض: لم معرفة surface حدث و أخرى محتوى كتلة استخدام هذا أصل لغة بصفة مستقل عام التقاط قاع عرض، عام نظر شعور تغيير سوف يأخذ غير متصل عرض اقتران دمج بدء قدوم.

**سوف سياق تصيير لـ read أداة.** لـ الذي بـ مرفوض: مباشر إعادة استخدام `ToolRow` سوف لـ قد سجل غير مستخدم رسالة إضافة خطأ أداة دلالة، حالة و مفتاح تحكم توزيع.

**إضافة جديدة مفتاح تحكم context-view slot.** لـ الذي بـ مرفوض: حالي كل سياق مصدر كل استخدام نفسه عنوان و مصدر معلومة رئيسي جسم، تسجيل seam مؤقت بلا مستهلك. إذا سوف قدوم ظهور من مختلف مصدر يملك عرض، ما زال يمكن في لا أكثر تعديل هذا سطر حال حال تحت إضافة هذا seam.

## عاقبة

سياق حقن و Tool calls اعتماد متسق نظر شعور لغة، معا لا تغيير ذلك حمل دائم حفظ دلالة. مشترك استخدام توسيع بند عنوان شريط يمكن منع توقف هذا اثنان نوع سطر تدريجي تدريجي انحراف مغادرة، بينما مخصص استخدام سياق رئيسي جسم و عام `JsonBlock` ما زال يمكن مستقل عرض دخول. ثابت عال درجة رئيسي جسم بـ لا يمكن مع محتوى تلقائي زيادة عال لـ بديل قيمة، لـ transcript(نص سجل) صيانة حمل مستقر ترتيب إصدار عقدة عزف؛ فحص نظر مقارنة طويل حقن إشارة أمر وقت يجب تمرير.
