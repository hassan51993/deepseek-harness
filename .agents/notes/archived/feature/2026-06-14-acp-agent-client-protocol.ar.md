# Agent Note: Agent Client Protocol(ACP) دعم حمل——من خارجي تحرير جهاز قيادة تحرير رمز agent

Status: implemented
Archived: 2026-07-26

[English](2026-06-14-acp-agent-client-protocol.md) | العربية

> قد يتم [ACP بصفة فقط موجه إلى تلقائي تحويل بروتوكول](../simplification/2026-07-23-acp-automation-only-protocol.md) يحل محل. هذا Agent Note سجل قد تراجع دور موجه إلى تحرير جهاز جسر وصل طبقة تصميم.

## مشكلة

harness الأكثر أول فقط عبر readline حلقة كشف agent. هذا واجهة قدرة نقل نص، لكن تحرير جهاز لا يمكن بـ بنية تحويل طريقة إنشاء أو استعادة جلسة، صلة ربط نص التوجيه إتمام، تدفق صيغة إخراج دفع إدارة (reasoning) و أداة نشط حركة، تصيير أداة مخصص تابع UI، طلب إذن، أو في لا جاف إزعاج أخرى محادثة قبل رفع تحت إلغاء بعض عدد محادثة.ACP(Agent Client Protocol) سوف هذه تفاعل تعريف لـ أساس في stdio JSON-RPC،Zed هو لأجل فعل خروج أداة جسم توافق صفة قرار هدف عميل.

جسر وصل طبقة يجب إبقاء harness قائم كل حق حد. هو لا يستطيع اعتماد أداة جسم agent loop(ذكي جسم حلقة) ، لا يستطيع التفاف مرور أداة سجل التسجيل، لا يستطيع في تحرير جهاز في تنفيذ shell أمر، أيضا لا يستطيع إرسال واضح ثاني عدد جلسة حق مصدر.stdout معا أيضا هو بروتوكول نقل عبر طريق، لذلك أي معنى خارج سجل إخراج كل سوف كسر تالف اتصال.

## قرار

`@deepseek-ai/dsh-acp` سبق هو `ui` حزمة مجموعة في UI/عميل قيادة إضافة (الآن يقع في `acp`). هو استخدام `@agentclientprotocol/sdk` `AgentSideConnection`(أساس في stdin/stdout) ، فقط تحرير ترتيب واجهة خدمة:agent إنشاء/استعادة عمل مصنع، جلسة حفظ دائم، أداة سجل التسجيل، مستخدم تفاعل، و اختياري مراجعة دفعة/bash قدرة. هو لا تعديل agent loop، أيضا لا هو قدرة seam تنفيذ.

جسر وصل طبقة تنفيذ التالي مستقر جلسة مسار:

- `initialize` تنسيق تجارة بروتوكول إصدار، إعلان دعم حمل text و `resource_link` نوع نص التوجيه، و إعلان `loadSession` قدرة.
- `session/new` تحقق قطعا مقابل مسار `cwd`، سوف ذلك تخزين دخول `SessionHeader`، عبر `ctx.agents` إنشاء agent، و إرجاع من تركيب طبقة دعم حمل إعداد خيار.
- `session/load` في بنية صنع agent قبل تحقق طلب cwd و حفظ دائم بيانات وصفية هل متسق، في مختلف خطوة استعادة خلال إبقاء id، سوف مستخدم/مساعدة يد/أداة حدث بصفة ACP update إعادة تشغيل، و تقرير إبلاغ استعادة بعد config-option طي نتيجة.
- `session/prompt` قبول نص و resource link، رفض لا دعم حمل أو فارغ محتوى، كل جلسة معا فقط سماح واحد in-flight نص التوجيه، و في هذا نص التوجيه الذي تابع `turn/end` وقت تسوية. خطأ جولة رفض RPC؛ أخرى إغلاق جولة سبب عبر واحد كل تغطية ACP stop-reason تحرير حل رمز جهاز خريطة.
- `session/cancel` استدعاء طابور صف شعور معرفة agent إلغاء مسار، فقط تسوية يتم بحث عنوان جلسة نص التوجيه.

أداة استدعاء عرض ما زال من أداة ذاته مسؤول. أداة `presentCall` و `presentResult` إرجاع `generic`،`terminal` أو `diff` تصيير معنى رسم تغيير جسم؛ جسر وصل طبقة مقابل هذا ربط دمج نوع فعل switch و خريطة إلى ACP. لا يوجد presenter أداة نيل نيل عام رجوع.Bash طرفية بطاقة استخدام Zed قدرة باب تحكم اتفاق `_meta.terminal_info`،`_meta.terminal_output` و `_meta.terminal_exit`؛harness ما زال عبر `ctx.bash` تنفيذ أمر، إبقاء صندوق رملي، بيئة صاف غسل، كل حق و cwd. لا دعم حمل هذا توسيع عميل استلام إلى عادي نص محتوى. نظام الملفات أداة توفير diff بطاقة و ملف موضع، جسر وصل طبقة في بلا حاجة صلب تحرير رمز أداة اسم فرع.

إذن معالجة هو[مستخدم مراجعة دفعة seam](2026-07-06-approval-seam.md) فوق واحد answerer، بينما غير ACP في «كل مرة أداة استدعاء كل استفسار سؤال» سياسة. مقابل جسر وصل طبقة الذي تابع agent كما حمل لديه call id `approval/request`، سوف تغيير لـ هذا agent تحرير جهاز جلسة فوق `session/request_permission`، توفير مرة صفة سماح/رفض خيار. خارجي طلب أو بلا call id طلب تفويض حمل إعطاء تحت تنقل؛ ناقص أو فشل answerer سوف في لذا عائق وقت إبقاء رفض. إرسال بدء استفسار سؤال إضافة (مثل مسبق تنفيذ سياسة أو bash ترقية) يملك «هل استفسار سؤال» قرار حق.

عند `ctx.permission` يتم تركيب وقت، جسر وصل طبقة من نشر مسبق ضبط جدول في كشف واحد `permission` select. قد إصدار `workspace-write` و `danger-full-access` مسبق ضبط كل منها ربط ربط واحد صندوق رملي نمط و واحد بند مراجعة دفعة سياسة؛ لا يمكن مطابقة صالح دوران زر تركيب إنتاج فقط قدرة قطع مشي `custom` حالة.`session/set_config_option` عبر `PermissionService.set()` تحقق و كتابة اثنان عدد الذي تابع دوران زر حدث. في فتح وضع جولة في تبديل قيام أي إلحاق؛ فارغ خامل وقت تبديل تراكم إضافة في استجابة في، و في تحت مرة `agent/prompt-submit` وقت مرساة تحديد إلى فتح وضع جولة قبل طلب تجميع مرحلة مقطع. في هذا قبل هو فقط تخزين في داخل تخزين، لذلك انهيار انهيار بعد استعادة هو حفظ دائم طي نتيجة.ACP session mode لا يتم بناء نموذج، لأن config option هو موجه إلى لم قدوم بروتوكول جدول وجه؛`AcpConfig.model` إبقاء اتصال درجة آخر.

جسر وصل طبقة أيضا توفير أساس في ACP `UserInteractionProvider`:`ask_user_question` طلب تغيير لـ الذي تابع جلسة فوق جدول مفرد جذب توجيه.select،multi-select، خيار وصف و ذاتي تعريف عودة جواب تغطية دلالة متساو يتم إبقاء.

دورة الحياة كل حق هو صريح. جسر وصل طبقة لـ كل نشط وثب جلسة يحتفظ واحد `AgentHandle`. قطع وصل و Cordis dispose(مورد تحرير) سوف إلغاء انتظار معالجة نص التوجيه، و سطر dispose كل handle، انتظار حلقة تماما توقف مستقر و حفظ دائم تحديث كتابة، لكن بعد إزالة سجل. تدفق إشعار فشل يتم عزل، لذلك إزالة فقد عميل لن كسر تالف agent جولة.ACP تطبيق تركيب لا تحميل stdout logger؛ واحد اختبار حراسة حماية stdout فقط يتضمن لقطة تحويل JSON-RPC.

حالي بروتوكول عقد نحو رؤية [`dsh-acp` حزمة README](../../../../packages/acp/acp/README.md).

## سبق اعتبار بديل خطة

**في `tools/execute` مستمع قبل وضع واحد طبقة، مقابل كل ACP الذي تابع استدعاء كل استفسار سؤال إذن**: مرفوض. هذا سوف سوف إذن سياسة صلب تحرير رمز إلى UI جسر وصل طبقة، أي جعل لا يوجد سياسة اشتراط أيضا سوف استفسار سؤال، كما لا يمكن خدمة في تنفيذ بدء بعد عندئذ إنتاج مراجعة دفعة طلب. مشترك user-approval seam سوف آلية، استفسار سؤال سياسة و UI answerer قسم مغادرة.

**حقن أداة جسم `agentLoop`**: مرفوض.agent إنشاء، استعادة، فارغ خامل مراقبة و تحرير هو `dsh-agent` فوق واجهة درجة كل حق عملية؛UI إضافة لا حاجة اعتماد قاعدة مثال خارج.

**عبر ACP `terminal/*` تنفيذ bash**: مرفوض. هذا سوف سوف تنفيذ نقل إلى harness خارج، التفاف مرور ذلك صندوق رملي، سند إثبات صاف غسل، مهمة كل حق،cwd تحليل و جلسة سجل. طرفية بيانات وصفية فقط لأجل عرض.

**سوف إذن مسبق ضبط يمثل لـ ACP session mode**: مرفوض. نشر تعريف مسبق ضبط قد هو واحد config-option select، بينما session mode هو ACP v2 حساب تخطيط إزالة متروك إبقاء واجهة.

**منع صد صفة خطف حمل stdout**: مرفوض. عملية درجة monkey-patching تجاوز خروج Cordis فرعي أثر كل حق نطاق، كما و بروتوكول نقل وجود تنافس تنازع. تطبيق تركيب يملك stdout صاف صاف صفة.

## عاقبة

تحرير جهاز يمكن عبر واحد بند ACP اتصال إنشاء، تحميل، إيداع نص التوجيه، إلغاء، تصيير، استفسار سؤال و إعادة إعداد كثير عدد harness جلسة، بلا حاجة اعتماد خاص تحديد حلقة تنفيذ. جلسة حدث سجل ما زال هو إعادة تشغيل، نص التوجيه تسوية،cwd و كل جلسة إعداد حمل دائم حق مصدر. أداة عرض و شخص عمل عودة جواب عبر طريق ما زال هو يمكن توسيع إضافة عقد نحو، بينما غير ACP مخصص تابع سلوك.

جسر وصل طبقة متعمد لا تنفيذ جلسة قائمة/حذف/استعادة/إغلاق قدرة،MCP نفاذ نقل، مرفق إضافة دليل، صورة/صوت تردد/تضمين دخول مورد نص التوجيه،plan، مائل عمود أمر، استخدام كمية تحديث، تحرير جهاز نظام الملفات تفويض حمل أو ACP طرفية تنفيذ فرعي بروتوكول. لاحق قد عبر معيار جلسة إعداد خيار إضافة دخول وقت التشغيل نموذج اختيار، رؤية [LLM دليل و ACP اختيار Agent Note](../architecture/2026-07-15-llm-model-catalog-and-acp-selection.md).

فارغ خامل وقت إعداد اختيار في فوري استجابة في هو حقيقي، لكن في تحت مرة `agent/prompt-submit` سوف ذلك مرساة تحديد إلى فتح وضع جولة قبل لا أداة حمل دائم صفة. في هذا حد قبل انهيار انهيار سوف فقد فقد انتظار تحديد اختيار؛ هذا هو إبقاء جلسة حدث غلاف إغلاق في جولة داخل كما إعادة تشغيل أمان بديل قيمة.

## تحقق

ACP اختبار طقم عنصر تغطية داخل تخزين بروتوكول تحرير حل رمز جهاز، إنشاء/تحميل إعادة تشغيل، دقيق نص التوجيه تسوية، إلغاء تنافس تنازع، لا دعم حمل محتوى، أداة عرض، طرفية قدرة رجوع، إذن نتيجة خريطة،config-option تحقق و حفظ دائم، كثير جلسة عزل، قطع وصل/تحرير بعد تماما توقف مستقر، و HMR(حار وحدة استبدال) تنظيف. لقطة اختبار و built-bin اختبار تحقق تطبيق تركيب، حقيقي API e2e اختبار في بلا key وقت تلقائي قفز مرور.
