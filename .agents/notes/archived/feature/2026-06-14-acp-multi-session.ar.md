# Agent Note: في مفرد عدد اتصال فوق كثير مسار إعادة استخدام تزامن ACP جلسة

Status: implemented
Archived: 2026-09-04

[English](2026-06-14-acp-multi-session.md) | العربية

> هذا Agent Note كتابة في ACP أيضا هو تحرير جهاز جسر وصل طبقة وقت مدة، حركة آلة قدوم ذاتي Zed كثير جلسة عميل نموذج.[ACP بصفة فقط موجه إلى تلقائي تحويل بروتوكول](../simplification/2026-07-23-acp-automation-only-protocol.ar.md) إزالة تحرير جهاز واجهة؛ كثير مسار إعادة استخدام قرار ذاته ثابت، هذا Agent Note الآن اعتماد وفق تلقائي تحويل اتفاق قديم وصف هو.

## مشكلة

واحد ACP(Agent Client Protocol) تلقائي تحويل عميل يمكن في نفس عدد agent(ذكي جسم) عملية فرعية فوق إبقاء كثير عدد محادثة. إذا جسر وصل طبقة فقط دعم حمل مفرد نشط وثب جلسة، حينئذ لا نيل لا بدء مقدار خارج عملية، أيضا سوف منع توقف واحد أب تحكم جهاز عبر واحد بند اتصال قيادة كثير عدد مستقل فرعي مهمة. كثير مسار إعادة استخدام جذب دخول عزل ريح خطر: قد إيداع عودة جواب، نص التوجيه إتمام، إلغاء، إذن طلب و يمكن مسبق قياس خلفية job id أبدا قدرة عبر تجاوز جلسة حد.

## قرار

ACP جسر وصل طبقة سوف نشط وثب جلسة تخزين في `Map<SessionId, AcpSession>` في.agent أثر مجال عودة ضبط استخدام `ownedRecord`: في صحيح نحو map في فحص بحث `agent.session.id`، كما فقط عند هذا وحدة يملك دقيق agent كائن وقت عندئذ وصل قبول هو، جعل خارجي نفس id كائن لا يمكن خطر قيادة جلسة. وحدة يملك Agent handle،MCP تركيب، نموذج اختيار، لديه ترتيب تحديث، تسجيل ذاكرة تحويل إغلاق، و اختياري إجراء في نص التوجيه و نهائي تسوية هو حمل دائم جولة رقم. جلسة header يملك ذلك cwd؛ جسر وصل طبقة لا إبقاء مستو سطر مساحة العمل أو عميل قدرة حالة.

كل `session/event` عودة ضبط في إرسال أو تسوية أي محتوى قبل، أولا تحليل خروج الذي تابع سجل. كل جلسة مستقل سماح واحد إجراء في نص التوجيه. نص التوجيه التقاط ذاتي ذات مصدر ذاتي مستخدم رسالة `turn/start`، و فقط في مطابقة `turn/end` وصول وقت تسوية؛ حقن جولة، إضافة أو goal ذاتي رئيسي جولة، و قدوم ذاتي قد إلغاء قبل واحد جولة متأخر إلى end كل لا يستطيع resolve هو.`session/cancel` تحديد موضع إلى واحد بند سجل، فقط استدعاء هذا agent طابور صف شعور معرفة إلغاء مسار.

إذن ملكية استخدام مقابل صحيح نحو map نفس دقيق agent فحص.ACP `approval/request` ينبغي جواب جهاز فقط لـ يملك إرسال بدء طلب agent جلسة إرسال مرة صفة آلة جهاز سياسة طلب، و سوف خارجي طلب أو لا حمل call id طلب تفويض حمل خروج ذهاب. جسر وصل طبقة لا يوجد جدول مفرد جذب توجيه، إعداد اختيار أو أخرى شخص آلة تفاعل حالة.

خلفية bash مهمة يحمل واحد لا نفاذ واضح owner token، ذلك قيمة انتظار في الذي تابع جلسة id.`job_output` و `job_kill` في قراءة أو إنهاء قبل، سوف استدعاء جهة token و منفذ مهمة ملكية إجراء مقارنة مقارنة؛ فقط سند يمكن مسبق قياس job id لا يستطيع نيل نيل وصول حق. ملكية معلومة و منفذ مهمة واحد بدء تخزين، لذلك أداة إضافة إعادة تحميل لن مسح حذف هو.

تدريجي جلسة إغلاق، اتصال تفكيك حذف و إضافة تحرير مشترك كل `AcpSession` تسجيل ذاكرة تحويل إغلاق. جسر وصل طبقة في حدث و تحديث drain خلال إبقاء نشط وثب map، يأخذ كل انتظار معالجة نص التوجيه تسوية لـ قد إلغاء،drain يمكن متابعة بعد بديل، في جلسة ما زال تركيب وقت flush، و سطر تحرير Agent scope. تأكيد قطع سجل فقط في إغلاق عملية تسوية بعد مغادرة فتح map.

## بروتوكول و مساحة العمل أثر مجال

[ACP v1 واضح سماح واحد اتصال فوق وجود كثير عدد تزامن جلسة](https://github.com/agentclientprotocol/agent-client-protocol/blob/01beb5fb5eec60e9f516a80d85eb03594bac61e3/docs/get-started/architecture.mdx#L16-L24) ، كل جديد جلسة كل يحمل ذاتي ذات رئيسي `cwd`. هذا جسر تنفيذ هذا جلسة درجة كثير مسار إعادة استخدام، منها يشمل[حسب جلسة cwd قرار](../architecture/2026-07-02-fs-per-session-cwd.ar.md) الذي سجل مختلف رئيسي مساحة العمل؛ هو لن لـ كل جلسة إنشاء واحد agent عملية فرعية.

واحد جلسة داخلي كثير أصل مشروع هو آخر بند اختياري قدرة:ACP يأخذ[صالح أصل دليل تعريف لـ رئيسي `cwd` إضافة `additionalDirectories`](https://github.com/agentclientprotocol/agent-client-protocol/blob/01beb5fb5eec60e9f516a80d85eb03594bac61e3/docs/protocol/v1/session-setup.mdx#L313-L367). تلقائي تحويل جسر وصل طبقة لا عام نشر أي كثير أصل قدرة، و رفض غير فارغ `additionalDirectories`؛ مثل[حزمة اتفاق](../../../../packages/acp/acp/README.ar.md#standard-acp-v1-surface) الذي سجل، كل جلسة تماما جيد لديه واحد مساحة العمل.

[معيار نقل هو كل stdio اتصال واحد agent عملية فرعية](https://github.com/agentclientprotocol/agent-client-protocol/blob/01beb5fb5eec60e9f516a80d85eb03594bac61e3/docs/protocol/v1/transports.mdx#L17-L42) ؛ كثير عدد اتصال لذلك حاجة كثير عدد عملية فرعية أو ذاتي تعريف نقل، بينما هذا قرار حفظ إثبات هو واحد اتصال داخلي وجود كثير عدد جلسة. في هذا اتصال داخل،`ctx.sandboxPolicy` يأخذ كل جلسة `cwd` تحليل لـ ذلك ذاتي ذات `workspace-write` أصل دليل، لذلك مشترك bash و نظام الملفات خدمة يمكن خدمة تزامن مشروع بينما لا منح إعطاء عبر مشروع كتابة. هذا لن إضافة ACP `additionalDirectories`؛ هو فقط هو من قد دعم حمل «كل جلسة واحد رئيسي أصل دليل» مسار في إزالة عملية درجة أصل دليل حد.

## سبق اعتبار بديل خطة

**كل اتصال مفرد نشط وثب جلسة**: مرفوض. زيادة عملية فتح إلغاء، و منع توقف برنامج تحويل أب تحكم جهاز كثير مسار إعادة استخدام يمكن مستقل إلغاء عمل.

**كل جلسة `ctx.extend()`**: مرفوض. فرعي سياق ذاته لن إنشاء فرعي إضافة fiber، لذلك مستمع ما زال يخص جسر وصل طبقة fiber. فعلي تنفيذ جسر وصل طبقة استخدام عام مستمع إضافة صريح O(1) حل إعادة استخدام، و كل جلسة يملك سجل؛agent دورة الحياة من `AgentHandle` إدارة.

**بـ agent كائن معرف بصفة bash مهمة ملكية**: مرفوض. استعادة أو استبدال بعد agent كائن ممكن دمج قاعدة أرض بديل جدول نفس عدد حمل دائم جلسة. لا نفاذ واضح جلسة token عندئذ هو عبر حد معرف، ينبغي عند في إضافة إعادة تحميل بعد ما زال تخزين نشط.

## عاقبة

N عدد جلسة يمكن تزامن أرض إرجاع قد إيداع عودة جواب، إيداع نص التوجيه، طلب إذن و تشغيل خلفية مهمة، بينما لن تسليم خطأ أو عبر جلسة تسوية. واحد جلسة في إلغاء لا أثر متبادل مجاور جلسة. جسر وصل طبقة لـ هذا دفع خروج صريح map و عزل اختبار بديل قيمة، لكن هو لن لـ كل جلسة إضافة واحد مجموعة مستمع، من بينما تجنب تجنب طويل اتصال خلال مستمع مروحة خروج.

معيار `session/close` سوف مستقل توقف مستقر واحد نشط وثب جلسة، و إبقاء ذلك يمكن استعادة حمل دائم حالة.`session/list` حذف نشط حركة سجل،`session/resume` رفض ما زال تخزين نشط id، لذلك تلقائي تحويل عميل لا يستطيع لـ نفس حمل دائم جلسة إنشاء اثنان عدد Agent كائن.

## تحقق

كثير جلسة اختبار طقم عنصر عبر حسب توجيه إلقاء تمرير قد إيداع عودة جواب، مستقل إجراء في نص التوجيه، تحديد نحو إلغاء و مشترك تفكيك حذف قدوم قيادة تزامن جلسة؛ مراجعة دفعة و إخراج حد طقم عنصر تغطية إذن توجيه و مقابل غير نفس agent كائن رفض. أداة bash اختبار إثبات واحد جلسة لا يمكن قراءة أو إنهاء آخر عدد جلسة خلفية مهمة.
