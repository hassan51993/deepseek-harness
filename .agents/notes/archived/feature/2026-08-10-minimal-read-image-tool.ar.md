# Agent Note: أساس في قائم seam الأكثر صغير read_image أداة

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-minimal-read-image-tool.md) | العربية

## مشكلة

كثير نموذج حالة مرفق عنصر عمل لـ مستخدم فوق نقل بناء قيام كامل حمل دائم مسار، لكن نموذج لا يمكن فحص نظر مغناطيس قرص صورة.`read` حسب اتفاق رفض اثنان دخول صنع محتوى، لذلك يتم سؤال إلى قطع رسم أو تصيير رسم جدول agent يلزم ما فشل، يلزم ما استخدام لديه ضرر تغيير عبر طريقة.PR #598 مستقل محاولة تجربة يأخذ أداة و حلقة درجة توجيه أثر مجال، حسب توجيه تحكم schema مرئي صفة و جديد جلسة سجل عام فكرة وضع في واحد بدء. هذه قدرة لا هو إصدار واحد بند حمل صورة كما قد سجل أداة نتيجة الذي مطلوب.

## قرار

اثنان عدد صورة قراءة عملية كل وضع في `dsh-tool-fs`، عبر قائم نقطة توسيع إصدار عادي حمل دائم أداة نتيجة.

- **`read_image` قراءة نظام الملفات مسار.** توسيع اسم اختيار إعلان PNG/JPEG/WebP/GIF وسيط جسم نوع، مرفق عنصر تخزين سحر عدد و مثل عنصر تحقق إبقاء مرجعي. بايت امتداد `ctx.fs.stat` → محدود `ctx.fs.readBytes` → `ctx.attachments.saveImage` → `fs/observed` تدفق حركة. أداة نتيجة يتضمن بيانات وصفية و واحد `ImageBlock`.
- **`FileSystem.readBytes(target, signal, maxBytes)`** هو جديد لا بد تجهيز مزود أصل لغة: بايت حد أعلى وضع في seam فوق، أي خلفية كل لا يمكن بلا حد مؤقت اندفاع ملف؛stat كبير صغير أولا قصير مسار، مع بعد تدفق الأكثر كثير كثير قراءة واحد بايت بـ منع stat بعد زيادة طويل (`FS_TOO_LARGE`).
- **تسجيل مع تركيب شرط تركيب، تنفيذ حسب توجيه بوابة.** أداة فقط في `ctx.inject(['attachments'], …)` أثر مجال داخل تسجيل. تنفيذ وقت في I/O قبل عبر `ctx.llm.resolveModelInfo` تحليل استدعاء توجيه، و اشتراط `inputModalities` يتضمن `image`؛ قدرة لم معرفة أي رفض. صاف نص توجيه ما زال يمكن استخدام هذا قبل حمل دائم صورة، لأن مشترك LLM وقت التشغيل سوف في طلب تجميع وقت يأخذ صورة إسقاط لـ احتلال موضع رمز.
- **PTC mode بـ حمل خارج طريقة تحويل إرسال رسم مثل**: تضمين طقم قسم إرسال إرجاع مواصفة قيمة (فقط حد هذا مرة تنفيذ، لا يحتوي رسم مثل كتلة) ، و تأخير متأخر إيداع واحد بند يحمل معلومة غلاف و رسم مثل `user` زاوية لون سياق رسالة، صورة ما زال سوف وصول تحت مرة طلب.
- **llm-replay نموذج يمكن إعلان `inputModalities`**، لذلك keyless ACP لقطة يمكن تغطية دعم حمل صورة نتيجة و صاف نص رفض.

## اعتبار مرور بديل خطة

- **PR #598 توجيه أثر مجال تصميم**استخدام request-ready نقطة توسيع، حسب توجيه تحكم schema مرئي صفة، يمكن عكس إسقاط و ثلاثة عدد حمل دائم عام فكرة. مشترك LLM طلب إسقاط الآن يمكن معالجة صاف نص توجيه، بلا حاجة يأخذ أداة تسجيل أو جلسة صيغة وضع دخول agent-loop.
- **استخدام `agent.inject()` بديل بديل حمل رسم مثل أداة نتيجة**——يأخذ رسم مثل التفاف مرور أداة نتيجة، بصفة مفرد وحيد حقن مستخدم رسالة. رفض: رسم مثل حينئذ هو أداة نتيجة؛ تفكيك فتح فقط سوف كثير واحد بند بلا استلام فائدة سجل رسالة، بينما أداة نتيجة مسار هذا حينئذ طرف إلى طرف متاح.
- **استخدام سحر عدد شم استكشاف بديل بديل توسيع اسم إعلان**——شم استكشاف تكرار مرفق عنصر تخزين قد يملك فحص قياس (أساس في sharp، مرجعي). توسيع اسم فقط هو إعلان؛ لا مطابقة وقت حسب تعديل اسم إصلاح تلميح فشل إغلاق، بينما لا هو يتم ساكن صامت قبول، هذا أيضا يجعل نموذج مقابل ملف اسم و محتوى مقابل إبقاء صدق فعلي. هذا واحد رفض تغطية حمل توسيع اسم مسار؛[بلا توسيع اسم صورة مسار](../bug-fix/2026-08-28-read-image-extensionless-paths.ar.md) سوف ذلك استلام ضيق، ماذا أيضا لا إعلان مسار حسب ملف توقيع تعرف آخر.
- **بلا شرط تسجيل، نقص تخزين وقت تنفيذ تقرير خطأ**——رفض؛ لا يوجد مرفق عنصر تخزين نشر دائم بعيد لا يمكن ممتلئ كاف هذا أداة، ذلك schema سوف هو معتاد حالة كذب قول. متبادل عكس، توجيه بوابة هو تدريجي استدعاء حالة، صحيح تأكيد موضع حينئذ هو تنفيذ حد.

## عاقبة

- أداة في صاف نص توجيه فوق رفض تنفيذ، بينما جلسة تاريخ في قد وجود صورة سوف من طلب مدة احتلال موضع رمز يمثل.
- تكرار صورة نتيجة سوف تراكم تراكم طلب صار هذا، مباشر إلى طلب إسقاط أو ضغط سوف ذلك إزالة؛ محتوى بحث عنوان فقط ذهاب إعادة حمل دائم بايت.
- أداة نتيجة بطاقة الآن مرور من متصفح `tool.call.images` مجرى موضع تصيير رسم مثل ذاته (رؤية [tool-card image results قلم تسجيل](2026-08-20-tool-card-image-results.ar.md)) ؛ لم تركيب مرفق عنصر عرض إضافة UI عرض نتيجة معلومة غلاف نص.
