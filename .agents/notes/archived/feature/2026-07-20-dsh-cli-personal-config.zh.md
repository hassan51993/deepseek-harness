# Agent Note: dsh CLI و قدوم ذاتي Harness home عدد شخص إعداد overlay

Status: implemented
Archived: 2026-09-04

[English](2026-07-20-dsh-cli-personal-config.md) | العربية

## مشكلة

تطوير من ذاتي ذات انحراف جيد——TUI استخدام أي عدد مزود و نموذج، عدد شخص سند إثبات، خاص مهايئ توجيه——حذف تعديل قد إيداع ملف خارج بلا موضع أمان وضع. يلزم يأخذ TUI عرض مثال إشارة نحو عدد شخص Anthropic بديل إدارة Opus توجيه، فقط قدرة في مساحة العمل داخل تعديل `examples/tui-agent/cordis.yml` و `.env`، قائم إيداع مفتاح ريح خطر، أيضا يلزم في كل checkout داخل تكرار واحد مرة. أيضا لا يوجد يمكن تثبيت أمر: تفكير في مهمة معنى مشروع دليل داخل تشغيل هذا عدد agent(ذكي جسم) ، يجب عودة إلى مستودع أصل دليل استدعاء عرض مثال نص برمجي.Loader بيانات وصفية هو ساكن حالة——بند `disabled` حقل حذف خارج (رؤية [loader `disabled` إدراج قيمة قرار](../architecture/2026-08-11-loader-entry-disabled-interpolation.zh.md))——الذي بـ «شرط تركيب استخدام overlay»(AGENTS.md) ؛ لكن overlay هذا قبل فقط بـ قد إيداع نفس درجة ملف شكل صيغة وجود، لا يوجد آلة جهاز درجة طبقة.

## قرار

تحت نص كل مدخل نمط، و عدد شخص ملف اسم و موضع، قد يتم [profile إضافة تركيب حزمة قرار](../architecture/2026-08-05-profile-plugin-bundles.zh.md) يحل محل:`dsh` بدء profile، عدد شخص طبقة تغيير صار تدريجي profile و home درجة `cordis.patch.yml`. إبقاء ثابت هو هذا قلم تسجيل فعلي جودة: بـ Harness home بصفة آلة جهاز درجة طبقة أصل دليل، في مع مرفق تركيب لـ فوق استخدام patch دلالة، و تحليل فشل وقت واضح تقرير خطأ.

اثنان عدد اقتران دمج جزء، و `dsh web` PR(#443) رفع خروج `apps/` تركيب إعداد طبقة مقابل متساو:

**`dsh` CLI(أمر سطر واجهة؛`apps/cli`،npm اسم `@deepseek-ai/dsh`).** `apps/*` هو يقع في `packages/*` مكتبة لـ فوق منتج تجميع طبقة. واحد bin مسؤول توزيع افتراضي تفاعل صيغة TUI،`-p`/`--prompt` بلا رأس جولة و `web` واجهة.TUI بـ استدعاء دليل لـ workspace، بدء `examples/tui-agent/cordis.yml`(أو `--config` إشارة تحديد إعداد). في شفرة المصدر فحص خروج في، أصل دليل `pnpm dsh` نص برمجي لا تنفيذ بناء، مباشر استخدام tsx ESM hook تشغيل نفس مدخل؛ تشغيل طريقة من[شفرة المصدر بدء قرار](../architecture/2026-07-29-dsh-source-launch-tsx-esm.zh.md) قاعدة تحديد، ناتج توليد من[شفرة المصدر بدء و بناء قسم مغادرة قرار](../simplification/2026-08-12-separate-source-launch-from-build.zh.md) قاعدة تحديد.

**عدد شخص إعداد (`dsh-app-boot`).** عدد شخص overlay تخزين وضع في Harness home——`$DSH_HOME`، لا فإن `~/.dsh`——من مشترك [`resolveDshHome`](../architecture/2026-07-24-single-harness-home-resolver.zh.md)(`@deepseek-ai/dsh-home-paths`) تحليل، و skill(تقنية قدرة) ،AGENTS.md تحليل الذي اعتماد حسب مفرد واحد أصل دليل نفسه.dsh TUI،Web و بلا رأس واجهة استخدام منها اثنان عدد اختياري ملف؛ كل عرض مثال bin ما زال تدريجي بايت حسب قد إيداع إعداد شجرة بدء:

- `.env`——في استدعاء دليل `.env` بعد تحميل؛`process.loadEnvFile` من لا تغطية قد لديه قيمة، لذلك أولوية درجة لـ بيئة متغير > مشروع `.env` > عدد شخص `.env`.
- `config.yaml`——قمة طبقة YAML عدد مجموعة، عنصر عنصر لـ `@cordisjs/plugin-include` `PatchOptions`، استخدام include ذاتي ذات `!!js` جهة قول تحليل (`loadPersonalPatches`) و نقل إعطاء `boot()`، من هو بصفة أصل include `patches` تحويل إرسال. رقعة دلالة و تسليم surface overlay متسق: حسب id تحديد موضع رقعة استبدال هذا بند إعداد كامل `config`،`insert` إلحاق بند إعداد، لم مطابقة id ساكن صامت لا تنفيذ أي عملية. خارجي حزمة بصفة [profile تركيب حزمة](../simplification/2026-08-09-remove-repository-plugin.zh.md) تثبيت؛ هذا عدد عدد شخص طبقة مسؤول إعداد هذه تركيب حزمة توفير Loader بند إعداد.
- ملف ناقص أي بلا overlay؛ ملف وجود لكن غير ممكن قراءة، غير ممكن تحليل أو غير عدد مجموعة فإن في بدء وقت رمي خروج (إعداد خطأ سوف واضح تقرير خطأ، أبدا ساكن صامت قفز مرور).

PTY خطر دخان اختبار بدء جهاز يأخذ `$DSH_HOME` عزل إلى كل اختبار ذاتي ذات دليل، و هو قد لديه `DSH_AGENTS_HOME` عزل طريقة تماما متسق، تطوير من حقيقي عدد شخص overlay غير ممكن قدرة تسرب تسرب دخول fixture(اختبار قبل وضع بيانات) ؛ فقط لديه dsh CLI قراءة عدد شخص إعداد، لذلك أخرى اختبار بدء جهاز بلا حاجة تعديل.

TUI و Web بدء بعد عبر Cordis HMR(حار وحدة استبدال) تسجيل تأكيد قطع عدد شخص إعداد مسار. كل مرة إضافة جديدة، تغيير أو إزالة كل سوف بـ أمر خدمة طريقة عبر بدء جهاز ذاتي ذات تركيب إغلاق حزمة إعادة تركيب كامل patch قائمة، لذلك جديد عدد شخص patch سقوط في بدء وقت نفسه طبقة مرة موضع.YAML بلا فاعلية أو Loader مرشح يتم رفض وقت، الأكثر بعد واحد متاح شجرة إبقاء نشط حركة حالة، و واسع بث `hmr/config-update-failed(filename, Error)`؛ بلا رأس واجهة فقط في بدء وقت قراءة هذا ملف.Include في قد إيداع ملف إعداد تحديث جديد وقت أيضا سوف إعادة تطبيق ذلك patch(رؤية[إعداد حار إعادة تحميل متين صفة Agent Note](../bug-fix/2026-07-20-config-hot-reload-resilience.zh.md)).

## اعتبار مرور بديل خطة

**آخر ضبط واحد `bin/dsh` حزمة تركيب نص برمجي و من ذلك احتلال استخدام `dsh` اسم.** مرفوض، لأن `apps/cli` هو موحد واحد منتج CLI، مسؤول توزيع افتراضي TUI، بلا رأس و Web واجهة. اثنان عدد متبادل متبادل تنافس تنازع مدخل سوف في `$PATH` و منتج هوية فوق اندفاع مفاجئ.

**pi ريح إطار نوع تحويل ضبط ملف (`defaultProvider`/`defaultModel`/`providers`).** مرفوض، اختيار رقعة دلالة (منتج مسؤول شخص قرار): عدد شخص ملف هو تراكم إضافة في مع مستودع توفير افتراضي إعداد لـ فوق cordis overlay، بينما لا هو حاجة آخر سطر يملك و قلب ترجمة ثاني طقم إعداد مفردات.

**عدد شخص كامل `cordis.yml` ذهاب include طلب إعداد.** مرفوض: عدد شخص ملف سوف لا نيل لا كتابة ميت ورقة فرعي إعداد مسار، بينما هذا مسار مع checkout تغير؛ رقعة عكس تحويل اعتماد جهة نحو،bin ما زال اختيار إعداد شجرة، عدد شخص طبقة فقط فعل إصلاح صحيح.

**يأخذ عدد شخص رقعة عميق دمج دخول بند إعداد إعداد.** مرفوض: سوف جعل رقعة دلالة و قد إيداع overlay و vendor include قسم تقاطع؛ كامل `config` استبدال قد هو صار نص اتفاق.

**استخدام بيئة متغير فتح صلة بديل بديل وجود حكم قطع.** مرفوض: افتراضي إغلاق عدد شخص إعداد دائم بعيد لن يتم استخدام بدء قدوم؛ وجود أي توليد فاعلية إضافة فوق كل اختبار صريح عزل، يجعل فعلي تشغيل نيل نيل overlay، اختبار نيل نيل غلاف إغلاق صفة.

## عاقبة

- قد تثبيت `dsh` أمر يمكن من مهمة معنى دليل تشغيل، شفرة المصدر مستخدم فإن من checkout استدعاء `pnpm dsh`؛ اثنان من كل بلا حاجة تعديل checkout يكفي تطبيق عدد شخص مزود، نموذج، قد تثبيت تركيب حزمة بند إعداد و أخرى Loader بند إعداد. هذا سلوك قد إبرة مقابل عدد شخص Anthropic بديل إدارة و Opus 4.8 طرف إلى طرف تحقق، يشمل مرة bash أداة نحو إرجاع.
- من في حسب id تحديد موضع رقعة استبدال كامل `config`، عدد شخص تغطية يجب تكرار وصف هو إبقاء أساس أساس حقل، و ممكن مع أساس أساس بند إعداد شكل تغير بينما عائم نقل؛ تشخيص يد مقطع هو loader «بند إعداد لم بحث إلى/اسم لا مطابقة» تحذير إبلاغ و [`dsh --dump-config`](../../../../apps/cli/README.zh.md#profiles)(ضرب طبع هذه رقعة دمج صار خروج إعداد شجرة).
- عدد شخص رقعة فقط في يتم بدء ملف ذاته شجرة داخل تحليل id، لذلك تضمين طقم include overlay(PTC mode) لن يتم عدد صفة تحويل؛ هذه ورقة فرعي فعلي تشغيل انتظار قيمة صفة مؤقت مؤقت.
- `dsh-app-boot` اعتماد `js-yaml`، و مباشر استيراد include `!!js` YAML جهة قول (`entryListSchema`) ؛ و `apps/cli` واحد مثال اعتماد `@deepseek-ai/dsh-home-paths` بـ نيل أخذ `resolveDshHome`.
- فقط لديه طويل وقت تشغيل TUI و Web عملية إجراء فوري مراقبة نظر. بلا رأس تلقائي تحويل استخدام تحديد صفة بدء إعداد، خروج وقت لن إبقاء watcher.

## اختبار

`packages/boot/app-boot/tests/user-patches.spec.ts` ثابت تحليل، بدء وقت تطبيق، تأكيد قطع مسار إضافة جديدة، فشل، استعادة، إزالة، الأكثر بعد متاح حالة تراجع، فشل واسع بث و تطبيق ذاتي لديه patch إبقاء.`apps/cli/tests/built-bin.e2e.ts` بدء حقيقي dsh bin و أساس في profile طرف إلى طرف تحقق فوري patch طبقة. اختبار بدء جهاز سوف عزل `$DSH_HOME`، لذلك تطوير من حقيقي overlay لن تسرب تسرب دخول fixture.
