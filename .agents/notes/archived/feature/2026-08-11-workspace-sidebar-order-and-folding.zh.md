# Agent Note: Workspace جانب حافة شريط ترتيب و طي

Status: implemented
Archived: 2026-09-04

[English](2026-08-11-workspace-sidebar-order-and-folding.md) | العربية

## مشكلة

Session جدا كثير Workspace سوف احتلال ممتلئ كامل جانب حافة شريط، يأخذ أخرى Workspace ضغط خروج مرئي نطاق. ضيق تجميع قائمة حاجة محدود افتراضي عال درجة، معا ما زال يلزم توفير وصول كل بند Session واضح مدخل. جانب حافة شريط أيضا حاجة موجه إلى نشط حركة وقت ترتيب، لكن `WorkspaceView.sessionIds` هو حمل دائم يد حركة تسجيل حساب، لا يستطيع يتم Session نشط حركة تعديل كتابة.

Workspace قسم مجموعة ذاته لا يوجد مستخدم يمكن تحكم حمل دائم ترتيب. متصفح أصلي سحب جر أيضا سوف يأخذ قائمة خارج رخو يد حكم لـ رفض، و يأخذ سطر نابض عودة أصل موضع، أي جعل تطبيق ما زال يحتفظ صالح إدراج دخول علامة.Workspace توسيع بعد، إذا فقط حسب مجموعة رأس أمر في، اثنان عدد قسم مجموعة بين نظر شعور حد أيضا لم يعد انتظار في مهمة واحد مجموعة رأس في نقطة.

## قرار

### Workspace ترتيب

Workspace سجل التسجيل يحتفظ حمل دائم `workspaceIds` ترتيب، و توفير اعتماد DOM `insertBefore` دلالة `insertBefore(id, beforeId?)`.Host RPC `workspace.insertBefore` إرجاع كامل قد إيداع ترتيب؛ مفرد صاف ترتيب تغيير عبر `host/workspace-order-changed` دفع إرسال نفس نسخة كامل ترتيب. لم معرفة مصدر أو مرساة نقطة id بـ `workspace-not-found` رفض؛ بـ ذاته لـ مرساة نقطة أو نقل حركة إلى حالي موضع لن كتابة.

عميل مقابل Workspace سحب جر إجراء مرح مراقبة تثبيت. طلب بديل مرة و لقطة بديل مرة حفظ إثبات فقط لديه الأكثر جديد واحد عنصر عودة صوت يمكن استبدال محلي ترتيب، كما تحديث Host لقطة أولوية في قديم استجابة؛ الأكثر جديد طلب يتم رفض وقت سوف استعادة الأكثر قريب واحد نسخة من Host أساس خط، لقطة أو حالي واحد عنصر عودة صوت تأكيد كامل ترتيب. كل مرة نجاح قائمة أساس خط كل سوف استعادة Host ترتيب، لذلك إعادة وصل سوف وصل قبول أخرى موضع إيداع حمل دائم تغيير.

### Session طي و عرض ترتيب

كل Workspace حفظ دائم واحد بند متصفح محلي فتح حالة: إغلاق يمثل صفر بند Session سطر، فتح يمثل الأكثر كثير خمسة بند غير فارغ أبيض سطر، مجددا يأخذ حالي اختيار في فارغ أبيض “جديد جلسة” بصفة واحد بند مؤقت مقدار خارج سطر.**توسيع ذلك بقية**فقط في حالي تركيب خلال عرض ما زال يتم إخفاء بند؛ إغلاق كامل Workspace سوف صاف حذف هذا مؤقت توسيع، لذلك إعادة فتح وقت استعادة لـ محدود طي إسقاط. اختيار Session بحث نتيجة سوف انتظار حالي Workspace stream أخذ نيل كامل Host أساس خط بعد مجددا فتح الذي تابع قسم مجموعة، و كما فقط عند هدف يقع في خمسة سطر طي بعد وقت، عندئذ سوف في حالي تركيب خلال إظهار كشف ذلك بقية إخفاء بند. فقط لديه في مستخدم بعد لم لـ هذا Workspace تخزين واضح حالة وقت، حالي Session الذي في قسم مجموعة عندئذ سوف تلقائي فتح. من Workspace سطر إنشاء Session وقت سوف في بدء Session قبل فتح هدف قسم مجموعة، جعل حالة نقل بث إتمام بعد جديد سطر إبقاء مرئي. حينئذ خيط Workspace أساس خط حدوث تغير بعد، متصفح سوف إزالة أساس خط في لا وجود id توسيع حالة، ترتيب و قد مراقبة ختم الوقت سجل، معا إبقاء Ungrouped و مفرد قائمة تسجيل حساب.

تركيب عرض قائمة مفرد في قسم مجموعة و مفرد قائمة عرض في كل توفير**يد حركة ترتيب ترتيب**و**الأكثر قريب تحديث**، كل تسجيل حساب كل منها يحتفظ واحد نسخة متصفح محلي حمل دائم ترتيب. حقيقي Workspace من `WorkspaceView.sessionIds` ابتدائي تحويل؛Ungrouped و عبر Workspace مفرد قائمة من الأكثر قريب تحديث وقت ترتيب ابتدائي تحويل، كما لا يوجد Host Session تسجيل حساب. دخول الأكثر قريب تحديث وقت سوف تنفيذ مرة كامل وقت ترتيب ترتيب؛ لاحق user prompt أو steer سوف سوف مقابل Session وضع قمة مرة، سحب جر ما زال يمكن تحرير الذي نيل ترتيب. إرجاع يد حركة ترتيب ترتيب سوف إبقاء حالي ترتيب، فقط توقف استخدام لاحق نشط حركة وضع قمة. حقيقي Workspace في يد حركة نمط تحت سحب جر أيضا سوف كتابة Host Session تسجيل حساب، بينما Ungrouped و مفرد قائمة سحب جر و نشط حركة وضع قمة إبقاء في متصفح محلي. مفرد قائمة لا يوجد أب درجة طبقة مرة، لذلك لا عرض فارغ يسار جانب حالة مجرى؛ وجود مرئي حالة وقت ما زال إبقاء هذا مجرى.

إنشاء “جديد جلسة” و اختيار في فارغ أبيض Session وقت، متصفح سوف في ذلك قسم مجموعة تسجيل حساب و مفرد قائمة تسجيل حساب في كل وضع قمة مرة. هذا مرة واضح إنشاء وضع قمة لن دفع دخول `updatedAt`.Session إبقاء فارغ أبيض خلال، قسم مجموعة طي لن يجعل هو احتلال استخدام خمسة بند غير فارغ أبيض سطر إعداد مقدار؛ أول بند نص التوجيه سقوط أرض بعد، هذا سطر استعادة عادي إعداد مقدار، معا لن سحب إلغاء يد حركة نمط تحت سحب جر.

### سحب جر و ضيق تجميع واجهة

Workspace أمر في اختبار استخدام كامل تصيير قسم مجموعة منطقة مقطع، يشمل مرئي Session سطر. قبل واحد قسم مجموعة تحت نصف جزء و بعد واحد قسم مجموعة فوق نصف جزء مشترك نفس بند إدراج دخول حد، إشارة عرض جهاز هو واحد بند حمل لديه متبادل وصل يمين نحو حاد زاوية كما لا أثر تخطيط قطعا مقابل تحديد موضع أفقي خط. شجرة رئيسي جسم تغطية طبقة سوف في تمرير قطع قطع منطقة خارج بـ نفسه سالب انحراف نقل رسم صنع رقم واحد بند حد، لذلك يسار جانب حاد زاوية إبقاء مرئي، قائمة موضع أيضا لن تغيير. طي حالة Session سحب جر حسب تصيير سطر تحديد إدراج دخول حد، يأخذ مصدر سطر وضع في هذا حد موضع كل إخفاء تسجيل حساب عضو قبل، و رفض سوف إخفاء مصدر سطر نتيجة.Workspace أو Session سحب جر خلال، وثيقة درجة `dragover` و `drop` معالج سوف قبول أصلي عملية؛ إذا في Workspace قائمة خارج رخو يد،`dragend` سوف إيداع الأكثر بعد واحد صالح علامة.

بحث في طي وقت هو منطقة رأس عملية، توسيع بعد احتلال حسب عنوان و ذيل جزء عملية فضاء. استعلام مرور صاف حذف أول ذيل فارغ أبيض بعد لـ فارغ وقت، نقر خارجي سوف استلام بدء بحث؛ غير فارغ استعلام فإن سوف إبقاء؛ مسار طريق بحث يد اتجاه ما زال في إجراء خلال، خارجي نقر مستمع إبقاء لم تركيب ([مسار طريق بحث ذاتي أنا استلام بدء](../bug-fix/2026-08-18-rail-search-outside-click-self-dismissal.zh.md)). ضيق تجميع Workspace و Session سطر،24px قاع جزء تدريجي خفي و إلغاء كل Workspace Session عدد كمية مشترك نفس عقدة حذف رأسي نحو فضاء، معا إبقاء تنقل مدخل.

## اعتبار مرور بديل خطة

**يأخذ كل مرة نشط حركة وضع قمة كتابة `Workspace.sessionIds`.** متصفح عرض انحراف جيد سوف في مستخدم كل مرة إيداع نص التوجيه وقت تغطية مشترك Host تسجيل حساب.

**لـ يد حركة ترتيب ترتيب و الأكثر قريب تحديث قسم آخر إبقاء مستقل ترتيب.** تبديل نمط سوف استخدام آخر نسخة ترتيب في قديم موضع استبدال مرئي قائمة، بينما اختيار يد حركة ترتيب ترتيب فقط يمثل لاحق نشط حركة لم يعد نقل حركة بند.

**فتح Workspace وقت بداية نهاية عرض الكل Session.** كبير نوع Workspace ما زال سوف ضغط احتلال أخرى قسم مجموعة؛ فقط تسجيل ذاكرة كامل قسم مجموعة فتح حالة لا يمكن حد ذلك عال درجة.

**حفظ دائم توسيع باق بقية حالة.** جدا دائم بـ بعد إعادة فتح Workspace وقت، هو ممكن معنى خارج احتلال ممتلئ جانب حافة شريط. فقط لديه محدود طي حالة يخص مستقر تنقل انحراف جيد؛ عرض باق بقية بند فقط هو مرة محلي فحص نظر.

**استخدام عدد حرف تحت علامة أو فقط حسب مجموعة رأس أمر في سحب جر.** سحب جر خلال سطر حدوث تغير سوف جعل تحت علامة عائم نقل؛Workspace توسيع وقت، مجموعة رأس في نقطة و مرئي حد لا متسق. مرساة نقطة id و كامل منطقة مقطع بضعة أي في اثنان نوع حال حال تحت كل إبقاء مستقر.

**يجعل متصفح رفض قائمة خارج رخو يد.** تطبيق سوف إيداع الأكثر بعد واحد صالح علامة، بينما متصفح معا بث وضع رفض حركة رسم، شكل صار متبادل متبادل تناقض درع عكس تغذية.

## عاقبة

- Workspace ترتيب عبر Host حمل دائم و مشترك؛ قسم مجموعة طريقة، فتح حالة، كل تسجيل حساب Session عرض ترتيب و استعلام حالة ما زال هو متصفح محلي عرض انحراف جيد.Ungrouped و مفرد قائمة دعم حمل نفسه سحب جر و وضع قمة قاعدة، لكن بسبب لا يوجد مفرد واحد Workspace تسجيل حساب، ذلك ترتيب فقط حفظ في متصفح محلي.
- الأكثر قريب تحديث نمط سوف في دخول وقت تنفيذ كامل وقت ترتيب ترتيب، مع بعد إبقاء يد حركة ضبط كامل، مباشر إلى user prompt أو steer دفع دخول بعض بند Session و سوف ذلك وضع قمة. إرجاع يد حركة ترتيب ترتيب سوف إبقاء كل حالي موضع.
- جديد اختيار في فارغ أبيض “جديد جلسة” سطر سوف في قسم مجموعة و مفرد قائمة ترتيب في كل وضع قمة مرة. قسم مجموعة طي سوف في خمسة بند غير فارغ أبيض سطر خارج مقدار خارج تصيير هذا سطر، مباشر حتى أول بند نص التوجيه سقوط أرض بعد استعادة عادي إعداد مقدار.
- لم تنفيذ واضح**توسيع ذلك بقية**يد اتجاه أو بحث نتيجة تنقل وقت، فتح Workspace الأكثر كثير عرض خمسة بند غير فارغ أبيض Session؛ حالي اختيار في فارغ أبيض “جديد جلسة” يمكن زيادة واحد بند مؤقت سطر. إغلاق قسم مجموعة سوف إعادة وضع مؤقت ذلك بقية بند توسيع حالة.
- Host Session تسجيل حساب متابعة اعتماد[جلسة قائمة تصفح تصفح و Workspace يد حركة ترتيب ترتيب](2026-07-25-session-list-browsing-and-manual-order.zh.md) تأكيد قيام يد حركة ترتيب يحتوي معنى.

## اختبار

مجال و Host اختبار تغطية حمل دائم Workspace نقل حركة، بلا عملية و بلا فاعلية مرساة نقطة، إعادة بدء استعادة، كامل ترتيب RPC استجابة، ترتيب لقطة و كل بند Host stream أساس خط فقط قراءة واحد نسخة Workspace لقطة. وقت التشغيل اختبار تغطية مرح مراقبة ترتيب، لقطة/استجابة أولوية درجة، إعادة تراكم رفض بعد استعادة Host قد تأكيد ترتيب، إعادة وصل أساس خط و New Session هدف أولوية درجة.UI اختبار تغطية خمسة سطر طي، فارغ أبيض سطر إعداد مقدار و إخفاء عدد كمية، عبر إخفاء سطر طي سحب جر مرساة نقطة، مؤقت توسيع إعادة وضع، طي نطاق خارج بحث نتيجة إظهار كشف، ابتدائي و إعادة وصل Workspace أساس خط انتظار،Workspace إزالة بعد تنظيف حمل دائم حالة، إبقاء ترتيب نمط تبديل، مرة صفة الأكثر قريب تحديث و “جديد جلسة” وضع قمة، أول بند نص التوجيه سقوط أرض بعد إبقاء يد حركة سحب جر، متصفح محلي Ungrouped و مفرد قائمة سحب جر حفظ دائم، بلا طبقة درجة مفرد قائمة سطر يسار جانب بين مسافة، حالي عرض علامة، توسيع منطقة مقطع Workspace أمر في، لم قطع قطع رقم واحد بند إدراج دخول حد، قائمة خارج Workspace و Session رخو يد، بحث استلام بدء قاعدة و ضيق تجميع CSS مقياس قياس. حقيقي تركيب Web لقطة ثابت خمسة بند قائم سطر و مؤقت “جديد جلسة” و صف عرض.
