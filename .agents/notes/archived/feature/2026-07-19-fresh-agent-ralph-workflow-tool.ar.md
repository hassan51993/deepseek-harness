# Agent Note: كل جديد agent Ralph سير العمل أداة

Status: implemented
Archived: 2026-09-04

[English](2026-07-19-fresh-agent-ralph-workflow-tool.md) | العربية

## مشكلة

نفس جلسة هدف سوف إبقاء محادثة، يجعل واحد agent(ذكي جسم) حمل متابعة إتمام حمل دائم هدف؛ عام سير العمل أداة فإن يجعل نموذج تحرير كتابة مروحة خروج تحرير ترتيب نص برمجي. اثنان من كل لا هو Ralph نمط: يأخذ نفس هدف عكس تكرار تسليم إعطاء كل جديد عمل من، بـ مشترك مساحة العمل بصفة طويل مدة تسجيل ذاكرة، و كما في كل Round بين فقط نقل تمرير واحد نسخة صغير نوع صريح تسليم وصل، مباشر إلى عمل إتمام أو لمس و حد.

إذا يأخذ Ralph سلوك إضافة دخول `dsh-agent-loop`، هدف مشغل أو موجه إلى نموذج عام سير العمل لغة، حينئذ سوف يجعل واحد بند سياسة و غير متصل تنفيذ آلية اقتران دمج. يجعل كل فرعي agent وراثة أب محادثة أيضا سوف كسر تالف سياق إعادة وضع، و يجعل إعادة وضع اعتماد لا قطع زيادة طويل خفي صيغة بادئة. هذا وظيفة حاجة واحد بند من قائم إضافة أصل لغة تركيب بينما صار ثابت، يمكن مراجعة سياسة، معا حفظ إثبات إلغاء بعد تماما توقف مستقر، محدود عبر Round بيانات، عرض وفرة كما يمكن إعداد حد أعلى، و كما لا جذب دخول جديد موجه إلى شخص صنف هدف حالة.

## قرار

في `packages/workflow/` تحت إضافة جديدة مستقل مستهلك حزمة `@deepseek-ai/dsh-tool-ralph`. هو تسجيل `ralph({ objective, maxRounds? })`، يملك ثابت سير العمل نص برمجي، و كما فقط اعتماد `ctx.tools`،`ctx.systemPrompt`،`ctx.workflowEngine` و `ctx.subagents`.Ralph تشغيل لا هو جلسة هدف، لن إنشاء هدف حالة، أيضا لا اشتراط في أداة جسم agent loop في زيادة فرع.

هذا أداة فقط بـ قبل منصة طريقة تشغيل. استدعاء agent بصفة كل فرعي agent أب درجة بـ توفير cwd و جدول نظام، أب أداة استدعاء انتظار كامل مرة تشغيل انتهاء، أب خطوة في توقف إشارة سوف إلغاء سير العمل. كل بند مسار كل سوف انتظار `run.dispose()`، لذلك استدعاء إرجاع قبل، إلغاء سوف مرور مرور عمل خط مسار جذب محرك محدود استلام جمع و جعل فرعي agent تماما توقف مستقر.

### كل مرة تشغيل سير العمل مزود توجيه

`WorkflowStartRequest` إضافة جديدة اختياري `subagentProvider`. عمل خط مسار جذب محرك أولا تحليل هذا عدد صريح كل مرة تشغيل قيمة، مجددا رجوع إلى جذب محرك إعداد مزود؛ في إصدار تشغيل قبل، هو اشتراط الذي اختيار مواصفة تحويل توجيه قد تسجيل، و يأخذ نتيجة لأجل كل مرة `agent()` استدعاء. نص برمجي لا يمكن مراقبة أو استبدال هذا توجيه. عادي `workflow` أداة لا ضبط هذا حقل، أيضا لا كشف جديد نموذج معامل، لذلك عام سير العمل سلوك و مزود سياسة إبقاء ثابت.

Ralph إضافة `subagentProvider` افتراضي لـ `spawn`. كل مرة استدعاء قبل، هو اشتراط أداة اسم مزود قد وجود، دعم حمل بنية تحويل إخراج كما تقرير إبلاغ `inheritsParentContext: false`؛ صنف يشبه fork أو قدرة لا كاف مزود سوف في سير العمل بدء قبل واضح تقرير خطأ. مزود فحص بحث إبقاء في استدعاء مدة، لأن فاعلية نتيجة أثر مجال داخل مزود تسجيل ممكن مع HMR(حار وحدة استبدال) تغيير.

### كل مرة تشغيل سير العمل فرعي agent حد أعلى

`WorkflowStartRequest` أيضا إضافة جديدة اختياري `maxTotalAgents`. عمل خط مسار جذب محرك اشتراط هو هو صحيح أمان كامل عدد كما لا عال في قد إعداد نشر حد أعلى، و في إصدار تشغيل قبل يأخذ تحليل قيمة تركيب دخول هذا تشغيل عمل خط مسار حد.Ralph يأخذ تحليل بعد `maxRounds` بصفة هذا حد أعلى، لذلك ثابت حلقة Round ميزانية لن و عام فقد تحكم فرعي agent بعد تجهيز حد اندفاع مفاجئ. عادي سير العمل أداة لا ضبط هذا حقل و إبقاء جذب محرك قيمة افتراضية.

### Ralph Round و تسليم وصل

طبقة درجة لـ Ralph تشغيل → Ralph Round → كل جديد فرعي agent جولة → خطوة. كل Ralph Round تماما جيد عبر الذي اختيار مزود إنشاء واحد فرعي agent.spawn إعطاء هذا فرعي agent واحد لا يوجد نوع فرعي مستقل جلسة، معا إبقاء أب درجة cwd، لذلك مشترك عمل شجرة هو حمل دائم مرجعي، أب محادثة و أولا قبل فرعي agent تاريخ كل لن دخول طلب.

ثابت تلميح فقط نقل تمرير غير ممكن تغيير هدف، حالي Round و حد أعلى، بـ مساحة العمل لـ مرجعي إشارة أمر، و فوق واحد نسخة بنية تحويل تقرير إبلاغ.`RalphRoundReport` يتضمن `status: continue | complete | blocked`،`summary`،`evidence`،`nextSteps` و `blocker`. نص يجب مواصفة تحويل؛`continue` اشتراط وجود تحت واحد خطوة كما لا يوجد منع سد بند،`complete` اشتراط وجود دليل كما لا يوجد تحت واحد خطوة أو منع سد بند،`blocked` اشتراط أداة جسم منع سد بند. تقرير إبلاغ يصبح تحت مرة تسليم وصل قبل، نص برمجي سوف تحقق دلالة و تسلسل تحويل كبير صغير؛ مستهلك أيضا سوف عبر workflow seam مجددا مرة تحقق فعلي جسم تحويل إنهاء قيمة.

`maxRounds` افتراضي لـ `256`، معا أيضا هو استدعاء تغطية قيمة نشر حد أعلى.`maxHandoffChars` و `maxResultChars` متساو افتراضي لـ `16384`. ثلاثة من كل هو صحيح أمان كامل عدد إعداد قيمة. مرور كبير تسليم وصل سوف فشل، بينما لن يتم ساكن صامت قطع قطع؛`maxResultChars` مفرد وحيد حد موجه إلى أب درجة كامل نجاح نص، يشمل خارج طبقة نص و قطع قطع علامة، و كما لن تغيير عبر Round حالة. الأكثر بعد واحد سماح Round تقرير إبلاغ `continue` بعد، ثابت نص برمجي إرجاع `budget-limited`؛`complete` و `blocked` سوف قيام أي إرجاع نهائي تقرير إبلاغ و قد بدء Round عدد.

سير العمل لغة سوف يأخذ صحيح معتاد انتهاء لكن لم نجاح فرعي agent خريطة لـ `null`. ثابت نص برمجي سوف في تقرير إبلاغ تحقق قبل فحص قياس هذا قيمة، و إرجاع `round-failed`، منها يتضمن فشل Round، و وجود وقت فوق واحد نسخة نجاح تسليم وصل؛ أداة سوف يأخذ هو تحويل صار خطأ، بينما لن خطأ حكم لـ شاذ شكل تقرير إبلاغ أو ميزانية استهلاك كل.Ralph لا إضافة إعادة محاولة سياسة. يؤدي أمر مزود بدء، نقل، عمل خط مسار و سير العمل خطأ ما زال هو عام سير العمل فشل، لأن هذه مسار فوق workflow seam لا يحمل يمكن استعادة فرعي تقرير إبلاغ.

### نموذج و UI

نموذج فقط قدرة توفير `objective` و اختياري `maxRounds`؛ مزود اختيار، تقرير إبلاغ schema، تسليم وصل حد أعلى و نص برمجي كل من نشر جهة تحكم. ثابت تلميح منطقة مقطع شرح، فقط لديه مباشر تفاعل شخص صنف واضح اشتراط Ralph أو كل جديد agent تكرار بديل وقت عندئذ استخدام `ralph`، و سوف ذلك و نفس جلسة هدف، محدود تفويض إرسال و عام مروحة خروج سير العمل منطقة قسم فتح. هذا هو إشارة توجيه، بينما لا هو جديد هدف UX حالة آلة.

موجه إلى شخص صنف عرض استخدام عام `ralph` بطاقة، و يأخذ هدف بصفة أصلي إدخال؛ACP(Agent Client Protocol) فقط تحمل تحميل قد إيداع مساعدة يد نص. نجاح إتمام و منع سد خارج طبقة نص سوف شرح نتيجة من عمل من تقرير إبلاغ، بينما لن يأخذ هو عرض لـ مستقل إقرار إثبات. أب درجة transcript(نص سجل) فقط إبقاء أصلي أداة استدعاء، و واحد نسخة محدود نجاح إنهاء تقرير إبلاغ أو واحد خطأ، لا يتضمن في بين فرعي agent رسالة. إصدار بلا رأس،TUI و ACP تركيب سوف في قائم سير العمل جذب محرك جانب تحميل هذا إضافة؛JSON-RPC إبقاء ثابت، لأن ذلك افتراضي تركيب لا كشف سير العمل.

## اختبار

اختبار وحدة تغطية إعداد و استدعاء حد أعلى تحليل، مزود قدرة رفض، ثابت بدء طلب توجيه و فرعي agent حد أعلى، الكل نجاح إنهاء نتيجة، عادي فرعي agent فشل خارج طبقة قيمة، شاذ شكل و مرور كبير حد قيمة، نجاح نتيجة دقيق قطع قطع، في توقف وقت ترتيب،dispose(مورد تحرير) ، تصيير معنى رسم، تلميح دورة الحياة و نطاق الأسماء إضافة شكل حالة، و بلوغ إلى تدريجي ملف 100% نسبة التغطية. سير العمل جذب محرك اختبار إثبات مزود توجيه سوف تزامن تحقق، كل مرة تشغيل فرعي agent حد أعلى يمكن منخفض في نشر حد أعلى، و كما مزود تغطية سوف اختيار كل فرعي agent كما لا تغيير إعداد قيمة افتراضية، منها يشمل عادي Node تحت بناء بعد `lib/worker.cjs`.

واحد بند بلا key حقيقي مكدس integration عبر فعلي worker-thread engine،spawn provider،structured-output runtime و agent loop قيادة ثابت script. هو إثبات child agent identity مختلف،`isSeeded: false` كما cut لـ صفر، وراثة cwd، اثنان عدد child request كل لا يحتوي parent-history marker، فوق واحد نسخة report فقط دقيق ظهور في تحت واحد Round handoff في، فقط إنتاج واحد phase event،terminal completion، و اثنان عدد child agent كل قد dispose. نفس حقيقي مكدس أيضا تغطية blocker و Round-limit outcome، لم مواصفة تحويل و دلالة بلا فاعلية report، مرور كبير handoff، إبقاء فوق واحد نسخة صالح handoff عادي child failure، و إلغاء بعد child تماما توقف مستقر. بلا key [`ralph-loop` headless snapshot](../../../../snapshots/session/ralph-loop/) استدعاء `ralph`، ثابت parent stream transcript، و فحص حمل دائم log في وجود اثنان عدد مختلف كما unseeded child Session، كما Round 1 handoff فقط ظهور في Round 2.Tool test ثابت عام call/result presentation،request-header snapshot ثابت قد إصدار schema و prompt-guidance transcript.

## اعتبار مرور بديل خطة

- **يأخذ Ralph وضع دخول نفس جلسة هدف مشغل** — رفض، لأن Goal Round متعمد إبقاء نفس مقطع محادثة، بينما Ralph تعريف صفة خاصية هو كل Round استخدام كل جديد سياق؛ دمج اثنان من سوف يجعل هدف دورة الحياة و فرعي agent تحرير ترتيب لا يمكن قسم مغادرة.
- **في عام سير العمل أداة فوق كشف `fresh` أو حلقة علامة سجل** — رفض، لأن نموذج تحرير كتابة نص برمجي API ينبغي إبقاء عام كما و مزود غير متصل؛Ralph ثابت تقرير إبلاغ بروتوكول و إيقاف سياسة قيمة نيل يملك واحد يمكن مراجعة مستهلك.
- **لـ جهة سهل إعادة وضع بينما استخدام `subagent_fork`** — رفض، لأن وراثة قد إتمام جولة هو خفي صيغة، لا قطع زيادة طويل تسليم وصل حالة، و مخالفة عكس كل جديد سياق اتفاق. مساحة العمل إضافة واحد نسخة بنية تحويل تقرير إبلاغ يكفي إعادة وضع، بلا حاجة إدراج دخول شخص لـ إلغاء سجل.
- **يجعل أداة مباشر استدعاء subagent seam** — رفض، لأن قائم سير العمل جذب محرك قد يملك قبل منصة تحرير ترتيب، بنية تحويل فرعي agent، إلغاء نقل بث، عمل خط مسار إنهاء، حدث و مسؤول dispose و انتظار تماما توقف مستقر. إعادة استخدام هو يمكن عرض إضافة تركيب، بينما لا هو بناء ثاني عدد حلقة وقت التشغيل.
- **ساكن صامت قطع قطع كبير نوع تقرير إبلاغ** — رفض، لأن قطع قطع ممكن حذف حالة دليل أو تحت واحد خطوة، لكن ما زال نظر يشبه مرجعي تسليم وصل. إنتاج جهة يجب في إعداد حد داخل إرسال خروج صالح تقرير إبلاغ.

## عاقبة

- كل جديد agent تكرار بديل يصبح واحد بند واحد انتظار نموذج أداة، و تماما بـ قائم seam لـ فوق يمكن إزالة إضافة تنفيذ.
- Goal Round و Ralph Round إبقاء مختلف عام فكرة: قبل من هو مرة نفس جلسة متابعة سطر جولة، بعد من هو قبل منصة سير العمل في واحد كل جديد فرعي agent.
- مساحة العمل يصبح مرجعي عبر Round تسجيل ذاكرة، لذلك عمل من يجب فحص و تحقق مساحة العمل، بينما لا يستطيع معلومة مهمة سرد أمر صفة تسليم وصل.
- عرض وفرة Round حد أعلى سماح كبير كمية ذاتي معالجة عمل، بينما نشر إعداد ما زال سوف حد فرعي agent عدد كمية، و كما كل مرة تسليم وصل بداية نهاية تلقي كبير صغير قيد.
- مزود توجيه و يمكن خفض منخفض كل مرة تشغيل فرعي agent حد أعلى يصبح صريح سير العمل بدء صلة ملاحظة نقطة، لكن لا توسيع نص برمجي أو عادي سير العمل أداة تجميع.

## معروف حد و مؤقت مؤقت أمر بند

- إتمام و منع سد حالة من عمل من ذاتي سطر إعلان. مستقل تقييم تقدير جهاز، تقييم تقدير جهاز قيادة عكس تغذية Round، إتمام إثبات كتاب أو مقابل مقاومة صيغة verifier يتم متعمد دفع متأخر.
- تشغيل يقع في قبل منصة كما فقط وجود في عملية داخل. خلفية استلام تجميع، حفظ دائم/استعادة، ضبط درجة و إعادة بدء استعادة متساو لا وجود.
- Round عدد هو وحيد تجمع دمج ميزانية.token، بضاعة عملة، استهلاك وقت و مزود استخدام كمية ميزانية ما زال يخص لم قدوم مستقل سياسة.
- كل Round إنشاء واحد فرعي agent.Round داخل مروحة خروج، تقييم تقدير جهاز/عمل من زاوية لون قسم مغادرة، حركة حالة مزود أو نموذج اختيار، و عبر تشغيل سجل متساو يتم دفع متأخر.
- عادي فرعي agent فشل سوف انتهاء تشغيل كما لا إعادة محاولة، معا إبقاء فشل Round و فوق واحد نسخة نجاح تسليم وصل. يؤدي أمر سير العمل أساس أساس ضبط تطبيق خطأ ممكن في ثابت نص برمجي إرجاع هذا حالة قبل انتهاء؛ زيادة إعادة محاولة أو أكثر وفير غني فشل نقل حاجة مستقل سياسة و حد تصميم.
- تلميح إشارة توجيه نموذج لا يلزم تمرير عودة استدعاء Ralph؛ بنية تحويل فرعي agent أداة حد حاجة آخر سطر تصميم سير العمل فرعي سياسة API.
