# Agent Note: داخل وضع dsh شعار فصل skill

Status: implemented
Archived: 2026-08-22

[English](2026-08-06-bundled-dsh-badge-skill.md) | العربية

## مشكلة

[Cordis تعليم مسار](../../../../docs/cordis-tutorial/index.zh.md) كل عدد صفحة كل استخدام رسمي جهة «powered by dsh» شعار فصل، لكن تسليم CLI(أمر سطر واجهة) حيث لا يوجد لأجل في أخرى موضع تطبيق نفس مثال توقيع اسم يمكن إعادة استخدام إشارة أمر، أيضا لا يوجد يمكن صريح اختيار إضافة دخول مزود.

## قرار

`@deepseek-ai/dsh-skill-badge` هو واحد أصلي Cordis إضافة، سوف في `ctx.skills` فوق تسجيل واحد غير ممكن تغيير داخل وضع مزود. هذا مزود مسؤول `dsh-badge` ملخص، إشارة أمر متن و PNG مورد أساس قاع؛`dsh-tool-skill` ما زال هو موجه إلى نموذج دليل و loader تصيير وحيد ملكية جهة.

تسليم CLI تركيب سوف `skill-badge` إعلان لـ منع استخدام. تفعيل هذا عدد قائم إعداد سطر حينئذ هو صريح اختيار إضافة دخول؛ منع استخدام هو تثبيت نسخة لن عام أي شعار فصل skill(تقنية قدرة) ، أيضا لن نيل نيل أي نموذج مرئي محتوى.

هذا مزود استخدام ترتيب في مشروع، ذاتي تعريف و مستخدم نظام الملفات مصدر بعد داخل وضع rank، لذلك مستخدم ذاتي لديه `dsh-badge` تعريف يمكن عبر سجل التسجيل معتاد قاعدة أولوية درجة اتفاق تغطية هو. مزود تحرير وقت، سجل التسجيل يملك effect سوف إزالة هذا مساهمة.

## سبق اعتبار بديل خطة

**عبر `dsh-skill-filesystem` تركيب مع حزمة ملف.** مرفوض، لأن نظام الملفات اكتشاف، تحليل و مراقبة نظر سوف جذب دخول دورة الحياة آلية، بينما غير ممكن تغيير مفرد واحد skill مزود و لا حاجة هذه آلية.

## عاقبة

شعار فصل إشارة أمر و مصدر PNG مع DSH واحد نفس قبول دخول إصدار إدارة، و عبر بـ مع حزمة دليل لـ أساس أساس مورد أساس قاع تحليل. هذا مزود لا يوجد إعداد وجه. حزمة اختبار ثابت مزود دورة الحياة و رسمي جهة PNG بايت محتوى؛ بلا مفتاح تجميع تطبيق لقطة فإن ثابت تفعيل بعد دليل و قد تحميل skill متن.
