# Agent Note: Fixed `Tool / <name>` header for tool-call cards

Status: implemented
Archived: 2026-08-04

[English](2026-07-27-tui-tool-card-header.md) | العربية

## Problem

TUI سبق يأخذ كل مرة أداة استدعاء تصيير لـ `{glyph} {title}`، منها `title` هو presenter تجميع وصل «حركة كلمة إضافة دقيق عقدة» نص (`Read src/index.ts (1200-1360)`،`Edit files`، أو bash بطاقة نموذج وصف) ، بـ حالة لون إضافة خشن و إضافة تحت تخطيط خط عرض. مفرد واحد مسطح مستو مجرى موضع معا تحمل تحميل أداة هوية، عملية كائن و حالة، بينما مثال صيغة أيضا خلط استخدام إضافة خشن، تحت تخطيط خط و لون لون، قبل بعد لا متسق——جدول رأس قراءة بدء قدوم مثل ضجيج صوت، «تشغيل أي عدد أداة» في نظر شعور فوق و «هو عملية ماذا» لا يمكن منطقة قسم.

## Decision

جدول رأس هو ثابت `{ring} Tool / <name>` إطار هيكل، اعتماد مفرد واحد مسطح مستو حالة لون——لا إضافة خشن، لا إضافة تحت تخطيط خط، ثابت داكن——لذلك كامل سطر لون لون إبقاء متسق.`Tool` هو حرف وجه معتاد كمية؛`<name>` هو أصلي أداة اسم. قسم فصل رمز هو ASCII `/`. حلقة شكل علامة في استدعاء تعليق بدء وقت لـ `○`، سقوط تحديد بعد لـ `●`؛ جدول رأس لون لون (تعليق بدء استخدام warning، نجاح استخدام success، خطأ استخدام error) منطقة قسم تعليق بدء، نجاح و خطأ، لذلك نفس عدد فعلي قلب حلقة يمكن معا خدمة في اثنان نوع سقوط تحديد حالة.

جدول رأس فقط يحمل واحد اختياري مقدار خارج محتوى:bash(طرفية) بطاقة من نموذج تأليف كتابة وصف، بصفة ` / <desc>` مقطع إلحاق (`● Tool / bash / Run the coverage gate`). أخرى أداة كل لا نحو جدول رأس مساهمة دقيق عقدة.

كل واحد بند أداة مخصص تابع دقيق عقدة كل نقل دخول جدول رأس تحت جهة متن كتلة. غير طرفية بطاقة presenter عنوان (`Read src/index.ts`،`Grep pattern`) يصبح متن رقم واحد سطر، حذف غير هو فقط هو تكرار أداة اسم (بلا `presentCall` أداة التقاط قاع presenter، أو لم معرفة أداة) ، هذا وقت جدول رأس قد عرض مرور. طرفية بطاقة إبقاء ذلك أمر بصفة `$` سطر.diff بطاقة تماما ترك استخدام ذلك عنوان——من كل ملف مسار جدول رأس و واحد بند تغيير صفحة قدم تحمل تحميل يحتوي معنى——و إلحاق واحد بند تغيير داكن `└ +A -R · N file(s)` صفحة قدم، تجميع مجموع كل ملف زيادة حذف سطر عدد.

هذا مرة تعديل إصدار فقط حد TUI. هو تعديل `packages/ui/tui/src/components/transcript.ts` في `ToolCardComponent`، لا لمس اصطدام أي presenter:`Tool / <name>` إطار هيكل في TUI جانب من استدعاء أداة اسم دفع توجيه خروج اسم، متن عنوان ترحيل فإن إعادة استخدام presenter قد إرجاع عنوان.`presentation.ts` و كل واحد `presentCall`/`presentResult` متساو إبقاء ثابت.

## Alternatives considered

**يأخذ أداة اسم إضافة خشن جعل ذلك مفاجئ خروج.** قد مرفوض: في يأخذ SGR-1 تصيير لـ مضيء لون تغيير جسم طرفية فوق، إضافة خشن أخضر لون أداة اسم قراءة بدء قدوم و ذلك بقية أخضر لون جدول رأس هو مختلف لون لون——إعادة جذب دخول تعديل إصدار يلزم إزالة حذف لا متسق. أداة اسم اعتماد هو في ثابت إطار هيكل في موضع مفاجئ خروج، بينما غير اعتماد حرف إعادة.

**يأخذ presenter عنوان إبقاء في جدول رأس**(مثال مثل `Tool / read / Read src/index.ts`). قد مرفوض: حركة كلمة و أداة اسم تكرار، بينما غير bash أداة و لا يوجد حق صحيح مستقل مفرد سطر وصف——عملية كائن يخص متن، لذلك فقط لديه bash نحو جدول رأس مساهمة وصف مقطع.

**لـ كل واحد نوع بطاقة كل إضافة واحد بند تجميع مجموع صفحة قدم**(سطر عدد، خروج رمز شعار فصل،diff حساب عدد موحد واحد لـ واحد بند `└ …` سطر). قد دفع متأخر: فقط diff صفحة قدم سقوط أرض. طرفية خروج إبقاء ذلك قائم تغيير داكن `[exit N]` سطر، طويل إخراج إبقاء ذلك قائم أول ذيل في مقطع حذف، فارغ نتيجة إبقاء فقط جدول رأس، خطأ متن إبقاء بسيط عنصر (فقط جدول رأس لون لون تحمل تحميل خطأ)——هذه قائم معالجة هو متعمد إبقاء، بينما غير متروك تسرب. متن أصل هذا بـ افتراضي قبل مشهد لون مستو فرش، هذا نوع مثال صيغة بعد قدوم أيضا مرور مرور ضبط كامل:[كامل دمج بعد TUI عرض](../architecture/2026-07-28-consolidated-tui-presentation.md) يأخذ كامل متن استلام دخول هذا نص الذي وصف لون لون حالة عنوان لـ تحت نفس نوع داكن لون ضبط.

## Consequences

أداة استدعاء الآن يأخذ هوية عرض في واحد مستقر موضع، حالة كل سطر قراءة عمل واحد نوع مسطح مستو لون، في هو سماح كثير استدعاء سجل مسح قراءة بدء قدوم هو واحد صف `Tool / <name>`، بينما غير واحد سد خلط دمج مثال صيغة حركة كلمة نص لـ جدار. بديل قيمة هو غير طرفية أداة كثير خروج واحد سطر متن (ترحيل مرور قدوم عنوان) ، و فقد فقد أولا قبل زائد بقية كبح صنع——عند جدول رأس قد تسمية مسار وقت حذف diff كل ملف مسار؛ مثل اليوم جدول رأس لم يعد تسمية أي مسار، لذلك كل diff كل سوف يأخذ مسار ضرب طبع مرة. من في تعديل نطاق حد في `ToolCardComponent`، أخرى UI جسر (ACP،JSON-RPC) إبقاء كل منها أداة استدعاء عرض؛`Tool / <name>` شكل هو TUI نطاق جزء، لا يخص أي عبر حزمة عقد نحو.

## Testing

`packages/ui/tui/tests/tui.spec.ts` ثابت جديد جدول رأس (`Tool / <name>`) ، ترك استخدام diff عنوان، ترحيل بعد generic عنوان و `· N file(s)` صفحة قدم. حزمة درجة دلالة لقطة في بلا واجهة طرفية في تغطية كل صنف بطاقة. قد حذف تطبيق مسار هذا قبل توفير تجميع بعد أداة تنفيذ؛ لم قدوم طرفية نشر مسؤول توفير انتظار قيمة transcript تغطية.
