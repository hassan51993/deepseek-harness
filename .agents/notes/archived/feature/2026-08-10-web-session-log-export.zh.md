# Agent Note: Web جلسة سجل توجيه خروج——مضيف تدفق صيغة ZIP تحت تحميل

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-web-session-log-export.md) | العربية

## مشكلة

Trajectory عرض لا يوجد أي طريقة يأخذ ضبط تجربة عمل عنصر تسليم إلى شخص يد داخل: أصلي جلسة سجل تخزين وضع في مغناطيس قرص و مضيف جانب، عميل تاريخ وجه فقط توفير طي بعد إسقاط (بينما غير أصلي حدث) ، بينما حمل فرعي بديل إدارة جلسة أفقي عبر كثير عدد متبادل متبادل مستقل جلسة سجل.bug تقرير إبلاغ حاجة كامل شجرة جلسة شجرة كامل أصلي سجل، و كما شكل يلزم قدرة في يتم تحويل إرسال بعد ما زال متاح.

## قرار

- **توجيه خروج هو مضيف جانب تحت تحميل وجه، لا هو RPC**:`GET /api/session.export?sessionId=…&includeDescendants=true` تدفق صيغة إرجاع واحد ZIP مرفق عنصر. كل Session ملف كل هو من حفظ دائم قراءة جملة مقبض توليد مواصفة حالي JSONL: واحد سطر v2 header، مع بعد كل قد تحقق حمل دائم حدث كل احتلال واحد سطر. خلفية مخصص تابع generation اسم،Zstandard framing و تاريخ packed row كل إبقاء في حفظ دائم seam بعد وجه؛archive بداية نهاية يأخذ root كتابة لـ `session.jsonl`، يأخذ descendant كتابة لـ `subagents/<id>/session.jsonl`. ضغط في مضيف جانب استخدام fflate تدفق صيغة `Zip`/`ZipDeflate` API و قد تحقق `sessionExportCompressionLevel` 0–9(افتراضي 6) ، جعل نشر يمكن في CPU/تأخير متأخر و عودة ملف كبير صغير بين أخذ ترك؛ كل بند حسب محدود قسم كتلة حافة إنتاج خروج حافة ضغط، استجابة مع توليد قسم كتلة كتابة خروج، مضيف من لا يأخذ كامل عودة ملف وضع دخول مفرد عدد مؤقت اندفاع منطقة (حذف مسبق تحميل root خارج، الأكثر كثير معا يحتفظ واحد بند descendant سجل نص). وصول 64 KiB استجابة بايت عال ماء موضع بعد، إنتاج سوف انتظار Consumer pull استعادة سعة كمية؛fflate تزامن عودة ضبط الأكثر كثير فقط سوف في هذا طابور صف حد حد خارج مجددا زيادة مرة محدود input push. لا كتابة manifest——كل بند سجل عبر ذاتي ذات header و تضمين دخول صيغة v2 lineage marker ذاتي وصف، مرجع media فإن إبقاء ذلك content-addressed archive path.
- **خطأ مفردات هو HTTP أصلي**: خدمة ناقص → 500، أصل جلسة ناقص → 404، اثنان من كل في أي بايت تدفق خروج قبل حكم تحديد؛descendant نقص قليل stored log أو مرجع media object سوف جعل stream فشل (fail-loud، أبدا ساكن صامت قليل توجيه خروج). طلب في توقف سوف إبقاء إلغاء دلالة بينما لن تعديل كتابة صار 500؛ طلب إلغاء و استجابة Consumer إلغاء تجميع دمج إلى إنتاج من signal، هذا signal سوف نقل إلى دم حافة، حفظ دائم و مرفق عنصر قراءة، و إنهاء نشط وثب ضغط جهاز.Connection في توزيع `session-log-export` تسجيل دقيق `GET`/`HEAD /api/session.export` توجيه قبل تطبيق `/api` معلومة مهمة محيط شريط.
- **UI فقط مسؤول تحت تحميل**: متصفح Consumer يمكن أولا إرسال خروج لا قراءة body `HEAD` مسبق فحص بـ أخذ نيل دقيق تجهيز مرحلة مقطع خطأ، مجددا يأخذ GET طرف نقطة تسليم إعطاء متصفح أصلي تحت تحميل إدارة جهاز، لذلك JavaScript لن مؤقت اندفاع ZIP. مبكر أولا تكرار بديل إصدار `session.log` RPC قد حذف——تحت تحميل طرف نقطة هو هو وحيد إزالة استهلاك من، مستودع قاعدة هو لا إبقاء بلا حالي كل من عام مشترك واجهة. عميل bundle لا يتضمن أي عودة ملف تنفيذ.
- حالي Header و `/export` Consumer من [Session سجل توجيه خروج حزمة اتفاق](../../../../packages/session-query/session-log-export/README.zh.md) تعريف.

## اعتبار مرور بديل خطة

- **`session.log` بيانات RPC + عميل تحزيم**——أولا إصدار، بعد و مستخدم مشترك نفس مرفوض: متصفح يلزم سحب أخذ كامل أصلي JSON(نحو لـ نهائي zip 10 ضعف) و في رئيسي خط مسار ضغط؛ مقابل فعلي استخدام في 23 MB درجة آخر جلسة، مضيف تدفق صيغة صارم إطار أكثر أفضل. ترحيل وقت يأخذ هذا RPC واحد و حذف، بينما لا هو إبقاء عمل بلا إزالة استهلاك من عام مشترك واجهة.
- **استخدام معلومة غلاف سطر يأخذ كثير جلسة تحرير رمز دخول مفرد واحد JSONL**——و مستخدم مشترك نفس مرفوض: يأخذ كثير عدد جلسة خلط دخول واحد JSONL سوف فقد ذهاب جاف صاف حسب ملف حد؛ZIP يجعل كل جلسة إبقاء واحد مواصفة ملف.
- **jszip**——أكثر إعادة (نحو 100 kB) ، اعتماد رسم أيضا سوف سحب دخول readable-stream متصفح خريطة؛fflate مخصص لـ هذا بينما توليد كما جسم تراكم صغير.
- **سوف fflate متصفح مدخل vendoring دخول مستودع**——مستودع vendoring مسار موجه إلى cordis درجة آخر ثابت شفرة المصدر؛resolveId آخر اسم في إبقاء صيانة في اعتماد معا بلا حاجة نسخ شفرة (مضيف جانب fflate أصل هذا لا حاجة آخر اسم).

## عاقبة

- توجيه خروج حفظ حق درجة: قراءة كل فوري أصل جلسة أو بعد بديل قبل، توجيه خروج جهاز سوف عبر مرجعي `SessionStore.flush` حمل دائم صفة شاشة عائق؛ كل توجيه خروج ملف كل بـ نفسه حالي JSONL شكل صيغة يمثل هذا مرور مرور تحقق حمل دائم logical log، لا تلقي خلفية framing أثر. فوري جلسة ممكن في ذاته قراءة بعد مجددا مرة إلحاق، لذلك عودة ملف هو حسب جلسة قراءة حد شكل صار لقطة، بينما لا هو كامل شجرة شجرة أصل فرعي لقطة. ضغط حزمة اسم لـ `dsh-session-<sanitized-id>.zip`، عودة ملف مسار في تشكيل صنع بند قبل سوف أولا صاف تحويل جلسة id.
- توجيه خروج لا حاجة seam قدرة: كل نسخة سجل مرور من حفظ دائم قراءة جملة مقبض قراءة، و في هذا موضع تسلسل تحويل لـ مواصفة JSONL، لذلك أي تركيب خلفية توجيه خروج تماما متسق (مبكر أولا تدريجي حرف عمل عنصر جدول وجه إزالة من[توجيه خروج و مسبق إصدار قطع قص](../simplification/2026-08-27-persistence-export-and-pre-release-trims.zh.md) سجل). ناقص من مرة `stat` مسبق فحص حكم تحديد (جلسة ناقص → 404).`session-log-export` نحو Connection تسجيل واحد دقيق Host-only Fetch توجيه؛ تدفق صيغة استجابة لا استخدام Remote descriptor أو JSON envelope يمثل.
- fixture نمط (بلا مضيف) مقابل توجيه خروج ينبغي جواب 404، متصفح سوف سوف ذلك تقرير إبلاغ لـ تحت تحميل فشل؛navigation-panes golden لقطة يتضمن «توجيه خروج» حسب زر.
- مؤقت مؤقت:transcript.md و report/feedback تحزيم إبقاء انتظار لاحق؛ مستقر تدريجي جلسة JSONL و بلا manifest تخطيط يجعل هذا توسيع إبقاء نزيه قيمة.
