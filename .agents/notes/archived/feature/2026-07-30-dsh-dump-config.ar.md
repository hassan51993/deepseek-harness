# Agent Note: dsh --dump-config ضرب طبع دمج صار بعد إعداد شجرة

Status: implemented
Archived: 2026-08-07

[English](2026-07-30-dsh-dump-config.md) | العربية

## Problem

بدء إعداد شجرة هو واحد نسخة مستخدم من لم رؤية مرور دمج صار نتيجة: قد تسليم أساس أساس إعداد، واجهة تغطية طبقة، و `--config` أو عدد شخص `~/.dsh/config.yaml` تغطية طبقة بصفة نفس درجة رقعة قائمة اعتماد مرة تطبيق، منها كل حسب id تحديد نحو رقعة استبدال هدف سطر كامل `config`، لم مطابقة id فقط إنتاج تحذير إبلاغ. ضبط تجربة واحد سلوك استثناء عدد شخص تغطية طبقة (تسرب إسقاط حاجة إعادة وصف حقل، سطر id تجميع خطأ، رقعة تطبيق إلى خطأ واجهة) حاجة في دماغ في عبر ثلاثة عدد ملف إعادة وضع رقعة حساب قاعدة. حيث لا يوجد إنجاز قاعدة يرى توليد فاعلية شجرة، أيضا لا يوجد إنجاز قاعدة يأخذ هو و قد تسليم قيمة افتراضية فعل diff.

## Decision

`dsh --dump-config` و `dsh web --dump-config` يأخذ دمج صار بعد بند قائمة——أساس أساس إعداد، واجهة تغطية طبقة، مجددا تراكم `--config` أو عدد شخص تغطية طبقة، تماما جيد هو هذا واجهة بدء وقت تجميع ذلك بعض طبقة——بـ YAML ضرب طبع إلى stdout بعد خروج، لا بدء أي شرق غرب.`dsh --dump-default-config` / `dsh web --dump-default-config` توقف خطوة في واجهة تغطية طبقة، لذلك مقابل اثنان نسخة إخراج فعل diff حينئذ قدرة دقيق نظر خروج مستخدم طبقة تعديل ماذا.

dump غير ممكن قدرة و فعلي بدء عائم نقل، لأن هو إعادة استخدام تركيب شفرة:vendored include يأخذ رقعة حساب قاعدة توجيه خروج لـ صاف دالة `applyEntryPatches(data, patches, warn)`(خاص `applyPatches` طريقة الآن تفويض حمل إعطاء هو) ، و يأخذ `!!js` YAML جهة قول توجيه خروج لـ `entryListSchema`؛`dsh-app-boot` `renderConfigDump()` عبر هذا اثنان من مقابل حمل وسم طبقة إتمام دمج صار و تصيير،`apps/cli/src/dump-config.ts` فقط هو اختيار واجهة رقيق غلاف تركيب.`!!js` جدول بلوغ صيغة أصل مثال ضرب طبع، لا طلب قيمة——dump عرض هو دمج صار نتيجة، لا هو بعض عدد عملية بيئة——هدف سطر لا وجود رقعة سوف وصل نفس ذلك طبقة وسم تقرير إلى stderr، و Loader بدء وقت تحذير إبلاغ متسق. من بدء جهاز يحتفظ بدء سياق قيمة (جلسة هوية،web CLI علامة سجل رقعة، قبل طرف dist مسار) هو كل مرة استدعاء واقع، يقع في إعداد شجرة خارج، لن ظهور.dump علامة سجل رفض فقط لأجل بدء علامة سجل (`-p`،`--resume`،`--config-replace`) كما اثنان عدد dump علامة سجل متبادل رفض،`--dump-default-config` لا قبول `--config`.

كل مقطع مصدر نفسه وصل متابعة سطر قبل كل لديه واحد بند `# ==` ملاحظة تفسير، علامة واضح مساهمة هذه سطر ملف و إصلاح تكملة مرور هو جمع طبقة (`# == base.cordis.yml, patched by tui.cordis.yml`) ، لذلك إخراج حيث عرض كل واحد عقدة قدوم ذاتي أي عدد ملف، أيضا ما زال هو واحد نسخة يمكن تحميل YAML وثيقة. دمج صار هو مقابل كل طبقة عرض مستو بعد مرة `applyEntryPatches` استدعاء——و بدء استدعاء شكل حالة تماما متسق، لذلك أي سهل هو رقعة مرئي صفة حافة زاوية حال حال (بعد واحد طبقة تحديد موضع إلى قبل واحد طبقة عبر عادي `config` استبدال جذب دخول مجموعة داخل فرعي بند، بينما مفرد مرة id بحث جذب نظر لا إلى هو) أيضا و بدء دمج صار تماما نفسه؛ إذا حسب طبقة كل استدعاء مرة، سوف في طبقة و طبقة بين إعادة بناء بحث جذب، ضرب طبع خروج واحد شجرة بدء من لا تركيب شجرة. مصدر من مفرد مرة استدعاء بادئة لقطة (أساس أساس + رقم 1..k طبقة) حسب موضع diff نيل خروج: رقعة حساب قاعدة فقط سوف أصل أرض تعديل كتابة سطر أو في نهاية ذيل إلحاق، لذلك قمة طبقة بحث جذب في كل لقطة بين معرف نفس سطر؛ إضافة دخول بعض طبقة بعد هذا سطر حدوث تغير (استبدال config، منع استخدام، مجموعة داخل إدراج دخول) أي نظر لـ هذا طبقة إصلاح تكملة هذا واحد سطر. كل لقطة كل سوف تغلب ضخم رقعة قائمة، لأن `applyEntryPatches` سوف يأخذ `insert` سطر حسب مرجع من رقعة قائمة دفع دخول نتيجة.

`dsh-app-boot` قبل لـ تحليل رقعة نسخ include `!!js` YAML نوع؛ الآن تعديل لـ استيراد `entryListSchema`، جهة قول فقط لديه واحد ملكية من.

## Alternatives considered

**بدء كامل شجرة شجرة بعد dump `ctx.loader.entries()`.** رفض: بدء سوف طلب قيمة `!!js` جدول بلوغ صيغة (يأخذ بعض منصة آلة جهاز بيئة تسرب تسرب دخول ضرب طبع إعداد) ، بـ فرعي أثر بدء مهايئ و جلسة، حاجة مستقل في TTY تفكيك إزالة مسار، بينما كما بطيء.dump هو استخدام قدوم ضبط تجربة دمج صار، بينما دمج صار هو ذلك بعض ملف صاف دالة.

**في CLI داخل إعادة تنفيذ رقعة دمج.** رفض:`applyPatches` ثاني عدد تنفيذ سوف و vendored include صامت لكن عائم نقل——هذا تماما تماما هو هذا وظيفة يلزم ضبط تجربة فشل نمط. توجيه خروج include ذاتي ذات حساب قاعدة فقط زهرة استهلاك واحد بند سجل في سجل vendor تعديل، لكن حفظ إثبات نفس صفة.

**استخدام `/dump-config` TUI أمر بديل بديل علامة سجل.** بصفة وحيد شكل صيغة يتم رفض: رئيسي يلزم استخدام قاعدة هو `dsh --dump-config | diff - <(dsh --dump-default-config)` هذا صنف إدارة طريق سير العمل، حاجة تجنب بدء، غير TTY واجهة. بعد يمكن في نفس عدد `renderConfigDump` لـ فوق مجددا إضافة TUI أمر.

## Consequences

إعداد ضبط تجربة من دماغ في إعادة وضع رقعة تغيير صار واحد بند أمر، دعم حمل عمل أيضا يمكن مباشر بحث يلزم `--dump-config` إخراج.vendored include كثير خروج واحد بند سجل في سجل محلي تعديل (توجيه خروج `applyEntryPatches`/`entryListSchema`؛ مقابل تركيب سلوك بلا أثر) ، فوق تنقل تزامن وقت يحتاج إعادة تطبيق. مصدر تتبع أثر لـ كل طبقة إعادة دمج صار مرة بادئة لقطة و حسب JSON stringify مقابل سطر فعل diff، لذلك dump لديه و طبقة عدد²×سطر عدد صار صحيح مقارنة مقدار خارج فتح إلغاء؛ هذا فتح إلغاء فقط وجود في تجنب بدء dump مسار.`renderConfigDump` اختبار وحدة تغطية طبقة تراكم ترتيب،`!!js` أصل مثال نحو إرجاع، مصدر قسم فصل و قسم مجموعة، حمل وسم لم مطابقة رقعة تحذير إبلاغ، و قراءة/تحليل/شكل حالة فشل كبير صوت تقرير خطأ؛built-bin e2e عبر `lib/bin.js` قيادة الكل أربعة نوع علامة سجل شكل صيغة، يشمل عدد شخص تغطية طبقة، ذلك مصدر وسم و ذلك stderr تحذير إبلاغ.
