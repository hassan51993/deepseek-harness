# Agent Note: منتج subagent تسمية نسخة

Status: implemented
Archived: 2026-09-04

[English](2026-08-18-product-subagent-named-instances.md) | العربية

## مشكلة

Profile يمكن استخدام كثير عدد بند إعداد تركيب نفس عدد Cordis إضافة حزمة، لكن Codex و Claude Code منتج مزود هذا قبل سوف يأخذ كل بند إعداد كل تسجيل إلى واحد ثابت منتج اسم تحت. لذلك، ثاني عدد بند إعداد سوف في ذلك مستقل نموذج، إذن نمط، بيئة أو عملية تحرير ضبط متاح قبل بسبب اسم تكرار بينما فشل. أصل حسب هذه ضبط خفي صيغة إرسال توليد اسم سوف بناء قيام ثاني طقم هوية قاعدة، بينما في أداة استدعاء خلال اختيار مزود سوف يجعل نموذج إدخال قرار نشر إذن.

قائم subagent سجل التسجيل قد يملك مزود اسم وحيد صفة، يمكن عكس تسجيل، دورة الحياة حدث و من يحتفظ جهة يملك قد إصدار تشغيل. قائم `dsh-tool-subagent` إعداد أيضا قد يأخذ واحد مزود اسم ربط إلى واحد نموذج مرئي أداة اسم. منتج مزود فقط يحتاج عام ناقص Profile كل هوية، بلا حاجة زيادة آخر طقم سجل التسجيل أو اختيار بروتوكول.

## قرار

كل منتج مزود Config كل يملك غير فارغ `providerName`؛ قيمة افتراضية ما زال قسم آخر لـ `codex` و `claude-code`. إضافة بند إعداد تحميل وقت سوف ثابت تحليل بعد اسم، و يأخذ هو بصفة Provider كائن `name`؛ تسجيل، فحص بحث، دورة الحياة حدث، تشغيل سجل و HMR(حار وحدة استبدال) إزالة لذلك استخدام نفس عدد قيمة. كل قد تركيب بند إعداد إبقاء ذاتي ذات اختياري غير فارغ `model`،`permissionMode`،`env`،`disposeGraceMs` و تشغيل مورد. صريح نموذج سوف لـ هذا نسخة كل مرة query أو خط مسار ثابت، حذف وقت ما زال بـ أصلي منتج ضبط لـ مرجعي.

عند كل بند إعداد استخدام مختلف `providerName` وقت،Profile يمكن تركيب كثير عدد Codex أو Claude Code بند إعداد. كل `dsh-tool-subagent` بند إعداد متابعة استخدام قد لديه `provider` حقل ربط هذا عدد دقيق تأكيد اسم، و عام مستقل إعداد `toolName`. أداة استدعاء لا يحمل مزود اختيار جهاز، آخر اسم أو إذن إدخال. تكرار مزود اسم امتداد استخدام قائم `DUPLICATE_PROVIDER` مسار فشل، بينما كما لن استبدال رقم واحد تسجيل بند.

إزالة واحد مزود بند إعداد سوف منع توقف جديد بدء، و كما فقط إزالة ربط إلى هذا اسم أداة. هذا نسخة قد إصدار تشغيل ما زال من ذلك يحتفظ جهة يملك، و سوف مستقل تسوية أو dispose(مورد تحرير). أخ أخ نسخة متابعة إبقاء تسجيل، و إبقاء كل منها إعداد نموذج، بيئة، أصلي إذن نمط، إلغاء تحكم جهاز، منتج عملية و تنظيف عرض حد مدة.

### كل حق و دورة الحياة

| واقع أو عملية | مسؤولية مهمة جهة | نتيجة |
| --- | --- | --- |
| مزود نسخة اسم | منتج مزود Config | كل قد تركيب بند إعداد يملك واحد غير ممكن تغيير تسجيل اسم؛ حذف وقت استخدام قائم قيمة افتراضية |
| اسم وحيد صفة و دورة الحياة حدث | `ctx.subagents` | تكرار تسجيل فشل؛ مورد تحرير فقط إزالة مطابقة اسم |
| نموذج مرئي أداة اسم و ربط | `dsh-tool-subagent` Config | واحد ساكن حالة أداة تحليل واحد قد إعداد مزود اسم |
| نموذج، إذن، بيئة و عملية تنظيف | واحد مزود نسخة | تزامن تشغيل و أخ أخ نسخة لا مشترك نشر إعداد أو تشغيل مورد |

## تحقق

اثنان عدد منتج حزمة اختبار كل سوف ثابت افتراضي و ذاتي تعريف اسم، فارغ اسم و فارغ نموذج رفض، تكرار تسجيل تراجع، فعلي اسم تشخيص، استخدام مختلف نموذج، إذن نمط، بيئة و تنظيف عرض حد مدة اثنان عدد تزامن نسخة، إلغاء عزل، و إزالة واحد نسخة بعد ذلك قد إصدار تشغيل ما زال صالح. رسمي جهة منتج fixture سوف إثبات حذف نموذج وراثة، و تدريجي query أو تدريجي خط مسار دقيق تأكيد نموذج عزل. عام مشترك Loader تركيب سوف لـ كل منتج تركيب اثنان عدد بند إعداد و اثنان عدد مختلف أداة، بينما كما لا بدء مهمة واحد منتج؛ بلا مفتاح ACP لقطة ثابت نهائي أربعة أداة تركيب، و إثبات لا يوجد حركة حالة مزود أو نموذج معامل.

## اعتبار مرور بديل خطة

**أصل حسب منتج أو إذن نمط إرسال توليد اسم.** خفي صيغة بعد لاحقة سوف يجعل نشر ضبط تغير معا تغيير هوية، بينما كما انتظار قيمة بند إعداد بين ما زال ممكن اندفاع مفاجئ.Profile سوف صريح توفير هوية.

**يجعل أداة استدعاء اختيار مزود.** هذا سوف يجعل نموذج إدخال اختيار إذن و بيئة نسخة. مستقل أداة بند إعداد سوف يجعل تخويل و عام نطاق إبقاء ساكن حالة إعداد.

**بناء قيام منتج نسخة دليل أو آخر اسم سجل التسجيل.** قائم subagent سجل التسجيل قد يملك اسم، وحيد صفة، فحص بحث، حدث و مورد تحرير. آخر طقم دليل لا يوجد مستقل مستهلك، فقط سوف نسخ حالة.

**تلقائي إعادة تسمية تكرار بند إعداد.** ساكن صامت إضافة بعد لاحقة سوف يجعل أداة ربط و دورة الحياة تشخيص اعتماد تحميل ترتيب. تكرار اسم متابعة سريع سرعة فشل.

## نتيجة

Profile يمكن عام كثير عدد من مختلف نموذج، أصلي إذن نمط و بيئة دعم حمل Codex و Claude Code أداة، بينما قائم إعداد ما زال سوف تحليل لـ `codex` و `claude-code`. مزود اسم و أداة اسم متابعة هو ذاك هذا مستقل إعداد واقع، لذلك تعديل منها واحد بند وقت يجب معا تحديث مرجع هو ربط.

هذا تصميم لا زيادة وقت التشغيل تعديل اسم، نموذج مرئي مزود أو نموذج اختيار جهاز، تلقائي توليد أداة اسم، حمل دائم نسخة دليل، مشترك عملية حوض، نموذج اكتشاف،fallback أو توافق آخر اسم. صحيح تأكيد كثير نسخة إعداد اشتراط مزود اسم و أداة اسم كل إبقاء وحيد؛ تكرار أداة اسم انتظار مشكلة ما زال هو مستقل حد.
