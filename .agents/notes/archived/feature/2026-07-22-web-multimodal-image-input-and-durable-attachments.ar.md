# Agent Note: Web كثير نموذج حالة صورة إدخال و حمل دائم مرفق عنصر

Status: implemented
Archived: 2026-09-04

[English](2026-07-22-web-multimodal-image-input-and-durable-attachments.md) | العربية

## مشكلة

في هذا تغيير قبل،Web إدخال منطقة فقط قبول نص:`InputBar` استقبال نص مسودة مسودة،`ConversationController.send()` إنشاء نص محتوى، مضيف مجددا يأخذ هذا محتوى تحويل إرسال إعطاء agent(ذكي جسم). مستخدم لا يمكن لصق لصق صورة، في إرسال قبل فحص نظر صورة، إيداع فقط يحتوي صورة نص التوجيه، أيضا لا يمكن من تاريخ سجل في استعادة قد إرسال صورة.

هذا لا فقط هو إدخال منطقة وظيفة ناقص. نواة قلب طبقة حاجة حمل دائم صورة محتوى كتلة، مزود حاجة واضح معالجة نموذج حالة، جلسة سجل فإن يجب إعادة بناء نموذج مرئي الكل محتوى.[هذا قبل إزالة صورة كتلة قرار](../../archived/simplification/2026-07-04-drop-image-content-block.md) مرفوض ممكن ساكن صامت فقد فقد صورة أو سوف ذلك عرض مستو لا كامل تصميم. متصفح كائن URL، محلي مسار، مزود URL أو base64 بيانات كل لا يستطيع يصبح مواصفة جلسة محتوى.

[Web عميل هيكل بنية](../../implemented/architecture/2026-07-19-gui-web-client-architecture.ar.md) اشتراط مكون إبقاء صاف خالص، و سوف كل جلسة إدخال منطقة حالة وضع في `ctx.conversation` في؛[قد عودة ملف GUI قسم طبقة و RPC بروتوكول قرار](../../archived/architecture/2026-07-19-gui-layering-and-rpc-protocol.md) فإن اشتراط حمل دائم حدث يصبح فوري تصيير و تاريخ إعادة تشغيل مشترك نفس حق مصدر. لذلك، صورة استقبال، حفظ دائم، مزود تحويل و تصيير حاجة التزام دوران نفس عدد واضح دورة الحياة.

نفس صنف منتج عام مرة في تحرير جهاز فوق جهة ضبط مرفق عنصر شريط، لكن تخزين خطة كل لا نفسه. عدة مثل `/var/folders/.../codex-clipboard-*.png` Codex صيغة مسار ملائم دمج بصفة استقبال إدخال وقت مؤقت تخزين موضع، لكن لا يستطيع بصفة حمل دائم رسالة هوية: عملية نظام ممكن حذف ملف، آخر منصة مضيف لا يمكن قراءة ملف، استعادة بعد جلسة أيضا لا يستطيع اعتماد ملف ما زال وجود.

## قرار

لصق لصق أو سحب وضع ضوء شبكة صورة هو Web إدخال منطقة مقابل حمل دائم مرفق عنصر قدرة أول عدد تطبيق مشهد. لم إرسال ملف ما زال هو من عميل يحتفظ مؤقت مسودة مسودة حالة. كل وفير غني محتوى وصل دخول مهايئ كل سوف حل رمز ذاته بروتوكول كتلة، إثبات توجيه قدرة، و في إلحاق رسالة حدث قبل يأخذ كامل صورة دفعة مرة تفويض حمل إعطاء مرفق عنصر خدمة. توليد بنية تحويل صورة إخراج مزود مهايئ في إلحاق متبادل ينبغي مساعدة يد كتلة قبل، أيضا يجب حمل دائم إيداع إخراج. مواصفة مستخدم محتوى و مساعدة يد محتوى فقط يتضمن زاوية لون غير متصل `ImageBlock` مرجع.

رقم واحد إصدار دعم حمل لصق لصق و سحب وضع PNG،JPEG،WebP و GIF، دعم حمل فقط صورة أو خلط دمج نص التوجيه، دعم حمل تصيير تاريخ مستخدم صورة و مساعدة يد صورة، و دعم حمل مفرد ضرب معاينة أصل رسم (عرض و تفاعل دقيق عقدة جزء من[مرفق عنصر عرض مقابل متساو Note](2026-08-11-web-attachment-display-alignment.ar.md) يحل محل). ملف اختيار، عام ملف،PDF، صوت تردد، نظر تردد، صورة نسخ و ذاتي تعريف سياق قائمة مفرد ما زال قسم آخر بصفة لاحق عمل.

### منتج سلوك

- لصق لصق أو سحب وضع واحد ورقة أو كثير ورقة تلقي دعم حمل صورة بعد، نص إطار فوق جهة سوف حسب ترتيب عرض تقليص اختصار رسم، لكن لن إدراج دخول احتلال موضع نص. ملف سحب دخول إدخال منطقة وقت سوف عال مضيء وضع وضع هدف.
- نفس عدد معتاد إقامة `InputBar` سوف في فارغ أبيض جلسة Hero و نشط وثب جلسة تخطيط في تصيير مرفق عنصر شريط. مرفق عنصر شريط لـ فارغ وقت إخفاء، عبر أفقي نحو تمرير تجنب تجنب دعم عرض إدخال منطقة.
- كل تقليص اختصار رسم لـ 64 × 64 مثل عنصر، إزالة حسب زر يقع في بطاقة داخلي، معلق توقف وقت عرض؛ مفرد ضرب فتح مسودة مسودة أصل رسم، فيض خروج استخدام اثنان طرف سهم رأس قلب صفحة بينما غير مرئي تمرير بند.
- نص التوجيه يمكن معا يتضمن نص و صورة، أيضا يمكن فقط يتضمن صورة. لصق لصق صاف نص وقت إبقاء متصفح أصلي سلوك؛ لصق لصق خلط دمج قص لصق لوح محتوى وقت، نص سوف صحيح معتاد إدراج دخول، ملف فإن معا إضافة إلى مرفق عنصر شريط؛ فقط لصق لصق ملف وقت عندئذ منع توقف متصفح افتراضي معالجة. في إدخال منطقة وضع وضع ملف وقت مجموع سوف منع توقف متصفح تنقل، و في محلي تقرير إبلاغ لا تلقي دعم حمل ملف.
- إرسال فشل وقت استعادة كامل نص و صورة مسودة مسودة، لكن لن تغطية طلب طيران سطر خلال إضافة جديدة نص أو صورة. إزالة، إرسال نجاح، جلسة scope تحرير، قد تصيير تاريخ سجل تحرير و تطبيق تحرير كل سوف سحب إلغاء كل منها يحتفظ كائن URL.
- تاريخ مستخدم صورة و مساعدة يد صورة مشترك استخدام واحد `MessageImage` تحكم عنصر. سطر داخل صورة إبقاء ثابت لديه عرض عال مقارنة، لا وضع كبير، و حد في 240 × 240 مثل عنصر حد إطار داخل.
- مفرد ضرب رسالة صورة سوف في لا تجاوز خروج نظر فتحة نموذج حالة إطار في فتح تخزين أصل رسم. حسب Escape، تنشيط إغلاق تحكم عنصر أو تنشيط خلف مشهد منطقة مجال كل سوف إغلاق نموذج حالة إطار و استعادة تركيز نقطة.
- رقم واحد إصدار لا تغطية متصفح سياق قائمة مفرد، أيضا لا توفير واضح صورة نسخ عملية.

### تخزين دورة الحياة و ملكية

حفظ دائم حد هو رسالة يتم قبول، بينما لا هو صورة يتم لصق لصق:

| حالة | سماح يمثل | حمل دائم صفة و ترتيب |
| --- | --- | --- |
| لم إرسال مستخدم مسودة مسودة | متصفح `File` إضافة كائن URL؛ أصلي عميل يمكن استخدام `/var/...` انتظار عملية نظام مؤقت ملف | مؤقت كما من عميل يحتفظ. هو ممكن في إعادة تحميل أو عملية خروج بعد إزالة فقد، أبدا ظهور في جلسة حدث في. |
| قد قبول مستخدم صورة | `DSH_HOME` تحت غير ممكن تغيير كائن إضافة `ImageAttachmentRef` | في `agent.send()` أو `agent.steer()` قدرة كاف إلحاق الذي تابع مستخدم حدث قبل، مضيف إيداع كل ورقة صورة. |
| بنية تحويل نموذج صورة إخراج | `DSH_HOME` تحت غير ممكن تغيير كائن إضافة `ImageAttachmentRef` | مزود مهايئ في إرسال خروج قد إتمام صورة كتلة أو مساعدة يد رسالة حدث قبل إيداع بايت. حدث في منع توقف ظهور مؤقت URL، مسار و base64. |

كل جلسة `InputMachine` حالة في فوري مسودة مسودة جانب حفظ فقط حد وقت التشغيل لديه ترتيب مرفق عنصر معرف رمز. إطار هيكل يحتفظ chat store فقط استقبال مسودة مسودة صاف نص حفظ دائم مرآة مثل،`ConversationController` فإن يحتفظ متبادل ينبغي متصفح مخصص استخدام `File` و كائن URL سجل التسجيل:

```ts
import type { Branded } from '@deepseek-ai/dsh-brand'

type DraftAttachmentId = Branded<'DraftAttachmentId'>

interface ChatStoreState {
  selection: object | null
  draft: string
  view: string | null
}

interface InputState {
  draft: string
  imageIds: readonly DraftAttachmentId[]
}

interface ComposerAttachment {
  kind: 'image'
  id: DraftAttachmentId
  file: File
  previewUrl: string
}
```

هذا واحد تفكيك قسم يأخذ جلسة provide عبر طريق إدخال hook و actions استخدام عمل فوري إدخال منطقة حالة وحيد حجز قراءة مسار، معا تجنب تجنب يأخذ غير ممكن تسلسل تحويل متصفح كائن كتابة دخول حمل دائم JSON. فقط لديه صاف نص مسودة مسودة مرآة مثل استخدام `localStorage`؛ مرفق عنصر معرف رمز، متصفح `File` كائن و كائن URL كل حد تحديد في فوري جلسة إدخال خارج قشرة scope داخل. لم إرسال صورة لذلك لا يمكن عبر إعادة تحميل أو جلسة scope تحرير إبقاء. تبديل Workspace وقت، فقط لديه هدف خارج قشرة قبول كامل صورة دفعة مرة، رسم نص خلط دمج مسودة مسودة عندئذ سوف نقل حركة؛ رفض وقت، نص و صورة كل إبقاء في مصدر خارج قشرة. أصلي عميل يمكن في عملية نظام مؤقت دليل في مؤقت تخزين إدخال، لكن يجب مثل مقابل انتظار متصفح كائن URL واحد مثال مقابل انتظار هذا مسار: لم يعد حاجة وقت حذف، و في رسالة يتم قبول قبل يأخذ بايت نسخ دخول حمل دائم تخزين.

محلي مرفق عنصر خلفية اعتماد مرة تحليل صريح `dshHome`،`$DSH_HOME` و `~/.dsh`. هو يأخذ محتوى بحث عنوان كائن تخزين في `$DSH_HOME/attachments/v1/objects/<prefix>/<sha256>` تحت، و لـ دليل و ملف ضبط فقط كل من يمكن وصول إذن. كل عملية أول مرة لـ بعض عدد home حفظ كائن وقت، كل سوف إنشاء هذا home، و تدريجي درجة تزامن كل أصل أولا دليل بند مباشر حتى نظام الملفات أصل دليل؛ لا يستطيع يأخذ وجود نظر لـ حمل دائم صفة، لأن آخر عدد عملية ممكن ما زال موضع في `mkdir` و أب دليل `fsync` بين. مع بعد، خدمة كتابة و تزامن مؤقت ملف، مجددا بـ أصل فرعي طريقة إصدار، و مقابل إصدار مسار تنفيذ دليل تزامن جعل ذلك حمل دائم (POSIX؛Windows اعتماد نظام الملفات بيانات وصفية سجل) ، بعد عندئذ إرجاع مرجع. محتوى ملخص تحرير رمز في لا نفاذ واضح `sha256:<digest>` معرف رمز في. دقيق دخول سوف تطبيق جهة نحو، حذف بيانات وصفية، تحويل لـ 8-bit sRGB/sRGBA، و في مستقل مقياس قياس و بايت حد أعلى داخل إبقاء عرض عال مقارنة، توليد و مزود غير متصل رئيسي إصدار. قراءة سوف تحقق ملخص، بايت طويل درجة و قد سجل بيانات وصفية. توجيه مخصص استخدام تحديد صفة طلب إصدار مفرد وحيد ذاكرة مؤقتة، كامل سياسة رؤية[موحد واحد صورة رئيسي إصدار، طلب إصدار و مزود ملف](2026-08-20-unified-image-request-pipeline.ar.md).

رقم واحد إصدار لا مقابل تخزين تنفيذ تلقائي حذف. قد إرسال مستخدم صورة و نموذج توليد صورة سوف واحد مباشر إبقاء، بـ توفير تاريخ سجل، استعادة و fork استخدام. حسب مرجع شعور معرفة نفاية قمامة عودة استلام حاجة مفرد وحيد تصميم، لأن فقط حسب وقت تنظيف ممكن حذف ما زال يتم حمل دائم جلسة مرجع بيانات. نشر بايت و مثل عنصر حد هو كتابة وقت دقيق دخول سياسة؛ قراءة وقت سوف تحقق ملخص و قد سجل بيانات وصفية، لكن لا إعادة تطبيق حالي دقيق دخول حد، لذلك استلام ضيق سياسة لن توجيه يؤدي قديم تاريخ سجل بطلان.

### حمل دائم محتوى و نص التوجيه بروتوكول

مرفق عنصر seamعام غير ممكن تغيير صورة كتابة و مرور مرور تحقق قراءة عملية. مواصفة بيانات وصفية لحظة معنى مقارنة عام ملف سجل أكثر ضيق:

```ts
import type { Branded } from '@deepseek-ai/dsh-brand'

type AttachmentId = Branded<'AttachmentId'>

interface ImageAttachmentRef {
  attachmentId: AttachmentId
  mediaType: 'image/png' | 'image/jpeg' | 'image/webp' | 'image/gif'
  bytes: number
  width: number
  height: number
  name?: string
}

interface ImageBlock {
  type: 'image'
  attachment: ImageAttachmentRef
}
```

`ImageBlock` إضافة دخول يمكن دمج توسيع نواة قلب `ContentBlockMap`، في مستخدم محتوى و مساعدة يد محتوى في كل صالح. هو أبدا يحمل base64، كائن URL، نظام الملفات مسار أو مزود يحتفظ تحديد موضع رمز. لذلك، جلسة حدث و غير ممكن تغيير كائن تخزين كاف بـ مشترك نفس إعادة بناء نموذج مرئي تأكيد قطع صورة.LLM مفردات من هذا فقط في نوع طبقة وجه اعتماد مرفق عنصر seam؛ مزود وقت التشغيل اعتماد ما زال من كل مهايئ يحتفظ.

متصفح لا يمكن توليد حمل دائم مرجع، لذلك `session.prompt` قبول نطاق ضيق ضيق استقبال ربط دمج نوع، بينما لا هو مواصفة `ContentBlock[]`:

```ts
export {}

type PromptInputPart =
  | { type: 'text'; text: string }
  | {
      type: 'image'
      mediaType: 'image/png' | 'image/jpeg' | 'image/webp' | 'image/gif'
      data: string
      name?: string
    }
```

Base64 فقط عبر تجاوز مرة بروتوكول حد، و في حفظ دائم بعد إسقاط. كل مدخل كل سوف تحقق مواصفة base64 و إعلان MIME حقل، مجددا استخدام كامل حل رمز دفعة مرة استدعاء `AttachmentStore.saveImages()`. خدمة مسؤول صورة عدد كمية، مجموع بايت عدد، مفرد ورقة صورة بايت عدد، إعلان MIME و كامل حل رمز بعد ضوء شبكة صورة هل متسق، ثابت لديه مقياس قياس، حل رمز مثل عنصر عدد و رئيسي إصدار دقيق تجهيز. هو سوف في إصدار أي عضو قبل فقط دقيق تجهيز و تحقق كل دفعة مرة عضو مرة، لذلك واحد ورقة شاذ شكل صورة لن إنتاج جزء مرجع، كبير رسم أيضا لن في إيداع وقت تكرار حل رمز و تحرير رمز. مع بعد حسب ترتيب إيداع تخزين. إذا لاحق تخزين I/O عملية فشل، استدعاء جهة لن إلحاق نموذج مرئي حدث، أيضا لن استلام إلى جزء مرجع، لكن أولا قبل غير ممكن تغيير محتوى بحث عنوان كائن ممكن حسب قائم تخزين قاعدة إبقاء بلا مرجع حالة. فقط لديه كل ورقة صورة كل نجاح بعد، مدخل عندئذ سوف استخدام مواصفة تحويل نص و حسب بروتوكول ترتيب ترتيب صف حمل دائم صورة كتلة استدعاء agent. فشل وقت لا عام أي مرفق عنصر مسار أو أصلي بايت.

`session.attachment` هو فقط قراءة كما حد تحديد في جلسة أثر مجال طرف نقطة. فقط لديه هذا جلسة في حمل دائم حدث مرجع الذي طلب مرفق عنصر معرف رمز، مضيف عندئذ توفير بايت. جلسة موضع في تصيير حالة وقت، عميل سوف حسب جلسة و مرفق عنصر معرف رمز مقابل تحميل عملية ذهاب إعادة؛ قد تصيير جلسة تحرير وقت سوف سحب إلغاء قد تحليل URL، و في قسم إعداد كائن URL قبل رفض قد بطلان تأخير متأخر تحميل، بـ تجنب قد إزالة جلسة أو قد تحرير خدمة إعادة كتابة ذاكرة مؤقتة.

### نموذج قدرة و مزود سلوك

نموذج دليل بند زيادة اختياري كما يمكن دمج توسيع إدخال نموذج حالة إعلان. نقص قليل إعلان يمثل لم معرفة؛ إعلان وجود لكن لا يحتوي `image`، فإن واضح يمثل لا دعم حمل صورة.

مضيف هو مرجعي قبل وضع فحص نقطة. هو سوف تحليل جلسة الأكثر جديد توجيه إلى مزود و نموذج، و في ناقص وقت اعتماد مرة رجوع إلى agent خيار و مضيف قيمة افتراضية؛ إذا نموذج واضح ترتيب حذف صورة إدخال، مضيف سوف في كتابة مرفق عنصر أو حدث قبل رفض جديد صورة نص التوجيه، عميل فإن استعادة مسودة مسودة. يتضمن صورة نص التوجيه دقيق دخول و نموذج اختيار مشترك استخدام واحد بند تدريجي agent سلسلة سطر سلسلة ([ترتيب قرار](../bug-fix/2026-07-29-atomic-web-image-admission.ar.md)) ، أيضا يشمل لا دخول ترتيب طابور UI مرآة مثل steering. هذا سوف لـ نص التوجيه و تزامن اختيار توفير تحديد ترتيب. صورة دخول حمل دائم تاريخ بعد ما زال اختياري اختيار صاف نص نموذج؛ مشترك LLM وقت التشغيل سوف في هذا طلب في يأخذ إبقاء صورة كتلة استبدال لـ تحديد نص احتلال موضع رمز.`session.updateQueue` فقط قبول نص محتوى، لذلك طابور صف تحرير لا يمكن التفاف مرور دقيق دخول حقن صورة. قدرة لم معرفة وقت متابعة دخول مهايئ قوي صنع فحص، جعل لم استلام تسجيل نموذج معرف رمز ما زال متاح. متصفح سوف في قسم إعداد معاينة URL قبل رفض إعلان لا دعم حمل صورة وسيط جسم نوع، لكن لن لـ نشر حد أو نموذج قدرة إبقاء لقطة. مضيف سوف أصل حسب حالي مفرد ورقة بايت عدد، صورة عدد كمية، مجموع بايت عدد، وسيط جسم نوع، مقياس قياس، مثل عنصر عدد و توجيه نموذج سياسة تحقق كامل دفعة مرة، مجددا كتابة مرفق عنصر أو حدث؛ رفض سوف عبر composer قصير وقت toast عرض.

Pi-AI و مباشر DeepSeek مهايئ كل سوف في طلب وقت تحليل `ctx.attachments`، تمرير عودة تحويل كل إبقاء صورة مرجع، يشمل تضمين طقم في أداة نتيجة في مرجع، و كما فقط لـ إعلان دعم حمل صورة إدخال نموذج توليد مزود أصلي صورة محتوى. اثنان عدد مهايئ كل من حمل دائم رئيسي إصدار طلب نفس عدد تحديد صفة توجيه إصدار.Pi-AI في اعتبار base64 توسيع ورقة طلب ميزانية داخل داخل ربط يحمل هو. داخل وضع DeepSeek توجيه عام نشر `deepseek-v4-flash-vision-exp`، يأخذ كل إبقاء إصدار فوق نقل إلى Files API، و عبر بحث جذب إعادة استخدام، مرور مدة معالجة، محدود قديم قديم ID إعادة محاولة، إعداد مقدار تنظيف و صريح حذف إرسال `file_id` كتلة.DeepSeek صاف نص نموذج، لم إعلان صورة قدرة ذاتي تعريف نموذج و لم صف خروج نفاذ نقل ID إبقاء صاف نص. في طلب وقت تحليل خدمة، يمكن تجنب تجنب Cordis تحميل ترتيب سوف اختياري مرفق عنصر خدمة متاح صفة ثابت تحويل. مهايئ لا نيل عرض مستو أو ساكن صامت قفز مرور إبقاء صورة؛ لا دعم حمل زاوية لون و نموذج سوف بـ نوع تحويل `UNSUPPORTED_CONTENT` فشل.

نواة قلب طبقة دعم حمل بنية تحويل مساعدة يد صورة كتلة، لكن حالي لا يوجد أي إنتاج مزود مسار عبر صورة إخراج إقرار إثبات. لم قدوم أي دعم حمل إخراج مهايئ كل يجب في محدود كبير صغير و وقت سياسة تحت نيل أخذ مزود بايت، عبر نفس عدد مرفق عنصر خدمة تحقق و حفظ دائم بايت، بعد عندئذ قدرة بـ أصل فرعي طريقة إصدار `ImageBlock`. مساعدة يد Markdown في URL ما زال هو نص، أبدا تلقائي تحت تحميل.

مزود غير متصل token تقدير حساب لن أصل حسب صورة مقياس قياس تخمين قياس نظر شعور تحديد قيمة؛ مزود إرجاع استخدام كمية ما زال هو مرجعي قيمة. فقط لديه إعداد تأكيد قطع توجيه و مرفق عنصر نشر يمكن قبول صورة وقت،ACP(Agent Client Protocol) عندئذ عام نشر صورة نص التوجيه قدرة؛ هو سوف في إصدار مستخدم حدث قبل حفظ دائم داخل ربط إدخال، و إعادة قراءة قد إيداع مساعدة يد صورة مرجع قدوم إرسال أصلي ACP صورة تحديث.MCP لـ برنامج تحويل استدعاء جهة إبقاء مواصفة أصلي كتلة، معا يأخذ قد دقيق دخول صورة إسقاط لـ حمل دائم نواة قلب كتلة؛PTC mode سوف يأخذ أي قد تسوية كما يحتوي صورة فرعي نتيجة مرور خارج طبقة نتيجة تحويل تشغيل لـ حمل مصدر ملكية كما كتابة سجل سياق.

ضغط سوف يأخذ اختيار تحديد جلسة بادئة و منها صورة مرجع إعادة تشغيل إلى قد إعداد ملخص توليد مسار. دعم حمل نظر شعور مسار استخدام و عادي جولة نفسه تحديد صفة طلب إصدار. صاف نص مسار استقبال و أخرى LLM طلب نفسه تحديد صفة مرفق عنصر احتلال موضع رمز. دمج صار فحص نقطة ما زال فقط يتضمن نص،`compaction-basic` سوف بـ `UNSUPPORTED_CONTENT` رفض يتضمن صورة ملخص إخراج.

### تاريخ تصيير و أصل رسم معاينة

تاريخ سجل طي سوف في مستخدم رسالة و مساعدة يد رسالة في إبقاء `ImageBlock`. مستخدم صورة في نص فوق جهة اعتماد ذيل طرف مقابل متساو؛ مساعدة يد صورة فإن إبقاء في اعتماد قبل طرف سرد وصف تدفق في أصل محتوى كتلة موضع.`MessageImage` أصل حسب سجل مقياس قياس إرسال توليد مستقر سطر داخل حد إطار، عبر جلسة تخويل تحميل جهاز تحليل بايت، استخدام `object-fit: contain`، و سوف كائن ناقص أو ضرر تالف تحويل لـ يمكن إعادة محاولة خطأ تحكم عنصر.

إدخال منطقة تقليص اختصار رسم و كل `MessageImage` كل منها يحتفظ مؤقت أصل رسم معاينة حالة، و استدعاء نفس عدد صاف `ImageLightbox`. نموذج حالة إطار استخدام قد تحليل أصلي كائن URL، فقط حد عرض مقياس قياس؛ هو سوف تجمع تركيز إغلاق تحكم عنصر، و في إغلاق وقت يأخذ تركيز نقطة استعادة إلى أولا قبل هدف.

### حد و معلومة مهمة حد

رقم واحد إصدار فقط قبول PNG،JPEG،WebP و GIF. لا قبول SVG و بعيد مسار URL. مصدر ملف إدخال افتراضي حد لـ كل ورقة صورة 32 MiB، كل بند رسالة 20 ورقة صورة و 100 MiB صورة مجموع بايت عدد، كل ورقة صورة واحد مليار حل رمز مثل عنصر، و مهمة واحد حافة 16384px. و مزود غير متصل رئيسي إصدار افتراضي طويل حافة 2048px، مستقل أمان حد أعلى 4 MiB. مزود طلب مثل عنصر و تحرير رمز بايت حد أعلى هو مفرد وحيد توجيه سياسة. هذه مع نشر تغير حد يخص مرور مرور تحقق خلفية إعداد، و في حفظ دائم أو طلب إرسال قبل قوي صنع تنفيذ. عميل اتصال تحميل جسم لـ كل API طلب ضبط مستقل كما يمكن إعداد `maxRequestBodyBytes` حد أعلى، افتراضي 160 MiB؛ إذا هذا حد أعلى لا يمكن سعة قبول مصدر ملف مجموع كمية حد مرور base64 و طلب غلاف تركيب تمدد انتفاخ بعد كبير صغير، تحميل حينئذ سوف فشل. لم إعلان طويل درجة طلب جسم في تجاوز مرور حد أعلى وقت أي يتم رفض، بينما لا هو أولا قراءة تمام مجددا رفض.

صيغة خطأ base64، لا دعم حمل أو لا مطابقة وسيط جسم، قطع قطع صورة بيانات، تجاوز خروج بايت حد، تجاوز خروج صورة عدد كمية، تجاوز خروج مثل عنصر حد، تجاوز خروج مفرد حافة مقياس قياس حد، كائن ناقص و كامل صفة لا مطابقة كل سوف إرجاع مستقر بنية تحويل خطأ. أصلي ملف اسم فقط إبقاء لأجل عرض نهاية مقطع، تحكم محرف سوف يتم إزالة، و كما أي محلي مسار كل لن كتابة سجل أو إرجاع متصفح.

### تنفيذ

قد تنفيذ قدرة يشمل فقط دقيق تجهيز مرة مشترك دفعة كمية دقيق دخول، و مزود غير متصل رئيسي إصدار، تحديد صفة طلب إصدار،DeepSeek Files إعادة استخدام، مستقر قطع قص جملة مقبض، زاوية لون غير متصل صورة كتلة،Pi-AI و DeepSeek إدخال تحويل،Web/ACP/MCP حفظ دائم ترتيب،Web فوق نقل و قراءة بروتوكول، شرط صيغة ACP صورة دعم حمل، حمل حمل دائم صورة إسقاط بلا ضرر MCP نتيجة،PTC mode وفير غني نتيجة تحويل إرسال، محدود Web طلب، مسودة مسودة و تاريخ صورة UI، ضغط معالجة، و تجميع بعد بلا مفتاح تغطية.

مسبق إصدار نص التوجيه بروتوكول لا حاجة توافق حزمة تركيب طبقة؛ جذب دخول متبادل ينبغي قطع قطعة وقت سوف معا تعديل كل استدعاء نقطة و fixture.

## سبق اعتبار بديل خطة

### سوف كل ورقة لصق لصق صورة إبقاء في `/var` أو أخرى مؤقت دليل في

مؤقت تخزين ملائم دمج في إرسال قبل استخدام، أيضا ملائم دمج عبر عملية نظام استقبال قص لصق لوح ملف أصلي عميل. لكن هو لا ملائم دمج في رسالة يتم قبول بعد متابعة استخدام: تنظيف لا في harness تحكم نطاق داخل، مسار بسبب مضيف بينما مختلف، استعادة أو fork بعد جلسة أيضا ممكن مقارنة ملف وجود نيل أكثر دائم. رفع سجل سماح مؤقت مؤقت تخزين، لكن سوف في إلحاق حدث قبل سوف قد قبول بايت نسخ دخول `DSH_HOME`.

### لصق لصق أو سحب وضع بعد قيام أي حفظ دائم

قيام أي حفظ دائم يمكن يجعل مسودة مسودة في إعادة تحميل بعد متابعة وجود، لكن سوف في جلسة أو رسالة يحتفظ كائن قبل حينئذ إنشاء حمل دائم كائن، لذلك يجب تعريف إعداد مقدار، متروك إبقاء كائن دورة الحياة و تنظيف سياسة. رقم واحد إصدار إبقاء لم إرسال مسودة مسودة لـ مؤقت حالة، و يأخذ إرسال يتم قبول بصفة حمل دائم صفة حد.

### في رسالة و جلسة سجل في داخل ربط base64

هذا نوع طريقة سوف في RPC، حدث، تاريخ قسم صفحة،fork، ضغط و متصفح تخزين في نسخ اثنان دخول صنع بيانات، أيضا سوف إغراء جعل token حساب كمية يأخذ تحرير رمز نص عند صار نموذج نص. مفرد واحد غير ممكن تغيير كائن إعداد دمج صغير نوع مرجع، يمكن يجعل حمل دائم يمثل إبقاء محدود.

### استخدام متصفح كائن URL، محلي مسار أو مزود URL بصفة مواصفة محتوى

كائن URL سوف مع وثيقة بطلان، محلي مسار غير ممكن نقل غرس، مزود URL فإن ممكن مرور مدة، تتبع أثر فحص نظر من أو كشف اعتماد. هو جمع فقط قدرة بصفة مؤقت نقل أو معاينة دقيق عقدة وجود.

### استخدام واحد عام `AttachmentBlock` يمثل صورة، ملف، صوت تردد و نظر تردد

إدخال منطقة عرض يمكن استخدام عام مرفق عنصر شريط، لكن مزود دلالة أخذ قرار في أداة جسم نموذج حالة. صورة هو أصلي كثير نموذج حالة إدخال؛PDF ممكن هو مزود ملف أو رفع أخذ بعد نص؛ نظر تردد ممكن من نموذج أصلي دعم حمل، سحب لقطة معالجة أو لا تلقي دعم حمل. خاص تحديد `ImageBlock` سوف إجبار جعل كل مستهلك واضح معالجة أو رفض هذا نموذج حالة.

### اعتماد UI قدرة فحص أو ساكن صامت مرور ترشيح صورة

UI حالة ممكن قديم قديم، أيضا لا يمكن حفظ حماية مباشر SDK،ACP، إعادة تشغيل أو لم استلام تسجيل نموذج مسار. ساكن صامت مرور ترشيح سوف تغيير مستخدم معنى رسم. مزود قوي صنع فحص ما زال هو مطلوب بند،UI فحص فإن هو اختياري رفع قبل عكس تغذية.

### في نواة قلب محتوى مفردات لـ فوق إضافة عام RichContent خدمة

لا إعطاء اعتماد، لأن نواة قلب قد يملك زاوية لون غير متصل `ContentBlock` مفردات و مرفق عنصر مرجع. ثاني طقم عام خدمة سوف تكرار ترتيب، قدرة، سجل و دورة الحياة دلالة، معا كل بروتوكول مهايئ ما زال يحتاج تحليل ذاته بروتوكول. محيط التفاف قائم نواة قلب بناء نطاق ضيق ضيق صورة مهايئ، يمكن إبقاء ملكية صاف واضح، و يجعل صوت تردد/مورد في تأكيد لديه حاجة وقت بناء قيام ذاتي ذات دورة الحياة عقد نحو.

### يأخذ MCP نتيجة مواصفة تحويل لـ نواة قلب محتوى، و سوف ذلك بصفة مواصفة أداة قيمة

لا إعطاء اعتماد، لأن PTC mode و برنامج تحويل استدعاء جهة حاجة كامل MCP JSON كتلة و اختياري `structuredContent`؛ استخدام Native إسقاط استبدال هذا قيمة سوف يجعل جسر وصل لديه ضرر.MCP إبقاء بروتوكول قيمة، و آخر سطر دقيق تجهيز نموذج إسقاط؛ نهائي post-execute سياسة ما زال أداة لديه مرجعي صفة.

### في تزامن إخراج مصير في تنفيذ مرفق عنصر قراءة كتابة

لا إعطاء اعتماد، لأن أداة مصير يجب صاف صاف، تزامن كما يمكن إعادة تشغيل.MCP في مختلف خطوة تنفيذ خلال دقيق تجهيز صورة إسقاط، فقط في سجل التسجيل نهائي تحويل حد تثبيت؛ACP في ذاتي ذات نقل دورة الحياة في تنفيذ مختلف خطوة دقيق دخول و إخراج تحويل.PTC mode تحويل إرسال مراقبة قد تسوية نهائي محتوى، بينما لا هو يجعل كل صورة أداة كل منها معالجة خاص أب token سلوك.

## اختبار

- تخزين اختبار تغطية محتوى بحث عنوان ذهاب إعادة، خاص إذن، دقيق دخول فشل، كائن ضرر تالف أو ناقص وقت فشل، و استلام ضيق نشر حد بعد قراءة تاريخ بيانات.
- مضيف و بروتوكول اختبار تغطية أولا حفظ دائم مجددا إلحاق حدث ترتيب، سجل في لا يحتوي base64، جلسة أثر مجال تخويل، قدرة رفض، فوق نقل حد، كبير صغير تلقي حد HTTP طلب جسم، صورة دقيق دخول و نموذج اختيار ترتيب ترتيب، فقط نص طابور صف تحرير، و صاف نص طلب إسقاط.
- عميل اختبار وحدة تغطية لصق لصق و سحب وضع، خلط دمج قص لصق لوح نص، فقط صورة إرسال، مسودة مسودة استعادة، ترتيب، مسودة مسودة، جلسة أثر مجال و تطبيق طبقة درجة كائن URL تنظيف، و واحد بند في تحرير بعد عندئذ إتمام تأخير متأخر تاريخ قراءة؛keyless تجميع بعد بناء ناتج عبر طريق (`apps/web/tests/image-display.expected.e2e.ts`،`pnpm run test:web`) تغطية مرور تخويل مرفق عنصر توجيه تصيير تاريخ مستخدم و مساعدة يد صورة رسم ممر، أصل رسم lightbox، و composer لصق لصق تقليص اختصار رسم بند.
- مهايئ و ضغط اختبار تغطية تحديد صفة Pi-AI طلب إصدار،DeepSeek Files فوق نقل و إعادة استخدام، قديم قديم ID استعادة، صاف نص إسقاط، تمرير عودة تضمين طقم في أداة نتيجة في صورة، مشترك ملخص طلب إصدار، و واضح رفض صورة إخراج.
- مرفق عنصر،MCP،ACP و PTC mode اختبار تغطية كتابة قبل تحقق الكل عضو، رسم نص خلط دمج ترتيب، حمل دائم حدث لا يحتوي داخل ربط base64، تأكيد قطع توجيه قدرة بوابة، واضح لا دعم حمل محتوى تشخيص،post-execute استبدال/منع توقف أولوية درجة، دقيق دخول خلال إلغاء، مرور مرور تحقق مساعدة يد صورة تسليم، و عام تضمين طقم صورة تحويل إرسال. تجميع بعد بلا مفتاح ACP لقطة إرسال حقيقي داخل ربط PNG، و في جلسة سجل في فقط ثابت ذلك حمل دائم مرجع.
- حاجة اعتماد فعلي API اختبار سوف تغطية إعداد Anthropic توجيه و داخل وضع `deepseek-official` Files مسار.DeepSeek اختبار لا استخدام ذاتي تعريف مزود بند.
- حالي إنتاج مهايئ تجميع دمج لا يوجد مرور مرور إقرار إثبات صورة إخراج توجيه؛ إخراج مزود إقرار إثبات ما زال لا في رقم واحد إصدار نطاق داخل.

## عاقبة

- حمل دائم تخزين سوف في لا يوجد نفاية قمامة عودة استلام وقت حمل متابعة زيادة طويل. رقم واحد إصدار اختيار إعادة تشغيل أمان، بينما لا هو مرور مبكر حذف.
- كائن ناقص أو ضرر تالف سوف يجعل نموذج طلب لا يمكن دقيق إعادة بناء. واضح فشل يمكن إبقاء كامل صفة، لكن في إصلاح قبل ممكن منع توقف هذا جلسة متابعة تشغيل.
- JSON-RPC base64 سوف زيادة فوق نقل داخل تخزين، و حمل قدوم نحو ثلاثة قسم لـ واحد تحرير رمز فتح إلغاء. رقم واحد إصدار حد يمكن قيد فتح إلغاء؛ أكثر كبير وسيط جسم حاجة تدفق صيغة نقل أو اثنان دخول صنع نقل بروتوكول.
- لم إرسال صورة لا يمكن عبر إعادة تحميل إبقاء. حمل دائم مسودة مسودة حاجة إعداد مقدار و متروك إبقاء كائن تنظيف، بينما لا هو خفي صيغة إعادة استخدام رسالة تخزين.
- أصل رسم معاينة حل رمز مثل عنصر كثير في سطر داخل تحكم عنصر عرض مثل عنصر. مثل عنصر حد، مرة فقط فتح واحد معاينة و كائن URL تحرير يمكن قيد لكن لا يمكن إزالة حذف متصفح لحظة وقت داخل تخزين احتلال استخدام.
- قدرة بيانات وصفية ممكن ناقص أو قديم قديم. مضيف قبل وضع فحص يمكن تعديل حسن عكس تغذية، مهايئ قوي صنع فحص ما زال هو مرجعي نتيجة.
- لم قدوم إخراج مزود ممكن حاجة مرور مرور هوية إقرار إثبات تحت تحميل، مساعدة يد صورة عندئذ قدرة إتمام، هذا سوف زيادة تأخير متأخر و جديد لذا عائق نقطة. أولا حفظ دائم مجددا إلحاق حدث ترتيب أولوية حفظ عائق إعادة تشغيل كامل صفة.
- ملف اختيار، عام ملف و PDF، صوت تردد و نظر تردد، حمل دائم مسودة مسودة مؤقت تخزين، صورة نسخ، ذاتي تعريف سياق قائمة مفرد، إخراج مزود إقرار إثبات و حسب مرجع شعور معرفة نفاية قمامة عودة استلام ما زال هو متبادل متبادل مستقل تصميم.
