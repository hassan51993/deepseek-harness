# Agent Note: في أداة استدعاء في استخدام نظام تطبيق فتح ملف

Status: implemented
Archived: 2026-09-04

[English](2026-07-28-tool-call-file-open-in-os.md) | العربية

## مشكلة

حديث يوم أداة سطر يأخذ كامل سطر ملخص عند عمل نقر هدف، نقر بعد فتح يمين جانب details وجه لوح، و حمل لديه كامل سطر معلق توقف خلف مشهد. مقابل نظام الملفات أداة بينما قول، لديه استخدام حركة عمل هو استخدام عملية نظام افتراضي تطبيق فتح الذي تعلق ملف، بينما لا هو في جانب شريط داخل فحص نظر أصلي أداة تحميل حمل.

## قرار

ملف أداة مسار ملخص (`read`/`write`/`edit` معامل في `path` أو `file_path`) تصيير لـ ساكن توقف حالة تحت أي حمل تحت تخطيط خط رابط، و استخدام pointer ضوء علامة. نقر مسار سوف مرور حديث يوم عرض `openFile` injection استدعاء `session/openWorkspacePath`؛ حديث يوم عرض سوف في هدف Session cwd معروف وقت حسب هذا تحليل متبادل مقابل مسار. حمل ملف رابط سطر إغلاق معامل توسيع (يسار جانب رسم علامة غير ممكن نقطة) ؛ أداة سطر (يحتوي bash و todo تسجيل) ذهاب إسقاط كامل سطر نقر، كامل سطر معلق توقف قاع لون، و نقر فتح details يد اتجاه.details وجه لوح و ذلك inject وجه ما زال إبقاء توفير برنامج تحويل اختيار؛ أداة سطر لم يعد قيادة هو جمع.

`session/openWorkspacePath` استخدام مرور مرور إقرار إثبات Remote carrier، بينما منتج UI فقط في loopback صفحة كما `session/canOpenWorkspacePath` نتيجة لـ true وقت توفير هذا يد اتجاه. منصة مهايئ لا مرور shell فتح:macOS لـ `open`،Windows لـ PowerShell `Invoke-Item`، طاولة وجه Linux لـ `xdg-open`؛ متصفح يمكن تصيير وثيقة سوف في macOS و طاولة وجه Linux فوق أولوية استخدام إشارة تحديد افتراضي متصفح. كل إدارة Node سوف WSL تقرير إبلاغ لـ `linux`،WSL ما زال هو واحد نوع مستقل مضيف شكل: مهايئ أصل حسب ذلك بيئة أو Microsoft داخل نواة release تعرف آخر هو، استخدام `wslpath -w` تحويل Linux مسار، و سوف الذي نيل Windows/UNC مسار تسليم إعطاء نفس PowerShell تسليم وصل. فتح جهاز منصة معلومة و أمر تشغيل جهاز يمكن في اختبار في حقن. فقط يحتوي URL read معامل (`web_fetch`) لا هو ملف رابط.

## اعتبار مرور بديل خطة

- إبقاء كامل سطر نقر فتح details، آخر إضافة ملف مدخل — مرفوض؛ منتج اشتراط استخدام ملف رابط استبدال كامل سطر يد اتجاه.
- في تطبيق داخل معاينة ملف — مرفوض؛ اشتراط هو عملية نظام افتراضي تطبيق.
- سوف WSL عند عمل طاولة وجه Linux — مرفوض؛WSL عملية تقرير إبلاغ `linux`، لكن Linux طاولة وجه ملف صلة ربط و غير لا بد لديه، بينما ذلك معتاد قاعدة مستخدم طاولة وجه و متصفح يقع في Windows فوق.
- إعادة استخدام `host.pickDirectory` مهلة إعفاء تجنب — لا لا بد يلزم؛ فتح مسار تسليم وصل في معتاد قاعدة واحد عنصر قطع توقف وقت داخل يكفي إتمام.

## عاقبة

نقر أداة سطر في ملف مسار سوف في مضيف فوق فتح هذا مسار. غير ملف أداة سطر فقط هو غير ممكن تفاعل ملخص (سطر داخل قد لديه توسيع فتح صلة ما زال إبقاء).Client في غير loopback صفحة لا توفير ملف فتح يد اتجاه؛ كل مرة قد كشف Host استدعاء ما زال اشتراط متصفح جلسة.Host أو عملية نظام رفض من حديث يوم عرض يملك: هو عرض رمي خروج سبب، و مقابل نفس مسار توفير إعادة محاولة ([فتح فشل](../bug-fix/2026-08-18-tool-row-file-open-failure.zh.md)).

## ريح خطر

- لا يوجد `xdg-open` طاولة وجه Linux مضيف، و Windows متبادل عملية (`wslpath` إضافة `powershell.exe`) غير ممكن استخدام WSL مضيف، سوف جعل RPC فشل؛ حديث يوم عرض عرض هذا Host خطأ و توفير إعادة محاولة.
- لا يوجد جلسة cwd وقت متبادل مقابل مسار سوف أصل مثال تحويل إرسال، ممكن في مضيف جانب فشل.
