# Agent Note: Web رسالة IconActions و وقت ساعة

Status: implemented
Archived: 2026-08-07

[English](2026-07-29-web-message-icon-actions-and-clock.md) | العربية

## مشكلة

Web حديث يوم مستخدم هواء فقاعة قد لديه نسخ، فرع، تحرير IconActions، لكن لا يوجد وقت ساعة. قد تحديد مسودة assistant سرد وصف تحت جهة تماما لا يوجد عملية شريط، كل إدارة harness تصميم مسودة في عودة جواب انتهاء بعد عرض نسخ، فرع، وقت ساعة. تدفق صيغة عودة تكرار لا نيل في تدريجي token إخراج خلال وميض الآن هذا عملية شريط. مرور memo أفضل تحويل سطر في عبر ظهر ليل وقت ما زال إبقاء مستقر props، لذلك مرة صفة `Date.now()` سوف يجعل أمس يوم رسالة واحد مباشر بطاقة في `HH:mm`.

## قرار

**مستخدم هواء فقاعة في قائم IconActions سطر فتح رأس إضافة شعور معرفة يوم مدة محلي وقت ساعة؛ كل جولة في الأكثر بعد واحد بند حمل text محتوى assistant في متن تحت إلحاق حمل `margin-top: 16px` نسخ، فرع، وقت ساعة؛ اثنان حافة فقط يلزم تركيب حينئذ إبقاء مرئي، و في تحت واحد محلي ظهر ليل إعادة صيغة تحويل.**

assistant واحد جانب مقعد موضع من[قد إتمام جولة قرار](../bug-fix/2026-08-05-turn-tail-actions-require-a-completed-turn.md) استلام ضيق: فقط لديه وجود `turn/end` جولة عندئذ منح إعطاء هذا سطر، ما زال في إنتاج خروج خطوة جولة لا يأخذ هذا سطر تسليم إعطاء أي عقدة.user واحد جانب فرع تحكم عنصر يتم [user هواء فقاعة فرع إزالة قرار](../simplification/2026-08-06-user-bubbles-drop-the-branch-action.md) مباشر إزالة؛user سطر IconActions فقط لديه وقت ساعة و نسخ.

اثنان حافة كل عبر `formatMessageClock` صيغة تحويل `node.time`: نفس يوم تاريخ يوم → `HH:mm`، نفس سنة أكثر مبكر → `MشهرDيوم HH:mm`، عبر سنة → `YYYYسنةMشهرDيوم HH:mm`.`useCalendarDay` هو مكون محلي يوم لحظة درجة (تحديد وقت إلى تحت واحد محلي ظهر ليل) ، لذلك memo سطر في يوم تاريخ يوم تغير وقت سوف إعادة تصيير، كما لا إضافة جديدة إطار هيكل خطاف.`MessageItem` يأخذ وسم وضع في نسخ قبل (figma `388:20051`).`ChatView` عبر `assistantActionsSeqs` دفع توجيه جولة ذيل جزء seq، و لا لـ جولة في بين محتوى نقل دخول `time`؛`AssistantMarkdown` يأخذ هذا سطر وضع في فرع بعد (figma `43:32997`) ، كما فقط في `streaming` لـ false، معروف حدث وقت، كما عقدة يحتوي غير فارغ text محتوى وقت تصيير. صاف Think عقدة، جولة في بين سرد وصف و تدفق صيغة ذيل جزء حذف هذا سطر. نسخ كتابة تجميع وصل بعد text كتلة. اثنان نوع رسالة سطر كل يأخذ ذاتي ذات حدث `seq` تسليم إعطاء نفس عدد fork عودة ضبط؛ حقيقي mutation عقد نحو من [Web session fork عملية](2026-07-27-web-session-fork-actions.md) تعريف. قص لصق لوح كتابة و وقت ساعة مساعد مساعدة دالة وضع في `message-chrome.ts`. تجميع بعد واجهة من `apps/web/tests/message-actions.e2e.ts`(بارد seed تاريخ + aria golden) تثبيت إقامة؛aria عودة واحد تحويل يأخذ كل نوع وقت ساعة شكل طي لـ `{{clock}}`.

## سبق اعتبار خطة

**في تدفق صيغة مرور مسار في عرض assistant IconActions.** مرفوض: يحتاج طلب هو إخراج إتمام بعد عندئذ عرض هذا سطر؛ في طريق chrome سوف وميض وميض، و إغراء جعل نسخ نصف قطع عودة جواب.

**إعطاء كل قد تحديد مسودة assistant عقدة (يحتوي صاف Think) كل تعليق IconActions.** مرفوض: لا يوجد text محتوى وقت نسخ لا يوجد يمكن كتابة محتوى، كما في كل واحد خطوة/Think تحت تكرار chrome سوف ضرب فوضى مسار؛ فقط لديه محتوى إخراج يملك هذا مقعد موضع.

**إعطاء كثير خطوة جولة في كل واحد بند حمل text محتوى assistant كل تعليق IconActions.** مرفوض: جولة في بين سرد وصف (أداة استدعاء قبل text) لا هو قد تحديد مسودة جواب سجل؛ في كل واحد خطوة تحت تكرار نسخ، فرع، وقت ساعة سوف ضرب فوضى مسار. فقط لديه هذا جولة في الأكثر بعد واحد بند محتوى assistant يملك هذا مقعد موضع.

**في أداة تجهيز hover قدرة إشارة إبرة فوق استخدام hover عندئذ كشف عرض عملية سطر.** مرفوض: سطر واحد حالما وجود حينئذ ينبغي إبقاء يمكن اكتشاف؛ استخدام opacity إخفاء سعة سهل تسرب نظر، كما حاجة أب درجة hover اختيار جهاز تكرار تركيب باب تحكم.

**من IconActions قرار معا تعريف session fork دلالة.** مرفوض: هذا قلم تسجيل فقط يملك رسالة chrome، وقت ساعة و تركيب باب تحكم؛ حد اختيار، فشل سلوك و تبديل دلالة يخص مستقل [Web session fork عملية](2026-07-27-web-session-fork-actions.md) ، تجنب تجنب عرض مكون يصبح session mutation ثاني صحيح بيت.

**عبر chat store أو inject خطاف إصدار يوم تاريخ يوم.** مرفوض: يوم لحظة درجة فقط هو عرض طبقة محلي حالة، لا يوجد عبر مدخل مستهلك؛ مكون محلي timeout رمز دمج «سلوك خطاف يمكن يملك لا حجز قراءة خارجي مصدر حالة» هذا واحد عميل قاعدة.

## عاقبة

كل جولة في الأكثر بعد واحد بند قد تحديد مسودة محتوى عودة جواب في سطر تركيب بعد قيام لحظة كشف نسخ، فرع و حدث وقت ساعة؛ جولة في بين محتوى و صاف Think عقدة لا حمل chrome. مستخدم و assistant وقت ساعة مشترك استخدام نفس طقم عبر يوم، عبر سنة إضافة عرض قاعدة، و في ظهر ليل بعد بلا حاجة رسالة تغيير يكفي تحديث جديد. تدريجي رسالة قسم صفحة ما زال هو حزمة README في سجل مؤقت مؤقت footer وظيفة موضع. حزمة درجة اختبار تثبيت إقامة ثلاثة نوع وقت ساعة شكل، ظهر ليل إضافة عرض،assistant فقط محتوى باب تحكم، جولة ذيل جزء seq باب تحكم، و user/assistant فرع حسب زر كل منها نقل تمرير حدث `seq`؛Web e2e مشهد تثبيت إقامة تجميع بعد IconActions chrome.
