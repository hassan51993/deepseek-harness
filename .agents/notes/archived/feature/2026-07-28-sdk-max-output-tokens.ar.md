# Agent Note: SDK الأكثر كبير إخراج token عدد

Status: implemented
Archived: 2026-09-04

[English](2026-07-28-sdk-max-output-tokens.md) | العربية

## مشكلة

Python و TypeScript SDK يمكن اختيار مزود و نموذج، لكن لا يمكن حد محادثة نموذج إخراج. أي جعل تقييم قياس مضيف اشتراط ثابت إخراج ميزانية، وقت التشغيل ما زال سوف حذف `GenerateOptions.maxTokens`، من مزود قيمة افتراضية تحكم.`compaction-basic.maxTokens` فقط حد ضغط ملخص استدعاء، لا يستطيع تحمل تحمل هذا واحد مسؤولية.

## قرار

عال طبقة SDK عام واحد اختياري عملية درجة إخراج حد أعلى:Python تسمية لـ `max_tokens`،TypeScript تسمية لـ `maxTokens`، مشترك `initialize` بروتوكول تحميل حمل استخدام `maxTokens`.JSON-RPC خدمة طرف رفض أي لا يخص صحيح أمان كامل عدد قيمة، و سوف عبر تحقق حد أعلى و مزود/نموذج توجيه واحد نفس حفظ.

كل من SDK إنشاء أصل Agent كل عبر `AgentOptions.maxTokens` نيل نيل هذا حد أعلى.agent loop(ذكي جسم حلقة) سوف هو وضع دخول ابتدائي `LlmCallConfig`؛ نهائي استدعاء دقيق تجهيز سوف إبقاء صريح قيمة، أو ملء دخول تأكيد قطع نموذج مهايئ قيمة افتراضية، مجددا سوف توليد فاعلية حد أعلى سجل إلى طلب header، و من هذا حفظ دائم header إعادة بناء كل مرة قسم إرسال محادثة طلب. لذلك، حذف SDK خيار وقت سوف تطبيق الذي اختيار مهايئ أو مزود توجيه قيمة افتراضية.

عملية داخل subagent وراثة أب درجة مزود، نموذج و إخراج حد أعلى. صريح `SubagentStartRequest.agentOptions.maxTokens`(يشمل عبر `dsh-tool-subagent` إعداد قيمة) سوف تغطية هذا فرعي درجة و ذلك بعد بديل وراثة قيمة.`subagent-dsh-sdk` لـ كل مرة تشغيل يحتفظ مستقل وقت التشغيل: طلب `maxTokens` سوف تغطية اختياري نسخة قيمة افتراضية، تحليل بعد حد أعلى مجددا مرور مرور هذا فرعي وقت التشغيل ذاتي ذات SDK إمساك يد.

ضغط، جلسة عنوان توليد، شبكة صفحة بحث و أخرى مساعد مساعدة استدعاء متابعة استخدام كل منها يحتفظ مستقل إخراج حد أعلى.`maxTokensAsSuccess` ما زال فقط مسؤول نتيجة خريطة، لن ضبط أو تغيير حد أعلى.

## اعتبار مرور بديل خطة

**فقط ضبط مهايئ بيئة متغير.** تسلسل تحويل جهاز خاص رجوع فقط ملائم لأجل DeepSeek مهايئ، لن ظهور في جلسة طلب header في، مقابل يتم اعتراض قطع طلب أو أخرى مهايئ بلا فاعلية، أيضا سعة سهل و مزود قيمة افتراضية خلط خلط. مهايئ يحتفظ قيمة افتراضية يمكن تعديل لـ عبر تأكيد قطع نموذج بيانات وصفية عام، و في سجل قبل ملء دخول مزود غير متصل طلب إعداد.

**في كل `session/prompt` فوق زيادة `maxTokens`.** حسب جولة تعديل سوف توسيع ملء بروتوكول صيغة، و جذب دخول حالي تقييم قياس حالة استخدام لا حاجة طلب إعداد تحويل. وقت التشغيل ابتدائي تحويل خيار يمكن يجعل واحد SDK عملية في كل جلسة يملك نفسه، يمكن إعادة الآن ميزانية.

**إعادة استخدام `compaction-basic.maxTokens`.** ضغط قيمة تحكم ملخص توليد، بينما غير عادي محادثة طلب. مشترك استخدام سوف اقتران دمج اثنان صنف مختلف token ميزانية، ضبط كامل واحد جهة وقت سوف ساكن صامت تغيير آخر جهة.

## عاقبة

SDK استدعاء جهة بلا حاجة تعديل Cordis تركيب يكفي حد نموذج إخراج، مباشر إنشاء Agent أيضا استخدام نفس طقم مرور مرور تحقق `AgentOptions` اتفاق. هذا حد أعلى في حفظ دائم طلب header في مرئي، و بـ `GenerateOptions.maxTokens` وصول مزود مهايئ؛DeepSeek تسلسل تحويل سوف سوف ذلك خريطة لـ `max_tokens`.

واحد SDK وقت التشغيل فقط لديه واحد افتراضي حد أعلى. حاجة مختلف حد أعلى استدعاء جهة ينبغي تشغيل مستقل وقت التشغيل نسخة، أو استخدام إعلان `agentOptions` subagent مزود؛DSH SDK سوف ذاتي لكن أرض لـ كل مرة فرعي درجة تشغيل إنشاء واحد هذا مثال وقت التشغيل. بلوغ إلى حد أعلى وقت ما زال إنتاج قائم `max-tokens` إيقاف سبب؛ سوف ذلك خريطة لـ `ok` أيضا هو `error` ما زال من نشر سياسة قرار.
