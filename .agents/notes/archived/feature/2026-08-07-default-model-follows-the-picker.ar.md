# Agent Note: افتراضي نموذج تتبع مع اختيار جهاز

Status: implemented
Archived: 2026-09-04

[English](2026-08-07-default-model-follows-the-picker.md) | العربية

## مشكلة

جلسة نموذج اختيار جهاز و نشر قيمة افتراضية هو نفس بند انحراف جيد اثنان عدد طبقة مرة. إذا اختيار جهاز فقط أثر ذلك الذي في جلسة، تحت واحد فارغ أبيض جلسة ممكن اختيار مختلف نموذج، مستخدم لكن لا يوجد طريق مسار جعل قيمة افتراضية و اختيار جهاز متسق. إذا قيمة افتراضية يقع في Host شبكة صلة داخلي، مباشر إنشاء Agent مدخل فقط لديه اعتماد Host أو نسخ حالة عندئذ قدرة مشترك هو.

دفع إدارة قوي درجة جعل حفظ دائم شكل تغيير نيل إعادة يلزم: لا يحتوي قوي درجة نموذج اختيار يجب صاف حذف قد تخزين قوي درجة، لا فإن تحت واحد Agent ممكن سوف اعتماد الذي اختيار نموذج لا قبول قوي درجة.

## قرار

`AgentDefaultModelConfig` توفير `ctx.agentDefaultModel`، و يأخذ `{provider, model, reasoningEffort?}` تسجيل لـ `agent-default-model` Settings قسم عقدة. ذلك `{provider, model}` تركيب بند هو base طبقة،`settings.yaml` توفير مستخدم طبقة. هذا خدمة لا انحراف نحو خاص تحديد مدخل، لذلك مباشر إنشاء و Session Controller Remote إنشاء مشترك نفس عدد قيمة افتراضية ([headless مباشر core مدخل](../architecture/2026-08-09-headless-direct-core-entry-point.ar.md)).

`reasoningEffort` يخص Settings قسم عقدة، لكن لا يخص إضافة إعداد.Settings طبقة حسب حقل دمج، لذلك قد إعداد قوي درجة سوف في مستخدم اختيار حذف هو وقت متابعة وجود.`saveSelection()` كتابة كامل مستخدم قسم عقدة؛ لذلك، نقص قليل هذا حقل سوف صاف حذف قد تخزين قوي درجة. نشر درجة قوي درجة قيمة افتراضية يخص مهايئ profile، و من هو حسب نموذج تحليل.

`session.selectModel` يأخذ يتم قبول `ModelSelection` تطبيق في الذي في جلسة، و استدعاء `saveDefaultModelSelection()` حفظ مشترك Agent قيمة افتراضية. تخزين فشل فقط تسجيل سجل، لا سحب إلغاء جلسة اختيار. لا يوجد Settings مزود نشر إبقاء تركيب بند، يتم قبول اختيار فقط توقف إبقاء في هذا جلسة في.

`ApiProxyDefaults` يحمل `defaultModelSelection()` و `saveDefaultModelSelection()` إغلاق حزمة، لذلك `createApiProxy` لا اعتماد Settings seam.`ApiProxyService` سوف هو جمع قسم آخر وصل إلى `ctx.agentDefaultModel.currentSelection()` و `ctx.agentDefaultModel.saveSelection()`.

`selectionFor(agent)` كل مرة قراءة وقت كل تحليل كل طبقة: أولا أخذ عملية داخل جلسة اختيار، ذلك مرة أخذ جلسة الأكثر جديد سجل `request/header`، الأكثر بعد أخذ حالي Agent قيمة افتراضية. قد لديه طلب سجل جلسة حمل متابعة ربط إلى سجل في حفظ دائم اختيار. فارغ أبيض جلسة أي جعل إنشاء في انحراف جيد حفظ قبل، أيضا سوف مراقبة إلى حالي قيمة افتراضية؛ هذا و New Session واجهة ممكن إعادة استخدام فارغ أبيض جلسة سلوك متسق.

قد تخزين اختيار لا اشتراط يخص دليل. بعض بند مزود توجيه ممكن خدمة ذلك فقط توفير مشاركة اعتبار دليل لم صف خروج نموذج. لذلك،`session.models` سوف في قد عام نشر قسم مجموعة خارج مفرد وحيد تقرير إبلاغ قد تخزين اختيار، و آخر سطر تقرير إبلاغ مهايئ هل خدمة ذلك مزود.

## أثر

`session/modelCatalog` تقرير إبلاغ حالي Agent قيمة افتراضية. نموذج تبديل نجاح بعد،`settings.yaml` في سوف تخزين لديه واحد `agent-default-model:` قسم عقدة.Settings صفحة لا كشف هذا namespace؛ نموذج اختيار جهاز هو هو تحرير جهاز.

## لا يمكن إرسال رسالة جلسة

عند لا يوجد مهايئ خدمة جلسة الذي اختيار مزود وقت،`session.prompt` سوف في فتح بدء جولة قبل بـ `model-unavailable` رفض. هذا واحد طريقة هو قوي صنع تنفيذ حد؛ منع استخدام composer فقط هو عميل توفير سهل فائدة.

`session.models` تقرير إبلاغ `routable`.ui-model-selection إضافة عبر `ctx.conversation.blocks` إسقاط غير ممكن توجيه اختيار،composer مع لـ تغيير لـ غير ممكن عملية، معا إبقاء نموذج seat متاح. عميل لا معرفة طريق هل يمكن توجيه وقت لن منع قطع إدخال، يشمل دليل أول مرة تحميل أو تحميل فشل حال حال.

يمكن توجيه صفة و دليل عضو علاقة مختلف. ما زال في خدمة مزود توجيه يمكن معالجة لم عام نشر نموذج، لذلك لا في دليل قسم مجموعة في و لا بديل جدول جلسة غير ممكن استخدام.

## اعتبار مرور بديل خطة

| بديل خطة | اتفاق لا مطابقة لـ موضع |
|---|---|
| قد تخزين مزود غير ممكن استخدام وقت عودة سقوط إلى تركيب بند | منتج سوف ساكن صامت قطع مغادرة مستخدم اختيار. |
| أصل حسب دليل عضو علاقة تحقق قد تخزين اختيار | دليل فقط توفير مشاركة اعتبار، ممكن حذف ما زال يمكن طلب نموذج. |
| استخدام دمج patch حفظ | حذف `reasoningEffort` لا يمكن صاف حذف قد تخزين حقل. |
| فقط حفظ فارغ أبيض جلسة في اختيار | محادثة خلال معرفة حال عمل خروج اختيار لن يصبح نشر قيمة افتراضية. |
| زيادة مفرد وحيد «ضبط لـ افتراضي» يد اتجاه | جلسة اختيار جهاز و لم قدوم جلسة انحراف جيد رغم لكن بديل جدول نفس مستخدم اختيار، لكن ما زال ممكن قسم اختلاف. |
