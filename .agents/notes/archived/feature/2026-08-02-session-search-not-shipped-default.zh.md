# Agent Note: جلسة بحث أداة لا هو تسليم افتراضي بند

Status: implemented
Archived: 2026-09-04

[English](2026-08-02-session-search-not-shipped-default.md) | العربية

## مشكلة

[تسليم بيان قرار](2026-07-31-even-out-shipped-tool-rosters.zh.md) يأخذ `tool-session-query` ضبط لـ مشترك [`cordis.patch.yml`](../../../../packages/bundle/base/cordis.patch.yml) افتراضي سطر، في هو تسليم TUI و Web surface يأخذ هذا خمسة عدد جلسة بحث أداة (`session_search`،`session_event_search`،`session_trace`،`session_event_trace`،`session_event_read`) عرض إعطاء نموذج. هذا و[موجه إلى نموذج جلسة استعلام أداة قرار](2026-07-24-model-facing-session-query-tools.zh.md) متبادل مقاومة لمس، هذا قرار حمل يحتاج صريح تفعيل قيام ساحة، حزمة README سوف ذلك سجل لـ «shipped host compositions do not mount it by default». هذا بند افتراضي ضبط أيضا تسليم واحد نص التوجيه مقطع، نحو نموذج شرح منح واحد طقم حيث نحو عمل بحث سير العمل، بينما لا يوجد أي مستخدم اشتراط مرور.

## قرار

تسليم TUI،Web و بلا رأس surface متساو لا تركيب `@deepseek-ai/dsh-tool-session-query`، تسليم agent preset أيضا كل لا يتضمن هو. هذا مستهلك ما زال إبقاء opt-in، و موجه إلى نموذج جلسة استعلام أداة قرار الذي وصف تماما متسق:[session-query لقطة تركيب](../../../../snapshots/session/session-query-spill/cordis.yml) ما زال هو تركيب مشاركة اعتبار، ذاتي تعريف تركيب أيضا يمكن وصل نفس مهلة و spill سياسة واحد بدء تركيب هذا حزمة.

`ctx.sessionQuery` خدمة ذاته إبقاء تركيب.`session-query-sqlite` ما زال هو base واحد سطر،TUI `session-reference` إزالة استهلاك هو قدوم تنفيذ `/resume`؛ ذلك كل نص بحث جذب افتراضي إغلاق (`openAt: never`، رؤية[محتوى بحث opt-in قرار](../architecture/2026-08-13-session-content-search-opt-in.zh.md)) ،Web overlay إبقاء داخل تخزين بحث جذب أخذ قيمة، توفير تفعيل محتوى بحث نشر استخدام. يتم إزالة فقط لديه موجه إلى نموذج مستهلك.

## سبق اعتبار بديل خطة

- **يأخذ `session-query-sqlite` بحث جذب أيضا واحد و إزالة**——مرفوض، لأن `/resume` و Web محتوى بحث إطار مباشر إزالة استهلاك `ctx.sessionQuery`؛ هو جمع هو مضيف وظيفة، لا هو نموذج أداة، إزالة مزود سوف كسر تالف هو جمع.
- **إبقاء هذا سطر، لكن في كل overlay في منع استخدام هو**——مرفوض، لأن واحد بند يتم منع استخدام base سطر ما زال سوف تسليم اعتماد، بينما كما واحد سطر حينئذ قدرة خفيف سهل إعادة تفعيل؛ قد سجل opt-in قيام ساحة اشتراط مستهلك لا ظهور في تسليم surface فوق، بـ ACP عرض مثال بصفة تركيب مشاركة اعتبار.
- **فقط في TUI فوق تركيب**——مرفوض، لأن مشترك base هو كل surface مشترك استخدام واحد مجموعة سطر؛surface مخصص تابع تركيب سوف إعادة جذب دخول تسليم بيان قرار الذي إزالة حذف بيان قسم شق.

## عاقبة

اثنان عدد surface كل عودة إلى نفس مثال اثنان عشرة عدد بلا شرط أداة (ripgrep متاح وقت مجددا إضافة فوق `glob`/`grep`) ، خمسة عدد جلسة بحث schema و ذلك نص التوجيه مقطع أيضا واحد و خروج افتراضي طلب. اثنان عدد surface فوق تسليم تركيب اختبار كل ثابت هذا نسخة أكثر صغير دليل، لذلك يأخذ جلسة بحث إعادة بصفة افتراضي إضافة عودة سوف لمس و نفس مثال اختبار. تفكير يلزم جلسة بحث مستخدم من عدد شخص overlay أو ACP عرض مثال تركيب هذا مستهلك، و في تركيب موضع إضافة اعتماد.
