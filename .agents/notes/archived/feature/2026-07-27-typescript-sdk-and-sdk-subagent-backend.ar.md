# Agent Note: TypeScript SDK عميل و SDK subagent خلفية

Status: implemented
Archived: 2026-09-04

[English](2026-07-27-typescript-sdk-and-sdk-subagent-backend.md) | العربية

## مشكلة

stdio JSON-RPC مقابل خارج خدمة واجهة (`@deepseek-ai/dsh-sdk-jsonrpc-server`، رؤية[مفرد ملف يمكن تنفيذ Agent Note](../architecture/2026-07-10-single-file-executable-sdk-runtime-distribution.ar.md)) عند وقت فقط لديه واحد عميل:Python SDK. تفكير يلزم نفس مثال «يأخذ harness بصفة عملية فرعية قيادة» قدرة TypeScript مستهلك——مستودع اختبار، تلقائي تحويل، خاصة ذلك هو واحد ذلك عملية فرعية هو*كامل harness وقت التشغيل*(بينما غير عام ACP agent(ذكي جسم)) subagent خلفية——لا يوجد يمكن استيراد محتوى: طلب/إشعار تحميل حمل شكل حالة فقط بـ مجهول اسم كائن حرف وجه كمية وجود في خادم داخلي، نقل صنف أيضا استلقاء في خادم إضافة حزمة داخل.

## قرار

ثلاثة عدد حزمة، قسم طبقة و قائم Python مكدس تماما متسق، خارج إضافة واحد Service Provider تسجيل:

- **`@deepseek-ai/dsh-sdk-protocol`**(`packages/sdk/protocol/`)—— يأخذ بروتوكول صيغة فعل صار مشترك كما أداة اسم.`JsonRpcLineTransport` يقع في هذا موضع،`types.ts` لـ خادم الذي قول كل تحميل حمل تسمية:`InitializeParams/Result`،`SessionPromptParams/Result`، أربعة عدد إشعار تحميل حمل، و `HarnessSdkRequestMap`/`HarnessSdkNotificationMap` بحث جذب.`InitializeParams` يحمل مزود، نموذج، اختياري كما من مهايئ يحتفظ دفع إدارة قوي درجة، و اختياري إخراج حد أعلى. هذا حزمة أصل صريح توجيه خروج كامل واجهة، كما لا توفير إشارة نحو مصدر وحدة عميق طبقة استيراد. خادم `notify()` استدعاء نقطة بـ هذه أداة اسم تحميل حمل علامة ملاحظة نوع، خادم عائم نقل سوف أولا كسر تالف تحرير ترجمة بينما لا هو كسر تالف عميل. خطأ استجابة بـ يحمل بروتوكول `code`/`data` `JsonRpcResponseError` رفض، و Python عميل متسق.
- **`@deepseek-ai/dsh-sdk-client`**(`packages/sdk/client/`)—— `python/sdk` TypeScript توأم توليد:`HarnessClient`(spawn، قسم لقطة، إشعار مروحة خروج، لديه نوع خطأ جدول وجه، مرور مشترك dispose(مورد تحرير) مرحلة سلم إغلاق حتى تماما توقف مستقر) لـ فوق هو `DeepSeekHarness`/`HarnessSession`(كسول صفة بدء، تسجيل ذاكرة تحويل `initialize`، و يجعل مرة `run()` و ذلك ذاتي لديه `session/prompt` نشط حركة إعداد مقابل). ذلك حزمة أصل مستهلك واجهة صريح توجيه خروج اثنان طبقة عميل، موجه إلى استدعاء جهة نوع، و بروتوكول حزمة الذي يملك `JsonRpcResponseError`؛ مصدر وحدة، مواصفة تحويل مساعد مساعدة دالة و إشعار إلقاء تمرير طرف كل إبقاء لـ داخلي تنفيذ.`RunResult.events` فقط يتضمن أصل جلسة نوع تحويل حدث، بينما `notifications` فإن إبقاء أصل جلسة و من `subagent.started` اكتشاف بعد بديل كل منها جلسة id؛ جلسة شجرة نطاق حد تحديد في عميل إتمام، مرآة مثل `client.py`. نتيجة يحمل أصل جلسة نهائي مساعدة يد نص، لكن لا يتضمن نص التوجيه درجة حالة أو جولة سبب. بدء واجهة تحليل نفس إصدار `@deepseek-ai/dsh` اعتماد و اختيار أداة اسم profile، اختياري إعداد يشمل `dshBin`، لديه ترتيب patch، صريح Harness home، عملية cwd، بيئة و مهلة؛ مهمة معنى command/argv بدء فقط بصفة داخلي fake-runtime مهايئ.`initialize` يحمل مزود، نموذج، اختياري دفع إدارة قوي درجة و اختياري إخراج حد أعلى. جاف صاف checkout في إذا لا وجود `lib/bin.js`،client سوف عبر قطعا مقابل `tsx/esm` loader استخدام هذا حزمة شفرة المصدر مدخل، و تطبيق واحد حذف بناء مدة توليد Typert مساهمة تحميل داخلي patch؛SDK بروتوكول لا إزالة استهلاك هذه مساهمة.`env` كامل جسم استبدال بينما غير دمج، و في `start()` spawn وقت قراءة، لذلك اعتماد سياسة عودة استدعاء جهة، كما استدعاء جهة يمكن في أول مرة استخدام قبل إتمام بيئة دقيق تجهيز. إمساك يد فشل لكن تنظيف نجاح وقت، نسخة سوف تبديل دخول كل جديد client، جعل لاحق استدعاء عبر جديد عملية إعادة محاولة؛ إذا ابتدائي تحويل و SDK ذاتي لديه تنظيف متساو فشل،`start()` سوف بـ لديه ترتيب `AggregateError` رفض و إبقاء فشل client، بينما لن في بعد لم إثبات أصل عملية خروج وقت و ترتيب spawn جديد عملية. تفكيك حذف مشي خاص stdin-EOF → SIGTERM → SIGKILL مرحلة سلم مباشر إلى حق صحيح خروج، لأن client تشغيل في أي harness سياق خارج.
- **`@deepseek-ai/dsh-subagent-dsh-sdk`**(`packages/subagent/subagent-dsh-sdk/`)—— ثاني عدد عملية خارج `SubagentProvider`، اعتماد و `subagent-acp` مقابل انتظار بنية، لكن إعلان `agentOptions: true`: كل مرة تشغيل كل سوف يأخذ مزود/نموذج/دفع إدارة قوي درجة/maxTokens دمج إلى نسخة قيمة افتراضية لـ فوق، و كما فقط يأخذ هذه حقل إرسال دخول عملية فرعية `initialize`. أخرى بدء قدرة إبقاء false،`inheritsParentContext: false`. مزود إبقاء إمساك يد بعد إصدار كل حق أمر خدمة، عبر `onError` sink سوف نتيجة عودة واحد لـ أبدا رفض، و أب نطاق الأسماء run id. فرعي جواب سجل من تدفق صيغة `session.event` قراءة——الأكثر بعد واحد بند كامل `assistant/message`، لا فإن تراكم تراكم `text-delta` كتلة، جزء جواب سجل في إلغاء وقت نيل بـ إبقاء. إيقاف سبب من عملية فرعية بنية تحويل `TurnEndReason` خريطة:`completed`،`max-tokens` و عادي `aborted` مباشر عبر،`blocked` تغيير لـ `refusal`، أخرى غير إتمام قيمة تغيير لـ `error`. يمكن بلوغ فرعي فشل و SDK خطأ سوف مرفق إضافة[عملية خارج تشخيص قرار](2026-08-21-out-of-process-subagent-minimal-diagnostics.ar.md) تعريف محدود أمان تشخيص، فقط استخدام واحد category و حالي مزود stage. ذلك `dshBin`/profile/patch/home إعداد اختيار عزل SDK تطبيق،`env` فإن توفير عملية فرعية مخصص استخدام صريح قيمة، مثال مثل ذلك API key.
- **subagent seam إضافة جديدة `out-of-process.ts`**: اثنان عدد عملية خارج خلفية مشترك provider جانب مفردات——`NO_START_CAPABILITIES`، وقت حد تحقق، عملية فرعية cwd تحليل (إعداد تغطية، لا فإن إرسال بدء تفويض حمل أب جلسة مساحة العمل) ، أبدا رفض `settleRunResult`، و `subprocessRunHandle` إصدار. عملية آلية (spawn، بيئة تنظيف، عملية شجرة تنظيف) يخص `dsh-subprocess` seam؛`subagent-acp` مرور `ctx.subprocess` spawn عملية فرعية، هذا خلفية فإن مرور SDK عميل spawn عملية فرعية (subprocess README تسجيل تحميل SDK حمل إدارة نقل مثال خارج) و ذاتي سطر تطبيق هذا seam `scrubbedParentEnv()`.

`dsh-sdk-jsonrpc-server` سوف في `initialize` خلال تحقق تأكيد قطع مزود/نموذج/دفع إدارة قوي درجة توجيه، فقط حفظ صريح توفير دفع إدارة قوي درجة و token قيمة، و استخدام هذا بند ثابت عملية درجة توجيه إنشاء كل SDK أصل Agent. من في JSON-RPC طلب ممكن تزامن قسم إرسال، هو سوف في مرة ابتدائي تحويل نجاح إتمام قبل رفض `session/prompt`، تجنب تجنب انتظار تحديد أو غير قاعدة توجيه رجوع إلى بنية صنع مدة قيمة افتراضية.TypeScript و Python عميل كل عبر `dsh --profile sdk` عام نفس مجموعة ابتدائي تحويل حقل؛Python wheel سوف تحزيم هذا CLI و ذلك غلاف إغلاق اعتماد شجرة.

## اختبار

أربعة طبقة، اعتماد[اختبار سياسة سياسة](../../../../docs/testing.ar.md):

- **تجنب مفتاح وحدة**——`sdk-client` عبر حقيقي stdio قيادة نص برمجي تحويل زائف وقت التشغيل (`tests/fake-runtime.ts`، بيئة متغير نص برمجي تحويل، صاف بروتوكول——أي Python `test_client.py` نمط) ؛`subagent-dsh-sdk` مرور حقيقي مزود قيادة نفس زائف وقت التشغيل، تغطية تدريجي مرة توجيه تغطية، يمكن بلوغ فرعي سبب،typed خطأ، و initialize/session-run/shutdown تشخيص. ثلاثة عدد حزمة الكل 100% تدريجي ملف تغطية.
- **تجنب مفتاح Loader تركيب**——`subagent-dsh-sdk/tests/loader-composition.e2e.ts` بدء حزمة ذاتي لديه اختبار تركيب (`packages/subagent/subagent-dsh-sdk/tests/fixtures/loader/`) ، منها عملية فرعية هو حقيقي ثاني عدد `dsh --profile sdk` وقت التشغيل، يملك مستقل home و لديه ترتيب patch؛ أداة نتيجة و حفظ دائم طلب header سوف إثبات مزود، نموذج، دفع إدارة قوي درجة،maxTokens و أب جلسة cwd، فشل مشهد فإن ثابت و جزء إخراج قسم مغادرة نموذج مرئي فرعي خطأ تشخيص.
- **تجنب مفتاح لقطة**——`snapshots/sdk/sdk.snapshot.ts` عبر حقيقي `dsh-sdk-client` قيادة حقيقي `dsh --profile sdk` وقت التشغيل، و عبر لديه ترتيب `llm-replay` patch إعادة تشغيل قد تسجيل صنع fixture(اختبار قبل وضع بيانات). واحد DSH SDK مشهد يأخذ نموذج اختيار توجيه ثابت في تفويض إرسال أداة، ثاني عدد SDK وقت التشغيل و فرعي درجة حفظ دائم طلب header في؛ آخر عدد مشهد ثابت أمان تشخيص مواصفة تحويل إشعار تدفق،SDK نتيجة، حمل دائم سجل و قبل منصة/خلفية فشل نص.
- **حمل مفتاح e2e**——لقطة طقم عنصر `DSH_SNAPSHOT=record` نمط أي حقيقي API مسار (قد إيداع fixture من هو إنتاج خروج) ؛ تركيب e2e تصميم فوق بلا حاجة مفتاح.

## اعتبار مرور بديل خطة

**من `dsh-sdk-jsonrpc-server` استيراد بروتوكول نوع بينما لا هو رفع أخذ بروتوكول حزمة.** سوف يجعل كل SDK مستهلك (يشمل أبدا قدرة توفير JSON-RPC خدمة `subagent-dsh-sdk`) اعتماد خادم إضافة و ذلك `dsh-agent`/`dsh-llm-deepseek` peer تجميع دمج، كما إشعار تحميل حمل ما زال مجهول اسم. قدرة seam قاعدة (Service Definition/Service Provider/Consumer ثلاثة عدد حزمة قسم قيام) قد نقطة اسم هذا نوع شكل؛ هذا عدد نقل هو بضاعة حق قيمة فعلي مزدوج حافة شيء.

**يجعل `subagent-dsh-sdk` مباشر قول عار JSON-RPC، التفاف فتح عميل SDK.** سوف نسخ SDK وجود معنى معنى الذي في طلب/إشعار إعداد مقابل، حجز قراءة مروحة خروج، مهلة و تفكيك حذف منطق؛ مستخدم اشتراط واضح هو واحد*استخدام* SDK خلفية، قسم طبقة عودة تقرير هو خلفية يصبح يمكن إعادة استخدام عميل لـ فوق نحو 200 سطر صاف سياسة.

**يأخذ SDK خلفية طي دخول `subagent-acp`، استخدام نقل فتح صلة منطقة قسم.** اثنان عدد خلفية مشترك عملية فرعية دورة الحياة، لكن بروتوكول (ACP SDK اتصال vs harness JSON-RPC) ، عملية فرعية اتفاق (مهمة معنى ACP agent vs harness وقت التشغيل) ، نتيجة رفع أخذ (`agent_message_chunk` تراكم تراكم vs جلسة حدث قراءة) جزء بلا مشترك. إعداد حكم آخر حقل سوف يأخذ اثنان عدد بروتوكول دفن دخول واحد حزمة؛ حق صحيح مشترك مزود جانب جزء نقل دخول subagent seam `out-of-process.ts`، عملية آلية فإن إقامة في `dsh-subprocess` seam.

**فقط من `PATH` تحليل `dsh`.** رفض:Node مستهلك لا واحد تحديد وراثة مشروع محلي `.bin` دليل. نفس إصدار حزمة اعتماد لـ قد تثبيت مستهلك توفير بناء بعد CLI، و لـ جاف صاف checkout توفير شفرة المصدر مدخل.

**توجيه خروج مصدر وحدة، مواصفة تحويل مساعد مساعدة دالة و حجز قراءة إلقاء تمرير طرف عملية.** هذه كل هو استدعاء جهة لا حاجة تنفيذ دقيق عقدة؛ كشف هو جمع سوف يجعل استدعاء جهة لا نيل لا إدارة حل عميل مثل أي تحقق و توزيع بروتوكول إدخال. كل حزمة أصل تحويل بينما قطعة رفع تلقي دعم حمل عميل واجهة و بروتوكول واجهة، عميل فإن فقط إعادة توجيه خروج استدعاء جهة يجب منطقة قسم ذلك واحد نوع بروتوكول خطأ.

**إعادة استخدام `dsh-session-snapshot` ACP `runScenario` فعل SDK لقطة.** هذا مهايئ قول ACP(`ClientSideConnection`،`InputStep` نص برمجي).SDK طقم عنصر الكل معنى معنى حينئذ هو بـ *SDK عميل*لـ مدخل؛ هو إعادة استخدام normalize/refresh مكتبة طبقة (`normalizeSessionLog`،`refreshFixtureReplacements`……) ، لا حركة ACP مهايئ.

## عاقبة

**استلام فائدة**:SDK وقت التشغيل بروتوكول يملك خادم و اثنان عدد عميل SDK مشترك، تحرير ترجمة جهاز تحقق أداة اسم نوع؛TypeScript مستهلك نيل نيل و Python نفسه عملية فرعية قيادة قدرة، كما حمل نوع تحويل خطأ و بنية تحويل جولة سبب، حزمة أصل أيضا فقط كشف عودة استدعاء جهة كل عملية؛subagent seam يملك واحد harness أصلي عملية خارج خلفية، ذلك عملية فرعية هو كامل مقابل انتظار جسم (ذاتي لديه إعداد، حفظ دائم، أداة) ، أب agent أيضا قدرة مرور نفس SDK مسار استلام إلى الأكثر صغير أمان فرعي جولة/SDK فشل واقع؛SDK profile عبر SDK مسار ذاته معا ثابت نجاح و فشل تفويض إرسال سلوك.

**بديل قيمة**:`sdk/` مجموعة كثير رقم ثلاثة عدد حزمة،subagent كثير رقم أربعة عدد يلزم إبقاء الأكثر جديد خلفية؛SDK خلفية كل عملية فرعية بدء كامل إضافة شجرة (مفرد مرة صار هذا عال في ACP عملية فرعية؛ حوض تحويل و ACP واحد مثال إبقاء عمل لم قدوم عمل) ؛ بروتوكول ما زال بلا إلغاء طريقة،SDK `RequestTimeoutError` و خلفية dispose كل فقط في محلي تسوية، خادم جانب جولة سوف متابعة تشغيل إلى عملية تنظيف لـ توقف؛ لقطة fixture تسجيل صنع في `deepseek-v4-flash`، و أخرى تسجيل صنع لغة مادة واحد مثال مع نموذج سلوك عائم نقل بينما إعادة تسجيل.
