# Agent Note: كل جلسة فقط استخدام واحد جدول طبقة إدارة جهاز

Status: implemented
Archived: 2026-07-26

[English](2026-07-19-use-one-session-surface-manager.md) | العربية

## مشكلة

`Session` سبق إبرة مقابل نفس نسخة فقط إلحاق حدث سجل صيانة اثنان عدد `SurfaceManager` نسخة. واحد نسخة مسؤول تحقق نوع فرعي حدث و إلحاق مرشح حدث، آخر عدد تأخير متأخر إنشاء نسخة فإن مستقل طي قد إيداع حدث، توفير `session.surface`، إرسال توليد رسالة، ضغط (compaction) و مساحة العمل سياق استخدام. واحد حالما قراءة عام مشترك جدول طبقة، بعد كل حدث كل سوف دفع دخول اثنان نسخة تكرار عقدة حالة و استبدال بديل عدد حالة، لكن لا يوجد شكل صار مستقل حق مصدر أو فشل حد.

## قرار

كل `Session` رئيسي حركة إنشاء و فقط يحتفظ واحد `SurfaceManager`. نوع فرعي حدث و إلحاق حدث وصل قبول مسار في إيداع حدث قبل استدعاء هذا إدارة جهاز `validateNext()`،`session.surface` فإن عبر التالي فقط قراءة عقد نحو إرجاع نفس عدد كائن:

```ts
export interface SessionSurface {
  readonly nodes: readonly number[]
  readonly replaceGeneration: number
}
```

مرشح حدث تحقق ما زال إبقاء أصل فرعي صفة.`validateNext()` يمكن تزامن قد إيداع سجل حدث، لكن مقابل بعد لم إيداع مرشح حدث فقط صنع تحديد تغيير حساب تخطيط. مرشح حدث في `log.push()` بعد، تحت مرة زيادة كمية تزامن وقت عندئذ دخول إدارة جهاز حالة، لذلك جدول طبقة تحقق فشل أو إيداع قبل `internal/dispatch` مرفوض كل لن إبقاء تحت وهمي زائف عقدة أو استبدال بديل عدد.

`foldSurface()` ما زال هو مغادرة خط تحقق و إعادة بناء استخدام قسم مغادرة صيغة كامل سجل إعادة تشغيل دالة. هو استخدام نفسه حالة تحويل، و كما مقابل كل قد إيداع بادئة كل و نشط وثب إدارة جهاز متسق، لكن لا مشترك متغير حالة.

## تجهيز اختيار خطة

**متابعة قسم مغادرة وصل قبول حالة و إسقاط عرض.** اثنان عدد مستقل نسخة نظر يشبه قدرة كاف عزل عام مشترك قراءة و تحقق، لكن استدعاء جهة أخذ نيل هذا قدوم حينئذ هو استعارة استخدام جدول طبقة حالة، إعلان فقط قراءة عقد نحو سوف منع توقف عادي تعديل. نسخ إدارة جهاز و لا يستطيع بنية صار وقت التشغيل معلومة مهمة حد.

**كل مرة قراءة كل أصل حسب كامل سجل إعادة حساب حساب عام مشترك جدول طبقة.** هذا خطة قدرة إزالة حذف تكرار ذاكرة مؤقتة حالة، لكن سوف وضع ترك زيادة كمية إرسال توليد، جعل كل مرة طلب بنية صنع كل مع كامل جلسة تاريخ زيادة طويل.

## أثر

- وصل قبول مسار،`session.surface`، إرسال توليد رسالة، ضغط و مساحة العمل سياق مراقبة نفس نسخة زيادة كمية حالة.
- `Session.surface` لا كشف تحقق طريقة، معا إبقاء كائن معرف و استعارة استخدام فقط قراءة عقدة عدد مجموعة مستقر.
- سيئ معنى نوع تأكيد ما زال يمكن كسر تالف استعارة استخدام حالة؛ لحظة معنى التفاف مرور فقط قراءة عقد نحو JavaScript استدعاء جهة لا يخص تلقي دعم حمل نفس عملية حد.
- جدول طبقة، نوع فرعي، ضبط درجة مرفوض، طلب إعادة بناء، ضغط و مساحة العمل سياق اختبار تغطية مشترك إدارة جهاز و قسم مغادرة إعادة تشغيل مسار.
