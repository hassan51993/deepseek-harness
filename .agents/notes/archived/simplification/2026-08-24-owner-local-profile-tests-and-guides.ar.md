# Agent Note: ملكية جهة محلي Profile اختبار و يمكن تشغيل إشارة جنوب

Status: implemented
Archived: 2026-09-04

[English](2026-08-24-owner-local-profile-tests-and-guides.md) | العربية

## مشكلة

قمة طبقة `examples/` شجرة خلط دمج أربعة نوع متبادل لا نفسه زاوية لون: تكرار تطبيق تركيب، عبر حزمة profile اختبار، حزمة مخصص تابع Loader fixture، و يمكن تشغيل مستخدم إشارة جنوب. هو umbrella workspace manifest رئيسي يلزم لأجل يجعل مهمة معنى تضمين طقم Cordis ملف تحليل حزمة، لذلك اختبار و وثيقة موضع قرار اعتماد تحليل، أيضا يجعل لا تلقي دعم حمل demo launcher نظر بدء قدوم مثل منتج واجهة.

## قرار

مستودع لا وجود قمة طبقة `examples/` شجرة. أداة اسم `dsh` profile هو وحيد Node تطبيق تركيب. عبر حزمة ACP،headless و SDK profile اختبار يقع في `apps/cli/tests/profiles/`؛ حزمة مخصص تابع Loader إعداد و driver يقع في هذا حزمة `tests/fixtures/`. تسجيل صنع جلسة اختبار متابعة يقع في قمة طبقة `snapshots/`، غير جلسة مسبق مدة إخراج متابعة ملكية جهة محلي حفظ.

اختياري مستخدم overlay بصفة تسليم مورد إنتاج يقع في `apps/cli/config/examples/`، منها عار إضافة اسم عبر CLI تطبيق manifest تحليل.GitHub مراجعة،Schedule، تسجيل ذاكرة MCP و وقت التشغيل Cordis إشارة جنوب يقع في `docs/user/` و رابط هذه مورد إنتاج. يمكن تشغيل Python SDK برنامج و أقصى بسيط overlay يقع في `python/sdk/examples/`.

مستودع لا وجود `demo:acp` و `demo:cordis` نص برمجي.ACP عبر `dsh --profile acp` بدء؛Cordis إشارة جنوب استخدام صريح overlay بدء `dsh web`.`demo:ptc` متابعة بصفة رقيق wrapper، بـ `DSH_TOOLS_MODE=ptc` تشغيل `dsh --profile headless`.

## اعتبار مرور بديل خطة

**فقط لـ وحدة تحليل إبقاء examples workspace.** قد مرفوض: يتضمن غير متصل اختبار و إشارة جنوب اعتماد و تجميع resolver manifest سوف إخفاء كل حق، و يجعل مهمة معنى leaf جدول الآن نيل مثل تطبيق حزمة.

**يأخذ كل ملف كل نقل إلى CLI تطبيق تحت.** قد مرفوض: حزمة مخصص تابع اختبار تركيب مع مقابل حزمة عرض دخول، مستخدم شرح يخص إصدار إشارة جنوب طبقة درجة،Python عرض مثال يخص SDK.

**إبقاء توافق demo أمر.** قد مرفوض: أداة اسم profile و صريح overlay قد توفير تلقي دعم حمل بدء طريقة؛ توافق wrapper سوف إبقاء ثاني طقم تطبيق مفردات.

## عاقبة

مسار ذاته يكفي جدول بلوغ كل حق، بلا حاجة فحص قراءة قطع قرار جدول.CLI profile اختبار من مفرد واحد تطبيق manifest تحليل؛ حزمة اختبار يحمل ذاتي ذات fixture؛ تسليم اختياري overlay مع CLI حزمة تثبيت؛ مستخدم إشارة جنوب دخول شبكة محطة تنقل؛Python عرض مثال يقع في SDK جانب. حذف إشارة جنوب أو اختبار لم يعد تغيير عام اعتماد umbrella.
