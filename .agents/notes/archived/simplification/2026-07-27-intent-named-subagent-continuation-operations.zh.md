# Agent Note: حسب معنى رسم تسمية subagent متابعة تنفيذ عملية

Status: implemented
Archived: 2026-09-04

[English](2026-07-27-intent-named-subagent-continuation-operations.md) | العربية

مزود طلب و جلسة flush قرار ما زال صالح.[متبادل مجاور Agent مشترك واحد Steer رسالة عملية](../architecture/2026-08-27-adjacent-agent-steer-messaging.zh.md) يحل محل هذا سجل `followup` تسمية و options: عام عملية الآن هو متاح في مهمة واحد متبادل مجاور جهة نحو `sendMessage(sender, targetId, content, { signal })`.

## مشكلة

سوف يمكن متابعة child تحرير ترتيب دمج إلى `ctx.subagents` بعد، مزود توزيع و استدعاء جهة معنى رسم مشترك تخزين في نفس عدد عام خدمة في.`resume(name, request)` قبول وصف رمز، قد تمييز حق parent، حفظ دائم child id و تنشيط إشارة، بينما فقط لديه داخلي متابعة تنفيذ إدارة جهاز عندئذ قدرة صحيح تأكيد تحليل هذه بيانات. جهة نحو مخصص تابع `followup` و `reportFrom` عملية أيضا سوف لـ واحد بند متبادل مجاور Agent قدرة تحرير رمز مختلف توجيه و ضبط درجة.

حمل دائم صفة حد أيضا معا عام `SessionStore.flush()` و `flushRequired()`. اثنان من تنفيذ نفسه أثر مجال داخل و سطر توزيع، وحيد فرق آخر هو هل قبول فارغ مستمع لقطة، لذلك جلسة واجهة سوف واحد مستهلك سياسة تحرير رمز لـ ثاني بند عملية.

## قرار

`SubagentRuntime` قسم مغادرة ثلاثة نوع استدعاء جهة معنى رسم:`start(name, request)` إرجاع عادي، من يحتفظ جهة مسؤول one-shot run؛`startContinuable(spec)` بناء قيام حفظ دائم child، و إرجاع ذلك id و قد قبول ابتدائي `MessageId`؛`sendMessage(sender, targetId, content, { signal })` فإن عبر واحد بند مباشر parent-child حافة إرسال من نموذج تحرير كتابة محتوى. رسالة عملية من تأكيد قطع في خط sender دفع توجيه مصدر معلومة، و مسؤول متبادل مجاور علاقة فحص، بارد استعادة و ثابت Steer ضبط درجة. وحيد موجه إلى نموذج `send_message({ agent_id, message })` أداة سوف في اثنان عدد جهة نحو تفويض حمل إعطاء هذا عملية.

استدعاء جهة طلب و مزود طلب متبادل متبادل قسم مغادرة.`SubagentStartRequest` يتضمن استدعاء جهة توفير one-shot بيانات؛`ResolvedSubagentStartRequest` سوف في استدعاء `SubagentProvider.start()` قبل إضافة دخول من خدمة تحليل وصف رمز. إنشاء يمكن متابعة child وقت، إدارة جهاز سوف `ContinuableCreateRequest` نقل إعطاء اختياري `SubagentProvider.prepareContinuable()`، كما فقط استقبال قسم مغادرة إنشاء بيانات.`SubagentRuntime.resume()` و مزود استعادة توزيع متساو لا وجود: متابعة تنفيذ إدارة جهاز تحميل وصف رمز، مقابل parent إجراء تمييز حق، و مسؤول Agent فعلي جسم تحويل، نص التوجيه إلقاء تمرير، بارد استعادة و teardown.

`SessionStore.flush(session)` هو وحيد حمل دائم صفة شاشة عائق، و إرجاع `Promise<boolean>`. حتى قليل واحد أثر مجال داخل مستمع نجاح مشاركة و بعد، هو تحليل لـ `true`؛ مستمع لقطة لـ فارغ وقت تحليل لـ `false`؛ كل مستمع تسوية بعد، مثل لديه فشل، فإن بـ تسجيل ترتيب الأكثر اعتماد قبل مستمع خطأ رفض. مشاركة و نتيجة لا يمكن جدول واضح الذي اختيار حفظ دائم خلفية هل قد تخزين حالة. عادي فحص نقطة يمكن تجاهل اختصار هذا قيمة منطقية؛ متابعة تنفيذ إدارة جهاز نفس مثال سوف نهائي flush نظر لـ best-effort شاشة عائق، متعمد تجاهل اختصار مشاركة و نتيجة، سجل رفض سجل، و ما زال سوف مقابل child تنفيذ dispose(مورد تحرير) و تحرير كل حق.

## قد اعتبار بديل خطة

**إبقاء عام مزود استعادة توزيع.** متابعة تنفيذ إدارة جهاز خارج، لا يوجد أي إنتاج استدعاء جهة معا مسؤول أمان استدعاء الذي يحتاج وصف رمز فحص بحث، مباشر parent تمييز حق،Agent فعلي جسم تحويل،Activation كل حق و child-first teardown. عام طريقة سوف كشف قد تحليل تنفيذ بيانات، لكن لا يوجد دمج إدارة مستقل استدعاء معنى رسم؛ مزود تعديل لـ عبر `prepareContinuable` مساهمة قسم مغادرة أول مرة إنشاء بيانات، كما من لا مشاركة و بارد استعادة.

**إبقاء جهة نحو مخصص تابع `followup` و `reportFrom` عملية.** هذا مثال يمكن إبقاء child بلا حاجة ملء كتابة استقبال جهة قصير استدعاء، لكن سوف تكرار إذن، مصدر معلومة و إلقاء تمرير سلوك، و يجعل خدمة مفردات أخذ قرار في جهة نحو. واحد `sendMessage` عملية يمكن تسمية مشترك معنى رسم، و يجعل هدف إبقاء صريح.

**إبقاء `flushRequired()`.** ثاني عدد طريقة فقط غلاف تركيب فارغ مستمع فحص. من قائم شاشة عائق إرجاع هل لديه مستمع مشاركة و، يمكن يجعل توزيع فقط إبقاء واحد طقم تنفيذ، و يجعل كل استدعاء جهة ذاتي سطر حكم تحديد نقص قليل مستمع هل يمكن قبول.

**دمج عادي بدء و يمكن متابعة بدء.** واحد علامة سجل سوف يجعل نفس طريقة يلزم ما انتظار من يحتفظ جهة مسؤول one-shot run حينئذ خيط بعد إرجاع، يلزم ما قيام أي إرجاع حفظ دائم child و رسالة معرف. حسب معنى رسم تفكيك قسم طريقة بلا حاجة قيمة راجعة ربط دمج نوع يكفي إبقاء كل حق و وقت ترتيب فرق مختلف.

## أثر

- Cordis خدمة دليل فقط يتضمن استدعاء جهة عملية؛ مزود يمكن عبر `SubagentProvider.prepareContinuable?()` اختيار مشاركة و يمكن متابعة child أول مرة إنشاء، لكن لن نيل نيل Agent دورة الحياة إذن أو عام استعادة عملية.
- sender إذن قدوم ذاتي تأكيد قطع في خط `Agent`؛ إلغاء إشارة عبر واحد خيار كائن نقل تمرير، و كما فقط مسؤول inbox قبول قبل عمل.
- جلسة حمل دائم صفة فقط لديه واحد شاشة عائق عملية. مشاركة و نتيجة ما زال يمكن مراقبة قياس، لكن أي يمكن متابعة child مسار كل لن سوف مهمة معنى مستمع مشاركة و نظر لـ حفظ دائم خلفية قد تخزين حالة إثبات.
- مفرد واحد `send_message` schema، قد قبول رسالة معرف،`AgentHandle` كل حق، حفظ دائم حدث مفردات و نموذج مرئي transcript(نص سجل) التزام دوران فوق نص رابط أساس في Activation تنفيذ.
