# Agent Note: بلا حاجة حمل إدارة تثبيت جهاز شفرة المصدر تشغيل

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-source-run-without-managed-installer.md) | العربية

## مشكلة

مستودع ذاتي حمل شفرة المصدر تثبيت جهاز يمكن توفير مستقر بدء جهاز، متبادل متبادل عزل staging worktree، أصل فرعي ترقية، تراجع تخزين، و لأجل عدد شخص تحديد صنع مشترك صيانة سير العمل. و هذا معا، مستودع أيضا يجب في حزمة إدارة جهاز خارج مسؤول ثاني طقم دورة الحياة: تثبيت مضيف اعتماد، تلميح إدخال سند إثبات، وصل إدارة فحص خروج، إدارة رمز رقم رابط ملكية، تنسيق ضبط staging فرع، معالجة ترقية استعادة، و حمل متابعة إبقاء تثبيت جهاز و مع مرفق صيانة skill(تقنية قدرة) توافق صفة.

من شفرة المصدر فحص خروج تشغيل أو تطوير DeepSeek Harness و لا حاجة هذا طقم دورة الحياة. صيانة هو سوف توسيع كبير حاجة دعم حمل نظام الملفات و Git حالة فضاء، لكن لا يمكن تعديل دخول مستودع أصلي تنفيذ مسار.

## قرار

مستودع عبر أصل دليل `pnpm` نص برمجي دعم حمل من شفرة المصدر تشغيل.`package.json` في `dsh` بند عبر `node --import tsx/esm` مباشر بدء `apps/cli/src/bin.ts`؛ ناتج توليد هو مستقل `pnpm run build` عملية، من[شفرة المصدر بدء و بناء قسم مغادرة قرار](2026-08-12-separate-source-launch-from-build.ar.md) قاعدة تحديد. هذا حزمة نص برمجي سوف تحويل إرسال معامل و وراثة استدعاء جهة بيئة؛ عند دعم حمل بيئة بديل إدارة Node إصدار يجب التزام دوران `HTTP_PROXY` و `HTTPS_PROXY` وقت، استدعاء جهة يمكن ضبط `NODE_USE_ENV_PROXY=1`. مستخدم استخدام `pnpm dsh web` اختيار Web، استخدام `pnpm dsh --profile headless "task"` اختيار بلا رأس تنفيذ، و استخدام `pnpm dsh --profile acp` تشغيل ACP تلقائي تحويل.

مستودع لا توزيع شفرة المصدر تثبيت جهاز، تثبيت جهاز اختبار طقم عنصر، أيضا لا توزيع اعتماد تلقي إدارة `current` رمز رقم رابط و حمل ختم الوقت staging worktree skill. شفرة المصدر فحص خروج تخزين وضع موضع،Git تحديث، و مستخدم في مستودع خارج إنشاء أي بدء جهاز متساو من مستخدم مسؤول.

## اعتبار مرور تجهيز اختيار خطة

**إبقاء تثبيت جهاز، لكن سوف `pnpm run` تسجيل عمل آخر بند مسار.**هذا مثال يمكن إبقاء تلقي إدارة بدء جهاز و تراجع قدرة، لكن اثنان طقم دورة الحياة اتفاق ما زال سوف معا توليد فاعلية، منها يشمل تثبيت جهاز اختبار و اعتماد staging تخطيط skill.

**إبقاء عام تحديد صنع و فوق تنقل إصدار skill.**منها أمان قاعدة أيضا قدرة لأجل staging تخطيط خارج، لكن قائم سير العمل مشترك نفس بنية صار واحد طقم اقتران دمج صيانة نظام: تحديد صنع سير العمل فحص بحث قد تثبيت staging فحص خروج، ترقية سير العمل تنفيذ تبديل، فوق تنقل إصدار سير العمل فإن من هذه عدد شخص تعديل في اختيار إصدار محتوى. عام Git مساهمة إشارة جنوب قد يخص مستودع إشارة أمر، بلا حاجة بـ منتج مع مرفق skill شكل صيغة توفير.

**استخدام أكثر صغير بدء جهاز رابط نص برمجي استبدال تثبيت جهاز.**هذا مثال يمكن بسيط تحويل ضبط مرور مسار، لكن مستودع ما زال يحتاج مسؤول تعديل مضيف PATH و إدارة بدء جهاز ملكية. شفرة المصدر نص برمجي بلا حاجة جذب دخول هذا صنف حالة يكفي توفير مدخل نقطة.

## أثر

شفرة المصدر مستخدم عبر مستودع نص برمجي تشغيل برنامج، بينما غير استخدام قد تثبيت `dsh` أمر. مستودع لا توفير أصل فرعي ترقية تبديل، أيضا لا إبقاء staging تراجع فحص خروج؛ مستودع نفس مثال لن تلقائي تجميع صار عدد شخص شفرة المصدر تعديل أو سوف ذلك إصدار إلى فوق تنقل. لم قدوم توزيع آلية يجب شرح لـ أي ينبغي من ذلك إدارة تثبيت و ترقية حالة، تعريف استعادة سلوك، و تكملة ملء اختبار و مستخدم وثيقة، معا لا نيل يجعل شفرة المصدر تشغيل مسار اعتماد هذا آلية. لم قدوم أي إصدار سير العمل كل يجب عزل خروج واحد بند نيل دفعة وظيفة، و في أول مرة دفع إرسال و إنشاء مسودة مسودة PR(Pull Request) قبل أخذ نيل واضح دفعة دقيق.

تحقق نطاق يشمل مستودع داخل مقابل قد إزالة مدخل نقطة كل مرجع، وثيقة رابط، توليد رقم ثلاثة جهة إعلان ملف جديد طازج درجة،`package.json` في مباشر شفرة المصدر بدء أمر، و عبر دقيق تأكيد `node --import tsx/esm` تشغيل طريقة مقابل شفرة المصدر CLI إجراء خطر دخان اختبار.
