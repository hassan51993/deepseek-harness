# Agent Note: صريح إعداد dsh مدخل

Status: implemented
Archived: 2026-08-08

[English](2026-08-03-explicit-config-dsh-entrypoint.md) | العربية

## مشكلة

عار `dsh` سوف خفي صيغة اختيار منتج TUI. هذا جعل واحد بند أمر مسؤول طرفية دورة الحياة، جلسة هوية و استعادة نقل تسليم،onboarding، شفرة المصدر workspace سريع سريع مدخل، جذب توجيه صيغة ترقية جلسة، عدد شخص إعداد استماع، و واحد كامل طقم قاعدة نموذج ضخم كبير تطبيق درجة PTY و transcript(نص سجل) لقطة اختبار. هذا افتراضي سلوك أيضا إخفاء حقيقي تركيب حد:`--config` هو TUI overlay لـ فوق اختياري رقم ثلاثة طبقة، بينما لا هو raw بدء جهاز الذي يحتاج نشر تعريف.

مشترك base متعمد إبقاء في صفة: هو توفير كل بند قدرة، لكن لن إنشاء بدء agent(ذكي جسم) أو تفاعل مدخل. سوف في صفة base و خفي صيغة تطبيق إعداد مقابل، جعل raw إعداد تركيب نقص نقص واضح حد، أيضا جعل منتج سياسة سياسة إبقاء في CLI(أمر سطر واجهة) في، بينما لا هو من استدعاء جهة اختيار تحديد overlay يحتفظ.

## قرار

raw تنفيذ طريقة لـ `dsh --config <path>`. إشارة تحديد ملف يجب هو واحد نسخة Include رقعة قائمة، و في نفس include طبقة درجة مباشر تطبيق إلى `apps/cli/config/base.cordis.yml` لـ فوق. بدء وقت يجب توفير هذا ملف؛ هو لا هو كامل استبدال إعداد شجرة، أيضا لن وراثة `apps/cli/config/web.cordis.yml` أو `$DSH_HOME/config.yaml`. متبادل مقابل مسار من استدعاء دليل تحليل. بدء خطأ سوف واضح تقرير خطأ؛SIGINT و SIGTERM سوف أولا مقابل أصل سياق تنفيذ dispose(مورد تحرير) ، مجددا خروج.

raw تشخيص شكل صيغة ما زال بلا حاجة بدء:`dsh --dump-default-config` ضرب طبع base،`dsh --config <path> --dump-config` فإن ضرب طبع base و مطلوب overlay دمج صار نتيجة. تحويل تخزين مرور مسار استخدام Include تنفيذ رقعة حساب قاعدة و YAML جهة قول.

CLI لم يعد تسليم TUI تطبيق.TUI overlay، بدء جهاز، أول مرة تشغيل onboarding مورد إنتاج، تطبيق درجة TUI fixture(اختبار قبل وضع بيانات) ،PTY harness، طرفية مسار و لقطة متساو قد حذف.`meta` و `upgrade` فرعي أمر، مقابل فعلي تحقق وظيفة بوابة، افتراضي surface استعادة مدخل، و كامل شجرة إعداد شجرة `--config-replace` مسار أيضا مع هذا تطبيق واحد و حذف. تثبيت جهاز لم يعد توفير واجهة اختيار جهاز، فقط بناء و بدء Web.

`dsh web` إبقاء مشترك base،Web overlay و عدد شخص أو صريح مستخدم طبقة.`dsh -p` إبقاء مرة صفة Web/headless تركيب. يمكن إعادة استخدام TUI حزمة (package) في هذا مدخل تغيير بعد بدء أول إبقاء، مع بعد[كل حزمة إزالة قرار](2026-08-04-remove-tui-package.md) سوف ذلك و SDK واجهة حذف.

هذا قرار يحل محل التالي سجل في مخصص لأجل `dsh` جزء:[مستقل TUI مدخل](../../archived/feature/2026-07-17-dedicated-full-screen-tui-front-door.md) ،[عدد شخص إعداد](../feature/2026-07-20-dsh-cli-personal-config.md) ،[جذب توجيه صيغة skill أمر](../../archived/feature/2026-07-28-dsh-guided-skill-session-commands.md) ،[meta workspace](../../archived/feature/2026-07-28-dsh-meta-source-workspace.md) ،[مشترك إعداد overlay](2026-07-29-shared-base-config-overlays.md) ،[إعداد تحويل تخزين](../../archived/feature/2026-07-30-dsh-dump-config.md) ،[أول مرة تشغيل فرح استقبال صفحة](../../archived/feature/2026-07-30-versioned-tui-first-run-welcome.md) و[فعلي تحقق صفة فرعي أمر بوابة](../../archived/feature/2026-07-31-experimental-subcommand-gate.md). لاحق[كل حزمة إزالة قرار](2026-08-04-remove-tui-package.md) يحل محل منها صلة في يمكن إعادة استخدام حزمة قرار، و كامل دمج قد حذف بدء جهاز هوية سجل.

## تحقق

محلل اختبار اشتراط raw بدء توفير `--config`، و رفض قد حذف أمر اسم و لا توافق خيار تركيب. بناء بعد اثنان دخول صنع تحقق استلام اختبار في لا استخدام tsx حال حال تحت تشغيل قد إصدار JavaScript مدخل، فحص فقط يحتوي base و base إضافة overlay تحويل تخزين، و نقل دخول بلا فاعلية raw مزود overlay، بـ إثبات بدء فشل قدرة كاف انتهاء و خروج، بينما لن تعليق بدء. شفرة المصدر بدء توافق صفة اختبار عبر `bin/dsh` فحص نفس بند نقص قليل مطلوب إعداد تشخيص.`apps/cli` لم يعد يتضمن أي TUI demo أو اختبار.

## سبق اعتبار بديل خطة

**إبقاء عار `dsh` بصفة TUI، و إضافة جديدة صريح إعداد فرعي أمر.** غير مقبول، لأن CLI ما زال يحتاج يحتفظ اثنان طقم متبادل لا متبادل صلة تطبيق سياسة سياسة، و إبقاء فقط توفير TUI استخدام بدء جهاز،onboarding و اختبار أساس أساس ضبط تطبيق.

**سماح عار `dsh` بدء في صفة base.** غير مقبول، لأن base لن إنشاء agent أو تفاعل مدخل. عملية نجاح انتهاء بدء لكن لا يوجد متاح مدخل، سوف إخفاء غطاء ناقص نشر قرار.

**إبقاء `--config-replace` بـ دعم حمل كامل إعداد شجرة.** غير مقبول، لأن raw تنفيذ الآن فقط لديه واحد نسخة تركيب عقد نحو: في منتج base لـ فوق تطبيق إضافة واحد نسخة مطلوب overlay. كامل إعداد شجرة نشر يمكن استخدام عام Cordis loader أو مخصص استخدام تطبيق اثنان دخول صنع ملف، بلا حاجة لـ `dsh --config` زيادة ثاني نوع يحتوي معنى.

**مع منتج مدخل واحد و حذف TUI حزمة.** الأكثر أول غير مقبول، لأن فقط إزالة واحد بند قد تسليم تطبيق ذاته و لا اشتراط إزالة يمكن إعادة استخدام UI تنفيذ. عند قد تسليم تركيب و مستقل مستهلك متساو لا تكرار وجود بعد،[كل حزمة إزالة قرار](2026-08-04-remove-tui-package.md) قبول هذا واحد خطة.

## عاقبة

استدعاء `dsh` وقت إذا حيث لا إشارة تحديد نمط، أيضا لا توفير raw إعداد، سوف إنتاج استخدام قاعدة خطأ. قائم TUI بدء،`meta`،`upgrade`، استعادة و كامل شجرة إعداد شجرة استبدال استدعاء سوف إيقاف عمل، كما لا توفير توافق آخر اسم. أصل حسب إصدار قبل توافق صفة قيام ساحة، هذا هو يمكن قبول، و قدرة جعل دعم حمل أمر لغة قاعدة إبقاء دقيق بسيط.

raw نشر يجب في overlay في إعلان agent و مدخل بند إعداد، جعل تطبيق حد يمكن توفير مراجعة، و قدرة متابعة امتصاص استلام قاع طبقة base تحديث. هو جمع لن خفي صيغة استقبال عدد شخص إعداد؛ حاجة هذا سياسة سياسة نشر يجب ذاتي سطر تركيب.Web ما زال هو تثبيت بعد توفير تفاعل صيغة منتج surface،headless و تلقائي تحويل مدخل ما زال إبقاء مستقل.

إعادة جذب دخول قد تسليم طرفية تطبيق، حاجة لديه أداة جسم منتج يحتاج طلب، اعتماد أداة اسم مدخل نمط بينما غير خفي صيغة raw قيمة افتراضية، و بناء قيام ذاته حالي صالح لقطة و دورة الحياة تحقق استلام وجه.
