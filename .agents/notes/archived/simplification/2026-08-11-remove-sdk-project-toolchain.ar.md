# Agent Note: إزالة SDK مشروع أداة سلسلة

Status: implemented
Archived: 2026-09-04

[English](2026-08-11-remove-sdk-project-toolchain.md) | العربية

## مشكلة

مستودع سبق يتضمن واحد طقم من لم إصدار كما لا يوجد مستهلك تطوير من مشروع منتج.`@deepseek-ai/create-sdk` لأجل توليد يمكن تحرير Cordis مشروع؛`@deepseek-ai/dsh-scripts` توفير `dsh-sdk` تطوير، بناء، بدء، إعداد و إضافة تثبيت أمر؛`@deepseek-ai/dsh-helper` تنسيق ضبط وظيفة تعريف و كثير ملف مشروع تحرير؛`@deepseek-ai/dsh-telemetry` فوق تقرير بدء جهاز نشط حركة. هذا تصميم غاية في يجعل توليد مشروع إبقاء يمكن تحرير، و جعل مشروع إنشاء و لاحق إعداد مقابل اعتماد،Cordis بند إعداد، بيئة متغير احتلال موضع رمز و ملكية ملف اعتماد نفس طقم تعريف.

لا يوجد أي مشروع هو عبر عام إصدار إصدار إنشاء، حالي مستودع و خارجي مستهلك أيضا كل لا حاجة هذا طقم دورة الحياة. إبقاء هو حينئذ معنى طعم حال متابعة صيانة 4 عدد حزمة،2 طقم تفاعل صيغة أمر منتج، مشروع نموذج لوح، حزمة إدارة جهاز مهايئ، إعداد ضبط و، بدء جهاز بعيد قياس،1 عدد مستودع skill(تقنية قدرة) و ذلك اختبار و وثيقة، لكن لا يوجد دليل جدول واضح هذا بند منتج حد ينبغي عند وجود.

نفس `scaffold/` قسم مجموعة أيضا يتضمن كل منها مستقل استخدام SDK بروتوكول،TypeScript عميل و JSON-RPC خادم. هذه حزمة لـ Python SDK،`dsh-sdk` subagent مزود و JSON-RPC عرض مثال توفير دعم حمل؛ ذلك وقت التشغيل بروتوكول لا اعتماد توليد مشروع أو يتم إزالة بدء جهاز.

## قرار

حذف SDK مشروع أداة سلسلة.`@deepseek-ai/create-sdk`،`@deepseek-ai/dsh-scripts`،`@deepseek-ai/dsh-helper` و `@deepseek-ai/dsh-telemetry` حزمة و ذلك اثنان دخول صنع ملف، اختبار، نموذج لوح، وظيفة دليل، مشروع تحرير نموذج، حزمة إدارة جهاز دعم حمل، بدء جهاز بعيد قياس و مستودع مشروع إنشاء skill متساو لا توفير بديل تنفيذ أو توافق طبقة. و ذلك مقابل workspace، بناء، اختبار، تحزيم، وثيقة توليد جهاز،vendor scope إعادة كتابة و اعتماد سجل أيضا واحد و إزالة.

إبقاء وقت التشغيل SDK.`@deepseek-ai/dsh-sdk-client`،`@deepseek-ai/dsh-sdk-protocol` و `@deepseek-ai/dsh-sdk-jsonrpc-server` إبقاء أصل مثال، من `packages/scaffold/` نقل حتى `packages/sdk/`؛ ذلك npm اسم و بروتوكول تفاعل سلوك إبقاء ثابت. مستهلك متابعة توفير واحد يمكن تنفيذ ملف و واحد نسخة خارج وضع `cordis.yml`،JSON-RPC خادم ما زال هو من هذا إعداد اختيار عادي إضافة.[مستودع تسمية اتفاق](../architecture/2026-08-11-repository-naming-contract-and-rename-ledger.ar.md) مسؤول قاعدة تحديد `SDK` في مستودع في وحيد يحتوي معنى و إبقاء حزمة اسم؛ هذا شرح مسؤول سجل قد حذف أداة سلسلة.

يتم إلغاء تطوير من مشروع، مشروع تحرير و لاحق قدرة رفع سجل إعطاء بـ حذف، بينما لا هو إبقاء لـ نشط وثب أو قد مرفوض سجل. هذا Agent Note إبقاء هذه رفع سجل مشترك لديه حركة آلة، لا تسليم هذا منتج قرار، وضع ترك قدرة، و إعادة اعتبار هذا واحد قرار شرط. قد تجميد ربط عودة ملف Agent Note ما زال هو تاريخ لقطة، لا عمل تعديل.

## تحقق

workspace في لم يعد وجود فوق وصف 4 عدد قد حذف حزمة اسم أو 2 طقم قد إزالة أمر منتج. حزمة تجمع دمج إعداد، شفرة المصدر مسار خريطة، حزمة بيانات وصفية، اختبار استلام تجميع إعداد، إصدار قيد، توليد دليل، اعتماد إعلان ملف و قفل ملف كل فقط تحليل `packages/sdk/` تحت 3 عدد وقت التشغيل SDK حزمة. وقت التشغيل SDK حزمة اختبار، قد بناء خادم خطر دخان اختبار،TypeScript مستهلك، مستودع وثيقة بوابة، بناء و hygiene فحص مشترك نفس ثابت إبقاء سلوك، و تأكيد حفظ لا وجود قديم قديم حزمة مسار.

## اعتبار مرور بديل خطة

**فقط حذف ابتدائي تحويل جهاز.** غير مقبول، لأن `dsh-sdk`، مشترك مشروع نموذج و بدء جهاز بعيد قياس كل هو لـ عملية هذا ابتدائي تحويل جهاز إنشاء مشروع، بينما قائم مشروع متساو لا حاجة هذه قدرة.

**إبقاء فقط لأجل تقرير خطأ حزمة أو أمر آخر اسم.** غير مقبول، لأن هذه أمر كل من لم عام إصدار. قبر نصب سوف في لا وجود توافق معنى خدمة حال حال تحت إبقاء حزمة و يمكن تنفيذ ملف واجهة نطاق.

**معا حذف وقت التشغيل SDK مكدس.** غير مقبول، لأن Python SDK، عملية خارج Harness subagent مزود و JSON-RPC عرض مثال هدف قبل ما زال هو بروتوكول، عميل و خادم مستهلك.

**سوف وقت التشغيل مكدس متابعة إبقاء في `packages/scaffold/` تحت.** غير مقبول، لأن هذا قسم مجموعة باق بقية محتوى متساو لم يعد مسؤول تركيب بناء مشروع.`packages/sdk/` مباشر شرح إبقاء محتوى مسؤولية، لأن `SDK` في مستودع في فقط لديه واحد يحتوي معنى: تلقي دعم حمل Python و TypeScript SDK الذي استخدام JSON-RPC عميل/خادم بروتوكول.DeepSeek Harness ذاته لا هو SDK مشروع.

## عاقبة

DeepSeek Harness لم يعد إنشاء أو إدارة مستقل تطوير من SDK مشروع. تلقائي مشروع توليد، وظيفة شجرة إعداد، محلي إضافة قدم يد هيكل، مشروع محلي تطوير، بناء و بدء أمر، و موجه إلى تطوير دورة مدة بدء جهاز بعيد قياس متساو متعمد لم يعد توفير؛ عادي تطبيق و وقت التشغيل توزيع ما زال عبر كل منها ملكية حزمة و `cordis.yml` ملف تركيب إضافة.

مستودع حذف كامل دعم حمل رسم، بينما لا هو متابعة إبقاء راحة نوم سحب كائن. إعادة جذب دخول مشروع أداة سلسلة يجب أولا لديه حقيقي مستهلك، و أساس في هذا مستهلك سير العمل رفع خروج جديد رفع سجل؛ افتراضي حال حال تحت، لن تكرار نشط هذه حزمة أو قد حذف كما لا تحمل وعد توافق صيغة.
