# Agent Note: إزالة لم يتم إزالة استهلاك web مراقبة قياس واجهة——`providers-change` حدث و status طريقة

Status: implemented
Archived: 2026-07-26

[English](2026-07-04-drop-unconsumed-web-observation-surface.md) | العربية

## مشكلة

`WebService` كشف واحد مجموعة لا يوجد أي إنتاج شفرة مراقبة قياس مراقبة قياس واجهة:

- **`web/providers-change`**(`packages/web/web/src/index.ts`) في كل مرة مزود تسجيل و dispose(مورد تحرير) وقت إعلان تزامن خروج، كما كل تسجيل effect تراجع yield يتم لحظة معنى ترتيب في emit قبل، وحيد هدف هو يجعل رمي خروج استثناء change listener قدرة رجوع تسجيل. في هذا حزمة ذاته اثنان عدد اختبار وحدة خارج لا يوجد أي listener(منها واحد اختبار وجود فقط فقط هو لـ ثابت ذلك عدد تراجع ترتيب).
- **`searchStatus()` / `fetchStatus()` و `WebCapabilityStatus` ربط دمج نوع**(نفس حزمة) لا يوجد إنتاج استدعاء جهة:`dsh-tool-web` مباشر عبر `ctx.web.search()`/`fetch()` تنفيذ، و يأخذ غير ممكن استخدام صفة عرض لـ seam في تنفيذ وقت رمي خروج بنية تحويل `WebError` code(`packages/web/tool-web/src/search.ts`،`packages/web/tool-web/src/fetch.ts`) ؛ وحيد status استدعاء جهة هو web حزمة ذاتي ذات اختبار.`packages/web/tool-web/README.md` و [architecture.md](../../../../docs/architecture.md) في متن صوت تسمية أداة “فقط قراءة تجمع دمج `searchStatus()`/`fetchStatus()`”——هذا نوع عائم نقل لـ الذي بـ تخزين متابعة، فقط هو لأن لا يوجد آلية مقابل وفق استدعاء موضع فحص متن.

seam ذاته تصميم جعل هذا اثنان عدد واجهة يوم لكن لا يوجد مستهلك: أداة تسجيل تتبع مع منتج ENABLEMENT بينما غير مزود متاح صفة (`packages/web/tool-web/src/index.ts`) ، مزود اختيار في تنفيذ وقت تحليل كما من لا ذاكرة مؤقتة——لذلك لا يوجد حاجة بطلان ذاكرة مؤقتة، لا يوجد حاجة إعادة حساب تسجيل تجميع دمج، أيضا لا يوجد استدعاء جهة حاجة واحد لديه آخر في «تنفيذ و توجيه بنية تحويل خطأ» متاح صفة استكشاف قياس.HMR(حار وحدة استبدال) تنظيف من effect disposer ذاته تحمل تحميل.

هذا و[حذف بلا شخص إزالة استهلاك `llm/adapter-change` حدث](2026-06-20-drop-unconsumed-llm-adapter-change-event.md) متبادل نداء ينبغي؛ بعد من من `LlmService` إزالة نفسه إشعار شكل حالة، نفسه emit قبل تراجع آلية و نفسه مستمع رمي خطأ اختبار. هذا Agent Note(agent قرار سجل) إبقاء/حذف معيار هو: لـ ممكن موجه إلى مستخدم أداة قائمة مستهلك إبقاء `tools/change`، حذف بدء وقت خلفية سجل التسجيل إشارة. حسب هذا واحد معيار،web مزود سجل التسجيل واضح يخص حذف واحد جانب؛status طريقة فإن هو يأخذ نفس حكم قطع تطبيق في سحب أخذ جدول وجه، بينما غير دفع إرسال جدول وجه.

## قرار

إزالة سجل التسجيل تغيير حدث، تجمع دمج status طريقة و نوع، و هو جمع مخصص تابع اختبار. مزود خاص status إبقاء لأجل تنفيذ وقت اختيار. موجه إلى استدعاء جهة نسبة التغطية الآن تأكيد نجاح تنفيذ أو بنية تحويل اختيار خطأ،web وثيقة وصف هذا حسب يحتاج استدعاء عقد نحو.

## سبق اعتبار بديل خطة

### لـ ماذا لا إبقاء؟

web seam Agent Note لحظة معنى قاعدة تحديد اثنان من——حدث بصفة الأكثر صغير HMR مرئي صفة إشارة،status طريقة بصفة أداة تجمع دمج تشخيص——لم قدوم أيضا يمكن ضبط تفكير مزود حالة وجه لوح. لكن نفس Agent Note أخرى اختيار يجعل هو جمع فقد ذهاب توليد تخزين شرط: استدعاء وقت إرسال توليد اختيار و أساس في تفعيل حالة تسجيل، جعل أي مستهلك كل غير ممكن قدرة حاجة منها مهمة واحد بند؛ قد إصدار أداة عرض حقيقي نمط (تنفيذ و توجيه بنية تحويل خطأ) ؛ حدوث عائم نقل README جملة فرعي فإن جدول واضح تحمل وعد في مستهلك من لم ظهور. حسب وفق AGENTS.md الذي وصف “Agent Note هو رفع سجل، بينما غير قطعا مقابل حق إدارة” ، شفرة بعد قدوم إثبات رفع سجل في هذه جزء تجاوز خروج حاجة؛ لم قدوم مراقبة من ينبغي أصل حسب حقيقي مستهلك شكل حالة، إعادة جذب دخول هو فعلي إزالة استهلاك الأكثر صغير إشارة أو استعلام.

## تحقق

حذف Agent Note تاريخ خارج، لم يعد وجود `providers-change`،`searchStatus`،`fetchStatus` أو `WebCapabilityStatus` تجميع كتابة؛ دليل إبقاء جديد طازج (`verify-cordis-catalog` لـ أخضر لون) ؛ تسجيل/تحرير HMR أمان صفة اختبار عبر تنفيذ سلوك إثبات تنظيف؛tool-web README و هيكل بنية مقطع سقوط أيضا وصف أداة فعلي يملك تنفيذ وقت خطأ توجيه عقد نحو.

## عاقبة

لم قدوم إذا لديه مزود اختيار جهاز UI أو تشخيص وجه لوح حاجة تغيير إشعار أو status استعلام، هو سوف إعادة إضافة ذاته الذي إزالة استهلاك الأكثر صغير واجهة؛ نفسه حكم قطع و ذلك عكس تحويل شرط قد سجل في LLM(كبير لغة نموذج) أولا مثال في.
