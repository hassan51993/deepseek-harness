# Agent Note: سوف agent توجيه إبقاء لـ خاص تنفيذ

Status: implemented
Archived: 2026-09-04

[English](2026-07-30-private-agent-send.md) | العربية

## مشكلة

عام `Agent.send()` طريقة كشف أداة جسم حلقة تنفيذ توجيه مستطيل دفعة، لكن إنتاج استدعاء جهة فقط استخدام دلالة واضح `followup()`،`steer()` و `inject()` عملية. رقم أربعة نوع تركيب، أي `next-turn` إعداد دمج `wakeup: false`، حذف اختبار خارج لا يوجد مستهلك. سوف هذا بند كامن في قدرة إبقاء لـ عام واجهة، أيضا سوف إجبار جعل أخرى `Agent` تنفيذ و اختبار بديل ذات قبول تنفيذ طبقة توجيه سياسة.

## قرار

`Agent` سوف `followup()`،`steer()` و `inject()` بصفة كامل تسليم اتفاق عام.`ReactLoopAgent` إبقاء خاص `send()` مساعد مساعدة طريقة، توفير هذا ثلاثة عدد طريقة مشترك استخدام توجيه آلية؛`dsh-agent` لم يعد توجيه خروج `SendTarget` و `SendOptions`.

عام واجهة لا يمكن في لا نداء تنبيه مشغل حال حال تحت يجعل واحد جولة دخول طابور.`followup()` بداية نهاية طلب تنفيذ،`steer()` طلب الأكثر قريب خطوة،`inject()` فإن توفير موجه إلى نموذج سياق بينما لا طلب تنفيذ. هذا قرار جزء يحل محل[موحد واحد تسليم قرار](../architecture/2026-07-22-unified-send-and-coalesced-user-messages.ar.md) في صلة في عام واجهة محتوى، معا إبقاء ذلك داخلي توجيه و موحد واحد `user/message` يمثل.

## سبق اعتبار بديل خطة

**يجعل توجيه مستطيل دفعة إبقاء عام.** هذا سوف إبقاء لم استخدام بلا نداء تنبيه ترتيب طابور تركيب، لكن أيضا سوف كشف آلية بينما غير استدعاء جهة معنى رسم، و اشتراط كل بديل مشغل كل دعم حمل هذا آلية.

**إضافة عام بلا نداء تنبيه ترتيب طابور طريقة.** استخدام أداة اسم طريقة سوف مقارنة أصلي توجيه علامة سجل أكثر صاف واضح، لكن هدف قبل لا يوجد إنتاج سير العمل حاجة يجعل عمل حمل متابعة موضع في انتظار حالة، مباشر إلى غير متصل تسليم سوف ذلك نداء تنبيه.

## عاقبة

إضافة من ثلاثة نوع دلالة عملية في اختيار، لم يعد ذاتي سطر بنية صنع توجيه خيار. أخرى مشغل و بنية نوع اختبار بديل ذات فقط يحتاج تنفيذ أكثر صغير اتفاق،Cordis API دليل أيضا لم يعد صف خروج `send`،`SendTarget` أو `SendOptions`.

فقط لديه ظهور واضح مستهلك و تعريف صريح دورة الحياة دلالة بعد، عندئذ قدرة استعادة قد إزالة بلا نداء تنبيه ترتيب طابور قدرة.`cancel({ keepInbox: true })` ما زال سوف إبقاء قد عبر تلقي دعم حمل تسليم مسار دخول انتظار معالجة حالة عمل.
