# Agent Note: حذف agent-spine demo حزمة

Status: implemented
Archived: 2026-09-04

[English](2026-08-26-remove-agent-spine-demo.md) | العربية

## مشكلة

`@deepseek-ai/dsh-agent-spine-demo` اسم و موضع سوف هو وصف لـ عرض مثال، لكن هو فعلي كشف حمل كبير نوع دمج إعداد عام تركيب إضافة. ذلك وحيد تسليم مستهلك هو `dsh-sdk-minimal`، منها واحد إضافة إعداد سطر إخفاء مطلوب agent(ذكي جسم) وقت التشغيل، بينما هذا تركيب حزمة هدف هذا هو توفير كامل، صريح إعداد شجرة. أخرى مستهلك الكل هو اختبار. هذا حزمة أيضا تكرار قد عودة `dsh-base` كل تركيب سياسة، لكن لا يوجد توفير يمكن مستقل عرض دخول قدرة.

## قرار

حذف هذا حزمة، ذلك عام إعداد و `packages/examples` قسم مجموعة، لا إبقاء آخر اسم.`dsh-sdk-minimal` الآن مباشر في patch في إعلان timer،LLM(كبير لغة نموذج) ، جلسة، عنوان، توجيه النظام، أداة،agent، إعادة محاولة، محلي خلفية مهمة، ثابت كمية سجل التسجيل و إعداد طقم مدخل، و agent loop(ذكي جسم حلقة) إعداد سطر. هو ما زال حذف مساحة العمل إشارة أمر،skill(تقنية قدرة) ، موجه إلى نموذج خلفية مهمة أداة،goal،subagent،settings و `dsh-base` أخرى وظيفة.

Profile اختبار تكامل عبر `loadProfile` تحميل قد تسليم profile و تركيب حزمة patch، مجددا يأخذ إنتاج patch و ضيق اختبار `*.patch.yml` ملف تسليم إعطاء تطبيق بدء استخدام نفس عدد أصل `cordis:include`. اختبار patch تغطية نموذج محاكاة مزود أو نموذج، عزل حفظ دائم و يتم قياس إضافة، لن إعادة إنشاء مطلوب agent إعداد شجرة. لا تغطية profile تجميع صار SDK server اختبار وحدة في محلي تركيب `dsh-agent-loop-testkit` و `dsh-agent-loop`.

## تحقق

`sdk-minimal` تركيب حزمة اختبار فحص ذلك دقيق إعداد سطر بيان و كل جهة إعداد، بناء بعد CLI اختبار فحص إخراج profile إعداد شجرة. حقيقي Loader fixture بـ اختبار overlay تغطية قد تسليم تركيب حزمة طبقة،SDK server اختبار فإن تغطية حزمة داخل testkit تركيب. إعداد، حزمة، ثابت كمية، توليد وثيقة، بناء،hygiene و لقطة بوابة تحقق لا يوجد الآن سطر منتج أو اختبار استيراد قد حذف حزمة.

## اعتبار مرور بديل خطة

**استخدام `dsh-base` استبدال هذا حزمة.** رفض، لأن `dsh-base` هو كامل منتج أساس أساس، بينما `sdk-minimal` لحظة معنى حذف ذلك settings، اعتماد، مساحة العمل سياق،skill،goal، ضغط، بعيد قياس،subagent و واسع عام أداة إعداد سطر. استخدام base استبدال سوف تغيير profile، بينما لا هو إزالة بين وصل طبقة.

**إعادة تسمية و نقل حركة عام تركيب حزمة.** رفض، لأن لا يوجد اثنان عدد تسليم منتج مشترك هذا تركيب. إعادة تسمية بعد حزمة ما زال سوف إبقاء دمج إعداد تحويل إرسال، و في profile patch في إخفاء إعداد سطر كل جهة.

**لـ اختبار إبقاء خاص مطلوب وقت التشغيل تركيب.** رفض، لأن خاص TypeScript إعداد شجرة ما زال سوف تكرار إنتاج تركيب سياسة، و ممكن انحراف مغادرة قد تسليم profile. اختبار overlay يمكن إبقاء صريح، معا لا يملك ذلك لم تعديل إعداد سطر.

## عاقبة

مسبق إصدار حزمة استيراد و دمج إعداد يتم حذف.`sdk-minimal` تغيير نيل أكثر طويل، لكن كل تركيب وظيفة كل مفرد وحيد مرئي، يمكن patch.`dsh-base` ما زال هو كامل منتج تركيب، لا يستطيع بديل أكثر صغير إعداد شجرة. قد تسليم base أو نمط تركيب حزمة حدوث تغير وقت،profile اختبار تكامل الآن أيضا سوف مع لـ تغير، لذلك ذلك Loader و recorded-session تغطية عكس عكس إنتاج إعداد شجرة، بينما غير مستو سطر اختبار تركيب.
