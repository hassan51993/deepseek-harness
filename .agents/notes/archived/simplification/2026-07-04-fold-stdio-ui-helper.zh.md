# Agent Note: سوف stdio UI مساعد مساعدة وحدة طي دخول stdio تطبيق

Status: implemented
Archived: 2026-07-26

[English](2026-07-04-fold-stdio-ui-helper.md) | العربية

بعد قدوم[زائد بقية agent(ذكي جسم) إزالة](2026-07-20-remove-stdio-and-echo-agents.md) يحل محل هذا بند حزمة وضع وضع قرار، و كامل إزالة دمج بعد حزمة، تطبيق و موجه إلى سطر جدول وجه.

## مشكلة

readline UI سبق هو واحد كامل حزمة (`packages/support/` تحت `@deepseek-ai/dsh-ui-stdio`) ، ذلك وحيد وقت التشغيل استيراد جهة هو تطبيق حزمة `@deepseek-ai/dsh-stdio-demo`. عرض مثال عبر تحميل تطبيق قدوم استخدام readline UI، من لا ذاتي سطر تركيب هذا مساعد مساعدة وحدة؛ مستودع في كل أخرى مرجع كل هو لأن حزمة حد وجود بينما وجود آلة آلة صفة أو وصف صفة جدول وجه:manifest(بيانات وصفية بيان) و tsconfig بند، توليد module-graph سطر، اعتماد رسم و README سطر، و تسمية هذا حزمة وثيقة ملاحظة تفسير.ui مجموعة README سجل support وضع وضع إدارة من ("رئيسي يلزم لـ عرض مثال و نسبة التغطية بوابة بينما وجود،`ui/` إبقاء إعطاء بصفة منتج تسليم واجهة") ، هذا إبقاء تحت واحد حمل متابعة ورقة قوة: واحد قد تسليم منتج تطبيق اعتماد واحد يتم واضح علامة ملاحظة لـ غير منتج جدول وجه support حزمة.

هذا بند حد تبديل قدوم هو: حزمة بيانات وصفية،workspace و tsconfig مرجع،module-graph سطر،README بند، و publint جدول وجه——خدمة في واحد و غير ممكن مستقل استبدال مساعد مساعدة وحدة:stdio تطبيق قبل باب تجميع مجموعة بداية نهاية يتضمن readline UI، كما لا يوجد أخرى مستهلك قدرة متعمد معنى أرض استخدام هو.

## قرار

عند وقت، هذا مساعد مساعدة دالة نقل دخول `@deepseek-ai/dsh-stdio`، يصبح طرفية عبر طريق إضافة.`createStdioChat`، ذلك `StdioRuntime` اختبار seam و اختبار وحدة مع لـ واحد نفس ترحيل، جعل EOF معالجة، تصيير، تحرير و إدارة طريق/TTY سلوك متابعة تلقي تدريجي ملف نسبة التغطية بوابة قيد، بينما لن خطف حمل عملية عام كمية. هذا وحدة إبقاء تطبيق تركيب الذي إزالة استهلاك أداة اسم `name`/`inject`/`Config`/`apply` توجيه خروج شكل حالة؛ عند وقت Echo و REPL Loader خطر دخان إثبات تركيب شجرة، إضافة شكل حالة طقم عنصر فإن ثابت صريح `unwrapExports` سلوك. فوق جهة يحل محل هذا نص إزالة سجل مسؤول حالي حزمة و عرض مثال حالة.

مبكر مدة دعم حمل مساعد مساعدة حزمة قد إزالة: ذلك بيان،tsconfig مرجع، وحدة رسم سطر و README سطر متساو قد إزالة فقد، ذلك بقية وثيقة تعديل لـ وصف حزمة داخل وحدة.

## سبق اعتبار بديل خطة

### لـ ماذا لا سوف ذلك رفع رفع إلى `ui/` بينما هو طي دخول؟

رفع رفع يمكن حل قرار support و product بين خطأ موضع، معا إبقاء حد——فقط لديه في readline UI هو واحد يمكن مستقل استبدال تجميع صار أو لديه ثاني عدد تركيب جهة وقت عندئذ هو صحيح تأكيد اختيار، بينما مستهلك عام فحص جدول واضح اثنان من جميع غير. بنية تحويل ACP(Agent Client Protocol) جسر وصل إبقاء لـ مستقل حزمة، لأن هو هو أداة لديه ذاته عقد نحو و لقطة طبقة درجة تلقائي تحويل بروتوكول جدول وجه؛readline مساعد مساعدة وحدة فقط هو واحد تطبيق قبل باب قدم يد هيكل. في إصدار قبل إعادة تفكيك قسم صار هذا جدا منخفض: إذا سوف قدوم لديه ثاني عدد منتج تطبيق حاجة readline UI، دورة وقت مجددا تفكيك خروج قدوم، من ذلك عدد مستهلك قدوم تشكيل صنع حزمة عقد نحو.

## عاقبة

- stdio تطبيق كامل يملك ذاتي ذات قبل باب؛ ورقة فرعي `cordis.yml` ما زال فقط تحميل واحد تطبيق حزمة، عرض عرض شكل لا يوجد تغير.
- لم قدوم إذا لديه مستقل طرفية UI حاجة سوف هذا مساعد مساعدة وحدة بصفة حزمة استخدام، دورة وقت من ذلك عدد ثاني مستهلك قيادة إعادة جذب دخول، بينما غير مستودع لـ زائف ضبط صفة إعادة استخدام إبقاء واحد بند حد.
