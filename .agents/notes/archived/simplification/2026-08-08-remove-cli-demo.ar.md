# Agent Note: إزالة مستقل CLI demo

Status: implemented
Archived: 2026-09-04

[English](2026-08-08-remove-cli-demo.md) | العربية

## مشكلة

في [`dsh --profile headless`](../architecture/2026-08-06-app-owned-command-line.ar.md) يصبح منتج مرة صفة أمر بعد،`@deepseek-ai/dsh-cli-demo` ما زال هو تحمل تحمل نفس عمل ثاني عدد تطبيق حزمة. هو آخر سطر يملك واحد طقم يمكن تنفيذ ملف، معامل لغة قاعدة، تطبيق تجميع، إلغاء دورة الحياة، نص/JSON/stream-JSON إخراج اتفاق، بناء ناتج، إعداد طقم وثيقة و اختبار طقم عنصر. اثنان عدد مدخل تجميع شجرة أيضا لا نفسه، لذلك demo نجاح لا يستطيع إثبات قد تسليم `headless` profile متاح، مستخدم أيضا يجب في وظيفة إعادة تراكم أمر بين عمل خروج اختيار.

إعادة تشغيل طقم عنصر ما زال حاجة مواصفة جلسة حدث قدوم ثابت تجميع بعد خلفية سلوك. هذا واحد اختبار يحتاج طلب لا حاجة قد إصدار أمر أو توافق صفة اتفاق.

## قرار

تام قاع حذف `@deepseek-ai/dsh-cli-demo`: يشمل هو حزمة،bin، محلل، تطبيق إضافة، إخراج صيغة، اختبار،workspace مرجع، توليد دليل بند و الآن سطر وثيقة. لا إبقاء آخر اسم أو توافق حزمة. شفرة المصدر مستخدم عبر `pnpm dsh --profile headless` استدعاء منتج أمر؛stdout فوق نهائي نص،stderr فوق فشل تشخيص، حفظ دائم، خروج حالة و إغلاق سلوك متساو من هذا أمر مسؤول.

`apps/cli/tests/profiles/headless` تحميل قد تسليم `base` و `headless` تركيب حزمة طبقة، لكن بعد فقط مقابل إعادة تشغيل أو نموذج محاكاة مزود، عزل حفظ دائم و يتم قياس سلوك تطبيق ضيق overlay. دعم حمل طبقة `@deepseek-ai/dsh-loader-smoke` حزمة مسؤول تسليم profile تجميع helper، مشترك مباشر agent جولة helper و فقط حد اختبار driver؛ هذا driver سوف مواصفة حدث تصيير لـ JSONL، لكن لا تعريف تلقي دعم حمل منتج إخراج صيغة.

## اعتبار مرور بديل خطة

- **إبقاء `dsh-cli-demo` بصفة `dsh --profile headless` آخر اسم أو حزمة تركيب طبقة.** غير مقبول: ثاني عدد bin و حزمة سوف يجعل نفس وظيفة متابعة وجود اثنان عدد يمكن اكتشاف ملكية جهة، لكن لا يوجد زيادة أي قدرة.
- **يأخذ JSON و stream-JSON علامة سجل نقل إلى `dsh --profile headless`.** غير مقبول: حالي لا يوجد منتج مستهلك حاجة هذه علامة سجل؛ امتداد استخدام قديم demo بروتوكول، فقط سوف لـ إبقاء اختبار آلية بينما توسيع كبير مواصفة CLI(أمر سطر واجهة) اتفاق.
- **مع حزمة واحد و حذف مواصفة حدث لقطة.** غير مقبول: هذه لقطة ثابت نموذج مرئي تجميع سلوك، بينما فقط فحص نهائي نص منتج تحقق استلام لا يمكن مراقبة هذه سلوك.
- **إبقاء تطبيق إضافة، فقط حذف هو bin.** غير مقبول: إخفاء تجميع ما زال سوف تكرار صريح headless profile، و إخفاء غطاء اختبار ورقة عقدة تركيب أي بعض خدمة.

## عاقبة

هذا هو متعمد لـ لـ كسر تالف صفة تغيير.`dsh-cli-demo`، هو `--output-format` خيار و مقابل `@deepseek-ai/dsh-cli-demo/src/cli.ts` استيراد كل لم يعد يمكن تحليل. هذا تغيير لا توفير عام حدث تدفق بديل واجهة؛ استدعاء جهة استخدام `dsh --profile headless` تنفيذ مرة صفة مهمة، حاجة بنية تحويل تلقائي تحويل وقت فإن يجب اختيار قائم بروتوكول واجهة.

مستودع عبر فقط توفير اختبار أساس أساس ضبط تطبيق إبقاء خلفية إعادة تشغيل تغطية، منتج خطر دخان اختبار و built-bin تحقق استلام فإن تشغيل `dsh --profile headless`. فقط لديه عند مستقل مرة صفة حزمة مسؤول واحد طقم حق صحيح مستقل، حمل إصدار كما لا يستطيع عودة منتج بدء جهاز كل بروتوكول وقت، هو عندئذ يمكن إعادة جذب دخول؛ ثاني نوع أمر كتابة قاعدة أو إخراج shim و لا كاف بـ بنية صار إدارة من.

## تحقق

تجمع تركيز Loader خطر دخان اختبار في شفرة المصدر نمط و من عادي Node بدء بناء نمط تحت تغطية صريح تجميع، لقطة اختبار مقابل مقارنة ذلك مواصفة JSONL و حفظ دائم سجل، منتج تحقق استلام تغطية `dsh --profile headless`، وثيقة فحص و توليد رسم جدول/دليل بوابة فإن رفض مقابل قد إزالة حزمة نشط وثب مرجع. تجميد ربط Agent Note عودة ملف إبقاء لـ تاريخ دليل، لن يتم إعادة كتابة.
