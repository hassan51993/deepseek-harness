# Agent Note: إزالة بلا مستهلك skill مزود حدث

Status: implemented
Archived: 2026-07-26

[English](2026-07-12-drop-unconsumed-skill-provider-events.md) | العربية

## مشكلة

skill(تقنية قدرة) سجل التسجيل إنتاج خروج اثنان عدد إشعار حدث، لكن لا يوجد إنتاج بيئة استماع جهة. توليد إنتاج من/مستهلك مستطيل دفعة و مقابل حدث اسم دقيق بحث جدول واضح،`skill/provider-added` و `skill/provider-removed` فقط ظهور في إعلان،emit محطة نقطة، اختبار، توليد catalog و سطر نص في.

skill اكتشاف حسب يحتاج قراءة حالي مزود خريطة جدول، مزود تسجيل وقت تزامن صاف حذف قد إتمام catalog، بينما await بعد إصدار فحص منع توقف قديم قديم اكتشاف نتيجة دخول ذاكرة مؤقتة. لا يوجد أخ أخ إضافة عبر هذه حدث انتظار skill مزود——و لـ شكل صار مقابل مقارنة هو نشط وثب `subagent/provider-added` مستهلك، هو سعة تحمل أخ أخ تزامن تحميل.

`tools/change` و `system-prompt/change` واضح لا في هذا رفع سجل نطاق داخل. قائم بسيط تحويل قرار سوف هو جمع إبقاء لـ موجه إلى فوري أداة و نص التوجيه UI متعمد مراقبة قياس نقطة، كما ذاتي مرجع قد تركيب إضافة قد في استخدام `tools/change`. هذا رفع سجل نفس مثال لا تعديل `subagent/provider-added`/`removed`، لأن `tool-subagent` لديه إنتاج بيئة دورة الحياة مستهلك.

## قرار

skill سجل التسجيل لم يعد إعلان و emit مزود عضو تغيير حدث. مزود تسجيل و dispose(مورد تحرير) ما زال لـ effect كل مباشر حالة تغيير، تزامن جعل قد إتمام catalog بطلان؛ فحص بحث و اكتشاف حسب يحتاج قراءة حالي مزود خريطة جدول. اختبار عبر مزود فحص بحث و استلام تجميع إلى إخراج قدوم مراقبة تنظيف سلوك، بينما غير اعتماد دورة الحياة إشعار.

توليد صيغة حدث دليل،API دليل و إنتاج من/مستهلك مستطيل دفعة متساو لم يعد يتضمن قد حذف إشعار.skill system Agent Note(agent قرار سجل) و حزمة وثيقة تعديل لـ عبر ذلك من effect مباشر يملك حالة و cache بطلان عقد نحو وصف تسجيل.

## سبق اعتبار بديل خطة

**لـ لم قدوم إضافة إبقاء skill مزود إشعار.** رقم ثلاثة جهة إضافة ممكن تفكير مراقبة مزود متاح صفة، لكن مباشر مزود تسجيل و حسب يحتاج فحص بحث عندئذ هو توسيع عقد نحو؛ حالي لا يوجد مستهلك حاجة دفع إرسال إشارة. إذا سوف قدوم ظهور أخ أخ تحميل تنافس حالة، يمكن مثل subagent سجل التسجيل ذلك مثال، جذب دخول واحد حمل لديه هذا مستهلك فعلي الذي يحتاج هوية و حينئذ خيط دلالة إشعار.

## عاقبة

توليد حدث مستطيل دفعة في لم يعد لديه `skill/provider-added` أو `skill/provider-removed` سطر.skill اكتشاف، مباشر وقت التشغيل تسجيل، مزود effect تراجع/dispose، ذاكرة مؤقتة بطلان و سجل التسجيل فحص بحث تنظيف إبقاء ثابت؛ استماع جهة إطلاق تراجع مع حدث واحد بدء إزالة فقد.`tools/change`،`system-prompt/change` و قد يتم إزالة استهلاك subagent مزود دورة الحياة حدث لا تلقي أثر.

مسبق إصدار مستهلك فقد ذهاب skill مزود مراقبة قياس نقطة، لكن ما زال إبقاء اثنان نوع مساهمة skill طريقة: مباشر وقت التشغيل تسجيل و مزود تسجيل. لم قدوم إذا لديه مستهلك حاجة فوري مزود متاح صفة معلومة، يجب إضافة جديدة واحد حمل لديه ذلك فعلي الذي يحتاج هوية و حينئذ خيط دلالة مخصص استخدام إشعار.
