# Agent Note: منتج subagent عام الأكثر صغير يمكن سطر حركة تشخيص

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-product-subagent-minimal-diagnostics.md) | العربية

## Problem

Claude Code و Codex مزود سوف من ذاك هذا مستقل إصدار تحويل منتج وقت التشغيل استقبال بنية تحويل فشل. إذا يأخذ هذه فوق تنقل خطأ ربط دمج كل عضو كل مرآة مثل دخول نموذج مرئي تشخيص، ذلك ما أي جعل كثير عدد صنف آخر سوف يجعل أب agent أخذ أخذ نفس نوع تحت واحد خطوة حركة عمل، كل مرة وقت التشغيل ترقية ما زال سوف توسيع كبير مزود اتفاق.

أصلي SDK خطأ،app-server payload،stderr، أمر، مسار، مهمة محتوى، بيئة قيمة و سند إثبات كل لا يستطيع يحل محل بنية تحويل خريطة، لأن هذه محتوى عبر تجاوز منتج عملية حد وقت لا يوجد مستقر أمان حفظ إثبات. أب agent ما زال حاجة كاف كاف معلومة قدوم منطقة قسم منتج حد، وصول حد، خدمة أو نقل مشكلة، بلا فاعلية نتيجة و تلقي إدارة عملية فشل.

## Decision

كل منتج مزود كل سوف أصل حسب حالي عملية و أمان بنية تحويل منتج واقع إرسال توليد قليل كمية سطر حركة صنف آخر. قائم `SubagentResult.diagnostic` نص ما زال هو وحيد عام مشترك يمثل: مستهلك فقط عرض بينما لا تحليل، مشترك subagent نتيجة حد متابعة مقابل كامل نص تنفيذ 4096 بايت UTF-8 حد أعلى.

Claude Code سوف يأخذ Agent SDK نتيجة خريطة لـ خمسة نوع صنف آخر:

| صنف آخر | أمان إدخال |
| --- | --- |
| `limit` | جولة، ميزانية أو بنية تحويل إخراج إعادة محاولة حد |
| `product-error` | واحد عام SDK تنفيذ فشل |
| `invalid-result` | علامة لـ خطأ أو محتوى فارغ أبيض نجاح نتيجة، أو ناقص نهاية حالة نتيجة |
| `process` | تلقي إدارة CLI في نهاية حالة نتيجة قبل خروج |
| `unknown` | بدء، تنظيف، لا يمكن تعرف آخر SDK قيمة، أو لا يوجد أكثر أداة جسم أمان واقع فشل |

تشخيص أيضا سوف إبقاء إرسال توليد `query-start`،`query-run`،`process` أو `teardown` مرحلة مقطع، و قسم آخر مراقبة قياس إلى خروج رمز و إشارة. مشاركة و فشل إذن قرار سوف تتبع في فشل سطر بعد. نجاح إتمام و محلي إلغاء لا عام فشل تشخيص، أصلي SDK نص فقط إبقاء في داخلي cause سلسلة و Host مراقبة قياس في.

Codex سوف يأخذ app-server فشل خريطة لـ ثمانية نوع صنف آخر:

| صنف آخر | أمان إدخال |
| --- | --- |
| `limit` | سياق، جلسة ميزانية أو استخدام كمية حد |
| `access-policy` | هوية تحقق، شبكة شبكة أمان سياسة، منتج سياسة أو sandbox فشل |
| `service` | مرور تحميل أو داخلي خدمة فشل |
| `transport` | HTTP و استجابة stream اتصال فشل أو محاولة تجربة استهلاك كل |
| `product-error` | بلا فاعلية طلب، تراجع، نشط حركة جولة أو أخرى منتج فشل |
| `invalid-result` | قد إتمام جولة لا يوجد غير فارغ أبيض نهائي جواب سجل |
| `process` | تلقي إدارة app-server في أخرى نهاية حالة نتيجة قبل خروج |
| `unknown` | بدء، تنظيف، صيغة خطأ بروتوكول قيمة، أو لا يوجد أكثر أداة جسم أمان واقع فشل |

Codex تشخيص سوف إبقاء `initialize`،`thread-start`،`turn-start`،`turn`،`process` أو `teardown`، و ملائم استخدام عدد قيمة HTTP status و قسم آخر مراقبة قياس إلى خروج رمز و إشارة.`contextWindowExceeded` ما زال يأخذ مشترك إنهاء سبب خريطة لـ `max-tokens`؛ أخرى كل صنف آخر ما زال استخدام `error`. فقط لديه بنية تحويل بروتوكول واقع سوف مساهمة إذن شرح. منتج stderr فقط توفير Host مراقبة قياس، حيث لن يتم تصنيف، أيضا لن نسخ دخول نتيجة.

### كل حق و دورة الحياة

| واقع أو عملية | مسؤولية مهمة جهة | نتيجة |
| --- | --- | --- |
| منتج خطأ حل تفسير | رسمي جهة منتج وقت التشغيل | مزود فقط إزالة استهلاك ذلك قفل تحديد تجميع صار عام بنية تحويل واقع |
| سطر حركة صنف آخر و مرحلة مقطع | مفرد مرة منتج مزود تشغيل | في فشل موضع إرسال توليد، و في نتيجة تسوية بعد إسقاط |
| خروج رمز و إشارة | `dsh-subprocess` جملة مقبض | مراقبة قياس إلى وقت قسم آخر عرض، لا دفع قطع ناقص قيمة |
| إذن قرار | منتج مزود إذن عودة ضبط أو بروتوكول | فقط في مشاركة و فشل وقت التشغيل إلحاق |
| تشخيص نقل تمرير و بايت حد أعلى | `dsh-subagent` و ذلك قبل منصة أو Job مستهلك | واحد محدود اختياري نص متابعة و assistant إخراج قسم مغادرة |

## Verification

Claude Code حزمة اختبار تغطية الكل خشن حبة درجة صنف آخر، أربعة عدد مرحلة مقطع، لم معرفة بنية تحويل قيمة، إذن ترتيب، أصلي نص ترتيب حذف، نجاح و إلغاء وقت حذف، تزامن تشغيل عزل، و ذاك هذا مستقل خروج رمز و إشارة حقل. حقيقي Agent SDK 0.3.241 و Claude Code 2.1.241 fixture سوف إنتاج فعلي max-turns حد، عملية فشل، إذن رفض، صارم إطار نهائي جواب سجل، إلغاء و كامل شجرة عملية شجرة تماما توقف مستقر.Codex حزمة اختبار تغطية الكل خشن حبة درجة صنف آخر، ستة عدد مرحلة مقطع، ملائم استخدام HTTP status، بنية تحويل إذن ترتيب،stderr ترتيب حذف، نجاح و إلغاء وقت حذف، تزامن و تنظيف تجمع دمج. حقيقي 0.149.1 app-server fixture سوف إنتاج خدمة، منتج خطأ، عملية، نهائي جواب سجل، نموذج عزل، إلغاء و تماما توقف مستقر دليل.Loader و بلا مفتاح منتج تركيب متابعة عام ساكن حالة أداة، لا زيادة تشخيص محلل أو نموذج مرئي صنف آخر إدخال.

## Alternatives considered

**إبقاء كل فوق تنقل قطعة رفع عضو.** كثير عدد عضو سوف إطلاق نفس نوع أب درجة حركة عمل، بينما فقط مسؤول عرض مستهلك لا يمكن من دقيق تأكيد اسم نيل نيل مقدار خارج سلوك. متابعة إبقاء سوف يجعل معتاد قاعدة منتج ترقية إعادة تعريف أكثر كبير Harness مرئي تحمل وعد.

**إرجاع أصلي منتج نص أو تصنيف واحد عام stderr.** ذاتي من نص ممكن يتضمن حساس شعور مهمة و بيئة بيانات، أيضا لا يوجد مستقر إصدار تحويل يحتوي معنى. فقط لديه بنية تحويل منتج واقع، مزود مرحلة مقطع، إذن قرار و تلقي إدارة عملية نتيجة يمكن يصبح إدخال.

**زيادة مشترك بنية تحويل خطأ نوع.** اثنان عدد منتج مستقل إصدار تحويل فشل، بينما حالي مستهلك فقط عرض محدود نص. مشترك قطعة رفع سوف في لا يوجد إزالة استهلاك يحتاج طلب حال حال تحت، يأخذ منتج إصدار تغيير حركة نقل دخول مزود غير متصل seam.

**أصل حسب صنف آخر إعادة محاولة أو fallback.** مزود فقط يملك مرة one-shot تشغيل، لا يوجد إعادة محاولة إذن،fallback نموذج، حمل دائم منتج جلسة أو استعادة حالة. صنف آخر فقط لأجل إشعار أب درجة، لن بدء آخر بند منتج حركة عمل.

## Consequences

منتج وقت التشغيل ترقية لم يعد اشتراط لـ كل SDK أو app-server خطأ عضو توفير نموذج مرئي تحمل وعد. أب درجة ما زال يمكن منطقة قسم حد، وصول و سياسة حد، خدمة و نقل فشل، واحد عام منتج فشل، بلا فاعلية نتيجة، تلقي إدارة عملية خروج و لم معرفة فشل، و إبقاء ملائم استخدام مرحلة مقطع، إذن،HTTP و عملية واقع.

تشخيص ما زال هو أمان عرض نص، بينما لا هو استعادة بروتوكول. هذا تعديل لا زيادة أصلي خطأ تحويل إرسال،fallback نموذج، تلقائي إعادة محاولة، منتج جلسة حفظ دائم، عام مشترك بنية تحويل نتيجة حقل أو حركة حالة مزود و نموذج اختيار.
