# Agent Note: سوف شفرة المصدر بدء و مستودع بناء قسم مغادرة

Status: implemented
Archived: 2026-09-04

[English](2026-08-12-separate-source-launch-from-build.md) | العربية

## مشكلة

TypeScript شفرة المصدر بدء جهاز بلا حاجة في كل مرة استدعاء قبل إتمام كامل مستودع بناء.Web واجهة فإن حاجة قد بناء قبل طرف و Client plugin ناتج. من نفس عدد حزمة نص برمجي معا مسؤول هذا اثنان بند عملية، سوف يجعل تكرار بدء TUI، بلا رأس نمط و Web وقت كل تحمل تحمل كل مستودع بناء تأخير متأخر، أيضا سوف إخفاء غطاء متصفح ناتج أي وقت تحديث جديد.

مرور من tsx تحميل شفرة المصدر وحدة و مرور من قد بناء تركيب حزمة تحميل متصفح وحدة أداة لديه مختلف جديد طازج درجة جدول الآن. سوف اثنان بند أمر قسم مغادرة بعد، حاجة واضح ناتج توليد مسؤولية مهمة، و دقيق تأكيد شرح ناتج ناقص و مرور مدة وقت فشل نمط.

## قرار

أصل دليل `dsh` نص برمجي فقط تشغيل `node --import tsx/esm apps/cli/src/bin.ts`.`pnpm run build` ما زال هو توليد حزمة و قبل طرف ناتج مستقل عملية. شفرة المصدر مستخدم في أول مرة إجراء صنف إنتاج بدء قبل تشغيل بناء، و في قبل طرف أو Client plugin ناتج حاجة تحديث جديد وقت مجددا مرة تشغيل.

Typert Host ناتج ناقص وقت،profile بدء سوف بسبب لا يحتوي بناء إشارة جذب وحدة تحليل خطأ بينما فشل. هذه Host ناتج وجود بعد، إذا قبل طرف أو Client plugin ناتج ناقص، بدء سوف فشل، تشخيص معلومة سوف إشارة عرض مستخدم تشغيل `pnpm run build`. بدء جهاز لن تحقق ناتج هل لـ الأكثر جديد: قد لديه قديم قديم قبل طرف أو Client plugin تركيب حزمة ما زال سوف يتم قبول، و ممكن متابعة تشغيل قديم إصدار متصفح شفرة، مباشر حتى تحت مرة بناء. كل حزمة Node نصف جانب حتى قليل بناء مرور مرة بعد،`pnpm run dev:web` فقط إعادة بناء إعلان `dsh.client` حزمة؛ هو سوف إبقاء Client plugin تركيب حزمة لـ الأكثر جديد حالة و تفعيل ذلك حار إعادة تحميل مسار، لكن لن إعادة بناء قبل طرف shell.

هذا قرار فقط قاعدة تحديد بناء ضبط درجة.[tsx ESM شفرة المصدر بدء قرار](../architecture/2026-07-29-dsh-source-launch-tsx-esm.ar.md) قاعدة تحديد TypeScript تحويل و workspace تحليل،[شفرة المصدر تشغيل قرار](2026-08-10-source-run-without-managed-installer.ar.md) قاعدة تحديد بـ مستودع نص برمجي بصفة تلقي دعم حمل فحص خروج مدخل،[عدد شخص إعداد قرار](../feature/2026-07-20-dsh-cli-personal-config.ar.md) قاعدة تحديد آلة جهاز درجة إعداد طبقة.

## اعتبار مرور تجهيز اختيار خطة

**كل مرة شفرة المصدر بدء قبل كل تنفيذ بناء.**هذا مثال يمكن توفير الأكثر قوي افتراضي جديد طازج درجة حفظ إثبات، لكن أي جعل متبادل صلة ناتج قد هو الأكثر جديد حالة، كل مرة استدعاء ما زال يلزم تحمل تحمل كل مستودع ناتج توليد فتح إلغاء.

**فقط في ناتج ناقص وقت تنفيذ بناء.**هذا مثال يمكن تجنب تجنب جزء بدء فتح إلغاء، لكن لا يمكن اكتشاف مرور مدة ناتج، أيضا سوف يجعل بناء سلوك تغيير صار من حالي نظام الملفات محتوى قرار خفي صيغة سياسة.

**من `pnpm dsh` بدء Web ناتج watcher.**هذا مثال يمكن إبقاء Client plugin تركيب حزمة لـ الأكثر جديد حالة، لكن سوف يجعل مرة صفة بدء جهاز مسؤول آخر عدد طويل وقت تشغيل عملية. صريح `pnpm run dev:web` أمر قد مسؤول هذا طقم تطوير دورة الحياة.

## أثر

- تكرار شفرة المصدر بدء بلا حاجة انتظار كامل مستودع بناء، بناء إخراج أيضا لن و CLI إخراج خلط في واحد بدء.
- شفرة المصدر مستخدم مسؤول ناتج جديد طازج درجة. ناتج ناقص سوف منع توقف بدء، لكن فقط لديه قبل طرف و Client plugin ناتج ناقص خطأ سوف إشارة عرض مستخدم تشغيل `pnpm run build`؛ قد لديه مرور مدة قبل طرف و Client plugin تركيب حزمة ممكن ساكن صامت توفير قديم إصدار متصفح شفرة.
- TUI،Web و بلا رأس نمط اختيار، معامل تحويل إرسال، بيئة وراثة، و tsx ESM بدء طريقة إبقاء ثابت.
- أصل دليل فوق يد إشارة جنوب و CLI مشاركة اعتبار سوف بناء و بدء صف لـ مستقل أمر، و شرح مرور مدة ناتج سلوك.

## تحقق

`apps/cli/tests/source-launch.compat.spec.ts` ثابت أصل دليل حزمة أمر دقيق تأكيد محتوى، و تنفيذ إنتاج شفرة المصدر بدء طريقة.`packages/bundle/web-app/tests/web-app.spec.ts` و `packages/client/modules/tests/node-half.client.spec.ts` ثابت ناتج ناقص تشخيص.
