# Agent Note: إزالة مخصص استخدام repository إضافة مسار

Status: implemented
Archived: 2026-09-04

[English](2026-08-09-remove-repository-plugin.md) | العربية

## مشكلة

repository إضافة مسار و profile تركيب حزمة مسار تكرار تنفيذ رقم ثلاثة جهة حزمة تثبيت و تركيب. هو زيادة `.dsh-plugin` manifest(بيانات وصفية بيان) ، توليد حزمة تركيب طبقة، دقيق تجهيز عمل يمكن تنفيذ ملف، ثاني طقم Git/حزمة ذاكرة مؤقتة،Loader داخل وضع بند، و repository مخصص استخدام skill(تقنية قدرة) و MCP مهايئ.profile تركيب حزمة قد قدرة عبر profile حزمة إدارة جهاز تثبيت npm أو Git حزمة شرح رمز، إبقاء صحيح معتاد اعتماد و دورة الحياة دلالة، و توفير واحد لديه ترتيب `cordis.patch.yml` طبقة، منها يمكن تركيب عادي Cordis إضافة.

تكرار مسار الذي قدرة توفير إعداد أيضا قليل في تركيب حزمة. ذلك `repositories` قائمة اختيار مصدر نص، لكن توليد حزمة تركيب طبقة تركيب شفرة مدخل وقت لا يمكن نقل دخول مستخدم توفير إضافة إعداد. لذلك،repository مخصص استخدام دقيق تجهيز مسار زيادة كبير كمية شفرة و CI عمل، لكن لا يوجد يصبح عام خارجي إضافة توزيع آلية.

## قرار

DeepSeek Harness فقط إبقاء واحد نوع مستقل خارجي إضافة توزيع مسار: يمكن تثبيت profile تركيب حزمة.`dsh plugin --profile <name> add <package-or-git-spec>` سوف اعتماد سجل إلى profile حزمة في، تثبيت حزمة عبر إعلان `dsh.bundle.patch` توفير ذاتي ذات patch طبقة. حزمة إدارة جهاز مسؤول نيل أخذ مصدر، إدارة إصدار و اعتماد، تشغيل بناء دورة الحياة، و صيانة قفل ملف. تركيب حزمة patch مسؤول اختيار Cordis إضافة و توفير كامل إضافة إعداد.

إزالة `@deepseek-ai/dsh-repository-plugin` حزمة،`.dsh-plugin` تحرير كتابة صيغة،`dsh-plugin-prepare` يمكن تنفيذ ملف، توليد حزمة تركيب طبقة، غير ممكن تغيير repository ذاكرة مؤقتة،base في `repository-plugins` بند إعداد، و مخصص استخدام GitHub تحقق استلام خط الإنتاج.vendor في لم مجددا استخدام `@cordisjs/plugin-loader/repository` فرعي مسار و ذلك مع مرفق pnpm اعتماد، أيضا مع وحيد مستهلك واحد و إزالة. قائم repository ذاكرة مؤقتة دليل فقط هو لن مجددا إنتاج أثر مستخدم بيانات؛DSH حيث لن قراءة، أيضا لن حذف هذه دليل.

تركيب حزمة مباشر تركيب قائم ملكية جهة. توفير skill تركيب حزمة تركيب `@deepseek-ai/dsh-skill-filesystem`؛ توفير MCP خادم تركيب حزمة تركيب `@deepseek-ai/dsh-mcp-client`؛ أصلي سلوك فإن تركيب عادي قد تحرير ترجمة Cordis إضافة. هذه حزمة متابعة حفظ لديه كل منها تحقق، دورة الحياة، تسجيل و teardown عقد نحو. أصل حسب مسبق إصدار توافق سياسة سياسة، لا إبقاء إبرة مقابل `.dsh-plugin` توافق محلل أو ترحيل آلية.

هذا شرح كامل دمج قد إزالة repository ذاكرة مؤقتة، ساكن حالة صيغة، صاف إعداد تجميع صار، من npm دعم حمل دقيق تجهيز مسار و تلقي معلومة مهمة شفرة مدخل قرار. ذلك أصلي حركة آلة إبقاء في هذا: مستقل مستخدم حاجة من حزمة إدارة جهاز مسؤول خارجي تركيب طريقة؛Git و npm اعتماد يمكن تنفيذ تلقي معلومة مهمة دورة الحياة شفرة؛ ساكن حالة skill و MCP مساهمة ينبغي إعادة استخدام قائم ملكية جهة؛ مصدر معرف ينبغي يقع في profile اعتماد شرح رمز و قفل ملف في. متبادل ينبغي تنفيذ خاص لديه حزمة تركيب طبقة، ذاكرة مؤقتة generation و دقيق تجهيز بروتوكول لم يعد قيد منتج.

## سبق اعتبار بديل خطة

**إبقاء repository إضافة، سوف ذلك بصفة تركيب حزمة سهل فائدة حزمة تركيب طبقة.** غير مقبول، لأن هذا سوف لـ نفس عدد حزمة إبقاء اثنان بند تثبيت أمر، اثنان نوع manifest صيغة، و اثنان طقم فشل/ذاكرة مؤقتة معرف. إذا واحد طبقة سهل فائدة حزمة تركيب لا يستطيع نقل تمرير عادي إضافة إعداد، ذلك قدرة ما زال لا و هو الذي حزمة تركيب آلية.

**يجعل repository حزمة تركيب طبقة تحميل تركيب حزمة patch.** غير مقبول، لأن repository ذاكرة مؤقتة و دقيق تجهيز بروتوكول ما زال سوف تكرار profile اعتماد تثبيت. تركيب حزمة قد يمكن عبر pnpm قبول npm،Git،file و link شرح رمز.

**لـ لم قدوم ممكن ظهور مستهلك إبقاء عام Loader repository ذاكرة مؤقتة.** غير مقبول، لأن في إزالة متبادل صلة حزمة بعد، هو قد بلا حالي مستهلك، لكن ما زال يجعل واحد vendor في و متصفح متبادل مجاور حزمة يحمل ثابت إصدار حزمة إدارة جهاز وقت التشغيل. فقط لديه عند بلا حاجة صريح تثبيت يكفي في إعداد مرحلة مقطع تنشيط هذا واحد قدرة يصبح profile اعتماد لا يمكن ممتلئ كاف منتج يحتاج طلب وقت، عندئذ لديه إدارة من إعادة جذب دخول مخصص استخدام ذاكرة مؤقتة؛ دورة وقت هذا مستهلك يمكن اختيار ذاتي ذات ذاكرة مؤقتة اتفاق.

**منع استخدام repository إضافة، لكن إبقاء ذلك مغناطيس قرص صيغة بـ توفير ترحيل.** أصل حسب مسبق إصدار جهة إبرة، غير مقبول. إبقاء محلل أو توافق loader سوف في لا يوجد خارجي توافق معنى خدمة حال حال تحت، يجعل قد إزالة عقد نحو متابعة وجود.

## عاقبة

- رقم ثلاثة جهة حزمة موحد واحد استخدام واحد نوع تثبيت و تركيب نموذج، اعتماد عادي اعتماد إعلان و كامل patch طبقة إضافة إعداد.
- تثبيت أو تحديث خارجي تركيب حزمة وقت، يجب صريح عبر `dsh plugin` تنفيذ حزمة إدارة جهاز عملية، بينما لا هو تحرير تلقي استماع مصدر قائمة. مستخدم patch HMR(حار وحدة استبدال) ما زال يمكن إعداد قد تثبيت تركيب حزمة الذي توفير بند إعداد.
- تثبيت profile وقت، مضيف آلة `PATH` في يجب توفير `pnpm`. مقابل في صريح حزمة إدارة عملية، هذا واحد اشتراط يمكن قبول، و كما يمكن تجنب تجنب فقط لـ إعداد مرحلة مقطع تنشيط بينما مع منتج تسليم قد إزالة ذاكرة مؤقتة الذي استخدام ثابت إصدار حزمة إدارة جهاز وقت التشغيل.
- `.dsh-plugin` حزمة و قائم repository مصدر قائمة patch إيقاف عمل. مستخدم ما زال يمكن ذاتي سطر حذف ذلك ذاكرة مؤقتة ملف، لكن نظام لن ترحيل أو تلقائي حذف هذه ملف.
- مخصص استخدام pnpm وقت التشغيل، دقيق تجهيز عمل يمكن تنفيذ ملف، حزمة تركيب طبقة توليد جهاز،Git اعتماد CI ضبط،repository ذاكرة مؤقتة و repository مخصص استخدام اختبار الكل إزالة فقد.
- ساكن حالة مورد حاجة واحد نوع من تركيب حزمة يملك، يمكن متبادل مقابل في حزمة تحليل مسار شكل صيغة، جعل إعلان صيغة تركيب حزمة يمكن سوف `dsh-skill-filesystem`،`dsh-mcp-client` أو أخرى إضافة إشارة نحو هو مع حزمة تسليم ملف، بينما بلا حاجة تحديد صنع وقت التشغيل شفرة. هذا قدرة عودة تركيب حزمة صيغة كل، بينما لا هو repository مهايئ.

## اختبار

ساكن حالة بوابة سوف رفض ناقص إبقاء حزمة، إعداد، وثيقة، رسم و workspace مرجع. قائم `dsh plugin` قد بناء CLI(أمر سطر واجهة) تحقق استلام اختبار تغطية profile ابتدائي تحويل، حزمة إدارة جهاز تثبيت، تركيب حزمة اكتشاف و طبقة ضبط و. إعلان صيغة، متبادل مقابل في حزمة تحليل skill و MCP تركيب حزمة مورد ما زال هو هذا إزالة طبقة في قد واضح سجل تغطية نقص فتحة.
