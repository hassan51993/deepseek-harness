# Agent Note: رفع سؤال مسودة مسودة في Session تبديل بعد إبقاء

Status: implemented
Archived: 2026-09-04

[English](2026-08-26-question-drafts-survive-session-switch.md) | العربية

## Problem

`conversation.composer` هو صارم إطار حسب Session تخطيط قسم scope slot، لذلك اختيار آخر عدد Session سوف إزالة ذلك رفع سؤال بند. عام `QuestionFlow` يأخذ حالي عنوان رقم، قد اختيار وسم، ذاتي تعريف نص و قفز مرور علامة حفظ في React مكون حالة في. لذلك، أي جعل انتظار معالجة تحميل جسم ما زال عودة Session A كل، واحد ما زال في انتظار طلب مرور مرور A → B → A Session تبديل بعد، أيضا سوف بـ فارغ جواب سجل إعادة ظهور.

مسودة مسودة هو مؤقت عرض حالة: هو يجب في حالي صفحة داخل تتبع مع الذي تابع Session، لكن لا يستطيع تغيير صار انتظار معالجة عمل خدمة تحميل جسم فوق متغير حالة، أيضا لا يستطيع يصبح عبر Host settings تزامن مستخدم انحراف جيد.

## Decision

رفع سؤال بند تسجيل إلى `conversation.composer` وقت إعلان واحد غير حفظ دائم `createQuestionDraftStore` handle.renderer لـ كل Session scope يملك واحد نسخة، و في اختيار تبديل خلال إبقاء هذا نسخة، لذلك إعادة تركيب نفس Session وقت سوف قراءة إلى نفسه دخول درجة.

store الأكثر كثير حفظ واحد طلب معرف و واحد دخول درجة قيمة: حالي عنوان رقم، و كل طريق عنوان كل واحد نسخة selected/custom/skipped مسودة مسودة. فقط لديه محلي انتظار معالجة طلب key و عنوان هدف عدد كمية كل متبادل رمز وقت،`QuestionFlow` عندئذ قراءة قد تخزين قيمة. لذلك، جديد طلب سوف قيام أي تصيير لـ فارغ، و في أول مرة كتابة وقت أصل فرعي استبدال قديم قيمة، بينما لن تراكم تراكم طلب سجل. نجاح عودة جواب و إلغاء سقوط تحديد بعد فقط صاف حذف و ذاته متبادل رمز طلب key، لذلك مرور مدة إتمام حركة عمل لن حذف مقارنة جديد مسودة مسودة.

مشغول مشغول حالة، فشل تلميح، طي حالة و تركيز نقطة سجل ما زال إبقاء في مكون محلي، لأن هو جمع وصف حالي قد تركيب تفاعل، بينما لا هو لم إتمام جواب سجل.`plan-review` عرض واجهة لا يوجد كثير عنوان مسودة مسودة، أيضا لا قراءة هذا store.

هذا سقوط فعلي قائم [Session scope قاعدة](../architecture/2026-07-25-web-client-session-scope-and-provide-channel.zh.md): حاجة عبر إعادة تركيب إبقاء حالة ينبغي عودة Session ربط بيانات مصدر؛ معا إبقاء[من Host حفظ دائم انحراف جيد قرار](2026-08-06-host-backed-web-preferences.zh.md): مسودة مسودة ما زال فقط وجود في حالي صفحة، من لا دخول settings،`localStorage` أو مغناطيس قرص.[كثير اختيار ذاتي تعريف جواب سجل تركيب](2026-07-30-multi-select-custom-answer-composition.zh.md) قاعدة تحديد جواب سجل دلالة إبقاء ثابت.

## Testing

store اختبار ثابت حسب key استبدال و مرور مدة تنظيف عزل. مكون اختبار في نفس عدد store نسخة فوق إزالة و إعادة تركيب صارم إطار Session بند، و اشتراط عنوان رقم، قد اختيار خيار و ذاتي تعريف نص الكل استعادة. بلا مفتاح تجميع Web مشهد سوف إدخال اثنان نوع جواب سجل، تبديل إلى جديد Session، إرجاع ما زال في انتظار Session، مقابل استعادة بعد تحرير جهاز توليد لقطة، مجددا مرور حقيقي رفع سؤال waterfall إيداع استعادة قيمة.

## Alternatives considered

**متابعة يأخذ حالة إبقاء في `QuestionFlow`.** لا اعتماد، لأن صارم إطار Session تبديل سوف لحظة معنى إلغاء تدمير هذا React نسخة؛ مكون محلي key لا يمكن مقارنة ذلك تجربة رسم معرف إزالة مرور مسار نشط نيل أكثر دائم.

**يأخذ متغير مسودة مسودة وضع دخول `PendingQuestion`.** لا اعتماد، لأن تحميل جسم يمثل انتظار معالجة طلب سقوط تحديد مرور مسار، بينما لا هو React عرض حالة؛ في منها فعل تغيير أيضا سوف التفاف مرور Slot store توفير حجز قراءة قراءة كتابة واجهة و دورة الحياة ملكية.

**استخدام حسب Session و طلب بناء قيام بحث جذب وحدة درجة map.** لا اعتماد، لأن plugin إعادة تحميل و Session قطع قص لا يملك ذلك تنظيف مرور مسار، قد إتمام طلب بند أيضا ممكن انفصال مغادرة renderer scope دورة الحياة لا قطع تراكم تراكم.

**عبر Host settings أو متصفح تخزين حفظ دائم مسودة مسودة.** لا اعتماد، لأن نفس صفحة داخل تبديل Session حاجة هو عبر إعادة تركيب وصل متابعة صفة، بينما لا هو عبر صفحة أو عبر عملية تحمل دائم صفة. حفظ دائم سوف يأخذ مؤقت جواب سجل نص تزامن إلى يملك هو تفاعل خارج.

## Consequences

لم إيداع عام رفع سؤال جواب سجل الآن قدرة في حالي صفحة عادي Session تنقل في إبقاء، يشمل حالي عنوان رقم و صريح قفز مرور حالة. تحديث جديد صفحة،Session scope يتم قطع قص أو انتظار معالجة طلب معرف يتم استبدال بعد، مسودة مسودة ما زال سوف إعادة وضع. كل Session داخل تخزين صار هذا يتم حد لـ واحد طلب دخول درجة قيمة، و مع Slot store Session scope واحد بدء تحرير.
