# Agent Note: demo:web بناء عميل إضافة تحزيم ناتج

Status: implemented
Archived: 2026-07-26

[English](2026-07-23-demo-web-builds-client-bundles.md) | العربية

## Problem

`dsh web` عبر `GET /plugins/<id>/client.js` توفير كل web عميل إضافة تحزيم ناتج، ذلك مسار من حزمة `exports["./client"]`(`lib/client.js`) تحليل نيل إلى. هذه تحزيم ناتج فقط من أصل دليل `pnpm run build`(أولا `tsc -b`، مجددا تنفيذ كل حزمة `tsdown.client.ts` إعداد) توليد؛Vite `build:web` خطوة فقط بناء قبل طرف خارج قشرة.`demo:web` و README Web UI شرح فقط تشغيل `build:web`، لذلك في لم مسبق أولا كامل بناء فحص خروج فوق، كل إضافة تحزيم ناتج كل إرجاع 404، عميل loader سوف كل إضافة علامة لـ فشل، بدء واجهة عرض "Failed to load plugins". قبل طرف خارج قشرة قدرة صحيح معتاد بناء، يأخذ ناقص ناتج إخفاء إخفاء في متصفح وقت التشغيل فشل خلف بعد.

## Decision

`demo:web` في `npm run build:web` قبل أولا تشغيل `npm run build`، جعل إضافة `lib/client.js` تحزيم ناتج في `dsh web` توفير هو جمع قبل قد وجود.README Web UI صغير عقدة إبرة مقابل قد تثبيت `~/.dsh/source` فحص خروج تشغيل `pnpm run build && pnpm run build:web`، لأن تثبيت جهاز من لا بناء هو.

## Verification

كامل بناء بعد، الكل ثمانية عدد `/plugins/<id>/client.js` طرف نقطة متساو إرجاع 200، بلا رأس Chromium تحميل `http://127.0.0.1:3080` قدرة تصيير خروج خارج قشرة، لم يعد ظهور "Failed to load plugins" حالة.

## Alternatives considered

**في `dsh web` بدء وقت بناء تحزيم ناتج.** هذا تطبيق عبر tsx من شفرة المصدر تشغيل، ذاته لا يوجد بناء خطوة؛ يأخذ ناتج بناء سد دخول خادم بدء مسار سوف تجاوز مرور شفرة المصدر و ناتج قسم مغادرة، و سحب بطيء كل مرة بدء.

**توسيع كبير tsdown أصل إعداد، جعل `pnpm run build:web` أيضا إنتاج خروج عميل تحزيم ناتج.** `build:web` هو Vite قبل طرف بناء؛ عميل تحزيم ناتج هو مقابل `lib/types` آخر مرة مستقل tsdown معالجة. يأخذ اثنان من دمج سوف خلط خلط خارج قشرة بناء و حزمة بناء، بينما كما أصل دليل `build` ما زال هو وحيد إنتاج خروج من.

## Consequences

`demo:web` الآن كل مرة استدعاء كل يلزم دفع خروج كامل `tsc -b && tsdown` بديل قيمة، بينما لم يعد فقط هو Vite بناء. هذا هو من جاف صاف شفرة شجرة تشغيل web عرض عرض الذي يلزم دفع خروج بديل قيمة؛ قد إتمام بناء استدعاء جهة يمكن مباشر استدعاء `dsh web`.
