# Agent Note: Web agent نيل نيل صريح وقت التشغيل سياق

Status: implemented
Archived: 2026-09-04

[English](2026-07-28-web-agent-runtime-context.md) | العربية

## مشكلة

CLI(أمر سطر واجهة) مشترك base إعداد فارغ نشر persona،Web overlay لا يوجد استبدال هو، بينما Web بدء جهاز حيث لم إضافة شفرة المصدر نص التوجيه مقطع، أيضا لم إضافة تفاعل واجهة نص التوجيه مقطع. جلسة header سوف سجل عمل دليل، توفير أداة و حفظ دائم استخدام، لكن نموذج نص التوجيه حيث لا شرح هذا دليل، أيضا لا معرف DeepSeek Harness Web GUI. لذلك، عند مستخدم رفع خروج «تعديل هذا عدد صفحة رئيسي عنوان» لـ صنف طلب وقت، أي استخدام مستخدم إشارة هو تحمل تحميل حالي جلسة GUI،agent(ذكي جسم) أيضا سوف في الذي خيار هدف في بحث واحد لم واضح شرح صفحة.

## قرار

Web profile سوف تركيب `dsh-base` و `dsh-web-app` اثنان عدد تركيب حزمة.Web تركيب حزمة توفير واحد مقطع بسيط نظيف تحرير رمز agent persona، منها يتضمن تحليل بعد `{{model}}` و جلسة `{{cwd}}`؛ عند `surfaceContext` لـ true وقت، ذلك `web-runtime` إضافة سوف إضافة `app:web-surface` نص التوجيه مقطع. تركيب profile إعداد شجرة قبل،`dsh web` آخر اسم سوف قراءة تركيب بعد نفس بند ضبط، و كما فقط في تفعيل واجهة سياق وقت تثبيت قائم `harness:source` نص التوجيه مقطع. بلا رأس تركيب حزمة و يملك كامل نص التوجيه profile كل سوف ضبط `surfaceContext: false`، من بينما كبح صنع Web نص التوجيه و تلقي إدارة shell واقع؛Web آخر اسم أيضا سوف كبح صنع شفرة المصدر نص التوجيه مقطع، بينما بلا حاجة فحص overlay مسار. كل بند قد تركيب نص التوجيه مساهمة ما زال سوف في agent loop(ذكي جسم حلقة) انتظار مستهلك إرسال خروج request header قبل تنشيط. شفرة المصدر نص التوجيه مقطع إجراء لفظ، و منها لا نيل من واحد بند مسار دفع قطع آخر بند مسار تحذير إبلاغ، متساو من آخر سطر سجل[شفرة المصدر checkout و عمل دليل منطقة قسم قرار](2026-07-30-source-checkout-workdir-distinction.zh.md) مسؤول.

Web نص التوجيه مقطع يأخذ لم حد تحديد «هذا عدد صفحة»«هذا عدد GUI» أو «هذا عدد تطبيق» حل تفسير لـ DeepSeek Harness Web GUI. معا، هو سوف واضح شرح متصفح لن خفي صيغة توفير DOM، توجيه أو قطع رسم سياق، جعل نموذج قدرة كاف تعرف آخر منتج، لكن لن صوت تسمية كف إمساك لم استلام إلى نظر شعور حالة. تجميع بعد نص سوف سجل في `request/header` في، من بينما إبقاء «نموذج مرئي محتوى يجب لديه سجل سجل» هذا واحد ثابت كمية.

## تحقق

Web وقت التشغيل اختبار وحدة سوف ثابت تفعيل و منع استخدام `surfaceContext` وقت سلوك،Web آخر اسم اختبار وحدة فإن سوف ثابت تركيب بعد إعداد سطر مقابل شفرة المصدر نص التوجيه مقطع افتراضي تفعيل و صريح منع استخدام باب تحكم. بلا مفتاح Web fresh-round-trip مشهد سوف بدء قد تسليم base و Web تركيب حزمة، عبر HTTP/SSE(Server-Sent Events) تطبيق تشغيل واحد حقيقي جلسة، و في مواصفة تحويل شفرة المصدر مسار و عمل دليل بعد مقابل توجيه النظام بادئة توليد لقطة. هذا لقطة حسب طلب ترتيب ثابت harness هوية، شفرة المصدر checkout،Web واجهة تحديد موضع، و تحليل بعد تحرير رمز agent persona.Core Web لقطة سوف تطبيق RL overlay، و ثابت لا يحتوي شفرة المصدر نص التوجيه مقطع أو Web نص التوجيه مقطع كامل توجيه النظام.

## اعتبار مرور بديل خطة

**كل مرة نص التوجيه كل إرسال URL،DOM أو قطع رسم.** هذا مرة لذا عائق فقط حاجة مستقر منتج تحديد موضع؛ حالي أصل URL لا يمكن معرف الذي اختيار مكون، رسالة اتفاق في أيضا لا وجود نظر شعور التقاط محتوى. إضافة حركة حالة صفحة حالة حاجة آخر سطر تصميم يمكن سجل نموذج إدخال، لا يخص هذا مرة إصلاح خفي يحتوي نطاق.

**اشتراط جلسة Workspace يجب هو harness checkout.** Workspace cwd هو مستخدم مهمة هدف، يمكن دمج إدارة أرض إشارة نحو فارغ مشروع أو أخرى مستودع. سوف ذلك و تطبيق شفرة المصدر موضع خلط لـ واحد حديث سوف كسر تالف هذا واحد حد، و كما ما زال لا يمكن إزالة حذف قد تثبيت إصدار أو خارجي بدء جلسة في اختلاف معنى.

**يأخذ Web نص سجل وضع دخول عام harness هوية.** `dsh-system-prompt` أيضا خدمة في TUI،ACP(Agent Client Protocol) ،SDK و لا في متصفح في تشغيل ذاتي تعريف نشر. هذا واجهة واقع ينبغي من تجميع Web تطبيق مسؤول.

**لـ كل CLI واجهة تعديل قائم شفرة المصدر موضع نص التوجيه مقطع.** TUI أيضا إعادة استخدام شفرة المصدر موضع نص التوجيه مقطع، بينما هذا مقطع فقط قديم وصف checkout واقع. مفرد وحيد إبقاء Web واجهة تحديد موضع يمكن صيانة حمل هذا نسخة يمكن إعادة استخدام اتفاق، تجنب تجنب خطأ أرض إبلاغ إبلاغ بلا رأس أو طرفية agent هو جمع صحيح موضع في متصفح في.

## أثر

معتاد قاعدة Web طلب سوف زيادة واحد مقطع مقارنة قصير كما مستقر نص التوجيه بادئة؛ نشر هذا تغيير وقت، نموذج مزود بادئة ذاكرة مؤقتة ممكن بطلان مرة.agent يمكن منطقة قسم GUI شفرة المصدر checkout و الذي اختيار Workspace، و كما بلا حاجة مجددا مرور مرور واحد جولة توضيح صاف يكفي تحليل مقابل حالي تطبيق واحد عام إشارة بديل. مقابل خاص تحديد نظر شعور حالة إشارة بديل ما زال تلقي «بلا DOM/بلا توجيه/بلا قطع رسم» هذا واحد صريح حد قيد، لا بد يلزم وقت ما زال يحتاج مستخدم توفير مسار، وصف أو مرفق عنصر. يملك كامل نص التوجيه profile يمكن عبر Web وقت التشغيل تركيب ضبط اختيار خروج، بينما بلا حاجة فحص بدء جهاز مسار.
