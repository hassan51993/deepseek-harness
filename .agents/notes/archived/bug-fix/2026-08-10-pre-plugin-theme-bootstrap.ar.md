# Agent Note: إضافة تنشيط قبل رئيسي عنوان جذب توجيه

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-pre-plugin-theme-bootstrap.md) | العربية

## مشكلة

Web قشرة في متصفح جانب إضافة شجرة تنشيط قبل عرض `Loading plugins…`.ui-theme token مثال صيغة مع حركة حالة عميل bundle وصول، لذلك لا اعتماد إطار هيكل تحميل صفحة استخدام خاص واضح داكن رجوع إعداد لون. إذا لا رفع قبل كتابة `color-scheme` و `body[data-ds-dark-theme]`، حفظ دائم انحراف جيد لـ عميق لون وقت، هذا صفحة ما زال سوف أولا حسب ضحل لون رجوع رسم صنع، مجددا في ui-theme ThemeRuntime و ui-layout ThemePresenter تنشيط بعد قطع لـ عميق لون.

`dshClient.immediately` فقط يأخذ bundle قبول دخول رقم واحد مرحلة مقطع مسبق أخذ، لن يجعل إضافة في HTML تحليل أو قشرة أول مرة تصيير قبل تنفيذ. فقط ضبط كامل عميل إضافة تحميل ملف موضع لا يمكن إغلاق هذا مقطع وقت نافذة.

## قرار

ui-theme رئيسي آلة جانب بـ واحد بند body تحديد موضع script سطر (`bootThemeInjection`) عودة ينبغي كل مرة `webserver/index-inject` استلام تجميع،`renderIndex` يأخذ هو تصيير لـ `<body>` بدء بداية وسم بعد ضيق وصل واحد مقطع تزامن داخل ربط نص برمجي. حجز قراءة هو بلا شرط——لا يوجد web server تركيب أصل هذا لن emit هذا حدث،ui-theme وفق معتاد تنشيط كما لا مساهمة أي سطر.HTML محلل تنفيذ هذا نص برمجي وقت،body قد وجود، بينما قشرة وحدة نص برمجي و لا اعتماد إطار هيكل بدء صفحة بعد لم تشغيل.

settings provider وجود وقت، رئيسي آلة جانب سوف تسجيل [`ui-theme.preference` settings قسم عقدة](2026-08-06-host-backed-web-preferences.ar.md). هو لـ كل نسخة index استجابة يأخذ مرور مرور schema تحقق داخل بناء انحراف جيد تضمين دخول داخل ربط نص برمجي؛ لا وجود settings provider أو صالح تسجيل وقت فإن تضمين دخول قيمة افتراضية `system`. متصفح عبر `prefers-color-scheme` تحليل `system`، لا دعم حمل `matchMedia` وقت رجوع لـ ضحل لون. نص برمجي فقط كتابة ThemePresenter لاحق يملك اثنان بند DOM حالة:`document.documentElement.style.colorScheme` و `body[data-ds-dark-theme]`.

جذب توجيه منطق فقط إقرار تعرف داخل بناء `light`،`dark`،`system` دلالة، لا تسجيل مستمع، أيضا لا تحليل رقم ثلاثة جهة رئيسي عنوان أو token تغطية. متصفح جانب إضافة شجرة تنشيط بعد،ThemeRuntime ما زال هو رئيسي عنوان حالة مرجعي مصدر،ThemePresenter سوف يأخذ كامل تحليل نتيجة إعادة كتابة نفس مجموعة DOM حالة و مسؤول لاحق تحديث و تحرير.

## تحقق

ui-theme اختبار وحدة تغطية لا يحتوي مهمة واحد اختياري Host خدمة وقت تنشيط، نص برمجي موضع،Host ضبط أولوية درجة، نظام انحراف جيد، نقص قليل `matchMedia`، لا يحتوي body إدخال، فوري قراءة settings، و Host تسجيل مع إضافة fiber واحد نفس تحرير. حقيقي Web تركيب Chromium مشهد سوف اختيار حفظ دائم عميق لون انحراف جيد و اعتراض إقامة إضافة bundle طلب، جعل تحميل صفحة إبقاء يمكن مراقبة، مجددا تأكيد index استجابة إنتاج عميق لون خلف مشهد،body خاصية و أصل عنصر عنصر `color-scheme`. هذا تغير لا تغيير يمكن وصول صفة شجرة، لذلك لا إنتاج جديد صفحة golden.

## اعتبار مرور بديل خطة

**يأخذ منطق ثابت كتابة دخول `apps/web/index.html`.** هذا مثال قدرة في نفسه وقت آلة تنفيذ، لكن ساكن حالة HTML لا يمكن تضمين دخول حالي Host ضبط، أيضا سوف نسخ ui-theme يملك انحراف جيد تحليل و DOM حقل؛Host تحويل سوف تتبع مع رئيسي عنوان إضافة دورة الحياة، و يجعل تطبيق قشرة بلا حاجة حل رئيسي عنوان مجال.

**يجعل ui-theme عميل bundle تزامن أو أكثر مبكر تنشيط.** `immediately` فقط تحكم مسبق أخذ، إضافة نسخة تحويل ما زال حدوث في قشرة بدء تشغيل بعد؛ يأخذ أول مرة تصيير منع سد إلى ThemeRuntime تنشيط سوف تأخير بعد مرئي تحميل و تقرير خطأ واجهة، أيضا سوف يجعل قشرة لذا عائق عرض اعتماد يتم هو مراقبة قياس إضافة شجرة.

**فقط اعتماد `prefers-color-scheme` CSS.** وسيط جسم استعلام لا يمكن قراءة صريح حفظ دائم اختيار، لذلك عملية نظام لـ ضحل لون بينما مستخدم اختيار عميق لون وقت ما زال سوف وميض وميض.

**في `<head>` في تنفيذ و إعطاء html إضافة مؤقت صنف.** body هذا وقت بعد لا وجود، أيضا حاجة واحد طقم و صحيح صيغة ضبط لون لوح خاصية مختلف مؤقت اختيار جهاز. ضيق وصل `<body>` هو قدرة كاف مباشر كتابة صحيح صيغة DOM حقل الأكثر مبكر تحليل موضع.

## عاقبة

تحميل صفحة أول لقطة و حفظ دائم داخل بناء انحراف جيد متسق؛ لم تركيب settings provider وقت فإن افتراضي اعتماد نظام انحراف جيد.index تحويل سوف لـ كل نسخة استجابة قراءة Host settings، بينما داخل ربط نص برمجي فقط يتضمن اختيار تحديد داخل بناء قيمة و `system` تحليل منطق. داخل بناء انحراف جيد دلالة أو ThemePresenter DOM حقل تغير وقت، يجب معا تحديث نص برمجي و ThemeRuntime. ذاتي تعريف رئيسي عنوان ما زال سوف في متصفح إضافة تنشيط بعد عندئذ كامل تطبيق؛ تحميل خلال، صفحة استخدام ذاتي ذات ضحل لون أو عميق لون رجوع إعداد لون.
