# Agent Note: read_image قبول بلا توسيع اسم صورة مسار

Status: implemented
Archived: 2026-09-04

[English](2026-08-28-read-image-extensionless-paths.md) | العربية

## مشكلة

`read_image` فقط حسب توسيع اسم يأخذ `file_path` خريطة إلى وسيط جسم نوع، و رفض لا يوجد توسيع اسم مسار. لذلك، نموذج يجب أولا إنشاء واحد نسخة تعديل اسم فرعي هذا، عندئذ قدرة فحص نظر دمج قاعدة بلا توسيع اسم صورة. نحو نموذج عام مواصفة تحويل محلي مرفق عنصر كائن بـ محتوى ملخص تسمية، لا حمل توسيع اسم، الذي بـ ذلك قد إصدار فقط قراءة مسار أيضا سوف إطلاق نفس بند رفض.

## قرار

`read_image` يأخذ ملف توسيع اسم نظر لـ وسيط جسم نوع إعلان.PNG،JPEG،WebP و GIF توسيع اسم اختيار كل منها إعلان نوع؛ أخرى غير فارغ توسيع اسم في نظام الملفات I/O قبل يتم رفض، مرفق عنصر تخزين كامل حل رمز سوف رفض و بايت لا مطابقة إعلان. مقابل في بلا توسيع اسم مسار، أداة عبر `ctx.fs` في قائم `maxImageBytes` و أكثر صارم إطار `maxMessageImageBytes` حد أعلى داخل قراءة ملف، مجددا من أداة داخلي `sniffImageMediaType` مساعد مساعدة دالة تعرف آخر أربعة نوع تلقي دعم حمل ملف توقيع. تعرف آخر نتيجة مرور مرور نفس طقم نشر وسيط جسم نوع سياسة و `saveImage` دقيق دخول، بعد من كامل حل رمز إبقاء مرجعي. هذا يأخذ[الأكثر صغير read_image أداة Agent Note](../feature/2026-08-10-minimal-read-image-tool.zh.md) في مقابل شم استكشاف رفض استلام ضيق إلى حمل توسيع اسم مسار.

تركيب `ctx.fs` خلفية هو `read_image` مسار تخويل كامل اعتماد حسب. توسيع اسم و ملف توقيع فقط قرار أداة هل قبول خلفية إرجاع بايت. هذا خلفية يمكن قراءة كل دمج قاعدة بلا توسيع اسم صورة كل قدرة دخول حالي جلسة، يشمل مواصفة تحويل مرفق عنصر كائن؛ أداة لا إثبات Session مرجع، مرفق عنصر خدمة أيضا لا توفير عكس نحو مسار فحص بحث.

دقيق دخول فشل سوف إشارة خروج خروج خطأ مسار. بلا توسيع اسم مسار نوع لا مطابقة سوف إشارة خروج توفير إعلان ملف توقيع، بينما لا تلقي دعم حمل بايت لن ظهور في خطأ رسالة في.

## اعتبار مرور بديل خطة

**من مرفق عنصر Service Definition حزمة توجيه خروج ملف توقيع تعرف آخر.** فقط لديه `read_image` حاجة هذا بند دقيق دخول قبل إعلان. عام هذا مساعد مساعدة دالة سوف يأخذ مفرد عدد مستهلك ملف اسم سياسة إضافة دخول مزود غير متصل مرفق عنصر API، بينما تخزين قد مسؤول مرجعي حل رمز.

**خاص خاص معالجة مواصفة تحويل مرفق عنصر كائن مسار.** يأخذ مسار عكس فحص لـ Session مرجع، سوف جعل `ctx.fs` بـ نفسه طريقة توفير اثنان عدد ملف أصل حسب مصدر إنتاج مختلف قراءة نتيجة، بينما كما عادي بلا توسيع اسم صورة ما زال لا تلقي دعم حمل. نظام الملفات وصول إبقاء قراءة تخويل قرار.

**لـ تخزين مرفق عنصر كائن زيادة توسيع اسم.** هذا سوف لـ ممتلئ كاف واحد أداة وسيط جسم نوع إعلان قاعدة بينما تعديل تخزين تخطيط و كل كائن مسار مستهلك.

## أثر

نموذج يمكن في native و PTC نمط تحت مباشر قراءة عادي بلا توسيع اسم صورة و مواصفة تحويل مرفق عنصر مسار. خطأ توسيع اسم إبقاء I/O قبل رفض و نوع لا مطابقة إصلاح تلميح. بلا توسيع اسم غير صورة مسار سوف في رفض قبل قراءة إلى صورة بايت حد أعلى، مواصفة تحويل كائن أيضا سوف إعادة مرور مرور مصدر دقيق دخول، بينما لن التفاف مرور حالي نشر حد مقدار. سلوك تعديل فقط يقع في `dsh-tool-fs`؛ مرفق عنصر Service Definition و محلي مزود إبقاء قائم API و تخزين سلوك.
