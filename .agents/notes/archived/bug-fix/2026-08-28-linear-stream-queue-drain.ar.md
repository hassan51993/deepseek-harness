# Agent Note: طويل مدة تدفق طابور صف خط صفة ترتيب فارغ

Status: implemented
Archived: 2026-09-04

[English](2026-08-28-linear-stream-queue-drain.md) | العربية

## مشكلة

عند مستهلك مشغول مشغول وقت، طويل مدة وجود تدفق طابور صف ممكن تراكم تراكم عدد ألف عدد لقطة. في مراقبة قياس إلى V8 مسار فوق، استخدام `Array.prototype.shift()` إزالة كل لقطة سوف نقل حركة باق بقية عدد مجموعة منطقة بين، لذلك ترتيب فارغ `N` عدد ترتيب طابور لقطة سوف تنفيذ اثنان مرة جهة درجة آخر مرجع نقل حركة، و تأخير متأخر نفس حدث حلقة فوق غير متصل عمل.[Issue #3270](https://github.com/deepseek-harness/deepseek-harness/issues/3270) سجل يأخذ `ArrayShift`،`MoveRange` و `memmove` تعرف آخر لـ رئيسي يلزم كومة مكدس إنتاج أخذ مثال.

تلقي أثر تدفق أداة لديه مختلف نداء تنبيه، فشل، إلغاء و disposal سلوك. هو جمع مشترك نفس اشتراط هو إبقاء FIFO ترتيب، معا لا بديل هو جمع عمل خروج هذه دورة الحياة قرار تخزين.

## قرار

`@deepseek-ai/dsh-deque` لـ Host و متصفح مستهلك يملك واحد صفر اعتماد حلقة شكل عدد مجموعة.`pushBack()`،`pushFront()` و `popFront()` تغيير بحث جذب، بينما لا نقل حركة تخزين نشط منطقة بين. إزالة سوف قيام أي صاف فارغ مقابل مجرى موضع. بعد تجهيز عدد مجموعة في ممتلئ تحميل وقت قلب ضعف، في غير فارغ مزدوج طرف طابور صف بلوغ إلى أربعة قسم لـ واحد سعة كمية وقت نقص نصف، لذلك توسيع سعة و ضغط نسخ عمل إبقاء توزيع إلغاء معتاد عدد وقت، كما تسليم خطأ طابور صف استخدام خلال فارغ خامل تخزين إبقاء محدود.

هذا حزمة لا يوجد مستهلك بين مشترك singleton حالة، رمز رقم أو صنف هوية. كل مستهلك كل سوف بنية صنع و وحيد احتلال ذاتي ذات مزدوج طرف طابور صف، لذلك npm في وجود تكرار حزمة فرعي هذا لن تغيير وقت التشغيل سلوك، إصدار اعتماد سياسة أيضا سوف يأخذ `Deque` نظر لـ أمان Host توجيه خروج.Client bundle purity قاعدة نفس مثال يأخذ هذا حزمة نظر لـ يمكن داخل ربط مكتبة.Gateway متصفح ناتج يحمل ذلك مزدوج طرف طابور صف تنفيذ، بينما لا جذب دخول module-table بند أو Cordis خدمة.

Host Remote حدث مصدر، كل قد اتصال Client Remote حدث طابور صف، متصفح Remote تدفق inbox، كل جلسة تاريخ follower، كل جلسة تحكم تدفق و كل Workspace follower كل في هذا مزدوج طرف طابور صف في تخزين لقطة. هو جمع الذي تابع صنف إبقاء الكل نداء تنبيه، فشل، إلغاء، مؤقت اندفاع ترتيب فارغ و disposal سلوك. جلسة تاريخ استخدام قبل إدراج، يأخذ منشئ نوع فرعي حدث وضع في فتح مراقبة خلال استلام إلى live حدث قبل.

طابور صف سعة كمية، لقطة دمج، مرور تحميل رفض و عام agent admission ما زال هو مستهلك أو تطبيق سياسة. مزدوج طرف طابور صف لن أصل حسب تخزين ضغط قوة دفع قطع منها أي سياسة.

## تحقق

مزدوج طرف طابور صف اختبار وحدة تغطية FIFO ترتيب، قبل إدراج، عدد مجموعة حد حلقة التفاف، بضعة أي توسيع سعة، تسليم خطأ دخول طابور و خروج طابور بعد أربعة قسم لـ واحد ممتلئ ضغط، صاف فارغ، إعادة استخدام و `undefined` بند. تجمع تركيز نسبة التغطية تقرير إبلاغ عرض `packages/util/deque/src/index.ts` لغة جملة، فرع، دالة و سطر متساو لـ 100%.

API Remote،Gateway، جلسة تحكم/تاريخ و Workspace follow اختبار تغطية ترحيل بعد دورة الحياة سلوك. هو جمع إبقاء الذي تابع حزمة مقابل ترتيب، فشل، إلغاء و disposal تأكيد.

أمر `pnpm exec tsx packages/util/deque/benchmarks/drain.ts` في Node v26.0.0،arm64 macOS 26.4 فوق تشغيل. كل قاعدة نموذج أخذ مثال خمسة مرة، نيل إلى التالي مزدوج طرف طابور صف ترتيب فارغ وقت في موضع عدد؛ قياس كمية لا يتضمن دخول طابور وقت:

| بند عدد | ترتيب فارغ في موضع عدد | كل بند قبول ثانية عدد |
|---:|---:|---:|
| 250,000 | 1.705 ms | 6.818 ns |
| 500,000 | 2.541 ms | 5.082 ns |
| 1,000,000 | 4.668 ms | 4.668 ns |
| 2,000,000 | 9.656 ms | 4.828 ns |

فحص دخول benchmark جعل هذا قياس كمية يمكن تكرار الآن، لكن CI لا قوي صنع جدار ساعة وقت عتبة قيمة. تحديد صفة وحدة نسبة التغطية مسؤول حساب قاعدة و ضغط مسار؛benchmark في الذي سجل وقت التشغيل فوق إثبات ترتيب فارغ عمل قريب يشبه خط صفة.

## اعتبار مرور بديل خطة

**عدد مجموعة رأس جزء إزالة.** إبقاء `shift()` قدرة نيل إلى الأكثر صغير شفرة المصدر فرق مختلف، لكن سوف تكرار إنتاج لذا عائق نمط، أيضا لا توفير توزيع إلغاء معتاد عدد وقت حفظ إثبات.

**مفرد ضبط رأس تنقل علامة إعداد دمج أحيانا ذلك قطع قطعة.** هذا يمكن توفير توزيع إلغاء معتاد عدد وقت FIFO إزالة، لكن جلسة تاريخ أيضا حاجة في تزامن مؤقت اندفاع بند قبل تنفيذ قبل إدراج. حلقة شكل مزدوج طرف طابور صف عبر واحد بند تخزين قاعدة معا توفير اثنان نوع عملية، لا حاجة خاص خاص تاريخ بادئة مؤقت اندفاع منطقة.

**سلسلة صيغة مزدوج طرف طابور صف.** سلسلة صيغة عقدة يجعل كل طرف نقطة عملية كل إبقاء معتاد عدد وقت، و قيام أي تحرير قد إزالة عقدة، لكن كل لقطة أيضا سوف قسم إعداد واحد عقدة و إشارة إبرة حقل. حلقة شكل عدد مجموعة إبقاء وصل متابعة تخزين، و توزيع إلغاء تردد معدل مقارنة منخفض نسخ.

**خارجي مزدوج طرف طابور صف اعتماد.** الذي يحتاج API جدا صغير، إبقاء قاعدة يشمل قيام أي صاف فارغ مجرى موضع و ارتداد اختبار يجب تغطية خاص تحديد تقليص سعة شرط. محلي صفر اعتماد أداة يجعل اثنان عدد تحرير ترجمة face كل قدرة فحص هذا تخزين دورة الحياة؛ خارجي تجميع دمج ما زال يحتاج نفسه تجميع صار و إبقاء تحقق.

## عاقبة

ترتيب فارغ backlog سوف تنفيذ خط صفة مزدوج طرف طابور صف عمل، بينما لا هو اثنان مرة جهة درجة آخر عدد مجموعة منطقة بين نقل حركة. قد إزالة لقطة مرجع في بعد تجهيز تخزين ضغط قبل يكفي عودة استلام، حمل متابعة نشط حركة تدفق أيضا لن إبقاء كل تاريخ مجرى موضع.

مستودع يملك واحد بند صغير نوع عام تجميع دمج تنفيذ و ذلك توافق صفة واجهة. مقابل ذلك بحث جذب، توسيع سعة أو تقليص سعة قاعدة تعديل حاجة تجمع تركيز ترتيب و ضغط تغطية، لأن كل قد ترحيل تدفق كل سوف مشترك نتيجة.

بلا حد إنتاج من ما زال ممكن عبر دمج قاعدة تدريجي لقطة عمل عدد كمية استهلاك كل داخل تخزين أو تأخير متأخر مستهلك. سعة كمية و admission سياسة ما زال هو مستقل قرار، بينما لا هو عام تجميع دمج في إخفاء سلوك.
