# Agent Note: DeepSeek Files تحليل فشل وقت استعادة صورة طلب

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-deepseek-files-inline-fallback.md) | العربية

## Problem

DeepSeek رسمي جهة نظر شعور توجيه استخدام مزود ملف ID، جعل تكرار طلب لا لا بد مجددا مرة إرسال صورة بايت. إذا Files طرف نقطة غير ممكن استخدام، لا تلقي دعم حمل أو واحد مباشر لا إرجاع،chat سوف في نموذج طلب بدء قبل فشل، أي جعل نفس طرف نقطة ما زال قبول داخل ربط صورة بيانات. امتداد استخدام 128MiB Files ميزانية رجوع سوف تجاوز مرور داخل ربط طلب جسم حد أعلى، مستقل تحويل صورة رجوع فإن ممكن إرسال و فشل file ID محاولة تجربة مختلف مثل عنصر.

## Decision

Files ما زال هو أول اختيار نقل طريقة. كل ورقة طلب صورة ملف تحليل كل لديه يمكن إعداد `filesApiTimeoutMs` وقت حد، افتراضي واحد قسم ساعة.stream idle وقت حد افتراضي لـ خمسة قسم ساعة، لذلك Files وقت حد عبر معتاد سوف لـ داخل ربط رجوع إبقاء خروج وقت. نشر أيضا يمكن يأخذ stream idle وقت حد ضبط نيل أكثر قصير، يجعل هو أولا إنهاء طلب. كل مرة نجاح تحليل كل سوف تحديث جديد خارج طبقة idle watchdog. استدعاء جهة إلغاء و خارج طبقة تدفق وقت حد ما زال مباشر إنهاء طلب.

ملف تحليل فشل بعد، مهايئ سوف إسقاط لـ هذا مرة chat محاولة تجربة تجميع مؤقت ملف كتلة، و استخدام base64 data URL إعادة تجميع كامل صورة طلب. كل ورقة إبقاء صورة كل إعادة استخدام قد دقيق تجهيز جيد تحديد صفة `RequestImageAttachment`؛ رجوع لن مجددا مرة حل رمز، تقليص وضع أو تحرير رمز، نفس عدد chat طلب أيضا لن خلط استخدام file ID و داخل ربط صورة. مقارنة مبكر صورة في لاحق صورة فشل قبل قد إيداع فوق نقل خريطة سوف إبقاء، توفير بعد طلب استخدام. تحت مرة طلب سوف إعادة محاولة تجربة Files، لذلك لا حاجة حفظ عملية درجة لذا عائق حالة.

داخل ربط رجوع استخدام مستقل base64 تمدد انتفاخ بعد عال ماء موضع،`maxInlineRequestImageBytes` افتراضي لـ 20MiB.`inlineImageOffloadByteQuantum` افتراضي لـ 10MiB، لذلك تجاوز مرور عال ماء موضع وقت، تحديد صفة الأكثر قديم صورة بادئة سوف دفع دخول إلى تحت واحد 10MiB إزالة حد. قائم 600 ورقة صورة حد أعلى و عدد كمية خطوة طويل متابعة توليد فاعلية. ملف نمط متابعة استخدام 128MiB عال ماء موضع و 64MiB إزالة خطوة طويل.

مزود chat خطأ متابعة استخدام قائم تصنيف. بطلان file ID سوف يتم صاف حذف، إعادة فوق نقل و إعادة محاولة مرة. إذا استبدال تحليل فشل، هذا مرة سماح إعادة محاولة سوف استخدام داخل ربط يمثل. عادي chat خطأ لا يستطيع إثبات Files تحليل فشل، لذلك لن تبديل نقل طريقة.

## Alternatives considered

**أولوية إرسال داخل ربط صورة.** لا اعتماد، لأن Files فوق نقل نجاح بعد يمكن عبر جولة إعادة استخدام تحديد صفة طلب بايت، لا لا بد في كل مرة طلب في تكرار base64.

**بعض مرة فوق نقل فشل بعد خلط استخدام قد تحليل file ID و داخل ربط صورة.** لا اعتماد، لأن طلب ما زال اعتماد حدوث لذا عائق Files خدمة، بينما كما حاجة معا معالجة اثنان طقم صورة ميزانية.

**يأخذ 128MiB Files حد أعلى لأجل داخل ربط رجوع.** لا اعتماد، لأن base64 سوف توسيع كبير سالب تحميل، و ممكن تجاوز مرور chat طلب جسم حد أعلى.20MiB ميزانية سوف لـ JSON، نص تاريخ و أداة إبقاء تحت فضاء.

**تسجيل إقامة لذا عائق، و في لاحق طلب في قفز مرور Files.** لا اعتماد، لأن عملية درجة حالة سوف جذب دخول استعادة وقت و مشترك لذا عائق حالة. تحت مرة طلب إعادة محاولة تجربة Files، يمكن في بلا حاجة إضافة جديدة حساب وقت جهاز حال حال تحت اكتشاف خدمة استعادة.

## Verification

تسلسل تحويل اختبار تغطية نفسه طلب إصدار ملف و data URL يمثل، الكل دعم حمل وسيط جسم نوع، أداة نتيجة موضع، و 20MiB إلى 10MiB base64 offload. مهايئ اختبار تغطية قيام أي تحليل فشل، جزء file ID نجاح بعد فشل، وقت حد إطلاق رجوع، بطلان ID استبدال فشل، كل داخل ربط طلب جسم، استدعاء جهة إلغاء وقت لا رجوع، و عادي chat خطأ لا تبديل نقل طريقة. إعداد اختبار تغطية اثنان بند داخل ربط ميزانية، و متبادل متبادل مستقل Files و stream idle وقت حد.

## Consequences

رمز دمج داخل ربط ميزانية صورة chat لن مجددا بسبب Files لذا عائق بينما فشل. رجوع سوف تكرار إرسال صورة بايت، بينما كما من في حد أعلى أكثر منخفض، ممكن مقارنة ملف نمط حذف أكثر كثير تاريخ. لاحق صورة فشل وقت، طلب ممكن إبقاء تحت مقارنة مبكر صورة نجاح فوق نقل، لكن هذه بحث جذب خريطة يمكن إعادة استخدام، أيضا لن تغيير رجوع إرسال chat طلب جسم. صريح ملف إدارة عملية متابعة كشف ذاته خطأ.
