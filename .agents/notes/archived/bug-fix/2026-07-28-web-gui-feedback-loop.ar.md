# Agent Note: Web GUI تعديل في قائم URL فوق إغلاق حلقة

Status: implemented
Archived: 2026-09-04

[English](2026-07-28-web-gui-feedback-loop.md) | العربية

## مشكلة

Web agent(ذكي جسم) حيث لا يمكن تعرف آخر تحمل تحميل حالي جلسة GUI، أيضا لا معرفة طريق مستخدم صحيح في فحص نظر أي عدد URL.[وقت التشغيل سياق قرار](2026-07-28-web-agent-runtime-context.ar.md) توفير قبل واحد بند واقع، لكن GUI تحرير ما زال لا يوجد يمكن تنفيذ تحقق استلام هدف: شفرة المصدر تحرير، ناتج بناء، استماع في عملية و مستخدم قد فتح صفحة فقط هو متبادل لا صلة ربط مراقبة نتيجة. مستودع توفير مدخل يجعل خطأ بديل خطة إظهار نيل دمج إدارة، لأن `apps/web/package.json` سوف `vite` كشف لـ `dev` نص برمجي، بينما عار Vite أي جعل لا يمكن حقن `window.__DSH_BOOT__`، ما زال سوف إرجاع HTTP 200.

[أمر لذا تكرار قرص](../../../../docs/postmortem/0003-web-agent-gui-feedback-loop.ar.md) تجميع في سجل حدث سجل وقت خط، و حل تفسير أصل لديه فحص لـ أي سوف قبول خطأ صفحة، عملية و طرف فتحة.

## قرار

معتاد قاعدة `dsh web` تركيب سوف تركيب Web تركيب حزمة `web-runtime` إضافة، من هو إصدار واحد مواصفة عودة حلقة URL، معا سوف ذلك بصفة نموذج مرئي واجهة تحديد موضع معلومة و تلقي إدارة shell واقع.`app:web-surface` نص التوجيه مقطع شرح: لم إضافة حد تحديد إشارة بديل إشارة نحو هذا GUI، و إعطاء خروج URL؛`DSH_WEB_URL` سوف يأخذ نفس مثال واقع نقل دخول كل مرة قبل منصة أو تلقي إدارة خلفية bash استدعاء. هذا مقطع إبقاء «لن خفي صيغة نيل نيل DOM، توجيه أو قطع رسم» هذا واحد حد، أيضا لا صوت تسمية نطاق مجال شبكة آخر اسم انتظار في متصفح في فعلي عنوان. يملك كامل نص التوجيه profile سوف يأخذ هذا إعداد سطر `surfaceContext` ضبط لـ false، و كما لن استلام إلى هذا نص التوجيه مقطع و هذا تلقي إدارة متغير؛Web بدء جهاز أيضا سوف استخدام نفس بند ضبط قدوم كبح صنع ذلك شفرة المصدر checkout نص التوجيه مقطع.

نص التوجيه يجعل agent بينما غير مستخدم مسؤول إخفاء بدء اتفاق.HMR(حار وحدة استبدال) استقبال طرف بداية نهاية تركيب، لكن عميل إضافة يلزم تلقائي إعادة تحميل، أيضا حاجة في نفس فحص خروج في تشغيل `pnpm run dev:web` استماع عملية،agent سوف في تحمل وعد بلا حاجة تحديث جديد يكفي تحديث قبل تحقق هذا واحد نقطة. خارج قشرة و أخرى عادي حزمة تغيير ما زال حاجة إعادة بناء تلقي أثر ناتج و تحديث جديد قائم URL. حذف غير مستخدم اشتراط،agent لن بدء بديل GUI.

`apps/web` تطوير نص برمجي و Vite إعداد كل سوف في فتح طرف فتحة قبل رفض خدمة نمط. تشخيص معلومة سوف إشارة خروج `apps/web` فقط هو واحد فقط توفير بناء خارج قشرة، شرح فقط لديه `dsh web` عندئذ سوف حقن `window.__DSH_BOOT__`، و إعطاء خروج إنتاج مدخل و HMR مدخل مسار.Vite بناء نمط إبقاء ثابت.

ساكن حالة ناتج حدوث تغير وقت، لا حاجة فقط لـ هذا إعادة بدء أو استبدال خادم. مضيف سوف في كل مرة طلب وقت قراءة `index.html` و ساكن حالة مورد، عميل bundle أيضا سوف من حالي ملف توفير، و ضبط `no-cache`؛ لذلك، إعادة بناء متبادل صلة خارج قشرة و إضافة bundle بعد، تحديث جديد قائم URL حينئذ هو تحقق استلام مسار. بدء آخر عدد خادم فقط قدرة إثبات آخر عدد خادم متاح. إذا مستخدم واضح اشتراط مجددا بدء واحد طويل مدة تشغيل خادم، فإن قائم تلقي إدارة خلفية مهمة اتفاق مسؤول ذلك دورة الحياة و إتمام إشعار؛shell `&` لا يستطيع بديل هذا طقم دورة الحياة آلية.

## تحقق

بلا مفتاح fresh-round-trip متصفح مشهد سوف بدء قد تسليم Web تركيب، قيادة حقيقي إعادة تشغيل جلسة، مقابل يتضمن URL توجيه النظام بادئة توليد لقطة، و استدعاء تجميع بعد bash أداة، إثبات `$DSH_WEB_URL` و فعلي ربط وقت التشغيل متسق. حقيقي CLI خطر دخان اختبار سوف بدء `dsh web` و التقاط نموذج مزود طلب، من بينما ثابت كامل مزدوج أمر تطوير اتفاق.`dev:web` watcher اختبار سوف في شفرة المصدر حدوث تغير بعد إعادة بناء عزل عميل bundle؛ متصفح HMR مشهد سوف بدء `dsh web`، تعديل ابتدائي roster في bundle، و في صفحة identity ثابت حال حال تحت مراقبة جديد DOM. حقيقي Vite عملية فرعية اختبار اشتراط خدمة نمط في إعطاء خروج تعديل استخدام كامل مضيف تصحيح صحيح معلومة بعد ذاتي لكن خروج، و عبر إدراج وتد `Server.listen()` إثبات هو من لم يتم استدعاء. حقيقي loader Web خادم اختبار سوف في عملية إتمام ربط بعد تعديل كتابة ساكن حالة مورد، و إثبات نفس طرف فتحة إرجاع جديد بايت. هذه تأكيد فحص نص التوجيه حالة، عملية خروج حالة،shell إخراج،DOM identity و HTTP بايت، بينما لا هو agent نجاح إعلان.

## اعتبار مرور بديل خطة

**فقط توسيع توجيه النظام.** غير مقبول، لأن هذا مثال سوف يجعل أداة ما زال لا يمكن نيل نيل هدف، إبقاء أداة لديه خطأ توجيه صفة عار Vite مسار، و كما لا يمكن إثبات قائم عملية مثل أي مراقبة إعادة بناء ناتج.

**حذف `apps/web` تطوير نص برمجي، لكن لا لـ Vite إضافة منع حماية.** غير مقبول، لأن أمر لذا في فعلي استخدام أمر `npx vite` سوف التفاف مرور حزمة نص برمجي. خدمة نمط ذاته يجب فشل.

**كل مرة تحرير بعد تلقائي إعادة بدء أو استبدال حالي Web عملية.** غير مقبول، لأن ساكن حالة خادم هذا حينئذ سوف في كل مرة طلب وقت قراءة حالي ناتج، إعادة بدء أيضا سوف في قطع إرسال بدء تحرير طلب جلسة، بينما عميل إضافة إعادة تحميل من بداية نهاية تركيب HMR سلسلة مسار إضافة `pnpm run dev:web` watcher مسؤول.

**كل مرة طلب كل إرسال DOM، توجيه أو قطع رسم.** دفع متأخر إلى آخر سطر تصميم قد سجل إدخال آلية. مستقر URL هوية كاف بـ إغلاق دمج هذا مرة عكس تغذية حلقة، معا لن صوت تسمية مضيف كف إمساك ذلك لم استقبال متصفح حالة.

## أثر

معتاد قاعدة Web نص التوجيه سوف زيادة واحد حركة حالة URL مقطع سقوط، لذلك نموذج مزود بادئة إعادة استخدام سوف مع ربط طرف فتحة تغير. متبادل ينبغي Bash عملية سوف زيادة واحد غير حساس شعور تلقي إدارة بيئة متغير. عار Vite لم يعد قدرة استخدام عمل فقط اعتماد shell نظر شعور صندوق رملي؛ تطوير من ينبغي تعديل استخدام كامل مضيف أو بناء نمط. بصفة تسليم تبديل،GUI عمل لديه واحد يمكن من آلية مراقبة وحيد هدف،agent يمكن نحو مستخدم شرح فعلي تحمل تحميل ذلك جلسة عملية بحث فعلا مثل أي تحديث، لا تلقي دعم حمل بدء مسار أيضا سوف في ظهور أبيض شاشة قبل فشل.URL اتفاق سوف جذب توجيه agent تجنب تجنب استخدام بديل طرف فتحة، لكن لن منع توقف مهمة معنى shell أمر بدء بديل خدمة. منع استخدام `surfaceContext` profile أيضا سوف وضع ترك هذا بند عكس تغذية إغلاق حلقة إشارة جذب و shell سياق.
