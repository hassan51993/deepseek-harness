# Agent Note: minimal preset يملك كامل RL agent تركيب

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-minimal-preset-owns-rl-composition.md) | العربية

## مشكلة

مع مرفق Web إعداد معا من اثنان عدد موضع تعريف و Claude SWE توافق RL agent(ذكي جسم): عملية درجة `core-web.cordis.yml` patch، و تدريجي جلسة `minimal` preset.[agent preset](../architecture/2026-08-03-per-session-agent-presets.zh.md) يصبح agent تركيب حد بعد،preset في حمل أثر مجال `deployment:persona` سوف استخدام قديم قديم coding-agent نص حجب حجب overlay إصلاح صحيح مرور عام persona.overlay اختبار لا يوجد تركيب preset، بينما preset اختبار بدء وقت لا يوجد overlay، لذلك اثنان من كل لا يوجد تغطية مستخدم فعلي اختيار تركيب.

هذا نوع تفكيك قسم أيضا إخفاء غطاء أخرى انحراف فرق.preset تركيب مرة صفة Bash، بينما لا هو RL harness استخدام[حمل دائم Bash](../feature/2026-07-29-persistent-bash-str-replace-editor.zh.md) ، و كما متروك تسرب RL ضغط (compaction) سياسة. إبقاء اثنان عدد كل من، سوف جعل اليوم بعد كل مرة تعديل نص التوجيه، أداة أو سياسة وقت كل يجب تحقق اثنان من تسليم تقاطع تركيب.

## قرار

مع مرفق Web `minimal` preset هو RL agent تركيب في Web في وحيد كل من. هو إعلان entry محلي PTY سجل التسجيل و محلي خلفية، حمل RL بيئة وصف كما مهلة لـ 300 ثانية حمل دائم `bash`، و `str_replace_editor`. أداة عرض ما زال من نشر اختيار. لاحق[عار مزدوج أداة وقت التشغيل قرار](../feature/2026-08-11-minimal-profiles-bare-two-tool-runtime.zh.md) يحل محل هذا سجل الأكثر أول ضغط و نظام الملفات مزود اختيار: حالي preset تركيب entry محلي `fs-local` مزود، لا تركيب ضغط خلفية. تحرير جهاز لا قبول `requireAbsolutePath` ضبط، لأن اشتراط قطعا مقابل مسار هو هو بلا شرط اتفاق.

preset persona تماما جيد هو `You are a helpful software engineer assistant.`، هو ضبط `complete: true`، و لـ ذلك agent أثر مجال كبح صنع runtime context.complete `PromptSection` مشاركة و معتاد قاعدة تجميع، لذلك أداة، متغير و تنسيق عمل صيغة مستمع ما زال سوف تحليل؛`system-prompt/assemble` waterfall(شلال نشر صيغة حدث) انتهاء بعد، نص التوجيه سجل التسجيل سوف سوف هذا مقطع سقوط مستقل فرعي هذا استعادة لـ وحيد توجيه النظام مقطع سقوط، و إسقاط كل حركة حالة سياق مساهمة. وجود كثير عدد صالح complete مقطع وقت، تجميع سوف يتم رفض. هذه نهائي سجل التسجيل قيد يمكن منع توقف harness هوية،Web تحديد موضع، أداة جذب توجيه، تجميع مستمع، صندوق رملي سياسة، دفعة دقيق سياسة، تفويض إرسال أو أخرى حركة حالة سياق مزود إضافة نموذج إدخال.

عملية درجة `core-web.cordis.yml` patch نقص مقعد. متصفح UI،workspace مرفق إضافة، حفظ دائم، عملية فرعية، صندوق رملي، إذن، نموذج توجيه و أخرى عبر جلسة خدمة ما زال من مضيف يحتفظ. اختيار `minimal` سوف تغيير واحد agent موجه إلى نموذج تركيب، و كما فقط لـ هذا agent حجب حجب مضيف نظام الملفات مزود، لن تغيير Web عملية في أخرى جلسة.

## تحقق

توجيه النظام و persona حزمة اختبار إثبات complete مقطع نهائي قيد و runtime-context كبح صنع، يشمل waterfall تعديل و تكرار بند رفض. تسليم preset تركيب اختبار في افتراضي أصلي عرض تحت تأكيد دقيق نص التوجيه،Bash وصف، اشتراط قطعا مقابل مسار تحرير جهاز schema و مزدوج أداة دليل. بلا مفتاح Web إعادة تشغيل عبر `minimal` agent إرسال واحد حقيقي طلب، معا تسجيل عام هوية،Web تحديد موضع نص، حركة حالة سياسة سياق و واحد اختبار مقطع سقوط؛ هو تأكيد لا وجود runtime-context لقطة،entry محلي نظام الملفات هو عار خلفية كما ضغط لا وجود، مع بعد تنفيذ اثنان مرة حمل دائم Bash استدعاء، إثبات بيئة و cwd حالة قدرة كاف إبقاء، و عبر قطعا مقابل مسار تنفيذ تحرير جهاز.

مستقل [`sdk-minimal` تركيب حزمة](../../../../packages/bundle/sdk-minimal/README.zh.md) هو `dsh --profile sdk-minimal` كامل مزدوج أداة تركيب.[عار مزدوج أداة وقت التشغيل قرار](../feature/2026-08-11-minimal-profiles-bare-two-tool-runtime.zh.md) شرح ذلك بدء طريقة مخصص تابع بيئة إعداد، عار نظام الملفات و بلا compaction اختيار؛[مستقل profile قرار](../architecture/2026-08-24-standalone-sdk-minimal-profile.zh.md) مسؤول ذلك launcher و تركيب حزمة موضع. ذلك بلا مفتاح SDK عملية اختبار سوف تأكيد تجميع بعد توجيه النظام و مزدوج أداة دليل،installed-wheel مشهد سوف عبر استدعاء تنفيذ حمل دائم Bash و استخدام تحرير جهاز؛Python SDK تعليم مسار توفير يمكن تشغيل مدخل.

## اعتبار مرور بديل خطة

**سوف `core-web.cordis.yml` إبقاء لـ توافق patch.** يتم رفض، لأن عملية patch و جلسة preset هو نفس agent اتفاق اثنان عدد مستقل كل من؛ أولوية درجة سوف جعل مهمة معنى واحد جهة كل قدرة ساكن صامت سحب إلغاء آخر جهة إعداد.

**في preset في منع استخدام كل معروف نص التوجيه مساهمة جهة.** يتم رفض، لأن مضيف سطر يخص كامل عملية، جديد مساهمة جهة أيضا سوف إعادة فتح وضع نص التوجيه. من تجميع نص التوجيه سجل التسجيل فعلي تطبيق نهائي complete مقطع قيد، عندئذ قدرة جدول بلوغ هذا بند لا تحديد حفظ إثبات.

**فقط استخدام قبل وضع waterfall مستمع غربلة اختيار مقطع سقوط.** يتم رفض، لأن آخر عدد قبل وضع حزمة تركيب طبقة يمكن في هذا مستمع خارج تنفيذ، و في غربلة اختيار بعد إلحاق محتوى. في كامل waterfall انتهاء بعد فعلي تطبيق قيد، عندئذ قدرة مستقر يملك نهائي قرار حق.

**في Web مضيف فوق تركيب PTY خدمة.** يتم رفض، لأن فقط لديه minimal agent إزالة استهلاك هذه خدمة.entry محلي `pty` realm و وحيد مستهلك أداة لديه نفسه دورة الحياة و أثر مجال، بلا حاجة من preset إصدار عملية درجة عام خدمة.

## عاقبة

Web RL نص التوجيه ثابت ثابت، لا يستطيع عبر بيئة تغطية؛ مستقل JSON-RPC نص التوجيه من نشر اختيار.Web preset و `sdk-minimal` profile في كل منها بدء مسار مشترك حمل دائم shell إضافة editor سلوك؛`sdk-minimal` في Windows فوق اختيار PowerShell.Shell حالة حسب agent عزل، و مع هذا agent واحد و إزالة فقد.Web preset لـ ذاته PTY و عار نظام الملفات خدمة نسخة تحمل تحمل فتح إلغاء، أخرى preset بلا حاجة تحمل تحمل.Web preset Bash خلفية حاجة تلقي دعم حمل POSIX طرفية أساس أساس بيئة، لذلك هذا preset لا دعم حمل Windows agent.
