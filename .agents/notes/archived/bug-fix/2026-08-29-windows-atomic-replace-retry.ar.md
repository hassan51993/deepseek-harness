# Agent Note: إعادة محاولة Windows فوق لحظة وقت أصل فرعي استبدال فشل

Status: implemented
Archived: 2026-09-04

[English](2026-08-29-windows-atomic-replace-retry.md) | العربية

## مشكلة

عند آخر عدد نظام مكون يحتفظ هدف ملف وقت،Windows ممكن بـ `EACCES`،`EBUSY` أو `EPERM` مؤقت وقت رفض استبدال قد لديه ملف rename. عبر عملية كتابة قفل قدرة كاف ترتيب ترتيب تطبيق داخل متبادل متبادل تنسيق عمل كتابة جهة، لكن لا يمكن تحرير هذا خارجي جملة مقبض، لذلك يأخذ رقم مرة خطأ عند عمل دائم دائم فشل سوف يجعل هذا قدوم صالح ضبط أو اعتماد تحديث مع آلة فشل.

## قرار

`writeFileAtomic` مسؤول استبدال إعادة محاولة، لأن كل ملف نوع تخزين كل حاجة نفسه حفظ إثبات. هو فقط في Windows فوق إعادة محاولة `EACCES`،`EBUSY` و `EPERM`، الأكثر كثير ثمانية مرة، تأخير متأخر من 20 جزء ثانية إشارة عدد زيادة طويل حتى 200 جزء ثانية. كامل مرور مسار في، نفس نسخة قد كامل كتابة مؤقت أخ أخ ملف بداية نهاية بصفة rename مصدر؛ استدعاء جهة يحتفظ كتابة قفل أيضا سوف إبقاء إلى `writeFileAtomic` انتهاء.

أخرى رمز خطأ و أخرى عملية نظام سوف قيام أي فشل. إعادة محاولة ميزانية استهلاك كل بعد، دالة إزالة مؤقت أخ أخ ملف و إعادة رمي خروج الأكثر بعد واحد نظام الملفات خطأ؛ من في أي محاولة تجربة كل لن حذف أو قطع قطع قائم هدف، هدف محتوى إبقاء ثابت.

## اعتبار مرور بديل خطة

**إعادة محاولة اعتماد تغيير.** مستهلك درجة إعادة محاولة ما زال سوف يجعل ضبط و لم قدوم تخزين كشف في نفس مشكلة، بينما كما إعادة وضع مرة قراءة-تعديل-كتابة عملية ممكن تكرار أصل فرعي استبدال خارج عمل. مشترك أصل لغة هو فقط مسؤول استبدال إعادة محاولة الأكثر ضيق كل من.

**في rename قبل حذف هدف.** حذف هدف سوف يجعل قراءة جهة مراقبة إلى ملف ناقص، و وضع ترك أصل فرعي استبدال، لذلك لا يستطيع بصفة استعادة خطوة.

**بلا حد إعادة محاولة.** دائم دائم إذن خطأ سوف من هذا تعليق إقامة كتابة جهة و كل قفل تنافس تنازع من. محدود تأخير متأخر يمكن امتصاص استلام لحظة وقت ملف احتلال استخدام، معا إبقاء يمكن مسبق قياس فشل نتيجة.

## عاقبة

واحد لحظة وقت Windows جملة مقبض الأكثر كثير سوف يجعل مفرد مرة استبدال كثير انتظار 1.1 ثانية، مع بعد نهائي محاولة تجربة فشل. في هذا خلال، قراءة جهة متابعة يرى كامل قديم هدف؛ نجاح ما زال من مرة أصل فرعي rename إتمام. ارتداد اختبار حقن كل نوع يمكن إعادة محاولة خطأ، دائم دائم خطأ، غير Windows خطأ و إعادة محاولة استهلاك كل، و مراقبة rename محاولة تجربة و دفع دخول زائف وقت ساعة، بينما لا اعتماد حقيقي وقت sleep.
