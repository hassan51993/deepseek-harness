# Agent Note: شبكة صفحة رسم علامة مع إعداد لون خطة تبديل

Status: implemented
Archived: 2026-08-10

[English](2026-08-10-web-favicon-dark-mode.md) | العربية

## مشكلة

`apps/web/public/favicon.svg` يأخذ DeepSeek رسم علامة رسم صنع لـ صاف أسود لون (`fill="#000"`) ، بينما `index.html` فقط إعلان هذا واحد SVG رسم علامة. عند عملية نظام أو متصفح موضع في داكن لون إعداد لون خطة وقت، وسم شريط نفس مثال هو عميق لون، أسود لون رسم علامة فعلي فوق غير ممكن رؤية.Safari 26 قبل إصدار لا تصيير SVG favicon، لذلك هذه إصدار Safari مستخدم بلا نقاش أي نوع إعداد لون خطة كل نظر لا إلى وسم صفحة رسم علامة.

## قرار

favicon إبقاء مفرد واحد ملف، و عبر متصفح ذاته إعداد لون خطة إشارة ذاتي ملائم ينبغي:`favicon.svg` داخل تضمين `@media (prefers-color-scheme: dark) { path { fill: #fff } }`، في داكن لون خطة تحت يأخذ رسم علامة تبديل لـ أبيض لون، ضحل لون خطة إبقاء أسود لون.`index.html` و `manifest.webmanifest` معا إعلان 32×32 PNG التقاط قاع (`favicon-32x32.png`،DeepSeek صنف لوحة أزرق `#4D6BFE`) ،Safari 26 قبل إصدار سوف تصيير هذا PNG، كما هو في ضحل لون و عميق لون وسم شريط فوق كل صاف واضح مرئي؛ هذا هو مقابل [Web تثبيت manifest قرار](../feature/2026-08-06-web-install-manifest.md) توسيع.

رئيسي عنوان إشارة أخذ عملية نظام/متصفح خطة، بينما لا هو GUI تطبيق داخل `dsh.theme` فتح صلة:favicon يقع في متصفح chrome في، ذلك خلف مشهد تتبع مع متصفح خطة، لذلك `prefers-color-scheme` هو صحيح تأكيد دلالة، بلا حاجة أي JavaScript. معروف متصفح غريب ميل——Chromium في تبديل خطة بعد ممكن يلزم إلى تحديث جديد صفحة عندئذ إعادة رسم وسم رسم علامة،Safari 26 قبل إصدار تجاهل اختصار SVG تغيير جسم——متساو يتم قبول، قديم إصدار Safari مشهد من PNG التقاط قاع تغطية.

## سبق اعتبار بديل خطة

- **إضافة جديدة إشارة نحو مستقل داكن لون SVG ثاني عدد `<link rel="icon" media="(prefers-color-scheme: dark)">`.** غير مقبول: دلالة نفسه لكن يلزم كثير صيانة واحد ملف، متبادل مقارنة ملف داخل وسيط جسم استعلام لا يوجد أي استلام فائدة.
- **من رئيسي عنوان presenter في `theme/change` وقت استبدال رسم علامة href.** غير مقبول: هو سوف تتبع مع تطبيق داخل فتح صلة، بينما لا هو حق صحيح قرار وسم شريط لون لون متصفح خطة، و كما لـ واحد chrome مورد جذب دخول عميل شفرة و presenter.
- **لا توفير PNG التقاط قاع.** غير مقبول:Safari 26 قبل إصدار من لا تصيير SVG favicon، التقاط قاع هو هذه إصدار نيل نيل وسم رسم علامة وحيد طريق مسار.

## عاقبة

ضحل لون خطة ما زال عرض أسود لون رسم علامة، داكن لون خطة عرض أبيض لون،Safari 26 قبل إصدار اثنان نوع خطة كل عرض أزرق لون PNG.`apps/web/tests/pwa-manifest.e2e.ts` ثابت تأكيد PNG رابط و ذلك يقع في SVG قبل ترتيب،manifest في اثنان عدد رسم علامة، تسليم PNG صيغة و مقياس قياس، و تسليم SVG داخلي داكن لون وسيط جسم استعلام.Chromium إعادة رسم غريب ميل ما زال هو متصفح سلوك، تطبيق لا يمكن إصلاح.
