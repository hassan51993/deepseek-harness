# Agent Note: حفظ إثبات Code Mode نتيجة بطاقة محتوى كامل

Status: implemented
Archived: 2026-07-26

[English](2026-07-20-code-mode-result-card-completeness.md) | العربية

## مشكلة

خارج طبقة `run_code` أداة سوف حفظ دائم كامل تصيير محتوى، لكن ذلك UI عرض جهاز تجاهل اختصار هذه محتوى، تحويل بينما أصل حسب فقط يحتوي سجل `presentationMeta` إسقاط إعادة بناء بطاقة متن. فقط لديه نتيجة تشغيل نظر يشبه صحيح تأكيد، هو لأن عرض جهاز متن لـ فارغ وقت، مستهلك سوف رجوع إلى `tool/result.content`. فقط يلزم برنامج إخراج واحد بند سجل، عرض جهاز حينئذ سوف توفير غير فارغ محتوى، رجوع مع أي إيقاف، قيمة راجعة سهل سوف من إتمام حالة بطاقة في إزالة فقد. عند قد التقاط سجل جعل قديم قديم إسقاط تغيير لـ غير فارغ وقت، إخراج سقوط قرص سياسة نهائي توليد رأس ذيل معاينة أيضا سوف تلقي إلى نفس مسؤولية تفكيك قسم أثر.

تضمين طقم Code استدعاء من لا توليد ذاتي ذات بطاقة. لذلك، فقط فقط لـ إعادة بناء هذا واحد ورقة لا كامل بطاقة بينما إعطاء خارج طبقة استدعاء توليد بيانات وصفية، أيضا إخفاء غطاء كل مرة خارج طبقة استدعاء فقط توليد واحد ورقة بطاقة مسبق مدة حد.

## قرار

مواصفة أداة سجل التسجيل خط الإنتاج مسؤول نهائي موجه إلى نموذج خارج طبقة محتوى. نجاح وقت،`run_code` إخراج مصير أولا تصيير قد التقاط سجل، لكن بعد تصيير قيمة راجعة أو صريح بلا إخراج علامة. وقت التشغيل فشل و تنفيذ قبل سياسة رفض من `ToolRegistry` عودة واحد تحويل لـ خطأ محتوى، مرور مسار في لن استدعاء هذا مصير.Post-execute منع قطع حدوث في نجاح تصيير بعد، و يأخذ نتيجة استبدال لـ خطأ محتوى؛ أخرى post-execute سياسة و إخراج سقوط قرص قرار يمكن في حفظ دائم قبل استبدال محتوى.

`run_code` لا توفير `presentResult`. قائم عام نتيجة رجوع آلية سوف إبقاء انتظار إتمام برنامج عنوان، و تصيير أصلي نهائي `tool/result.content`؛ هذا واحد حمل دائم، يمكن إعادة تشغيل كما مرور مرور post-policy معالجة إسقاط هو بطاقة في نتيجة محتوى وحيد مصدر. مضيف API بديل إدارة لذلك لا توفير مفرد وحيد نتيجة عرض، بينما لن في `event.data.content` و `view.view.content` في تكرار تسلسل تحويل نفس محتوى. زائد بقية فقط يحتوي سجل `presentationMeta` إسقاط متابعة إبقاء إزالة حالة.

تضمين طقم توزيع إبقاء ثابت. حمل لديه `exec.parent` علامة استدعاء سوف إرسال خروج `tool/code-dispatch` حدث (يحمل كامل تصيير محتوى) ، لكن لن توليد و `tool/call` أو `tool/result` مقابل واجهة بطاقة، لذلك مرة خارج طبقة `run_code` استدعاء ما زال فقط سوف توليد واحد ورقة بطاقة.

## اختبار

أداة اختبار وحدة عبر مواصفة سجل التسجيل تغطية فقط لديه سجل، فقط لديه نتيجة، سجل و نتيجة و تخزين، بلا إخراج، نتيجة سقوط قرص و فشل نتيجة، لكن بعد ثابت حمل دائم محتوى و نتيجة عرض جهاز لا وجود هذا واحد واقع. مضيف mux ارتداد اختبار استخدام فقط لديه استدعاء عرض جهاز، إثبات نتيجة لقطة تماما جيد يحمل مرة أصلي محتوى، كما لا يحتوي عرض. هذه سجل مثال إثبات قديم قديم بيانات وصفية لا يمكن استبدال نهائي محتوى، معا لن يجعل مضيف تكرار هذا محتوى.

بلا مفتاح ACP(Agent Client Protocol) خلفية لقطة و TUI Code Mode لقطة سوف تنفيذ واحد خارج طبقة برنامج: برنامج إجراء اثنان مرة تضمين طقم bash استدعاء، سجل `captured output`، و إرجاع `CODE_ONE+CODE_TWO`.ACP حفظ دائم سجل ثابت كامل نتيجة؛TUI واجهة فقط عرض واحد ورقة إتمام حالة خارج طبقة بطاقة، منها يتضمن هذا اثنان سطر محتوى، كما لا يوجد تضمين طقم بطاقة.

## تجهيز اختيار خطة

**يأخذ قيمة راجعة إلحاق إلى سجل بيانات وصفية:**غير مقبول. بيانات وصفية سوف و مصير تكرار، و كما حاجة لـ كل واحد نوع JSON أصل آخر سطر صيانة مستقر صيغة تحويل عقد نحو؛post-policy محتوى استبدال أو إخراج سقوط قرص معاينة ما زال سوف يتم متروك تسرب.

**يأخذ عرض بيانات وصفية و `result.content` دمج:**غير مقبول. تصيير محتوى قد يتضمن سجل؛ دمج سوف صنع صار تكرار، أيضا حاجة اعتماد هش ضعيف ذهاب إعادة منطق.

**عبر عام نتيجة عرض جهاز تحويل إرسال `result.content`:**غير مقبول. حمل دائم حدث قد يحمل هذا محتوى،UI مستهلك أيضا قد لديه عام أصلي محتوى رجوع آلية. مضيف mux سوف في حدث جانب تسلسل تحويل أداة يملك نتيجة عرض، لذلك تحويل إرسال فقط فقط هو لـ إعادة بناء هذا رجوع آلية، لكن سوف في واحد لقطة في تكرار تصيير محتوى؛ فقط افتراضي worker في تصيير قبل سماح 64 MiB متغير تحميل حمل ميزانية.

**لـ كل مرة تضمين طقم توزيع إنشاء واحد ورقة بطاقة:**غير مقبول. في بين قيمة متعمد فقط وجود في تنفيذ خلال، دائم بعيد لا موجه إلى نموذج. كثير ورقة بطاقة سوف كشف تنفيذ مسار أثر، بينما لا هو نموذج و مستخدم استدعاء مفرد مرة Code Mode عملية.

## أثر

TUI و JSON-RPC/Web عبر عام نتيجة رجوع آلية عرض و نموذج استقبال و إعادة تشغيل حفظ دائم نفسه كامل محتوى، منها يشمل post-policy إخراج سقوط قرص معاينة. مضيف API إبقاء انتظار إتمام برنامج عنوان، معا لا في مفرد وحيد عرض سالب تحميل في تكرار أصلي نتيجة. جديد `run_code` نتيجة لم يعد يحمل اختياري سجل بيانات وصفية، لكن بلا حاجة رفع رفع جلسة صيغة إصدار: قائم سجل ما زال صالح، لأن عرض منطق سوف قراءة منها حفظ دائم تصيير محتوى.
