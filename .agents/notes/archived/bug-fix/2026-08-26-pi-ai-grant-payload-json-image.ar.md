# Agent Note: pi-ai grant payload سقوط قرص ذلك JSON مثل

Status: implemented
Archived: 2026-09-04

[English](2026-08-26-pi-ai-grant-payload-json-image.md) | العربية

## Problem

مرة موجه إلى github.com GitHub Copilot تسجيل تسجيل في إيداع حلقة عقدة فشل:`credentials-local: record "llm-pi-ai/github-copilot" payload holds a value JSON cannot represent`.pi-ai Copilot اعتماد بـ صريح `undefined` يحمل اختياري عضو (لم ملء Enterprise مجال اسم وقت لـ `enterpriseUrl: undefined`——هذا هو `JSON.stringify` سوف مباشر إسقاط JavaScript معتاد استخدام كتابة قاعدة) ، بينما `llm-pi-ai` تخزين جسر وصل يأخذ اعتماد كائن أصل مثال بصفة grant payload إيداع. اعتماد تخزين تحقق جهاز صحيح عند أرض رفض `undefined` لـ غير ممكن يمثل، في هو كل مسار إبقاء لديه لم ملء اختياري عضو grant كل لا يمكن سقوط قرص، مزود قد إتمام تخويل بعد تسجيل تسجيل لكن تقرير فشل.

## Decision

`packages/llm/llm-pi-ai/src/auth.ts` `toRecord` تعديل لـ سقوط قرص grant اعتماد JSON مثل:`jsonImage` إسقاط عادي كائن داخل صريح لـ undefined عضو، يأخذ عدد مجموعة في undefined بند تصيير لـ `null`، و `JSON.stringify` تماما متسق. ذلك بقية واحد قطع——غير لديه حد عدد، مختلف نوع أصل نوع كائن——أصل مثال نفاذ نقل، لذلك حق صحيح غير ممكن تخزين قيمة ما زال سوف في تخزين تحقق جهاز موضع كبير صوت فشل، بينما لا هو يتم ساكن صامت تعديل كتابة. قراءة عودة ثابت: عضو ناقص و صريح undefined مقابل بـ خاصية قراءة وصول اختياري عضو pi-ai مستهلك غير ممكن منطقة قسم.

## Testing

`tests/auth.spec.ts` مرور حقيقي `LocalCredentialProvider` كتابة Copilot شكل حالة grant(صريح `undefined` عضو، تضمين طقم إسقاط، عدد مجموعة فارغ ثقب) ، تأكيد سقوط قرص payload لـ JSON مثل؛ ثاني عدد حالة استخدام إيداع حمل `Date` عضو grant و تأكيد تخزين رفض وصول استدعاء جهة، إثبات fail-loud مسار ما زال في.

## Alternatives considered

**`JSON.parse(JSON.stringify(credential))`.**مرفوض: هو أيضا سوف يأخذ `NaN`/`Infinity` تصيير لـ `null` و تنفيذ `toJSON` طريقة، يأخذ صارم إطار تحقق جهاز هذا يلزم كبير صوت رفض قيمة ساكن صامت تعديل كتابة إسقاط.

**وضع عرض تخزين تحقق جهاز، قفز مرور undefined عضو.**مرفوض:seam تخزين payload هو من لا قراءة أو تعديل كتابة، كل إنتاج جهة كل اعتماد تدريجي بايت نحو إرجاع؛ عودة واحد تحويل يخص حل ذاتي بيت مكتبة معتاد استخدام قاعدة إنتاج جهة، بينما لا هو كل إضافة مشترك تخزين.

**في pi-ai فوق تنقل إصلاح إسقاط لم ملء عضو.**لا في هذا مستودع كف تحكم داخل كما مع إصدار هش ضعيف: سوف قدوم أي مسار إعادة جذب دخول هذا معتاد استخدام قاعدة كل سوف مجددا مرة فعل تالف تسجيل تسجيل. من جسر وصل طبقة يملك هذا مرة قلب ترجمة، يجعل harness مقابل كامل صنف مشكلة تجنب وباء.

## Consequences

كل pi-ai مسار grant بلا نقاش إبقاء فارغ أي بعض اختياري عضو كل قدرة سقوط قرص. جسر وصل طبقة الآن يملك مرة مفرد نحو عودة واحد تحويل: كتابة وقت صريح لـ undefined عضو في قراءة عودة وقت ناقص، هذا مقابل خاصية وصول غير ممكن منطقة قسم، كما صحيح هو وثيقة تحويل JSON دلالة.
