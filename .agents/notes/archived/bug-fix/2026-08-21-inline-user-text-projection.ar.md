# Agent Note: قد إرسال مستخدم نص سطر داخل إسقاط،Queue سطر طي wire مرجع

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-inline-user-text-projection.md) | العربية

## مشكلة

قد إرسال مستخدم نص وجود اثنان عدد عرض نقص فتحة، كل مبكر في Lexical composer. مستخدم هواء فقاعة تركيب زينة جهاز (`projectUserText`، عند وقت هو `MessageItem` خاص دالة) يأخذ واحد بند رسالة قطع صار عادي قطعة مقطع و مرجع chip، لكن كل عادي قطعة مقطع كل مرور كتلة درجة `MessageText` div تصيير——يتم تركيب زينة مفرد سطر رسالة لذلك يتم تفكيك صار كل مقطع واحد سطر، اثنان عدد متبادل مجاور token بين مفرد عدد فارغ إطار أكثر هو تصيير صار واحد كامل سطر فارغ أبيض. آخر موضع،queue dock فقط قراءة سطر أصل مثال ضرب طبع `row.preview`، يحمل chip ترتيب طابور رسالة لذلك عرض wire جلسة شكل صيغة `@[فحص نظر و قسم تحليل صورة](dsh-session:InNlc3Npb24t…)`——موجه إلى نموذج نص، بصفة معاينة غير ممكن قراءة. اثنان موضع حمل دائم نموذج نص كل هو صحيح تأكيد (قد مقابل وفق جلسة سجل بايت نواة فعلي) ؛ اثنان عدد نقص وقوع كل صاف تابع عرض طبقة.

## قرار

من واحد مشترك سطر داخل إسقاط `reference/user-text.tsx` مسؤول قد إرسال مستخدم نص عرض، هواء فقاعة و queue سطر مشترك نفس إزالة استهلاك:

- **واحد قطع سطر داخل.** عادي قطعة مقطع تصيير لـ `span`؛ كتلة درجة `MessageText` تام قاع خروج هذا مسار. تبديل سطر سياسة عودة مستهلك: هواء فقاعة إعلان `pre-wrap`(حقيقي تبديل سطر إبقاء) ،queue معاينة إبقاء `nowrap`/حذف رقم مفرد سطر——مشترك span اثنان من كل لا تثبيت ميت.
- **wire جلسة شكل صيغة طي.** إضافة جديدة الأكثر عال أولوية درجة قاعدة يأخذ `@[label](dsh-session:…)` طي لـ عرض وسم جلسة chip(أصل نص إبقاء في `title`). قائم قاعدة——recall صلة ربط دقيق وسم، حسب شكل حالة تعرف آخر عار `/name` / `@name` token——حسب أصل أولوية درجة تتبع مع، لذلك طي معا حجب إقامة عار token مسح (لا فإن هو سوف يأخذ URI خطأ قراءة صار ملف مسار).
- **Queue تحرير حالة إبقاء أصل نص.** سطر تحرير إطار عرض لم مرور معالجة `row.text`: مستخدم تحرير صحيح هو سوف يلزم إرسال محتوى، طي واحد يمكن تحرير جدول وجه سوف يجعل مرئي نص و حمل دائم نص انفصال خطاف.

`queue-actions.e2e` تحديد موضع جهاز من `getByText(…).locator('..')` تعديل لـ سطر حاوية مطابقة (حمل `hasText` `li`): إسقاط كثير واحد طبقة span، من أمر العربية هذا نحو فوق قفز واحد درجة لم يعد سقوط في سطر عنصر عنصر فوق.

## سبق اعتبار بديل خطة

- **في ترتيب طابور نموذج نص جانب آخر تخزين واحد نسخة عرض نص**: مرفوض——لـ عرض صلة قطع زيادة wire/جلسة حقل، مخالفة خلف مفرد واحد حق مصدر؛ تصيير مدة طي لا حاجة جديد حالة.
- **تحرير إطار داخل أيضا طي**: مرفوض——تحرير كائن حينئذ هو حرف وجه إرسال نص، يمكن تحرير جدول وجه طي سوف يجعل مستخدم"تحرير"واحد مقطع و غير فعلي إرسال نص.
- **فقط استخدام CSS إصلاح هواء فقاعة فارغ سطر**(طي فارغ قطعة مقطع): مرفوض——قطعة مقطع كتلة درجة صفة هو بنية صفة، كما queue نقص فتحة هذا قدوم حينئذ حاجة مشترك إسقاط.

## عاقبة

- يتم تركيب زينة مفرد سطر رسالة تصيير لـ واحد سطر؛ الآن ساحة تقرير إبلاغ في هواء فقاعة من أربعة نظر شعور سطر (يحتوي واحد فارغ سطر) خفض إلى ذاتي لكن تبديل سطر عال درجة.
- Queue معاينة حسب composer في مثال فرعي عرض: وسم chip يحل محل `dsh-session:` URI؛wire شكل صيغة إذا دخول حمل دائم نص، هواء فقاعة نفس مثال طي.
- `MessageItem` و `QueueDock` مشترك واحد طقم تركيب زينة مفردات و مثال صيغة جدول (`user-text.module.css`) ؛chip مثال صيغة نقل خروج `MessageItem.module.css`.
- اختبار:`user-text.client.spec` تثبيت إقامة سطر داخل حفظ إثبات (صفر `div`، قطعة مقطع إبقاء فارغ أبيض) و كل بند طي قاعدة؛chat-view حرف وجه نص مطابقة جهاز مع عنصر عنصر تغير تحديث.
