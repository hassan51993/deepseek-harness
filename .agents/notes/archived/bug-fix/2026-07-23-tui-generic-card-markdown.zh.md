# Agent Note: TUI عام بطاقة Markdown تصيير

Status: implemented
Archived: 2026-08-04

[English](2026-07-23-tui-generic-card-markdown.md) | العربية

## Problem

أداة عرض جهاز يمكن في عام بطاقة (generic card) محتوى في كتابة Markdown، منها يشمل لأجل خلفية مهمة تأكيد و تنفيذ خطأ محيط شريط `console` إخراج. يأخذ هذه محتوى حسب صاف نص تصيير سوف كشف محيط شريط علامة، و و نفس transcript(نص سجل) في مساعدة يد محتوى و مستخدم محتوى عرض لا متسق.

## Decision

TUI أولا استخدام مشترك Markdown رئيسي عنوان تصيير عام بطاقة نتيجة محتوى، مجددا تطبيق بطاقة رأس ذيل سطر عدد حد. طرفية بطاقة و diff بطاقة إبقاء كل منها مخصص باب صاف نص مصير؛ عام بطاقة أصلي إدخال ما زال حسب حرف وجه عرض، لأن هو بديل جدول هو أداة معامل، بينما غير عرض جهاز تأليف كتابة سطر نص.

مشترك رئيسي عنوان إخفاء محيط شريط لغة قاعدة، إبقاء اختياري لغة وسم، و سوف محيط شريط متن حسب شفرة إعداد لون. تصيير أولا في قطع قطع تنفيذ، لذلك استلام بدء حالة بطاقة سطر عدد و حد وصف هو مرئي طرفية سطر، بينما غير Markdown مصدر نص سطر.

## Alternatives considered

**في Bash عرض جهاز في تقشير حذف محيط شريط.**هذا فقط إصلاح واحد إنتاج جهة، أخرى أداة إنتاج عام بطاقة Markdown ما زال لن يتم تصيير، أيضا سوف يجعل عرض جهاز اعتماد TUI سلوك.

**يأخذ كل نوع أداة بطاقة كل حسب Markdown تصيير.**طرفية إخراج و diff لديه مخصص باب صيغة، كما ممكن يتضمن يجب إبقاء حرف وجه عرض Markdown علامة نقطة.

**في Markdown تصيير قبل تطبيق استلام بدء حالة بطاقة سطر عدد حد.**حسب مصدر نص سطر قطع قطع ممكن من في بين قطع قطع محيط شريط كتلة، أيضا سوف يجعل مرئي سطر عدد و بطاقة استخدام سطر عدد لا متسق.

## Consequences

عام أداة بطاقة و محادثة محتوى استخدام نفس طقم Markdown مفردات و صاف تحويل مسار. عام بطاقة في Markdown علامة نقطة سوف يتم حل تفسير، بينما لم يعد مجموع هو حسب حرف وجه عرض؛ حاجة حرف وجه طرفية إخراج أداة استخدام طرفية بطاقة هذا واحد تصيير معنى رسم.

تجمع تركيز TUI اختبار ثابت إخفاء محيط شريط، إبقاء لغة وسم و متن نص. بلا مفتاح طرفية حالة لقطة عبر تجميع بعد TUI transcript تغطية هذا سلوك.
