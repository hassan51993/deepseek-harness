# Agent Note: Web إيقاف عملية إبقاء انتظار معالجة Queue

Status: implemented
Archived: 2026-09-04

[English](2026-07-31-web-stop-preserves-queue.md) | العربية

## مشكلة

Web إيقاف حسب زر استدعاء `session.cancel`، بعد من خريطة إلى واسع معنى `agent.cancel({ kind: 'user' })`. في نشط حركة جولة خلال، عادي composer إيداع قد يتم وصل قبول لـ يمكن مستقل بحث عنوان Queue دخول طابور بند. مستخدم فقط تفكير إيقاف حالي توليد وقت، واسع معنى إلغاء لكن سوف إسقاط كل دخول طابور بند، خلط خلط جولة في قطع و Queue صريح حذف عملية.

متصفح لا يمكن عبر إعادة إرسال مرئي سطر إصلاح هذا واحد ضرر فقد. هو لا يملك هذه سطر فوري `InboxItemId`، نداء تنبيه سياسة أو إقرار قيادة تنافس حالة؛ إعادة إرسال أيضا ممكن تكرار Host قد إقرار قيادة عمل.

## قرار

`session.cancel` هو Web Host API موجه إلى عادي جلسة نشط حركة جولة إيقاف عملية. هو سوف بـ `agent-busy` رفض من جلسة دعم دعم subagent؛ لا فإن سوف استدعاء `agent.cancel({ kind: 'user' }, { keepInbox: true })`، في تنسيق عمل صيغة في توقف حالي جولة معا إبقاء انتظار معالجة inbox عمل. قاع طبقة خيار سوف إبقاء queued و steering دخول طابور بند؛Web Queue إسقاط متابعة فقط كشف queued دخول طابور بند.

AgentLoop لن بدء تزامن بديل جولة. هو سوف إغلاق و flush يتم في قطع جولة، بلوغ إلى إلغاء تماما توقف مستقر، لكن بعد عبر قائم FIFO مشغل إقرار قيادة تحت واحد يمكن نداء تنبيه queued دخول طابور بند. هذا إقرار قيادة سوف إرسال خروج `agent/inbox/dequeue`، لذلك Host مرجعي `session/queue` لقطة سوف تراجع دور قد إقرار قيادة سطر، و جعل باق بقية طابور ذيل إبقاء مرئي. متصفح حيث لا إعادة إرسال، أيضا لا رفع رفع أي سطر. تجاهل اختصار إلغاء عمل سوف تأخير متأخر هذا واحد تسليم وصل، مباشر إلى هذا عمل تسوية.

هذا خريطة فقط أكثر تعديل Web عميل استخدام Host `session.cancel` طرف نقطة.`Agent.cancel()` افتراضي اتفاق ما زال لـ واسع معنى إلغاء،ACP و TUI إبقاء قائم إلغاء سياسة،`AgentHandle.dispose()` في تفكيك إزالة خلال ما زال سوف صاف حذف انتظار معالجة عمل. إزالة Queue سطر ما زال هو لأجل إسقاط مفرد عدد انتظار معالجة دخول طابور بند صريح Web عملية.

## اعتبار مرور بديل خطة

**إيقاف حسب زر متابعة استخدام واسع معنى إلغاء.** لـ الذي بـ مرفوض: إيقاف مرة توليد لا ينبغي إلغاء تدمير قد مستقل ترتيب طابور مستخدم معنى رسم؛Queue قد يملك صريح حذف عملية.

**إلغاء بعد من متصفح إعادة إرسال تحت واحد سطر.** لـ الذي بـ مرفوض:Host يملك دخول طابور بند معرف و إقرار قيادة ترتيب. عميل إعادة إيداع ممكن تكرار عمل، إعادة ترتيب FIFO، أو و مرجعي خروج طابور إنتاج تنافس حالة.

**يتم إلغاء عمل بلوغ إلى تماما توقف مستقر قبل بدء تحت واحد جولة.** لـ الذي بـ مرفوض: اثنان عدد جولة سوف تزامن تعديل نفس جلسة سجل، و مشترك Agent يملك مورد. تنسيق عمل صيغة إلغاء سوف مثل فعلي انتظار نشط حركة عمل تسوية.

**لـ واسع معنى إلغاء و إبقاء صيغة إلغاء إضافة بروتوكول خيار.** لـ الذي بـ مرفوض: في Web منتج توفير مستقل «إيقاف و صاف فارغ Queue» تفاعل قبل، لا حاجة هذا خيار. قائم إيقاف حسب زر فقط لديه واحد بند سياسة، بينما تدريجي سطر حذف قد توفير حالي إسقاط تحكم عنصر.

## تحقق

AgentLoop تغطية سوف إبقاء واحد نشط حركة نموذج تدفق، سوف اثنان عدد يمكن نداء تنبيه جولة ترتيب طابور، استخدام `keepInbox` إلغاء، و ثابت تحقق أولا في توقف، بعد إتمام جولة سبب،FIFO مستخدم رسالة ترتيب، لا وجود discard حدث، و نهائي فارغ خامل حالة. بلا مفتاح Web مشهد عبر HTTP/SSE قيادة قد تجميع تركيب: هو إيقاف واحد بطاقة إقامة جولة، مراقبة طابور ذيل إبقاء مرئي وقت تحت واحد queued دخول طابور بند بدء، مجددا إيقاف هذا جولة، و مراقبة الأكثر بعد واحد queued دخول طابور بند إتمام. ذلك يمكن وصول صفة لقطة ثابت في بين Queue إبقاء حالة.

## عاقبة

Web إيقاف سوف إبقاء قد وصل قبول ترتيب طابور معنى رسم، و في إلغاء مثل فعلي تسوية بعد تلقائي دفع دخول. لا إعداد دمج إلغاء نشط حركة عمل استلام ذيل وقت،Queue سطر ممكن ما زال إبقاء مرئي؛ من نفس inbox خيار إبقاء خارجي steering يمكن دخول تحت واحد قد وصل قبول جولة، كل إدارة Web لن في QueueDock في تصيير steering. لم قدوم دفعة كمية صاف فارغ تفاعل حاجة صريح منتج عملية، بينما لا هو مرور تحميل إيقاف.
