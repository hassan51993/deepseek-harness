# Agent Note: ذاتي لديه تشغيل انتهاء سبب تقرير إبلاغ

Status: implemented
Archived: 2026-09-04

[English](2026-08-11-owned-run-finish-reason.md) | العربية

## مشكلة

Python SDK مستهلك حاجة بسيط نظيف أرض حكم قطع ذاتي لديه نشط حركة منطقة بين مثل أي دخول idle. اشتراط كل مستهلك مسح أصلي `turn/end` حدث سوف تكرار بروتوكول معرفة تعرف، بينما عام نجاح حالة سوف فقد فقد token حد أعلى و نموذج خطأ بين منطقة آخر.

## قرار

`RunResult.finish_reason` هو من قد إيداع رسالة دخول حمل دائم inbox عودة تنفيذ بدء، إلى كامل agent تحت مرة دخول idle لـ توقف الذي استلام تجميع أصل جلسة الأكثر بعد واحد `turn/end` نص `kind`. إذا هذا منطقة بين لا يوجد `turn/end`، حقل لـ `None`. نقص قليل نص `data.reason.kind` `turn/end` سوف رمي خروج `SdkProtocolError`، بينما لن تقرير إبلاغ لـ منطقة بين داخل لا يوجد جولة انتهاء. هذا حقل وصف ذاتي لديه تشغيل منطقة بين؛ هو لن يأخذ هذا عدد انتهاء سبب ملكية في قد إيداع نص التوجيه.[ذاتي لديه تشغيل حد قرار](../architecture/2026-07-30-followup-enqueue-and-owned-runs.zh.md) ما زال منع توقف نص التوجيه درجة نتيجة عودة بسبب.

هذا حقل فقط عام kind، لأن استدعاء جهة حاجة مستقر تصنيف، كامل بنية تحويل سبب ما زال يمكن من `RunResult.events` أخذ نيل. نقل فقد فقد، مهلة و بروتوكول لذا عائق ما زال سوف رمي خروج استثناء، بينما لن توليد انتهاء سبب.

## اعتبار مرور بديل خطة

**استعادة `status`.** من نشر خريطة `ok` أو `error` حالة سوف خلط خلط مختلف حمل دائم انتهاء حال حال، بينما كما نظر بدء قدوم مثل نقل نجاح حالة، لذلك لا يمكن عودة جواب منطقة بين لـ أي انتهاء.

**عام نموذج `FinishReason`.** مرة تشغيل ممكن يتضمن كثير عدد نموذج خطوة، في بين `tool-calls` انتهاء و لا بديل جدول تشغيل انتهاء.agent الأكثر بعد واحد `turn/end` عندئذ هو متبادل صلة تشغيل درجة مراقبة قياس.

**سوف حقل تسمية لـ `stop_reason`.** ACP و subagent seam سوف يأخذ جولة انتهاء سبب خريطة إلى كل منها `stopReason` أخذ قيمة تجميع دمج.Python حقل إبقاء أصلي agent سبب kind، لذلك امتداد استخدام هو جمع اسم سوف يجعل شخص خطأ بـ لـ هذا واجهة أيضا تنفيذ هذا نوع خريطة.

**عام كامل بنية تحويل جولة سبب.** أصلي حدث تدفق قد إبقاء خطأ و إلغاء تفصيل دقيق معلومة. في `RunResult` فوق نسخ هذا عدد كائن سوف إنتاج اثنان نوع حاجة Python استدعاء جهة تنسيق ضبط يمثل.

## تحقق

Python SDK اختبار تغطية اختيار الأكثر بعد واحد جولة انتهاء، منطقة بين داخل لا يوجد جولة انتهاء، و رفض شاذ شكل جولة انتهاء سبب.SDK README سجل حقل أخذ قيمة،`None` حال حال، فشل سلوك و تشغيل درجة نطاق.

## عاقبة

استدعاء جهة بلا حاجة تحليل حدث قائمة، يكفي حسب `completed`،`max-tokens`،`error` و لم قدوم سبب kind فرع. هذا حقل ممكن وصف منطقة بين داخل إضافة دخول steering، حقن سياق أو ترتيب طابور عمل، لذلك لا يستطيع سوف ذلك جدول وصف لـ ابتدائي نص التوجيه بسبب نتيجة نتيجة. مستودع داخل TypeScript SDK فقط عبر نوع تحويل حدث توفير انتهاء سبب مراقبة قياس؛ ذلك استدعاء جهة يمكن مباشر من `SessionEvent[]` قراءة هذا مراقبة قياس.
