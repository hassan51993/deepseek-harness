# Agent Note: صريح Web index مسار و ساكن حالة مورد لم أمر في 404

Status: implemented
Archived: 2026-09-04

[English](2026-08-20-explicit-web-index-paths.md) | العربية

## مشكلة

بلا شرط SPA رجوع سوف يجعل كل لم مطابقة GET أو HEAD طلب نظر بدء قدوم كل نجاح. بطلان عادي رابط، و ناقص JavaScript، مثال صيغة جدول،source map أو manifest، كل سوف استلام إلى حالة رمز لـ 200 HTML خارج قشرة، توجيه يؤدي متصفح، ذاكرة مؤقتة و مراقبة تحكم لا يمكن منطقة قسم صالح صفحة مدخل و ناقص مورد.

## قرار

`dsh-host-frontend-static` فقط في مواصفة تحويل هدف لـ dist أصل دليل أو إعداد index مسار وقت تصيير `index.html`. حالي Web عميل لا يوجد History API pathname توجيه؛ استعلام نص لن تغيير pathname مطابقة،URL قطعة مقطع أيضا لن وصول خادم. قائم ملف وفق معتاد توفير، بينما `ENOENT`،`EISDIR` و `ENOTDIR` قراءة إنتاج لا حمل محتوى نوع فارغ 404 استجابة. أخرى نظام الملفات فشل سوف إعادة رمي إعطاء webserver طلب فشل معالجة، لن يتم خطأ علامة لـ ناقص.

GET و HEAD مقابل index مدخل، ملف و لم أمر في بند استخدام نفسه حالة رمز و محتوى نوع. أداة اسم توجيه ما زال أولا في رجوع مطابقة، تجاوز خروج dist أصل دليل مرة تاريخ ما زال إرجاع 403، وصول رجوع غير GET/HEAD طلب ما زال إرجاع 405.

## سبق اعتبار بديل خطة

**أصل حسب مسار لا يوجد ملف توسيع اسم قدوم دفع قطع صفحة توجيه.** ملف توسيع اسم لن إعلان عميل توجيه: هذا نوع فعل قاعدة ما زال سوف يأخذ لم معرفة عادي مسار تغيير صار نجاح صفحة، سوف رفض لم قدوم أي حمل نقطة رقم عميل توجيه، أيضا سوف في نقص قليل بلا توسيع اسم ساكن حالة ملف وقت خطأ معالجة هذا طلب.

**يأخذ `Accept: text/html` طلب رأس بصفة رجوع قاعدة.** هذا طلب رأس جدول بلوغ هو محتوى يمثل انحراف جيد، بينما لا هو pathname هل لـ قد إعلان عميل توجيه. متصفح fetch، آلة جهاز شخص و مراقبة تحكم كل ممكن لـ بلا فاعلية مسار طلب HTML، لذلك ما زال سوف إنتاج نفس مثال زائف نجاح سلوك.

**إضافة يمكن إعداد pathname سماح قائمة.** حالي لا يوجد عميل توجيه إزالة استهلاك هذا بند إعداد. لم قدوم History API توجيه يمكن في جذب دخول الذي يحتاج توجيه وقت، معا إضافة صريح خادم قاعدة أو إعداد حقل، بلا حاجة إبقاء دفع قياس صفة عام خيار.

## عاقبة

بطلان رابط و ناقص مورد أداة لديه يمكن توفير ذاكرة مؤقتة و مراقبة تحكم مراقبة مستقل HTTP حالة، مورد تحميل جهاز أيضا لن يأخذ HTML خارج قشرة عند عمل JavaScript تنفيذ. لم قدوم أساس في pathname عميل توجيه سوف إبقاء 404، مباشر إلى نفس بند تغيير معا إضافة دخول خادم مدخل قاعدة و حقيقي تركيب اختبار.frontend-static حقيقي Loader اختبار ثابت index مدخل، قائم مورد، عادي لم أمر في و مورد لم أمر في GET/HEAD حالة متسق صفة، و تغطية صنف يشبه API مسار، مسار مرة تاريخ، شاذ شكل هدف، لا دعم حمل طريقة و رجوع تحرير.
