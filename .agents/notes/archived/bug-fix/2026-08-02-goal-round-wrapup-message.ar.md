# Agent Note: Goal Round استلام ذيل رسالة

Status: implemented
Archived: 2026-09-04

[English](2026-08-02-goal-round-wrapup-message.md) | العربية

## مشكلة

ذاتي رئيسي Goal Round تقرير إبلاغ `update_goal` `complete` أو `blocked` وقت، شيء إدارة جولة في أداة نتيجة موضع مباشر نهاية ربط، نموذج في استدعاء بعد مجددا بلا إرسال قول آلة سوف. جلسة إنهاء في واحد ورقة عار `update_goal` بطاقة فوق، داخل قياس نفس تعلم مراقبة شعور هو agent كلام قول إلى واحد نصف توقف لكن بينما توقف: نموذج استدعاء قبل نص عبر معتاد مسبق إبلاغ واحد نسخة تجميع تقرير (“هدف بلوغ صار، علامة إتمام:”) لكن دائم بعيد لا يوجد تحت نص، لأن معيار tool-use مسبق مدة هو أداة نتيجة بعد أيضا لديه واحد بند assistant رسالة، بينما Goal Round نص التوجيه و أداة وصف كل لا يوجد شرح هذا مرة استدعاء هو نهاية نقطة. صلب إيقاف قدوم ذاتي [goal أداة قرار](../feature/2026-07-19-model-facing-goal-tools.ar.md) ، هذا note يحل محل منها جولة إيقاف بند بند.

## قرار

Goal Round `complete` أو `blocked` نجاح لم يعد استدعاء `concludeTurn()`. أداة تعديل لـ في ذاتي ذات نتيجة فوق مرفق حمل واحد بند استلام ذيل سياق: بـ `{ kind: 'plugin', plugin: 'tool-goal' }` لـ source user رسالة، يحمل `<goal_complete>`/`<goal_blocked>` إشارة أمر، اشتراط نموذج نحو مستخدم كتابة خروج لديه اعتماد حسب استلام ذيل رسالة كما لم يعد استدعاء أداة. بعد جولة مرور من agent loop معتاد قاعدة بلا أداة استدعاء إيقاف مسار انتهاء، لذلك لا وجود جديد loop أصل لغة،steering دلالة لا تلقي أثر. شخص صنف مباشر تغيير إبقاء أصل مثال، لا حقن إشارة أمر. بديل قيمة هو كل goal دورة الحياة مرة مقدار خارج نموذج طلب، بينما غير كل جولة مرة.

إشارة أمر إجراء لفظ عبر في `deepseek-v4-pro` فوق استخدام إعادة بنية Goal Round تحويل تسجيل فعل A/B أخذ مثال اختيار تحديد: بنية تحويل إشارة أمر (نتيجة، تحقق، ناتج، لاحق) في كامل درجة فوق مستقر أفضل في أقصى بسيط “مجموع ربط واحد تحت” ؛ تكملة ملء “بـ جلسة داخل دليل لـ دقيق” grounding بند بند يجعل بلا اعتماد حسب دقيق عقدة من تأكيد واقع تراجع لـ حمل إبقاء بناء اقتراح؛ بينما بلا إشارة أمر مقابل وفق مجموعة استلام ذيل جهة فرق جدا كبير، يشمل قول لـ نقر نقر ملف درجة دقيق عقدة تحرير صنع.

لـ يجعل keyless إثبات يمكن نص برمجي تحويل، لقطة ضبط تطبيق تكملة واحد بند قدرة:`dsh-llm-replay` سوف إبرة مقابل فوري طلب تحليل نص برمجي بند في `{{fromRequest:<regex>}}` احتلال موضع رمز، لأن ساكن حالة مرافق مع ملف غير ممكن قدرة مسبق معرفة نموذج يجب عودة ملء دخول `update_goal` مع آلة توليد goal id.

## تحقق

`tool-goal` حزمة اختبار تثبيت إقامة اثنان عدد نهاية حالة action حقن سياق (source، وسم،objective، منع توقف مجددا ضبط أداة بند بند) و لا وجود `concludesTurn`، و شخص صنف مباشر pause و complete لا حقن مسار، ملف نسبة التغطية 100%.`llm-replay` اختبار وحدة تثبيت إقامة احتلال موضع رمز اتفاق: الأكثر بعد مرة مطابقة أخذ فوز التقاط، بلا التقاط مجموعة وقت كامل جسم مطابقة رجوع، و لم مطابقة، غير قاعدة، لم إغلاق دمج نمط واضح تقرير خطأ. إضافة جديدة keyless ACP لقطة `goal-wrapup` قيادة صار صنف تطبيق مشي تمام create → رقم واحد جولة → ذاتي رئيسي complete، و في حمل دائم جلسة سجل و ACP stdout تدفق في معا تأكيد plugin مصدر استلام ذيل حقن، نفس جولة داخل استلام ذيل assistant رسالة و `completed` جولة انتهاء.

## سبق اعتبار بديل خطة

- **في `update_goal` UI بطاقة فوق عرض إتمام نص** — رفض:`complete` لا يحمل أي ذاتي من نص؛ إضافة جديدة `summary` معامل سوف يجعل موجه إلى مستخدم تجميع تقرير مشي أداة معامل عبر طريق، بينما كما اعتماد لكن قطع إسقاط نموذج في نتيجة بعد ذاتي لكن إرسال قول.
- **إبقاء `concludeTurn()` و إضافة جديدة “مجددا كثير واحد خطوة صاف نص” loop أصل لغة** — رفض: لـ معتاد قاعدة إيقاف مسار قد قدرة توفير سلوك (فقط يلزم لا يوجد نتيجة نهاية ربط جولة) زيادة جديد `agent-loop` آلية.
- **يأخذ إشارة أمر كتابة دخول أداة نتيجة محتوى** — رفض:goal أداة مواصفة إخراج هو يتم برنامج تحويل إزالة استهلاك ضيق تجميع JSON؛ في منها خلط دخول تفرق نص إشارة أمر سوف يأخذ نموذج جانب اتفاق و أداة يمكن إعادة تشغيل قيمة خلط في واحد بدء.

## Consequences

كل ذاتي رئيسي goal كل بـ واحد بند موجه إلى مستخدم استلام ذيل رسالة انتهاء، بينما غير واحد ورقة عار أداة بطاقة، بديل قيمة هو كل goal دورة الحياة مرة نموذج طلب.`concludeTurn()` إبقاء ذلك loop دلالة، لكن في subagent بنية تحويل إخراج خارج فقد ذهاب وحيد واحد جهة استدعاء من. لقطة مشهد الآن يمكن عبر `{{fromRequest:...}}` نص برمجي تحويل فقط في وقت التشغيل عندئذ وجود قيمة، لـ أي “عودة إظهار id” صنف أداة مسار (لا حد في goal) حل قفل keyless تغطية.
