# Agent Note: مستقر جولة مرور مسار ترتيب ترتيب

Status: implemented
Archived: 2026-09-04

[English](2026-08-26-stable-turn-process-order.md) | العربية

## مشكلة

Assistant إخراج تدفق صيغة توليد، يصبح نهائي متن، أو بسبب أداة استدعاء،Retry، لاحق خطوة بينما فقد ذهاب متن مورد إطار وقت، جولة مرور مسار نطاق سوف تغير. إذا قائم Chat Node ترتيب ترتيب اعتماد هذا مقطع متغير نطاق، أول جولة توجيه النظام و يقع في User قبل سياق سوف عبر مرور فتح ساحة User، توجيه يؤدي نفس عدد منطق سطر في جولة خلال ظهور في مختلف موضع.

## قرار

قائم Chat Node في نفس صفحة دورة الحياة داخل إبقاء نفس عرض ترتيب. ذلك موضع فقط اعتماد حمل دائم مرساة نقطة، عقدة نوع صنف و فتح ساحة شخص عمل إدخال، لا اعتماد متغير مرور مسار بدء نقطة أو متن حد. تحميل أكثر مبكر تاريخ إطلاق اعتماد إعادة وضع وقت، قد إسقاط خروج توجيه النظام إبقاء أصل لديه مرساة نقطة. جديد إسقاط خروج مرور مسار تحكم عنصر يمكن إدراج دخول قائم سطر بين؛ إتمام حالة،Retry، لاحق خطوة، قسم صفحة إتمام و يد حركة توسيع فقط تغيير مرئي صفة أو زيادة جديد دليل.

توجيه النظام مستقل في جولة مرور مسار: ابتدائي نص التوجيه بداية نهاية عرض في فتح ساحة User فوق جهة، و كما لن نيل نيل مرور مسار عضو أو مرور مسار إخفاء حالة. لاحق نص التوجيه إذا أول مرة من لا كامل تاريخ نافذة إسقاط، تحميل أكثر مبكر طلب تاريخ بعد ما زال إبقاء هذا موضع. سياق حقن ما زال يخص مرور مسار محتوى. إذا سياق أو ذلك هو كامن في مرور مسار سطر حدث مرساة نقطة مبكر في فتح ساحة User،Chat من أول مرة إسقاط بدء حينئذ سوف ذلك عرض في هذا User بعد؛ مرور مسار تحكم عنصر ظهور بعد احتلال حسب User و هذه مرور مسار سطر بين مستقر موضع. لا يوجد فتح ساحة شخص عمل إدخال وقت، تحكم عنصر من أول مرة ظهور بدء حينئذ يقع في الأكثر مبكر مرور مسار مرشح قبل.

قائم[جولة مرور مسار طي قرار](../feature/2026-08-14-web-turn-process-folding.ar.md) متابعة مسؤول عضو علاقة، إتمام حالة، حفظ دائم، تركيز نقطة و قسم صفحة سلوك؛ هذا سجل فقط يحل محل منها “طي توجيه النظام” و “انتظار متغير نطاق قبول دخول سطر بعد عندئذ ضبط كامل User قبل مرور مسار ترتيب” قديم قرار.

## سبق اعتبار بديل خطة

**يجعل توجيه النظام متابعة يخص Process، لكن إبقاء أصل موضع.** لا اعتماد: يقع في فتح ساحة User تحت جهة disclosure سوف تحكم ذاته فوق جهة محتوى، بينما كما استلام بدء بعد سوف إخفاء لأجل حد تحديد هذا User طلب كامل مقطع إشارة أمر.

**فقط ترتيب حذف توجيه النظام.** لا اعتماد: يقع في User قبل سياق ما زال سوف مع متن مورد إطار تغير بينما نقل حركة، إبقاء نفس صنف نظر شعور قفز حركة.

**يأخذ مرور مسار سطر إعادة تعليق وصل إلى disclosure تحت.** لا اعتماد: عبر React أب عقدة نقل حركة keyed سطر سوف إعادة تركيب لديه حالة renderer.

## عاقبة

مستقر أول جولة عرض ترتيب لـ «توجيه النظام → User → Process → سياق و ذلك هو مرور مسار سطر → نهائي Assistant». لذلك، يقع في User قبل حقن سياق عرض ترتيب ممكن مختلف في أصلي حدث ترتيب، لكن من أول مرة تصيير بدء إبقاء ثابت. اختبار تغطية ابتدائي حالة، مرور مسار ظهور، إتمام بعد افتراضي استلام بدء، يد حركة توسيع و فقط متن حد تغير مشهد.
