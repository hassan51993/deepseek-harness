# Agent Note: Windows أصل فرعي ملف استبدال خلال إبقاء DACL

Status: implemented
Archived: 2026-09-04

[English](2026-07-19-windows-atomic-write-dacl-preservation.md) | العربية

## مشكلة

أصل فرعي كتابة في POSIX فوق بـ `0o700` حفظ حماية مؤقت تخزين دليل، بـ `0o600` حفظ حماية مؤقت ملف، لكن Windows mode موضع فقط عرض فعلي DACL دمج صار فقط قراءة عرض. في هدف ملف أب دليل تحت إنشاء مؤقت تخزين دليل و مؤقت ملف، و كما فقط اعتماد وراثة DACL، كاف بـ ممتلئ كاف جديد بناء ملف حاجة، لكن لا يمكن أمان استبدال صريح أو تلقي حفظ حماية DACL مقارنة أب دليل أكثر صارم إطار قائم ملف: محتوى سوف في إذن أكثر عرض رخو أب دليل DACL تحت كتابة، بينما إعادة تسمية أيضا سوف يأخذ هذا عدد مؤقت تخزين أمان وصف رمز حمل إلى استبدال بعد ملف فوق.

## قرار

`dsh-fs-local` عبر `GetFileSecurityW` قراءة قائم هدف ملف DACL، في كتابة محتوى قبل سوف ذلك بـ منع توقف وراثة شكل صيغة تطبيق إلى فارغ مؤقت ملف، و عبر `ReplaceFileW` إصدار قد إغلاق مؤقت ملف. تلقي حفظ حماية مؤقت تخزين أمان وصف رمز يمكن منع توقف مؤقت تخزين دليل في وراثة بند توسيع كبير وصول إذن؛`ReplaceFileW` سوف إبقاء أصل هدف ملف وصول سياسة و أخرى استبدال بيانات وصفية. ذلك ACL دمج مرور مسار ممكن إعادة تسلسل تحويل تلقائي وراثة حالة أو نسخ انتظار قيمة ACE، لذلك لا يستطيع يأخذ ذاتي متبادل مقابل أمان وصف رمز مؤقت اندفاع منطقة تدريجي بايت متبادل انتظار بصفة مستقر اتفاق. جديد Windows ملف لا يوجد قائم وصف رمز حاجة إبقاء، لذلك ما زال وراثة هدف دليل DACL؛ ذلك مؤقت تخزين دليل أيضا لذلك يقع في هدف ملف جانب.POSIX متابعة استخدام فقط كل من يمكن وصول مؤقت تخزين mode، و إبقاء قائم هدف ملف mode.

Windows أصلي نسبة التغطية اختبار سوف حفظ حماية هدف ملف DACL، فحص كتابة إتمام مؤقت تخزين ملف، و مقابل مقارنة نهائي استبدال ملف في إبقاء ترتيب كما ذهاب إعادة بعد ACE سياسة. و مضيف منصة غير متصل ربط اختبار تغطية Win32 خطأ تحويل و كل أصلي استدعاء حد.mode موضع تأكيد ما زال فقط ملائم لأجل POSIX؛ جديد ملف DACL وراثة من عملية نظام اتفاق قاعدة تحديد، لا ينبغي عبر خاص تحديد آلة جهاز حساب مستخدم سماح قائمة قدوم تأكيد.

## تجهيز اختيار خطة

**استبدال ملف وقت اعتماد دليل وراثة.** لا إعطاء اعتماد، لأن هدف ملف ممكن حمل لديه مقارنة أب دليل أكثر صارم إطار صريح أو تلقي حفظ حماية DACL؛ دليل وراثة حيث لا يمكن حفظ حماية مؤقت تخزين محتوى، أيضا لا يمكن إبقاء هدف ملف وصول سياسة.

**استخدام `ReplaceFileW`، لكن لا حفظ حماية مؤقت ملف.** لا إعطاء اعتماد، لأن هذا فقط قدرة في محتوى قد حسب مؤقت تخزين ملف وراثة DACL كتابة بعد إصلاح نهائي وصف رمز.

**كل مرة كتابة كل ضبط فقط كل من يمكن وصول DACL.** لا إعطاء اعتماد، لأن هذا سوف كسر تالف مشروع متعمد ضبط مشترك إذن. نسخ هدف ملف DACL يمكن إبقاء نشر في قد لديه وصول سياسة، بلا حاجة آخر سطر إنشاء ضبط سياسة.

**استخدام `Get-Acl` أو `icacls` تأكيد وراثة حساب مستخدم.** لا إعطاء اعتماد، لأن هذا صنف اختبار تحقق هو آلة جهاز سياسة، بينما لا هو حزمة سلوك؛ نظام داخل وضع حساب مستخدم اسم سوف محلي تحويل، جعل إخراج في مختلف مضيف فوق لا مستقر.

**في Windows فوق قفز مرور قائم `chmod` استدعاء.** لا إعطاء اعتماد، لأن Node سوف يأخذ هذه يمكن كتابة mode خريطة لـ بلا ضرر فارغ عملية؛ منصة شرط حكم قطع فقط سوف زيادة فرع، لن تغيير DACL سلوك.

## أثر

استبدال Windows ملف الآن اشتراط استدعاء جهة لديه حق قراءة هدف DACL و ضبط مؤقت ملف DACL؛ إذا إذن لا كاف، نظام سوف في كتابة محتوى قبل واضح فشل. هذا حزمة جذب دخول Koffi بـ تنفيذ قليل كمية Win32 استدعاء، و كما فقط في Windows استبدال مسار فوق تحميل. جديد Windows ملف سوف في دليل حسب تصميم فتح وضع مقارنة عرض وصول إذن وقت وراثة هذا إذن، بينما POSIX مؤقت محتوى ما زال فقط سماح كل من وصول؛ فقط قراءة Windows هدف ملف ما زال سوف في إصدار وقت فشل، مبكر في إعادة وضع دمج صار mode ممكن إنتاج أثر وقت نقطة.
