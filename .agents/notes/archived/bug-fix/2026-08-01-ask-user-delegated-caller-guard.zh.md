# Agent Note: رفض وقت التشغيل في ملكية في أخرى agent subagent نحو شخص صنف إرسال بدء تفاعل

Status: implemented
Archived: 2026-09-04

[English](2026-08-01-ask-user-delegated-caller-guard.md) | العربية

## مشكلة

مرة صفة subagent استدعاء `ask_user_question` وقت ممكن بلا حد منع سد. هذا استدعاء سوف انتظار شخص صنف عودة جواب، لكن فرعي درجة لا يوجد من ذاته مستقل يملك شخص صنف تفاعل عبر طريق، لذلك فرعي درجة لا يمكن إتمام، انتظار ذلك إتمام أب درجة أيضا سوف مع لـ توقف ركود.

حفظ دائم جلسة جدول نظام لا يمكن حكم قطع ينبغي جواب من هل وجود. فرعي جلسة بعد ممكن استعادة لـ جديد قمة طبقة وقت التشغيل أصل، بينما وقت التشغيل في ملكية في أخرى agent(ذكي جسم) تخزين نشط فرعي درجة، ذلك حفظ دائم تفويض حمل عميق درجة لكن ممكن لـ صفر أو ناقص. مشترك seam فوق خطأ إشارة جذب أيضا يجب ملائم لأجل كل مستهلك:`exit_plan_mode` سوف استخدام `ctx.userQuestions.ask()`، لكن لن استدعاء `ask_user_question`.

## قرار

إذا وجود `AskUserQuestionRequest.agent`،`UserQuestionService.ask()` سوف عبر `ctx.agents` تحقق هذا agent حينئذ هو سجل التسجيل في تخزين نشط نسخة، و كما فقط في `ctx.agents.roots()` يتضمن هذا نسخة وقت عندئذ سماح استدعاء. ناقص سجل التسجيل أو نقل دخول فقط id نفسه قديم قديم كائن وقت، بـ `CALLER_NOT_LIVE` فشل؛ تخزين نشط agent ملكية في آخر عدد تخزين نشط agent وقت، بـ `DELEGATED_CALLER` فشل. هذا فحص يقع في قائم قد في توقف و فارغ دفعة مرة حراسة حماية بعد، معنى رسم تحقق أو مزود قسم إرسال قبل، لذلك ملكية في أخرى agent فرعي درجة أبدا سوف إطلاق UI انتظار.

بـ وقت التشغيل كل حق لـ إذن اعتماد حسب. يحمل جدول نظام جلسة في بلا كل من حال حال تحت استعادة وقت حينئذ هو وقت التشغيل أصل، يمكن رفع سؤال؛ تخزين نشط فرعي درجة أي جعل حفظ دائم `delegationDepth` لـ صفر، ما زال بلا مورد إطار رفع سؤال. لا حمل agent برنامج تحويل استدعاء متابعة امتداد استخدام قائم مزود مسار.

مشترك فشل نص و أداة جسم مستهلك غير متصل، و إعطاء خروج يمكن تنفيذ إشارة جذب: فرعي درجة يأخذ بعد لم حل قرار مشكلة أو قرار كتابة نهائي نتيجة. تفويض حمل اتفاق هذا حينئذ سوف يأخذ هذا نتيجة نقل إعطاء أب درجة، أب درجة يمكن حسب هذا قرار هل استفسار سؤال شخص صنف. خدمة و فرعي درجة كل لن إعلان تسمية وجود فعلي فوق و لا وجود نحو فوق رسالة نقل تمرير أو عودة جواب تحويل إرسال قدرة.

هذا أمان حد و متصفح composer اختيار رفع متبادل متبادل مستقل. رفع اقتراح[دلالة composer مرحلة مقطع](../../proposed/architecture/2026-08-08-semantic-composer-chain-phases.zh.md) حل قرار قد لديه انتظار معالجة تفاعل و فقط قراءة subagent واجهة ترتيب ترتيب طريقة؛ هو لن تقليل ضعيف هذا وقت التشغيل حراسة حماية.

## تجهيز اختيار خطة

**استخدام `session.header.delegationDepth > 0`.** لا إعطاء اعتماد: حفظ دائم جدول نظام سوف في استعادة بعد متابعة وجود، لكن لا يستطيع إثبات حالي عملية داخل كل من. هذا خطة سوف رفض صالح قد استعادة أصل، أيضا ممكن وضع سطر حفظ دائم header لا كامل تخزين نشط فرعي درجة.

**فقط في `dsh-tool-ask-user` داخل رفض.** لا إعطاء اعتماد:`exit_plan_mode` و مباشر استدعاء جهة مشترك استخدام `ctx.userQuestions.ask()`. خدمة هو كل شخص آلة تفاعل مستهلك مشترك نفس مرور مرور الأكثر ضيق عملية حد.

**يجعل فرعي درجة نحو فوق تفويض حمل أو انتظار تحويل إرسال.** لا إعطاء اعتماد: مرة صفة تفويض حمل لا يوجد عام من فرعي درجة نحو أب درجة طلب عبر طريق، أيضا لا يوجد عودة جواب تحويل إرسال بروتوكول. وحيد لديه حفظ إثبات إرجاع مسار هو فرعي درجة نهائي نتيجة.

**اعتماد متصفح composer إصلاح.** لا إعطاء اعتماد: عرض طريقة لا يمكن سند فارغ إنتاج من كل من مسؤول شخص صنف عبر طريق، غير متصفح نشر ما زال حاجة هذا استدعاء قدرة كاف إنهاء.

## أثر

وقت التشغيل في ملكية في أخرى agent فرعي درجة استدعاء سوف بـ مستقر بنية تحويل خطأ سريع سرعة فشل، بينما لا هو تعليق بدء. سجل التسجيل في تأكيد قطع تخزين نشط أصل و لا حمل agent برنامج تحويل استدعاء ما زال لديه مورد إطار رفع سؤال، يشمل حمل لديه تاريخ فرعي درجة جدول نظام قد استعادة جلسة.`ask_user_question` و `exit_plan_mode` سوف استلام إلى نفسه في صفة تصحيح صحيح إشارة جذب، بينما ذلك نموذج مرئي schema و توجيه النظام بادئة إبقاء ثابت؛ فقط لديه إلحاق خطأ نتيجة حدوث تغير، لذلك قائم KV Cache بادئة ما زال يمكن إعادة استخدام.

## اختبار

خدمة اختبار تغطية حفظ دائم عميق درجة لـ صفر تخزين نشط فرعي درجة، عميق درجة لـ واحد قد استعادة وقت التشغيل أصل، ناقص سجل التسجيل، فقط id نفسه قديم قديم كائن، و كل مرة رفض كل لا استدعاء مزود. أداة و plan-mode اختبار إثبات اثنان عدد مستهلك كل سوف عرض في صفة `DELEGATED_CALLER` نتيجة، كما أبدا لمس بلوغ مزود. بلا مفتاح تجميع لقطة تفويض حمل واحد محاولة تجربة استدعاء `ask_user_question` فرعي درجة، ثابت ذلك خطأ أداة نتيجة و نهائي تسليم وصل، و إثبات أب درجة يمكن إتمام، بينما لا هو واحد مباشر انتظار عودة جواب.
