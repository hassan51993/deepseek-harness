# Agent Note: إخفاء Windows عملية فرعية نافذة

Status: implemented
Archived: 2026-09-04

[English](2026-09-03-hidden-windows-subprocess-windows.md) | العربية

## مشكلة

محلي subprocess provider يمكن في لا يوجد مرئي تحكم منصة GUI أو خدمة مضيف في تشغيل. مضيف لم توفير تحكم منصة وقت،Windows سوف لـ عملية فرعية إنشاء جديد مرئي نافذة، لذلك عادي أمر أو `taskkill` مساعد مساعدة عملية ممكن وميض الآن و انتزاع احتلال تركيز نقطة، أي جعل harness و لم لـ هذا عملية توفير موجه إلى مستخدم terminal.

## قرار

provider مقابل كل مرة غير terminal `spawn` و اثنان موضع تزامن `taskkill` استدعاء كل ضبط `windowsHide: true`. رئيسي عملية فرعية فقط في Windows تنفيذ مسار استخدام هذا خيار؛`taskkill` ذاته فقط لأجل Windows.terminal عملية متابعة اعتماد PTY تنفيذ يملك مرئي صفة و تحكم منصة سلوك.

هذا خيار سوف إخفاء تحكم منصة نافذة، و التزام دوران Windows عملية بدء مرئي صفة ضبط GUI نافذة. استدعاء جهة لا يستطيع اختيار هذا سلوك، لأن محلي provider مسؤول قرار ذلك خلفية عملية إدارة هل إنشاء مضيف نافذة.

## اعتبار مرور بديل خطة

**فقط إخفاء رئيسي عملية فرعية.** غير مقبول، لأن إلغاء، مهلة ترقية،terminal تفكيك إزالة و مضيف خروج تنظيف ما زال ممكن بدء `taskkill` و وميض الآن تحكم منصة نافذة.

**كشف استدعاء جهة خيار.** غير مقبول، لأن مستهلك لا يمكن يمكن اعتماد حكم قطع محلي مضيف هل يملك تحكم منصة، لا متسق اختيار سوف إعادة جذب دخول انتزاع احتلال تركيز نقطة عملية إدارة نافذة.

**فقط إخفاء تحكم منصة برنامج.** غير مقبول، لأن Node فقط كشف واحد Windows بدء خيار، لا يمكن في spawn قبل يمكن اعتماد منطقة قسم يمكن تنفيذ ملف نوع؛ استكشاف قياس هدف أيضا سوف زيادة منصة خاص تحديد تنافس حالة، لكن لا يستطيع إبقاء لديه استخدام منتج سلوك.

## عاقبة

خلفية subprocess عملية لن إنشاء مرئي Windows عملية فرعية أو `taskkill` نافذة. مباشر بدء كما التزام دوران بدء مرئي صفة ضبط GUI برنامج أيضا سوف بـ إخفاء طريقة تشغيل؛ حاجة تفاعل صيغة مرئي تطبيق مستهلك يجب استخدام يملك هذا مستخدم تفاعل قدرة، بينما لا هو خلفية subprocess provider.

اختبار وحدة حقن عملية launcher، ثابت رئيسي عملية فرعية و اثنان بند `taskkill` مسار `windowsHide`، كما لن إنشاء مضيف عام نافذة أو إنهاء حقيقي عملية.
