# Agent Note: بنية تحويل خطأ تصنيف جسم نظام

Status: implemented
Archived: 2026-09-04

[English](2026-06-11-structured-error-taxonomy.md) | العربية

## مشكلة

لذا عائق عبر تجاوز seam وقت فقط هو عار نص. أداة خطأ يتم مسطح مستو تحويل لـ واحد نص كتلة (name،code و stack الكل فقد فقد) ، توجيه يؤدي لم قدوم صندوق رملي/إعادة محاولة إضافة لا يمكن منطقة قسم ENOENT و EACCES، نموذج أيضا لم قدرة نيل نيل هذا يمكن توفير أكثر أداة يمكن عملية صفة عكس تغذية. غير Error throw تراجع تحويل أكثر صارم إعادة:agent loop(ذكي جسم حلقة) سوف ذلك حزمة تركيب لـ `new Error(String(x))`، إسقاط كل code. بينما `LlmError` هو نظام في وحيد نوع تحويل خطأ، لا يوجد مشترك أساس صنف، مستهلك لا يمكن مقابل ذلك إجراء عام `instanceof` حكم قطع.

## قرار

في `dsh-llm`(ورقة فرعي حزمة، كل أخرى حزمة كل قد اعتماد هو، لا جذب دخول جديد اعتماد حافة) في جذب دخول واحد `HarnessError extends Error` أساس صنف: مستقر `code`(و `message` قسم مغادرة) ، عبر `ErrorOptions` إجراء `cause` رابط،`name` افتراضي لـ فرعي صنف اسم.`isHarnessError` في seam موضع فعل نوع استلام ضيق.

- `LlmError` و `ToolArgsError`(dsh-tools) وراثة هذا أساس صنف، إبقاء كل منها قائم code.
- `ToolExecutionResult` إضافة جديدة اختياري حقل `error: { name, code }`، في سجل التسجيل catch في عند رمي خروج قيمة لـ `HarnessError` وقت ملء ملء.agent loop سوف ذلك تحويل إرسال إلى `tool/result` جلسة حدث (هذا حدث أيضا إضافة جديدة نفس اختياري حقل) ، جعل بنية تحويل فشل معلومة إبقاء في سجل في، توفير إعادة محاولة/صندوق رملي إضافة و إعادة تشغيل استخدام. موجه إلى نموذج نص كتلة إبقاء ثابت.
- agent loop `toError` سوف غير Error throw حزمة تركيب لـ `HarnessError`(`code: 'UNKNOWN'`، أصلي قيمة بصفة `cause` رابط) ، بينما غير عار `Error`؛ هذا مثال أي جعل هو لا مواصفة throw أيضا قدرة يحمل يمكن توجيه code دخول جلسة `error` حدث (هذا حدث هذا قبل قد كشف `code`).

## عاقبة

- خطأ طرف إلى طرف يمكن آلة جهاز توجيه: إضافة يمكن أساس في `error.code` فرع، بينما بلا حاجة مقابل رسالة فعل فرعي سلسلة مطابقة.
- واحد أساس صنف يتم واسع عام استيراد، لكن هو يقع في كل حزمة قد اعتماد حزمة في، بديل قيمة فقط هو واحد بند import لغة جملة، بينما غير جديد اعتماد حافة.
- `deriveMessages` لن سوف `error` كشف إلى نموذج تاريخ في——نموذج ما زال يرى نص كتلة؛ بنية تحويل حقل خدمة في شفرة و إعادة تشغيل.
- معامل تحقق إبقاء ذلك قائم code و سلوك؛ حزمة ذاتي لديه تشخيص ثابت صيغة مستقل يحمل مستقر code، جعل ثابت صيغة سجل التسجيل بلا حاجة استيراد منتج حزمة. مشترك أساس صنف زيادة عبر seam توجيه بيانات وصفية، لا تغيير موجه إلى نموذج نص.
