# Agent Note: منتج subagent مزود يقع في مشترك profile مضيف

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-product-subagent-providers-in-shared-host.md) | العربية

## مشكلة

[Codex و Claude Code مزود اتفاق](../feature/2026-08-04-claude-code-and-codex-subagent-backends.ar.md) الأكثر أول بـ يمكن مستقل تثبيت حزمة تسليم، من نشر بيئة في عام subagent أداة جانب تحميل.Agent Preset بعد قدوم يصبح مفرد عدد agent(ذكي جسم) نموذج مرئي أداة معتاد قاعدة مسؤولية مهمة جهة، لكن preset لا يستطيع أمان أرض يملك هذه منتج مزود:`ctx.subagents` هو عملية درجة سجل التسجيل، مزود اسم في Host داخل وحيد، بينما مضيف مستهلك سوف عبر جلسة تحليل نفس عدد سجل التسجيل. لذلك، تكرار تجميع preset سوف تنازع استخدام نفس مجموعة قد إعداد اسم. إذا اشتراط مستخدم معا تحرير Profile و Preset، أيضا سوف جعل عام preset بند إعداد ذاته لا كامل.

ملكية قرار يجب معا إبقاء اثنان عدد ذاك هذا مستقل واقع: تحميل مزود لا نيل بدء منتج، أيضا لا نيل مقابل منتج تنفيذ هوية تحقق؛ بينما أداة تخويل ما زال يجب حسب preset قرار، هذا مثال اثنان عدد جلسة عندئذ قدرة كشف مختلف منتج. عام منتج فتح صلة، حسب agent إنشاء مزود نسخة أو مسبق أولا قطعة رفع تركيب preset، كل سوف لـ منها واحد واقع آخر ضبط ثاني مسؤولية مهمة جهة.

## قرار

منتج مزود ما زال هو عملية درجة host plane(مضيف مستو وجه) تسجيل.[إنتاج تثبيت ترتيب حذف قرار](../simplification/2026-08-12-production-dsh-excludes-product-subagent-providers.ar.md) فقط يحل محل هذا شرح أصل أولا من base bundle تثبيت مزود اختيار: إنتاج `dsh-base` حيث لا اعتماد أيضا لا تركيب هو جمع. اختيار منتج تجميع صار Profile سوف تثبيت هدف مزود Bundle؛ ذلك patch تركيب افتراضي نسخة، بينما Profile يمكن في host plane تركيب أكثر كثير تسمية نسخة.[تسمية نسخة قرار](../feature/2026-08-18-product-subagent-named-instances.ar.md) مسؤول كل بند إعداد تسجيل هوية: اثنان عدد منتج كل قبول كثير عدد وحيد `providerName`، معا إبقاء `codex` و `claude-code` بصفة قيمة افتراضية. تحميل مهمة واحد إضافة فقط سوف تسجيل واحد راحة نوم خلفية؛ مقابل Codex أو Claude عملية مباشر إلى رقم مرة فعلي تفويض إرسال استدعاء وقت عندئذ بدء.Agent Preset عبر عادي `dsh-tool-subagent` بند إعداد `provider` و `toolName` دقيق تأكيد عام مفرد عدد agent الذي يحتاج قد إعداد نسخة، بينما بلا حاجة أكثر تعديل Host سجل التسجيل.

كل مزود حزمة كل يملك يمكن مباشر تثبيت Bundle patch و خاص منتج وقت التشغيل. هذا شرح متابعة مسؤول كل قد تثبيت مزود عملية درجة Host وضع وضع. مزود اتفاق شرح متابعة مسؤول كل منتج بروتوكول، نتيجة خريطة، إلغاء، عملية شجرة دورة الحياة و دليل طبقة درجة.[تسمية نسخة قرار](../feature/2026-08-18-product-subagent-named-instances.ar.md) مسؤول اثنان عدد اختياري منتج نموذج و أخرى تدريجي نسخة إعداد.[Agent Preset هيكل بنية](2026-08-03-per-session-agent-presets.ar.md) متابعة مسؤول مضيف و agent تخطيط قسم،preset إنشاء عمل، و تعديل فقط أثر جديد تجميع جلسة قاعدة.

كل Bundle كل يأخذ يمكن تنفيذ ملف اختيار تسليم إعطاء حزمة ذاتي لديه منتج وقت التشغيل:Codex حزمة تشغيل ذاته إعلان wrapper،Claude Code حزمة فإن يجعل قفل تحديد Agent SDK اختيار خاص أصلي يمكن تنفيذ ملف. اثنان عدد مزود كل لن استعلام أو رجوع مضيف منتج أمر. تحميل Profile لن إنشاء منتج حالة، استكشاف قياس إصدار أو اختبار هوية تحقق؛ هو يمكن توفير كل قد تركيب Provider نسخة نشر إعداد، يشمل اختياري لا نفاذ واضح نموذج، و من[غير تفاعل إذن قرار](../feature/2026-08-15-product-subagent-noninteractive-permissions.ar.md) مسؤول منتج مخصص تابع `permissionMode` قيمة، لكن لن يأخذ هذه اختيار نقل دخول Agent Preset أو موجه إلى نموذج أداة. منصة تحميل حمل ناقص و منتج لذا عائق ما زال نطاق حد في حدوث مشكلة ذلك مرة تفويض إرسال.

## تحقق

base bundle اختبار إثبات إنتاج `dsh-base` حيث لا يتضمن منتج مزود اعتماد، أيضا لا يتضمن مزود بند إعداد.Web تجميع سوف تثبيت اثنان عدد اختياري Bundle، و تغطية لا كشف أي أداة، فقط كشف Codex، فقط كشف Claude و معا كشف اثنان من هذا أربعة نوع أداة تجميع دمج، أيضا تغطية ذاتي سطر إنشاء عمل preset حدوث تعديل بعد بديل حد عزل. من حزمة مسؤول Loader تجميع إثبات كل Bundle افتراضي نسخة و مقدار خارج تسمية نسخة كل سوف إتمام تسجيل، بينما لن بدء منتج عملية. بلا مفتاح ACP(Agent Client Protocol) لقطة ثابت Codex مزدوج أداة تجميع دمج و نهائي أربعة أداة تركيب، مزود اختبار فإن آخر سطر إثبات خاص منصة تحميل حمل اختيار و بلا مضيف رجوع، إعداد عزل، فشل، إلغاء و عملية شجرة تماما توقف مستقر.

## اعتبار مرور بديل خطة

**سوف منتج مزود إبقاء لـ Profile طبقة حسب يحتاج تفعيل بند.** هذا مثال يمكن تقليص صغير افتراضي اعتماد إغلاق حزمة، لكن اشتراط مستخدم معا تحرير Profile و Preset. إنتاج تثبيت ترتيب حذف قرار قبول هذا بند تثبيت أخذ ترك؛ هذا شرح إبقاء اشتراط هو، أي يتم اختيار في مزود نسخة كل في host plane تركيب، بينما لا هو وضع دخول preset.

**تخزين عام أو حسب Profile إعداد منتج تفعيل فتح صلة.** عملية درجة فتح صلة سوف و Preset تنازع انتزاع نموذج مرئي أداة مسؤولية مهمة ملكية، أيضا لا يمكن يمثل اثنان عدد جلسة استخدام مختلف تركيب. متاح صفة و هوية تحقق يخص نشر واقع، و غير آخر نسخة حاجة حفظ دائم منتج حالة.

**في كل Agent Preset داخل تركيب مزود.** مزود اسم يخص عملية درجة سجل التسجيل، لذلك تكرار تجميع جلسة سوف في نفس مجموعة قد إعداد اسم فوق حدوث اندفاع مفاجئ. مضيف مستهلك أيضا حاجة مستقل في أي مفرد عدد agent دورة الحياة استخدام هذا سجل التسجيل.

**تسليم أربعة عدد منتج تركيب preset.** أربعة عدد هوية سوف نسخ كامل تجميع، فقط لـ يمثل اثنان بند مستقل أداة سطر. عادي سطر قد قدرة جدول بلوغ كامل مستطيل دفعة، بلا حاجة إضافة جديدة اسم مفرد أو صيانة حالة.

## عاقبة

مستخدم في Profile في تثبيت كل يتم اختيار في منتج مزود، تركيب الذي يحتاج تسمية نسخة، مجددا عبر و أخرى إضافة نفسه Agent Preset إنشاء عمل مسار عام هذه نسخة أداة. كل جديد جلسة فقط سوف نيل نيل ذلك الذي اختيار preset الذي مساهمة أداة. لا يوجد اختيار منتج مزود Profile لا تحمل تحمل مقابل حزمة أو وحدة تحميل فتح إلغاء؛ تحميل قد اختيار نسخة ما زال لن بدء منتج عملية، تسجيل تسجيل، استدعاء نموذج أو إنشاء منتج رئيسي دليل.

Host سجل التسجيل ما زال هو مزود وحيد مرجعي، كل Bundle ما زال هو نشر متاح صفة مرجعي، كل Preset ما زال هو نموذج أداة مرجعي. هذا عدد صريح مزدوج باب دورة الحياة تجنب تجنب عام تفعيل فتح صلة، و يجعل حزمة إزالة و حسب جلسة إنشاء عمل إبقاء مستقل.
