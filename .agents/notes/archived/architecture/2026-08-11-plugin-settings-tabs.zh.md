# Agent Note: “إضافة” ضبط في وظيفة ذاتي لديه وسم صفحة

Status: implemented
Archived: 2026-08-22

[English](2026-08-11-plugin-settings-tabs.md) | العربية

## مشكلة

إضافة إعداد و فقط قراءة Loader بيان كل منها تسجيل واحد قمة طبقة `settings.section`. اثنان من وصف نفس عدد “إضافة” مجال، لكن احتلال حسب اثنان سطر تنقل، يأخذ بحث و إعداد تفكيك صار متبادل لا متبادل صلة صفحة، أيضا لا يوجد إعطاء Settings خارج قشرة واحد لديه أصل فإن تجمع دمج طريقة. إذا مباشر دمج اثنان من مكون، فإن سوف يجعل واحد وظيفة إضافة import و يملك آخر عدد وظيفة بيانات دورة الحياة.

## قرار

`@deepseek-ai/dsh-client-ui-settings-plugins` يملك وحيد واحد id لـ `plugins` `settings.section` مساهمة. هو تصيير مشترك عنوان و ضيق تجميع وسم شريط، إعلان أصل درجة قائمة slot `settings.plugins.tab`، و يأخذ هذا سجل في id،order و تتبع مع لغة label إسقاط صار وسم صفحة. هذا slot مواصفة نوع يقع في `ui-settings`، لذلك وسم صفحة مساهمة جهة اعتماد ضبط مجال اتفاق، بينما لا هو اعتماد آخر عدد وظيفة إضافة.

قسم منطقة يملك جهة مساهمة `configurable` وسم صفحة، من هو إعلان قائم تضمين طقم `settings.plugin.item` قائمة. إعداد بطاقة أصل لديه نطاق الأسماء ربط، مسودة مسودة حالة، تحقق و كتابة متساو إبقاء ثابت.`@deepseek-ai/dsh-client-ui-settings-plugin-inventory` نحو `settings.plugins.tab` مساهمة `all` وسم صفحة؛ هو Host Loader مراقبة جهاز، توليد Remote نطاق الأسماء،DTO و بحث دلالة إبقاء ثابت. قد توقف استخدام بيان بند سوف في ملخص و تفصيل حال في حذف تكرار “لم تركيب” تشغيل حالة، قد تفعيل بند ما زال عرض ذلك Cordis مرحلة مقطع.

افتراضي اختيار ترتيب في رقم واحد وسم صفحة. بعض عدد وسم صفحة فقط لديه أول مرة يتم اختيار وقت عندئذ تركيب، بعد في “إضافة” قسم منطقة إبقاء تركيب خلال فقط إخفاء بينما لا إزالة. هذا مثال سوف يأخذ بيان RPC تأخير متأخر إلى مستخدم فتح**إضافة قائمة**وقت، و في تبديل وسم صفحة وقت إبقاء مسودة مسودة، بحث نص، طي حالة و قد قراءة لقطة. إغلاق Settings سوف إزالة هذا قسم منطقة، لذلك مجددا مرة فتح بعد، إعادة اختيار هذا وسم صفحة وقت سوف أخذ نيل جديد بيان لقطة.

اثنان بند تسجيل كل استخدام `ctx.slots.inject()`. قسم منطقة إعلان جهة إزالة وقت، وسم slot و ذلك الكل مساهمة مع لـ طي؛ إعادة إعلان بعد، كل بند وظيفة كل قدرة إعادة تسجيل، بلا حاجة ساكن حالة import، أيضا لا اعتماد تنشيط ترتيب.

## تجهيز اختيار خطة

**إبقاء اثنان سطر Settings تنقل، فقط تعديل اسم.** مرفوض، لأن تكرار هو بنية مشكلة، بينما غير نص سجل مشكلة: اثنان عدد صفحة ما زال بديل جدول نفس عدد “إضافة” مجال، و متابعة تنازع انتزاع تنقل فضاء.

**يأخذ بيان مكون import دخول `ui-settings-plugins`.** مرفوض، لأن إعداد إضافة سوف لذلك يملك آخر عدد إضافة Remote اعتماد و دورة الحياة، أيضا سوف يأخذ اختياري متصفح مساهمة تغيير صار حزمة درجة اعتماد.

**في قسم منطقة يملك جهة صلب تحرير رمز اثنان عدد وسم صفحة اسم و مكون.** مرفوض، لأن رقم ثلاثة بند وظيفة حاجة تعديل يملك جهة،HMR teardown أيضا ممكن إبقاء تحت قد لا وجود مساهمة واجهة إطار هيكل.slot سجل قد توفير معرف، ترتيب، محلي تحويل و درجة ربط دلالة.

**يأخذ “إضافة” تجمع دمج نقل دخول `ui-settings-general`.** مرفوض، لأن Settings خارج قشرة يملك عام تنقل و نموذج حالة واجهة إطار هيكل، بينما لا يملك وظيفة محتوى. يأخذ “إضافة” مخصص تابع وسم صفحة وضع في ذلك داخل، سوف يجعل اليوم بعد كل واحد نوع “إضافة” عرض كل حاجة تعديل خارج قشرة.

## أثر

Settings فقط لديه واحد سطر “إضافة” تنقل، ترتيب في “Agent مسبق ضبط” قبل، يتضمن**إضافة إعداد**و**إضافة قائمة**اثنان عدد وسم صفحة.“Agent مسبق ضبط” ما زال هو مستقل قسم منطقة، لأن هو تحرير كل جلسة agent تجميع، بينما غير فوري Host Loader شجرة.

وظيفة كل حق إبقاء واضح:`ui-settings-plugins` يملك “إضافة” صفحة و يمكن تحرير بطاقة،`ui-settings-plugin-inventory` يملك فقط قراءة بيان عرض،Host/RPC مسار ثابت. جديد “إضافة” عرض فقط يحتاج تسجيل واحد `settings.plugins.tab` مساهمة يكفي إضافة دخول.

هذا تجمع دمج اعتماد قسم منطقة يملك جهة يتم تجميع: لا يوجد `ui-settings-plugins` وقت،`ui-settings-plugin-inventory` سوف انتظار وسم slot إعلان كما لا تصيير أي محتوى. هذا هو عبر slot سجل التسجيل تحمل تحميل متعمد تركيب اعتماد، بينما لا هو ساكن حالة حزمة import.
