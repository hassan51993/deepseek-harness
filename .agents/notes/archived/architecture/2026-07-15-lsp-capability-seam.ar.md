# Agent Note: LSP قدرة seam و موجه إلى نموذج استعلام أداة

Status: implemented
Archived: 2026-09-04

[English](2026-07-15-lsp-capability-seam.md) | العربية

## مشكلة

harness قد أداة تجهيز نص بحث و ملف قراءة قدرة، لكن اثنان من كل لا يمكن تعرف آخر برنامج رمز رقم. نص مطابقة لا يمكن يمكن اعتماد أرض منطقة قسم نفس اسم دالة، تتبع أثر استيراد آخر اسم، صلة ربط واجهة و أداة جسم تنفيذ، أيضا لا يمكن تقرير إبلاغ دفع قطع نوع. لذلك،agent(ذكي جسم) في تعديل شفرة قبل نقص قليل شخص صنف عبر تحرير جهاز لغة خادم نيل نيل دلالة تنقل قدرة.

لغة خادم بروتوكول (Language Server Protocol،LSP) دعم حمل قسم تابع ثلاثة عدد مسؤولية جهة: نموذج حاجة مستقر استعلام schema،harness حاجة مزود اختيار و مواصفة تحويل نتيجة، محلي تنفيذ فإن مسؤول عملية،JSON-RPC، مساحة العمل، تزامن و نظام الملفات سلوك. سوف ثلاثة من دمج سوف جعل نموذج اتفاق ربط محلي عملية فرعية، و منع عائق بعيد مسار أو صندوق رملي أصلي مزود.

سماح كثير لغة خادم في استعلام وثيقة قد حسب حالي نص فتح وقت جدول الآن الأكثر جيد. توافق agent عميل يجب حد هذا بند حالة، تعريف داخلي قراءة هل حساب عمل نموذج مراقبة، و تأكيد حفظ وثيقة لقطة و خادم مساحة العمل بحث جذب يقع في نفس نظام الملفات نطاق الأسماء.

## قرار

سوف LSP بناء صار من ثلاثة عدد حزمة مجموعة صار قدرة seam، منها يتضمن واحد فقط قراءة نموذج أداة و واحد عام محلي مزود تنفيذ:

1. `packages/lsp/lsp` تحت `@deepseek-ai/dsh-lsp` مسؤول `ctx.lsp`، مزود تسجيل و اختيار، معيار تحويل طلب و نتيجة، تنفيذ تحكم، و بنية تحويل LSP خطأ.
2. `packages/lsp/lsp-stdio` تحت `@deepseek-ai/dsh-lsp-stdio` سوف إعداد stdio لغة خادم ملائم إعداد إلى هذا seam. واحد إضافة نسخة استقبال أداة اسم خادم جدول، و لـ كل مجموعة أمر و توسيع اسم إلى لغة id خريطة تسجيل واحد عزل مزود.
3. `packages/lsp/tool-lsp` تحت `@deepseek-ai/dsh-tool-lsp` مسؤول موجه إلى نموذج `lsp` schema، نص التوجيه إشارة توجيه، معامل تحقق، نتيجة حد و صيغة تحويل، و و نقل طريقة غير متصل UI عرض.

`dsh-lsp-stdio` هو عام host، لا هو لغة خادم دليل أو تثبيت جهاز. نشر صريح إعداد أمر و خريطة؛ لم قدوم preset يخص تركيب إضافة أو `cordis.yml` overlay.

نموذج و seam فقط عام `goToDefinition`،`findReferences`،`goToImplementation` و `hover`؛`ctx.lsp` لا توفير مهمة معنى JSON-RPC طريقة. هذه عملية حرف وجه كمية و Claude Code ناضج معرفة camelCase تسمية متسق، بينما أداة اسم و `file_path` حقل ما زال من harness ذاتي سطر تعريف.

نص التوجيه سوف LSP تحديد موضع لـ دقيق استعلام يد مقطع:`Use search/read for ordinary navigation. Use lsp when textual matches are ambiguous or before a change requires precise definitions, implementations, or references.`

## حزمة و مسؤولية حد

`dsh-lsp` حسب حمل صنف لوحة نوع id و توسيع اسم إلى لغة id خريطة تسجيل مزود.`registerProvider()` بـ أصل فرعي طريقة احتلال استخدام id و كل مواصفة تحويل توسيع اسم: إدخال بلا فاعلية أو وجود اندفاع مفاجئ وقت لا إصدار أي حالة،dispose(مورد تحرير) دالة تحرير الكل احتلال استخدام. مزود إضافة عبر `ctx.effect()` تسجيل. نظام حسب استعلام كما لا تلقي ترتيب أثر أرض اختيار مزود؛ لا يوجد مطابقة بند وقت إرجاع بنية تحويل غير ممكن استخدام خطأ. رقم واحد إصدار لا توفير glob،language-id أو صريح توجيه اختيار جهاز، أيضا لا ساكن حالة إعلان عملية قدرة.

seam فقط عام `query(request, signal?)`، لأن لا يوجد حقل حاجة تنفيذ طبقة ملء ملء قيمة افتراضية:`workspaceRoot` هو لا بد ملء بند،`languageId` قدوم ذاتي تسجيل خريطة، مهلة و نتيجة حد من مستهلك مسؤول.`query()` تنفيذ اختيار و دفع توجيه وقت لا استخدام إخفاء `??` بعد تجهيز منطق، لذلك لا يوجد حاجة resolve يمكن تنفيذ spec.`dsh-tool-lsp` تحقق نموذج معامل، و فقط يأخذ `exec.signal` بصفة عار `AbortSignal` نقل تمرير، و web متسق، و جعل `dsh-lsp` لا اعتماد `dsh-tools`. مزود في اختيار قبل يتم إزالة وقت حسب غير ممكن استخدام فشل؛ بعد dispose التزام دوران قد اختيار مزود إلغاء دورة الحياة، لا تعديل توجيه.

اتفاق مثل تحت:

```ts
import type { Branded } from '@deepseek-ai/dsh-brand'

type LspOperation = 'goToDefinition' | 'findReferences' | 'goToImplementation' | 'hover'
type LspProviderId = Branded<'LspProviderId'>

interface LspPosition {
  readonly line: number
  readonly character: number
}

interface LspRange {
  readonly start: LspPosition
  readonly end: LspPosition
}

interface LspQueryRequest {
  readonly operation: LspOperation
  readonly filePath: string
  readonly position: LspPosition
  readonly workspaceRoot: string
}

interface LspProviderQuery extends LspQueryRequest {
  readonly languageId: string
}

type LspQueryResult =
  | { readonly kind: 'locations'; readonly locations: readonly { readonly uri: string; readonly range: LspRange }[]; readonly resolvedWorkspaceUri: string }
  | { readonly kind: 'hover'; readonly hover: { readonly contents: string; readonly range?: LspRange } | null }

interface LspProvider {
  readonly id: LspProviderId
  readonly extensionToLanguage: Readonly<Record<string, string>>
  query(request: LspProviderQuery, signal?: AbortSignal): Promise<LspQueryResult>
}

interface LspService {
  registerProvider(provider: LspProvider): () => void
  query(request: LspQueryRequest, signal?: AbortSignal): Promise<LspQueryResult>
}
```

خريطة مفتاح مواصفة تحويل لـ حمل قبل توجيه نقطة صغير كتابة توسيع اسم، و حسب `filePath` الأكثر بعد واحد توسيع اسم اختيار؛ لغة id فقط لأجل وثيقة تزامن.seam في موضع و نطاق من صفر بدء حسب UTF-16 حساب عدد.`findReferences` بداية نهاية يتضمن إعلان: مزود في داخلي تنفيذ هذا قيد، محلي خريطة ضبط `context.includeDeclaration: true`، استدعاء جهة لا يستطيع إعداد. غلاف إغلاق نتيجة ربط دمج سوف تنقل موحد واحد لـ موضع، سوف `hover` موحد واحد لـ محتوى أو `null`؛ تنقل نتيجة يحمل مزود مواصفة مساحة العمل URI، جعل مستهلك في تنفيذ عالم حد نطاق الأسماء داخل متبادل مقابل تحويل ملف URI.seam لا عام بروتوكول نوع، عملية أو وثيقة تحكم، أيضا لا توفير عام طلب هروب توليد فتحة.

`dsh-lsp-stdio` مسؤول خادم إعداد،JSON-RPC، عملية و مؤقت وثيقة حالة و بروتوكول تحويل. هو عبر `ctx.fs` قراءة، عبر `ctx.subprocess` بدء، فقط اعتماد اثنان من Service Definition حزمة بينما غير أداة جسم مزود؛[يمكن نقل غرس تنفيذ بيئة قرار](2026-07-28-portable-execution-world-consumers.ar.md) مسؤول تعريف هذا نوع إعداد مقابل. خادم جدول مفتاح هو مزود id. إضافة في تسجيل قبل تحليل كل خادم محلي ضبط؛ إذا لاحق خريطة بلا فاعلية أو حدوث اندفاع مفاجئ، إضافة سوف سحب إلغاء هذا قبل تسجيل، و لـ كل مزود إبقاء مستقل عملية حوض.`dsh-tool-lsp` في وقت التشغيل فقط حقن `tools`،`lsp` و `systemPrompt`، عبر حزمة داخل `sessionCwd(exec)` مساعد مساعدة دالة من `exec.agent?.session.header.cwd` أخذ نيل مساحة العمل، ذلك أخذ قيمة طريقة و نظام الملفات أداة متسق، أيضا لا استيراد مزود.

## موجه إلى نموذج اتفاق

مفرد واحد `lsp` أداة قبول التالي معامل:

```ts
interface LspToolInput {
  readonly operation: 'goToDefinition' | 'findReferences' | 'goToImplementation' | 'hover'
  readonly file_path: string
  readonly line: number
  readonly character: number
}
```

`line` و `character` هو من 1 بدء حساب عدد صحيح عدد UTF-16 ضوء علامة جلوس علامة؛ أداة سوف ذلك تحويل لـ seam في من صفر بدء `LspPosition`، و سوف تصيير موضع تحويل عودة.`findReferences` يتضمن إعلان، تجنب تجنب أثر قسم تحليل تسرب إسقاط تعريف موضع. مزود، لغة id، مساحة العمل أصل دليل، حد، مهلة، ابتدائي تحويل و يمكن تنفيذ ملف متساو لا دخول نموذج إدخال.

أداة يجب من جلسة `header.cwd` أخذ نيل `workspaceRoot`، لا يوجد بعد تجهيز قيمة؛ ناقص وقت في استعلام أو بدء قبل بـ `LSP_WORKSPACE_REQUIRED` فشل. محلي مزود أساس في أصل دليل تحليل متبادل مقابل مسار و مباشر قبول قطعا مقابل مسار؛ اثنان نوع مسار كل سوف إجراء مواصفة تحويل، إذا هدف يقع في مواصفة مساحة العمل خارج، فإن في بدء قبل رفض.

موضع في لا تطبيق harness مضيف مسار قاعدة حال حال تحت حسب ملف مستقر قسم مجموعة و تصيير لـ `path:line:character`. صالح `file:` URI سقوط في مزود مواصفة مساحة العمل URI داخل وقت تحويل لـ متبادل مقابل مسار، يقع في ذلك خارج وقت تحويل لـ من URI إرسال توليد قطعا مقابل مسار؛ صيغة خطأ URI و غير `file:` URI إبقاء أصل مثال.`maxLocations` قيمة افتراضية لـ `100`، و تقرير إبلاغ حذف بند؛`maxResultChars` قيمة افتراضية لـ `16_000`، و حد كل كامل تصيير نتيجة، منها يشمل قطع قطع بيانات وصفية. فارغ موضع و `null` hover هو نجاح بلا نتيجة استجابة؛ خادم تحميل حمل ناقص أو صيغة خطأ وقت، بـ بنية تحويل `LSP_MALFORMED_RESPONSE` خطأ فشل.

و نقل طريقة غير متصل عرض جهاز استخدام `{ card: 'generic', kind: 'search', title, locations: [{ path: file_path, line }] }`،`title` من معامل دفع توجيه و علامة واضح عملية و ضوء علامة. من في `FileLocation` لا يوجد character، تتبع مع موضع تجمع تركيز إدخال سطر، عنوان إبقاء كامل ضوء علامة؛ عرض إبقاء صاف دالة.

## مهلة ملكية

`dsh-tool-lsp` سوف واحد يمكن إعداد `timeoutMs` ميزانية مرفق إضافة إلى أداة تعريف، قيمة افتراضية لـ `60_000`.`dsh-tool-call-timeout-policy` تنفيذ ميزانية و توفير نقل دخول `ctx.lsp.query` `exec.signal`؛ هذا ميزانية تغطية ترتيب طابور، فتح، استعلام و إغلاق كامل دورة الحياة، نموذج غير ممكن إعداد.

seam و مزود لا زيادة بدء أو طلب قطع توقف وقت. غير أداة استدعاء جهة لن نيل نيل إخفاء مهلة، يجب ذاتي سطر توفير `AbortSignal`، و في حاجة ميزانية وقت استخدام `deadline()`.

مزود dispose حدوث في أداة تنفيذ خارج، لذلك `dsh-lsp-stdio` إبقاء `shutdownTimeoutMs`(افتراضي `5_000`) حد `shutdown`/`exit`، و `killGraceMs`(افتراضي `2_000`) ، معا لأجل حد طلب إلغاء عرض حد مدة و من SIGTERM ترقية إلى SIGKILL عرض حد مدة؛ فشل نسخة تنظيف أيضا استخدام نفسه حد. تحديد وقت جهاز قيمة تجاوز مرور Node `2_147_483_647` ms ضبط درجة نطاق وقت، إضافة تحميل فشل. مزود استخدام `deadline()` و `timeoutOf()`، لكن ما زال مسؤول طلب إلغاء، عملية إشارة و انتظار إغلاق، لأن مهلة إشعار لن إنهاء عمل.

## مساحة العمل، نظام الملفات و وثيقة تزامن

`dsh-lsp-stdio` في لغة خادم تنفيذ بيئة في عبر `ctx.fs` مواصفة تحويل و قراءة ملف. هو اشتراط مساحة العمل هدف هو دليل، استخدام مزود ذاتي لديه containment رفض مساحة العمل خارج مصدر ملف، إزالة استهلاك `streamText`، و في قسم قطعة وصول وقت تنفيذ `maxDocumentBytes` حد أعلى؛ عادي ملف تحقق و UTF-8 حل رمز ما زال من مزود مسؤول، وثيقة حد أعلى فإن من بروتوكول مستهلك مسؤول. هو سوف إبرة مقابل كل بند نظام الملفات عملية دمج استدعاء جهة إلغاء و مزود dispose، تتبع أثر بعد لم دخول طابور صف مساحة العمل فحص بحث، و في dispose خلال انتظار هذه فحص بحث تسوية. هو لا إرسال `fs/observed`: فقط لديه LSP نتيجة مقابل نموذج مرئي، لذلك استعلام لا ممتلئ كاف كتابة قبل قراءة سياسة.

`read` أداة إخراج حمل نافذة و سطر رقم، دخول transcript(نص سجل) كما قد يتم مراقبة، لا ملائم دمج بصفة مصدر ملف. في `tool-lsp` داخل قراءة أيضا سوف يأخذ مزود مخصص استخدام تزامن مسؤولية تسليم إعطاء مستهلك، و ترتيب حذف غير محلي مزود.

محلي مزود مقابل كل مرة استعلام كل اعتماد توافق أولوية مؤقت فتح مسار. هو قبول قديم صيغة `textDocumentSync` `Full` أو `Incremental`، أيضا قبول ضبط `openClose: true` خيار؛ تزامن قدرة ناقص، لـ `None` أو واضح لا توافق وقت، في `didOpen` قبل بـ لا دعم حمل خطأ فشل.

1. عبر `ctx.fs` تحليل مصدر ملف و فحص ذلك يقع في مساحة العمل داخل، مجددا عبر نفس مزود تدفق صيغة قراءة حالي نص، معا تنفيذ وثيقة بايت حد أعلى.
2. إرسال `textDocument/didOpen`، منها يتضمن إصدار `1`، كامل نص و إعداد لغة id. هذا كتابة ما زال يمكن إلغاء؛ كتابة فشل أو تعرض إلغاء سوف جعل نسخة بطلان، و انتظار محدود عملية إنهاء إتمام، حوض عندئذ قدرة إعادة استخدام هو.
3. إرسال الذي طلب `textDocument/definition`،`textDocument/references`،`textDocument/implementation` أو `textDocument/hover` طلب.
4. إذا `didOpen` نجاح، فإن في طلب إتمام أو إلغاء بعد في `finally` في محاولة تجربة إرسال `textDocument/didClose`. إغلاق كتابة فشل لن تغطية قد تحديد نتيجة أو خطأ، لكن سوف جعل نسخة بطلان، و انتظار محدود عملية إنهاء إتمام.

كل مرة استدعاء بعد كل إغلاق وثيقة، لذلك رقم واحد إصدار لا حاجة `didChange`،`didSave`، محتوى ذاكرة مؤقتة، تغيير مستمع أو وثيقة LRU. كل مساحة العمل مزود طابور صف يمكن إلغاء، و سلسلة سطر تنفيذ مصدر ملف قراءة، فتح، استعلام و إغلاق كامل دورة الحياة، لذلك انتظار في استعلام فقط في جولة إلى هو وقت عندئذ قراءة حالي بايت؛ نسخة أيضا سوف سلسلة سطر تنفيذ بروتوكول دورة الحياة. مختلف مساحة العمل يمكن و سطر. خادم مساحة العمل بحث جذب ما زال مسؤول من مصدر ملف قفز تحويل إلى قد إغلاق ملف.

مواصفة مساحة العمل هدف يجب هو دليل. ذلك هدف مفتاح توفير عملية حوض identity، عملية مسار توفير cwd، عودة مزود كل `file:` URI فإن توفير `rootUri` و وحيد `workspaceFolders` بند؛ نظام الملفات مزود سوف آخر اسم تحليل لـ نفس مفتاح وقت، هو جمع مشترك نسخة. نتيجة موضع يمكن في مساحة العمل خارج، لكن خارجي مسار لا يستطيع يصبح استعلام مصدر. لا يمكن و تركيب عملية فرعية مزود مشترك مسار نظام الملفات يخص تركيب خطأ، لا هو آخر بناء LSP حزمة إدارة من.

## محلي خادم دورة الحياة و بروتوكول سلوك

`dsh-lsp-stdio` حسب `(provider id, canonical workspace target)` كسول بدء واحد خادم، و عبر single-flight دمج بدء. إضافة تحميل وقت، هو استخدام قد إعداد بيئة استدعاء `ctx.subprocess.resolveExecutable()`؛ أمر غير ممكن استخدام وقت في تسجيل قبل فشل. أول مرة استعلام عبر أصلي بروتوكول إدارة طريق بدء خادم، لا مرور مرور shell، و استلام تجميع محدود stderr ذيل جزء.`maxMessageBytes` قيمة افتراضية لـ `16_000_000`،`maxStderrBytes` قيمة افتراضية لـ `1_000_000`،`maxDocumentBytes` قيمة افتراضية لـ `4_000_000`. انهيار انهيار جعل حالي استعلام فشل كما لا إعادة وضع؛ لاحق استعلام يمكن استبدال عملية. كل مرة استعلام الأكثر كثير بدء واحد عملية، لذلك MVP لا ضبط عبر طلب إعادة بدء حساب عدد جهاز.

ابتدائي تحويل استخدام `processId: null`، لأن عميل و خادم ممكن يقع في مختلف عملية نطاق الأسماء. هو إعلان `general.positionEncodings: ['utf-16']`،`workspace: { workspaceFolders: true, configuration: true }`،`textDocument.hover.contentFormat: ['markdown', 'plaintext']`، و definition و implementation `linkSupport: true`، لكن لا دعم حمل حركة حالة تسجيل. خادم إرجاع عملية و تزامن قدرة متساو لـ حق مصدر. خادم حذف `positionEncoding` وقت افتراضي لـ `utf-16`؛ أخرى قيمة متساو يخص بروتوكول خطأ. إعداد يمكن توفير ابتدائي تحويل خيار و `workspace/configuration` استجابة، لكن عميل رفض `workspace/applyEdit`، أبدا تنفيذ أمر أو تحرير.

تنقل نتيجة مباشر خريطة `Location`، و سوف `LocationLink` `targetUri` و `targetSelectionRange` خريطة لـ موحد واحد موضع. موضع يجب هو غير سالب كامل عدد.`hover` عودة واحد تحويل فقط قبول صالح `MarkupContent` و `MarkedString` بنية، إبقاء نص قيمة، يأخذ حمل لغة وسم قيمة تصيير لـ محيط شريط شفرة كتلة، و بـ واحد فارغ سطر اتصال عدد مجموعة. موجه إلى نموذج أداة في تصيير بعد تطبيق `maxResultChars`.

إلغاء إشارة نقل تمرير إلى استعلام كل مرحلة مقطع، طلب id إنشاء بعد أيضا سوف إرسال `$/cancelRequest`. بلا استجابة خادم سوف يتم إنهاء و انتظار إغلاق؛ نسخة سلسلة سطر تحويل حفظ إثبات لا يوجد أخرى صحيح في تنفيذ عمل يتم وصل حمل في قطع.dispose سوف رفض و إلغاء عمل، محاولة تجربة أفضل أنيق إغلاق، عبر محدود إنهاء مسار ترقية معالجة، و انتظار تماما توقف مستقر.

## واضح تأخير بعد API

رمز رقم عملية بسبب حاجة مختلف schema كما و قراءة أو بحث إعادة تراكم بينما تأخير بعد؛ لم قدوم مساحة العمل رمز رقم أداة يجب استقبال بحث كلمة. استدعاء طبقة درجة بسبب دعم حمل درجة لا واحد بينما تأخير بعد،`prepareCallHierarchy` ما زال هو داخلي دقيق تجهيز خطوة، لا هو نموذج عملية.

تشخيص حاجة مستقل جديد طازج درجة، تراكم تراكم و transcript قاعدة. إعادة تسمية، شفرة عملية و صيغة تحويل انتظار تغيير قدرة حاجة مفرد وحيد أداة، و تجميع صار معاينة، إذن و كتابة سياسة.

مزود معلومة مهمة إعداد خادم. ذلك نظام الملفات مرئي صفة و عملية عزل تماما أخذ قرار في تركيب تنفيذ بيئة؛LSP لا زيادة مستقل صندوق رملي سياسة.

## تجهيز اختيار خطة

**وفق نقل Claude Code موحد واحد schema.** هو ضوء علامة عملية تحقق نواة قلب مشهد، لكن رمز رقم و استدعاء طبقة درجة حاجة مختلف معامل. وفق نقل تسعة نوع عملية سوف ثابت تحويل بعد لم تحقق واجهة، لذلك هذا seam فقط مقابل متساو أربعة نوع دلالة استعلام.

**سماح مزود تسجيل أداة.** قد تحميل خادم سوف تحكم نموذج schema و نص التوجيه، لا يمكن في محلي و بعيد مسار مزود بين صيانة حمل موحد واحد اتفاق.

**عام مهمة معنى LSP طريقة.** JSON-RPC هروب توليد فتحة سوف تسرب كشف بروتوكول تحميل حمل، و سماح لم مرور مراجعة تغيير أو أمر تنفيذ؛ عملية ربط دمج إبقاء غلاف إغلاق.

**عام `resolve(request)` / `query(spec)`.** لا يوجد حاجة ملء ملء قيمة افتراضية حقل وقت،resolve فقط سوف كشف مزود اختيار، بينما عام spec ممكن حمل متابعة إلى مزود dispose أو استبدال بعد. مفرد واحد عملية يجعل اختيار و استدعاء مشترك استخدام تسجيل دورة الحياة.

**سوف إشارة حزمة تركيب لـ LSP تنفيذ سياق كائن.** Web نقل تمرير عار `AbortSignal`؛ فقط حزمة تركيب هذا واحد حقل سوف صنع صار بلا يسمى لا مقابل تسمية. فقط لديه آخر عدد حقل تأكيد لديه حاجة وقت،`query()` عندئذ جذب دخول سياق كائن.

**عبر موجه إلى نموذج `read` أداة قراءة.**رفض، لأن أداة إخراج حمل نافذة و سطر رقم، سوف دخول transcript كما قد يتم مراقبة. مزود مباشر عبر عملية فرعية الذي استخدام نفس `ctx.fs` تنفيذ بيئة إزالة استهلاك تدفق صيغة نقل كامل نص.

**إبقاء وثيقة فتح.** مرآة مثل تحرير حاجة إصدار ملكية، تغطية كل مسار `didChange`،HMR استعادة، تصفية استبعاد و قديم قديم حالة قاعدة. مؤقت فتح تجنب تجنب في MVP جذب دخول هذا طقم حالة آلة.

**إعداد قسم مرحلة مقطع مهلة.** تضمين طقم تحديد وقت جهاز سوف إنتاج متبادل متبادل تنافس تنازع تصنيف و جديد ميزانية. واحد من استدعاء جهة مسؤول قطع توقف وقت تغطية استعلام؛ فقط لديه استدعاء خارج تنظيف إبقاء محلي حد.

**لا إرسال `didOpen`.** بروتوكول رغم سماح، لكن دعم حمل لا متسق كما ممكن استخدام قديم قديم خادم حالة. مؤقت فتح توفير واضح حالي لقطة.

**زيادة توجيه أو اختيار أول عدد مطابقة بند.** تسجيل ترتيب و HMR وقت آلة لا هو منتج دلالة، توجيه جدول أيضا سوف تكرار وحيد توسيع اسم كل حق. لذلك، توسيع اسم إعادة تراكم وقت تسجيل فشل.

**في واحد نسخة في تزامن استعلام.** إلغاء فشل وقت، إنهاء مشترك عملية سوف قتل ميت غير متصل عمل. نسخة داخل سلسلة سطر يمكن حد أثر نطاق؛ مختلف نسخة ما زال يمكن و سطر.

**داخل وضع preset أو PATH اكتشاف.** دليل سوف يجعل عام host تحمل تحمل لغة سياسة، بينما اكتشاف آلية لا يمكن دفع قطع معامل، لغة id أو ابتدائي تحويل إعداد. نشر صريح إعداد مزود، تركيب إضافة يمكن غلاف تركيب preset.

## اختبار

- حزمة اختبار ثابت ثلاثة عدد حزمة اعتماد جهة نحو، وقت التشغيل حقن و فقط عبر `ctx.lsp` عبر معلومة حد.
- أداة اختبار ثابت أربعة نوع عملية، جلوس علامة تحقق، إعداد حد و حذف علامة، نص التوجيه و UI عرض.
- سجل التسجيل اختبار ثابت أصل فرعي احتلال استخدام/تحرير، لا تلقي ترتيب أثر اختيار، و بنية تحويل غير ممكن استخدام، قد تحرير، اندفاع مفاجئ و لا دعم حمل عملية خطأ.
- اختبار استخدام stdio server ثابت دقيق ابتدائي تحويل قدرة، أربعة نوع بروتوكول خريطة،`Location`/`LocationLink` و `hover` عودة واحد تحويل، و `findReferences` إلى `references.includeDeclaration` خريطة.
- تزامن اختبار ثابت UTF-16 تنسيق تجارة و تحويل، تلقي دعم حمل و يتم رفض `textDocumentSync` شكل صيغة، فتح كتابة منع سد و فشل، إعداد مقابل مؤقت فتح/إغلاق، إغلاق كتابة فشل و خطأ استجابة رفض.
- مهلة اختبار ثابت واحد `TOOL_TIMEOUT` ميزانية، لا مقابل فوق تنقل إلغاء خطأ تصنيف،LSP بلا إخفاء قطع توقف وقت، و تلقي حد كما انتظار إتمام تنظيف.
- دورة الحياة اختبار ثابت بدء single-flight، كامل دورة الحياة سلسلة سطر تحويل و ترتيب طابور استعلام قراءة الأكثر جديد مصدر ملف، عبر مساحة العمل و سطر، يمكن إلغاء طابور صف، انهيار انهيار بعد لا إعادة وضع استبدال،stdin فشل بعد عملية تفكيك حذف، و dispose بعد تماما توقف مستقر.
- نظام الملفات مضيف اختبار ثابت session cwd اشتراط، مزود ذاتي لديه containment و URI تصيير، محدود وثيقة قراءة، بلا صيغة مصدر نص و لا إرسال `fs/observed`.
- بلا مفتاح كما ثابت إصدار TypeScript حقيقي خادم e2e تغطية أربعة نوع عملية؛ يمكن تشغيل إعداد استخدام نفس بند صريح مزود خريطة.
- لقطة تغطية نموذج مرئي schema، نص التوجيه، نتيجة و حذف تلميح؛ بناء ناتج خطر دخان اختبار تغطية قسم لقطة و تنظيف.
- حزمة و هيكل بنية وثيقة تغطية إعداد، أمان حد و بحث/قراءة إشارة توجيه؛ نفس تعديل في، جديد `packages/lsp/` حزمة مجموعة يلزم إضافة دخول AGENTS.md مستودع تخطيط كتلة،packages/README.md قسم مجموعة جدول و architecture.md.

## أثر

كل لغة خادم مقابل طريقة دعم حمل، قدرة حل تفسير و بحث جذب حينئذ خيط وقت آلة معالجة مختلف؛LSP لا يوجد موحد واحد “بحث جذب إتمام” إشارة. لا أداة تجهيز توافق مؤقت فتح تزامن قدرة خادم لا تلقي دعم حمل، أي جعل هو قدرة استعلام قد إغلاق وثيقة. تلقي دعم حمل خادم ما زال ممكن إرجاع فارغ نتيجة أو لا كامل نتيجة، لذلك أداة لا تحمل وعد عبر خادم كامل صفة. ثابت TypeScript e2e فقط بناء قيام واحد بند توافق صفة أساس خط، لا بديل جدول عبر لغة تحمل وعد.

مؤقت فتح سوف تكرار تحليل و إنتاج إشعار. نسخة داخل سلسلة سطر سوف زيادة تزامن agent تأخير متأخر، طويل مدة تشغيل مساحة العمل عملية فإن حمل متابعة احتلال استخدام داخل تخزين مباشر إلى dispose.

نفس وقت التشغيل داخل توسيع اسم كل حق متبادل رفض. أي جعل language id مختلف، اثنان عدد مزود أيضا لا يستطيع معا احتلال استخدام `.ts`؛ هذا هو متعمد قبول MVP حد. مسبق مدة توسيع طريقة هو في تسجيل لـ فوق زيادة من نشر إعداد selector، سماح وضع عرض متبادل رفض احتلال استخدام، معا لا نحو نموذج إدخال زيادة مزود اختيار، أيضا لا تغيير `LspProvider.query`.

UTF-16 ضوء علامة صف و بروتوكول تماما متسق، لكن نموذج صعب بـ في يتضمن غير BMP محرف نص في دقيق تأكيد حساب عدد. بلا فاعلية موضع أو لا في رمز رقم فوق موضع ممكن إرجاع فارغ نتيجة، لذلك خطأ نص و نص التوجيه عرض مثال يجب شرح جلوس علامة اتفاق، معا تجنب تجنب حث تشجيع نموذج واسع عام استخدام LSP.

إعداد مقابل نظام الملفات/عملية فرعية مزود سوف مقابل متساو استعلام لقطة و خادم بحث جذب، لكن لن لذلك جعل تلقي معلومة مهمة لغة خادم تغيير نيل أمان. مواصفة containment سوف في تحليل وقت رفض مساحة العمل خارج استعلام مصدر، لكن فتح تدفق لن في مسار تزامن استبدال خلال مقدار خارج حفظ إثبات مستقر جملة مقبض هوية؛ خادم ذاته نيل نيل تنفيذ بيئة الذي إعداد إذن، ما زال يمكن قراءة أخرى مسار أو استخدام ذاكرة مؤقتة.
