# Agent Note: أداة نتيجة إبقاء مكتبة

Status: implemented
Archived: 2026-09-04

[English](2026-07-06-tool-result-retention-library.md) | العربية

## مشكلة

كثير عدد موجه إلى نموذج أداة قد حد ذلك إرجاع سياق كمية، لكن كل أداة كل يملك مختلف نطاق جزء آلية و مفردات:bash إبقاء ذيل جزء و توفير spill ملف؛web search حد مصدر قائمة؛web fetch حد متن محتوى؛`glob`/`grep` اكتشاف أداة حاجة في سطر داخل توفير رقم واحد صفحة، معا لـ كامل نتيجة تجميع إبقاء دقيق حذف بيانات وصفية. مفرد واحد `truncate(text)` مساعد مساعدة دالة لا يمكن تغطية هذه حال حال: بند نوع أداة حاجة بند حساب عدد، و في أصل لغة خارج قسم مجموعة؛ نص نوع أداة فإن حاجة بايت ميزانية و UTF-8 أمان أول ذيل قطع قطع.

هذه أداة حاجة مشترك سحب كائن هو**إبقاء**، بينما لا هو عام تجميع دمج. استدعاء جهة نحو واحد محدود كائن إدخال بند أو نص قسم قطعة، قليلا بعد أخذ نيل إبقاء محتوى و دقيق حذف بيانات وصفية. أداة مخصص استخدام شفرة ما زال مسؤول عمل خدمة دلالة: ملف قسم مجموعة، سطر رقم، خروج رمز، مزود خطأ حالة،spill ملف و موجه إلى نموذج شرح. عام مشترك مكتبة فقط مسؤول واحد آلة آلة مشكلة:«إبقاء ماذا، أيضا حذف ماذا؟»

## قرار

`@deepseek-ai/dsh-output-retention` يقع في `packages/util/` تحت، و `dsh-brand` و `dsh-timeout` نفس درجة، مسؤول محدود نموذج مرئي إخراج. هو هو واحد مجموعة صاف صنف و دالة بنية صار مكتبة،**لا هو** Cordis خدمة أو إضافة: لا استقبال `ctx`، لا تسجيل أي محتوى، لا يحتفظ عبر استدعاء حالة، أيضا لا إرسال خروج حدث. كل أداة حزمة حاجة حد إخراج وقت مباشر استيراد هو.

هذا مكتبة يتضمن اثنان عدد متبادل متبادل مستقل retainer:

- `ItemRetainer<T>` معالجة لديه ترتيب منطق وحدة، مثال مثل مسار،grep مطابقة بند أو بحث مصدر. هو فقط دعم حمل `head` إبقاء، معا صيانة حمل retainer شكل، بـ سهل لم قدوم إضافة دخول أخرى إبقاء سياسة.
- `TextRetainer` معالجة موجه إلى بايت نص تدفق، مثال مثل bash stdout/stderr أو web استجابة متن. هو دعم حمل `head`،`tail` و `headTail` إبقاء، و في `finish()` وقت صيانة حمل UTF-8 حد.

اثنان عدد retainer كل سوف إرجاع واحد صغير نوع `PushDecision`؛ كل مرة استدعاء `push()` بعد، استدعاء جهة كل قدرة نيل معرفة هذا وحدة/قسم قطعة هل كامل إبقاء، و تراكم تراكم نتيجة هذا وقت هل قد يتم قطع قطع. لأن استدعاء جهة سوف متابعة إدخال كل واحد قد مراقبة إلى بند/قسم قطعة، الذي بـ حذف حساب عدد هو دقيق.

```ts ignore-check
/**
 * How much content the retainer omitted.
 *
 * `unknown` is reserved for callers that omit without a count; the retainers
 * themselves return `none` or `exact`.
 */
type Omitted =
  | { kind: 'none' }
  | { kind: 'exact'; count: number }
  | { kind: 'unknown' }

interface PushDecision {
  kept: boolean
  truncated: boolean
}

/**
 * Final result for ordered logical units.
 */
interface RetainedItems<T> {
  items: T[]
  truncated: boolean
  seen: number
  kept: number
  omitted: Omitted
}

/**
 * Final result for text streams.
 *
 * The returned `text` is safe to send to a formatter; the retainer does not add
 * tool-specific headers, exit markers, XML tags, or recovery instructions.
 */
interface RetainedText {
  text: string
  truncated: boolean
  omittedBytes: Omitted
}
```

### سياسة

بند إبقاء دعم حمل رأس جزء نافذة. نص إبقاء دعم حمل رأس جزء، ذيل جزء و أول ذيل بايت نافذة.

```ts ignore-check
type ItemRetentionStrategy =
  | {
      /** Keep the first `maxItems` units. Use for `glob`, `grep`, and web sources. */
      kind: 'head'
      maxItems: number
    }

type TextRetentionStrategy =
  | {
      /** Keep the first `maxBytes` bytes. */
      kind: 'head'
      maxBytes: number
    }
  | {
      /** Keep the final `maxBytes` bytes. Requires reading to the end. */
      kind: 'tail'
      maxBytes: number
    }
  | {
      /** Keep a stable prefix and suffix, omitting the middle. Requires reading to the end. */
      kind: 'headTail'
      headBytes: number
      tailBytes: number
    }
```

### أداة خريطة

`read` يتم متعمد ترتيب حذف في إبقاء مكتبة خارج. هو `read-render` مساعد مساعدة دالة يملك ملف مخصص استخدام قسم صفحة اتفاق:`offset`/`limit`، سطر رقم،`totalLines`،offset تجاوز حد خطأ، تدريجي سطر معاينة قطع قطع، و قدرة كاف في نافذة في طريق إيقاف مسح الذي اختيار إخراج بايت حد أعلى. هذا هو سطر نافذة مصير، لا هو عام إبقاء أصل لغة. هو لم قدوم يمكن مشترك في صفة تلميح مساعد مساعدة دالة، لكن لا ينبغي يأخذ قد اختيار تحديد نافذة مجددا نقل دخول `ItemRetainer`.

تحت نص `FsGlobEntry` و `FlatGrepMatch` هو مسبق مدة من اكتشاف أداة استخدام بند شكل، لا هو قائم إبقاء مكتبة توجيه خروج.`FsGlobEntry` هو واحد من خلفية إرسال توليد مسار؛`FlatGrepMatch` هو خلفية سوف إبقاء مطابقة بند حسب ملف قسم مجموعة قبل واحد بند لم قسم مجموعة grep مطابقة.

`glob` استلام تجميع كامل ترتيب ترتيب مسار قائمة بعد، استخدام `ItemRetainer<FsGlobEntry>`، و سوف ذلك إعداد لـ `{ kind: 'head', maxItems: globMaxResults }`. أداة في سطر داخل إبقاء رقم واحد صفحة، و يمكن عبر spill seam حفظ كامل قائمة. مسار خريطة، قفز مرور مرشح بند و `incomplete` متساو يقع في retainer خارج.

`grep` في قسم مجموعة قبل استخدام `ItemRetainer<FlatGrepMatch>`، و سوف ذلك إعداد لـ `{ kind: 'head', maxItems: grepMaxMatches }`. منفذ تحليل ripgrep إخراج، خريطة مسار، تطبيق تدريجي سطر معاينة قطع قطع، و إدخال مسطح مستو مطابقة بند. استدعاء `finish()` بعد، أداة حسب ملف مقابل إبقاء مطابقة بند قسم مجموعة؛ إذا سطر داخل نتيجة بلوغ إلى حد أعلى، أيضا يمكن عبر spill seam حفظ كامل مطابقة قائمة. قسم مجموعة لا يخص retainer، لأن حد أعلى إبرة مقابل مطابقة مجموع عدد، بينما لا هو ملف عدد؛ تدريجي مطابقة بند معاينة قطع قطع و `incomplete` أيضا و نتيجة درجة إبقاء متبادل متبادل مستقل.

`bash` يمكن استخدام `TextRetainer`، إعداد لـ `tail` أو `headTail`، و قراءة حتى عملية انتهاء.bash منفذ ما زال مسؤول spill ملف، خروج حالة، إشارة، مهلة و خلفية مهمة سلوك؛ إبقاء مساعد مساعدة دالة فقط في حاجة هذا سلوك وقت استبدال مؤقت تنفيذ داخل تخزين أول ذيل نواة حساب. طويل وقت تشغيل مهمة كل حق و[عام طويل وقت تشغيل أداة وقت التشغيل](2026-06-20-generic-long-running-tool-runtime.zh.md) متبادل متبادل مستقل.

`web_fetch` يمكن استخدام `TextRetainer`، إعداد لـ `head` أو `headTail`؛ إذا مزود يجب في داخلي قراءة و حل رمز، أيضا يمكن إبقاء من مزود مسؤول متن حد أعلى. بلا نقاش اعتماد أي نوع طريقة،fetch نتيجة في `truncated` ما زال هو مزود/أداة واقع، هذا مكتبة فقط توفير إبقاء نص و حذف بيانات وصفية.

`web_search` يمكن استخدام `ItemRetainer<WebSearchSource>`، إعداد لـ `head`. حالي مزود عبر معتاد إرجاع عدد مجموعة، الذي بـ هذا يخص أمر بعد معالجة، لكن ما زال قدرة موحد واحد تلميح معلومة.

### تلميح

هذا مكتبة عام واحد في صفة تلميح بنية و واحد صغير نوع صيغة تحويل خطاف، لكن موجه إلى مستخدم إجراء لفظ من أداة توفير.grep صفحة قدم سوف تلميح «تقليص صغير pattern،path أو include» ؛web fetch صفحة قدم سوف تلميح «نيل أخذ أكثر أداة جسم URL أو فصل عقدة» ؛bash فإن يمكن إشارة نحو spill ملف.retainer لا يمكن نيل معرفة هذه استعادة عملية.

```ts ignore-check
interface RetentionNotice {
  scope: string
  strategy: 'head' | 'tail' | 'headTail'
  unit: 'items' | 'bytes' | 'chars' | 'lines'
  limit: number | { head: number; tail: number }
  kept: number
  omitted: Omitted
}

const formatGrepNotice = (notice: RetentionNotice): string =>
  formatRetentionNotice(
    notice,
    ({ kept }) => `Results capped at ${kept}. Narrow the pattern, path, or include to see more.`,
  )
```

صيغة تحويل خطاف لحظة معنى إبقاء دقيق بسيط: أداة يأخذ `RetentionNotice` تحويل لـ ذاتي ذات صفحة قدم نص. مساعد مساعدة دالة يمكن موحد واحد حذف إجراء لفظ، لكن لا مسؤول استعادة إشارة جذب.

`truncated` يمثل retainer بسبب ميزانية حذف أصل هذا متاح محتوى، لا يمثل فوق تنقل نتيجة لا كامل. أداة سوف لـ إذن فشل، قفز مرور اثنان دخول صنع ملف، مزود نطاق جزء فشل، غير ممكن قراءة مرشح بند، بلا فاعلية UTF-8، و أخرى أي «لا يمكن فحص» حالة حال إبقاء مستقل حقل.

## أثر

**قد تسليم محتوى.** `@deepseek-ai/dsh-output-retention` توجيه خروج `ItemRetainer`،`TextRetainer`، نتيجة نوع (`RetainedItems`،`RetainedText`) ، سياسة نوع (`ItemRetentionStrategy`،`TextRetentionStrategy`) ،`Omitted`،`PushDecision`،`RetentionNotice`، و في صفة تلميح مساعد مساعدة دالة `describeOmitted`/`formatRetentionNotice`، كما لا اعتماد Cordis أو أي أداة حزمة. اختبار وحدة تغطية أداة لديه دقيق حذف حساب عدد بند رأس جزء إبقاء، نص رأس جزء إبقاء، نص ذيل جزء إبقاء، أول ذيل بايت إبقاء، صفر ميزانية،UTF-8 حد معالجة (2،3،4 بايت رمز موضع، و كل قطع قطع موضع فوق بلا فاعلية بدء بداية بايت) و لم معرفة حذف كمية إجراء لفظ.

**قد سجل لكن بعد لم ترحيل محتوى.** `glob`،`grep`،`bash`،`web_fetch` و `web_search` خريطة قد سجل في[حزمة README](../../../../packages/util/output-retention/README.zh.md) في، لكن هذا مرة تعديل و لم يأخذ كل أداة كل ترحيل إلى هذا مكتبة؛ ترحيل عمل لحظة معنى إبقاء عمل مستقل لاحق مهمة.`read` يتم واضح سجل لـ لا في نطاق داخل: ذلك `read-render` سطر نافذة اتفاق (`offset`/`limit`،`totalLines`،offset نطاق خطأ، تدريجي سطر معاينة قطع قطع، و إبرة مقابل الذي اختيار نافذة بايت حد أعلى) لا يخص عام إبقاء، بينما واحد `Omitted` حساب عدد أيضا لا يمكن معا جدول بلوغ سطر نافذة اثنان جانب.

**هذا مكتبة صيانة حمل حد.** `truncated` يمثل retainer بسبب ميزانية حذف أصل هذا متاح محتوى، أبدا يمثل فوق تنقل لا كامل. أداة مخصص استخدام حالة، يشمل `incomplete`، إذن فشل، مزود نطاق جزء فشل، قفز مرور اثنان دخول صنع ملف،bash spill مسار استعادة و بلا فاعلية UTF-8، متساو إبقاء في أداة مجال حقل في، يقع في retainer خارج. لم قدوم تعديل ترحيل بعض بند أداة وقت، هذا حزمة README و اختبار يجب إثبات، حذف متعمد تغيير تلميح إجراء لفظ خارج، نموذج مرئي نتيجة نص لا يوجد تغير.

**قبول أخذ ترك.**واجهة لحظة معنى فقط دعم حمل بند `head` إبقاء، و نص `head`/`tail`/`headTail` إبقاء؛ نافذة، قسم مجموعة ميزانية، شعور معرفة ترتيب ترتيب حد أعلى و فوق تنقل إيقاف تحكم، يلزم انتظار ثاني عدد مستهلك إثبات يحتاج طلب بعد مجددا جذب دخول. نص إبقاء حسب بايت حساب عدد، بـ حفظ عائق عملية/متن أمان؛ محرف درجة و سطر درجة معاينة ميزانية متابعة من أداة جسم أداة مسؤول.

## اعتبار مرور بديل خطة

**فقط إجراء أمر بعد `truncate(text)`.** غير مقبول: هو ملائم دمج Codex تاريخ/أداة إخراج قطع قطع مشهد، لكن سوف فقد فقد بند حساب عدد، قسم مجموعة حد،UTF-8 أمان بايت نافذة و دقيق حذف بيانات وصفية.

**استخدام واحد حمل يمكن إدراج نزع عودة ضبط عام `Collector<T>`.**غير مقبول، لأن هو سوف إخفاء غطاء اثنان نوع إعادة يلزم مورد نمط. منطق بند إبقاء حسب بند حساب عدد؛ نص إبقاء حسب بايت حساب عدد و صيانة حمل UTF-8 حد. مستقل `ItemRetainer` و `TextRetainer` اسم واضح جدول بلوغ هذا نوع فرق مختلف، معا إبقاء API دقيق بسيط.

**يأخذ `read` نافذة تسليم إعطاء `ItemRetainer`.**غير مقبول:`read` هو وحيد قد تسليم نافذة مستهلك، ذلك دلالة يخص ملف قسم صفحة، بينما لا هو عام إبقاء. واحد `Omitted` حساب عدد لا يمكن يمثل سطر نافذة اثنان جانب، بينما كما `read` أيضا يحمل `totalLines`،offset نطاق خطأ، تدريجي سطر معاينة قطع قطع و إبرة مقابل الذي اختيار إخراج بايت حد أعلى. يجعل `read-render` من أداة كل، يمكن تجنب تجنب مشترك مكتبة محيط التفاف واحد بند خاص مثال تمدد انتفاخ.

**يجعل قطع قطع يصبح `ToolExecutionResult` واحد جزء.** غير مقبول: أداة سجل التسجيل سوف لا نيل لا إدارة حل أداة مخصص استخدام استعادة إشارة جذب، قسم مجموعة، سطر رقم، خروج حالة و مزود دلالة. إبقاء هو من أداة Native renderer(أصلي مصير) استخدام مكتبة؛ نموذج مرئي إسقاط متابعة من أداة كل، بينما[مواصفة قيمة](2026-07-20-canonical-tool-output-contract.zh.md) يمكن إبقاء كامل قد أخذ تجميع نتيجة.

**في كل موجه إلى نموذج أداة schema في عام حد أعلى.** لا بصفة افتراضي خطة:Claude Code grep عام `head_limit`/`offset`، لكن هذا harness سوف يأخذ معتاد قاعدة ميزانية إبقاء لـ نشر إعداد، حذف غير نموذج تأكيد فعلي حاجة تحكم قسم صفحة. لم قدوم يمكن لـ أداة جسم أداة زيادة صنف يشبه read متابعة نقل حقل؛ هو لا يخص مشترك إبقاء أصل لغة.
