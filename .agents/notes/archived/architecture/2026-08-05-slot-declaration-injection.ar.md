# Agent Note: slot إعلان حقن و إعادة تحميل دورة الحياة

Status: implemented
Archived: 2026-09-04

[English](2026-08-05-slot-declaration-injection.md) | العربية

## مشكلة

عميل إضافة ممكن في إعلان بعض عدد slot إضافة قبل أو بعد نحو هذا slot مساهمة محتوى.Cordis خدمة حقن لا يمكن جدول بلوغ هذا نوع اعتماد: خدمة فقط قدرة بصفة بين وصل ترتيب إشارة؛ عميل manifest(بيانات وصفية بيان) اعتماد لن قاعدة تحديد تنشيط ترتيب؛ أي جعل كل متبادل صلة خدمة بداية نهاية تركيب،slot ما زال ممكن إزالة فقد بعد إعادة ظهور. لذلك، قيام أي تسجيل سوف و بعد لم إعلان slot شكل صار تنافس حالة، بينما انتظار غير متصل خدمة فإن سوف اقتران دمج هذا يمكن مستقل إعادة تحميل وظيفة.

slot درجة حار استبدال أيضا اشتراط اثنان عدد متبادل متبادل مستقل كل من. إزالة إعلان جهة إضافة يجب إزالة ذلك فرعي slot تحت كل مساهمة؛ إزالة مساهمة جهة إضافة فقط قدرة إزالة هذا إضافة ذاتي ذات بند. أي جعل إزالة فقد و إعادة ظهور دمج في نفس مرة إشعار في، نفس عدد key استبدال إعلان أيضا يخص جديد دورة الحياة.

## قرار

`SlotRegistry.inject(name, callback)` بـ قد إعلان slot ذاته بصفة اعتماد. كامل `SlotMap` key سوف مرور مرور ساكن حالة فحص؛ نظام لا جذب دخول نطاق الأسماء بناء جهاز، دمج صار Cordis خدمة أو slot مخصص تابع `Context`. إعلان وجود وقت عودة ضبط تزامن تنفيذ، لا فإن انتظار؛ عودة ضبط إرجاع واحد تزامن disposer، أو من كثير عدد disposer بنية صار تزامن iterable.iterable effect تثبيت أداة لديه أمر خدمة صفة: لاحق setup فشل وقت، نظام سوف حسب عكس ترتيب dispose(مورد تحرير) قبل yield كل effect.

هذا حساب هذا سجل مستقل في slot عادي بند إصدار declaration epoch(إعلان بديل مرة). كل عند فرعي إعلان إنشاء أو طي وقت،epoch كل سوف تغير. حقن سوف تسجيل إقامة نشط وثب epoch؛ هذا epoch انتهاء وقت، حقن سوف dispose ذلك عودة ضبط effect؛ أي جعل نهائي مراقبة قياس إلى حالة بداية نهاية لـ قد إعلان، أيضا سوف لـ استبدال إعلان إعادة تنفيذ عودة ضبط. عادي مساهمة تغيير لن إعادة بدء حقن.

إعلان جهة و مساهمة جهة كل منها إبقاء ذلك ذاتي لكن كل حق. حقن تحكم جهاز و كل بند مساهمة كل تشغيل في مساهمة جهة إضافة استدعاء وقت `Context` فوق، لذلك dispose هذا إضافة سوف معا إزالة ذلك انتظار و نشط وثب بند.slot حساب هذا قائم فرعي بند طي درجة ربط سوف في إعلان جهة إزالة فقد وقت إزالة بند؛ مع بعد، حقن سوف تشغيل ذلك disposer بـ تحرير خدمة طبقة مورد، و متابعة انتظار لاحق إعلان. نظام حيث لن سوف إعلان جهة إضافة `Context` إبقاء لـ capability مصدر، أيضا لن نحو مساهمة جهة عام هو.

حركة حالة إعادة تحميل شفرة استخدام عادي Cordis إضافة fiber بصفة استبدال وحدة: عبر `ctx.plugin()` تنشيط جديد وحدة؛ تركيب استبدال وحدة قبل، أولا dispose و انتظار قديم fiber؛ هذا fiber `slots.inject` و `slots.register` effect سوف مع لـ خروج.renderer حجز قراءة سوف مراقبة إلى حساب هذا إزالة و إزالة مكون؛ بلا حاجة بناء قيام slot ذاتي لديه fiber شجرة.

## فشل و دورة الحياة اتفاق

إذا حقن إنشاء وقت إعلان قد وجود، عودة ضبط setup فشل سوف تزامن فوق تقرير. تأخير متأخر إعلان ظهور بعد حدوث عودة ضبط فشل، سوف أولا إلغاء حجز قراءة و تراجع قد استلام تجميع effect، مجددا في slot إشعار تحديث جديد خارج فوق تقرير، تجنب تجنب واحد تسجيل جهة جعل أخرى listener نيل لا إلى تنفيذ آلة سوف. مباشر استدعاء `slots.register()` نحو لم إعلان slot تسجيل ما زال سوف رمي خروج استثناء: حقن هو صريح آلية، لن تقليل ضعيف تحميل وقت تحقق.

مقابل حقن تنفيذ dispose أداة لديه قوة انتظار صفة. هو سوف أولا إلغاء حجز قراءة، مجددا تحرير نشط وثب عودة ضبط effect، تجنب تجنب تفكيك إزالة إطلاق حساب هذا إشعار تكرار نشط هذا بند مساهمة. إعلان ربط teardown و حساب هذا حد تزامن، لذلك سوف في نفس tick أي لاحق تسجيل قبل تحرير خدمة طبقة مورد. مع إضافة واحد نفس dispose انتظار أمر حقن لا يمكن في بعد تنشيط.

## تجهيز اختيار خطة

**سوف `ConversationController` أو أخرى خدمة استخدام عمل ترتيب شاشة عائق.** خدمة وجود و لا يستطيع معرف متبادل ينبغي إعلان، أيضا لن تتبع مع إعلان إعادة تحميل دورة الحياة؛ فقط مسؤول عرض مساهمة جهة أيضا سوف لذلك إنتاج وهمي زائف حزمة اعتماد.

**سوف كل بند إعلان جسر وصل لـ `slot:<name>` Cordis خدمة.** هذا سوف تلوث صبغ خدمة نطاق الأسماء، جعل تجميع خطأ حركة حالة key تغيير صار ساكن صامت خدمة انتظار، و يأخذ حساب هذا حالة زائف تركيب صار عمل خدمة قدرة. أصلي slot حقن بلا حاجة تغيير Cordis توسيع اندفاع، يكفي توفير نفس مثال انتظار قدرة.

**لـ كل slot إنشاء Cordis سياق أو fiber.** مساهمة جهة حاجة هو ذاته إضافة دورة الحياة و إعلان دورة الحياة تسليم تجميع، بينما لا هو إعلان جهة قدرة.slot كل سياق سوف جذب دخول capability وراثة و مزدوج أب درجة تفكيك إزالة مشكلة، لكن لا يمكن تعديل حسن حساب هذا كل حق.

**يجعل `register()` خفي صيغة انتظار.** مقابل لم إعلان هدف قيام أي فشل هو واحد بند لديه قيمة قيمة إعداد فحص. صريح حقن قدرة كاف منطقة قسم متعمد مستقل ترتيب ترتيب مساهمة و خطأ تركيب.

**فقط أصل حسب `spec(name) !== undefined` حكم قطع استبدال.** طي و إعادة إعلان يمكن دمج صار واحد نهائي حالة بداية نهاية وجود إشعار، بينما قديم مساهمة هذا وقت قد يتم إزالة.declaration epoch إبقاء هذا بند دورة الحياة حد.

## أثر

slot اعتماد يمكن في تسجيل نقطة مراجعة حساب، و كما بلا حاجة خاص تحديد في حزمة ترتيب اتفاق يكفي تتبع مع إعلان استبدال. حركة حالة إضافة dispose سوف عبر قائم Cordis effect إزالة قد تصيير بند، بينما إعلان استبدال فإن لـ لاحق slot درجة HMR(حار وحدة استبدال) توفير مستقر خطاف.

وقت التشغيل لـ كل يتم وصول slot كثير صيانة واحد مفرد ضبط epoch، كما حقن عودة ضبط يجب إرجاع تنظيف عملية. كثير تسجيل عودة ضبط استخدام iterable effect، جعل setup و teardown إبقاء أصل فرعي صفة. مسطح مستو نقطة قسم key حساب هذا و وحيد `register()` تركيب مرجعي إبقاء ثابت.
