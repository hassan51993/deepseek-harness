# Agent Note: dsh تحت مستقل sdk-minimal profile

Status: implemented
Archived: 2026-09-04

[English](2026-08-24-standalone-sdk-minimal-profile.md) | العربية

## مشكلة

أقصى بسيط SDK agent حاجة صريح إضافة بيان. إذا يأخذ هو جدول بلوغ لـ كامل `sdk` profile فوق overlay، كل `dsh-base` خدمة ما زال إبقاء تركيب، ترتيب حذف منطق فإن اعتماد قسم تفرق في غير متصل إضافة في غربلة اختيار جهاز و disable بند إعداد. بـ بعد إضافة جديدة base بند إعداد أي جعل لا يوجد دخول موجه إلى نموذج أداة بيان، أيضا ممكن تغيير وقت التشغيل سلوك.

من استدعاء جهة توفير كامل Cordis إعداد شجرة يمكن نيل إلى تأكيد قطع بيان، لكن سوف التفاف مرور profile ابتدائي تحويل، تركيب حزمة تحليل، حمل دائم إضافة إدارة،home و استدعاء patch طبقة، و من `dsh` يملك عملية دورة الحياة. أقصى بسيط نمط حاجة في تركيب طبقة ترتيب حذف وظيفة، معا لا يستطيع إنشاء آخر عدد launcher أو Python ذاتي لديه تطبيق.

## قرار

### بدء و كل حق

`dsh --profile sdk-minimal` هو مع مرفق فقط بدء وقت profile. ذلك manifest فقط صف خروج `@deepseek-ai/dsh-sdk-minimal`، لا صف خروج `@deepseek-ai/dsh-base`. هذا تركيب حزمة في launcher فارغ profile أصل لـ فوق إدراج دخول كامل Cordis إعداد شجرة، بينما profile patch،home patch و لديه ترتيب استدعاء patch ما زال في ذلك فوق إبقاء عادي أولوية درجة.

`dsh` CLI ما زال هو وحيد تطبيق launcher.Python عرض مثال عبر عام `profile` حقل و صريح Harness home اختيار `sdk-minimal`.Python لا كشف كامل إعداد أو مهمة معنى argv مسار. كامل Python و TypeScript SDK قيمة افتراضية ما زال هو `sdk`.

هذا تركيب حزمة إعادة استخدام `@deepseek-ai/dsh-sdk-app` توفير أمر help،stdin EOF و محدود إغلاق. بدء مزود قبول profile اسم إعداد، لذلك اثنان عدد SDK profile كل قدرة عرض ذاتي ذات فعلي أمر، كما بلا حاجة نسخ عملية دورة الحياة شفرة.

### صريح تركيب

هذا تركيب حزمة يملك واحد DeepSeek مهايئ،SDK JSON-RPC خدمة، صريح agent نواة قلب، محلي عملية فرعية و لا تلقي حد نظام الملفات مزود، حسب منصة اختيار حمل دائم shell، نص استبدال editor، و يقع في `$DSH_HOME/sessions` لم ضغط JSONL جلسة.Linux و macOS تركيب Bash،Windows تركيب PowerShell.SDK ابتدائي تحويل طلب يملك نموذج id؛`DSH_CONTEXT_WINDOW` لـ لا في مهايئ بناء اقتراح دليل في نموذج توفير بعد تجهيز سعة كمية.Persona قدوم ذاتي `DSH_SYSTEM_PROMPT`، اعتماد قدوم ذاتي `DEEPSEEK_API_KEY`.

Harness هوية، وقت التشغيل سياق،workspace إشارة أمر،skills، موجه إلى نموذج job تحكم،compaction،settings، حمل إدارة اعتماد، بعيد قياس،Web أداة،subagent و أخرى كل base بند إعداد متساو لا وجود، بينما لا هو يتم إخفاء. هذا profile ثابت استخدام `danger-full-access`،`maxTokensAsSuccess: false` و فقط بدء وقت patch تحميل.

### ذاتي تعريف و Web

`dsh plugin --profile sdk-minimal add <package>` تثبيت حمل دائم اعتماد و تركيب حزمة طبقة.Profile ذاته `cordis.patch.yml`،home patch و Python `patches` قسم آخر توفير حمل دائم، آلة جهاز محلي و تدريجي مرة استدعاء بند إعداد تغيير. ذاتي تعريف يمكن توسيع أو استبدال صريح إعداد شجرة، لكن ما زال مرور مرور نفس عدد launcher و profile تحليل.

Python وقت التشغيل متابعة تحزيم `dsh-web-app` و قبل طرف ناتج.`dsh web` سوف من قد تثبيت wheel بدء هذا عدد مستقل متصفح تطبيق؛Python SDK client لا يستطيع اختيار `web`، لأن منها لا يوجد JSON-RPC server بند إعداد.

## قائم قرار و يحل محل علاقة

هذا قرار جزء يحل محل[تطبيق profile استخدام نفس عدد dsh launcher](2026-08-22-single-dsh-application-launcher.zh.md) في base أولوية قاعدة و مستقل إعداد شجرة مرفوض. صريح بيان يخص منتج سلوك وقت، يمكن استخدام مستودع ذاتي لديه كما لديه إصدار مستقل profile تركيب حزمة؛ من استدعاء جهة توفير كامل إعداد شجرة و بديل يمكن تنفيذ برنامج ما زال يتم مرفوض.

هذا قرار أيضا يحل محل [Python SDK وقت التشغيل عبر dsh profile launcher بدء](2026-08-23-python-sdk-dsh-profile-runtime.zh.md) في أقصى بسيط overlay تنفيذ، و [profile إضافة تركيب حزمة](2026-08-05-profile-plugin-bundles.zh.md) في افتراضي profile متساو بـ base فتح رأس جدول وصف. هذه Agent Note مقابل launcher كل حق،Python تحزيم و home اشتراط، عادي profile قسم طبقة و إضافة إدارة ما زال إبقاء مستقل مرجعي. لا يوجد نشط وثب Agent Note يتم تماما يحل محل أو رمز دمج عودة ملف شرط.

## تحقق

تركيب حزمة اختبار ثابت تأكيد قطع بند إعداد و اعتماد بيان.Profile نموذج لوح و إعداد dump اختبار ثابت مفرد تركيب حزمة manifest، فقط بدء وقت دورة الحياة،`dsh-base` نقص مقعد و وحدة HMR نقص مقعد.Keyless شفرة المصدر اختبار بدء حقيقي `dsh --profile sdk-minimal` عملية، إتمام واحد عودة دمج تأكيد توليد manifest.Installed-wheel أقصى بسيط مشهد عبر قد إيداع نموذج مرئي لقطة ثابت كامل توجيه النظام و اثنان عدد مقابل خارج عام نشر أداة، معا مرور من تحزيم يمكن تنفيذ برنامج تحقق حمل دائم shell حالة،editor ملف فاعلية نتيجة و JSONL حفظ دائم.

## اعتبار مرور بديل خطة

**متابعة يأخذ أقصى بسيط نمط بصفة `sdk` فوق overlay.** مرفوض: غربلة اختيار موجه إلى نموذج أداة لن إزالة base خدمة، نص التوجيه مساهمة جهة، حفظ دائم اختيار أو لاحق وقت التشغيل سلوك. هذا خطة أيضا اشتراط مشترك SDK server توفير أصل أداة غربلة اختيار، و اشتراط system-prompt إعداد توفير complete-persona سريع سريع بند؛ هذا اثنان عدد مشترك واجهة متساو لم يعد يحمل هذه تركيب تحكم بند.

**استعادة Python `cordis` معامل أو من بيئة اختيار كامل إعداد.** مرفوض: هذا سوف إعادة إنشاء Python ذاتي لديه تطبيق تركيب، و التفاف مرور profile إضافة إدارة و launcher دورة الحياة.

**إنشاء ثاني عدد أقصى بسيط SDK بدء إضافة.** مرفوض: وحيد تغير هو profile شعور معرفة help؛SDK بدء مزود يمكن يملك هذا إعداد، معا يأخذ EOF و إغلاق سلوك إبقاء في واحد موضع.

**من Python وقت التشغيل إغلاق حزمة إزالة Web حزمة.** مرفوض:wheel توزيع عادي `dsh` تطبيق، بينما كما Python نشر أيضا ممكن حاجة `dsh web`؛ هذه تطبيق من profile اختيار عزل، بينما لا هو من تحزيم فرق مختلف عزل.

## عاقبة

أقصى بسيط نموذج و وقت التشغيل بيان فقط لديه في الذي تابع تركيب حزمة تغير، أو تلقي معلومة مهمة فوق طبقة patch توسيع هو وقت عندئذ سوف تغير. بديل قيمة هو لحظة معنى تكرار واحد شجرة مقارنة صغير كامل تطبيق شجرة، و في هذا profile في حذف مشترك settings، اعتماد، سياسة تحكم، بعيد قياس و Web وظيفة. حاجة هذه خدمة مستخدم اختيار كامل `sdk` profile؛ اثنان نوع اختيار ما زال مشترك استخدام واحد launcher، واحد طقم profile مفردات و واحد تحزيم وقت التشغيل.
