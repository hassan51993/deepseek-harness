# Agent Note: مشترك أثر مجال قسم طبقة تخزين

Status: implemented
Archived: 2026-09-04

[English](2026-07-12-scoped-layers-store.md) | العربية

## مشكلة

agent(ذكي جسم) أثر مجال آلية ([قرار](2026-07-08-agent-scope-contexts.zh.md) ،[وقت التشغيل تصميم](2026-07-12-agent-scope-runtime-design.zh.md)) يجعل دعم حمل أثر مجال سجل التسجيل عكس تكرار عرض نفس نوع شكل: واحد عام تسجيل طبقة، إضافة فوق واحد و أداة جسم agent دقيق مقابل طبقة. سبعة عدد تسجيل باب وجه كل اعتماد هذا واحد شكل:`tools.register`،`tools.restrict` و `tools.guard`(يقع في `dsh-tools`) ؛`SystemPrompt.section`،`SystemPrompt.tools` و `SystemPrompt.variable`(يقع في `dsh-system-prompt`) ؛ و `CommandRuntime.register`(يقع في `dsh-commands`).

إذا لا يوجد مشترك أصل لغة، كل باب وجه كل يلزم محيط التفاف ذاتي ذات مجال حالة تكرار نفسه دورة الحياة تحرير ترتيب: من استدعاء جهة سياق توجيه خروج مرئي صفة، حسب يحتاج إنشاء مخصص تابع حاوية، يأخذ تابع رئيسي ربط إلى نفس عدد Cordis fiber، أولا تركيب دخول undo مجددا إشعار مراقبة من، أصل مثال إرجاع Cordis disposer، و عودة استلام فارغ مخصص تابع حالة. كل منها قسم مغادرة خريطة و تجميع دمج نوع أيضا سوف يجعل خدمة نقص قليل واحد يمثل بعض عدد scope كامل مساهمة كائن.

تكرار شفرة تحمل تحميل حال ثلاثة بند لا واضح إظهار اشتراط:

- مرئي صفة و تابع رئيسي يجب قدوم ذاتي نفس عدد سياق؛ إذا قسم فتح قبول اثنان من، حينئذ قدرة تسجيل تسجيل خروج مقابل واحد scope مرئي، لكن مع آخر عدد scope إلغاء تدمير مساهمة.
- change عودة ضبط تشغيل قبل يجب استلام تجميع undo، رمي خطأ عودة ضبط عندئذ قدرة تراجع تغيير.
- عام disposer يجب حينئذ هو `ctx.effect()` إرجاع ذلك عدد دالة؛ حزمة تركيب هو سوف كسر تالف Cordis أساس في هوية لديه ترتيب تفكيك حذف.

مشترك هو دورة الحياة و إبقاء إدراج دخول ترتيب تخزين، بينما لا هو سجل التسجيل سياسة. أداة حد، إبقاء نقل بند معالجة، نص التوجيه طلب قيمة وقت آلة، أمر مواصفة تحويل، دقيق تشخيص و عودة ضبط استثناء عزل، ما زال قسم آخر يخص مختلف مجال اتفاق.

## قرار

`@deepseek-ai/dsh-scope` توفير و مفتاح نوع غير متصل `store.ts` تنفيذ وحدة. هذا حزمة متابعة سوف Cordis و `@deepseek-ai/dsh-invariants` صف لـ مقابل انتظار اعتماد (peer dependency) ، ذلك ثابت كمية إعداد طقم وحدة إبقاء ثابت. حزمة أصل توجيه خروج أربعة عدد تخزين رمز رقم:`ScopeLayer`،`ScopedLayers`،`NamedEntries` و `AnonymousEntries`.`EntryValues` ما زال هو داخلي واجهة،`store.ts` لا هو حزمة فرعي مسار.

`ScopeLayer` إبقاء صريح تجمع دمج عام فكرة، معا فقط اشتراط حكم قطع كامل طبقة هل لـ فارغ. خدمة تعريف واحد أداة جسم طبقة، جعل ذلك جدول بنية و مجال helper ملائم دمج هذا خدمة؛`ScopedLayers` مسؤول بنية صنع، اختيار، دورة الحياة تعليق وصل، إشعار و تجمع دمج عودة استلام.

## عام واجهة

```ts ignore-check
export interface ScopeLayer {
  isEmpty(): boolean
}

export class ScopedLayers<L extends ScopeLayer> {
  constructor(
    createLayer: (scope: ScopeKey | undefined) => L,
    onChange: () => void,
  )

  readonly global: L
  peek(scope: ScopeKey | undefined): L | undefined

  merge<V>(
    scope: ScopeKey | undefined,
    pick: (layer: L) => NamedEntries<V>,
  ): Map<string, V>

  effect(
    ctx: Context,
    action: (layer: L) => () => void,
    options: { label: string; notify?: boolean },
  ): () => void
}

export class NamedEntries<V> {
  constructor(duplicateError: (name: string) => Error)
  insert(name: string, value: V): () => void
  get(name: string): V | undefined
  has(name: string): boolean
  keys(): IterableIterator<string>
  entries(): IterableIterator<[string, V]>
  values(): IterableIterator<V>
  isEmpty(): boolean
}

export class AnonymousEntries<V> {
  append(value: V): () => void
  values(): IterableIterator<V>
  isEmpty(): boolean
}
```

## تخزين اتفاق

- منشئ فقط إنشاء مرة `global`، استدعاء هو `createLayer(undefined)`. فقط لديه `effect()` سوف إنشاء مخصص تابع طبقة؛`peek()` و `merge()` من لا إنشاء مخصص تابع طبقة، بينما `peek(undefined)` إرجاع `undefined`، لأن عام طبقة قد صريح وجود.
- `merge()` هو وحيد سوف شيء تحويل نتيجة عام قراءة واجهة. هو حسب إدراج دخول ترتيب نسخ عام تسمية بند، مجددا حسب مخصص تابع بند إدراج دخول ترتيب تطبيق هذه بند؛ نفس اسم بند إتمام حجب حجب، لكن لن نقل حركة غير متصل اسم.
- `NamedEntries.insert()` بـ أصل فرعي طريقة فحص و إدراج دخول، إرجاع قوة انتظار كما فقط سحب إلغاء هذا دقيق بند undo، و عبر استدعاء جهة توفير عمل مصنع أخذ نيل الذي تابع سجل التسجيل دقيق إعادة اسم تشخيص. استعلام و مكرر إبقاء `Map` أصلي ترتيب، و في نفس عدد غير فارغ جدول generation داخل إبقاء نشط مرة تاريخ؛ صاف فارغ جدول سوف فتح بدء جديد generation، لذلك بعد لم انتهاء مكرر لا يمكن مراقبة إلى ذاتي أنا استبدال.
- `AnonymousEntries.append()` لـ كل مرة تسجيل تسجيل قسم إعداد وحيد داخلي مفتاح، لذلك قيمة متبادل انتظار عودة ضبط أو أخرى قيمة ما زال ذاك هذا مستقل. ذلك مكرر إبقاء إدراج دخول ترتيب، و اعتماد نفس مثال generation نشط مرة تاريخ حد.
- `effect()` عبر `scopeOf(ctx)` توجيه خروج مفتاح، و يأخذ action تعليق إلى نفس عدد `ctx.effect()` فوق. هو فقط قبول واحد تزامن action، كما هذا action فقط إرجاع واحد تزامن undo؛action يلزم ما إرجاع ذلك undo، يلزم ما يجب في إبقاء أي مساهمة قبل رمي خطأ.helper لن مواصفة تحويل أكثر عرض عام Cordis `Effect` union.
- `effect()` في استدعاء `onChange` قبل استلام تجميع action undo، و أصل مثال إرجاع `ctx.effect()` disposer. إلغاء تدمير وقت أولا تشغيل action undo مجددا إشعار؛Cordis حفظ إثبات ذلك قوة انتظار صفة؛ فقط لديه في كامل طبقة `ScopeLayer.isEmpty()` إرجاع true بعد،helper عندئذ سوف حذف مخصص تابع طبقة.
- `options.notify` افتراضي لـ `true`. عودة ضبط ذاته سياسة ما زال أداة نهائي فاعلية قوة: أداة و نص التوجيه change عودة ضبط يمكن رمي خطأ و إطلاق تسجيل تسجيل تراجع؛`CommandRuntime.notifyChange()` سوف عزل مراقبة من فشل؛ أداة guard نقل دخول `notify: false`.

## سجل التسجيل ترحيل

`dsh-tools` تعريف واحد `ToolLayer`، منها يتضمن تسمية أداة و مجهول اسم قد تحرير ترجمة restriction و guard تسجيل تسجيل.`ToolRuntime` إبقاء ذلك خاص مجال محلل، من هو معالجة مرئي تعريف، حد قبل معروف اسم، يمكن حد عام اسم، مخصص تابع حجب حجب،restriction، و إبقاء `run_code` إدراج دخول.guard طلب قيمة سوف أولا نشط مرة تاريخ عام تسجيل تسجيل، مجددا نشط مرة تاريخ مخصص تابع تسجيل تسجيل: نحو غير فارغ generation إضافة جديدة تسجيل تسجيل يمكن في حالي توزيع في تشغيل، بينما guard جدول صاف فارغ بعد ذاتي أنا استبدال فإن من تحت مرة توزيع بدء تشغيل.

`dsh-system-prompt` تعريف واحد `PromptLayer`، منها يتضمن تسمية مقطع سقوط و متغير، و مجهول اسم أداة مزود. تجميع مسار في طلب قيمة قبل دمج مقطع سقوط، لذلك يتم حجب حجب مزود لن يتم استدعاء. كل مرة تجميع فقط شيء تحويل مرة أداة مزود عضو تجميع دمج. متغير مزود سوف أولا نشط مرة تاريخ عام جدول، مجددا نشط مرة تاريخ مخصص تابع جدول: نحو غير فارغ generation إضافة جديدة مزود يمكن في حالي تجميع في تشغيل، بينما متغير جدول صاف فارغ بعد ذاتي أنا استبدال فإن من تحت مرة تجميع بدء تشغيل.

`dsh-commands` تعريف واحد مفرد جدول طبقة، منها يتضمن `NamedEntries<RegisteredCommand>`. توليد فاعلية عرض استخدام `merge()`؛`CommandRuntime` فإن إبقاء مقابل تعريف مواصفة تحويل و تجميد ربط معالجة، دقيق إعادة اسم تشخيص، مرور مرور ترتيب ترتيب غير ممكن تغيير وصف رمز، مباشر تنفيذ،HMR(حار وحدة استبدال) تنظيف، و مقابل كل عدد `commands/change` مراقبة من قسم آخر عزل فشل سلوك.

سبعة عدد باب وجه كل يأخذ تحقق و تشخيص إبقاء في الذي تابع سجل التسجيل في، و متابعة إرجاع Cordis أصلي disposer. ترحيل حيث لا تغيير عام سجل التسجيل سلوك، أيضا لا تغيير نموذج مرئي أو شخص صنف مرئي إخراج، و بروتوكول، حفظ دائم أو إعداد طبقة وجه مرئي إخراج.

## تجهيز اختيار خطة

**إبقاء ذاك هذا مستقل تنفيذ.** هذا مثال لا لا بد إضافة جديدة مكتبة واجهة، لكن سبعة عدد باب وجه ما زال سوف تكرار دورة الحياة ترتيب،disposer هوية و scope عودة استلام.

**كل ورقة جدول واحد helper.** هذا قدرة نقص قليل واحد جزء نطاق جزء شفرة، لكن سوف إبقاء كثير ورقة حسب scope تخطيط قسم خريطة، بينما كما لا يمكن صحيح تأكيد عودة استلام بعض عدد scope تجمع دمج مساهمة.

**كل scope واحد سجل التسجيل نسخة.** فرعي سجل التسجيل حاجة عبر تفويض حمل نيل نيل عام إضافة مخصص تابع عرض، مقابل restriction إجراء خاص خاص نقص قاعدة معالجة، و عبر نسخة اكتشاف مراقبة من. هذا فقط سوف تحويل نقل تكرار مختلط درجة، بينما لن إزالة حذف تكرار مختلط درجة.

**تسجيل طريقة فوق صريح scope معامل.** قسم فتح مرئي صفة و تابع رئيسي إدخال يجعل لا مطابقة دورة الحياة يصبح يمكن جدول بلوغ حالة، بينما متروك تسرب scope فإن سوف ساكن صامت تغيير صار عام تسجيل تسجيل.

**قبول كامل Cordis `Effect` union.** سبعة عدد تسجيل تسجيل فتحة كل لا تعلق و مختلف خطوة setup، كثير نسخة undo أو مستقل تسوية حد. إذا لا يوجد قائم مستهلك حاجة، عام مواصفة تحويل فقط سوف تكرار تنفيذ Cordis دورة الحياة آلية.

**كشف `ScopedLayers.values()`،`ScopedLayers.keys()` أو عام وضع سطر يسمى كلمة.** هذه عملية سوف تحرير رمز مستهلك خاص لديه نشط مرة تاريخ أو شيء تحويل سياسة، و مرور ترشيح سياسة. مباشر مرة تاريخ بند جدول يمكن إبقاء صريح نشط دلالة،`merge()` تغطية مشترك تسمية حجب حجب عملية، بينما `ToolRuntime` متابعة حفظ لديه وظيفة أكثر وفير غني خاص محلل.

**يأخذ `values()` وضع في `ScopeLayer` فوق، أو توجيه خروج `EntryValues`.** واحد طبقة سوف تجمع دمج مختلف بنية جدول، بسبب بينما لا يوجد متسق قيمة نوع أو تكرار بديل سياسة.`EntryValues` فقط ملائم دمج في اثنان عدد جدول صنف بين مشترك تنفيذ دقيق عقدة؛ سوف ذلك عام فقط سوف توسيع كبير واجهة، لكن لا يستطيع لـ استدعاء جهة توفير متعمد معنى كامل طبقة قراءة طريقة.

**عبر mapped-type جدول وصف توليد طبقة.** ثلاثة جدول و مفرد جدول أداة جسم طبقة كل جدا قصير، سهل في فحص، و يمكن ذاتي من يحتفظ مجال helper. صنف توليد جهاز سوف زيادة ثاني نوع بنية صنع نموذج و توليد صيغة وقت التشغيل شكل حالة، استلام فائدة لكن جدا صغير.

## عاقبة

- دعم حمل أثر مجال سجل التسجيل كل منها عبر واحد تجمع دمج طبقة جدول بلوغ حالة، و إعادة استخدام نفسه بنية صنع، تابع رئيسي، تراجع، إشعار و عودة استلام تحرير ترتيب. كل سجل التسجيل ما زال كل منها حفظ لديه مجال خاص لديه تحقق، تشخيص، مرور ترشيح، طلب قيمة و مراقبة من سياسة.
- عام قراءة واجهة إبقاء ضيق ضيق: مباشر مرة تاريخ بند جدول يمكن إبقاء صريح نشط دلالة،`merge()` هو وحيد مشترك شيء تحويل حجب حجب عملية. مختلف بنية `ScopeLayer` لا أداة تجهيز كامل طبقة `values()` اتفاق.
- helper لحظة معنى إبقاء تزامن. لم قدوم تسجيل تسجيل إذا حاجة مختلف خطوة setup أو كثير نسخة قسم آخر يملك تابع رئيسي undo، يجب أولا واضح تابع رئيسي و settlement حد، مجددا توسيع عرض هذا بند اتفاق.
- action يجب في إبقاء مساهمة قبل رمي خطأ، أو من لـ ذاتي ذات إبقاء واحد قطع إرجاع undo؛helper لا يمكن إصلاح تجاوز خروج هذا بند اتفاق تغيير. توفير بند عملية هو أصل فرعي، ترحيل بعد سجل التسجيل سوف في إدراج دخول قبل تنفيذ ممكن فشل تحقق.
- مخصص تابع طبقة سوف واحد مباشر إبقاء قد قسم إعداد حالة، مباشر إلى ذلك تجمع دمج داخل كل جدول كل لـ فارغ. لذلك، إلغاء تدمير واحد باب وجه لن إسقاط نفس scope يملك أخرى مساهمة.
- أربعة عدد عام رمز رقم بنية صار واحد بند يمكن إعادة استخدام حزمة اتفاق. سوف `EntryValues` إبقاء لـ داخلي واجهة، و يأخذ مستهلك سياسة إبقاء في helper خارج، يمكن حد توافق صفة نطاق.
- ترحيل لا تغيير أي عام سجل التسجيل سلوك، أيضا لا تغيير نموذج، شخص صنف، بروتوكول، حفظ دائم، إعداد أو اعتماد رسم طبقة وجه أي إخراج.

## تحقق

- `dsh-scope` اختبار وحدة تغطية عام بنية صنع، مخصص تابع طبقة تأخير متأخر بنية صنع، غير إنشاء صيغة قراءة، تسمية دمج ترتيب و حجب حجب، تجمع دمج عودة استلام، عمل مصنع و action فشل تنظيف، إشعار ترتيب و تراجع،`notify: false`،effect وسم، أصلي disposer هوية، قوة انتظار تفكيك حذف، استدعاء جهة توفير إعادة اسم خطأ، نفسه مجهول اسم قيمة مستقل تسجيل تسجيل، نشط مكرر، و جدول صاف فارغ بعد generation انفصال مغادرة.
- أداة، توجيه النظام و أمر مخصص بند اختبار طقم عنصر تغطية restriction، إبقاء نقل بند معالجة، معروف اسم و يمكن حد اسم متسق صفة،guard إعادة دخول و ذاتي أنا استبدال، تحقق ترتيب، دقيق تشخيص،section أولا حجب حجب مجددا طلب قيمة، مزود لقطة عضو علاقة،variable إعادة دخول و ذاتي أنا استبدال، عزل فشل أمر مراقبة من، تجميد ربط كما مرور مرور ترتيب ترتيب عرض، مباشر تنفيذ و دورة الحياة إلغاء تدمير.
- أثر مجال نواة قلب بيانات نوع انتظار قيمة صفة فحص سوف `ScopeLayer` وثيقة و ذلك مصدر إعلان ربط. مستودع درجة وثيقة، وحدة رسم، بناء،hygiene، نسبة التغطية و بناء ناتج بوابة سوف تغطية حزمة أصل توجيه خروج و حزمة حد.
- قائم ACP(Agent Client Protocol) ،headless و TUI بلا مفتاح لقطة متابعة بصفة أداة schema و نص التوجيه تجميع ارتداد حد؛ شخص صنف أمر من TUI تغطية. تنفيذ لن تحديث أي مسبق مدة transcript(نص سجل).
