# Agent Note: قراءة بروتوكول خاص تحديد نموذج قائمة

Status: implemented
Archived: 2026-09-04

[English](2026-09-02-protocol-specific-model-listing-discovery.md) | العربية

## مشكلة

[مزود مسودة مسودة استفسار سؤال قرار](2026-08-04-draft-provider-endpoint-interrogation.ar.md) الأكثر أول فقط قراءة OpenAI توافق `data` عدد مجموعة. واحد بعض توافق شبكة صلة تعديل لـ عام نشر غني معلومة `models` كائن، بينما Anthropic عام نشر أداة لديه مختلف إقرار إثبات و URL قاعدة أصلي نموذج قائمة توجيه. يأخذ مهمة واحد حال حال نظر لـ لا تلقي دعم حمل، كل سوف إجبار استخدام مستخدم يد عمل نسخ نموذج id و سعة كمية، أي جعل طرف نقطة قد عام نشر هذه معلومة.

نحو واحد شبكة صلة إرسال OpenAI SDK `User-Agent` يمكن جعل ذلك إرجاع OpenAI ريح إطار عدد مجموعة. هذا سلوك لا يوجد وثيقة، تغيير طلب ملكية، و جعل عودة جواب أخذ قرار في عميل هوية بينما غير تلقي دعم حمل استجابة محلل.

## قرار

`dsh-llm-pi-ai` حسب الذي اختيار بروتوكول صيغة قراءة نموذج قائمة.`openai-completions` و `openai-responses` بـ bearer إقرار إثبات استخدام `GET {baseURL}/models`.`anthropic-messages` بـ `x-api-key` و `anthropic-version: 2023-06-01` استخدام `GET /v1/models?limit=1000`.Anthropic صفحة كبير صغير اعتماد وثيقة قاعدة تحديد الأكثر كبير قيمة؛ نموذج اكتشاف لن متابعة تتبع مع `has_more`، لذلك عام نشر تجاوز مرور 1,000 عدد نموذج طرف نقطة فقط سوف كشف رقم واحد صفحة.

Anthropic SDK مورد طريقة سوف ذاتي سطر إلحاق `/v1`، بينما شبكة صلة وثيقة سوف معا إصدار حمل و لا حمل هذا بعد لاحقة API أصل عنوان. لذلك قائمة URL سوف يأخذ نهاية ذيل لـ `/v1` Anthropic `baseURL` مسودة مسودة نظر لـ و لا حمل هذا بعد لاحقة عنوان نفسه API أصل عنوان، و كما فقط لديه هو سوف عودة واحد تحويل هذا واحد مقطع: نموذج طلب استلام إلى ما زال هو إعداد أصل مثال `baseURL`، و pi-ai معالجة تماما متسق. نشر مسار بادئة سوف إبقاء:`https://gateway.example/tenant/v1` و `https://gateway.example/tenant` كل في `/tenant/v1/models` قائمة.

محلل قبول `data` عدد مجموعة أو غني معلومة `models` كائن، و في عدد مجموعة وجود وقت أولوية استخدام هو. عدد مجموعة بند استخدام ذاته `id`؛ كائن بند استخدام خاصية مفتاح، لأن تضمين طقم `id` ممكن إشارة نحو مواصفة نموذج، بينما لا هو طلب الذي قبول توجيه آخر اسم. فقط لديه قيمة لـ كائن خريطة بند عندئذ نظر لـ نموذج، لذلك أصلي نوع دليل بيانات وصفية لن معنى خارج يصبح مرشح. فارغ خاصية مفتاح عندئذ سوف رجوع إلى تضمين طقم `id`.

محلل سوف يأخذ تلقي دعم حمل اسم و سعة كمية تجميع كتابة عودة واحد تحويل لـ `LlmDiscoveredModel`. ناقص عرض اسم سوف تغيير صار طلب id، جعل قبول عملية ملء دخول كامل يمكن تحرير سطر. طلب إبقاء Harness ملكية علامة رأس؛ شبكة صلة توافق صفة من استجابة تحليل توفير، بينما غير خطر ملء عميل هوية.

## اعتبار مرور بديل خطة

**تتبع مع Anthropic كل صفحة.** تنقل علامة مرة تاريخ يمكن إرجاع تجاوز مرور 1,000 عدد بند قائمة، لكن سوف إعطاء إعداد عملية زيادة كثير طلب فشل، إلغاء، تنقل علامة دفع دخول و مجموع كبير صغير معالجة. تنفيذ طلب Anthropic الأكثر كبير صفحة، و سجل باق بقية قطع قطع حد.

**معا عودة واحد تحويل دفع إدارة عنوان.** في نموذج توجيه قبل قطع إسقاط نفس مقطع `/v1` يمكن يجعل `/v1` عنوان حيث قدرة قائمة أيضا قدرة خدمة، لكن هذا سوف يأخذ طلب URL قاعدة من pi-ai نقل دخول هذه الحزمة، كما فقط لـ واحد نوع بروتوكول. نموذج طلب إبقاء pi-ai ذاته مقابل `baseURL` معالجة؛ قائمة طلب هو هذه الحزمة بنية صنع وحيد URL.

**رفض نهاية ذيل `/v1`.** في تحميل أو استكشاف قياس وقت رفض يمكن كل مبكر نقطة خروج خطأ، لكن شبكة صلة وثيقة إصدار حينئذ هو `/v1` كتابة قاعدة، وفق وثيقة لصق لصق عنوان مستخدم سوف يتم واحد هذا قدرة عمل قائمة رفض لـ باب خارج.

**لـ نموذج اكتشاف إرسال OpenAI SDK `User-Agent`.** هذا سوف يجعل واحد شبكة صلة إرجاع `data`، لكن سوف خطأ علامة Harness تدفق كمية، و اعتماد لم سجل عميل اسم فرع. قراءة اثنان نوع معروف استجابة صيغة يمكن إبقاء ملكية دقيق تأكيد.

**قبول `models` كائن كل خاصية.** أصلي نوع خاصية لا يستطيع إثبات ذلك مفتاح هو نموذج id، أيضا ممكن هو عدد كمية أو حالة انتظار دليل بيانات وصفية. يأخذ بند حد لـ سجل يمكن تجنب تجنب وهمي بنية نموذج مرشح.

## عاقبة

Models صفحة بلا حاجة تغيير طلب هوية، يكفي استفسار سؤال OpenAI توافق شبكة صلة و Anthropic Messages طرف نقطة. اكتشاف مرشح سوف في طرف نقطة توفير وقت يحمل توجيه id، اسم، سياق نافذة و الأكثر كبير إخراج token عدد، فقط لديه id قائمة أيضا سوف عبر id رجوع نيل نيل يمكن تحرير وسم.Anthropic عنوان بـ أصل عنوان أو `/v1` شكل صيغة كل قدرة قائمة؛ نموذج طلب استخدام pi-ai استلام إلى إعداد عنوان.

تلقي دعم حمل صيغة ما زال هو صريح توافق تجميع دمج، بينما لا هو مهمة معنى JSON دفع قطع. مرئي نموذج تجاوز مرور 1,000 عدد Anthropic حساب مستخدم حاجة يد عمل تسجيل دخول رقم واحد صفحة خارج بند، أصلي نوع `models` خاصية سوف يتم تجاهل اختصار.

## اختبار

محلي HTTP خادم اختبار تثبيت إقامة اثنان نوع تلقي دعم حمل استجابة صيغة، حقل عودة واحد تحويل، اسم رجوع، تجاهل اختصار شاذ شكل بند،Anthropic علامة رأس، الأكثر كبير صفحة استعلام، و Anthropic أصل عنوان اثنان نوع كتابة قاعدة.2026-09-02 من OpenRouter،models.dev و DeepSeek تسجيل نيل عودة تكرار، وصل نفس Anthropic List Models مشاركة اعتبار وثيقة إعطاء خروج عرض مثال عودة تكرار، تخزين وضع في `packages/llm/llm-pi-ai/tests/fixtures/model-listings/` تحت و مرور محلل إعادة تشغيل، لذلك تلقي دعم حمل حقل تجميع كتابة تثبيت في حقيقي طرف نقطة و عام مشاركة اعتبار وثيقة فوق، بينما لا هو يد كتابة مثال مثال فوق.
