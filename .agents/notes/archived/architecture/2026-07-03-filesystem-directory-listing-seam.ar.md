# Agent Note: لـ نظام الملفات seam إضافة مباشر دليل صف رفع قدرة

Status: implemented
Archived: 2026-07-26

[English](2026-07-03-filesystem-directory-listing-seam.md) | العربية

## مشكلة

`@deepseek-ai/dsh-fs` هو نظام الملفات وصول مزود seam، محلي خلفية و لم قدوم غير محلي خلفية مشترك نفس عدد `ctx.fs` عقد نحو. في هذا مرة تغيير قبل، هو قدرة تحليل مسار،stat هدف، قراءة نص، تدفق صيغة قراءة نص، كتابة نص و تحرير نص. هذا مقابل موجه إلى نموذج ملف أداة قد كاف كاف، لكن مقابل في حاجة قطعة رفع دليل بينما أيضا لا تفكير مباشر استيراد `node:fs` غير نموذج جانب مستهلك قدوم قول أيضا لا كاف.

مباشر ضغط قوة قدوم ذاتي skill(تقنية قدرة) تحميل: قراءة مفرد عدد `SKILL.md` قد يمكن مشي `ctx.get('fs')`، لكن اكتشاف أي بعض skill أصل دليل يتضمن `<name>/SKILL.md` أو `<name>.md` ما زال حاجة دليل قطعة رفع. إذا فقط في `dsh-skill` في إضافة دليل صف رفع، يلزم ما إبقاء مقابل Node مباشر اعتماد، يلزم ما في نظام الملفات مزود مكدس خارج إرسال واضح واحد مرة صفة محلي مساعد مساعدة دالة.

هذا قرار فقط إضافة مزود قدرة، لا تعلق و موجه إلى نموذج `ls`/`list` أداة أو skill اكتشاف آلية تغيير. ذلك بعض مستهلك حاجة مستقل UX، نص التوجيه و سياسة قرار.

## قرار

في `@deepseek-ai/dsh-fs` في إضافة `FileSystem.listDir(target, signal?)`.

`listDir` فقط صف رفع واحد طبقة دليل. هو بـ مستقر اسم ترتيب إرجاع مباشر فرعي بند، يتضمن التالي حقل:

- `name`: فرعي بند basename؛
- `type`:`file`،`directory` أو `other`؛
- `target`: قد تحليل فرعي بند `FsTarget`؛
- `version`: متاح وقت إرجاع خفيف كمية بيانات وصفية؛
- `size`: متاح وقت إرجاع معتاد قاعدة ملف كبير صغير.

هو من لا قراءة ملف محتوى. تمرير عودة مرة تاريخ،glob مطابقة، قسم صفحة، بحث، ملف استماع و موجه إلى نموذج تصيير متساو متعمد لا في نطاق داخل.

محلي خلفية عبر `readdir({ withFileTypes: true })`،`resolveLocalTarget` و بيانات وصفية `stat`/`realpath` استكشاف قياس قدوم تنفيذ. نتيجة ترتيب هو تحديد صفة (`name.localeCompare`) ، بـ إبقاء لم قدوم مستهلك نص التوجيه/قائمة إخراج مستقر، و رفع عال بادئة ذاكرة مؤقتة إعادة استخدام معدل.

ضرر تالف أو قد إزالة فقد فرعي بند يمكن يمثل لـ `type: 'other'`(لا حمل `version`/`size`) ؛ هو جمع لن في توقف كامل صف رفع. في صف رفع دليل أو تحليل/استكشاف قياس فرعي بند بيانات وصفية وقت لقاء إلى إذن أو خلفية I/O لذا عائق، فإن بـ بنية تحويل `FsError` رمز خطأ جعل كامل صف رفع فشل:

- `FS_NOT_FOUND`: هدف لا وجود؛
- `FS_NOT_DIRECTORY`: هدف وجود لكن لا هو دليل؛
- `FS_PERMISSION_DENIED`: إذن لا كاف؛
- `FS_IO_ERROR`: أخرى خلفية I/O لذا عائق؛
- `FS_ABORTED`: استدعاء يتم في توقف.

## سبق اعتبار بديل خطة

**في إضافة seam معا إضافة موجه إلى نموذج list أداة.** مرفوض. ذلك نص التوجيه،schema و تصيير عقد نحو و مزود أصل لغة متبادل متبادل مستقل.

**يجعل كل مستهلك ذاتي سطر قطعة رفع دليل.** مرفوض. هذا سوف سوف `dsh-skill` انتظار منتج حزمة ربط إلى Node/محلي نظام الملفات سلوك فوق، التفاف مرور سياسة/بعيد مسار/صندوق رملي خلفية.

**يجعل `listDir` دعم حمل تمرير عودة أو glob شكل صيغة.** مؤقت وقت مرفوض.skill أصل اكتشاف فقط حاجة مباشر فرعي بند، بينما بسيط مفرد مفرد طبقة صف رفع هو لم قدوم مستهلك يمكن أمان تركيب الأكثر صغير خلفية عقد نحو.

**قفز مرور بيانات وصفية تحليل فشل فرعي بند.** مرفوض.API تحمل وعد إرجاع قد تحليل فرعي بند target، لذلك تحليل فرعي بند وقت إذن/IO لذا عائق يخص عقد نحو فشل. ضرر تالف أو قد إزالة فقد فرعي بند هو مثال خارج، لأن هو جمع ما زال يمكن في لا صوت تسمية يملك واحد نشط وثب قد تحليل ملف قبل رفع تحت يتم يمثل.

## عاقبة

كل نظام الملفات خلفية الآن يجب كثير تنفيذ واحد مزود أصل لغة. هذا هو harness بعد لم إصدار وقت متعمد لـ لـ أساس أساس عمل، لكن أيضا معنى طعم حال لم قدوم صندوق رملي/بعيد مسار خلفية حاجة تعريف انتظار قيمة مباشر فرعي بند صف رفع سلوك.

هذا قدرة ما زال توقف إبقاء في مزود طبقة وجه. في مستهلك سقوط أرض قبل،ACP(Agent Client Protocol)/نموذج جلسة ما زال يحتاج استخدام `bash` انتظار قائم أداة قدوم صف رفع دليل. نقص قليل موجه إلى نموذج `listdir` أداة هو مسبق مدة سلوك، بينما غير وصل خط خطأ.
