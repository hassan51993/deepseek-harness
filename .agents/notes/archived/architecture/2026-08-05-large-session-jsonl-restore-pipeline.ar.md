# Agent Note: كبير نوع جلسة JSONL استعادة خط الإنتاج

Status: implemented
Archived: 2026-09-04

[English](2026-08-05-large-session-jsonl-restore-pipeline.md) | العربية

## مشكلة

استعادة قد تخزين جلسة سوف تنشيط هذا جلسة، و في agent(ذكي جسم) تشغيل قبل شيء تحويل كامل كما مرجعي حدث سجل. معالجة كبير نوع JSONL ناتج وقت، هذا عدد مرة صفة عملية سوف إنتاج بضعة بند لا لا بد يلزم فتح إلغاء: كل مستقل Zstandard لقطة كل سوف إنشاء و إغلاق واحد حل رمز سياق؛ حل رمز بعد واضح نص سوف تجميع مجموع صار كامل نسخة سجل مؤقت اندفاع منطقة و نص، مجددا إجراء تكرار مسح؛ للتو تحليل خروج حدث أيضا سوف دخول موجه إلى استعارة استخدام قيمة أو حلقة مرجع قيمة تصميم عام لقطة و عميق درجة تجميد ربط مسار.

واحد نسخة بديل جدول صفة صفة قدرة تشريح تحليل يتضمن 61.8 MiB Zstandard بيانات،97.1 MiB واضح نص و 1,307,073 عدد حدث. استعادة مسار يجب خفض منخفض CPU و داخل تخزين فتح إلغاء، معا إبقاء تحقق و تحقق، قد إيداع منطقة مجال ضرر تالف فحص قياس، تمزيق شق ذيل جزء استعادة، تسلسل و `surface` تحقق، و جلسة سجل غير ممكن تغيير صفة.

## قرار

استعادة مرور مسار هو واحد بند من حفظ دائم ناتج دخول `Session.fromRestore` كل حق تحويل نقل خط الإنتاج. ضغط ناتج ما زال بصفة مصدر مؤقت اندفاع منطقة إقامة إبقاء، لكن حل رمز و مسح مرحلة مقطع سوف زيادة كمية إزالة استهلاك فوق واحد مرحلة مقطع إخراج، لن إبقاء كامل نسخة سجل واضح نص أو تحليل فرعي هذا؛ نهائي حدث عدد مجموعة هو وحيد كامل قد حل رمز يمثل.

### لقطة حل رمز

Zstandard بنية مسح جهاز سوف في حل رمز قبل تعرف آخر كامل لقطة نطاق. نظام مفرد وحيد حل رمز مخصص استخدام أول لقطة و سوف ذلك تحليل لـ جلسة رأس جزء، لاحق واضح نص لقطة فإن حسب ترتيب إنتاج خروج و إرسال دخول JSONL مسح جهاز.

`ZstdFrameDecoder` لـ يمكن متبادل تبديل تزامن تنفيذ توفير موحد واحد دورة الحياة. أول اختيار تنفيذ سوف استكشاف قياس تلقي دعم حمل Node 22،24 و 26 تدفق بنية، في كل كامل لقطة بين إعادة استخدام واحد خاص أصلي حل رمز سياق و مؤقت مؤقت اندفاع منطقة، الأكثر بعد فقط إغلاق مرة. إذا خاص بنية غير ممكن استخدام، عمل مصنع سوف اختيار استخدام عام مشترك `zstdDecompressSync` تنفيذ، و إبقاء نفسه مكرر و تحقق و خطأ اتفاق. مكرر إنتاج خروج مؤقت عرض سوف في دخول تحت مرة تكرار بديل قبل يتم إزالة استهلاك.

تراكم حساب لقطة معالجة وقت نحو بلوغ 500 ms بعد، مختلف خطوة قراءة جهاز سوف في تحت واحد لقطة حد يجعل خروج حدث حلقة، و في متابعة قبل مراقبة إلغاء إشارة. مفرد عدد لقطة ما زال هو غير ممكن قسم قطع تزامن عملية. كامل لقطة يجب عبر لقطة انتهاء و تحقق و تحقق؛ فقط لديه بنية فوق لا كامل نهائي لقطة عندئذ استخدام قائم بادئة حل رمز جهاز إجراء استعادة.

### زيادة كمية JSONL مسح

`SessionLogScanner` استخدام `Buffer.indexOf(0x0A)` في أصلي مؤقت اندفاع منطقة في فحص بحث تبديل سطر، فقط يأخذ كامل سجل تحويل لـ UTF-8 و تسليم إعطاء `JSON.parse`. مسح جهاز سوف عبر حل رمز كتابة إبقاء لا كامل سجل؛ من في خاص حل رمز جهاز ممكن إعادة استخدام إخراج مؤقت اندفاع منطقة، هو فقط نسخ هذا عدد قطعة مقطع. مسح مرور مسار لن بنية صنع كامل نسخة واضح نص مؤقت اندفاع منطقة أو نص، أيضا لن بنية صنع سطر عدد مجموعة أو ثاني نسخة تحليل سجل عدد مجموعة.

مسح جهاز في لقاء إلى رقم واحد بند لا يمكن تحليل سجل أو تسلسل نقص فتحة بعد إيقاف إبقاء حدث، لكن سوف متابعة فحص لاحق كامل سجل. لاحق ظهور `turn/end`، شرح مشكلة يقع في قد إيداع منطقة مجال، نظام سوف رفض هذا سجل. معالجة تمام كل كامل لقطة بعد، إذا ما زال وجود لم قرار تحليل خطأ، تسلسل خطأ أو جزء سجل،Zstandard قراءة جهاز نفس مثال سوف رفض سجل؛ فقط لديه بنية فوق تمزيق شق نهائي لقطة عندئذ قدرة توفير يمكن استعادة بعد لاحقة. هذا تمزيق شق لقطة إنتاج خروج كامل سجل سوف مرور مرور نفس مسح جهاز، و إبقاء قائم إصلاح انحراف نقل كمية و استعادة حدث دلالة.

### استعادة دقيق دخول

حفظ دائم يأخذ للتو شيء تحويل حالي JSON قيمة تحويل نقل إعطاء `Session.fromRestore`. هذه قيمة هو قد قسم مغادرة كما بلا حلقة tree؛ تاريخ packed row و متبادل مجاور migration قد توليد جديد قسم إعداد v2 settlement.restore-only path استخدام مرة `for...in` و `switch` تحقق ثابت event envelope، حسب event discriminant تنفيذ حالي يمثل فحص، و عبر صريح `pending` array تكرار بديل تجميد ربط owned object graph، لا استخدام cycle-tracking set.`surface` تحقق سجل مرة transition plan، و في نفس عدد candidate event دخول log وقت إيداع هذا plan.

عادي إنشاء و fork مسار استخدام استعارة استخدام `seed` ما زال سوف إنشاء JSON لقطة، و استخدام دعم حمل حلقة فحص قياس عام عميق درجة تجميد ربط. لذلك، هذا بند خاص تحويل فقط تغيير حمل دائم استعادة، لن وضع عرض استدعاء جهة كل قيمة دقيق دخول اشتراط.

## اعتبار مرور بديل خطة

- **كل لقطة تنفيذ مرة مختلف خطوة أصلي عملية**: غير مقبول، لأن مقابل في يتضمن كبير كمية صغير نوع حفظ دائم دفعة مرة سجل، ضبط درجة و عودة ضبط فتح إلغاء احتلال حسب رئيسي يلزم جزء. تنسيق عمل صيغة تزامن حل رمز فقط في دورة مدة صفة يجعل خروج حد دعم دفع هذا صنف فتح إلغاء.
- **تزامن معالجة كامل سجل كما لا يجعل خروج حدث حلقة**: غير مقبول، لأن كامل استعادة خلال كل لا يمكن استجابة إلغاء أو دفع دخول حدث حلقة. لقطة حد يجعل خروج آلية بلا حاجة تفكيك قسم تحرير حل رمز عملية، حينئذ قدرة إبقاء محدود مراقبة نقطة.
- **مسح قبل تجميع وصل الكل واضح نص**: غير مقبول، لأن هذا خطة سوف معا إبقاء ضغط إدخال، كامل واضح نص، كامل نسخة سجل UTF-8 نص، سطر بيانات وصفية و تحليل سجل، و سوف إعادة مسح تمزيق شق لقطة بادئة.
- **تنفيذ تدفق صيغة JSON محلل**: غير مقبول، لأن JSONL قد توفير سجل حد؛ استخدام أصلي تبديل سطر بحث و `JSON.parse` حينئذ قدرة إزالة كبير نوع في بين بنية، بلا حاجة ذاتي سطر صيانة آخر طقم محلل أو تغيير JSON دلالة.
- **تجميد ربط استعادة حدث وقت مشترك واحد `WeakSet`**: غير مقبول، لأن JSON شيء تحويل غير ممكن قدرة إنتاج حلقة مرجع، بينما هذا تجميع دمج سوف مقابل كل كائن زيادة مرة فحص بحث، و في مرة تاريخ خلال إبقاء كامل كائن رسم.
- **قفز مرور استعادة قيمة تحقق أو تجميد ربط**: غير مقبول، لأن حمل دائم تخزين يخص وقت التشغيل حد، بينما Session قراءة طريقة تحمل وعد قد قبول تاريخ غير ممكن تغيير. أفضل تحويل مسار فائدة استخدام أكثر قوي كل حق واقع خاص تحويل هذه عملية، بينما لا هو سوف ذلك إزالة.

## عاقبة

في بديل جدول صفة صفة قدرة تشريح تحليل في، زيادة كمية مسح سوف JSONL مسح وقت من نحو 598 ms خفض حتى 397 ms، ذروة قيمة RSS من نحو 1,494 MiB خفض حتى 1,060 MiB. استعادة دقيق دخول سوف `Session.fromRestore` من 604–608 ms خفض حتى نحو 263 ms، منها `assertSessionEventEnvelope` من نحو 77 ms خفض حتى 13 ms. هذه بيانات لأجل وصف أفضل تحويل إدخال، لا بنية صار وقت التشغيل حد أعلى.

سريع سرعة حل رمز جهاز اعتماد وقت التشغيل استكشاف قياس Node داخلي واجهة، لكن واجهة لا توافق وقت سوف تعديل استخدام عام مشترك تنفيذ، لن تغيير صحيح تأكيد صفة. نظام سوف في تنسيق عمل صيغة لقطة حد يجعل خروج نقطة مراقبة إلغاء إشارة؛ قطع توقف وقت و لا هو مفرد عدد لقطة داخلي صارم إطار تعليق ساعة وقت حد أعلى. كامل حدث عدد مجموعة ما زال سوف إقامة إبقاء داخل تخزين، لأن هو هو نشط وثب جلسة مرجعي سجل؛ هذا خط الإنتاج إزالة هو تكرار يمثل، و لم مقابل هذا نسخة حالة فعل قسم صفحة.

اختبار سوف قوي صنع تنفيذ اثنان نوع حل رمز جهاز تنفيذ، مقارنة مقابل لقطة ترتيب و ضرر تالف معالجة سلوك، تغطية تنسيق عمل صيغة إلغاء و تمزيق شق ذيل جزء استعادة، و إبقاء قائم جلسة معلومة غلاف،`surface` و غير ممكن تغيير صفة اتفاق.
