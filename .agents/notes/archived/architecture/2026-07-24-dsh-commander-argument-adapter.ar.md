# Agent Note: عبر مفرد عدد Commander مهايئ تحليل `dsh` argv

Status: implemented
Archived: 2026-07-26

[English](2026-07-24-dsh-commander-argument-adapter.md) | العربية

## مشكلة

`dsh` CLI(أمر سطر واجهة) مدخل (`apps/cli`) بـ ثلاثة نوع يد كتابة طريقة تحليل argv، هذه طريقة لا يمكن تركيب، أيضا لا توفير `--help`/`--version`.`bin.ts` عبر أصلي فحص إجراء توزيع: أولا حكم قطع `argv[0] === 'web'`، مجددا حكم قطع `argv.includes('-p') || argv.includes('--prompt')`، لا فإن مشي TUI. هذا نوع طريقة مقابل موضع لا حساس شعور: موضع خطأ prompt علامة سجل أو إعداد مسار ممكن يأخذ نمط توجيه خطأ، بينما `argv.includes('-p')` لا يمكن منطقة قسم حق صحيح علامة سجل و أحيانا لكن ظهور token.`headless.ts` و `web.ts` كل منها تشغيل ذاتي ذات `node:util` `parseArgs`، و داخل ربط تحقق host/port، بينما `dsh-app-boot` يحمل `parseResumeArg`——واحد نحو 30 سطر تحديد صنع مسح جهاز، لـ `--resume` إعادة تنفيذ علامة سجل،`=` شكل صيغة، أخذ قيمة و تكرار معالجة. استخدام قاعدة شرح فقط لديه واحد سطر صلب تحرير رمز `usage: dsh -p "task"`؛ حيث لا يوجد إصدار علامة سجل، أيضا لا يوجد تصيير خروج مساعدة مساعدة معلومة.

## قرار

argv فقط في `apps/cli/src/args.ts` في تحليل مرة، و استخدام Commander مهايئ (SDK bin `create-sdk`،`dsh-scripts` قد موحد واحد اعتماد نفس محلل).`parseDshArgs(argv, version)` إرجاع فقط يتضمن ثلاثة نوع فعلي نمط حكم آخر صيغة `DshInvocation` ربط دمج نوع:`{ mode: 'tui', config?, resume? }`،`{ mode: 'headless', prompt }` أو `{ mode: 'web', host?, port?, dev }`. هو**لن**سوف مساعدة مساعدة، إصدار معلومة أو خطأ بناء نموذج لـ بيانات: هذه حال حال من Commander معالجة، في إطلاق موضع ضرب طبع استخدام قاعدة أو تشخيص معلومة و خروج.`exitOverride()` سوف سوف كل نوع حال حال تحويل لـ رمي خروج `CommanderError`، و يحمل مسبق مدة خروج رمز (مساعدة مساعدة أو إصدار لـ 0، تحليل خطأ أو مجال خطأ لـ 1) ؛ وحيد واحد موضع `try/catch` يقع في `parseDshArgs` في، التقاط خطأ بعد استدعاء `process.exit`.

`bin.ts` فقط استدعاء مهايئ مرة، و مقابل `mode` فعل فرع تبديل (غلاف إغلاق ربط دمج نوع، افتراضي فرع لـ `satisfies never`) ، فقط حركة حالة استيراد الذي اختيار نمط مقابل وحدة؛ فقط لديه دمج قاعدة غير مساعدة مساعدة طلب عندئذ سوف دخول هذا مقطع فرع منطق، لذلك منها لا يوجد مساعدة مساعدة، إصدار أو خطأ فرع. كل نمط وحدة فقط إزالة استهلاك قد تحليل جيد قيمة:`runTui(config, resume)`،`runHeadless(task)`،`runWeb(host, port, dev, workspaceRoot)`، كل لن مجددا مرة قراءة argv. كامل CLI من**مفرد عدد Commander برنامج**تنفيذ: افتراضي واجهة (لا استخدام فرعي أمر وقت) فقط يتضمن خيار علامة سجل——`--config <path>`،`-p/--prompt <task>`،`--resume <id>`——بينما `web` هو عبر `program.command('web')` تعريف حق صحيح فرعي أمر. افتراضي واجهة لا قبول موضع معامل، لذلك `web` يمكن يصبح حق صحيح فرعي أمر كما لن حدوث موضع معامل اندفاع مفاجئ،`dsh --help` أيضا سوف أصلي صف خروج `web`، بلا حاجة يد عمل تجميع وصل أمر نص. افتراضي أمر و `web` فرعي أمر معالجة دالة سوف ضبط تحليل نيل إلى نمط، مع بعد مقابل Commander لا يمكن جدول بلوغ مجال تحقق استدعاء `command.error(...)` قيام أي إنهاء (ضرب طبع معلومة و بـ خروج رمز 1 خروج):`--prompt` اختيار headless نمط؛ إذا مهمة لـ فارغ، أو استدعاء في أيضا يتضمن `--config` أو `--resume`، هو سوف رفض استدعاء، بينما لن ساكن صامت إسقاط TUI إدخال؛ فارغ `--resume=` id سوف صريح فشل (agent-loop يأخذ `''` نظر لـ لا استعادة).Commander سوف سوف `web` token قبل بعد افتراضي واجهة خيار كل تحليل دخول `program.opts()`؛ من في `web` لا و افتراضي واجهة مشترك استخدام أي خيار،`web` فرعي أمر معالجة دالة سوف رفض خطأ دخول `--config`/`-p`/`--resume`(`dsh web -p x`،`dsh --config c.yml web`) ، بينما لا هو ساكن صامت بدء خدمة و إسقاط هذه خيار.`dsh web` `--host`/`--port` هو لم مرور تحقق، مباشر نفاذ نقل تغطية قيمة: مهايئ حيث لا ضبط قيمة افتراضية، أيضا لا تنفيذ تحقق، فقط استخدام `Number` سوف طرف فتحة نص تحويل لـ عدد حرف (schema اشتراط هذا قيمة لـ عدد حرف).`dsh-host-webserver` schemastery `Config`(`host` هو `127.0.0.1`/`0.0.0.0` حرف وجه كمية ربط دمج نوع،`port` هو لا كبير في 65535 ذاتي لكن عدد) هو قيمة افتراضية و صالح صفة وحيد حق مصدر: لم توفير علامة سجل وقت، مع منتج توفير `apps/cli/cordis.yml` في `webserver` بند إعداد إبقاء أصل قيمة؛`AppCLIEntry` سوف صريح علامة سجل قيمة مباشر كتابة هذا بند إعداد، لذلك بلا فاعلية host/port سوف في بدء وقت إطلاق schema تحقق و صريح فشل، بينما لا هو في معامل تحليل مرحلة مقطع فشل.`--dev` سوف تركيب عميل HMR(حار وحدة استبدال) قيادة، و تفعيل بناء ناتج مراقبة نظر،`--workspace-root <path>` فإن هو مباشر نفاذ نقل إعطاء `AppCLIEntry` خيار (حسب اسم إنشاء workspace وقت استخدام أب دليل). تكرار توفير `--resume`، أو لاحق علامة سجل يتم التقاط لـ `--resume` أو `--prompt` قيمة، كل هو Commander معيار سلوك (الأكثر بعد مرة أخذ قيمة توليد فاعلية/سوف تحت واحد token بصفة قيمة) ، هذا مهايئ لا عمل جاف مسبق؛ بلا فاعلية id سوف في تحت تنقل لا يمكن تحميل جلسة وقت صريح فشل.`--version` قراءة هذا تطبيق `package.json`.

`dsh` لا قبول موضع معامل.`--config <path>` إشارة تحديد واحد نسخة بديل Cordis إعداد شجرة، نظام بدء هذا إعداد شجرة بينما لا هو مع منتج توفير افتراضي إعداد شجرة؛ هذا علامة سجل فقط لأجل يجعل عرض عرض و اختبار استدعاء نقطة (`demo:cordis`،`demo:code-mode`، بلا مفتاح PTY خطر دخان اختبار) عبر مع منتج توفير bin بدء واحد نسخة عرض مثال شجرة. مباشر تشغيل `dsh` سوف بدء مع منتج توفير إعداد شجرة، و تراكم إضافة `~/.dsh/config.yaml` عدد شخص تغطية؛ فعلي مستخدم من لا نقل دخول `--config`.

CLI تحليل تماما يقع في `apps/cli` في.`dsh-app-boot` توفير بدء، بيئة متغير، إعداد و عدد شخص تغطية مساعد مساعدة دالة، لا يتضمن argv مسح جهاز.

## عبر بدء سياق استعادة جلسة

`dsh --resume <id>` هو استعادة حفظ دائم جلسة وحيد طريقة، بلا حاجة بيئة متغير.`runTui` عبر `boot` `prepare(ctx)` خطاف، في بدء سياق في توفير قد تحليل id:`ctx.provide(RESUME_SESSION_ID_KEY, id)`(`dsh-app-boot` واحد بند توجيه خروج، قيمة لـ `'resumeSessionId'`) ؛ مع منتج توفير tui-agent/cordis إعداد سوف هذا قيمة بصفة عار معرف رمز قراءة:`resumeSessionId: !!js "typeof resumeSessionId === 'string' ? resumeSessionId : undefined"`. هذا عدد جدول بلوغ صيغة حاجة إضافة جذب رقم، لا فإن YAML سوف يأخذ `?` و `:` تحليل لـ خريطة؛`typeof` حراسة حماية جعل من لم توفير هذا مجرى موضع بدء جهاز أيضا قدرة صحيح معتاد تشغيل.`/resume` أصل أرض تسليم وصل (`process.execve`) أصل حسب قد تحليل قيمة سوف إعادة تنفيذ وقت argv بنية صنع صار `dsh --resume=<id> [--config <path>]`.

## وحيد طرفية مدخل:`dsh`

`dsh` هو وحيد طرفية مدخل؛`dsh-tui-demo` حزمة (package) توفير TUI تطبيق تركيب إضافة، مع منتج توفير إعداد سوف تركيب هذا إضافة، بينما هذا حزمة لا توفير ذاتي ذات bin.`demo:cordis`،`demo:code-mode` و tui-agent و cordis-agent بلا مفتاح PTY خطر دخان اختبار كل عبر `apps/cli/src/bin.ts` بدء، و نقل دخول `--config <path>`.`dsh` TTY حراسة حماية سوف في بدء قبل رفض معيار إدخال إخراج وصل دخول إدارة طريق استدعاء، و تلميح تلقائي تحويل مشهد استخدام `dsh -p`؛`apps/cli/tests/built-bin.e2e.ts` قفل تحديد هذا واحد سلوك: هذا اختبار سوف معيار إدخال إخراج وصل دخول إدارة طريق، و عبر عادي Node تشغيل بناء بعد `lib/bin.js`(e2e Vitest include يتضمن `apps/cli/tests`).`cli-demo`،`acp-demo` و `jsonrpc-demo` إبقاء كل منها bin، لأن هو جمع قسم آخر توفير `dsh` الذي لا يوجد مستقل واجهة (headless،ACP(Agent Client Protocol) ،JSON-RPC).

## حزمة توسيع اندفاع

معامل تحليل إبقاء في `apps/cli`(تجميع طبقة) داخل، بينما لا هو `packages/*` مكتبة في: هو هو هذا واحد تطبيق ذاته توجيه، بينما غير يمكن إعادة استخدام seam.`dsh-app-boot` استلام تقليص لـ صاف خالص boot لاصق ماء شفرة، لم يعد تحمل تحمل CLI تحليل مسؤولية.`commander@^15` يتم إضافة دخول `apps/cli/package.json`، و SDK bin قفل تحديد إصدار متسق.

## اعتبار مرور بديل خطة

**إبقاء `node:util` `parseArgs`، فقط موحد واحد توزيع.** قد مرفوض:`parseArgs` لا يوجد فرعي أمر نموذج، لا يوجد تصيير خروج مساعدة مساعدة، أيضا لا يوجد إصدار علامة سجل، لذلك `web` توجيه و `--help`/`--version` ما زال سوف إبقاء يد كتابة. هذا مستودع أخرى CLI قد اختيار Commander؛ مفرد وحيد لـ `dsh` جذب دخول ثاني طقم محلل طريقة، صحيح هو هذا مرة تغيير يلزم إزالة حذف تفتيت قطعة تحويل.

**إبقاء `parseResumeArg` بصفة مشترك مساعد مساعدة دالة، و نحو هو تغذية دخول Commander ناقص بقية معامل.** قد مرفوض: كامل عنصر أمر نواة قلب حينئذ هو يلزم تراجع دور هذا عدد تحديد صنع مسح جهاز.Commander أصلي تحليل `--resume`(فارغ إطار و `=` شكل صيغة، نقص قيمة، موضع غير متصل صفة) ؛ لـ هذا واحد علامة سجل إبقاء واحد بند مستو سطر يد كتابة مسار، فقط سوف إبقاء هذا مرة تغيير يلزم نهاية ربط تكرار.

**استخدام عار `dsh <config>` موضع معامل إشارة تحديد بديل إعداد شجرة.** قد مرفوض: أصل درجة موضع معامل و حق صحيح `web` فرعي أمر لا يمكن في نفس عدد Commander برنامج في مشترك تخزين (فرعي أمر سوف احتلال استخدام رقم واحد موضع معامل). موضع معامل سوف إجبار جعل نظام يأخذ يقع في أول موضع `web` بصفة إبقاء token توزيع إعطاء آخر عدد محلل، و يد عمل صيانة واحد سطر `web` نص، توفير `--help` عرض. فقط لديه عرض عرض و اختبار استدعاء نقطة حاجة إشارة تحديد بديل إعداد شجرة، لذلك `--config` علامة سجل حيث قدرة ممتلئ كاف هذه استدعاء نقطة، أيضا قدرة يجعل افتراضي واجهة لا يتضمن موضع معامل؛ هذا مثال،`web` حينئذ قدرة في مفرد عدد برنامج في يصبح عادي فرعي أمر، و من أصلي `--help` عرض.

**يأخذ معامل تحليل فعل صار `packages/*` seam.** قد مرفوض:`dsh` خارج لا يوجد أي مستهلك استخدام هو، بينما قدرة seam لا ينبغي يتم رفع قبل تفكيك قسم. هذا عدد Commander مهايئ هو `apps/cli` ذاته أمر خدمة.

**إبقاء `RESUME_SESSION_ID` بصفة استعادة عبر طريق**: غير مقبول.`--resume` قد يتم تحليل صار bin حالي يحتفظ قيمة؛ إذا مجددا عبر بيئة متغير نقل تمرير و من إعداد إعادة قراءة، فقط سوف جذب دخول بلا فائدة بين وصل طبقة، أيضا سوف جعل عرض عرض bin إبقاء ثاني بند فقط اعتماد بيئة متغير استعادة مسار. في بدء سياق في توفير id، و `boot` `prepare` خطاف لـ `tuiResumeHost` توفير قيمة الذي اعتماد هو نفس عبر طريق.

**إبقاء `dsh-tui-demo` bin**: غير مقبول. هو و `dsh --config <path>` وظيفة تماما تكرار؛ إبقاء هو أيضا سوف إجبار جعل عرض عرض مخصص استخدام `RESUME_SESSION_ID` رجوع مسار متابعة وجود. إعداد فعلي تركيب هو هذا حزمة إضافة؛ زائد بقية فقط لديه بصفة طرفية مدخل bin، بينما `dsh` هو وحيد طرفية مدخل.

## اختبار

`apps/cli/tests/args.spec.ts`(إضافة جديدة؛`apps/*/tests` إضافة دخول vitest include،`apps/cli/tests` إضافة دخول `tsconfig.host.json`) تغطية مهايئ صلة مفتاح سلوك: أصل حسب معامل شكل إجراء نمط توجيه (يشمل `web --dev` و host/port نفاذ نقل) ، و عبر `process.exit` spy التقاط مهايئ صريح تقرير خطأ فحص (استعادة id أو نص التوجيه لـ فارغ،`--prompt` و إعداد أو `--resume` خلط استخدام، لم معرفة خيار، كثير بقية موضع معامل) و `--help`/`--version` خروج رمز.host/port صالح صفة من webserver schema مسؤول، و من web خطر دخان اختبار في بدء وقت تحقق، لا يخص مهايئ اختبار تغطية نطاق.`examples/tui-agent/tests/tui-keyless-smoke.e2e.ts` في اثنان مجموعة PTY خطر دخان اختبار الآن كل قيادة حقيقي `apps/cli/src/bin.ts`:`tui-agent` مجموعة عبر `--config` بدء عرض مثال شجرة،`dsh CLI` مجموعة تغطية افتراضي بدء، عدد شخص تغطية، بلا فاعلية إعداد، إعداد مقابل `--resume` استقبال، عبر `process.execve` أصل أرض استعادة تسليم وصل، و يتضمن شفرة المصدر مسار توجيه النظام.`examples/cordis-agent/tests/keyless-smoke.e2e.ts` نفس مثال عبر `dsh` بدء.`packages/ui/app-boot/tests/app-boot.spec.ts` إزالة ذلك `parseResumeArg` و `replaceResumeArg` اختبار كتلة؛TUI اختبار وحدة و لقطة fixture(اختبار قبل وضع بيانات) استخدام `dsh --resume {session}` استعادة أمر.

## أثر

`dsh` سوف تصيير `--help`/`--version`، و بـ متسق طريقة صريح تقرير إبلاغ تحليل خطأ؛ نمط توجيه لا اعتماد علامة سجل موضع.argv تحليل تجميع في في واحد موضع، و و SDK bin مشترك استخدام واحد طقم محلل طريقة، بديل قيمة هو `apps/cli` اعتماد `commander`، كما Commander تحليل دلالة (خطأ نص و `exitOverride` عقد نحو) يصبح CLI مدخل واحد جزء.`dsh-app-boot` لا توفير أي CLI تحليل واجهة؛ حاجة `--resume` صيغة تحليل مستهلك عبر تركيب Commander قدوم تنفيذ. جلسة استعادة عبر بدء سياق إتمام، بينما لا استخدام بيئة متغير؛`dsh` هو وحيد طرفية مدخل؛`dsh-tui-demo` حزمة هو من إعداد تركيب إضافة تركيب حزمة.
