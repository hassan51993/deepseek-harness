# Agent Note: جلسة سجل قراءة صريح جدول بلوغ شيء تحويل صار هذا

Status: implemented
Archived: 2026-09-04

[English](2026-08-21-session-log-read-intent.md) | العربية

## مشكلة

عام `Session.events` وصول جهاز سوف في كل مرة append بعد أول مرة قراءة في إخفاء مرة و عدد مجموعة كبير صغير صار صحيح مقارنة نسخ. كامل تجميد ربط لقطة يمكن ذاكرة مؤقتة، لكن تدفق صيغة إخراج كل جديد حدث كل سوف جعل ذاكرة مؤقتة بطلان، لذلك فقط حاجة سجل طويل درجة أو مفرد عدد حدث استدعاء جهة أيضا ممكن عكس تكرار نسخ عدد مئة ألف عدد مرجع. قيمة راجعة غير ممكن تغيير و لا اشتراط كل نوع قراءة معنى رسم كل تحمل تحمل هذا صار هذا؛ حدث غير ممكن تغيير صفة من[مصدر طرف يملك جلسة غير ممكن تغيير صفة قرار](2026-06-11-dev-invariants-over-deep-readonly.ar.md) آخر سطر مسؤول.

## قرار

`Session` توفير ثلاثة نوع صار هذا مختلف قراءة عملية.`seq` بـ معتاد عدد وقت قراءة حالي طويل درجة،`eventAt(seq)` بـ معتاد عدد وقت قراءة واحد حدث،`snapshotEvents(fromSeq?, toSeqExclusive?)` فإن لـ حاجة عدد مجموعة عملية أو مستقر شيء تحويل منطقة بين مستهلك صريح شيء تحويل تجميد ربط عدد مجموعة. تسلسل معامل هو غير سالب سجل موضع، لا هو من نهاية ذيل حساب حساب `Array.prototype.slice` انحراف نقل كمية. الذي اختيار agent preset هذا صنف تكرار قراءة مجال حالة قدوم ذاتي جلسة إسقاط، بينما لا هو عكس تكرار مسح نشط وثب سجل.

حالي كامل لقطة سوف ذاكرة مؤقتة إلى تحت مرة append، جعل تكرار قراءة كامل سجل مستهلك يمكن مشترك نفس عدد غير ممكن تغيير عدد مجموعة. منطقة بين لقطة فقط نسخ الذي اختيار مرجع كما لا ذاكرة مؤقتة: ذاكرة مؤقتة مهمة معنى منطقة بين سوف إبقاء عدد كمية بلا حد عدد مجموعة، و اشتراط مقدار خارج تصفية استبعاد سياسة. أولا قبل إرجاع لقطة إبقاء مستقر، لأن قد قبول حدث غير ممكن تغيير، كما لقطة عدد مجموعة لن في append بعد زيادة طويل.

عند الذي يحتاج قيمة يمكن زيادة كمية صيانة وقت، تكرار مجال حالة قراءة استخدام[جلسة إسقاط](2026-08-19-session-projection-state-and-client-views.ar.md). حفظ دائم، توجيه خروج، إعادة تشغيل، و إخراج ذاته حينئذ هو حدث تسلسل مستهلك ما زال ملائم دمج استخدام أصلي سجل لقطة. هذا API جعل شيء تحويل صار هذا صريح مرئي، لكن لن في نفس بند تعديل في إزالة حذف كل كامل سجل طي.

## سبق اعتبار بديل خطة

**إبقاء ذاكرة مؤقتة `events` عدد مجموعة وصول جهاز.** هذا إبقاء عادي عدد مجموعة لغة قاعدة، لكن سوف يجعل علامة كمية قراءة و بحث جذب قراءة نظر يشبه نزيه قيمة، بينما مرة append حينئذ ممكن جعل منها أي مرة قراءة تغيير صار كامل سجل نسخ.

**إرجاع توفير صنف عدد مجموعة مرة تاريخ عملية ذاتي تعريف غير ممكن تغيير cut.** التقاط طويل درجة يمكن في حمل متابعة زيادة طويل سجل فوق توفير مستقر كما معتاد عدد وقت cut، لكن مع حال استدعاء جهة اشتراط أكثر كثير عملية، هذا سحب كائن سوف لا قطع إعادة تنفيذ الذي اختيار عدد مجموعة دلالة. صريح بحث جذب قراءة، صريح شيء تحويل و إسقاط بـ أكثر صغير عام API تغطية قد تسليم قراءة معنى رسم.

**ذاكرة مؤقتة كل شيء تحويل منطقة بين أو صيانة زيادة كمية قسم قطعة لقطة.** منطقة بين ذاكرة مؤقتة حاجة إبقاء و تصفية استبعاد قاعدة، بينما عام قسم قطعة يمثل سوف تغيير مستهلك و تسلسل تحويل طريقة؛ سماح كثير استدعاء جهة قد عبر بحث جذب قراءة أو إسقاط تجنب فتح هذا بند صار هذا. إذا فعلي قياس كامل لقطة مستهلك إثبات لديه لا بد يلزم، ما زال يمكن اعتبار هذه يمثل.

## عاقبة

- طويل درجة قراءة و مفرد حدث قراءة لن نسخ سجل.
- كامل لقطة و منطقة بين لقطة ما زال لديه و الذي اختيار حدث عدد كمية صار صحيح مقارنة صريح خط صفة صار هذا.
- مستهلك في استدعاء نقطة اختيار أصلي تاريخ أو زيادة كمية صيانة حالة.
- عام API لا نموذج محاكاة عدد مجموعة؛ استدعاء جهة فقط في حاجة عدد مجموعة عملية وقت شيء تحويل.
