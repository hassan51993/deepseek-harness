# Agent Note: Loader إدراج قيمة بند `disabled` حقل

Status: implemented
Archived: 2026-09-04

[English](2026-08-11-loader-entry-disabled-interpolation.md) | العربية

## مشكلة

Windows منصة طبقة (عند وقت هو base patch جانب مستقل `windows.cordis.patch.yml`، الآن قد طي دخول base سطر——رؤية «قرار») في win32 فوق منع استخدام `tool-bash`، لكن shipped مسبق ضبط كل منها تركيب واحد سطر `tool-bash`. مسبق ضبط سطر الأكثر بعد تركيب، نفس اسم سطر في Windows فوق إعادة تفعيل هذا أداة——جلسة معا يملك `tool-bash`(PowerShell خلفية) و `tool-pwsh`، كما هو ساكن صامت، لأن لا يوجد spec pin تركيب بعد مسبق ضبط طبقة. بند بيانات وصفية لا يوجد شرط آلية:`!!js` فقط في إضافة `config` تحت إدراج قيمة،[postmortem 0002](../../../../docs/postmortem/0002-js-expression-disabled-filesystem-tools.zh.md) سجل `disabled: !!js ...` إبقاء حق قيمة جدول بلوغ صيغة كائن، في كل منصة فوق منع استخدام هذا سطر أمر لذا.

## قرار

Loader إدراج قيمة بند `disabled` حقل (`vendor/loader/src/config/entry.ts`):`!!js` جدول بلوغ صيغة في كل مرة تركيب قرار وقت أساس في loader سياق طلب قيمة.`disabled` هو وحيد يتم إدراج قيمة بيانات وصفية حقل؛`id`،`name`،`group`،`inject` إبقاء ساكن حالة. أصلي عقدة إبقاء في options في، كتابة عودة إبقاء `!!js` شكل صيغة.shipped مسبق ضبط (standard،code،cordis) ذاتي ذات إعلان shell أداة سطر و حسب منصة باب تحكم——`tool-bash` يحمل `disabled: !!js process.platform === 'win32'`، ذلك توأم توليد سطر `tool-pwsh` بـ أخذ عكس جدول بلوغ صيغة——لذلك مسبق ضبط طبقة كل منصة مضيف تماما جيد كشف واحد shell أداة؛web-app overlay منع استخدام اثنان عدد أداة host سطر، من كل جلسة مسبق ضبط قرار.`verify-cordis-config` الآن فقط سماح `disabled` في جدول بلوغ صيغة.

هذا آلية تكملة كل منصة طبقة طي:base bundle `cordis.patch.yml` في ذاته سطر فوق حسب منصة باب تحكم اثنان عدد shell مكدس——`bash-sandbox`/`tool-bash` يحمل `disabled: !!js process.platform === 'win32'`، هو جمع توأم توليد سطر `pwsh-sandbox`/`tool-pwsh` بـ أخذ عكس جدول بلوغ صيغة فقط في win32 تركيب. بدء جهاز مستقل Windows منصة طبقة (`windows.cordis.patch.yml` و `apps/cli/src/windows-shell.ts` و ذلك حقن إلى boot،live إعادة تركيب،config dump منطق) يتم حذف——هذا طبقة فقط بسبب بند بيانات وصفية هو ساكن حالة بينما وجود،`disabled` يمكن إدراج قيمة بعد شرط حينئذ سقوط في هو الذي معالجة إدارة سطر فوق.

## تجهيز اختيار خطة

**سطر فوق إعلان صيغة `platform` حقل.**ساكن حالة كما يمكن يتم بوابة فحص، لكن هو هو `!!js` خارج ثاني نوع تركيب آلية، بينما منصة فقط هو جمهور كثير نشر شرط لـ واحد.

**مسبق ضبط درجة منصة overlay.** يتم لا: شرط ينبغي عند يخص هو الذي معالجة إدارة سطر——نفس أصل فإن يأخذ بدء جهاز مستقل Windows منصة طبقة طي دخول base سطر.

## عاقبة

سطر يمكن حسب منصة أو بيئة باب تحكم ذاته؛ خطأ جدول بلوغ صيغة في بدء وقت صدى مضيء فشل. ذلك بقية بيانات وصفية حقل إبقاء حرف وجه قيمة، بوابة متابعة رفض ذلك داخل جدول بلوغ صيغة——`disabled` فوق postmortem-0002 خفي علة بـ «طلب قيمة» بينما غير «منع توقف» إغلاق.Windows shell مكدس تبديل من بدء جهاز حقن patch طبقة نقل إلى base bundle ذاته سطر فوق:win32 تركيب تلقي حد pwsh مكدس،POSIX يحمل يتم منع استخدام pwsh سطر، نفس نسخة patch ملف خدمة اثنان نوع دفعة سعة——[Windows افتراضي pwsh](../feature/2026-08-01-windows-pwsh-default.zh.md) note طبقة آلية قد يتم يحل محل.shell أداة سطر التزام دوران و أخرى مسبق ضبط إعلان سطر نفسه one-plane قاعدة:web-app overlay منع استخدام host وجه `tool-bash`/`tool-pwsh` سطر، مسبق ضبط بـ متبادل عكس منصة باب تحكم إعلان اثنان من، لذلك مهمة واحد مضيف كل جلسة كل يمكن حسب مسبق ضبط إسقاط أو استبدال shell أداة.`minimal` مسبق ضبط ناقص win32 PTY مكدس هو مسبق ضبط بيانات وصفية لاحق عمل.
