# Agent Note: سوف code-mode إعادة تسمية لـ ptc——نقل طبقة تسمية لـ PTC، مستخدم نص سجل استخدام PTC mode

Status: implemented
Archived: 2026-09-04

[English](2026-08-25-rename-code-mode-to-ptc.md) | العربية

## مشكلة

عبر توليد SDK و `run_code` نقل طبقة نحو نموذج عرض أداة سجل التسجيل نمط، إصدار وقت استخدام اسم حرف هو Code Mode؛ بينما اختيار هذا نمط عميل مسبق ضبط مبكر قد بـ «PTC mode» إصدار (locale `presetPtcName: 'PTC mode'`، العربية `PTC نمط`). نفس وظيفة لديه اثنان طقم اسم حرف: إعداد قيمة، إضافة و حدث اسم، ملف و وثيقة كتابة هو `code`/`code-mode`، مستخدم مرئي اسم حرف لكن هو «PTC mode». مسبق إصدار مرحلة مقطع أكثر اسم يجب مرة صفة تحديث كل مرجع——لا إضافة أي توافق آخر اسم.

## قرار

هذا وظيفة أكثر اسم لـ PTC(programmatic tool calls، برنامج تحويل أداة استدعاء). شفرة معرف رمز استخدام `ptc`——هذا نقل طبقة و غير plan-mode نفس صنف نمط، لذلك معرف رمز لا حمل `-mode`. مستخدم مرئي نص سجل امتداد استخدام «PTC mode»(إنجليزي نص)/«PTC نمط»(العربية) ، و قد إصدار مسبق ضبط اسم متسق.

هذا PR إتمام إعادة تسمية يشمل:

- إعداد قيمة `tools.mode: 'code'` → `'ptc'`(`ToolPresentationMode` و `dsh-tools`،`dsh-agent-tool-presentation` في zod union)
- مسبق ضبط دليل `presets/code/` → `presets/ptc/`(مسبق ضبط id لـ `ptc`)
- مصدر ملف و اختبار ملف `code-mode.ts` → `ptc.ts` انتظار؛ أصل demo `demo:code-mode` → `demo:ptc`(`scripts/demo-ptc.mjs`)
- توزيع waterfall `tools/code-dispatch-log` → `tools/ptc-dispatch-log`، نوع `CodeDispatch*` → `PtcDispatch*`
- نص التوجيه قاعدة `tools:code-only` → `tools:ptc-only`
- وثيقة،README و ثمانية عدد بـ هذا وظيفة تسمية implemented Agent Note في نص سجل "Code Mode" → "PTC mode"/"PTC نمط"(هذه Note ملف واحد و حينئذ أرض تعديل اسم)

جلسة حمل دائم مفردات متابعة تأخير بعد معالجة: حمل دائم حدث نوع `tool/code-dispatch`/`tool/code-dispatch-start`، سجل في إضافة اسم `tools-code-mode`، فرعي استدعاء id مقطع `:code:`. إعادة تسمية هذه قيمة يخص بنية صفة Session صيغة تغيير، يجب في ثابت انتظار v0-to-v1 أساس أساس بعد يملك ذاتي ذات متبادل مجاور ترحيل حافة.

إبقاء ثابت:`run_code` و ذلك `code` معامل (هو جمع وصف برنامج تحميل حمل، بينما غير نمط) ،`CodeSdkLanguage`،`CodeRunFailedError`،`dsh-code-runtime*` حزمة عائلة، رقم ثلاثة جهة اثنان دخول صنع اسم `codex-code-mode-host`، و كل تجميد ربط archived Note.

## تجهيز اختيار خطة

- **استخدام `ptc-mode` معرف رمز**——مرفوض:PTC هو أداة عرض نقل طبقة، لا هو plan-mode معنى معنى فوق نمط، معرف رمز لا ينبغي إعلان عرض هذا نوع قريب حافة علاقة.
- **فقط إعادة تسمية جدول وجه**——مرفوض: مسبق إصدار قيام ساحة اشتراط مرة صفة تحديث كل مرجع.
- **وصل `run_code` واحد بدء تعديل اسم**——مرفوض: هذا أداة اسم وصف هو تشغيل برنامج، لا هو نمط، بينما كما هو مقابل نموذج مرئي API جدول وجه.
- **لا توفير متبادل مجاور ترحيل حافة حينئذ إعادة تسمية حمل دائم حدث مفردات**——مرفوض: حينئذ أرض إعادة تسمية `tool/code-dispatch*` سوف يجعل أكثر اسم قبل Session سجل لا يمكن قراءة؛ هذا إعادة تسمية حاجة لاحق بنية صيغة إصدار و صريح ترحيل.

## عاقبة

إعداد في كتابة `mode: code`، مسبق ضبط id لـ `code`، في هذا بناء فوق لم يعد تلقي دعم حمل. جلسة حمل دائم مفردات ما زال لـ `tool/code-dispatch*`،`tools-code-mode` و `:code:`؛ ثابت انتظار v0-to-v1 ترحيل حافة سوف إبقاء هذه قيمة، لذلك هذا مرة أكثر اسم لا يتضمن بنية إصدار تغيير. لاحق متبادل مجاور ترحيل حافة يجب إعادة تسمية هذا مفردات و تحديث جديد يتضمن توزيع fixture(مشاركة رؤية[إصدار آلية](2026-08-10-session-log-version-mechanism.zh.md)). هذا Note الذي أكثر اسم قد إصدار قرار هو [PTC أساس أساس Note](../feature/2026-06-15-ptc.zh.md).
