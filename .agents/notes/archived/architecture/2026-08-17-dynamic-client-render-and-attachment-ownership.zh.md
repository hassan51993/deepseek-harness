# Agent Note: عميل تصيير و مرفق عنصر عرض حركة حالة ملكية

Status: implemented
Archived: 2026-09-04

[English](2026-08-17-dynamic-client-render-and-attachment-ownership.md) | العربية

## مشكلة

مضيف تحرير كتابة عميل رسم إدارة متصفح إضافة، لكن ثلاثة بند عرض مسار يقع في ذلك دورة الحياة خارج.Web داخل نواة إنشاء React أصل و من خارج قشرة يحتفظ تجميع زائف entry،`ui-conversation` بـ حزمة قيمة شكل صيغة استيراد مرفق عنصر مكون، خارج قشرة أيضا استيراد ui-theme عام مثال صيغة. لذلك، منع استخدام، فشل أو إعادة تحميل بعض عدد إضافة وقت، و لا يستطيع معا إدارة يخص هذا إضافة الكل تصيير و CSS.

تحميل و فشل صفحة اشتراط صحيح جيد متبادل عكس: يشمل مصير في داخل أي حركة حالة إضافة تنشيط فشل وقت، هو كل يجب إبقاء متاح. هو لا يستطيع اعتماد ذاتي ذات صحيح في تقرير إبلاغ ذلك فشل React شجرة.

## قرار

`@deepseek-ai/dsh-client-web` هو لا اعتماد إطار هيكل بدء داخل نواة. هو عبر DOM عملية و محلي CSS رجوع رسم صنع تحميل و فشل صفحة، بنية صنع عميل وحدة نظام و Cordis Loader، إنشاء ساكن حالة وصل قبول modules بدء entry و مضيف رسم في كل entry، و انتظار كل fiber دخول ACTIVE.Loader حالة تغير سوف إبقاء نفس عدد spinner عقدة، فقط في entry أول مرة دخول active وقت تحديث ذلك CSS دائرة قوس. دائرة قوس من دائرة حلقة خمسة قسم لـ واحد زيادة طويل حتى خمسة قسم لـ أربعة، في دوران تحويل خلال بداية نهاية إبقاء مرئي نقص فتحة. اسم سجل مستقر بعد، داخل نواة تحليل `ctx.uiRenderer`، يأخذ قائم حاوية تسليم إعطاء `mount()`.

`@deepseek-ai/dsh-client-ui-renderer` هو حمل `immediately` علامة حركة حالة عميل إضافة. هو يحتفظ React slot outlet،SessionProvider و observable إلى uSES ربط. هو حقن `slots` و `sessions` تنشيط بعد، سهل تثبيت slot مصير و توفير `ctx.uiRenderer`.`mount()` hydrate داخل نواة توليد بدء DOM، مجددا عبر layout effect في متصفح رسم صنع في بين لقطة قبل سوف ذلك استبدال لـ تجميع إتمام تطبيق.hydrate بعد spinner عقدة سوف إبقاء حركة رسم متبادل موضع. تجميع بعد شجرة إسقاط حالي جلسة عنوان، و تنفيذ وحيد مرة سياق درجة `renderSlot('root')` استدعاء. خدمة، مصير تثبيت و React أصل كل مع كل منها يحتفظ جهة dispose.

`ui-conversation` إعلان `conversation.input.attachments` و `conversation.message.images`، و توفير مرفق عنصر بيانات، عودة ضبط، مرور جلسة تخويل صورة تحميل و ذلك locale seat.`ui-attachment` عبر `ctx.slots.inject()` انتظار هذه إعلان، مجددا تسجيل مسودة مسودة مرفق عنصر شريط/سحب وضع هدف و تاريخ صورة رسم ممر/مصباح صندوق.React تنفيذ ما زال هو حزمة داخل قيمة؛ عبر إضافة تركيب عبر slot إتمام. هذا بند حزمة تجميع صار قرار يحل محل[مرفق عنصر عرض Note](../feature/2026-08-11-web-attachment-display-alignment.zh.md) في مباشر استيراد قاعدة، لكن لا تغيير هذا Note نظر شعور و تفاعل قرار.

ui-theme يأخذ ذاتي ذات خمسة نسخة عام مثال صيغة جدول بصفة `?inline` نص استيراد. عميل entry استدعاء `installThemeStyles(ctx)`، مرور `ctx.effect()` لـ كل نسخة مثال صيغة تثبيت واحد style وسم، لذلك إزالة أو إعادة تحميل ui-theme وقت، ذلك عام CSS سوف مع خدمة نفس دورة الحياة حذف أو استبدال.Web داخل نواة فقط إبقاء تركيب قيمة افتراضية، و حرف جسم و لون لون و مقابل رئيسي عنوان token متسق ذاتي إعطاء ذاتي كاف بدء صفحة إعداد لون.

React،React DOM،Cordis،ui-slots و ui-primitives ما زال هو إبقاء مفرد واحد متصفح هوية ساكن حالة منصة وحدة. حركة حالة ui-renderer bundle إزالة استهلاك هذه مشترك وحدة و يحتفظ تصيير فرعي أثر.

## تحقق

مكون اختبار ثابت حمل دائم دخول درجة spinner،hydrate لا تغيير بدء DOM، وثيقة عنوان، تطبيق شجرة، مرفق عنصر entry و dispose سلوك. تجميع بعد بناء bundle بدء اختبار سوف تشغيل حقيقي وحدة جدول و حركة حالة entry،theme مثال صيغة اختبار فإن إثبات هذه وسم سوف مع إضافة fiber تثبيت و تحرير. متصفح إعادة تشغيل اختبار تغطية من لا اعتماد إطار هيكل صفحة إلى تصيير تطبيق كامل تسليم وصل.

## تجهيز اختيار خطة

**إبقاء خارج قشرة يحتفظ تطبيق تجميع زائف entry.** مرفوض: هو ما زال لا في مضيف رسم في، بينما كما سوف يأخذ تصيير ملكية تغيير صار خاص خاص Loader مسار، كل إدارة هذا تجميع فقط لديه عادي خدمة اعتماد و دورة الحياة فرعي أثر.

**إبقاء توجيه خروج مرفق عنصر أصل فرعي مكون و من ui-conversation استيراد.** مرفوض: مباشر استيراد مكون سوف التفاف مرور مستقل إضافة تركيب و إعادة تحميل ملكية. يحتفظ جهة بيانات ما زال عبر حمل نوع slot props مباشر نقل تمرير؛ فقط لديه عرض اختيار هو حركة حالة.

**يأخذ ui-theme مثال صيغة إبقاء في خارج قشرة أساس أساس مثال صيغة جدول في.** مرفوض: رئيسي عنوان إضافة ناقص أو فشل وقت، رئيسي عنوان CSS ما زال سوف توليد فاعلية، بينما كما لن مشاركة و إضافة إعادة تحميل تنظيف.

**استخدام React تصيير فشل صفحة.** مرفوض: تصيير خدمة أو React شجرة فشل وقت، لا يستطيع وصل نفس متصفح في وحيد تشخيص واحد بدء إزالة.

## نتيجة

مضيف رسم يتضمن كل حركة حالة تصيير يحتفظ جهة،HMR عبر إضافة دورة الحياة استبدال مرفق عنصر عرض، تصيير تجميع و رئيسي عنوان CSS. تصيير خدمة فشل وقت سوف إبقاء تحت يمكن قراءة DOM فشل صفحة، بينما لا هو فارغ أبيض React تركيب نقطة. متعمد حذف ui-attachment سوف يجعل ذلك اختياري slot إبقاء لـ فارغ؛ مع منتج تسليم Web تركيب يتضمن هذا إضافة، بينما إعداد في وجود لكن تنشيط فشل entry سوف منع توقف كامل تطبيق تسليم وصل.

تطبيق أول عدد React لقطة ما زال سوف انتظار كامل عميل اسم سجل. خارج قشرة ما زال ساكن حالة تحزيم منصة وحدة هوية؛ من في ui-theme CSS يلزم انتظار إلى هذا إضافة شيء تحويل بعد عندئذ متاح، بدء صفحة أيضا يلزم صيانة واحد صغير طقم خاص واضح داكن إعداد لون.
