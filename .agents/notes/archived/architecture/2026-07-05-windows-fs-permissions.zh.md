# Agent Note: Windows كتابة إذن دلالة: وراثة DACL، بينما غير إذن نمط موضع

Status: implemented
Archived: 2026-07-26

[English](2026-07-05-windows-fs-permissions.md) | العربية

هذا سجل في صلة في استبدال ملف قرار قد من [Windows DACL إبقاء آلية](../bug-fix/2026-07-19-windows-atomic-write-dacl-preservation.md) يحل محل.

## مشكلة

`writeFileAtomic` في `@deepseek-ai/dsh-fs-local` في استخدام POSIX إذن نمط موضع حفظ حماية صحيح في كتابة محتوى: بـ `0o700` إنشاء مؤقت تخزين دليل، بـ `0o600` فتح مؤقت ملف، جديد ملف أيضا افتراضي استخدام `0o600`. في POSIX فوق، بلا نقاش أب دليل إذن مثل أي، هذه ضبط كل قدرة حفظ إثبات مؤقت محتوى فقط مقابل كل من مرئي.

Windows في نفس API خلف بعد لا يوجد متاح مقابل انتظار آلية.Node `chmod` في Windows فوق فقط سوف قيادة فقط قراءة خاصية (هذا حزمة نقل دخول كل نوع نمط كل يتضمن كل من كتابة إذن، لذلك هذه استدعاء هو بلا ضرر فارغ عملية) ،`stat().mode` فإن تقرير إبلاغ دمج صار `0o666`/`0o444` إذن موضع. حق صحيح أمان حالة من ملف DACL قرار: جديد بناء ملف أو دليل سوف من أب دليل وراثة، استبدال عملية فإن حاجة من يحل محل هذا نص Agent Note الذي تعريف صريح معالجة.

## قرار

Windows جديد بناء ملف استخدام دليل وراثة، بينما لا استخدام دمج صار إذن نمط موضع: مؤقت تخزين دليل في هدف أب دليل (`dirname(absolutePath)`) داخل إنشاء، لذلك هو و مؤقت ملف كل سوف وراثة هدف دليل DACL. استبدال ملف التزام دوران أكثر صارم إطار [DACL إبقاء عقد نحو](../bug-fix/2026-07-19-windows-atomic-write-dacl-preservation.md).

اختبار فقط في POSIX فوق تأكيد إذن نمط موضع.Windows أصلي نسبة التغطية قفل تحديد من هذه الحزمة (package) مسؤول استبدال سلوك؛ جديد ملف وراثة ما زال يخص عملية نظام عقد نحو، بينما لا هو إبرة مقابل خاص تحديد آلة جهاز ACL سماح بيان.

## تجهيز اختيار خطة

**لـ جديد ملف صريح ضبط فقط كل من متاح DACL.** غير مقبول، لأن هذا سوف كسر تالف وراثة، أيضا سوف جعل خاص معنى مشترك مشروع دليل مستخدم شعور إلى معنى خارج. استبدال كتابة سوف نسخ هدف قائم DACL، بينما لن ذاتي سطر تصميم فقط كل من متاح سياسة.

**في اختبار في تحقق ACL.** `Get-Acl` SID سماح بيان أو `icacls` تحقق هو Windows وراثة آلية و حالي آلة جهاز `%TEMP%` ACL، بينما غير حزمة سلوك؛`icacls` أيضا سوف مقابل معرفة اسم حساب مستخدم اسم إجراء محلي تحويل، توجيه يؤدي تحليل سعة سهل تلقي لغة منطقة مجال أثر.

**في Windows فوق قفز مرور `chmod`.** لـ بلا ضرر فارغ عملية استدعاء زيادة منصة حراسة حماية فرع، لن تغيير أي سلوك.

## عاقبة

بلا نقاش أب دليل إذن مثل أي،POSIX كل سوف متابعة سوف مؤقت محتوى حد لـ فقط كل من متاح.Windows في جديد هدف إذا يقع في واسع عام يمكن وصول دليل داخل، سوف حسب تصميم وراثة هذا نوع يمكن وصول صفة؛ إذا استبدال هدف وجود أكثر صارم إطار DACL، فإن سوف إبقاء هذا DACL.

في Windows فوق، استبدال وقت نمط إبقاء سوف تراجع تحويل لـ فارغ عملية: يمكن كتابة ملف استكشاف قياس نتيجة لـ `0o666`، عبر `chmod` إعادة وضع هذا نمط سوف جعل فقط قراءة خاصية متابعة إبقاء صاف حذف حالة. من في إصدار عملية سوف في دمج صار نمط إرسال تلويح أثر قبل فشل،Windows فوق لا يمكن استبدال فقط قراءة هدف.
