# Agent Note: عبر dsh profile بدء جهاز تشغيل Python SDK وقت التشغيل

Status: implemented
Archived: 2026-09-04

[English](2026-08-23-python-sdk-dsh-profile-runtime.md) | العربية

## مشكلة

Python SDK توزيع واحد خاص Node تطبيق، مباشر بدء كامل خارجي `cordis.yml`؛ أخرى كل تلقي دعم حمل تطبيق كل من `dsh` profile دخول. هذا مثال خارج تكرار بيئة تحميل، إعداد كل حق، إضافة تحليل، إغلاق مسار، ناتج تسمية و اختبار مسار. هو أيضا يأخذ SDK ذاتي تعريف تغيير صار كل كمية استبدال تطبيق شجرة: فقط تفكير استبدال واحد إضافة استدعاء جهة أيضا يجب يملك JSON-RPC server و كل غير متصل deployment بند إعداد.

فقط تعديل Python wrapper لا يمكن اعتماد عادي profile. وقت التشغيل يمكن تنفيذ برنامج يجب يتضمن `dsh` CLI، مع مرفق profile و bundle ملف، أصلي مكتبة، و في profile ملف و خارجي إضافة يقع في pkg وهمي محاكاة نظام الملفات خارج وقت ما زال يمكن عمل وحدة تحليل مسار.

## قرار

### واحد تطبيق بدء جهاز

وقت التشغيل يمكن تنفيذ برنامج تحزيم `@deepseek-ai/dsh` و تشغيل ذلك عادي أمر لغة قاعدة.Python عميل افتراضي اختيار `--profile sdk`، تحويل إرسال لديه ترتيب قطعا مقابل `--patch` مسار، أيضا يمكن اختيار آخر عدد `dsh` يمكن تنفيذ برنامج أو profile. يمكن تشغيل أقصى بسيط عرض مثال اختيار مع مرفق `sdk-minimal` profile. خاص `@deepseek-ai/dsh-sdk-python-runtime` تطبيق حزمة و فحص دخول وقت التشغيل `cordis.yml` متساو لا وجود.JSON-RPC خدمة ما زال من `@deepseek-ai/dsh-sdk-app` bundle و `@deepseek-ai/dsh-sdk-jsonrpc-server` إضافة توفير، بينما لا هو Python ذاتي لديه بدء مسار.

عام Python إعداد يشمل `dsh_bin`،`profile`، لديه ترتيب `patches`،`dsh_home`، عملية cwd/بيئة،provider/model/token اختيار، محدود ابتدائي تحويل timeout، و اختياري جولة/إغلاق timeout. هو لا كشف كامل Cordis شجرة أو مهمة معنى بدء argv.`RunResult` تقرير إبلاغ بروتوكول كل تشغيل قيمة، لا تكرار profile حفظ دائم مسار.

كل مرة Python بدء كل اشتراط صريح `dsh_home`، أو عملية فرعية بيئة في غير فارغ `DSH_HOME`.SDK أبدا سوف اكتشاف `~/.dsh`. الذي اختيار home موحد واحد يملك profile، خارجي إضافة، اعتماد، ضبط و جلسة.

### إضافة ذاتي تعريف

حمل دائم SDK ذاتي تعريف استخدام و مباشر CLI نفسه profile واجهة.`dsh plugin --profile <name> ...` إدارة خارجي اعتماد و bundle ترتيب،`$DSH_HOME/profiles/<name>/cordis.patch.yml` مسؤول حمل دائم بند إعداد تغيير،home patch مقابل كل profile تطبيق آلة جهاز محلي تغيير،Python `patches` فإن توفير مفرد مرة بدء overlay. الذي اختيار profile فقط لديه إبقاء SDK server بند إعداد وقت عندئذ صالح. ناقص profile،bundle،server بند إعداد أو غير قاعدة patch كل سوف مباشر فشل، لا وجود كامل إعداد رجوع؛ إبقاء تشغيل لكن لا توفير JSON-RPC خدمة profile سوف في مستقل محدود ابتدائي تحويل إمساك يد في فشل، تشخيص سوف إشارة واضح هذا profile.

[مستقل sdk-minimal profile](2026-08-24-standalone-sdk-minimal-profile.ar.md) فقط صف خروج واحد مستودع ذاتي لديه تركيب حزمة، هذا تركيب حزمة سوف إدراج دخول لا يحتوي `dsh-base` كامل صريح إعداد شجرة. حمل دائم Bash و نص استبدال editor عبر تركيب وجود؛ مشترك JSON-RPC server لا كشف أصل agent أداة غربلة اختيار جهاز. حركة حالة وقت التشغيل سياق،workspace إشارة أمر،settings، حمل إدارة اعتماد، بعيد قياس،compaction و أخرى كل base بند إعداد متساو لا وجود. نفس وقت التشغيل ما زال سوف يأخذ كامل `sdk` و `web` profile بصفة مستقل اختيار تحزيم.

وقت التشغيل wheel تثبيت `dsh` تحكم منصة أمر. عادي profile و SDK تشغيل ما زال لا حاجة Node؛ خارجي حزمة إدارة اشتراط استدعاء جهة ذاتي سطر تثبيت `pnpm`.

### يمكن تنفيذ برنامج تحزيم

صفر شفرة نشر manifest هو `dsh-python-runtime-closure`. هو يأخذ `node_modules/@deepseek-ai/dsh/lib/bin.js` و profile،bundle،preset، أصلي addon و مشترك مكتبة مورد تحزيم دخول `deepseek-harness-sdk-runtime-<platform>-<arch>`.Wheel distribution اسم،Python import وحدة،JSON-RPC رسالة و بروتوكول مستقر `serverInfo.name = deepseek-harness-sdk-runtime` إبقاء ثابت.

عادي Node profile في `$DSH_HOME/profiles/node_modules` في استخدام رمز رقم رابط، يجعل خارجي إضافة مشترك تثبيت حزمة. عملية نظام رمز رقم رابط لا يمكن دخول pkg `/snapshot` نظام الملفات، لذلك تحزيم CLI تعديل لـ كتابة صغير نوع حقيقي ESM بديل إدارة حزمة. كل بديل إدارة مباشر حسب Node import شرط تحليل مصدر حزمة صريح ESM exports map، عام تثبيت في فعلي وجود هدف، و إعادة توجيه خروج ذلك وهمي محاكاة وحدة URL. لا يوجد ESM وقت التشغيل هدف export بند و فقط يحتوي يمكن تنفيذ مدخل أو نوع إعلان مدخل حزمة لن إنتاج غير ممكن استخدام بديل إدارة بند؛ صيغة خطأ exports map سوف توجيه يؤدي بدء فشل. كامل كما مطابقة generation لن نيل أخذ عبر عملية كتابة قفل. ناقص أو مرور مدة بند إعداد سوف نيل أخذ هذا قفل، إعادة فحص generation، و في لا كشف نصف صار صنف بديل إدارة قبل رفع تحت إصلاح؛ مهمة واحد تحميل جسم كل يمكن استبدال آخر تحميل جسم إبقاء تحت تلقي إدارة بند إعداد.Loader بند إعداد و خارجي إضافة peer بسبب بينما يمكن عبر عادي profile تدريجي درجة نحو فوق فحص بحث تحليل، معا إبقاء واحد Cordis و كل داخل وضع وحدة مفرد واحد نسخة.

قد إصدار هدف تجميع دمج هو Linux x64،Linux arm64،macOS arm64،macOS x64 و Windows x64.Installed-wheel أسود صندوق CI في كل هدف فوق مسؤول ناتج مصدر، افتراضي و patched profile، خارجي bundle تثبيت، أصلي أداة،MCP، مباشر JSON-RPC، لقطة، و يمكن معلومة حقيقي مزود جولة.[Windows x64 وقت التشغيل قرار](2026-08-23-python-sdk-windows-x64-runtime.ar.md) مسؤول Windows ناتج و ذلك منصة مخصص تابع shell surface.

## قائم قرار و يحل محل علاقة

هذا قرار تنفيذ و يحل محل[مفرد واحد dsh تطبيق بدء جهاز](2026-08-22-single-dsh-application-launcher.ar.md) في Python مثال خارج و تأخير بعد ترحيل فصل عقدة. هو يحل محل[مفرد ملف Python SDK وقت التشغيل توزيع](2026-07-10-single-file-executable-sdk-runtime-distribution.ar.md) في خاص تطبيق، خارجي كامل إعداد، ناتج اسم و ذاتي تعريف واقع؛ بعد من متابعة مسؤول pkg/SEA،wheel بناء، أصلي هدف تحقق و إصدار.[مستقل sdk-minimal profile](2026-08-24-standalone-sdk-minimal-profile.ar.md) فقط يحل محل هذا Note في أقصى بسيط overlay تنفيذ. لا يوجد أي active note يتم تماما يحل محل، لذلك بلا حاجة عودة ملف.

## اعتبار مرور بديل خطة

**يأخذ كامل `cordis.yml` إبقاء لـ عال درجة هروب توليد فتحة.** لا إعطاء اعتماد، لأن هو سوف إبقاء ثاني طقم تطبيق تجميع، و سماح استدعاء جهة التفاف مرور profile بيئة، إضافة و إغلاق كل حق.

**لـ توافق صفة ساكن صامت استخدام `~/.dsh`.** لا إعطاء اعتماد، لأن SDK عملية لا ينبغي في لا يوجد صريح اختيار وقت وراثة عدد شخص إضافة، اعتماد، ضبط أو جلسة.

**يأخذ وهمي محاكاة اعتماد شجرة نسخ إلى كل home.** لا إعطاء اعتماد، لأن هذا سوف تكرار عدد مئة MB، و تحميل ثاني عدد Cordis نسخة. إبقاء exports بديل إدارة جدا صغير، بينما كما صيانة حمل وحدة هوية.

**يأخذ pnpm و Node حزمة إدارة قبول دخول كل مرة SDK بدء.** لا إعطاء اعتماد، لأن قد تثبيت إضافة يخص deployment حالة، بينما لا هو تدريجي جولة وقت التشغيل عمل. فقط لديه `dsh plugin` حاجة خارجي حزمة إدارة جهاز.

## نتيجة

Python استدعاء جهة استخدام و TypeScript و مباشر CLI مستخدم نفسه profile مفردات، مهمة معنى خارجي bundle يمكن توسيع SDK profile، بينما بلا حاجة جذب دخول آخر عدد launcher. استدعاء جهة يجب صريح اختيار home، كامل إعداد و `session_root` معامل غير ممكن استخدام، يمكن تنفيذ برنامج فإن يتضمن مشترك مكتبة مورد و profile وحدة بديل إدارة. كامل `sdk`، مستقل `sdk-minimal` و `web` تطبيق بصفة نفس تحزيم CLI داخل مختلف profile إبقاء قسم مغادرة.Installed-wheel CI سوف حزمة،profile، أصلي و مزود مسار تغيير صار إصدار اشتراط، بينما لا هو فقط في شفرة المصدر في صار قيام زائف ضبط.
