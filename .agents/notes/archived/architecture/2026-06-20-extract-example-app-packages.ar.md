# Agent Note: سوف عرض مثال تطبيق رفع أخذ لـ مستقل حزمة

Status: implemented
Archived: 2026-07-26

[English](2026-06-20-extract-example-app-packages.md) | العربية

## مشكلة

عرض مثال دليل هذا ينبغي هو*دقيق بسيط*——فقط يتضمن عرض عرض متغير وصل خط، بينما غير عرض عرض أساس أساس ضبط تطبيق. في هذا مرة تغيير قبل، هو هو منتفخ تورم. كل عرض مثال كل يحمل واحد نسخة يد كتابة `start.ts` بدء جذب توجيه، واحد مقطع أساس أساس ضبط تطبيق قبل توجيه (`timer`، و stdio عرض عرض الذي يحتاج `logger` + `hmr`(حار وحدة استبدال)) ، ثلاثة عدد مشترك YAML قطعة مقطع تضمين طقم مرجع (`base.yml` / `base-core.yml` / `acp-agent/acp-tail.yml`) ، أيضا لديه كل عرض مثال ذاته `agent-loop`/حفظ دائم/توجيه النظام إعداد. حق صحيح تطبيق——كل agent(ذكي جسم) كل حاجة خدمة رئيسي جاف——تفرق سقوط في ورقة فرعي إعداد و ذلك بعض include في.

ورقة فرعي إعداد أيضا يملك اقتران دمج قبل باب.ACP(Agent Client Protocol) اشتراط stdout صاف صاف، و عبر `session/new` إنشاء agent؛ طرفية تطبيق و Headless تطبيق فإن مسبق إنشاء `main`، لكن عملية I/O عقد نحو مختلف. منع توقف خطأ تركيب وحيد شاشة عائق هو وثيقة في نص حرف تحذير إبلاغ، بينما ثلاثة عدد `start.ts` ملف تكرار حال Loader جذب توجيه و دورة الحياة شفرة.

## قرار

كل عرض مثال الآن**رئيسي يلزم هو مقابل واحد تطبيق حزمة (package) استدعاء**، امتداد حال قائم[واجهة / تنفيذ / مستهلك seam](2026-06-13-capability-seams.md) تفكيك قسم وصل خط:**تطبيق حزمة يملك تركيب**، ورقة فرعي `cordis.yml` فقط يملك**يمكن استبدال اختيار**(أي عدد LLM(كبير لغة نموذج) مهايئ، أي عدد bash منفذ، نموذج، نص التوجيه، حفظ دائم أصل دليل).

- **`@deepseek-ai/dsh-agent-spine-demo`**([packages/examples/agent-spine-demo](../../../../packages/examples/agent-spine-demo)) تركيب لا يحتوي مزود، لا يحتوي منفذ، لا يحتوي UI رئيسي جاف، و تحويل إرسال agent loop(ذكي جسم حلقة) agent قائمة إعداد. هو مقابل أداة جسم loop اعتماد هو متعمد لـ لـ، لأن هذا حزمة تركيب هو رئيسي جاف بينما غير توسيع رئيسي جاف؛ استبدال loop معنى طعم حال توفير آخر عدد bundle.
- **`@deepseek-ai/dsh-tui-demo`**،**`@deepseek-ai/dsh-cli-demo`** و **`@deepseek-ai/dsh-acp-demo`** كل منها داخل وضع ذلك عملية زاوية لون.TUI يتضمن كل شاشة UI و مسبق إنشاء `main`؛Headless يتضمن one-shot driver و مسبق إنشاء `main`؛ACP يتضمن bridge كما لا مسبق إنشاء agent. ثلاثة من كل يتضمن JSONL حفظ دائم، و حذف stdout logger.
- **`start.ts` قد إزالة.** كل تطبيق حزمة كل كشف واحد bin؛`demo:*` نص برمجي استدعاء هو.Loader جذب توجيه،`.env` تحميل و سريع سرعة فشل حراسة حماية يقع في مشترك [`@deepseek-ai/dsh-app-boot`](../../../../packages/ui/app-boot) حزمة (في تدريجي ملف نسبة التغطية بوابة تحت لديه اختبار وحدة——رؤية[مشترك تطبيق bin بدء لاصق ماء](../simplification/2026-07-04-share-app-bin-boot-glue.md)) ؛ دقيق بسيط ذاتي تنفيذ مدخل من keyless Loader مسار اختبار قيادة.
- **كل ورقة فرعي `cordis.yml` دقيق بسيط لـ**خلفية، اختياري منتج أداة، و واحد تحمل تحميل تطبيق إعداد app بند.TUI و Headless يأخذ نموذج/جلسة اختيار توجيه إلى مسبق إنشاء agent؛ACP يأخذ ابتدائي مزود/نموذج توجيه إلى bridge.
- **`base.yml`،`base-core.yml` و `acp-agent/acp-tail.yml` قد تراجع دور**——هو جمع مشترك رئيسي جاف الآن يقع في `dsh-agent-spine-demo` في.

`bash-local` و LLM مهايئ ما زال هو**ورقة فرعي اختيار**:bundle توفير `tool-bash`(مستهلك schema) ، ورقة فرعي اختيار منفذ تنفيذ، لذلك صندوق رملي منفذ أو إعادة تشغيل مهايئ بلا حاجة لمس اصطدام تطبيق يكفي استبدال.

### تنفيذ إصلاح صحيح:`hmr` إبقاء لـ ورقة فرعي بند

رفع سجل الأكثر أول سوف `hmr` صف دخول تفاعل صيغة تطبيق داخل وضع قبل باب تجميع مجموعة. مقابل وفق شفرة تحقق بعد اكتشاف، سوف `hmr` داخل وضع إلى تطبيق حزمة في سوف في اثنان عدد جهة وجه و Cordis اندفاع مفاجئ، لذلك تعديل لـ بصفة**ورقة فرعي `cordis.yml` بند**تسليم:

1. `@cordisjs/plugin-hmr` هو واحد فقط حد Loader، فقط حد عملية فرعية تطوير إضافة——هو حاجة نشط وثب `loader` خدمة و ذلك داخلي وحدة وصول إذن، لذلك فقط قدرة في حقيقي `demo:*`/bin عملية فرعية في تشغيل، لا يستطيع في عملية داخل وحدة/نسبة التغطية اختبار طبقة تشغيل.
2. عملية داخل اختبار طبقة (vitest) جدا حتى لا يمكن*استيراد* vendor `hmr` وحدة (ذلك class-decorator `@Inject` شكل صيغة في Vite transform تحت سوف فشل) ، لذلك واحد `apply` ساكن حالة استيراد هو حزمة دائم بعيد لا يمكن ممتلئ كاف ذلك رئيسي دالة تدريجي ملف 100% نسبة التغطية بوابة.

صلة مفتاح في في،`hmr` لا هو stdout صاف صاف خفي علة:ACP إعداد في خطأ إضافة هذا بند لن كسر تالف JSON-RPC لقطة. كل قد تسليم تطبيق كل حذف stdout تحكم منصة logger؛stdout فقط عودة تطبيق أو بروتوكول driver كل.

## سبق اعتبار بديل خطة

### لـ ماذا لا متابعة استخدام مشترك YAML include قدوم إدارة وصل خط؟

قديم `base*.yml`/`acp-tail.yml` include قد ذهاب إعادة*إعداد*، لكن YAML include لا يمكن**غلاف تركيب**قبل باب اقتران دمج——هو فقط قدرة في ملاحظة تفسير في وصف، و معلومة مهمة كل ورقة فرعي التزام حراسة. هو أيضا لا يمكن يملك `bin`، لذلك بدء لاصق ماء واحد مباشر في ثلاثة عدد `start.ts` ملف في تكرار. حزمة سوف «ACP تطبيق أبدا نحو stdout إخراج سجل» من نص حرف تحذير إبلاغ تغيير صار ناتج خاصية: ورقة فرعي في لا وجود يمكن كتابة خطأ logger بند.

## تحقق

- عرض مثال دليل فقط يتضمن إعداد،README و اختبار:`start.ts`، أساس أساس ضبط تطبيق قبل توجيه و مشترك YAML include قد إزالة.
- `demo:tui`،`demo:headless` و `demo:acp` استدعاء تطبيق حزمة bin.
- كل جديد حزمة كل لديه README و تدريجي ملف 100% نسبة التغطية؛ كل تطبيق حزمة أيضا لديه واحد keyless حقيقي Loader مسار bin خطر دخان اختبار، لأجل التقاط[أمر بعد قسم تحليل 0001](../../../../docs/postmortem/0001-acp-default-export-drops-inject.md) في وصف توجيه خروج شكل حالة لذا عائق.
- ACP إعادة تشغيل طقم عنصر عبر تطبيق حزمة bin بدء، لذلك بروتوكول وصل خط و تجميع بعد خلفية سلوك كل عبر تجاوز حقيقي Loader حد.

## عاقبة

- **عار إضافة شجرة تعليم تعلم صفة.** رئيسي جاف الآن إخفاء في bundle بعد، فحص نظر كامل شجرة معنى طعم حال فتح `dsh-agent-spine-demo`. تطبيق حزمة README تحمل تحمل هذا نسخة تعليم تعلم مسؤولية.
- **كثير واحد طبقة بين وصل.**«هذا عدد عرض عرض تحميل ماذا؟» من مسح مفرد عدد YAML تغيير صار قراءة قراءة واحد حزمة.
