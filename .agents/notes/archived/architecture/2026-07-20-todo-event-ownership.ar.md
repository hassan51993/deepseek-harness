# Agent Note: todo حدث نوع عودة ذلك إنتاج جهة كل

Status: implemented
Archived: 2026-09-04

[English](2026-07-20-todo-event-ownership.md) | العربية

## مشكلة

`SessionEventMap` يمكن عبر إعلان دمج توسيع، جعل كل إضافة كل قدرة إضافة حمل دائم سجل، بينما بلا حاجة يجعل نواة قلب جلسة حزمة اعتماد كل حدث إنتاج جهة.`todo/write` و ذلك `TodoItem` payload من todo مجال إنتاج و حل تفسير؛ نواة قلب جلسة فقط توفير عام إلحاق، إعادة تشغيل،surface و ثابت كمية توسيع آلية. في نواة قلب في إعلان todo مخصص تابع نوع أو علاقة، سوف يجعل جلسة رئيسي جاف يملك واحد هو حيث لا إنتاج، أيضا لا يمكن كامل تحقق إضافة مفردات.

## قرار

`@deepseek-ai/dsh-tool-todo` في ذلك فقط نوع خروج فتحة في إعلان `TodoItem`، و عبر `@deepseek-ai/dsh-session/types` إعلان دمج إضافة دخول `todo/write`. حزمة أصل مدخل و `/client` مدخل إعادة توجيه خروج `TodoItem`، جعل host و متصفح مستهلك مشترك نفس موضع إعلان، بينما بلا حاجة تحميل todo إضافة.

فحص todo سجل مستهلك استخدام فقط نوع استيراد، و إعلان صريح حزمة اعتماد و TypeScript مشروع مرجع. إنتاج خروج JavaScript لا يحتوي todo استيراد؛ تركيب فقط لـ بحث، نقل أو تصيير ممكن يحتوي لديه `todo/write` سجل وقت، بلا حاجة تركيب todo أداة.

todo ثابت كمية إعداد طقم إضافة معا يملك payload قاعدة و حدث يجب يقع في فتح وضع جولة داخل علاقة. نواة قلب جلسة يمكن دمج توسيع switch مقابل `todo/write` مشي افتراضي فرع؛todo إعداد طقم إضافة سوف في إلحاق قبل رفض صيغة خطأ أو يقع في فتح وضع جولة خارج لقطة. هو سوف مفرد مرة تحقق قائم جلسة و جديد إصدار جلسة، و لـ لاحق حدث دفع دخول تدريجي جلسة قد إيداع جولة تتبع أثر حالة.todo مخصص تابع إلحاق، إعادة تشغيل، إسقاط و جولة غلاف إغلاق اختبار و todo حزمة وضع في واحد بدء. موجه إلى نموذج سلوك ما زال من [`todo_write` وظيفة قرار](../feature/2026-06-29-todo-write-tool.ar.md) مسؤول.

## تحقق

تجمع تركيز todo أداة، ثابت كمية، إسقاط، تجميع صار و Loader تركيب اختبار تغطية إنتاج جهة و ذلك إعداد طقم إضافة.session-query رفع أخذ و عميل runtime/connection اختبار إثبات فقط نوع مستهلك ما زال قدرة إبقاء todo دلالة معالجة. كل مساحة العمل نوع فحص إثبات إعلان دمج عبر صريح مشروع رسم توليد فاعلية؛ إعادة توليد حدث، حفظ دائم،API و وحدة دليل سجل إعلان موضع و اعتماد حافة.

## سبق اعتبار بديل خطة

- **يأخذ payload نوع إبقاء في نواة قلب في بصفة مشترك UI مفردات**——رفض: تصيير إعادة استخدام و لن يجعل نواة قلب يصبح حمل دائم حدث إنتاج جهة أو دلالة كل جهة.
- **يجعل كل مستهلك كل منها حسب بنية استلام ضيق `todo/write`**——رفض: تكرار payload إعلان سوف عائم نقل، و التفاف مرور يمكن دمج توسيع حدث جدول.
- **اشتراط كل مستهلك كل تركيب todo إضافة**——رفض: قراءة حمل دائم سجل هو نوع و بيانات اعتماد، و لا بنية صار تثبيت موجه إلى نموذج أداة تخويل.

## عاقبة

نواة قلب جلسة حزمة لا توجيه خروج `TodoItem`، أيضا لا قوي صنع todo علاقة. تسمية أو استلام ضيق `todo/write` حزمة إعلان مقابل `dsh-tool-todo` فقط نوع اعتماد؛ فقط يأخذ لم معرفة دمج حدث عمل عام معالجة مستهلك بلا حاجة اعتماد هو.todo حزمة هو حدث payload، عميل نوع، وقت التشغيل تحقق و فتح وضع جولة قاعدة وحيد مصدر.
