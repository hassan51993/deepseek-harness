# Agent Note: حزمة يملك ثابت صيغة خدمة اتفاق

Status: implemented
Archived: 2026-09-04

[English](2026-07-19-package-owned-invariant-service.md) | العربية

## مشكلة

وقت التشغيل ثابت صيغة فحص عبر تجاوز جلسة مسار أثر،agent(ذكي جسم) حالة، أثر مجال dispatch و طلب إعادة بناء. إذا كل فحص كل وضع في واحد تشخيص حزمة في، هذا حزمة حينئذ يجب استيراد ذاك هذا غير متصل منتج مجال مفردات، اختبار أيضا سوف مغادرة فتح حق صحيح كل من؛ أي منتج حزمة إضافة جديدة أو إزالة فحص وقت، كل يلزم تعديل في وسط حزمة.

اختيار تفعيل تشخيص نشر أيضا حاجة مقارنة “هل تحميل واحد إضافة” أكثر دقيق تحكم. هذا صنف تركيب سوف يحمل معروف ثابت صيغة مساهمة، معا سماح عام إغلاق أو حسب حزمة اختيار تشخيص. حزمة قليلا بعد تحميل أو في HMR(حار وحدة استبدال) تحت إعادة تحميل وقت، اختيار نتيجة يجب إبقاء مستقر؛ يتم مرور ترشيح مساهمة أيضا لا يستطيع يجعل اثنان عدد إضافة ساكن صامت احتلال استخدام نفس عدد حزمة اسم.

قد إصدار حزمة كل حق يجب آلة آلة كامل. إذا لا يوجد مستودع قاعدة، حزمة ممكن كشف لا كامل companion، اعتماد أو إصدار خريطة، و واحد مباشر إبقاء ضرر تالف، مباشر إلى صيانة من اكتشاف؛ لا إصدار companion حزمة فإن يجب في README في إبقاء يمكن مراجعة سبب.

## قرار

### واحد سجل التسجيل خدمة، مساهمة عودة حزمة كل

`@deepseek-ai/dsh-invariants` هو و منتج غير متصل Cordis خدمة إضافة، تسجيل `ctx.invariants`. هو فقط مسؤول إعداد، تسجيل وحيد صفة، فرعي fiber دورة الحياة و حمل حزمة ملكية فشل؛ لا استيراد session،agent،scope أو agent-loop حزمة، أيضا لا يتضمن هذه حزمة فحص.

فقط لديه يملك يمكن مستقل مراقبة حدث أو متغير بيانات علاقة وقت، مساحة العمل حزمة عندئذ إصدار `./invariant` مرافق مع إضافة؛ هذا companion سوف تسجيل ذاتي ذات كامل كما دقيق تأكيد npm حزمة اسم. لا يوجد هذا علاقة حزمة سوف حذف companion و إصدار وصل خط، و في README في سجل سبب؛[وقت التشغيل اتفاق Agent Note](2026-07-19-package-invariant-runtime-contracts.ar.md) و[حذف قرار](../simplification/2026-08-28-omit-unneeded-invariant-companions.ar.md) منع توقف توليد احتلال موضع رمز، فارغ installer و دمج صار API شكل حالة تأكيد. حزمة أصل مدخل لن خفي صيغة استيراد أو تسجيل تشخيص، لذلك تحميل أصل حزمة لن تغيير وقت التشغيل فحص، أيضا لا اشتراط ثابت صيغة خدمة وجود.

### إعداد و اختيار

```ts
interface Config {
  enabled?: boolean
  package_allowlist?: string[]
  package_blocklist?: string[]
}
```

قيمة افتراضية لـ `enabled: true`،`package_allowlist: []` و `package_blocklist: []`. مقابل كامل تسجيل اسم اختيار قاعدة لـ:

```ts
export function selected(enabled: boolean, package_allowlist: RegExp[], package_blocklist: RegExp[], packageName: string): boolean {
  return enabled
    && (
      package_allowlist.length === 0
      || package_allowlist.some(pattern => pattern.test(packageName))
    )
    && !package_blocklist.some(pattern => pattern.test(packageName))
}
```

blocklist مطابقة أولوية في allowlist مطابقة. كل بند كل هو منطقة قسم كبير صغير كتابة JavaScript صحيح فإن جدول بلوغ صيغة مصدر، عبر `new RegExp(pattern)` تحرير ترجمة. حذف غير استدعاء جهة توفير `^` و `$`، لا فإن مطابقة لا مرساة تحديد؛ نظام لن تحليل مائل عمود حزمة محيط لغة قاعدة أو flags. خدمة بدء سوف رفض فارغ أبيض، أول ذيل حمل فارغ أبيض، بلا فاعلية أو نفس قائمة داخل تكرار مصدر. لا يوجد مطابقة حالي قد تحميل حزمة صالح مصدر ما زال دمج قاعدة، لأن تسجيل ترتيب، قليلا بعد تحميل و HMR لا ينبغي تغيير إعداد صالح صفة.

### تسجيل و فشل ملكية

عام تسجيل حد هو `ctx.invariants.register(packageName, installer)`. أي جعل مرور ترشيح جهاز منع توقف تثبيت، هو أيضا سوف لـ كل كامل npm حزمة اسم إبقاء وحيد نشط وثب تسجيل، و إرجاع effect disposer. إزالة مرافق مع إضافة أو خدمة كل سوف تحرير تسجيل اسم و الكل مساهمة حالة.

تفعيل installer في خدمة يملك مستقل Cordis فرعي fiber في تشغيل.`InvariantInstaller.inject` صريح إعلان هذا فرعي fiber خدمة API؛ سجل التسجيل لا يحمل منتج مخصص استخدام اعتماد بيانات وصفية. خدمة سوف في تسجيل نجاح قبل انتظار installer إرجاع promise، لذلك مختلف خطوة بدء فحص ما زال أداة لديه أمر خدمة صفة.installer استقبال ربط بعد `fail(message)` تقرير إبلاغ جهاز. استدعاء هو سوف رمي خروج اسم لـ `InvariantError` `Error` فرعي صنف، إبقاء مستقر شفرة `INVARIANT` و سجل تسجيل جهة `packageName`؛ هذا خطأ لا وراثة منتج حزمة في خطأ أساس صنف.

تسجيل بدء هو أمر خدمة صفة. إذا installer في تسجيل مستمع بعد فشل، فرعي fiber سوف كامل تحرير، و في فشل نحو خارج نقل بث قبل حل حذف حزمة اسم احتلال استخدام. يتم مرور ترشيح تسجيل لا إنشاء فرعي fiber، لكن سوف إبقاء احتلال استخدام مباشر إلى dispose(مورد تحرير). مرافق مع إضافة إعادة تحميل وقت مجموع سوف من جاف صاف installer حالة بدء؛ لديه حالة مساهمة من ذلك الذي تابع خدمة إعادة بناء أساس خط.

أصل لديه دالة صيغة إضافة مدخل و مفرد معامل `InvariantError` بنية صنع دالة لا بصفة توافق API إبقاء. مستودع موضع في مسبق إصدار مرحلة مقطع، كل استدعاء جهة سوف واحد بدء ترحيل إلى خدمة و حمل حزمة ملكية خطأ.

### أول دفعة لديه حالة مرافق مع إضافة و كامل كل حق

| مرافق مع مدخل | تسجيل اسم | الذي تابع فحص |
|---|---|---|
| `@deepseek-ai/dsh-session/invariant` | `@deepseek-ai/dsh-session` | جلسة تسلسل، جولة/خطوة حزمة محيط علاقة و نفس خطوة استدعاء/نتيجة مسار أثر |
| `@deepseek-ai/dsh-agent/invariant` | `@deepseek-ai/dsh-agent` | agent حالة تحويل |
| `@deepseek-ai/dsh-scope/invariant` | `@deepseek-ai/dsh-scope` | أثر مجال حدث تحميل جسم وجود و رئيسي جسم متسق صفة |
| `@deepseek-ai/dsh-agent-loop/invariant` | `@deepseek-ai/dsh-agent-loop` | نموذج طلب إعادة بناء |

هذا أربعة عدد كل من توفير أول دفعة لديه حالة فحص. لاحق كل من سوف لـ حقيقي حدث أو متغير بيانات علاقة زيادة companion، لا يوجد هذا علاقة حزمة فإن حذف companion و سجل سبب. كل قد إصدار مرافق مع مدخل كل هو مفرد وحيد تحزيم `./invariant` export، أداة لديه مستقل إعلان و مقابل Loader أمان نطاق الأسماء إضافة شكل.

`verify-package-invariants` سوف اكتشاف كل مساحة العمل حزمة، قبول كامل حذف، و رفض لا كامل companion وصل خط، توليد علامة، فارغ installer، نقص قليل أو لا استخدام فشل تقرير إبلاغ جهاز installer، خارجي أو لا يمكن تحليل تسجيل اسم، ناقص `./invariant` export أو إصدار ملف، ناقص ثابت صيغة مقابل انتظار اعتماد (peer dependency) ، تطوير اعتماد و مشروع مرجع، و متروك تسرب قد إصدار مرافق مع مدخل ذاتي تعريف بناء إعداد.

### أثر مجال حدث دلالة خريطة

توليد أثر مجال حدث رئيسي جسم تحليل جدول يقع في `dsh-scope`، و إزالة استهلاك هو اتفاق و ثابت صيغة متبادل مجاور.`gen-scoped-events` استخدام أصل TypeScript Program قطعة رفع `this: Scoped<Base>` إعلان، من حقيقي `scopeTarget(base, key)` استدعاء دفع قطع توجيه مفتاح نوع، و اشتراط وحيد، بلا اختلاف معنى payload رئيسي جسم أو صريح unsupported علامة. إيداع وقت التشغيل خريطة لا استيراد حدث كل من حزمة، لذلك دلالة كامل صفة لن توسيع كبير خدمة حزمة أو scope حزمة وقت التشغيل اعتماد إغلاق حزمة.

### عرض مثال تركيب و SDK إخراج

`dsh-sdk-minimal` patch سوف هذا خدمة و أربعة عدد لديه حالة إعداد طقم فرعي مسار بصفة صريح إعداد سطر تركيب. فرعي مسار إعداد سطر سوف إضافة يمكن تثبيت أصل npm حزمة، بينما لن يأخذ فرعي مسار خطأ عند صار حزمة اسم. أصل حسب[تسليم إعداد قرار](../simplification/2026-08-03-omit-invariants-from-shipped-config.ar.md) ، تسليم، أساس في base إعداد شجرة سوف حذف هذا خدمة و ذلك إعداد طقم إضافة.

Workspace قيد تعرف آخر مستقل ثابت صيغة bundle؛ حزمة exports، مشروع مرجع، بناء إعداد، اعتماد إعلان و lockfile وصف نفس نسخة إصدار بيانات وصفية. توليد إعداد دليل، وحدة رسم و API وثيقة كل من هذه مصدر إرسال توليد.

## اختبار

خدمة اختبار تغطية قيمة افتراضية، عام إغلاق،allow/block اختيار،blocklist أولوية درجة، مرساة تحديد و غير مرساة تحديد مطابقة، كبير صغير كتابة حساس شعور، بلا فاعلية إعداد، صفر مطابقة نمط، تأخير متأخر تسجيل، تكرار كل حق،dispose، تراجع و HMR إعادة تسجيل. أداة تجهيز يمكن تنفيذ فحص كل من سوف يأخذ صحيح نحو و سالب نحو سلوك إبقاء في companion شفرة المصدر جانب حافة.

تركيب اختبار تغطية معيار رئيسي جاف تحويل إرسال و توليد SDK بند.Loader اختبار ثابت كل مرافق مع نطاق الأسماء، بناء بعد صاف Node خطر دخان اختبار تغطية تحرير ترجمة فرعي مسار export. أثر مجال حدث جديد طازج درجة بوابة سوف إعادة تنفيذ دلالة Program قسم تحليل.

كل Vitest إعداد كل سوف تحميل اختبار مضيف؛ في عادي Cordis أصل سياق بدء رقم واحد إضافة قبل، مضيف سوف تركيب صريح تفعيل خدمة، و في حالي اختبار حزمة وجود مرافق مع إضافة وقت إضافة هو. واحد كامل توسيع اندفاع سوف مرة تركيب كل قد إصدار مرافق مع إضافة؛ خدمة و كل من تجمع تركيز اختبار ذاتي سطر بناء ثابت صيغة توسيع اندفاع، من بينما في لا حدوث تكرار كل حق اندفاع مفاجئ قبل رفع تحت تغطية إغلاق، مرور ترشيح، تراجع و إعادة تحميل. بوابة اختبار أيضا سوف تنفيذ كل قد إصدار مرافق مع إضافة `apply` دالة، و تحقق هو استدعاء `register` وقت استخدام manifest(بيانات وصفية بيان) في حزمة اسم، بينما لا هو فقط فحص شفرة المصدر نص.

## اعتبار مرور بديل خطة

- **يأخذ كل فحص إبقاء في `dsh-invariants`.** غير مقبول، لأن سجل التسجيل ما زال يلزم استيراد كل يتم فحص منتج مجال، كل من تغيير ما زال يحتاج في وسط تحرير، اختبار أيضا متابعة بعيد مغادرة يتم حفظ حماية اتفاق.
- **عند `ctx.invariants` تماما جيد وجود وقت، يجعل أصل حزمة مدخل خفي صيغة تسجيل فحص.** غير مقبول، لأن أصل مدخل سلوك سوف اعتماد تركيب ترتيب و اختياري خدمة هل وجود، تشخيص لا يمكن مستقل اختيار، بينما كما حزمة تحميل سوف إخفاء واحد لا في صريح مرافق مع إضافة في تسجيل effect.
- **في وقت التشغيل تلقائي اكتشاف كل `invariant.ts` ملف.** غير مقبول، لأن نظام الملفات أو حزمة اكتشاف لا هو وقت التشغيل كل حق اتفاق، سوف يجعل bundle إصدار يحتوي معنى لا صاف، أيضا لا يمكن جدول بلوغ صريح Cordis تحميل ترتيب أو اعتماد تثبيت. بناء مدة توليد و تحقق و اختبار مضيف يمكن قطعة رفع شفرة المصدر شجرة، لأن هو جمع تحقق هو مستودع كامل صفة، بينما لا هو تركيب قد إصدار نشر.
- **أصل حسب حالي قد تحميل حزمة تجميع دمج تحقق allow/block بند.** غير مقبول، لأن صفر مطابقة نمط ممكن متعمد إشارة نحو قليلا بعد تحميل أو HMR تحميل مساهمة؛ حالي تحميل ترتيب لا يستطيع قرار إعداد صالح صفة.

## عاقبة

- منتج حزمة يملك و اختبار ذاتي ذات علاقة تأكيد، خدمة إبقاء و منتج غير متصل.
- فقط لديه أداة تجهيز متعمد معنى وقت التشغيل علاقة كل من عندئذ تحمل تحمل companion إصدار، اعتماد،listener أو trace حالة صار هذا؛ أخرى حزمة في README في سجل حذف سبب.
- تركيب تشخيص تركيب بلا حاجة تغيير إضافة شجرة يكفي إغلاق الكل فحص أو حسب حزمة اسم اختيار.
- صريح مرافق مع بند يجعل تشخيص صار هذا و كل حق في Cordis إعداد و حزمة export في مرئي.
- كل اختيار في مساهمة زيادة واحد فرعي fiber و ذلك listener/حالة صار هذا، يتم مرور ترشيح تسجيل فإن فقط إبقاء حزمة اسم احتلال استخدام.
- صحيح فإن جدول بلوغ صيغة مصدر يخص نشر إعداد، في خدمة إعادة تحميل قبل إبقاء ثابت.
- حالي اختبار حزمة إصدار مرافق مع إضافة وقت، عادي Vitest أصل سياق سوف تثبيت منها يتم اختيار في مرافق مع إضافة؛ واحد كامل توسيع اندفاع فقط دعم دفع مرة الكل فرعي fiber صار هذا، لأجل تغطية كامل مستودع تسجيل.
- جلسة تخزين تحقق، لقطة، تجميد ربط، مرجع مصدر حدث تحقق و surface قبول قاعدة بداية نهاية تفعيل، لا تلقي ثابت صيغة اختيار أثر.
