# Agent Note: ربط دورة الحياة رسالة عكس تغذية مرافق مع سجل

Status: implemented
Archived: 2026-09-04

[English](2026-08-10-message-feedback-sidecar.md) | العربية

## مشكلة

قائم `/feedback` أمر سجل غير ممكن تغيير Session درجة `feedback/record` حدث. في `FEEDBACK_ONLY` تحت، هذا حدث يمكن تحرير انتظار معالجة بعيد قياس بادئة، لذلك هو لا ملائم دمج بصفة تعليق في مفرد بند assistant رسالة فوق يمكن تحرير جيد تقييم/فرق تقييم و اختياري ملاحظة مرجعي مصدر. رسالة عكس تغذية حاجة مستقل تحديث و حذف دلالة، كما لا نيل دخول مرجعي Session سجل، تغيير إسقاط، وصول نموذج سياق، أو خفي صيغة يمثل بعيد قياس نفس معنى.

فقط حسب `SessionId` بناء بحث جذب مرافق مع سجل ممكن في هذا id بـ مختلف header هوية إعادة بناء بعد، متابعة تخزين نشط في ذلك الذي وصف سجل دورة الحياة خارج.Session درجة revision أيضا سوف يجعل غير متصل رسالة تحرير ذاك هذا اندفاع مفاجئ، بينما عادي storage-domain قراءة/كتابة لا توفير عبر عملية compare-and-swap.Session disposal فقط هو من live store انفصال مغادرة، و غير حمل دائم حذف؛ حالي Session حفظ دائم seam أيضا لا يوجد يمكن يملك حقيقي درجة ربط حذف عملية.

## قرار

`@deepseek-ai/dsh-message-feedback` يملك `ctx.messageFeedback` خدمة، و يأخذ رسالة عكس تغذية تخزين لـ كل Session واحد بند storage-domain مرافق مع سجل (sidecar). هذا مرافق مع سجل حيث لا هو Session سجل محتوى، أيضا لا هو Session إسقاط. هو لا إرسال خروج `feedback/record` حدث، أيضا لا تنفيذ بعيد قياس تسليم وصل؛command-feedback و message-feedback اتفاق إبقاء مستقل.

كل بند متاح سجل كل ربط إلى مرور فحص Session header هوية `{createdAt, cwd}`، بينما لا فقط هو ذلك `SessionId`. دورة الحياة لا مطابقة حسب لا وجود معالجة:`list` إرجاع فارغ بند،`put` يمكن استخدام ربط حالي هوية جديد سجل استبدال قديم قديم سطر. لذلك، بـ مختلف header هوية إعادة استخدام id لن وراثة قديم قديم عكس تغذية.fork يملك ذاتي ذات Session هوية، كما لا نسخ مرافق مع سجل: أي جعل fork نوع فرعي يتضمن نفسه assistant رسالة، عكس تغذية ما زال فقط يخص شخص صنف سجل هو ذلك عدد Session.

`put` فقط في يتم مراقبة قياس سجل——live يحتفظ من داخل تخزين حدث، لا فإن هو مرور من حفظ دائم قراءة جملة مقبض قراءة حمل دائم سجل——يتضمن غير فارغ،append-origin كما `MessageId` و هدف نفسه `assistant/message` وقت عندئذ قبول هذا هدف.replacement-origin رسالة، فقط تحمل تحميل usage فارغ assistant سجل و غير assistant هدف كل سوف يتم رفض. مراقبة قياس هو cold-safe : هو لن فقط لـ تحقق عكس تغذية بينما إصدار أو استعادة Agent، أيضا لن إيداع cold سجل إصلاح.cold مسار من `stat()` مسبق فحص واضح لا وجود؛ قد دخول دليل Session إذا قراءة فشل، ما زال حسب أساس أساس ضبط تطبيق لذا عائق معالجة. لذلك، طلب إذا تماما سقوط في live detach إلى header materialization أقصى قصير نافذة، ممكن إرجاع `session-not-found`، استدعاء جهة في retirement materialization بعد إعادة محاولة.

`put` إيداع مرافق مع سجل قبل، سوف أولا يجعل هدف سجل عبر durability barrier. هوية مطابقة live Session مرور مرور مرجعي `ctx.sessions.flush` checkpoint، مع بعد live و cold مسار كل سوف عبر جديد فتح حفظ دائم قراءة جملة مقبض من تسلسل صفر فعل شيء إدارة تكرار قراءة. بعد مجددا مرة تحقق الذي نيل مراقبة قياس header هوية و هدف. نقص قليل flush مشاركة و جهة، هوية تغير، هدف إزالة فقد أو شيء إدارة قراءة فشل كل سوف منع توقف مرافق مع سجل كتابة، لذلك قد إيداع عكس تغذية أبدا سوف أولا في هو مرجع حمل دائم assistant رسالة.

كل رسالة بند كل يحمل ذاتي ذات opaque version، و Host قسم إعداد `createdAt` و `updatedAt` ختم الوقت.`put` فقط يأخذ استدعاء جهة `ifVersion` و هدف بند مقارنة مقارنة، لذلك تحرير واحد بند رسالة لن جعل آخر بند رسالة بطلان. أي جعل هدف قيمة قد نفسه، مقارنة مقارنة ما زال صارم إطار تنفيذ، من بينما منع توقف قديم قديم طلب اختراق مرور ABA قيمة حلقة؛ اندفاع مفاجئ سوف إرجاع مرجعي حالي بند، استدعاء جهة بلا حاجة اثنان مرة قراءة يكفي تنسيق ضبط. يحمل مطابقة version بلا تغير طلب سوف إبقاء version و ختم الوقت؛ فعلي جودة تحديث إبقاء `createdAt`، استبدال version، و حفظ إثبات `updatedAt` لا قلب تراجع. حذف قد لا وجود بند أيضا نفس مثال نجاح.version هو فقط قدرة فعل متبادل انتظار مقارنة مقارنة token، لا هو استدعاء جهة يمكن ترتيب ترتيب أو ذاتي سطر دمج صار حساب عدد جهاز.

حسب Session تخطيط قسم تغيير طابور صف تغطية دورة الحياة فحص، مرافق مع سجل قراءة، اندفاع مفاجئ حكم قطع و كامل سطر كتابة. هذا جعل نفس عدد خدمة نسخة تغيير سلسلة سطر تحويل، و في مفرد عدد Host عملية داخل إبقاء تدريجي رسالة compare-and-swap اتفاق.Plugin disposal سوف إغلاق وصل قبول، ترتيب فارغ قد دخول طابور صف عمل، لكن بعد إغلاق storage domain. قاع طبقة storage-domain API لا توفير عبر عملية شرط كتابة، لذلك تنفيذ لا تحمل وعد عبر عملية خط صفة متسق صفة أو منع توقف فقد فقد تحديث.

`maxNoteBytes` هو لا بد ملء نشر اختيار، لأجل حد اختياري ملاحظة UTF-8 بايت طويل درجة؛Web Host bundle سوف ذلك صريح ضبط لـ `8192`. هذا حزمة عبر `TypertRemoteService` و `@Remote` مباشر إصدار Host `messageFeedback.list`،`messageFeedback.put` و `messageFeedback.delete` اتفاق. عميل Remote تجمع دمج تركيب و UI من كل منها حد مسؤول و إبقاء تأخير بعد؛ لاحق ملائم إعداد طبقة فقط هو هذا Host اتفاق رقيق إزالة استهلاك من.

خدمة لا زائف صنع حذف درجة ربط.`session/disposed` و `host/session-removed` يمثل انفصال مغادرة live ownership، بينما غير حمل دائم حذف،Session persistence حالي أيضا لا يوجد حذف واجهة. لذلك في حمل خارج إزالة سجل بعد، مرافق مع سجل ممكن متابعة وجود؛ مختلف `{createdAt, cwd}` يمكن منع توقف هذا صنف متروك إبقاء سجل تغيير صار بعد قدوم إعادة استخدام هذا id Session عكس تغذية.

## اعتبار مرور بديل خطة

**يأخذ تحرير إلحاق إلى Session سجل و إرسال توليد إسقاط.** غير مقبول، لأن يمكن تحرير UI بيانات وصفية سوف تغيير صار مرجعي كما مجاور قريب محادثة تاريخ،fork سوف إعادة تشغيل و وراثة هو، حذف حاجة tombstone، بينما إعادة استخدام `feedback/record` سوف يأخذ رسالة تقييم قسم و بعيد قياس نفس معنى ساكن صامت اقتران دمج.

**حسب عام `MessageId` بناء بحث جذب، في fork وقت نسخ، أو استخدام واحد Session revision.** غير مقبول، لأن رسالة id فقط في بعض عدد Session دورة الحياة داخل متعمد معنى،fork بعد محادثة حاجة مستقل شخص صنف حكم قطع، بينما كما غير متصل رسالة تغيير لا ينبغي صنع صنع وهمي زائف اندفاع مفاجئ.

**في هذا مرة تغيير في لـ `KvTable` توسيع عبر عملية compare-and-swap.** غير مقبول، لأن قائم storage-domain خلفية لا يوجد مشترك نفس شرط كتابة أصل لغة. عملية داخل طابور صف رمز دمج تلقي دعم حمل مفرد Host توسيع اندفاع؛ حقيقي كثير عملية حفظ إثبات حاجة خلفية درجة أصل فرعي اتفاق، يخص مستقل عمل.

**في Session disposal وقت حذف عكس تغذية.** غير مقبول، لأن disposal يتضمن عادي detach و rollback مسار. يأخذ هو عند صار حمل دائم حذف سوف في Session سجل ما زال وجود وقت فقد فقد عكس تغذية؛ تنظيف يجب انتظار حق صحيح Session حذف مرجعي.

## عاقبة

رسالة عكس تغذية في محلي حفظ دائم و يمكن مستقل تحرير، كما لا تغيير نموذج مرئي تاريخ أو بعيد قياس سلوك. نفس Host في تزامن استدعاء جهة نيل نيل تدريجي رسالة اندفاع مفاجئ فحص قياس و يمكن أمان إعادة محاولة نتيجة؛ كثير عدد كتابة من مشترك نفس تخزين أصل دليل نشر ما زال لا تلقي دعم حمل. مختلف header هوية سوف يجعل قديم قديم سجل يتم نظر لـ لا وجود، لكن لن سوف ذلك عودة استلام؛ هذا اتفاق لا يمكن منطقة قسم إبقاء نفسه `{createdAt, cwd}` تغلب ضخم سجل.Host Remote اتفاق الآن متاح؛ عميل تجميع و UI يمكن إبقاء لـ رقيق إزالة استهلاك من، بينما لا وصل إدارة حفظ دائم أو تزامن دلالة.
