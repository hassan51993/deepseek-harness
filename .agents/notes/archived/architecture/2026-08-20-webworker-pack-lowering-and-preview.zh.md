# Agent Note: pack مدة lowering و مفرد بناء preview

Status: implemented
Archived: 2026-09-04

[English](2026-08-20-webworker-pack-lowering-and-preview.md) | العربية

## مشكلة

متصفح worker حيث لا يستطيع في تركيب تحميل مدة تحرير ترجمة وحدة، أيضا لا يستطيع من منتج webserver توفير صفحة: كل وحدة جسم يجب بـ يمكن مباشر تشغيل شكل وصول، صفحة يجب هو ساكن حالة ناتج. اثنان عدد وجه مبكر مدة كل حدوث مرور عائم نقل. تركيب تحميل جهاز سبق يحمل واحد التقاط قاع تحرير ترجمة جهاز، في هو استلام تجميع جهاز نقص فتحة جدول الآن لـ «بدء تغيير بطيء» بينما لا هو «مرآة مثل تالف»——بينما كما `acorn` مرور حزمة barrel خلط دخول `lib/worker.js`، واحد فقط حزمة تركيب مسبق lowered وحدة جسم وقت التشغيل أصل هذا لا حاجة محلل.preview سبق هو خدمة صفحة جانب ثاني نسخة HTML نموذج لوح، واحد served index يمكن صامت صامت عائم مغادرة صفحة.

## قرار

**Lowering فقط حدوث في pack مدة.** `@deepseek-ai/dsh-experimental-webworker-packer` تركيب profile، شيء تحويل إغلاق حزمة،lower كل JavaScript وحدة جسم؛`LOWERING_VERSION` و `WRAPPER_PARAMS` هو pack↔worker عقد نحو، و مرآة مثل تخطيط ذلك بقية جزء واحد بدء وضع في `src/image-layout.ts`. تركيب تحميل جهاز تماما حسب مرآة مثل يحتفظ شكل حزمة تركيب وحدة جسم: ما زال حمل وحدة لغة قاعدة وحدة جسم هو مرة نقطة اسم مرآة مثل رفض، كما `startWorkerHost` في تركيب أي وحدة قبل اشتراط manifest `lowered` انتظار في هذا بناء عقد نحو.`lowerModuleSource` هو تحويل جهاز وحيد وجه،packer هو هو وحيد استدعاء جهة؛ نفس مرة تحليل سوف يأخذ أداة اسم ساكن حالة import،re-export و حركة حالة import، مرور `require` إرسال بدء استدعاء، و عبر `node:module` أو `module` أداة اسم استيراد في وحدة أثر مجال مباشر إرسال بدء `createRequire(import.meta.url)('pkg')` استدعاء إرسال دخول يمكن بلوغ صفة مرة تاريخ. حفظ تحت قدوم نتيجة، مرور CommonJS نيل أخذ `createRequire`، حساب حساب نيل إلى طلب اسم و أخرى أساس دقيق فقط في وقت التشغيل تحليل؛ فقط قدرة عبر هذه شكل صيغة لمس بلوغ هدف حاجة مرآة مثل مدخل نوع فرعي.worker رسم داخلي import واحد قاعدة إشارة نحو يملك هذا قيمة وحدة——أبدا إشارة نحو حزمة barrel، ذلك صحيح هو يأخذ محلل سرقة تشغيل دخول قدوم ذلك بند حافة. شفرة المصدر دليل ترتيب حذف فقط لأجل تشغيل مدة استخدام قد بناء `lib/` workspace و vendored حزمة؛ قد تثبيت رقم ثلاثة جهة حزمة سوف إبقاء `src/` و `dist/` تحت JavaScript، لأن ذلك إصدار مدخل ممكن تحليل إلى هذه موضع.

**preview حينئذ هو خدمة صفحة إضافة واحد وسم.** مرة Vite بناء إنتاج خروج مشترك الكل chunk `dist/index.html` و `dist/preview.html`؛ وحيد فرق مختلف هو قبل إدراج واحد جذب استيراد فتحة، ذلك وحدة مسؤول اتصال worker host. بدء مع لـ تجميع في واحد بروتوكول: تطبيق حقن جدول واحد جهة settle `__DSH_BOOT_READY__` deferred——served مصير في تصيير تمام سطر بعد استخدام ذيل جزء نص برمجي resolve،worker جذب توجيه مقطع في أول عدد await قبل تثبيت، نهاية سطر توليد فاعلية بعد settle——client مدخل في قراءة أي حقن حالة قبل await هو، لذلك من معيار مدخل بدء سلسلة مسار تدريجي حرف حينئذ هو served سلسلة مسار. إضافة combo نص برمجي و map كل عبر tunnel؛ صفحة جانب loader سوف في تنفيذ نص برمجي Blob قبل، يأخذ كل فقط tunnel يمكن بلوغ map داخل تضمين لـ Base64 data URL، من بينما لا اعتماد آخر بند object URL دورة الحياة، و في DevTools في إبقاء indexed map مكون اسم. بناء استخدام متبادل مقابل base، ناتج يمكن تركيب في مهمة معنى ساكن حالة دليل؛served شكل في serve مدة تصيير `<base href="/">` مرساة تحديد عميق طبقة SPA fallback مسار، مغناطيس قرص فوق اثنان عدد صفحة إبقاء بايت مشترك.

**مستودع preview يحمل اختياري اختيار نظام الملفات مصدر.** Packer إنتاج خروج واحد نسخة أساس أساس مرآة مثل، و لـ كل طقم أداة اسم داخل وضع fixture إنتاج خروج واحد نسخة صغير نوع overlay عودة ملف. لا يوجد مصدر query وقت،`preview.html` سوف توقف في اختيار وجه لوح، اختياري اختيار فارغ نظام الملفات، داخل وضع fixtures، أو عودة آخر تنفيذ كل WebFS provider. دمج قاعدة `preview-fixture=none|<built-in-id>` query سوف مباشر اختيار و قفز مرور وجه لوح، توفير تحديد صفة متصفح مسار استخدام؛ هذا مستقل اسم تجنب فتح Client قائم `fixture` transport فتح صلة.Worker أولا تركيب أساس أساس مرآة مثل، مجددا حسب ترتيب يأخذ الذي اختيار overlays تطبيق إلى فقط حد `home/` و `workspace/` مسار، مع بعد عندئذ تحقق أساس أساس manifest و بدء Cordis.`packages/experimental/webworker-runtime/tests/fixtures/vfs-example/` توفير منها واحد طقم داخل وضع overlay،Packer بلا حاجة إدارة حل Session أو Workspace. واضح نص JSONL سجل استخدام persistence backend حقيقي project/session دليل تخطيط، لذلك Session Persistence سوف بارد قراءة هو جمع،Workspace Registry فإن أصل حسب ذلك `/dsh/workspace` header إرسال توليد Workspace. رئيسي Session تجاوز مرور Client 50-message page، و يأخذ بديل جدول صفة أداة نتيجة إبقاء في ذيل صفحة؛ حفظ دائم one-shot و continuable child لأجل تحقق subagent catalog.WebFS تخويل و مستخدم بيانات ما زال يخص مستقل provider، أبدا و هذا fixture مشترك استخدام دليل.

اثنان عدد حزمة بـ `@deepseek-ai/dsh-experimental-*` اسم معنى وضع في `packages/experimental/`، خاص كما في رسمي جهة إصدار خارج. تحمل تحميل منتج تحمل وعد حد ما زال في منتج حزمة داخل: حقن جدول،`__DSH_TRANSPORT__` و `/plugins` bundle بايت من `dsh-host-webserver`،`dsh-client-modules`،`dsh-client-connection` يملك.

## سبق اعتبار بديل خطة

**إبقاء تركيب تحميل مدة تحويل جهاز عمل أمان شبكة.** هو يأخذ تالف مرآة مثل تغيير صار بلا شخص عودة بسبب استهلاك وقت ارتداد، و كما يجعل «هذا عدد وحدة جسم هو من lower » من خارجي غير ممكن عودة جواب.

**عقد نحو معتاد كمية إبقاء في تحويل جهاز داخل، معلومة مهمة tree shaking.** تحويل دالة تأكيد فعلي يتم هز إسقاط، لكن `acorn` لم إعلان `sideEffects`، فقط barrel واحد بند حافة حينئذ يأخذ كامل محلل حمل دخول worker bundle.

**مستقل preview نموذج لوح.** قد تراجع دور `preview.html` نموذج لوح نسخ خدمة وثيقة تزامن توليد عائم نقل (لغة، عنوان، مدخل وصل خط). في `closeBundle` من built index إرسال توليد صفحة فإن تام قاع إزالة إطفاء ثاني نسخة وثيقة.

**استخدام قمة طبقة await ترتيب بينما غير deferred ذهاب بوابة معيار مدخل.** أخ أخ module script متبادل لا انتظار مقابل جهة قمة طبقة await؛`??=` تثبيت deferred جعل إمساك يد و طلب قيمة ترتيب غير متصل، كما فشل إمساك يد قدرة reject دخول boot صفحة فشل عرض.

**في Worker بدء وقت توليد عرض مثال حالة.** Preview مخصص استخدام Session أو Workspace إنشاء فرع سوف التفاف مرور بارد persistence قراءة، أيضا سوف يجعل runtime يملك اختبار بيانات. ساكن حالة مرآة مثل ملف و قائم مستخدم بيانات مرور مرور نفسه اكتشاف و قسم صفحة مسار.

**عبر WebFS حقن عرض مثال.** WebFS يملك مستخدم اختيار تحديد durable storage و ذلك دورة الحياة. يجعل داخل وضع عرض عرض اعتماد هو، سوف جعل ساكن حالة preview تلقي متصفح حفظ دائم حالة أثر، و نموذج غامض أي بعض بايت قدوم ذاتي نشر.

**كل طقم fixture كل ضرب واحد نسخة كامل أساس أساس مرآة مثل.** كامل مرآة مثل تغيير جسم سوف تكرار runtime package closure، و جعل تركيب عدد كمية مستو جهة زيادة طويل. تلقي حد overlay فقط إبقاء واحد غير ممكن تغيير أساس أساس مرآة مثل، اختيار وجه لوح يمكن تركيب صفر إلى كثير عدد بيانات مصدر، لم قدوم WebFS ماء دمج أيضا قدرة إعادة استخدام نفس عدد pre-boot تطبيق نقطة.

## عاقبة

- `lib/worker.js` لا يحتوي محلل (عند سكين سقوط وقت لـ 423.5 kB → 246.3 kB، مبكر في shell عملية طبقة سقوط أرض).
- `diff dist/index.html dist/preview.html` تماما لـ واحد script وسم؛`packages/experimental/webworker-packer/tests/image-loadable.spec.ts` تثبيت إقامة تركيب تحميل جهاز عقد نحو اثنان نصف،transform دلالة طقم عنصر تثبيت إقامة `createRequire` طلب اكتشاف،`apps/web/tests/preview-boot.e2e.ts` فإن في web متصفح عربة طريق تثبيت إقامة preview متاح صفة (boot إلى يمكن تفاعل صفحة) ، بديل قد سحب تحرير `apps/web/scripts/preview/` استكشاف إبرة نص برمجي.
- تحويل corpus سوف أولا عبر Node استيراد كل قد بناء bundle، مجددا مقارنة مقارنة lowered export. ثابت إعفاء تجنب سوف نقطة اسم حق صحيح غير ممكن استيراد bundle، و في ذلك استعادة يمكن استيراد وقت فشل:`win32-process` هو Koffi نوع owner و تحمل تحمل تكرار نوع إعفاء تجنب؛`sandbox-windows-acl` يمكن صحيح معتاد استيراد، لا تحمل تحمل هذا إعفاء تجنب.
- served `<base href="/">` مرساة وجود سبب هو: متبادل مقابل مورد إنتاج URL في SPA fallback عميق مسار تحت سوف تحليل دخول طلب دليل؛ فقط لديه و متبادل مقابل بناء base واحد بدء عندئذ يمكن إزالة هو.
- مرآة مثل بـ تحديد صفة gzip ضغط tar تسليم (`vfs-image.tar.gz`؛MTIME 0،OS بايت 0xff): ساكن حالة حمل إدارة لا ضغط اثنان دخول صنع content-type(نوع أبيض اسم مفرد،CDN مقياس قياس قبعة) ، ضغط يجب مع صنع صنف مشي؛worker استخدام متصفح أصلي `DecompressionStream` في تحت تحميل معا حل ضغط fetch body.
- Preview سوف توقف في pre-boot مصدر اختيار وجه لوح. داخل وضع عرض مثال توفير يمكن تكرار الآن Workspace و بارد Session لغة مادة، بلا اعتماد، صفر نموذج استدعاء يكفي فحص أداة بطاقة،subagent تنقل و نحو قبل قسم صفحة؛ فارغ أبيض خيار إبقاء أول مرة بدء تغطية.Fixture اختبار عبر إنتاج reader تحقق شيء إدارة سجل، متصفح تحقق استلام معا تحقق اثنان نوع اختيار.
