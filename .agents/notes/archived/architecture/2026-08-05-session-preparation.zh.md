# Agent Note: إصدار قبل يمكن إعادة استخدام Session دقيق تجهيز مرحلة مقطع

Status: implemented
Archived: 2026-09-04

[English](2026-08-05-session-preparation.md) | العربية

## مشكلة

جديد بناء و حفظ دائم استعادة عبر مختلف بنية صنع مسار مقاومة بلوغ نفسه إصدار حد. هذا جعل واحد بند صلة مفتاح ثابت كمية لا كاف صاف واضح: ضبط يجب أساس في واحد لم إصدار Session إتمام، بعد نظام عندئذ قدرة معا عام هذا عدد دقيق Session و ذلك agent.

بارد تاريخ فحص و agent(ذكي جسم) استعادة أيضا سبق قسم آخر فعلي جسم تحويل نفس نسخة حمل دائم جلسة سجل، هذا Note الأكثر أول بـ حفظ دائم جانب قد دقيق تجهيز Session ذاكرة مؤقتة عودة جواب هذا واحد نصف مشكلة؛ ذلك واحد نصف قد في تحت نص في يتم يحل محل.

## قرار

`SessionPreparation` يحتفظ واحد دقيق لم إصدار `Session`، مباشر حتى إصدار أو تراجع. هو يخص Session دورة الحياة، لا يخص agent دورة الحياة أو تنشيط آلية. جديد بناء مسار حزمة تركيب `SessionStore.prepare()` نتيجة؛ حفظ دائم استعادة عبر هذا جلسة كتابة جملة مقبض قراءة قد تخزين سجل، إلحاق `interruptedTurnClosers`، مجددا حزمة تركيب `SessionStore.prepare(id, { seed, meta, seedSource: 'persistence' })`——أي حينئذ أرض تحقق و تجميد ربط تحويل نقل كائن رسم استعادة فرع.

agent loop(ذكي جسم حلقة) عبر نفس بند ضبط و إصدار خط الإنتاج إزالة استهلاك هذا اثنان نوع شكل صيغة: أولا أخذ نيل دقيق تجهيز كائن، محيط التفاف `preparation.session` بناء خاص agent سياق، انتظار اختياري ضبط إتمام، مجددا إصدار هذا دقيق Session و agent، و في كل خروج مسار فوق مقابل دقيق تجهيز كائن تنفيذ dispose(مورد تحرير). إصدار بعد، فوري دورة الحياة من قائم Session و agent تخزين وصل إدارة؛`SessionPreparation` ذاته لا مسؤول أي agent سلوك.

هذا آلية دقيق تحويل [agent دورة الحياة و كل حق قرار](2026-06-18-agent-lifecycle-and-ownership-contracts.zh.md) في إصدار حد، لكن لا استبدال ذلك كل حق نموذج.

## قد يتم يحل محل: حفظ دائم جانب دقيق تجهيز دورة الحياة

هذا Note الأكثر أول أيضا منح إعطاء حفظ دائم واحد `prepare(id)`/`inspect(id)` دورة الحياة: من تنسيق ضبط جهاز دعم دعم، تركيب لديه بارد لم إصدار Session محدود LRU، حمل وحيد احتلال مسبق إبقاء، حسب revision تحقق إعادة استخدام، و في `prepare`/`load` داخلي إيداع إصلاح، جعل تاريخ قسم صفحة و لاحق استعادة مشترك مرة بارد فعلي جسم تحويل.[أساس في جملة مقبض حفظ دائم seam](2026-08-27-handle-based-session-persistence.zh.md) حذف هذا واحد قطع: حفظ دائم فقط كشف جملة مقبض، استعادة عبر ذلك كتابة جملة مقبض قراءة سجل و ذاتي سطر مسؤول إصلاح، فقط قراءة مراقبة جهة (session-query) يملك ذاتي ذات بارد Session ذاكرة مؤقتة، بـ `stat().revision` تغيير أمر لوحة لـ مفتاح. قراءة إعادة استخدام هدف في هذا ذاكرة مؤقتة في نيل بـ تأخير متابعة؛ وحيد احتلال مسبق إبقاء آلية فإن لا يوجد تأخير متابعة، لأن كتابة جملة مقبض مفرد كتابة من كل حق صحيح هو استعادة حق صحيح حاجة ترتيب هو يد مقطع. في قد دقيق تجهيز ذاكرة مؤقتة لديه وقت قدرة توفير دافئ Session مشهد تحت، استعادة يلزم لـ عبر جملة مقبض مرة كل سجل قراءة دفع خروج بديل قيمة——هذا هو جملة مقبض Note في سجل، قد يتم قبول صار هذا.

## حد

- دقيق تجهيز كائن هو واحد يمكن dispose كل حق نافذة، بينما لا هو ذاكرة مؤقتة:dispose تزامن كما قوة انتظار، إصدار فقط قبول دقيق قد دقيق تجهيز Session.
- جديد بناء مسار أبدا خفي صيغة إقرار قيادة حفظ دائم هوية. حفظ دائم اندفاع مفاجئ ما زال سوف يتم رفض (`SessionAlreadyExistsError`،`SessionAlreadyOwnedError`).
- فوري Session من قائم تخزين يحتفظ؛ دقيق تجهيز كائن فقط يحتفظ لم إصدار Session.

## تحقق

agent loop اختبار تغطية create،`createAgent` و resume بين موحد واحد إصدار خط الإنتاج، يشمل ضبط فشل وقت تراجع، إلغاء و تنظيف، و dispose سوف تحرير كتابة جملة مقبض (إعادة بـ كتابة نمط فتح يمكن نجاح).Session store اختبار تغطية استعادة فرع حينئذ أرض تحقق و تجميد ربط كل حق تحويل نقل.

## اعتبار مرور بديل خطة

**من تاريخ قراءة تنشيط agent.** لا اعتماد، لأن قسم صفحة سوف جعل فقط لأجل استعلام agent طويل مدة إبقاء فوري حالة، و يأخذ ذاكرة مؤقتة خروج مشكلة تحويل نقل إلى agent دورة الحياة. هذا إدارة من ما زال حراسة حماية حال session-query بارد ذاكرة مؤقتة: مراقبة أبدا إنشاء agent.

**فقط ذاكرة مؤقتة `{ meta, events }`.** عند وقت لا اعتماد، لأن استعادة ما زال يحتاج من ذاكرة مؤقتة قيمة إعادة بنية صنع Session. في جملة مقبض seam تحت، هذا تماما جيد هو قراءة جانب فعل قاعدة——session-query حسب revision لـ فقط قراءة استخدام طريق ذاكرة مؤقتة واحد بارد Session——بينما استعادة فإن من جملة مقبض قراءة إعادة بناء، بـ دافئ Session إعادة استخدام تبديل أخذ وحيد كتابة كل حق لـ باب.

**في agent loop في زيادة استعادة أمر خدمة أو تنسيق ضبط جهاز.** لا اعتماد، لأن بارد قراءة و Session بنية صنع يخص حفظ دائم و Session مسؤولية.agent loop فقط حاجة موحد واحد `SessionPreparation` كل حق حد؛ جملة مقبض seam إبقاء هذا واحد قسم عمل، معا يأخذ إصلاح نقل دخول حلقة استعادة مسار.

## عاقبة

جديد بناء و استعادة مشترك نفس إصدار بروتوكول، معا إبقاء agent و Session مسؤولية قسم مغادرة، كما كل بند خروج مسار تماما جيد dispose واحد دقيق تجهيز كائن. هذا Note الأكثر أول سجل حفظ دائم جانب إعادة استخدام عاقبة (مشترك بارد فعلي جسم تحويل،LRU حد أعلى، مسبق إبقاء تنسيق ضبط) مثل اليوم ملكية في[جملة مقبض Note](2026-08-27-handle-based-session-persistence.zh.md) و يحل محل هو جمع session-query ذاكرة مؤقتة.
