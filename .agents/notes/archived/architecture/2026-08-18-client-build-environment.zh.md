# Agent Note: Client عمل خدمة شفرة استخدام بناء مدة عام بيئة متغير

Status: implemented
Archived: 2026-09-04

[English](2026-08-18-client-build-environment.md) | العربية

## Problem

متصفح عمل خدمة حزمة حاجة حسب نشر بناء اختيار ساكن حالة سلوك، لكن Web client لديه اثنان بند متبادل لا يتضمن ناتج مسار:Vite بناء ساكن حالة قشرة، مشترك tsdown preset بناء وقت التشغيل تحميل حركة حالة إضافة. فقط في واحد بند مسار استبدال بيئة متغير سوف جعل نفسه عمل خدمة جدول بلوغ صيغة بسبب الذي في حزمة نوع مختلف بينما إنتاج مختلف نتيجة.

متصفح لا يوجد Node `process`، بينما يأخذ بناء عملية كامل بيئة كائن وضع دخول ناتج سوف تسرب كشف و قبل طرف غير متصل قيمة. وقت التشغيل إعداد أيضا لا يستطيع دقيق تأكيد جدول بلوغ بناء تغيير جسم، لأن ناتج إصدار بعد لا ينبغي مجددا تغيير هذا صنف اختيار.

## Decision

`DSH_CLIENT_*` هو يمكن عام إعطاء متصفح عمل خدمة شفرة بناء مدة نطاق الأسماء. عمل خدمة شفرة متاح ساكن حالة نقطة وصول `process.env.DSH_CLIENT_NAME` اختيار سلوك؛ قيمة فقط أخذ ذاتي بناء عملية بيئة، لا قراءة Vite `.env*` ملف. ضبط قيمة في بناء وقت داخل ربط لـ نص، لم ضبط قيمة لـ `undefined`.

Vite إعداد و حركة حالة client bundle مشترك tsdown preset استخدام نفس define توليد جهاز. توليد جهاز فقط لـ `DSH_CLIENT_*` إنشاء دقيق استبدال، و يأخذ ذلك بقية `process.env` قراءة استلام جمع إلى فارغ كائن؛ متصفح لا نيل نيل عام `process`، حركة حالة مفتاح قراءة أو بيئة قطعة رفع قدرة.

`DSH_CLIENT_*` اسم ذاته يمثل عام صفة. اعتماد، مسار و أخرى فقط توفير Host أو CI استخدام قيمة لا نيل استخدام هذا بادئة.

أصل بناء حزمة تركيب نص برمجي نحو اثنان عدد bundler توفير نفس نسخة دقيق عام بيئة. كل مرة كامل بناء كل بـ `DSH_CLIENT_VERSION` يحمل أصل حزمة إصدار، و بـ `DSH_CLIENT_COMMIT_HASH` يحمل شفرة المصدر Git HEAD سبعة موضع بادئة؛ لا يوجد مستودع بيانات وصفية بناء بيئة يمكن صريح توفير commit. افتراضي محلي بناء أيضا سوف في بناء قبل قراءة Git حالة؛ وجود أي مؤقت تخزين، لم مؤقت تخزين، لم تتبع أثر أو فرعي وحدة تغير وقت ضبط `DSH_CLIENT_GIT_DIRTY=true`. لا يوجد تغير worktree و لا يوجد Git بيانات وصفية شفرة المصدر لا يحمل dirty حقل. هذه من مستودع يحتفظ حقل سوف استبدال وراثة قيمة، حذف هذا خارج،`pnpm run build` متابعة وراثة استدعاء جهة باق بقية `DSH_CLIENT_*` قيمة.

`pnpm run build:official` لا اعتماد خاص تحديد shell بيئة متغير لغة قاعدة، مباشر اختيار مستودع رسمي جهة ناتج profile. هو دقيق بيئة يحمل إصدار و commit، ضبط `DSH_CLIENT_BUILD_PROFILE=official` توفير نشر مخصص تابع عمل خدمة تسجيل استخدام، و حذف محلي dirty بيانات وصفية. كامل بناء نجاح بعد سوف كتابة دقيق عام بيئة، و تغطية Vite إخراج و كل حركة حالة client bundle ملخص؛ نطاق جزء بناء أمر لن استبدال هذا سجل.`pnpm run dev:web` فإن سوف في بدء وقت قراءة مرة افتراضي محلي بيئة، و في هذا مرة جلسة في يأخذ هذا بيئة نقل إعطاء كل watcher stage. هو لن تحقق كامل بناء سجل، لأن watcher stage سوف إعادة كتابة سجل تغطية الكل ناتج.

## Alternatives considered

**فقط في Vite في استبدال.** حركة حالة إضافة `lib/client.js` بصفة مستقل نص برمجي من متصفح تحميل، لا دخول Vite وحدة رسم، جدول بلوغ صيغة سوف ناقص إبقاء إلى بلا `process` متصفح.

**عام الكل `DSH_*`.** مستودع في Host، اختبار و CI متغير استخدام هذا بادئة، منها ممكن يتضمن اعتماد أو محلي مسار؛ أكثر ضيق `DSH_CLIENT_*` يجعل عام معنى رسم يمكن مراجعة حساب.

**في متصفح توفير كامل `process.env` كائن.** هذا سوف سماح قطعة رفع بناء بيئة و يأخذ Node توافق وسادة قطعة تغيير صار وقت التشغيل API؛ ساكن حالة دقيق استبدال كاف بـ تحمل تحميل بناء اختيار.

**موحد واحد تعديل استخدام `import.meta.env`.** حركة حالة إضافة إخراج لـ مستقل CJS factory، لا يستطيع إبقاء `import.meta`؛ عمل خدمة شفرة ما زال سوف بسبب ناتج مسار مختلف بينما استخدام اثنان طقم واجهة.

**يجعل watcher إعادة استخدام فوق مرة كامل بناء سجل.** watcher stage سوف إعادة كتابة سجل تغطية الكل client ناتج، لذلك صحيح معتاد تطوير خلال ناتج ملخص حينئذ سوف تغيير لـ قديم قديم. رسمي جهة بناء سجل أيضا سوف يجعل مرور مرور تحرير محلي شفرة المصدر متابعة يحمل رسمي جهة profile و عنوان. بدء وقت قراءة مرة يمكن يجعل كل stage مشترك استخدام نفس نسخة محلي بيانات وصفية لقطة، معا تجنب تجنب watcher إعادة بدء اعتماد سجل ناتج ملخص.

**كل مرة watcher إعادة بناء كل إعادة قراءة Git حالة.** Vite و tsdown في طويل إقامة watcher بدء وقت ثابت define استبدال. مستودع حالة تغير وقت إعادة بدء بناء خط الإنتاج، سوف جعل مرة زيادة كمية شفرة المصدر تعديل إعادة بناء غير متصل ناتج؛ بدء وقت فقط قراءة مرة يمكن إبقاء كل stage متسق، معا تجنب تجنب بسبب لاحق حالة تغير بينما إعادة بناء.

## Consequences

Vite ساكن حالة قشرة و مشترك tsdown حركة حالة bundle مقابل نفس `DSH_CLIENT_*` بناء عملية متغير إنتاج نفسه نص قيمة. لم ضبط ساكن حالة نقطة وصول نيل إلى `undefined`، غير `DSH_CLIENT_*` قيمة لن عبر هذا آلية دخول متصفح ناتج، عمل خدمة شفرة أيضا لا يمكن قطعة رفع بناء عملية بيئة. كل مرة كامل بناء كل يحمل يمكن عام عرض حزمة إصدار و قصير شفرة المصدر revision؛dirty افتراضي بناء أيضا سوف علامة واضح ذلك شفرة المصدر وجود لم إيداع تغير.CI بناء بوابة اختيار رسمي جهة profile، بينما لا يأخذ منها عام قيمة كشف إعطاء شفرة المصدر اختبار أو غير متصل workflow خطوة.npm تحزيم و built Web اختبار سوف تحقق سجل في بيئة و حالي ناتج ملخص، لذلك افتراضي بناء بعد طلب رسمي جهة تحزيم، نطاق جزء إعادة بناء أو تعديل إخراج كل سوف في إزالة استهلاك ناتج قبل فشل.watch build سوف إبقاء بدء وقت لقطة، مباشر إلى `pnpm run dev:web` إعادة بدء.

أي يتم عمل خدمة شفرة مرجع `DSH_CLIENT_*` قيمة كل سوف يصبح عام ناتج محتوى، تسمية خطأ ممكن تسرب كشف معلومة. بناء اختيار في ناتج توليد وقت ثابت؛ حاجة نشر بعد تغير ضبط يجب استخدام يملك تحقق، نقل و وثيقة وقت التشغيل إعداد آلية.
