# Agent Note: مباشر تعديل Desktop profile

Status: implemented
Archived: 2026-09-17

[English](2026-09-09-desktop-in-place-profile.md) | العربية

## مشكلة

staging قدرة إبقاء قديم إضافة تثبيت، لكن زيادة profile نسخ، دليل نقل حركة، استعادة سجل و تراجع حالة. محلي إضافة تغيير قبول فشل بعد صريح إصلاح، بـ تجنب تجنب هذه تكرار مختلط درجة.

## قرار

تطبيق إدارة حزمة إبقاء نطاق تلقي[إنتاج تنظيف قرار](../bug-fix/2026-09-15-desktop-profile-core-cleanup.ar.md) حد تحديد.

Desktop إيقاف Host بعد مباشر تعديل حالي profile. مشترك app-boot تنظيف في حزمة تغيير قبل قسم مغادرة ذلك يملك وحدة تكملة كل رابط؛Host مشترك profile runner في بدء وقت تكملة كل الذي يحتاج رابط. حزمة قفل و إعداد سماح دورة الحياة نص برمجي إبقاء. ترقية تحديث جديد وحدة رابط، لا نسخ إضافة ملف.

حزمة عملية أو Host فشل سوف إبقاء جزء تعديل، توفير إصلاح و إعادة محاولة. لا استخدام staging profile، تنشيط سجل، دليل تبديل استعادة أو تلقائي تراجع. قد لديه مؤقت دليل لن يتم حل تفسير أو حذف.

هذا سجل يحل محل[تحزيم قرار](2026-08-25-electron-desktop-packaging-and-updates.ar.md) ،[داخل وضع وقت التشغيل قرار](2026-09-08-desktop-bundled-runtime-and-external-plugins.ar.md) و[قيام أي عرض نافذة قرار](2026-09-09-desktop-immediate-window-and-direct-start.ar.md) في مؤقت تخزين و تراجع.Host بدء التزام دوران[رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md) ؛ إصدار، وحدة ملكية و نافذة دورة الحياة ما زال من كل منها قرار مسؤول.

Desktop سوف تثبيت و دورة الحياة نص برمجي تسليم إعطاء pnpm، لا ضبط انتظار إتمام عملية بدء بوابة، لا قوي صنع حسب قفل ملف إعادة تركيب، أيضا لا تلقائي إعادة بناء. حزمة عملية فشل سوف إبقاء جزء تغيير، ما زال يمكن منع استخدام، حذف و إعادة محاولة بدء.Host وراثة مستخدم بيئة،profile يمكن استخدام دليل رابط. لم مرور تعديل قديم إصدار Desktop توليد pnpm إعداد استبدال لـ Web قيمة افتراضية؛ ذاتي تعريف إعداد ما زال من مستخدم إدارة.

## اعتبار مرور بديل خطة

staging بـ نسخ و انهيار انهيار استعادة لـ بديل قيمة حفظ حماية قديم تثبيت. إصدار تحويل دليل ما زال حاجة دقيق تجهيز، اختيار و تنظيف. مباشر كتابة وضع ترك تلقائي استعادة؛ فقط لديه بلا شخص قيمة حراسة استعادة منتج اشتراط قدرة إثبات هذه صار هذا دمج إدارة وقت، عندئذ إعادة جذب دخول.

## عاقبة

اختبار تغطية مغادرة خط ابتدائي تحويل، أصل أرض ترقية، كتابة قبل فشل،Host فشل بعد إبقاء تعديل،pnpm جزء فشل، مضيف رابط استعادة و وحيد احتلال حزمة عملية. توقيع تطبيق و GUI تحقق استلام ما زال من إصدار بيئة مسؤول.
