# Agent Note: تجميع في إدارة نادر متباعد first-party نص التوجيه مقطع ترتيب

Status: implemented
Archived: 2026-09-04

[English](2026-08-25-sparse-first-party-prompt-section-orders.md) | العربية

## مشكلة

مستودع ذاتي حمل توجيه النظام مقطع قسم تفرق في اثنان عشرة كثير عدد حزمة في، كل منها إعلان متبادل لا صلة ربط عدد حرف حرف وجه كمية. رئيسي يلزم أداة تسلسل وصل متابعة احتلال استخدام 100 إلى 117، لاحق إدراج دخول أيضا استخدام نصف خطوة عدد قيمة. لذلك، لاحق أكثر تعديل ممكن في لا يمكن يرى كامل قسم إعداد جدول حال حال تحت و قد لديه مقطع حدوث اندفاع مفاجئ.

نفسه order اعتماد JavaScript مستقر ترتيب ترتيب، جعل إضافة تنشيط ترتيب يصبح فعلي مستو نطاق قاعدة.[Cordis/workflow نص التوجيه ترتيب إصلاح](../../archived/bug-fix/2026-08-24-system-prompt-section-order-ties.md) جدول واضح، كامل كما صالح تركيب ممكن حسب مختلف ترتيب تنشيط نفس مجموعة إضافة، دخول بينما إنتاج مختلف طلب header و لقطة نتيجة. نطاق جزء إصلاح مرة اندفاع مفاجئ، لا يمكن منع توقف آخر عدد حزمة مجددا مرة استخدام نفس عدد قيمة.

هذا خارج،shell إشارة توجيه يقع في نظام الملفات إشارة توجيه بعد، لكن shell أمر أداة لديه الأكثر واسع عام تنفيذ و فشل دلالة. نموذج ينبغي أولا قراءة إلى shell نتيجة معنى خدمة، مجددا قراءة قراءة سوف ملف عملية قسم تدفق إلى مخصص استخدام أداة أكثر ضيق إشارة أمر.

## قرار

`@deepseek-ai/dsh-system-prompt` يحتفظ مستودع نص التوجيه مقطع و runtime context خاص أداة اسم قسم إعداد. كل مستودع مساهمة جهة عبر `ctx.systemPrompt.getSectionOrder(name)` أو `getContextOrder(name)` نحو نشط وثب خدمة استعلام مرور مرور نوع قيد موضع، بينما لم يعد استيراد قيمة أو إعلان عدد حرف حرف وجه كمية. مقطع قيمة هو متبادل لا نفسه كامل عدد، متبادل مجاور قد قسم إعداد مقطع قيمة لـ فرق حتى قليل لـ عشرة؛context قيمة فإن في ذاتي ذات مستقل تسلسل في إبقاء وحيد كامل عدد.

حذف اثنان بند متعمد ضبط كامل خارج، هذا قسم إعداد إبقاء قائم first-party ترتيب:Bash، أو Windows تركيب في PowerShell، يقع في تدريجي أداة إشارة توجيه أول موضع؛ أصل أولا مشترك order مقطع نيل نيل واضح ترتيب. قسم مجموعة مثل تحت:

| قسم مجموعة | بند |
|---|---|
| منتج فتح ساحة | `harness:identity` −1000،`harness:source` −900،`app:web-surface` −800،`deployment:persona` 0 |
| عمل نمط | `plan:policy` 500،`team:policy` 600 |
| استدعاء قبل وضع شرح | `tools:ptc-only` 800،`context:file-reference` 900 |
| محلي أداة | `tool:bash` 1000،`tool:pwsh` 1010،`tool:read` 1100،`tool:write` 1200،`tool:edit` 1300،`tool:glob` 1400،`tool:grep` 1500،`tool:jobs` 1600،`tool:pty` 1700 |
| عال طبقة أداة | `tool:web_search` 2000،`tool:web_fetch` 2100،`tool:lsp` 2200،`tool:session-query` 2300،`tool:goal` 2400،`tool:cordis` 2500،`tool:workflow` 2600،`tool:ralph` 2700، يمكن متابعة تشغيل subagent إشارة توجيه 2800 |
| توليد بروتوكول | `tools:sdk` 5000 |
| نهائي إخراج معنى خدمة | يمكن تسليم ملف مرجع 9000،`tool:structured_output` 9900 |

Runtime-context قسم إعداد لـ `SANDBOX_POLICY` 110،`APPROVAL_POLICY` 115 و `SUBAGENT_DELEGATION` 120.

`SystemPrompt.assemble()` مقارنة مقارنة `order` بعد، حسب نص التوجيه مقطع اسم شفرة وحدة ترتيب ترتيب صف نفس رقم بند. هذا مثال بلا حاجة استخدام تلقي منطقة مجال ضبط أثر مقارنة مقارنة، أيضا قدرة يجعل رقم ثلاثة جهة اندفاع مفاجئ إنتاج تحديد نتيجة.first-party مساهمة جهة ما زال استخدام مختلف rank، ذلك مسبق مدة ترتيب من قسم إعداد جدول واضح جدول بلوغ، بينما لا اعتماد التقاط قاع قاعدة.

حركة حالة `PromptContext` ترتيب و أداة schema `toolOrder` هو مستقل تسلسل.Prompt context استخدام خدمة يحتفظ مستقل context قسم إعداد، أداة schema فإن متابعة من `toolOrder` إدارة. حمل أثر مجال `deployment:persona` ما زال سوف في مقطع ترتيب ترتيب قبل حسب اسم حجب حجب عام مقطع، و عبر خدمة تحليل نفس عدد `DEPLOYMENT_PERSONA` موضع.

## تحقق

توجيه النظام اختبار وحدة عبر خدمة تحليل كل قد إعداد section و context اسم. هو تحقق عدد قيمة لـ كامل عدد كما متبادل لا تكرار، متبادل مجاور section قيمة حتى قليل متبادل فرق عشرة، و تحقق ترتيب متبادل عكس اثنان نوع نفس رقم تسجيل ترتيب صف نيل إلى نفسه شفرة وحدة اسم ترتيب. حقيقي تركيب لقطة ثابت موجه إلى نموذج ترتيب، يشمل Bash يقع في نظام الملفات إشارة توجيه قبل، و Cordis،workflow،Ralph،subagent و report واضح تسلسل.

## اعتبار مرور بديل خطة

**إبقاء حزمة داخل عدد حرف حرف وجه كمية و عبر مراجعة شخص عمل فحص اندفاع مفاجئ.**لم اعتماد، لأن مساهمة جهة لا يمكن في نطاق جزء يرى كامل قسم إعداد جدول، بينما كما مبكر مدة إصلاح دمج دخول بعد، إطلاق هذا إصلاح نفس صنف اندفاع مفاجئ مجددا مرة ظهور.

**متابعة إدراج دخول صغير عدد قيمة.**لم اعتماد، لأن صغير عدد لا يوجد حمل دائم بين مسافة قاعدة، صعب بـ جدول بلوغ دلالة قسم مجموعة، أيضا لا يمكن منع توقف غير متصل حزمة اختيار نفس عدد قيمة.

**فقط مواصفة تحويل لقطة مقارنة مقارنة.**لم اعتماد، لأن وقت التشغيل طلب header و نموذج نص التوجيه ما زال اعتماد تنشيط ترتيب، اختبار فقط سوف إخفاء فرق مختلف.

**نفس rank وقت إبقاء تنشيط ترتيب.**لم اعتماد، لأن تنشيط ترتيب لا هو نص التوجيه ترتيب قرار، و كما سوف في صالح تركيب بين تغير. اسم ترتيب لـ خارجي اندفاع مفاجئ توفير تحديد نتيجة؛ أداة اسم موضع مسؤول جدول بلوغ first-party معنى رسم.

**يأخذ حركة حالة context و أداة schema وضع دخول section قسم إعداد.**لم اعتماد، لأن وقت التشغيل مستقل تجميع هذه تسلسل.Context استخدام ذاتي ذات أداة اسم خدمة قسم إعداد؛ يأخذ مهمة واحد تسلسل و section دمج كل سوف داكن عرض وقت التشغيل و لا تنفيذ عبر تسلسل ترتيب.

## عاقبة

عدد حرف rank لن يتم تصيير، لذلك مفرد صاف إعادة تحرير رقم لن تغيير نموذج نص.Bash أو PowerShell سوف نقل إلى أخرى تدريجي أداة إشارة توجيه قبل، أصل أولا نفس رقم مقطع سوف نيل نيل تحديد ترتيب؛ هذه موجه إلى نموذج تغير سوف تحديث طلب header لقطة، و ممكن من رقم واحد نقل حركة مقطع سقوط بدء جعل مزود بادئة إعادة استخدام بطلان.

خارجي إضافة يمكن لـ ذاتي ذات section أو context اختيار مهمة معنى لديه حد عدد حرف order. أداة اسم order استعلام يخص مستودع داخلي موضع، بينما لا هو توسيع API. خارجي section ما زال يمكن استخدام نفسه rank، و سوف حسب اسم نيل نيل تحديد ترتيب.

توجيه النظام حزمة الآن حل مستودع وظيفة اسم و متبادل مقابل موضع. هذا نوع تجميع في اقتران دمج هو متعمد: سجل التسجيل هذا حينئذ يملك ترتيب ترتيب دلالة، بينما قسم تفرق عدد حرف حرف وجه كمية فقط هو يجعل نفس علاقة تغيير نيل خفي صيغة كما لا يمكن فحص.
