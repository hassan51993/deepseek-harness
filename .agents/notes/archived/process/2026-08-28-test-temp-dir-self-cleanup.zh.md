# Agent Note: مفرد قياس حذف ذاتي ذات إنشاء dsh-* مؤقت دليل

Status: implemented
Archived: 2026-09-04

[English](2026-08-28-test-temp-dir-self-cleanup.md) | العربية

## Problem

اختبار عملية استخدام `mkdtemp(join(tmpdir(), 'dsh-*'))` إنشاء `/tmp/dsh-*` دليل بعد لا تنظيف. في ذاتي حمل إدارة Linux CI رئيسي آلة فوق (32 عدد runner نسخة مشترك واحد `/tmp`) ، ناقص إبقاء اثنان مرة استهلاك كل أصل قسم منطقة inode(issue #3134،2026-08-13 و 2026-08-26). آلة جهاز جانب `dsh-tmp-sweep` timer و CI lane sweep(إبقاء لم دمج، في فرع `fix/ci-tmp-residue-cleanup` فوق) كل هو أمر بعد حذف ناقص إبقاء، لم إصلاح إسقاط إنتاج ناقص إبقاء نقص وقوع هذا جسم. شخص صنف review #3233(2026-08-28) مرفوض sweep: مفرد قياس ينبغي تعديل لـ ذاتي ذات تنظيف إنشاء دليل.

## Decision

لـ spec ملف إنشاء كل `dsh-*` مؤقت دليل تكملة فوق حذف مسار، تعليق في الذي تابع اختبار teardown فوق:

- إنشاء دليل لكن من لا حذف spec ملف، الآن يأخذ كل إنشاء root تسجيل دخول وحدة درجة قائمة، و في `afterEach`/`afterAll` داخل حذف (`rm`/`rmSync` حمل `recursive: true, force: true`)——و session حزمة قائم `roots.splice(0)` اتفاق متسق. إنشاء root helper(`tmp()`،`tempDir()`،`fakeLauncher()`،harness دالة) في إنشاء موضع تسجيل تسجيل، واحد نقطة تغطية الكل استدعاء جهة.
- كامل ملف مشترك وحدة درجة fixture دليل (executor spill دليل) في الأكثر بعد واحد اختبار بعد `afterAll` داخل حذف.
- هدف ملف بيان قدوم ذاتي CI رئيسي آلة فوق ناقص إبقاء فعلي قياس بيان (حالي `/tmp/dsh-*` دليل نموذج لوح مباشر جهة رسم): فقط لديه دليل تأكيد فعلي ظهور في ناقص إبقاء داخل spec ملف عندئذ هو تسرب تسرب مصدر. قد لديه حذف منطق ملف (agent-team،tool-subagent،list-children،hooks coverage cases) تأكيد في صحيح معتاد انتهاء مسار فوق هذا قدوم جاف صاف، لا تعديل.
- منتج جانب تنظيف حد تحديد في `dsh-subprocess-local/spawn` كل عملية spill دليل (`privateSpillDir`): في JavaScript يمكن مراقبة عملية خروج وقت، فقط عند دليل**لم يحتفظ أي قد إتمام spill ملف**عندئذ حذف——قد إتمام spill ملف بصفة كامل إخراج استعادة ناتج إبقاء إلى خارجي تنظيف، لذلك فقط لديه من لم spill مرور دليل (CI رئيسي آلة ناقص إبقاء رئيسي تدفق شكل: سحب مثال `dsh-subprocess-*` دليل 92% لـ فارغ) سوف يتم حذف. حذف هو best-effort(ENOENT/ENOTEMPTY/EBUSY/EPERM لا نيل تغيير خروج رمز).`dsh-spill-local` افتراضي root **لحظة معنى لا فعل**خروج حذف: هذا root من حزمة ذاتي حمل 30 يوم بدء sweep تغطية، كما[إبقاء سياسة note](../architecture/2026-07-17-local-spill-startup-cleanup.zh.md) منع توقف حذف resume/fork جلسة ما زال ممكن مرجع جديد spill ناتج.

## Verification

- محلي تحديد نحو ركض مرور الكل تعديل مفرد قياس spec عبر (36 عدد تعديل `*.spec.ts` ملف، قسم مجموعة تشغيل) ، يحتوي مباشر استخدام تعديل بعد منتج شفرة المصدر طقم عنصر؛2 عدد تعديل web `*.e2e.ts` من web e2e lane تحمل تحميل.
- CI في Linux و Windows coverage lane ركض تعديل spec؛ مرة كل أخضر بعد، يتم إصلاح ملف ناقص إبقاء نموذج لوح (فعلي قياس كل اثنان صغير وقت الأكثر كثير كل نحو 5,000 عدد دليل، مثل `dsh-profile-`،`dsh-app-boot-`،`dsh-presets-*`،`dsh-upload-index-`) ينبغي لم يعد ظهور في CI رئيسي آلة جديد طازج `/tmp` ناقص إبقاء داخل.

## Alternatives considered

### إبقاء صاف sweep خطة (review مرفوض)

Sweep خطوة و timer فقط حذف قد وجود ناقص إبقاء؛ محلي تشغيل ما زال سوف تراكم تراكم، آلة جهاز sweep أيضا منطقة قسم لا قد ميت run ناقص إبقاء و تخزين نشط run دليل.review قرار هو تدريجي اختبار تنظيف، هذا تنفيذ تغطية صحيح معتاد انتهاء مسار.

### جذب دخول مشترك مؤقت دليل helper حزمة

لم اختيار: تسرب تسرب ملف كل منها عبر ذاتي ذات صغير helper إنشاء root، في ذلك بعض helper موضع تسجيل تسجيل هو كل ملف مفرد نقطة تعديل؛ إضافة جديدة test-support حزمة فقط سوف زيادة اعتماد، لا نقص قليل تدريجي ملف مراجعة حساب كمية.

## Consequences

- استلام فائدة: صحيح معتاد انتهاء (يحتوي اختبار فشل) وقت،spec `dsh-*` دليل في teardown حذف؛`dsh-subprocess-local` لم يحتفظ أي قد إتمام spill ملف كل عملية spill دليل في JavaScript يمكن مراقبة عملية خروج وقت حذف.
- بديل قيمة: يتم SIGKILL عملية (run يتم إلغاء، مهلة يتم قتل) لا يمكن تشغيل أي عملية داخل teardown، طيران سطر في ناقص إبقاء ما زال في——آلة جهاز جانب timer متابعة التقاط قاع هذا مسار.
- بديل قيمة: عملية فرعية إنشاء دليل فقط لديه في اختبار معرفة طريق ذلك مسار وقت عندئذ يتم تغطية؛ منتج ذاتي لديه، ما زال يحتفظ spill ملف دليل و `dsh-spill-local` افتراضي root حسب قائم إبقاء سياسة إبقاء ملف، من هذا حزمة ذاته sweep تنظيف.
