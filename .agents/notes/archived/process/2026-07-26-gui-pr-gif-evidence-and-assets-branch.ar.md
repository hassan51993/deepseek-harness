# Agent Note: GUI PR GIF دليل و assets فرع إصدار

## مشكلة

تغيير منتج مستخدم في GUI في الذي رؤية سلوك PR(Pull Request) ، هذا قبل فقط قدرة عبر نص حرف وصف و اختبار اسم قبول مراجعة، اثنان من كل لا يمكن عرض تصيير نتيجة.[متصفح عرض عرض GIF تسجيل صنع](../../../skills/record-browser-gif/SKILL.md) مقابل skill(تقنية قدرة) قدرة توليد حقيقي يمكن معلومة محلي GIF، لكن لحظة معنى توقف خطوة في محلي ناتج، في هو كل تفكير عرض GIF PR كل نيل كل منها إعادة لمس بحث إصدار طريقة؛ بينما يأخذ GIF إيداع إلى PR فرع من قدوم غير ممكن قبول: دخول تاريخ اثنان دخول صنع وسيط جسم سوف دائم دائم زيادة كبير بعد كل مرة تغلب ضخم جسم تراكم.

تسجيل صنع مسار ذاته أيضا في اعتماد مرة مرة فشل عكس تكرار إعادة تعلم تعود: قطع رسم كتابة إلى متصفح أداة سماح أصل دليل خارج أو كتابة لا وجود دليل، سوف في قطع أخذ وقت مباشر فشل؛ عبر كثير مرة أداة استدعاء جولة استفسار لحظة حالة UI حالة سوف فقد فقد، لأن استدعاء بين جولة قد تسوية؛ استخدام فرعي سلسلة مطابقة فعل إتمام حكم تحديد سوف أمر في مستخدم ذاتي ذات نص التوجيه عودة إظهار؛ في تحرير رمز جهاز أمر فوق داخل ربط منح قيمة بيئة متغير فإن بسبب معامل أولا في منح قيمة توسيع بينما لا توليد فاعلية.

## قرار

كل تغيير منتج مستخدم مرئي GUI سلوك PR كل يتضمن واحد استخدام [record-browser-gif skill](../../../skills/record-browser-gif/SKILL.md) تسجيل صنع عرض عرض GIF، ذلك مصدر يجب حقيقي: من هذا PR ذاته فرع شجرة بدء حقيقي خادم، حقيقي API مفتاح، حقيقي نموذج جولة، و في تضمين دخول موضع ملاحظة واضح مصدر. فقط لديه عند مستخدم واضح اشتراط fixture(اختبار قبل وضع بيانات) مصدر وقت عندئذ يمكن استخدام fixture.

GIF إصدار إلى مخصص استخدام منعزل طفل (orphan)assets فرع فوق: هذا فرع لا يوجد أب إيداع، فقط يحتوي وسيط جسم،GIF أبدا دخول PR ذاتي ذات فرع؛ واحد assets فرع خدمة كامل PR نظام صف (قائم فرع:`code-mode-ui-assets`،`pr-613-assets`). إصدار في ضحل طبقة مفرد فرع مؤقت تغلب ضخم في إجراء، إيداع معلومة شكل مثل `assets: <what it shows> gif (#<pr>)`،PR متن استخدام حمل مطلوب `?raw=true` بعد لاحقة blob URL تضمين دخول.assets فرع فقط سماح إلحاق: قد دمج PR متن سوف دائم بعيد مرجع ذلك URL، لذلك assets فرع أبدا إعادة كتابة أو حذف.

تسجيل صنع ذاته إبقاء بلا فرعي أثر؛ إصدار هو واحد لديه حد استلام ذيل خطوة، فقط عند مهمة يتضمن يأخذ GIF مرفق إلى PR وقت عندئذ من هذا skill تنفيذ.[record-browser-gif skill](../../../skills/record-browser-gif/SKILL.md) ما زال هو تسجيل صنع جزء الآن سطر عقد نحو.

هذا skill أيضا امتصاص استلام تسجيل صنع فعلي ممارسة تبديل قدوم عملية مرور تحقق: لقطة ملف وضع في مستودع `.gitignore` تجاهل اختصار `.playwright-mcp/` دليل تحت و في قطع أخذ قبل أولا إنشاء، لأن متصفح أداة فقط قدرة كتابة ذلك سماح أصل دليل، متبادل مقابل ملف اسم أيضا متبادل مقابل مستودع أصل دليل تحليل؛ كل PR من ذاتي ذات بناء فرع شجرة بدء خدمة، إعداد بـ كل جديد مؤقت مساحة العمل دليل، كل تسجيل صنع مشهد جديد فتح جلسة، إيقاف خادم وقت حسب PID دقيق مطابقة بينما لا هو استخدام عرض عام عملية اسم نمط؛ لحظة حالة حالة اعتماد قيادة واحد مؤقت بطيء قبل منصة عملية، و في نفس مرة متصفح نص برمجي استدعاء داخل جولة استفسار أداة جسم DOM علامة قدوم قطع أخذ؛ إتمام حكم تحديد مطابقة دقيق نص عنصر عنصر بينما غير فرعي سلسلة؛ تحرير رمز جهاز في مفرد وحيد واحد سطر export `GIF_SKILL_DIR` بعد تشغيل، تدريجي لقطة وقت طويل يجعل نهائي مستقر حالة توقف إبقاء الأكثر دائم، و معا نواة مقابل JSON ملخص و هدف نظر فحص تحرير رمز بعد GIF.

## سبق اعتبار بديل خطة

**يأخذ GIF إيداع إلى PR فرع.**دمج دخول افتراضي فرع اثنان دخول صنع وسيط جسم سوف إبقاء في تاريخ في، أثر بعد كل مرة تغلب ضخم و سحب أخذ؛ عرض عرض GIF قيمة قيمة توقف في مراجعة، بديل قيمة لكن دائم لا إزالة فقد.

**بصفة GitHub مرفق عنصر فوق نقل.**سحب جر إنتاج `user-attachments` فوق نقل مقابل أمر سطر سير العمل غير ممكن استخدام، لا يمكن من مستودع إعادة بناء أو مراجعة حساب، وسيط جسم دورة الحياة أيضا انفصال مغادرة مستودع تحكم.

**استخدام Git LFS تخزين GIF.**LFS ما زال يأخذ وسيط جسم اقتران دمج دخول شفرة فرع تاريخ، إعطاء كل مرة تغلب ضخم و CI سحب أخذ زيادة واحد بند أساس أساس ضبط تطبيق اعتماد، متبادل مقارنة عادي git يكفي دعم حمل عزل فرع لا يوجد أي مقدار خارج استلام فائدة.

**كل PR واحد assets فرع.**حسب PR بناء فرع سوف يجعل ref نطاق الأسماء امتداد تأخير، و في واحد نظام صف داخل صار ضعف زيادة مؤقت تغلب ضخم؛ كل نظام صف واحد فرع يجعل إصدار فقط يحتاج مرة دفع إرسال، معا ما زال و شفرة تاريخ عزل.

**يأخذ إصدار إبقاء في تسجيل صنع skill خارج.**هذا هو هذا قبل حالة؛ هو حفظ إقامة جاف صاف حد، لكن يجعل كل PR إعادة لمس بحث نفس طقم مسار. هذا عدد حد مثل اليوم بـ صريح شرط شكل صيغة إبقاء: فقط عند مهمة يتضمن يأخذ GIF مرفق إلى PR وقت عندئذ تنفيذ إصدار، بينما لا هو اعتماد حذف قدوم جسم الآن.

**يجعل GIF في كل PR في إبقاء اختياري.**اختياري دليل تماما تماما سوف في الأكثر حاجة هو دخول درجة ضغط قوة تحت إزالة فقد؛ لا يوجد تسجيل صنع GUI تغيير مراجعة، انتظار في اشتراط مراجعة شخص ذاتي سطر تفكير كائن تصيير نتيجة أو إعادة بناء فرع.

## عاقبة

كل GUI PR كل يحمل ملاحظة واضح مصدر يمكن نظر دليل، مراجعة شخص بلا حاجة إعادة بناء فرع يكفي يرى تغيير. مستودع تاريخ إبقاء لا يحتوي وسيط جسم؛ بديل قيمة تحويل نقل إلى فقط إلحاق assets فرع فوق: هو جمع سوف حمل متابعة زيادة طويل، يمكن منخفض صار محلي ضحل تغلب ضخم، كما دائم بعيد لا يستطيع حذف. قوي صنع حقيقي مصدر تسجيل صنع إعطاء كل GUI PR سير العمل زيادة مرة حقيقي مفتاح، حقيقي نموذج جولة تشغيل، هذا هو متعمد لـ لـ، لأن هذا مرة تشغيل ذاته حينئذ هو دليل. تسجيل صنع جزء ما زال في محلي يمكن سحب إلغاء؛ مهمة لا يتضمن مرفق إلى PR GIF طلب، ما زال بـ قد تحقق محلي ناتج انتهاء.
