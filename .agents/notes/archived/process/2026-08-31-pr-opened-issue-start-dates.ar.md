# Agent Note: في PR إنشاء وقت ضبط Issue بدء يوم مدة

Status: implemented
Archived: 2026-09-02

[English](2026-08-31-pr-opened-issue-start-dates.md) | العربية

## مشكلة

مجموعة نسج درجة `Start date` Issue حقل سجل عمل بدء وقت، لكن يأخذ Issue إضافة دخول Issue Project أو من PR صلة ربط هو كل لن توفير يوم مدة قيمة.PR يمكن معا معرف هو الذي حل قرار Issue و توفير متبادل صلة تنفيذ سياق Issue؛ اثنان نوع علاقة كل يمثل مستودع عمل قد بدء.

إذا كل PR حدث كل تحديث هذا حقل، تحرير، دفع إرسال أو إعادة فتح PR سوف لـ قد لديه عمل تكملة فوق يوم مدة. تغطية قد لديه يوم مدة أيضا سوف إسقاط شخص عمل قاعدة تخطيط يوم مدة أو مقارنة مبكر PR سجل يوم مدة.

## قرار

Issue دورة الحياة سير العمل فقط في `pull_request.opened` وقت ابتدائي تحويل `Start date`. سير العمل قراءة PR فوري متن، إبقاء كل قدرة تحليل لـ Issue نفس مستودع مرجع، يأخذ `created_at` حسب إعداد Project وقت منطقة تحويل لـ يوم تاريخ يوم مدة، تأكيد حفظ Issue هو Project item، و فقط في حالي قيمة لـ فارغ وقت كتابة إعداد مجموعة نسج درجة Issue Date حقل.

إعداد إشارة تحديد Project في عرض حقل و وقت منطقة. هذا Project حقل يجب تحليل لـ مجموعة نسج درجة Issue Date حقل؛ سير العمل قراءة هو Issue قيمة و عبر `updateIssueFieldValue` تحديث. إعداد ناقص سوف في سياسة وحدة تحميل وقت فشل؛ حقل ناقص، حقل لا هو Date نوع أو هو Project نطاق جزء حقل، ختم الوقت بلا فاعلية أو API طلب فشل سوف يجعل أول عدد متبادل صلة PR سير العمل فشل.

[من حدث مباشر إشارة تحديد PR مراجعة حالة أمر](2026-08-10-event-directed-pr-review-status.ar.md) متابعة مسؤول Status تحويل. يوم مدة ابتدائي تحويل معا يتضمن حل قرار نوع و معلومة نوع Issue مرجع، مقابل Draft PR و تلقائي تحويل PR نفس مثال تشغيل، أيضا لا اعتماد PR سياسة فحص هل توليد فاعلية.

## تحقق

[Issue إدارة اختبار](../../../../.github/issue-management/policy.test.mjs) تغطية فوق بحر وقت منطقة يوم مدة حد، فقط opened قسم إرسال، الكل إبقاء Issue مرجع،Issue حقل اكتشاف، فارغ قيمة كتابة، قد لديه قيمة إبقاء،Project item ناقص، حقل إعداد بلا فاعلية و `updateIssueFieldValue` متغير.[سير العمل اختبار](../../../../scripts/ci-workflow.spec.ts) اشتراط إبقاء `pull_request.opened` حجز قراءة.

## اعتبار مرور بديل خطة

**استخدام Project داخل وضع سير العمل.** داخل وضع سير العمل مسؤول ثابت Project item و Status تحويل؛ مستودع سير العمل قد مسؤول مرور مرور هوية تحقق GraphQL mutation، و كما قدرة كاف توفير PR إنشاء يوم مدة.

**استخدام Project نطاق جزء Date حقل.** Project حقل سماح نفس عدد Issue في مختلف Project في استخدام مختلف يوم مدة، و كما لن عرض في Issue ذاته. عمل هو إبرة مقابل Issue بدء، بينما لا هو إبرة مقابل بعض مرة Project ملكية بدء، لذلك من مجموعة نسج درجة Issue حقل يحتفظ هذا قيمة.

**معالجة كل قد حجز قراءة PR حدث أو تشغيل تنسيق ضبط جهاز.** لاحق حدث يمكن لـ قد لديه PR و إنشاء بعد إضافة جديدة مرجع تكملة فوق يوم مدة، لكن هذا سوف يجعل هذا حقل يصبح إصلاح نوع إسقاط، بينما لا هو مع PR إنشاء سجل، و كما سوف زيادة تكرار Project قراءة.

**فقط تحديث حل قرار نوع Issue مرجع.** معلومة نوع مرجع نفس مثال معرف مع هذا PR بدء تنفيذ عمل Issue، لذلك يوم مدة ابتدائي تحويل استخدام قائم الكل مرجع تجميع دمج،Status تحويل ما زال فقط معالجة حل قرار نوع مرجع.

**تغطية قد لديه يوم مدة.** لاحق PR لا نيل استبدال شخص عمل حساب تخطيط أو لـ مقارنة مبكر عمل كتابة يوم مدة، لذلك mutation أولا قراءة و فقط معالجة فارغ قيمة.

## عاقبة

فقط لديه سير العمل إصدار بعد جديد بناء PR سوف ابتدائي تحويل يوم مدة. إنشاء بعد إضافة جديدة مرجع و قائم فتح وضع PR إبقاء ثابت، سير العمل لن مسح قد لديه Project item أو PR. يوم مدة سوف مع Issue ظهور في مجموعة نسج داخل عرض هذا حقل كل عدد Project في.

فارغ قيمة قراءة جعل إعادة محاولة في عبر معتاد حال حال تحت إبقاء قوة انتظار.Issue حقل mutation لا يوجد مقارنة مقارنة و ضبط قبل رفع، لذلك معا مرجع نفس عدد فارغ يوم مدة Issue PR ممكن كل سوف كتابة؛ حسب PR ضبط تزامن تحكم لن سلسلة سطر تحويل هذا Issue، الأكثر بعد مرة mutation ممكن فوز خروج.
