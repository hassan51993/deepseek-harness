# Agent Note: توليد صيغة إضافة إعداد دليل

Status: implemented
Archived: 2026-07-27

[English](2026-07-06-generated-config-catalog.md) | العربية

## مشكلة

مستودع هذا قبل لا يوجد بـ شفرة المصدر لـ بعد درع إضافة إعداد مشاركة اعتبار. كل حزمة (package) README مقابل حقل سجل طريقة لا متسق، لم صف رفع أي بعض حزمة يمكن يتم تحميل، أيضا لم تحقق وقت التشغيل schema و إعلان إعداد نوع هل متسق.

## قرار

`scripts/gen-config-catalog.ts` أصل حسب كل إضافة إعلان config نوع و JSDoc توليد [docs/config-catalog.md](../../../../docs/config-catalog.md) ، و يتضمن حقن اشتراط، يتم مرجع نوع رابط و شفرة المصدر موضع. حزمة داخل نوع سوف بـ نقل تمرير طريقة قبول دخول؛workspace نوع و خارجي نوع فإن سوف رابط أو نقطة اسم. تحديد صفة `--write` و `--check` نمط جعل إيداع صفحة يصبح توليد ناتج.

هذا موضع اعتماد صاف AST توليد هو صحيح تأكيد، سبب و حدث/خدمة دليل نفسه، بينما و أداة دليل مختلف: إعداد نوع هو ساكن حالة إعلان، مستودع في كل schemastery schema كل هو ساكن حالة `z.object`/`z.intersect` حرف وجه كمية، لذلك شفرة المصدر أي الكل حق متبادل——إعداد جدول وجه لا يوجد أي جزء هو وقت التشغيل تركيب.

أداة جسم اختيار:

- **إعداد نوع هو ثاني معامل نوع.** catalog سجل هو `apply(ctx, config)` / خدمة بنية صنع دالة `(ctx, config)` إعلان معامل نوع——أي Cordis فعلي نقل دخول قيمة——بينما غير حسب تسمية اتفاق تحديد موضع `Config` توجيه خروج. هذا جعل نيل مرة تاريخ هو كل كمية: بلا نقاش واجهة نداء `AcpConfig` أيضا هو `BasicCompactConfig`، بلا نقاش نوع إعلان في أخ أخ ملف في، أيضا هو إضافة تماما لا يوجد تحقق schema، كل قدرة صحيح معتاد عمل.
- **تصنيف هو كل كمية.** كل `packages/<group>/<pkg>` بند كل سوف يتم تحليل (مرآة مثل Loader `unwrapExports`:`exports.default ?? exports`) ، عودة دخول يمكن إعداد إضافة، بلا إعداد إضافة، سحب كائن seam صنف أو مكتبة لـ واحد——كل منها تصيير في مستقل صغير عقدة في——لا يمكن عودة صنف بند مباشر تقرير خطأ. جديد حزمة غير ممكن قدرة يتم صامت صامت متروك تسرب.
- **تدريجي حقل JSDoc قوي صنع اشتراط.** لصق لصق إعلان في كل خاصية (يشمل تضمين طقم نوع حرف وجه كمية) كل حاجة غير فارغ JSDoc وصف، لا فإن توليد فشل. لصق لصق ذاته حينئذ هو وثيقة، لذلك هذا و events catalog عبر `@mode` تطبيق إضافة قوي صنع دالة نفسه: شفرة المصدر وثيقة مرور في مفرد رقيق وقت بوابة تقرير خطأ، بينما غير إنتاج خروج مفرد رقيق catalog.
- **Schema مفتاح و إعلان نوع فعل مقارنة مقابل.** توليد جهاز عبر نطاق جزء و workspace نوع تحليل تضمين طقم كائن و عدد مجموعة مسار. تحديد ناقص مسار تقرير خطأ؛ لا يمكن قطعة رفع خارجي أو حركة حالة شكل حالة فإن قفز مرور. مقارنة مقابل متعمد تصميم لـ مفرد نحو، لأن إعلان نوع ممكن يتضمن يتم ترتيب حذف في loader إعداد خارج وقت التشغيل مخصص استخدام حقل.
- **مخصص استخدام محيط شريط.** لصق لصق إعلان استخدام ` ```ts config-catalog ` معلومة نص،`doc-typecheck` سوف قفز مرور هو (مرجع استيراد نوع منعزل قيام إعلان لا يمكن مستقل تحرير ترجمة) ، و سوف ذلك ترتيب حذف في opt-out مقارنة مثال خارج——و `cordis-catalog` و `persistence-catalog` محيط شريط معالجة طريقة نفسه.
- **مفرد ملف `docs/config-catalog.md`**، بينما غير واحد مفرد ملف دليل: هذا صفحة موجه إلى مفرد واحد تلقي جمهور (`cordis.yml` تحرير كتابة من) ، فقط لديه واحد صيانة درجة، مختلف في `cordis-catalog/`(منها يتضمن اثنان عدد و صف صفحة).

كل حزمة README في `## Config` صغير عقدة إبقاء. إعادة تراكم هو متعمد قبول:README هو مرور مرور سياسة تخطيط تدريجي حزمة عقد نحو (في نشر سياق في وصف إعداد دلالة، وصل نفس حد و نقطة توسيع) ،catalog فإن هو نفاد رفع صيغة توليد قطعة رفع. من في catalog هو توليد، اثنان من لا متسق وقت شرح README لديه خطأ، إصلاح طريقة هو تحرير README——catalog لن عائم نقل.

## سبق اعتبار بديل خطة

- **دمج صار صيغة تدريجي حقل تصيير**: لـ كل حقل توليد مشروع رمز رقم قائمة، جدول إطار أو حمل ملاحظة تفسير YAML قطعة مقطع، من تحليل JSDoc إضافة schema بيانات وصفية تجميع. مرفوض، تعديل استخدام تدريجي حرف لصق لصق: واجهة وصل نفس ذلك JSDoc ذاته حينئذ هو بـ أصلي شكل صيغة تأليف كتابة عقد نحو، دمج صار مصير سوف إعادة صيغة تحويل هو لا يملك سطر نص، زيادة واحد ممكن مائل منحنى أصل معنى تصيير طبقة.
- **وقت التشغيل بدء + schema داخل حذف (مثل أداة دليل الذي فعل ذلك مثال)**: مرفوض. هذا موضع لا يوجد أي محتوى هو وقت التشغيل تركيب، كما schema ذاته مقابل إعداد جدول وجه وثيقة تحويل لا كاف (بـ سطر نص سجل قيمة افتراضية، وقت التشغيل مخصص استخدام حقل، تماما لا يوجد schema إضافة). بدء فقط سوف زيادة هش ضعيف صفة بينما لا زيادة حق متبادل.
- **مزدوج نحو schema/واجهة انتظار قيمة فحص**: مرفوض، تعديل استخدام فرعي تجميع فحص. إعلان نوع دمج إدارة أرض يتضمن schema رفض من إعداد قبول عضو (وقت التشغيل مخصص استخدام seam).
- **في نفس تغيير في ملغى حذف README `## Config` صغير عقدة**: مرفوض. إبقاء يمكن قبول إعادة تراكم جعل تدريجي حزمة عقد نحو في أصل موضع يمكن قراءة، بينما تنظيف عمل حاجة أولا يأخذ كل README مقدار خارج واقع طي دخول حقل JSDoc——هذا هو يمكن قسم مغادرة عمل،catalog لا اعتماد هو.

## عاقبة

- دليل لن حدوث عائم نقل: إيداع ملف لم عكس عكس شفرة المصدر تغير سوف جعل `doc-sync` و CI في `verify-config-catalog` فشل.config حقل لم سجل، يتم مرجع نوع اسم لا يمكن تحليل، أو schema مفتاح لم ظهور في config نوع في، كل سوف مباشر جعل توليد جهاز فشل.
- إعداد سطر نص الآن لديه إعلان موضع قوي صنع دالة: تحرير كتابة جديد إعداد حقل معنى طعم حال تحرير كتابة ذلك JSDoc، بينما هذا JSDoc سوف تدريجي حرف يصبح catalog بند.
- توليد جهاز مقابل لا يمكن ساكن حالة مرة تاريخ شكل حالة مباشر تقرير خطأ——آخر اسم تحويل حزمة داخل إعداد استيراد، غير `object`/`intersect` تركيب بناء schema، لم صف دخول عام نوع اسم. جذب دخول هذا صنف شكل حالة وقت يجب معا تعليم سوف توليد جهاز (لا فإن هذا شكل حالة لا يستطيع دخول مستودع) ، هذا صحيح هو تصميم معنى رسم:catalog بداية نهاية هو الكل حق متبادل.
- `gen-cordis-catalog.ts` توجيه خروج ذلك JSDoc/إشارة إبرة مساعد مساعدة دالة و `LINK_MAP` توفير إعادة استخدام، لذلك اثنان عدد catalog بـ نفسه طريقة تسليم تقاطع رابط نوع، إضافة جديدة واحد بند link-map بند معا خدمة في اثنان من.
