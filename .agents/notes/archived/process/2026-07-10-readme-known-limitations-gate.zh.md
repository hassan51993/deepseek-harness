# Agent Note: كل حزمة README في تلقي بوابة حفظ حماية «معروف حد» فصل عقدة

Status: implemented
Archived: 2026-09-04

[English](2026-07-10-readme-known-limitations-gate.md) | العربية

## مشكلة

[وثيقة معيار](../../../../docs/AGENTS.md) قاعدة تحديد حد بند ملكية حزمة README. لا يوجد موحد واحد بنية وقت، فصل عقدة ناقص سهل لا يمكن منطقة قسم “مرور مراجعة حساب تأكيد لا يوجد حد” و “نسيان تسجيل تحرير كتابة وثيقة” ، مختلف عنوان أيضا سوف عائق عائق كل مستودع بحث.

## قرار

كل نسخة يقع في `packages/<group>/<pkg>/package.json` manifest(بيانات وصفية بيان) كل لديه واحد نفس درجة README، منها يتضمن مواصفة `## Known Limitations and Deferred Work` فصل عقدة. منها مشروع رمز رقم سجل من هذا حزمة مسؤول طويل مدة مستهلك نقص فتحة و لا واضح إظهار صيانة من قيد؛ واحد عام تنظيف أمر بند ما زال إبقاء في شفرة المصدر TODO أو الذي تابع Agent Note في.[`verify-package-readme-limitations` بوابة](../../../../scripts/verify-package-readme-limitations.ts) من manifest دفع توجيه حزمة تجميع دمج، رفض ناقص README، و اشتراط تماما جيد واحد مواصفة H2 عنوان، كما حتى قليل يتضمن واحد قمة طبقة مشروع رمز رقم.“Limitations”“Deferred”“What is NOT here” أو “Non-goals” انتظار قريب يشبه عنوان كل سوف فشل.

إذا واحد حزمة تأكيد فعلي لا يوجد حاجة إعلان حد أمر بند، فإن سوف ذلك صف دخول `NO_LIMITATIONS` و حذف هذا فصل عقدة. إضافة جديدة حد أمر بند وقت يجب إزالة هذا بند؛ حزمة إعادة تسمية أو إزالة بعد، قديم قديم بند سوف جعل بوابة فشل، لأن كل بند كل يجب مقابل واحد يتم مسح حزمة.

بوابة فحص وجود، شكل حالة و سماح قائمة. مراجعة اعتماد حسب وثيقة و[سطر نص](../../../skills/dsh-prose-standard/SKILL.md) معيار فحص تغطية وجه و دقيق تأكيد صفة. معتاد ضبط قاعدة يقع في [packages/AGENTS.md](../../../../packages/AGENTS.md).

## سبق اعتبار بديل خطة

- **ذاتي من صيغة عنوان**: لا يمكن موحد واحد بحث، ما زال يحتاج قريب يشبه عنوان فحص قياس.
- **اشتراط فارغ فصل عقدة أو كتابة "None."**: مثال لوح نص حرف ممكن في حزمة إضافة جديدة حد أمر بند بعد ما زال ناقص إبقاء؛ سماح قائمة جعل «تأكيد فعلي لا يوجد حد أمر بند» هذا واحد حالة صريح كما يمكن مراجعة.
- **ضبط كلمة عدد حد أعلى**: دمج إدارة حد أمر بند عدد كمية بسبب حزمة بينما مختلف، لذلك من مراجعة إدارة تحكم هذا واحد لا ضبط كلمة عدد ميزانية README طبقة درجة.

## عاقبة

- جديد بناء حزمة يجب إعلان رمز دمج شرط حد أمر بند، أو صريح إضافة دخول أبيض اسم مفرد؛ ناقص، عائم نقل أو فارغ فصل عقدة سوف في محلي و CI `doc-sync` في فشل.
- بوابة لـ `doc-sync` إضافة جديدة واحد بلا خارجي اعتماد TypeScript نص برمجي.
- إعادة تسمية تلقي قوي صنع عنوان حاجة معا تعديل نص برمجي و كل حزمة README.
