## مشكلة

أصل README هو مستودع منتج مدخل. ذلك منتج أولوية بنية و قائم لغة هواء ما زال صالح، لكن مع حال وقت التشغيل لا قطع توسيع، أداة جسم مدخل و قدرة إعلان سوف تدريجي تدريجي قديم قديم. إعادة كتابة واقع ما زال صحيح تأكيد فصل عقدة، سوف توسيع كبير مراجعة نطاق، أيضا سوف إسقاط قد سطر لـ صالح إجراء لفظ.

## قرار

أصل README هو بسيط قصير منتج و مساهمة من مدخل. هو شرح منتج تحديد موضع و إضافة هيكل بنية، رابط وثيقة محطة، علامة واضح تطوير من معاينة و أمان حالة، لكن بعد إعطاء خروج تلقي دعم حمل npm و شفرة المصدر بدء مسار.

اثنان بند بدء مسار كل عبر `dsh` profile مدخل بدء Web UI. شفرة المصدر مسار أولا بناء حالي فحص خروج، مجددا تشغيل `pnpm dsh web`.ACP،TUI،SDK، قدرة و حزمة تفصيل دقيق شرح من مستخدم إشارة جنوب، هيكل بنية وثيقة و حزمة بحث جذب صيانة، لا في مدخل صفحة تكرار.

ذلك بقية فصل عقدة رابط مجتمع منطقة دعم حمل، مساهمة إشارة جنوب، تطوير وثيقة،agent إشارة أمر، سماح يمكن إثبات و رقم ثلاثة جهة إعلان. في إنجليزي نص README إبقاء نفسه تقنية فن بنية، مجتمع منطقة رابط قسم آخر خدمة كل منها لغة تلقي جمهور. وثيقة شبكة محطة إبقاء مستقل[سريع سرعة بدء مدخل توجيه](../../../../docs/user/index.zh.md).

## اعتبار مرور بديل خطة

**محيط التفاف جديد منتج سرد أمر إعادة كتابة README.** كامل إعادة كتابة قدرة كاف مفاجئ خروج كل قائم مدخل و قدرة، لكن أيضا سوف استبدال دقيق تأكيد كما قد مرور مراجعة نص سجل، صنع صار لا لا بد يلزم تغيير حركة. قائم واقع قدرة كاف قبول دخول قائم منتج أولوية بنية.

**سوف مستودع عرض لـ SDK و حزمة بيان.** هذا مثال قدرة قيام أي عرض الآن تنفيذ واسع درجة، لكن سوف إجبار جعل جديد قراءة من من حزمة اسم عكس دفع خروج منتج. حزمة بحث جذب و توليد قدرة رسم ما زال هو مرجعي بيان.

**استخدام يتضمن قطع رسم، شعار فصل و تكرار تعليم مسار طويل مقالة تشغيل إلغاء صفحة.** غني وسيط جسم قدرة كاف عرض مستقر منتج استخدام مسار، لكن ذلك محتوى سوف مستقل في أمر و شفرة المصدر اتفاق بينما تدريجي تدريجي قديم قديم. أصل README إبقاء ضيق تجميع، و رابط إلى يمكن تشغيل عرض مثال و كل منها صيانة إشارة جنوب.

**سوف أصل README إسقاط لـ وثيقة شبكة محطة أول صفحة.** استخدام نفس عدد أول صفحة يمكن تجنب تجنب اثنان طقم سرد أمر، لكن وثيقة شبكة محطة مستخدم إشارة جنوب و مستودع موجه إلى منتج و تطوير من مدخل في تنقل و صيانة يحتاج طلب فوق و لا نفسه. وثيقة أصل توجيه فإن سوف قراءة من جذب توجيه حتى سريع سرعة بدء.

## نتيجة

مراجعة من يمكن منطقة قسم واقع تحديث و تحرير صفة إعادة كتابة؛ اليوم بعد تحديث سوف إبقاء قائم إجراء لفظ، حذف غير ذلك يحتوي معنى قد لم يعد صحيح تأكيد أو كامل. تلقي أثر أمر، مدخل، إصدار مرحلة مقطع إعلان أو عال طبقة قدرة صنف آخر حدوث تغير وقت،README ما زال يجب تزامن تحديث؛ كامل دقيق عقدة فإن متابعة بـ رابط طريقة توفير، بينما لا هو نسخ إلى متن.
