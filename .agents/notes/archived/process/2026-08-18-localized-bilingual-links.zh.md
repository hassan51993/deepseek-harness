# Agent Note: مزدوج لغة وثيقة رابط محلي تحويل

Status: implemented
Archived: 2026-09-04

[English](2026-08-18-localized-bilingual-links.md) | العربية

## Problem

GitHub سوف مباشر تحليل مستودع Markdown رابط، لا مرور مرور وثيقة شبكة محطة locale projector. إذا اشتراط مزدوج لغة إعداد مقابل اثنان جانب إبقاء نفسه `.md` أصلي هدف، أي جعل قد لديه مرور مراجعة `.zh.md` أخ أخ ملف، العربية مصدر ملف قراءة من أيضا سوف يتم حمل إلى إنجليزي نص صفحة. وثيقة شبكة محطة سوف حسب حالي locale توجيه عادي رابط، من بينما إخفاء غطاء هذا عدد خطأ، توجيه يؤدي مستودع شفرة المصدر و إصدار شبكة محطة إنتاج مختلف تنقل نتيجة.

## Decision

هدف يخص نشط وثب مزدوج لغة لغة مادة وقت، مستودع متبادل مقابل وثيقة رابط تتبع مع مصدر ملف locale: إنجليزي نص مصدر استخدام هدف `.md`، العربية مصدر استخدام ذلك `.zh.md`. اثنان جانب إبقاء نفسه دلالة هدف و تماما نفسه query/fragment بعد لاحقة. هذا نطاق داخل نقص قليل مقابل جانب يخص إعداد مقابل كامل صفة خطأ، لا نيل رجوع؛ خارجي URL، صورة، صاف صفحة داخل fragment و نطاق خارج هدف إبقاء ثابت. لغة تبديل سطر هو صريح عبر locale مثال خارج.

معنى رسم دخول تعليم مسار أول صفحة صفحة تنقل رابط سوف صريح كتابة خروج `index.md` أو `index.zh.md`، جعل GitHub مباشر فتح صفحة، بينما لا هو دليل قائمة. قد مراجعة حساب basic،framework و practice مدخل متساو استخدام هذه أداة جسم هدف؛ عادي package، شفرة المصدر، عرض مثال و manifest دليل مرجع ما زال صالح، لا وجود عام دليل رابط منع توقف قاعدة.

إعداد مقابل نواة قلب سوف اعتماد حسب مستودع ملف شجرة تحليل متبادل مقابل مسار، مجددا تطبيق نشط وثب نطاق و manifest ترتيب حذف بند يسمى كلمة، و في بنية مقارنة مقارنة وقت يأخذ إعداد مقابل locale مسار مواصفة تحويل لـ نفس عدد إنجليزي نص أخ أخ ملف هوية.`verify-translation-pairing` سوف آخر خارج رفض locale خطأ هدف، و تقرير إبلاغ مصدر ملف، سطر رقم، فعلي URL و مدة نظر URL. دمج قيادة، آلة آلة قلب ترجمة بسيط تقرير و Cordis توليد جهاز استخدام نفس طقم نطاق يسمى كلمة و دلالة مقارنة مقارنة، لذلك حيث قدرة قبول صحيح تأكيد locale مسار فرق مختلف، أيضا لن تقليل ضعيف أخرى بنية اشتراط.

Cordis subsystem منطقة كتلة توليد جهاز أولا تصيير نفس عدد catalog model، مجددا لـ العربية إخراج إسقاط إعداد مقابل وثيقة هدف. توليد منطقة كتلة مقارنة مقارنة فقط مواصفة تحويل هذه إعداد مقابل locale مسار؛marker، متن، ترتيب، شفرة، غير وثيقة URL و query/fragment بعد لاحقة ما زال يجب تدريجي بايت متسق.

قائم نشط وثب مزدوج لغة مصدر ملف متساو استخدام locale صحيح تأكيد هدف. إذا العربية هدف نقص قليل إنجليزي نص fragment id، فإن في مقابل ترجمة نص عنوان قبل توفير صريح `<a id>` آخر اسم، جعل اثنان عدد مصدر ملف بلا حاجة ثاني نسخة قلب ترجمة خريطة يكفي إبقاء نفس عدد مستقر fragment بعد لاحقة. إعداد مقابل متسق صفة سجل إشارة نحو ترحيل بعد محتوى.

## Verification

إعداد مقابل اختبار تغطية في إنجليزي نص locale اختيار، وجود أخ أخ ملف نطاق خارج هدف، نطاق داخل نقص قليل مقابل جانب هدف، لغة تبديل سطر ترتيب حذف،query/fragment أصل مثال إبقاء، لا من دليل هدف دفع قطع بحث جذب صفحة، تعريف صيغة رابط، إعادة كتابة و تشخيص. وثيقة شبكة محطة اختبار أيضا سوف ثابت في إنجليزي نص اثنان جانب قد مراجعة حساب basic،framework و practice مدخل، اشتراط هو جمع إشارة نحو أداة جسم بحث جذب صفحة. دمج قيادة، قلب ترجمة بسيط تقرير و Cordis توليد جهاز اختبار قسم آخر تغطية كل منها إزالة استهلاك مسار. كل لغة مادة فحص اشتراط locale خطأ رابط لـ صفر،fragment يمكن تحليل، توليد منطقة كتلة جديد طازج، إعداد مقابل سجل لـ حالي محتوى، و اشتراط وثيقة شبكة محطة نجاح بناء.

## Alternatives considered

**اثنان جانب كل إبقاء `.md` هدف.** هذا نوع طريقة قدرة إبقاء أصلي هدف متبادل انتظار، لكن سوف يجعل GitHub تنقل مغادرة فتح العربية لغة مادة. شبكة محطة إعادة كتابة لا يمكن إصلاح مستودع تصيير نتيجة.

**استخدام قلب ترجمة بعد عنوان fragment.** كل locale مخصص تابع fragment سوف اشتراط كل رابط توليد جهة حل ترجمة نص عنوان، أيضا سوف جذب دخول واحد نسخة ممكن حدوث عائم نقل خريطة. مشترك نفس عدد بعد لاحقة، و من هدف وثيقة توفير صريح آخر اسم، قدرة يجعل مستقر معرف عودة هدف وثيقة كل.

**صيانة locale رابط manifest.** إعداد مقابل اكتشاف، فقط يحتوي ترتيب حذف بند manifest و أخ أخ تسمية اتفاق قد قدرة كاف تحديد هدف هل يخص لغة مادة و إعداد مقابل مسار. ثاني نسخة سجل التسجيل سوف تكرار هوية واقع، و اشتراط كل مرة نقل حركة ملف أو إضافة جديدة إعداد مقابل وقت تزامن تحديث.

**فقط في إصدار وقت إعادة كتابة رابط.** وثيقة شبكة محطة قد هذا مثال معالجة، لكن GitHub و أخرى مستودع مصير سوف مباشر إزالة استهلاك مصدر ملف. صحيح تأكيد شفرة المصدر مسار ذاته حينئذ هو مستخدم مرئي سلوك.

## Consequences

هدف يخص نشط وثب مزدوج لغة لغة مادة وقت،GitHub قراءة من سوف إبقاء في ذاتي ذات اختيار لغة في؛ لم قدوم رجوع سوف من يملك مزدوج لغة بنية نفس طريق كل لغة مادة إعداد مقابل فحص رفض. إعداد مقابل اثنان جانب سوف متعمد استخدام مختلف إعداد مقابل وثيقة مسار تجميع كتابة، بينما رابط أخرى خاصية ما زال إبقاء متسق. مستقر إنجليزي نص fragment آخر اسم سوف لـ قلب ترجمة هدف زيادة قليل كمية دائم دائم معرف؛ معا يملك اثنان جانب إخراج توليد جهاز يجب أولا إسقاط locale مسار، مجددا سجل إعداد مقابل.
