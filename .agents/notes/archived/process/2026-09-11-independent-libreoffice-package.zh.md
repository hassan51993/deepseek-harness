# Agent Note: مستقل مسبق تحرير ترجمة LibreOffice حزمة

Status: implemented
Archived: 2026-09-11

[English](2026-09-11-independent-libreoffice-package.md) | العربية

## مشكلة

في عادي DSH بناء في تحرير ترجمة LibreOffice، سوف اشتراط كل مساهمة من و CI job نيل أخذ أداة سلسلة و تكرار تنفيذ كبير نوع هذا آلة بناء.Desktop أيضا حاجة قدرة مع مغادرة خط تثبيت مادة مادة توزيع غير ممكن تغيير جذب محرك مورد.

## قرار

[جذب محرك حزمة](../../../../native/libreoffice-wasm/package.json) اعتماد مستقل إصدار، فقط توجيه خروج ناتج بيان. شفرة المصدر دليل لا يخص رئيسي pnpm workspace. تثبيت لا يوجد دورة الحياة hook، تحزيم فقط تحقق قد لديه نجاح بناء، لا تنفيذ تحرير ترجمة.[إصدار سير العمل](../../../../.github/workflows/libreoffice-wasm-release.yml) فقط في واضح ضبط درجة وقت تحرير ترجمة؛ إصدار اشتراط مطابقة جذب محرك إصدار tag و تلقي حفظ حماية npm بيئة.

كل tarball يتضمن جذب محرك بيان و ناتج، مقابل شفرة المصدر إصدار، رقعة، كامل شفرة المصدر فرق مختلف، و بناء إرسال سطر شيء سماح يمكن إثبات و إعلان. تحزيم رفض لا مطابقة بناء سجل، يتم تعديل ناتج، لم صف دخول بيان جذب محرك ملف، ناقص إعلان و داخل وضع حرف جسم. فشل لن تلقائي إطلاق تحرير ترجمة.

[محلي معاينة قرار](../architecture/2026-09-10-local-office-preview.zh.md) متابعة مسؤول تحويل و صريح ناتج إعداد. هذا تعديل بناء قيام إصدار آلية، لا نحو DSH إضافة بعد لم إصدار جذب محرك اعتماد. قائم [Desktop حزمة تجميع دمج](../../../../apps/desktop/scripts/prepare-package-set.ts) ما زال هو لم قدوم ثابت إصدار اعتماد و ذلك مغادرة خط seed مسبق مدة تحميل جسم.

## اعتبار مرور بديل خطة

**في عادي بناء أو حزمة تثبيت خلال تحرير ترجمة.** أي جعل جذب محرك إصدار لا يوجد تغير، كل مستهلك أيضا يلزم تحمل تحمل أداة سلسلة متاح صفة اشتراط و تحرير ترجمة فتح إلغاء.

**سحب خروج عام Node تحويل مكتبة.** حرف جسم معالجة،Worker كل حق و تحويل API يمكن متابعة من مزود مسؤول. توزيع مسبق تحرير ترجمة ناتج و سوف تحرير ترجمة و DSH CI عزل لا حاجة ترحيل هذه منطق.

**سوف جذب محرك شفرة المصدر رابط لـ workspace اعتماد.** مساحة العمل رابط سوف يأخذ قد إصدار مسبق تحرير ترجمة حزمة استبدال لـ نقص قليل جذب محرك ملف شفرة المصدر دليل.

## أثر

جذب محرك يمكن مستقل في DSH تحرير ترجمة و إصدار إصدار. حزمة كشف ملف بينما غير تحويل API؛ مزود إبقاء وقت التشغيل كل حق.[تحزيم اختبار](../../../../scripts/libreoffice-package.spec.ts) فحص عادي بناء لا تحرير ترجمة LibreOffice.

أول مرة إصدار و ثابت إصدار مستهلك وصل دخول بعد لم إتمام. و سجل إعداد جهة لا متسق شفرة المصدر شجرة لا يستطيع إنتاج إصدار tarball. أول عدد يتم إزالة استهلاك جذب محرك إرسال سطر إصدار يجب معا إتمام حقيقي جذب محرك تحويل، تحزيم تثبيت، و Desktop مغادرة خط seed تحقق.
