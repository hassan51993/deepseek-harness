# Agent Note: كل بند فعلي جودة صفة تغيير كل يجب مرفق حمل Agent Note

Status: implemented
Archived: 2026-09-04

[English](2026-07-19-require-agent-notes-for-non-trivial-changes.md) | العربية

## مشكلة

إذا فقط في قرار يتم إقرار لـ حمل دائم، لديه تنازع اقتراح كما خروج شخص معنى مادة وقت عندئذ سجل Agent Note، فعلي جودة صفة تغيير حينئذ ممكن في لا يوجد حفظ قرار اعتماد حسب حال حال تحت سقوط أرض. شفرة و اختبار قدرة عرض تعديل محتوى، لكن لا يمكن مستقر إبقاء بعض نوع خطة فوز خروج سبب، يتم وضع ترك تجهيز اختيار خطة، و صيانة من قبول صار هذا.

## قرار

كل بند فعلي جودة صفة تغيير كل في نفس عدد PR(Pull Request) في إضافة جديدة أو تحديث حتى قليل واحد نسخة Agent Note. فعلي جودة صفة تغيير يشمل سلوك، هيكل بنية، عبر ملف أو عبر حزمة اتفاق، مسار أو أداة، اختبار سياسة، مغناطيس قرص صيغة، بروتوكول صيغة (wire format) أو إعداد صيغة، و صيانة من ممكن دمج إدارة إعادة مراجعة أخرى قرار.

تحديث قد يحتفظ هذا قرار Agent Note أي ممتلئ كاف قاعدة؛ فقط عند لا يوجد Agent Note يحتفظ هذا قرار وقت عندئذ إضافة جديدة سجل. تماما آلة آلة أو نطاق جزء، كما لا تغيير سلوك، اتفاق، بنية، مسار أو قرار اعتماد حسب تحرير يمكن إعفاء تجنب.[Agent Notes README](../../README.ar.md#when-to-write-one) يحتفظ هذا بند حد، أصل دليل `AGENTS.md` فإن يحمل معتاد إقامة إشارة أمر.

فقط لديه في حالي يحتفظ هذا قرار سجل حفظ كل وحيد لديه قرار اعتماد حسب، تجهيز اختيار خطة، أثر، تحقق اتفاق و واضح إشارة خروج تغطية نقص فتحة بعد، عندئذ يمكن سوف يتم تماما يحل محل implemented Agent Note دمج إلى هذا سجل في و حذف. نفس تغيير أيضا يلزم إصلاح دخول محطة رابط، و حذف العربية مقابل جانب ملف و مرافق مع سجل. فقط جزء يتم يحل محل وقت، اثنان عدد سجل ما زال يحتاج متبادل متبادل رابط و إبقاء و الآن حالة متسق؛ دمج حيث لا سوف قديم قرار تعديل كتابة صار و ذلك متبادل عكس قرار، أيضا لا يجعل git تاريخ يصبح قرار اعتماد حسب وحيد فرعي هذا.

لاحق قرار تماما إزالة مقارنة مبكر وظيفة وقت، فقط لديه هذا وظيفة قد من إنتاج شفرة، إعداد،schema، حفظ دائم صيغة أو بروتوكول صيغة، ترحيل و توافق سلوك في إزالة فقد، حالي وثيقة لم يعد سوف ذلك وصف لـ متاح، كما لا يوجد اختبار يأخذ هو بصفة تلقي دعم حمل سلوك قدوم تنفيذ، إزالة سجل عندئذ سوف يصبح حالي يحتفظ سجل. إزالة قرار اعتماد حسب و تحقق هذا وظيفة قد لا وجود اختبار يمكن إبقاء. هو يجب إبقاء هذا وظيفة الأكثر أول حركة آلة، لـ ماذا هذا حركة آلة قد لا كاف بـ إثبات متابعة إبقاء هذا وظيفة، تماما إزالة خارج تجهيز اختيار خطة، وضع ترك قدرة، إعادة جذب دخول شرط، و إثبات قد تام قاع إزالة تحقق. فقط وصف قد حذف سلوك تنفيذ بيان و اختبار قد مرور وقت، لا يخص حالي تحقق اتفاق. فقط إزالة واحد نوع نقل، قيمة افتراضية، تنفيذ أو عرض ما زال يخص جزء يحل محل.

مراجعة مسؤول تنفيذ هذا بند دلالة حد. تلقائي تحويل بوابة لا محاولة تجربة يأخذ فرق مختلف تصنيف لـ مستو كل أو فعلي جودة صفة تغيير، لذلك هذا بند سياسة سياسة لن زيادة بوابة مرحلة مقطع أو وقت التشغيل بين.

## تجهيز اختيار خطة

**فقط لـ يتم حكم قطع لـ حمل دائم، لديه تنازع اقتراح كما خروج شخص معنى مادة قرار اشتراط Agent Note.** هذا بند باب عتبة مرور في رئيسي مراقبة، فعلي جودة صفة تغيير ممكن يتم نظر لـ إظهار بينما سهل رؤية أو نطاق جزء تعديل، من بينما فقد فقد Agent Note هذا ينبغي حفظ قرار اعتماد حسب.

**كل بند تغيير كل يجب إضافة جديدة Agent Note.** عند قائم Agent Note قد يحتفظ هذا قرار وقت، هذا سوف إنتاج تكرار سجل، أيضا سوف يجعل صاف آلة آلة تحرير تحمل تحمل فارغ ثقب مسار سالب تحمل.

**دائم دائم إبقاء كل نسخة يتم تماما يحل محل Agent Note.** فقط يلزم قديم قرار ما زال لديه جزء ملائم استخدام، حينئذ حاجة إبقاء متبادل متبادل رابط سجل؛ لكن تماما بطلان implemented Agent Note و سجل حالي حالة اتفاق متبادل تناقض درع، و تكرار حفظ هذا يمكن من واحد سجل يحتفظ قرار اعتماد حسب.

**إضافة جديدة `superseded/` دورة الحياة.** إضافة جديدة دورة الحياة ما زال سوف إبقاء مرور وقت سجل و توسيع ورقة دليل شجرة، صيغة بوابة و صيانة قاعدة، لكن لا يمكن نقص قليل تكرار محتوى.

**سوف قديم Agent Note تعديل كتابة لـ بديل هو قرار.** هذا مثال سوف مسح ذهاب قرار حد و ذلك مرفوض تجهيز اختيار خطة. دمج فعل قاعدة هو في حذف مرور وقت ملف قبل، أولا من حالي يحتفظ قرار سجل حفظ هذه واقع.

**إبقاء قد إزالة وظيفة كل واحد بند تنفيذ و اختبار دقيق عقدة.** هذا سوف في بديل سجل في إعادة بناء مرور وقت سجل. إزالة قرار يحتفظ سجل فقط إبقاء إدارة حل أو إعادة مراجعة نظر حالي قد إزالة حالة الذي يحتاج قرار اعتماد حسب و تحقق، قد حذف آلية ما زال يمكن من git تاريخ فحص نظر.

**إضافة CI فرق مختلف تصنيف بوابة.** آلة آلة فحص لا يمكن يمكن اعتماد حكم قطع دلالة تغيير هل مستو كل، مقدار خارج بوابة أيضا سوف زيادة وقت التشغيل بين، و جذب دخول خطأ تقرير أو جدول وجه دمج قاعدة.

## أثر

- كل بند فعلي جودة صفة تغيير كل سوف في تنفيذ جانب إبقاء ذلك قرار اعتماد حسب و يتم وضع ترك تجهيز اختيار خطة.
- مساهمة من صيانة قائم قرار يحتفظ سجل، بينما لا هو إنشاء تكرار سجل.
- يتم تماما يحل محل سجل يمكن عودة و إلى واحد حالي يحتفظ سجل في، معا لا فقد فقد ذلك وحيد لديه قرار اعتماد حسب أو تحقق اتفاق.
- بعد قدوم يتم إزالة وظيفة يمكن فقط لديه واحد حالي يحتفظ سجل، بينما بلا حاجة متابعة إبقاء مرور وقت تنفيذ و اختبار بيان.
- فقط جزء يتم يحل محل حال حال ما زال يحتاج واضح سجل و متبادل متبادل رابط؛ حذف سجل فإن يجب في نفس تغيير في تنظيف رابط و مزدوج لغة إعداد مقابل.
- آلة آلة تحرير ما زال إبقاء خفيف كمية، بوابة توسيع اندفاع و وقت التشغيل بين أيضا إبقاء ثابت.
