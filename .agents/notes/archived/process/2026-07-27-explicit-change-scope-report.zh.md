# Agent Note: صريح تقرير إبلاغ مستودع تغيير نطاق

Status: implemented
Archived: 2026-09-04

[English](2026-07-27-explicit-change-scope-report.md) | العربية

## مشكلة

[pre-push سير العمل](../../../skills/dsh-pre-push-checks/SKILL.md) حاجة أخذ نيل متبادل مقابل في فعلي أساس دقيق diff، لكن حسب `origin/<current-branch>` بنية صنع مرجع وجود اثنان صنف مشكلة: مقابل في رقم مرة دفع إرسال قبل تتبع أثر `origin/master`، بعد بلا نفس اسم بعيد طرف فرع جديد worktree فرع، هذا مرجع لا يمكن تحليل؛ مقابل في PR(Pull Request) بـ آخر وظيفة فرع لـ أساس دقيق كومة تراكم فرع، هذا مرجع سوف خطأ وصف أساس دقيق.[شفرة مراجعة](../../../skills/dsh-code-review/SKILL.md) و[وثيقة مراجعة حساب](../../../skills/dsh-doc/SKILL.md) سير العمل نفس مثال حاجة حكم قطع حالي أساس دقيق.

خطأ نطاق ممكن متروك تسرب تلقي أثر مسار، من بينما تقليل ضعيف دليل اختيار. ثلاثة نقطة نطاق إنتاج قد إيداع diff أيضا تماما لا يمكن شرح Git في ذاك هذا مستقل قد مؤقت تخزين، لم مؤقت تخزين و لم تتبع أثر طبقة.

## قرار

أصل دليل `change-scope` أمر اشتراط توفير `--base <ref>`، قبول اختياري `--head <ref>`(افتراضي لـ `HEAD`) ، و كتابة خروج واحد نسخة حمل رقم الإصدار JSON تقرير إبلاغ. هذا أمر سوف فحص قياس اختلاف معنى، سوف اثنان عدد إدخال تحليل لـ commit، و اشتراط اثنان من تماما جيد لديه واحد دمج أساس نقطة، بعد عندئذ سوف عرض تقرير إبلاغ. تقرير إبلاغ سجل مستودع أصل دليل (لا مقابل مسار في دمج قاعدة فارغ أبيض محرف عمل مواصفة تحويل معالجة) ، إدخال مرجع، تحليل بعد أساس دقيق، رأس جزء و دمج أساس نقطة commit ID، و ترتيب ترتيب بعد قد إيداع، قد مؤقت تخزين، لم مؤقت تخزين و لم تتبع أثر مسار تجميع دمج. مسار سجل أولا حسب أصلي NUL بايت قطع قسم؛ مستودع أصل دليل و كل بند مسار كل بـ صارم إطار UTF-8 حل رمز. لقاء إلى بلا فاعلية قيمة وقت، تقرير إبلاغ سوف في توقف، لن استخدام استبدال محرف بديل بديل بلا فاعلية بايت أو يأخذ مختلف قيمة دمج لـ واحد بند.

قد إيداع مسار من تحليل بعد دمج أساس نقطة و رأس جزء بين مقارنة مقارنة نيل خروج. أي جعل `--head` إشارة تحديد أخرى commit، كل صنف لم إيداع مسار تجميع دمج ما زال بداية نهاية وصف حالي worktree و بحث جذب. كل مرة Git استكشاف قياس كل سوف منع استخدام إعداد نظام الملفات مراقبة نظر جهاز و اختياري إضافة قفل؛diff إعداد لا يستطيع إخفاء فرعي وحدة، أيضا لا يستطيع استدعاء خارجي diff أو نص تحويل قيادة؛ نظام منع استخدام إعادة تسمية فحص قياس، لذلك إعادة تسمية قبل بعد مسار كل سوف إبقاء في نتيجة في.

هذا أمر من لا تخمين قياس أو نيل أخذ أساس دقيق، لا استعلام شفرة حمل إدارة مزود، أيضا لا اختيار اختبار. استدعاء هذا أمر كل سير العمل كل سوف تحقق حالي بعيد طرف أو كومة تراكم حالة، صريح توفير أساس دقيق، و سوف هذا نسخة واقع تقرير إبلاغ بصفة دلالة مراجعة أو دليل اختيار إدخال.

تجمع تركيز مؤقت مستودع اختبار تغطية صريح مرجع و كومة تراكم مرجع، كل لم إيداع تعديل طبقة، دمج قاعدة مسار فارغ أبيض، صارم إطار مسار حل رمز، بلا فرعي أثر استكشاف قياس، بلا فاعلية مرجع، تحديد صفة schema، و تقرير إبلاغ قبل بعد ثابت مرجع، بحث جذب، إعداد و حالة.

## اعتبار مرور بديل خطة

**متابعة استخدام مؤقت تجميع تركيب diff أمر، مساعد بـ نص حرف تحويل رجوع شرح.** هذا نوع طريقة بلا حاجة إضافة مستودع نص برمجي، لكن مختلف سير العمل مقابل معتاد رؤية جديد worktree و كومة تراكم أساس دقيق توسيع اندفاع ما زال سوف عمل خروج لا متسق معالجة، بينما كما لا يمكن شمول غطاء لم إيداع تعديل طبقة.

**أصل حسب إعداد فوق تنقل دفع قطع أساس دقيق.** رقم مرة دفع إرسال قبل، فوق تنقل ممكن هو `origin/master`؛ دفع إرسال بعد، هو ممكن هو نفس وظيفة فرع؛ أيضا ممكن هو واحد رأس جزء دعم، بينما ذلك PR بـ آخر وظيفة فرع لـ أساس دقيق. لا يوجد واحد نوع دفع قطع قدرة كاف ملائم لأجل كل توسيع اندفاع.

**في أمر داخل استعلام GitHub بـ تحديد أساس دقيق.** هذا سوف يأخذ محلي فقط قراءة تقرير إبلاغ ربط إلى مفرد واحد شفرة حمل إدارة منصة و شبكة شبكة سند إثبات، لكن ما زال لا يمكن تحليل بعد بلا PR فرع.

**أصل حسب تغيير مسار توليد مطلوب اختبار.** تغيير مسار لا يمكن كشف عرض مرور من إعداد، حركة حالة تحميل، عملية فرعية،worker، بناء ناتج أو مزود لمس بلوغ سلوك.pre-push سير العمل ما زال يجب عبر حكم قطع قدوم اختيار دليل.

**تقرير إبلاغ حالي فرع و فوق تنقل، و صيانة و سطر شخص صنف يمكن قراءة مصير.** استدعاء جهة في استدعاء قبل قد تحقق فرع و أساس دقيق حالة، لا يوجد مستهلك استخدام هذه حقل، بينما صيغة تحويل نص حرف فقط سوف تكرار JSON schema، و لا يستطيع رفع عال مسار كامل صفة.

## عاقبة

صريح إدخال ما زال ممكن إشارة تحديد خطأ أساس دقيق، لكن هذا نوع خطأ هو مرئي: تقرير إبلاغ في سوف عرض إدخال مرجع و تحليل خروج ثلاثة عدد commit ID. استدعاء جهة حاجة دفع خروج قليل كمية صار هذا، في تشغيل هذا أمر قبل تحقق فوري أساس دقيق و من بعيد طرف نيل أخذ هو.

نص schema متعمد لا يمثل غير UTF-8 مسار بايت. يحتوي لديه هذا صنف مسار مستودع يجب أولا إعادة تسمية هذه مسار عندئذ قدرة توليد تقرير إبلاغ، بـ هذا إبقاء نطاق دقيق، بينما غير إرجاع لديه ضرر نتيجة.

مستودع حاجة صيانة واحد Git توسيع اندفاع مساعد مساعدة أداة و متبادل ينبغي تجمع تركيز اختبار. من هذا،pre-push دليل اختيار، شفرة مراجعة و وثيقة مراجعة حساب يمكن مشترك واحد نسخة صلة في قد إيداع تغيير و محلي تغيير تحديد صفة فقط قراءة شرح، بينما لا لا بد خلط دخول شفرة حمل إدارة منصة أو سياسة مسؤولية.
