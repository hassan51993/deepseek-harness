# Agent Note: متصفح عرض عرض GIF تسجيل صنع

Status: implemented
Archived: 2026-07-26

[English](2026-07-23-browser-demo-gif-recording.md) | العربية

## مشكلة

متصفح عرض عرض واحد مباشر عبر مرة صفة قطع أخذ و تحرير رمز أمر صنع عمل. هذا سوف توجيه يؤدي بث وضع عقدة عزف و إخراج كبير صغير لا متسق، سعة سهل يجعل تسجيل صنع من اختيار وصل متابعة تسجيل صنع، عكس بينما إخفاء غطاء لديه استخدام حالة تغير، أيضا ممكن نموذج غامض حقيقي خادم أو API مسار و fixture(اختبار قبل وضع بيانات) بين حد حد. سوف محلي تسجيل صنع و مرفق عنصر فوق نقل أو PR(Pull Request) تحرير دمج في نفس مهمة في، أيضا سوف يجعل هذا ينبغي فقط معالجة وسيط جسم مهمة نيل نيل غير متصل بعيد مسار كتابة إذن.

## قرار

مستودع توفير [`record-browser-gif`](../../../skills/record-browser-gif/SKILL.md) skill(تقنية قدرة) ، لأجل توليد محلي متصفح عرض عرض ناتج. هذا skill استخدام حالي متاح متصفح تحكم سير العمل، أولا تأكيد طلب مسار هو حقيقي مسار، من fixture دعم دعم، أيضا هو اعتماد أخرى نموذج محاكاة طريقة، مجددا فقط في UI بلوغ إلى دلالة فوق يمكن مراقبة حالة بعد قطع أخذ واحد مجموعة دقيق بسيط قسم مرآة لقطة. لقطة ملف تخزين وضع في مستودع `.gitignore` تجاهل اختصار `.playwright-mcp/` دليل تحت (متصفح أداة فقط قدرة كتابة ذلك سماح أصل دليل) ، لن فعل قذر worktree.

مع مرفق `encode_gif.py` مساعد مساعدة نص برمجي حسب كلمة قاعدة ترتيب ترتيب صف كل لقطة، لـ كل لقطة ضبط واضح توقف إبقاء وقت طويل، عبر `ffmpeg` ضبط لون لوح خط الإنتاج تحرير رمز، و استعارة مساعدة `ffprobe` تحقق مصدر رسم مثل مقياس قياس و تحرير رمز نتيجة لقطة عدد، مقياس قياس، وقت طويل و بايت حد أعلى. تسجيل صنع في إرجاع قد تحقق GIF قطعا مقابل مسار بعد أي انتهاء؛ عند مهمة يتضمن يأخذ GIF مرفق إلى PR وقت،[GUI PR GIF دليل قرار](2026-07-26-gui-pr-gif-evidence-and-assets-branch.md) يملك قوي صنع دليل سياسة سياسة و مع بعد assets فرع إصدار خطوة.

## سبق اعتبار بديل خطة

**وصل متابعة تسجيل صنع نظر تردد بعد مجددا تحويل.**وصل متابعة تسجيل صنع قدرة إبقاء كل مرة ضوء علامة نقل حركة و تحميل مرور عبور، لكن سوف إنتاج جسم تراكم أكثر كبير، جاف إزعاج أكثر كثير ناتج، أيضا أكثر صعب إبقاء تحديد بث وضع وقت ترتيب. حالة قسم مرآة أكثر ملائم دمج بسيط قصير وظيفة عرض عرض، لأن متعمد معنى دليل فقط هو قليل عدد بضعة عدد مرئي حالة تغير.

**في skill في إبقاء داخل ربط `ffmpeg` إعداد جهة.**كل مرة تشغيل كل إعادة تجميع جذب رقم تحويل معنى، وقت ترتيب بيان، ضبط لون لوح مرور ترشيح جهاز، تغطية سلوك و تحرير رمز بعد فحص، سعة سهل خروج خطأ. مع مرفق مساعد مساعدة نص برمجي جعل هذه آلية إبقاء يمكن تنفيذ،skill فإن مسؤول حكم قطع أي وقت قطع أخذ رسم وجه.

**قبول دخول GitHub مرفق عنصر فوق نقل و وصف تحرير.**فوق نقل و بعيد مسار تعديل حاجة كل منها مستقل هوية إقرار إثبات، تأكيد و استعادة قاعدة. يجعل تسجيل صنع ذاته إبقاء محلي كما يمكن سحب إلغاء أي صيانة هذا واحد حد؛ مقابل تأكيد يحتاج يأخذ GIF مرفق إلى PR مهمة،[GUI PR GIF دليل قرار](2026-07-26-gui-pr-gif-evidence-and-assets-branch.md) يملك ذلك عدد لديه حد إصدار خطوة.

**كل عند fixture أكثر سعة سهل نشر وضع وقت حينئذ استخدام هو.**عند طلب واضح اشتراط من fixture دعم دعم عرض عرض وقت، استخدام fixture هو صالح؛ لكن هو لا يمكن لـ حقيقي خادم أو حقيقي API إعلان توفير دليل. هذا skill سوف إبقاء طلب إشارة تحديد عرض عرض مصدر، و في نقص قليل أولا قرار شرط وقت تقرير إبلاغ مشكلة، لن تخصص ذاتي أكثر تعديل مصدر.

## عاقبة

تسجيل صنع نتيجة يصبح جسم تراكم صغير، يمكن تكرار توليد محلي ناتج، واضح علامة ملاحظة عرض عرض مصدر، و و مستودع إبقاء صاف واضح حد. هذا سير العمل وضع ترك تدفق سلس وصل متابعة حركة حالة فاعلية نتيجة، اعتماد هذا آلة توفير `ffmpeg` و `ffprobe`، و اشتراط تسجيل صنع من تعرف آخر أداة لديه دلالة معنى معنى قطع أخذ وقت نقطة. اختبار استخدام أربعة حالة متصفح عرض عرض و بلا فاعلية وقت طويل إدخال فحص تحقق مساعد مساعدة نص برمجي؛skill بنية و مستودع رابط من skill تحقق جهاز و وثيقة بوابة تغطية.
