# Agent Note: تحقق قد إصدار وثيقة fragment

Status: implemented
Archived: 2026-09-04

[English](2026-08-13-published-document-fragments.md) | العربية

## Problem

`verify-md-links` استخدام GitHub Markdown عنوان id تحقق fragment، بينما وثيقة شبكة محطة استخدام VitePress تصيير عنوان. يتضمن مقارنة كثير علامة نقطة عنوان و قلب ترجمة بعد عنوان ممكن عبر شفرة المصدر تحقق، لكن في قد إصدار HTML في لا يوجد مقابل id.VitePress بناء نجاح فقط سوف تحقق هدف صفحة، لن تحقق fragment id.

## Decision

`docs:build` و ذلك MPA تغيير جسم سوف في VitePress توليد `website/.dist` بعد تشغيل `verify-doc-site-fragments`. هذا تحقق جهاز تحليل كل توليد HTML صفحة، حسب وفق VitePress clean URL تحليل كل داخلي fragment رابط، و في بناء ناتج لا وجود، توجيه لديه اختلاف معنى،href صيغة خطأ، هدف صفحة لا وجود أو طلب id ناقص وقت فشل. اختبار وحدة تغطية هذه فشل، و clean URL،`.html` آخر اسم، نفس صفحة رابط، تحرير رمز و حرف وجه id و خارجي رابط ترتيب حذف.

أي GitHub id و VitePress id مختلف fragment هدف عنوان كل سوف حمل لديه و GitHub توافق صريح آخر اسم. إنجليزي نص يد كتابة صفحة و قلب ترجمة صفحة سوف في عنوان قبل إضافة آخر اسم؛ قلب ترجمة صفحة استخدام مزدوج لغة مقابل جانب ملف مشترك إنجليزي نص id. توليد إعداد، أداة و حفظ دائم دليل من الذي تابع توليد جهاز إخراج آخر اسم. شفرة المصدر Markdown تحقق إبقاء مستقل، ما زال سوف رفض في مستودع تصيير قاعدة تحت لا يمكن تحليل رابط.

هدف وجود إعداد مقابل ملف وقت، ملف مسار حسب وفق[مزدوج لغة وثيقة رابط محلي تحويل قرار](2026-08-18-localized-bilingual-links.zh.md) تتبع مع مصدر وثيقة locale؛ إعداد مقابل اثنان جانب ما زال استخدام تماما نفسه query و fragment بعد لاحقة.

## Alternatives considered

**استخدام كل لغة مخصص تابع fragment.** إعداد مقابل ملف مسار سوف تتبع مع مصدر وثيقة locale، لكن مزدوج لغة اثنان جانب ما زال لحظة معنى إبقاء نفسه fragment بعد لاحقة. لغة مخصص تابع fragment سوف اشتراط كل رابط توليد جهة كل حل هدف لغة قلب ترجمة بعد عنوان.

**اعتماد VitePress عنوان id.** هذه id أخذ قرار في تصيير بعد علامة نقطة و محلي تحويل عنوان نص، لا يمكن إبقاء مستودع رابط و توليد مرجع قد استخدام GitHub id.

**فقط فحص Markdown شفرة المصدر.** هذا نوع فعل قاعدة لن تحقق إصدار ناتج، أيضا لا يمكن اكتشاف GitHub و VitePress slug حساب قاعدة بين فرق مختلف.

## Consequences

كل مرة إنتاج وثيقة بناء كل سوف قراءة مرة توليد HTML، في قائم شبكة محطة بناء بعد زيادة واحد محدود فحص. عبر صفحة fragment رابط يجب إشارة نحو إصدار بعد ما زال وجود id. صريح آخر اسم يصبح قد إصدار مشاركة اعتبار واحد جزء، جعل عنوان أكثر تبديل لغة أو علامة نقطة بعد ما زال قدرة إبقاء قائم fragment.
