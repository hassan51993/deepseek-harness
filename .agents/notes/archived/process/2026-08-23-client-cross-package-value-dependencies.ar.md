# Agent Note: Client عبر حزمة قيمة اعتماد تصنيف

Status: implemented
Archived: 2026-09-04

[English](2026-08-23-client-cross-package-value-dependencies.md) | العربية

## مشكلة

[PR #2728](https://github.com/deepseek-ai/deepseek-harness/pull/2728) و [PR #2911](https://github.com/deepseek-ai/deepseek-harness/pull/2911) تفكيك قسم Client حزمة بعد، وظيفة إضافة manifest في أيضا إبقاء لديه 15 بند `dsh.client.external` طلب. أي جعل مستهلك فقط حاجة واحد نوع، واحد مقطع صغير نوع صاف تحويل أو وصول قد حقن Cordis service، هذه طلب أيضا سوف يأخذ عادي قيمة import تغيير صار تزامن وحدة جدول ترتيب قيد.

آلة آلة حذف كل import سوف إنتاج آخر اقتران دمج: عام أداة حزمة ممكن تغيير صار مختلط بند عمل خدمة owner،service ممكن تحمل تحميل صاف عرض تحويل، أو من فقط لـ عبر تكرار فحص قياس بينما يأخذ target سلوك تجميع في إلى واحد موضع. صيانة Client وقت، حاجة أولا استخدام نفس طقم مسار تصنيف، مجددا قرار عبر حزمة مرجع ينبغي عند وضع في أي داخل.

## قرار

كل بند Client عبر حزمة مرجع كل حسب فعلي عبر تجاوز حزمة حد محتوى تصنيف. وظيفة إضافة لا من آخر عدد وظيفة إضافة استيراد وقت التشغيل قيمة، أيضا لا إعلان `dsh.client.external`.[Client shell قسم طبقة قرار](../architecture/2026-08-15-client-shells-and-dynamic-packages.ar.md) متابعة مسؤول bundle بناء و وحدة جدول تحميل؛ هذا قرار دخول واحد خطوة حد تحديد وظيفة شفرة مثل أي استخدام هذه آلية.

| حال شكل | معالجة طريقة | سبب |
| --- | --- | --- |
| لم استخدام قيمة أو تحويل إرسال export | حذف | لا يوجد استدعاء جهة اعتماد لا حاجة إبقاء owner. |
| مشترك إعلان | من إعلان جهة حزمة استخدام `import type` استيراد | يتم مسح حذف import إبقاء مفرد واحد نوع مرجعي، لكن لا إنتاج وقت التشغيل حافة. |
| لديه حالة، تلقي دورة الحياة قيد أو يمكن استدعاء وظيفة سلوك | عبر حقن Cordis service كشف | توفير إضافة يملك تنفيذ و دورة الحياة؛ مستهلك فقط اعتماد service اسم و واجهة. |
| عرض مساهمة | عبر إعلان جهة slot تسجيل | owner تحكم وضع وضع موضع، كل مساهمة جهة ما زال يمكن مستقل تحميل. |
| عام بلا حالة مساعد مساعدة دالة أو أساس أساس مكون | وضع دخول ضيق مسؤولية ساكن حالة أداة حزمة أو `ui-primitives` | فقط لديه لا يحتفظ وظيفة حالة، دورة الحياة أو مجال مرجعي سلوك عندئذ سماح يتم كثير عدد حزمة تزامن مشترك. |
| صغير نوع target مخصص تابع إسقاط | كل target إبقاء واحد نسخة محلي تنفيذ | Chat و Trajectory يمكن مستقل حل تفسير نفس حمل دائم حدث؛ فقط فقط إعادة استخدام شفرة لا كاف بـ إثبات ينبغي بناء قيام وظيفة اعتماد. |
| توليد Remote ناتج | فقط في يملك توليد تسجيل API نقل تجميع طبقة استيراد | توليد provider هو نقل وصل خط، لا هو وظيفة حزمة يمكن استدعاء مساعد مساعدة API. |

متعمد إبقاء target محلي فرعي هذا فقط استخدام `jscpd:ignore-start`/`jscpd:ignore-end` حزمة إقامة تكرار تنفيذ، و في ملاحظة تفسير في نقطة اسم متبادل متبادل مستقل owner؛ ترتيب حذف نطاق لا نيل تغطية دورة محيط عمل خدمة منطق. فقط لديه دلالة مستقل في كل حالي استدعاء جهة وقت، عام سلوك عندئذ دخول أداة حزمة؛ هذا مرة تنظيف يأخذ Workspace مسار صيغة تحويل وضع دخول `dsh-util-workspace-path`، يأخذ بايت تحرير رمز وضع دخول `dsh-util-crypto`، يأخذ مشترك مرجع رسم علامة وضع دخول `ui-primitives`.

`verify-client-packages` رفض `packages/client/*` تحت كل `dsh.client.external` إعلان. في هذا وظيفة شجرة خارج، كل بند إعلان كل يجب مقابل إنتاج شفرة في وقت التشغيل import أو re-export. إبقاء اثنان بند طلب هو Session Controller → API Gateway و Workspace Controller → API Gateway، اثنان من كل يخص نقل أساس أساس ضبط تطبيق.Client bundle preset أيضا سوف رفض حيث غير وحدة جدول طلب، أيضا لم يتم واضح إضافة دخول ساكن حالة إدخال allowlist workspace وقت التشغيل import.

موجه إلى Host نقل مهايئ لا يخص وظيفة إضافة منع أمر.Connection يمكن استخدام API Proxy carrier تنفيذ،`api/remotes` يمكن تحميل توليد Host Remote provider؛ هذه import لأجل تجميع نقل، بينما لا هو مشترك وظيفة سلوك.

## اعتبار مرور بديل خطة

**يأخذ كل إعادة استخدام قيمة كل وضع إلى `uiConversation`.** مرفوض، لأن صاف event→view تحويل سوف تغيير صار service استدعاء أو وظيفة export، إجبار جعل Chat،Trajectory،Approval،Question،Subagent و Workspace تحميل واحد غير متصل وظيفة owner.

**إبقاء وظيفة إضافة `dsh.client.external` إعلان.** مرفوض، لأن تحميل نجاح فقط سوف يأخذ تزامن قيمة اعتماد ترتيب صريح تحويل، لن إزالة حذف هذا اعتماد.

**يأخذ كل تكرار دالة كل نقل دخول نفس عدد أداة حزمة.** مرفوض، لأن target مخصص تابع حل تفسير سوف لذلك نيل نيل واحد وهمي زائف مشترك owner. فقط لديه دلالة مستقل في استدعاء جهة بلا حالة سلوك عندئذ يخص ساكن حالة أداة.

**تجاهل اختصار الكل Client تكرار شفرة.** مرفوض، لأن تكرار افتراضي ما زال هو لديه استخدام إشارة. كل بند ignore يجب نطاق ضيق ضيق، و شرح أي بعض أداة اسم target حاجة متعمد إبقاء مستقل.

## عاقبة

15 بند وظيفة إضافة external طلب قد إزالة، مشترك إعلان import إبقاء صريح كما فقط نوع تحويل. وظيفة تحميل ترتيب من Cordis service و slot قرار، لم يعد من تزامن وظيفة وحدة import قرار.

قليل كمية إسقاط دالة وجود اثنان نسخة تنفيذ. كل owner يمكن مستقل عرض دخول، تكرار فحص قياس ما زال تغطية ملاحظة حل فرعي هذا بـ خارج الكل شفرة. ساكن حالة أداة حزمة زيادة قليل كمية عام مشترك API، و كما يجب إبقاء بلا حالة كما يمكن في متصفح تشغيل.

هذا بند قاعدة حسب حزمة زاوية لون منطقة قسم، و غير كل وجه منع توقف عبر حزمة قيمة. تحميل أو بروتوكول تجميع حاجة أساس أساس ضبط تطبيق مهايئ و توليد تسجيل ناتج ما زال إبقاء مباشر import،`verify-client-packages` فإن تأكيد حفظ هذه مثال خارج إبقاء مرئي كما تأكيد فعلي ما زال يتم استخدام.
