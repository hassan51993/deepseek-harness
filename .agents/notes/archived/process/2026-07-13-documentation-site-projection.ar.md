# Agent Note: سوف مرجعي وثيقة إسقاط إلى شبكة محطة

Status: implemented
Archived: 2026-09-04

[English](2026-07-13-documentation-site-projection.md) | العربية

## مشكلة

مستودع حاجة واحد يمكن تنقل وثيقة شبكة محطة، لكن لا يستطيع يجعل شبكة محطة دليل يصبح ثاني عدد وثيقة مصدر. يأخذ حزمة إشارة جنوب، هيكل بنية صفحة أو توليد دليل نسخ إلى شبكة محطة مخصص استخدام دليل شجرة، سوف جعل اثنان نسخة فرعي هذا حدوث عائم نقل؛ يجعل VitePress مباشر إشارة نحو مستودع أصل دليل، أيضا سوف يأخذ عام URL و تنقل و داخلي ملف تخطيط اقتران دمج. مستودع متبادل مقابل رابط في شبكة محطة فوق أيضا حاجة إشارة نحو مختلف موضع: قد إصدار صفحة ينبغي إبقاء في محطة داخل، مصدر ملف و لم إصدار مساهمة من وثيقة فإن ينبغي إشارة نحو GitHub.

## قرار

مرجعي Markdown إبقاء في ذلك الذي تابع مستودع طبقة درجة في. موجه إلى منتج إشارة جنوب يقع في `docs/user/`، توليد مشاركة اعتبار مورد مادة إبقاء في قائم توليد دليل في، هيكل بنية صفحة و فعلي تشغيل يد سجل (cookbook) صفحة أيضا إبقاء في قائم `docs/` مسار.

`website/docs.ts` هو واحد نسخة صريح إصدار manifest(بيانات وصفية بيان). كل بند سوف واحد مرجعي مصدر ملف خريطة إلى مستقر عام توجيه، جانب حافة شريط، قسم منطقة و ترتيب. لذلك، إضافة جديدة أو إزالة قد إصدار صفحة هو واحد بند يمكن مراجعة manifest تغيير، بينما لا هو خفي صيغة دليل مسح نتيجة.

في VitePress بدء أو بناء قبل،`scripts/project-doc-site.ts` سوف يأخذ manifest إسقاط إلى يتم تجاهل اختصار `website/.generated/` دليل. توليد دليل شجرة التزام دوران عام توجيه، جعل VitePress تنقل،locale فحص قياس و محلي بحث استخدام نفس طقم توجيه تسمية. كل صفحة كل سوف نيل نيل واحد إشارة نحو ذلك مرجعي مستودع ملف `editSource` frontmatter حقل؛ تحرير رابط عودة ضبط فقط قراءة هذا صفحة بيانات، لذلك عام URL و مصدر ملف تخطيط ذاك هذا مستقل.

كل locale أول صفحة إسقاط فقط إبقاء مرجعي YAML frontmatter. موجه إلى مستودع متن إبقاء ذلك H1 و مزدوج لغة مصدر ملف رابط؛frontmatter تنفيذ[إبقاء locale ثابت سريع سرعة بدء إعادة تحديد نحو](../../../../docs/user/index.ar.md) ، شبكة محطة تنقل مسؤول تبديل locale.

إسقاط جهاز تحليل Markdown رابط، لكن لن إعادة تسلسل تحويل وثيقة. إشارة نحو آخر عدد قد إصدار مصدر ملف رابط سوف تغيير صار محطة داخل متبادل مقابل توجيه؛ إشارة نحو لم إصدار مستودع ملف رابط سوف تغيير صار `deepseek-ai/deepseek-harness` مستودع رئيسي صفحة تحت مصدر ملف رابط؛ مستودع صورة سوف يتم نسخ صدفة دخول توليد شجرة و من ذلك داخل مرجع ([سبب](2026-08-06-doc-site-carries-its-images.ar.md)). متبادل مقابل هدف لا وجود وقت، إسقاط سوف فشل. اختبار وحدة سوف قفل تحديد هذه تحويل سلوك،`docs:check` فإن تشغيل إسقاط جهاز اختبار و VitePress إنتاج بناء، و سوف اثنان من قبول دخول `doc-sync` و و سطر وثيقة بوابة.

`verify-public-repository-links` سوف رفض قد تتبع أثر ملف في إشارة نحو غير ممكن استخدام قديم مستودع مرجع. مصدر ملف رابط و تحرير رابط استخدام حالي مستودع رئيسي صفحة.

`website/AGENTS.md` هو شبكة محطة فرعي شجرة في وحيد صيانة Markdown ملف. إسقاط جهاز اختبار سوف قطعة رفع كل قد تتبع أثر ملف و لم يتم تجاهل اختصار لم تتبع أثر ملف، و رفض شبكة محطة في أي أخرى Markdown، لذلك شبكة محطة مخصص استخدام locale، توجيه،API أو توليد مصدر ملف فرعي هذا لا يمكن التفاف مرور إصدار manifest.

Mermaid تصيير مرجعي رسم جدول. شبكة محطة مساحة العمل صريح إعلان `vitepress-plugin-mermaid` اشتراط Vite مسبق تحزيم 5 عدد حزمة، لأن pnpm صارم إطار اعتماد عزل سوف جعل محلي تطوير خادم لا يمكن استخدام هذه نقل تمرير اعتماد.

إعداد بعد Markdown مصير سوف في مفرد مرة بناء خلال ذاكرة مؤقتة غير Mermaid، غير snippet شفرة محيط شريط، ذاكرة مؤقتة مفتاح يتضمن تأكيد قطع متن،info string، قسم فصل رمز و token خاصية. مزدوج لغة إسقاط في نحو نصف عدد شفرة محيط شريط هو تكرار محتوى، لذلك Shiki فقط تصيير مرة كل نوع مختلف يمثل.Mermaid محيط شريط لن دخول ذاكرة مؤقتة، لأن إضافة إخراج يتضمن token موضع id؛VitePress snippet فإن في تصيير خلال تحليل مصدر ملف. ذاكرة مؤقتة فقط في إنتاج بناء في تفعيل، كل مرة بناء بعد سوف مع مصير واحد نفس إسقاط، و كما لن تغيير توليد محيط شريط HTML.

شبكة محطة إصدار و شبكة محطة بناء إبقاء قسم مغادرة. مخصص استخدام GitHub Actions سير العمل تشغيل قائم وثيقة بوابة، سوف `website/.dist` بصفة Pages ناتج فوق نقل، و فقط في بناء نجاح بعد نشر.`actions/configure-pages` في بناء وقت نحو VitePress توفير هدف موضع base path، لذلك خاص Pages مصدر محطة، لم قدوم عام مشروع مسار و ذاتي تعريف مجال اسم لا حاجة كل منها فحص دخول إعداد.Pages مرئي صفة ما زال هو مستودع حمل إدارة ضبط، بينما لا هو سير العمل إذن.

## اعتبار مرور بديل خطة

**في `website/` تحت إيداع نسخ Markdown.** هذا نوع طريقة يجعل VitePress ضبط أكثر مباشر، لكن كل نسخة نسخ إشارة جنوب أو API جدول إطار كل سوف كثير خروج واحد ملكية جهة، و كما حاجة واحد طقم لا يمكن تعرف آخر مرجعي فرعي هذا تزامن اتفاق.

**يجعل `website/` يصبح كل قد إصدار صفحة مرجعي ملكية.** هذا نوع طريقة ما زال فقط لديه واحد نسخة فرعي هذا، لكن فقط هو لـ ممتلئ كاف مصير، حينئذ يأخذ هيكل بنية، توليد مشاركة اعتبار مورد مادة و موجه إلى مساهمة من مادة مادة نقل خروج كل منها مستودع ملكية طبقة درجة.

**تلقائي اكتشاف كل Markdown ملف.** هذا نوع طريقة الأكثر كبير حد درجة نقص قليل manifest صيانة، لكن سوف معنى خارج إصدار داخلي وثيقة، يأخذ مصدر ملف نقل حركة كشف لـ URL تغيير، و أصل حسب أحيانا لكن دليل ترتيب توليد تنقل.

**استخدام نظام الملفات رمز رقم رابط.** رمز رقم رابط إبقاء مفرد واحد مصدر، لكن لا يمكن حل قرار عام توجيه أو مستودع متبادل مقابل رابط مشكلة، بينما كما في محلي تطوير، حزمة أداة و حمل إدارة CI بيئة في سلوك لا كاف يمكن مسبق قياس.

**فقط في نشر سير العمل في بناء.** نشر عمل عمل يمكن في دمج بعد اكتشاف تصيير لذا عائق. يأخذ إنتاج بناء قبول دخول `doc-sync`، فإن بلا نقاش هل وجود عام نشر، نفس عدد لذا عائق كل قدرة في محلي و معتاد قاعدة CI في كشف.

**صلب تحرير رمز عام مشروع مسار.** ثابت `/deepseek-harness/` base ملائم لأجل عام مشروع URL، لكن لا ملائم لأجل خاص Pages محطة نقطة قسم إعداد وحيد مصدر محطة، أيضا لا ملائم لأجل لم قدوم ذاتي تعريف مجال اسم. استخدام Pages بيانات وصفية يمكن يجعل هذه هدف موضع مشترك نفس نسخة بناء اتفاق.

## عاقبة

وثيقة واقع فقط لديه واحد يمكن تحرير ملكية، عام توجيه في مصدر ملف نقل حركة بعد ما زال إبقاء مستقر، شبكة محطة أيضا قدرة قبول دخول توليد مشاركة اعتبار مورد مادة بينما بلا حاجة إيداع آخر نسخة توليد فرعي هذا. محلي تطوير سوف مراقبة نظر مرجعي إدخال و إعادة توليد مرة صفة إسقاط. تخطيط بوابة سوف يأخذ قديم قديم شبكة محطة مخصص استخدام Markdown دليل شجرة تغيير صار دمج فشل، بينما لا هو يتم تجاهل اختصار بناء إدخال. نحو Pages إصدار بـ من إصدار tag يد حركة dispatch طريقة تشغيل، لذلك محطة نقطة عرض هو قد إصدار لقطة بينما غير حالي master([سبب](2026-08-21-documentation-site-tag-release.ar.md)).

إصدار manifest هو واحد نسخة حاجة صيانة allowlist، رابط إسقاط أيضا جذب دخول واحد طبقة مستودع مخصص استخدام بناء مهايئ. إضافة جديدة واحد نوع Markdown رابط سلوك وقت، حاجة زيادة إسقاط جهاز اختبار.Mermaid دعم حمل أيضا سوف زيادة كبير عميل bundle، لكن قدرة إبقاء مرجعي وثيقة في قد استخدام رسم جدول.
