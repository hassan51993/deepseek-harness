# Agent Note: README مورد إنتاج عبر مخصص استخدام مستودع إصدار

## مشكلة

عام العربية README تضمين دخول 3 ورقة مجتمع منطقة اثنان صيانة رمز. استخدام مستودع متبادل مقابل مسار وقت، كل مرة استبدال كل اعتماد شفرة المصدر تغيير و مستقل عام مستودع إصدار مسار، أي جعل صورة بايت و لم تغيير منتج شفرة أو وثيقة نص حرف.

هذه صورة حاجة مستقر عام URL، معا يجب واضح و يمكن مراجعة أرض حفظ مصدر ملف بايت، إصدار سند إثبات، ذاكرة مؤقتة سلوك و تحديث تاريخ.

## قرار

README مرجع `https://cdn.deepseek.com/harness/readme/` تحت ثابت URL. خاص مستودع [`deepseek-harness/readme-cdn-assets`](https://github.com/deepseek-harness/readme-cdn-assets) مسؤول إدارة 3 ورقة سماح إصدار PNG ملف، متبادل ينبغي اختبار و إصدار شفرة. نحو هذا مستودع `master` فرع push سوف تشغيل `publish.yml`، تثبيت ثابت إصدار زاهر لـ سحابة OBS SDK، اختبار `scripts/upload.mjs` تزامن نشر صورة.

فوق نقل نص برمجي فقط قبول 3 عدد README صورة ملف اسم، تحقق كل مصدر ملف متساو لـ PNG، و بـ `Content-Type: image/png` و `Cache-Control: no-store` فوق نقل إلى `dp-cdn-deepseek/harness/readme/`. نص برمجي فحص OBS استجابة حالة، تقرير إبلاغ مقابل عام URL، و في نجاح أو فشل بعد إغلاق عميل. مستودع درجة GitHub Actions Secret توفير `OBS_DSH_README_ACCESS_KEY_ID` و `OBS_DSH_README_SECRET_ACCESS_KEY`؛OBS هوية فقط يحتاج يملك هذا كائن بادئة كتابة إذن.

مورد إنتاج مستودع توفير تحديث سجل و تراجع حق مصدر. صورة استبدال بعد، عام README متابعة استخدام نفسه URL، لذلك معتاد قاعدة صورة تحديث بلا حاجة تعديل منتج مستودع أو تزامن عام مستودع.

## سبق اعتبار بديل خطة

**متابعة في `master` فوق استخدام مستودع متبادل مقابل صورة.**هذا نوع فعل قاعدة فقط استخدام GitHub حمل إدارة صورة، لكن كل مرة تشغيل تشغيل اثنان صيانة رمز استبدال ما زال و شفرة مراجعة و عام مستودع إصدار مسار اقتران دمج.

**في منتج مستودع في إبقاء طويل مدة مورد إنتاج فرع.**مورد إنتاج فرع يمكن تجنب تجنب تعديل منتج `master`، لكن صورة كل حق،OBS سند إثبات و إصدار سير العمل ما زال اعتماد مرفق في منتج مستودع و ذلك كل مستودع تلقائي تحويل. مخصص استخدام مستودع لـ هذا بند تشغيل تشغيل مورد توفير مفرد واحد افتراضي فرع و مفرد واحد مسؤولية.

**استخدام محتوى بحث عنوان CDN كائن اسم.**غير ممكن تغيير كائن لن إنتاج قديم قديم ذاكرة مؤقتة، لكن كل مرة استبدال صورة أيضا يجب تعديل README URL، لا يمكن توفير هذا سير العمل الذي يحتاج مستقل تحديث مسار.

**سماح فوق نقل نص برمجي إصدار مهمة معنى مسار.**عام فوق نقل نص برمجي يمكن في لا تعديل شفرة حال حال تحت دعم حمل لم قدوم مورد إنتاج، لكن نفس مجموعة سند إثبات أيضا قدرة تغطية غير متصل CDN كائن. ثابت سماح قائمة سوف إصدار مهمة حد في هو مسؤول README صورة داخل.

## عاقبة

مجتمع منطقة اثنان صيانة رمز يمكن عبر مرة مورد إنتاج مستودع push تحديث، عام README بلا حاجة تغيير. منتج مستودع لا يحمل OBS اعتماد أو سند إثبات؛ فوق نقل محتوى إبقاء يمكن مراجعة حساب git حق مصدر؛CDN استجابة يحمل `Cache-Control: no-store`.

README اعتماد عام CDN و GitHub صورة بديل إدارة، إصدار مسار فإن اعتماد آخر عدد خاص مستودع و ذلك 2 عدد GitHub Actions Secret.`no-store` لـ هذه صغير ملف وضع ترك حافة حافة عقدة و متصفح ذاكرة مؤقتة.
