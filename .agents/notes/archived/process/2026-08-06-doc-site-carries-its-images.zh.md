# Agent Note: وثيقة محطة نقطة ذاتي حمل صورة

Status: implemented
Archived: 2026-09-04

[English](2026-08-06-doc-site-carries-its-images.md) | العربية

## مشكلة

`scripts/project-doc-site.ts` سوف يأخذ إصدار manifest(بيانات وصفية بيان) لم استلام تسجيل مستودع متبادل مقابل هدف واحد قاعدة تعديل كتابة صار GitHub عنوان، مقابل صورة بينما قول حينئذ هو `https://raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>`. محطة نقطة بناء لا نسخ صدفة أي ملف:`srcDir` هو استخدام تمام أي ترك `.generated` شجرة،VitePress لا يوجد ضبط `publicDir`(ذلك قيمة افتراضية `<srcDir>/public` تماما جيد يقع في إسقاط كل مرة وقت التشغيل حذف ذلك شجرة شجرة داخل) ، بينما كتابة دخول ذهاب فقط لديه Markdown.

هذا فقط مقابل عام مستودع صار قيام. هذا مستودع هو خاص، بينما `raw.githubusercontent.com` مقابل لم إقرار إثبات طلب واحد قاعدة عودة 404——github.com فوق تسجيل تسجيل جلسة أيضا لا يستطيع إقرار إثبات هو، لأن GitHub ذاتي بيت واجهة هو استخدام آخر طقم مفرد وحيد توقيع عنوان توفير خاص blob . في هو محطة نقطة فوق كل واحد ورقة صورة مقابل كل واحد موضع قراءة من كل هو تالف، لكن لا يوجد أي بوابة قدرة قول خروج قدوم:`verify-md-links` و إسقاط تحقق هو هدف ملف**في مستودع داخل هل وجود**، ذلك و محطة نقطة قراءة من قدرة لا أخذ إلى هو هو اثنان عدد مشكلة.

## قرار

`rewriteMarkdown` إضافة جديدة اختياري `placeImage(absPath): string`. عند صفحة مرجع واحد ورقة manifest لم بصفة صفحة إصدار صورة وقت، إسقاط يأخذ هذا ملف نسخ دخول توليد شجرة في هذا صفحة جانب حافة، و يأخذ مرجع تعديل كتابة لـ `./<basename>`؛ مع بعد Vite سوف مثل معالجة أخرى محطة نقطة مورد واحد مثال تحزيم هو. مستودع مرئي صفة مجددا أيضا أثر لا إلى قد إصدار صفحة.

فرعي هذا سقوط في صفحة جانب حافة، بينما لا هو بعض عدد مشترك مورد دليل. كل locale توجيه شجرة كل حمل واحد نسخة فرعي هذا، لذلك نفس عدد متبادل مقابل URL في `guide/` و `en/guide/` تحت كل صحيح تأكيد، بلا حاجة حسب locale حساب حساب بادئة؛manifest سحب تحت بعض صفحة وقت، هو مورد أيضا مع لـ إزالة فقد. واحد ورقة جدول تسجيل تسجيل كل يتم إسقاط مسار——صفحة و صورة واحد نظر نفس لب——نفس مسار ظهور ثاني عدد مصدر حينئذ رمي خطأ، و قائم تكرار توجيه فحص نفس عدد قيام ساحة، بينما لا هو يجعل الأكثر بعد كتابة ذلك عدد ساكن صامت فوز خروج.

فقط لديه حقيقي مسار يقع في مستودع داخل عادي ملف عندئذ سوف يتم نسخ صدفة، ذلك بقية واحد قاعدة يجعل إسقاط فشل و نقطة اسم صفحة و هدف. رابط تعديل كتابة فقط حاجة معرفة طريق هدف**وجود**، لكن إصدار هو يأخذ هو بايت نسخ فوق محطة نقطة، لذلك واحد هروب خروج مستودع مرجع——مرور من `../..` أو إشارة نحو شجرة خارج رمز رقم رابط——سوف يأخذ بناء آلة فوق ملف وضع إلى قد إصدار صفحة فوق. مرجع ذاتي حمل `?query` أو `#fragment` سوف مع أمان وضع بعد URL واحد نفس إبقاء، و GitHub فرع واحد اختراق فعل قاعدة متسق؛ ملف اسم فعل مئة قسم رقم تحرير رمز، لأن هدف يقع في Markdown داخل ربط هدف موضع.

`docsSourceFiles()` سوف وصل نفس يتم أمان وضع صورة واحد بدء فوق تقرير، في هو استبدال قطع رسم وقت تطوير خادم watcher سوف إعادة إسقاط، بينما لا هو واحد مباشر خدمة قديم فرعي هذا مباشر إلى لديه شخص اصطدام واحد تحت صفحة.

`placeImage` لـ الذي بـ اختياري، هو لأن `rewriteMarkdown` أيضا يتم هو ذاتي ذات spec مباشر استدعاء، بينما ذلك داخل و لا وجود توليد شجرة. لا نقل هو وقت،GitHub raw رجوع سوف إشارة نحو عام مصدر رئيسي صفحة؛ هذا يجعل هذا seam مقابل فقط تعديل كتابة نص مستهلك إبقاء صدق فعلي.

صحيح هذا Markdown وفق قديم كتابة عادي مستودع متبادل مقابل صورة مسار، لذلك نفس نسخة ملف في GitHub فوق و محطة نقطة فوق كل قدرة صحيح معتاد عرض. لا يوجد أي وثيقة لـ نقل حينئذ VitePress بينما كتابة محطة داخل قطعا مقابل URL.

## اعتبار مرور بديل خطة

**يأخذ `publicDir` ضبط إلى `.generated` خارج، و استخدام محطة داخل قطعا مقابل URL.** إسقاط هذا حافة نشط حركة جزء عنصر أكثر قليل، لكن نفس نسخة Markdown في مستودع في قراءة قراءة وقت، كل واحد موضع صورة مرجع كل سوف هو تالف، بينما صحيح هذا وثيقة هو اثنان نوع طريقة كل يلزم قراءة.

**يأخذ صورة وضع إلى assets فرع، حينئذ مثل عرض عرض GIF ذلك مثال.** ذلك عدد فرع وجود هو لـ يجعل كبير جسم تراكم اثنان دخول صنع لا دخول رئيسي خط تاريخ، بينما هو raw عنوان لديه حال تماما نفسه مرئي صفة مشكلة. هو ما زال هو تسجيل شاشة صحيح تأكيد عودة مضيف؛ لكن هو حل قرار لا هذا عنصر أمر.

**انتظار مستودع تحويل لـ عام.** ذلك فقط هو إزالة حذف عرض حالة، لن يجعل محطة نقطة ذاتي إعطاء ذاتي كاف، بينما كما كل واحد ورقة صورة كل سوف يجعل محطة نقطة خفي صيغة اعتماد GitHub متاح صفة و حد تدفق.

## عاقبة

قد إصدار وثيقة في صورة، الآن بلا نقاش من في قراءة قراءة، بلا نقاش مستودع هل عام كل قدرة عرض، محطة نقطة بناء أيضا لم يعد لـ صورة اعتماد GitHub وقت التشغيل يمكن بلوغ صفة. توليد شجرة سوف لـ كل locale كل زيادة واحد نسخة يتم مرجع صورة فرعي هذا——نموذج مزود إشارة جنوب داخل أربعة ورقة قطع رسم، كل locale نحو 270 KB.

**لم إصدار**وثيقة مرجع صورة لا تلقي أثر. صاف نص إسقاط سوف متبادل مقابل في عام مصدر رئيسي صفحة تحليل هو جمع؛ لا في محطة نقطة فوق وثيقة لا يوجد محطة نقطة بناء يمكن تحمل تحميل ذلك مورد.

## اختبار

`scripts/project-doc-site.spec.ts` تغطية:placer استلام إلى تحليل بعد قطعا مقابل مسار كما ذلك إرجاع URL سقوط دخول Markdown، يتم أمان وضع مرجع إبقاء ذلك fragment، وجود placer وقت قد إصدار صفحة رابط ما زال تحليل إلى ذاتي ذات توجيه، و لا نقل placer وقت ثابت GitHub raw رجوع.`publishableImage` آخر لديه مباشر تغطية: مستودع داخل عادي ملف يتم قبول، بينما هدف هروب خروج مستودع رمز رقم رابط، مستودع خارج مسار و دليل واحد قاعدة رفض.`pnpm docs:check` سوف حمل حال نموذج مزود إشارة جنوب قطع رسم بناء محطة نقطة، و في مصدر ناقص وقت فشل؛ يتم نسخ صدفة ملف و ذلك `./<basename>` مرجع قد في `website/.generated` و تشغيل في `docs:dev` داخل نواة فعلي (اثنان عدد locale متساو `naturalWidth > 0`).
