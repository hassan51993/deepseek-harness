# Agent Note: زيادة كمية تحديث PR base فرع

Status: implemented
Archived: 2026-09-04

[English](2026-07-26-incremental-pr-base-retargeting.md) | العربية

## مشكلة

سوف PR(Pull Request) base فرع حالي قمة طرف إيداع دمج دخول PR فرع مرور مسار في،base فرع ممكن متابعة قبل نقل. إذا تعديل من جديد قمة طرف إيداع إعادة بدء، حينئذ سوف إسقاط قد إتمام اندفاع مفاجئ حل قرار و تحقق عمل. إعادة كتابة قد دفع إرسال دمج أيضا سوف مسح ذهاب يمكن توفير مراجعة تاريخ سجل.

## قرار

اختيار merge-forward وقت، كل مرة مراقبة إلى base فرع قمة طرف إيداع كل إبقاء لـ مستقل دمج فحص نقطة. إذا معالجة خلال base فرع متابعة قبل نقل، أولا إتمام و تحقق صحيح في إجراء دمج، مجددا سوف ذلك إيداع؛ مهمة تخويل دفع إرسال وقت، أيضا يلزم إتمام دفع إرسال. إتمام هذه خطوة بعد، عندئذ قدرة نيل أخذ مقارنة جديد base، و عبر مفرد وحيد دمج إيداع سوف ذلك دمج دخول. في هذا بند merge-forward تسلسل في، لا نيل وضع ترك أو إعادة كتابة أي فحص نقطة.

[أصلي كومة تراكم و اختياري rebase قرار](2026-08-02-native-github-stacks-and-optional-rebases.ar.md) أيضا سماح مستقل أو كومة تراكم PR استخدام تلقي lease حفظ حماية rebase، مراجعة بعد نفس مثال مثل هذا. هذا نص فقط مسؤول merge-forward مسار.[كومة تراكم PR سقوط أرض skill(تقنية قدرة)](../../../skills/dsh-merging-stacked-prs/SKILL.md) أصل حسب أصل [AGENTS.md](../../../../AGENTS.md) اختيار منها واحد نوع تاريخ تحديث طريقة،[كومة تراكم مراجعة إشارة جنوب](../../../../docs/cookbook/responding-to-pr-review-on-a-stack.ar.md) فإن مسؤول شرح مثل أي في اعتماد طبقة بين نقل بث إصلاح.

## سبق اعتبار بديل خطة

**في توقف حالي عمل، تعديل من الأكثر جديد base إعادة بدء.** هذا سوف إسقاط قد حل قرار اندفاع مفاجئ و إتمام تحقق، تكرار جهد حركة، و فقد ذهاب واحد لديه استخدام استعادة نقطة.

**إعادة كتابة لـ مرة معا يتضمن اثنان عدد base فرع قمة طرف دمج.** هذا سوف إخفاء غطاء اندفاع مفاجئ حل قرار ترتيب؛ إذا رقم مرة دمج قد دفع إرسال، أيضا يجب إعادة كتابة بعيد مسار تاريخ.

## عاقبة

- PR base كثير مرة قبل نقل وقت، هذا عدد PR يمكن يتضمن كثير عدد لأجل دمج base إيداع.
- قد إتمام عمل لن يتم إسقاط، بينما هو إبقاء يمكن توفير مراجعة و استعادة.
- دمج دخول مقارنة جديد base سوف تغيير دمج بعد ملف شجرة، لذلك متبادل صلة فحص سوف في تحت مرة دفع إرسال قبل إعادة تشغيل.
