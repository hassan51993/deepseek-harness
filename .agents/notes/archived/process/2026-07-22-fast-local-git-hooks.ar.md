# Agent Note: سريع سرعة محلي Git خطاف

Status: implemented
Archived: 2026-09-04

[English](2026-07-22-fast-local-git-hooks.md) | العربية

## مشكلة

agent(ذكي جسم) قد سوف تشغيل قدرة كاف تغطية ذاته تعديل اختبار و فحص، بينما إيداع، دفع إرسال و CI ممكن قسم آخر تكرار منها نطاق تجاوز قدوم تجاوز واسع فرعي تجميع. لذلك، كل كمية pre-push طقم عنصر سوف سحب بطيء كل مرة دفع إرسال، وضع كبير و حالي تعديل غير متصل محلي أحيانا إرسال فشل، بينما كما CI ضيق وصل حال مجددا مرة تشغيل كامل مستطيل دفعة وقت لن توفير جديد إشارة.

سريع سرعة خطاف ما زال يحتاج في عمل مغادرة فتح هذا آلة قبل اعتراض تحت فحص صار هذا منخفض كما يأخذ إمساك عال نقص وقوع. مؤقت تخزين ملف صيغة مشكلة، فارغ أبيض خطأ،vendor شفرة المصدر بيانات وصفية ناقص و مستودع نوع خطأ رمز دمج هذا بند حد؛ اختبار وحدة طقم عنصر، لقطة، وثيقة فحص، بناء و حزمة `hygiene` فحص فإن مع تعديل نطاق بينما مختلف، لا رمز دمج هذا بند حد.

## قرار

[lefthook.yml](../../../../lefthook.yml) سوف اثنان عدد خطاف كل إبقاء لـ محدود محلي فحص نقطة.Pre-commit حسب ترتيب تشغيل: لا تحميل مشروع [Oxlint](2026-07-29-oxlint-linter.ar.md) إعداد تحقق تعديل مرور JavaScript و TypeScript ملف، تطبيق حمل[مرة محدود إعادة محاولة](2026-08-09-oxlint-only-fix-workflow.ar.md) أمان إصلاح، و إعادة مؤقت تخزين هذه ملف؛`git diff --cached --check` رفض مؤقت تخزين diff في فارغ أبيض خطأ،vendor manifest(بيانات وصفية بيان) حراسة حماية فحص vendor شفرة المصدر بيانات وصفية.Pre-push تشغيل `pnpm run typecheck`؛ هذا أمر سوف أولا دقيق تجهيز جيد توليد Host Typert اتفاق، مجددا تشغيل Client زيادة كمية نوع فحص.

Pre-commit لا تشغيل نوع قسم تحليل، اختبار، لقطة، وثيقة فحص، بناء،`hygiene` أو بوابة مجدول.Pre-push فقط زيادة مستودع نوع فحص الذي يحتاج Host اتفاق بناء. اختياري تشغيل `check:all` حزمة نص برمجي مستقل في هذه خطاف، من [scripts/run-gates.ts](../../../../scripts/run-gates.ts) في اختيار `check-all` مجدول بيان؛ هو هو مساهمة من أمر، بينما غير مقابل agent إشارة أمر.

agent فحص انتظار دفع إرسال diff، و فقط تشغيل مرة قدرة كاف تغطية ذلك سلوك الأكثر صغير نطاق اختبار و فحص.CI مسؤول كل كمية نسبة التغطية بوابة، بناء ناتج فحص و منصة مستطيل دفعة. فقط لديه في واضح اشتراط، تشخيص CI، أو تعلق و كل مستودع تعديل لا يمكن من نطاق أكثر ضيق دليل نيل إلى يمكن معلومة تحقق وقت، عندئذ كامل تشغيل واحد مرة محلي فحص مستطيل دفعة.

## يحل محل علاقة

هذا قرار يحل محل[و سطر pre-push بوابة](2026-07-06-parallel-pre-push-gates.ar.md) في تعلق و محلي خطاف جزء، و[بـ آلة آلة جودة كمية بوابة بديل بديل نص حرف مواصفة](2026-06-11-quality-gates.ar.md) في صلة في خطاف و CI مقابل تسمية صفة جزء. فوق وصف سجل في صلة في CI مجدول، حزمة بوابة و آلة آلة تحويل قوي صنع تنفيذ قرار متابعة صالح.

## اعتبار مرور بديل خطة

- **إبقاء كل كمية pre-push طقم عنصر و أفضل تحويل ذلك مجدول**——قدرة كاف الأكثر مبكر توفير كل وجه إشارة، لكن ما زال سوف تكرار agent قد اختيار أخذ دليل و CI، كما غير متصل فشل ما زال سوف منع سد دفع إرسال.
- **تماما إزالة pre-push**——دفع إرسال صار هذا الأكثر منخفض، لكن سوف فقد ذهاب TypeScript في كثير عدد إيداع بعد توفير سريع سرعة عبر ملف حفظ إثبات.
- **في pre-commit في إبقاء نوع فحص**——أكثر مبكر التقاط نوع خطأ، لكن كل مرة في بين إيداع كل يلزم تحمل تحمل فتح إلغاء، بينما لا هو فقط في دفع إرسال وقت تشغيل مرة؛ مؤقت تخزين ملف lint قد تغطية إيداع ذاته لغة قاعدة و ريح إطار حد.
- **سوف مؤقت تخزين ملف lint ضبط لـ فقط فحص نمط**——تجنب تجنب خطاف تعديل ملف، لكن مساهمة من متعمد إبقاء تلقائي إصلاح سير العمل؛Oxlint مرة محدود إعادة محاولة و Lefthook `stage_fixed` سوف إبقاء هذا سير العمل، بلا حاجة مفرد وحيد صيغة تحويل جهاز، أيضا بلا حاجة تكرار تنفيذ `git add`.

## نتيجة

عادي إيداع صلة مفتاح مسار هو لا تحميل مشروع مؤقت تخزين ملف Oxlint إصلاح و تحقق، ذاكرة مؤقتة قد مسبق حار وقت دفع إرسال صلة مفتاح مسار هو مرور مرور دقيق تجهيز زيادة كمية نوع فحص. مساهمة من ما زال اختياري اختيار استخدام واحد بند أمر كامل عرض تدريب، كما لن توسيع خطاف صلة مفتاح مسار أو agent يجب تشغيل تحقق تجميع دمج. خطاف استهلاك وقت فقط بصفة تطوير مراقبة بيانات و PR(Pull Request) دليل سجل، لا ضبط سوف تلقي رئيسي آلة سالب تحميل و ذاكرة مؤقتة حالة أثر حساب وقت اختبار.

من محلي دفع إرسال نجاح لم يعد قدرة إثبات مستودع كامل مستطيل دفعة قد عبر.agent يجب اختيار متبادل صلة سلوك دليل، مراجعة شخص يجب حكم قطع هذا اختيار هل و diff متبادل رمز،CI فإن مقابل كل دفع إرسال إصدار توفير مرة كل وجه إشارة.
