# Agent Note: مستودع داخل Landlock إصدار

Status: implemented
Archived: 2026-09-04

[English](2026-08-06-in-repository-landlock-release.md) | العربية

## مشكلة

`@deepseek-ai/node-addon-landlock-run` شفرة المصدر قد و ذلك DeepSeek Harness مستهلك واحد نفس يقع في `native/landlock-run` تحت، لكن هذا قبل ما زال إبقاء مستقل pnpm workspace و قفل ملف، و اعتماد واحد مستقل مستودع إصدار إلى npm.Harness حزمة استخدام npm سجل التسجيل في ثابت إصدار، لذلك نفس عدد PR(Pull Request) يمكن معا تعديل بدء جهاز اتفاق و ذلك مستهلك، لكن لا يمكن واحد بدء اختبار هذه تعديل. شفرة المصدر مستودع أصلي سير العمل يمكن عرض تدريب تحزيم مسار، لكن لن إصدار هو فعلي اختبار مرور ناتج.

إصدار مرآة مثل أيضا صنع صار تكرار إصدار تنسيق ضبط عمل: توجيه خروج شفرة المصدر، تحديث آخر نسخة قفل ملف، تشغيل آخر طقم إصدار سير العمل، إصدار أصلي حزمة بيت عائلة، لكن بعد عودة إلى هذا مستودع تحديث سجل التسجيل اعتماد.npm مستخدم فعلي يحتاج طلب و لم تغيير، هذا نوع تفكيك قسم لكن يجعل كل اثنان دخول صنع أكثر صعب مقابل إلى ذلك مصدر إيداع، أيضا يجعل إصدار تراجع و أمان إصلاح تنسيق ضبط أكثر صعب صعب.

قائم غير scoped npm حزمة اسم عودة مستقل إصدار حساب رقم كل، بينما لا يخص `@deepseek-ai` مجموعة نسج. لذلك، فقط ترحيل سير العمل ما زال سوف يجعل إصدار اعتماد مستودع إصدار ملكية خارج عدد شخص سند إثبات.

هذا مرة كامل دمج يجب إبقاء منصة اختيار آلية. عام توزيع متعمد اعتماد واحد JavaScript مدخل حزمة، و لـ Linux x64 و arm64 قسم آخر توفير اثنان دخول صنع حزمة؛ دمج مستودع ملكية و لا معنى طعم حال يلزم يأخذ كل اثنان دخول صنع ملف وضع دخول نفس عدد tarball، أيضا لا معنى طعم حال يلزم حسب وفق بدء جهاز إصدار إصدار كل DeepSeek Harness حزمة.

## قرار

`native/landlock-run` و `native/landlock-run/packages/*` يخص مستودع أصل pnpm workspace، و استخدام أصل `pnpm-lock.yaml`.Harness مستهلك سوف `@deepseek-ai/node-addon-landlock-run` إعلان لـ `workspace:*`، لذلك تطوير، نوع فحص، بناء و PR اختبار كل سوف من نفس عدد checkout تحليل مدخل حزمة. أصل TypeScript مشروع رسم سوف أولا بناء هذا مدخل حزمة، مجددا بناء مستهلك؛ مستودع تنظيف جهاز مسؤول تنظيف ذلك مباشر توليد `lib/` إخراج دليل.

عام npm توزيع حد من 3 عدد عودة مجموعة نسج كل حزمة مجموعة صار، هو جمع مشترك استخدام واحد بدء جهاز حزمة بيت عائلة إصدار:`@deepseek-ai/node-addon-landlock-run`،`@deepseek-ai/node-addon-landlock-run-linux-x64` و `@deepseek-ai/node-addon-landlock-run-linux-arm64`. مدخل حزمة متابعة عبر `optionalDependencies` إعلان اثنان عدد منصة حزمة؛ هو جمع في manifest(بيانات وصفية بيان) في `os` و `cpu` حقل يجعل npm فقط تثبيت توافق حزمة. مستودع قيد اشتراط هذا 3 عدد حزمة اسم ضبط `publishConfig.access: public`، و اشتراط ذلك إصدار و خاص بدء جهاز workspace أصل حزمة متسق. أصل أولا غير scoped حزمة اسم لا يخص هذا مستودع إصدار هدف. هذا 3 عدد قد لم يعد هو وحيد عام حزمة:[حسب تسلسل منطقة قسم access قرار](2026-08-13-public-vendor-and-native-sequences.zh.md) يجعل vendored إطار هيكل تسعة حزمة أيضا عام إصدار، بينما dsh عائلة إبقاء تلقي حد.

رئيسي مستودع معا مسؤول أصلي CI و إصدار.`Landlock Run` سوف لـ متبادل صلة PR و `master` دفع إرسال تشغيل، و في كل منها مطابقة أصلي runner فوق بناء كل منصة حزمة. يد حركة إطلاق `Landlock Run Release` سير العمل سوف بناء اثنان عدد منصة اثنان دخول صنع ملف، سوف ذلك بصفة سير العمل ناتج نقل تمرير، تجميع و تحقق كامل حزمة بيت عائلة، تحزيم خروج محتوى غير ممكن تغيير npm tarball، تثبيت و فعلي تشغيل هذه tarball، بعد عندئذ سماح تلقي حفظ حماية إصدار عمل عمل تنفيذ. إصدار ترتيب هو منصة tarball في قبل، الأكثر بعد إصدار سوف هو جمع صف لـ اختياري اعتماد مدخل tarball. إصدار استخدام `landlock-run-vX.Y.Z` tag، تجنب تجنب بدء جهاز إصدار و monorepo في أخرى إصدار بيت عائلة حدوث اندفاع مفاجئ؛ مسبق إصدار إصدار استخدام npm `next` dist-tag.

صندوق رملي تحزيم تثبيت عرض تدريب لا سماح npm سجل التسجيل توفير بدء جهاز. هو سوف أصل حسب حالي workspace `dependencies`،`optionalDependencies` و مطلوب `peerDependencies` تمرير عودة دفع توجيه harness إغلاق حزمة؛ أصلي حزمة بيت عائلة إبقاء مستقل، لأن إبقاء ملف نمط تحزيم نص برمجي سوف توفير مدخل حزمة و مطابقة منصة حزمة. عرض تدريب يأخذ هذه محلي tarball تثبيت إلى مستودع خارجي صاف Node مستهلك في، و في اختبار قيد فاعلية نتيجة أو فشل إغلاق دمج سلوك قبل، إثبات الذي تثبيت بدء جهاز يمكن تنفيذ، و أصلي بناء ناتج بايت تماما متسق، كما أداة لديه صحيح تأكيد ELF هيكل بنية.

## سبق اعتبار بديل خطة

- **إبقاء مستقل مستودع بصفة إصدار مرآة مثل**: غير مقبول، لأن في مرجعي شفرة المصدر قد نقل دخول هذا مستودع بعد، هذا ما زال سوف إبقاء تفكيك قسم قفل ملف، شفرة المصدر توجيه خروج، اختبار استخدام قديم قديم سجل التسجيل إصدار وقت نافذة، و عبر مستودع إصدار تسلسل.
- **إصدار واحد يتضمن كل منصة اثنان دخول صنع ملف npm حزمة**: غير مقبول، لأن مستخدم سوف تحت تحميل لا يمكن في ذلك رئيسي آلة فوق تشغيل اثنان دخول صنع ملف، بينما كما npm لا يمكن مجددا فائدة استخدام حزمة درجة `os`/`cpu` غربلة اختيار. مستودع ملكية و npm حزمة تخطيط هو اثنان عدد ذاك هذا مستقل اختيار.
- **يجعل بدء جهاز استخدام DeepSeek Harness أصل إصدار، و تمرير عودة إصدار كامل monorepo**: غير مقبول، لأن هذا مرة تعديل مسؤول هو واحد من 3 عدد حزمة مجموعة صار عام حزمة بيت عائلة، بينما لا هو مستقل `@deepseek-ai/dsh-*` أساس خط.[ناتج أولوية npm أساس خط رفع سجل](../../proposed/process/2026-08-04-artifact-first-npm-baseline-publication.zh.md) واضح سوف أصلي workspace ترتيب حذف في ذلك هدف تجميع دمج خارج.
- **في واحد إصدار عمل عمل في تسليم تقاطع تحرير ترجمة اثنان عدد اثنان دخول صنع ملف**: غير مقبول، لأن مستودع داخل قد إيداع حزمة مستطيل دفعة قد لـ كل نوع هيكل بنية قسم إعداد أصلي GitHub runner، بلا حاجة مجددا يأخذ تسليم تقاطع أداة سلسلة قبول دخول معلومة مهمة حد.

## عاقبة

نفس عدد PR يمكن معا تعديل بدء جهاز بروتوكول،TypeScript مدخل شفرة، أصلي شفرة المصدر،harness مستهلك صيغة و إصدار مسار اختبار، و من نفس نسخة قفل ملف تحليل هذه محتوى. إصدار tag الآن معرف شفرة المصدر، مستهلك تجميع صار، بناء إشارة أمر، و رئيسي مستودع اختبار مرور tarball. مستقل مرآة مثل قد لم يعد يخص إصدار مسار، يمكن في رقم مرة نجاح من هذا مستودع إصدار بعد عودة ملف.

npm مستهلك تعديل لـ تثبيت `@deepseek-ai/node-addon-landlock-run`؛ أصل أولا غير scoped حزمة اسم لن يتم ساكن صامت إعادة تحديد نحو. تلقي دعم حمل Linux رئيسي آلة سوف تحت تحميل scoped مدخل حزمة و و ذلك هيكل بنية مطابقة حزمة، و قفز مرور آخر هيكل بنية حزمة. لا تلقي دعم حمل رئيسي آلة لن استلام إلى منصة اثنان دخول صنع ملف، و متابعة امتداد استخدام قائم تحديد صفة فشل إغلاق دمج استكشاف قياس مسار.

تنفيذ تعلق و ملف مقارنة فقط تعديل واحد سطر اعتماد أكثر كثير، لأن مستودع أيضا يجب مسؤول workspace قيد،TypeScript بناء ترتيب، تنظيف،CI إطلاق شرط، إصدار tag، قفل ملف توليد، سوف قد تثبيت اثنان دخول صنع و workspace بناء إجراء مقارنة مقارنة، إصدار وثيقة و توليد رقم ثلاثة جهة إعلان. سلوك حد ما زال جدا ضيق: هذا مرة تعديل فقط أثر Landlock حزمة بيت عائلة و ذلك 3 عدد مباشر workspace مستهلك، لا تغيير أخرى DeepSeek Harness حزمة إصدار أو إصدار حالة.

رقم مرة إصدار scoped حزمة وقت، يجب عبر `npm-publish` بيئة `NPM_TOKEN` استخدام `@deepseek-ai` مجموعة نسج token، لأن npm فقط لديه في حزمة قد وجود بعد عندئذ قدرة إعداد trusted publishing. إتمام bootstrap بعد، يجب يجعل 3 عدد حزمة كل تخويل هذا مستودع إصدار سير العمل، عندئذ قدرة إزالة بعد تجهيز token.npm ما زال سوف حسب ترتيب إصدار كل عدد حزمة، كما لا توفير عبر حزمة أمر خدمة، لذلك إصدار فشل ممكن إبقاء تحت فقط إتمام واحد جزء إصدار. من في npm سوف رفض قد إصدار نفس اسم نفس إصدار حزمة، عملية شخص عضو يجب فحص سجل التسجيل و فقط إصدار ناقص tarball، بينما لا يستطيع أصل مثال إعادة تشغيل سير العمل.Linux x64 و arm64 runner ما زال توفير مرجعي اثنان دخول صنع بناء و حقيقي داخل نواة فحص؛macOS checkout يمكن تحقق مدخل حزمة و لا تلقي دعم حمل منصة فوق سلوك، لكن لا يستطيع يحل محل هذه عمل عمل.

هذا شرح فقط يحل محل[صندوق رملي Agent Note](../feature/2026-07-06-sandbox.zh.md) في لديه صلة إصدار مرآة مثل و تطوير شفرة المصدر وقت اعتماد سجل التسجيل ثابت إصدار جدول وصف؛ هذا Agent Note ما زال مسؤول صندوق رملي سلوك،runner اختيار و قوي صنع تنفيذ دلالة.
