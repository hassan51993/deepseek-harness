# Agent Note: وثيقة محطة صاف Markdown توأم توليد صفحة و llms.txt

Status: implemented
Archived: 2026-09-04

[English](2026-08-20-doc-site-raw-markdown-twins.md) | العربية

## Problem

وثيقة محطة فقط توفير تصيير بعد HTML،agent قراءة وثيقة يلزم ما إمساك أخذ VitePress علامة، يلزم ما تراجع عودة مستودع مصدر ملف، بينما بعد من رابط و صورة مرجع تتبع مع شفرة المصدر تخطيط بينما غير عام توجيه.Claude منصة وثيقة تأكيد قيام هذا خاص صفة قبول اتفاق: مهمة معنى صفحة URL إضافة `.md` بعد لاحقة أي نيل إلى هذا صفحة أصلي Markdown، محطة أصل `llms.txt` بصفة موجه إلى agent بحث جذب.[محطة نقطة إسقاط](2026-07-13-documentation-site-projection.zh.md) هذا حينئذ لـ عام محطة نقطة إعادة كتابة كل صفحة رابط، نقص فقط هو يأخذ هذا نسخة إسقاط بـ صاف Markdown شكل صيغة مقابل خارج توفير.

## Decision

`vitepress build` انتهاء وقت نحو بناء إخراج إرسال إطلاق كل قد إصدار توجيه صاف Markdown توأم توليد صفحة.`emitRawMarkdownPages` إعادة استخدام ملء ملء `website/.generated/` نفس مرة manifest إضافة إسقاط جهاز مسار، لكن بـ أصلي صفحة محتوى كتابة `<outDir>/<route>`: لا حمل `editSource`/`outline` إسقاط frontmatter، لا فعل locale أول صفحة قطع قطع——frontmatter هو VitePress تصيير إعداد، توأم توليد صفحة إسقاط هو و إبقاء متن——مستودع إصدار صيغة (لغة تبديل سطر، شعار فصل) تقشير مغادرة و تصيير محطة متسق. صفحة مرجع صورة نسخ إلى توأم توليد صفحة جانب حافة.

واحد نسخة إسقاط معا خدمة اثنان شجرة شجرة، لأن محطة داخل رابط هو متبادل مقابل مسار.`./sibling.md` في HTML محطة تصيير لـ clean URL، في أصلي شجرة في حسب ملف مقابل ملف تحليل، توأم توليد صفحة لا حاجة ثاني طقم رابط تعديل كتابة نمط. كل توجيه كل يتم إرسال إطلاق، يشمل فقط لديه frontmatter locale أول صفحة: قد إصدار صفحة رابط إلى هو جمع، أصلي شجرة يجب إبقاء رابط غلاف إغلاق؛ واحد spec مرة تاريخ إرسال إطلاق شجرة في كل بند متبادل مقابل رابط قدوم تثبيت إقامة هذا بند إغلاق دمج صفة.

index توجيه في تصيير محطة فوق عرض لـ دليل URL،"إضافة `.md`"في ذهاب إسقاط نهاية ذيل مائل عمود بعد سقوط في `<dir>.md` فوق؛ لذلك كل index توجيه أيضا إرسال إطلاق واحد أب درجة آخر اسم توأم توليد صفحة. آخر اسم لا هو نسخ صدفة——نسخ صدفة `index.md` سوف يجعل متبادل مقابل رابط كامل جسم فوق نقل واحد طبقة——بينما هو بـ آخر اسم route لـ أساس دقيق مستقل إسقاط، رابط تحليل ما زال إبرة مقابل canonical manifest، بداية نهاية إشارة نحو canonical توأم توليد صفحة. أصل أول صفحة لا يوجد يمكن وضع آخر اسم أب درجة؛`/` في وثيقة في كتابة واضح استخدام `/index.md`.

كل إنتاج بناء مدخل كل سوف تحليل VitePress إعداد، اشتراط `outDir` يجب هو محطة نقطة أصل دليل صارم إطار فرعي دليل، و اشتراط هو الأكثر قريب قائم أب دليل يجب تحليل إلى محطة نقطة أصل دليل حقيقي مسار بـ داخل. بناء سوف مباشر حل حذف رابط نوع إخراج بينما لا مرة تاريخ ذلك هدف، و في تحزيم قبل حذف حقيقي إخراج دليل. من مشروع مسؤول هذا واحد خطوة تغطية لن صاف فارغ نهائي إخراج دليل MPA بناء، و تجنب تجنب يتم إزالة توجيه أو مورد إنتاج في إعادة بناء بعد ناقص إبقاء. مع بعد أصلي توأم توليد صفحة إرسال إطلاق سوف يأخذ حالي VitePress بناء إنشاء ملف نظر لـ قد احتلال استخدام: توأم توليد صفحة أو صورة واحد قاعدة لا نيل تغطية هذا صنف ملف (مثال مثل `public/` فرعي هذا) ، نفس اسم اندفاع مفاجئ سوف جعل إرسال إطلاق فشل.

`llms.txt` من إصدار manifest توليد في محطة أصل: اثنان شجرة لغة شجرة حسب جانب حافة شريط ترتيب ترتيب صف، كل صفحة واحد سطر `- [label](<base><route>): <section>`، رابط لـ يحمل نشر مدة `DOCS_BASE` محطة داخل قطعا مقابل مسار.locale أول صفحة لا صف دخول——هذا عدد ملف ذاته حينئذ هو agent مدخل.

تطوير خادم مقابل تنقل و بلا رأس عميل توفير نفس جدول وجه.doc-projector إضافة في middleware تدريجي طلب من canonical مصدر إسقاط `.md` طلب و حسب يحتاج توليد `llms.txt`،`docs:dev` بلا حاجة إعادة بناء أي و خط فوق متسق؛ صفحة داخل `fetch()`(`Sec-Fetch-Dest: empty`) في dev تحت لحظة معنى ما زال تسليم إعطاء Vite، بينما إنتاج ساكن حالة حمل إدارة مقابل هو إرجاع أصلي ملف.

بناء بعد بوابة `verify-doc-site-fragments` في مهمة واحد توجيه توأم توليد صفحة أو `llms.txt` ناقص وقت حكم تحديد بناء فشل، حذف إسقاط `buildEnd` وصل خط لا يمكن عبر CI.

## Alternatives considered

**`vitepress-plugin-llms`.** صيانة نشط وثب،MIT بروتوكول،Vite،Vue،Vitest رسمي جهة محطة نقطة في استخدام؛ قدرة توليد كل صفحة Markdown،`llms.txt`،`llms-full.txt` و تطوير خادم استجابة. لكن اثنان عدد صلب تحرير رمز سلوك في هذا محطة إنتاج كسر تالف. هو يأخذ `dir/index.md` عرض مستو لـ `dir.md` كما لا يمكن إغلاق، معا لا تعديل كتابة صفحة داخل رابط، كل إشارة نحو شريط هدف سقوط أرض صفحة متبادل مقابل رابط الكل 404——هذا محطة كل لغة شجرة إصدار سبعة عدد index توجيه. هو أيضا يأخذ صورة مرجع تعديل كتابة لـ لا حمل محطة نقطة base أصل قطعا مقابل ها أمل مورد إنتاج مسار، في هذا محطة فرعي مسار GitHub Pages نشر تحت لا بد لكن 404؛ ذلك اعتماد من كل نشر في مجال اسم أصل، اثنان عدد مشكلة كل اصطدام لا إلى. ذلك `llms.txt` فقط إقرار قمة طبقة theme إعداد جانب حافة شريط، إقرار لا خروج هذا محطة حسب locale تخزين وضع جانب حافة شريط. إصلاح صحيح هذه معنى طعم حال fork أو واحد طبقة اقتران دمج إضافة داخلي سلوك بعد معالجة——مقارنة إعادة استخدام قد قياس إسقاط جهاز صغير إرسال إطلاق جهاز يملك أكثر كثير ذاتي لديه وجه تراكم.

**مرور Vite `publicDir` إرسال إطلاق.** Vite فقط دعم حمل واحد public دليل، هذا محطة قد سوف ذلك إشارة نحو يتم تتبع أثر `website/public/`؛ توليد توأم توليد صفحة سوف سقوط دخول تخطيط بوابة منع توقف تتبع أثر شجرة.

**توأم توليد صفحة داخل استخدام قطعا مقابل رابط.** platform.claude.com استخدام قطعا مقابل رابط هو لأن ذلك رئيسي آلة ثابت. هذا محطة base في محلي `/` و Pages فرعي مسار بين تغير، بينما إسقاط جهاز متبادل مقابل رابط في اثنان شجرة شجرة في أصل مثال يمكن تحليل، قطعا مقابل تحويل تعديل كتابة فقط سوف جذب دخول ثاني طقم رابط لغة قاعدة بينما لا تعديل حسن تحليل.

**أصلي شجرة قفز مرور locale أول صفحة.** قد إصدار صفحة رابط إلى `docs/user/index.md`، حذف أول صفحة توجيه سوف كسر تالف رابط غلاف إغلاق. تقشير مغادرة إصدار صيغة بعد باق تحت متن (أي H1) صار هذا لـ صفر، إعادة تحديد نحو frontmatter في VitePress خارج لا يوجد معنى معنى.

## Consequences

Agent يأخذ صفحة URL ذهاب إسقاط نهاية ذيل مائل عمود مجددا إضافة `.md` أي نيل أخذ هذا صفحة صاف Markdown، و في `/llms.txt` اكتشاف كل تجميع؛ تصيير محطة ثابت. بناء إخراج لـ كل توجيه كثير حمل واحد Markdown ملف، كل index توجيه كثير حمل واحد آخر اسم، خارج إضافة جانب وضع صورة فرعي هذا——متبادل مقابل تحزيم مورد إنتاج فقط هو ألف بايت درجة. توأم توليد صفحة إبقاء GitHub ريح إطار عنوان نص، بينما تصيير محطة مقابل يحتوي علامة نقطة عنوان استخدام مختلف slug؛agent ذاتي سطر تحليل عنوان، لذلك لا يوجد بوابة تغطية أصلي شجرة fragment. بسبب توأم توليد صفحة تلقي جمهور لا حاجة بينما مؤقت مؤقت:`llms-full.txt`، و كل صفحة"فحص نظر Markdown"تحكم عنصر——بعد من حاجة stock-theme محطة نقطة لحظة معنى لا ضبط theme دليل.
