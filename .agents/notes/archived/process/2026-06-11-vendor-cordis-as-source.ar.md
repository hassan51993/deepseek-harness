# Agent Note: سوف Cordis بـ شفرة المصدر شكل صيغة استلام تسجيل، بينما غير بصفة NPM اعتماد

Status: implemented
Archived: 2026-09-04

[English](2026-06-11-vendor-cordis-as-source.md) | العربية

## مشكلة

DeepSeek Harness بناء في Cordis إطار هيكل لـ فوق. هذا مستودع بدء وقت،Cordis core موضع في 4.0.0-rc.6(واحد مرشح إصدار إصدار) ؛harness اعتماد إطار هيكل داخلي تنفيذ (fiber دورة الحياة،dispose(مورد تحرير) ،waterfall(شلال نشر صيغة حدث) توزيع) ، ذلك تأكيد قطع سلوك مباشر علاقة إلى agent loop(ذكي جسم حلقة) صحيح تأكيد صفة حفظ إثبات.

## قرار

سوف الذي يحتاج Cordis حزمة (core،loader،include،group،timer،hmr،logger-console) و cordiverse أساس أساس مكتبة (cosmokit،schemastery) بـ شفرة المصدر شكل صيغة نسخ إلى `vendor/`، مسطح مستو تحويل وضع وضع، إبقاء ذلك أصلي npm حزمة اسم بـ تنفيذ نفاذ واضح workspace تحليل.`pnpm-workspace.yaml` ضبط `linkWorkspacePackages: true`، الذي بـ فقط يلزم فوق تنقل semver نطاق مطابقة، بلا نقاش بـ شفرة المصدر تنفيذ أيضا هو بـ بناء ناتج تنفيذ، اعتماد كل سوف تحليل إلى هذه ثابت إصدار workspace. حق صحيح رقم ثلاثة جهة اعتماد (js-yaml،chokidar،@standard-schema/spec انتظار) ما زال من npm نيل أخذ.

`vendor/README.md` هو manifest(بيانات وصفية بيان): سجل كل حزمة فوق تنقل مستودع و commit SHA، و واحد نسخة تفصيل كل محلي تعديل سجل.pre-commit حراسة حماية (`scripts/check-vendor-manifest.sh`) سوف رفض لم في نفس مرة إيداع في تحديث manifest vendor شفرة المصدر تغيير.

## سبق اعتبار بديل خطة

- **اعتماد npm حزمة**: مرفوض.core موضع في مرشح إصدار مرحلة مقطع،harness اعتماد إطار هيكل داخلي تنفيذ (fiber دورة الحياة،dispose،waterfall توزيع) ،agent loop صحيح تأكيد صفة حفظ إثبات أخذ قرار في هذه سلوك تأكيد قطع جدول الآن؛ فوق تنقل RC إصدار ترقية ممكن في لا يوجد محلي إصلاح مسار حال حال تحت كسر تالف هو جمع.
- **تمرير عودة استلام تسجيل كل نقل تمرير اعتماد**: مرفوض. حق صحيح رقم ثلاثة جهة اعتماد (js-yaml،chokidar،@standard-schema/spec انتظار) ما زال من npm نيل أخذ؛ فقط لديه داخلي تنفيذ مقابل أنا جمع لديه أثر إطار هيكل طبقة عندئذ حاجة ذاتي سطر يحتفظ.

## عاقبة

- harness تماما يحتفظ ذلك إطار هيكل طبقة: يمكن مراجعة حساب، يمكن ضرب رقعة، إصدار قفل تحديد. فوق تنقل RC لا يمكن توجيه يؤدي هذا مشروع لذا عائق، إطار هيكل bug يمكن في مستودع داخل مباشر إصلاح.
- بناء بعد حزمة و شفرة المصدر اختبار تنفيذ هو نفس إصدار استلام تسجيل Cordis؛ إزالة workspace رابط بعد، بناء بعد حزمة سوف في حزمة اسم ثابت حال حال تحت ساكن صامت تعديل استخدام npm فرعي هذا.
- فوق تنقل تزامن هو يد حركة عملية (مسار سجل في manifest في). تعديل سجل جعل diff نطاق بداية نهاية يمكن معرفة.
- استلام تسجيل حزمة إبقاء فوق تنقل شفرة ريح إطار؛lint و صارم إطار صفة بوابة سوف ذلك ترتيب حذف (هو جمع tsconfig في محلي وضع عرض أنا جمع مقارنة جديد تحرير ترجمة جهاز خيار).
- من رقم واحد يوم بدء حينئذ لديه واحد محلي رقعة: إزالة hmr locale-YAML استيراد (وقت التشغيل YAML استيراد خطاف لم يتم استلام تسجيل).
