# Agent Note: توليد Cordis نواة قلب API مشاركة اعتبار وثيقة

Status: implemented
Archived: 2026-07-27

[English](2026-07-20-generated-cordis-core-api.md) | العربية

## مشكلة

إضافة عمل من حاجة حل `ctx`، حدث إرسال إرسال،Fiber، إضافة تسجيل و Service خلف بعد تفصيل دقيق Cordis API. قد لديه [Harness حدث و خدمة دليل](2026-06-20-generated-cordis-catalog.md) متعمد فقط بسيط يلزم عام تضمين وراثة ذاتي Cordis عضو، لذلك لا يمكن بديل طريقة درجة Cordis مشاركة اعتبار وثيقة. إذا في شبكة محطة تحت صيانة آخر نسخة يد كتابة فرعي هذا، هو سوف و vendored شفرة المصدر إنتاج عائم نقل، أيضا سوف يجعل مصير يصبح مقدار خارج وثيقة كل من.

## قرار

`scripts/cordis-core-api.ts` استخدام TypeScript Compiler API، من `vendor/cordis/src` قراءة عام إعلان و أصلي JSDoc. واحد صريح صفحة بيان في [`docs/cordis-catalog/core/`](../../../../docs/cordis-catalog/core/context.md) تحت توليد خمسة عدد ملف:Context،Events،Fiber،Registry و Service.`scripts/gen-cordis-catalog.ts` سوف هذه صفحة و Harness حدث و خدمة دليل واحد نفس كتابة،`verify-cordis-catalog` سوف رفض مرور مدة ناتج.

توليد جهاز سوف تحقق الذي سجل صنف و طريقة إبقاء وصف صفة JSDoc، يشمل معامل و غير void قيمة راجعة عقد نحو. هو توليد يتضمن أصلي JSDoc كما فقط يحتوي إعلان `ts cordis-catalog` شفرة محيط شريط، مجددا سوف نفس نسخة شرح، معامل و قيمة راجعة عقد نحو تصيير لـ سهل في قراءة قراءة Markdown. شفرة المصدر رابط إشارة نحو vendored ملف، خمسة عدد صفحة بين متبادل متبادل تسليم تقاطع رابط.Harness دليل ما زال هو مستودع إعلان حدث و `ctx.*` خدمة كامل بيان؛ نواة قلب صفحة مسؤول شرح وراثة ذاتي Cordis API مثل أي عمل.

`website/docs.ts` سوف خمسة عدد مواصفة مصدر ملف إصدار إلى بنية مقابل `/reference/cordis-api/` و `/en/reference/cordis-api/` توجيه. في توليد جهاز إنتاج خروج قلب ترجمة صفحة قبل، اثنان عدد locale كل استخدام إنجليزي نص توليد مصدر، لذلك تبديل لغة وقت تنقل بنية و توجيه معرف إبقاء ثابت.

## اعتبار مرور بديل خطة

**سوف قديم شبكة محطة ملف استعادة لـ مواصفة Markdown.** هذا قدرة سريع سرعة استعادة صفحة، لكن ذلك توقيع و شرح ممكن و vendored تنفيذ عائم نقل، شبكة محطة أيضا سوف إعادة يصبح ثاني عدد وثيقة مصدر.

**مباشر توسيع ملء Harness دليل في وراثة طبقة.** هذه دليل عودة جواب لديه أي بعض Harness حدث و خدمة. سوف كامل إطار هيكل صنف مشاركة اعتبار خلط دخول نفس صفحة سوف نموذج غامض هذا نسخة بيان تحديد موضع، و دفع قلب وراثة طبقة إبقاء دقيق بسيط قائم قرار.

**مباشر إصدار vendored شفرة المصدر إعلان.** مصدر ملف أداة لديه مرجعي صفة، لكن لا يستطيع توفير مستقر رئيسي عنوان صفحة، مرور مرور غربلة اختيار عام ترتيب أو شبكة محطة تنقل، أيضا سوف كشف لا يخص مشاركة اعتبار عقد نحو تنفيذ جسم.

## أثر

خمسة عدد Cordis API صفحة عبر نفس عدد تحديد صفة توليد جهاز تتبع مع vendor تحديث، و إعادة استخدام مستودع وثيقة جديد طازج درجة فحص. شبكة محطة بلا حاجة نسخ محتوى يكفي نيل نيل مستقل Cordis API فصل عقدة، العربية مدخل و إنجليزي نص مدخل تنقل بنية إبقاء متسق.

صفحة بيان حاجة شخص عمل صيانة، لذلك إضافة جديدة عام Cordis نواة قلب نوع وقت يجب صريح إضافة توليد جهاز بند. حالي توليد شرح فقط لديه إنجليزي نص، كما شفرة المصدر JSDoc جودة كمية مباشر قرار مشاركة اعتبار وثيقة جودة كمية؛ العربية ناتج حاجة في توليد جهاز طبقة تنفيذ قلب ترجمة، لا يستطيع يد عمل تحرير توليد ملف.
