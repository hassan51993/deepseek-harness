# Agent Note: خفيف كمية تحويل يوم معتاد وثيقة قلب ترجمة

Status: implemented
Archived: 2026-09-04

[English](2026-08-08-lightweight-routine-documentation-translation.md) | العربية

## مشكلة

يوم معتاد مزدوج لغة تحرير سوف تلقائي اختيار استخدام كامل[قلب ترجمة skill(تقنية قدرة)](../../../skills/dsh-translate-docs/SKILL.md). أي جعل مرور مرور[أساس في بسيط تقرير تحديث أفضل تحويل](2026-07-26-briefed-minimal-translation-updates.ar.md) ، مرة صغير وثيقة تعديل ما زال ممكن تحميل مخصص استخدام سير العمل، توليد بسيط تقرير، يأخذ سطر نص قلب ترجمة تفويض إرسال إعطاء subagent، و آخر سطر تنفيذ واحد جولة نواة تحقق. هذا نوع تحرير ترتيب استهلاك استهلاك وقت، سياق و نموذج token مقارنة مباشر قلب ترجمة تعديل نص ذاته أيضا كثير، بينما كما skill تلقائي اكتشاف آلية أيضا سوف في عادي وثيقة معالجة جولة في كشف هذا سير العمل.

## قرار

- **يوم معتاد قلب ترجمة مرة إتمام، فقط معالجة واحد مرة.** حالي agent(ذكي جسم) تحميل [terminology.md](../../../../docs/i18n/terminology.md) ، مباشر قلب ترجمة حدوث تعديل محتوى؛ إذا فن لغة فعلي أول الآن موضع عبر مرور تحرير حد، فإن نقل حركة متبادل ينبغي تضمين ملاحظة، لا فإن إبقاء تعديل خارج قد مراجعة مقابل جانب ملف سطر نص؛ الأكثر بعد إعادة سجل إعداد مقابل. هو لن استدعاء قلب ترجمة skill، توليد بسيط تقرير، بدء مفرد وحيد قلب ترجمة مراجعة جولة، أيضا لن يأخذ قلب ترجمة تفويض إرسال إعطاء subagent.
- **توسيع سير العمل فقط حد يد حركة استدعاء.** [dsh-translate-docs](../../../skills/dsh-translate-docs/SKILL.md) إبقاء بسيط تقرير، سطر نص قلب ترجمة تفويض إرسال، كامل مقالة وثيقة و حسب نطاق نواة تحقق مسار.[Claude Code skill عقد نحو](https://code.claude.com/docs/en/skills#control-who-invokes-a-skill) قراءة `SKILL.md` في `disable-model-invocation: true` و `user-invocable: true`؛Codex قراءة `agents/openai.yaml` في `policy.allow_implicit_invocation: false`. مستودع `.claude/skills` رمز رقم رابط يأخذ نفس عدد skill دليل خريطة إعطاء Claude Code، لذلك اثنان عدد منتج مشترك نفس نسخة إيداع إلى مستودع سير العمل، معا قسم آخر تنفيذ كل منها استدعاء بيانات وصفية عقد نحو.`doc-sync` في skill استدعاء بيانات وصفية بوابة سوف يجعل هذا اثنان نسخة مستقل سياسة إبقاء متسق.
- **تلقائي سير العمل لن سلسلة ربط استدعاء هذا بند فقط حد يد حركة استدعاء skill.** خفيف كمية افتراضي سلوك من أصل درجة إشارة أمر و وثيقة إشارة أمر تعريف. وثيقة، شبكة محطة تزامن، سطر نص و شفرة مراجعة skill سوف رابط هذه إشارة أمر أو i18n عقد نحو، بينما لن لأن دفع قطع إلى مزدوج لغة تعديل حينئذ تحميل `dsh-translate-docs`.
- **إعداد مقابل عقد نحو و مراجعة عقد نحو إبقاء ثابت.** اثنان نوع لغة ملف ما زال سوف واحد و تحديث؛ لم لمس و مقابل جانب ملف إجراء لفظ إبقاء مستقر؛ فن لغة قيد ما زال صالح؛ فقط لديه حالي agent تأكيد إعداد مقابل بعد، عندئذ سوف إعادة كتابة متسق صفة سجل؛`doc-sync`(وثيقة تزامن بوابة) متابعة تنفيذ كل لغة مادة آلة آلة فحص. دلالة طبقة وجه قلب ترجمة جودة كمية ما زال من شخص عمل مراجعة مسؤول.

## سبق اعتبار بديل خطة

- **حذف توسيع skill و بسيط تقرير أداة**: غير مقبول. في كامل مقالة وثيقة قلب ترجمة أو شائك يد اثنان جانب محتوى تنسيق ضبط في، و مقابل متعمد اختيار تلقي تحكم سير العمل استدعاء جهة بينما قول، صريح يد حركة استدعاء ما زال لديه قيمة قيمة.
- **استخدام تلقائي استدعاء خفيف كمية skill يحل محل توسيع skill**: غير مقبول. آخر بند تلقائي skill ما زال سوف إعطاء هذا بند مهمة زيادة اكتشاف سياق و استدعاء حد، بينما حالي agent فقط اعتماد حسب فن لغة جدول و معتاد إقامة إشارة أمر يكفي مباشر إتمام هذا مهمة.
- **فقط مقابل جديد إعداد مقابل أو كبير قاعدة نموذج تعديل إبقاء تلقائي استدعاء**: غير مقبول. أساس في قاعدة نموذج دفع قطع نفس مثال هو واحد بند إخفاء سياسة سياسة، ممكن خروج نحو معنى مادة أرض تفعيل عال فتح إلغاء سير العمل. أي وقت قيمة نيل لـ توسيع مسار دفع خروج صار هذا، ينبغي من مستخدم بينما غير agent قرار.
- **معا إلغاء تحميل فن لغة جدول**: غير مقبول. فن لغة جدول هو جسم كمية صغير لكن لديه قيد قوة إدخال، يمكن منع توقف كامل مستودع حدوث فن لغة عائم نقل؛ إزالة هو انتظار في استخدام منتج لغة لا متسق تبديل أخذ token عقدة حذف.

## عاقبة

- عادي تطوير صار هذا قدوم ذاتي حدوث تعديل مصدر نص، ذلك نطاق جزء مقابل جانب ملف سياق و فن لغة جدول، لم يعد قدوم ذاتي توسيع سير العمل بسيط تقرير و subagent سياق.
- حالي agent في نفس جولة داخل مقابل يوم معتاد قلب ترجمة نهائي نتيجة مسؤول. خفيف كمية مسار متعمد وضع ترك توسيع سير العمل توفير تلقائي توليد مقابل متساو معلومة، تفويض إرسال الذي توفير عزل، و مفرد وحيد سطر نص نواة تحقق جولة.
- مستخدم ما زال يمكن في Claude Code في عبر `/dsh-translate-docs`، أو في Codex في عبر `$dsh-translate-docs` صريح استدعاء كامل سير العمل.
- Claude Code frontmatter و Codex سياسة ملف هو ذاك هذا مستقل منتج عقد نحو؛ إذا بعض بند skill فقط في واحد منتج في تغيير لـ يد حركة استدعاء، أو من في Claude Code في مقابل نموذج و مستخدم كل غير ممكن استخدام،`doc-sync` سوف رفض هذا حالة.
