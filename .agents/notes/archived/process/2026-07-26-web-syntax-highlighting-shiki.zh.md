# Agent Note: web client لغة قاعدة عال مضيء——تزامن دقيق حبة درجة shiki

Status: implemented
Archived: 2026-09-04

[English](2026-07-26-web-syntax-highlighting-shiki.md) | العربية

> نطاق:web client وحيد واحد طقم لغة قاعدة عال مضيء جسم نظام——اعتماد قطع قرار، مفرد مثال شكل،token جدول اتفاق و كل إزالة استهلاك جدول وجه. هذا مقالة هو PTC mode UI كومة تراكم PR(Pull Request) سلسلة رقم خمسة عدد PR؛[chat فرعي استدعاء سطر Agent Note](../feature/2026-07-26-ptc-chat-subcall-rows.zh.md) تسليم `run_code` برنامج متن، بينما هذا جسم نظام وجود معنى معنى صحيح هو يجعل هو يمكن قراءة. مثال صيغة أساس هذا قاعدة من [Web مثال صيغة جسم نظام قطع قرار](2026-07-19-web-styling-system.zh.md) قاعدة تحديد.

## مشكلة

client مرور ذهاب يأخذ كل واحد موضع شفرة جدول وجه——assistant متن داخل markdown محيط شريط شفرة كتلة،`run_code` برنامج متن،details وجه لوح معامل——واحد قاعدة تصيير صار لا حمل عال مضيء انتظار عرض صاف نص. هذا كومة تراكم PR سلسلة رئيسي يلزم تحميل حمل هو نموذج تأليف كتابة TypeScript؛ لم مرور عال مضيء برنامج مسح قراءة بدء قدوم واضح إظهار أكثر أكل قوة، بينما مستودع قد في ذاتي بيت VitePress محطة نقطة فوق تسليم مرور shiki عال مضيء شفرة، في هو web تطبيق صار وحيد لا حمل لغة قاعدة عال مضيء شفرة تصيير جدول وجه.

## قرار

**اعتماد تزامن دقيق حبة درجة شكل shiki، بصفة `ui-primitives` داخل واحد مفرد مثال، رئيسي عنوان تحويل تماما مرور من CSS ذاتي تعريف خاصية إتمام.**

- **اعتماد**:`shiki/core` + `@shikijs/langs`، مرور `createHighlighterCoreSync` تركيب إعداد `createJavaScriptRegexEngine({ forgiving: true })` تجميع——لا حمل oniguruma WASM، لا يوجد مختلف خطوة ابتدائي تحويل، مقابل bundle صديق جيد. لغة قاعدة (grammar) أبيض اسم مفرد:`typescript`(داخل تضمين JS) ،`shellscript`،`json`——أي harness فعلي سوف تصيير ذلك بضعة نوع لغة؛ ذلك بقية واحد قاعدة رجوع إلى بضعة أي تماما متسق صاف نص كتلة، أبدا تقرير خطأ. أولا مثال:VitePress محطة نقطة قد عبر shiki تصيير الكل وثيقة شفرة؛ بينما في TypeScript(صحيح هو هذا موضع يلزم ضيق تحميل حمل) فوق،TextMate لغة قاعدة فعلي جودة صفة أفضل في صحيح فإن عال مضيء جهاز.
- **مفرد مثال**:`ui-primitives/src/markdown/highlight.ts` لـ كل document إنشاء واحد `HighlighterCore`، و عام `highlightToHtml(code, lang)`(undefined أي تصيير لـ صاف نص). جذب محرك إضافة لغة قاعدة بناء هو مرة نحو 120-175ms طويل مهمة، لذلك وحدة في إضافة بدء وقت استخدام تأخير متأخر مهمة مسبق حار مفرد مثال (كسول صفة مسار إبقاء لـ صحيح تأكيد صفة التقاط قاع) ، يأخذ هذا قلم فتح إلغاء نقل خروج تصيير مسار——لا فإن تدفق صيغة finalize تسليم تبديل ذلك واحد لحظة سوف بطاقة توقف. آخر اسم جدول استخدام `Map` بينما غير كائن:fence معلومة نص من assistant تأليف كتابة، عدة مثل `constructor` هذا مثال وسم يجب سقوط فارغ، بينما لا هو تحليل إلى وراثة خاصية و يجعل shiki انهيار انهيار. مشترك `CodeBlock` مكون معا يملك اثنان بند فرع؛ ذلك shiki فرع مرور `dangerouslySetInnerHTML` حقن توليد span شجرة——هذا استخدام قاعدة نيل دقيق، لأن shiki إخراج هو من شفرة نص حساب حساب خروج ساكن حالة span شجرة (لا تدفق مرور أي مستخدم HTML، لا يوجد نص برمجي أو حدث معالج) ، هذا صحيح هو shiki ذاته وثيقة تحميل واضح إزالة استهلاك مسار.
- **رئيسي عنوان تحويل**:shiki `createCssVariablesTheme` يجعل كل واحد نوع token لون لون كل مرور من `--shiki-*` ذاتي تعريف خاصية توجيه؛ أخذ قيمة ذاته إقامة في `ui-theme/styles/shiki.css` token جدول داخل (مضيء لون في `:root`، داكن لون في `body[data-ds-dark-theme]`——طبقة تراكم طريقة و ذلك بقية كل ورقة مثال صيغة جدول نفسه) ، من ui-theme حركة حالة عميل entry استيراد و تحرير ترجمة دخول هذا إضافة يحتفظ عام CSS. مكون CSS إبقاء فقط استخدام token؛ أي لون لون حرف وجه كمية كل لا دخول JS أو مكون مثال صيغة جدول. خلف مشهد/قبل مشهد بـ آخر اسم إشارة نحو قائم markdown شفرة كتلة token، جعل عال مضيء كتلة و صاف نص كتلة ذاك هذا متسق.
- **جدول وجه**:markdown محيط شريط شفرة كتلة (`MarkdownText` `pre` مكون يأخذ مفرد نص محيط شريط توجيه إلى `CodeBlock`) ،`run_code` توسيع بعد برنامج متن (ToolRow code تغيير جسم،`lang="typescript"`) ، و details وجه لوح Input معامل (`lang="json"`). أداة إخراج من لا فعل لغة قاعدة عال مضيء——هو هو مهمة معنى نص، صلب تخمين واحد نوع لغة قاعدة، حمل قدوم خطأ عال مضيء سوف كثير في مساعدة مساعدة؛bash بطاقة إخراج فقط تحمل تحميل ذلك ذاته ANSI تسلسل إعلان لون لون، مرور من[طرفية بطاقة](../feature/2026-07-28-web-terminal-card.zh.md) تصيير.

## سبق اعتبار بديل خطة

**`rehype-highlight`/lowlight.** انحناء إقامة مرة اختيار: يوم لكن تزامن،bundle جسم تراكم نحو لـ ثلاثة قسم لـ واحد، لكن أساس في صحيح فإن لغة قاعدة في TypeScript فوق حفظ حق درجة لحم عين مرئي أرض أكثر فرق، بينما كما مستودع سوف من هذا معا تشغيل اثنان طقم عال مضيء جسم نظام (محطة نقطة استخدام shiki، تطبيق استخدام highlight.js) ، صيانة اثنان طقم رئيسي عنوان تحويل مفردات.

**كامل `shiki` bundle، أو oniguruma WASM جذب محرك.** مرفوض: كامل bundle سوف حمل فوق كل واحد نوع لغة قاعدة و رئيسي عنوان؛WASM حاجة مختلف خطوة تحميل، بينما هذا صحيح هو تزامن client بدء لحظة معنى قاعدة تجنب. دقيق حبة درجة core إضافة ثلاثة نوع لغة قاعدة، يجعل صار هذا و فعلي استخدام كمية صار صحيح مقارنة.

**في worker في عال مضيء/مختلف خطوة عال مضيء.** مرفوض: تحميل حمل كل جدا صغير (برنامج، محيط شريط شفرة كتلة، معامل) ؛ تزامن JS جذب محرك دقيق ثانية درجة حينئذ قدرة يأخذ هو جمع token تحويل، بينما مختلف خطوة سوف جذب دخول واحد مقطع لم عال مضيء شفرة وميض الآن، خارج إضافة تصيير آلية إزعاج حركة، لكن لا يوجد أي فعلي قياس نيل خروج حاجة.

## عاقبة

كل مستهلك مشترك استخدام نفس عدد شفرة جدول وجه——لم قدوم جديد جدول وجه استيراد `CodeBlock` أي وراثة عال مضيء، رئيسي عنوان تحويل و صاف نص رجوع.bundle زيادة كمية هو shiki core إضافة ثلاثة نوع لغة قاعدة (في `ui-primitives` في مرة صفة دعم دفع).token لون لون هو رقم واحد ورقة `--shiki-*` جدول؛ تسجيل آخر اسم تغطية كتابة رئيسي عنوان حزمة توسيع هو جمع طريقة و توسيع أي أخرى token بلا مختلف.jsdom spec قفل تحديد token span بنية، آخر اسم تحليل، اثنان بند رجوع فرع و محيط شريط توجيه؛ قائم قد بناء bundle لقطة و متصفح e2e تغطية تجميع بعد مسار.
