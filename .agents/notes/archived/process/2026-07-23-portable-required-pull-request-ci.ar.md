# Agent Note: سحب أخذ طلب CI يمكن نقل غرس استعادة حد

Status: implemented
Archived: 2026-09-04

[English](2026-07-23-portable-required-pull-request-ci.md) | العربية

## مشكلة

قسم إعداد إلى مجموعة نسج ذاتي لديه تشغيل جهاز وسم سحب أخذ طلب مطلوب عمل عمل، في GitHub لا يمكن لـ هذه حوض قسم إعداد تشغيل جهاز وقت سوف حمل متابعة ترتيب طابور. سير العمل ذاته صالح،GitHub معيار حمل إدارة عمل عمل ما زال قدرة عبر، لكن `all checks passed` بداية نهاية لا يمكن بدء، أصل هذا سليم سليم سحب أخذ طلب لذلك لا يمكن ممتلئ كاف فرع حفظ حماية اشتراط.

حساب مفرد حالة صحيح معتاد، تشغيل جهاز تعريف موضع في `Ready` حالة و مقارنة عال تلقائي توسيع تقليص سعة حد أعلى، كل لا يستطيع إثبات إشارة تحديد تشغيل جهاز حوض يمكن استقبال عمل عمل. مطلوب صحيح تأكيد صفة فحص حاجة مسبق أولا واضح واحد بند يمكن نقل غرس استعادة مسار، أي جعل يوم معتاد منخفض تأخير متأخر مسار اعتماد مستودع خارجي تشغيل جهاز مسبق إعداد أيضا لا مثال خارج.

## قرار

[CI](../../../../.github/workflows/ci.yml)(فقط pull request) في فقط حد هذا مستودع استخدام مؤسسة عمل درجة 32 نواة تشغيل جهاز حوض فوق تشغيل مطلوب رئيسي Node 24 عمل عمل، و مستقر `all checks passed` تجمع دمج مسار. هذا تجمع دمج مسار لا تنفيذ شفرة فحص خروج أو مستودع بوابة؛ لكن يجعل هو و الذي اعتماد فعلي جودة صفة عمل عمل مشترك استخدام مؤسسة عمل درجة تشغيل جهاز حوض، يمكن تجنب تجنب هذه عمل عمل قد نجاح بعد، مطلوب حكم تحديد نتيجة أيضا جذب دخول واحد بند مفرد وحيد معيار حمل إدارة حساب استهلاك اعتماد. مطلوب Windows عمل عمل في معيار `ubuntu-latest` فوق عبر Wine تشغيل Windows Node، تغطية منع قطع صفة فحص نطاق؛ واحد مستقل أصلي `windows-2025` عمل عمل سوف تلقائي بدء، لكن لا مشاركة و تجمع دمج مسار ([مزدوج Windows قرار](2026-08-08-native-windows-pull-request-ci.ar.md)). معيار حمل إدارة job إبقاء Node 22.19،Node 26،Python SDK اختبار وحدة طقم عنصر، و في كل قد إصدار أصلي هدف فوق تشغيل[تثبيت بعد wheel Python وقت التشغيل تحقق](../testing/2026-08-23-installed-python-wheel-black-box-ci.ar.md) ؛ سلسلة سطر مشاركة اعتبار مسار (في `ci-master.yml` في) ما زال هو كامل كما لم قسم قطعة عبر منصة تعريف. هذه معيار حمل إدارة عمل عمل يجعل يمكن نقل غرس تنفيذ حد إبقاء يمكن مراقبة قياس، بينما لا لا بد في كل سحب أخذ طلب في تكرار رئيسي بيان.

ثلاثة بند Linux رئيسي عمل عمل،Node توافق صفة،Python SDK اختبار وحدة طقم عنصر،Python وقت التشغيل تحقق و `windows node 24 / wine blocking` متابعة بصفة `all checks passed` اعتماد؛`windows node 24 / native complete` يتم لحظة معنى ترتيب حذف. فرع حفظ حماية متابعة اشتراط `e2e` و `all checks passed`. باق بقية مؤسسة عمل درجة Linux تشغيل جهاز وسم لا يمكن قسم إعداد تشغيل جهاز وقت لا يوجد تلقائي بعد تجهيز آلية: معيار عمل عمل سوف متابعة تقرير إبلاغ كل منها اتفاق، لكن لا يمكن إنتاج خروج ناقص مطلوب نتيجة.

حالي رئيسي توسيع اندفاع و ذلك قياس كمية نتيجة بـ[كبير نوع تشغيل جهاز قرار](2026-07-22-evidence-based-larger-hosted-runners.ar.md) لـ دقيق.[عبر منصة سلسلة سطر مشاركة اعتبار مسار](2026-07-21-serial-cross-platform-ci-reference.ar.md) متابعة بصفة مستقل كامل صفة فحص، الآن من `master` فوق عام شركة ذاتي لديه `vm-backup`/`dsh-win-ci` ذاتي حمل إدارة حار تجهيز عبر طريق توفير؛ فقط تخزين حمل إدارة سلسلة سطر مشاركة اعتبار هو منع استخدام `serial-macos`. يد حركة كبير نوع تشغيل جهاز طقم عنصر فإن إبقاء قاعدة إطار مقارنة مقارنة، معا لا توسيع كبير عادي مطلوب مستطيل دفعة.

## سبق اعتبار بديل خطة

**سوف Linux رئيسي عمل عمل و تجمع دمج مسار إبقاء في معيار سعة كمية فوق.** هذا خطة إزالة حذف باق بقية مؤسسة عمل درجة تشغيل جهاز قسم إعداد اعتماد، لكن معيار تشغيل جهاز فوق كامل عمل عمل عكس تغذية واضح إظهار أكثر بطيء، ما زال سوف لقاء إلى مشترك سعة كمية ترتيب طابور. حالي تفكيك قسم حيث إبقاء يمكن نقل غرس توافق صفة و سلسلة سطر دليل، أيضا سوف مؤسسة عمل درجة تشغيل جهاز سعة كمية لأجل Linux رئيسي صلة مفتاح مسار.

**أصل حسب علامة تسمية نواة قلب عدد اختيار مؤسسة عمل قاعدة إطار.** أساس دقيق اختبار جدول واضح توسيع فاعلية نتيجة لا عرض مفرد ضبط تغير، ضبط استهلاك وقت أيضا وجود موجة حركة، لذلك مطلوب تشغيل جهاز حوض تعديل من كامل عمل عمل دقيق قياس كمية نتيجة اختيار تحديد.

**في سعة كمية غير ممكن استخدام وقت قفز مرور فحص أو خفض منخفض ذلك درجة آخر.** هذا نوع طريقة عبر إسقاط دليل بينما غير تنفيذ مستودع مطلوب اتفاق قدوم جعل حالة تغيير أخضر.

**في كل منصة رئيسي آلة فوق استخدام نفس عمل خط مسار سياسة.** خارج طبقة بوابة تزامن و داخل طبقة أداة عمل خط مسار في Linux،Windows و معيار تشغيل جهاز فوق تنازع استخدام طريقة مختلف؛ حسب رئيسي آلة فعلي قياس حد أعلى يمكن تجنب تجنب إضافة جديدة نواة قلب عكس بينما سحب بطيء تنفيذ.

## عاقبة

عادي سحب أخذ طلب سوف سوف مؤسسة عمل درجة تشغيل جهاز سعة كمية لأجل Linux صلة مفتاح مسار، بينما Wine عمل عمل يجعل مطلوب Windows حكم تحديد متابعة استخدام معيار Linux تشغيل جهاز سعة كمية. مستقل أصلي عمل عمل استخدام معيار Windows تشغيل جهاز سعة كمية، لن تأخير متأخر أو تغيير تجمع دمج مسار. مرة إبرة مقابل تأكيد قطع فرع رأس فعلي تشغيل سوف منطقة قسم فرع حفظ حماية اعتماد أمر و مفرد وحيد تشخيص اتفاق؛ ترتيب طابور تأخير متأخر و كل عمل عمل من `startedAt` إلى `completedAt` تنفيذ منطقة بين قسم فتح تقرير إبلاغ.

مؤسسة عمل درجة تشغيل جهاز قسم إعداد قدرة تحت خفض وقت، معيار توافق صفة عمل عمل، مطلوب Wine عمل عمل و تشخيص صفة أصلي Windows عمل عمل ما زال قدرة توفير لديه استخدام دليل، لكن لا يمكن يجعل تلقي منع مطلوب Linux عمل عمل أو تجمع دمج مسار تغيير أخضر. استعادة Linux متاح صفة وقت، ممكن حاجة استعادة كامل معيار حمل إدارة توسيع اندفاع؛ فقط تغيير تشغيل جهاز حوض تعريف حالة، لا كاف بـ إثبات هو يمكن استقبال عمل عمل.
