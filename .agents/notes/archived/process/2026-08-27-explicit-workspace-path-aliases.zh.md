# Agent Note: Explicit workspace path aliases replace per-group wildcards

Status: implemented
Archived: 2026-09-04

[English](2026-08-27-explicit-workspace-path-aliases.md) | العربية

## Problem

`tsconfig.base.json` هو كامل مستودع تحليل باب وجه: كل حزمة project كل extends هو، اثنان عدد تجمع دمج إعداد كل قراءة هو، كل Vitest إعداد كل يأخذ `vite-tsconfig-paths` إشارة نحو هو. منها اثنان بند آخر اسم حسب حزمة**قسم مجموعة**بينما لا هو حسب حزمة كل كتابة واحد بند مرشح——`@deepseek-ai/dsh-*` صف 49 عدد مرشح glob،`@deepseek-ai/dsh-*/invariant` صف 45 عدد.

TypeScript و tsx حسب ترتيب تدريجي عدد محاولة تجربة هذه مرشح، أخذ رقم واحد وجود، لذلك واحد يقع في قائمة اعتماد بعد موضع حزمة، ذلك شرح رمز يلزم لـ قبل وجه كل مرة لم أمر في شراء مفرد. في `dsh` شفرة المصدر بدء تحت، كل مرة لم أمر في كل هو واحد `ERR_MODULE_NOT_FOUND`، بينما Node سوف استخدام `decorateErrorWithCommonJSHints` تركيب زينة هو——كل مرة فشل كل ركض واحد مرة كامل CommonJS تحليل مشي فحص. مرة شفرة المصدر بدء profile يأخذ **934.6 ms(احتلال بدء 35%)**مفرد وحيد عودة إعطاء هذا بند تركيب زينة مسار، مصدر هو 60,942 مرة فشل تحليل.

بديل قيمة الأكثر إعادة تماما جيد سقوط في يتم مرجع الأكثر كثير حزمة فوق:`packages/util/*` ترتيب في 49 عدد مرشح داخل رقم 44 موضع، لكن تركيب حال بضعة نحو كل إضافة كل يلزم مرجع ورقة فرعي أداة، لذلك `dsh-timeout` كل مرة تحليل نحو دفع 9 ms، بينما واحد لديه صريح آخر اسم شرح رمز فقط يلزم 0.05 ms.

## Decision

`scripts/gen-tsconfig-paths.ts` في `paths` نهاية ذيل واحد حمل علامة منطقة مجال داخل، لـ كل workspace حزمة كتابة واحد بند صريح آخر اسم، اثنان بند قسم مجموعة عبر إعداد رمز مع لـ حذف.`pnpm run gen-tsconfig-paths` إعادة كتابة هذا منطقة مجال؛`pnpm run verify-tsconfig-paths` فقط تقرير إبلاغ عائم نقل، و و أخرى توليد شيء فحص واحد بدء ركض في `ci-static` عربة طريق فوق.

توليد جهاز فقط لـ**إعلان اسم تماما جيد انتظار في `@deepseek-ai/dsh-<دليل اسم>`** حزمة إرسال آخر اسم، لأن ذلك هو عبر إعداد رمز وحيد ممكن تحليل خروج شكل: هو يأخذ شرح رمز بعد لاحقة بديل دخول `packages/<group>/<بعد لاحقة>/src`. اسم حرف و دليل لا متسق حزمة——`packages/typert/protocol` فوق `@deepseek-ai/dsh-typert-protocol`، و `dsh-client-*` و `dsh-host-*` اثنان عائلة——هذا قدوم حينئذ لديه يد كتابة آخر اسم، إبقاء لا حركة. إذا بعض عدد شرح رمز يتم اثنان عدد حزمة دليل معا إقرار قيادة، توليد جهاز**رمي خطأ**بينما لا هو مهمة اختيار ذلك واحد، لأن صريح خريطة لا يمكن جدول بلوغ عبر إعداد رمز اعتماد قسم مجموعة ترتيب قطع قرار؛ حالي لا وجود هذا نوع اندفاع مفاجئ.

حذف عبر إعداد رمز أيضا حذف إسقاط «لا شخص كتابة آخر اسم حزمة ما زال قدرة تحليل» التقاط قاع، لذلك توليد جهاز معا تأكيد تغطية تمام تجهيز: كل يحتوي `src` workspace حزمة كل يجب يتم توليد آخر اسم أو يد كتابة آخر اسم خريطة،`--check` سوف نقطة اسم أي لم يتم تغطية من. لا يوجد هذا بند تأكيد، واحد اسم حرف و دليل لا متسق جديد حزمة سوف يتم توليد جهاز قفز مرور، متابعة مرور workspace لين سلسلة تحليل إلى بناء ناتج `lib/`——صحيح هو صريح آخر اسم يلزم إزالة حذف ناتج طبقة تسرب تسرب.

هذا منطقة مجال استخدام علامة ملاحظة تفسير بين**تحديد نقطة نص تعديل كتابة**توليد، بينما لا هو إعادة تسلسل تحويل كامل ملف.`tsconfig.base.json` هو JSONC، ذلك يد كتابة آخر اسم حمل لديه حل تفسير غير إظهار لكن خريطة ملاحظة تفسير، إعادة تسلسل تحويل سوف يأخذ هو جمع فقد إسقاط.

هذا قرار**جزء يحل محل**[حزمة بيان تلقائي اكتشاف رفع سجل](../../proposed/process/2026-06-20-discover-package-inventory.zh.md)——هذا رفع سجل يأخذ «دمج لـ واحد عبر إعداد رمز» تسجيل لـ حالي تنفيذ، بينما عبر إعداد رمز قد يتم حذف؛ هذا رفع سجل باق بقية رئيسي عنوان (تجمع دمج إعداد داخل صريح `references` عدد مجموعة) لا تلقي هذا مرة تعديل أثر.

إبقاء أربعة بند عبر إعداد رمز، كل بند فقط لديه واحد مرشح:`dsh-host-*/invariant`،`dsh-client-*/invariant`،`dsh-client-*/client`، و خمسة بند `dsh-host-<name>/*` فرعي مسار خريطة. واحد مرشح فقط زهرة مرة استكشاف قياس، توسيع هو جمع فقط سوف تبديل قدوم ملف تغيير كبير بينما بلا استلام فائدة.

## Resolution differences this change makes

مستودع شفرة المصدر في ظهور كل `@deepseek-ai/dsh-*` شرح رمز——مشترك 1,023 عدد متبادل لا نفسه——تحليل هدف و تعديل قبل تماما متسق، فقط لديه عشرة واحد مثال خارج: هو جمع الآن قدرة تحليل، بينما هذا قبل لا يستطيع. هذا عشرة واحد هذا قبل كل هو مرور workspace لين سلسلة تحليل إلى بناء ناتج `lib/`، بينما لا هو شفرة المصدر.

منها سبعة عدد هو `/invariant` فرعي مسار:`dsh-invariants/invariant`،`dsh-lsp/invariant`،`dsh-lsp-stdio/invariant`،`dsh-tool-lsp/invariant`،`dsh-terminal/invariant`،`dsh-terminal-bash/invariant`،`dsh-tool-terminal/invariant`.

يتم حذف `dsh-*/invariant` عبر إعداد رمز متروك تسرب `lsp`،`terminal`،`client`،`host` أربعة عدد قسم مجموعة. منها `client` و `host` متروك تسرب هو**لحظة معنى كما لديه وثيقة**——هذا اثنان عائلة لديه مخصص استخدام عبر إعداد رمز، لأن هو جمع حزمة اسم بـ قسم مجموعة دليل اسم لـ بادئة. بينما `lsp` و `terminal` متروك تسرب لا يوجد أي هذا صنف إدارة من،`packages/runtime-diagnostics/invariants` فإن اثنان بند قائمة كل لا في. في هو هذا سبعة عدد شرح رمز هذا قبل هو عبر workspace لين سلسلة و حزمة `./invariant` توجيه خروج تحليل إلى بناء ناتج `lib/types/*.d.ts`، بينما لا هو تحليل إلى شفرة المصدر——هذا و «ساكن حالة بوابة عبر `paths` يأخذ workspace استيراد تحليل إلى `src`، و في جاف صاف شجرة فوق عبر» قاعدة متبادل مقاومة لمس. يأخذ آخر اسم موحد واحد بعد، هو جمع و كل نفس صنف واحد مثال تحليل إلى شفرة المصدر.

آخر خارج أربعة عدد هو يتم تغطية تأكيد انتزاع خروج قدوم**كامل حزمة**:`dsh-client-ui-directory-picker-browse`،`dsh-client-ui-directory-picker-native`،`dsh-experimental-agent-team-profile`،`dsh-experimental-agent-team-web-profile`. هو جمع كل نداء `dsh-<قسم مجموعة>-<دليل>`، أي عبر إعداد رمز كل بديل لا خروج هذا نوع شكل؛ بينما هو جمع ذات جانب نفس عائلة حزمة كل لديه يد كتابة آخر اسم——هذا أربعة عدد فقط هو تسرب. الآن تكملة فوق.

## Testing

`scripts/gen-tsconfig-paths.spec.ts` تثبيت إقامة: استلام تجميع جهاز يأخذ حزمة خريطة إلى هو ذاتي ذات دليل، قفز مرور حمل يد كتابة آخر اسم حزمة، إرجاع لديه تسلسل جدول؛ مصير يجعل يقع في يد كتابة شرح رمز، كما منطقة مجال استلام ذيل لا حمل كثير بقية فاصلة رقم؛ منطقة مجال كتابة جهاز فقط استبدال علامة نطاق، و في نقص قليل علامة وقت رفض؛ و إيداع بعد إعداد داخل اثنان بند قسم مجموعة عبر إعداد رمز كل لا تكرار وجود. آخر لديه اثنان بند حالة استخدام تثبيت إقامة تغطية تأكيد: هو سوف نقطة اسم لم يتم خريطة حزمة، كما مقابل إيداع بعد إعداد تقرير إبلاغ لـ فارغ.

بوابة رفض مسار يتم مباشر تحقق مرور: حذف إسقاط واحد بند توليد آخر اسم سوف يجعل `verify-tsconfig-paths` بـ غير صفر رمز خروج، استعادة بعد فحص عبر.

CLI مدخل حراسة حماية اعتماد مستودع قائم مقارنة مقارنة طريقة `import.meta.filename === resolve(process.argv[1])`، بينما لا هو تجميع وصل `file://` URL. تجميع وصل شكل صيغة في `import.meta.url` فعل مئة قسم رقم تحرير رمز بينما `process.argv[1]` لا فعل وقت بطلان——مستودع مسار يحتوي فارغ إطار، أو أي Windows قرص رمز مسار——كما بطلان هو ساكن صامت: نص برمجي ماذا أيضا لا فعل حينئذ بـ 0 خروج، تماما تماما سوف يجعل هذا طريق باب في الأكثر حاجة هو بيئة داخل شكل نفس وهمي ضبط. يأخذ نص برمجي نسخ إلى واحد اسم حرف يحتوي فارغ إطار دليل تحت تشغيل يكفي تكرار الآن: تجميع وصل صيغة حراسة حماية طلب قيمة لـ false، قائم كتابة قاعدة لـ true.

## Alternatives considered

**إعطاء عبر إعداد رمز مرشح glob إعادة ترتيب ترتيب، يأخذ الأكثر حار قسم مجموعة وضع قبل وجه.** هذا لا حاجة توليد جهاز أيضا لا حاجة جديد بوابة، يأخذ `util`،`core`،`llm`،`session` نقل إلى قبل وجه كبير نحو قدرة أخذ عودة واحد نصف استلام فائدة. مرفوض إدارة من: استلام فائدة مع حال حزمة زيادة بينما ضعف نقص، هذا عدد ترتيب لا يوجد أي قراءة من يمكن نواة تحقق ثابت كمية، بينما كما رقم واحد قسم مجموعة بعد كل واحد مجموعة ما زال يلزم دفع مال. هو أيضا إبقاء الأكثر سيئ صفة جودة——إضافة جديدة واحد حزمة قسم مجموعة سوف صامت صامت سحب بطيء كل شخص بدء.

**يأخذ `paths` نقل دخول واحد توليد `tsconfig.paths.json`، من base إعداد `extends`.** هذا قدرة يأخذ توليد محتوى تام قاع نقل خروج يد كتابة ملف،diff أيضا أكثر جاف صاف. هذا مرة مرفوض إدارة من هو: لديه إذا جاف إزالة استهلاك من**مباشر قراءة** `tsconfig.base.json`، بينما لا هو عبر سوف تتبع مع `extends` محلل——ستة عدد Vitest إعداد، خارج إضافة `project-reference-faces.ts`،`verify-export-jsdoc.ts`،`doc-typecheck.ts`،`rescope-vendor.ts`——تدريجي عدد مراجعة حساب هو جمع مقارنة هذا مرة آخر اسم تعديل صنع ذاته أيضا كبير. علامة منطقة مجال استخدام صفر إزالة استهلاك من ريح خطر بلوغ صار نفس مثال عزل.

**في صريح آخر اسم تحت جهة إبقاء عبر إعداد رمز بصفة التقاط قاع.** صريح آخر اسم هذا قدوم حينئذ أولوية في عبر إعداد رمز، لذلك صحيح تأكيد صفة ثابت، بينما كما إضافة جديدة حزمة نسيان إعادة توليد أيضا ما زال قدرة تحليل. مرفوض إدارة من: التقاط قاع تماما تماما هو يجعل قديم قديم إعداد خفي شكل سبب——مستودع قيام ساحة هو «misconfiguration fails loud» ، بينما `--check` بوابة يأخذ ناقص آخر اسم تغيير صار مرة أداة اسم فشل، بينما لا هو مرة لا شخص عودة بسبب بطيء بدء.

## Consequences

`headless` profile شفرة المصدر بدء من 2,157 / 2,182 / 2,153 ms أساس خط خفض إلى 1,069 / 1,052 / 1,055 ms——نحو **1.1 ثانية،51%**، اثنان عدد منطقة بين متبادل مسافة أقصى بعيد، كما `--help` إخراج تدريجي بايت متسق.

**استلام فائدة فقط حد في tsx شفرة المصدر بدء هذا واحد بند مسار.** Vitest مشي `vite-tsconfig-paths`، هو في عملية داخل فعل مطابقة و ملف وجود فحص، من لا بنية صنع Node وحدة خطأ، لذلك من لم دفع مرور ذلك قلم تركيب زينة بديل قيمة: مقابل بعض عدد حزمة كامل طقم حالة استخدام فعل A/B، فعلي قياس 5,934 / 5,829 / 5,908 ms مقابل 5,878 / 5,851 / 5,905 ms، يخص ضجيج صوت. مستودع بوابة نص برمجي فقط import قليل عدد بضعة عدد `@deepseek-ai/dsh-*` حزمة، نفس مثال قياس لا خروج يمكن قسم مغادرة فرق مختلف. إصدار مستخدم في عار Node تحت ركض بناء جيد `lib/`، هذا قدوم حينئذ لا تلقي أثر.

`paths` من 188 عدد key زيادة طويل إلى 523 عدد، إضافة جديدة حزمة وقت يجب تشغيل توليد جهاز.`--check` بوابة يأخذ هذا عنصر أمر تغيير صار مرة أداة اسم فشل بينما غير ساكن صامت فشل، بينما توليد منطقة مجال يجعل هذا صنف تعديل diff فقط لديه واحد سطر.
