# Agent Note: عبر مسار تحرير رمز فرعي دليل مقابل Agent Note إجراء تصنيف

Status: implemented
Archived: 2026-09-04

[English](2026-06-20-agent-note-classification.md) | العربية

## مشكلة

فقط حسب دورة الحياة مجموعة نسج Agent Note دليل شجرة (`proposed/` / `implemented/` / `rejected/`) لا يمكن سجل كل ملف يتضمن أي واحد*صنف*قرار. قراءة من تصفح تصفح بعض عدد دورة الحياة وقت، إذا لا تدريجي واحد فتح ملف، حينئذ لا يمكن منطقة قسم جديد وظيفة، إزالة بند أو أداة سياسة تغيير.

هذا مستودع واحد اختراق ميل نحو هو[آلة آلة جودة كمية بوابة أفضل في سطر نص مواصفة](2026-06-11-quality-gates.zh.md): لا يتم آلة جهاز فحص اتفاق نهاية سوف فاسد تالف. لذلك هذا داخل تصنيف خطة يجب يمكن قوي صنع تنفيذ، بينما غير اعتماد ذاتي شعور ملف رأس.

## قرار

زيادة ثاني عدد صيانة درجة، أي Agent Note **صنف آخر**، و سوف ذلك تحرير رمز في مسار في:`{lifecycle}/{class}/yyyy-mm-dd-topic.md`. ملف مشبك*حينئذ هو*وسم. ملف موضع إعلان ذلك صنف آخر؛ غلاف إغلاق تجميع دمج حد تحديد لـ «هذه ملف مشبك كما فقط حد هذه» ؛ قائم [verify-md-links](2026-06-18-markdown-cross-link-lint.zh.md) بوابة قد حفظ حماية نقل حركة ملف الذي يحتاج مسار تعديل كتابة.

### ستة عدد صنف آخر غلاف إغلاق تجميع دمج

| صنف آخر | شمول غطاء نطاق |
|---|---|
| `feature` | موجه إلى مستخدم أو نموذج جديد وظيفة. |
| `bug-fix` | إصلاح صحيح نقص وقوع أو ملء تكملة أمر لذا تكرار قرص (postmortem) كشف فارغ أبيض. |
| `simplification` | إزالة شفرة، سلوك أو مقابل خارج واجهة نطاق، لا جذب دخول جديد وظيفة. |
| `architecture` | صلة في**تسليم شفرة المصدر**بنية صفة قرار——حزمة بين علاقة، وقت التشغيل مفردات. |
| `process` | **محيط التفاف**شفرة أداة، سياسة أو سير العمل، بينما غير وقت التشغيل سلوك. |
| `testing` | اختبار أساس أساس ضبط تطبيق و سياسة. |

`architecture` و `process` قسم حد هو:**architecture** صلة نحو أنا جمع تسليم شفرة المصدر؛**process** صلة نحو شفرة المصدر دورة حافة أداة و سير العمل. هذا Agent Note ذاته يخص `process` قرار: هو تغيير مستودع مجموعة نسج طريقة و بوابة، بينما لا هو harness وقت التشغيل سلوك، لذلك يقع في `implemented/process/` تحت.

### اثنان طريق بوابة

اثنان من كل هو `doc-sync`(وثيقة تزامن بوابة) عضو، ريح إطار و `verify-md-wrap` متسق (tsx ESM، فقط تحقق لا توليد، أول عدد مخالفة قاعدة أي بـ غير صفر خروج رمز خروج):

- **`scripts/verify-agent-note-classification.ts`**: تعريف غلاف إغلاق دورة الحياة و صنف آخر تجميع دمج. هو تأكيد دورة الحياة ملف مشبك تحت كل ملف كل يقع في مواصفة تجميع دمج في صنف آخر ملف مشبك داخل (دورة الحياة أصل دليل تحت تفرق سقوط `.md` أو لم معرفة صنف آخر ملف مشبك كل سوف فشل) ، و رفض تجميع في صيغة `INDEX.md`. مواصفة تجميع دمج يقع في `scripts/agent-note-tree.ts` في،[README](../../README.zh.md) فإن بـ سطر نص سجل كل صنف آخر.
- **`scripts/verify-doc-refs.ts`**: فحص مرجع وثيقة شفرة المصدر ملاحظة تفسير.Agent Note مسار لا فقط ظهور في Markdown في، أيضا ظهور في TypeScript وثيقة ملاحظة تفسير في (مثال مثل بـ مستودع أصل لـ بدء نقطة `.agents/notes/implemented/testing/2026-06-19-acp-snapshot-tests.md`).`verify-md-links` نظر لا إلى هذه مرجع، لذلك دليل إعادة مجموعة ممكن ساكن صامت إبقاء تحت بطلان مرجع. هذا بوابة مسح `packages/**` تحت مستودع ذاتي لديه `.ts` ملف (ترتيب حذف قد بناء `lib/` و `vendor/`) ، فحص بحث `docs/….md` و `.agents/notes/….md` token، تحليل كل بـ مستودع أصل لـ بدء نقطة مسار و تأكيد ذلك وجود. هو اشتراط استخدام `.md` توسيع اسم، لذلك سوف تجاهل اختصار سطر نص في لا حمل توسيع اسم مرجع.

## سبق اعتبار بديل خطة

- **في كل ملف في إضافة `Classification:` نص سطر**(ضيق مجاور `Status:`) ، من بوابة تحليل. يمكن سطر، لكن هو سوف مسار قد قدرة تحمل تحميل واقع تكرار إلى ملف في، كما سطر محتوى ممكن و الذي في ملف مشبك لا متسق. مسار تحرير رمز جعل وسم و ذلك تخزين دمج اثنان لـ واحد، لا يوجد حاجة إبقاء تزامن شرق غرب.
- **ضبط قيام `refactor` صنف آخر.** و `simplification` بضعة نحو تماما إعادة تراكم؛ وحيد لديه شخص تجربة رسم استخدام قدوم منطقة قسم معيار هو «يمكن مراقبة سلوك هل تغيير؟» ، بينما `simplification` قد تحرير رمز هذا واحد نقطة (هو لا تغيير). واحد صنف آخر يكفي، بلا حاجة اثنان عدد.
- **توليد أو يد عمل صيانة وثيقة تجميع بحث جذب.** غير مقبول: دورة الحياة/صنف آخر دليل شجرة عندئذ هو مرجعي بنية؛ تجميع في صيغة بيان سوف صنع صنع دمج حار نقطة، لكن لا يوجد توفير دليل شجرة تنقل أو مستودع بحث لا يمكن تنفيذ اكتشاف قدرة.

## عاقبة

- كل نسخة Agent Note كل يقع في واحد صنف آخر ملف مشبك تحت. قراءة من تصفح تصفح مفرد عدد ملف مشبك، يكفي فحص نظر بعض عدد دورة الحياة داخل الكل بسيط تحويل أو اختبار قرار.
- `doc-sync` سلسلة في كثير اثنان عدد سريع سرعة tsx نص برمجي؛ بلا جديد اعتماد (mdast/GFM مكدس قد بسبب `verify-md-wrap`/`verify-md-links` بينما وجود).
- إضافة جديدة صنف آخر يجب هو صريح قرار: تعديل `scripts/agent-note-tree.ts` في `const` و [Classification فصل عقدة](../../README.zh.md#classification) ، بينما لا هو فقط استخدام `mkdir` إنشاء ملف مشبك. بوابة سوف رفض لم معرفة ملف مشبك، لذلك مؤقت صنف آخر لا يمكن صامت لكن خلط دخول.
- شفرة المصدر ملاحظة تفسير في وثيقة مرجع نفس مثال تلقي بوابة قيد: يتم `.ts` ملاحظة تفسير مرجع وثيقة واحد حالما نقل حركة أو إعادة تسمية،`doc-sync` و CI في `verify-doc-refs` حينئذ سوف فشل، من بينما سد إقامة `verify-md-links` في بنية فوق لا يمكن اكتشاف واحد صنف عائم نقل.
