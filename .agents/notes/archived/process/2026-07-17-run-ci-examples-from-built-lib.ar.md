# Agent Note: في CI في من بناء بعد lib تشغيل عرض مثال

Status: implemented
Archived: 2026-07-27

[English](2026-07-17-run-ci-examples-from-built-lib.md) | العربية

## مشكلة

CI عبر `node --import tsx` و أصل tsconfig `paths` خريطة بدء عرض مثال و تحميل Cordis إعداد اختبار مشروع. هذا نوع طريقة حيث زيادة TypeScript تحويل فتح إلغاء، أيضا تغيير حزمة تحليل سلوك:import سوف تحليل إلى workspace شفرة المصدر، بينما لا هو مرور حزمة `exports` دخول بناء بعد `lib/`.

لذلك، هذه اختبار لا يوجد تغطية قد تثبيت مستهلك فعلي تشغيل شفرة و تحليل مسار. أي جعل حزمة بناء توجيه خروج رسم لا كامل أو تحليل نتيجة مختلف،CI ما زال ممكن عبر.

## قرار

تنفيذ آلية يتضمن اثنان نوع نمط.`src` هو محلي تطوير افتراضي نمط و استخدام tsx؛`lib` هو صارم إطار CI نمط، عبر plain Node بدء بناء بعد bin، لا تحميل tsx، أيضا لا استخدام tsconfig مسار خريطة.

- CI في بدء عرض مثال أو توقيع دخول مستودع `cordis.yml` عملية فرعية استخدام `lib` نمط.
- فقط تنفيذ ACP أو MCP مقابل طرف، كما لا تحميل Cordis TypeScript fixture(اختبار قبل وضع بيانات) مباشر من Node تشغيل. فقط لديه صريح تحقق شفرة المصدر مسار ارتداد اختبار يمكن إبقاء `src` نمط.

### تحليل توسيع اندفاع

كل اختبار Cordis إعداد كل يجب قدرة من ملف إعداد الذي في دليل نحو فوق تحليل عار وحدة.

- `examples/` بصفة واحد pnpm workspace عضو، توفير موحد واحد `examples/node_modules` تحليل أصل دليل.
- كل توقيع دخول مستودع اختبار Cordis إعداد، يشمل لقطة إعداد و حزمة داخل اختبار fixture، كل وضع في مقابل `examples/<agent>/` دليل شجرة تحت. ملكية `packages/<group>/<package>/` إعداد خريطة إلى `examples/<agent>/tests/fixtures/<group>/<package>/cordis.yml`؛ اختبار قيادة و تأكيد ما زال إبقاء في حزمة داخل.
- عرض مثال Cordis إعداد في مرجع كل حزمة كل معا تسجيل تسجيل في `examples/package.json` و أصل `tsconfig.json` references في، قسم آخر دعم حمل `lib` و `src` تحليل.

### بدء سياسة

مشترك Loader اختبار harness عبر `DSH_EXAMPLE_MODE` اختيار `src` أو `lib`.CI أولا بناء مجددا اختيار `lib`؛ لم ضبط نمط وقت إبقاء سريع سرعة محلي شفرة المصدر تطوير عودة مسار.

## سبق اعتبار بديل خطة

- **CI متابعة استخدام tsx**: غير مقبول، لأن هو سوف إبقاء تحويل فتح إلغاء و فقط ملائم لأجل شفرة المصدر تحليل سلوك.
- **كل بيئة فقط استخدام lib**: غير مقبول، لأن محلي تطوير كل مرة تشغيل قبل كل يجب بناء. مزدوج نمط تجنب تجنب يأخذ هذا بند صار هذا حمل دخول تطوير عودة مسار.
- **كل اختبار مفرد وحيد بنية صنع `node_modules`**: غير مقبول، لأن هو سوف تكرار مستهلك قدم يد هيكل. بـ `examples/` بصفة workspace أصل، يمكن يجعل كل Cordis إعداد عبر نفس بند حقيقي كما صريح إعلان مسار تحليل وحدة.

## عاقبة

- CI يمكن تحقق بناء بعد حزمة توجيه خروج، لم يعد تلقي tsx وحدة تحليل أثر؛ محلي تطوير ما زال إبقاء تجنب بناء شفرة المصدر عودة مسار.
- CI يجب أولا بناء مجددا تشغيل هذه اختبار؛ يد حركة تنفيذ `lib` نمط وقت ممكن قراءة قديم قديم محلي ناتج.
- معتاد قاعدة TypeScript import قسم تحليل لا يمكن تعرف آخر Cordis إعداد اعتماد، لذلك `examples/package.json`، أصل tsconfig references و ملف إعداد يجب إبقاء تزامن.
