# Agent Notes

[English](README.md) | العربية

هذا داخل تخزين وضع واحد صنف تصميم وثيقة.**Agent Note** سجل أثر هذا شفرة مكتبة قرار أو رفع سجل: شفرة و وثيقة لا يمكن تحمل تحميل*لـ ماذا*و*وضع ترك ماذا*. هذا ملف قاعدة تحديد Agent Note تخزين وضع في أي داخل، أي وقت حاجة كتابة واحد نسخة، و[ملف داخل صيغة](#the-file-format).

## تخطيط و تسمية

كل نسخة Agent Note لديه اثنان عدد صيانة درجة، كل تحرير رمز في ذلك**مسار**في:`{lifecycle}/{class}/yyyy-mm-dd-topic-title.md`.

- **دورة الحياة**(قمة طبقة ملف مشبك) هو Agent Note حالة،Agent Note مع حالة تغير في ملف مشبك بين نقل حركة:
  - **`proposed/`**: فعلي تطبيق قبل مراجعة رفع سجل؛ بعد لم بناء (أو فقط جزء بناء).
  - **`implemented/`**: قرار قد تسليم. ملف سجل فعل ماذا قرار، مرفوض ماذا، و**و فعلي تسليم محتوى إبقاء تزامن**: عند شفرة لاحق نقل حركة ملف، إعادة تسمية حزمة أو أكثر تعديل مفتاح اسم/قيمة افتراضية وقت،Agent Note في نفس عدد تغيير في تزامن تحديث (فقط حد واقع——مسار، اسم، بنية——بينما غير قرار ذاته). رؤية [implemented/AGENTS.md](implemented/AGENTS.md).
  - **`rejected/`**: رفع سجل مرور مرور نقاش نقاش بعد يتم مرفوض. فقط عند ذلك قرار اعتماد حسب ما زال قدرة تجنب تجنب واحد نوع إغراء شخص كما أثر إعادة كبير خطأ وقت إبقاء؛ لا فإن حذف كامل إنجليزي نص، العربية و مرافق مع سجل ثلاثة ملف مجموعة.
- **صنف آخر**(تضمين طقم ملف مشبك) هو قرار*نوع صنف*——رؤية تحت جهة[تصنيف](#classification).

ملف اسم في يوم مدة هو هذا رئيسي عنوان**أول مرة رفع خروج**وقت (بـ git تاريخ لـ دقيق).Agent Note بين تسليم تقاطع مرجع استخدام متبادل مقابل Markdown رابط (`[topic](../../implemented/architecture/2026-…-….md)`) ، من لا استخدام صاف نص حرف أو تحرير رقم، هذا مثال حيث يمكن آلة آلة فحص، أيضا قدرة في ملف مشبك بين نقل حركة وقت إبقاء صالح.

نشط وثب دورة الحياة دليل شجرة حينئذ هو عمل بيان: تصفح تصفح ذلك دورة الحياة/صنف آخر ملف مشبك، أو بحث مستودع يكفي. طلب لا إضافة تجميع في صيغة `INDEX.md`؛ تصميم إدارة من رؤية[لا ضبط بحث جذب Agent Note](implemented/process/2026-07-19-remove-generated-agent-note-index.zh.md). لم قدوم إشارة توجيه قيمة قيمة مقارنة منخفض قد فعلي تطبيق سجل سوف نقل حتى تحت نص الذي وصف، مفرد وحيد تجميد ربط [`archived/`](archived/AGENTS.md) دليل شجرة.

## تصنيف

كل نسخة Agent Note يخص `scripts/agent-note-tree.ts` في غلاف إغلاق تجميع دمج داخل واحد مسار تحرير رمز صنف آخر؛ تصنيف بوابة رفض أخرى ملف مشبك. إضافة جديدة صنف آخر حاجة معا تحديث مواصفة تجميع دمج و هذا عقدة.

| صنف آخر | تغطية نطاق |
|---|---|
| `feature` | موجه إلى مستخدم أو نموذج جديد قدرة. |
| `bug-fix` | إصلاح صحيح نقص وقوع أو سد تكملة أمر لذا تكرار قرص (postmortem) اكتشاف نقص فتحة. |
| `simplification` | في لا زيادة قدرة قبل رفع تحت إزالة شفرة، سلوك أو مقابل خارج نطاق. |
| `architecture` | صلة في**تسليم شفرة المصدر**بنية صفة قرار: حزمة بين علاقة، وقت التشغيل مفردات. |
| `process` | شفرة**دورة حافة**أداة، سياسة أو سير العمل——بوابة، حزمة إدارة جهاز،vendor تحويل——لا تعلق و وقت التشغيل سلوك. |
| `testing` | اختبار أساس أساس ضبط تطبيق و سياسة. |

`architecture` و `process` حد خط:**architecture** صلة نحو أنا جمع تسليم شفرة المصدر؛**process** صلة نحو محيط التفاف شفرة المصدر أداة و سير العمل.(`refactor` يتم متعمد ترتيب حذف: هو و `simplification` إعادة تراكم، بينما بعد من حكم آخر معيار «يمكن مراقبة سلوك هل تغيير» قد تغطية هو.)

## عودة ملف و حذف

عند واحد نسخة implemented Agent Note سجل تسليم قرار قد كامل سقوط أرض، كما ذلك قرار اعتماد حسب لا جدا ممكن مجددا إشارة توجيه لم قدوم عمل وقت، سوف ذلك عودة ملف. إذا منها تجهيز اختيار خطة، ملكية حد، لا تحديد صفة حفظ إثبات، حفظ دائم دلالة أو بروتوكول دلالة، أمان قاعدة، أو من إعادة جذب دخول شرط ما زال لديه قيمة قيمة، فإن متابعة بصفة نشط وثب سجل إبقاء. أبدا عودة ملف proposed Agent Note: مرور وقت رفع سجل ينبغي تحويل لـ rejected. فقط عند rejected Agent Note ما زال قدرة تجنب تجنب واحد نوع ممكن حدوث خطأ وقت إبقاء؛ لا فإن واحد و حذف ذلك إنجليزي نص، العربية و مرافق مع سجل ملف. طلب استخدام مرور مرور تدقيق دقيق [`dsh-archive-agent-notes`](../skills/dsh-archive-agent-notes/SKILL.md) سير العمل، لا يلزم أصل حسب حرف عدد، تخزين متابعة وقت أو هدف إعداد مقدار قدوم حكم قطع.

عودة ملف مسار تحرير رمز لـ `archived/{class}/yyyy-mm-dd-topic-title.md`؛ منها متعمد حذف `implemented`، لأن فقط لديه implemented Agent Note يمكن دخول عودة ملف. عودة ملف تغيير سوف نقل حركة كامل إنجليزي نص، العربية و مرافق مع سجل ثلاثة عدد ملف، إبقاء `Status: implemented`، في اثنان نوع لغة ملف في ضيق وصل هذا حالة سطر إدراج دخول نفسه `Archived: YYYY-MM-DD` سطر، إعادة سجل مرافق مع سجل، و إصلاح أو حذف دخول محطة رابط. عودة ملف وقت فقط سماح مقابل محتوى فعل هذه أكثر تعديل.

غلاف تخزين بعد، كل مجموعة عودة ملف ملف كل دائم دائم تجميد ربط. منع توقف تحرير، قلب ترجمة، إعادة صيغة تحويل، تحديث، نقل حركة أو حذف، أيضا لا نيل سوف ذلك نظر لـ حالي سلوك مرجعي اعتماد حسب. وثيقة بوابة سوف قفز مرور عودة ملف مصدر ملف، يشمل منها خروج محطة رابط؛ عند نشط وثب وثيقة متعمد مرجع تاريخ وقت، ما زال يمكن رابط إلى عودة ملف Agent Note.[`verify-archived-agent-notes`](../../scripts/verify-archived-agent-notes.ts) قوي صنع تنفيذ غلاف إغلاق صنف آخر دليل شجرة، كامل ثلاثة ملف إعداد مقابل، عودة ملف بيانات وصفية، مرافق مع سجل hash، و فقط إلحاق تجميد ربط محتوى manifest(بيانات وصفية بيان).[عودة ملف سياسة سياسة Agent Note](implemented/process/2026-07-26-frozen-agent-note-archive.zh.md) سجل تصميم اعتماد حسب.

## أي وقت حاجة كتابة واحد نسخة

فقط لديه شفرة، اختبار و قائم وثيقة لم قدرة حل تفسير قرار إدارة من أداة لديه طويل مدة قيمة قيمة وقت، عندئذ في نفس PR(Pull Request) في إضافة جديدة أو تحديث Agent Note. مقابل لم قدوم إعادة كبير عمل رفع سجل من `proposed/` بدء؛ قد فعل خروج قرار من `implemented/` بدء. اختيار و قرار مطابقة صنف آخر ملف مشبك (رؤية[تصنيف](#classification)).

تحديث قد يملك هذا قرار Agent Note يكفي ممتلئ كاف قاعدة؛ لا يلزم إنشاء تكرار سجل. آلة آلة صفة أو نطاق جزء تحرير متساو يمكن إعفاء تجنب، يشمل نطاق جزء UI عرض و تفاعل ضبط كامل.Agent Note دائم بعيد لن يتم تحرير لـ واحد*مختلف قرار*: استخدام جديد Agent Note يحل محل قديم سجل، و يجعل اثنان عدد سجل إبقاء متبادل متبادل رابط، حذف غير لاحق اعتماد حسب تحت جهة قاعدة تماما دمج قديم سجل. تحرير `implemented/` Agent Note بـ تتبع أثر ذلك قائم قرار الذي في موضع هو مطلوب، بينما غير منع توقف؛ رؤية [implemented/AGENTS.md](implemented/AGENTS.md).

يتم تماما يحل محل implemented Agent Note يمكن دمج إلى حالي يحتفظ هذا قرار سجل في، و حذف أصل ملف. حذف قبل، حالي سجل يجب حفظ كل وحيد لديه قرار اعتماد حسب، تجهيز اختيار خطة، أثر، مطلوب تحقق و واضح إشارة خروج تغطية نقص فتحة؛ إصلاح كل دخول محطة رابط؛ و في نفس تغيير في حذف العربية مقابل جانب ملف و متسق صفة سجل. فقط جزء يتم يحل محل سجل لا رمز دمج هذا شرط: إبقاء اثنان عدد سجل و يجعل هو جمع متبادل متبادل رابط، معا تحديث كل ما زال ملائم استخدام واقع. دمج لا نيل سوف قديم ملف تعديل كتابة صار و ذلك متبادل عكس قرار، أيضا لا نيل يجعل git تاريخ يصبح قرار اعتماد حسب وحيد فرعي هذا.

فقط لديه عند واحد بند وظيفة قد من إنتاج شفرة، إعداد،schema، حفظ دائم صيغة أو بروتوكول صيغة، ترحيل و توافق سلوك في تماما إزالة فقد، حالي وثيقة لم يعد سوف ذلك وصف لـ متاح، كما لا يوجد اختبار يأخذ هو بصفة تلقي دعم حمل سلوك قدوم تنفيذ وقت، إضافة جديدة هذا وظيفة Agent Note عندئذ يمكن دمج دخول لاحق إزالة سجل. إزالة قرار اعتماد حسب و تحقق هذا وظيفة قد لا وجود اختبار يمكن إبقاء. إزالة قرار يحتفظ سجل يجب إبقاء الأكثر أول حركة آلة، لـ ماذا هذا حركة آلة قد لا كاف بـ إثبات إبقاء هذا وظيفة دمج إدارة صفة، تماما إزالة خارج تجهيز اختيار خطة، وضع ترك قدرة، إعادة جذب دخول شرط، و إثبات قد تام قاع إزالة تحقق. مرور وقت تنفيذ بيان و فقط تحقق قد حذف سلوك اختبار لا يخص حالي تحقق دليل. فقط إزالة واحد نوع نقل، قيمة افتراضية، تنفيذ أو عرض يخص جزء يحل محل؛ ما زال لديه أي حمل دائم بيانات أو توافق معالجة أيضا نفس مثال مثل هذا.

## ملف صيغة

كل نسخة نشط وثب Agent Note التزام دوران موحد واحد ملف داخل صيغة، من `pnpm run verify-agent-note-format`([scripts/verify-agent-note-format.ts](../../scripts/verify-agent-note-format.ts) ،`doc-sync`(وثيقة تزامن بوابة) واحد حلقة) قوي صنع تنفيذ؛ هذا صيغة تصميم حركة آلة و ذلك مرفوض بديل خطة رؤية[موحد واحد صيغة Agent Note](implemented/process/2026-07-05-uniform-agent-note-format.zh.md). عودة ملف سجل إبقاء غلاف تخزين وقت صيغة، و زيادة فوق وصف عودة ملف يوم مدة سطر.

### رأس جزء كتلة

كل نسخة Agent Note قبل ثلاثة سطر صارم إطار لـ:

```markdown
# Agent Note: <title>

Status: <status>
```

بعد تتبع واحد فارغ سطر.`Status:` قيمة لديه ثلاثة نوع شكل صيغة، كما يجب و ملف الذي في دورة الحياة ملف مشبك متسق——بوابة سوف تسليم تقاطع فحص:

- `Status: proposed`
- `Status: implemented`
- `Status: rejected — <why, in one line>`

حالة سطر لا حمل يوم مدة، لا حمل تضمين رقم تكملة ملء شرح: ملف اسم سجل أول مرة رفع خروج يوم مدة،git سجل ذلك بقية واحد قطع؛ «بـ إصلاح حجز شكل صيغة قبول» لـ صنف شرح يخص متن محتوى (في قديم وصف قرار أرض جهة شرح إصلاح حجز). رفض سبب هو وحيد حمل محتوى حالة، لأن قراءة من فحص قراءة يتم مرفوض Agent Note وقت، ربط نقاش صحيح هو هو جمع يلزم بحث.

### متن هيكل هيكل

كل نسخة Agent Note متن بـ `## Problem` فتح رأس: حركة آلة، كتابة قاعدة فوق لا اعتماد حل قرار خطة يكفي مستقل صار نص. لاحق محتوى أخذ قرار في دورة الحياة؛ ثابت فصل عقدة استخدام التالي مواصفة اسم كما فقط حد هذه اسم، بينما حق صحيح وحيد خاص تقنية فن فصل عقدة (حزمة توسيع اندفاع، بروتوكول اتفاق،schema انتظار) في مطلوب فصل عقدة بين يمكن ذاتي من مجموعة نسج.

#### `proposed/`

```markdown
## Problem
## Proposal
…bespoke sections…
## Alternatives considered
## Acceptance criteria
## Risks
```

`## Proposal` وصف محاكاة اقتراح تغيير، يمكن دمج إدارة أرض استخدام سوف قدوم وقت حالة——حساب تخطيط، ترحيل خطوة و انتظار حل قرار مشكلة في عمل بعد لم إتمام وقت يخص هذا موضع.`## Acceptance criteria` شرح ماذا يمكن مراقبة حالة معنى طعم حال إتمام.`## Risks` شمول غطاء ممكن خروج خطأ أمر بند و هذا تغيير متعمد وضع ترك شرق غرب.

#### `implemented/`

```markdown
## Problem
## Decision
…bespoke sections…
## Alternatives considered
## Consequences
```

`## Decision` بـ الآن وقت حالة وصف قد تسليم الآن فعلي، كامل ملف حسب [implemented/AGENTS.md](implemented/AGENTS.md) اشتراط و لـ إبقاء تزامن.`## Consequences` سجل حق توازن بديل قيمة**و**استلام فائدة. رفع سجل مرحلة مقطع عنوان في هذا يخص قاعدة إطار استخدام لغة، بوابة سوف رفض هو جمع:`## Proposal`،`## Plan`،`## Migration plan` و `## Acceptance criteria` لا نيل ظهور في implemented Agent Note في (سبب رؤية [slop فحص بيان](../../docs/AGENTS.md)).`## Testing`،`## Deferred` أو `## Related` فصل عقدة في قديم وصف الآن وقت حالة واقع وقت هو سماح.

#### `rejected/`

يتم مرفوض Agent Note هو تجميد ربط رفع سجل: إبقاء رفع سجل وقت كل فصل عقدة (يشمل `## Acceptance criteria` أو `## Plan`) ، ربط نقاش كتابة في `Status:` سطر فوق. فقط رأس جزء كتلة،`## Problem` فتح رأس،`## Proposal` فصل عقدة و تحت جهة «سبق اعتبار بديل خطة» قوي صنع اشتراط ملائم استخدام.

### سبق اعتبار بديل خطة——مطلوب

كل نسخة Agent Note كل يجب يتضمن `## Alternatives considered` فصل عقدة: كل حقيقي بديل خطة و ذلك سقوط اختيار سبب، كل بديل خطة استخدام واحد إضافة خشن جذب توجيه مقطع سقوط، أو مقابل تنازع اقتراح مقارنة كبير بديل خطة استخدام `### Why not <X>?` فرعي عقدة. سجل قرار وقت لا سجل هو ضرب فشل ماذا، حينئذ هو في دعوة طلب عكس تكرار تنازع نقاش——هذا صحيح هو Agent Note غاية في منع توقف مشكلة.

بديل خطة هو سجل تحت قدوم، لا هو سند فارغ تحرير صنع. يوم مدة مبكر في 2026-07-05 كما بديل خطة لا يمكن من سجل في إعادة بناء Agent Note، استخدام التالي دقيق ملاحظة تفسير بديل بديل هذا فصل عقدة، بوابة فقط مقابل صيغة مواصفة قبل ملف قبول هذا ملاحظة تفسير:

```markdown
<!-- agent-note-format: alternatives-not-recorded (pre-format Agent Note) -->
```

### في دورة الحياة بين نقل حركة

سوف ملف في دورة الحياة ملف مشبك بين نقل حركة معنى طعم حال في نفس عدد تغيير في تحديث `Status:` سطر و ممتلئ كاف هدف ملف مشبك هيكل هيكل اشتراط——لا فإن بوابة سوف فشل. أداة جسم بينما قول،`proposed/` → `implemented/` سوف `## Proposal` تعديل كتابة لـ الآن وقت حالة `## Decision`، سوف `## Acceptance criteria` و `## Risks` طي دخول `## Consequences`(أو طي دخول واحد الآن وقت حالة `## Testing`/`## Verification` فصل عقدة، لأجل وصف الآن قفل تحديد هذا سلوك محتوى) ، و استخدام فعلي تسليم محتوى استبدال حساب تخطيط——أيضا حينئذ هو سوف [implemented/AGENTS.md](implemented/AGENTS.md) الذي اشتراط تعديل كتابة تغيير صار يمكن آلة آلة فحص قاعدة.`proposed/` → `rejected/` فقط في `Status:` سطر إضافة سبب و تجميد ربط ملف.

### العربية مقابل جانب ملف

`.zh.md` مقابل جانب ملف حسب [i18n اتفاق](../../docs/i18n/README.zh.md) تدريجي فصل عقدة و ذلك إنجليزي نص مقابل جانب ملف إبقاء نفسه بنية؛ آلة جهاز فحص رأس جزء علامة (`# Agent Note: ` و `Status:` سطر) إبقاء إنجليزي نص أصل مثال لا قلب ترجمة. صيغة بوابة قفز مرور `.zh.md` ملف؛ إعداد مقابل بوابة فحص هو جمع متسق صفة.
