# Agent Note: فقط إعادة استخدام حلقة قد إثبات رسالة تجميد ربط

Status: implemented

[English](2026-09-06-agent-request-freeze-evidence.md) | العربية

## مشكلة

طويل أداة محادثة في بنية صنع طلب وقت عكس تكرار مرة تاريخ غير ممكن تغيير تاريخ.[خلفية متابعة ركض أساس خط](../testing/2026-09-06-backend-continuation-performance.zh.md) في مرة 211.300 ms طلب تاريخ عملية في، سوف 132.876 ms أخذ مثال CPU ذاتي استهلاك وقت عودة بسبب في `buildRequest` `deepFreeze`. قفز مرور كل قد تجميد ربط أصل كائن و لا أمان: استعادة عملية سوف وصل إدارة مستقل يملك كائن رسم بينما لا تجميد ربط هو جمع، ضحل تجميد ربط رسالة ما زال ممكن يتضمن متغير محتوى.

## قرار

كل `ReactLoopAgent` يملك خاص WeakSet<Message>، منها فقط سجل هذا نسخة في كامل `deepFreeze` استدعاء نجاح كائن هوية. كل لم رؤية رسالة أولا أصل أرض عميق تجميد ربط، مجددا إضافة دخول تجميع دمج. لاحق طلب إعادة استخدام هذا إثبات. جديد حلقة سوف إعادة إثبات كل كائن؛ رسالة id متبادل انتظار لا يستطيع إثبات كائن هوية نفسه. ضعيف مرجع لن زيادة مقابل قد ضغط تاريخ كل حق.

حلقة كل مرة طلب كل عميق تجميد ربط مقارنة صغير محلي مواصفة تحويل header.`canonicalHeader` مشترك تضمين طقم قيمة،`Session.append` تجميد ربط هو مستقل لقطة: اثنان من كل لا يستطيع إثبات محلي tools أو `NO_ADAPTER` رجوع في stop عدد مجموعة غير ممكن تغيير. حلقة قسم آخر تجميد ربط جديد رسالة عدد مجموعة و طلب غلاف تركيب، إبقاء `markAgentLoopRequest`، و إبقاء فوري `AbortSignal` متغير. استعادة رسالة كائن هوية و ذلك خارج محيط حدث حزمة تركيب كائن متغير صفة إبقاء ثابت.

هذا قرار مخصص باب أفضل تحويل طلب بنية صنع، لا تغيير Session كل حق أو عام `deepFreeze` سلوك.`Session.deriveMessages` و `fromRestore` إبقاء ثابت.LLM(كبير لغة نموذج) ملف، رسم مثل و إعادة تشغيل إسقاط إبقاء كل منها تجميد ربط، لأن هو جمع جديد توليد قيمة لا يوجد حلقة محلي إثبات.[يمكن إعادة بناء طلب قرار](../architecture/2026-07-05-reconstructable-requests.zh.md) متابعة يملك يمكن مراقبة غير ممكن تغيير صفة و أساس في سجل طلب إعادة بناء قاعدة.

### معيار حمل إدارة CI تدقيق دقيق

معيار مزدوج CPU `ubuntu-24.04` اختبار عبر طريق تشغيل Node 24.20.0. تشغيل 34033336380، مهمة 101487280801 في Azure eastus فوق قياس كمية أفضل تحويل طلب مسار:183.355397, 184.468253, 185.042397, 182.160790, 182.924728 ms؛ في موضع عدد 183.355397 ms. كل مثال هذا كل إتمام نفسه 40 عدد طلب و 13,923 عدد حدث. في WeakSet تنفيذ و عمل سالب تحميل لم تغيير حال حال تحت، الكل خمسة عدد مثال هذا متساو تجاوز مرور تاريخ 175 ms ميزانية.

تحديد صفة مقابل وفق استدعاء حساب وقت مشهد استخدام `assertRequestHistoryBudget`. هو جمع قبول قد سجل 185.042397 ms الأكثر كبير قيمة و اثنان مرة مقارنة بطيء حمل إدارة في موضع عدد، معا رفض من 308, 310, 312, 311, 309 ms إدخال نيل إلى دمج صار 310 ms في موضع عدد. مقارنة بطيء تشغيل جهاز قبول مقابل وفق في زيادة بقية كمية قبل تكرار الآن `265.796833 > 238`؛ كامل الذي تابع ملف في 297 ms تحت عبر 11 عدد اختبار. إعادة تشغيل قد سجل عدد قيمة تحقق هو تأكيد، بينما غير جديد حمل إدارة تشغيل. تاريخ دمج صار 250 ms مشهد و أصل إصدار M4 246.130875 ms قياس كمية رمز دمج هذا بقية كمية، لم يعد بصفة رفض مقابل وفق؛ أصل إصدار/أفضل تحويل إصدار M4 قياس كمية ما زال إبقاء لـ تجميد ربط تنفيذ استلام فائدة دليل.

## اعتبار مرور بديل خطة

**`Object.isFrozen` لـ حق وقت قيام أي إرجاع.** قد تجميد ربط أصل كائن لا يستطيع إثبات ذلك بعد بديل قد تجميد ربط. في مشترك مساعد مساعدة دالة في استخدام هذا سريع مسار سوف تقليل ضعيف كل استدعاء جهة، يشمل استعادة و إسقاط مسار.

**معلومة مهمة كل Session رسالة أو ذاكرة مؤقتة رسالة id.** استعادة واضح سماح يملك مستقل كل حق لم تجميد ربط بيانات؛ استبدال عملية يمكن إبقاء id، معا تغيير كائن هوية و محتوى. فقط لديه مقابل هذا دقيق كائن إتمام مرة تاريخ عندئذ قدرة إثبات طلب اشتراط.

**إبقاء قوي مرجع Set أو مشترك عام إثبات ذاكرة مؤقتة.** قوي مرجع سوف تأخير طويل قديم تاريخ دورة الحياة. عام ذاكرة مؤقتة سوف كل حق توسيع كبير إلى agent(ذكي جسم) خارج، مقابل نفس حلقة تكرار طلب و بلا لا بد يلزم.

**إزالة تحت تنقل إسقاط تجميد ربط.** إسقاط بعد ملف/رسم مثل/إعادة تشغيل رسالة هو يملك مستقل كل حق مختلف قيمة. أفضل تحويل هو جمع حاجة مستقل دليل، لا يستطيع من مواصفة تاريخ قد تجميد ربط دفع توجيه خروج قدوم.

## أثر

طلب بنية صنع ما زال مسح رسالة هوية و قسم إعداد جديد عدد مجموعة، لكن تجنب تجنب تمرير عودة مرة تاريخ قد إثبات تاريخ. كل حلقة كل لـ استعادة تاريخ دعم دفع مرة كامل مرة تاريخ صار هذا. محلي header ما زال هو كل مرة طلب صار هذا. رسالة قيمة، طلب علامة، أولا قبل طلب لقطة، إلغاء و SDK تسلسل تحويل إخراج إبقاء قائم سلوك.

[تجمع تركيز اختبار](../../../../packages/core/agent-loop/tests/request-freeze.spec.ts) تغطية أداة لديه متغير بعد بديل ضحل تجميد ربط استعادة أصل كائن، حزمة تركيب كائن هوية و متغير صفة، فقط نجاح مرة تاريخ إثبات، تكرار طلب، نفس id ضغط استبدال، جديد حلقة، تضمين طقم أداة schema، مهايئ و `NO_ADAPTER` stop عدد مجموعة، يحتفظ قديم طلب و فوري إلغاء. إعادة بناء و إلغاء اختبار تجميع تغطية متبادل مجاور حلقة دلالة. صفة قدرة قياس كمية اعتماد ثابت[متابعة ركض عمل سالب تحميل](../../../../benchmarks/agent-continuation/workload.ts) ، بينما غير تقليص صغير دمج صار دقيق أساس دقيق.

تحقق تشغيل 646 عدد agent loop و LLM اختبار،agent.ts لغة جملة، فرع، دالة و سطر نسبة التغطية متساو لـ 100%. بلا مفتاح TypeScript SDK bash-tool و multi-turn لقطة عبر إعادة بناء مكتبة تنفيذ و عبر.Python sdk-minimal و sdk-snapshot فحص استخدام مستقل تحزيم node24-macos-arm64 يمكن تنفيذ ملف و عبر. اثنان عدد SDK متساو بلا حاجة تعديل مدة نظر إخراج. تحزيم نشر مؤقت وقت إزالة مساحة العمل اعتماد رابط؛ تنفيذ تجميد ربط lockfile تثبيت يمكن في شفرة المصدر فحص قبل استعادة هو جمع، بلا حاجة تعديل تلقي إصدار إدارة اعتماد ملف.

الآن سطر غير ممكن تغيير صفة، رسالة هوية، يمكن مراقبة حالة آلة و خلفية أساس خط شرح ما زال كل منها أداة لديه قيمة قيمة؛ لا يوجد شرح يتم تماما يحل محل أو عودة ملف. هذا نص مخصص باب قاعدة تحديد طلب تجميد ربط آلية، و و يمكن إعادة بناء صفة الذي تابع شرح تسليم تقاطع رابط.
