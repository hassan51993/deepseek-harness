# Agent Note: إزالة E2B تنفيذ مزود

Status: implemented

[English](2026-09-11-remove-e2b-providers.md) | العربية

## مشكلة

E2B فعلي تحقق لـ ملف أداة،Bash،PTY و لغة خادم توفير واحد بعيد مسار نظام الملفات/عملية عالم حد، بينما Harness، اعتماد، نموذج نقل و جلسة حالة إبقاء في مضيف. ثلاثة عدد مزود إثبات، هذه مستهلك يمكن مشترك قائم نظام الملفات و عملية فرعية واجهة، بلا حاجة خاص تحديد في مزود أداة.

PTC Node قيد حاجة مستقل في مهمة معنى برنامج stdin/stdout/stderr مزدوج نحو تحكم عبر معلومة. ثابت إصدار `e2b@2.29.1` SDK توفير معيار عملية تدفق و PTY إخراج، لا يوجد مقدار خارج وصف رمز نقل. في VM في إنشاء وصف رمز لن جعل ذلك كشف إعطاء Harness مضيف؛ يجب عبر بعيد مسار في استمرار أو مستقل إقرار إثبات تدفق إجراء جسر وصل.

هذا مثال جسر وصل مسؤول إخراج منع سد وقت مستقل دفع دخول، محدود إبقاء، عبر طريق إغلاق، بدء إصدار، أمر هوية، إلغاء و قطع خط تنظيف. أي جعل مستهلك تطبيق إضافة عكس ضغط،SDK ما زال إبقاء كامل stdout/stderr، لذلك فقط حد تدفق درجة طابور صف لا يمكن قيد مضيف داخل تخزين. توسيع هذا واحد مهايئ سوف يأخذ فعلي تحقق تغيير صار مستقل بعيد مسار نقل مشروع.

## قرار

مستودع لا يتضمن E2B صندوق رملي كل من، نظام الملفات مزود و عملية فرعية مزود، أيضا لا يتضمن ذلك SDK اعتماد، تجميع صار fixture، اختياري سير العمل و توليد تسجيل بند. مستودع لا توفير E2B تنفيذ خلفية. إزالة استخدام وضع ترك هذا تجميع صار تبديل أخذ أكثر صغير صيانة نطاق؛ هذا لا معنى طعم حال E2B لا يمكن دعم حمل دمج ملائم نقل، أيضا لا معنى طعم حال قد إصدار حزمة لا يوجد خارجي مستخدم.

[يمكن نقل غرس تنفيذ عالم حد قرار](../architecture/2026-07-28-portable-execution-world-consumers.ar.md) متابعة مسؤول `ctx.fs` و `ctx.subprocess` اتفاق. اثنان من وصف نفس عدد مسار نطاق الأسماء و عملية عالم حد. مزود مسؤول مسار تحويل، يمكن تنفيذ ملف فحص بحث، عادي تدفق، طرفية قسم إعداد و تلقي إدارة تنظيف؛ مستهلك إبقاء أداة دلالة، سياسة و عرض.local/remote بيانات وصفية وسم لن لـ هذه عملية زيادة إذن اعتماد حسب.

بعيد مسار تنفيذ ما زال هو مسبق مدة قدرة. طرفية قسم إعداد، كتابة، قبل منصة فحص و إشارة إرسال إبقاء Promise اتفاق، و انتظار معالجة عملية إلغاء حفظ إثبات. محلي تنفيذ تزامن إتمام هذه استدعاء، لا كاف بـ دعم حمل إزالة بعيد مسار مزود الذي يحتاج مختلف خطوة سلوك. عملية إتمام، طرفية حينئذ خيط حكم قطع، نموذج محاكاة جهاز تحليل و تلقي إدارة نطاق توقف مستقر أيضا إبقاء قائم مسؤولية ملكية.

هذا قرار إزالة واحد مزود عائلة. هو حيث لا تغيير PTC تنفيذ، أيضا لا تغيير مشترك نظام الملفات، عملية فرعية و طرفية واجهة. مباشر Node قيد و برنامج توليد تحكم عبر معلومة تحقق حاجة كل منها تنفيذ و دليل.

## اعتبار مرور بديل خطة

**إبقاء E2B و رفض تحكم عبر طريق طلب.** هذا فقط يحتاج قليل كمية جديد نقل شفرة يكفي إبقاء قائم بعيد مسار وظيفة، لكن ما زال إبقاء SDK و بعيد مسار دورة الحياة صيانة مسؤولية مهمة، معا ترتيب حذف جديد تنفيذ قدرة. إزالة واضح جدول بلوغ هذا واحد صيانة أخذ ترك.

**عبر E2B معيار تدفق كثير مسار إعادة استخدام عبر طريق.** في استمرار يمكن مقابل stdin/control إدخال و stdout/stderr/control إخراج قسم لقطة. هو أيضا حاجة تدريجي عبر طريق تدفق كمية تحكم و إغلاق، محدود طابور صف، و تراكم حساب SDK إخراج إبقاء حل قرار خطة. هذه هو بعيد مسار نقل دلالة، لا هو وصف رمز وصل خط.

**استخدام مستقل إقرار إثبات تدفق.** هذا يمكن تجنب فتح SDK إبقاء إخراج مسار، و يجعل تحكم عبر معلومة مستقل دفع دخول. هو زيادة طرف نقطة وصول، إقرار إثبات، شبكة سياسة، بدء تنسيق ضبط و اتصال فشل تنظيف. هذا مرة إزالة لا جذب دخول هذا نقل.

**يأخذ طرفية عملية تعديل لـ تزامن.** هذا يمكن بسيط تحويل محلي حزمة تركيب، لكن سوف إزالة بعيد مسار مزود حاجة تأخير متأخر عملية سلوك. مشترك مختلف خطوة واجهة و ذلك إلغاء/ترتيب اختبار في لا يوجد E2B وقت ما زال لديه استخدام.

## عاقبة

اعتماد مستودع E2B حزمة ذاتي تعريف تركيب فقد ذهاب هذا خلفية. خارجي اعتماد حال حال لم معرفة. إزالة تجميع صار أيضا سوف إزالة ذلك حقيقي بعيد مسار تركيب دليل؛ إبقاء محلي و تأخير متأخر مزود اختبار حفظ حماية كل منها اتفاق، و لا تحقق بعد لم تنفيذ بديل خطة.

[أصلي قيد](../architecture/2026-08-28-subprocess-native-containment.ar.md) ،[خروج محطة بديل إدارة](../architecture/2026-08-27-outbound-proxy-policy.ar.md) و[مساحة العمل ملف خدمة](../architecture/2026-09-05-workspace-files-service.ar.md) قرار إبقاء صالح. هو جمع E2B تنفيذ و تحقق بيان يتم سحب تحت، عملية كل حق، توجيه و ملف وصول اشتراط إبقاء كامل. يمكن نقل غرس صفة قرار فقط لديه E2B تنفيذ جزء يتم يحل محل.

## إعادة جذب دخول شرط

بعيد مسار مزود حاجة أداة جسم تنفيذ حالة استخدام، و إثبات مشترك ملف/عملية جلوس علامة، سياسة قوي صنع، محدود نقل إبقاء، مستقل تحكم دفع دخول، دقيق عبر طريق إغلاق و تلقي إدارة إلغاء. مصدر شفرة و بناء بعد تركيب يجب تنفيذ هذه سلوك. اتصال فقد فقد لا يستطيع يصبح إعادة وضع ممكن قد تنفيذ برنامج إدارة من، أيضا لا يستطيع حسب هذا صوت تسمية لم مراقبة إلى تنظيف قد نجاح.

[POSIX SSH مزود](../architecture/2026-09-11-posix-ssh-runtime.ar.md) استخدام مستقل في E2B أمر SDK تراكم حساب إخراج إبقاء مسار اثنان دخول صنع عبر طريق. عادي SSH exec لا خريطة مهمة معنى عملية فرعية وصف رمز، لذلك ذلك بعيد طرف مساعد مساعدة برنامج مسؤول تحكم تدفق جسر وصل، ملف دلالة، عملية دورة الحياة و بعيد طرف سياسة تنفيذ. هذا تنفيذ استخدام إبقاء واجهة؛E2B تجميع صار متابعة تراجع دور.

## تحقق

إزالة صاف نقطة لم اكتشاف صالح E2B حزمة، سير العمل، استيراد، اعتماد أو دليل بند. قفل ملف في كل إبقاء importer و حزمة تحليل نتيجة كل إبقاء أصل قيمة. مشترك عملية فرعية و طرفية تنفيذ، تأخير متأخر مزود اختبار و PTC مصدر شفرة إبقاء ثابت.

إبقاء نظام الملفات، عملية فرعية،Bash، طرفية و LSP طقم عنصر، و تلقي أثر توليد جهاز و سير العمل اختبار متساو عبر. إزالة بعد `pnpm run build`،`pnpm run test:docs`،`pnpm run doc-sync`،`pnpm run lint` و `pnpm run hygiene` متساو عبر. هذه فحص تحقق نيل إلى شفرة شجرة؛ قد حذف E2B اختبار لا لـ ذلك توفير دليل.
