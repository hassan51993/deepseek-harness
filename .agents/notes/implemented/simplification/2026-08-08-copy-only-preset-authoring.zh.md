# Agent Note: فقط نسخ preset إنشاء عمل، و عبر نحو preset ملف مدخل

Status: implemented

[English](2026-08-08-copy-only-preset-authoring.md) | العربية

## مشكلة

agent-preset ضبط صفحة حمل حال واحد شبكة صفحة YAML تحرير جهاز:`agentPreset.write` استقبال مهمة معنى تجميع نص، صفحة هو واحد لا يوجد تكملة كل، عال مضيء أو diff نص مجال، شكل حالة فحص اعتماد Loader ذاتي ذات `entryListSchema`——ذلك جهة قول يحتوي `!!js`، الذي بـ «مرور شكل حالة فحص نص» في تحت مرة تركيب وقت ما زال هو مهمة معنى شفرة. بصفة تحرير جهاز جدا ضعيف، بصفة قدرة جدا عرض، أيضا هو هذا قسم منطقة لا نيل لا منع صد «تحرير جهاز vs اسم مفرد» تنافس حالة مصدر.

## قرار

إنشاء عمل تعديل لـ مضيف طرف نسخ، ملف حينئذ هو تحرير جهاز.`agentPreset.write` تغيير لـ `agentPreset.copy { from, agentPreset, name? }`: اثنان عدد من مضيف مقابل وفق ذاته أصل دليل تحليل id إضافة واحد اختياري عرض اسم، كامل دليل `cp`(رمز رقم رابط حل مرجع، إذن استلام ضيق لـ فقط تابع رئيسي و إبقاء تابع رئيسي تنفيذ موضع) ، بيانات وصفية إعادة كتابة لـ إبقاء مصدر وصف، لكن أبدا إبقاء ذلك اسم أو `order`. صفحة يتضمن مع مرفق تجميع فقط قراءة فحص نظر جهاز، بصفة وحيد إنشاء مدخل نسخ محادثة إطار (لا توفير فارغ أبيض «جديد بناء مسبق ضبط») ، ذاتي تعريف سطر حذف، و عبر نحو ملف موضع عملية.`settings/openAgentPresetDirectory { agentPreset }` في Host جانب تحليل دليل و أصلي فتح، نشر لا يوجد طاولة وجه وقت عودة جواب `{ opened: false, path }` توفير هذا سطر بـ نص شكل صيغة عرض؛`settings/canOpenAgentPresetDirectory` تحكم هذا سطر هل عرض،Settings Controller `nativeOpen` فإن في منصة استكشاف قياس ممكن خطأ حكم وقت ثابت خدمة طرف سلوك.

## عاقبة

- إنشاء عمل اثنان عدد جهة نحو كل لا يوجد تجميع نص أو مسار عبر تجاوز متصفح نقل طبقة؛`entryListSchema`/`!!js` اعتبار اعتبار مع `assertComposition` ذاته (قد حذف) واحد و إزالة حل. إنشاء عمل عملية هو `read`/`copy`/`openDocument`/`remove`——لا يوجد واحد استقبال نظام الملفات هدف، كما Connection استخدام كامل Host API نفس جلسة إقرار إثبات هو جمع.
- تحرير جهاز إزالة بعد، يد تعديل `agent.cordis.yml` يصبح وحيد تجميع تحرير طريقة، لذلك معتاد إقامة تركيب طبقة زيادة بـ stamp لـ مفتاح بديل حد:`ensureStanding` مقارنة مقابل ملف mtime+كبير صغير، لـ لاحق جلسة فتح بدء تحت واحد بديل حد ([معتاد إقامة تركيب note](../../archived/architecture/2026-08-08-per-preset-standing-mounts.md) ، قد حينئذ أرض تحديث). لا يوجد هو، تعديل مرور ملف يلزم انتظار عملية إعادة بدء عندئذ توليد فاعلية.
- فرعي هذا هو كامل لقطة، سوف مع مع مرفق مصدر ترقية بينما عائم نقل——قبول؛preset طبقة لا يوجد patch دلالة (ذلك هو bundle طبقة `cordis.patch.yml` قدرة) ، مع مرفق تجميع دمج ذاتي ذات أيضا لـ «واحد ملف قراءة كامل نسخة تجميع» دفع نفس مثال بديل قيمة (`cordis`/`code` حينئذ هو `standard` كامل فرعي هذا).
- `read` ذهاب إسقاط `writable`(لا يوجد تحرير جهاز يمكن باب تحكم) ، داخل وضع دليل أبدا يتم فتح (`openDocument` و `remove` واحد مثال رفض غير `user` معلومة مهمة): تثبيت دليل سوف يتم ترقية تغطية، يأخذ تحرير جهاز إشارة نحو هو انتظار في استدعاء احتضان سوف يتم ترقية صامت صامت إسقاط تحرير.

## صلة مفتاح تنفيذ دقيق عقدة

- **نسخ هدف رفض لحظة معنى قسم اثنان طريق فحص.** roster فحص رفض مهمة واحد أصل دليل توفير id——و مع مرفق preset نفس اسم مستخدم دليل سوف يتم حجب حجب، «إنشاء» فقط سوف سقوط تحت واحد دائم بعيد لا يتم صف خروج ملف؛ مغناطيس قرص فحص (`cp` قبل `PresetExistsError`،`errorOnExist` عمل تنافس حالة التقاط قاع) رفض احتلال حال اسم حرف لكن لا هو preset دليل، ذلك هو discovery نظر لا رؤية.
- **عرض مسار هو استجابة جهة نحو كشف كشف، كما مرور مرور متصفح إقرار إثبات.**«لا يوجد أي متصفح تحميل حمل قدرة اختيار في مهمة معنى نظام الملفات هدف» هذا بند ثابت كمية قول هو طلب جهة نحو؛ يأخذ تحليل خروج دليل عرض إعطاء قد إقرار إثبات متصفح صحيح هو خطة اشتراط تخفيض. هو أبدا تركيب ركوب `list`.
- **e2e lane تثبيت ميت `nativeOpen: false`**(`agent-preset-authoring.overlay.yml`)——حيث يجعل golden في macOS تطوير آلة و بلا رأس Linux CI فوق تصيير نفس فرع، أيضا يجعل اختبار تشغيل دائم لا نابض خروج حقيقي ملف إدارة جهاز. كشف عرض دليل من lane ذاتي ذات token تحويل لـ `{{presetRoot}}`، لأن `normalizeAria` فقط إقرار تعرف workspace cwd.

## اعتبار مرور بديل خطة

إبقاء write تبديل عدد أكثر جيد تحرير جهاز (CodeMirror انتظار): نقل طبقة فوق ما زال هو مهمة معنى قدرة، ما زال هو تنافس حالة مصدر، بينما كما ما زال لا مثل مستخدم ذاتي ذات تحرير جهاز. حمل patch دلالة فرعي هذا («standard إضافة هذا نقطة diff»):bundle وجه لـ تحت لا يوجد هذا مثال طبقة، مستودع ذاتي ذات مع مرفق preset أيضا لحظة معنى اختيار كامل فرعي هذا. متصفح طرف أخذ إرجاع مسار ضبط `session/openWorkspacePath`: مسار واحد حالما يصبح طلب معامل، حينئذ ضرب كسر README «غير ممكن اختيار في مهمة معنى هدف» ثابت كمية.
