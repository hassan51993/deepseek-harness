# Agent Note: لا يوجد مستقل مراقبة وقت حذف ثابت كمية مرافق توليد مدخل

Status: implemented

[English](2026-08-28-omit-unneeded-invariant-companions.md) | العربية

## مشكلة

حزمة ثابت كمية قاعدة سبق اشتراط كل مساحة العمل حزمة كل إصدار `./invariant`، يشمل لا يوجد وقت التشغيل علاقة يمكن فحص حزمة. حالي مساحة العمل لديه 209 عدد حمل شرح فارغ مرافق توليد مدخل، كل مدخل كل حمل مصدر ملف، عام مشترك توجيه خروج، إصدار بند، فقط توفير ثابت كمية استخدام اعتماد أو TypeScript مرجع، بناء وصل خط و تسجيل اختبار. هذا طقم آلية فقط جدول بلوغ لا تحديد ربط نقاش، لا يوجد زيادة وقت التشغيل تأكيد.

`dsh-host-webserver` مرافق توليد مدخل بـ يمكن تنفيذ شكل صيغة كشف نفس مشكلة. هو سوف في إضافة دورة الحياة حدث فوق تسجيل و تحرير دمج صار إبقاء توجيه، مجددا مرة استدعاء نفس مجموعة خدمة عملية قدوم فحص قياس ناقص إبقاء. هذا استكشاف إبرة لا يوجد مستقل إنتاج مراقبة: هو عبر ذاتي ذات يلزم تحقق تنفيذ تعديل و فحص نفس ورقة توجيه جدول، بينما حقيقي توجيه و HMR اختبار قد تغطية تكرار رفض و disposer مقابل تسمية صفة.

## قرار

### مستقل مراقبة هو إصدار شرط

فقط لديه عند حزمة قدرة كاف مقارنة مقارنة ممكن مستقل إنتاج قسم اختلاف مراقبة وقت، عندئذ إصدار `./invariant`. رمز دمج شرط علاقة يشمل عبر حدث دورة الحياة، ترتيب، هوية أو إعداد مقابل بروتوكول؛ حدث و مرجعي متغير حالة مقابل وفق؛ كثير عدد إنتاج جهة أو adapter تجميع إخراج؛ و من آخر عدد عملية لاحق طي أو إزالة استهلاك حمل دائم بيانات.

خدمة أو طريقة هل وجود، إضافة metadata أو effect، ثابت صاف دالة عرض مثال، و استدعاء نفس تغيير عملية قدوم تحقق هذا عملية استكشاف إبرة، ما زال يخص نوع، تحميل، وحدة أو اختبار تكامل.parser و config إدخال، نموذج أو أداة JSON، حمل دائم ملف،worker و عملية رسالة و wire إدخال، ما زال في يملك ذلك إدخال عملية موضع تحقق.

`dsh-time-context` مرافق توليد مدخل متابعة إصدار. هو يأخذ إضافة إنتاج context message و مستقل يملك حالي جولة مستخدم رسالة source و حمل دائم حدث وقت إجراء مقابل وفق، لذلك أي جعل formatter ذاته صحيح تأكيد،attribution، جولة موضع و elapsed-time علاقة ما زال ممكن إنتاج قسم اختلاف.

### في حزمة README في واضح حذف

لا يوجد رمز دمج شرط علاقة وقت، حزمة سوف حذف `src/invariant.ts`،`./invariant` توجيه خروج،`lib/invariant.js` إصدار، فقط توفير ثابت كمية استخدام اعتماد و TypeScript مرجع، بناء مدخل و مرافق توليد مدخل مخصص استخدام اختبار. في إنجليزي نص حزمة README سوف شرح لا إصدار مرافق توليد مدخل، و سجل هذا حزمة أداة جسم سبب. مستودع سوف رفض فارغ installer، لأن لا وجود مصدر ملف إضافة README شرح يمكن مباشر جدول بلوغ هذا قرار.

`verify-package-invariants` سوف مسح كل حزمة. هو اشتراط إنجليزي نص README سجل حزمة درجة حذف سبب، رفض لا كامل توجيه خروج، إصدار أو مرافق توليد مدخل بناء وصل خط، رفض فارغ installer، و مقابل كل قد إصدار مرافق توليد مدخل تنفيذ تسجيل،Loader namespace،reporter استخدام، اعتماد، مرجع و بناء فحص.Vitest Host فقط في حالي حزمة وجود مرافق توليد مدخل وقت تركيب هو، توسيع اندفاع و بناء ناتج فحص فإن قطعة رفع قد إصدار تجميع دمج.

### مراجعة حساب نتيجة

كل مستودع مراجعة حساب حذف 209 عدد حمل شرح فارغ مرافق توليد مدخل و دمج صار `dsh-host-webserver` مرافق توليد مدخل، إبقاء تحت 39 بند مقارنة مقارنة مستقل مراقبة فحص. إبقاء بند يشمل session،command،approval،workflow و hook دورة الحياة انتظار عبر حدث بروتوكول؛settings،storage-domain،Workspace،client modules و slots انتظار حدث إلى حالة فحص؛system prompt و time context انتظار كثير إنتاج جهة تجميع فحص؛ و todo،plan mode و sandbox mode انتظار من projection أو policy state إزالة استهلاك حمل دائم بيانات.

يتم حذف علاقة متابعة من قائم حزمة سلوك اختبار مسؤول، يشمل webserver توجيه تسجيل و HMR تحرير. منتج سلوك و حزمة أصل مدخل ثابت؛ يتم حذف `./invariant` فرعي مسار حسب وفق مستودع مسبق إصدار توافق سياسة إزالة.

## اعتبار مرور بديل خطة

- **إبقاء حمل شرح فارغ مرافق توليد مدخل.** لا اعتماد: مصدر ملف، عام مشترك فرعي مسار، اعتماد حافة، بناء إخراج و اختبار هو واحد طقم مرور في كثيف إعادة آلية، لا ينبغي فقط استخدام قدوم جدول بلوغ لا وجود فحص؛ حزمة README يمكن مباشر سجل هذا ربط نقاش.
- **يأخذ webserver استكشاف إبرة إبقاء لـ تنظيف sentinel.** لا اعتماد: هو سوف في غير متصل دورة الحياة حدث فوق تعديل إبقاء توجيه، و كما فقط تحقق ذاتي ذات استدعاء خدمة طريقة. حقيقي توجيه و HMR اختبار يمكن في لا يوجد إنتاج تشخيص effect حال حال تحت تغطية هذا سلوك.
- **يأخذ كل إنتاج جهة صيغة parser كل نظر لـ ذاتي تحقق.** لا اعتماد: أي جعل نص فقط لديه واحد إنتاج جهة،parser ما زال ممكن مقابل وفق مستقل source identity، وقت أو حمل دائم تاريخ.`dsh-time-context` رمز دمج شرط، لأن ذلك رسالة سوف و حالي جولة مستخدم رسالة و حمل دائم حدث وقت مقابل وفق؛ فقط مقابل نفس كتابة جهة payload فعل نحو إرجاع فحص لا رمز دمج شرط.
- **اشتراط كل يملك خاص متغير حالة حزمة كل إصدار مرافق توليد مدخل.** لا اعتماد: لا يوجد مستقل حدث أو ثاني بيانات مصدر خاص حالة فقط قدرة عبر تكرار تنفيذ قدوم فحص، أو من حاجة مخصص باب لـ تشخيص كشف جديد API.

## عاقبة

- يملك متعمد معنى فحص حزمة إبقاء يمكن مستقل تحميل، مرور ترشيح و ملكية إلى حزمة مرافق توليد مدخل.
- لا يوجد فحص حزمة لم يعد تحمل تحمل ثابت كمية مصدر ملف، عام مشترك فرعي مسار، بناء ناتج أو فقط توفير ثابت كمية استخدام اعتماد، ذلك README سوف إبقاء سبب.
- إضافة جديدة متغير علاقة أو يتم إزالة استهلاك حدث بروتوكول وقت، يجب إعادة مراجعة نظر حذف ربط نقاش، تحديث README، و إضافة حمل سالب نحو اختبار تجمع تركيز مرافق توليد مدخل.
- ثابت كمية خدمة إعداد، ملكية وحيد صفة، فرعي fiber دورة الحياة، مرور ترشيح، تراجع،dispose و HMR اتفاق إبقاء ثابت.
- مبكر مدة[متعمد معنى وقت التشغيل اتفاق قرار](../architecture/2026-07-19-package-invariant-runtime-contracts.ar.md) ما زال هو دلالة فحص جودة كمية مرجعي اعتماد حسب؛ هذا قرار يحل محل منها نفاد كل إصدار و حمل شرح فارغ مدخل شكل صيغة.
