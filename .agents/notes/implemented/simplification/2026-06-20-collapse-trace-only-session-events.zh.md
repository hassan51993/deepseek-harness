# Agent Note: سوف فقط لأجل تتبع أثر جلسة واقع طي دخول تحمل تحميل فعلي وظيفة حدث

Status: implemented

[English](2026-06-20-collapse-trace-only-session-events.md) | العربية

## مشكلة

جلسة حدث مفردات في يتضمن واحد بعض واحد انتظار حدث، هو جمع لا يخص يمكن إعادة تشغيل محادثة تاريخ، في إنتاج بيئة في بضعة نحو لا يوجد مستهلك.`usage` قد بصفة نموذج تدفق قسم قطعة وجود، بعد حلقة أيضا إلحاق واحد مستقل `usage` حدث.`error` و `turn/end { kind: 'error', message, code }` في حلقة فشل سبب تكرار؛ACP(Agent Client Protocol) تسوية قراءة جولة انتهاء سبب، بينما رسالة إسقاط و UI إسقاط كل سوف قفز مرور مستقل `error` حدث.

هذه حدث يجعل مواصفة transcript(نص سجل) نظر بدء قدوم مقارنة فعلي أكثر ملائم دمج بصفة بعيد قياس بيانات. هو جمع زيادة حدث تغيير جسم، ثابت صيغة، اختبار، لقطة و حفظ دائم حالة استخدام، لكن بصفة مستقل سجل و لا تحمل تحميل فعلي وظيفة. هو جمع يحمل واقع ما زال لديه استخدام:token استخدام كمية ينبغي عند إبقاء بـ توفير نواة حساب، خطأ خطوة تحرير رقم أيضا لا ينبغي صامت لكن إزالة فقد. بسيط تحويل طريقة هو سوف هذه واقع طي دخول مستهلك هذا قد يجب إدارة حل مجاور قريب حدث، بينما غير نقص قليل سجل معلومة كمية.

## قرار

فقط في معلومة قد يتم إبقاء، بلا حاجة و سطر سجل حال حال تحت، إزالة مستقل، فقط لأجل تتبع أثر حدث:

- نجاح خطوة usage طي دخول مطابقة `assistant/message`(`assistant/message { turn, step, content, usage? }`) ، جعل تجميع جيد نموذج إخراج و ذلك نواة حساب معلومة واحد نفس نقل تمرير.
- فشل أو في توقف خطوة إذا لديه usage لكن لا يوجد مساعدة يد محتوى، فإن سوف usage وضع في واحد فارغ محتوى `assistant/message { content: [], usage }` فوق——لن لديه قد حفظ دائم usage قسم قطعة بلا موضع أمان وضع. يجب تأكيد حفظ معلومة لا فقد فقد قاموس نوع حال شكل هو max-tokens مسار: واحد يتم قطع قطع خطوة لديه usage لكن محتوى لـ فارغ (مثال مثل فقط لديه واحد يتم إسقاط أداة استدعاء) ، بـ قبل سوف إرسال خروج مستقل `usage`. لـ منع توقف فارغ محتوى حدث نحو مزود transcript حقن واحد كثير بقية بلا محتوى مساعدة يد جولة،`deriveMessages()` قفز مرور فارغ محتوى `assistant/message` حدث؛ ارتداد اختبار تأكيد usage ما زال لديه سجل، كما إرسال توليد تاريخ لم يتم كسر تالف.
- مستقل `error` حدث في خطوة تحرير رقم طي دخول `turn/end.reason`(عند `kind: 'error'` وقت:`{ kind: 'error', step, message, code? }`)——`turn/end` هو ACP و استعادة آلية قد إزالة استهلاك حمل دائم جولة نتيجة.
- `agent/error` و سجل إبقاء لأجل فوري تشخيص؛`turn/end` بعد لم يعد لديه ثاني بند جلسة سجل خطأ سجل.

مستخدم محادثة سجل يتضمن تصيير، استعادة، مراجعة حساب و نواة حساب الذي يحتاج الكل معلومة، مستهلك بلا حاجة تنسيق ضبط تكرار تتبع أثر سطر.

## سبق اعتبار بديل خطة

**إبقاء مستقل سطر بصفة بعيد قياس**——هذه حدث يجعل مواصفة transcript نظر بدء قدوم مقارنة فعلي أكثر ملائم دمج بصفة بعيد قياس بيانات، بديل قيمة هو زيادة حدث تغيير جسم، ثابت صيغة، اختبار، لقطة و حفظ دائم حالة استخدام، لكن لا يوجد أي مستهلك استخدام. إذا قسم تحليل يحتاج طلب حق صحيح ظهور، صحيح تأكيد شكل هو إسقاط مساعد مساعدة أداة أو حمل لديه مستقل إبقاء سياسة مخصص استخدام بعيد قياس تخزين، بينما غير محادثة سجل في تكرار تتبع أثر سطر.

## تحقق

`SessionEventMap` لم يعد يتضمن مستقل `usage` أو `error`؛agent loop(ذكي جسم حلقة) لم يعد إلحاق مستقل usage حدث، و عبر `turn/end { kind: 'error', step, message, code? }` حمل دائم سجل فشل؛ACP لقطة و حفظ دائم اختبار تأكيد لا وجود فقط لأجل تتبع أثر سطر؛ تجميد ربط v0 codec و ثابت انتظار ترحيل سوف يأخذ هذا قد إصدار يمثل إبقاء إلى قد إصدار v1؛ وثيقة شرح token استخدام كمية و تشغيل خطأ مراقبة قياس موضع.

## عاقبة

مستهلك لا يستطيع مجددا من مواصفة سجل في غربلة اختيار مستقل `usage` أو خطوة درجة `error` سطر، بينما يجب من تحمل تحميل هذه معلومة مساعدة يد رسالة أو فشل حدث في قراءة هذه واقع. من في نفسه واقع ما زال وجود——«تحقق» واحد عقدة إعطاء خروج إثبات——هذا هو دمج إدارة بسيط تحويل.

## تنفيذ شرح

**صيغة إصدار.** هذا حدث بسيط تحويل مبكر في قد إصدار v0 أساس خط.`dsh-session` يملك حالي كتابة جهة معتاد كمية، ساكن حالة دليل و متبادل مجاور حزمة فإن يملك تلقي دعم حمل تاريخ إصدار حل رمز و ترحيل. ثابت انتظار v0-to-v1 حافة في لا تغيير هذا حدث يمثل حال حال تحت إثبات كامل طقم دورة الحياة.

Usage الآن عبر `assistant/message.usage` مراقبة قياس؛ تشغيل خطأ خطوة تحرير رقم عبر `turn/end.reason`(عند `kind: 'error'` وقت) مراقبة قياس.`agent/error` و سجل لأجل فوري تشخيص، إبقاء ثابت.
