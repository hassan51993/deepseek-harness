# Agent Note: موحد واحد agent id و جلسة id

Status: implemented

[English](2026-06-20-unify-agent-and-session-id.md) | العربية

## مشكلة

واحد تخزين نشط agent(ذكي جسم)/جلسة مقابل حاجة استخدام نفس identity إتمام سجل التسجيل توجيه، حدث تتبع مصدر و حفظ دائم. يجعل factory قبول متبادل متبادل مستقل `agentId` و `sessionId` إدخال، سوف سماح أي إنتاج مسار كل لا يمكن استخدام إعداد مقابل، معا إجبار جعل كل مستهلك لـ نفس دورة الحياة في اثنان عدد اسم بين اختيار أو تحويل.

ACP(Agent Client Protocol) مقابل اثنان نوع identity استخدام نفسه قيمة.Stdio و خطاف أيضا في جلسة حدث تدفق فوق عمل، و كما مباشر حاجة مقابل تخزين نشط agent؛ لا يوجد إنتاج مسار سوف يأخذ واحد تخزين نشط agent كائن إعادة مرفق حال إلى كثير عدد جلسة، أو عبر كثير عدد agent id قيادة واحد جلسة.

[agent نطاق وقت التشغيل](../architecture/2026-07-12-agent-scope-runtime-design.zh.md) استخدام نفس عدد `AgentCreationTransaction` تنفيذ إنشاء و استعادة،agent/جلسة بند مشترك نفسه نهائي بند اندفاع مفاجئ قاعدة. ثاني عدد identity و لا بديل جدول مفرد وحيد تخزين نشط صفة، تراجع أو تماما توقف مستقر؛ هو فقط سوف محيط التفاف نفس أمر خدمة زيادة API و تحويل حالة.

جلسة identity نفس مثال فقط لديه واحد ملكية، أي `Session.header.id`؛`Session.id` هو إرسال توليد وصول جهاز، بينما غير حاجة تكرار تحقق مستقل حالة.

## قرار

agent سجل التسجيل id انتظار في ذلك جلسة id.`CreateAgentOptions` قبول واحد `sessionId`، معا لأجل اثنان عدد نهائي سجل التسجيل بند؛ استعادة وقت بـ `resumeSessionId` تسجيل agent؛ عملية داخل subagent إنشاء استخدام فرعي جلسة id؛`Session.id` فإن إرسال توليد ذاتي `header.id`. بعيد مسار ACP تشغيل لا يوجد محلي agent/جلسة مقابل: هو إبقاء واحد من أب بند صب صنع دورة الحياة id، بينما فرعي خادم بروتوكول محلي جلسة id ما زال فقط توفير ACP استدعاء داخلي استخدام. قائم إنشاء أمر خدمة، نهائي بند اندفاع مفاجئ فحص و دقيق بند قسم مغادرة دلالة إبقاء ثابت؛ وحيد مسؤولية هو في محلي id بين تحويل map و حقل قد إزالة فقد.

إعداد قيادة مسار إبقاء `agents[].id` بصفة مستقر إعداد وسم، بينما غير تخزين نشط حالة توجيه identity. عادي كل جديد بدء سوف صب صنع تركيب id `${label}-session-${randomUUID()}`، جعل حمل دائم إعادة بدء لن اندفاع مفاجئ. اقتران دمج تطبيق يمكن مسبق أولا صب صنع و نقل دخول دقيق `sessionId`: أول مرة استخدام وقت إنشاء هو، بينما عند حفظ دائم خدمة قد وجود وقت،AgentLoop إعادة تركيب سوف في نفس identity تحت استعادة قد شيء تحويل تاريخ.`resumeSessionId` فإن اشتراط قد لديه حفظ دائم identity. اثنان عدد دقيق id إدخال متبادل رفض.Stdio استخدام «استعادة أو إنشاء» شكل صيغة، جعل إعداد إنشاء agent و UI في حلقة إعادة تحميل بين مشترك واحد لا نفاذ واضح identity، بينما لا هو أصل حسب بادئة تخمين قياس. سجل يمكن استخدام مستقر وسم، بينما كل تخزين نشط حالة و حفظ دائم فحص بحث كل استخدام نفس عدد `SessionId`.

`agent/created` و `agent/disposed` إبقاء. هو جمع هو صار مقابل إصدار دورة الحياة حدث، بينما غير identity آخر اسم؛ بـ بعد إذا اكتشاف لا يوجد مستهلك و يلزم إزالة، يجب أولا إعادة بحث، مجددا رفع خروج مستقل رفع سجل.

## سبق اعتبار بديل خطة

**إبقاء توجيه و سجل identity قسم مغادرة.** مستقر إعداد وسم إضافة كل جديد حمل دائم محادثة تأكيد فعلي لديه استخدام، لكن لا حاجة اثنان عدد تخزين نشط identity: وسم يمكن متابعة بصفة إعداد/عرض بيانات وصفية، بينما كل مرة تشغيل تركيب `SessionId` مسؤول توجيه و حفظ دائم. إبقاء اثنان عدد id سوف يجعل تحويل map حمل متابعة وجود، سماح غير ممكن قدرة إعداد مقابل، لكن لن زيادة دورة الحياة قدرة.

## تحقق

- agent إنشاء/استعادة و subagent إنشاء فقط يحمل واحد identity،`Session` أيضا فقط في واحد موضع تخزين هو.
- إنشاء أمر خدمة متابعة تغطية نهائي بند اندفاع مفاجئ، دقيق بند قسم مغادرة، تراجع و تماما توقف مستقر، بلا حاجة identity خاص لديه دورة الحياة حالة.
- ACP،stdio، خطاف،bash ملكية، حفظ دائم و lineage مباشر استخدام مشترك `SessionId`.ACP subagent خلفية في أب نطاق الأسماء في صب صنع ذلك دورة الحياة id، لأن فرعي خادم إرجاع جلسة id فقط في خادم محلي صالح؛ACP bridge أصل حسب صحيح نحو جلسة map تحقق دقيق `Agent` ملكية؛JSON-RPC فقط تحويل حدوث أمر دورة مدة حدث في من خدمة لقطة حفظ `local` علامة لـ true حدث، من حمل نطاق حدث carrier أخذ نيل تفويض حمل أب بند، و كما لا إبقاء فرعي identity أو lineage cache.
- إعداد قيادة استعادة أو إنشاء سياسة هو صريح، و في حفظ دائم إعادة بدء مشهد تحت نيل إلى تغطية.
- إنتاج مستمع بحث تأكيد إبقاء `agent/created`/`agent/disposed` و ذلك إصدار دلالة.

## عاقبة

هذا ترتيب حذف كامن في كثير جلسة actor و جلسة تسليم وصل تصميم، و جعل من عميل اختيار، قد حفظ دائم جلسة identity يصبح سجل التسجيل identity. إذا مستقل توجيه identity يصبح حقيقي يحتاج طلب، حينئذ حاجة صريح دورة الحياة تصميم، بينما لا هو من استدعاء جهة توفير واحد مقابل لا تلقي قيد قيمة.
