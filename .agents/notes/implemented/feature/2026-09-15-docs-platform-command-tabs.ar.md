# Agent Note: Python SDK إشارة جنوب منصة أمر وسم

Status: implemented

[English](2026-09-15-docs-platform-command-tabs.md) | العربية

## مشكلة

[Python SDK إشارة جنوب](../../../../docs/user/guide/python-sdk.ar.md) قسم آخر توفير POSIX shell و Windows PowerShell أمر. وصل متابعة عرض اثنان عدد إصدار جعل قراءة من في كل واحد خطوة كل يلزم قفز مرور آخر منصة، أيضا سعة سهل يأخذ اثنان اختيار واحد أمر إدارة حل لـ حاجة اعتماد مرة تنفيذ.

## قرار

أربعة عدد منصة متبادل صلة خطوة قسم آخر استخدام VitePress أصلي `code-group`:Linux/macOS في قبل،Windows PowerShell في بعد. كل مجموعة مستقل اختيار، ابتدائي متساو عرض Linux/macOS. إعداد اعتماد و تشغيل عرض مثال ما زال هو اثنان عدد ترتيب خطوة. مشترك استخدام Python و YAML عرض مثال إبقاء مباشر مرئي.

اثنان نوع لغة متساو في مواصفة Markdown في إبقاء كل بند أمر. وثيقة إسقاط جهاز في شبكة محطة أصلي Markdown في إبقاء قسم مجموعة و شفرة. كل مجموعة قبل صريح مرساة نقطة إبقاء أصل لديه منصة عنوان رابط هدف؛ منصة مرساة نقطة تحديد موضع إلى قسم مجموعة، لكن لا اختيار وسم.

رئيسي عنوان لـ أصلي مفرد اختيار حسب زر وسم تكملة ملء مرئي مفتاح قرص تركيز نقطة جولة محيط، و في لا يمكن عملية وسم بحث ملخص في عرض اثنان عدد أمر كتلة.Markdown تصيير مهايئ سوف كل أصلي وسم شريط ضبط لـ منع توقف إيداع جدول مفرد. محلي بحث سوف نسخ فصل عقدة تصيير بعد HTML، منها يتضمن مفرد اختيار حسب زر اسم؛ مستقل الذي تابع جدول مفرد يمكن تجنب تجنب فرعي هذا صاف حذف صفحة اختيار.VitePress مسؤول اختيار، لغة قاعدة عال مضيء و نسخ حالي شفرة كتلة.MPA بناء لا يتضمن هذه عميل معالج، لذلك بناء مخصص استخدام مثال صيغة عرض اثنان عدد أمر كتلة، و إخفاء وسم شريط و نسخ حسب زر. لا جذب دخول مشترك اختيار حالة أو حفظ دائم انحراف جيد.

## اعتبار مرور بديل خطة

**إبقاء رأسي نحو تكرار منصة فصل عقدة.** اثنان عدد إصدار كل قيام يكفي رؤية، لكن تكرار تجهيز اختيار أمر سوف ضرب قطع إشارة جنوب ترتيب خطوة.

**ذاتي بناء وسم مكون و مشترك أو حفظ دائم اختيار.** Windows قراءة من فقط يحتاج اختيار مرة، لكن مشترك حالة سوف اقتران دمج مستقل عرض مثال، و جذب دخول تجاوز خروج الذي يحتاج عرض وظيفة اختيار و دورة الحياة شفرة. أصلي قسم مجموعة سوف تفاعل حد تحديد في كل مجموعة داخل.

## أثر

SPA قراءة من كل واحد خطوة فقط يرى واحد أمر إصدار،MPA، مستودع و أصلي Markdown قراءة من ما زال قدرة نيل أخذ اثنان عدد إصدار.Windows قراءة من حاجة في كل مجموعة في اختيار PowerShell. أصل لديه منصة رابط ما زال وصول مقابل خطوة، لكن منصة اسم لم يعد ظهور في صفحة كبير خطوط في.

تحقق تغطية أمر إبقاء، مزدوج لغة إعداد مقابل، إسقاط و أصلي Markdown، و حقيقي متصفح في تبديل، نسخ، مفتاح قرص تركيز نقطة، بحث، رئيسي عنوان و ضيق شاشة تخطيط. إطار هيكل مسؤول تفاعل في تشغيل في محطة نقطة تحقق استلام؛ جلسة إعادة تشغيل لا ملائم لأجل هذا بند صاف وثيقة عرض تغيير.

تجمع تركيز تصيير ارتداد تحقق محلي بحث نسخ فصل عقدة وقت مفرد اختيار حسب زر ملكية. مهايئ اعتماد VitePress أصلي وسم شريط HTML، بنية تغير وقت سوف جعل بناء فشل؛ إطار هيكل ترقية يجب إبقاء بحث عزل و متصفح فحص.
