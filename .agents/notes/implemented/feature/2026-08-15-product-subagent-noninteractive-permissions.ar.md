# Agent Note: منتج subagent استخدام Profile اختيار غير تفاعل إذن

Status: implemented

[English](2026-08-15-product-subagent-noninteractive-permissions.md) | العربية

## Problem

[Claude Code و Codex منتج مزود](2026-08-04-claude-code-and-codex-subagent-backends.ar.md) كل في لا يوجد شخص عمل واجهة حال حال تحت تشغيل. لذلك، أصلي إذن تلميح، مستخدم محادثة أو MCP elicitation لا يستطيع انتظار شخص عضو استجابة، لكن اعتماد مهمة واحد منتج بيئة في قيمة افتراضية ما زال ممكن اختيار تفاعل نمط. نشر أيضا حاجة اختيار أكثر عرض رخو أصلي نمط، معا لا يستطيع يجعل أب نموذج أو مفرد مرة أداة استدعاء رفع رفع ذاته إذن.

فشل منتج تشغيل هذا قبل فقط قدرة يأخذ إنهاء سبب إرسال دخول [subagent seam](2026-06-21-subagent-capability-seam.ar.md). سجل يمكن إبقاء منتج خطأ، لكن قبل منصة أب agent و[مرة صفة خلفية Job](../../archived/feature/2026-08-12-product-subagent-one-shot-background-tasks.md) لا يمكن منطقة قسم إذن رفض و أخرى فشل. إذا إعادة استخدام assistant إخراج تحمل تحميل هذا واقع، فإن سوف يأخذ أساس أساس ضبط تطبيق شرح خطأ عودة بسبب إعطاء فرعي نموذج.

## Decision

كل منتج مزود قسم آخر يملك ذاتي ذات Profile درجة `permissionMode` قيمة. اثنان عدد Config حقل متعمد استخدام كل منتج أصلي اسم، بينما لا هو مشترك تلقي حد/تلقائي/تماما سحب كائن. مزود سوف لـ هذا إضافة نسخة كل مرة تشغيل ثابت قد تحليل قيمة.subagent أداة schema و `SubagentStartRequest` كل لا يتضمن إذن حقل، لذلك نموذج أو مفرد مرة تفويض إرسال لا يمكن تغيير هو.

### Claude Code

Claude Code افتراضي استخدام `dontAsk`، بينما كما فقط قبول قفل تحديد إصدار Agent SDK دعم حمل أصلي غير تفاعل نمط:

| قيمة | أصلي سلوك |
| --- | --- |
| `dontAsk` | لا نابض خروج تلميح، مباشر رفض بعد لم نيل تخويل عملية. |
| `acceptEdits` | قبول تحرير؛ ذلك بقية إذن تلميح من بلا شخص قيمة حراسة عودة ضبط رفض. |
| `auto` | من Claude Code أصلي تصنيف جهاز سماح أو رفض إذن طلب. |
| `plan` | استخدام قاعدة تخطيط نمط، رفض تنفيذ مراجعة دفعة، و يأخذ كامل حساب تخطيط بصفة نهائي جواب سجل إرجاع. |
| `bypassPermissions` | ضبط SDK صريح خطر خطر تأكيد و قفز مرور إذن فحص. |

مزود متابعة حذف `settingSources`: اختياري نسخة درجة نموذج هو مستقل مباشر SDK تغطية؛ حذف الذي اختيار نمط بـ خارج، مستخدم، مشروع و محلي ضبط، هوية تحقق، أداة و صندوق رملي سلوك ما زال من Claude Code يملك.

كل مرة query كل منع استخدام `AskUserQuestion`. غير bypass نمط إذن عودة ضبط سوف رفض طلب، بينما لن إرجاع SDK في سوف بلا حد منع سد `null`؛plan نمط أيضا سوف يأخذ `ExitPlanMode` وضع دخول `disallowedTools`، لذلك أصلي allow قاعدة لا يمكن يأخذ بلا شخص قيمة حراسة query قطع عودة تنفيذ نمط.MCP elicitation سوف يتم رفض؛ قد دعم حمل رفض محادثة سوف يتم إلغاء؛ لم إعلان محادثة نوع استخدام SDK بلا محادثة فشل سلوك. أصلي `permission_denied` رسالة سوف سجل نفس نسخة حالي تشغيل واقع. هذه مسار لن إنشاء مراجعة دفعة جلسة، طابور صف، ذاكرة مؤقتة أو إعادة محاولة حلقة.

### Codex

Codex افتراضي استخدام `never`، و قبول Codex 0.153.4 عام ثلاثة نوع أصلي غير تفاعل نمط. مزود بدء ثابت app-server أمر، مجددا يأخذ الذي اختيار نمط خريطة لـ رسمي جهة `thread/start` حقل، لأن CLI عام إذن flag لن إعداد بعد من app-server عميل إنشاء خط مسار:

| قيمة | `thread/start` حقل | أصلي سلوك |
| --- | --- | --- |
| `never` | `approvalPolicy: never`؛ حذف sandbox | دائم لا نابض خروج تلميح؛ تنفيذ فشل سوف في أصلي sandbox تحت إرجاع نموذج. |
| `approve-for-me` | `approvalPolicy: on-request`،`approvalsReviewer: auto_review`،`sandbox: workspace-write` | من Codex تلقائي مراجعة إذن طلب. |
| `dangerously-bypass-approvals-and-sandbox` | `approvalPolicy: never`،`sandbox: danger-full-access` | قفز مرور مراجعة دفعة و sandbox. |

مزود فقط تغطية هذه إذن و sandbox حقل. اختياري نسخة درجة نموذج هو مستقل مباشر `thread/start` تغطية؛`CODEX_HOME`، مشروع إعداد، نموذج provider اختيار،MCP،hook،skill، هوية تحقق، و نمط لم اختيار sandbox واقع ما زال يخص Codex أصلي حالة.wire ما زال سوف رفض أي معنى خارج وصول مراجعة دفعة، إذن، مستخدم إدخال أو MCP طلب، بينما لن فتح وضع حركة حالة allow عبر طريق.

### فشل تشخيص

`SubagentResult` يحمل اختياري `diagnostic`، لأجل مزود إنتاج كما لا يخص assistant محتوى فشل شرح. مزود في توليد هو قبل سوف ترتيب حذف أداة إدخال، ملف محتوى، بيئة قيمة، سند إثبات و أصلي بروتوكول تحميل حمل. مشترك عملية خارج نتيجة حد سوف يأخذ كامل نص حد في 4096 عدد UTF-8 بايت بـ داخل، و في لا قطع قطع محرف قبل رفع تحت علامة قطع قطع.[الأكثر صغير تشخيص قرار](../../archived/simplification/2026-08-21-product-subagent-minimal-diagnostics.md) مسؤول اثنان عدد منتج عبر نفس حقل تحمل تحميل غير إذن سطر حركة صنف آخر، دورة الحياة مرحلة مقطع،HTTP واقع و عملية نتيجة.

كل منتج إذن واقع كل فقط يتضمن صالح نمط، طلب صنف آخر، بلا شخص قيمة حراسة قرار و ثابت أمان سبب.Claude Code من SDK عودة ضبط و `permission_denied` رسالة أخذ نيل هذه واقع.Codex من app-server طلب، يتم رفض item و بنية تحويل `sandboxError` نهاية حالة أخذ نيل واقع. أصلي stderr ما زال سوف تحويل إرسال إعطاء Host، لكن حيث لن يتم تصنيف، أيضا أبدا سوف نسخ دخول تشخيص. اثنان عدد مزود كل سوف يأخذ فشل سطر وضع في الأكثر جديد مشاركة و فشل إذن واقع قبل. نجاح نتيجة فقط إرجاع صارم إطار نهائي جواب سجل؛ محلي إلغاء ما زال بـ `aborted` تسوية كما لا مرفق حمل إذن شرح؛ لم إصدار بدء فشل ما زال سوف رفض `start()`. مزود أبدا سوف يأخذ مهمة واحد تشخيص واقع كتابة assistant إخراج، بنية تحويل إخراج أو `subagent/end.lastAssistantMessage`.

قبل منصة مستهلك اعتماد مرة عرض إنهاء سبب عنوان، اختياري تشخيص و أي جزء assistant إخراج. مرة صفة خلفية مهايئ سوف في فشل Job detail في، يأخذ نفس تشخيص و إنهاء سبب واحد بدء حفظ. لا يوجد ملء كتابة هذا حقل مزود إبقاء أصل لديه سلوك.

### كل حق و دورة الحياة

| واقع أو مورد | Owner | يمكن مراقبة سلوك |
| --- | --- | --- |
| Profile إذن اختيار | كل منتج مزود Config | إعداد مرحلة مقطع سوف رفض بلا فاعلية، تفاعل صيغة أو لم معرفة قيمة. |
| إذن و صندوق رملي دلالة | Claude Code Agent SDK أو Codex app-server | كل مزود نقل دخول واحد أصلي نمط، لا مرآة مثل منتج سياسة. |
| تفاعل قرار و أمان تشخيص | مفرد مرة منتج تشغيل | تزامن تشغيل قسم آخر يملك مستقل نمط، بروتوكول و تشخيص حالة. |
| تشخيص نوع و بايت حد أعلى | `dsh-subagent` | مستهلك استلام إلى و assistant إخراج قسم مغادرة محدود اختياري حقل. |
| قبل منصة و Job عرض | `dsh-tool-subagent` و عام Job وقت التشغيل | ضبط درجة اختيار لن تغيير قاع طبقة فشل واقع. |
| عملية إلغاء و تماما توقف مستقر | منتج مزود و `dsh-subprocess` | نتيجة تسوية بعد ما زال تنفيذ قوة انتظار كامل عملية شجرة مورد تحرير. |

## Verification

حزمة اختبار ثابت كل سماح و رفض Config قيمة، دقيق تأكيد SDK و app-server حقل خريطة، خطر خطر تأكيد، بلا شخص قيمة حراسة نهاية حالة، تشخيص انفصال حساس و UTF-8 حد أعلى، نجاح نتيجة لا يحمل تشخيص، تزامن تشغيل عزل، قبل منصة ترتيب،Job detail،stderr observer تحرير و عملية تنظيف. حقيقي Claude Agent SDK 0.3.263 و Claude Code 2.1.263 fixture إثبات ذلك أمان افتراضي، تلقي حد رفض، صريح bypass و كامل شجرة عملية شجرة تماما توقف مستقر. حقيقي Codex 0.153.4 app-server fixture إثبات خط مسار درجة `never` تغطية بيئة في `on-request`، تلقائي مراجعة يمكن بدء، خطر خطر التفاف مرور فقط في اختبار يملك مؤقت تخزين في كتابة، يتم رفض رفع حق لن إبقاء تحت فرعي أثر كما تشخيص لا يحتوي أصلي أمر أو مسار،stderr فقط توفير Host مراقبة قياس، بينما كما wrapper/native عملية شجرة سوف خروج.Loader تجميع إثبات غير افتراضي نمط يمكن في لا بدء مهمة واحد منتج حال حال تحت إصدار؛ بلا مفتاح ACP snapshot فإن سجل كل منتج فشل تشخيص مثل أي مرور مرور قبل منصة و Job عرض، معا موجه إلى نموذج منتج أداة schema لا يتضمن إذن معامل.

## Alternatives considered

**استخدام منتج بيئة في إذن قيمة افتراضية.** أصلي ضبط ممكن اختيار تفاعل نمط، جعل بلا شخص قيمة حراسة سلوك اعتماد نشر بيئة. مزود يجب لـ كل مرة query صريح اختيار غير تفاعل نمط.

**يأخذ إذن نمط وضع دخول موجه إلى نموذج أداة أو كل مرة start طلب.** هذا سوف يجعل مهمة محتوى اختيار إذن، و في كل مرة استدعاء في تكرار واحد Profile نشر قرار.

**نسخ منتج ضبط أو خريطة أب درجة Harness صندوق رملي.** كل منتج و لا مشترك نفس طقم إذن مفردات. مرآة مثل هذه حالة سوف إنشاء ثاني عدد مرجعي، و إخفاء غطاء تلقائي نمط و bypass نمط أصلي صندوق رملي عاقبة.

**يأخذ تلميح تحويل إرسال إعطاء أب agent،Web عميل أو CLI.** مرة صفة منتج تشغيل لا يوجد من ذلك يملك شخص عمل تفاعل دورة الحياة. إضافة جديدة هذا قدرة حاجة حمل دائم طلب هوية، توجيه، إلغاء و timeout دلالة، تجاوز خروج هذا قرار نطاق.

**إرجاع أصلي منتج خطأ،stderr أو أداة إدخال.** هذه قيمة ممكن يتضمن أمر، مسار، مساحة العمل بيانات، بيئة قيمة أو سند إثبات. ثابت أمان تشخيص حيث إبقاء يمكن عملية صفة، أيضا لن كشف منتج transcript.

**مفرد وحيد حفظ Job تشخيص.** Job فقط هو نفس `SubagentRun` ضبط درجة مهايئ؛ ثاني عدد حقل سوف يجعل قبل منصة و خلفية فشل يحتوي معنى حدوث عائم نقل.

## Consequences

Profile يمكن في مزود بدء قبل اختيار كل منتج أصلي تلقي حد، تلقائي، في منتج دعم حمل وقت فقط قاعدة تخطيط/تحرير وضع سطر، أو bypass سلوك، بينما اثنان عدد أمان قيمة افتراضية كل أبدا سوف استفسار سؤال شخص عضو. أكثر عرض رخو نمط ما زال هو صريح نشر اختيار، و إبقاء ذلك أصلي صندوق رملي عاقبة.

إذن فشل سوف معا وصول قبل منصة أب agent و مرة صفة خلفية Job، كما لن يأخذ أساس أساس ضبط تطبيق نص زائف تركيب صار assistant عودة جواب. نفس حقل أيضا يمكن تحمل تحميل من آخر بند قرار مسؤول بنية تحويل فشل واقع. هو يمكن امتداد عادي إزالة استهلاك مسار دخول نموذج سياق،Job إشعار،API إسقاط و Job UI، لذلك مزود يجب في نتيجة تسوية قبل مقابل كامل نص إتمام انفصال حساس و حد طويل.

هذا تعديل لا زيادة منتج جلسة حفظ دائم، شخص عمل مراجعة دفعة عبر طريق، حركة حالة إذن عملية، دخول درجة تدفق، إعادة محاولة سياسة أو تراجع. أخرى مزود بلا حاجة إنتاج تشخيص أو عام إذن نمط Config، ما زال إبقاء دمج قاعدة.
