# Agent Note: MCP مورد متاح صفة أخذ قرار في قد إعداد خادم

Status: implemented

[English](2026-09-13-mcp-resources-in-profiles.md) | العربية

## مشكلة

لم إعداد MCP خادم جلسة لا حاجة مورد schema أو MCP إشارة جذب. اشتراط مفرد وحيد مورد خدمة بند، أيضا يجعل مستخدم في إعداد كل اتصال خارج أيضا يلزم إعداد مشترك مورد وصول. من أول منصة خادم يملك مشترك أداة تجميع ممكن مع هذا خادم إزالة بينما إزالة فقد، أي جعل أخرى خادم ما زال حاجة هو.

## قرار

كل مع مرفق profile موحد واحد تركيب `mcp-resources` مرة: يشمل Desktop في داخل أساس في base profile من `dsh-base` وراثة هذا سطر؛ مستقل `sdk-minimal` يملك ذاتي ذات سطر. مستخدم فقط يحتاج إعداد `mcp-client` بند. افتراضي لا تفعيل أي MCP خادم.

مورد خدمة استخدام استدعاء جهة أثر مجال في قد إعداد مزود تسجيل، يشمل من أخرى مزود تركيب MCP عميل. مرئي سجل التسجيل لـ فارغ وقت، لا مساهمة مورد نص التوجيه،native أداة schema،PTC إعلان أو PTC ربط. أثر مجال في أول عدد مزود تفعيل مشترك أداة؛ إزالة الأكثر بعد واحد مزود وقت إزالة هذه محلي تسجيل، معا إبقاء وراثة مزود و أداة. مورد خدمة مستقل في أي خادم إضافة يملك مشترك أداة effect.

اتصال سليم سليم حالة لا قرار هذه محتوى مرئي صفة. تنشيط عميل في طلب فشل أو إعادة وصل محاولة تجربة خلال ما زال يخص قد إعداد حالة؛ مشترك مورد أداة و خادم اسم إشارة جذب إبقاء متاح، استدعاء سوف تقرير إبلاغ اتصال فشل. خادم إشارة أمر إبقاء من اتصال يملك إصدار قاعدة.

هذا قرار جزء يحل محل[مورد و إشارة أمر قرار](2026-09-12-mcp-resources-and-instructions.zh.md) في مفرد وحيد تفعيل مورد خدمة تركيب طريقة. هذا قلم تسجيل إبقاء عملية، أثر مجال اختيار، مواصفة نتيجة، اثنان دخول صنع تصيير و قد سجل إشارة أمر تصميم اعتماد حسب.

## اعتبار مرور بديل خطة

**إبقاء مفرد وحيد مورد تركيب.** هذا سوف يجعل مشترك قدرة يصبح ثاني بند مستخدم إعداد مهمة، و سماح مع مرفق profile استخدام مختلف قيمة افتراضية.

**لا يوجد خادم وقت ما زال عرض مورد أداة.** هذا سوف نحو عادي جلسة زيادة غير ممكن استخدام عملية و نص التوجيه token، يشمل افتراضي فقط لديه واحد shell أقصى بسيط SDK.

**حسب تنسيق تجارة خروج مورد قدرة مرور ترشيح مزود.** هذا قدرة حذف لم إعلان مورد خادم مقابل مورد إشارة جذب، لكن سوف يجعل مرئي صفة أخذ قرار في نجاح قدرة تسليم تبديل. قد إعداد عميل سياسة مقابل مباشر إعداد و من مزود تركيب عميل استخدام نفس معيار، يشمل أول مرة نجاح اتصال قبل و استعادة خلال.

**من أول منصة خادم إضافة يملك مشترك أداة.** تحرير هذا خادم ممكن إزالة أخرى قد إعداد خادم ما زال حاجة أداة، لذلك من خدمة يملك هذه أداة دورة الحياة.

## تحقق

[مورد اختبار](../../../../packages/mcp/mcp-resources/tests/resources.spec.ts) تغطية فارغ native و PTC عرض، أثر مجال وراثة، أول عدد و الأكثر بعد واحد مزود تغير، تحرير، و قد إعداد مزود استدعاء فشل.[حقيقي SDK اختبار](../../../../packages/mcp/mcp-client/tests/protocol.spec.ts) ثابت فقط توفير أداة خادم إرجاع فارغ اكتشاف نتيجة، و لا تلقي دعم حمل قراءة تقرير خطأ.[Profile تركيب اختبار](../../../../apps/cli/tests/profile-mcp.spec.ts) تحليل كل مع مرفق CLI نموذج لوح؛[Desktop تركيب اختبار](../../../../apps/desktop/tests/profile-mcp.spec.ts) يتضمن ذلك profile و Host overlay. فارغ native و PTC تسجيل صنع جلسة استخدام مع مرفق headless تركيب، لا إضافة مورد بند.

## عاقبة

فارغ MCP إعداد لا زيادة MCP نص التوجيه أو أداة token. لا أداة تجهيز مورد قدرة قد إعداد خادم ما زال مساهمة اسم و مشترك مورد schema.SDK إرجاع فارغ اكتشاف قائمة؛ لا تلقي دعم حمل قراءة سوف فشل. إضافة أول عدد مرئي خادم أو إزالة الأكثر بعد واحد خادم، سوف تغيير لاحق نص التوجيه و أداة تجميع. أقصى بسيط SDK في مستخدم إضافة MCP خادم قبل فقط عام نشر واحد shell. مورد قراءة ما زال حسب يحتاج إجراء، بلا حاجة أكثر تعديل اتصال أو حمل دائم Session صيغة.
