# Agent Note: إدخال إطار مرجع معاينة

Status: implemented

[English](2026-09-10-composer-reference-previews.md) | العربية

## Problem

مستخدم حاجة في تحرير كتابة رسالة وقت و إرسال بعد فحص نظر مرجع ملف و skill إشارة أمر. ملف وسم و يمكن تحرير مائل عمود نص أداة لديه مختلف تحرير دلالة، لكن كل حاجة واضح معاينة يد اتجاه، كما لا يستطيع تغيير تحت واحد بند تلميح إرسال محتوى.

## Decision

[إدخال إطلاق مصدر](../../../../packages/client/ui-input-trigger/README.ar.md) مسؤول اختياري مرجع تنشيط. تحرير جهاز حسب مصدر هوية توجيه أصل فرعي مرجع، حسب مصدر حالي كلمة جدول توجيه يمكن تحرير نص. ملف و skill مصدر في تحرير كتابة رسالة Session في فتح قائم يمين جانب شريط ملف مورد.Skill اكتشاف إبقاء فوز خروج مزود اختياري إشارة أمر ملف مسار، تجنب تجنب تحميل متن أو أصل حسب skill اسم، دليل معتاد مثال تخمين قياس مسار.

[إدخال إطار](../../../../packages/client/ui-conversation/README.ar.md) مشترك استخدام مرجع معلق توقف مثال صيغة، معا إبقاء أصل فرعي ملف وسم و يمكن تحرير `/name` نص. نقر لا تسلسل تحويل أو إيداع مسودة مسودة. بلا فاعلية وسم، اختيار يد اتجاه و غير ممكن استخدام مصدر هدف ما زال من تحرير جهاز معالجة؛ وهمي محاكاة skill ما زال يمكن استدعاء، لكن لا يوجد ملف معاينة.

قد إرسال رسالة هواء فقاعة إبقاء سجل في skill استدعاء دليل بصفة تركيب زينة اعتماد حسب.[Chat هدف](../../../../packages/client/ui-chat/README.ar.md) في حالي فحص نظر Session في فتح ملف مسار، و عبر هذا Session مصدر توجيه قد تحميل skill اسم. مشترك مستخدم نص مكون سوف هذه مرجع تصيير لـ حسب زر، إعادة استخدام قائم متن ملف رابط معلق توقف و تجمع تركيز مثال صيغة؛ جلسة، دليل و أمر مرجع لا توفير تنقل.

## Alternatives considered

**سوف skill نص تحويل لـ ملف وسم**سوف لـ عرض يحتاج طلب بينما تغيير تحرير، قص لصق لوح و تلميح دلالة. قائم يمكن تحرير نص قد قدرة كاف عبر مصدر كلمة جدول معرف skill.

**في إدخال إطار داخل تحليل ملف و skill صيغة**سوف يجعل تحرير جهاز اعتماد مزود دليل سياسة و معاينة خدمة. من مصدر مسؤول تنشيط، جعل هذه اعتماد إبقاء في قد مسؤول مرجع اكتشاف إضافة في.

**اكتشاف وقت تحميل كل skill متن**سوف في مستخدم طلب معاينة قبل زيادة عمل و مزود فرعي أثر. اختياري مسار بيانات وصفية كاف بـ دعم حمل نظام الملفات skill، و إبقاء وهمي محاكاة مزود.

## Consequences

معاينة مسار هو مؤقت اكتشاف بيانات، لن إضافة دخول Session رسالة.Skill إضافة استخدام قائم حسب Session ذاكرة مؤقتة آلية جعل مسار بطلان. ذاكرة مؤقتة لم حينئذ خيط وقت، نقر انتظار مشترك دليل طلب و إبقاء الذي تابع Session عنوان؛ ذاكرة مؤقتة بطلان و إضافة تحرير سوف إلغاء انتظار معالجة معاينة. نظام الملفات مزود عام نشر تحليل بعد إشارة أمر مسار، معا إبقاء اكتشاف وقت إعادة تحميل تحديد موضع معلومة و مورد أصل. جانب شريط مورد قراءة جهاز متابعة مسؤول حالي محتوى، ملف ناقص خطأ و وصول سياسة.[مساحة العمل مصدر ملف قرار](2026-09-08-present-workspace-source-files.ar.md) ما زال مسؤول تسليم ملف سلوك؛ إدخال إطار معاينة لا يحل محل هذا قرار.

إبرة مقابل صفة اختبار تغطية مصدر توجيه، تحرير، ذاكرة مؤقتة بطلان، حمل جذب رقم مسار، نص اختيار و مسودة مسودة ثابت. حقيقي Web تركيب تحقق اثنان نوع معاينة، متسق معلق توقف خلف مشهد و فتح بعد حذف عملية؛ ذلك الذي تابع مسبق مدة إخراج سجل skill وثيقة و قد إرسال رسالة. إعادة تشغيل skill استدعاء جولة تحقق تحديث جديد تاريخ بعد اثنان نوع قد إرسال مرجع ما زال يمكن معاينة.
