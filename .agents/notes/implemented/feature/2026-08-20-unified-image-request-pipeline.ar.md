# Agent Note: موحد واحد مواصفة تحويل مرفق عنصر، طلب إصدار و مزود ملف

Status: implemented

[English](2026-08-20-unified-image-request-pipeline.md) | العربية

## Problem

حمل دائم صورة تاريخ، مزود قسم تمييز معدل، داخل ربط طلب كبير صغير و بعيد طرف ملف إعادة استخدام لديه مختلف حد. مرور ذهاب يأخذ قد وصل قبول صورة مباشر بصفة بعد كل مرة طلب إرسال بايت، توجيه يؤدي واحد بايت حد أعلى و واحد نسخة ضوء شبكة معا تحمل تحمل أربعة نوع مسؤولية. عادي كبير رسم سوف يتم رفض؛ جاف صاف 16-bit PNG يمكن دخول تاريخ، بعد عندئذ يتم DeepSeek رفض؛ تكرار base64 جعل طويل جلسة طلب حمل متابعة زيادة طويل؛ مزود رفض بعد، نفس حمل دائم صورة أيضا سوف دخول كل مرة لاحق طلب.

## Decision

صورة مسار لديه اثنان عدد صريح إصدار. مرفق عنصر خلفية يملك مزود غير متصل حمل دائم مواصفة تحويل مرفق عنصر. كل بند دعم حمل صورة نموذج توجيه يملك تحديد صفة طلب سياسة، مرفق عنصر خلفية من هذا مرفق عنصر إرسال توليد و ذاكرة مؤقتة تأكيد قطع طلب إصدار. جلسة تاريخ فقط يتضمن مواصفة تحويل مرفق عنصر مرجع؛ داخل ربط بايت و مزود ملف ID كل هو لحظة وقت طلب إسقاط.

### مزود غير متصل مواصفة تحويل مرفق عنصر

كل بند رسالة الأكثر كثير دقيق دخول 20 ورقة صورة، مصدر رسم تحرير رمز بايت مجموع كمية لا تجاوز مرور 200MiB. كل ورقة مصدر رسم سوف في يمكن إعداد 20MiB،64,000,000 مثل عنصر و مفرد حافة 8192px حد داخل كامل حل رمز. مواصفة تحويل مرور مسار سوف تطبيق EXIF جهة نحو، حذف بيانات وصفية و لون لون ملف إعداد، تحويل لـ 8-bit sRGB/sRGBA، و إبقاء عرض عال مقارنة تقليص وضع دخول `normalizedImageMaxPixels` مجموع مثل عنصر ميزانية (افتراضي 2048×2048) ، مع بعد تلقي `normalizedImageMaxDimension` طويل حافة حد أعلى قيد (افتراضي 8192px). تقليص وضع نقص صغير ضوء شبكة وقت،`originalDimensions` سجل مواصفة تحويل قبل، تطبيق جهة نحو بعد إدخال عرض عال.

مواصفة تحويل مرفق عنصر لديه مستقل `normalizedImageMaxBytes` تحرير رمز بايت هدف، افتراضي 4MiB. نفاذ واضح عبر طريق أبدا فرش مستو. تحرير رمز توجيه فقط نظر حل رمز خروج alpha واقع: نفاذ واضح إدخال تحرير رمز لـ WebP(effort 0) ، غير نفاذ واضح إدخال تحرير رمز لـ JPEG، مشترك استخدام 85/75/60 جودة كمية مرحلة سلم؛ الكل ملف موضع كل تجاوز مرور هدف وقت إبقاء الأكثر صغير ناتج، رؤية يحل محل هذا عقدة[حسب alpha توجيه جودة كمية مرحلة سلم سجل](../bug-fix/2026-08-24-alpha-routed-image-quality-ladders.ar.md). موضع في الكل مواصفة تحويل حد داخل جاف صاف، مفرد لقطة،8-bit sRGB/sRGBA PNG،JPEG أو WebP حسب بايت أصل مثال مباشر عبر، و إبقاء محتوى بحث عنوان ذهاب إعادة.GIF، حركة رسم، بيانات وصفية، جهة نحو،16-bit PNG و لا توافق لون لون فضاء كل سوف إطلاق تحويل. مصدر رسم و تحويل إخراج كل كامل حل رمز مرة؛ إخراج صيغة، مقياس قياس، موضع عميق، لون لون فضاء و نفاذ واضح عبر طريق واقع عبر تحقق بعد، ذلك ملخص عندئذ سوف دخول مرجع.

دفعة كمية دقيق دخول في إصدار أي عضو قبل، لـ كل ورقة صورة كل دقيق تجهيز و تحقق مرة مواصفة تحويل مرفق عنصر. تحقق فشل لن بدء كتابة. إصدار مباشر استخدام هذه قد دقيق تجهيز بايت، لذلك كبير دفعة مرة لن في إيداع وقت تكرار كامل حل رمز و تحرير رمز. بعد حدوث تخزين فشل لن إرجاع جزء مرجع؛ حسب قائم تخزين قاعدة، قد إصدار غير ممكن تغيير كائن ممكن إبقاء غير ممكن بلوغ.

### تحديد صفة طلب إصدار

`AttachmentStore.readImageRequest` حسب توجيه يملك مجموع مثل عنصر و تحرير رمز بايت ميزانية إرسال توليد طلب إصدار. تقليص وضع عام صيغة لـ `min(1, sqrt(maxPixels / (width * height)))`، لن وضع كبير صغير رسم، مع بعد نحو ميزانية داخل أخذ كامل، تأكيد حفظ تحرير رمز ضوء شبكة لا تجاوز مرور مجموع مثل عنصر حد أعلى.DeepSeek V4 Flash Vision Exp افتراضي استخدام مجموع مثل عنصر 640,000 و أصلي تحرير رمز بايت هدف 1MiB. ذلك catalog فقط استخدام واحد `imagePixelBudget` حقل: صحيح كامل عدد اختيار تأكيد قطع مجموع مثل عنصر ميزانية،`low` اختيار مجموع مثل عنصر 512×512، حذف وقت استخدام توجيه قيمة افتراضية.2048×1024 مواصفة تحويل مرفق عنصر في هذا عدد صلب حد أعلى تحت سوف إسقاط لـ 1130×565. طلب تحرير رمز و مواصفة تحويل مشترك استخدام نفس طقم alpha توجيه و 85/75/60 جودة كمية مرحلة سلم، حسب يحتاج تنفيذ؛ لا يوجد أي ملف موضع بلوغ إلى هدف وقت إبقاء الأكثر صغير ناتج (رؤية[حسب alpha توجيه جودة كمية مرحلة سلم سجل](../bug-fix/2026-08-24-alpha-routed-image-quality-ladders.ar.md)). عادي agent جولة، مباشر `ctx.llm.stream` استدعاء، ضغط و أخرى مساعد مساعدة تدفق كل استخدام نفس إرسال توليد مرور مسار.

`variantId` و ذاكرة مؤقتة مسار تغطية مواصفة تحويل مرفق عنصر ID، تغيير تبديل سياسة إصدار، توجيه مثل عنصر و بايت ميزانية و ثابت تحرير رمز معامل. جديد ذاكرة مؤقتة بند في إصدار قبل سوف كامل حل رمز. ذاكرة مؤقتة أمر في فقط استكشاف قياس ملف رأس، تحقق صيغة،8-bit sRGB/sRGBA، مقياس قياس و نفاذ واضح عبر طريق، لن مجددا مرة كامل حل رمز ضوء شبكة؛ لا مطابقة وقت سوف إعادة توليد. لذلك، نفس سياسة تحت DeepSeek Files و pi-ai داخل ربط base64 استخدام نفسه تحديد صفة بايت. داخل ربط حساب كمية استخدام إرسال توليد بايت مرور مرور base64 تمدد انتفاخ بعد طويل درجة، لا استخدام مواصفة تحويل مرفق عنصر بايت عدد. نفس عملية داخل نفسه `variantId` استدعاء مشترك مرة تغيير تبديل و ذاكرة مؤقتة كتابة. كل استدعاء جهة يمكن إلغاء ذاتي ذات انتظار؛ فقط لديه الكل انتظار جهة كل إلغاء وقت، مشترك تغيير تبديل عندئذ سوف في توقف. استدعاء جهة مقابل مفرد عدد `readImageRequest` استخدام `Promise.all` إبقاء نتيجة ترتيب. محلي تنفيذ عبر واحد FIFO حد تدفق جهاز تشغيل مواصفة تحويل و طلب تغيير تبديل،`imageCompressionConcurrency` يمكن إعداد نطاق لـ 1 حتى 8، قيمة افتراضية لـ 2. الكل مواصفة تحويل مرفق عنصر دقيق تجهيز إتمام بعد، دفعة مرة ما زال حسب ترتيب إصدار.

طلب كبير صغير offload التزام دوران[حمل دائم صورة حذف قرار](../architecture/2026-09-10-image-offload-events.ar.md). توجيه أصل حسب طلب إصدار بايت و صورة عدد كمية ميزانية فحص إبقاء موضع، عبر `IMAGE_OFFLOAD_REQUIRED` تقرير إبلاغ الذي يحتاج إزالة عدد كمية.Compaction إضافة في `image/offload` في سجل واضح الأكثر قديم صورة ظهور موضع،Session إرسال توليد وقت تطبيق علامة. مهايئ فقط دقيق تجهيز إبقاء مرفق عنصر، سوف كل حمل علامة موضع تصيير لـ يتضمن ذلك هوية و حالي تنفيذ بيئة وصول مسار احتلال موضع نص، تضمين طقم أداة نتيجة صورة أيضا ملائم استخدام. أصلي رسالة حدث إبقاء مرفق عنصر مرجع.

### مستقر جملة مقبض

كل ورقة إبقاء طلب صورة قبل كل لديه عرض اسم أو كامل مرفق عنصر ID، و فعلي طلب مقياس قياس. مرفق عنصر مزود يمكن إعطاء خروج مضيف كائن موضع؛LLM مستهلك سوف ذلك و حالي نظام الملفات خريطة تركيب بعد، مجددا إضافة دخول قطعا مقابل فقط قراءة مسار، مواصفة تحويل مقياس قياس و وسيط جسم نوع. وصف سوف شرح مواصفة تحويل أو طلب إسقاط ممكن تقليص صغير أو إعادة تحرير رمز فوق نقل صورة، لذلك نموذج لا يستطيع من مهمة واحد إصدار دفع قطع فوق نقل صورة أصل هذا خاصية. مستخدم رسالة، أداة نتيجة،agent loop طلب، ضغط و مباشر `ctx.llm.stream` استدعاء مشترك هذا طقم إسقاط. مسار مستقل في تحديد صفة طلب إصدار تحليل، لا دخول ذلك `variantId`، حمل دائم مرجع أو جلسة سجل.

### DeepSeek Files دورة الحياة

مباشر `deepseek-official` مهايئ عبر معتاد عبر الذي اختيار بروتوكول Files API فوق نقل كل ورقة إبقاء طلب إصدار، تزامن إرسال file-id مرجع.[Messages](2026-09-07-deepseek-messages-adapter.ar.md) و Chat Completions مشترك دورة الحياة، كل منها إبقاء طرف نقطة و بروتوكول صيغة. ملف تحليل فشل وقت،[محدود داخل ربط رجوع](../../archived/bug-fix/2026-08-21-deepseek-files-inline-fallback.md) سوف إرسال نفسه تحديد صفة طلب إصدار. افتراضي catalog يأخذ `deepseek-v4-flash-vision-exp` عام نشر لـ دعم حمل صورة. فوق نقل ID حسب Files طرف نقطة و API key أثر مجال و `variantId` كتابة بحث جذب. فوق نقل افتراضي طلب 7 يوم صالح مدة.Chat سجل إرجاع `expires_at`؛Messages بيانات وصفية لا يحتوي مرور مدة وقت، لذلك محلي إعادة استخدام مدة حد استخدام أصلي فوق نقل وقت إضافة إعداد توليد تخزين مدة، لكن لا حفظ إثبات بعيد طرف ملف حذف. محلي خريطة باق بقية إعادة استخدام وقت لا تجاوز مرور واحد صغير وقت وقت سوف مباشر استبدال، لن أولا استعلام بعيد طرف ملف. بحث جذب أبدا تخزين API key.

فقط لديه فوق نقل استجابة إرجاع صالح أصلي ملف كائن، بايت عدد مطابقة، كما عميل تحديد هذا بروتوكول إعادة استخدام مدة حد وقت، فوق نقل نتيجة عندئذ سوف كتابة بحث جذب. ناقص أو لا متسق استجابة لن إبقاء تحت محلي خريطة، لاحق طلب سوف إعادة فوق نقل. نفس أثر مجال و `variantId` تزامن تحليل مشترك مرة مزود فوق نقل؛ مفرد عدد انتظار جهة لا يمكن إلغاء أخرى انتظار جهة، الكل انتظار جهة إلغاء وقت عندئذ سوف إيقاف فوق نقل. صيغة ضرر تالف فوق نقل بحث جذب حسب فارغ ذاكرة مؤقتة معالجة، و في تحت مرة نجاح فوق نقل وقت استبدال؛ نظام الملفات I/O فشل ما زال هو خطأ. إذا نموذج طرف نقطة تقرير إبلاغ ID قد مرور مدة، حذف، ناقص أو بلا فاعلية، و إشارة خروج هذا مرة طلب استخدام واحد أو كثير عدد ID، مهايئ فقط حذف هذه خريطة. إذا استجابة فقط شرح ملف حالة بطلان بينما لا يوجد إشارة خروج أداة جسم ID، مهايئ سوف حذف هذا مرة نموذج طلب استخدام الكل خريطة. تلقي أثر طلب بايت سوف إعادة فوق نقل، نموذج طلب فقط إعادة محاولة مرة. ثاني مرة ما زال تقرير إبلاغ ملف بطلان وقت، مهايئ سوف حسب استجابة تنظيف خريطة و إرجاع خطأ، لن إرسال بدء رقم ثلاثة مرة نموذج طلب. مرة فوق نقل إعداد مقدار خطأ سوف أولا صف خروج إعداد عدد كمية الأكثر قديم `dsh-` ملف، مجددا حذف استلام تجميع إلى ملف و إعادة محاولة مرة؛ قسم صفحة إتمام بعد عندئذ حذف، تجنب تجنب تنقل علامة بطلان. عام ملف عملية توفير قائمة، استعلام، حذف، مفرد عدد تغيير جسم تحرير و كامل أثر مجال تحرير. كل Files طلب كل يحمل Harness مشترك `User-Agent`. عميل تنفيذ Files مفرد مرة فوق نقل 128MiB، طلب مفرد رسم 32MiB،10,000 عدد ملف،25GiB، و واحد صغير وقت إلى 30 يوم صالح مدة حد.

### تشخيص

16-bit RGB أو RGBA PNG يخص عادي يمكن وصل قبول إدخال، سوف تحويل لـ 8-bit sRGB/sRGBA. محلي تحويل فشل وقت،`read_image` سوف كتابة واضح مسار، فحص قياس إلى 16-bit PNG، الذي يحتاج مواصفة شكل صيغة و يد عمل تحويل طريقة. إذا DeepSeek رفض قد مواصفة تحويل طلب إصدار، رئيسي خطأ سوف كتابة واضح مرفق عنصر ID أو عرض اسم، حمل دائم رسالة و صورة موضع، مواصفة تحويل وسيط جسم نوع،8-bit sRGB/sRGBA موضع عميق، مقياس قياس و مزود رسالة. كثير صورة خطأ لا يمكن تحديد كائن وقت سوف صف خروج الكل مرشح صورة. أصلي مزود متن إبقاء لـ خطأ cause، لن يصبح وحيد مرئي رسالة.

حمل دائم مرفق عنصر كائن بعد ناقص أو لا يمكن عبر كامل صفة تحقق وقت، نظام ما زال سوف واضح فشل. حمل دائم عزل و مرور تحقق استعادة حاجة إضافة جديدة جلسة حدث، من[عزل غير ممكن قراءة تاريخ مرفق عنصر](../../proposed/bug-fix/2026-08-20-attachment-read-quarantine.ar.md) متابعة تتبع أثر.

## Alternatives considered

**استخدام واحد نسخة 1MiB مواصفة تحويل مرفق عنصر معا مسؤول تخزين و طلب.** هذا نوع فعل قاعدة يجعل نموذج قسم تمييز معدل قرار حمل دائم صورة دقيق عقدة، و يأخذ محلي تخزين، داخل ربط تمدد انتفاخ،Files إعداد مقدار و نموذج مثل عنصر دمج صار واحد ضبط. مستقل مواصفة تحويل و طلب سياسة سوف واضح منطقة قسم هذه مسؤولية.

**رفض تجاوز مرور مزود مقياس قياس أو بلوغ إلى تحرير رمز جودة كمية تحت حد صورة.** مزود حد يخص أداة جسم توجيه، لم قدوم طلب ممكن تعديل استخدام آخر عدد نموذج. حسب مقارنة مثال مواصفة تحويل و إسقاط طلب إصدار يمكن وصل قبول عادي كبير رسم، معا قيد كل نوع لاحق يمثل.

**يأخذ PNG عند عمل قطع رسم، و رفض 16-bit PNG.** ملف صيغة لا يستطيع شرح مثل عنصر تكرار مختلط درجة،16-bit RGB/RGBA هو يمكن تحويل موضع عميق، لا هو لا دعم حمل صورة نوع. مثل عنصر أخذ مثال و تحويل بعد استكشاف قياس قدرة توفير الذي يحتاج واقع.

**يأخذ DeepSeek data URL بصفة أول اختيار نقل طريقة.** داخل ربط base64 سوف في كل مرة طلب في تكرار بايت، و حسب طلب متن كبير صغير حد متاح صورة تاريخ.Files API مرجع سوف إعادة استخدام فوق نقل بعد تحديد صفة طلب بايت، و حد محلي إعادة استخدام مدة حد، توفير صريح حذف عملية؛ محدود رجوع فقط في ملف تحليل فشل وقت إرسال داخل ربط base64.

**دائم دائم معلومة مهمة محلي بحث جذب في ملف ID.** بعيد طرف مرور مدة، حذف و فوق نقل استجابة فقد فقد سوف جعل محلي و مزود حالة لا متسق. حسب استجابة بطلان و مرة إعادة فوق نقل يمكن استعادة، معا تجنب تجنب بلا حد إعادة محاولة؛ استجابة لا يوجد إعطاء خروج يمكن أمان استخدام دقيق هدف وقت، يجب جعل هذا مرة طلب استخدام الكل ملف بطلان.

**تاريخ في ظهور صورة بعد رفض اختيار صاف نص نموذج.** حمل دائم تاريخ ممكن مقارنة الأكثر أول قراءة هو نموذج تخزين نشط أكثر دائم. حسب طلب توليد احتلال موضع نص يمكن إبقاء جلسة متاح، بلا حاجة تعديل كتابة تاريخ.

**طلب كل مرة تجاوز مرور حد أعلى حينئذ إزالة واحد ورقة صورة.** هذا نوع فعل قاعدة سوف في بضعة نحو كل مرة إضافة جديدة صورة بعد تعديل كتابة مقارنة مبكر طلب رسالة. حسب ثابت خطوة طويل تمرير زيادة إزالة بادئة سوف خفض منخفض ذاكرة مؤقتة بطلان تردد معدل، معا التزام حراسة إعداد حد أعلى.

## Verification

حزمة اختبار سوف توليد 16-bit RGB و RGBA PNG fixture، تحقق 8-bit تحويل و جاف صاف 8-bit بايت مباشر عبر، بايت ضغط قوة تحت إبقاء نفاذ واضح عبر طريق، أول عدد مرشح دمج قاعدة بعد إيقاف تحرير رمز، بايت هدف غير ممكن بلوغ وقت إبقاء الأكثر صغير مرحلة سلم ناتج، صحيح جهة شكل و عرض شاشة 640,000 مثل عنصر إسقاط، نفسه تغيير جسم و فوق نقل singleflight كما لن مشترك إلغاء، تغيير تبديل تزامن حد أعلى، ذاكرة مؤقتة و فوق نقل هوية، قفز مرور قد حمل دائم حذف تاريخ مرفق عنصر قراءة، دفعة كمية فقط دقيق تجهيز مرة،Files استجابة لا متسق، دخول تحديث جديد بقية كمية وقت لا استعلام بعيد طرف و تحديث ID، مفرد عدد ID، كثير عدد ID و نموذج غامض بطلان استجابة فقط استعادة مرة، ملف تحليل فشل بعد رجوع إلى محدود كل داخل ربط طلب، حذف إعداد مقدار ملف قبل إتمام قسم صفحة، مواصفة تحويل مزود تشخيص، صاف نص إسقاط، و عادي طلب و ضغط مشترك طلب بايت. بلا حاجة مفتاح تجميع لقطة تغطية حقيقي أداة schema و صورة طلب مسار. استخدام اعتماد اختبار فقط استخدام داخل وضع `deepseek-official` توجيه و ذلك قد إعداد طرف نقطة، لا استخدام ذاتي تعريف مزود بند.

## Consequences

حمل دائم مواصفة تحويل مرفق عنصر الأكثر كثير احتلال استخدام مستقل محلي أمان حد أعلى، طلب ذاكرة مؤقتة و بعيد طرف Files أيضا سوف احتلال استخدام مقدار خارج إرسال توليد تخزين. تحديد صفة هوية و singleflight جعل هذه صار هذا يمكن يتم مشترك نفس DSH home جولة و جلسة إعادة استخدام. معا تنفيذ اثنان عدد تغيير تبديل سوف خفض منخفض دفعة مرة تأخير متأخر، لكن ذروة قيمة RSS عال في سلسلة سطر تنفيذ؛ داخل تخزين أكثر ضيق ورقة نشر يمكن يأخذ حد أعلى ضبط لـ 1. تحرير رمز جهاز أو تغيير تبديل سياسة إصدار تغير سوف لـ لم قدوم محتوى إنتاج جديد هوية، لن تعديل كتابة قد لديه تاريخ.DeepSeek صورة طلب أولوية إعادة استخدام Files؛ محدود قديم قديم ID استعادة سوف معالجة بعيد طرف حالة لا متسق، ملف تحليل فشل فإن استخدام مقارنة صغير داخل ربط ميزانية. ناقص أو ضرر تالف حمل دائم مرفق عنصر ما زال حاجة مفرد وحيد عزل تصميم.
