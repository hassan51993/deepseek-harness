# Agent Note: DeepSeek طلب مستخدم و جلسة هوية رأس جزء

Status: implemented

[English](2026-08-11-deepseek-request-user-id-header.md) | العربية

## مشكلة

عند استدعاء جهة توفير `GenerateOptions.sessionId` وقت، مباشر وصل DeepSeek طلب قد يحمل `x-deepseek-harness-session-id`، يجعل مزود جانب دعم حمل و تشخيص يمكن صلة ربط نفس محادثة في كثير عدد جولة. لكن طلب نقص قليل عبر جلسة مستقر هوية، بينما harness قد لـ بعيد قياس و عكس تغذية حفظ دائم مجهول اسم مستخدم id. آخر سطر توليد id سوف كسر تالف صلة ربط؛ يأخذ هو وضع دخول مزود غير متصل ملكية مساعد مساعدة دالة، فإن سوف يجعل كل HTTP مهايئ كل إرسال مستقر تدريجي مستخدم معرف.

مستخدم id هو نقل بيانات وصفية، لا هو نموذج إدخال. هو لا نيل دخول طلب جسم، نص التوجيه،token حساب كمية،KV cache هوية أو جلسة سجل. إرسال هدف هو مهايئ تحليل بعد `baseURL`، حيث ممكن هو DeepSeek ذاته، أيضا ممكن هو إعداد شبكة صلة، لذلك يجب واضح خفي خاص حد.

## قرار

`dsh-llm-deepseek` في اعتماد تحليل نجاح بعد إرسال خروج كل مزود طلب فوق إرسال `x-deepseek-harness-user-id`. هذا قيمة قدوم ذاتي `@deepseek-ai/dsh-anonymous-user-id`، لذلك و نفس `$DSH_HOME` OpenTelemetry Resource `user.id` و `/feedback` تأكيد متسق. مهايئ متابعة فقط في وجود `GenerateOptions.sessionId` وقت إرسال `x-deepseek-harness-session-id`؛ عادي agent، عنوان توليد و ضغط طلب من agent loop توفير حالي حفظ دائم `Session.id`.

إضافة في اعتماد تحليل نجاح بعد كسول صفة نيل أخذ مستخدم id، و في هذا إضافة نسخة داخل ذاكرة مؤقتة. نقص قليل اعتماد لن إنشاء `.anonymous-user-id`؛ أي جعل ضبط `DSH_TELEMETRY_DISABLED`، أول عدد قد تخويل مزود طلب ما زال ممكن إنشاء هو. مباشر وصل مهايئ بنية صنع دالة استقبال `resolveUserId` اعتماد، جعل خط مسار سلوك يمكن في اختبار وحدة في إبقاء تحديد صفة.

اثنان عدد رأس جزء كل هو إرسال إلى تحليل بعد `baseURL` نموذج غير ممكن رؤية HTTP بيانات وصفية. هوية قيمة لا في JSON طلب جسم في، أيضا لن يصبح نموذج مرئي إدخال أو جلسة حدث. إعداد شبكة صلة سوف استلام إلى هو جمع. مزود خاص تحديد متن توسيع من [DeepSeek LLM API توسيع قرار](../architecture/2026-08-21-deepseek-llm-api-request-extensions.zh.md) مفرد وحيد يملك. بعيد قياس مشترك فقط تحكم بعيد قياس توجيه خروج، لن منع استخدام مزود طلب هوية.

## تحقق

- mock مزود تأكيد قد تخويل طلب يحمل `getOrCreateAnonymousUserId()` إرجاع نفس مستخدم id، و في لم توفير جلسة id وقت حذف جلسة رأس جزء.
- جلسة هوية خط مسار اختبار تأكيد اثنان عدد رأس جزء كل وجود، و أصل مثال إبقاء نقل دخول جلسة id.
- مباشر وصل مهايئ اختبار تأكيد كل بند stream فقط تحليل مرة مستخدم id،keyless إعداد اختبار فإن إثبات اعتماد فشل لن إنشاء `.anonymous-user-id`.
- حقيقي Loader تركيب اختبار تأكيد تجميع بعد إضافة استخدام مشترك user-id حزمة، بينما غير اختبار مخصص استخدام قيمة.
- بلا حاجة تعديل keyless snapshot، لأن هذه رأس جزء لا هو نموذج مرئي أو مستخدم مرئي transcript محتوى.

## اعتبار مرور بديل خطة

| قد مرفوض | سبب |
|---|---|
| يأخذ id إضافة دخول عام `attributionHeaders()` | هذا مساعد مساعدة دالة هو مزود غير متصل كما ساكن حالة؛ إضافة دخول تدريجي مستخدم قيمة سوف يأخذ هو إرسال إعطاء غير متصل مزود، و مخالفة عكس ذلك تطبيق هوية خفي خاص عقد نحو |
| في `cordis.yml` في إعداد ثابت ذاتي تعريف رأس جزء | نشر إعداد لا يمكن دفع توجيه حالي جلسة id، كما سوف يأخذ مستقر هوية كشف لـ متغير إعداد، بينما لا هو استخدام ذلك الذي تابع وقت التشغيل عقد نحو |
| توليد DeepSeek مخصص استخدام مستخدم id | مزود طلب سوف لا يمكن و نفس harness home بعيد قياس و عكس تغذية صلة ربط |
| مع بعيد قياس مشترك إغلاق هذا رأس جزء | مزود طلب هوية و بعيد قياس توجيه خروج استقبال جهة و هدف مختلف؛ مشترك استخدام فتح صلة سوف إخفاء غطاء حقيقي خفي خاص حد |
| يأخذ id وضع دخول OpenAI توافق `user` أو `metadata` طلب حقل | body حقل ممكن أثر مزود schema، سجل، ذاكرة مؤقتة،token تحويل أو نموذج مرئي إعادة بناء؛HTTP بيانات وصفية يمكن إبقاء مسبق مدة حد |

## عاقبة

- DeepSeek دعم حمل يمكن عبر واحد مجهول اسم harness-home id عبر جلسة صلة ربط طلب، و عبر حفظ دائم session id صلة ربط نفس محادثة.
- أول عدد قد تخويل DeepSeek طلب يمكن مستقل في بعيد قياس توجيه خروج إنشاء `$DSH_HOME/.anonymous-user-id`.
- ذاتي تعريف DeepSeek شبكة صلة سوف استلام إلى مستقر مستخدم id و متاح جلسة id، لذلك تشغيل صيانة جهة يجب سوف إعداد `baseURL` نظر لـ هوية استقبال جهة.
- هوية رأس جزء لن تغيير طلب جسم، نص التوجيه،token عدد،KV cache هوية أو جلسة سجل؛ مفرد وحيد تسجيل DeepSeek متن توسيع إبقاء كل منها اتفاق.
