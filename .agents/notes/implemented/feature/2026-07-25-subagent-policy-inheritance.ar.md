# Agent Note: عملية داخل subagent سياسة وراثة——فرعي agent في أب درجة صندوق رملي تغطية بند تحت بدء

Status: implemented

[English](2026-07-25-subagent-policy-inheritance.md) | العربية

## مشكلة

Auto أو Full access مسبق ضبط هوية و صندوق رملي و مراجعة دفعة تغطية بند كل هو حسب جلسة سجل طي. عملية داخل subagent سوف نيل نيل واحد جلسة جديدة، لذلك spawn فرعي agent(ذكي جسم) مرور ذهاب سوف رجوع إلى نشر قيمة افتراضية،fork فرعي agent فإن فقط قدرة يرى ذلك اكتمل جولة بادئة في تبديل. لذلك، تفويض إرسال ممكن وضع عرض قد تبديل إلى `read-only` أب درجة، أو في Auto و Full access مشترك استخدام نفس دوران زر تركيب وقت ساكن صامت إبقاء قديم قديم هوية.

## قرار

تفويض إرسال حد سوف في رقم مرة await قبل استدعاء مشترك فرعي agent مساعد مساعدة دالة (`dsh-subagent` في `captureDelegatedPolicyOverrides`/`appendDelegatedPolicyOverrides`) ؛ مرة صفة مشغل و[يمكن متابعة بدء](../../../../packages/subagent/subagent/README.ar.md) كل سوف استخدام هو جمع. عند `permissionPresets.current(parent.session)` لـ `auto` أو `danger-full-access` وقت، التقاط سوف نسخ حالي `permission/preset` هوية، معا مقابل `sandboxPolicy.overrideOf(parent.session)` نيل أخذ لقطة، و يأخذ فرعي agent مراجعة دفعة سياسة تثبيت تحديد لـ `'never'`. أب درجة لاحق تبديل يخص أب درجة لم قدوم؛ إلغاء بعد إعادة تفويض إرسال سوف أخذ نيل جديد لقطة. إذن مسبق ضبط و صندوق رملي سياسة خدمة كل هو اختياري: فقط نسخ Auto/Full access مشترك استخدام دوران زر تركيب هوية و صريح صندوق رملي جلسة تغطية بند، أبدا نسخ نشر قيمة افتراضية أو مرة صفة تخويل. مراجعة دفعة سياسة لا وراثة——[مراجعة دفعة تثبيت تحديد قرار](2026-08-10-subagent-approval-pinned-never.ar.md) يحل محل هذا note أصل أولا مراجعة دفعة تغطية بند وراثة.

وراثة Auto أو Full access هوية سوف يصبح واحد بند `permission/preset` حدث، التقاط صندوق رملي قيمة و تثبيت تحديد مراجعة دفعة قيمة فإن سوف في فرعي agent عمل مصنع لم إصدار ضبط مرحلة مقطع يصبح حمل مصدر علامة `sandbox/mode` و `approval/policy` حدث. جلسة بنية صنع دالة قد يأخذ `Session.firstLiveSeq` ثابت في constructor seed بعد، بينما `Session.inheritedEventCount` إبقاء دقيق fork بادئة طويل درجة، لذلك وراثة واقع سوف ترتيب في fork تاريخ بعد، لكن لا تغيير ذلك جدول نظام cut. دورة الحياة محلي بعيد قياس من `firstLiveSeq` بدء، لذلك ترتيب حذف constructor seed، و يتضمن هذه لم إصدار ضبط حدث. لذلك، قائم نهاية حدث فوز خروج طي سوف يجعل تفويض إرسال لقطة ضغط مرور قديم قديم fork تاريخ، و يجعل فرعي agent لاحق تبديل ضغط مرور هذا لقطة. حفيد بديل agent سوف طي ذلك أب درجة قد سجل حالة، لذلك بلا حاجة آخر طقم وراثة آلية يكفي تركيب هذا قاعدة.

Auto review لن يأخذ هذا بند وراثة preset حدث تغيير صار تخويل عودة تنفيذ. كل مرة child استدعاء ما زال سوف إعادة تصنيف: عادي مشروع داخل عمل لـ منخفض ريح خطر و مباشر سماح؛ في ريح خطر عمل يجب في child إنشاء prompt أو قد نواة تحقق human/مباشر أب درجة رسالة في نيل إلى نقطة اسم حركة عمل، دقيق تأكيد هدف و نطاق واضح تخويل، كما لا وجود لم حل قرار اندفاع مفاجئ؛ عال ريح خطر عمل بداية نهاية رفض.`parentSession`، إنشاء prompt و قائم `agent-message.senderSessionId` كاف بـ في one-shot،continuable و cold resume مسار في استعادة هذا نسخة سياق؛ لن إضافة جديدة أب call id، تحليل بعد مهمة metadata، تفويض إرسال سجل،review receipt أو Session format migration.

عادي جلسة إلحاق سوف في إصدار قبل تحقق وراثة حدث، حفظ دائم طبقة فإن في جلسة عام نشر وقت التقاط كامل لم إصدار سجل. لذلك، أي قد شيء تحويل فرعي agent سجل كل سوف في أول دفعة بيانات في تخزين تحت وراثة حدث؛ لا وجود ثاني طقم سياسة تخزين،schema حقل أو استعلام بحث جذب.`source: 'delegation'` علامة يجعل مراجعة دفعة سرد وصف قدرة كاف منطقة قسم وراثة و فرعي agent جانب مستخدم تبديل.

### يتم اعتراض إقامة فرعي agent سوف مرور تاريخ ماذا

تلقي حد فرعي agent سوف نيل إلى عادي رفض علامة، ترقية طلب فإن يتم فرعي agent تثبيت تحديد `'never'` سياسة تحديد صفة رفض؛`subagent:delegation` وقت التشغيل سياق إعلان إبلاغ معرفة فرعي agent فوق تقرير حد بينما لا هو إعادة محاولة، من تحكم جهاز يحتفظ أب agent يمكن وضع عرض ذاتي ذات جلسة بعد إعادة تفويض إرسال ([مراجعة دفعة تثبيت تحديد قرار](2026-08-10-subagent-approval-pinned-never.ar.md)).

[Auto review قرار](2026-08-28-auto-review.ar.md) لـ مشترك Auto/Full access دوران زر تركيب توسيع هذا وراثة قاعدة؛ هذا نص ما زال يملك تفويض إرسال وقت إذن التقاط قرار.

## اعتبار مرور بديل خطة

- **عام `SessionHeader` سياسة حقل**: غير مقبول. هو جمع سوف في بيانات وصفية في نسخ واحد بند حدث تتبع مصدر واقع، و اشتراط اختراق اختراق نواة قلب جلسة نوع، حفظ دائم خلفية، استعلام بحث جذب، اصطدام اصطدام معرف و كل سياسة مستهلك إجراء نقل بث. لم إصدار ضبط مرحلة مقطع حدث أداة تجهيز الذي يحتاج ترتيب، و إعادة استخدام قائم حفظ دائم تخزين.
- **سوف جديد سياسة واقع و بنية صنع تاريخ دمج**: غير مقبول، لأن هذا سوف يأخذ child يملك تفويض إرسال سياسة عودة صنف لـ وراثة تاريخ، و نموذج غامض child لقطة ضغط مرور قديم قديم fork قيمة الذي اعتماد دورة الحياة ترتيب. لم إصدار ضبط يجعل تاريخ و جديد واقع إبقاء في بنية صنع حد كل منها أصل لديه واحد جانب، بلا حاجة مجددا زيادة جلسة خيار؛ بعيد قياس سوف التقاط child ذاتي لديه واحد جانب.
- **أول عدد نص التوجيه مستمع**: غير مقبول. كل إدارة إنشاء أمر خدمة قد سماح في إصدار قبل إلحاق سجل، هو ما زال سوف جذب دخول مستمع ترتيب و أكثر متأخر وقت ترتيب حد.
- **نسخ نشر قيمة افتراضية**: غير مقبول. قيمة افتراضية ما زال من تشغيل صيانة شخص عضو يملك كما ممكن تغير؛ لم تبديل أب درجة لن سجل أي قيمة، لذلك ذلك فرعي agent تتبع مع حالي نشر.
- **كل مرة استدعاء وقت امتداد `parentSession` فوري تحليل**: غير مقبول. هذا سوف ضرب كسر «اثنان عدد جلسة دائم بعيد نظر لا إلى ذاك هذا حالة» عزل ثابت كمية، اشتراط أب جلسة في فرعي agent كامل دورة الحياة داخل إبقاء تحميل، أيضا سوف يجعل أب درجة في فرعي agent تشغيل طريق في فعل تبديل تتبع تتبع صفة أرض تغيير واحد جارٍ تشغيل فرعي agent. تفويض إرسال وقت لقطة عندئذ هو هذا تصميم دلالة: فرعي agent إبقاء هو يتم تسليم وقت سياسة؛ إلغاء بعد إعادة spawn يكفي أخذ إلى استلام ضيق بعد سياسة.
- **قوي صنع استخدام `'never'`**: هذا note عند أول لا بصفة وراثة سلوك قبول، إدارة من هو قوي صنع قيمة سوف ترتيب حذف لم قدوم فرعي agent ينبغي جواب جهاز؛ هذا ربط نقاش قد يتم[مراجعة دفعة تثبيت تحديد قرار](2026-08-10-subagent-approval-pinned-never.ar.md) دفع قلب، الآن سطر إدارة من عودة ذلك كل. يأخذ ask توجيه إلى أصل تحكم جهاز حاجة أب سلسلة كل حق و إرسال بدء spawn `callId`، ما زال حسب[مراجعة دفعة seam Agent Note](2026-07-06-approval-seam.ar.md) الذي وصف تأجيل.

## عاقبة

- spawn،fork و تضمين طقم عملية داخل فرعي agent سوف في أب درجة اختيار في Auto وقت إبقاء ذلك هوية، إبقاء أب درجة صريح صندوق رملي تغطية بند، و يتم تثبيت تحديد لـ `'never'` مراجعة دفعة. تجمع تركيز اختبار طقم عنصر إثبات Auto هوية، حقيقي نظام الملفات رفض، قديم قديم fork أولوية درجة، تفويض إرسال وقت التقاط، فوري حدث حد، قيمة افتراضية حذف و سياق تحرير.
- في Auto تحت، هذه child ما زال سوف لـ كل مرة استدعاء إعادة نيل نيل low/medium/high قرار.human إشارة أمر في في ريح خطر حركة عمل فوق أولوية في مباشر أب درجة مهمة ضبط كامل، بينما كما اثنان نوع مصدر كل لا يستطيع تخويل عال ريح خطر حركة عمل.
- بلا مفتاح headless لقطة هو تجميع بعد تطبيق طبقة وجه ارتداد اختبار: فقط لديه أب درجة هو `read-only`، نشر قيمة افتراضية هو `workspace-write`؛ إذا إزالة التقاط، فرعي agent حفظ دائم حدث و يتم رفض مغناطيس قرص كتابة هذا اثنان بند فحص كل سوف فشل.
- كل مرة تفويض إرسال الأكثر كثير زيادة ثلاثة بند فقط سجل حدث. إذن مسبق ضبط، صندوق رملي سياسة و مراجعة دفعة هذا ثلاثة بند خدمة اختياري peer نوع من `dsh-subagent` يملك——ذلك مشترك مساعد مساعدة دالة يحتفظ `ctx.get` إزالة استهلاك؛ لم تركيب هذه خدمة تركيب إبقاء أصل لديه سلوك. عملية خارج فرعي agent ما زال اعتماد ذاته نشر سياسة، جارٍ تشغيل فرعي agent لا تتبع مع أب درجة لاحق تبديل.
