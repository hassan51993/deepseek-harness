# Agent Note: MCP SDK بروتوكول تنسيق تجارة

Status: implemented

[English](2026-09-12-mcp-sdk-protocol-negotiation.md) | العربية

## مشكلة

MCP خادم استخدام مختلف بروتوكول إصدار. محيط التفاف قديم إصدار SDK تنفيذ اكتشاف و تنفيذ أداة جسر وصل جهاز ممكن متروك تسرب الآن بديل طلب header، حجز قراءة بناء قيام أو بروتوكول تحقق.

## قرار

`dsh-mcp-client` استخدام رسمي جهة TypeScript client 2.0.0 و تلقائي تنسيق تجارة بروتوكول.SDK مسؤول الآن بديل اكتشاف و قديم إصدار ابتدائي تحويل، حسب نقل طريقة تنسيق تجارة، قائمة تغير حجز قراءة، قسم صفحة، طلب header، إلغاء و إخراج تحقق. جسر وصل جهاز استخدام عال طبقة `listTools` و `callTool`، و نحو كل مرة استدعاء نقل تمرير كامل اكتشاف تعريف.

جسر وصل جهاز إبقاء خادم حد تحديد اسم، أصل فرعي تسجيل و حمل دائم صورة وصل قبول. لم إعلان tools قدرة خادم لا إصدار أداة. اكتشاف فشل إبقاء فوق مرة نجاح تسجيل؛ تكرار اسم ما زال رفض جديد تسجيل بديل. صيغة خطأ تنقل علامة سلسلة سوف في SDK صفحة عدد حد أعلى موضع إيقاف؛ جسر وصل جهاز لا زيادة و سطر قسم صفحة تنفيذ.

مراقبة إشراف جهاز في SDK سوف نقل ربط إلى Client قبل حينئذ يحتفظ هذا نقل. تحرير وقت أولا إغلاق لم ربط نقل بـ إلغاء تنسيق تجارة، مجددا انتظار اتصال محاولة تجربة انتهاء، يجعل SDK عودة استلام استكشاف قياس عملية. فشل استكشاف قياس لن إنتاج Client إغلاق حدث؛SDK تنظيف إتمام بعد، هو استخدام صحيح معتاد إعادة محاولة ميزانية. قد ربط اتصال إبقاء إغلاق حدث شاشة عائق، منع توقف خادم عملية إعادة تراكم.

مشترك نتيجة ملائم إعداد دالة نحو كل مزود عودة ضبط نقل تمرير أصلي `ToolExecution`، إبقاء ذلك Agent هوية و إلغاء إشارة. أصلي Cua Driver نتيجة سوف أولا عبر SDK عام مواصفة نوع تحقق، مجددا توليد مواصفة قيمة إسقاط؛ ملائم إعداد دالة لا قبول آخر نوع عرض رخو نتيجة صيغة.

[أداة جسر وصل سجل](2026-07-07-mcp-client-plugin.ar.md) إبقاء مستقل تسمية، أثر مجال و صورة قرار. هذا سجل ضبط كامل ذلك SDK تنفيذ، لا بديل هذه قرار.

## اعتبار مرور بديل خطة

**لـ توافق صفة إبقاء أصلي طلب.** هذا إبقاء عرض رخو خطأ نتيجة معالجة، لكن التفاف مرور SDK مسؤول الآن بديل header و schema تحقق. صالح بروتوكول إخراج أولوية في قديم صيغة `toolResult` بديل نتيجة.

**في جسر وصل جهاز داخل تنفيذ الآن بديل بروتوكول سلوك.** هذا سوف تكرار قد صيانة SDK سلوك، و زيادة واحد نسخة توافق صفة تنفيذ.

## أثر

Stdio تنسيق تجارة بدء يمكن تحرير استكشاف قياس عملية، و انتظار ذلك خروج بعد عندئذ بدء فعلي خدمة عملية.SDK عبر صفحة عدد حد أعلى قيد اكتشاف، صيغة خطأ نتيجة سوف في إسقاط قبل فشل. صالح نص، مواصفة JSON، صورة وصل قبول، إلغاء و تسجيل ملكية ما زال هو جسر وصل جهاز اتفاق. مع مرفق profile يتضمن مشترك مورد وصول؛elicitation،MCP تلميح نموذج لوح و مهمة تنفيذ ما زال لا تلقي دعم حمل.

حقيقي SDK دورة الحياة اختبار تحقق استكشاف قياس تحرير، عملية ترتيب،HTTP استكشاف قياس إعادة محاولة ميزانية و stdio بدء فشل. اتصال مراقبة إشراف جهاز اختبار إبقاء قد ربط نقل إغلاق شاشة عائق و محدود فشل سلوك.
