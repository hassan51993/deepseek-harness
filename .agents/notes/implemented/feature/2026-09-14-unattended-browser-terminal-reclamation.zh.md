# Agent Note: Two-hour reclamation of unattended browser terminals

Status: implemented

[English](2026-09-14-unattended-browser-terminal-reclamation.md) | العربية

## مشكلة

متصفح ممكن في لا يوجد إغلاق طرفية وسم صفحة حال حال تحت إزالة فقد. إذا بداية نهاية إبقاء بلا شخص استخدام طرفية،shell، بعد بديل عملية و شاشة ستار مؤقت اندفاع منطقة سوف بلا حد مدة احتلال استخدام مورد. إخراج حجز قراءة لا يستطيع بديل جدول هل متروك ترك: إخفاء وسم و غير حالي Session دمج إدارة أرض إيقاف تتبع مع شاشة ستار.

## قرار

فقط لديه لا يوجد أي نافذة يحتفظ طرفية، و كما Host حمل متابعة تأكيد فارغ خامل ممتلئ اثنان صغير وقت، عندئذ عودة استلام متصفح طرفية. تشغيل في عمل و لم معرفة نشط حركة كل سوف إلغاء فارغ خامل قطع توقف وقت. عمل إتمام بعد إعادة إعطاء إعطاء كامل عرض حد مدة؛ أمر تنفيذ وقت طويل و بلا إخراج وقت كل لا هو قطع توقف شرط. واضح إغلاق وسم، و Session أو Host إزالة، ما زال لديه حق إنهاء عمل.

| حال حال | سلوك |
|---|---|
| قد اتصال نافذة يحتفظ وسم، يشمل جانب شريط طي أو غير حالي Session | إبقاء طرفية. |
| كثير عدد يحتفظ نافذة في واحد إزالة فقد | فقط يلزم أيضا لديه أخرى نافذة يحتفظ، حينئذ متابعة إبقاء. |
| الأكثر بعد واحد نافذة إزالة فقد وقت، أمر ما زال في تشغيل، إيقاف، انتظار إدخال أو خلفية تنفيذ | إبقاء عمل، لا حد تنفيذ وقت طويل. |
| بلا نافذة يحتفظ، كما واضح تأكيد طرفية فارغ خامل | بدء كامل عرض حد مدة، تنظيف قبل مجددا مرة فحص. |
| نافذة في تنظيف قبل إرجاع | إعادة وصل أصل عملية، إلغاء عودة استلام. |
| حفظ عملية قد لا وجود | إبقاء وسم، عرض محلي تحويل غير ممكن استخدام تلميح و “جديد بناء طرفية”. فقط لديه واضح نقر بعد، عندئذ في أصل موضع استخدام كل جديد هوية استبدال. |

مثال مثل، نافذة في 14:00 قطع فتح، بينما أمر حمل متابعة إلى 20:00، فإن الأكثر مبكر أيضا لا يستطيع في 22:00 قبل عودة استلام. مدة حد من بعد رقم مرة تأكيد فارغ خامل مراقبة بدء حساب حساب.

[جانب شريط](../../../../packages/client/ui-sidebar-right/README.zh.md#state) حسب Session حفظ دائم تخطيط، و عبر `openTabs` إصدار قد حفظ و قد اعتماد Session وسم بيانات وصفية. بدء اكتشاف لن تركيب غير حالي محتوى،pin ملف أو تنشيط Agent. نافذة داخل بـ قد اعتماد store لـ دقيق؛ أخرى نافذة مقابل storage كتابة لا يستطيع سحب إلغاء حالي نافذة نشط حركة يحتفظ علاقة. دائم دائم حذف scope وقت إزالة متبادل ينبغي بيانات وصفية.

طرفية provider سوف هذا بيان و ذاتي ذات حفظ طرفية صلة ربط و لم إتمام إغلاق طلب أخذ تسليم تجميع. كل نافذة لـ كل مختلف طرفية استخدام واحد بند `retain(sessionId, id, signal)` Remote تدفق. تأكيد لقطة منح إعطاء يحتفظ علاقة، لا إرسال شاشة ستار إخراج، لا تنشيط Agent، لا وصل إدارة إدخال، أيضا لا إنشاء عملية. استعادة إخراج قبل انتظار حالي يحتفظ علاقة تأكيد. نقل بديل مرة مستقل إلغاء، نقل تخزين نشط من قائم Gateway إعادة وصل و قلب قفز آلية مسؤول.

subprocess قدرة واجهة توفير حمل حالة و revision `inspectActivity()`. عادي غير تسجيل تسجيل Bash 4.4+ و Zsh دعم حمل صريح تفعيل دورة الحياة سجل، و ربط دمج كامل عملية جدول مراقبة و أصلي عملية هوية.Zsh منطقة قسم فارغ قمة طبقة تحرير تلميح رمز و `vared`، اختيار و متابعة سطر إدخال. إدخال جعل تلميح رمز دليل بطلان؛ خلفية و إيقاف بعد بديل منع توقف فارغ خامل حكم قطع. أصلي Linux أيضا فحص systemd task عدد، حفظ حماية انفصال مغادرة عملية شجرة لكن ما زال في ذاتي لديه scope في بعد بديل. ذاتي تعريف trap،Zsh مختلف خطوة ملف وصف رمز handler، لا دعم حمل بدء طريقة و لا كامل مراقبة إبقاء unknown. دورة الحياة ملف لـ خاص ملف، في تنظيف نجاح بعد حذف.

Host [طرفية تحكم جهاز](../../../../packages/api/terminal-controller/README.zh.md#use-this-package) إدارة يمكن إعداد `unattendedTimeoutMs`(7200000) ،`activityPollIntervalMs`(30000) و `cleanupRetryMs`(60000). صفر فقط منع استخدام تلقائي عودة استلام. تحكم جهاز استخدام مفرد ضبط وقت ساعة؛ مراقبة بين فصل تجاوز مرور جولة استفسار دورة مدة اثنان ضعف وقت، قديم دليل بطلان و إعادة وضع عرض حد مدة. إدخال و يحتفظ علاقة تغير سوف جعل صحيح في إجراء مراقبة بطلان. نهائي فحص عبر بعد، في مختلف خطوة إنهاء قبل سوف هوية علامة لـ إغلاق، منع توقف متأخر إلى إنشاء و اتصال. قد إغلاق هوية لا يستطيع إعادة استخدام، كل تنظيف مهمة بداية نهاية يخص أصل قدوم Session owner.

تنظيف انتظار provider نطاق تماما توقف مستقر و نهائي شاشة ستار إخراج ترتيب فارغ. فشل وقت إبقاء كل حق، رفض جديد يحتفظ علاقة، و أمان ترتيب مرة إعادة محاولة، لا إعادة إعطاء إعطاء فارغ خامل عرض حد مدة. قسم إعداد فشل بعد تنظيف اعتماد نفسه إعادة محاولة سياسة.owner إزالة سوف إيقاف حساب وقت جهاز و تدفق، في تنظيف و مراقبة كل انتهاء بعد عندئذ تقرير إبلاغ فشل، يشمل تنظيف مبكر في مراقبة انتهاء بينما رفض حال حال.Agent طرفية أداة، نموذج إدخال و Session حدث متساو لا تغيير.

Codex خط مسار إزالة،OpenCode Location scope و [VS Code PTY عرض حد مدة](https://github.com/microsoft/vscode/blob/main/src/vs/platform/terminal/node/ptyService.ts) ضبط بحث دعم حمل مستقل مرجع و تأخير متأخر تنظيف تصميم. اثنان صغير وقت هو DSH منتج سياسة، لا هو سطر عمل قيمة افتراضية.[متصفح طرفية قرار](2026-09-09-web-sidebar-terminal.zh.md) و[تخطيط/provider استعادة قرار](../architecture/2026-09-14-sidebar-layout-provider-recovery.zh.md) متابعة صالح، لأن ذلك مورد كل حق و حفظ دائم مسؤولية تخطيط قسم ما زال ملائم استخدام.

## اعتبار مرور بديل خطة

**موحد حساب إخراج حجز قراءة من.** تبديل وسم أو Session سوف إيقاف إخراج حجز قراءة، لكن و لم وضع ترك مقابل طرفية. نافذة يحتفظ علاقة تعديل لـ تتبع أثر تخطيط في فتح وسم.

**قطع فتح ممتلئ اثنان صغير وقت حينئذ قتل إسقاط كل طرفية.** ثابت قطع توقف وقت سوف قتل إسقاط دمج إدارة طويل أمر. لذلك تشغيل في و لم معرفة حالة عمل لا يوجد تلقائي الأكثر طويل تنفيذ وقت.

**أصل حسب ساكن صامت، منخفض CPU أو قبل منصة هوية دفع قطع فارغ خامل.** ساكن صامت بناء، راحة نوم مهمة،shell داخل بناء أمر و انتظار إدخال أمر كل ممكن ممتلئ كاف هذه شرط لكن بعد لم إتمام. يجب معا أداة لديه صحيح وجه دورة الحياة دليل و ذاتي لديه مهمة مراقبة.

**فقط استعادة مرئي Session، أو إبقاء كل حفظ صلة ربط.** قبل من في تحديث جديد بعد فقد فقد غير حالي Session يحتفظ علاقة؛ بعد من يجعل مرور وقت صلة ربط حفظ نشط بلا شخص استخدام عملية. تخطيط و provider تسليم تجميع عندئذ بديل جدول هذا نافذة فعلي فتح وسم.

## نتيجة و بديل قيمة

بلا شخص استخدام فارغ خامل طرفية أداة لديه إبقاء مدة حد، بينما قد اتصال نافذة و طويل مهمة قدرة عبر تحديث جديد و عرض تغير متابعة وجود. تشغيل في، تعليق بدء أو طويل مدة توفير خدمة أمر ممكن بلا حد مدة إبقاء؛ لا دعم حمل shell و لا تحديد عملية مراقبة أيضا هو مثل هذا. ما زال يمكن واضح إغلاق.PowerShell،fish،Windows، ذاتي تعريف shell معامل و مرور مرور sandbox حزمة تركيب بدء حالي إرجاع unknown.

أصل shell خروج لا منح إعطاء إنهاء بعد بديل إذن.Linux عملية قطعة رفع فشل يمثل مراقبة غير ممكن استخدام، بينما لا هو عملية نطاق لـ فارغ؛ نشط حركة إبقاء unknown، تنظيف إبقاء كل حق. واضح لـ فارغ أصلي Linux نطاق و كامل كما لـ فارغ Linux جلسة سماح تنظيف قد خروج سجل.macOS لا يمكن في أصل عملية خروج بعد تأكيد لم مراقبة إلى نطاق، ممكن إبقاء سجل مباشر إلى واضح إغلاق أو owner إزالة.provider مقابل قد هروب هروب كما لم مراقبة إلى بعد بديل حد ما زال وجود؛ دورة الحياة سجل لا هو لأجل منع صد نفس مستخدم سيئ معنى عملية أمان شاشة عائق.

متصفح storage فشل وقت، حالي داخل تخزين حالة ما زال يمكن استخدام، لكن لا يستطيع حفظ إثبات تحديث جديد بعد استعادة غير حالي Session.Host إعادة بدء لا يستطيع استعادة PTY. شاشة ستار تاريخ و كل Session طرفية إعداد مقدار إبقاء أصل لديه حد أعلى، لا إضافة جديدة بلا حد زيادة طويل إلى مدة سبب ذاكرة مؤقتة.

وهمي محاكاة وقت ساعة اختبار تغطية قطع توقف وقت، إعادة وصل تنافس تنازع، مراقبة بطلان و تنظيف إعادة محاولة. حقيقي PTY اختبار تغطية ساكن صامت أمر، داخل بناء أمر، خلفية و إيقاف مهمة،Zsh تحرير نمط، بدء ملف و trap. متصفح اختبار تغطية حفظ دائم تخطيط، كثير نافذة، طي بعد تحديث جديد، نقل في قطع، إبقاء عملية هوية، واضح عملية بعد استبدال بطلان وسم، و نقل في قطع بعد إعادة وصل أصل عملية. بلا حاجة مفتاح قد سجل Session مشهد تحقق ملف معاينة تخطيط استعادة.
