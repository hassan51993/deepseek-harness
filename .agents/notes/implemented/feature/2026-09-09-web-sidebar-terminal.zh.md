# Agent Note: Web sidebar terminals

Status: implemented

[English](2026-09-09-web-sidebar-terminal.md) | العربية

## مشكلة

Web مستخدم حاجة في Session جانب استخدام تفاعل صيغة shell فحص مساحة العمل و تشغيل أمر.Agent حمل دائم طرفية أداة تحكم تلميح رمز و انتظار دلالة نتيجة؛ شخص عمل طرفية حاجة أصلي مفتاح قرص إدخال، صحيح معتاد shell إعداد و كامل شاشة ستار. أمر ما زال في وقت التشغيل، متصفح تصيير و شبكة شبكة اتصال ممكن إزالة فقد.

## قرار

بدء صفحة مدخل إعلان provider داخل مستقر id.keyed `sidebar.right.tab.guide.entry` slot حسب حالي توليد فاعلية provider id توزيع، لذلك بديل builtin extension أيضا تحكم مقابل مدخل تصيير. جانب شريط مسؤول بطاقة ترتيب صف و افتراضي رجوع،provider مكون مسؤول ذاتي ذات تحكم عنصر، و عبر إطار هيكل hook قراءة الذي في وسم صفحة. مدخل slot يمكن تحمل تحميل shell قائمة مفرد، بلا حاجة استبدال كامل بدء صفحة أو يأخذ تفاعل حسب زر تضمين طقم في آخر عدد حسب زر داخل.

تطبيق رئيسي عنوان توفير طرفية افتراضي لون لون. طرفية متن قراءة تحليل بعد CSS أمر لوحة، فقط في لون لون تغير وقت تحديث xterm. عام OSC تحليل مراقبة جهاز سوف بحث جذب لون و افتراضي لون لون تغطية و DSH قيمة افتراضية قسم فتح حفظ؛ إعادة وضع أمر أولا حذف مقابل تغطية، مجددا استعادة حالي رئيسي عنوان. مراقبة جهاز سوف استعلام و لون لون معالجة تسليم إعطاء xterm.xterm الأكثر صغير مقابل مقارنة درجة ضبط كامل تعديل حسن نص حرف يمكن قراءة صفة، معا لا إعادة خريطة ANSI خلف مشهد لون.DOM ضوء علامة في كل مرة تصيير بعد قراءة وحدة إطار فعلي خلف مشهد، عبر نطاق جزء CSS متغير استخدام لديه كاف كاف مقابل مقارنة درجة ملء ملء لون، لذلك ضوء علامة نقل حركة لن إعادة وضع ضبط لون لوح. متصفح فحص تغطية بحث جذب لون، حق لون لون، عكس لون وحدة إطار، واضح داكن رئيسي عنوان تبديل،OSC إبقاء و إعادة وضع، و وميض وميض ضوء علامة مثال صيغة.

`api-terminal-controller` حسب Session إدارة مستخدم طرفية و توفير `terminal` Remote namespace.`ui-sidebar-terminal` تسجيل أصلي يمين جانب شريط وسم صفحة، استخدام xterm.js تصيير و FitAddon قياس كمية مقياس قياس. طرفية بدء صفحة بطاقة رئيسي عملية فتح فوق مرة اختيار كما ما زال متاح shell، مستقل قائمة مفرد توفير قد تثبيت shell. اختيار قائمة مفرد بند سوف سجل مسار و قيام أي فتح جديد طرفية؛ فقط استكشاف قياس shell لا قسم إعداد عملية. كل وسم صفحة يملك ذاتي ذات بدء و إغلاق دورة الحياة.Host استكشاف قياس سوف تحقق إعداد مرشح، و يأخذ تنفيذ بيئة افتراضي بند وضع في أول موضع؛ إنشاء فقط قبول حالي استكشاف قياس إرجاع مسار. متصفح في حالي محطة نقطة localStorage في تسجيل إقامة فوق مرة اختيار shell مسار، هذا مسار غير ممكن استخدام وقت عودة إلى حالي افتراضي بند. طرفية نوع إعلان مستقل نسخة، لذلك فتح أو توقف اعتماد وسم صفحة وقت، عادي صفحة ذهاب إعادة قاعدة لن دمج مختلف عملية. قد لديه جانب شريط تحكم عنصر مسؤول فتح أكثر كثير وسم صفحة، مزدوج ضرب وسم صفحة عنوان يمكن إعادة تسمية طرفية. طرفية عملية استخدام تركيب subprocess provider؛[مستخدم طرفية إذن](../architecture/2026-09-16-user-terminal-permissions.zh.md) قاعدة تحديد ذلك مستقل في Agent تنفيذ إذن.shell في استكشاف قياس و إنشاء وقت تحليل؛ قراءة حد و إعادة اتصال قد لديه عملية لا اعتماد افتراضي يمكن تنفيذ ملف ما زال متاح. تفاعل صيغة shell إعداد توفير Tab تكملة كل و اختياري داخل ربط بناء اقتراح.

إغلاق و استبدال سوف تزامن إزالة وسم صفحة، و في خلفية تنظيف عملية.Client أولا بـ طرفية مستقل localStorage key حفظ لم إتمام إغلاق طلب؛ نجاح بعد حذف، بدء وقت إعادة محاولة باق بقية طلب. تنظيف فشل وقت عرض حمل إعادة محاولة عملية خفيف كمية إشعار، لا إعادة فتح وسم صفحة. مستقل key تجنب تجنب أخرى نافذة تغطية غير متصل تنظيف طلب. طي، تبديل وسم صفحة أو Session، طفو حركة، كل شاشة و متصفح قطع خط متساو إبقاء عملية. مكون تنظيف و `TabDomain.signal` فقط إيقاف متصفح عمل، لأن إضافة إعادة تحميل أيضا سوف انتهاء هذه دورة الحياة. عملية تنظيف فشل وقت إبقاء كل حق، يشمل قسم إعداد إتمام لكن create بعد لم إصدار وقت فشل.Session owner و Host إضافة إزالة أيضا سوف تنظيف طرفية. واضح Session لا وجود استجابة سوف صاف حذف قد حفظ إغلاق طلب، لأن عملية تنظيف من Session مسؤول؛ نقل فشل ما زال يمكن إعادة محاولة.Client إضافة إزالة انتظار كل قطع فتح تدفق انتهاء، تجنب تجنب استبدال إضافة وراثة لم إتمام Client تنظيف.

[جانب شريط تخطيط حفظ دائم و provider استعادة](../architecture/2026-09-14-sidebar-layout-provider-recovery.zh.md) مسؤول متصفح تحديث جديد: أولا استعادة تخطيط و وسم هوية، مجددا من terminal provider إعادة وصل عرض. قائمة ما زال مباشر استخدام Session ID، لأن تاريخ سجل يمكن مقارنة Agent و طرفية owner تخزين نشط أكثر دائم؛ مغادرة خط Session لا يوجد حاجة استعادة إبقاء طرفية. فقط لديه جديد عرض يمكن قسم إعداد عملية، استعادة هدف إزالة فقد وقت عرض خطأ. عملية حالة، عنوان و شاشة ستار محتوى ما زال بـ Host لـ دقيق.

استدعاء من في إنشاء قبل إبقاء طرفية ID. نفسه Session و لم إغلاق ID تكرار create لم يعد قسم إعداد عملية. إنشاء نتيجة لا تحديد وقت، إغلاق ما زال استخدام هذا ID، أي جعل لا يوجد استلام إلى إنشاء استجابة.Host في انتظار قسم إعداد إتمام قبل سجل قد إغلاق ID، منع توقف متأخر إلى create تكرار نشط قد إغلاق طرفية. كل مرة اتصال أولا استقبال متسق، محدود xterm تسلسل تحويل شاشة ستار، لاحق لديه ترتيب إخراج استخدام Gateway قد لديه إعادة استخدام Remote stream. إخراج و شاشة ستار لقطة مشترك عملية طابور صف. حجز قراءة من صحيح معتاد إغلاق وقت إبقاء نهاية ذيل إخراج، ذاكرة مؤقتة تجاوز حد وقت واضح فشل. متصفح في إتمام تصيير بعد تأكيد لقطة، تجنب تجنب React دفعة معالجة فقد فقد زيادة كمية.

الأكثر جديد اتصال تحكم إدخال و مقياس قياس، أخرى اتصال إبقاء فقط قراءة. كل مرة شيء إدارة تدفق بناء قيام كل إنشاء جديد إدخال اتصال معرف، يشمل نقل تلقائي استعادة. إدخال RPC حسب ترتيب إرسال، قديم اتصال نتيجة لا يستطيع يأخذ جديد اتصال تخفيض لـ فشل. طرفية إخراج لا إنتاج نموذج إدخال،Agent أداة نتيجة أو Session حدث.[Agent حمل دائم طرفية قرار](2026-07-16-persistent-pty-sessions.zh.md) ما زال قيد نموذج يملك طرفية؛ هذا وظيفة لـ[يمكن نقل غرس subprocess provider](../architecture/2026-07-28-portable-execution-world-consumers.zh.md) زيادة تنفيذ بيئة واقع و resize. تحكم حق تحويل نقل و عملية خروج توجيه يؤدي رفض فقط منع استخدام إدخال، إبقاء سليم سليم إخراج عرض.Client ذاتي إنتاج خطأ معرف من طرفية UI قلب ترجمة، يشمل اسم مقدار استخدام ممتلئ وقت إغلاق قد إبقاء خروج طرفية تلميح.

## اعتبار مرور بديل خطة

**في متصفح حفظ كامل shell profile.** مستخدم انحراف جيد فقط يتضمن اختيار في مسار. معامل و متاح صفة من Host استكشاف قياس قرار؛ حفظ دائم هذه معلومة سوف يجعل مرور مدة profile التفاف مرور حالي تنفيذ إعداد. طرفية قائمة و وسم صفحة تحكم عنصر ما زال من جانب شريط مسؤول.

**عملية تنظيف إتمام قبل إبقاء وسم صفحة.** مؤقت بطيء أو فشل إنهاء سوف سحب تأخير مستخدم إغلاق عملية. حفظ تنظيف معنى رسم بعد، يمكن قيام أي إزالة وسم صفحة، معا إبقاء خطأ عكس تغذية و إعادة محاولة.

**حفظ دائم بصفة مرجعي نشط وثب عملية سجل التسجيل.** متصفح عملية حالة ممكن مستقل في Host حالة بطلان.[تخطيط حفظ دائم قرار](../architecture/2026-09-14-sidebar-layout-provider-recovery.zh.md) يحل محل لا حفظ وسم صلة ربط حد تحديد، معا إبقاء Host مقابل عملية تخزين نشط حالة قرار حق.

**مشترك استخدام Agent طرفية سجل التسجيل.** تلقي تحكم تلميح رمز و دلالة تحويل send/wait سوف تغيير شخص عمل shell إعداد و خلط خلط عملية كل حق. مستخدم طرفية فقط مشترك subprocess قدرة.

**زيادة مخصص استخدام طرفية WebSocket.** قائم Remote stream قد إدارة إقرار إثبات، إلغاء و إعادة وصل. ثاني بند نقل عبر طريق سوف تكرار هذه مسؤولية.

**فقط إعادة وضع محدود أصلي بايت ذيل جزء.** بايت ذيل جزء ممكن من تحويل معنى تسلسل في بين بدء، أو ناقص تجهيز استخدام شاشة ستار تبديل. تسلسل تحويل طرفية شاشة ستار قدرة في إبقاء محدود تاريخ معا توفير متسق استعادة نقطة.

**React متن أو tab signal إزالة وقت kill.** مكون إزالة،Session تبديل و إضافة إعادة تحميل كل ممكن انتهاء هذه دورة الحياة، بينما مستخدم و لم إغلاق طرفية. تنظيف يجب تتبع مع صريح إغلاق عملية.

**ذاتي بناء Web تكملة كل جذب محرك.** shell أصلي تكملة كل عبر عادي PTY إدخال معالجة أمر، مسار و قد إعداد إضافة. مستقل تكملة كل واجهة حاجة إبرة مقابل shell تحليل و تزامن، لا يخص هذا وظيفة.

## أثر

إبقاء طرفية سوف إبقاء عملية و محدود شاشة ستار داخل تخزين. تحديث جديد استعادة جانب شريط تخطيط و إعادة وصل Host إبقاء طرفية؛Host إعادة بدء لا استعادة عملية.shell خروج بعد إبقاء مرئي، لا تلقائي إعادة بدء. خلفية تنظيف ممكن مقارنة وسم صفحة تخزين نشط أكثر دائم، متصفح تخزين غير ممكن استخدام وقت فقط قدرة في حالي صفحة إبقاء إعادة محاولة قدرة. أصلي PTY دعم حمل و بعد بديل عملية تنظيف حفظ إثبات ما زال من provider قرار. مفرد واحد يمكن كتابة اتصال تجنب تجنب تنافس تنازع إدخال و مقياس قياس تدفق، صريح وصل إدارة سماح من آخر صفحة استعادة عملية.Session صندوق رملي نمط تغيير وقت، مستخدم طرفية إبقاء فتح.

Agent طرفية و يمكن نقل غرس تنفيذ بيئة اثنان مقالة سجل ما زال إبقاء، ذلك كل حق و provider قرار متابعة مستقل صالح، لا يتم متصفح طرفية يحل محل.

[بلا شخص اتصال طرفية اثنان صغير وقت عودة استلام](2026-09-14-unattended-browser-terminal-reclamation.zh.md) في الكل قبل طرف يحتفظ من قطع فتح بعد ضبط فارغ خامل عرض حد مدة، إبقاء مشغول مشغول أو حالة لا تحديد عمل.
