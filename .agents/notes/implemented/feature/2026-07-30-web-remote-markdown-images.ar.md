# Agent Note: Web في بعيد مسار Markdown صورة

Status: implemented

[English](2026-07-30-web-remote-markdown-images.md) | العربية

## مشكلة

assistant Markdown يمكن استخدام معيار صورة لغة قاعدة مرجع رسم جدول و قطع رسم، لكن Web مصير سوف يأخذ كل ورقة صورة استبدال لـ مائل جسم بديل نص. لذلك، أي جعل هدف عنوان هو قطعا مقابل HTTP(S) URL، أيضا لا يمكن نيل نيل عادي Markdown صورة سلوك.

## قرار

`MarkdownText` سوف قطعا مقابل HTTP(S) صورة هدف عنوان تصيير لـ تأخير متأخر تحميل استجابة صيغة `<img>` عنصر عنصر، و استخدام مختلف خطوة حل رمز و `referrerPolicy="no-referrer"`. متبادل مقابل مسار، قطعا مقابل محلي مسار،`file:` URL و لا دعم حمل بروتوكول متابعة امتداد استخدام قائم بديل نص رجوع. أصلي HTML إبقاء منع استخدام، لذلك assistant لا يمكن عبر يد كتابة `<img>` التفاف مرور Markdown صورة مكون.

صورة مكون إعادة استخدام مصير قطعا مقابل URL سياسة، لا إضافة جديدة رئيسي آلة بديل إدارة، محلي ملف توجيه،Session اعتماد، صاف تحويل جهاز أو صورة إمساك أخذ جهاز. اكتمل تاريخ رسالة، تدفق صيغة إخراج، يتم في قطع جزء إخراج و أخرى كل `MarkdownText` مستهلك متساو نيل نيل نفس سلوك.

## اعتبار مرور بديل خطة

**سوف كل صورة كل إبقاء لـ بديل نص.** هذا نوع خطة صيانة حمل الأكثر صغير شبكة حد، لكن لا يمكن ممتلئ كاف في سطر داخل عرض شبكة حمل إدارة نظر شعور ناتج هذا واحد منتج يحتاج طلب.

**عبر رئيسي آلة بديل إدارة بعيد مسار صورة.** بديل إدارة يمكن نحو صورة مصدر محطة إخفاء متصفح شبكة عنوان، لكن هذا سوف يجعل رئيسي آلة تنفيذ مهمة معنى خروج محطة طلب، و كما حاجة مفرد وحيد صنع تحديد إعادة تحديد نحو،DNS، كبير صغير و محتوى سياسة. مباشر تحميل HTTP(S) صورة يمكن يجعل متصفح تحكم آلية متابعة مراقبة هذا طلب؛ لا إرسال referrer يمكن نقص قليل محادثة مصدر معلومة كشف.

**في نفس تغيير في دعم حمل محلي مسار.** Web مصدر لا يمكن مباشر تحميل رئيسي آلة ملف. أمان تنفيذ حاجة مفرد وحيد مراجعة إذن حد، لذلك متبادل مقابل مسار، قطعا مقابل محلي مسار و `file:` URL إبقاء منع استخدام.

**سماح `data:` صورة.** كبير نوع data URL سوف سوف اثنان دخول صنع محتوى بـ نص شكل صيغة تكرار كتابة حفظ دائم transcript(نص سجل). فقط سماح HTTP(S) سياسة كاف بـ ممتلئ كاف حالي يحتاج طلب، كما لن توسيع كبير جلسة سجل.

## عاقبة

assistant عودة تكرار سوف في تدفق صيغة إخراج و إعادة تشغيل خلال عرض بعيد مسار صورة، كما لا تغيير جلسة حدث أو رئيسي آلة بروتوكول. بعيد مسار مصدر محطة ما زال يمكن مراقبة إلى صورة طلب، عميل شبكة عنوان، و متصفح سياسة سماح إرسال إعطاء هذا مصدر محطة أي اعتماد. محلي و لا دعم حمل هدف عنوان ما زال فقط عرض لن إرسال بدء طلب بديل نص.
