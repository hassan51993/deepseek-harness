# Agent Note: PTC mode نوع تحويل أداة قيمة راجعة

Status: implemented

[English](2026-07-20-ptc-typed-tool-returns.md) | العربية

## مشكلة

PTC mode مرور ذهاب سوف يأخذ كل تضمين طقم أداة نتيجة من `ContentBlock[]` إعادة إسقاط لـ واحد نص. هذا مثال رغم لكن إبقاء ملائم دمج شخص صنف قراءة قراءة Native عرض، لكن فقد فقد أداة قد توليد مواصفة نتيجة: برنامج فقط قدرة من ذاتي لكن لغة في رفع أخذ job id و حركة حالة تركيب id؛ بنية تحويل بحث و سير العمل نتيجة فقد ذهاب أصل لديه شكل؛ غير نص كتلة فإن تغيير لـ احتلال موضع رمز. توليد SDK يمكن وصف معامل، لكن بلا نقاش أداة فعلي إخراج لـ أي كل فقط قدرة تحمل وعد `Promise<string>`.

وقت التشغيل أيضا يأخذ ربط قيمة و برنامج نهائي قيمة راجعة عند عمل عرض بيانات. سجل و إتمام قيمة قسم آخر ضبط حد أعلى، توجيه يؤدي مرور كبير أو لا يمكن تغلب ضخم إتمام قيمة ممكن يتم استبدال لـ فحص بعد توليد نص، بينما في بين قيمة هذا قدوم حينئذ لن دخول نموذج سياق. هذا نوع تصميم جعل برنامج تحويل تركيب إنتاج معلومة ضرر فقد، أيضا خلط خلط داخل تخزين حد و نص التوجيه حد.

[مواصفة أداة إخراج اتفاق](../architecture/2026-07-20-canonical-tool-output-contract.ar.md) تأكيد قيام مفرد واحد، مرور مرور تحقق تنفيذ مدة قيمة، و سوف Native مصير و لـ قسم مغادرة.PTC mode ينبغي مباشر إزالة استهلاك هذا قيمة، في عبر تجاوز worker حد وقت كامل إبقاء هو، و كما فقط حد برنامج متعمد إرجاع إعطاء نموذج نهائي إخراج.

## قرار

PTC mode هو مرئي أداة سجل التسجيل نوع تحويل إسقاط. كل نجاح ربط استدعاء كل سوف تحليل لـ post-execute سياسة معالجة بعد نهائي مواصفة `JsonValue`، فشل ربط استدعاء فإن سوف بـ حق صحيح `ToolCallError` رفض Promise. في بين قيمة فقط وجود في هذا مرة تشغيل في، و كامل عبر تجاوز worker حد. خارج طبقة `run_code` سجل، إتمام قيمة أو فشل تشخيص سوف دخول يمكن إعداد إخراج حساب هذا و موجه إلى نموذج إخراج سقوط قرص خط الإنتاج؛ إذا نجاح تسوية فرعي استدعاء نهائي Native محتوى يتضمن صورة، ذلك كامل لديه ترتيب محتوى أيضا سوف مرور أب نتيجة تأخير بعد لـ كتابة سجل كما حمل مصدر ملكية سياق.

هذا وثيقة تعريف تراكم إضافة في أصلي [PTC mode أساس أساس](2026-06-15-ptc.ar.md) لـ فوق قيمة راجعة و فشل اتفاق. موحد واحد schema مفردات من [JSON قيمة schema DSL Agent Note](../architecture/2026-07-20-unified-json-value-schema-dsl.ar.md) مسؤول تعريف؛Native تصيير و سياسة إسقاط ما زال من مواصفة إخراج Agent Note مسؤول تعريف.

### توليد SDK

كل مرة تجميع نص التوجيه وقت، سجل التسجيل كل سوف يأخذ كل مرئي أداة معامل schema و ذلك قسم مغادرة مواصفة إخراج schema إسقاط لـ واحد نسخة تحديد صفة إعلان:

```ts ignore-check
type JsonValue = null | boolean | number | string | JsonValue[] | { [key: string]: JsonValue }

interface ToolArgsMap {
  // one exact inferred entry per visible tool
}

interface ToolOutputMap {
  // one exact inferred entry per visible tool
}

type ToolName = keyof ToolOutputMap

declare class ToolCallError extends Error {
  readonly name: 'ToolCallError'
  readonly toolName: ToolName
}

declare const tools: {
  [K in ToolName]: (args: ToolArgsMap[K]) => Promise<ToolOutputMap[K]>
}
```

`jsonSchemaToTs()` تغطية موحد واحد schema دعم حمل كل عقدة: كائن، عدد مجموعة، نص، عدد حرف، كامل عدد، قيمة منطقية،null، بلا قيد JSON، علامة كمية `enum` و `const`، و `oneOf`. نص التوجيه توليد خلال، لا دعم حمل أصلي بنية سوف رجوع لـ `unknown`، بينما لن توجيه يؤدي تجميع فشل. أداة اسم سوف إبقاء دقيق مفتاح اسم، يشمل يجب استخدام جذب رقم وصول اسم.

### ربط قيمة و فشل

توزيع قبل، جسر وصل طبقة سوف يأخذ ربط معامل لقطة لـ بلا ضرر JSON، مجددا مقابل قسم مغادرة بعد قيمة توليد مرة لقطة، توفير مستقل حمل دائم ملخص حدث استخدام. مضيف جانب قيمة قسم مغادرة، تنفيذ بيانات غير ممكن تغيير معالجة و إخراج schema إسقاط متساو اعتماد تكرار بديل مرة تاريخ، بينما لا استخدام تضمين طقم بنية تحويل تغلب ضخم أو تمرير عودة تجميد ربط.`undefined`، غير لديه حد عدد،`-0`، نادر متباعد عدد مجموعة، حلقة مرجع، دالة و غير عادي كائن كل سوف جعل هذا استدعاء في أداة تشغيل قبل يتم رفض. نجاح توزيع سوف إرجاع `ToolExecutionResult.value`؛Native `content`، بيانات وصفية و داخلي خطأ معلومة لن نقل دخول برنامج. يحتوي صورة نهائي محتوى لا هو ثاني نسخة ربط قيمة: جسر وصل طبقة سوف في خارج طبقة نتيجة بعد تحويل تشغيل هو، جعل تحت مرة نموذج طلب يمكن يرى حمل دائم صورة؛post-execute منع توقف/محتوى استبدال ما زال أداة لديه مرجعي صفة، صاف نص نتيجة لن تكرار.

PTC mode عبر وقت التشغيل طلب في `{ name: "ToolCallError", memberNameProperty: "toolName" }` إعلان ذلك بـ استثناء رفض Promise قدرة. وقت التشغيل Service Definition فقط يأخذ هذه اسم نظر لـ بيانات:worker سوف حركة حالة توليد و حقن حق صحيح لأجل `tools` ربط فشل بنية صنع دالة، لذلك بلا حاجة يجعل عام وقت التشغيل حل أداة،`error instanceof ToolCallError` أيضا قدرة صار قيام.worker استخدام وحدة ابتدائي تحويل وقت التقاط Error بنية صنع دالة و خاصية تعريف داخل بناء طريقة، إعداد دمج أصل نوع لـ null خاصية وصف رمز، بنية صنع فشل كائن و تعريف ذلك عام حقل، لذلك نموذج شفرة تعديل لن يأخذ اتفاق تحمل وعد reject تغيير صار worker فشل. هذا خطأ يتضمن معيار `Error` رسالة و تأكيد قطع `toolName`، و متعمد حذف `ToolFailure.info`، خطأ شفرة و Native محتوى. هذا هو واحد بند لأجل تحكم تدفق استثناء اتفاق، بينما لا هو توفير برنامج تصنيف فشل ربط دمج.

ربط معامل و ربط قيمة راجعة سوف في غير ممكن معلومة worker بروتوكول اثنان طرف إعادة تحقق لـ بلا ضرر JSON، كما لا ضبط بايت حد أعلى. كل قسم مغادرة بعد قيمة في عبر بنية تحويل تغلب ضخم عبر تجاوز حد قبل، كل سوف تحرير رمز لـ مسطح مستو قبل ترتيب token تدفق، ذلك نقل بنية تضمين طقم عميق درجة محدود؛ استقبال جهة مجددا بـ تكرار بديل طريقة إعادة بناء هذا قيمة. لذلك، صالح تطبيق بيانات تضمين طقم عميق درجة حيث لا تلقي JavaScript استدعاء مكدس عميق درجة حد أعلى حد، أيضا لا تلقي خاص تحديد منصة مقابل تضمين طقم بنية تحويل تغلب ضخم تطبيق إضافة حد أعلى حد. وحدة ابتدائي تحويل وقت،worker سوف التقاط ذاته JavaScript تشغيل مجال في `Array.prototype` و `Object.prototype` مرجع، فقط لأجل تعرف آخر أخرى تشغيل مجال عادي حاوية أصل نوع، يمكن نيل أخذ أصلي دالة شفرة المصدر داخل بناء دالة، و JSON حد لأجل بنية معالجة و حساب كمية الكل داخل بناء طريقة. خاصية كتابة استخدام أصل نوع لـ null خاصية وصف رمز؛ داخلي عدد مجموعة و تجميع دمج عملية مباشر استدعاء التقاط طريقة، لن وصول متغير عام أو أصل نوع مجرى موضع. لذلك، أي جعل نموذج شفرة استبدال `Object.keys`،`Array.isArray`، تجميع دمج طريقة، نص طريقة أو `Buffer.byteLength` انتظار مساعد مساعدة طريقة، إعادة كتابة داخل بناء أصل نوع بنية صنع دالة مجرى موضع، أو نحو `Object.prototype` إضافة شكل مثل خاصية وصف رمز حقل، أيضا لن تغيير تحقق، بروتوكول نقل أو بايت حساب كمية. موجه إلى أخرى تشغيل مجال أصلي دالة شفرة المصدر فحص ما زال سوف رفض من مستخدم تحرير كتابة، خطر ملء `Object` أو `Array` بنية صنع دالة. لـ إبقاء اعتماد خفيف كمية، وقت التشغيل Service Definition سوف بنية انتظار قيمة نوع تسمية لـ `PtcJsonValue`، من بينما بلا حاجة اعتماد جلسة جانب يملك مواصفة نوع؛ توليد SDK و أداة API فإن استخدام `JsonValue`. هذه قيمة لن مرور مرور نص التوجيه قطع قطع، سياق spill أو حفظ دائم. لذلك، برنامج يمكن كامل غربلة اختيار قد أخذ تجميع بحث، سير العمل، مهمة، نظام الملفات و MCP قيمة، معا مزود و منفذ أخذ تجميع حد أعلى ما زال سوف فعلي توليد فاعلية.

### خارج طبقة نتيجة و إخراج حساب هذا

وقت التشغيل قبول بـ مهمة معنى JSON نوع لـ أصل دقيق بلا ضرر إتمام قيمة. إرجاع `undefined` يمثل حذف إتمام قيمة؛ إرجاع `null` فإن هو صريح نتيجة.`run_code` كشف مواصفة خارج طبقة قيمة `{ logs: string[], result?: JsonValue }`. ذلك Native مصير أولا إخراج سجل؛ نص نتيجة إبقاء أصل نص، أخرى كل JSON أصل قيمة فإن استخدام تكرار بديل صيغة جميل تحويل مصير. مجموع تقليص دخول طويل درجة حد أعلى لـ 10 عدد محرف، أكثر عميق فرعي شجرة إبقاء ضيق تجميع صيغة، حيث إبقاء قائم ضحل طبقة نص، أيضا تأكيد حفظ مرة تاريخ لا تلقي استدعاء مكدس عميق درجة حد، كما صيغة تحويل إخراج كبير صغير و مواصفة JSON كبير صغير عرض خط صفة علاقة.

`NodePtcRuntime` بـ يمكن إعداد `maxOutputBytes` يحل محل ذاك هذا مستقل سجل و قيمة حد أعلى، قيمة افتراضية لـ `67_108_864` بايت.worker سوف سوف قد التقاط سجل تسلسل تحويل لـ JSON نص بعد دقيق بايت عدد حساب دخول حساب هذا، و في إرسال نهاية حالة رسالة قبل، أصل حسب تركيب حساب هذا باق بقية مقدار درجة مسبق فحص قسم مغادرة بعد إتمام قيمة أو برنامج استثناء. لذلك، أي جعل رمي خروج نص أو كومة مكدس أقصى كبير، عبر worker طرف فتحة أيضا فقط سوف هو ثابت `output-limit` تشخيص. مضيف جانب سوف إبرة مقابل زائف صنع تدفق كمية و worker لا يمكن مراقبة أصلي إدارة طريق كتابة، تكرار تنفيذ هذا طقم موجه إلى غير ممكن معلومة مقابل طرف حساب هذا تحقق. ثابت `PtcRunResult` حقل اسم، زهرة تضمين رقم، محدود خطأ نوع وسم و لاحق عرض فارغ أبيض متعمد لا حساب دخول هذا نسخة متغير سالب تحميل حساب هذا. هذا اثنان عدد مرحلة مقطع كل لن فعلي توليد تجاوز خروج حد أعلى إتمام قيمة تسلسل تحويل نتيجة. نتيجة لا تجاوز مرور حد أعلى وقت سوف إبقاء دقيق. إتمام قيمة لا يمكن عبر بلا ضرر JSON لقطة وقت، بـ `invalid-output` فشل؛ قيمة، تشخيص أو يتضمن سجل تركيب نتيجة تجاوز مرور حد أعلى وقت، بـ `output-limit` فشل، بينما لن تغيير صار فحص صيغة تحويل بعد أو قطع قطع نص.

سجل سوف في إنتاج وقت قيام أي تدفق خروج، لذلك تشغيل يتم إنهاء وقت ما زال يمكن إبقاء قد قبول دخول مقدار درجة إخراج. التفاف مرور worker في قد تعديل كتابة تدفق كتابة مدخل أصلي stdout و stderr كتابة سوف مرور من ذاك هذا مستقل إدارة طريق نقل، لذلك وقت التشغيل في نهاية حالة تسوية خلال ما زال سوف متابعة في حد أعلى داخل التقاط إخراج، مباشر حتى worker تماما إنهاء، لكن بعد عندئذ تجميع نتيجة. تجاوز مرور حد أعلى بعد، وقت التشغيل سوف إرجاع واحد صريح محدود فشل، و يحمل يمكن سعة قبول قد التقاط بادئة. هذا خارج طبقة نتيجة مع بعد عبر عادي `run_code` تصيير و spill سياسة؛ سياسة يمكن حفظ قد التقاط نص، و كشف ذلك إعداد إشارة تحديد رأس ذيل معاينة.spill طبقة لا يمكن استعادة وقت التشغيل في صلب حد أعلى خارج رفض بايت.

حساب حساب وقت، جدار ساعة وقت،worker كومة داخل تخزين، إلغاء و كل مرة تشغيل استخدام كل جديد worker عزل ما زال هو متبادل متبادل مستقل حد. خارج طبقة حساب هذا من لا حساب دخول في بين ربط قيمة، لذلك توليد لقطة، مسطح مستو بروتوكول صيغة تحرير رمز و حل رمز، بنية تحويل تغلب ضخم فتح إلغاء، و عملية أو worker متاح داخل تخزين بنية صار هذه قيمة فعلي حد.

### نوع تحويل جملة مقبض و دورة الحياة

خلفية إنتاج جهة إرجاع نوع تحويل مواصفة جملة مقبض، مثال مثل `{ kind: 'background', jobId }`، معا إبقاء قائم Native لغة جملة. قد مسبق أولا في توقف خلفية استدعاء ما زال هو فشل، لأن نجاح إخراج تحمل وعد إرجاع id، بينما هذا وقت و لم إنشاء مهمة.`ctx.jobs.start()` إصدار id بعد، عمل من مهمة ذاتي لديه إلغاء آلية تحكم: خارج محيط `run_code` استدعاء إتمام، أو مع بعد يتم إلغاء، كل لن إنهاء هذا مهمة. لاحق برنامج يمكن يأخذ إرجاع id نقل إعطاء `job_output`؛ مهمة إلغاء فإن من `job_kill`، كل من dispose(مورد تحرير) أو خدمة teardown مسار مسؤول. قبل منصة تنفيذ ما زال و هذا مرة استدعاء إشارة اقتران دمج. مهمة دورة الحياة اتفاق من[خلفية مهمة وقت التشغيل Agent Note](../architecture/2026-06-20-generic-long-running-tool-runtime.ar.md) تعريف.

مؤقت Cordis إضافة التزام دوران نفس قاعدة:`cordis_mount` إرجاع `{ id, pluginName, state, provides, waitingFor }`، لذلك برنامج يمكن مباشر قراءة `mounted.id`، فحص active أو pending حالة، و يأخذ هذا id نقل إعطاء `cordis_unmount`، بلا حاجة تحليل مستقر Native لغة جملة.

### حفظ دائم، بيانات وصفية و spill

تضمين طقم توزيع في `tool/ptc-dispatch` فوق سجل فرعي استدعاء كامل تصيير بعد `content`/`isError`، لكن لن حفظ دائم مواصفة قيمة.`tool/result` متابعة فقط حفظ دائم تصيير بعد محتوى، خطأ و اختياري بيانات وصفية. يتضمن صورة نجاح نهائي محتوى تسلسل أيضا سوف حزمة تركيب صار حمل مصدر ملكية مستخدم رسالة، و مرور خارج طبقة نتيجة تأخير بعد؛ عادي جلسة حدث جعل هذا نموذج مرئي إدخال يمكن إعادة بناء.[PTC mode note](2026-06-15-ptc.ar.md) مسؤول حمل دائم حدث اسم و تاريخ معرف إبقاء قاعدة؛ إعادة تشغيل لا يمكن إعادة بناء برنامج مواصفة في بين قيمة.

لا نفاذ واضح `exec.parent` token لأجل معرف تضمين طقم استدعاء. عرض بيانات وصفية و عام أو أداة ذاتي لديه spill إسقاط كل سوف قفز مرور هذه استدعاء؛ هو جمع مواصفة قيمة دائم بعيد لن دخول سياق.Client يمكن من أصلي توزيع حدث إرسال توليد[تضمين طقم terminal بطاقة](../bug-fix/2026-09-05-nested-terminal-cards.ar.md) ، بلا حاجة بيانات وصفية. خارج طبقة `run_code` استدعاء إنتاج موجه إلى نموذج نتيجة، و كما ممكن مقابل post-policy معالجة بعد نهائي عرض تنفيذ spill؛`run_code` متعمد حيث لا إعلان نتيجة عرض جهاز، أيضا لا إعلان عرض بيانات وصفية، لذلك UI مهايئ سوف عبر عام أصلي محتوى رجوع آلية، استخدام حفظ دائم `tool/result.content` تكملة كل هذا بطاقة.

## اختبار

تحرير ترجمة مدة اختبار و لقطة اختبار قفل تحديد دقيق `ToolArgsMap`،`ToolOutputMap`،`ToolName`،schema إلى TypeScript تغطية نطاق، خاص خاص اسم، و تجميع بعد PTC mode صورة تحويل إرسال. سجل التسجيل و حقيقي worker اختبار تغطية علامة كمية، عدد مجموعة، كائن و null قيمة؛ نص أصل نص تصيير؛ نقص مقعد `undefined`؛ مستهلك إعلان، فعلي لأجل رفض Promise استثناء صنف، يشمل `ToolCallError`؛ بلا فاعلية معامل و إتمام قيمة، يشمل زائف تركيب لـ داخل بناء أصل نوع زائف صنع أصل نوع؛ نموذج شفرة تعديل مرور JSON حد عام كائن، أصل نوع طريقة، بنية صنع دالة مجرى موضع، و وراثة بينما قدوم خاصية وصف رمز حقل؛ فوق وصف تعديل بعد نوع تحويل ربط فشل؛ لا ضبط حد أعلى كبير نوع في بين ربط قيمة؛ تضمين طقم إخراج سقوط قرص كبح صنع؛ عام يحتوي صورة سياق تأخير بعد و post-execute استبدال/منع توقف أولوية درجة؛64 MiB حد أعلى داخل خارج دقيق حساب كمية؛ سجل، قيمة و تشخيص تركيب حساب كمية؛ رمي خروج تجاوز كبير كومة مكدس؛ محدود فشل إخراج سقوط قرص؛ غير ممكن معلومة مقابل طرف زائف صنع تدفق كمية؛ و بناء بعد حزمة تنفيذ.

بلا مفتاح حقيقي worker اختبار تكامل قفل تحديد ذاتي لكن لغة نتيجة لا يمكن أمان دعم حمل اثنان نوع جملة مقبض سير العمل. خلفية bash استدعاء إرجاع job id، خارج طبقة تشغيل انتهاء، بعد تشغيل مجددا أصل حسب هذا id جولة استفسار مباشر حتى مهمة إتمام؛ أخرى حالة استخدام قسم آخر إثبات، مسبق أولا في توقف لن إنشاء مهمة، إصدار بعد استدعاء إلغاء سوف إبقاء مهمة، قبل منصة تنفيذ ما زال و إشارة اقتران دمج، و كما من `job_kill` مسؤول إلغاء.Cordis برنامج سوف مباشر قراءة active أو pending تركيب id و `waitingFor` حقل، حسب هذا id إزالة، و في لا تحليل تصيير نص حال حال تحت تأكيد تركيب قد إزالة.

## اعتبار مرور بديل خطة

**إرجاع Native نص و مرفق إضافة اختياري JSON:**غير مقبول. برنامج سوف وجه مقابل اثنان طقم متبادل متبادل تنافس تنازع نجاح اتفاق؛ اختياري قيمة لا وجود وقت، ما زال يحتاج استخدام أداة مخصص تابع تحليل قاعدة. مواصفة قيمة عندئذ هو API؛Native محتوى فقط هو هو عرض.

**يجعل كل ربط إرجاع نجاح/فشل ربط دمج:**غير مقبول. فشل لا يوجد مستقر برنامج تحويل تصنيف جسم نظام.reject إبقاء عادي `try`/`catch` تحكم تدفق، و كما فقط كشف أداة اسم و يمكن توفير شخص قراءة قراءة رسالة.

**حد كل في بين ربط قيمة:**غير مقبول. في بين قيمة لن دخول نموذج سياق، مهمة معنى قطع قطع سوف كسر تالف برنامج تحويل تركيب. واضح حد ما زال هو إنتاج جهة أخذ تجميع اتفاق و عملية داخل تخزين.

**ساكن صامت فحص صيغة تحويل أو قطع قطع مرور كبير إتمام قيمة:**غير مقبول. يأخذ JSON قيمة تعديل صار نص قائم ضرر أيضا مخالفة عكس نوع. صريح `output-limit` فشل يجعل نموذج يمكن اختيار إرجاع أكثر صغير نتيجة، بينما إبقاء سجل و تشخيص ما زال يمكن استخدام عادي خارج طبقة spill آلية.

**اشتراط كل وفير غني ورقة فرعي أداة فحص `exec.parent` و ذاتي سطر تأخير بعد.** لا إعطاء اعتماد، لأن هذا سوف يأخذ ورقة فرعي أداة و PTC mode داخلي آلية اقتران دمج، تكرار سياسة معالجة، و متروك تسرب لم قدوم وفير غني أداة. توزيع جسر وصل طبقة مسؤول من قد تسوية نهائي نتيجة عام تحويل إرسال.

**يأخذ Native وفير غني محتوى كشف لـ كل ربط مواصفة قيمة واحد جزء.** لا إعطاء اعتماد، لأن مواصفة قيمة هو بلا ضرر JSON كما من أداة تعريف؛ مرفق عنصر كتلة هو أداة لديه حمل دائم دورة الحياة دلالة نموذج إسقاط. إبقاء قيمة و إسقاط قسم مغادرة، حيث قدرة إبقاء نوع تحويل برنامج، أيضا لن من لاحق نموذج سياق في إسقاط صورة.

## عاقبة

PTC mode برنامج يمكن عبر مستقر قيمة تركيب أداة، بلا حاجة عكس نحو تحليل Native ذاتي لكن لغة.Native و Both Mode إبقاء قائم نص و UI عرض،PTC mode فإن نيل نيل إخراج schema نوع و دقيق وقت التشغيل JSON. أداة عمل من يجب يأخذ مواصفة قيمة نظر لـ برنامج تحويل API، و سوف فقط لأجل عرض صيغة تحويل وضع دخول مصير.

worker سوف بـ تضمين طقم عميق درجة محدود مسطح مستو بروتوكول صيغة نقل بيانات و تنفيذ بلا ضرر تحقق، لكن لن خفض منخفض في بين قيمة فتح إلغاء، أيضا لن جعل ذلك أداة تجهيز حمل دائم صفة. خارج طبقة إخراج فيض خروج سوف صريح توجيه يؤدي تشغيل فشل، خطأ معالجة فإن متعمد من شخص صنف جذب توجيه، بينما لا هو اعتماد حمل إصدار خطأ شفرة ربط دمج.

## معروف حد و مؤقت مؤقت أمر بند

- أي جعل أداة إخراج يمكن اعتماد مهمة معنى JSON أصل،subagent و سير العمل في من استدعاء جهة تعريف بنية تحويل إخراج ما زال عبر مستهلك درجة آخر بوابة إبقاء كائن أصل حد.
- Post-execute قسم آخر توفير قيمة إسقاط و عرض إسقاط؛ استبدال محتوى لا هو حفظ سري آلية، لذلك سياسة إذا يحتاج نحو برنامج تحويل استدعاء جهة إخفاء محتوى، حينئذ يجب منع توقف استدعاء أو استبدال قيمة.
- في بين مواصفة قيمة فقط وجود في تنفيذ خلال، لا يمكن لأجل إعادة تشغيل، لأن حمل دائم حدث فقط تخزين عرض و محدود ملخص.
- في بين قيمة لا يوجد بايت حد أعلى، ممكن بسبب قيمة إبقاء، مسطح مستو بروتوكول صيغة فرعي هذا أو بنية تحويل تغلب ضخم فتح إلغاء بينما استهلاك كل عملية أو worker داخل تخزين.
- 64 MiB صلب حد أعلى فقط ملائم لأجل خارج طبقة متغير سالب تحميل، لا حساب ثابت نتيجة غلاف تركيب لغة قاعدة و عرض فارغ أبيض؛spill لا يمكن استعادة تجاوز خروج هذا حد أعلى بعد يتم رفض بايت.
- مزود أو منفذ أخذ تجميع حد أعلى ممكن في مواصفة قيمة وصول PTC mode قبل حينئذ قد إسقاط جزء مصدر بيانات.
- لا دعم حمل MCP إخراج schema سوف رجوع لـ `JsonValue`؛ قد دقيق دخول MCP صورة استخدام عام تأخير بعد إسقاط، بينما صوت تردد و تضمين دخول مورد تحميل حمل ما زال فقط توفير تشخيص.
- تضمين طقم استدعاء لا يوجد مستقل موجه إلى نموذج نتيجة؛Client فرعي استدعاء بطاقة لن زيادة نموذج سياق.
- PTC mode فشل فقط كشف `ToolCallError` رسالة و أداة اسم، لا توفير برنامج متاح خطأ شفرة ربط دمج.
