# Agent Note: Profile أمر بسيط كتابة

Status: implemented

[English](2026-09-15-profile-command-shorthand.md) | العربية

## Problem

Profile بدء حاجة واحد نوع ملائم لأجل ذاتي تعريف اسم بسيط نظيف كتابة قاعدة، معا لا يستطيع يجعل إضافة إدارة اعتماد Harness home في محتوى.

## Decision

CLI في تحليل قبل، سوف فتح رأس غير خيار كما غير `plugin` معامل توسيع لـ `--profile <name>`. اثنان نوع كتابة قاعدة استخدام نفسه بدء جهاز flag، تطبيق معامل نفاذ نقل و profile تحقق.`plugin` فقط في أول عدد معامل موضع إبقاء أمر أولوية درجة؛`dsh --profile plugin` صريح اختيار نفس اسم profile. اختيار تحديد profile بعد،`plugin` بصفة تطبيق معامل نفاذ نقل. تطبيق معامل بدء قبل، تكرار اختيار profile سوف يتم رفض.

هذا قرار يحل محل[موحد واحد dsh تطبيق بدء جهاز](../architecture/2026-08-22-single-dsh-application-launcher.ar.md) في فقط لـ Web توفير بسيط كتابة آلية؛ هذا Note متابعة مسؤول تطبيق تركيب و دورة الحياة كل حق.

## Alternatives considered

- سوف profile تسجيل لـ أمر حاجة مسح نظام الملفات، و جعل تحليل اعتماد قد تثبيت profile.
- يجعل profile أولوية في داخل وضع أمر، سوف جعل تثبيت profile تغيير إضافة إدارة استدعاء يحتوي معنى.
- يجعل بعد مرة profile اختيار تغطية قبل مرة، ممكن بدء و فتح رأس اسم مختلف تطبيق؛ صريح رفض يمكن تجنب تجنب هذا نوع اختلاف معنى.

## Consequences

ذاتي تعريف و داخل وضع profile مشترك استخدام واحد نوع بسيط كتابة، بلا حاجة إضافة جديدة عام نوع. اسم يجب ضيق تتبع `dsh`؛ لم معرفة اسم سوف إطلاق قائم profile ناقص تشخيص. إزالة مخصص استخدام `web` أمر بعد، قد اختيار تحديد profile أيضا قدرة سوف `web` بصفة تطبيق معامل استقبال. تحليل انتظار قيمة صفة اختبار، بناء ناتج تحقق استلام و بلا مفتاح headless أداة نحو إرجاع مشهد تغطية مشترك استخدام بدء مسار.
