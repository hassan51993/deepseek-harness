# Agent Note: في Trajectory في فحص قد سجل PTC شفرة المصدر

Status: implemented

[English](2026-09-09-ptc-trajectory-code-inspection.md) | العربية

## مشكلة

PTC برنامج بـ JSON نص معامل نقل دخول. تحويل معنى جعل طويل برنامج في عام معامل شجرة في صعب بـ قراءة قراءة، بينما تاريخ استدعاء استخدام وقت التشغيل لغة ممكن مختلف في حالي نشر. سجل نتيجة نص يمكن معا يتضمن ضرب طبع إخراج و قيمة راجعة، لكن لم إبقاء اثنان من قسم حد.

## قرار

[Trajectory](../../../../packages/client/ui-trajectory/README.ar.md) حسب قد سجل أداة اسم تعرف آخر استدعاء، و من قد تحقق `run_code` معامل إرسال توليد شفرة فحص جهاز. تحقق بعد برنامج يحمل أصلي JSON نص؛ نسخ وقت إبقاء شفرة المصدر و معامل بايت، و عبر مستقل تبديل حسب زر عرض أصلي JSON. لغة قاعدة عال مضيء اشتراط هذا استدعاء سجل معامل شرح يتضمن واضح كما بلا اندفاع مفاجئ TypeScript أو Python تلميح؛ لم معرفة أو اندفاع مفاجئ تلميح استخدام صاف نص. لا دعم حمل معامل إبقاء عام فحص جهاز.

نتيجة عرض إبقاء سجل نص، فقط مقابل كامل JSON كائن أو عدد مجموعة استخدام شجرة شكل عرض. خطأ إبقاء قد التقاط إخراج. شفرة عرض في فتح وقت قراءة مشترك تبديل سطر انحراف جيد، و في تركيب خلال إبقاء ذاته اختيار.

[PTC وقت التشغيل قرار](2026-06-15-ptc.ar.md) ما زال مسؤول تنفيذ و تسوية؛[عميل عرض قرار](../architecture/2026-08-23-client-derived-tool-presentation.ar.md) ما زال مسؤول من قد سجل واقع إرسال توليد UI. هذا فحص جهاز لا زيادة Session حدث أو مضيف عرض حقل.

Trajectory تفكير اعتبار افتراضي توسيع، و دعم حمل يد حركة توسيع طي.[Chat توسيع قيمة افتراضية](../bug-fix/2026-09-14-chat-presentation-defaults.ar.md) هو مستقل عرض قرار.

## اعتبار مرور بديل خطة

**يأخذ شفرة المصدر إبقاء في معامل شجرة في.** JSON تحويل معنى حجب حجب برنامج بنية، أيضا جعل نسخ يمكن تنفيذ شفرة المصدر تغيير نيل كثيف تافه.

**استخدام حالي وقت التشغيل لغة، أو من شفرة المصدر دفع قطع لغة.** اثنان نوع طريقة كل ممكن خطأ علامة ملاحظة تاريخ برنامج. قد سجل Schema تلميح قيد عال مضيء، بلا حاجة تعديل سجل.

**تفكيك قسم ضرب طبع إخراج و قيمة راجعة.** تاريخ تصيير نص لا يمكن تحديد اثنان من قسم حد؛ محلل ممكن سند فارغ إضافة إنتاج جهة من لم سجل قسم فصل.

## عاقبة

قراءة من يمكن فحص و نسخ قد سجل برنامج، بلا حاجة تعديل إعادة تشغيل بيانات.Schema لا يوجد يمكن تعرف آخر لغة تلميح وقت لا توفير لغة قاعدة عال مضيء. مكون اختبار تغطية سجل أداة اسم تعرف آخر،Schema رجوع، شفرة المصدر و معامل أصل مثال نسخ، إخراج حالة و مستقل تبديل سطر.JSON شجرة اختبار تغطية قطع قص بضعة أي، نقص قليل `ResizeObserver`، معلق توقف تبديل أو إزالة بعد قص لصق لوح كتابة سقوط تحديد، و معلق توقف خلال قراءة قيمة مرة عدد. تفكير اعتبار اختبار تغطية يد حركة توسيع طي و Trajectory سجل تبديل؛[PTC متصفح مشهد](../../../../apps/web/tests/ptc-round.e2e.ts) ثابت تجميع بعد فحص جهاز عرض، و تحقق فيض خروج و أصلي JSON نحو إرجاع تبديل.
