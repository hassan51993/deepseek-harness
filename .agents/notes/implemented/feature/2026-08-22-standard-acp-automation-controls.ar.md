# Agent Note: معيار ACP v1 تلقائي تحويل تحكم

Status: implemented

[English](2026-08-22-standard-acp-automation-controls.md) | العربية

> هذا شرح فقط يحل محل [ACP بصفة صاف تلقائي تحويل بروتوكول](../simplification/2026-07-23-acp-automation-only-protocol.ar.md) في فقط دعم حمل نص التوجيه بروتوكول بيان. هذا قرار صلة في منع توقف ACP يصبح ثاني طقم منتج UI قاعدة تحديد ما زال أداة مرجعي صفة.

## مشكلة

صاف تلقائي تحويل ACP جسر وصل طبقة يمكن إنشاء جديد جلسة، مرة إيداع واحد نص التوجيه، إلغاء نص التوجيه، استقبال قد إيداع assistant رسالة، و عودة جواب مرة صفة إذن طلب. عام خارجي تلقائي تحويل تحكم جهاز ما زال يحتاج اعتماد خاص عملية معرفة تعرف، عندئذ قدرة اكتشاف نموذج، تركيب MCP خادم، في إعادة بدء بعد بحث إلى حمل دائم جلسة، استعادة جلسة، مستقل إغلاق واحد جلسة، و مراقبة reasoning، أداة أو سياق ضغط قوة دخول درجة. إذا في تجميع صار مخصص استخدام runtime في نسخ هذه تحكم،ACP فقط سوف اسم معنى فوق يمكن متبادل عملية، بينما DSH تلقائي تحويل ما زال اعتماد خاص جانب مسار بروتوكول.

مستقر ACP v1 بروتوكول قد تعريف الذي يحتاج تحكم مفردات. زيادة خاص `_meta`، ذاتي تعريف طريقة، حالة استخدام مخصص استخدام بيئة معالجة أو عرض إسقاط سوف قطع شق هذا مفردات، و إعادة جذب دخول صاف تلقائي تحويل قرار قد إزالة UI اقتران دمج.

## قرار

`@deepseek-ai/dsh-acp` تنفيذ عام تحكم جهاز حاجة كامل معيار ACP v1 تلقائي تحويل فرعي تجميع:`session/new`،`session/list`،`session/resume`،`session/close`،`session/prompt`،`session/cancel`،`session/set_config_option`،JSON-RPC `$/cancel_request`،`session/update` و `session/request_permission`. مستودع داخل كل بند اتصال اثنان طرف كل استخدام `@agentclientprotocol/sdk` 1.4 app/context واجهة.

قدرة سوف حذف لم دعم حمل طريقة و وظيفة.DSH لا زيادة ذاتي تعريف طريقة، قدرة علامة أو `_meta`، أيضا لا لـ عميل بيانات وصفية منح إعطاء خاص يحتوي معنى.`session/load`،`session/delete`،`session/fork`، مرفق إضافة دليل،SSE و ACP نقل MCP، نمط، أمر، حساب تخطيط، طرفية، عميل نظام الملفات عملية و elicitation ما زال لا تلقي دعم حمل. جلسة تحكم و دلالة تحديث هو تلقائي تحويل بروتوكول بيانات؛ هو جمع لن جعل ACP يصبح شخص عمل UI.

## Per-session كل حق

كل قد عام نشر Agent من واحد `AcpSession` وحدة يملك، هذا وحدة معا يملك الذي اختيار نموذج حالة، طلب MCP تركيب، مفرد نص التوجيه مجرى موضع، لديه ترتيب تحديث سلسلة و تسجيل ذاكرة تحويل إغلاق عملية. عام حدث مستمع فقط تعرف آخر تأكيد قطع Agent أو Session، مجددا تفويض حمل إعطاء هذا وحدة. وحدة سوف في داخل تخزين في يأخذ دقيق دخول لقطة و قد تعرف آخر رسالة صلة ربط إلى inbox claim وقت لحظة، مجددا سوف ذلك ثابت إلى قد دقيق دخول جولة. لذلك، صورة قدرة فحص، نص التوجيه متغير، طلب header و كل نموذج خطوة كل استخدام نفس عدد مزود/نموذج/reasoning tuple، بينما عادي حمل دائم مستخدم source إبقاء ثابت. تزامن إعداد تغيير من تحت واحد ACP جولة بدء توليد فاعلية.

صريح `session/close`، اتصال فقد فقد و إضافة تحرير استدعاء نفس عدد إغلاق عملية. هو سوف أولا إلغاء دقيق دخول و Agent عمل، مجددا انتظار؛ مع بعد drain قد إيداع تحديث و يمكن متابعة بعد بديل،flush حفظ دائم، و تحرير Agent scope و ذلك MCP عميل. إغلاق مسار سوف إبقاء حدث توجيه مباشر إلى drain إتمام. فقط لديه كل ذاتي لديه جلسة teardown كل إتمام بعد عندئذ تقرير إبلاغ فشل، أخرى قبل طرف Agent و بعد بديل لا تلقي أثر.

## حمل دائم جلسة تحكم

كامل ACP دورة الحياة دعم حمل اشتراط تركيب جلسة حفظ دائم.`session/list` قراءة قد فعلي جسم تحويل قمة طبقة header، ترتيب حذف نشط حركة جلسة و بعد بديل جلسة، حسب مواصفة شيء إدارة `cwd` مرور ترشيح، حسب إنشاء وقت و id ترتيب ترتيب، و عبر لا نفاذ واضح keyset cursor إرجاع محدود صفحة. ملخص متعمد حذف عنوان و عرض بيانات وصفية.

`session/new` سوف صريح اشتراط حفظ دائم في لا وهمي بنية جلسة حدث حال حال تحت فعلي جسم تحويل live session header، لذلك أي جعل فارغ جلسة أيضا يمكن إغلاق، صف خروج و استعادة. أخرى قبل طرف ما زال إبقاء حفظ دائم seam كسول صفة افتراضي سلوك، لن فعلي جسم تحويل يتم وضع ترك فارغ جلسة.`session/resume` رفض نشط حركة id، و غير قمة طبقة أو لم معرفة حمل دائم id؛ في تركيب Agent قبل تحقق طلب مواصفة `cwd`؛ استعادة حمل دائم سجل لكن لا نحو عميل إعادة وضع؛ تركيب هذا طلب توفير MCP إعلان.`session/close` يجعل حمل دائم سجل يمكن توفير لاحق عملية استخدام.

حفظ دائم متعمد يأخذ `create(meta)` نظر لـ live registration: تسليم JSONL provider في أول مرة إلحاق حدث قبل لا إنشاء artifact. هذا افتراضي سلوك سوف إزالة يتم وضع ترك فارغ جلسة، لكن ACP لا يستطيع وراثة هو، لأن `session/new` سوف في أي نص التوجيه ظهور قبل عام نشر جلسة هوية، بينما عملية ممكن في إرجاع نجاح استجابة بعد، استلام إلى `session/close` قبل إيقاف. جسر وصل طبقة فقط في Agent و MCP تركيب نجاح بعد، إرجاع `session/new` قبل تنفيذ فعلي جسم تحويل؛ تركيب فشل ما زال لا إبقاء تحت ناقص إبقاء شيء، كل قد إرجاع id فإن كل قدرة في إعادة بدء بعد متابعة وجود.

bridge مرور من عادي حمل دائم صفة شاشة عائق فعلي جسم تحويل:`ctx.sessions.flush(session)` مقاومة بلوغ هذا جلسة كتابة جملة مقبض، ذلك `flush` في بعد بلا أي إلحاق وقت كتابة فقط header فعلي جسم تحويل.JSONL كتابة واحد header frame؛ مستودع خارج provider يجب أصل فرعي فعلي جسم تحويل انتظار قيمة header حالة، لا فإن رفض هذا عملية. تكرار استدعاء قوة انتظار. يجعل `create` كل وجه eager سوف تغيير كل قبل طرف وضع ترك جلسة سلوك؛ إلحاق synthetic event سوف فقط لـ إطلاق تخزين بينما وهمي بنية sequence و replay واقع؛ انتظار إلى إغلاق وقت مجددا كتابة فإن سوف يجعل حمل دائم صفة و عملية فقد فقد تنافس تنازع.

## معيار إعداد خيار

بناء اقتراح صفة LLM catalog الآن خدمة في آخر عدد تلقائي تحويل consumer، لكن لن يصبح طلب تحقق.ACP عام حسب مزود قسم مجموعة `model` select، ذلك لا نفاذ واضح قيمة إبقاء مزود/نموذج مقابل؛ أيضا سوف عام قدوم ذاتي قد تحليل تأكيد قطع نموذج اعتماد `reasoning_effort` select. أداة لديه efforts لكن لا يوجد adapter إعداد قيمة افتراضية نموذج سوف يتضمن `Provider default`، بـ إبقاء حذف حالة و يجعل مزود ذاتي سطر اختيار. جديد بناء، استعادة و ضبط استجابة كل إرجاع كامل حالة.Adapter توسيع اندفاع حدث إرسال خروج `config_option_update`؛ كل جلسة حسب استقبال ترتيب سلسلة سطر معالجة تغيير. إعداد ACP مزود/نموذج ما زال هو ابتدائي اختيار؛ لم صف خروج إعداد توجيه سوف دمج صار إلى إرجاع خيار في، بينما لن يتم رفض.

## معيار MCP خريطة

`session/new` و `session/resume` قبول معيار stdio و Streamable HTTP MCP إعلان.Stdio استخدام جلسة `cwd`؛HTTP استخدام قد إعلان URL و header؛ اثنان من كل إبقاء `dsh-mcp-client` مهلة و إعادة وصل قيمة افتراضية. اسم، أمر،URL، بيئة بند،header و تكرار مواصفة تحويل namespace كل سوف في Agent عام نشر قبل تحقق. ابتدائي اتصال أو اكتشاف فشل سوف تراجع بعد لم عام نشر Agent.

MCP namespace reservation تتبع مع الأكثر قريب DSH registration scope، بينما لا هو عملية root. مستقل Agent scope يمكن استخدام نفس خادم اسم، نفس Agent داخل تكرار اسم ما زال سوف فشل.Scoped disposal سوف تحرير أداة، نقل و reservation.

ACP عميل هو تلقي معلومة مهمة تحكم جهاز:stdio إعلان تخويل تنفيذ عملية،HTTP إعلان تخويل يحمل ذلك header إرسال بدء طلب.DSH لا زيادة كل خادم خاص cwd أو مهلة حقل. أداة تركيب بعد، عادي DSH أداة سياسة ما زال قيد استدعاء.

## دلالة تحديث إسقاط

فقط لديه قد إيداع حمل دائم واقع سوف دخول `session/update`.Assistant نص/صورة تغيير صار `agent_message_chunk`؛reasoning تغيير صار `agent_thought_chunk`؛ أداة استدعاء/نتيجة تغيير صار عام `tool_call` و `tool_call_update`؛ معروف قياس كمية سياق ضغط قوة و سعة كمية تغيير صار `usage_update`؛adapter توسيع اندفاع تغير تغيير صار `config_option_update`. حمل دائم رسالة id و أداة استدعاء id إبقاء صلة ربط. مواصفة DSH أداة اسم بصفة معيار أداة استدعاء title.

Per-session سلسلة سوف سلسلة سطر معالجة كل تحديث، و في نص التوجيه إتمام قبل drain. مرجع أداة استدعاء إذن طلب فقط سوف في هذا أداة استدعاء إشعار drain بعد إرسال. أصلي نموذج delta، إعادة محاولة محاولة تجربة، بطاقة، طرفية حالة،diff، موضع، حساب تخطيط، عنوان،todo و لا تلقي دعم حمل محتوى لن دخول wire.

`session/cancel` و `$/cancel_request` دخول نفس عدد نص التوجيه ذاتي لديه إلغاء مسار. صلة ربط ربط ذيل فقط خريطة إلى معيار stop reason و JSON-RPC error؛ نموذج إخراج بلوغ إلى حد أعلى وقت تقرير إبلاغ `max_tokens`.ACP لا إرجاع مقدار خارج DSH نتيجة بنية.

## اعتبار مرور بديل خطة

**زيادة خاص تحكم جهاز توسيع.** قد رفض، لأن معيار ACP v1 قد تحمل تحميل الذي يحتاج دورة الحياة، إعداد،MCP، إلغاء، إذن و دلالة تحديث عام فكرة. خاص توسيع سوف جعل عام SDK عميل لا كامل.

**استعادة قبل تحرير جهاز إسقاط.** قد رفض، لأن حساب تخطيط، طرفية،diff، بطاقة، تنقل و شخص عمل elicitation يخص عرض مسؤولية. دلالة أداة و reasoning واقع يمكن بصفة لديه استخدام تلقائي تحويل بعيد قياس، بينما بلا حاجة استيراد عرض وحدة.

**تنفيذ كل ACP جلسة طريقة.** قد رفض. صف خروج، استعادة و إغلاق قد إتمام حمل دائم تلقائي تحويل دورة الحياة. تحميل/إعادة وضع، حذف و fork سوف جذب دخول هذا حالة استخدام لا حاجة مستقل transcript، كسر تالف صفة تخزين و lineage دلالة.

**استخدام لا مستقر provider طريقة اكتشاف نموذج.** قد رفض، لأن معيار جلسة إعداد خيار يمكن جدول بلوغ هذا اختيار، و إبقاء جلسة scope.

**يأخذ كل DSH runtime حقل نسخ إلى ACP بيانات وصفية.** قد رفض، لأن دقيق token واضح دقيق، خاص نتيجة حالة، برنامج تحويل عرض اسم و كل MCP tunable لا يوجد مستقر ACP v1 مقابل بند.

## تحقق

تجمع تركيز اختبار تغطية: بلا خاص بيانات وصفية تأكيد قطع قدرة عام نشر؛ نموذج/reasoning اختيار، بلا فاعلية و تزامن تغيير، توسيع اندفاع تحديث و صورة توجيه ثابت؛stdio/HTTP MCP ضبط، إعلان تراجع،scope عزل، استعادة و تحرير؛ قائمة قسم صفحة، مواصفة workspace تحقق، نشط حركة اندفاع مفاجئ، إغلاق/استعادة و إعادة بدء استعادة؛ رسالة/تفكير اعتبار/أداة/استخدام كمية ترتيب و id؛ أداة أولا في إذن؛ معيار stop reason؛ طلب و جلسة إلغاء؛ اتصال فقد فقد teardown.

عام keyless conformance اختبار سوف بدء حقيقي ACP demo اثنان مرة، و كما فقط استخدام عام ACP SDK: اختيار نموذج و reasoning effort، تركيب MCP خادم، تنفيذ أداة جولة، مراقبة معيار تحديث، إغلاق، إعادة بدء، صف خروج، استعادة و إلغاء. هو لا يتضمن تجميع صار مخصص استخدام اسم، اعتماد، بيانات وصفية أو بيئة سلوك.

## عاقبة

خارجي تلقائي تحويل مشروع يمكن عبر مستقر ACP v1 استخدام DSH، بينما بلا حاجة صيانة DSH مخصص استخدام runtime بروتوكول. جسر وصل طبقة تحكم واجهة تغيير كبير، لكن ما زال صغير في UI: هو يملك دورة الحياة و دلالة متبادل عملية، بينما شخص عمل عرض و تفاعل ما زال يخص منتج عميل.

حمل دائم دورة الحياة و طلب MCP تركيب يجعل جلسة إنشاء أكثر صارم إطار. إعداد خطأ و ابتدائي MCP فشل سوف في عام نشر قبل رفض، إغلاق سوف انتظار حقيقي تماما توقف مستقر و حفظ دائم. هذا هو تجنب تجنب جزء Agent، تسرب تسرب أداة أو منعزل طفل عملية الذي يحتاج كل حق إثبات.
