# Agent Note:Present التزام دوران Session نظام الملفات وصول قاعدة

Status: implemented

[English](2026-09-09-present-filesystem-access.md) | العربية

## مشكلة

توليد ملف مرور معتاد يقع في مساحة العمل خارج، خاصة ذلك هو `/tmp`. مساحة العمل يتضمن فحص سوف رفض Session نظام الملفات و جانب شريط قد سماح وصول ملف. مزود عملية مسار أيضا ممكن إشارة نحو بعيد طرف ملف، بينما غير خدمة Host فوق ملف.

## قرار

`present` قبول الذي تركيب `ctx.fs` يمكن وصول قد لديه عادي ملف، متبادل مقابل مسار حسب Session عمل دليل تحليل. لا فحص مساحة العمل يتضمن علاقة، أيضا لا آخر ضبط مؤقت دليل أبيض اسم مفرد. ملف ناقص، لـ دليل، نهائي مسار لـ رمز رقم رابط أو مزود خروج خطأ وقت، إعلان فشل. نظام الملفات مزود غير ممكن رؤية صندوق رملي خاص مؤقت ملف ما زال غير ممكن استخدام.

أصلي عملية استخدام و إعلان واحد بدء إرجاع حالي Session header، لـ `workspaceFiles.stat` توفير عمل دليل: أولوية استخدام منها cwd، لم سجل وقت استخدام نشر عمل دليل. جانب شريط معاينة و أصلي تحقق استخدام نفس تركيب نظام الملفات، بلا حاجة بدء Agent، فرعي جلسة أيضا ملائم استخدام. نيل إلى مواصفة تحويل عملية مسار يجب قدرة عبر هذا نظام الملفات من Host مسار خريطة عودة نفس عملية مسار. خريطة ناقص أو مختلف سوف إرجاع 422، و عرض استخدام جانب شريط معاينة محلي تحويل تلميح. هذا فقط دعم حمل مواصفة تحويل بعد و عملية مسار كتابة قاعدة نفسه Host مسار؛ فقط دعم حمل مختلف كتابة قاعدة Host خريطة مزود ما زال يمكن توفير معاينة. لا يوجد خريطة وقت، هذا آلة نفس اسم ملف لا يستطيع بديل مزود ملف.

هذا قرار بديل[مصدر ملف تسليم قرار](2026-09-08-present-workspace-source-files.zh.md) في فقط سماح مساحة العمل ملف وصول قاعدة. أصل شرح متابعة مسؤول لا حفظ محتوى إعلان،Session حدث و تحرير حالي مصدر ملف. طلب ما زال فقط حسب قد حفظ Session، حدث و ملف بحث جذب اختيار ملف، لا قبول متصفح توفير مهمة معنى مسار.

## اعتبار مرور بديل خطة

`/tmp` أبيض اسم مفرد سوف ترتيب حذف أخرى يمكن قراءة إخراج موضع، و تكرار نظام الملفات سياسة. يأخذ كل مزود عملية مسار كل نظر عمل Host مسار ممكن فتح لا متبادل صلة هذا آلة ملف. زيادة عام عكس نحو مسار خريطة API أو نسخ بعيد طرف ملف، سوف يجعل مزود و ملف إبقاء تحمل تحمل مصدر ملف تسليم خارج مسؤولية.

## أثر

مساحة العمل ملف، يمكن وصول مؤقت ملف،Downloads و أخرى مشروع في ملف استخدام نفسه إعلان قاعدة. أصلي فتح معا اشتراط خدمة رئيسي آلة لديه متاح طاولة وجه و مرور مرور تحقق Host مسار. بيانات وصفية فحص لا يستطيع جعل طاولة وجه تطبيق مع بعد حسب مسار فتح ملف عملية أداة لديه أصل فرعي صفة.

تحديد نحو اختبار تغطية مساحة العمل خارج قطعا مقابل و متبادل مقابل مسار، نهائي رمز رقم رابط، ملف ناقص،Session استعلام فشل،Host خريطة ناقص أو لا متسق، و محلي تحويل أصلي عملية غير ممكن استخدام حالة. قد لديه Web تسجيل صنع مشهد متابعة تغطية إعلان، معاينة، أصلي عملية و لا يحتوي ملف محتوى توجيه خروج.
