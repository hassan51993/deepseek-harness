# Agent Note: minimal profile استخدام عار وقت التشغيل

Status: implemented

[English](2026-08-11-minimal-profiles-bare-two-tool-runtime.md) | العربية

## مشكلة

Web `minimal` preset و مستقل JSON-RPC minimal تركيب مقابل خارج توفير حمل دائم `bash` و `str_replace_editor`، لكن دعم دعم خدمة و هدف تدريب تدريب وقت التشغيل لا متسق. اثنان من كل تركيب سياق ضغط، بينما Web preset وراثة مضيف صندوق رملي نظام الملفات،JSON-RPC تركيب فإن تركيب `fs-sandbox` و نظام الملفات سياسة. لذلك، طويل جلسة ممكن استبدال تاريخ سجل، تحرير جهاز أيضا سوف إعلان إبلاغ و فعلي تطبيق عار محلي مشاركة اعتبار وقت التشغيل و لا أداة تجهيز نظام الملفات سياسة.

اثنان بند بدء مسار إعداد كل من أيضا مختلف.Web في قد تشغيل مضيف فوق تركيب تدريجي agent preset،Python SDK فإن ابتدائي تحويل واحد كامل stdio JSON-RPC عملية فرعية. سوف اثنان من نظر لـ يمكن متبادل تبديل نفس عدد Cordis leaf سوف إخفاء غطاء دورة الحياة فرق مختلف، بينما كما SDK عرض مثال لا يوجد عبر بيئة اختيار نموذج أو توجيه النظام مدخل.

## قرار

مع مرفق Web minimal preset مقابل خارج توفير حمل دائم `bash`؛ مستقل profile في Linux/macOS فوق توفير حمل دائم `bash`، في Windows فوق توفير `pwsh`. اثنان من كل لا تركيب سياق ضغط أو نظام الملفات مزود، و لـ جديد بناء جلسة كبح صنع كل `dsh-system-prompt` runtime-context مساهمة.[فقط حمل دائم shell قرار](../simplification/2026-09-03-minimal-profiles-persistent-shell-only.ar.md) من اثنان نسخة تركيب في إزالة تحرير جهاز و ذلك أصل هذا حذف هذا خارج بلا شخص استخدام `fs-local` مزود.Web preset persona متابعة اعتماد مقارنة مبكر [minimal preset تركيب قرار](../../archived/bug-fix/2026-08-10-minimal-preset-owns-rl-composition.md) الذي يملك ثابت complete نص التوجيه، و فقط لـ هذا agent أثر مجال فعلي تطبيق runtime-context كبح صنع. مستقل spine سوف نفس ضبط تحويل إرسال إعطاء ذلك عملية يملك system-prompt خدمة.Web مضيف إبقاء صندوق رملي و دفعة دقيق خدمة؛ مستقل profile تركيب danger-full-access صندوق رملي سياسة، لا تركيب دفعة دقيق خدمة. اثنان من كل لا مساهمة موجه إلى نموذج سياسة سياق.

مستقل [`@deepseek-ai/dsh-sdk-minimal` تركيب حزمة](../../../../packages/bundle/sdk-minimal/README.ar.md) ما زال هو `dsh --profile sdk-minimal` بعد وجه كامل JSON-RPC عملية تركيب. هو تركيب SDK بدء و JSON-RPC خدمة، حسب منصة اختيار حمل دائم shell الذي يحتاج محلي PTY و عملية فرعية خدمة، هذا shell أداة مستهلك، و يقع في `$DSH_HOME/sessions` لم ضغط JSONL حفظ دائم. هو لا تركيب `token-meter`،`compaction-basic`،`fs-local`،`fs-sandbox`،`fs-observation-policy` أو نظام الملفات أداة. حمل دائم shell إزالة استهلاك هذا profile danger-full-access صندوق رملي سياسة.[docs/architecture.md](../../../../docs/architecture.ar.md) مسؤول هذا تركيب حزمة موضع و ذلك و `dsh-base` قسم مغادرة.

`DSH_SYSTEM_PROMPT` اختيار مستقل تركيب persona،`DSH_CONTEXT_WINDOW` لـ لا يوجد تأكيد قطع دليل بيانات وصفية نموذج توفير بعد تجهيز سعة كمية.SDK عميل JSON-RPC `initialize` طلب هو وحيد وقت التشغيل نموذج اختيار.[`minimal.py`](../../../../python/sdk/examples/minimal.py) يمكن فقط يأخذ `DSH_MODEL` قراءة عمل أمر افتراضي `model` معامل؛ صريح `--model` لا حاجة مطابقة عملية فرعية بيئة قيمة. طرف نقطة و اعتماد متغير متابعة من DeepSeek مهايئ قائم بيئة تحليل مسار يحتفظ.

## تحقق

Web إعادة تشغيل سوف بدء كامل Web مضيف، عبر preset خدمة إنشاء agent، و تأكيد لا وجود أثر مجال نظام الملفات أو ضغط خدمة، لا يوجد إلحاق system-prompt يملك runtime-context رسالة، بينما كما تجميع طلب فقط يتضمن ثابت نص التوجيه و حمل دائم Bash. مع بعد، هو عبر حقيقي أثر مجال خدمة تنفيذ حمل دائم Bash.

SDK keyless شفرة المصدر اختبار بدء حقيقي `dsh --profile sdk-minimal`، استخدام بيئة اختيار نص التوجيه إتمام واحد عودة دمج، و تأكيد توليد مفرد تركيب حزمة manifest.Python SDK تحزيم وقت التشغيل لقطة ثابت تجميع نص التوجيه، دقيق مفرد أداة دليل، و ثابت لا وجود أي system-prompt الذي يملك runtime-context رسالة. تحزيم وقت التشغيل تغطية سوف عبر كل نوع متاح تحميل جسم، استخدام بيئة اختيار نموذج، نموذج سعة كمية و نص التوجيه قيمة ابتدائي تحويل مستقل profile، لكن بعد تنفيذ الذي اختيار حمل دائم shell.Cordis تحقق سوف فحص اثنان نسخة إعداد قدرة لا تحليل إعلان إضافة و إعداد حقل.

## اعتبار مرور بديل خطة

**بـ مقارنة عال عتبة قيمة إبقاء `compaction-basic`.** لا إعطاء اعتماد، لأن أي سهل مزود في قصير اختبار في لم إطلاق، مقارنة طويل جلسة ما زال سماح استبدال تاريخ سجل، بينما كما minimal تركيب ما زال سوف اعتماد نموذج سعة كمية بيانات وصفية و token meter.

**إزالة تحرير جهاز بعد إبقاء `fs-local`.** لا إعطاء اعتماد، لأن اثنان نسخة minimal تركيب كل لا يوجد أخرى نظام الملفات مستهلك. إبقاء هذا مزود فقط سوف توسيع كبير وقت التشغيل بيان، لن إضافة جديدة نموذج مرئي قدرة.

**لـ Web و Python SDK بدء استخدام نفس عدد Cordis leaf.** لا إعطاء اعتماد، لأن Web preset نحو قائم كثير جلسة مضيف مساهمة agent أثر مجال خدمة، بينما Python SDK يجب بدء يتضمن JSON-RPC خادم و ذلك عملية درجة اعتماد كامل عملية.

**يأخذ طلب نموذج مرآة مثل إلى `DSH_MODEL`.** لا إعطاء اعتماد، لأن مباشر مهايئ قبول لا في بناء اقتراح دليل في نموذج id، و لـ هو جمع تحليل بعد تجهيز سياق بيانات وصفية. مرآة مثل سوف لـ نفس بند اختيار صنع صنع اثنان عدد إدخال؛SDK ابتدائي تحويل طلب أداة لديه مرجعي،`DSH_MODEL` فقط إبقاء لـ `minimal.py` سهل سريع قيمة افتراضية.

## عاقبة

Minimal جلسة لن ملخص أو استبدال مقارنة مبكر تاريخ، أيضا لن إضافة runtime-context لقطة؛ استدعاء جهة يجب يجعل جلسة جولة إبقاء في الذي اختيار نموذج سياق سعة كمية داخل، كما لا نيل اعتماد نموذج مرئي معتاد إقامة صندوق رملي أو دفعة دقيق سياسة شرح. اثنان بند بدء مسار مشترك مفرد أداة، بلا نظام الملفات، بلا سياق و بلا ضغط حفظ إثبات، معا إبقاء ملائم دمج كل منها كل من مختلف نص التوجيه و نموذج إعداد.Python SDK مسار فقط عبر داخل وضع `dsh` stdio JSON-RPC profile عبر معلومة.
