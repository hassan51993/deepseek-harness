# Agent Note: عام ملف فوق نقل

Status: implemented

[English](2026-08-26-generic-file-upload.md) | العربية

## مشكلة

جلسة يمكن يأخذ لصق لصق أو سحب دخول صورة بصفة حمل دائم مرفق عنصر استقبال، لكن أخرى أي ملف كل دخول لا محادثة:composer رفض غير صورة بايت، وحيد و ملف متبادل صلة مدخل هو `@` مسار مرجع، بينما هو اشتراط ملف هذا قدوم حينئذ قدرة من مضيف مساحة العمل قراءة إلى. مستخدم لا يمكن من متصفح يأخذ PDF، بيانات ملف أو ضغط حزمة تسليم إعطاء ذكي جسم، بينما DeepSeek Chat مستخدم مدة انتظار عودة شكل إبرة إضافة ملف بطاقة فوق نقل تفاعل (#2984).

أمر مستو وجه قد لـ صورة بناء قيام كامل إيداع قاعدة: أمر يجب معا إزالة استهلاك نص و مرفق عنصر، أو واضح رفض كامل مرة إيداع.`input.images` إعلان و فقط دعم حمل صورة RPC تحميل حمل جعل عام ملف في عادي رسالة متاح بعد ما زال مشي مستقل رفض مسار.Plan و goal مدخل حاجة استخدام نفس مرفق عنصر مفردات، معا إبقاء منفذ قوي صنع قاعدة، لا يستطيع ساكن صامت صاف حذف مسودة مسودة.

## قرار

ملف و صورة استخدام مختلف تخزين خطة، و دخول نفس عدد لديه ترتيب رسالة مرفق عنصر قائمة. صورة مواصفة تحويل مرفق عنصر خط الإنتاج إبقاء ثابت. أخرى يتم اختيار في ملف دخول نفس عدد أولا دخول أولا خروج خلفية فوق نقل طابور صف، حسب بايت أصل مثال حفظ كما لا ضبط نوع و كبير صغير حد، مجددا في هذا عملية داخل حسب نفس Session مؤقت تخزين. نفسه بايت في `DSH_HOME/attachments/v1/file-objects/<digest-prefix>/<digest>` تحت فقط لديه واحد مواصفة كائن؛ كل بند نموذج مرئي فقط قراءة مسار `DSH_HOME/attachments/v1/files/<digest-prefix>/<digest>/<name>` كل هو صلب رابط، لذلك مختلف عرض اسم لن نسخ محتوى. هذا طابور صف يمكن إعداد، افتراضي معا تشغيل اثنان بند نقل. مستقل مزدوج طرف `file-upload` Cordis حزمة يملك نقل و مؤقت تخزين. ذلك Client `fileUpload` خدمة معا استقبال الذي تابع Session معرف و `Blob`، دقيق بايت أو فقط قدرة استخدام مرة `ReadableStream<Uint8Array>`؛ هو استخدام هذا معرف تجميع أصلي توجيه طلب، أو مباشر استدعاء توليد Remote. ذلك Host `fileUploads` خدمة يملك تدفق صيغة توجيه، تحرير رمز Remote التقاط قاع، أمر سند إثبات محلل، و بـ استقبال جهة Agent Session كائن لـ مفتاح سند إثبات جدول. تحرير رمز دقيق دخول و مرفق عنصر خطأ تعرف آخر عبر `ctx.attachments` إتمام، بايت تخزين من مرفق عنصر مزود يملك.Session Controller تسجيل لأجل راحة نوم عادي Agent محلل، و في prompt دقيق دخول وقت إزالة استهلاك سند إثبات؛Session كائن لا عام ملف نقل. عادي Web صفحة يأخذ كل نشط حركة طلب جسم تسليم إعطاء مخصص استخدام فوق نقل Worker:Blob طلب جسم عبر XMLHttpRequest إرسال و تقرير إبلاغ يتضمن مجموع كمية بايت دخول درجة،stream فإن تحويل نقل كل حق و زيادة كمية نقل دخول Fetch.Worker-hosted صفحة عبر صفحة ذاتي لديه Fetch تحميل جسم يأخذ طلب جسم تحويل تسليم إعطاء Host Worker، بعد من قراءة محدود قسم قطعة. صفحة خط مسار لا قراءة عام ملف بايت، أيضا لا فعل base64 تحرير رمز أو JSON تسلسل تحويل. مرور مرور إقرار إثبات Host توجيه صريح استخدام Connection تدفق صيغة طلب نمط، لذلك bridge سوف في إزالة استهلاك طلب جسم قبل توزيع، محلي تخزين فإن يأخذ محدود قسم قطعة كتابة خاص مؤقت تخزين كائن و معا حساب حساب ملخص. استقبال إتمام بعد، محتوى بحث عنوان كائن بـ أصل فرعي طريقة إصدار؛ إلغاء أو فشل سوف إزالة مؤقت تخزين ملف. فوق نقل مهمة و مسودة مسودة حالة يخص معتاد إقامة conversation أصل، لذلك قطع إلى آخر بند Session لن إيقاف نقل، إرجاع أصل Session وقت ما زال عرض نفس ورقة ملف بطاقة و حالي دخول درجة. إزالة ملف بطاقة سوف قفز مرور ترتيب طابور في نقل أو في توقف صحيح في تشغيل نقل. إرسال رسالة في `user/message` داخل يحمل بنية تحويل `FileBlock`(`{ name, bytes, attachmentId }`) ، لا إضافة جديدة جلسة حدث نوع.`LlmRuntime` طلب تجميع يأخذ كل ملف كتلة، يشمل تضمين طقم أداة نتيجة في ملف كتلة، إسقاط صار تحديد صفة handle نص، إشارة خروج ملف و ذلك فقط قراءة حفظ مسار.handle سوف اشتراط رئيسي agent تفويض إرسال ملف مهمة وقت مرفق فوق هذا مسار، و في فرعي درجة تنفيذ بيئة نظر لا إلى مسار وقت واضح تقرير إبلاغ. مزود لن استلام إلى ملف بايت، نموذج في حاجة وقت استخدام قائم ملف أداة قراءة تخزين فرعي هذا.

افتراضي نمط، تنشيط Plan Mode و active goal مشترك استخدام عادي queue،follow-up و steer مرفق عنصر دقيق دخول.`/goal` create و edit و `/plan` دخول قبول نفس طقم لديه ترتيب صورة و ملف دفعة كمية؛ يحمل مرفق عنصر تحكم فرعي أمر سوف في حالة تغيير قبل رفض. أمر إيداع مرجع قد إتمام مؤقت تخزين ملف سند إثبات، لن مجددا مرة قراءة أو نسخ عام ملف بايت.Session Controller أولا يأخذ كل ملف سند إثبات تحليل لـ حمل دائم مرجع، مجددا من `ctx.attachments.admitPromptContent()` استقبال كامل لديه ترتيب محتوى قائمة؛ مرفق عنصر دقيق دخول سوف حفظ دائم صورة، و يجعل ملف مرجع أصل مثال عبر. أصل Agent قد إلغاء تدمير وقت،Host سوف رفض إصدار فوق نقل إتمام سند إثبات، و حسب `rpcId` ذهاب إعادة قد وجود prompt إعادة محاولة.prompt سند إثبات في فشل استعادة خلال إبقاء متاح، قد قبول queue أو تاريخ occurrence يتم مراقبة بعد عندئذ تراجع راحة؛ فقط يتم أمر استخدام سند إثبات إبقاء إلى Session إلغاء تدمير. إيداع عودة إظهار في تسلسل تحويل قبل مرور `beginSubmission` تسجيل، عبر `pendingSubmissions` يحمل خلط دمج مرفق عنصر، بـ `rpcId` صلة ربط، في queue أو تاريخ مراقبة بعد فقط تراجع راحة مرة، و في فشل وقت إبقاء مسودة مسودة. إرسال قبل،composer يأخذ لديه ترتيب مرفق عنصر وضع دخول نفس بند لا تبديل سطر أفقي نحو مرفق عنصر شريط: صورة استخدام 64 ركوب 64 مثل عنصر تقليص اختصار رسم، عام ملف استخدام 240 ركوب 64 مثل عنصر بطاقة، حمل 16 مثل عنصر دائرة زاوية، أزرق لون وثيقة رسم علامة، ملف اسم إضافة توسيع اسم و كبير صغير، و معلق توقف أو مفتاح قرص عملية وقت متاح إزالة حسب زر.QueueDock استخدام نفسه ترتيب و ضيق تجميع تقليص اختصار رسم و ملف بطاقة. إرسال بعد،Chat يأخذ لديه ترتيب مرفق عنصر وضع دخول نفس عدد يمين مقابل متساو، يمكن تبديل سطر مرفق عنصر منطقة مجال. فقط لديه واحد ورقة صورة وقت إبقاء صورة رسم ممر كبير رسم مثال صيغة؛ واحد بند رسالة يحتوي لديه كثير عدد مرفق عنصر وقت، صورة استخدام 64 ركوب 64 مثل عنصر تقليص اختصار رسم، ملف استخدام 240 ركوب 64 مثل عنصر بطاقة، ملف و صورة في متاح عرض درجة داخل مشترك استخدام واحد سطر، فضاء لا كاف وقت مجددا تبديل سطر.Trajectory إبقاء ضيق تجميع مستخدم رسالة معاينة، و زيادة محلي تحويل عام ملف عدد كمية. عودة شكل إبرة، سحب جر و لصق لصق حسب MIME تصنيف؛ إرسال سوف انتظار كل ملف فوق نقل إتمام.continuable فرعي بديل إدارة composer منع استخدام مرفق عنصر مدخل،Host سوف رفض استلام إلى أي فرعي جلسة ملف كتلة.

## اعتبار مرور بديل خطة

- **يأخذ فوق نقل تخزين دخول مشروع أصل دليل**(OpenHands / ChatGPT `/mnt/data` شكل). رفض: مستخدم دليل داخل ملف ممكن يتم تحرير، نقل حركة أو حذف، سوف ضرب قطع جلسة سجل مستقر مرجع، تلوث صبغ `git status`، أيضا اشتراط مساحة العمل يجب وجود.`DSH_HOME` استخدام محتوى بحث عنوان حفظ تجميد ربط فقط قراءة بايت؛ تنفيذ عالم حد مرئي صفة من إسقاط مسار توفير، بعد أيضا يمكن تكملة واحد خطوة نسخ صدفة دخول مساحة العمل.
- **مخصص استخدام `read_file` أداة.** رفض:handle نص إشارة نحو واحد بند عادي مسار، قائم `read` أداة (و نموذج أخرى ملف أداة) قد تغطية هو؛ مجددا إضافة واحد قراءة أداة فقط سوف قسم شق نموذج سلوك بينما لا زيادة قدرة.
- **يأخذ محتوى عاجل قطع حقن نص التوجيه.** مقابل ملف رفض إدارة من و عند سنة مقابل `@` مرجع تماما نفسه ([web ملف مرجع](../../archived/feature/2026-07-27-web-file-and-session-references.md)): مرفق إضافة وقت متبادل صلة صفة لم معرفة، كسول صفة أداة قراءة يجعل كل مرة محتوى وصول كل إبقاء في سجل داخل.
- **نوع أبيض اسم مفرد و كبير صغير حد أعلى.** الآن مرحلة مقطع رفض:DeepSeek Chat أبيض اسم مفرد وجود هو لأن ذلك خدمة طرف يلزم تحليل فوق نقل، بينما هذا harness فقط تخزين بايت، يجعل نموذج ذاتي ذات قراءة. تدفق صيغة تحميل جسم و تخزين يجعل داخل تخزين احتلال استخدام و محدود قسم كتلة كبير صغير متبادل صلة، لذلك حد أعلى يخص مغناطيس قرص و نقل سياسة، لا لأجل حفظ إثبات طلب أمان.
- **إضافة جديدة attachment/file جلسة حدث.** رفض: صورة قد اعتماد «كتلة داخل ربط في `user/message`» نمط يكفي ممتلئ كاف نموذج مرئي ⟺ يمكن سجل إعادة بناء، بلا حاجة توسيع كبير حدث مفردات.
- **لديه مرفق عنصر وقت منع توقف كل أمر.** رفض:`/goal` هدف و `/plan` دخول حاجة مشاركة اعتبار ملف، موحد واحد رفض سوف جعل هذه ملف لا يوجد دخول نموذج أمر مسار.
- **أي أمر نجاح بعد تلقائي إرسال مرفق عنصر.** رفض:`/model` و `/compact` انتظار حالة أمر لا يمثل نموذج مرئي إدخال. مرفق عنصر هل يصبح مستخدم رسالة من أمر إنتاج جهة مسؤول.
- **يأخذ هدف مرفق عنصر تخزين دخول goal مجال.** رفض: واحد بند عادي قد سجل مستخدم رسالة حينئذ قدرة يجعل لاحق Goal Round نيل نيل نفسه تاريخ، بلا حاجة توسيع كبير goal schema أو يأخذ مرفق عنصر نسخ دخول Round نص التوجيه.
- **أي أمر نجاح كل إزالة استهلاك مرفق عنصر.** رفض:`/goal pause` أو `/plan off` سوف صاف حذف غير متصل بطاقة. فقط لديه إنتاج جهة واضح نجاح عندئذ إزالة استهلاك مرفق عنصر؛ لا يمكن استخدام مرفق عنصر لغة قاعدة شكل صيغة إرجاع خطأ.
- **فقط في عميل تنفيذ إعلان.** رفض: مباشر RPC استدعاء جهة يمكن التفاف مرور composer.`CommandRuntime` في معالج تشغيل قبل قوي صنع فحص إعلان، تخزين متاح صفة، نفس Session ملف سند إثبات تحليل، صورة base64 دقيق دخول و صورة حد.
- **عبر `ctx.connection` كشف فوق نقل و امتداد Session منشئ نقل تمرير هذا كائن.** رفض:Connection لا يملك ملف نقل، في بين كائن طبقة أيضا لا استخدام هذا بند اعتماد. مستقل فوق نقل خدمة مباشر استقبال Session معرف، و سماح عادي متصفح و Worker-hosted صفحة استبدال تحميل جسم، بلا حاجة توسيع كبير Connection أو Session.

## عاقبة

- فوق نقل بايت دائم لا حذف كما لا يوجد كبير صغير حد أعلى،`DSH_HOME` زيادة طويل بلا حد؛ نفاية قمامة عودة استلام و صورة إبقاء مشكلة واحد نفس متابعة تعليق بدء.
- إسقاط مسار فقط في مقابل تنفيذ بيئة في صالح: لا يمكن خريطة `DSH_HOME` صندوق رملي أو بعيد مسار نظام الملفات سوف نيل إلى صريح بلا مسار handle، نموذج سوف تقرير إبلاغ لا يمكن قراءة هذا ملف. أساس في تخزين قراءة التقاط قاع يتم دفع متأخر.
- مؤقت تخزين فوق نقل حسب Session وجود Host داخل تخزين داخل؛ فوق نقل و إرسال بين Host إعادة بدء سوف ظهور `FILE_NOT_STAGED`، عميل إعادة إضافة ملف يكفي.
- متصفح إلى Host نقل استخدام مرة لا حمل قطع نقطة متابعة نقل انحراف نقل تدفق صيغة HTTP طلب؛ اتصال أو Host فشل بعد إعادة محاولة سوف من رقم واحد بايت إعادة نقل كامل ملف.
- `ReadableStream` فوق نقل فقط إزالة استهلاك و تحويل نقل مرة stream؛ إعادة محاولة يجب إعادة إنشاء stream، بينما كما في لم قدوم API سماح إنتاج جهة توفير طويل درجة قبل، دخول درجة لا يستطيع تقرير إبلاغ مجموع كمية.
- متصفح فوق نقل Worker من ذاتي يتضمن دالة نص شكل صيغة توليد. حاجة وقت التشغيل import وقت، يجب تعديل استخدام من tsdown تحزيم مستقل Worker مدخل.
- أمر يجب إعلان قبول مرفق عنصر. أمر رفض وقت إبقاء نص مسودة مسودة و الكل مرفق عنصر بطاقة، توفير مستخدم إعادة محاولة.
- فرعي بديل إدارة لا مستقل فوق نقل ملف. رئيسي agent تفويض إرسال وقت نقل تمرير حفظ مسار؛ فقط لديه نفس آلة أو وراثة أب درجة تاريخ كما تنفيذ بيئة قدرة خريطة هذا مسار فرعي درجة يمكن قراءة.
- فوق نقل ملف بعد لم دخول `@` تكملة كل؛ هذا ربط حركة هو حساب تخطيط في لاحق مرحلة مقطع.
- أمر سجل التسجيل دقيق دخول حمل نوع علامة `CommandSubmitAttachment` ربط دمج نوع، منها ملف عضو يحمل مؤقت تخزين سند إثبات، مجددا نحو معالج توفير واحد تجميد ربط لديه ترتيب `ImageBlock | FileBlock` عدد مجموعة. سجل التسجيل لا أمان ترتيب نموذج إدخال؛`/goal` زيادة واحد بند قد سجل follow-up،`/plan` steer لديه ترتيب مرفق عنصر كتلة.
- من قائمة مفرد اختيار نابض نافذة أمر لن إيداع composer كامل طقم محتوى. مرفق عنصر إبقاء مرئي، مباشر إلى مستخدم إيداع أمر سطر أو إزالة مرفق عنصر.
- إعلان، تخزين ناقص، لم معرفة سند إثبات و صورة حد رفض حدوث في معالج تشغيل قبل. إنتاج جهة لغة قاعدة رفض و صورة دقيق دخول بعد إلغاء ممكن إبقاء تحت بلا مرجع محتوى بحث عنوان كائن، من لاحق مرفق عنصر نفاية قمامة عودة استلام معالجة.

## اختبار

وحدة و تجميع صار تغطية أصل مثال و تدفق صيغة تخزين، ملف اسم صاف غسل، إعلان لـ 2.19 GiB طلب عبر تدفق صيغة bridge كما لا حدوث مجموع كمية مؤقت اندفاع، أصلي بايت و RPC wire دقيق دخول،Blob و يمكن تحويل نقل `ReadableStream` تحميل جسم، خلفية فوق نقل تزامن حد أعلى، دخول درجة و إلغاء، عبر Session فوق نقل معتاد إقامة، أمر عبر ملف سند إثبات إيداع كما لم يعد مرة قراءة بايت،read-only و workspace-write إذن تحت native و PTC إسقاط، فوق نقل مؤقت تخزين، لديه ترتيب queue و steer إيداع، طابور صف تحويل steer،pending عودة إظهار تراجع راحة و فشل استعادة،active plan و goal مرفق عنصر مدخل،`/plan` و `/goal` خلط دمج مرفق عنصر، فرعي بديل إدارة رفض،composer و Chat مرفق عنصر تخطيط، و Trajectory ملف ملخص.keyless `file-upload-round` لقطة سجل متصفح فوق نقل، نموذج قراءة ملف و جواب سجل عرض.
