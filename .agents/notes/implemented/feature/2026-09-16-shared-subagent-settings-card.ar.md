# Agent Note: موحد واحد Subagent ضبط بطاقة

Status: implemented

[English](2026-09-16-shared-subagent-settings-card.md) | العربية

## Problem

تفويض إرسال حد و نموذج تخويل وصف هو نفس طقم Subagent سير العمل مسار، لكن قسم فتح ضبط بطاقة يجعل مستخدم يجب قسم آخر فحص بحث و حفظ.

## Decision

واحد Subagent صفحة مجموعة نسج تفويض إرسال حد و نموذج اختيار، مشترك استخدام واحد حفظ حسب زر. مغادرة فتح صفحة سوف إسقاط اثنان عدد مسودة مسودة. اثنان عدد قائم تحكم جهاز ما زال كل منها يملك مسودة مسودة، تحقق و نطاق الأسماء كتابة. مهمة واحد مسودة مسودة بلا فاعلية أو اندفاع مفاجئ وقت، بطاقة منع توقف حفظ؛ حفظ خلال منع استخدام اثنان عدد قسم منطقة؛ اثنان من متساو نجاح إتمام بعد ما زال إبقاء فتح. فشل قسم منطقة إبقاء مسودة مسودة بـ توفير إعادة محاولة. حد شرح عبر حقل اسم جانب معلومة حسب زر حسب يحتاج توسيع، استخدام أداة جسم طبقة درجة عرض مثال و حساب عدد قاعدة. تحقق خطأ ما زال مباشر عرض، تجنب تجنب طي شرح بعد إخفاء منع توقف حفظ سبب.

إضافة في مهمة واحد نطاق الأسماء متاح وقت تسجيل واحد `plugins.item` بند. مكون فقط عرض متاح قسم منطقة، حيث إبقاء فقط توفير حد أو نموذج ضبط نشر، أيضا بلا حاجة يجعل إضافة صفحة حل Subagent قسم مجموعة.

## Alternatives considered

**إبقاء قسم فتح بطاقة.** مستقل تحكم عنصر جعل تفويض إرسال سياسة و نموذج تخويل بين علاقة لا كاف صاف واضح، أيضا حاجة قسم آخر حفظ.

**دمج Host نطاق الأسماء.** UI قسم مجموعة لا حاجة تغيير حفظ دائم ضبط، نطاق الأسماء revision أو اثنان بند سياسة مختلف توليد فاعلية وقت آلة. قائم نطاق الأسماء تحكم جهاز إبقاء هذه اتفاق.

## Consequences

مستخدم يمكن في نفس موضع فحص اثنان عدد قسم منطقة. حفظ ما زال قسم آخر كتابة كل منها نطاق الأسماء، لذلك ممكن جزء نجاح؛ نجاح مسودة مسودة صاف حذف، يتم رفض مسودة مسودة إبقاء مرئي و يمكن إعادة محاولة. نموذج تخويل ما زال في ذاتي ذات نطاق الأسماء داخل أصل فرعي كتابة فتح صلة و توجيه.[حزمة مشاركة اعتبار وثيقة](../../../../packages/client/ui-settings-plugins/README.ar.md) وصف تحكم عنصر و ذلك توليد فاعلية نطاق.

## Verification

تجمع تركيز مكون و تحكم جهاز اختبار تغطية مشترك نفس تحقق، حفظ، مغادرة فتح وقت إسقاط مسودة مسودة، إجراء في كتابة، جزء فشل، و فقط توفير مهمة واحد نطاق الأسماء نشر. تجميع بعد Web مشهد عبر واحد حسب زر حفظ اثنان عدد قسم منطقة، و عودة قراءة ضبط وثيقة.
