# Agent Note: حركة حالة سير العمل——نص برمجي قيادة كثير agent تحرير ترتيب seam

Status: implemented

[English](2026-07-05-dynamic-workflows.md) | العربية

## مشكلة

harness يمكن عبر `dsh-tool-subagent` سوف واحد مهمة تفويض إرسال إعطاء واحد فرعي agent(ذكي جسم) ، لكن حاجة مروحة خروج إلى كثير عدد مستقل جزء عمل——عبر كثير ملف مراجعة حساب، ترحيل، كثير زاوية درجة ضبط بحث، مقابل مقاومة صيغة تحقق——إجبار جعل نموذج تدريجي جولة تحرير ترتيب: كل في بين نتيجة كل سقوط دخول أب سياق، خطة بلا موضع حمل دائم تخزين، كل واحد خطوة تنسيق ضبط كل يلزم إزالة استهلاك مرة نموذج نحو إرجاع.Claude Code بـ[حركة حالة سير العمل](https://code.claude.com/docs/en/workflows) شكل صيغة توفير هذا واحد قدرة: نموذج تحرير كتابة واحد مقطع JavaScript تحرير ترتيب نص برمجي، وقت التشغيل تنفيذ هو، من نص برمجي (بينما غير محادثة) يحتفظ حلقة، فرع و في بين نتيجة.

## قرار

في `packages/workflow/` تحت بـ bash seam شكل (Service Definition/Service Provider/Consumer) توفير واحد مجموعة سير العمل قدرة، و هو في subagent seam فوق الذي يحتاج بنية تحويل إخراج أساس أساس.

### نص برمجي اتفاق (توافق Claude Code)

مرة سير العمل استدعاء يتضمن JSON `meta`(`name`،`description`، و اختياري `whenToUse`/`phases`) و واحد مقطع دعم حمل قمة طبقة `await` و إرجاع JSON قيمة JavaScript `script` متن. بيانات وصفية بصفة بيانات تحقق، من لا يتم تنفيذ. متن استقبال `agent(prompt, options)`،`parallel(thunks)`،`pipeline(items, ...stages)`،`phase(title)`،`log(message)` و `args`. خط الإنتاج كل مرحلة مقطع استقبال `(prev, item, index)`، مرحلة مقطع بين بلا شاشة عائق؛ فشل فرعي agent و عادي مرحلة مقطع خطأ سوف تلقي أثر item تسوية لـ `null` و قفز مرور ذلك باق بقية مرحلة مقطع.Claude Code تحديد صفة حد مع سجل آلية واحد و تأخير بعد تنفيذ، لذلك توافق نص برمجي متن في سوف meta رأس نقل دخول معامل بعد يمكن استخدام وقت ساعة و مع آلة عدد.

و CC لديه واحد موضع لحظة معنى صارم إطار صفة فرق مختلف: خطاف خطأ استخدام——لم معرفة أو تأخير متأخر خيار (`effort`/`isolation`/`agentType`) ، صيغة خطأ معامل، تجاوز خروج دعم حمل فرعي تجميع schema، إطلاق حد أعلى،seam بدء فشل——سوف رمي خروج حمل `fatal: true` `WorkflowError`، تركيب جهاز سوف إعادة رمي خروج fatal خطأ بينما غير سوف item وضع لـ null. إذا لا هذا مثال فعل، واحد تجميع خطأ خيار سوف صامت لكن تغيير صار واحد و فرعي agent فشل لا يمكن منطقة قسم `null`——هذا صحيح هو هذا مستودع منع توقف «يتم قبول بعد يتم تجاهل اختصار» فشل نمط. آخر لديه واحد موضع إضافة جديدة: أداة `args` معامل هو واحد JSON كائن (عار قائمة يتم حزمة تركيب لـ واحد حقل) ، جعل بروتوكول صيغة (wire format) إبقاء صدق فعلي.

### seam(dsh-workflow)

`ctx.workflowEngine` هو bash شكل سحب كائن `WorkflowEngine`——كل سياق واحد جذب محرك، بلا تسمية مزود سجل التسجيل (جذب محرك هو نشر درجة استبدال، لا هو مشترك تخزين من).`start(request)` مقابل لا يمكن بدء نص برمجي تزامن رمي خروج؛ إرجاع `WorkflowRun` `result` دائم لا reject(فشل وقت تسوية لـ `stopReason: 'error' | 'cancelled'`).`workflow/*` حدث هو فقط مراقبة emit، يحمل بيانات لقطة (id + meta؛`workflow/end` حذف result قيمة) ، حسب مستمع عزل، و `subagent/start`/`subagent/end` مقابل تسمية——تحكم حق إبقاء في run يحتفظ من يد في. مفردات تفصيل حال رؤية [subsystems/workflow.md](../../../../docs/subsystems/workflow.ar.md).

### جذب محرك (dsh-workflow-ptc): مشترك Node عملية تنفيذ

[سير العمل صندوق رملي إعادة استخدام قرار](../architecture/2026-09-13-workflow-ptc-sandbox-reuse.ar.md) يحل محل worker-thread تنفيذ و معلومة مهمة تنفيذ. جذب محرك في صندوق رملي تحويل PTC Node عملية في إبقاء VM و مساعد مساعدة دالة.VM تعريف نص برمجي API؛OS ملف سياسة و تلقي إدارة عملية تنظيف من مشترك تنفيذ مزود مسؤول.

مضيف في إصدار قبل تحقق بيانات وصفية و تحليل متن.Host ربط سوف guest اتصال إلى subagent و سير العمل مراقبة جهاز. انتظار بدء و قد إصدار فرعي سجل مشترك إلغاء إشارة؛[agent أثر مجال وقت التشغيل تصميم Agent Note](../architecture/2026-07-12-agent-scope-runtime-design.ar.md#workflow-children-are-pending-starts-or-published-records) مسؤول ذلك دورة الحياة قاعدة.

**Meta هو بيانات**:Host من لا تنفيذ بيانات وصفية حرف وجه كمية.**قيمة هو بلا ضرر JSON**:guest جانب realm شيء تحويل في PTC نقل قبل رفض لا دعم حمل قيمة.getter في تلقي حد عملية داخل تشغيل، خطاف خطأ عبر realm إبقاء مستقر `name` و `code` حقل. إبقاء تنسيق عمل صيغة مساعد مساعدة دالة حد أعلى و الأكثر أول تزامن قطعة مقطع مهلة؛ لا زيادة كامل جسم سير العمل مرور مرور وقت تحديد وقت جهاز.

### Consumer(`dsh-tool-workflow`)

واحد `workflow` أداة، مرآة مثل `dsh-tool-subagent` تزامن شكل: بدء،await،`try/finally` dispose،abort جسر وصل `exec.signal`، غير `completed` → `isError`. تصيير معنى رسم: واحد ورقة بـ استدعاء `meta.name` معامل لـ عنوان `generic` بطاقة (عرض هو معامل صاف دالة). أداة وصف أي موجه إلى نموذج تحرير كتابة مواصفة. استخدام سياسة بـ أداة ذاته `tool:<toolName>` نص التوجيه مقطع سقوط مع أداة إصدار (صريح طلب عندئذ استخدام جذب توجيه——أداة جذب توجيه وجود في أداة إضافة في، من لا في نشر persona في) ؛harness لا يوجد ultracode ريح إطار effort باب تحكم.

مقابل في قمة طبقة أداة تنفيذ، نفس مستهلك أيضا سوف يأخذ تشغيل و فعلي عضو دورة الحياة كتابة استدعاء جهة أب Session، شكل صار أربعة صنف log-only `tool-workflow/*` حدث. سجل مسار فقط مراقبة، لا تحكم تنفيذ: رقم مرة append فشل سوف منع استخدام هذا تشغيل لاحق كتابة و إبقاء تحت دمج قاعدة بادئة، لا تغيير أداة نتيجة.[`ui-workflow-run`](../../../../packages/client/ui-workflow-run/README.ar.md) عبر Conversation Node جذب محرك إعادة بناء هذه واقع، شكل صار مستقل keyed Chat سطر؛ قائم generic أداة سطر متابعة يملك ذاتي ذات عرض. حفظ دائم، إعادة تشغيل، توسيع/طي و فوري تنقل تفصيل دقيق قرار رؤية [Chat في حمل دائم سير العمل تشغيل](../../archived/feature/2026-08-10-durable-workflow-runs-in-chat.md).

### أساس أساس:subagent seam فوق بنية تحويل إخراج

`SubagentStartRequest.outputSchema` من `dsh-subagent-in-process-driver` لـ اثنان عدد عملية داخل خلفية تنفيذ. كل بنية تحويل فرعي agent في `child.ctx` فوق نيل نيل ذاتي ذات أثر مجال التقاط أداة، إشارة أمر و قوي صنع تسجيل؛ تزامن فرعي agent يمكن استخدام مختلف schema بينما لا مشترك متغير سياسة،dispose فرعي agent وقت إزالة كامل مرفق عنصر.

إخراج schema جعل مرة schema صالح قد إيداع التقاط يصبح فرعي agent نجاح إتمام لا بد يلزم شرط. أثر مجال وقت التشغيل عرض التقاط أداة و إشارة أمر، فقط إيداع نجاح نهائي نتيجة (يشمل SDK استدعاء وقت خارج طبقة `run_code` نتيجة) ، في التقاط تغيير لـ pending بعد رفض لاحق فرعي أثر، و في إيداع بعد لم يعد إجراء نموذج خطوة أي إيقاف فرعي agent. تحقق فشل ما زال هو يمكن إعادة محاولة أداة خطأ؛ لا يوجد قد إيداع التقاط صحيح معتاد إتمام بـ خطأ تسوية.

`ObjectJsonSchema` هو `dsh-tools` موحد واحد كما يمكن قوي صنع تنفيذ أصلي JSON Schema فرعي تجميع الذي توفير كائن أصل مستهلك عرض؛ لا دعم حمل صلة مفتاح حرف سوف واضح تقرير خطأ، لأن هذا بروتوكول بيانات سوف تدريجي حرف يصبح التقاط أداة parameters.[موحد واحد JSON قيمة schema Agent Note](../architecture/2026-07-20-unified-json-value-schema-dsl.ar.md) تعريف مفردات و تحقق دلالة،[agent أثر مجال وقت التشغيل تصميم Agent Note](../architecture/2026-07-12-agent-scope-runtime-design.ar.md#structured-output-commits-only-authoritative-outcomes) فإن تعريف تجميع، إيداع، حراسة حماية و إنهاء إيقاف حساب قاعدة.

## اختبار

تحقق من سير العمل مساعد مساعدة دالة و Host دورة الحياة اختبار، مشترك Node PTC قيد اختبار، و عبر قد إصدار profile شفرة المصدر/بناء بعد سير العمل تنفيذ مسؤول. قد سجل سير العمل و صريح تفعيل Ralph مشهد مسؤول تجميع بعد نموذج تحويل تسجيل؛ استخدام passthrough صندوق رملي إعادة تشغيل إعداد لا يستطيع إثبات OS قوي صنع قدرة.

## تأخير متأخر (واضح غير هدف)

- **خلفية استلام تجميع**(بدء أداة → run id → إتمام إشعار → استلام تجميع) ، و shell/subagent خلفية موحد واحد واحد بدء تصميم.
- **سجل تحويل + استعادة**(`resumeFromRunId`، ذاكرة مؤقتة agent() بادئة): تنفيذ هو سوف بـ نص برمجي اتفاق استلام ضيق شكل صيغة إعادة جذب دخول CC تحديد صفة منع أمر (نص برمجي يمكن قراءة وقت ساعة).
- **حفظ/تحزيم سير العمل**(`.deepseek/workflows/` سجل التسجيل، مائل عمود أمر API) و**نص برمجي حفظ دائم إلى تشغيل دليل**(استدعاء الأداة حدث قد حمل دائم سجل نص برمجي).
- **تضمين طقم `workflow()`**،**token `budget`**، و `effort`/`isolation`/`agentType` agent خيار (كل كل سوف واضح رفض، و في رسالة في ملاحظة واضح ذلك قد تأخير متأخر تنفيذ).
- **كامل جسم تشغيل تعليق ساعة مهلة**: سير العمل دورة الحياة ما زال من استدعاء جهة تحكم؛ صريح إلغاء إيقاف PTC تنفيذ و انتظار فرعي agent تنظيف.
- **ACP(Agent Client Protocol) خلفية بنية تحويل إخراج**و **`toolFilter`**(اثنان من ما زال بـ قدرة علامة سجل `false` باب تحكم).

## سبق اعتبار بديل خطة

- **VM قيمة Host جانب منع حماية**(بديل إدارة رفض، وصف رمز مرة تاريخ و عبر realm تغلب ضخم): هذه لا يمكن قوي صنع OS ملف إذن.VM طلب قيمة و شيء تحويل يخص تلقي حد عملية داخلي؛ مشترك PTC مزود مسؤول عملية نقل موضع تحقق.
- **عملية داخل `node:vm` تنفيذ**: آلة آلة فوق الأكثر بسيط——بلا RPC، بلا خط مسار——لكن `start()` سوف في نص برمجي ابتدائي تزامن مقتطعة خلال منع سد استدعاء جهة، رقم واحد await بعد تزامن ذاتي دوران لا يمكن في عملية داخل إنهاء (vm `timeout` فقط تغطية رقم واحد مقتطعة) ، كما `dispose()` فقط قدرة في مضيف حلقة فوق وضع ترك واحد لم settle نص برمجي.PTC عملية إبقاء vm سياق نص برمجي API، معا حل حذف مضيف منع سد و توفير تلقي إدارة إنهاء.
- **`isolated-vm`**: جذب دخول آخر طقم JavaScript جذب محرك سوف زيادة أصلي اعتماد و نشر اشتراط؛ مشترك PTC مزود قد توفير عملية قيد.
- **خلفية تنفيذ بصفة افتراضي**(CC شكل): تأخير متأخر. قبل منصة تزامن و `dsh-tool-subagent` حالي شكل متسق، خلفية دلالة ينبغي في bash،subagent و سير العمل بين موحد واحد تصميم مرة، بينما غير تدريجي أداة تصميم.
- **سير العمل طبقة لـ `agent({schema})` فعل JSON تحليل**: في واحد مستهلك تكرار seam صلة ملاحظة نقطة، بينما seam قدرة علامة سجل ما زال لا صدق فعلي أرض لـ `false`.
- **Meta تضمين دخول نص برمجي في بصفة `export const meta = {...}`**(CC تأكيد قطع صيغة): إبقاء نص برمجي ذاتي يتضمن كما CC نص برمجي يمكن مباشر استخدام، لكن نيل أخذ meta حاجة في مضيف فوق تنفيذ نموذج تحرير كتابة نص. أي جعل واحد فارغ حد وقت vm سياق أيضا لا يمكن قيد نص برمجي تحكم getter(عند مضيف قراءة نتيجة كائن وقت).JSON معامل إزالة حذف مسح جهاز، تنفيذ و مضيف ذاتي دوران تسرب ثقب؛ بديل قيمة هو CC نص برمجي meta رأس يجب نقل دخول معامل (متن إبقاء يمكن مباشر استخدام).
- **`ValueSchemaSpec` بصفة `outputSchema` بروتوكول نوع**: موجه إلى عمل من شكل صيغة مثل اليوم أداة لديه انتظار قيمة مفردات، لكن سير العمل توفير هو قدوم ذاتي أخرى realm أصلي JSON Schema بيانات؛ سوف هذا صنف وقت التشغيل بيانات زائف تركيب صار يمكن معلومة عمل من إعلان، سوف قفز مرور أصلي schema تأكيد حد.
- **schema كائن مكتبة (zod أو هذا مستودع schemastery) لأجل بنية تحويل إخراج فرعي تجميع**:schema هو بروتوكول بيانات——صاف JSON، عبر تجاوز `agent({schema})` في vm realm حد و تدريجي حرف سقوط دخول قوي صنع أداة parameters——صحيح هو نشط schema كائن لا يمكن وجود موضع؛ في وقت التشغيل إزالة استهلاك أصلي JSON Schema حاجة في ذلك فوق إضافة واحد رقم ثلاثة جهة تحويل جهاز (zod core فقط إخراج JSON Schema، لا يستطيع عكس نحو) ، كما سوف في schemastery إعداد زاوية لون جانب حافة وضع وضع ثاني نوع schema لغة.
- **ajv لأجل قيمة تحقق**: هو تحقق كامل JSON Schema، لذلك فرعي تجميع باب تحكم——وحدة حق صحيح يلزم نقطة، لأن كل يتم قبول صلة مفتاح حرف كل يجب هو harness قوي صنع تنفيذ——بلا نقاش مثل أي ما زال يحتاج يد كتابة؛ هو عبر `new Function` تحرير ترجمة تحقق جهاز؛ كما هو سوف يصبح dsh-tools رقم واحد وقت التشغيل اعتماد، فقط لـ استبدال نحو 70 سطر قيمة مرة تاريخ جهاز، بينما حمل مسار كما تدريجي واحد تقرير إبلاغ كل مخالفة قاعدة خطأ تقرير إبلاغ بلا نقاش مثل أي كل هو ذاتي تعريف.
- **مزود JSON نمط بديل بديل التقاط أداة**: هو حفظ إثبات JSON صالح، لكن لا حفظ إثبات ذلك رمز دمج schema، كما هو و استدعاء الأداة تفاعل لا واضح. التقاط أداة إبقاء جولة داخل تحقق إعادة محاولة. مزود جانب صارم إطار أداة schema لاحق يمكن في لا تغيير هذا تصميم حال حال تحت استلام ضيق قبول فرعي تجميع.

## عاقبة

مروحة خروج خطة الآن وجود في يمكن إعادة تشغيل نص برمجي في،`outputSchema` توفير مرجعي بنية تحويل فرعي agent نتيجة. كل مرة تشغيل دفع خروج PTC عملية بدء و ربط RPC صار هذا.Host تنفيذ إبقاء غير منع سد، إلغاء إيقاف تلقي إدارة عملية،JSON تسلسل تحويل سوف guest قيمة و Host قسم فتح. بلا فاعلية خيار سوف فشل بينما غير تراجع تحويل لـ Claude Code `null`؛ مستهلك عبر run handle إبقاء تحكم حق، مراقبة من فقط استقبال لقطة. قمة طبقة Web مستخدم أيضا سوف نيل إلى حمل دائم، يمكن إعادة تشغيل سير العمل سجل، معا لا توسيع عرض تنفيذ seam، أيضا لا يأخذ أصل أداة بطاقة اقتران دمج إلى سير العمل مخصص تابع UI.
