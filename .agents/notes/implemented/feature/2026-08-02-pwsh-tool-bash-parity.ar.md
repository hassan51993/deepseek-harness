# Agent Note: pwsh أداة و bash مقابل متساو

Status: implemented

[English](2026-08-02-pwsh-tool-bash-parity.md) | العربية

## مشكلة

أول عدد Windows أصلي أساس أساس تسليم `dsh-tool-pwsh` هو لحظة معنى الأكثر صغير رسم مثل——فقط قبل منصة (كل مرة استدعاء كل بدء جديد عملية؛ بلا حمل دائم PTY جلسة) ، تلقي إدارة بيئة فقط لديه ثلاثة عدد صلب تحرير رمز `DSH_*` مفتاح، و واحد لم إعلان حينئذ انحراف مغادرة bash أداة marker لذا أمر («ثابت ضرب `[exit code: N]`»). نموذج مرئي اتفاق سبق و تنفيذ انفصال عقدة: وصف تحمل وعد مصير من لم تنفيذ spill مسار تقرير إبلاغ،README إعلان تسمية لا وجود توجيه خروج و أداة لم فعل تصيير، أداة ذاتي ذات اختبار أيضا تثبيت ميت لديه ضرر سلوك. الأكثر صغير رسم مثل أيضا يجعل `DSH_*` contributor seam بسبب نقص مقعد بينما تكرار: نحو `ctx.shellEnv` مساهمة بيئة واقع إضافة مقابل pwsh استدعاء جزء بلا أثر.

## قرار

`dsh-tool-pwsh` الآن تدريجي استدعاء مرآة مثل `dsh-tool-bash`، ذلك نموذج مرئي نص دقيق وصف هذا واحد سلوك:

- **تصيير سلوك و bash تماما متسق**:stdout، حمل علامة `[stderr]` مقطع، حمل spill مسار قطع قطع إشعار، فارغ جسم تصيير `(no output)`، خروج marker فقط حد غير صفر خروج——جاف صاف خروج لا إنتاج marker. وصف و `tool:pwsh` نص التوجيه جزء دقيق قديم وصف هذا واحد نقطة («Non-zero exits are reported as `[exit code: N]` markers») ، لحظة معنى لا نسخ bash نص التوجيه في و ذلك ذاته تصيير تناقض درع «every result» إجراء لفظ.
- **`run_in_background` مرور عام مهمة وقت التشغيل وصل خط**، و bash أداة تماما متسق: مسبق فحص،owner تسجيل،`job_output`/`job_kill` تحكم و نفسه نتيجة خريطة. ذلك خلف بعد هو `pwsh-local` مبكر قد مرآة مثل جيد `start()` جملة مقبض.
- **`DSH_*` بيئة مشترك بينما غير نسخ**:`ShellEnvRegistry` من `dsh-tool-bash` نقل دخول جديد أداة غير متصل حزمة `@deepseek-ai/dsh-shell-env`(`ctx.shellEnv` + داخل وضع واقع + جلسة حفظ دائم مساهمة جهة) ، اثنان عدد shell أداة كل حقن هو.contributor مقابل pwsh استدعاء و bash استدعاء واحد نظر نفس لب؛ لذلك، مشترك بيئة كل حق لا يخص أي واحد موجه إلى نموذج shell أداة.
- **Windows الآن فعلي في bash بلا مقابل موضع تثبيت ميت**: كل بند أمر كل في UTF-8 إخراج قبل وضع شفرة تحت تشغيل، جعل Windows PowerShell 5.1 التقاط قاع لا يمكن مرور UTF-8 حل رمز collector كسر تالف غير ASCII إخراج؛ نص التوجيه شرح Windows قوي صنع إنهاء بـ exit 1 تسوية، لا إنتاج signal marker.
- **نطاق خارج، ثابت**: حمل دائم PTY shell(خلفية فقط حد Linux/macOS؛ConPTY تابع مسار خط رسم). صندوق رملي ترقية مع [Windows ACL صندوق رملي قرار](2026-08-08-windows-acl-restricted-token-sandbox.ar.md) قليلا بعد تسليم——pwsh أداة الآن يحمل صندوق رملي رفض تصيير و نفس جولة `sandbox_permissions` ترقية وجه، خارج إضافة ذلك وصف في Windows ConstrainedLanguage اتفاق. حمل خروج pill pwsh مخصص تابع terminal بطاقة قد مع [pwsh UI عرض و bash مقابل متساو](../../archived/feature/2026-08-05-pwsh-ui-bash-parity.md) قرار آخر سطر تسليم.

## تجهيز اختيار خطة

**إبقاء الأكثر صغير رسم مثل، فقط إصلاح إعلان.** مرفوض: من bash نسخ نص اتفاق في نقص قليل مقابل تنفيذ وقت سوف عائم نقل؛ الأكثر صغير أداة إضافة دقيق تأكيد إعلان ما زال يجعل pwsh استدعاء لا يوجد خلفية تنفيذ، لا يوجد contributor مقابل انتظار، و إبقاء تحت واحد يجب دائم بعيد إعادة جدل حماية انحراف مغادرة marker لذا أمر.

**في تحميل وقت رفض لا مطابقة منفذ جهة قول.** دمج قبل محاولة تجربة مرور و سحب عودة: في `ShellExecutor` فوق إضافة `ShellDialect` علامة (`bash` | `powershell`) ، اثنان عدد shell أداة في تركيب منفذ قول آخر نوع جهة قول وقت رمي خطأ. هو إجبار جعل كل منفذ تنفيذ——يشمل كل اختبار و عرض مثال fake——كل يلزم إعلان dialect، لـ واحد طريق مستودع داخل و دمج إدارة نشر في كل لا يوجد هدف يمكن اعتراض حماية شريط (تسليم تركيب مجموع هو يأخذ tool-pwsh إعداد `dsh-pwsh-local`،tool-bash إعداد `dsh-bash-local`) إعطاء كل shell أداة اختبار إضافة ضجيج. إعداد مقابل اتفاق تعديل من كل أداة README سجل.

**رفع أخذ تماما مشترك أداة تنفيذ أساس مقعد (سحب كائن shell جهة قول، اثنان عدد رقيق ورقة فرعي).** اعتبار بعد دفع متأخر:shell-env رفع أخذ و بنية مرآة مثل (`render.ts`/`background.ts` توأم توليد) هو هو يلزم قيام كاف أساس أساس؛ في ظهور رقم ثلاثة نوع جهة قول أو حمل دائم PTY توأم توليد، يجعل سحب كائن شكل يمكن مراقبة قبل، لا فعل كامل أساس مقعد.

## عاقبة

- bash و pwsh أداة في قبل منصة، خلفية و صندوق رملي تحويل shell عمل فوق سلوك يمكن متبادل تبديل (صندوق رملي جدول طبقة من Windows ACL صندوق رملي قرار مسؤول) ، مصير تغطية ثابت كل واحد جملة pwsh نص التوجيه و وصف.
- مقابل متساو أيضا عكس نحو حدوث مرور مرة:pwsh أداة بنية تحويل قبل منصة في توقف (`HarnessError('tool call aborted', TOOL_ABORTED)`،name لـ `AbortError`) يتم عودة نقل إلى bash أداة، يحل محل ذلك بلا رمز `Error('command aborted')`——هذا هو نموذج مرئي/دخول سجل تغيير، من اثنان جانب دقيق شكل حالة اختبار و cancel-tool-calls fixture(اختبار قبل وضع بيانات) تثبيت إقامة.
- `@deepseek-ai/dsh-shell-env` يصبح جديد تسليم حزمة؛`dsh-tool-bash` `dshHome` إعداد نقل نحو ذلك داخل، لذلك تركيب shell أداة تركيب أيضا يجب تركيب `shell-env`(رئيسي جاف تركيب حزمة قد مثل هذا).
- Windows مخصص تابع دلالة (CRLF عودة واحد تحويل، قوي صنع إنهاء exit-1/signal-null، فقط POSIX ذاتي إشارة) واحد مثل حيث نحو من اختبار تثبيت إقامة.
- pwsh أداة تدريجي ملف نسبة التغطية بوابة من يمكن نص برمجي تحويل fake منفذ طقم عنصر (`tests/tools.spec.ts`) تحمل تحمل؛ حقيقي pwsh تجميع صار و Loader تركيب طقم عنصر في بلا `pwsh` مضيف ذاتي قفز مرور، و bash طقم عنصر قسم عمل متسق.
- مسار خط رسم رفع سجل parity مرحلة مقطع قد تسليم؛terminal بطاقة عرض مرحلة مقطع مع [pwsh UI عرض و bash مقابل متساو](../../archived/feature/2026-08-05-pwsh-ui-bash-parity.md) قرار تسليم (TUI ذاته قد إزالة) ، باق بقية مرحلة مقطع هو Windows افتراضي تركيب.
