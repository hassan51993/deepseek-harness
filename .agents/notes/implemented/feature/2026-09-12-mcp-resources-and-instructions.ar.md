# Agent Note: حسب يحتاج MCP مورد و أثر مجال خادم إشارة أمر

Status: implemented

[English](2026-09-12-mcp-resources-and-instructions.md) | العربية

## مشكلة

MCP خادم سوف وثيقة و URI نموذج لوح بصفة مستقل في أداة قدرة كشف. فقط دعم حمل أداة عميل لا يمكن قراءة هذه وثيقة، أيضا لا يمكن استخدام فقط توفير مورد بينما لا توفير أداة خادم. خادم أيضا توفير إشارة أمر قدوم حل تفسير كل بند عملية مثل أي إعداد دمج؛ تجاهل اختصار هذه إشارة أمر سوف فقد فقد اختيار و تركيب عملية الذي يحتاج سياق.

## قرار

[`mcp-resources`](../../../../packages/mcp/mcp-resources/README.ar.md) توفير ثلاثة عدد مشترك أداة، لأجل صف خروج مورد، صف خروج نموذج لوح و قراءة URI. كل أداة كل اشتراط صريح إشارة تحديد قد إعداد خادم اسم. تركيب يتضمن توجيه النظام تركيب إعداد وقت، حرف وجه مقطع سقوط من إرسال إرسال سجل التسجيل نيل أخذ استدعاء جهة مرئي اسم، لذلك لا يوجد خادم إشارة أمر صاف مورد خادم ما زال يمكن يتم اكتشاف. قد لديه نظام رسالة سجل سجل هذه اسم؛ مزود تحرير بعد، لاحق تجميع سوف إزالة ذلك اسم. تنفيذ مسار في إرسال إرسال قبل في استدعاء agent أثر مجال في تحليل هذا خادم؛ مزود تسجيل استخدام يمكن سحب إلغاء Cordis effect.

[Profile متاح صفة قرار](2026-09-13-mcp-resources-in-profiles.ar.md) يحل محل مفرد وحيد تفعيل مورد خدمة تركيب طريقة، و يملك أداة شرط مرئي صفة. هذا قلم تسجيل إبقاء مورد عملية، نتيجة يمثل و إشارة أمر قرار. كل [`mcp-client`](../../../../packages/mcp/mcp-client/README.ar.md) نسخة يملك ذاتي ذات اتصال، و في خدمة قد تركيب وقت تسجيل مورد مزود. خادم نقص قليل مورد قدرة وقت،SDK إرجاع فارغ مورد قائمة و نموذج لوح قائمة؛ لا تلقي دعم حمل قراءة سوف فشل. خادم بلا حاجة إعلان أداة قدرة. رسمي جهة SDK مسؤول بروتوكول عملية؛ قائمة تنقل علامة و مورد URI إبقاء لا نفاذ واضح؛ صريح تنقل علامة طلب واحد صفحة، حذف تنقل علامة فإن من SDK تجميع مجموع كل صفحة.

مورد نتيجة لـ برنامج تحويل استدعاء جهة إبقاء كامل مواصفة JSON.Native نص يتضمن قد إعداد خادم اسم و إرجاع URI بيانات وصفية. نص قيمة `blob` حقل تغيير لـ اثنان دخول صنع شرح نص حرف، لا داخل ربط base64. قد لديه أداة نتيجة سجل سجل نموذج إسقاط؛ هذه الحزمة لا إنشاء و سطر مورد سجل أو اثنان دخول صنع مرفق عنصر تخزين.

خادم إشارة أمر لـ كل قد إعداد MCP خادم مساهمة واحد أثر مجال داخل حرف وجه توجيه النظام مقطع سقوط. قد لديه نظام رسالة سجل سجل نهائي إرسال بلوغ نموذج تجميع بعد إشارة أمر. مورد محتوى إبقاء حسب يحتاج قراءة، لذلك اتصال خادم لن سوف ذلك وثيقة مسبق تحميل إلى نص التوجيه في.

هذا قرار فقط يحل محل[أصل MCP عميل سجل](2026-07-07-mcp-client-plugin.ar.md) في تأخير بعد مورد دعم حمل قرار. هذا سجل متابعة إبقاء في نشط وثب دليل، لأن ذلك أداة تسمية، مواصفة نتيجة، بيئة و نقل إدارة من ما زال ملائم استخدام.Prompts ما زال لا تلقي دعم حمل.

## سبق اعتبار بديل خطة

**لـ كل منصة خادم إنشاء مستقل مورد أداة.** لا إعطاء اعتماد، لأن كل منصة خادم كل سوف زيادة آخر طقم نفسه عملية schema. ثلاثة عدد مشترك أداة إبقاء مقارنة صغير أداة دليل؛ صريح خادم معامل و تنفيذ وقت أثر مجال تحليل مسؤول اختيار مزود.

**تلقائي حقن أو تحديث جديد مورد محتوى.** لا إعطاء اعتماد، لأن مورد قائمة لا يمكن تحديد مهمة حاجة أي بعض وثيقة. حسب يحتاج قراءة يجعل نموذج اختيار محتوى، تجنب تجنب قراءة غير متصل وثيقة، و إبقاء فعلي استخدام مرور نتيجة. مورد حجز قراءة و تحديث إشعار ما زال لم تنفيذ.

**سوف اثنان دخول صنع مورد إسقاط لـ أصلي محتوى.** تأخير بعد، لأن صورة و صوت تردد حاجة قدرة، حفظ دائم و عرض تنسيق نفس دعم حمل. إبقاء مواصفة بايت و تصيير بيانات وصفية، يمكن توفير فعلي استخدام نص مورد وصول، بينما بلا حاجة آخر بناء محتوى آلية.

**لـ إشارة أمر و قراءة إضافة MCP مخصص تابع حمل دائم حدث.** لا إعطاء اعتماد، لأن تجميع بعد نظام رسالة و أداة نتيجة قد سجل نموذج مرئي إدخال. ثاني عدد حدث مرجعي سوف تكرار هذه سجل.

## تحقق

[مورد اختبار](../../../../packages/mcp/mcp-resources/tests/resources.spec.ts) ثابت ثلاثة عدد عملية، أصل مثال تنقل علامة، لا بد ملء خادم معامل، غير ممكن استخدام خادم رفض، أثر مجال مزود اختيار، تكرار تسجيل رفض، تحرير، و إبقاء كامل مواصفة نتيجة لكن لا نحو نموذج نص كتابة اثنان دخول صنع سلوك. هو جمع أيضا تحقق بلا خادم إشارة أمر وقت استدعاء جهة مرئي خادم اسم، اسم حرف وجه إبقاء، و مزود أو مورد خدمة تحرير وقت إزالة نص التوجيه سياق.[أداة نتيجة عقد نحو](../architecture/2026-07-20-canonical-tool-output-contract.ar.md) يملك تنفيذ وقت قيمة و قد سجل نموذج محتوى بين منطقة قسم.

## عاقبة

فقط توفير مورد خادم بلا حاجة إضافة حسب خادم منطقة قسم نموذج أداة يكفي استخدام. استدعاء جهة مرئي خادم اسم و خادم إشارة أمر زيادة نص التوجيه token؛ مورد وثيقة فقط في قراءة وقت زيادة token. فقط يلزم استدعاء جهة مرئي عميل ما زال قد إعداد، اتصال فشل خلال مشترك schema حينئذ إبقاء مستقر، لكن الذي اختيار خادم غير ممكن استخدام وقت استدعاء ما زال سوف فشل. اثنان دخول صنع مورد ما زال هو برنامج تحويل قيمة، قسم صفحة التزام دوران SDK.
