# Agent Note: إضافة ذاتي لديه شخص صنف أمر تسجيل

Status: implemented

[English](2026-07-19-plugin-command-registration.md) | العربية

## مشكلة

TUI يملك مائل عمود أمر. إذا أمر اسم، مساعدة نص، تلقائي تكملة كل، قسم إرسال و إلغاء كل إبقاء في مهايئ داخلي، كل جديد أمر كل حاجة تعديل TUI، اختياري إضافة أيضا لا يمكن مساهمة أمر. يأخذ مائل عمود إدخال عند عمل عادي نموذج نص التوجيه نفس مثال لا أمان: مستخدم مرئي مباشر عملية ممكن معنى خارج إزالة استهلاك token، أو يجعل نموذج إعادة حل تفسير لم معرفة أمر.

مشترك آلية يجب ما زال هو UI صلة ملاحظة نقطة، بينما لا هو نموذج أداة أو agent loop(ذكي جسم حلقة) فرع. هو أيضا حاجة دقيق إلى كل agent(ذكي جسم) مرئي صفة،HMR(حار وحدة استبدال) أمان إزالة، مباشر نتيجة تصيير و طلب أثر مجال إلغاء، معا لن تلقائي يأخذ أمر نص أو إخراج إضافة دخول نموذج تاريخ.

## قرار

يقع في `packages/interaction/commands/` `@deepseek-ai/dsh-commands` هو منتج أمر سجل التسجيل.`dsh-base` لـ إزالة استهلاك هذا خدمة قبل طرف تركيب هو؛[فقط موجه إلى تلقائي تحويل ACP(Agent Client Protocol) تطبيق](../simplification/2026-07-23-acp-automation-only-protocol.ar.md) و مستقل `sdk-minimal` إعداد شجرة كل حذف هذا خدمة.UI واجهة حقن هذا خدمة، أمر إنتاج من فقط اعتماد سجل التسجيل و ذلك عملية مجال.

### سجل التسجيل اتفاق

`CommandDefinition` يتضمن لا حمل `/` صغير كتابة اسم، غير فارغ وصف، اختياري غير بنية تحويل إدخال تلميح، و يمكن إلغاء معالج. تسجيل سوف تحقق بيانات وصفية و نسخ واحد نسخة و استدعاء جهة انفصال مغادرة فرعي هذا، تجميد ربط نهائي توليد فاعلية تعريف، و إرجاع مقابل Cordis effect دقيق disposer(مورد تحرير جهاز). نفس طبقة في تكرار اسم سوف فشل. كل مستهلك كل قدرة يرى كل صالح تعريف؛ إذا أمر إضافة لا يمكن في بعض نوع نشر في تشغيل، هو حينئذ لا في هذا نشر في تسجيل، بينما لا هو يأخذ مستهلك هوية تحرير رمز دخول مشترك مجال.

`list(agent)` في أثر مجال حجب حجب بعد إرجاع غير ممكن تغيير، حسب اسم ترتيب وصف رمز.`find(agent, name)` تحليل صالح تعريف.`execute(agent, line, signal)` تحليل و تشغيل معروف تعريف، إرجاع قسم مغادرة بعد `success` أو `error` نتيجة؛ بلا فاعلية لغة قاعدة و لم معرفة اسم إرجاع `undefined`، من مهايئ مسؤول توليد مباشر عرض خطأ نص.

`parseCommand(line)` اشتراط `/` يقع في رقم صفر بايت، بعد وصل من حرف أم، عدد حرف،`_` أو `-` مجموعة صار صغير كتابة ASCII اسم، و بـ فارغ أبيض أو إدخال نهاية ذيل انتهاء. هو يأخذ مهايئ تسليم كامل بعد لاحقة إبقاء لـ `rawInput`، يشمل قسم فصل فارغ أبيض. كل أمر إضافة ذاتي سطر مسؤول لاحق كل لغة قاعدة قرار.

### أثر مجال و دورة الحياة

بلا أثر مجال تسجيل هو عام تسجيل. تركيب في agent سياق لـ تحت و حقن `commands` إضافة سوف وراثة هذا agent أثر مجال مفتاح و دورة الحياة، لذلك ذلك تعريف فقط سوف لـ مقابل نفس عدد agent حجب حجب نفس اسم عام تعريف. فرعي إضافة ذاتي سطر إعلان `commands` حقن، لأن `agent.ctx` متعمد وراثة نواة قلب agent loop اعتماد واجهة؛ فقط لـ تنفيذ أثر مجال تسجيل بينما يجعل حلقة اعتماد UI خدمة سوف قلب وضع اعتماد رسم.

تسجيل و إزالة سوف إرسال خروج لم مرور ترشيح، غير ممكن مرفوض `commands/change` سجل التسجيل إشعار. مهايئ إعادة حساب حساب كل تخزين متابعة agent صالح عرض، بينما لا محاولة تجربة دفع قطع بعض مرة تغيير أثر أي بعض جلسة. سجل التسجيل سوف قسم آخر عزل و سجل كل مراقبة من فشل، لذلك ضرر تالف UI تحديث جديد لا يمكن تراجع آخر إضافة تغيير، أيضا لا يمكن منع توقف لاحق مراقبة من.Cordis كل حق سوف في إنتاج من،UI نسخة أو agent أثر مجال إزالة وقت إزالة تعريف، لذلك HMR لن إبقاء تحت قديم قديم اكتشاف بند أو معالج.

### مباشر قسم إرسال و إلغاء

أمر في فقط موجه إلى شخص صنف أمر مستو وجه في تشغيل. سجل التسجيل لن يأخذ إدخال تحويل صار `user/message`، إخراج لن يصبح جلسة حدث، اثنان من كل لن خفي صيغة إرسال إعطاء نموذج. معالج استقبال مقابل نفس عدد هدف agent، أصلي إدخال و هذا مرة طلب يحتفظ `AbortSignal`؛ إنتاج من يمكن عبر هذا agent صريح ضبط درجة مفرد وحيد نموذج مرئي عمل، مع بعد من إنتاج من مسؤول ذلك سجل سجل و دورة الحياة اتفاق. إشارة في توقف وقت، سجل التسجيل لم يعد انتظار لا دمج عمل معالج؛ معالج ما زال مسؤول إيقاف قد بدء خارجي فرعي أثر.

مسبق مدة معالج فشل إرجاع `CommandResult.error`. رمي خروج استثناء أو صيغة خطأ نتيجة ما زال هو مهايئ مرئي أمر فشل، بينما لا هو نموذج رسالة. هذا حد متعمد قسم مغادرة UI إخراج و حمل دائم مجال تغيير: مثال مثل هدف أمر يمكن تغيير `ctx.goals`، لكن حمل دائم حالة من هدف خدمة يملك.

### TUI خريطة

TUI يأخذ داخل وضع مائل عمود أمر تسجيل لـ agent أثر مجال أمر تعريف، لم يعد مقابل نص تنفيذ switch. تلقائي تكملة كل و مساعدة عرض قراءة فوري دليل، لذلك إضافة أمر سوف مع ذلك effect ظهور و إزالة فقد. أي بـ `/` فتح رأس إيداع سطر كل إبقاء في أمر مستو وجه؛ لم معرفة إدخال إنتاج طرفية تحذير إبلاغ، لن سقوط دخول `Agent.steer()`.

كل مرة إيداع أمر كل سوف إنشاء واحد مخصص تابع `AbortController`.TUI تحرير سوف في توقف لم إتمام قسم إرسال، إزالة محلي تعريف، و انتظار أمر إنتاج من fiber انتهاء بعد مجددا إتمام تنظيف.

## اختبار

سجل التسجيل اختبار تغطية لغة قاعدة حد، غير ممكن تغيير مواصفة تحويل، وقت التشغيل بيانات وصفية تحقق، تحديد صفة ترتيب، عام و أثر مجال حجب حجب، تكرار رفض، دقيق تأكيد تحرير، تغيير إشعار فشل عزل، مباشر استدعاء، مسبق مدة و صيغة خطأ نتيجة، تزامن و مختلف خطوة فشل، و كل نوع في توقف وقت ترتيب حافة امتداد؛ بلوغ إلى تدريجي ملف 100% لغة جملة، فرع، دالة و سطر نسبة التغطية.

TUI اختبار تغطية الكل ترحيل بعد داخل وضع أمر، فوري إضافة اكتشاف، مساعدة و تلقائي تكملة كل تحديث جديد، مباشر نتيجة، لم معرفة أمر رفض، أصلي إدخال تسليم، تعريف إزالة، بدء تراجع و تحرير إلغاء. بلا مفتاح طرفية لقطة ثابت تصيير بعد مساعدة، خطأ و أمر نتيجة شكل.

## اعتبار مرور بديل خطة

- **إبقاء مهايئ محلي switch**——غير مقبول، لأن اختياري إضافة لا يمكن مساهمة اكتشاف و سلوك، حذف غير تعديل TUI.
- **يأخذ شخص صنف أمر يمثل لـ نموذج أداة**——غير مقبول، لأن اكتشاف و مباشر استدعاء يخص شخص صنف UI سلوك؛ مرور من نموذج توجيه سوف زيادة تأخير متأخر،token صار هذا و إعادة حل تفسير.
- **يأخذ سجل التسجيل وضع دخول مطلوب agent نواة قلب**——غير مقبول، لأن بلا UI تشغيل مدخل لا إزالة استهلاك هو، بينما UI profile يمكن صريح تركيب هو.
- **يجعل `dsh-agent-loop` حقن commands**——غير مقبول، لأن حلقة لا تنفيذ أيضا لا اكتشاف شخص صنف أمر.agent أثر مجال إنتاج من تعديل لـ في فرعي إضافة في إعلان UI اعتماد.
- **لـ كل تعريف مرفق إضافة مهايئ إخفاء رمز**——غير مقبول، لأن دعم حمل قدرة هو تركيب واقع، بينما لا هو أمر مجال حالة. كل قد تركيب مهايئ كل كشف قد تسجيل أمر؛ لا توافق إضافة لن في هذا نشر في تسجيل.
- **يأخذ لم معرفة مائل عمود إدخال إرسال إعطاء نموذج**——غير مقبول، لأن إدخال خطأ أو غير ممكن استخدام مباشر عملية يجب يمكن مسبق قياس أرض فشل، بينما لا يستطيع تغيير تنفيذ مستو وجه.
- **حفظ دائم عام أمر إدخال و إخراج**——غير مقبول، لأن مهايئ تلميح لا هو نموذج مرئي حالة. تغيير حمل دائم سلوك معالج سوف استدعاء يملك هذا حالة مجال API، من بعد من سجل ذاتي ذات حدث.

## عاقبة

- أمر إنتاج من هو عادي يمكن إزالة إضافة،TUI إزالة استهلاك ذلك مرور مرور تحقق دليل و قسم إرسال اتفاق.
- خاص تحديد في agent تعريف إبقاء قائم مسطح مستو أثر مجال و حجب حجب دلالة، لا جذب دخول نواة قلب إلى UI اعتماد.
- لم معرفة مائل عمود إدخال و أمر إخراج هو تحديد صفة UI سلوك، مباشر نموذج token صار هذا لـ صفر.
- مباشر أمر إلغاء و نموذج جولة إلغاء ذاك هذا عزل.

## معروف حد و مؤقت مؤقت أمر بند

- إدخال بيانات وصفية فقط حد غير بنية تحويل نص تلميح. نوع تحويل جدول مفرد، معامل schema و تكملة كل مزود ما زال من أمر يملك، أو حاجة لاحق سجل التسجيل أو مستهلك توسيع.
- عام أمر إخراج فقط فوري وجود،TUI إعادة بدء بعد لن إعادة بناء.
- سجل التسجيل إلغاء سوف قيام أي إيقاف انتظار، لكن خارجي عمل فقط لديه في معالج إعداد دمج إشارة وقت عندئذ سوف إيقاف.
- ACP تلقائي تحويل خادم، بلا رأس CLI(أمر سطر واجهة) و JSON-RPC SDK تشغيل مدخل لا كشف أمر مستو وجه؛ فقط لديه TUI إزالة استهلاك هو.
