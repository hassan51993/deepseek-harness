# Agent Note: PTC mode——نموذج إبرة مقابل أداة سجل التسجيل تحرير كتابة TypeScript

Status: implemented

[English](2026-06-15-ptc.md) | العربية

## مشكلة

في سجل التسجيل أصلي عرض طريقة تحت،agent loop(ذكي جسم حلقة) سوف كل مرئي قدرة بـ JSON Schema دالة تعريف شكل صيغة عبر إبلاغ إعطاء نموذج.`ToolRuntime` سوف ذلك schema مساهمة إعطاء توجيه النظام تجميع، تجميع نتيجة في `tools` سقوط إلى بروتوكول صيغة (wire format) فوق (أيضا سجل في طلب رأس سجل في) ، نموذج كل خطوة استدعاء واحد `tool-call` كتلة، بينما في هذا note كتابة عمل وقت، حلقة عبر `ctx.tools.execute()` **تدريجي عدد**توزيع كل مرة استدعاء (و سطر أداة تنفيذ عند وقت أيضا هو open TODO؛ هذا بعد محدود و سطر توزيع قد تسليم——رؤية[و سطر أداة استدعاء note](2026-07-10-parallel-tool-call-execution.zh.md) ، و [docs/architecture.md](../../../../docs/architecture.zh.md) في rolling pool)——كما**كل واحد**في بين `tool-result` كل سوف في تحت مرة طلب وقت إعادة دخول نموذج سياق.

مقابل في كثير خطوة أداة عملية، هذا نوع طريقة token فتح إلغاء كبير كما سلسلة سطر. نموذج لا يمكن تركيب أداة——مرة تاريخ نتيجة تجميع، أصل حسب في بين قيمة فرع، مروحة خروج، بعد معالجة——كل مرة استدعاء كل حاجة مرة كامل نموذج نحو إرجاع، بينما كل مرة نحو إرجاع كل سوف يأخذ كامل في بين نتيجة سحب عودة سياق، لا إدارة نموذج هل حاجة.

Cloudflare [Code Mode](https://blog.cloudflare.com/code-mode/) رفع خروج واحد نوع بديل خطة، أساس في واحد بسيط مفرد مراقبة:LLM(كبير لغة نموذج) تحرير كتابة شفرة قدرة أفضل في إرسال خروج أداة استدعاء، لأن هو جمع رؤية مرور عدد مئة ألف سطر حقيقي شفرة، بينما شخص لـ بنية صنع أداة استدعاء trace متبادل مقابل جدا قليل. نموذج لم يعد كل خطوة إرسال خروج مرة أداة استدعاء، بينما هو إبرة مقابل أداة توليد API تحرير كتابة واحد مقطع TypeScript برنامج، برنامج في صندوق رملي وقت التشغيل في تنفيذ، نموذج فقط غربلة اختيار إرجاع محتوى——فقط حد هو print أو return جزء——بينما غير كل في بين نتيجة.

أداة عرض يخص كف إدارة أداة مرئي صفة سجل التسجيل: سوف آخر نوع عرض تنفيذ لـ أمر بعد waterfall(شلال نشر صيغة حدث) تغيير تبديل سوف اعتماد مستمع ترتيب، و و[يمكن إعادة بناء طلب](../architecture/2026-07-05-reconstructable-requests.zh.md) اندفاع مفاجئ. تنفيذ يجب مستقل في عرض نمط، إبقاء كل جديد برنامج حالة،Host يملك ربط و يمكن إلغاء تسوية.

## قرار

ثلاثة بند قرار، كل منها في تحت جهة مستقل صغير عقدة في توسيع:

1. **PTC mode هو `ToolRuntime`(`dsh-tools`) واحد انتظار عرض نمط**، عبر مرور تحقق `mode` إعداد اختيار:`'native'`(افتراضي، مساهمة مرئي قدرة schema) ،`'ptc'`(سجل التسجيل فقط مساهمة ذلك إبقاء `run_code` نقل عبر طريق إضافة واحد نسخة توليد SDK `.d.ts` إلى توجيه النظام في) أو `'both'`(أصلي schema إضافة نقل عبر طريق + SDK). سجل التسجيل في مصدر رأس بناء ذلك مواصفة مساهمة؛ تنسيق عمل صيغة نص التوجيه تجميع نتيجة ما زال أداة مرجعي صفة، سجل في سجل في طلب رأس دقيق عكس عكس هذا إرجاع عرض.
2. **شفرة تنفيذ هو واحد قدرة seam**——`packages/ptc-runtime/` يتضمن Service Definition حزمة `@deepseek-ai/dsh-ptc-runtime`، يملك `ctx.ptcRuntime`([قدرة seam](../architecture/2026-06-13-capability-seams.zh.md) ؛ مستهلك = `dsh-tools`،core إزالة استهلاك seam أولا مثال رؤية `agent-loop` → `dsh-llm`). وقت التشغيل مقابل أداة واحد بلا الذي معرفة: هو استقبال واحد مقطع برنامج و تسمية مختلف خطوة ربط، تنفيذ برنامج، تقرير إبلاغ `{ value, logs, error? }`. لغة و أساس قاع هو خلفية خاصية، لذلك لم قدوم Python أو حاوية خلفية فقط هو آخر عدد Service Provider حزمة، بينما غير إعادة تصميم.
3. **تسليم تنفيذ هو `@deepseek-ai/dsh-ptc-runtime-node`**: كل برنامج في كل جديد تلقي إدارة Node عملية في، حسب استدعاء Session قد تحليل صندوق رملي سياسة تشغيل. مباشر Node API في هذا سياسة داخل ما زال يمكن استخدام؛ أداة اسم Host ربط عبر مفرد وحيد تحقق تحكم عبر طريق استدعاء.

هذا شرح مسؤول PTC عرض، تركيب و تسوية.[نوع تحويل أداة إرجاع قرار](2026-07-20-ptc-typed-tool-returns.zh.md) مسؤول توليد إخراج، مواصفة ربط قيمة،`ToolCallError` و بلا ضرر خارج طبقة إخراج.[صندوق رملي Node قرار](../architecture/2026-09-11-sandboxed-node-ptc-runtime.zh.md) يحل محل worker تنفيذ، معلومة مهمة وضع حالة و ميزانية تنفيذ، معا إبقاء هذا شرح مستهلك قاعدة.

### كل مقطع برنامج تنفيذ تحكم

مستهلك أصل حسب وقت التشغيل فقط قراءة `timeout` وصف رمز عبر إبلاغ `timeoutMs`، و يأخذ صريح قيمة تسليم إعطاء ذلك محلل. لا دعم حمل مزود لا عام مهلة حقل، و رفض صريح طلب. صندوق رملي رفع رفع في وقت التشغيل تحليل و بدء قبل استخدام مشترك صارم إطار توسيع كبير إذن مراجعة دفعة مساعد مساعدة دالة؛ فقط استبدال قد تحليل سياسة نمط، جعل تخويل فقط أثر في واحد مقطع برنامج. تضمين طقم توزيع إبقاء أصلي Agent و Session، لذلك ذلك مراجعة دفعة و ملف سياسة إبقاء مستقل. فشل برنامج لن خفي صيغة إعادة وضع، لأن أولا قبل فاعلية نتيجة ممكن قد إيداع.

[Node تنفيذ قرار](../architecture/2026-09-11-sandboxed-node-ptc-runtime.zh.md#deferred-timeout-design) مسؤول مرور مرور وقت ميزانية نواة حساب و تأجيل دورة الحياة مشكلة.

### سجل التسجيل يملك نمط

`ToolRuntime` نيل نيل واحد مرور schemastery تحقق إعداد (`static Config`) ، هذا هو هو رقم واحد إعداد:`mode: 'native' | 'ptc' | 'both'`، افتراضي `'native'`. نشر عبر `cordis.yml` قلب تحويل نمط (`tools: { mode: ptc }`) ، بلا حاجة تعديل شفرة، التزام دوران no-hardcoded-tunables اتفاق.

**بروتوكول أداة قائمة.** سجل التسجيل في `'native'` تحت مساهمة مرئي قدرة، في `'ptc'` تحت فقط مساهمة `run_code`، في `'both'` تحت اثنان من كل مساهمة. نهائي `PromptAssembly.tools` قائمة سجل في طلب رأس في.`run_code` هو واحد إبقاء عرض نقل عبر طريق، يقع في تسجيل و حد طبقة خارج؛ مباشر نص التوجيه مزود و تجميع waterfall ما زال كل منها مسؤول ذاتي ذات مساهمة.

**و `toolOrder` تفاعل:** إذا إعداد `systemPrompt.toolOrder` مرجع أصلي قدرة اسم، في `mode: 'ptc'` تحت سوف رفض كل تجميع، لأن ذلك بعض اسم لا في هذا نمط بروتوكول تحقق نطاق داخل. هذا هو صحيح تأكيد سلوك بينما غير bug: استخدام PTC mode نشر حاجة تحديث ذلك order إعداد أو إزالة هو.

**SDK نص التوجيه مقطع.** في `'ptc'` و `'both'` تحت،tool-guidance order band في كسول صفة `tools:sdk` مقطع لـ حالي scope مرئي قدرة تصيير الذي تحميل وقت التشغيل لغة إعلان إضافة ثابت استخدام شرح (افتراضي TypeScript؛[لغة توزيع note](../../archived/feature/2026-07-31-ptc-language-dispatch.md) إضافة دخول Python و حسب `ctx.ptcRuntime.language` اختيار مصير جدول). هو مشترك فحص بحث و تنفيذ مرئي صفة، ترتيب حذف `run_code`، و حسب حرف قاموس ترتيب ترتيب صف أداة بـ نيل نيل بايت مستقر إخراج.

**تجميع كل حق.** `run_code` و `tools:sdk` بصفة صحيح معتاد تجميع إدخال دخول تلقي معلومة مهمة `system-prompt/assemble` waterfall. واحد scoped `tools:sdk` مقطع يمكن في توزيع قبل حجب حجب عام قيمة افتراضية، مستمع أيضا يمكن إزالة أو استبدال مهمة واحد مساهمة.waterfall إرجاع تجميع نتيجة هو نهائي، لذلك تعديل هذه إدخال شخص لديه مسؤولية مهمة في نشر مدة نظر PTC mode متاح وقت إبقاء بروتوكول وجه كامل صفة؛ لا يوجد استعادة pass سوف تغطية متعمد تركيب.

**شفرة توليد.** `jsonSchemaToTs()` سوف `defineTool` JSON Schema فرعي تجميع خريطة لـ TypeScript، سوف schema وصف حمل دخول JSDoc، لا دعم حمل بنية صنع تخفيض لـ `unknown`.SDK سوف أداة كشف لـ حمل جذب رقم كائن مفتاح، دعم حمل مهمة معنى اسم بينما بلا حاجة آخر اسم أو اندفاع مفاجئ معالجة. نوع هو بناء اقتراح صفة، لأن وقت التشغيل في تنفيذ قبل سوف تقشير مغادرة نوع.

### run_code أداة و توزيع جسر

في `'ptc'` و `'both'` تحت، سجل التسجيل يملك `run_code` بصفة إبقاء عرض نقل عبر طريق، حمل اثنان عدد مطلوب معامل `{ code: string; description: string }`(description لـ UI علامة ملاحظة هذا استدعاء، امتداد استخدام bash أولا مثال). هو من واحد صحيح معتاد `ToolDefinition` يمثل بـ توفير توزيع، لكن يقع في يمكن مرور ترشيح قدرة طبقة خارج، لذلك حد قاعدة لن معنى خارج إزالة PTC mode وحيد مدخل. استدعاء مرة تاريخ كامل أداة خط الإنتاج——`tools/pre-execute` → مفرد ضبط صفة حراسة حماية → `tools/execute` حزمة لف توزيع → `tools/post-execute` → من تعريف يملك اختياري `finalizeContent` → غير ممكن تغيير `tools/result` إشعار——و أصلي استدعاء تماما متسق؛ إذن إضافة يمكن في برنامج تشغيل قبل فحص برنامج نص، نهائي نتيجة مراقبة من يرى هو مواصفة تحويل خارج طبقة نتيجة. ذلك `execute(args, exec)`:

1. **بناء ربط.** واحد run درجة آخر signal تتبع مع خارج طبقة إلغاء، و في run تسوية وقت يتم abort. كل مرئي أداة ربط كل سوف مقابل بلا ضرر JSON معامل إنشاء لقطة، دخول أصلي اتفاق توزيع حوض (ضبط درجة تصميم من[فوري و سطر Agent Note](2026-07-26-ptc-live-parallel-dispatch.zh.md) مسؤول) ، بـ تحديد صفة call id و خارج طبقة token بصفة `parent` تنفيذ، عبر خارج طبقة execution تأخير بعد إرجاع سياق، و سجل `tool/ptc-dispatch-start`/`tool/ptc-dispatch` حدث مقابل، منها تسوية جانب يحمل كامل تصيير بعد نتيجة محتوى. نجاح وقت إرجاع أداة نهائي مواصفة JSON قيمة؛ فشل فإن تغيير لـ برنامج مرئي `ToolCallError`. كل فرعي استدعاء إبقاء ذاتي ذات غير ممكن تغيير تنفيذ معرف، و مرة تاريخ كامل أداة خط الإنتاج.
2. **تشغيل قد تحليل إدخال:** `ctx.ptcRuntime.run(ctx.ptcRuntime.resolve(request))`. طلب يحمل برنامج، ربط، تشغيل درجة إشارة، استدعاء Session cwd و ملائم استخدام قد تحليل ملف سياسة. تشغيل درجة إشارة سوف خارج طبقة تسوية و تنفيذ إلغاء صلة ربط.
3. **تماما توقف مستقر بعد تسوية.** وقت التشغيل تسوية بعد، جسر abort لم إتمام عمل و ترتيب فارغ توزيع طابور صف بعد مجددا إرجاع. نجاح وقت إرجاع التقاط سجل و إتمام قيمة، سوف ذلك بصفة مواصفة إخراج؛ سجل التسجيل مجددا يأخذ هذا قيمة تصيير لـ حفظ دائم `tool/result.content`، توفير نتيجة بطاقة مباشر قراءة. وقت التشغيل فشل تغيير لـ `CodeRunFailedError`؛ خلفية رفض استخدام سجل التسجيل صحيح معتاد خطأ حد. اثنان من كل إنتاج بنية تحويل خطأ نتيجة، كما `run_code` تسوية بعد لا سماح فرعي استدعاء إلحاق.

**فرعي استدعاء سياق عبر أب استدعاء تأخير بعد.** في `run_code` داخلي حقن سوف كسر تالف أب استدعاء/نتيجة متبادل مجاور صفة، لذلك `ToolRunContext.deferContext()` حسب توزيع ترتيب استلام تجميع كل فرعي نتيجة `additionalContexts` بند. أي جعل برنامج بعد قدوم رمي خروج استثناء، سجل التسجيل ما زال يحمل هذا عدد مجموعة؛ حلقة فقط في خارج طبقة نتيجة و خطوة في كل أخ أخ نتيجة بعد إلحاق كل بند. خارج طبقة post-execute منع توقف سوف إسقاط أداة تأخير بعد بند، فقط كشف منع توقف decision صريح مرفق إضافة سياق.

**تزامن هو محدود، بينما غير يتم تسلسل تحويل.** كل مرة run يملك واحد توزيع طابور صف، صارم إطار حسب إيداع ترتيب بدء استدعاء، و عبر `registry.executionMode` مقابل كل استدعاء تصنيف——و أصلي حلقة الذي استخدام fail-closed `isConcurrencySafe` اتفاق نفسه. وصل متابعة parallel صنف استدعاء الأكثر كثير إعادة تراكم `maxParallelSubCalls` عدد (افتراضي 10؛ ضبط لـ `1` استعادة سلسلة سطر توزيع) ؛exclusive صنف استدعاء سوف ترتيب فارغ حوض و مفرد وحيد تشغيل. تسوية وقت وضع ترك بعد لم بدء ترتيب طابور استدعاء. هذا note تسليم هو يتم تسلسل تحويل احتلال موضع تنفيذ؛ يحل محل هو مجدول من[فوري و سطر Agent Note](2026-07-26-ptc-live-parallel-dispatch.zh.md) مسؤول.

**عرض.** `run_code` render intent حسب[عرض معنى رسم Agent Note](../architecture/2026-07-02-tool-render-intent-union.zh.md) في هذا قرار:`presentCall` إنشاء واحد `generic` بطاقة،`kind: 'execute'`، بـ برنامج نص بصفة عنوان، و سوف نفس برنامج نص بصفة `rawInput`؛`run_code` متعمد لا إعلان `presentResult`، لذلك TUI و مضيف/عميل وقت التشغيل (Web) سوف عبر عام أصلي محتوى رجوع آلية، استخدام نهائي حفظ دائم `tool/result.content` تكملة كل هذا بطاقة، منها يشمل التقاط سجل، و قيمة راجعة، فشل معلومة أو post-policy spill معاينة. هذا لا هو `terminal` بطاقة: هذا بطاقة دلالة هو «عمل دليل في shell أمر» ، برنامج لا هو. مشاركة رؤية[نتيجة بطاقة كامل صفة شرح](../../archived/bug-fix/2026-07-20-code-mode-result-card-completeness.md).

### يمكن مراقبة قياس صفة:`tool/ptc-dispatch`

كل مرة فرعي توزيع في دخول توزيع حوض وقت إلحاق واحد فقط سجل `tool/ptc-dispatch-start` حدث، و بـ واحد `tool/ptc-dispatch` تسوية حدث استلام ذيل، بعد من يتضمن أب فرعي call id، أداة معرف، مواصفة تحويل معامل و كامل تصيير بعد `content`/`isError` نتيجة. هو لا دخول نموذج تاريخ، لكن يمكن توفير حفظ دائم و UI استخدام. إلحاق حدوث في فتح وضع `run_code` جولة داخل. لا يوجد agent مباشر تنفيذ ما زال تشغيل، لكن لا يمكن سجل هذا حدث.

جديد فرعي استدعاء استخدام `<parent>:ptc:<n>` معرف، حسب إيداع ترتيب تحرير رقم. إزالة استهلاك من سوف كل call id نظر لـ لا نفاذ واضح قيمة: ترحيل تدريجي بايت إبقاء كل تاريخ معرف، يشمل `:code:` فرعي سلسلة، لذلك توزيع حدث مقابل،spill مرجع و أخرى صلة ربط إبقاء كامل. جسر وصل طبقة سوف تحويل إرسال صورة سياق مصدر علامة لـ `{ kind: 'plugin', plugin: 'tools-ptc' }`.

[V2 إلى V3 PTC مواصفة](../../../../packages/session/session-format-v2-to-v3/README.zh.md#ptc-vocabulary) مسؤول دقيق تاريخ وسم و ملكية تحويل؛[أصلي V3 دقيق دخول](../../../../packages/session/session-format-v2-to-v3/README.zh.md#native-v3-admission) مسؤول قبل بديل وسم رفض. هذه لا هو وقت التشغيل آخر اسم: لا نفاذ واضح توسيع لا يستطيع فقط بسبب إصدار تغير حينئذ نيل نيل PTC دورة الحياة يحتوي معنى.

### ptc-runtime seam

`dsh-ptc-runtime` مسؤول `PtcRuntime` و[طلب، قد تحليل spec، ربط و نتيجة نوع](../../../../docs/subsystems/ptc-runtime.zh.md).`resolve(request)` تحقق دعم حمل cwd،timeout و سياسة اختيار و تكملة الكل توقيع قيمة افتراضية؛`run(spec)` تنفيذ كامل إدخال. أداة اسم مختلف خطوة ربط و اختياري رفض منشئ جعل وقت التشغيل لا لا بد حل سجل التسجيل خاص تحديد أداة اسم.

`language` اختيار SDK مصير و `run_code` flavor؛ لا دعم حمل لغة جعل تجميع فشل.`isolation` معرف تنفيذ أساس قاع، لا معرف إذن.`sandboxMode` يمثل مستهلك قدرة لا نقل دخول قد تحليل Session ملف سياسة. نقص قليل وقت التشغيل جعل PTC تجميع فشل،native عرض فإن لا حاجة وقت التشغيل.

برنامج نتيجة بـ حقل إرجاع؛ استدعاء جهة خطأ استخدام يمكن رفض. بلا ضرر ربط قيمة في مزود ذاتي ذات نقل حد تحت عبر تجاوز. صندوق رملي نمط، رفض و قوي صنع واقع مستقل في نجاح أو فشل.

### Node عملية وقت التشغيل

Node مزود مسح حذف يمكن مسح حذف TypeScript، في إعداد نظام الملفات/عملية فرعية عالم حد في تحليل يمكن تنفيذ ملف و bootstrap، و عبر مشترك صندوق رملي و تلقي إدارة عملية كل من بدء. كل عملية فرعية كل لديه فارغ نموذج بيئة و كل جديد برنامج عام كائن. نوع تحويل رفض منشئ و التقاط console ما زال مقابل برنامج مرئي.

ربط عبر معلومة استخدام و stdout/stderr قسم فتح مخصص استخدام تحكم عبر طريق.Host في قسم إرسال قبل تحقق لقطة، استدعاء هوية و سماح ربط. إخراج، انتظار معالجة استدعاء و عبر طريق مؤقت اندفاع لديه إعداد حد أعلى؛ إتمام، قطع توقف، إلغاء و بروتوكول فشل سوف إنهاء و انتظار تلقي إدارة نطاق. مزود README و صندوق رملي Node قرار مسؤول تأكيد قطع حد أعلى و منصة حد.

### معلومة مهمة وضع حالة

الذي اختيار OS خلفية حسب وفق و Bash نفسه سياسة قيد مباشر Node فرعي أثر. تضمين طقم أداة إبقاء سجل التسجيل سياسة و مراجعة دفعة مسار. كامل أو جزء قوي صنع قدرة مستقل تقرير إبلاغ؛ الذي يحتاج خلفية غير ممكن استخدام وقت بـ فشل إغلاق. تنظيف وراثة عملية فرعية مزود إعلان نطاق؛ عملية وصف رمز لا معنى طعم حال أكثر قوي كثير إيجار مستخدم حفظ إثبات.

### نموذج يرى محتوى

SDK إشارة عرض نموذج تحرير كتابة واحد الذي تحميل وقت التشغيل لغة مختلف خطوة دالة جسم (افتراضي يمكن مسح حذف TypeScript؛Python وقت التشغيل تحت لـ Python `async` دالة جسم——رؤية[لغة توزيع note](../../archived/feature/2026-07-31-ptc-language-dispatch.md)) ، عبر `await tools.name(args)` استدعاء أداة، في حاجة وقت التقاط يتم رفض أداة استدعاء، و فقط return أو log ينبغي إعادة دخول سياق إخراج. اثنان نوع flavor استخدام كل منها أصل لغة قديم وصف نفس اتفاق: متبادل متبادل مستقل فقط قراءة استدعاء يمكن (MAY) في `Promise.all`(TypeScript) أو `asyncio.gather`(Python) تحت إعادة تراكم، لديه فرعي أثر استدعاء حسب إيداع ترتيب مفرد وحيد تشغيل، لديه اعتماد عمل استخدام `await` ترتيب ترتيب. إعلان بادئة ممكن و أصلي schema واحد مثال كبير، خاصة ذلك في `'both'` تحت، لكن مقابل مزود ذاكرة مؤقتة إبقاء مستقر.

نقل ذاته `description` و اثنان نوع flavor SDK شرح كل بـ نقطة اسم `code` و `description` هذا اثنان عدد لا بد ملء معامل فتح رأس. يأخذ هذا استدعاء وصف صار «نقل دخول واحد برنامج» تفرق نص سوف يجعل ثاني عدد معامل فقط قدرة من معامل schema في اكتشاف، بينما فقط إرسال خروج `{code}` نموذج سوف بسبب `INVALID_ARGS` يتم رفض، وصل نفس قد كتابة جيد كامل برنامج واحد بدء فقد فقد.

## عاقبة

تبديل إلى `'ptc'` نشر يجب تحديث أي فقط حد native `toolOrder`. تجميع مستمع لديه مسؤولية مهمة صيانة أي يتم إعادة كتابة بروتوكول رسالة كامل صفة. فرعي توزيع في محدود إعادة تراكم حوض تحت حسب إيداع ترتيب بدء، بينما كل مرة استدعاء سياق سوف عبر خارج طبقة نتيجة إبقاء ذلك source، معلومة غلاف و بيانات وصفية.

## اختبار

- **Node وقت التشغيل:** مزود اختبار تغطية مباشر Node تنفيذ، قد تحليل cwd/سياسة، فارغ بيئة، نوع تحويل ربط، سيئ معنى تحكم لقطة، إخراج حد أعلى، قطع توقف، إلغاء و تلقي إدارة تنظيف.Bootstrap اختبار تغطية مصدر شفرة و بناء بعد تنفيذ.
- **سجل التسجيل تجميع صار:** اختبار تغطية شفرة توليد، كل عرض نمط، إبقاء اسم و حد قاعدة،scoped مرئي صفة، مرجعي تجميع إعادة كتابة،`toolOrder`، وقت التشغيل توافق صفة فشل، كامل خط الإنتاج فرعي توزيع،parent-token صلة ربط، تسلسل تحويل، إلغاء و طابور صف ترتيب فارغ،JSON مواصفة تحويل، خطأ نقل بث، سجل حدث، نجاح و فشل برنامج في لديه ترتيب سياق تأخير بعد، خارج طبقة منع توقف كبح صنع و HMR(حار وحدة استبدال) تنظيف.
- **حمل مفتاح e2e:** حقيقي نموذج في واحد برنامج في تركيب اثنان مرة bash استدعاء؛ آخر عدد نموذج عبر PTC mode fs توزيع اكتشاف تضمين طقم مساحة العمل إشارة أمر. اختبار تحقق طي طلب رأس، صلة ربط توزيع حدث، نتيجة ملف، تأخير بعد سياق و نموذج سلوك.
- **لقطة:** `ptc-turn`،`both-mode-turn` و `ptc-workspace-context` fixture(اختبار قبل وضع بيانات) ثابت SDK نص، طلب رأس أداة قائمة، توزيع حدث، تأخير بعد سياق و نتيجة بطاقة.TypeScript SDK PTC مشهد عبر اختبار يملك صريح profile patch تركيب Node وقت التشغيل، و ثابت Session حدث و JSON-RPC إشعار؛ مسبق مدة عودة تكرار و إتمام جولة فحص في refresh كتابة قبل تنفيذ.

## سبق اعتبار بديل خطة

**واحد صفر نواة قلب تعديل مرفق إضافة مستهلك إضافة.** مرفوض، لأن `agent/request` في[يمكن إعادة بناء طلب](../architecture/2026-07-05-reconstructable-requests.zh.md) تحت فقط حد call-config، بينما تغيير تبديل قد تجميع أداة قائمة حاجة في لا يملك ذلك إعداد حال حال تحت سحب إلغاء `toolOrder` مواصفة تحويل، و اعتماد مستمع ترتيب. نحو نموذج توفير أي بعض أداة، بـ أي نوع يمثل شكل صيغة توفير، هو سجل التسجيل مفرد واحد صلة ملاحظة نقطة: أصلي schema و SDK هو نفس عدد مرئي تخزين اثنان نوع إسقاط.

**سوف `node:vm` بصفة وقت التشغيل أمان آلية.** لغة realm لن مقابل مباشر Node API قوي صنع OS ملف/عملية سياسة. لذلك مزود استخدام مشترك صندوق رملي و تلقي إدارة عملية كل من؛ مستقل realm لا يستطيع بديل بديل هذه حفظ حماية.

**في أصلي أداة استدعاء فوق فعل نتيجة حذف/ملخص.** فقط حل قرار مشكلة في سياق تمدد انتفاخ هذا واحد نصف: قطع قص قديم `tool-result` بصفة يمكن إعادة بناء طلب تحت سجل تحويل جدول وجه استبدال صار هذا منخفض، لكن ما زال يحتاج كل مرة استدعاء مرة نموذج نحو إرجاع، كما لا يمكن جدول بلوغ حلقة، فرع أو تجميع دمج. متبادل تكملة بينما غير تنافس تنازع؛ هو يمكن في PTC mode تحت لـ ناقص بقية أصلي استدعاء قسم طبقة.

**حلقة في و سطر أصلي توزيع.** قرار عند وقت مقابل نحو إرجاع صار هذا آخر عدد جواب سجل؛ هو يتم تزامن أمان بيانات وصفية منع سد، كما بلا نقاش مثل أي كل لا توفير تركيب قدرة——هو و سطر تحويل هو نموذج في واحد خطوة في قد قرار استدعاء.PTC mode طابور صف قرار إبقاء اثنان من توافق، اثنان من بعد قدوم كل قد تسليم: بيانات وصفية أي `isConcurrencySafe`(رؤية[و سطر أداة استدعاء note](2026-07-10-parallel-tool-call-execution.zh.md)) ، أصلي rolling-pool توزيع إضافة كل أداة ربط و سطر تحويل فإن أساس في نفس عدد تصنيف جهاز.

**بداية نهاية ترتيب هو (وفي في Cloudflare، بلا نمط).** مرفوض، لأن هذا SDK رئيسي يلزم مستهلك هو تحرير رمز agent: ذلك يوم معتاد مفرد مرة استدعاء (`bash`،`read`،`edit`) بصفة أصلي استدعاء قد هو الأكثر أفضل، قوي صنع كل مرة تحرير كل عبر برنامج سوف إعطاء معتاد رؤية مشهد زيادة سالب تحمل.mode إعداد يجعل وفي فعلي شكل صيغة (`'ptc'`) فقط يحتاج واحد سطر إعداد يكفي تفعيل، بينما لا قوي إضافة في شخص.

**كل أداة مرئي صفة قسم طبقة (هذا أداة native، ذاك أداة ptc-only).** دفع متأخر: هو حاجة كل أداة بيانات وصفية و `'native' | 'ptc' | 'both'` لا توفير عرض تفكيك قسم، كما ذلك تصميم أخذ قرار في نموذج في `'both'` تحت مثل أي قسم إعداد استخدام دليل.

**SDK في صاف نظيف تحويل معرف رمز آخر اسم**(`my-tool` → `my_tool`،Cloudflare فعل قاعدة). مرفوض:`declare const` فوق حمل جذب رقم مفتاح جعل كل اسم يمكن بلوغ، صفر آخر اسم اصطدام اصطدام منطق؛ نموذج قدرة صحيح معتاد معالجة `tools["my-tool"](…)`.

**REPL ريح إطار حمل دائم داخل نواة**(حالة عبر `run_code` استدعاء تخزين نشط). في MVP في مرفوض: عبر استدعاء حالة مقابل جلسة سجل غير ممكن رؤية، كسر تالف «كل طلب هو سجل صاف دالة» هذا واحد يمكن إعادة بناء صفة حفظ إثبات؛ كل مرة run متساو استخدام كل جديد نسخة فإن صيانة حمل هذا واحد حفظ إثبات. داخل نواة ريح إطار خلفية في لم قدوم ما زال يمكن عبر نفس seam جدول بلوغ، إعداد دمج ذاتي ذات سجل خطة.

## ريح خطر

**منصة قوي صنع قدرة و تنظيف قدرة مختلف.** وقت التشغيل تقرير إبلاغ الذي اختيار صندوق رملي خلفية كامل صفة، و وراثة تلقي إدارة عملية كل من نطاق. لا دعم حمل أو جزء منصة حفظ إثبات إبقاء واضح، لا إخفاء في isolation وصف رمز بعد.

**`stripTypeScriptTypes` علامة لـ experimental.** هو و Node ذاته أصلي `.ts` تنفيذ خلف بعد جذب محرك (amaro/swc) نفسه، في هذا مستودع كامل جذب محرك نطاق داخل بصفة API كشف. مؤقت حل إجراء تطبيق: وقت التشغيل اختبار وحدة طقم عنصر سوف فحص موضع إبقاء و يمكن مسح حذف حد رفض رسالة في مطلوب جزء؛ استدعاء يقع في واحد خاص دالة بعد، كما `amaro`/`sucrase` يمكن في API تغير وقت مباشر استبدال هو. فقط يمكن مسح حذف فرعي تجميع هو موجه إلى نموذج إدخال حد، خطأ رسالة سوف إبلاغ إبلاغ نموذج مثل أي إصلاح صحيح برنامج.

**SDK نص التوجيه صار هذا، خاصة ذلك في `'both'` تحت.** `.d.ts` ممكن و هو تكملة ملء أصلي schema جسم كمية متبادل عند؛`'both'` يحمل اثنان نوع يمثل. بادئة مستقر صفة + مزود ذاكرة مؤقتة توزيع إلغاء كل جلسة صار هذا؛mode حسب نشر إعداد؛ هذا Agent Note لا فعل بلا شرط عقدة حذف إعلان. أي وقت أولوية استخدام أي نوع نمط كمية تحويل إشارة توجيه واضح يخص فوق خط بعد تعلم تعود.

**سجل التسجيل scope زيادة طويل.** `dsh-tools` امتصاص استلام شفرة توليد، واحد أداة، واحد جسر و واحد حدث. حزمة داخل وحدة يأخذ هذه مسؤولية قسم فتح (`ts-types.ts`،`ptc.ts` و `schema.ts`،`json-schema.ts`،`presentation.ts` و صف) ، كل ptc-runtime مخصص استخدام تنفيذ كل من `ctx.ptcRuntime` توفير.

**كبير نوع ربط قيمة ما زال ممكن استهلاك كل داخل تخزين.** Node مزود حد تحكم لقطة، لم إتمام معامل و ترتيب طابور كتابة، بينما Host ربط يمكن في هذه فحص قبل قسم إعداد ذلك نتيجة. بلا ضرر JSON نقل و خارج طبقة إخراج حساب هذا لا بنية صار عملية درجة قسم إعداد إعداد مقدار.

**فرعي توزيع إعادة تراكم من أداة ذاته أمان إعلان حد تحديد، بينما غير من استدعاء جهة قرار.** برنامج داخل `Promise.all` أو `asyncio.gather` فقط في أداة ذاتي ذات تصنيف لـ تزامن أمان استدعاء بين تبديل قدوم تعليق ساعة و سطر صفة؛ واحد سلسلة exclusive استدعاء ما زال يلزم حسب ترتيب دفع خروج كل منها نحو إرجاع فتح إلغاء، نموذج ممكن مرور درجة مدة نظر. اثنان نوع flavor SDK شرح كل قديم وصف حقيقي اتفاق. هذا note تسليم هو جعل هذا ريح خطر قطعا مقابل تحويل تسلسل تحويل احتلال موضع تنفيذ؛ مجدول و ذلك إعادة تراكم حد أعلى من[فوري و سطر Agent Note](2026-07-26-ptc-live-parallel-dispatch.zh.md) مسؤول.

**مرور مرور وقت قطع توقف يشمل يتم انتظار عمل.** تضمين طقم أداة و مراجعة دفعة انتظار إزالة استهلاك برنامج مرور مرور وقت ميزانية.Host في قطع توقف إلى مدة وقت إيقاف تنفيذ و انتظار تلقي إدارة تنظيف؛ هو لا حساب كمية عملية شجرة CPU إزالة استهلاك. صندوق رملي Node قرار سجل حالي قيمة افتراضية و تأخير بعد تقييم تقدير timeout مشكلة.
