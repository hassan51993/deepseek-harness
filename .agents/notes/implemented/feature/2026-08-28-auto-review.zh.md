# Agent Note: كل مرة أداة استدعاء قبل فعلي تحقق صفة Auto review

Status: implemented

[English](2026-08-28-auto-review.md) | العربية

## مشكلة

Full access يجعل لديه استخدام مشروع عمل بلا حاجة عكس تكرار مراجعة دفعة يكفي متابعة، لكن أيضا سماح كسر تالف صفة عملية و حساس شعور معلومة خارج تسرب. يأخذ مراجعة دفعة تفويض حمل إعطاء نموذج إذن نمط حاجة واضح مرجعي سياسة، كامل انتظار تنفيذ حركة عمل وصف، و أبدا تنفيذ يتم رفض body فشل مسار. مشترك استخدام Full access تنفيذ دوران زر أيضا جعل مستقل حمل دائم نمط هوية يصبح لا بد يلزم، يشمل child وراثة مقارنة مبكر fork بادئة حال حال.

## قرار

[`dsh-experimental-auto-review`](../../../../packages/experimental/auto-review/README.zh.md) هو صريح تثبيت فعلي تحقق صفة Web طبقة، حسب[فعلي تحقق حزمة إصدار قرار](../process/2026-09-12-publish-all-experimental-packages.zh.md) مشاركة و إصدار. افتراضي Web إبقاء Read Only،Workspace Write و Full access. هذا طبقة مساهمة فقط حد حالي جلسة `auto`، وحيد حمل دائم هوية لـ `permission/preset:auto`؛ هو مشترك استخدام Full access لم تغيير `danger-full-access + never` دوران زر و أداة تعريف.Headless، عام ضبط و جديد جلسة قيمة افتراضية كل ترتيب حذف هذا integration.

كل أصلي استدعاء و قد بدء PTC `tools.*` inner call كل في body قبل قبول مرة مراجعة فحص. خارج طبقة `run_code` transport و PTC برنامج داخل مباشر Node فاعلية نتيجة لا في حفظ إثبات نطاق داخل. لا توفير حسب أداة اسم إعفاء تجنب، ذاكرة مؤقتة grant، إعادة محاولة، يمكن إعداد سياسة، ثاني تخويل فحص أو شخص عمل fallback. تكرار استدعاء أيضا إعادة مراجعة فحص.

### فاعلية نتيجة و مرجعي

ثابت سياسة التزام دوران allow/soft-deny/hard-deny منطقة قسم، حسب حركة عمل فعلي فاعلية نتيجة تصنيف، لا حسب اسم أو صوت تسمية معنى رسم تصنيف:

| ريح خطر | عرض مثال | قرار |
| --- | --- | --- |
| `low` | عادي مشروع داخل قراءة كتابة، قسم تحليل،format/lint/test/build، غير كسر تالف صفة Git، و إبقاء استدعاء قدرة إثبات في هذا Session إنشاء كائن دقيق تنظيف | سماح |
| `medium` | غير ممكن عكس حذف قائم حالة،force push/تاريخ تعديل كتابة، إنتاج قراءة كتابة/نشر، غير حساس شعور خارجي كتابة/إرسال، و إذن/أمان/نظام تغيير | فقط لديه حالي human أو مباشر أب درجة واضح تخويل حركة عمل، دقيق تأكيد هدف و لا بد يلزم نطاق وقت عندئذ سماح |
| `high` | حساس شعور بيانات عبر تجاوز حالي معلومة مهمة حد خارج تسرب و انتظار قيمة hard-deny فاعلية نتيجة | رفض، يشمل صريح طلب حركة عمل |

فعلي فاعلية نتيجة لا واضح أو تجاوز خروج قد تأكيد قيام نطاق وقت حسب رفض معالجة. لاحق إشارة أمر فقط لديه واضح سحب إلغاء أو استبدال قديم إشارة أمر عندئذ قدرة إزالة حذف اندفاع مفاجئ؛ مباشر أب درجة إشارة أمر لا يستطيع تغطية human حد. تاريخ يمكن إثبات كائن من هذا جلسة إنشاء، لكن لا يستطيع تخويل medium عملية أو حل حذف high منع أمر.

Reviewer من قائم Session واقع إرسال توليد مرجعي.Shipped Web human إشارة أمر أداة لديه `source.kind === 'user'` و متصفح prompt admission كتابة `rpcId`.Child ابتدائي مباشر أب درجة prompt في ذلك ذاته قائم إنشاء descriptor بعد تعرف آخر؛ لاحق `agent-message` فقط لديه `senderSessionId` و `SessionHeader.parentSession` مطابقة وقت عندئذ يخص مباشر أب درجة إشارة أمر.Human نص تعريف أو استبدال مهمة و حد. مباشر أب درجة نص في هذه حد داخل تعريف child مهمة. مشروع إشارة أمر فقط تطبيق إضافة قيد؛checkpoint استعادة لديه ضرر لغة بيئة؛ صورة، مرفق عنصر بيانات وصفية و تاريخ استدعاء توفير واقع.Compaction لن يأخذ checkpoint رفع رفع لـ قد مغادرة فتح surface أصل نص الذي يملك human مرجعي.

### مرة كامل reviewer طلب

Integration فقط استخدام الأكثر جديد `request/header.config` provider/model و shipped adapter افتراضي reasoning. هو حيث لا مقارنة مقارنة زائد بقية route metadata، أيضا لا نسخ رئيسي agent طلب. طلب ثابت يتضمن خمسة عدد قسم منطقة:

| قسم منطقة | إبقاء إدخال |
| --- | --- |
| `REVIEW_POLICY` | ثابت تصنيف، مصدر مرجعي و صارم إطار نتيجة قاعدة؛allow بعد قيام أي بـ Full access تنفيذ، لا يوجد لاحق تأكيد |
| `ENVIRONMENT` | فقط قائم Session header `cwd` |
| `PROJECT_INSTRUCTIONS` | مرئي مشروع إشارة أمر، إبقاء أصلي مصدر و منح إعطاء قيد زاوية لون |
| `FILTERED_HISTORY` | حالي compaction surface في حمل مصدر human/مباشر أب درجة رسالة،checkpoint، صورة/مرفق عنصر واقع، و تاريخ استدعاء اسم و سجل معامل |
| `PENDING_ACTION` | أداة اسم، وصف، معامل schema و تحليل بعد arguments |

reviewer من Session كامل حركة عمل تاريخ بناء هذا اثنان عدد حركة عمل قسم عقدة: تخويل هو رمز دمج `REVIEW_POLICY` مصدر قاعدة ذلك عدد أكثر مبكر استدعاء، بينما تكرار أو اندفاع مفاجئ هوية يجب في كامل نسخة سجل أي موضع كل مرئي، بينما لا هو فقط في قريب مدة نافذة داخل مرئي، لذلك Session إسقاط و محدود قراءة كل لا يمكن دعم دعم هذا حكم تحديد. هذا مرة قراءة استخدام قد ملغى ترك تزامن `snapshotEvents()`، و حمل لديه سطر درجة `typescript/no-deprecated` إعفاء تجنب.

رئيسي agent V3 `system/message` عقدة،assistant متن/reasoning و tool results الكل ترتيب حذف. حالي استدعاء يجب يخص `step/start` سجل فتح وضع step؛ نقص قليل step ملكية وقت رفض تنفيذ. هذا استدعاء فقط في `PENDING_ACTION` ظهور؛ بعد لم بدء sibling لا يوجد تاريخ استدعاء واقع. أصلي schema قدوم ذاتي الأكثر جديد request header.PTC في binding بنية صنع وقت التقاط تجميد ربط schema، مرور من مجدول نقل دخول `ToolExecution`؛ وصف و معامل schema لا دخول بدء/تسوية حدث أو Session/SDK wire. حركة عمل واقع ناقص، لا متسق أو لديه اختلاف معنى وقت رفض استدعاء، لا استعلام live registry. تجاوز نافذة طلب مباشر رفض، لا فعل ملخص، قطع قطع، مقدار خارج compaction أو ضبط صغير نوع إخراج token ميزانية.

### نتيجة و إلغاء

Reviewer يمكن إخراج reasoning blocks، مع بعد تماما جيد واحد JSON text block و نهاية حالة `stop`. غلاف إغلاق كائن فقط سماح `low + allow`،`medium + allow/deny` و `high + deny`؛ فقط لديه deny يمكن يحمل نص `reason`. مقدار خارج حقل، تكرار عضو، غير قاعدة تركيب، أخرى block أو نهاية حالة و provider فشل متساو استخدام عادي Auto رفض نتيجة. ريح خطر و reviewer trace لا يصبح حمل دائم حالة.

أصلي نتيجة و PTC تسوية حدث يحمل نفس شكل بنية تحويل `AutoReviewDeniedError`/`AUTO_REVIEW_DENIED` و اختياري أصلي إدارة من. رئيسي agent عبر عادي فشل تصيير فقط استلام إلى `Auto review rejected tool "<name>"; its body was not executed`.PTC إبقاء قائم برنامج استثناء/catch سلوك؛ التقاط رفض لن سوف ذلك رفع رفع لـ خارج طبقة فشل. عام Web أداة بطاقة لـ طي سطر توفير رفض هوية، لـ توسيع سطر توفير واحد سطر لم تنفيذ إخراج، لا توفير إدخال متن. فقط لديه هذا عرض مرور مسار سوف trim، طي سطر قسم فصل رمز، أو توفير محلي تحويل فارغ إدارة من fallback؛ حفظ دائم و اثنان طقم SDK إبقاء كامل أصلي إدارة من، لا زيادة طويل درجة أو انفصال حساس قاعدة.

دقيق دخول و في طريق review تسجيل تسجيل في أول مرة await قبل تزامن إتمام.Integration يملك واحد دورة الحياة controller و واحد في طريق عملية تجميع دمج. إزالة أولا إغلاق جديد اختيار/review admission، مرور من قائم preset writer يأخذ تخزين نشط Auto Session قطع لـ Full access، لا تغيير دوران زر، لا إغلاق طرفية، لكن بعد في توقف و انتظار review ربط صاف، الأكثر بعد إزالة listener و contribution.Provider تسوية بعد،lifecycle abort بداية نهاية شكل صار مواصفة dispatch قبل إلغاء، يشمل متأخر إلى allow،deny أو failure.Caller إلغاء إبقاء ToolRuntime أولوية درجة: متأخر إلى allow في dispatch قبل إلغاء؛ متأخر إلى deny أو failure إبقاء أصل نتيجة. يتم إلغاء review لا بدء أداة body.

كامل integration ناقص أو فشل وقت، حمل دائم Auto Session لا يستطيع إصدار. سجل لا تعديل كتابة، أيضا لا خلفية إعادة محاولة. إعادة تركيب بعد مستخدم يمكن إعادة فتح هو؛ قد ترحيل لـ Full access تخزين نشط Session إبقاء أصل حالة، مباشر إلى صريح تبديل.

### عملية دليل و child

Permission owner عبر توليد `permissionPresets` Remote طريقة إصدار واحد نسخة كامل عملية دليل؛BFF صريح تركيب هو، و تحويل إرسال بلا payload بطلان حدث. واحد متصفح دليل في قراءة قبل حجز قراءة، لـ اثنان عدد اختيار جهاز توفير بيانات.Epoch و connection-generation فحص فقط إصدار فوز خروج كامل نتيجة. فوز خروج قراءة فشل أو connection reset سوف صاف فارغ قديم لقطة؛ فقط لديه لاحق قائم قراءة، إشعار أو reset عندئذ إعادة محاولة. قد dispose أو قديم قديم تسوية لا يستطيع إصدار. كل مرة دليل بطلان كل عبر أمر owner إغلاق slash اختيار جهاز و انتظار تأكيد محادثة إطار، معا إبقاء مسودة مسودة، لذلك انتظار ذاته قراءة اختيار جهاز ما زال إبقاء فشل و إعادة محاولة حالة؛ إعادة فتح وقت تحميل حالي دليل.Session إسقاط فقط يحمل حالي اختيار، لذلك دليل تثبيت أو إزالة لا كتابة Session حدث أو ترتيب رقم.

Auto حمل يمين فوق علامة `EXP`. اثنان عدد مرئي حالي جلسة اختيار جهاز كل اشتراط فعلي تحقق تأكيد؛ صريح `/permission auto` قد بنية صار نفس معنى.Composer استخدام عام Menu قائم portal تحديد موضع إبقاء في نظر فتحة داخل، معا إبقاء 218–360px حد.Slash popup إبقاء `min(220px, 100%)` و `max-width: 100%`، ضيق composer سوف trigger طي وقت أيضا واحد مثال.

[تفويض إرسال وقت إذن التقاط](2026-07-25-subagent-policy-inheritance.zh.md) في أول مرة await قبل سجل Auto أو Full access، و في fork seed و sandbox/approval override بعد إلحاق هذا قائم preset event. مفرد مرة و يمكن متابعة إنشاء مشترك استخدام هذا قاعدة؛cold resume فقط قراءة child سجل. لاحق parent تبديل لا تغيير هذا child، لاحق child ذاتي ذات تبديل ما زال يمكن فوز خروج.Read Only و Workspace Write إبقاء sandbox وراثة إضافة `approval: never`، لذلك ممكن إبقاء `custom`.Auto child استخدام قائم lineage و رسالة مستقل تصنيف كل مرة استدعاء، لا زيادة أب call metadata، تفويض إرسال سجل،receipt،Header/descriptor حقل أو Session format. عملية خارج child في أب تفويض إرسال نيل دقيق بعد إبقاء ذاتي ذات إذن نظام.

## اعتبار مرور بديل خطة

**افتراضي أو صحيح صيغة إصدار integration** سوف يأخذ فعلي تحقق نموذج مراجعة دفعة سياسة حمل دخول كل نشر. خاص شفرة المصدر Web patch في إعادة استخدام قائم إضافة تثبيت جهاز معا إبقاء صريح opt-in.

**إضافة جديدة sandbox أو approval-policy قيمة**سوف يأخذ review و تنفيذ اقتران دمج، إنتاج لا يوجد حالي إزالة استهلاك من تركيب. صريح preset هوية إبقاء Full access لم تغيير تنفيذ سلوك.

**حفظ دائم PTC schema أو إعادة قراءة registry**يلزم ما لـ مؤقت إدخال توسيع ورقة حمل دائم wire، يلزم ما مراجعة فحص و برنامج استلام إلى binding مختلف تعريف.Binding قد يملك الذي يحتاج غير ممكن تغيير لقطة.

**استخدام Session حدث جدول بلوغ دليل تغير**سوف يأخذ عملية متاح صفة عودة إلى Session، و اشتراط نفس ترتيب رقم إعادة إصدار. كامل Remote قراءة إضافة بطلان إشعار يجعل كل بند واقع إبقاء في ذاتي ذات owner.

**يمكن إعداد سياسة، إعفاء تجنب،grant أو آخر عدد مراجعة دفعة مرحلة مقطع**سوف تقليل ضعيف ثابت أمان حد أعلى، أو جذب دخول ثاني عدد قرار دورة الحياة. كل تلقي دعم حمل استدعاء مرة review توفير مفرد واحد نتيجة و إلغاء owner.

## عاقبة

Auto زيادة نموذج تأخير متأخر و token صار هذا، و ممكن خطأ حكم فاعلية نتيجة.Full access تنفيذ و PTC برنامج حد جعل فعلي تحقق تأكيد يصبح لا بد يلزم. مرور ترشيح حد غير ممكن معلومة إشارة أمر زاوية لون، لكن لن يأخذ LLM تصنيف جهاز تغيير صار تحديد صفة أمان حد.

تجمع تركيز owner اختبار ثابت طلب مرور ترشيح، صارم إطار استجابة تحليل، رفض نقل بث، دليل ترتيب، إلغاء و seed بعد child هوية. حقيقي Web composition اختبار تغطية افتراضي/فعلي تحقق قائمة مفرد، تأكيد، رفض بطاقة،live إزالة/إعادة تركيب، حمل دائم استعادة و طرفية تخزين نشط. إقرار إثبات runner في عزل هدف فوق استخدام shipped tools، صارم إطار إرسال بدء ثمانية مرة حقيقي reviewer استدعاء:Flash تغطية دقيق تنظيف هذا جلسة إنشاء كائن، لم تخويل/قد تخويل حذف قائم كائن، و صريح طلب دمج صار حساس شعور معلومة خارج تسرب؛Pro و Vision كل فقط تكرار medium pair. هو سجل انفصال حساس قرار و خارجي فاعلية نتيجة، لا إعادة محاولة، لا قفز مرور case؛ تحديد صفة اختبار في بلا اعتماد وقت توفير نفس شكل سياسة حالة استخدام.
