# Agent Note: Windows طاولة وجه قمة شريط و تطبيق قائمة مفرد

Status: implemented

[English](2026-09-16-windows-desktop-titlebar.md) | العربية

## Problem

Windows حاجة ضيق تجميع قمة شريط، في جانب شريط إخفاء أو ملف فرش ممتلئ محتوى منطقة وقت ما زال إبقاء جانب شريط تنقل. مستقل تطبيق/تحرير قائمة مفرد كثير احتلال واحد سطر، كما ممكن و تطبيق لغة مختلف. مشترك عميل يجب إبقاء عادي Web و macOS عرض.

## Decision

Windows رئيسي نافذة تركيب Electron إخفاء عنوان شريط و أصلي نافذة حسب زر تغطية طبقة. فقط لديه محلي تطبيق preload إصدار `data-windows-titlebar`؛ مشترك تخطيط، جانب شريط و كل شاشة وجه لوح قاعدة متساو اشتراط هذا علامة. أصلي قمة شريط لون لون و يمين مفتاح قائمة مفرد لغة تتبع مع تطبيق وثيقة. مصير رسالة فقط قبول رئيسي نافذة رئيسي إطار هيكل مصدر.

Windows إزالة مستقل أصلي قائمة مفرد سطر. تطبيق preload في عزل shadow root في تركيب محلي تحويل “تطبيق” و “تحرير” قمة شريط مدخل، رئيسي عملية لـ عبر تحقق طلب فتح أصلي نابض خروج قائمة مفرد.“تطبيق” و أخرى منصة مشترك استخدام أمر نموذج لوح؛ “تحرير” إبقاء Windows أصلي أمر تجميع دمج، و صريح توفير من لغة حرف قاموس إدارة وسم. قمة شريط تنقل إعادة استخدام قائم جانب شريط عودة ضبط، لا آخر بناء تنقل تخزين، استلام بدء حالة جديد بناء جلسة تحكم عنصر يقع في جانب شريط فتح صلة و قائمة مفرد بين.[macOS قمة شريط قرار](2026-09-13-macos-hidden-titlebar-vibrancy.zh.md) ما زال مستقل ملائم لأجل macOS.

## Alternatives considered

حسب Alt عرض أصلي قائمة مفرد سطر مقدار خارج احتلال استخدام رأسي نحو فضاء، كما اعتماد مفتاح قرص معتاد مثال عندئذ قدرة اكتشاف. تماما إزالة أمر سوف فقد فقد يد حركة تحديث و تحرير أمر. إضافة إدارة استخدام رئيسي تطبيق “إضافة” صفحة. قمة شريط مدخل إبقاء هذه عملية بينما لا زيادة قائمة مفرد سطر. أصلي نابض خروج قائمة مفرد إبقاء أمر تنفيذ و مفتاح قرص تنقل، بلا حاجة في Web مكون في تكرار تحرير جهاز عملية.

ذاتي تعريف HTML نافذة حسب زر سوف يجعل تطبيق تحمل تحمل أصلي قمة شريط تفاعل. أصلي تغطية طبقة إبقاء هذه حسب زر، معا سماح تطبيق محتوى عرض في جانب حافة. عام CSS تعديل سوف أثر Web و macOS؛ من preload يحتفظ علامة سوف عرض حد في Windows رئيسي نافذة.

## Consequences

قمة شريط في كل شاشة ملف وجه لوح فوق جهة إبقاء متاح، استلام بدء تنقل لم يعد احتلال استخدام رأسي نحو مسار طريق. قمة شريط قائمة مفرد إبقاء تطبيق و تحرير أمر، عادي Web وثيقة لا نيل نيل طاولة وجه تحكم عنصر. تحرير عملية نحو حالي تحرير جهاز إرسال مقابل حسب مفتاح، بـ استخدام تحرير جهاز ذاته سحب إلغاء تاريخ. قمة شريط مدخل يقع في محتوى نابض نافذة حجب غطاء لـ فوق. مفتاح قرص تنشيط في إرسال إرسال قبل استعادة فوق واحد تحرير جهاز و اختيار منطقة؛ إشارة إبرة تنشيط إبقاء تحرير جهاز تركيز نقطة؛ قائمة مفرد إغلاق بعد صاف حذف مدخل تنشيط حالة. رئيسي عملية تحقق رفض أخرى إطار هيكل، لم معرفة قائمة مفرد اسم و بلا فاعلية مرساة نقطة جلوس علامة. أصلي نابض خروج قائمة مفرد خارج مراقبة تتبع مع عملية نظام.

## Testing

طاولة وجه بدء و preload اختبار تغطية منصة عزل، لغة تغيير، ضبط لون لوح رسالة، مصدر تحقق، أصلي أمر خريطة، قائمة مفرد دورة الحياة و طاولة وجه إضافة سريع سريع مفتاح ناقص. قائمة مفرد و جانب شريط محلي لقطة تغطية محلي تحويل مدخل و توسيع، استلام بدء تحكم عنصر؛ تخطيط اختبار تغطية صفر عرض درجة استلام بدء. نافذة تحقق تغطية أصلي نابض خروج قائمة مفرد، قمة شريط تنقل و كل شاشة تجنب يجعل. عادي متصفح تحقق فحص طاولة وجه تحكم عنصر ناقص و جانب شريط مسار طريق إبقاء.
