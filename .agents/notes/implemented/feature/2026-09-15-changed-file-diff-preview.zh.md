# Agent Note: جولة review tab

Status: implemented

[English](2026-09-15-changed-file-diff-preview.md) | العربية

## Problem

[تعديل ملف بطاقة](2026-09-11-turn-changed-files-card.zh.md) إبلاغ إبلاغ مستخدم واحد جولة تعديل أي بعض ملف، تعديل كثير قليل سطر، لكن لا قول تعديل ماذا. نقطة واحد سطر فتح هو ملف حالي محتوى، في Sidebar داخل أو في طاولة وجه تطبيق داخل، حيث نظر لا إلى هذا جولة تحرير، أيضا نظر لا إلى تحرير قبل حالة.git تغطية لا إلى ملف——يتم تجاهل اختصار ملف، مستودع خارج ملف، و لا يوجد مستودع عمل دليل داخل كل مرة ملف أداة تحرير——فقط لديه ملف أداة مع نتيجة حفظ دائم hunk: سياق لا كامل، سطر عدد حسب تكرار تحرير تراكم إضافة، تماما لا يوجد كامل ملف مقابل مقارنة.

## Decision

بطاقة كل واحد سطر في يمين جانب Sidebar فتح هذا جولة `changes-review` tab و اختيار في هذا ملف، بطاقة رأس جزء فإن في رقم واحد ملف فوق فتح هو: كل جولة واحد tab، من حالي فحص نظر Session و إعلان إبلاغ حدث ترتيب رقم تحديد عنوان، رأس جزء لديه واحد صف خروج كل سجل ملف ملف اختيار جهاز، مرة عرض واحد ملف في جولة بدء و انتهاء وقت مقابل مقارنة.Host جانب [workspace-changes](../../../../packages/deliverables/workspace-changes/README.zh.md) سجل جهاز عبر `workspaceChanges.diff(sessionId, seq, index, signal)` توفير كل مقابل مقارنة؛[إنتاج خروج شيء إضافة](../../../../packages/client/ui-deliverables/README.zh.md) تسجيل هذا tab نوع، يأخذ سطر ملف تحت علامة بصفة تنقل معامل نقل دخول، و عبر مرور مرور إقرار إثبات توجيه قراءة ملخص و مقابل مقارنة. رأس جزء أداة في مفرد شريط و يسار يمين عرض بين تبديل، تبديل تلقائي تبديل سطر، في Sidebar في فتح حالي كامل ملف، لديه Host طاولة وجه وقت استخدام افتراضي تطبيق فتح هو؛ عرض و تبديل سطر اختيار حسب tab إبقاء. لديه لا يوجد طاولة وجه، سطر و رأس جزء كل فتح review، أولا قبل سطر درجة آخر أصلي فتح و رأس جزء فتح ملف مشبك كل نقل دخول tab، بطاقة فقط إبقاء واحد نوع سلوك.

git تغطية لا إلى ملف حسب Codex turn diff tracker مقابل مقارنة ذلك `apply_patch` تحرير طريقة مقابل مقارنة: استخدام كامل ملف فرعي هذا، لا استخدام hunk. في `write`،`edit` أو لديه تعديل أثر `str_replace_editor` استدعاء تشغيل قبل، سجل جهاز هذا قدوم حينئذ يلزم انتظار أساس خط لقطة `tools/pre-execute` خطوة يأخذ الذي إشارة ملف نسخ إلى Session مؤقت دليل داخل لقطة كائن جانب حافة، كل جولة كل مسار مرة؛ جولة انتهاء وقت مجددا نسخ مرة هذا مسار. فرعي هذا حسب ذلك بايت SHA-1 تسمية، نفسه محتوى فقط تخزين واحد نسخة، كما لا حاجة git. لقطة تغطية إلى مسار إبقاء git سطر عدد؛ ذلك بقية كل يتم التقاط مسار من اثنان نسخة فرعي هذا تدريجي سطر مقابل مقارنة صف خروج، عكس تكرار تحرير سطر فقط حساب مرة، ملف أداة تحرير بعد shell تعديل أيضا يتضمن في داخل. سجل جهاز لم يعد قراءة حفظ دائم hunk و من معامل دفع خروج hunk.

اثنان عدد حد أعلى يجعل فرعي هذا و مقابل مقارنة إبقاء صغير.`maxFileBytes` حد فرعي هذا و لـ مقابل مقارنة بينما قراءة خروج لقطة blob؛ أكثر كبير ملف صف خروج وقت حمل `oversized`، لا يوجد سطر عدد، ذلك مقابل مقارنة يتم رفض، كامل ملف فرعي هذا لذلك سالب تحمل نيل بدء.`diffTimeoutMs` حد تدريجي سطر مقابل مقارنة، و Codex واحد مثال هو 100 جزء ثانية؛ مهلة بعد تراجع تحويل لـ واحد استبدال الكل سطر hunk، علامة `coarse`، لذلك مرض حالة ملف من لن سحب إقامة هذا جولة سجل أو tab. اثنان من كل هو Config حقل.

مقابل مقارنة في يتم طلب وقت في Host فوق حساب حساب، مصدر هو حفظ في الذي توفير ملخص جانب حافة اثنان جانب محتوى مصدر: لقطة شجرة في مسار، استخدام `ls-tree -l` و `cat-file blob` في بايت حد أعلى لـ داخل قراءة خروج؛ أو من من مغناطيس قرص قراءة فرعي هذا.git تقرير إبلاغ لـ اثنان دخول صنع لقطة واحد جانب و يحتوي NUL بايت فرعي هذا لا توفير سطر.tab تصيير حمل قديم جديد سطر رقم hunk، لا يوجد لغة قاعدة عال مضيء؛ يسار يمين عرض يأخذ كل واحد مقطع حذف و ضيق مع ذلك بعد إضافة جديدة تدريجي سطر إعداد مقابل.Host قد لم يعد توفير مقابل مقارنة، قراءة فشل، اثنان دخول صنع ملف و مرور كبير ملف كل عرض واحد سطر.

محتوى ما زال فقط في هذا Host عملية داخل مع Session تخزين نشط، هذا هو بطاقة قرار قد تحديد تحت؛ مقابل مقارنة و بطاقة نفس عمر أمر، لذلك Host إعادة بدء بعد إعادة فتح محادثة اثنان من كل لا يوجد.

## Alternatives considered

**يأخذ كامل ملف قبل بعد نص وضع دخول ملف أداة نتيجة بيانات وصفية**، مثل Codex `apply_patch` إرجاع ذلك مثال، سوف يأخذ كل يتم تحرير ملف اثنان مرة كتابة دخول Session سجل. سجل جهاز تعديل لـ ذاتي ذات التقاط ملف، سجل متابعة فقط يحمل جولة رقم.

**يأخذ فرعي هذا وجود داخل تخزين داخل**، مثل Codex كل جولة tracker ذلك مثال، سوف مع كل واحد جولة زيادة طويل، لأن سجل يلزم نشط إلى Session انتهاء؛ فرعي هذا وضع إلى Session مؤقت دليل داخل لقطة كائن جانب حافة، فقط في طلب مقابل مقارنة وقت قراءة.

**يأخذ فرعي هذا تخزين لـ خاص كائن مكتبة داخل git blob** قدرة و لقطة مشترك استخدام واحد بند قراءة مسار، لكن سوف يجعل ملف أداة هذا بند مسار اعتماد git، بينما لا يوجد مستودع أو لا يوجد git عمل دليل إعطاء لا هو؛ نفس دليل تحت عادي ملف يجعل هذا بند مسار و git غير متصل.

**إعطاء مستودع خارج عمل دليل بناء أثر فرعي مستودع**ما زال دفع متأخر؛ فرعي هذا قد تغطية ذلك داخل ملف أداة تحرير، هذا هو مستخدم قدرة أخذ أخذ سطر حركة جزء.

**كل ملف واحد tab**، بـ ملف اسم عمل عنوان، هو رقم واحد إصدار تنفيذ؛ مراجعة قراءة واحد جولة معنى طعم حال كل سطر واحد tab. كل جولة واحد tab إضافة ملف اختيار جهاز يأخذ واحد جولة تعديل وضع في واحد بدء، سطر ما زال قدرة سقوط إلى ذاتي ذات ملف فوق.

**tab داخل لغة قاعدة عال مضيء**دفع متأخر إلى صاف نص عرض يتم إثبات لا كاف استخدام وقت مجددا فعل.

**إبقاء سطر فتح حالي ملف**سوف يجعل مقابل مقارنة كثير مرة نقر عندئذ قدرة وصول؛ حالي ملف ما زال يمكن من متن رابط و ملف tab فتح.

## Consequences

كل مرة ملف أداة تحرير في Host فوق كل جولة قراءة كتابة مرة كامل ملف، تلقي `maxFileBytes` حد، أي جعل لقطة أيضا تغطية هذا مسار؛Session مؤقت دليل حفظ فرعي هذا مباشر إلى تحرير. لم تغطية ملف مقابل مقارنة سطر عدد هو أول ذيل مقابل مقارنة، لا هو تراكم إضافة؛ اثنان جانب كل تجاوز مرور حد أعلى ملف صف لـ `oversized` بينما لا هو فقد إسقاط، لأن لا قراءة مرور محتوى دائم بعيد لا يستطيع إقرار تحديد لـ لا يوجد تعديل. مرة مقابل مقارنة الأكثر كثير زهرة استهلاك اثنان مرة `ls-tree`، اثنان مرة `cat-file` و مرة محدود تدريجي سطر مقابل مقارنة؛ مهلة مقابل مقارنة يحمل اثنان جانب الكل سطر، الأكثر كثير اثنان ضعف `maxFileBytes`،tab الأكثر كثير رسم صنع منها 5000 سطر. مقابل مقارنة توجيه سوف يأخذ الذي صف ملف في Host فوق سجل وقت كامل نص إرسال إلى متصفح، يشمل يتم تجاهل اختصار ملف، عمل دليل لـ فوق مستودع ملف و مساحة العمل خارج ملف، بينما ملخص توجيه فقط إرسال مسار و سطر عدد،Sidebar ملف معاينة أيضا حد تحديد في مساحة العمل أصل دليل لـ داخل؛ هذه تحرير هو مستخدم تخويل، لذلك قبول هذا واحد نقطة، و تسجيل دخول اثنان عدد README.

`WorkspaceChangedFile` نوع إضافة جديدة `oversized`،`WorkspaceChanges` إضافة جديدة `diff`، اثنان عدد توفير إعطاء عميل نوع `WorkspaceDiffHunk` و `WorkspaceFileDiff` إضافة دخول فرعي نظام صفحة.Session سجل ثابت. تعديل ملف بطاقة سطر في اثنان نوع لغة داخل كل علامة لـ فتح هذا ملف تعديل، لذلك تسجيل صنع Web مشهد أصفر ذهب ملف تغيير؛ نفس مشهد الآن سوف من لقطة فتح واحد shell إلحاق مرور ملف مقابل مقارنة، من فرعي هذا فتح واحد يتم تجاهل اختصار ملف مقابل مقارنة.

تجمع تركيز اختبار تغطية كامل ملف التقاط تصنيف، مهلة تراجع تحويل، من لقطة شجرة توفير مقابل مقارنة، تعديل اسم، حذف ملف، مرور كبير blob و فرعي هذا، مقابل مقارنة توجيه،tab عنوان،store و كل حالة، و بطاقة سطر وصل خط.
