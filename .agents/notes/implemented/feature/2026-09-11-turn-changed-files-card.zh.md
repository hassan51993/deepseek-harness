# Agent Note: هذا جولة تعديل ملف بطاقة

Status: implemented

[English](2026-09-11-turn-changed-files-card.md) | العربية

## Problem

واحد جولة انتهاء بعد، مستخدم تفكير يرى نموذج تعديل أي بعض ملف، تعديل كثير قليل.Web جولة ذيل فقط صف خروج نجاح `write`،`edit` و `str_replace_editor` استدعاء مسار، لا يوجد سطر عدد، أيضا تسرب إسقاط كل shell أمر تعديل ملف؛ رسالة تدفق في تدريجي استدعاء diff بطاقة فقط قدرة مرة عودة جواب واحد استدعاء.

## Decision

Host جانب [workspace-changes](../../../../packages/deliverables/workspace-changes/README.zh.md) إضافة تجميع مجموع كل قمة طبقة جولة تعديل ملف، استخدام فقط حمل جولة رقم `workspace/changes` Session حدث إعلان إبلاغ، و عبر `workspaceChanges` خدمة توفير ملخص مباشر إلى Session تحرير؛[إنتاج خروج شيء إضافة](../../../../packages/client/ui-deliverables/README.zh.md) قراءة توفير ملخص و تصيير لـ تعديل ملف بطاقة، يحل محل تعديل استدعاء سطر. هذا حدث فقط كتابة سجل، نموذج دائم بعيد نظر لا إلى.

سجل جهاز في جولة بدء و انتهاء وقت استخدام git مقابل عمل شجرة فعل لقطة: بـ مستودع index لـ نوع فرعي في خاص index فوق تنفيذ `add --all`، مجددا تنفيذ `write-tree`. اثنان من كل كتابة Session ذاتي ذات يملك مؤقت كائن دليل، مستودع ذاتي ذات كائن مكتبة بـ فقط قراءة alternate تعليق وصل، لذلك مستخدم مستودع لن كثير خروج أي كائن؛ يأخذ التقاط كل بايت كل وضع في مساحة العمل خارج تعلم ذاتي مساحة العمل تغيير سجل POC(#2973) ، بينما كما لأن stat ذاكرة مؤقتة في index داخل، هو مقابل استهلاك وقت لا يوجد يمكن قياس كمية أثر. اثنان عدد tree id استخدام `diff-tree -r -M --numstat` مقارنة مقارنة، لذلك ملخص تماما جيد فقط يتضمن هذا جولة تعديل——مستخدم هذا قبل لم إيداع عمل، بلا نقاش هل مؤقت تخزين، كل يخص أساس خط——نموذج في جولة في فعل إيداع أيضا إخفاء لا إقامة تعديل. مستودع ذاتي ذات index، كائن، عمل شجرة و ref من لا يتم تعديل. في واحد ألف عدد ملف مستودع فوق، مرة لقطة نحو 60 ms، مقارنة مقارنة نحو 10 ms؛ أساس خط و أول مرة نموذج طلب و سطر، أداة تنفيذ سوف انتظار هو.

git استخدام `PATH` فوق افتراضي يمكن تنفيذ ملف، لا استفسار سؤال أي بيئة إضافة. لا في أي مستودع داخل أو لا يوجد git وقت، لا فعل لقطة، ملخص فقط صف ملف أداة تحرير، و بـ عمل دليل بصفة مساحة العمل، لذلك بطاقة ما زال سوف ظهور، لكن نقص قليل shell تعديل. تضمين طقم مستودع و submodule هو gitlink، لن عميق دخول.

لقطة تغطية خارج تعديل قدوم ذاتي كامل ملف التقاط: في `write`،`edit` أو لديه تعديل أثر `str_replace_editor` استدعاء تشغيل قبل، سجل جهاز يأخذ الذي إشارة ملف نسخ إلى Session مؤقت دليل، كل جولة كل مسار مرة، جولة انتهاء وقت مجددا نسخ مرة؛ يتم تجاهل اختصار ملف، عمل شجرة خارج ملف، و لا يوجد لقطة وقت كل مرة ملف أداة تحرير، كل من اثنان نسخة فرعي هذا تدريجي سطر مقابل مقارنة صف خروج ([مقابل مقارنة قرار](2026-09-15-changed-file-diff-preview.zh.md)). مؤقت دليل تحت ملف يتم حذف، حذف غير هو جمع يقع في عمل دليل داخل؛ إبقاء في `/tmp` داخل ملف حاجة `present` عندئذ قدرة وصول مستخدم. تغطية خارج shell تحرير هو معروف حد.

قائمة حسب عرض مسار رمز عنصر ترتيب ترتيب ترتيب: متبادل مقابل عمل دليل مسار، مستودع داخل يقع في ذلك فوق ملف لـ `../`، بيت دليل تحت لـ `~`، ذلك بقية لـ قطعا مقابل مسار؛ فوق درجة مسار و قطعا مقابل مسار لذلك ذاتي لكن ترتيب في الأكثر قبل، لا حاجة مفرد وحيد قسم مجموعة. بطاقة عنوان عرض مجموع عدد و زيادة حذف سطر عدد دمج حساب، طي قبل عرض ثلاثة سطر، توسيع بعد قاع جزء لديه استلام بدء تحكم عنصر. كل واحد سطر في يمين جانب Sidebar فتح هذا جولة review tab و اختيار في هذا ملف، عنوان فإن في رقم واحد ملف فوق فتح هو ([review قرار](2026-09-15-changed-file-diff-preview.zh.md)) ؛Host لديه طاولة وجه وقت،review tab توفير استخدام افتراضي تطبيق فتح.

سجل جهاز في `agent/turn-stopping` وقت في جولة داخل إلحاق حدث، و كما فقط عند الأكثر بعد مرة سجل بعد ما زال لديه أداة نتيجة انتهاء وقت في `turn/end` بعد مجددا مرة إلحاق، لذلك في توقف، فشل و يتم تحويل نحو جولة كل يتم تغطية.Client إبقاء كل جولة الأكثر جديد إعلان إبلاغ، و عبر مرور مرور إقرار إثبات ملخص توجيه قراءة مرة ملخص.

سجل متعمد فقط يحمل جولة رقم. ملخص، لقطة شجرة و التقاط فرعي هذا فقط في Host عملية داخل مع Session تخزين نشط: ملخص في سجل جهاز داخل، كائن و فرعي هذا في تحرير وقت حذف مؤقت دليل داخل.Host إعادة بدء بعد إعادة فتح محادثة، أولا قبل جولة لا يوجد بطاقة. منتج فوق قرار هو،Host قد ضرب لا فتح محتوى بطاقة أصل هذا لا هذا ظهور، الذي بـ بطاقة عمر أمر انتظار في محتوى عمر أمر، بينما لا هو سجل عمر أمر. محتوى لا عبر إعادة بدء إبقاء ([مقابل مقارنة قرار](2026-09-15-changed-file-diff-preview.zh.md)).

## Alternatives considered

**إعطاء تعديل استدعاء سطر تكملة فوق hunk حساب عدد**سوف في تدريجي استدعاء diff بطاقة جانب إبقاء ثاني عدد أكثر ضعيف تنفيذ، كما ما زال تسرب إسقاط shell تحرير؛git لا إدارة أداة هو ماذا كل قدرة يرى كل مرة كتابة.

**جولة نهاية مباشر و `HEAD` مقارنة مقارنة**فقط يحتاج واحد بند أمر، لكن سوف يأخذ مستخدم لم إيداع عمل حساب إلى هذا جولة.

**كل جولة ضرب واحد git tag أو `stash create`**سوف في مستخدم مستودع داخل إبقاء تحت ref، أو من متروك تسرب لم تتبع أثر ملف؛ عبر خاص index كتابة خروج شجرة اثنان من كل لن حدوث.

**لـ لا يوجد git رئيسي آلة جذب دخول صاف JavaScript git أو ربط ربط اثنان دخول صنع**سوف لـ كبير كثير عدد لا استخدام بطاقة مستخدم زيادة عدد MB جسم تراكم و واحد طقم منصة مستطيل دفعة؛ في git ظهور قبل بطاقة فقط صف ملف أداة تحرير.

**تراكم إضافة ملف أداة حفظ دائم hunk** هو لم تغطية ملف رقم واحد إصدار تنفيذ؛ هو سوف يأخذ عكس تكرار تحرير سطر حساب حساب كثير مرة، أيضا إعطاء لا خروج كامل ملف مقابل مقارنة، لذلك سجل جهاز تعديل لـ في أول مرة لمس اصطدام وقت نسخ كامل ملف ([مقابل مقارنة قرار](2026-09-15-changed-file-diff-preview.zh.md)).

**يأخذ ملف قائمة و سطر عدد تسجيل دخول حدث**هو رقم واحد إصدار تنفيذ: بطاقة من هذا يمكن دائم بعيد من سجل تصيير، بينما هو فتح محتوى لكن نشط لا ذلك ما دائم. هو يتم فقط فعل إعلان إبلاغ حدث يحل محل، يجعل بطاقة و محتوى مشترك استخدام واحد عمر أمر.

**Harness home تحت حمل بايت حد أعلى لقطة كائن مكتبة**هو رقم واحد إصدار تنفيذ وضع وضع طريقة: كل مستودع واحد، كل Session مشترك استخدام، تجاوز مرور حد أعلى حينئذ إسقاط. هو قدرة نشط مرور Host إعادة بدء، بينما ملخص قد لم يعد حاجة هذا واحد نقطة؛ هو أيضا حاجة اثنان عدد إعداد حقل، و كما واحد Session إسقاط كائن مكتبة سوف يجعل آخر عدد Session لقطة فشل. كل Session واحد مؤقت دليل يأخذ هذا ثلاثة نقطة واحد بدء ذهاب إسقاط.

**لأجل تحديد موضع git بيئة توفير من وصل شق**من مجموعة طابور رفع خروج لكن بعد لم تحديد سجل؛ إضافة استخدام `PATH` و يأخذ فحص بحث استلام جمع في واحد موضع.

**لـ لا في أي مستودع داخل عمل دليل بناء أثر فرعي مستودع**، أي يأخذ git دليل وضع في Harness home تحت، عمل شجرة إشارة نحو عمل دليل، يمكن يجعل هذه مستخدم في لا كثير خروج `.git` حال حال تحت أيضا يرى shell تعديل، لكن أثر فرعي مستودع لا يوجد `.gitignore`، واحد نسخة إعداد ترتيب حذف قائمة لا يمكن في كل مشروع تخطيط داخل يمكن اعتماد أرض حجب إقامة بناء ناتج، ذاكرة مؤقتة و اعتماد دليل. هو مؤقت مؤقت إلى ترتيب حذف سياسة تحديد تحت قدوم لـ توقف؛ سجل جهاز قد يأخذ مستودع عند عمل إدخال، إضافة هذا واحد ملف فقط تغيير لقطة كتابة إلى أي داخل.

## Consequences

كل لديه أداة نتيجة جولة في Host فوق زهرة استهلاك اثنان مرة لقطة و مرة مقارنة مقارنة، و يأخذ تعديل ملف blob و tree كائن كتابة Session مؤقت دليل، تحرير وقت واحد و حذف. مستخدم في جولة إجراء في تحرير سوف يتم حساب إلى هذا جولة. كل مرة ملف أداة تحرير أيضا سوف يأخذ كامل ملف نسخ دخول هذا دليل، كل جولة مرة.

فقط لديه Web bundle تركيب سجل جهاز، لذلك headless،SDK و ACP سجل ثابت؛ تسجيل صنع Web مشهد فقط يلزم بعض واحد جولة تعديل ملف حينئذ سوف إضافة جديدة هذا حدث و بطاقة؛ واحد مخصص باب مشهد نوع دخول git مستودع، يجعل بطاقة أيضا حمل فوق shell تعديل، ذلك بقية مشهد فقط صف هو جمع ملف أداة كتابة. بطاقة يحل محل في إنجليزي نص “هذا جولة ملف تعديل” سطر؛ متن ملف رفع و ما زال حسب تعديل استدعاء مسار و تسليم تحليل.

تجمع تركيز اختبار استخدام حقيقي git تغطية مستودع، لا في أي مستودع داخل دليل، مقابل قد التقاط مسار تغطية نطاق تصنيف، يتم تحت واحد جولة ضغط فوق في قطع جولة، ترتيب ترتيب، حد أعلى، تحرير،macOS وتد برنامج، تعديل ملف توجيه، بطاقة طي و يد اتجاه حالة، و مرة Loader تركيب. بلا مفتاح Web مشهد طرف إلى طرف إعادة تشغيل سجل جهاز، منها يشمل واحد يتم مستودع تجاهل اختصار جديد بناء ملف.
