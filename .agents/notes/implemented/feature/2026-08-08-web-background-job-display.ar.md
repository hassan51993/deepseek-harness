# Agent Note: Web خلفية مهمة عرض

Status: implemented

[English](2026-08-08-web-background-job-display.md) | العربية

## مشكلة

`ctx.jobs` قد تحمل تحميل harness في خلفية بدء الكل طويل وقت عمل——`bash`،`pwsh`،`pty-send`، و مرة صفة خلفية subagent——لكن هو وحيد قراءة من هو نموذج.[`dsh-tool-jobs`](../../../../packages/jobs/tool-jobs/README.ar.md) كشف `job_list`،`job_output` و `job_kill`، حذف هذا خارج لا يوجد أي شرق غرب مراقبة هذا عدد سجل التسجيل.

في هو Web طرف شخص صنف نظر لا إلى بناء جارٍ ركض، قسم لا صاف واحد مهمة هو اكتمل أيضا هو بطاقة ميت، أيضا لا يمكن يأخذ هو توقف إسقاط. وحيد أثر أثر هو transcript داخل أكثر مبكر بعض موضع ذلك ورقة ضرب طبع job id `run_in_background` أداة بطاقة، بينما ذلك ورقة بطاقة هذا بعد مجددا أيضا لن تحديث.

جلسة header هذا قدوم حينئذ هو كل جلسة خلفية نشط حركة سقوط نقطة:[`dsh-client-ui-subagent`](../../../../packages/client/ui-subagent/README.ar.md) يأخذ subagent دليل مساهمة إلى `conversation.session.header.actions`. موضع لا يوجد تنازع اقتراح. نقص هو أي واحد بند يأخذ مهمة حالة إرسال إلى متصفح عبر طريق.

## قرار

مهمة حالة بـ**كل جلسة واحد لقطة كامل نسخة control لقطة**وصول متصفح، في سجل التسجيل كل واحد سوف تغيير هذا جلسة مرئي محتوى إيداع نقطة دفع خروج. عميل إبقاء واحد نسخة last-wins مرآة مثل، من واحد header مدخل تصيير. لا يوجد RPC، لا يوجد جولة استفسار، عميل لا حاجة أي مرور مدة حالة إدارة.

هذا مرة فقط تسليم قائمة. كل مهمة تدفق صيغة إخراج و شخص صنف إرسال بدء في قطع هو كل منها مستقل مرحلة مقطع، بينما عبر طريق شكل حالة يجعل اثنان من كل لا لا بد دفع قلب هو.

### خط مسار شكل حالة

Session Controller control تدفق في واحد لقطة:

```ts ignore-check
| { type: 'jobs'; sessionId: SessionId; jobs: SessionJob[] }
```

`SessionJob` هو متصفح أمان نوع، و أخرى Session Remote اتفاق واحد بدء من [`packages/api/session-controller/src/types.ts`](../../../../packages/api/session-controller/src/types.ts) يملك:

```ts
import type { JobId } from '@deepseek-ai/dsh-jobs/brand'

export interface SessionJob {
  id: JobId
  kind: string
  label: string
  status: 'running' | 'stopping' | 'completed' | 'killed' | 'failed'
  detail?: string
  startedAt: number
  finishedAt?: number
}
```

`JobId` أخذ ذاتي لا اعتماد cordis [`@deepseek-ai/dsh-jobs/brand`](../../../../packages/jobs/jobs/src/brand.ts) ورقة فرعي——و `api/subagents.ts` قد في استخدام `@deepseek-ai/dsh-llm/brand` استيراد هو نفس نوع أمان ترتيب، لأن `dsh-jobs` أصل خروج فتحة سوف جر إلى `dsh-agent`، أي سهل فقط عمل نوع أيضا لا يمكن يتم عميل برنامج لمس و. و هذا مستودع أخرى كل واحد غير أصل فرعي مسار واحد مثال، هو حمل لديه صريح `tsconfig.base.json` `paths` بند؛ لا يوجد هذا واحد بند،Typert قسم تحليل جهاز سوف يأخذ هذا specifier تحليل إلى `lib/types/` و حكم تحديد هذا مرجع لم يتم تصدير.

خط مسار فوق `kind` هو `string` بينما غير `JobKind`.kind خريطة من إنتاج من إضافة حسب إعلان دمج توسيع، عميل بناء لا يمكن قطعة رفع هذا عدد إغلاق تجميع؛ لقاء إلى لا يمكن تعرف آخر kind، عرض طبقة مشي واحد بند لديه وثيقة افتراضي فرع.

`JobSnapshot` ثلاثة عدد حقل يتم لحظة معنى حذف ذهاب:`ownerSession`(لقطة `sessionId` قد حمل) ،`reported`(داخلي إشعار إلقاء تمرير موضع، مقابل مستخدم بلا معنى معنى) ، و `outputLimitBytes`(إنتاج من يملك نموذج عرض سياسة).

هذا واحد لقطة حمل كامل نسخة لقطة بينما غير زيادة كمية، لذلك بدء، في قطع، تسوية، إعادة وصل، و ثاني عدد متصفح وسم صفحة، كل كل عبر نفس عدد مرجعي قيمة استلام جمع. واحد جلسة مهمة تجميع هو عدد موضع عدد، لقطة جدا صغير.

### مهمة سجل التسجيل تغيير حجز قراءة

`JobRegistry` يملك واحد مراقبة طريقة:

```ts ignore-check
abstract onJobsChanged(listener: JobsChangedListener): () => void
```

هو في كل واحد سوف تغيير `list(owner)` إرجاع محتوى إيداع نقطة**بعد**إطلاق:`start()` نهاية ذيل تسجيل،`kill()` داخل تحويل دخول `stopping`، تسوية، و `disposeOwner()` تنفيذ إزالة.`owner` لـ `undefined` يمثل واحد بلا رئيسي مهمة حدوث تغير، بسبب بينما كل واحد استدعاء جهة عرض كل تغيير.

مستمع حسب owner بينما غير حسب مهمة قسم حبة درجة. وحيد مستهلك دفع هو كامل نسخة لقطة، تدريجي مهمة سجل إلى يد أي ترك——بينما كما تدريجي مهمة حجز قراءة أصل هذا لا يمكن جدول بلوغ owner إلغاء تدمير وقت إزالة، حذف غير إرسال واضح واحد آخر موضع كل لا حاجة قبر نصب حالة.

`onJobDone` لا هو هو فرعي تجميع. بعد من حسب first-wins دلالة إلقاء تمرير نهاية حالة سجل و تأكيد قطع owner `Agent`،`dsh-tool-jobs` يأخذ هذا طقم دلالة و `reported` ربط في واحد بدء؛`onJobsChanged` هو صاف مراقبة، لا يحتوي أي إلقاء تمرير يحتوي معنى، أيضا لا يأخذ أي شرق غرب علامة لـ قد فوق تقرير. مستمع رمي خطأ يتم حزمة إقامة كما من لا await، و `onJobDone` متسق، كل مرة تسجيل كل هو استدعاء جهة fiber فوق effect.

خدمة إلغاء تدمير لحظة معنى ماذا كل لا عبر إبلاغ. كل `onJobsChanged` تسجيل كل هو سجل التسجيل ذاته fiber فوق effect، انتظار إلى teardown صاف فارغ store وقت مستمع مبكر قد إزالة فقد؛ مراقبة من عبر ذاتي ذات إلغاء تدمير بينما لا هو واحد نسخة نهائي فارغ تجميع قدوم نيل معرفة سجل التسجيل مغادرة فتح.

### Session Controller تحميل جسم

[`SessionControlController.control()`](../../../../packages/api/session-controller/src/control.ts) أولا إرسال خروج واحد نسخة كامل Host نطاق baseline، مجددا إرسال لاحق `jobs` استبدال لقطة. كل مرة شيء إدارة إعادة وصل كل سوف فتح جديد واحد بديل تدفق، لذلك عميل سوف أولا استبدال عملية محلي مرآة مثل، مجددا تطبيق لاحق تغيير.

تحميل جسم حراسة حال أربعة بند قاعدة:

- **أبدا resume.** تغيير دفع إرسال استخدام مستمع إعطاء خروج تأكيد قطع `Agent` ضبط `jobs.list(owner)`، أي جعل هذا owner scope جارٍ تفكيك حذف، حسب id فحص بحث قد فحص لا إلى، هو اعتماد لكن صحيح تأكيد.baseline فإن قراءة `ctx.jobs.list(ctx.agents.get(session.id))`، لا يوجد live Agent Session صحيح تأكيد أرض فقط نيل إلى بلا رئيسي مهمة. اثنان بند مسار كل لا استدعاء [Session Controller Agent محلل](../../../../packages/api/session-controller/src/agent.ts) ، لأن صف خروج مهمة أبدا قدرة تكرار نشط مستخدم مع يد تخطيط مرور Session.
- **بلا رئيسي تغيير يلزم مروحة خروج.** `owner` لـ `undefined` وقت نحو كل واحد قد تعليق وصل Session دفع واحد نسخة جديد لقطة، لأن بلا رئيسي مهمة مقابل كل استدعاء جهة مرئي.
- **إبقاء اختياري.** تحميل جسم قراءة `ctx.get('jobs')`. لا يوجد تعليق سجل التسجيل تركيب تقرير إبلاغ فارغ مهمة تجميع، عميل أيضا حينئذ لا تصيير مدخل.
- **صريح يمثل فارغ تجميع.** opening baseline لـ كل قد تعليق وصل Session توفير واحد بند، يشمل `[]`؛ لاحق تغيير صاف فارغ واحد قائمة وقت أيضا سوف دفع إرسال `[]`. عميل لذلك يمكن يأخذ فارغ تجميع عودة واحد تحويل لـ ناقص مفتاح، بينما لن إبقاء قديم قديم سطر.

### عميل مرآة مثل

`SessionListState` حمل لديه `jobsBySession: Readonly<Record<SessionId, readonly JobView[]>>`، من `SessionManager` يملك، حسب last-wins من لقطة طي بينما قدوم؛ يتم صاف فارغ تجميع دمج تخزين لـ ناقص مفتاح، جعل «ناقص» و `[]` يصبح نفس نوع يمثل.

هو وضع في قائمة مرآة مثل بينما لا هو `Session` فوق، لديه ثلاثة عدد إدارة من:header مدخل هذا قدوم حينئذ عبر `useSessions` قراءة قائمة حالة؛ لا يوجد composer سلوك اعتماد مهمة؛ سوف قدوم جانب شريط إضافة إشارة عرض جهاز وقت لا لا بد مجددا فتح ثاني بند عبر طريق.

اثنان عدد استبدال نقطة يجعل هو إبقاء صدق فعلي. كل واحد بديل control تدفق كل سوف أولا صاف فارغ كامل مهمة مرآة مثل، مجددا تثبيت جديد baseline في غير فارغ تجميع دمج.`api-session/removed` حدث أيضا سوف حذف هذا Session بند، لا اعتماد مهمة سجل التسجيل disposal إشعار و هو بين ترتيب.

### header مدخل

[`@deepseek-ai/dsh-client-ui-jobs`](../../../../packages/client/ui-jobs/README.ar.md) في `conversation.session.header.actions` تسجيل واحد بند، ترتيب في subagent دليل بعد. عرض عقد نحو عودة هو ذاتي ذات README؛ قيمة نيل تسجيل في هذا داخل قرار هو: جلسة لا يوجد مهمة وقت تحكم عنصر أصل هذا لا تصيير؛ نشط وثب زاوية علامة لـ صفر وقت حذف، يجعل فقط باق تاريخ جلسة إبقاء واحد أمان ساكن مدخل؛ نهاية حالة سطر إبقاء مرئي، لأن فشل مهمة `detail` هو ذلك فشل وحيد يمكن قراءة لـ موضع.

لذلك واحد تشغيل في مرة صفة خلفية subagent سوف معا ظهور في ذلك داخل و subagent دليل داخل. اثنان من عودة جواب مختلف مشكلة——دليل مسؤول دخول فرعي جلسة transcript، بينما هذا عدد قائمة هو في قطع قدرة وحيد ممكن مرفق حال جملة مقبض——في هذا داخل شاشة حجب `kind: 'subagent'` سوف يجعل في قطع ذلك واحد مدة تماما جيد مقابل هذا دفعة مهمة لا يوجد مدخل.

### لحظة معنى لا فعل أمر

**لا يوجد أي Web مسار استدعاء `ctx.jobs.read()`.** هو إزالة استهلاك وحيد إخراج تنقل علامة، متصفح قراءة مرة حينئذ صامت صامت أخذ مشي نموذج `job_output` دائم بعيد نظر لا إلى بايت. هذا هذا هو واحد بند لديه اختبار التقاط قاع ثابت كمية بينما لا هو واحد بند اتفاق، لأن هو لذا عائق في استدعاء نقطة تماما غير ممكن رؤية.

**لا فعل في قطع.** ذلك واحد مدة نقص واحد seam هدف قبل لا يوجد عودة جواب قرار:`kill()` سوف يأخذ نهاية حالة إلقاء تمرير علامة لـ قد فوق تقرير، الذي بـ وفق `kill()` عقد نحو كتابة خروج قدوم شخص صنف في قطع، سوف يجعل نموذج واحد مباشر بـ لـ هو مهمة أيضا في ركض.

**لقطة فوق لا حمل إخراج ماء موضع.** إخراج ذلك واحد مدة زيادة كمية عبر طريق عندئذ هو مرساة نقطة حقل هذا ظهور أرض جهة؛ الآن إضافة حينئذ هو واحد لا يوجد قراءة من حقل.

## تجهيز اختيار خطة

**إشارة لقطة إضافة RPC سحب أخذ، أي subagent دليل شكل حالة.** دفع واحد بلا payload `jobs-changed` إشارة، منع اهتزاز بعد استخدام واحد عنصر RPC إعادة قراءة مرجعي حالة.subagent دليل حينئذ هو هذا ما فعل، بديل قيمة في [`SessionManager`](../../../../packages/api/session-controller/src/client/sessions/manager.ts) داخل واحد تصفح بلا بقية:`catalogInflight` فعل مفرد طيران سطر،`catalogStale` في عضو لقطة سقوط في طلب في طريق وقت تكملة مرة ذيل سحب،`updateCatalogActivity` حيث حينئذ أرض ضرب رقعة أيضا نحو في طريق طلب داخل كتابة واحد نسخة جيد يجعل مقارنة لقطة أكثر قديم استجابة يتم تغطية،`parentAvailableOverride` إعادة وضع واحد مرور مدة `false`، أيضا لديه إعادة وصل وقت تدريجي واحد إعادة سحب كل فتح دليل. هذا طقم تركيب وضع لـ الذي بـ وجود، هو لأن دليل مرجعي يتم شق صار اثنان نصف——حمل دائم دم حافة قدوم ذاتي إسقاط، نشط وثب درجة هو استجابة وقت لحظة أخذ مثال——بينما مهمة لا يوجد حمل دائم ذلك واحد نصف، لا هذا وراثة هذا نسخة تكرار مختلط درجة. هو أيضا تماما جيد في إخراج ذلك واحد مدة الأكثر في معنى وقت لحظة بطلان: مهمة تسوية، إخراج تدفق قيام أي إغلاق، حالة لكن يلزم انتظار منع اهتزاز إضافة مرة نحو إرجاع عندئذ إلى، ذلك مقطع نافذة داخل UI عرض واحد تدفق قد ميت تشغيل في مهمة.

**فقط في نابض طبقة فتح وقت جولة استفسار، لا تعديل seam.** الأكثر حذف أمر، أيضا هو وحيد لا اصطدام `JobRegistry` خيار. هو لا يمكن في لا معتاد إقامة جولة استفسار قبل رفع تحت دعم حمل إطلاق جهاز فوق معتاد إقامة حساب عدد، بينما بعد وجه اثنان مدة عكس صحيح كل حاجة واحد بند حق صحيح تغيير حجز قراءة، الذي بـ هو حذف تحت واحد دورة أيضا أيضا عودة ذهاب.

**أساس في حمل دائم مهمة حدث session-projection وحدة.** إسقاط وحدة في قد إيداع جلسة حدث فوق طي، الذي بـ هذا بند مسار يلزم أولا يجعل مهمة دورة الحياة تغيير حمل دائم——`job/started` … `job/settled` بصفة واحد مقابل مستقل فتح دمج تضمين رقم، من الأكثر بعد واحد [`session/end-seed`](../../../../packages/core/session/src/types.ts) يأخذ لم إعداد مقابل فتح تضمين رقم علامة لـ ميت تاريخ، و compaction تضمين رقم قد لديه فعل قاعدة تماما متسق. هو في عميل تأكيد فعلي أكثر حذف:`dsh-tool-todo` استخدام عشرة خمسة سطر وحدة عرض كامل طقم نمط، بينما الآن صار `session/projection` لقطة،history-tail كتلة و حفظ دائم checkpoint ذاكرة مؤقتة هذا يمكن تحمل تحميل هذا دفعة بيانات، بلا حاجة جديد خط مسار وجه، بلا حاجة تحميل جسم حجز قراءة، بلا حاجة manager حالة. مرفوض هو، هو لأن هذا يلزم أخذ مرة حمل دائم صيغة تغيير ذهاب تبديل واحد متصفح قائمة، بينما كما هو و لا يستطيع تأخير امتداد إلى الأكثر حاجة هو ذلك واحد مدة:[`spill/`](../../../../packages/spill/README.ar.md) وجود صحيح هو لـ يجعل تجاوز كبير أداة إخراج إبقاء في سجل خارج، الذي بـ تدفق صيغة مهمة إخراج بلا نقاش مثل أي كل لا يستطيع ركوب في حمل دائم حدث فوق. إذا حمل دائم مهمة تاريخ سوف قدوم سند ذاته قيمة قيمة محطة نيل إقامة، هذا تصميم لا منع حجب إعادة اعتبار هو.

**إعادة استخدام `dsh-tool-jobs` `PublicJobSnapshot`.** حقل بضعة نحو حينئذ هو مقابل، لكن هو يخص موجه إلى نموذج تحكم وجه. متصفح برنامج من واحد tool حزمة استيراد خط مسار نوع، سوف يأخذ عميل عرض اقتران دمج إلى موجه إلى prompt قرار فوق، و يأخذ واحد host-only حزمة سحب دخول عميل بناء.

**و دخول subagent دليل فعل صار موحد واحد «نشط حركة» وجه لوح.** واحد مدخل بينما لا هو اثنان عدد. مرفوض إدارة من هو `SubagentCatalogAction` قد 605 سطر، ذلك رئيسي عنوان هو يحتوي قد انتهاء فرعي جلسة حمل دائم جلسة دم حافة شجرة؛ عملية مجال مهمة هو ثاني طقم بيانات نموذج، هوية، توليد أمر مدة و متاح حركة عمل كل مختلف، بينما دليل كسول توسيع فرع، وقت طويل و token عقد نحو كل كل يلزم إعادة كتابة عندئذ قدرة سعة قبول هو جمع.

**عبر الكل جلسة host عام مهمة قائمة.**«عرض كل تشغيل في مهمة» حرف وجه قراءة قاعدة. مرفوض هو لأن سجل التسجيل تمييز حق محيط شريط هو حسب owner جلسة، عام قراءة حاجة واحد بند جديد وصول قاعدة، بينما كما عام قائمة لا هذا ظهور في بعض عدد جلسة header داخل——هو حاجة جانب شريط داخل ذاتي ذات موضع. هذا تصميم لا يوجد منع حجب لاحق مجددا إضافة؛ حسب جلسة لقطة حينئذ هو نفس دفعة بيانات.

## اختبار

[web e2e مشهد](../../../../apps/web/tests/background-job-list.e2e.ts) هو طرف إلى طرف دليل، كما بلا حاجة مفتاح: مرة حقيقي `run_in_background` bash استدعاء تسجيل دخول `ctx.jobs`،header حساب عدد و سطر في لا يوجد أي مستخدم عملية حال حال تحت ظهور، عبر سجل التسجيل قتل إسقاط هذا مهمة بعد فتح حال قائمة قلب إلى إنتاج من إعطاء خروج detail. هو تأكيد هو كامل بند إلقاء تمرير سلسلة مسار، بينما لا هو منها بعض واحد طبقة.

في هو لـ تحت،[`jobs-local`](../../../../packages/jobs/jobs-local/tests/jobs.spec.ts) تثبيت إقامة تغيير حجز قراءة الكل أربعة عدد إيداع نقطة، مقابل رمي خطأ مراقبة من حزمة سعة، و صريح إلغاء تدمير و fiber تفكيك حذف اثنان بند مسار فوق ملاحظة إلغاء؛[`control-jobs`](../../../../packages/api/session-controller/tests/control-jobs.host.spec.ts) تثبيت إقامة كامل baseline، ثلاثة مرة تغيير دفع إرسال، يتم إسقاط داخلي حقل، بلا رئيسي مروحة خروج، لا resume حفظ إثبات، لا يوجد سجل التسجيل تركيب، و لا نيل إزالة استهلاك نموذج إخراج؛ عميل كل طقم عنصر تثبيت إقامة baseline استبدال،last-wins طي، ناقص مفتاح يمثل، إزالة تنظيف، و مكون ترتيب، وقت طويل و إغلاق سلوك.

## أثر

**تسرب إسقاط واحد إيداع نقطة سوف تسرب سطر.** إذا `disposeOwner()` إزالة لديه نحو واحد يوم لم يعد إطلاق حجز قراءة، عميل سوف واحد مباشر إبقاء حال قد لا وجود مهمة، مباشر إلى جلسة إزالة فقد. كامل نسخة لقطة شكل حالة يجعل هذا عنصر أمر يمكن استعادة بينما غير ضرر تالف——تحت مرة صحيح عند تغيير حينئذ إصلاح جيد——لكن إلغاء تدمير مسار هو الأكثر سعة سهل يتم نسيان إسقاط واحد بند، الذي بـ هو ذاتي حمل اختبار.

**بلا رئيسي مهمة مروحة خروج جدا سعة سهل فعل تسرب.** فقط دفع إعطاء تغيير owner الذي في جلسة، مقابل لديه رئيسي مهمة هو مقابل، مقابل موضع موضع مرئي بلا رئيسي مهمة فإن هو صامت صامت خطأ. هذا عدد bug فقط سوف في سوف إنشاء بلا رئيسي مهمة تركيب داخل إظهار شكل، الذي بـ تحميل جسم طقم عنصر مباشر تغطية هو.

**UI تجميع دمج لا انتظار في سجل التسجيل تجميع دمج.** header عرض هو «واحد جلسة قدرة يرى ماذا» ، الذي بـ آخر جلسة يملك مهمة في هذا داخل دائم بعيد لا ظهور، كل إدارة سجل التسجيل داخل لديه هو؛ بينما من في سجل التسجيل هو عملية محلي، مرة إعادة بدء سوف صاف فارغ كل قائمة،transcript داخل ذلك بعض بدء هو جمع `run_in_background` بطاقة لكن أيضا في. بلا رئيسي مهمة هو عكس مرور قدوم حال شكل: هو جمع سوف دخول كل واحد جلسة قائمة، صحيح مثل `list(caller)` مقابل كل استدعاء جهة كل تقرير إبلاغ هو جمع.

**نهاية حالة سطر سوف كومة تراكم.** سجل التسجيل يأخذ قد تسوية مهمة إبقاء إلى owner إلغاء تدمير، الذي بـ واحد ركض جدا كثير خلفية أمر طويل جلسة سوف تراكم خروج طويل قائمة. إذا حق يصبح احتضان شكوى، إعطاء نهاية حالة ذيل با إضافة حد أعلى هو عرض طبقة تعديل بينما غير بروتوكول تعديل.

**`stopping` جدا قليل مرئي.** فقط لديه نموذج `job_kill` سوف إنتاج هو، الذي بـ هذا عدد حالة سوف يتم تصيير لكن في شخص صنف في قطع سقوط أرض قبل جدا قليل رؤية إلى. الآن حينئذ قبول دخول ربط دمج نوع، هو لأن يأخذ هو إبقاء في خارج وجه سوف يجعل ذلك واحد مدة تغيير صار مرة خط مسار تغيير.

**واحد تشغيل في subagent لديه اثنان عدد مدخل.** هذا هو لحظة معنى قبول، كما يتم حد في مرة صفة خلفية تفويض إرسال هذا واحد نوع حال حال. إذا فعلي استخدام بدء قدوم قراءة حال مثل ضجيج صوت، إصلاح قاعدة هو عرض طبقة——يمكن يجعل دليل سطر مرجع ذلك عدد مهمة، بينما لا هو يجعل مهمة قائمة إخفاء هذا عدد kind.

**إضافة جديدة غير أصل فرعي مسار يجب تكملة `paths` بند.** `@deepseek-ai/dsh-jobs/brand` نيل أولا تسجيل تسجيل دخول `tsconfig.base.json`،Typert قسم تحليل جهاز عندئذ سوف قبول هذا مرجع. هو لذا عائق جدول الآن هو واحد بند قدوم ذاتي بعيد مغادرة تعديل موضع توليد جهاز، أمر شخص صعب حيرة «not exported by» خطأ، الذي بـ هذا عدد بند هو إضافة جديدة فرعي مسار مجموعة صار جزء، بينما لا هو أفضل تحويل.
