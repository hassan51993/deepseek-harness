# Agent Note: تكرار صندوق رملي نمط بلا حاجة مراجعة دفعة

Status: implemented

[English](2026-09-16-sandbox-same-mode.md) | العربية

## مشكلة

نموذج ممكن في `danger-full-access` قد توليد فاعلية وقت تكرار نقل دخول `sandbox_permissions: danger-full-access`. رفض هذا استدعاء سوف منع توقف قد نيل تخويل عمل، لكن لا يوجد منع توقف أي إذن زيادة.

## قرار

عند طلب نمط و توليد فاعلية نمط نفسه وقت،`approveEscalation` قيام أي إرجاع توليد فاعلية نمط. أداة ما زال اشتراط معامل صار مقابل ظهور. أكثر عرض نمط ما زال يحتاج مراجعة دفعة؛ أكثر ضيق و لا دعم حمل هدف ما زال فشل. هذا جزء يحل محل[صندوق رملي قرار](2026-07-06-sandbox.zh.md) في غير وضع عرض طلب رفض قاعدة؛ ذلك قيد و تدريجي استدعاء مراجعة دفعة قرار ما زال صالح.

## اعتبار مرور بديل خطة

**رفض كل غير وضع عرض طلب.** أي جعل لا يوجد طلب مقدار خارج إذن، زائد بقية معامل أيضا سوف توجيه يؤدي استدعاء فشل.

**مجددا مرة طلب مراجعة دفعة.** قائم إذن قد كاف كاف، مجددا مرة تلميح لن زيادة تخويل.

## أثر

Bash و نظام الملفات أداة بلا حاجة مراجعة دفعة خدمة أو agent يكفي قبول تكرار توليد فاعلية نمط. مشترك اختبار وحدة تغطية اثنان عدد قد عام نشر هدف، اثنان عدد أداة مستهلك متساو تنفيذ تكرار نمط،`fs-same-mode` ACP لقطة تحقق لا يوجد مراجعة دفعة حدث بلا حد كتابة و فحص توليد ملف.
