# Agent Note: Markdown ملف معاينة رابط

Status: implemented

[English](2026-09-15-markdown-file-preview-links.md) | العربية

## Problem

Assistant شرح حل سوف رابط إلى هذا جولة لم تعديل أو تسليم قائم شفرة المصدر ملف. إذا فقط سماح إنتاج خروج ملف رفع و يصبح يمكن نقر مرجع، قراءة من حينئذ لا يمكن في عودة جواب جانب فتح هذه شفرة المصدر.

## Decision

سقوط تحديد بعد Assistant Markdown عبر `MarkdownDelegateProvider` سوف صريح محلي رابط هدف نقل إعطاء Chat ملف فتح جهاز.Provider معا يملك ملف و HTTP(S) تنقل عودة ضبط؛ داخلي رابط مكون قراءة ذلك حالي عودة ضبط، في بين مصير بلا حاجة زيادة تنقل props. مصير تعرف آخر قطعا مقابل مسار و مساحة العمل متبادل مقابل مسار، مقابل مئة قسم رقم تحويل معنى حل رمز مرة، و سوف `#L24` أو `#L24-L30` قسم مغادرة لـ بدء بداية سطر تنقل طلب. ملف تحكم عنصر إبقاء أصلي وسم و عرض ملف صنف آخر رسم علامة، أبدا يجعل متصفح تنقل إلى أصلي مسار.

قائم[جانب شريط تنقل](../architecture/2026-09-05-sidebar-tab-types-and-navigation.zh.md) مسؤول Session بحث عنوان، وسم إعادة استخدام و معاينة اختيار.Host ملف خدمة إبقاء وصول فحص و ملف ناقص خطأ. سطر داخل شفرة إنتاج خروج ملف مطابقة إبقاء مستقل. خارجي URL إبقاء بروتوكول سماح قائمة؛ استعلام سلسلة، فقط لديه قطعة مقطع هدف، لا دعم حمل قطعة مقطع، خطأ تحويل معنى و بلا فاعلية سطر رقم نطاق متساو غير ممكن نقر.

Web ملف مرجع نص التوجيه اشتراط رابط أمر، إعداد جدول بلوغ صيغة و شفرة كتلة بـ خارج كل مرة قائم ملف رفع و، يشمل تكرار رفع و و جدول إطار. اسم افتراضي استخدام basename أو صاف واضح آخر اسم، فقط إضافة إزالة حذف اختلاف معنى الذي يحتاج أب دليل. دقيق وسم استخدام `filename:24` أو `filename:24–30`، هدف ما زال استخدام محلل دعم حمل `#L24` أو `#L24-L30` لغة قاعدة. مصير إبقاء نموذج أصل نص، لا عبر إعادة كتابة وسم قوي صنع ممتلئ كاف نص التوجيه.

## Alternatives considered

**متبادل مقابل متصفح رابط.** هذا سوف قفز تحويل تطبيق URL، بينما غير طلب Session ملف محتوى.

**اشتراط إنتاج خروج ملف بند.** هذا سوف ترتيب حذف عادي فقط قراءة شرح حل.

**زيادة معاينة خدمة.** Chat قد توفير الذي يحتاج فتح جهاز و سطر رقم معامل.

**عبر مصير props تدريجي طبقة نقل تمرير تنقل عودة ضبط.** كل نوع إضافة جديدة تنقل قدرة كل سوف توسيع كبير غير متصل في بين واجهة. رابط مكون قراءة أثر مجال داخل delegate، أيضا يجعل ذاكرة مؤقتة Markdown قدرة استجابة عودة ضبط تغير.

**ملف اسم أولوية أو فقط مواصفة عرض نص التوجيه.** ثلاثة إصدار تطوير مقابل وفق في A تدريجي مرة مرجع رابط نسبة التغطية مقارنة عال، مستخدم أيضا أكثر انحراف جيد ذلك إخراج.B تماما لا يوجد تسرب سلسلة عودة جواب أكثر كثير، لذلك هذه مراقبة لا يستطيع إثبات بعض إصدار عام مرة أكثر أفضل. مستخدم اختيار ناضج معرفة خطر رقم صيغة، وضع ترك عرض `#L` بعد لاحقة؛ هدف إبقاء مرساة نقطة لغة قاعدة بـ صيانة حمل قائم تنقل.

## Consequences

شفرة المصدر مرجع بلا حاجة إضافة جديدة Session حدث. ساكن حالة Web إشارة توجيه عبر قائم نظام رسالة آلية سجل. رابط في رسالة سقوط تحديد بعد متاح. نطاق تحديد موضع إلى بدء بداية سطر؛ معاينة لن عال مضيء كثير سطر اختيار منطقة. اختبار وحدة تغطية هدف تحليل، مشترك ملف و HTTP(S) توجيه، تضمين طقم أثر مجال و عودة ضبط استبدال أو إزالة؛ بلا مفتاح `markdown-file-links` Web لقطة عبر صحيح صيغة تركيب تغطية ملف محتوى، خطر رقم وسم، سطر رقم تنقل و وسم إعادة استخدام. حزمة اختبار تحقق كل نسخة Web نص التوجيه sidecar في إشارة توجيه.
