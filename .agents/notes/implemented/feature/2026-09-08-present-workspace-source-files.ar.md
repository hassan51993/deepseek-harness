# Agent Note:Present إعلان تسليم مساحة العمل مصدر ملف

Status: implemented

[English](2026-09-08-present-workspace-source-files.md) | العربية

## مشكلة

مستخدم حاجة فتح و تحرير مساحة العمل في إنتاج خروج ملف، يشمل لا يوجد تحرير جهاز تعديل سجل shell إنتاج خروج ملف. حفظ مستقل تسليم إصدار سوف لـ هذا واحد مسار زيادة محتوى تخزين، فرعي هذا تحقق، مؤقت ملف إبقاء، و ثاني عدد تحرير هدف.

## قرار

[present أداة](../../../../packages/deliverables/tool-present/README.ar.md) إعلان تسليم[Session نظام الملفات وصول سياسة](2026-09-09-present-filesystem-access.ar.md) سماح قد لديه عادي مصدر ملف. هو سجل مسار و اختياري شرح، لا قراءة أو نسخ محتوى.[تسليم إضافة](../../../../packages/client/ui-deliverables/README.ar.md) استخدام Host افتراضي تطبيق فتح حالي مساحة العمل مصدر ملف. تحت مرة فتح سوف يرى تحرير بعد محتوى؛ حذف أو نقل حركة ملف سوف جعل إعلان غير ممكن استخدام. ملف محتوى إبقاء و كتابة وقت نسخ تخزين تأجيل إلى لديه حفظ دائم تصميم مسؤول وقت تنفيذ.

أداة شرح اشتراط في كتابة جيد مستخدم اشتراط استقبال ملف بعد، نهائي عودة تكرار قبل استدعاء `present`، يشمل عبر Bash أو شفرة تنفيذ إنشاء ملف. متن في مسار مرجع لا يستطيع بديل استدعاء. تسجيل صنع [SVG تسليم مشهد](../../../../snapshots/web/present-svg/snapshot.yml) استخدام لم رفع و `present` مستخدم طلب، فحص توليد ملف، تسليم حدث و بطاقة. ذلك UI لقطة تغطية توسيع بعد Chat محادثة محتوى؛ تنقل و إدخال إطار تحكم عنصر من كل منها مشهد مسؤول، تجنب تجنب غير متصل واجهة تعديل جعل ملف تسليم مسبق مدة بطلان.

أداة إبقاء لـ عادي حزمة، مشترك نظام الملفات و أداة خطأ نوع. ذلك صاف نوع مدخل يملك تسليم حدث، لا نحو متصفح استيراد Host شفرة.`standard`،`ptc` و `cordis` preset تركيب أداة؛`minimal` إبقاء اثنان عدد أداة. كل إضافة نسخة سوف ذلك تنفيذ و نجاح نهائي `tools/result` إشعار صلة ربط، مجددا إلحاق `deliverables/presented`. أصلي و تضمين طقم استدعاء التزام دوران نفس قاعدة. خارج طبقة برنامج مع بعد فشل لن سحب إلغاء قد إتمام تضمين طقم إعلان؛ يتم منع توقف نتيجة لا إصدار إعلان، نفس اسم أثر مجال استبدال أيضا لا يستطيع إصدار أخرى نسخة نتيجة.

مرور مرور إقرار إثبات POST حسب حالي فحص نظر Session، حدث ترتيب رقم و أصلي ملف بحث جذب اختيار إعلان. حدث لا يحمل الذي تابع Session ID؛ وراثة تاريخ في متبادل مقابل مسار حسب حالي فحص نظر Session مساحة العمل تحليل.Host في أصلي فتح قبل فحص عادي ملف هل وجود، و تحقق Host مسار خريطة. توجيه تحرير وقت إلغاء و انتظار إجراء في أمر.[تعديل ملف بطاقة](2026-09-11-turn-changed-files-card.ar.md) في تسليم بطاقة جانب صف خروج هذا جولة سجل تعديل؛ اثنان عدد جدول وجه متساو لا يمثل نهائي تسليم.

ملف بطاقة اعتماد و Session قمة شريط نفسه قسم مقطع تحكم عنصر. نقر بطاقة أو يسار جانب “فتح” منطقة مجال سوف في يمين جانب Sidebar معاينة مصدر ملف؛ يمين جانب سهم رأس فتح يتضمن افتراضي تطبيق و ملف إدارة جهاز عملية معيار قائمة مفرد.Host في Finder أو ملف مورد إدارة جهاز في اختيار العربية عنصر، أو عبر Linux افتراضي ملف إدارة جهاز فتح الذي في ملف مشبك. اثنان عدد أصلي عملية كل تحليل نفس نسخة قد حفظ إعلان و تحقق Session نظام الملفات و Host مسار؛ متساو لا قبول متصفح توفير بديل مسار. قدوم ذاتي Host طاولة وجه معلومة جعل بعيد مسار متصفح في نص سجل و متاح صفة إبقاء دقيق تأكيد، توجيه في كل مرة أصلي عملية وقت تنفيذ إعداد متاح صفة فحص. مفرد عدد تسليم احتلال ممتلئ كامل سطر؛ كثير عدد تسليم كل سطر الأكثر كثير اثنان صف، و إبقاء كل إعلان، قبل أربعة ورقة بطاقة بعد محتوى في مستخدم توسيع قائمة قبل إبقاء استلام بدء. طاولة وجه بيانات وصفية مع اتصال بديل مرة بطلان، تجنب تجنب قديم رئيسي آلة معلومة يجعل أصلي عملية حمل متابعة منع استخدام أو عرض خطأ ملف إدارة جهاز اسم. قديم بيانات وصفية طلب سوف يتم إلغاء، لا يستطيع تغطية جديد بديل مرة استجابة.

## اعتبار مرور بديل خطة

**غير ممكن تغيير مرفق عنصر لقطة و يمكن تحرير مؤقت فرعي هذا**يمكن في مصدر ملف تحرير أو حذف بعد إبقاء تسليم إصدار، لكن سوف جعل طاولة وجه تحرير و مساحة العمل ملف قسم مغادرة، و في نقص قليل حالي منتج يحتاج طلب وقت جذب دخول إبقاء عمل. هذا قرار يحل محل[لقطة تسليم تصميم](../../archived/feature/2026-09-08-web-explicit-file-delivery.md). لا إبقاء تحت تحميل طرف نقطة أو رجوع فرعي هذا؛ اثنان من كل حاجة لم قدوم واضح منتج قرار.

**مباشر فتح مرفق عنصر تخزين ملف**سوف يجعل تحرير جهاز تعديل غير ممكن تغيير كائن. لم قدوم حفظ دائم تسليم نظام حاجة أولا واضح تحرير و إبقاء سياسة، مثال مثل كتابة وقت نسخ، مجددا سوف حفظ إصدار كشف إعطاء تطبيق.

**عام artifact حقل أو UI حزمة داخل Host أداة فرعي مسار**سوف توسيع غير متصل API، أو سوف preset تثبيت و متصفح تحزيم اقتران دمج. أداة يملك حدث و عادي حزمة إبقاء قائم نقطة توسيع و إصدار قاعدة.

**بـ أداة نص بصفة حمل دائم بحث جذب**لا يمكن يمكن اعتماد ينبغي مقابل بعد معالجة أو نتيجة فيض خروج. تنفيذ هوية و نهائي نجاح نتيجة جعل إعلان ملكية مستقل في عرض أداة نص.

**ربط ملف وصف رمز نظام الملفات توسيع**سوف تعديل كل مزود، لكن لا يمكن جعل خارجي طاولة وجه تطبيق مع بعد حسب مسار فتح حركة عمل أصل فرعي تحويل. حالي فحص تحقق ملف بيانات وصفية و مسار خريطة؛ تزامن استبدال بعد تكرار أصل ما زال لا في مسار API حفظ إثبات نطاق داخل.

## أثر

Session سجل حفظ دائم إعلان، لا حفظ قدوم ذاتي `present` مرفق عنصر مرجع أو ملف محتوى.Session ZIP توجيه خروج يتضمن هذه إعلان؛ تحويل نقل سجل لن تحويل نقل مساحة العمل ملف. هذا حدث ما زال اشتراط قراءة طرف تعرف آخر، لأن ساكن صامت فقد فقد تسليم إعلان سوف تغيير إعادة بناء أو fork تاريخ. قد إصدار Session صيغة بديل حد إبقاء ثابت.

فقط إعلان بيانات وصفية لا حاجة ملف كبير صغير حد أعلى، لذلك حذف هذا حد؛ يمكن إعداد ملف عدد كمية حد أعلى ما زال حد نتيجة كبير صغير. بطاقة عرض ملف اسم و شرح، لا يوجد شرح وقت رجوع إلى ملف نوع، و كما لا عرض ممكن مرور وقت بايت كبير صغير. لا جذب دخول artifact خدمة أو دفع قياس صفة تخزين رجوع.

تحديد نحو اختبار تغطية لا قراءة محتوى إعلان، بلا فاعلية إدخال، يتم منع توقف نتيجة، مصدر مسار هوية، تحرير بعد حالي بايت، ناقص ملف، مساحة العمل تجاوز حد،fork متبادل مقابل مسار، إعادة محاولة، إلغاء و تحرير. تسجيل صنع Web مشهد تغطية تضمين طقم نجاح بعد خارج طبقة فشل، مصدر ملف تحرير، إعادة تحميل، حذف خطأ، بطاقة و متن فتح كما بلا متصفح تحت تحميل، و لا يتضمن تسليم محتوى Session توجيه خروج.
