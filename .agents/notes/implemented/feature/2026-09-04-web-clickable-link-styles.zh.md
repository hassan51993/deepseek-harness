# Agent Note: Web يمكن نقر رابط لغة——رابط آخر اسم،hover نقطة حالة تحت تخطيط خط، تصنيف رسم علامة

Status: implemented

[English](2026-09-04-web-clickable-link-styles.md) | العربية

## مشكلة

جلسة سجل داخل يمكن نقر ناتج رابط لديه أربعة طقم متبادل لا متسق مثال صيغة:Markdown مرساة نقطة و متن ملف مرجع هو business-primary أزرق إضافة hover فعلي خط تحت تخطيط خط، شبكة صفحة بحث/إمساك أخذ رابط و لـ نفسه، ناتج chips هو رمادي لون دواء حبة (interactive-bg-hover قاع فوق label-secondary نص حرف،96px الأكثر كبير عرض درجة) ،workflow عضو رابط فإن حمل معتاد إقامة فعلي خط تحت تخطيط خط. لا يوجد أي علامة شرح رابط نقطة فتح بعد ذهاب أي طفل (متصفح، مضيف تطبيق،Finder، تطبيق داخل عرض) ، بينما كما رابط لون لون اقتران دمج في `--dsw-alias-state-business-primary` فوق——هو معا قيادة تركيز نقطة حلقة و حالة نقطة، ضبط رابط لون سوف موجة و غير متصل جدول وجه.

## قرار

جلسة سجل يمكن نقر رابط جدول وجه——Markdown مرساة نقطة (يحتوي مرجع صيغة رابط،mailto، يتم رفع رفع لـ رابط inline code) ، متن ملف مرجع، شبكة صفحة بحث مصدر رابط و إمساك أخذ URL، ناتج chips،workflow عضو رابط——موحد واحد لـ واحد طقم رابط لغة:

- لون لون مرور من `design-platform.css` في مخصص استخدام `--dsw-alias-link` آخر اسم (مضيء لون `deepseek-500`، داكن لون `deepseek-400`) ، و `state-business-primary` حل اقتران؛ رابط بـ `font-weight: 500` عرض، افتراضي بلا تحت تخطيط خط،hover/focus وقت لـ 3px offset `underline dotted`.
- قبل وضع تصنيف رسم علامة——ui-primitives إضافة جديدة `LinkIcon`،kind لـ `url`،`folder`،`code`،`image`،`document`،`other`(ورق ورقة)——فقط تصيير `currentColor`؛`url` رسم شكل لـ أرض كرة، هدف أرض رئيسي آلة يخص معروف محطة نقطة وقت فإن لـ هذا محطة نقطة ذاتي ذات علامة ([معروف محطة نقطة رابط علامة](2026-09-16-known-site-link-marks.zh.md)) ؛`classifyLinkPath` يأخذ[مشترك دقيق دقيق ملف نوع تصنيف](2026-09-08-shared-file-type-icons.zh.md) طي دخول هذا ستة نوع رابط صنف آخر، شفرة، شبكة صفحة، بيانات توسيع اسم حسب تصميم مشترك استخدام code رسم شكل. اثنان صنف مرساة نقطة لا حمل رسم علامة:workflow عضو رابط (تطبيق داخل عضو عرض لا يخص أي ملف أو URL صنف آخر) و فقط حزمة صورة مرساة نقطة (شعار فصل أو تقليص اختصار رسم——صورة جانب معلق حال أرض كرة لا يوجد يمكن جذب توجيه نص حرف). سطر داخل رسم علامة لـ 1.1em، أساس خط انحراف نقل −0.25em؛flex إقامة في ناتج رسم علامة فإن تحت نقل 1.2px، لأن 22px نص حرف صندوق حرف شكل منخفض في صندوق في قلب.
- ناتج chips ذهاب إسقاط رمادي لون دواء حبة و 96px حد أعلى: صاف رابط أزرق نص حرف حسب ذاتي لكن عرض درجة عرض، فقط عند كامل سطر فيض خروج وقت عندئذ استلام تقليص خروج حذف رقم؛ حاوية استعلام ملف موضع في قرار عرض بضعة عدد chip وقت ما زال حسب كل 96px ميزانية.
- [ضيق تجميع Thinking Markdown](../bug-fix/2026-09-17-thinking-markdown.zh.md) إبقاء tertiary نص حرف لون و افتراضي نقطة حالة تحت تخطيط خط، بـ إبقاء مرة درجة قوي ضبط.
- لحظة معنى لا حركة:ToolRow رمادي لون نقطة خط ملف رابط، و رمادي لون «في ملف مشبك في عرض» عملية (هو نيل نيل ملف مشبك رسم علامة لكن إبقاء رمادي لون مثال صيغة).
- نفس دفعة مرة في،inline code قاع لون من `neutral-bluish-100` تبديل إلى `neutral-50`(داكن لون:`neutral-800`) ، و إضافة جديدة 0.5px l1 وصف حافة.

تغطية:LinkIcon مفرد قياس (كل kind واحد مستقل رسم شكل، تصنيف جدول) ، تحديث جديد بعد markdown-dom تجهيزة، و `clickable-links-gallery` web e2e——واحد settled keyless عودة دمج تصيير الكل يمكن نقر رابط شكل——مثل أخرى جذب scaffold نفس صنف واحد مثال تسجيل دخول host تحرير ترجمة وجه (`tsconfig.host.json`).

## تجهيز اختيار خطة

- **لون لون Word/Excel/PPT/PDF رابط رسم شكل.** مرفوض: ثابت صنف لوحة ملء ملء مخالفة عكس رسم علامة تجميع currentColor-only قاعدة، لذلك هذه توسيع اسم و دخول مفرد واحد outline `document` رسم شكل. مقارنة كبير ملف بطاقة primitive تعديل استخدام كل منها مختلف current-color جولة محيط.
- **كل توسيع اسم واحد رابط رسم علامة.** استلام جمع لـ ستة عدد صنف آخر:14px تحت تجاوز خروج لحم عين يمكن قسم تمييز عدد كمية رسم شكل فقط سوف زيادة ضجيج صوت.28px `FileTypeIcon` يملك أكثر دقيق دقيق ملف هوية؛ حسب محطة نقطة علامة يقع في نفس `url` صنف آخر لـ تحت ([معروف محطة نقطة رابط علامة](2026-09-16-known-site-link-marks.zh.md)).
- **رابط متابعة استخدام `state-business-primary`.** أكثر عميق رابط أزرق (تجربة مرور blue-600/650/700 أيضا رجوع) سوف وصل حمل تركيز نقطة حلقة و حالة نقطة؛ مخصص استخدام آخر اسم يأخذ لم قدوم ضبط لون استلام جمع إلى واحد سطر.
- **إعطاء ToolRow مسار رابط إضافة رسم شكل.** مرفوض: أداة سطر إبقاء أكثر أمان ساكن رمادي لون نقطة خط عرض قدرة، في قد جدا سري سطر داخل إضافة قبل وضع رسم شكل سوف صنع صار رسم علامة كومة تراكم.

## عاقبة

- جديد يمكن نقر ناتج جدول وجه ينبغي إزالة استهلاك `--dsw-alias-link` و LinkIcon مفردات، بينما لا هو جذب دخول آخر نوع لون لون أو تحت تخطيط خط شكل؛ قاعدة سجل في [docs/web-styling.md](../../../../docs/web-styling.zh.md).
- طويل ناتج ملف اسم حسب ذاتي لكن عرض درجة عرض؛ كامل سطر فيض خروج وقت flex حسب مقارنة مثال استلام تقليص كل chip، بضعة عدد طويل اسم حرف واحد بدء استلام تقليص، بينما لا هو الأكثر بعد واحد أولا يجعل موضع.
- mailto رابط هدف قبل مشترك استخدام `url` أرض كرة رسم شكل؛ إذا سوف قدوم حاجة مستقل بريد عنصر صنف آخر، واحد سطر يكفي إضافة فوق.
