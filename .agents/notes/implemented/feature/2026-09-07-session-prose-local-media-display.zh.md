# Agent Note: جلسة متن محلي وسيط جسم مسار عبر نفس مصدر ملف توجيه عرض

Status: implemented

[English](2026-09-07-session-prose-local-media-display.md) | العربية

## Problem

Assistant متن ممكن عبر نظام الملفات مسار مرجع صورة، لكن متصفح لا يمكن قراءة Host ملف. فقط سماح قطعا مقابل HTTP(S) هدف مصير سوف يأخذ هذه مرجع إبقاء لـ ساكن حالة alt نص.Issue #3662 سجل هذا واحد عرض نقص فتحة.

## Decision

Session متن في محلي وسيط جسم مسار عبر نفس مصدر ملف توجيه تصيير. هذا سجل يملك مصير كلمة جدول و ذلك ملكية؛[تمييز حق نظام الملفات قراءة](2026-09-08-file-display-through-filesystem.zh.md) يملك حالي ملف خدمة سياسة، و يحل محل تحت نص مساحة العمل و وسيط جسم حد.

`ui-primitives` يملك `MarkdownText` فوق `MarkdownPathImages` كلمة جدول. و `fileMentions` واحد مثال، هو فقط في رسالة مستقر بعد توليد فاعلية، جعل تجميد ربط تدفق صيغة كتلة لا يمكن ذاكرة مؤقتة كلمة جدول معالجة دالة. مستقر تصيير مرور مسار إعادة كتابة بعيد مسار URL أبيض اسم مفرد خارج صورة هدف، و فقط إخراج قطعا مقابل `http(s)`،`blob` أو `data` نتيجة. لا يوجد كلمة جدول وقت، محلي هدف إبقاء ساكن حالة alt نص. تحميل فشل سوف يأخذ صورة استبدال لـ عمل من توفير alt نص؛alt لـ فارغ وقت عرض أصلي هدف مسار؛ مختلف مصدر ما زال يمكن إعادة تحميل.

`ui-chat` عبر `AssistantMarkdown` توفير صفحة مستقر `localPathMediaUrl` كلمة جدول. هو يأخذ قطعا مقابل POSIX مسار خريطة إلى صفحة نفس مصدر `/api/file?path=…`. متبادل مقابل مسار، بروتوكول متبادل مقابل مسار،Windows ريح إطار مسار، و Electron `file://` انتظار غير HTTP صفحة نقل إبقاء ساكن حالة رجوع.

`session-controller` في `SessionFileReferences` جانب يملك `SessionMediaReferences` مساهمة. هو عبر `connection.fetch` تسجيل؛ هذا عبر طريق تنفيذ و `/api` RPC نفسه متصفح تمييز حق و معلومة مهمة فحص. ثابت نفس مصدر طرف نقطة يجعل تزامن مصير نيل نيل مستقر URL، بلا حاجة مختلف خطوة قدرة تنسيق تجارة.

## Alternatives considered

**من Typert gateway أو workspace controller يملك.** gateway يملك Remote RPC توزيع،workspace controller يملك سجل التسجيل دورة الحياة. اثنان من كل لا يملك ملف بايت عرض؛Session Controller هو خدمة Session متن مستهلك.

**أولا مرور Session RPC نيل أخذ، مجددا استخدام blob/data URL.** مرفق عنصر صورة يمكن مختلف خطوة نيل أخذ، لكن هذا Markdown كلمة جدول يجب في تسجيل ذاكرة تحويل تصيير مرور مسار في تزامن تحليل هدف.

**صورة مخصص استخدام طرف نقطة.** مفرد واحد ملف توجيه يكفي خدمة صورة، صوت تردد و نظر تردد، بلا حاجة مستقل URL كلمة جدول. حالي تنفيذ إرجاع محدود كامل ملف؛Markdown صوت نظر تردد بث وضع جهاز عقدة ما زال هو مستقل عمل.

**توجيه في بايت توقيع تحقق.** موجه إلى نموذج `read_image` أداة يملك صورة دقيق دخول فحص. عرض استجابة عبر MIME استعلام وصف محتوى، من متصفح حل رمز رفض ضرر تالف تحميل حمل، تجنب تجنب تكرار تنفيذ توقيع فحص جهاز.

**فقط حد مساحة العمل و وسيط جسم وصول (قد يحل محل).** أصل سياسة يأخذ مواصفة مسار حد في قد تسجيل مساحة العمل أصل دليل داخل، و سماح حذف SVG خارج image/video/audio MIME صنف آخر. فتح قبل عادي ملف فحص رفض إدارة طريق و ضبط تجهيز؛ قد فتح جملة مقبض هوية مقارنة مقارنة استلام ضيق استبدال تنافس حالة. هذه حد قيد تمييز حق بعد وصول نطاق، و تجنب تجنب كل مرة طلب تفاعل تخويل مسار. هو جمع أيضا ترتيب حذف مؤقت قطع رسم و بعيد مسار ملف؛ لاحق سجل شرح بديل سياسة و لا إبقاء هذه حد إدارة من.

## Consequences

عميل كلمة جدول لا يمكن التفاف مرور Host تمييز حق أو نظام الملفات مزود. أصل تلقي حد توجيه منطقة قسم مساحة العمل خارج قد وجود مسار و ناقص مسار، أي جعل رفض ذلك بايت ما زال كشف وجود؛ لاحق سياسة فإن سماح مزود يمكن قراءة عادي ملف.

عميل كلمة جدول ما زال لا دعم حمل عمل من توفير Windows ريح إطار مسار. مسار أثر و أداة بطاقة Markdown مستهلك لا توفير هذا كلمة جدول، صوت نظر تردد Markdown عقدة أيضا لا تصيير بث وضع جهاز. هذه يخص مصير حد، و ملف توجيه يمكن قراءة MIME نوع غير متصل.

قد عودة ملف[نموذج يمكن قراءة صورة مسار](../../archived/feature/2026-08-21-model-readable-image-paths.md) سجل يملك نموذج جانب سلوك؛ هذا سجل يملك مستخدم جانب عرض، لا يحل محل هو.

## Testing

مصير اختبار تغطية مستقر و تدفق صيغة بوابة، مرجع صيغة صورة، بروتوكول تكرار فحص، تحميل فشل رجوع و مصدر استبدال. حديث يوم اختبار تغطية كلمة جدول و مكون اتصال.`apps/web/tests/markdown-images.e2e.ts` متصفح مشهد استخدام قد بث نوع Session بدء تسليم Web تركيب، فحص فعلي تحميل و رجوع نص. نموذج قيادة سجل Session نحو إرجاع ما زال مستقل في هذا UI مدة نظر؛ لاحق سجل شرح حالي توجيه تغطية.
