# Agent Note: جانب شريط مساحة العمل طبقة درجة

Status: implemented

[English](2026-09-15-sidebar-workspace-hierarchy.md) | العربية

## مشكلة

سماح كثير دليل مشترك نفس أب دليل وقت، مستو فرش Workspace قائمة لا سهل تصفح متبادل صلة مشروع. إذا يجعل أب دليل يملك كل بعد بديل Session، فإن سوف مخالفة خلف Workspace عضو Session مواصفة عمل دليل يجب انتظار في تسجيل مسار هذا واحد اشتراط.

## قرار

جانب شريط افتراضي سوف Workspace عرض لـ نفس درجة قسم مجموعة. في**عرض خيار → قسم مجموعة طريقة**في اختيار**حسب مساحة العمل شجرة**بعد، جانب شريط من قد تسجيل Workspace مسار إرسال توليد تمرير عودة طبقة درجة. الذي اختيار نمط حفظ في قائم متصفح محلي عرض تخزين في. كل Workspace يقع في الأكثر قريب صارم إطار أصل أولا تحت؛ نفسه مسار لن يصبح ذاتي ذات أب درجة. مقارنة مقارنة التزام دوران دليل قسم فصل رمز و Host كبير صغير كتابة تجميع كتابة، لا تحليل رمز رقم رابط آخر اسم. نفس درجة مشروع إبقاء Host ترتيب.

إضافة دليل سوف مباشر تسجيل عادي Workspace و فتح ذلك Session. أب Workspace إبقاء ذاتي ذات Session و معيار سطر عملية، فرعي Workspace يقع في أب درجة ذاتي ذات Session قبل. قائم متصفح محلي توسيع حالة معا تحكم فرعي Workspace و أب درجة ذاتي ذات Session سطر؛ لا يوجد صريح انحراف جيد وقت، أصل أولا افتراضي توسيع. صريح طي أيضا سوف إخفاء حالي Session، لكن أصل أولا ملف مشبك رسم علامة سوف معرف هو الذي في فرعي شجرة. كل سطر عال مضيء و نقر منطقة مجال انتظار عرض، محتوى حسب طبقة درجة تقليص دخول.Workspace سحب جر حد في نفس درجة بين؛ بعد بديل سقوط نقطة تسليم إعطاء الأكثر قريب توافق أصل أولا، نفس درجة موضع لم تغيير وقت لا كتابة Host ترتيب، بحث تنقل سوف توسيع الكل أصل أولا.

## اعتبار مرور بديل خطة

**افتراضي اعتماد شجرة شكل قسم مجموعة:**هذا سوف يأخذ مشروع إخفاء في أصل أولا لـ تحت، أي استخدام مستخدم أمل نظر مباشر تصفح الكل Workspace. صريح عرض نمط إبقاء افتراضي تخطيط، أيضا لا لـ دليل إضافة مسار زيادة تأكيد.

**تمرير عودة Workspace عضو علاقة:**هذا سوف تغيير عمل دليل ثابت كمية، و يجعل واحد Session معا رمز دمج كثير عدد تسجيل حساب. عرض تضمين طقم لا حاجة هذا اثنان بند تغيير.

**مستقل أب دليل سجل و إضافة وقت اختيار:**هذا سوف تكرار يمثل قد لديه Workspace دليل، و لـ عادي إضافة زيادة تأكيد. أصل حسب سجل التسجيل إرسال توليد طبقة درجة يمكن إبقاء مفرد واحد إضافة مسار، و يجعل كل دليل كل قدرة يملك Session.

**تلقائي اكتشاف دليل:**هذا قدرة عرض بعد لم تسجيل مشروع، لكن حاجة نظام الملفات صف رفع، تحديث جديد و اعتماد سلوك. جانب شريط فقط استخدام حالي Workspace قائمة.

## نتيجة

مستخدم يمكن طي متبادل صلة مشروع، بينما لا تغيير Session ملكية. حذف أصل أولا سوف إبقاء فرعي مساحة العمل تسجيل؛ مستقل [Workspace حذف دلالة](2026-07-27-workspace-registration-deletion.ar.md) ما زال قرار يتم حذف Workspace ذاته Session معالجة، هذا قرار متابعة صالح. متصفح محلي طي انحراف جيد لا عبر متصفح تزامن، تضمين طقم أخذ قرار في قسم فصل رمز عودة واحد تحويل بعد تسجيل مسار تجميع كتابة.

صاف مسار اختبار تغطية صارم إطار أصل أولا علاقة، مسار مقطع حد،POSIX عكس مائل عمود و Windows قسم فصل رمز. مكون و متصفح مشهد تغطية افتراضي نفس درجة قسم مجموعة، شجرة شكل نمط اختيار و استعادة، مباشر إضافة، لاحق تسجيل، أب درجة مستقل Session، طي استعادة، بحث توسيع، عبر بعد بديل سقوط نقطة إجراء نفس درجة ترتيب، أب درجة فرعي شجرة نقل حركة، طي حالي جلسة تلميح و كامل سطر انتظار عرض.
