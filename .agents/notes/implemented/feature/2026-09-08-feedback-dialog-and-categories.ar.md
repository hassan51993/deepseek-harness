# Agent Note: ملاحظات نابض نافذة، تصنيف و تأكيد toast

Status: implemented

[English](2026-09-08-feedback-dialog-and-categories.md) | العربية

## مشكلة

Web عميل لديه اثنان بند متبادل لا متبادل وصل ملاحظات مسار، كما كل لا يوجد مرئي نتيجة.`/feedback <text>` سجل واحد بند Session ملاحظة و في تحويل تسجيل داخل تصيير واحد سطر تأكيد؛ مدح دوس مقابل قيام أي سجل تقييم قسم، ذاتي من نص فإن عبر مرساة تحديد في هذا سطر تحت جهة ملاحظة طفو طبقة ملء كتابة. اثنان بند مسار كل لا إبلاغ إبلاغ مستخدم إيداع ماذا، ذهاب أي داخل، كل لا استلام تجميع تصنيف، بينما نقطة دوس هذا عدد مستخدم الأكثر رغبة معنى حل تفسير مشهد ماذا أيضا لا سؤال.Issue #3515 و ذلك تصميم مسودة اشتراط: واحد نابض نافذة، يمكن من إدخال إطار قائمة مفرد، لا حمل نص `/feedback` و نقطة دوس ثلاثة موضع فتح، حمل سبعة عدد ثابت تصنيف، اختياري وصف، نجاح toast، و قد سجل تقييم قسم فعلي قلب رسم علامة؛ نقطة مدح إبقاء قيام أي سجل.

## قرار

`command-feedback` في ذلك عميل متاح `./types` تصدير في بـ `FeedbackCategory` ربط دمج نوع و `FEEDBACK_CATEGORIES` عنصر مجموعة يملك تصنيف جدول،`feedback/record` تغيير لـ `{ text?, category? }`: فارغ أبيض نص تسجيل لـ نقص حذف، اثنان عدد عضو كل لا يوجد بند ما زال سوف سجل، لأن ملاحظات الذي تخويل سجل إلقاء تمرير ذاته حينئذ هو محتوى. نفس عدد حزمة عبر `TypertRemoteService` إصدار `sessionFeedback.record` Remote، حسب id بحث إلى live Session بعد استدعاء قد لديه `recordFeedback` إنتاج جهة، لذلك نابض نافذة سجل هو و أمر نفسه حدث، فقط هو لا يوجد أمر دفتر تسجيل.`message-feedback` إعطاء `MessageFeedbackItem` و `MessageFeedbackPutRequest` إضافة فوق اختياري `category`، حسب عنصر مجموعة تحقق قد تخزين قيمة، و يأخذ تصنيف تغير حساب عمل فعلي جودة تحرير.

`ui-message-feedback` يصبح Web ملاحظات واجهة. كل Session واحد `FeedbackSurface`، يملك رسالة ملاحظات تحكم جهاز، مسؤول مسودة مسودة، إيداع و toast ترتيب رقم `FeedbackDialogController`، و اثنان من بين توجيه: رسالة هدف مرور رسالة تحكم جهاز put واحد بند حمل نابض نافذة تصنيف و ملاحظة الذي اختيار تقييم قسم،Session هدف مرور `ctx.remote.sessionFeedback` سجل.`conversation.input.overlay` `FeedbackDialog` بند من نابض نافذة store تصيير Modal و Toast أساس عنصر. مضيف `feedback` أمر فوق تركيب زينة يجعل قائمة مفرد اختيار في أو لا حمل معامل عودة عربة لـ Session فتح نابض نافذة، بينما `/feedback <text>` ما زال وصول مضيف؛ هو استخدام `CommandUiSpec` في `action` نوع صنف: عار استدعاء إزالة استهلاك إطلاق token بعد تشغيل واحد عميل عودة ضبط، لا إيداع أي محتوى. لاحق[مقابل تسمية رسالة ملاحظات إيداع](2026-09-10-symmetric-message-feedback-submission.ar.md) قرار يملك تقييم قسم مدخل قاعدة: مهمة واحد لم سجل تقييم قسم كل سوف فتح نابض نافذة، مجددا مرة نقر قد سجل تقييم قسم فإن سحب عودة. ملاحظة طفو طبقة،`clearNote` و `clear` متابعة إبقاء إزالة، لأن نابض نافذة هو وحيد ملاحظة تحرير جهاز.

نابض نافذة هو مشترك استخدام Modal بطاقة، عرض درجة حسب تصميم مسودة؛ تصميم مسودة داخل «يشمل حالي محادثة سجل» تكرار اختيار إطار لا فعل، لأن سجل مع كل ملاحظات حدث واحد بدء إلقاء تمرير، لا هو اختياري بند. تجاوز طويل وصف ما زال في إيداع وقت بـ `note-too-large` فشل؛ نابض نافذة إبقاء مسودة مسودة و عبر تحذير إبلاغ toast عرض محلي تحويل خطأ.

## اعتبار مرور بديل خطة

**يأخذ تصنيف تحرير دخول ملاحظة نص.** ذاتي من نص داخل بادئة لا تحليل حينئذ لا يمكن مرور ترشيح، أيضا سوف خلط دخول بعيد قياس فوق نقل أصل مثال ملاحظة؛ تحميل حمل داخل حمل دائم id عندئذ هو مستهلك قدرة قسم مجموعة شرق غرب.

**يجعل نابض نافذة مرور أمر مستو وجه بـ `/feedback <text>` إيداع.** أمر رفض فارغ نص، حمل لا تصنيف، أيضا سوف كتابة واحد سطر تصميم مسودة قد استخدام toast يحل محل تأكيد؛Remote سجل نفس عدد حدث كما لا يوجد هذا اثنان عدد قيد.

**في نابض نافذة خارج إبقاء ملاحظة طفو طبقة.** نفس بند ملاحظة لديه اثنان عدد يمكن بلوغ صفة مختلف تحرير جهاز، سوف يجعل هذا سطر في بعض بعض عرض درجة تحت تغيير صار اثنان سطر، صحيح هو عند أول جذب دخول طفو طبقة يلزم تجنب تجنب نقص وقوع، بينما كما تصميم مسودة فقط لديه اثنان عدد إبهام إشارة.

**كل رسالة تحكم عنصر كل منها واحد Toast.** إدخال إطار طفو طبقة قد حسب Session تركيب مرة، نابض نافذة أيضا يملك toast ترتيب رقم، لذلك واحد يحتفظ من معا خدمة اثنان نوع رسالة تقييم قسم مسار و Session نابض نافذة.

**في `CommandUiSpec` داخل إضافة جديدة dialog نوع صنف.** واحد إزالة استهلاك token بعد تشغيل عميل عودة ضبط action قد كاف استخدام؛ «ملف» سطر استخدام نفس عدد `action` نوع صنف، واحد نسخة تعريف يكفي خدمة اثنان عدد بند.

## عاقبة

إضافة جديدة تصنيف معنى طعم حال يأخذ هو إضافة دخول ربط دمج نوع، مضيف عنصر مجموعة، نابض نافذة وسم سجل و `feedback` كلمة قاموس؛ عميل تحزيم صاف درجة بوابة توقف من مضيف حزمة فعل قيمة استيراد، لذلك نابض نافذة بـ `Record<FeedbackCategory, true>` إعادة وصف تصنيف جدول، مفتاح ترتيب حينئذ هو وسم ترتيب، كامل صفة من تحرير ترجمة جهاز فحص. تجميد ربط قد إصدار v2 تحميل حمل بيان ما زال يأخذ `feedback/record` صف لـ فقط لديه `text`: هو إدارة ولاية من قديم بديل حد ترحيل قدوم ناتج، ذلك بعض ناتج غير ممكن قدرة يحمل جديد عضو، بينما نفس إصدار استعادة تطبيق هو قد تثبيت مفردات. ثابت طفو طبقة بضعة أي `message-feedback-layout` Web مشهد مع طفو طبقة واحد بدء حذف.message-feedback و feedback-release Web مدة نظر إخراج و ملاحظات فرعي نظام وثيقة في نفس عدد PR في تحديث؛SDK ملاحظات إنتاج جهة سوف سجل واحد بند حمل تصنيف Session ملاحظة و واحد بند حمل تصنيف فرق تقييم، لذلك اثنان عدد SDK مدة نظر إخراج كل يحمل جديد عضو.
