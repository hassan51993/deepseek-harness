# Agent Note: وثيقة محطة صفحة Markdown عملية

Status: implemented

[English](2026-09-15-docs-page-markdown-actions.md) | العربية

## مشكلة

قراءة من حاجة مرئي مدخل قدوم نيل أخذ مفرد صفحة وثيقة Markdown. إصدار نص يجب إبقاء حالي لغة و إسقاط بعد رابط. متصفح طلب في تطوير بيئة في أيضا و Vite صفحة وحدة استيراد مشترك استخدام URL، لذلك سوف كل Markdown طلب كل بصفة أصل نص معالجة سوف كسر تالف تنقل.

## قرار

[إسقاط جهاز](../../../../scripts/project-doc-site.ts) أصل حسب إصدار manifest(بيانات وصفية بيان) لـ عادي محتوى صفحة توفير `rawMarkdownPath`.[رئيسي عنوان](../../../../website/.vitepress/theme/index.ts) سوف هذا مسار و محطة نقطة base تركيب، في متن فوق جهة توفير نسخ و فحص نظر عملية. دليل صفحة استخدام كامل `index.md` توجيه، جعل متبادل مقابل رابط في تطوير بيئة و ساكن حالة بناء في إبقاء نفسه موضع. أول صفحة إعادة تحديد نحو و ناقص صفحة لا عرض عملية. أصل نص إخراج لا يتضمن إسقاط بيانات وصفية.

خدمة طرف تصيير صفحة توفير أصل نص رابط. عميل تركيب بعد سوف ذلك استبدال لـ نسخ حسب زر و قائمة مفرد، جعل MPA بناء و لم تشغيل JavaScript صفحة إبقاء متاح عملية. رئيسي حسب زر مباشر نسخ صفحة، و عبر `aria-disabled` و `aria-busy` في نسخ خلال إبقاء مفتاح قرص تركيز نقطة. جانب حافة توسيع حسب زر فتح حمل رسم علامة، عملية عنوان و شرح نص حرف قائمة مفرد، جعل معتاد استخدام عملية إبقاء مرئي، و سوف Markdown خيار وضع في واحد بدء. قائمة مفرد بند دعم حمل جهة نحو مفتاح،Home،End و تنشيط عملية؛Escape سوف تركيز نقطة استعادة إلى توسيع حسب زر، خارجي إشارة إبرة عملية و تركيز نقطة مغادرة فتح سوف إغلاق قائمة مفرد. قائمة مفرد حسب تحت وقت إبقاء تركيز نقطة مباشر حتى نقر تنفيذ، أيضا ملائم لأجل حسب تحت تحكم عنصر وقت لا تحويل نقل تركيز نقطة متصفح. قائمة مفرد حالة و ذلك خارجي إشارة إبرة مستمع ملكية في صفحة نسخة.

[تطوير في بين عنصر](../../../../website/raw-markdown.ts) قبول حمل لديه صريح `?dsh-raw=1` علامة متصفح طلب، مقابل لم إصدار أصل نص توجيه إرجاع 404. نص برمجي استيراد بداية نهاية تسليم إعطاء Vite. فحص نظر رابط في جديد وسم صفحة فتح عادي أصل نص URL؛ نسخ حسب يحتاج قراءة نفسه إسقاط متن. توليد Markdown ملف يحمل UTF-8 BOM، لأن ساكن حالة حمل إدارة ممكن حذف استجابة محرف تجميع، توجيه يؤدي متصفح مباشر وصول وقت خطأ حل رمز العربية انتظار غير ASCII محرف.Fetch حل رمز سوف في نسخ قبل إزالة BOM. اثنان نوع عملية كل لا من تصيير بعد DOM إعادة بناء Markdown.

[نسخ مكون](../../../../website/.vitepress/theme/page-markdown-actions.ts) في نقر يد اتجاه داخل استدعاء `clipboard.write`، و توفير من Promise تحمل تحميل بيانات `text/plain` ClipboardItem. أولا انتظار شبكة شبكة سوف في اشتراط مستخدم تنشيط متصفح في فقد فقد هذا تنشيط حالة. كل توجيه و لغة تركيب كل لديه مستقل، حمل key مكون نسخة، لذلك قديم كتابة لا يمكن تغيير جديد صفحة عكس تغذية. تحرير وقت إلغاء لم إتمام بيانات قراءة. قد إزالة استهلاك بيانات نظام قص لصق لوح كتابة لا يمكن سحب عودة. طلب فشل و قص لصق لوح فشل توفير محلي تحويل يد حركة نسخ إشارة جذب، نجاح تلميح في كتابة إتمام بعد عرض. يتم رفض كتابة ممكن تماما لا إزالة استهلاك بيانات Promise، لذلك هذا Promise لديه مستقل رفض معالج.

## اعتبار مرور بديل خطة

**أصل حسب متصفح عنوان دفع توجيه أصل نص URL.** بسيط نظيف URL، دليل بحث جذب، لغة بادئة و نشر base جعل هذا نوع طريقة لا مثل إسقاط جهاز معروف توجيه يمكن اعتماد.

**سوف كل Markdown طلب كل بصفة أصل نص معالجة.** Vite سوف نفسه URL استيراد لـ JavaScript وحدة. صريح طلب علامة منطقة قسم أصل نص نيل أخذ، معا ساكن حالة حمل إدارة ما زال يمكن مباشر إرجاع قد توليد ملف.

**أولا نيل أخذ متن، مجددا استدعاء `writeText`.** هذا نوع طريقة ممكن في Chromium في صالح، لكن أخرى متصفح سوف في شبكة شبكة انتظار بعد فقد فقد الأكثر أول يد اتجاه. من Promise تحمل تحميل قص لصق لوح بيانات يمكن إبقاء هذا يد اتجاه، بلا حاجة مسبق أخذ صفحة.

## أثر

تلقائي نسخ قبول `text/markdown` أو `text/plain` استجابة. حمل إدارة جهة يجب لـ `.md` ملف إشارة تحديد منها واحد نوع محتوى نوع؛ ناقص نوع و `application/octet-stream` سوف إطلاق فشل و يد حركة نسخ إشارة جذب. أبيض اسم مفرد أيضا سوف رفض HTML رجوع صفحة و JavaScript صفحة وحدة. تلقائي نسخ حاجة متصفح في أمان سياق في توفير مختلف خطوة ClipboardItem كتابة API. كتابة لا تلقي دعم حمل أو يتم رفض وقت، فحص نظر رابط ما زال متاح في يد حركة نسخ. صفحة نسخ حالة هو مؤقت حالة، ملكية في مفرد واحد توجيه؛ هو لا إنشاء Session بيانات أو نموذج طلب.

[مكون اختبار](../../../../website/tests/page-markdown-actions.spec.ts) في الذي تابع دليل في ثابت محلي تحويل يمكن وصول إخراج، و تحقق تأخير متأخر قراءة، كتابة رفض و تنقل وقت مورد تنظيف.[في بين عنصر اختبار](../../../../website/tests/raw-markdown.spec.ts) تغطية طلب توزيع. اثنان من كل عبر اختبار وحدة،`docs:check` و `doc-sync` تنفيذ.[Mermaid فحص نظر جهاز قرار](2026-09-14-docs-mermaid-viewer.ar.md) إبقاء مستقل تصيير و مورد دورة الحياة قاعدة.

**CI تغطية نقص فتحة.** DOM اختبار نموذج محاكاة قص لصق لوح، لا تنفيذ أصلي مستخدم تنشيط قاعدة، فعلي لصق لصق أو استجابة صيغة تخطيط. لذلك ما زال يحتاج في تطوير خدمة و ساكن حالة معاينة في إجراء متصفح تحقق، تغطية اثنان نوع لغة و محطة نقطة base. هذا ساكن حالة وثيقة وظيفة لا تعلق و حقيقي نموذج جولة.
