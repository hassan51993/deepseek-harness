# Agent Note: قد تسليم تركيب في افتراضي Web بحث

Status: implemented

[English](2026-07-31-web-default-search.md) | العربية

[مشترك base Web إمساك أخذ قيمة افتراضية](../../archived/feature/2026-09-01-shared-base-web-fetch-default.md) يحل محل هذا نص صلة في إمساك أخذ حسب يحتاج تفعيل قرار. هذا نص متابعة مسؤول افتراضي بحث مزود، اعتماد تحليل، طرف نقطة، مهلة، و مزود متاح صفة و نموذج أداة تسجيل بين منطقة قسم.

## مشكلة

هذا harness قد أداة تجهيز كامل Web قدرة جسم نظام: مزود سجل التسجيل،DeepSeek،Exa و Perplexity بحث مزود، محلي إمساك أخذ، مستقر موجه إلى نموذج أداة، و بنية تحويل نتيجة عرض، لكن قد تسليم `dsh web` تركيب لا يوجد تركيب منها أي واحد بند. حذف غير نشر توفير ذاتي تعريف تغطية طبقة، لا فإن نموذج لا يمكن اكتشاف الأكثر جديد معلومة. فقط تركيب قائم DeepSeek مزود ما زال لا يمكن ضرب عبر WebUI سلسلة مسار:Models صفحة عبر `ctx.credentials` تخزين `DEEPSEEK_API_KEY`، بينما بحث مزود فقط سوف في إضافة تحميل وقت ثابت قراءة عملية بيئة، لذلك في تشغيل في UI إدخال أو جولة تبديل مفتاح لا يمكن لأجل بحث.

## قرار

`packages/bundle/base/cordis.patch.yml` واضح تركيب `dsh-web`، إعداد `searchProvider: deepseek-official` و `fetchProvider: http`، معا تركيب `dsh-web-search-deepseek`،`dsh-web-fetch-http`، و بـ `searchTimeoutMs: 60000` تركيب `dsh-tool-web`.[مشترك base Web إمساك أخذ قيمة افتراضية](../../archived/feature/2026-09-01-shared-base-web-fetch-default.md) مسؤول حالي `fetch: true`؛ هذا نص متابعة مسؤول مزود اختيار، بحث اعتماد و مهلة. صريح مزود id جعل اختيار لا تلقي تسجيل ترتيب أثر، معا عدد شخص تغطية طبقة أو `--patch` تغطية طبقة ما زال يمكن استبدال أو منع استخدام هذه بند إعداد. قد تسليم واحد قسم ساعة ميزانية لأجل تغطية مرة مساعد مساعدة DeepSeek Messages طلب و خدمة طرف فحص بحث، معا إبقاء `dsh-tool-web` مزود غير متصل 30 ثانية قيمة افتراضية ثابت، بـ توفير ذاتي تعريف تركيب استخدام.[Web قدرة seam قرار](../architecture/2026-06-24-web-capability-seam.ar.md) مسؤول عام إمساك أخذ أمان سياسة.

DeepSeek بحث استخدام و رسمي جهة جلسة مهايئ نفسه `DEEPSEEK_API_KEY` اعتماد مرجع. مزود في كل مرة بحث داخلي عبر اختياري `ctx.credentials` خدمة تحليل هذا مرجع؛ فقط لديه لم تركيب هذا seam تركيب عندئذ سوف رجوع إلى بدء عملية بيئة متغير، غير فارغ `apiKey` حرف وجه قيمة ما زال بصفة برنامج تحويل إعداد الأكثر بعد التقاط قاع. لذلك، من Web Models صفحة تخزين أو جولة تبديل مفتاح بلا حاجة إعادة بدء يكفي لأجل تحت مرة بحث، مزود أيضا بلا حاجة إبقاء هذا قيمة. من في `WebSearchProvider.available()` هو تزامن طريقة، هو سوف سوف قد تثبيت محلل نظر لـ محلي متاح؛ إذا حركة حالة اعتماد ناقص، عملية سوف بـ مزود مخصص تابع رمز خطأ `WEB_PROVIDER_CREDENTIAL_MISSING` فشل، بينما مستقر أداة schema ما زال إبقاء تسجيل.

بحث طرف نقطة و chat completions إبقاء مستقل:`DEEPSEEK_SEARCH_BASE_URL` تغطية Anthropic توافق أساس عنوان،`DEEPSEEK_BASE_URL` فإن متابعة إعداد جلسة طلب. كل مرة `web_search` كل سوف إرسال بدء مرة مساعد مساعدة DeepSeek Messages استدعاء، و يحمل أصلي بحث خادم أداة. إرسال خروج طلب قبل واحد لحظة، مزود سوف نحو إرسال بدء طلب agent(ذكي جسم) جلسة إلحاق فقط لأجل سجل LLM(كبير لغة نموذج) طلب حدث `web/deepseek-search-llm-request`، منها يتضمن قد تحليل طرف نقطة،API إصدار، و لا يحتوي مفتاح دقيق JSON طلب جسم. طلب إرسال خروج بعد فشل سوف إشارة خروج هذا طرف نقطة؛ عند طرف نقطة لا رمز دمج مستخدم مسبق مدة وقت، خطأ رسالة سوف اشتراط جلسة نموذج إشارة توجيه مستخدم في Settings في تعديل شبكة صفحة بحث Endpoint حقل. هذا ضبط صفحة غير ممكن استخدام وقت، رسالة سوف شرح `DEEPSEEK_SEARCH_BASE_URL` و `web-search-deepseek.baseURL`؛ نموذج لا نيل بديل مستخدم اختيار أو تعديل اعتماد إرسال هدف أرض. اعتماد مسبق فحص ما زال إبقاء في مزود داخلي، و و استدعاء جهة إلغاء وجود تنافس حالة؛ هذا اثنان بند صلة ملاحظة نقطة كل لن توسيع عام Web seam أو اعتماد seam.

افتراضي تركيب لن إنشاء Web مخصص استخدام إذن سياسة.`web_search` و قد تفعيل `web_fetch` استدعاء سوف في bash/نظام الملفات صندوق رملي و مراجعة دفعة preset خارج تنفيذ، و التزام دوران `dsh-tool-web` قائم اتفاق.HTTP مزود يأخذ إمساك أخذ حد إلى قد تحقق عام هدف عنوان، لكن لا حد عام بيانات خروج محطة. قد تسليم `workspace-write` قيمة افتراضية فقط إدارة ولاية ملف تعديل؛ إذا منتج أخذ أخذ تلقي حد شبكة شبكة سياسة، حينئذ حاجة إضافة `tools/pre-execute` سياسة أو حسب قدرة حد شبكة شبكة وصول، بينما لا يستطيع داكن عرض نظام الملفات وصول نمط سوف إدارة ولاية Web استدعاء.

## اعتبار مرور بديل خطة

**فقط تركيب `dsh-tool-web`.** غير مقبول: مستقر schema إذا لا يوجد قد تسجيل مزود، كل مرة افتراضي استدعاء كل سوف فشل. تفعيل حالة و خلفية متاح صفة لحظة معنى قسم مغادرة، لكن قد تسليم افتراضي إعداد يجب توفير ذلك مسبق مدة تنفيذ.

**من `cordis.yml` قراءة `$DSH_HOME/.env`، أو سوف ذلك رفع رفع إلى `process.env`.** غير مقبول: اعتماد مزود يملك هذا ملف، بيئة متغير قيمة هو فقط قراءة تغطية؛ رفع رفع بعد تخزين مفتاح سوف لا يمكن جولة تبديل، أيضا سوف التفاف مرور مرور مراجعة حساب مفتاح حد.

**في مزود تحميل وقت ثابت قراءة `process.env.DEEPSEEK_API_KEY`.** غير مقبول:Web Models صفحة عبر `ctx.credentials` كتابة مفتاح؛ منتج وثيقة قاعدة تحديد أول مرة تشغيل مسار يجب حفظ إثبات تحت مرة عملية بلا حاجة إعادة بدء يكفي توليد فاعلية.

**سوف Web أداة إبقاء في `web.cordis.yml` في.** غير مقبول: هذا سوف إبقاء TUI و Web/بلا رأس واجهة بين لا يمكن حل تفسير أداة بيان فرق مختلف. هذه إعداد سطر و غير واجهة خاص لديه، لذلك ذلك وحيد ملكية هو `base.cordis.yml`؛[أداة بيان قرار](2026-07-31-even-out-shipped-tool-rosters.ar.md) سجل هذا واحد مشترك تركيب.

**رفع عال `dsh-tool-web` مزود غير متصل مهلة.** غير مقبول: ذاتي تعريف مزود و نشر لديه كل منها مختلف تأخير متأخر مسبق مدة؛ هذا واحد نشر ميزانية ينبغي عودة قد تسليم DeepSeek تركيب كل.

**في كل مشترك base surface فوق تفعيل إمساك أخذ.** هذا نص سبق بسبب كل منتج ممكن حاجة مختلف شبكة شبكة سياسة بينما مرفوض هذا خطة. قد تسليم منتج اعتماد نفس عدد كامل أداة تجميع دمج بعد،[مشترك base Web إمساك أخذ قيمة افتراضية](../../archived/feature/2026-09-01-shared-base-web-fetch-default.md) يحل محل هذا مرفوض؛ فقط حد عام هدف عنوان و بلا حاجة تدريجي مرة مراجعة دفعة قيد ما زال صالح.

## عاقبة

headless، كامل SDK،ACP و فقط استخدام base ذاتي تعريف profile أصلي نموذج طلب كل سوف يحمل `web_search` و `web_fetch` schema و إشارة جذب؛Web preset سوف كشف نفس مقابل أداة،PTC mode أيضا سوف عبر `run_code` كشف هو جمع. بحث سوف زيادة مرة كامل مساعد مساعدة نموذج استدعاء، و ممكن كثير مرة استخدام أصلي خادم أداة؛ إرسال بدء جلسة سجل ما زال يمكن دقيق إعادة بناء ذلك لا يحتوي مفتاح طلب. إمساك أخذ سوف قوي صنع استخدام عام عنوان، و كما بلا حاجة تدريجي مرة مراجعة دفعة.Web لقطة عبر طريق سوف بدء قد تسليم إعداد شجرة، استخدام محلي Messages fixture(اختبار قبل وضع بيانات) ، مرور من حقيقي DeepSeek مزود قيادة مرة إعادة تشغيل `web_search` استدعاء، تأكيد حفظ دائم مساعد مساعدة طلب و بنية تحويل نتيجة، و ثابت نهائي متصفح عرض. مشترك snapshot header سوف ثابت عام إمساك أخذ schema و تلميح إشارة جذب. تركيب خطر دخان اختبار سوف ثابت أداة تجميع دمج؛ بناء بعد تركيب إعداد تحويل تخزين ثابت قد تسليم واحد قسم ساعة بحث ميزانية؛ مزود اختبار ثابت ناقص، قد تخزين و قد جولة تبديل اعتماد سلوك، و حرف وجه قيمة و بيئة متغير توافق صفة.
