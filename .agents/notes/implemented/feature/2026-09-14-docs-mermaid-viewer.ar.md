# Agent Note: وثيقة محطة Mermaid عرض جهاز

Status: implemented

[English](2026-09-14-docs-mermaid-viewer.md) | العربية

## مشكلة

تكرار مختلط Mermaid رسم جدول تقليص وضع إلى وثيقة متن صف عرض بعد، دقيق عقدة صعب بـ تمييز إقرار. قراءة قراءة طويل وقت ترتيب رسم حاجة في إبقاء كل رسم عام تصفح معا وضع كبير و مستو نقل، بـ فحص تفاعل دقيق عقدة.

## قرار

[VitePress رئيسي عنوان](../../../../website/.vitepress/theme/index.ts) في كل ورقة قد تصيير Mermaid SVG زاوية سقوط زيادة كل شاشة رسم علامة. أصلي نموذج حالة محادثة إطار جعل خلف مشهد غير ممكن تفاعل، و دعم حمل Escape خروج. مرئي عنوان أيضا لأجل مساعد مساعدة تقنية فن تعرف آخر محادثة إطار؛ صفحة عنوان ناقص أو لـ فارغ أبيض وقت، استخدام محلي تحويل عرض جهاز عنوان. طفو حركة أداة شريط تجميع في عرض تقليص وضع تحكم عنصر، حالي مقارنة مثال و ملائم ينبغي نافذة عملية؛ إغلاق حسب زر يقع في قمة جزء زاوية سقوط، مساعدة حسب يحتاج توسيع. مفتاح قرص تركيز نقطة في خمسة عدد حسب زر بين حلقة.Panzoom توفير إشارة إبرة، تدحرج جولة و مزدوج إشارة تفاعل. جهة نحو مفتاح حسب ثابت شاشة ستار مسافة مغادرة مستو نقل. إغلاق وقت استعادة مدخل تركيز نقطة كما لا تمرير صفحة، و استعادة صفحة أصل لديه overflow ضبط.

عرض جهاز سوف SVG نسخ إلى shadow root في.Mermaid داخل تضمين اختيار جهاز و قطعة مقطع ID حد تحديد في فرعي هذا داخلي، لذلك فرعي هذا علامة و مثال صيغة لن تحليل إلى أصلي رسم جدول فوق.Panzoom تغيير تبديل و نظر فتحة انتظار كبير رسم نشر، منها SVG استخدام viewBox ذاتي لكن مقياس قياس، جعل إشارة إبرة جلوس علامة و تغيير تبديل أصل نقطة مشترك نفس عدد في قلب؛ ابتدائي تقليص وضع و كل مرة نافذة مقياس قياس تغير كل سوف ملائم إعداد كامل ورقة رسم جدول، كما لن وضع كبير إلى تجاوز خروج ذاتي لكن مقياس قياس. هذا مثال حيث إبقاء سهم كمية دقيق عقدة، أيضا جعل ملائم إعداد لا تلقي وثيقة ضيق صف عرض درجة أثر. رسم نشر لا يوجد مرئي حافة إطار؛ مسبق إبقاء فضاء جعل تحكم عنصر لن حجب حجب ملائم إعداد بعد رسم جدول.

عرض جهاز مورد من قد تركيب رئيسي عنوان يحتفظ. توجيه، لغة، رئيسي عنوان و مصدر SVG استبدال كل سوف إغلاق حالي عرض؛ مختلف خطوة تصيير Mermaid رسم جدول سوف نيل نيل جديد مدخل.body overflow تمرير قفل اعتماد افتراضي رئيسي عنوان يجعل HTML عنصر عنصر إبقاء visible overflow. هو تجنب تجنب تعديل HTML خاصية، لأن Mermaid إضافة سوف مراقبة هذه خاصية و إعادة تصيير.[تنفيذ](../../../../website/.vitepress/theme/mermaid-viewer.ts) سوف Markdown، أصلي صفحة فرعي هذا و `llms.txt` توليد إبقاء في أصل لديه ملكية موضع.

## اعتبار مرور بديل خطة

**إضافة عرض وثيقة متن صف.** أكثر عرض متن صف لا يمكن يجعل مهمة معنى كبير صغير رسم جدول دقيق عقدة كل صاف واضح يمكن قراءة، طويل رسم ما زال سوف تجاوز خروج نظر فتحة.

**استخدام ذاتي تعريف حجب غطاء و وثيقة درجة مستمع.** أصلي محادثة إطار قد قدرة جعل خلف مشهد غير ممكن تفاعل، و معالجة نموذج حالة خروج. من رئيسي عنوان يحتفظ مورد يجعل تنقل و مورد تنظيف مسؤولية واضح؛ حمل دائم وثيقة درجة مستمع فإن حاجة مفرد وحيد دورة الحياة آلية.

**موضع رسم معاينة أو نفس وثيقة داخل SVG فرعي هذا.** موضع رسم في عال ضعف معدل تقليص وضع تحت سوف فقد فقد سهم كمية دقيق عقدة. نفس وثيقة داخل فرعي هذا سوف تكرار Mermaid ID و داخل تضمين مثال صيغة؛ إعادة كتابة الكل SVG و CSS مرجع سوف حمل قدوم مقدار خارج تحليل مسؤولية، بينما shadow root يمكن تجنب تجنب هذا بند مسؤولية.

## أثر

وثيقة محطة زيادة Panzoom مباشر اعتماد، و استخدام أصلي dialog،shadow root و ResizeObserver دعم حمل. عرض جهاز تقليص وضع و مستو نقل حالة هو مؤقت: نافذة مقياس قياس تغير سوف إعادة ملائم إعداد رسم جدول، تنقل أو رئيسي عنوان تغير سوف إغلاق عرض. أصل لديه صفحة رسم جدول ما زال هو قراءة قراءة و رابط تنقل مصدر.

[تحديد نحو اختبار](../../../../website/tests/mermaid-viewer.spec.ts) يخص أصل اختبار وحدة تجميع؛`docs:check` و `doc-sync`(وثيقة تزامن بوابة) أيضا سوف اختيار في هذه اختبار، جعل فقط تشغيل وثيقة تحقق وقت نفس مثال تغطية عرض جهاز. هو جمع تحقق تأخير متأخر تصيير، بلا عائق عائق عنوان، ابتدائي و نافذة تغير بعد ملائم إعداد، تحكم عنصر اتصال، مفتاح قرص تركيز نقطة حلقة، رسم جدول استبدال و مورد تحرير.

**CI تغطية نقص فتحة.** DOM اختبار نموذج محاكاة Panzoom، لا تنفيذ متصفح تخطيط. أصلي نموذج حالة سلوك،SVG علامة، بـ إشارة إبرة لـ مرساة نقطة تدحرج جولة تقليص وضع، رسم نشر سحب حركة، رئيسي عنوان لون لون و ضيق شاشة بضعة أي تخطيط حاجة حقيقي متصفح تحقق. متصفح عرض عرض سجل توفير حالي تنفيذ دليل، لكن لا يخص تلقائي ارتداد فحص.
