# Agent Note: يتم تفويض إرسال subagent بـ تثبيت تحديد لـ `'never'` مراجعة دفعة سياسة تشغيل

Status: implemented

[English](2026-08-10-subagent-approval-pinned-never.md) | العربية

## مشكلة

يتم تفويض إرسال فرعي agent إرسال بدء مراجعة دفعة طلب وقت بلا شخص يمكن سؤال. في تفاعل صيغة أب درجة (`'ask'`) لـ تحت، خلفية فرعي agent ترقية طلب سوف تغيير صار واحد أي منتج واجهة كل لا عرض تعليق بدء مشكلة——subagent جلسة لا دخول Web الشريط الجانبي، أب درجة `list_agents` فقط تقرير إبلاغ عادي `running`/`idle`، دليل شجرة سطر أيضا فقط عرض نشط حركة حالة——لذلك يتم إذن اعتراض إقامة فرعي agent و صحيح معتاد جاف نشط فرعي agent لا يمكن منطقة قسم؛headless و بلا ينبغي جواب من تركيب فإن يجعل نفس مرة ask بـ `'unavailable'` فشل إغلاق. رفض مراجعة حساب سجل فقط سقوط في فرعي agent ذاتي ذات سجل داخل، بينما كما لا يوجد أي أداة معامل أو Web تحكم عنصر قدرة ضبط كامل واحد جارٍ تشغيل فرعي جلسة صندوق رملي نمط أو مراجعة دفعة سياسة (Issue #1723). آلية كثيف إعادة إصلاح خطة——حفظ دائم تلقي منع حالة إسقاط، أب درجة إشعار، دليل شجرة شعار علامة، و اختراق مرور subagent كل حق محيط شريط إذن كتابة مسار——في قرب قريب إصدار وقت بديل قيمة لا صار مقارنة مثال.

## قرار

يتم تفويض إرسال فرعي agent فقط في تفويض إرسال وقت ثابت إذن نطاق داخل سطر حركة، مراجعة دفعة تلميح فإن من هو عالم حد في تام قاع إزالة:`captureDelegatedPolicyOverrides(parent)`(`dsh-subagent/src/child-agent.ts`) ما زال مقابل أب جلسة صريح صندوق رملي تغطية بند بناء قيام لقطة، لكن فقط يلزم مراجعة دفعة قدرة قد تركيب، حينئذ يأخذ `approvalPolicy: 'never'` تثبيت تحديد تحت قدوم——لم يعد قراءة أب درجة ذاته مراجعة دفعة سياسة.`appendDelegatedPolicyOverrides()` يأخذ هذا عدد تثبيت تحديد بصفة حفظ دائم `approval/policy { policy: 'never', source: 'delegation' }` حدث كتابة فرعي agent سجل، و صندوق رملي لقطة مشي تماما نفسه مرة صفة و يمكن متابعة تفويض إرسال مسار، لذلك بارد استعادة سوف إعادة وضع هو،fork نوع فرعي في قديم قديم أب درجة سياسة أيضا سوف نقل إعطاء هو.

قوي صنع تنفيذ امتداد استخدام قائم `ApprovalService` `'never'` دلالة، سقوط في قطع قرار ask وحيد عملية فوق: فرعي agent كل مرة ask——bash أو fs `sandbox_permissions` ترقية،hook قيادة إذن استفسار سؤال، أي لم قدوم طلب جهة——كل في استشارة استفسار أي ينبغي جواب من قبل تحديد صفة أرض تحليل لـ `'rejected'`، معا ما زال في فرعي سجل فوق إبقاء تحت `approval/asked`/`approval/decided` مراجعة حساب مقابل. فرعي agent الكل إذن لذا أمر لذلك حينئذ هو هو صندوق رملي نطاق:`danger-full-access` أب درجة تفويض إرسال خروج فرعي agent بلا حاجة أي مراجعة دفعة،`read-only` أب درجة تفويض إرسال خروج فرعي agent لا يوجد أي هروب توليد عبر طريق، بينما وضع عرض قرار بداية نهاية يخص أب درجة واحد جانب (أولا وضع عرض أب جلسة، مجددا إعادة تفويض إرسال أو متابعة follow-up).

كل عملية داخل فرعي agent كل يتم إبلاغ معرفة بينما غير يتم صعب إقامة:`applyChildComposition` تسجيل أثر مجال داخل `subagent:delegation` وقت التشغيل سياق إعلان (order 120، يقع في `sandbox:policy` و `approval:policy` لغة جملة بعد) ، إعلان إذن نطاق قد في بدء وقت ثابت، حاجة مراجعة دفعة عملية سوف يتم تلقائي رفض، حاجة أكثر عرض وصول مهمة ينبغي بـ فوق تقرير حد استلام ذيل بينما لا هو إعادة محاولة. هذا إعلان هو وقت التشغيل سياق مساهمة بينما غير توجيه النظام section، لذلك نشر توجيه النظام في أب فرعي بين إبقاء موحد واحد (لقطة اختبار طقم عنصر تثبيت إقامة هذا واحد موحد واحد صفة) ، هذا واقع أيضا مع سياسة لغة جملة ركوب جلوس نفس نسخة حفظ دائم لقطة.

هذا قرار يحل محل[عملية داخل تفويض إرسال سياسة قرار](2026-07-25-subagent-policy-inheritance.ar.md) في مراجعة دفعة واحد نصف، و دفع قلب ذلك «قوي صنع `'never'` سوف ترتيب حذف لم قدوم فرعي agent ينبغي جواب جهاز» ربط نقاش: مراجعة دفعة وراثة قد سقوط أرض، إنتاج صحيح هو فوق وصف غير ممكن رؤية تلقي منع حالة؛ لم قدوم إذا يلزم جذب دخول فرعي agent ينبغي جواب جهاز، يجب أولا دفع قلب هذا note.

## اعتبار مرور بديل خطة

- **وراثة أب درجة مراجعة دفعة تغطية بند**(أولا قبل سلوك): غير مقبول. فقط لديه قد موضع في `'never'` أب درجة عندئذ إنتاج تحديد صفة فرعي agent؛ تفاعل صيغة أب درجة نوع خروج فرعي agent، ذلك ask يلزم ما انتظار واحد بلا شخص في نظر تلميح، يلزم ما بـ `'unavailable'` فشل إغلاق، نتيجة أخذ قرار في عند وقت تماما جيد وصل دخول أي بعض واجهة.
- **تلقي منع حالة مرئي صفة و تدريجي فرعي درجة إذن ضبط كامل**(#1723 أصل لديه تحقق استلام): تأخير بعد بينما غير مرفوض.`list_agents` تلقي منع علامة ملاحظة، مرور من تسوية إلقاء تمرير seam أب درجة إشعار، دليل شجرة شعار علامة، و subagent مخصص استخدام إذن عبر طريق ما زال هو أكثر كامل تصميم، لكن كل واحد بند كل حاجة مستقل seam عمل؛ واحد حالما فرعي agent غير ممكن قدرة دخول انتظار مراجعة دفعة تلقي منع حالة، هذه كل لم يعد هو مطلوب.
- **يأخذ فرعي agent ask توجيه إلى أب تحكم جهاز**: ما زال حسب[مراجعة دفعة seam Agent Note](2026-07-06-approval-seam.ar.md) تأخير بعد. هو حاجة أب سلسلة كل حق و إرسال بدء spawn `callId`.
- **في `ApprovalService` داخل حسب جلسة مصدر تثبيت تحديد**: غير مقبول. هذا سوف يجعل مراجعة دفعة حزمة اقتران دمج تفويض إرسال مفردات، و تكرار واحد تفويض إرسال حد قد يملك قرار؛ تفويض إرسال نوع دخول حدث لـ الذي بـ يمكن قوي صنع تنفيذ، هو لأن حالي لا وجود أي قدرة تبديل فرعي جلسة سياسة كتابة مسار (`/permission` أمر اشتراط عام Host توجيه، بينما subagent كل حق محيط شريط مقابل فرعي جلسة رفض هذا توجيه).

## عاقبة

- فرعي agent صندوق رملي وراثة حينئذ هو تفويض إرسال إذن نموذج الكل؛`DelegatedPolicyOverrides.approvalPolicy` حقل استلام ضيق لـ `'never' | undefined`(فقط في لم تركيب مراجعة دفعة قدرة وقت لـ `undefined`).
- نموذج مرئي: كل فرعي agent وقت التشغيل سياق لقطة يحمل `subagent:delegation` إعلان و ثابت مراجعة دفعة قد منع استخدام لغة جملة؛ أب درجة طلب ثابت.executor حد اختبار إثبات: أي جعل أصل جزء لديه واحد هذا سوف دفعة دقيق ينبغي جواب من، فرعي agent ترقية ما زال يتم رفض كما لا استشارة استفسار هذا ينبغي جواب من، مراجعة حساب مقابل وفق معتاد سقوط سجل.
- حد: عملية داخل مرة صفة، يمكن متابعة و workflow إرسال توليد فرعي agent كل مرور من مشترك مساعد مساعدة دالة قوي صنع تنفيذ؛`subagent-acp` فرعي agent إبقاء هذا مزود صريح آلة جهاز `permission` سياسة؛`claude-code`،`codex` و `dsh-sdk` فرعي agent تشغيل في خارجي عملية في، من كل منها تركيب قرار.
- في تثبيت تحديد قبل حفظ دائم فرعي agent بارد استعادة وقت طي إلى نشر مراجعة دفعة قيمة افتراضية؛ موضع في مسبق إصدار مرحلة مقطع، لا إضافة ترحيل.
- لقطة تجهيزة سجل هذا تثبيت تحديد: كل عملية داخل فرعي سجل كل إضافة جديدة تفويض إرسال `approval/policy` حدث،`subagent-published-run-failure` الآن سوف حفظ دائم واحد نسخة مفرد حدث فرعي سجل، بينما هذا قبل هذا فرعي agent لا إبقاء أي حفظ دائم حدث.
