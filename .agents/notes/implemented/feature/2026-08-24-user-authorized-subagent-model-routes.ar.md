# Agent Note: مستخدم تخويل subagent نموذج توجيه

Status: implemented

[English](2026-08-24-user-authorized-subagent-model-routes.md) | العربية

## Problem

تسجيل LLM مهايئ سوف جعل ذلك توجيه يمكن بلوغ، لكن لا بديل جدول تخويل Agent لـ فرعي درجة اختيار كل واحد يمكن بلوغ نموذج. إبرة مقابل فوري مهايئ سجل التسجيل مفرد واحد تفعيل انحراف جيد، سوف في آخر عدد مزود أو نموذج ظهور وقت ساكن صامت توسيع كبير نطاق. منتج حاجة واحد بند صريح كما مستقر تخويل قرار، معا تجنب تجنب يأخذ ممكن جدا كبير نموذج دليل تصيير دخول أب Agent كل مرة طلب.

## Decision

Host ذاتي لديه `subagent-model-selection` ضبط section حفظ صريح `enabled` فتح صلة و `allowedModels`، بعد من هو من دقيق `{ provider, model }` توجيه مجموعة صار عدد مجموعة. تفعيل وقت يجب حتى قليل لديه واحد بند توجيه؛ إغلاق وقت يمكن إبقاء قد اختيار توجيه، توفير بـ بعد إعادة تفعيل.Plugins ضبط بطاقة عبر `session/modelCatalog` قراءة فوري مهايئ دليل، يجعل مستخدم مؤقت تخزين فتح صلة و توجيه، مجددا في مرة حمل revision حد ضبط mutation في حفظ اثنان عدد حقل. هو لا حفظ مهايئ ذاتي لديه عرض اسم، وصف أو دفع إدارة قوي درجة بيانات وصفية. حالي دليل في ناقص قد تخزين أو مؤقت تخزين توجيه ما زال عرض لـ غير ممكن استخدام و سماح إزالة؛ بعض عدد مزود دليل فشل لن منع سد أخرى مزود، أيضا لن صاف حذف قد تخزين تخويل أو لم حفظ اختيار. اتصال إعادة وضع سوف إسقاط مسودة مسودة، لأن namespace revision فقط قدرة في نفس عدد Host عملية داخل مقارنة مقارنة.

ضبط تفعيل وقت، جديد تركيب قمة طبقة Session سوف في نموذج اختياري تعريف دخول طلب قبل، يأخذ توجيه قائمة لقطة سجل لـ `subagent/model-selection-policy`. حدث وجود حينئذ يمثل نموذج اختيار قد تفعيل؛ حدث لا حفظ عام فتح صلة. فرعي Session من في خط أب درجة وراثة نفس نسخة دقيق قائمة، استعادة Session استخدام قد سجل حدث بينما لا هو حالي ضبط. لذلك، ضبط تعديل فقط أثر بعد تركيب قمة طبقة Session، بينما لا يوجد هذا حدث قديم Session ما زال إبقاء منع استخدام، يشمل صريح لـ فارغ استعادة Session.

ثابت `list_subagent_models` schema لن قطعة رفع هذا سياسة. استدعاء وقت، مزود و نموذج قائمة هو Session توجيه قائمة و مهايئ فوري عام نشر دليل تسليم تجميع. دقيق provider/model استعلام أولا اشتراط تخويل، مجددا تحليل مهايئ ذاتي لديه نموذج بيانات وصفية و الكل قد عام نشر دفع إدارة قوي درجة. تفويض إرسال منفذ أيضا سوف مستقل رفض أي توليد فاعلية provider/model توجيه لا في Session قائمة داخل صريح مزود، نموذج أو قوي درجة اختيار، لكن بعد عندئذ من `resolveCallConfig()` تحقق مهايئ متاح صفة و قوي درجة دعم حمل. تماما لا يوجد اختيار حقل استدعاء إبقاء إعداد أو وراثة توجيه، لأن نموذج لا يوجد عمل خروج توجيه اختيار.

نموذج اختيار لم يعد لديه بلا حد ساكن حالة نمط. افتراضي إغلاق Host ضبط هو وحيد تخويل مصدر، تفعيل Session بداية نهاية يحمل دقيق سماح قائمة. رئيسي spawn أداة قراءة هذا ضبط؛ مع مرفق fork أداة ما زال لا عام توجيه اختيار، جعل وراثة محادثة بادئة متابعة رمز دمج مزود جانب KV Cache إعادة استخدام شرط.

## Alternatives considered

**في تفويض إرسال وصف في تصيير سماح توجيه.** لا اعتماد، لأن جدا كبير أو تغير قائمة سوف توسيع كبير كل مرة طلب، و جعل مقارنة مبكر نص التوجيه بادئة بطلان. حسب يحتاج اكتشاف سوف إبقاء ثابت schema بادئة مستقر، كما فقط في طلب دليل وقت سجل ذلك محتوى.

**فقط مرور ترشيح ضبط UI أو اكتشاف نتيجة.** لا اعتماد، لأن نموذج يمكن تخمين قياس توجيه، أو من مقارنة مبكر transcript في إبقاء توجيه. تخويل من بدء فرعي درجة منفذ قوي صنع تنفيذ.

**من غير فارغ `allowedModels` عدد مجموعة دفع قطع هل تفعيل.** لا اعتماد، لأن إغلاق وظيفة وقت يلزم ما يجب إسقاط ما زال لديه استخدام اختيار، يلزم ما يلزم إبقاء واحد يحتوي معنى أخذ قرار في كتابة تاريخ غير فارغ عدد مجموعة. صريح فتح صلة هو مرجعي اعتماد حسب، ضبط scope سوف في مرة من Host تحقق mutation في إيداع اثنان عدد حقل، لذلك لن حفظ دائم في بين حالة.

**حفظ كل بند توجيه دفع إدارة قوي درجة سماح قائمة.** لا اعتماد، لأن مستخدم قرار إبرة مقابل فرعي درجة نموذج، بينما قوي درجة id و توافق صفة يخص دقيق مهايئ توجيه. توجيه نيل دقيق بعد، ما زال يمكن استخدام مهايئ دعم حمل كل نوع قوي درجة.

**كل مرة اكتشاف أو تفويض إرسال استدعاء كل قراءة حالي ضبط.** لا اعتماد، لأن ضبط تحرير سوف ساكن صامت تغيير تشغيل في Session نموذج مرئي قدرة و تنفيذ إذن. حمل دائم Session لقطة سوف يجعل استعادة و فرعي درجة وراثة إبقاء تحديد.

## Consequences

- جديد مهايئ تسجيل و جديد عام نشر نموذج لن توسيع كبير مستخدم تخويل.
- مهايئ إزالة أو دليل فشل يمكن نقص قليل اكتشاف حالي صف خروج محتوى، لكن لن حذف قد تخزين توجيه قرار؛ أي جعل بناء اقتراح صفة دليل حذف بعض بند دقيق قد تخويل توجيه، فقط يلزم مهايئ قبول هو، هذا توجيه ما زال متاح.
- سماح قائمة ذاته لا إزالة استهلاك أب درجة طلب token. فقط لديه `list_subagent_models` نتيجة دخول transcript.
- سياسة حدث فقط وجود في سجل، و في Agent تركيب خلال، اثنان طقم SDK بدء حجز قراءة تشغيل قبل إلحاق. مع مرفق SDK profile لا تفعيل هذا بند Web ذاتي لديه انحراف جيد، لذلك هذا حدث لن تغيير مهمة واحد SDK مسبق مدة إشعار أو حمل دائم Session إخراج؛ ذلك حمل دائم إسقاط من حزمة درجة استعادة اختبار مسؤول، لن لـ إرسال خروج هذا حدث بينما وهمي بنية SDK تركيب.
- وحدة تغطية ثابت ضبط تحقق، استثناء حمل دائم قيمة،Session أخذ مثال و وراثة، اكتشاف تسليم تجميع، منفذ رفض،UI فوري دليل بطلان، مؤقت تخزين توجيه إبقاء، اتصال تبديل بديل بطلان، مؤقت تخزين بعد كامل عدد مجموعة كتابة، قديم قديم revision رفض، و أثر مجال تثبيت فشل بعد إعادة محاولة. تجميع Web مشهد ثابت حقيقي ضبط وثيقة و Plugins ضبط بطاقة مسار.
