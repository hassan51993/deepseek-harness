# Agent Note: نموذج اختيار subagent توجيه

Status: implemented

[English](2026-08-18-model-selected-subagent-routes.md) | العربية

## مشكلة

`dsh-tool-subagent` يمكن إعداد فرعي درجة `AgentOptions`، اثنان عدد عملية داخل مزود أيضا قد يأخذ هذه قيمة دمج إلى أب Agent LLM اختيار لـ فوق. لكن موجه إلى نموذج أداة لا يستطيع لـ بعض عدد ملائم دمج فرعي مهمة طلب مختلف مزود، نموذج أو دفع إدارة قوي درجة. لـ كل بند LLM توجيه تحميل واحد اسم مختلف تفويض إرسال أداة سوف تكرار schema، و يأخذ كل مرة استدعاء ضبط درجة اختيار تغيير صار نشر إعداد.

نموذج أيضا حاجة واحد نوع محدود طريقة قدوم اكتشاف فوري مزود و نموذج ذاتي لديه دفع إدارة قوي درجة ID. يأخذ adapter دليل تصيير إلى كل واحد نسخة تفويض إرسال وصف في، سوف يجعل فقط توفير مشاركة اعتبار كما سوف تغير دليل دخول prompt بادئة.

## قرار

فقط لديه Agent أثر مجال `modelSelectionSettings` نسخة تحليل خروج Session سياسة، كما ربط subagent مزود إعلان `SubagentCapabilities.agentOptions` وقت،`dsh-tool-subagent` عندئذ عام اختياري `provider`،`model` و `reasoning_effort` حقل. هذا سياسة استخدام[مستخدم تخويل subagent نموذج توجيه](2026-08-24-user-authorized-subagent-model-routes.ar.md) الذي يملك دقيق مستخدم تخويل؛ لا وجود بلا حد ساكن حالة نمط. منع استخدام نسخة سوف حذف و رفض موجه إلى نموذج اختيار، بينما إعداد `Config.agentOptions` ما زال هو نشر جهة كل قيمة افتراضية. إذا settings قد تفعيل نسخة نقص قليل هذا مزود قدرة، إضافة تركيب سوف فشل.

مزود و نموذج مشترك نفس مجموعة صار واحد بند توجيه، يجب واحد بدء توفير. إذا إعداد قيمة، أب درجة قيمة أو مزود يحتفظ توجيه قيمة افتراضية قدرة كاف توفير توليد فاعلية توجيه، فإن يمكن فقط توفير دفع إدارة قوي درجة. ساكن حالة `provider.agentRouteDefaults` في وجود وقت بنية صار provider/model أساس خط؛`Config.agentOptions` و نموذج معامل سوف في توجيه متبادل صلة قوي درجة صاف حذف قبل تغطية هو. لا يوجد ساكن حالة قيمة افتراضية مزود سوف استخدام أب Agent الأكثر جديد سجل طلب في توافق حقل، أول عدد طلب قبل من إنشاء خيار توفير رجوع، و إبقاء منها إعداد إخراج token حد أعلى. دفع إدارة قوي درجة ID ما زال من adapter كل. فقط لديه الذي اختيار أساس خط توجيه ثابت وقت عندئذ سوف وراثة حذف قوي درجة؛ أكثر تبديل مزود أو نموذج لكن لا يوجد إشارة تحديد قوي درجة وقت، سوف صاف حذف تحت طبقة توجيه ذاتي لديه قيمة، جعل الذي اختيار نموذج تحليل ذاتي ذات قيمة افتراضية.`AgentOptions` يأخذ نتيجة قوي درجة نقل دخول فرعي درجة حلقة، ذلك طلب header سوف سجل توليد فاعلية قيمة. يمكن متابعة وصف رمز سوف يأخذ هو و تحليل بعد مزود و نموذج واحد نفس سجل، جعل بعد لم كتابة أول عدد طلب فرعي درجة قدرة بـ نفسه اختيار بارد استعادة.

صريح أو إعداد مزود، نموذج أو قوي درجة سوف في مزود أساس خط و طلب أولوية درجة إتمام بعد، عبر `ctx.llm.resolveCallConfig()` تحليل. أداة لديه ساكن حالة توجيه قيمة افتراضية مزود سوف في طلب حذف قوي درجة وقت منع توقف وراثة أب درجة قوي درجة، من بينما إبقاء الذي اختيار نموذج قيمة افتراضية.LLM استعلام مسؤول مزود تسجيل، دقيق نموذج بيانات وصفية، دفع إدارة قوي درجة تحقق و adapter قيمة افتراضية. مختلف خطوة استعلام إتمام بعد، إنشاء فرعي درجة أو خلفية job قبل، أداة سوف مجددا مرة فحص إلغاء حالة، و تأكيد نفس عدد مزود نسخة ما زال موضع في تسجيل حالة، لذلك HMR لن يأخذ واحد مزود قيمة افتراضية و آخر عدد مزود عملية تركيب. حيث لا يوجد موجه إلى نموذج اختيار، أيضا لا يوجد إعداد توجيه حقل استدعاء سوف إبقاء أصل لديه مزود مسار، لا اشتراط اختياري LLM خدمة وجود.

تفعيل تعريف سوف تسجيل `list_subagent_models`. بلا معامل استدعاء صف خروج قد تخويل كما قد تسجيل مزود؛ توفير `provider` وقت أولا تخويل، مجددا استدعاء هذا مهايئ بناء اقتراح صفة نموذج دليل؛ معا توفير `provider` و `model` وقت سوف أولا تخويل دقيق توجيه، مجددا تحليل ذلك دفع إدارة قوي درجة و قيمة افتراضية. لأن اكتشاف أداة استخدام عام اسم، واحد أداة أثر مجال الأكثر كثير من واحد نسخة تفعيل اختيار. مع مرفق منتج تركيب في Agent أثر مجال رئيسي `subagent` نسخة فوق ضبط `modelSelectionSettings: true`، و تسجيل Host ذاتي لديه `subagent-model-selection` ضبط، منها يتضمن افتراضي إغلاق صريح `enabled` فتح صلة و `allowedModels` قائمة.Plugins ضبط صفحة سوف أصل فرعي حفظ اثنان عدد حقل. ضبط تفعيل وقت، جديد قمة طبقة Session سوف في أي نموذج طلب قبل، يأخذ توجيه سياسة لقطة سجل لـ `subagent/model-selection-policy`. فرعي Session وراثة في خط أب درجة سياسة؛ استعادة Session استخدام قد سجل حدث، بينما لا هو حالي ضبط. لذلك، ضبط تعديل فقط أثر بعد تركيب قمة طبقة Session. أي جعل نقص قليل اختياري LLM خدمة، ثابت اكتشاف تعريف ما زال إبقاء متاح؛ اكتشاف استدعاء و الذي اختيار توجيه استدعاء سوف في هذا خدمة ظهور قبل فشل. اكتشاف سوف صف خروج فوري دليل و قد سجل سياسة تسليم تجميع، منفذ سوف رفض سياسة خارج صريح توجيه.

مع مرفق `subagent_fork` نسخة لن قراءة نموذج اختيار ضبط، أي جعل عملية داخل fork مزود دعم حمل `agentOptions` أيضا هو مثل هذا.fork سوف وراثة أب درجة توليد فاعلية مزود و نموذج، جعل نسخ محادثة بادئة ما زال يمكن توفير مزود جانب KV Cache إعادة استخدام. أكثر تعديل مهمة واحد توجيه مكون كل سوف اشتراط جديد توجيه إعادة مسبق ملء ملء وراثة تاريخ، بينما هذا بند إعادة حساب صار هذا ممكن تجاوز مرور تفويض إرسال مهمة ذاته. هذا حد و اكتشاف أداة عام اسم غير متصل: قسم مغادرة اكتشاف أداة يحتفظ حق يمكن يجعل إعداد توليد فاعلية، لكن لا يمكن إبقاء إعادة استخدام. فقط لديه في توجيه تغير ما زال قدرة إبقاء بادئة إعادة استخدام، أو استدعاء جهة يمكن صريح حد و قبول إعادة حساب صار هذا وقت، عندئذ إعادة اعتبار fork توجيه اختيار.

تفويض إرسال تعريف لن مع adapter تسجيل و دليل تغير بينما تغيير، لذلك فوري توسيع اندفاع حيث لن توسيع كبير كل أب درجة طلب، أيضا لن جعل ذاكرة مؤقتة بادئة بطلان. فقط لديه استدعاء اكتشاف أداة وقت، دليل نتيجة عندئذ دخول transcript. ذاتي تعريف سياق وراثة نسخة إذا تفعيل اختيار، ذلك وصف سوف تحذير إبلاغ، أكثر تعديل مزود أو نموذج ممكن منع توقف مزود إعادة استخدام وراثة محادثة بادئة.

`SubagentCapabilities.agentOptions` ما زال هو نقل واقع. إذا طلب يحمل هذه خيار، بينما مزود إعلان لـ `false`، خدمة سوف في استدعاء مزود قبل رفض. اثنان عدد عملية داخل مزود و DSH SDK نقل إعلان لـ `true`؛DSH SDK سوف يأخذ provider/model قيمة افتراضية بصفة قسم مغادرة كما غير ممكن تغيير بيانات عام إعطاء Consumer مسبق فحص، بينما `start()` سوف لـ مباشر استدعاء جهة و فرعي وقت التشغيل ابتدائي تحويل مستقل تطبيق نفس نسخة Config قيمة افتراضية و maxTokens.ACP،Codex و Claude Code إعلان لـ `false`. أداة إعداد توفير `agentOptions`، ساكن حالة تفعيل نموذج اختيار أو يجعل هو تلقي settings تحكم وقت، إذا ربط مزود نقص قليل هذا قدرة، أيضا سوف فشل.

## اعتبار مرور بديل خطة

**اشتراط ساكن حالة تفعيل إعداد نشر توجيه سماح قائمة.** لا اعتماد، لأن هو سوف تكرار فوري LLM سجل التسجيل، و اشتراط ذاتي تعريف تركيب أولا إعداد عندئذ قدرة استخدام قد تسجيل توجيه. مع مرفق مستخدم ذاتي لديه انحراف جيد يخص آخر بند تخويل قرار، من[مستخدم تخويل subagent نموذج توجيه](2026-08-24-user-authorized-subagent-model-routes.ar.md) سجل.

**في كل واحد نسخة تفويض إرسال وصف في تصيير فوري adapter دليل.** لا اعتماد، لأن واحد مزود ممكن عام نشر عدد مئة عدد نموذج، من بينما توسيع كبير كل مرة طلب، بينما كما دليل تغير سوف تعديل كتابة ذاكرة مؤقتة بادئة في مبكر مدة تعريف. حسب يحتاج دليل يجعل متغير بيانات إبقاء في ثابت schema خارج.

**يأخذ عام نشر دليل عند عمل سماح قائمة.** لا اعتماد، لأن adapter دليل فقط توفير بناء اقتراح، لديه بعض مزود قبول مهمة معنى دقيق نموذج ID. دقيق تحليل ما زال هو مرجعي.

**في subagent خدمة في زيادة اكتشاف طريقة.** لا اعتماد، لأن مزود/نموذج/قوي درجة بيانات وصفية قد يخص `ctx.llm`؛ جديد أداة فقط هو هذا قائم قدرة موجه إلى نموذج Consumer.

**يأخذ اكتشاف أداة بصفة مستقل تحميل إضافة مدخل توجيه خروج.** لا اعتماد، لأن مع مرفق تركيب مجموع هو يأخذ اكتشاف أداة و رئيسي تفويض إرسال أداة إعداد طقم تحميل. في هذا نسخة فوق صريح إشارة تحديد يحتفظ حق، يمكن تجنب تجنب تكرار عام أداة اسم، بلا حاجة زيادة Cordis بند إعداد أو مستقل دورة الحياة.

**قسم آخر إعداد اكتشاف و موجه إلى نموذج اختيار.** لا اعتماد، لأن اكتشاف وظيفة لأجل نحو قدرة كاف اختيار هذه قيمة نفس عدد نموذج توفير صالح توجيه و قوي درجة ID. واحد فتح صلة يمكن تجنب تجنب أداة schema عام اختيار لكن لا يوجد مقابل اكتشاف مسار، أو عام اكتشاف لكن لا يوجد ملائم استخدام تفويض إرسال توجيه.

**في مع مرفق fork أداة فوق تفعيل موجه إلى نموذج توجيه اختيار.** لا مع منتج توفير، لأن أكثر تعديل مزود أو نموذج سوف فقد ذهاب وراثة بادئة KV Cache إعادة استخدام، إعادة مسبق ملء ملء بادئة صار هذا ممكن عال في تفويض إرسال عمل ذاته. فقط لديه في توجيه تغير ما زال قدرة إبقاء إعادة استخدام، أو واجهة قدرة يأخذ هذا بند صار هذا صريح تحويل و حد إقامة وقت، عندئذ إعادة اعتبار هذا خيار.

**استخدام عام دفع إدارة قوي درجة قطعة رفع.** لا اعتماد، لأن دفع إدارة قوي درجة ID و قيمة افتراضية يخص دقيق مزود/نموذج توجيه.LLM adapter سوف مباشر تحقق، بلا حاجة في قلب تحويل قلب ترجمة أو قطع قطع.

**سماح بعيد مسار مزود تجاهل اختصار هذه حقل.** لا اعتماد، لأن طلب سوف صوت تسمية حدوث فعلي فوق لا يوجد حدوث توجيه اختيار. قدرة علامة سوف يجعل لا دعم حمل مسار في إنشاء فرعي درجة قبل فشل.

## نتيجة

- settings قد تفعيل Session فقط قدرة اختيار ذلك سجل دقيق فرعي درجة LLM توجيه؛ منع استخدام Session سوف حذف و رفض موجه إلى نموذج توجيه حقل.
- رئيسي تفويض إرسال أداة نسخة افتراضي إغلاق اختيار، لـ جديد Session توفير Plugins صفحة دقيق توجيه opt-in، و كما فقط في حمل دائم سياسة وجود Session في تسجيل `list_subagent_models`؛ اكتشاف و صريح اختيار كل تلقي هذا سياسة حد.
- مع مرفق fork أداة سوف وراثة أب درجة مزود و نموذج، و حذف موجه إلى نموذج توجيه حقل، جعل وراثة محادثة بادئة ما زال يمكن توفير KV Cache إعادة استخدام.
- حذف اختيار وقت إبقاء إعداد قيمة افتراضية، و استخدام ساكن حالة مزود توجيه قيمة افتراضية أو قدوم ذاتي أب درجة الأكثر جديد سجل طلب توافق وراثة؛ تغيير توجيه لكن لا صريح إشارة تحديد قوي درجة وقت، استخدام الذي اختيار نموذج قيمة افتراضية.
- adapter دليل و توسيع اندفاع تغير لن تغيير تفويض إرسال تعريف و ذلك prompt ذاكرة مؤقتة بادئة.
- DSH SDK فرعي درجة قبول إعداد و نموذج اختيار Agent توجيه؛ACP،Codex و Claude Code في تنفيذ و إعلان هذا قدرة قبل ما زال سوف رفض.
- اختبار وحدة تغطية افتراضي إغلاق Host انحراف جيد، جديد Session قراءة، فرعي درجة وراثة، استعادة قرار، اختيار تفعيل وقت schema و تنفيذ قوي صنع، دمج أولوية درجة، توجيه متبادل صلة قوي درجة وراثة، مسبق فحص إلغاء، فوري اكتشاف، تشخيص، تعريف مستقر صفة، قدرة رفض و اختياري خدمة سلوك. مع مرفق headless لقطة ثابت من أب درجة قد سجل اختيار وراثة سلوك؛ مع مرفق عرض مثال تغطية تجميع بعد بلا مفتاح، نموذج مرئي schema،SDK Loader و لقطة دليل ثابت كامل توجيه مرور مرور مستقل فرعي وقت التشغيل سلسلة مسار.
