# Agent Note: مشترك ملف نوع رسم علامة

Status: implemented

[English](2026-09-08-shared-file-type-icons.md) | العربية

## مشكلة

عميل وظيفة إضافة فقط قدرة عبر `@deepseek-ai/dsh-client-ui-primitives` مشترك React مكون، لكن ملف بطاقة لا يوجد مشترك ملف نوع عرض.`LinkIcon` يملك وحيد واحد نسخة توسيع اسم جدول، و متعمد يأخذ مسار طي لـ ستة نوع رابط صنف آخر؛ مرفق عنصر بطاقة، قد إرسال رسالة مرفق عنصر، ترتيب طابور ملف و مساحة العمل ملف سطر فإن موحد واحد استخدام واحد عام وثيقة رسم شكل. منها اثنان عدد مستهلك أيضا كل منها حمل حال واحد نسخة توسيع اسم عرض مساعد مساعدة دالة. في أخرى موضع زيادة دقيق دقيق ملف رسم علامة، حاجة مجددا نسخ واحد نسخة توسيع اسم جدول أو يجعل وظيفة إضافة بين إنتاج وقت التشغيل import.

## قرار

`ui-primitives` موحد واحد يملك واحد طقم Cordis-free ملف تصنيف و تصيير API.`fileExtension(path)` مقابل اثنان نوع مسار قسم فصل رمز اعتماد مشترك basename و نهائي نقطة رقم دلالة.`classifyFileType(path)` لا منطقة قسم كبير صغير كتابة، و إرجاع إغلاق دمج `FileType` ربط دمج: نقل موحد `code`،`excel`،`folder`،`html`،`image`،`markdown`،`other`،`pdf`،`ppt`،`video`،`word` صنف آخر، و من `CodeFileIcon` تصيير دقيق قسم `CodeFileType` تجميع دمج. تحليل حسب كامل ملف اسم، ملف اسم بادئة، ملف اسم بعد لاحقة، اختياري مشروع سياق، توسيع اسم ترتيب تنفيذ. مسار تصنيف جهاز إرجاع `folder` خارج الكل عضو؛ استدعاء جهة تأكيد بند هو دليل وقت، عبر `FileTypeIcon` صريح `kind` تغطية إشارة تحديد دليل. لم معرفة توسيع اسم، بلا توسيع اسم و نهاية ذيل نقطة رقم رجوع إلى `other`، لكن مشترك جدول تعرف آخر `Dockerfile`،`Makefile`،`package.json`،`.gitignore`،`README`،`CHANGELOG` انتظار أداة اسم ملف.

`FileTypeIcon` قبول مسار، مشترك `IconProps`، صريح `kind`و اختياري مشروع ملف لقطة. نقل موحد ملف نوع يأخذ الذي توفير 28px وثيقة و ملف مشبك جولة محيط تصيير لـ inline SVG.Excel،Markdown،PDF،PPT،Word قبل مشهد علامة محيط التفاف ذاته نظر شعور في قلب تقليص وضع حتى 122%، ذلك بقية حمل علامة نقل موحد رسم شكل استخدام 112%؛ ملف قاع لوح و طي زاوية إبقاء مصدر رسم بضعة أي، عام ملف لا سند فارغ زيادة في قلب علامة. قاع لوح استخدام فعلي لون تصنيف لون لون، قبل مشهد علامة و عادي طي زاوية استخدام أبيض لون، عام ملف استخدام مقارنة عميق رمادي لون طي زاوية.CSS عبر ساكن حالة تصميم token قسم إعداد الذي توفير تصنيف ضبط لون لوح:code/HTML/Markdown استخدام DeepSeek أزرق،Word استخدام مقارنة ضحل DeepSeek أزرق،Excel استخدام أخضر لون،folder/PPT استخدام اثنان ملف كهرمان عنبر لون،PDF استخدام أحمر لون، لم معرفة ملف استخدام في صفة رمادي.image و video عبر مكون محلي متغير مشترك استخدام الذي توفير بنفسجي لون، لأن تصميم منصة لا يوجد مطابقة بنفسجي لون token. استدعاء جهة يمكن عبر `--dsh-file-type-icon-color` تغطية نقل موحد قاع لوح لون لون.

قد تعرف آخر شفرة و ملف إعداد يأخذ مقابل 20px جهة شكل رسم مسودة تقليص وضع إلى طلب رسم علامة مقياس قياس. داخل تضمين ساكن حالة جدول فقط يتضمن قائم 48 عدد `CodeFileType` بند؛ مورد حزمة في مقدار خارج رسم مسودة لن إضافة جديدة صنف آخر، متبادل مجاور manifest سجل مسؤول تصميم ملكية جهة و مصدر ملخص. اختبار سوف رفض هذا جدول في نص برمجي، حدث خاصية، خارجي مرجع و تكرار id.`CodeFileIcon` في إدراج دخول قبل لـ محلي SVG id إضافة فوق مكون نسخة بادئة، جعل تكرار تدريجي تغيير و قطع قص مسار متبادل لا جاف إزعاج. هذه تقنية فن علامة إبقاء ذاته داخل تضمين كثير لون ملء ملء، هو عادي current-color رسم علامة قاعدة واضح مثال خارج. خريطة يجعل React أولوية في TypeScript/JavaScript،Angular ملف اسم بعد لاحقة أولوية في أساس أساس توسيع اسم، و حسب ملف اسم تعرف آخر Docker/Node/Git/Make/CMake؛ فقط لديه اختياري مشروع لقطة يتضمن محتوى حمل `flutter:` `pubspec.yaml` وقت عندئذ اختيار Flutter.Markdown و SVG ما زال من نقل موحد Markdown و صورة صنف آخر يملك.CSV و TSV في ملف بطاقة، ملف سطر و معاينة عنوان في استخدام code رسم علامة، ذلك يمكن نقر رابط أيضا استخدام code.`.env` و بـ `.env` ربط ذيل ملف اسم متساو استخدام بيئة إعداد رسم علامة. كل نقل موحد و تقنية فن SVG كل هو `aria-hidden` ، يملك ملف هوية بطاقة، سطر أو حسب زر توفير بلا عائق عائق اسم.

`LinkIcon` تفويض حمل `classifyFileType` فعل توسيع اسم تصنيف، مجددا يأخذ دقيق دقيق نتيجة طي دخول أصل لديه رابط مفردات:code و HTML استخدام `code`، صورة استخدام `image`،PDF/Word/Excel/PPT استخدام `document`،Markdown،video و لم معرفة ملف استخدام `other`. بلا توسيع اسم ملف في رابط لغة بيئة في ما زال هو `other`، لذلك[يمكن نقر رابط قرار](2026-09-04-web-clickable-link-styles.ar.md) تعريف 14px خارج مراقبة ثابت.

مرفق عنصر فوق نقل بطاقة، قد إرسال رسالة ملف بطاقة، ترتيب طابور ملف سطر و مساحة العمل ملف سطر تصيير `FileTypeIcon`.Files وسم صفحة عنوان استخدام صريح `folder` صنف آخر، مقياس قياس لـ 16px. صريح تسليم بطاقة استخدام 20px `FileTypeIcon`، و عبر `fileExtension` توفير افتراضي بيانات وصفية. اثنان موضع بيانات وصفية سطر استخدام `fileExtension`، لم يعد إبقاء محلي محلل؛`.env` هذا مثال قبل توجيه نقطة basename سوف عرض `ENV`، بلا بعد لاحقة أو نهاية ذيل نقطة رقم فإن لا عرض توسيع اسم label. صورة محتوى متابعة تصيير لـ معاينة بينما لا هو ملف نوع رسم شكل، ناتج ملف رابط و Markdown ملف رفع و متابعة استخدام `LinkIcon`، لأن هو جمع يخص رابط جدول وجه.

## تجهيز اختيار خطة

**كل ملف جدول وجه كل استخدام `LinkIcon`.** مرفوض. هو ستة نوع صنف آخر و 14px outline رسم شكل لأجل في نص حرف مقياس قياس تحت جدول بلوغ رابط هدف؛28px ملف بطاقة لديه فضاء جدول بلوغ الذي توفير HTML،Markdown،PDF،Word،Excel،PPT و video هوية.

**في `LinkIcon` جانب إبقاء ثاني نسخة توسيع اسم جدول.** مرفوض. مهمة واحد قائمة زيادة طويل بعد، نفس مسار ممكن عائم نقل إلى مختلف صنف آخر. واحد نسخة دقيق دقيق جدول إضافة واحد صريح دقيق دقيق إلى رابط ملائم إعداد، قدرة معا حفظ إقامة اثنان صنف مستهلك دلالة.

**يأخذ الذي توفير نقل موحد ملف لون لون مباشر كتابة كل واحد بند SVG path.** مرفوض. نقل موحد SVG بضعة أي إبقاء يمكن إعادة استخدام، و التزام حراسة رسم علامة تجميع `currentColor` قاعدة؛ مكون مثال صيغة جدول يملك افتراضي تصنيف ضبط لون لوح، تصيير نقطة فقط يحتاج واحد CSS متغير يكفي تغطية لون لون، لا حاجة إعادة كتابة path ملء ملء. تقنية فن رسم مسودة هو مثال خارج، لأن ذلك داخل تضمين كثير لون علامة لأجل تعرف آخر لغة أو أداة، بينما لا هو تركيب زينة عام ملف جولة محيط.

**لـ مقابل تسمية زيادة archive،audio و data صنف آخر.** مرفوض. توفير رسم مسودة و حالي مستهلك كل لا حاجة هذه رسم شكل. إضافة جديدة `FileType` عضو يجب لديه قد إصدار تصيير نقطة، و في 28px slot في ما زال يمكن تمييز إقرار رسم مسودة.

## اختبار

`ui-primitives` اختبار تغطية لا منطقة قسم كبير صغير كتابة بعد لاحقة، اثنان نوع مسار قسم فصل رمز، قبل توجيه نقطة ملف، بلا بعد لاحقة و نهاية ذيل نقطة رقم، معتاد رؤية أداة اسم ملف، لم معرفة رجوع، الكل دقيق قسم شفرة خريطة، قاعدة أولوية درجة،Flutter سياق، دقيق 48 مفتاح رسم مسودة تجميع، يتم رفض مورد حزمة مقدار خارج صنف آخر، ساكن حالة markup أمان صفة، نسخة أمان SVG id و مرجع،`aria-hidden`، مقياس قياس/class تحويل إرسال، مختلف رسم مسودة،112% و 122% قبل مشهد علامة تغيير تبديل، و لا يحتوي SVG حرف وجه لون لون نقل موحد فعلي لون قاع لوح/مقابل مقارنة علامة طبقة. مثال صيغة جدول اختبار تثبيت إقامة كل واحد بند نقل موحد صنف آخر إلى لون لون خريطة، استدعاء جهة تغطية متغير و محلي بنفسجي لون قيمة. قائم `LinkIcon` تصنيف جدول تثبيت إقامة هو خشن حبة درجة إخراج، يشمل `Makefile` ما زال لـ `other`. مرفق عنصر، حديث يوم، طابور صف و الشريط الجانبي مكون اختبار تغطية ترحيل بعد تصيير مسار؛ من في رسم شكل ما زال هو تركيب زينة صفة، ذلك بلا عائق عائق إخراج ثابت.

## عاقبة

- عميل حزمة استخدام واحد ملف اسم محلل و واحد نسخة دقيق دقيق ملف نوع جدول، لم يعد import أو إعادة تنفيذ وظيفة حزمة محلي منطق.
- جديد بعد لاحقة فقط في قد لديه رسم شكل قدرة دقيق تأكيد جدول بلوغ هو وقت إضافة دخول دقيق دقيق جدول. إذا هو رابط صنف آخر و حالي ملائم إعداد مختلف، هذا مرة تعديل أيضا يجب قرار هل تغيير 14px رابط خارج مراقبة.
- شفرة و إعداد رسم مسودة إبقاء داخل تضمين ضبط لون لوح، لا قبول نقل موحد رسم شكل `--dsh-file-type-icon-color` تغطية.
- ثابت 48 بند رسم مسودة جدول لـ مشترك متصفح bundle زيادة نحو 35 kB لم ضغط جسم تراكم و 17 kB gzip جسم تراكم؛ إضافة جديدة صنف آخر يجب إثبات هذا نسخة ساكن حالة أساس خط صار هذا هو لا بد يلزم.
- primitive لا يملك نص سجل، لكن يملك افتراضي ملف نوع ضبط لون لوح. مستهلك متابعة يملك بلا عائق عائق label و دورة محيط نص حرف، و يمكن عبر `--dsh-file-type-icon-color` استبدال تصنيف لون لون.
- دقيق دقيق صنف آخر اسم وصف عرض معنى رسم، لا هو MIME تحقق. بعد لاحقة فقط هو عرض تلميح، لا يستطيع إثبات ملف محتوى أو يمكن معلومة درجة.
