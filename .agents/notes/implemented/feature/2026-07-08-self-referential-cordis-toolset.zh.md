# Agent Note:Cordis وقت التشغيل فحص و runner عزل

Status: implemented

[English](2026-07-08-self-referential-cordis-toolset.md) | العربية

## Problem

وقت التشغيل API اكتشاف يجب وصف إضافة فعلي قدرة استدعاء API. عملية داخل توليد تعريف أيضا حاجة تسجيل تحقق و كامل effect تحرير؛ فقط عزل JavaScript عام متغير و لا يستطيع حد حقن خدمة إذن.

## Decision

`cordis_inspect_list` و `cordis_inspect_query` توفير فقط قراءة وقت التشغيل اكتشاف. توليد دليل إبقاء شفرة المصدر في إعلان و JSDoc، و حسب تخزين نشط provider غربلة اختيار. دليل توليد جهاز رفض مرور مدة ناتج؛ دقيق استعلام تجنب تجنب كل مرة طلب كل تحمل تحمل كامل API إعلان token صار هذا.

Host و Client runner إبقاء برنامج جانب دورة الحياة و متصفح إزالة استهلاك من.Host تعريف في جديد vm realm في طلب قيمة، و استقبال context façade: خدمة وصول حاجة إعلان حقن، إطار هيكل داخلي بنية غير ممكن رؤية، تسجيل عودة تعريف fiber كل. أداة إخراج أولا عودة إلى Host realm إجراء عودة واحد تحويل، مجددا قبول تحقق. تحرير سوف انتظار fiber كل effect.vm منع توقف معنى خارج تلوث صبغ عام متغير؛ حقن نظام الملفات،shell و شبكة شبكة خدمة ما زال لديه حقيقي إذن، لذلك هو لا هو أمان حد.

تعريف فقط وجود في عملية في. إعادة بدء و جلسة استعادة لن من تاريخ استدعاء إعادة بناء هو جمع.[Creator حفظ دائم إضافة قرار](../architecture/2026-09-16-creator-persistent-plugin-management.zh.md) مسؤول agent تثبيت، مراجعة دفعة و profile حفظ دائم. داخل وضع نموذج أداة لا إنشاء أو تعديل runner تعريف.

## Alternatives considered

**يد كتابة API جدول.** رفض، لأن هو سوف مستقل في خدمة إعلان عائم نقل؛ توليد دليل و جديد طازج درجة فحص مشترك نفس شفرة المصدر.

**سوف vm نظر لـ أمان صندوق رملي.** رفض، لأن façade كشف خدمة يمكن وصول Host حقيقي مورد. تلقي حد عام متغير تعديل حسن دورة الحياة صحيح تأكيد صفة، لا تنفيذ إذن تحكم.

**من جلسة سجل إعادة بناء تعريف.** رفض، لأن إعادة وضع شفرة المصدر سوف تنفيذ تاريخ فرعي أثر. تاريخ بطاقة عرض حفظ دائم شفرة المصدر و نتيجة، لا استعادة تشغيل في تعريف.

## Consequences

فحص قدرة لا اعتماد Creator أو Plugin Manager.Runner دورة الحياة اختبار تغطية تلقي حفظ حماية تسجيل، بدء فشل تنظيف و انتظار تحرير. قائم متصفح إزالة استهلاك من إبقاء دورة الحياة API؛ إزالة ذلك كتابة سجل التسجيل و تنشيط آلية، حاجة تنسيق ضبط استبدال هذه إزالة استهلاك من، لا يستطيع حذف تاريخ تصيير أو زائف تحديد جلسة بيانات سوف إعادة بناء تشغيل حالة.
