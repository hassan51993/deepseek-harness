# Agent Note: Web subagent دليل و مستخدم متابعة تفاعل

Status: implemented

[English](2026-07-27-web-subagent-conversations.md) | العربية

## مشكلة

من جلسة دعم دعم subagent أداة لديه حفظ دائم هوية، حفظ دائم transcript(نص سجل) و مباشر child دليل، لكن عادي جلسة جدول نظام لا يمكن سوف هو جمع و fork منطقة قسم فتح، أيضا لا يمكن إثبات ذلك وصف رمز mode و متابعة تنفيذ تخويل. لا فإن، ربط إلى agent(ذكي جسم) عام Host عملية ممكن في ذلك مباشر parent متابعة تنفيذ owner خارج استعادة أو قيادة child.

متصفح يجب التزام حراسة[يمكن متابعة subagent اتفاق](../../implemented/feature/2026-07-28-continuable-subagent-conversations.ar.md): واحد يمكن متابعة child في عملية داخل الأكثر كثير فقط قدرة لديه واحد بند Activation، فقط قدرة عبر تأكيد قطع تخزين نشط مباشر parent قبول لاحق عمل، و سوف agent inbox استخدام عمل وحيد FIFO. فحص نظر تاريخ لا نيل إنشاء Activation.inbox رسالة واحد مرور قبول،HTTP استدعاء جهة حيث لا يملك ذلك تنفيذ مرور مسار، أيضا لن نيل نيل إلغاء جملة مقبض.

UI أيضا يجب إبقاء[حفظ دائم دليل](../../archived/feature/2026-07-22-durable-subagent-catalog-and-list-agents.md) عضو،mode و diagnostic. مشترك خدمة تقرير إبلاغ اعتماد فوري أولوية قاعدة لغة مادة نشط حركة حالة، بينما Web إسقاط سوف سوف ذلك استبدال لـ تأكيد قطع child Agent driver `running` أو `inactive` حالة. هذا اثنان نوع نشط حركة حالة كل لا هو حفظ دائم نتيجة، أيضا لا تحمل وعد متابعة تنفيذ سوف نجاح.

## قرار

Web منتج عبر صفحة رأس حالي title جدول نظام منطقة مجال عام اختيار في جلسة في من جلسة دعم دعم مباشر subagent. مستخدم يمكن كسول تحميل توسيع بعد بديل دليل، و في قائم محادثة منطقة مجال في فتح مهمة واحد mode.one-shot child دائم دائم فقط قراءة. يمكن متابعة child فقط لديه في ذلك تأكيد قطع مباشر parent agent تخزين نشط وقت عندئذ قبول مستخدم لاحق رسالة؛ لا فإن، ذلك حفظ دائم transcript ما زال يمكن قراءة، و مرفق حمل استعادة شرح.

نفس عدد صفحة رأس سطر أيضا يمكن يأخذ child بصفة `dsh-resource://chat/session/<childSessionId>?parent=<parentSessionId>&mode=<mode>` في يمين جانب Sidebar فتح. فتح وقت أولوية استخدام مستقل قسم شريط؛ لا يمكن قسم شريط وقت رجوع إلى حالي قسم شريط.Sidebar tab استخدام مشترك Conversation Component Factory تصيير و حذف عرض درجة تحكم، لذلك رئيسي محادثة و تضمين دخول صيغة محادثة مشترك استخدام واحد طقم تجميع، بينما لا مشترك تخطيط واجهة.

كل فتح child كل يحمل دليل إرسال توليد عنوان `{ parentSessionId, childSessionId, mode }`. اختيار مخصص استخدام تاريخ و نص التوجيه نقل هو يتضمن mode عنوان، بينما لا هو جدول نظام أو خشن حبة درجة origin علامة. تاريخ عملية سوف من حفظ دائم تخزين قراءة جلسة، بينما لا إطلاق تنشيط. يمكن متابعة نص التوجيه عبر `subagent.prompt` يحمل Queue أو Steer إلقاء تمرير، و في inbox قبول رسالة وقت بـ `{ messageId }` نجاح إرجاع؛ هو لن عام Activation، انتظار إتمام أو إرجاع نتيجة. متبادل مجاور Agent نموذج رسالة استخدام مفرد وحيد يملك ثابت Steer عملية.

عام Host مجال التزام حراسة نفس كل حق حد.`session.history` و `session.fork` مصدر طرف سوف قراءة قد مرفق إضافة Session أو فحص حفظ دائم تخزين، بينما لا نيل أخذ Agent؛history من الذي فحص تأكيد قطع بادئة عودة و بارد حالة إسقاط قيمة،fork فإن إصدار واحد عادي مستقل جلسة. ربط إلى Agent عام جلسة، أمر و هدف توجيه سوف مقابل من جلسة دعم دعم subagent إرجاع `agent-busy`؛ صريح id `session.create` وصل قبول و فقط إبرة مقابل قد مرفق إضافة جلسة طابور صف تحكم عنصر أيضا لكن. رفض تصنيف جهاز قبول خشن حبة درجة `origin` علامة، جلسة ذاته بعد لاحقة في `subagent/descriptor`، أو parent مقابل ذلك تأكيد قطع تخزين نشط وقت التشغيل كل حق؛ هذه إشارة فقط سوف منع توقف عام مسار أخذ نيل كل حق، أبدا يحل محل دليل mode أو مباشر parent تخويل.

إيقاف واحد قد بحث عنوان child أبدا رجوع إلى `session.cancel`. متصفح prompt إلقاء تمرير فقط مسؤول رسالة يتم inbox قبول قبل دقيق دخول، لا منح إعطاء إلغاء جملة مقبض؛ صحيح في تشغيل يمكن متابعة child عبر مخصص استخدام `subagent.interrupt` توجيه إيقاف، التزام دوران[حالي جولة في قطع اتفاق](2026-08-06-continuable-subagent-interrupt.ar.md) ، هذا اتفاق سوف توقف وضع و إبقاء انتظار معالجة عمل، بينما لا هو سوف ذلك إسقاط.one-shot child في Web طرف ما زال غير ممكن إلغاء.

هذا قرار شمول غطاء Web طرف اكتشاف،transcript فحص نظر و مرور parent تخويل مستخدم متابعة تفاعل. هو لن يجعل subagent يصبح مستخدم مستقل كل كائن؛ هذا صنف منتج ما زال يخص[تفاعل صيغة side session](../../proposed/feature/2026-07-08-interactive-side-sessions.ar.md).

## منتج اتفاق

فقط لديه عند كامل مباشر دليل فارغ استجابة و جلسة ملخص إسقاط متبادل رمز، اثنان من متساو جدول واضح لا يوجد معروف subagent بعد بديل وقت، عندئذ لا عرض بعد بديل عدد كمية تحكم عنصر. عادي جلسة سوف استخدام مائل عمود قسم فصل حالي title و هذا عدد كمية تحكم عنصر. كل واحد درجة subagent وجه حزمة فتات كل سوف ضيق تجميع 12px title و ثابت عرض مزدوج نحو سهم رأس تركيب صار واحد تحكم عنصر: حالي وجه حزمة فتات استخدام رئيسي وسم لون لون و 500 حرف إعادة، أصل أولا فإن استخدام ثلاثة درجة وسم لون لون و 400 حرف إعادة. معلق توقف تركيب تحكم عنصر 150ms بعد سوف فتح ذلك مباشر parent دليل؛ طفو طبقة قائمة مفرد أداة لديه قصير مؤقت عبر تجاوز عرض حد وقت،ArrowDown إبقاء لـ مفتاح قرص مدخل. نقر أصل أولا سوف إلغاء انتظار إطلاق معلق توقف، إغلاق قد فتح دليل، و كما فقط نحو فوق تنقل. كل مباشر parent دليل كل يمكن تبديل sibling، و سوف سليم سليم و diagnostic subagent مرشح كل سوف يحمل هذا علامة، بينما عادي fork لن. هذا مسبق فحص لا قراءة أي بعد بديل حدث سجل، توسيع بعد ما زال بـ وصف رمز دعم دعم دليل لـ مرجعي اعتماد حسب. عند ملخص في هذا دليل بعد لا وجود وقت أو في مرة قديم قديم فارغ استجابة بعد تأكيد قد لديه بعد بديل وقت، هذا عملية سوف إبقاء مرئي، و كما في فتح هو بـ تحديث جديد دليل قبل فقط عرض منع استخدام تحميل سطر؛ فقط من ملخص دعم دعم سطر أبدا سوف توفير تنقل قدرة.UI سوف في تفاعل قبل حينئذ حذف معروف ورقة فرعي عقدة توسيع تحكم عنصر؛ هذا تلميح لا تحمل وعد child سوف واحد مباشر هو ورقة فرعي. قد توسيع مباشر دليل تحميل خلال، معروف جدول إلى ذلك جلسة id. ضرر تالف، لا تلقي دعم حمل أو غير ممكن استخدام مرشح ما زال بـ منع استخدام diagnostic سطر عرض.

`running` يمثل في Host أخذ مثال حد، تأكيد قطع child Agent driver صحيح في معالجة عمل؛`inactive` يمثل هذا driver فارغ خامل أو لا وجود.UI لن يأخذ مهمة واحد قيمة حل تفسير لـ نجاح، فشل، إلغاء، إتمام حالة أو يمكن استعادة صفة.`subagent.list` توفير حالي driver حالة أساس خط،`host/session-status` سوف حينئذ أرض تحديث معروف نشط حركة حالة، طلب داخل إعادة تشغيل سوف منع توقف أكثر مبكر إرسال بدء لكن بعد لم إتمام قائمة استجابة تغطية مقارنة جديد حالة تحويل،`host/session-removed` فإن سوف جعل معروف سطر استعادة لـ `inactive`؛ إعادة وصل وقت سوف قراءة جديد أساس خط. مباشر subagent `host/session-added` لقطة سوف قيام أي يأخذ أي قد تحميل parent سطر قلب تحويل لـ `hasChildren: true`، و جعل هذا بند صحيح نحو تلميح لا يتم أكثر مبكر إرسال بدء لكن بعد لم إتمام دليل استجابة تغطية؛ تلقي أثر فرع فتح خلال، عضو،label،mode،diagnostic و مرجعي لقطة ما زال حاجة عبر ذهاب اهتزاز حركة `subagent.list` تحديث جديد قدوم تحديث. رسالة إلقاء تمرير وقت ما زال بـ نص التوجيه استجابة لـ مرجعي اعتماد حسب.

سليم سليم سطر سوف إعادة استخدام قائمة مرآة مثل في إبقاء معيار جلسة إسقاط.token استخدام كمية عدد قيمة سوف تجميع مجموع حفظ دائم سجل في أربعة عدد متبادل لا إعادة تراكم `tokenUsage` دلو.`subagentTiming` سوف في كل وصف رمز موضع إعادة وضع، جعل وراثة fork نوع فرعي لن حساب دخول child مجموع كمية؛ هو سوف تراكم إضافة قد إتمام `turn/start` → `turn/end` وقت مقطع، و يحمل لم انتهاء جولة نفس قطع وجه `active.since` و `active.through` حد. هذا جولة إبقاء لم انتهاء خلال، قائم جلسة حدث سوف دفع دخول `active.through`؛ قائمة مفرد لن زيادة مفرد وحيد حساب وقت جهاز أو سجل قراءة، كما فقط في لديه معروف بعد بديل موضع في تشغيل حالة وقت عندئذ دفع دخول ذلك محلي وقت ساعة. لا كاف واحد يوم وقت، قائمة مفرد سوف بـ كامل ثانية صيغة تحويل وقت؛ بلوغ إلى واحد يوم بعد نظر شعور قيمة الأكثر كثير إبقاء اثنان عدد متبادل مجاور مفرد موضع، منها شهر نسخة حسب قريب يشبه 30 يوم حساب حساب، سنة نسخة حسب قريب يشبه 365 يوم حساب حساب، بينما معلق توقف معلومة و بلا عائق عائق اسم سوف إبقاء دقيق يوم/صغير وقت/قسم ساعة/ثانية استهلاك وقت. مقابل inactive سطر، قائمة مفرد بـ `active.through` لـ يتم في قطع لم انتهاء جولة فوق حد، لذلك قديم قديم إسقاط أبدا سوف استعارة استخدام تحديث جلسة بيانات وصفية، كما إعادة فتح قائمة مفرد أبدا سوف يجعل قد إتمام عمل إعادة حساب وقت. هذا اثنان بند إشارة علامة كل لا كامن يحتوي حفظ دائم نتيجة دلالة.

اختيار واحد سطر بعد، نظام سوف أولا سجل ذلك تأكيد قطع عنوان، مجددا فتح معتاد إقامة عميل `Session`. تاريخ قسم صفحة، حدث fold، أداة تصيير معنى رسم،title و فوري mux عودة و كل سوف إعادة استخدام عادي محادثة آلية. وجه حزمة فتات تنقل فقط سوف امتداد `origin: 'subagent'` سطر أب رابط تدريجي درجة عودة تتبع، يتضمن رقم واحد عادي owner، و يجعل عادي fork إبقاء مفرد طبقة. كل واحد درجة subagent وجه حزمة فتات كل سوف نيل نيل ذلك مباشر parent sibling دليل، و في دليل متاح وقت اعتماد منها label. من قد بحث عنوان subagent إنشاء fork وقت، سوف توليد أداة لديه مباشر مصدر جدول نظام عادي fork، و سوف ذلك مرفق إضافة إلى الأكثر قريب يملك Workspace أصل أولا. دليل هو واحد شجرة ARIA شجرة، دعم حمل كسول تحميل صيغة ArrowRight/ArrowLeft توسيع و طي، خط صفة ArrowUp/ArrowDown تنقل،Home/End،Escape و تركيز نقطة استعادة.

one-shot سطر بداية نهاية سوف استخدام نص سجل بديل إدخال إطار، شرح تنفيذ سجل لـ فقط قراءة. يمكن متابعة سطر فقط في `parentAvailable` لـ false كما child لم في وقت التشغيل مثل هذا؛parent مغادرة خط لكن ما زال في تشغيل child إبقاء عادي إدخال إطار، و منع استخدام ذلك إدخال منطقة و Send عملية، يجعل مستقل Stop و في خط QueueDock تحكم إبقاء يمكن بلوغ، إيقاف بعد فقط قراءة بديل استعادة.parent في خط وقت، أي جعل child صحيح في تشغيل، عادي Enter/Cmd+Enter انحراف جيد أيضا سوف اختيار Queue أو best-effort Steer. مقابل في خط يمكن متابعة child،QueueDock Edit،Remove و Steer في parent مغادرة خط وقت ما زال متاح؛ مستقل Stop مرور من `subagent.interrupt` توجيه ([في قطع اتفاق](2026-08-06-continuable-subagent-interrupt.ar.md)). نص التوجيه فشل سوف عبر عادي خطأ سلوك إبقاء مسودة مسودة.

قد بحث عنوان child عرض لا توفير ربط إلى agent مساعد مساعدة تحكم عنصر. أداة جسم بينما قول، نموذج اختيار جهاز و `/model` contribution لن استدعاء عادي `session.models` أو `session.selectModel`؛Host أيضا سوف رفض أي معنى خارج استدعاء، بينما لا هو في مباشر parent متابعة تنفيذ مسار خارج تنشيط حفظ دائم child تاريخ.

## مضيف مهايئ و بروتوكول اتفاق

`@deepseek-ai/dsh-subagent` يملك متصفح أمان توليد `subagent` Remote نطاق الأسماء:

- `subagent.list` قبول `parentSessionId`، استدعاء `ctx.subagents.listChildren(parentSessionId, signal)`، إرجاع كامل لديه ترتيب بند و كل سليم سليم سطر نشر ذلك `hasChildren` لقطة، يأخذ كل سليم سليم سطر لغة مادة نشط حركة حالة استبدال لـ ذلك تأكيد قطع Agent driver هل صحيح في تشغيل، و شرح حالي قدرة لا من `ctx.agents` تحليل خروج تأكيد قطع parent.
- `subagent.history` قبول يتضمن mode كامل عنوان و عادي صفحة معامل. هو مقابل وفق مباشر دليل تحقق child و mode، عبر `ctx.sessionQuery.readSession()` قراءة، مجددا مرة فحص مباشر جدول نظام، و في لا إصدار agent حال حال تحت إرجاع عادي أصلي حدث، تصيير معنى رسم، قسم صفحة و من Host حساب حساب جلسة إسقاط أساس خط.
- `subagent.prompt` فقط قبول `mode: 'continuable'` عنوان،`delivery: 'queue' | 'steer'` و فوق نقل شكل `PromptContentPart[]`؛Host في إلقاء تمرير قبل يأخذ صورة جزء دقيق دخول و حفظ دائم لـ حمل دائم مرجع ([صورة إلقاء تمرير](../../archived/bug-fix/2026-08-27-steer-followup-image-delivery.md)). هو اشتراط تأكيد قطع تخزين نشط parent، إعادة تحقق دليل عنوان، استخدام continuation manager مشترك شخص صنف إلقاء تمرير دقيق دخول، و إرجاع قد قبول `MessageId`.

شبكة صلة سوف سوف parent ناقص، دليل بند ناقص أو لـ diagnostic،child غير ممكن استعادة أو لم تخويل، طلب إلغاء، صورة دقيق دخول أو صورة قدرة رفض (`subagent/attachment-invalid`) و متابعة تنفيذ دقيق دخول مؤقت وقت غير ممكن استخدام انتظار فشل خريطة لـ نوع تحويل RPC خطأ. هو لن عام وصف رمز أو مزود دقيق عقدة.list/prompt تنافس حالة يخص صحيح معتاد حال حال: مرجعي اعتماد حسب هو نص التوجيه عملية نتيجة، بينما لا هو أكثر مبكر متاح صفة أو نشط حركة لقطة.

فحص نظر حفظ دائم تاريخ ذاته لن إنشاء mux حجز قراءة. عند لاحق رسالة شيء تحويل بارد حالة child Activation وقت، قائم Host و mux تدفق سوف إصدار ذلك دورة الحياة و حدث. إعادة اتصال وقت، نظام عبر `subagent.history` إعادة بناء قد بحث عنوان نافذة.

عادي `session.history` توجيه مقابل في عادي جلسة و subagent جلسة نفس مثال فقط تنفيذ مراقبة، لكن هو حيث لا يحمل دليل عنوان، أيضا لا منح إعطاء متابعة تنفيذ إذن. كل بند حاجة Agent عادي توجيه كل سوف في استعادة بارد جلسة قبل مرور مرور مشترك كل حق شبكة شريط؛`session.cancel` إبقاء هذا شبكة شريط.`session.updateQueue` فقط لديه واحد هدف محلي مثال خارج: هدف هو في خط child، كما ذلك حالي projection identity لـ continuable و قدوم ذاتي ذاته غير seed suffix؛one-shot، ناقص، لم معرفة، ضرر تالف، فقط يحتوي seed identity أو بارد child ما زال تلقي شبكة شريط منع حجب.

مهايئ ما زال يقع في توليد Remote نطاق الأسماء بعد؛`dsh-host-webserver` ما زال بصفة تحميل جسم. متصفح شفرة عبر قائم اتصال حزمة استيراد اتفاق، أبدا مباشر وصول مضيف `ctx`، من بينما إبقاء[قد عودة ملف GUI RPC قسم طبقة قرار](../../archived/architecture/2026-07-19-gui-layering-and-rpc-protocol.md).

## عميل كائن طبقة و عرض

لا اعتماد React وقت التشغيل مسؤول دليل، مفرد مرة تزامن تحديث جديد، إبقاء عنوان، متاح صفة تلميح، نقل اختيار، و كل قائمة سطر حالي إسقاط قيمة مرجع مستقر خريطة. مجددا مرة اختيار معروف child وقت سوف إبقاء ذلك عنوان، تجنب تجنب تنقل ساكن صامت تبديل إلى عادي جلسة API. ناقص في بين وجه حزمة فتات عنوان يمكن من قد تحميل أصل أولا دليل استعادة، لكن في مستخدم اختيار هذا وجه حزمة فتات قبل لن إبقاء لـ نقل عنوان، أيضا لن إنشاء scope. استعادة تنقل سوف حفظ دائم يتضمن mode كامل عنوان.

دليل عبر معيار `useSessions` لقطة نقل تمرير. مكون نطاق جزء حالة مسؤول قائمة مفرد مرئي صفة، قد توسيع فرع، تركيز نقطة و معلق توقف حساب وقت جهاز.`ui-conversation` لـ حالي عادي title و كل واحد درجة subagent وجه حزمة فتات إعلان جدول نظام slot، نقل دخول صاف بيانات شكل صيغة وجه حزمة فتات هوية و عرض نص، و لـ أصل أولا نقل دخول نحو فوق تنقل عودة ضبط؛ عادي title من render site إبقاء لـ رجوع.`@deepseek-ai/dsh-client-ui-subagent` بـ مباشر parent دليل تنقل احتلال استخدام كل جدول نظام slot، و أصل حسب عادي owner props اختيار حسب سبب منطقة قسم فقط قراءة تحرير جهاز. مكون فقط استقبال إرسال توليد props و عودة ضبط، أبدا استقبال `ctx`.

كل عملية داخل subagent child كل سوف في إصدار قبل كتابة `SessionHeader.origin: 'subagent'`. جلسة قائمة ملخص و زيادة كمية Host لقطة سوف إسقاط هذا حقل، جعل قسم مجموعة و مسطح مستو جانب حافة شريط حذف تكرار child سطر، معا إبقاء عادي fork. نفس بند قائم `host/session-added` لقطة أيضا سوف يأخذ قد تحميل مباشر parent سطر علامة لـ يمكن توسيع، بينما بلا حاجة جذب دخول دليل حدث تدفق. وصف رمز mode و دليل تحقق ما زال هو تنقل، متابعة تنفيذ و تخويل مرجعي اعتماد حسب.

هذا حزمة قائم `@label` source ما زال هو مستقل موجه إلى نموذج صاف نص إدخال. هو لن سوف label تحليل لـ عنوان، أيضا لن نيل نيل متابعة تنفيذ دلالة.

## افتراضي Web تركيب

قد تسليم Web تركيب سوف في JSONL حفظ دائم جانب تركيب SQLite جلسة استعلام، و سوف spawn و fork خلفية تفويض إرسال إعداد لـ يمكن متابعة نمط. هو أيضا سوف تركيب موجه إلى نموذج `send_message` و `list_agents` مهايئ، بـ إبقاء coordinator مقابل انتظار صفة، لكن GUI سوف عبر مضيف RPC مجال استدعاء مشترك `SubagentRuntime`، بينما لا هو استدعاء نموذج أداة.one-shot child ما زال في دليل في مرئي كما فقط قراءة.

## تجهيز اختيار خطة

**مقابل قد بحث عنوان child استخدام عادي جلسة API.** غير مقبول، لأن عام تاريخ لا يحمل دليل mode تحقق، بينما ربط إلى Agent عام تحكم عنصر سوف متعمد رفض subagent، لن منح إعطاء مباشر parent متابعة تنفيذ تخويل.

**سوف مهايئ وضع دخول webserver.** غير مقبول، لأن دليل و متابعة تنفيذ هو عبر طريق غير متصل عميل قدرة؛webserver فقط تحمل تحميل قد تحقق رسالة.

**يأخذ من Host دعم دعم ملف و جلسة مرجع وضع دخول هذه الحزمة.** غير مقبول، لأن دليل و قد بحث عنوان child عرض اعتماد subagent جدول نظام، بينما تركيب مرجع اكتشاف هو مستقل Host وظيفة، من [`ui-reference`](../../../../packages/client/ui-reference/README.ar.md) إزالة استهلاك.

**تلقائي استعادة ناقص parent.** غير مقبول، لأن متابعة تنفيذ اشتراط تأكيد قطع تخزين نشط مباشر parent.child تنقل لا نيل تغيير parent دورة الحياة.

**عام عادي إلغاء عملية.** غير مقبول، لأن قد نيل inbox قبول جولة سوف مقارنة ذلك دقيق دخول طلب تخزين متابعة أكثر دائم، كما في هذا قرار عند وقت، متابعة تنفيذ اتفاق لم عام أداة تجهيز أمان تخويل إلغاء جملة مقبض. بعد قدوم[حالي جولة في قطع اتفاق](2026-08-06-continuable-subagent-interrupt.ar.md) بـ مخصص استخدام subagent توجيه تكملة فوق هذا بند صريح تخويل؛ رجوع إلى `session.cancel` ما زال يتم رفض.

**فقط عرض يمكن متابعة child.** غير مقبول، لأن حفظ دائم دليل متعمد وصف من جلسة دعم دعم اثنان نوع mode.one-shot transcript أي جعل أبدا قبول لاحق رسالة، ما زال لديه استخدام.

**أصل حسب جدول نظام دفع قطع mode أو جانب حافة شريط مرور ترشيح.** غير مقبول، لأن عادي fork مشترك `parentSession`. من وصف رمز دعم دعم دليل مسؤول توفير mode؛ مفرد وحيد `origin` علامة فقط هو منخفض صار هذا تنقل تصنيف جهاز.

**بناء مسبق أولا تحميل تمرير عودة شجرة أو مخصص استخدام دليل تدفق.** حينئذ حالي قاعدة نموذج بينما قول غير مقبول. فقط لأجل صفحة رأس واحد طبقة يمكن توسيع صفة مسبق فحص سوف في لا قراءة بعد بديل حدث حال حال تحت حفظ إثبات نقر قبل مستقر صفة، بينما توسيع ما زال هو كسول تحميل صيغة مرجعي مباشر child قراءة؛ قائم Host لقطة سوف تحديث نشط حركة حالة، استعادة parent سطر يمكن توسيع صفة، و إطلاق محدود عضو تحديث جديد.

**يجعل child في parent إزالة فقد بعد ما زال قدرة مستقل تفاعل.** غير مقبول، لأن مستقل دورة الحياة و مستخدم كل حق حاجة side session دلالة.

## اختبار

- مضيف بروتوكول اختبار ثابت schema(يشمل مطلوب نشر ذلك يمكن توسيع صفة) ،id عودة إظهار،mode تحقق، غير تنشيط صيغة تاريخ، تأكيد قطع parent قوي صنع اشتراط،FIFO دقيق دخول عودة تنفيذ، إلغاء و انفصال حساس بعد فشل خريطة.
- عام Host اختبار ثابت في لا إصدار Agent حال حال تحت قراءة قد مرفق إضافة و بارد حالة تاريخ و تنفيذ fork، بارد حالة إسقاط عودة و، حسب وصف رمز/origin/وقت التشغيل owner رفض، رفض صريح id وصل قبول، و مباشر طابور صف تحكم شبكة شريط.
- عميل كائن اختبار ثابت قد إبقاء و قد استعادة عنوان،one-shot فقط قراءة و إلغاء رفض، تاريخ توجيه، يمكن متابعة نص التوجيه و في قطع توجيه، شاشة حجب ربط إلى agent نموذج تحكم عنصر، فوري نشط حركة حالة قلب تحويل (يشمل في طريق استجابة إعادة تشغيل و detach رجوع) ،subagent parent يمكن توسيع صفة قلب تحويل و عضو تحديث جديد.
- jsdom اختبار ثابت عادي title قسم فصل رمز، تدريجي درجة دمج subagent title تبديل حار منطقة، تضمين طقم title 12px حرف رقم، حالي و أصل أولا مثال صيغة، اختيار في سطر حرف إعادة، دليل label أولوية درجة، معلق توقف تأخير متأخر، نحو فوق نقر كبح صنع، إبقاء سهم رأس قطع قطع، بعد بديل تجمع دمج حساب عدد و نشط حركة حالة، جانب حافة شريط نشط حركة في تضمين طقم جدول نظام في نقل بث و عادي fork حد، سطر حالة أولوية درجة،token استخدام كمية مجموع حساب، دقيق إلى ثانية تشغيل في استهلاك وقت و تجميد ربط بعد inactive استهلاك وقت، اعتماد ذاتي ملائم ينبغي مفرد موضع طويل استهلاك وقت و ذلك دقيق بلا عائق عائق نص، دليل ناقص أو لـ قديم قديم فارغ دليل وقت من ملخص دعم دعم أصل عملية، معروف تحميل سطر شكل، خلط دمج mode سطر، نقر قبل ورقة فرعي توسيع تحكم عنصر،diagnostic، بعد بديل كسول تحميل توسيع، مباشر parent عنوان، مفتاح قرص سلوك و اثنان نوع فقط قراءة سبب.
- بلا مفتاح تجميع Web لقطة يتضمن واحد أداة لديه حفظ دائم token استخدام كمية inactive يمكن متابعة child، واحد أداة لديه تحديد صفة طويل استهلاك وقت inactive one-shot sibling و واحد حفظ دائم grandchild؛ هو سوف ثابت إطلاق جهاز في مرة قديم قديم فارغ دليل استجابة بعد ما زال عرض ثلاثة عدد بعد بديل، و ثابت token استخدام كمية و حساب وقت سطر، ذاتي ملائم ينبغي طويل استهلاك وقت عرض و تجمع دمج `running` حالة تحويل، في لا تنشيط حال حال تحت توسيع، فتح حفظ دائم تاريخ، دقيق دخول واحد بند مستخدم FIFO لاحق رسالة، عودة و child mux حدث، و إثبات one-shot تاريخ ما زال فقط قراءة. آخر عدد مستقل تجميع مشهد سوف في LLM seam موضع إبقاء واحد حقيقي child Agent جولة إجراء في، معا ثابت صفحة رأس و مرئي فارغ خامل owner سطر في تجمع دمج تشغيل حالة، مع بعد في teardown خلال إلغاء هذا جولة.
- تنقل اختبار ثابت فقط يحتوي subagent وجه حزمة فتات تنقل، من subagent إنشاء fork وقت Workspace ملكية، و `origin: 'subagent'` جانب حافة شريط مرور ترشيح، معا لا إخفاء عادي fork.

## عاقبة

- دليل قراءة ممكن إعادة مسح حفظ دائم جدول نظام و كل مباشر مرشح وصف رمز سجل، لكن يمكن توسيع صفة فقط إعادة استخدام هذا تتبع أثر في قد لديه بعد بديل header؛Web نشط حركة أساس خط سوف لـ كل سليم سليم سطر زيادة مرة Agent سجل التسجيل فحص بحث، مع بعد استخدام قائم فوري لقطة، بينما token استخدام كمية و استهلاك وقت سوف إعادة استخدام إسقاط أساس خط و دفع إرسال، بلا حاجة حسب سطر قراءة سجل، عضو تحديث جديد فإن إبقاء ذهاب اهتزاز حركة و مفرد مرة تزامن.
- parent متاح صفة،child نشط حركة حالة و `hasChildren` كل هو لقطة. صف خروج بعد، إصدار،dispose(مورد تحرير) ، أخرى إرسال جهة أو أخرى عملية كل ممكن انتزاع أولا تغيير حالة؛ نوع تحويل نص التوجيه فشل ما زال تابع مسبق مدة سلوك.
- child ممكن في تاريخ نيل أخذ و mux حجز قراءة بين إصدار، لذلك قائم ترتيب رقم عودة و أيضا شمول غطاء من بارد حالة تحويل لـ تخزين نشط قد بحث عنوان مسار.
- حفظ دائم origin سوف لـ child header و قائمة إسقاط إضافة واحد متعمد إبقاء ضعيف قيد منتج تصنيف حقل؛ هو لا يستطيع تغيير صار تخويل سريع مسار.
- حذف مقابل صحيح في تشغيل يمكن متابعة child حالي جولة Stop([في قطع اتفاق](2026-08-06-continuable-subagent-interrupt.ar.md)) خارج،UI لا توفير child إلغاء، حفظ دائم نتيجة،Activation هوية، حذف أو يمكن مستقل تفاعل مغادرة خط mode، ذلك نص سجل لا نيل داكن عرض هذه قدرة قد وجود. نشط وثب جولة استهلاك وقت درجة كمية هو قد سجل عمل، بينما غير Activation إقامة إبقاء وقت.
