# Agent Note: Desktop رقم واحد جهة Runtime

Status: implemented

[English](2026-09-14-desktop-primary-runtime.md) | العربية

## Problem

Desktop بديل إدارة حاجة في لا يوجد تطوير بيئة آلة جهاز فوق نيل نيل تحديد Python بيانات معالجة مكتبة و مستقل Node حل تفسير جهاز. نظام حل تفسير جهاز اختيار يجب متابعة من مستخدم تحكم.

## Decision

Desktop سوف Python،Node.js،pnpm، بيانات معالجة مكتبة و Office إنشاء عمل مكتبة بصفة ربط تطبيق إصدار ناتج تسليم. مسار استعلام أداة من تطبيق مورد سوف ناتج تثبيت إلى Harness home تحت ثابت دليل، و إرجاع قطعا مقابل مسار و داخل وضع Python توزيع حزمة إصدار. إصدار تقرير إبلاغ لا يتضمن مستخدم ذاتي سطر إضافة حزمة. هو لا تعديل PATH، بيئة متغير أو حزمة إدارة جهاز إعداد.pnpm استخدام أصلي عام تثبيت قاعدة.

تطبيق إصدار، مكون إصدار،Python توزيع حزمة إصدار و قفل تحديد إدخال ملخص سجل في `runtime.json` في، لا وضع في دليل اسم داخل. ملخص شمول غطاء الذي اختيار هدف حل تفسير جهاز و wheel ضغط حزمة، مشترك wheel إدخال،Python توزيع حزمة إصدار،pnpm إصدار و تجميع صيغة؛ أخرى هدف لن جعل ذلك بطلان. الذي اختيار هدف،wheel سجل و توزيع حزمة خريطة داخلي مفتاح ترتيب، و wheel بند ترتيب مشاركة و هذا هوية حساب حساب؛ قفل ملف قمة طبقة مفتاح ترتيب لا مشاركة و. حل ضغط أو تجميع منطق في قفل تحديد إدخال ثابت وقت تغيير ناتج بايت، يجب صريح رفع رفع صيغة إصدار. تثبيت إصدار كامل مؤقت تخزين فرعي هذا، و في استبدال نجاح قبل إبقاء قبل دليل. نفسه ناتج إعادة استخدام قد تثبيت ملف؛ استبدال أيضا سوف إزالة تلقي إدارة دليل داخل مستخدم إضافة Python اعتماد. لا يحتوي ملخص قديم بيان ما زال يمكن قراءة، و و حالي ناتج منطقة قسم. توزيع حزمة اسم حسب PEP 503 عودة واحد تحويل، عودة واحد تحويل بعد تكرار اسم سوف يتم رفض؛ بيان يتضمن numpy/pandas توزيع حزمة إصدار وقت، يجب و متبادل ينبغي مكون إصدار متسق.Desktop مفرد نسخة كل من و أداة مشترك تثبيت Promise سلسلة سطر معالجة صحيح معتاد تثبيت طلب.

Node تحت تحميل و تحقق كامل قفل تحديد wheel تجميع ها أمل، سوف مكتبة ملف حل ضغط إلى site-packages. هذا تجنب تجنب اختيار بناء رئيسي آلة Python و pip إصدار، أيضا بلا حاجة تنفيذ اعتماد تحليل أو عام wheel تثبيت.XlsxWriter VBA رفع أخذ نص برمجي انتظار مساعد مساعدة نص برمجي إبقاء في wheel `.data/scripts` دليل في؛ أمر سطر مدخل حزمة تركيب جهاز لا يخص هذا مكتبة ناتج. أخرى `.data` تثبيت خطة سوف يتم رفض. هذا آلة smoke في مؤقت ملف حذف بعد تنفيذ نهائي ناتج، فحص دقيق قفل تحديد توزيع حزمة تجميع دمج و داخل وضع pip،Python و ثابت wheel إصدار، اعتماد كامل صفة و يمكن تحرير Office وثيقة كتابة و قراءة، لذلك حل تفسير جهاز رابط يجب في ترحيل بعد ما زال صالح.Smoke فحص منع استخدام بايت رمز كتابة، تجنب تجنب يأخذ تحقق ناتج قبول دخول توزيع محتوى.

macOS فقط نحو مستقل Node يمكن تنفيذ ملف منح إعطاء `com.apple.security.cs.allow-jit`. نقص قليل هذا إذن قوي تحويل وقت التشغيل توقيع سوف منع توقف V8 قسم إعداد شفرة منطقة مجال. حل تفسير جهاز و مكتبة smoke فحص في توقيع بعد و مؤقت تخزين تنظيف بعد تنفيذ؛ توقيع صالح ذاته لا يستطيع إثبات برنامج يمكن تشغيل.

Windows توقيع تحزيم عبر تلقي مراقبة إشراف رقم واحد جهة وقت التشغيل توقيع مرحلة مقطع، سوف ملف دقيق تجهيز و تنفيذ قسم فتح.PE فحص ترتيب حذف أخرى منصة Node إضافة، و رفض دليل رابط. صالح فوق تنقل توقيع إبقاء ثابت؛ فقط لم توقيع ملف استخدام إعداد EV إثبات كتاب توقيع. قد لديه توقيع بلا فاعلية وقت، في وصول صلب عنصر قبل فشل؛ كل جديد توقيع عبر صالح صفة، ختم الوقت و إثبات كتاب هوية فحص بعد، عندئذ معالجة تحت واحد ملف.electron-builder نسخ مرحلة مقطع توقيع خطاف فقط في تدريجي بايت مقارنة مقابل و تحقق توقيع عبر بعد إبقاء وقت التشغيل يمكن تنفيذ ملف؛ إبقاء تحقق فشل وقت، نفس سلسلة سطر طابور صف رفض لاحق مهمة. صلب عنصر استدعاء إعادة استخدام قائم مستخدم درجة متبادل قفل، سلسلة سطر توقيع جهاز و انفصال حساس سجل؛ أي فشل كل لا سماح إعادة محاولة أو متابعة لاحق مرحلة مقطع. وقت التشغيل تنفيذ لا استقبال توقيع اعتماد، و في كامل تحقق توقيع بعد إجراء. تطوير و لم توقيع دقيق تجهيز إبقاء هذا آلة smoke، لا تلقائي وصول صلب عنصر.

Desktop ZIP حل ضغط عبر تحديد نحو اعتماد تغطية لـ `extract-zip` ثابت `yauzl` 3.4.0.2.x قراءة جهاز في Node 26 فوق ممكن لا يمكن إتمام مقارنة كبير deflate بند قراءة ([فوق تنقل مشكلة](https://github.com/thejoshwolfe/yauzl/issues/176)) ؛ إبقاء قائم حل ضغط جهاز يمكن إبقاء ذلك مسار تحقق و wheel بند فحص. تطوير بدء جهاز استخدام قمة طبقة await، تجنب تجنب دقيق تجهيز لم إتمام لكن نجاح خروج. كبير ضغط wheel ارتداد اختبار فحص كامل حل ضغط بايت.

## Alternatives considered

**فقط استخدام نظام حل تفسير جهاز.** لا يمكن حفظ إثبات متاح صفة أو مسبق تركيب numpy و pandas.

**حقن PATH و إشارة تحديد pnpm عام دليل.** هذه طريقة سوف تغيير أمر اختيار، أو اشتراط pnpm عام أمر دليل قد في PATH في. قطعا مقابل حل تفسير جهاز مسار و pnpm أصلي سلوك بلا حاجة هذه تعديل يكفي ممتلئ كاف طلب نطاق.

**مستقل تحديث و إصدار دليل.** Runtime إصدار و Desktop ربط، كما طلب تثبيت موضع ثابت.

**فقط توقيع حل تفسير جهاز أو قفز مرور هذا آلة smoke.** Windows شفرة كامل صفة أيضا فحص DLL و Python توسيع. بدء برنامج لديه توقيع لا يستطيع يجعل لم توقيع توسيع يتم تحميل، قفز مرور تنفيذ سوف إخفاء تثبيت بعد غير ممكن استخدام اعتماد. إبقاء صالح فوق تنقل توقيع حيث نقص قليل صلب عنصر عملية، أيضا إبقاء فوق تنقل ملكية معلومة.

## Consequences

تطبيق يحمل مقدار خارج أصلي ملف، و في ترقية وقت استبدال كامل تلقي إدارة ناتج.Windows فوق تشغيل في حل تفسير جهاز ممكن منع توقف استبدال. هذا آلة بناء smoke، تثبيت و إعادة استخدام و استعادة اختبار، بلا مفتاح أداة خطأ جلسة قسم آخر تغطية تثبيت و نموذج إخراج مسار؛macOS توقيع إعادة استخدام قائم أصلي Runtime توقيع جهاز. حل تفسير جهاز ضغط حزمة و Python wheel ثابت ها أمل، سماح يمكن إثبات مع كل توزيع حزمة إبقاء.
