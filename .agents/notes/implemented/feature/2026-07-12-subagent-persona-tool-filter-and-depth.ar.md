# Agent Note: إعداد subagent شخص ضبط، أداة مرئي صفة و عميق درجة

Status: implemented

[English](2026-07-12-subagent-persona-tool-filter-and-depth.md) | العربية

## مشكلة

واحد يمكن إعادة استخدام subagent مزود حل قرار هو «مثل أي تشغيل فرعي agent(ذكي جسم)» مشكلة، لكن مختلف تفويض إرسال أداة حاجة مختلف فرعي agent سلوك. بعض عدد نشر ممكن حاجة مراجعة من شخص ضبط، فقط حد بحث بحث أداة تجميع، أو صلب صفة تمرير عودة حد أعلى، بينما لا لا بد لـ كل نوع تركيب إنشاء جديد مزود.

هذه تحكم أثر فرعي agent رقم مرة نموذج طلب، لذلك لا يستطيع في فرعي agent مرئي بعد مجددا تثبيت. هو جمع أيضا حاجة مزود صدق فعلي دعم حمل:ACP(Agent Client Protocol) خلفية لا يستطيع صامت صامت قبول واحد فقط حد عملية داخل أداة مرور ترشيح جهاز، بينما مرور ترشيح جهاز في كل إضافة تشغيل في نفس يمكن معلومة عملية حال حال تحت أيضا لا ينبغي يتم وصف لـ أمان حد.

## قرار

subagent بدء لديه ثلاثة عدد مستقل تركيب تحكم:`persona`،`toolFilter` و `maxDepth`. مزود إعلان مقابل كل تحكم دعم حمل حال حال، خدمة في بدء تشغيل قبل رفض لا تلقي دعم حمل طلب، عملية داخل مزود في فرعي agent بعد لم إصدار وقت تثبيت الذي طلب تركيب.

هذه تحكم عودة جواب مختلف مشكلة:

| تحكم | مشكلة | نتيجة |
|---|---|---|
| `persona` | ماذا زاوية لون إشارة أمر استبدال هذا فرعي agent نشر شخص ضبط؟ | واحد فرعي agent نطاق جزء نص التوجيه مقطع سقوط حجب حجب `deployment:persona-prefix` |
| `toolFilter` | نشر عام أداة في أي بعض دخول هذا فرعي agent مرئي أداة عرض؟ | واحد لديه أثر مجال حد في إضافة فرعي agent نطاق جزء أداة قبل مرور ترشيح عام أداة |
| `maxDepth` | هذا شجرة تفويض إرسال شجرة الأكثر عميق يمكن طويل إلى كثير قليل طبقة؟ | فرعي agent عميق درجة تجاوز مرور قطعا مقابل حد أعلى وقت، بدء طلب يتم رفض |

`dsh-tool-subagent` سوف هذه تحكم بصفة إضافة إعداد كشف، و نسخ إلى هو إنشاء كل طلب في. مباشر استدعاء `SubagentRuntime` استدعاء جهة يمكن حسب طلب اختيار هذه تحكم. مزود قدرة وصف رمز ما زال هو خلفية قدرة لا صرف الآن كل حقل حق مصدر.

### شخص ضبط هو لديه أثر مجال حجب حجب

شخص ضبط تحكم تغيير واحد فرعي agent سلوك، بينما لا تغيير نشر درجة نص التوجيه تجميع. في لم إصدار ضبط مرحلة مقطع، عملية داخل مزود في فرعي agent أثر مجال في تسجيل واحد اسم لـ `deployment:persona-prefix` مقطع سقوط؛ عادي الأكثر أداة جسم من أولوية تحليل قاعدة فقط في هذا فرعي agent تجميع في استبدال عام مقطع سقوط.

ذلك قيمة و نشر شخص ضبط أداة لديه نفسه صارم إطار نموذج لوح دلالة. حذف وقت عبر عام طبقة وراثة نشر مقطع سقوط؛ صريح فارغ نص فإن بـ فارغ مقطع سقوط حجب حجب عام شخص ضبط. أب درجة و أخ أخ درجة شخص ضبط دائم بعيد لن دخول فرعي agent مسطح مستو أثر مجال.

هذا استخدام هو معتاد قاعدة توجيه النظام تسجيل آلية، بينما غير ثاني بند شخص ضبط عبر طريق. لذلك رقم مرة نص التوجيه يرى تسمية مساهمة و لاحق نص التوجيه و نص التوجيه فحص أداة يرى متسق.

### أداة مرور ترشيح هو واحد بند أثر في فوري عام عرض قاعدة

أداة مرور ترشيح معا تحكم قدرة مرئي صفة و يمكن تنفيذ فحص بحث. عملية داخل مزود في إصدار قبل في فرعي agent أثر مجال في تثبيت `ToolRuntime.restrict()`، سجل التسجيل مفرد واحد محلل مقابل بروتوكول صيغة (wire format) أداة schema، فحص بحث، تنفيذ و PTC mode SDK توليد تطبيق إضافة نفسه نتيجة. مستقل تسجيل توجيه النظام مقطع سقوط ما زال من كل إضافة مسؤول. نظام الملفات، بحث و Web أداة إضافة استخدام قد لديه `PromptSection.text({ scope })` عودة ضبط و `ctx.tools.get(name, scope)`، حذف غير ممكن استخدام أداة إشارة توجيه، و اختيار ملائم استخدام عبر أداة نص. هذا سوف إبقاء تلقي دعم حمل أداة تجميع دمج تحت أصل لديه إجراء لفظ و ترتيب، ملائم لأجل مهمة معنى agent scope، أيضا يشمل بروتوكول عرض لـ `run_code` قاع طبقة PTC قدرة. هذا طريقة لا إضافة جديدة مقطع سقوط ملكية بيانات وصفية أو تجميع خطوة؛`restrict()` لن تلقائي تعديل كتابة أخرى ساكن حالة نص حرف.

تحليل التزام دوران التالي قاعدة:

1. كل بند حد مقابل نشط وثب نشر عام أداة سجل التسجيل أولا تطبيق `allow` مجددا تطبيق `deny`.
2. كثير بند حد أخذ تسليم تجميع، لذلك واحد عام أداة يجب نيل إلى كل بند قد تثبيت حد وضع سطر.
3. فرعي agent أثر مجال أداة في عام مرور ترشيح بعد إضافة، يمكن حجب حجب واحد قد وضع سطر عام أداة.
4. إبقاء `run_code` عرض و أخرى أثر مجال نطاق جزء بروتوكول مساهمة لا تلقي عام مرور ترشيح جهاز أثر.

عند مرور ترشيح جهاز حيث لم توفير `allow` أيضا لم توفير `deny`، أو تسمية حالي عام يمكن حد تجميع دمج خارج محتوى (يشمل فقط وجود في نطاق جزء أثر مجال اسم أو إبقاء اسم) وقت، إعداد سوف صريح فشل.`allow: []` دمج قاعدة، كما متعمد إخفاء كل عام أداة. هذه فحص قدرة التقاط تجميع كتابة خطأ، و منع توقف إعداد في لا يمكن أثر الذي تسمية بند وقت نظر بدء قدوم ما زال صالح.

عام سجل التسجيل إبقاء نشط وثب. فقط deny مرور ترشيح جهاز سوف وضع سطر بعد قدوم تسجيل عام اسم (حذف غير صريح deny هذا اسم) ؛allow قائمة سوف ترتيب حذف بعد قدوم تسجيل عام اسم (حذف غير صريح allow هذا اسم). إزالة واحد عام أداة سوف سوف ذلك من كل قد تحليل عرض في إزالة. هذه دلالة في إبقاء حار تسجيل معا، جعل allow و deny منطقة آخر صريح تحويل.

### عميق درجة هو قطعا مقابل شجرة حد أعلى

عميق درجة حد مستقل في أداة مرئي صفة قدوم قيد تمرير عودة تفويض إرسال. قمة طبقة agent عميق درجة لـ صفر؛ عملية داخل فرعي agent عميق درجة لـ ذلك أب درجة قد تحقق عميق درجة إضافة واحد.`maxDepth` هو واحد قطعا مقابل غير سالب أمان كامل عدد، عند دفع تصدير فرعي agent عميق درجة كبير في حد أعلى وقت، بدء في فرعي agent كل حق بدء قبل أي يتم رفض.

صالح أب درجة عميق درجة أخذ حمل دائم `SessionHeader.delegationDepth` و وقت التشغيل `AgentOptions.subagentDepth` في مقارنة كبير قيمة. عملية داخل فرعي agent يأخذ دفع تصدير عميق درجة سجل في جلسة header في، استعادة وقت سوف إعادة تحميل دخول هذا header، لذلك إعادة بدء لا يمكن خفض منخفض تمرير عودة حساب عدد.

كل عام مدخل كل ذاتي سطر تحقق قيمة مجال، بينما غير اعتماد مفرد واحد موجه إلى نموذج إعداد مسار. سالب قيمة، صغير عدد، سالب صفر، غير لديه حد قيمة، لا أمان كامل عدد، صيغة خطأ تخزين أب درجة عميق درجة و دفع توجيه فيض خروج متساو يتم رفض. مباشر `SubagentStartRequest` يمكن حذف حد أعلى، يجعل هذا آلية لا قيد عميق درجة؛ مرور loader تحليل `dsh-tool-subagent` إعداد فإن قيمة افتراضية لـ `3`، قبول عدد قيمة تغطية، و استخدام صريح `'provider-managed'` قدوم حذف من عملية خارج مزود نشر يملك تمرير عودة ميزانية وقت حد أعلى. ثلاثة هو واحد مقارنة صغير لديه حد قيمة افتراضية، ما زال سماح root إضافة ثلاثة بديل بعد بديل،[base profile](../../../../packages/bundle/base/cordis.patch.yml) اعتماد هذا بند عام سياسة. مزود نقص قليل `depthLimit` وقت، عدد قيمة أداة حد أعلى سوف في مزود تركيب مرحلة مقطع فشل.

نشر يمكن تركيب عميق درجة و مرور ترشيح، لكن عدد قيمة حد أعلى لن دمج صار مرور ترشيح جهاز. تفويض إرسال أداة في حد أعلى موضع ما زال مرئي، لأن تخويل ممكن اعتماد وقت التشغيل حالة؛ كل مرة محاولة تجربة بدء كل سوف فحص استدعاء جهة agent حالي حمل دائم و وقت التشغيل عميق درجة، يتم رفض بدء إرجاع خطأ أداة نتيجة، كما لا إصدار فرعي agent. مرئي صفة سياسة ثابت نشر يمكن آخر خارج في فرعي agent في deny تفويض إرسال أداة. اثنان نوع اختيار كل لا تغيير مزود محادثة تاريخ سلوك.

### قدرة باب تحكم إبقاء مزود صدق فعلي

قدرة سوف طلب وظيفة و مزود تنفيذ قسم مغادرة.`SubagentCapabilities` إعلان `persona`،`toolFilter` و `depthLimit`؛`SubagentRuntime.start()` في استدعاء مزود قبل، مقابل وفق هذه علامة سجل فحص طلب في كل وجود حقل.

هذا جعل spawn و fork مزود يمكن مشترك عملية داخل تنفيذ، بينما خارجي مزود فقط إعلان ذاتي ذات قدرة قوي صنع تنفيذ جزء. طلب دائم بعيد لن ساكن صامت تخفيض: اختيار لا تلقي دعم حمل تحكم سوف إنتاج `UNSUPPORTED_CAPABILITY`، لن لديه تشغيل أو دورة الحياة حدث وجود.

### لم إصدار ضبط جعل رقم مرة طلب صحيح تأكيد

كل فرعي agent نطاق جزء تركيب في فرعي agent تغيير نيل يمكن مراقبة قبل إتمام. عملية داخل مزود نحو agent إنشاء توفير واحد ضبط عودة ضبط؛ هذا عودة ضبط في فرعي agent أثر مجال في تثبيت شخص ضبط، أداة حد و بنية تحويل إخراج مساهمة. فقط لديه ضبط نجاح بعد، إنشاء عندئذ إصدار جلسة و agent و سماح مشغل بدء.

ضبط فشل سوف تراجع خاص فرعي agent. لا يوجد مراقبة من قدرة نيل أخذ إلى واحد «رقم مرة نص التوجيه استخدام نشر شخص ضبط أو لم مرور ترشيح أداة تجميع، لاحق نص التوجيه عندئذ استخدام الذي طلب إعداد» فرعي agent.

## مرئي صفة لا هو تخويل

هذه تحكم تركيب هو نفس يمكن معلومة عملية داخل سلوك، بينما غير تخويل سلوك.`toolFilter` تغيير أداة سجل التسجيل تحليل خروج فرعي agent عرض، لكن هو لا إنشاء أب إلى فرعي تخويل إطار، لا اشتراط فرعي agent فقط يحتفظ أب درجة فرعي تجميع تخويل، لا صندوق رملي تحويل إضافة، أيضا لا منع توقف يحتفظ آخر عدد Cordis سياق شفرة مباشر استدعاء خدمة.

أداة جسم بينما قول، فرعي agent نطاق جزء أداة في عام مرور ترشيح بعد إضافة، ممكن لا في أب درجة عرض في. فقط deny فرعي agent أيضا قدرة يرى deny قائمة لم تسمية بعد قدوم عام أداة. هذه هو متعمد حركة حالة تركيب دلالة، و لا بنية صار غير رفع حق حفظ إثبات.

أمان تصميم حاجة مستقل تخويل يمثل، نقل بث قاعدة و تنفيذ وقت قوي صنع نقطة. إنشاء وقت تخويل لقطة، أب درجة فرعي تجميع تخويل، صريح لم قدوم تخويل API، و عام قدرة، إخراج، إنهاء وسم متساو لا في هذا وظيفة نطاق داخل.

## سبق اعتبار بديل خطة

**لـ كل نوع شخص ضبط أو أداة تجميع إنشاء واحد مزود.** هذا سوف جعل مشترك نفسه نقل و دورة الحياة تنفيذ مزود صار ضعف زيادة، جعل حركة حالة نشر إعداد تغيير نيل أخرق أخرق، كما ما زال حاجة تمرير عودة آلية. مزود مسؤولية هو تنفيذ نقل؛ طلب تحمل تحميل كل فرعي agent تركيب.

**نسخ أب درجة كامل أداة عرض.** تسجيل أثر مجال تصميم فوق هو مسطح مستو، دورة الحياة كل حق لا معنى طعم حال مرئي صفة وراثة. نسخ قد تحليل عرض أيضا سوف تجميد ربط حركة حالة عام تسجيل، و في لم كامل تعريف مهمة واحد اتفاق حال حال تحت خلط خلط تركيب و تخويل.

**في فرعي agent إنشاء وقت لقطة سماح عام أداة.** تجميد ربط allow تجميع دمج جعل لم قدوم تسجيل موحد واحد غير ممكن استخدام، لكن هو تغيير حار تسجيل دلالة و فتح بدء تخويل تصميم. قد تنفيذ مرور ترشيح جهاز إبقاء لـ نشط وثب سجل التسجيل يسمى كلمة، و مباشر سجل allow و deny سلوك.

**فقط إخفاء أداة schema.** فقط عرض طبقة مرور ترشيح يجعل نموذج يمكن عبر PTC mode أو زائف صنع استدعاء تنفيذ واحد نص التوجيه صوت تسمية لا وجود أداة. تعديل لـ من واحد محلل معا إدارة تحكم عرض و تنفيذ.

**يأخذ عميق درجة حد أعلى تحرير رمز لـ تلقائي أداة مرور ترشيح جهاز.** إنشاء وقت مرور ترشيح جهاز سوف لقطة واحد ممكن اعتماد وقت التشغيل حالة قرار، فقط أثر واحد قد إعداد أداة اسم، كما لا حفظ حماية مباشر خدمة استدعاء جهة أو بديل تفويض إرسال أداة. مزود تعديل لـ في كل مرة بدء وقت قوي صنع قطعا مقابل حد أعلى.

## عاقبة

مساهمة من يمكن إعداد فرعي agent زاوية لون، مرئي عام أداة و تمرير عودة عميق درجة، بينما بلا حاجة تعريف جديد مزود. قدرة فحص في كل حق بدء قبل فشل، لم إصدار ضبط جعل رقم مرة طلب متسق، مفرد واحد أداة محلل منع توقف عرض/تنفيذ عائم نقل.

بديل قيمة هو نشر جهة يجب إدارة حل نشط وثب allow/deny سلوك و مرئي صفة و تخويل منطقة آخر. حالي عميق درجة سياسة منع توقف مجددا إنشاء فرعي agent بعد، نموذج ما زال ممكن استدعاء مرئي تفويض إرسال أداة و استلام إلى خطأ. مزود عمل من يجب دقيق تأكيد إعلان كل تلقي دعم حمل تحكم، عملية داخل مزود يجب في إصدار قبل تثبيت كل طلب مساهمة. هذه تحكم متعمد لا حل قرار أمان عزل أو أب إلى فرعي غير رفع حق مشكلة.
