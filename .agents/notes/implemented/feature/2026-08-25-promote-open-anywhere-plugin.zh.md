# Agent Note: سوف open-anywhere من مجتمع منطقة إضافة تحويل صحيح لـ رقم واحد جهة حزمة

Status: implemented

[English](2026-08-25-promote-open-anywhere-plugin.md) | العربية

## مشكلة

مجتمع منطقة إضافة `@dsh-plugins/open-anywhere`(gitlab.deepseek.com/Ciyou/dsh-open-anywhere) في جلسة رأس جزء زيادة واحد "Open In..." قسم جسم حسب زر، يمكن في Finder،Cursor،VS Code،Xcode،Git GUI أو طرفية في فتح جلسة workspace دليل. هو بـ يد كتابة `lib/` JavaScript شكل صيغة مرور `dsh plugin add` تثبيت: بلا نوع، بلا اختبار، مباشر استدعاء `node:child_process`، يد فرك تحت سحب قائمة مفرد و style وسم، ذاتي حمل إبرة مقابل rc6–rc8 متصفح طرف DSH إصدار بوابة، و اعتماد استكشاف قياس `process.argv` تخمين قياس تشغيل في dsh إصدار. مستخدم أمل نظر هذا وظيفة يصبح Web profile داخل وضع جزء، بينما bundle تثبيت مسار إعطاء لا هذا واحد نقطة——كما خارجي شكل بضعة نحو مخالفة عكس مستودع كل اتفاق (locale يملك نص سجل، تدريجي ملف نسبة التغطية،wire حد تحقق، رئيسي آلة أمر قدرة وصل شق).

## قرار

رقم واحد جهة وظيفة تسمية لـ `open-in-app`: هو اختيار في Harness رئيسي آلة فوق فتح workspace دليل تطبيق، لا يمثل آخر منصة آلة جهاز أو هدف موضع.

[launch-environment](../../../../packages/util/launch-environment/README.zh.md) في مشترك استخدام `launchedThroughSsh()` فقط من وراثة عملية طبقة قراءة غير فارغ `SSH_CONNECTION` أو `SSH_TTY`.SSH بدء وقت سوف في أي استكشاف قياس بدء قبل إرجاع فارغ تطبيق دليل. مشروع و مستخدم `.env` في قيمة لا يستطيع بصفة SSH بدء اعتماد حسب؛Web متصفح نداء بدء و ذاتي ملائم ينبغي دليل اختيار جهاز مشترك استخدام هذا حكم قطع. أي جعل عميل تسجيل إقامة تطبيق اختيار، أيضا سوف إخفاء عملية مدخل؛ قد لديه متاح صفة فحص سوف رفض رسم علامة و بدء طلب.SSH طرف فتحة تحويل إرسال فقط تغيير HTTP يمكن بلوغ صفة، لا تغيير مساحة العمل أو تطبيق الذي تابع آلة جهاز.

هذا وظيفة رقم واحد جهة ملكية هو واحد مقابل حزمة:`@deepseek-ai/dsh-host-open-in-app` يقع في `packages/host/open-in-app/`(استكشاف قياس، دليل و بدء توجيه) ،`@deepseek-ai/dsh-client-ui-open-in-app` يقع في `packages/client/ui-open-in-app/`(قسم جسم حسب زر) ، من `dsh-web-app` bundle `open-in-app` و `ui-open-in-app` اثنان سطر تركيب دخول Web profile. تحويل صحيح هو إعادة كتابة، لا هو vendoring:

- **واحد مقابل host/client حزمة، امتداد استخدام `directory-picker-browse`/`ui-directory-picker-browse` إعداد مقابل بنية**:host حزمة `src/index.ts` في `ctx.webServer` فوق تسجيل ثلاثة بند HTTP توجيه (`GET /open-in-app/apps`،`GET /open-in-app/icon/<id>`،`POST /open-in-app/open`) ؛ui حزمة `src/client/index.ts` مرور معيار slot/inject عبر بضاعة يأخذ قسم جسم حسب زر تسجيل دخول `conversation.session.header.utilities`، نص سجل في نوع تحويل `open-in-app` locale نطاق الأسماء في، مثال صيغة لـ `--dsw-*` token فوق CSS Modules(أصل إضافة يد عمل حقن style وسم و داخل ربط تحت سحب يتم `Menu` أصل لغة بديل) ، عقدة نصف حافة هو يجعل إضافة ظهور في رئيسي آلة اسم سجل فوق فارغ apply. توجيه مسار و wire تحميل حمل نوع فقط لديه واحد بيت:host حزمة متصفح أمان `./shared` فرعي مسار (فقط لديه معتاد كمية و نوع) ؛client bundle مرور client tsdown preset `INLINE_SAFE` بند سوف ذلك داخل ربط، و `dsh-session` كل wire قطع قطعة نفس عبر طريق.host أصل مدخل فقط توجيه خروج Loader الذي يحتاج إضافة فعلي جسم و نوع؛ دليل،resolver،launcher و رسم علامة helper إبقاء شفرة المصدر داخلي مرئي.
- **واحد مرة تحليل إنتاج خروج قد تحقق بدء جهاز؛ نقر أبدا إعادة فحص قياس.** رئيسي آلة يأخذ كامل دليل كل عملية كسول صفة تحليل مرة، إنتاج خروج دليل id إلى `OpenInAppResolvedLaunch` خريطة——هذا آلة فعلي يحتفظ بدء جهاز، أبدا هو عار تثبيت سجل.`GET /apps` توفير خريطة keys،`POST /open` مباشر بدء ذلك قيمة؛ بدء وقت اكتشاف يمكن تنفيذ ملف قد إزالة فقد (spawn `ENOENT`) سوف فقط عمل ملغى هذا بند، إعادة تحليل مرة، لا يمكن مجددا إثبات وقت يأخذ هو من قائمة إزالة (إزالة ذاتي شفاء، جديد تثبيت انتظار إعادة بدء).
- **تحليل مصدر حسب منصة خدمة فعلي كما نزيه قيمة.** macOS في معروف تطبيق دليل (`/Applications`،`~/Applications`) فحص بند bundle تجميع كتابة، بدء `open -a <تحليل خروج bundle>`؛Xcode تتبع مع `xcode-select -p`.Windows اعتماد مرة قراءة `App Paths`، فقط في قدرة إثبات مغناطيس قرص يمكن تنفيذ ملف وقت اعتماد Uninstall سجل، معروف مسار، و اعتماد إصدار تحويل تثبيت دليل تطبيق في الأكثر جديد دليل——كل مرة كل أصل واحد بند دفعة كمية `reg.exe query`.GitHub Desktop سوف معا تحليل إصدار تحويل يمكن تنفيذ ملف و مع حزمة توفير `cli.js`، لا مرور أمر shell استدعاء تلقي دعم حمل `github open <path>` سلوك.CLI اسم مرور `ctx.subprocess.resolveExecutable()` عملية داخل تحليل (PATH/PATHEXT stat، بلا shell، بلا `which`/`where.exe` عملية فرعية) ؛CLI لا في PATH فوق Linux GUI بند رجوع إلى ذلك XDG desktop بند تحقق مرور `TryExec`/`Exec`، كما فقط لديه رئيسي آلة إعلان display server وقت عندئذ توفير `xdg-open`. ذلك بقية رئيسي آلة أمر (`xcode-select`،`reg.exe`، رسم علامة رفع أخذ) مرور `@deepseek-ai/dsh-native-command`(argv، أبدا مشي shell) تنفيذ.
- **ثلاثة عدد مستقل مدة حد يحل محل مفرد واحد `commandTimeoutMs`**:`probeTimeoutMs`(تحليل أمر) ،`iconTimeoutMs`(رسم علامة رفع أخذ أمر) ،`launchWatchMs`(مبكر مدة فشل نظر حماية نافذة) ، ضبط كامل واحد نوع عملية مهلة لم يعد تغيير أخرى عملية استجابة وقت——مع إرسال سطر bundle حفظ حراسة أرض إبقاء 10 ثانية أمر مدة حد (مهلة هو فشل فوق حد بينما غير تأخير متأخر ميزانية) ، نظر حماية نافذة 1 ثانية، هو عندئذ هو قيد open توجيه و حسب زر مشغول مشغول حالة تعليق بدء مرة نجاح بدء وقت طويل كمية. بدء بـ تنظيف مرور اعتماد بيئة (`dsh-subprocess` `scrubbedParentEnv`) تراكم إضافة مهايئ صريح بيئة بعد detached إرسال توليد؛Windows GUI launcher افتراضي إبقاء مرئي، فقط لديه مسؤول آخر سطر فتح GUI CLI مهايئ سوف صريح إخفاء ذاتي ذات عملية. نظر حماية نافذة إغلاق وقت ما زال في تشغيل بدء جهاز حساب لـ قد بدء، أبدا سوف يتم قتل ميت أو انتظار (kitty و JetBrains IDE في كامل نافذة دورة الحياة داخل إبقاء قبل منصة).
- **لديه رئيسي آلة مصدر منصة كل رفع أخذ رسم علامة.** macOS يأخذ تحليل خروج bundle `.icns` تحويل 128px PNG(`plutil` + `sips`) ؛Windows استخدام توليد PowerShell نص برمجي بـ موضع صيغة `-File` معامل (مسار لا مرور أمر سطر تحليل) رفع أخذ تحليل خروج يمكن تنفيذ ملف صلة ربط رسم علامة لـ 32px PNG؛Linux امتداد spec desktop بند `Icon=` فحص hicolor رئيسي عنوان و pixmaps دليل (PNG أو SVG، صاف نظام الملفات). أي فشل ينبغي جواب 404، متصفح إبقاء عام احتلال موضع رسم شكل.
- **بدء دليل هو حسب منصة إعلان بند بيانات جدول**(`OPEN_IN_APP_CATALOG`): كل تطبيق id حسب منصة (`darwin`/`win32`/`linux`) إعلان واحد بند حسب ترتيب محاولة تجربة بدء جهاز مصدر سلسلة——`fixed`(مع نظام داخل وضع) ،`app`(معروف دليل bundle تجميع كتابة) ،`xcode`(`xcode-select -p`) ،`cli`(عملية داخل PATH تحليل) ،`file`(`${VAR}`/`~/` توسيع بعد رقم واحد وجود مرشح ملف) ،`scan`(حمل رقم الإصدار تثبيت دليل أخذ الأكثر جديد) ،`app-paths` و `install-record`(Windows سجل التسجيل اثنان طبقة) ،`github-desktop`(إصدار تحويل يمكن تنفيذ ملف و مع حزمة CLI) ،`desktop`(Linux XDG desktop بند)——إضافة بدء جهاز argv نموذج لوح (`{path}` token أصل موضع يحمل دليل، لا فإن دليل إلحاق في نهاية ذيل) ، اختياري بيئة و Windows مرئي صفة سياسة، و اختياري رجوع بدء جهاز (`xed` بعد `open -a <bundle>`). أبيض اسم مفرد مقابل متساو Codex "Open In" هدف قائمة: تحرير جهاز و IDE(VS Code،VS Code Insiders،Cursor،Windsurf،Zed،Sublime Text،Xcode،Android Studio، سبعة عدد JetBrains IDE) ، تحويل صحيح إضافة أصل لديه Git GUI، طرفية (Terminal،iTerm2،Ghostty،Warp،kitty،Windows Terminal،Git Bash،GNOME Terminal،Konsole) و كل منصة ملف إدارة جهاز. ملف إدارة جهاز و منصة طرفية استخدام مستقل id(`finder`/`explorer`/`filemanager`) ، بينما غير واحد id إعداد منصة وسم، لأن وسم هو ساكن حالة متصفح كلمة قاموس بند، كما كل منصة رئيسي آلة فقط سوف استكشاف قياس إلى منها واحد. ملف إدارة جهاز بند مباشر مرور `dsh-native-command` مسار فتح جهاز بدء (`shell-open`،OS shell open verb، يحمل كامل أب بيئة، بينما غير detached تنظيف بيئة spawn) ، لأن مباشر spawn `explorer.exe <dir>` لا يستطيع يمكن اعتماد أرض نابض خروج نافذة. غلاف إغلاق union بـ `assertNever` استلام ذيل.
- **كل توجيه كل تشغيل في تركيب connection خدمة معلومة مهمة شبكة شريط بعد**(`requestRejection`: إحباط فشل DNS rebinding و عبر محطة استدعاء Host/Origin شبكة شريط، إضافة فوق متصفح إقرار إثبات) ، و API gateway تطبيق إضافة في ذلك WebSocket upgrade فوق حراسة حماية نفسه؛ آلية وحيد خروج موضع هو `src/index.ts` وحدة ملاحظة تفسير. في هذا شبكة شريط لـ فوق،open توجيه في wire حد تحقق طلب جسم:`application/json` وسيط جسم نوع (دقيق essence، بينما غير فرعي سلسلة مطابقة) ، بـ ترتيب فارغ بعد 413 طريقة يأخذ body حد في 64 KiB، تحقق حقل نوع، فقط قبول استكشاف قياس لـ متاح دليل id، و اشتراط إشارة نحو الآن تخزين دليل قطعا مقابل مسار.
- **حذف DSH إصدار بوابة.** هو وجود هو لأن إضافة تدريجي إصدار ركوب ركوب واحد هو لا يملك واجهة؛ رقم واحد جهة حزمة و مستودع نفس إصدار إصدار، بوابة، هو `sessionStorage`/`localStorage` معلومة مهمة منصة حساب و argv مرة تاريخ إصدار استكشاف قياس كل فقد ذهاب الذي إشارة.
- **فوق مرة اختيار مرور `createSnapshotStore(..., { persist })` حفظ دائم**(`dsh.open-in-app.choice`) ، بديل يد كتابة `localStorage` وصول. جديد تخزين لا يوجد منصة خاص تحديد ابتدائي اختيار؛ مستخدم أول مرة اختيار قبل، مكون استخدام رئيسي آلة توفير رقم واحد متاح بند.

هذا مقابل حزمة وضع في `packages/host/` و `packages/client/`، لأن اثنان عدد نصف حافة هذا قدوم حينئذ هو هذا اثنان نوع شرق غرب: استكشاف قياس/بدء جانب هو رئيسي آلة أساس أساس ضبط تطبيق، و هو إزالة استهلاك webserver نفس مجموعة؛ حسب زر هو عميل جدول وجه، و أخرى `ui-*` حزمة نفس مجموعة. مراجعة يأخذ هو من `packages/workspace/` مفرد عدد مزدوج نصف حافة حزمة نقل إلى هذا داخل (رؤية بديل خطة).

## اعتبار مرور بديل خطة

**في SSH جلسة في توفير VS Code بعيد طرف CLI.** قد تثبيت يمكن تنفيذ ملف لا يستطيع إثبات تحرير جهاز اتصال متاح: وراثة IPC socket يخص واحد ما زال في تشغيل VS Code اتصال،Harness متابعة وقت التشغيل هو أيضا ممكن إزالة فقد. متصفح جانب SSH هدف إعداد و محلي تحرير جهاز نداء بدء لا يخص هذا عدد رئيسي آلة تطبيق وظيفة.

**سوف إضافة `lib/` أصل مثال vendor دخول `packages/`.** الأكثر سريع، لكن يد كتابة JavaScript سوف كامل جسم لا مرور typecheck، نسبة التغطية،i18n،JSDoc و invariant بوابة؛ لـ ذلك إبقاء إعفاء تجنب سوف صنع خروج مستودع لحظة معنى لا ضبط حزمة صنف آخر.

**استخدام Typert Remote بينما غير عار webServer توجيه.** apps/open استدعاء رمز دمج Remote RPC شكل، لكن icon توجيه توفير اثنان دخول صنع PNG،JSON RPC مفردات تحمل تحميل لا؛ يأخذ icon تفكيك ذهاب عار توجيه بينما apps/open مشي Remote سوف يجعل واحد وظيفة لديه اثنان نوع نقل. عار توجيه أيضا مطابقة أصل إضافة عميل، كما `webhook-github` قد تأكيد قيام حمل تحقق عار توجيه أولا مثال.

**توسيع `host/apiproxy` `openPath` بينما غير جديد open طرف نقطة.** `openPath` استخدام نظام افتراضي تطبيق فتح واحد مسار؛ هذا وظيفة رئيسي جسم هو*استخدام أي عدد*تطبيق، حمل متاح صفة استكشاف قياس و تدريجي تطبيق بدء جهاز——هو مختلف عقد نحو. اثنان من مشترك `dsh-native-command`.

**وضع في `packages/workspace/` مفرد عدد مزدوج نصف حافة حزمة (الأكثر أول تسليم شكل، امتداد استخدام `dsh-session-log-export`).** مراجعة مدة تفكيك صار host/client مقابل:workspace مجموعة عقد نحو هو host-side only، هذا وظيفة إزالة استهلاك هو `webServer` بينما غير `workspaceRegistry`، كما مفرد حزمة كامل جسم تسجيل في Client تحرير ترجمة تجمع دمج وجه إجبار جعل رئيسي آلة توجيه و دليل اختبار زائف تركيب صار `.client.spec.ts`. تفكيك قسم يجعل كل نصف حافة اختبار سقوط في ذاتي ذات تحرير ترجمة وجه، اعتماد سقوط في صحيح تأكيد منطقة مقطع؛wire عقد نحو مرور host حزمة `./shared` فرعي مسار إبقاء وحيد خروج موضع.

**يمكن إعداد دليل (cordis.yml تعريف تطبيق).** تأخير بعد: كل بند اقتران دمج اكتشاف، بدء معامل، عملية سياسة و رسم علامة سلوك، لذلك قبول مهمة معنى أمر قبل حاجة واضح مستخدم ضبط ملكية و تحقق قاعدة. مستخدم توفير label يخص مستخدم بيانات، لا و locale يملك منتج نص سجل اندفاع مفاجئ.Codex و Orca عرض ممكن توسيع شكل: صيانة مرور داخل وضع preset إضافة يمكن إعداد custom handler.

**عبر عملية نظام API قطعة رفع كل قد تثبيت تطبيق.** لا بصفة قائمة مفرد حق مصدر:Launch Services،Windows تسجيل معلومة و XDG desktop بند يمكن تحديد موضع تطبيق، لكن لا يستطيع إثبات كل تطبيق كل قدرة استقبال workspace دليل، أيضا لا يستطيع إعطاء خروج صحيح تأكيد فتح دليل الذي يحتاج بدء بروتوكول.OS أصلي معرف ما زال يمكن بصفة صيانة مرور preset locator إدخال؛custom handler لأجل تغطية طويل ذيل، بينما لا هو تخمين قياس بدء دلالة.

**لـ Windows/Linux بند داخل وضع ساكن حالة رسم علامة (Codex لـ كل هدف تحزيم PNG).** رفض: رسم علامة توجيه في ثلاثة عدد منصة كل توفير رئيسي آلة حقيقي رسم علامة، لـ تركيب زينة صفة استلام فائدة تحزيم رقم ثلاثة جهة منتج رسم شكل سوف جذب دخول مورد إنتاج إدارة خط و تجارة علامة ريح خطر وجه.

**إعادة عملية فرعية فحص قياس (الأكثر أول تسليم شكل):macOS كل بند مرة `open -Ra`،CLI كل مرة `which`/`where.exe`، كل مرة بدء إعادة تحليل.** مراجعة مدة استبدال: مرة قائمة تحليل في macOS فوق إرسال توليد نحو 26 عدد عملية فرعية، حسب عرض اسم فحص Launch Services دليل ضعيف في مغناطيس قرص فوق bundle، مستودع قد لديه عملية داخل PATH تحليل (`ctx.subprocess.resolveExecutable()`) ، كما نقر وقت إعادة فحص قياس يأخذ استكشاف قياس مدة حد وضع فوق تفاعل مسار. لـ نقل موضع macOS bundle اعتبار مرور دفعة كمية `mdfind` التقاط قاع، اعتماد مراجعة known-paths إشارة عرض لم اعتماد؛ تسرب فحص تسجيل دخول معروف حد. أصلي LaunchServices/NSWorkspace استعلام حاجة مستودع بعد بلا addon——تأخير بعد، بـ معروف `.app` مسار لـ بديل ذات.

**عام مشترك تطبيق اكتشاف Service Definition.** حسب مفرد إزالة استهلاك من قاعدة تأخير بعد: في ظهور ثاني عدد GUI اكتشاف إزالة استهلاك من قبل،resolver إبقاء لـ حزمة داخل وحدة.

**مرور `SHDefExtractIcon` P/Invoke(`Add-Type`) نص برمجي أخذ 128px Windows رسم علامة.** تأخير بعد:`ExtractAssociatedIcon` هو لا يحتاج تحرير ترجمة قطعة مقطع .NET معيار وجه،32px في حسب زر 15-18 CSS px مقياس قياس فوق فقط في عال قسم شاشة اختصار دقيق إرسال لين؛ إذا فعلي في معنى،P/Invoke تغيير جسم هو نص برمجي داخل نطاق جزء ترقية. نفس إدارة لم تتبع مستخدم Linux رسم علامة رئيسي عنوان——hicolor هو كل رئيسي عنوان وراثة freedesktop التقاط قاع——ذاتي تعريف رئيسي عنوان طاولة وجه سوف يرى أصل إصدار رسم علامة.

## عاقبة

- غير SSH جلسة في، فقط يلزم رئيسي آلة في macOS،Windows أو Linux فوق استكشاف قياس إلى حتى قليل واحد قد تثبيت دليل تطبيق،Web profile حينئذ سوف ظهور رأس جزء حسب زر؛ ذلك بقية حال حال صفر تصيير (استكشاف قياس دليل لـ فارغ → مكون إرجاع null).
- مجتمع منطقة إضافة تثبيت مسار ما زال صالح لكن قد زائد بقية؛ ذلك أصلي توجيه و متصفح اختيار مفتاح مستقل في `open-in-app`، لذلك استخدام رقم واحد جهة وظيفة تثبيت ينبغي إزالة مجتمع منطقة إضافة، تجنب تجنب ظهور تكرار رأس جزء تحكم عنصر.
- تحليل و رسم علامة كل رئيسي آلة عملية كسول صفة تنفيذ مرة،dsh تشغيل خلال تثبيت تطبيق يلزم إعادة بدء بعد عندئذ ظهور——قبول؛ إزالة جهة نحو مرور `ENOENT` مفرد بند تحديث جديد ذاتي شفاء.
- دليل في تحرير ترجمة مدة ثابت؛ توسيع هو معنى طعم حال معا تحرير `OPEN_IN_APP_CATALOG` و اثنان نسخة locale كلمة قاموس (README معروف حد). منصة تغطية لا متساو——إذا جاف Git GUI و طرفية فقط لديه macOS بند؛Windows رسم علامة تلقي حد في .NET معيار واجهة 32px رفع أخذ،Linux تتبع مع hicolor بينما غير حالي رئيسي عنوان، لا يوجد desktop سجل صاف CLI بند فإن إبقاء عام رسم علامة.
- محلل، رسم علامة، توجيه، تحكم جهاز و مكون اختبار تغطية منصة استكشاف قياس، بدء نتيجة، متاح صفة ذاكرة مؤقتة و HMR موضع وضع.[SSH Web لقطة](../../../../snapshots/web/open-in-app-ssh/snapshot.yml) في تفعيل اثنان عدد Open In بند إعداد و تسجيل إقامة تطبيق اختيار شرط تحت تصيير مشترك تسجيل صنع جلسة، و فقط التقاط جلسة رأس جزء؛ إدخال إطار و موحد حساب شريط من كل منها لقطة مسؤول. وراثة SSH علامة جعل فارغ تطبيق دليل في مختلف منصة فوق إبقاء تحديد. عادي Web لقطة ما زال منع استخدام اعتماد رئيسي آلة تطبيق استكشاف قياس.
