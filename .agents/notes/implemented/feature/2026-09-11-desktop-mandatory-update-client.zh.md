# Agent Note: Desktop قوي أكثر عميل و منع سد نافذة

Status: implemented

[English](2026-09-11-desktop-mandatory-update-client.md) | العربية

## مشكلة

محلي عمل خدمة server لن نقل تمرير بعيد مسار الأكثر منخفض إصدار سياسة.Desktop قشرة يجب مستقل نيل معرفة قوي أكثر اشتراط، في لا في قطع قائم مهمة حال حال تحت منع توقف لاحق تفاعل، و في سياسة استعلام أو updater دقيق تجهيز فشل وقت إبقاء استعادة مسار.

## قرار

قشرة مستقل في عمل خدمة تدفق كمية جولة استفسار[واجهة رفع سجل](../../proposed/feature/2026-09-08-desktop-mandatory-update-api.zh.md) في تنقل عميل بروتوكول. إعداد و تطبيق هوية في تحزيم وقت تضمين دخول؛ تحزيم تطبيق تجاهل اختصار بيئة تغطية.[Desktop README](../../../../apps/desktop/README.zh.md) مسؤول إعداد حقل و قيمة افتراضية. تحزيم في دقيق تجهيز ناتج أو توقيع قبل اشتراط توفير من updater نشر بيئة اختيار تحديد سياسة مصدر محطة. اختبار بيئة استخدام عزل طيران كتاب تمييز حق؛ صحيح صيغة بيئة إبقاء مجهول اسم. اختبار تسجيل تسجيل نافذة حسب F12 سوف فتح مستقل DevTools، معا إبقاء صندوق رملي، تنقل سماح قائمة و فقط إقامة داخل تخزين Session. فقط لديه لم تحزيم تطوير نمط يمكن حذف سياسة إعداد. هذا تجنب تجنب بسبب متروك تسرب سياسة إعداد بينما ساكن صامت إنتاج خروج لا يوجد قوي أكثر فحص إصدار حزمة، أو يجعل اختبار حزمة استعلام صحيح صيغة بيئة سياسة.

تنسيق ضبط جهاز يملك واحد نسخة غير ممكن تغيير قد تثبيت عميل هوية، مفرد واحد في طريق طلب، قطع توقف وقت، بين فصل اهتزاز حركة و لديه حد أعلى فشل تراجع تجنب. يد حركة فحص التفاف مرور ضبط درجة، لكن إعادة استخدام في طريق طلب.dispose(مورد تحرير) في توقف طلب، انتظار تسوية، و منع توقف متأخر إلى إصدار. مسطح مستو تحويل `40005` بناء قيام منع سد لا اعتماد اختياري عنوان، تفصيل حال و تحت تحميل صفحة حقل؛ محلي تحويل التقاط قاع نص سجل و إعادة محاولة عملية ما زال يمكن استخدام، ناقص أو لم نيل دفعة دقيق صفحة عنوان لن عرض. نقل،JSON، عمل خدمة رمز أو HTTP خطأ كل لا يستطيع صاف حذف معروف منع سد. فقط لديه جديد صالح بلا حاجة قوي أكثر استجابة عندئذ قدرة صاف حذف هو. نفس إصدار مغادرة خط حفظ دائم لم تنفيذ، لأن ذلك منتج سلوك بعد لم تحديد.

مستخدم إرسال بدء معتاد قاعدة فحص وقت سوف إطلاق مستقل سياسة تحديث جديد، لكن لن انتظار أو عرض سياسة فشل. فقط لديه قد تأكيد قوي أكثر قرار سوف إلغاء معتاد قاعدة نابض نافذة، و يأخذ عرض نقل تسليم إعطاء قوي أكثر نافذة. اختبار بيئة تمييز حق سوف انتظار حالي معتاد قاعدة نابض نافذة انتهاء؛ إلغاء و فشل سوف إبقاء updater نتيجة. تزامن استدعاء جهة إعادة استخدام حالي معتاد قاعدة عملية أو تمييز حق عملية، لا إنشاء متبادل متبادل تنافس تنازع نافذة.

قشرة يملك نموذج حالة نافذة استخدام مستقل صندوق رملي مسبق تحميل و بلا اعتماد IPC اسم. رئيسي عملية تحقق ذلك دقيق وثيقة URL و WebContents هوية. خدمة طرف عنوان/تفصيل حال حسب نص عرض، أبدا بصفة HTML. إغلاق،Esc، معتاد قاعدة تحديث نابض نافذة، إضافة نافذة مدخل، إضافة تعديل و استعادة عملية كل لا يستطيع التفاف مرور سياسة.Host إبقاء قائم عمل تشغيل؛ فقط لديه قائم updater مهمة أثر تأكيد عندئذ قدرة تخويل تثبيت استلام ذيل. ما زال يمكن خروج تطبيق.

نموذج حالة نافذة عبر معتاد قاعدة تنسيق ضبط جهاز توفير مستخدم إرسال بدء تحت تحميل و مستقل تثبيت. دقيق تجهيز و مهمة فحص نجاح بعد، نفس نابض نافذة تحويل لـ تثبيت تأكيد، لا إنشاء آخر عدد نافذة. قليلا بعد تحديث إبقاء منع سد و تثبيت حزمة؛ إعادة محاولة سوف فحص مهمة و اشتراط إعادة تأكيد. ملف تحقق و دقيق تجهيز مشترك استخدام واحد مرئي مرحلة مقطع. فقط لديه مراقبة قياس إلى تلقي أثر مهمة بعد، إعادة بدء تلميح عندئذ وصف صحيح في إيقاف مهمة. اثنان صنف نابض نافذة متساو اشتراط الذي تابع وثيقة و رئيسي frame؛ إغلاق، في توقف أو فقد ذهاب معتاد قاعدة تصيير عملية سوف إلغاء ذلك دفعة دقيق.

استعادة واجهة في منع سد نافذة داخل إبقاء محلي تحويل خطأ و طي تقنية فن تفصيل حال. صفحة عملية فقط في فشل أو لا يوجد متاح ناتج وقت ظهور، لا و صحيح معتاد عملية و صف. متصفح أو قص لصق لوح استخدام قبل تحقق دقيق HTTPS مصدر محطة. طلب فتح متصفح بعد قيام أي توفير نسخ استعادة مدخل؛ طلب إتمام لا يستطيع إثبات خارجي شبكة صفحة تحميل. فقط في نسخ فشل وقت عرض كامل، مرور مرور تحقق عنوان توفير يد حركة نسخ. تنقل و نسخ نتيجة مستقل في updater خطأ، سياسة هدف عنوان تغيير بعد تجاهل اختصار متأخر إلى نتيجة. فتح متصفح، تحت تحميل حينئذ خيط و تثبيت جهاز تسليم وصل متساو لا صاف حذف سياسة أو تغيير updater هدف.

خلفية حينئذ خيط وقت،Windows طلب أب نافذة مهمة شريط رفع تنبيه،macOS طلب معلومة درجة Dock نابض قفز، و محاولة تجربة مرة بلا صوت إشعار. إرجاع حالي تأكيد واجهة سوف تنظيف أصلي رفع تنبيه، لا منح إعطاء تثبيت إذن. تكرار حالة، قليلا بعد تحديث و تركيز نقطة تغير لن تكرار رفع تنبيه نفس مرة حينئذ خيط. سياسة حل حذف، تثبيت و مورد تحرير أيضا سوف تنظيف رفع تنبيه. إشعار لا تلقي دعم حمل أو يتم رفض وقت ما زال يمكن استخدام نابض نافذة؛ أصلي عرض يحتاج عبر تثبيت حزمة منصة تحقق استلام.

هذا قرار تنفيذ[تفاعل رفع سجل](../../proposed/feature/2026-09-08-desktop-update-policy-and-installation.zh.md) عميل جزء. هذا رفع سجل و واجهة رفع سجل ما زال مسؤول خلفية ربط ضبط، كل منصة إصدار تحقق استلام و لم قرار منتج أمر بند.[إصدار سياسة](../architecture/2026-08-25-electron-desktop-packaging-and-updates.zh.md) إبقاء ناتج توقيع و إصدار اشتراط؛ هذه سجل متساو لم يتم كامل يحل محل.

Host خروج و مهمة نجاح استلام ذيل هو اثنان عدد مستقل نتيجة. عملية كل من عبر مخصص استخدام خطأ نوع تقرير إبلاغ قد تأكيد لكن غير صحيح معتاد خروج. هذا نتيجة سماح خلفية إتمام تنظيف، لكن تثبيت ما زال فشل؛ قشرة استعادة حالي إصدار Host، و اشتراط إعادة تأكيد تثبيت، لا صاف حذف قوي أكثر سياسة. بديل Host سوف نيل نيل جديد Web مصدر محطة و تمييز حق Cookie، لذلك Host حينئذ خيط بعد سوف إعادة تحميل أصل لديه تطبيق عنوان، أي جعل طرف فتحة لم تغيير أيضا سوف إعادة نيل أخذ بدء بيانات. أخرى إيقاف فشل سوف إبقاء خلفية تنظيف خطأ و منع توقف بديل عملية بدء، لأن قديم عملية ممكن ما زال يحتفظ profile حالة.

مقابل في قد تأكيد غير صحيح معتاد استلام ذيل، اثنان صنف نابض نافذة كل سوف محلي تحويل استعادة تلميح و يمكن توسيع تقنية فن تفصيل حال قسم فتح عرض. تفصيل حال ابتدائي طي، لا منح إعطاء تحديث إذن. تشخيص عرض عملية دورة الحياة واقع، بينما غير ممكن يتضمن اعتماد مهمة معنى إضافة stderr. قوي أكثر نابض نافذة في حالة لم تغيير وقت إبقاء قد توسيع تفصيل حال، تشخيص تغيير أو صاف حذف وقت فإن طي.

مهمة تحذير إبلاغ وصف تشغيل في agent، ترتيب طابور إدخال و تشغيل في أو إيقاف في خلفية مهمة، بينما غير طلب تدفق كمية. مستخدم دفعة دقيق تثبيت بعد،Host رفض جديد API طلب، انتظار قد استقبال طلب انتهاء، مجددا فحص مهمة. هذا حيث حفظ حماية قد استقبال كتابة عملية، أيضا لا بسبب صفحة قراءة نابض خروج تحذير إبلاغ. مهلة أو يتم بديل انتظار لا يستطيع تخويل تثبيت؛ فشل بعد قشرة حل حذف دقيق دخول قفل.

منتج مسبق تحميل فقط إصدار دلالة تحويل updater مرحلة مقطع، إصدار، دخول درجة و فشل صنف آخر، لا يحمل محلي تحويل نص أو أصلي تشخيص. دقيق تجهيز مرحلة مقطع فشل يحمل نوع تحويل سبب، أصلي و Web واجهة قسم آخر اختيار استخدام ذاته locale تلميح، بلا حاجة مقارنة مقارنة قلب ترجمة بعد نص سجل. حساب مستخدم سطر و جانب شريط استلام بدء حالة عبر حالي Web locale تحليل هذه بيانات، أصلي نابض نافذة ما زال استخدام Desktop قشرة locale. رئيسي حركة خروج تطبيق وقت، منتج نافذة سوف في Host استلام ذيل قبل إخفاء، و في عملية خروج قبل تجاهل اختصار تجمع تركيز طلب، تجنب تجنب يأخذ مسبق مدة اتصال في قطع عرض صار استعادة عملية.

## اعتبار مرور بديل خطة

**لا يوجد شبكة صلة تسليم وصل آلية وقت استخدام نظام متصفح.** ذلك Cookie لن و Electron طلب مشترك. صريح تفعيل اختبار نشر تعديل استخدام صندوق رملي BrowserWindow و مستقل داخل تخزين Session، لا تفعيل Node تجميع صار أو مسبق تحميل. وثيقة تنقل فقط سماح إعداد HTTPS سياسة مصدر محطة و قد مراجعة نواة طيران كتاب مصدر محطة؛ رفض إذن، تحت تحميل، جديد نافذة و HTTP تمييز حق. شبكة صلة لا حاجة إضافة جديدة token تسليم تبديل واجهة. هذا بـ عبر إعادة بدء تسجيل تسجيل و لا تلقي حد هوية مزود تنقل تبديل أخذ عزل. افتراضي مجهول اسم بروتوكول و updater نقل ثابت.

**في اختبار تسجيل تسجيل نافذة منع استخدام DevTools.** هذا سوف منع توقف محلي فحص رقم ثلاثة جهة صفحة، لكن جعل تمييز حق فشل صعب بـ ترتيب فحص.F12 هو هذا نافذة فوق صريح محلي عملية؛ صحيح معتاد تسجيل تسجيل لن تلقائي فتح DevTools.

**سوف تسجيل تسجيل إعادة تحديد نحو إتمام نظر لـ تحديث قرار.** Windows شبكة صلة استكشاف إبرة من لم تمييز حق 401 تغيير لـ تطبيق طبقة 422، إغلاق تسجيل تسجيل نافذة بعد ما زال إعادة استخدام Session. هذا تحقق نفس عملية Cookie نقل، و لا إثبات و Harness سياسة API توافق. عميل في تسجيل تسجيل بعد إعادة فحص سياسة، تمييز حق مرور مدة أو استجابة شاذ شكل وقت إبقاء معروف منع سد، كما من لا استخدام شبكة صلة توفير تسجيل تسجيل URL. كل مرة تسجيل تسجيل نافذة كل أولا مرور مرور مستخدم تأكيد. تحزيم تطبيق أول مرة بدء فحص يمكن في محلي خلفية حينئذ خيط قبل شرح تمييز حق اشتراط؛ بعد تلقائي فحص إبقاء ساكن صامت. شرح، تسجيل تسجيل و إعادة فحص من نفس عدد عملية مسؤول، جعل تزامن مدخل لا يمكن إنشاء متبادل متبادل تنافس تنازع تسجيل تسجيل نافذة.

**يأخذ سياسة متاح بصفة معتاد قاعدة تحديث عكس تغذية قبل وضع شرط.** سياسة نقل أو بروتوكول فشل سوف ضغط صنع صالح updater نتيجة، و جعل معتاد قاعدة ناتج توزيع اعتماد قوي أكثر خدمة. لذلك اثنان عدد فحص مشترك استخدام مستخدم إطلاق مدخل، لكن قسم آخر معالجة نتيجة؛ فقط لديه قد بناء قيام قوي أكثر حالة يمكن انتزاع احتلال معتاد قاعدة عرض.

**انتظار عمل خدمة API إرجاع إصدار خطأ.** Desktop عمل خدمة تدفق كمية في محلي، لذلك بعيد مسار سياسة يجب لديه مستقل تنقل عميل طلب.

**استخدام يمكن إلغاء معتاد قاعدة رسالة إطار.** هو لا مسؤول حمل دائم تحت تحميل دخول درجة، إعادة محاولة، صفحة التقاط قاع و سياسة تحديث جديد. مخصص استخدام نموذج حالة نافذة إبقاء هذه عملية، معا لا سماح إلغاء قوي أكثر اشتراط.

**سياسة وصول وقت إنهاء مهمة.** سياسة اشتراط إيقاف لاحق تفاعل، بينما غير صحيح في تشغيل عمل. تثبيت دفعة دقيق ما زال هو إيقاف تلقي أثر مهمة مستقل تخويل.

**يجعل سياسة اختيار أو عمل ملغى updater تثبيت حزمة.** هذا سوف زيادة ثاني عدد ناتج مرجعي، و مخالفة خلف قد تأكيد عال إصدار تغطية سياسة. فقط لديه updater اختيار و تحقق ذلك إصدار ربط تثبيت حزمة.

**تقنية فن تفصيل حال فقط إبقاء في سجل في.** نابض نافذة داخل طي تفصيل حال يجعل مستخدم بلا حاجة فحص بحث محلي سجل يكفي ترتيب فحص إيقاف فشل، معا إبقاء افتراضي استعادة تلميح يمكن قراءة.

**مقابل كل في طريق API طلب كل نابض خروج تحذير إبلاغ.** بدء قراءة سوف في لا يوجد تلقي أثر مهمة وقت إطلاق في قطع تحذير إبلاغ. سوف طلب استلام ذيل و مهمة فحص قسم فتح، يمكن تجنب تجنب هذا نوع خطأ تقرير، أيضا بلا حاجة حسب URL تصنيف RPC أو إسقاط لم إتمام كتابة عملية.

**عبر مسبق تحميل نقل تمرير محلي تحويل تحديث نص سجل.** Desktop قشرة locale ممكن مختلف في Web تطبيق داخل اختيار لغة، قد نقل تمرير نص أيضا لا يمكن استجابة بعد لغة تبديل. دلالة تحويل عرض بيانات يجعل مكون متابعة يملك مستخدم الذي اختيار Web لغة تحت نص سجل.

**معتاد قاعدة خروج وقت إبقاء منتج نافذة مرئي.** أولا إغلاق ذاتي لديه Host سوف يأخذ مسبق مدة قطع فتح عرض إلى اتصال استعادة واجهة. استلام ذيل قبل إخفاء نافذة حيث إبقاء عملية صحيح معتاد تنظيف، أيضا لن لـ رئيسي حركة إغلاق عرض إعادة محاولة عملية.

## عاقبة

معتاد قاعدة فحص و تحت تحميل فشل سوف لغة حرف قاموس توفير ملخص و يمكن توسيع updater تشخيص قسم مغادرة. معلق توقف تلميح لا يحتوي أصلي خطأ نص؛ تحت تحميل معلق توقف تلميح شرح عملية و هدف إصدار.Web تحديث حالة مستقل في أصلي نابض نافذة لغة، تتبع مع تطبيق داخل حالي locale. قشرة تقرير إبلاغ صحيح في تثبيت وقت، تحديث حالة أولوية في اتصال عكس تغذية، لأن إيقاف ذاتي لديه خلفية هو مسبق مدة سلوك. تثبيت فشل سوف صاف حذف هذا أولوية درجة، جعل حقيقي إعادة وصل إبقاء مرئي. معتاد قاعدة خروج سوف في حدوث نفس مسبق مدة خلفية قطع فتح قبل إزالة منتج نافذة. عادي طويل تشخيص مستقل في تأكيد عملية تمرير؛ توسيع تفصيل حال لا منح إعطاء تثبيت إذن.

[محلي تحقق](../testing/2026-09-10-desktop-local-updater-qualification.zh.md) تنفيذ حقيقي Electron نموذج حالة نافذة، تلقي حد مسبق تحميل، صفحة حسب زر معالجة، شبكة شبكة سياسة و updater تحت تحميل. رئيسي مدخل ارتداد تحقق Host عمل إبقاء و عمل خدمة تحكم رفض. الذي تابع اختبار دليل داخل العربية DOM مسبق مدة إخراج قيد مرئي نص سجل و عملية. هذه اختبار لا إثبات إنتاج API توافق صفة، أصلي متصفح/قص لصق لوح تجميع صار، كامل مساحة العمل نظر شعور فاعلية نتيجة، توقيع تثبيت أو إعادة بدء بعد سليم سليم حالة؛[تحقق سجل](../../../../apps/desktop/tests/README.zh.md) صف خروج بعد نقص دليل.
