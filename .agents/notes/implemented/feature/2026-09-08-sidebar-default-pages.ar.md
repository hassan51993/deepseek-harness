# Agent Note: Sidebar افتراضي صفحة

Status: implemented

[English](2026-09-08-sidebar-default-pages.md) | العربية

## مشكلة

فقط لديه واحد تسجيل مدخل جذب توجيه صفحة زيادة مرة نقر، لكن لا توفير اختيار.

## قرار

Sidebar من قد تسجيل جذب استيراد فتحة قائمة اختيار كل افتراضي صفحة. تماما جيد واحد مدخل وقت فتح مقابل صفحة؛ لا يوجد مدخل أو لديه كثير عدد مدخل وقت فتح جذب توجيه صفحة. لا يوجد جذب استيراد فتحة مورد عرض جهاز لا أثر حساب عدد. صريح إضافة جذب توجيه صفحة بداية نهاية فتح جذب توجيه، كل إطار الأكثر كثير يحتفظ واحد.

[الأكثر بعد واحد tab إغلاق قاعدة](2026-09-08-sidebar-last-tab-close-rules.ar.md) مسؤول إغلاق حفظ حماية: بصفة وحيد توقف اعتماد tab جذب توجيه صفحة إبقاء فتح، أخرى أي وحيد tab كل سوف وصل نفس كامل صف واحد بدء إغلاق. عام توقف اعتماد طقم عنصر استقبال عرض عودة ضبط، لا يملك ملف متصفح أو جذب توجيه صفحة سياسة. نقل حركة tab ما زال سوف معالجة فارغ إطار، تخطيط حالة فقط تخزين في داخل تخزين.

هذا قرار يحل محل[مع حزمة نوع](2026-09-05-sidebar-text-preview-and-file-tree.ar.md) في افتراضي جذب توجيه اختيار، و[توقف اعتماد أساس أساس ضبط تطبيق](2026-09-04-right-sidebar-docking-infrastructure.ar.md) في صريح إغلاق الأكثر بعد واحد tab. هو جمع تسجيل، محتوى حالة، جذب محرك و تخطيط كل حق قرار متابعة صالح.

## اعتبار مرور بديل خطة

**موحد حساب كل قد تسجيل tab نوع أو قد فتح tab.** اثنان من كل لا بديل جدول جذب توجيه صفحة توفير اختيار؛ مورد عرض جهاز لا واحد تحديد مساهمة مدخل.

## عاقبة

مفرد مدخل تركيب مباشر فتح قد تسجيل صفحة، لا كتابة ميت Files. جذب توجيه صفحة اختيار ما زال يمكن استبدال ذاته tab.store و مكون اختبار تغطية تسجيل عدد كمية؛ تجميع بعد متصفح مشهد تغطية افتراضي Files، صريح إضافة جديدة جذب توجيه و إغلاق وحيد tab بعد إرجاع Files.
