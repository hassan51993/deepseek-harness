# Agent Note: حزمة تجربة النموذج اتفاق

Status: implemented

[English](2026-07-12-package-model-experience-contract.md) | العربية

## مشكلة

حزمة README يمكن حل تفسير API و وقت التشغيل آلية، لكن لا عودة جواب رئيسي توجيه agent harness(ذكي جسم إطار هيكل) سلوك و صار هذا مشكلة: هذا حزمة أي بعض محتوى سوف دخول نموذج طلب، في ماذا شرط تحت دخول، هذه token سوف إبقاء كثير دائم، و لاحق طلب هل سوف إبقاء يمكن إعادة استخدام KV Cache بادئة. في إضافة هيكل بنية في، هذا نوع متروك تسرب خاصة ذلك صعب بـ مراجعة حساب. مستهلك ممكن يأخذ خلفية نتيجة تحويل لـ أداة رسالة، سياسة إضافة ممكن بـ خطأ يحل محل نجاح نتيجة، ضغط ممكن إزالة قديم تاريخ، بينما agent نطاق تسجيل ممكن تغيير بعض عدد agent نص التوجيه أو schema، لكن لا أثر أخرى agent. لذلك، فقط قراءة قراءة اسم معنى فوق موجه إلى نموذج حزمة سوف متروك تسرب حقيقي سياق فاعلية ينبغي، بينما في كل مرة معتاد قاعدة مراجعة في عبر كل اعتماد قراءة قراءة شفرة المصدر أيضا صار هذا مرور عال.

## قرار

كل أداة لديه موجه إلى نموذج أو مجاور قريب نموذج اتفاق workspace حزمة README كل بـ مواصفة[تجربة النموذج فصل عقدة](../../../../docs/cookbook/adding-a-package.ar.md#4-write-the-package-readme) استلام ذيل، موضع ضيق مجاور `## Known Limitations and Deferred Work` قبل؛ يقع في “بلا معروف حد” سماح قائمة في حزمة فإن بـ تجربة النموذج فصل عقدة ذاته ربط ذيل. مرور مراجعة حساب تأكيد و نموذج غير متصل عام حزمة عبر `NO_MODEL_EXPERIENCE_SECTION` حذف هذا فصل عقدة.

أداة لديه مباشر، شرط صيغة، لديه حد أعلى، دورة الحياة، كثير جدول وجه أو مساعد مساعدة نموذج فاعلية ينبغي حزمة، لـ كل سياق جدول وجه استخدام واحد H3. كل جدول وجه يتضمن ثلاثة عدد لديه ترتيب H4 حقل——`What the model sees`،`Token effect` و `KV Cache effect`——كل حقل كل بـ واحد متن مقطع سقوط فتح رأس. ذاكرة مؤقتة حقل منطقة قسم فقط إلحاق زيادة طويل، مستقر تكرار بادئة، استبدال أولا قبل token، و مستقل نموذج طلب؛ هو نقطة واضح من حزمة يملك، كما قدرة في جديد محتوى إلحاق قبل تغيير طلب كل بند إعداد، أثر مجال، دورة الحياة، ضغط أو توجيه تغير.“Does not invalidate” يمثل هذا حزمة إبقاء واحد قد يمكن إعادة استخدام بادئة، و غير تحمل وعد مزود واحد تحديد قدرة أمر في ذاكرة مؤقتة أو سوف ذلك إبقاء خاص تحديد وقت طويل. من حزمة يملك مستقر نص حسب أصل نص دقيق مرجع: توجيه النظام متن و أخرى طويل حرف وجه كمية في جذب دخول هو جمع حقل تحت استخدام حمل عنوان H5 إضافة `markdown` محيط شريط، عبر معتاد يقع في `What the model sees`؛ قصير حرف وجه كمية فإن بـ داخل ربط شكل صيغة إبقاء، و نقطة اسم إدراج قيمة احتلال موضع رمز. أداة schema رابط توليد[أداة دليل](../../../../docs/tool-catalog.ar.md) في حمل مرساة نقطة فصل عقدة، و كما فقط قديم وصف تركيب أو إعداد زيادة كمية؛ فقط وقت التشغيل تعريف حل تفسير دليل لـ أي حذف هو جمع. اعتماد بيانات و من مزود يملك نص اعتماد ملخص.agent نطاق مرئي صفة يجب صريح شرح؛ عند نطاق يمكن إخفاء نص التوجيه و schema في واحد من بينما لا أثر آخر من وقت، اثنان نوع جدول وجه إبقاء قسم مغادرة.

لا يوجد نموذج سياق فاعلية ينبغي حزمة، أو بعض بند مسار تماما من آخر عدد حزمة تصيير حزمة، استخدام تحقق جهاز مراجعة حساب مرور قصير صيغة: واحد جملة بـ `None, as ` أو `Indirectly, through ` فتح رأس جملة فرعي، مع بعد هو واحد `KV Cache effect` H4 و واحد متن مقطع سقوط. صاف نقل حزمة و بلا مفتاح اختبار دعم حمل حزمة إذا لا إنشاء أي دخول نموذج محتوى، حينئذ استخدام none صيغة. مزود خلفية أي جعل سوف حد أو مرور ترشيح بيانات، أيضا استخدام بين وصل صيغة؛ أداة اسم فرعي بند يملك الكل فاعلية ينبغي وقت، وصل خط bundle أيضا استخدام هذا صيغة. هذه فصل عقدة سوف إشارة خروج مساهمة الذي في، و إعلان لن مباشر توجيه يؤدي KV Cache بطلان، معا لا تكرار قديم وصف مستهلك. بنية تحويل فصل عقدة نفس مثال فقط سجل من حزمة يملك إدخال، تغيير تبديل و زيادة كمية.

`verify-package-readme-model-experience` اكتشاف كل حزمة manifest(بيانات وصفية بيان) ، و تحقق ثلاثة نوع تصنيف، مواصفة نهاية ذيل فصل عقدة ترتيب، تأكيد قطع حقل عنوان عميق درجة و ترتيب، غير فارغ حقل مقطع سقوط، تدريجي حرف كتلة H5 ملكية، أداة جسم حرف وجه كمية دليل، و حمل مرساة نقطة أداة دليل رابط. هو في `doc-sync` و و سطر بوابة runner في تشغيل. مراجعة ما زال مسؤول تغطية وجه، رابط متبادل صلة صفة و واقع دقيق تأكيد صفة.

## سبق اعتبار بديل خطة

- **فقط سجل تسجيل نص التوجيه أو أداة حزمة**: مرفوض. خلفية، سياسة إضافة، مهايئ، حفظ دائم، أثر مجال و ضغط كل سوف تغيير token محتوى أو دورة الحياة، لكن لا يملك موجه إلى نموذج schema.
- **من شفرة المصدر توليد واحد نسخة تجميع في صيغة سياق صار هذا دليل**: مرفوض.AST قدرة بحث إلى تسجيل نقطة، لكن لا يمكن دفع قطع دلالة شرط، مثل تاريخ إبقاء، إخراج قطع قطع، أب فرعي مرئي صفة أو مساعد مساعدة نموذج حد. حزمة README هو تنفيذ محلي اتفاق؛ تجميع في فرعي هذا سوف زيادة أيضا واحد عائم نقل نقطة.
- **اشتراط إعطاء خروج دقيق token عدد**: مرفوض. دقيق عدد كمية أخذ قرار في الذي اختيار نموذج tokenizer، مهايئ تسلسل تحويل طريقة، إعداد و وقت التشغيل بيانات. مستقر اتفاق هو زيادة طويل شكل حالة: كل طلب ثابت، كل استدعاء شرط صفة، إبقاء، استبدال، لديه حد أعلى أو صفر مباشر أثر.
- **استخدام جدول إطار**: مرفوض. دقيق شفرة المصدر نص و شرط صيغة نتيجة شكل حالة سوف جعل وحدة إطار سري تجميع بينما صعب بـ مسح قراءة. تكرار صغير عقدة في إبقاء نفسه حقل معا، لـ كل سياق جدول وجه توفير سهل قراءة رأسي نحو فضاء.
- **سماح كل صفر أثر حزمة حذف هذا فصل عقدة**: مرفوض. بلا قيد ناقص في «مرور مراجعة حساب صفر أثر» و «نسيان تسجيل كتابة وثيقة» بين لديه اختلاف معنى. حذف فقط حد في في تحقق جهاز في بـ إدارة من تسمية نموذج غير متصل عام حزمة؛ نموذج متبادل مجاور صفر أثر حزمة إبقاء واحد جملة صريح شرح.
- **اشتراط مرور مراجعة حساب صفر فاعلية ينبغي حزمة أو بسيط مفرد بين وصل حزمة استخدام كامل بنية تحويل صيغة**: مرفوض. هو سوف محيط التفاف واحد واقع تكرار وسم. تلقي بوابة قيد جملة فرعي إضافة cache حقل حيث إبقاء صريح تغطية، أيضا لا يوجد كثير بقية جهاز صيغة.
- **فقط لديه معتاد مثال بينما بلا بوابة**: مرفوض. مستودع درجة اتفاق يجب تغطية لم قدوم كل حزمة؛ مراجعة من تسجيل ذاكرة لا يمكن يمكن اعتماد أرض فحص قياس إلى متروك تسرب README فصل عقدة.

## عاقبة

مراجعة من يمكن من أي موجه إلى نموذج أو مجاور قريب نموذج حزمة بدء، يرى هو مقابل محادثة نموذج، فرعي نموذج و مساعد مساعدة استدعاء مساهمة، بلا حاجة إعادة بناء كامل إضافة رسم.token ميزانية عمل يمكن منطقة قسم تكرار طلب فتح إلغاء و اعتماد بيانات تاريخ، بينما cache حساس شعور عمل يمكن تعرف آخر فقط إلحاق مسار، و الأكثر مبكر من حزمة جذب بدء طلب بادئة تغير موضع.agent نطاق تغيير لديه واضح وثيقة فحص نقطة. كل عند نموذج مرئي سلوك حدوث تغير وقت، حزمة عمل من كل يلزم صيانة واحد أو كثير عدد ضيق تجميع سياق بند كتلة، أو واحد نوع قد تصنيف قصير صيغة؛ مرور مراجعة حساب عام حزمة لا يحمل غير متصل نموذج مثال لوح. بنية تحويل حقل لا تحمل وعد من مزود إعطاء خروج دقيق token عدد أو cache أمر في؛ قياس كمية ما زال أخذ قرار في أداة جسم نموذج، مزود و عمل سالب تحميل، بينما الذي سجل زيادة طويل، مرئي صفة و بادئة مستقر صفة اتفاق إبقاء مستقر.
