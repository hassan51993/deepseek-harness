# Agent Note: دلالة تحويل Issue template و لا فحص عرض شكل صيغة policy

Status: implemented

[English](2026-09-03-semantic-issue-templates-and-policy.md) | العربية

## مشكلة

Issue و سحب أخذ طلب (Pull Request،PR)template يأخذ معلومة استلام تجميع مشكلة و مراجعة دليل خلط في واحد بدء، و استخدام `details` عنصر عنصر طي الكل محتوى. لم استخدام frontmatter و مستقل Idea و Research template زيادة اختيار، لكن لا يوجد تغيير مستودع قاعدة تخطيط هذه عمل طريقة.

Issue policy أيضا يأخذ Markdown عرض طريقة عند صار مستودع metadata. مقابل `details` عنصر عنصر،50 مفرد موضع مرئي متن، العربية عنوان، عنوان metadata بادئة و متن `Owner:` سطر اشتراط سوف إنتاج فشل، لكن لا يستطيع إشارة خروج نقص قليل أي بند دلالة قرار.

## قرار

Issue template فقط تغطية Bug،Feature و Task.Bug استلام تجميع ملخص، تكرار الآن طريقة، حالي سلوك، مسبق مدة سلوك و بيئة.Feature استلام تجميع حركة آلة و سلوك.Task استلام تجميع ملخص و تسليم شيء. حذف غير لم قدوم قرار لـ Idea و Research تعريف مختلف دورة الحياة سلوك، لا فإن هو جمع يخص Task.

Issue template frontmatter فقط يحتوي `name`،`about` و `type`.Markdown عنوان تعريف معلومة طبقة درجة،HTML ملاحظة تفسير شرح كل عنوان تحت ينبغي ملء كتابة محتوى.

PR template يتضمن `Motivation`، في `Changes` في متبادل مجاور ترتيب صف عام مشترك واجهة و سلوك تغير احتلال موضع شرح، و مباشر عرض كل بند اختبار طريقة و في نطاق جزء `details` عنصر عنصر في وضع وضع مقابل إثبات `Testing` بند.

Issue policy لا فحص `details` عرض شكل صيغة، مرئي متن طويل درجة، عنوان لغة، عنوان بادئة أو متن ownership سطر. أخرى كل policy فحص، تحذير إبلاغ، دورة الحياة عملية،workflow إطلاق شرط و PR قوي صنع نطاق إعفاء تجنب متساو إبقاء قائم سلوك. هذا بند قرار لا زيادة metadata تلقائي إصلاح،Issue تصنيف، بيانات ترحيل أو workflow قدرة.

## تحقق

[Issue إدارة اختبار](../../../../.github/issue-management/policy.test.mjs) ثابت template بيان و عنوان،PR اختبار بنية، و تحقق فقط عرض شكل صيغة مختلف عنوان، متن و assignee حالة يمكن عبر.

## اعتبار مرور بديل خطة

**إبقاء Idea و Research template.** هو جمع جدول مفرد لا يوجد بناء قيام منطقة آخر في Task دورة الحياة أو policy سلوك، لذلك مستقل مدخل فقط سوف زيادة اختيار، بينما لا يستطيع إبقاء متعمد معنى Type منطقة آخر.

**يأخذ عرض قاعدة إبقاء لـ تحذير إبلاغ.** هذه قاعدة سوف يجعل أصل هذا يمكن تنفيذ Issue فشل، أيضا لا يستطيع تحديد يحتاج طلب عمل، مسبق مدة سلوك أو تسليم شيء هل صاف واضح.

**زيادة metadata تلقائي إصلاح أو Issue تصنيف.** هذه سلوك حاجة جديد تعديل قاعدة، إذن، فشل معالجة و تشغيل دليل. هو جمع ينبغي بصفة مستقل قرار، بينما لا مع policy بسيط تحويل واحد نفس جذب دخول.

## عاقبة

مساهمة من سوف يرى أكثر قصير جدول مفرد، ذلك عنوان قسم آخر مقابل Issue معلومة استلام تجميع و PR مراجعة الذي يحتاج معلومة.Policy فشل سوف متابعة تجمع تركيز قائم دلالة metadata فحص.

Policy لن تعديل كتابة قديم وسم، اختيار ناقص Issue Type، تزامن Priority أو ترحيل قائم مستودع بيانات. هذه عملية لم قدوم مثل يحتاج تلقائي تحويل، يجب مفرد وحيد قرار و مراجعة.
