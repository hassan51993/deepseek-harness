# Agent Note: Issue سياسة اختيار صفة طلب قيمة

Status: implemented

[English](2026-09-07-selective-issue-policy-evaluation.md) | العربية

## مشكلة

معلومة نوع Issue مرجع توفير خلف مشهد، حل قرار نوع مرجع فإن حمل لديه Priority معنى خدمة. اثنان من كل اشتراط Project وصول، سوف يجعل غير متصل نظر لوح إعداد أو App متاح صفة منع توقف فقط توفير خلف مشهد PR(Pull Request). في تحديد قوي صنع نطاق قبل قراءة يتم مرجع Issue، أيضا سوف لـ غير ممكن قدرة بسبب سياسة بينما فشل PR إزالة استهلاك اعتماد و API طلب.

دورة الحياة حدث لديه مستقل صار هذا: دفعة دقيق، تقييم نقاش، دفع إرسال، وسم تغيير أو إشارة إرسال تغيير لا واحد تحديد حاجة تنفيذ Project حالة تسليم وصل. لـ معروف بلا عملية حدث قسم إعداد runner، سوف احتلال استخدام سعة كمية بينما لا تغيير Issue.

## قرار

[Issue policy](../../../../.github/workflows/issue-policy.yml) إبقاء مطلوب job و تلقي معلومة مهمة افتراضي فرع تنفيذ. قوي صنع نطاق حكم تحديد أولا في مرجع قراءة و Project App token إنشاء: مسودة مسودة PR،Bot/App عمل من، و حيث بلا مراجعة طلب أيضا بلا قد إيداع مراجعة شخص صنف PR متساو لا حاجة سياسة تحقق.

سير العمل في استدعاء أمر قبل فحص تلقي معلومة مهمة فحص خروج في اختيار صفة مسبق فحص قدرة علامة. نقص قليل علامة فحص خروج مقابل شخص صنف PR تنفيذ كامل قديم إصدار تحقق، و إبقاء قديم إصدار Bot/App إعفاء تجنب. هذا دعم حمل PR سير العمل YAML و نقص قليل مسبق فحص وظيفة افتراضي فرع شفرة إعداد دمج تنفيذ؛ تنفيذ خطأ لن إطلاق رجوع.

قوي صنع نطاق داخل PR عبر مستودع REST قراءة تحليل مرجع. معلومة نوع مرجع بلا حاجة Project وصول يكفي إثبات Issue هوية. فقط لديه حل قرار نوع مرجع إشارة نحو فعلي Issue حاجة قراءة Project Priority؛PR تحرير رقم حيث لا يستطيع ممتلئ كاف Issue مرجع اشتراط، أيضا لن جذب إرسال Project استعلام.[الذي تابع مشاركة اعتبار وثيقة](../../../../.github/issue-management/README.ar.md) تعريف بيانات وصفية تحقق و فشل سلوك.

[Issue lifecycle](../../../../.github/workflows/issue-lifecycle.yml) حجز قراءة و حالة متبادل صلة PR حدث، و مرور ترشيح فقط عنوان تحرير. هو لا حجز قراءة PR دفع إرسال،PR وسم تغيير أو Issue إشارة إرسال تغيير.job شرط في runner قسم إعداد قبل ترتيب حذف approved/commented مراجعة. طلب تعديل مراجعة إبقاء ذلك حالة أمر.

هذا ضبط درجة قرار جزء يحل محل[حدث قيادة مراجعة حالة](2026-08-10-event-directed-pr-review-status.ar.md) في بلا عملية job ضبط درجة طريقة، لكن لا يحل محل تسليم وصل دلالة أو شخص عمل حالة ملكية حفظ حماية.[Project نطاق جزء قاعدة تخطيط حقل](2026-09-02-project-local-issue-planning-fields.ar.md) ما زال يملك مقابل كل يتم مرجع Issue(يشمل معلومة نوع مرجع) فقط في PR فتح وقت، فقط مقابل فارغ قيمة ابتدائي تحويل Start Date قاعدة. تحقق قراءة إعفاء تجنب لا إعفاء تجنب هذا دورة الحياة mutation.

## اعتبار مرور بديل خطة

**قراءة كل يتم مرجع Issue Project حقل.** معلومة نوع مرجع لا قيد Priority، لذلك هذه استعلام فقط زيادة فشل اعتماد، لا مساهمة تحقق نتيجة.

**لـ دفعة دقيق و تقييم نقاش إبقاء نجاح بلا عملية دورة الحياة job.** هذا يمكن إبقاء أخضر لون job عرض، لكن سوف لـ لا يوجد دورة الحياة أمر حدث قسم إعداد runner. دورة الحياة و إبقاء مطلوب سياسة job متبادل متبادل مستقل.

**حذف مطلوب سياسة job أو إعادة تصميم فحص مرجعي مصدر.** اختيار صفة قراءة و دورة الحياة ضبط درجة يمكن نقص قليل يمكن تجنب تجنب عمل، بلا حاجة تغيير GitHub مدة انتظار مطلوب فحص. فحص مرجعي مصدر إعادة تصميم لا يخص هذا قرار.

## أثر

فقط يحتوي معلومة نوع مرجع تحقق حاجة مستودع وصول، لكن لا حاجة Project اعتماد. حل قرار نوع تحقق في الذي يحتاج Project قراءة أو حقل فحص فشل وقت ما زال سوف فشل. مسبق فحص و نهائي تحقق كل منها قراءة فوري REST حالة، تكرار مستودع طلب بينما لا ذاكرة مؤقتة ربط نقاش. تجنب تجنب Project قراءة و token إنشاء لا حفظ إثبات نقص قليل API طلب مجموع عدد. مطلوب سياسة job ما زال قسم إعداد runner؛ هو و غير صفر صار هذا مطلوب فحص.

صيانة من يد حركة إدارة Project ذاتي تعريف Priority حقل. أصلي Issue حقل skill إشارة جذب لن تحديث هذا قيمة. لا توفير Priority تزامن أو حقل ترحيل، أيضا لا تغيير[لا فحص عرض شكل صيغة سياسة](2026-09-03-semantic-issue-templates-and-policy.ar.md).

يتم حذف دورة الحياة حدث لا يستطيع إصلاح مرور وقت Project حالة. حدث إعادة وضع و تزامن كتابة ما زال لديه دورة الحياة و قاعدة تخطيط حقل وثيقة سجل تنافس حالة. فعلي Actions دقيقة عقدة حذف و GitHub App فعلي وصول إذن حاجة تشغيل تشغيل مراقبة، لا يستطيع من نموذج محاكاة API اختبار دفع قطع.

## تحقق

[سياسة اختبار](../../../../.github/issue-management/policy.test.mjs) تحقق مبكر مدة إعفاء تجنب، فقط استخدام REST معلومة نوع مرجع، فعلي Issue مرور ترشيح، حل قرار نوع Priority قراءة و فشل، و دورة الحياة أمر اختيار.[سير العمل اختبار](../../../../scripts/ci-workflow.spec.ts) تحقق Project token شرط، إبقاء مطلوب job، دقيق بسيط بعد حجز قراءة و runner درجة دورة الحياة مرور ترشيح. محلي fixture لا يستطيع إثبات فعلي webhook تسليم أو حساب استهلاك نتيجة.
