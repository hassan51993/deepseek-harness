# Agent Note: فقط master تنفيذ منصة CI

Status: implemented

[English](2026-09-06-master-only-platform-ci.md) | العربية

## Problem

macOS Intel،ARM و Linux ARM64 فوق Python وقت التشغيل بناء، و عبر Wine تنفيذ Windows بناء و شبكة محطة فحص، سوف في كل مرة سحب أخذ طلب إصلاح حجز وقت إزالة استهلاك دفع استهلاك حمل إدارة سعة كمية. أصلي Linux و Windows x64 قد توفير مطلوب يمكن تنفيذ ملف و تثبيت بعد wheel حزمة دليل، أصلي Windows فحص أيضا سوف في دمج قبل تغطية بناء و عملية سلوك.

## Decision

[CI](../../../../.github/workflows/ci.yml) اشتراط Linux x64 و Windows x64 فوق Python وقت التشغيل تحقق.[CI master](../../../../.github/workflows/ci-master.yml) فقط في master دفع إرسال وقت عبر نفس يمكن إعادة استخدام بناء جهاز اختيار Linux ARM64،macOS ARM64 و macOS x64. اثنان عدد استدعاء جهة متساو نقل دخول `ci: true` و صريح خارجي API مفتاح، إبقاء كامل بلا مفتاح تثبيت بعد wheel حزمة مشهد و يمكن معلومة live اختبار واضح فشل.Fork و Dependabot سحب أخذ طلب ما زال لا حمل مفتاح؛ تشغيل جهاز معلومة مهمة و رجوع اختيار جهاز إبقاء ثابت.Python إصدار إبقاء الكل خمسة عدد هدف.

Wine بصفة مستقل حمل إدارة Ubuntu master عمل عمل تشغيل مرة. ذلك قائم حسب مرآة مثل معرف apt ذاكرة مؤقتة استعادة و حفظ أيضا مسؤول توليد افتراضي فرع ذاكرة مؤقتة، لذلك لا حاجة مفرد وحيد ذاكرة مؤقتة مسبق حار عمل عمل. أصلي Linux و Windows سلسلة سطر تجمع دمج لا استدعاء Wine.Wine إبقاء حمل إدارة تشغيل، تجنب تجنب في حمل دائم Linux VM فوق تنفيذ مشترك مضيف آلة apt أمر خدمة و مشترك Wine prefix تنظيف. نص برمجي مسؤول مؤقت لقطة،checkout داخل Wine prefix و مرور مرور تحقق و تحقق Windows Node ذاكرة مؤقتة؛ بيئة دقيق تجهيز، فشل نقل بث و بداية نهاية تنفيذ تنظيف إبقاء ثابت.

[يتم يحل محل CI إلغاء سياسة](2026-09-09-cancel-superseded-ci.zh.md) ملائم لأجل أب سير العمل و يمكن إعادة استخدام وقت التشغيل سير العمل: تحديث master دفع إرسال أو يد حركة تشغيل سوف إلغاء نفس سير العمل/مرجع مجموعة داخل قديم تحقق، بينما إصدار الذي تابع بناء ما زال تلقي حفظ حماية.master دفع إرسال سوف ضبط درجة الكل ثلاثة عدد اختيار تحديد تحميل جسم، لكن لا حفظ إثبات كل في بين إيداع كل نيل إلى نتيجة.

هذا قرار جزء يحل محل[تثبيت بعد wheel حزمة تحقق](../testing/2026-08-23-installed-python-wheel-black-box-ci.zh.md) ،[أصلي Windows CI](2026-08-08-native-windows-pull-request-ci.zh.md) ،[سلسلة سطر مشاركة اعتبار](2026-07-21-serial-cross-platform-ci-reference.zh.md) و[لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.zh.md) في ضبط درجة سياسة. هذه سجل ما زال إبقاء ناتج مصدر، منصة حفظ حق درجة، سلسلة سطر كامل صفة و معلومة مهمة قاعدة قرار قيمة قيمة.

## Alternatives considered

**في سحب أخذ طلب فوق إبقاء الكل هدف و Wine مطلوب فحص.** هذا قدرة في دمج قبل اكتشاف منصة خاص تحديد نقص وقوع، لكن سوف في كل مرة إصلاح حجز وقت تكرار دفع استهلاك أصلي بناء. الذي اختيار سياسة واضح قبول هذا أربعة بند فحص في دمج بعد اكتشاف مشكلة.

**انتظار إلى إصدار أو اشتراط يد حركة إرسال إرسال.** هذا سوف فقد ذهاب تلقائي افتراضي فرع إشارة.master دفع إرسال إبقاء تحديد مدة إطلاق فحص، لا تقليص نقص إصدار مستطيل دفعة.

**يأخذ Wine دمج دخول ذاتي حمل إدارة سلسلة سطر تجمع دمج.** تجمع دمج لم تغطية Wine. إضافة دخول هو سوف تغيير حمل دائم مضيف آلة اعتماد، مشترك ذاكرة مؤقتة ملكية و تنظيف عزل؛ هذا مرة ضبط درجة أفضل تحويل لا حاجة هذا نوع ترحيل.

## Consequences

macOS،Linux ARM64 أو Wine خاص تحديد ارتداد ممكن في مطلوب PR فحص لـ أخضر وقت دمج.master فشل ما زال هو عادي فشل عمل عمل، لا هو `continue-on-error` مراقبة قياس بند.Linux/Windows x64 تثبيت بعد wheel حزمة فحص و أصلي Windows بناء و عملية فحص متابعة منع سد PR تجمع دمج؛ ذلك اعتماد أبدا مرجع قد إزالة Wine PR عمل عمل.

[توجيه ارتداد اختبار](../../../../scripts/tests/ci-master-platforms.spec.ts) عبر قائم نص برمجي spec نسبة التغطية بيان تشغيل، فحص هدف تخطيط قسم، فقط master شرط، اعتماد نقل تمرير، إلغاء،Wine وحيد صفة، تجمع دمج اعتماد صالح صفة و كامل إصدار مستطيل دفعة. قد تنفيذ سالب مقابل وفق إزالة Intel هدف، خطأ توجيه Wine و استعادة بطلان تجمع دمج اعتماد؛ كل بند متساو إنتاج مسبق مدة فشل. حقيقي منصة تنفيذ ما زال من CI مسؤول؛ محلي ضبط درجة اختبار لا صوت تسمية تنفيذ أصلي وقت التشغيل أو Wine.
