Status: implemented

## مشكلة

PR(Pull Request) معاينة بناء كامل مساحة العمل و متصفح worker VFS مرآة مثل. مقارنة منخفض كل قسم ساعة تشغيل جهاز قيمة إطار لا يستطيع حفظ إثبات مقارنة منخفض عمل عمل صار هذا، لأن GitHub سوف كل عمل عمل نحو فوق أخذ كامل حتى كامل قسم ساعة. سوف معاينة نقل حتى حفظ دائم ذاتي حمل إدارة آلة جهاز أيضا سوف تغيير عزل طريقة، لا يخص هذا قرار نطاق.

## قرار

[معاينة سير العمل](../../../../.github/workflows/build-preview-cloudflare.yml) استخدام معيار GitHub حمل إدارة `ubuntu-24.04`. بناء، ذاكرة مؤقتة، نشر، تلقي حفظ حماية مرآة مثل تحقق و تقييم نقاش دلالة إبقاء ثابت.[قاعدة إطار مشاركة اعتبار](../../../../.github/preview-sizing/README.zh.md) مسؤول مقارنة مقارنة اشتراط. مستقل CI [لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.zh.md) إبقاء ذلك تشغيل جهاز تبديل قرار؛ معاينة لا استخدام هذه فتح صلة.

### قياس كمية

فعلي تحقق 34012729982 ثمانية نوع قاعدة إطار/ذاكرة مؤقتة تركيب و واحد ذاكرة مؤقتة مسبق حار عمل عمل متساو نجاح. كل قياس كمية عمل عمل فحص خروج نفس عدد فعلي تحقق إصلاح حجز، استخدام Node 24.19.0 و pnpm 11.7.0، و تنفيذ غير ممكن تغيير تثبيت، كامل مساحة العمل بناء، معاينة/VFS تحزيم، و يحتوي gzip كامل صفة تحقق محلي فوق نقل محتوى كامل إدارة. حار عمل عمل استعادة نفس عدد تشغيل خاص دقيق pnpm ذاكرة مؤقتة؛ بارد عمل عمل قفز مرور استعادة، لكن يتضمن pnpm جذب توجيه تثبيت ملف. لا استعادة تحرير ترجمة ناتج.

حسب[عام استهلاك معدل](https://docs.github.com/en/billing/reference/actions-runner-pricing) ، قياس كمية عمل عمل دمج حساب $0.504؛60 ثانية معيار مسبق حار عمل عمل زيادة $0.006.$0.510 مجموع حساب حساب استهلاك استخدام تقدير حساب يتضمن ضبط، استعادة، قياس كمية فوق نقل و تنظيف، لكن لا يحتوي تخزين و حساب مستخدم طي خصم. في كل نوع أخذ مثال ذاكرة مؤقتة حالة تحت، معيار تشغيل جهاز مقارنة 16 نواة منخفض 80.95%، مقارنة 4 نواة منخفض 33.33%. متبادل مقارنة مقابل 16 نواة عمل عمل زيادة 78 ثانية.

معيار عمل عمل توفير اثنان عدد vCPU و 7.75 GiB داخل تخزين. مساحة العمل الأكثر كبير عملية RSS لـ 2.86 / 2.76 GiB؛ معاينة الأكثر كبير عملية RSS لـ 0.76 / 0.74 GiB. اثنان من متساو لم حدوث OOM أو مهلة و إتمام.GNU time RSS لا هو عملية شجرة معا احتلال استخدام داخل تخزين مجموع كمية. هذه مثال هذا إثبات نجاح تنفيذ، بينما غير دائم دائم داخل تخزين حفظ إثبات.

مقارنة مقارنة ثابت مصدر شفرة، قفل ملف، أمر و وقت التشغيل إصدار، لكن لا ثابت شيء إدارة CPU أو مرآة مثل إصدار: معيار و 4 نواة استخدام مرآة مثل 20260831.293.1؛8 نواة و 16 نواة استخدام 20260823.283.1.CPU يشمل AMD EPYC 9V74/7763 و Intel Xeon 8370C/8573C. كل نوع ذاكرة مؤقتة حالة مفرد عدد مثال هذا قياس كمية الذي توفير وسم، بينما غير مستقل CPU توسيع صفة أو موحد حساب يمكن تكرار صفة.

فعلي تحقق لا نشر، أيضا لا وصول Cloudflare اعتماد. قياس كمية فوق نقل استهلاك وقت صفر حتى واحد ثانية؛ حار ذاكرة مؤقتة استعادة استهلاك وقت ستة حتى عشرة ثانية. بصفة خلف مشهد، إنتاج عمل عمل 101428009994 (run 34011495156) في مختلف SHA فوق فوق نقل استهلاك وقت 14 ثانية، تحقق واحد ثانية، تقييم نقاش اثنان ثانية. سوف هذا فتح إلغاء إضافة حتى هذا فعلي تحقق يخص دفع حساب، بينما غير قد قياس كمية معيار تشغيل جهاز إصدار نتيجة. فعلي PR معاينة سير العمل مسؤول نشر تأكيد.

## اعتبار مرور بديل خطة

**إبقاء 16 نواة.** هو توفير الأكثر قصير قياس كمية عمل عمل، لكن لـ 78 ثانية تعديل حسن جعل كل مثال هذا زيادة $0.102. مقابل في هذا مرة بـ صار هذا لـ إعادة نقطة قرار، معاينة بناء لا قيمة نيل هذا بند فيض قيمة.

**اختيار 4 نواة أو 8 نواة.** اثنان من متساو نجاح و تقليص قصير بناء، لكن أخذ كامل بعد مثال هذا استهلاك استخدام عال في معيار Ubuntu. إذا لم قدوم عمل سالب تحميل استهلاك كل معيار سعة كمية،4 نواة يمكن إبقاء أكثر كثير داخل تخزين و مغناطيس قرص بقية كمية؛ هذا مثال تغيير حاجة جديد قياس كمية.

**نقل حتى ذاتي حمل إدارة.** بسبب نطاق حد بينما رفض: معاينة إبقاء في GitHub CI. قائم Linux و Windows تسجيل نسخة ممكن مشترك حفظ دائم رئيسي آلة؛ ذلك اعتماد،store لفة و تنظيف زائف ضبط لا ملائم لأجل كل جديد حمل إدارة VM. لا تغيير لذا عائق تبديل أو معلومة مهمة شرط.

## أثر

معاينة بـ نحو 78 ثانية أخذ مثال بناء عمل عمل تأخير متأخر تبديل أخذ أكثر منخفض حساب حساب استهلاك استخدام. إنتاج Cloudflare تأخير متأخر، مرآة مثل إصدار فرق مختلف، لم قدوم بناء زيادة طويل و أكثر واسع عام نجاح معدل ما زال هو يمكن مراقبة قياس حد. لا من هذا مرة مفرد واحد فعلي تحقق خارج دفع كل صغير وقت أو كل شهر عقدة حذف. نهائي ملف شجرة لا يتضمن مؤقت أساس دقيق سير العمل و ذلك أمان اختبار؛ فعلي تحقق إيداع و رابط تشغيل إبقاء طريقة و دليل.

قد تنفيذ[إبرة مقابل صفة ارتداد](../../../../scripts/preview-workflow.spec.ts) ثابت حمل إدارة توجيه،PR إطلاق جهاز و إذن، غير ممكن تغيير كامل بناء، فقط استعادة ذاكرة مؤقتة، إصدار محتوى كامل إدارة، تلقي حفظ حماية مرآة مثل فحص و قوة انتظار تقييم نقاش. فعلي تعديل لـ ذاتي حمل إدارة توجيه سوف جعل توجيه تأكيد فشل؛ استعادة بعد الكل ثلاثة عدد اختبار عبر. لا تغيير نموذج مرئي وقت التشغيل سلوك، لذلك لا حاجة تعديل Session لقطة.
