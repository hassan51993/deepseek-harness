# Agent Note: حسب ملف مسار تعرف آخر مراجعة دفعة مراجعة سير العمل

Status: implemented

[English](2026-09-10-approval-review-workflow-identity.md) | العربية

## مشكلة

GitHub ممكن استخدام توسيع بعد `run-name` ملء ملء سير العمل تشغيل `name`. مراجعة دفعة مراجعة سير العمل في هذا عنوان في يتضمن سحب أخذ طلب تحرير رقم، لذلك سوف `workflow_run.name` و ساكن حالة سير العمل اسم مقارنة مقارنة، سوف في تحديث جديد مراجعة دفعة حالة قبل رفض صالح مراجعة حدث.

## قرار

[مراجعة دفعة إصدار جهاز](../../../../.github/review-ownership/check-approval.mjs) حسب دقيق `workflow_run.path` تعرف آخر مراجعة حدث سير العمل. هو أيضا اشتراط هذا تشغيل من `pull_request_review` إطلاق كما نجاح إتمام، من `display_title` تحليل سحب أخذ طلب تحرير رقم، تحقق توفير سحب أخذ طلب صلة ربط، و في حساب حساب مراجعة دفعة نتيجة قبل سوف سحب أخذ طلب حالي رأس إيداع و قد مراجعة رأس إيداع إجراء مقارنة مقارنة.

## اعتبار مرور بديل خطة

**قبول اسم بادئة.** عرض اسم لا يمكن تعرف آخر سير العمل ملف؛ آخر عدد سير العمل يمكن استخدام نفسه عنوان.

**حذف حمل تحرير رقم تشغيل عنوان.** عند GitHub إرجاع فارغ `pull_requests` عدد مجموعة وقت، عنوان توفير سحب أخذ طلب تحرير رقم. حذف هو حاجة آخر نوع نقل تمرير آلية.

## أثر

تشغيل عنوان توسيع لن منع توقف مراجعة دفعة تحديث جديد، بينما غير مسبق مدة سير العمل ملف ما زال لا يمكن عبر تحقق. نقل حركة مراجعة حدث سير العمل وقت، حاجة تحديث إصدار جهاز مسبق مدة مسار.

[مراجعة دفعة سياسة اختبار](../../../../.github/review-ownership/check-approval.test.mjs) تغطية حمل تحرير رقم تشغيل اسم، بلا فاعلية مصدر مسار و حدث، لم نجاح تشغيل، بلا فاعلية عنوان و قد يتم بديل رأس إيداع.[مراجعة دفعة نتيجة سياسة](2026-09-09-blocked-weighted-approvals-remain-pending.ar.md) متابعة مسؤول انتظار تحديد و نجاح حالة دلالة.
