# Agent Note: يجعل Lefthook تثبيت حد تحديد في كل worktree

Status: implemented

[English](2026-07-27-worktree-local-lefthook.md) | العربية

## مشكلة

كل مرة تشغيل `pnpm install` كل سوف تنفيذ أصل دليل [`postinstall`](../../../../package.json) ، منها [`install-lefthook.mjs`](../../../../scripts/install-lefthook.mjs) سوف استدعاء `lefthook install --force`. إذا بلا مقدار خارج إعداد، صلة ربط Git worktree مشترك استخدام نفس مستودع افتراضي خطاف دليل، لذلك في مهمة واحد worktree في تثبيت كل ممكن تعديل كتابة أخرى كل worktree استخدام خطاف.

Lefthook توليد خطاف سوف أولوية استخدام تثبيت وقت من مقابل worktree سجل قطعا مقابل اثنان دخول صنع ملف مسار، بعد عندئذ محاولة تجربة حالي worktree رجوع مسار. لذلك، مشترك خطاف سوف واحد مباشر تشغيل آخر عدد worktree ثابت إصدار اثنان دخول صنع ملف، مباشر إلى هذا worktree إزالة فقد؛ تزامن تثبيت أيضا سوف كتابة نفس مجموعة ملف.

## قرار

خطاف تثبيت بـ worktree لـ أثر مجال. عند `CI=true` أو `GITHUB_ACTIONS=true` وقت، تثبيت برنامج سوف في استكشاف قياس Git أو فعل خروج أي تغيير قبل إرجاع، لأن تلقائي تحويل مهمة لن استخدام مساهمة من خطاف. لا فإن، تثبيت برنامج اشتراط Git 2.26 أو أكثر عال إصدار، جعل `git config --show-scope` يمكن تقرير إبلاغ من أي عدد أثر مجال توفير إعداد قيمة؛ هو سوف سوف صيغة إصدار لـ 0 مستودع ترقية إلى صيغة إصدار 1، تفعيل `extensions.worktreeConfig`، و سوف حالي worktree `core.hooksPath` ضبط لـ إشارة نحو `$GIT_DIR/dsh-hooks` قطعا مقابل مسار.

ترقية صيغة 0 قبل، تثبيت برنامج سوف رفض مشترك استخدام إعداد في مباشر ضبط `extensions.*`؛ هو أيضا سوف رفض مباشر ضبط `core.worktree` أو `core.bare=true`، و تفعيل توسيع بعد سوف يتم تنشيط غير فارغ راحة نوم worktree إعداد. ترحيل سوف إزالة مباشر ضبط `core.bare=false`، لأن false هو Git قيمة افتراضية. مشترك استخدام مستودع إعداد و كل قد لديه `config.worktree` كل يجب هو معتاد قاعدة ملف. هذه فحص سوف منع استخدام include توسيع، لأن Git مستودع صيغة محلل أيضا سوف تجاهل اختصار include هدف. مستودع درجة قفل سوف سلسلة سطر تحويل ترحيل و خطاف كتابة؛ تحرير وقت، قفل عملية ID، مع آلة أمر لوحة، ملف هوية و كامل محتوى يجب ما زال مطابقة. الذي تابع عملية قد انتهاء أو محتوى بلا فاعلية قفل يجب شخص عمل وسيط دخول استعادة، بينما لا يستطيع تلقائي قوي صنع حل حذف.

كل خطاف دليل كل لديه واحد JSON كل حق علامة، منها يتضمن فوق مرة كتابة worktree إعداد قطعا مقابل مسار. فحص خروج دليل نقل حركة بعد، هذا علامة فقط سماح استبدال تأكيد قطع قديم قديم ذاتي لديه قيمة.Git سوف بـ رئيسي worktree إعداد لـ جديد رابط worktree ابتدائي تحويل `config.worktree`؛ عند هذا ابتدائي إعداد يتضمن بعض عدد قد تسجيل worktree في من كل حق علامة مساعدة إثبات إبقاء خطاف مسار وقت، تثبيت برنامج فقط سوف في جديد worktree إعداد في سوف ذلك استبدال لـ جديد worktree ذاتي لديه مسار.Lefthook تشغيل قبل، كل حق علامة و كل قد لديه توليد خطاف كل يجب هو لا حمل آخر اسم معتاد قاعدة ملف. تثبيت برنامج سوف تحليل `core.hooksPath` توليد فاعلية أثر مجال، مصدر و قيمة، يشمل عبر حالي توليد فاعلية `config.worktree` include تحميل قيمة؛ هو سوف رفض أمر أثر مجال مسار، غير ذاتي لديه worktree أثر مجال مسار و غير ذاتي لديه إبقاء دليل. وراثة ذاتي نظام، عام أو مشترك استخدام مستودع إعداد مسار يجب ضبط `DSH_LEFTHOOK_ALLOW_HOOKS_PATH_OVERRIDE=1`، من بينما فقط يجعل حالي worktree صريح تفعيل Lefthook. لم توليد فاعلية `includeIf` هدف لن يتم تمرير عودة فحص، لأن هو جمع لا أثر حالي إعداد. إتمام تحقق بعد،Lefthook عملية فرعية بيئة سوف إزالة أمر أثر مجال Git إعداد.

إذا Lefthook في أكثر تعديل `core.hooksPath` بعد فشل، تثبيت برنامج سوف استعادة أولا قبل worktree قيمة؛ إذا تراجع فشل، سوف و تثبيت فشل واحد و تقرير إبلاغ.`$GIT_COMMON_DIR/hooks` في قائم ملف أبدا سوف يتم إزالة أو تعديل كتابة. لديه إبرة مقابل صفة تثبيت برنامج اختبار قفل تحديد التالي سلوك: عزل، مقابل نسخ بينما قدوم جديد worktree إعداد معالجة، ترحيل رفض، كل حق و فحص خروج دليل نقل حركة، تزامن تثبيت، ذاتي تعريف مسار و تراجع.

## اعتبار مرور بديل خطة

**إبقاء مشترك توليد خطاف، و اعتماد ذلك حالي worktree رجوع مسار.** فقط يلزم مقابل worktree ما زال وجود، سجل قطعا مقابل مسار حينئذ سوف أولوية توليد فاعلية، لذلك رجوع مسار لا يمكن توفير إصدار أو دورة الحياة عزل.

**يجعل كل worktree كل إشارة نحو نفس عدد قبول دخول إصدار تحكم `.githooks` دليل.** استخدام تلقي إصدار تحكم متبادل مقابل دليل يمكن إزالة حذف توليد قطعا مقابل مسار، لكن أكثر تعديل مشترك `core.hooksPath` ممكن سوف منع استخدام قديم worktree في خطاف، لأن ذلك فرع و لا يتضمن هذا دليل؛ معا، كل worktree ما زال اقتران دمج في نفس عدد مشترك إعداد قيمة.

**بناء عام خطاف إدارة جهاز سلسلة ربط طبقة.** تنفيذ ترتيب، معامل تحويل إرسال، فشل دلالة و ترقية كل سوف يصبح مستودع ذاتي سطر مسؤول سلوك، لكن و Lefthook عزل غير متصل. لذلك، تثبيت برنامج سوف رفض worktree مخصص تابع ذاتي تعريف مسار، فقط سوف نطاق أكثر ضيق وراثة مسار تغطية ضبط لـ صريح عملية.

**سوف خاص تحديد CI توفير تجارة اعتماد include مسار إضافة دخول أبيض اسم مفرد.**CI لا استخدام مساهمة من خطاف، لذلك مسار إعفاء تجنب سوف جعل تثبيت برنامج أمان صفة اقتران دمج في CI توفير تجارة فحص خروج مسار داخلي تنفيذ، و تقليل ضعيف مساهمة من تثبيت وقت صارم إطار تحقق. في CI في مباشر قفز مرور عملية، بلا حاجة أي إعفاء تجنب يكفي تجنب تجنب تعديل مستودع.

**إيقاف تلقائي تثبيت خطاف.** يد حركة ضبط يمكن تجنب تجنب مشترك كتابة، لكن سوف جعل مستودع في منخفض صار هذا إيداع و دفع إرسال فحص معنى خارج تغيير صار اختياري بند، قصير مدة وجود، من agent(ذكي جسم) استخدام worktree خاصة ذلك سعة سهل تلقي إلى أثر.

## عاقبة

تثبيت أو إزالة مهمة واحد worktree لم يعد تغيير أخرى worktree توليد فاعلية خطاف، اثنان دخول صنع ملف مسار أو توليد خطاف بايت. تزامن تثبيت سوف سلسلة سطر تنفيذ، تكرار تثبيت إبقاء قوة انتظار؛[سريع سرعة محلي Git خطاف](../../archived/process/2026-07-22-fast-local-git-hooks.md) الذي قاعدة تحديد مهمة و تأخير متأخر حد إبقاء ثابت.

أول مرة تثبيت بعد، مستودع سوف اعتماد Git صيغة إصدار 1. تثبيت برنامج حاجة Git 2.26 قدوم استخدام `--show-scope`؛worktree إعداد توسيع ذاته ظهور مبكر في هذا أمر. ذاتي تعريف worktree خطاف إدارة جهاز حاجة واضح اختيار تجميع صار طريقة؛ وراثة خطاف مسار يمكن متابعة توفير أخرى worktree استخدام، لكن حالي worktree صريح تفعيل Lefthook بعد، منها لن تشغيل هذه وراثة خطاف، حذف غير مساهمة من عبر `lefthook.yml` سوف ذلك سلسلة ربط بدء قدوم.

قديم مشترك استخدام خطاف سوف لـ بعد لم ترقية worktree إبقاء في مغناطيس قرص فوق. هو جمع ممكن تدريجي تدريجي قديم قديم، لكن تلقائي حذف هذه خطاف سوف كسر تالف قد تسجيل لكن الذي في فرع بعد لم اعتماد هذا تثبيت برنامج worktree.
