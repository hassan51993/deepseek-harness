# Agent Note: بلا حاجة توليد بحث جذب يكفي اكتشاف Agent Note

Status: implemented

[English](2026-07-19-remove-generated-agent-note-index.md) | العربية

## مشكلة

إيداع إلى مستودع Agent Note بحث جذب، سوف تكرار سجل كل ملف دورة الحياة/صنف آخر مسار، ملف اسم يوم مدة و H1 قد تحرير رمز واقع. أي فرع فقط يلزم إضافة، نقل حركة أو إعادة تسمية ذاك هذا غير متصل Agent Note، كل سوف إعادة كتابة نفس عدد توليد ملف، لذلك هذا ناتج سوف يصبح يمكن مسبق رؤية دمج اندفاع مفاجئ حار نقطة.

و تصفح تصفح دورة الحياة/صنف آخر دليل شجرة أو بحث مستودع متبادل مقارنة، هذا نسخة تجميع في صيغة وقت ترتيب بيان توفير اكتشاف قيمة قيمة لديه حد؛ لكن ذلك توليد جهاز، مصير، أمر و جديد طازج درجة فحص ما زال بنية صار صيانة سالب تحمل.

## قرار

حسب دورة الحياة/صنف آخر مجموعة نسج نظام الملفات دليل شجرة حينئذ هو Agent Note بيان.[README.md](../../README.ar.md) متابعة بصفة شخص عمل صيانة مدخل و اتفاق، عادي دليل شجرة تصفح تصفح و مستودع بحث مسؤول محتوى اكتشاف.

`scripts/agent-note-tree.ts` يحتفظ غلاف إغلاق دورة الحياة/صنف آخر تجميع دمج و بنية مرة تاريخ جهاز.`verify-agent-note-classification` تحقق هذا دليل شجرة، و رفض قديم دليل و أصل دليل في `INDEX.md`، لكن لن تصيير تجميع في صيغة بيان أو فحص ذلك جديد طازج درجة.

## تجهيز اختيار خطة

**إبقاء إيداع إلى مستودع توليد بحث جذب، و عبر إعادة توليد حل قرار اندفاع مفاجئ.** إعادة توليد قدرة يجعل اندفاع مفاجئ حل قرار مرور مسار آلة آلة تحويل، لكن لا يمكن منع توقف غير متصل فرع تعديل نفس ناتج، أيضا لن نقص قليل من هذا إنتاج مراجعة ضجيج صوت.

**توفير لا إيداع إلى مستودع حسب يحتاج بحث جذب أمر.** هذا يمكن تجنب تجنب قد إيداع ملف اندفاع مفاجئ، لكن ما زال يحتاج صيانة مصير و أمر، بينما دليل شجرة تصفح تصفح و مستودع بحث قد تغطية هذا اكتشاف مسار.

**استعادة شخص عمل صيانة بحث جذب.** هو نفس مثال سوف صنع صار مشترك ملف تنازع استخدام، أيضا سوف إعادة جذب دخول توليد آلية قد تجنب تجنب كامل صفة و ترتيب ترتيب خطأ.

## أثر

- إضافة، نقل حركة أو إعادة تسمية Agent Note وقت، لم يعد تعديل تغطية كامل لغة مادة مكتبة توليد ملف.
- تصنيف بوابة تنفيذ عمل أكثر قليل، وثيقة بوابة توسيع اندفاع أيضا بلا حاجة زيادة عملية أو مرحلة مقطع.
- قراءة من لم يعد نيل نيل مفرد واحد وقت ترتيب صفحة، تعديل استخدام دورة الحياة/صنف آخر دليل شجرة أو مستودع بحث.
