# Agent Note: Issue سياسة وحدة ملكية

Status: implemented

[English](2026-09-07-issue-policy-module-ownership.md) | العربية

## مشكلة

Issue تحقق و Project دورة الحياة معالجة استخدام نفسه مرجع محلل، بيانات وصفية قاعدة و GitHub قراءة، لكن كل منها عمل خروج مختلف قرار، تنفيذ مختلف كتابة. سوف هذه مسؤولية وضع في أمر مدخل في، سوف جعل إعادة استخدام سياسة قاعدة وقت أكثر صعب وضع انفصال مقابل حدث قسم إرسال و إخراج معالجة اعتماد.

## قرار

Issue إدارة سوف صاف قرار،GitHub وصول،PR(Pull Request) طلب قيمة، دورة الحياة mutation و أمر قسم إرسال قسم إعداد إعطاء كل منها الذي تابع وحدة.[الذي تابع مشاركة اعتبار وثيقة](../../../../.github/issue-management/README.zh.md#module-ownership) سوف هذه مسؤولية مقابل إلى مصدر ملف. استدعاء جهة و اختبار مباشر استيراد يملك هذا عملية وحدة، لا يأخذ أمر مدخل استخدام عمل توجيه خروج تجميع دمج.

هذا مسؤولية قسم مغادرة إبقاء سياسة نتيجة، تشخيص، اعتماد،API طلب، دورة الحياة mutation و سير العمل مدخل أمر.[اختيار صفة طلب قيمة](2026-09-07-selective-issue-policy-evaluation.zh.md) ما زال مستقل يملك قوي صنع نطاق،Project قراءة اختيار و حدث ضبط درجة قاعدة؛ هذا قرار لا إعادة تعريف هذه سلوك.

## اعتبار مرور بديل خطة

**إبقاء مفرد واحد أمر وحدة.** مفرد ملف يمكن تجنب تجنب محلي الذي تابع وحدة بين استيراد، لكن سوف يأخذ يمكن إعادة استخدام قرار و GitHub وصول ربط إلى أمر معالجة. مستقل الذي تابع وحدة يجعل PR تحقق و دورة الحياة معالجة يمكن مشترك قائم قاعدة و قراءة، بينما بلا حاجة مشترك أمر قسم إرسال.

## أثر

صيانة من يمكن حسب مسؤولية تحديد موضع قاعدة، شبكة شبكة عملية أو حدث معالج. إعادة استخدام عبر عادي محلي ESM استيراد إتمام، بينما لا هو إضافة جديدة حزمة أو إضافة API. إضافة جديدة وحدة جذب دخول استيراد علاقة حاجة في مشترك دالة تغيير وقت تزامن صيانة.

وحدة قسم مغادرة لن منح إعطاء أكثر قوي اعتماد، أكثر تعديل فحص مرجعي مصدر، سلسلة سطر تحويل Project mutation، أيضا لا يستطيع منع توقف لم قدوم سلوك ارتداد. قائم دورة الحياة تنافس حالة و حقل إدارة حد ما زال من كل منها سلوك وثيقة سجل.

## تحقق

[سياسة اختبار](../../../../.github/issue-management/policy.test.mjs) تشغيل الذي تابع وحدة، و فحص يمكن مراقبة سياسة و دورة الحياة سلوك.[سير العمل اختبار](../../../../scripts/ci-workflow.spec.ts) تغطية أمر وصل خط و سير العمل إعلان. هذه دليل إبرة مقابل يتم فحص تنفيذ، لا حفظ إثبات لاحق تحرير ما زال إبقاء سلوك.
