# Agent Note: سوف لم قدوم إشارة توجيه قيمة قيمة مقارنة منخفض Agent Note تجميد ربط في نشط وثب سجل تجميع دمج خارج

Status: implemented

[English](2026-07-26-frozen-agent-note-archive.md) | العربية

## مشكلة

implemented Agent Note بصفة حالي قرار سجل حمل متابعة صيانة، لذلك نشط وثب سجل تجميع دمج في كل مسار، رمز رقم، قيمة افتراضية، ترجمة نص، محيط شريط شفرة كتلة، حزمة مرجع و خروج محطة رابط كل سوف شكل صار صيانة معنى خدمة. عند قرار اعتماد حسب يمكن إشارة توجيه لم قدوم عمل وقت، هذا بند صار هذا دمج إدارة؛ لكن مقابل في قد استلام ذيل UI دقيق عقدة، صغير نوع إصلاح، قد يتم يحل محل تنفيذ آلية، أو حالي مرجعي اعتماد حسب قد تحويل نقل إلى آخر موضع مسار تاريخ، هذا بند صار هذا و لا قيمة نيل. حذف كل منخفض قيمة قيمة قد فعلي تطبيق سجل سوف مسح ذهاب لديه استخدام تاريخ دليل، بينما إبقاء كل واحد بند يتم مرفوض رفع سجل، أيضا سوف إبقاء تحت حيث بلا قبول ممكن أيضا بلا بدء إرسال معنى معنى تفكير قاعدة. هذا طقم سجل تجميع دمج حاجة واحد طريق إبقاء تخزين حد، في منطقة قسم نشط وثب إشارة توجيه و تجميد ربط تاريخ معا، تجنب تجنب يجعل عودة ملف يصبح آخر عدد صيانة طبقة درجة.

## قرار

فقط لديه implemented Agent Note يمكن عودة ملف. عند واحد نسخة قد فعلي تطبيق سجل تسليم قرار قد كامل سقوط أرض، كما ذلك قرار اعتماد حسب، تجهيز اختيار خطة، عاقبة، لا تحديد صفة حفظ إثبات و إعادة جذب دخول شرط لا جدا ممكن مجددا إشارة توجيه لم قدوم عمل وقت، سوف ذلك نقل دخول عودة ملف. أساس أساس صفة حد، حمل دائم دلالة و بروتوكول دلالة، أمان قاعدة، عكس تكرار ظهور كما نظر يشبه إغراء شخص تصميم اختيار و بعد لم حل قرار إعادة جذب دخول شرط، بلا نقاش سجل تخزين متابعة وقت أو حرف عدد مثل أي، كل متابعة بصفة نشط وثب سجل إبقاء.proposed Agent Note أبدا دخول عودة ملف؛ مرور وقت رفع سجل ينبغي تحويل لـ rejected. فقط عند rejected Agent Note ما زال قدرة تجنب تجنب واحد نوع إغراء شخص كما أثر إعادة كبير خطأ وقت إبقاء، لا فإن سوف ذلك ثلاثة عدد إعداد مقابل ملف كامل حذف.

عودة ملف مسار لـ `.agents/notes/archived/{kind}/yyyy-mm-dd-topic.md`، منها حذف زائد بقية `implemented` طبقة درجة. عودة ملف تغيير سوف نقل حركة كامل إنجليزي نص، العربية و متسق صفة مرافق مع سجل ثلاثة عدد ملف، إبقاء `Status: implemented`، و في اثنان نوع لغة ملف في ضيق وصل هذا حالة سطر إدراج دخول `Archived: YYYY-MM-DD`. عودة ملف وقت فقط سماح فعل ملف ترحيل، إضافة هذا بيانات وصفية سطر، متبادل ينبغي أرض إعادة سجل مرافق مع سجل، و آلة آلة إصلاح دخول محطة رابط.

أصل دليل `.rgignore` سوف سوف عودة ملف دليل ترتيب حذف في من فوق طبقة دليل بدء بحث خارج. فحص بحث تاريخ محتوى وقت سوف صريح إشارة تحديد عودة ملف دليل، لذلك ما زال يمكن حسب يحتاج وصول، معا لن يأخذ تجميد ربط واقع خلط دخول مقابل نشط وثب قرار فحص بحث.

عودة ملف بعد، هذا ثلاثة عدد ملف دائم دائم تجميد ربط، فقط بصفة تاريخ خلف مشهد، لم يعد هو حالي مرجعي اعتماد حسب. لا نيل لأن حزمة إعادة تسمية، سلوك تغير، قلب ترجمة معيار، صيغة قاعدة، خروج محطة رابط بطلان أو لاحق وثيقة اتفاق بينما تحديث عودة ملف ملف. نشط وثب وثيقة يمكن متعمد رابط إلى عودة ملف Agent Note، أيضا يمكن يأخذ هذا رابط إعادة تحديد نحو إلى حالي مرجعي اعتماد حسب، أو مباشر حذف. مستودع بوابة لذلك سوف تحقق إشارة نحو عودة ملف ملف رابط، لكن أبدا يأخذ عودة ملف ملف بصفة رابط مصدر قدوم تحقق.

[`verify-archived-agent-notes`](../../../../scripts/verify-archived-agent-notes.ts) مسؤول صيانة تجميد ربط حد. هو فقط قبول غلاف إغلاق تجميع دمج في Agent Note صنف آخر، اشتراط ثلاثة عدد إعداد مقابل ملف كامل، حالة لـ implemented، كما عودة ملف يوم مدة صالح و متبادل متبادل مطابقة؛ هو أيضا سوف استخدام مزدوج جهة حالي Git blob hash تحقق مرافق مع سجل، و في فقط إلحاق manifest(بيانات وصفية بيان) في حسب مسار و SHA-256 محتوى hash غلاف تخزين كل بند ناتج. ذلك `--write` نمط سوف أولا إثبات كل بند قائم غلاف تخزين سجل مقابل محتوى كل لم تغيير، مجددا فقط إلحاق جديد عودة ملف ناتج. سحب أخذ طلب CI سوف توفير يمكن معلومة أساس دقيق SHA، و في تشغيل تحقق جهاز قبل فحص خروج كامل تاريخ، لذلك إعادة استخدام تشغيل جهاز فوق ضحل تغلب ضخم فحص خروج لا يمكن تسرب إسقاط أساس خط manifest. عادي Agent Note صيغة، قلب ترجمة إعداد مقابل، تبديل سطر،Markdown رابط، حزمة مسار،Mermaid، وثيقة TypeScript و نوع انتظار قيمة بوابة كل ترتيب حذف عودة ملف مصدر ملف، لذلك هذه بوابة حمل متابعة عرض دخول معيار لن إنتاج تعديل تاريخ سجل ضغط قوة.

[`dsh-archive-agent-notes`](../../../skills/dsh-archive-agent-notes/SKILL.md) سير العمل مسؤول تصنيف حكم قطع. هو اشتراط تدريجي نسخة Agent Note فعل دلالة مراجعة حساب، استخدام شفرة و حالي وثيقة تعرف آخر الآن سطر مرجعي اعتماد حسب، فقط يأخذ حرف عدد بصفة أول خطوة غربلة اختيار يد مقطع، استلام تسجيل مرور مرور تدقيق دقيق إبقاء، عودة ملف و حذف عرض مثال، و تقرير إبلاغ حق صحيح موضع في حد نتيجة، بـ توفير مراجعة.

في تحرير كتابة جديد Agent Note وقت حينئذ فحص يحل محل علاقة، بينما لا هو دفع متأخر إلى يوم بعد تنظيف سجل تجميع دمج وقت مجددا معالجة. عمل من سوف سوف جديد سجل و شمول غطاء نفس بند قرار، آلية أو يتم مرفوض تجهيز اختيار خطة نشط وثب سجل إجراء مقارنة مقارنة، و تدريجي بند حكم تحديد يخص تماما يحل محل أيضا هو جزء يحل محل. رمز دمج شرط implemented Agent Note ثلاثة ملف إعداد مقابل سوف في نفس عدد سحب أخذ طلب في عودة ملف؛ فقط جزء يتم يحل محل سجل، و ما زال حفظ لديه مستقل قيمة قيمة قرار اعتماد حسب، سوف متابعة بصفة نشط وثب سجل إبقاء و و جديد سجل متبادل متبادل رابط، بينما مطابقة إلى proposed و rejected Agent Note فإن التزام دوران كل منها دورة الحياة قاعدة.

## سبق اعتبار بديل خطة

**حذف كل واحد نسخة نقل خروج نشط وثب سجل تجميع دمج سجل.** غير مقبول، لأن قد فعلي تطبيق سجل ممكن مقابل لم قدوم إشارة توجيه قيمة قيمة مقارنة منخفض، لكن ما زال قدرة لـ قد استلام ذيل قرار توفير لديه استخدام تاريخ دليل. حسب محتوى hash غلاف تخزين عودة ملف حيث قدرة إبقاء هذه دليل، أيضا لن زائف تركيب هو جمع ما زال عكس عكس حالي حالة.

**متابعة سوف كل واحد نسخة implemented و rejected Agent Note بصفة نشط وثب سجل إبقاء.** غير مقبول، لأن لم يعد مساعدة مساعدة لم قدوم قرار سجل سوف لا قطع زيادة صيانة صار هذا و بحث ضجيج صوت. خاصة ذلك هو rejected Agent Note، فقط لديه قدرة تجنب تجنب واحد نوع ممكن حدوث خطأ خطأ وقت، عندئذ قيمة نيل إبقاء.

**يجعل عودة ملف Agent Note متابعة ظهور في افتراضي مستودع بحث نتيجة في.** غير مقبول، لأن عودة ملف واقع حسب تصميم ممكن قد قديم قديم، و ممكن فقط سند حرف وجه مطابقة حينئذ ترتيب في حالي نتيجة قبل. حاجة فحص بحث تاريخ محتوى وقت، يمكن صريح بحث عودة ملف دليل.

**يأخذ يحل محل علاقة تنظيف إبقاء إلى تحديد مدة مراجعة حساب سجل تجميع دمج وقت مجددا فعل.** غير مقبول، لأن بديل سجل عمل من كف إمساك حال صلة في ملكية و إعادة تراكم الأكثر جديد دليل. دفع متأخر معالجة سوف إبقاء تحت زائد بقية نشط وثب مرجعي اعتماد حسب، و زيادة يوم بعد تصنيف صار هذا.

**معا عودة ملف rejected أو proposed Agent Note.** غير مقبول، لأن عودة ملف حالة جدول بلوغ هو «قد فعلي تطبيق تاريخ قرار». مرور وقت رفع سجل حاجة واضح تحويل لـ rejected؛ لا يمكن توفير منع خطأ قيمة قيمة rejected Agent Note فإن ينبغي حذف، بينما لا هو مجددا وضع دخول ثاني عدد منخفض قيمة قيمة تخزين وضع منطقة.

**متابعة مقابل عودة ملف Agent Note تطبيق كل وثيقة بوابة.** غير مقبول، لأن لاحق إضافة جديدة صيغة، قلب ترجمة، شفرة، حزمة أو رابط قاعدة سوف إجبار جعل صيانة من إعادة كتابة تاريخ لقطة. تعديل من مخصص استخدام تحقق جهاز مسؤول كامل صفة و غير ممكن تغيير صفة.

**سماح تحديث واقع، فقط تجميد ربط قرار اعتماد حسب.** غير مقبول، لأن هذا سوف إعادة جذب دخول نشط وثب سجل تجميع دمج حكم قطع و قلب ترجمة سالب تحمل، أيضا سوف يجعل قراءة من لا يمكن قسم تمييز أي بعض بند بند يخص تاريخ. حالي واقع ينبغي كتابة في نشط وثب وثيقة أو جديد نشط وثب Agent Note في.

## عاقبة

نشط وثب سجل تجميع دمج من مسبق حساب ما زال سوف أثر لم قدوم عمل قرار مجموعة صار؛ لم قدوم إشارة توجيه قيمة قيمة مقارنة منخفض فعلي تطبيق تاريخ ما زال يمكن صريح بحث و رابط، لكن لم يعد إزالة استهلاك صيانة دقيق قوة، أيضا لن ظهور في من فوق طبقة دليل بدء بحث في. تحرير كتابة جديد سجل وقت سوف يتضمن واحد بند نطاق واضح يحل محل علاقة فحص، لذلك يحل محل قائم قرار جديد قرار لا يمكن صامت لكن إبقاء تحت زائد بقية نشط وثب سجل. عند يتم مرفوض سجل لم يعد حفظ حماية متعمد معنى اختيار وقت، يمكن صاف حذف هذا صنف مختلط بند؛ رفع سجل أيضا لا يمكن عبر عودة ملف صامت صامت هروب تجنب واضح ربط نقاش. عودة ملف آلية زيادة واحد نسخة manifest، واحد مخصص استخدام تحقق جهاز و واحد صريح مرة صفة بيانات وصفية خطوة. عودة ملف في واقع و خروج محطة رابط يمكن حسب تصميم تدريجي تدريجي قديم قديم، لذلك قراءة من و agent(ذكي جسم) يجب بـ نشط وثب شفرة و وثيقة لـ مرجعي اعتماد حسب، و كما فقط سوف عودة ملف Agent Note بصفة تاريخ مرجع.
