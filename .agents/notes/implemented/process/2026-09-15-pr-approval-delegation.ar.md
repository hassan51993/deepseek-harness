# Agent Note: PR نطاق داخل دفعة دقيق تفويض حمل

Status: implemented

[English](2026-09-15-pr-approval-delegation.md) | العربية

## Problem

مراجعة شخص ممكن معلومة مهمة آخر موضع مراجعة شخص قدوم قرار بعض عدد PR(Pull Request) ، معا إبقاء ذاتي ذات مستودع زاوية لون و شفرة ملكية مقابل قسم عدد. إذا معا حساب دخول أصلي دفعة دقيق و تحويل تسليم قسم عدد، حينئذ سوف وضع كبير هذا مراجعة شخص مساهمة.

## Decision

[دفعة دقيق سياسة](../../../../.github/review-ownership/README.md#delegating-points) قبول PR عادي تقييم نقاش في `/delegate @username`. كل موضع رمز دمج مورد إطار تفويض حمل شخص، ذلك قسم عدد تتبع مع إشارة تحديد تلقي حمل شخص صالح دفعة دقيق، حسب تفويض حمل شخص حق إعادة حساب دخول مرة. تفويض حمل فقط ملائم لأجل حالي PR، كما مزدوج جهة كل يجب أداة لديه كتابة إذن، لا يستطيع هو PR عمل من. استلام إلى قسم عدد لا يستطيع متابعة تحويل تسليم. أمر سوف عبر GitHub سحب إلغاء تفويض حمل شخص أصل لديه دفعة دقيق و تغيير طلب. أخرى صالح منع سد مراجعة ما زال التزام دوران[منع سد مراجعة سياسة](2026-09-09-blocked-weighted-approvals-remain-pending.ar.md).

حسب تقييم نقاش إنشاء ترتيب، الأكثر جديد، ما زال وجود كما رمز دمج مورد إطار أمر قرار تلقي حمل شخص. تحرير مرور أمر اشتراط الأكثر قريب تحرير من و عمل من غير ممكن تغيير حساب مستخدم ID متسق؛ أخرى لديه كتابة إذن شخص لا يستطيع عبر تحرير تقييم نقاش تحويل تسليم أو إلغاء عمل من قسم عدد. تفويض حمل إعطاء ذاتي ذات أو مع بعد إيداع مراجعة سوف استعادة استخدام تفويض حمل شخص هذا شخص مراجعة قرار. فقط تقييم نقاش مراجعة أيضا سوف استلام عودة قسم عدد؛ بعد لم إيداع مراجعة لن. ختم الوقت نفسه وقت بـ مراجعة لـ دقيق، مع بعد سحب إلغاء مراجعة أيضا لن إعادة تفعيل تفويض حمل. مراجعة بعد جديد أمر يمكن مجددا مرة تفويض حمل. تحرير و حذف سوف أصل حسب حالي تقييم نقاش إعادة حساب، يشمل استعادة مقارنة مبكر أمر. يمكن معلومة إصدار جهاز حسب `/delegate` غربلة اختيار عادي تقييم نقاش تغيير، تحليل فوري كما لم إغلاق PR رأس إيداع، و سوف تقييم نقاش و تحرير من هوية بصفة API بيانات قراءة. كل مرة تقييم تقدير كل سوف معالجة كل صالح كما رمز دمج مورد إطار أمر، سحب إلغاء قديم قرار صفة مراجعة، و طلب بعد لم دفعة دقيق، بعد لم استلام إلى طلب تلقي حمل شخص إجراء مراجعة. هذا تغطية ترتيب طابور حدث يتم استبدال و مسودة مسودة تحويل لـ ready حال حال؛ أخرى requested reviewers إبقاء ثابت. سحب إلغاء بعد تحديث جديد قسم عدد؛ سحب إلغاء إبقاء قديم إيداع ختم الوقت، لن إلغاء تفويض حمل. إزالة تلقي حمل شخص دفعة دقيق فقط سوف إزالة حساب دخول قسم عدد، تفويض حمل ما زال إبقاء، توفير ذلك تحت مرة دفعة دقيق استخدام. مسودة مسودة PR لا سحب إلغاء أو طلب مراجعة. سحب إلغاء فشل سوف جعل تقييم تقدير فشل؛ طلب فشل مفرد وحيد سجل سجل، و في لاحق تقييم تقدير في إعادة محاولة. قد إغلاق أو دمج PR سوف في كتابة حالة و تثبيت اعتماد قبل قفز مرور. مستقل[مراجعة سير العمل تحقق](2026-09-10-approval-review-workflow-identity.ar.md) إبقاء ثابت.

## Alternatives considered

**يأخذ تفويض حمل مباشر نظر لـ دفعة دقيق.** هذا سوف في اختيار تحديد مراجعة شخص عمل خروج قرار قبل دفعة دقيق PR.

**زيادة تفويض حمل شخص قسم عدد، معا إبقاء ذلك مباشر مساهمة.** هذا سوف سوف نفس حساب مستخدم حساب حساب اثنان مرة، تقليل ضعيف دفعة دقيق عتبة قيمة.

**امتداد تفويض حمل سلسلة متابعة تحويل تسليم استلام إلى قسم عدد.** هذا سوف سماح تلقي حمل شخص سوف هو شخص قسم عدد تحويل إعطاء لم مرور أصل تفويض حمل شخص إشارة تحديد حساب مستخدم.

**فقط في قسم عدد في تجاهل اختصار تفويض حمل شخص قديم قرار.** GitHub سوف إبقاء أصل لديه دفعة دقيق أو منع سد مراجعة. سحب إلغاء قديم مراجعة جعل أصلي مراجعة حالة و تفويض حمل متسق.

**تفويض حمل شخص إيداع مراجعة بعد ما زال إبقاء تفويض حمل.** قد إيداع مراجعة جدول بلوغ تفويض حمل شخص هذا شخص قرار، متابعة استخدام هو شخص دفعة دقيق سوف تجاهل اختصار هذا قرار.

**في تقييم نقاش خارج مفرد وحيد حفظ دائم أمر.** هذا حاجة مقدار خارج تخزين، و تنسيق ضبط تحرير و حذف؛ حالي تقييم نقاش قد توفير يمكن فحص سجل.

## Consequences

تفويض حمل إبقاء تفويض حمل شخص[إنتاج شفرة ملكية حق إعادة](2026-09-11-production-blame-approval-weight.ar.md) و مستقل عمل من معلومة استخدام قاعدة. كل مرة تقييم تقدير كل حاجة كامل تقييم نقاش و تحرير من تاريخ و مشاركة و من حالي إذن؛ تاريخ ناقص سوف جعل تقييم تقدير فشل. تحرير مقارنة مبكر أمر لن تغيير ذلك أولوية درجة، حذف مقارنة جديد أمر ممكن إعادة تفعيل مقارنة مبكر أمر. سياسة اختبار تغطية قسم عدد حراسة ثابت، مراجعة إطلاق استلام عودة، قديم مراجعة سحب إلغاء، إذن مرور ترشيح، مراجعة طلب، منع سد مراجعة، قسم صفحة و فشل حالة إصدار؛ سير العمل اختبار قيد يمكن معلومة تنفيذ و كل PR مشترك تزامن قسم مجموعة. مرور مدة مراجعة و الأكثر جديد دفع إرسال اشتراط ما زال من GitHub أصلي قاعدة مسؤول.
