# Agent Note: حسب حزمة مرساة تحديد فرعي نظام صفحة و دقيق بسيط قسم مجموعة README

Status: implemented

[English](2026-08-03-package-anchored-subsystem-pages.md) | العربية

## مشكلة

[فرعي نظام دليل](../../archived/process/2026-06-20-core-data-structures-catalog.md) الأكثر أول استخدام رئيسي جاف-vs-seam قاعدة حد تحديد أول صفحة نطاق: إذا حلقة في كل جولة كل يحتفظ، إرسال توليد، تدفق صيغة نقل أو سجل بعض عدد نوع، هو حينئذ هو «نواة قلب». هذا قاعدة اختيار هو نوع بينما غير حزمة، لذلك عند دليل زيادة طويل إلى أربعة عشرة كثير صفحة بعد، أول صفحة تغيير صار عبر حزمة كبير مختلط خليط:LLM(كبير لغة نموذج) محادثة مفردات ترتيب في agent(ذكي جسم) اتفاق قبل، إنشاء/كل حق مفردات (`AgentHandle`،`CreateAgentOptions`،`ResumeAgentOptions`،`AgentFactory`) في دليل في بلا موضع سجل (توليد جهاز يأخذ هو جمع إعفاء تجنب إعطاء بعض عدد حزمة README) ، قراءة من لا يمكن أصل حسب نوع الذي في موضع مسبق قياس أي واحد صفحة سجل هو. و هذا معا، كل حزمة قسم مجموعة README لا يوجد موحد واحد شكل حالة——لديه حمل قسم عقدة جدول إطار، تنقل مغادرة تصميم قصير نص، أو هذا ينبغي يخص فرعي نظام صفحة ذيل جزء مقطع سقوط.

## قرار

كل `docs/subsystems/` صفحة مرساة تحديد إلى إعلان ذلك مفردات حزمة أو حزمة قسم مجموعة، صفحة ملكية تتبع مع مستودع تخطيط:[core.md](../../../../docs/subsystems/core.zh.md) هو `packages/core` صفحة (إنشاء و كل حق،`Agent` جملة مقبض و ذلك إلقاء تمرير/إلغاء/اعتراض قطع اتفاق، إشارة نحو هذا مجموعة مخصص تابع صفحة رابط) ،[llm-streaming.md](../../../../docs/subsystems/llm-streaming.zh.md) كامل شمول غطاء `packages/llm`، اعتماد هذا صنف دفع. كل مستودع عام نوع نمط (`…Map → إرسال توليد ربط دمج`، صنف لوحة تحويل id) إبقاء في core.md واحد واضح علامة ملاحظة استلام ذيل صغير عقدة في، بينما لا هو و حزمة محتوى تسليم خطأ. هذا في*صفحة نطاق حد تحديد قاعدة*معنى معنى فوق يحل محل رئيسي جاف-vs-seam قاعدة؛ تخزين نشط تحت قدوم وضع وضع بدء إرسال صيغة أكثر بسيط مفرد: نوع سجل في ذلك إعلان حزمة مقابل صفحة، متبادل صلة تنفيذ آلية ما زال تجميع في سجل في ذلك الذي تابع صفحة.

توليد توقيع مرجع كل نوع كل يجب قدرة في دليل في بعض موضع تحليل:agent كل حق مفردات من توليد جهاز `TYPE_LINK_EXEMPTIONS` نقل دخول `LINK_MAP → core.md`، لذلك إعفاء تجنب فقط إبقاء إعطاء تأكيد فعلي فقط لأجل خدمة داخلي أو قدوم ذاتي vendored شفرة نوع بنية. كل لصق لصق إعلان فقط لديه واحد بيت (`SessionEvent` يقع في [session.md](../../../../docs/subsystems/session.zh.md) ؛core.md عام تضمين و رابط).

كل `packages/<group>/README.md` إعداد مقابل كل هو موحد واحد شكل حالة دقيق بسيط مدخل: واحد مقطع أولا شرح «لـ ماذا» وسيط تعريف، واحد ورقة حزمة جدول إطار (حزمة / زاوية لون / ctx مفتاح) ، واحد إشارة نحو مقابل فرعي نظام صفحة استلام ذيل رابط. لم إعلان مستقل فرعي نظام مشاركة اعتبار مورد مادة قسم مجموعة سوف في `GROUPS_WITHOUT_SUBSYSTEM_PAGE` في مرفق فوق غير فارغ إدارة من. إذا تحمل تحميل صلة مفتاح معلومة متن تجاوز خروج هذا واحد بنية الذي قدرة سعة قبول نطاق، حينئذ سوف ذلك ترحيل إلى مقابل فرعي نظام صفحة، بينما غير حذف.

`verify-subsystem-pages` معا من قسم مجموعة README و فرعي حزمة manifest(بيانات وصفية بيان) اكتشاف قسم مجموعة. هو سوف رفض نقص قليل قسم مجموعة README، قسم مجموعة حيث لا يوجد موجه إلى قراءة من كما مباشر إشارة نحو `docs/subsystems/` تحت بعض واحد إنجليزي نص ملف رابط أيضا لا يوجد صريح إعفاء تجنب، إعفاء تجنب لـ فارغ أو يصبح منعزل قيام بند، قد إعفاء تجنب قسم مجموعة إضافة جديدة رابط، و رابط إشارة نحو صفحة لا وجود؛ شفرة، ملاحظة تفسير، صورة، تضمين طقم مسار و مسار اختراق تجاوز كل لا يستطيع ممتلئ كاف كل حق إعلان. هذا فحص بصفة مستقل `doc-sync`(وثيقة تزامن) ورقة عقدة تشغيل، لذلك إضافة جديدة حزمة قسم مجموعة وقت لا يستطيع صامت صامت متروك تسرب ذلك وثيقة يملك جهة.

[فرعي نظام README](../../../../docs/subsystems/README.zh.md) في في إنجليزي نص اثنان جانب بحث جذب دليل في كل واحد صفحة؛`scripts/project-doc-site.spec.ts` قوي صنع كل صفحة مقابل واحد جدول إطار سطر، لذلك إضافة جديدة أو دمج امتصاص استلام صفحة لا يمكن صامت صامت نقص مقعد بحث جذب.

## اعتبار مرور بديل خطة

**إبقاء رئيسي جاف-vs-فرعي نظام حد تحديد قاعدة.**هو تدريجي نوع عودة جواب «هذا عدد نوع هو نواة قلب هل؟» ، هذا صحيح هو أول صفحة تراكم تراكم أربعة عدد حزمة نوع، لكن ناقص `packages/core/agent` واحد نصف عام واجهة سبب. حسب مستودع تخطيط إجراء مسبق قياس خطة فوز خروج.

**مسطح مستو مفرد وثيقة دليل.**في[أصل دليل Agent Note](../../archived/process/2026-06-20-core-data-structures-catalog.md) في قد يتم مرفوض؛ زيادة طويل إلى أربعة عشرة واحد صفحة إثبات فعلي هذا ربط نقاش.

**فقط في حزمة README في سجل كل حق مفردات (إعفاء تجنب الآن حالة).**هذا يجعل `AgentHandle` و إنشاء/استعادة خيار في ذاتي تسمية نوع مشاركة اعتبار دليل في غير ممكن رؤية، توليد `Types:` صفحة قدم أيضا لا يمكن رابط هو جمع.

## عاقبة

- أي واحد صفحة سجل بعض نوع يمكن من `packages/<group>/` مسبق قياس؛ فرعي نظام README هو من اختبار قوي صنع كامل بحث جذب.
- كل حزمة قسم مجموعة كل سوف سوف ذلك فرعي نظام يملك جهة أو دمج إدارة نقص مقعد سبب كشف إعطاء مراجعة، كما `verify-subsystem-pages` سوف رفض لم تصنيف إضافة جديدة بند و قديم قديم إعفاء تجنب.
- توليد توقيع صفحة قدم رابط agent كل حق مفردات، بينما لا هو ساكن صامت إعفاء تجنب.
- `verify-type-equiv` 1:1 manifest(بيانات وصفية بيان) حفظ إثبات كل لصق لصق مفرد واحد ملكية؛ تكرار `SessionEvent` لصق لصق قد إزالة.
- [أصل دليل Agent Note](../../archived/process/2026-06-20-core-data-structures-catalog.md) ما زال يملك `ts type-equiv` عائم نقل فحص آلية؛ هذا موضع فقط يحل محل ذلك صفحة نطاق حد تحديد قاعدة.
