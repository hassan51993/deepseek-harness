# Agent Note: Web مثال صيغة جسم نظام——token إطار هيكل و عمل مسار قيد

Status: implemented

> token جسم نظام تحديث (2026-07-22): هذا نص إطار هيكل قطع قرار (CSS Modules + clsx، بلا مكون مكتبة، بلا tailwind، لون لون فقط استخدام token) ما زال توليد فاعلية، لكن اثنان طبقة `--bg-*`/`--text-*` token جدول و ذلك مضيف `web-ui/src/style/global.css` قد يتم `packages/client/ui-theme/src/styles/` `--dsw-*` static+alias مزدوج طبقة جدول يحل محل (داكن لون=`body[data-ds-dark-theme]` تغطية كتابة)——مثال صيغة جدول ذاته أي token مرجعي.

[English](2026-07-19-web-styling-system.md) | العربية

> قسم عمل: هذا RFC تحديد إطار هيكل و قيد (قليل تغيير) ؛[docs/web-styling.md](../../../../docs/web-styling.ar.md) هو نشط مواصفة (token مرجعي قيمة، تحرير رمز مواصفة ضرب ربط بيان، انحراف مغادرة سجل، مع تنفيذ عرض دخول). تعديل token/إضافة قاعدة ذهاب ذلك حافة؛ حركة إطار هيكل ذاته عندئذ عودة هذا داخل (دفع قلب يجب جديد RFC).

## Problem

GUI بلا تصميم معلم توفير إعطاء، مثال صيغة من agent تحرير كتابة و review؛ لا يوجد واحد طقم آلة جهاز يمكن فحص token جسم نظام و تحرير رمز مواصفة، لون لون/دائرة زاوية/حركة فاعلية سوف في مكون بين حرف وجه كمية عائم نقل، داكن لون رئيسي عنوان سوف طويل صار مكون داخل تفرق سقوط شرط فرع.

## Decision(إطار هيكل خمسة بند)

| # | قرار | محتوى |
|---|---|---|
| 1 | **نظر شعور أساس خط = Chat مقابل متساو** | أخذ قيمة الكل قدوم ذاتي مقابل Chat قبل طرف ضبط بحث (صنف لوحة أزرق `--accent: #3964fe`، رمادي مرحلة، هواء فقاعة/الشريط الجانبي بضعة أي، ظل أثر قسم درجة……) ؛ سماح انحراف مغادرة لكن يجب في web-styling.md انحراف مغادرة جدول سجل |
| 2 | **token اثنان طبقة لا ثلاثة طبقة** | أساس خط مستودع هو static→alias→specific ثلاثة طبقة؛ أنا جمع جسم كمية تحت ضغط صار «دلالة طبقة مباشر حمل فعلي قيمة (ملاحظة تفسير علامة base لون لوح خروج موضع)+ أقصى قليل عدد مكون مخصص تابع مجرى موضع (`--bg-sidebar`/`--bubble-bg`)» اثنان طبقة، الكل إقامة `web-ui/src/style/global.css` |
| 3 | **حرف رقم/بين مسافة لا token تحويل** | أساس خط مستودع نفس بند قرار: حرف رقم في مكون داخل كتابة px كما**صار مقابل كتابة سطر عال**(16/24،14/22،12/18) ، بين مسافة استخدام 4 ضعف عدد؛token تحويل فقط تغطية لون لون/دائرة زاوية/حركة فاعلية/حرف جسم مكدس/ظل أثر |
| 4 | **حافة إطار و تفاعل حالة استخدام نفاذ واضح درجة صنع** | حافة إطار `rgba(0,0,0,.04/.1)`،hover/active `rgba(38,49,72,.06/.1)`——تراكم إضافة في مهمة معنى طبقة درجة خلف مشهد لون فوق كل صار قيام، لا جديد صنع فعلي لون رمادي |
| 5 | **داكن لون فقط في token جدول فعل** | `:root` مضيء لون فعلي قيمة + `[data-theme='dark']` تغطية نفس اسم متغير؛**مكون CSS صفر رئيسي عنوان اختيار جهاز**؛ تأكيد يحتاج حسب رئيسي عنوان تبديل غير token قيمة وقت استخدام «CSS متغير جسر»(مكون تعريف نطاق جزء متغير، رئيسي عنوان كتلة فقط تغطية كتابة متغير) |

## عمل مسار قيد

- **CSS Modules + clsx، بلا مكون مكتبة، بلا tailwind**: كل مكون نفس دليل نفس اسم `.module.css`؛ صنف اسم camelCase، حالة صنف مفرد شكل سعة كلمة من clsx تركيب؛ مكون نفاذ نقل `className`.
- **منع `composes`**؛`:global` فقط اختراق نفاذ رقم ثلاثة جهة/عبر حزمة صنف اسم، لا تعريف جديد عام صنف؛ عام أداة صنف فقط إقامة global.css كما عدد موضع عدد (الآن حالة `.scrollable`).
- **PostCSS إضافة الآن حالة لـ صفر**(vite بلا postcss إعداد، مستو فرش CSS أي كاف استخدام؛ جذب دخول nested/custom-media قبل يحتاج أولا تسجيل دخول web-styling.md) ؛CSS Modules نوع إعلان استخدام `css-modules.d.ts` عبر إعداد declare(مكون عدد تجاوز 20 مجددا تقييم تقدير typed-css-modules تدريجي ملف توليد).
- **حركة حالة مثال صيغة مشي CSS متغير جسر**:JS فقط كتابة متغير (`style={{'--x': v}}`) ، قاعدة إبقاء في CSS؛ منع توقف TSX داخل تجميع مثال صيغة كائن فعل رئيسي عنوان/حالة فرع.
- مرور عبور واحد قاعدة `var(--dur*) var(--ease)` كما فقط مرور عبور opacity/transform/خلف مشهد لون/ظل أثر؛ تمرير حاوية موحد واحد `.scrollable`(مكون داخل منع كتابة `::-webkit-scrollbar`).

## إعطاء agent تنفيذ شكل

مواصفة بـ **review مقابل وفق ضرب ربط بيان**شكل صيانة (web-styling.md §3،12 بند): كل بند هو يمكن حكم تحديد «رؤية X أي ضرب عودة» ، لا هو ريح إطار بناء اقتراح——كتابة مثال صيغة و review مثال صيغة مشترك استخدام نفس ورقة جدول.

معتاد رؤية أمر بند مدخل (عملية بيان):

- **كتابة جديد مكون مثال صيغة**: نفس دليل نفس اسم `.module.css`، مقابل وفق web-styling.md §3 تدريجي بند ذاتي فحص؛ لون لون/دائرة زاوية/حركة فاعلية فقط جذب §1 token.
- **إضافة واحد token**: أولا دخول web-styling.md §1 جدول تكملة واحد سطر (مضيء لون قيمة+داكن لون صف+base لون لوح خروج موضع ملاحظة تفسير)→ global.css `:root` و `[data-theme='dark']` اثنان كتلة تزامن → مجددا في مكون داخل مرجع.
- **انحراف مغادرة نظر شعور أساس خط معتاد عدد**(web-styling.md §2 بضعة أي/ظل أثر قيمة): أولا في §5 انحراف مغادرة جدول تسجيل واحد سطر (يوم مدة/بند/إدارة من) مجددا سقوط رمز.
- **حاجة حسب رئيسي عنوان تغير غير token قيمة**(تدريجي تغيير طرف نقطة انتظار): مكون تعريف نطاق جزء CSS متغير، رئيسي عنوان كتلة فقط تغطية كتابة متغير (متغير جسر) ، مكون CSS إبقاء صفر `[data-theme]` اختيار جهاز.

## Consequences

مثال صيغة استلام جمع إلى آلة جهاز يمكن فحص: لون لون/دائرة زاوية/حركة فاعلية/ظل أثر فقط جذب web-styling.md §1 token، داكن لون هو مفرد واحد خاصية اختيار جهاز تغطية جدول،review و ذاتي فحص مشترك استخدام نفس ورقة 12 بند بيان. قبول بديل قيمة: حرف رقم/بين مسافة اعتماد صار مقابل سطر عال و 4 ضعف عدد سجل قاعدة بينما غير token؛ حركة إطار هيكل ذاته يجب من جديد RFC يحل محل هذا نص.

## Alternatives considered

| وضع ترك بند | واحد جملة كلام إدارة من |
|---|---|
| حرف رقم/بين مسافة token تحويل | أساس خط مستودع فعلي إثبات لا token تحويل أيضا قدرة استلام جمع (صار مقابل كتابة سطر عال سجل قاعدة بديل) ؛token جدول تمدد انتفاخ خفض منخفض لون لون token مرجعي صفة |
| داكن لون استخدام `prefers-color-scheme` أو مكون داخل فرع | خاصية اختيار جهاز كامل جدول تغطية يجعل مكون صفر شعور معرفة؛ نظام انحراف جيد يمكن لاحق في toggle طبقة ملائم إعداد، لا حركة token آلية |
