# Agent Note: في حفظ دائم Linux تشغيل جهاز فوق تنفيذ تلقي معلومة مهمة إصدار عرض تدريب

Status: implemented

[English](2026-09-06-release-rehearsal-selfhosted.md) | العربية

## Problem

اعتماد تخطيط فحص و إصدار تحزيم عرض تدريب إزالة استهلاك حمل إدارة Linux قسم ساعة، لكن لا حاجة npm أو API اعتماد. سوف مهمة معنى سحب أخذ طلب شفرة أو يحمل اعتماد إصدار مهمة وضع إلى حفظ دائم مشترك رئيسي آلة سوف تقليل ضعيف عزل؛ إعادة استخدام لم مرور تنظيف فحص خروج دليل أيضا سوف تقليل ضعيف تحزيم تحميل حمل تحقق.

## Decision

[release.yml](../../../../.github/workflows/release.yml) اثنان عدد عمل عمل و [release-vendor.yml](../../../../.github/workflows/release-vendor.yml) تحزيم عمل عمل فقط في كتابة إذن صيانة من تحكم مستودع متغير `DSH_CI_FAILOVER_LINUX` ضبط لـ `selfhosted` وقت اختيار قائم Linux ذاتي حمل إدارة حوض. اختيار جهاز اشتراط حالي مستودع لـ صحيح صيغة مستودع كما إطلاق من لا هو Dependabot، لكن بعد فقط وصل قبول master دفع إرسال، أو عمل من لا هو Dependabot نفس مستودع، غير fork PR(Pull Request). يد حركة إطلاق بداية نهاية اختيار `ubuntu-24.04`، أخرى لا ممتلئ كاف شرط سياق أيضا واحد مثال.[لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.zh.md) مسؤول حسب منصة تخطيط قسم فتح صلة و حار تجهيز عملية. إصدار عرض تدريب متعمد و رئيسي CI مشترك استخدام Linux فتح صلة: تفعيل أو منع استخدام سوف معا توجيه اثنان صنف سالب تحميل، لا يستطيع مستقل تبديل إصدار عرض تدريب. لم ضبط وقت ما زال افتراضي استخدام حمل إدارة حوض؛ فقط لديه تشغيل صيانة شخص عضو اختيار `selfhosted` خلال عندئذ عقدة حذف حمل إدارة قسم ساعة، بلا نقاش هذا اختيار لأجل لذا عائق استعادة أيضا هو حمل متابعة صار هذا تحكم.

تشغيل جهاز وسم لـ `[self-hosted, linux, x64, vm-backup]`. تشغيل جهاز تسجيل مشترك واحد منصة وهمي محاكاة آلة، لا بديل جدول مستقل آلة جهاز سعة كمية. كل عمل عمل في pnpm ضبط قبل سوف Node تحرير ترجمة ذاكرة مؤقتة و node-gyp رأس ملف وضع في تشغيل جهاز خاص مؤقت لفة فوق،pnpm ضبط هدف مسار يتضمن تشغيل، إعادة محاولة مرة عدد و عمل عمل معرف.`TMPDIR` أيضا إشارة نحو `runner.temp`، لذلك مؤقت npm إزالة استهلاك دليل حيث في فحص خروج دليل خارج، أيضا في تشغيل جهاز تنظيف نطاق لـ داخل، أي جعل عملية يتم قوي قتل بينما لا يمكن تنفيذ `finally` أيضا واحد مثال. حفظ دائم pnpm تخزين يقع في فحص خروج تنظيف نطاق خارج؛ فقط لديه GitHub حمل إدارة تشغيل جهاز استعادة بعيد طرف تخزين ذاكرة مؤقتة. اثنان عدد عرض تدريب سير العمل كل لا حفظ بعيد طرف ذاكرة مؤقتة.

فحص خروج عملية صريح تنظيف يتم تجاهل اختصار و لم تتبع أثر إخراج، مجددا تنفيذ قفل تحديد اعتماد تثبيت و قائم بناء. كامل وسم تاريخ، تحزيم تزامن، اعتماد فحص، ضغط حزمة تحقق و ناتج إبقاء مدة متساو إبقاء ثابت. تحزيم تثبيت تحقق جهاز في فحص خروج دليل خارج إنشاء كل جديد إزالة استهلاك دليل، استخدام npm تثبيت ضغط حزمة، إزالة وراثة Node تحليل خطاف، و في `finally` في حذف إزالة استهلاك دليل؛ مسبق حار pnpm تخزين لا يمكن استخدام مساحة العمل رابط أو مرور مدة بناء إخراج بديل بديل ضغط حزمة تحميل حمل.[npm إصدار قرار](2026-08-10-npm-release-sequences.zh.md) ما زال مسؤول إصدار عائلة و إصدار عملية. اثنان عدد يد حركة إصدار سير العمل الكل إبقاء في حمل إدارة تشغيل جهاز فوق، هذا تعديل لا زيادة اعتماد، أيضا لا تغيير سجل التسجيل.

## Alternatives considered

بداية نهاية استخدام حمل إدارة عرض تدريب يمكن تجنب تجنب حفظ دائم رئيسي آلة ريح خطر، لكن سوف إبقاء الكل حمل إدارة قسم ساعة. بداية نهاية ذاتي حمل إدارة فإن فقد ذهاب يمكن نقل غرس رجوع. زيادة ضبط درجة عمل عمل أو يمكن إعادة استخدام سير العمل سوف كثير خروج واحد منطق عمل عمل، و إخفاء ثلاثة عدد بسيط قصير ضبط تسلسل. سماح مهمة معنى مرجع يد حركة إطلاق، سوف يجعل صيانة من عملية نيل نيل مقارنة واضح حدث معلومة مهمة قاعدة أكثر واسع حفظ دائم رئيسي آلة وصول إذن.

## Consequences

إلغاء متغير أو سوف ذلك تعديل لـ غير `selfhosted` قيمة، سوف سوف لاحق رمز دمج شرط عمل عمل توجيه إلى حمل إدارة Ubuntu. هذا هو تشغيل صيانة شخص عضو اختيار رجوع، لن تلقائي استكشاف قياس تشغيل جهاز سليم سليم، أيضا لن تبديل قد ترتيب طابور عمل عمل. مشترك وهمي محاكاة آلة ما زال ممكن و أخرى تلقي معلومة مهمة عمل عمل تنافس تنازع مورد؛ مستودع كتابة إذن صيانة من ما زال مقابل دخول حفظ دائم معلومة مهمة مجال شفرة مسؤول. سير العمل لا تثبيت رئيسي آلة نظام حزمة، أيضا لا تعديل عام رئيسي آلة إعداد.

[scripts/tests/ci-release-selfhosted.spec.ts](../../../../scripts/tests/ci-release-selfhosted.spec.ts) استخدام تلقي معلومة مهمة حدث و fork،Dependabot، أخرى مستودع، غير master دفع إرسال، يد حركة إطلاق، ناقص PR بيانات، منع استخدام فتح صلة انتظار سالب نحو مقابل وفق طلب قيمة قد إيداع اختيار جهاز. اختبار ثابت ضبط ترتيب، فحص خروج تنظيف، فقط حمل إدارة تشغيل جهاز وصول بعيد طرف ذاكرة مؤقتة، إصدار عزل و إبقاء أمر. حقيقي إصدار بناء و تحزيم تثبيت تنفيذ ما زال من PR CI تحقق؛ اختيار جهاز اختبار لا صوت تسمية إعادة الآن هذه بناء.
