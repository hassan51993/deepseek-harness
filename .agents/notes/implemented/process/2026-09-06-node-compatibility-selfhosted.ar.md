# Agent Note: ذاتي حمل إدارة Linux فوق عزل Node توافق صفة عمل عمل

Status: implemented

[English](2026-09-06-node-compatibility-selfhosted.md) | العربية

## مشكلة

أي جعل مستودع قد اختيار قائم ذاتي حمل إدارة Linux حوض،Node 22.19،24.9 و 26 توافق صفة عمل عمل ما زال إزالة استهلاك حمل إدارة Linux دقيقة عدد. سوف إصدار تثبيت جهاز نقل إلى حفظ دائم مشترك آلة جهاز فوق ممكن صنع صار أداة دليل اندفاع مفاجئ، و يجعل توليد ذاكرة مؤقتة ملف تراكم تراكم في تشغيل جهاز تنظيف نطاق خارج.

## قرار

[CI](../../../../.github/workflows/ci.yml) سوف Linux لذا عائق تبديل متغير تطبيق في هذا ثلاثة عدد عمل عمل، اشتراط عمل من لا هو Dependabot، كما غير fork رأس جزء مستودع و حالي مستودع نفسه. معيار حمل إدارة رجوع ما زال متاح. هذه شرط قيد هذا عمل عمل، بينما غير كل يمكن دخول هذا حوض سير العمل. مستودع هوية و fork حالة متساو صريح إبقاء، بـ سهل في مستودع ضبط تغيير وقت إبقاء هذا عمل عمل معلومة مهمة حد؛ قائم أخ أخ اختيار جهاز لا يخص هذا مرة ترحيل نطاق.`blacksmith` لذا عائق تبديل أخذ قيمة تحت فرع وضع ترك هذه شرط: هو موجه إلى مؤقت Blacksmith تشغيل جهاز، لذلك مستودع هوية و fork حالة لا مشاركة و باب تحكم (رؤية [blacksmith لذا عائق تبديل دعم مسار قلم تسجيل](2026-09-09-blacksmith-failover-leg.ar.md)).

مؤقت أداة ذاكرة مؤقتة بـ تكرار تحت تحميل Node لـ بديل قيمة، تبديل أخذ تزامن تشغيل جهاز و Node إصدار بين عزل. فقط لأجل setup-node [ESM مسبق تحميل وحدة](../../../../scripts/ci-compatible-toolcache.mjs) في action عملية داخل إشارة تحديد ذاكرة مؤقتة:Actions تشغيل جهاز في قراءة خطوة إعداد بعد سوف تغطية إبقاء بيئة متغير. فعلي تنفيذ مسار فحص رفض تشغيل جهاز مؤقت دليل خارج تثبيت؛ توافق صفة عملية لا وراثة مسبق تحميل ضبط.pnpm إبقاء قائم خاص تثبيت دليل و حفظ دائم محتوى بحث عنوان store. تحرير ترجمة ذاكرة مؤقتة و node-gyp رأس ملف في أول مرة استدعاء pnpm قبل حينئذ استخدام تشغيل جهاز مؤقت دليل. لا جذب دخول عام Node رمز رقم رابط أو نظام لين عنصر حزمة تغيير. حمل إدارة عمل عمل إبقاء ذلك أداة و لين عنصر حزمة ذاكرة مؤقتة؛ ذاتي حمل إدارة عمل عمل لا استعادة أو فوق نقل حمل إدارة لين عنصر حزمة ذاكرة مؤقتة. تشغيل جهاز مسؤول عمل عمل بين مؤقت دليل تنظيف، مشترك مرآة مثل توفير أصلي npm لين عنصر حزمة الذي يحتاج تحرير ترجمة جهاز و Python قبل وضع اعتماد.

[لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.ar.md) ما زال يملك مستودع معلومة مهمة و حوض تبديل قاعدة.[سلسلة سطر مشاركة اعتبار قرار](2026-07-21-serial-cross-platform-ci-reference.ar.md) ما زال يملك master ضبط درجة قاعدة. حذف توافق صفة عمل عمل تشغيل جهاز اختيار خارج، هذا اثنان عدد قرار كل لم يتم يحل محل؛ اثنان من متساو إبقاء نشط وثب.

## سبق اعتبار بديل خطة

**يجعل كل توافق صفة عمل عمل إبقاء حمل إدارة.** هذا تجنب تجنب مقدار خارج مشترك رئيسي آلة سالب تحميل، لكن متابعة لـ لا حاجة مختلف عملية نظام أو هيكل بنية Linux وقت التشغيل فحص دفع استهلاك.

**استخدام مشترك Node تثبيت أو عام إصدار إدارة جهاز رابط.** هذه عمل عمل يجب تزامن تشغيل مختلف Node إصدار. متغير مشترك رابط سوف جعل اختيار في إصدار أخذ قرار في آخر عمل عمل وقت ترتيب.

**في نفس تعديل في ترحيل Python SDK عمل عمل.** ذلك setup-python تثبيت و عبر عام pip تثبيت uv حاجة مفرد وحيد عزل دليل. هذا عدد قصير مؤقت حمل إدارة عمل عمل لا هو Node أفضل تحويل مطلوب جزء.

## عاقبة

كل يمكن معلومة PR(Pull Request) سوف لـ حوض زيادة ثلاثة عدد عمل عمل؛ كل عمل عمل إبقاء بوابة تزامن درجة واحد، يشمل حاجة بناء Node 22 بند.9 شهر 6 يوم بيان تقرير إبلاغ 31 عدد Linux تسجيل نسخة، بينما لا هو 31 منصة مستقل آلة جهاز. مشترك وهمي محاكاة آلة مورد تنازع استخدام و تحت تحميل تأخير متأخر ما زال هو فوق خط ريح خطر؛ متغير إبقاء حمل إدارة استعادة مسار. اختبار بيان، فحص اسم و master ضبط درجة إبقاء ثابت.

## تحقق

تجمع تركيز[سير العمل ارتداد اختبار](../../../../scripts/ci-compatible-selfhosted.spec.ts) تنفيذ حقيقي توجيه جدول بلوغ صيغة و بيئة ضبط. إزالة fork شرط سالب مقابل وفق جعل حمل إدارة رجوع تأكيد فشل. هو فحص صيانة من إعادة ركض Dependabot PR، مستودع لا مطابقة،fork علامة سجل، منع استخدام متغير و تشغيل جهاز نطاق داخل ذاكرة مؤقتة مسار.

فعلي تطبيق أساس خط فوق نجاح حار تجهيز تشغيل 33984559660 توفير Linux Node 24.19.0 و Windows Node 24.20.0 أساس خط دليل.Linux عمل عمل 101359402557 استخدام بيانات لفة فوق تشغيل جهاز مخصص تابع مؤقت دليل و أداة دليل. فقط قراءة قدرة استكشاف قياس 34012679056 (job 101431064925) تقرير إبلاغ Linux x64،192 عدد في خط منطق CPU،GCC/G++ 13.3،Make 4.3 و Python 3.12.3.Python 3.10 ناقص، دخول واحد خطوة شرح SDK حاجة مفرد وحيد إعداد.PR تشغيل 34013779750 تحقق ذاتي حمل إدارة Linux فوق Node 22.19.0،24.9.0 و 26.8.1، يشمل ضبط، يمكن تنفيذ ملف مسار فحص، توافق صفة اختبار و post actions. يمكن تنفيذ ملف يقع في كل تشغيل جهاز `_temp/node-compat-toolcache/node/<version>/x64/bin` تحت؛ إتمام عمل عمل قسم آخر استهلاك وقت 228s،94s و 101s. هذه مراقبة قياس إثبات إصدار و مسار توافق صفة، بينما غير وحيد احتلال رئيسي آلة سعة كمية حفظ إثبات.
