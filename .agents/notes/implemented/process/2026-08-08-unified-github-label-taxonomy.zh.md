# Agent Note: موحد واحد GitHub وسم تصنيف جسم نظام

Status: implemented

[English](2026-08-08-unified-github-label-taxonomy.md) | العربية

## مشكلة

PR(Pull Request) وسم عودة جواب اثنان عدد متبادل متبادل مستقل مشكلة: عمل حمل قدوم أي واحد صنف تغيير، و سوف مقابل أي بعض حمل دائم مستودع مجال إنتاج فعلي جودة أثر. خلط استخدام هذا اثنان عدد صيانة درجة، أو معا إبقاء نفس معنى بلا بادئة وسم و حمل نطاق الأسماء وسم، كل سوف جعل استعلام يحتوي معنى نموذج غامض؛ غلاف إغلاق مجال بيان فإن سوف إجبار جعل جديد مجال عودة دخول لا دقيق تأكيد صنف آخر.

Issue قد لديه أصلي Issue Type و مستقل مصدر تصنيف جسم نظام. في هذا اثنان صنف كائن فوق إعادة استخدام PR نوع أو مصدر وسم سوف إنتاج تكرار بيانات وصفية، و تقليل ضعيف كل وسم عائلة يحتوي معنى.

## قرار

كل بند فتح وضع أو قد دمج PR كل حمل لديه تماما جيد واحد مواصفة `kind/*` وسم، و حتى قليل واحد يمثل فعلي جودة تلقي أثر مجال `area/*` وسم. لم دمج أي إغلاق PR إبقاء مرور ترحيل تاريخ وسم علاقة، لكن لن سند فارغ تكملة ملء ناقص تصنيف. إدارة استخدام طريق وسم يمكن و تخزين، لكن لا يستطيع ممتلئ كاف هذا اثنان عدد صيانة درجة في مهمة واحد.

### تغيير نوع

نوع تجميع دمج غلاف إغلاق كما متبادل رفض:

| تغيير نوع | يحتوي معنى |
|---|---|
| `kind/feature` | إضافة جديدة سلوك أو متعمد تغيير سلوك. |
| `kind/bug-fix` | إصلاح صحيح خطأ سلوك. |
| `kind/doc` | بـ وثيقة تغيير لـ رئيسي توجيه معنى رسم. |
| `kind/testing` | في لا تغيير منتج سلوك قبل رفع تحت تعديل اختبار أو اختبار أساس أساس ضبط تطبيق. |
| `kind/cleanup` | في إبقاء سلوك ثابت قبل رفع تحت، صيانة أو بسيط تحويل تنفيذ أو مستودع مسار. |
| `kind/dependency` | في لا يوجد أخرى رئيسي توجيه معنى رسم وقت تحديث اعتماد. |

نوع سجل رئيسي توجيه معنى رسم. إعداد طقم اختبار، وثيقة، تنظيف أو اعتماد ضبط كامل لن غطاء مرور وظيفة تغيير أو نقص وقوع إصلاح هذا واحد رئيسي توجيه معنى رسم. إضافة جديدة نوع سوف تغيير هذه تصنيف قاعدة، لذلك يجب واضح تعديل تصنيف جسم نظام و سياسة سياسة.

مستودع سياسة سياسة سوف رفض لا دعم حمل `kind/*` قيمة، و سوف موحد واحد مرور مسار في إزالة كل آخر اسم صف لـ إبقاء اسم:`kind/bug`،`kind/documentation`،`feature`،`bug-fix`،`doc`،`cleanup`،`testing`،`dependencies`،`ci`،`cli`،`llm` و `web-search`. دقيق إبقاء هذا مجموعة قد ترحيل اسم، يمكن منع توقف مرور وقت نفس معنى اسم يتم إعادة إنشاء صار نظر يشبه غير متصل إدارة استخدام طريق وسم.

### مجال

مجال يمثل حمل دائم منتج أو عمل مسار رئيسي عنوان، بينما لا هو مؤقت مخصص بند، ملكية علاقة أو أحيانا لكن لمس و كل بند مسار. واحد بند PR تعديل مختلف سلوك أو API وقت حمل لديه كثير عدد مجال وسم، لكن لن استخدام واحد مجموع تضمين وسم و واحد مقارنة ضيق وسم تكرار وصف نفس بند تغيير.GitHub فوق الآن سطر `area/*` اسم و شرح تعريف حالي بيان؛ هذا سجل تعريف بسيط قصير وسم شرح لا يمكن يمكن اعتماد سعة قبول اختيار حال شكل.

- `area/web` تغطية متصفح و Electron رسم شكل واجهة،`area/vscode` تغطية تحرير جهاز توسيع،`area/api` تغطية عبر واجهة بروتوكول و كل لغة SDK.
- `area/planning` تغطية هدف، حساب تخطيط، انتظار إنجاز و ضبط درجة،`area/workflow` فإن تغطية يمكن تنفيذ سير العمل و خلفية مهمة وقت التشغيل.
- `area/artifact` متعمد دمج ناتج، مرفق عنصر و كثير نموذج حالة تسليم. فقط لديه عند هذه صلة ملاحظة نقطة مجددا مرة حاجة مستقل مراجعة أو استعلام وقت، عندئذ لديه إدارة من تفكيك قسم وسم.
- `area/tools` ملائم لأجل عام سجل التسجيل،schema و تنفيذ اتفاق. أداة جسم قدرة استخدام ذاته مجال وسم، حذف غير هو أيضا تعديل منها واحد بند اتفاق.
- `area/hooks` يمثل Claude Code و Codex جسر وصل،`area/infra` تغطية بناء، إصدار،CI، مستودع بوابة، توليد جهاز، اعتماد و تطوير من أداة،`area/windows` تغطية أصلي Windows منتج دعم حمل، بينما لا هو CI runner اختيار نوع.

مجال تجميع دمج متعمد إبقاء يمكن توسيع. عند قائم شرح كل لا يمكن مثل فعلي شمول غطاء واحد حمل دائم كما يمكن إعادة استخدام مجال وقت،agent(ذكي جسم) بلا حاجة آخر سطر دفعة دقيق، يكفي إنشاء واحد بسيط نظيف `area/<lowercase-kebab-case>` وسم.agent لا نيل لـ مفرد عدد PR، أحيانا لكن تعلق و مسار، مؤقت مشروع، حالة، عدد شخص أو مجموعة طابور إنشاء مجال، و كما يجب في تطبيق جديد وسم بعد نحو طلب من تقرير إبلاغ هذا وسم و إدارة من. فقط لـ تجنب تجنب إضافة جديدة واحد تأكيد لديه لا بد يلزم مجال وسم بينما إعادة استخدام لا دقيق تأكيد مجال، غير ممكن قبول.

### Issue و ترحيل

Issue استخدام أصلي Issue Type، بينما لا هو `kind/*`؛ ذلك `area/*` وسم ما زال اختياري.`source/*` وسم سجل Issue إنشاء طريقة، لا ملائم لأجل PR. أولوية درجة،GitHub افتراضي وسم و سير العمل إطلاق جهاز ما زال هو متبادل متبادل مستقل إدارة بيانات وصفية.

مستودع دورة الحياة سوف أولا من Issue في إزالة PR `kind/*` وسم و إبقاء آخر اسم، مجددا تنفيذ مراجعة حساب. سياسة سياسة تقييم نقاش فقط تقرير إبلاغ لا يمكن من Issue دفع توجيه مسبق مدة قيمة مخالفة قاعدة بند، مثال مثل ناقص أصلي Issue Type أو استخدام لا تلقي دعم حمل أولوية درجة.

ترحيل وسم وقت، يجب أولا إبقاء دلالة، مجددا إزالة آخر اسم: أولا إضافة مواصفة بديل وسم، نواة تحقق يمكن إضافة وسم كائن، مجددا إزالة ملغى ترك وسم علاقة. فقط لديه في كل PR و Issue كل لم يعد استخدام بعض عدد وسم بعد عندئذ قدرة سوف ذلك حذف، كما أبدا كامل مجموعة استبدال غير متصل وسم.

## اعتبار مرور بديل خطة

**بلا بادئة وسم.** بلا بادئة اسم يمكن نقص قليل نظر شعور ضجيج صوت، لكن لا يمكن جدول واضح وسم تصنيف هو معنى رسم، مجال، مصدر، أولوية درجة أيضا هو تلقائي تحويل استخدام طريق. معا إبقاء بلا بادئة و حمل نطاق الأسماء نفس معنى وسم، أيضا سوف جعل استعلام و سياسة سياسة تنفيذ يحتوي معنى نموذج غامض.

**لا منطقة قسم صيانة درجة مفرد واحد وسم تجميع دمج.** بعض عدد وسم وجود، و لا يستطيع إثبات معنى رسم و دلالة نطاق كل مرور مرور اعتبار.

**مستودع سياسة سياسة في ثابت مجال سماح بيان.** حمل دائم مستودع مجال سوف عرض دخول.`area/*` نطاق الأسماء ما زال يمكن آلة آلة تعرف آخر، بينما الآن سطر شرح تحمل تحميل يمكن توسيع بيان.

**حسب حزمة أو مسار إرسال توليد مجال.** مجال وصف عبر تجاوز حزمة حد دلالة أثر، بينما تغيير مسار سوف يتضمن أحيانا لكن تعلق و اختبار، وثيقة و دعم حمل ملف.

**لـ كل نوع تسليم تحميل جسم أو وسيط جسم دورة الحياة مفرد ضبط وسم.** متصفح و Electron تسليم مشترك استخدام واحد رسم شكل واجهة مجال، ناتج، مرفق عنصر و كثير نموذج حالة تسليم هدف قبل أيضا مشترك استخدام واحد مراجعة/استعلام مجال. فقط لديه عند تفكيك قسم قدرة استعادة لديه استخدام مستقل تصنيف وقت، عندئذ ينبغي في لاحق تصنيف جسم نظام تغيير في إجراء.

**استخدام عرض عام تنفيذ وسم يحل محل منتج أو عمل مسار رئيسي عنوان.** واحد بند أداة جسم قدرة و لا فقط هو ذلك أداة، واجهة، نظام الملفات أو عملية تنفيذ. عام تنفيذ مجال فقط في ذلك ذاته سلوك أو API تغير وقت ملائم استخدام.

**في Issue فوق استخدام نوع وسم.** أصلي Issue Type قد مسؤول هذا بند تصنيف؛ مجددا استخدام وسم نسخ سوف صنع صار عائم نقل.

**فقط استخدام تقييم نقاش تنفيذ Issue سياسة سياسة.** تقييم نقاش سوف إبقاء بلا فاعلية بيانات وصفية؛ أي جعل وحيد صالح نتيجة هو إزالة، ما زال اشتراط شخص عمل تنظيف. دورة الحياة سوف مباشر تنفيذ هذا صنف إزالة، فقط مقابل لا يمكن دفع قطع اختيار إبقاء تقييم نقاش.

**كل PR تماما جيد واحد مجال.** داخل تجمع تغيير ممكن مقابل كثير عدد مستقل API أو سلوك إنتاج فعلي جودة أثر، إسقاط مرة يلزم مجال سوف إخفاء تلقي أثر نطاق.

## عاقبة

مراجعة شخص و تلقائي تحويل مسار يمكن قسم آخر استعلام معنى رسم، دلالة نطاق،Issue إنشاء طريقة، أولوية درجة و سير العمل إطلاق شرط. بلا فاعلية Issue وسم سوف مباشر إزالة فقد، لن إنتاج سياسة سياسة تقييم نقاش؛ وسم حدث سوف سجل هذا إصلاح. إذا لا وجود أخرى مخالفة قاعدة بند، دورة الحياة سوف حذف أكثر مبكر سياسة سياسة تقييم نقاش. صيانة من يجب قراءة قراءة تغيير محتوى و الآن سطر وسم شرح، بينما لا يستطيع أصل حسب عنوان بادئة أو مسار دفع قطع تصنيف. عند بعض نوع نوع أو بعض بند غير إظهار لكن مجال حد حدوث تغير وقت، الآن سطر وسم بيان، هذا سجل في قرار اعتماد حسب و سياسة سياسة تنفيذ يجب تزامن تحديث؛ تصنيف جسم نظام ترحيل أيضا سوف إنتاج واضح تاريخ عودة ملء و تحقق صار هذا.
