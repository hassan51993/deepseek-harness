# Agent Note: افتراضي إصدار فعلي تحقق صفة حزمة و إبقاء صريح خاص مثال خارج

Status: implemented

[English](2026-09-12-experimental-publication-denylist.md) | العربية

## مشكلة

عام فعلي تحقق صفة حزمة سماح قائمة اشتراط كل جديد إضافة دخول مستودع يمكن تثبيت أصل نوع كل تعديل مرة سياسة. فعلي تحقق صفة حالة وصف توافق صفة و دعم حمل مسبق مدة، لكن داخلي مخصص استخدام أصل نوع ما زال حاجة صريح ترتيب حذف إصدار.

## قرار

محلي npm baseline إصدار جهاز و عام dsh إصدار نظام صف افتراضي اكتشاف فعلي تحقق صفة حزمة.[`PRIVATE_EXPERIMENTAL_PACKAGE_DIRECTORIES`](../../../../scripts/experimental-package-policy.ts) مسؤول صريح خاص ترتيب حذف بند.[كامل فعلي تحقق حزمة إصدار قرار](2026-09-12-publish-all-experimental-packages.ar.md) جعل هذا رفض قائمة إبقاء لـ فارغ؛ كل حالي فعلي تحقق صفة حزمة كل مشاركة و إصدار.

رفض قائمة بـ خارج كل فعلي تحقق صفة دليل افتراضي عام.workspace قيد اشتراط عام حزمة حذف `private` و ضبط `publishConfig.access: public`؛ كل فعلي تحقق صفة حزمة إبقاء `@deepseek-ai/dsh-experimental-*` npm بادئة. إضافة خاص أصل نوع حاجة رفض قائمة بند و ذلك خاص manifest(بيانات وصفية بيان).

هذا قرار يحل محل [Agent Teams حزمة قرار](../architecture/2026-08-18-experimental-agent-teams-packages.ar.md) في افتراضي خاص إصدار أصل فإن. هذا قرار اعتماد عزل، صريح تفعيل تركيب، عمل مسار اشتراط و promotion قاعدة متابعة توليد فاعلية. إصدار لا توفير مستقر صفة أو دعم حمل تحمل وعد.

## سبق اعتبار بديل خطة

**إبقاء عام سماح قائمة.** أي جعل افتراضي إصدار مسار قدرة كاف اكتشاف جديد عام فعلي تحقق صفة حزمة، كل حزمة ما زال حاجة مقدار خارج سياسة بند.

**قيام أي إصدار كل فعلي تحقق صفة حزمة.** هذا سوف كشف قائم داخلي مخصص استخدام أصل نوع. صريح خاص رفض قائمة تغيير جديد حزمة افتراضي سياسة، معا إبقاء هذه أصل نوع حالي إصدار حالة.[كامل إصدار قرار](2026-09-12-publish-all-experimental-packages.ar.md) سجل مقابل هذه حزمة مفرد وحيد إصدار قرار.

## عاقبة

جديد فعلي تحقق صفة حزمة بلا حاجة تعديل سماح قائمة يكفي إضافة دخول اثنان بند npm إصدار مسار. خاص مثال خارج لديه واحد مشترك owner،workspace تحقق سوف رفض و لـ لا رمز manifest.
