# Agent Note: عبر منصة سلسلة سطر CI مشاركة اعتبار مسار

Status: implemented

[English](2026-07-21-serial-cross-platform-ci-reference.md) | العربية

## مشكلة

سحب أخذ طلب سير العمل سوف مطلوب فحص دمج إلى مخصص استخدام Linux و Windows عمل عمل في. هذه عمل عمل ما زال لا ينبغي يصبح وحيد كامل صفة حكم تحديد أساس دقيق: إذا ذلك بوابة بيان أو اعتماد رسم وجود نقص وقوع، أي جعل مطلوب تجمع دمج نتيجة إبقاء أخضر مصباح، أيضا ممكن تسرب إسقاط جزء عمل.

سوف غير Windows عمل عمل 1 قسم ساعة هدف و Windows عمل عمل 3 قسم ساعة هدف كتابة صار عمل عمل مهلة، سوف جذب دخول آخر نوع فشل نمط. حمل إدارة تشغيل جهاز بدء وقت و صفة قدرة سوف موجة حركة، لذلك أي جعل بوابة ذاته صحيح تأكيد، أيضا ممكن في وصول هدف وقت حد وقت يتم إلغاء، قدوم لا و إخراج لديه استخدام تشخيص معلومة. صفة قدرة هدف حاجة أصل حسب GitHub ختم الوقت توازن كمية، بينما صحيح تأكيد صفة تحقق حاجة إعطاء بوابة إبقاء كاف إتمام وقت.

مراجعة شخص أيضا حاجة مباشر عودة جواب واحد أكثر بسيط مفرد مشكلة: في كل اختيار تحديد حمل إدارة عملية نظام فوق، إذا مستودع كامل رئيسي Node CI تجمع دمج مسار لا استخدام مستطيل دفعة اختيار، قسم قطعة متغير أو تزامن بوابة، تشغيل نتيجة سوف كيف مثال؟

حقيقي داخل نواة صندوق رملي تحقق حاجة خاص تحديد حمل إدارة عملية نظام و هيكل بنية، لكن لن إنتاج سحب أخذ طلب دمج قطع قرار. في كل سحب أخذ طلب فوق تكرار تشغيل هذا عدد يتضمن أربعة عدد عمل عمل مستطيل دفعة سوف إزالة استهلاك Linux،arm64 Linux و macOS سعة كمية، لكن حيث لا يستطيع ممتلئ كاف فرع حفظ حماية، أيضا لا يمكن مشاركة و آخر سير العمل في مطلوب تجمع دمج نتيجة.

## قرار

[CI](../../../../.github/workflows/ci.yml)(فقط pull request) و [CI master](../../../../.github/workflows/ci-master.yml)(master دفع إرسال + `workflow_dispatch`) لـ سحب أخذ طلب حدث و master دفع إرسال حدث منح إعطاء متبادل تكملة مسؤولية. سحب أخذ طلب تشغيل Linux، أصلي Windows،[فقط في Linux متغير و معلومة مهمة شرط ممتلئ كاف وقت استخدام ذاتي حمل إدارة توجيه Node توافق صفة](2026-09-06-node-compatibility-selfhosted.zh.md) و Python فحص؛[منصة ضبط درجة](2026-09-06-master-only-platform-ci.zh.md) سوف Wine و ثلاثة عدد Python وقت التشغيل تحميل جسم قسم إعداد إعطاء master دفع إرسال. نحو `master` دفع إرسال وقت، حالي تفعيل مشاركة اعتبار عمل عمل هو عام شركة ذاتي لديه `vm-backup` حوض فوق `serial / linux (self-hosted standby)` و `dsh-win-ci` حوض فوق `serial / windows (self-hosted standby)`——هذه حار تجهيز عرض تدريب حمل متابعة تحقق[لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.zh.md) الذي وصف تبديل هدف. لا وجود معيار حمل إدارة `serial / linux` تعريف؛ معيار حمل إدارة `serial / macos` ما زال موضع في منع استخدام حالة، و من `TODO(hosted-serial-ci)` علامة، مباشر إلى ذلك يمكن نقل غرس سعة كمية استعادة. حالي `serial / windows` تعريف هو عام شركة ذاتي لديه `dsh-win-ci` حوض standby. كل منها مستقل عمل عمل تعريف متعمد صريح إبقاء بسيط قصير شفرة فحص خروج، وقت التشغيل ضبط و اعتماد قفل تحديد تثبيت خطوة، بينما لا هو استخدام مستطيل دفعة أو يمكن إعادة استخدام سير العمل إخفاء عملية نظام فرق مختلف.`workflow_dispatch` فقط لأجل تشغيل جهاز أساس دقيق اختبار.

كل مشاركة اعتبار عمل عمل متساو في لا ضبط أي قسم قطعة اختيار جهاز حال حال تحت تشغيل `pnpm run check:ci`.`DSH_GATE_CONCURRENCY=1` جعل قمة طبقة تجمع دمج كل مرة فقط تنفيذ واحد قد حينئذ خيط بوابة؛ نسبة التغطية، لقطة إعادة تشغيل،built-bin خطر دخان اختبار و إصدار تحقق worker عدد كمية أيضا ضبط لـ 1. كل مشاركة اعتبار عمل عمل يمكن ذاك هذا و سطر، لكن كل منصة رئيسي آلة فوق مستودع بوابة كل سلسلة سطر تشغيل كما كامل تنفيذ.Linux في إعادة تشغيل لقطة قبل تثبيت bubblewrap،Windows فإن في تثبيت اعتماد رمز رقم رابط مساحة العمل قبل تفعيل تطوير شخص عضو نمط.

هذا كامل تجمع دمج مسار ما زال واضح تخطيط قسم منصة ملكية.`terminal-bash` دعم حمل Linux و macOS، لذلك ذلك اختبار وحدة و تدريجي ملف نسبة التغطية اتفاق من POSIX منصة مسؤول، بينما لن في Windows فوق تحميل واحد واضح رفض `win32` خلفية؛Windows ما زال سوف تنفيذ كل يمكن نقل غرس حزمة. يمكن نقل غرس fixture(اختبار قبل وضع بيانات) عبر `node:path` إرسال توليد أصلي مسار، استخدام و إنتاج شفرة نفسه أصلي realpath تنفيذ مقارنة مقارنة مواصفة تحويل بعد مسار معرف، و اعتماد كل مضيف آلة متساو سماح ملف اسم.ACP(Agent Client Protocol) لقطة تشغيل أيضا سوف يأخذ توليد cwd قسم آخر عبر realpath JavaScript تنفيذ و أصلي تنفيذ نيل إلى اثنان نوع يمثل واحد و نقل إعطاء مواصفة تحويل جهاز؛ مواصفة تحويل جهاز حسب طويل درجة من طويل إلى قصير استبدال هذه آخر اسم، تجنب تجنب Windows قصير مسار و طويل مسار يمثل فرق مختلف توجيه يؤدي مشترك fixture عكس تكرار تغير.

macOS مشاركة اعتبار مسار استخدام fork عملية تشغيل معتاد قاعدة Vitest مشروع.macOS arm64 فوق Node 24 سبق في عمل خط مسار في تنفيذ CJS كلمة قاعدة قسم تحليل جهاز وقت استثناء إنهاء؛ عملية حد قدرة كاف عزل هذا واحد خارجي وقت التشغيل لذا عائق، كما بلا حاجة من تجمع دمج مسار في حذف أي اختبار، بينما Linux و Windows ما زال استخدام فتح إلغاء أكثر منخفض خط مسار حوض. مستودع ذاته جذب دخول تنافس حالة متساو في متبادل ينبغي مراقبة قياس حد إصلاح: تطوير بناء ناتج جولة استفسار منطق كل مرة إصدار إعادة مسح نتيجة قبل، كل سوف أولا مؤقت تخزين مرشح جدول، مرشح رسم و مرشح مراقبة نظر أساس خط خريطة؛ بناء ناتج ناقص بعد سوف واحد مباشر إبقاء قذر حالة، مباشر إلى نجاح حساب حساب محتوى ها أمل.PTY حينئذ خيط فحص قياس سوف في جولة استفسار فحص قبل منصة عملية مجموعة ملكية خلال إبقاء تلميح رمز مرشح بند؛ معتاد قاعدة ساكن صامت وقت حد أيضا شمول غطاء من تفاعل صيغة عملية فرعية وراثة بينما قدوم علامة. حقيقي PTY fixture سوف في وقت التشغيل تجميع وصل تزامن علامة، جعل حينئذ خيط انتظار منطق لن يأخذ تفاعل صيغة shell إدخال عودة إظهار خطأ حكم لـ عملية فرعية قد حينئذ خيط. فوري رابط مشهد تحت حزمة إدارة جهاز e2e سوف إبقاء من سير العمل مسبق أولا دقيق تجهيز Corepack رئيسي دليل،pnpm بيانات وصفية ذاكرة مؤقتة و store ذاكرة مؤقتة، معا عزل أخرى حزمة إدارة جهاز متغير ذاكرة مؤقتة، لذلك لن في تثبيت قبل إسقاط يمكن إعادة استخدام حزمة إدارة جهاز حالة.

مستقل [Sandbox](../../../../.github/workflows/sandbox.yml) سير العمل يخص نفس مسؤولية تخطيط قسم في مشاركة اعتبار جانب. ذلك bwrap،Landlock x64/arm64 و Seatbelt حقيقي داخل نواة مستطيل دفعة فقط في نحو `master` دفع إرسال بعد تشغيل. هذا أربعة عدد عمل عمل فقط لأجل تشخيص: هو جمع حيث لا هو فرع حفظ حماية مطلوب بند، أيضا لن عبر سير العمل حساب دخول `all checks passed`. سحب أخذ طلب CI ما زال عبر معتاد قاعدة اختبار وحدة و نسبة التغطية بيان فحص صندوق رملي شفرة المصدر؛ مضيف داخل نواة و packed-install تحقق في دمج بعد تقرير إبلاغ نتيجة.

master فرع مشاركة اعتبار عمل عمل فقط لأجل تشخيص، لا مشاركة و سحب أخذ طلب الذي اشتراط `all checks passed` نتيجة.ci-master و Sandbox سير العمل يأخذ عبر منصة مشاركة اعتبار مسار إبقاء في master دفع إرسال فوق. نظام أصل حسب قد إتمام حمل إدارة عمل عمل ختم الوقت تقييم تقدير صفة قدرة، و سوف ذلك تقرير إبلاغ لـ قياس كمية نتيجة، بينما لا هو كتابة صار `timeout-minutes` قيمة.

حالي تفعيل مشاركة اعتبار مسار تشغيل في عام شركة ذاتي لديه `vm-backup`(`serial / linux`) و `dsh-win-ci`(`serial / windows`) ذاتي حمل إدارة حوض فوق؛ وحيد باق بقية منع استخدام حمل إدارة مشاركة اعتبار عمل عمل (`serial-macos`) استخدام `macos-latest`، كما لا وجود معيار حمل إدارة `serial / linux` وسم. فقط master إطلاق Wine عمل عمل في `ubuntu-latest` فوق تشغيل، بينما سحب أخذ طلب أصلي عمل عمل في صحيح معتاد تشغيل تحت استخدام حمل إدارة `dsh-windows-2025-16core` تشغيل جهاز، في `selfhosted` لذا عائق تبديل أخذ قيمة تحت استخدام ذاتي حمل إدارة `[self-hosted, dsh-win-ci, windows]` حوض، في `blacksmith` أخذ قيمة تحت استخدام Blacksmith Windows تشغيل جهاز (رؤية [blacksmith لذا عائق تبديل دعم مسار قلم تسجيل](2026-09-09-blacksmith-failover-leg.zh.md) ؛ آخر رؤية[لذا عائق تبديل يد سجل](2026-07-26-ci-failover-runbook.zh.md)) ، اعتماد حسب[أصلي Windows قرار](2026-08-08-native-windows-pull-request-ci.zh.md) ، منها بناء و تحديد نحو عملية فحص مشاركة و مطلوب تجمع دمج مسار. اعتماد حسب[مطلوب CI قرار](../../archived/process/2026-07-23-portable-required-pull-request-ci.md) ، سحب أخذ طلب مطلوب عمل عمل استخدام يمكن نقل غرس معيار سعة كمية. أكثر عال نواة قلب عدد حمل إدارة تشغيل جهاز ما زال فقط لأجل يد حركة أساس دقيق اختبار، لأن صحيح تأكيد صفة مسار يجب بلا حاجة مستودع خارجي تشغيل جهاز إعداد يكفي تشغيل.

## سبق اعتبار بديل خطة

- **سوف كل مهلة قيمة ضبط لـ متبادل ينبغي تأخير متأخر هدف**: غير مقبول، لأن ضبط درجة موجة حركة سوف في توقف أصل هذا صحيح تأكيد تنفيذ، و جعل تشخيص ارتداد الذي يحتاج دليل لا يمكن إنتاج.
- **فقط معلومة مهمة تزامن تنفيذ رئيسي بوابة بيان**: غير مقبول، لأن ضبط درجة منطق و تحقق منطق مشترك تنفيذ زائف ضبط؛ سلسلة سطر تجمع دمج مسار هو واحد بند مستقل كامل صفة فحص.
- **في كل سحب أخذ طلب فوق تشغيل سلسلة سطر مشاركة اعتبار عمل عمل**: غير مقبول، لأن هذه عمل عمل سوف تكرار كامل عبر منصة تجمع دمج مسار، و لـ كل بند تعديل زيادة macOS عمل؛ مطلوب عمل عمل قد تنفيذ منع سد صفة Linux و أصلي Windows فحص، بينما ذلك هو أصلي عمل عمل توفير كامل Windows نتيجة.
- **في كل سحب أخذ طلب فوق تشغيل حقيقي داخل نواة Sandbox مستطيل دفعة**: غير مقبول، لأن هو أربعة عدد حالة لا مشاركة و فرع حفظ حماية، بينما تكرار تثبيت،Landlock بناء و لـ إبقاء منصة متسق بينما تشغيل macOS اختبار وحدة سوف إزالة استهلاك تشغيل جهاز سعة كمية، لكن لن تغيير دمج قطع قرار.master فوق تشغيل إبقاء منصة و قد تثبيت launcher إشارة.
- **استخدام واحد عملية نظام مستطيل دفعة**: غير مقبول، لأن ثلاثة عدد أداة اسم عمل عمل بلا حاجة آخر طقم اختيار آلية، حينئذ قدرة يجعل مشاركة اعتبار مسار بنية صار صاف واضح مرئي.
- **في كبير نوع تشغيل جهاز فوق تشغيل سلسلة سطر مشاركة اعتبار مسار**: غير مقبول، لأن عند مجموعة نسج ذاتي لديه تشغيل جهاز حوض لا يمكن قسم إعداد عمل عمل وقت، مطلوب CI و ذلك مستقل مشاركة اعتبار مسار كل يجب ما زال يمكن تشغيل.

## عاقبة

سير العمل يتضمن تكرار ضبط خطوة،master مشاركة اعتبار تشغيل أيضا ممكن مقارنة أفضل تحويل بعد سحب أخذ طلب مسار استهلاك وقت طويل نيل كثير. هذه تكرار هو متعمد إبقاء: مراجعة شخص بلا حاجة تحليل مستطيل دفعة أو تزامن مجدول، حينئذ قدرة مباشر فحص كل نوع عملية نظام تنفيذ كامل أمر.

مشاركة اعتبار مسار ممكن كشف بعض بعض منصة فوق لذا عائق، بينما أفضل تحويل بعد منع سد بوابة تجميع دمج بعد لم إعلان دعم حمل هذه منصة،Windows خاصة ذلك مثل هذا. هذا صنف فشل عكس عكس حالي عبر منصة سلوك، لا ينبغي يصبح تقليل ضعيف أو ساكن صامت قفز مرور هذا تجمع دمج مسار إدارة من.

فقط في حقيقي مضيف داخل نواة أو تحزيم بعد Landlock تثبيت في مرئي صندوق رملي ارتداد، ممكن في master فوق تشغيل تقرير إبلاغ قبل قد دمج. أنا جمع قبول هذا عدد دمج بعد فحص قياس نافذة، بـ تبديل أخذ من كل سحب أخذ طلب في إزالة أربعة عدد غير منع سد عمل عمل؛ افتراضي فرع ما زال إبقاء كامل إشارة.

واضح `terminal-bash` ملكية حد معنى طعم حال Windows لن صوت تسمية تغطية واحد لا يمكن تحميل خلفية، بينما macOS اعتماد fork اختبار وحدة عمل عملية سوف زيادة عملية بدء فتح إلغاء. هذه بديل قيمة تبديل قدوم هو: دعم حمل نطاق داخل كل جهة وجه كل لديه قدرة كاف مثل فعلي عكس عكس مقابل منصة سلوك حكم حسب، أصلي وقت التشغيل استثناء إنهاء لن مسح إسقاط ذلك بقية اختبار وحدة نتيجة، كل بند مقابل وقت ترتيب حساس شعور مراقبة قياس منطق أيضا كل سوف بـ استدعاء جهة لديه آلة سوف تعديل حالة قبل قد بناء قيام حالة بصفة بدء نقطة.

إزالة صارم إطار وقت طويل مهلة بعد، نظام سوف مراقبة قياس إلى تأخير متأخر ارتداد، بينما لا هو في حدوث ارتداد وقت تلقائي إلغاء تشغيل. لذلك، صفة قدرة تعديل يجب مرفق حمل حمل إدارة بيئة قياس كمية نتيجة، قد إتمام سجل فإن إبقاء أفضل تحويل الأكثر بطيء عبر طريق الذي يحتاج معلومة.
