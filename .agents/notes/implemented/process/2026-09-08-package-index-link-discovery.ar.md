# Agent Note: سوف حزمة بحث جذب قبول دخول Markdown رابط اكتشاف نطاق

Status: implemented

[English](2026-09-08-package-index-link-discovery.md) | العربية

## مشكلة

في `verify-md-links` في، تضمين طقم مجموعة درجة و حزمة درجة glob لا يمكن مطابقة `packages/README.md` و منها نص مقابل ملف. حذف غير فحص جهاز أيضا اكتشاف هذه مصدر ملف، لا فإن اثنان نسخة بحث جذب في ميت سلسلة كل لن دخول تحقق.

## قرار

[`verify-md-links`](../../../../scripts/verify-md-links.ts) في قائم مصدر ملف اكتشاف نطاق في إضافة دخول `packages/*.md`. أمر و اختبار مشترك استخدام نفس عدد اكتشاف دالة. رمز رقم رابط ذهاب إعادة و تجميد ربط Agent Note ترتيب حذف ما زال من [`repo-files`](../../../../scripts/repo-files.ts) مسؤول.

## اعتبار مرور بديل خطة

**فقط إصلاح عدد آخر رابط.** هذا سوف إبقاء مصدر ملف اكتشاف متروك تسرب، لاحق إضافة جديدة بحث جذب ميت سلسلة ما زال ممكن عبر نفس فحص.

**آخر إضافة حزمة بيان فحص جهاز.** بحث جذب كامل صفة و رابط صالح صفة هو مختلف اشتراط. قبل من حاجة دعم حمل حالي جدول إطار صيغة و مزدوج لغة رابط هدف، لا يستطيع بديل مقابل كل قد اكتشاف مصدر ملف رابط فحص.

## عاقبة

اثنان نسخة حزمة بحث جذب في متبادل مقابل ميت سلسلة سوف جعل قائم وثيقة أمر فشل. اكتشاف اختبار تغطية هذه فشل، إبقاء حزمة درجة إشارة أمر ملف و تضمين طقم وثيقة فحص نطاق، و ترتيب حذف تجميد ربط قلم تسجيل. هذا فحص تحقق رابط، لا اشتراط بحث جذب قطعة رفع كل حزمة، أيضا لا تعريف أخرى وثيقة فحص مصدر ملف تجميع دمج.
