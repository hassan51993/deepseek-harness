# Agent Note: Agent Note موحد واحد تلقي بوابة قيد ملف داخل صيغة

Status: implemented

[English](2026-07-05-uniform-agent-note-format.md) | العربية

## مشكلة

Agent Note مسار تحرير رمز دورة الحياة و صنف آخر، لكن ملف محتوى ما زال خلط مختلط حال مختلف عنوان، حالة صيغة،ADR و رفع سجل نموذج لوح، و قد تنفيذ سجل في رفع سجل مرحلة مقطع فصل عقدة. عمل من سوف نسخ مع يد بحث إلى متبادل مجاور ملف، بينما دورة الحياة ترحيل ممكن قفز مرور لا بد يلزم تعديل كتابة، لأن لا يوجد بوابة قوي صنع تنفيذ ملف داخل اتفاق.

## قرار

[README.md § ملف صيغة](../../README.ar.md#the-file-format) هو ملف داخل اتفاق——رأس جزء كتلة (`# Agent Note: <title>`، إضافة فوق بلا يوم مدة كما و ملف مشبك متسق `Status:` قطعة رفع، منها فقط لديه رفض سبب يمكن بصفة مقدار خارج محتوى) ، كل دورة الحياة متن هيكل هيكل (كل ملف متساو بـ `Problem` فتح مقالة؛`proposed/` استخدام `Proposal`/`Acceptance criteria`/`Risks`؛`implemented/` استخدام الآن وقت `Decision`/`Consequences`، و منع توقف رفع سجل مرحلة مقطع عنوان؛`rejected/` تجميد ربط رفع سجل بنية) ، قوي صنع `Alternatives considered` فصل عقدة، و مواصفة فصل عقدة مفردات؛ تحديد صنع تقنية فن فصل عقدة يمكن في هذه مواصفة فصل عقدة بين إبقاء ذاتي من شكل صيغة.`pnpm run verify-agent-note-format`([scripts/verify-agent-note-format.ts](../../../../scripts/verify-agent-note-format.ts)) بصفة `doc-sync` واحد جزء قوي صنع تنفيذ كل بند آلة آلة قاعدة، لذلك قفز مرور تعديل كتابة دورة الحياة ترحيل الآن سوف جعل CI فشل، بينما لم يعد اعتماد مراجعة من تسجيل ذاكرة.

تعريف هذا صيغة نفس تغيير مواصفة تحويل كامل لغة مادة مكتبة——التزام دوران مسبق إصدار قيام ساحة: لا ضبط مرور عبور مدة، لا سعة تحمل مزدوج صيغة. وحيد ملائم استخدام قائم محتوى إعفاء تجنب هو محتوى، بينما غير صيغة: بديل خطة فقط قدرة سجل، لا يستطيع منع تأليف، لذلك إذا بعض نسخة صيغة صنع تحديد قبل Agent Note لا يمكن من سجل في أيضا أصل بديل خطة، حينئذ سوف حمل لديه محتوى تماما مطابقة `agent-note-format: alternatives-not-recorded` ملاحظة تفسير؛ بوابة فقط مقابل يوم مدة مبكر في هذا نص ملف قبول هذا ملاحظة تفسير.

## سبق اعتبار بديل خطة

- **كامل للتو صفة نموذج لوح**(كل دورة الحياة استخدام ثابت فصل عقدة ترتيب، إعادة بنية كل نسخة Agent Note بـ ملائم إعداد): مرفوض. كبير نوع تصميم Agent Note يتضمن ثمانية إلى عشرة خمسة عدد تحديد صنع تقنية فن فصل عقدة (حزمة توسيع اندفاع، بروتوكول اتفاق،schema) ، هو جمع هو تحمل تحميل تصميم محتوى، بينما غير عائم نقل؛ للتو صفة ترتيب سوف إجبار جعل أنا جمع الآن إجراء كسر تالف صفة تعديل كتابة، و دائم بعيد و نموذج لوح مقارنة قوة.
- **فقط مواصفة تحويل رأس جزء**(H1 و Status، متن لا حركة): مرفوض. دين خدمة علامة إشارة خروج هو*متن*جسم قطع قسم شق، يجعل `Context`/`Decision` و `Problem`/`Proposal` بلا حد مدة و تخزين ماذا أيضا حل قرار لا.
- **لا ضبط Status سطر**(ملف مشبك قد يمثل حالة؛ صيغة صنع تحديد قبل الأكثر جديد ثلاثة نسخة Agent Note و منها واحد نسخة العربية مقابل ملف حذف هذا سطر): مرفوض، إبقاء ملف ذاتي وصف صفة. عبر بوابة تحقق هذا سطر و ملف مشبك متسق، إزالة حذف أصل هذا حث جعل أنا جمع حذف هو عائم نقل ريح خطر.
- **حمل يوم مدة Status**(`Status: implemented (accepted YYYY-MM-DD)`): مرفوض. قبول يوم مدة يخص سرد وصف صفة تاريخ، كتابة عمل قاعدة سوف ذلك ترتيب حذف في وثيقة خارج؛ ملف اسم تحمل تحميل أول مرة رفع خروج يوم مدة،git تحمل تحميل ذلك بقية معلومة؛ بوابة قدرة فحص يوم مدة صيغة، لكن دائم بعيد لا يمكن فحص ذلك حقيقي صفة.
- **عار `# <title>` H1**: مرفوض. ملف انفصال مغادرة دليل شجرة مفرد وحيد قراءة قراءة وقت،`Agent Note: ` بادئة قدرة ذاتي وصف ذلك جسم قطع، بينما صيغة بوابة يمكن منع توقف هو عائم نقل.
- **بـ `## What we give up` بصفة قد تنفيذ سجل ربط ذيل**(README مقابل Agent Note الذي سجل محتوى أصل لديه جدول وصف): مرفوض. هو فقط نقطة خروج صار هذا، بينما صدق فعلي عاقبة فصل عقدة أيضا سوف سجل أخذ ترك تبديل قدوم ماذا.
- **فقط لديه معتاد مثال لا يوجد بوابة**(كتابة تحت اتفاق، اعتماد مراجعة قوي صنع تنفيذ): مرفوض.slop checklist قد عبر معتاد مثال منع توقف في `implemented/` في استخدام spec لغة هواء، بينما عشرة تسعة عدد ملف عرض فقط اعتماد معتاد مثال في هذا موضع قدرة بلوغ إلى ماذا فاعلية نتيجة.
- **مستقل `FORMAT.md` اتفاق ملف**: مرفوض. من واحد مدخل معا تحمل تحميل تخطيط، تصنيف و صيغة، مقارنة صيانة اثنان عدد اتفاق ملف أكثر سهل اكتشاف و صيانة.

## عاقبة

الآن كل نسخة Agent Note كل حاجة قليلا كثير واحد بعض بنية، بينما قوي صنع `Alternatives considered` فصل عقدة هو متعمد ضبط منع قوة: سجل قرار لكن لا سجل هو فوز مرور ماذا، سوف استدعاء يؤدي Agent Note هذا ينبغي منع توقف إعادة تنازع نقاش. لا يمكن أيضا أصل بديل خطة صيغة صنع تحديد قبل Agent Note سوف دائم دائم إبقاء قائم محتوى إعفاء تجنب ملاحظة تفسير——هذا هو سجل في صدق فعلي نقص فتحة، بينما لا هو منع تأليف إدارة من.`doc-sync` زيادة واحد طريق بوابة؛ في دورة الحياة ملف مشبك بين نقل حركة Agent Note وقت، الآن يجب عند ساحة إتمام حق صحيح عمل (ترحيل هذا حينئذ ينبغي يتضمن متن تعديل كتابة) ، بينما لا هو دفع متأخر لـ بلا شخص تتبع أثر تنظيف مهمة. ثلاثة عشرة تسعة عدد دين خدمة علامة قد إزالة فقد، من هو جمع واحد مباشر انتظار نموذج لوح حل قرار.
