# Agent Note: سوف Node LTS جذب محرك تحت حد رفع رفع حتى 22.19

Status: implemented

[English](2026-07-06-node-engine-floor.md) | العربية

## مشكلة

أصل `engines.node` نطاق في Node 22 فرع هو مقابل تثبيت بعد مساحة العمل اتفاق، بينما لا فقط فقط هو harness شفرة المصدر مباشر استدعاء وقت التشغيل API اتفاق. هو لا نيل منخفض في مساحة العمل في هذا فرع فوق تثبيت اعتماد حزمة الذي إعلان `engines.node`؛ لا فإن `pnpm install --engine-strict` سوف في واحد قد إعلان نقل LTS إصدار فوق فشل، بينما غير صارم إطار نمط تحت تثبيت نتيجة فإن سوف في اعتماد الذي دعم حمل وقت التشغيل نطاق خارج تشغيل.

## قرار

سوف `engines.node` ضبط لـ `^22.19.0 || >=24.0.0`، و في `['22.19', 24, 26]` فوق تشغيل keyless CI. رئيسي يلزم Node 24 مهمة مسؤول كامل طقم نوع فحص و اختبار وحدة نسبة التغطية مهمة؛ ثلاثة عدد إصدار متساو تشغيل source-worker،Zstandard،source-launch و [jsdom تخزين](../../archived/testing/2026-07-30-vitest-jsdom-webstorage-ownership.md) مخصص بند خطر دخان اختبار، لا تكرار هذا طقم نوع فحص و نسبة التغطية مهمة. حقيقي API e2e سير العمل إبقاء في Node 24 فوق، لأن هو تحقق هو API تجميع صار بينما غير وقت التشغيل تحت حد.

اثنان عدد Node خاص صفة قرار شفرة المصدر وقت التشغيل باب عتبة:

- **`node:sqlite`**:`packages/storage/storage-sqlite` في قمة طبقة تنفيذ `import { DatabaseSync } from 'node:sqlite'`، اختياري Session-query provider فإن في أول مرة بحث وقت تحميل هو. هذا وحدة في **22.13**(LTS) و **23.4**(Current) إلغاء `--experimental-sqlite` علامة سجل اشتراط؛ في هذا قبل، استيراد هو سوف في تحميل وقت رمي خروج استثناء.
- **أصلي TypeScript نوع تقشير مغادرة**——بناء نمط `apps/cli/tests/profiles/headless/tests/keyless-smoke.e2e.ts` خطر دخان اختبار استخدام صاف `node`(بلا tsx) بدء test-support `.ts` driver، و تحميل `.ts` اختبار مهايئ (`cli-mock-llm.ts`). نوع تقشير مغادرة من **22.18**(LTS) و **23.6**(Current) بدء يصبح افتراضي سلوك؛ أكثر مبكر إصدار حاجة `--experimental-strip-types`.

هذه شفرة المصدر خاص صفة في 22.x خط فوق في **22.18** الكل حينئذ خيط، لكن قد تثبيت Pi مهايئ اعتماد سوف إعلان نقل LTS تحت حد دخول واحد خطوة رفع عال.`@deepseek-ai/dsh-llm-pi-ai` اعتماد `@earendil-works/pi-ai@0.79.3`، بعد من حزمة إعلان `engines.node >=22.19.0`، لذلك LTS تحت حد لـ **22.19**.24.x فرع إبقاء `>=24.0.0`. هذا لا متبادل تسليم نطاق تماما ترتيب حذف Node 23:Node 23.0–23.5 حتى قليل أيضا لديه واحد شفرة المصدر خاص صفة حاجة علامة سجل، بينما 23 خط هو غير LTS/قد EOL ، إعلان نقل `>=23.6` سوف زيادة واحد بند قد إنهاء إصدار خط و واحد بند CI فرع، بينما لا يوجد أي نشر ينبغي عند استخدام هو.

`@types/node` متابعة ثابت في 22.x خط (`^22.20.0`) ، بـ مطابقة LTS دعم حمل خط: استخدام Node 23+/24+/25+ API سوف في كل آلة جهاز و نوع فحص بوابة في توجيه يؤدي `tsc` فشل، بينما لا هو أولا تحرير ترجمة عبر، مباشر إلى تحت حد مستطيل دفعة فرع وقت التشغيل عندئذ كشف خطأ. كامل شفرة شجرة إبرة مقابل Node 22 نوع API نوع فحص الكل عبر، لذلك ثابت هذا إصدار لا إنتاج أي بديل قيمة.

## عاقبة

- إعلان نقل LTS فرع لم يعد منخفض في Pi مهايئ اعتماد تحت حد.
- CI عبر Node 22.19 مباشر تحقق Node 22 LTS تحت حد، سوف رئيسي يلزم نسبة التغطية مهمة إبقاء في `node: 24`، و استخدام Node 26 تحقق تحت واحد أحيانا عدد خط؛ ثلاثة عدد إصدار متساو تشغيل تجمع تركيز توافق صفة خطر دخان اختبار.
- بناء نمط خطر دخان اختبار بلا حاجة إصدار شرط علامة سجل: في 22.19 فوق نوع تقشير مغادرة قد هو افتراضي سلوك، لذلك عرض مثال ذاتي لديه TypeScript driver إبقاء استخدام صاف `node fixture.ts` مسار.
- لم قدوم إذا اعتماد أو شفرة المصدر API رفع عال وقت التشغيل تحت حد، يجب في نفس تغيير في تزامن ضبط كامل `engines.node`، توافق صفة مستطيل دفعة و هذا Agent Note.

## سبق اعتبار بديل خطة

- **إبقاء `^22.18.0 || >=24.0.0`.** مرفوض: هو إعلان نقل LTS إصدار منخفض في Pi مهايئ اعتماد تحت حد.`@earendil-works/pi-ai@0.79.3` اشتراط `>=22.19.0`.
- **تخفيض أو ثابت `@earendil-works/pi-ai` بـ إبقاء 22.18 إعلان نقل نطاق.** مرفوض: حالي Pi مهايئ اعتماد هو مسبق مدة مساحة العمل واحد جزء، كما 22.19 ما زال في Node 22 LTS خط داخل.
- **تحت حد `>=22.13`(`node:sqlite` حد) إضافة فوق في 22.13–22.17 built-bin خطر دخان اختبار في استخدام `--experimental-strip-types`.** مرفوض: هو لـ واحد ضيق ضيق نطاق زيادة إصدار شرط اختبار علامة سجل، و سوف فعلي تحقق صفة علامة سجل اعتماد حزمة تركيب لـ صحيح صيغة دعم حمل.Pi مهايئ اعتماد قد اشتراط أكثر عال LTS تحت حد.
- **استخدام بلا حد أعلى `>=22.19`.** مرفوض: هو إعلان نقل دعم حمل Node 23.0–23.5، بينما في هذه إصدار فوق `node:sqlite`(مباشر إلى 23.4) أو نوع تقشير مغادرة (مباشر إلى 23.6) ما زال يحتاج علامة سجل.
- **يتضمن Node 23.6+(`^22.19.0 || >=23.6.0`).** مرفوض:23.6+ تأكيد فعلي قدرة بلا علامة سجل تشغيل اثنان عدد شفرة المصدر خاص صفة، لكن Node 23 قد انتهاء دورة الحياة (EOL) ؛ إعلان نقل واحد بند قد إنهاء إصدار خط سوف زيادة واحد نطاق بند و واحد بند CI فرع، بينما لا يوجد أي نشر ينبغي عند استخدام هذا وقت التشغيل.
- **مستطيل دفعة `[22, 24, 26]` بينما غير ثابت `22.19`.** مرفوض: طفو حركة رئيسي رقم الإصدار بند سوف مع وقت فوق عائم، صامت لكن لم يعد تحقق الذي إعلان LTS تحت حد.
- **إبقاء `@types/node` تجاوز قبل في وقت التشغيل تحت حد (`^25`).** مرفوض: نوع تعريف تجاوز قبل في وقت التشغيل تحت حد سوف يجعل فقط Node 24/25 عندئذ لديه API تحرير ترجمة عبر، فقط في 22.x فوق وقت التشغيل عندئذ فشل. سوف `@types/node` ثابت في 22.x خط فوق يمكن سوف هذا صنف مشكلة تحويل تحويل لـ كل بيئة تحت تحرير ترجمة خطأ.
