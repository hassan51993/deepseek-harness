# Agent Note: متصفح رقم ثلاثة جهة مكتبة بصفة بناء إدخال

Status: implemented

[English](2026-09-08-browser-third-party-build-inputs.md) | العربية

## مشكلة

مسبق بناء متصفح إضافة رقم ثلاثة جهة تنفيذ قد مع JavaScript توزيع، لكن إنتاج NPM اعتماد ما زال يجعل تثبيت جهاز آخر خارج تحت تحميل هذه مكتبة و تحليل ذلك مقابل انتظار اعتماد (peer dependency).React فقط في بناء مدة إعلان وقت، تثبيت جهاز يمكن لـ هذه مقدار خارج اعتماد اختيار و متصفح ناتج مختلف React إصدار.`use-sync-external-store@1.2.0` و `@tanstack/react-virtual@3.14.9` كل دعم حمل حالي React 18؛ مشكلة لا اشتراط ترقية React.

## قرار

متصفح مخصص استخدام رقم ثلاثة جهة اعتماد يخص `devDependencies`، يشمل حركة حالة إضافة داخل ربط تنفيذ، ساكن حالة متصفح مكتبة إدخال، و من Web قشرة توفير مشترك نسخة React. هذا قاعدة جزء يحل محل[قد إصدار اعتماد تصنيف](2026-08-26-published-dependency-faces.ar.md) مقابل عادي رقم ثلاثة جهة إعلان إبقاء سياسة؛ هذا وثيقة متابعة قاعدة تحديد حزمة اختيار نطاق،Host قيمة اعتماد و Cordis نسخة هوية.

اعتماد تصنيف جهاز من شفرة المصدر استيراد و JSX استلام تجميع بناء إدخال.Host وقت التشغيل يمكن بلوغ رقم ثلاثة جهة مكتبة أولوية عودة دخول `dependencies`؛ مقدار خارج Node بناء مدخل أيضا يجب قبول دخول فحص. شفرة المصدر في صاف نوع مرجع لا إنتاج Host وقت التشغيل اعتماد. إعداد بيانات وصفية و مشترك Host تصدير قائم تصنيف إبقاء ثابت.

NPM حقل لا قرار متصفح تحزيم طريقة. حركة حالة إضافة متابعة داخل ربط خاص مكتبة، و من منصة وحدة جدول قراءة React انتظار مشترك وحدة؛ ساكن حالة متصفح مكتبة متابعة إبقاء عار استيراد و مثال صيغة، من نهائي Vite بناء معالجة. ساكن حالة حزمة هو Web قشرة بناء إدخال، لا تحمل وعد مستقل تثبيت بعد أداة تجهيز اثنان مرة تحزيم الذي يحتاج الكل اعتماد. شفرة المصدر بناء حاجة تطوير اعتماد؛ تثبيت قد إصدار Web ناتج لا حاجة هو جمع.

سماح يمكن إثبات تصنيف بـ تسليم محتوى لـ دقيق. حقيقي متصفح بناء إعداد اعتماد تحليل معا تغطية حركة حالة إضافة و Web قشرة؛ تحليل إلى رقم ثلاثة جهة تنفيذ ما زال حساب دخول[وقت التشغيل كشف كشف](2026-07-30-generated-third-party-notices.ar.md) ، أي جعل بيان سوف ذلك صف لـ تطوير اعتماد. اختبار أداة، صاف نوع استيراد و بناء أداة لن فقط بسبب موضع في `devDependencies` بينما حساب عمل توزيع شفرة.

## اعتبار مرور بديل خطة

**لـ إنتاج تثبيت مقدار خارج إعلان React، أو قوي صنع تغطية مقابل انتظار اعتماد.** هذا إبقاء متصفح لا استخدام مقدار خارج تثبيت رسم، كما و لم جعل تثبيت فرعي هذا يصبح متصفح مشترك نسخة.

**يأخذ ساكن حالة مكتبة كل اعتماد رفع قبل داخل ربط.** هذا سوف تغيير Vite مقابل رقم ثلاثة جهة قسم كتلة، ذاكرة مؤقتة و CSS معالجة؛ اعتماد تصنيف لا حاجة تغيير هذه بناء سلوك.

**يأخذ حمل Client حزمة الكل رقم ثلاثة جهة اعتماد نقل مشي.** مزدوج وجه حزمة ما زال ممكن في Host تحميل مكتبة، مثال مثل ZIP إخراج الذي استخدام `fflate` و RPC تحقق الذي استخدام `zod`؛ هذه تثبيت علاقة يجب إبقاء.

**حسب بيان حقل مباشر تخطيط قسم سماح يمكن إثبات كشف كشف.** متصفح شفرة تسليم و تثبيت جهاز هل تحت تحميل نفس اسم حزمة لا هو نفس واقع، لا يستطيع لذلك إلغاء مقابل توزيع شفرة سماح يمكن إثبات فحص.

## نتيجة

إنتاج اعتماد لم يعد لـ صاف متصفح تنفيذ تكرار تثبيت رقم ثلاثة جهة مكتبة.React و React DOM إبقاء نفس بناء إصدار، إضافة متابعة إزالة استهلاك Web قشرة مشترك نسخة. تصنيف اختبار معا قيد متصفح dev-only،Host أولوية و إصلاح قوة انتظار؛ إصدار فحص رفض React تثبيت تسرب تسرب، متصفح ناتج تحقق مستقل تغطية فعلي وحدة تحميل.

تصنيف فحص إبقاء شفرة المصدر تنفيذ طريقة. سماح يمكن إثبات تحليل أيضا لا يستطيع اعتماد قد لديه `lib/` أو كتابة بناء إخراج؛ ذلك اختبار تغطية حقيقي تحليل، صاف نوع مسح حذف، مورد مرجع و ناقص اعتماد. مستقل إزالة استهلاك ساكن حالة حزمة أو عام نوع تطوير من حاجة ذاتي ذات توفير متبادل ينبغي بناء اعتماد؛ هذا قرار لا زيادة مستقل متصفح مكتبة دعم حمل تحمل وعد.
