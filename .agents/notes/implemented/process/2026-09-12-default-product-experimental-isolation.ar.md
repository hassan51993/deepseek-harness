# Agent Note: سوف فعلي تحقق حزمة عزل في افتراضي منتج خارج

Status: implemented

[English](2026-09-12-default-product-experimental-isolation.md) | العربية

## Problem

في npm فوق عام متاح لا معنى طعم حال فعلي تحقق حزمة يخص افتراضي منتج. مباشر manifest فحص سوف تسرب إسقاط اعتماد آخر اسم، نقل تمرير تثبيت مسار، فقط إعلان لـ تطوير اعتماد وقت التشغيل استيراد، و من إعداد تحميل إضافة. إصدار smoke سوف واحد بدء تثبيت كل tarball، لذلك إزالة استهلاك من دليل في وجود فعلي تحقق حزمة و لا يستطيع شرح افتراضي منتج حاجة هو.

## Decision

[`verify-default-product-isolation`](../../../../scripts/verify-default-product-isolation.ts) في ساكن حالة CI و حزمة hygiene في تشغيل. هو من كل تطبيق و Python runtime خروج إرسال، مرة تاريخ وقت التشغيل اعتماد، اختياري اعتماد و peer، تحليل workspace و npm آخر اسم، و حسب npm بادئة أو مستودع دليل تعرف آخر فعلي تحقق حزمة. إصدار denylist عضو علاقة لا أثر هذا تصنيف. بدء جهاز في `OPTIONAL_BUNDLES` داخل نقطة اسم تركيب حزمة هو وحيد إعلان مثال خارج ([مع تثبيت توفير اختياري تركيب حزمة](2026-09-15-shipped-optional-bundles.ar.md)).

شفرة المصدر فحص أيضا قراءة الذي اختيار حزمة وقت التشغيل استيراد، تثبيت ذاتي حمل profile bundle قائمة،bundle patch، مع منتج توفير Agent preset، و إعلان إعداد شجرة. هو استخدام إنتاج patch محلل تحميل افتراضي Web كل طبقة، و استخدام بدء وقت نفس عدد patch جذب محرك إتمام تركيب. فحص كائن يشمل نهائي entry و تطبيق patch بعد Include شجرة، لذلك فقط حسب id تغطية group patch أيضا لا يمكن إخفاء استبدال بعد إضافة. منع استخدام إضافة سطر ما زال قبول دخول فحص؛ عادي إضافة إعداد بيانات لن يتم حل تفسير لـ آخر عدد Loader entry قائمة. افتراضي مدخل ناقص سوف جعل فحص فشل.

افتراضي Web شفرة المصدر رسم من فعلي HTML مدخل في module script خروج إرسال، يشمل داخل ربط وحدة و محلي مرجع Worker مدخل. مستقل فعلي تحقق معاينة يمكن وجود بينما لا إضافة دخول هذا رسم؛ افتراضي مدخل استيراد هو وقت فحص سوف فشل. شفرة المصدر في Cordis ملف إعداد مرجع سوف سوف Desktop patch قبول دخول نفس إثبات.

[Host بدء smoke](../../../../apps/cli/tests/profiles/web/tests/web-default-isolation.expected.e2e.ts) في مستقل Harness home في عبر بناء بعد `dsh` تصدير بدء حقيقي Web profile. اختبار مخصص استخدام مراقبة جهاز في حينئذ خيط بعد قراءة فعلي Loader سطر، تسجيل fiber، تسجيل عودة ضبط الذي تابع وحدة و Node قد تحميل وحدة ذاكرة مؤقتة.[Chromium smoke](../../../../apps/web/tests/default-product-isolation.e2e.ts) بدء فعلي تسليم صفحة، قراءة حقيقي Client Loader،registry و وحدة ذاكرة مؤقتة، و اشتراط كل تسليم entry متساو قد تنشيط. اثنان بند فحص كل سوف رفض ذلك صريح سالب مثال أمر تركيب حقيقي فعلي تحقق إضافة. قائم expected-output و Web CI lane في كامل بناء بعد تنفيذ هذه اختبار.

بناء إدخال فحص تغطية متصفح تحزيم اثنان عدد مرحلة مقطع.[Client preset](../../../../packages/client/tsdown.client.ts) في أصلي مسار يتم طي دخول `lib/client.js` قبل، رفض غير فعلي تحقق إخراج في فعلي تحقق إدخال.[Web رسم فحص](../../../../scripts/web-product-bundle-isolation.ts) من `index.html` امتداد حقيقي Vite إخراج حافة مرة تاريخ، تغطية تأخير متأخر تحميل chunk،Worker،CSS اعتماد و مورد. مستقل preview لا يخص منتج رسم. نقص قليل مطلوب وحدة أو مورد إدخال سجل سوف جعل بناء فشل؛ فشل Web بناء لا يمكن إنتاج نجاح كامل Client بناء سجل.Notices توليد جهاز عبر صريح قسم تحليل علامة فحص ذلك جزء اعتماد رسم، هذا علامة اشتراط منع استخدام إخراج كتابة. أخرى داخل تخزين داخل منتج بناء ما زال تنفيذ هذه فحص.

[`verify-packed-install`](../../../../scripts/release/verify-packed-install.ts) من `@deepseek-ai/dsh` مرة تاريخ قد تثبيت اعتماد رسم، عبر تحليل بعد manifest اسم تعرف آخر آخر اسم و خارجي نقل تمرير اعتماد. تطوير اعتماد و تثبيت في منتج جانب حافة لا متبادل صلة tarball لا مشاركة و مرة تاريخ. ناقص مطلوب اعتماد سوف فشل؛ سماح حذف اختياري اعتماد، لكن ذلك اسم لا نيل إشارة نحو فعلي تحقق حزمة.

هذا فحص تنفيذ قائم[فعلي تحقق حزمة اعتماد عزل قاعدة](../architecture/2026-08-18-experimental-agent-teams-packages.ar.md).[إصدار سياسة](2026-09-12-experimental-publication-denylist.ar.md) مستقل قرار صريح إزالة استهلاك من يمكن تثبيت أي بعض فعلي تحقق حزمة.

## Alternatives considered

**فقط فحص مباشر اعتماد اسم.** آخر اسم، وقت التشغيل شفرة المصدر استيراد و إعداد تحميل إضافة يمكن التفاف مرور هذا فحص.

**رفض أي قد تثبيت فعلي تحقق tarball.** إصدار smoke متعمد تثبيت كامل إصدار عائلة، يشمل اختياري تفعيل حزمة. فقط لديه افتراضي مدخل اعتماد رسم قدرة كاف عودة جواب هذه حزمة هل يصبح منتج اعتماد.

**سوف الكل Web شفرة المصدر نظر لـ افتراضي مدخل.** أي جعل افتراضي HTML و وقت التشغيل استيراد من لم وصول مستقل فعلي تحقق معاينة، هذا أيضا سوف خطأ رفض هو.

**فقط فحص نهائي Vite وحدة مسار.** مستقر `lib/client.js` مسار ممكن يتضمن قبل واحد مرحلة مقطع من فعلي تحقق حزمة ضرب دخول شفرة. كل تحزيم مرحلة مقطع كل يجب فحص فعلي إدخال.

## Consequences

فعلي تحقق حزمة يمكن إصدار بينما لا إضافة دخول افتراضي تثبيت أو تركيب. شفرة المصدر، نهائي تركيب، بناء إدخال، تثبيت اعتماد و وقت التشغيل registry فحص توفير متبادل متبادل مستقل دليل.SDK [شفرة المصدر بدء توافق patch](../../../../apps/cli/src/sdk-source.cordis.patch.yml) عبر حساب حساب خروج ملف مسار اختيار، لا في ساكن حالة إعداد اكتشاف نطاق داخل. وقت التشغيل smoke مراقبة بدء و Client تنشيط؛ هو جمع لا بديل لاحق كل بند مستخدم إطلاق مسار اختبار، أيضا لا بديل صريح تثبيت profile توسيع اختبار.
