# Agent Note: متصفح GIF إبقاء مفرد واحد دليل سلسلة

Status: implemented

[English](2026-08-08-browser-gif-evidence-chain.md) | العربية

## مشكلة

متصفح عرض عرض قسم مرآة يمكن من كل ورقة كل حقيقي قطع رسم مجموعة صار، لكن لا يمكن إثبات هذه قطع رسم قدوم ذاتي نفس مرة حقيقي تنفيذ. إعادة استخدام تطبيق عام حالة ممكن جذب دخول قديم ضبط أو قديم جلسة؛ تسجيل صنع تلقائي تحويل ممكن خطأ سوف مختلف نموذج تشغيل رسم وجه دمج؛ حديث يوم transcript(نص سجل) ممكن عرض تخفيض معالجة نجاح، لكن لا يوجد كشف عرض إطلاق تخفيض أداة رفض. حسب بلا عائق عائق اسم إجراء نموذج غامض مطابقة، أيضا ممكن خطأ يأخذ نص التوجيه عودة إظهار أو بعد بديل نص عند صار مسبق مدة نتيجة.

بلا رأس نمط تحت إنتاج بيئة تسجيل صنع أيضا لديه اثنان طريق حد. منتج افتراضي إعداد ممكن فتح تلقائي تحويل لا يمكن تشغيل تحكم أصلي عملية نظام واجهة، بينما استخدام mock أو اختبار خطاف استبدال هذا واجهة، حينئذ معنى طعم حال GIF لم يعد عرض إنتاج مسار. إصدار بعد، فوق نقل أو دفع إرسال نجاح أيضا لا يستطيع إثبات فوق نقل مورد إنتاج في مراجعة مسار فوق يمكن بلوغ كما تمام جيد، أو GitHub قدرة سوف PR(Pull Request) Markdown تعرف آخر لـ صورة.

## قرار

[`record-browser-gif`](../../../skills/record-browser-gif/SKILL.md) سير العمل سوف واحد طقم قسم مرآة بصفة نفس مرة تنفيذ كامل دليل، و ثابت إلى دقيق PR head. بناء قبل، سير العمل اشتراط worktree جاف صاف و سجل ذلك commit SHA. كل مرة تشغيل كل استخدام كل جديد `DSH_HOME`،`DSH_AGENTS_HOME`، مساحة العمل، جلسة و عزل متصفح حالة، كل إصدار لقطة متساو قدوم ذاتي نفس عدد خادم و نفس مرة من نموذج قيادة مشهد تنفيذ. لا يمكن إنشاء كل جديد متصفح سياق وقت، ينبغي في تنقل قبل صاف حذف هذا origin cookie و محطة نقطة تخزين. فقط لديه مستخدم رفع خروج اشتراط أو تأكيد لديه لا بد يلزم وقت عندئذ قدرة استخدام مستخدم قد لديه متصفح حالة؛ يجب في GIF جانب شرح استخدام هذا حالة، و لا نيل بـ هذا إثبات عميل حالة كل جديد. تسجيل صنع فشل وقت، إسقاط هذا مرة تشغيل و من كل جديد حالة أصل دليل إعادة تنفيذ، لا و آخر مرة تشغيل دمج.

متصفح تلقائي تحويل سوف انتظار وحيد كما دقيق دلالة حالة. إذا حاجة إثبات استدعاء الأداة، رفض أو استعادة، قسم مرآة حينئذ يجب يتضمن تفصيل حال لقطة أو مسار أثر لقطة: علامة واضح أداة، عرض ذلك حالة أو مستقر رمز خطأ، و عرض لاحق نتيجة. نهائي تحرير رمز خروج GIF بداية نهاية هو تحقق كائن؛ إذا عرض جهاز لا يمكن بث وضع حركة رسم، ينبغي من هذا GIF في حل رمز خروج بديل جدول صفة لقطة، بينما لا يستطيع سوف مصدر قطع رسم نظر لـ انتظار فاعلية دليل.

ما زال ينبغي أولوية استخدام قد لديه متصفح تحكم سير العمل. إذا هذا سير العمل غير ممكن استخدام، تسجيل صنع برنامج ينبغي في عزل بلا رأس متصفح في استخدام مستودع قد إعلان Playwright اعتماد، بينما لا هو تثبيت أخرى قيادة أو فتح مستخدم متصفح. فقط لديه عبر صحيح معتاد تطبيق إعداد اختيار استخدام رسمي جهة كما يمكن من متصفح عملية إنتاج خلفية، عندئذ قدرة استبدال أصلي إنتاج واجهة، و كما يجب في GIF جانب ملاحظة واضح هذا واحد تغطية.fixture(اختبار قبل وضع بيانات) ،mock نقل طبقة، دمج صار حدث و اختبار مخصص استخدام خطاف متساو لا يستطيع دعم دعم حقيقي إنتاج تنفيذ رئيسي ورقة.

إصدار حلقة عقدة سوف مجددا مرة تحقق حد. أول اختيار مسار استخدام `gh --attach` فوق نقل (v2.99.0 أو أكثر عال إصدار؛ فقط حد github.com؛ لا تجاوز مرور 10 MB): متن ملف مرجع محلي GIF مسار، أمر فوق نقل قد تحقق ناتج و يأخذ هذا مرجع حينئذ أرض تعديل كتابة، بعد في خط متن يجب عرض تعديل كتابة بعد فوق نقل URL، كما هذا URL يجب إرجاع `200` و `image/gif`. عند attach لا يمكن استخدام وقت——GIF تجاوز مرور 10 MB،`gh` إصدار مرور قديم أو مستودع يقع في GitHub Enterprise Server——ما زال إبقاء مورد إنتاج فرع مسار: هذا فرع فقط يتضمن وسيط جسم ملف، مؤقت تخزين و إصدار بايت يجب و قد تحقق ناتج متسق، خاص مستودع في مورد إنتاج يجب عبر مرور هوية تحقق API أو أصلي محتوى طلب فحص ذلك مسار، بايت كبير صغير، تحقق و، استجابة حالة و وسيط جسم نوع، هذا فقط قدرة إثبات مستودع عضو مراجعة وصول مسار ([وثيقة محطة نقطة صورة قرار](../../archived/process/2026-08-06-doc-site-carries-its-images.md) حل تفسير عام مشترك محطة نقطة لـ أي لا يستطيع اعتماد خاص أصلي محتوى URL). تعديل PR متن قبل، يجب مجددا مرة تأكيد في خط head ما زال و تسجيل صنع وقت head نفسه. تحرير بعد أيضا يلزم مجددا مرة فحص في خط head، كما هو يجب إبقاء لـ هذا سجل قيمة؛GitHub Markdown مصير فإن يجب مفرد وحيد توليد مسبق مدة صورة.

## سبق اعتبار بديل خطة

**فقط يلزم مرئي حالة نظر بدء قدوم انتظار قيمة، حينئذ سماح استخدام مختلف تشغيل رسم وجه.**نظر شعور متبادل يشبه لا يستطيع إثبات كل رسم وجه مشترك نفس حالة، أداة لديه بسبب نتيجة ترتيب أو قدوم ذاتي نفس مرة مشهد تنفيذ. إعادة تسجيل صنع حاجة مجددا تنفيذ مرة حقيقي نموذج جولة، لكن قدرة صيانة حمل كامل طقم قسم مرآة الذي جدول بلوغ رئيسي ورقة.

**سوف حديث يوم transcript نظر لـ أداة استعادة ملء قسم دليل.**نهائي جواب سجل قدرة إثبات مهمة اكتمل، لكن ممكن إخفاء استدعاء أي عدد أداة، فشل هل لـ بنية تحويل فشل، و نموذج هل من هذا فشل في استعادة. مسار أثر لقطة أو تفصيل حال لقطة يمكن مباشر تحمل تحميل هذه واقع.

**استخدام fixture أو اختبار خطاف استبدال لا يمكن وصول أصلي UI.**هذا نوع فعل قاعدة عبر تغيير يتم مراقبة منتج مسار قدوم بسيط تحويل تلقائي تحويل. عبر صحيح معتاد إعداد اختيار استخدام رسمي جهة إنتاج خلفية، حيث قدرة إبقاء تلقي قياس تنفيذ حقيقي، أيضا قدرة واضح جدول وصف الذي اعتماد مقارنة ضيق تشغيل نمط.

**متبادل معلومة فوق نقل نجاح، أو متبادل معلومة دفع إرسال نجاح.**فوق نقل أو دفع إرسال فقط قدرة إثبات GitHub قبول متبادل ينبغي بايت، لا يستطيع إثبات متن مرجع إشارة نحو قد فوق نقل مورد إنتاج، أو Markdown قدرة يأخذ صورة تصيير خروج قدوم. إعادة قراءة في خط متن و مرور GitHub Markdown API تصيير، تغطية مراجعة من فعلي استخدام اثنان طريق إصدار حد.

## عاقبة

GUI دليل الآن قدرة إثبات مرة أداة لديه بسبب نتيجة علاقة تنفيذ، بينما لن يأخذ مختلف تنفيذ في يمكن معلومة رسم وجه عند عمل نفس مرة تنفيذ دليل؛ مراجعة من حيث يمكن فحص بنية تحويل أداة فشل، أيضا يمكن فحص نهائي إتمام نتيجة. في PR متن يتم نظر لـ إتمام قبل، إصدار تحقق يمكن اكتشاف قديم قديم PR head، ضرر تالف أو موضع خطأ وسيط جسم ملف، و بلا فاعلية صورة Markdown.

هذا سير العمل سوف احتلال استخدام مقدار خارج مؤقت حالة؛ تسجيل صنع فشل بعد، ممكن حاجة مجددا تشغيل مرة من حقيقي نموذج قيادة مشهد؛ عبر معتاد أيضا سوف زيادة واحد ورقة تفصيل حال لقطة و إصدار فحص——في خط head و متن تكرار قراءة،Markdown تصيير و فوق نقل URL طلب؛ مورد إنتاج فرع مسار أيضا سوف زيادة ذلك مرور هوية تحقق مورد إنتاج فحص. متبادل مقارنة تفاعل صيغة طاولة وجه، بلا رأس تسجيل صنع يمكن استخدام إنتاج خلفية أكثر قليل؛ كل الذي اختيار خلفية كل سوف في GIF جانب شرح.
