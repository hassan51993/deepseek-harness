# Agent Note: إصدار كل حالي فعلي تحقق صفة حزمة

Status: implemented

[English](2026-09-12-publish-all-experimental-packages.md) | العربية

## مشكلة

مستخدم حاجة عبر npm استخدام Auto review،Inspector،CPython PTC خلفية و متصفح worker مكتبة، معا إبقاء ذلك فعلي تحقق صفة API حالة. فقط في شفرة المصدر checkout في اختبار، لا يستطيع إثبات tarball يتضمن قد تثبيت مستهلك الذي يحتاج وقت التشغيل ملف و import.

## قرار

`packages/experimental/` تحت كل حالي حزمة كل عبر dsh إصدار نظام صف و محلي npm baseline إصدار. كل manifest(بيانات وصفية بيان) حذف `private`، و ضبط `publishConfig.access: public`.[إصدار رفض قائمة](2026-09-12-experimental-publication-denylist.ar.md) ما زال متاح في لم قدوم خاص مثال خارج، لكن لا يتضمن أي دليل. فعلي تحقق صفة npm اسم، صريح تفعيل تركيب، اعتماد عزل، توافق صفة مسبق مدة و دعم حمل حد إبقاء ثابت.

Inspector tarball يتضمن `lib/worker.js`،Host مدخل عبر متبادل مجاور URL بدء هو. ذلك بناء ناتج اختبار أولا تحزيم و حل ضغط حزمة، مجددا بدء هذا Worker.WebWorker تحزيم جهاز عبر وقت التشغيل عام مكتبة مدخل استيراد وحدة بديل إدارة و استبدال حزمة جدول؛ تحرير ترجمة بعد repository قسم قطعة لا حاجة وقت التشغيل TypeScript شفرة المصدر. ذلك قد تحزيم مستهلك اختبار في عادي Node تحت استيراد اثنان عدد حل ضغط بعد tarball، و في لا استخدام هذا اثنان عدد حزمة شفرة المصدر دليل حال حال تحت تركيب توليد أساس أساس مرآة مثل و بيانات تراكم إضافة طبقة.

CPython PTC خلفية يحمل Python نص برمجي، في Unix فوق ما زال حاجة تلقي دعم حمل خارجي حل تفسير جهاز. متصفح worker حزمة توفير قد تثبيت مكتبة API؛ تحزيم جهاز مستودع CLI(أمر سطر واجهة) ما زال حاجة وثيقة اشتراط قد بناء checkout. إصدار لن يأخذ هذه حزمة إضافة دخول أي مع مرفق profile، أيضا لن يجعل متصفح معاينة يصبح منتج بدء مدخل.

## سبق اعتبار بديل خطة

**يجعل يتم ترتيب حذف حزمة متابعة إبقاء خاص.** أي جعل الذي اختيار تركيب صريح قبول فعلي تحقق صفة سلوك، مستخدم ما زال لا يمكن تثبيت استخدام.

**فقط تعديل manifest وصول حقل.** Inspector سوف متروك تسرب ذلك Worker، تحرير ترجمة بعد WebWorker تحزيم جهاز سوف استيراد وقت التشغيل tarball في لا وجود مصدر ملف. قد تحزيم مستهلك فحص يجب تغطية ممكن يتم شفرة المصدر اختبار إخفاء غطاء وقت التشغيل ملف.

**سوف هذه حزمة رفع رفع إلى منتج مجموعة.** تثبيت لا حاجة إزالة فعلي تحقق صفة npm اسم، أيضا لا حاجة قبول مستقر owner و دعم حمل معنى خدمة.

## عاقبة

كل حالي فعلي تحقق صفة حزمة كل يمكن من صريح مستهلك استخدام. إصدار تجميع دمج و حزمة عمل من تحمل تحمل كامل عام ناتج مسؤولية مهمة، معا إبقاء افتراضي منتج تركيب عزل. فارغ رفض قائمة عبر fixture(اختبار قبل وضع بيانات) متابعة تحقق لم قدوم خاص ترتيب حذف بند.
