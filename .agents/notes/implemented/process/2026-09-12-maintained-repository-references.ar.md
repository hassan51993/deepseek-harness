# Agent Note: صيانة في مستودع مرجع

Status: implemented

[English](2026-09-12-maintained-repository-references.md) | العربية

## مشكلة

تاريخ دليل حاجة يمكن تمييز إقرار إرسال سطر إصدار،PR و قياس كمية تشغيل معرف. صيانة في ملف أيضا موجه إلى عام شفرة المصدر رئيسي صفحة، بينما أصلي إصدار استخدام سير العمل توفير مستودع هوية. أداة جسم إيداع مرجع و و نشر ربط مجموعة نسج URL لا يمكن جدول بلوغ هذا واحد منطقة قسم.

## قرار

تاريخ دليل استخدام إرسال سطر tag و PR، تشغيل أو job معرف، حالي مستودع ملف استخدام متبادل مقابل رابط.[مرجع فحص](../../../../scripts/verify-repository-references.ts) مسح قد تتبع أثر ملف و لم يتم تجاهل اختصار جديد ملف.Vendor شفرة المصدر و تجميد ربط Agent Note إبقاء قائم ترتيب حذف قاعدة؛ نشط وثب قلم تسجيل و تاريخ إرسال سطر سجل ما زال مشاركة و فحص.

فحص جهاز إبرة مقابل محلي Git كائن مكتبة تحليل عشرة ستة دخول صنع مرشح قيمة، فقط رفض قدرة واضح معرف إيداع قيمة. معرف blob إعداد مقابل ها أمل،schema ملخص، غير متصل عشرة ستة دخول صنع قيمة، و تحليل إلى مختلف كائن معرف عشرة ستة دخول صنع فرع اسم ما زال صالح. مجموعة نسج URL فحص قياس و قائم مستودع رابط سياسة مشترك حل رمز و مواصفة تحويل منطق.

أصلي شفرة المصدر بيان معرف عام شفرة المصدر رئيسي صفحة. سير العمل تحزيم خلال،[أصلي تحزيم جهاز](../../../../native/system/scripts/pack-release.mjs) سوف سير العمل مستودع إسقاط إلى مؤقت إدخال، يجعل npm يمكن معلومة إصدار يمكن نواة تحقق ناتج هوية. هو إبقاء شفرة المصدر بيان، توليد tarball أيضا لا في إصدار وقت تعديل كتابة. لا يوجد سير العمل سياق محلي تحزيم إبقاء عام شفرة المصدر بيانات وصفية.

## اعتبار مرور بديل خطة

**رفض كل عشرة ستة دخول صنع نص.** حفظ دائم schema و مزدوج لغة إعداد مقابل دمج إدارة استخدام ها أمل.Git كائن نوع تحقق سوف إيداع مرجع و هذه قيمة منطقة قسم فتح.

**فقط فحص جديد diff سطر.** سياسة ملائم لأجل كل صيانة في ملف، يشمل قائم مرجع. كامل مسح أيضا سوف في إصدار قبل اكتشاف مؤقت تخزين أو بعد لم تتبع أثر إضافة جديدة ملف.

**حذف إصدار الذي يحتاج بيانات وصفية.** أصلي إصدار ما زال حاجة سير العمل مستودع هوية. في تحزيم مرحلة مقطع إسقاط هذا هوية، يمكن إزالة شفرة المصدر في حرف وجه كمية، معا إبقاء npm نواة تحقق هوية ثابت.

## أثر

فحص جهاز منع توقف شبكة نيل أخذ، يشمل Git جزء تغلب ضخم تأخير متأخر نيل أخذ. هو فحص محلي كل متاح إيداع كائن، يشمل غير ممكن بلوغ تاريخ PR رأس؛ ناقص كائن لا يمكن مطابقة. لذلك، يتضمن مقدار خارج PR كائن مساحة العمل ممكن فحص قياس إلى CI كامل تاريخ تغلب ضخم في لا وجود مرجع. مرجع تحقق بناء قيام صيانة العربية عنصر سياسة، لا إثبات بعيد طرف tag غير ممكن تغيير أو تاريخ توافق صفة. قد إصدار أصلي tarball في npm Repository بيانات وصفية في عرض سير العمل مستودع؛ شفرة المصدر بيان إبقاء عام شفرة المصدر رئيسي صفحة.

Vendored إعلان رابط مستودع داخل شفرة المصدر موضع، معا إبقاء فوق تنقل اسم، سماح يمكن إثبات و لم تغيير vendor بيان.
