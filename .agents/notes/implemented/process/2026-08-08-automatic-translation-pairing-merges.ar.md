# Agent Note: تلقائي تركيب قلب ترجمة إعداد مقابل سجل

Status: implemented

[English](2026-08-08-automatic-translation-pairing-merges.md) | العربية

## مشكلة

واحد نسخة مزدوج لغة متسق صفة سجل يتضمن اثنان جانب Markdown ملف دقيق blob hash. لذلك، عند اثنان عدد فرع قسم آخر تحديث نفس قد تأكيد إعداد مقابل مختلف جزء وقت، أي جعل Git قدرة جاف صاف دمج اثنان جانب Markdown ملف، سجل في اثنان سطر hash ما زال سوف حدوث اندفاع مفاجئ. اختيار مهمة واحد جانب كل سوف إبقاء تحت قديم قديم hash؛ يد عمل إعادة توليد سجل فإن سوف تكرار تنفيذ واحد بند تحديد صفة عملية، و منع توقف هذا يمكن تلقائي إتمام دمج.

## قرار

`*.i18n.yaml` استخدام من مستودع صيانة `dsh-translation-pairing` دمج قيادة.worktree محلي Git تثبيت نص برمجي في ضبط Lefthook معا تسجيل هذا قيادة أمر؛Git إعداد ما زال حد تحديد في حالي worktree، لأن تلقي تتبع أثر خاصية يمكن إشارة تحديد قيادة، لكن لا يمكن يحمل ذلك يمكن تنفيذ أمر.

تثبيت نص برمجي سوف في إصدار worktree تجميع صار قبل تحميل تأكيد قطع Node/tsx مدخل نقطة.Git سوف استدعاء مستودع داخل قد إيداع كما لا اعتماد Node shell بدء جهاز؛ هذا بدء جهاز سوف في كل مرة تنفيذ قيادة قبل تكرار هذا بند استكشاف قياس. وقت التشغيل أو مدخل نقطة غير ممكن استخدام وقت، أي جعل نص دمج جاف صاف إتمام، بدء جهاز أيضا سوف سوف Git عادي ثلاثة جهة نص دمج نتيجة كتابة مرافق مع ملف و إرجاع اندفاع مفاجئ حالة، جعل Git إبقاء لم دمج بحث جذب مرحلة مقطع، أبدا قبول لم مرور تحقق بيانات وصفية.

قيادة سوف تحليل أصل أولا، حالي و آخر جانب سجل، و تحميل منها hash إشارة نحو ستة عدد Markdown blob. هو قسم آخر مقابل إنجليزي نص وثيقة ثلاثة عدد blob و العربية وثيقة ثلاثة عدد blob تشغيل Git افتراضي ثلاثة جهة نص دمج، اشتراط اثنان مرة دمج كل جاف صاف إتمام، تحقق لغة تبديل سطر و إعداد مقابل بنية توقيع، تخزين اثنان عدد دمج بعد blob، مجددا سوف ذلك hash كتابة مواصفة سجل. هذا واحد مرور مسار تركيب اثنان عدد أب إيداع في قد وجود تأكيد؛ هو أبدا سوف لـ عادي مفرد جانب وثيقة تحرير كتابة سجل.

سجل صيغة خطأ، كائن ناقص، إعداد مقابل وثيقة اعتماد أخرى دمج سياسة (يشمل أصل هذا لم مفرد وحيد إشارة تحديد سياسة مسار وراثة غير نص `merge.default`) ، مهمة واحد إعداد مقابل وثيقة وجود محتوى اندفاع مفاجئ، أو دمج بعد إعداد مقابل مخالفة عكس بنية فحص وقت، قيادة سوف يجعل مرافق مع ملف إبقاء لـ عادي لم حل قرار اندفاع مفاجئ. إضافة جديدة، حذف و إعادة تسمية حال شكل ما زال يحتاج يد عمل معالجة، لأن هو جمع مسار ملكية علاقة لا يمكن من فوق وصف أساس في ثلاثة نسخة سجل عملية معالجة.

`pnpm run resolve-translation-pairing-conflicts` سوف في دمج قد إيقاف بعد تطبيق نفس حساب قاعدة. كتابة أي مرافق مع ملف قبل، هو سوف تحقق مرافق مع ملف ما زال إبقاء Git توليد كما لم مرور تعديل اندفاع مفاجئ نتيجة، و تحقق مؤقت تخزين منطقة في إعداد مقابل وثيقة blob ID و عمل شجرة في ملف بايت كل و أداة مستقل إتمام دمج نتيجة متسق. أي جعل أخرى إعداد مقابل ما زال يحتاج يد عمل معالجة، هو أيضا سوف سوف كل يمكن أمان توليد سجل بصفة واحد دفعة مرة كتابة و مؤقت تخزين؛ مع بعد تقرير إبلاغ باق بقية إعداد مقابل اندفاع مفاجئ و بـ غير صفر حالة خروج، تأكيد حفظ استدعاء جهة لن يأخذ فقط جزء حل قرار خطأ إقرار لـ دمج اكتمل.

`pre-merge-commit` و `pre-commit` سوف مقابل وفق اثنان جانب وثيقة في بحث جذب في دقيق بايت، تحقق مؤقت تخزين `.i18n.yaml` ملف. هذه خطاف سوف تحقق قيادة إخراج، لكن لن إعادة توليد سجل، لذلك التفاف مرور خطاف أيضا لا يمكن صامت صامت تأكيد حدوث عائم نقل ترجمة نص؛CI في كل لغة مادة `doc-sync`(وثيقة تزامن بوابة) ما زال هو مرجعي فحص.

## فشل اتفاق

| عادي `git merge` خلال فشل | يمكن مراقبة حالة | استعادة |
|---|---|---|
| كل جديد تثبيت لا يمكن استكشاف قياس قيادة أو تثبيت Lefthook | لن إصدار جديد قيادة أو خطاف مسار إعداد؛ أي إضافة جديدة تجميع صار كل سوف تراجع إلى أصل لديه خطاف فحص بحث طريقة. | استعادة اعتماد و إعادة تشغيل `node scripts/install-lefthook.mjs`. |
| تثبيت بعد Node،tsx أو قيادة مدخل نقطة تغيير نيل غير ممكن استخدام | دمج إيقاف، مرافق مع ملف حالة لـ `UU`؛ بحث جذب مرحلة مقطع 1/2/3 إبقاء،worktree في مرافق مع ملف يتضمن Git نص نتيجة،`MERGE_HEAD` وجود، كما لا إنشاء إيداع. | استعادة اعتماد و تشغيل `pnpm run resolve-translation-pairing-conflicts`، أو تشغيل `git merge --abort`. |
| حل مستودع حالة قيادة رفض سجل | دمج إيقاف، مرافق مع ملف إبقاء لم حل قرار حالة كما لا إنشاء إيداع؛ قيادة سوف ضرب طبع إصلاح إعداد مقابل وثيقة و تشغيل صريح اندفاع مفاجئ حل قرار أمر مسار. | إصلاح إعداد مقابل وثيقة اندفاع مفاجئ أو سجل، لكن بعد تشغيل ضرب طبع خروج اندفاع مفاجئ حل قرار سير العمل، أو في توقف دمج. |
| قيادة عملية بـ كبير في 128 حالة رمز انهيار انهيار | Git في توقف دمج سياسة، حيث لا كتابة `MERGE_HEAD`، أيضا لا إنتاج لم دمج بحث جذب مرحلة مقطع. | إصلاح وقت التشغيل و إعادة تنفيذ دمج. |
| `pre-merge-commit` رفض أصل هذا قدرة جاف صاف إتمام ملف دمج | لم يعد لديه لم دمج بند، كامل نتيجة قد مؤقت تخزين كما `MERGE_HEAD` وجود، لكن لن إنشاء دمج إيداع. | إصلاح خطاف فشل و تشغيل `git commit`، أو تشغيل `git merge --abort`. |

تثبيت نص برمجي تراجع فشل وقت، سوف معا تقرير إبلاغ الأكثر أول تثبيت خطأ و كل واحد بند تراجع خطأ. هذا وقت worktree إعداد ممكن فقط إتمام واحد جزء، لذلك مساهمة من سوف أولا إصلاح أو فحص إعداد مجددا تنفيذ دمج، بينما لا هو اعتماد ساكن صامت رجوع.

## تحقق

نص برمجي اختبار عبر قد تثبيت بدء جهاز تغطية بلا اندفاع مفاجئ تركيب، و تغطية وقت التشغيل ناقص و مدخل نقطة ضرر تالف وقت نص رجوع، تثبيت نص برمجي استكشاف قياس تراجع، رفض دمج `pre-merge-commit` خطاف، من يحتوي لم حل قرار بند بحث جذب في صريح استعادة، يمكن أمان حل قرار إعداد مقابل و إعداد مقابل وثيقة اندفاع مفاجئ إعداد مقابل و تخزين، يتم تحرير مرور مرافق مع ملف، غير نص افتراضي دمج إعداد، سجل تحليل و worktree محلي تثبيت. قائم كل لغة مادة تحقق جهاز متابعة إثبات قد إيداع سجل و اثنان جانب إعداد مقابل وثيقة متبادل رمز.

## اعتبار مرور بديل خطة

**اختيار ours أو استخدام Git union قيادة.** مهمة واحد أب إيداع سجل كل إشارة نحو دمج قبل محتوى، بينما union سوف إنتاج تكرار أو فوضى ترتيب hash مفتاح. اثنان من كل لا يمكن يمثل دمج بعد إعداد مقابل وثيقة.

**في `post-merge` في أو فقط عبر إيداع خطاف إعادة توليد.** حدوث اندفاع مفاجئ دمج لن تشغيل `post-merge`، بينما كما هذا خطاف لا يمكن تغيير دمج نتيجة. فقط لديه مؤقت تخزين منطقة لا يحتوي لم حل قرار بند بعد عندئذ سوف إطلاق إيداع خطاف، لذلك فقط استخدام خطاف لا يمكن صاف حذف توليد ملف اندفاع مفاجئ.

**استخدام مستودع أمر حزمة تركيب كل مرة دمج.** حزمة تركيب أمر يمكن أصل حسب قد من دمج ملء ملء بحث جذب حل قرار اندفاع مفاجئ، صريح اندفاع مفاجئ حل قرار أمر أيضا إبقاء هذا بند استعادة مسار، لكن مباشر تشغيل Git،stack أداة،rebase و cherry-pick وقت ما زال سوف في هذا قبل إيقاف. دمج قيادة عندئذ هو هذه عملية مشترك استخدام ملف درجة نقطة توسيع.

**عبر GitHub Actions أو تطبيق حل قرار.** حمل إدارة تلقائي تحويل يمكن تحديث PR(Pull Request) فرع، لكن سوف جذب دخول اعتماد، تزامن تحكم و فرع تعديل. محلي تنفيذ أو من agent(ذكي جسم) قيادة merge-forward سير العمل قد أداة لديه فحص خروج دليل و دفع إرسال إذن، لذلك مستودع لا يأخذ بعيد مسار تلقائي تحويل قبول دخول هذا آلية.

## عاقبة

إتمام تثبيت worktree سوف تلقائي إزالة حذف فقط من إعداد مقابل سجل جذب بدء اندفاع مفاجئ، معا ما زال من شخص عمل معالجة إعداد مقابل وثيقة اندفاع مفاجئ و تقييم حكم قلب ترجمة جودة كمية.GitHub حمل إدارة يمكن دمج صفة حساب حساب لن تشغيل worktree محلي يمكن تنفيذ أمر، لذلك ما زال يجب من مساهمة من أو agent سوف base فرع دمج دخول حالي فرع و دفع إرسال نتيجة إيداع، بعيد طرف اندفاع مفاجئ علامة عندئذ سوف إزالة فقد.

تثبيت نص برمجي سوف في worktree إعداد في مسبق إبقاء `merge.dsh-translation-pairing.*`، و رفض و لـ اندفاع مفاجئ ذاتي تعريف قيمة. و مستودع مساهمة من خطاف واحد مثال، تلقائي تركيب اعتماد قد تثبيت Node اعتماد؛ وقت التشغيل غير ممكن استخدام وقت سوف إنتاج مرئي لم حل قرار نص نتيجة، بينما لا هو اختيار قديم قديم بيانات وصفية.
