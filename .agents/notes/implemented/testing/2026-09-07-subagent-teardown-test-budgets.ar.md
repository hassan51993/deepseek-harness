# Agent Note: فرعي بديل إدارة تنظيف اختبار وراثة تنفيذ عبر طريق وقت ميزانية

Status: implemented

[English](2026-09-07-subagent-teardown-test-budgets.md) | العربية

## مشكلة

Windows نسبة التغطية تشغيل (run 34085536250, job 101628739668) لـ اختبار و خطاف توفير 90 ثانية ميزانية، لكن تقرير إبلاغ اثنان عدد تنظيف فشل.ACP تجاهل اختصار EOF اختبار يجعل تنظيف و ذاتي ضبط خمسة ثانية تحديد وقت جهاز تنافس تنازع. حقيقي Codex اختبار سوف خطاف ميزانية تغطية لـ 30 ثانية. هذا اثنان عدد مدة حد كل لا لأجل تحقق منتج تأخير متأخر حفظ إثبات.Codex اختبار متن في خطاف فشل قبل قد مراقبة إلى عملية شجرة خروج؛ سجل لم إشارة خروج بحث فعلا هو سياق تحرير،HTTP إغلاق أيضا هو مؤقت دليل حذف تجاوز خروج خطاف ميزانية.

## قرار

[ACP اختبار](../../../../packages/subagent/subagent-acp/tests/subagent-acp.spec.ts) في تنفيذ عبر طريق اختبار ميزانية داخل انتظار تنظيف إتمام، لكن بعد فحص حقيقي عملية فرعية نتيجة. فشل تنظيف أولا انتظار تحرير و عملية فرعية إتمام، مجددا حذف خاص دليل. تأخير متأخر خروج مراقبة إثبات، تنظيف لا يستطيع فقط بسبب قد طلب إنهاء بينما إتمام. إنتاج بيئة EOF و إنهاء عرض حد مدة إبقاء ثابت.

[Codex اختبار](../../../../packages/subagent/subagent-codex/tests/real-product.spec.ts) وراثة تنفيذ عبر طريق خطاف ميزانية. تنظيف في رقم مرة مختلف خطوة انتظار قبل أخذ نيل ذلك سياق،HTTP تجهيزة و مؤقت أصل دليل، لذلك مهلة خطاف لا يستطيع أخذ مشي أخرى اختبار تسجيل مورد. تنظيف إبقاء سياق تحرير، خادم إغلاق، دليل حذف ترتيب، انتظار كل قد أخذ نيل تحرير عملية، و في رفض بعد متابعة محاولة تجربة ذلك بقية تنظيف مرحلة مقطع. استلام تجميع خطأ إشارة خروج كل منها فشل مرحلة مقطع أو مسار و إبقاء أصلي سبب؛ فقط لديه الكل قد أخذ نيل مورد كل محاولة تجربة تنظيف بعد عندئذ تقرير إبلاغ خطأ.

[أصلي Windows CI قرار](../process/2026-08-08-native-windows-pull-request-ci.ar.md) متابعة مسؤول عبر طريق ضبط درجة و ميزانية. هذا مرة تعديل فقط إزالة اندفاع مفاجئ نطاق جزء مدة حد و إضافة قوي مورد دورة الحياة تأكيد؛ هو و لا إثبات Windows عملية إنهاء أو نظام الملفات وجود نقص وقوع.

## سبق اعتبار بديل خطة

- زيادة إنتاج بيئة عرض حد مدة أو نظام الملفات إعادة محاولة مرة عدد: هذه فشل لا يستطيع إثبات منتج وقت ترتيب خطأ أو حذف إعادة محاولة استهلاك كل.
- استخدام أكثر كبير معتاد كمية استبدال نطاق جزء مدة حد: هذا مثال ما زال سوف تغطية لم قدوم عبر طريق ميزانية.
- طلب إنهاء بعد قيام أي انتهاء تنظيف: هذا مثال سوف سماح عملية فرعية أو طقم وصل حرف تخزين نشط تجاوز مرور تجهيزة دورة الحياة.
- سوف نسبة التغطية اختبار سلسلة سطر تحويل: غير متصل اختبار لا ينبغي لـ اثنان عدد نطاق جزء مدة حد تغطية بينما فقد ذهاب تزامن قدرة.

## عاقبة

عبر طريق مهلة ما زال لـ تعليق بدء توفير وقت حد أعلى. تحديد نحو اختبار تحقق مراقبة إلى عملية فرعية إتمام و تنظيف كل حق، بينما لا هو مضيف آلة إنهاء سرعة درجة.taskkill، عملية خروج إشعار و NTFS حذف ما زال يحتاج أصلي Windows تشغيل توفير دليل؛macOS اختبار عبر لا يستطيع إثبات هذه آلية. نموذج مرئي إخراج،Session تجهيزة، إنتاج بيئة مهلة و CI توجيه متساو ثابت.
