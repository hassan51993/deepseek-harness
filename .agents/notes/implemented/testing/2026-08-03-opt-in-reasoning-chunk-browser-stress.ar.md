# Agent Note: دفع إدارة (reasoning) قسم قطعة تدريجي لقطة تراكم حساب إصدار و متصفح ضغط قوة تحقق

Status: implemented

[English](2026-08-03-opt-in-reasoning-chunk-browser-stress.md) | العربية

## مشكلة

طويل reasoning stream سوف في واحد حمل دائم settlement قبل وصل متابعة إنتاج كبير كمية عملية محلي `assistant/live-chunk` update. كل update كل يجب إبقاء لديه ترتيب و طي دخول Assistant Definition، بـ إبقاء فوري كامل صفة؛settlement فإن تضمين دخول دقيق stream توفير replay.React فقط حاجة يرى حالي تراكم حساب نتيجة، لا حاجة مراقبة نفس متصفح لقطة داخل كل في بين حالة.

مختلف خطوة تدفق كل مرة `yield` كل ممكن شكل صار جديد دقيق مهمة حد، لذلك فقط اعتماد دقيق مهمة دمج دفعة `Notifier.markDirty()` سوف تراجع تحويل لـ كل قسم قطعة إعادة بناء مرة `ConversationSnapshot`، إشعار مرة `useSyncExternalStore` و تشغيل مرة React render. أي جعل فوري Think سطر إبقاء طي،100,000 عدد دفع إدارة قسم قطعة ما زال سوف يجعل تنسيق ضبط، إيداع و تخطيط عمل ضغط إقامة رئيسي خط مسار. صفة قدرة حد يجب يقع في جلسة استقبال و React إصدار بين؛ اختبار يجب إبقاء كل أصلي حدث، و منطقة قسم مفرد دفعة تصيير صار هذا و بلا حد تراكم تراكم transport backlog.

## قرار

Session Controller يأخذ كل Client-only live chunk إلحاق إلى event source،Conversation سوف قيام أي يأخذ هو طي دخول كل مطابقة Definition State.Chat و Trajectory Definition لـ مرئي `block-start`،`text-delta`،`reasoning-delta`،`tool-call-delta` و `block-end` chunk طلب `animation-frame` publication؛ رقم واحد بند تغير ضبط درجة مرة `requestAnimationFrame`، لاحق chunk متابعة تحديث State،frame callback مجددا من الأكثر جديد State materialize واحد تراكم حساب snapshot.`usage` و `finish` لا طلب publication. حمل دائم `assistant/message` أو `assistant/attempt` settlement سوف قيام أي إصدار، و في تاريخ replay في تكرار الآن نفس نهائي stream.

`BoundConversation` لـ كل Session يملك واحد pending frame. عادي بنية event و حمل دائم settlement طلب immediate publication،flush الأكثر جديد assembled State، و يجعل بعد frame callback بسبب لا يوجد dirty Context بينما لا إنتاج أثر. لا يوجد `requestAnimationFrame` بيئة سوف قيام أي إصدار.Settlement يمكن قفز مرور واحد بعد لم عرض في بين partial، لكن إصدار نهائي content و حمل دائم تضمين دخول صيغة stream إبقاء كامل.

فوري Think سطر مقابل تراكم حساب نص أفقي نحو تتبع ذيل يخص صاف نظر شعور مقابل متساو، لا حاجة في كل مرة React إيداع في تزامن قراءة تخطيط. مكون داخل مجدول سوف وصل متابعة طلب دمج لـ كل ثلاثة لقطة مرة، من الأكثر جديد DOM قراءة `scrollWidth` و `clientWidth` و سوف `scrollLeft` مباشر تحديث إلى الأكثر جديد موضع؛ ثابت نظر شعور عقدة عزف يجعل ملخص تغير يمكن قراءة، أيضا لن تراكم ضغط متصفح مستو انزلاق تمرير حركة رسم. هذا عقدة تدفق فقط أثر في Think أفقي نحو ملخص، لا تأخير متأخر Chat متن تمرير، تاريخ prepend مرساة تحديد أو مستخدم إطلاق `scrollIntoView`.

`pnpm run test:web:stress` إبقاء لـ بلا مفتاح، يحتاج صريح تفعيل متصفح صفة قدرة دليل. اختبار يحتفظ نموذج adapter عبر حقيقي Host،Gateway،WebSocket،Session عودة و و فوري Think سطر إرسال خروج 100,000 عدد `reasoning-delta` chunk. كل دفعة 128 عدد chunk سوف انتظار مرة متصفح timer جولة بعد مجددا إرسال تحت واحد دفعة، لذلك 50 جزء ثانية قلب قفز و مسبق أولا ضبط درجة DOM حدث حسب 250 جزء ثانية ميزانية قياس كمية واحد محدود استقبال/تصيير منطقة بين، بينما لا هو تراكم تراكم socket backlog. ربط ذيل علامة إثبات كل chunk كل قد وصول UI.`DSH_WEB_STRESS_HEADFUL=1` سماح تطوير من في مرئي متصفح في استخدام Performance وجه لوح قسم تحليل نفس مشهد. هذا ضغط قوة عربة طريق هو يد حركة صفة قدرة تشخيص و إصلاح تحقق استلام دليل، لا هو افتراضي CI بوابة، أيضا لا بديل تحديد صفة ضبط درجة اختبار وحدة.

تجمع تركيز اختبار ثابت `Notifier` تدريجي لقطة دمج، بنية حدث انتزاع احتلال، بطلان عودة ضبط و بلا rAF رجوع، و في `Session` طبقة إثبات واحد لقطة فقط إصدار مرة الأكثر جديد تراكم حساب نص كما تحديد مسودة لن يتم قديم لقطة عودة ضبط تكرار إشعار. حسب يحتاج تفعيل متصفح حالة استخدام يحتفظ adapter عقدة عزف، دقيق حدث عدد و ربط ذيل علامة تسليم، لا يأخذ 100,000 قسم قطعة عمل سالب تحميل حمل دخول افتراضي اختبار طقم عنصر.

## سبق اعتبار بديل خطة

**في React داخل مقابل لقطة استخدام transition،deferred value أو مكون عقدة تدفق.** غير مقبول: جلسة مصدر ما زال سوف تدريجي قسم قطعة إشعار `useSyncExternalStore`،React render في مكون قرار تأخير بعد عرض قبل قد حدوث، كما كثير عدد إزالة استهلاك نفس لقطة مكون حاجة تكرار تنفيذ سياسة.Think ملخص نظر شعور تتبع ذيل عقدة تدفق يقع في لقطة إصدار بعد، فقط نقص قليل تزامن تخطيط تردد معدل، لا تحمل تحمل بيانات إصدار سياسة.

**في Definition fold قبل إسقاط أو سحب مثال live chunk.** غير مقبول: فوري تراكم حساب State سوف و حمل دائم تضمين دخول صيغة stream قسم اختلاف، و ممكن حذف مرئي في بين محتوى. ضيق تجميع حمل دائم تخزين و تدريجي frame دمج React publication حل قرار هو مختلف صار هذا.

**فقط استخدام دقيق مهمة دمج دفعة.** غير مقبول: وصل متابعة مختلف خطوة `yield` سوف في متبادل مجاور قسم قطعة بين ترتيب فارغ دقيق مهمة طابور صف، جعل دقيق مهمة دمج دفعة قريب يشبه تراجع تحويل لـ كل قسم قطعة إشعار مرة.

**حسب حركة رسم لقطة تحكم اختبار إنتاج جهة عقدة عزف.** غير مقبول: إنتاج جهة سوف في تصيير تغيير بطيء وقت تزامن نقص سرعة، جعل صفحة نيل نيل حقيقي شبكة شبكة تدفق لا وجود خفي صيغة خلف ضغط، و إخفاء غطاء رئيسي خط مسار جوع جوع.

**لا انتظار تأكيد حينئذ يأخذ أصل لديه متصفح محلي سرعة معدل إرسال دخول WebSocket.** غير مقبول:transport عمل ترتيب طابور سرعة درجة سوف تجاوز مرور نموذج ممكن بلوغ إلى إنتاج خروج سرعة درجة، جعل نتيجة تغيير صار socket backlog قياس كمية. متصفح timer تأكيد حد كل دفعة عمل كمية، معا heartbeat ما زال قدرة اكتشاف واحد دفعة بيانات جعل صفحة جوع جوع.

**حقيقي خارجي نموذج أو تسجيل صنع HTTP بايت تدفق.** غير مقبول: خارجي نموذج لا أداة تحديد صفة،HTTP تسجيل صنع أيضا سوف زيادة ثاني نوع fixture صيغة، لكن لن تعديل دخول هدف تأكيد. اختبار يحتفظ adapter يجعل كل chunk مرور مرور حقيقي Host و متصفح transport، معا تحكم عمل سالب تحميل.

## عاقبة

تدفق صيغة `ConversationSnapshot` إصدار تردد معدل تلقي متصفح رسم صنع تردد معدل قيد،React كل لقطة حتى كثير معالجة واحد يتضمن الكل قد استقبال نص تراكم حساب partial؛ بنية حدث ما زال يمكن أكثر سريع إصدار. استقبال، ترتيب ترتيب، سجل سجل، نص تجميع وصل و تراكم تراكم جهاز تحديث ما زال حسب أصلي قسم قطعة تنفيذ، لذلك هذا قرار خفض منخفض هو لقطة إعادة بناء و React عمل، لا يأخذ أصلي تدفق تحليل صار هذا زائف تركيب صار قد حل قرار.

طي Think ملخص أفقي نحو تخطيط قراءة كتابة الأكثر كثير كل ثلاثة لقطة تنفيذ مرة، و مباشر تتبع فوق هذا وقت لحظة الأكثر جديد موضع؛React ما زال حسب تراكم حساب لقطة صحيح معتاد إيداع، تحديد مسودة وقت ملخص استعادة إلى أول سطر. هذا نطاق جزء نظر شعور سياسة لن تغيير متن تمرير و مستخدم تفاعل أي وقت صفة.

متصفح ضغط قوة عربة طريق متابعة توفير حقيقي تجميع تطبيق و تحميل جسم فوق استجابة صفة إشارة و مرئي profiling مدخل، لكن صلب عنصر و ضبط درجة فرق مختلف جعل ذلك فقط ملائم دمج بصفة صريح صفة قدرة دليل. تحديد صفة focused tests مسؤول حراسة إقامة إصدار مرة عدد، تراكم حساب محتوى و انتزاع احتلال ترتيب، افتراضي اختبار عربة طريق إبقاء سريع سرعة.
