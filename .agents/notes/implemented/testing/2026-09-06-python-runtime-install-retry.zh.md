# Agent Note: Python runtime اعتماد تثبيت محدود إعادة محاولة

Status: implemented

[English](2026-09-06-python-runtime-install-retry.md) | العربية

## مشكلة

Python runtime عبر طريق `Install (immutable)` خطوة في كل هدف فوق تشغيل `pnpm install`، تثبيت مدة أصلي بناء تحت تحميل سوف من nodejs.org نيل أخذ Node رأس ملف. هذا طرف نقطة سوف بين راحة صفة توقف ركود:2026-09-06، حمل إدارة `node24-macos-x64` وحدة في `fs-ext` بناء node-gyp تحت تحميل مقابل nodejs.org رمي خروج 10 ثانية اتصال مهلة بعد `ConnectTimeoutError` وقت فشل، جعل غير ممكن تغيير تثبيت في توقف. هذا توقف ركود يخص خارجي، لحظة وقت مشكلة؛ هذا قبل عبر طريق حذف شخص عمل إعادة ركض عمل عمل خارج لا يوجد أي استعادة يد مقطع.

## قرار

تثبيت خطوة مقابل `pnpm install --frozen-lockfile` الأكثر كثير إعادة محاولة ثلاثة مرة (مشترك ثلاثة مرة محاولة تجربة، فشل بين فصل عشرة ثانية) ، و في كل منصة فوق بـ `bash` تشغيل (حمل إدارة Windows مرآة مثل ذاتي حمل Git Bash). مهمة معنى مرة نجاح قيام أي انتهاء خطوة؛ كل مرة محاولة تجربة كل سوف فشل ملف قفل فحص أو أصلي بناء خطأ ما زال سوف في محدود ميزانية بعد جعل خطوة فشل. هذا استعارة تمييز Wine عبر طريق قد سجل محدود نقل سياسة، بينما لا جذب دخول مرآة مثل، لأن هذه تثبيت أيضا سوف تحليل أصلي addon، ذلك اثنان مرة تحت تحميل مصدر نفس مثال إعادة يلزم.

## قد اعتبار بديل خطة

**رفع عال اتصال أو عمل عمل مهلة.** لا اعتماد: مراقبة إلى توقف ركود هو 10 ثانية بعد اتصال مهلة، بينما مقابل هذا فشل نمط ملائم استخدام استعادة هو يحمل جديد اتصال كامل جسم إعادة محاولة؛ طرف نقطة لذا عائق وقت أكثر طويل مهلة ما زال فشل.

**لـ Node رأس ملف تحت تحميل استخدام مرآة مثل.** دفع متأخر:Wine عبر طريق مرآة مثل فقط متابعة نقل ذاتي ذات عودة ملف؛Python runtime عبر طريق حاجة حسب هدف إعداد مرآة مثل و ذاتي ذات تحقق مرجعي، بينما لحظة حالة لذا عائق إعادة محاولة و لا حاجة هذه.

**شخص عمل إعادة ركض فشل عمل عمل.** لا اعتماد لـ هذا عبر طريق معتاد ضبط تكملة إنقاذ: هو إزالة استهلاك واحد كامل عبر طريق دورة مدة كما توقف إبقاء في يد حركة طبقة وجه؛ محدود إعادة محاولة امتصاص استلام لحظة حالة لذا عائق، حمل متابعة صفة لذا عائق ما زال سوف صدى مضيء فشل.

## عاقبة

مرة nodejs.org لحظة حالة توقف ركود الأكثر كثير دفع خروج اثنان مرة مقدار خارج تثبيت محاولة تجربة (نحو اثنان عشرة ثانية) ، تحديد صفة تثبيت نقص وقوع ما زال سوف في ميزانية بعد فشل. كل هدف مشترك نفس إعادة محاولة مسار، تثبيت تشخيص ما زال لـ خطوة داخل التقاط pnpm إخراج.
