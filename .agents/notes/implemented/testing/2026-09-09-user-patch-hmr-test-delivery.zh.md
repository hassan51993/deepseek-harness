# Agent Note: مستخدم patch اختبار تحكم نظام الملفات حدث إلقاء تمرير

Status: implemented

[English](2026-09-09-user-patch-hmr-test-delivery.md) | العربية

## مشكلة

macOS Sandbox تشغيل (run 34238200206, job 102101292119) في انتظار أول مرة مستخدم patch إضافة جديدة وقت مهلة. محلي تزامن تكرار الآن جدول واضح، لا يوجد نظام الملفات إشعار وصول HMR. جولة استفسار تغيير جسم أيضا سوف متروك تسرب لاحق تعديل، هذا وقت HMR لا يوجد انتظار تنفيذ تحديث جديد. هذه فشل منع توقف تحديث جديد تأكيد تنفيذ ذلك مسؤول تحقق تحليل، تنشيط و تراجع سلوك.

## قرار

[مستخدم patch اختبار](../../../../packages/boot/app-boot/tests/user-patches.spec.ts) كتابة حقيقي patch ملف، و عبر لا يحتفظ أصلي استماع جملة مقبض Chokidar watcher إلقاء تمرير add،change و unlink حدث. تطبيق بدء مراقبة نظر جهاز تسجيل، تحديث جديد سلسلة سطر تحويل،Include إعادة مجموعة، إضافة تنشيط، فشل تقرير إبلاغ و استعادة ما زال استخدام حقيقي تنفيذ؛[Loader سياسة](../simplification/2026-09-09-nontransactional-loader.zh.md) لا توفير إضافة تراجع. أي جعل ابتدائي تحويل في دخول نطاق جزء تنظيف كتلة قبل فشل، تجهيزة أيضا سوف استعادة watcher عمل مصنع و إلغاء تدمير Context.

مستقل [مراقبة نظر جهاز اختبار](../../../../packages/boot/hmr/tests/watch-config.spec.ts) مسؤول أصلي إشعار إلقاء تمرير، يشمل add/change/unlink، ابتدائي لا وجود أب دليل و نظام الملفات آخر اسم. تحديث جديد اختبار لا تحقق عملية نظام إلقاء تمرير حفظ إثبات.

## اعتبار مرور بديل خطة

**كل تحديث جديد تأكيد كل استخدام أصلي إشعار.** لا اعتماد، لأن هذا سوف يجعل كل مرة محلل و تنشيط حالة تحويل كل تكرار اعتماد أصلي إلقاء تمرير. حدث ناقص سوف إخفاء غطاء تحت تنقل بحث فعلا أي عدد سلوك ظهور مشكلة.

**جولة استفسار و ثابت انتظار.** لا اعتماد، لأن اثنان من كل لا يستطيع تأكيد تحت مرة تعديل قد إلقاء تمرير.Chokidar حينئذ خيط حالة لا كشف Node مختلف خطوة ابتدائي جولة استفسار أساس خط إتمام وقت لحظة؛ محلي جولة استفسار تكرار الآن ما زال سوف متروك تسرب تعديل. تأخير طويل اختبار مدة حد لا يمكن استعادة من لم إرسال خروج حدث.

**Mock HMR تسجيل أو Include.** لا اعتماد، لأن اختبار يجب إبقاء حقيقي إعادة مجموعة، تقرير إبلاغ تنشيط فشل، و في تحليل فشل بعد إبقاء تشغيل في إعداد.

## أثر

تحديث جديد تسلسل إبقاء ذلك دلالة تأكيد، و إزالة ثابت change عقدة تدفق انتظار. مستقل تزامن عملية تحقق عزل صفة، قوي صنع ابتدائي تحويل فشل فإن تحقق watcher في تحت واحد حالة استخدام قبل إغلاق، عمل مصنع في تحت واحد حالة استخدام قبل استعادة. أصلي watcher فشل ما زال في ذلك الذي تابع اختبار في مرئي، حاجة مفرد وحيد تشخيص.
