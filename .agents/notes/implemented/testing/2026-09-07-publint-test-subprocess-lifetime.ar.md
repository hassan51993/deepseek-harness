# Agent Note: Publint اختبار عملية فرعية وراثة تنفيذ عبر طريق مدة حد

Status: implemented

[English](2026-09-07-publint-test-subprocess-lifetime.md) | العربية

## مشكلة

publint نص برمجي اختبار ذاتي ضبط خمسة ثانية تزامن عملية فرعية مدة حد، منخفض في Windows نسبة التغطية عبر طريق قائم 90 ثانية اختبار و خطاف ميزانية. قد التقاط Windows فشل في صالح و بلا فاعلية JavaScript/CSS حالة استخدام في كل تقرير إبلاغ فارغ خروج حالة؛ صالح حالة استخدام استهلاك وقت 5028 مللي ثانية. هذه سجل لا يوجد سجل عملية فرعية خطأ و إشارة، لذلك لا يستطيع إثبات ETIMEDOUT. مدة حد لا مطابقة هو مشترك اختبار نقص وقوع، لا هو منتج تعديل توجيه يؤدي فشل دليل.

## قرار

[publint اختبار](../../../../scripts/publint-all.spec.ts) استخدام قائم Execa اعتماد و Vitest اختبار سياق إشارة، لا ضبط مستقل عملية فرعية مهلة.[سير العمل](../../../../.github/workflows/ci.yml) و[نسبة التغطية معامل كل من](../../../../scripts/coverage-partitions.ts) متابعة مسؤول ميزانية. هذا و[فرعي بديل إدارة تنظيف اختبار](2026-09-07-subagent-teardown-test-budgets.ar.md) اعتماد نفسه عبر طريق كل حق قاعدة، لكن لا تغيير ذلك تنظيف منطق.

كل مباشر Node عملية فرعية إنشاء بعد قيام أي تسجيل تسجيل، إلغاء طلب إرسال SIGKILL؛ تنظيف أولا انتظار كل قد تسجيل تسجيل عملية فرعية نتيجة و close حدث، مجددا حذف خاص حزمة أصل دليل. مسبق مدة خروج رمز تأكيد قبل أولا تشخيص عملية خطأ، إلغاء، مهلة علامة، إشارة و التقاط إخراج تدفق. صحيح معتاد خروج رمز واحد ما زال هو publint سالب مثال صالح نتيجة. خمسة عدد حالة استخدام متساو عبر عزل إصدار تجهيزة استدعاء حقيقي نص برمجي.

## سبق اعتبار بديل خطة

- زيادة كبير خمسة ثانية معتاد كمية: آخر عدد نطاق جزء معتاد كمية ما زال سوف تغطية تنفيذ عبر طريق ميزانية.
- مسبق تحميل أو استبدال publint: اثنان من كل لا يستطيع تحقق بارد بدء نص برمجي استيراد و حقيقي إصدار فحص.
- إرسال إنهاء إشارة بعد قيام أي إرجاع: عملية و إدارة طريق إغلاق يجب أولا في تجهيزة حذف.

## عاقبة

بـ حينئذ خيط حالة لـ قبل رفع مدة حد ارتداد اختبار إلغاء اثنان عدد تخزين نشط عملية فرعية، و فحص اثنان عدد إغلاق حدث،PID قد لا وجود و لديه استخدام تشخيص معلومة. ناقص عمل دليل تحقق بدء خطأ تشخيص. مستقل تزامن اختبار عملية تحقق مؤقت دليل عزل و عملية فرعية ضبط درجة.Windows إنهاء و نظام الملفات دليل ما زال من أصلي Windows CI مسؤول؛macOS نتيجة لا يستطيع إثبات هذه حفظ إثبات. منتج شفرة، سير العمل ميزانية و لقطة إخراج متساو ثابت.
