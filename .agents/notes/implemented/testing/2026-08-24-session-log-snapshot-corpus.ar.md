# Agent Note: Session-log snapshot corpus

Status: implemented

[English](2026-08-24-session-log-snapshot-corpus.md) | العربية

## Problem

بلا مفتاح لقطة لغة مادة عبر ACP تحكم سماح كثير مشهد، لكن هذه مشهد تأكيد سلوك فعلي يخص تجميع بعد Agent، أداة، حفظ دائم أو أخرى منتج واجهة. هذا جعل تلقائي تحويل بروتوكول نظر يشبه يملك خلفية سلوك، معا في تلقي دعم حمل `dsh` بدء جهاز خارج إبقاء اختبار مخصص استخدام تطبيق مدخل، و سوف تسجيل صنع جلسة قسم تفرق في عرض مثال،SDK،Web و نص برمجي دليل في.

لقطة واحد كلمة أيضا لأجل متبادل لا متبادل صلة ARIA، بضعة أي، توليد جهاز و حزمة درجة اختبار وحدة مسبق مدة إخراج. مساهمة من لا يمكن من مسار حكم قطع اختبار هل من تسجيل صنع جلسة قيادة، جلسة هل معا بصفة إعادة تشغيل إدخال و مسبق مدة إخراج، أو أي عدد أمر مسؤول تحديث جديد.

## Decision

قمة طبقة `snapshots/` شجرة و `*.snapshot.ts` بعد لاحقة فقط لأجل يملك أو صريح مرجع تسجيل صنع جلسة JSONL مشهد. كل عملية درجة مشهد كل عبر `dsh` بدء واحد مع مرفق profile؛ صغير نوع مهايئ تحكم headless،SDK،ACP أو Web سلوك، لكن لا يصبح آخر عدد تطبيق مدخل. إعلان صيغة `snapshot.yml` فقط حفظ اكتمل جلسة لا يمكن جدول بلوغ profile،patch، دورة الحياة تحكم، منصة،header pin و workspace واقع.

هذا قرار يحل محل[مرة تسجيل صنع/تحديد صفة إعادة تشغيل قرار](2026-06-19-acp-snapshot-tests.ar.md) في ACP مخصص تابع وضع وضع موضع و تحكم جهاز كل حق؛ بعد من متابعة مسؤول جلسة سجل إعادة تشغيل، مثال خارج override، مواصفة تحويل و ACP transcript مقارنة مقارنة.

تسجيل صنع جلسة ما زال هو رئيسي يلزم إدخال، و في حالي بديل حد مشهد في معا بصفة مسبق مدة إخراج. قدوم ذاتي مستخدم رسالة قيادة الذي اختيار عام واجهة، تسجيل صنع assistant chunk قيادة تحديد صفة نموذج إعادة تشغيل، مواصفة تحويل بعد حفظ دائم نتيجة يجب انتظار في fixture. أب جلسة و فرعي جلسة مشترك نفس نوع تحويل انفصال حساس خريطة. إيداع fixture استخدام إبقاء علاقة هوية token، و سوف طلب system prompt و أداة schema استبدال لـ token؛ كل مختلف header صنف ما زال إبقاء واحد صريح sidecar كل من.

Fixture حل رمز و مقارنة مقارنة فقط أخذ قرار في اختيار تحديد JSONL محتوى؛ ملف اسم معرف inventory role، لكن لا هو parser إدخال.replay،seed،record،refresh و مواصفة تحويل مقارنة مقارنة مسار كل استخدام نفس عدد صارم إطار ساكن حالة catalog تحقق.

Headless stderr إعادة بناء سوف معا توسيع `assistant/message` و فقط كتابة سجل `assistant/attempt` settlement في تضمين دخول reasoning، لذلك فشل أو إعادة محاولة محاولة تجربة reasoning ما زال يخص عملية إخراج إسقاط.

كل parent أو child زاوية لون كل استخدام `session[.<ordinal>][.vN].jsonl`؛v0 حذف إصدار، كما كل ملف اسم كل و ذلك header متسق. إعادة تشغيل، تسجيل صنع و تحديث جديد حسب زاوية لون اختيار عدد قيمة الأكثر عال generation. كبير كثير عدد owner حذف `sessionFormat` و تتبع مع حالي writer؛ تلقي حد تاريخ owner سوف إعلان دقيق إصدار و غلاف إغلاق coverage اسم. لغة مادة إبقاء اختيار تحديد v0 زاوية لون، تغطية كثير قفز، تحزيم سطر، إعادة محاولة/فشل و مع مرفق profile، و إبقاء اختيار تحديد v1 زاوية لون تغطية كامل ترحيل سلسلة في v1→v2 بنية edge. تسجيل صنع و تحديث جديد أبدا تعديل كتابة صريح إبقاء تاريخ fixture، إعادة تسمية قد إيداع generation أو عبر تلقائي تنظيف حذف generation. إبقاء Session generation لن تجميد ربط غير Session مسبق مدة إخراج:refresh ما زال سوف أصل حسب حالي run كتابة owner يحتفظ system-prompt و tool-schema sidecar. تلقي مراجعة قراءة مصدر شجرة كامل إدارة فقط لديه في نفس زاوية لون وجود قد تحقق حالي بعد استمرار بعد عندئذ إزالة قبل بديل. لغة مادة سياسة اشتراط اختيار تحديد حالي زاوية لون بداية نهاية احتلال كثير عدد، و سوف اختيار تحديد تاريخ زاوية لون حد أعلى ضبط لـ عشرة عدد؛ أكثر منخفض قبل بديل generation يمكن إبقاء في اختيار تحديد حالي بعد استمرار جانب.

مشهد يملك HTTP fixture سوف جلسة في تسجيل صنع مستقر authority و نقل listener قسم مغادرة. كل fixture في عودة حلقة عنوان فوق ربط طرف فتحة `0`، من عملية نظام بـ مرة أصل فرعي عملية قسم إعداد و ربط طرف فتحة، مجددا سوف تسجيل صنع URL أو endpoint عبر حقيقي provider خريطة إلى هذا listener. أي عملية عام نقل اعتراض قطع فقط مطابقة تسجيل صنع endpoint، من fixture fiber يملك، و في إغلاق listener قبل استعادة.

كل قائم ACP مشهد كل نيل نيل واحد إبقاء سلوك هدف. عادي مفرد مرة سلوك استخدام headless profile، حاجة حمل دائم آلة جهاز تحكم سلوك استخدام SDK profile، فقط لديه ACP بروتوكول سلوك متابعة عودة ACP كل. من تسجيل صنع جلسة قيادة Web مشهد إضافة دخول هذا لغة مادة، و إبقاء ذلك ARIA أو بضعة أي مسبق مدة إخراج بصفة مساعد مساعدة دليل. لا يوجد تسجيل صنع جلسة مصدر Web و حزمة درجة اختبار إبقاء ملكية جهة محلي مسبق مدة إخراج، و إيقاف استخدام لقطة مسار أو ملف اسم.

Workspace إدخال متابعة عودة كل مشهد محلي كل. تغيير ملف مشهد مقارنة مقارنة كامل مسبق مدة نهائي workspace،record و refresh أبدا تعديل كتابة هذا مسبق مدة، لذلك نموذج أو أداة ذاتي تقرير نتيجة لا يمكن ممتلئ كاف اختبار. قائم متعمد جلسة إعادة استخدام متابعة استخدام صريح، بلا حلقة كل من مرجع؛ لغة مادة لا زيادة workspace وراثة أو عام fixture دمج آلية.

حالي writer request-header pin و إبقاء ترحيل إدخال قسم مغادرة:`tool-call-turn` ثابت default تركيب،`empty-response-retry-current` ثابت retry تركيب. يمكن قراءة sidecar ما زال من `text-turn` يحتفظ. ستة نسخة إبقاء تاريخ إدخال إبقاء بايت تجميد ربط، و متابعة يتم اختيار لـ إعادة تشغيل إدخال؛ ذلك ثابت تاريخ إصدار دليل لا يحتوي سوف يحل محل هو جمع تحديث مواصفة نفس زاوية لون ملف. مفرد وحيد `writer.expected.jsonl` و `writer.<ordinal>.expected.jsonl` ملف ثابت دقيق مواصفة تحويل أصلي حالي صيغة أب فرعي جلسة إخراج، إبقاء تاريخ إدخال SDK مشهد فإن عبر `notifications.current.expected.jsonl` ثابت حالي إشعار. هذه إخراج مقارنة مقارنة أساس دقيق لا هو replay بديل حد.[لقطة أداة حزمة](../../../../packages/test-support/session-snapshot/README.ar.md) مسؤول اختيار و تحديث جديد سلوك. بنية ترحيل يمكن إبقاء طلب يحتوي معنى بينما لا تكرار الآن أصلي writer حدث تخطيط، لذلك صحيح صيغة ترحيل يملك مستقل صحيح تأكيد صفة اختبار. عكس نحو إسقاط لـ تاريخ header، تقشير حذف بنية فرق مختلف، قفز مرور إخراج متبادل انتظار تأكيد أو استبدال تجميد ربط إدخال كل سوف إخفاء غطاء ارتداد، بينما لا هو تحقق هذه متبادل متبادل مستقل اتفاق.

## Alternatives considered

**متابعة سوف ACP بصفة عام مشغل.** هذا سوف إبقاء قائم harness، لكن متابعة يأخذ خلفية تغطية اقتران دمج إلى منخفض أولوية درجة بروتوكول، أيضا لا يمكن إثبات تلقي دعم حمل headless،SDK و Web بدء مسار.

**سوف كل مشهد نقل حركة إلى جديد headless اختبار مشغل.** خاص مشغل سوف إعادة الآن تطبيق مدخل مشكلة، أيضا لا يمكن جدول بلوغ مع مرفق SDK profile قد توفير كثير جولة، إلغاء أو خلفية دورة الحياة تحكم.

**سوف كل نوع مسبق مدة إخراج تجميع في إلى `snapshots/`.** ARIA، بضعة أي، توليد جهاز و اختبار وحدة مسبق مدة لن يأخذ تسجيل صنع جلسة معا استخدام عمل إدخال و نتيجة. خلط دمج هذه محتوى سوف إبقاء حالي يحتوي غامض فن لغة، و تقليل ضعيف حزمة كل حق.

**إنشاء موحد واحد إعلان صيغة متصفح و طرفية لغة.** تكرار مختلط UI و PTY مشهد حاجة تفاعل شفرة. مشترك لقطة نواة قلب إضافة واجهة مهايئ يمكن إزالة تطبيق مشغل، بينما بلا حاجة زيادة ثاني طقم اختبار إطار هيكل.

**تلقائي ذهاب إعادة workspace و تسجيل صنع جلسة.** حالي workspace تكرار جدا قليل، متعمد إبقاء محلي صفة أكثر سهل مراجعة فحص. فقط لديه قائم دلالة جلسة إعادة استخدام قيمة نيل صريح مرجع.

**مباشر ربط تسجيل صنع URL عدد قيمة طرف فتحة.** مستقر listener طرف فتحة جعل نقل قيمة و transcript قيمة متسق، لكن نفس رئيسي آلة فوق تزامن لقطة job مشترك شبكة نطاق الأسماء، سوف تنازع استخدام هذا طرف فتحة.

**في بدء مشهد قبل استكشاف قياس لم استخدام طرف فتحة.** عملية فرعية ربط قبل تحرير قد استكشاف قياس طرف فتحة سوف إنتاج فحص وقت و استخدام وقت تنافس حالة. في يملك هذا طرف فتحة عملية داخل ربط طرف فتحة `0`، يمكن جعل قسم إعداد و كل حق إبقاء أصل فرعي صفة.

**يجعل كل اختيار تحديد fixture كل استخدام حالي إصدار.** هذا سوف نقص قليل fixture إصدار، لكن إزالة مع مرفق profile مقابل كامل متبادل مجاور ترحيل سلسلة ما زال يمكن أيضا أصل قد إصدار إدخال إثبات.

**يجعل كل مشهد كل متابعة اختيار ذلك الأكثر قديم generation.** هذا سوف الأكثر كبير تحويل ترحيل استدعاء، لكن جعل لقطة لغة مادة لم يعد يأخذ حالي writer و حالي صيغة سريع سرعة مسار بصفة عادي حال حال قدوم تغطية.

## Invariants

- كل قائم تسجيل صنع جلسة مشهد كل في إزالة قديم كل من قبل يملك واحد عبر بديل مشهد.
- كل عملية درجة لقطة كل عبر `dsh` بدء، تطبيق مدخل بيان لم يعد سماح قد تراجع راحة لقطة مشغل.
- كل قمة طبقة مشهد كل يملك أو مرجع جلسة JSONL؛ غير جلسة مسبق مدة إخراج متابعة عودة كل من محلي كل.
- إيداع جلسة fixture هو انفصال حساس ثابت نقطة، لا يحتوي system prompt أو أداة schema متن، و لـ كل header صنف إبقاء كما فقط إبقاء واحد pin.
- مواصفة fixture اسم و ذلك header إصدار متسق؛ كل بند مرجع كل إشارة نحو owner اختيار تحديد parent generation؛ الأكثر كثير عشرة عدد اختيار تحديد زاوية لون استخدام صريح v0/v1 إعلان، اختيار تحديد حالي زاوية لون كثير في هذه تاريخ زاوية لون، كما بعد من coverage اسم شمول غطاء كل بند إبقاء ترحيل سلوك.
- تغيير محتوى مشهد من خارجي تحقق نهائي workspace.
- الذي تابع موضع عملية مسبق مدة استخدام `*.expected.e2e.ts`، و من مفرد وحيد بناء ناتج بوابة تشغيل.
- شفرة المصدر و بناء مهايئ في عزل profile fallback في تثبيت فقط إعادة تشغيل حزمة؛ مختلف نص التوجيه section ترتيب قيمة جعل اثنان نوع نمط طلب header إبقاء بايت متسق.
- مشهد HTTP fixture ربط من عملية نظام قسم إعداد عودة حلقة طرف فتحة، معا إبقاء تسجيل صنع نموذج مرئي authority.
- شفرة المصدر و بناء بدء نمط، متصفح إعادة تشغيل،SDK إسقاط، تحزيم Python وقت التشغيل مشهد، وثيقة بوابة و مستودع حماية توليد فحص عبر.

## Consequences

هذا لغة مادة يجعل تحكم جهاز كل حق مرئي: عادي Agent سلوك لم يعد وراثة ACP بروتوكول إخراج،SDK و Web إسقاط إبقاء كل منها واجهة مخصص لديه دليل، فقط لديه ACP إلغاء و إذن تسليم تبديل ما زال عودة ACP كل. مساهمة من مراجعة فحص واحد نسخة مواصفة تحويل جلسة فرق مختلف، و توفير مستقل دليل sidecar أو UI مسبق مدة. إضافة جديدة تركيب يجب توفير manifest صنف آخر pin؛ إضافة جديدة سهل تغيير هوية يجب إضافة إبقاء علاقة حمل نوع انفصال حساس قاعدة، بينما لا هو توسيع كبير نص صاف غسل نطاق. تزامن job يمكن إعادة تشغيل اعتماد شبكة fixture، بينما بلا حاجة مسبق إبقاء مستودع درجة طرف فتحة، بديل قيمة هو fixture داخل حاجة صيانة تسجيل صنع authority و نقل listener خريطة.

تاريخ ترحيل تغطية بديل قيمة هو صريح تدريجي مشهد بيانات وصفية و إبقاء قبل بديل ملف؛ اختيار تحديد حالي زاوية لون احتلال كثير عدد فإن منع توقف توافق صفة fixture إخفاء حالي writer ارتداد.

## Risks

لغة مادة ممكن تغيير عدد مئة عدد fixture،generation اسم تعديل ممكن إخفاء غطاء سلوك تغير. لذلك،diff و تحقق يجب قدرة قسم آخر ملكية آلة آلة generation إخراج، مواصفة تحويل سلوك و تحكم جهاز سلوك، مسبق مدة إخراج تعديل كتابة حاجة تدريجي مشهد مراجعة فحص.

سوف واحد نسخة تسجيل صنع جلسة معا استخدام عمل إعادة تشغيل إدخال و مسبق مدة إخراج، ممكن سوف مستقر تكرار الآن خطأ نموذج نص برمجي. مستقل عالم حد حالة تأكيد، بروتوكول أو UI مسبق مدة، حقيقي نموذج تسجيل صنع و تجمع تركيز حزمة درجة اختبار ما زال هو لا بد يلزم تكملة ملء دليل.
