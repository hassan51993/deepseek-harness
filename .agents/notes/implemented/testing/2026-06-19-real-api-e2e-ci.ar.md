# Agent Note: في CI في مقابل خارجي DeepSeek API تشغيل حقيقي API e2e اختبار

Status: implemented

[English](2026-06-19-real-api-e2e-ci.md) | العربية

## مشكلة

أصل حسب سياسة،harness عال درجة اعتماد حقيقي API اختبار:[docs/testing.md](../../../../docs/testing.ar.md) إشارة خروج، بلا مفتاح طقم عنصر إثبات هو إدارة خط، بينما غير منتج؛[ACP(Agent Client Protocol)inject أمر لذا تكرار قرص (postmortem)](../../../../docs/postmortem/0001-acp-default-export-drops-inject.ar.md) فإن هو معتاد ضبط دليل——178 بند بلا مفتاح اختبار إبقاء أخضر لون وقت، حقيقي ACP عميل جلسة لكن قيام أي انهيار انهيار. حقيقي API e2e طقم عنصر (`pnpm run test:e2e`، أي `*.e2e.ts` ملف) وجود صحيح هو لـ سد دمج هذا واحد نقص فتحة: هو إبرة مقابل خط فوق DeepSeek API قيادة agent(ذكي جسم)——حقيقي نموذج استدعاء، حقيقي bash أداة، كثير جولة، استعادة،ACP-over-stdio.

افتراضي بوابة ([.github/workflows/ci.yml](../../../../.github/workflows/ci.yml)) لحظة معنى بلا مفتاح: لا يحمل secret، يمكن توفير fork تشغيل.`test:e2e` في بلا مفتاح وقت تلقائي قفز مرور (`describe.skipIf(!process.env.DEEPSEEK_API_KEY)`) ، لذلك سوف ذلك إضافة دخول هذا سير العمل فقط سوف تقرير أخضر بينما لن حق صحيح تنفيذ حقيقي طقم عنصر. يلزم يجعل حقيقي API نسبة التغطية يصبح دمج إشارة، حاجة واحد مستقل، يحمل secret سير العمل.

## قرار

واحد و ci.yml قسم مغادرة مخصص استخدام سير العمل [.github/workflows/e2e.yml](../../../../.github/workflows/e2e.yml) استخدام repo secret مقابل خارجي API تشغيل كما فقط تشغيل `pnpm run test:e2e`، فقط في يمكن معلومة حدث فوق إطلاق، و حمل لديه واحد preflight فحص: سوف ناقص secret تحويل تحويل لـ واضح فشل بينما غير وهمي زائف أخضر لون. بلا مفتاح سير العمل إبقاء مستقل، جعل يمكن fork جودة كمية بوابة و إزالة استهلاك secret حقيقي API بوابة كل منها يملك مختلف إطلاق و سند إثبات سياسة.

### مستقل سير العمل، بينما غير ci.yml في واحد job

ci.yml قيمة قيمة في في هو بلا مفتاح، يمكن fork، بداية نهاية لـ أخضر: أي مساهمة من (يشمل خارجي fork) كل قدرة نيل نيل كامل بلا مفتاح إشارة،secret لا في انفجار انفجار نصف مسار داخل. في منها إضافة إزالة استهلاك secret job سوف سوف هذا عدد بداية نهاية لـ أخضر بوابة اقتران دمج إلى سند إثبات متاح صفة و مختلف إطلاق سياسة فوق. سوف يحمل secret عمل وضع في مستقل ملف في، عزل secret، إطلاق و تزامن سياسة، و لـ fork إبقاء ci.yml خاص صفة. مختلف دورة الحياة→مختلف ملف.

### قيد لا هو صار هذا، بينما هو يمكن اعتماد صفة

داخلي دفع إدارة (inference) صار هذا لا هو حد بسبب عنصر، لذلك سير العمل إبرة مقابل تغطية وجه و إشارة أفضل تحويل. هو سوف في كثير نوع إطلاق شرط و كل تلقي معلومة مهمة PR(Pull Request) فوق تشغيل كل مطابقة `*.e2e.ts` ملف، بـ سقوط فعلي [docs/testing.md](../../../../docs/testing.ar.md) لديه مفتاح سياسة.

### إطلاق شرط: فقط حد يمكن معلومة حدث

`workflow_dispatch` + `push` إلى `main`/`master` + كل ليل `schedule`(`17 0 * * *`، أي شمال عاصمة وقت 08:17)+ `pull_request`.push توفير دمج بعد إشارة؛schedule التقاط إمساك خارجي API عائم نقل؛dispatch هو يد حركة هروب توليد عبر طريق؛ يمكن معلومة PR نيل نيل دمج قبل بوابة. هذا دمج قبل إشارة متعمد قبول § أمان صفة في وصف أكثر كبير مفتاح كشف وجه.

### غير ممكن معلومة PR بوابة

GitHub مقابل اثنان صنف PR خصم إبقاء repo secret: قدوم ذاتي **fork** PR، و **Dependabot** PR(نفس مستودع فرع،`head.repo.fork == false`، لكن secret ما زال يتم خصم إبقاء). واحد job درجة `if:` مقابل اثنان من كل قفز مرور كامل job:

```
github.event_name != 'pull_request'
  || !(github.event.pull_request.head.repo.fork || github.event.pull_request.user.login == 'dependabot[bot]')
```

Dependabot فرعي جملة أساس في PR **عمل من**(`pull_request.user.login`) بينما غير `github.actor`(تشغيل إطلاق من): صيانة من إعادة فتح أو إعادة ركض Dependabot PR وقت،`github.actor` سوف تغيير صار شخص صنف، لكن هذا PR ما زال بلا مفتاح؛ أساس في عمل من حكم قطع في هذا نوع حال حال تحت اعتماد لكن صحيح تأكيد. يتم **job درجة** `if:` قفز مرور job تقرير إبلاغ لـ*نجاح*فحص (مختلف في سير العمل/إطلاق درجة قفز مرور سوف إبقاء pending) ، لذلك إذا حاجة سوف هذا سير العمل علامة لـ required status check أيضا هو أمان——fork/Dependabot PR قفز مرور لكن أخضر لون فحص لن منع سد دمج.

هذا بوابة هو واحد*جاف صاف قفز مرور سهل فائدة إجراء تطبيق*، بينما غير secret أمان حد (رؤية § أمان صفة——حد هو GitHub ذاته في `pull_request` تحت مقابل fork secret خصم إبقاء آلية). لا يوجد هذا بوابة،fork ما زال لا يمكن قراءة مفتاح؛ فقط هو سوف لقاء إلى أمر شخص صعب حيرة preflight صلب فشل و موجة استهلاك حساب حساب مورد.

### Preflight: واضح فشل، أبدا وهمي زائف تقرير أخضر

من في job فقط في secret ينبغي عند وجود يمكن معلومة حدث فوق تشغيل،preflight هو واحد بلا شرط وجود فحص: مفتاح لـ فارغ→`exit 1` و مرفق حمل `::error::` ملاحظة حل إشارة واضح حاجة إعداد secret اسم. هذا هو يجعل ذاتي قفز مرور طقم عنصر يمكن أمان أرض بصفة بوابة صلة مفتاح. لا يوجد هو، يتم حذف/إعادة تسمية/خطأ إعداد secret سوف يجعل `test:e2e` قفز مرور كل حقيقي طقم عنصر و تقرير إبلاغ كل أخضر——كامل أمان شبكة ساكن صامت تراجع تحويل. هذا حراسة حماية سوف «secret ناقص» من غير ممكن رؤية وهمي زائف عبر تحويل تحويل لـ مرئي فشل.(ذلك صحيح تأكيد صفة قد في فعلي في تحقق:secret وجود قبل تشغيل تماما جيد في هذا خطوة فشل.)

### Secret خريطة و حماية توليد

repo secret تسمية لـ `DEEPSEEK_API_KEY_EXTERNAL`؛ خريطة إلى مهايئ و اختبار قراءة `DEEPSEEK_API_KEY` بيئة متغير (`process.env.DEEPSEEK_API_KEY`). مستقل secret اسم سجل معنى رسم (هذا هو*خارجي*عام API مفتاح، لا هو داخلي طرف نقطة مفتاح) ، و سماح داخلي طرف نقطة مفتاح يوم بعد بلا اندفاع مفاجئ أرض مشترك تخزين. التالي حماية توليد اختيار متساو لـ منع صد صفة تصميم:

- **خطوة درجة secret.** `DEEPSEEK_API_KEY` فقط في preflight و e2e خطوة `env:` في ضبط، من لا في job درجة ضبط——لذلك checkout/setup-node/install دائم بعيد نظر لا إلى هو. اعتماد في يتم دخول اعتداء تثبيت وقت دورة الحياة نص برمجي لا يمكن قراءة لا في ذلك بيئة في secret.
- **`permissions: contents: read`.** job فقط قراءة مستودع بـ تشغيل اختبار؛ لا حاجة كتابة إذن (بلا PR تقييم نقاش، بلا status كتابة) ، لذلك `GITHUB_TOKEN` خفض حتى الأكثر صغير إذن.
- **`DEEPSEEK_BASE_URL` ثابت**لـ e2e خطوة فوق `https://api.deepseek.com`. مهايئ في لم ضبط وقت سوف افتراضي استخدام هذا قيمة ([packages/llm/llm-deepseek/src/index.ts](../../../../packages/llm/llm-deepseek/src/index.ts) `PUBLIC_BASE_URL`) ، لكن صريح ثابت أداة لديه ذاتي وثيقة صفة و سري غلاف صفة——مستودع أصل دليل `.env`(إذا وجود،`vitest.e2e.config.ts` سوف تحميل هو) لا يمكن ساكن صامت أرض سوف تشغيل إعادة تحديد نحو إلى أخرى طرف نقطة.
- **لا عودة إظهار secret.** preflight فقط ضرب طبع `DEEPSEEK_API_KEY present.`——لا ضرب طبع قيمة أو طويل درجة.

### نطاق و وقت التشغيل شكل

job فقط في Node 24 فوق تشغيل `test:e2e`؛ بلا مفتاح بوابة و إصدار توافق صفة يخص رئيسي CI سير العمل. اختبار عبر workspace paths خريطة بـ لم بناء شكل صيغة تشغيل، استخدام محدود يمكن إعداد worker حوض، تدريجي اختبار إعادة محاولة و job مهلة.[يتم يحل محل CI إلغاء سياسة](../process/2026-09-09-cancel-superseded-ci.ar.md) سوف في PR،push،schedule و يد حركة إطلاق بين إلغاء نفس سير العمل/مرجع مجموعة داخل قديم تشغيل؛ دمج بعد أو كل ليل إطلاق و لا حفظ إثبات إتمام.

DeepSeek أصلي `web_search` استكشاف قياس قد تسجيل لكن سوف قفز مرور. خط فوق Anthropic توافق طرف نقطة ممكن إرجاع نجاح استجابة لكن لا يوجد بنية تحويل مصدر كتلة، لذلك مقابل مصدر وجود صحيح نحو تأكيد لا هو يمكن اعتماد دمج إشارة؛ اختبار وحدة ما زال سوف قفل تحديد استجابة تحليل سلوك، لكن CI لن تحقق خط فوق طرف نقطة إرجاع مصدر كتلة بروتوكول صيغة (wire format).

## أمان صفة

مستودع أول عدد CI secret حاجة واحد نسخة سجل في سجل قوة تهديد نموذج، لأن نفس مستودع PR،fork PR و Dependabot PR وصول إذن كل لا نفسه، كما مستودع عام بعد سوف حدوث تغير.

### خاص مستودع في من قدرة لمس و secret

- **بلا كتابة إذن (fork PR): لا يستطيع.** اثنان عدد مستقل واقع منع توقف هو. رقم واحد، سير العمل استخدام `pull_request` بينما**غير** `pull_request_target`——GitHub لن سوف repo secret نقل تمرير إعطاء fork PR `pull_request` تشغيل، لذلك `secrets.DEEPSEEK_API_KEY_EXTERNAL` في fork runner فوق تحليل لـ فارغ. ثاني،`if:` بوابة تماما قفز مرور fork PR.secret خصم إبقاء هو حق صحيح حد؛ بوابة هو رأسي عميق منع صد و مستخدم تجربة.
- **لديه كتابة (push) إذن: قدرة.** نفس مستودع فرع PR سوف استلام إلى secret، لذلك لديه كتابة إذن عمل من يمكن تعديل اختبار شفرة (أو تثبيت دورة الحياة نص برمجي، أو ذلك فرع فوق سير العمل YAML) قدوم سرقة أخذ مفتاح. هذا**هو GitHub Actions ثابت لديه خاص صفة، و غير هذا نص جذب دخول**: أي مقابل أي مستودع لديه push إذن شخص كل يمكن عبر تحرير كتابة سير العمل قدوم سرقة أخذ هذا مستودع أي Actions secret. كتابة إذن⇒secret وصول حق، بداية نهاية مثل هذا. مؤقت حل إجراء تطبيق في في من يتم منح إعطاء كتابة إذن و فرع حفظ حماية، بينما غير هذا ملف.

لذلك «أي قدرة فتح PR شخص كل قدرة سرقة أخذ هو» هو خطأ: فقط لديه كتابة إذن تجميع دمج داخل شخص قدرة، بينما هذه شخص هذا قدوم حينئذ قدرة سرقة أخذ مستودع يحتفظ أي secret.

### `pull_request` إطلاق جهاز زيادة ناقص بقية كشف وجه

من في تفعيل PR تشغيل، مفتاح سوف في دمج قبل يتم تسليم إعطاء**كتابة إذن عمل من PR فرع فوق شفرة**. هذا مقارنة `push` + `schedule` + `workflow_dispatch` كشف وجه أكثر كبير، لـ في يمكن معلومة كتابة إذن تجميع دمج داخل نيل نيل دمج قبل إشارة بينما قبول. إذا هذا واحد حق توازن حدوث تغير، يمكن إزالة `pull_request` إطلاق جهاز، معا إبقاء دمج بعد، كل ليل و حسب يحتاج تغطية.

### مستودع عام بعد تغير

**عبر هذا سير العمل**،secret مقابل عام جمهور ما زال تلقي حفظ حماية:`pull_request` في عام مستودع فوق سلوك متسق——fork PR(الآن أي شخص كل قدرة فتح) ما زال استلام لا إلى secret، كما في عام مستودع فوق GitHub مقدار خارج اشتراط صيانة من دفعة دقيق fork PR تشغيل، أي جعل دفعة دقيق بعد تشغيل أيضا لن نيل نيل secret(دفعة دقيق تشغيل لا انتظار في تسليم خروج مفتاح). كتابة إذن تجميع دمج لا بسبب مرئي صفة تغيير بينما تغيير، لذلك داخلي شخص عضو الآن فعلي أيضا ثابت.

تغيير فرق هو*دورة حافة*نموذج، التالي هو قلب تحويل مرئي صفة قبل حاجة معالجة أمر بند:

- **سجل تغيير لـ كل كرة يمكن قراءة.** تسرب كشف إعطاء مجموعة نسج عضو خشن قلب secret عودة إظهار، عام بعد سوف تسرب كشف إعطاء كامل متبادل ربط شبكة و في عدد قسم ساعة داخل يتم زحف أخذ.secret معالجة سجل قاعدة (لا عودة إظهار قيمة/طويل درجة——قد فعل إلى) إعادة يلزم صفة كبير عرض رفع رفع.
- **`pull_request_target` وقوع فخ تغيير لـ كارثة صعب صفة.** إذا لديه شخص لـ «إصلاح»PR تشغيل بينما سوف إطلاق جهاز تبديل لـ `pull_request_target`، سير العمل سوف في base-repo سياق في تشغيل غير ممكن معلومة fork شفرة و**يحمل** secret——كامل مفتاح تسرب كشف نحو كمية. في خاص مستودع في هذا جهد قوي بلا ضرر، في عام مستودع في فإن هو كارثة صعب.e2e.yml في إطلاق جهاز فوق `SECURITY —` ملاحظة تفسير منع توقف هذا أكثر تعديل و إشارة نحو هذا نص.
- **قلب تحويل وقت جولة تبديل مفتاح.** مفتاح سبق وجود في خاص مستودع CI في؛ سوف عام نظر لـ «زائف تحديد قد كشف» ، في ذلك واحد لحظة جولة تبديل `DEEPSEEK_API_KEY_EXTERNAL`.
- **سوف secret وضع في تحكم لـ تحت.** تأكيد Settings → Actions → *"Send secrets to workflows from fork pull requests"* إبقاء**إغلاق**(هذا هو وحيد حق صحيح سوف ضرب كسر fork حد ضبط) ، و اعتبار سوف مفتاح نقل دخول حمل لديه required reviewers GitHub **Environment**، جعل أي جعل قد دمج شفرة أيضا فقط في تلقي تحكم شرط تحت استخدام هو، كما جولة تبديل لديه مفرد واحد ملكية.

بـ فوق متساو لا حاجة تعديل سير العمل يكفي عام؛ هو جمع هو تشغيل صيانة خطوة إضافة فوق قد إضافة `pull_request_target` حراسة حماية ملاحظة تفسير.

## سبق اعتبار بديل خطة

- **في ci.yml في إضافة إزالة استهلاك secret job**: مرفوض. سوف سوف بلا مفتاح، يمكن fork، بداية نهاية لـ أخضر بوابة اقتران دمج إلى سند إثبات متاح صفة و مختلف إطلاق/تزامن سياسة فوق؛ مختلف دورة الحياة، مختلف ملف.
- **حذف `pull_request` إطلاق جهاز**(أكثر صغير مفتاح كشف وجه): لـ نيل نيل دمج قبل إشارة بينما مرفوض؛ أمان صفة فصل عقدة تحمل تحميل قد قبول كشف قسم تحليل.

## عاقبة

إضافة جديدة واحد CI سير العمل و مستودع أول عدد حاجة صيانة secret. حقيقي API طقم عنصر الآن بصفة دمج بوابة (يمكن معلومة PR فوق دمج قبل بوابة، رئيسي فرع فوق دمج بعد بوابة) و كل ليل تشغيل، لذلك agent و خارجي API تفاعل في حقيقي لذا عائق سوف في CI في طفو الآن، بينما غير فقط في تطوير من محلي تشغيل في ظهور——بديل قيمة هو كل يمكن معلومة PR و دمج كل سوف إنتاج حقيقي (لكن داخلي تجنب استهلاك)API استدعاء.preflight جعل secret إعداد خطأ تغيير لـ ذاتي أنا عبر إبلاغ بينما غير ساكن صامت منع استخدام أمان شبكة.

هذا تصميم حمل لديه قد سجل قيد جدول وجه:`pull_request` إطلاق جهاز في مفتاح كشف جهة وجه أخذ ترك (حذف هو يمكن إضافة قوي منع حماية) ،`if:` بوابة مقابل أساس في عمل من Dependabot فحص اعتماد، و مقابل `pull_request_target` صارم إطار منع توقف. فوق جهة عام مستودع فحص بيان هو عملية إعداد طقم——لم قدوم صيانة من في أكثر تعديل إطلاق جهاز تجميع دمج أو تبديل مستودع مرئي صفة قبل، ينبغي إعادة قراءة قراءة هذا Agent Note، بينما لا هو من رأس دفع توجيه fork/secret نموذج.

schedule إطلاق جهاز في مستودع لا نشط وثب 60 يوم بعد سوف تلقائي منع استخدام (GitHub سلوك) ؛push/PR/dispatch هو بعد تجهيز، نشط وثب monorepo لن لمس و هذا حد. زائف ضبط runner مقابل `https://api.deepseek.com` لديه خروج محطة وصل عبر صفة——GitHub حمل إدارة `ubuntu-latest` أداة تجهيز هذا شرط؛ تلقي خروج محطة حد ذاتي حمل إدارة runner حاجة في اعتماد كل ليل تشغيل قبل تأكيد وصل عبر صفة.
