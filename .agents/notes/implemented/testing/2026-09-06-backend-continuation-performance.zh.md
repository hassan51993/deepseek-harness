# Agent Note: أداة سري تجميع خلفية متابعة حديث صفة قدرة أساس خط

Status: implemented

[English](2026-09-06-backend-continuation-performance.md) | العربية

## مشكلة

فتح واحد Session لا يستطيع توازن كمية طويل أداة محادثة بعد تكرار دقيق تجهيز نموذج طلب، تنفيذ أكثر كثير أداة سري تجميع جولة أو اكتشاف كثير عدد غير نشط حركة fork فرعي جلسة صار هذا.[Session فتح بوابة](2026-09-04-session-open-performance-gate.zh.md) تغطية أول شاشة تاريخ و تنشيط، لكن متعمد توقف في جديد نموذج عمل بدء قبل. هو نص و دفع إدارة سالب تحميل أيضا لا يتضمن تاريخ أداة استدعاء معامل و كبير نوع أداة نتيجة.

## قرار

[agent-continuation أساس دقيق](../../../../benchmarks/agent-continuation/agent-continuation.bench.ts) زيادة ثلاثة عدد مشهد مجموعة، يتضمن واحد قد إصدار profile تغيير جسم، لا تعديل منتج تنفيذ. هو جمع عبر إنتاج إلحاق، تدفق تراكم تراكم و حفظ دائم API بنية صنع حالي بديل حد Zstandard Session. مستقل بث نوع عملية في قياس كمية قبل توليد تحديد صفة مصدر بيانات؛ كل مثال هذا سوف ذلك نسخ إلى خاص أصل دليل، و بدء جديد قد تحرير ترجمة صاف Node worker. إدخال لا قدوم ذاتي تسجيل صنع Session، بيئة مستودع، شبكة شبكة، خاص Harness رئيسي دليل أو قد نشر GUI.

مشترك تاريخ يتضمن 800 عدد قد إتمام مزدوج خطوة جولة، كل جولة أربعة مرة أداة استدعاء، أداة نتيجة لـ 2,048 محرف: مشترك 13,600 عدد حدث و 5,600 بند محادثة رسالة. كل بند مساعدة يد عودة تكرار يحمل دفع إدارة، نص و ضيق تجميع تدفق سجل؛ طلب أداة عودة تكرار أيضا يحمل قسم قطعة معامل. بث نوع بيانات استخدام ثابت ختم الوقت و id. فوري دمج صار عودة تكرار استخدام حقيقي حلقة وقت ساعة و id، لا تغطية عملية عام حالة.

أداة تنفيذ إدارة خط، طلب دقيق تجهيز، هذه خدمة الذي يحتاج Session إسقاط، حفظ دائم و دليل مراقبة متساو إبقاء إنتاج شفرة. فقط لديه نموذج مهايئ و محدود أداة جسم هو دمج صار. مهايئ فقط إبقاء طلب حساب عدد، لا إبقاء طلب كائن، لذلك fixture(اختبار قبل وضع بيانات) لن صنع صنع لا قطع زيادة طويل إبقاء صار هذا. ترتيب إدخال جعل كل فارغ خامل منطقة بين مقابل هذا worker إيداع وحيد طلب؛ هذا لا بديل جدول تزامن إدخال وقت يمكن يأخذ فارغ خامل حالة دفع واسع لـ تدريجي رسالة إتمام API.

SDK fixture عبر profile patch صريح إدراج دخول `fs-local` و `str_replace_editor`. هذا جعل مرور تدقيق دقيق ملف فحص نظر سالب تحميل لا اعتماد[أقصى بسيط profile فقط توفير shell افتراضي تركيب](../simplification/2026-09-03-minimal-profiles-persistent-shell-only.zh.md). ملف قراءة، حساب وقت نهاية نقطة و ميزانية إبقاء ثابت.

خمسة عدد مثال هذا تقرير إبلاغ أصلي جدار ساعة وقت،CPU مستخدم حالة/داخل نواة حالة وقت، ذروة قيمة RSS، نهاية نقطة حساب عدد و مجموع جدار ساعة وقت الأكثر صغير قيمة، في موضع عدد و الأكثر كبير قيمة. كل نسخة تجميع مجموع تقرير إبلاغ أيضا في حساب وقت worker خروج بعد سجل CPU نوع رقم، متاح و سطر درجة، منصة، هيكل بنية و Node/V8 إصدار. ميزانية قيد لم مرور ترك دخول في موضع عدد. متابعة حديث أيضا متبادل مقابل قد ابتدائي تحويل Host قياس كمية إبقاء كومة داخل تخزين: حساب وقت عملية قبل بعد كل تنفيذ اثنان مرة صريح GC، في بين يجعل خروج مرة حدث حلقة، فارغ خامل Agent بداية نهاية يمكن بلوغ. لذلك هذا زيادة كمية يتضمن معتاد إقامة تاريخ Session و فوري إلحاق، بينما لا فقط هو جديد جولة.GC و مورد تحرير لا حساب وقت؛flush حساب وقت. طلب تاريخ داخل تخزين أساس خط من استعادة بعد بدء، فقط عمل تشخيص. دليل ذروة قيمة RSS فقط عمل تشخيص؛ لا يوجد إبقاء كومة ميزانية صوت تسمية توازن كمية قد تحرير فرعي جلسة مراقبة.

أب عملية لـ كل عملية فرعية ضبط 60 ثانية حد أعلى، مستقل فحص مهلة، إشارة، خروج حالة و تقرير إبلاغ، انتظار عملية إغلاق، و في فشل بعد حذف خاص أصل دليل.Context و Agent في finally في تحرير. بث نوع عملية لا يمكن مسبق حار يتم قياس عملية ذاكرة مؤقتة. لا قوي صنع صاف حذف نظام الملفات ذاكرة مؤقتة: بارد إشارة جديد عملية، لا إشارة بارد شيء إدارة تخزين.

مستقل صاف Node طلب تاريخ CPU profile في مرة 211.300 ms عملية في، سوف 132.876 ms أخذ مثال ذاته وقت عودة بسبب في buildRequest استدعاء deepFreeze. هذا يأخذ تكرار مرة تاريخ قد تجميد ربط تاريخ تحديد موضع لـ تجمع تركيز ضبط فحص هدف، لا هو قد إثبات فعلي أفضل تحويل نتيجة. دليل أول مرة/تكرار وقت قسم آخر إبقاء، لأن مراقبة تحرير بعد ثاني مرة صف رفع ما زال قراءة حمل نوع فرعي فرعي جلسة متن.

قد إصدار SDK تغيير جسم إتمام 100 عدد جولة،200 مرة طلب و 800 مرة حقيقي ملف قراءة. خمسة مثال هذا smoke مجموع وقت لـ 1,521.773،1,463.465،1,689.701،1,365.485 و 1,417.106 ms(في موضع عدد 1,463.465 ms) ؛ كامل طقم عنصر تكرار تشغيل تقرير إبلاغ 1,596.183،1,784.536،2,120.082،1,405.365 و 1,355.894 ms(في موضع عدد 1,596.183 ms).1,700 ms مشاركة اعتبار مدة نظر مقابل 4,250 ms CI ميزانية. تكرار تشغيل في لم تغيير خدمة حالة استخدام أيضا تغيير بطيء، لذلك هذا هو متغير رئيسي آلة سالب تحميل تحت تحقق، لا هو وضع عرض ذلك وحيد احتلال تدقيق دقيق ميزانية اعتماد حسب.SDK عملية استخدام أبيض اسم مفرد بيئة و خاص رئيسي دليل/مساحة العمل.40 ثانية قطع توقف وقت بدء SDK إغلاق؛ كل مسار انتظار نفس عدد تسجيل ذاكرة تحويل close Promise، و مبكر في خارج طبقة worker 60 ثانية قطع توقف وقت.Profile وقت يتضمن بدء، الكل جولة و إغلاق، قسم آخر تقرير إبلاغ؛ لا يأخذ أب عملية CPU أو كومة إشارة علامة عند عمل خدمة طرف داخل تخزين. مهايئ لا لـ خارجي نموذج خدمة تجارة تسلسل تحويل طلب.

## اعتبار مرور بديل خطة

**تكرار قائم ترحيل و أول مرة فتح تغيير جسم.** رفض: قائم عشرة اثنان عدد حالة استخدام قد منطقة قسم فقط قراءة دقيق تجهيز و يمكن كتابة إصدار. هذه حالة استخدام استخدام حالي بديل حد و بدء أو متابعة فعلي نموذج عمل، أو من صف رفع لغة مادة تجميع دمج بينما لا هو فتح مفرد عدد Session.

**فقط قياس deriveMessages.** رفض: هو زيادة كمية ذاكرة مؤقتة لا يتضمن كامل طلب تجميد ربط، مهايئ توزيع، فوري إلحاق أو حفظ دائم. فعلي ترتيب طلب حفظ حماية Agent كل واحد خطوة دعم دفع صار هذا.

**فقط استخدام إسقاط ذاكرة مؤقتة سطر قد مسبق حار بلا نوع فرعي فرعي جلسة.** رفض: هذا مسار التفاف مرور متن مراقبة، متروك تسرب fork فرعي جلسة دقيق وراثة قطع نقطة اشتراط. دليل حالة استخدام متعمد لا تركيب اختياري إسقاط ذاكرة مؤقتة، تقرير إبلاغ حمل نوع فرعي رجوع مسار؛ هو لا بديل جدول ذاكرة مؤقتة أمر في اكتشاف مرور مسار.

**سوف أفضل تحويل و ذلك هدف ميزانية و أول مرة قياس كمية واحد بدء تطبيق.** رفض: صاف أساس خط طبقة يمكن مستقل دمج، و في عودة بسبب أو تنفيذ تغيير قبل سجل حالي سالب تحميل. بيئة متغير لا يستطيع تغطية شفرة المصدر معتاد كمية.

## عاقبة

عبر طريق زيادة ثلاثة عدد مشهد مجموعة في أربعة عدد حالة استخدام، اثنان عشرة عدد قياس كمية worker و اثنان عدد بث نوع عملية. تجميع صار متابعة حديث حالة استخدام تغطية استعادة، إتمام نموذج/أداة عمل و حفظ دائم flush. قد إصدار SDK سير العمل مقدار خارج يتضمن profile بدء،SDK نقل، حقيقي ملف أداة و إغلاق؛ فقط لديه نموذج مهايئ هو دمج صار. هو إنشاء جديد Session، لأن عام مشترك SDK prompt API إنشاء بينما غير استعادة قد تخزين هوية. اثنان بند مسار متساو لا يتضمن شبكة شبكة نموذج تأخير متأخر، خدمة تجارة مخصص تابع طلب تسلسل تحويل، اختياري مستخدم إضافة، ضغط، فشل أداة نتيجة، رسم مثل، إلغاء أو متصفح تصيير. وظيفة اختبار ما زال مسؤول حدث محتوى، غير ممكن تغيير رسالة، أداة دلالة،fork جدول نظام و فقط قراءة/يمكن كتابة فرعي أثر؛ نهاية نقطة حساب عدد منع توقف يأخذ قفز مرور عمل عند عمل قياس كمية نتيجة، لا تكرار هذه تأكيد.

هذا سجل تكملة ملء بينما غير يحل محل Session فتح بوابة عزل و تدقيق دقيق اعتماد حسب. لا تراجع دور أي قائم نشط وثب قرار.
