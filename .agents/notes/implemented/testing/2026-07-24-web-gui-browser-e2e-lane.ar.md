# Agent Note: Web GUI بلا مفتاح متصفح e2e عربة طريق

Status: implemented

[English](2026-07-24-web-gui-browser-e2e-lane.md) | العربية

## مشكلة

Web GUI بـ واحد بند حقيقي تجميع سلسلة تسليم——chromium صفحة → client إضافة bundle → HTTP مفرد مرة RPC + اثنان بند SSE(Server-Sent Events) تدفق → `toFetchHandler`/apiproxy → host طرف agent loop(ذكي جسم حلقة) ، أداة و JSONL حفظ دائم——لكن لا يوجد أي اختبار بلا مفتاح كما تحديد صفة أرض فحص تحقق هذا بند سلسلة.[GUI اختبار جسم نظام](../process/2026-07-20-gui-testing-system.ar.md) تغطية رقم 1 طبقة (Node في بروتوكول نفس بنية) ، رقم 2 طبقة (كائن طبقة حالة آلة) و رقم 3 طبقة خطر دخان اختبار، لكن أصل لديه بلا مفتاح خطر دخان قيادة هو مستقل Client fixture——لا يوجد host، لا يوجد wire، لا يوجد agent loop——بينما كل سلسلة مسار خطر دخان حاجة `DEEPSEEK_API_KEY` و حقيقي نموذج، لذلك لا تحديد، في بلا مفتاح CI في ذاتي سطر قفز مرور.[docs/testing.md](../../../../docs/testing.ar.md) لقطة حكمة تعلم——حمل مفتاح تسجيل صنع مرة، دائم دائم بلا مفتاح إعادة تشغيل، صيغة تغيير حركة وقت تحديث جديد——قد تغطية ACP(Agent Client Protocol) ،headless `stream-json` و TUI ثلاثة عدد transcript(نص سجل) جدول وجه؛web جدول وجه هو وحيد لا يوجد هذا طبقة حفظ عائق تجميع شكل. بينما نقص فتحة تماما تماما هو اثنان بدء قد فعلي إثبات GUI P0 إخفاء ذات لـ موضع: مستقل fixture قصير مسار إسقاط wire تحمل تحميل سلسلة.

## قرار

تخطيط تأكيد أولا انتظار حرف جسم تحميل، إطار هيكل مرور عبور إتمام و Conversation عرض درجة إصدار، مجددا قراءة مقياس قياس؛ إطلاق دمج صار resize بعد، أيضا يحتاج انتظار ذلك ضبط درجة React تحديث، عندئذ قدرة قياس كمية عبر portal تركيب وجه لوح. دليل شجرة فرعي دليل و أصل دليل قراءة استخدام نفسه Remote انتظار ميزانية. مساحة العمل إعادة تحميل مشهد في فتح آخر عدد مسار تحرير جهاز قبل، انتظار Session اختيار استعادة و إدخال إطار نيل نيل تركيز نقطة، لأن متأخر إلى تجمع تركيز سوف إلغاء مسار مسودة مسودة. استجابة صيغة ملف وسم مشهد سوف فعلي قياس عبر طريق عرض درجة وضع في حاوية استعلام ملف موضع داخلي، و لـ منصة حرف جسم درجة كمية إبقاء واضح بقية كمية.

`pnpm run test:web` يحمل `apps/web/tests/` تحت بلا مفتاح، تحديد صفة متصفح e2e عربة طريق: تسجيل صنع جلسة سجل fixture مرور `@deepseek-ai/dsh-llm-replay` مقابل حقيقي عملية داخل web تركيب إعادة تشغيل؛ مستخدم مرئي حالة استخدام مواصفة تحويل aria مسبق مدة إخراج، حفظ دائم عالم حد حالة فإن استخدام عملية داخل تأكيد. إعداد طقم منتج اتفاق يشمل `dsh-llm-replay` عقدة عزف تحكم، إزالة استهلاك فحص و قد تحقق بحث جذب صيغة تغطية كتابة patch؛ عبر حزمة `dsh-llm` فشل عبر ذاتي لديه بيانات خاصية إبقاء مرور تحقق مزود معلومة؛ قد تسليم web تركيب تركيب `llm-retry`، بـ معالجة لحظة حالة نموذج فشل.

### Scaffold:`apps/web/tests/scaffold.ts`

واحد عادي مشترك fixture وحدة ([اختبار سياسة سياسة إقرار يمكن شكل](../../../../docs/testing.ar.md)) ، لا هو حزمة: قيمة نيل بوابة يأخذ حراسة منطق——إعادة تشغيل دفع توجيه، جلسة تحليل، سجل انفصال حساس، حفظ دائم——كل في قد تلقي بوابة حزمة `dsh-llm-replay`،`dsh-session-snapshot`،`dsh-session-persistence-jsonl` في؛ باق تحت فقط هو بدء وصل خط و متصفح لاصق ماء، بينما قيادة chromium شفرة المصدر في بلا متصفح نسبة التغطية runner فوق لا يمكن صدق فعلي إبقاء تدريجي ملف 100% نسبة التغطية.

`launchWebScaffold()` عبر vendored Loader include آلية، من تسليم `apps/cli/config/base.cordis.yml` و `apps/cli/config/web.cordis.yml` بدء حقيقي web تركيب——و `AppCLIEntry` لـ `dsh web` قيادة هو نفس شجرة شجرة، نفس طقم آلية. فرق مختلف الكل مرور include patch تغطية في هذا شجرة شجرة فوق، أي ACP `cordis.snapshot.yml` نمط عملية داخل جدول بلوغ: مؤقت `persistenceRoot`؛ كل رئيسي آلة درجة `skill-filesystem` أصل دليل (`dshHome`،`agentsHome` و `bundledSkillDir`) كل تثبيت في مؤقت مساحة العمل تحت و منع استخدام استماع، لأن بيئة skill(تقنية قدرة) دليل هو نموذج مرئي إدخال؛ منع استخدام `agent-instructions`(تسجيل صنع fixture لا نيل تضمين دخول هذا مستودع AGENTS.md) ؛ منع استخدام `session-title-llm`(ذلك إرسال بعد لا إدارة عنوان استدعاء سوف و حلقة تنازع انتزاع جلسة إعادة تشغيل تنقل علامة) ؛webserver سطر تثبيت إلى طرف فتحة 0، و استخدام قد بناء dist؛ بلا مفتاح نمط تحت منع استخدام `llm-deepseek`.patch id واحد حالما لم يعد مطابقة أي سطر،boot مسح سوف كبير صوت فشل بينما لا هو عائم نقل.boot في مؤقت مساحة العمل `chdir` تحت تشغيل، جعل api-gateway `process.cwd()` جلسة قيمة افتراضية، أداة cwd و fixture متسق؛`dsh web` bin ذاته لاصق ماء (argv،profile json،AppCLIEntry) ما زال من `smoke-real.e2e.ts` في بلا مفتاح CLI(أمر سطر واجهة) خطر دخان يأخذ حراسة. ابتدائي تحويل تراجع و صحيح معتاد إغلاق كل سوف أولا مقابل Cordis شجرة تنفيذ dispose(مورد تحرير) ، مجددا حذف scaffold يحتفظ اثنان عدد مؤقت أصل دليل؛ كل بند تنظيف كل سوف مستقل محاولة تجربة، و سوف تقرير إبلاغ تنظيف فشل بينما لا إخفاء غطاء ابتدائي تحويل فشل.

بلا مفتاح نموذج استبدال = منع استخدام مهايئ سطر patch إضافة `installLlmReplay` في توقف مستقر أصل ctx فوق بـ مزود دليل (providers-catalog) نمط ملء ملء فارغ مهايئ سجل التسجيل——أبدا استخدام catch-all: مهايئ سطر يتم منع استخدام بعد لا وجود أي مهايئ،catch-all سوف يجعل `resolveModelInfo` بلا توجيه يمكن مشي،`compaction-basic` خطوة بعد ضغط قوة فحص سوف خطوة خطوة إبلاغ تحذير، بينما لا هو يتم يمكن إثبات أرض خامل وضع (إصدار 128k `contextWindow` جعل هذا مسار مقابل صغير fixture إبقاء خامل وضع). اختيار مباشر تثبيت بينما غير إدراج دخول إعادة تشغيل إضافة سطر هو لحظة معنى: مباشر تثبيت إرجاع استلام ذيل إزالة استهلاك فحص الذي يحتاج `ReplayHandle`. لا يوجد fixture مشهد يجعل سجل التسجيل إبقاء فارغ وضع، أي معنى خارج تدفق صيغة استدعاء كل سوف بـ NO_ADAPTER كبير صوت فشل.

`seedSession()` عبر حقيقي حفظ دائم API بث نوع بارد جلسة——مرة صفة `Context` تركيب `SessionStore` + `JsonlSessionPersistence` إلى host أصل سياق،`create()` + `append()`، مرة `utimes` عودة تحويل حفظ إثبات جانب شريط ترتيب تحديد (`semantic-checkpoint.snapshot.ts` أولا مثال)——أبدا عار كتابة ملف، لذلك بث نوع جهاز مقابل دلو ها أمل، ملف اسم تحرير رمز، ضغط واحد بلا الذي معرفة،host zstd قيمة افتراضية أيضا بلا حاجة أي بدء فتح صلة. نوع فرعي في بث نوع وقت أي تحقق (يمكن تحليل، بـ `turn/end` ربط ذيل——لم إغلاق دمج نهائي جولة سوف يتم استعادة (resume) انهيار انهيار إصلاح تعديل كتابة).

### تحديد صفة قاعدة

إعادة تشغيل نمط تحت متصفح تأكيد شاشة عائق مكدس، حسب ترتيب:(1)host جانب `await agent.whenIdle()` إضافة مهلة، بـ عملية داخل `turn/end` لـ مرساة——فارغ خامل قلب تحويل حدوث في حفظ دائم سقوط قرص بعد، مرة انتظار معا تغطية جولة إتمام و حمل دائم صفة؛ (2) متصفح أمان تحديد جولة استفسار (تدفق صيغة إخراج عقدة قد إزالة، نهائي نص مرئي). تسجيل صنع نمط تحت، سجل أخذ استلام في `whenIdle()` بعد،scaffold تحرير قبل إجراء، هذا وقت تشغيل في جلسة ما زال متاح. مفرد وحيد استماع عملية داخل `turn/end` هو خطأ شاشة عائق (هو أولا في SSE لقطة وصول متصفح، أولا في fsync إطلاق) ؛ منع توقف جولة استفسار حفظ دائم ملف قدوم ملء عند جولة إتمام أو حمل دائم صفة شاشة عائق (NFS فوق بطيء، كما يتم `whenIdle` يحل محل) ، لكن أداة تحكم مؤقت حينئذ خيط علامة يمكن فقط بصفة هذا إتمام شاشة عائق قبل تفاعل باب تحكم إجراء جولة استفسار؛`networkidle` يتم تام قاع منع توقف (SSE تدفق إبقاء فتح وقت هو دائم لا تحليل). تنقل تأكيد سوف في صفحة تحميل قبل معا استماع `session.list` و `workspace.list` ابتدائي استجابة، مع بعد انتظار بث نوع بيانات إسقاط إلى DOM؛ فقط سند shell قد تركيب لا يستطيع حكم تحديد حينئذ خيط، لأن مقارنة متأخر إتمام bootstrap ممكن استبدال تلقي تحكم حالة.

لا فعل مفرد مرة لحظة حالة DOM تأكيد: من replay yield إلى React commit كل واحد قفز كل ممكن دمج chunk، أخذ مثال `[data-streaming]` يوم لكن حينئذ هو تنافس حالة. تدفق صيغة زيادة كمية صفة عبر لديه ترتيب `agent/assistant-stream` follow path تأكيد، نهائي حمل دائم `assistant/message` أو `assistant/attempt` فإن تضمين دخول replay استخدام دقيق stream.`dsh-llm-replay` اختياري `paceMs`(افتراضي نقص حذف = burst) فقط هو يجعل متصفح مراقبة إلى حق صحيح زيادة كمية SSE حقيقي شعور دوران زر؛ صحيح تأكيد صفة أبدا اعتماد هو، كما pace wait خلال abort سوف أي وقت إلغاء.

قسم صفحة قيادة سوف انتظار تفاعل صيغة تحميل سطر خروج pending حالة، و في تمرير قبل سجل طلب قبل سطر عدد. لذلك، أي وقت إيداع معتاد إقامة صفحة ما زال يمكن مراقبة قياس، لن تغيير صار مرة تمرير يد اتجاه لن تكرار إطلاق طلب أساس خط.

كل مشهد كل سوف بسبب أي pageerror أو عميل اتصال فقد فقد/بين فجوة إصلاح تحكم منصة تحذير إبلاغ بينما فشل: لا فإن إعادة وصل آلية إضافة تاريخ إعادة تزامن سوف يأخذ واحد بند ميت إسقاط SSE عبر مسار ذاتي شفاء إسقاط، طقم عنصر عكس بينما إقرار إثبات تالف wire.Scaffold `close()` استدعاء `ReplayHandle.assertConsumed()` استلام ذيل فحص (كل قد تسجيل نص برمجي كل يتم ربط، كل تنقل علامة كل استهلاك كل) ، يأخذ ساكن صامت قليل وضع و خطأ ربط تغيير صار صاف واضح تشخيص. عربة طريق لا ضبط vitest إعادة محاولة؛ كل ملف واحد chromium، كل مشهد واحد جديد context، كل مشهد واحد host؛ نظر فتحة ثابت؛ تفاعل اختيار جهاز مرساة تحديد role،`data-*` خاصية و مرئي نص، بينما frame و جلسة منطقة أخذ تجميع فإن استخدام قائم CSS وحدة نطاق جزء صنف اسم مرساة نقطة. معتاد قاعدة مشهد فتح بدء `en-US` متصفح، جعل محلي تحويل role تحديد موضع جهاز و مسبق مدة إخراج موحد واحد اعتماد واضح إشارة تحديد لغة؛ تأكيد العربية نص سجل مشهد فإن فتح بدء `ar-SA` متصفح، لأن Host settings وثيقة لا يوجد صريح انحراف جيد وقت، عميل مؤقت تحديد locale من `navigator` دفع توجيه ([من متصفح دفع توجيه ابتدائي locale](../../archived/feature/2026-07-31-browser-derived-initial-locale.md)).`settings-chrome.e2e.ts` أيضا مقدار خارج تغطية مزدوج نحو تبديل، كل جديد إنجليزي نص متصفح افتراضي حالة، و مشترك نفس DSH home مختلف طرف فتحة بين انحراف جيد حفظ دائم.

### مسبق مدة إخراج

أداة لديه مستقر الذي تابع منطقة مجال مشهد سوف لـ كل مختلف مستخدم مرئي حالة إيداع واحد نسخة مواصفة تحويل `ariaSnapshot()`؛ عبر منطقة مجال workspace إدارة حالة فإن استخدام دلالة DOM تأكيد و مرجعي host حالة فحص.UUID،cwd،workspace basename و وقت طويل انتظار سهل تغيير محتوى سوف عودة واحد لـ مستقر token؛ أخذ تجميع مرور مسار حمل متابعة جولة استفسار، مباشر إلى وصل متابعة اثنان مرة مواصفة تحويل قراءة نتيجة نفسه.Role و نص مرساة نقطة متابعة ملء عند يمكن مراجعة مسبق مدة إخراج دورة محيط دلالة منع خط، و مباشر تغطية عبر منطقة مجال حالة. يملك تسجيل صنع Session مشهد افتراضي سوف مواصفة تحويل بعد إعادة حفظ دائم أصل generation و اختيار تحديد الأكثر عال parent fixture مقارنة مقارنة (v0 لـ `session.jsonl`، صحيح generation لـ `session.vN.jsonl`) ؛ استعارة استخدام أو إرسال توليد fixture مشهد صريح إغلاق هذا مقارنة مقارنة. عالم حد حالة تأكيد ما زال استخدام مرجعي host حالة أو مستقل، كامل `workspace.expected/`، لأن transcript مطابقة لا يستطيع إثبات خارجي فاعلية نتيجة.`refresh` هو ARIA مسبق مدة إخراج وحيد writer؛replay نمط تحت نقص قليل مسبق مدة إخراج وقت، اختبار سوف وصل نفس إعادة توليد أمر واحد بدء فشل.

نوع فحص مستو وجه قطع قسم هو بنية صفة:host scaffold، ذلك دعم حمل وحدة، و كل بدء أو فحص host تركيب web spec كل سوف من تسجيل في client جانب `apps/web` عمل مسار في ترتيب حذف، و تدريجي ملف قبول دخول `tsconfig.host.json`. واحد برنامج لا يستطيع معا يحتفظ Cordis `Context` دمج اثنان جانب.

### نمط و fixture

`DSH_SNAPSHOT` اختيار replay(افتراضي، بلا مفتاح) ،record(حمل مفتاح) أو refresh(بلا مفتاح). إرسال بدء تلميح spec سوف كل نمط مشترك استخدام قيادة خطوة و فقط توفير replay/refresh استخدام تأكيد قسم فتح؛record نمط قيادة حقيقي إدخال إطار، أخذ استلام داخل تخزين في جلسة header و حدث، انفصال حساس طلب رأس، و token تحويل عند مرة تشغيل جلسة،cwd و RPC معرف. مع بعد مرة بلا مفتاح refresh إعادة توليد ARIA مسبق مدة إخراج. كل بند نص التوجيه كل سوف و fixture في تسجيل صنع `user/message` نواة مقابل؛ كل مشهد دليل كل اعتماد غلاف إغلاق بيان، منها كل JSONL كل هو انفصال حساس لا حركة نقطة. لغة مادة manifest لـ كل Web تركيب/header صنف قسم إعداد كما فقط قسم إعداد واحد pin، و فقط في هذا pin sidecar في إبقاء نص التوجيه و أداة schema متن.

### تغطية اتفاق

هذا عربة طريق تغطية ثلاثة صنف سلوك. فوري جولة مشهد تثبيت إقامة عادي أداة تنفيذ، إلغاء، غير ممكن إعادة محاولة فشل، لحظة حالة إعادة محاولة، معتاد إقامة رفع سؤال و جولة في طريق steering(في طريق جذب توجيه) ؛ تزامن اعتماد حمل دائم حدث،`whenIdle()` أو صريح إعادة تشغيل علامة، بينما لا استخدام تأخير وقت. بارد تاريخ مشهد عبر حقيقي حفظ دائم API بث نوع، في لا استدعاء نموذج حال حال تحت تغطية تاريخ تصيير، جانب شريط بحث،Trajectory و waterfall(شلال نشر صيغة حدث) عرض و أداة تفصيل حال. متصفح دورة الحياة مشهد تغطية أول مرة إرسال وقت شيء تحويل مساحة العمل، إعادة تحميل استعادة، تخطيط إعادة وضع، رئيسي عنوان و لغة انحراف جيد، و مساحة العمل إنشاء، إعادة تسمية و عرض عملية. كل صنف مشهد كل تأكيد متصفح جدول وجه و مرجعي host حالة؛ معنى خارج نموذج استدعاء أو لم استهلاك كل fixture سوف جعل تفكيك إزالة فشل. مطلوب عربة طريق أيضا يتضمن واحد نسخة دمج صار 88 جولة Chat تمرير اتفاق، منها خلط دمج تبديل سطر Markdown، محيط شريط شفرة و صار مقابل bash استدعاء/نتيجة. حقيقي wheel، إدخال إطار، أداة،tab، جلسة و viewport تفاعل سوف في تزامن تاريخ قبل إدراج إضافة حمل عقدة عزف تدفق صيغة إخراج، لصق قاع/مغادرة قاع تدفق صيغة إخراج، أداة disclosure مغادرة شاشة حلقة، توسيع تاريخ بعد عرض/جلسة إعادة تركيب، عرض درجة إعادة ترتيب، لصق قاع بعد قيام أي إعادة تركيب، إدخال إطار مقياس قياس تغير و textarea wheel سلسلة مشهد في، تأكيد واحد قد مستقر أداة اسم سطر متبادل مقابل transcript scrollport قمة جزء موضع و إلى حقيقي قاع جزء مسافة مغادرة؛ حقيقي مفتاح قرص قلب صفحة و لمس لمس صيغة معتاد صفة انزلاق حركة نموذج محاكاة مقدار خارج تثبيت إقامة لا اعتماد wheel لصق قاع تتبع مع كل حق ([قراءة من تمرير عودة بسبب قلم تسجيل](../../archived/bug-fix/2026-08-06-reader-scroll-attribution-observed-top-ledger.md)) ؛ هو لحظة معنى لا تثبيت DOM أساس عدد أو قطعا مقابل `scrollTop`، لذلك نفس اتفاق يمكن تحقق استلام وهمي محاكاة تحويل تنفيذ. آخر نسخة أساس في نفس fixture تفاعل اتفاق تثبيت إقامة مختلف بنية سطر ترتيب، متبادل مجاور أداة disclosure مستقل حالة، مستخدم رسالة قص لصق لوح محتوى دقيق قيمة، بـ جولة لـ حد رسالة fork، مصدر جلسة/فرعي جلسة عزل، و فرعي جلسة في مرة حقيقي تتبع سؤال جولة؛wheel إدخال فقط لأجل تنقل إلى دلالة هدف، لا تحمل تحميل بضعة أي مسبق مدة. واحد نسخة بسيط قصير فوري تاريخ اتفاق من فارغ أبيض مساحة العمل بدء، وصل متابعة قيادة إدخال إطار جولة، منها يشمل حقيقي bash استدعاء/نتيجة جولة و واحد مقطع حمل عقدة عزف طويل مقالة نهائي استجابة؛ هو تثبيت إقامة مفرد واحد جلسة هوية، كل جولة حدث دقيق ملكية، متصفح عودة إظهار وحيد صفة و إدخال إطار استعادة، لا ضبط وقت عتبة قيمة.

### CI قيام ساحة

أصل حسب[متصفح لقطة CI قرار](2026-07-30-web-browser-snapshot-ci-gate.ar.md) ، هذا عربة طريق هو Linux سحب أخذ طلب مطلوب فقط مقارنة مقارنة بوابة.`node 24 / snapshots and artifacts` مستهلك مهمة في[مستهلك مستقل بناء](../../archived/process/2026-07-30-independent-ci-consumer-build.md) في مسؤول وحيد مرة Linux بناء، تثبيت قفل ملف اختيار تحديد Chromium، استعادة بـ عملية نظام و قفل ملف لـ مفتاح ذاكرة مؤقتة، و استخدام `DSH_SNAPSHOT=replay` تشغيل هذا عربة طريق. هذا هو متعمد مستو وجه قطع قسم:host و spec استخدام [tsx شفرة المصدر بدء اتفاق](../architecture/2026-07-29-dsh-source-launch-tsx-esm.ar.md) ، متصفح فإن إزالة استهلاك `apps/web/dist` و حزمة `lib/client.js` ناتج، لذلك بوابة اعتماد `built-package-invariants` توفير هذه عميل ناتج. ذاتي حمل إدارة افتراضي فرع Linux سلسلة سطر حار تجهيز تشغيل نفس بوابة؛ لا وجود حمل إدارة Linux سلسلة سطر إنتاج من توليد توفير PR إزالة استهلاك متصفح ذاكرة مؤقتة، حفظ دائم ذاتي حمل إدارة حوض فإن لا حاجة حمل إدارة جانب ذاكرة مؤقتة.CI من لا تسجيل صنع أو تحديث جديد مسبق مدة إخراج. مشهد ما زال موجه إلى POSIX، و متابعة وضع في Windows و macOS مستطيل دفعة خارج.

عال أساس عدد صفة قدرة تشخيص استخدام مفرد وحيد حسب يحتاج تفعيل `apps/web/tests/**/*.perf.ts` بيان، و كما فقط من `vitest.web.perf.config.ts` اختيار في.`complex-history.perf.ts` عزل حالة استخدام إعادة استخدام حقيقي scaffold: مساحة العمل حالة استخدام بث نوع 1,000 عدد ضيق تجميع جلسة و واحد نسخة يتضمن 500 مرة أداة استدعاء 500 جولة تاريخ، في Chat في نفاد كل و إعادة تركيب هذا تاريخ، و تقرير إبلاغ Chromium رئيسي خط مسار،DOM، مستمع، كومة داخل تخزين، قسم صفحة، بحث و Trajectory قياس كمية نتيجة. اثنان عدد متابعة حديث حالة استخدام بث نوع نفس نسخة طويل تاريخ، لكن مقارنة مقارنة افتراضي 24 جولة Chat نافذة و توسيع الكل 500 جولة حالة، لكن بعد كل منها عبر حقيقي إدخال إطار،agent loop،SSE wire، أداة و حفظ دائم متابعة إجراء 8 عدد نفسه جولة؛ منها اثنان جولة تنفيذ حقيقي `bash` استدعاء و تأكيد ذلك حفظ دائم نتيجة، الأكثر بعد واحد جولة فإن ملء دخول واحد بند يتضمن 8,232 عدد محرف خلط دمج لغة نص التوجيه، و إعادة تشغيل 120 عدد حمل عقدة عزف نص زيادة كمية. واحد مفرد وحيد soak حالة استخدام من فارغ أبيض جلسة بدء، عبر حقيقي إدخال إطار وصل متابعة قيادة 100 جولة، كل رقم 10 جولة تنفيذ مرة `bash` استدعاء و إنتاج نتيجة، كل 10 جولة قوي صنع تنفيذ مرة GC، و تقرير إبلاغ كل 10 جولة تأخير متأخر نافذة و إبقاء متصفح حالة. مع بعد هو عبر تلقي معلومة مهمة متصفح نقر إيداع رقم 101 عدد صاف نص جولة، و استخدام متصفح وقت ساعة قسم آخر قياس كمية إرسال إلى transcript DOM و إرسال إلى رسم صنع بعد تأخير متأخر، ترتيب حذف إدخال إطار مسودة مسودة مرآة مثل، و و كامل جولة إتمام وقت قسم فتح. تدريجي جولة تشخيص شمول غطاء إدخال إطار ملء دخول، نقر إلى مستخدم رسالة عودة إظهار، نقر إلى أول عدد قسم قطعة، إتمام، متصفح تغيير، حفظ دائم قسم قطعة و أداة حدث؛ دمج صار إعادة تشغيل نموذج يملك كاف كاف سياق سعة كمية، يمكن جعل fixture أساس عدد إبقاء مستقر، بينما لن بسبب ضغط (compaction) إزالة استهلاك نص برمجي تحويل استدعاء. بنية صفة تأكيد تثبيت إقامة مسبق مدة سالب تحميل، تدفق و أداة شكل حالة، لكن وقت ما زال لا ضبط عتبة قيمة، لأن آلة جهاز سرعة درجة لا يخص صحيح تأكيد صفة اتفاق. مطلوب `vitest.web.config.ts` بيان ما زال فقط حد `*.e2e.ts` و `*.snapshot.ts`، لذلك `test:web:built` و ذلك CI بوابة كل لن استلام تجميع صفة قدرة حالة استخدام.

## عمل حد أولا مثال

ضبط بحث AI(شخص عمل ذكي) حديث يوم/agent web UI و mock طبقة (LibreChat،vercel/ai-chatbot + AI SDK،lobe-chat،open-webui،OpenHands،Chainlit،continue،cline،langfuse،gradio/streamlit؛Playwright HAR/route،MSW،Polly/nock،WireMock،aimock). ذاتي لديه خلفية تطبيق رئيسي تدفق صار ناضج هيكل بنية هو: حقيقي خلفية اتفاق بعد وضع واحد عملية داخل زائف صنع/إعادة تشغيل نموذج، تحت تنقل الكل حقيقي (LibreChat `LIBRECHAT_TEST_RUN_HOOK` زائف نموذج؛ai-chatbot `MockLanguageModelV3` + `simulateReadableStream`؛continue نص برمجي تحويل mock مزود صنف)——هذا صحيح هو `dsh-llm-replay` قد لكن الذي هو. متصفح طبقة SSE اعتراض قطع لا يمكن فحص تحقق زيادة كمية تصيير (`route.fulfill` مرة صفة تسليم كامل استجابة جسم؛playwright#33564) ، كما خدمة طرف SSE مكدس تماما فقد قياس، لذلك كل مشروع فقط يأخذ هو لأجل حافة حافة حالة استخدام. قسم قطعة عقدة عزف بصفة fixture معامل عكس تكرار ظهور (LibreChat افتراضي 10ms مرفق بطيء سرعة ملف؛ai-chatbot 500ms) ؛CI داخل حقيقي نموذج سوف فاسد تالف (open-webui طقم عنصر طويل خروج 120 ثانية مهلة، أولا يتم منع استخدام بعد يتم حذف) ؛ جلسة في حفظ دائم طبقة بـ تلقي تحكم ختم الوقت بث نوع (LibreChat مباشر إدراج عودة تحويل وقت Mongo وثيقة؛langfuse بث نوع ذلك قاعدة بيانات). لا يوجد أي يتم ضبط بحث مشروع لـ UI اختبار يأخذ تسجيل صنع agent حدث سجل مرور حقيقي خلفية إعادة تشغيل——الأكثر وصل قريب هو مزود طبقة تسجيل صنع fixture(aimock) و قبل طرف طبقة socket تاريخ إرسال إطلاق (OpenHands MSW)——لذلك جلسة سجل أي fixture تصميم امتداد حال هذا مستودع «نموذج مرئي ⟺ قد سجل» ثابت صيغة الذي إشارة جهة نحو مقارنة عمل حد أولا مثال كثير مشي واحد خطوة.

## سبق اعتبار بديل خطة

**متصفح شبكة شبكة طبقة SSE اعتراض قطع (`page.route`).** قد مرفوض:`route.fulfill` لا يمكن تدفق صيغة إخراج، زيادة كمية token تصيير بلا من فحص تحقق، كما خدمة طرف SSE/خلف ضغط/إغلاق مسار——اثنان بدء قد فعلي إثبات P0 إخفاء ذات موضع——تماما فقد قياس.

**`DEEPSEEK_BASE_URL` موضع mock HTTP مزود.** بصفة هذا عربة طريق آلية قد مرفوض (فقط إبقاء إعطاء قائم مساحة العمل استكشاف إبرة خطر دخان):fixture سوف تغيير صار يد كتابة OpenAI SSE بايت نص برمجي، واحد نوع و مستودع ذلك بقية جزء تسجيل صنع إعادة تشغيل جلسة سجل صيغة تدريجي سطر تدريجي بعيد ثاني fixture صيغة؛ مهايئ حقيقي HTTP مسار عودة حمل مفتاح e2e إدارة.

**إبقاء أو توسيع `?fixture` عميل.** قد مرفوض: فقط عميل تجميع اختبار حقن `RemoteMock`، اعتماد Host سلوك اختبار فإن تشغيل حقيقي scaffold. إنتاج query فتح صلة سوف إبقاء ثاني طقم تطبيق خلفية، بينما كما Client API التالي ما زال حسب بنية صنع فقد قياس.

**استخدام احتلال موضع `DEEPSEEK_API_KEY` + إعادة تشغيل اعتراض قطع بديل منع استخدام مهايئ سطر.** كل إدارة صفر تركيب تعديل كما شجرة داخل لديه اثنان موضع أولا مثال ما زال يتم مرفوض: هو استخدام كذب قول ممتلئ كاف `llm-deepseek` سريع سرعة فشل مفتاح فحص، أيضا إبقاء تحت واحد تركيب لكن يتم اعتراض قطع ميت مهايئ؛ منع استخدام سطر (ACP overlay نفس بند فعل قاعدة) هو صدق فعلي بلا مفتاح، و في الأكثر مبكر يمكن تحليل نقطة سريع سرعة فشل.

**`packages/test-support/web-snapshot` حزمة + `defineWebSnapshotSuite` عمل مصنع.** قد مرفوض: قيادة chromium شفرة المصدر في بلا متصفح نسبة التغطية runner فوق لا يمكن صدق فعلي إبقاء تدريجي ملف 100%، كما حذف تلقي بوابة حزمة قد توجيه خروج مساعد مساعدة أداة و محلي scaffold خارج، هذه مشهد مخصص استخدام تفاعل بعد لم شكل صار مستقر بلا متصفح اتفاق. ظهور ثاني عدد web شكل مستهلك، أو يتم إثبات فعلي تكرار دورة الحياة شفرة تأكيد قيام هذا اتفاق بعد، مجددا إعادة اعتبار.

**مفرد وحيد صيانة ثاني نسخة مواصفة تحويل Session سجل مسبق مدة إخراج.** لا إعطاء اعتماد: يأخذ اختيار تحديد تسجيل صنع generation مجددا نسخ صار آخر عدد ملف سوف جعل refresh صار هذا قلب ضعف، لكن لن زيادة مستقل oracle. لغة مادة تعديل لـ سوف مواصفة تحويل حفظ دائم نتيجة و قيادة replay نفس نسخة الأكثر عال generation parent fixture مقارنة مقارنة، معا بـ host حالة و كامل workspace تأكيد إبقاء مستقل عالم حد تحقق معنى خدمة.

**بـ `DSH_SNAPSHOT` إعادة تشغيل فرع سحب بدء `dsh web` bin.** قد مرفوض: هو حاجة في تسليم CLI في زيادة اختبار مخصص استخدام إعادة تشغيل فرع و بيئة متغير إدارة طريق. عملية داخل scaffold قد تحميل نفس نسخة `apps/cli/config/base.cordis.yml` و `apps/cli/config/web.cordis.yml`؛ فقط باق argv،profile JSON و `AppCLIEntry` لاصق ماء لا في ذلك تغطية نطاق داخل، بينما هذه مسار قد من بلا مفتاح CLI خطر دخان تغطية.

**لـ يمكن اختبار صفة تعديل wire بروتوكول.** قد مرفوض: اتفاق قد لديه رقم واحد انتظار بلا مفتاح عملية داخل مسار (`InProcessApiClient(toFetchHandler(api))`) ، تدريجي حدث لا دمج دفعة SSE تماما هو إعادة تشغيل في متصفح في يمكن مراقبة قياس سبب، اختبار واحد بند لم يعد تسليم wire سوف قلب قلب هذا طبقة وجود معنى معنى.

**بـ حقيقي نموذج متصفح اختبار ملء عند بلا مفتاح عربة طريق.** قد مرفوض: حسب بنية صنع أي لا تحديد؛ يتم ضبط بحث قبل عربة لـ تمييز (open-webui) طويل خروج بلا حد مهلة بعد يتم حذف. حمل مفتاح حقيقي host خطر دخان ما زال هو حقيقي نموذج جانب تكملة ملء.

**في مطلوب متصفح بوابة في تشغيل عال أساس عدد صفة قدرة حالة استخدام.** قد مرفوض: ذلك fixture ضبط و كامل تاريخ تصيير سوف زيادة عدد عشرة ثانية استهلاك وقت، بينما جدار ساعة وقت و داخل تخزين قيمة مع host مختلف بينما تغير، لا يمكن توفير مستقر صحيح تأكيد صفة عتبة قيمة. مطلوب عربة طريق إبقاء تحديد صفة سلوك تأكيد؛ مساهمة من في ضبط فحص أو أكثر تعديل كبير قائمة و طويل تاريخ تصيير وقت تشغيل هذا تشخيص حالة استخدام.

**عميل `data-dsh-busy` أمان تحديد إشارة.** مؤقت مؤقت:host جانب `whenIdle` شاشة عائق إعداد دمج مستقر DOM جولة استفسار، كاف بـ تغطية حالي مشهد. رقم مرة أمان تحديد جولة استفسار اهتزاز حركة، أو لا بد يلزم حالة في DOM في غير ممكن مراقبة وقت، مجددا إعادة اعتبار.

## اختبار

`pnpm run test:web` بناء و بلا مفتاح تشغيل هذا عربة طريق؛`test:web:built` أساس في قائم بناء ناتج تشغيل.`pnpm run test:web:perf` بناء و تشغيل يد حركة صفة قدرة بيان؛`test:web:perf:built` إعادة استخدام قائم ناتج.`DSH_SNAPSHOT=record pnpm exec vitest run --config vitest.web.config.ts apps/web/tests/<spec>` مقابل حقيقي نموذج تسجيل صنع واحد إرسال بدء تلميح مشهد،`DSH_SNAPSHOT=refresh pnpm run test:web` فإن بلا مفتاح إعادة كتابة aria مسبق مدة إخراج.CI صريح اختيار إعادة تشغيل نمط.live-interactions AUTH مشهد سوف يأخذ غير ممكن إعادة محاولة نهاية حالة فشل تثبيت لـ Chat داخل ربط حالة، منها يحمل ملائم دمج عرض رسالة و رمز خطأ، و تحقق مزود عودة إظهار اعتماد قطعة مقطع لن ظهور في Chat أو Trajectory في؛ هذا مشهد معا تغطية إدخال إطار استعادة و `turn/end` خطأ.scaffold بيئة عزل مشهد سوف في الكل 3 عدد بيئة skill أصل دليل في قسم آخر ملء دخول مختلف بند، و اشتراط هذه بند كل لا نيل دخول تجميع بعد دليل.`dsh-llm-replay` وحدة نسبة التغطية تثبيت إقامة عقدة عزف تحكم، إلغاء، إزالة استهلاك تشخيص،sidecar تحقق، حسب بحث جذب استبدال و وحيد إلحاق موضع.

## مؤقت مؤقت

- **استعادة بعد تتبع سؤال مشهد**: حقيقي wire فوق تاريخ/فوري شق دمج مسار؛ عند هذا شفرة تغيير أو ارتداد وقت بصفة مستقل مشهد تكملة ملء.
- **إدخال إطار steering يد اتجاه**: إدخال في تشغيل خلال قفل تحديد (فقط قدرة إيقاف أو انتظار) ، لذلك steering مشهد من صفحة مشي wire فعل steer؛`TODO(web-steer-composer)` انتظار منتج طويل خروج حقيقي إدخال إطار يد اتجاه بعد، يأخذ قيادة خطوة ترقية لـ هذا يد اتجاه.
- **سحب جر جلسة إعادة ترتيب**:`workspace.insertSessionBefore` بعد بلا متصفح مشهد؛ هو حاجة في نفس عدد مساحة العمل داخل شيء تحويل اثنان عدد جلسة، و دمج صار HTML5 سحب جر حدث. عند هذا جدول وجه تغيير أو ارتداد وقت مجددا تكملة ملء. بلا سلوك جلسة Rename/Fork/Delete و مساحة العمل Delete قائمة مفرد سطر انتظار نيل نيل سلوك بعد مجددا تكملة ملء مشهد.
- **طويل تاريخ Chat إلى Trajectory Inspect**: اثنان عدد عرض مشترك استخدام Session قسم صفحة، بينما الذي اختيار Trajectory سجل من واحد إرسال توليد جدول إطار بحث جذب تحديد موضع؛ مع حال مقارنة مبكر صفحة قبل إدراج، هذا بحث جذب ممكن نقل حركة. قصير تاريخ Inspect ما زال لديه تغطية؛ في اختيار في بند أداة لديه مستقر دلالة هوية قبل، طويل تاريخ تفاعل اتفاق لا يتضمن هذا بند تسليم وصل.

## عاقبة

Web جدول وجه نيل نيل تسجيل صنع مرة/دائم دائم إعادة تشغيل طبقة درجة: حقيقي chromium → SSE → apiproxy → حلقة → أداة → حفظ دائم سلسلة مسار بـ نحو 10-30 ثانية بلا مفتاح تشغيل، تكرار تشغيل نتيجة تحديد،fixture من عربة طريق ذاته يحتفظ و يمكن إعادة تسجيل. قبول صار هذا: كل مرة متعمد جلسة UI تغيير كل بـ مرة بلا مفتاح `DSH_SNAPSHOT=refresh` استلام ذيل (مسبق مدة إخراج تغيير حركة هو تلقي مراجعة diff، مرساة تأكيد حفظ إقامة دلالة أخضر لون) ؛aria صيغة عودة Playwright كل——مستودع وحيد لا تلقي ذاتي ذات تحكم إيداع لقطة صيغة——لذلك playwright إصدار ترقية يجب هو لحظة معنى ترقية إضافة تحديث جديد إيداع (اعتماد في `apps/web/package.json` في طفو حركة لـ `^1.49.0`؛ إذا تغيير حركة إصابة شخص فإن تعديل لـ دقيق قفل تحديد) ؛ إعادة تشغيل أول مرة استدعاء ترتيب ربط يأخذ كل مشهد حد لـ حتى كثير واحد إرسال بدء تلميح جلسة، إزالة استهلاك تأكيد هو عرقلة خط؛`compaction-basic` و جلسة مشترك إعادة تشغيل تنقل علامة، فقط في دليل في إصدار 128k سياق نافذة تحت إبقاء خامل وضع؛ مطلوب مستهلك مهمة تحمل تحمل Chromium توفير إعطاء و مرة متصفح تشغيل صار هذا، جعل تعديل تجميع بعد UI PR(Pull Request) يحتفظ متبادل ينبغي مسبق مدة إخراج diff. حسب يحتاج تفعيل صفة قدرة عربة طريق إبقاء يمكن تكرار، بلا عتبة قيمة تشخيص عمل سالب تحميل، ذلك قياس كمية حاجة شخص عمل حل قراءة. مستقل مطلوب[قبل طرف صفة قدرة أساس دقيق](2026-09-06-frontend-performance-budgets.ar.md) في عزل أساس دقيق CI job في تنفيذ مرور تدقيق دقيق ميزانية؛ هو جمع لا نحو يد حركة بيان إضافة عتبة قيمة.
