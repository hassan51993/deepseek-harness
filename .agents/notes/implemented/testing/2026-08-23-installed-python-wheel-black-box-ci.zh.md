# Agent Note: تثبيت بعد Python wheel أسود صندوق سحب أخذ طلب تحقق

Status: implemented

[English](2026-08-23-installed-python-wheel-black-box-ci.md) | العربية

## Problem

Python SDK اختبار وحدة قيادة fake peer، بينما تحزيم وقت التشغيل سير العمل يمكن في اثنان عدد Python distribution بعد لم توليد وقت، استخدام شفرة المصدر SDK قيادة جديد بناء يمكن تنفيذ ملف. جاف صاف وهمي محاكاة بيئة فقط تغطية افتراضي و MCP مشهد، مطلوب سحب أخذ طلب CI أيضا فقط بناء Linux x64. لذلك، شفرة المصدر checkout،editable install، لا مطابقة SDK/وقت التشغيل تركيب، ضرر تالف أصلي wheel حزمة، منصة متبادل إغلاق حزمة أو حقيقي مزود تجميع صار كل ممكن التفاف مرور منع توقف دمج دليل.

## Decision

### تثبيت ناتج حد

مطلوب Python وقت التشغيل سير العمل أولا بناء صاف SDK wheel حزمة و كل منصة وقت التشغيل wheel حزمة، مجددا إجراء سلوك اختبار. كل أصلي هدف كل يأخذ هذا اثنان عدد محلي ملف تثبيت دخول جديد Python 3.10 وهمي محاكاة بيئة، تبديل إلى مستودع خارج مؤقت دليل، صاف حذف `PYTHONPATH` و `DSH_RUNTIME_MODE`، و كما فقط استدعاء عام Python وحدة و تحزيم بعد يمكن تنفيذ ملف.

أسود صندوق اختبار سوف رفض غير venv عملية، مستودع داخل عمل دليل، شفرة المصدر أو editable import، لا متبادل انتظار distribution إصدار، لم دقيق ثابت وقت التشغيل إصدار SDK اعتماد، يقع في قد تثبيت وقت التشغيل حزمة خارج يمكن تنفيذ ملف، و لم ظهور في وقت التشغيل distribution سجل في يمكن تنفيذ ملف. هذا مصدر تحقق حدوث في أول عدد agent طلب قبل، لذلك سلوك عبر أيضا لا يستطيع إخفاء غطاء فعلي تشغيل خطأ شفرة.

### Keyless سلوك

كل هدف كل سوف في تثبيت بعد تشغيل كامل تحزيم وقت التشغيل مشهد. واحد محلي SSE mock نموذج توفير تحديد صفة إخراج، عام SDK فإن تغطية افتراضي SDK profile، لديه ترتيب patch overlay، عبر `dsh plugin` تثبيت خارجي bundle، حمل دائم PTY و editor سلوك،PTC Node برنامج و workflow تنفيذ، أساس في ripgrep بحث، خارجي stdio MCP اكتشاف و تنفيذ، نموذج مرئي و حفظ دائم لقطة،Zstandard حفظ دائم، مباشر JSON-RPC و إغلاق.Restart لقطة إبرة مقابل نفس حفظ دائم أصل دليل بدء اثنان عدد كامل SDK وقت التشغيل عملية، و ثابت ذلك ذاك هذا عزل نموذج تاريخ، عال طبقة نتيجة و مستقل حمل دائم سجل. تثبيت بعد تشغيل يحل محل wheel بناء قبل شفرة المصدر SDK تشغيل، لذلك يمكن تنفيذ ملف و wheel حزمة مشترك نفس قبول مرة تحقق، بينما لا هو صيانة اثنان طقم سلوك بيان.

Linux آخر خارج إبقاء manylinux 2.28 جاف صاف تثبيت خطر دخان اختبار و GLIBC فحص.macOS إبقاء نشر هدف و أصلي helper فحص. هذه منصة قيد تكملة ملء مشترك نفس أسود صندوق سلوك، لا يستطيع بديل هو.

### حقيقي DeepSeek API

يمكن معلومة سحب أخذ طلب و master دفع إرسال سوف في كل منها اختيار تحديد أصلي هدف فوق تشغيل ثاني بند تثبيت بعد wheel فحص، و كما فقط في مسبق فحص و live اختبار خطوة في يأخذ `DEEPSEEK_API_KEY_EXTERNAL` خريطة دخول ذهاب. مفتاح لـ فارغ وقت مسبق فحص فشل، لذلك مزود اختبار لا يستطيع عبر ذاتي سطر skip إنتاج زائف أخضر. هذا اختبار عبر عام SDK وصول `https://api.deepseek.com`، اشتراط نموذج عبر حالي منصة shell كتابة محتوى دقيق sentinel ملف، مجددا في نفس session ثاني عدد جولة في قراءة هو، و تحقق خارجي ملف سطر محتوى، نهائي استجابة، قد إتمام جولة انتهاء سبب، نموذج طلب أداة استدعاء، و session سجل وجود كما اعتماد Zstandard framing. حل رمز بعد سجل محتوى و قد إتمام جولة حمل دائم صفة هو من restart لقطة مسؤول تحديد صفة keyless اشتراط، لا من ضغط بعد live مزود بايت دفع قطع.

Fork و Dependabot سحب أخذ طلب دائم بعيد لن نيل نيل مستودع مفتاح. هو جمع أصلي job تشغيل كامل keyless مسار و قفز مرور اثنان عدد حمل مفتاح خطوة؛ منع توقف استخدام `pull_request_target`، لأن هو سوف يجعل غير ممكن معلومة شفرة حمل حال مفتاح تنفيذ.

### مطلوب هدف

سحب أخذ طلب `python-runtime` job إبرة مقابل Linux x64 و Windows x64 استدعاء يمكن إعادة استخدام بناء جهاز؛master دفع إرسال أصل حسب[فقط master منصة سياسة](../process/2026-09-06-master-only-platform-ci.zh.md) اختيار Linux arm64 و اثنان نوع macOS هيكل بنية. ذلك تجمع دمج نتيجة ما زال هو `all checks passed` اعتماد، لذلك مهمة واحد أصلي تحميل جسم فشل، إلغاء أو ناقص كل سوف منع توقف مطلوب حكم تحديد عبر.[sdk-runtime README](../../../../python/sdk-runtime/README.zh.md) مسؤول Windows هدف و ذلك PowerShell مخصص تابع أقصى بسيط لقطة.

## Existing decisions and supersession

هذا قرار يحل محل قد عودة ملف[مطلوب Python وقت التشغيل سحب أخذ طلب تحقق](../../archived/testing/2026-08-12-required-python-runtime-pull-request-ci.md) في مفرد هدف توسيع اندفاع، معا إبقاء حقيقي يمكن تنفيذ ملف، لقطة،wheel حزمة و جاف صاف تثبيت يجب في كل اختيار تحديد هدف فحص في متبادل لقاء اشتراط.[docs/architecture.md](../../../../docs/architecture.zh.md) مسؤول بدء تطبيق و ذاتي تعريف واجهة؛[مفرد ملف Python SDK وقت التشغيل distribution](../architecture/2026-07-10-single-file-executable-sdk-runtime-distribution.zh.md) متابعة مسؤول SEA تحزيم، أصلي sidecar،wheel حزمة وسم و إصدار ناتج.

## Alternatives considered

**فقط إبقاء Linux x64 مطلوب تحميل جسم.** مرفوض: خمسة عدد قد إصدار هدف أصلي addon، يمكن تنفيذ ملف بناء،wheel حزمة وسم و helper ملف مختلف. انتظار إلى إصدار وقت عندئذ اكتشاف مشكلة، مقابل كل Python SDK تثبيت كل سوف حسب منصة اختيار ناتج بينما قول جدا متأخر.

**في wheel بناء قبل تشغيل كامل سلوك، و إبقاء اثنان عدد جدا صغير تثبيت بعد خطر دخان اختبار.** مرفوض: هذا فقط قدرة إثبات يمكن تنفيذ ملف إعداد دمج شفرة المصدر import عمل، مجددا عبر distribution إثبات جدا قليل سلوك. جاف صاف تثبيت بيئة هو في نفس دفعة مشهد في تحقق مستخدم فعلي تثبيت محتوى أكثر قوي موضع.

**فقط استخدام keyless نموذج نموذج محاكاة.** مرفوض: محلي SSE endpoint لا يستطيع إثبات حقيقي مزود إقرار إثبات، طلب توافق صفة، تدفق صيغة إخراج، أداة استدعاء حل تفسير أو كامل جولة.

**عبر `pull_request_target` نحو fork سحب أخذ طلب كشف مفتاح.** مرفوض: مهمة معنى fork شفرة كل يمكن سرقة أخذ مستودع مفتاح. غير ممكن معلومة ref نقص قليل حمل اعتماد دليل هو واضح كما إبقاء أمان صفة نتيجة؛ يمكن معلومة head و دمج بعد مزود CI متابعة توفير live إشارة.

## Consequences

كل سحب أخذ طلب كل سوف تحمل تحمل اثنان عدد أصلي يمكن تنفيذ ملف و wheel حزمة بناء، و تشغيل تحديد صفة تثبيت بعد ناتج مشهد. يمكن معلومة نفس مستودع سحب أخذ طلب أيضا سوف في كل هدف فوق تحمل تحمل مرة مزدوج جولة DeepSeek مهمة. متبادل ينبغي أرض، مطلوب نتيجة وصف Python مستخدم فعلي تثبيت ملف، في دمج قبل إثبات اختيار تحديد تحميل جسم، و كما لا يستطيع عبر استيراد checkout أو ساكن صامت قفز مرور حقيقي مزود بينما عبر.
