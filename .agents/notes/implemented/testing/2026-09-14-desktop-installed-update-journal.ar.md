# Agent Note: عبر إعادة بدء إبقاء قد تثبيت Desktop تحديث دليل

Status: implemented

[English](2026-09-14-desktop-installed-update-journal.md) | العربية

## مشكلة

قد تثبيت تطبيق تحديث سوف استبدال تطبيق ملف، و خروج مراقبة قياس تحت تحميل عملية. فقط لديه طرفية إخراج لا يمكن سلسلة ربط نقل فشل، صريح إعادة محاولة، تثبيت تخويل و تحت واحد إصدار بدء. أصلي updater تشخيص ممكن يتضمن خاص URL أو اعتماد.

## قرار

Desktop رئيسي مدخل قبول صريح تفعيل قطعا مقابل مسار `DSH_DESKTOP_UPDATE_JOURNAL_DIR`. تحقق استلام حزمة يجب في مختلف إصدار بين إبقاء نفس عدد خارجي دليل. كل عملية وحيد احتلال إنشاء مفرد وحيد JSONL ملف، و في متابعة تنفيذ قبل تحديث جديد أبيض اسم مفرد داخل حالة و عملية سجل. قد تثبيت إصدار،PID، ترتيب رقم و UTC وقت معرف سجل. كامل عدد دخول درجة تغير حد تكرار كتابة؛ أصلي خطأ،URL، طلب رأس و حديث يوم محتوى متساو يتم حذف. معروف خطأ علامة إنتاج ثابت تصنيف، لا نسخ تشخيص نص.

لم ضبط هذا متغير وقت لا تفعيل سجل. صريح تفعيل تحقق استلام تخزين فشل سوف نحو فوق نقل بث، لن ساكن صامت صوت تسمية دليل كامل. بدء و مساحة العمل حينئذ خيط فقط هو مراقبة قياس نتيجة، لا يستطيع إثبات تثبيت نجاح أو مستخدم بيانات إبقاء.[محلي تحقق استلام قرار](2026-09-10-desktop-local-updater-qualification.ar.md) متابعة صالح: هذا سجل لا يحل محل ذلك عزل اشتراط، تثبيت اعتراض قطع نطاق حد أو صلب عنصر حد.

[تثبيت إصدار دفعة مرة أداة](../../../../apps/desktop/scripts/installed-update-qualification.ts) إنشاء مستقل test بيان، لا قراءة اعتماد أو تنفيذ بعيد مسار عملية. ذلك فقط قراءة فحص جهاز اشتراط نفس أصل عملية داخل حسب ترتيب سجل فشل، يد حركة إعادة محاولة، حينئذ خيط، تأكيد و خروج، مجددا سجل بعد استمرار إصدار بدء و مساحة العمل حينئذ خيط. لم معرفة حقل، لا كامل سجل، ترتيب رقم نقص فتحة و خلط دمج عملية هوية متساو يتم رفض. أي جعل سجل مسار كامل، أيضا إبقاء إصدار وقت، شبكة استعادة، تثبيت جهاز إتمام و بيانات إبقاء مستقل شخص عمل فحص؛ واحد مجموعة بدء سجل لا يستطيع بديل بديل هذه مراقبة قياس.

## اعتبار مرور بديل خطة

**فقط إبقاء طرفية إخراج أو تثبيت دليل داخل ملف.** تثبيت سوف استبدال تطبيق ملف، جديد عملية أيضا ممكن في طرفية انتهاء بعد متابعة تشغيل. دليل دليل إبقاء في تثبيت دليل شجرة خارج.

**حفظ مهمة معنى سجل و مقابل معروف سري سري انفصال حساس.** لم معرفة إقرار إثبات قيمة و خاص مسار لا يمكن نفاد كل قطعة رفع. حقل أبيض اسم مفرد إبقاء دقيق عقدة مقارنة قليل، لكن ترتيب حذف هذه نص.

## نتيجة

سجل استلام تجميع فقط قراءة مرة عبر تحقق بايت، و من هذه بايت توليد حفظ ملف و داخل مسار نصب تقرير إبلاغ. قسم آخر لـ كل إخراج إعادة قراءة تغير في مصدر ملف، ممكن تقرير إبلاغ حفظ سجل في لا وجود مراقبة قياس. كل مرة استلام تجميع استخدام جديد دليل و سجل ملف ها أمل؛ قديم استلام تجميع و مصدر سجل ثابت. في بايت دخول استلام تجميع دليل قبل، ملف قراءة جهاز أيضا فحص ثابت تشخيص قيمة، بينما غير فقط اعتماد كتابة جهاز. إدخال بلا فاعلية وقت رفض استلام تجميع؛ تخزين فشل إبقاء جزء دليل، لا إعلان تسمية إتمام. كامل داخل مسار نصب تسلسل ما زال سوف شخص عمل تحقق استلام إبقاء لـ انتظار تأكيد.

سجل و رئيسي مدخل اختبار تغطية حفظ دائم، إعادة محاولة علامة، مختلف إصدار مستقل ملف، خاص حقل حذف و تخزين غير ممكن استخدام. قد تثبيت تطبيق إعادة بدء، تثبيت إتمام، بيانات إبقاء و شبكة لذا عائق حقن ما زال يحتاج شخص عمل تحقق استلام. سجل لن تلقائي حذف؛ عملية من مسؤول إبقاء سجل، و يجب رفض دليل ناقص أو لا كامل نتيجة. سجل لن صاف حذف توقيع قفل تحديد أو تخويل تثبيت.
