# Agent Note: CI fixture إتمام و عزل

Status: implemented

[English](2026-09-08-ci-completion-observations.md) | العربية

## مشكلة

مشاركة اعتبار CI تشغيل (run 34206953049) تقرير إبلاغ: جولة استفسار واحد ثانية بعد webhook إنشاء Session ما زال لا وجود، خمسة ثانية قراءة مدة حد داخل PowerShell إخراج لـ فارغ.HTTP قبول،UI إسقاط حالة، عملية بدء و حفظ دائم إتمام هو مختلف مراقبة. اختبار حاجة واضح إتمام شرط، و استخدام مقابل وفق منع توقف في بين حالة ممتلئ كاف هذا شرط.[إتمام انتظار قرار](2026-09-08-ci-readiness-and-completion.ar.md) يملك هذه شرط و lane ميزانية؛ هذه fixture عبر تلقي تحكم تأخير متأخر جعل ترتيب و تنظيف يمكن مراقبة.

## قرار

[GitHub مراجعة متصفح اختبار](../../../../apps/web/tests/github-ready-review.e2e.ts) في HTTP 202 بعد منع سد حقيقي Workspace إنشاء، تحقق Agent و نموذج طلب متساو لا وجود، مجددا تحرير إنشاء و انتظار مقابل Session `turn/end`. أي جعل اختبار مهلة، تنظيف أيضا سوف تحرير شاشة عائق، استعادة طريقة و إزالة حدث مستمع.Workspace ملكية، طلب عدد كمية، نص التوجيه محتوى و متصفح مسبق مدة إبقاء أصل لديه تأكيد.

[PowerShell منفذ اختبار](../../../../packages/shell/pwsh-local/tests/executor.spec.ts) استخدام خاص ملف شاشة عائق تحكم بدء و إزالة استهلاك صيغة قراءة. اختبار قرار لاحق إخراج أي وقت متاح؛ نهائي stdin/بيئة متغير إخراج في `done` بعد قراءة. جولة استفسار استخدام حالي اختبار ميزانية، كل إنشاء Context كل في إضافة ابتدائي تحويل قبل تسجيل تسجيل. تنظيف في انتظار تحرير قبل معا أخذ نيل Context و دليل، إتمام تحرير بعد عندئذ حذف دليل.

[ترتيب طابور صورة اختبار](../../../../apps/web/tests/queue-image.e2e.ts) قسم آخر منع سد وصل قبول و مرفق عنصر قراءة، مجددا التقاط قد وصل قبول سطر في تحميل إتمام تقليص اختصار رسم. تنظيف مشترك واحد Promise، تحرير إبقاء طلب، و في إغلاق متصفح قبل انتظار ذلك handler إتمام.

[تفصيل حال Session دورة الحياة اختبار](../../../../apps/web/tests/details-session-lifecycle.e2e.ts) في إغلاق حالة ظهور بعد انتظار إطار هيكل قد التقاط حركة رسم Promise، مجددا فحص مسار طريق عرض درجة لـ صفر. إلغاء مرور عبور نفس مثال دخول هذا تأكيد؛ حركة رسم انتهاء لا يستطيع يجعل حمل متابعة غير صفر مسار طريق عبر.

[كامل طابور صف steering اختبار](../../../../apps/web/tests/steering.e2e.ts) انتظار steering عملية متاح و composer عرض طابور صف steering تلميح. نموذج تدفق شاشة عائق في اختبار مراقبة steering وقت منع توقف لاحق مشكلة composer وصل إدارة. تنظيف في إغلاق متصفح قبل تحرير هذا شاشة عائق.

[Workspace إدارة اختبار](../../../../apps/web/tests/workspace-management.e2e.ts) في تحت مرة دليل محادثة إطار عملية قبل انتظار استعادة بعد composer تركيز نقطة. عودة ملف حالة استخدام عبر Session controller لـ معروف seed id ضبط صريح مستخدم عنوان، مجددا استخدام هذا دقيق عنوان عبر إعادة تحميل تحديد موضع سطر. غير متصل استعادة سطر لا يمكن مطابقة هذا تحديد موضع جهاز؛ حفظ دائم عودة ملف تأكيد ما زال فحص seed id و إبقاء سجل.

[Node وقت التشغيل اختبار](../../../../packages/ptc-runtime/ptc-runtime-node/tests/runtime.spec.ts) تنفيذ حقيقي تلقي إدارة عملية، ربط نقل، مرور مرور وقت قطع توقف و إلغاء.[صندوق رملي Node قرار](../architecture/2026-09-11-sandboxed-node-ptc-runtime.ar.md) يحل محل worker ELU ميزانية و ذلك تلقي تحكم مثال هذا اختبار؛ حقيقي عملية و نقل دليل ما زال لا بد يلزم.

[قسم مغادرة بدء اختبار](../../../../packages/host/open-in-app/tests/launch-detached.spec.ts) تحكم مراقبة وقت، و عبر حقيقي launcher تسجيل تسجيل عودة ضبط إرسال متأخر إلى عملية حدث. اختبار فحص فقط إتمام مرة، فقط unref مرة كما لا إنهاء عملية فرعية.[Resolver اختبار](../../../../packages/host/open-in-app/tests/resolver.spec.ts) إبقاء حقيقي عملية بيئة متغير و رفع قبل خروج حالة استخدام.

[LSP خلف ضغط اختبار](../../../../packages/lsp/lsp-stdio/tests/instance.spec.ts) إبقاء حقيقي مؤقت توقف قراءة fixture و كبير نوع أصلي إدارة طريق كتابة. قبول abort خطأ قبل، اختبار تحقق انتظار معالجة كتابة عودة ضبط اكتمل، التقاط عملية فرعية أيضا قد انتهاء؛`instance.dead` في تحرير بدء وقت حينئذ ممكن لـ حق.

### قد بناء Client استيراد تصنيف

[Node import sweep](../../../../packages/experimental/webworker-runtime/tests/compile/transform-corpus-check.ts) فقط لديه في Node إبرة مقابل بعض عدد `.css` ملف تقرير إبلاغ `ERR_UNKNOWN_FILE_EXTENSION` وقت عندئذ قبول Dockkit bundle، أخرى كل خطأ و كل معنى خارج نجاح إعفاء تجنب استيراد كل سوف فشل؛ هذا إعفاء تجنب تغطية أي بعض مثال صيغة جدول من[مثال صيغة جدول إعفاء تجنب قرار](../bug-fix/2026-09-10-built-bundle-css-exemption.ar.md) يملك. حد تحديد نطاق resolve/load hook تغطية مسبق مدة CSS فشل، أخرى مثال صيغة جدول، أخرى توسيع اسم، مهمة معنى فشل، أخرى رمز خطأ و قديم قديم إعفاء تجنب، لا تعديل مشترك بناء ناتج.

## اعتبار مرور بديل خطة

**إنتاج مهلة، إعادة محاولة أو طقم عنصر سلسلة سطر تحويل.** رفض، لأن متساو لا يستطيع بناء قيام نقص قليل إتمام مراقبة.

**من قبول أو معاينة دفع قطع إتمام.** HTTP 202 و مرح مراقبة صورة ممكن مبكر في يتم تأكيد عملية.

**استخدام تلقي تحكم مثال هذا بديل بديل حقيقي تنفيذ.** لا قبول، لأن فقط اعتماد تحديد وقت جهاز مثال هذا لا يمكن تحقق عملية بدء، تحكم نقل أو تلقي إدارة تنظيف.

## أثر

كل fixture يملك ذاتي ذات وقت ساعة، شاشة عائق، عودة ضبط، عملية و مؤقت مسار. تلقي تحكم مراقبة تكملة ملء حقيقي worker، عملية فرعية، متصفح و حفظ دائم مسار. منتج سلوك، إنتاج وقت ترتيب، أساس دقيق ميزانية،CI ضبط درجة و تسجيل صنع مسبق مدة متساو إبقاء ثابت.
