# Agent Note: Web متصفح مسبق مدة إخراج مطلوب CI بوابة

Status: implemented

[English](2026-07-30-web-browser-snapshot-ci-gate.md) | العربية

## مشكلة

[بلا مفتاح Web متصفح e2e عربة طريق](2026-07-24-web-gui-browser-e2e-lane.zh.md) فقط من محلي `pnpm run test:web` تشغيل،PR CI لا مقارنة مقارنة `snapshots/web/` أو `apps/web/tests/expected/` تحت Web مسبق مدة إخراج. لذلك، تغيير مستخدم مرئي Web إخراج PR يمكن في تسرب تحديث مسبق مدة إخراج وقت إبقاء أخضر لون؛ بعد قدوم مهمة معنى فرع صريح تشغيل `DSH_SNAPSHOT=refresh`، كل سوف بديل قبل ترتيب تغيير تكملة حساب و إنتاج و هذا فرع غير متصل diff. عادي محلي تشغيل قد افتراضي استخدام فقط قراءة replay، نقص فتحة هو PR درجة قوي صنع تنفيذ، بينما لا هو منع توقف refresh كتابة.

## قرار

Linux PR `node 24 / snapshots and artifacts` يجب تشغيل كامل Web متصفح replay/compare. إعداد `DSH_WEB_SNAPSHOT_WORKERS` بعد،`scripts/run-gates.ts` يأخذ `test:web:ci` تسجيل تسجيل لـ `ci-consumers` بوابة، و صريح حقن `DSH_SNAPSHOT=replay`؛CI دائم لا بـ `record` أو `refresh` نمط تشغيل، لذلك إيداع مسبق مدة إخراج و حالي تجميع تطبيق لا متسق وقت اختبار مباشر فشل، لن في runner داخل ساكن صامت تعديل كتابة بعد عبر.

مستهلك job في[مستهلك مستقل بناء](../../archived/process/2026-07-30-independent-ci-consumer-build.md) في مسؤول وحيد مرة Linux بناء، لذلك `apps/web/dist` و حزمة `lib/` دليل سوف إبقاء في ذلك مساحة العمل في، توفير متصفح طقم عنصر استخدام. في حمل إدارة تشغيل جهاز فوق،CI حسب قفل ملف في Playwright إصدار تثبيت Chromium و ذلك نظام اعتماد. في حفظ دائم لذا عائق تبديل VM فوق، مرآة مثل مسؤول مسبق تركيب Linux نظام لين عنصر حزمة،CI فقط تثبيت Chromium، تجنب تجنب كل مرة تشغيل كل عبر `apt` تعديل نظام.PR استعادة بـ عملية نظام و قفل ملف لـ مفتاح متصفح ذاكرة مؤقتة، جعل مطلوب مسار بلا حاجة تحمل تحمل ضغط و فوق نقل فتح إلغاء، و يمكن في قفل ملف تغير وقت حسب عملية نظام بادئة رجوع. لا يوجد أي master عمل عمل توليد هذه hosted ذاكرة مؤقتة، لذلك استعادة فقط قدرة أمر في ما زال لديه عودة ملف قديم بند، مباشر حتى ذلك يتم تدريجي خروج. ذاتي حمل إدارة حار تجهيز تشغيل نفسه مقارنة مقارنة، لكن لا تنفيذ حمل إدارة ذاكرة مؤقتة عملية.

محلي `pnpm run test:web` ما زال أولا بناء، مجددا سلسلة سطر تشغيل كامل متصفح طقم عنصر؛`test:web:built` هو قد لديه بناء ناتج سلسلة سطر تنفيذ مدخل. تطوير من فقط في تأكيد مستخدم مرئي إخراج متعمد تغير بعد صريح تشغيل `DSH_SNAPSHOT=refresh pnpm run test:web`، مراجعة كل واحد موضع مسبق مدة إخراج diff، مجددا بـ replay نمط تكرار تحقق لم يعد كتابة ملف.

CI `scripts/run-web-snapshots.ts` مفرد وحيد تشغيل سوف تعديل بناء ناتج `hmr-live.e2e.ts`. مع بعد من واحد ستة worker Vitest حوض تشغيل ذلك بقية ملف، يشمل تاريخ Cordis بطاقة تصيير. كل عملية فرعية وراثة stdio، من `run-gates` تدفق صيغة تحويل إرسال إخراج.

مقابل PR بينما قول، بوابة فقط في Linux مستهلك job في تشغيل: هذه مشهد موجه إلى POSIX، أخرى PR job لا تثبيت Chromium. ذاتي حمل إدارة افتراضي فرع Linux سلسلة سطر حار تجهيز أيضا يتضمن هذا مقارنة مقارنة، بينما macOS و Windows سلسلة سطر job ما زال لا استخدام متصفح (لا وجود حمل إدارة Linux سلسلة سطر تجمع دمج).PR `all checks passed` قد اعتماد مستهلك job، لذلك متصفح مقارنة مقارنة فشل سوف منع توقف دمج، بلا حاجة إضافة جديدة branch-protection check اسم.

كامل محلي replay في،6-worker متصفح أمر استهلاك وقت نحو 65–71 ثانية.12-worker مقابل مقارنة نحو لـ 50 ثانية، لذلك يأخذ متصفح worker ميزانية نقص نصف فقط زيادة نحو 15–20 ثانية، بينما لا هو يجعل جدار ساعة وقت قلب ضعف. بوابة مجدول سوف في `built-package-invariants` نجاح بعد قيام أي بدء متصفح لقطة، تزامن تشغيل ذاك هذا مستقل بوابة، لذلك حيث لا حاجة مخصص استخدام job مهلة، أيضا لا حاجة يد حركة صنع تحديد YAML ترتيب قاعدة.

## سبق اعتبار بديل خطة

**متابعة فقط اشتراط محلي تشغيل.** قد مرفوض: تنفيذ اعتماد تطوير من تسجيل ذاكرة، صحيح هو قديم قديم golden عبر PR عائم نقل سبب، لا يستطيع حفظ إثبات إنتاج سلوك تغير PR ذاتي ذات يحمل مسبق مدة إخراج diff.

**يجعل CI بـ `refresh` نمط تشغيل بعد فحص عمل شجرة.** قد مرفوض: كتابة بعد مقارنة مقارنة يأخذ تأكيد آلية تغيير صار توليد جهاز، إذا عمل شجرة فحص وصل دخول لديه خطأ، حينئذ ممكن يأخذ ارتداد تغيير صار قدرة كاف عبر مسبق مدة إخراج تحديث؛replay مباشر مقارنة مقارنة قد لديه golden، فشل وجه أكثر صغير.

**جديد بناء مستقل browser job و إعادة بناء كل مستودع.** قد مرفوض: هو سوف تكرار اعتماد تثبيت و إصدار بناء. قائم Linux مستهلك job قد مسؤول هذا بناء، و قد يتم موحد واحد required verdict تجمع دمج.

**في و سطر حوض في تشغيل HMR.** رفض، لأن هو سوف تعديل مشترك بناء ناتج. أخرى متصفح fixture يملك عزل حالة، مشترك استخدام واحد محدود حوض.

**استخدام jsdom لقطة بديل بديل حقيقي Chromium.** قد مرفوض:jsdom لا تغطية متصفح،HTTP/SSE تحمل تحميل و حقيقي عميل إضافة حزمة تركيب؛ هو ما زال متاح في سريع سرعة تحت طبقة عكس تغذية، لكن لا يستطيع بديل تجميع بعد متصفح سلسلة مسار.

## عاقبة

كل PR كل في دمج قبل إثبات حالي Web تجميع و كل قد إيداع متصفح مسبق مدة إخراج متسق؛ تسرب تحديث سوف في تغيير هذا تجميع نفس عدد PR في فشل. صار هذا هو مستهلك job حاجة تثبيت Chromium، سلسلة سطر تشغيل 2 عدد مشهد و تنفيذ 1 عدد محدود 6-worker حوض؛ مستهلك مستقل بناء و متصفح ذاكرة مؤقتة تجنب تجنب إعادة ركض وقت تكرار بناء و تحت تحميل. و سطر ملف فشل سوف قيام أي تدفق صيغة عرض، لكن worker ميزانية أي تغير ما زال حاجة كامل طرف إلى طرف قياس كمية، بينما لا يستطيع اعتماد حسب تشغيل في استهلاك وقت تخمين قياس. بوابة لا صوت تسمية عبر منصة متصفح متسق صفة،Playwright/Chromium ترقية إذا تغيير ARIA صيغة، ترقية PR يجب صريح refresh و مراجعة churn.
