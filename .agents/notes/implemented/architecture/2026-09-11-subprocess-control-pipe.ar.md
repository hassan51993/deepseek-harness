# Agent Note: Subprocess control pipe

Status: implemented

[English](2026-09-11-subprocess-control-pipe.md) | العربية

## مشكلة

تلقي إدارة Node برنامج يمكن نحو stdout و stderr كتابة مهمة معنى بايت. إذا مضيف بروتوكول مشترك استخدام منها مهمة واحد تدفق، حينئذ لا يمكن في لا حد عادي Node سلوك قبل رفع تحت منطقة قسم بروتوكول بايت و برنامج تشخيص.Windows عملية حزمة تركيب جهاز أيضا اشتراط في فرعي وقت التشغيل قسم إعداد ذاته وصف رمز قبل صريح ضبط وصف رمز وراثة.

## قرار

عادي subprocess طلب يمكن ضبط `stdio.control: 'pipe'`، و عبر `handle.control` استلام إلى أصلي `Duplex`. هدف عبر `@deepseek-ai/dsh-subprocess/control` فتح fd 7. مزود يملك بيئة علامة؛ عملية فرعية مساعد مساعدة دالة سوف إزالة استهلاك هو. مستهلك مسؤول محدود قسم لقطة، رسالة تحقق، خلف ضغط و طرف نقطة إغلاق. معيار إخراج استلام تجميع و تلقي إدارة نطاق دورة الحياة إبقاء قائم دلالة. مزود مستقل تتبع أثر فتح تحكم طرف نقطة، مباشر إلى هو جمع إغلاق، يشمل تلقي إدارة نطاق خروج بعد؛ إلغاء تدمير وقت أولا محاولة تجربة تلقي إدارة نطاق تفكيك إزالة، مجددا إغلاق باق بقية طرف نقطة.

POSIX بدء جهاز في exec وقت إبقاء fd 7.Windows عادي Job و تلقي حد أمر لوحة بدء جهاز يأخذ إدارة طريق وضع دخول CRT بدء وصف رمز جدول مجرى 7، إبقاء معيار جملة مقبض، و يجعل سالب تحميل في مجرى 3–6 إبقاء إغلاق. كل طبقة حزمة تركيب جهاز في تحويل نقل كل حق بعد إغلاق ذاته تحمل تحميل طرف. جملة مقبض وراثة فقط في عملية إنشاء خلال تفعيل. هذا عبر طريق لا منح إعطاء أي مضيف قدرة: عملية فرعية ما زال غير ممكن معلومة، كل مرة مضيف أداة طلب كل حاجة عبر معتاد توزيع و مراجعة دفعة فحص.

تحكم إدارة طريق استخدام Node `overlapped` stdio موضع وضع طريقة: هو في POSIX فوق انتظار نفس في `pipe`، في Windows فوق إنشاء حمل لديه `FILE_FLAG_OVERLAPPED` جملة مقبض. لذلك قراءة كتابة يمكن مستقل إجراء، يشمل عملية فرعية في مضيف إرسال أي محتوى قبل إرسال خروج رقم واحد بند رسالة.

Windows تلقي إدارة نطاق إثبات مستقل مراقبة runner عملية خروج و ذلك خاص IPC نتيجة، لا اعتماد استدعاء جهة ترتيب فارغ تدفق. استلام إلى نتيجة كما runner صحيح معتاد خروج يكفي تأكيد نطاق انتهاء؛ صحيح معتاد خروج لكن لم استلام إلى نتيجة وقت، الأكثر كثير انتظار إلى IPC عبر طريق إغلاق. مؤقت توقف تحكم إخراج لن تأخير متأخر هذا إثبات، أيضا لن منع توقف مزود إلغاء تدمير وقت إغلاق طرف نقطة.

نظام الملفات و subprocess خدمة ما زال يمكن من بعيد مسار مزود صار مقابل استبدال. عام مشترك جملة مقبض و طلب متساو لا عام مضيف مسار، عملية معرف، تنفيذ عالم حد علامة سجل أو نقل تنسيق تجارة دليل. طرفية قسم إعداد إبقاء مختلف خطوة، كما لا زيادة مقدار خارج وصف رمز.

## اعتبار مرور بديل خطة

**Stdout قسم لقطة.** أصلي شفرة و عادي `process.stdout.write` يمكن إخراج مهمة معنى بايت، لذلك بروتوكول كامل صفة سوف اعتماد في اعتراض قطع برنامج إخراج.

**تزامن Windows إدارة طريق.** وراثة تزامن إدارة طريق فوق منع سد قراءة ممكن منع توقف نفس جملة مقبض فوق تزامن كتابة متابعة تنفيذ. مضيف أولا إرسال عودة إظهار لا يمكن كشف هذا ميت قفل؛ عملية فرعية أولا تقرير إبلاغ حينئذ خيط و تفكيك إزالة كل حاجة إعادة تراكم I/O جملة مقبض.

**Node IPC.** Windows عملية مراقبة إشراف جهاز قد استخدام خاص IPC عبر طريق. يأخذ سالب تحميل طلب اقتران دمج إلى هذا إدارة بروتوكول سوف كشف مراقبة إشراف جهاز عملية، و جعل بعيد مسار نقل تكرار مختلط تحويل.

**في Windows بدء بعد استبدال وصف رمز.** Node بدء بعد استبدال fd 7 ممكن تغطية داخلي وصف رمز.CRT بدء جدول في وقت التشغيل ابتدائي تحويل قبل إبقاء هو، و إبقاء كل مضيف عملية فرعية API متسق.

**كل منصة استخدام مختلف وصف رمز.** مختلف منصة تحرير رقم سوف زيادة جذب توجيه فرع، لكن لا يستطيع حذف ذهاب أصلي بدء عمل. ثابت مجرى موضع أيضا يجعل بعيد مسار مزود يمكن إبقاء نفسه عملية فرعية API.

## عاقبة

أصلي حزمة تركيب جهاز يجب صريح إبقاء و إغلاق واحد بند مقدار خارج إدارة طريق.subprocess خدمة لا حل تفسير تحكم رسالة، أيضا لا بديل استدعاء جهة مؤقت اندفاع رسالة، لذلك بروتوكول مستهلك يجب ذاتي سطر حد إبقاء إدخال و إخراج. عملية نظام صندوق رملي و تلقي إدارة عملية يملك من ما زال مسؤول حد و تفكيك إزالة؛ مستقل نقل لا هو JavaScript أمان حد.
