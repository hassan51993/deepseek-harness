# Agent Note: جلسة إسقاط بصفة مطلوب قراءة seam

Status: implemented

[English](2026-08-19-session-projection-mandatory-seam.md) | العربية

## مشكلة

اختياري إسقاط سجل التسجيل سوف يجعل host سلوك قراءة إسقاط حالة إضافة في نقص قليل هذا حالة وقت ما زال تنشيط. حذف غير قراءة جهة رفض ناقص سجل التسجيل أو key، لا فإن host سلوك أو subagent دليل حقل ممكن ساكن صامت إزالة فقد. فقط لديه دفعة كمية قراءة أيضا سوف في مستهلك فقط حاجة واحد host قيمة وقت شيء تحويل كل عميل view. جزء مساهمة موضع متعمد إبقاء اختياري `ctx.inject` تسجيل شكل صيغة، لذلك ذلك قراءة جهة حاجة واضح ناقص حالة قاعدة.

## قرار

هذا قرار بناء قيام في[جلسة إسقاط host حالة و عميل عرض](../../archived/architecture/2026-08-19-session-projection-state-and-client-views.md) الذي تعريف تفكيك قسم لـ فوق.

كل host قراءة جهة كل يأخذ إسقاط سجل التسجيل و ذلك الذي يحتاج key نظر لـ مطلوب حالة. إضافة يلزم ما يأخذ `sessionProjections` إعلان لـ مطلوب حقن، يلزم ما صريح تحليل سجل التسجيل و key، و في رقم مرة اعتماد هو جمع وصول وقت رمي خطأ. صحيح صيغة تركيب في هذه إضافة قبل تركيب سجل التسجيل.`ApiProxyService` اعتماد مطلوب حقن شكل صيغة؛ مقارنة منخفض طبقة `createApiProxy` factory مقابل عزل اختبار و تشخيص إبقاء سعة خطأ.

مجال مساهمة جهة يمكن عبر `ctx.inject(['sessionProjections'], ...)` تسجيل وحدة. اختياري تسجيل فقط تحكم فرعي وظيفة دورة الحياة؛ هو و لا سماح قراءة جهة في سجل التسجيل أو key ناقص وقت استبدال لـ قيمة افتراضية.

سجل التسجيل توفير `stateOf(session, key)` قدوم قراءة واحد نوع تحويل host حالة، و لـ دفعة كمية carrier إبقاء `snapshot()`. عميل view فقط يتضمن مستهلك استخدام حقل؛host قراءة جهة عبر `stateOf` أخذ نيل أكثر وفير غني حالة.

`onChanged` فقط إصدار عميل مرئي قيمة تغير. وحدة تسجيل و إزالة ما زال هو ربط effect سجل التسجيل دورة الحياة؛`register()` إرجاع Cordis أصلي disposer، جعل تركيب صيغة مجال owner يمكن أولا اعتماد حسب إسقاط حالة إتمام تنظيف، مجددا إزالة ذاته وحدة. تسجيل تغير لن إنشاء ثاني بند Host حدث تدفق أو عميل tombstone بروتوكول. لاحق مرجعي history أو list أساس خط سوف عكس عكس نشط وثب key تجميع.

## اعتبار مرور بديل خطة

- **لـ ناقص إسقاط حالة توفير قيمة افتراضية.** هذا سوف إبقاء أكثر كثير لا كامل تركيب، لكن ناقص host حالة سوف لا يمكن و دمج قاعدة فارغ قيمة منطقة قسم. صحيح صيغة profile قد تركيب سجل التسجيل، إعداد خطأ يجب صريح فشل، لذلك مرفوض.
- **اشتراط كل مساهمة جهة كل في تنشيط وقت قوي اعتماد.** هذا سوف موحد واحد key تجميع، لكن سوف يجعل مساهمة دورة الحياة و خدمة تنشيط إنتاج لا لا بد يلزم اقتران دمج. أول مرة وصول وقت صريح فشل حيث قدرة إبقاء اختياري تسجيل شكل صيغة، أيضا لن سماح ساكن صامت تخفيض.
- **كل مرة قراءة كل استخدام `snapshot()`.** هذا فقط إبقاء واحد طريقة، لكن سوف حساب حساب غير متصل wire view، و حث تشجيع مستهلك يجعل host منطق اعتماد دفعة كمية نقل بيانات. تعديل استخدام نوع تحويل مفرد key حالة قراءة.
- **نحو عميل إرسال كامل host قيمة.** هذا تجنب تجنب مفرد وحيد view نوع، لكن سوف كشف عميل لا إزالة استهلاك مصدر معلومة و سياسة دوران زر. تعديل استخدام صريح قطع قص view.
- **عبر Host و mux stream واسع بث سجل التسجيل إضافة جديدة و إزالة.** اثنان بند stream لا يوجد مشترك ترتيب، عميل لذلك حاجة tombstone، مؤقت اندفاع لقطة و أساس خط إعادة محاولة قدوم تنسيق ضبط. إضافة key تغير لا قيمة نيل جذب دخول ثاني طقم تزامن بروتوكول.

## عاقبة

- نقص قليل إسقاط تركيب سوف في تنشيط خلال أو رقم مرة اعتماد هو host وصول وقت فشل، أبدا سوف تخفيض لـ قيمة افتراضية.
- host مستهلك تجنب تجنب تكرار كل سجل التسجيل لقطة و سجل مسح.
- بروتوكول سالب تحميل ترتيب حذف host داخلي حقل و تدريجي key ماء موضع حزمة تركيب؛ عادي أساس خط سوف نقل بلوغ نشط وثب key تجميع.
