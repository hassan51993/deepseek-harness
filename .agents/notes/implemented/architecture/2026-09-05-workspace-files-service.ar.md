# Agent Note: مساحة العمل ملف خدمة

Status: implemented

[English](2026-09-05-workspace-files-service.md) | العربية

## Problem

Web عميل حاجة من واحد لم لا بد في Host آلة جهاز فوق متصفح عرض جلسة مساحة العمل داخل ملف:agent إنتاج خروج ملف،`read` أداة سطر نقطة اسم مسار، بعد أيضا لديه ملف شجرة، و حيث لا صغير أيضا لا هو نص ملف معاينة. وحيد واحد مرور خط مسار قراءة مساحة العمل ملف طرف نقطة بـ `workspace-file.ts` إقامة في Session Controller فوق، و هو جزء غير متصل نظام جلسة دورة الحياة لـ مجاور. هو في واحد مجموع بايت حد أعلى لـ تحت إرجاع كامل ملف، لذلك كبير سجل وصل واحد جزء كل نظر لا، اثنان دخول صنع أصل هذا نظر لا؛ هو لا يوجد `stat`، لا يوجد صف رفع، لا يوجد تغيير إشارة، معاينة لا إعادة قراءة حينئذ لا يمكن نيل معرفة agent قد تعديل كتابة ملف؛ ذلك نتيجة أيضا بـ Host `url` تسمية ملف، بينما Client فوق لا يوجد أي شرق غرب يأخذ هذا نوع تجميع قاعدة عند عنوان استخدام.

اثنان عدد قيد إطار تحديد هذا بند خدمة. مرور `ctx.fs` ملف قراءة استخدام Session تركيب بعد نظام الملفات خلفية، ذلك قراءة إذن ممكن تأخير امتداد إلى مساحة العمل خارج، بينما دليل شجرة و تغيير تدفق مستهلك بـ مساحة العمل لـ أصل. خدمة لـ عادي ملف إبقاء خلفية قراءة قرار، معا تنفيذ ملف نوع و محدود مؤقت اندفاع فحص؛`list` و `changes` إبقاء مساحة العمل يتضمن حد. آخر خارج `dsh-fs` فقط كشف واحد نوع أصلي بايت قراءة `readBytes(target, signal, maxBytes)`، هو رفض أي مقارنة حد أعلى أكثر طويل ملف: مقابل نموذج كامل جسم التقاط دخول صورة هو صحيح تأكيد، مقابل كبير ملف واحد نافذة فإن جزء بلا استخدام موضع.

## Decision

`packages/api/workspace-files`(`@deepseek-ai/dsh-api-workspace-files`) معا يملك Host خدمة `ctx.workspaceFiles`،`workspaceFiles` Remote نطاق الأسماء، و سوف `stat` و `changes` تحويل صار[مورد نموذج](2026-09-05-client-resource-model.ar.md) فوري بيانات وصفية Client `file` توفير من؛ حزمة مجموعة نسج طريقة من[مزدوج وجه حزمة مجموعة نسج](2026-09-07-workspace-files-dual-face-package.ar.md) قاعدة تحديد. ملف طريقة من مساحة العمل أصل تحليل متبادل مقابل مسار، لكن وراثة Session نظام الملفات خلفية قراءة إذن؛`list` و `changes` ما زال حد في مساحة العمل.[مساحة العمل ملف قراءة إذن](2026-09-09-workspace-file-read-authority.ar.md) يملك هذا واحد قسم طبقة و ذلك أمان عاقبة. نتيجة بـ ملف في نظام الملفات تنفيذ بيئة في قطعا مقابل مسار تسمية ملف، محتوى فإن تلقي صفحة، بايت نافذة أو كامل ملف حد أعلى قيد. بايت نافذة اعتماد حمل `dsh-fs` إضافة جديدة seam `FileSystem.readByteRange`، من كل توفير من تنفيذ.Session Controller لم يعد يحمل أي مساحة العمل ملف شفرة.

### حزمة توسيع اندفاع

[مزدوج وجه حزمة مجموعة نسج](2026-09-07-workspace-files-dual-face-package.ar.md) يحل محل هذا سجل في يأخذ Host و Client قسم صار اثنان عدد حزمة مجموعة نسج اختيار؛ هذا داخل ملف خدمة، قسم صفحة و تغيير تدفق اتفاق إبقاء ثابت.[مساحة العمل ملف قراءة إذن](2026-09-09-workspace-file-read-authority.ar.md) يحل محل ملف طريقة أصل لديه مساحة العمل يتضمن اختيار.Host و Client قسم آخر تحرير ترجمة في اثنان عدد ورقة إعداد في، مشترك خط مسار نوع،Client لا استيراد Host وقت التشغيل مدخل.

| وجه | حزمة | ملف | اعتماد |
|---|---|---|---|
| Host | `api/workspace-files/tsconfig.host.json` | `src/index.ts`(`WorkspaceFiles`،`Config`، محيط شريط، قطع صفحة جهاز) ،`src/changes.ts`(`WorkspaceChangeFeed`) ،`src/types.ts`(خط مسار نوع، رمز خطأ) | `dsh-fs`،`dsh-sandbox-policy`،`dsh-typert-protocol`،`dsh-session`،`dsh-session-persistence` |
| Client | `api/workspace-files/tsconfig.client.json` | `src/client/index.ts`(إضافة جسم) ،`provider.ts`،`change-feed.ts`،`remote.ts`،`types.ts`، و مشترك `src/types.ts` | `dsh-api-gateway/client`،`dsh-session/types`،`dsh-client-resources`،`dsh-client-ui-slots`،`dsh-util-workspace-path`،`dsh-typert-protocol`، و هذه الحزمة توليد `./remote` |

`api/remotes` و اثنان عدد أصل تجمع دمج قسم آخر مرجع مطابقة Host/Client ورقة فرعي. حزمة تصدير `.`،`./client`،`./types`،`./typert` و `./remote`،web-app في مفرد عدد `workspace-files` بند توفير ينبغي اثنان وجه.Client إضافة حقن `['resources', 'remote', 'remote.workspaceFiles']`؛ مورد نموذج مباشر من بروتوكول حزمة أخذ نتيجة نوع،Sidebar معامل إعلان عودة نص معاينة، لذلك Client تحرير ترجمة رسم لم يعد عكس نحو اعتماد Remote تركيب إعداد أو يمين شريط UI.

### `workspaceFiles` Remote نطاق الأسماء

كل Host طريقة أول مشاركة كل هو `WorkspaceFileScope`.Gateway من خط مسار فوق Session هوية تحليل هو: أولوية قراءة live Session header،cold Session فإن فقط استدعاء `SessionPersistence.stat`؛ لن تنشيط Agent، قراءة حدث متن أو رجوع إلى أب Session.scope يحمل الذي اختيار Session id و ذلك `cwd`، فقط عند هذا header لا يوجد `cwd` وقت عندئذ استخدام صندوق رملي سياسة نشر أصل.Client نقل دخول Session id، من لا ذاتي سطر تسمية أصل. سبعة عدد توقيع وفق `src/index.ts` إعلان:

```ts ignore-check
@Remote async read(workspaceFileScope: WorkspaceFileScope, path: string, range: WorkspaceFileRange, signal: AbortSignal): Promise<WorkspaceFileText>
@Remote async readBytes(workspaceFileScope: WorkspaceFileScope, path: string, range: WorkspaceByteRange, signal: AbortSignal): Promise<WorkspaceFileBytes>
@Remote async readAll(workspaceFileScope: WorkspaceFileScope, path: string, signal: AbortSignal): Promise<WorkspaceFileBytes>
@Remote async readRelated(workspaceFileScope: WorkspaceFileScope, path: string, relativePath: string, signal: AbortSignal): Promise<WorkspaceFileBytes>
@Remote async stat(workspaceFileScope: WorkspaceFileScope, path: string, signal: AbortSignal): Promise<WorkspaceFileStat>
@Remote async list(workspaceFileScope: WorkspaceFileScope, path: string, signal: AbortSignal): Promise<WorkspaceDirectoryListing>
@Remote({ mode: 'stream' }) changes(workspaceFileScope: WorkspaceFileScope, signal: AbortSignal): AsyncIterable<WorkspaceFileWatchFrame>
```

- **`stat`** إرجاع `WorkspaceFileStat { absolutePath, version, bytes? }`: ملف هوية، لا نفاذ واضح جديد طازج درجة أمر لوحة، و خلفية تقرير نيل خروج وقت كبير صغير. هو فقط قبول عادي ملف.
- **`read`** إرجاع واحد سطر نافذة `WorkspaceFileText = WorkspaceFileStat & { offset, text, lines, eof }`؛`lines` حساب صفحة داخل سطر عدد، جعل فقط يحتوي واحد فارغ سطر صفحة (`text: ''`،`lines: 1`) و تجاوز مرور ملف نهاية ذيل صفحة (`lines: 0`) يمكن منطقة قسم.`range.offset` هو 1 بدء حساب أول سطر، نقص حذف 1؛`range.limit` هو الأكثر كثير سطر عدد، نقص حذف `maxLines` كما لا نيل تجاوز مرور. سطر بـ `\n` انتهاء، نهاية ذيل `\n` إنهاء الأكثر بعد واحد سطر بينما لا هو فتح بدء واحد فارغ سطر؛`text` بـ `\n` اتصال هذا صفحة كل سطر كما لا حمل إنهاء رمز؛ صفحة يحتوي الأكثر بعد واحد سطر وقت `eof` لـ true، تجاوز مرور نهاية ذيل offset إرجاع `eof` لـ true فارغ صفحة. قطع صفحة جهاز امتداد `streamText` قبل دخول، عدد مرور نافذة قبل سطر بينما لا إبقاء، يأخذ كل نافذة داخل قطعة مقطع أولا حسب `maxBytes` نواة دقيق مجددا مؤقت اندفاع، و في تجاوز مرور نافذة رقم واحد محرف موضع إرجاع، لذلك مهمة معنى كبير صغير ملف فقط زهرة واحد صفحة داخل تخزين. صفحة فوق `version` و `bytes` قدوم ذاتي تدفق قبل ذلك مرة stat.
- **`readBytes`** إرجاع واحد أصلي بايت نافذة `WorkspaceFileBytes = WorkspaceFileStat & { offset, data, eof }`.`range.offset` هو 0 بدء حساب أول بايت، نقص حذف 0؛`range.length` هو الأكثر كثير بايت عدد، نقص حذف `maxBytes` كما لا نيل تجاوز مرور.`data` لـ base64، ملف في نافذة داخل انتهاء فإن قصير في `length`، يقع في أو تجاوز مرور نهاية ذيل فإن لـ فارغ؛ نافذة يحتوي الأكثر بعد واحد بايت وقت `eof` لـ true. لا فعل أي حل رمز، أيضا لا حسب اثنان دخول صنع رفض.`read` حسب سطر قسم صفحة، أبدا حسب بايت؛ بايت نافذة مشي `readBytes`.
- **`readAll` و `readRelated`** في `maxFileBytes` حد أعلى داخل إرجاع كامل `WorkspaceFileBytes`.`readRelated` من أساس دقيق ملف الذي في دليل تحليل متبادل مقابل نظام الملفات مسار؛Host مقابل اثنان عدد ملف تنفيذ نفسه عادي ملف فحص و خلفية قراءة إذن.[Document Preview](2026-09-08-document-preview-operations.ar.md) مسؤول ذلك تحميل و عنوان دلالة.
- **`list`** إرجاع `WorkspaceDirectoryListing { path, entries, truncated }`: يتم صف دليل متبادل مقابل أصل مساحة العمل مسار (أصل لـ فارغ سلسلة) ، ذلك مباشر فرعي بند حسب خلفية مستقر اسم ترتيب بـ `{ name, type, size? }` إعطاء خروج، و `maxEntries` هل مقتطع قائمة.`type` لـ `file`،`directory` أو `other`؛ رمز رقم رابط فرعي بند تقرير إبلاغ ذلك إشارة نحو هدف نوع، معلق فارغ من لـ `other`، بينما فتح هذا مثال فرعي بند ما زال سوف في تحت نص رابط صلة يتم رفض.dotfile وفق معتاد صف خروج، لا فعل أي مرور ترشيح.
- **`changes`** إنتاج خروج `WorkspaceFileWatchFrame`: في مراقبة طابور صف تسجيل كما مساحة العمل أصل تحليل إتمام بعد أولا إرسال `{ kind: 'ready' }`، مع بعد لـ `{ kind: 'change', change }`. تحميل حمل `WorkspaceFileChange` مقابل وجود ملف لـ `{ absolutePath, version }`، مقابل إزالة فقد ملف لـ `{ absolutePath, absent: true }`. مصدر هو مساحة العمل أصل داخل `fs/observed`، لا مراقبة نظر عملية نظام. أول مرة سحب أخذ بعد مراقبة كل سوف ترتيب طابور، يشمل أصل تحليل خلال مراقبة؛ إلغاء أو إضافة تحرير سوف انتهاء هذا بديل تدفق.

### خط مسار فوق مسار

مغادرة فتح خدمة مسار مفردات لديه اثنان طقم، كل طريقة فقط استخدام منها واحد طقم.`read`،`readBytes`،`readAll`،`readRelated`،`stat` و `changes` بـ `absolutePath` تسمية ملف: هو في نظام الملفات تنفيذ بيئة في، رمز رقم رابط قد تحليل قطعا مقابل مسار (`ctx.fs.processPath(target)`) ، لذلك Client توفير من حسب قطعا مقابل مسار يأخذ تغيير لقطة مطابقة إلى قد فتح عنوان:Client يأخذ عنوان مسار أصل مثال تسليم إعطاء Host، و فقط حسب نجاح `stat.absolutePath` ربط تتبع مع من، لا قراءة جلسة ملخص cwd.`list` قول مساحة العمل مسار——و ذلك `path` معامل نفسه لغة قاعدة، قطعا مقابل أو متبادل مقابل أصل——لأن ذلك مستهلك هو واحد شجرة بـ أصل لـ بدء نقطة شجرة. هذا حقل نداء `absolutePath` بينما لا نداء `url`، لأن هو لا هو مورد عنوان؛ عنوان لغة قاعدة عودة `dsh-util-workspace-path` كل، و مورد نموذج واحد و وصف.`read`،`readBytes`،`readAll`،`readRelated`،`stat` و `list` إدخال مسار هو قطعا مقابل مسار أو متبادل مقابل جلسة مساحة العمل أصل مسار، من لا متبادل مقابل خلفية ذاتي ذات cwd.

`version` هو إزالة استهلاك من فقط مقارنة مقارنة هل متبادل انتظار، من لا تحليل لا نفاذ واضح نص: محلي خلفية من ضبط تجهيز،inode، كبير صغير و قبول ثانية درجة mtime و ctime تصدير، لذلك محتوى ثابت إعادة كتابة أيضا سوف تغيير هو.`offset` في `read` فوق إشارة سطر، في `readBytes` فوق إشارة بايت؛ اثنان طقم مفرد موضع من لا خلط استخدام، اثنان من `eof` كل يمثل نافذة وصول ملف نهاية ذيل.

### ملف فحص و مساحة العمل يتضمن

`read`،`readBytes`،`readAll`،`readRelated` و `stat` مشترك عادي ملف فحص، بعد اعتماد نظام الملفات خلفية قراءة إذن.`list` مشترك مسار فحص، لكن أيضا سوف فحص مساحة العمل يتضمن علاقة؛`changes` فإن يأخذ مراقبة مرور ترشيح إلى مساحة العمل أصل داخل. خدمة تنفيذ التالي فحص:

1. **مسار ذاته.** `lstat` في تتبع مع أي شرق غرب قبل فحص مسار: ناقص مسار لـ `not-found`؛ رمز رقم رابط——لا نقاش إشارة نحو أي داخل، يشمل إشارة عودة مساحة العمل داخل——مقابل ملف طريقة لـ `not-regular-file`(kind لـ `symlink`) ، مقابل `list` لـ `not-directory`. فارغ مسار هو `gateway/bad-request`.
2. **`list` مساحة العمل يتضمن.** دليل تحليل لـ هدف، من `ctx.fs.contains(root, target)` حكم تحديد، منها `root` هو من الذي اختيار Session header تحليل خروج `WorkspaceFileScope.workspaceRoot`.`..` زحف خروج أو أصل خارج قطعا مقابل دليل لـ `outside-workspace`.`changes` مقابل مراقبة إلى هدف استخدام نفسه خلفية يتضمن حكم تحديد.
3. **حد أعلى.** تجاوز مرور `maxBytes` صفحة أو نافذة، أو `read` بحث يلزم تجاوز مرور `maxLines` سطر عدد، واحد قاعدة رفض، أبدا قطع قصير، لأن صامت صامت قطع قصير صفحة قراءة بدء قدوم حينئذ مثل كامل صفحة؛ تجاوز مرور `maxEntries` قائمة يتم مقتطع و مثل فعلي تقرير إبلاغ. كل نص و صلة ربط ملف قراءة تجاوز مرور `maxFileBytes` وقت يتم رفض.
4. **نص.** فقط حد `read`: إلى صفحة نهاية لـ توقف لا هو UTF-8 محتوى، خلفية 8 KiB فتح رأس مثال هذا داخل NUL بايت، أو صفحة داخل أي موضع NUL بايت، كل هو `not-text`؛ صفحة بعد بايت لا فحص.

مسار فحص بعد، ملف طريقة مجددا مقابل تحليل خروج هدف `stat` مرة، لأن ملف ممكن في قراءة قبل قد إزالة فقد أو تبديل نوع صنف: إزالة فقد من لـ `not-found`، يتم استبدال من لـ حمل جديد نوع صنف `not-regular-file`. مقابل `list` بينما قول، أصل خارج بند إذا نوع ذاته قد لا دمج إطار، سوف أولا تقرير إبلاغ ذلك نوع صنف بينما لا هو موضع.

### فشل

كل نوع فشل كل هو واحد حمل نوع تحويل details `RemoteError` شفرة، إعلان في رمي خروج هو شفرة جانب، حسب شفرة بينما غير رسالة منطقة قسم.

| شفرة | أي وقت | Details |
|---|---|---|
| `workspace-file/not-found` | مسار موضع بلا بند، أو ملف في مرور صلة بعد إزالة فقد | `{ path }` |
| `workspace-file/outside-workspace` | `list` هدف لا في مساحة العمل أصل داخل | `{ path }` |
| `workspace-file/too-large` | واحد صفحة نص أو بايت نافذة تجاوز مرور `maxBytes`، أو كل نص قراءة تجاوز مرور `maxFileBytes` | `{ path, limit }` |
| `workspace-file/not-text` | إلى صفحة نهاية لـ توقف غير قاعدة UTF-8، أو مثال هذا أو صفحة داخل NUL بايت (فقط `read`) | `{ path }` |
| `workspace-file/not-regular-file` | مقابل غير عادي ملف تنفيذ `read`،`readBytes`،`readAll`،`readRelated` أو `stat` | `{ path, kind: 'directory' \| 'symlink' \| 'other' }` |
| `workspace-file/not-directory` | مقابل غير دليل تنفيذ `list` | `{ path, kind: 'file' \| 'symlink' \| 'other' }` |
| `workspace-file/unsupported-address` | Client صب خروج: هذا توفير من لا يمكن خدمة مورد عنوان | `{ address }` |
| `workspace-file/unknown-workspace` | Client صب خروج: لا يحمل Session `absolute` عنوان | `{ address }` |
| `gateway/bad-request` | فارغ مسار، أو لا هو نطاق داخل كامل عدد `offset`،`limit`،`length` | `{}` |

هذا عدد تجميع دمج فقط زيادة لا تعديل لا حذف: يمكن إضافة جديدة شفرة، لكن لا إعادة تسمية، لا إزالة أي واحد، لأن مستهلك عبر خط مسار حسب هذه نص فرع.

### إعداد

أربعة عدد حقل، كل هو يمكن في `cordis.yml` في تعديل، مرور تحقق صحيح كامل عدد، هذا خارج لا يوجد أخرى يمكن ضبط بند:`maxBytes`(افتراضي 2,097,152، أي 2 MiB) هو مفرد صفحة نص و مفرد عدد بايت نافذة يحتوي حد أعلى؛`maxLines`(افتراضي 5,000) هو صفحة نقص حذف و الأكثر كبير سطر عدد؛`maxEntries`(افتراضي 2,000) هو إرجاع دليل بند عدد حد أعلى؛`maxFileBytes`(افتراضي 33,554,432، أي 32 MiB) حد كل نص و صلة ربط ملف قراءة. قسم صفحة و فتح نافذة قراءة لا حد كامل ملف كبير صغير.

### `dsh-fs` في `readByteRange` seam

كبير ملف بايت نافذة حاجة واحد نوع بـ نافذة لـ حد نظام الملفات قراءة، بينما `FileSystem` فقط لديه بـ كامل ملف لـ حد `readBytes(target, signal, maxBytes)`. لذلك `dsh-fs` إضافة جديدة ثاني عدد أصلي بايت أصل لغة:

```ts ignore-check
abstract readByteRange(target: FsTarget, range: { offset: number; length: number }, signal?: AbortSignal): Promise<Uint8Array>
```

هو إرجاع `[offset, offset + length)` موضع بايت، ملف في نافذة داخل انتهاء فإن تغيير قصير،`offset` يقع في أو تجاوز مرور نهاية ذيل فإن لـ فارغ. نافذة أي حد: خلفية الأكثر كثير نقل لـ وصول `offset` بينما قفز مرور بادئة خارج `length` بايت، من لا مؤقت اندفاع كامل ملف، لذلك استدعاء جهة مقابل `length` حد أعلى حينئذ هو منع بلا حد مؤقت اندفاع حراسة حماية، و `readBytes` حد و صف بينما غير يحل محل هو. معامل ترتيب التزام دوران `readText`،`streamText` و `listDir`——أولا هدف، مجددا عملية ذاتي ذات معامل، الأكثر بعد اختياري signal——بينما لا هو `readBytes` يأخذ signal وضع في بين شكل صيغة، ذلك هو هذا صنف في وحيد مثال خارج.`offset` و `length` حسب قبل وضع شرط كل هو غير سالب كامل عدد؛seam هو نوع تحويل نفس عملية حد، لا فعل أي تحقق، من Remote طريقة في خط مسار موضع تحقق.

`fs-local` في و أخرى قراءة نفسه عادي ملف stat بعد فتح `createReadStream(targetKey, { start: offset, end: offset + length - 1 })`، مقابل `length` لـ 0 مباشر إرجاع فارغ عدد مجموعة بينما لا فتح تدفق؛`fs-sandbox` وراثة `LocalFileSystem`، مع لـ وراثة هذا طريقة. وراثة `FileSystem` أربعة عدد اختبار بديل ذات أيضا تنفيذ هذا طريقة.

### Client `file` توفير من

Client تصدير نحو `ctx.resources` تسجيل واحد `ResourceProvider<'file'>`، تخزين نشط مدة و إضافة نفسه، و إعلان `ResourceProtocolMap.file`.Document Preview حزمة يأخذ هذه الحزمة تصدير `WorkspaceFileParams` تسجيل لـ `SidebarRightResourceParamsMap.file`.

- **قيمة هو بيانات وصفية**،`WorkspaceFileStat { absolutePath, version, bytes? }`؛ محتوى من لا دخول تدفق، لأن محتوى يمكن مهمة معنى كبير، بينما تدفق هو استخدام قدوم دفع إرسال تغيير بينما لا هو تحميل حمل. إزالة استهلاك من استخدام `read` قراءة صفحة (أو استخدام `readBytes` فتح نافذة) ، و مقارنة مقارنة إصدار حكم قطع هو جمع هل مرور وقت؛ جديد طازج درجة حكم قطع و تحديث جديد يخص كل مستهلك، لا يخص مشترك مراقبة.
- **عنوان تسمية ملف، أثر مجال قرار قراءة جلسة.** `session` عنوان يحمل متبادل مقابل أو قطعا مقابل مسار أصل مثال تسليم إعطاء Host؛ مساحة العمل أصل لـ متبادل مقابل مسار توفير أساس دقيق،Session نظام الملفات خلفية قرار قراءة إذن.Client لا حاجة يحتفظ cwd.`absolute` عنوان لا حمل Session، بـ `workspace-file/unknown-workspace` فشل، لا استعارة استخدام حالي أو tab الذي تابع Session. لا دعم حمل لغة قاعدة إنتاج `workspace-file/unsupported-address`. هذا اثنان نوع Client خطأ سوف انتهاء تدفق.
- **لقطة.** رقم واحد لقطة هو `stat`أو ذلك فشل `ok: false` لقطة؛ توفير من لا رمي أيضا لا وصل، لأن Remote وجه من لا reject، بينما توفير من تدفق داخل رمي خطأ فقط ممكن هو تحرير مسار خطأ، مهمة ذلك طفو خروج. يحمل قيمة بعد لم يحتفظ إصدار Host كتابة إنتاج هذا إصدار، إبقاء بايت عدد، لا فعل stat؛ يحمل قد يحتفظ إصدار لقطة يتم إسقاط. تقرير إبلاغ إزالة فقد سوف مجددا stat مرة——ما زال في فإن هو جديد بيانات وصفية، لا في فإن هو إبقاء فوق واحد قيمة توفير عرض `not-found` لقطة. تتبع مع هو عنوان بينما لا هو ملف:stat فشل بعد تدفق متابعة، لذلك agent إنشاء هذا ملف سوف يجعل مورد استعادة صحيح معتاد. في توقف signal فإن تدفق ساكن صامت انتهاء.
- **كل جلسة واحد بند `changes` حجز قراءة.** أول موضع تتبع مع من فتح `remote.$stream`، الأكثر بعد واحد موضع مغادرة فتح وقت تحرير، بعد استمرار تدفق و إضافة تفكيك حذف انتظار إغلاق إتمام.Client قبول Host `ready` بعد عندئذ بدء أول مرة `stat`؛ محلي إرسال خروج WebSocket طلب لا هو Host تأكيد. تتبع مع من أولا حسب عنوان تسجيل، مؤقت اندفاع مسار لم معرفة خلال تغيير، نجاح stat بعد حسب إرجاع `absolutePath` مرور ترشيح ترتيب طابور و فوري لقطة، عكس مائل عمود عودة واحد لـ مائل عمود. بعد لم نجاح ربط وقت،Session داخل أي كتابة متساو يمكن إطلاق إعادة stat. تحميل جسم إسقاط خط من Gateway مراقبة إشراف جهاز إعادة وصل؛Host انتهاء أو نهاية حالة فشل سوف انتهاء تتبع مع من، و إبقاء الأكثر قريب بيانات وصفية، مباشر إلى إعادة فتح.
- **تنقل معامل.** `SidebarRightResourceParamsMap.file` هو `WorkspaceFileParams { line?: number }`، أي يلزم إظهار كشف 1 بدء حساب سطر رقم. سطر رقم بصفة تنقل معامل بينما لا هو عنوان واحد جزء نقل تمرير، لأن لا نقاش من قمة جزء أيضا هو رقم 400 سطر فتح، ملف كل هو نفس نسخة محتوى.

### متبادل صلة سجل

[مورد نموذج](2026-09-05-client-resource-model.ar.md) يملك `ctx.resources`،`useResource`،`dsh-resource://<type>/…` عنوان لغة قاعدة و"كل عنوان واحد نسخة مورد"دفع إدارة؛[نص معاينة و ملف شجرة](../feature/2026-09-05-sidebar-text-preview-and-file-tree.ar.md) هو `read`،`list` و `file` توفير من مع حزمة تسليم مستهلك؛[يمين جانب Sidebar توقف اعتماد أساس أساس ضبط تطبيق](../feature/2026-09-04-right-sidebar-docking-infrastructure.ar.md) هو هو جمع فتح دخول ذهاب واجهة؛[مساحة العمل ملف رابط](../feature/2026-07-31-web-workspace-file-links.ar.md) هو مرور HTTP توفير ملف يتم مرفوض لـ موضع. أي في هذا طقم جسم نظام فوق توسيع شخص كل مرور `remote.workspaceFiles` لمس بلوغ نفس مثال سبعة عدد طريقة، مرور `useResource<'file'>` لمس بلوغ نفس مثال `file` مورد؛ خط مسار نوع بـ `@deepseek-ai/dsh-api-workspace-files/types` إصدار.[مساحة العمل ملف قراءة إذن](2026-09-09-workspace-file-read-authority.ar.md) مسؤول Host قراءة إذن و HTML أمان أخذ ترك؛[Document Preview](2026-09-08-document-preview-operations.ar.md) مسؤول محتوى تحميل و تدريجي tab جديد طازج درجة.

## Alternatives considered

**يأخذ مساحة العمل ملف طرف نقطة إبقاء في Session Controller فوق.** الأكثر أول شكل: مجموع بايت حد أعلى لـ تحت واحد `read`، بصفة Session Controller فرعي إضافة تسجيل، لأن خط مسار مدخل هذا قدوم حينئذ في ذلك داخل. يتم لا، لأن Workspace File خدمة هو ذاتي ذات قدرة——قراءة و stat ملف، و صف رفع و مراقبة مساحة العمل——هذه استعلام ينبغي عودة في واحد موضع، بينما Session Controller صلة قلب هو جلسة دورة الحياة. نقل خروج أيضا يجعل خدمة طويل إلى خمسة عدد طريقة بينما لا إعطاء Controller ملف إضافة ثاني إعادة هدف.

**حمل لديه عكس نحو UI اعتماد مزدوج وجه حزمة.** تفكيك حزمة اختيار مصدر في `api/remotes` مرجع Client ورقة فرعي بعد شكل صار اثنان بند عمل مسار مرجع حلقة: مورد نموذج لـ نتيجة نوع مرجع Remote تركيب إعداد، ملف توفير من لـ Sidebar معامل جدول مرجع يمين شريط UI.TypeScript بـ `TS6202` رفض هذه حلقة.[مزدوج وجه حزمة مجموعة نسج](2026-09-07-workspace-files-dual-face-package.ar.md) يحل محل تفكيك حزمة اختيار: نتيجة نوع مباشر أخذ ذاتي بروتوكول حزمة،Sidebar معامل تسجيل نقل حتى نص معاينة؛ إبقاء اثنان عدد أصل تجمع دمج في صريح تحرير ترجمة مدخل.

**مرور HTTP توفير مساحة العمل ملف.** قد يتم[مساحة العمل ملف رابط](../feature/2026-07-31-web-workspace-file-links.ar.md) بـ origin إدارة من مرفوض كما لم إعادة اقتراح:`read` و `readBytes` مرور إقرار إثبات Remote تحميل جسم نقل إرسال صاف نص و base64، لذلك لا توفير وثيقة، لا صب URL، أيضا لا إنتاج origin مشكلة.

**ملف قراءة اعتماد “سجل يمكن بلوغ” أو مساحة العمل يتضمن تخويل.** وحيد يأخذ ملف محتوى إرسال مرور خط مسار أولا مثال——أمر مرفق عنصر——فقط تخويل ظهور في جلسة سجل داخل ملف، هذا سوف ترتيب حذف يد نقل مسار؛ مساحة العمل يتضمن فإن سوف ترتيب حذف Session خلفية أخرى موضع يمكن قراءة ملف.[مساحة العمل ملف قراءة إذن](2026-09-09-workspace-file-read-authority.ar.md) تعديل لـ بـ خلفية قراءة قرار لـ دقيق، فقط مقابل مساحة العمل شكل عملية إبقاء يتضمن حد.

**لـ بايت نافذة كامل ملف قراءة مجددا مقتطعة.** `readBytes` مؤقت شكل مرور `readBytes(target, signal, offset + length)` من ملف فتح رأس قراءة إلى نافذة نهاية طرف مجددا مقتطعة. هو قراءة لا مقارنة هذا نهاية طرف أكثر طويل ملف نافذة——seam سوف بـ مرور كبير رفض هذا مثال ملف——لذلك لا يوجد أي نافذة قدرة تقرير إبلاغ `eof: false`، و هذا طريقة وجود إدارة من متبادل تناقض. يتم لا، تعديل لـ بـ نافذة لـ حد `readByteRange` seam.

**يأخذ ملف حقل تسمية لـ `url`(أو `hostUrl`).** Session Controller `WorkspaceFileText.url` هو Host جانب ملف `file:` URL. مورد عنوان ظهور بعد أي يتم لا: خط مسار فوق URL قراءة بدء قدوم مثل عنوان، بينما هذا عدد لا هو——هو فقط هو عنوان الذي حمل نفس مسار آخر نوع تحرير رمز تجميع قاعدة،Client يجب حل رمز عندئذ قدرة مطابقة تغيير لقطة. خط مسار حقل حسب ذلك الذي هو تسمية، لذلك حقل لـ `absolutePath`،`changes` لقطة يحمل نفس حقل.

**في `FileSystem` أساس صنف داخل إعطاء `readByteRange` واحد افتراضي تنفيذ.** أساس في `readBytes` غير سحب كائن افتراضي قدرة تجنب ذهاب اختبار بديل ذات واحد طريقة، لكن فقط قدرة اعتماد يأخذ ملف من رأس قراءة إلى نافذة نهاية طرف قدوم تنفيذ——صحيح هو فوق نص مرفوض سلوك——أو من نقل واحد بلا حد حد أعلى. تعديل لـ سحب كائن طريقة، من كل توفير من و بديل ذات تنفيذ.

**مساحة العمل عملية استخدام نص بادئة يتضمن حكم تحديد.** يأخذ تحليل بعد مسار نص و أصل مقارنة مقارنة مقارنة `fs.contains` بسيط مفرد، لكن `resolve` سوف أخذ realpath، مغادرة فتح أصل رمز رقم رابط تحليل إلى أصل خارج مسار، بينما مقابل لم تحليل تجميع قاعدة بادئة اختبار سوف وضع سطر؛ مقابل قد تحليل تجميع قاعدة بادئة اختبار أيضا ما زال يحتاج خلفية مقابل"نفس ملف"تعريف.`list` و `changes` من نظام الملفات حكم تحديد يتضمن علاقة.

## Consequences

- مساحة العمل ملف وصول من `api/workspace-files` Host/Client اثنان وجه مشترك نفس تحمل تحمل؛Session Controller لا يحمل منها أي تنفيذ، اثنان وجه تحرير ترجمة و وقت التشغيل مدخل إبقاء مستقل.header-only Session scope يجعل عادي،subagent،live و cold Session كل قدرة تحليل ذاتي ذات متبادل مقابل مسار، لا حاجة Agent دورة الحياة، أيضا لا رجوع أب Session.
- مهمة معنى كبير صغير ملف كل قدرة فتح: نص حسب سطر صفحة، أي ملف حسب بايت نافذة، في Host فوق كل منها فقط زهرة واحد صفحة أو واحد نافذة داخل تخزين؛ كل نص قراءة فإن تلقي `maxFileBytes` قيد؛ بديل قيمة هو إزالة استهلاك من ذاتي ذات تجميع تركيب صفحة، كما مفرد سطر تجاوز مرور `maxBytes` سطر لا يوجد أي صفحة، لأن صفحة حسب سطر قطع.
- كل نظام الملفات توفير من كل توفير فتح نافذة أصلي قراءة؛`fs-local` مباشر تحديد موضع إلى الذي طلب انحراف نقل كمية.
- خط مسار فوق مسار هو مواصفة:`absolutePath` و تغيير لقطة بـ رمز رقم رابط قد تحليل تجميع قاعدة تسمية ملف. تتبع مع من ربط إلى نجاح `stat.absolutePath`، لذلك نفس ملف آخر نوع تجميع قاعدة——مرور رمز رقم رابط وصول مساحة العمل أصل——أيضا استخدام هذا مواصفة تغيير مفتاح.
- تغيير لقطة فقط تقرير إبلاغ agent ذاتي ذات عملية. مستخدم تحرير جهاز،shell أو عملية فرعية تعديل ملف لا إنتاج لقطة؛agent فقط فقط قراءة واحد يتم آخر موضع تعديل ملف لكن سوف إنتاج لقطة، لأن قراءة مراقبة إلى جديد إصدار.
- ملف نوع فحص أولا في خلفية قراءة،`list` أيضا أولا تقرير نوع صنف مجددا تقرير أصل خارج موضع. صفحة `version` ممكن سقوط بعد محتوى مرة كتابة، توقف ركود `changes` إزالة استهلاك من سوف يجعل Host داخل تخزين زيادة طويل، لأن واحد بديل تدفق طابور صف بلا حد؛ كل واحد بند كل هو حزمة README سجل في سجل معروف أخذ ترك.
- `file` مورد دفع إرسال تغيير بينما غير محتوى، لذلك معاينة لا اعتماد تحميل حمل حينئذ نيل معرفة ملف قد تحديث و قراءة هو تفكير يلزم صفحة؛ فشل فتح متابعة تتبع مع عنوان، لذلك agent إنشاء هذا ملف وقت tab بلا حاجة مستخدم حركة عمل أي استعادة صحيح معتاد.
- `readBytes` بعد بلا مع حزمة تسليم مستهلك؛Document Preview مقابل كامل ملف صيغة استخدام `readAll`.

## Testing

`packages/api/workspace-files/tests` في Host spec تغطية live و cold subagent Session header-only scope تحليل، نشر fallback، ناقص هوية و lookup تحرير؛ قسم صفحة قراءة (كامل ملف، تضمين طقم مسار، فارغ ملف، كثير بايت UTF-8، سطر نافذة حد، نقص حذف و رفض limit، إبقاء عودة عربة) ؛ بايت نافذة (نقص حذف، في مقطع و ذيل نافذة، تجاوز حد و فارغ ملف،base64 نحو إرجاع، إصدار، حد أعلى، تالف نطاق و بلا كبير ساعة `eof`) ؛`stat`؛ مساحة العمل خارج قراءة و خلفية رفض؛`list` يتضمن، مقتطع، رمز رقم رابط و `not-directory`؛ و من `fs/observed` قيادة و حسب أصل مرور ترشيح `changes`.Client spec تغطية توفير من لقطة، تغيير تدفق، لا دعم حمل عنوان و تسجيل و تحرير.`fs/fs` و `fs-local` spec تثبيت إقامة `readByteRange`؛`dsh-util-workspace-path` spec تثبيت إقامة ملف عنوان لغة قاعدة.connection fixture لـ web e2e طقم عنصر توفير `stat`، قسم صفحة `read`،`list` و واحد لقطة اختياري تفعيل `changes`.

## Deferred

- إعطاء `changes` واحد بديل تدفق طابور صف إضافة حد أعلى.
- `readBytes` مع حزمة تسليم مستهلك (صورة و اثنان دخول صنع معاينة) و أي كتابة، بحث أو وسيط جسم توجيه؛ هذا خدمة فقط قراءة.
- ملف عنوان في `session` خارج أثر مجال؛ لغة قاعدة إبقاء لديه بقية أرض، توفير من فقط خدمة واحد.
