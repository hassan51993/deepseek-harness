# Agent Note: إنشاء صنع نمط تثبيت حفظ دائم إضافة تركيب حزمة

Status: implemented

[English](2026-09-16-creator-persistent-plugin-management.md) | العربية

## Problem

agent حاجة تثبيت قدرة و في نفس مقطع محادثة في استخدام. توليد شفرة أداة في عادي قد تثبيت تركيب حزمة خارج جذب دخول ثاني طقم إضافة دورة الحياة.

## Decision

إنشاء صنع نمط تفعيل قائم `plugin_manager` أداة.agent سوف حزمة و Loader YAML patch كتابة مساحة العمل ملف، مجددا عبر `install_bundle` تثبيت.MCP اتصال هو إدراج دخول قد تثبيت `dsh-mcp-client` صاف إعداد تركيب حزمة؛UI تركيب حزمة يتضمن Host مدخل و Client ناتج.profile قفل، حزمة تثبيت، بدء توقف و HMR متابعة من قائم إدارة جهاز مسؤول. كامل إدارة أداة اشتراط `danger-full-access` أو مفرد مرة استدعاء دفعة دقيق:profile تغيير قدرة بـ مضيف إذن تحميل شفرة، و أثر أخرى جلسة. كل مرة تنفيذ (يشمل استعلام قائمة) كل سوف أولا استخدام مشترك صندوق رملي رفع حق دالة و مراجعة دفعة خدمة، مجددا وصول إدارة جهاز. في مقارنة منخفض صندوق رملي نمط تحت،`ask` طلب مراجعة دفعة،`never` رفض؛ كامل إذن جلسة بلا حاجة مقدار خارج مراجعة دفعة. دفعة دقيق لا تغيير جلسة إذن، لكن هذا مرة عملية profile تغيير سوف حفظ دائم. هذا يجعل و shell انتظار قيمة مضيف وصول حاجة واضح تخويل، معا لا لا بد دائم دائم رفع رفع كامل جلسة إذن. من مستخدم مباشر عملية Web و CLI تحكم عنصر إبقاء أصل لديه سلوك.

نموذج مرئي اثنان عدد فقط قراءة Cordis فحص أداة، لم يعد توفير توليد شفرة define/run/stop/undefine و حركة حالة ذاتي حذف أداة API. قائم وقت التشغيل و Client إزالة استهلاك من إبقاء ذلك خدمة؛ تاريخ جلسة بطاقة ما زال يمكن قراءة. هذا فقط يحل محل[ذاتي مرجع أداة تجميع قرار](../feature/2026-07-08-self-referential-cordis-toolset.zh.md) في نموذج جانب تغيير مسار؛ ذلك وقت التشغيل كل حق و صندوق رملي اعتماد حسب ما زال لديه مستقل قيمة قيمة.[profile أمر خدمة قرار](2026-09-14-current-profile-plugin-management.zh.md) متابعة قاعدة تحديد قفل، حزمة تثبيت و جزء فشل سلوك.

حذف غير مستخدم إشارة تحديد أخرى هدف، نظر شعور إنشاء طلب افتراضي عبر قد تثبيت Client إضافة عرض في حالي Web صفحة. تطوير skill توفير الأكثر صغير حزمة و من effect إدارة Client تسجيل عرض مثال. معروف الذي يحتاج API بعد انتهاء استكشاف فحص، في اختياري نظر شعور أفضل تحويل قبل أولا تثبيت قدرة عمل أول إصدار. لديه شرط وقت استخدام قد اتصال صفحة تحقق. متصفح إقرار إثبات أو عملية نظام ضبط لا هو تثبيت إضافة قبل رفع،mock معاينة لا يستطيع إثبات تطبيق داخل نتيجة.

Desktop عبر بدء جهاز توفير profile معلومة نقل دخول داخل وضع pnpm مدخل و Electron Node استدعاء طريقة.Plugin Manager استخدام هذا استدعاء إتمام تثبيت، إزالة و registry فحص، إبقاء عبر معتاد profile أمر خدمة و تنشيط سلوك. ذلك بيئة فقط تطبيق في حزمة إدارة عملية فرعية؛ عادي Host عملية فرعية لا وراثة خاص Node بدء جهاز مسار.CLI profile إبقاء ذلك إعداد PATH أمر.

تاريخ Cordis جلسة بـ دقيق تأكيد صيغة إصدار إعلان `retired-tools` تغطية، أي جعل هذا إصدار انتظار في حالي writer أيضا مثل هذا. هو جمع هو غير ممكن تعديل كتابة إعادة وضع إدخال؛ حفظ دائم بعد أداة استدعاء و نتيجة بيانات سوف إجراء مقارنة مقارنة، بطاقة تصيير لا تسجيل قد إزالة أداة. هذا تغطية لا حساب دخول ترحيل تغطية. إبقاء runner كتابة API توفير برنامج و متصفح إزالة استهلاك من استخدام؛ إزالة وقت يجب واحد بدء استبدال هذه إزالة استهلاك من.

## Alternatives considered

عام بند زيادة حذف تعديل فحص و MCP مخصص استخدام إدارة API تكرار تركيب حزمة ملف و قائم تثبيت، بدء توقف عملية قدرة كاف جدول بلوغ قدرة، تلميح قيادة تثبيت لا حاجة هذه واجهة. سوف توليد شفرة إصدار إدارة نقل دخول Plugin Manager سوف إبقاء اثنان طقم دورة الحياة، كما لا يمكن توفير عادي حزمة حفظ دائم طريقة.

## Consequences

قد اختيار تركيب حزمة أثر profile في كل جلسة، و في إعادة بدء بعد إبقاء.HMR في فوري profile في تنشيط جديد تركيب حزمة؛ استبدال قد تثبيت حزمة حاجة إعادة بدء.agent قسم آخر تقرير إبلاغ حفظ حالة و تنشيط نتيجة، و تحقق الذي يحتاج قدرة. فرعي أثر ملكية في إضافة دورة الحياة، يشمل مثال صيغة جدول تنظيف.

بناء بعد Web profile اختبار تثبيت MCP تركيب حزمة، فحص قائم و جديد بناء إنشاء صنع نمط جلسة، إعادة بدء عملية، و تحقق إزالة تركيب حزمة بعد أداة تحرير. تسجيل صنع جلسة بلا حاجة نموذج اعتماد يكفي إعادة تشغيل إدارة جهاز تفعيل قد إعداد MCP بند و لاحق حقيقي محلي MCP طلب. تاريخ بطاقة اختبار إبقاء قد إزالة أداة قد حفظ عرض.
