# Agent Note: client إضافة تركيب تحميل——كسول صفة factory،Cordis دورة الحياة و حار إعادة تحميل

Status: implemented

[English](2026-07-23-client-plugin-loading-model.md) | العربية

> نطاق: متصفح جانب إضافة تركيب تحميل آلة عنصر——شفرة مثل أي وصول،Cordis مثل أي معالجة إدارة شفرة، و حار إعادة تحميل مثل أي تركيب ركوب هذا طقم نموذج. هذا Note يملك تركيب تحميل سلسلة؛[client خارج قشرة قسم طبقة Note](2026-08-15-client-shells-and-dynamic-packages.ar.md) يملك حزمة تصنيف، بناء face، مشترك وحدة طلب و npm اعتماد إعلان،[Web عميل هيكل بنية قلم تسجيل](2026-07-19-gui-web-client-architecture.ar.md) فإن يملك slot و بيانات كائن طبقة.

## Problem

host جانب،cordis إضافة تركيب تحميل محطة في Node وحدة آلية لـ فوق——require cache و داخلي ESM loader يملك وحدة هوية و بايت.vendored `@cordisjs/plugin-loader` في هذا طبقة أساس مقعد لـ فوق تنفيذ إضافة معالجة إدارة و حار إعادة تحميل، اثنان من في وحيد واحد طريق حد متبادل وصل:`Loader.internal`.

متصفح عميل ركض نفس طقم cordis إضافة آلية، لذلك قاع تحت حاجة نفس مثال أساس مقعد——بينما متصفح لا يوجد Node وحدة نظام.

معتاد قاعدة قبل طرف عمل مسار في بناء مدة إزالة تحويل الكل اعتماد: مفرد واحد bundle،external من تحزيم جهاز حل قرار، وقت التشغيل بلا شيء يمكن إدارة. في هذا لـ فوق مجددا فعل وقت التشغيل وحدة إدارة، صحيح هو هذا داخل خاص خاص يحتاج طلب.client لذلك تفكيك صار اثنان طبقة: فوق طبقة هو مرور نفس نسخة vendored Loader cordis إضافة تركيب تحميل، تحت طبقة هو وحدة حبة درجة اعتماد إدارة——`dsh-client-modules`.

تحت طبقة توفير إعطاء أربعة بند قدرة:external(منصة بيان) ، بعيد مسار وصول (نفس مصدر خارجي classic script إضافة كسول صفة عمل مصنع تسجيل تسجيل) ، غير ممكن تغيير إصدار تحويل تسليم، حار تحديث (invalidate/prefetch).

إضافة bundle مستقل بناء في Vite وحدة رسم خارج. إذا يأخذ استجابة نص سد دخول داخل ربط script، متصفح فقط قدرة يرى مرة حركة حالة شفرة المصدر تنفيذ: شبكة مورد، توليد bundle،TypeScript/TSX شفرة المصدر بين لا يوجد معيار sourcemap سلسلة، صفة قدرة profile و stack فقط قدرة سقوط إلى توليد بعد `client.js`؛ وحدة نظام أيضا يلزم يحتفظ كامل نسخة شفرة المصدر نص، و يأخذ نفس بند وصول مسؤولية تفكيك صار fetch و execute اثنان طريق نقل حد.

في هذا لـ فوق،client و host إضافة بـ متسق طريقة تسجيل و تركيب تحميل: حزمة إعلان مرة `dsh.client`،host يأخذ إعلان مسح دخول boot رسم، نفس طقم Loader دلالة في اثنان جانب معالجة إدارة entry.

رقم واحد بديل client loader(`createClientLoader`) يأخذ هذا اثنان طبقة يد كتابة دخول نفس عدد دالة. هذا واحد دمج دمج إبقاء تحت هو: لا يوجد إزالة/إعادة تحميل مسار (تركيب تحميل مرة صفة،style وسم من لا إزالة) ، في ثلاثة عدد ملف بين شخص لحم نسخ كتابة كما مبكر قد عائم نقل اعتماد بيان، واحد بند توفير عبر إضافة import مشي وحدة جدول بعد باب——حيث نسخ cordis خدمة آلية، أيضا يأخذ تركيب تحميل ترتيب تغيير صار صحيح تأكيد صفة قيد. تحت نص بنية يحل محل هو.

## Decision

### حزمة عضو و وحدة طلب

[Client خارج قشرة قسم طبقة Note](2026-08-15-client-shells-and-dynamic-packages.ar.md) تعريف حالي ساكن حالة، حركة حالة حزمة تجميع دمج و ذلك import قاعدة. تركيب تحميل آلة عنصر يأخذ كل `dsh.client` حزمة نظر لـ واحد host graph row؛ كل حزمة كل لديه واحد عادي `lib/client.js` factory bundle، أيضا يمكن لديه تحرير ترجمة جهاز توليد `lib/client.<name>.js` chunk. حزمة إعلان يحمل Cordis `inject` حافة، تزامن وحدة جدول `external` طلب، و اختياري `immediately` مسبق أخذ علامة؛ مسؤول تركيب app فقط يملك تركيب اسم سجل.

Web داخل نواة إبقاء لا اعتماد إطار هيكل، أيضا لا import أي حركة حالة حزمة فعلي جسم.Modules ذاته هو حركة حالة رسم row، لكن host parser سوف في Vite رئيسي وحدة قبل إرسال بلوغ ذلك factory. داخل نواة استدعاء `create()` وقت، من HTML تثبيت `__ModuleLoader__` facade استخدام هذا factory بنية صنع وحدة نظام. أخرى كل حركة حالة رسم row كل ملكية واحد application combo نص برمجي؛React،Cordis و ساكن حالة UI مكتبة هوية من خارج قشرة seed توفير.

### واحد طقم وحدة نظام، واحد إضافة معالجة إدارة جهاز

متصفح تكرار لحظة host جانب قسم عمل.`dsh-client-modules`(`ClientModuleSystem`) جلوس فوق host جانب من Node داخلي ESM loader احتلال حسب وحدة نظام مقعد موضع؛ نفس نسخة vendored `@cordisjs/plugin-loader` في اثنان جانب كل جلوس معالجة إدارة مقعد. اثنان من قسم حد خط واحد جملة كلام قول كل:**وحدة نظام يملك وحدة هوية و بايت——شفرة كيف ما وصول، كيف ما تسجيل تسجيل، كيف ما تغيير صار تصدير محتوى؛Loader يملك إضافة دورة الحياة——إضافة أي وقت تركيب، انتظار ماذا، مثل أي تفكيك حذف.**

`ClientModuleSystem` هو واحد ورقة lazy CJS جدول. تنفيذ bundle فقط**تسجيل تسجيل**ذلك factory——مدخل استدعاء `window.__ModuleLoader__.load({ id, factory })`،chunk أيضا سوف توفير ذلك توليد ملف اسم——هذا خارج ماذا كل لا حدوث. وحدة جسم واحد قطع فرعي أثر (يشمل CSS حقن) كل إقامة في factory إغلاق حزمة داخل، في شيء تحويل وقت تشغيل: شيء تحويل أي هذا id أول مرة `require`/import، هذا بعد تسجيل ذاكرة تحويل.Import و prefetch سوف أولا تمرير عودة تسجيل تسجيل قد إعلان حركة حالة طلب، مجددا تسجيل تسجيل إزالة استهلاك من؛ مع بعد factory سوف تزامن شيء تحويل أي قد تسجيل تسجيل لكن بعد لم شيء تحويل طلب. يمكن استدعاء `require` تحليل تزامن وحدة جدول طلب؛ ذلك `require.async` عملية إرجاع Promise، مسؤول تحميل، تسجيل تسجيل و شيء تحويل واحد حزمة داخل chunk. مشترك tsdown مسبق ضبط يأخذ شفرة المصدر في إبرة مقابل حزمة داخل chunk `import()` جدول بلوغ صيغة تحرير ترجمة إلى هذا عدد مستقل عملية. تلقي دعم حمل ناتج يجب ذاتي يتضمن: مدخل أو chunk لا يستطيع تزامن require آخر عدد متبادل مقابل `client*.js` ناتج. وحدة جدول حسب ثابت فرع ترتيب تحليل:seed word → تسجيل ذاكرة تحويل سجل → graph row classic-script تسجيل تسجيل → قد تسجيل تسجيل factory شيء تحويل → كبير صوت رمي خطأ.Modules factory هو ذاتي رفع مثال خارج:HTML facade أولا شيء تحويل هو، بنية صنع مرور مسار مجددا يأخذ نفس exports مباشر كتابة تسجيل ذاكرة تحويل جدول. الأكثر بعد هذا واحد رمي هو بناء مدة صاف درجة بوابة في وقت التشغيل مرآة مثل. نظام أيضا حفظ إدارة تدريجي وحدة دفتر تسجيل——اسم تحت `<style data-plugin>` وسم id، مراقبة قياس إلى require حافة——و كشف HMR(حار وحدة استبدال) حاجة اثنان عدد حركة كلمة:`prefetch(id)`(تسجيل تسجيل الذي طلب حركة حالة factory و هذا row ذاته factory؛ تزامن وصول مشترك واحد مهمة) و `invalidate(id)`(دفع دخول owner بديل مرة و إسقاط غير bootstrap حزمة مدخل و chunk factory و سجل، يجعل تحت مرة وصول إعادة تحميل هو جمع). في قديم بديل مرة التقاط chunk طلب لا يستطيع ملء ملء جديد بديل مرة.

vendored Loader مرور ذلك `internal` اتفاق إزالة استهلاك وحدة نظام——وحيد استدعاء نقطة هو `tree.import`——و يملك واحد قطع entry شكل حالة أمر خدمة:entry إنشاء،fiber مرور cordis خدمة انتظار تنشيط (حقن خدمة لم حينئذ موضع أي إبقاء PENDING، خدمة provide وقت درجة ربط تنشيط) ،update/refresh، تفكيك حذف. معالجة إدارة شفرة حسب vendor سياسة سياسة و host جانب تدريجي بايت نفسه. متصفح تحويل هو قشرة vite إعداد داخل تحرير ترجمة مدة خريطة: واحد `node:module` stub آخر اسم إضافة إذا جاف `process.*` define، جعل `ModuleLoader.fromInternal()` إرجاع undefined——هذا صحيح هو إبقاء إعطاء قشرة قدوم ملء فارغ مجرى. وحدة نظام تركيب لـ `ctx.modules`.

### Combo خارجي نص برمجي وصول و شفرة المصدر خريطة

Host سوف لقطة كل قد بناء إضافة مدخل bundle، و يأخذ كل ضبط درجة مرحلة مقطع لديه ترتيب row تخطيط دخول واحد أو كثير عدد نفس مصدر classic script. هو في أكثر طويل map شكل صيغة طلب URL إبقاء في 3 KiB بـ داخل وقت طمع قلب ملء ملء كل مجموعة، حيث إبقاء graph ترتيب، أيضا بـ زيادة طلب بديل بديل تجاوز طويل URL. كل نص برمجي فقط يتضمن `client.js` مورد، و من هذه package مورد بحث عنوان، مثال مثل `/plugins/??<package-a>/client.js,<package-b>/client.js&rev=<rev>`.Host لا مسح نفس درجة ملف، أيضا لا يأخذ chunk إضافة دخول بدء combo.`bootstrap` و `application` هو رسم في ضبط درجة مرحلة مقطع، لا هو URL مجموعة صار جزء:HTML أولا مسبق تحميل كل application URL، مجددا تنفيذ كل منع سد parser bootstrap URL. وحدة نظام حسب combo URL إعادة استخدام إجراء في نقل، لذلك نفس مجموعة row تزامن وصول فقط تنفيذ واحد نص برمجي. نجاح تسوية ما زال اشتراط وحدة جدول في قد وجود يتم طلب row factory id؛ تسجيل تسجيل لن تشغيل factory، الذي بـ فرعي أثر حد اعتماد لكن هو أول مرة شيء تحويل.

مرة `require.async("./client.<name>.js")` استدعاء سوف طلب دقيق حمل revision URL:`/plugins/<package>/client.<name>.js?rev=<rev>`.Host فقط في استلام إلى طلب وقت قراءة هذا ملف، يأخذ ملف قد لديه chunk تسجيل تسجيل حزمة تركيب لـ واحد نص برمجي استجابة، و حسب URL ذاكرة مؤقتة استجابة. تزامن استدعاء مشترك واحد إجراء في نص برمجي مهمة؛ نجاح تسوية اشتراط chunk قد تسجيل تسجيل، مع بعد loader عندئذ سوف شيء تحويل و تسجيل ذاكرة تحويل ذلك exports. لم معرفة اسم، ناقص ملف و مختلف في الذي تابع graph row revision كل إرجاع 404.

مشترك tsdown مسبق ضبط لـ كل إضافة مدخل و chunk إنتاج خروج map، و يأخذ رقم واحد جهة شفرة المصدر مسار إعادة كتابة صار متصفح يمكن تعرف آخر مستودع شكل صيغة `/packages/<group>/<package>/src/...`. إنتاج Client بناء سوف إزالة استهلاك `lib/types`؛ مسبق ضبط يأخذ كل نسخة tsc map تسليم إعطاء Rolldown، و من أصل ملف تكملة متساو `sourcesContent`، جعل نهائي map عودة إلى TypeScript/TSX، بينما لا هو توقف في تحرير ترجمة بعد JavaScript. داخل ربط دخول bundle أخرى workspace شفرة المصدر نفس مثال عودة إلى ذلك `packages/` ملكية، اعتماد حزمة مسار إبقاء أصل مثال.Combo توليد سوف إزالة كل نطاق جزء ضبط تجربة إشارة أمر، سجل ذلك توليد سطر انحراف نقل، بـ أصل إضافة map URL تحليل كل ذاتي حمل source، مجددا إنتاج خروج Indexed Source Map v3. إضافة لديه ذاتي حمل map وقت مباشر لأجل مقابل section؛ لا يوجد وقت فإن توليد identity section، داخل تضمين بناء بعد bundle، و في وجود وقت يأخذ packer كتابة `sourceURL` استخدام عمل source اسم. قطعا مقابل combo map URL سوف مستو سطر تعديل كتابة نص برمجي مورد قائمة في كل `client.js` بعد لاحقة، لذلك `/plugins/??<package-a>/client.js,<package-b>/client.js&rev=<rev>` إشارة نحو `/plugins/??<package-a>/client.js.map,<package-b>/client.js.map&rev=<rev>`.chunk نص برمجي نفس مثال إشارة نحو ذاتي ذات map URL. فقط لديه في هذه map URL استلام إلى `GET` بعد،source map ملف عندئذ سوف يتم قراءة و تركيب؛`HEAD` لن شيء تحويل نص برمجي أو map body.Vite قشرة نفس مثال إنتاج خروج sourcemap، جعل قشرة شفرة و مرور خارجي تحميل إضافة كل قدرة من stack و صفة قدرة profile عودة إلى TypeScript/TSX.

رسم لـ HMR إبقاء كل row حمل revision مفرد مورد combo URL، و لـ كل بدء combo طلب زيادة حمل revision وصف؛ كثير بند وصف يمكن استخدام نفس ضبط درجة مرحلة مقطع. ابتدائي row revision هو عملية درجة لا نفاذ واضح nonce، بينما لا هو محتوى ها أمل؛ هو بلا حاجة في بدء وقت ها أمل كل إضافة، أيضا قدرة حفظ إثبات قد لقطة مفرد مورد استجابة غير ممكن تغيير. مشترك مسبق ضبط سوف في كل حزمة إخراج كتابة تمام بعد علامة مدخل.watcher مراقبة إلى هذا بناء إتمام علامة بعد،`rebuilt(id)` سوف يأخذ مدخل بايت و ذلك ختم الوقت واحد بدء ها أمل تزامن نشر الذي نيل revision؛ لذلك فقط إعادة بناء chunk أيضا سوف دفع دخول owner revision، بلا حاجة Host مسح sibling. بدء combo revision من لديه ترتيب row revision إرسال توليد. نص برمجي body في أول مرة `GET` وقت تركيب؛source map ملف في أول مرة map `GET` وقت مفرد وحيد قراءة و تركيب.`HEAD` لن شيء تحويل مهمة واحد body. إصدار تحويل نص برمجي و map استخدام immutable ذاكرة مؤقتة، غير متصل رسم إعادة مجموعة سوف إبقاء نفسه revision تحت قد شيء تحويل chunk استجابة.Host فقط توفير دقيق توليد URL؛ قديم قديم revision و لم إصدار مورد قائمة إرجاع 404، لن آخر اسم إلى أخرى بايت. خارجي نص برمجي `error` حدث لا إعطاء استجابة حالة و متن، لذلك فشل تشخيص فقط تقرير إبلاغ URL؛ نفس مصدر Host و بناء مدة كتابة registration id هو هوية حد،`load` بعد factory وجود فحص مسؤول رفض لم تسجيل تسجيل مسبق مدة id ناتج.

### تركيب تحميل مسار، طرف إلى طرف

من `dsh web` بدء إلى UI ظهور بين حدوث ماذا؟ ثلاثة عدد مرحلة مقطع:host تركيب graph و من parser مسبق تحميل bootstrap factory،HTML facade إنشاء وحدة نظام كما خارج قشرة تنفيذ مسبق أخذ، لكن بعد Cordis تحرير ترتيب.

**host جانب——تركيب هذا ورقة رسم.**

1. مسؤول تركيب app(`apps/cli`) يأخذ اسم سجل بصفة عادي سطر وضع دخول هو `cordis.yml` إعداد شجرة——client إضافة حزمة و كل host إضافة واحد مثال هو entry سطر، يشمل بلا شرط تركيب `client-hmr` سطر.`auditStartupEntries` تقرير إبلاغ import فشل، حمل أصلي stack تنشيط خطأ، و انتظار ممتلئ كاف اعتماد؛optional entry إخراج warning،required entry فإن جعل بدء فشل ([بدء سياسة](2026-09-09-consumer-owned-startup-strictness.ar.md)).
2. `dsh-client-modules` node نصف (هذا حزمة هو مزدوج وجه: متصفح نصف حينئذ هو وحدة جدول) استخدام Host face import وقت نفسه `name` و الذي تابع tree `baseUrl` تحليل كل live Loader entry، مجددا قراءة الأكثر قريب ملكية package.json `dsh.client` إعلان و تركيب خروج `window.__DSH_BOOT__`:`{ rev, entries: [{ id, url, rev, inject?, immediately?, external? }], batches: [{ phase, url, rev, entries }] }`. أي جعل overlay إشارة نحو متبادل مقابل source أو built entry ملف،manifest حزمة اسم ما زال هو متصفح وحدة هوية. إذا مختلف active Loader source تحليل إلى نفس حزمة اسم، تركيب سوف فشل؛ واحد مصدر إزالة بعد، ما زال تخزين نشط مصدر بلا حاجة إعادة بدء fiber يكفي توفير هذا row.Row ثلاثة عدد اختياري حقل كل قدوم ذاتي manifest، دائم لا شخص لحم نسخ كتابة. تركيب سوف يأخذ يتم طلب حركة حالة رسم row ترتيب إلى إزالة استهلاك من قبل، رفض تزامن طلب حلقة، و يأخذ كل row تماما جيد قسم إعداد إعطاء واحد ابتدائي دفعة مرة. هو سوف رفض لا يوجد قد بناء `./client` bundle قد إعلان إضافة، و يأخذ هو جمع package/path سطر عودة إلى واحد بند شفرة المصدر بناء اشتراط تحت؛ شاذ شكل إعلان حقل نفس مثال سوف يجعل تنشيط فشل،Host فحص سوف من FAILED fiber تقرير إبلاغ هذا اثنان صنف خطأ.
3. مسح هو مفرد حزمة زيادة كمية——لا وجود كل كمية إعادة مسح شفرة مسار. كل مرة cordis `internal/plugin` إرسال إطلاق يأخذ هذا fiber entry اسم علامة قذر (بلا entry fiber O(1) إسقاط) ؛ دقيق مهمة flush يأخذ كل قذر اسم مقابل حساب live loader entries، حزمة بيانات وصفية (يحتوي «غير client حزمة» لا تحديد ربط نقاش) حسب entry اسم و الذي تابع tree base URL ذاكرة مؤقتة حتى عملية انتهاء،bundle إعادة ها أمل فقط مرور `rebuilt(id)` يمكن بلوغ. تنشيط مرة من حالي entries ملء نفس قذر تجميع دمج تزامن flush، أول مسح و مستقر حالة مشترك واحد بند تنفيذ. ابتدائي row استخدام لا نفاذ واضح عملية nonce إضافة ترتيب رقم، لا مقابل ذلك ناتج طلب ها أمل؛ بدء combo revision مقابل دمج نص برمجي إدخال و indexed map طلب ها أمل،row و دفعة مرة وصف مجددا مشترك نفس ها أمل دخول `graph.rev`. رسم نوع مفرد مصدر في modules حزمة `./client` خروج فتحة——webserver مقابل رسم واحد بلا الذي معرفة؛modules سوف تسجيل combo توجيه و مساهمة بنية تحويل index حقن سطر.

لـ ماذا اسم سجل هو yml سطر بينما لا هو مسح؟ لأن أي بعض إضافة تركيب دخول مرة نشر هو تركيب قرار، لا هو حزمة خاصية——واحد في مستودع في إعلان dsh.client حزمة، لا بديل جدول هذا مرة نشر يلزم تركيب هو، مسح اكتشاف بلا من بديل شخص فعل هذا عدد قرار؛node نصف فقط مسح إعداد شجرة فعلي تركيب شرق غرب.

**رقم واحد مرحلة مقطع——وحدة وجه.**حقن HTML بـ queue نمط تثبيت `window.__ModuleLoader__`، بدء مسبق تحميل كل application combo URL، بـ منع سد صيغة classic script اعتماد مرة تنفيذ كل bootstrap combo URL، منح قيمة `window.__DSH_BOOT__`، لكن بعد بدء Vite رئيسي وحدة. داخل نواة يأخذ أصلي رسم و خارج قشرة seed نقل إعطاء facade `create()`.Facade إزالة modules registration، استخدام رفض الكل external bootstrap `require` سوف ذلك شيء تحويل، مجددا استدعاء ذلك `createClientModuleSystem` تصدير.Modules bundle تحليل رسم، بنية صنع و إرجاع نظام، تسجيل ذاكرة تحويل ذاته exports، و يأخذ نفس facade تبديل إلى live registration. مع بعد داخل نواة و سطر مسبق أخذ كل `immediately` row؛ نفس application combo في row مشترك مرة تنفيذ، مختلف combo سوف في immediate row، يتم طلب اعتماد أو عادي entry import أول مرة لمس و وقت مستقل تحميل. مسبق أخذ فشل في هذا داخل يتم ابتلاع تحت، لأن ثاني مرحلة مقطع import سوف إعادة محاولة و يملك ذلك مرة كبير صوت فشل.`immediately` ما زال هو registration barrier، لا هو حزمة هوية.

**ثاني مرحلة مقطع——إضافة وجه.**

1. داخل نواة تركيب vendored Loader، في أي entry وجود قبل حينئذ يأخذ وحدة نظام حقن لـ `internal`. ترتيب لديه شرح بحث:`tree.import` عار import التقاط قاع فرع في متصفح داخل أبدا قدرة ركض إلى.
2. هو موحد واحد إنشاء كل graph row.Import modules row سوف إرجاع تسجيل ذاكرة تحويل bootstrap exports، ذلك `apply()` قراءة هذا شجرة `Loader.internal`، يأخذ نفس عدد نسخة توفير لـ `ctx.modules`؛ حاجة هذا service row سوف إبقاء PENDING مباشر حتى هذا وقت، لذلك modules row بلا حاجة خاص خاص إنشاء موضع. تصيير تجميع هو من `dsh-client-ui-renderer` توفير عادي host graph row؛ داخل نواة لا إلحاق تجميع زائف entry.
3. Graph ترتيب معالجة إدارة تزامن factory متاح صفة؛Cordis تنشيط و لـ مستقل، ما زال مرور خدمة انتظار دفع دخول.
4. `settled` = كل entry قد إنشاء + `loader.await()` تماما توقف مستقر + مرة كل ACTIVE مسح. مسح صف خروج كل import فشل،FAILED أو PENDING fiber و ذلك ناقص خدمة. هو وجود إدارة من:cordis inject انتظار لا يوجد مهلة——هذا مرة مسح حينئذ هو كبير صوت فشل التقاط قاع خط.
5. لا اعتماد إطار هيكل loading صفحة مرور `internal/status` إسقاط حقيقي fiber حالة. فحص إتمام بعد، داخل نواة استدعاء `ctx.uiRenderer.mount(container)`، مرة تبديل إلى حقيقي UI.

### حركة حالة رسم مقابل حساب

modules تحكم جهاز فقط يحتفظ من بدء بيان إنشاء Loader بند.Host كامل لقطة تحديث وحدة وصف و مقابل حساب هذه بند؛ أخرى Loader مساهمة جهة إبقاء ذاته كل حق. إضافة جديدة وحدة عبر مفرد مورد URL وصول، لأن إعادة وضع بدء batch ممكن تكرار تسجيل قائم factory. إزالة استخدام Loader حذف دلالة، مع بعد انتظار قد التقاط fiber تنظيف تمام انتهاء، مجددا إزالة لم استخدام وحدة و مثال صيغة. قد إعلان و قد مراقبة إلى نقل تمرير اعتماد جعل مشترك وحدة إبقاء تخزين نشط.Factory revision تتبع أثر مستقل في بند تنشيط، لأن تحت تحميل أو شيء تحويل إتمام بعد ما زال ممكن لا يوجد إنشاء بند. رسم تحديث سوف في أي إزالة استهلاك من استيراد اعتماد قبل، جعل لم ملكية تلقي إدارة بند قديم قديم factory و فشل وصول هدف بطلان، و صاف حذف ذلك مثال صيغة؛ إعادة بناء لقطة أيضا سوف مقابل حساب بسبب استيراد فشل بينما ناقص بند.

Host SSE مهايئ تحويل اكتشاف لديه رسم تغير إشعار، و في اتصال وقت إرسال حالي كامل رسم. رسم وصف متصفح هدف بند، لا بديل جدول Host تنظيف إتمام:Host دورة الحياة ترتيب يخص ذلك Loader، كل متصفح فإن انتظار ذاته يتم إزالة fiber تنظيف. رسم مقابل حساب و شفرة إعادة بناء مشترك استخدام واحد صفحة طابور صف. محلي بديل حد منع توقف مرور مدة تحت تحميل تركيب؛ لا نفاذ واضح revision فقط مقارنة مقارنة متبادل انتظار. فشل صفحة تقرير إبلاغ محلي خطأ، و يمكن إعادة محاولة نفس ورقة رسم بينما لا تغيير Host تفعيل حالة. هذا إبقاء غير متصل صفحة حالة، أيضا بلا حاجة إعادة بدء تطبيق أو جذب دخول ثاني طقم إضافة منفذ.Electron مستقل تثبيت مسار لا يخص هذا آلية.

### حار إعادة تحميل: واحد قيادة إضافة، ذاتي سطر مراقبة نظر bundle

حار إعادة تحميل هو واحد بند تركيب قرار:web تركيب حزمة بلا شرط تركيب `client-hmr` سطر (واحد معتاد قاعدة إضافة حزمة) ، ذلك node نصف حمل قدوم bundle مراقبة نظر و SSE(Server-Sent Events) عبر طريق؛ لا يوجد إعادة بناء watcher تعديل كتابة عميل bundle وقت سلسلة مسار إبقاء فارغ خامل. لا ينبغي كشف هو تركيب يمكن منع استخدام هذا سطر.

إعادة بناء جيد bundle كيف ما تغيير صار إعادة تحميل إشارة؟hmr node نصف ذاتي ذات مراقبة——لا يوجد بناء جهاز قدوم إشعار هو. وحدة host في قراءة كل نسخة بدء لقطة قبل التقاط مدخل stat أساس خط، و عبر `ctx.clientModules.artifactBaseline(id)` كشف هو.HMR ذاتي حمل مفرد عدد تحديد وقت جهاز يأخذ حالي رسم كل row و هذا نسخة أساس خط مقارنة مقارنة: لم تغير row مباشر بدء مراقبة نظر، لا قراءة محتوى أيضا لا طلب ها أمل؛ أساس خط التقاط بعد كتابة قد شكل صار stat فرق مختلف، فقط لديه هذا row سوف دخول `rebuilt(id)`. هذا معا إزالة حذف بدء مدة كل كمية إعادة ها أمل، و تجنب فتح `fs.watchFile` بـ مختلف خطوة أول مرة stat بناء قيام أساس خط، ممكن ساكن صامت امتصاص استلام بنية صنع مدة إعادة بناء مشكلة. مراقبة نظر تجميع دمج عضو مع `onGraphChanged` تحديث؛ إزالة فقد row سحب تحت مراقبة نظر، جولة استفسار وقت ناقص مدخل فإن يجعل مقابل row إبقاء علامة قذر حالة، ملف إعادة الآن وقت أي جعل بيانات وصفية نفسه أيضا قوي صنع توليد جديد revision. مشترك tsdown مسبق ضبط سوف في كل sibling إخراج كتابة تمام بعد علامة `client.js`؛ مدخل mtime أو size تغير، أو row موضع في علامة قذر حالة وقت،`rebuilt(id)` من مدخل بايت و بناء إتمام ختم الوقت إرسال توليد revision. فقط تعديل chunk لذلك أيضا سوف أكثر تبديل revision؛ جزء كتابة بعد إتمام علامة أيضا سوف توفير مرة أكثر متأخر stat تغير بـ إتمام ذاتي شفاء.`rev` تغير وقت،node نصف في `GET /plugins/events` فوق واسع بث `rebuilt` لقطة——هذا هو واحد بند نظام درجة SSE عبر طريق، اتصال أي إرسال كل كمية رسم، تغيير وقت إرسال `rebuilt` لقطة، فقط توفير عرض wire، دائم لا دخول جلسة سجل. جولة استفسار هو لحظة معنى اختيار:inotify في weka شبكة تركيب فوق لا إطلاق، بناء جانب مراقبة نظر جهاز حاجة `--poll` أيضا هو نفس سبب؛ كل row كل بين فصل فقط يحتاج مرة مدخل stat، جولة استفسار بين فصل هو واحد مرور تحقق إعداد حقل (افتراضي 500ms) ،dispose(مورد تحرير) سوف صاف إسقاط ذلك واحد تحديد وقت جهاز. إعادة بناء ناتج عملية يجب استخدام مشترك Client tsdown مسبق ضبط؛`scripts/dev-web.ts` ما زال بصفة watch بناء مدخل إبقاء، ذلك حزمة بيان في بدء وقت مسح `packages/*/*/package.json` حسب dsh.client اكتشاف، بناء جهاز و host بين لا يوجد إشعار بروتوكول.

متصفح جانب نقل يأخذ شفرة استبدال تسليم إعطاء مسؤول رسم مقابل حساب نفس عدد modules تحكم جهاز:

1. `invalidate`——إسقاط قديم قديم factory و سجل، و يأخذ rebuilt لقطة revision ربط إلى هذا row مفرد مورد combo URL.Factory أيضا نشط حال سوف يجعل تحت واحد خطوة تغيير صار no-op.
2. `prefetch`——تحميل هذا مفرد مورد خارجي نص برمجي و تسجيل تسجيل جديد factory، قديم fiber هذا لحظة ما زال في خدمة دور. ابتدائي كثير مورد نص برمجي لن مجددا مرة تنفيذ.
3. `registry.delete`——أولا في أي fiber عملية. عار فعل fiber dispose سوف إطلاق vendored Loader ذاتي dispose فرع، يأخذ entry دائم دائم توقف استخدام.
4. ترتيب فارغ قديم fiber كل disposer.
5. إزالة اسم تحت `<style data-plugin>` وسم.
6. عبر وحدة نظام شيء تحويل جديد تصدير، مجددا استدعاء `entry.refresh()` من Loader تركيب.CSS في قديم disposer تنظيف إتمام بعد إعادة حقن؛ صريح شيء تحويل جعل استيراد خطأ قدرة كاف يتم التقاط، بينما لا فقط إبقاء تحت Loader تحكم منصة سجل.
7. `fiber.await()`——يجعل فشل كبير صوت إعادة رمي.

Bootstrap استبدال سوف في بطلان أو إزالة قبل يتم رفض: وحدة نظام إبقاء ذلك ابتدائي تصدير، إعادة تركيب قديم شفرة سوف إعادة وضع إزالة استهلاك من، لكن لا يمكن تطبيق طلب revision. صفحة سوف تقرير إبلاغ حاجة تحديث جديد، و إبقاء bootstrap fiber. كل غير bootstrap إضافة كل مشترك نفس طقم استبدال دلالة؛`immediately` سطر إعادة تحميل و lazy سطر قسم جزء لا فرق. اعتماد درجة ربط لا زهرة واحد سطر client شفرة:fiber تنشيط سجل عنصر سلسلة وصل حال هو كل خدمة مزود uid، لذلك استبدال connection انتظار أساس أساس provider fiber وقت، كل اعتماد جهة كل سوف مرور cordis ذاته إعادة تركيب تحميل——سلوك صحيح تأكيد، لكن بديل قيمة مقارنة عال.

إعادة تحميل سوف إنشاء جديد fiber و مكون حالة، لا إبقاء يتم استبدال إضافة داخلي React حالة. ساكن حالة تجميع مكتبة و تطبيق قشرة حاجة إعادة بناء بعد صفحة. استيراد أو تنشيط فشل ما زال يمكن تشخيص و إعادة محاولة، لن تراجع غير متصل إضافة. ذاتي إعادة تحميل إغلاق قديم SSE عبر طريق و فتح جديد عبر طريق؛ ذلك كامل لقطة تكملة متساو متروك تسرب رسم تغيير. بدء، رسم تحديث و إعادة بناء لقطة مشترك استخدام نفس طابور صف، لذلك شفرة استبدال لن و ابتدائي وحدة وصول إعادة تراكم.

## Consequences

Wire اثنان جانب تشغيل نفس نسخة معالجة إدارة تنفيذ؛ متصفح خاص لديه طبقة فقط يتضمن واحد طقم وحدة نظام و واحد إعادة تحميل إضافة. حركة حالة حزمة فقط لديه واحد نوع ناتج شكل، لذلك صاف درجة فحص تغطية الكل حركة حالة حزمة.Cordis اعتماد، وحدة طلب و بدء ملف موضع كل و ذلك كل من——manifest——نفس إقامة، مسؤول تركيب app فقط إمساك اسم سجل.Host graph تحقق و تمرير عودة طلب وصول جعل تزامن factory اعتماد إبقاء صريح. متصفح أصلي script تركيب تحميل إبقاء إضافة شبكة مورد، توليد bundle و TypeScript/TSX شفرة المصدر بين معيار خريطة، وحدة نظام أيضا فقط إبقاء واحد يمكن استبدال `loadBundle` خطاف.

قبول بديل قيمة:vendored Loader في متصفح داخل خلف حال خامل وضع آلة عنصر (EntryTree حفظ دائم هو no-op، قسم مجموعة/عزل لم استخدام) ؛ تطوير مدة كل مرة تعديل إضافة كل يلزم دفع مرة bundle إعادة بناء إضافة fiber إعادة تعليق؛graph `inject` row إشارة توجيه factory وصول، لكن خدمة متاح صفة ما زال هو تنشيط مرجعي، لذلك لا مطابقة سوف في settled مسح وقت طفو خروج؛ ساكن حالة UI مكتبة إبقاء مباشر فعلي جسم تصدير؛ كل bundle كثير خروج واحد نسخة sourcemap ناتج، خارجي script فشل أيضا فقط قدرة إعطاء خروج خشن حبة درجة URL تشخيص، لا يستطيع مثل صريح fetch ذلك مثال تقرير إبلاغ HTTP حالة.Host لـ حالي رسم و فوق واحد بديل بدء رسم إبقاء bundle لقطة و كسول صفة استجابة خطة. نص برمجي و map body في أول مرة `GET` بعد ذاكرة مؤقتة، لذلك داخل تخزين مع bundle لقطة و قد طلب استجابة body زيادة طويل. كل نسخة قد شيء تحويل استجابة في ذلك URL تحت إبقاء ثابت؛ إذا فوق واحد بديل map في إعادة بناء بعد عندئذ أول مرة يتم طلب، فإن سوف قراءة حالي map ملف.

اسم سجل يقع في web تركيب حزمة إعداد شجرة (`packages/bundle/web-app/cordis.patch.yml`) ؛`mountWebPlugins` و `CLIENT_PACKAGES` معتاد كمية قد إزالة فقد، إعادة مجموعة مرة نشر انتظار في استبدال yml/overlay.Graph تركيب جهاز يقع في `dsh-client-modules` node نصف، من parser مسبق تحميل Client face فإن ذاتي رفع متصفح وحدة جدول.Webserver متابعة بصفة بسيط عنصر توجيه تسجيل إضافة؛`/api/*` ربط، متصفح إقرار إثبات،RPC envelope و دقيق Fetch توجيه يخص Connection node نصف،Remote توزيع يخص API Gateway، تطوير مدة bundle مراقبة نظر و SSE عبر طريق يخص HMR node نصف.
