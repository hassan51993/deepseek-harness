# Agent Note: سير العمل إعادة استخدام PTC Node صندوق رملي

Status: implemented

[English](2026-09-13-workflow-ptc-sandbox-reuse.md) | العربية

## مشكلة

حركة حالة سير العمل تنفيذ نموذج تحرير كتابة JavaScript و بدء subagent.worker خط مسار يأخذ نص برمجي تنفيذ نقل خروج مضيف حدث حلقة، لكن هروب هروب VM شفرة يمكن استخدام Node و يملك مضيف عملية ملف إذن.PTC قد لديه Node عملية تنفيذ، مسؤول OS ملف قيد، عزل برنامج حالة، محدود إخراج و تحكم عبر معلومة، و تلقي إدارة تنظيف. صيانة ثاني طقم بدء جهاز سوف تكرار هذه مسؤولية.

## قرار

`dsh-workflow-ptc` عبر مشترك Node `PtcRuntime` تنفيذ `WorkflowEngine`. كل مرة تشغيل في واحد PTC عملية في إبقاء قائم VM و سير العمل مساعد مساعدة دالة.Host ربط سوف guest اتصال إلى إعداد subagent مزود و سير العمل مراقبة جهاز؛Host توفير إرسال بدء استدعاء Agent، و تحليل ذلك Session معتاد ضبط ملف سياسة و cwd.

VM تعريف مساعد مساعدة API، و تنسيق عمل صيغة تزامن،agent مجموع عدد و بند حد أعلى. هو لا هو أمان حد، هذه حساب عدد جهاز أيضا لا هو Host قوي صنع أمان إعداد مقدار. ملف قوي صنع،V8 كومة حد، إخراج و تحكم حد، تلقي إدارة عملية تنظيف ما زال من PTC و ذلك صندوق رملي/عملية فرعية مزود مسؤول. شبكة شبكة وصول و مزود خاص لديه قيد حد إبقاء و PTC نفسه.

سير العمل تنفيذ نقل دخول `timeoutMs: null`، صريح منع استخدام Node وقت التشغيل مرور مرور وقت تحديد وقت جهاز. حذف timeout أو استخدام عدد قيمة PTC طلب إبقاء إعداد قيمة افتراضية و حد أعلى؛`run_code` ما زال فقط قبول صحيح عدد تغطية قيمة. الأكثر أول VM قطعة مقطع إبقاء مستقل تزامن مهلة. استدعاء جهة في توقف إشارة (يشمل خارج طبقة أداة قطع توقف) ما زال سوف إلغاء سير العمل.

إلغاء قيام أي في توقف PTC عملية، و انتظار بدء و نشط وثب فرعي agent مشترك إشارة. مهايئ انتظار انتظار إتمام بدء و فرعي agent مورد تحرير، يشمل إلغاء بعد عندئذ إصدار فرعي agent.PTC إيقاف برنامج؛ قد إجراء في Host ربط ما زال من ذلك استدعاء جهة مسؤول. لا زيادة سير العمل تنظيف تحديد وقت جهاز، أيضا لا انتظار guest إلغاء تأكيد.

دخول درجة معا فقط استخدام واحد ربط استدعاء. أول دفعة تزامن إرسال بدء، لاحق حدث حسب ترتيب ترتيب طابور، و في فرعي agent مورد تحرير و نهائي نتيجة قبل إتمام نقل تمرير. هذا تجنب تجنب عادي سجل مفاجئ إرسال استهلاك كل PTC انتظار إتمام استدعاء حد أعلى. إلغاء سوف إيقاف مقابل فرعي agent نتيجة انتظار، لكن ما زال انتظار فرعي agent مورد تحرير.

Node جذب توجيه برنامج إرسال نهاية حالة لقطة بعد إبقاء تحكم إدارة طريق فتح، مباشر إلى Host سوف ذلك إغلاق. لم يتم انتظار ربط عودة تكرار ممكن ما زال في نقل، لذلك عملية فرعية رفع قبل إغلاق سوف يجعل `EPIPE` و قد إتمام برنامج نتيجة حدوث تنافس تنازع.

[حركة حالة سير العمل قرار](../feature/2026-07-05-dynamic-workflows.zh.md) إبقاء نص برمجي، بنية تحويل إخراج، حدث و أداة دلالة؛ هذا نص فقط يحل محل ذلك تنفيذ أساس قاع و معلومة مهمة تنفيذ.[صندوق رملي تحويل Node PTC قرار](2026-09-11-sandboxed-node-ptc-runtime.zh.md) إبقاء تنفيذ و تحكم حفظ إثبات؛ صريح null قطع توقف توسيع ذلك خدمة خيار.[agent أثر مجال وقت التشغيل تصميم](2026-07-12-agent-scope-runtime-design.zh.md#workflow-children-are-pending-starts-or-published-records) إبقاء انتظار بدء و فرعي agent تنظيف ملكية قاعدة.

## سبق اعتبار بديل خطة

**إبقاء worker-thread تنفيذ.** إنهاء worker لا يمكن تطبيق Session OS ملف سياسة، أيضا لا يمكن توفير مباشر Node شفرة الذي يحتاج تلقي إدارة عملية تنظيف.

**إنشاء مستقل سير العمل عملية فرعية وقت التشغيل.** آخر طقم بدء جهاز، تحكم نقل و صندوق رملي مهايئ سوف تكرار صيانة نفسه تنفيذ مسؤولية.PTC قد قبول برنامج و أداة اسم مختلف خطوة Host ربط، بلا حاجة حل أداة أو Session.

**استخدام مباشر Node سير العمل API استبدال VM.** VM و مساعد مساعدة دالة إبقاء قائم نص برمجي دلالة، تزامن قطعة مقطع مهلة و JSON شيء تحويل. تنفيذ OS قيد لا حاجة إزالة هو جمع.

**مقابل سير العمل تطبيق PTC عدد قيمة قطع توقف.** سير العمل ممكن انتظار واحد طويل سلسلة subagent. صريح `null` إبقاء استدعاء جهة تحكم دورة الحياة، لا تغيير عادي PTC قيمة افتراضية، أيضا لا يأخذ مهمة معنى كبير عدد قيمة عند عمل لا يوجد قطع توقف.

## عاقبة

سير العمل و صريح تفعيل Ralph تنفيذ مشترك PTC أمان و عملية دورة الحياة تنفيذ.Ralph في قد إصدار افتراضي تركيب في إبقاء منع استخدام. نص برمجي ما زال استخدام نفسه خطاف و نتيجة معلومة غلاف؛ لا زيادة جديد مرجعي دخول درجة منصة حساب أو Host فرعي agent عدد كمية إعداد مقدار.

إلغاء لا انتظار نص برمجي تنسيق عمل دفع دخول. مهايئ انتظار فرعي agent تنظيف، لذلك لا تنفيذ سطر دورة الحياة اتفاق subagent مزود ممكن تأخير متأخر مورد تحرير. عملية تنظيف إبقاء الذي اختيار عملية فرعية مزود مقابل تلقي إدارة نطاق حد؛ هذا تغيير لا إعلان تسمية عملية شجرة CPU/RSS حساب كمية أو عام مرة بعد بديل إنهاء حفظ إثبات.
