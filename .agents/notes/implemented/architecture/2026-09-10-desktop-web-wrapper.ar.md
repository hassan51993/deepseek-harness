# Agent Note: عبر مشترك Web تطبيق تشغيل Desktop

Status: implemented

[English](2026-09-10-desktop-web-wrapper.md) | العربية

[Electron وقت التشغيل قرار](2026-09-11-desktop-electron-node-runtime.ar.md) بديل مستقل فوق تنقل Node يمكن تنفيذ ملف اختيار؛ هذا نص أخرى قرار ما زال ملائم استخدام.

## Problem

مستقل Desktop تركيب و طلب نقل حاجة قسم آخر صيانة إعداد، وحدة تحميل، تدفق صيغة استجابة و مورد خدمة سلوك. أي جعل مشترك تصيير واجهة، هذه تنفيذ أيضا ممكن متروك تسرب Web وظيفة.Desktop حاجة مستقل تثبيت و أصلي تحكم عنصر، لكن لا حاجة ثاني طقم تطبيق خلفية.

## Decision

خاص Desktop Host إبرة مقابل مستقل ملكية Desktop profile استدعاء CLI مشترك profile runner. كامل Web تركيب مسؤول إقرار إثبات،HTTP توجيه، عميل مورد،RPC و استجابة تدفق.Electron في عملية فرعية حينئذ خيط قبل تحميل تحزيم ساكن حالة Web مورد. عملية فرعية IPC تحمل تحميل حينئذ خيط، بنية تحويل بدء حقن و إغلاق.[قيام أي عرض نافذة قرار](2026-09-09-desktop-immediate-window-and-direct-start.ar.md) قاعدة تحديد محلي وثيقة HTTP تحويل إرسال و إقرار إثبات WebSocket وصول؛Web إبقاء تطبيق قسم إرسال و تدفق لقطة معالجة.

مشترك runner مسؤول profile و Harness-home patch، بديل إدارة ضبط، بعيد قياس قيمة افتراضية، وحدة تكملة كل، إعداد إعادة تحميل و تطبيق دورة الحياة.Desktop من مشترك Web نموذج لوح ابتدائي تحويل profile، و في رئيسي تطبيق في استخدام ذلك إضافة إدارة جهاز.Electron مسؤول نافذة، قائمة مفرد، أصلي دليل اختيار، استعادة و إصدار تحديث.

[داخل وضع وقت التشغيل قرار](2026-09-08-desktop-bundled-runtime-and-external-plugins.ar.md) إبقاء مستقل وقت التشغيل و إضافة تخزين، داخل وضع pnpm، و واضح حزمة ملكية. عام CLI متابعة رفض إبقاء Desktop profile.Electron profile دقيق تجهيز و أصلي استعادة في Host غير ممكن استخدام وقت ما زال يمكن تنفيذ.

مستقل حزمة ملكية منع توقف CLI و Desktop تعديل ذاك هذا تثبيت، لا بديل جدول Desktop اعتماد أكثر صارم إطار إضافة سياسة.Desktop سوف registry،store،Git،tarball، محلي مسار و عادي حزمة تثبيت تسليم إعطاء pnpm، و التزام دوران صحيح معتاد مستخدم و profile إعداد.Host وراثة `NODE_OPTIONS`،`NODE_PATH` و npm/pnpm بيئة متغير. مستخدم بناء إعداد قرار أي بعض اعتماد دورة الحياة نص برمجي يمكن تنفيذ. هذا بـ Web استخدام نفسه حزمة إدارة جهاز و تحميل جهاز مسؤولية يحل محل Desktop مخصص استخدام مصدر، بيئة و بناء حد.

مشترك Web إضافة إدارة جهاز مسؤول تثبيت، تنشيط، خطأ و إعادة بدء اشتراط.Electron لا توفير مستقل إضافة إدارة مصير،preload،shell مورد توجيه، إضافة IPC أو حزمة تغيير منفذ. تحزيم واضح اختيار رئيسي مدخل و تطبيق preload، تجنب تجنب قديم بناء ناتج إعادة حمل دخول قد حذف جسر وصل.

مشترك `initProfile` إنشاء ناقص profile ملف و إبقاء قائم محتوى.Host `healIsolatedProfileModuleFallback` هو تثبيت حزمة و bundle إسقاط وحيد ملكية جهة؛ حزمة عملية في pnpm قبل عبر مشترك `unlinkProfileModuleFallback` فقط قسم مغادرة هو ذاتي ذات يملك رابط.pnpm إدارة دليل إبقاء أولوية.Desktop لا صيانة ثاني طقم وقت التشغيل حالة، قفل ملف ها أمل أو رابط تنسيق ضبط آلية.`desktop-runtime-state.json` مرة صفة تنظيف فقط إزالة و سجل مطابقة رابط، و صاف حذف هذا بيانات وصفية.

هذا سجل جزء يحل محل[تحزيم قرار](2026-08-25-electron-desktop-packaging-and-updates.ar.md) في خاص تركيب و بلا طرف فتحة نقل. هذا تصميم تجنب تجنب استماع طرف فتحة، و استخدام قسم لقطة بايت إدارة طريق تجنب تجنب Base64 تمدد انتفاخ و عبر إصدار V8 تسلسل تحويل. مشترك HTTP وضع ترك بلا طرف فتحة حفظ إثبات، سوف خدمة و إقرار إثبات تسليم إعطاء قد لديه Web تنفيذ. إصدار هوية، توقيع، عملية ملكية و أصلي قشرة وظيفة ما زال هو صالح قرار.

محلي تطبيق أصلي دليل اختيار عبر ضيق preload IPC استدعاء Electron نافذة الذي تابع محادثة إطار.Main فقط قبول حالي تطبيق نافذة في يقع في `dsh-app://app` رئيسي إطار هيكل طلب؛shell، بعيد مسار صفحة و فرعي إطار هيكل متساو لا يستطيع استدعاء. تزامن طلب مشترك استخدام انتظار إتمام محادثة إطار، نافذة إلغاء تدمير بعد إسقاط اختيار نتيجة.Web خلفية اختيار و Host تصفح تصفح من مشترك تنفيذ مسؤول.

## Alternatives considered

**في Electron في استخدام Host عملية نظام اختيار جهاز.** Host macOS AppleScript محادثة إطار لا يوجد Electron أب نافذة، لا يمكن يمكن اعتماد تتبع مع تطبيق تركيز نقطة.Electron مسؤول محلي محادثة إطار،Web إبقاء Host اختيار جهاز؛ إلغاء و خطأ لن بدء ثاني عدد اختيار جهاز.

**صيانة ثاني طقم خلفية تركيب و نقل.** هذا سماح تطبيق لا استماع طرف فتحة، لكن كل بند Web توجيه، إعادة تحميل سلوك، إقرار إثبات تغير و تدفق صيغة قدرة كل حاجة Desktop تنفيذ أو واضح حذف. فقط لديه لا يمكن استخدام Web تنفيذ، كما كاف بـ تحمل تحمل حمل متابعة صيانة صار هذا طاولة وجه منتج يحتاج طلب، عندئذ دعم حمل إعادة جذب دخول هذا نوع خطة.

**دمج CLI و Desktop إضافة تثبيت.** مشترك بدء شفرة لا اشتراط مشترك يمكن تنفيذ اعتماد. مستقل تثبيت سماح قسم آخر تحقق استلام إصدار و إضافة إصدار، مشترك جلسة و ضبط فإن ما زال من قد لديه بيانات ملكية جهة مسؤول.

**إبقاء Desktop رابط حساب هذا و manifest تنسيق ضبط جهاز.** هذه آلية تكرار مشترك profile منطق، و ممكن بسبب إرسال توليد بيانات وصفية عائم نقل بينما رفض أصل هذا متاح تثبيت. مفرد واحد وحدة تكملة كل ملكية جهة يمكن حفظ حماية pnpm دليل، بلا حاجة في إضافة profile في صيانة إصدار هوية.

**إبقاء مستقل أصلي إضافة إدارة صفحة.** هو يمكن في Web Host غير ممكن استخدام وقت تشغيل، لكن تكرار صيانة حزمة عملية، مصير IPC، محلي تحويل و خلفية إعادة بدء معالجة. أصلي استعادة قد قدرة في لا يوجد Host وقت منع استخدام رقم ثلاثة جهة bundle و تجهيز نسخة profile patch. فقط لديه ظهور هذا استعادة طريقة لا يمكن توفير إصلاح عملية وقت، عندئذ ينبغي إعادة جذب دخول.

**ثابت registry و store، مرور ترشيح وقت التشغيل بيئة، و فقط سماح دفعة دقيق إضافة مصدر.** هذه قاعدة حد تنفيذ و حزمة اختيار، لكن جعل نفس مستخدم إعداد في Desktop و Web في إنتاج مختلف سلوك. مستقل تثبيت ملكية بلا حاجة هذه حد ما زال لديه استخدام.Desktop مخصص استخدام حد حاجة مستقل منتج يحتاج طلب، لا يستطيع فقط من تحزيم أو إضافة عزل دفع توجيه بينما قدوم.

## Consequences

Desktop عبر نفسه بدء و خدمة مسار وراثة Web وظيفة.HTTP استماع ملكية و إقرار إثبات ما زال يخص تطبيق بدء.Electron استخدام تقرير إبلاغ Host عنوان، و في حينئذ خيط قبل بعد إبقاء قائم Web وثيقة. مشترك Web تحميل صفحة في Host بدء قبل متاح؛ أصلي استعادة في بدء فشل وقت ما زال متاح.

مستخدم اختيار وقت التشغيل خيار، حزمة مصدر و سماح دورة الحياة نص برمجي ممكن أثر Host تنفيذ، تحميل رقم ثلاثة جهة شفرة أو صنع صار بدء فشل. مشترك Web إدارة جهاز مسؤول حزمة عملية فشل معالجة؛Electron لـ يؤدي أمر بدء فشل إبقاء أصلي استعادة. توقيع نواة قلب وقت التشغيل لا لـ مستخدم تثبيت إضافة شفرة خلف كتاب.

تحقق حاجة تغطية مشترك runner، إقرار إثبات HTTP مورد و API نقل، إعداد إعادة تحميل، أصلي دليل اختيار، عملية فرعية إغلاق و إضافة فشل استعادة. تثبيت بعد منصة تحقق استلام و حقيقي نموذج GUI تحقق استلام مستقل في اختبار وحدة؛ هذا سجل لا صوت تسمية قد قياس نيل بدء أو نقل رفع رفع.
