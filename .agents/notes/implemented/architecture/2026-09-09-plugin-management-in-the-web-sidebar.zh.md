# Agent Note: إضافة إدارة نقل إلى Web جانب شريط

Status: implemented

[English](2026-09-09-plugin-management-in-the-web-sidebar.md) | العربية

## مشكلة

قد تثبيت حزمة يخص تشغيل في profile، بينما ضبط هو تغطية في Session فوق نابض نافذة. إدارة صفحة حاجة سعة قبول حزمة تفصيل حال و تثبيت إخراج. تخطيط[عام رئيسي وجه لوح](2026-09-08-global-main-panels.zh.md) توفير مقابل دورة الحياة و فضاء.

## قرار

**إدارة يقع في جانب شريط، إعداد إبقاء في ضبط في.** `ui-plugin-manager` في `plugins` تحت تسجيل `sidebar.panellist` مدخل و هو فتح `main` وجه لوح. صفحة عبر[إضافة إدارة جهاز](2026-09-14-current-profile-plugin-management.zh.md) Remote إدارة profile تركيب حزمة و ذلك سطر، عرض تثبيت إخراج، و تأكيد إزالة. صفحة فقط صف خروج قد تثبيت تركيب حزمة. ضبط إضافة قسم منطقة إبقاء عام إعداد بطاقة، جانب حافة هو فقط قراءة «إضافة قائمة» وسم صفحة، مع تثبيت توفير تركيب حزمة (`dsh-base`،`dsh-web-app`) في ذلك داخل فحص نظر؛ هذا وسم صفحة اثنان عدد قسم مجموعة افتراضي استلام بدء، كما لا حمل أي إدارة تحكم عنصر.

**واحد store تتبع مع Host حالة.** إدارة جهاز تحكم جهاز يأخذ `listBundles` و `listPlugins` دمج صار كل تركيب حزمة واحد نسخة عرض، حسب بيان `managementAvailable` حكم تحديد متاح صفة، في إدارة عملية بعد، استلام إلى `plugin-manager/changed` وقت و إعادة وصل بعد تحديث جديد، و حسب الذي تابع job حفظ تثبيت دخول درجة. إعداد بطاقة استخدام أصل لديه عام settings ربط.

**تثبيت نتيجة يخص مرة طلب.** كل مرة تثبيت أو إعادة محاولة كل توليد جديد طلب ID، محادثة إطار حسب هذا ID غربلة اختيار Host دخول درجة، سجل و إرجاع نتيجة. إلغاء تأكيد ممكن أولا في أصل add استجابة وصول، لذلك قديم استجابة لا يستطيع انتهاء مع بعد إعادة محاولة. إلغاء اعتماد إدارة جهاز واضح تنظيف تأكيد؛ محلي RPC إلغاء و قطع خط متساو لا يمثل pnpm قد إيقاف. دخول إعداد تطبيق مرحلة مقطع بعد إغلاق إلغاء نافذة.

## اعتبار مرور بديل خطة

**استخدام واحد ضبط قسم منطقة فتح إدارة صفحة.** مرفوض: محادثة إطار غطاء إقامة رئيسي صف، هذا مثال مدخل يجب أولا صلة إسقاط ضبط عندئذ قدرة عرض صفحة.

**يأخذ إعداد وضع في إضافة صفحة فوق.** مؤقت لا قبول، إدارة من رؤية قرار؛ انتظار ضبط قدرة حسب قسم منطقة فتح بعد، هو سوف تغيير صار إضافة صفحة فوق واحد رابط.

## عاقبة

web bundle وجه لوح قائمة لم يعد لـ فارغ:**إضافة**مدخل يقع في جديد بناء جلسة و مساحة العمل بين. ضبط «إضافة» قسم منطقة إبقاء اثنان عدد وسم صفحة: إعداد صفحة و فقط قراءة «إضافة قائمة».`apps/web/tests/plugin-manager.e2e.ts` مرور جانب شريط وصول إدارة جهاز،`plugin-config` و `settings-chrome` مشهد و golden مع لـ تحديث.

## اختبار

`packages/client/ui-plugin-manager/tests` تثبيت إقامة نفس id تحت اثنان موضع تسجيل و صفحة تصيير؛`packages/client/ui-settings-plugins/tests` تثبيت إقامة لا يوجد وسم بند مفرد واحد مساهمة؛ فوق وصف web e2e مشهد في قدم يد هيكل فوق قيادة وجه لوح و قسم منطقة.
