# Agent Note: في تحزيم وقت تحقق Desktop إصدار توافق صفة

Status: implemented

[English](2026-09-09-desktop-build-release-validation.md) | العربية

## مشكلة

قشرة و وقت التشغيل وصف ملف واحد بدء إصدار. كل مرة بدء مقارنة مقارنة منها إصدار معلومة سوف تكرار تحزيم فحص، لكن لا يستطيع إثبات قد تثبيت يمكن تنفيذ ملف بايت و وصف ملف متسق.

## قرار

تحزيم تحقق جهاز مسؤول وصف ملف schema،shell إصدار، منصة، هيكل بنية، إعلان Host بروتوكول إصدار، و Node/pnpm semver تحقق. بدء قراءة دقيق تجهيز profile الذي يحتاج حقل، و إبقاء مشترك حزمة سجل و Host مدخل فحص. فعلي Host ready رسالة ما زال تحقق ذلك بروتوكول إصدار.

هذا قرار جزء يحل محل[داخل وضع وقت التشغيل قرار](2026-09-08-desktop-bundled-runtime-and-external-plugins.ar.md) في بدء إصدار توافق صفة فحص. هذا سجل متابعة مسؤول حزمة ملكية و توزيع إدارة من.

## اعتبار مرور بديل خطة

تكرار مقارنة مقارنة وصف ملف قدرة أكثر مبكر تشخيص خلط تركيب، لكن لا يستطيع إثبات يمكن تنفيذ ملف كامل صفة. إعادة جذب دخول هذه مقارنة مقارنة حاجة أداة جسم تثبيت لذا عائق، كما تحزيم تحقق و فعلي Host تشخيص لا يمكن ملء قسم حل تفسير هذا لذا عائق.

## عاقبة

بدء لن فقط بسبب وصف ملف إعلان إصدار schema، هدف أو Host بروتوكول مختلف، أو Node/pnpm إصدار نص لا هو semver بينما رفض تشغيل. تحزيم ما زال رفض هذه حال حال و shell إصدار لا مطابقة. اختبار منطقة قسم بدء قراءة و تحزيم تحقق.
