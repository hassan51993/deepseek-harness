# Agent Note: داخل وضع Desktop وقت التشغيل و إبقاء خارجي إضافة

Status: implemented

[English](2026-09-08-desktop-bundled-runtime-and-external-plugins.md) | العربية

إضافة إدارة و أصلي استعادة التزام دوران[مشترك Web رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md).

[Electron وقت التشغيل قرار](2026-09-11-desktop-electron-node-runtime.ar.md) بديل مستقل فوق تنقل Node يمكن تنفيذ ملف اختيار؛ هذا نص أخرى قرار ما زال ملائم استخدام.

## مشكلة

Desktop ابتدائي تحويل وقت تثبيت نواة قلب اعتماد رسم، سوف تكرار إصدار بناء جهاز اكتمل عمل. مغادرة خط store إزالة حذف تحت تحميل، لكن ما زال لديه حل ضغط، حزمة إدارة جهاز بدء و تثبيت صار هذا. مستخدم حاجة تطبيق في إنتاج اعتماد قد حينئذ خيط وقت بدء، معا إبقاء عادي npm إضافة تثبيت قدرة، و عبر تطبيق ترقية إضافة حالة.

قسم مغادرة حزمة دليل ممكن تحميل تكرار Cordis أو خدمة وحدة. فقط إبقاء إضافة ملف أيضا لا يستطيع إثبات هو و جديد مضيف API أو Node وقت التشغيل توافق.

## قرار

[وقت التشغيل دقيق تجهيز](../../../../apps/desktop/scripts/prepare-dsh.ts) في بناء وقت شيء تحويل مرة إنتاج اعتماد رسم، و عبر `extraResources/dsh` توزيع.Electron قشرة إبقاء في ASAR في.Electron RunAsNode عملية من مورد بدء خاص Desktop Host، و من `$DSH_HOME/profiles/desktop` تحميل قد تفعيل إضافة.

هذا سجل مسؤول نواة قلب مورد تخزين و خارجي إضافة اعتماد.[تحزيم قرار](2026-08-25-electron-desktop-packaging-and-updates.ar.md) إبقاء إصدار هوية، توقيع، عملية ملكية و فقط حد Electron إضافة تخويل.[رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md) مسؤول مشترك Web بدء و HTTP نقل.

## حزمة ملكية

مورد وصف ملف سجل دقيق إصدار إصدار،Node إصدار، منصة، هيكل بنية، مشترك حزمة إصدار و نهائي ملف ها أمل. وقت التشغيل شجرة يتضمن عادي ملف و دليل، لا يتضمن إشارة عودة pnpm بناء store رابط. أصلي Mach-O ملف أولا توقيع مجددا ها أمل؛ تطبيق توقيع جهاز إبقاء ذلك بايت، و في توقيع بعد فحص بيان. واضح `dsh/node_modules` مورد خريطة التفاف مرور electron-builder مقابل أصل `node_modules` ترتيب حذف، و في أي توقيع أو عام إثبات قبل تحقق نسخ بعد اعتماد شجرة.

[طاولة وجه ملف قاعدة](../../../../apps/desktop/scripts/runtime-file-policy.ts) في إنتاج npm اعتماد تثبيت بعد، أصلي توقيع أو وصف ملف توليد قبل تنفيذ.npm إصدار قائمة خدمة في مكتبة استخدام من، يمكن يتضمن إعلان،map، اختبار و أصلي بناء إدخال، لا يستطيع مباشر يمثل طاولة وجه عملية حاجة أي بعض ملف. طاولة وجه فرعي هذا ترتيب حذف إعلان و قد تعرف آخر source map، لأن Host تنفيذ JavaScript و توليد Typert ناتج.Host وراثة مستخدم بيئة. قد إصدار npm حزمة و خارجي إضافة دليل إبقاء كل منها ملف. شفرة المصدر ضبط تجربة تنقل من تطوير حزمة توفير.

حزمة مخصص استخدام ترتيب حذف بند يشمل Domino اختبار،fs-ext تحرير ترجمة ناتج،Koffi Windows استيراد مكتبة، و غير هدف منصة node-pty مسبق بناء ملف و ضبط تجربة رمز رقم. قاعدة إبقاء أصلي يمكن تنفيذ اعتماد،node-pty ConPTY مصدر توزيع محتوى، سماح يمكن إثبات و لم معرفة مورد؛ عرض عام ترتيب حذف `src`،`test`،`.ts` أو `.map` ممكن إزالة يمكن تنفيذ شفرة أو وقت التشغيل بيانات. نسخ اختبار إبقاء مراقبة جندي مورد و غلاف تخزين مرور ترشيح بعد بيان؛Electron [ناتج smoke](../../../../apps/desktop/tests/fixtures/runtime-payload-smoke.mjs) تحقق PTY إخراج، أصلي ملف تحديد موضع،FFI، رسم مثل تحويل و HTML تحليل. وقت التشغيل دقيق تجهيز ما زال سوف تحقق كل إبقاء بايت، و يحمل خارجي إضافة بدء كامل Host.

مشترك profile runner في Desktop profile داخل تكملة كل تثبيت حزمة و اختيار في bundle ناقص اعتماد.pnpm تثبيت حزمة أولوية. رابط عبر صحيح معتاد Node تحليل إشارة نحو حقيقي حزمة دليل، لذلك Host و إضافة استيراد نفس تصدير وقت مشترك ذلك وحدة نسخة. مختلف ESM و CommonJS شرط تصدير ما زال هو مختلف مدخل؛ رابط لا يستطيع دمج حزمة مزدوج إعادة تنفيذ.

خارجي إضافة استخدام صحيح معتاد Node حزمة تحليل.Desktop لا تمرير عودة فحص peer إصدار، تكرار حزمة، رابط حزمة أو فوق درجة دليل اعتماد تحليل. هذه فحص تكرار حزمة إدارة جهاز و تحميل جهاز مسؤولية، و رفض pnpm دعم حمل تثبيت مصدر. مشترك تكملة كل رابط توفير ناقص حزمة، لكن إضافة يمكن تحليل إلى آخر نسخة قد تثبيت فرعي هذا؛ لا توافق إضافة ممكن في Host بدء وقت فشل، حاجة عبر مستقل قشرة UI استعادة.

profile manifest قسم آخر سجل pnpm تثبيت اعتماد و قد تفعيل bundle قائمة. منع استخدام إضافة إبقاء ذلك حزمة، قفل ملف بند و مستخدم إعداد.[رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md) سوف ابتدائي تحويل،bundle تنسيق ضبط و وحدة رابط تسليم إعطاء مشترك app-boot helper؛Desktop لا حفظ مستقل رابط حساب هذا أو وقت التشغيل حالة هوية.

## أمر خدمة و ترقية

أول مرة بدء إنشاء profile بيانات وصفية و مضيف رابط، لا تشغيل pnpm، و إبقاء غير متصل ملف. توافق إصدار تغير أو تطبيق نقل حركة سوف مباشر تحديث جديد رابط.Node إصدار، منصة أو هيكل بنية تغير وقت إبقاء قد تثبيت إضافة؛ تثبيت و توافق صفة خطأ من pnpm و تحميل جهاز تقرير إبلاغ.

مشترك حزمة دليل استخدام أصلي مواصفة مسار تعرف آخر.Windows بدء جهاز ممكن تغيير مسار كبير صغير كتابة بينما لا نقل حركة تطبيق؛ نص متبادل انتظار حكم قطع سوف إطلاق لا لا بد يلزم profile دقيق تجهيز.profile تنظيف في إزالة حقيقي دليل قبل، صريح حل حذف كل واحد تضمين طقم دليل رابط.Windows تجهيزة في Electron 44 تحت تكرار الآن تمرير عودة `fs.rmSync` امتداد تضمين طقم junction حذف هدف ملف، بينما داخل وضع فوق تنقل Node 24.17 سوف إبقاء هو جمع. لذلك تنظيف تحقق استلام يتضمن حقيقي Electron وقت التشغيل؛ فقط في Node تحت اختبار لا يستطيع إثبات هدف ملف سوف إبقاء.

مشترك[إضافة إدارة جهاز](../../../../packages/boot/plugin-manager/README.ar.md) مسؤول دعم حمل حزمة قاعدة إطار،bundle تحقق، تنشيط و تثبيت فشل معالجة. داخل وضع pnpm قراءة صحيح معتاد مستخدم و profile ضبط. تطوير نمط استخدام نفسه Web إدارة جهاز عملية مستقل Desktop profile، مساحة العمل حزمة من تطوير وقت التشغيل توفير.

مشترك Web إضافة إدارة جهاز مسؤول حزمة تغيير و تنشيط؛Electron إبقاء profile دقيق تجهيز و أصلي استعادة.[Web رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md) مسؤول هذه مسؤولية.

[قيام أي عرض نافذة قرار](2026-09-09-desktop-immediate-window-and-direct-start.ar.md) مسؤول مباشر بدء Host.Web تطبيق لا يمكن بدء وقت، أصلي استعادة محادثة إطار يمكن منع استخدام رقم ثلاثة جهة bundle و تجهيز نسخة profile patch. قد تثبيت إضافة ملف إبقاء بـ توفير إصلاح.

## اعتبار مرور بديل خطة

كامل وقت التشغيل تحقق يخص تحزيم مسار. بدء قراءة مورد وصف ملف، و فحص مشترك حزمة سجل و لا بد يلزم Host مدخل.[إصدار تحقق قرار](2026-09-09-desktop-build-release-validation.ar.md) سوف إصدار و هدف توافق صفة فحص تسليم إعطاء تحزيم مسار. بدء حيث لا قطعة رفع قد تثبيت وقت التشغيل ملف، أيضا لا حساب حساب ذلك ها أمل. خلفية تحميل قبل قراءة كل ملف سوف زيادة و توزيع جسم تراكم صار صحيح مقارنة I/O؛ غير ممكن استخدام وحدة تعديل من تحميل وقت فشل كشف. بناء وقت تحقق حسب سجل بيان رفض محتوى تغير، ناقص، كثير بقية أو رابط ملف.

- **بدء وقت تثبيت داخل وضع مغادرة خط seed.** هذا إبقاء عادي pnpm تثبيت مسار، لكن سوف في كل منصة تلقي أثر آلة جهاز فوق تكرار نواة قلب حل ضغط و تثبيت. شيء تحويل مورد إزالة حذف هذا جزء عمل، بديل قيمة هو أكثر كثير تطبيق ملف و إصدار بناء جهاز مسؤولية مهمة.
- **قوي صنع إضافة استخدام Host اعتماد إصدار.** هذا سوف يجعل عادي إضافة اعتماد لا لا بد يلزم أرض اقتران دمج في Host. مشترك وحدة تكملة كل توفير ناقص حزمة،pnpm يملك بند إبقاء مستقل إصدار.
- **استخدام صلب رابط.** هو لا يستطيع يمثل دليل، ممكن لا يمكن عبر لفة، مشترك يمكن كتابة بايت، و في تطبيق استبدال بعد إبقاء قديم inode. دليل لين رابط و Windows junction قدرة جدول بلوغ مسبق مدة حزمة هدف.
- **استخدام `NODE_PATH` أو إبقاء لين رابط مسار.** هو جمع لا يستطيع توفير موحد واحد ESM تحليل أو مشترك وحدة هوية. عبر واضح رابط إجراء صحيح معتاد حزمة فحص بحث يمكن مباشر اختبار.
- **يأخذ نواة قلب حزمة إبقاء في ASAR.** عادي `extraResources` إبقاء أصلي تحميل و عملية فرعية مسار.ASAR حاجة مفرد وحيد تحقق حزمة تحليل.

## أثر

أول مرة بدء و توافق ترقية لا تثبيت نواة قلب حزمة. بيانات وصفية فحص و خلفية تحميل ما زال حاجة بدء وقت؛ لا يوجد قياس كمية قبل، لا صوت تسمية إصدار بدء تأخير متأخر أو تحت تحميل جسم تراكم تعديل حسن. إضافة إبقاء بـ مضيف API و أصلي وقت التشغيل توافق لـ شرط، شرط لا ممتلئ كاف وقت توفير مرئي استعادة مدخل.

[Desktop README](../../../../apps/desktop/README.ar.md) مسؤول عملية شرح. تحديد نحو اختبار تغطية حقيقي pnpm تثبيت و قد دفعة دقيق بناء، مشترك ESM نسخة هوية، خاص اعتماد إصدار، تطبيق نقل حركة، توقف استخدام إضافة، وقت التشغيل تغير وقت إبقاء إضافة، تنشيط فشل و أمر خدمة قفل. توقيع تثبيت ناتج ترقية،macOS عام إثبات،Windows junction و أصلي سلوك، إصدار جسم تراكم و بدء أساس دقيق، و حقيقي نموذج GUI تسجيل صنع ما زال هو إصدار بيئة تحقق استلام اشتراط؛ وحدة تجهيزة لا يستطيع بديل هذه تحقق.
