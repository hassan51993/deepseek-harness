# Agent Note: DeepSeek LLM API جلسة سجل و إضافة حزمة طلب توسيع

Status: implemented

[English](2026-08-21-deepseek-llm-api-request-extensions.md) | العربية

## مشكلة

مرجعي جلسة سجل يتضمن طلب حد، أصلي استجابة قسم قطعة، تجميع بعد رسالة، أداة نشط حركة، إضافة حدث و فشل واقع، نموذج رسالة قائمة لا يمكن إبقاء الكل محتوى.OTel جلسة بعيد قياس مسار مستقل في نموذج طلب إسقاط و دفعة معالجة هذا سجل، استخدام نشر جهة اختيار مشترك نمط، و لحظة معنى إسقاط كبير كثير عدد assistant قسم قطعة. لذلك،DeepSeek رسمي جهة API لا يمكن من عادي طلب رسالة أو بعيد قياس تدفق إعادة بناء كامل harness مسار أثر.

مزود جانب تشخيص أيضا حاجة إنتاج حالي طلب تأكيد قطع تخزين نشط إضافة حزمة إصدار. قائم موجه إلى متصفح إضافة بيان سوف تقرير إبلاغ قد إعداد Loader بند إعداد و دورة الحياة مرحلة مقطع، لكن حيث لا يملك حزمة manifest(بيانات وصفية بيان) تحليل، أيضا لا يملك طلب Agent standing preset تركيب.

اثنان عدد قيمة كل فقط يخص DeepSeek رسمي جهة مهايئ مسار. يأخذ هو جمع إضافة دخول `GenerateOptions` أو مزود غير متصل LLM seam، سوف يجعل pi-ai و لم قدوم كل مهايئ وصل لمس DeepSeek بروتوكول عام فكرة.

## قرار

`@deepseek-ai/dsh-deepseek-llm-api-extensions` تسجيل `ctx.deepseekLlmApiExtensions`، أي `deepseek-official` طلب متن قمة طبقة حقل زيادة كمية سجل التسجيل. مساهمة جهة عبر `register()` إقرار قيادة واحد مرور إعلان دمج حقل. مهايئ في تسلسل تحويل تأكيد قطع بروتوكول رسالة بعد استدعاء `prepare()`، نقل دخول طلب إلغاء إشارة، في HTTP قبل رفض دقيق تجهيز فشل أو أساس أساس حقل اندفاع مفاجئ، دمج قسم مغادرة حقل، و في HTTP 2xx بعد استدعاء التقاط `accept()` أمر خدمة. أي جعل مساهمة جهة تجاهل اختصار إشارة، سجل التسجيل أيضا سوف في إلغاء بعد إيقاف انتظار دقيق تجهيز. قبول فشل ما زال بـ `REQUEST_EXTENSION` جعل طلب فشل؛ نقل فشل و غير 2xx فشل أبدا سوف قبول مساهمة. لم تركيب سجل التسجيل تركيب سوف إبقاء يمكن إعادة استخدام أساس أساس مهايئ. مع مرفق تركيب سوف تركيب سجل التسجيل و اثنان عدد مساهمة جهة: إضافة حزمة بيانات وصفية و جلسة سجل فوق نقل متساو افتراضي فتح بدء؛ حسب[افتراضي فوق نقل قرار](2026-09-14-session-log-upload-default.ar.md) ، ضبط `session-log-deepseek.enabled: false` يمكن إغلاق سجل فوق نقل. بلا مفتاح `deepseek-official` إعادة تشغيل سوف استخدام دمج صار فارغ أساس أساس متن تنفيذ دقيق تجهيز، و في رقم واحد قد سجل قسم قطعة قبل استدعاء نفس قبول أمر خدمة؛ هو إبقاء هو 2xx بعد توسيع فرعي أثر، بينما غير حقل بايت.

مزود غير متصل `llm` حزمة و `llm-pi-ai` لا يتضمن أي توسيع نوع، خدمة فحص بحث، حقل دمج أو قبول استدعاء.

## زيادة كمية جلسة سجل حقل

`@deepseek-ai/dsh-session-log-deepseek` يملك افتراضي فتح بدء `dsh_session_log` حقل. تفعيل بعد، كل يحمل تخزين نشط جلسة id طلب كل سوف إرسال هذا تأكيد قطع جلسة هوية الأكثر كبير حمل دائم `session-log-deepseek/delivery-accepted` ماء موضع بعد وصل متابعة مرجعي حدث بعد لاحقة. هذا حقل يتضمن غير ممكن تغيير جلسة header و كامل حدث معلومة غلاف.2xx سوف لـ قد إرسال `throughSeq` إلحاق جديد ماء موضع؛ هذا حدث سوف دخول تحت مرة طلب بعد لاحقة.Fork سجل سوف إبقاء أب درجة ماء موضع id، لذلك فرعي جلسة سوف في ذاتي ذات هوية تحت من تسلسل صفر بدء. تزامن قبول ممكن فوضى ترتيب وصول، الأكثر كبير ماء موضع ما زال إبقاء مرجعي. عملية داخل fold سوف يجعل كل بند جلسة حدث فقط يتم مسح مرة، و زيادة كمية إزالة استهلاك لاحق إلحاق؛ جديد جلسة كائن أو HMR generation سوف من حمل دائم تاريخ إعادة بناء هذا fold.

فشل جهة نحو لـ حتى قليل مرة. نقل فشل أو مزود رفض لن سجل ماء موضع. بعيد طرف قبول بعد، ماء موضع حفظ دائم قبل حدوث انهيار انهيار، سوف في استعادة بعد إطلاق إعادة وضع، أبدا سوف قفز مرور تسلسل. قائم جلسة فحص نقطة سوف حفظ دائم هذا حدث؛ فوق نقل إضافة لا يملك ثاني نسخة تخزين.

`events` عدد مجموعة سوف مباشر يتضمن كامل مرجعي `SessionEvent` كائن. إرسال جهة سوف نسخ حدث كل قد لديه عضو، لا تنفيذ إسقاط أو انفصال حساس؛ هذا حقل ذاتي يتضمن، بلا حاجة أصل حسب `messages` إعادة بناء محتوى.

## إضافة حزمة حقل

`@deepseek-ai/dsh-plugin-package-inventory-deepseek` من `llm` حزمة بيت عائلة في يملك افتراضي فتح بدء `dsh_plugin_packages` حقل. هو سوف قراءة مضيف Loader شجرة تخزين نشط غير group بند إعداد، و لـ تخزين نشط طلب Agent قراءة ذلك standing preset شجرة.Node حزمة تحليل سوف تحديد موضع الذي تابع manifest، بلا حاجة توجيه خروج `./package.json`. عادي بند إعداد من ذلك الذي تابع شجرة تحليل؛standing preset أصل سوف تكرار الآن Loader مقابل مضيف أساس عنوان صريح تغطية كتابة، تضمين طقم include فإن إبقاء ذاته أساس عنوان. الأكثر قريب مجهول اسم manifest سوف علامة رخو تفرق وحدة؛ أداة اسم manifest يجب حمل لديه إصدار. نظام بـ تحديد صفة ترتيب حسب تأكيد قطع اسم/إصدار مقابل ذهاب إعادة، معا تخزين نشط مختلف إصدار ما زال سوف قسم فتح إبقاء.

منع استخدام،pending،failed،unloading،disposed، بنية صفة، رخو تفرق غير حزمة، عادي اعتماد، تحرير مسار صيغة فرعي fiber و داخل تخزين حركة حالة إضافة بند إعداد كل لا يخص هذا حزمة بيان. هذا عدد تعريف سوف تقرير إبلاغ وقت التشغيل يمكن إثبات حزمة دعم دعم تركيب واقع، بينما لن لـ مهمة معنى عودة ضبط إرسال واضح مصدر.

## مؤقت مؤقت بيان cache

حالي تنفيذ سوف لـ كل طلب إعادة حساب حساب تخزين نشط حزمة تجميع دمج، معا في عملية دورة الحياة داخل cache manifest هوية. واحد بند فقط يحتوي مضيف شجرة دمج صار أساس دقيق اختبار استخدام Node v24.16.0 و macOS arm64، اختبار كائن لـ كل لا نفسه تخزين نشط متبادل مقابل إضافة حزمة؛ اختبار أولا مسبق حار 20 عدد طلب، مجددا مقابل 25 بند و 100 بند مشهد قسم آخر قياس كمية 500 عدد طلب، مقابل 500 بند مشهد قياس كمية 250 عدد طلب.«أول مرة طلب» يتضمن لم cache manifest قراءة؛ «قد cache مزود في موضع عدد» عبر نفس سجل التسجيل إرجاع مسبق بناء حقل، لذلك ما زال يتضمن `structuredClone()` و تجميد ربط فتح إلغاء، لكن لا يتضمن مهايئ JSON تسلسل تحويل و شبكة شبكة وقت.

| تخزين نشط بند إعداد | أول مرة طلب | حالي مستقر حالة في موضع عدد | حالي مستقر حالة p95 | قد cache مزود في موضع عدد |
|---:|---:|---:|---:|---:|
| 25 | 1.23 ms | 0.05 ms | 0.07 ms | 0.02 ms |
| 100 | 2.23 ms | 0.14 ms | 0.24 ms | 0.04 ms |
| 500 | 10.22 ms | 0.60 ms | 0.79 ms | 0.18 ms |

هذه قياس كمية نتيجة دعم حمل متابعة مؤقت مؤقت cache: أي جعل وجود 500 عدد بند إعداد، مستقر حالة استهلاك وقت ما زال منخفض في 1 جزء ثانية؛ في غير ممكن تجنب تجنب JSON تسلسل تحويل قبل، مسبق حساب عقدة حذف نحو 0.42 جزء ثانية. إضافة دخول cache إطلاق شرط هو حقيقي profile عرض `prepare()` تأخير متأخر بلوغ إلى فعلي جودة ماء مستو، بينما لا هو ثابت بند إعداد عدد كمية عتبة قيمة.

مؤقت مؤقت تصميم استخدام واحد مفرد ضبط تمرير زيادة بيان epoch. عام `internal/status` listener سوف في Loader بند إعداد أصل fiber عبر تجاوز `FiberState.ACTIVE` حد وقت دفع دخول هذا قيمة، من بينما تغطية اعتماد تنشيط، منع استخدام، إزالة و HMR، كما لن إنتاج أساس في وقت قديم قديم نافذة. مساهمة جهة حسب epoch cache مضيف لقطة، في `WeakMap` في cache كل standing preset `EntryTree`، و حسب شجرة و epoch cache مضيف إضافة preset دمج نتيجة. نظام بـ خط صفة وقت دمج قد ترتيب ترتيب لقطة، و مقابل تأكيد قطع `(name, version)` مقابل ذهاب إعادة. حساب حساب إتمام قبل epoch حدوث تغير وقت، نظام سوف إعادة محاولة بينما غير إصدار قديم قديم لقطة؛ قد dispose preset شجرة ما زال يمكن عبر `WeakMap` يتم عودة استلام.

عملية دورة الحياة داخل manifest هوية cache إبقاء مستقل، لأن نظام لا دعم حمل في عملية داخل استبدال حزمة إصدار.

## تحقق

سجل التسجيل اختبار ثابت تكرار كل حق،effect أثر مجال dispose(مورد تحرير) ، قسم مغادرة حقل قيمة، تزامن كما يمكن إلغاء دقيق تجهيز، إبقاء استقبال من قبول عملية، مفرد مرة قبول تسوية و فشل تجمع دمج. جلسة اختبار ثابت افتراضي فتح بدء و صريح إغلاق سياسة، أول مرة كامل/لاحق بعد لاحقة تسليم، و أساس أساس متن رسالة غير متصل مباشر كامل حدث معلومة غلاف، زيادة كمية ماء موضع fold، حفظ دائم إعادة بدء استعادة،fork هوية محيط شريط، فوضى ترتيب قبول و invariant تأخير متأخر تحميل. إضافة حزمة بيان اختبار ثابت افتراضي فتح بدء و صريح إغلاق سياسة، مضيف و standing preset اكتشاف، اندفاع مفاجئ Loader تحليل أساس عنوان،manifest تحليل، دورة الحياة مرور ترشيح و تأكيد قطع اسم/إصدار ترتيب ترتيب. مباشر مهايئ mock اختبار إثبات HTTP قبل دقيق تجهيز فشل، إلغاء، غير 2xx لا قبول،2xx في لاحق تدفق فشل قبل قبول، و حقل اندفاع مفاجئ. بلا مفتاح إعادة تشغيل سوف ثابت 2xx بعد توسيع قبول،TypeScript JSON-RPC و Python تحزيم وقت التشغيل لقطة فإن عبر اثنان طقم SDK إسقاط قبول حدث. حقيقي Loader تركيب سوف ثابت افتراضي حزمة بيانات وصفية، افتراضي جلسة فوق نقل و صريح إغلاق فوق نقل، واحد حقيقي API طلب سوف تركيب اثنان عدد مع مرفق توسيع و إثبات رسمي جهة طرف نقطة قبول هو جمع؛pi-ai اختبار إبقاء ذلك بروتوكول طلب ثابت.

## اعتبار مرور بديل خطة

**نحو `GenerateOptions` أو `ctx.llm` إضافة عام بيانات وصفية.** قد مرفوض، لأن هذه قيمة و قبول وقت نقطة يخص DeepSeek بروتوكول دلالة؛ مزود غير متصل طلب سوف إجبار جعل كل مهايئ إدارة حل أو تجاهل اختصار خارج قدوم حقل.

**يأخذ اثنان عدد مزود صلب تحرير رمز دخول `llm-deepseek`.** قد مرفوض، لأن مهايئ سوف استيراد جلسة،Loader،preset، حزمة manifest و تنقل علامة منطق. سجل التسجيل يجعل نقل فقط مسؤول حقل دمج و HTTP قبول.

### لـ ماذا لا استخدام طلب متبادل مقابل رسالة مرجع؟

واحد نوع تمرير عودة حمل وسم يمثل يمكن استخدام الذي تابع طلب `messages` في مسار و UTF-8 بايت انحراف نقل، استبدال حدث نص تأكيد قطع نطاق. قياس كمية استخدام Node v24.16.0،macOS arm64 و متاح ثلاثة نسخة الأكثر كبير محلي Zstandard جلسة ناتج؛ ذلك ضغط ناتج كبير صغير قسم آخر لـ 2,437,052،572,602 و 118,811 بايت. تأخير متأخر تفعيل إعادة تشغيل استخدام كل جلسة الأكثر بعد واحد قد إتمام طلب حد؛ مستقر حالة إعادة تشغيل تغطية 411 عدد قد إتمام حد. بايت عدد تغطية كامل كما الأكثر صغير تحويل DeepSeek طلب.

| إعادة تشغيل طريقة | أصلي JSON | مرجع JSON | عقدة حذف مقارنة مثال | تزامن تحرير رمز جهاز استهلاك وقت |
|---|---:|---:|---:|---:|
| تأخير متأخر تفعيل | 29,668,725 B | 27,645,825 B | 6.82% | دمج حساب 500.1 s |
| مستقر حالة | 389,295,815 B | 387,180,848 B | 0.54% | دمج حساب 285.0 s |

ثلاثة مرة تأخير متأخر تفعيل استدعاء قسم آخر استهلاك وقت 470.5،29.4 و 0.158 ثانية.115,071 عدد حدث في فقط لديه 701 عدد (0.61%) اختيار مرجع. واحد بند زائف ضبط اعتماد level-6 كامل طلب gzip مقابل وفق، جعل أصلي طلب بايت في تأخير متأخر تفعيل مشهد نقص قليل 89.38%، في مستقر حالة مشهد نقص قليل 73.42%؛ إضافة دخول رسالة مرجع بعد،gzip نتيجة قسم آخر مقدار خارج نقص قليل 21.68% و 0.59%.

استقبال جهة أيضا حاجة مرة تاريخ حمل وسم شجرة، تحليل عبر نحو تأكيد قطع طلب رسالة مسار، تحقق UTF-8 نطاق، و إعادة بناء كل مرجع حدث. أي جعل يأخذ استقبال جهة صار هذا نظر لـ صفر، مستقر حالة بايت عقدة حذف، إرسال جهة تزامن صار هذا و مقابل آخر طلب حقل اعتماد، أيضا لا كاف بـ دعم دعم حمل إصدار بروتوكول صيغة.

### لـ ماذا لا حذف assistant قسم قطعة أو إعادة تراكم حدث بيانات؟

فعلي قياس v1 حقيقي Session event في نحو 98% لـ `assistant/chunk`. في مرجع تحرير رمز بعد حذف هو جمع، سوف يجعل كامل identity JSON في تأخير متأخر تفعيل مشهد دخول واحد خطوة نقص قليل 84.79%، في مستقر حالة مشهد دخول واحد خطوة نقص قليل 6.49%، لكن سوف منع توقف بلا ضرر إعادة بناء و يجعل message source-event reference معلق فارغ.V2 يأخذ ضيق تجميع stream تضمين دخول attempt settlement؛`dsh_session_log` ما زال سوف كامل إرسال كل حالي مواصفة event، كما لن حذف هذه تضمين دخول صيغة record. نموذج غامض أو مواصفة تحويل استبدال أيضا لديه نفسه إعادة بناء نقص وقوع.

**فقط في داخل تخزين في إبقاء فوق نقل تنقل علامة.** قد مرفوض، لأن عادي عملية إعادة بدء سوف إعادة إرسال كامل جلسة. مرجعي قبول حدث يجعل إعادة بدء استعادة نيل نيل كل قوة بينما لـ حمل دائم صفة، بلا حاجة آخر تخزين خلفية؛ باق بقية انهيار انهيار نافذة فقط سوف إنتاج سماح تكرار.

**صاف نقطة كل تخزين نشط Cordis fiber.** قد مرفوض، لأن تحرير مسار صيغة و داخل تخزين fiber لا يوجد مرجعي NPM حزمة مصدر.Loader دعم دعم مضيف و preset بند إعداد قدرة توفير يمكن دقيق تحليل حزمة هوية.

**cache واحد نسخة كل عملية بيان، أو حسب TTL جعل ذلك مرور مدة.** قد مرفوض، لأن مفرد نسخة غير ممكن تغيير بيان لا يمكن صحيح تأكيد عكس عكس Loader دورة الحياة و تدريجي جلسة preset،TTL فإن سماح بيانات وصفية في مرور مدة حد بين إبقاء قديم قديم. مؤقت مؤقت epoch تصميم سوف أصل حسب مرجعي تخزين نشط حالة تحويل تنفيذ بطلان.

**استخدام محتوى hash أو خدمة طرف بيان مرجع استبدال كامل حقل.** قد مرفوض، لأن هو سوف تغيير مستقل طلب إعادة بناء طريقة، حاجة طرف نقطة حالة و لاحق بروتوكول إصدار. هذا يخص طلب بايت بروتوكول تغيير، بينما لا هو حساب حساب cache أفضل تحويل.

## عاقبة

DeepSeek رسمي جهة طلب سوف يأخذ تخزين نشط حزمة إصدار إرسال إلى تحليل بعد `baseURL`، يشمل قد إعداد gateway. حذف غير إغلاق جلسة سجل فوق نقل، لا فإن رمز دمج شرط طلب أيضا سوف يحمل كامل لم قبول جلسة جديد بعد لاحقة. هذه حقل مقابل نموذج غير ممكن رؤية، لا زيادة نص التوجيه token، أيضا لا تغيير KV Cache، لكن ممكن إظهار بارز زيادة كبير HTTP متن.Manifest تحليل، حقل اندفاع مفاجئ، قبول سجل أو مزود schema رفض سوف جعل نموذج طلب فشل، بينما لن ساكن صامت إسقاط بيانات وصفية.

`delivery-accepted` حدث سوف يصبح مرجعي سجل واحد جزء، و في لاحق طلب في ذاتي سطر تسليم. انهيار انهيار استعادة ممكن تكرار بعد لاحقة، لكن لن أصل حسب assistant إخراج دفع قطع قبول، أيضا لن إنشاء ثاني نسخة محلي تنقل علامة تخزين. نقص قليل تخزين نشط جلسة مباشر استدعاء سوف حذف جلسة حقل؛ مضيف حزمة بيان ما زال متاح.

[DeepSeek طلب هوية قرار](../feature/2026-08-11-deepseek-request-user-id-header.ar.md) متابعة يملك user/session header، كما هذه header ما زال يقع في متن خارج.[جلسة بعيد قياس قرار](../feature/2026-07-23-session-telemetry-otel-revival.ar.md) في آخر بند تغيير حذف هذا seam و خلفية قبل ما زال إبقاء حالي صالح؛ هذا طلب مسار لا تغيير OTel التقاط أو مشترك نمط.
