# Agent Note: Package manifest إعلان ملكية

Status: implemented

[English](2026-09-05-package-manifest-types.md) | العربية

## مشكلة

خارجي حزمة حاجة Harness manifest نوع، بينما بلا حاجة اعتماد بدء جهاز أو عميل تنفيذ. سوف إعلان وضع في كل قراءة جهة جانب حافة، سوف جعل كامل إعداد API صعب بـ فحص بحث، أيضا سعة سهل يجعل إعادة تراكم حقل حدوث انحراف مغادرة.

## قرار

[`@deepseek-ai/dsh-package-manifest`](../../../../packages/util/package-manifest/README.ar.md) في واحد صاف نوع ملف في يملك `DshManifest` و ذلك عضو إعلان. هذه الحزمة يخص قائم أداة مكتبة قسم مجموعة، لا تصدير وقت التشغيل قيمة.[عام مشترك حزمة بيانات وصفية قرار](2026-09-10-public-package-manifest.ar.md) يملك عام مشترك حقل نطاق و ذلك و داخلي أداة بيانات وصفية تخطيط قسم.

كل قراءة جهة مباشر استيراد مشترك إعلان. بدء جهاز إبقاء profile تحميل، أصلي JSON فحص، قيمة افتراضية و تحليل بعد وقت التشغيل بيانات. عميل وحدة إبقاء عودة واحد تحويل بدء رسم. مرآة مثل تحزيم جهاز سوف إعلان مسار تحليل لـ دليل.Session دليل توليد جهاز إرسال توليد حمل لديه قد تحليل استيراد مسار فقط قراءة تحقق نتيجة؛ أصلي إدخال و اكتشاف قاعدة ما زال من محلي مسؤول.

App-boot إعلان إنتاج اعتماد، لأن ذلك إصدار إعلان ملف مرجع مشترك نوع. عميل وحدة استخدام تطوير اعتماد، لأن ذلك إصدار API لا كشف هذه نوع. داخلي مرآة مثل تحزيم جهاز و Session دليل إعلان إبقاء في كل منها قراءة جهة. كل حزمة مستهلك كل لديه TypeScript مشروع مرجع. خارجي عمل من من أداة حزمة استيراد؛app-boot لا توفير توافق صفة مجددا تصدير.

## اعتبار مرور بديل خطة

**سوف إعلان إبقاء في كل قراءة جهة.** خارجي عمل من سوف اعتماد وقت التشغيل تنفيذ، بينما فقط تغطية profile جزء تعريف سوف متروك تسرب قد لديه عميل و بناء حقل.

**إنشاء مستقل types قسم مجموعة.** قائم أداة مكتبة قسم مجموعة يمكن سعة قبول صاف نوع مكتبة، بلا حاجة زيادة حزمة تصنيف. وقت التشغيل خدمة و حدث إعلان ما زال من كل منها مسؤول جهة يملك.

**موحد واحد JSON محلل.** مشترك إعلان لا اشتراط تغيير تحقق، خطأ، قيمة افتراضية أو تحليل نتيجة؛ هذه ما زال من كل قراءة جهة مسؤول.

## عاقبة

عمل من نيل نيل موحد واحد عام مشترك استيراد مسار، بديل قيمة هو واحد إصدار حزمة و واضح اعتماد حافة. قد لديه app-boot manifest نوع استيراد حاجة تعديل استخدام جديد حزمة.[Profile تركيب تصميم](2026-08-05-profile-plugin-bundles.ar.md) متابعة مسؤول وقت التشغيل دلالة؛ نوع رفع أخذ لا تغيير إعداد قبول نطاق أو نموذج مرئي سلوك.

تحرير ترجمة جهاز و تحزيم بعد NodeNext مستهلك فحص تغطية عام مشترك استيراد. قد لديه profile، عميل، مرآة مثل إعداد و Session دليل اختبار تغطية قراءة سلوك؛ وثيقة فحص تغطية أداة مكتبة تصنيف و توليد حزمة دليل. إضافة جديدة اختياري إعلان حقل وقت، ما زال يحتاج رئيسي حركة تحديث مستهلك.

حالي تثبيت جهاز و تحميل جهاز لا قوي صنع فحص manifest صيغة أو مضيف توافق صفة إعلان. صاف نوع حزمة حيث لا توفير SemVer محلل، أيضا لا توفير تثبيت سياسة؛ ذلك README سجل هذا حد، تجنب تجنب سوف عمل من إعلان خطأ إقرار لـ توافق صفة فحص.
