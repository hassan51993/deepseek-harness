# Agent Note: متعمد معنى حزمة ثابت كمية اتفاق

Status: implemented

[English](2026-07-19-package-invariant-runtime-contracts.md) | العربية

## مشكلة

حزمة ذاتي لديه ثابت كمية خدمة يجعل إصدار و تسجيل تنفيذ كل تغطية، لكن الأكثر أول توليد أساس خط سماح فارغ تثبيت جهاز. لاحق خطة أيضا استخدام إبرة مقابل إضافة اسم، حقن،effect، خدمة طريقة و صاف أداة مكتبة في ثابت عرض مثال عام تأكيد بديل هذه فارغ تنفيذ. هذه تأكيد رغم لكن يجعل كل companion كل قدرة تنفيذ، لكن لا يوجد رفع عال نظام أمان صفة:TypeScript،Cordis بدء، حزمة اختبار و وحدة تحميل اختبار قد قيد هذه شكل حالة، بينما ثابت كمية خدمة ينبغي عند اكتشاف غير ممكن قدرة ظهور وقت التشغيل حالة.

لديه استخدام وقت التشغيل ثابت كمية سوف صلة ربط وقت فوق كثير عدد مراقبة قياس، أو صلة ربط متغير بيانات بنية في كثير عدد جزء. مثال مثل: إنهاء حدث لا يوجد مقابل بدء حدث،LLM(كبير لغة نموذج)delta إشارة نحو لم فتح كتلة، أو حفظ دائم نتيجة هوية و طلب مختلف. فقط تأكيد إعلان طريقة وجود، إضافة اسم رمز دمج مسبق مدة، أو معتاد كمية عرض مثال ما زال إرجاع معروف قيمة، كل لا يخص هذا نوع علاقة.

لديه بعض حزمة تأكيد فعلي لا يوجد يمكن حمل متابعة مراقبة قياس علاقة. صاف أداة، فقط مسؤول تركيب حزمة، رقيق مهايئ، يمكن تنفيذ مدخل و اختبار دعم حمل حزمة ممكن ما زال لديه إعادة يلزم اتفاق، لكن نوع فحص، تحميل فحص، تجمع تركيز اختبار وحدة أو اختبار تكامل أكثر ملائم دمج تنفيذ هذه اتفاق. قوي إجبار هذه حزمة إضافة دمج صار وقت التشغيل تأكيد، فقط سوف يجعل تنفيذ محيط التفاف عبر بوابة أفضل تحويل، بينما لا هو فحص قياس ضرر تالف.

## قرار

### قد إصدار تأكيد يجب متعمد معنى

فقط لديه يملك يمكن مستقل مراقبة وقت التشغيل علاقة وقت،workspace حزمة عندئذ إصدار مفرد وحيد بناء `./invariant` companion. قد إصدار companion يجب:

- تثبيت حزمة ذاتي لديه حدث تدفق أو متبادل صلة متغير بيانات بنية فحص، و عبر ربط `fail(message)` تقرير إبلاغ جهاز تقرير إبلاغ مخالفة قاعدة؛ و كما
- استخدام هذا حزمة دقيق تأكيد npm حزمة اسم تسجيل، معا إبقاء تشخيص منطق لا دخول أصل مدخل.

لا يوجد دمج إدارة علاقة وقت، حزمة سوف حذف companion و إصدار وصل خط، و في README في سجل هذا حزمة أداة جسم سبب. إذا لاحق تغيير جذب دخول يمكن مستقل مراقبة علاقة، حينئذ يجب استخدام متبادل ينبغي فحص استبدال هذا شرح. حذف آلية و حالي مراجعة حساب من[حذف لا لا بد يلزم companion قرار](../simplification/2026-08-28-omit-unneeded-invariant-companions.ar.md) مسؤول.

في وسط `dsh-invariants` خدمة فقط مسؤول إعداد، تسجيل وحيد صفة، فرعي fiber دورة الحياة، تراجع،dispose(مورد تحرير) و ملكية إلى حزمة فشل. هو لا كشف عام إضافة شكل حالة، خدمة شكل حالة أو بدء تأكيد helper، أيضا لا استيراد منتج حزمة.

### قد فعلي تطبيق فحص عرض مثال

قد إصدار companion من `verify-package-invariants` آلة آلة قطعة رفع؛ حالي مراجعة حساب عدد كمية سجل في[حذف لا لا بد يلزم companion قرار](../simplification/2026-08-28-omit-unneeded-invariant-companions.ar.md) في. تحت جدول فقط عرض لديه بديل جدول صفة وقت التشغيل علاقة، لن تدريجي بند صف خروج كل companion.

| كل من | وقت التشغيل علاقة |
|---|---|
| `dsh-session` | ترتيب رقم صارم إطار تمرير زيادة، جولة/خطوة حزمة محيط علاقة، و نفس خطوة داخل استدعاء الأداة/أداة نتيجة إعداد مقابل. |
| `dsh-agent` | agent(ذكي جسم) حالة لا نيل تكرار، و كما لا يستطيع مغادرة فتح نهاية حالة disposed. |
| `dsh-scope` | أثر مجال حدث يجب يحمل carrier، كما توجيه subject إبقاء متسق. |
| `dsh-agent-loop` | من جلسة حدث سجل إعادة بناء حمل صريح علامة تجميد ربط loop طلب. |
| `dsh-llm` | تدفق في كتلة نص قاعدة،delta نوع/بحث جذب مطابقة، مفرد مرة usage، كتلة إغلاق دمج و إنهاء finish. |
| `dsh-llm-retry` | حفظ دائم إعادة محاولة سجل إشارة نحو حالي فتح جولة في الأكثر قريب إغلاق خطوة؛ كل خطوة سجل إبقاء وحيد، إعادة محاولة مرة عدد مفرد ضبط تمرير زيادة، و كما إعادة محاولة مرة عدد و غير سالب تحديد وقت جهاز تأخير متأخر متساو إبقاء في حد داخل. |
| `dsh-tools` | pre/execute/post مرحلة مقطع مفرد ضبط دفع دخول، و نهائي execution/result لقطة غير ممكن تغيير. |
| `dsh-system-prompt` | مرجعي assembly في section، أداة و variable بيانات قيد. |
| `dsh-compaction` | ضغط (compaction)start/summary/end إعداد مقابل، نطاق طرف نقطة،token عدد كمية و نجاح وقت يجب وجود summary. |

| `dsh-sandbox-policy` | حفظ دائم `sandbox/mode` حدث يجب استخدام غلاف إغلاق sandbox-mode كلمة جدول. |
| `dsh-fs` | نظام الملفات قرار/مراقبة قياس حدث يجب يحمل متاح target و version هوية. |
| `dsh-goal` | حفظ دائم هدف لقطة إبقاء مصدر ملكية، تصيير محتوى، إصلاح حجز رقم، دورة الحياة و ختم الوقت علاقة، و حفظ إثبات قد دقيق دخول Round وصل متابعة تحرير رقم. |
| `dsh-goal-round-driver` | هدف مصدر متابعة تنفيذ رسالة يجب مطابقة أصل حسب هذا قبل حفظ دائم هدف حالة إعادة بناء نص التوجيه. |
| `dsh-subagent` | مزود add/remove و child start/end حدث يجب إبقاء هوية و إعداد مقابل. |
| `dsh-permission-presets` | حفظ دائم permission قرار يجب مرجع حالي permission جدول في preset. |

أساس في جلسة companion في تحميل وقت تحقق قد لديه حفظ دائم حدث؛ علاقة اعتماد حدث ترتيب وقت، سوف استخدام كل مرشح حدث قبل حدث بادئة. أخرى فحص مراقبة قياس مرجعي فوري حدث حد أو متغير خدمة نتيجة. إذا قبول بلا فاعلية حدث سوف إيداع خطأ حالة، تحقق حينئذ في إصدار قبل تنفيذ.

### مستودع بوابة و اختبار

`verify-package-invariants` اكتشاف كل workspace حزمة. هو قبول كامل حذف، رفض قديم قديم أو لا كامل companion وصل خط، و مقابل قد إصدار companion قوي صنع كامل اسم تسجيل، فقط يحتوي أداة اسم export Loader شكل حالة،`./invariant` export، إصدار ملف، اعتماد،TypeScript reference و bundle entry كامل. ذلك AST قاعدة رفض توليد علامة، افتراضي تصدير و فارغ installer. كل installer كل يجب استقبال و استخدام فشل تقرير إبلاغ جهاز، تسجيل وقت أيضا يجب نقل دخول هذا مرور فحص محلي `install` دالة. بوابة لن عبر طريقة اسم أو helper استدعاء دفع قطع دلالة جودة كمية.

Vitest لـ كل حزمة اختبار توسيع اندفاع استخدام `{ enabled: true }` تركيب `InvariantRegistry`، و في كل من إصدار companion وقت تحميل هو. ثابت كمية subpath path mapping سوف تحليل مصدر companion، بينما لا هو قديم قديم بناء إخراج. تجمع تركيز suite تغطية كل قد إصدار companion صالح و بلا فاعلية مراقبة قياس؛ نفاد رفع توسيع اندفاع عبر حقيقي Loader نطاق الأسماء عودة واحد تحويل تشغيل كل مصدر companion. بنية بوابة تحقق كل حزمة إصدار خريطة بعد، ناتج بوابة سوف مؤقت تخزين ذلك manifest(بيانات وصفية بيان) إعلان `lib/` ملف، في plain Node تحت استيراد قد تحرير ترجمة `./invariant` ذاتي مرجع، و تكرار تنفيذ هذا Loader شكل حالة فحص؛ هذا مثال، إذا companion استيراد لم إعلان وقت التشغيل قسم قطعة، بوابة حينئذ سوف في إصدار قبل فشل. دمج صار حدث تدفق اختبار يجب بنية صنع صالح خارج محيط دورة الحياة، حذف غير اختبار ذاته حينئذ هو في تأكيد مخالفة قاعدة.

## اعتبار مرور بديل خطة

- **إبقاء حمل شرح فارغ companion.** رفض، لأن فقط لـ جدول بلوغ README يمكن مباشر سجل لا تحديد ربط نقاش بينما إبقاء شفرة المصدر، إصدار، اعتماد و اختبار وصل خط، صار هذا مرور عال.
- **اشتراط كل حزمة كل تنفيذ تأكيد.** رفض، لأن طريقة وجود، إضافة شكل حالة و ثابت عرض مثال تأكيد سوف تكرار أكثر قوي نوع، تحميل و اختبار وحدة اتفاق، لكن لا يوجد فحص وقت التشغيل متسق صفة.
- **في خدمة في إبقاء عام شكل حالة helper.** رفض، لأن هذا سوف خلط خلط تحرير ترجمة مدة API تحقق و وقت التشغيل ثابت كمية، و حث تشجيع في في وسط تعريف منتج زائف ضبط.
- **يأخذ منتج فحص نقل دخول خدمة.** رفض، لأن منتج مفردات، اعتماد، اختبار و تغيير كل حق ينبغي ملكية في إنتاج هذه بيانات حزمة.
- **من أصل مدخل خفي صيغة تسجيل companion.** رفض، لأن تركيب ترتيب و اختياري خدمة وجود سوف إنتاج إخفاء effect.

## عاقبة

- يملك دمج إدارة وقت التشغيل علاقة حزمة أداة لديه مرئي كل حق و إصدار wiring؛ لا يوجد هذا علاقة حزمة سوف في README في سجل حذف سبب.
- فارغ companion سوف يجعل بوابة فشل، لا كامل حذف وصل خط أيضا سوف في بناء أو إصدار قبل فشل.
- نوع إعلان،Cordis يمكن تحميل صفة، إضافة metadata، خدمة طريقة API و صاف بديل عدد متابعة من الذي تابع تحرير ترجمة، تحميل، وحدة أو تجميع صار بوابة تغطية.
- وقت التشغيل فشل سوف علامة واضح الذي تابع npm حزمة، و إشارة خروج لا متسق مراقبة قياس، بينما لا هو تكرار وصف لا بد يلزم API شكل حالة.
- أصل لديه selection،blocklist أولوية درجة، تكرار كل حق، تراجع،dispose و HMR(حار وحدة استبدال) خدمة اتفاق إبقاء ثابت.
