# Agent Note: جلسة agent من واحد نسخة preset cordis.yml تجميع بينما صار

Status: implemented

[English](2026-08-03-per-session-agent-presets.md) | العربية

## مشكلة

واحد `dsh` عملية خدمة كثير عدد جلسة، لكن قرار agent(ذكي جسم) بحث فعلا هو ماذا ذلك طقم تجميع——هو أداة، شخص ضبط، نص التوجيه مقطع سقوط، تفويض إرسال خلفية——من بدء جهاز الذي جذب توجيه `cordis.yml` مرة صفة ثابت إعطاء كامل عملية. إذا بعض عدد نشر أمل نظر واحد benchmark دقيق بسيط agent و واحد كامل تحرير رمز agent و تخزين، حينئذ يجب ركض اثنان عدد عملية؛ بينما قائم تغيير عبر خطة (`apps/cli/config/minimal.cordis.yml`، واحد استخدام قدوم منع استخدام أداة سطر `--config` تغطية طبقة) سوف مرة صفة تغيير كل جلسة.

مقابل"يجعل جلسة ذاتي اختيار تجميع"الأكثر مباشر شعور إدارة حل، هو loader حاجة إضافة جديدة واحد طبقة. ذلك فعلي لا حاجة.[`dsh-tools`](../../../../packages/core/tools/README.zh.md) و [`dsh-system-prompt`](../../../../packages/core/system-prompt/README.zh.md) هذا حينئذ حسب استدعاء جهة سياق scope قسم طبقة عودة ملف تسجيل، بينما كما [agent ذاته حينئذ هو واحد تسجيل scope](2026-07-08-agent-scope-contexts.zh.md). هذا قبل نقص فقط هو واحد نوع يأخذ كامل نسخة `cordis.yml` إشارة نحو بعض واحد agent scope إنجاز قاعدة.

## قرار

**preset** هو واحد دليل، منها وضع وضع واحد نسخة `agent.cordis.yml`.agent عمل مصنع `setup(agentCtx)` يأخذ هو بصفة Cordis `include` فرعي شجرة، تركيب إلى هذا agent scope سياق لـ تحت.entry سياق امتداد أصل نوع سلسلة وصل إلى فرعي شجرة يتم تركيب وقت الذي في سياق، لذلك preset داخلي كل مرة تسجيل كل سقوط دخول هذا agent قسم طبقة، و مع agent واحد بدء إزالة. لا يوجد أي سجل التسجيل إضافة جديدة قسم طبقة، أيضا لا يوجد أي قد في تشغيل جلسة يتم لمس و.

تجميع تخطيط قسم لـ اثنان عدد مستو وجه، اعتماد حسب هو ماذا يجب مشترك، بينما لا هو ماذا شعور شعور فوق و agent لديه صلة:

| مستو وجه | نسخة عدد | محتوى |
|---|---|---|
| مضيف | واحد نسخة | سجل التسجيل ذاته (`tools`،`systemPrompt`،`agents`،`agent-loop`،`sessions`) ، عبر جلسة ضبط تطبيق (حفظ دائم، استعلام، إسقاط، تخزين، ضبط، اعتماد، بعيد قياس) ، هذه ضبط تطبيق الذي تحليل subagent provider، و web مضيف |
| agent | كل جلسة واحد نسخة | مفرد عدد agent مقابل هذه سجل التسجيل مساهمة: أداة إضافة، شخص ضبط و نص التوجيه مقطع سقوط، ضغط سياسة |

نموذج توجيه لا دخول preset.`installAgentLlmTarget` قد هو provider،model و reasoning effort حسب agent يمكن استبدال نقطة؛ بينما تعليق في preset داخلي LLM مهايئ دائم بعيد لن يتم `agent-loop` تحليل إلى، لأن بعد من يقع في مضيف مستو وجه.

نشر تسليم أي بعض preset، أخذ قرار في `packages/preset/agent-presets/presets/` تحت لديه أي بعض دليل؛ بيان هو ذلك نسخة دليل قائمة، بينما لا هو في هذا آخر نسخ واحد نسخة.

تركيب افتراضي حسب جلسة إجراء. فعلي قياس واحد نسخة عشرة اثنان سطر تجميع كل جلسة نحو 3ms، نحو 600KB، لذلك عزل مقارنة أي مشترك خطة كل أكثر تخطيط حساب؛ بينما من مستخدم أو agent كتابة خروج preset أيضا لذلك يملك كل ممكن صغير أثر وجه. تأكيد فعلي ذاتي حمل مرتفع ثمين مفرد مثال preset، يمكن استخدام Cordis ذاته `isolate` مفردات صريح اختيار مشترك: تسمية realm label هو عملية درجة عام، لذلك اثنان شجرة فرعي شجرة فقط يلزم كتابة نفس عدد label حينئذ تحليل إلى نفس عدد نسخة.

`agent-presets` مستخدم ضبط نطاق الأسماء معا يحمل `modeSelectionEnabled` و `default`.`modeSelectionEnabled` افتراضي لـ `true`: قائم جديد بناء جلسة اختيار جهاز إبقاء عرض؛ لم إشارة اسم جلسة سوف تحليل إلى قد حفظ مستخدم `default`، بعد لم حفظ وقت فإن استخدام تجميع في `default` إشارة تحديد نشر قيمة افتراضية.Web ضبط فتح صلة فقط تغيير هذا سياسة: إغلاق اختيار وقت مؤقت استخدام نشر قيمة افتراضية، مجددا مرة فتح بدء وقت استعادة قد حفظ مستخدم `default`. هذا هو مقابل #1539 الذي تأكيد قيام “مستخدم قيمة تغطية تجميع قيمة” هذا واحد عادي settings أولوية درجة متعمد مثال خارج: إخفاء اختيار جهاز سوف توقف استخدام مستخدم نمط اختيار سياسة، لكن لن حذف ذلك حفظ قيمة. هذا Host سياسة ملائم لأجل هذا بعد كل لم صريح إشارة تحديد preset جلسة؛ صريح إشارة تحديد و قائم جلسة لا تلقي أثر. تجميع قيمة أيضا جعل هذه الحزمة في لا يوجد settings مزود وقت وفق معتاد عمل؛ اختيار جهاز فتح بدء بعد، مستخدم يمكن تغطية قيمة افتراضية قدوم تغيير لاحق جلسة، بينما بلا حاجة تحرير نشر الذي يملك `cordis.yml`.

## عاقبة

**صالح قيمة افتراضية في كل مرة تحليل وقت قراءة، أبدا حفظ لقطة.** ذاكرة مؤقتة تحت قدوم حينئذ حاجة واحد `watch` حجز قراءة و واحد بند إعادة تحميل مسار عندئذ قدرة إبقاء صدق فعلي، بينما تحليل بعد scope هذا قدوم حينئذ سوف إعادة قراءة حار إعادة تحميل مرور وثيقة.Host ضبط ذاته سوف في هذا بعد تحليل لم إشارة اسم جلسة وقت توليد فاعلية.Web Settings في واضح عملية أيضا سوف يأخذ قد قبول صالح قيمة افتراضية إرسال دخول قائم فارغ أبيض جلسة اختيار سلسلة مسار، لكن فقط في عملية قبل التقاط جلسة id ما زال هو حالي فارغ أبيض جلسة وقت مقابل متساو؛ هو أبدا سوف إعادة تجميع تشغيل في جلسة، أيضا لن تعديل كتابة هذا جلسة تاريخ.session سجل من آخر جانب تنفيذ نفس بند ثابت كمية——header سجل جلسة**إنشاء وقت** id، هذا بعد فارغ أبيض مدة أي تبديل من `agent-preset/selected` حدث سجل، لذلك قراءة جهة تحليل هو اثنان من لـ و (`resolveSessionPreset`) ، أبدا مفرد نظر header: استعادة إعادة بناء هو ذلك تاريخ الذي إنتاج خروج ذلك نسخة تجميع بينما لا هو استعادة وقت نشر قيمة افتراضية، بارد قراءة سجل presenter في ذلك نسخة تجميع طبقة داخل تحليل، شبكة صلة أيضا سوف رفض يأخذ واحد نشط حال جلسة استلام تحرير إلى هو حالي تشغيل preset بـ خارج preset لـ تحت. لقطة سوف يجعل اثنان من تماما جيد في ضبط تغيير ذلك واحد لحظة كل قول كل كلام.

**مباشر تركيب فرعي شجرة مقابل بدء مراجعة حساب غير ممكن رؤية.** هو لن يأخذ ذاتي ذات صلة ربط إلى `Entry`، لذلك لا في `ctx.loader.entries()` في،`auditStartupEntries` أيضا نظر لا إلى هو. تركيب مرور مسار عبر واحد سوف عام ذاته tree `Include` فرعي صنف قراءة كل سطر، و اشتراط كل تفعيل سطر كل تنشيط، لا تلقي[تطبيق بدء سياسة](2026-09-09-consumer-owned-startup-strictness.zh.md) أثر.

**preset قدرة كتابة خروج group، هو لأن app تسجيل هو.** عبر سطر مشترك realm حينئذ هو واحد `cordis:group` سطر، بينما إقامة في هذا مساحة العمل خارج preset——أيضا حينئذ هو Harness home تحت من شخص أو agent إنشاء عمل ذلك بعض، صحيح هو هذا طقم تصميم هدف——لا يمكن حسب اسم حرف تحليل `@cordisjs/plugin-group`:Node نحو فوق فحص بحث `node_modules` مسار من ذلك داخل دائم بعيد مشي لا إلى harness. لذلك `boot()` يأخذ `cordis:group` و `cordis:include` و ترتيب تسجيل لـ loader builtin، اثنان من كل مرور من بيئة وحدة إدارة خط تحميل، بينما لا اعتماد يتم يتضمن شجرة ذاته شرح رمز تحليل. لا يوجد هو، فوق نص ذلك طقم `isolate` مفردات حينئذ فقط قدرة واحد سطر واحد سطر أرض جدول بلوغ، مزود أيضا دائم بعيد لا يمكن و هو مستهلك عودة دخول نفس مجموعة.

**preset لا نيل يأخذ خدمة إصدار دخول أصل realm.** هذا صنف خدمة هو عملية درجة عام بينما غير حسب جلسة، لذلك ثاني عدد تركيب نفس preset جلسة سوف و رقم واحد متبادل اصطدام——بينما هذا مرة متبادل اصطدام جدول الآن لـ `setup` دائم بعيد مراقبة لا إلى لم معالجة rejection، إبقاء تحت واحد نظر بدء قدوم سليم سليم، فعلي فإن تجميع إلى واحد نصف agent. تركيب تعديل لـ مباشر رفض هو؛ هذه الحزمة وقت التشغيل ثابت كمية أيضا سوف في كل مرة خدمة إشعار وقت تكرار فحص، لأن من تحديد وقت جهاز أو مختلف خطوة متابعة جسم في إصدار سطر سوف التفاف مرور مرة صفة مراجعة حساب.

**فشل سوف يجعل agent تراجع.** `setup` في إصدار قبل تشغيل، لذلك تركيب يتم رفض سوف يجعل `ctx.agents.create()` فشل كما لا إبقاء ناقص إبقاء. هذا صحيح هو `setup` هو وحيد تلقي دعم حمل استدعاء نقطة سبب.

**«preset ملف من لا يتم عودة كتابة» هذا بند تأكيد، يجب أولا لديه فشل ممكن.** الأكثر أول ذلك إصدار في مرة عادي تركيب بعد تأكيد ملف لم تغيير، ذلك فعلي ماذا أيضا إمساك لا إلى:Loader فقط في إقرار تحديد config تغيير وقت عندئذ سوف مشي إلى كتابة مسار، بينما ذلك نسخة تجميع داخل لا يوجد أي واحد سطر سوف ذاتي سطر إلغاء تدمير. ارتداد حالة استخدام تعديل لـ غرس دخول واحد ذاتي سطر إلغاء تدمير سطر——حقيقي preset في كل مرة agent يتم تفكيك حذف وقت كل سوف أمر في شكل حالة——و يأخذ تجميع وضع في مؤقت أصل دليل بينما لا هو `fixtures/` تحت: لا يوجد ذلك عدد تغطية كتابة،Loader سوف عودة كتابة هو قراءة دخول ملف، في هو إيداع دخول مستودع fixture سوف يتم**تماما تماما هو إثبات هذا نقص وقوع ذلك مرة تشغيل**تعديل تالف، بعد كل مرة تشغيل كل أخذ تعديل تالف بعد ملف عمل مقارنة مقارنة من بينما عبر.

**fiber ملكية حكم تحديد استخدام كائن نفس صفة، بينما غير `uid`.** `uid` هو حسب registry حساب عدد ترتيب رقم، لذلك اثنان عدد مختلف أصل تحت fiber سوف في هو فوق وجه اصطدام رقم؛ حسب `uid` مقارنة مقارنة سبق توجيه يؤدي واحد وقت التشغيل فرعي شجرة لـ آخر عدد وقت التشغيل في إصدار خدمة خلف قدر.`ctx.plugin()` إرجاع هو thenable `Object.create(fiber)` حزمة تركيب كائن، و أب سلسلة في ظهور fiber دائم بعيد مختلف واحد، لذلك فرعي شجرة في بنية صنع وقت التقاط ذاتي ذات fiber.

**preset ملف هو إدخال، أبدا هو حفظ دائم هدف.** فقط يلزم loader إقرار لـ إعداد تغيير،`EntryTree.write()` حينئذ سوف عودة كتابة كامل شجرة شجرة، بينما واحد إضافة ذاتي أنا dispose حينئذ كاف بـ إطلاق——إلغاء تدمير agent سوف dispose هو كامل شجرة فرعي شجرة. إذا وراثة هذا سلوك، هو سوف إعادة كتابة ذاتي ذات قراءة دخول ذلك نسخة تجميع، فعلي عاقبة هو رقم مرة جلسة انتهاء وقت يأخذ مع مرفق preset قطع قطع صار `[]`. فرعي شجرة لذلك يأخذ `write()` تغطية لـ فارغ عملية.

**حسب ذاته اسم حرف عودة فحص عام سجل التسجيل إضافة، في preset داخل لا بد لكن بطلان.** `ctx.tools.register()` عودة ملف دخول**استدعاء جهة**سياق scope، لذلك تعليق في preset داخل إضافة فقط لـ واحد agent تسجيل، بينما لا حمل scope `ctx.tools.get(name)` إدارة الذي عند لكن فحص لا إلى.`dsh-tool-skill` صحيح هو هذا مثال كتابة، في هو كل مرة preset تركيب كل رمي خطأ؛ الآن هو و ذاتي ذات تسجيل ذلك عدد تعريف مقارنة مقابل. أي أمل نظر يمكن يتم preset تركيب إضافة، كل يجب يحتفظ ذاتي ذات تسجيل كائن، بينما لا هو حسب اسم حرف إعادة قراءة.

**entry محلي `isolate` realm لا فقط مقابل مضيف غير ممكن رؤية، مقابل agent ذاته scope نفس مثال غير ممكن رؤية.** فقط لديه هذا مجموعة داخلي سطر قدرة تحليل إلى هذا خدمة. هذا صحيح هو يجعل preset `skills` سجل التسجيل ملكية مفرد عدد agent بينما غير مشترك سبب——معا أيضا معنى طعم حال: إبقاء في مزود مجموعة خارج مستهلك سوف صامت لكن تحليل إلى مضيف سجل التسجيل، لكن بعد ماذا كل لا مساهمة.

**فقط لديه فارغ أبيض جلسة عندئذ سماح تبديل.** واحد حالما ركض مرور أي جولة، ذلك مقطع تاريخ حينئذ هو في هذا preset أداة تحت إنتاج، استبدال سوف إبقاء تحت لا يمكن تنفيذ قد سجل tool call، لذلك `agentPreset.select` إرجاع `agent-preset-locked`. فارغ أبيض مدة تبديل إبقاء agent و session، فقط استبدال فرعي شجرة——لأن مضيف إسقاط هو إنشاء `AgentHandle`، أيضا لا يوجد delete RPC؛ بينما إبقاء هو جمع ذاته حينئذ هو أكثر جيد نتيجة، جلسة id،workspace تعليق وصل و projections كل أصل أرض لا حركة. هذا استبدال هو"أولا إزالة بعد تركيب"(اثنان نسخة تجميع سوف يأخذ نفس اسم أداة تسجيل دخول نفس قسم طبقة) ، لذلك هو في تفكيك حذف أي شرق غرب قبل أولا تحليل جديد preset، و في جديد تجميع تركيب تحميل فشل وقت استعادة أصل قدوم ذلك واحد نسخة.

**إنشاء عمل preset هو مرة RPC، بينما كما هو خاص حق RPC.** تجميع هو واحد ملف، لكن “ذهاب نظام الملفات داخل تعديل هو” و لا هو متصفح قدرة توفير عملية، لذلك اسم مفرد في `select` خارج إضافة جديدة `read`/`write`/`remove`.Connection استخدام واحد متصفح جلسة إقرار إثبات إنشاء عمل عملية،`list`،`select` و كامل Host API: تجميع إشارة واضح واحد جلسة الذي تشغيل إضافة، لذلك قراءة هو هو تحري ملاحظة، كتابة هو هو مهمة معنى قدرة؛ اختيار preset فإن لا يوجد منح إعطاء `session.create` يحمل `agentPreset` وقت بعد لم يملك قدرة. هذا نسخة قدرة أيضا لا من preset منح إعطاء: نشر ذاتي حمل افتراضي preset هذا حينئذ حمل حال `bash` و نظام الملفات أداة، لذلك أي يتم سماح فتح بدء جلسة استدعاء جهة، مبكر قد قدرة بـ هذا عملية هوية تنفيذ أمر. قيد هو id ذاته صفة جودة (`[a-z0-9][a-z0-9-]*`) ، في هو يصبح دليل اسم قبل حينئذ فحص، بينما لا هو أمر بعد مجددا ذهاب مراجعة نظر تجميع وصل خروج مسار؛ نص استخدام loader ذاته schema و جهة قول تحليل، لذلك حفظ لن إبقاء تحت أي جلسة كل لا يمكن تحميل ملف. مع نشر توفير preset رفض كتابة و حذف، لأن نشر ذاتي حمل ذلك واحد نسخة صحيح هو استخدام قدوم مقابل وفق لديه مشكلة محلي preset ——هذا أيضا يجعل “أولا نسخ، مجددا تحرير” يصبح إنشاء عمل مسار ذاته، بينما غير أمر بعد تكملة ملء.

**في agent مستو وجه خارج أيضا لديه مستهلك خدمة، لا يستطيع نقل دخول preset.** تنشيط دخول تفكيك قسم يأخذ `subagents` سجل التسجيل وصل نفس spawn/fork خلفية واحد بدء نقل دخول delegation مجموعة entry-local realm، في هو `dsh web` مباشر بدء لا قدوم:`SubagentRuntime` هو Host سطر، هو عام متصفح عبر جلسة Remote استعلام (`list`،`prompt`) ، بسبب بينما دائم بعيد انتظار واحد فقط لديه جلسة عندئذ توفير خدمة. حسب جلسة كل واحد نسخة في اثنان عدد طبقة وجه فوق كل هو خطأ——provider اسم فقط قدرة تسجيل مرة، ثاني عدد جلسة هذا قدوم أيضا سوف متبادل اصطدام. سجل التسجيل و كل مشترك خلفية، يشمل[ثابت Codex و Claude Code منتج provider](../../archived/architecture/2026-08-10-product-subagent-providers-in-shared-host.md) ، كل يخص مضيف مستو وجه؛preset فقط مساهمة ذاتي ذات agent ينبغي نظر رؤية تفويض إرسال**أداة**، هذه أداة تحليل مضيف سجل التسجيل.`workflows` إبقاء entry-local، لأن agent خارج لا يوجد أي شرق غرب قراءة هو. هذا هذا اعتراض تحت هو هو «فحص بحث حقن جهة» هذا واحد خطوة، بينما هو لا اعتراض إقامة: فحص بحث يجب تغطية مضيف حزمة، بينما لا فقط هو agent مستو وجه حزمة.

**حقيقي تجميع اختبار إذا منع استخدام بعض عدد مضيف سطر، حينئذ لا يمكن مراجعة حساب هذا سطر.** web تجميع اختبار إبقاء API Gateway و كل عمل خدمة Remote خدمة تفعيل، معا منع استخدام فقط تحمل تحميل نقل webserver،Connection،Session export، مورد و بعيد قياس سطر. استبدال لـ browse دليل اختيار جهاز بعد، ذلك بدء مراجعة حساب بلا حاجة ربط طرف فتحة يكفي تغطية Host مستو وجه خدمة رسم.

**preset حزمة اسم يجب من harness تحليل، بينما غير من preset تحليل.** `EntryTree.import()` حسب سطر الذي تابع شجرة `baseUrl` تحليل، بينما `Include` يأخذ هو ضبط لـ تجميع ملف الذي في دليل. هذا مقابل متبادل مقابل معرف رمز هو مقابل، مقابل حزمة اسم لكن هو يؤدي أمر: محلي إنشاء عمل preset يقع في مستخدم رئيسي دليل لـ تحت،Node نحو فوق فحص بحث `node_modules` دائم بعيد كاف لا إلى قد تثبيت harness، لذلك كل واحد `@deepseek-ai/dsh-*` سطر كل سوف استيراد فشل، كامل preset لا يمكن تركيب. مع نشر توفير preset إخفاء غطاء هذا واحد نقطة——هو جمع هذا حينئذ في تثبيت دليل لـ داخل. تركيب في إدراج دخول فرعي شجرة قبل أولا سجل مضيف تجميع أساس عنوان، و يأخذ عار معرف رمز إرسال نحو ذلك داخل، معا يجعل متبادل مقابل مسار متابعة من preset تحليل، جعل هو ذاتي حمل ملف ما زال مع هو واحد نفس ترحيل. اكتشاف هو صحيح هو ذلك عدد يأخذ preset كتابة مؤقت أصل دليل حقيقي تجميع اختبار.

**preset id مقابل نموذج مرئي، يجب كتابة سجل.** هو قرار أداة تجميع و نص التوجيه، لذلك يتم استعادة جلسة يجب أيضا أصل نفس نسخة تجميع؛ سجل هو يخص جلسة واقع، بينما غير وقت التشغيل حالة. هو و `cwd` و صف كتابة في جلسة رأس جزء، و من جلسة ملخص يحمل، جعل عميل واجهة عرض بعض عدد جلسة فعلي تشغيل preset، بينما غير نشر حالي قيمة افتراضية.

**حفظ دائم header حقل في provider كتابة قبل كل حساب لا فوق حمل دائم.** `agentPreset` حمل حال صحيح تأكيد إدارة من سقوط في `SessionHeader` فوق، بينما JSONL provider متروك تسرب هو؛ إرسال توليد query index أيضا صريح خريطة header حقل، في هو استعادة بعد Session لا يوجد preset، كل حسب بـ تسمية هو surface مع لـ فقد صوت.`summarizeCold` هو نفس نوع شكل صيغة——هو يد عمل تجميع تركيب cold list row، بينما لا يوجد إعادة استخدام مشترك projection. إعلان لـ حمل دائم حقل، حاجة واحد عبر تجاوز حقيقي store اختبار، بينما لا فقط هو إعلان هو نوع.

**هذا عدد اختيار يخص هو ما زال متاح ذلك عدد واجهة.** تحكم عنصر يقع في جديد بناء جلسة واجهة، مساحة العمل اختيار جهاز جانب حافة، في Host افتراضي فتح بدء سياسة تحت مباشر عرض، فقط في `modeSelectionEnabled` إغلاق بعد إخفاء. اختيار في ذلك داخل هو**مؤقت تخزين**: هذا واجهة أولا في هو يلزم تطبيق إلى جلسة وجود، مؤقت تخزين قيمة في بعض عدد جلسة يصبح حالي جلسة كما ما زال لـ فارغ أبيض وقت سقوط أرض——هذا حيث تغطية مساحة العمل اتصال جديد بناء جلسة، أيضا تغطية هو إعادة استخدام ذلك عدد فارغ أبيض جلسة، بينما تركيب `sessions.create` سهل عربة سوف تسرب إسقاط بعد من. هو واحد مرور استخدام أي يتم صاف فارغ، و جانب حافة مساحة العمل اختيار جهاز متسق؛ إخفاء اختيار جهاز سوف إسقاط بعد لم وصول جلسة مؤقت تخزين اختيار، و عبر نفس بند اختيار سلسلة مسار يأخذ حالي فارغ أبيض جلسة حمل عودة نشر قيمة افتراضية. حتى في تشغيل في أو تاريخ جلسة في ركض ماذا، ما زال من ذلك عنوان جانب فقط قراءة وسم عرض: في ذلك داخل وضع تحكم عنصر، انتظار في تحمل وعد مرة مضيف سوف قطع لكن رفض تبديل.

**preset وضع كبير هو مضيف هذا قدوم حينئذ في دفع بديل قيمة: لا يوجد أي شرق غرب سوف dispose واحد agent.** استخدام `--expose-gc` مقابل مع مرفق تجميع فعلي قياس: واحد تخزين نشط agent في `minimal` فوق نحو احتلال 0.17 MB، في `standard`/`cordis` فوق نحو 1.31 MB، تركيب استهلاك وقت قسم آخر نحو 38 ms و 135 ms؛ عملية داخل رقم واحد agent آخر يحتاج نحو 7 MB، ذلك هو Node أول مرة import وحدة مرة صفة صار هذا، هذا بعد كل مرة تركيب مشترك. زيادة طويل صارم إطار خط صفة——10،30،50 عدد مفرد عدد زيادة كمية متسق——كما dispose بعد أساس هذا كل مقدار عودة استلام (50 عدد `standard` احتلال إقامة 57.8 MB، تحرير بعد الكل عودة أيضا). الذي بـ كائن رسم و لا تسرب تسرب، نقص هو دورة الحياة.`ApiSessionAgentController` سوف إسقاط سجل التسجيل إرجاع `AgentHandle`،`archiveSession` فقط تعديل مساحة العمل سجل التسجيل،`AgentRegistry` لا يوجد دفع تدريجي آلية، بينما مضيف داخل وحيد واحد موضع dispose هو JSON-RPC خادم ذاته صلة توقف. في هو واحد web مضيف سوف إبقاء إقامة هو وصل لمس مرور كل واحد جلسة، تجميع preset بعد كل نحو 1.3 MB، بينما في هذا قبل نحو 0.2 MB. ملاحظة معنى: قص غصن تركيب سجل التسجيل في هذا داخل لا يوجد استخدام——هو إسقاط هو fiber `uid` قد صاف فارغ سجل، بينما دائم لا ميت هلاك agent دائم بعيد لن صاف فارغ هو.

- متروك إبقاء TODO:idle agent دفع تدريجي——جلسة حفظ دائم بعد dispose، استعادة وقت إعادة تركيب. هو يخص يحتفظ handle ذلك عدد مضيف، لا يخص هذا seam.

## اعتبار مرور بديل خطة

**في scope سجل التسجيل في إضافة جديدة preset قسم طبقة.** `ScopedLayers.merge()` يأخذ عام طبقة و تماما جيد واحد دقيق scope طبقة دمج. إضافة جديدة في بين طبقة يمكن يجعل كثير عدد جلسة مشترك استخدام واحد نسخة قد تركيب تجميع، لكن هو يلزم تعديل `dsh-scope` و كل scope شعور معرفة سجل التسجيل، تبديل قدوم فقط هو جزء ثانية درجة فتح إلغاء عقدة حذف، بينما كما سوف يجعل preset تسجيل نيل نيل واحد لا يوجد أي agent يملك دورة الحياة.

**يأخذ agent scope مفتاح ضبط لـ preset.** نفس preset فوق جلسة حينئذ قدرة تجنب استهلاك مشترك واحد طبقة، لكن حسب agent تسجيل——`installAgentLlmTarget`، حسب agent أداة حد——سوف عبر جلسة متبادل اصطدام.

**يأخذ كل preset بصفة عملية فرعية تشغيل.** [`subagent-dsh-sdk`](../../../../packages/subagent/subagent-dsh-sdk/README.zh.md) قد إثبات كامل فرعي harness يمكن سطر، عزل صفة أيضا سوف هو قطعا مقابل. لكن هذا معا معنى طعم حال يلزم حسب جلسة بديل إدارة تدفق صيغة إخراج، مراجعة دفعة و إسقاط، ذلك هو واحد نقل طبقة مشروع، بينما غير تجميع مشكلة.

**إعطاء منتج subagent زيادة عام تفعيل ضبط و مستقل ضبط صفحة.** عملية درجة قيمة سوف و preset تنازع انتزاع نموذج مرئي أداة كل حق، أيضا لا يمكن جدول بلوغ اثنان عدد جلسة استخدام مختلف تجميع. منتج provider إبقاء في مضيف، عادي preset سطر قسم آخر كشف Codex و Claude Code أداة.

**لـ Codex و Claude Code كل نوع تركيب تسليم واحد نسخة preset.** أربعة عدد هوية سوف نسخ كامل preset تجميع، فقط لـ يمثل اثنان بند مستقل سطر. نسخ بعد preset قد قدرة مباشر تفعيل مهمة واحد سطر، لذلك تركيب preset فقط زيادة اسم مفرد و صيانة صار هذا، لا زيادة مستخدم نتيجة.
