# Agent Note: أمر معرف و إدخال إطار يملك ملف حركة عمل

Status: implemented

[English](2026-09-10-command-identities-and-composer-file-action.md) | العربية

## مشكلة

استخدام أمر إنجليزي نص شرح مطابقة عميل كلمة قاموس، سوف يجعل علامة نقطة تعديل أثر محلي تحويل و ملء دخول أمر token. نفس اسم تغطية أيضا ممكن نسخ هذا مقطع شرح، لكن لا يوجد تنفيذ داخل وضع أمر سلوك.«ملف» قائمة مفرد بند حاجة إدخال إطار فوري مرفق عنصر سياسة، يشمل تركيب، قفل تحديد و إيداع حالة، أمر إضافة في آخر طقم فحص لا يمكن تحديد هذه حالة.

## قرار

أمر سجل التسجيل في صالح تعريف و وصف رمز فوق إبقاء اختياري صنف لوحة نوع `CommandDefinitionId` حقل `definitionId`. داخل وضع أمر مزود استخدام حزمة اسم بصفة مستقر معرف. أثر مجال تغطية اختيار كامل وصف رمز، لا وراثة يتم حجب حجب تعريف معرف. هذا معرف هو اكتشاف بيانات وصفية، لا بديل جدول تخويل، أيضا لا دخول أمر دورة الحياة حدث.

عميل أمر دليل عبر داخلي `resolution.ts` تحليل إدخال. دقيق تسجيل اسم أولوية، في إنجليزي نص آخر اسم فقط اختيار جلسة صالح دليل في مقابل داخل وضع تعريف. قائمة مفرد إقرار قيادة استخدام حالي لغة كتابة قاعدة، يد نقل إقرار قيادة إبقاء أصل كتابة قاعدة، إيداع استخدام تحليل إلى تسجيل اسم.`presentation.ts` فقط مسؤول قسم عقدة، عنوان، شرح و رسم علامة. تحليل مساعد مساعدة دالة و صغير عقدة معتاد كمية لا من إضافة مدخل تصدير.

Conversation عبر حقن أمر خدمة تسجيل «ملف» حركة عمل، و مسؤول ذلك محلي تحويل عنوان. قد تركيب إدخال إطار ربط ملف اختيار جهاز عودة ضبط و واحد فوري متاح صفة استعلام. قائمة مفرد مرور ترشيح و فعلي استدعاء استخدام نفس عدد استعلام، موحد واحد معالجة قفل تحديد، إزالة،subagent و إيداع حالة. ربط و استدعاء إبقاء في حزمة داخل عودة ضبط في، لا حاجة عبر إضافة ملف اختيار حدث. تجميع طبقة استخدام ضيق بنية تحويل حركة عمل تسجيل واجهة، لأن أمر UI قد إزالة استهلاك Conversation إدخال نوع، عكس نحو زيادة تحرير ترجمة مشروع اعتماد سوف شكل صار حلقة. تسجيل اختبار استخدام أمر إضافة مساهمة بند نوع إجراء تحقق.

هذا سجل فقط وصل إدارة[إدخال إطار قائمة مفرد قرار](../feature/2026-09-08-composer-menu-sections-and-localized-rows.ar.md) في معرف مطابقة، إدخال تحليل ملكية و ملف حركة عمل ملكية. أصل سجل متابعة مسؤول قائمة مفرد، تمرير، إقرار قيادة إبقاء و تركيب إدخال وقت ترتيب قرار.

## اعتبار مرور بديل خطة

**حسب اسم و إنجليزي نص شرح مطابقة.** نص سجل يمكن تعديل، أيضا يمكن يتم غير متصل تعريف نسخ. مستقر معرف سوف عرض اختيار و نص سجل قسم فتح، بلا حاجة يأخذ محلي تحويل نص نقل إلى مضيف.

**فقط حسب اسم مطابقة.** agent(ذكي جسم) أثر مجال تغطية ممكن لحظة معنى في نفس اسم تحت توفير آخر نوع أمر. حذف غير هو صريح يحمل مقابل معرف، لا فإن لا ينبغي وراثة داخل وضع عرض أو آخر اسم.

**يأخذ ملف حركة عمل إبقاء في أمر إضافة.** إدخال إطار مسؤول مرفق عنصر استقبال و DOM دورة الحياة. صيانة آخر طقم متاح صفة شرط سوف يأخذ نفس سياسة قسم إعطاء اثنان عدد وحدة.

**تصدير مساعد مساعدة دالة بـ توفير إعادة استخدام.** لا يوجد إنتاج استدعاء جهة حاجة يأخذ صغير عقدة معتاد كمية أو تحليل مساعد مساعدة دالة بصفة إضافة API. اختبار مباشر استيراد داخلي وحدة.

## عاقبة

داخل وضع أمر مزود و عميل خريطة يجب استخدام متسق مستقر معرف، رقم ثلاثة جهة تعريف يمكن حذف معرف. عرض نص سجل يمكن مستقل ضبط كامل. سجل التسجيل اختبار تغطية وصف رمز إبقاء و أثر مجال تغطية، عميل اختبار تغطية اثنان نوع لغة تحت تعديل شرح، آخر اسم تحليل و دقيق اسم أولوية. إدخال إطار اختبار تغطية فوري متاح صفة، عودة ضبط استبدال، إزالة و حركة عمل تسجيل dispose(مورد تحرير). قائم جلسة قيادة قائمة مفرد و أمر مشهد متابعة مسؤول تجميع بعد متصفح إخراج.
