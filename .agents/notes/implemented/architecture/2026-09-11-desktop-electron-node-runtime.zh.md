# Agent Note: استخدام Electron بصفة Desktop Node وقت التشغيل

Status: implemented

[English](2026-09-11-desktop-electron-node-runtime.md) | العربية

## مشكلة

في Electron خارج يحمل فوق تنقل Node يمكن تنفيذ ملف سوف تكرار توزيع JavaScript وقت التشغيل.Desktop حاجة يجعل Host و حزمة نص برمجي مشترك استخدام واحد وقت التشغيل، بلا حاجة مستخدم تثبيت Node.

## قرار

Desktop عبر ذاتي ذات Electron يمكن تنفيذ ملف تشغيل مشترك Web Host و داخل وضع pnpm، و ضبط `ELECTRON_RUN_AS_NODE=1`. تطبيق لا يحمل مستقل فوق تنقل Node يمكن تنفيذ ملف. هدف Electron توزيع حزمة معا بصفة تحزيم إدخال، و دقيق تجهيز و تحقق إنتاج اعتماد وقت التشغيل؛ إصدار بيانات وصفية سجل ذلك فعلي Node إصدار. تطوير نمط استخدام قد تثبيت Electron توزيع حزمة.

هذا قرار بديل[تحزيم قرار](2026-08-25-electron-desktop-packaging-and-updates.zh.md) و[داخل وضع وقت التشغيل قرار](2026-09-08-desktop-bundled-runtime-and-external-plugins.zh.md) في مستقل Node اختيار. مستقل إضافة تخزين و عادي مورد دليل تخطيط ما زال ملائم استخدام.[Web رقيق قشرة](2026-09-10-desktop-web-wrapper.zh.md) إبقاء مشترك profile runner و HTTP نقل.

## عاقبة

Host و pnpm بدء وقت نقل دخول `--expose-internals`: داخل وضع Cordis تحميل جهاز استخدام Node داخلي ESM تحميل جهاز، بينما ذلك أصلي builtin وصول جهاز لا يمكن في Electron 44 في بحث إلى الذي يحتاج رمز رقم. صريح معامل جعل تحميل جهاز متاح، بلا حاجة تعديل Cordis.RunAsNode fuse إبقاء تفعيل.

Host وراثة استدعاء من PATH، لا إضافة دخول Desktop خاص `bin` دليل، لذلك PTC و agent shell لن عبر هذا دليل تحليل داخلي بدء جهاز.`DSH_DESKTOP_NODE_EXECUTABLE` فقط لـ حزمة تثبيت حقن. حزمة نص برمجي بيئة في PATH قبل إضافة واحد صغير نوع `node` shell بدء جهاز، يأخذ معامل تحويل إرسال إعطاء حالي Electron يمكن تنفيذ ملف. هذا دعم حمل لا يوجد نظام Node shell دورة الحياة نص برمجي.Windows فوق هو هو `node.cmd`، و غير بديل `node.exe`؛ رقم ثلاثة جهة شفرة إذا التفاف مرور shell مباشر بدء اسم لـ `node` يمكن تنفيذ ملف، يجب استخدام `process.execPath` أو توفير ذاتي ذات وقت التشغيل. عملية فرعية وراثة RunAsNode؛worker خط مسار وراثة Host معامل.Desktop لا نموذج محاكاة فوق تنقل OpenSSL سلوك، أيضا لا تلقائي إعادة تحرير ترجمة مهمة معنى رقم ثلاثة جهة أصلي توسيع.

Electron Node رقعة و أصلي ABI يخص إصدار توافق صفة مسؤولية مهمة. تحزيم أصلي smoke في PATH لا يحتوي نظام Node حال حال تحت تحقق pnpm shell نص برمجي، و تحقق Windows shell طرفية إخراج،Koffi،Sharp و HTML تحويل.Host smoke تحميل مشترك Cordis خارجي إضافة، عبر حقيقي Web تطبيق توفير ذلك توجيه. كل منصة ما زال يحتاج إتمام توقيع و قد تثبيت تطبيق تحقق استلام؛Windows نتيجة لا يستطيع إثبات macOS توافق صفة.Windows Token توقيع سلسلة سطر تنفيذ و إبقاء أول مرة فشل، منع توقف ترتيب طابور مهمة تكرار إيداع يتم رفض PIN.

## اعتبار مرور بديل خطة

مستقل Node يمكن تنفيذ ملف يمكن يجعل Host و Electron وقت التشغيل قسم مغادرة، لكن سوف زيادة آخر نسخة اثنان دخول صنع ملف، تحت تحميل، توقيع و إصدار اختيار.Electron RunAsNode إزالة حذف هذا واحد تكرار. سوف إنتاج حزمة نقل دخول ASAR هو آخر بند تعلق و أصلي وحدة، حزمة تحليل و عملية فرعية مسار تعديل؛Host متابعة تحميل عادي مورد ملف.
