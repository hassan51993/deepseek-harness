# Agent Note: مسبق تحرير ترجمة نظام أصل لغة

Status: implemented

[English](2026-09-07-prebuilt-system-primitives.md) | العربية

## Problem

JSONL كتابة جهة اعتماد `fs-ext` في مستخدم تثبيت وقت تحرير ترجمة NAN addon. لذلك، أصلي تحرير ترجمة جهاز هل متاح و Node وحدة ABI تغير سوف أثر عادي تثبيت، يشمل Node 26. مستودع قد صيانة Landlock بدء جهاز و ذلك حسب منصة إصدار سير العمل.

## Decision

[native/system](../../../../native/system/README.ar.md) في مستقل إصدار `@deepseek-ai/node-addon-system` حزمة عائلة توزيع قائم `landlock-run` يمكن تنفيذ ملف و استخدام مستقر Node-API v8 `system.node` addon. منصة حزمة حسب عملية نظام و CPU اختيار؛Linux قسم آخر يحمل glibc و musl addon ملف.macOS يحمل addon، لكن لا يتضمن Landlock يمكن تنفيذ ملف. مدخل حزمة و منصة حزمة كل لا في تثبيت خلال تحرير ترجمة.

حزمة لا توفير أصل تصدير.`./landlock-run` JavaScript مدخل إبقاء Landlock API و [CLI بروتوكول](../../../../native/system/docs/cli-contract.md).`./flock` مدخل فقط في استدعاء `tryLockExclusive(fd)` وقت تحميل addon. هو في مختلف خطوة أصلي عمل في تنفيذ `flock(fd, LOCK_EX | LOCK_NB)`، و في هذا عمل خط مسار حفظ errno. استدعاء جهة في إتمام قبل يحتفظ وصف رمز، و عبر إغلاق هو تحرير قفل. ربط ناقص وقت رفض نيل أخذ قفل، لا منح إعطاء لا يوجد حفظ حماية قفل.

[Session كتابة إيجار نحو قرار](../feature/2026-08-31-cross-process-session-write-lease.ar.md) متابعة مسؤول نيل أخذ وقت آلة،inode تحقق، إغلاق كل حق و انهيار انهيار دلالة.Windows إبقاء قائم koffi إشارة كمية. متصفح worker فقط استبدال flock فرعي مسار، استخدام لم مرور تعديل `./landlock-run` JavaScript API.

شفرة المصدر بناء في حاجة addon مستودع اختبار و بناء قبل صريح تحرير ترجمة حالي مضيف addon.Native CI بناء كامل منصة ناتج، و يجعل نفسه addon بايت عبر Node إصدار اختبار؛Linux أيضا في Alpine في تنفيذ musl ناتج. منصة prepack رفض صيغة خطأ أو لا كامل اثنان دخول صنع، مغادرة خط npm تثبيت عرض تدريب فحص تثبيت بايت و حقيقي قفل سلوك.Native [اختبار](../../../../native/system/test/flock.test.js) تغطية وصف رمز و عملية تنافس تنازع، إغلاق و انهيار انهيار تحرير، مستقل errno قيمة و worker تنظيف.

## Alternatives considered

**إبقاء NAN، لـ كل Node ABI إصدار بناء.** هذا سوف لـ فقط يحتاج مستقر Node-API عملية ربط إبقاء Node رئيسي إصدار بناء مستطيل دفعة. قد تقييم تقدير `fs-ext-extra-prebuilt@2.2.14` في Node 26 ABI147 تحت اختيار في Node 25 ABI141 اثنان دخول صنع؛ افتراضي تثبيت رجوع أيضا سوف في NAN يتم رفع رفع تثبيت وقت رفع قبل خروج بينما لا تحرير ترجمة.

**سوف fs-ext ضرب دخول أب حزمة tarball.** npm افتراضي ما زال تنفيذ bundled اعتماد تثبيت خطاف. فقط تحزيم حيث لا يستطيع منع توقف تحرير ترجمة، أيضا لا يستطيع يجعل واحد اثنان دخول صنع عبر عملية نظام،CPU،libc تنفيذ أو Node ABI عام.

**سوف flock تبديل صار OFD/fcntl قفل.** في عادي Linux نظام الملفات فوق، هذه قفل لا واحد تحديد ترتيب رفض قائم flock يحتفظ من.tmpfs استكشاف إبرة في fs-ext يحتفظ flock وقت ما زال أخذ نيل OFD قفل، لذلك هذا لا هو إبقاء سلوك استبدال.

**عبر koffi تنفيذ POSIX استدعاء.** تزامن استدعاء تغيير حدث حلقة منع سد سلوك؛ في مختلف خطوة عودة ضبط بعد قراءة errno سوف قراءة إلى خطأ خط مسار قيمة. أصلي async-work مهايئ يأخذ نظام استدعاء نتيجة و errno حفظ في واحد بدء، بلا يجب آخر إضافة FFI تنسيق ضبط طبقة.

## Consequences

حزمة عائلة صيانة صغير نوع C ربط، منصة بناء و تثبيت ناتج تحقق، بينما لا هو كامل طقم نظام الملفات توسيع API.Node-API إزالة حذف حسب Node رئيسي إصدار توزيع اثنان دخول صنع اشتراط، لكن لا إزالة حذف عملية نظام،CPU و libc اشتراط. موحد واحد أصلي إصدار يتضمن اثنان بند قدرة، لكن استيراد أو استخدام منها واحد بند لن تحميل آخر بند.Landlock اثنان دخول صنع دلالة،Windows قفل و قد إصدار Session بيانات صيغة إبقاء ثابت.
