# Agent Note: LLM تدفق إنهاء فشل

Status: implemented

[English](2026-07-29-terminal-llm-stream-failures.md) | العربية

هذا شرح فقط يحل محل[محدود LLM(كبير لغة نموذج) طلب استعادة](2026-06-21-bounded-llm-request-recovery.zh.md) و[استدعاء بعد سياق فيض خروج استعادة](2026-07-10-after-call-compaction-pressure-and-overflow-recovery.zh.md) في صلة في رمي خروج خطأ هوية و استدعاء نطاق جزء sidecar آلية. فوق وصف شرح متابعة قاعدة تحديد بنية تحويل فشل واقع، إعادة محاولة سياسة، حمل دائم محاولة تجربة و ضغط (compaction) استعادة.

## Problem

مهايئ فشل سبق لديه اثنان نوع عام مشترك يمثل: اختيار، توزيع،iterator بنية صنع أو تكرار بديل رمي خروج استثناء، و حمل داخل `finish { kind: 'error' | 'aborted' }`.`LlmRuntime` سوف في بـ تدفق لـ مفتاح sidecar في علامة رمي خروج كائن، جعل agent loop(ذكي جسم حلقة) قدرة سوف ذلك و middleware و مستهلك فشل منطقة قسم فتح. مستهلك ما زال يحتاج استخدام catch حزمة محيط تكرار بديل،signal فحص، قسم قطعة سجل سجل و تجميع؛ صحيح تأكيد صفة لذلك أخذ قرار في إثبات هو أي بند لغة جملة رمي خطأ، و استعلام مرفق حال في الذي إرجاع ذلك عدد iterable بيانات وصفية.

إعادة محاولة سياسة أيضا اعتماد نفس مثال بين وصل ملكية. كل إدارة `prepareCall()` قد التقاط خدمة تسجيل، سياسة ما زال يلزم في توزيع بعد عبر تدفق sidecar فحص بحث. لذلك، من حزمة تركيب طبقة توفير خدمة توجيه و من مهايئ توفير خدمة توجيه مشترك استخدام واحد لا نفاذ واضح استعلام API، كل إدارة اثنان من مرجعي مختلف.

## Decision

`LlmRuntime` هو مرة مهايئ محاولة تجربة مواصفة تحويل حد. هو فقط التقاط نهائي مهايئ اختيار، تزامن توزيع،iterator بنية صنع و `next()` فشل، سوف رمي خروج قيمة تحويل لـ غير ممكن تغيير `LlmFailure`، تزامن خروج واحد إنهاء `finish`. استدعاء جهة إلغاء أو `ABORTED` فشل اختيار aborted انتهاء سبب؛ أخرى مهايئ فشل اختيار error انتهاء سبب. مهايئ أيضا يمكن مباشر إرسال خروج مهمة واحد إنهاء سبب.

مهايئ الذي تابع catch سوف في كل قسم قطعة يتم yield قبل انتهاء. قدوم ذاتي `llm/stream` middleware، تضمين طقم استدعاء، مهايئ تنظيف، قسم قطعة مستهلك، سجل سجل،signal فحص و تجميع خطأ ما زال بصفة نقص وقوع أو دورة الحياة فشل رمي خروج؛ هو جمع أبدا دخول نموذج طلب استعادة. جزء delta بعد نقل فشل ممكن إبقاء تحت لم إغلاق كتلة، لذلك تدفق invariant فقط سماح في إنهاء finish انتهاء سبب لـ error أو aborted وقت وجود لم إغلاق كتلة. لن من هذه لا كامل إخراج تجميع assistant رسالة أو أداة استدعاء.

`PreparedLlmCall` عام مع ذلك إعداد و تسجيل التقاط غير ممكن تغيير إعادة محاولة سياسة. مرة صفة جملة مقبض إعادة استخدام و إعداد لا مطابقة ما زال هو تزامن `INVALID_PREPARED_CALL` خطأ استخدام خطأ. تماما من `llm/stream` middleware توفير خدمة توجيه لا يوجد دقيق تجهيز إتمام تسجيل، لذلك أيضا لا يوجد خدمة سياسة.

agent loop فقط إزالة استهلاك واحد نوع فشل يمثل. هو لم يعد استخدام تصنيف catch، بينما هو مباشر تكرار بديل و سجل قسم قطعة، فحص إنهاء finish، مجددا يأخذ منها فشل واقع و دقيق تجهيز إتمام سياسة نقل إعطاء `agent/request-error`. عام مشترك `isLlmAdapterFailure`،`llmFailureOf` و `llmRetryPolicyOf` sidecar API لم يعد وجود.

## Alternatives considered

**إبقاء استدعاء نطاق جزء خطأ علامة.** هذا سوف إبقاء رمي خروج كائن هوية، لكن اشتراط كل مستهلك استخدام catch حزمة محيط واحد مقطع يتضمن ذاته سهل فشل عمل منطقة مجال، و يجعل تصنيف اعتماد iterable حزمة تركيب طبقة هوية. أصلي خطأ كائن لا يمكن في استعادة في إرسال تلويح حمل دائم أثر؛ مواصفة تحويل واقع عندئذ هو لديه استخدام حد قيمة.

**اشتراط كل مهايئ إرسال خروج فشل قسم قطعة، و منع توقف رمي خروج.** مكتبة iterator،transport و JavaScript توزيع ما زال ممكن رمي خطأ. اشتراط كل مهايئ نسخ نفس catch حد سوف صنع صار مسؤولية تكرار، أيضا لا يمكن حفظ حماية `LlmRuntime` مباشر مستهلك تجنب تلقي لا كامل تنفيذ أثر.

**في agent loop في التقاط كل تكرار بديل خطأ.** إذا لا إعادة بناء قيام من تدفق كائن إلى إنشاء هذا كائن مهايئ استدعاء sidecar خريطة،loop لا يمكن يمكن اعتماد منطقة قسم مزود فشل و middleware، جلسة إلحاق، إلغاء أو تجميع فشل. تصنيف ينبغي من إرسال بدء مهايئ استدعاء موضع مسؤول.

**في تدفق صيغة إخراج قبل إرجاع `Result`.** تدفق قبل نتيجة لا يمكن يمثل جزء إخراج بعد نقل فشل، حذف غير زيادة ثاني طقم استجابة دورة الحياة. قائم إنهاء قسم قطعة قد قدرة يمثل مبكر مدة و بعد مدة محاولة تجربة نتيجة.

## Consequences

كل `LlmRuntime.stream()` مستهلك كل عبر واحد نوع حمل نوع إنهاء بروتوكول استقبال مهايئ تشغيل فشل، بينما تحرير مسار و دورة الحياة فشل إبقاء عادي استثناء دلالة. استعادة وضع ترك دقيق رمي خروج كائن هوية، فقط كشف و أصل كائن قسم مغادرة مزود غير متصل واقع. تدفق خدمة تحمل تحمل اختصار كثير مهايئ معالجة عمل، لكن مستهلك حذف لأجل حكم قطع أي عدد مهايئ رمي خروج استثناء catch، أيضا حذف بـ تدفق لـ مفتاح بيانات وصفية. دقيق تجهيز إتمام استدعاء صريح يحمل سياسة، بينما تماما من middleware توفير خدمة توجيه ما زال واضح لا يوجد سياسة.
