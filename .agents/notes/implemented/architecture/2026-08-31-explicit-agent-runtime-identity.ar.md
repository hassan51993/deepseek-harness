# Agent Note: وقت التشغيل حد صريح يحمل Agent هوية

Status: implemented

[English](2026-08-31-explicit-agent-runtime-identity.md) | العربية

## مشكلة

Agent Cordis Context يملك تسجيل و ذلك تنظيف.Agent هوية فإن لـ بعض بند عملية اختيار جلسة، وقت التشغيل الذي تابع جهة، حدث رئيسي جسم، إذن قرار أو بروتوكول هوية.Context فوق عكس نحو Agent خاصية يجعل هذا اثنان عدد واقع نظر بدء قدوم يمكن متبادل تبديل: استدعاء جهة اختيار لأجل إدارة effect كل حق Context وقت، ممكن معنى خارج أرض يجعل هذا اختيار قرار مجال هوية.

نوع معلومة يتم مسح حذف بعد، هذا بند عكس نحو صلة ربط أيضا حاجة تكملة تعويض آلية.Host Remote تحويل إرسال سوف من قد توجيه رئيسي جسم فحص ذلك Context، إنشاء مسار سوف من استدعاء جهة Context دفع قطع وقت التشغيل أب درجة، مهايئ فإن صيانة عكس نحو هوية مسح. هذه آلية تكرار نوع تحويل طلب في قد لديه هوية، أيضا إخفاء غطاء أي عدد استدعاء جهة في وقت التشغيل يملك Agent.

إذا لا يوجد صريح الذي تابع جهة،`SubagentContinuationManager` سوف عبر خاص إضافة Context إنشاء و استعادة فرعي درجة، لذلك أساس في Context دفع قطع سوف يأخذ كل يمكن متابعة ركض فرعي درجة عودة صنف لـ runtime root، كل إدارة إدارة جهاز يحتفظ ذلك تأكيد قطع أب درجة. فقط حد أصل درجة مستهلك مع بعد ممكن مرفق إضافة ضبط درجة أداة، منح إعطاء مباشر شخص صنف إدخال مقابل Goal إذن، أو مثل معالجة قمة طبقة Agent واحد مثال توجيه مستخدم مشكلة.

## قرار

وقت التشغيل واجهة في يملك هوية موضع يحمل Agent هوية.`AgentSetup` استقبال `(agentCtx, agent)`؛ إنشاء و استعادة Agent options عبر `parentAgent` معرف وقت التشغيل فرعي درجة؛ أثر مجال حدث في payload في يحمل Agent؛Remote تحويل إرسال تحقق `request.agent` حينئذ هو carrier key؛Host Typert Context تحليل فإن يأخذ بروتوكول هوية خريطة إلى تخزين نشط Agent Context، لا تنفيذ عكس نحو مسح.`agent.ctx` متابعة يملك تسجيل و دورة الحياة، لا كشف عكس نحو Agent خاصية.

شعور معرفة أثر مجال سجل التسجيل متابعة فقط استخدام لا نفاذ واضح أثر مجال مفتاح حكم قطع تسجيل عضو علاقة.tool-subagent لن تصنيف هذا مفتاح، أيضا لن من Context تحليل Agent. مباشر `AgentSetup` صريح نقل دخول بعد لم إصدار Session، و في إصدار قبل عبر الذي إعطاء Context إتمام تثبيت. مقابل في من ضبط تحكم معتاد إقامة preset، حدث payload توفير Agent، ذلك Session توفير سياسة هدف، ذلك Context يملك تسجيل بند.

`SubagentContinuationManager` سوف يأخذ تأكيد قطع أب درجة وضع دخول كل جديد إنشاء و بارد استعادة options. لذلك، تخزين نشط يمكن متابعة ركض فرعي درجة لن ظهور في `AgentRegistry.roots()` في، و كما ممتلئ كاف `isOwnedBy(child.id, parent)`. حفظ دائم `parentSession` بيانات وصفية لا يستطيع بديل بديل هذا بند علاقة: لا يوجد تخزين نشط Agent يملك fork أو قد استعادة جلسة وقت، هو ما زال يمكن يصبح runtime root.

[Agent تسجيل أثر مجال قرار](2026-07-08-agent-scope-contexts.ar.md) ، ذلك[وقت التشغيل تصميم](2026-07-12-agent-scope-runtime-design.ar.md) و[إرسال بدء جهة أثر مجال قرار](2026-07-15-agent-initiator-scope.ar.md) متابعة يملك كل منها مستقل تسجيل، دورة الحياة و خاص استدعاء سلسلة إدارة من. هذا قرار فقط يحل محل منها وصف عكس نحو Context صلة ربط و خفي صيغة وقت التشغيل الذي تابع جهة دفع توجيه.

## تحقق

Agent إنشاء اختبار قفل تحديد صريح أصل درجة و فرعي درجة ملكية.continuation اختبار تكامل يجعل واحد حقيقي فرعي درجة إبقاء تخزين نشط، مباشر إلى تأكيد ذلك حيث لا يخص `roots()`، أيضا ممتلئ كاف `isOwnedBy()`. قائم Schedule اختبار تحقق فقط حد أصل درجة تسجيل بند لن ظهور في صريح ملكية فرعي درجة في.

Remote حدث اختبار سوف في تحويل إرسال أثر مجال waterfall قبل رفض ناقص أو لا مطابقة Agent.tool-subagent اختبار تحقق direct setup سوف في Session إصدار قبل إتمام تثبيت؛ معتاد إقامة preset اختبار تحقق تدريجي Session سياسة قراءة و وراثة.

## اعتبار مرور بديل خطة

**إبقاء `Context.agent`.** عكس نحو accessor سوف يجعل تسجيل كل حق نظر بدء قدوم انتظار نفس في عملية هوية، أيضا اشتراط كل Context إرسال توليد، مهايئ و اختبار بديل ذات إبقاء واحد بند و Cordis خدمة اختيار أو effect تنظيف غير متصل صلة ربط.

**من استدعاء جهة Context دفع قطع وقت التشغيل ملكية.** خاص إدارة جهاز Context،Agent Context و معتاد إقامة preset Context كل قدرة استدعاء نفس عدد عمل مصنع. لذلك،Context أصل أولا علاقة لا يمكن شرح من أي عدد تخزين نشط Agent يملك نتيجة؛ إنشاء جهة يجب يأخذ هو معروف أب درجة وضع دخول طلب options.

**تصنيف Agent أثر مجال مفتاح.** لا نفاذ واضح أثر مجال مفتاح جدول بلوغ توجيه عضو علاقة، بينما لا هو مجال هوية. تصنيف هذا مفتاح سوف يجعل Agent يصبح تركيب في قلب، أيضا ما زال سوف يأخذ إضافة effect كل من و سياسة الذي يحتاج Session اقتران دمج بدء قدوم.

**استخدام إرسال بدء Agent بصفة إنشاء ملكية.** إرسال بدء جهة أثر مجال سجل مختلف خطوة تنفيذ بسبب نتيجة علاقة، بينما غير دورة الحياة ملكية. أب درجة ممكن إرسال بدء متعمد إنشاء أصل درجة Agent عمل، بينما setup ما زال يقع في فرعي درجة قيادة حد خارج.

**استخدام حفظ دائم جلسة جدول نظام.** `parentSession` عبر عملية دورة الحياة سجل محادثة أصل أولا علاقة. وقت التشغيل ملكية تحكم تخزين نشط أصل درجة و teardown، لذلك يأخذ اثنان من انتظار نفس سوف منع توقف دمج قاعدة استعادة fork يصبح قمة طبقة Agent.

## عاقبة

دورة الحياة options، حدث، خدمة طلب و نقل طلب سوف يحمل صريح Agent هوية، لذلك كل بند عملية كل سوف إعلان ذاته استخدام هوية،TypeScript أيضا سوف فحص اثنان جانب.Context يمكن متابعة إعادة استخدام في اعتماد وصول و effect كل حق، بينما لن يصبح آخر نوع مجال كائن تحديد موضع جهاز.

يمكن متابعة ركض فرعي درجة و مرة صفة عملية داخل فرعي درجة استخدام نفس نوع وقت التشغيل أب درجة علاقة. فقط حد أصل درجة مستهلك سوف ترتيب حذف هذه فرعي درجة، أب درجة teardown يمكن اعتماد حسب وحيد تخزين نشط ملكية رسم دفع إدارة، بينما حفظ دائم جدول نظام ما زال يمكن وصف تاريخ، لا لا بد تحمل تحمل عملية داخل دورة الحياة دلالة.
