# Agent Note: مساحة العمل ملف قراءة إذن

Status: implemented

[English](2026-09-09-workspace-file-read-authority.md) | العربية

## Problem

Workspace Files معا توفير ملف محتوى و مساحة العمل تنقل. مقابل كل عملية تطبيق مساحة العمل يتضمن حد، سوف في Session نظام الملفات خلفية لـ فوق شكل صار ثاني طقم قراءة سياسة، و منع توقف مستخدم معاينة نفس Session في مساحة العمل خارج يمكن قراءة مسار.HTML معاينة أيضا حاجة مباشر قراءة متبادل مقابل JavaScript و مثال صيغة جدول ملف، يشمل يحتوي `..` مسار، بينما تفعيل نص برمجي وثيقة يمكن استخدام متصفح شبكة شبكة.

## Decision

`read`،`readBytes`،`readAll`،`readRelated` و `stat` وراثة يتم بحث عنوان Session نظام الملفات خلفية قراءة إذن. مساحة العمل أصل هو إدخال متبادل مقابل مسار أساس دقيق، بينما لا هو قراءة حد؛ فقط يلزم خلفية سماح، حينئذ يمكن قراءة قطعا مقابل مسار و مغادرة فتح مساحة العمل متبادل مقابل مسار. خدمة ما زال اشتراط عادي ملف، رفض رمز رقم رابط، و تطبيق نص و بايت حد أعلى.

`list` و `changes` ما زال حد في مساحة العمل، لأن هو جمع كشف مساحة العمل تنقل و مراقبة، بينما لا هو قراءة واحد أداة اسم ملف.`list` رفض أصل خارج دليل،`changes` عبر خلفية مساحة العمل يتضمن حكم تحديد مرور ترشيح مراقبة.

`readRelated` من أساس دقيق ملف الذي في دليل تحليل متبادل مقابل مسار. لذلك، فقط يلزم Session خلفية سماح،`..` مسار حينئذ يمكن قراءة مساحة العمل خارج JavaScript أو CSS.Document Preview يأخذ محدود، ساكن حالة إعلان محلي نص برمجي و مثال صيغة جدول تحزيم دخول حمل `sandbox="allow-scripts"` HTML Blob iframe؛ لا نفاذ واضح مصدر منع توقف وصول أب تطبيق، لكن متصفح إبقاء صحيح معتاد شبكة شبكة وصول. هذا نوع كشف هو لـ تصيير ساكن حالة توليد HTML بينما متعمد قبول أمان أخذ ترك.

[Workspace Files خدمة](2026-09-05-workspace-files-service.ar.md) مسؤول قسم صفحة، ملف فحص، صف رفع و مراقبة.[Document Preview](2026-09-08-document-preview-operations.ar.md) مسؤول اختيار يلزم تحزيم صلة ربط ملف و iframe sandbox.

## Alternatives considered

**يأخذ كل عملية حد في مساحة العمل داخل.** هذا سوف يجعل معاينة اعتماد مقارنة Session نظام الملفات خلفية أكثر ضيق سياسة، منع توقف قراءة واضح بحث عنوان يمكن قراءة ملف، و جعل يقع في خارجي مورد جانب HTML لا يمكن تصيير. عملية ذاته بديل جدول مساحة العمل وقت، ما زال إبقاء مساحة العمل يتضمن حد.

**سماح أصل خارج قراءة، لكن منع قطع iframe الكل شبكة شبكة.** أكثر صارم إطار CSP يمكن خفض منخفض بيانات خارج نقل ريح خطر، لكن أيضا سوف رفض ساكن حالة HTML معاينة متعمد إبقاء خارجي مورد و شبكة شبكة سلوك. لا نفاذ واضح sandbox حفظ حماية أب تطبيق، لكن لا تحمل وعد شبكة شبكة عزل.

## Consequences

يحتفظ صالح Session ملف عنوان استدعاء جهة يمكن استقبال Session نظام الملفات خلفية سماح قراءة كل عادي ملف بايت، يشمل مساحة العمل خارج ملف. معاينة HTML وثيقة يمكن تنفيذ قد تحزيم محلي JavaScript، تزامن بدء شبكة شبكة طلب. مساحة العمل خارج ملف لن إنتاج `changes` لقطة، لذلك ذلك معاينة حاجة صريح تحديث جديد عندئذ قدرة مراقبة تحديث.
