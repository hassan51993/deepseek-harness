# Agent Note: مستقل LibreOffice kit ملكية

Status: implemented

[English](2026-09-14-independent-libreoffice-kit.md) | العربية

## Problem

LibreOffice تحرير ترجمة، شفرة المصدر رقعة، منصة مورد إطار تحقق و كبير نوع اثنان دخول صنع إصدار صيانة دورة مدة مختلف في Harness إضافة. سوف هو جمع وضع في تطبيق مساحة العمل سوف توسيع كبير معتاد قاعدة CI، و يجعل جذب محرك إصلاح اعتماد monorepo حزمة قاعدة.

## Decision

`deepseek-harness/libreoffice-kit` مستودع صيانة يمكن إعادة استخدام `@deepseek-ai/libreoffice-kit` Node API،Worker، حرف جسم معالجة، جذب محرك اختيار، بناء إعداد جهة، رقعة، اختبار و إصدار.API لا اعتماد Cordis.Harness مسؤول سوف ذاتي ذات `OfficeToPdf` خدمة ملائم إعداد إلى هذا API، و Session تخويل، تحويل دورة الحياة، نقل،Web UI و تطبيق تحزيم.

kit إصدار مسار مستقل في Harness إصدار مسار.kit مستودع تحقق و بـ موحد واحد إصدار إصدار Node API و جذب محرك npm حزمة، بدء بداية إصدار لـ `0.0.1`.Harness إزالة استهلاك دقيق npm إصدار، و في `pnpm-lock.yaml` في إيداع اعتماد تحليل نتيجة؛Harness إصدار حيث لا بناء أيضا لا إصدار kit حزمة.

فوق تنقل API سوف منصة جذب محرك إعلان لـ اختياري اعتماد.[منصة جذب محرك قرار](2026-09-15-platform-office-engines.zh.md) يحل محل الأكثر أول قوي صنع يحمل WASM رجوع جذب محرك سياسة.Desktop سوف kit بصفة خارجي npm اعتماد تثبيت.Python sidecar سوف Worker، الذي اختيار جذب محرك و ذلك اعتماد إغلاق حزمة إبقاء في حقيقي نظام الملفات في، يقع في يمكن تنفيذ ملف وهمي محاكاة نظام الملفات خارج. تحويل بلا حاجة تحت تحميل أو GitHub اعتماد.

kit مستودع مسؤول جذب محرك مورد إطار تحقق و مقابل شفرة المصدر مادة مادة.API و جذب محرك يحمل MPL-2.0 إعلان، يمكن وصول شفرة المصدر و مجددا توزيع إعلان؛Harness تحزيم وقت إبقاء هذه مادة مادة. مجددا توزيع إعلان فحص فقط في سماح يمكن لـ MPL-2.0 وقت قبول API،WASM،macOS ARM64/x64 و Windows ARM64/x64 دقيق حزمة معرف؛ غير متصل حزمة و تغيير بعد سماح يمكن بند بند ما زال يتم رفض.

## Alternatives considered

**سوف عام API و Core بناء وضع في Harness.** هذا قدرة تزامن شفرة المصدر تغيير، لكن يجعل تطبيق صيانة تحمل تحمل استهلاك وقت جذب محرك بناء و خاص خاص حزمة قاعدة.Cordis provider هو تطبيق تجميع صار نقطة؛ يمكن إعادة استخدام تحويل API ينبغي و جذب محرك اختبار وضع في واحد بدء.

**تثبيت قبل دقيق تجهيز GitHub Release عودة ملف.** هذا حاجة مفرد وحيد تمييز حق، ها أمل، حل ضغط، مساحة العمل overrides و توزيع إعادة تحزيم. قد إصدار npm حزمة استخدام تطبيق معتاد قاعدة اعتماد تثبيت و منصة اختيار مسار.

## Consequences

تحديث kit حاجة في ذلك مستقل مستودع تحقق تزامن نشر جديد إصدار، مجددا تحديث Harness اعتماد إصدار و قفل ملف. مطلوب npm حزمة ناقص وقت تثبيت فشل؛Harness لا عبر تحرير ترجمة جذب محرك استعادة. أصلي و WASM تحويل خطر دخان تحقق قد تثبيت حزمة،Desktop و Python فحص تغطية تطبيق تحزيم.
