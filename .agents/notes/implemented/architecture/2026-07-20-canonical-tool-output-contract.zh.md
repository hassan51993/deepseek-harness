# Agent Note: مواصفة أداة إخراج اتفاق

Status: implemented

[English](2026-07-20-canonical-tool-output-contract.md) | العربية

## مشكلة

أداة رئيسي جسم مرور ذهاب مباشر تحرير كتابة موجه إلى نموذج `ContentBlock[]`، و اختياري اختيار سوف ذلك و لا نفاذ واضح `meta` حزمة تركيب في واحد بدء. لذلك،Native نمط Function Calling(دالة استدعاء) رغم لكن يملك يمكن توفير شخص قراءة قراءة إسقاط، لكن برنامج تحويل استدعاء جهة لا يوجد مستقر مجال قيمة:PTC mode سوف سوف محتوى كتلة إعادة عرض مستو لـ نص، حركة حالة أداة سوف تكرار تعريف محتوى شكل، سياسة أيضا يمكن استبدال عرض محتوى، لكن لا يمكن منطقة قسم هذا بند تغيير بحث فعلا هو استبدال عرض، أيضا هو استبدال عملية نتيجة. كثير عدد قدرة seam قد إرجاع معلومة أكثر وفير غني مزود قيمة، لكن أيضا في موجه إلى نموذج أداة حد إسقاط هذه قيمة.

حمل دائم جلسة اتفاق سوف هذا نسخة عرض محتوى نظر لـ إعادة تشغيل وقت مرجعي مصدر، لكن إذا حفظ دائم كل واحد معلومة وفير غني في بين قيمة، حينئذ سوف توسيع كبير سجل، جعل تنفيذ بيانات دخول ضغط (compaction) و ترحيل مسار، أيضا سوف خطأ أرض يأخذ تنفيذ مدة محلي API تغيير صار جلسة صيغة واحد جزء. لذلك، نظام قاع طبقة حاجة في تنفيذ خلال إبقاء واحد نوع تحويل قيمة، و صريح سوف ذلك إسقاط لـ قائم حفظ دائم محتوى و نموذج مرئي محتوى.

## قرار

كل أداة كل يجب إعلان مواصفة إخراج، و كما فقط قدرة إرجاع هذا إعلان وصف قيمة:

```ts ignore-check
output: {
  schema: OutputSchema
  render(args, value): ContentBlock[]
  presentationMeta?(args, value): JsonValue
}
```

`defineTool` من موحد واحد `ValueSchemaSpec` دفع توجيه أداة رئيسي جسم قيمة راجعة و اثنان عدد إسقاط جهاز نوع. أصلي تعريف و حركة حالة تعريف فإن توفير تحرير ترجمة بعد `JsonSchemaNode` شكل صيغة. تسجيل وقت سوف رفض ناقص إخراج إعلان أو اعتماد لا تلقي دعم حمل أصلي schema تعريف، لا توفير توافق قديم صيغة محتوى قيمة راجعة مسار.

كل مرة نجاح توزيع وقت، سجل التسجيل سوف سوف قيمة راجعة لقطة لـ بلا ضرر `JsonValue`، اعتماد حسب `output.schema` تحقق و عميق درجة تجميد ربط، لكن بعد استدعاء صاف مصير؛ مقابل في مباشر خارج طبقة استدعاء، أيضا سوف استدعاء اختياري بيانات وصفية إسقاط جهاز. مصير، إسقاط جهاز،schema أو بلا ضرر JSON معالجة فشل كل سوف يتم استلام جمع لـ عادي `ToolOutputError` نتيجة. محيط التفاف `tools/execute` حزمة تركيب طبقة استقبال و إرجاع مواصفة نجاح/فشل ربط دمج؛ حزمة تركيب طبقة ذاتي سطر إنتاج نجاح نتيجة سوف مجددا مرة عبر قد تحليل أداة إخراج إعلان إتمام عودة واحد تحويل، بينما لن معلومة مهمة ذلك مستقل تحرير كتابة محتوى. كل مواصفة نتيجة كل و إنشاء هو غير ممكن تغيير توزيع token ربط؛ لذلك، إذا حزمة تركيب طبقة إرجاع قدوم ذاتي أخرى استدعاء أو أداة ذاكرة مؤقتة نتيجة، نظام سوف اعتماد حسب حالي توليد فاعلية إخراج إعلان إعادة تنفيذ عودة واحد تحويل، بينما لن التفاف مرور هذا واحد خطوة.

```ts ignore-check
type ToolExecutionResult =
  | { isError: false; value: JsonValue; content: ContentBlock[]; meta?: JsonValue; additionalContexts?: HookContext[] }
  | { isError: true; error: { message: string; info?: { name: string; code: string } }; content: ContentBlock[]; meta?: JsonValue; additionalContexts?: HookContext[] }
```

`tools/post-execute` لـ نجاح نتيجة توفير اثنان نوع متبادل رفض إسقاط طريقة. استبدال `content` فقط تغيير Native/نموذج عرض، و إبقاء مواصفة قيمة و بيانات وصفية. استبدال `value` سوف إعادة تحقق بديل قيمة، و إعادة حساب حساب اثنان نسخة عرض إسقاط. منع توقف عملية سوف إزالة قيمة و تحويل لـ فشل. لذلك، استبدال محتوى و لا هو حفظ سري آلية: يجب منع توقف برنامج تحويل وصول سياسة، ينبغي عند منع توقف استدعاء أو استبدال قيمة.

مواصفة قيمة فقط وجود في تنفيذ خلال.agent loop(ذكي جسم حلقة) حفظ دائم `tool/result` فقط يتضمن `content`،`error` و اختياري `meta`؛PTC mode `tool/ptc-dispatch` حفظ دائم فرعي استدعاء تصيير بعد `content` و `isError`. اثنان عدد حدث كل لا تخزين مواصفة في بين قيمة، لذلك إعادة تشغيل يمكن إعادة الآن عرض، لكن لا يمكن إعادة بناء برنامج تحويل نتيجة. عند أداة إعلان `presentationMeta` وقت، نظام فقط سوف لـ مباشر خارج طبقة استدعاء حساب حساب هو؛ تضمين طقم Code توزيع لا يوجد بيانات وصفية.Client يمكن من أصلي معامل و تصيير بعد محتوى إرسال توليد[تضمين طقم terminal بطاقة](../bug-fix/2026-09-05-nested-terminal-cards.zh.md) ، بلا حاجة هذه بيانات وصفية. خارج طبقة `run_code` بطاقة فإن قراءة نهائي post-policy محتوى، و كما لا إعلان عرض بيانات وصفية. عام و أداة ذاتي لديه spill إسقاط نفس مثال قفز مرور تضمين طقم توزيع، لأن هو جمع مواصفة قيمة دائم بعيد لن دخول نموذج سياق.

رقم واحد جهة أداة في إبقاء قائم Native نص ثابت معا إرجاع مجال DTO:

| أداة نظام صف | مواصفة قيمة |
|---|---|
| `read` | `{ path, offset, lines: [{ number, text }], totalLines }` |
| `write` | `{ path, operation: "create" | "update", before: string | null, after }` |
| `edit` | `{ path, before, after }` |
| `glob` | `{ paths: string[] }` |
| `grep` | `{ matches: [{ path, lineNumber, line }] }` |
| `web_search` / `web_fetch` | عودة واحد تحويل بعد `WebSearchResult` / `WebFetchResult` |
| `lsp` | `{ kind: "locations", locations, resolvedWorkspaceUri }` أو `{ kind: "hover", hover }` |
| `bash` | `{ kind: "background", jobId }` أو `{ kind: "foreground" } & ShellRunResult` |
| `terminal_open` / `terminal_list` / `terminal_send` / `terminal_read` / `terminal_signal` / `terminal_close` | عام جلسة لقطة، محدود قراءة/إرسال DTO، إشارة/إغلاق عملية نتيجة، أو خلفية مهمة جملة مقبض |
| `job_output` / `job_list` / `job_kill` | لا يحتوي كل من أو إشعار إدارة معلومة عام مهمة لقطة |
| `subagent` | خلفية مهمة جملة مقبض أو `{ kind: "foreground", runId, output: JsonValue[] }` |
| `workflow` / `ralph` | `{ runId, agentsStarted, result: JsonValue }` |
| `skill` | `{ name, provider, resourceBase?, content }` |
| `todo_write` | `{ todos, counts }` |
| `ask_user_question` | `{ answers: [{ id, selected, custom? }] }` |
| `exit_plan_mode` | `{ approved: true }` |
| `cordis_inspect` / `cordis_mount` / `cordis_unmount` | فحص نص أو نوع تحويل مؤقت إضافة جملة مقبض |
| `structured_output` | `{ recorded: true }` |
| `run_code` | `{ logs: string[], result?: JsonValue }` |

مزود و منفذ أخذ تجميع حد أعلى ما زال سوف فعلي حد مواصفة قيمة. فقط لأجل صيغة تحويل حد عودة `render` كل؛ مثال مثل،`glob` و `grep` سوف في `value` في إبقاء كل قد أخذ تجميع بند، بينما ذلك Native إسقاط سوف إبقاء إعداد إشارة تحديد رقم واحد صفحة، و كل قوة سوف ذلك كتابة spill ملف. عام spill سوف قبل وضع تسجيل ذلك post-execute مستمع، و يجعل هذا مستمع أولا نحو بعد تفويض حمل، لذلك بلا نقاش إضافة تحميل ترتيب مثل أي، عادي أداة ذاتي لديه مختلف خطوة إسقاط كل سوف في عام بايت عدد حد أعلى معالجة قبل إتمام. نظام الملفات تغيير أداة أصل حسب `args` و مواصفة تغيير قبل/بعد قيمة دفع توجيه يمكن إعادة تشغيل diff بيانات وصفية، لم يعد من أداة رئيسي جسم إرجاع UI حالة.

MCP جسر وصل طبقة عبر `McpResult<{...}> = { content: JsonValue[]; structuredContent? }` إبقاء بروتوكول محتوى كتلة. عند عام نشر `outputSchema` يخص تلقي دعم حمل أصلي فرعي تجميع وقت، نظام سوف قوي صنع تحقق؛ لا تلقي دعم حمل schema فإن رجوع لـ `JsonValue`، بينما لن زائف تركيب قد إتمام تحقق.Native تصيير ما زال استخدام قائم MCP إلى `ContentBlock` إسقاط،MCP `isError` فإن سوف تغيير لـ فشل أداة نتيجة.

## تجهيز اختيار خطة

- **نحو PTC mode إرجاع تصيير بعد نص:**غير مقبول. استدعاء جهة ما زال يحتاج من ذاتي لكن لغة في رفع أخذ job id، تركيب id، مسار و بنية تحويل مزود نتيجة.
- **في `tool/result` فوق حفظ دائم مواصفة قيمة:**غير مقبول. تضمين طقم تنفيذ قيمة لا يخص نموذج تاريخ سجل، بلا حاجة في إعادة تشغيل بعد متابعة وجود؛ حفظ دائم أيضا سوف جذب دخول و Native إعادة بناء غير متصل جلسة صيغة و تخزين تحمل وعد.
- **سماح أداة معا قيمة راجعة و محتوى:**غير مقبول. من عمل من قسم آخر صيانة اثنان نسخة نتيجة ممكن متبادل متبادل تناقض درع، سياسة أيضا لا يمكن شرح أي واحد نسخة عندئذ هو مرجعي نتيجة. مصير سوف أصل حسب قد تحقق قيمة تحديد صفة أرض إنتاج عرض.
- **سوف محتوى استبدال نظر لـ قيمة انفصال حساس:**غير مقبول. عرض محتوى و برنامج تحويل وصول موجه إلى مختلف مستهلك؛ فقط إخفاء قبل من سوف صنع صنع وهمي زائف أمان حد.
- **اشتراط أداة إخراج يجب بـ كائن لـ أصل:**غير مقبول. علامة كمية، عدد مجموعة و null نتيجة كل هو دمج إدارة JSON API. فقط لديه من استدعاء جهة تعريف subagent/سير العمل بنية تحويل إخراج ما زال تلقي مستهلك كائن أصل قاعدة قيد.

## أثر

Native و إعادة تشغيل سلوك ما زال بـ محتوى لـ أولا، و إبقاء تدريجي بايت توافق؛ تنفيذ مدة استدعاء جهة فإن بلا حاجة تحليل محتوى، يكفي استخدام مرور مرور تحقق مجال قيمة. فشل نتيجة يجب يتضمن رسالة، و اختياري اختيار مرفق إضافة داخلي صنف اسم/شفرة معلومة؛ نجاح و فشل نتيجة من حكم آخر حقل منطقة قسم، فشل نتيجة أبدا سوف تحمل وعد وجود قيمة. أداة عمل من يجب واحد و تصميم قيمة و ذلك Native إسقاط؛ زيادة هذا بند إعلان هو متعمد لـ لـ، لأن هو تجنب تجنب من ذاتي لكن لغة محتوى معنى خارج دفع توجيه خروج برنامج تحويل اتفاق.

في بين قيمة فقط تلقي إنتاج هو جمع قدرة و عملية داخل تخزين حد. سجل لا يتضمن هذه قيمة، لذلك إعادة تشغيل لا يمكن استعادة؛ فقط معالجة محتوى post سياسة أيضا لا يمكن إخفاء هذه قيمة. هذه كل هو تنفيذ مدة محلي اتفاق واضح خاصية، و غير معنى خارج نقص فتحة.
