# Agent Note: وثيقة معاينة و ملف عنوان

Status: implemented

[English](2026-09-08-document-preview-operations.md) | العربية

## مشكلة

ملف معاينة جهاز حاجة مختلف تحميل سياسة، نفس توسيع اسم أيضا ممكن مقابل كثير نوع تنفيذ. تغيير تدفق لا يمكن معا جدول بلوغ حسب يحتاج قراءة بينما أيضا لا يأخذ فوري بيانات و يمكن استدعاء قدرة خلط في واحد بدء.HTML اعتماد أيضا حاجة Host نظام الملفات تخويل و مسار تحليل، بينما غير متصفح حالي دليل.

## قرار

Document Preview سوف مورد مراقبة و محتوى قراءة قسم فتح.[مورد نموذج](2026-09-05-client-resource-model.ar.md) فقط حسب عنوان مشترك مراقبة:`source(address)`،`pin(address, signal)` و مزود `open(address, { signal })` متساو لا يحمل إزالة استهلاك Session. مزود إرجاع `AsyncIterable<RemoteResult<ResourceProtocolMap[P]>>`؛`useResource` فقط كشف `{ status, value, failure }`. يحتفظ فقط تحكم مراقبة بدء توقف، لا تحكم قاع طبقة ملف أو Session توليد إطفاء. محتوى عبر عادي حقن Preview عودة ضبط قراءة.

[Workspace Files](../../../../packages/api/workspace-files/README.ar.md) إبقاء Host سطر قراءة، بايت نافذة، لديه حد أعلى كل نص قراءة و متبادل مقابل آخر ملف دليل محدود قراءة.Client `file` مزود فقط مراقبة `stat` و `changes`،`ResourceProtocolMap.file` مباشر لـ `WorkspaceFileStat`.Host عبر Session نظام الملفات تحليل كل بند مسار؛ ملف قراءة وراثة هذا خلفية قراءة إذن، دليل صف رفع و تغيير مراقبة ما زال حد تحديد في مساحة العمل.

يمكن قراءة ملف استخدام `dsh-resource://file/session/<sessionId>/<path>`. مسار يمكن متبادل مقابل مساحة العمل، أيضا يمكن هو قطعا مقابل مسار؛ تحرير رمز بعد قطعا مقابل مسار إبقاء قبل توجيه مائل عمود.`fileAddressFor` بداية نهاية توليد هذا نوع Session عنوان. مزود و Preview RPC فقط من هذا عنوان أخذ Session، لا أخذ حالي اختيار، أول عدد يحتفظ من أو tab الذي تابع Session. لا حمل Session `absolute` URI لا يمكن قراءة؛ مزود تقرير إبلاغ `workspace-file/unknown-workspace`.Session تخويل هو ملف بروتوكول قاعدة، لا هو مقدار خارج Resource هوية.

[Document Preview](../../../../packages/client/ui-sidebar-documentpreview/README.ar.md) مسؤول صيغة اختيار و تحميل سياسة. بيانات وصفية عبر `ctx.documentPreviews` تسجيل؛ مكون مفرد وحيد تسجيل إلى keyed `sidebar.right.tab.document` Slot. توسيع تسجيل أولوية في داخل وضع تسجيل، ذلك مرة مقارنة مقارنة بعد لاحقة طويل درجة و تسجيل ترتيب. أداة شريط صف خروج تلقي دعم حمل مرشح، حسب tab تسجيل إقامة يد حركة اختيار. لم معرفة توسيع اسم و نص توافق مصير ما زال يمكن استخدام صاف نص. نص توافق صفة من تسجيل اثنان دخول صنع بعد لاحقة قرار، و تحميل طريقة غير متصل؛HTML و SVG لا يخص اثنان دخول صنع بعد لاحقة، إبقاء شفرة المصدر عرض. فقط لديه واحد مرشح وقت لا عرض عرض جهاز تحكم عنصر. تسجيل إعلان لـ اثنان دخول صنع بعد لاحقة لا توفير صاف نص؛ معروف اثنان دخول صنع بعد لاحقة لا يوجد تسجيل مصير وقت لا إرسال بدء قراءة، و عرض لا دعم حمل معاينة فارغ حالة ([الشريط الجانبي معاينة ضرب طحن](../feature/2026-09-11-sidebar-document-preview-polish.ar.md)). فرعي مكون استلام إلى تراكم تراكم نص أو كامل أصلي بايت، أصلي مورد عنوان، و معيار `useResource` و `useTabInfo` خطاف.Preview مرور عادي حقن استدعاء قائم `read`،`readAll` و `readRelated`، في ذاتي ذات `rpc.ts` حل رمز بايت. تحديث جديد ما زال حسب tab مستقل إجراء، لا جذب دخول مورد reload، مشترك `changed` تأكيد، مقدار خارج مورد حزمة تركيب طبقة أو محتوى Session.

Markdown و شفرة عبر تراكم تراكم قسم صفحة نص إعادة استخدام زيادة كمية تصيير أصل لغة.HTML،PDF و صورة قراءة كامل `Uint8Array<ArrayBuffer>` بيانات؛Host نقل إبقاء base64. إصدار بعد مؤقت اندفاع منطقة فقط قراءة استعارة استخدام، أبدا حفظ دائم دخول تخطيط أو Session JSON.PDF.js في ذاتي لديه Worker في تشغيل، حرف جسم و حل رمز بيانات بـ نفسه إصدار مع حزمة إصدار، تحويل نقل إدخال قبل أولا نسخ، بـ إبقاء Preview مؤقت اندفاع منطقة.HTML في Blob iframe في تشغيل، ضبط `sandbox="allow-scripts"`، لا منح إعطاء نفس مصدر، نابض نافذة، جدول مفرد، تحت تحميل أو قمة طبقة تنقل إذن. متصفح إبقاء صحيح معتاد خارجي شبكة قاعدة. لديه حد أعلى ساكن حالة محلي JS/CSS قراءة من أب صفحة مسؤول؛ لا نفاذ واضح مصدر iframe إنشاء ذاتي ذات مورد Blob، لأن هو لا يستطيع تحميل أب مصدر إنشاء Blob.PNG،JPEG،GIF،WebP،BMP،ICO و SVG استخدام صورة مخصص استخدام Blob URL، في `<img>` ساكن حالة صورة سياق في تصيير. مقارنة وجه لوح عرض صورة حسب رأسي أفقي مقارنة تقليص صغير إلى وجه لوح عرض درجة؛ مقارنة صغير صورة إبقاء ثابت لديه CSS مثل عنصر مقياس قياس و من auto margin إقامة في، مقارنة عال صورة توسيع مشترك تمرير منطقة رأسي نحو نطاق ([الشريط الجانبي معاينة ضرب طحن](../feature/2026-09-11-sidebar-document-preview-polish.ar.md)). مصير لا توفير تقليص وضع أو سحب جر مستو نقل.SVG علامة أبدا دخول تطبيق DOM أو iframe، لذلك نص برمجي إبقاء غير ممكن تنفيذ، أيضا لا يمكن وصول أب صفحة. استبدال HTML أو صورة وقت سوف سحب إلغاء ذلك أصل Blob URL.

PDF.js رسمي جهة TextLayerBuilder في ملائم إعداد عرض درجة canvas فوق مسؤول اختيار حد و نسخ مواصفة تحويل، مشترك صفحة تنظيف، و استخدام من مكون يملك resize observer. استجابة صيغة مقياس قياس ملائم إعداد استخدام مستقل CSS `scale` خاصية، و PDF.js صفحة دوران تحويل و مستو نقل تغيير تبديل تركيب. ذلك محتوى انتهاء علامة و كومة تراكم قاعدة حد فارغ أبيض منطقة مجال في اختيار؛ تبديل سطر عال مضيء يتم كبح صنع. تدريجي صفحة إلغاء استخدام builder تنظيف عملية، بينما لا abort رقم واحد صفحة إشارة، لأن رسمي جهة اختيار مستمع عبر صفحة مشترك.

## اعتبار مرور بديل خطة

**عبر معاينة بيانات وصفية في عودة ضبط تحميل تحويل محتوى.** هذا نوع عودة ضبط سوف يجعل مشترك ملف store معا يحتفظ مصدر ملف بايت و صيغة مخصص تابع تحويل نتيجة. من مصير ذاتي سطر تحميل يمكن سوف تحويل ذاكرة مؤقتة، خطأ و حرف جسم بيانات وصفية إبقاء في Office، معا إبقاء مشترك ملف هوية و أداة شريط تحكم عنصر. تعريف إعلان `loading: 'renderer'`؛ متن استقبال و صيغة غير متصل تحميل revision، فقط تقرير إبلاغ قد عرض مصدر إصدار. إعادة تحميل أو استبدال تنفيذ سوف زيادة revision، مرور مدة تقرير إبلاغ سوف يتم تجاهل اختصار، متن في استبدال أو إزالة وقت إلغاء انتظار معالجة عمل.Office في tab دورة الحياة داخل إبقاء اكتمل محتوى، و تركيب ذاتي ذات PDF فرعي slot.

**يأخذ طريقة تعليق إلى Iterator أو ذلك قيمة فوق.** هذا سوف خلط خلط مراقبة و أمر، و في بيانات لقطة في تكرار قدرة هوية. لقطة يحمل بيانات و فشل؛ صريح Preview RPC عودة ضبط مسؤول قراءة.

**نواة قلب عام إسقاط عمل مصنع، أو في `open` داخل فعل نفس مثال تجميع.** قسم فتح تدفق قيمة،operations تركيب و عام واجهة زيادة تجميع خطوة، لا يوجد آخر عدد حالي مستهلك حاجة هو.Preview مشترك RPC ملائم إعداد قد يجعل مصير بلا حاجة حل رمز Session و base64.Resource لا توفير و مزود غير متصل أمر واجهة، أيضا لا توفير ربط في فتح نسخة أمر دورة الحياة؛ زيادة مهمة واحد نوع كل حاجة ملف معاينة خارج مستهلك دليل.

**يأخذ UI Session بصفة مقدار خارج Resource هوية، أو من أول عدد يحتفظ من، حالي اختيار قرار تخويل.** إبقاء tab يمكن يخص مختلف في حالي اختيار Session،UI الذي في موضع أيضا لا يستطيع معرف عنوان إشارة نحو ملف. سوف الذي يحتاج Session تحرير دخول ملف عنوان، حيث إبقاء Host تخويل، أيضا يجعل نفس عنوان كل قراءة من مشترك مراقبة.

**يجعل كل مورد توفير ملف قراءة طريقة.** Chat و طرفية مورد بيانات و عملية دلالة كل منها مستقل، فقط لديه مراقبة تسجيل و دورة الحياة هو مشترك استخدام آلية.

**معاينة مورد حزمة تركيب طبقة، محتوى Session أو ثاني عدد مورد Hook.** هذه خطة تكرار Resource و Workspace Files قد توفير بحث عنوان، إلغاء، حجز قراءة و ملكية. تحميل سياسة يخص معاينة كل من.

**محلي خادم، وهمي محاكاة رئيسي آلة أو `file:` iframe.** هذه خطة حاجة مقدار خارج حمل إدارة أو نظام الملفات إذن. معاينة موجه إلى ساكن حالة توليد صفحة، بينما غير كامل تطبيق وقت التشغيل؛ وحدة، حركة حالة نظام الملفات طلب و مهمة معنى تضمين طقم مورد رسم لا في دعم حمل نطاق داخل.

**تنظيف SVG بعد وضع دخول تطبيق DOM أو iframe.** sanitizer سوف زيادة ثاني طقم SVG parser و واحد طقم حمل متابعة عرض دخول رئيسي حركة محتوى سياسة، بعد ما زال يلزم يأخذ غير ممكن معلومة علامة وضع دخول يمكن تفاعل وثيقة.`<img>` ساكن حالة صورة سياق إبقاء متصفح أصلي SVG تصيير و ثابت لديه مقياس قياس، معا لا إعطاء علامة واحد قدرة تشغيل نص برمجي DOM.

## أثر

استبدال مصير لا حاجة تغيير Tab أو ملف بروتوكول. كل نص صيغة تحمل تحمل لديه حد أعلى كامل ملف داخل تخزين صار هذا،PDF زيادة مع حزمة إصدار Worker، حرف جسم و حل رمز جهاز بايت. صيغة اختيار و عرض حالة فقط يخص حالي صفحة، لا هو حمل دائم Session بيانات.Preview مستقل في بيانات وصفية مراقبة، يملك RPC إلغاء و أصلي مؤقت اندفاع منطقة.tab إبقاء قراءة إصدار و قراءة بدء وقت التقاط مراقبة إصدار؛ تحديث جديد هو حيث لا إسقاط أخرى tab محتوى، أيضا لا صاف حذف ذلك تغيير تلميح. ملف قراءة ما زال غير أمر خدمة، لا نفاذ واضح إصدار فقط مقارنة مقارنة متبادل انتظار صفة، لا ترتيب.[تسجيل صنع متصفح مشهد](../../../../apps/web/tests/document-preview.e2e.ts) تغطية مشترك استخدام أداة شريط، زيادة كمية نص، عزل HTML اعتماد، حسب عرض درجة ملائم إعداد موضع رسم و SVG تصيير، غير ممكن تنفيذ SVG نص برمجي، و كسول صفة وصل متابعة PDF Worker تصيير.
