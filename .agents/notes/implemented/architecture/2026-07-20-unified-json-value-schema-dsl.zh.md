# Agent Note: موحد واحد JSON قيمة schema DSL

Status: implemented

[English](2026-07-20-unified-json-value-schema-dsl.md) | العربية

## مشكلة

أداة معامل استخدام واحد طقم دقيق بسيط عمل من جانب schema DSL،subagent/سير العمل بنية تحويل إخراج فإن استخدام آخر طقم أصلي JSON Schema فرعي تجميع و تحقق جهاز. اثنان طقم مفردات في أصل نوع، علامة كمية قيد و تحقق طريقة فوق و لا متسق؛ إذا متابعة امتداد استخدام هذا نوع تخطيط قسم، نوع تحويل مواصفة أداة إخراج اتفاق يلزم ما أيضا يحتاج تكرار تنفيذ اثنان بند مسار، يلزم ما فقط قدرة قبول جزء إسقاط لا يمكن قوي صنع تنفيذ schema.

## قرار

`dsh-tools` بـ اثنان نوع يمثل شكل صيغة موحد واحد إدارة واحد طقم JSON قيمة schema مفردات.`ValueSchemaSpec` هو يمكن وصف مهمة معنى JSON أصل نوع عمل من جانب شكل صيغة؛`ParameterSchemaSpec` هو ذلك خفي صيغة كائن خاصية خريطة شكل صيغة، كل خاصية يمكن علامة `required: true`.`JsonSchemaNode` هو أصلي بروتوكول شكل صيغة. اثنان نوع شكل صيغة كل دعم حمل نص، لديه حد عدد قيمة، كامل عدد، قيمة منطقية،null، عدد مجموعة، كائن، نوع صحيح تأكيد علامة كمية `enum`/`const`، و اشتراط تماما جيد مطابقة واحد فرع `oneOf`؛`{ type: 'json' }` فقط هو عمل من جانب لغة قاعدة سكر، سوف تحرير ترجمة لـ فقط يحتوي ملاحظة حل، لا تطبيق إضافة قيد أصلي عقدة.

صريح عمل من جانب كائن يجب إعلان `additionalProperties: true | false`. خفي صيغة معامل أصل كائن و أصلي JSON Schema إبقاء معيار افتراضي فتح وضع دلالة.schema سجل فقط قدرة يتضمن ذاتي لديه كما يمكن قطعة رفع نص مفتاح،schema عدد مجموعة يجب هو كثيف سري داخل بناء عدد مجموعة، نظام فقط من ذاتي لديه خاصية قراءة تلقي دعم حمل صلة مفتاح حرف؛ لذلك، ذاتي تعريف أصل نوع، وراثة قيد،symbol و JSON غير ممكن رؤية مرفق إضافة محتوى كل لا يمكن يجعل تحرير ترجمة، إسقاط و تحقق مراقبة إلى مختلف إعلان. داخل بناء عادي Object و Array حاوية عبر JavaScript تشغيل مجال بعد ما زال نظر لـ عادي حاوية، بينما فرعي صنف و زائف صنع بنية صنع دالة أصل نوع ما زال نظر لـ غير عادي كائن.

`InferValue<S>` و `InferArgs<P>` أصل حسب نفس نسخة إعلان دفع توجيه TypeScript قيمة،`valueSchemaSpecToJsonSchema()` و `parameterSchemaSpecToJsonSchema()` أيضا سوف هذه إعلان تحرير ترجمة لـ JSON Schema. دقيق نوع دفع توجيه بـ 16 طبقة حاوية لـ حد، تجاوز مرور بعد استخدام `JsonValue`، من بينما تجنب تجنب TypeScript نوع نسخة تحويل مكدس حد عمل من قدرة إعلان تضمين طقم عميق درجة.`assertSupportedJsonSchema()` سوف رفض لا تلقي دعم حمل أو موضع خطأ صلة مفتاح حرف؛`validateJsonSchemaValue()` فإن بـ بلا ضرر `JsonValue` حد تحقق تلقي دعم حمل فرعي تجميع، لا سماح `undefined`، سالب صفر، غير لديه حد عدد، نادر متباعد عدد مجموعة، حلقة مرجع، غير عادي كائن، دالة،symbol و أخرى حاجة قوي صنع تحويل قيمة. عمل من جانب schema تحرير ترجمة، أصلي schema تأكيد، قيمة تحقق،schema إلى TypeScript تصيير، سجل التسجيل انفصال مغادرة مرجع، و حركة حالة Cordis عبر تشغيل مجال مواصفة تحويل و تغلب ضخم متساو استخدام صريح عمل مكدس، لذلك وقت التشغيل تضمين طقم فقط تلقي متاح داخل تخزين حد، لا تلقي JavaScript استدعاء مكدس حد.

كائن أصل حد يخص مستهلك قاعدة، لا يخص schema مفردات ذاته.subagent و سير العمل في من استدعاء جهة تعريف بنية تحويل إخراج عبر `assertObjectJsonSchema()` و `ObjectJsonSchema` إبقاء كائن أصل حد؛ أداة إخراج يمكن استخدام مهمة معنى أصل نوع. حركة حالة Cordis تسجيل سوف يأخذ عبر JavaScript تشغيل مجال نقل دخول schema إعادة بناء لـ مضيف يملك JSON قيمة، إبقاء أصلي حزمة تركيب طبقة افتراضي فتح وضع دلالة، و اشتراط مباشر استخدام DSL إعلان كائن واضح اختيار فتح وضع طريقة، لكن بعد مجددا استدعاء نفس تحرير ترجمة جهاز. حركة حالة حد سوف في مواصفة تحويل قبل رفض JSON غير ممكن رؤية سجل مفتاح و غير عادي schema عدد مجموعة، لذلك لن ساكن صامت إسقاط قيد، أيضا لن إطلاق ذاتي تعريف تكرار بديل منطق.

## تجهيز اختيار خطة

- **إبقاء اثنان طقم مستقل معامل و بنية تحويل إخراج schema نظام:**غير مقبول. كل إضافة جديدة واحد نوع إخراج بنية، كل يجب قسم آخر تعديل نوع دفع توجيه، تحرير ترجمة، تحقق و شفرة توليد، بينما هذا نوع تكرار و لم شكل صار متعمد معنى مسؤولية حد.
- **استخدام Schemastery معالجة أداة معامل:**غير مقبول.Schemastery عبر Standard Schema موجه إلى تحقق و تحويل، بينما لا هو توليد JSON Schema. اعتماد هو سوف زيادة واحد طبقة مهايئ، لكن لا يستطيع إنتاج خروج موجه إلى نموذج بروتوكول schema أو مشترك إخراج مفردات.
- **اعتماد كامل JSON Schema أو Ajv:**غير مقبول.harness يجب رفض كل لا يمكن إسقاط إلى توليد SDK و تحقق جهاز في بنية؛ إذا قبول أكثر كبير لغة فرعي تجميع، قوي صنع تنفيذ قدرة و نموذج إشارة جذب حينئذ سوف و واقع لا رمز.
- **يجعل كل كائن افتراضي فتح وضع أو افتراضي غلاف إغلاق:**غير مقبول. هذا اثنان نوع اختيار كل سوف إخفاء واحد بند أثر إعادة كبير عمل من قرار. فقط لديه إبقاء قديم لديه شكل خفي صيغة معامل أصل كائن و خارجي أصلي schema عندئذ متعمد إبقاء قيمة افتراضية.
- **يأخذ `oneOf` تعريف لـ أول عدد مطابقة فرع:**غير مقبول. هذا مثال واحد قدوم، فرع ترتيب سوف تغيير تحقق دلالة، إعادة تراكم فرع أيضا سوف إخفاء غطاء قيمة اختلاف معنى.

## أثر

- معامل تحقق، إخراج تحقق،schema إلى TypeScript شفرة توليد،subagent/سير العمل بوابة و حركة حالة تسجيل مشترك استخدام واحد طقم قوي صنع تنفيذ مفردات.
- إخراج إعلان يمكن دفع توجيه كائن، عدد مجموعة، علامة كمية أو null أصل نوع؛subagent/سير العمل بنية تحويل إخراج ما زال في ذلك قائم خدمة حد إبقاء كائن أصل حد.
- صريح كائن فتح وضع طريقة و نوع صحيح تأكيد حرف وجه كمية قيد سوف يجعل صيغة خطأ إعلان في تحرير كتابة أو تسجيل مرحلة مقطع سريع سرعة فشل، بينما لا هو سحب إلى لاحق نموذج استدعاء وقت عندئذ فشل.
- محدود نوع دفع توجيه سوف لـ معتاد قاعدة إعلان إبقاء لديه استخدام دقيق نوع، و سوف استثناء عميق ذيل جزء بنية تراجع تحويل لـ `JsonValue`؛ وقت التشغيل schema قوي صنع تنفيذ في مهمة معنى عميق درجة ما زال إبقاء دقيق.
- أصلي أداة ما زال يمكن مباشر تسجيل نطاق أكثر واسع JSON Schema، لكن موحد واحد شفرة توليد سوف يأخذ لا تلقي دعم حمل schema نظر لـ لم معرفة نوع، لن زائف تركيب ذاتي ذات قدرة كاف قوي صنع تنفيذ.
- كل خاصية `required: true` ما زال هو أداة عمل من اتفاق؛ أصل لديه دفع توجيه مسار كشف اختياري صفة نقص وقوع بعد، نوع درجة ارتداد تغطية سوف قفل تحديد لا بد ملء مفتاح لا نيل لـ اختياري.
- وقت التشغيل اختبار و تحرير ترجمة مدة اختبار تغطية كل أصل نوع، تماما جيد مطابقة واحد فرع وقت إعادة تراكم/بلا مطابقة سلوك، أصلي schema افتراضي فتح وضع دلالة، صريح فتح وضع طريقة، لديه ضرر JSON قيمة، نوع دفع توجيه، نواة قلب إسقاط و حركة حالة إسقاط في عميق طبقة تضمين طقم، حركة حالة تسجيل في JSON غير ممكن رؤية مفتاح، و غير عادي schema عدد مجموعة.
