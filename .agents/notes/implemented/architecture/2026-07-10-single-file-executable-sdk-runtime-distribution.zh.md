# Agent Note: مفرد ملف يمكن تنفيذ SDK وقت التشغيل توزيع (single-exe)

Status: implemented

[English](2026-07-10-single-file-executable-sdk-runtime-distribution.md) | العربية

## مشكلة

DeepSeek Harness حاجة لـ Python مكتبة مخصص باب توفير واحد نوع بلا حاجة تثبيت Node، يمكن مباشر في هدف منصة تشغيل SDK توزيع شكل: واحد مفرد ملف يمكن تنفيذ برنامج (تحت تسمية exe) ، عبر stdio توفير JSON-RPC مقابل خارج خدمة واجهة (`HarnessSdkJsonRpcServer`،Python SDK مقابل طرف) ، كما فعلي بدء إضافة و إعداد تماما من exe خارجي إدخال `cordis.yml` قرار.

- و Python SDK عبر معلومة JSON-RPC بروتوكول قد مرور تحقق
- حاجة توفير واحد نوع يجعل `cordis.yml` تحميل كل إضافة (ES وحدة) معيار طريقة
- توزيع شيء يلزم ذاتي حمل Node وقت التشغيل، و دعم حمل محلي شفرة المصدر رابط ضبط تجربة نمط

## قرار

### تحزيم مسار خط:@yao-pkg/pkg `--sea` نمط

exe استخدام [@yao-pkg/pkg](https://github.com/yao-pkg/pkg)(vercel/pkg عودة ملف بعد نشط وثب صيانة fork) **`--sea`(enhanced SEA) نمط**تحزيم. متبادل مقارنة Node أصلي SEA،pkg في ذلك فوق زيادة `/snapshot` وهمي محاكاة نظام الملفات (VFS) و وقت التشغيل وحدة خطاف، سوف ESM مدخل أصل مثال تسليم إعطاء Node افتراضي ESM loader، لا اعتماد أي ESM→CJS تحويل ترجمة.
> فعلي قياس (macos-arm64،node24 بناء هدف،pkg 6.21.0):VFS داخل عار حزمة اسم ESM حركة حالة `import()`(يحتوي قمة طبقة `await`) ،CJS متبادل عملية،`node:sqlite`، تجميع دمج خارج حزمة اسم واضح تقرير خطأ،VFS خارج مغناطيس قرص ESM `import()` الكل عبر،`import.meta.url` أصل مثال لـ `file:///snapshot/...`.

`--sea` اشتراط بناء هدف ≥ node22،exe موحد واحد بـ node24 لـ بناء هدف؛ كل مرة pkg استدعاء فقط تحزيم واحد بناء هدف، كثير منصة كل استدعاء مرة.

`@yao-pkg/pkg` هو دقيق تثبيت إصدار أصل `devDependency`، مرور `pnpm exec pkg` استدعاء، و بـ [`patches/@yao-pkg__pkg@6.21.0.patch`](../../../../patches/@yao-pkg__pkg@6.21.0.patch) إزالة SEA bootstrap في `patchChildProcess` استدعاء. لم ضرب رقعة وقت،pkg سوف يأخذ spawn `node` أمر——يشمل `-c`/`/c` علامة سجل بعد أمر سلسلة، تماما هو Bash أداة `bash -c` شكل——تعديل كتابة لـ exe ذاته، و نحو كل عملية فرعية بيئة حقن `PKG_EXECPATH`، نموذج تحت إرسال `node --version` سوف ساكن صامت بدء dsh CLI؛Node ذاته SEA طبقة لا يوجد هذا نوع تعديل كتابة، كما SEA اثنان دخول صنع دائم بعيد بدء داخل تضمين تطبيق، لا يمكن ملء عند صاف Node. إزالة هذا استدعاء بعد، عملية فرعية مثل عادي عملية واحد مثال مرور PATH تحليل `node`(بلا Node آلة جهاز مثل فعلي تقرير command not found) ، عملية فرعية بيئة لم يعد ظهور `PKG_EXECPATH`، بـ `process.execPath` قطعا مقابل مسار spawn إعادة دخول لا تلقي أثر،worker خط مسار هذا قدوم حينئذ لم تطبيق هذا خطاف،`process.pkg` جانب عربة اختيار أيضا لا تلقي أثر.

فن لغة رفع تنبيه:pkg `/snapshot` VFS و هذا مستودع اختبار جسم نظام «لقطة»(ACP(Agent Client Protocol) إعادة تشغيل مسبق مدة إخراج،`$DSH_SNAPSHOT`) غير متصل، هذا نص استخدام «VFS» إشارة قبل من.

### مقابل خارج خدمة واجهة هو dsh تطبيق في إضافة

تحديد صفة خدمة واجهة من تحزيم بعد `dsh` تطبيق اختيار لـ إضافة:

- [`packages/sdk/server`](../../../../packages/sdk/server/README.zh.md)(`@deepseek-ai/dsh-sdk-jsonrpc-server`): صاف بروتوكول إضافة؛ تنفيذ `apply` وقت، في عملية stdio فوق تركيب `HarnessSdkJsonRpcServer` و حسب سطر قسم فصل JSON-RPC نقل طبقة، مورد تحرير مشي `ctx.effect()`. هل توفير خدمة من `cordis.yml` قرار؛ لم تركيب هذا إضافة إعداد سوف بدء واحد لا توفير هذا خدمة دمج قاعدة عملية. بروتوكول درجة خروج عودة إضافة كل (ينبغي جواب و تأكيد حفظ `shutdown` استجابة إرسال تمام انتهاء بعد، مقابل أصل وقت التشغيل تنفيذ dispose(مورد تحرير) ، يجعل انتظار معالجة حفظ دائم عملية إتمام، مجددا استدعاء `exit(0)`؛HMR(حار وحدة استبدال) صيغة إزالة فقط إيقاف خدمة، لا خروج عملية).
- [`apps/cli`](../../../../apps/cli/README.zh.md)(`@deepseek-ai/dsh`): تحزيم بعد تطبيق مدخل؛ ذلك `sdk` profile تركيب `dsh-sdk-jsonrpc-server`،CLI مسؤول بيئة قسم طبقة،profile تركيب،stdin/signal إغلاق و عملية خروج.

Python عميل توفير صريح Harness home، و اختيار `sdk` profile و لديه ترتيب patch ملف. ناقص home،profile،bundle أو server بند إعداد كل سوف واضح فشل؛ لا وجود خارجي كامل إعداد رجوع.[docs/architecture.md](../../../../docs/architecture.zh.md) مسؤول هذا تطبيق واجهة.

### إضافة تحليل:VFS تركيب تحميل حقيقي حزمة شجرة، إغلاق حزمة manifest(بيانات وصفية بيان) حينئذ هو نشر أصل دليل

exe VFS داخل هو**بناء ناتج شكل حقيقي حزمة شجرة**(كل حزمة `lib/` + حقيقي `node_modules`). تحزيم مخصص استخدام JSON-RPC مدخل سوف نحو app-boot أصل Include توفير ذاته قد تثبيت harness أساس دقيق موضع: متبادل مقابل إضافة شرح رمز من خارجي إعداد دليل تحليل، عار حزمة اسم فإن من VFS تحليل، لذلك يقع في آخر عدد Node مشروع داخل إعداد لا يمكن حجب حجب قد تحزيم إضافة تجميع دمج. عادي تطوير bin ما زال من بند إعداد هدف توفير عار حزمة. تحزيم مدخل في عار حزمة اسم من هذا مدخل في VFS داخل موضع امتداد `node_modules` نحو فوق تحليل، ذاتي لكن سقوط في VFS داخل. غلاف إغلاق تجميع لا حاجة أبيض اسم مفرد شفرة——VFS في تثبيت ماذا، تجميع دمج في حينئذ لديه ماذا؛`import()` تجميع دمج خارج اسم سوف فشل.

نشر أصل دليل هو [`python/sdk-runtime/package.json`](../../../../python/sdk-runtime/package.json)(`dsh-python-runtime-closure`،pnpm مساحة العمل عضو، صفر شفرة صاف اعتماد manifest) ، أيضا هو «exe تثبيت أي بعض إضافة» و «Python وقت التشغيل توزيع ماذا» موحد واحد حق مصدر. نحو exe إضافة إضافة، حينئذ هو في manifest في زيادة واحد سطر اعتماد بعد إعادة تحزيم.[`scripts/verify-runtime-closure.ts`](../../../../scripts/verify-runtime-closure.ts) قراءة كل قد إصدار `packages/preset/agent-presets/presets/*/agent.cordis.yml`، إبرة مقابل `python/sdk-runtime/platforms.json` في كل هدف تحليل مقارنة مقارنة `process.platform` `disabled` شرط، و اشتراط هذا هدف تفعيل كل مساحة العمل إضافة كل عبر صريح `workspace:` اعتماد صف في وقت التشغيل أصل دليل. هو أيضا مرة تاريخ هذا manifest تغطية الكل مساحة العمل حزمة، اشتراط كل غير اختياري مساحة العمل مقابل انتظار اعتماد (peer dependency) كل صريح صف خروج، و تقرير إبلاغ “preset أو مرجع حزمة → ناقص اعتماد” كامل سلسلة مسار؛ لا يمكن تعرف آخر منصة شرط سوف إبقاء تفعيل، تجنب تجنب بسبب لا دعم حمل جدول بلوغ صيغة متروك تسرب إضافة.`pnpm run hygiene`،CI ساكن حالة فحص و single-exe بناء كل سوف في تحزيم قبل تشغيل هذا بوابة. نشر أيضا سوف اعتماد حسب كل حزمة `files` حقل تحزيم، لذلك tsdown تفكيك خروج مشترك قسم قطعة يجب يتم `files` تغطية.

نشر أصل دليل صريح يتضمن `@deepseek-ai/dsh-mcp-client`، سوف ذلك بصفة ذاتي تعريف إعداد متاح إضافة، أي جعل مع مرفق preset متساو لم تركيب هذا إضافة. خارجي إعداد لذلك يمكن اتصال من مستخدم توفير stdio و Streamable HTTP MCP server و تسجيل ذلك أداة؛ توزيع شيء لا يتضمن هذه server. اختياري مورد خدمة توفير MCP Resources؛MCP Prompts ما زال لا تلقي دعم حمل. يمكن تنفيذ برنامج و قد تثبيت wheel حزمة خطر دخان اختبار سوف بدء مؤقت stdio server، اكتشاف ذلك أداة، و إتمام مرة من نموذج طلب استدعاء.

[Office kit](2026-09-14-independent-libreoffice-kit.zh.md) و ذلك قد تثبيت اعتماد شجرة يقع في `<executable-stem>-office/node_modules`، إبقاء كامل حزمة محتوى و مساعد مساعدة برنامج إذن. قمة طبقة `pkg.ignore` من SEA عودة ملف ترتيب حذف kit حزمة، يشمل اعتماد `files` حقل اختيار في مورد؛ و أخرى استخدام جهة مشترك صغير نوع اعتماد ما زال يمكن في VFS في استخدام.Python خاص bootstrap استخدام Node `registerHooks` من حقيقي دليل تحليل kit مدخل و ذلك حزمة بيان. لذلك أصلي يمكن تنفيذ برنامج و URL Worker إبقاء عادي ملف مسار، بلا حاجة تعديل kit أو عام CLI. مطلوب حزمة ناقص أو قد تثبيت حزمة نقص قليل بيان سوف جعل نسخ فشل؛ لم تثبيت اختياري حزمة إبقاء kit ذاته جذب محرك اختيار قاعدة.

### Python SDK توزيع: مزدوج تحميل جسم،exe لأجل إنتاج،`node` لأجل تطوير

Python SDK يقع في [`python/`](../../../../python/README.zh.md):`python/sdk` هو عميل،`python/sdk-runtime` هو وقت التشغيل تحميل جسم حزمة. وقت التشغيل حزمة بيانات دليل يتضمن بناء حقن منصة يمكن تنفيذ ملف و ذلك مطلوب `-rg` مرافق مع ملف،`-office/` دليل و اختياري macOS helper، و توفير مستودع تطوير استخدام بناء حقن `runtime/node/` إغلاق حزمة شجرة.`resolve_bundled_launch_args()` افتراضي اختيار يمكن تنفيذ ملف؛ صريح ضبط `DSH_RUNTIME_MODE=node` سوف في نظام Node 22.19 أو أكثر عال إصدار فوق تشغيل `runtime/node/node_modules/@deepseek-ai/dsh/lib/bin.js`.node تحميل جسم من لا دخول wheel توزيع، اثنان نوع تحميل جسم كل لا استخدام فحص دخول كامل `cordis.yml`.

[`scripts/build-python-release.py`](../../../../scripts/build-python-release.py) من مستودع أصل دليل `package.json` قراءة مرجعي `X.Y.Z` أو مسبق إصدار إصدار، يأخذ مسبق إصدار إصدار تحويل لـ PEP 440 كتابة قاعدة، و بـ هذا wheel حزمة إصدار مؤقت تخزين اثنان عدد حزمة، يجعل `deepseek-harness-sdk` دقيق اعتماد مطابقة إصدار `deepseek-harness-runtime-bin`. اختياري `python-v<repository-version>` إصدار وسم فقط هو واحد بند متسق صفة تأكيد، و مستودع إصدار مختلف وقت سوف يتم رفض؛ شفرة المصدر `pyproject.toml` في تطوير احتلال موضع إصدار من لا قرار إصدار إصدار. مؤقت تخزين مرور مسار أيضا سوف يأخذ مستودع سماح يمكن إثبات وضع دخول اثنان عدد wheel حزمة، و يأخذ رقم ثلاثة جهة إعلان وضع دخول داخل وضع وقت التشغيل wheel حزمة.SDK هو `py3-none-any` wheel حزمة؛ كل فقط توفير wheel حزمة وقت التشغيل حزمة كل يتضمن واحد exe، ذلك Office دليل و هيكل بنية مطابقة ripgrep مرافق مع ملف،macOS wheel حزمة أيضا يتضمن و ذلك هيكل بنية مطابقة spawn helper. وقت التشغيل wheel حزمة استخدام `py3-none-manylinux_2_28_x86_64`،`py3-none-manylinux_2_28_aarch64`،`py3-none-macosx_14_0_arm64`،`py3-none-macosx_14_0_x86_64` أو `py3-none-win_amd64`؛Hatch خطاف رفض sdist، عام وسم، خلط دمج منصة تحميل حمل، مرافق مع ملف ناقص أو كثير بقية، و لا دعم حمل منصة. اثنان عدد macOS وسم كل سوف خاص معنى إعلان حفظ حراسة 14.0 تثبيت تحت حد: تحزيم بعد Node 24 يمكن تنفيذ ملف إعلان macOS 13.5،x64 PTY helper إعلان 10.7، لكن إصدار تحقق فقط حسب وفق 14.0 wheel إعلان إثبات كامل تحميل حمل، لن يأخذ كل مكون فعلي قياس الأكثر منخفض إصدار تحمل وعد لـ تلقي دعم حمل مضيف. اثنان عدد macOS wheel حزمة ما زال حسب هيكل بنية قسم آخر إصدار، لا إصدار universal2 wheel حزمة.

Python عميل استخدام الذي اختيار profile(افتراضي `sdk`) ، لديه ترتيب patch ملف و صريح Harness home بدء تحزيم بعد `dsh` أمر.Profile مسؤول JSON-RPC خدمة و تطبيق تركيب؛ ناقص home،profile،bundle،patch أو server بند إعداد كل سوف فشل، لا وجود خارجي كامل إعداد رجوع.

### تسمية دم موحد

`dsh-python-runtime-closure` هو خاص نشر manifest،`deepseek-harness-sdk-runtime-<platform>-<arch>` هو يمكن تنفيذ ملف عائلة. بروتوكول حقل `serverInfo.name` هو `deepseek-harness-sdk-runtime`؛Python توزيع حزمة اسم هو `deepseek-harness-sdk` / `deepseek-harness-runtime-bin`، استيراد وحدة اسم هو `deepseek_harness` / `deepseek_harness_runtime`.

## تحزيم بعد سير العمل و شفرة تنفيذ

`dsh-workflow-ptc` عبر `dsh-ptc-runtime-node` إرسال ذاتي يتضمن guest برنامج. مشترك مزود عبر يمكن تنفيذ ملف خاص Node bootstrap قسم إرسال بدء تلقي إدارة عملية فرعية، و استخدام مخصص استخدام تحكم عبر طريق؛ لا حاجة مستقل سير العمل worker مورد.[صندوق رملي Node قرار](2026-09-11-sandboxed-node-ptc-runtime.zh.md) مسؤول عملية و سياسة دورة الحياة،[سير العمل صندوق رملي إعادة استخدام](2026-09-13-workflow-ptc-sandbox-reuse.zh.md) مسؤول سير العمل مهايئ.

## اختبار

تحقق وجه قسم ثلاثة طبقة. آلية طبقة:`--sea` سلسلة مسار فعلي قياس ربط نقاش داخل تضمين في «قرار» كل عقدة (VFS داخل ESM حركة حالة `import()`، مفرد واحد Cordis نسخة، واضح تقرير خطأ إعداد سلسلة مسار،`node:sqlite`،macOS ad-hoc توقيع يمكن تشغيل).SDK طبقة: كامل بلا مفتاح pytest طقم عنصر بـ mock وقت التشغيل مقابل طرف تغطية عميل بروتوكول، عملية فرعية تنظيف، قطعا مقابل `cwd` نقل تمرير، مزدوج تحميل جسم بدء و تحميل جسم تحليل؛ أصل CI في Python 3.10 فوق تشغيل الكل حالة استخدام. طرف إلى طرف طبقة: كل منصة بناء كل سوف يأخذ اثنان عدد wheel حزمة تثبيت دخول checkout خارج جاف صاف venv، إثبات إصدار نفسه و قد تثبيت وحدة/يمكن تنفيذ ملف موضع، مجددا عبر افتراضي SDK مسار، ذاتي تعريف إعداد، مستودع داخل وضع مستقل minimal تركيب و مباشر اثنان دخول صنع بروتوكول، مقابل mock طرف نقطة إتمام جولة، و تحقق نهائي نص و JSONL.minimal تشغيل سوف تأكيد ذلك دقيق توجيه النظام و مفرد عدد shell أداة دليل، و عبر استدعاء إبقاء shell حالة. ذاتي تعريف إعداد أيضا سوف عبر مشترك تحزيم بعد Node عملية bootstrap تنفيذ `run_code` و لا بدء agent `workflow`. نظام الملفات بحث مشهد اشتراط نموذج عبر هدف منصة `-rg` مرافق مع ملف استدعاء `glob` و `grep`.spawn-node مشهد قيادة منصة shell أداة تنفيذ بـ `node` فتح رأس أمر، اشتراط أداة نتيجة إعطاء خروج آلة جهاز ذاته Node إصدار كما عملية فرعية بيئة في بلا `PKG_EXECPATH`، يأخذ تحزيم وقت التشغيل تثبيت ميت في «pkg ترقية إعادة تسجيل child_process رقعة أيضا لا نيل ارتداد» سلوك فوق.MCP مشهد سوف بدء مؤقت خارجي stdio server، لحظة معنى تأخير متأخر أول مرة `tools/list` استجابة، مع بعد قيام أي بدء رقم واحد SDK نص التوجيه؛ هذا نص التوجيه يجب يرى و استدعاء قد اكتشاف أداة، من بينما إثبات `initialize` هو حق صحيح بـ Loader إضافة شجرة تماما مستقر لـ دقيق حينئذ خيط حد، بينما لا هو اعتماد تحديد وقت sleep. نفس بند تثبيت بعد تشغيل أيضا سوف مرور Python SDK مقارنة مقارنة واحد مجموعة فحص دخول exe مخصص استخدام لقطة: بلا مفتاح نص برمجي تحويل نموذج تركيب واحد سوف تسجيل أداة Cordis إضافة، من `run_code` استدعاء هذا أداة، تشغيل واحد مباشر spawn subagent و واحد سوف عبر spawn بدء ثاني عدد subagent سير العمل، مع بعد إزالة هذا إضافة. هذا fixture(اختبار قبل وضع بيانات) سوف صريح منع استخدام تركيب حزمة في لم استخدام Bash و محلي skill(تقنية قدرة) اكتشاف، جعل ذلك أداة تجميع لا اعتماد مستودع خارجي حالة؛ مقارنة مقارنة وقت سوف مواصفة تحويل SDK نتيجة و إشعار تدفق، و أب جلسة و اثنان عدد فرعي جلسة JSONL سجل في لا نفاذ واضح رسالة،agent، سير العمل تشغيل و جلسة ID. يمكن معلومة سحب أخذ طلب سوف زيادة حقيقي مزود مزدوج جولة ملف كتابة/قراءة، و اشتراط خارجي بايت، أداة استدعاء، قد إتمام سبب و حفظ دائم سجل متسق. هذا harness و ACP `pnpm run test:snapshot` إبقاء مستقل، لأن اثنان من بروتوكول و بناء ناتج مختلف.

يد عمل قيادة ملاحظة معنى:`bin` سوف stdin EOF نظر لـ «عميل قد مغادرة فتح» و قيام أي dispose، دورة الحياة مقارنة قصير إدارة طريق سوف في توقف إجراء في جولة——إدارة طريق قيادة يجب إبقاء stdin فتح، مباشر إلى جولة انتهاء.

تثبيت بعد wheel `sdk-office` مشهد سوف سوف هدف كامل تحميل حمل نسخ إلى خاص مؤقت دليل، اشتراط فقط وجود واحد هدف خلفية (استخدام قد إعلان أصلي هدف، لم إعلان أصلي هدف وقت استخدام WASM) ، و عبر مع مرفق SDK profile استخدام هذا جذب محرك تحويل مرة DOCX. هو فحص kit وحدة تأكيد فعلي تحليل إلى ترحيل بعد دليل، تحويل تقرير إبلاغ مسبق مدة خلفية، كما إخراج يتضمن PDF بايت.wheel تحقق سوف فحص إعلان جذب محرك مورد و أصلي مساعد مساعدة برنامج تنفيذ موضع؛CI فوق نقل قد إتمام wheel، لذلك تضمين طقم مساعد مساعدة برنامج إذن إبقاء في ZIP عودة ملف في.

## سبق اعتبار بديل خطة

**عار استخدام Node أصلي SEA.** حقن رئيسي نص برمجي يجب هو CJS مفرد ملف،blob داخل لا يوجد نظام الملفات و وحدة تحليل، لذلك حركة حالة `import()` لا يمكن تحليل عار حزمة اسم؛ فقط قدرة يأخذ إضافة ساكن حالة تحرير ترجمة دخول رئيسي نص برمجي و يد عمل تسجيل. هذا سوف التفاف مرور معيار وحدة تحليل و صلب تحرير رمز إضافة تجميع دمج، و «إعداد قرار واحد قطع» متبادل تناقض. نهائي مسار خط فعلي هو «رسمي جهة SEA أساس أساس + pkg VFS/وحدة خطاف طبقة» ؛ مرفوض هو عار استخدام طريقة، بينما لا هو SEA ذاته.

**pkg معيار نمط.** PoC إثبات هذا نمط غير ممكن سطر، بينما غير حق توازن بعد وضع ترك: هو عبر esbuild سوف ESM تحويل لـ CJS + V8 بايت رمز، لكن وقت التشغيل VM تحرير ترجمة لا يوجد وصل دخول حركة حالة `import()` عودة ضبط، أي `import()` كل سوف رمي خروج `ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING`،`--options experimental-require-module` أيضا بلا فاعلية؛ هذا خارج، هو اعتماد مجتمع منطقة رقعة إصدار Node اثنان دخول صنع (macos-arm64 لا يوجد مسبق تحرير ترجمة إصدار، الآن ساحة من شفرة المصدر تحرير ترجمة نحو يحتاج 10 قسم ساعة). هذا نمط لا ملائم لأجل هذا مستودع هيكل بنية.

**كل حزمة ESM→CJS مسبق تحزيم دخول VFS.** إبقاء حقيقي تحليل دلالة، فقط تخفيض وحدة صيغة طي في؛`--sea` مباشر عبر فعلي قياس، هذا طبقة بناء تكرار مختلط درجة بلا حاجة جذب دخول.

**يجعل jsonrpc-agent تحمل تحمل كامل إغلاق حزمة اعتماد.** تطبيق مدخل سوف إعلان 53 عدد بـ فوق ذاته و لا `import()` اعتماد، جعل «تحزيم manifest» زائف تركيب صار حقيقي اعتماد علاقة، أيضا سوف إجبار جعل `constraints` لـ ذلك زيادة `cordis-in-dependencies` و `files` عبر إعداد رمز اثنان عدد مثال خارج. سوف إغلاق حزمة manifest وضع في Python جانب manifest حزمة بعد،`constraints` لا حاجة أي مثال خارج،`bin` أيضا قدرة إبقاء و acp-agent نفس بنية صحيح معتاد حزمة شكل حالة.

**فتح وضع إضافة تجميع (من مغناطيس قرص تحميل مستخدم إضافة).** تسليم تجميع دمج هو غلاف إغلاق؛PoC معا إثبات فعلي، يمكن عبر `ctx.baseUrl` متبادل مقابل مسار عبر طريق من VFS خارج مغناطيس قرص `import()` ESM. هذا قدرة صف لـ لاحق عرض دخول، دورة وقت أيضا يحتاج حل قرار خارجي إضافة و exe داخل Cordis نسخة مشترك مشكلة.

## عاقبة

**شراء إلى**: تلقي دعم حمل هدف بلا حاجة اعتماد نظام Node.js؛ إضافة دلالة و شفرة المصدر تشغيل صارم إطار متسق (نفس شجرة حقيقي حزمة شجرة، بلا تحويل ترجمة، بلا سجل التسجيل) ؛ مقابل خارج خدمة واجهة، إضافة تجميع و إعداد الكل استلام جمع إلى `cordis.yml` و واحد نسخة اعتماد manifest هذا اثنان عدد حق مصدر؛exe و `node` مزدوج تحميل جسم استخدام نفس شجرة شجرة و نفسه دلالة، تطوير تحقق بلا حاجة انتظار تحزيم؛ رسمي جهة Node اثنان دخول صنع إزالة حذف رقعة إصدار اثنان دخول صنع توفير ينبغي سلسلة اعتبار اعتبار.

**دفع خروج**: كبير نوع Office جذب محرك مورد إبقاء في SEA عودة ملف خارج، يمكن تنفيذ ملف يجب و مطلوب مرافق مع ملف واحد بدء ترحيل؛ شفرة المصدر أصل مثال دخول توزيع شيء (لا يوجد بايت رمز خلط خلط؛ إغلاق مصدر توزيع إبلاغ طلب حاجة آخر سطر تقييم تقدير) ؛pkg VFS/وحدة خطاف طبقة ما زال من مجتمع منطقة صيانة (`@yao-pkg/pkg` لـ دقيق تثبيت إصدار، حمل pnpm رقعة أصل devDependency، ترقية يحتاج إعادة تسجيل رقعة، تابع صريح تعديل) ؛`--sea` كل بناء هدف استدعاء مرة (و CI كل منصة واحد مهمة متبادل مطابقة، محلي كثير منصة بناء سلسلة سطر تنفيذ).
