# Agent Note: كل /api توجيه مشترك استخدام واحد طريق تحميل جسم درجة متصفح معلومة مهمة حد

Status: implemented

[English](2026-07-28-api-browser-trust-boundary.md) | العربية

## مشكلة

Web GUI مضيف بـ صاف loopback HTTP توفير `/api`(افتراضي `127.0.0.1:3080`؛CLI رفض `--host 0.0.0.0`) ، بينما هذا عدد وجه فوق لديه بعيد مسار شفرة تنفيذ درجة آخر طريقة——`session.prompt` قيادة agent(ذكي جسم) يمكن تشغيل bash. متصفح سوف استخدام اثنان نوع مرور قاموس طريقة يأخذ عملية من تغيير صار هجوم ضرب هذا صنف محلي API «خلط خلط بديل إدارة شخص»: سيئ معنى صفحة إرسال خروج عبر محطة «بسيط مفرد طلب» POST(`text/plain`——لا مرور CORS مسبق فحص أي إرسال خروج) ، ذلك فرعي أثر وفق معتاد تنفيذ، فقط هو استجابة غير ممكن قراءة؛ و DNS rebinding بعد مصدر بـ «نفس مصدر» هوية مباشر وصل socket،CORS كامل جسم بطلان، فقط لديه `Host` رأس سوف كشف هجوم ضرب من مجال اسم. في هذا قرار قبل، نظام داخل وحيد متصفح معلومة مهمة فحص (`isTrustedNativeDialogRequest`: عودة حلقة socket، نفس مصدر، عودة حلقة Host) فقط حراسة حال واحد تركيب زينة صفة توجيه——`host.pickDirectory`، ذلك أصلي محادثة إطار نابض في مضيف شاشة ستار فوق——بينما كل حق صحيح أداة لديه صارم إعادة عاقبة طريقة كل لا يوجد منع حماية. حسب RPC تدريجي عدد ضبط منع أيضا نشط لا مرور تطبيق داخل دليل متصفح: هو وجود معنى معنى حينئذ هو خدمة دمج قاعدة بعيد مسار عميل، عودة حلقة قاعدة تماما تماما سوف رفض هو جمع.

## قرار

في تحميل جسم طبقة مقابل كامل `/api` بادئة مرة صفة تنفيذ متصفح معلومة مهمة فحص——قسم لـ اثنان جزء:

- **وسيط جسم نوع شبكة شريط (dsh-client-connection)**: كل `/api` POST يجب إعلان `application/json`، لا فإن في تحليل قبل بـ 415 رفض. عبر محطة «بسيط مفرد طلب» من هذا لا تكرار وجود: أي عبر محطة محاولة تجربة كل يتم إجبار دخول مرة هذا خادم من لا ينبغي جواب CORS مسبق فحص.
- **مرجعي شبكة شريط (dsh-client-connection،`src/api-request-trust.ts`)**: كل طلب `Host` كل يجب هو عودة حلقة عنوان، أو و بعض عدد `trustedHosts` بند مطابقة (حمل طرف فتحة `host:port` بند دقيق مطابقة، لا حمل طرف فتحة بند مطابقة مهمة معنى طرف فتحة، متساو مرور WHATWG عودة واحد تحويل؛rebinding منع صد). لحظة معنى لا لـ بلا علامة طلب فتح سريع مسار: واضح نص HTTP تحت متصفح قراءة (EventSource، صورة، تنقل——هذه رأس فقط إرسال إعطاء يمكن معلومة هدف) حيث لا حمل `Origin` أيضا لا حمل Fetch-Metadata، لذلك بلا علامة طلب ممكن هو يتم إعادة ربط صفحة إرسال بدء كما استجابة يمكن يتم قراءة مشي قراءة، بينما Host هو إعادة ربط وحيد زائف صنع لا طلب رأس؛ غير متصفح عميل مرور من عودة حلقة عنوان، دفع توجيه LAN IP حرف وجه كمية أو قد إعلان مرجعي عبر. إذا حمل `Origin` فإن يجب و Host مرجعي تماما متسق؛`sec-fetch-site: cross-site` واحد قاعدة رفض. لا هو مفرد صاف مواصفة تحويل authority `trustedHosts` بند سوف توجيه يؤدي إضافة تحميل فشل——لا فإن WHATWG تحليل سوف صامت صامت تخويل قلم خطأ داخل hostname، أو وضع كبير دقيق طرف فتحة تخويل.`host.pickDirectory` فقد ذهاب مخصص تابع حراسة حماية، و أخرى طلب نفس شبكة بينما سطر.

يمكن بلوغ صفة من webserver ربط إعداد (`host: 127.0.0.1 | 0.0.0.0`) تحكم، هذا طريق شبكة شريط هو خلط خلط بديل إدارة شخص منع صد، بينما لا هو هوية.Connection في شبكة شريط بعد تطبيق مستقل[متصفح أمر لوحة إقرار إثبات](2026-08-24-browser-token-authentication.ar.md). شبكة شريط لا فحص مقابل طرف socket عنوان: ربط جدول بلوغ يمكن بلوغ صفة،`trustedHosts` نقطة اسم قبول authority،socket عنوان توفير لا Host/Origin تحقق حاجة مقدار خارج معلومة.

## سبق اعتبار بديل خطة

- **حسب RPC ضبط منع (تأخير متابعة الآن حالة).** مرفوض: حراسة حماية بيان دائم بعيد تتبع حال طريقة بيان ركض، قيمة قيمة الأكثر عال طريقة هذا قدوم حينئذ لا يتم حراسة إقامة، بينما browse RPC فوق عودة حلقة قاعدة سوف كسر تالف هو جمع لـ لـ وجود بعيد مسار نشر.
- **CORS رأس و حذف اعتماد.** مرفوض: أنا جمع أصل هذا لا تفكير يلزم أي عبر مصدر قراءة، ينبغي جواب مسبق فحص فقط سوف توسيع كبير كشف وجه؛ رفض مسبق فحص صارم إطار أكثر قوي أيضا أكثر بسيط مفرد.
- **إقرار إثبات أمر لوحة.** في هذا تغيير في مرفوض: أمر لوحة توقيع إرسال، تخزين و جولة تبديل يخص مستقل منتج قرار. لاحق[متصفح أمر لوحة إقرار إثبات](2026-08-24-browser-token-authentication.ar.md) يحتفظ هذه آلية، لا تغيير هذا شبكة شريط.

## عاقبة

- لم قدوم أي `/api` طريقة يوم لكن في تغطية نطاق داخل؛ لا وجود سوف يتم متروك نسيان حسب توجيه معلومة مهمة قرار.
- ذاتي تعريف غير loopback تركيب يجب معلومة مهمة ذلك خدمة authority، لا فإن طلب سوف يتم رفض؛ مع بعد ما زال مثل كل loopback طلب واحد مثال ممتلئ كاف متصفح إقرار إثبات. مع مرفق CLI رفض `--host 0.0.0.0`؛`--trusted-host` فقط توسيع Host/Origin شبكة شريط، أبدا منح إعطاء هوية.
- عميل يجب إعطاء POST جسم علامة ملاحظة `application/json`(أنا جمع ذاتي ذات عميل واحد نحو مثل هذا؛ عار fetch اختبار تكملة فوق هذا رأس).
- Host و Origin ما زال فقط هو طلب توجيه دليل. عملية أمر لوحة و توقيع cookie بناء قيام كل Host طريقة استخدام متصفح هوية.
