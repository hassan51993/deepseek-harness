# Agent Note: مؤقت تخزين إتمام بعد استبدال Windows تطبيق دليل

Status: implemented

[English](2026-09-11-windows-directory-installation.md) | العربية

## مشكلة

Desktop توزيع حزمة يتضمن عدد ألف عدد صغير ملف. أولا حل ضغط إلى مؤقت دليل، مجددا سوف كل ملف نسخ إلى تثبيت موضع، الأكثر بعد حذف مؤقت شجرة، سوف تكرار تنفيذ نظام الملفات عملية.Windows فوق واحد نسخة 616,701,792 بايت،11,735 عدد ملف تحميل حمل مرور مرور هذا ثلاثة عدد مرحلة مقطع قسم آخر استهلاك وقت 101.235،79.203 و 114.391 ثانية، منها نسخ احتلال 70.296،56.688 و 85.281 ثانية. هذه مكون قياس كمية لا يشمل قديم إصدار إزالة، تسجيل، بدء، أيضا لا يوجد صاف فارغ ذاكرة مؤقتة.

## قرار

[NSIS مهايئ](../../../../apps/desktop/scripts/windows-directory-installer.mjs) إبقاء electron-builder تثبيت جهاز، توقيع إزالة جهاز توليد، تسجيل، سريع سريع طريقة و تحديث ذاكرة مؤقتة. هو في إيقاف قديم تطبيق قبل، سوف كامل جديد تطبيق مؤقت تخزين إلى هدف دليل جانب.[دليل أمر خدمة](../../../../apps/desktop/scripts/installer-directories.nsh) يأخذ قديم دليل تعديل اسم لـ وحيد تجهيز نسخة، سوف جديد دليل تعديل اسم لـ صحيح صيغة هدف، و في بدء قبل حذف تجهيز نسخة. اثنان مرة تعديل اسم كل يقع في هدف لفة. هذا بديل[تحزيم سجل](2026-08-25-electron-desktop-packaging-and-updates.zh.md) في أساس في نسخ تثبيت قرار.

تثبيت جهاز تضمين دخول ثابت إصدار 7-Zip أمر سطر أداة، لـ توقيع إصدار توقيع توقيع ذلك خاص فرعي هذا، و يحمل سماح يمكن إثبات نص.Windows في نسخ بعد وقت التشغيل يمكن تنفيذ مورد توقيع إتمام بعد سجل ملف بيان. حل ضغط خروج رمز غير صفر وقت، قديم تطبيق إبقاء كامل. فوق تنقل تثبيت جهاز خروج قبل صريح تنظيف دليل، أيضا تغطية ساكن صامت إلغاء. نفس مسار ترقية قفز مرور قديم إزالة جهاز، تجنب تجنب ذلك رفع قبل حذف تراجع فرعي هذا أو تسجيل معلومة. مختلف مسار و تثبيت نطاق ترحيل إبقاء electron-builder قديم إزالة جهاز سلوك؛ دليل تراجع لن سحب إلغاء هذه إزالة عملية.

## أثر

دليل تنظيف (يشمل إزالة) استخدام Windows توسيع طويل درجة مسار، تغطية عميق طبقة اعتماد و تجهيز نسخة بعد لاحقة. جديد دليل استبدال فشل وقت، تثبيت جهاز محاولة تجربة استعادة قد تعديل اسم قديم دليل. إذا آخر عدد عملية منع توقف استعادة، كامل تجهيز نسخة ما زال إبقاء. عملية يتم قوي صنع انتهاء أو قطع كهرباء ممكن إبقاء تحت مؤقت تخزين أو تجهيز نسخة دليل؛ تثبيت جهاز لا تحمل وعد عبر اثنان مرة تعديل اسم انهيار انهيار أصل فرعي صفة. أمر خدمة فقط تغيير تثبيت ملف، لا تغيير خارجي Desktop إضافة profile أو منتج بيانات.

## اعتبار مرور بديل خطة

- **مباشر تغطية تشغيل في تثبيت دليل.** قائم ملف احتلال استخدام استكشاف إبرة إثبات،`Nsis7z::Extract` ممكن إبقاء قديم ملف بينما لا ضبط NSIS خطأ علامة سجل. استخدام أداة لديه خروج حالة أداة إجراء مؤقت تخزين، يمكن تجنب تجنب قبول خلط دمج إصدار تثبيت.
- **حل ضغط قبل حذف قديم إصدار.** ضغط حزمة ضرر تالف أو كتابة فشل وقت، سوف في استبدال حينئذ خيط قبل إزالة وحيد متاح إصدار.
- **يأخذ Host وضع دخول ASAR.** أصلي وحدة، حزمة تحليل و عملية فرعية مسار حاجة مفرد وحيد تحقق؛ دليل استبدال إبقاء مورد تخطيط.

## تحقق

[أصلي دليل smoke](../../../../apps/desktop/scripts/smoke-installer-directories.ps1) في خاص دليل في استدعاء إنتاج كبير. هو تغطية أول مرة تثبيت، ترقية وقت حذف مرور وقت ملف، دليل احتلال استخدام فشل، ثاني مرة تعديل اسم فشل بعد استعادة، ضرر تالف عودة ملف، و إلغاء تنظيف. نموذج لوح اختبار ثابت مؤقت تخزين مبكر في إغلاق تطبيق، صحيح صيغة استبدال مبكر في تسجيل. توقيع 0.1.5-rc.2 تثبيت جهاز في Windows فوق عبر أول مرة تثبيت، نفس مسار ترقية و إزالة مرور وقت ملف، ملف احتلال استخدام فشل بعد إبقاء قديم تثبيت، تغيير تثبيت موضع و كامل إزالة. كل مرة تثبيت فحص كل سوف الكل 11,736 عدد تحميل حمل ملف و تحزيم دليل مقارنة مقابل، و تحقق برنامج، إزالة جهاز توقيع و تسجيل معلومة. قد تثبيت وقت التشغيل عبر أصلي اعتماد،Web قبل طرف، خارجي إضافة توجيه و فعلي Electron نافذة بدء و خروج فحص. نهائي تثبيت جهاز مرة مثال هذا في، أول مرة تثبيت استهلاك وقت 38.0 ثانية، نفس مسار ترقية استهلاك وقت 27.5 ثانية، لا يتضمن تحقق و بدء، لم صاف فارغ ذاكرة مؤقتة. هذه كامل تثبيت جهاز مراقبة قياس و فوق وجه مكون أساس خط قسم آخر سجل. خط فوق تحديث تحت تحميل و من تاريخ قد إصدار إصدار ترقية ما زال يخص إصدار تحقق استلام.
