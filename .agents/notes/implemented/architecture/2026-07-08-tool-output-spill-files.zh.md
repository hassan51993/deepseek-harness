# Agent Note: أداة إخراج spill سياسة

Status: implemented

[English](2026-07-08-tool-output-spill-files.md) | العربية

## مشكلة

أداة إخراج حاجة محدود نموذج مرئي معاينة، لكن جزء تجاوز كبير نتيجة ما زال ممكن في بعد لديه استخدام. إمساك أخذ صفحة متن أو زائد طويل أداة استجابة لا ينبغي كامل احتلال استخدام تحت مرة نموذج طلب، لكن نموذج ينبغي قدرة استخدام قائم ملف قراءة أداة، في بعد فحص نظر مرور مرور صيغة تحويل كامل نتيجة.

هذا بند تعديل قبل سلوك و لا متسق.`dsh-bash-local` قد سوف في داخل تخزين ذيل جزء فيض خروج وقت، يأخذ كامل stdout/stderr تدفق كتابة خاص مؤقت spill ملف؛ عادي نص أداة نتيجة فإن ما زال بـ داخل ربط شكل صيغة إرجاع، حذف غير أداة ذاتي سطر تنفيذ حد أعلى.[أداة نتيجة إبقاء مكتبة](../../archived/architecture/2026-07-06-tool-result-retention-library.md) مسؤول معاينة آلية، لكن لا مسؤول تخزين، أيضا لا مسؤول يأخذ هذه آلية تطبيق في نهائي أداة نتيجة تنفيذ خط الإنتاج سياسة.

ذلك شكل و مهلة سياسة تصميم متسق: أداة عمل من إعلان مواصفة قيمة و Native renderer(أصلي مصير) ، من سياسة إضافة في تصيير بعد محتوى فوق تنفيذ نشر افتراضي سياق ميزانية. أداة ما زال يمكن في مزود أخذ تجميع حد أعلى موضع رفع قبل spill؛ من أداة مسؤول عرض spill يمكن إبقاء قد كامل أخذ تجميع مواصفة قيمة، بينما فقط استبدال عرض محتوى.[مواصفة أداة إخراج اتفاق](2026-07-20-canonical-tool-output-contract.zh.md) قاعدة تحديد هذا بند منطقة قسم.

## قرار

في جديد `packages/spill/` قسم مجموعة تحت زيادة واحد طبقة خفيف كمية spill تخزين seam و واحد افتراضي spill سياسة إضافة:

| حزمة | زاوية لون |
|---|---|
| `@deepseek-ai/dsh-spill` | واجهة:`ctx.spillStore`، مفردات نوع، لا يتضمن تخزين تنفيذ. |
| `@deepseek-ai/dsh-spill-local` | محلي خلفية: في مضيف نظام الملفات في توفير خاص، جلسة أثر مجال ملف تخزين. |
| `@deepseek-ai/dsh-spill-policy` | أداة نتيجة سياسة إضافة: حزمة تركيب توزيع بعد نهائي نص نتيجة، و بـ إبقاء معاينة و spill تحديد موضع رمز استبدال تجاوز كبير نتيجة. |

أداة نتيجة مستهلك هو `dsh-spill-policy`، هو عبر `tools/post-execute` waterfall(شلال نشر صيغة حدث) استخدام نهائي أداة نتيجة. نموذج حسب وفق خلفية مع تحديد موضع رمز إرجاع فحص بحث تلميح قراءة محتوى.[جلسة مرجع spill إعادة استخدام](../bug-fix/2026-09-05-session-reference-spill-reuse.zh.md) زيادة واحد مباشر تخزين مستهلك، اعتماد مستقل معاينة، مصدر معلومة و فشل دلالة؛ هو لا تغيير أداة نتيجة سياسة.

### spill seam

تخزين seam إبقاء الأكثر صغير تحويل: حفظ نص، و إرجاع تحديد موضع رمز و فحص بحث تلميح.

```ts ignore-check
interface SpillStore {
  saveText(input: SaveTextSpill): Promise<SpillRef>
}

type SpillSource = {
  kind: 'tool'
  toolName: string
  callId: ToolCallId
  label: string
} | {
  kind: 'session-reference'
  sessionId: SessionId
  label: string
}

interface SaveTextSpill {
  owner: { sessionId: SessionId }
  source: SpillSource
  suggestedName: string
  content: string
}

type SpillLocator = Branded<'SpillLocator'>

interface SpillRef {
  locator: SpillLocator
  bytes: number
  retrievalHint: string
}
```

`SpillLocator` هو واحد[صنف لوحة تحويل](../../../../packages/util/brand) نموذج مرئي جملة مقبض، من خلفية إرجاع. محلي خلفية سوف ذلك تصيير لـ نظام الملفات مسار؛ بعيد مسار أو قاعدة بيانات خلفية يمكن تصيير URI، مفتاح أو أمر token. مستهلك يأخذ هو نظر لـ لا نفاذ واضح قيمة، و استخدام `retrievalHint` تصيير، بينما لا هو زائف تحديد `read` بداية نهاية هو صحيح تأكيد فحص بحث آلية.`SpillOwner.sessionId` هو حفظ وقت تخزين نطاق الأسماء:fork بعد جلسة سوف من نوع فرعي سجل وراثة قد لديه spill تحديد موضع رمز، بلا حاجة نسخ هو جمع أو إعادة أخذ نيل كل حق؛fork بعد جديد spill استخدام فرعي جلسة id. إبقاء مدة تنظيف يمكن وصل نفس أخرى قديم جلسة ناتج واحد بدء جعل قديم تحديد موضع رمز بطلان؛spill seam لا تعريف تدريجي جلسة تنظيف سياسة.

`dsh-spill-local` مسؤول تخزين دقيق عقدة: اختيار جلسة أثر مجال دليل، أمان اسم، منع توقف مسار مرة تاريخ، تنفيذ كتابة، محلي ناتج دورة الحياة، و إرجاع `{ locator, bytes, retrievalHint }`. هو لا مسؤول أداة نتيجة استبدال، نموذج مرئي معاينة سياسة، بحث، ملف فحص، أيضا لا تعريف seam درجة أو تدريجي جلسة إبقاء سياسة. ملف كتابة `<root>/session-<hash>/<random>-<safeName>`:`root` هو إعداد مسار، أو تأخير متأخر إنشاء خاص (0700) عملية درجة مؤقت دليل؛ جلسة فرعي دليل هو `sha256(sessionId)` قصير بادئة؛ ورقة عقدة من مع آلة عشرة ستة دخول صنع بادئة و استدعاء جهة `suggestedName` مجموعة صار، بعد من سوف يتم تنظيف صار مفرد واحد مسار مقطع (و JSONL خلفية `encodeSegment` متسق). نظام استخدام `open(path, 'wx', 0o600)` كتابة، تأكيد حفظ وحيد احتلال كما فقط كل من يمكن وصول، لذلك مسبق أولا غرس دخول رمز رقم رابط لا يمكن إعادة تحديد نحو كتابة. تحديد موضع رمز حينئذ هو هذا مسار، فحص بحث تلميح فإن إبلاغ معرفة نموذج يمكن في هذا مسار فوق استخدام `read` أو `grep`. هو مرة صفة بدء تنظيف سوف تطبيق[محلي spill تنظيف شرح](../../archived/architecture/2026-07-17-local-spill-startup-cleanup.md) الذي وصف خلفية مخصص تابع ناتج دورة الحياة.

### spill سياسة

`dsh-spill-policy` هو واحد `tools/post-execute` نتيجة تحويل جهاز، فقط توفير واحد بند إعداد:

```ts ignore-check
interface Config {
  /** Omitted means no automatic spill policy. Present means apply to oversized plain text tool results. */
  maxInlineBytes?: number
}
```

حذف `maxInlineBytes` وقت، إضافة لن تسجيل أي محتوى، هو حق صحيح بلا عملية. ضبط هذا قيمة بعد، هو سوف مقابل نهائي صاف نص أداة نتيجة تطبيق افتراضي سياسة:

1. يجعل أداة صحيح معتاد تشغيل، عبر `next()` تفويض حمل، جعل تحت تنقل مستمع أولا تسوية نتيجة.
2. فقط عند قد قبول نهائي `ContentBlock[]` الكل هو صاف نص وقت، عندئذ سوف ذلك عرض مستو؛ يحتوي أي غير نص كتلة نتيجة إبقاء ثابت.
3. إذا UTF-8 بايت كبير صغير لا تجاوز مرور `maxInlineBytes`، إبقاء ثابت.
4. إذا تجاوز خروج حد أعلى، استخدام كامل نهائي نص استدعاء `ctx.spillStore.saveText()`.
5. يأخذ نموذج مرئي نتيجة استبدال لـ إبقاء أول ذيل معاينة و spill مرجع.

معاينة يخص سياسة كل تنفيذ قيمة افتراضية: بـ `maxInlineBytes` لـ حد أعلى، استخدام إبقاء مكتبة `TextRetainer` إجراء أول ذيل قسم قطع. فقط لديه ثاني عدد نشر إثبات لديه هذا يحتاج طلب بعد، لم قدوم إعداد عندئذ سوف عام معاينة كبير صغير.

استبدال نص لحظة معنى إبقاء عام، لأن سياسة فقط معرفة طريق نهائي صيغة تحويل أداة نتيجة، لا حل أداة داخلي مورد:

```text
<retained preview>

(Omitted N bytes. Full formatted result stored at: /.../session-.../....txt. Use read with offset/limit, or grep this path to search within it.)
```

إذا `ctx.spillStore.saveText()` فشل (إذن،ENOSPC، خلفية غير ممكن استخدام) ، أو استدعاء لا يوجد جلسة كل من، أو لم تحميل خلفية، إضافة سوف سجل سبب و أصل مثال إرجاع نتيجة.spill فشل أبدا سوف يأخذ نجاح أداة استدعاء تغيير لـ `isError` نتيجة، أيضا لن إخفاء داخل ربط نتيجة.

سياسة قفز مرور `read`، بـ تجنب تجنب شكل صار `read -> spill file -> read again` حلقة. مقدار خارج اختيار خروج إعداد يلزم انتظار تأكيد فعلي ظهور ثاني عدد لديه هذا يحتاج طلب أداة بعد مجددا جذب دخول.

## عرض مثال:web_fetch

`web_fetch` هو أول عدد عرض مثال، لأن هو يوم لكن سوف إرجاع مقارنة كبير نص نتيجة، بينما كما بلا حاجة أداة مخصص استخدام spill شفرة. هذا أداة ذاته بلا حاجة خاص خاص معالجة:

```ts ignore-check
ctx.tools.register(defineTool({
  name: 'web_fetch',
  output: {
    schema: WEB_FETCH_RESULT_SCHEMA,
    render: (_args, value) => [{ type: 'text', text: formatFetchOutput(value) }],
  },
  async execute(args, exec) {
    const result = await ctx.web.fetch({ url: args.url }, exec.signal ? { signal: exec.signal } : undefined)
    return result
  },
}))
```

إعداد `dsh-spill-policy` بعد، صيغة تحويل بعد كبير نوع fetch نتيجة سوف تلقائي إبقاء و spill. نشر عبر يأخذ مزود مورد حد أعلى ضبط نيل عال في سياسة حد أعلى قدوم عرض هذا سلوك:

```yaml
- id: web-fetch-http
  name: '@deepseek-ai/dsh-web-fetch-http'
  config:
    maxBodyChars: 500000

- id: spill-local
  name: '@deepseek-ai/dsh-spill-local'

- id: spill-policy
  name: '@deepseek-ai/dsh-spill-policy'
  config:
    maxInlineBytes: 50000
```

هذا بند قسم مغادرة جدا إعادة يلزم.`web-fetch-http` ما زال مسؤول مورد حد أعلى (`maxResponseBytes`،`maxBodyChars`) ، استخدام قدوم حفظ حماية شبكة شبكة، داخل تخزين و حل رمز عمل.`spill-policy` فقط مسؤول نتيجة قد وجود بعد إبرة مقابل نموذج سياق حد أعلى. إذا مزود قد إرجاع `truncated: true`،spill ملف يتضمن هو أداة إرجاع كامل صيغة تحويل نتيجة، بينما لا هو أصلي شبكة صفحة كل نص؛ سياسة لن فعل خروج أخرى تحمل وعد.

## و إبقاء و رفع قبل spill علاقة

إبقاء و spill تخزين متبادل متبادل مستقل:

- `@deepseek-ai/dsh-output-retention` مسؤول معاينة آلية (`TextRetainer`،`ItemRetainer` و حذف بيانات وصفية).
- `@deepseek-ai/dsh-spill` مسؤول حفظ نهائي نص، و إرجاع تحديد موضع رمز و فحص بحث تلميح.
- `@deepseek-ai/dsh-spill-policy` في أداة خط الإنتاج في تطبيق افتراضي نهائي نتيجة سياسة، سوف قبل اثنان من تركيب بدء قدوم.

نهائي نتيجة سياسة لا يستطيع يحل محل من أداة مسؤول رفع قبل spill. جزء لديه استخدام محتوى و لا وجود في نهائي `ToolExecutionResult.content` في:

- `bash` نهائي إخراج قد هو ذيل جزء محتوى إضافة مؤقت spill مسار؛ كامل stdout/stderr تدفق يقع في منفذ ملف في.
- `subagent` نهائي إخراج هو subagent نهائي عودة جواب، بينما لا هو subagent تنفيذ مسار أثر.
- لم قدوم أداة ممكن توليد من لم ظهور في نهائي `ToolExecutionResult.content` في وقت التشغيل ناتج.

هذه مشهد يمكن في لاحق عمل في مباشر استخدام `ctx.spillStore`، لا يخص أول عدد عرض مثال نطاق.

## غير هدف

- هذا قرار لا زيادة موجه إلى نموذج `artifact_read` أو `artifact_search` أداة.
- هذا قرار لا زيادة تدريجي أداة إبقاء إعداد.
- لا زيادة موجه إلى نموذج مهلة/قطع قطع معامل.
- لا يأخذ `read` إخراج ترحيل إلى spill ملف.
- لا يحل محل `web-fetch-http.maxBodyChars` انتظار مزود/مورد حد أعلى.
- رقم واحد إصدار لا موحد واحد bash مؤقت ملف، أيضا لا أخذ تجميع subagent تنفيذ مسار أثر.

## تأخير بعد أمر بند

- لأجل قائم منفذ spill ملف `saveFile()`/`linkOrCopy`، هذا هو موحد واحد bash سلوك الذي مطلوب.
- من أداة مسؤول subagent تنفيذ مسار أثر spill(`await run.result`، في `run.dispose()` قبل قراءة عملية داخل فرعي جلسة، حفظ JSONL).
- إذا داخل وضع `read` قفز مرور قاعدة لا كاف، مجددا زيادة تدريجي أداة اختيار خروج أو تدريجي أداة سياسة إعلان.
- موجه إلى ACP(Agent Client Protocol) أو بعيد مسار بيئة بعيد مسار/قاعدة بيانات تخزين خلفية، لأن محلي مسار في هذه بيئة في لا يوجد معنى معنى.

محلي خلفية عبر مرة صفة بدء مسح تنظيف قديم ملف، بينما لا هو ربط إلى جلسة حذف——مشاركة رؤية[بدء تنظيف Agent Note](../../archived/architecture/2026-07-17-local-spill-startup-cleanup.md).seam ما زال لم تعريف تدريجي جلسة تنظيف سياسة؛ إبقاء سياسة يخص خلفية.

## اختبار

- `dsh-spill` اختبار وحدة قفل تحديد seam اتفاق: تسجيل لـ `ctx.spillStore`، كل سياق فقط سماح واحد نوع تنفيذ، و في dispose(مورد تحرير) وقت تحرير.
- `dsh-spill-local` اختبار وحدة تغطية `saveText`،`encodeSegment` تنظيف (قسم فصل رمز/موجة موجة رقم/كامل مسار مقطع نقطة/فارغ قيمة) ، جلسة ها أمل دليل، فقط كل من إذن، كل مرة حفظ توليد مختلف مسار، إعداد أصل دليل/خاص أصل دليل، و تخزين فشل وقت رفض.
- `dsh-spill-policy` اختبار وحدة عبر `ctx.tools.execute` قيادة حقيقي أداة: منع استخدام نمط تحت بلا عملية، استبدال تجاوز كبير نص، صغير نتيجة/غير نص نتيجة إبقاء ثابت، قفز مرور `read`، كل قوة رجوع (حفظ فشل/بلا خلفية/بلا كل من) ، و تحت تنقل تركيب (حد قد استبدال نتيجة، إبقاء `additionalContexts`).
- `dsh-tool-web` اختبار تكامل قيادة `web_fetch`، ذلك فعلي تنفيذ مسار مرور مرور `ctx.tools.execute`، و استخدام حقيقي `spill-local` خلفية و سياسة؛ اختبار إثبات فقط لديه لحظة معنى إضافة دخول spill تلميح سوف تغيير نموذج مرئي نص، بينما spill ملف حفظ كامل صيغة تحويل نتيجة.
- `tui-agent` عرض مثال تحميل `spill-local` و `spill-policy`، لذلك ذلك بلا مفتاح Loader/PTY خطر دخان اختبار سوف تنفيذ حقيقي تحميل مسار (namespace-plugin توجيه خروج شكل و `inject`).

## أثر

افتراضي سياسة فقط قدرة نظر رؤية نهائي صيغة تحويل نص. هو لا يمكن إبقاء قد من مزود حد داخلي محتوى، أيضا لا يمكن إبقاء من لم يصبح نتيجة واحد جزء وقت التشغيل ناتج. رقم واحد إصدار تجمع تركيز نهائي نتيجة spill بينما لا هو رفع قبل spill، لذلك يمكن قبول هذا واحد حد؛ من أداة مسؤول رفع قبل spill ما زال يخص لاحق عمل.

محلي خلفية إرجاع حقيقي مسار، جعل ذلك إبقاء بسيط مفرد و رمز دمج قد تحقق agent(ذكي جسم) أداة سلوك؛seam ذاته فقط تحمل وعد واحد لا نفاذ واضح تحديد موضع رمز إضافة فحص بحث تلميح، الذي بـ بعيد مسار خلفية يمكن إرجاع غير ملف تحديد موضع رمز.

محلي خلفية قيمة قيمة أخذ قرار في قائم `read`/`grep` أداة قدرة لا فحص إرجاع محلي مسار، أي جعل spill دليل يقع في جلسة cwd خارج. هذا واحد شرط صار قيام، لأن نظام الملفات سياسة سوف سجل مراقبة نتيجة و ضبط كتابة حفظ حماية، لكن لن يأخذ قراءة حد في مساحة العمل داخل. لم قدوم مساحة العمل حد سياسة يجب صريح سماح محلي spill مسار، أو تعديل استخدام فحص بحث تلميح إشارة نحو تلقي دعم حمل قراءة جهاز غير ملف spill خلفية.

**لقطة نقص فتحة.** هدف قبل لا يوجد ACP لقطة مشهد تغطية transcript(نص سجل) مرئي `web_fetch` spill تلميح.ACP لقطة harness في بلا مفتاح بيئة في إعادة تشغيل، لا يمكن وصول فوري web، بينما `web_fetch` spill حاجة واحد حقيقي تجاوز حد أعلى HTTP متن؛ تحديد صفة مشهد حاجة واحد مسبق وضع loopback fetch هدف، لكن حالي إعادة تشغيل شجرة بعد لم وصل خط (عرض مثال أصل هذا لا يوجد تحميل `tool-web`). هذا سلوك تعديل من `dsh-tool-web` إبرة مقابل loopback server اختبار تكامل تغطية. سد تكملة هذا نقص فتحة يخص لاحق عمل: يأخذ `tool-web` و مسبق وضع fetch هدف وصل دخول ACP عرض مثال، لكن بعد تسجيل صنع `web-fetch-spill` مشهد.

إذا سياسة بدء مسؤول أداة مخصص استخدام دلالة، حينئذ سوف تمدد انتفاخ نيل مرور كبير. هو نطاق إبقاء ضيق ضيق: فقط معالجة صاف نص نهائي نتيجة. من أداة مسؤول رفع قبل spill ما زال إبقاء عمل لم قدوم عمل.

## اعتبار مرور بديل خطة

**اشتراط كل أداة عبر إبقاء إعلان اختيار إضافة دخول.**غير مقبول، لأن هدف هو تنفيذ صنف يشبه Claude Code عام أداة نتيجة حفظ دائم افتراضي سلوك. فقط يحتاج واحد `maxInlineBytes` نشر بند إعداد يكفي تحقق هذا شكل.

**يأخذ `tool-results` بناء صار عرض عام أداة نتيجة منصة.** غير مقبول: عرض عام حزمة اسم سوف إغراء جعل نظام يأخذ إبقاء سياسة، نتيجة استبدال، معاينة إجراء لفظ، بحث و رفع قبل spill دمج دخول واحد seam. يمكن مشترك تخزين جزء أكثر صغير: حفظ نص، و إرجاع تحديد موضع رمز و فحص بحث تلميح.

**استخدام `ctx.fs.writeText` أو موجه إلى نموذج `write` أداة.** غير مقبول: مساحة العمل نظام الملفات كتابة حمل لديه مشروع ملف دلالة، كتابة/تحرير سياسة، مراقبة حالة و موجه إلى مستخدم فرعي أثر.spill ملف هو وقت التشغيل ناتج، لا هو من نموذج تحرير كتابة مساحة العمل تعديل. قائم `read` أداة بعد يمكن فحص هو جمع، لكن إنشاء عملية يخص وقت التشغيل spill seam.

**يجعل `web-fetch-http` لا تلقي حد أرض إمساك أخذ، فقط اعتماد اعتماد spill-policy.** غير مقبول:spill-policy في نهائي أداة نتيجة قد وجود بعد عندئذ تشغيل، لا يمكن حفظ حماية شبكة شبكة، داخل تخزين أو حل رمز مورد. مزود مورد حد أعلى ما زال يجب وجود.

**يأخذ إبقاء دمج دخول spill آلية.** غير مقبول: إبقاء و spill مسؤولية مختلف.`TextRetainer`/`ItemRetainer` قرار إبقاء أي جزء معاينة، أيضا حذف ماذا؛spill تخزين فقط مسؤول حفظ سياسة اشتراط نهائي نص.
