# Agent Note: POSIX SSH تنفيذ مزود

Status: implemented

[English](2026-09-11-posix-ssh-runtime.md) | العربية

## مشكلة

بعيد طرف تحرير رمز حاجة ملف أداة،Bash، طرفية، لغة خادم و Node برنامج يرى نفس عدد نظام الملفات و عملية بيئة.[يمكن نقل غرس مستهلك قرار](2026-07-28-portable-execution-world-consumers.ar.md) توفير هذه واجهة.[E2B تراجع دور قرار](../simplification/2026-09-11-remove-e2b-providers.ar.md) إبقاء ذلك مختلف خطوة دلالة، معا إزالة واحد حاجة مفرد وحيد نقل مشروع عندئذ قدرة عبر معيار تدفق مكتبة تحمل تحميل مزدوج نحو PTC تحكم تدفق تجميع صار.

SSH توفير مرور مرور إقرار إثبات بايت عبر طريق و تدريجي عبر طريق تدفق كمية تحكم، لكن عادي exec طلب لا خريطة مهمة معنى عملية فرعية وصف رمز. إذا يأخذ SSH عند عمل عملية إدارة جهاز بديل صنف، تحكم تدفق جسر وصل، بدء إصدار،EOF، إلغاء و قطع وصل تنظيف حينئذ سوف نقص قليل تنفيذ.

## قرار

نشر جهة يحتفظ OpenSSH رئيسي آلة آخر اسم سوف محلي Harness اتصال إلى قد تثبيت POSIX مساعد مساعدة برنامج. نظام الملفات، عملية فرعية و صندوق رملي مزود مشترك هذا مساعد مساعدة برنامج؛Harness إبقاء Cordis كائن، نموذج نقل، إذن، عودة ضبط و Session حفظ دائم. طرفية طريقة إبقاء مختلف خطوة. مزود مسار وصف تنفيذ بيئة، بلا حاجة مقدار خارج محلي/بعيد طرف علامة.

حد تحليل دعم حمل مختلف خطوة و إلغاء: صحيح في تشغيل مساعد مساعدة برنامج عبر قد تحميل صندوق رملي مزود تحليل كل مرة سياسة، لكن بعد عملية فرعية مزود أخذ نيل يمكن مباشر تنفيذ argv.`ShellExecutor.start()` في دقيق تجهيز إتمام بعد إرجاع `Promise<ShellProcess>`. عام مهمة دقيق دخول إبقاء تزامن؛ من أداة مسؤول `JobHooks` في مسبق فحص بعد بدء مختلف خطوة shell دقيق تجهيز، إلغاء انتظار إتمام دقيق تجهيز و انتظار أي تأخير متأخر ظهور عملية جملة مقبض انتهاء.

خاص إدارة RPC و كل بند برنامج تدفق استخدام مستقل SSH عبر طريق. بعيد طرف مسبق إبقاء عملية في برنامج بدء قبل إنشاء طلب تدفق طرف نقطة.stdout و stderr لا يمكن تحمل تحميل إدارة عودة تكرار، مؤقت توقف واحد بند إخراج عبر طريق أيضا لن احتلال استخدام fd 7 تدفق تحكم نافذة. هذا استخدام أكثر كبير بعيد طرف مساعد مساعدة برنامج تبديل أخذ صريح اثنان دخول صنع نقل و محدود تدفق إبقاء.

كل بند تدفق عبر خاص إدارة RPC نيل نيل جديد 256 موضع TLS مسبق مشترك مفتاح.TLS 1.2 إعداد دمج `PSK-AES256-GCM-SHA384` في تدفق إصدار قبل إقرار إثبات اثنان طرف و حفظ حماية لاحق بايت. مفتاح أبدا بصفة تدفق بادئة نقل. فقط اعتماد طقم وصل حرف إذن لا كاف: ملف فاعلية نتيجة حد ممكن سماح نفس مستخدم اتصال، أو سماح في يمكن كتابة مؤقت دليل في استبدال مسار اسم. برنامج لن نيل نيل إدارة Unix استماع طرف نقطة أو تدفق مفتاح. حزمة تركيب إتمام بعد، إلغاء مسؤولية مهمة تحويل نقل إلى TLS حزمة تركيب تدفق؛ تنظيف أولا إغلاق هذا تدفق، مجددا إغلاق قاع طبقة طقم وصل حرف، تأكيد حفظ أصلي TLS قراءة لن تجاوز مرور نقل طبقة دورة الحياة.

استلام تجميع stdout و stderr عبر فقط تحديث إخراج مراقبة قياس معالج نقل تمرير محدود ذيل جزء لقطة. لقطة انتظار نقل وقت، إخراج التقاط متابعة إجراء. نهائي لقطة إبقاء أصلي بايت انحراف نقل، قد إتمام spill ملف في اتصال تحرير بعد استخدام محلي مزود إبقاء إخراج تخزين.

حينئذ خيط مسار تحقق قد تثبيت مساعد مساعدة برنامج ملخص، و في إعداد PTC وقت تحقق قد تثبيت Node جذب توجيه برنامج ملخص. هذه فحص ثابت مسبق مدة نشر ناتج، لا لأجل إقرار إثبات سيئ معنى بعيد طرف عملية نظام. مساعد مساعدة برنامج منع استخدام عبر `SIGUSR1` بدء Node ضبط تجربة جهاز: ملف فاعلية نتيجة حد ما زال ممكن سماح نفس مستخدم إشارة، هذه إشارة لا نيل كشف مساعد مساعدة برنامج لا تلقي حد نظام الملفات و عملية خدمة. ملف فاعلية نتيجة حد تفويض حمل إعطاء بعيد طرف محلي صندوق رملي مزود، إبقاء ذلك كامل/جزء تنفيذ كشف كشف و منصة حد.

مسار مواصفة تحويل يخص ملف فعلي وجود موضع. مشترك سياسة محلل إبقاء تنفيذ بيئة في قطعا مقابل مسار كتابة قاعدة؛ تنفيذ حد مزود في ذاتي ذات نظام الملفات فوق تحليل رمز رقم رابط و `..`.headless عبر `ctx.fs` سجل و تحقق cwd.SSH لا توفير رئيسي آلة مسار إسقاط، لذلك Node تنفيذ حاجة صريح تثبيت بعيد طرف جذب توجيه برنامج.

اتصال فقد فقد سوف جعل انتظار معالجة عملية بطلان، لا إجراء إعادة وصل أو إعادة وضع. مساعد مساعدة عملية EOF، إشارة و قلب قفز إيجار مدة سوف بدء بعيد طرف أصلي تنظيف. عميل لا يستطيع يأخذ إيجار مدة إلى مدة عند عمل مراقبة إلى نجاح إنهاء: يتم في قطع تعديل أو بدء ممكن نتيجة لم معرفة. إدارة طلب قطع توقف وقت حد، مستهلك تنفيذ قطع توقف وقت حد و تنظيف قسم آخر من كل منها ملكية جهة مسؤول.

## اعتبار مرور بديل خطة

**في SSH exec stdout/stdin فوق لـ كل تدفق قسم لقطة.** هذا تجنب تجنب Unix طقم وصل حرف تحويل إرسال، لكن اشتراط تطبيق بروتوكول ذاتي سطر تنفيذ تدريجي تدفق مقدار درجة، طابور صف حد أعلى و مستقل EOF دلالة. مستقل SSH عبر طريق استخدام نقل طبقة قائم تدفق تحكم، و سوف برنامج إخراج و إدارة لقطة قسم فتح.

**فقط استخدام SFTP بديل بعيد طرف ملف عملية.** SFTP توفير ملف نقل، لكن لا مباشر إبقاء قائم حمل حفظ حماية أصل فرعي كتابة، تحرير، سياسة و خطأ دلالة. إعادة استخدام بعيد طرف محلي نظام الملفات مزود، جعل هذه آلية متابعة ملكية قائم تنفيذ.

**عبر TCP أو HTTP طرف نقطة توفير برنامج تدفق.** هذا سماح مستقل نقل، لكن سوف في قائم SSH اتصال خارج جذب دخول بعيد طرف طرف فتحة كشف، طرف نقطة إقرار إثبات و خادم نشر. تحويل إرسال Unix طقم وصل حرف استخدام قد إقرار إثبات SSH جلسة، و عبر TLS-PSK مقدار خارج إقرار إثبات تدفق اثنان طرف، بـ منع صد نفس مستخدم اتصال أو مسار اسم استبدال.

**يأخذ كامل Harness نقل إلى بعيد طرف رئيسي آلة.** هذا هو آخر نوع نشر نموذج، سوف سوف نموذج اعتماد،Session تخزين و إضافة حالة مع تنفيذ واحد بدء ترحيل، بينما لا هو توفير قائم قدرة بعيد طرف تنفيذ.

## أثر

بعيد طرف مزود رغم لكن إعادة استخدام محلي ملف و عملية آلية، ما زال زيادة نقل، مسبق إبقاء و قطع وصل مسؤولية مهمة. أصلي تدفق، استلام تجميع ذيل جزء و بعيد طرف spill ملف إبقاء كل منها دورة الحياة. مستهلك يجب تحرير تدفق و جملة مقبض؛ نقل فقد فقد بعد لا يمكن إعادة بناء مساعد مساعدة عملية تنظيف نتيجة.

ابتدائي تركيب نطاق لـ POSIX headless و ذاتي تعريف إعداد تركيب. زائف تحديد يمكن وصول رئيسي آلة نظام الملفات Web مساحة العمل مستهلك حاجة مستقل تجميع صار. شبكة شبكة حد، عملية مرئي صفة عزل، سيئ معنى رئيسي آلة إثبات، حمل دائم بعيد طرف جملة مقبض و تلقائي ناتج إعداد لا يخص هذا مزود بيت عائلة.

يمكن نقل غرس مستهلك قرار متابعة صالح؛ هذا نص توفير ذلك SSH تنفيذ.E2B تراجع دور قرار ما زال مسؤول قد إزالة تجميع صار و صيانة أخذ ترك. اثنان مقالة سجل متساو لم يتم تماما يحل محل.

## تحقق

لا بد يلزم بروتوكول و دورة الحياة دليل تغطية شاذ شكل رسالة، حد أعلى، مسبق إبقاء إلغاء، مرور مرور إقرار إثبات تدفق إصدار و قطع وصل خطأ. أصلي SSH تحقق استلام يجب تغطية بعيد طرف ملف حفظ حماية و رمز رقم رابط هوية،Bash حد،fd 7 اثنان دخول صنع تدفق، إخراج مؤقت توقف وقت تحكم دخول عرض، طرفية عملية،LSP و Node تنفيذ. فوري فحص اشتراط صريح إعداد يمكن إسقاط بعيد طرف مساحة العمل؛ بلا مفتاح اختبار لا إنشاء بعيد طرف بيئة.

أمان دليل اشتراط معا محاولة تجربة نفس مستخدم اتصال و استبدال طقم وصل حرف استماع طرف نقطة، و تأكيد ذلك لا يمكن احتلال استخدام مسبق إبقاء تدفق، نيل معرفة تدفق مفتاح، تعديل آخر تنفيذ أو استلام إلى ذلك واضح نص إخراج. عملية دورة الحياة دليل منطقة قسم مباشر خروج و حمل إدارة عملية نطاق ساكن توقف، و اختبار بدء إصدار قبل و برنامج بدء بعد إلغاء. شفرة المصدر و بناء بعد إعداد تركيب فحص تحقق قد تثبيت مساعد مساعدة برنامج/جذب توجيه أمان ترتيب، لا نحو برنامج بيئة نقل تمرير رئيسي آلة اعتماد.

## تأخير بعد عمل

حمل دائم بعيد طرف إعادة وصل حاجة مستقل عملية هوية و استعادة تصميم، لا يستطيع في قطع وصل بعد إعادة استخدام نشط وثب عودة ضبط جملة مقبض. أكثر واسع عام Web دعم حمل حاجة من مزود مسؤول مساحة العمل مورد. أكثر قوي مورد حساب كمية أو إصلاح حجز بعد PTC yield/wait و مهلة سياسة يخص [Node وقت التشغيل مشاركة اعتبار](../../../../packages/ptc-runtime/ptc-runtime-node/README.ar.md) ، لا يخص SSH إدارة طلب قطع توقف وقت حد.
