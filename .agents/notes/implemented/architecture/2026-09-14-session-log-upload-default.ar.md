# Agent Note: DeepSeek جلسة سجل افتراضي فوق نقل

Status: implemented

[English](2026-09-14-session-log-upload-default.md) | العربية
## مشكلة

عادي DeepSeek طلب لا يتضمن كامل مواصفة جلسة مسار أثر. اشتراط كل تثبيت بيئة تفعيل سجل مساهمة، سوف جعل افتراضي منتج إعداد لا يمكن توفير هذا مسار أثر. تسجيل صنع جلسة مشهد أيضا حاجة مستقر، واضح فوق نقل سياسة، لأن قبول حدث يخص ذلك مدة نظر سجل.

## قرار

`session-log-deepseek.Config.enabled` في كل عملية في متساو افتراضي لـ `true`. صريح ضبط `enabled: false` يمكن إغلاق مساهمة. إضافة لا قراءة اختبار تشغيل جهاز أو لقطة بيئة متغير.

هذا قرار فقط يحل محل[طلب توسيع قرار](2026-08-21-deepseek-llm-api-request-extensions.ar.md) في رئيسي حركة تفعيل افتراضي سياسة؛ هذا سجل ما زال مسؤول حقل تسلسل تحويل، هدف عنوان، قبول و إعادة محاولة دلالة.headless و ACP لغة مادة أساس أساس patch و Web scaffold صريح إغلاق فوق نقل. لاحق مشهد patch يمكن تفعيل فوق نقل.SDK text-turn تسجيل صنع حذف هذا ضبط، تحقق منتج قيمة افتراضية و حمل دائم قبول حدث.

## اعتبار مرور بديل خطة

**أصل حسب اختبار بيئة علامة قرار إنتاج قيمة افتراضية.** استدعاء من وراثة هذه متغير وقت، تحت تنقل SDK سلوك أيضا سوف تغيير، عادي اختبار أيضا سوف اعتماد مختلف منتج قيمة افتراضية.

**تحديث جديد كل تسجيل صنع جلسة بـ يتضمن فوق نقل قبول حدث.** صريح اختبار إعداد إبقاء قائم مشهد، معا استخدام افتراضي إعداد SDK تسجيل صنع و Loader ارتداد تحقق افتراضي فتح بدء مسار.

**إبقاء رئيسي حركة تفعيل سياسة.** لا يوجد تثبيت بيئة مخصص استخدام إعداد وقت، هذا سياسة لا يمكن من عادي منتج طلب توفير كامل مسار أثر.

## عاقبة

رمز دمج شرط طلب سوف نحو تحليل بعد DeepSeek طرف نقطة أو قد إعداد شبكة صلة إرسال كامل لم قبول مواصفة سجل بعد لاحقة، يشمل رسالة نص، أداة معامل و نتيجة، مساحة العمل مسار و ملاحظات. لا زيادة نص التوجيه token أو نموذج مرئي محتوى. طلب متن ممكن إظهار بارز زيادة كبير، مزود رفض ما زال سوف جعل طلب فشل.OTel إبقاء مستقل، إغلاق OTel لن إغلاق هذا مساهمة.

إعداد اختبار تغطية لديه بلا اختبار بيئة علامة وقت افتراضي فتح بدء و صريح تغطية. اثنان نوع DeepSeek بروتوكول Loader حالة استخدام مراقبة افتراضي طلب حقل و قد سجل قبول ماء موضع، صريح إغلاق حالة استخدام مراقبة اثنان من متساو لا وجود. قائم headless،ACP،Web و SDK تسجيل صنع تحقق كل منها إعلان فوق نقل سياسة، بلا حاجة إعادة كتابة قد إيداع جلسة بديل حد.
