# Agent Note: أصلي Windows تثبيت صفحة

Status: implemented

[English](2026-09-10-windows-native-installer-pages.md) | العربية

## Problem

Windows تثبيت واجهة حاجة رمز دمج صنف لوحة تصميم مضيء داكن صفحة، معا تجنب تجنب جذب دخول مقدار خارج تطبيق وقت التشغيل، أيضا لا يستطيع استبدال Desktop حل ضغط، تسجيل، ترقية و إزالة إصدار آلية.

## Decision

تثبيت برنامج عبر electron-builder NSIS include وصل دخول ذاتي تعريف فرح استقبال صفحة، دخول درجة صفحة و إتمام صفحة. أصلي نص برمجي متابعة مسؤول تثبيت و إزالة برنامج توليد. كامل ذاتي تعريف نص برمجي سوف التفاف مرور electron-builder مفرد وحيد توليد و توقيع إزالة برنامج مسار، لذلك لا ملائم دمج هذا مرة واجهة تعديل.[Desktop إصدار قرار](2026-08-25-electron-desktop-packaging-and-updates.ar.md) متابعة مسؤول إصدار هوية، تحديث توزيع و توقيع اشتراط.

NSIS أصلي تحكم عنصر إبقاء دليل تحرير، ملف مشبك اختيار، تكرار اختيار حالة و مفتاح قرص تفاعل.x86 Win32/GDI+ مساعد مساعدة مكتبة إبقاء DWM ظل أثر، و في أصلي تثبيت عمل خط مسار تشغيل خلال، من واجهة خط مسار رسم صنع تثبيت دخول درجة. أي جعل NSIS في MUI عودة ضبط بعد إعادة عرض صفحة، أصلي صفحة ما زال إبقاء إخفاء.Windows 11 توفير خارج إطار دائرة زاوية نصف مسار؛Windows 10 إبقاء ذلك دعم حمل نافذة خارج مراقبة.

تثبيت موجه إلى حالي مستخدم. فرح استقبال صفحة مغادرة فتح تحقق في فأرة علامة و مفتاح قرص تنقل وقت متساو قراءة حالي تحرير إطار؛ منع اهتزاز عرض سطر داخل تلميح لا قرار فعلي تثبيت مسار. عملية فحص مطابقة تلقي أثر يمكن تنفيذ ملف مسار، جعل أخرى تثبيت إبقاء مستقل. إتمام صفحة مغادرة فتح عودة ضبط في فأرة علامة و مفتاح قرص تنقل وقت متساو التزام دوران بدء تكرار اختيار إطار.electron-builder في ذاتي تعريف ابتدائي تحويل قبل تحليل قد تسجيل تسجيل دليل، لذلك لا حمل `/D=` ساكن صامت تحديث سوف إبقاء هذا دليل. دليل مؤقت تخزين و استبدال إبقاء إصدار تثبيت جهاز تراجع سلوك؛ أول مرة بدء إعداد ملف سجل دقيق تجهيز ما زال لا يخص تثبيت برنامج.

## Alternatives considered

**Electron تثبيت واجهة**سوف في تطبيق تثبيت قبل جذب دخول وقت التشغيل، و اشتراط مقدار خارج تثبيت عبر معلومة آلية. أصلي تحكم عنصر قدرة في قائم تثبيت برنامج داخل توفير الذي يحتاج تفاعل.

**استخدام خفيف كمية أصل نوع استبدال كامل NSIS نص برمجي**أيضا سوف استبدال ترقية، سجل التسجيل، إزالة و توقيع سلوك. أصل نوع أمر خدمة آلية حاجة مفرد وحيد إجراء إصدار تحقق، لا قبول دخول واجهة وصل دخول.

**استخدام نافذة منطقة مجال قطع قص دائرة زاوية**سوف منع استخدام DWM نافذة ظل أثر. نظام نافذة إطار هيكل إبقاء ظل أثر، معا قبول منصة توفير دائرة زاوية نصف مسار.

## Consequences

Windows تحزيم مقدار خارج اشتراط x86 Visual C++ تحرير ترجمة جهاز و Windows SDK. مساعد مساعدة مكتبة في تضمين دخول قبل استخدام و أخرى Windows ناتج نفسه توقيع جهاز توقيع. دقيق تجهيز خطاف في كل منصة إرجاع true، جعل electron-builder استلام تجميع إنتاج اعتماد. دليل تثبيت جهاز مسؤول مؤقت تخزين، استبدال، تسجيل و استعادة. ذلك حل ضغط خطاف عبر مستقل دخول درجة إدارة طريق و مفرد وحيد تشخيص ملف استدعاء قفل تحديد إصدار 7-Zip يمكن تنفيذ ملف. عملية فرعية فقط وراثة معيار تدفق جملة مقبض، و في إنشاء وقت إضافة دخول إغلاق أي إنهاء Job، لذلك إنهاء تثبيت برنامج أيضا سوف إيقاف حل ضغط. فقط لديه خروج رمز لـ صفر عندئذ سماح استبدال دليل. مساعد مساعدة مكتبة عبر إدارة طريق قراءة حد تحليل مئة قسم مقارنة، لا ذاتي سطر تنفيذ ضغط حزمة حل ضغط أو تمرير عودة نسخ. دقيق تجهيز، استبدال، تسجيل و تنظيف ما زال استخدام محدود تقدير حساب. مرحلة مقطع حق إعادة يمثل اكتمل عمل كمية، بينما غير باق بقية وقت. عرض دخول درجة لا رجوع، نص سجل تتبع مع عرض مرحلة مقطع.NSIS نجاح إشارة سماح تنفيذ 600 مللي ثانية تكملة ممتلئ حركة رسم و قصير مؤقت عرض 100%، تبديل هدف وقت طويل لـ 750 مللي ثانية؛ حساب وقت جهاز لا يستطيع إعلان إبلاغ نجاح. نافذة إطار هيكل في صنف لوحة تحكم عنصر دقيق تجهيز إتمام قبل إبقاء إخفاء، كما فقط ابتدائي تحويل مرة، صفحة تبديل إبقاء ذلك موضع. نقر إتمام بعد أولا إخفاء نافذة، مجددا بـ حالي مستخدم مباشر إنشاء قد تثبيت تطبيق عملية؛ صريح رفع حق تثبيت برنامج إبقاء عبر مستخدم طاولة وجه بدء طريقة. بدء فشل سوف استعادة إتمام صفحة. تطبيق بدء استهلاك وقت و تثبيت نافذة إغلاق قسم آخر معالجة.

أصلي تثبيت ارتداد بناء فقط إنجليزي نص و فقط العربية تغيير جسم، و من مرئي فرح استقبال صفحة حسب زر تعرف آخر لغة؛Windows تثبيت لغة لا قرار اختبار نص سجل. ترتيب تنفيذ اختبار استخدام مستقل منتج هوية و خاص تثبيت دليل، تحقق مسار رفض، ملف مشبك اختيار، بدء خيار، ترقية، تشغيل في عملية إبقاء، أصلي دخول درجة بند إخفاء، أول مرة عرض وقت حينئذ خيط و إزالة. نهاية ذيل حمل قسم فصل رمز قد تسجيل تسجيل مسار ما زال متاح في ترقية، مغناطيس قرص أصل دليل ما زال بلا فاعلية. تحديد صفة أصلي دخول درجة اختبار تغطية سريع سرعة و بطيء سرعة حل ضغط، توقف ركود، دخول درجة مصدر إعادة وضع، قسم قطعة دخول درجة نص، قصير مؤقت تنظيف، و اثنان مرة واجهة تحديث جديد بين نجاح حال حال. دليل اختبار عبر مساعد مساعدة مكتبة تنفيذ حل ضغط، تغطية طويل مسار، جديد تركيب، استبدال، ملف احتلال استخدام استعادة، مؤقت تخزين دليل ناقص، ضرر تالف ضغط حزمة و إلغاء. قطع رسم و مسبق مدة سلوك ملكية Desktop اختبار، لا وضع دخول تسجيل صنع Session لقطة. توقيع إصدار ما زال يحتاج استخدام قد إعداد إثبات كتاب،Token و حقيقي Windows تحديث ناتج إجراء تحقق.
