# Agent Note: متبادل مجاور Agent مشترك واحد Steer send_message عملية

Status: implemented

[English](2026-08-27-adjacent-agent-steer-messaging.md) | العربية

## مشكلة

يمكن متابعة Agent الأكثر أول استخدام جهة نحو مخصص تابع نموذج تحكم.parent استدعاء `send_message({ subagent_id, message })`، تفويض حمل إعطاء FIFO `followup` خدمة عملية.child فإن نيل نيل child أثر مجال `report({ output })` أداة،`tool:report` توجيه النظام section، و من نشر اختيار ساكن صامت أو نداء تنبيه إلقاء تمرير. اثنان عدد أداة استخدام مختلف schema، خدمة مسار، مصدر و ضبط درجة وصف نفس عدد متبادل مجاور Agent عملية.

يمكن متابعة child يملك ذاتي ذات Session، لذلك parent لن تلقائي استلام إلى child transcript(نص سجل) ، أداة إخراج أو دفع إدارة. إرجاع مسار يجب إبقاء صريح كما يمكن تكرار:child يمكن في انتهاء قبل إرسال دخول درجة، إرسال بعد ما زال إبقاء متاح، أيضا ممكن في قدوم نيل و إعداد دمج قبل فشل. يأخذ كل بند نهائي assistant رسالة تغيير صار خفي صيغة نتيجة سوف خلط خلط جولة إتمام و نموذج اختيار عبر معلومة، بينما كما لا يمكن تغطية استثناء انتهاء.

child مخصص تابع أداة و توجيه النظام section أيضا يقع في كل وراثة fork جولة قبل. هو جمع يجعل يمكن متابعة fork child طلب رأس في fork غاية في إعادة استخدام تاريخ قبل حينئذ و parent مختلف، إجبار جعل مزود إعادة مسبق ملء ملء كامل نسخة نسخ transcript.

## قرار

`SubagentRuntime.sendMessage(sender, targetId, content, { signal })` هو وحيد عام نموذج تحرير كتابة رسالة عملية. متابعة تنفيذ إدارة جهاز فقط قبول تأكيد قطع في خط sender و واحد بند متبادل مجاور حافة فوق هدف:

- parent إلى مباشر يمكن متابعة child، من child حفظ دائم `SessionHeader.parentSession` تخويل؛
- إقامة إبقاء يمكن متابعة child إلى ذلك تأكيد قطع في خط مباشر parent، من child Activation تخويل.

sibling، ذاته هدف، تجاوز مرور واحد بند حافة ancestor، قديم قديم Agent كائن، لم معرفة هدف و مرة صفة child كل لا هو بديل توجيه. هذا عملية لا يوجد استدعاء جهة توفير source، إلقاء تمرير نمط، مغادرة خط parent mailbox أو مزود توزيع.

كل بند يتم قبول رسالة كل استخدام `Agent.steer()`. تشغيل في هدف في الأكثر قريب step حد استقبال رسالة؛ فارغ خامل هدف بدء جولة. ناقص مباشر child سوف أولا عبر قائم متابعة تنفيذ دورة الحياة بارد استعادة، مجددا قبول نفس Steer إلقاء تمرير. إدارة جهاز إبقاء نداء تنبيه إرسال تسجيل حساب، لذلك تلقي متابعة تنفيذ إدارة هدف لن في تزامن inbox إدراج دخول و driver دقيق دخول بين تسوية.

اثنان عدد جهة نحو استخدام نفس نوع حمل دائم مصدر. خدمة من قد تخويل Agent دفع توجيه `senderSessionId`، و يأخذ نموذج مرئي محتوى تجميع لـ `Agent <sender-id> sent a message:`، لذلك مصدر معلومة لن انحراف مغادرة إذن.

```ts
import type { SessionId } from '@deepseek-ai/dsh-session'

interface AgentMessageSource {
  readonly kind: 'agent-message'
  readonly form: 'relay'
  readonly senderSessionId: SessionId
}
```

### واحد نموذج أداة و واحد بند إرجاع إشارة أمر

عام تسجيل نموذج أداة و جهة نحو غير متصل، و استخدام واحد ثابت schema:

```ts
interface SendMessageInput {
  readonly agent_id: string
  readonly message: string
}
```

parent و child بـ نفسه سجل التسجيل ترتيب وراثة نفسه تعريف. معيار تعريف يحمل عملية مستقر داخلي هوية، نفس اسم أثر مجال أداة لا ممتلئ كاف هذا هوية.child `toolFilter` يمكن صريح إزالة وراثة أداة، أثر مجال بديل أداة أيضا يمكن توفير مختلف دلالة؛ اثنان نوع حال حال كل لن استلام إلى معيار استدعاء إشارة أمر. عند معيار أداة ما زال مرئي وقت، متابعة تنفيذ إدارة جهاز سوف يأخذ مرور مرور JSON تحرير رمز مباشر parent id، انتهاء قبل إرسال واحد نسخة ذاتي يتضمن نتيجة إشارة أمر، و أكثر مبكر إرسال يمكن عملية اكتشاف إشارة أمر إلحاق إلى child ابتدائي مستخدم مهمة. مقابل fork child بينما قول، هذا مهمة يقع في وراثة اكتمل جولة بادئة بعد؛ لا يوجد child مخصص تابع توجيه النظام section أو أداة schema يقع في هذا بادئة قبل.

هذا إشارة أمر هو إشارة توجيه، لا هو تسوية قوي صنع. إرسال لن انتهاء child جولة، آلية ما زال سماح صفر مرة أو كثير مرة استدعاء،runtime أبدا سوف بسبب child إبقاء غرق صامت بينما رفض هو. من إدارة جهاز مسؤول `subagent-settled` إشعار ما زال بلا شرط إرسال و اعتماد مستقل مصدر، لأن هو سجل Activation مثل أي انتهاء، و في child لا يمكن إعداد دمج وقت إبقاء نهاية حالة إخراج.

متصفح في شخص صنف تلميح لا هو نموذج تحرير كتابة Agent رسالة. بعيد مسار تلميح مسار إبقاء خاص Queue إلقاء تمرير، جعل كل بند شخص صنف تلميح إبقاء لـ مستقل جولة. في قطع سلوك و تسوية إلقاء تمرير إبقاء مستقل.

### كامل إزالة و إعادة جذب دخول شرط

مستقل `@deepseek-ai/dsh-tool-subagent-report` حزمة،`report` schema،`tool:report` نص التوجيه section،`reportDelivery` إعداد،report مخصص تابع رسالة مصدر، دليل بند، تركيب سطر و تلقي دعم حمل سلوك لقطة متساو قد لا وجود. موحد واحد أداة وضع ترك بلا حاجة استقبال جهة child سريع سريع طريقة، أيضا وضع ترك يجعل بنية صفة إرجاع أداة التفاف مرور صريح child allow-list قديم قدرة. فقط لديه أداة جسم حالة استخدام حاجة متبادل مجاور `agent_id` و ثابت Steer لا يمكن جدول بلوغ دلالة وقت، هذه قدرة عندئذ سوف إعادة ظهور؛ إعادة جذب دخول حاجة مستقل نموذج عملية و بادئة صار هذا دليل، بينما غير `sendMessage()` لـ فوق آخر اسم.

## اعتبار مرور بديل خطة

**إبقاء `followup` و إضافة child إلى parent توجيه.** هذا اسم تحمل وعد لاحق جولة و وراثة `Agent.followup()` دلالة. هو سوف إخفاء غطاء اختيار تحديد الأكثر قريب step سلوك، و لـ جهة نحو غير متصل قدرة إبقاء بـ parent لـ في قلب اسم.

**إبقاء `sendMessage()` لـ فوق بلا حاجة استقبال جهة `report` حزمة تركيب طبقة.** هذا سوف إبقاء سهل فائدة child سريع سريع طريقة، و يجعل أثر مجال نطاق جزء تسجيل التفاف مرور عام أداة مرور ترشيح. هو سقوط اختيار هو لأن مستقل schema و نص التوجيه تكرار واحد عملية، جعل parent و child طلب رأس مختلف، و سماح انتظار قيمة جهة نحو مجددا مرة عائم نقل.

**يجعل `report` عام مرئي.** أصل Agent، مرة صفة child، بعيد مسار child و بلا Agent استدعاء جهة لا يمكن دفع توجيه report استقبال جهة. عام إعلان نقل هو سوف يجعل schema مرئي صفة و إذن لا متسق، بينما `send_message` قد صريح إعطاء خروج استقبال جهة.

**يأخذ كل بند child نهائي رسالة تغيير صار خفي صيغة إرسال.** طويل مدة تشغيل child ممكن في بعض عدد جولة لا يوجد قيمة نيل إرسال محتوى، في آخر عدد جولة لكن لديه كثير بند اكتشاف. تلقائي إلقاء تمرير سوف خلط دمج نموذج تحرير كتابة عبر معلومة و runtime تسوية شرح، بينما كما لا يمكن بديل خطأ، إلغاء أو token استهلاك كل وقت بلا شرط إشعار.

**فقط اعتماد أداة وصف.** أداة وصف سوف في نموذج اعتبار هذا أداة بعد توفير مساعدة؛ فشل نمط هو child إقرار لـ ذاتي ذات اكتمل بينما أصل هذا لا يوجد اعتبار إرجاع استدعاء. ابتدائي مهمة إشارة توجيه قدرة لمس و هذا قرار، أيضا لن تغيير وراثة نظام أو أداة بادئة.

**إبقاء ساكن صامت إلقاء تمرير بصفة نشر سياسة.** ساكن صامت نموذج تحرير كتابة رسالة ممكن يتم قبول، لكن فارغ خامل هدف دائم بعيد لن قراءة هو. ثابت Steer لـ اثنان عدد جهة نحو توفير واحد نوع إلقاء تمرير يحتوي معنى، و إبقاء و لاحق تسوية إشعار قبول ترتيب.

## عاقبة

- نموذج Consumer نحو parent و child عام واحد `send_message({ agent_id, message })` تعريف، لا توفير نموذج اختيار Queue و Steer معامل.
- متابعة تنفيذ إدارة جهاز ما زال هو متبادل مجاور علاقة تخويل، إقامة إبقاء، بارد استعادة، نداء تنبيه دقيق دخول و تفكيك إزالة تنافس حالة وحيد كل من.
- يتم قبول رسالة يمكن تأخير طويل تشغيل في هدف حالي جولة؛ واحد بدء انتظار رسالة مشترك next-step FIFO ترتيب.
- استدعاء جهة إلغاء فقط في inbox قبول قبل كف إدارة عمل، لن سحب عودة قد قبول رسالة أو dispose(مورد تحرير) هدف.
- ابتدائي مهمة في fork بادئة بعد يحمل مرور مرور JSON تحرير رمز حركة حالة parent عنوان، بينما طلب رأس توجيه النظام و أداة ترتيب إبقاء يمكن إعادة استخدام.
- شخص صنف تلميح، تسوية إشعار،QueueDock و base bundle مرة صفة fork سياسة ما زال هو مستقل قرار.

هذا قرار دمج و حذف قد تماما يتم يحل محل report أداة و child report معنى خدمة سجل. هو يحل محل[حسب معنى رسم تسمية subagent متابعة تنفيذ عملية](../../archived/simplification/2026-07-27-intent-named-subagent-continuation-operations.md) في `followup` تسمية اختيار، و إبقاء[Child Agent رسالة أولا في ذلك تسوية إشعار](../bug-fix/2026-08-17-subagent-message-settlement-ordering.ar.md) في قبول ترتيب حفظ إثبات.
