# Agent Note: Show the Desktop window before starting the Host

Status: implemented

[English](2026-09-09-desktop-immediate-window-and-direct-start.md) | العربية

إضافة إدارة و أصلي استعادة التزام دوران[مشترك Web رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md).

## مشكلة

انتظار خلفية حينئذ خيط سوف يجعل مستخدم في دقيق تجهيز profile و تحميل وحدة خلال نظر لا إلى نافذة. كامل staging سليم سليم فحص عملية سوف في تطبيق بدء خدمة عملية قبل تكرار بدء خلفية، بينما إضافة في فعلي خدمة عملية في ما زال ممكن بدء فشل.

## قرار

Electron في profile تدقيق دقيق أو Host بدء قبل إنشاء حمل تحزيم Web تحميل صفحة رئيسي نافذة.Web مدخل أولا عرض بدء صفحة، مجددا انتظار Host حينئذ خيط. ذاتي لديه preload تسليم بنية تحويل بدء حقن، قائم وثيقة تطبيق حقن بعد تنشيط عميل إضافة؛ بدء فشل وقت عرض تشخيص و متاح استعادة عملية. تحميل خلال إغلاق نافذة سوف إلغاء لاحق بدء عمل، و انتظار جارٍ بدء عملية فرعية خروج.

يؤدي أمر خطأ عرض التزام دوران[أصلي Desktop استعادة](2026-09-15-desktop-native-fatal-recovery.ar.md). نافذة عرض وقت آلة، مباشر بدء Host و إغلاق كل حق ما زال من هذا نص قاعدة تحديد.

Desktop أصل موضع دقيق تجهيز profile بعد، عبر[مشترك Web runner](2026-09-10-desktop-web-wrapper.ar.md) بدء فعلي Host. حينئذ خيط معلومة توفير إقرار إثبات بعد Host URL و بدء حقن. طاولة وجه قشرة استخدام هذا URL تبديل أخذ Host cookie، تحويل إرسال تطبيق HTTP طلب، و فقط لـ الذي تابع تطبيق مصدر إقرار إثبات مباشر WebSocket طلب. هذا تحمل تحميل ملائم إعداد إبقاء Web توجيه و تدفق دلالة، معا سماح ساكن حالة HTML في Host حينئذ خيط قبل عرض.

هذا قرار جزء يحل محل[تحزيم قرار](2026-08-25-electron-desktop-packaging-and-updates.ar.md) و[داخل وضع وقت التشغيل قرار](2026-09-08-desktop-bundled-runtime-and-external-plugins.ar.md) في staging خلفية استكشاف إبرة و تأخير متأخر إنشاء رئيسي نافذة. هذا اثنان نسخة سجل ما زال إبقاء إصدار، توقيع، نقل و مورد ملكية إدارة من. كامل وقت التشغيل ملف تحقق ما زال يخص تحزيم عملية.

## اعتبار مرور بديل خطة

**إبقاء كامل staging سليم سليم فحص.** هو يمكن في تنشيط قبل رفض جزء بدء فشل، لكن سوف تنفيذ اثنان مرة إضافة ابتدائي تحويل، أيضا لا يستطيع حفظ إثبات خدمة عملية قدرة كاف بدء. فعلي Host نتيجة توفير صريح استعادة الذي يحتاج تشخيص.

**في حينئذ خيط قبل إخفاء رئيسي نافذة.** هذا تجنب تجنب عرض تحميل صفحة، لكن خلفية تحميل خلال مستخدم نظر لا إلى دخول درجة، أيضا لا يمكن تفاعل. قشرة يملك صفحة يمكن في Host بدء فشل وقت متابعة استخدام.

## عاقبة

مستخدم يمكن في منتج UI متاح قبل يرى بدء دخول درجة و من فشل في استعادة. نافذة قدرة كاف استجابة لا بديل جدول خلفية قد حينئذ خيط، بدء تأخير متأخر ما زال يحتاج عبر قد تثبيت ناتج قياس كمية. تنشيط فشل بعد،profile تعديل إبقاء في أصل موضع.

تحقق تغطية Host تأخير متأخر وقت مرئي تحميل صفحة، جديد profile فقط بدء مرة خدمة، نفس نافذة في فشل و إعادة محاولة، أصلي استعادة، و عملية فرعية بدء وقت إغلاق. تثبيت بعد GUI دليل تكملة ملء دورة الحياة اختبار.
