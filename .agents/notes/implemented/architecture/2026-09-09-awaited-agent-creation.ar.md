# Agent Note: يمكن انتظار مفرد عدد agent ابتدائي تحويل

Status: implemented

[English](2026-09-09-awaited-agent-creation.md) | العربية

## مشكلة

مشترك preset لـ كل Agent(ذكي جسم) قسم آخر تثبيت أداة و نص التوجيه مقطع. تثبيت ممكن يلزم انتظار إضافة تنشيط، خارجي SessionStart خطاف أيضا ممكن مختلف خطوة إنتاج سياق. إنشاء جهة يجب معرفة طريق هذه مساهمة اكتمل، عندئذ قدرة سماح Agent إرسال بدء أول مرة نموذج طلب.

## قرار

`agent/created` هو عمل مصنع setup إتمام كما دخول سجل التسجيل بعد سلسلة سطر ابتدائي تحويل حدث. كل مستمع إتمام بعد عندئذ بدء تحت واحد؛ رمي خروج أو رفض سوف جعل إنشاء فشل، و قفز مرور لاحق مستمع. تحميل حمل إبقاء `SessionStartSource`، و قبول عمل مصنع إلغاء إشارة. استدعاء جهة انتظار `register()` و `announce()` إتمام. دورة الحياة مصدر من عمل مصنع إصدار وقت عبر `announce()` إشارة تحديد؛`register()` إعلان إبلاغ كل جديد بدء.

AgentLoop في setup و إنشاء توزيع خلال إبقاء قائم صيانة نشط حركة. ابتدائي تحويل خلال إدخال يمكن دخول استلام عنصر صندوق، لكن فقط لديه نجاح إتمام بعد مشغل عندئذ سوف بدء. فشل سوف إلغاء هذا نشط حركة بينما لا نداء تنبيه قد ترتيب طابور إدخال؛ لديه ترتيب teardown يملك استلام عنصر صندوق تنظيف. منطقة قسم هذا اثنان بند عملية، قدرة كاف في آخر بند teardown قد إزالة استلام عنصر صندوق إسقاط وقت إبقاء ابتدائي تحويل خطأ.

إنشاء توزيع في مستمع انتظار خلال إبقاء أثر مجال و Session.Dispose(مورد تحرير) سوف إلغاء ابتدائي تحويل، و في تحرير هذه مورد قبل انتظار توزيع انتهاء. مستمع لا نيل انتظار ذاته Agent فارغ خامل حالة أو ذاته كل من dispose، لأن اثنان من كل يلزم انتظار هذا مستمع إتمام. آخر عدد Agent فوق خلفية عمل التزام دوران هذا Agent ذاتي ذات ابتدائي تحويل دورة الحياة.

هذا قرار يملك مختلف خطوة إنشاء وقت ترتيب.[أثر مجال وقت التشغيل قرار](2026-07-12-agent-scope-runtime-design.ar.md) متابعة يملك سجل التسجيل هوية و teardown ملكية،[اعتراض قطع قرار](../feature/2026-06-30-interception-extension-points.ar.md) متابعة يملك سياسة و أداة حدث دلالة.

## اعتبار مرور بديل خطة

**مفرد وحيد setup حدث.** قائم إنشاء مستمع قد تثبيت إبرة مقابل مفرد عدد agent مساهمة. ثاني عدد ابتدائي تحويل حدث سوف تفكيك قسم هذا واحد مسؤولية، لكن لا يوجد مستقل مستهلك يحتاج طلب.

**قسم مغادرة تشغيل ابتدائي تحويل.** في إضافة تنشيط أو خطاف سياق تسوية قبل إرجاع، سوف يجعل أول مرة طلب نقص قليل الذي يحتاج أداة أو سياق، أيضا سوف جعل ابتدائي تحويل فشل انفصال مغادرة إنشاء جهة.

## عاقبة

إنشاء تأخير متأخر يشمل مختلف خطوة إضافة و SessionStart عمل. ابتدائي تحويل جهاز فشل يصبح استدعاء جهة مرئي إنشاء فشل، إلغاء اعتماد مستمع تنسيق عمل تسوية. قد إرسال بلوغ إشعار لا يمكن سحب عودة؛ تراجع سوف لـ ذلك إعداد مقابل إلغاء تدمير إشعار.

أثر مجال تثبيت جهاز اختبار تحقق تراجع، دورة الحياة اختبار تحقق لديه ترتيب إتمام و إلغاء،SDK serial-created مشهد تحقق مختلف خطوة نص التوجيه سياق دخول أول مرة طلب. خطاف اختبار تغطية يحتاج انتظار سياق حقن و عملية فرعية dispose.
