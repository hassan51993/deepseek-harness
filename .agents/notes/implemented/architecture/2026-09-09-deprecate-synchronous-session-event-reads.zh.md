# Agent Note: ترك استخدام مقابل جلسة مهمة معنى موضع حدث تزامن قراءة

Status: implemented

[English](2026-09-09-deprecate-synchronous-session-event-reads.md) | العربية

## مشكلة

تزامن وصول مهمة معنى حدث موضع، جعل مستهلك اعتماد كامل جلسة حدث تسلسل في داخل تخزين في مع وقت متاح. تخزين عرض دخول جهة نحو هو لم يعد سوف كامل تسلسل حفظ في داخل تخزين في. تاريخ حدث واحد حالما حاجة تخزين I/O، وقت التشغيل إذا لا متابعة إبقاء تاريخ أو منع سد انتظار تخزين، حينئذ لا يمكن صيانة حمل نفسه تزامن قراءة حفظ إثبات.

أي جعل فقط قراءة واحد قديم حدث، إضافة جديدة استدعاء أيضا سوف إضافة عميق هذا نوع اعتماد. استعادة بعد عكس تكرار مسح تاريخ، أيضا سوف جعل عادي مجال منطق اعتماد تاريخ تخزين، بينما لا هو هو حق صحيح حاجة حالة.

## قرار

ترك استخدام كل تزامن قراءة جلسة حدث تاريخ مهمة معنى موضع أو منطقة بين عملية، يشمل `Session.eventAt()`،`Session.snapshotEvents()` و `Session.ownEvents()`. قائم منطق يمكن مؤقت لا ترحيل، لكن منع توقف إضافة جديدة استدعاء. نفس مثال منع توقف إضافة جديدة كشف نفسه تزامن تاريخ وصول قدرة آخر اسم أو حزمة تركيب طبقة.

هذا ثلاثة عدد طريقة عبر `@deprecated` JSDoc إعلان هذا قاعدة. هذا هو API استخدام قرار؛ حالي Session تنفيذ ما زال في داخل تخزين في إبقاء كامل حدث تسلسل.

مستودع اختبار ملف (يشمل `scripts/**/*.spec.{ts,tsx}`) يمكن استدعاء هذا ثلاثة عدد قراءة طريقة، بـ فحص قد إرسال خروج حدث و تحقق Session تاريخ سلوك. اختبار ملف lint override سماح `snapshotEvents`،`eventAt` و `ownEvents`، أخرى ترك استخدام اسم ما زال تقرير خطأ. في حالي linter تحت، هذا إعفاء تجنب أيضا تغطية استخدام هذا ثلاثة عدد اسم أخرى إعلان. هو لا ملائم لأجل إنتاج شفرة المصدر أو غير اختبار مستودع نص برمجي.

### استعادة بعد حاجة حالة

ربط دمج تصميم حمل دائم حدث حقل و جلسة إسقاط، جعل كل مجال كل قدرة إعادة بناء ذلك مستهلك الذي يحتاج حالة. في استعادة خلال أيضا أصل هذه حالة، مع بعد عبر جديد إيداع حدث زيادة كمية صيانة. استعادة بعد، عادي منطق قراءة إسقاط أو معالجة حالي استلام إلى حدث، بينما لا هو عودة رأس فحص بحث تاريخ حدث. تزامن قراءة قد صيانة جيد إسقاط حالة، لا حاجة مهمة معنى وصول حدث سجل.

حسب يحتاج عرض تاريخ محتوى اعتماد صريح مختلف خطوة قسم صفحة و تدريجي دخول صيغة تحميل، كل مرة قراءة حد في طلب نافذة داخل. في تزامن مساعد مساعدة طريقة خلف بعد تحميل كامل تسلسل، ما زال إبقاء هذا قرار يلزم إزالة حذف اعتماد.

### تأكيد فعلي حاجة كامل تاريخ عملية

fork انتظار قليل عدد عملية ممكن تأكيد فعلي حاجة كامل تاريخ تسلسل أو وراثة بادئة. هو جمع مقابل هذه سجل يحتاج طلب ما زال صار قيام، حاجة عبر صريح تخزين قراءة قدوم ممتلئ كاف. هذا لا اشتراط كامل تسلسل معتاد إقامة داخل تخزين، أيضا لا بنية صار إضافة جديدة قد ترك استخدام تزامن قراءة استدعاء مثال خارج. كل هذا صنف مستهلك كل يجب شرح، لـ ماذا ذلك نتيجة حاجة كامل تسلسل، بينما لا يستطيع فقط استخدام إسقاط حالة أو نطاق جزء تاريخ نافذة.

## سبق اعتبار بديل خطة

**فقط ترك استخدام كامل لقطة، إبقاء تزامن مفرد حدث قراءة.** مفرد عدد يتم طلب حدث أيضا ممكن لا في داخل تخزين في. حد إرجاع نتيجة كبير صغير و لا يستطيع إزالة حذف تخزين اعتماد،`ownEvents()` انتظار مساعد مساعدة طريقة مقابل بعد لاحقة تسلسل أيضا إبقاء حال نفسه زائف ضبط.

**لـ إبقاء قراءة API بينما يجعل كامل تسلسل معتاد إقامة داخل تخزين.** هذا سوف يجعل مستهلك سهل فائدة صفة قرار جلسة داخل تخزين إبقاء طريقة، منع عائق مسبق مدة تخزين تصميم. إسقاط إبقاء الذي يحتاج حالة، صريح تاريخ قراءة فإن إبقاء مقابل سجل ذاته وصول قدرة.

**اشتراط قيام أي ترحيل كل قائم استدعاء جهة.** هذا قرار سماح قائم منطق دفع متأخر ترحيل. منع توقف إضافة جديدة اعتماد يمكن حد باق بقية عمل قاعدة نموذج، بلا حاجة سوف كل قائم مستهلك كل قبول دخول نفس مرة تعديل.

**في كامل اختبار ملف في منع استخدام ترك استخدام lint، أو حسب اسم إعفاء تجنب إنتاج شفرة في قراءة طريقة.** اختبار فقط حاجة هذا ثلاثة عدد قراءة طريقة اسم؛ أخرى ترك استخدام API يجب متابعة تقرير خطأ. إنتاج شفرة ما زال منع توقف إضافة جديدة تزامن قراءة.

**إضافة مفرد وحيد اختبار مخصص استخدام قراءة API.** ثلاثة عدد قائم قراءة طريقة قد توفير هذه اختبار الذي يحتاج مراقبة نتيجة. حزمة تركيب هو جمع سوف زيادة واحد API و إنتاج شفرة استيراد فحص، لكن لن تغيير هذه مراقبة نتيجة.

## عاقبة

إضافة جديدة مجال سلوك يجب جعل ذلك حدث بيانات و إسقاط حالة كاف بـ دعم حمل استعادة بعد تنفيذ. مستخدم طلب تاريخ ما زال يمكن تدريجي دخول صيغة تحميل، تأكيد فعلي حاجة كامل تاريخ عملية ما زال يحتاج تصميم تخزين قراءة مسار. هذا قرار لا يمثل استعادة أو fork قد قدرة كاف تجنب تجنب تحميل كامل سجل.

اختبار ملف خارج استدعاء حمل لديه تدريجي سطر `typescript/no-deprecated` إعفاء تجنب، شرح مؤقت مؤقت ترحيل أو قد ترك استخدام قراءة طريقة بين تفويض حمل. حذف قد ترك استخدام استدعاء وقت ينبغي واحد و حذف ذلك إعفاء تجنب؛ سوف إعفاء تجنب نسخ إلى إضافة جديدة إنتاج استدعاء مخالفة عكس هذا سياسة. فعلي تنفيذ lint فحص سماح اختبار قراءة و قد لديه إعفاء تجنب استدعاء، رفض لم إعفاء تجنب إنتاج قراءة، و رفض اختبار في أخرى قد ترك استخدام API. وثيقة فحص تحقق و شفرة المصدر متسق API إعلان و مزدوج لغة سجل.
