# Agent Note: Client Session مرجع، مرجع مصدر و UI حالة

Status: implemented

[English](2026-09-15-client-session-references.md) | العربية

## مشكلة

Session دليل، نشط وثب Client كائن، عرض و مختلف خطوة عملية أداة لديه مختلف دورة الحياة. دليل عضو علاقة لا يستطيع إثبات ما زال في استخدام. استعارة استخدام binding لا يمكن حفظ حماية مختلف خطوة عمل، أيضا لا يمكن منطقة قسم نفس Session ID مختلف Client بديل. عام current Session سوف جعل مستقل ربط مكون عملية آخر عدد عرض Session.

مرجع حساب عدد قدرة جدول واضح ما زال في استخدام، لكن لا يستطيع تعرف آخر استخدام جهة. رئيسي منطقة مجال عال مضيء،Sidebar كل حق و خلفية عملية حاجة استخدام جهة مصدر معلومة. انتظار معالجة تفاعل و إتمام رفع تنبيه أيضا حاجة موحد واحد UI قراءة واجهة، تجنب تجنب Workspace و Conversation كل منها تركيب نفسه حالة.

Client تاريخ وصول و Host Agent(ذكي جسم) تنفيذ أداة لديه مستقل دورة الحياة. تاريخ فتح ممكن فشل؛ نيل أخذ محلي Context لا واحد تحديد حاجة قراءة تاريخ. صريح كل حق يجب إبقاء تنقل، تحميل، خطأ معالجة و استعادة سلوك، لا إضافة غير متصل UI سياسة.

## قرار

### نطاق و كل حق

Client Session كائن،Agent أثر مجال Client Context، مرجع، استخدام جهة مصدر بيانات وصفية،UI حالة و صريح Provider تركيب التزام دوران تحت وصف كل حق قاعدة.Host Session و Agent دورة الحياة،SlotFactory،activity قائمة عرض، حمل دائم Session صيغة و اثنان عدد SDK Host بروتوكول إبقاء مستقل.

| كل من | مسؤولية |
| --- | --- |
| Client Session Controller | دليل، نشط وثب بديل، مرجع، مصدر حساب عدد،binding، تاريخ نافذة و قائم Session تحكم حالة |
| `ui-session` | صريح Session Provider تجميع صار و موحد واحد UI حالة مصدر |
| عرض أو عملية | ذاتي ذات مرجع، هدف، مصدر معرف و تحرير وقت آلة |
| Workspace UI | رئيسي منطقة مجال هدف و مرجع، تنقل، حمل دائم هدف و إنشاء مسار |
| UI تركيب حد | سوف كل من توفير مرجع تسليم إعطاء واحد واضح `SessionProvider` |
| Conversation و Sidebar فرعي شجرة | فقط إزالة استهلاك الذي في Provider Session، لا قراءة رئيسي منطقة مجال مرجع أو عام اختيار |
| Client Gateway | معالجة Host حدث وقت استدعاء مدة Context كل حق |

[Client قسم طبقة تصميم](../../implemented/architecture/2026-08-20-client-session-conversation-ownership.ar.md) تعريف بيانات، مهايئ، مصير و عرض طبقة مفرد نحو اعتماد. مرجع مصدر موحد حساب لن جعل Controller اعتماد UI حزمة.

هذا قرار جزء يحل محل [Web Client Session scope و provide channel قرار](2026-07-25-web-client-session-scope-and-provide-channel.ar.md) في من list اختيار قيادة scope دورة الحياة؛ بعد من إبقاء صريح Provider كل حق تحت blank Session و استلام رعاية دلالة إدارة من.

### عنوان،binding و مرجع

`SessionTarget` هو معروف `SessionId` أو حمل دائم مباشر أب فرعي `SubagentAddress`. هو معرف يلزم نيل أخذ هدف، لا يحتفظ أي كائن.Controller تحليل صريح عنوان وقت لا اشتراط مسبق أولا تحميل parent catalog،Host فإن في فتح تاريخ وقت تحقق ذلك parent،child و mode. فرعي جلسة اكتشاف و معروف فرعي جلسة عنوان متساو لا انتظار نفس في يحتفظ هذا فرعي جلسة. تنقل استخدام نفس نوع هدف يمثل، لا زيادة آخر طقم تنقل عنوان.

`SessionBinding` هو مشترك Client بديل، يتضمن `sessionId`،Session واجهة، حدث مصدر و أثر مجال Context. نفس نشط وثب بديل كثير عدد مرجع مشترك هذا عدد binding. نفس ID جديد واحد بديل أداة لديه مختلف binding و Context.

`SessionReference` يحتفظ بعض عدد تأكيد قطع بديل مرة استخدام. هو عام فقط قراءة `sessionId` و `binding`، يمثل مشترك أول مرة تاريخ فتح `ready` Promise، و قوة انتظار `release()` و `Symbol.dispose`. مقابل `Session.open()` محاولة تجربة تحليل وقت،`ready` تحليل لـ هذا تأكيد قطع binding، يشمل بـ حالة يمثل Remote failure نتيجة. مرجع تحرير أو ذلك بديل تنظيف بعد، قراءة `binding` سوف فشل. نيل أخذ، تحرير أو فحص نظر مرجع متساو لا إنشاء حمل دائم Session، أيضا لا بدء، إيقاف أو يحتفظ Host Agent.

`SessionBinding` هو استعارة استخدام قيمة، لا بنية صار يحتفظ. فقط لديه لم تحرير `SessionReference` حساب دخول مصدر و مجموع مرجع عدد. تزامن شفرة يمكن في يملك من مرجع دورة الحياة داخل استعارة استخدام binding؛ حاجة تجاوز مرور هذا دورة الحياة عمل يجب يملك ذاتي ذات مرجع.

| API | إرجاع نتيجة و استدعاء جهة معنى خدمة |
| --- | --- |
| `sessions.retain(target, options)` | `SessionReference`؛ قيام أي إرجاع، استدعاء جهة يحتفظ هذا مرجع مباشر إلى تحرير |
| `sessions.using<T>(target, options, operation)` | `Promise<T>`؛ اعتماد مرة انتظار `reference.ready` و `operation(reference)`، تحرير ذاتي ذات مرجع، و إرجاع عملية نتيجة |
| `sessions.retainInfo(id)` | محلي مرجع حساب عدد مستقر فقط قراءة observable، لا نيل أخذ مرجع، لا إنشاء أثر مجال، أيضا لا تنفيذ تاريخ I/O |
| `sessions.scope(id)` / `sessions.binding(id)` | استعارة استخدام قد وجود نشط وثب بديل أو إرجاع `undefined`، لا فتح هو، أيضا لا تأخير طويل ذلك دورة الحياة |
| `sessions.sessionOf(ctx)` | إرجاع مطابقة نشط وثب Session واجهة أو `undefined`؛ قد انتهاء Context لا يستطيع تحليل لـ نفس ID بديل بديل |
| `sessions.create(...)` / `sessions.fork(...)` | قائم Host عملية، إرجاع Session هوية؛ يحتفظ و عرض ما زال يحتاج صريح تنفيذ |

`SessionRetainOptions` يتضمن لا بد ملء `source: SessionReferenceSource` و اختياري `signal: AbortSignal`. اثنان عدد نيل أخذ طريقة متساو قبول `target: SessionTarget` و هذه options. مصدر مفتاح من استخدام جهة تعريف، عبر إعلان دمج توسيع؛ لا توفير وقت التشغيل مصدر تسجيل بروتوكول، أيضا لا افتراضي استخدام رئيسي عرض مصدر. مصدر هو استخدام وسم، لا هو آخر نوع Session عنوان، أيضا لا منح إعطاء عملية إذن.

### نيل أخذ، فشل و تحرير

نيل أخذ عملية تزامن تحليل هدف، إنشاء أو يحتفظ محلي Session،Context،fiber و binding، سجل واحد نسخة مرجع و ذلك مصدر حساب عدد، بدء هذا بديل مشترك أول مرة تاريخ فتح، لكن بعد إرجاع مرجع. تزامن نيل أخذ مشترك هذا مرة فتح، لكن قسم آخر نيل نيل مستقل مرجع و حينئذ خيط انتظار. مشترك `Session.open()` محاولة تجربة تحليل وقت،`reference.ready` تحليل لـ ما زال صالح تأكيد قطع binding.

لم معرفة Session id بحث عنوان في إرجاع مرجع قبل فشل؛ صريح subagent عنوان من Host في فتح خلال تحقق. رمي خروج فتح فشل، استدعاء جهة إلغاء، مرجع تحرير أو هذا بديل انتهاء سوف رفض هذا مرجع `ready`؛ إلغاء واحد انتظار جهة لن إلغاء أخرى كل من مشترك فتح عملية. بـ `openState: 'error'` يمثل Remote failure تتبع مع `Session.open()` دلالة و تحليل حينئذ خيط، خطأ ما زال يمكن عبر binding تصيير. استدعاء جهة يحتفظ قد إرجاع مرجع مباشر إلى تحرير، بينما `sessions.using` سوف في حينئذ خيط أو عملية فشل وقت تحرير ذاتي ذات مرجع.

`using reference = sessions.retain(target, options)` في الذي في أثر مجال خروج وقت تحرير؛ حاجة انتظار أول مرة تاريخ محاولة تجربة تسوية شفرة انتظار `reference.ready`.`sessions.using` هو موجه إلى عودة ضبط استدعاء جهة مساعد مساعدة طريقة: هو أولا انتظار هذا مرة تسوية، مجددا استدعاء عملية و انتظار عملية إرجاع عادي قيمة أو Promise، الأكثر بعد تحرير. قيمة راجعة لا يستطيع اعتماد مساعد مساعدة طريقة قد تحرير مرجع ما زال يمكن استخدام؛ حاجة أكثر طويل دورة الحياة استخدام جهة ذاتي سطر نيل أخذ مرجع. مساعد مساعدة طريقة نقل بث يتم رفض حينئذ خيط و عملية فشل، لا توفير التقاط قاع نتيجة، إعادة محاولة أو خطأ عرض. نموذج اختيار بديل حد فحص و خطأ حالة تحديث إبقاء في ModelSelection.

`ready` Promise نجاح يمثل أول مرة `Session.open()` محاولة تجربة قد تسوية؛ هو لا حفظ إثبات `openState: 'open'`، أيضا لا حفظ إثبات اتصال دائم لا في قطع. بـ حالة يمثل فتح فشل و بعد تدفق فشل متابعة عبر قائم Session حالة عام. استدعاء جهة إبقاء مقابل هذه خطأ قائم معالجة و عرض.

تحرير فقط إزالة هذا مرجع و ذلك مصدر حساب عدد. الأكثر بعد تحرير في تنظيف Session و fiber قبل سحب عودة هذا بديل دقيق دخول و ID خريطة. لاحق retain يمكن قيام أي إنشاء جديد واحد بديل؛ قديم بديل تنظيف لا يستطيع إزالة بديل بديل.`release()` تزامن إرسال بدء محلي تنظيف، أصل تنظيف انتظار بعد لم انتهاء مختلف خطوة تحرير عمل.

الذي تابع Client أصل في إغلاق وقت جعل الكل مرجع بطلان. هو رفض جديد نيل أخذ، سحب عودة نشط وثب خريطة، و تجميع دمج أثر مجال تنظيف و Session تدفق تحرير. مرجع لا يستطيع جعل قد تنظيف Client أصل متابعة تخزين نشط. فقط إزالة دليل سجل لن تنظيف ما زال يتم مرجع يحتفظ بديل.

### مرجع مصدر و Session قائمة سجل

Controller سوف مصدر حساب عدد و كل نشط وثب بديل مرجع مشترك نفس إدارة. كل مصدر حساب عدد انتظار في هذا بديل بعد لم تحرير كما حمل لديه هذا مصدر مرجع عدد. نفس Session يمكن لديه كثير عدد مصدر، نفس مصدر يمكن يحتفظ كثير نسخة مرجع. قسم إعداد جهاز لا منح إعطاء أي مصدر خاص خاص دورة الحياة سلوك.

كل بند قد لديه Session قائمة سجل عام فقط قراءة `retainedBy`، من مصدر مفتاح خريطة إلى صحيح عدد مرجع حساب عدد. لم يتم يحتفظ سجل استخدام فارغ كائن؛ صفر حساب عدد مفتاح لا وجود. نيل أخذ فشل و تحرير تحديث هذا إسقاط، يشمل حذف الأكثر بعد واحد مصدر مفتاح.Host بيانات وصفية تحديث جديد وقت، مصدر حساب عدد ما زال هو محلي واقع،Host استجابة لا يستطيع تغطية هو.

أي جعل Session بعد لم دخول Host دليل أو ذلك دليل بيانات وصفية قد يتم إزالة، حساب عدد ما زال من مقابل بديل يحتفظ.`byId` لـ كل نشط وثب بديل دمج صار محلي التقاط قاع سجل، بـ سهل Provider و كل حق استخدام جهة تحليل هو؛`ids` ما زال يمثل Host قائمة عضو علاقة و ترتيب. التقاط قاع سجل لا هو Host بيانات وصفية. كل بند سجل `retainedBy` إسقاط متساو استخدام نشط وثب بديل حساب عدد. مرجع كائن و حساب عدد متساو لا حفظ دائم، أيضا لا إرسال إعطاء Host.

مثال مثل،`retainedBy = { mainView: 1, gateway: 2 }` يمثل رئيسي عرض و اثنان عدد Host استدعاء يحتفظ ثلاثة نسخة مرجع. تحرير رئيسي عرض مرجع فقط إزالة `mainView`؛Gateway استدعاء متابعة يحتفظ هذا بديل. عرض مثال في مصدر اسم هو استخدام جهة مفتاح، لا هو Controller داخل غلاف إغلاق قطعة رفع.

`current` يمثل رئيسي عرض احتلال استخدام: سجل `mainView` مصدر حساب عدد لـ صحيح عدد وقت، حينئذ أداة لديه هذا عدد علامة. هذا فقط هو عام مصدر سجل واحد نوع استخدام طريق، لا هو مستقل `sessions.current` قيمة أو Session اختيار خدمة. أخرى استخدام جهة يمكن من ذاتي ذات مصدر مفتاح إرسال توليد علامة. مرجع نظام لا اشتراط عام وحيد استخدام جهة، أيضا لا من كثير عدد مصدر في اختيار واحد Session.

رئيسي منطقة مجال كل من إدارة ذاتي ذات هدف و مرجع تبديل. قائمة لا أصل حسب تماما جيد تركيب كثير قليل Provider دفع قطع اختيار. مصدر سجل عكس عكس فعلي كل حق، يشمل نيل أخذ خلال قصير مؤقت إعادة تراكم؛UI تنقل ما زال مسؤول ذاتي ذات هدف، لا يأخذ اختيار حق تسليم إعطاء قسم إعداد جهاز.

نافذة درجة استخدام جهة يمكن فحص نظر مصدر علامة.Session عمل خدمة عملية ما زال استخدام نقل دخول أثر مجال أو صريح مرجع، لا نيل من دليل في فحص بحث `mainView` قدوم تكملة متساو ناقص عملية هدف. خلفية مرجع فقط قدرة إثبات كل حق، لا يستطيع إثبات مستخدم فحص نظر مرور Session.

`SessionRetainInfo` يتضمن `referenceCount` و فقط قراءة `retainedBy` سجل.`sessions.retainInfo(id)` مستقل في دليل عضو علاقة مراقبة محلي كل حق، و في نفس ID تبديل بديل وقت إبقاء مستقر. لا يوجد نشط وثب بديل هوية أداة لديه صفر مرجع و فارغ مصدر سجل؛ قراءة هذا قيمة لا بديل جدول هذا هوية في Host فوق وجود.

`ui-session` عبر `useSessionRetainInfo(sessionId, selector)` قراءة واضح هوية، عبر `useSessionRetainInfo(selector)` قراءة خارج محيط Provider ربط Session. لم ربط أثر مجال نحو بعد واحد نوع شكل صيغة توفير ناقص قيمة، لا رجوع إلى رئيسي منطقة مجال Session. اثنان نوع شكل صيغة متساو من مصير من نفسه عار retain-info مصدر بنية صنع. استخدام جهة فحص `mainView` مصدر حساب عدد بـ تعرف آخر أصل current-Session زاوية لون، أخرى مصدر مفتاح أيضا يمكن نفس انتظار استعلام. قراءة أو حجز قراءة لن يحتفظ Session.

### موحد واحد UI Session حالة

`ui-session` يملك لا اعتماد React `sessionStatus` مصدر، عبر معيار `useSessionStatus` خطاف عام. لقطة حسب Session هوية بحث جذب، لـ كل معروف Session توفير واحد بند UI حالة سجل. هو تركيب تحت صف مستقل واقع، لا سوف هو جمع ضغط صار متبادل رفض مفرد واحد مرحلة مقطع:

| حقل | أخذ قيمة | يحتوي معنى و كل من |
| --- | --- | --- |
| `running` | `boolean` أو `undefined` | الأكثر جديد معروف Session تشغيل واقع؛ نقص قليل أساس خط لا يمثل قد تأكيد idle |
| `pendingInteraction` | `SessionPendingInteraction` أو `undefined` | مجال يملك صالح طلب؛ لا يوجد انتظار معالجة طلب وقت ناقص |
| `completionUnread` | `boolean` | قد مراقبة إلى إيقاف، لكن بعد لم تأكيد UI رفع تنبيه |

مصدر حساب عدد بـ `SessionListState.byId[id].retainedBy` لـ دقيق؛UI حالة قراءة هو بـ تنفيذ تأكيد سياسة، لا صيانة آخر طقم مرجع سجل التسجيل. عنوان،Workspace صلة ربط، تاريخ، طابور صف و إسقاط بيانات إبقاء في كل منها قائم كل من في.

انتظار معالجة مجال إبقاء `SessionPendingInteractionMap`، طلب هوية، أولوية درجة، إصدار تنظيف دالة و إزالة تفويض حمل. موحد واحد حالة يتضمن نفس عدد صالح طلب كائن، لا نسخ طلب، أيضا لا إنشاء ثاني طقم انتظار معالجة سجل التسجيل.Workspace حالة إشارة عرض جهاز و Conversation composer اختيار قراءة `useSessionStatus`، لم يعد قسم آخر قراءة `useSessionPendingInteraction` و `useCompletedSessionIds` خطاف.

إتمام تتبع أثر حجز قراءة قد لديه `api-session/status` حدث، تجنب تجنب running إلى idle تغير في دمج دفعة دليل لقطة في فقد فقد. دليل لقطة بناء قيام ابتدائي و إعادة وصل أساس خط.pending حالة تحت فارغ دليل لا يستطيع إثبات Session قد إزالة فقد. تحديث قاعدة مثل تحت:

- ابتدائي idle أساس خط لا إنتاج إتمام رفع تنبيه.
- مراقبة إلى running وقت صاف حذف قديم رفع تنبيه، و سجل تشغيل أساس خط.
- من معروف running تغيير لـ idle وقت، فقط في Session لا يوجد رئيسي عرض يحتفظ حال حال تحت ضبط `completionUnread`.
- نيل نيل رئيسي عرض يحتفظ وقت صاف حذف رفع تنبيه؛ غير متصل مصدر retain لا صاف حذف رفع تنبيه.
- تحرير رئيسي عرض يحتفظ لن لـ أكثر مبكر مرة إيقاف تكملة صنع رفع تنبيه.
- إزالة Session وقت صاف حذف ذلك إتمام رفع تنبيه و تشغيل أساس خط؛ انتظار معالجة طلب تنظيف ما زال يخص طلب مجال.

رفع تنبيه يمثل مراقبة إلى مرة إيقاف، لا بديل جدول مهمة نجاح، أيضا لا بديل جدول بعض بند ترتيب طابور رسالة إتمام. أي جعل عام وجه لوح مؤقت وقت إخفاء Conversation، رئيسي عرض كل حق ما زال إبقاء أساس في اختيار تأكيد دلالة. هذا تصميم لا توفير `ui-session/view-presence` حدث، قد تركيب Provider بحث جذب أو Provider تركيب وقت خفي صيغة تأكيد.

Session Controller إصدار تشغيل و مرجع مصدر واقع، لكن لا يملك إتمام رفع تنبيه تجميع دمج،`consumeCompletion` طريقة أو انتظار معالجة تفاعل عرض. مرجع نيل أخذ لا تنفيذ إتمام رفع تنبيه عمل خدمة منطق.

### صريح Provider، و سطر Conversation و ذاكرة مؤقتة هوية

وحيد `SessionProvider` يمكن وراثة خارج طبقة binding، أيضا يمكن استخدام صريح `session={reference | undefined}` تغطية هذا فرعي شجرة. هو لا نيل أخذ أو تحرير كل حق. أصل Provider من `mainView` كل حق علامة تحليل رئيسي binding، لا صيانة آخر نسخة current؛ و صف أو تضمين طقم Provider فقط أثر كل منها فرعي شجرة. صريح ناقص إبقاء ناقص، لا رجوع إلى رئيسي منطقة مجال.

Provider حقن اختيار تحديد binding، لكن لا لـ كامل body ضبط key. صارم إطار `session` entry في binding Context تغيير وقت إعادة تركيب. فارغ أبيض `session-maybe` entry قبول أول عدد binding وقت لا إعادة تركيب؛ قبول بعد، تبديل إلى آخر عدد binding Context أو عودة إلى ناقص حالة سوف إنشاء جديد مكون incarnation.

`uiWorkspace` يحتفظ مصدر لـ `mainView` رئيسي منطقة مجال مرجع،`ui-session` من هذا مرجع في Session سجل في كل حق علامة بناء قيام أصل Provider.Provider تحت Conversation، يمين Sidebar،preset، أمر، إدخال و نموذج مكون فقط قدرة قراءة Provider ربط معيار بيانات. هو جمع لا نيل قراءة رئيسي منطقة مجال مرجع أو عام اختيار، أيضا لا نيل حسب Session ID إعادة بحث بحث واحد ممكن يخص أخرى Provider binding.

كل Provider occurrence بـ نقل دخول `SessionReference` بناء قيام مستقل تصيير أثر مجال. اثنان عدد مرجع يمكن إشارة نحو مختلف Session، أيضا يمكن مشترك نفس `SessionBinding`؛ مختلف binding عمل خدمة و مراقبة نظر بيانات تماما قسم مغادرة، نفس binding Provider مشترك Session،Conversation، إدخال انتظار Session درجة بيانات، لكن إبقاء كل منها مكون نطاق جزء حالة. رئيسي منطقة مجال و Sidebar يمكن معا تركيب اثنان عدد Conversation، مهمة واحد Provider استبدال أو إزالة لا تغيير آخر شجرة فرعي شجرة هدف.

`ui-session` لـ كل نشط وثب `SessionBinding` إعادة استخدام مستقر عمل خدمة observable.Conversation assembly،input shell،command popup،input-trigger controller و model directory انتظار بديل حد ذاكرة مؤقتة بـ binding لـ ضعيف مفتاح، لم يعد بـ Session ID لـ مفتاح؛ حاجة قطعة رفع نشط وثب قيمة ذاكرة مؤقتة استخدام `util-values` `WeakMapWithValues<SessionBinding, Value>`، من ضعيف مفتاح جدول و قوي قيمة تجميع دمج مشترك نفس صيانة هوية استعلام و قيمة مرة تاريخ. هذا حاوية لا تنفيذ تنظيف؛ حجز قراءة، تحكم جهاز،URL و أخرى مورد ما زال عبر `binding.ctx.effect()` تحديد صفة تحرير.Provider occurrence مراقبة نظر حالة مع هذا Provider تصيير أثر مجال تحرير، نهائي generation تنظيف من binding Context مسؤول.

Descriptor تغير أولا تجميع بديل مصدر مجددا إصدار، لا إعادة بناء Session بديل.Provider في قراءة reference وقت تحقق هو ما زال صالح؛ قد تحرير، قدوم ذاتي أخرى Controller أو لم يعد مقابل نشط وثب binding reference لا يستطيع إنشاء أثر مجال.

| استخدام جهة | نيل أخذ و تحرير |
| --- | --- |
| رئيسي Conversation | `uiWorkspace` نيل أخذ تنقل هدف؛`ui-session` من `mainView` علامة بناء قيام أصل Provider،Conversation فرعي شجرة فقط إزالة استهلاك Provider ربط |
| صلة ربط يمين Sidebar | `RightbarRoot` وراثة أصل Provider، لا قراءة رئيسي منطقة مجال مرجع |
| مستقل Session عرض | ذاتي ذات كل من يحتفظ هدف، و بـ ذاتي ذات مرجع بناء قيام Provider؛ و رئيسي منطقة مجال معا تشغيل |
| Client في Host حدث handler | يحتفظ محلي Context مرجع مباشر إلى handler و عودة تكرار تسوية |

Conversation مرجع يخص ذلك عرض كل من، لا يخص Chat،Trajectory أو بعض مرة نقر.Chat،Trajectory، أمر، إدخال، فوق نقل، صورة قراءة و نموذج اختيار في Provider دورة الحياة داخل استعارة استخدام نفس binding؛ هو جمع لا حسب سطر حركة تكرار نيل أخذ مرجع. تبديل أو إغلاق هذا Conversation يمكن انتهاء ما زال في طريق محلي عمل.Sidebar tab تخطيط و مورد كل حق إبقاء مستقل؛ فقط لديه تحمل تحميل Conversation Sidebar عرض كل من حاجة ذاتي ذات Session مرجع. فارغ تخطيط و guide احتلال موضع صفحة لا يحتفظ مرجع.

أثر مجال عمل خدمة كائن من Provider التقاط ذاتي ذات binding، لا يأخذ قديم Context أو دليل إعادة حل تفسير صار نفس ID جديد واحد بديل.ModelSelection استعارة استخدام Provider binding، و إبقاء ذاتي ذات اختيار بديل حد و خطأ قاعدة. تحرير جهاز انفصال مغادرة عودة ضبط ممكن و أثر مجال تنظيف إعادة تراكم؛ اختياري trigger و popup مقابل قد انتهاء Context إرجاع فارغ قيمة، لا تحليل أخرى generation.

### رئيسي منطقة مجال تنقل و عرض

`uiWorkspace.openSession`،`openWorkspace`،`forkSession` و `startSession` ما زال هو تنقل مدخل. هو جمع قبول أو تحليل واضح هدف، تغيير رئيسي عرض، و حسب قائم تنقل سياسة سوف رئيسي منطقة مجال إرجاع Conversation.`retain` ذاته من لا تنقل. مرجع كل حق لا جذب دخول `registerNavigation` استقبال من بروتوكول، أيضا لا جذب دخول ثاني عدد تنقل خدمة.

قائم `uiWorkspace` تنفيذ مباشر يحتفظ مصدر لـ `mainView` رئيسي منطقة مجال مرجع و هدف. تنقل طريقة مباشر تحديث هذا كل من، لا استدعاء Conversation تسجيل استقبال من.`ui-session` أصل حسب مصدر علامة يأخذ هذا مرجع مقابل binding حقن أصل Provider؛ رئيسي Conversation و صلة ربط يمين شريط فقط وراثة Provider، حيث لا اعتماد `uiWorkspace`، أيضا نظر لا إلى رئيسي مرجع. مستقل Sidebar Conversation بـ ذاتي ذات reference بناء قيام تضمين طقم Provider، و تغطية هذا فرعي شجرة binding. رئيسي مرجع لا هو عام معيار prop، فرعي شجرة Hook أو حسب ID استعلام قيمة افتراضية.

رئيسي عرض في `dsh.sessions.current` تحت خاص تحت حفظ دائم هدف هوية و فرعي جلسة عنوان، لا حفظ مرجع. بدء استعادة، ابتدائي Workspace اختيار و عودة ملف رئيسي هدف بعد صاف فارغ ما زال يخص UI. عودة ملف أو إزالة دليل بيانات وصفية لا سحب إلغاء أخرى استخدام جهة يحتفظ مستقل مرجع.

| UI سلوك | نهائي قاعدة |
| --- | --- |
| Session قائمة عال مضيء و فارغ أبيض سجل معالجة | من `retainedBy.mainView` إرسال توليد رئيسي منطقة مجال احتلال استخدام، لا حسب قد تركيب Session Provider عدد كمية حكم قطع |
| New Session Workspace | أولوية استخدام صريح Workspace، ذلك مرة حسب قائم فحص بحث قاعدة استخدام رئيسي Session Workspace، الأكثر بعد استخدام قائم الأكثر قريب Workspace سياسة |
| Onboarding | حكم قطع رئيسي منطقة مجال Session هل ناقص أو لـ فارغ أبيض، لا حكم قطع كل تاريخ Session |
| متصفح وثيقة عنوان | Conversation عرض Session عنوان و منتج عنوان؛ عام وجه لوح عرض منتج عنوان |
| Chat/Trajectory استعادة | لـ صريح اختيار في رئيسي هدف استعادة عرض؛ مستقل ربط عرض إبقاء ذاتي ذات حالة |
| Cordis inventory وجه لوح | استخدام لا منطقة قسم current/other مفرد واحد قائمة؛runner لا توفير رئيسي منطقة مجال اختيار عام getter |

DOM تركيز نقطة نقل حركة أو عام وجه لوح إخفاء ما زال يتم يحتفظ عرض وقت، مصدر بيانات وصفية ثابت.[عام رئيسي وجه لوح تصميم](../../implemented/architecture/2026-09-08-global-main-panels.ar.md) يملك وجه لوح اختيار و تخطيط؛Session مرجع كل حق لا بديل هو.

Conversation إبقاء `hero`،`settling`،`active` تركيب و قائم تاريخ تحميل و `openError` معالجة. نيل أخذ مرجع لا زيادة خارج طبقة loading/error مرحلة مقطع عرض، مقدار خارج إخفاء composer شرط،Retry حسب زر أو استبدال Sidebar محتوى استعادة وجه لوح. قد لديه خطأ معالجة جهة متابعة معالجة ذاتي ذات خطأ؛ لا يوجد خطأ عرض استدعاء نقطة لا زيادة عرض.Promise رفض و صحيح تأكيد تحرير مرجع لا معنى طعم حال مقدار خارج زيادة UI معالجة جهة.

Workspace اتصال و fork إبقاء قائم تنقل فحص و وجه لوح تبديل بطلان قاعدة. مباشر فتح Session لا زيادة عام تنقل إلغاء سياسة.Agent Team تحديث جديد إبقاء إرسال بدء وقت اختيار ما زال صالح شرط، لا في تحديث جديد قبل بدء عام تنقل token. مرجع نيل أخذ لا توسيع كبير إلغاء نطاق، لا أثر غير متصل تنقل أو صحيح في تنفيذ عملية؛ محلي إلغاء لا تراجع Host فاعلية نتيجة.

### مسبق ضبط و إنشاء مسار

مسبق ضبط دليل و نشر قيمة افتراضية يمكن مشترك. قد ربط Session مسبق ضبط عبر Provider binding قراءة أو تعديل؛ مسبق ضبط تحكم جهاز حسب `SessionBinding` ذاكرة مؤقتة، لا من أصل درجة current-Session تتبع مع جهاز إدارة.Hero preset seat استخدام `session-maybe` Provider: لا يوجد Session وقت عرض إنشاء مسار اختيار، ربط فارغ أبيض Session بعد عملية هذا تأكيد قطع Session. عنوان وسم قراءة نفس Provider ربط Session إسقاط.

Session إنشاء قبل اختيار preset إبقاء في رئيسي Conversation `session-maybe` preset surface في.Workspace إنشاء أو إعادة استخدام فارغ أبيض Session و بناء قيام رئيسي Provider بعد، هذا surface سوف اختيار تطبيق إلى Provider ربط Session. ضبط صفحة تعديل افتراضي preset أو picker ضبط وقت،preset خدمة من Provider قد بناء قيام binding ذاكرة مؤقتة في اختيار حمل `mainView` كل حق علامة فارغ أبيض Session، و تحديث هذا Session. غير فارغ أبيض رئيسي Session،Sidebar مستقل Provider و أخرى خلفية مرجع متساو لا تلقي هذا ضبط حركة عمل أثر؛preset فرعي شجرة لا قراءة رئيسي مرجع، أيضا لا عبر عام current follower بحث بحث هدف.

### Host حدث Context كل حق و Typert

مرور تحقق Host waterfall(شلال نشر صيغة حدث) هوية يمكن أولا في دليل اكتشاف وصول.Client Context محلل يجب إبقاء تزامن. هو حمل فوق Gateway مصدر نيل أخذ محلي بديل مرجع، إرجاع `TypertOwnedValue<Context>`، لا فتح تاريخ، أيضا لا تحديث جديد فرعي دليل. حاجة تاريخ handler آخر سطر نيل أخذ عام مرجع و انتظار ذلك `ready` Promise، أو استخدام `sessions.using`.

Gateway يحتفظ محلي مرجع، مباشر إلى handler استخدام و عودة تكرار تسوية متساو انتهاء.Context نيل أخذ فشل إبقاء قائم سجل خطأ و تفويض حمل دلالة،handler فشل إنتاج رفض عودة تكرار. إلغاء عبر قد لديه signal وصول handler، و كبح صنع متأخر عودة تكرار، لكن لن في Context ما زال يتم استخدام وقت رفع قبل تحرير. إضافة إغلاق تجميع دمج حالي اتصال بديل في طريق handler؛Connection فقط في هذا مصدر تسوية بعد بدء بديل بديل.

`TypertOwnedValue` عبر عام Gateway نقل تمرير قيمة و ذلك تنظيف عملية. هو لا يوجد مقدار خارج مرجع حساب عدد، أيضا لا اشتراط Gateway إدارة حل Session مخصص استخدام كل حق. مستقل Client bundle مشترك owned-value علامة.Client إرسال طلب `identity(ctx)` إبقاء تزامن؛Host Context تحليل و Host دورة الحياة ثابت.

## اعتبار مرور بديل خطة

**بـ دليل عضو علاقة بصفة كل حق.** اكتشاف بيانات لا يمكن إثبات عرض أو عملية ما زال في استخدام، بينما كما جزء Context هوية أولا في دليل عضو علاقة وصول.

**خفي صيغة رئيسي Session إضافة صريح بديل مسار.** اثنان طقم هدف تحليل قاعدة سوف جعل يمكن إعادة استخدام مكون اعتماد ذلك تصيير موضع. صريح Provider توفير هدف، عام مصدر سجل خدمة في نافذة درجة مراقبة.

**Provider فرعي شجرة متابعة قراءة `mainSession`.** نفس مكون سوف معا يملك Provider و نافذة درجة هدف،Sidebar مستقل Conversation أيضا سوف يتم رئيسي منطقة مجال تغير إعادة تحديد نحو. رئيسي مرجع فقط مشاركة و Provider تركيب إعداد، فرعي شجرة فقط قراءة Provider.

**بـ Session ID لـ بديل حد ذاكرة مؤقتة مفتاح.** نهائي تحرير سماح نفس ID جديد بديل في قديم تنظيف انتهاء قبل ظهور،ID مفتاح سوف إعادة استخدام قديم كائن أو يجعل قديم تنظيف حذف جديد كائن. عمل خدمة ذاكرة مؤقتة استخدام ضعيف مرجع binding هوية، مورد تنظيف من binding Context مسؤول.

**فقط في تاريخ فتح بعد تحليل مختلف خطوة `retain`.** هو سوف يأخذ Provider تثبيت و رئيسي عرض تنقل دفع متأخر إلى تاريخ وصول بعد، توجيه يؤدي قائم تحميل حالة لا يمكن قيام أي تصيير. تزامن مرجع يأخذ كل حق و صريح `ready` نتيجة قسم فتح.

**في تزامن Context تحليل في تنفيذ تاريخ I/O.** Host حدث إرسال إرسال حاجة أثر مجال دورة الحياة، لا واحد تحديد حاجة تاريخ نافذة؛ اقتران دمج اثنان من سوف في دليل اكتشاف قبل تأخير متأخر أو منع توقف handler.

**مخصص استخدام current علامة سجل.** واحد نوع استخدام جهة مخصص استخدام علامة سجل لا يمكن وصف Sidebar و خلفية كل حق. رئيسي عرض علامة يمكن من عام حسب مصدر حساب عدد في إرسال توليد.

**Session Controller في إتمام حالة، أو مستقل انتظار معالجة و إتمام رفع تنبيه خطاف.** إتمام تأكيد يخص UI سياسة. موحد واحد UI حالة مصدر تركيب مستقل واقع، معا إبقاء مجال يملك انتظار معالجة كائن و Controller يملك تشغيل واقع.

**بـ Provider عرض قرار تأكيد أو تحرير.** تركيب حيث لا انتظار في كل من دورة الحياة، أيضا لا انتظار في أساس في اختيار تأكيد. هو لا يمكن قرار أي بعض خلفية أو مؤقت وقت إخفاء استخدام ما زال ينبغي تخزين نشط، أو ينبغي عند حساب عمل قد فحص نظر.

**Provider في عار ID أو عام binding revision.** ID لا جدول بلوغ بديل حد كل حق، عام تحديث جديد سوف جعل غير متصل Session استخدام جهة بطلان.

**كل سطر حركة كل منها نيل أخذ مرجع.** Provider قد تعريف Conversation استخدام دورة الحياة؛ لـ كل مرة نقر تكرار يحتفظ سوف يأخذ عرض كل حق تفكيك صار كبير كمية دقيق حبة درجة مصدر. فقط لديه واضح حاجة تجاوز مرور Provider دورة الحياة عمل عندئذ آخر سطر يحتفظ مرجع.

**تنقل تسجيل، جديد إلغاء سياسة و نيل أخذ مخصص استخدام استعادة UI.** مرجع كل حق اشتراط صريح هدف، تحرير و فشل نقل بث، لا اشتراط مقدار خارج تنقل أو استعادة سلوك.

**Client مرجع يحتفظ Host Agent.** تاريخ وصول و Host تنفيذ هو مستقل استخدام يحتاج طلب، طويل وقت فتح Client عرض لا يستطيع تعريف Host عمل خدمة عملية دورة الحياة.

## تحقق

- نيل أخذ اختبار تغطية مشترك أول مرة فتح، عادي و معنى خارج فتح فشل، مستقل انتظار جهة إلغاء، تأكيد قطع بديل استبدال، و أصل تنظيف بلوغ إلى تماما توقف مستقر.
- مصدر اختبار تغطية كثير عدد مصدر، نفس مصدر كثير نسخة مرجع، نيل أخذ فشل تراجع، قوة انتظار تحرير، دليل تحديث جديد أو إزالة، و قديم بديل متأخر تحرير لا تغيير بديل بديل.
- Retain-info خطاف اختبار تغطية واضح هوية،Provider ربط قيمة افتراضية، لم ربط و تضمين طقم أثر مجال، عبر بديل مصدر تحديث، و قراءة لا إنشاء مرجع أو طلب تاريخ.
- أثر مجال و Gateway اختبار تغطية دليل اكتشاف قبل لا تنفيذ تاريخ I/O تزامن Context نيل أخذ، نيل أخذ فشل سجل و تفويض حمل،handler رفض عودة تكرار، إلغاء و تسوية خلال كل حق، و عبر bundle مشترك owned-value علامة.
- UI حالة اختبار تغطية انتظار معالجة أولوية درجة و تنظيف، سوف يتم لقطة دمج دفعة فقد فقد حدث تغير، ابتدائي و إعادة وصل أساس خط، رئيسي مصدر تأكيد، غير متصل مصدر يحتفظ، و لا وجود Provider عرض حدث.
- عرض تحقق تغطية اثنان عدد مختلف Session و نفس Session كثير مرة استخدام و سطر صريح Provider، متبادل لا إعادة تحديد نحو Conversation، مستقل Slot store، أثر مجال preset،descriptor تحديث، و لا يوجد جديد استعادة تحكم عنصر Sidebar دورة الحياة.
- فعلي تركيب متصفح مشهد إبقاء رئيسي منطقة مجال عال مضيء، فارغ أبيض سجل،onboarding،Workspace قيمة افتراضية، عنوان و اتفاق تنقل أو خطأ سلوك. فقط لديه Client كل حق تغيير وقت، قد لديه نموذج جولة تسجيل صنع ما زال بصفة سلوك إدخال.
- عام `retain`،`using`،Provider، توليد API دليل، حزمة اتفاق و نوع فحص مقابل options و كل حق إبقاء متسق.Provider فرعي شجرة لا قراءة رئيسي منطقة مجال مرجع، مستقل كل من كل منها تحرير ذاتي ذات مرجع.

## عاقبة

استخدام جهة يجب يأخذ مرجع إبقاء إلى حقيقي انتهاء نقطة؛ في نشط وثب Client أصل داخل، لم تحرير مرجع ما زال سوف تسرب تسرب. الأكثر بعد تحرير بعد مجددا مرة retain سوف إنشاء جديد واحد بديل، و ممكن إعادة فتح تاريخ. مصدر حساب عدد وصف كل حق، لا وصف مرئي صفة، مهمة نجاح أو عملية إذن؛ بـ رئيسي علامة بصفة عمل خدمة التقاط قاع سوف إعادة جذب دخول خفي صيغة current-Session اقتران دمج.

الأكثر بعد واحد نسخة reference تحرير بعد، لم حفظ دائم binding ذاتي لديه حالة سوف يتم إسقاط، يشمل قد تحميل تاريخ صفحة،Chat تمرير مرساة نقطة، معاينة تبديل سطر،Files توسيع حالة،composer مرفق عنصر و undo تاريخ. فقط لديه حفظ دائم Session-keyed Store قيمة أو من آخر نسخة reference حفظ نشط generation قدرة عبر عرض تبديل إبقاء؛runtime لن صاف حذف هذه حمل دائم قيمة.

كل مرة عام `retain` كل سوف بدء هذا generation مشترك أول مرة تاريخ فتح، يشمل Session إعادة تسمية و fork عنوان ضبط الذي استخدام مؤقت مرجع. هذه بيانات وصفية عملية في استخدام Session قبل انتظار `reference.ready`، لذلك بارد generation سوف تحمل تحمل هذا مرة تاريخ I/O.

دليل،UI حالة و عرض هدف من مختلف كل من إدارة، يمكن مستقل إصدار. استخدام جهة لا يستطيع فقط من إشعار ترتيب دفع قطع دورة الحياة تغير. رئيسي عرض ما زال هو عادي مرجع كل من، ذلك تنقل و عرض قاعدة إبقاء في UI، لا دخول مرجع قسم إعداد جهاز.
