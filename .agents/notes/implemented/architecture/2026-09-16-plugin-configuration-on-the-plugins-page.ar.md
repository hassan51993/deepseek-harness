# Agent Note: إضافة صفحة فوق إضافة إعداد

حالة: قد تنفيذ

[English](2026-09-16-plugin-configuration-on-the-plugins-page.md) | العربية

## مشكلة

إضافة ضبط أصل هذا وضع في ضبط داخل، إضافة قسم منطقة إعداد وسم صفحة فوق: أربعة ورقة يمكن طي بطاقة، كل مضيف مستو وجه نطاق الأسماء واحد ورقة، جانب حافة هو فقط قراءة بيان وسم صفحة. جانب شريط إضافة صفحة قدرة صف خروج و بدء توقف تركيب حزمة، لكن ضرب لا فتح إضافة ضبط، في هو نفس عدد كائن يتم اثنان عدد واجهة كل حمل واحد نصف؛ مستودع خارج تثبيت تركيب حزمة أكثر هو تماما لا يوجد أرض جهة وضع ذاتي ذات جدول مفرد.

## قرار

**إضافة صفحة تحمل تحميل إعداد؛ ضبط فقط إبقاء بيان.** صفحة في ذلك `main` بند تحت إعلان ثلاثة عدد فرعي slot.`plugins.item`(list) حسب `label` يأخذ رسمي جهة إضافة صف في رسمي جهة قسم مجموعة داخل.`plugins.bundle.config`(بـ تركيب حزمة حزمة اسم لـ مفتاح) تصيير في تركيب حزمة صفحة وصف و سطر بين.`plugins.row.config`(بـ `<حزمة اسم>#<سطر id>` لـ مفتاح) إعطاء هذا واحد سطر واحد إعداد تحكم عنصر، فتح بـ سطر id لـ عنوان صفحة. كل بند كل حسب صفحة بـ owner props نقل دخول اثنان نوع عرض تصيير:`summary` هو عنوان تحت واحد جملة كلام بسيط وسيط،`page` هو جدول مفرد. صفحة مسؤول رسم عنوان، رسم علامة و وجه حزمة فتات، يأخذ ثلاثة نسخة حساب هذا إسقاط صار واحد يمكن مراقبة كائن (`configLedgerSource`) ربط في store جانب حافة، ذاته من لا نقطة اسم أي يمكن إعداد إضافة.

**ملكية من تسجيل جهة في slot اسم و مفتاح داخل إعلان.** لا إضافة manifest حقل، لا إضافة تسجيل بيانات وصفية، أيضا لا من settings خدمة أخذ owner معلومة: رسمي جهة صفحة لا حمل تركيب حزمة تسجيل، تركيب حزمة صفحة حمل ذاتي ذات حزمة اسم تسجيل، سطر صفحة حمل تركيب حزمة و ذلك patch إعلان سطر id تسجيل. لا يوجد متصفح نصف جانب مجتمع منطقة تركيب حزمة حينئذ لا يوجد إعداد صفحة؛ صفحة لن من settings schema تصيير عام جدول مفرد.

**فقط لديه حفظ عندئذ كتابة.** جدول مفرد وضع ترك تحكم عنصر و لم حفظ علامة كل ذهاب إسقاط: مغادرة فتح صفحة أي إسقاط مؤقت تخزين تعديل، جدول مفرد في إزالة وقت تنفيذ. حفظ ما زال مرور من عميل settings scope، حمل revision شبكة شريط.

**أربعة عدد مضيف مستو وجه صفحة من `ui-settings-plugins` في Host خدمة ذلك نطاق الأسماء خلال تسجيل.** هذا حزمة يأخذ ضبط قسم منطقة إبقاء لـ بيان وسم صفحة خارج وجه**داخل وضع إضافة**خارج قشرة، في مشترك settings مرآة مثل عرض بعض عدد نطاق الأسماء وقت عبر `ctx.slots.inject` تسجيل مقابل صفحة، نطاق الأسماء إزالة فقد وقت إلغاء تدمير، لذلك لا يوجد تجميع هذا إضافة نشر لن إبقاء تحت هو أثر أثر.`settings.plugin.item` slot تراجع دور.

**رسمي جهة قسم مجموعة.** تثبيت مع مرفق اختياري تركيب حزمة فتح بدء هذا عدد قسم مجموعة، يخص beta وظيفة (Agent Teams) حمل **Beta** وسم، لم يعد لديه رسمي جهة وسم؛ إعداد صفحة ترتيب في ذلك بعد.Auto review مغادرة فتح `OPTIONAL_BUNDLES` و CLI اعتماد: هو هو واحد قد إصدار فعلي تحقق حزمة، تثبيت جذب توجيه أخذ هو عمل عرض مثال.

## عاقبة

- تركيب حزمة متصفح نصف جانب استخدام مرة slot تسجيل إضافة ذاتي ذات كلمة قاموس حينئذ قدرة توفير جدول مفرد؛ تركيب حزمة patch يجب بـ مفتاح داخل id إعلان هذا واحد سطر، تسجيل فقط في تحمل تحميل تركيب حزمة متصفح نصف جانب ذلك واحد سطر فتح بدء خلال وجود:`dsh-client-modules` يأخذ هذا نصف جانب تعليق في شرح رمز تماما لـ حزمة اسم ذلك واحد سطر فوق، لذلك مفتاح إشارة نحو فرعي مسار سطر سطر درجة صفحة مع أصل سطر إزالة فقد، بينما لا مع هو ذاتي ذات سطر.
- أربعة عدد صفحة، هو جمع جدول مفرد و settings كتابة مسار ثابت؛`ui-settings-plugins` إبقاء ذلك اسم حرف، لأن هو ما زال يملك ذلك عدد قسم منطقة، كل إدارة هو صفحة إقامة في إضافة صفحة فوق.
- ضبط فقط صف خروج بيان؛ حمل لديه إضافة تنقل بند و إعداد وسم صفحة ضبط صنف golden قد إعادة تسجيل.

## اعتبار مرور بديل خطة

**slot بند فوق تسجيل بيانات وصفية.** من slot إعلان `meta` نسخة مقدار (وصف، تركيب حزمة، سطر) قدرة يجعل مفرد عدد `plugins.item` slot تغطية كل حال حال، بديل قيمة هو `ui-slots` كثير واحد عام فكرة؛ ثلاثة عدد slot استخدام قائم API جدول بلوغ نفس مثال معلومة.

**من settings schema توليد عام جدول مفرد.** `describe()` قد يأخذ كل نطاق الأسماء schemastery schema إرسال إعطاء متصفح، لا يوجد متصفح نصف جانب مجتمع منطقة نطاق الأسماء هذا يمكن نيل نيل واحد نسخة افتراضي جدول مفرد. تأجيل: رسمي جهة صفحة هو دقيق اختيار، عام جدول مفرد سوف في لا يوجد أبيض اسم مفرد حال حال تحت كشف داخلي نطاق الأسماء، بينما يأخذ نطاق الأسماء ملكية إلى تركيب حزمة أيضا حاجة descriptor حمل owner.

**يأخذ بطاقة إبقاء في ضبط داخل، من إضافة صفحة رابط مرور ذهاب.** الأكثر حذف أمر، لكن review اشتراط جدول مفرد في إضافة ذاتي ذات صفحة فوق.

## اختبار

`ui-plugin-manager` مفرد قياس تغطية حساب هذا إسقاط، رسمي جهة قسم مجموعة بطاقة و صفحة، تركيب حزمة جدول مفرد و سطر صفحة؛`ui-settings-plugins` مفرد قياس تغطية حسب يتم خدمة نطاق الأسماء تسجيل و سحب تحت، و جدول مفرد فقط حفظ لا وضع ترك سلوك.`plugin-config` web lane عبر حقيقي سلسلة مسار تحرير shell صفحة، و في فتح بدء مجتمع منطقة تجهيزة تركيب حزمة بعد فتح ذلك سطر صفحة؛`plugin-manager` lane سجل جديد رسمي جهة قسم مجموعة.
