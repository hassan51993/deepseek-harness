# Agent Note: متصفح بدء أمر لوحة إقرار إثبات

Status: implemented

[English](2026-08-24-browser-token-authentication.md) | العربية

## مشكلة

Web Host بـ حالي عملية نظام مستخدم إذن تشغيل أداة لديه أداة قدرة Session، لكن ذلك HTTP واجهة استخدام طلب توجيه واقع تعرف آخر خاص حق استدعاء من. أداة جسم بينما قول، حسب طريقة صيانة loopback قائمة يأخذ loopback `Host` قيمة نظر لـ محلي authority، كل إدارة HTTP عميل يمكن تحكم هذا header. قدرة كاف وصول خادم استدعاء من لذلك يمكن إعلان `localhost`، دخول إعداد طريقة، مجددا فائدة استخدام نموذج اكتشاف انتظار Host جانب عملية كشف كشف تخزين اعتماد. مع مرفق CLI ربط loopback يمكن حد عادي يمكن بلوغ صفة، لكن لا يستطيع إقرار إثبات يتم تحويل إرسال أو بـ أخرى طريقة إرسال بلوغ هذا socket طلب.

## قرار

`dsh-client-connection` في توزيع قبل إقرار إثبات كامل Host API. كل API Proxy طريقة،Remote واحد عنصر استدعاء، عام Connection channel و Remote WebSocket stream كل اشتراط نفس عدد متصفح جلسة؛endpoint كل حق و طريقة اسم لا تغيير authority. قائم Host/Origin تحقق أولا تنفيذ، متابعة مسؤول DNS rebinding و عبر محطة طلب منع صد، فشل وقت إرجاع 403.Host يمكن معلومة لكن لا يوجد صالح متصفح جلسة وقت إرجاع 401. متصفح معلومة مهمة قاعدة ما زال من[تحميل جسم درجة متصفح معلومة مهمة قرار](2026-07-28-api-browser-trust-boundary.zh.md) يحتفظ.

كل Host عملية توليد مع آلة بدء أمر لوحة، و من تطبيق أصل context عبر Connection حار إعادة تحميل إبقاء.`dsh-web-app` كل عملية فقط ضرب طبع و فتح مرة query في حمل هذا أمر لوحة عادي أصل URL.`frontend-static` طلب Connection تخويل index استجابة: فقط لديه `GET /?token=...` سوف يأخذ عملية أمر لوحة تسليم تبديل لـ cookie، مجددا إعادة تحديد نحو إلى جاف صاف `/`؛API مسار و Authorization header كل لا قبول هذا أمر لوحة. مرور وقت أمر لوحة إذا معا حمل لديه صالح cookie، سوف إعادة تحديد نحو إلى جاف صاف `/`. ناقص و بلا فاعلية اعتماد نيل إلى نفس نسخة الأكثر صغير 401 استجابة. غير index ساكن حالة مورد إنتاج إبقاء عام.

cookie هو توقيع كما ربط authority bearer. تحديد صفة اسم و توقيع payload كل يتضمن مواصفة تحويل hostname و port، لذلك نفس Harness home يمكن في مختلف Web port تشغيل بينما لا حدوث cookie اندفاع مفاجئ.payload في قطعا مقابل صالح مدة داخل يحمل أمان كامل عدد شكل صيغة توقيع إرسال و مرور مدة وقت؛`cookieMaxAgeDays` افتراضي لـ 30.cookie هو host-only،`Path=/`،`HttpOnly`،`SameSite=Strict`. مع مرفق خادم استخدام loopback HTTP، لذلك لا ضبط `Secure`. هذا داخل لا يوجد logout عملية أو عكس نحو بديل إدارة مخصص استخدام معالجة.

HMAC مفتاح هو `ctx.credentials` في يقع في `client-connection/browser-session` إصدار تحويل `grant` سجل؛ محلي مزود سوف ذلك تخزين دخول `$DSH_HOME/.credentials.yaml`.Connection في تنشيط خلال تحميل أو إنشاء هذا سجل، و إبقاء مفتاح بـ تزامن تحقق طلب. حمل دائم سجل حدوث تغير بعد، حالي Connection متابعة استخدام قد تحميل مفتاح؛ تحت مرة تنشيط سوف تحميل استبدال سجل أو إنشاء ناقص سجل، لذلك حذف سجل و إعادة بدء عملية سوف سحب إلغاء الكل قائم cookie. بلا فاعلية owner payload سوف واضح فشل، بينما لا هو يتم تغطية. بدء أمر لوحة ذاته أبدا حفظ دائم و في كل مرة عملية بدء وقت تغير؛ لم مرور مدة cookie فإن قدرة في نفسه authority فوق عبر إعادة بدء متابعة صالح.

صفحة داخل Web Worker preview لا كشف شبكة شبكة socket. ذلك من صفحة يحتفظ `postMessage` tunnel أولا دخول حقيقي route، استلام إلى 401 أو 403 بعد مجددا مرور worker محلي fetch handler إعادة محاولة. هذا مثال حيث إبقاء Connection interceptor، أيضا يأخذ إقرار إثبات التفاف مرور حد في إنشاء Host worker صفحة داخل.

مع مرفق CLI متابعة رفض `--host 0.0.0.0`. إقرار إثبات لا بديل جدول دعم حمل شبكة شبكة نشر،TLS، تحويل إرسال header حل تفسير أو بديل إدارة إعداد.

## تحقق

وحدة تغطية Connection إعادة تحميل وقت إبقاء عملية أمر لوحة، كل مرة تنشيط فقط تحميل مرة مفتاح، بلا حاجة قراءة اعتماد مزود تزامن تحقق،cookie خاصية،HMAC و payload تحقق،authority و صالح مدة تحقق، سجل حذف في تحت مرة تنشيط وقت توليد فاعلية، بلا فاعلية حمل دائم سجل، و استخدام صالح cookie تنظيف مرور وقت أمر لوحة URL.Host نقل طقم عنصر ثابت عام RPC،Typert Remote HTTP، دقيق Fetch توجيه و WebSocket upgrade مسار فوق متسق 401/403 سلوك.frontend حقيقي تركيب اختبار مرور Loader بدء credentials،Connection،webserver و ساكن حالة خدمة، إثبات قراءة index قبل إتمام أمر لوحة تسليم تبديل، معا ساكن حالة مورد إنتاج ما زال عام. تحزيم worker اختبار إثبات cookie تحرير رمز يمكن نقل غرس، و تغطية إقرار إثبات و معلومة مهمة رفض بعد worker محلي إعادة محاولة. حقيقي CLI اختبار في مؤقت `DSH_HOME` فوق استخدام نفس طرف فتحة اثنان مرة بدء `dsh web`، إثبات زائف صنع `Host: localhost` ما زال لم إقرار إثبات، بـ تسليم تبديل الذي نيل cookie استدعاء `settings/describe`، مراقبة قياس جديد عملية أمر لوحة، و في إعادة بدء بعد إعادة استخدام قديم cookie.

## سبق اعتبار بديل خطة

**من TCP مقابل طرف عنوان حكم تحديد خاص حق استدعاء من.** مباشر مقابل طرف عنوان ما زال ممكن فقط تعرف آخر محلي تحويل إرسال عملية، بينما غير متصفح مستخدم؛ هو سوف في API أمر تنفيذ قدرة جانب إبقاء ثاني طقم authority نموذج، و اشتراط بديل إدارة سياسة عودة جواب أصلي استدعاء من هو من. واحد تطبيق اعتماد عندئذ هو كل بند عملية كل قدرة تنفيذ هوية.

**إبقاء حسب طريقة خاص حق قائمة، و يأخذ تخزين اعتماد حد في قد إعداد هدف.** قائمة ممكن تسرب إسقاط جديد endpoint، أيضا لا يستطيع قيد قد تحكم أداة نوع Session استدعاء من.`discoverModels` هدف قاعدة لا بنية صار أمان حد، لأن نفس قد إقرار إثبات رئيسي جسم يمكن تحديث settings و تشغيل أمر. موحد واحد إقرار إثبات تغطية منح إعطاء عملية تحكم حق عملية.

**حفظ دائم بدء أمر لوحة أو يأخذ هو بصفة API bearer قبول.** حمل دائم بدء أمر لوحة سوف يصبح ثاني نسخة طويل مدة اعتماد؛Authorization header دعم حمل فإن سوف زيادة لا يوجد حالي consumer غير متصفح عميل اتفاق. عملية أمر لوحة فقط إتمام مرة متصفح cookie تسليم تبديل.

**كل مرة إعادة بدء كل جولة تبديل توقيع مفتاح.** هذا سوف منع توقف قائم متصفح في عادي DSH إعادة بدء بعد إعادة وصل. فقط حفظ دائم توقيع مفتاح حيث إبقاء هذا سير العمل، أيضا من عملية أمر لوحة جولة تبديل يأخذ بدء URL حد تحديد في واحد عملية دورة الحياة.

**زيادة logout،TLS بديل إدارة و تحويل إرسال header إعداد.** loopback Web تطبيق و قد تقرير إبلاغ إقرار إثبات نقص فتحة كل لا حاجة هذه قدرة؛ إضافة دخول هو جمع سوف في لا يوجد حالي consumer وقت تعريف نشر اتفاق. متصفح محطة نقطة بيانات تحكم سوف سحب إلغاء مفرد عدد متصفح جلسة؛ حذف اعتماد سجل و إعادة بدء عملية سوف سحب إلغاء الكل جلسة.

## عاقبة

يحتفظ متصفح cookie حينئذ قدرة استدعاء كامل أداة نوع Host API، هذا و Web تطبيق في إنشاء Session بعد كشف authority متسق.`Host` لا منح إعطاء أكثر عال طريقة طبقة درجة، طريقة في API Proxy و Typert Remote بين ترحيل أيضا لن تغيير استدعاء من تجميع دمج.

حمل دائم مفتاح جعل cookie عبر إعادة بدء توليد فاعلية، أيضا يجعل يتم سرقة cookie الأكثر كثير حفظ لديه إعداد قطعا مقابل صالح مدة. حذف سجل و إعادة بدء عملية هو عام سحب إلغاء آلية؛ حالي Connection لحظة معنى تجنب تجنب في كل طلب فوق وصول اعتماد مزود. لا ضبط `Secure` إبقاء loopback HTTP، لكن إذا عملية من يجعل نفس cookie authority مرور لم إضافة سري شبكة شبكة يمكن بلوغ،cookie سوف بـ واضح نص نقل. بدء URL يحتوي عملية اعتماد، يجب نظر لـ حساس شعور إخراج؛ وقت التشغيل تشخيص لن تكرار هو.

هذا قرار جزء يحل محل[متصفح معلومة مهمة شرح](2026-07-28-api-browser-trust-boundary.zh.md) في إقرار إثبات تأجيل و لم إقرار إثبات غير loopback عاقبة. هذا شرح ما زال هو وسيط جسم نوع،Host،Origin،Fetch-Metadata و إعداد authority تحقق صالح مرجعي. لا يوجد active Agent Note يتم عودة ملف: إعادة تراكم فقط حدوث في نطاق جزء، اثنان بند أمان قاعدة كل حفظ لديه لم قدوم قرار قيمة قيمة.
