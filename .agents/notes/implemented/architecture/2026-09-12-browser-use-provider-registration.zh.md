# Agent Note: متصفح عملية مزود تسجيل و Session كل حق

Status: implemented

[English](2026-09-12-browser-use-provider-registration.md) | العربية

## مشكلة

متصفح تحكم خلفية كشف مختلف عملية و مراقبة قياس صيغة. في يمكن نقل غرس مستهلك وجود قبل، عام متصفح حركة عمل API سوف قيد هذه فعلي تحقق. متصفح جلسة يمكن عزل، بينما مرفق إضافة قائم قد تسجيل تسجيل متصفح يجب إبقاء ذلك حالة، و منع توقف واحد مزود داخل ظهور تزامن كل حق.

## قرار

[`dsh-browser-use`](../../../../packages/browser-use/browser-use/README.zh.md) يملك `ctx.browserUse`، تسجيل واحد مزود يملك اسم و إرجاع ذلك effect تنظيف جهاز. ثاني مرة تسجيل بلا نقاش اسم لـ أي كل سوف فشل. خدمة لا يتضمن متصفح كائن، مشترك عملية نوع، قسم إرسال طريقة، مورد دورة الحياة أو وقت التشغيل اختيار جهاز.[حساب حساب آلة عملية تسجيل قرار](2026-09-12-computer-use-provider-registration.zh.md) ما زال مستقل يملك طاولة وجه مزود تسجيل و مشترك طاولة وجه تنسيق ضبط قاعدة.

[Playwright MCP](../../../../packages/experimental/browser-use-playwright-mcp/README.zh.md) ،[Chrome DevTools MCP](../../../../packages/experimental/browser-use-chrome-devtools-mcp/README.zh.md) و[أصلي Stagehand](../../../../packages/experimental/browser-use-stagehand-native/README.zh.md) يملك ذاتي ذات متصفح أداة، و عبر معتاد قاعدة DSH أداة إدارة خط تجميع صار. هو جمع هو عام مشترك فعلي تحقق صفة اختياري وظيفة.DSH يملك مهمة قاعدة تخطيط و مهمة حلقة؛Stagehand توفير مفرد بند AI(شخص عمل ذكي) مساعد مساعدة عملية.Profile أو preset إعداد لـ كل مرة مزود تنشيط اختيار بدء أو مرفق إضافة نمط.

متصفح مورد يخص تأكيد قطع فوري Agent و Session، بينما غير فقط سند يمكن إعادة استخدام Session id. استدعاء عبر جولة إبقاء حالة. وقت التشغيل تحرير سوف إغلاق بدء مورد، إعادة تحميل أو fork لن وراثة بدء profile. مرفق إضافة إبقاء قائم متصفح حالة، و في هذا مزود نسخة داخل سوف خارجي متصفح وحيد احتلال إبقاء إعطاء واحد Session. تنظيف قطع فتح اتصال بينما لا إغلاق خارجي متصفح.

[فعلي تحقق صفة وقت التشغيل مساعد مساعدة مكتبة](../../../../packages/experimental/browser-use-runtime/README.zh.md) يملك مشترك مورد دورة الحياة و مرفق إضافة إبقاء آلية، بينما لا نحو متصفح عملية خدمة جذب دخول هذه طريقة. إلغاء استدعاء جهة مقابل مورد نيل أخذ انتظار بعد، ابتدائي تحويل و ذلك إبقاء ما زال عودة Session كل. نشط حركة عملية استلام إلى Agent تحرير إلغاء إشارة وقت، في Agent انتظار فارغ خامل قبل بدء مورد إغلاق، لأن متصفح استدعاء ممكن فقط لديه في اتصال إغلاق بعد عندئذ قدرة انتهاء. مزود تنظيف إيقاف استقبال أداة استدعاء، و إبقاء تسجيل، مباشر إلى مورد تنظيف و نشط حركة استدعاء إتمام. خدمة إبقاء مستقل في كل فعلي تحقق حزمة.

Stagehand بدء جهاز وراثة ذلك عملية بيئة،SDK ابتدائي تحويل ممكن في تنظيف إتمام قبل مهلة. مزود Host استخدام `@puppeteer/browsers` في CDP أو SDK حينئذ خيط قبل أخذ نيل الذي بدء Chromium و ذلك مؤقت profile كل حق، و تنظيف عملية فرعية بيئة. بدء و مرفق إضافة نمط كل من عزل Worker تشغيل SDK، كما فقط عبر CDP اتصال. أصلي دفع إدارة لا قبول abort signal.SDK إغلاق سوف انتظار نشط حركة عمل؛ تنظيف نجاح بعد يمكن إعادة اتصال و إبقاء متصفح حالة.SDK عمل لم قدرة انتهاء وقت، فقط يلزم Chromium ما زال في تشغيل، حينئذ منع توقف إعادة استخدام. نهائي تنظيف يمكن في ذاتي لديه Chromium و Worker إنهاء بعد تحرير بدء متصفح احتلال استخدام. مرفق إضافة نمط تحت SDK عمل لم قدرة انتهاء،Worker إنهاء فشل أو ذاتي لديه عملية تنظيف فشل وقت، إبقاء احتلال استخدام.Host فقط إنهاء ذاتي ذات يملك Chromium عملية، انتظار عملية فرعية إغلاق بعد عندئذ حذف profile؛ خارجي يملك متصفح إبقاء تشغيل.

Stagehand استخدام صريح إعداد ثابت إصدار SDK دليل داخل أصلي نموذج. إعداد API مفتاح و اختياري طلب رأس سوف تحويل إرسال إلى متصفح توسيع، من Stagehand في توسيع داخل تنفيذ دفع إدارة. متصفح أداة إدخال و إرجاع بيانات استخدام قائم Session سجل، يشمل SDK نتيجة بيانات وصفية.DSH نموذج توجيه، اعتماد إعادة استخدام، قاع طبقة دفع إدارة طلب/استجابة التقاط، و و Session استخدام كمية حساب كمية تجميع صار ما زال تابع مؤقت مؤقت عمل؛ هذا تجميع صار لا زيادة حفظ دائم حدث أو Session schema تغيير.

MCP عميل تنشيط سوف انتظار اتصال و أداة اكتشاف، لكن مزود ممكن في أي Session وجود قبل حينئذ إتمام تنشيط. هذا تنشيط promise لا يمكن بديل جدول لم قدوم كل Session يملك عميل. كل MCP متصفح مزود في قائم سلسلة سطر `agent/created` حدث في انتظار مرة عميل بدء محاولة تجربة.[انتظار Agent إنشاء قرار](2026-09-09-awaited-agent-creation.zh.md) مسؤول ترتيب طابور إدخال ترتيب و إنشاء تراجع. إنشاء أو استعادة نجاح بعد، نص التوجيه تجميع و مباشر استدعاء جهة يكفي قراءة كامل دليل.

بدء فشل أو إلغاء سوف رفض إنشاء أو استعادة، و إطلاق Agent و ذلك عميل مورد تراجع. مرفق إضافة اتصال يتم احتلال استخدام وقت، هذا مرة تنشيط دائم دائم قفز مرور بدء، لكن أخرى عمل متابعة تشغيل؛ اتصال تحرير بعد، جديد إنشاء أو استعادة Agent يمكن نيل أخذ اتصال. مقارنة متأخر تثبيت و إعادة تحميل فقط أثر في لاحق تنشيط، و [Schedule تركيب سياسة](../../../../packages/schedule/schedule/README.zh.md#use-this-package) متسق. نجاح عميل متصفح أداة و مورد طلب مشترك Session طابور صف؛ أخرى Session لا يستطيع تنفيذ هذه طلب، أيضا لا يستطيع استلام إلى هذا خادم إشارة توجيه.

## اعتبار مرور بديل خطة

**موحد واحد متصفح حركة عمل API.** Playwright،Chrome DevTools و Stagehand أصلي دلالة مختلف. حالي لا يوجد مستهلك اشتراط يمكن متبادل تبديل حركة عمل طريقة، لذلك من مزود يملك أداة بـ إبقاء هذه دلالة.

**مزود ذاتي لديه بدء مرحلة مقطع.** قائم سلسلة سطر `agent/created` انتظار Session ذاتي لديه ضبط، و نحو إنشاء جهة تقرير إبلاغ فشل. مستقل صيانة مهمة سوف تكرار هذا نسخة دورة الحياة كل حق.

**في نص التوجيه تجميع خلال اكتشاف.** نص التوجيه و أداة استلام تجميع حاجة قد حينئذ خيط تسجيل. هذا وقت بدء اكتشاف يلزم ما كشف لا كامل دليل، يلزم ما اشتراط مجددا مرة استلام تجميع؛ انتظار إنشاء سوف في جولة بدء قبل إتمام اكتشاف.

**كثير عدد Session مشترك واحد متصفح.** متصفح وسم صفحة، تنقل و تسجيل تسجيل حالة يمكن حسب Session عزل. مشترك هو جمع سوف جذب دخول طاولة وجه تجميع صار عبر معتاد لا يمكن تجنب تجنب عبر Session جاف إزعاج.

**مرفق إضافة وقت إنشاء كل جديد context.** جديد متصفح context لا وراثة قائم تسجيل تسجيل حالة. وحيد احتلال استخدام مرفق إضافة متصفح يمكن إبقاء مرفق إضافة الذي دعم حمل سير العمل.

**مع Session استعادة متصفح profile.** حمل دائم متصفح حالة جذب دخول Session سجل خارج profile تخزين و ترحيل كل حق. بدء حالة فقط في فوري وقت التشغيل تخزين متابعة؛ خارجي يملك متصفح إبقاء ذاتي ذات حفظ دائم سياسة.

**فقط دعم حمل عزل بدء.** مستخدم حيث حاجة جاف صاف متصفح جلسة، أيضا حاجة وصول قائم هوية تحقق حالة. إعداد صريح اختيار كل حق سياسة.

**تفويض حمل متصفح agent.** هذه فعلي تحقق مقارنة مقارنة متصفح تحكم خلفية. سوف كامل مهمة تفويض حمل إعطاء آخر قاعدة تخطيط جهاز سوف تغيير DSH مقابل مهمة حلقة تحكم.

**DSH نموذج جسر وصل.** أصلي Stagehand إعداد جعل متصفح تجميع صار مستقل في DSH نموذج طلب ملائم إعداد و حفظ دائم.Session نموذج اختيار، اعتماد إعادة استخدام، قاع طبقة دفع إدارة التقاط و Session استخدام كمية حساب كمية بصفة واحد تنسيق ضبط تجميع صار مؤقت مؤقت.

## أثر

مزود مستقل عرض دخول ذاتي ذات أداة، بينما مشترك خدمة إبقاء فقط تسجيل اسم. ثلاثة عدد مزود و ذلك وقت التشغيل مساعد مساعدة مكتبة بصفة فعلي تحقق صفة حزمة إصدار، لكن لا في داخل وضع افتراضي إعداد في تفعيل. متصفح حزمة مجموعة لا اعتماد فعلي تحقق صفة وقت التشغيل شفرة.

مرفق إضافة إبقاء آلية أثر في مفرد عدد مزود نسخة؛ هو لا تنسيق ضبط مستقل DSH عملية أو خارجي متصفح عميل.Session إعادة وضع لا يتضمن متصفح حالة، إلغاء لن سحب إلغاء قد تسليم متصفح عملية. مزود README يملك جذب محرك دعم حمل، نموذج اشتراط و فوق تنقل حد.
