# Agent Note: يمين جانب Sidebar tab نوع و تنقل

Status: implemented

[English](2026-09-05-sidebar-tab-types-and-navigation.md) | العربية

## Problem

[توقف اعتماد وجه](../feature/2026-09-04-right-sidebar-docking-infrastructure.ar.md) إعطاء يمين جانب Sidebar قسم شريط،tab و طفو حركة وجه لوح، لكن واحد إطار tab فقط لديه في آخر إضافة قدرة نحو داخل وضع محتوى وقت عندئذ لديه استخدام. هذا حاجة ثلاثة نسخة توقف اعتماد وجه ذاته لا تعريف عقد نحو: إضافة مثل أي إعلان واحد نوع tab و ذلك قدرة عرض عنوان؛ أي استدعاء جهة——جلسة منطقة داخل إنتاج خروج ملف chip، ملف شجرة داخل واحد سطر، إضافة ذاتي ذات حسب زر——مثل أي طلب Sidebar عرض بعض مثال شرق غرب؛ و tab متن في وقت التشغيل قدرة اعتماد ماذا. كل واحد نسخة كل هو مستودع خارج إضافة سوف قدوم يلزم مقابل حال كتابة عام وجه، الذي بـ يجب في ذلك بعض إضافة ظهور قبل تحديد تحت قدوم: بعد تعديل واحد حقل اسم، واحد قطعة رفع قيمة أو عنوان لغة قاعدة، حينئذ سوف معا فعل تالف هو جمع الكل.

اثنان بند قيد قرار جواب سجل. حركة حالة عميل إضافة بين لا سماح مرجع وقت التشغيل قيمة——دالة، معتاد كمية، صنف——فقط قدرة جذب نوع، لذلك هذه عقد نحو داخل لا نيل اشتراط من Sidebar حزمة جذب دخول مساعدة مساعدة دالة أو توجيه خروج معتاد كمية. بينما Web عميل قد لديه واحد طقم مكون نموذج، أي Slot نظام؛ مجددا لـ tab صنع واحد طقم، حينئذ هو ثاني عدد يلزم تعلم يلزم صيانة و سطر إطار هيكل.

## Decision

tab نوع هو نحو `ctx.sidebarRightTabs` مرة ساكن حالة تسجيل؛tab متن و عنوان هو عادي keyed Slot تسجيل؛`ctx.sidebarRight` فقط بـ اثنان نوع طريقة فتح محتوى——حسب عنوان فتح مورد، حسب kind فتح صفحة——ذلك بقية فقط عملية تخطيط؛ متن عبر إطار هيكل حقن `useTabInfo()` قراءة نسخة معلومة. تحت وجه حسب إضافة عمل من لقاء إلى ترتيب وصف هذا أربعة عدد وجه.

### نوع سجل التسجيل:`ctx.sidebarRightTabs`

`register(definition): () => void` سجل واحد نوع tab نوع و إرجاع ملاحظة إلغاء جهاز، استدعاء جهة يأخذ هو وضع دخول ذاتي ذات `ctx.effect`، في هو نوع عمر أمر تماما جيد انتظار في مساهمة هو إضافة. تعريف هو ساكن حالة:

```ts ignore-check
interface SidebarRightTabDefinition {
  readonly id: string                                   // this implementation's identity in the tab system
  readonly kind: string                                 // what the tabs of this type are; what openTab names
  readonly patterns?: readonly string[]                 // resource-address globs; omitted by a page type
  readonly priority?: 'extension' | 'builtin' | 'fallback'   // defaults to extension
  readonly canOpen?: (address: string) => boolean       // veto after a glob matched
  readonly title: (address: string) => string           // chip text, captured at open time
  readonly guide?: readonly SidebarRightGuideEntry[]    // entry boxes on the guide page
}
```

`id` و `kind` هو اثنان عودة أمر.`kind` هو نوع حكم آخر رمز——tab *هو ماذا*،`openTab` نقطة اسم ماذا،tab هوية من ماذا بنية صار.`id` هو بعض عدد kind واحد*تنفيذ*هوية، في الكل تسجيل داخل وحيد، حزمة اسم هو ذاتي لكن أخذ قيمة. اثنان من قسم فتح هو لأن kind و لا وحيد:`extension` يمكن تسجيل واحد `builtin` قد يحتفظ kind، اثنان عدد تنفيذ مع أي في سجل التسجيل داخل مشترك تخزين، توليد فاعلية هو extension. سجل التسجيل رفض تكرار `id`، نفس kind في نفس ملف ثاني مرة تسجيل، و أي و نفس kind `fallback` متبادل لقاء تسجيل؛ هو فقط قبول extension ضغط builtin هذا واحد مقابل،extension ملاحظة إلغاء بعد builtin استعادة.

`patterns` هو مورد عنوان فوق glob، استخدام `picomatch` حسب VS Code تحرير جهاز محلل قاعدة مطابقة، فقط لديه واحد موضع محلي تعديل: يحتوي `:` pattern مطابقة كامل عنوان (`dsh-resource://file/**`) ، لا يحتوي مطابقة URI مسار كما مهمة معنى عميق درجة (`*.md`) ، مطابقة لا منطقة قسم كبير صغير كتابة، لا إخفاء dotfile، لا هو URI عنوان لا مطابقة أي مسار pattern. صفحة نوع——جذب توجيه صفحة، ملف شجرة——لا تعرف آخر أي عنوان، حذف `patterns`، حسب kind فتح.

`priority` هو ثلاثة عدد حرف وجه كمية ملف موضع لـ واحد، كتابة صار نص، جيد يجعل آخر حزمة نوع لا حاجة أي وقت التشغيل جذب دخول:`extension` هو قدوم ذاتي منتج خارج نوع ملف موضع أيضا هو الأكثر عال ملف، الذي بـ ماذا كل لا إعلان نوع ضغط مرور هذا داخل مع حزمة تسليم كل فحص نظر جهاز؛`builtin` هو مع حزمة نوع معتاد قاعدة ملف؛`fallback` هو أي أكثر أداة جسم شرق غرب كل ينبغي ضغط مرور صاف محتوى موضع،VS Code نص تحرير جهاز خفي يحتوي أرض احتلال حسب هو، أنا جمع نص معاينة واضح أرض احتلال حسب هو.`candidates(address)` إرجاع glob أمر في كما `canOpen` لم مرفوض كل نوع، حسب ملف موضع، مجددا حسب أمر في الأكثر طويل pattern طويل درجة، مجددا حسب تسجيل ترتيب ترتيب ترتيب.`claim(address, kind?)` أخذ الأكثر جيد مرشح، أو في استدعاء جهة إشارة تحديد وقت أخذ هذا kind توليد فاعلية نوع (لا فحص هو glob؛ نقطة اسم أي قرار) ، مقابل بلا شخص رغبة فتح عنوان رمي خطأ——هذا هو وصل خط خطأ، لا هو مستخدم خطأ.`get(kind)` إرجاع توليد فاعلية نوع؛`entries()` و `guide()` صف خروج توليد فاعلية نوع و ذلك جذب استيراد فتحة؛`subscribe` مراقبة تغير.

`title(address)`،`guide[].title()` و اختياري `guide[].description()` كل هو كل مرة استخدام وقت إعادة قراءة thunk، لغة تبديل بلا حاجة إعادة تسجيل.[جذب توجيه بدء بداية صفحة و موحد حساب pill دقيق تحويل](../feature/2026-09-10-guide-start-page-and-stat-pill-refinements.ar.md) مسؤول حالي وصف عرض و التقاط قاع رسم علامة قاعدة. سجل التسجيل ذاته هو `apply` قمة طبقة توفير عادي كائن،**لا حمل** `Service.tracker`:tracker سوف يأخذ `this.ctx` إعادة ربط إلى استدعاء جهة سياق، عبر حزمة `register()` حينئذ سوف في استدعاء جهة fiber ما زال هو نشط حركة أثر مجال وقت نحو هو فوق إضافة effect، متصفح بدء سوف بلا صوت بطاقة ميت.

### متن و عنوان: حسب تعريف `id` keyed Slot حفرة موضع

نوع سجل التسجيل قول نوع هو ماذا؛Slot نظام قول هو طويل ماذا مثال. نوع يأخذ متن تسجيل دخول keyed،session أثر مجال حفرة موضع `sidebar.right.pane.tab`، مفتاح هو ذاتي ذات `id`، و يمكن يأخذ عنوان مكون تسجيل دخول `sidebar.right.pane.tab.title`، مفتاح نفسه. رسم tab مقعد موضع مرور سجل التسجيل يأخذ tab `kind` تحليل صار توليد فاعلية نوع، مجددا إرسال إرسال إلى هذا نوع `id`، في هو extension وصل إدارة builtin kind وقت اثنان عدد حزمة متبادل لا معرفة معرفة أيضا قدرة صحيح تأكيد تصيير، كما لا يوجد أي أولوية درجة عدد حرف عبر مرور حزمة حد. لا يوجد توليد فاعلية نوع kind تصيير تابع رئيسي «لا يوجد شرق غرب قدرة فحص نظر هو» تلميح؛ لا تسجيل عنوان نوع نيل إلى سجل التسجيل في فتح وقت التقاط `title(address)` نص.

آخر لديه اثنان عدد حفرة موضع توسيع جذب توجيه و قائمة مفرد:`sidebar.right.tab.guide` هو chain، رقم واحد لا رفض بند في لا استبدال tab قبل رفع تحت استبدال مع حزمة جذب توجيه متن؛`sidebar.right.tab.menu.item` هو list، إلحاق في مكتبة ذاته تخطيط حركة عمل بعد، وضع و tab محتوى لديه صلة حركة عمل. نوع ذاتي ذات تحكم عنصر——إعادة تحميل، تبديل سطر فتح صلة——إقامة في ذاتي ذات متن داخل؛tab بند يخص وجه لوح، فقط وضع وجه لوح تحكم عنصر. نوع ذاتي ذات حالة هو متن تسجيل فوق عادي Slot store و inject وجه؛ إطار هيكل لا إعطاء مكون نموذج إضافة أي شرق غرب.

### وسم نسخة معلومة

[استجابة صيغة Sidebar و وسم معلومة](2026-09-07-sidebar-responsive-tab-info.ar.md) يحل محل هذا سجل في بـ مستو فرش owner props نقل تمرير نسخة معلومة اختيار. متن، عنوان و جذب توجيه صفحة استبدال بند استقبال إطار هيكل حقن `useTabInfo()`، بـ `{ sidebar, panel, tab }` قراءة الذي تابع Sidebar، نافذة إطار و وسم. نسخة سجل، تنقل، مرئي صفة،signal و ربط حركة عمل متساو في `tab` داخل؛ دقيق حقل رؤية [Sidebar مشاركة اعتبار](../../../../docs/subsystems/sidebar-right.ar.md).

وسم مجال ما زال لـ كل قد إيداع سجل يملك واحد نسخة، يشمل `AbortController`، تنقل لقطة و ربط إلى الذي تابع Session حركة عمل. سجل تخزين نشط خلال، ذلك عنوان يتم تثبيت في[مورد نموذج](2026-09-05-client-resource-model.ar.md) في؛ إخفاء و تبديل Session لا انتهاء نسخة، إغلاق سجل فإن في توقف و تحرير هو. إطار هيكل قد لديه تخزين و تنقل خطاف توفير فوري قراءة، نوع لا ذاتي سطر حجز قراءة.

### تنقل:`ctx.sidebarRight`

هذا وجه بـ اثنان نوع طريقة فتح محتوى، مقابل محتوى لا فعل آخر أمر:

```ts ignore-check
openResource(address: string, options?: { kind?: string; params?: SidebarRightResourceParams; paneId?; replaceTab?: TabId; revealIfOpened?: boolean }): void
openTab<K extends string>(kind: K, options?: { params?: SidebarRightTabParamsFor<K>; paneId?; replaceTab?: TabId; revealIfOpened?: boolean }): void
```

`openResource` وصل واحد مورد عنوان——`dsh-resource://<type>/…` URI، مورد نموذج فقط لديه scheme——و سؤال سجل التسجيل من قدوم عرض: لا حمل `kind` وقت سؤال مرة كل نوع من ترتيب ترتيب قرار؛ حمل `kind` وقت من هذا نوع توليد فاعلية تنفيذ فتح. ذلك هو scheme عنوان و بلا شخص إقرار قيادة عنوان مشي نفس بند فشل مسار.`openTab` حسب kind فتح صفحة نوع، دائم بعيد رؤية لا إلى عنوان:Sidebar يأخذ هذا tab تسجيل حساب في `sidebar://<kind>` تحت، هذا عدد حرف وجه كمية فقط في حزمة داخل واحد موضع تجميع تركيب، لـ هو صفحة tab و ذلك هو tab واحد مثال لديه `contentId` توفير هوية و تاريخ استخدام. هذا عدد scheme فقط هو تسجيل حساب: لا يوجد استدعاء جهة تجميع هو، عمل خدمة حزمة داخل لا يوجد هذا عدد حرف وجه كمية، ملف شجرة و جذب توجيه صفحة قسم آخر بـ `openTab('files')`،`openTab('guide')` فتح.

اثنان نوع فتح مشي نفس مثال أربعة خطوة: تحليل نوع (حسب ترتيب ترتيب أو حسب kind) ؛ حذف غير `revealIfOpened` لـ `false`، لا فإن حسب `(kind, contentId)` تحديد موضع قد لديه tab؛ سقوط موضع——سقوط في `replaceTab` إطار و بند موضع،`paneId`، أو نشط وثب إطار؛ يأخذ توسيع، فتح أو تجمع تركيز، و `replaceTab` إغلاق تسجيل لـ واحد بند تاريخ، مجددا يأخذ `{ address, params }` تسليم إعطاء tab مجال. سقوط موضع هو استدعاء جهة أمر، من لا هو نوع درجة خاص صفة: ملف شجرة يأخذ ملف فتح دخول ذاتي ذات إطار هو لأن هو ذاتي ذات قول، صحيح مثل VS Code Explorer ذاتي ذات نقل `SIDE_GROUP` أو `ACTIVE_GROUP`.`replaceTab` فقط لديه واحد يحتوي معنى——في ذلك عدد tab موضع فتح و في نفس خطوة صلة إسقاط هو——لـ هو جذب توجيه صفحة مدخل إطار يأخذ ذاتي ذات tab تسليم إعطاء الذي نقطة صفحة.

معامل حسب يتم فتح شرق غرب تحديد نوع، مرور Sidebar حزمة إعلان، من مفتاح يملك من زيادة تكملة اثنان ورقة يمكن إعلان دمج جدول:

```ts
interface SidebarRightResourceParamsMap {}   // key: resource type — the text preview declares { line?: number }
interface SidebarRightTabParamsMap {}        // key: kind — a page type declares its own shape, or nothing
```

`openResource` قبول كل قد إعلان مورد شكل حالة ربط دمج،`openTab<K>` قبول لـ `K` إعلان شكل حالة؛ متن حسب ذاتي ذات الذي خدمة بروتوكول أو kind استلام ضيق `navigation.params`. معامل يخص مورد نوع بينما غير فحص نظر جهاز، لأن سطر رقم هو صلة في ملف موضع واقع، لا هو صلة في نص معاينة، أي إقرار قيادة `file` عنوان نوع استلام إلى نفس شكل حالة. قيمة يجب يمكن JSON تسلسل تحويل، واحد بند سجل يجب فقط سند عنوان و معامل حينئذ قدرة إعادة بناء، لأن سحب إلغاء، إعادة فعل، تحديث جديد و HMR كل في فتح بدء جهة قد لا في وقت إعادة بناء tab.

حذف اثنان نوع فتح خارج، هذا وجه أيضا لديه `close(tabId)`،`active()`،`isExpanded()`،`toggleExpanded()`، و أربعة عدد عملية نوع طريقة——`focus(tabId)`،`split(paneId?)`(إرجاع جديد إطار، ميزانية أو عرض درجة قاعدة لا سماح قسم شريط وقت إرجاع `undefined` كما لا تسجيل حساب) ،`float(tabId, rect?)` و `dock(paneId)`——كل تسجيل واحد بند تاريخ، هدف لا وجود أو قد في هدف حالة وقت لـ no-op. لا يوجد تخطيط لقطة، لا يوجد حجز قراءة، لا يوجد حسب عنوان فحص بحث: هذا وجه إعطاء هو مقابل تخطيط تحكم حق، لا هو تخطيط عرض. مقعد موضع تركيب خلال إصدار ذلك ربط——ذاتي ذات جلسة، ذلك store action و ذلك وجه؛ عام وجه فوق أمر أثر في قد تركيب جلسة، لا يوجد قد تركيب جلسة وجه وقت رمي خطأ.tab ذاتي ذات حركة عمل فإن وصول ذلك جلسة ذاتي ذات store:slot وقت التشغيل كل جلسة صب واحد store، إضافة في صب خروج وقت تدريجي عدد استلام رعاية، تحكم جهاز حسب جلسة id توجيه، لذلك مستخدم تبديل جلسة بعد إطلاق حركة عمل وفق مثال سقوط أرض، بينما store من لم صب خروج جلسة ماذا أيضا لا فعل.

### عنوان

عنوان قسم اثنان عائلة، دائم لا خلط استخدام. مورد عنوان هو مورد نموذج `dsh-resource://<type>/…` URI(مساحة العمل ملف هو `dsh-resource://file/session/<sessionId>/<متبادل مقابل هذا جلسة مساحة العمل أصل مسار>`، مهمة معنى ملف هو `dsh-resource://file/absolute/<قطعا مقابل مسار>`، كل من `dsh-util-workspace-path` بنية صنع و تحليل) ؛ هو جمع هو `openResource` دخول مشاركة،`patterns` مطابقة كائن،`useResource` قراءة كائن. تنقل عنوان تسمية هو صفحة بينما غير بيانات؛ اليوم يوم وحيد واحد نوع هو صفحة tab تسجيل حساب استخدام داخلي `sidebar://<kind>`. فقط لديه مورد عائلة هو عقد نحو: تنقل عائلة في Sidebar داخلي تجميع تركيب و إزالة استهلاك، أكثر كامل تنقل بروتوكول هو بعد قرار، هذا قرار عبر يأخذ كل تنقل حرف وجه كمية إبقاء في واحد موضع لـ هو مسبق إبقاء فضاء.

### مدخل

جلسة منطقة `openFile(path, { line? })`——أداة سطر مسار رابط، إنتاج خروج ملف chip، استلام ذيل رسالة رفع و——يأخذ مسار تحرير رمز لـ هذا Session ملف مورد عنوان و استدعاء `openResource`، استدعاء جهة معرفة طريق سطر رقم وقت حمل `params.line`؛`read` أداة سطر نقل دخول ذلك `offset` معامل بدء بداية سطر.tab بند «+» لـ الذي في إطار استدعاء `openTab('guide', { paneId, revealIfOpened: false })`؛ جذب استيراد فتحة إطار استدعاء `tab.actions.openTab(entry.kind, { replaceTab: true })`؛ ملف شجرة واحد سطر استدعاء `tab.actions.openResource(address)`، سقوط في شجرة ذاتي ذات إطار داخل.

## Alternatives considered

**استخدام chain حفرة موضع إرسال إرسال tab، أو فقط استخدام keyed حفرة موضع.** chain `select` غير ممكن قطعة رفع، بينما جذب توجيه صفحة و تنقل وجه يجب قطعة رفع نوع؛keyed حفرة موضع فقط حمل متن، نوع عنوان و عنوان تعرف آخر بلا موضع يمكن إقامة. اثنان مقطع——تعريف سجل التسجيل إضافة keyed مكون حفرة موضع——هو مستودع قائم نمط (`ConversationViewRegistry`).

**وقت التشغيل hook أو كل tab واحد نسخة كائن.** ورق وجه فوق تجربة مرور كثير نوع شكل——كل tab واحد Cordis fiber، سحب كائن أساس صنف، إرجاع حمل `dispose` نسخة `initial`/`create` مقابل، واحد مجموعة `useTab*` hook، إطار هيكل حمل إدارة `useTabResource(fetch)`،`useTabStream`. اعتماد مرة مرفوض: كل tab واحد fiber جدا إعادة؛ حركة حالة حزمة لا يمكن مشترك أساس صنف أو توجيه خروج معتاد كمية؛ نسخة طبقة تكرار Slot store و inject وجه قد هو شرق غرب؛ كل tab hook تكرار وصف owner props؛ إطار هيكل حمل إدارة fetch لا يوجد جيد ذاكرة مؤقتة مفتاح؛tab مجال فوق تدفق hook سؤال خطأ رئيسي شخص——حديث يوم بيانات يجب قدوم ذاتي حديث يوم مجال، ملف بيانات قدوم ذاتي مساحة العمل ملف خدمة. باق تحت هو owner props إضافة واحد كل عميل `useResource`.`visible` بعد قدوم بـ prop بينما غير hook إضافة دخول أيضا هو نفس إدارة من: هو هو صلة في هذا مرة ظهور أيضا واحد واقع، بينما props قد تحمل تحميل هذا مرة ظهور. مقابل نسخة قراءة خطاف مرفوض من[وسم معلومة قرار](2026-09-07-sidebar-responsive-tab-info.ar.md) يحل محل؛ مقابل مستقل نسخة كائن،fiber و بيانات تدفق كل حق إدارة من ما زال ملائم استخدام.

**كل إطار واحد أداة منطقة حفرة موضع وضع نشط وثب tab تحكم عنصر (`sidebar.right.pane.tab.tools`).** فوق خط واحد جولة مراجعة بعد حذف: هو يأخذ نوع خاص حسب زر وضع إلى وجه لوح tab بند فوق، و قسم شريط و استلام بدء تحكم عنصر و صف، قراءة بدء قدوم مثل وجه لوح chrome. نوع تحكم عنصر يخص ذاتي ذات متن.

**نوع درجة سقوط موضع (`opensInto`) و إخفاء متبادل مجاور إطار بدء إرسال صيغة.** مرفوض:tab سقوط في أي هو فتح بدء جهة أمر، صحيح مثل VS Code Explorer ذاتي ذات قرار `sideBySide`.

**توسيع اسم قائمة و عدد حرف أولوية درجة.** `claims.extensions` جدول بلوغ لا `.d.ts`،`Dockerfile`، دليل قيد أو كامل scheme——هو هو تراجع تحويل glob؛ عدد حرف أولوية درجة حاجة حركة حالة حزمة لا يمكن جذب دخول توجيه خروج معتاد كمية. حرف وجه كمية ملف موضع إضافة glob.VS Code ذاتي ذات ملف موضع من خمسة عدد استلام صار ثلاثة عدد:`option` ملف (فقط صف خروج، دائم لا تلقائي اختيار في) في «استخدام أخرى طريقة فتح» وجود قبل لا يوجد إزالة استهلاك من،`default` ملف تعديل اسم `extension`، لأن ذلك عدد اسم حرف قراءة بدء قدوم مثل الأكثر منخفض ملف بينما هو هو الأكثر عال ملف.

**واحد `open(address)` حزمة ضرب يوم تحت، خارج إضافة تجميع صفحة عنوان مساعدة مساعدة دالة.** رقم واحد إصدار صفحة أيضا حسب عنوان فتح، في هو عمل خدمة حزمة حاجة `sidebar://<kind>` حرف وجه كمية أو قدوم ذاتي Sidebar حزمة `sidebarAddress(kind)` مساعدة مساعدة دالة. اثنان من كل يتم قيمة مرجع قاعدة منع توقف، أيضا كل تسرب كشف بعد لم تصميم تنقل scheme. يأخذ وجه تفكيك صار `openResource` و `openTab`، وحيد حرف وجه كمية إبقاء في حزمة داخل، كما كل نوع نمط كل منها تحديد نوع معامل.

**فتح وقت نقطة اسم بعض عدد تنفيذ (`?impl=`) ،`find(address)`،`mode()`/`setMode()`، تخطيط لقطة،`features` بيان.** كل اعتبار مرور و إبقاء في خارج وجه. نقطة اسم تنفيذ يخص بعد لا وجود تنقل بروتوكول؛`find` و لقطة سوف يأخذ هذا وجه تغيير صار تخطيط عرض، بينما هو هذا هذا هو مقابل تخطيط تحكم؛ عرض نمط هو UI فتح صلة لا هو إضافة صلة قلب أمر؛ قدرة بيان في هذا وجه بعد في استلام جمع وقت لـ وقت مرور مبكر.

**استخدام Slot أولوية درجة جدول بلوغ extension وصل إدارة builtin، مع بعد هو سجل التسجيل صب صنع حفرة موضع مفتاح.** رقم مرة محاولة تجربة يجعل تغطية جهة مرور واحد توجيه خروج معتاد كمية بـ أكثر منخفض Slot أولوية درجة تسجيل متن——هذا هو حركة حالة إضافة بين قيمة مرجع، أيضا هو أخذ ثاني طقم قاعدة (Slot أولوية درجة) بديل سجل التسجيل قاعدة محطة منصة. ثاني مرة محاولة تجربة يجعل سجل التسجيل لـ كل مرة تسجيل صب واحد مفتاح و من `register()` إرجاع، هذا يأخذ تسجيل تغيير صار اثنان خطوة كما ترتيب حساس شعور رقص خطوة. يجعل تنفيذ ذاتي ذات إعلان `id`——لا بد ملء، وحيد، و هو تسجيل حفرة موضع الذي استخدام نفس عدد سلسلة——حيث لا حاجة معتاد كمية، أيضا لا حاجة صب مفتاح و ترتيب، أيضا إعطاء سجل التسجيل رفض تكرار الذي يحتاج هوية.

## Consequences

- واحد نوع = واحد ساكن حالة كائن + واحد إلى اثنان عدد keyed حفرة موضع تسجيل؛ ذلك نسخة معلومة عبر حقن `useTabInfo()` قراءة. إطار هيكل لا طويل أي حسب نوع API وجه، مستودع خارج نوع من Sidebar حزمة فقط جذب نوع.
- اثنان نوع فتح إعداد اثنان ورقة معامل جدول، معنى طعم حال استدعاء جهة لا يمكن فقط حسب عنوان فتح صفحة أو فقط حسب kind فتح مورد، تحرير ترجمة جهاز سوف شرح؛ بديل قيمة هو كل تفكير يلزم نوع تحويل معامل جديد مورد نوع أو صفحة kind كل يلزم زيادة تكملة واحد ورقة جدول.
- `id` و `kind` قسم مغادرة يجعل extension قدرة حسب kind أصل موضع استبدال مع حزمة نوع،extension ملاحظة إلغاء بعد builtin استعادة؛ بديل قيمة هو كل تعريف كثير واحد لا بد ملء حقل.
- تنقل وجه فقط لديه تحكم حق. حاجة معرفة طريق تخطيط إضافة لا يمكن بحث أخذ، هذا يجعل تخطيط شكل حالة في تنقل بروتوكول قرار كشف ماذا قبل لا دخول أي إضافة عقد نحو.
- `sidebar://<kind>` حرف وجه كمية إقامة في واحد ملف داخل. بعد تعديل تنقل لغة قاعدة فقط اصطدام Sidebar حزمة.
- هذه وجه هو Sidebar داخل يتم تحديد ميت جزء: عنوان، تسجيل حقل و ملف موضع، اثنان نوع فتح و ذلك معامل جدول،slot اسم و حقن وسم معلومة. مستخدم يرى واحد قطع سلوك——طفو نافذة لصق إلى أي، قسم شريط تحكم عنصر أي وقت وضع رمادي، نص سجل، شجرة ترتيب ترتيب——كل هو هذا داخل أي عقد نحو خارج منتج قاعدة، تعديل بلا حاجة إشعار أي إضافة.

## Testing

`ui-sidebar-right` spec تغطية سجل التسجيل (ملف موضع،extension ضغط builtin و استعادة،`id` و نفس ملف اندفاع مفاجئ،glob و مسار مطابقة،`canOpen`، ترتيب ترتيب و مستو نطاق) ، اثنان نوع فتح (صحيح معتاد، حد و فشل مسار، يحتوي خطأ scheme و لم تسجيل kind) ،`replaceTab` تسجيل واحد بند تاريخ، مقعد موضع يأخذ kind تحليل إلى توليد فاعلية تنفيذ و رجوع،`useTabInfo()` يحتوي طي و طفو نافذة تحت `tab.visible`، و عملية نوع طريقة no-op و رمي خطأ حال شكل.Web e2e طقم عنصر في Chromium داخل مرور حقيقي إضافة رسم قيادة جذب توجيه صفحة، ملف شجرة و مرة ملف فتح. اثنان طقم متساو بلا حاجة مفتاح.

## Deferred

- `sidebar://<kind>` خارج تنقل بروتوكول: صفحة داخل فرعي توجيه، نقطة اسم تنفيذ، و موجه إلى توليد حالة ذلك هو تنقل scheme قاعدة.
- من عام وجه نحو شاشة فوق جلسة خارج جلسة داخل فتح؛ عام وجه فقط أثر في قد تركيب جلسة، بينما tab ذاتي ذات حركة عمل قد أثر في ذلك الذي في جلسة.
- من جلسة منطقة فتح فشل وقت محلي تحويل تلميح؛ هدف قبل هو رمي خطأ نص ذاته.
