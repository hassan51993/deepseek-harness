# Agent Note: حالي profile إضافة إدارة مشترك CLI أمر خدمة

Status: implemented

[English](2026-09-14-current-profile-plugin-management.md) | العربية

## مشكلة

Web و Agent تحكم عنصر حاجة تعديل تشغيل في profile، معا تجنب تجنب آخر بناء حزمة تثبيت جهاز أو تغطية مستخدم تحرير كتابة YAML. ملف مستمع ممكن قراءة إلى تثبيت خلال كتابة في بين manifest، أيضا ممكن في يتم حذف إضافة بعد لم تحرير مورد وقت تقرير إبلاغ نجاح.

## قرار

[إضافة إدارة جهاز](../../../../packages/boot/plugin-manager/README.zh.md) و `dsh plugin` استدعاء نفس طقم مختلف خطوة حزمة عملية.launcher عبر صاف بيانات `ctx.profileContext` توفير profile و تحليل موضع، بدء وقت تركيب حزمة و استدعاء درجة overlay. مشترك دالة تركيب حالي ملف؛ هذا واجهة لا يتضمن عودة ضبط أو تعديل طريقة.CLI و service تعديل يحتفظ profile manifest كتابة قفل؛[DSH HMR](../../../../packages/boot/hmr/README.zh.md) عبر نفس طابور صف سلسلة سطر تنفيذ وحدة استبدال،Include تحديث جديد،profile إعادة تركيب و إدارة جهاز إعداد تغيير.HMR في ذاته ابتدائي تحويل وقت تسجيل profile استماع، انتظار تطبيق حينئذ خيط بعد مجددا معالجة تحرير.manifest إشعار فقط مقارنة مقارنة لديه ترتيب تركيب حزمة قائمة؛ فقط اعتماد حقل تغير لن إطلاق إعداد إعادة تحميل. نهائي YAML تركيب قرار هل تشغيل HMR، بدء جهاز لا تثبيت رجوع نسخة.pnpm في `hmr.runExclusive()` خارج تنفيذ؛ فقط لديه إعداد تغيير و Loader تحديث دخول هذا طابور صف.HMR لا نيل أخذ حزمة عملية كتابة قفل، لذلك تثبيت لن منع سد أخرى من ملف تغير إطلاق إعداد تحديث. كل مرة إعادة تحميل إعادة قراءة manifest، تركيب حزمة طبقة و مستخدم patch، معا إبقاء استدعاء درجة overlay أولوية درجة.

إعداد استماع افتراضي استخدام Chokidar كتابة مستقر فحص قياس. عادي تغير معالج سوف إسقاط 50 ms داخل ثاني عدد حدث، لذلك تنشيط بعد قيام أي مجددا مرة كتابة ممكن يجعل قبل تركيب حزمة متابعة تشغيل. مستقر بعد تسليم حدث سوف مراقبة نهائي ملف؛ ملف قيادة تحديث تحمل تحمل مستقر انتظار، مباشر إدارة جهاز أمر خدمة فإن لا حاجة. ارتداد اختبار عبر Chokidar حقيقي مواصفة تحويل مسار تسليم وصل متابعة تغير، تحقق اثنان عدد حالة متساو يتم تطبيق.

profile ملف إبقاء لـ حمل دائم حالة: بند فتح صلة فقط تعديل الأكثر بعد واحد بند رمز دمج بند id و وحدة اسم تأكيد تغطية بند في `disabled`، لا يوجد مطابقة بند وقت إلحاق، تركيب حزمة فتح صلة تعديل لديه ترتيب نص قائمة. تحديث اعتماد لن إعادة تنشيط إبقاء قد توقف استخدام تركيب حزمة.service حذف تركيب حزمة وقت، أولا تطبيق ذهاب إسقاط هذا تركيب حزمة إعداد، انتظار قديم fiber إتمام إزالة بعد مجددا حذف اعتماد. قد حفظ إعداد،pnpm إتمام حالة و وقت التشغيل تنشيط قسم آخر تقرير إبلاغ؛ فشل حذف إبقاء فعلي جزء حالة و تشخيص مسار، فشل أو يتم إلغاء تثبيت فإن استعادة هو لقطة profile ملف.

هذا توسيع[profile تركيب حزمة قرار](2026-08-05-profile-plugin-bundles.zh.md).startup profile إبقاء عملية تركيب،Desktop حزمة إدارة ما زال من shell يحتفظ.Web تحكم عنصر و صريح تفعيل Agent أداة استدعاء نفس service. إدارة عملية نحو استدعاء جهة إرجاع نتيجة، لا نحو تخزين نشط Agent إضافة رسالة. إنشاء صنع نمط تفعيل هذا Agent أداة؛base تركيب حزمة و أخرى داخل وضع مسبق ضبط افتراضي منع استخدام. صاف متصفح worker معاينة لا يوجد مضيف حزمة تثبيت جهاز؛ ذلك وحدة بديل إدارة جدول واضح رفض `execa` استدعاء، معا إبقاء إدارة وحدة لأجل بيان اكتشاف.

CLI استدعاء وراثة طرفية و إقرار إثبات بيئة؛service استدعاء إبقاء عملية فرعية اعتماد تنظيف و محدود تشخيص. إدارة نتيجة توفير رمز خطأ و معامل، من Web كلمة قاموس عرض نص سجل. إعادة تحميل قبل بعد مقارنة مقارنة entry،fiber، إعداد و تشخيص: لم تغير قد لديه لذا عائق إبقاء لـ تحذير إبلاغ، هذا مرة أثر إلى جديد لذا عائق جعل عملية فشل. صريح تفعيل هدف يجب نجاح تنشيط.

بناء مراجعة دفعة في نفس عدد profile كتابة قفل داخل تحديث pnpm 11 بعد لم قرار `allowBuilds` بند، و إبقاء غير متصل YAML. تخويل حسب دقيق تأكيد حزمة اسم حفظ دائم، لا اعتماد بلا شرط سماح نص برمجي سياسة. إعادة محاولة فقط قبول ما زال في انتظار مراجعة دفعة قائمة في حزمة اسم، لذلك مرور مدة طلب لا يستطيع تغطية لاحق رفض. حزمة تنظيف إبقاء مراجعة دفعة ضبط، لاحق إعادة محاولة يمكن إعادة استخدام تخويل بينما لا لا بد إبقاء جزء تثبيت اعتماد.service تقرير إبلاغ فقط تعلق و سياسة تغير.Agent أداة يمكن بديل جدول مستخدم تخويل؛ أداة شرح اشتراط مستخدم في محادثة في واضح نفس معنى، بينما service فقط تحقق انتظار مراجعة دفعة حزمة اسم. مراجعة دفعة رفض `allowBuilds` داخل مرساة نقطة و آخر اسم، تجنب تجنب مشترك YAML عقدة تغيير لم طلب إذن.

## اعتبار مرور بديل خطة

**من service بدء آخر عدد dsh عملية.** هذا سوف تكرار دورة الحياة تنسيق ضبط، أيضا لا يمكن تأكيد حالي Loader قد إتمام إزالة بعد عندئذ يجعل pnpm حذف ملف. مشترك عملية وحدة إبقاء مفرد واحد تنفيذ، معا يجعل استدعاء جهة يحتفظ كل منها عرض طريقة.

**فشل بعد استعادة قد لديه حزمة.** لا يمكن فقط سند أصل manifest يمكن اعتماد إعادة بناء حزمة إصدار، اعتماد شجرة و تثبيت نص برمجي فرعي أثر، لذلك قد لديه اعتماد و تثبيت نجاح لكن تنشيط فشل حزمة إبقاء أصل موضع. فشل أو يتم إلغاء تثبيت فقط استعادة pnpm تشغيل قبل لقطة manifest و lockfile نص ([جذب توجيه صيغة إضافة تثبيت](2026-09-15-guided-plugin-installation.zh.md)) ؛ قد تحت تحميل ملف إبقاء إلى تحت مرة حزمة عملية تنظيف لـ توقف.

**حزمة تحديث وقت حار استبدال شفرة المصدر وحدة.** إعداد تغير يمكن إعادة استخدام قد تحميل وحدة ذاكرة مؤقتة، استبدال قد تثبيت JavaScript فإن حاجة جديد عملية. استبدال قد لديه اعتماد سوف تقرير إبلاغ حاجة إعادة بدء.

## أثر

نفس profile يمكن عبر CLI،Web و أداة إدارة، عملية عبر ملف قفل تنسيق ضبط و إبقاء patch أولوية درجة. تشغيل صيانة شخص عضو حاجة أصل حسب تقرير إبلاغ ملف و تشخيص إصلاح فشل حزمة عملية.startup عملية يجب أولا إيقاف، عندئذ قدرة عبر CLI حذف ذلك تحميل حزمة. إدارة مكون تلقي حفظ حماية، لا يستطيع عبر service حذف.
