# Agent Note: What stays host-plane once presets own the agent plane

Status: implemented

[English](2026-08-10-host-plane-ownership-after-presets.md) | العربية

## مشكلة

[تدريجي جلسة agent preset](2026-08-03-per-session-agent-presets.ar.md) يأخذ كل واحد موجه إلى نموذج سطر نقل فوق agent مستو وجه، هذا بعد كل واحد موضع إصلاح كل هو واحد ما زال حسب نقل نقل قبل عالم حد كتابة صار قراءة نقطة.`tasks` لأن realm خارج preset سطر يلزم تحليل هو بينما نقل عودة مضيف؛`goals` لأن نفس مثال إدارة من من لم مغادرة فتح؛ بينما عند كل موجه إلى نموذج أداة كل تغيير صار أصل أولا مساهمة بعد، فرعي agent `toolFilter` أيضا قد يتم إصلاح جيد ([فرعي agent إضافة دخول أب جهة preset](../bug-fix/2026-08-10-child-agents-join-their-parent-preset.ar.md)).

أيضا لديه اثنان عدد قراءة نقطة ما زال محطة في هذا بند خط خطأ واحد جانب.

`dsh-token-meter` في مضيف جانب يتم منع استخدام، تعديل تعليق دخول كل preset `compaction` realm. هو لا قبول أي إعداد، كل مرة طي كل بـ `Session` بناء مفتاح، أيضا لا تسجيل أداة أو تلميح مقطع——لكن هو يملك `tokenUsage`،`contextPressure` و `contextBreakdown` ثلاثة عدد إسقاط وحدة، بينما `sessionProjections` هو واحد ورقة عملية درجة، لا يوجد أثر مجال قسم طبقة جدول. لذلك من بعض عدد preset داخلي تسجيل وحدة سوف بديل كل جلسة عمل جواب: واحد `minimal` جلسة هل عرض context meter، أخذ قرار في هذا مرة بدء بـ قدوم لديه لا يوجد**آخر**جلسة تعليق مرور `standard`؛ بينما فقط ركض مرور `minimal` عملية أصل هذا لا عرض.

لا يوجد إضافة دخول أي preset agent أيضا بلا شخص إشارة خروج. إضافة دخول هو واحد بند scope أب سلسلة رابط؛ نقص هو،`tools`،`system-prompt` و `skill` عرض كل تحليل إلى فارغ عام طبقة، نموذج ماذا أيضا استلام لا إلى——لا تقرير خطأ، أيضا لا يوجد فارغ دليل يمكن نظر، فقط هو واحد لا يمكن سطر حركة agent. يتم تفويض إرسال فرعي agent في preset وجود كامل مقطع وقت داخل كل هو هذا مثال تشغيل، بينما نفس عدد ثقب في كل واحد مبكر في preset مدخل نقطة فوق كل فتح حال.

## قرار

**meter يخص مضيف مستو وجه.** `dsh-token-meter` عودة إلى مضيف تجميع، و مغادرة فتح كل preset `isolate` خريطة، في هو `compaction-basic` و `tool-result-pruner` في ذاتي ذات realm داخلي تحليل إلى ذلك واحد نسخة مضيف نسخة.preset إبقاء realm و ضغط خلفية——preset اختيار هو هو agent هل ضغط، بينما لا هو هو token هل يتم حساب. هذا صحيح هو `tasks` و `goals` قد اعتماد حكم حسب، فقط هو هذا مرة ملائم لأجل واحد بسبب**إسقاط**لمس بلوغ وجه بينما لا هذا عودة preset كل Service: عند واحد وحدة فارغ قيمة و حقيقي قيمة لا يمكن منطقة قسم وقت، فقط يلزم هو تسجيل دخول ذلك ورقة جدول هو عملية درجة، هو حينئذ لا يستطيع هو تدريجي تجميع.

**لم إضافة دخول agent في اثنان عدد مختلف نقطة فوق يتم إشارة خروج اثنان مرة.** في إعداد اسم مفرد قبل رفع تحت،`AgentPresets` مقابل كل أثر مجال سلسلة طويل درجة لـ واحد حينئذ إصدار agent سجل واحد بند تحذير إبلاغ.invariant إعداد طقم فإن مباشر فشل——و كما حدوث في `system-prompt/assemble` بينما غير إصدار وقت، لأن واحد لم إضافة دخول agent في هو مقابل نموذج قول كلام قبل كل هو دمج قاعدة:`recompose` ربط صحيح هو هذا مثال واحد agent بصفة هو أول مرة رابط؛ بينما نص التوجيه تجميع هو وحيد سوف توفير agent أثر مجال استدعاء جهة، لذلك مضيف تجميع و معتاد إقامة تركيب كل صحيح تأكيد أرض سقوط في فحص نطاق خارج.

لديه ثلاثة موضع حد لا في هذا موضع إصلاح، بينما هو سجل في سوف عض إلى هو جمع أرض جهة: إسقاط key هل وجود لا يستطيع عند عمل تدريجي جلسة قدرة إشارة ([`dsh-session-projection`](../../../../packages/session/session-projection/README.ar.md)) ؛ يتم بديل معتاد إقامة بديل حد دائم لا عودة استلام، بينما ضبط صفحة تحرير كتابة مسار يأخذ هو تغيير صار كل مرة حفظ بديل قيمة ([`dsh-agent-presets`](../../../../packages/preset/agent-presets/README.ar.md)) ؛ عبر `cordis_mount` تعليق فوق مؤقت إضافة يخص تجميع بينما غير تركيب هو جلسة ([`dsh-tool-cordis`](../../../../packages/extensions/tool-cordis/README.ar.md)).

## اختبار

`apps/cli/tests/web-agent-presets.e2e.ts` في هذا ملف في أي preset تركيب**قبل**، في قد بدء Web تجميع فوق قراءة `ctx.get('tokenMeter')`——preset جانب meter سوف انتظار في `isolate` realm داخل، مقابل `ctx.get` غير ممكن رؤية، لذلك هذا مرة قراءة هو مرة كل حق تأكيد بينما لا هو تركيب ترتيب بارع دمج——مع بعد تأكيد واحد `minimal` جلسة لقطة حمل متساو ثلاثة عدد وحدة.

`packages/preset/agent-presets/tests/mount.spec.ts` تأكيد تحذير إبلاغ مقابل عار agent تماما جيد إطلاق مرة، مقابل قد إضافة دخول agent تماما لا إطلاق.`tests/invariant.spec.ts` تحمل تحمل سالب تحكم: لم إضافة دخول agent تجميع يتم رفض، بينما قد إضافة دخول agent تجميع و لا حمل أثر مجال مضيف تجميع كل عبر.

## اعتبار مرور بديل خطة

**يأخذ meter إبقاء في preset، تعديل لـ إعطاء إسقاط سجل التسجيل قسم طبقة.** هذا هو أكثر دقيق إصلاح قاعدة، بديل قيمة أيضا كبير نيل كثير:`snapshot`،`checkpoint` و رئيسي حركة قيادة كل حاجة مرة «جلسة → أثر مجال» تحليل، بينما بارد قراءة في لا يوجد api-proxy `presenterScopeFor` وقت و لا أداة تجهيز. متبادل مقابل في واحد تماما لا يوجد per-preset حالة Service، هذا لا صار مقارنة مثال، لذلك تعديل لـ يأخذ عبر فإن كتابة في سجل التسجيل فوق.

**مقابل لم إضافة دخول agent مرفوض إصدار.** كبير صوت فوز مرور ساكن صامت، سجل التسجيل أيضا دعم حمل هذا ما فعل——تزامن `agent/created` مستمع رمي خروج سوف يأخذ إنشاء كامل جسم تراجع. مرفوض إدارة من هو: في اسم مفرد خارج تجميع agent هو دمج قاعدة——`recompose` كتابة واضح هو مع بعد ربط ذلك عدد عار agent، بينما ACP جسر،SDK server و headless bundle كل سوف إنشاء واحد. مرفوض سوف يأخذ قدرة نقص فتحة تغيير صار مرة لذا عائق.

**يجعل إعداد طقم أيضا في `agent/created` موضع فحص إضافة دخول حال حال.** مرفوض: إصدار وقت قسم لا صاف تسرب إسقاط إضافة دخول و بعد عندئذ سوف يتم ربط agent، لذلك هذا فحص سوف رفض واحد بند قد كتابة واضح مسار. نص التوجيه تجميع قسم نيل صاف.

**أساس في نفس مثال إسقاط إدارة من، يأخذ `plan-mode` و `tool-todo` أيضا نقل مغادرة agent مستو وجه.** مرفوض: اثنان من تأكيد فعلي هو تدريجي preset قدرة، كما مقابل من لا استخدام هو جمع جلسة، ذلك وحدة حساب خروج حينئذ هو فارغ قيمة، بينما عميل هذا قدوم حينئذ حسب قيمة قراءة (`plan.active`، فارغ قائمة). فقط لديه فارغ قيمة و حقيقي قيمة لا يمكن منطقة قسم وحدة——meter——عندئذ يتم إجبار عودة مضيف كل.

## عاقبة

context meter يصبح تدريجي جلسة واقع، بينما لم يعد هو تركيب تاريخ دالة. بديل قيمة هو preset لا يستطيع مجددا اختيار لا فعل token تسجيل حساب؛ مع مرفق preset لا يوجد واحد هذا ما فعل،`minimal` الآن أيضا كتابة واضح هو وضع ترك هو تلقائي ضغط بينما غير تسجيل حساب.

ذلك بند تحذير إبلاغ هو بناء اقتراح صفة، لذلك إعطاء ACP أو SDK server مدخل إضافة فوق اسم مفرد نشر اعتماد لكن سوف بدء لا يوجد أداة agent——فقط هو كل agent سوف قول مرة، بينما لم يعد ساكن صامت.invariant فقط لمس بلوغ تركيب تحميل `dsh-invariants` تجميع، لذلك هو يأخذ صلة هو حزمة اختبار و تطوير مضيف، لا هو مع مرفق مضيف.
