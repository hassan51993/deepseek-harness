# Agent Note: أصلي Desktop يؤدي أمر خطأ استعادة

Status: implemented

[English](2026-09-15-desktop-native-fatal-recovery.md) | العربية

## Problem

استعادة وثيقة اعتماد مصير و preload، بينما هذه مكون لذا عائق ذاته حينئذ ممكن منع توقف تطبيق بدء. نفس مرة بدء فشل كثير عدد تقرير إبلاغ أيضا ممكن إخفاء غطاء أصلي تشخيص و ضرب قطع استعادة عملية.

## Decision

Electron في كل تطبيق عملية في توفير مرة أصلي يؤدي أمر خطأ محادثة إطار. واضح رئيسي نافذة إنشاء، وثيقة تحميل،preload، مصير،Web ابتدائي تحويل و خلفية فشل دخول هذا مسار. عادي طلب إبقاء نطاق جزء خطأ معالجة، مشترك Web إضافة إدارة جهاز مسؤول حزمة عملية فشل. مسبق مدة إلغاء و إغلاق لا دخول استعادة. لا عبر استهلاك وقت دفع قطع بطيء بدء لـ يؤدي أمر لذا عائق.

أول مرة تقرير إبلاغ في انتظار محادثة إطار قبل أخذ نيل عرض حق. لاحق تقرير إبلاغ إبقاء في سجل في.Electron تحكم منصة إبقاء كامل قد تقرير إبلاغ تشخيص. أصلي محادثة إطار لا يمكن تمرير، لذلك فقط عرض أول مرة تشخيص نهاية ذيل ثمانية سطر، و سوف يتضمن قطع قطع تلميح و إعادة تركيب بناء اقتراح كامل تفصيل حال حد لـ 1,200 عدد UTF-16 شفرة وحدة. محادثة إطار توفير خروج، إعادة بدء أو منع استخدام رقم ثلاثة جهة bundle بعد إعادة بدء كامل تطبيق. استعادة عملية انتظار Host إغلاق بعد، في قد لديه profile قفل داخل استدعاء مشترك app-boot `sanitizeProfile` دالة. هذا دالة استعادة استدعاء جهة إشارة تحديد bundle، و سوف profile patch إعادة تسمية لـ وحيد تجهيز نسخة، بلا حاجة تحليل patch، ابتدائي تحويل وقت التشغيل أو حذف تثبيت ملف. استدعاء جهة مسؤول profile إغلاق و ترتيب حذف تزامن كتابة؛ حالي إنتاج استدعاء جهة هو Desktop.home درجة patch إبقاء ثابت. صريح استعادة عملية فشل سوف مفرد وحيد عرض، لا حساب لـ آخر مرة تلقائي يؤدي أمر تقرير إبلاغ.

Web وثيقة إبقاء في أصل موضع. مضيف عودة ضبط مسؤول بدء فشل عرض، مشترك بدء صفحة إبقاء تحميل حركة رسم؛ عادي متصفح بدء ما زال عرض ذاته فشل تقرير إبلاغ. فقط لديه رئيسي تطبيق إطار هيكل يمكن فوق تقرير Web بدء فشل. خلفية حالة إبقاء في رئيسي عملية في، أصلي استعادة مباشر مسؤول منع استخدام الكل رقم ثلاثة جهة bundle.Desktop لا توفير profile إعادة وضع أو ينبغي عاجل استعادة وثيقة. خلفية يؤدي أمر لذا عائق يجب عبر أصلي استعادة عملية معالجة، لا في حالي عملية في إعادة محاولة.

هذا قرار يحل محل[قيام أي عرض نافذة قرار](2026-09-09-desktop-immediate-window-and-direct-start.ar.md) في استعادة صفحة و إعادة وضع سلوك؛ ذلك قيام أي عرض و مباشر بدء Host إدارة من ما زال صالح.[Web رقيق قشرة قرار](2026-09-10-desktop-web-wrapper.ar.md) مسؤول مشترك إضافة إدارة و أصلي profile دقيق تجهيز.

## Alternatives considered

Web نموذج حالة إطار اعتماد عميل ابتدائي تحويل، بينما ثاني نسخة استعادة وثيقة سوف زيادة مصير مورد و preload استعادة مسار. أصلي محادثة إطار في هذه مكون فشل وقت ما زال متاح. تلقائي إعادة وضع إعداد أو كل مرة تقرير إبلاغ كل إعادة بدء ممكن حذف مستخدم إعداد أو شكل صار إعادة بدء حلقة؛ صريح عملية إبقاء مستخدم تحكم حق.

**منع استخدام bundle، لكن إبقاء توليد فاعلية profile patch.** ضرر تالف patch أو إدراج دخول لذا عائق إضافة patch ما زال يمكن منع توقف بدء. إعادة تسمية إبقاء مستخدم أصلي محتوى توفير يد حركة إصلاح، معا سوف هذا طبقة نقل خروج بدء مرور مسار؛ وحيد تجهيز نسخة اسم إبقاء هذا قبل استعادة عملية تجهيز نسخة.

## Consequences

استعادة وظيفة لا يمكن تقرير إبلاغ Electron رئيسي عملية يتم إنهاء أو انهيار انهيار، ساكن صامت بدء تعليق بدء أيضا لا يوجد تلقائي مهلة تلميح. ضرر تالف home درجة patch في profile استعادة بعد ما زال سوف منع توقف بدء، حاجة يد حركة إصلاح. تجهيز نسخة في profile دليل في تراكم تراكم، لن تلقائي تنظيف؛ مستخدم في لم يعد حاجة وقت حذف. بلا فاعلية profile JSON ممكن منع توقف منع استخدام إضافة؛ عملية تقرير إبلاغ فشل بعد ما زال يمكن خروج و إعادة بدء. تحديد نحو دورة الحياة اختبار تغطية يؤدي أمر إشارة، إلغاء، أول مرة تقرير إبلاغ ذهاب إعادة و إغلاق ترتيب؛ لغة مسبق مدة سجل محادثة إطار تشخيص و عملية، بدء اختبار إبقاء عادي متصفح فشل عرض.
