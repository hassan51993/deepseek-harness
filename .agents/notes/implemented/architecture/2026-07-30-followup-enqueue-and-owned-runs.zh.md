# Agent Note: follow-up دخول طابور و ذاتي لديه تشغيل حد

Status: implemented

[English](2026-07-30-followup-enqueue-and-owned-runs.md) | العربية

## مشكلة

`Agent.followup()` سوف معرف واحد بند مستخدم رسالة و سوف ذلك ترتيب دخول طابور صف، لكن مفرد مرة follow-up و لا يملك مع بعد حدوث نشط حركة. في agent(ذكي جسم) تحت مرة دخول idle قبل،steering(في طريق جذب توجيه) ، حقن سياق، أداة متابعة سطر، استعادة و لاحق ترتيب طابور رسالة كل ممكن مشاركة و نشط حركة. لذلك،`MessageId` يمكن إثبات رسالة قد نيل inbox دقيق دخول، لكن لا يستطيع معرف أي واحد بند assistant رسالة أو أي واحد `turn/end` هو هذا إدخال نتيجة.

[one-send-one-turn قرار](../simplification/2026-07-17-one-send-one-turn.zh.md) قد في نواة قلب API في ترتيب حذف حسب send إرجاع إتمام جملة مقبض تصميم. كل هو يأخذ واحد بند نص التوجيه طلب و واحد جولة نتيجة إعداد مقابل بروتوكول طبقة و SDK طبقة، كل سوف في تحت تنقل شخص لـ بنية صنع هذا واحد ناقص علاقة. واحد حالما نشط حركة دقيق دخول أكثر كثير إدخال، هذا إعداد مقابل حينئذ سوف إنتاج اختلاف معنى، أيضا سوف يأخذ جولة آلية كشف لـ نص التوجيه درجة نتيجة.

## قرار

إبقاء `Agent.followup(message): void`، جعل ذلك فقط تنفيذ دخول طابور.`Agent.whenIdle()` و `agent/status` ما زال لأجل مراقبة كامل agent دورة الحياة؛ اثنان من كل لا تسوية مفرد بند رسالة.Inbox حمل دائم صفة سوف سجل قد معرف رسالة و ذلك دقيق دخول أو إلغاء، لكن لن يأخذ لاحق إخراج ملكية في هذا رسالة.

قاع طبقة SDK بروتوكول في دخول طابور نجاح بعد قيام أي بـ `{ messageId }` استجابة `session/prompt`. هو عبر `session.event` تدفق صيغة نقل حمل دائم واقع، عبر `session.status` إصدار كامل agent حالة تحويل، كما لا يتضمن `session.finished`. قاع طبقة عميل يمكن مراقبة هذا عودة تنفيذ و بعد idle، لكن لن استلام إلى نص التوجيه نتيجة.

فقط لديه واضح يملك واحد نشط حركة منطقة بين وقت، عال طبقة تلقائي تحويل API عندئذ إرجاع `RunResult`.TypeScript و Python SDK `run()` طريقة من قد إيداع رسالة حمل دائم inbox عودة تنفيذ بدء استلام تجميع، مباشر حتى كامل agent تحت مرة دخول `idle`؛ ذلك نهائي استجابة هو هذا منطقة بين داخل الأكثر بعد واحد بند قد إيداع assistant رسالة، بينما لا هو حسب بسبب نتيجة علاقة ملكية في قد إيداع نص التوجيه استجابة.Python SDK أيضا يأخذ أصل جلسة الأكثر بعد واحد جولة انتهاء سبب kind بصفة تشغيل درجة [`finish_reason`](../../archived/bug-fix/2026-08-11-owned-run-finish-reason.md) إرجاع، لكن لن سوف ذلك عودة بسبب في قد إيداع نص التوجيه. مفرد مرة CLI(أمر سطر واجهة) يملك متبادل ينبغي idle إلى idle منطقة بين. عزل فرعي agent تشغيل يمكن تقرير إبلاغ نتيجة، لأن استدعاء جهة يملك كامل فرعي درجة دورة الحياة، أي steering كل يخص هذا تشغيل.

ACP(Agent Client Protocol) يجب إرجاع بروتوكول قاعدة تحديد `stopReason`. ذلك جسر وصل طبقة مقابل كل ACP جلسة في نص التوجيه إجراء سلسلة سطر معالجة، و يملك من دقيق دخول إلى كامل Agent idle و لديه ترتيب تحديث تسليم منطقة بين. هو سوف صلة ربط دقيق دخول هذا قد تعرف آخر ACP رسالة جولة، لكن لن صوت تسمية منطقة بين داخل كل نشط حركة كل فقط من هذا رسالة جذب بدء. صلة ربط token حد أعلى ربط ذيل خريطة لـ معيار `max_tokens`؛ صلة ربط نموذج خطأ في نفس عدد تماما توقف مستقر حد رفض؛ بلا جولة slot و صريح ACP إلغاء أو dispose واحد مثال بـ `cancelled` تسوية. أخرى صحيح معتاد تماما توقف مستقر تقرير إبلاغ `end_turn`.

Goal متابعة سطر فقط إبقاء `MessageId`، لأجل تعرف آخر حمل دائم ترتيب طابور و قد دقيق دخول goal رسالة. هو في كامل agent دخول idle وقت أصل حسب حمل دائم goal حالة دفع دخول، لا يأخذ رسالة خريطة إلى جولة نتيجة.

## اعتبار مرور بديل خطة

**سوف `MessageId` خريطة إلى دقيق دخول هو جولة.** واحد جولة ممكن استخدام steering و حقن سياق، أيضا ممكن مرور مرور كثير عدد نموذج/أداة خطوة متابعة تنفيذ. هذا خريطة فقط قدرة معرف دقيق دخول، لا يستطيع تأكيد قيام نتيجة إخراج أو إيقاف سبب بسبب نتيجة ملكية.

**إرجاع حسب follow-up منطقة قسم إتمام جملة مقبض.** هذا مثال جملة مقبض داكن عرض مشترك agent دورة الحياة في وجود و لا فعلي صار قيام نتيجة حد. هو يلزم ما متروك تسرب أثر نشط حركة عمل، يلزم ما في لا عمل شرح حال حال تحت امتصاص استلام لاحق غير متصل إدخال.

**استخدام دخول idle قبل مراقبة إلى الأكثر بعد واحد `turn/end`.** مقابل في واضح يملك منطقة بين، هذا هو واحد بند لديه استخدام تشغيل درجة مراقبة قياس؛ لكن إذا سوف ذلك تسمية لـ قد إيداع رسالة نتيجة، حينئذ سوف مجددا مرة عمل خروج خطأ بسبب نتيجة إعلان.

## تحقق

- Agent و inbox اختبار ثابت follow-up فقط دخول طابور، حمل دائم دقيق دخول أو إلغاء و كامل agent idle مراقبة قياس.
- SDK بروتوكول،TypeScript SDK و Python SDK اختبار ثابت `{ messageId }` عودة تنفيذ،`session.status`، لا وجود `session.finished`، و لا يحتوي نص التوجيه درجة `status` أو `reason` عودة تنفيذ إلى idle `RunResult` استلام تجميع؛Python SDK اختبار آخر سطر ثابت ذلك تشغيل درجة `finish_reason` مراقبة قياس.
- ACP، مفرد مرة CLI،goal متابعة سطر و subagent اختبار ثابت كل تجميع صار فعلي يملك مختلف نشط حركة حد.
- مستهلك اختبار ثابت إنتاج تجميع صار كل لن عبر صلة ربط `MessageId` و `turn/end` قدوم دفع توجيه follow-up نتيجة.

## عاقبة

ذاتي لديه نشط حركة منطقة بين يمكن يتضمن دخول idle قبل إيداع steering، حقن سياق أو أخرى عمل، لذلك ذلك نهائي استجابة، انتهاء سبب و حدث متعمد مقارنة ابتدائي رسالة شمول غطاء أكثر واسع. قاع طبقة DSH SDK نتيجة ما زال لا يتضمن نص التوجيه درجة نموذج خطأ و token حد أعلى تصنيف.ACP سوف في منطقة بين تماما توقف مستقر وقت يأخذ صلة ربط جولة إسقاط صار ذلك مطلوب معيار error أو `max_tokens` stop reason، لكن لا زيادة DSH مخصص استخدام نتيجة، أيضا لا صوت تسمية ترتيب هو بسبب نتيجة علاقة. في نفس جلسة فوق تزامن تنفيذ تلقائي تحويل عملية وقت، يجب اعتماد صريح سلسلة سطر أو كل حق سياسة، لا يستطيع اعتماد خفي صيغة تدريجي follow-up نتيجة.
