# Agent Note: عام مشترك package manifest حقل

Status: implemented

[English](2026-09-10-public-package-manifest.md) | العربية

## مشكلة

إضافة عمل من حاجة من موحد واحد عام مشترك استيراد مسار نيل أخذ npm هوية، وقت التشغيل اشتراط و DSH إعلان. داخلي مرآة مثل تحزيم،Session دليل و توليد بديل إدارة بيانات وصفية لا تعريف مجتمع منطقة إضافة نقطة توسيع. سوف هذه حقل واحد بدء كشف، سوف يجعل خارجي عمل من خطأ بـ لـ داخلي آلية أيضا يمكن توفير استخدام.

## قرار

[`DshPackageManifest`](../../../../packages/util/package-manifest/src/types.ts) وصف DSH استخدام package.json حقل، منها `name` و `version` لا بد ملء. ذلك اختياري `dsh` عضو استخدام `DshManifest` وصف عام مشترك تركيب و عمل من بيانات وصفية. هذا نوع فقط اختيار أخذ الذي يحتاج npm حقل، لا هو كامل package.json schema(نمط).App-boot عبر `Partial` ملائم إعداد بلا حاجة إصدار هوية محلي profile.

وقت التشغيل اشتراط يقع في قمة طبقة `engines`:`dsh`،`node` و `npm` متساو لـ اختياري إصدار نص، أيضا سماح أخرى engine اسم.`dsh.manifestVersion` معرف إعلان صيغة `1`. حالي تثبيت جهاز و تحميل جهاز لا قوي صنع فحص صيغة و DSH توافق صفة إعلان.

مرآة مثل تحزيم جهاز يملك `configTrees`، مساحة العمل دليل توليد جهاز يملك Session ترحيل إعلان،app-boot يملك توليد وحدة بعد تجهيز بيانات وصفية. هذه داخلي أداة ما زال يمكن قراءة قائم مغناطيس قرص حقل، لكن عام مشترك manifest نوع لا كشف هذه حقل. هذا نطاق دقيق تحويل[مشترك إعلان ملكية قرار](2026-09-05-package-manifest-types.zh.md) ، بعد من حزمة موضع و اعتماد قاعدة ما زال صالح.

كل مستهلك مسؤول JSON تحليل، حقل تحقق، قيمة افتراضية تحليل و وقت التشغيل بيانات ملائم إعداد. واجهة لن تحقق قد تحليل JSON. فقط لديه كثير عدد مستهلك حاجة نفسه تحقق أو عودة واحد تحويل وقت،helper عندئذ يخص مشترك حزمة؛ تكرار خاصية وصول getter لا توفير مشترك سياسة.

## اعتبار مرور بديل خطة

**سوف داخلي بيانات وصفية إبقاء في عام مشترك إعلان في.** فقط حد مساحة العمل ترحيل دليل و فعلي تحقق صفة مرآة مثل تحزيم جهاز، لن لأن ذلك بيانات وصفية يمكن يتم اكتشاف حينئذ توفير عام مشترك إضافة سلوك.

**سوف DSH توافق صفة وضع في `dsh.engines` تحت.** [VS Code](https://code.visualstudio.com/api/references/extension-manifest) سوف مضيف اشتراط وضع في قمة طبقة `engines.vscode`. قمة طبقة `engines.dsh` يجعل عمل من في نفس موضع إعلان وقت التشغيل اشتراط؛ ذاتي تعريف مفتاح فحص ما زال من DSH مسؤول.

**فقط استخدام peer dependency إعلان مضيف اشتراط.** Peer dependency قيد قد تثبيت npm حزمة، يشمل CLI حزمة `@deepseek-ai/dsh`. إضافة يقع في مستقل profile مشروع وقت، هو جمع لا يمكن معرف حالي تشغيل DSH عملية.

**عبر موحد واحد قوي صنع محلل تحليل كل مجال.** قائم قراءة جهة إزالة استهلاك مختلف حقل فرعي تجميع، و كل منها يملك خطأ و قيمة افتراضية. دمج هو جمع سوف يجعل عميل قراءة جهة تحقق غير متصل profile إعلان. عام مشترك نوع إبقاء مستقل في نظام الملفات وصول و تحليل سياسة.

## عاقبة

خارجي عمل من نيل نيل كامل حزمة درجة إعلان و أكثر صغير DSH عمل من API. قد إزالة داخلي نوع مستهلك يجب استخدام كل منها مسؤول تنفيذ. تحزيم جهاز و مستودع دليل لم يعد اعتماد عام مشترك إعلان حزمة؛app-boot إبقاء إنتاج اعتماد، لأن ذلك إصدار profile نوع مرجع هذا حزمة.

تحرير ترجمة جهاز و بناء بعد NodeNext استيراد فحص تحقق حزمة هوية لا بد ملء، جزء profile، قمة طبقة engine إعلان، و عام مشترك API لا يحتوي داخلي حقل. قائم profile، تحزيم جهاز و Session دليل اختبار متابعة تغطية ذلك قبول ملف و شاذ شكل إعلان.Session صيغة، إضافة تحميل قاعدة و نموذج مرئي سلوك متساو لا تغيير.
