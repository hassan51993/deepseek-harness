# Agent Note: locale ملكية client UI نص سجل

Status: implemented

[English](2026-08-23-locale-owned-client-ui-copy.md) | العربية

## Problem

typed locale namespace و مزدوج لغة حرف قاموس مقابل انتظار صفة يمكن إثبات قد تسجيل حرف قاموس كامل، لكن لا يمكن إثبات عرض شفرة استخدام حرف قاموس.JSX نص، بلا عائق عائق خاصية، صيغة تحويل دالة قيمة راجعة و zero-Cordis أصل فرعي مكون قيمة افتراضية كل ممكن التفاف مرور `t`، بينما الكل locale فحص ما زال إبقاء أخضر لون.[الأكثر أول كل كمية وصل دخول قرار](../../archived/architecture/2026-07-30-client-locale-full-rollout.md) في مؤقت فعل أو زائف تحديد لـ لغة غير متصل مثال خارج تدريجي تدريجي شكل صار خلط دمج لغة UI،trajectory فحص وجه و عام أداة بطاقة خاصة لـ واضح إظهار.

## Decision

**كل منتج تحرير كتابة client UI إجراء لفظ كل من locale حرف قاموس يحتفظ.** مرئي نص، بلا عائق عائق اسم،tooltip،placeholder، فارغ حالة، حالة وسم، مفرد موضع و صيغة نموذج لوح يجب مرور typed `t` مقعد موضع أو قد محلي تحويل prop وصول عرض طبقة. من مستخدم، نموذج، مزود، إضافة،wire مقابل طرف أو عملية نظام تحرير كتابة قيمة ما زال هو بيانات و أصل مثال تصيير؛ بروتوكول tag، أداة اسم، مسار،URL،JSON/JavaScript حرف وجه كمية و مستقر داخلي id لا قلب ترجمة.

منتج يحتفظ دليل شرح التزام دوران نفس قاعدة.client سوف تماما مطابقة داخل وضع مزود، نموذج و شرح خريطة إلى locale key؛ شرح حدوث تغير أو قدوم ذاتي خارجي مزود وقت، هو ما زال هو مزود بيانات و أصل مثال تصيير.

**Cordis-free أصل فرعي مكون اشتراط كامل محلي تحويل نص سجل prop، كما ذاته لا يحتفظ لغة عودة سقوط قيمة.** `MarkdownText`،`JsonTree`،`TerminalBlock`،`DiffBlock`،`ReadBlock`،`SearchBlock`،`WebBlock`،`CodeBlock`،`JsonBlock`،`HoverCard` و `ConnectionIndicator` chrome متساو من وظيفة تصيير نقطة نقل دخول. هذا مثال حيث إبقاء أصل فرعي مكون حزمة وقت التشغيل مستقل صفة، أيضا يجعل متروك تسرب يصبح نوع خطأ، بينما لا هو ساكن صامت اختيار العربية أو إنجليزي نص. مشترك استخدام كلمة دخول `common` namespace؛ وظيفة مخصص تابع قصير لغة إبقاء في قرار ذلك دلالة وظيفة جانب.

**محلي تحويل عرض نص أبدا تحمل تحمل هوية.** نموذج و تخزين إبقاء حكم آخر حقل، مستقر id و غير عرض marker. مصير أولا مطابقة مجددا قلب ترجمة، طلب خريطة عبر مستقر مجموعة عضو علاقة دخول trajectory ledger. يجب حفظ في عرض نموذج في client دمج صار خطأ استخدام مستقر marker، فقط في عرض وقت قلب ترجمة. لذلك لغة تبديل فقط تغيير إجراء لفظ، لا تغيير اختيار، قسم مجموعة، بحث هوية أو دورة الحياة حالة.

**`verify-client-ui-i18n` قوي صنع شفرة المصدر ملكية.** أساس في TypeScript AST فحص سوف اكتشاف كل يتضمن TSX package `src/client` دليل شجرة،`packages/client/ui-*` تحت كل مساعد مساعدة TS ملف و web تطبيق شفرة المصدر؛ هو رفض ذاتي لكن لغة JSX نص، تحمل تحميل نص سجل خاصية و مكون prop،JSX حرف وجه كمية فرع،label/copy بيانات، أداة اسم نص سجل مساعد مساعدة دالة، إرجاع نص عرض صيغة تحويل دالة و حل بنية قيمة افتراضية.locale حرف قاموس owner و غير ممكن تغيير لغة token هو صارم إطار لغة قاعدة درجة ترتيب حذف بند. اكتشاف نطاق تقليص ضيق سوف مباشر فشل، وحدة fixture ثابت قبول دخول و ترتيب حذف شكل، فحص إضافة دخول ساكن حالة CI و `hygiene` رسم. حرف قاموس key مقابل انتظار صفة ما زال من مستقل فحص مسؤول: واحد طريق بوابة إثبات نص سجل دخول locale مسار، آخر طريق بوابة إثبات اثنان نوع إصدار لغة كل تنفيذ هذا مسار.

[الأكثر أول وصل دخول قرار](../../archived/architecture/2026-07-30-client-locale-full-rollout.md) في منتج ذاتي إنتاج خطأ و تصميم حرف وجه كمية مثال خارج، أصل فرعي مكون افتراضي نص سجل و trajectory مؤقت فعل متساو من هذا قرار يحل محل؛ ذلك label thunk،typed مقعد موضع، متصفح locale، يوم مدة صيغة تحويل و بحث احتلال موضع سطر قرار ما زال صالح.

## Verification

AST فحص ذاته Vitest spec ثابت مباشر JSX، نموذج لوح فرع، دلالة نص سجل prop،label بيانات، صيغة تحويل دالة قيمة راجعة،locale key استدعاء، بنية خاصية و حرف قاموس owner.locale حرف قاموس مقابل انتظار صفة ثابت `ar`/`en` key متسق.client اختبار تغطية مباشر قلب ترجمة مقعد موضع،locale prop مهايئ، و لا تغيير خارجي شرح داخل وضع دليل شرح محلي تحويل. تجميع web إعادة تشغيل و قاعدة تحديد حقيقي خادم GIF في فعلي trajectory واجهة فوق عرض إصدار لغة تبديل.

## Alternatives considered

**فقط اعتماد مراجعة و AGENTS.md.** مرفوض. قائم قاعدة و typed حرف قاموس و عدد مئة عدد التفاف مرور نقطة معا وجود؛ مراجعة من حاجة في جذب دخول سطر استلام إلى شفرة المصدر درجة فشل.

**استخدام نص صحيح فإن، أو منع توقف كل نص حرف وجه كمية.** مرفوض.TypeScript و JSX في يتضمن import،CSS class، حكم آخر قيمة، حدث اسم،SVG بيانات و مستخدم/wire قيمة. حسب لغة قاعدة سياق فحص يمكن في لا توسيع ورقة ملف allowlist حال حال تحت إبقاء صالح إشارة، بينما الأكثر صغير اكتشاف عدد كمية يمكن منع توقف مسح نطاق تقليص صغير بعد زائف أخضر.

**لـ جهة سهل مباشر استخدام بينما إبقاء أصل فرعي مكون عودة سقوط نص سجل.** مرفوض. عودة سقوط قيمة ذاته حينئذ هو خفي صيغة locale اختيار. لا بد ملء label prop يجعل أصل فرعي مكون إبقاء إطار هيكل غير متصل، و إجبار جعل كل منتج تصيير نقطة واضح نص سجل owner.

**قلب ترجمة كل دخول DOM نص.** مرفوض. خارجي تحرير كتابة بيانات و بروتوكول/شفرة token و غير منتج إجراء لفظ. قلب ترجمة سوف كسر تالف دليل، معرف رمز، أمر، مسار،URL و مزود تشخيص؛ فقط لديه ذلك دورة محيط منتج chrome يخص locale نظام.

## Consequences

- إضافة جديدة أو تعديل client UI نص سجل وقت، يجب في اثنان نوع locale في إضافة typed حرف قاموس key، و لـ تلقي أثر تصيير مسار توفير سلوك دليل.
- صاف أصل فرعي مكون صريح prop نوع تغيير كبير، اختبار يحتاج توفير متعمد اختيار label fixture؛ هذا بند صار هذا تبديل قدوم بلا إخفاء locale سلوك.
- AST فحص يمكن إمساك إلى منتج تحرير كتابة حرف وجه كمية التفاف مرور، لكن لا يمكن إثبات مهمة معنى حركة حالة نص prop قد قلب ترجمة. نوع، حرف قاموس مقابل انتظار صفة، مكون اختبار و مراجعة ما زال مشترك نفس مسؤول هذا واحد دلالة منطقة قسم.
- locale خدمة قبل تصيير boot علامة و خارجي تحرير كتابة وقت التشغيل بيانات ما زال في حرف قاموس مسار خارج؛locale تنشيط بعد، منتج UI سوف استبدال boot نص سجل.
