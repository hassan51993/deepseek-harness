# Agent Note: سوف كل بند رسالة إنشاء لـ حمل معرف غير ممكن تغيير قيمة

Status: implemented

[English](2026-07-28-identified-immutable-message-values.md) | العربية

## مشكلة

harness سبق وجود كثير نوع شكل يشبه رسالة يمثل، كل منها اعتماد مختلف معرف قاعدة.agent(ذكي جسم) إدخال فقط لديه في agent loop قبول بعد عندئذ سوف أخذ نيل inbox صلة ربط id، بينما حمل دائم مستخدم رسالة،assistant رسالة، أداة نتيجة و نموذج طلب رسالة كل ممكن لا يوجد معرف. لذلك، نص التوجيه دقيق دخول وسيط في إنشاء رسالة و بناء قيام معرف بين؛ انتظار قيمة محتوى سوف في فوري حدث، حمل دائم حدث و نموذج طلب بين نسخ، لكن لا يوجد واحد قيمة قدرة في رسالة كامل دورة الحياة في معرف هو.

هذا جعل معرف يصبح توجيه فرعي أثر، بينما لا هو رسالة ثابت كمية. إنتاج جهة لا يمكن في استدعاء agent قبل مرجع واحد بند رسالة، نص التوجيه خطاف سوف قسم آخر استقبال محتوى و مصدر، لاحق إسقاط فإن يجب واحد حافة إعادة بناء رسالة، واحد حافة قرار id هل وجود. غير ممكن تغيير صفة أيضا من مختلف حد بدء: جزء إدخال من agent loop تجميد ربط، جزء مباشر إلى جلسة إلحاق وقت عندئذ تجميد ربط، من مزود توليد assistant إخراج فإن استخدام آخر نوع يحمل مزود، نموذج و إعادة تشغيل حالة شكل حالة.

## قرار

`@deepseek-ai/dsh-llm` يحتفظ وحيد واحد نوع `Message` قيمة، ذلك `id`،`role`،`content` و `source` متساو لـ لا بد ملء.`MessageId` هو لا نفاذ واضح معرف، من مستخدم رسالة،assistant رسالة و أداة نتيجة رسالة مشترك. رسالة في إنشاء وقت حينئذ سوف نيل نيل id، مبكر في inbox توجيه، قيادة أخذ،pre-step تعديل كتابة، حمل دائم إلحاق أو طلب إسقاط. نفس عدد id سوف عبر تجاوز كل يمثل حد.

`createMessage(input)` هو زاوية لون عام مواصفة إنشاء حد. هو سوف توليد `MessageId`، سوف نقل دخول زاوية لون، محتوى و مصدر و استدعاء جهة كائن حل حذف مرجع علاقة، و في إرجاع كامل قيمة قبل سوف ذلك عميق درجة تجميد ربط.`createUserMessage({ content, source })` لـ نص التوجيه و سياق إنتاج جهة ثابت user زاوية لون.`createAssistantMessage({ content, source })` معا ثابت assistant زاوية لون و نموذج مصدر صنف آخر، لذلك نموذج إخراج إنتاج جهة فقط يحتاج توفير محتوى، و مزود، نموذج و اختياري إعادة تشغيل حالة. كل إنشاء مساعد مساعدة دالة إدخال كل لا يتضمن id، لذلك استدعاء جهة لن معنى خارج أرض يأخذ جديد رسالة إنشاء زائف تركيب صار قد لديه رسالة استيراد.`freezeMessage(message)` هو مستقل استيراد أو تحويل حد: هو سوف سوف قد لديه معرف رسالة و استدعاء جهة كائن حل حذف مرجع علاقة و عميق درجة تجميد ربط، لن توليد بديل معرف.

رسالة مساعد مساعدة دالة يقع في أساس أساس رسالة مفردات جانب `dsh-llm` في، لأن هو جمع كامل اتفاق فقط اعتماد هذا مفردات. هو جمع استخدام `dsh-brand` بلا حالة `brandString()` بنية صنع دالة توليد `MessageId`، و في عبر `structuredClone()` قسم مغادرة إدخال بعد استخدام `dsh-util-values` مشترك `deepFreeze()` تنفيذ.`createToolResultMessage()` و أخرى إنشاء مساعد مساعدة دالة نفس تابع هذا موضع: هو سوف أداة استدعاء id و تأكيد قطع user-role أداة نتيجة كتلة و مصدر اقتران دمج بدء قدوم، لا اعتماد جلسة حالة أو حدث.`dsh-session` فقط إزالة استهلاك كامل رسالة، لا مسؤول بنية صنع هو جمع.

`Agent` واجهة عبر `followup`،`steer` و `inject` استقبال كامل `UserMessage`. هذه عملية أبدا سوف قسم إعداد أو إرجاع معرف؛ هو جمع سوف تجميد ربط استيراد قيمة، بينما استدعاء جهة قد يحتفظ هذا قيمة id.inbox قيادة أخذ و `agent/pre-step` سوف مباشر استقبال هذا رسالة. تعديل كتابة محتوى وقت سوف إنشاء أداة لديه نفسه id تجميد ربط بديل قيمة، بينما كل مرفق إضافة سياق كل هو مفرد وحيد إنشاء `UserMessage`، يملك ذاتي ذات id.

إنتاج حمل دائم رسالة حدث سوف تخزين كامل رسالة.`user/message` مباشر تخزين ذلك `UserMessage`؛`assistant/message` و `tool/result` فإن سوف كل منها زاوية لون مخصص استخدام رسالة و حدث محلي موضع، استخدام كمية، فشل أو عرض واقع حزمة تركيب في واحد بدء. جلسة إرسال توليد سوف إرجاع هذه تجميد ربط قيمة، بينما لا هو إعادة بناء مجهول اسم رسالة.assistant تجميع سوف في استجابة إتمام وقت إنشاء نموذج مصدر رسالة، أداة تنفيذ سوف في إيداع نتيجة وقت إنشاء أداة مصدر رسالة.

فقط تغيير قد لديه دلالة رسالة يمثل عملية سوف إبقاء ذلك id، و إرجاع آخر عدد تجميد ربط قيمة. إنشاء جديد دلالة رسالة عملية فإن سوف توليد جديد id. لذلك، ضغط (compaction) في محتوى تعديل كتابة سوف إبقاء يتم تعديل كتابة أداة نتيجة معرف، بينما ملخص فحص نقطة هو واحد بند جديد رسالة.

## اعتبار مرور بديل خطة

**يجعل أساس أساس رسالة id إبقاء اختياري.** هذا قدرة نقص قليل fixture(اختبار قبل وضع بيانات) ترحيل، و سماح مزود أو حفظ دائم شكل حالة متابعة إبقاء مجهول اسم، لكن أيضا سوف إبقاء أصل لديه اختلاف معنى: كل مستهلك كل يجب أصل حسب معرف هل وجود تنفيذ فرع، كما لا يوجد أي نوع قدرة إثبات دقيق دخول، سجل أو إسقاط إبقاء معرف.

**يجعل agent تسليم قسم إعداد id.** هذا سوف سوف معرف حد تحديد في inbox صلة ربط نطاق داخل، لكن أيضا سوف يجعل agent استدعاء يصبح إنتاج جهة يمكن معرف ذاته رسالة الأكثر مبكر وقت آلة. هذا مثال واحد قدوم، في تسليم إرجاع قبل، نص التوجيه بنية صنع،UI مرفق عنصر و تزامن دخول طابور/إسقاط تنسيق ضبط كل حاجة إجراء محتوى مطابقة، أو استخدام حمل خارج token.

**يجعل كل حمل دائم حدث قسم إعداد جديد id.** هذا قدرة لـ حمل دائم رسالة توفير معرف، لكن سوف متعمد قطع قطع هو و فوري إدخال صلة ربط، و يجعل إعادة تشغيل طلب جدول الآن نيل مثل يتضمن مختلف رسالة. معرف يخص دلالة قيمة، بينما لا هو تحمل تحميل هو كل غلاف تركيب.

**فقط في agent أو جلسة دقيق دخول وقت تجميد ربط.** هذا قدرة حذف ذهاب إنشاء مساعد مساعدة دالة، لكن سوف إبقاء تحت واحد حمل معرف لكن متغير وقت منطقة بين، استدعاء جهة شفرة يمكن في هذا مقطع وقت داخل تغيير هذا id الذي صلة ربط يحتوي معنى. هذا قرار يجعل «يملك id» و «هو غير ممكن تغيير لقطة» معا صار قيام.

## عاقبة

كل رسالة إنتاج جهة كل يجب صريح اختيار إنشاء أو استيراد، اختبار أيضا سوف بنية صنع كامل قيمة، بينما لا هو لا كامل محتوى/مصدر سجل.UUID توليد سوف قبل نقل حتى الأكثر أول دلالة إنشاء نقطة، لذلك توفير قد لديه id تحديد صفة fixture سوف استخدام `freezeMessage()`، بينما لا هو `createMessage()`.

فوري inbox حدث، حمل دائم حدث، إرسال توليد تاريخ و نموذج طلب يمكن صلة ربط نفس بند رسالة، بلا حاجة مقارنة مقارنة محتوى أو استخدام غلاف تركيب مخصص استخدام id. انتظار معالجة إدخال سياسة و UI مرفق عنصر تنظيف يمكن في جولة وجود قبل مقارنة مقارنة `MessageId`، قيادة أخذ بعد فإن سوف في قد فتح جولة داخل إبقاء هذا معرف. عميق درجة تجميد ربط يمكن منع توقف إنتاج جهة، خطاف أو مراقبة جهة في معرف بناء قيام بعد أكثر تعديل رسالة قيمة.

مشترك يمثل إزالة قديم `UserMessageData`/`AgentMessage` تخطيط قسم، و سوف مزود، نموذج و اختياري إعادة تشغيل حالة وضع دخول حمل نوع رسالة مصدر. حدث غلاف تركيب ما زال يحتفظ لا يخص رسالة دلالة واقع، مثال مثل جولة و خطوة موضع،token استخدام كمية، داخلي أداة فشل معرف و عرض بيانات وصفية.

رسالة و مساعد مساعدة دالة اختبار وحدة سوف قفل تحديد أي وقت معرف، حل حذف إدخال مرجع، عميق درجة غير ممكن تغيير صفة، و استيراد id إبقاء.agent loop اختبار سوف قفل تحديد معرف عبر تجاوز دقيق دخول،inbox دورة الحياة، حمل دائم إلحاق، محتوى تعديل كتابة و إلغاء سلوك؛ جلسة اختبار سوف قفل تحديد تجميد ربط إرسال توليد و إبقاء معرف استبدال سلوك.
