# Agent Note: User-terminal permissions

Status: implemented

[English](2026-09-16-user-terminal-permissions.md) | العربية

## مشكلة

مستخدم حاجة في حد Agent(ذكي جسم) إذن معا قريب ذاتي تشغيل أمر. مشترك Agent صندوق رملي نمط سوف إجبار استخدام مستخدم لـ يد حركة عملية بينما توسيع كبير Agent إذن؛ إبقاء تفاعل صيغة shell أيضا سوف منع توقف لاحق نمط تبديل، لأن قد لديه عملية صندوق رملي حد لا يمكن تتبع مع جديد Session ضبط تغيير.

## قرار

Web جانب شريط طرفية مباشر عبر Session subprocess provider تشغيل، استخدام تنفيذ بيئة في نظام مستخدم إذن. هو لا عبر Agent صندوق رملي حد shell، أيضا لا طلب Agent مراجعة دفعة. عملية نظام إذن، حاوية عزل و provider مقابل بيئة اعتماد صاف حذف ما زال توليد فاعلية.Session معرف مسؤول وصول نطاق، عملية تنظيف و ابتدائي دليل؛sandbox policy فقط في Session لا يوجد cwd وقت توفير إعداد افتراضي دليل.

تغيير Agent إذن وقت، مستخدم طرفية متابعة تشغيل.Agent استخدام shell و terminal أداة إبقاء كل منها صندوق رملي حد. مستخدم طرفية إدخال و إخراج لا إنتاج نموذج إدخال أو Session حدث.

هذا قرار فقط يحل محل [Web جانب شريط طرفية قرار](../feature/2026-09-09-web-sidebar-terminal.zh.md) في مشترك صندوق رملي سياسة و نمط تبديل حد. أصل سجل متابعة مسؤول عملية كل حق، نقل، شاشة ستار استعادة و shell اختيار.OpenCode `packages/core/src/pty.ts` و `packages/core/src/pty/pty.node.ts` توفير متبادل مجاور تنفيذ اعتماد حسب: ذلك تفاعل صيغة طرفية استخدام اختيار تحديد shell و عمل دليل مباشر إنشاء PTY.

## اعتبار مرور بديل خطة

**وراثة Agent إذن.** واحد Session نمط يمكن وصف اثنان صنف عملية، لكن مستخدم يجب معا منح إعطاء Agent فقط لأجل يد حركة أمر إذن. حمل دائم مستخدم shell مع لـ منع عائق Agent إذن تبديل.

**زيادة مستقل طرفية إذن اختيار جهاز.** منتج سوف هذا طرفية نظر لـ مستخدم عملية نظام shell. آخر عدد اختيار جهاز سوف زيادة سياسة حالة و عملية إعادة بدء دلالة، هدف قبل لا يوجد مقابل يحتاج طلب؛ نشر و عملية نظام تحكم قد تحديد تنفيذ بيئة.

## أثر

وصول Web طرفية يكفي بصفة subprocess provider نظام مستخدم تنفيذ أمر، يشمل في هذا مستخدم لديه إذن وقت كتابة Session مساحة العمل خارج مسار. هو لن منح إعطاء root إذن أو هروب هروب حاوية.Session كل حق متابعة لأجل قسم مجموعة و تنظيف، لا معنى طعم حال Agent قرار مستخدم عملية إذن.

Controller اختبار تغطية الكل Agent صندوق رملي نمط تحت مباشر shell بدء، و نمط تغيير بعد حمل متابعة كل حق. تسجيل صنع Web إذن سياسة مشهد في فقط قراءة، تماما وصول و مساحة العمل كتابة بين تبديل وقت إبقاء نفس عدد حقيقي مستخدم PTY، تحقق مساحة العمل داخل خارج كتابة، و إبقاء Agent فقط قراءة رفض و مراجعة دفعة تأكيد.Bash متصفح تأكيد في macOS و Linux تشغيل؛Windows إبقاء يمكن نقل غرس controller فحص و Agent سياسة إعادة تشغيل.
