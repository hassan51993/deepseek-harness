# Agent Note: PTC وقت التشغيل مفردات

Status: implemented

[English](2026-09-12-ptc-runtime-vocabulary.md) | العربية

## Problem

PTC نمط و ذلك تنفيذ مزود حاجة في حزمة بيان، خدمة فحص بحث، عام مشترك نوع، إعداد و وثيقة في استخدام نفس عدد يمكن بحث اسم. خلط دمج وقت التشغيل بادئة جعل صيانة من صعب بـ من profile تتبع أثر إلى مزود تنفيذ و تحزيم بعد جذب توجيه برنامج.

## Decision

تنفيذ قدرة استخدام `ptc-runtime` حزمة عائلة،`PtcRuntime` نوع و `ctx.ptcRuntime`.Node و خاص فعلي تحقق صفة Python مزود مشترك هذا طقم مفردات.Profile بند معرف رمز، داخلي جذب توجيه اختيار جهاز، تحرير ترجمة جهاز مرجع، حزمة توجيه خروج و توليد دليل استخدام نفسه اسم؛ لا توفير توافق حزمة أو ثاني نسخة خدمة تسجيل.

وقت التشغيل حزمة و SDK لغة نوع PTC اسم يحل محل[مبكر مدة تسمية قرار](../../archived/architecture/2026-08-25-rename-code-mode-to-ptc.md) سجل مثال خارج، جعل مزود و استدعاء جهة استخدام نفس طقم يمكن بحث مفردات.

موجه إلى نموذج `run_code` عملية، ذلك `code` شفرة المصدر معامل و مستقر فشل معرف إبقاء وصف صفة اسم. واحد عام شفرة المصدر فن لغة، رمز خطأ، خارجي مشروع اسم و URL، تاريخ ترحيل معرف رمز و غلاف تخزين Agent Note إبقاء أصل لديه يحتوي معنى و سجل تجميع كتابة. هذا واحد تسمية قرار لا تغيير برنامج تنفيذ، صندوق رملي إذن، مدة حد، ربط أو Session صيغة.

## Alternatives considered

**إبقاء مفرد وحيد عام وقت التشغيل بادئة.** مزود ما زال مستقل في أداة و Session كل حق، لكن ذلك حزمة اسم و خدمة اسم معرف PTC تنفيذ قدرة. مفرد وحيد بادئة سوف زيادة ثاني عدد اسم، لكن لا يوجد قسم مغادرة خروج مستقل عرض دخول وظيفة.

**استبدال كل واحد موضع “code”.** برنامج شفرة المصدر، عملية اسم، خارجي مرجع و تاريخ سجل وصف مختلف كائن. استبدال هذه محتوى سوف تغيير وقت التشغيل تسمية قرار خارج عام مشترك عملية أو قد سجل واقع.

**إصدار قديم اسم آخر اسم.** API بعد لم مستقر، مستودع في كل مستهلك مشترك نفس ترحيل. آخر اسم سوف إبقاء تكرار حزمة و خدمة هوية، جعل لاحق فحص بحث يحتوي غامض لا صاف.

## Consequences

نشر إعداد و شفرة المصدر مستهلك مشترك نفس استخدام PTC حزمة اسم و إعداد معرف رمز. قد لديه `run_code` سجل و خطأ توجيه ما زال يمكن قراءة. آلة آلة مراجعة حساب مقارنة مقارنة إعادة تسمية قبل بعد شفرة المصدر token، إبقاء خارجي URL و تجميد ربط سجل، و فحص كل واحد موضع ناقص إبقاء قديم وقت التشغيل اسم؛ بناء بعد profile، حزمة و snapshot فحص تغطية ساكن حالة استيراد لا يمكن تحقق مستهلك.
