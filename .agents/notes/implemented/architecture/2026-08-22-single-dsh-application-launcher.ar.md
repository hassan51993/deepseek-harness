# Agent Note: من واحد dsh بدء تطبيق profile

Status: implemented

[English](2026-08-22-single-dsh-application-launcher.md) | العربية

## Problem

DeepSeek Harness تطبيق عملية حاجة من نفس عدد آلية مسؤول تركيب، إضافة تحليل، بيئة اكتشاف، إغلاق و مستخدم ذاتي تعريف. حمل كامل `cordis.yml` مخصص استخدام تطبيق bin سوف في profile بدء خارج شكل صار ثاني طقم دورة الحياة: تثبيت إلى profile إضافة لا يمكن وصول هو، سلوك سوف و `dsh-base` انحراف مغادرة،SDK استدعاء جهة أيضا حاجة تعلم تعود مهمة معنى عملية argv، بينما لا هو منتج تركيب نموذج.

Python SDK عبر أربعة عدد منصة wheel حزمة توزيع أصلي يمكن تنفيذ ملف. ذلك تحزيم عملية استخدام نفس profile بدء جهاز، معا إبقاء غلاف إغلاق VFS اعتماد شجرة، أصلي مرافق مع ملف و installed-wheel دليل.

## Decision

### بدء نطاق

كل تلقي دعم حمل Node تطبيق كل عبر `dsh` CLI و واحد أداة اسم profile بدء. مع مرفق profile لـ `web`،`headless`،`sdk`،`sdk-minimal` و `acp`، يمكن عبر `dsh --profile <name>` أو `dsh <name>` اختيار.`plugin` يمثل إدارة أمر؛ نفس اسم profile يجب استخدام `--profile plugin` اختيار.

Vendor CLI، فقط لأجل بناء و اختبار يمكن تنفيذ ملف، عملية داخل مباشر تركيب إضافة و خاص متصفح WebWorker معاينة كل لا يخص تطبيق بدء بيان. حزمة تطبيق bin أو مباشر بدء حزمة مدخل أصل demo كل لا هو يمكن قبول نقطة توسيع.

### Profile تطبيق

`@deepseek-ai/dsh-sdk-app` و `@deepseek-ai/dsh-acp-app` في `@deepseek-ai/dsh-base` لـ فوق تركيب كامل بروتوكول تطبيق.SDK تركيب حزمة زيادة JSON-RPC خادم، تطبيق ذاتي لديه مساعدة مساعدة و stdio دورة الحياة؛ACP تركيب حزمة زيادة فقط لأجل تلقائي تحويل ACP خادم و نفسه تطبيق مسؤولية. اثنان من كل اعتماد base طبقة نموذج، أداة، حفظ دائم،settings،credentials، سياسة و بيئة سلوك.[مستقل sdk-minimal profile](../../archived/architecture/2026-08-24-standalone-sdk-minimal-profile.md) إعادة استخدام SDK بدء و JSON-RPC خدمة، لكن لحظة معنى يملك لا يحتوي `dsh-base` كامل صريح إعداد شجرة.

Profile manifest مسؤول patch إعادة تحميل:

| Profile | `patchReload` |
|---|---|
| `web` | `live` |
| `headless` | `startup` |
| `sdk` | `startup` |
| `sdk-minimal` | `startup` |
| `acp` | `startup` |

ذاتي تعريف profile افتراضي لـ `live`.`startup` profile ما زال سوف تطبيق تركيب حزمة،profile،home درجة و استدعاء وقت `--patch` كل طبقة، لكن بدء بعد لن مراقبة نظر هذه ملف.`dsh-base` إدراج دخول وحدة HMR(حار وحدة استبدال) بند إعداد افتراضي منع استخدام؛ أداة لديه مرور مرور تحقق شفرة المصدر وحدة إعادة تحميل دورة الحياة profile يجب صريح تفعيل هو. مع مرفق profile متساو لا تفعيل خادم وحدة HMR:`patchReload: live` استخدام بدء جهاز فقط إعداد watcher،`startup` profile فإن لا تثبيت watcher.SDK و ACP لا يمكن في واحد ذاتي لديه stdio اتصال داخل أمان استبدال ذلك خادم،agent، حفظ دائم أو أداة سجل التسجيل.

مع مرفق بروتوكول profile سوف stdout إبقاء إعطاء بروتوكول لقطة، عرض مساعدة مساعدة وقت لا بدء transport، و عبر محدود أصل عقدة dispose(مورد تحرير) معالجة stdin EOF و إشارة.ACP متابعة فقط لأجل تلقائي تحويل.SDK JSON-RPC طريقة، إشعار حقل و `initialize.serverInfo.name` إبقاء مستقر. كامل profile نموذج مرئي أداة و حفظ دائم قيمة افتراضية قدوم ذاتي `dsh-base`، يشمل ذلك[افتراضي تحرير جهاز اختيار](../simplification/2026-09-05-base-default-file-editor.ar.md) ؛`sdk-minimal` يملك ذاتي ذات صريح قيمة افتراضية. يمكن تشغيل لقطة مسؤول ثابت قد تجميع تطبيق إخراج.

### TypeScript SDK ذاتي تعريف

`@deepseek-ai/dsh-sdk-client` اعتماد نفس إصدار `@deepseek-ai/dsh` حزمة، تحليل ذلك قد تثبيت CLI وحدة، عبر حالي Node يمكن تنفيذ ملف تشغيل هذا وحدة، و افتراضي اختيار `sdk`. اثنان طبقة عميل كل كشف `dshBin`،`profile`، لديه ترتيب `patches`،`dshHome`، عملية cwd، بيئة و مهلة؛ مهمة معنى command/argv بدء فقط إبقاء لـ fake-runtime اختبار داخلي مهايئ.

SDK مستخدم عبر profile ذاتي تعريف إضافة.`dsh plugin --profile <name> ...` إدارة حمل دائم اعتماد و تركيب حزمة ترتيب،profile `cordis.patch.yml` مسؤول حمل دائم بند إعداد تغيير، بدء وقت `patches` توفير لديه ترتيب مؤقت تغطية. ذاتي تعريف profile يجب إبقاء `@deepseek-ai/dsh-sdk-app` أو آخر عدد SDK خادم بند إعداد. متبادل مقابل CLI وحدة،patch، صريح home و عملية cwd مسار سوف في spawn قبل تغيير لـ قطعا مقابل مسار؛ ابتدائي تحويل أداة لديه لديه حد وقت حد، تشخيص سوف كتابة واضح الذي اختيار profile.

مباشر استخدام SDK وقت التزام دوران عادي Harness home تحليل: صريح `dshHome`، وراثة `DSH_HOME`، الأكثر بعد هو `~/.dsh`.`subagent-dsh-sdk` فإن اشتراط صريح قطعا مقابل home، لذلك تضمين طقم وقت التشغيل لن عبر عملية نظام home اكتشاف عدد شخص profile، قد تثبيت إضافة، اعتماد أو جلسة.DSH مخصص استخدام ACP عملية فرعية عرض مثال نفس مثال نقل دخول عزل home؛ACP خلفية ذاته متابعة ملائم لأجل غير DSH agent.

### Python وقت التشغيل

Python وقت التشغيل wheel سوف [`python/sdk-runtime/runtime-bootstrap.mjs`](../../../../python/sdk-runtime/runtime-bootstrap.mjs) مؤقت تخزين لـ `dsh-python-runtime-closure` مدخل. ذلك عادي فرع استدعاء عام CLI export؛ مزود خاص اختيار سوف في CLI تحليل قبل قسم إرسال إلى داخلي عملية فرعية runner، بينما لا هو تطبيق مدخل.[أصلي containment قرار](2026-08-28-subprocess-native-containment.ar.md) مسؤول هذا خاص قسم إرسال.Python عميل افتراضي اختيار `dsh --profile sdk`، لديه ترتيب patch ملف و صريح Harness home؛`python/sdk/examples` تحت يمكن تشغيل عرض مثال اختيار `sdk-minimal`. تثبيت `dsh` تحكم منصة أمر كشف نفسه profile لغة قاعدة، يشمل `web` profile.

يمكن تنفيذ ملف عائلة هو `deepseek-harness-sdk-runtime-<platform>-<arch>`.SDK بروتوكول صيغة،wheel و import توزيع اسم، مرافق مع ملف اسم، و بروتوكول identity `deepseek-harness-sdk-runtime` إبقاء مستقر.SDK حزمة عائلة هو `@deepseek-ai/dsh-sdk-client`،`@deepseek-ai/dsh-sdk-protocol` و `@deepseek-ai/dsh-sdk-jsonrpc-server`؛`@deepseek-ai/dsh-acp` متابعة بصفة ACP بروتوكول إضافة. مستودع لا إبقاء Python مخصص استخدام Node تطبيق، فحص دخول كامل إعداد، توافق حزمة، تحويل إرسال يمكن تنفيذ ملف، بعد تجهيز محلل أو SDK/ACP بدء آخر اسم.[docs/architecture.md](../../../../docs/architecture.ar.md) مسؤول هذا بدء طريقة،[`python/sdk-runtime` README](../../../../python/sdk-runtime/README.ar.md) مسؤول Windows تحميل جسم.

### قوي صنع تحقق

`verify-application-entrypoints` مسح تطبيق/حزمة manifest، يمكن تنفيذ شفرة المصدر و أصل demo نص برمجي. سماح بيان مقابل `dsh` منتج bin، ترتيب حذف vendor نطاق، خاص WebWorker بناء أداة و اختبار دعم حمل إجراء تصنيف. لم تصنيف shebang، جديد حزمة bin أو التفاف مرور `apps/cli/src/bin.ts` demo wrapper كل سوف جعل hygiene و primary/static CI تجمع دمج فشل.

## قائم قرار و يحل محل علاقة

[Profile أمر بسيط كتابة](../feature/2026-09-15-profile-command-shorthand.ar.md) يحل محل هذا Note في فقط لـ Web توفير بسيط كتابة آلية؛ هذا Note متابعة مسؤول تطبيق تركيب و دورة الحياة كل حق.

هذا قرار يحل محل [profile إضافة تركيب حزمة](2026-08-05-profile-plugin-bundles.ar.md) ،[TypeScript SDK عميل و SDK subagent خلفية](../../archived/feature/2026-07-27-typescript-sdk-and-sdk-subagent-backend.md) ،[إزالة SDK مشروع أداة سلسلة](../../archived/simplification/2026-08-11-remove-sdk-project-toolchain.md) و[مفرد ملف Python SDK وقت التشغيل توزيع](2026-07-10-single-file-executable-sdk-runtime-distribution.ar.md) في تطبيق بدء و حزمة اسم واقع. هذه Note مقابل profile قسم طبقة، عميل/بروتوكول دلالة، قد حذف مشروع أداة سلسلة و أصلي تحزيم ما زال قسم آخر أداة لديه مستقل مرجعي.

[ACP فقط تلقائي تحويل بروتوكول](../simplification/2026-07-23-acp-automation-only-protocol.ar.md) متابعة مسؤول ACP بروتوكول صيغة و تفاعل نطاق.[إضافة حزمة فعلي تشغيل يد سجل](../../../../docs/cookbook/adding-a-package.ar.md) مسؤول أساس في زاوية لون حزمة اسم.[مستقل sdk-minimal profile](../../archived/architecture/2026-08-24-standalone-sdk-minimal-profile.md) جزء يحل محل هذا Note base أولوية قاعدة و كامل إعداد شجرة بديل خطة، معا إبقاء هذا Note مقابل launcher كل حق قرار. لا يوجد أي نشط وثب Note يتم تماما يحل محل، أيضا لا يوجد Note رمز دمج عودة ملف شرط.

## اعتبار مرور بديل خطة

**إبقاء مباشر بدء bin، فقط إعلان دفع ترشيح profile.** رفض: فقط يلزم تلقي دعم حمل يمكن تنفيذ ملف ما زال التفاف مرور profile، وثيقة حينئذ لا يمكن يجعل profile حق صحيح مسؤول إضافة تثبيت، بيئة تحميل، إغلاق و اختبار.

**إبقاء تحويل إرسال توافق bin.** رفض: تحويل إرسال يمكن تنفيذ ملف ما زال شكل صار آخر عدد عام بدء اسم و توافق تحمل وعد. مسبق إصدار مستودع يمكن يجعل استدعاء جهة مباشر ترحيل إلى profile.

**يأخذ استدعاء جهة توفير كامل Cordis شجرة وضع إلى profile wrapper بعد وجه.** رفض: هذا فقط تجميع في argv، لا يوجد تجميع في تطبيق تركيب. كامل profile استخدام `dsh-base` إضافة خفيف كمية تطبيق تركيب حزمة، جعل مشترك سياسة فقط لديه واحد ملكية. فقط لديه عند صريح بيان ذاته يخص منتج سلوك وقت، عندئذ سماح مستودع ذاتي لديه كما لديه إصدار مستقل تركيب حزمة، أداة جسم رؤية [sdk-minimal](../../archived/architecture/2026-08-24-standalone-sdk-minimal-profile.md).

**في TypeScript بنية صنع دالة في قبول داخل ربط إضافة أو كامل `cordis.yml`.** رفض:SDK سوف لذلك يصبح آخر عدد حزمة تثبيت جهاز و تطبيق تركيب جهاز. أداة اسم profile و patch ملف قد عبر موحد واحد تحليل نموذج توفير حمل دائم و تدريجي مرة بدء ذاتي تعريف.

**فقط من `PATH` تحليل `dsh`.** رفض: عادي Node عملية لا واحد تحديد وراثة مشروع محلي `.bin` مسار. نفس إصدار حزمة اعتماد يمكن توفير تحديد وقت التشغيل.

**في `dsh-base` في تفعيل وحدة HMR، مجددا من لا أمان profile تدريجي واحد منع استخدام.** رفض: مشترك base نفس مثال تحمل تحميل ذاتي تعريف profile؛ افتراضي تفعيل سوف اشتراط كل جديد تطبيق كل تسجيل نيل خروج شفرة المصدر وحدة استبدال.base افتراضي منع استخدام سوف يجعل وحدة HMR يصبح صريح profile قدرة، معا إبقاء `patchReload: live` إعداد مراقبة نظر.

**حار إعادة تحميل بروتوكول profile.** رفض: استبدال بروتوكول خادم أو ذلك اعتماد ممكن كسر تالف انتظار معالجة بروتوكول لقطة و SDK ذاتي لديه agent. عملية إعادة بدء هو SDK و ACP إعداد تغيير اعتماد حد.

**لا فعل مستقل تحزيم إثبات حينئذ يأخذ Python يمكن تنفيذ ملف ترحيل إلى profile.** رفض: أصلي VFS إغلاق حزمة، أربعة عدد منصة wheel حزمة،profile مورد،ripgrep و spawn-helper مرافق مع ملف و جاف صاف تثبيت سلوك كل حاجة ذاتي ذات ترحيل دليل.

## تحقق

- شفرة المصدر و بناء بعد CLI تحقق استلام تغطية `sdk`،`sdk-minimal` و `acp` مساعدة مساعدة،transport بدء،stdout صاف صاف صفة،EOF، إشارة و أصل عقدة dispose.
- تركيب حزمة إعداد اختبار تثبيت إقامة `dsh-base` افتراضي منع استخدام وحدة HMR، مع مرفق نمط تغطية طبقة لا يحتوي هذا سياسة؛ ذاتي تعريف live profile e2e تثبيت إقامة بدء جهاز فقط مراقبة نظر fallback توفير إعداد إعادة تحميل.
- تجمع تركيز وحدة طقم عنصر تغطية profile بدء تحليل، ابتدائي تحويل وقت حد،SDK إعادة محاولة، خادم حينئذ خيط و تضمين طقم عزل home، و مقابل تغيير بعد وقت التشغيل شفرة المصدر تنفيذ 100% نسبة التغطية.
- تجنب مفتاح ACP و SDK لقطة بدء حقيقي `dsh` profile، و تثبيت إقامة بروتوكول إخراج و حفظ دائم سجل؛ تضمين طقم SDK تركيب سوف بدء ثاني عدد حقيقي profile وقت التشغيل.
- حقيقي API سير العمل يأخذ ملف و سطر درجة حد لـ 4، لأن واحد profile e2e ملف ممكن يملك كثير عدد كامل `dsh` عملية فرعية شجرة؛ سير العمل اختبار سوف تثبيت إقامة هذا مورد حد أعلى.
- Python طقم عنصر معا اختبار exe و node تحميل جسم؛ تحزيم وقت التشغيل مشهد، أصلي macOS يمكن تنفيذ ملف بناء، اثنان عدد wheel حزمة و جاف صاف wheel افتراضي/MCP خطر دخان اختبار سوف تثبيت إقامة `deepseek-harness-sdk-runtime-*` ناتج و profile بدء.
- `verify-application-entrypoints` يتضمن حزمة bin، يمكن تنفيذ شفرة المصدر، مباشر بدء حزمة demo wrapper و لم تصنيف demo انتظار غير قاعدة fixture(اختبار قبل وضع بيانات).

## أثر

- مستخدم عبر أداة اسم profile و لديه ترتيب patch أكثر تعديل SDK تطبيق إضافة تركيب، استخدام و أخرى كل dsh تطبيق نفسه تثبيت و تحليل نموذج.
- ذاتي تعريف profile يمكن في لا تفعيل خادم وحدة HMR حال حال تحت نيل نيل فوري إعداد مراقبة نظر، فقط لديه صريح تغطية بند إعداد عندئذ سوف تفعيل شفرة المصدر وحدة استبدال.
- كامل SDK و ACP profile مشترك كامل base تطبيق و نفس نسخة سياسة و أداة؛`sdk-minimal` يملك ذاتي ذات صريح مستقل بيان، لقطة سوف عرض هذه لحظة معنى اعتماد تجميع فرق مختلف.
- زيادة `@deepseek-ai/dsh` سوف توسيع كبير TypeScript عميل تثبيت جسم تراكم، تبديل قدوم تحديد نفس إصدار وقت التشغيل.
- تلقي معلومة مهمة مستخدم patch يمكن زيادة كتابة stdout إضافة و كسر تالف ذاتي ذات بروتوكول تدفق؛ مع مرفق profile حفظ إثبات صاف صاف، لا لـ مهمة معنى رقم ثلاثة جهة تركيب توفير حفظ إثبات.
- Python تحزيم عادي `dsh` profile بدء جهاز، معا إبقاء غلاف إغلاق أصلي وقت التشغيل،wheel مستخدم بلا حاجة نظام Node.
