# Agent Note: عبر Messages إعادة تشغيل غير قاعدة تاريخ أداة إدخال

Status: implemented

[English](2026-09-16-messages-historical-tool-input.md) | العربية

## مشكلة

Chat Completions سوف أداة معامل إبقاء لـ نص، منها ممكن يتضمن فشل استدعاء إنتاج غير قاعدة JSON. سوف هذا مقطع تاريخ تبديل إلى Messages وقت، كل `tool_use.input` كل يجب هو كائن. رفض واحد بند تاريخ معامل حينئذ سوف منع قطع يتضمن هو كل لاحق طلب، أي جعل أداة إعادة محاولة قد نجاح؛ يتضمن نفس استدعاء ملخص طلب أيضا سوف فشل.

## قرار

[Messages تسلسل تحويل جهاز](../../../../packages/llm/llm-deepseek/src/protocols/messages/serialize.ts) التزام دوران [pi-ai تاريخ تحويل](../../../../packages/llm/llm-pi-ai/src/replay.ts) فعل قاعدة: فقط في إرسال خروج تاريخ أداة إدخال في، سوف غير قاعدة JSON و غير كائن قيمة استبدال لـ `{}`. استدعاء ID، اسم، نتيجة و أصلي Session سجل إبقاء ثابت. أصلي إعادة تشغيل بيانات وصفية صالح، ناقص أو غير ممكن استخدام وقت متساو اعتماد هذا قاعدة، أيضا لن إعادة تنفيذ تاريخ استدعاء.

هذا يحل محل [Messages مهايئ قرار](../feature/2026-09-07-deepseek-messages-adapter.ar.md) في تاريخ معامل رفض قاعدة. جديد توليد Messages استجابة في نجاح إتمام قبل ما زال اشتراط أداة معامل هو صالح كائن؛ بلوغ إلى إخراج حد أعلى وقت ما زال حسب قائم قاعدة قطع قص. لا تغيير Session حدث، حفظ دائم نوع أو بروتوكول إعداد.

## اعتبار مرور بديل خطة

**رفض غير قاعدة تاريخ.** فشل استدعاء يمكن متابعة بصفة متبادل صلة دليل إبقاء، بينما لا لا بد منع قطع كل لاحق نموذج طلب.

**إصلاح أو تغطية قد تخزين معامل.** تخمين قياس ناقص جذب رقم أو إبقاء جزء تحليل نتيجة ممكن تغيير طلب عملية. فقط في طلب في استخدام فارغ إدخال يمكن إبقاء أصلي دليل، أيضا لا حاجة ترحيل.

**حذف استدعاء.** مقابل نتيجة ما زال مرجع استدعاء ID؛ معا إبقاء استدعاء و نتيجة، يمكن إبقاء أداة تفاعل بينما لا تحرير صنع معامل.

## عاقبة

Messages يمكن في حذف غير ممكن استخدام تاريخ معامل معا متابعة جلسة، و إبقاء استدعاء هوية و نتيجة. نموذج يرى هو `{}`، بينما لا هو أصلي غير قاعدة نص؛ هذا التقاط قاع و pi-ai واحد مثال لا إنتاج تشخيص. أصلي معامل ما زال يمكن في Session سجل في فحص قراءة؛ هذا لا حفظ إثبات مزود إدخال بلا ضرر، أيضا لا إصلاح جديد توليد غير قاعدة استدعاء.

تحقق تغطية فقط قبول كائن تحويل، فشل نتيجة بعد مستخدم إدخال،JSON نحو إرجاع، صالح و تخفيض إعادة تشغيل بيانات وصفية، عبر قد إصدار headless profile و حقيقي Messages تسلسل تحويل جهاز تشغيل[تسجيل صنع Session](../../../../snapshots/session/deepseek-messages-invalid-tool-history/snapshot.yml) ، و حاجة اعتماد حقيقي Messages متابعة وصل.
