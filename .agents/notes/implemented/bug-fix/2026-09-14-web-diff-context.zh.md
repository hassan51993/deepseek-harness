# Agent Note: Web diff بطاقة مقارنة مقارنة يحتوي سياق محتوى

Status: implemented

[English](2026-09-14-web-diff-context.md) | العربية

## Problem

نظام الملفات نتيجة بيانات وصفية يحمل قبل بعد نص قطعة مقطع يتضمن لم تعديل سياق. يأخذ كامل قطعة مقطع قسم آخر عند عمل حذف و إضافة جديدة سوف خطأ علامة مشترك سطر، و مبالغة كبير بطاقة و طي أداة سطر موحد حساب.

## Decision

Web أصل لغة عبر صيانة في `diff` مكتبة توليد سطر رقعة، استخدام `maxEditLength: 256`. كل موضع دقيق تعديل اثنان جانب الأكثر كثير إبقاء ثلاثة سطر في صفة سياق؛ بعيد مسافة مغادرة تعديل قسم صار مستقل hunk، مشترك سياق لا حساب دخول زيادة حذف موحد حساب. كل قطعة مقطع إضافة جديدة و حذف سطر عدد تجاوز مرور 256 وقت، بحث إيقاف، كامل جديد قديم قطعة مقطع حسب خشن حبة درجة استبدال عرض، مشترك سطر أيضا حساب دخول عرض، نسخ و موحد حساب. بطاقة و `diffTotals` استخدام نفس تحديد صفة دفع توجيه. هذا التزام دوران[أداة عرض ملكية قرار](../architecture/2026-08-23-client-derived-tool-presentation.zh.md) ، ما زال يخص Client عرض، لا تغيير حفظ دائم بيانات وصفية أو عام props.

## Alternatives considered

بلا حد أعلى مقارنة مقارنة سوف يجعل كبير كمية تعديل قطعة مقطع طي ملخص توقف توقف. تحديد صفة تحرير مسافة مغادرة حد أعلى قدرة يجعل نادر متباعد تحرير إبقاء دقيق، لا تلقي ملف طويل درجة أثر؛ جدار ساعة مهلة ممكن جعل ملخص و متن في سالب تحميل تحت اختيار مختلف نتيجة. خشن حبة درجة استبدال في تجاوز مرور حد أعلى بعد وضع ترك مقابل متساو، لكن إبقاء الكل إدخال سطر. ذاكرة مؤقتة أو مختلف خطوة تصيير سوف زيادة ملكية و بطلان معالجة، بينما محدود مقارنة مقارنة لا حاجة هذه آلية. هذا عرض سلوك بلا حاجة توسيع حفظ دائم بيانات وصفية أو صيانة ذاتي تعريف diff حساب قاعدة.

## Measurement

محلي CPU تشخيص استخدام esbuild(`--bundle --platform=node --format=esm`) تحزيم إنتاج `DiffBlock.tsx` مدخل، و في macOS ARM64 Node 26.5.0 تحت حساب وقت `diffTotals`. كل قطعة مقطع لديه واحد ألف سطر: الكل استبدال حمل وحيد بحث جذب سطر، متساو متساو قسم نشر 100 موضع استبدال، أو تسليم بديل تكرار `old`/`shared` و `new`/`shared` سطر. لا حساب إدخال بنية صنع و وحدة تحميل؛ إرجاع موحد حساب قيمة إبقاء يمكن بلوغ. هذه هو دالة استهلاك وقت، لا هو متصفح رسم صنع أو إدخال تأخير متأخر، أيضا لا يوجد بصفة CI وقت عتبة قيمة.

| إدخال | بلا حد أعلى جزء ثانية عدد | محدود بحث جزء ثانية عدد |
| --- | --- | --- |
| الكل استبدال | 6492.16, 6777.79, 6786.79 | 5.25, 4.66, 4.19 |
| 100 موضع نادر متباعد استبدال | 8.19, 4.58, 4.01 | 7.58, 4.26, 4.13 |
| تسليم بديل تكرار سطر | 3383.13 | 10.26, 7.46, 5.52 |

حد أعلى سماح الكل 100 موضع نادر متباعد استبدال إبقاء دقيق. إزالة حد أعلى وقت،129 موضع استبدال ارتداد سوف فشل، لأن بلا حد أعلى تنفيذ إرجاع دقيق موحد حساب، بينما غير اشتراط كامل قطعة مقطع رجوع.

## Consequences

متصفح بناء يتضمن `diff`. حد أعلى قيد تحرير رسم بحث، لا قيد جدار ساعة وقت طويل: مواصفة تحويل، رجوع سطر و نسخ محتوى ما زال مع إدخال طويل درجة زيادة طويل، توسيع بطاقة أيضا سوف مفرد وحيد دفع توجيه متن سطر. محتوى سطر قاعدة يأخذ نهاية ذيل تبديل سطر نظر لـ إنهاء رمز. ارتداد تغطية 256 مرة تحرير وقت دقيق إخراج، تجاوز مرور حد أعلى بعد كامل خشن حبة درجة إخراج، واحد ألف سطر في نادر متباعد تحرير، مشترك و بعيد مسافة مغادرة سياق، تكرار سطر، نسخ بادئة و ملخص و قاع جزء موحد حساب متسق صفة. تحرير كتابة و استعارة استخدام Session لقطة قسم آخر تغطية خشن حبة درجة و دقيق متصفح بطاقة.
