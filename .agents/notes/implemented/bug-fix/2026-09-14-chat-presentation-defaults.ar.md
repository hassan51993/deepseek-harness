# Agent Note: إبقاء Chat عرض و Trajectory عرض مستقل

Status: implemented

[English](2026-09-14-chat-presentation-defaults.md) | العربية

## مشكلة

Trajectory عرض ملائم دمج مباشر عرض كامل قد سجل تفكير اعتبار. سوف هذا افتراضي سلوك تطبيق إلى Chat سوف في تفكير اعتبار خلال توسيع فوري محادثة، و في عودة جواب أو استدعاء الأداة إلى قدوم وقت تغيير ذلك عال درجة.Trajectory عرض تعديل أيضا لـ Chat زيادة تاريخ أول token حساب وقت استعادة، لكن لا يوجد مستقل Chat سلوك قرار.

## قرار

[Chat](../../../../packages/client/ui-chat/README.ar.md#turn-process-folding) كل تفكير اعتبار سطر ابتدائي كل طي، لاحق إخراج و تسوية إبقاء مستخدم يد حركة اختيار توسيع حالة. تسوية سوف إزالة مراقبة قياس إلى فوري chunk، و من حمل دائم حدث إعادة بناء Chat عودة تكرار عقدة، لا من داخل تضمين تدفق استعادة أول token وقت. لذلك، فوري تسوية بعد و إعادة فتح تاريخ بعد، اكتمل جولة كل لا عرض TTFT و حل رمز سرعة درجة. جولة درجة مرور مسار طي ما زال مستقل صيانة.

[Trajectory عرض](../feature/2026-09-09-ptc-trajectory-code-inspection.ar.md) إبقاء تفكير اعتبار افتراضي توسيع، قد سجل حساب وقت،JSON تحكم عنصر و PTC شفرة عرض جهاز.[ضيق تجميع تدفق قراءة جهاز](../architecture/2026-09-06-embedded-stream-record-readers.ar.md) ما زال توفير Trajectory و أخرى مستهلك استخدام. هذه قرار جزء يحل محل Chat عرض زيادة كمية، معا إبقاء اثنان نسخة سجل كل منها مستقل إدارة من.

## اعتبار مرور بديل خطة

**إبقاء Chat تلقائي توسيع و تاريخ حساب وقت استعادة.** هذه تغيير الذي طلب Trajectory عرض عمل خارج Chat سلوك. إعادة جذب دخول مهمة واحد سلوك كل حاجة مستقل Chat منتج قرار و متبادل ينبغي تحقق.

**سحب عودة كامل عرض تعديل.** هذا سوف في سحب عودة معنى خارج Chat تعديل معا إزالة الذي طلب Trajectory سلوك.

## أثر

Chat تفكير اعتبار حاجة نقر عندئذ قدرة عرض كل نص. جولة مجموع استهلاك وقت و مستقل إسقاط Session Stats ما زال متاح. تجميع جهاز اختبار منطقة قسم فوري تسوية وقت إزالة مؤقت بيانات و إعادة فتح حمل دائم تاريخ؛ متصفح إعادة تشغيل تحقق إعادة تحميل قبل بعد اكتمل جولة حساب وقت محادثة إطار. مكون اختبار تغطية تدفق صيغة و فقط تفكير اعتبار عودة تكرار افتراضي طي، و عودة جواب و استدعاء الأداة إلى قدوم وقت يد حركة توسيع حالة.Trajectory اختبار إبقاء ذلك مستقل قيمة افتراضية و حساب وقت.
