# Agent Note: pi-ai ترقية توافق صفة

Status: implemented

[English](2026-09-05-pi-ai-upgrade-compatibility.md) | العربية

## Problem

pi-ai مهايئ صريح تصنيف فوق تنقل توافق حقل، و كما فقط حفظ دائم لاحق طلب حاجة إعادة تشغيل بيانات وصفية.SDK ترقية ممكن في لا تغيير Harness مزود غير متصل API حال حال تحت لـ مهمة واحد تجميع دمج إضافة جديدة حقل. لم تصنيف إعداد حقل سوف توجيه يؤدي تحرير ترجمة فشل؛ متروك تسرب إعادة تشغيل بيانات وصفية فإن ممكن ساكن صامت تغيير لاحق مزود طلب.

## Decision

مهايئ التزام دوران [pi-ai 0.85.1](https://github.com/earendil-works/pi/blob/v0.85.1/packages/ai/CHANGELOG.md).`thinkingTokenBudgetField`،`vllmPriority` و `supportsMaxOutputTokens` هو صريح تفعيل شبكة صلة تحكم؛`thinking.budget` إضافة دخول قائم نموذج لوح احتلال موضع رمز.SDK يملك ميزانية تحليل و تسلسل تحويل.`supportsMidConvoEffort` و `allowedFallbackModels` ما زال من دليل يملك، لأن ذلك صحيح تأكيد صفة اعتماد تأكيد قطع Anthropic نقل، نموذج قدرة و رجوع تحديد قيمة.

اختياري `providerThinkingLevel` حفظ في مهايئ replay-v2 استجابة بيانات وصفية في، يجعل Anthropic تاريخ إبقاء مزود أصلي effort. ناقص ما زال صالح؛ إعادة تشغيل إصدار و قد إصدار Session صيغة متساو لا تغيير. إعادة تشغيل مصدر إبقاء طلب نموذج،`responseModel` فإن إبقاء Anthropic آخر اسم تحليل أو رجوع بعد نموذج. إعادة بناء سوف استعادة هذا أصلي نموذج، يجعل pi-ai متابعة تطبيق ذلك عبر نموذج توقيع قاعدة. مزود غير متصل LLM API إبقاء ثابت؛[حسب مزود توجيه إعادة تشغيل ملكية قاعدة](../architecture/2026-07-14-provider-routed-llm-adapters.ar.md) ما زال ملائم استخدام.0.84.2 Anthropic مهايئ[من طلب ابتدائي تحويل `model`](https://github.com/earendil-works/pi/blob/v0.84.2/packages/ai/src/api/anthropic-messages.ts#L510-L515) ، و كما[في رسالة بدء وقت فقط سجل استجابة ID و استخدام كمية](https://github.com/earendil-works/pi/blob/v0.84.2/packages/ai/src/api/anthropic-messages.ts#L589-L605). هو من لا كتابة `responseModel`، لذلك ذلك إعادة تشغيل سجل إبقاء طلب نموذج، لا يحمل أصلي نموذج بيانات وصفية.

## Alternatives considered

**إبقاء كل إضافة جديدة حقل لـ غير ممكن إعداد.** هذا سوف يأخذ نشر يملك شبكة صلة تحكم خطأ تصنيف لـ دليل واقع: فوق تنقل واضح لا في توليد دليل في ضبط ميزانية حقل اختيار و vLLM أولوية درجة.

**فتح وضع كل إضافة جديدة حقل.** هذا سوف سماح مهمة معنى شبكة صلة في نقص قليل دليل دليل وقت إعلان دعم حمل نموذج مخصص تابع Anthropic effort و رجوع قدرة، بينما هذه دليل صحيح هو متبادل صلة وظيفة صالح اعتماد حسب.

## Consequences

تحرير ترجمة مدة تغطية إبقاء صريح حقل تصنيف.[توافق صفة اختبار](../../../../packages/llm/llm-pi-ai/tests/compat-upgrade.spec.ts) تغطية schema قبول، بلا فاعلية قيمة، بروتوكول ملائم استخدام نطاق و شيء تحويل، كما لا تغيير قيمة افتراضية.[إعادة تشغيل تحويل اختبار](../../../../packages/llm/llm-pi-ai/tests/convert.spec.ts) تغطية اختياري effort إبقاء. خلط دمج بروتوكول دليل اختبار استخدام قد تثبيت OpenCode دليل. مزود سلوك ما زال من فوق تنقل يملك؛ حقيقي مزود تحقق و بلا حاجة مفتاح مهايئ اختبار قسم فتح.
