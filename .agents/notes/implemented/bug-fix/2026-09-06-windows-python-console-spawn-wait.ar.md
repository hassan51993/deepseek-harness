# Agent Note: انتظار Windows Python تحكم منصة وقت التشغيل

Status: implemented

[English](2026-09-06-windows-python-console-spawn-wait.md) | العربية

## مشكلة

Python تثبيت `dsh.exe` تحكم منصة أمر سوف في ابتدائي تحويل profile قبل بين راحة صفة أرض بـ Windows وصول اندفاع مفاجئ `0xc0000005` خروج. ذلك خطر دخان تأكيد متروك تسرب عملية حالة، فقط تقرير إبلاغ فارغ معيار تدفق. أصلي faulthandler استكشاف قياس (run 34030851888) سوف لذا عائق تحديد موضع في وقت التشغيل تحكم منصة مدخل استدعاء Python 3.10 `os._execvpe`، بينما غير تحزيم Node يمكن تنفيذ ملف. مباشر بدء يمكن تنفيذ ملف مقابل وفق عبر.

## قرار

[Python تحكم منصة مدخل](../../../../python/sdk-runtime/src/deepseek_harness_runtime/__init__.py) في Windows فوق استخدام `subprocess.run`، وراثة معيار تدفق و بيئة، انتظار وقت التشغيل انتهاء، مجددا بـ وقت التشغيل حالة خروج.POSIX إبقاء `os.execvpe` عملية استبدال.Windows CRT exec و غير POSIX عملية استبدال؛ صريح بدء و انتظار مسار تجنب فتح مراقبة قياس إلى أصلي exec عملية.

[تثبيت بعد wheel خطر دخان اختبار](../../../../scripts/smoke-python-runtime.py) في profile تثبيت فشل وقت، معا تقرير إبلاغ عشرة دخول صنع، بلا رمز رقم 32 موضع عشرة ستة دخول صنع حالة و التقاط معيار تدفق. هذا إبقاء عادي أمر فشل و أصلي عملية استثناء منطقة آخر.

## قد اعتبار بديل خطة

**منع استخدام Node تحرير ترجمة ذاكرة مؤقتة.** لم اعتماد: مبكر مدة استكشاف قياس في ذاكرة مؤقتة بيئة تغير و نتيجة متبادل صلة، لكن بارد ذاكرة مؤقتة مقابل وفق أيضا قدرة عبر، كما Python faulthandler سوف فعلي لذا عائق تحديد موضع في أصلي exec استدعاء. ذاكرة مؤقتة إعداد إبقاء ثابت.

**إعادة محاولة أو التفاف مرور قد تثبيت تحكم منصة أمر.** رفض، لأن اثنان من كل سوف إخفاء غطاء قد إصدار أمر فشل، بينما لا هو إصلاح عملية بدء.keyless تثبيت بعد wheel تأكيد ما زال لـ مطلوب فحص.

## عاقبة

Windows إبقاء Python أب عملية مباشر إلى وقت التشغيل خروج، لم يعد اعتماد CRT overlay سلوك. معيار تزامن عملية فرعية تنفيذ مسؤول انتظار و في قطع تنظيف. لا إضافة ذاتي تعريف عملية شجرة إدارة جهاز أو عام رئيسي آلة ضبط.

[وقت التشغيل تحليل اختبار](../../../../python/sdk/tests/test_runtime_resolution.py) إبقاء POSIX تحويل إرسال تحقق، و تغطية Windows معامل/بيئة تحويل إرسال، حالة 0/37/513، حقيقي عملية فرعية إتمام،Unicode معيار تدفق و حمل فارغ إطار معامل. عرض خروج حالة من أصلي Windows تحقق، لأن POSIX سوف سوف عملية حالة قطع قطع لـ ثمانية موضع. أصلي ثابت مرة عدد مقابل وفق (run 34031142773) في، تفعيل تحرير ترجمة ذاكرة مؤقتة أربعة مرة إصلاح بعد بدء الكل عبر؛ هذا دفعة مرة أربعة مرة لم إصلاح مقابل وفق أيضا الكل عبر، لذلك هو لا هو نفس دفعة مرة تكرار الآن. كامل تثبيت بعد wheel CI يجب مستقل في محلي فرع درجة اختبار، تحقق نهائي ناتج.
