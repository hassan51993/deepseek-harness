# Agent Note: في إنشاء وقت إخفاء Windows عملية فرعية تحكم منصة نافذة

Status: implemented

[English](2026-09-16-windows-subprocess-console-visibility.md) | العربية

## مشكلة

PTC وقت التشغيل و shell استدعاء مشترك استخدام Windows عملية فرعية مزود. ذلك عادي Job runner لم ضبط نافذة إخفاء، أصلي هدف فقط توفير معيار جملة مقبض بينما لا يوجد بدء مرئي صفة علامة سجل. لذلك،Desktop تنفيذ قصير أمر وقت ممكن وميض الآن تحكم منصة نافذة.

## قرار

خاص Node Job runner استخدام `windowsHide: true`. عادي و تلقي حد أمر لوحة أصلي عملية إنشاء في هدف شفرة تشغيل قبل، سوف `STARTF_USESHOWWINDOW` و `SW_HIDE` و معيار جملة مقبض واحد بدء نقل دخول. تحكم منصة وراثة، استعادة خط مسار قبل قسم إعداد Job و إدارة طريق ملكية إبقاء ثابت. أي عملية كل لا إخفاء قد لديه أب تحكم منصة، أيضا لا تحمل وعد كبح صنع أمر صريح فتح نافذة.

[ACL صندوق رملي قرار](../feature/2026-08-08-windows-acl-restricted-token-sandbox.zh.md) ما زال مسؤول تلقي حد أمر لوحة سياسة و تحكم منصة عزل حد. ضبط ابتدائي نافذة مرئي صفة لا حاجة نحو تلقي حد عملية إنشاء إضافة `CREATE_NO_WINDOW` أو `CREATE_NEW_CONSOLE`.

## اعتبار مرور بديل خطة

**فقط إخفاء خارج طبقة runner.** أصلي هدف إنشاء مستقل في Node بدء خيار، لذلك أيضا حاجة واضح ضبط ابتدائي مرئي صفة.

**إزالة كل عملية تحكم منصة.** تلقي حد أمر لوحة إعداد دمج تحكم منصة عزل علامة سجل وجود قد سجل DLL ابتدائي تحويل فشل. بدء مرئي صفة ضبط إبقاء قائم تحكم منصة مرفق حال قاعدة.

**PowerShell بدء بعد مجددا إخفاء نافذة.** نافذة ممكن في نص برمجي تنفيذ قبل قد مرئي؛ إنشاء وقت ضبط يمكن تجنب تجنب هذا واحد بين فصل.

## عاقبة

عادي عملية فرعية بدء كبح صنع مرفق حمل تحكم منصة نافذة، لا تغيير أداة إخراج أو عملية تنظيف. أصلي Windows اختبار فحص بعد بديل عملية و اثنان نوع ACL نمط تحكم منصة مرئي صفة، و إعداد دمج قائم تدفق، تحكم إدارة طريق و Job دورة الحياة اختبار. لا يوجد تحكم منصة أيضا هو صالح حالة؛ اختبار لا اشتراط تحكم منصة يجب وجود. بدء معامل اختبار ثابت إنشاء وقت حفظ إثبات، مفرد وحيد مراقبة نهائي مرئي صفة لا يمكن تأكيد هذا واحد نقطة.

جلسة تسجيل صنع لا يمكن مراقبة أصلي تحكم منصة نافذة، تحويل تسجيل محتوى أيضا لا يوجد تغير. هذا ارتداد من Windows أصلي اختبار مسؤول؛ متصفح قطع رسم لا يمكن تأكيد طاولة وجه نافذة لا وجود.
