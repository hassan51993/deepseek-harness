# Agent Note: في Desktop إنتاج بدء قبل تنظيف تطبيق إدارة حزمة

Status: implemented

[English](2026-09-15-desktop-profile-core-cleanup.md) | العربية

## Problem

قديم Desktop profile يتضمن قد تثبيت نواة قلب حزمة و محلي tarball اعتماد إعلان. أي جعل تطبيق يحمل متسق إصدار ناتج، محلي حزمة أولوية قاعدة ما زال ممكن يأخذ قديم Web قبل طرف و جديد إضافة تركيب بدء قدوم. مستخدم تبديل إلى قد تثبيت تطبيق وقت، تطوير نمط رجوع رابط أيضا سوف ناقص إبقاء.

## Decision

إنتاج إصدار Desktop في بدء Host قبل، يحتفظ قائم profile قفل، تنظيف قد تحقق وقت التشغيل وصف رمز أو قديم Desktop حزمة بيان سجل صف خروج حزمة فرعي هذا. تنظيف حذف مقابل اعتماد إعلان و pnpm overrides، في حزمة حالة تغير وقت جعل قفل ملف بطلان، و حل حذف رجوع رابط بينما لا حذف ذلك هدف. أخرى إضافة،bundle اختيار، إعداد و جلسة بيانات إبقاء. تطوير نمط قفز مرور تنظيف.

تنفيذ و مؤقت تفعيل معتاد كمية تجميع في في `apps/desktop/src/profile-core-cleanup.ts`، من profile دقيق تجهيز مسار في واحد استدعاء وصل دخول. كل مرة إنتاج بدء كل تنفيذ تنظيف، لأن تطوير نمط أو حزمة عملية ممكن إعادة إنتاج ناقص إبقاء. هذا حد تحديد[داخل وضع وقت التشغيل قرار](../architecture/2026-09-08-desktop-bundled-runtime-and-external-plugins.ar.md) في حزمة إبقاء نطاق؛ مباشر كتابة و فشل استعادة إبقاء ثابت.

## Alternatives considered

**فقط في تثبيت جهاز في تنظيف**سوف متروك تسرب أخرى مستخدم profile و تثبيت بعد إعادة إنتاج حزمة؛ اثنان عدد منصة كل في بدء وقت تنظيف.

**حذف مجموعة نسج اسم بادئة تحت كل حزمة**ممكن خطأ حذف اختياري رسمي جهة إضافة. واضح حالي و تاريخ حزمة بيان قرار ملكية.

**فقط حذف حزمة دليل**سوف يجعل pnpm أصل حسب إبقاء إعلان و overrides إعادة تثبيت نفسه قديم حزمة.

## Consequences

إنتاج إصدار لم يعد استخدام profile مقابل استخدام إدارة حزمة محلي تغطية. حدوث تغير profile إسقاط قفل ملف، تحت مرة pnpm عملية سوف إعادة تحليل ذلك بقية إضافة اعتماد. تنظيف لا تشغيل pnpm، أيضا لا إنشاء تراجع حالة؛ فشل سوف إيقاف دقيق تجهيز مسار، بعد يمكن إعادة محاولة. إعادة تحديد نحو حزمة أب دليل سوف في حذف قبل تقرير خطأ. تحديد نحو اختبار تغطية إضافة إبقاء، إعلان، تكرار تنظيف، تطوير نمط ترتيب حذف، تراجع دور حزمة، بلا فاعلية سجل و رابط هدف.
