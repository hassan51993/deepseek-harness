# Agent Note: إدراج دخول رقعة إضافة ملف URL

Status: implemented

[English](2026-09-05-patch-plugin-file-urls.md) | العربية

## Problem

Node ESM سوف يأخذ Windows قرص رمز بادئة حل تفسير لـ URL scheme، و يأخذ ملف اسم في قطعة مقطع محرف نظر لـ URL لغة قاعدة. لذلك، مباشر سوف نظام الملفات مسار نقل إعطاء إضافة استيراد سوف جعل Windows قطعا مقابل مسار و يتضمن `#` أو `%` ملف اسم تحميل فشل.

## Decision

رقعة ملف تحليل سوف `insert` بند و ذلك تضمين طقم قسم مجموعة في هذا آلة قطعا مقابل مسار، متبادل مقابل في رقعة ملف `./` أو `../` اسم تحويل لـ ملف URL. حزمة معرف رمز، قد لديه URL، قد لديه بند اسم تأكيد و استبدال استخدام `config` قيمة إبقاء أصل لديه يحتوي معنى. تحليل مرحلة مقطع مسؤول تحويل، لأن في دمج كل طبقة قبل هو كف إمساك مصدر رقعة دليل.

اختياري `HostResolvedRootInclude` استيراد تغطية كتابة سوف آخر خارج لـ اختيار تثبيت مضيف تحليل أساس عنوان استدعاء جهة تحويل قطعا مقابل مسار. عادي CLI profile لا اختيار هذا تغطية كتابة، لذلك هو لا يستطيع بديل بديل رقعة ملف تحويل.

## Alternatives considered

**فقط في Python fixture في استخدام `Path.as_uri()`.** هذا قدرة تجنب فتح مرة فشل، لكن مستخدم تحرير كتابة profile و overlay رقعة ما زال سوف لقاء إلى مشكلة.

**تعديل مشترك Loader أساس عنوان.** هذا سوف فقد فقد تدريجي رقعة مصدر معلومة و تغيير عار حزمة تحليل. ملف URL إبقاء اختيار تحديد محلي ملف، بلا حاجة تعديل تحليل أساس عنوان.

## Consequences

اختياري و مطلوب رقعة قراءة جهاز مشترك استخدام هذا تحويل. مباشر Loader استيراد و استبدال قسم مجموعة config جذب دخول فرعي بند لا في ذلك نطاق داخل؛ توسيع هذه مسار حاجة كل منها دلالة و تغطية.

رقعة قراءة جهاز اختبار تحقق تحويل و حقيقي تنشيط. بناء بعد SDK تحقق استلام تحميل ملف اسم يحتوي URL حساس شعور محرف قطعا مقابل مسار overlay إضافة، و تحقق ذلك نظام الملفات علامة، ابتدائي تحويل و إغلاق.
