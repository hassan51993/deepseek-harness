# Agent Note: PTC mode انهيار تقليص منفذ بينما غير فقط عبر إبلاغ وجه

Status: implemented

[English](2026-08-07-ptc-executor-collapse.md) | العربية

## مشكلة

`mode: 'ptc'` فقط انهيار تقليص عبر إبلاغ وجه، لا يوجد انهيار تقليص تنفيذ وجه.`wireSchemas()` فقط نحو نموذج إرسال واحد أداة——`run_code`——لكن منفذ عبر `get()` تحليل كل استدعاء، بينما `get()` إرجاع كامل مرئي أداة جدول خارج إضافة إبقاء نقل أداة. نموذج واحد حالما إرسال خروج أصلي أداة اسم (`write`،`read`،`bash`،`subagent` انتظار) ، حينئذ قدرة تماما التفاف مرور `run_code`: استدعاء وفق معتاد مشي كامل خط الإنتاج و تنفيذ نجاح، كل إدارة هو schema من لم يتم عبر إبلاغ مرور. نموذج مزود لا اعتراض قطع لم عبر إبلاغ أداة اسم، لذلك لا إرسال schema انتظار في لا يوجد قيد.

حزمة عقد نحو نقطة اسم هذا عدد عكس نمط: عند مباشر استدعاء جهة يمكن التفاف مرور وقت،schema حذف لا حساب قوي صنع تنفيذ؛ رفض يجب مرور منفذ تحقق.

## قرار

`ToolRuntime` عبر إضافة جديدة خاص `resolveExecution(name, scope, nested)` تحليل يمكن تنفيذ تعريف، في يملك هذا قرار عملية حد فوق تطبيق نمط انهيار تقليص. عند `modeFor(scope)` تحليل لـ `ptc` وقت، نموذج مباشر نداء (`nested = false`) فقط سماح تسمية إبقاء `run_code` نقل أداة؛ أي أصلي اسم حرف كل تحليل لـ `undefined`، و بـ منفذ قائم `UNKNOWN_TOOL` خطأ عرض، ذلك رسالة سوف إشارة خروج تعديل مشي `run_code` صحيح تأكيد مسار——لأن هذا عدد اسم حرف مقابل حالي نموذج بينما قول هو**قد إعلان مرور**(قد في توقف استدعاء جهة signal إبقاء إلغاء عقد نحو:`ABORTED_BEFORE_DISPATCH`، و تطبيق مرئي أداة finalizer). صالح scope نمط يشمل من agent preset وراثة إعلان، لذلك ذلك wire schema و تنفيذ إذن إبقاء متسق. يتم انهيار تقليص استدعاء في `createExecution`(`prepare` رقم واحد مرحلة مقطع) أي إنهاء——في يمكن توسيع سياسة خط الإنتاج قبل، لذلك `tools/pre-execute` مستمع،approval `ask` و guard دائم بعيد لن مراقبة إلى واحد ملاحظة تحديد يتم رفض استدعاء، شخص صنف أيضا لن يتم تلميح ذهاب دفعة دقيق هو. تضمين طقم فرعي استدعاء (`nested = true`——أي ضبط `parent` token، إنتاج شفرة في فقط لديه `run_code` SDK ربط سوف ضبط) يمكن استدعاء مهمة معنى مرئي أداة، لذلك برنامج إبقاء توليد SDK إعلان الكل ربط.

تنفيذ سلسلة مسار أربعة موضع فحص جدول——`executionMode`،`dispatchToolBody`،`postExecute`،`normalizeDispatchResult`——تعديل مشي `resolveExecution`.`createExecution` عبر مشترك `collapses(name, nested)` يسمى كلمة تطبيق نفس انهيار تقليص، بـ سهل في سياسة خط الإنتاج قبل منطقة قسم يتم انهيار تقليص استدعاء و حق صحيح لم معرفة اسم حرف. عام مشترك سجل التسجيل عرض (`get`) و SDK إسقاط (`schemas`) دلالة ثابت: عرض، فحص و ربط قطعة رفع ما زال يرى كامل مرئي تجميع دمج. عبر إبلاغ (`wireSchemas`) و منفذ الآن متسق. حمل غير JSON يمكن تسلسل تحويل معامل انهيار تقليص استدعاء تقرير إبلاغ معامل `TypeError`(invalid-args عقد نحو) ، بينما غير `UNKNOWN_TOOL`——دالة جسم ما زال لن تشغيل، سياسة أيضا لن تنفيذ.

انهيار تقليص هو أمان متبادل صلة ثابت كمية، لذلك تحقق استلام مرور منفذ تثبيت ميت:`ptc` نمط تحت نموذج مباشر نداء أصلي أداة إرجاع `UNKNOWN_TOOL`؛ نفس أداة مرور SDK فرعي استدعاء نجاح؛`native`/`both` نمط مباشر نداء و `run_code` ذاته سلوك ثابت. هذا note يأخذ تنفيذ حد تراكم إضافة في أساس أساس [PTC mode أساس أساس](../feature/2026-06-15-ptc.ar.md) لـ فوق، نقل تصميم من بعد من يملك.

## تجهيز اختيار خطة

### حسب نمط مرور ترشيح `get()` / سجل التسجيل عرض

عرض يتم عرض جهة،`tool-cordis` فحص و SDK ربط إزالة استهلاك؛ انهيار تقليص عرض سوف من برنامج جدول وجه إخفاء ما زال يجب ربط أداة، و تغيير كل إزالة استهلاك من عام مشترك تحليل عقد نحو، بينما لا فقط هو منفذ.

### في agent-loop مدخل مرور ترشيح

loop لا هو وحيد منفذ استدعاء جهة، كما حق صحيح يلزم ضيق منطقة قسم (نموذج مباشر نداء vs نقل فرعي استدعاء) تعليق في تنفيذ إدخال فوق، لا في loop حد. مدخل مرور ترشيح أيضا سوف تكرار تحرير رمز سجل التسجيل قد يملك نمط دلالة.

### عبر داخل وضع guard رفض

guard هو اختياري إضافة توسيع؛ أمان ثابت كمية لا يستطيع اعتماد نشر تماما جيد تجميع صحيح تأكيد إضافة. نمط قرار عودة سجل التسجيل كل، يجب من هو ذاتي ذات تنفيذ.

### فقط إبقاء schema حذف (صيانة حمل الآن حالة)

لا يوجد مزود حفظ إثبات اعتراض قطع لم عبر إبلاغ اسم حرف؛ يتم تقرير إبلاغ جلسة إثبات اعتراض قطع لن حدوث.

## عاقبة

- `mode: 'ptc'` الآن صرف الآن ذلك عبر إبلاغ: نموذج مباشر نداء أصلي أداة تغيير لـ `UNKNOWN_TOOL`، نموذج يمكن عبر تعديل مشي `run_code` ذاتي سطر تصحيح صحيح (قد في توقف استدعاء ما زال حسب إلغاء عقد نحو تحليل لـ `ABORTED_BEFORE_DISPATCH`).
- `both` و `native` سلوك ثابت؛SDK فرعي استدعاء ثابت (حكم آخر إشارة هو `parent` token).
- يتم انهيار تقليص استدعاء في `prepare` مرحلة مقطع أي يتم رفض——في يمكن توسيع سياسة خط الإنتاج قبل:pre-execute مستمع،approval `ask` و guard دائم بعيد لن مراقبة إلى هو.`executionMode` نفس مثال fail-closed(`exclusive`) ، ضبط درجة بلا يمكن مراقبة فرق مختلف.
- أصلي أداة إشارة جذب مقطع (`tool:read`،`tool:write`،`tool:bash` انتظار) إبقاء في توجيه النظام في، لأن هو جمع معا وصف عبر توليد SDK و أصلي دالة استدعاء متاح قدرة، منها إذا جاف مقطع أيضا تحمل تحميل حال أي مفرد عدد أداة وصف كل تركيب لا تحت عبر أداة توجيه سياسة (`read` أولوية في `bash cat`، افتراضي fs-observation-policy اشتراط أولا `read` مجددا `write`، واحد اثنان عدد تفويض إرسال استخدام `subagent` بينما غير `workflow`). منع توقف نموذج مباشر نداء أصلي أداة هو منفذ انهيار تقليص، بينما غير نص التوجيه مرور ترشيح.
- نص التوجيه سوف**إعلان**هذا بند انهيار تقليص، يقع في first-party تدريجي أداة إشارة توجيه قبل `tools:ptc-only` مقطع. ذلك بعض مقطع فقط كتابة خروج أداة اسم بينما لا حد تحديد ذلك يمكن بلوغ طريقة، لذلك فقط قراءة إلى هو جمع نموذج سوف إرسال خروج أصلي استدعاء، لـ واحد نفس نسخة نص التوجيه للتو للتو إعلان مرور أداة استلام إلى `UNKNOWN_TOOL`، دخول بينما حكم تحديد نشر لا متسق، بينما لا هو ذاتي سطر تصحيح صحيح. رفض معلومة إعطاء خروج صحيح تأكيد مسار أيضا هو نفس سبب.TypeScript SDK مقطع في توليد إعلان جانب مجددا مرة منطقة قسم اثنان من، سوف ذلك علامة لـ فقط قدرة في برنامج داخل استخدام ربط، و شرح فقط لديه مفرد وحيد توفير أداة schema عندئذ منح إعطاء مباشر نداء إذن. إعلان قائمة ممكن يتم خطأ قراءة لـ أصلي أداة متاح صفة، لذلك عند حالي `bash` معامل schema قبول عرض مثال معامل وقت، هذا مقطع سوف إعطاء خروج بـ `run_code` حزمة إقامة `tools.bash(...)` كامل استدعاء.`both` تحت هذا قاعدة تصيير لـ فارغ: هو أصلي استدعاء تأكيد فعلي سوف تنفيذ، في ذلك داخل إعلان حينئذ هو زائف كلام——هذا أيضا هو `both-mode-turn` لم يعد و `ptc-turn` مشترك استخدام مدة نظر نص التوجيه سبب.
- لم قدوم أي ضبط `parent` token تركيب نقل، ذلك فرعي استدعاء تلقائي مشي كل جدول، و هذا token قد لديه تضمين طقم استدعاء دلالة متسق.
