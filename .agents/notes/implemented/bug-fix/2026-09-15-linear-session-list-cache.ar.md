# Agent Note: Session قائمة ذاكرة مؤقتة خط صفة مقابل حساب

Status: implemented

[English](2026-09-15-linear-session-list-cache.md) | العربية

## مشكلة

Client Session قائمة إبقاء سطر كائن، بـ صيانة حمل React مرجع مستقر صفة. لـ كل ذاكرة مؤقتة ID مسح كامل جديد قائمة، سوف جعل لقطة إعادة بناء صار هذا حسب مستو جهة زيادة طويل؛ أول مرة تحميل أيضا تلقي أثر، لأن جديد سطر في تنظيف قبل حينئذ قد دخول ذاكرة مؤقتة. عدد ألف عدد Session ممكن في قائمة تحديث وقت احتلال استخدام متصفح خط مسار.

## قرار

SessionManager من مقابل حساب بعد سطر بناء واحد ID تجميع دمج، لأجل ذاكرة مؤقتة تصفية استبعاد و اختيار في سطر عضو فحص. حقل مقارنة مقارنة، سطر كائن معرف، عدد مجموعة إعادة استخدام، إرسال توليد ترتيب و إبقاء فرعي ذكي جسم عنوان صيانة حمل قائم دلالة.

## اعتبار مرور بديل خطة

**كل مرة إعادة بناء كل استبدال سطر ذاكرة مؤقتة.** جديد Map نفس مثال يمكن في خط صفة وقت داخل إزالة ناقص بند، لكن حاجة تعديل سطر إعادة استخدام مسار. مؤقت عضو تجميع دمج يأخذ تعديل حد تحديد في عضو فحص.

**في اختبار وحدة في حد فعلي استهلاك وقت.** مشترك CI سالب تحميل سوف جعل صارم إطار وقت ميزانية غير ممكن اعتماد. نسخة نطاق جزء ID وصول جهاز موحد حساب تكرار تحديث جديد وقت عضو قراءة مرة عدد؛ أصل تنفيذ تجاوز مرور خط صفة حد أعلى، بلا حاجة اعتماد آلة جهاز سرعة درجة.

## أثر

مقابل في n عدد حالي سطر و c عدد ذاكرة مؤقتة سطر، مقابل حساب استخدام O(n + c) وقت و O(n) مؤقت عضو تخزين. ناقص سطر فقد ذهاب ذاكرة مؤقتة معرف؛ لم تغير سطر و ذلك عدد مجموعة إبقاء معرف، مغادرة فتح قائمة مرشح اختيار في بند في سطر إرجاع بعد يمكن مجددا مرة يصبح حالي بند.

محلي macOS arm64 Node 26 قياس كمية سوف إنتاج manager تحرير ترجمة لـ JavaScript، و في وجود حجز قراءة وقت، من تحديث جديد بدء حساب وقت إلى نتيجة قائمة لقطة يمكن قراءة،Remote استجابة استخدام جديد بناء دمج صار كائن. مسبق حار ثلاثة مرة بعد أخذ تجميع تسعة عدد مثال هذا،1,000،2,600،5,000 و 10,000 سطر تحديث جديد استهلاك وقت في موضع عدد قسم آخر لـ 0.67،1.40،2.78 و 5.46 ms. أصل تنفيذ مقابل في موضع عدد لـ 4.86،29.01،30.62 و 459.89 ms. قياس كمية يتضمن قائمة إعادة بناء، ترتيب حذف خدمة طرف مسح، نقل،DOM تصيير، متصفح إدخال و داخل تخزين قياس كمية، لذلك لا يستطيع إثبات طرف إلى طرف إعادة وصل تأخير متأخر. تجمع تركيز manager اختبار تغطية تصفية استبعاد، فارغ قائمة، اختيار استعادة، معرف إعادة استخدام و خط صفة قراءة حد أعلى.
