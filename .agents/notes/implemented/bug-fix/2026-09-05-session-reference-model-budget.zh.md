# Agent Note: نموذج متبادل مقابل جلسة مرجع ميزانية

Status: implemented

[English](2026-09-05-session-reference-model-budget.md) | العربية

## Problem

ثابت 64 KiB مرجع ميزانية سوف في كبير سياق نموذج فوق إسقاط لديه استخدام مصدر سياق. هدف جلسة رأس وصف فوق مرة طلب، بينما agent options لـ توجيه توفير ابتدائي قيمة؛ اثنان من كل لا واحد تحديد معرف حالي دخول خطوة الذي اختيار نموذج.

## Decision

[Session-reference](../../../../packages/context/session-reference/README.zh.md) عبر محلي prepend مستمع مراقبة قد إتمام `system-prompt/assemble` شلال نشر، و يأخذ provider/model مقابل تخزين دخول بـ Agent لـ مفتاح WeakMap. دقيق تجهيز مرحلة مقطع عبر اختياري LLM خدمة تحليل هذا توجيه؛ أول مرة تجميع قبل مباشر دقيق تجهيز فإن استخدام agent options. لا حمل Agent تشخيص لن تحديث خريطة.

كل مصدر نيل نيل `max(65536, floor(contextWindow × 4 × referenceContextFraction))` بايت، افتراضي مقارنة مثال لـ `0.2`. كل token أربعة بايت هو سعة كمية تقدير حساب. صريح `maxReferenceBytes` قفز مرور نموذج استعلام و إبقاء دقيق قيمة. نقص قليل توجيه، خدمة، مهايئ أو سعة كمية وقت إبقاء تحت حد؛ أخرى استعلام فشل و إلغاء سوف نقل بث. نقص قليل مهايئ لا عائق عائق تدفق في بين عنصر معالجة هذا توجيه.

## Alternatives considered

**كل خطوة قراءة جلسة رأس أو options.** فوري تبديل بعد، اثنان من كل ممكن اختيار في قديم نموذج. إتمام تجميع عام نموذج اختيار الذي التقاط توجيه.

**في pre-step في إعادة تجميع أو إعادة قسم إرسال طلب توجيه.** هذه عملية سوف تكرار إضافة فاعلية نتيجة، و ممكن التقاط مختلف اختيار. محلي مراقبة جهاز لا حاجة تعديل حلقة أو زيادة عام مشترك توجيه API.

## Consequences

ميزانية مع نموذج سعة كمية زيادة طويل، لا تغيير إسقاط، إبقاء أو معاينة سياسة. هو ما زال حسب مصدر حساب حساب، بينما لا هو تجمع دمج token مسبق إبقاء. مستمع من effect يحتفظ و يمكن تحرير؛ خريطة لن إبقاء agent. تجمع تركيز اختبار تغطية تحت حد، مقارنة مثال تبديل حساب، صريح تغطية، فوري اختيار، بيانات وصفية ناقص، إلغاء، استعلام خطأ و مستمع إزالة.
