# Agent Note: متن عرض درجة سحب جر بند يقع في Chat محتوى تحت جهة

Status: implemented

[English](2026-09-14-transcript-width-handle-layering.md) | العربية

## مشكلة

Conversation shell سوف كل متن عرض درجة سحب جر بند تصيير لـ قراءة قراءة صف جانب كل عال قطعا مقابل تحديد موضع منطقة مجال. مقارنة عال كومة تراكم طبقة درجة جعل هذا منطقة مجال غطاء في سوف دمج إدارة فيض خروج قراءة قراءة صف عرض Markdown جدول إطار لـ فوق. سحب جر بند عال مضيء سوف حجب إقامة جدول إطار محتوى، ذلك إشارة إبرة هدف أيضا ممكن يحل محل جدول إطار ذاته تفاعل هدف.

## قرار

Conversation shell سوف عرض درجة سحب جر بند إبقاء في رقم صفر طبقة، لا إنشاء تغطية كامل body كومة تراكم سياق.Chat فقط سوف أداة جسم جدول إطار عنصر عنصر رفع إلى رقم واحد طبقة، قراءة قراءة صف، حد تحديد في صف داخل أداة بطاقة و جدول إطار breakout حزمة تركيب طبقة كل لا إنشاء جديد كومة تراكم طبقة درجة. لذلك فقط لديه جدول إطار مرئي صندوق فرعي فعلي تأخير امتداد دخول خندق مجرى وقت عندئذ سوف احتلال لديه إشارة إبرة؛ قدرة سعة قبول في متن في أربعة قائمة إطار لن منع قطع جانب حافة خندق مجرى سحب جر. رسالة ثابت تحديد موضع Tooltip إبقاء في جدول إطار كومة تراكم سياق خارج، ما زال يمكن رسم صنع في لصق ركود composer فوق جهة.

هذا قاعدة اعتماد تسليم Chromium جذب محرك لن يأخذ ChatView inline-size query container تغيير صار في بين كومة تراكم سياق.back-to-bottom تحكم عنصر قدرة عال في لصق ركود composer أيضا قد اعتماد نفسه جذب محرك سلوك.Chromium أمر في اختبار ثابت هذا واحد زائف ضبط؛ إذا تعديل لـ رفع عال كامل Chat root، ذلك نفاذ واضح كل عرض صندوق فرعي عكس بينما سوف إعادة احتلال استخدام خندق مجرى.

عرض درجة سحب جر بند فقط استخدام رئيسي إشارة إبرة حسب مفتاح بدء ضبط كامل. سحب جر بند فوق عادي تدحرج جولة إدخال سوف من مثل عنصر، حساب حساب بعد سطر عال أو صفحة مفرد موضع قاعدة كامل لـ مثل عنصر، مجددا تحويل إرسال إعطاء مباشر متبادل مجاور transcript scrollport، لذلك إشارة إبرة معلق توقف في خندق مجرى وقت لن في قطع قراءة قراءة تمرير.Ctrl+تدحرج جولة يمثل متصفح تقليص وضع أو لمس تحكم لوح قرص دمج يد اتجاه، لن يتم تحويل إرسال.

كل جانب أمر في منطقة مجال الأكثر عرض لـ 10px. معلق توقف إشارة عرض خط استخدام مقابل مقارنة درجة أكثر منخفض ساكن توقف تمرير بند لون لون، خط عرض 2px، في قلب فعلي لون مقطع طويل 16px، اثنان طرف كل تدريجي خفي 28px، مرئي مجموع طويل درجة لـ 72px.

Composer chrome إبقاء أكثر عال طبقة درجة، لذلك كامل لصق ركود قاع جزء منطقة حمل لحظة معنى لن بدء عرض درجة ضبط كامل. إذا سحب جر بند في دخول هذا منطقة حمل قبل قد نيل نيل إشارة إبرة التقاط، هو سوف مؤقت رفع إلى رقم ثمانية طبقة، جعل إشارة عرض خط في رخو فتح قبل إبقاء مرئي. احتلال حسب كامل View composer takeover ما زال سوف تماما إخفاء سحب جر بند.

## اعتبار مرور بديل خطة

**سوف سحب جر بند نقل إلى مغادرة قراءة قراءة صف أكثر بعيد موضع.** عرض جدول إطار يمكن استخدام transcript متاح عرض درجة، لذلك ثابت زيادة بين مسافة فقط قدرة نقص قليل جزء نافذة مقياس قياس تحت إعادة تراكم، أيضا سوف يجعل سحب جر بند أكثر صعب لمس بلوغ.

**فقط يلزم transcript يتضمن عرض محتوى حينئذ منع استخدام سحب جر بند.** واحد سطر عرض محتوى سوف يجعل كامل Session كل لا يمكن ضبط كامل عرض درجة، يشمل و أخرى سطر متبادل مجاور فارغ أبيض خندق مجرى.

**في JavaScript في فحص إشارة إبرة تحت جهة عنصر عنصر.** حركة حالة أمر في اختبار سوف تكرار متصفح كومة تراكم و إشارة إبرة توزيع قاعدة، و كما ما زال ممكن و جديد إضافة renderer لا متسق.

## عاقبة

مرئي Chat محتوى فقط في ذلك مرئي عنصر عنصر فعلي تأخير امتداد دخول عرض درجة سحب جر منطقة مجال وقت يملك إشارة إبرة إدخال، عار كشف خندق مجرى فإن إبقاء أكثر خفيف عرض درجة ضبط كامل تلميح، رئيسي حسب مفتاح سحب جر و transcript تدحرج جولة تمرير. اختبار وحدة ثابت إعلان سحب جر بند مقياس قياس، إشارة إبرة حسب مفتاح سلوك، مباشر scrollport فحص بحث، تقليص وضع ترتيب حذف و كل نوع DOM delta mode.Chromium `elementFromPoint` تغطية إثبات فيض خروج جدول إطار نيل نيل إشارة إبرة أمر في، بينما يمكن سعة قبول `md-table-wide` حزمة تركيب طبقة لن؛ رسالة عملية اختبار إثبات ثابت تحديد موضع Tooltip ما زال رسم صنع في لصق ركود composer فوق جهة.
