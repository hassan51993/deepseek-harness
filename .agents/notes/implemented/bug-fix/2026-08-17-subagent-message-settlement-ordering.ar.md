# Agent Note: Child Agent رسالة أولا في ذلك تسوية إشعار

Status: implemented

[English](2026-08-17-subagent-message-settlement-ordering.md) | العربية

## مشكلة

يمكن متابعة child يمكن إرسال اختيار في محتوى، بعد أيضا سوف إنتاج واحد بند من إدارة جهاز تحرير كتابة كما بلا شرط إلقاء تمرير تسوية إشعار. إذا هذا اثنان بند رسالة دخول قيادة أخذ أولوية درجة مختلف طابور صف، مقارنة متأخر تسوية إشعار ممكن أولا في مقارنة مبكر child رسالة وصول parent نموذج. واحد جولة رقم واحد step سوف أولا قيادة أخذ كامل `next-step` دفعة مرة، مجددا قيادة أخذ واحد بند `next-turn` رسالة، لذلك خلط استخدام FIFO لاحق جولة إرسال و next-step تسوية سوف قلب قلب بسبب نتيجة ترتيب.Issue #2600سجل هذا نقص وقوع.

child إشارة أمر اشتراط في اكتشاف سوف تغيير parent تحت واحد خطوة حركة عمل وقت إرسال هذا اكتشاف. يأخذ هذا بند رسالة دفع متأخر إلى لاحق جولة حيث مخالفة خلف ذلك ضبط درجة يحتوي معنى، أيضا سوف يأخذ أداة لديه بسبب نتيجة ترتيب رسالة تفكيك إلى قيادة أخذ أولوية درجة مختلف طابور صف.

## قرار

كل بند نموذج تحرير كتابة متبادل مجاور Agent رسالة كل عبر `SubagentRuntime.sendMessage()` استخدام ثابت Steer إلقاء تمرير. تشغيل في parent في الأكثر قريب أمان step حد قراءة child رسالة، فارغ خامل parent فإن بدء واحد جولة. نموذج لا يوجد ساكن صامت أو next-turn إلقاء تمرير خيار.

متابعة تنفيذ إدارة جهاز سوف في إلقاء تمرير إلى إقامة إبقاء يمكن متابعة parent رسالة دورة محيط إبقاء `sendWaking()`، و عبر parent خاص `SubagentInbox` تنفيذ تزامن إرسال. حزمة تركيب طبقة سوف في تثبيت closing promise قبل قبول إرسال، و في تثبيت بعد رفض إرسال؛ يتم قبول محاولة تجربة سوف في إرجاع قبل تحديث Activation wake generation. لذلك، استقبال جهة Activation لن تجاوز مرور واحد بند قد قبول نداء تنبيه إرسال إتمام تسوية.

### مختلف parent حالة تحت ترتيب

تشغيل في parent في نفس بند `next-step` FIFO في استقبال قد قبول child رسالة و هذا child مع بعد تسوية إشعار. إذا parent في تسوية وصول قبل تغيير لـ فارغ خامل، هو قد قيادة أخذ child رسالة؛ تسوية مع بعد يمكن فتح بدء لاحق جولة، بينما لن قلب قلب مراقبة ترتيب.

parent موضع في maintenance وقت،child رسالة احتلال استخدام `next-step` و قفل تخزين مرة نداء تنبيه، بينما تسوية ممكن بسبب maintenance تقرير إبلاغ فارغ خامل حالة بينما احتلال استخدام `next-turn`. ابتدائي قيادة أخذ ما زال سوف أولا أخذ next-step إدخال، مجددا أخذ ترتيب طابور جولة. إلغاء بعد إيداع نداء تنبيه إدخال التزام دوران نواة قلب Agent إلغاء استلام جمع، بينما لن التفاف مرور هو.

### تحقق

تحكم أداة اختبار طقم عنصر يجعل parent إبقاء في نشط وثب نموذج طلب في، إيداع child رسالة، تسوية child، و تحقق sender هوية،Steer دقيق دخول،FIFO دفعة معالجة و تسوية بعد إبقاء. متابعة تنفيذ تغطية ثابت إقامة إبقاء يمكن متابعة parent نداء تنبيه دقيق دخول تسجيل حساب، و يجعل runtime كل تسوية مصدر و `agent-message` إبقاء مختلف.

بلا مفتاح يمكن متابعة subagent لقطة استخدام مع مرفق ثابت إلقاء تمرير. ذلك child مرئي أداة schema و parent نفسه، كما قد قبول child رسالة أولا في بعد تسوية إشعار، بلا حاجة ضبط درجة overlay.

## اعتبار مرور بديل خطة

**توفير ساكن صامت إلقاء تمرير.** فارغ خامل parent توقف إقامة بعد ممكن دائم بعيد لا قراءة ساكن صامت رسالة. هو أيضا سوف يجعل انتظار قيمة نموذج تحرير كتابة رسالة أداة لديه مختلف تخزين نشط دلالة، و إعادة جذب دخول اعتماد نشر ترتيب.

**توفير next-turn إلقاء تمرير.** مقارنة متأخر next-step تسوية إشعار ما زال ممكن تجاوز مرور هو. إبقاء رسالة أولا في تسوية حاجة عبر طابور صف ترتيب شاشة عائق، بينما حالي لا يوجد نموذج عملية مقابل لاحق جولة عزل يحتاج طلب قوي إلى كاف بـ تحمل تحمل هذا آلية.

**يأخذ تسوية إشعار نقل إلى `next-turn`.** تسوية دفعة معالجة استخدام next-step طابور صف، جعل كثير عدد child معا انتهاء فقط إزالة استهلاك parent واحد step، بينما لا هو كل child واحد جولة. نقل حركة تسوية سوف لـ إبقاء لا لا بد يلزم رسالة ضبط درجة نمط بينما زيادة تأخير متأخر و نموذج عمل.

## عاقبة

- child رسالة يمكن تأخير طويل فتح وضع parent جولة. هو أبدا سوف في قطع نشط وثب نموذج طلب أو أداة تنفيذ؛agent loop فقط في step حد وصل قبول هو.
- واحد بدء يتم قبول رسالة مشترك واحد next-step دفعة مرة، إبقاء FIFO ترتيب و حد جولة وضع كبير.
- نموذج استدعاء جهة لا يستطيع اختيار إلقاء تمرير نمط، لذلك ترتيب و نداء تنبيه سلوك لن مع نشر أو استدعاء بينما تغير.
- child إلى parent إرسال ما زال اشتراط مباشر parent إبقاء في خط؛ خدمة لا توفير حمل دائم parent mailbox.
