# Agent Note: pi-ai دليل تغير بعد يمكن إصلاح ضبط

Status: implemented

[English](2026-09-07-pi-ai-settings-catalog-recovery.md) | العربية

## Problem

قد تثبيت pi-ai دليل ممكن تغيير لم تعديل مستخدم ضبط صالح صفة.OpenRouter دليل خارج نموذج يمكن في كل داخل وضع نموذج بروتوكول متسق وقت وراثة بروتوكول؛ إضافة دخول ثاني نوع بروتوكول سوف جعل هذا نوع دفع قطع بطلان. حذف دليل نموذج أيضا سوف جعل حسب ذلك قديم ID إعلان تغطية بطلان. تسجيل وقت رفض كامل settings نطاق الأسماء، سوف يجعل غير متصل مزود إزالة فقد، أيضا إزالة إصلاح إعداد الذي يحتاج تحكم عنصر.

## Decision

pi-ai إزالة استهلاك من استخدام قائم settings `validate` عودة ضبط. نطاق الأسماء تسجيل خلال سعة تحمل دليل تشخيص؛ تسجيل إتمام بعد، سوف تغير مزود و حالي قد تحليل قسم عقدة مقارنة مقارنة و صارم إطار تحقق.Settings في تحديث، كامل جسم استبدال و مسار تعديل حفظ دائم قبل استدعاء هذا عودة ضبط. خارجي إعادة تحميل استخدام نفسه صارم إطار تحقق، فشل وقت إبقاء الأكثر بعد مرة قبول قسم عقدة.Settings خدمة و ذلك عام مشترك API إبقاء ثابت.

أول مرة تحليل profile وقت إبقاء دليل تشخيص، بينما schema و profile ذاته قيد ما زال سوف رفض تحميل. كتابة سوف سوف صالح مزود قيمة و قد إيداع لقطة مقارنة مقارنة، صارم إطار تحليل كل إضافة جديدة أو تعديل مزود. لم تعديل خطأ مزود لن منع توقف أخرى مزود تحرير، حذف ما زال متاح. تعديل مزود درجة ضبط سوف تحقق ذلك أثر كل نموذج.

Profile تحليل في صالح نموذج جانب إبقاء تدريجي نموذج خطأ. فقد ذهاب مرجع هدف تغطية سوف إبقاء تشخيص، بينما لن منع استخدام ذلك بقية دليل. توجيه درجة دليل فشل سوف إبقاء مزود و يمكن تحرير ضبط، لكن لا توفير يمكن استدعاء نموذج. توجيه درجة تحقق في توقف دليل تحليل وقت، لا كامل دليل و ذلك قد استلام تجميع تدريجي نموذج تشخيص سوف يتم إسقاط، هذا توجيه فوق نموذج طلب موحد واحد تقرير إبلاغ توجيه درجة خطأ. مهايئ في تحليل اعتماد و شبكة شبكة I/O قبل فحص الذي اختيار نموذج قد سجل خطأ، و تقرير إبلاغ `INVALID_CONFIG`. تحميل مرور مسار لن تخمين قياس بروتوكول أو تعديل كتابة مستخدم إعداد. غير ممكن تغيير لقطة ما زال حفظ إثبات إجراء في طلب استخدام ذلك التقاط إعداد.

`LlmConfigurableProvider.error` أولوية لـ مزود سطر يحمل أول عدد نموذج تشخيص، بلا نموذج تشخيص وقت إرجاع توجيه خطأ. مزود بنية صنع فشل لن تغطية قد استلام تجميع نموذج تشخيص، من بينما إبقاء نقص قليل بروتوكول وقت أداة جسم إصلاح تلميح. يمكن إعداد مزود دليل إصدار تشخيص تغير، إصلاح إعداد سوف تحديث جديد متصفح، بلا حاجة إعادة تسجيل مهايئ. خطأ نموذج ID إبقاء في ضبط في، نموذج اختيار جهاز فقط استقبال يمكن خدمة بند. نموذج ضبط صفحة عرض تشخيص و إبقاء تحرير، حذف تحكم عنصر. اثنان عدد إضافة عملية كل اشتراط ذلك الذي تابع settings نطاق الأسماء وجود؛ عادي إضافة قائمة مفرد سوف مرور ترشيح غير ممكن استخدام نطاق الأسماء.

هذا قرار توسيع[حسب مزود توجيه مهايئ قرار](../architecture/2026-07-14-provider-routed-llm-adapters.zh.md): مزود كل حق و طلب لقطة ثابت، دليل صالح صفة لا قرار ضبط هل يمكن إدارة. قديم سجل ما زال إبقاء لـ توجيه، كل حق و إعادة تشغيل تصميم اعتماد حسب.

## Alternatives considered

**في تسجيل وقت رفض دليل خطأ.** هذا سوف منع توقف مستخدم إصلاح بنية يمكن تحليل إعداد، و يجعل لم استخدام مرور مدة نموذج منع استخدام غير متصل مزود.

**معا وضع عرض حفظ تحقق.** مقابل لا يمكن دفع قطع بروتوكول جديد نموذج، يمكن قيام أي رفض و نقطة اسم مزود و نموذج. قبول هو فقط سوف صنع صنع يمكن تجنب تجنب طلب وقت خطأ.

**كل مرة حفظ كل صارم إطار إعادة تحقق كامل نطاق الأسماء.** غير متصل مزود قديم خطأ سوف منع توقف إضافة صحيح معتاد مزود، أو تدريجي عدد إصلاح مزود.

**لـ OpenRouter إشارة تحديد ثابت توجيه بروتوكول.** توجيه تغطية سوف استبدال كل نموذج بروتوكول، ممكن تغيير متعمد استخدام أخرى API صحيح معتاد دليل بند.

## Consequences

اعتماد ترقية إنتاج خطأ ما زال مرئي، يمكن إصلاح، بينما إضافة جديدة مزود تحرير تحقق لن وضع عرض. إعداد خطأ و بعيد طرف نموذج هل وجود ما زال مختلف: صريح إشارة تحديد بروتوكول دليل خارج ID يمكن يتم قبول، من طرف نقطة قرار هذا ID هل وجود. علامة كمية أو وثيقة خطأ ما زال كل مبكر فشل. نموذج ضبط صفحة لا عرض نطاق الأسماء تسجيل فشل سبب، هذا صنف خطأ حاجة فحص إعداد و بدء تشخيص. لا زيادة Settings API، تخزين صيغة أو session حدث؛ يمكن إعداد مزود بند إضافة جديدة واحد اختياري تشخيص حقل.

## Testing

مهايئ اختبار تغطية صالح و خطأ نموذج خلط دمج، تغطية هدف يتم حذف، مستقل مزود تحرير، توجيه حذف، ربط شبكة قبل فشل و إصلاح. ملف استماع ارتداد تحقق غير قاعدة خارجي تحرير إبقاء الأكثر بعد مرة قبول profile، بينما إصلاح بعد ملف قدرة كاف توليد فاعلية. كامل Web مدة نظر اختبار من مرور مدة OpenRouter ضبط بدء، إبقاء zai و اثنان عدد إضافة تحكم عنصر، في لا تغيير ملف قبل رفع تحت رفض بلا فاعلية حفظ، و عبر حذف مرور مدة نموذج إصلاح توجيه. قد لديه لقطة اختبار متابعة مسؤول طلب تجميد ربط و إعادة تشغيل سلوك.
