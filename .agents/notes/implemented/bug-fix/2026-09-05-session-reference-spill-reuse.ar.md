# Agent Note: لـ قطع قطع جلسة مرجع إعادة استخدام spill تخزين

Status: implemented

[English](2026-09-05-session-reference-spill-reuse.md) | العربية

## مشكلة

محدود عبر جلسة معاينة ممكن حذف كامل بند رسالة، أيضا ممكن حذف إبقاء رسالة في كبير جزء نص. فقط يرى معاينة نموذج حاجة دقيق تأكيد حل حذف حال حال، و قدرة فحص قد التقاط نص، معا لا يستطيع يأخذ أخرى جلسة إشارة أمر نظر لـ حالي تخويل. مصدر جلسة متابعة دفع دخول أو حدوث ضغط بعد، مجددا مرة قراءة لا يمكن استعادة نفس مرة مراقبة.

## قرار

[جلسة مرجع دقيق تجهيز](../../../../packages/context/session-reference/README.ar.md) إبقاء قائم معاينة سياسة و تدريجي مرجع JSON بايت ميزانية. كل يتم قطع قطع مرجع عبر اختياري `ctx.get("spillStore")` محاولة تجربة `saveText`؛ لم قطع قطع مرجع لا كتابة ناتج. كامل تحويل تسجيل و محدود معاينة قدوم ذاتي نفس نسخة قد التقاط user/assistant نص إسقاط، يتضمن ضغط فحص نقطة، لكن ترتيب حذف أداة، دفع إدارة و أخرى حقن سياق. لا حدوث ثاني مرة مصدر قراءة.

ناتج عودة استقبال سياق هدف جلسة كل. ذلك وصف صفة مصدر هو `{ kind: "session-reference", sessionId, label }`، منها `sessionId` معرف يتم مرجع جلسة.[spill تخزين](../../../../packages/spill/spill/README.ar.md) في أداة مصدر خارج قبول هذا واحد الأكثر صغير فرع؛ لا حاجة زائف صنع أداة اسم أو استدعاء id. تخزين ملكية لا تخويل أخذ عودة.

محدود معاينة JSON خارج مستقل حذف إشعار سجل دقيق `omittedMessages` و `omittedBytes`. إشعار يحمل حفظ بعد تحديد موضع معلومة و خلفية `retrievalHint`، أو منطقة قسم لم إعداد تخزين و حفظ فشل غير ممكن استخدام نتيجة. هذا إشعار هو نفس بند حمل دائم مرجع رسالة في نموذج مرئي محتوى، بينما لا هو فقط توفير UI استخدام بيانات وصفية تركيب زينة. أقصى صغير معاينة ميزانية لا يمكن إزالة هو. حفظ تحويل تسجيل يحمل يشمل `capturedFormatVersion` في داخل التقاط بيانات وصفية، و و معاينة نفسه لا تلقي معلومة مهمة خلف مشهد تحذير إبلاغ. كل بند رسالة JSON نص قطعة مقطع كل سطر حتى كثير يتضمن 64 عدد Unicode رمز نقطة؛ حل رمز و تجميع وصل بعد يمكن استعادة دقيق نص، يشمل أصلي تبديل سطر. هذا نوع ثابت ناتج صيغة يجعل عادي قسم صفحة ملف قراءة يمكن أخذ عودة جدا طويل مفرد سطر نص في جزء، بينما لا تغيير معاينة إبقاء سياسة.

مختلف خطوة حفظ بعد إلغاء سوف منع توقف سياق إصدار، أي جعل تخزين قد إنشاء ناتج. مستهلك لا زيادة تراجع أو حذف API؛ هذا ناتج التزام دوران خلفية قائم مرور مدة سياسة. إعادة تشغيل استخدام قد سجل معاينة و إشعار، لن تكرار حفظ أو مصدر قراءة.

## اعتبار مرور بديل خطة

**آخر كتابة واحد جلسة مرجع ملف تخزين.** غير مقبول، لأن خاص تسمية، جلسة درجة ملكية، تحديد موضع إشارة جذب و ناتج دورة الحياة قد من spill تخزين مسؤول. ثاني طقم تخزين سوف تكرار هذه سياسة.

**حفظ أو أخذ عودة وقت إعادة قراءة مصدر.** غير مقبول، لأن مصدر تغيير ممكن جعل ناتج و معاينة و ذلك التقاط تسلسل لا متسق. حفظ أصلي إسقاط يمكن إبقاء هذا مرة مراقبة.

**يأخذ حذف و أخذ عودة بيانات وضع دخول محدود معاينة JSON.** غير مقبول، لأن هذا سوف يجعل بيانات وصفية احتلال استخدام محادثة ميزانية، و ممكن في ميزانية الأكثر صغير وقت تماما جيد إخفاء إشعار. مستقل حمل دائم نموذج مرئي نص معا إبقاء اثنان بند حفظ إثبات.

**كل spill كل استخدام أداة مصدر.** غير مقبول، لأن جلسة مرجع لا يوجد نموذج إرسال خروج أداة استدعاء. وهمي بنية أداة id سوف خطأ ملكية ناتج، بينما لا هو وصف ذلك إنتاج من.

## عاقبة

نموذج يمكن فحص معاينة حذف نص، بينما بلا حاجة زيادة معاينة ميزانية. إشعار في هذا ميزانية خارج زيادة طلب token، بعد أخذ عودة مجددا إضافة الذي طلب تحويل تسجيل نص. تخزين اعتماد كل قوة بينما لـ سياسة: غير ممكن استخدام إشعار مثل فعلي شرح لا يمكن أخذ عودة، بينما محدود معاينة ما زال يمكن استخدام. أي جعل إشعار ما زال في حمل دائم تاريخ في، حفظ تحديد موضع معلومة أيضا ممكن مرور مدة؛ هذا وظيفة لا تحمل وعد دائم دائم عودة ملف، أيضا لا يمكن استعادة مصدر ضغط قد إزالة محتوى.

## تحقق

[اختبار وحدة](../../../../packages/context/session-reference/tests/session-reference.spec.ts) قفل تحديد حذف حساب عدد، كامل Unicode و تحكم محرف استعادة، كامل بند رسالة إسقاط، ثلاثة عدد مرجع عزل، بلا تخزين و حفظ فشل، مصدر ترتيب حذف و تغيير عزل، و إصدار قبل إلغاء.[Loader تركيب اختبار](../../../../packages/context/session-reference/tests/loader-composition.spec.ts) استخدام حقيقي محلي تخزين و قسم صفحة `read` أداة، قراءة ضخم نوع مفرد سطر رسالة في جزء، و فحص تخزين عودة هدف جلسة كل.[بلا مفتاح تسجيل صنع جلسة مشهد](../../../../snapshots/session/session-reference-spill/snapshot.yml) قفل تحديد حمل دائم نموذج مرئي مرجع سياق. تضمين طقم Windows تحديد موضع معلومة ارتداد تغطية تسلسل تحويل رفع أخذ و مواصفة تحويل، كما لا تعديل كتابة غير متصل عكس مائل عمود. إعادة تشغيل سوف[مواصفة تحويل معروف حمل جذب رقم spill تحديد موضع معلومة](../../../../packages/test-support/session-snapshot/README.ar.md) ، معا إبقاء حفظ بايت عدد و حذف حساب عدد.

## متبادل صلة قرار

[أداة إخراج spill قرار](../architecture/2026-07-08-tool-output-spill-files.ar.md) إبقاء نشط وثب: ذلك تخزين/سياسة قسم مغادرة، فشل تخفيض، مزود حد أعلى و أخذ عودة بديل خطة ما زال قيد أداة مستهلك. هذا شرح توسيع ذلك إنتاج من مفردات، بينما لا بديل هذه إدارة من.[قسم مغادرة سياق حقن و جولة تنفيذ](../architecture/2026-07-24-separate-context-injection-from-turn-execution.ar.md) ما زال مسؤول حمل دائم رسالة دقيق دخول،[إنتاج من إعلان سياق شكل صيغة](../feature/2026-08-05-context-form-vocabulary.ar.md) ما زال مسؤول recall عرض.
