# Agent Note: عبر Host settings حفظ دائم Web مستخدم انحراف جيد

Status: implemented

[English](2026-08-06-host-backed-web-preferences.md) | العربية

## مشكلة

Web Appearance،Language و كثيف مشغول حالة Enter انحراف جيد أصل هذا وجود متصفح `localStorage` في. متصفح تخزين بـ origin لـ أثر مجال، لذلك تبديل واحد طرف فتحة إعادة فتح `dsh web` سوف اختيار في آخر عدد تخزين قسم منطقة و فقد فقد اختيار، أي جعل اثنان عدد عملية استخدام نفس عدد DSH home. هذه هو مستخدم درجة منتج انحراف جيد؛ جلسة اختيار، مسودة مسودة، طي توسيع حالة و أخرى لحظة حالة متصفح حالة ما زال إبقاء في صفحة داخل.

رقم واحد إصدار رئيسي عنوان تنفيذ فقط يأخذ Appearance نقل دخول Host settings، لكن سوف في توفير `ThemeRuntime` قبل انتظار ابتدائي RPC. مؤقت بطيء أو غير ممكن استخدام settings طلب بسبب بينما سوف تعليق بدء تجميع بعد صفحة. هذا تنفيذ أيضا في قراءة بعد عندئذ بناء قيام حجز قراءة، ممكن خطأ مرور هذا نافذة داخل بطلان إشعار؛ هو كتابة وقت لا يحمل namespace revision، و كما سماح قد تحرير إضافة الذي ترتيب طابور كتابة وصول Host.

## قرار

كل مجال الذي تابع Host half تسجيل ثلاثة نسخة schema: اختياري `locale.preference`(`ar` أو `en`، ناقص وقت تسليم من متصفح قرار) ،`ui-theme.preference`(`light`،`dark` أو `system`، افتراضي لـ `system`) ، و `ui-conversation.busyEnter`(`queue` أو `steer`، افتراضي لـ `queue`). محلي settings مزود سوف صريح اختيار تخزين دخول `$DSH_HOME/settings.yaml`، في استخدام افتراضي home وقت، هذا مسار تحليل لـ `~/.dsh/settings.yaml`.API بديل إدارة في Connection متصفح إقرار إثبات بعد خدمة كل واحد قد تسجيل namespace؛ حقل زاوية لون ما زال سوف انفصال حساس آلة سري قيمة.

`dsh-client-ui-settings` يحتفظ واحد متصفح عام settings describe مرآة مثل، و توفير `ctx.settingsScope.bind(spec)` بصفة هذا مرآة مثل فوق تدريجي namespace selector. مرآة مثل في بدء خلفية قراءة قبل تثبيت `settings/document-updated` و `connection/reset` مستمع، لذلك أي settings نقل كل لن منع سد إضافة تنشيط، بطلان إشعار أيضا لن إسقاط دخول أولا قراءة، بعد حجز قراءة فارغ ملف. كل ربط scope سوف إصدار واحد توفير مجال خدمة حجز قراءة لقطة store(حالة، قسم عقدة قيمة،revision، يمكن كتابة صفة،host/داخل تخزين نمط) ، ذاته لم يعد زيادة بروتوكول قراءة أو مستمع. افتراضي حل رمز جهاز سوف مقابل وفق هذا namespace ذاته تسلسل تحويل wire schema(مرور نفس حزمة `ctx.settingsSchema` خدمة أيضا أصل) تحقق كل نقل دخول قسم عقدة، لذلك كل مجال بلا حاجة يحمل يد كتابة wire تحقق جهاز. مجال خدمة يأخذ scope عند عمل عادي بنية صنع دالة تنسيق عمل من استقبال، قيام أي إصدار كل منها مؤقت تحديد قيمة افتراضية: من متصفح إرسال توليد locale، نظام رئيسي عنوان و Queue؛ مع بعد قبول قد نيل قبول Host قسم عقدة، لكن لا سوف ذلك كتابة عودة؛ لا حمل scope بنية صنع خدمة——مستقل كلمة قاموس أو سياسة سياسة fixture(اختبار قبل وضع بيانات)——فإن فقط توقف إبقاء في عملية محلي. مشترك قراءة و بطلان دورة الحياة من لاحق [settings describe مرآة مثل قرار](../../archived/architecture/2026-08-17-settings-describe-mirror.md) قاعدة تحديد.

مستخدم تغيير سوف تزامن تحديث فوري خدمة، و مرور `scope.set` سوف واحد بند `settings.mutate` مسار عملية ترتيب دخول طابور صف.scope سوف سلسلة سطر معالجة يد اتجاه، بـ الأكثر جديد معروف namespace revision بصفة `expectedRevision` إرسال، سجل كل مرة نجاح كتابة revision، و كما فقط سماح الأكثر جديد كتابة تسوية نتيجة إعادة إصدار فوري حالة. الأكثر جديد كتابة يتم رفض أو فشل وقت،scope سوف إعادة تحميل Host حالة. إضافة تحرير سوف رفض جديد عمل، قفز مرور قد ترتيب طابور عملية، كبح صنع تشغيل في عملية إصدار حالة، و انتظار هذا عملية تسوية بعد عندئذ يجعل إضافة بلوغ إلى تماما توقف مستقر.

Client في غير loopback صفحة منع استخدام Host حفظ دائم، لذلك هذه صفحة انحراف جيد ما زال فقط إبقاء في عملية داخل، كل إدارة Connection إقرار إثبات كامل API. حركة حالة رقم ثلاثة جهة رئيسي عنوان id ما زال هو داخل وضع Host schema خارج عملية داخل توسيع؛ إزالة منها واحد سوف إعادة وضع فوري سجل التسجيل، لكن لن استبدال فوق واحد حفظ دائم داخل وضع انحراف جيد.

## سبق اعتبار بديل خطة

**إبقاء `localStorage`، و في مختلف طرف فتحة بين نسخ قيمة.** واحد origin لا يمكن قطعة رفع آخر عدد origin تخزين، بينما Host في استمرار سوف محيط التفاف متصفح خاص لديه صيغة إعادة تنفيذ واحد طقم settings خدمة.

**سوف Host settings مرآة مثل إلى `localStorage`.** ثاني عدد مرجعي مصدر سوف اشتراط آخر خارج تعريف بدء و بطلان وقت اندفاع مفاجئ قاعدة، معا اعتماد لكن إبقاء صنع صار هذا نقص وقوع قسم منطقة.Host settings وثيقة هو وحيد حفظ دائم حق مصدر.

**انتظار ابتدائي قراءة، بـ تجنب تجنب مؤقت تحديد تصيير.** رسم صنع صفحة لا بـ إعداد متاح لـ قبل وضع شرط. خلفية قراءة ممكن جذب إرسال مرة فوري استلام جمع، لكن هو سوف عزل فشل، و إبقاء قائم متصفح/نظام/افتراضي عودة سقوط مسار.

**يجعل كل مجال يملك ذاتي ذات settings تحكم جهاز.** تزامن،revision، فشل، بطلان و تحرير قاعدة تماما متسق؛ هذا قبل رئيسي عنوان تنفيذ قد بسبب نسخ هذه قاعدة إنتاج دورة الحياة عائم نقل. من مجال يحتفظ schema، يمكن تجنب تجنب يأخذ منتج سياسة سياسة وضع دخول مشترك وقت التشغيل.

**حمل صار مقابل sync/persist عودة ضبط تدريجي حقل انحراف جيد تحكم جهاز.** رقم واحد إصدار مشترك دورة الحياة مرور مجال توفير `sync` عودة ضبط تزامن مفرد عدد علامة كمية حقل، خدمة فإن مرور حقن `persist` عودة ضبط كتابة عودة. هذا مقابل متبادل متبادل اعتماد عودة ضبط إجبار جعل بنية صنع قسم اثنان مرحلة مقطع إتمام——كتابة جهاز أولا افتراضي لـ بلا عملية، قليلا بعد مرور `bindPersistence` استبدال——namespace كل إضافة جديدة واحد حقل، هذا كل نيل مجددا يحمل واحد ذاتي ذات تحكم جهاز و مرة كل وثيقة قراءة، كما كل مجال كل إعادة إعلان واحد قد تسجيل wire schema هذا قد جدول بلوغ يد كتابة تحقق جهاز.namespace scope إصدار واحد نسخة توفير خدمة حجز قراءة لقطة و مباشر قبول كتابة، لذلك هذا مقابل عودة ضبط و ثاني عدد بنية صنع مرحلة مقطع كل لا وجود.

**يأخذ كل `localStorage` بند كل نقل دخول settings.** حالي جلسة، مسودة مسودة، وجه لوح توسيع حالة،trajectory عرض حالة و صنف يشبه بند يخص متصفح نسخة حالة، بينما غير مستخدم إعداد. سوف هو جمع رفع رفع لـ ضبط، سوف في لا يوجد منتج عقد نحو حال حال تحت، عبر وسم صفحة و طرف فتحة تزامن قصير مؤقت تنقل حالة.

## عاقبة

Appearance،Language و كثيف مشغول حالة Enter اختيار سوف تتبع مع DSH مستخدم home، عبر تجاوز إعادة تحميل، طرف فتحة و عودة حلقة origin. مباشر تحرير `settings.yaml` الذي إنتاج تغيير سوف عبر قائم بطلان تدفق استلام جمع، بينما قديم `dsh.theme`،`dsh.locale` و `dsh.conversation.busyEnter` بند حيث لن يتم قراءة، أيضا لن يتم كتابة.

بدء وقت ممكن سوف في خلفية قراءة تسوية قبل قصير مؤقت عرض مجال قيمة افتراضية. قصير مؤقت قراءة فشل سوف إبقاء هذا قيمة افتراضية أو فوق واحد صحيح تأكيد عملية داخل قيمة؛ إعادة وصل وقت سوف إعادة محاولة. كتابة يتم رفض وقت، واجهة ممكن سوف في محلي قيمة قيام أي تغير بعد واضح إظهار استعادة لـ حفظ دائم انحراف جيد.

تجمع تركيز اختبار وحدة تغطية schema تسجيل، أولا استماع بعد قراءة ترتيب، غير منع سد تنشيط، مرور schema تحقق قسم عقدة قبول، يحمل revision لديه ترتيب كتابة، قديم قديم استجابة عزل، لذا عائق استعادة، تحرير وقت تماما توقف مستقر، و بعيد مسار طرف فقط داخل تخزين نمط. بـ namespace لـ حبة درجة scope أيضا تحمل تحميل كثير حقل قسم عقدة، لذلك لاحق إعداد جدول وجه يمكن امتداد استخدام نفس نسخة دورة الحياة، بينما لا لا بد يد تركيب describe/mutate تزامن. بلا مفتاح Web settings مشهد عبر UI كتابة الكل ثلاثة بند انحراف جيد، تحقق YAML وثيقة و تأكيد قديم `localStorage` لـ فارغ، إعادة تحميل، مجددا استخدام نفس عدد DSH home في مختلف طرف فتحة فوق بدء آخر عدد Host.
