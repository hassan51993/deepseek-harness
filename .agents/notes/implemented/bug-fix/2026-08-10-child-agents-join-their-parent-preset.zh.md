# Agent Note: Child agents join their parent's preset composition

Status: implemented

[English](2026-08-10-child-agents-join-their-parent-preset.md) | العربية

## مشكلة

أداة و تلميح مقطع مرئي صفة امتداد `dsh-scope` أب سلسلة وراثة، بينما agent scope key صب صنع خروج قدوم وقت لا يوجد أب.[تدريجي جلسة agent preset](../architecture/2026-08-03-per-session-agent-presets.zh.md) يأخذ كل موجه إلى نموذج سطر نقل إلى agent مستو وجه، و يجعل `AgentPresets.mount()` يصبح ربط ذلك بند أب سلسلة وحيد طريق مسار——استدعاء نقطة في api-proxy جلسة إنشاء، استعادة و fork مسار فوق. اثنان عدد عملية داخل subagent قيادة عبر `applyChildComposition()` تجميع فرعي agent، بينما هو فقط تثبيت تدريجي فرعي agent persona و أداة حد، في هو فرعي agent scope سلسلة طويل درجة لـ واحد، ذلك سجل التسجيل عرض فقط قدرة تحليل إلى عام طبقة.

في أي إعداد preset roster نشر داخل، ذلك واحد طبقة الآن هو فارغ:web-app رقعة طبقة منع استخدام الكل مضيف مستو وجه أداة سطر. لذلك مرة صفة فرعي agent مقاومة بلوغ نموذج وقت أداة لـ صفر، يمكن متابعة فرعي agent فقط باق مضيف مستو وجه `report`، اثنان من كل لا حمل أب جهة persona، مساحة العمل سياق،plan-mode مقطع و تقنية قدرة دليل.fork مسار هذا قبل قد بسبب نفس إدارة من فعل مرور نفسه معالجة؛ تفويض إرسال لا يوجد.

فرعي agent حفظ دائم header يجعل مشكلة أكثر دخول واحد خطوة.`childSessionMeta()` لا سجل أي preset، في هو بارد قراءة واحد فرعي جلسة تحليل إلى هو نشر قيمة افتراضية——واحد طقم هذا فرعي agent من لم تشغيل مرور أداة تجميع، بينما هذا صحيح هو"نموذج مرئي ⟺ قد سجل"قاعدة يلزم منع قطعا حال شكل.

## قرار

`AgentPresets.composeFrom(agentCtx, parentCtx)` يجعل واحد agent إضافة دخول آخر عدد agent قد في تشغيل معتاد إقامة تجميع، و إرجاع الذي إضافة دخول preset id. هو عبر `standingMountFor()` تحديد موضع أب جهة تركيب——agent key إقرار أب إلى ذلك preset معتاد إقامة key، صحيح هو `serviceForAgent()` قراءة نفس علاقة——مجددا يأخذ فرعي agent key ربط إلى نفس عدد معتاد إقامة key فوق، ربط جملة مقبض ما زال عودة roster وحيد لديه إعادة سلسلة مرجعي يحتفظ. لم إضافة دخول أي preset أب جهة لا إنتاج إضافة دخول، أيضا لا تقرير خطأ، ذلك حينئذ هو بلا roster نشر: هو موجه إلى نموذج سطر يقع في مضيف تجميع في، فرعي agent قد قدرة عبر عام طبقة تحليل إلى هو جمع.

هذا هو إقرار أب بينما غير تركيب، اثنان موضع فرق آخر كل يلزم ضيق. فرعي agent أخذ إلى هو أب جهة ذلك عدد تأكيد قطع بديل حد، لذلك أب جهة بدء بعد يتم تحرير مرور تجميع ملف غير ممكن قدرة يأخذ و أب جهة تاريخ الذي إنتاج خروج وقت مختلف آخر عدد بديل حد تسليم إعطاء هو، هذا بعد يتم حذف preset أيضا غير ممكن قدرة يجعل واحد أب جهة ما زال في تشغيل فرعي agent فشل. هو أيضا هو تزامن، هذا صحيح هو فرعي agent إنشاء نافذة قدرة كاف استخدام هو قبل رفع——اثنان عدد عملية داخل قيادة كل في تزامن `setup` في إتمام تجميع.

`applyChildComposition(childCtx, parent, composition)` استقبال أب جهة، و في تطبيق فرعي agent ذاته تسجيل قبل إتمام إضافة دخول. هذا عدد معامل صحيح هو يلزم نقطة الذي في: هو يجعل"تجميع فرعي agent لكن لا فعل هذا إضافة دخول"في كل استدعاء نقطة لا يمكن جدول بلوغ، بينما لا هو يأخذ ثاني عدد خطوة إبقاء إعطاء كل جديد قيادة ذهاب تسجيل إقامة.`childSessionMeta()` عبر `AgentPresets.composedPreset()` سجل الذي إضافة دخول id، هذا قيمة من أب جهة**نشط حال** scope سلسلة قراءة بينما لا هو من ذلك header قراءة، لأن في فارغ أبيض مدة تبديل مرور preset أب جهة تشغيل في تحديث ذلك نسخة تجميع فوق، بينما هو header ما زال كتابة حال قديم ذلك عدد.

`dsh-subagent` بـ نوع درجة استيراد إضافة اختياري peer اعتماد طريقة، عبر `ctx.get('agentPresets')` لمس بلوغ roster——هذا صحيح هو هو مقابل `sandboxPolicy` و `approval` قد في استخدام، لديه واضح وثيقة آلة سوف صفة إزالة استهلاك نمط.

يأخذ أب جهة أداة تسليم إعطاء فرعي agent بعد، كشف خروج نفس مرة agent مستو وجه نقل نقل جذب دخول ثاني عدد نقص وقوع:`ToolRuntime` يأخذ**أثر مجال درجة**تسجيل ترتيب حذف في حد خارج، فقط مرور ترشيح عام طبقة، لذلك عند كل موجه إلى نموذج سطر كل تغيير صار أصل أولا مساهمة بعد، فرعي agent `toolFilter` حينئذ لم يعد قيد أي شرق غرب——بينما كما عام طبقة لـ فارغ وقت،`restrict()` سوف يأخذ استلام إلى كل اسم حرف كل حكم لـ لم معرفة و مباشر يجعل فرعي agent إنشاء فشل. إعفاء تجنب تجميع دمج ينبغي عند هو أثر مجال**ذاتي ذات تسجيل**أداة، بينما لا هو تماما جيد يقع في عام طبقة أداة؛ بعد واحد نوع قراءة قاعدة فقط في هذا اثنان عدد تجميع دمج إعادة دمج وقت عندئذ صار قيام.`view()` الآن مرور ترشيح أثر مجال وراثة قدوم واحد قطع——عام طبقة و كل أصل أولا طبقة——فقط إعفاء تجنب هو ذاتي ذات ذلك طبقة. هذا بند ذاته طبقة إعفاء تجنب هو تحمل إعادة بينما غير ترتيب حمل: تفويض إرسال وقت التشغيل يأخذ فرعي agent بنية تحويل إخراج أداة تسجيل دخول فرعي agent ذاتي ذات ذلك طبقة، بينما واحد فقط نقطة اسم فرعي agent متاح قدرة مرور ترشيح جهاز أبدا قدرة يأخذ هو إنتاج خروج طلب نتيجة الذي اعتماد آلية واحد و تقشير إسقاط.

## اعتبار مرور بديل خطة

**في فرعي agent setup داخل حسب id إعادة تركيب أب جهة preset.** دلالة و آلية اثنان جهة وجه كل لا صار قيام بينما يتم مرفوض. هو سوف إعادة قراءة roster و إعادة stat تجميع ملف، لذلك أب جهة بدء بعد مرة تحرير حينئذ سوف يأخذ فرعي agent قسم تقاطع إلى آخر عدد بديل حد، بينما هذا بعد يتم حذف preset سوف يجعل فرعي agent فشل، أب جهة لكن وفق معتاد تشغيل.`mount()` أيضا هو مختلف خطوة، تزامن إنشاء نافذة لا يمكن في لا إعادة بنية اثنان عدد قيادة قبل رفع تحت قبول هو.

**يأخذ فرعي agent key ربط إلى**أب جهة** key بينما لا هو معتاد إقامة تركيب فوق.** مرفوض، لأن هذا تغيير فرعي agent وراثة محتوى: أب جهة ذاتي ذات scope طبقة يحمل ذلك تدريجي agent حد، ذلك بعض حد سوف حينئذ هذا و كل بعد بديل طلب تسليم، بينما نشط نيل مقارنة أب جهة دائم فرعي agent سوف تعليق في واحد قد dispose agent key فوق. إضافة دخول معتاد إقامة تركيب إعطاء إلى فرعي agent هو أب جهة تجميع، فقط هذا بينما قد.

**لـ اثنان عدد قيادة جذب دخول واحد نسخة مشترك child setup سجل التسجيل.** مرفوض، لأن تزامن كما يمكن سحب إلغاء مساهمة بناء نموذج هو سوف قدوم سوف مشي نشر قدرة، بينما preset إضافة دخول هو مرة صفة إقرار أب، ذاته لا يوجد سحب إلغاء يمكن قول. يجعل تركيب مرور من اختياري سجل التسجيل إتمام، عكس بينما سوف يجعل أي التفاف مرور هو قيادة إعادة أداة تجهيز متروك تسرب ممكن.

**يجعل `dsh-subagent` استيراد `resolveSessionPreset` و حسب تحليل خروج id تركيب.** مرفوض، لأن هذا سوف إعطاء واحد يجب في لا يوجد roster وقت أيضا قدرة عمل حزمة جذب دخول صلب وحدة حافة، بينما كما نهائي ما زال سقوط عودة فوق وصف إعادة تركيب دلالة.

**مرور ترشيح سلسلة فوق كل واحد طبقة، يشمل أثر مجال ذاته ذلك طبقة.** مرفوض، لأن ذلك سوف يجعل تدريجي فرعي agent قدرة مرور ترشيح جهاز حذف إسقاط هذا فرعي agent بنية تحويل إخراج أداة——هو من تفويض إرسال وقت التشغيل تسجيل دخول فرعي agent ذاتي ذات ذلك طبقة——في هو واحد نقطة اسم “فرعي agent متاح أي بعض قدرة” `allow` سوف يجعل هو لا يمكن إنتاج خروج الذي طلب نتيجة.

**فقط إصلاح نشط حال إضافة دخول، لا حركة حفظ دائم header.** مرفوض، لأن ذلك مثال نشط حال فرعي agent و بارد قراءة نفس عدد فرعي agent سوف مقابل"أي نسخة تجميع إنتاج خروج هذا مقطع تاريخ"إعطاء خروج مختلف جواب سجل——نفس صنف نقص وقوع، فقط هو يتم نقل عدد أرض جهة بينما لا هو يتم إصلاح إسقاط.

## اختبار

`packages/preset/agent-presets/tests/mount.spec.ts` استخدام حقيقي fixture تجميع تغطية هذا إضافة دخول: فرعي agent يرى أب جهة أداة و تلميح مقطع، لن تركيب خروج ثاني عدد بديل حد، إضافة دخول في أب جهة dispose بعد اعتماد لكن صار قيام (نشط نيل مقارنة أب جهة دائم خلفية فرعي agent) ، فوق تقرير id متسق، لا يوجد preset أب جهة لا إنتاج إضافة دخول، و بلا scope سياق يتم رفض.

`packages/core/tools/tests/scoped.spec.ts` مباشر تغطية هذا حد قاعدة: فرعي agent مرور ترشيح جهاز قدرة إزالة هو من أصل أولا أثر مجال وراثة قدوم أداة، فرعي agent ذاته تسجيل في ذاتي ذات مرور ترشيح جهاز تحت تخزين نشط، أصل أولا حد ما زال أثر في ذلك داخل تضمين طقم كل أثر مجال.

`packages/subagent/subagent-in-process-driver/tests/preset-inheritance.spec.ts` في واحد لا يحتوي أي موجه إلى نموذج سطر مضيف تجميع فوق، عبر `startInProcessRun()` تأكيد نموذج مرئي نتيجة: فرعي agent ذاته طلب في schema، أب جهة تلميح مقطع، سجل تحت قدوم header preset، تطبيق إضافة في وراثة قدوم preset أداة لـ فوق `toolFilter`، و في فارغ أبيض مدة تبديل مرور preset أب جهة——تبديل إلى**آخر عدد** preset، هذا مثال تأكيد عندئذ قدرة منطقة قسم"قراءة أب جهة نشط scope سلسلة"و"قراءة أب جهة إنشاء header".

تجميع سجل هذا واحد طبقة استخدام هو حقيقي shipped Web تجميع e2e، بينما لا هو بلا مفتاح لقطة. هذا مستودع كل يمكن تشغيل example كل لا تجميع preset roster، لذلك هذا نقص وقوع في لقطة harness داخل أصل هذا غير ممكن مراقبة: يلزم فعل لقطة مشهد، نيل أولا لديه واحد حيث تركيب roster أيضا إرسال بدء تفويض إرسال example.Web e2e بدء هو حقيقي `base` + `web-app` رقعة طبقة و اثنان عدد shipped preset، هذا صحيح هو اختبار سياسة سياسة اشتراط تجميع دليل؛Web متصفح lane subagent golden تحمل تحميل مرئي عاقبة——سجل preset فرعي agent الآن سوف عرض و ذلك أب جهة نفسه preset شعار علامة.

## عاقبة

تفويض إرسال الآن صار هذا هو كل فرعي agent مرة scope إقرار أب، مجددا بلا أخرى——لا يوجد مقدار خارج إضافة نسخة، لا يوجد roster قراءة، لا يوجد جديد فشل نمط. فرعي agent قدرة تماما جيد انتظار في أب جهة قدرة، نقص ذهاب هو ذاتي ذات `toolFilter` الذي إزالة جزء؛ تدريجي subagent preset("agent نوع") ما زال لم بناء، ذلك سوف هو واحد جديد طلب حقل، بينما لا هو مقابل هذا مرة إضافة دخول تعديل.

`applyChildComposition()` شكل تغيير، لذلك سوف قدوم أي مستودع خارج عملية داخل قيادة كل يجب توفير أب جهة. هذا هو لحظة معنى دفع خروج بديل قيمة: هذا قبل توقيع سماح استدعاء جهة تجميع خروج واحد جزء بلا قدرة فرعي agent بينما لا تقرير أي خطأ.

بارد استعادة يمكن متابعة فرعي agent إضافة دخول هو أب جهة**حالي**تجميع، بينما لا هو هو ذاتي ذات header الذي سجل ذلك نسخة. نافذة جدا ضيق——أب جهة يجب أولا بناء فرعي، إبقاء فارغ أبيض، تبديل preset، بعد عندئذ نداء تنبيه هو؛ إقامة إبقاء في فرعي agent لن إعادة إضافة دخول، مرة صفة فرعي agent أيضا لن استعادة——بينما بديل خطة أكثر سيئ: حسب فرعي agent ذاتي ذات سجل id تحليل سوف إعادة قراءة roster، يأخذ هذا مرة إقرار أب لحظة معنى قاعدة تجنب إسقاط"preset قد حذف"فشل نمط أيضا طلب عودة قدوم. فرعي agent header ما زال سجل هو بدء وقت ذلك نسخة، لذلك هذا موضع قسم اختلاف هو يمكن مراقبة بينما غير ساكن صامت.

`ToolRuntime` الآن يأخذ حد إعفاء تجنب تجميع دمج قراءة عمل"هذا أثر مجال ذاتي ذات تسجيل شرق غرب"بينما لا هو"عام طبقة"، هذا في تفويض إرسال خارج تغيير واحد موضع قائم سلوك:**أصل أولا**أثر مجال مساهمة أداة الآن سوف تلقي بعد بديل مرور ترشيح جهاز قيد، بينما هذا قبل فقط لديه عام طبقة أداة سوف. سلسلة فوق ذلك بقية جزء إعفاء تجنب ثابت——أثر مجال ذاته تسجيل ما زال في ذاتي ذات مرور ترشيح جهاز خارج، هذا صحيح هو تفويض إرسال وقت التشغيل الذي اعتماد صفة جودة.
