# Agent Note: جلسة كتابة جملة مقبض احتلال استخدام ملاحظات

Status: implemented

[English](2026-09-16-session-writer-held-feedback.md) | العربية

## Problem

Agent فارغ خامل وقت،Session ما زال ممكن يحتفظ كتابة جملة مقبض. آخر عدد Host لا يمكن استعادة هذا جلسة، لكن عام داخلي خطأ toast لا يوجد توفير استعادة إشارة جذب. يحتفظ من أيضا ممكن يخص نفس عدد عملية، لذلك فقط سند احتلال استخدام لا يستطيع تحديد هو آخر عدد جارٍ تشغيل تطبيق.

## Decision

عند استعادة بسبب `SessionAlreadyOwnedError` فشل كما لا وجود يمكن إعادة استخدام Agent وقت،Session Controller إرجاع `session/writer-held`، يحمل `{ sessionId }`.Client التزام دوران [Remote فشل مفردات](../architecture/2026-08-28-ctx-remote-failure-vocabulary.ar.md) ، حسب code حكم آخر.Controller حسب Error اسم تعرف آخر حفظ دائم خطأ، و Session Query اختياري اعتماد معالجة متسق؛ تحميل Controller لا حاجة حفظ دائم تنفيذ أو خطأ صنف هوية نفسه.

إرسال و نموذج اختيار فشل عرض محلي تحويل إشارة جذب، شرح ممكن لديه أخرى DSH نسخة احتلال استخدام Session، و بناء اقتراح خروج أخرى نسخة بعد إعادة محاولة. نموذج اختيار سوف أصلي Remote نتيجة إرجاع إعطاء اثنان عدد UI مدخل؛ خطأ تصنيف لا اعتماد قليلا بعد قراءة مشترك دليل حالة.[كتابة إيجار نحو قرار](../feature/2026-08-31-cross-process-session-write-lease.ar.md) متابعة يملك قفل تحديد و تحرير دلالة؛ هذا ملاحظات حيث لا انتزاع احتلال كتابة إذن، أيضا لا تلقائي إعادة محاولة كتابة.

## Alternatives considered

**في `session/agent-busy` تحت استخدام ذاتي من نص reason.** ثاني عدد نص حكم آخر قيمة فقد ذهاب code و details نوع علاقة، و سوف كتابة احتلال استخدام و نص التوجيه وصل قبول فشل خلط في واحد بدء.

**مفرد وحيد دليل علامة سجل أو مطلوب حفظ دائم peer.** علامة سجل تكرار سجل عملية فشل، كما ممكن في دليل تحديث جديد بعد مرور وقت. فقط لـ تعرف آخر خطأ بينما قوي صنع اعتماد حفظ دائم، سوف إزالة مقابل بلا حفظ دائم نشر دعم حمل.

## Consequences

Wire إضافة جديدة واحد لديه نوع فشل رمز، لا تغيير قد تخزين Session بيانات. استعادة إشارة جذب لا يمكن تحديد أي عدد عملية يحتفظ جملة مقبض.Host اختبار تغطية خطأ اسم، و لديه، بلا حفظ دائم وقت عادي فشل؛Client اختبار تغطية اثنان نوع لغة و مع نموذج عملية إرجاع فشل. بلا مفتاح `queue-actions` Web مشهد عبر مع مرفق تركيب ثابت كتابة احتلال استخدام toast و إبقاء مسودة مسودة إخراج.`verify-optional-dependency-imports` منع توقف اختياري اعتماد قيمة استيراد كسر تالف وحدة تحميل.
