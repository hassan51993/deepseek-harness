# Agent Note: عبر دمج صار Alt حسب مفتاح يجعل Win32 اختيار جهاز نيل نيل قبل منصة تنشيط

Status: implemented

[English](2026-09-07-win32-picker-foreground-alt-key.md) | العربية

## Problem

web GUI مضيف عبر أصلي Win32 ملف مشبك محادثة إطار اختيار مساحة العمل دليل، محادثة إطار تشغيل في مضيف spawn عملية فرعية في (issue #3543).Windows فقط يأخذ قبل منصة منح إعطاء قبل منصة عملية، من قبل منصة عملية بدء عملية أو الأكثر قريب استلام إلى إدخال عملية؛ خلفية خادم عملية عملية فرعية ثلاثة من كل لا ممتلئ كاف، لذلك `Show` فتح محادثة إطار أي جعل يخص عملية فرعية أول عدد نافذة، أيضا سوف سقوط في كل مرئي نافذة بعد.spawn تصميم خلف بعد"أول نافذة أي تنشيط"زائف ضبط ([عودة ملف وظيفة سجل](../../archived/feature/2026-08-02-win32-in-process-folder-dialog.md)) فقط في spawn سلسلة يحتفظ تحكم منصة قبل منصة وقت صار قيام، مثال مثل تحكم منصة بدء CLI.

## Decision

`runFolderDialog` في `showing` إشعار و منع سد صيغة `Show` بين استدعاء إضافة جديدة `pressAltForForeground` ربط. هذا ربط في محادثة إطار خط مسار فوق دمج صار مرة Alt حسب مفتاح (`keybd_event` يحمل `VK_MENU`، أولا حسب تحت بعد رفع بدء) ، جعل Windows يأخذ هذا عملية حساب لـ الأكثر قريب إدخال كل من——وثيقة تسجيل تحميل سماح قبل منصة تنشيط إدارة من لـ واحد——في هو `Show` إنشاء محادثة إطار نافذة بـ قبل منصة طريقة تنشيط.bindings وحدة قد تحميل koffi `user32`، لذلك تعديل فقط زيادة مرة دالة نيل أخذ و اثنان مرة استدعاء. هذا حسب مفتاح في Windows فوق بلا شرط تنفيذ. عند عملية قد يحتفظ قبل منصة حق فائدة (تحكم منصة بدء CLI) وقت، محادثة إطار هذا قدوم حينئذ سوف تنشيط، حسب مفتاح لا بدء أثر؛ هذا لحظة نيل نيل تركيز نقطة نافذة ما زال سوف استلام إلى هذا مرة مفرد وحيد Alt، ممكن قصير مؤقت عال مضيء ذلك قائمة مفرد شريط. في دمج صار إدخال يتم كبح صنع بيئة (أمان طاولة وجه، تلقي حد بعيد مسار جلسة، رفع حق قبل منصة نافذة) في، محادثة إطار ما زال سوف سقوط في أخرى نافذة بعد وجه، حزمة README سجل هذا حد.

## Alternatives considered

**ذاتي تعريف URL بروتوكول إضافة متصفح نقر يد اتجاه.** مسودة مسودة PR #3544 عبر يجعل قبل منصة متصفح تنقل إلى قد تسجيل `dsh-picker://` URL قدوم منح إعطاء قبل منصة، جعل shell يأخذ محادثة إطار عملية بصفة قبل منصة عملية بعد بديل بدء. هذا تخويل حسب تصميم أداة لديه تحديد صفة، لكن آلية أفقي عبر سجل التسجيل و VBS بدء جهاز ملف، بروتوكول مدخل نقطة، يحمل كل مرة بدء أمر لوحة picker-result HTTP توجيه، و أول مرة استخدام وقت متصفح تأكيد، أيضا زيادة واحد بند متصفح يمكن بلوغ خدمة طرف توجيه. دمج صار حسب مفتاح حذف كامل هذا واحد وجه.

**من نقر جهة استدعاء AllowSetForegroundWindow.** هذا API يجب من حالي قبل منصة عملية——متصفح——استدعاء، و كما فقط قدرة نقطة اسم واحد يتم سماح عملية؛spawner لا يمكن بديل بديل متصفح استدعاء هو.

**مقابل تجمع تركيز خط مسار AttachThreadInput.** يأخذ محادثة إطار خط مسار مرفق حال إلى تركيز نقطة نافذة الذي تابع خط مسار نفس مثال قدرة التفاف مرور قبل منصة حد كما لا يوجد حسب مفتاح فرعي أثر، لكن نفس مثال لا يوجد وثيقة عقد نحو، حاجة في عرض وقت أخذ نيل تركيز نقطة نافذة خط مسار id، و في تركيز نقطة نافذة يخص أكثر عال كامل صفة عملية وقت فشل؛ لم فعل أصل نوع تحقق.

## Consequences

اختيار جهاز إبقاء مفرد واحد spawn عملية فرعية تصميم، و في خلفية مضيف مشهد نيل نيل قبل منصة سلوك، بديل قيمة هو مرة koffi استدعاء مقابل.bindings spec في زائف COM عالم حد فوق ثابت Alt حسب تحت/رفع بدء تسلسل و ذلك ضيق مجاور `Show` قبل موضع؛logic spec ثابت كامل showing → press → `Show` ترتيب.Windows CI lane ما زال سوف حقيقي فتح و في توقف إغلاق واحد محادثة إطار (حسب مفتاح وجود) ، لكن لا تأكيد تنشيط. في واحد منصة يأخذ قبل منصة قفل قوي صنع إلى الأكثر كبير قيمة Windows 11 آلة جهاز فوق فعل تحقق: لا إضافة حسب مفتاح تكرار الآن فشل (محادثة إطار في أخرى نافذة بعد وجه) ، إضافة فوق حسب مفتاح بعد محادثة إطار نيل نيل قبل منصة، خمسة جولة تكرار الكل نجاح؛Windows 10 بعد لم تحقق. دمج صار إدخال من raw input thread مختلف خطوة إزالة استهلاك، لذلك تنشيط تخويل أصل فإن فوق وجود تنافس تنازع نافذة؛ تكرار تشغيل في لم ظهور خطأ مرور، هش ضعيف بيئة ما زال هو سجل حزمة حد بينما غير ثاني طقم آلية، لأن تصفح خلفية ما زال هو أصلي اختيار غير ممكن معلومة مشهد في تركيب طبقة وجه جواب سجل.
