# Agent Note: Messages أساس عنوان صارم إطار تعرف آخر v1

Status: implemented

[English](2026-09-15-messages-v1-base-url.md) | العربية

## مشكلة

Messages نقل سوف في إعداد أساس عنوان بعد إلحاق Anthropic معيار `/v1` نطاق الأسماء. هذا قبل، قد بـ `/v1` ربط ذيل أساس عنوان سوف توليد `/v1/v1/messages`؛ بينما يأخذ كل `v` إضافة عدد حرف بعد لاحقة كل تعرف آخر لـ مزود إصدار، سوف توفير لم مرور شرح توافق صفة، و ممكن التفاف مرور معيار نطاق الأسماء.

## قرار

مشترك Messages API كل من إزالة نهاية ذيل مائل خط، فقط يأخذ صارم إطار انتظار في `v1` الأكثر بعد مسار مقطع نظر لـ قد لديه API إصدار. هو إبقاء هذا أصل عنوان و إلحاق `/messages` أو `/files`؛ أخرى أساس عنوان متساو إلحاق `/v1/messages` أو `/v1/files`. ذاكرة مؤقتة ملف فوق نقل أيضا استخدام نفس عدد تحليل بعد أصل عنوان تخطيط قسم أثر مجال. لذلك، رسمي جهة `https://api.deepseek.com/anthropic` أساس عنوان تحليل لـ `/anthropic/v1`، صريح `/anthropic/v1` أساس عنوان إبقاء ثابت.

Chat Completions إبقاء مستقل URL سلوك.Messages قاعدة لن دفع قطع مقابل `v1beta`،`v2`،`v4` أو أخرى إصدار صيغة بعد لاحقة دعم حمل؛ يتضمن هذه مسار مقطع نشر سوف في ذلك تحت نيل نيل معيار `/v1` نطاق الأسماء.

## اعتبار مرور بديل خطة

**تعرف آخر كل بـ `v` إضافة عدد حرف فتح رأس نهاية ذيل مسار مقطع.** هذا يمكن تجنب تجنب أكثر كثير ذاتي تعريف طرف نقطة تكرار إصدار، لكن سوف يأخذ نطاق لديه حد `v1` تكرار إصلاح تغيير صار لم مرور شرح توافق سياسة، و ممكن يأخذ طلب توجيه إلى Anthropic معيار نطاق الأسماء خارج.

**بداية نهاية إلحاق `/v1`.** هذا مقابل بلا إصدار أصل عنوان التزام دوران معيار مسار، لكن ما زال سوف لـ قد بـ `/v1` ربط ذيل إعداد إنتاج أصل لديه تكرار مسار.

## نتيجة

Messages،Files و ملف ذاكرة مؤقتة معرف استخدام نفس بند تحديد صفة قاعدة. صارم إطار مطابقة `/v1` إعداد إبقاء توافق، دفع ترشيح بلا إصدار أساس عنوان بلا حاجة تغيير. أخرى إصدار صيغة بعد لاحقة لا يتم نظر لـ API إصدار، لذلك سوف في ذلك تحت إلحاق `/v1`؛ هذا سوف متعمد وضع ترك مقابل بديل إدارة دفع قياس صفة توافق.
