# Agent Note: موحد واحد لم قراءة نظام الملفات أداة تشخيص

Status: implemented

[English](2026-09-03-normalized-unread-fs-tool-diagnostic.md) | العربية

## مشكلة

`dsh-tool-fs` write و edit عملية ممكن من مراقبة قياس سياسة أو نظام الملفات مزود استلام إلى `FS_NOT_OBSERVED`. هذه مصدر استخدام عملية خاص تحديد رسالة وصف نفسه اشتراط، لذلك نفسه استعادة شرط سوف بـ مختلف إجراء لفظ وصول نموذج. مزود نص أيضا ممكن كشف يتم رفض عملية هل سوف تغطية قائم هدف، لكن نموذج فقط يحتاج قراءة هدف بعد إعادة محاولة.

## قرار

`remediateFsError(error, displayPath)` في `dsh-tool-fs` نموذج حد يأخذ كل بند `FS_NOT_OBSERVED` رسالة استبدال لـ `cannot modify "<path>": file has not been read — read the file, then retry`. حزمة تركيب طبقة إبقاء بنية تحويل رمز خطأ، و يأخذ مصدر خطأ سلسلة لـ `cause`، لذلك آلة جهاز توجيه و تشخيص ما زال قدرة فحص أصلي لذا عائق.

`FS_STALE_VERSION` متابعة استخدام[تلقي منع حماية تغيير استعادة إشارة أمر سجل](../../archived/feature/2026-08-03-fs-tool-error-remedy.md) يملك إلحاق صيغة إعادة قراءة إشارة أمر. نظام الملفات مزود و سياسة إبقاء ذلك عملية خاص تحديد رسالة، لأن أخرى مستهلك و لا مشترك هذا أداة موجه إلى نموذج عرض.

## اعتبار مرور بديل خطة

**لـ كل بند مصدر رسالة إلحاق نفسه استعادة بعد لاحقة.** غير مقبول، لأن نموذج ما زال سوف لـ نفس بند لا بد يلزم عملية استلام إلى مختلف سبب، منها يتضمن لن تغيير استعادة طريقة مزود هدف وجود دقيق عقدة.

**في مزود و سياسة مصدر رأس موحد واحد رسالة.** غير مقبول، لأن هذه مكون يملك توفير `dsh-tool-fs` خارج مستهلك استخدام موجه إلى آلة جهاز خطأ؛ فقط لديه هذا أداة يملك هذا مقطع نموذج مرئي إجراء لفظ.

**لـ موحد واحد بعد نتيجة جذب دخول آخر عدد رمز خطأ.** غير مقبول، لأن قاع طبقة شرط و استعادة توجيه ما زال هو `FS_NOT_OBSERVED`؛ تغيير رمز خطأ سوف فقد فقد آلة جهاز مستهلك حاجة توافق صفة.

## عاقبة

بلا نقاش تغيير من سياسة أيضا هو مزود رفض،write و edit كل سوف إعطاء خروج نفس بند مستقر لم قراءة هدف تشخيص. نموذج وضع ترك مصدر خاص تحديد إجراء لفظ و مزود هدف وجود تلميح، بـ تبديل أخذ واحد بند موحد واحد كما يمكن تنفيذ استعادة إشارة أمر. أصلي رسالة ما زال يمكن عبر `cause` نيل أخذ.

وحدة و اختبار تكامل ثابت اثنان بند مصدر مسار، رمز خطأ إبقاء،cause سلسلة و نموذج مرئي نص كل نص.`fs-policy-reject` تسجيل صنع جلسة يحمل نفس بند تشخيص لأجل إعادة وضع.
