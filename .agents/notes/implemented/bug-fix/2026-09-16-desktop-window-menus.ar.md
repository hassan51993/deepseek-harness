# Agent Note: Desktop standard macOS window menus

Status: implemented

[English](2026-09-16-desktop-window-menus.md) | العربية

## مشكلة

Desktop shell استخدام ذاتي تعريف نموذج لوح استبدال Electron افتراضي تطبيق قائمة مفرد، هذا نموذج لوح هذا قبل فقط صف خروج تطبيق قائمة مفرد و Edit قائمة مفرد.Electron فقط بناء نموذج لوح في إعلان role، لذلك macOS فقد ذهاب افتراضي نموذج لوح توفير File،Window قائمة مفرد و تطبيق إخفاء أمر، يشمل Close Window(⌘W) ،Minimize(⌘M) و Hide(⌘H). هذه سريع سريع مفتاح في Desktop تطبيق في كل لا يوجد أي فاعلية نتيجة، بينما نفس صنف macOS تطبيق كل سوف استجابة هو جمع (#4374).

## قرار

macOS فوق نموذج لوح في Edit قائمة مفرد قبل إعلان `{ role: 'fileMenu' }`، في ذلك بعد إعلان `{ role: 'windowMenu' }`، و في تطبيق فرعي قائمة مفرد Quit قبل إعلان من قسم فصل رمز فصل فتح `hide`،`hideOthers` و `unhide`. هذه role فقط توفير معيار قائمة مفرد بند؛ لا إعلان Services فرعي قائمة مفرد، نافذة قائمة أو أخرى macOS افتراضي بند.Windows و Linux إبقاء تطبيق قائمة مفرد و Edit قائمة مفرد.

هذه role وسم هو Electron داخلي إنجليزي نص معتاد كمية (`lib/browser/api/menu-item-roles.ts` `filemenu`،`windowmenu`،`close`،`minimize`،`hide`) ، لا يوجد لغة استعلام، بينما كما Electron في قائمة مفرد عرض قبل سوف يأخذ هذه وسم إعادة كتابة إلى هذا آلة قائمة مفرد بند فوق، لذلك في غير إنجليزي نص Desktop فوق هو جمع ما زال هو إنجليزي نص؛ قائم Edit قائمة مفرد نفس مثال مثل هذا. هذا داخل لا إضافة جديدة أي ذاتي تعريف إغلاق، الأكثر صغير تحويل أو إخفاء شفرة:⌘W عبر Electron ذاته role إلغاء تدمير نافذة.

## اعتبار مرور بديل خطة

**يأخذ ⌘W ربط لـ الأكثر صغير تحويل أو إخفاء نافذة.** macOS يأخذ الأكثر صغير تحويل إبقاء إعطاء ⌘M، يأخذ إخفاء إبقاء إعطاء ⌘H، نفس صنف تطبيق كل استخدام ⌘W إغلاق الأكثر قبل نافذة. إعطاء هذا عدد سريع سريع مفتاح ربط أخرى أمر سوف مخالفة خلف هذا تعديل الذي التزام دوران منصة معتاد مثال.

**فقط إعلان Window قائمة مفرد.** هذا قائمة مفرد توفير Minimize و Zoom، لكن لا توفير إغلاق،⌘W ما زال لا يوجد ربط.

**في تطبيق فرعي قائمة مفرد داخل مباشر إضافة واحد `{ role: 'close' }` بند.** هذا مثال يمكن تجنب تجنب فقط لديه واحد أمر File قائمة مفرد، لكن سوف يأخذ نافذة أمر وضع إلى Plugins،Updates،Hide،Quit هذه تطبيق درجة أمر في بين، لا يوجد macOS تطبيق هذا مثال ترتيب نشر.

**في كل منصة كل إعلان File و Window قائمة مفرد.** نفس نسخة نموذج لوح في ذلك بعض منصة سوف يأخذ Ctrl+W إعلان لـ إغلاق؛ تطبيق فقط لديه واحد نافذة، إغلاق هو سوف إطلاق `window-all-closed` و خروج تطبيق، يأخذ نافذة سريع سريع مفتاح تغيير صار مستخدم لا يوجد اشتراط خروج مسار.

**يجعل Dock تنشيط وقت بلا نقاش أخرى نافذة هل وجود كل إعادة بناء رئيسي نافذة.** إضافة نافذة يمكن مقارنة رئيسي نافذة تخزين نشط أكثر دائم، لذلك يأخذ `activate` حكم قطع من `BrowserWindow.getAllWindows()` تعديل لـ `mainWindow` قدرة يجعل نقر Dock مجموع يمكن استعادة رئيسي نافذة. لكن هذا تجاوز خروج استعادة يتم ضغط إسقاط منصة أمر، يخص نافذة دورة الحياة سلوك تغيير، لذلك إبقاء قائم `activate` حكم قطع.

## أثر

macOS استعادة ذاتي تعريف قائمة مفرد ضغط إسقاط نافذة و تطبيق أمر، بديل قيمة هو أربعة عدد قائمة مفرد role. في غير إنجليزي نص Desktop فوق هذه وسم ما زال هو إنجليزي نص.

## اختبار

`apps/desktop/tests/main-startup.spec.ts` في واحد حالة استخدام ثابت كل منصة إعلان قائمة مفرد role، يشمل macOS إخفاء أمر. أساس في role قائمة مفرد بند من هذا آلة تنفيذ، لذلك برنامج تحويل `click()` و vitest Electron mock كل لا يمكن لمس بلوغ هذه سريع سريع مفتاح؛ استخدام حقيقي Electron 44 تشغيل نفس نموذج لوح عرض، فقط لديه في هذا تعديل بعد عندئذ ظهور معيار File،Window و تطبيق قائمة مفرد بند، و كما في `app.getLocale()`،`getSystemLocale()` و `getPreferredSystemLanguages()` كل تقرير إبلاغ `ar-SA` وقت وسم إبقاء ثابت.
