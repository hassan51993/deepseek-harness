# Agent Note: Thinking ضيق تجميع Markdown

Status: implemented

[English](2026-09-17-thinking-markdown.md) | العربية

## مشكلة

Chat Thinking يتضمن نموذج تحرير كتابة Markdown، لكن صاف نص تصيير مباشر عرض عنوان، قوي ضبط علامة و شفرة محيط شريط. مشترك عودة جواب ترتيب إصدار سوف يجعل عنوان مقارنة مرة درجة دفع إدارة نص أكثر كبير، أكثر تنبيه هدف.Trajectory مقابل نفس دفع إدارة محتوى استخدام عودة جواب ترتيب إصدار.

## قرار

[MarkdownText](../../../../packages/client/ui-primitives/src/markdown/MarkdownText.tsx) يملك ضيق تجميع عرض تغيير جسم، توفير Chat Thinking و Trajectory تفكير اعتبار تفصيل حال استخدام. محتوى امتداد استخدام مرة درجة حرف رقم، سطر عال و tertiary لون لون. كل درجة عنوان إبقاء دلالة عنصر عنصر، لكن موحد واحد استخدام 600 حرف إعادة و نفسه حرف رقم؛ مقطع سقوط، قائمة، مرجع و شفرة اعتماد ضيق تجميع بين مسافة. رابط إبقاء افتراضي نقطة حالة تحت تخطيط خط و tertiary لون لون، بصفة[مشترك رابط مثال صيغة](../feature/2026-09-04-web-clickable-link-styles.ar.md) مرة درجة محتوى مثال خارج؛ شفرة إبقاء انتظار عرض حرف جسم و قاع لون.

جدول إطار و عام صيغة متابعة عبر قائم محلل تفعيل. ذلك حاوية حد أفقي نحو فيض خروج، عام صيغة نص وراثة مرة درجة حرف رقم. سطر داخل عام صيغة إبقاء KaTeX أصلي أساس خط، من خارج طبقة نص كتلة تحمل تحمل فيض خروج معالجة، قصير عام صيغة لن إنتاج تمرير بند. ضيق تجميع شفرة شريط إبقاء صحيح معتاد وثيقة تدفق، يجعل [Thinking طي عنوان](../feature/2026-08-03-web-sticky-collapsible-headers.ar.md) يقع في تمرير محتوى فوق جهة، بلا حاجة ثاني بند sticky شريط.

Chat سوف تشغيل حالة نقل إعطاء قائم زيادة كمية Markdown مصير. طي ملخص ما زال هو مستقل مفرد سطر نص إسقاط. محلل، تجميد ربط كتلة ذاكرة مؤقتة، تخزين دفع إدارة محتوى و Session صيغة متساو إبقاء ثابت.Trajectory سوف Thinking ثابت في فحص جهاز 13px/20px طبقة درجة، و Chat محتوى حرف رقم ضبط غير متصل. ذلك عودة جواب إخراج إبقاء قائم ترتيب إصدار و ذلك [Thinking طي سلوك](../feature/2026-09-09-ptc-trajectory-code-inspection.ar.md).

## سبق اعتبار بديل خطة

**مباشر استخدام عودة جواب ترتيب إصدار.** كبير عنوان و عرض رخو كتلة بين مسافة يجعل دفع إدارة مقارنة عودة جواب أكثر تنبيه هدف.

**من كل استخدام جهة مفرد وحيد ضبط Markdown مثال صيغة.** Chat و Trajectory سوف حاجة قسم آخر تتبع أثر نفسه تصيير عنصر عنصر؛ أساس عنصر يملك هذه عنصر عنصر و ذلك ضيق تجميع عرض.

**منع استخدام جدول إطار و عام صيغة.** قائم مصير قد دعم حمل اثنان من. حد فيض خروج و وراثة حرف رقم يمكن إبقاء لديه استخدام محتوى، بلا حاجة زيادة آخر نوع تحليل نمط.

## عاقبة

Thinking دعم حمل بنية تحويل قراءة قراءة، معا إبقاء مرة درجة قوي ضبط. رغم لكن نظر شعور طبقة درجة يتم موحد واحد، مساعد مساعدة تقنية فن ما زال يمكن استخدام دلالة عنوان. مشترك تغيير جسم معا لأجل اثنان عدد عرض؛ لاحق Markdown عنصر عنصر تغيير يجب معا إبقاء ضيق تجميع ترتيب إصدار و افتراضي عودة جواب ترتيب إصدار.

Markdown لين تبديل سطر و عودة جواب متن واحد مثال طي؛ صلب تبديل سطر و مستقل مقطع سقوط حاجة متبادل ينبغي Markdown لغة قاعدة. تدفق صيغة تجميد ربط بـ كامل كتلة لـ مفرد موضع، لذلك بعد لم انتهاء طويل مقطع سقوط ما زال موضع في متغير ذيل جزء، و مع زيادة طويل إعادة تحليل.
