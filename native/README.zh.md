و DeepSeek Harness واحد نفس صيانة أصلي شفرة المصدر و عام حزمة.[`system/` workspace](system/README.zh.md) مسؤول Landlock بدء جهاز،POSIX flock ربط، منصة حزمة و[إصدار مسار](system/docs/release.md).

## Workspace و إصدار حد

`system/` و ذلك حزمة يخص مستودع أصل pnpm workspace، و مشترك استخدام أصل قفل ملف. تطوير و CI في harness مستهلك مباشر استخدام حالي workspace مدخل حزمة، لذلك بدء جهاز اتفاق تغيير و مستهلك تحديث يمكن في نفس عدد تعديل في سقوط أرض و واحد بدء اختبار.

رئيسي مستودع `Node Addon System` سير العمل لـ كل تلقي دعم حمل هيكل بنية بناء و اختبار.`Node Addon System Release` تجميع تجميع هذه أصلي ناتج، تحزيم و تحقق npm tarball، مع بعد اختياري اختيار بـ نفس عدد أصلي حزمة إصدار إصدار. مدخل حزمة متابعة سوف منصة حزمة إعلان لـ npm اختياري اعتماد، لذلك npm ما زال فقط سوف تثبيت و مستخدم عملية نظام و CPU مطابقة حزمة.
