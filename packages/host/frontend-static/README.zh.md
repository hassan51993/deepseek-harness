# @deepseek-ai/dsh-host-frontend-static

[English](README.md) | العربية

## عام وصف

من إعداد إصدار دليل نحو متصفح توفير قد بناء Web قشرة. أصل مسار و إعداد index مسار تصيير يتضمن بدء معلومة index؛ قد لديه مورد إنتاج مباشر توفير، بينما ناقص أو غير ملف مسار إرجاع 404، مسار مرة تاريخ إرجاع 403، لا دعم حمل طريقة إرجاع 405. وصول index حاجة صالح عملية token أو متصفح cookie، لكن ساكن حالة مورد إنتاج ما زال يمكن عام وصول. نفس وقت فقط قدرة لديه واحد نسخة معالجة لم مطابقة توجيه؛ ثاني عدد نسخة بدء فشل، إزالة نشط حركة نسخة بعد، لم مطابقة طلب إرجاع 404.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في خدمة قد بناء Web قشرة متصفح مضيف في تركيب هذا إضافة: هو احتلال حسب webserver رجوع مقعد موضع، و ينبغي جواب كل لم يتم أداة اسم توجيه أمر في طلب. هو فقط حاجة واحد إعداد قيمة——قد بناء قبل طرف `index.html` يقع في أي موضع.

### الأكثر صغير إعداد

```yaml
- name: '@deepseek-ai/dsh-host-frontend-static'
  config:
    distIndex: /absolute/path/to/dist/index.html
```

`distIndex` هو تركيب تطبيق تجميع واقع:[`dsh-web-app`](../../bundle/web-app/README.zh.md) عبر قبل طرف حزمة exports تحليل هو و تركيب هذا إضافة؛ نشر أبدا صلب تحرير رمز هو.

### خادم فعلي تطبيق قيد

طلب من dist أصل دليل (يتضمن `distIndex` دليل) توفير.dist أصل دليل و إعداد index مسار بـ HTTP 200 تصيير `index.html`؛ أي أخرى قد لديه ملف حسب ذاته MIME نوع مباشر توفير، لم معرفة توسيع اسم حسب `application/octet-stream` توفير. تحليل إلى أصل دليل خارج مسار بـ 403 رفض، لذلك دقيق قلب بنية صنع مسار لا يمكن قراءة dist لـ فوق ملف.dist أصل دليل داخل لا وجود أو لا هو ملف هدف——ملف ناقص، دليل أو إعداد index ناقص——إرجاع فارغ 404. لا يوجد مطابقة أداة اسم توجيه غير GET/HEAD طلب إرجاع 405. كل نجاح index استجابة كل مرور webserver `renderIndex` تصيير، لذلك بدء manifest(بيانات وصفية بيان) سوف عبر `/` و إعداد index مسار إرسال بلوغ صفحة.

أصل مسار و إعداد index استجابة سوف في قراءة HTML قبل استدعاء `ctx.connection.authorizeIndex`. صالح عملية token سوف نيل إلى 303 إعادة تحديد نحو و حمل دائم متصفح cookie؛ قد لديه صالح cookie وقت مباشر توفير index؛ أخرى index طلب نيل إلى Connection كل 401 استجابة. غير index ملف ما زال هو عام ساكن حالة مورد.Token،cookie، مرور مدة وقت و توقيع سجل دلالة كل عودة Connection كل.

### يمكن مراقبة فشل

مرة تاريخ إرجاع 403 بينما لا هو خطأ صفحة.dist أصل دليل داخل لا وجود أو لا هو ملف هدف إرجاع فارغ 404، لذلك بطلان رابط أو تجميع خطأ pathname هو صريح فشل، بينما لا هو ساكن صامت SPA رجوع. ثاني مرة احتلال حسب مقعد موضع سوف رمي خطأ، بينما مقعد موضع بلا شخص احتلال حسب وقت webserver إرجاع 404——هذا إضافة fiber يتم dispose(مورد تحرير) بعد، متصفح يرى حينئذ هو هذا استجابة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### تصميم إدارة فكرة

هذه الحزمة هو محيط التفاف `serveStatic` واحد دالة إضافة:`apply` من `distIndex` تحليل خروج dist أصل دليل، بناء واحد مقابل أصلي `index.html` تشغيل `ctx.webServer.renderIndex` `renderIndex` إغلاق حزمة، و في effect أثر مجال تحت تسجيل رجوع handler. حسب webserver اتفاق، مقعد موضع فقط لديه مفرد واحد كل من——ثاني مرة تسجيل سوف رمي خطأ——كما تلقي effect أثر مجال قيد، لذلك dispose fiber أي تحرير مقعد موضع.

### مرة تاريخ شبكة شريط

`serveStatic` مواصفة تحويل طلب pathname و تجميع وصل إلى dist أصل دليل، لكن بعد اشتراط هدف حينئذ هو أصل دليل ذاته أو إبقاء في هو لـ تحت. فحص استخدام `sep` بينما غير `/`، لأن `resolve()` في Windows فوق إخراج عكس مائل عمود مسار، هذا وقت `/` بعد لاحقة سوف يأخذ كل دمج قاعدة فرعي مسار كل عند عمل مرة تاريخ رفض.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح بعض عدد مورد إنتاج صنف آخر أي وقت بعد لم يتم تغطية. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **ابتدائي MIME جدول جدا دقيق بسيط**: هو تغطية Vite إخراج مورد إنتاج تجميع دمج و فعلي تسليم PWA manifest؛ أخرى توسيع اسم في متبادل ينبغي مورد إنتاج صنف آخر إصدار قبل كل سوف رجوع إلى `application/octet-stream`.
- **Pathname توجيه هو صريح إعلان**——حالي عميل من أصل دليل أو إعداد index مسار دخول، لا يوجد History API pathname توجيه. إضافة جديدة واحد بند حاجة صريح خادم قاعدة و حقيقي تركيب تغطية، بينما لا هو مقابل كل مرة لم أمر في فعل عرض عام رجوع.
