# @deepseek-ai/dsh-host-directory-picker-browse

[English](README.md) | العربية

## عام وصف

لا يمكن لمس بلوغ OS اختيار جهاز مستخدم ما زال قدرة عبر `dsh-host-directory-picker-browse` اختيار مساحة العمل دليل: هو أساس في Node معيار مكتبة توفير مفرد طبقة دليل صف رفع و فرعي دليل إنشاء، مضيف شاشة ستار فوق لا تصيير أي شرق غرب——لذلك هو قدرة خدمة أصلي خلفية لا يمكن لمس و بعيد مسار عميل. صف رفع فقط إرجاع دليل، حسب اسم ترتيب، تتبع مع إشارة نحو دليل رمز رقم رابط، و يحمل مضيف حكم تحديد `hidden` علامة سجل؛ إنشاء لا تمرير عودة، كما يأخذ اسم تحقق لـ مفرد عدد مسار مقطع. واحد سطر تركيب إعداد أيضا سوف استخدام تطبيق داخل**اختيار مساحة العمل دليل**محادثة إطار ملء ممتلئ مساحة العمل مسار دليل توسيع موضع.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في بعيد مسار متصفح،SSH تحويل إرسال جلسة أو بلا شخص قيمة حراسة مضيف انتظار لا يمكن استخدام OS اختيار جهاز مشهد في، إذا يجب اختيار مساحة العمل دليل، طلب تركيب هذا خلفية. مساحة العمل مسار قيادة `directoryPicker/list` و `directoryPicker/createDirectory`؛ اثنان عدد أصل لغة كل أساس في مضيف نظام الملفات إرجاع نتيجة.

### صف رفع دليل

`list(path?)` إرجاع واحد دليل طبقة درجة: حسب اسم ترتيب فرعي دليل و ذلك قطعا مقابل مسار،`hidden` علامة سجل (POSIX فوق لـ نقطة بادئة) ،`home` مرساة نقطة، و `crumbs`——من أصل إلى هدف أصل أولا سلسلة، منها كل crumb كل هو قفز تحويل هدف، أصل بـ كامل مسار علامة ملاحظة. لا حمل مسار وقت صف رفع مضيف حساب مستخدم بيت دليل. مفرد مرة استدعاء حتى كثير إرجاع `maxEntries` سطر (بند إعداد، افتراضي 1,000——GitHub شبكة صفحة طرف مقابل دليل صف رفع اعتماد نفس حد أعلى) ، يتم مقتطع طبقة درجة سوف تقرير إبلاغ `truncated: true`، توفير عميل تلميح طبقة درجة لا كامل. إشارة نحو دليل رمز رقم رابط سوف يتم تتبع مع؛ قطع سلسلة و حلقة رابط يتم قفز مرور.

### إنشاء دليل

`createDirectory(path, name)` في قائم أب دليل تحت إنشاء واحد فرعي دليل. هو لا تمرير عودة——أب دليل ناقص هو حقيقي فشل، لا هو يلزم تكملة صنع طبقة درجة——و كما رفض أي غير مفرد عدد غير فارغ أبيض مسار مقطع محتوى (`name` لا نيل يتضمن قسم فصل رمز، أيضا لا نيل لـ `.` أو `..`).

### يمكن مراقبة فشل

اثنان عدد أصل لغة كل رفض غير تماما حد تحديد مسار——متبادل مقابل شكل، و Windows فوق `isAbsolute` سوف وضع سطر بلا قرص رمز لديه أصل شكل (`\foo`،`/foo`) و لا كامل UNC بادئة——تقرير `directory-unreadable` أو `directory-create-failed`، بينما لا هو يأخذ هو تحليل إلى مضيف عملية عمل دليل لـ تحت. إنشاء قد وجود فرعي دليل وقت إرجاع `directory-exists`. استدعاء جهة `AbortSignal` سوف إيقاف إجراء في مسح، لذلك قطع وصل أو مهلة لن يجعل مسح مقارنة استدعاء جهة نشط نيل أكثر دائم.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxEntries` | `1,000` | مفرد عدد صف رفع طبقة درجة كامل نتيجة حد أعلى؛ إخفاء سطر حساب دخول هذا حد أعلى |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-host-directory-picker-browse) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### تصميم إدارة فكرة

خلفية يأخذ مفرد عدد دليل طبقة درجة تدفق صيغة إرسال دخول واحد محدود، حسب اسم ترتيب نافذة، لذلك بلا نقاش دليل لديه كثير قليل فرعي بند، داخل تخزين كل إبقاء O(maxEntries): يتم مقتطع طبقة درجة إبقاء حسب اسم ترتيب رأس جزء، إخفاء سطر حساب دخول حد أعلى، فقط استكشاف قياس نافذة داخل مرشح، و تقرير إبلاغ `truncated: true`. نافذة إدراج دخول لـ اثنان قسم فحص بحث، ممتلئ نافذة ذيل جزء مفرد مرة مقارنة مقارنة أي رفض، لذلك تجاوز كبير نوع طبقة درجة في رأس جزء بعد كل مرشح كل فقط يحتاج O(1) ، بينما لا هو نافذة مسح.

### تماما حد تحديد شبكة شريط

`fullyQualified` رفض أي لا إشارة نحو واحد و عملية حالة غير متصل ثابت نظام الملفات موضع مسار:POSIX فوق اشتراط POSIX قطعا مقابل مسار؛Windows فوق فقط قبول قرص رمز حد تحديد (`C:\…`) أو كامل UNC(`\\server\share…`) شكل. بلا قرص رمز لديه أصل شكل و لا كامل UNC بادئة قدرة عبر `isAbsolute`، لكن ما زال سوف تحليل إلى عملية حالي قرص رمز، لذلك خلفية سوف رفض هو جمع، بينما لا هو إعادة تحديد موضع بروتوكول نقل دخول قيمة.

### في توقف و استكشاف قياس

كل مرة انتظار نظام الملفات عملية وقت، كل سوف عبر `raceAbort` و استدعاء جهة إشارة تنافس تنازع، لذلك توقف ركود شبكة نظام الملفات لا يمكن يجعل قد مغادرة فتح استدعاء جهة طلب متابعة تخزين نشط؛ قد وضع ترك قراءة عملية أي جعل قليلا بعد انتهاء، ذلك نتيجة أيضا سوف يتم تجاهل اختصار. رمز رقم رابط يمكن دخول صفة من `stat` استكشاف قياس قرار——فشل أي غير ممكن دخول——نافذة داخل قطع سلسلة رمز رقم رابط لن من نافذة خارج عودة ملء، لأن حدوث مرور دفع تدريجي ذاته قد يأخذ طبقة درجة علامة لـ مقتطع.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح تصفح تفاعل في أي موضع لا كامل أو متعمد لا حد تحديد نطاق. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **لا قراءة Windows إخفاء خاصية**——Node dirent لا كشف `FILE_ATTRIBUTE_HIDDEN`، لذلك في كل منصة فوق `hidden` كل معنى طعم حال نقطة بادئة، مباشر إلى أصلي استكشاف قياس قيمة نيل دفع خروج متبادل ينبغي صار هذا لـ توقف.
- **لا قطعة رفع قرص رمز أصل**——Windows فوق أصل أولا سلسلة توقف في قرص رمز أصل؛ عبر قرص اعتماد متصفح UI مسار إدخال مدخل، بينما لا هو هذا داخل قطعة رفع أصل لغة.
- **كل قرص يمكن تصفح**——لا يوجد حسب نشر حد تحديد تصفح أصل؛`workspace.create` قبول مهمة معنى مسار، لذلك هذا داخل أصل سوف حد تحديد UX نطاق، بينما لا هو أمان حد.
