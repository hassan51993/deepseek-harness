# @deepseek-ai/dsh-mcp-resources

[English](README.md) | العربية

## عام وصف

`dsh-mcp-resources` يجعل نموذج اكتشاف و قراءة قد إعداد MCP خادم توفير وثيقة. مع مرفق profile في استدعاء جهة أثر مجال في إعداد خادم وقت، تلقائي توفير ثلاثة عدد مشترك أداة. كل أداة كل اشتراط صريح إشارة تحديد خادم اسم، و كما فقط في استدعاء وقت قراءة محتوى. مورد نص دخول محادثة تاريخ؛ اثنان دخول صنع تحميل حمل ما زال يمكن توفير برنامج تحويل استدعاء جهة وصول، و بـ شرح نص حرف عرض إعطاء نموذج.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

مع مرفق profile قد موحد واحد تركيب هذه الحزمة مرة. أنت فقط يحتاج لـ الذي يحتاج خادم إعداد [MCP عميل](../mcp-client/README.ar.md) بند.

### خادم إعداد

عبر[عميل إعداد](../mcp-client/README.ar.md#use-this-package) في هدف أثر مجال في إضافة خادم. هذه الحزمة لا يوجد إعداد حقل.

استدعاء جهة لا يوجد قد إعداد MCP خادم وقت، في native أو PTC نمط تحت كل نظر لا إلى MCP نص التوجيه نص أو مورد أداة. إعداد خادم بعد سوف تفعيل ثلاثة عدد مشترك مورد أداة، يشمل من أخرى مزود تركيب عميل خادم، و لا يوجد أداة أو إشارة أمر خادم. فقط يلزم عميل بند إبقاء تنشيط، اتصال فشل حينئذ لن إزالة مشترك أداة؛ مورد استدعاء سوف تقرير إبلاغ اتصال خطأ.

### اكتشاف و قراءة

تركيب توجيه النظام تجميع خدمة وقت، نص التوجيه صف خروج استدعاء agent مرئي خادم اسم. سوف منها واحد اسم بصفة `server` استدعاء `list_mcp_resources` أو `list_mcp_resource_templates`. لم توفير تنقل علامة وقت،MCP SDK استلام تجميع خادم الكل قسم صفحة؛ صريح توفير تنقل علامة وقت إرجاع واحد صفحة؛ سوف منها `nextCursor` أصل مثال بصفة `cursor` نقل دخول، بـ طلب تحت واحد صفحة. استخدام نفسه `server` اسم و صريح `uri`، عبر `read_mcp_resource` قراءة قد صف خروج URI أو توسيع بعد نموذج لوح.

كل عملية كل في استدعاء agent أثر مجال في تحليل خادم. نقص قليل خادم معامل أو خادم غير ممكن استخدام وقت، سوف في إرسال إرسال قبل فشل. اتصال كل من مسؤول طلب إلغاء، مهلة و استعادة؛ فشل طلب ما زال جدول الآن لـ فشل أداة استدعاء.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ داخلي دقيق عقدة——انقر للتوسيع</summary>

[base](../../bundle/base/README.ar.md) و مستقل [sdk-minimal](../../bundle/sdk-minimal/README.ar.md) bundle قسم آخر يملك التالي إعداد سطر:

```yaml
- id: mcp-resources
  name: '@deepseek-ai/dsh-mcp-resources'
```

أثر مجال في أول عدد مزود تسجيل هذا أثر مجال مشترك أداة؛ إزالة الأكثر بعد واحد مزود سوف إزالة محلي أداة تسجيل، وراثة مزود و أداة ما زال مرئي. مورد خدمة مستقل في أول عدد مزود إضافة يملك مشترك أداة effect، لذلك إزالة هذا مزود لن إزالة أخرى خادم ما زال حاجة أداة. مزود اختيار و خادم اسم نص التوجيه استخدام نفس أثر مجال سجل التسجيل. كل مرة استدعاء كل في إرسال إرسال قبل تحليل خادم.

مواصفة نتيجة لـ برنامج تحويل استدعاء جهة إبقاء كامل JSON. صاف نص مصير إضافة خادم ملكية معلومة، و سوف نص قيمة `blob` حقل استبدال لـ شرح ذلك base64 طويل درجة نص حرف؛URI،MIME نوع و نص حقل ما زال إبقاء في تصيير بعد JSON في. أداة خط الإنتاج مسؤول سجل نتيجة. خادم إشارة أمر عودة MCP عميل و ذلك قد سجل توجيه النظام مقطع سقوط كل.

| شفرة المصدر | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | أثر مجال مزود اختيار و خادم اسم نص التوجيه سياق |
| [`src/tools.ts`](src/tools.ts) | مشترك مورد عملية و معامل schema |
| [`src/render.ts`](src/render.ts) | حمل ملكية معلومة كما لا داخل ربط اثنان دخول صنع تحميل حمل نص إسقاط |

لا إصدار `./invariant` إعداد طقم مدخل: أداة، نص التوجيه اسم و إرسال إرسال متساو مصدر في نفس مجموعة من effect يملك مزود تسجيل. هو جمع لا يوجد يمكن توفير نواة مقابل مستقل مراقبة قياس قيمة؛ سجل التسجيل effect فحص لا يخص وقت التشغيل ثابت صيغة.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### مشترك مورد أداة

#### نموذج يرى ماذا

[توليد أداة schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-mcp-resources) تعريف استدعاء جهة مرئي كل قد إعداد خادم مشترك ثلاثة عدد أداة. لا يوجد هذا صنف خادم وقت،native schema،PTC إعلان و ربط و خادم اسم نص التوجيه متساو لا وجود. تنشيط عميل اتصال، قطع فتح أو إعادة محاولة وقت، هذه مشترك أداة تعريف إبقاء ثابت. تركيب توجيه النظام تركيب إعداد كما وجود مرئي مزود وقت،`MCP resource servers` مقطع سقوط عرض `Use list_mcp_resources, list_mcp_resource_templates, or read_mcp_resource with one of these names as the server argument: <JSON array>.` اسم قدوم ذاتي نفس أثر مجال سجل التسجيل، يشمل حيث لا يوجد أداة أيضا لا يوجد إشارة أمر خادم. سجل التسجيل لـ فارغ وقت لا مساهمة هذا مقطع سقوط.

#### Token أثر

لا يوجد استدعاء جهة مرئي قد إعداد خادم وقت، هذه الحزمة لا زيادة أداة أو نص التوجيه token. لا فإن، ثلاثة عدد مشترك تعريف حمل قدوم ثابت schema فتح إلغاء، خادم اسم مقطع سقوط زيادة حسب ترتيب ترتيب صف مرئي اسم JSON قائمة. مورد قائمة و وثيقة فقط في عملية إرجاع بعد زيادة محتوى.

#### KV Cache أثر

إضافة استدعاء جهة مرئي أول عدد خادم أو إزالة الأكثر بعد واحد خادم، سوف تغيير لاحق أداة schema أو PTC إعلان بادئة. مرئي اسم تغير وقت تحديث خادم اسم مقطع سقوط؛ استبدال نفس اسم مزود لن تغيير هذا نص. مفرد صاف اتصال فشل لن تغيير مشترك تعريف أو اسم.

### مورد نتيجة

#### نموذج يرى ماذا

نجاح نتيجة بـ `MCP server: <server>` فتح رأس، مع بعد هو تبديل سطر و إرجاع JSON. كل نص قيمة `blob` كل تغيير لـ `[binary resource: <length> base64 characters; available to programmatic callers]`. خادم توفير نص، بيانات وصفية و متابعة نقل تنقل علامة ما زال مرئي.

#### Token أثر

تصيير بعد نتيجة نحو أداة تاريخ إضافة نص. اثنان دخول صنع شرح نص حرف بديل تحميل حمل base64 token فتح إلغاء؛ هذه الحزمة لا ضبط مقدار خارج نص كبير صغير حد.

#### KV Cache أثر

كل نتيجة إلحاق إلى تاريخ في، لا تعديل كتابة هذا قبل نتيجة. لاحق قراءة يمكن إرجاع قد تغير خادم محتوى و إلحاق مختلف نتيجة؛ هذه الحزمة لن تحديث جديد هذا قبل قد سجل محتوى.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

مورد وصول من صريح استدعاء حسب يحتاج إرسال بدء.

- لا أداة تجهيز MCP `resources` قدرة قد إعداد خادم ما زال سوف ظهور في خادم اسم نص التوجيه في، و إبقاء مشترك مورد أداة متاح.SDK إرجاع فارغ مورد قائمة و نموذج لوح قائمة؛ لا تلقي دعم حمل قراءة سوف فشل.
- `tools.restrict()` في تسجيل مرور ترشيح شرط وقت فحص عام أو أصل أولا أثر مجال توفير اسم. مرجع هذه أثر مجال في لا وجود مورد أداة اسم سوف تقرير لم معرفة أداة خطأ. تسجيل في استدعاء جهة ذاته أثر مجال في مورد أداة لا تلقي allow/deny إخفاء رمز مرور ترشيح.
- لا دعم حمل مورد حجز قراءة و تحديث إشعار؛ مجددا مرة استدعاء قائمة أو قراءة أداة بـ نيل أخذ حالي محتوى.
- اثنان دخول صنع مورد لن إسقاط لـ أصلي صورة أو صوت تردد. برنامج تحويل استدعاء جهة إبقاء ذلك مواصفة base64 قيمة.
- استدعاء جهة يجب توفير خادم اسم. مشترك أداة لن تجمع دمج مختلف خادم؛ قسم صفحة التزام دوران MCP SDK.
