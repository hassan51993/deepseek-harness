# @deepseek-ai/dsh-mcp-client

[English](README.md) | العربية

## عام وصف

`dsh-mcp-client` يجعل نموذج استخدام خارجي MCP(Model Context Protocol) خادم أداة و مورد. كل منصة خادم إعداد واحد بند سجل؛ ذلك أداة استخدام `mcp__github__create_issue` هذا مثال اسم. افتراضي لا تفعيل أي خادم. مع مرفق profile قد توفير[مشترك مورد اكتشاف و قراءة](../mcp-resources/README.ar.md). استدعاء جهة أثر مجال لـ فارغ وقت، لا إضافة MCP أداة أو نص التوجيه نص. خادم إشارة أمر بصفة حرف وجه نص إضافة دخول قد سجل توجيه النظام؛MCP نص التوجيه نموذج لوح لا تلقي دعم حمل. مؤقت بطيء أو انهيار انهيار خادم ممكن تأخير متأخر بدء، أو يجعل استدعاء فشل مباشر حتى استعادة.

## استخدام هذه الحزمة

عند نموذج حاجة مثل استدعاء أصلي أداة واحد مثال استدعاء خارجي MCP خادم وقت، إضافة `dsh-mcp-client`. لـ كل منصة خادم إشارة تحديد وحيد اسم و نقل طريقة. رسمي جهة SDK أولوية اختيار متاح 2026-07-28 بروتوكول، و رجوع إلى دعم حمل قديم إصدار بروتوكول. محلي برنامج استخدام stdio، بعيد طرف خدمة استخدام Streamable HTTP؛stdio تنسيق تجارة سوف أولا بدء مؤقت استكشاف قياس عملية، مجددا بدء فعلي خدمة عملية.

### الأكثر صغير إعداد

كل منصة خادم إضافة واحد بند بند إعداد يكفي، بلا حاجة أخرى محتوى.harness بدء بعد، خادم أداة سوف ظهور في نموذج أداة قائمة في.

```yaml
- id: mcp-github
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: github
    transport: stdio
    command: npx
    args: ['-y', '@modelcontextprotocol/server-github']
    env:
      GITHUB_TOKEN: !!js process.env.GITHUB_TOKEN

- id: mcp-web
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: web
    transport: streamable-http
    url: http://localhost:3000/mcp
    headers:
      Authorization: !!js '`Bearer ${process.env.MCP_TOKEN}`'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `transport` | لا بد ملء | `stdio` أو `streamable-http` |
| `serverName` | لا بد ملء | خادم أداة اسم namespace؛`[A-Za-z0-9_-]{1,32}`، في واحد تسجيل أثر مجال داخل وحيد |
| `command` / `args` / `env` / `cwd` | — | stdio: يمكن تنفيذ ملف، معامل، دمج إلى صاف غسل مرور بيئة لـ فوق مقدار خارج بيئة متغير، عمل دليل |
| `url` / `headers` | — | streamable-http: طرف نقطة URL و مقدار خارج طلب علامة رأس |
| `toolCallTimeoutMs` | `60,000` | كل مرة `tools/call` أو مورد طلب مهلة |
| `maxInstructionBytes` | `32,768` | يشمل خادم ملكية معلومة في داخل خادم إشارة أمر UTF-8 بايت حد أعلى؛ تجاوز خروج وقت اتصال فشل |
| `failOnStartupError` | `false` | ابتدائي اتصال أو أداة تزامن فشل وقت رفض إضافة تنشيط |
| `reconnect.enabled` | `true` | اتصال فقد فقد بعد تلقائي إعادة اتصال |
| `reconnect.initialDelayMs` | `500` | أول مرة إعادة وصل تأخير متأخر؛ كل مرة وصل متابعة فشل محاولة تجربة قلب ضعف |
| `reconnect.maxDelayMs` | `30,000` | تراجع تجنب حد أعلى؛ معا هو إعادة وضع محاولة تجربة ميزانية الذي يحتاج صحيح معتاد وقت التشغيل طويل |
| `reconnect.maxAttempts` | `10` | كل مرة في قطع داخل وصل متابعة فشل محاولة تجربة مرة عدد حد أعلى، تجاوز خروج بعد وضع ترك |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-mcp-client) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

بدء بعد، خادم أداة سوف بـ `mcp__<serverName>__<tool>` شكل صيغة ظهور——تجربة حال استخدام واحد بند نص التوجيه استدعاء منها واحد. إذا ابتدائي اتصال فشل،harness ما زال سوف بدء، لكن هذا خادم أداة لن ظهور، و سوف سجل واحد بند خطأ. ضبط `failOnStartupError: true` سوف رفض إضافة تنشيط؛[app-boot بدء سياسة](../../boot/app-boot/README.ar.md) ما زال سماح اختياري MCP بند إعداد فشل، بينما لا في توقف harness.

### أداة تسمية و مشترك تخزين

نموذج يرى كل أداة كل حمل لديه مستقر خادم حد تحديد اسم:`mcp__<serverName>__<rawName>`، مثال مثل `mcp__github__create_issue`——و Claude Code و Codex استخدام تسمية شكل نفسه. فقط يلزم خادم إبقاء نفسه أداة اسم، اسم حينئذ إبقاء ثابت، لذلك جلسة تاريخ و إذن قاعدة في إعادة بدء و إعادة تحميل بعد ما زال صالح. اثنان عدد خادم يمكن معا توفير اسم لـ `search` أداة، قسم آخر بـ `mcp__github__search` و `mcp__web__search` مشترك تخزين.

- إصدار نفسه أداة اسم (مثال مثل `search`) اثنان عدد خادم سوف في كل منها namespace تحت مشترك تخزين.
- اثنان بند بند إعداد استخدام نفسه خادم اسم وقت، بعد تحميل واحد بند سوف في تحميل وقت بـ واضح خطأ فشل.
- خادم في أداة قائمة في اثنان مرة صف خروج نفس أداة وقت، ذلك أداة قائمة سوف يتم بصفة بلا فاعلية قائمة رفض، فوق واحد مجموعة أداة إبقاء متاح.
- SDK مسؤول اكتشاف قسم صفحة و صفحة عدد حد أعلى. اكتشاف فشل سوف إبقاء قبل أداة؛ صيغة خطأ تنقل علامة سلسلة التزام دوران SDK معالجة سلوك.
- أداة تحديث و قد لديه أداة اسم اندفاع مفاجئ وقت، هذا تحديث سوف يتم كامل جسم رفض——أبدا سوف نيل إلى هذا خادم جزء أداة تجميع.

### استدعاء أداة و قراءة نتيجة

نموذج استدعاء MCP أداة وقت، استدعاء سوف بـ كل مرة استدعاء مهلة (افتراضي 60 ثانية) إرسال نحو بعيد مسار خادم، و مثل أخرى استدعاء الأداة واحد مثال يمكن إلغاء. نتيجة حسب كتلة ترتيب بـ عادي نص إرجاع؛ مورد رابط بـ نص شكل صيغة عرض اسم و URI. إذا خادم تقرير إبلاغ خطأ، استدعاء سوف واضح فشل——نموذج لن يرى وهمي زائف نجاح.

حالي نموذج قبول صورة إدخال كما harness تفعيل مرفق عنصر وظيفة وقت دعم حمل صورة؛ صورة سوف مثل أخرى صورة واحد مثال ظهور في محادثة في. لا دعم حمل صورة وقت——و خادم إرجاع صوت تردد أو تضمين دخول مورد وقت——نموذج سوف يرى صاف واضح تشخيص رسالة، بينما لا هو ماذا كل لا يوجد.

### بدء، أداة تحديث و إعادة وصل

خادم أداة سوف في harness بدء أول عدد جولة قبل ظهور. خادم أكثر تعديل أداة قائمة وقت، نموذج أداة تجميع سوف تلقائي تحديث؛ تحديث فشل وقت، فوق واحد مجموعة أداة متابعة متاح.

خادم اتصال قطع فتح وقت——مثال مثل محلي خادم عملية انهيار انهيار——إضافة سوف بـ من 500 ms بدء تدريجي مرة قلب ضعف، حد أعلى 30 s تأخير متأخر تلقائي إعادة وصل، و تحديث جديد أداة تجميع؛ إعادة وصل دخول درجة في سجل في مرئي. في قطع خلال الأكثر بعد معروف أداة ما زال سوف صف خروج، لكن مقابل هو جمع استدعاء سوف فشل، مباشر إلى خادم استعادة. وصل متابعة فشل عشرة مرة بعد، هذا خادم أداة سوف يتم إزالة، إعادة وصل إيقاف، مباشر إلى أنت إعادة تحميل إعداد أو إعادة بدء harness؛ خادم حمل متابعة اتصال واحد مقطع وقت بعد، هذا حساب عدد سوف إعادة وضع. ضبط `reconnect.enabled: false` يمكن منع استخدام تلقائي إعادة وصل——هذا وقت أداة في قطع فتح بعد ما زال سوف صف خروج، لكن استدعاء فشل، مباشر إلى أنت إعادة تحميل. تحرير بند إعداد سوف في أصل أرض إعادة تحميل خادم اتصال، لم تغيير اسم إبقاء ثابت.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير جسر وصل خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **خادم حد تحديد هوية.** كل MCP أداة كل لديه مستقر هوية `(serverName, rawName)`.namespace هو محلي إعداد، أبدا اعتماد بعيد مسار `serverInfo.name`——بعيد مسار اسم غير ممكن معلومة، في نشر بين لا وحيد، كما ترقية وقت ممكن تغير، هذه كل لا سماح ساكن صامت إعادة تسمية موجه إلى نموذج أداة.
- **تسمية هو ثابت اتفاق.** عام اسم هو `(serverName, rawName)` صاف دالة، و ممتلئ كاف DeepSeek دالة اسم اتفاق؛ لديه ضرر مواصفة تحويل سوف إلحاق 12 موضع عشرة ستة دخول صنع SHA-256 hash، جعل مختلف هوية أبدا سوف طي. جلسة تاريخ و إذن قاعدة لذلك قدرة في HMR(حار وحدة استبدال) ، إعادة تزامن و أخرى خادم تغير بعد إبقاء صالح.
- **أصلي اسم هو وحيد بروتوكول اسم.** `tools/call` بداية نهاية استلام إلى أصلي اسم؛ عام اسم أبدا سوف إرسال إعطاء خادم، أيضا أبدا سوف يتم تحليل قدوم أيضا أصل أصلي اسم.
- **يلزم ما كامل عالم بديل، يلزم ما لا يوجد.** تزامن سوف أصل فرعي أرض تسليم تبديل عالم بديل: نيل أخذ فشل إبقاء فوق واحد عالم بديل، تسجيل اندفاع مفاجئ فإن تراجع كامل محاولة تجربة في عالم بديل.
- **واحد مواصفة قيمة، واحد إسقاط.** منفذ إرجاع بروتوكول كامل مواصفة `McpResult`؛ آخر عدد لديه ترتيب إسقاط دقيق تجهيز Native محتوى،`finalizeContent` فقط في سجل التسجيل تنفيذ بعد نتيجة لم تغيير وقت تثبيت هو، لذلك سياسة كتلة و قيمة استبدال إبقاء مرجعي.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema،`serverName` مسبق إبقاء، تنشيط انتظار |
| [`src/connection.ts`](src/connection.ts) | اتصال مراقبة إشراف جهاز: عميل عالم بديل، إعادة وصل سياسة، محاولة تجربة ميزانية،dispose(مورد تحرير) |
| [`src/server-context.ts`](src/server-context.ts) | مورد مزود تسجيل و حرف وجه خادم إشارة أمر |
| [`src/tools.ts`](src/tools.ts) | أداة جسر وصل: اكتشاف، تسمية، تسجيل تسليم تبديل، تنفيذ، صورة إسقاط |
| [`src/transport.ts`](src/transport.ts) | نقل عمل مصنع: حمل صاف غسل بيئة stdio spawn،Streamable HTTP |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛MCP عالم بديل سوف عبر أداة سجل التسجيل إرسال تلويح أثر، لكن جسر وصل في مختلف خطوة إعادة تزامن بعد لا توفير مستقل خادم أداة خريطة لقطة. |

تصدير `createMcpToolDefinition(ctx, options)` سوف فوق تنقل أداة schema و أصلي نتيجة عودة ضبط ملائم إعداد إلى نفسه مواصفة قيمة، خطأ و حفظ دائم رسم مثل إسقاط. كل مرة عودة ضبط كل استلام إلى أصل مثال `ToolExecution`، يشمل ذلك Agent و إلغاء إشارة؛SDK مواصفة نوع تحقق سوف في إسقاط قبل فحص إرجاع نتيجة. استدعاء جهة مسؤول تسجيل، إلغاء قطع توقف وقت و مزود إزالة. أصلي Cua Driver مزود استخدام هذا ملائم إعداد دالة، بلا حاجة فتح MCP نقل.

### دورة الحياة و تزامن

`apply` تحليل إعادة وصل سياسة، في حالي تسجيل أثر مجال داخل مسبق إبقاء `serverName`، بدء مراقبة إشراف جهاز، و انتظار ابتدائي اتصال إضافة اكتشاف إتمام. مستقل agent(ذكي جسم) أثر مجال يمكن إعادة استخدام نفسه namespace، لأن ذلك أداة و نقل ذاك هذا عزل؛ نفس أثر مجال داخل تكرار سوف في تحميل وقت فشل. مراقبة إشراف جهاز يأخذ كل تزامن——ابتدائي، إشعار و إعادة وصل——سلسلة سطر إلى نفس بند طابور صف، لذلك اثنان مرة تزامن أبدا سوف تسليم خطأ تنفيذ كل منها أولا dispose بعد تسجيل تسليم تبديل.dispose سوف إلغاء انتظار تنفيذ إعادة وصل، إغلاق تنسيق تجارة في نقل أو قد ربط عميل، انتظار إجراء في محاولة تجربة و ترتيب طابور تزامن تماما توقف مستقر، لكن بعد ملاحظة إلغاء حالي عالم بديل.

SDK عبر قديم إصدار إشعار أو الآن بديل بروتوكول حجز قراءة استقبال أداة قائمة تغير. مراقبة إشراف جهاز سوف كل مرة إعادة تزامن ترتيب طابور؛ نيل أخذ فشل وقت إبقاء قبل تسجيل بديل، تسجيل اندفاع مفاجئ فإن تراجع هذا مرة محاولة تجربة. كل مرة لذا عائق مشترك واحد محاولة تجربة ميزانية: وصل متابعة فشل بلوغ إلى `maxAttempts` بعد ملاحظة إلغاء أداة و إيقاف إعادة وصل؛ اتصال حمل متابعة تجاوز مرور `maxDelayMs` فإن إعادة وضع ميزانية.

### أداة تنفيذ داخلي دقيق عقدة

استدعاء الأداة نحو SDK توفير أصلي اسم، كامل أداة تعريف،JSON معامل، إلغاء إشارة و إعداد مهلة.SDK مسؤول بروتوكول تحقق، قد إعلان إخراج schema تحقق و الآن بديل بروتوكول طلب header. نجاح نتيجة مواصفة قيمة لـ `{ content: JsonValue[], structuredContent? }`، لـ تحرير مسار استدعاء جهة و PTC نمط إبقاء صالح MCP JSON كتلة.MCP `isError` نتيجة سوف في صورة حفظ دائم قبل رمي خروج. جسر وصل جهاز في حفظ قبل تحقق كامل دفعة صورة؛ رفض وقت سوف كل ورقة صورة إسقاط لـ تشخيص نص.

### بيئة صاف غسل (stdio)

عملية فرعية بيئة بـ عملية فرعية seam `scrubbedParentEnv()` لـ أساس مقعد——حذف مطابقة `/KEY|PASSWORD|SECRET|TOKEN/i` بيئة اسم و كل `DSH_*` اسم——مجددا في ذلك فوق دمج إعداد `env`، لذلك صريح تغطية نيل بـ إبقاء. فعلي spawn من MCP SDK مسؤول؛ هذه الحزمة مشترك صاف غسل تعريف، بينما غير spawn مسار.

## تجربة النموذج

### قد اكتشاف MCP أداة

#### نموذج يرى ماذا

اكتشاف نجاح بعد،SDK قبول MCP أداة بـ أصلي أداة اسم `mcp__<serverName>__<rawName>`(أو ذلك تحديد صفة مواصفة تحويل شكل صيغة) ظهور، يحمل خادم وصف و إدخال schema. إعادة تزامن سوف استبدال تسجيل بديل؛ تحرير أو إعادة وصل ميزانية استهلاك كل سوف إزالة أداة. لم إعلان tools قدرة خادم بـ فارغ أداة تجميع اتصال.

#### Token أثر

أداة تسجيل خلال، أداة وصف و إدخال schema سوف دخول كل مرة طلب؛ إعادة تزامن سوف استبدال بينما غير تراكم تراكم schema، خادم حد تحديد اسم أيضا سوف لـ كل أداة تعريف و استدعاء زيادة token. قد إعداد عميل أيضا سوف تفعيل[مشترك مورد أداة و خادم اسم نص التوجيه](../mcp-resources/README.ar.md#model-experience).

#### KV Cache أثر

قد اكتشاف أداة تجميع دمج و ذلك schema ثابت وقت، أداة تعريف بادئة إبقاء مستقر. زيادة، إزالة، إعادة تسمية أو أكثر تعديل أداة إعادة تزامن سوف استبدال تعريف، و ممكن جعل من رقم واحد تغير schema token بدء إعادة استخدام بطلان؛ استعادة لم تغيير قائمة إعادة وصل سوف توليد تماما نفسه تعريف، بادئة إبقاء مستقر.

### استدعاء الأداة تاريخ و نتيجة

#### نموذج يرى ماذا

عام أداة اسم و JSON معامل إبقاء في assistant تاريخ في. مواصفة قيمة بداية نهاية لـ برنامج تحويل استدعاء جهة و PTC نمط استدعاء جهة إبقاء كامل MCP JSON كتلة و اختياري بنية تحويل محتوى؛ تلقي دعم حمل صورة كتلة في تأكيد قطع توجيه قدرة نيل إلى إثبات بعد، حسب أصلي ترتيب و نص واحد بدء إسقاط. يتم رفض صورة، صوت تردد، تضمين دخول مورد، مورد رابط و لم معرفة كتلة متابعة بـ محدود نص تشخيص مرئي؛MCP `isError` سوف في صورة حفظ دائم قبل رفض استدعاء.

#### Token أثر

معامل، خريطة بعد نص و حمل دائم صورة مرجع إبقاء إلى ضغط (compaction) حدوث وقت. داخل ربط MCP base64 فقط وجود في تنفيذ نطاق جزء مواصفة قيمة في، أبدا سوف نسخ دخول جلسة حدث؛ مزود سوف من مرفق عنصر تخزين قراءة مرور مرور تحقق بايت. صوت تردد و تضمين دخول مورد تحميل حمل لن دخول نموذج سياق.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV-cache بند بطلان.

### خادم إشارة أمر

#### نموذج يرى ماذا

كل نجاح اتصال إرجاع غير فارغ أبيض إشارة أمر حفظ في واحد حمل خادم اسم مقطع سقوط في. لم إرجاع إشارة أمر أو إشارة أمر فقط يحتوي فارغ أبيض وقت، لا نحو نص التوجيه إضافة نص. زهرة تضمين رقم إبقاء حرف وجه قيمة. بديل اتصال فقط في اكتشاف نجاح بعد إصدار ذلك إشارة أمر؛ تحرير أو استهلاك كل استعادة ميزانية وقت إزالة هذا مقطع سقوط.

#### Token أثر

أثر مجال مقطع سقوط توليد فاعلية خلال، خادم إشارة أمر لـ نموذج طلب مساهمة نص. مورد وثيقة فقط عبر صريح مورد قراءة دخول تاريخ.

#### KV Cache أثر

لم تغير إشارة أمر إبقاء نفسه نص التوجيه نص. تحديث أو إزالة إشارة أمر سوف تغيير تحت مرة تجميع نظام رسالة و ذلك يمكن إعادة استخدام بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أنت لا يمكن استخدام هذا إضافة فعل ماذا، و أي وقت حاجة تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو و أخرى MCP عميل مقابل مقارنة، أيضا لا هو مهمة تراكم ضغط.

- **مورد حسب يحتاج قراءة**——مع مرفق profile توفير[مشترك مورد خدمة](../mcp-resources/README.ar.md) ؛ مورد حجز قراءة و MCP نص التوجيه نموذج لوح لا تلقي دعم حمل.
- **بدء و اكتشاف مهلة وراثة ذاتي MCP SDK**——إضافة لا كشف مفرد وحيد اتصال أو اكتشاف مهلة. تنسيق تجارة و اكتشاف استخدام SDK افتراضي 60 ثانية طلب مهلة؛ اكتشاف أيضا استخدام SDK صفحة عدد حد أعلى. إضافة إزالة أولا إغلاق نقل بـ في قطع انتظار معالجة بدء طلب، مجددا انتظار تنظيف.
- **إعادة وصل معالجة تنسيق تجارة فشل و نقل إغلاق**——ابتدائي استكشاف قياس فشل أو stdio عملية فرعية انهيار انهيار كل سوف استخدام إعداد إعادة وصل ميزانية.HTTP بناء قيام اتصال بعد، طلب فشل استخدام SDK نقل استعادة آلية، بينما غير إعادة إنشاء اتصال.
- **صورة هو وحيد حمل دائم وفير غني نتيجة جسر وصل**——PNG،JPEG،WebP و GIF في تأكيد قطع قدرة نيل إلى إثبات بعد دخول Native سياق. صوت تردد و تضمين دخول مورد تحميل حمل ما زال فقط وجود في تنفيذ نطاق جزء و حمل واضح تشخيص، مورد رابط فقط بـ نص إبقاء اسم و URI.
- **بلا فاعلية بروتوكول نتيجة أو إخراج schema من SDK رفض**——جسر وصل جهاز لا قبول قديم صيغة `toolResult` بديل نتيجة، أيضا لا التفاف مرور قد إعلان schema تحقق.
- **اشتراط أساس في مهمة MCP أداة في استدعاء وقت يتم رفض**——اشتراط استخدام أساس في مهمة تنفيذ (task-based execution) توسيع أداة سوف رمي خروج استثناء بينما غير يتم جسر وصل؛ هذا توسيع لم تنفيذ.

- MCP نص التوجيه نموذج لوح حاجة مستقل مستخدم اختيار و نموذج لوح استدعاء آلية.
- ثابت MCP SDK ما زال في عرض تحويل؛ فوق تنقل كسر تالف صفة تغيير حاجة تحديث جسر وصل.
