# @deepseek-ai/dsh-spill

[English](README.md) | العربية

## عام وصف

`dsh-spill` يجعل إضافة و أداة عبر عام `ctx.spillStore` API حفظ تجاوز كبير نص، و أخذ نيل لا نفاذ واضح تحديد موضع معلومة، دقيق بايت عدد و أخذ عودة إشارة جذب. عند كامل نتيجة يجب إبقاء يمكن أخذ عودة، معا أيضا لا يستطيع ملء ممتلئ نموذج سياق وقت اختيار هو. إعداد `dsh-spill-local` يمكن نيل نيل محلي حفظ دائم؛ عند تجاوز كبير أداة نتيجة ينبغي تغيير لـ محدود معاينة وقت، مجددا إضافة `dsh-spill-policy`. هذا API لا توفير إبقاء، استبدال، أخذ عودة أو بحث عملية. تخزين لذا عائق سوف جعل حفظ عملية رفض، من استدعاء جهة قرار إبقاء داخل ربط محتوى أيضا هو يجعل عملية فشل.

## استخدام هذه الحزمة

حفظ spill ناتج تركيب حاجة تركيب واحد خلفية——فقط هذه الحزمة ذاته لا تخزين أي محتوى.`dsh-spill-policy` قرار أداة نتيجة أي وقت spill؛`dsh-session-reference` مباشر حفظ مقتطع بعد جلسة مرجع transcript(نص سجل) ، لا حاجة هذا سياسة. استدعاء جهة استخدام `ctx.spillStore.saveText()` و واضح إشارة تحديد ملكية؛ اختياري مستهلك عبر `ctx.get("spillStore")` نيل أخذ خلفية.

### أي وقت اختيار

عند نشر حاجة في نموذج يرى محدود معاينة بعد ما زال قدرة أخذ عودة كل نص وقت، اختيار spill تخزين، مثال مثل إمساك أخذ صفحة متن أو قد التقاط جلسة مرجع transcript. قبل رفع هو خلفية تحديد موضع معلومة و أخذ عودة إشارة جذب في نشر بيئة في متاح؛ هذا خدمة لا اشتراط محلي نظام الملفات وصول.

### الأكثر صغير متاح تركيب

يأخذ خلفية و سياسة واحد بدء تركيب؛ ضبط `maxInlineBytes` بعد، أي مرور كبير صاف نص أداة نتيجة كل سوف تلقائي تغيير صار معاينة إضافة تحديد موضع معلومة.

```yaml
- name: '@deepseek-ai/dsh-spill-local'
- name: '@deepseek-ai/dsh-spill-policy'
  config:
    maxInlineBytes: 50000
```

### حفظ نص

تركيب خلفية بعد، استخدام الذي تابع جلسة، مصدر وصف، بناء اقتراح ملف اسم و كامل نص استدعاء `ctx.spillStore.saveText()`:

```text
const ref = await ctx.spillStore.saveText({
  owner: { sessionId: 'session-1' },
  source: { kind: 'tool', toolName: 'web_fetch', callId: 'call-1', label: 'result' },
  suggestedName: 'web_fetch.txt',
  content: fullText,
})
```

إرجاع `SpillRef` يحمل ثلاثة عدد حقل:`locator`، خلفية إنتاج موجه إلى نموذج لا نفاذ واضح جملة مقبض (مقابل `dsh-spill-local` هو محلي ملف مسار، مقابل أخرى خلفية ممكن هو URI أو مفتاح) ؛`bytes`، كتابة دقيق UTF-8 بايت عدد؛`retrievalHint`، مستهلك عرض إعطاء نموذج إشارة جذب——مقابل محلي خلفية بينما قول هو قراءة أو بحث هذا مسار. مستهلك سوف تحديد موضع معلومة و إشارة جذب واحد نفس عرض، أبدا ذاتي سطر تحليل تحديد موضع معلومة.

### ملكية و حد

تخزين حسب الذي تابع جلسة قسم مجموعة:fork بعد جلسة من نوع فرعي سجل وراثة قائم تحديد موضع معلومة، بلا حاجة نسخ أو أكثر تعديل ملكية،fork بعد جديد إنتاج spill استخدام فرعي جلسة id. جلسة مرجع ناتج عودة استقبال سياق هدف جلسة كل، بينما لا هو يتم مرجع مصدر جلسة.`suggestedName` فقط هو تلميح——خلفية سوف يأخذ هو تنظيف صار مفرد عدد أمان مسار مقطع، أبدا يأخذ هو عند عمل يمكن معلومة مسار. معاينة و spill قرار من مستهلك مسؤول؛ تخزين و ناتج مرور مدة من خلفية مسؤول.

### لذا عائق و استعادة

`saveText` فقط في حقيقي تخزين لذا عائق وقت رفض——إذن لا كاف، مغناطيس قرص قد ممتلئ أو خلفية غير ممكن استخدام. من استدعاء جهة قرار مثل أي تخفيض: قد تسليم سياسة يأخذ رفض عند عمل كل قوة بينما لـ معالجة، سجل تحذير إبلاغ و إبقاء أصلي داخل ربط نتيجة، لذلك spill فشل أبدا سوف يأخذ نجاح استدعاء الأداة تغيير صار خطأ أو إخفاء محتوى. إذا لا يوجد تركيب خلفية، حينئذ لا يوجد يمكن حفظ هدف؛ طلب في تركيب في تحميل `dsh-spill-local` أو أخرى خلفية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذا خدمة خلف بعد تصميم قرار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة بناء قيام في واحد قسم مغادرة و لحظة معنى أقصى بسيط لـ فوق:

- **اتفاق، تنفيذ و سياسة إبقاء قسم مغادرة.** هذه الحزمة تعريف خلفية فعل ماذا (`saveText`) ؛`dsh-spill-local` تنفيذ هو؛`dsh-spill-policy` قرار أي وقت إطلاق. كل بند صلة ملاحظة نقطة مستقل عرض دخول و استبدال.
- **فقط لديه واحد طريقة، آخر بلا أخرى.** هذا seam لا مسؤول إبقاء سياسة، نتيجة استبدال أو أخذ عودة/بحث API——ذلك بعض كل لديه كل منها ملكية حزمة.
- **في seam موضع رفض، أبدا ساكن صامت تخفيض.** تخفيض من استدعاء جهة مسؤول؛seam تقرير إبلاغ حقيقي تخزين لذا عائق.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: سحب كائن `SpillStore` خدمة و ذلك `saveText` اتفاق |
| [`src/types.ts`](src/types.ts) | مفردات:`SaveTextSpill`،`SpillRef`، حمل صنف لوحة نوع `SpillLocator`،`SpillOwner`،`SpillSource` |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ حذف ملكية seam قوي صنع تنفيذ اتفاق خارج، هذه الحزمة لا كشف مستقل حدث تسلسل أو متغير بيانات علاقة. |

### بيانات نموذج

`SaveTextSpill` سوف تخزين ملكية و وصف صفة مصدر معلومة قسم فتح.`SpillSource` قبول أداة مصدر `{ kind: "tool", toolName, callId, label }` أو `{ kind: "session-reference", sessionId, label }`، بعد من id معرف يتم التقاط مصدر جلسة. جلسة مرجع أبدا زائف صنع استدعاء الأداة id. مصدر معلومة و ملكية نطاق الأسماء كل لا منح إعطاء قراءة إذن. مستهلك يأخذ إرجاع تحديد موضع معلومة نظر لـ لا نفاذ واضح قيمة، و و أخذ عودة إشارة جذب واحد نفس عرض.

### دورة الحياة

خلفية وراثة `SpillStore` و بـ إضافة طريقة تحميل، تسجيل لـ `ctx.spillStore`؛ كل سياق فقط لديه واحد تنفيذ، ثاني مرة تحميل سوف فشل. تنفيذ dispose(مورد تحرير) وقت سوف تحرير هذا خدمة. سحب كائن صنف ذاته لا تسجيل أي محتوى——هذه الحزمة فقط توفير اتفاق و مفردات.

<a id="model-experience"></a>
## تجربة النموذج

spill مستهلك سوف خلفية تحديد موضع معلومة و أخذ عودة إشارة جذب تصيير إعطاء نموذج، من بينما بين وصل أثر تجربة النموذج.

#### KV Cache أثر

لن مباشر توجيه يؤدي KV Cache بطلان؛ طلب بادئة تغيير من فوق وصف مستهلك مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح spill تخزين خدمة مفرد وحيد استخدام وقت في أي بعض جهة وجه لا كامل. هو جمع هو حالي حزمة قيد.

- **لا يوجد أخذ عودة أو حذف API**——مستهلك فقط قدرة تصيير خلفية تحديد موضع معلومة و إشارة جذب؛ دورة الحياة و وصول دلالة ما زال من خلفية ذاتي سطر قرار.
- **تخزين لا انتظار في وصول تحكم**——الذي تابع جلسة منطقة قسم كتابة نطاق الأسماء، لكن لن تخويل عبر تحديد موضع معلومة قراءة محتوى؛ كل خلفية و أخذ عودة مستهلك كل يجب ذاتي سطر قوي صنع تنفيذ وصول حد.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: بعد لم قرار استكشاف جهة نحو و فتح وضع مشكلة. هو واضح لا أداة مرجعي صفة.

#### لم قدوم: منفذ spill ملف تجميع صار

هذا seam فقط لديه `saveText`؛ لـ قائم منفذ spill ملف توفير حفظ ملف أو رابط/نسخ مسار (مثال مثل مواصفة تحويل bash مؤقت ملف) ، و لـ subagent توسيع توفير أداة ذاتي لديه spill، ما زال تأجيل، رؤية[أداة إخراج spill قرار](../../../.agents/notes/implemented/architecture/2026-07-08-tool-output-spill-files.ar.md).

#### لم قدوم: غير محلي خلفية و تنظيف

بعيد مسار أو قاعدة بيانات خلفية ما زال هو فتح وضع جهة نحو. محلي خلفية تنفيذ ذلك[بدء تنظيف سياسة](../spill-local/README.ar.md#startup-cleanup) ؛ هذا خدمة لم تعريف حسب جلسة تنظيف أو تحديث جديد تحديد موضع معلومة API.
