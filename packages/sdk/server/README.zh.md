# @deepseek-ai/dsh-sdk-jsonrpc-server

[English](README.md) | العربية

## عام وصف

`dsh-sdk-jsonrpc-server` عبر stdio خدمة SDK بروتوكول صيغة (wire format) ، جعل عملية خارج عميل قدرة كاف قيادة harness agent(ذكي جسم): هو لـ كل `sessionId` فتح واحد جلسة، يأخذ مستخدم نص التوجيه ترتيب دخول طابور صف، و يأخذ كل جلسة حدث و agent حالة تحويل تدفق صيغة إرسال عودة عميل. يأخذ هو بصفة `jsonrpc` إضافة تركيب إلى Loader تركيب في؛ خارج محيط إضافة شجرة توفير ذلك بقية واحد قطع——agent، نموذج مهايئ، حفظ دائم و أداة.Stdout فقط تحمل تحميل JSON-RPC لقطة، لذلك نشر لا نيل تركيب stdout logger. هو عبر dispose(مورد تحرير) أصل وقت التشغيل و بـ 0 خروج ينبغي جواب `shutdown`؛EOF و إشارة خروج عودة app bin مسؤول.

## استخدام هذه الحزمة

عند وقت التشغيل يجب خدمة SDK عميل وقت تركيب هذا إضافة: يأخذ هو إضافة دخول تركيب agent خدمة `cordis.yml`، بدء وقت التشغيل، عميل يكفي عبر stdio اتصال. معتاد استخدام مسار هو صريح——إضافة حاجة `agents` خدمة؛ ذلك بقية كل قدرة كل قدوم ذاتي خارج محيط إضافة شجرة.

### تجميع

إضافة في أول مرة استخدام وقت لـ كل `sessionId` إنشاء واحد agent. قد تسجيل نموذج مهايئ أولوية لأجل هذا توجيه؛ بعد بلا مهايئ مسؤول `deepseek-official` توجيه سوف تركيب DeepSeek مهايئ، أي أخرى بعد بلا مهايئ مسؤول مزود كل سوف توجيه يؤدي ابتدائي تحويل فشل. ابتدائي تحويل نجاح قبل، الذي اختيار مهايئ سوف تحليل تأكيد قطع نموذج و اختياري دفع إدارة قوي درجة.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxTokensAsSuccess` | `false` | يأخذ max-token جولة أو subagent إنهاء تقرير إبلاغ لـ نجاح SDK نتيجة |

profile تركيب يملك كل أصل agent أداة.`input`،`output` و `exit` هو فقط توفير اختبار وقت التشغيل نقل خطاف؛ إنتاج بيئة استخدام عملية stdio و `process.exit`. توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-sdk-jsonrpc-server) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### stdout أي بروتوكول

Stdout فقط تحمل تحميل JSON-RPC لقطة، عميل يمكن تدريجي بايت تحليل؛ تشخيص معلومة ينبغي كتابة stderr. طلب لا في تركيب إضافة شجرة في إضافة دخول stdout logger.

### SDK عميل يمكن فعل ماذا

`initialize` هو وقت التشغيل حينئذ خيط حد: خادم من Loader تركيب تركيب وقت، سوف انتظار حالي إضافة شجرة إتمام كل تحميل مهمة بعد مجددا استجابة، لذلك أول مرة نص التوجيه قدرة كاف يرى MCP ابتدائي أداة اكتشاف انتظار مختلف خطوة نفس درجة قدرة. إمساك يد إرجاع بروتوكول مستقر معرف `deepseek-harness-sdk-runtime`. خادم سوف عبر الذي اختيار مهايئ تحقق مزود/نموذج توجيه و اختياري غير فارغ `reasoningEffort`، مجددا حفظ هذه قيمة؛ حذف وقت لن حفظ دفع إدارة قوي درجة، لذلك نموذج إبقاء ذاته قيمة افتراضية. اختياري صحيح كامل عدد `maxTokens` سوف يصبح كل SDK إنشاء agent و ذلك عملية داخل بعد بديل طلب إخراج حد أعلى، حذف وقت فإن تطبيق الذي اختيار مهايئ أو مزود توجيه قيمة افتراضية.JSON-RPC طلب ممكن تزامن قسم إرسال، لذلك في مرة `initialize` نجاح إتمام قبل،`session/prompt` سوف رفض؛ عميل يجب انتظار إمساك يد إتمام بعد مجددا إرسال نص التوجيه. قد قبول نص التوجيه سوف يأخذ واحد بند حمل معرف مستخدم رسالة ترتيب دخول طابور صف، و قيام أي إرجاع `{ messageId }`؛ خادم مع بعد يأخذ كل حمل دائم واقع بصفة `session.event`، يأخذ كامل agent دورة الحياة كل مرة حالة تحويل بصفة `session.status` تدفق صيغة إرسال خروج. هو لن يأخذ بعض بند مساعدة يد رسالة أو `turn/end` ملكية في بعض عدد نص التوجيه، نفس جلسة فوق مستقل طلب يمكن متابعة ترتيب دخول أكثر كثير عمل. حفظ دائم أصل دليل و persona قدوم ذاتي خارج محيط تركيب.

### إغلاق و خروج

إضافة ينبغي جواب `shutdown`، تحديث جديد استجابة و dispose أصل سياق، جعل SDK يحتفظ agent، حجز قراءة و حفظ دائم بلوغ إلى تماما توقف مستقر، لكن بعد بـ 0 خروج.EOF و إشارة خروج عودة app bin مسؤول، بعد من أيضا سوف dispose أصل سياق. فقط إزالة هذا إضافة سوف إيقاف خدمة، لكن لن خروج عملية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خدمة إضافة خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا إضافة هو خفيف كمية عرض مهايئ:[`HarnessSdkJsonRpcServer`](src/server.ts) مسؤول بروتوكول طريقة و إشعار، نقل و أداة اسم بروتوكول نوع قدوم ذاتي `dsh-sdk-protocol`، و عميل SDK مشترك. هو حجز قراءة جلسة،agent و subagent دورة الحياة حدث، و يأخذ هو جمع بصفة بروتوكول إشعار تحويل إرسال؛ فقط لديه عند خدمة في دورة الحياة بناء قيام لقطة وقت سجل `local` علامة سجل لـ true وقت عندئذ تحويل إرسال subagent إتمام حدث——مزود اسم، فرعي درجة id و حفظ دائم جدول نظام متساو لا يستطيع إثبات محلي صفة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema،stdio وصل خط، طلب توزيع، مشترك إغلاق و خروج مهمة |
| [`src/server.ts`](src/server.ts) | `HarnessSdkJsonRpcServer`: بروتوكول طريقة، تدريجي جلسة agent إنشاء، دورة الحياة حجز قراءة، تنظيف |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا عرض مهايئ لا يملك حزمة داخل حمل دائم حدث تدفق؛ حد و إعادة تشغيل اختبار تغطية بروتوكول خريطة. |

### طلب مسار

كل بروتوكول طريقة في تنفيذ قبل كل سوف تحقق إدخال و تحليل مسؤول هذا طلب حالة——`initialize` حفظ SDK توجيه،`session/prompt` تحليل تخزين نشط agent و جلسة إعداد مقابل و ترتيب دخول رسالة،`shutdown` تحديث جديد استجابة، مجددا dispose أصل سياق جعل ذلك بلوغ إلى تماما توقف مستقر، الأكثر بعد بـ 0 خروج——مشترك خروج مهمة تأكيد حفظ تنافس تنازع `shutdown` طلب أبدا سوف تكرار dispose أو خروج. توزيع منطق يقع في [src/index.ts](src/index.ts) و [src/server.ts](src/server.ts).

### تنظيف

`server.shutdown()` فقط dispose خادم ذاته يحتفظ محتوى——فقط إزالة هذا إضافة وقت، خارج محيط سياق إبقاء تشغيل. بروتوكول `shutdown` فإن dispose أصل fiber، جعل حفظ دائم و كامل وقت التشغيل في عملية خروج قبل بلوغ إلى تماما توقف مستقر.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### SDK مستخدم رسالة

#### نموذج يرى ماذا

مقابل في كل قد قبول `session/prompt`، نص و حمل دائم محتوى مرجع سوف أصل مثال دخول واحد بند مستخدم رسالة. داخل ربط `SdkEncodedImageBlock` سوف أولا عبر تركيب في مرفق عنصر تخزين إتمام تحقق و إيداع، لذلك جلسة سجل إبقاء محتوى بحث عنوان صورة مرجع بينما لا هو base64 بايت. هذا حزمة لن إضافة توجيه النظام نص أو أداة schema؛ هذه محتوى قدوم ذاتي تركيب في أخرى إضافة.

#### Token أثر

اعتماد بيانات بينما تحديد مستخدم رسالة token سوف دخول إبقاء جلسة تاريخ، و في لاحق جولة في تكرار إرسال، مباشر حتى آخر عدد حزمة سوف ذلك ضغط (compaction).JSON-RPC لقطة، جلسة إشعار و خادم داخلي سجل لن زيادة نموذج سياق token.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا إضافة أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو و أخرى خدمة طريقة مقابل مقارنة أو مهمة تراكم ضغط.

- **بروتوكول لا يوجد تدريجي جلسة إغلاق أو نص التوجيه إلغاء طريقة**——SDK إنشاء agent سوف واحد مباشر تخزين نشط إلى عملية إغلاق.
- **لا يوجد تدريجي نص التوجيه نتيجة**——`MessageId` فقط معرف inbox دقيق دخول؛ يملك تلقائي تحويل نشط حركة منطقة بين عميل يجب ذاتي سطر تعريف و مراقبة هذا منطقة بين.
- **stdout صاف صاف صفة من نشر حفظ إثبات**——خارج محيط إعداد ما زال ممكن تحميل stdout logger و كسر تالف JSON-RPC عبر طريق؛ هذا إضافة لن فحص أو مرفوض نفس درجة logger.
- **تلقائي تركيب مهايئ فقط دعم حمل DeepSeek**——`initialize` يمكن إعادة استخدام أي مسبق أولا تسجيل نموذج مهايئ، لكن وحيد رجوع سلوك هو تركيب DeepSeek مهايئ.
