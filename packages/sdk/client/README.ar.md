# @deepseek-ai/dsh-sdk-client

[English](README.md) | العربية

## عام وصف

`dsh-sdk-client` يجعل TypeScript برنامج عبر stdio JSON-RPC بدء و قيادة كامل DeepSeek Harness وقت التشغيل. استخدام `DeepSeekHarness` يمكن فتح جلسة، إرسال نص أو رسم مثل نص التوجيه، استلام تجميع حدث و إشعار تدفق، و في وقت التشغيل دخول idle بعد أخذ نيل الأكثر بعد إيداع مساعدة يد استجابة؛ استخدام `HarnessClient` يمكن مباشر إرسال بروتوكول طلب و حجز قراءة إشعار. استدعاء جهة يمكن توفير `dshBin`؛ لا فإن عميل تحليل نفس إصدار `@deepseek-ai/dsh` يمكن تنفيذ ملف. عميل عبر كثير مرة تشغيل يحتفظ عملية فرعية، عام نوع تحويل نقل و بروتوكول خطأ، و في `close()` أو `await using` وقت عودة استلام عملية. هو ملائم لأجل استدعاء جهة قدرة كاف اختيار وقت التشغيل profile و بدء ضبط مشهد.

## استخدام هذه الحزمة

عند TypeScript شفرة حاجة من آخر عملية قيادة كامل Harness وقت التشغيل، كما أنت قدرة صريح إشارة اسم وقت التشغيل يمكن تنفيذ ملف وقت، استخدام هذا عميل. معتاد استخدام مسار أقصى بسيط: استخدام بدء قاعدة إطار بنية صنع `DeepSeekHarness`، تشغيل نص التوجيه، لكن بعد إغلاق هو، جعل عملية فرعية مجموع قدرة يتم عودة استلام.

### استخدام DeepSeekHarness تشغيل agent جولة

```ts
import { DeepSeekHarness } from '@deepseek-ai/dsh-sdk-client'
import { ReasoningEffortId } from '@deepseek-ai/dsh-llm'

await using harness = new DeepSeekHarness({
  profile: 'sdk',
  patches: ['./automation.cordis.yml'],
  provider: 'deepseek-official',
  model: 'deepseek-v4-flash',
  reasoningEffort: ReasoningEffortId('max'),
  maxTokens: 49_152,
})
const result = await harness.run('say hi')
console.log(result.finalResponse)
```

عملية فرعية في أول مرة استخدام وقت كسول صفة بدء، و في كثير مرة `run()` استدعاء بين حمل متابعة عودة نسخة كل؛ طلب استدعاء `close()`(أو استخدام `await using`) ، عملية فرعية عندئذ مجموع قدرة يتم عودة استلام.`start()` سوف تسجيل ذاكرة تحويل محدود `initialize` إمساك يد، منها يتضمن مساحة العمل cwd، مزود/نموذج توجيه، اختياري كما من مهايئ يحتفظ `reasoningEffort`، و اختياري صحيح كامل عدد `maxTokens` إخراج حد أعلى. خادم سوف في قبول نص التوجيه قبل تحقق هذا تأكيد قطع توجيه؛ حذف دفع إدارة قوي درجة وقت إبقاء نموذج ذاته قيمة افتراضية.`initializeTimeoutMs` افتراضي 10 ثانية، تشخيص سوف كتابة واضح الذي اختيار profile و مرفق حمل إبقاء stderr ذيل جزء.`run(input, { sessionId?, onNotification? })` قبول نص أو `SdkPromptContentBlock[]`؛ داخل ربط شبكة إطار رسم مثل كتلة يحمل مواصفة base64 و `mimeType`، و في وقت التشغيل داخل تغيير صار حمل دائم مرفق عنصر. هذا استدعاء يملك واحد نشط حركة منطقة بين: هو سوف نص التوجيه ترتيب دخول طابور صف، انتظار ذلك رسالة id ظهور في حمل دائم دخول طابور عودة تنفيذ في، لكن بعد حمل متابعة استلام تجميع إلى كامل agent تحت مرة دخول `idle`. هو إرجاع `RunResult { sessionId, finalResponse, events, notifications }`، منها `finalResponse` هو هذا منطقة بين داخل أصل جلسة الأكثر بعد إيداع مساعدة يد نص——و غير بسبب نتيجة فوق ملكية في هذا نص التوجيه استجابة، لأن steering(في طريق جذب توجيه) ، حقن سياق و أخرى ترتيب طابور عمل كل ممكن في idle قبل مشاركة و منها.`session(id?)` فتح أداة اسم أو كل جديد جلسة جملة مقبض. إمساك يد فشل كما تنظيف نجاح وقت، نسخة سوف تبديل دخول كل جديد عميل، جعل لاحق استدعاء استخدام جديد عملية إعادة محاولة، مباشر إلى نهاية ربط صفة `close()`؛ إذا ابتدائي تحويل و تنظيف متساو فشل،`start()` سوف إرجاع إبقاء اثنان عدد سبب لديه ترتيب `AggregateError`، و متابعة إبقاء فشل عميل، تجنب تجنب في أصل عملية خروج بعد لم نيل إلى إثبات وقت بدء آخر عدد عملية.`maxTokens` حد كل أصل agent طلب إخراج كمية، و من عملية داخل بعد بديل وراثة؛ ضغط (compaction) إضافة مفرد وحيد يحتفظ ملخص حد أعلى.

### استخدام HarnessClient فعل منخفض طبقة تحكم

`HarnessClient` هو تشغيل API لـ تحت بروتوكول عميل: صريح `start()`،`initialize()`،`prompt()`،`request()` و `close()`، خارج إضافة إشعار حجز قراءة.`prompt()` في وقت التشغيل قبول ترتيب طابور رسالة بعد قيام أي إرجاع هذا رسالة id، أبدا انتظار agent نشط حركة.`subscribe(filter?)` إرجاع `NotificationSubscription`(يمكن انتظار `next()`، غير منع سد `tryNext()`، مختلف خطوة تكرار بديل) ؛`subscribeSessionTree(id)` يأخذ نطاق حد تحديد إلى واحد جلسة و من `subagent.started` دم حافة حافة اكتشاف بعد بديل——وقت التشغيل مقابل سياق داخل كل جلسة كل إرسال إشعار، نطاق حد تحديد في عميل إتمام، و Python SDK تماما متسق.

هذا عميل لـ كل نوع فشل نمط توجيه خروج نوع تحويل خطأ:`JsonRpcResponseError`(بروتوكول خطأ استجابة، إبقاء code و data) ،`RequestTimeoutError`(إعداد وقت حد قد إلى) ،`SdkProtocolError`(استجابة تجاوز خروج وثيقة تحويل بروتوكول) ،`TransportClosedError`(وقت التشغيل قد إزالة فقد——رسالة يحمل خروج رمز و محدود stderr ذيل جزء).`close()` أولا طلب بروتوكول `shutdown`(تلقي `shutdownTimeoutMs` قيد، افتراضي 1000 جزء ثانية) ، لكن بعد مشي stdin-EOF → SIGTERM → SIGKILL مرحلة سلم مباشر إلى عملية خروج؛ قوة انتظار، قد إغلاق عميل رفض إعادة استخدام.`HarnessClientOptions.env` إعطاء تحديد وقت كامل جسم استبدال عملية فرعية بيئة (`undefined` أصل مثال وراثة أب عملية بيئة) ؛ اعتماد سياسة عودة استدعاء جهة——`dsh-subprocess` `scrubbedParentEnv` هو موجه إلى عزل بدء مشترك مسح حذف أساس قاع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير عميل خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

عميل هو نفس بروتوكول فوق اثنان طبقة:`DeepSeekHarness`(ذاتي لديه تشغيل) تراكم إضافة في `HarnessClient`(بروتوكول عميل) لـ فوق، و Python SDK قسم طبقة متسق. هو تشغيل في أي harness سياق خارج، لذلك مباشر spawn وقت التشغيل بينما غير مرور من `dsh-subprocess` خدمة——أي هذا seam سجل SDK حمل إدارة نقل مثال خارج——ذلك إغلاق مرحلة سلم أيضا يقع في هذه الحزمة. وقت التشغيل مقابل سياق داخل كل جلسة كل إرسال إشعار؛ جلسة شجرة نطاق حد تحديد هو عميل مقابل `subagent.started` دم حافة حافة مرور ترشيح.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/api.ts`](src/api.ts) | `DeepSeekHarness` + `HarnessSession`: ذاتي لديه تشغيل، من عودة تنفيذ إلى idle استلام تجميع،`finalResponse` |
| [`src/client.ts`](src/client.ts) | `HarnessClient`:spawn، إمساك يد، طلب، حجز قراءة مروحة خروج، نوع تحويل خطأ |
| [`src/dispose.ts`](src/dispose.ts) | خاص إغلاق مرحلة سلم:stdin EOF → SIGTERM → SIGKILL مباشر إلى حق صحيح خروج |
| [`src/types.ts`](src/types.ts) | بدء و مهلة خيار، إشعار بنية،`RunResult` |
| [`src/index.ts`](src/index.ts) | مستهلك واجهة: اثنان طبقة عميل و موجه إلى استدعاء جهة نوع |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا عميل مكتبة تشغيل في أي harness سياق خارج (ذلك مقابل طرف هو مستقل وقت التشغيل عملية) ؛ وقت التشغيل ذاته حزمة مسؤول صيانة حدث تدفق علاقة. |

### ذاتي لديه نشط حركة مسار

مرة تشغيل سوف حجز قراءة جلسة شجرة، يأخذ نص التوجيه ترتيب دخول طابور صف، انتظار نص التوجيه رسالة id ظهور في حمل دائم `agent/inbox/spliced` عودة تنفيذ في، لكن بعد حمل متابعة استلام تجميع إشعار، مباشر إلى كامل agent تقرير إبلاغ `idle`.`finalResponse` من استلام تجميع إلى حدث في الأكثر بعد واحد بند `assistant/message` إرسال توليد. نقل فقد فقد، مهلة و بروتوكول مخالفة مثال سوف جعل هذا مرة تشغيل يتم رفض؛ نموذج نتيجة ما زال يمكن في حدث تدفق في مراقبة، لكن لن ملكية في بعض واحد إدخال.

### خطأ و إغلاق

كل نوع فشل نمط كل خريطة إلى واحد توجيه خروج خطأ صنف——بروتوكول خطأ استجابة، طلب وقت حد قد إلى، استجابة تجاوز خروج وثيقة تحويل بروتوكول، وقت التشغيل ميت هلاك——استدعاء جهة يمكن حسب فشل نوع فرع معالجة؛ هذا أربعة عدد صنف من [src/index.ts](src/index.ts) توجيه خروج. إغلاق اعتماد خاص قوة انتظار مرحلة سلم (stdin EOF → SIGTERM → SIGKILL) ، يقع في [src/dispose.ts](src/dispose.ts) ، فقط في عملية حق صحيح خروج وقت انتهاء.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا عميل أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو و أخرى SDK عميل مقابل مقارنة أو مهمة تراكم ضغط.

- **بلا ربط ربط وقت التشغيل تحليل**——عميل تحليل نفس إصدار `@deepseek-ai/dsh` حزمة (أو استدعاء جهة توفير `dshBin`) ؛ تحزيم يمكن تنفيذ ملف اكتشاف إبقاء في Python جانب، مباشر إلى ظهور TypeScript إرسال سطر إصدار مستهلك.
- **بلا جولة في إلغاء**——بروتوكول طبقة لا يوجد نص التوجيه إلغاء طريقة؛ وضع ترك جولة معنى طعم حال إغلاق وقت التشغيل (رؤية[بروتوكول حد](../protocol/README.ar.md#known-limitations-and-deferred-work)).
- **لا يوجد تدريجي نص التوجيه نتيجة**——منخفض طبقة `prompt()` فقط إرجاع دخول طابور عودة تنفيذ؛ عال طبقة `run()` مسؤول من عودة تنفيذ إلى idle استلام تجميع، وضع ترك هذا مرور مسار معنى طعم حال إغلاق وقت التشغيل.
- **عميل→خدمة طرف إشعار و خدمة طرف→عميل طلب**في بروتوكول اثنان طرف كل لم تنفيذ؛ نقل طبقة لـ لم قدوم مراجعة دفعة مسار إبقاء تحمل تحميل قدرة.
