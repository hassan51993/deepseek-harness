# @deepseek-ai/dsh-tmux-context

[English](README.md) | العربية

## عام وصف

`dsh-tmux-context` يجعل نموذج تعرف آخر ذلك agent عملية الذي في tmux جلسة،window،pane و pane شجرة تخطيط. هو فقط في موضع حدوث تغير وقت، في كل جولة رقم واحد خطوة إلحاق واحد بند حمل دائم، حمل مصدر قراءة عدد. إذا طرفية فقط وراثة tmux بيئة متغير، لكن و لم في الذي إشارة اسم pane في تشغيل، فإن لا إضافة أي محتوى؛ استعلام فشل نفس مثال لا إضافة محتوى، أيضا لن جعل هذا جولة فشل. هذه الحزمة يحتاج رئيسي حركة تفعيل، كما لا يتضمن في مع مرفق Web أو بلا رأس profile في.

## استخدام هذه الحزمة

عند agent عملية تشغيل في tmux داخل، كما نموذج حاجة معرفة طريق ذلك window و pane موضع وقت، تركيب هذا إضافة. كل بند قراءة عدد كل هو حمل دائم تاريخ في مقدار خارج واحد بند user زاوية لون رسالة؛ موضع لم تغير وقت لا إضافة أي محتوى، لذلك طويل وقت جلسة تراكم تراكم جدا قليل.

### نموذج قدرة نيل إلى ماذا

في tmux حالة حدوث تغير كل واحد جولة، نموذج سوف استلام إلى واحد بند حمل مصدر علامة سياق رسالة، يتضمن جلسة اسم،window بحث جذب و اسم،pane بحث جذب و id، نشط حركة علامة سجل، و ضيق تجميع pane شجرة تخطيط. قراءة عدد فقط حدوث في كل جولة رقم واحد خطوة؛ جولة في طريق نقل حركة أو تقليص وضع pane سوف في تحت واحد جولة عكس عكس. مثل عنصر مقياس قياس متعمد حذف، متبادل مجاور pane مرئي محتوى من لا أخذ تجميع.

### إعداد

الأكثر صغير تركيب بلا حاجة أي إعداد.`refreshIntervalMs` لـ صحيح قيمة وقت، سوف مقدار خارج كبح صنع مسافة الأكثر قريب مرة حقن لا كاف هذا مللي ثانية عدد حقن؛ حذف أو ضبط لـ `0` وقت، فقط يلزم tmux حالة ذاتي فوق مرة حقن بـ قدوم حدوث تغير حينئذ حقن.

```yaml
- name: '@deepseek-ai/dsh-tmux-context'
  config:
    refreshIntervalMs: 60000
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `refreshIntervalMs` | `0`(كل تغير جولة) | نفس جلسة في اثنان مرة حمل دائم حقن بين الأكثر صغير مللي ثانية عدد |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tmux-context) هو كل تلقي دعم حمل حقل و ذلك JSDoc كامل حق مصدر.

### أي وقت معرفة طريق موضع

فقط لديه عند عملية تحكم طرفية و pane `#{pane_tty}` متسق وقت، عندئذ نظر لـ يقع في tmux في؛ من tmux shell بدء طرفية (VS Code تجميع صار طرفية، طاولة وجه بدء جهاز) سوف وراثة متغير لكن لا في pane داخل، لذلك يتم نظر لـ لا في tmux في.`ctx.shell` ناقص، بيئة متغير لا وجود أو قراءة عدد صيغة غير قاعدة وقت هو فارغ عملية؛ منفذ رفض سوف يتم التقاط إقامة و سجل لـ تحذير إبلاغ، بينما لن جعل هذا جولة فشل.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير إضافة تصميم؛ يمكن مراقبة سلوك رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

إضافة قبل وضع تسجيل واحد `agent/pre-step` مستمع، فقط في كل جولة رقم واحد خطوة تشغيل. حاجة حقن وقت، هو عبر `ctx.shell` منفذ خدمة تشغيل واحد بند فقط قراءة أمر——نشر جهة صندوق رملي و سياسة كل سوف تطبيق، إضافة لا يملك أي عملية فرعية شفرة. أمر في إخراج صنع جدول رمز قسم فصل حقل قبل، سوف مقارنة مقارنة `$TMUX_PANE` `#{pane_tty}` و هذا عملية ذاته تحكم طرفية، لذلك وراثة بيئة سوف يتم نظر لـ لا في tmux في. إضافة فقط في تصيير خروج حالة و فوق مرة حقن مختلف وقت إعادة حقن.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: رقم واحد خطوة مستمع،shell استعلام، تغير كبح صنع، ضبط درجة |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ كل مرة قراءة كل هو خارجي tmux حالة مفرد جولة لقطة، جلسة لا يوجد يمكن فحص عبر حدث علاقة؛ ضبط درجة و صيغة من خط الإنتاج اختبار مسؤول. |

### رئيسي يلزم مسار

في كل جولة رقم واحد خطوة، مستمع فحص حقن هل إلى مدة، عبر `ctx.shell` استعلام موضع، و يأخذ تصيير حالة و هذا مصدر الأكثر قريب مرة حمل دائم حقن مقارنة مقارنة. تغير كبح صنع و بين فصل ضبط درجة سوف مسح أصلي حمل دائم جلسة حدث، لذلك ضبط درجة يمكن عبر ضغط (compaction) و استعادة عملية تخزين متابعة، بلا حاجة عملية داخل ذاكرة مؤقتة حالة؛ كل جلسة مستقل ضبط درجة. تحت تنقل في خطوة قبل تشغيل مستمع رفض أو فشل وقت، هذا قراءة عدد لن يتم سجل.

<a id="model-experience"></a>
## تجربة النموذج

### دقيق تجهيز مدة tmux موضع

#### نموذج يرى محتوى

في tmux حالة حدوث تغير كل واحد جولة، حقن واحد بند حمل مصدر علامة، يحتوي التالي ثلاثة سطر سياق رسالة.`<window-layout>` هو tmux ضيق تجميع pane شجرة وصف؛pane و window مثل عنصر مقياس قياس متعمد حذف، متبادل مجاور pane محتوى من لا أخذ تجميع.

##### تغير جولة قراءة عدد

```markdown
tmux location (turn <turn>):
session <session>, window <index> "<name>", pane <index> <pane-id>
window active=<0|1>, pane active=<0|1>, layout <window-layout>
```

#### Token أثر

كل بند ثلاثة سطر قراءة عدد سوف تراكم تراكم، مباشر إلى ضغط سوف ذلك حجب حجب. موضع لم تغير و بين فصل كبح صنع لن إضافة جديدة محتوى.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قد لديه KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح tmux موضع سياق أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد.

- **فقط رقم واحد خطوة**——جولة في طريق نقل حركة أو تقليص وضع pane سوف في تحت واحد جولة عكس عكس، بينما غير في خطوة بين.
- **فقط ذاته موضع**——إضافة من لا أخذ تجميع متبادل مجاور pane مرئي نص.
- **فقط لديه تخطيط، لا يوجد مقياس قياس**——حذف pane/window مثل عنصر مقياس قياس؛ فقط تقرير إبلاغ تخطيط شجرة و نشط حركة علامة سجل.
- **صنع جدول رمز قسم فصل حقل**——إذا tmux window اسم يتضمن حرف وجه اثنان محرف تسلسل `\t`، سوف جعل قراءة عدد قسم قطع خطأ و بصفة غير قاعدة قراءة عدد قفز مرور؛ معتاد قاعدة اسم لا تلقي أثر.
- **أساس في tty pane حكم تحديد**——فقط لديه عند عملية تحكم طرفية و `$TMUX_PANE` `#{pane_tty}` متسق وقت، عندئذ نظر لـ «يقع في tmux في». هذا سوف متعمد ترتيب حذف من tmux أصل أولا عملية وراثة `$TMUX`/`$TMUX_PANE` طرفية (مثل VS Code تجميع صار طرفية).`ps -o tty=` يخص POSIX؛ في ذلك أو `#{pane_tty}` غير ممكن استخدام بيئة في، هذا فحص أي لـ فارغ عملية.
