# @deepseek-ai/dsh-session-reference

[English](README.md) | العربية

## عام وصف

`dsh-session-reference` يجعل مرة محادثة يمكن مرجع أخرى جلسة: مضيف يأخذ `@label` mention تحويل لـ مواصفة URI، خدمة فإن لـ نموذج دقيق تجهيز كل يتم مرجع جلسة محدود، فقط قراءة لقطة، بصفة حمل دائم، لا تلقي معلومة مهمة خلف مشهد سياق. مرشح اكتشاف حسب عمل دليل قريب و درجة مقابل أخرى جلسة ترتيب ترتيب، و استخدام ذلك الأكثر جديد عنوان عمل وسم. لقطة في التقاط بعد غير ممكن تغيير، و حمل لديه ثابت تحذير إبلاغ، منع توقف التزام دوران منها إشارة أمر، إذن إعلان أو أداة طلب. هو هو موجه إلى دعم حمل عبر جلسة mention مضيف اختياري خدمة؛ هو إزالة استهلاك `ctx.sessionQuery`، لا حاجة SQLite FTS.

## استخدام هذه الحزمة

عند مضيف ينبغي سماح مستخدم رفع و آخر عدد جلسة و يأخذ ذلك سياق تسليم إعطاء نموذج وقت، تفعيل هذا خدمة. من في هو إزالة استهلاك خلفية غير متصل compact فحص نقطة علامة، أي session-query خلفية كل يمكن إعداد دمج استخدام.

### mention لغة قاعدة

مواصفة mention هو Markdown شكل صيغة `@[label](dsh-session:<base64url تحرير رمز id>)`، أو عار `dsh-session:` URI؛ كل JavaScript نص جلسة id كل قدرة دقيق نحو إرجاع. خدمة سوف يأخذ mention تعديل كتابة لـ رسالة في يمكن قراءة `@label` نص، و إرجاع بنية تحويل مرجع. صريح Markdown mention سوف رفض صيغة خطأ URI؛ فارغ أو فقط يحتوي علامة نقطة رمز رقم scheme mention ما زال هو عادي نقاش نقاش نص.

### agent(ذكي جسم) قدرة نيل إلى ماذا

مرجع أخرى جلسة رسالة بعد سوف ضيق وصل واحد بند `## Referenced sessions` لقطة، بصفة ثاني بند user زاوية لون رسالة. لقطة هو لا تلقي معلومة مهمة خلف مشهد: ثابت تحذير إبلاغ إبلاغ إبلاغ نموذج، حذف غير حالي مستخدم واضح تكرار، لا فإن لا نيل التزام دوران منها إشارة أمر، إذن إعلان أو أداة طلب. كل مصدر معاينة كل مستقل محدود——كل بند رسالة حتى كثير `maxReferences` عدد مختلف جلسة، كل مصدر تسلسل تحويل JSON اعتماد إعداد قيمة أو نموذج متبادل مقابل بايت ميزانية. إبقاء سياسة أولا إسقاط مقارنة مبكر غير فحص نقطة رسالة، مجددا تقليص قصير إبقاء نص؛ فقط لديه إبقاء معالجة بعد مرجع ما زال لا يمكن ممتلئ كاف ميزانية وقت، دقيق تجهيز عندئذ سوف فشل.

مرجع يتم قطع قطع وقت، اختياري spill خلفية سوف في هدف جلسة تحت حفظ كامل قد التقاط نص إسقاط. محدود معاينة JSON خارج مستقل حذف إشعار إعطاء خروج دقيق `omittedMessages` و `omittedBytes`، و حفظ بعد تحديد موضع معلومة و `retrievalHint`، أو منطقة قسم لم إعداد تخزين و حفظ فشل غير ممكن استخدام نتيجة. هذا إشعار يخص نفس بند حمل دائم سياق رسالة. كامل transcript(نص سجل) يحمل نفسه لا تلقي معلومة مهمة خلف مشهد تحذير إبلاغ و التقاط بيانات وصفية، يشمل `capturedFormatVersion`. كل بند رسالة استخدام كل سطر حتى كثير 64 عدد Unicode رمز نقطة JSON نص قطعة مقطع؛ حل رمز و تجميع وصل ذلك قطعة مقطع يكفي استعادة دقيق نص، يشمل أصلي تبديل سطر. هذا نوع ثابت تخزين صيغة جعل جدا طويل مفرد سطر نص أيضا يمكن عبر قسم صفحة ملف قراءة قدوم فحص.

### فحص بحث يمكن مرجع جلسة

`listCandidates(agent, query?, limit?)` صف خروج حذف agent ذاته خارج جلسة، حسب id، عمل دليل، إسقاط عنوان أو عرض عنوان فعل لا منطقة قسم كبير صغير كتابة مرور ترشيح، و يأخذ نفس دليل جلسة ترتيب في قبل وجه. كل مرشح `label` استخدام الأكثر جديد عنوان؛ عنوان ناقص أو غير ممكن قراءة وقت رجوع إلى جلسة id. عرض عنوان أولوية استخدام subagent حمل دائم إنشاء label، مجددا رجوع إلى هذا عنوان. مرشح أيضا سوف تقرير إبلاغ ذلك عمل دليل هل حينئذ هو إرسال بدء جهة agent عمل دليل، مضيف لذلك يمكن فقط في موضع قدرة منطقة قسم هذا سطر وقت عندئذ عرض هو. متصفح مستهلك عبر `ctx.remote.sessionReferenceResolver.candidates` استدعاء نفس اكتشاف قدرة؛ هذا طريقة في `displayTitle` وجود وقت استخدام هو علامة مواصفة mention.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxReferences` | `3` | واحد بند قد دقيق تجهيز رسالة في مختلف مصدر جلسة الأكثر كبير عدد كمية؛ لا نيل تجاوز مرور `3` |
| `candidateLimit` | `50` | إرجاع إعطاء مضيف افتراضي مرشح عدد كمية |
| `maxReferenceBytes` | تلقائي | كل مصدر الأكثر كبير تسلسل تحويل JSON بايت عدد؛ صريح ضبط وقت دقيق تغطية تلقائي ميزانية |
| `referenceContextFraction` | `0.2` | كل مصدر سياق نافذة مقارنة مثال، نطاق لـ `0` إلى `1` |

تلقائي ميزانية لـ كل مصدر `max(65536, floor(contextWindow × 4 × referenceContextFraction))` بايت. نموذج سياق سعة كمية بـ token حساب كمية؛ كل token أربعة بايت هو سعة كمية تقدير حساب، لا هو دقيق token تبديل حساب. نقص قليل توجيه،LLM(كبير لغة نموذج) خدمة، مهايئ أو سعة كمية وقت استخدام 64 KiB؛ أخرى نموذج بيانات وصفية استعلام خطأ و إلغاء سوف جعل دقيق تجهيز فشل.

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-session-reference) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خدمة تصميم؛ يمكن مراقبة سلوك رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

دقيق تجهيز مرحلة مقطع في هدف رسالة وصول `agent/pre-step` وقت، مقابل كل يتم مرجع جلسة حالي جدول طبقة كل دقيق قراءة مرة. معاينة و spill استخدام نفس نسخة قد التقاط إسقاط: مستخدم مباشر إرسال نص،assistant نص، و يحمل مواصفة ضغط (compaction) علامة user فحص نقطة؛ أداة، دفع إدارة (reasoning) و أخرى حقن سياق متساو يتم ترتيب حذف. هذا حيث منع توقف مرجع تمرير عودة نقل بث، أيضا منع توقف مصدر جلسة لاحق تغيير أثر قد حفظ transcript. معاينة JSON سوف كل `<` تحويل معنى لـ `\u003c`، لذلك مصدر نص لا يمكن تجميع خروج `<referenced-sessions>` تحديد حد وسم.

محلل عبر `ctx.get("spillStore")` نيل أخذ اختياري تخزين، فقط حفظ يتم قطع قطع مرجع. تخزين عودة هدف جلسة كل؛ مصدر معلومة معرف يتم مرجع مصدر جلسة و وسم، لا زائف صنع أداة استدعاء. مختلف خطوة حفظ بعد سوف فحص إلغاء، أي جعل ناتج قد كتابة، أيضا سوف منع توقف إصدار. ناتج مرور مدة ما زال التزام دوران خلفية قائم سياسة.

ميزانية استخدام هدف agent `system-prompt/assemble` إتمام بعد التقاط مزود و نموذج. أول مرة تجميع قبل مباشر استدعاء `prepare` وقت استخدام agent خيار؛ جلسة رأس لا قرار ميزانية نموذج. لا حمل agent تشخيص تجميع لن أثر قد التقاط توجيه.

### رئيسي يلزم مسار

خارج طبقة `agent/pre-step` مستمع قبول خطوة، من مباشر مستخدم رسالة في تحليل مواصفة mention، مجددا استدعاء `prepare`: مواصفة تحويل مرجع (إبقاء أول مرة mention ترتيب، ذهاب إعادة، رفض ذاتي مرجع و تجاوز حد عدد كمية) ، و سطر قراءة كل جدول طبقة، في تحليل خروج بايت ميزانية تحت تدريجي مصدر إبقاء، و تصيير تجمع دمج نص التوجيه. كل بند حمل دائم مصدر سجل إبقاء تجميد ربط `capturedThroughSeq` و سجل غير صفر `capturedFormatVersion`؛ حقل ناقص يمثل صيغة v0. كل نسخة لقطة كل إدراج دخول إلى مرجع هو رسالة ضيق بعد، هدف سجل أولا سجل يمكن قراءة مباشر رسالة، مجددا سجل ذلك حمل مصدر سياق، لذلك التقاط بعد مصدر تغيير لا يمكن تغيير هدف إعادة تشغيل.

<a id="model-experience"></a>
## تجربة النموذج

### مرجع جلسة خلف مشهد

#### نموذج يرى محتوى

نموذج سوف يرى اثنان بند وصل متابعة user زاوية لون رسالة: أولا هو حمل يمكن قراءة `@label` حالي رسالة، مجددا هو `## Referenced sessions` لا تلقي معلومة مهمة لقطة. تحذير إبلاغ منع توقف التزام دوران لقطة في إشارة أمر، إذن إعلان أو أداة طلب، حذف غير حالي مستخدم واضح تكرار هذه محتوى. وسم،cwd قيمة،id و جلسة نص سوف بصفة JSON في `<referenced-sessions>` وسم في تسلسل تحويل؛ بيانات في كل `<` كل سوف بـ بلا ضرر JSON تحويل معنى `\u003c` شكل صيغة إرسال خروج، لذلك مصدر نص لا يمكن تجميع خروج تحديد حد وسم.

#### Token أثر

كل بند يتضمن مرجع رسالة كل سوف إضافة ثابت تحذير إبلاغ و الأكثر كثير ثلاثة عدد تسلسل تحويل معاينة، كل معاينة كل تلقي إعداد قيمة أو نموذج متبادل مقابل بايت ميزانية مستقل حد. يتم قطع قطع مرجع سوف في هذا ميزانية خارج إضافة مستقل حذف إشعار؛ قد حفظ كامل transcript فقط لديه في يتم أخذ عودة وقت عندئذ زيادة token. دقيق سياق سوف إبقاء في هدف تاريخ في، مباشر إلى هدف ضغط حجب حجب أو ملخص هو؛ مصدر جلسة تغيير لن إضافة أكثر كثير token.

#### KV Cache أثر

طلب و لقطة هو اثنان بند وصل متابعة، فقط إلحاق هدف رسالة، و إبقاء مقارنة مبكر يمكن ذاكرة مؤقتة تاريخ. مختلف مرجع أو مصدر التقاط محتوى فقط تغيير جديد بعد لاحقة؛ لاحق هدف ضغط ممكن جعل من استبدال حد بدء إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح عبر جلسة مرجع أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد.

- **لا دعم حمل رسالة متن فحص بحث**: مرشح استعلام سوف فحص عنوان، لكن لا بحث رسالة رئيسي جسم.
- **وسم فقط قدوم ذاتي إسقاط**: قد تركيب جلسة وسم قدوم ذاتي فوري إسقاط قطع وجه، بارد جلسة وسم قدوم ذاتي حمل دائم فحص نقطة؛ إذا جلسة لا يمكن توفير هذا اثنان من، فإن بـ ذلك id بصفة وسم، أيضا لا يمكن حسب عنوان بحث إلى. اكتشاف مرور مسار أبدا قراءة سجل: طي خروج واحد عنوان حاجة معالجة كامل نسخة سجل، بينما هذا مقطع شفرة سوف في كل مرة تكملة كل ضرب مفتاح وقت تشغيل. في إسقاط ذاكرة مؤقتة بناء قيام قبل حفظ دائم جلسة، سوف في أول مرة فتح وقت استعادة عنوان و كتابة فحص نقطة.
- **تلقي معلومة مهمة استدعاء جهة حد**: هذا خدمة زائف ضبط مضيف لديه حق قراءة `ctx.sessionQuery` عام كل جلسة؛ هو لا هو موجه إلى نموذج بحث أداة.
- **فقط إسقاط نص**: لن في جلسة بين نقل بث غير نص user و assistant كتلة.
- **لا يوجد فوري رابط**: مرجع هو لقطة، لا هو fork، استعادة، حجز قراءة أو مصدر جلسة تغيير.
- **transcript بحث حسب سطر إجراء**: حرف وجه قصير لغة ممكن عبر تجاوز JSON قطعة مقطع سطر أو يتضمن تحويل معنى محرف؛ دقيق نص مطابقة يحتاج أولا حل رمز و تجميع وصل رسالة قطعة مقطع. قد حفظ ناتج ممكن حسب خلفية سياسة مرور مدة.
