# @deepseek-ai/dsh-file-reference-local

[English](README.md) | العربية

## عام وصف

agent(ذكي جسم) و مضيف UI يمكن استخدام كل agent محلي مساحة العمل في مرور مرور ترتيب مسار تكملة كل `@file` mention؛ محدود اكتشاف يجعل كبير نوع مستودع أيضا قدرة إبقاء استجابة سريع سرعة. نتيجة سوف في أداة نشط حركة بعد تحديث جديد كما لن منع سد تكملة كل، و كما بداية نهاية لن تتبع مع دليل رمز رقم رابط. عند `read` متاح وقت، نموذج أيضا سوف استلام إلى صلة في مثل أي إدارة حل مرجع مسار مستقر إشارة جذب. عند `read` استخدام Harness مضيف نظام الملفات وقت اختيار هذه الحزمة؛ بعيد مسار أو وهمي محاكاة نطاق الأسماء حاجة و لـ مطابقة اكتشاف قدرة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند `@file` تكملة كل ينبغي اكتشاف Harness مضيف ذاته نظام الملفات——أي مع مرفق `read` أداة الذي عملية نطاق الأسماء——وقت، تركيب هذا مزود. كل agent مساحة العمل من هذا جلسة عمل دليل بدء بناء قيام بحث جذب؛ جلسة لا يوجد عمل دليل وقت رجوع إلى مضيف عملية دليل.

### تفعيل مزود

افتراضي ضبط ملائم دمج قاموس نوع مساحة العمل، لذلك الأكثر صغير تركيب بلا حاجة أي إعداد:

```yaml
- name: '@deepseek-ai/dsh-file-reference-local'
  config:
    maxResults: 20
```

### أنت قدرة نيل إلى ماذا

في مضيف UI في إدخال `@` سوف لـ إشارة تحديد agent إرجاع حتى كثير `maxResults` عدد ترتيب مسار مرشح. يتضمن `/` استعلام مباشر صف خروج مطابقة دليل بند؛ عار استعلام مقابل محدود تمرير عودة بحث جذب فعل نموذج غامض ترتيب. دليل مرشح بـ ذيل مائل عمود إبقاء mention فتح وضع. أي أداة نتيجة بعد، هذا agent بحث جذب سوف يتم علامة لـ قديم قديم: تحت مرة استعلام ما زال من هو عمل جواب، ذلك بديل صنف في خلفية بناء، لذلك إعادة بناء لن حجب في ضوء علامة قبل وجه.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxResults` | `20` | مفرد مرة استعلام إرجاع ترتيب مرشح الأكثر كبير عدد كمية |
| `maxEntries` | `50000` | كل agent مساحة العمل بناء قيام بحث جذب ملف و دليل الأكثر كبير عدد كمية |
| `excludedDirectories` | `['.git', 'node_modules', 'dist', 'build', 'out', 'coverage', 'target', '.next', '.nuxt', '.turbo', '.venv', '__pycache__', '.pytest_cache', '.mypy_cache', '.gradle']` | مرة تاريخ و مرشح في ترتيب حذف دليل أساس اسم |

كل عدد قيمة كل يجب هو صحيح أمان كامل عدد، كل ترتيب حذف اسم كل يجب هو لا يحتوي `/` أو `\` غير فارغ أساس اسم.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مزود تصميم؛ يمكن مراقبة سلوك رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

مزود لـ كل agent صيانة واحد يمكن إعادة استخدام `WorkspaceFileSearch`، بـ هذا جلسة `cwd` لـ أصل. دليل نطاق استعلام (`a/b/...`) صف خروج فوري دليل حالة، عار نموذج غامض استعلام مشترك مرة محدود تمرير عودة مرة تاريخ. كل مساحة العمل فقط أول مرة عار استعلام سوف انتظار هذا مرة تاريخ؛`tool/result` حدث يأخذ اكتمل بند علامة لـ قديم قديم، تحت مرة عار استعلام في بديل صنف بناء خلال متابعة من هو عمل جواب. نموذج إشارة جذب هو حسب agent نص التوجيه مقطع، فقط في إشارة تحديد agent يملك `read` أداة وقت مساهمة؛ إنشاء سوف انتظار نص التوجيه تثبيت، تثبيت فشل سوف تراجع agent؛agent dispose(مورد تحرير) وقت سوف معا تحرير بحث جذب و نص التوجيه fiber.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | `LocalFileReferenceService`: إعداد تحقق، حسب agent بحث، نص التوجيه تثبيت |
| [`src/search.ts`](src/search.ts) | `WorkspaceFileSearch`: مرة تاريخ، ترتيب، ترتيب حذف، قديم قديم علامة و خلفية إعادة بناء |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ حسب agent index هو خاص advisory cache، ذلك بطلان و dispose سلوك عبر خدمة اختبار مباشر مراقبة. |

### رئيسي يلزم مسار

`list(agent, query, signal)` يلزم ما صف خروج بعض عدد دليل بند، يلزم ما قراءة مشترك محدود بحث جذب، مقابل مرشح ترتيب (دقيق، بادئة، فرعي سلسلة، مجددا إلى فرعي تسلسل نيل قسم، دليل لديه إضافة صار) ، و حسب تحديد صفة ترتيب إرجاع حتى كثير `maxResults` عدد.`tool/result` حدث يأخذ إشارة تحديد agent بحث جذب علامة لـ قديم قديم؛ تحت مرة عار استعلام ما زال من قديم بحث جذب إرجاع نتيجة، معا في خلفية بناء بديل بحث جذب. غير ممكن قراءة أو قد ترتيب حذف فرعي دليل لا مساهمة مرشح، بينما غير ممكن قراءة أصل دليل فإن يجعل هذا مرة مرة تاريخ فشل: مرة لحظة وقت لذا عائق لا نيل استخدام فارغ بحث جذب تغطية ما زال صالح بند.

<a id="model-experience"></a>
## تجربة النموذج

### `read` متاح وقت ملف مرجع إشارة جذب

#### نموذج يرى محتوى

عند إشارة تحديد agent لديه فعلي توليد فاعلية `read` أداة وقت، مزود سوف مساهمة التالي مستقر توجيه النظام مقطع:

##### ملف مرجع إشارة أمر

```markdown
Tokens prefixed with @ are workspace paths the user explicitly referenced, relative to the workspace root. A trailing slash marks a directory: list it when its contents matter. Anything else is a file: use the read tool when its contents are needed, and do not claim to have inspected it before reading. @"..." quotes a path containing spaces.
```

#### Token أثر

هذا أثر لديه شرط كما ثابت: فقط يلزم `read` مقابل إشارة تحديد agent مرئي، هذا واحد جملة حينئذ سوف وجود؛ مرشح استعلام ذاته لا زيادة token، الذي اختيار مسار فقط سوف مساهمة عادي مستخدم رسالة في مقابل محرف.

#### KV Cache أثر

هذا مستقر جملة فرعي سوف إضافة دخول توجيه النظام بادئة. تركيب أو إزالة هذا مزود، أو من تغيير `read` هل مرئي، كل سوف تغيير هذا بادئة؛ استعلام، مرشح بند و بحث جذب قديم قديم علامة لن تغيير بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد.

- **مضيف محلي نطاق الأسماء**: مزود مسح Harness مضيف نظام الملفات، لذلك بعيد مسار أو وهمي محاكاة `read` تنفيذ حاجة استخدام نطاق الأسماء و هذا أداة متسق مزود.
- **محدود تلميح صفة بحث جذب**: تجاوز كبير نوع مساحة العمل ممكن حذف `maxEntries` بعد مسار؛ يتم ترتيب حذف أو لا يمكن قراءة دليل لن ظهور. افتراضي ترتيب حذف بند فقط صف لا يوجد أي توليد حالة استخدام عمل شفرة المصدر دليل بناء ناتج؛`lib` يتم لحظة معنى ترتيب حذف في خارج، لذلك بناء دخول `lib` مساحة العمل يحتاج عبر `excludedDirectories` ذاتي سطر إضافة فوق.
- **مرة بطلان قديم قديم نافذة**: ضيق وصل أداة نتيجة بعد عار استعلام عكس عكس هو فوق مرة مرة تاريخ وقت دليل شجرة؛ تحت مرة استعلام عندئذ يرى إعادة بناء نتيجة.
- **لا يوجد تجاهل اختصار ملف دلالة**:`.gitignore` و أخرى مشروع تجاهل اختصار ملف لن أثر اكتشاف؛ نظام فقط ترتيب حذف قد إعداد دليل أساس اسم.
