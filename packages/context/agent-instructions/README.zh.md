# @deepseek-ai/dsh-agent-instructions

[English](README.md) | العربية

## عام وصف

`dsh-agent-instructions` نحو agent(ذكي جسم) توفير قدوم ذاتي مستخدم عام ملف و مشروع درجة ملف مساحة العمل إشارة جذب؛ هذه ملف متساو و `AGENTS.md` توافق. هو لـ رقم مرة طلب تحميل ملائم استخدام إشارة أمر سلسلة. هو لن حمل متابعة مراقبة نظر خارجي تحرير: نجاح نظام الملفات عملية سوف اكتشاف جديد ملائم استخدام تضمين طقم ملف، و يجعل لاحق تغيير أو إزالة مرئي؛ استعادة جلسة أيضا سوف مقابل حساب أساس خط.`dsh-base` افتراضي تفعيل هذا سلوك،profile يمكن منع استخدام. بايت ميزانية حد حقن سياق: مقارنة عرض عام ملف أولا يتم حذف، الأكثر أداة جسم ملف الأكثر بعد يتم قطع قطع، فارغ إشارة أمر سلسلة لا إضافة أي محتوى.

## استخدام هذه الحزمة

عند agent حاجة اعتماد حسب مساحة العمل ذاته إشارة أمر ملف عمل وقت، تركيب هذا إضافة.`dsh-base` قد يتضمن هو و إعطاء إعطاء 65,536 بايت ميزانية، لذلك أساس في base profile فقط في حاجة أخرى `maxBytes` وقت استبدال هذا إعداد سطر؛ لا يوجد نظام الملفات مزود شجرة تحميل لا إلى أي محتوى، مباشر إلى مزود ظهور.

### agent نيل نيل محتوى

رقم مرة طلب يتضمن واحد بند حمل دائم أساس خط رسالة: أولا هو مستخدم عام `$DSH_HOME/AGENTS.md`، مجددا حسب من عرض عام إلى أداة جسم ترتيب يتضمن مشروع إشارة أمر سلسلة——من مشروع أصل دليل إلى جلسة عمل دليل كل دليل في كل قائم مرشح ملف. ذهاب حذف أول ذيل فارغ أبيض بعد محتوى متسق نفس درجة ملف فقط تصيير مرة، لذلك نسخ `AGENTS.md` `CLAUDE.md` لن يتم تكرار تحميل. عند نجاح `read`،`write` أو `edit` استدعاء وصول أكثر عميق دليل بعد، تحت مرة طلب سوف يتضمن جديد ملائم استخدام إشارة أمر ملف؛ قد تغيير ملف سوف استبدال ذلك محتوى، إزالة فقد أو يصبح مقارنة مبكر مرشح ملف تكرار بند ملف سوف إنتاج إزالة إشعار.

### إعداد

افتراضي ضبط ملائم دمج قاموس نوع فحص خروج:`.git` علامة مشروع أصل دليل،`AGENTS.md` و `CLAUDE.md` هو أساس أساس مرشح،`AGENTS.local.md` و `CLAUDE.local.md` هو تراكم إضافة محلي overlay. فقط لديه `maxBytes` لا بد ملء——هو حد كامل تصيير بعد أساس خط، يجعل كل نشر صريح اختيار ذاتي ذات نص التوجيه ميزانية.

فقط لديه تأكيد مشروع أصل علامة لا وجود وقت، مشروع أصل اكتشاف عندئذ سوف متابعة فوق تتبع. إذن أو I/O فشل سوف إيقاف اكتشاف، و رمي خروج مضيف أو نظام الملفات مزود أصلي خطأ، بينما لن اختيار أصل أولا مشروع.[أصل علامة بيانات وصفية قرار](../../../.agents/notes/implemented/bug-fix/2026-09-03-root-marker-metadata-failures.zh.md) شرح اكتشاف لـ أي يجب فشل، بينما لا يستطيع استبدال لـ أخرى أصل دليل.

```yaml
- name: '@deepseek-ai/dsh-agent-instructions'
  config:
    maxBytes: 65536
```

تلقي دعم حمل حقل واحد تصفح:

```ts
export interface Config {
  dshHome?: string
  projectRootMarkers?: string[]
  maxBytes: number
  maxSourceBytes?: number
  instructionFileCandidates?: string[]
  localInstructionFileCandidates?: string[]
}
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxBytes` | لا بد ملء | كامل تصيير أساس خط رسالة حد أعلى، مفرد موضع لـ بايت |
| `maxSourceBytes` | `1048576` | تصيير قبل مفرد عدد مصدر إشارة أمر ملف حد أعلى |
| `projectRootMarkers` | `['.git']` | علامة مشروع أصل دليل دليل اسم |
| `instructionFileCandidates` | `['AGENTS.md', 'CLAUDE.md']` | كل مشروع دليل في تحميل أساس أساس ملف اسم |
| `localInstructionFileCandidates` | `['AGENTS.local.md', 'CLAUDE.local.md']` | في أساس أساس ملف بعد تحميل محلي overlay ملف اسم |
| `dshHome` | `$DSH_HOME` أو `~/.dsh` | تخزين وضع مستخدم عام `AGENTS.md` دليل |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-agent-instructions) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### مراقبة ميزانية

تصيير سوف أولوية إبقاء الأكثر أداة جسم ملف: أولا إسقاط كامل مقارنة عرض عام ملف، مجددا قطع قطع الأكثر أداة جسم ملف، تزامن خروج مرئي `Workspace instruction budget ...` إشعار، إشارة اسم يتم حذف و يتم قطع قطع مسار. تصيير بعد بايت عدد أبدا تجاوز مرور `maxBytes`. تجاوز خروج ميزانية عرض عام ملف سوف يتم تجاهل اختصار؛ تحديث جديد خلال هو يتم نظر لـ مؤقت وقت غير ممكن استخدام، بينما غير يتم إزالة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير إضافة خلف بعد تصميم قرار؛ يمكن مراقبة سلوك رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

هذا إضافة بناء قيام في واحد أصل فإن فوق: مساحة العمل إشارة أمر هو حمل دائم محادثة محتوى، حسب agent و جلسة قسم آخر ملكية. أساس خط رسالة و تحديث جديد رسالة كل هو عادي حمل مصدر `user/message` حدث، لذلك و أخرى تاريخ واحد مثال يمكن إعادة تشغيل، يمكن ضغط (compaction) ، يمكن استعادة، نموذج مرئي حالة مجموع قدرة من جلسة سجل إعادة بناء. إضافة يملك كامل `<system-reminder>` إطار هيكل، كل بند حقن رسالة كل أصل مثال وصول نموذج.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:pre-step مستمع،`tools/result` touch تتبع أثر،inbox تركيب |
| [`src/config.ts`](src/config.ts) | `Config` schema، ميزانية تحليل، أساس خط معرف |
| [`src/files.ts`](src/files.ts) | مرشح اكتشاف، مشروع أصل بحث، محدود تدفق صيغة قراءة |
| [`src/render.ts`](src/render.ts) | إشارة أمر تصيير، ميزانية قطع قطع، تغيير سجل |
| [`src/state.ts`](src/state.ts) | حمل دائم رسالة مصدر، إصدار/digest ذاكرة مؤقتة، مقابل حساب |
| [`src/digest.ts`](src/digest.ts) | SHA-1 محتوى معرف و كل دليل تكرار مفتاح |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ إعادة تشغيل سوف سعة تحمل لم معرفة أو صيغة خطأ workspace source، خاص pending/cache حالة تحويل من إبرة مقابل صفة خط الإنتاج اختبار تغطية. |

### رئيسي يلزم مسار

في جلسة رقم مرة رمز دمج شرط `agent/pre-step`، إضافة تركيب أساس خط و يأخذ هو طي دخول دخول خطوة دفعة مرة، ضيق مع قد قيادة أخذ رسالة بعد. نجاح رقم واحد جهة `read`،`write`،`edit` استدعاء مساهمة touch سوف امتداد أب درجة تنفيذ token تدريجي طبقة فوق طفو؛ عند خارج طبقة خطوة دخول حمل دائم تاريخ بعد، مرة إسقاط سوف يأخذ مرئي جلسة حالة و inbox مقابل حساب، و ترتيب دخول إضافة جديدة، استبدال أو إزالة. مسار و digest كل لم تغيير محتوى أبدا تكرار حقن. اكتشاف تتبع مع بنية تحويل نظام الملفات نشط حركة، بينما غير shell تنقل، لأن كل مرة محلي shell استدعاء كل بدء جديد عملية، تحليل مهمة معنى shell لغة قاعدة لا هو يمكن اعتماد نظام الملفات seam.

### ثابت صيغة

كل بند حقن رسالة كل يحمل حمل نوع مصدر و ذلك تغيير قائمة؛ كامل أساس خط أيضا يحمل من مواصفة تحويل اكتشاف، أولوية درجة، مشروع أصل و ميزانية إعداد إرسال توليد معرف، مطابقة حمل دائم رسالة سوف تأكيد قد ترتيب طابور أساس خط. نموذج مرئي نص لا يحتوي إخفاء حالة علامة، إشارة أمر محتوى أو نموذج مرئي بيانات وصفية في حرف وجه `</system-reminder>` نص كل سوف يتم تحويل معنى، لذلك مستودع تحكم نص لا يمكن إغلاق إضافة تحكم إطار هيكل.

## تجربة النموذج

### أساس خط سياق

#### نموذج يرى محتوى

رقم مرة طلب إرسال توليد تاريخ في يتضمن واحد بند حمل دائم user زاوية لون رسالة، منها حسب من عرض عام إلى أداة جسم ترتيب يتضمن محدود مستخدم عام إشارة أمر و مشروع إشارة أمر سلسلة. مرئي أساس خط توافق وقت، استعادة سوف إعادة استخدام هذا رسالة.

##### أساس خط إشارة أمر نموذج لوح

```markdown
<system-reminder>
The following workspace instructions may be relevant to your work. Use them as guidance when applicable. More specific instructions take precedence over broader ones. They do not override system, developer, or direct user instructions.

Instructions from: ~/.dsh/AGENTS.md

<user-global-instructions>

Instructions from: AGENTS.md

<project-instructions>
</system-reminder>
```

#### Token أثر

تصيير بعد أساس خط فقط إلحاق مرة، و إبقاء في إرسال توليد تاريخ في مباشر إلى ضغط.`maxBytes` حد كامل رسالة، مقارنة عرض عام ملف في الأكثر أداة جسم ملف قطع قطع قبل يتم حذف، فارغ إشارة أمر سلسلة لا إنتاج token.

#### KV Cache أثر

فقط إلحاق، يقع في قائم يمكن إعادة استخدام بادئة بعد. مرئي أساس خط معرف توافق وقت، استعادة سوف إبقاء إعادة استخدام؛ لا توافق معرف سوف إلحاق واحد بند كامل بديل أساس خط، لذلك اكتشاف، أولوية درجة، مشروع أصل أو ميزانية تغيير فقط سوف من هذا تاريخ موضع بدء أثر إعادة استخدام.

### جديد اكتشاف scope سياق

#### نموذج يرى محتوى

نجاح رقم واحد جهة نظام الملفات استدعاء وصول أكثر عميق دليل بعد، تحت مرة طلب سوف يتضمن واحد بند إبقاء حمل مصدر `user/message`، منها يتضمن جديد ملائم استخدام إشارة أمر ملف.

##### مرفق إضافة إشارة أمر نموذج لوح

```markdown
<system-reminder>
Additional instructions from: packages/app/AGENTS.md

These instructions apply to work under `packages/app`. Use them as guidance when relevant; more specific instructions take precedence. They do not override system, developer, or direct user instructions.

<nested-instructions>
</system-reminder>
```

#### Token أثر

كل قد اكتشاف scope كل سوف إضافة محدود تاريخ token، مباشر إلى ضغط. مرئي جلسة حالة و إصدار/digest مقارنة مقارنة سوف كبح صنع لم أكثر تعديل محتوى،PTC mode سوف نفس رسالة تأخير متأخر حتى خارج طبقة `run_code` نتيجة و ذلك الذي تابع حمل دائم خطوة بعد.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### قد تغيير أو إزالة إشارة أمر سياق

#### نموذج يرى محتوى

قد تغيير ملف سوف إنتاج `Updated instructions from: <path>` إضافة استبدال محتوى. إزالة فقد أو يصبح نفس دليل في مقارنة مبكر مرشح ملف تكرار بند مرشح ملف سوف إنتاج تحت جهة إزالة إشعار.

##### إزالة إشعار

```markdown
<system-reminder>
Instructions removed: packages/app/AGENTS.md

The previously loaded instructions from this file no longer apply.
</system-reminder>
```

#### Token أثر

كل بند قد تأكيد تغيير أو إزالة كل هو واحد بند تلقي `maxBytes` حد إبقاء تاريخ رسالة. مزود فشل لا إضافة رسالة، ميزانية حذف تحديث ما زال يمكن في لاحق نظام الملفات touch في معالجة.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح إشارة أمر تحميل أي وقت لا دمج ملائم أو حاجة تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **اكتشاف تتبع مع بنية تحويل fs أداة، بينما غير shell تنقل**: أكثر تعديل دليل `bash` أمر لن إطلاق تضمين طقم إشارة أمر اكتشاف، لأن shell لغة قاعدة و كل مرة استدعاء shell حالة لا هو يمكن اعتماد نظام الملفات seam.
- **تحديث جديد من touch قيادة**: لا يوجد watcher؛ خارجي تحرير سوف في تحت مرة نجاح رقم واحد جهة `read`،`write` أو `edit` وقت، استعادة مقابل حساب مرئي أساس خط وقت، أو دخول خطوة pre-step استعادة يتم حجب حجب أساس خط وقت مرئي.
- **مرشح دلالة متعمد إبقاء بسيط مفرد**: لا حل تفسير صغير كتابة اسم،`.claude/rules/` و `@path` import؛ مشروع scope افتراضي تحميل `AGENTS.local.md`/`CLAUDE.local.md` overlay، لكن مستخدم عام `$DSH_HOME` scope لا يوجد محلي overlay، أخرى ذاتي تعريف اسم حاجة صريح مرشح إعداد.
- **كل دليل ذهاب إعادة أساس في محتوى**: نفس درجة مرشح فقط لديه في ذهاب حذف أول ذيل فارغ أبيض بعد بايت تماما متسق وقت عندئذ طي.`CLAUDE.md` إذا symlink إلى نفس درجة `AGENTS.md`، سوف تحليل لـ نفسه محتوى و مثل أي تكرار بند واحد مثال طي؛ من `AGENTS.md` عائم نقل مستقل فرعي هذا فإن سوف و هو واحد بدء كامل تحميل.
- **Symlink إشارة أمر ملف سوف عبر تجاوز معلومة مهمة حد تتبع مع**: نهائي مكون هو symlink مرشح ملف سوف يتم تحليل و تحميل ذلك هدف، لذلك تغلب ضخم مستودع يمكن سوف شجرة خارج ملف محتوى عرض لـ مقارنة منخفض أولوية درجة مساحة العمل إشارة جذب (هو أبدا تغطية system،developer أو مستخدم مباشر تحت بلوغ إشارة أمر). تحميل لا تلقي معلومة مهمة مستودع وقت، طلب استخدام نظام الملفات سياسة بوابة أو OS صندوق رملي حد `ctx.fs`.
- **إشارة أمر محتوى تلقي حد لكن لن يتم ملخص**: تجاوز خروج ميزانية عرض عام ملف سوف يتم حذف، الأكثر أداة جسم ملف ممكن يتم قطع قطع؛ هذا إضافة أبدا طلب نموذج ضغط إشارة أمر نص.
