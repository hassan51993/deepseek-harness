# @deepseek-ai/dsh-computer-use

[English](README.md) | العربية

## عام وصف

نشر كل مرة يمكن تفعيل واحد حساب حساب آلة عملية مزود. تحميل آخر عدد مزود وقت سوف فشل، و تقرير إبلاغ قد تسجيل مزود اسم. كل مزود توفير ذاتي ذات أداة و طاولة وجه عملية. هذه الحزمة لا إضافة نموذج مرئي أداة، أيضا لا تنسيق ضبط تزامن Session.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في Cordis تركيب في، سوف خدمة و اختيار تحديد مزود واحد بدء تركيب مرة:

```yaml
- name: '@deepseek-ai/dsh-computer-use'
```

خدمة لا يوجد بند إعداد. مزود إضافة حقن `computerUse` و استدعاء `ctx.computerUse.register(ComputerUseProviderName(name))`؛ هذا صنف لوحة نوع من `@deepseek-ai/dsh-computer-use/brand` تصدير. إرجاع effect تنظيف دالة تحرير هذا مرة تسجيل.

مزود أولا إيقاف استقبال استدعاء الأداة، إغلاق مورد و انتظار ذاتي لديه عمل انتهاء، مجددا تحرير تسجيل. تحرير قبل،`ctx.computerUse.providerName` بداية نهاية تقرير إبلاغ قد تسجيل اسم.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة — انقر للتوسيع</summary>

واحد خاص اسم احتلال استخدام تسجيل موضع.Cordis effect في إضافة إزالة وقت إزالة مساهمة؛ تكرار استدعاء تنظيف دالة لن إزالة لاحق تسجيل.[شفرة المصدر](src/index.ts) لا يتضمن قيادة كائن، عملية واجهة أو مزود اختيار جهاز.

لا إصدار `./invariant` مرافق مع مدخل: سجل التسجيل فقط لديه واحد مرجعي حقل، لا يوجد ممكن و لـ قسم اختلاف مستقل صيانة مراقبة قياس قيمة. الذي تابع اختبار تغطية تكرار تسجيل رفض و إضافة إزالة.

</details>

<a id="model-experience"></a>
## تجربة النموذج

بلا، لأن هذا سجل التسجيل فقط سجل مزود اسم.

#### KV ذاكرة مؤقتة أثر

تسجيل لا تغيير نموذج طلب. مزود يملك أداة و إشارة توجيه نص قرار كل منها مقابل طلب بادئة أثر.

## معروف حد و لاحق عمل

<a id="known-limitations-and-deferred-work"></a>

خدمة في ذلك Cordis خدمة نسخة داخل حد تسجيل.

- **مشترك طاولة وجه** — تزامن Session و مستقل DSH عملية يمكن عملية نفس طاولة وجه؛ استدعاء جهة تنسيق ضبط كامل حساب حساب آلة عملية مسار.
- **مزود اختيار** — من إعداد اختيار مزود؛ نموذج لا يستطيع في وقت التشغيل تبديل قد تسجيل قيادة.
