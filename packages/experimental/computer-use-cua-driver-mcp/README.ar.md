# @deepseek-ai/dsh-experimental-computer-use-cua-driver-mcp

[English](README.md) | العربية

## عام وصف

يجعل نموذج عبر قد تثبيت Cua Driver عملية محلي طاولة وجه. سوف هذه الحزمة و computer-use خدمة واحد نفس تركيب، يكفي عبر MCP توفير قيادة ذاته أداة وصف، معامل و نتيجة. تثبيت و طاولة وجه إذن من Cua Driver مسؤول، افتراضي لا تفعيل أي قيادة. توفير من في اتصال و أداة إتمام إغلاق قبل حمل متابعة احتلال استخدام حساب حساب آلة استخدام قدرة؛ تزامن Session من استدعاء جهة ذاتي سطر تنسيق ضبط.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند Cua Driver قد في تشغيل DSH نفس منصة آلة جهاز فوق تثبيت و إعداد جيد وقت، اختيار هذا توفير من. منصة ضبط بـ[فوق تنقل تثبيت و إذن إشارة جنوب](https://github.com/trycua/cua/blob/cua-driver-rs-v0.28.0/libs/cua-driver/README.md) لـ دقيق.

### الأكثر صغير إعداد

سوف التالي بند إضافة دخول قد توفير tools و system-prompt خدمة تركيب. قطع رسم أيضا حاجة مرفق عنصر تخزين، و إعلان دعم حمل رسم مثل إدخال نموذج توجيه.

```yaml
- name: '@deepseek-ai/dsh-computer-use'
- name: '@deepseek-ai/dsh-experimental-computer-use-cua-driver-mcp'
  config:
    command: cua-driver
    args: [mcp]
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `command` | `cua-driver` | قد تثبيت يمكن تنفيذ برنامج مسار أو PATH أمر |
| `args` | `[mcp]` | لا مرور مرور shell، مباشر نقل دخول معامل |
| `toolCallTimeoutMs` | MCP عميل قيمة افتراضية | مفرد مرة استدعاء مهلة تغطية قيمة، مفرد موضع لـ جزء ثانية |
| `reconnect` | MCP عميل سياسة | اختياري إعادة وصل تغطية إعداد |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-experimental-computer-use-cua-driver-mcp) صف خروج قبول حقل. مهلة و إعادة وصل قيمة افتراضية من [MCP عميل](../../mcp/mcp-client/README.ar.md) تعريف.

### تنشيط و كل حق

توفير من في اتصال قبل بـ `cua-driver-mcp` تسجيل. ثاني عدد حساب حساب آلة استخدام توفير من سوف تنشيط فشل، يشمل هذه الحزمة آخر عدد نسخة. ابتدائي تحويل أو أول مرة أداة اكتشاف فشل سوف جعل هذا بند تنشيط فشل، و في تنظيف بعد تحرير تسجيل. بعد اتصال قطع فتح وقت،MCP عميل إعادة وصل أو استهلاك كل محاولة تجربة مرة عدد متساو إبقاء تسجيل؛ إزالة بند عندئذ سوف تحرير تسجيل.

نموذج يرى أداة استخدام ثابت `mcp__cua-driver-mcp__` نطاق الأسماء. أداة اسم، وصف، إدخال نمط، مواصفة نتيجة و رسم مثل دقيق دخول التزام دوران قائم [MCP جسر وصل جهاز](../../mcp/mcp-client/README.ar.md). هذه الحزمة لا مقدار خارج توفير DSH عملية دليل أو توفير من اختيار أداة.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة — انقر للتوسيع</summary>

[`src/index.ts`](src/index.ts) سوف حساب حساب آلة استخدام تسجيل و الذي تابع MCP فرعي إضافة عودة دخول نفس عدد لديه ترتيب فرعي أثر. فرعي إضافة إتمام تنظيف بعد عندئذ تشغيل تسجيل تحرير دالة، تنشيط فشل وقت أيضا التزام دوران هذا واحد ترتيب.MCP عميل مسؤول اعتماد مرور ترشيح، عملية فرعية إنهاء، أداة تزامن، إلغاء و حفظ دائم رسم مثل إسقاط.

هذه الحزمة لا إصدار وقت التشغيل ثابت كمية مرافق مع إضافة: توفير من لا يوجد مستقل قيادة حالة يمكن و تسجيل مقارنة مقارنة، اتصال و أداة بديل مرة من فرعي إضافة يحتفظ.

### تحقق قد تثبيت قيادة

في مستودع أصل دليل، استخدام Cua Driver يمكن تنفيذ برنامج قطعا مقابل مسار صريح تفعيل حقيقي توافق صفة اختبار. اختبار اكتشاف أداة، بـ `prompt: false` استدعاء `check_permissions`، و تحقق تنظيف نتيجة. في macOS فوق،`--direct` استخدام بدء مضيف إذن في MCP عملية في تشغيل قيادة؛ حذف `DSH_COMPUTER_USE_MCP_ARGS` فإن استخدام افتراضي `["mcp"]` معامل.

```sh
DSH_COMPUTER_USE_MCP_EXECUTABLE=/absolute/path/to/cua-driver \
DSH_COMPUTER_USE_MCP_ARGS='["mcp","--direct"]' \
pnpm run test:e2e packages/experimental/computer-use-cua-driver-mcp/tests/installed-driver.e2e.ts
```

<a id="model-experience"></a>
## تجربة النموذج

### Cua Driver أداة و قطع رسم

#### نموذج مرئي محتوى

قد تثبيت قيادة إعلان أداة وصف و إدخال نمط استخدام `mcp__cua-driver-mcp__<tool>` اسم عرض. نجاح استدعاء إبقاء لديه ترتيب نص و قد دقيق دخول قطع رسم؛ لا دعم حمل رسم مثل توجيه سوف استلام إلى MCP جسر وصل جهاز تشخيص نص. أداة استدعاء و إسقاط بعد نتيجة عبر صحيح معتاد تنفيذ مسار دخول Session سجل.

#### Token أثر

قد تسجيل نمط دخول نموذج طلب، أداة معامل، نص نتيجة و قد دقيق دخول رسم مثل حمل متابعة احتلال استخدام سياق، مباشر إلى ضغط. مواصفة نتيجة في داخل ربط رسم مثل بايت لن كتابة Session حدث؛ حفظ دائم مرفق عنصر مرجع معرف نموذج مرئي رسم مثل.

#### KV ذاكرة مؤقتة أثر

أداة اكتشاف نتيجة ثابت وقت، أداة تعريف بادئة إبقاء مستقر. دليل تغير ممكن من رقم واحد تغير نمط بدء جعل ذاكرة مؤقتة بطلان؛ إلحاق أداة نتيجة إبقاء هذا قبل طلب بادئة.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

هذا توفير من اعتماد قد تثبيت قيادة و MCP جسر وصل جهاز دعم حمل قدرة.

- طاولة وجه وصول حاجة إتمام فوق تنقل تثبيت و أخذ نيل منصة إذن؛ إضافة تنشيط ذاته لا يستطيع إثبات كل طاولة وجه عملية كل قد نيل دقيق.
- كثير عدد Session مشترك واحد طاولة وجه. مرة تشغيل واحد حساب حساب آلة استخدام سير العمل، أو في خارجي تنسيق ضبط؛ تسجيل لن سلسلة سطر تحويل Session عملية.
- قيادة ترقية ممكن تغيير اكتشاف دليل. هذا توفير من لا دعم حمل وقت التشغيل قيادة تبديل، مخصص استخدام طاولة وجه إذن واجهة أو DSH عملية سحب كائن.
- بدء وقت حد و غني نتيجة حد التزام دوران [MCP عميل حد](../../mcp/mcp-client/README.ar.md#known-limitations-and-deferred-work).
