# `@deepseek-ai/dsh-experimental-webworker-packer`

[English](README.md) | العربية

## عام وصف

VFS مرآة مثل تحزيم جهاز: يأخذ واحد نسخة دمج صار profile تغيير صار متصفح worker تركيب لـ نظام الملفات gzip ضغط أساس أساس tar، و يأخذ لا نفاذ واضح بيانات دليل تغيير صار حسب ترتيب تطبيق overlay tar([فعلي تحقق مجموعة](../README.zh.md)). لا فعل أي شفرة المصدر تحرير ترجمة——أساس أساس مرآة مثل يحمل مستودع حقيقي بناء ناتج، معاينة نشر ضبط تجربة صحيح هو served نشر تسليم بايت. تحزيم معاينة مرآة مثل أو ترتيب فحص مرآة مثل محتوى وقت، طلب قراءة قراءة هذا صفحة.

## استخدام هذه الحزمة

عام npm حزمة عبر مكتبة مدخل توجيه خروج `packVfsImage` و `packVfsOverlay`. استدعاء جهة توفير دمج صار إعداد، حزمة دليل و تحليل أصل دليل؛ هذه الحزمة لا تثبيت profile طبقة. وقت التشغيل مكتبة مدخل توفير تحزيم الذي استخدام وحدة بديل إدارة جدول و استبدال جدول.

تحزيم جهاز في [`src/repository.ts`](src/repository.ts) في يملك داخلي `dsh.configTrees` إعلان، تحقق و مصدر دليل تحليل. هذا حقل لا يخص عام مشترك إضافة manifest API.

تحزيم هو ثلاثة طبقة معيار مكدس:

1. **Roster**——دمج صار profile إضافة سطر (معيار YAML تحليل،Include جهة قول،`!!js` أصل مثال إبقاء) ، إضافة فوق CLI(أمر سطر واجهة) في `package.json` `dsh.configTrees` داخل إعلان كل شجرة إعداد شجرة (agent(ذكي جسم) presets) سطر، حسب Node صيغة اعتماد إغلاق حزمة شيء تحويل. خارجي peer حافة أبدا سوف ربط إلى worker،workspace peer إبقاء في سلسلة فوق.
2. **إصدار عرض**——كل workspace أو vendored حزمة مساهمة ذلك بناء بعد npm قطع قطعة (`files` مشي picomatch) ، لا حمل شفرة المصدر و workspace `dist/`. خارجي حزمة `main` أو `exports` ممكن إشارة نحو `src/` أو `dist/`، لذلك اثنان موضع إصدار JavaScript كل سوف إبقاء، فقط تطبيق عام اختبار،map، إعلان و عودة ملف ترتيب حذف قاعدة.
3. **يمكن بلوغ صفة sweep**——استخدام وقت التشغيل تحميل جهاز ذاتي ذات تحليل، من الكل workspace توجيه خروج وجه إضافة worker تركيب إعداد نوع فرعي (`IMAGE_ENTRY_SEEDS`) خروج إرسال، تحزيم وقت يأخذ كل يمكن بلوغ وحدة تحويل لـ رمز دمج حزمة تركيب طبقة اتفاق شكل صيغة. هذا تحويل سوف تقرير إبلاغ اسم يمكن ساكن حالة تحديد import،re-export و حركة حالة import، مرور `require` إرسال بدء استدعاء، و عبر `node:module` أو `module` أداة اسم استيراد (يحتوي استيراد آخر اسم) في وحدة أثر مجال مباشر إرسال بدء `createRequire(import.meta.url)('pkg')` استدعاء. صفحة مورد إنتاج (`./client` توجيه خروج خلف بعد `lib/client.js`) أصل مثال مباشر إرسال؛ ذاتي بيت شفرة غير ممكن تحليل طلب سوف يجعل تحزيم فشل، رقم ثلاثة جهة غير ممكن تحليل طلب فإن سماح تأخير بعد إلى require وقت واضح فشل.

`repository.ts` يملك مستودع شكل إدخال (`vendor/`،`packages/`،`native/system/packages/` و `apps/` workspace مسح؛ مرور حق CLI dump مسار دمج صار profile) ؛`pack.ts` واحد عام لا يملك، نفس مكتبة تبديل مشاركة يكفي ضرب آخر شجرة شجرة.Native مسح جعل Landlock مدخل حزمة يصبح عادي إصدار عرض اعتماد، ذلك يمكن تنفيذ ملف ما زال من Worker منصة تنفيذ.CLI لـ `dsh-pack-vfs-image --out <file> [--profile web]`؛`apps/web` `build:preview` في معاينة قشرة بناء بعد تشغيل هو.

مستودع مهايئ أيضا إعلان `webworker-runtime/tests/fixtures/` تحت فقط لأجل preview fixture(اختبار قبل وضع بيانات) tree.CLI سوف يأخذ كل طقم أداة اسم fixture ضرب صار واحد نسخة مستقل تحديد صفة overlay عودة ملف، و كتابة خروج متصفح يمكن قراءة manifest(بيانات وصفية بيان).Overlay ملف التفاف مرور npm إصدار عرض و وحدة يمكن بلوغ صفة ترتيب حذف قاعدة، لذلك نقطة دليل و عرض مثال شفرة المصدر سوف كامل إبقاء؛ ذلك تركيب موضع فقط حد `home/` و `workspace/`.`pack.ts` يأخذ هو جمع نظر لـ لا نفاذ واضح بايت؛ جلسة و Workspace حل تفسير ما زال عودة يملك هذه صيغة وقت التشغيل حزمة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **قاعدة جدول اعتماد شخص عمل حكم قطع**(`rules.ts`:exclude glob، صفحة مورد إنتاج نمط، مدخل نوع فرعي) ، من `tests/` تثبيت إقامة؛worker حاجة لمس بلوغ جديد مورد إنتاج صنف آخر ينبغي إضافة جدول سطر، بينما لا هو تعديل مسح جهاز.
- **يمكن بلوغ صفة فقط دفع قطع دقيق طلب شكل صيغة**——حساب حساب نيل إلى `import` و `require` معامل، حفظ تحت قدوم `createRequire` نتيجة، مرور CommonJS نيل أخذ `createRequire`، و أساس دقيق لا هو `import.meta.url` استدعاء فقط في وقت التشغيل تحليل؛ إذا هدف قد يتم قطع إسقاط حينئذ سوف صريح فشل. فقط قدرة عبر هذه شكل صيغة لمس بلوغ هدف حاجة صريح مرآة مثل مدخل نوع فرعي.
- **vendored حزمة شفرة المصدر (`src/*.ts`) يتم ترتيب حذف**——وقت التشغيل بلا شخص تحليل هو جمع؛ لم قدوم إذا لديه worker داخل شفرة المصدر تفقد فحص وظيفة حاجة مخصص باب include قاعدة.
- **تحزيم جهاز زائف تحديد بناء ناتج `lib/` هو جديد طازج**: هو من لا تحرير ترجمة، مساحة العمل بناء قديم قديم حينئذ سوف تحزيم قديم قديم بايت. أولا ركض مستودع بناء.
- **CLI يجب يقع في أصل لديه مستودع موضع**:`dsh-pack-vfs-image` متبادل مقابل في ذاته تثبيت ملف تحديد موضع فحص خروج دليل، و من في قراءة شفرة المصدر CLI، إعداد شجرة و معاينة fixture.npm تثبيت دعم حمل معامل تحويل مكتبة API؛CLI و مستودع مساعد مساعدة دالة حاجة كامل كما قد بناء DeepSeek Harness فحص خروج دليل.
