# @deepseek-ai/dsh-experimental-computer-use-cua-driver-native

[English](README.md) | العربية

## عام وصف

استخدام Cua Driver فحص و عملية طاولة وجه نافذة، بلا حاجة تثبيت ذلك مستقل CLI أو تطبيق. أصلي npm اعتماد في DSH رئيسي آلة عملية داخل تشغيل، توفير Cua Driver ذاتي ذات أداة. قطع رسم عبر حفظ دائم مرفق عنصر نقل إعطاء دعم حمل رسم مثل نموذج. هذا فعلي تحقق صفة لين عنصر حزمة سوف إصدار إلى npm، حاجة بدء رئيسي آلة طاولة وجه إذن، و كما يجب في تركيب إعداد في صريح تفعيل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في قد توفير أداة سجل التسجيل و توجيه النظام تركيب في تركيب هذا توفير من.

### الأكثر صغير إعداد

```yaml
- name: '@deepseek-ai/dsh-computer-use'
- name: '@deepseek-ai/dsh-experimental-computer-use-cua-driver-native'
```

هذا توفير من لا يوجد إعداد حقل. هو تحميل [package.json](package.json) إعلان تأكيد قطع Cua Driver npm إصدار، و اعتماد ذلك عملية داخل افتراضي إعداد. أصلي وحدة استيراد، وقت التشغيل ابتدائي تحويل، دليل صيغة، أداة إعادة اسم أو كهرباء دماغ عملية تسجيل اندفاع مفاجئ سوف جعل تنشيط فشل، و تراجع الذي يملك مورد. تسجيل توفير من اسم لـ `cua-driver-native`.

تركيب مرفق عنصر تخزين و استخدام واضح إعلان دعم حمل رسم مثل إدخال نموذج توجيه، عندئذ قدرة استقبال قطع رسم.[MCP نتيجة مهايئ](../../mcp/mcp-client/README.ar.md) مسؤول رسم مثل وصل قبول و تشخيص سلوك؛ نموذج لا يمكن استقبال رسم مثل وقت، برنامج استدعاء جهة ما زال إبقاء مواصفة أصلي نتيجة. استدعاء اعتماد Cua Driver فوق تنقل أداة معامل و نتيجة.

### رئيسي آلة اشتراط

أصلي اعتماد عبر npm اختياري اعتماد توفير كل منصة اثنان دخول صنع ملف، لذلك يجب إبقاء اختياري اعتماد تثبيت. طلب نحو بدء DSH تطبيق منح إعطاء طاولة وجه إذن؛ هذا توفير من حيث لا تثبيت مستقل يحتفظ إذن تطبيق، أيضا لا أكثر تعديل عملية نظام تخويل. أصلي وقت التشغيل و رئيسي آلة مشترك عملية، لذلك أصلي انهيار انهيار ممكن إنهاء هذا عملية. إذا حاجة من مستقل Cua Driver تطبيق يحتفظ إذن و تنفيذ عملية، طلب استخدام[قد تثبيت MCP توفير من](../computer-use-cua-driver-mcp/README.ar.md).

### تحقق قد تثبيت SDK

في مستودع أصل دليل تشغيل هذا بند صريح تفعيل فحص، تحقق قد تثبيت أصلي اعتماد. هو اكتشاف أداة، عبر `prompt: false` قراءة إذن حالة، و تحقق إزالة؛ هو لا قطع رسم، لا إرسال إدخال، أيضا لا طلب عملية نظام إذن. صاف حذف `NODE_USE_ENV_PROXY` يمكن منع توقف Node في اختبار ابتدائي تحويل قبل اعتماد بدء shell بديل إدارة ضبط.

```sh
env -u NODE_USE_ENV_PROXY DSH_COMPUTER_USE_NATIVE_E2E=1 node node_modules/vitest/vitest.mjs run --config vitest.e2e.config.ts packages/experimental/computer-use-cua-driver-native/tests/native.e2e.ts
```

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى ماذا

في أصلي أداة تركيب خلال، هذا توفير من إضافة دخول التالي كهرباء دماغ عملية إشارة توجيه نص.

##### أصلي Cua Driver إشارة توجيه نص

```markdown
Cua Driver native computer-use tools operate the host desktop. Discover the exact app and window, then get a fresh window snapshot before acting. Use element_token from that snapshot, or coordinates from its screenshot. A new snapshot of that window invalidates its earlier element tokens. Select either target or the legacy pid/window_id fields; do not combine them.

Prefer background delivery. A refusal does not authorize a foreground retry. Verify the requested outcome from fresh state after an action; a delivered click alone does not prove the outcome. After cancellation, inspect current state before retrying because completed input is not rolled back. Other sessions and applications may change the same desktop.

On macOS, cursor-overlay operations may return facility_unavailable even when screenshots and input work.
```

#### Token أثر

توفير من تركيب خلال، هذا مقطع ثابت إشارة توجيه نص زيادة توجيه النظام token. فوق تنقل إشارة توجيه مورد لن تلقائي تحميل.

#### KV Cache أثر

إشارة توجيه نص ثابت وقت، ذلك تكرار نص التوجيه بادئة إبقاء مستقر. تركيب، إزالة أو تحرير هو سوف تغيير هذا بادئة، و ممكن نقص قليل ذاكرة مؤقتة إعادة استخدام.

### اكتشاف Cua Driver أداة و نتيجة

#### نموذج يرى ماذا

أداة اسم استخدام `cua_driver_native__` بادئة و مرفق إضافة فوق تنقل اسم، إبقاء فوق تنقل وصف و إدخال schema. فوق تنقل أداة رفض تحويل لـ أداة خطأ. دعم حمل قطع رسم بصفة حفظ دائم رسم مثل مرجع ظهور في نتيجة نص جانب؛ برنامج استدعاء جهة ما زال يمكن قراءة مواصفة أصلي نتيجة.

#### Token أثر

اكتشاف دليل لـ كل طلب إضافة دخول أداة تعريف. بلا عائق عائق شجرة، نتيجة نص و نيل دقيق وصل قبول قطع رسم زيادة كل مرة استدعاء سياق. أصلي base64 إبقاء في تنفيذ خلال مواصفة قيمة في، لا نسخ إلى نموذج تاريخ.

#### KV Cache أثر

دليل ثابت وقت، أداة تعريف بادئة إبقاء مستقر. أداة نتيجة إلحاق إلى Session تاريخ. استبدال توفير من أو ذلك دليل سوف تغيير نموذج مرئي أداة، و ممكن نقص قليل بادئة إعادة استخدام.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

هذا لين عنصر حزمة إبقاء فوق تنقل قيادة منصة و تطبيق حد.

- **رئيسي آلة إذن و رسم شكل جلسة**——npm تثبيت لن منح إعطاء طاولة وجه وصول إذن أو إنشاء رسم شكل جلسة.
- **أصلي ضوء علامة تغطية طبقة**——بلا واجهة macOS Node رئيسي آلة ممكن مقابل تغطية طبقة عملية إرجاع `facility_unavailable`، معا قطع رسم و خلفية إدخال ما زال متاح.
- **مشترك طاولة وجه**——هذا توفير من لا لـ بعض عدد Session مسبق إبقاء نافذة أو كامل سير العمل. أخرى استدعاء جهة و تطبيق يمكن في اثنان مرة استدعاء بين أكثر تعديل نفس طاولة وجه.
- **إلغاء**——يتم إلغاء استدعاء ممكن قد نقل دخول إدخال؛ إعادة محاولة قبل يجب فحص جديد حالة. إزالة وقت توفير من انتظار SDK إغلاق، لكن لا تحمل وعد تراجع أصلي عملية.
- **إغلاق فشل**——إذا أصلي إغلاق فشل، تسجيل اسم مقدار إبقاء احتلال استخدام. تركيب أخرى كهرباء دماغ عملية توفير من قبل يجب إعادة بدء رئيسي آلة.
- **فعلي تحقق صفة إصدار**——أداة schema تتبع مع قفل تحديد فوق تنقل SDK، لا عمل DSH مستقر صفة تحمل وعد.
