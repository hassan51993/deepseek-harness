# `@deepseek-ai/dsh-experimental-webworker-runtime`

[English](README.md) | العربية

## عام وصف

متصفح worker مضيف: كامل شجرة harness إضافة شجرة ركض في واحد dedicated Web Worker داخل، لأجل معاينة نشر و تحزيم ارتداد ([فعلي تحقق مجموعة](../README.ar.md)).worker حافة تحت تحميل حافة حل ضغط تحزيم جيد VFS مرآة مثل و تركيب دخول داخل تخزين، مرور CommonJS حزمة تركيب تحميل جهاز تركيب تحميل وحدة، و عبر واحد بند شرح صاف HTTP postMessage نفق طريق خدمة صفحة. عند معاينة حاجة في لا يوجد Node مضيف بيئة في تشغيل قد تحزيم harness وقت، طلب استخدام هو.

## استخدام هذه الحزمة

عام npm حزمة في أصل مدخل تصدير وقت التشغيل مكتبة، عبر `./worker` توفير ذاتي يتضمن متصفح Worker، عبر `./client` توفير صفحة اتصال جهاز. نشر جهة عبر [تحزيم جهاز](../webworker-packer/README.ar.md) مفرد وحيد توفير و حمل إدارة VFS مرآة مثل؛ تثبيت هذا مكتبة لن زيادة profile طبقة. أصل مدخل أيضا تصدير تحزيم جهاز الذي استخدام وحدة بديل إدارة جدول و استبدال جدول.

واحد بند tsdown إدارة خط إنتاج خروج ثلاثة عدد بناء ناتج؛ آخر لديه واحد طبقة من شفرة المصدر صيانة عملية تنفيذ:

- **`lib/index.js`(تركيب إعداد مكتبة)**——`createWorkerHost`/`startWorkerHost` تركيب أساس أساس مرآة مثل و حسب ترتيب صف بيانات overlays(`storage/`) ، تثبيت وحدة تحميل جهاز (`module-system/`) و `process` shim، مرور مرآة مثل ذاتي حمل `dsh-app-boot` بدء إضافة شجرة، و يأخذ خدمة seam تسليم إعطاء نفق طريق.Overlay فقط قدرة استبدال `home/` و `workspace/` تحت ملف، لا يستطيع استبدال أساس أساس manifest، إعداد أو وحدة. مرآة مثل تخطيط عقد نحو (`image-layout.ts`: وهمي محاكاة أصل،config/manifest مسار، فارغ دليل،`lowered` حزمة تركيب عقد نحو باب) و packer مشترك.boot patch قوي صنع نشر شكل سطر: صلة قبل طرف ساكن حالة خدمة،JSONL جلسة سجل مشي واضح نص،preset أصل إشارة نحو مرآة مثل داخل `config/agent-presets`.
- **`lib/worker.js`(worker حزمة)**——تركيب إعداد مكتبة إضافة هذه الحزمة Node توافق طبقة، دمج صار واحد ذاتي يحتوي ES module. وحدة بديل إدارة جدول (`module-proxies.ts`) هو وحيد منصة تقاطع فتحة:`node:*` داخل بناء مشي VFS، نفق طريق و متصفح أصل لغة، متصفح فعل لا إلى مشي بنية تحويل stub(استدعاء أي في console تقرير خطأ و رمي خروج) ،native/binary حزمة فإن استبدال تنفيذ خلفية.`node:module` في مرآة مثل package أصل لـ فوق توفير `createRequire().resolve` و `.resolve.paths()`، جعل لم تعديل حزمة بلا حاجة تنفيذ هدف وحدة يكفي اكتشاف manifest. عام `process` shim حمل لديه يشمل `title` في داخل Node بيئة تعرف آخر حقل، تجنب تجنب Worker تنفيذ خطأ دخول فقط ملائم لأجل DOM فرع.pack مدة محلل سوف يأخذ اسم ساكن حالة يمكن معرفة وحدة طلب تقرير إبلاغ إعطاء packer يمكن بلوغ صفة مرة تاريخ، منها يشمل عبر `node:module` أو `module` أداة اسم استيراد في وحدة أثر مجال مباشر إرسال بدء `createRequire(import.meta.url)('pkg')` استدعاء. حفظ، مرور CommonJS نيل أخذ أو آخر ضبط أساس دقيق `createRequire` استدعاء حاجة مرآة مثل مدخل نوع فرعي.VFS mutation قيادة `node:fs` callback،polling و promise watcher؛ فتح descriptor في rename،replacement و unlink بعد ما زال إبقاء ملف هوية و وصول نمط، فقط يلزم ملف اسم ما زال إشارة نحو هذا ملف،`FileHandle.stat({ bigint: true })` تقرير إبلاغ device و inode هوية حينئذ و مسار stat نفسه،`FileHandle.chmod()` فإن تحديث فتح ملف هوية إذن؛`readable-stream` توفير ملف تدفق و Chokidar،readdirp انتظار لم تعديل مرآة مثل حزمة الذي استخدام تدفق حالة آلة.AsyncLocalStorage مرور pack وقت خفض منخفض حقن snapshot/restore وجه في `await` بين يحمل تزامن مكدس بسبب نتيجة.worker لا حمل تحرير ترجمة جهاز:packer لم خفض منخفض مرآة مثل في تركيب وقت يتم رفض. عودة ضبط صيغة `fs.realpath.native` آخر اسم في قد تركيب VFS داخل تحليل مسار، و دعم حمل `util.promisify`.
- **`src/shell/`(worker ذاتي ذات عملية طبقة)**——متصفح worker لا يمكن fork، الذي بـ `node:child_process` لا هو stub بينما هو تنفيذ:`spawn` يأخذ أمر وضع دخول هو ذاتي ذات Web Worker——حينئذ هو هذا نفس عدد حزمة، من أول لقطة إبلاغ إبلاغ هو «أنت هو shell عملية»——و بـ subprocess خدمة إزالة استهلاك `ChildProcess` وجه تقرير إبلاغ نتيجة. أمر لا احتلال مضيف خط مسار،`SIGKILL` لا إدارة هو في جاف ماذا كل قدرة إنهاء هو، بينما هو فقط قدرة اعتماد رسالة لمس بلوغ VFS(من مضيف ينبغي جواب هذه لقطة).Worker منصة executable في لا استبدال JavaScript حزمة، أيضا لا يأخذ أداة جسم تنفيذ اقتران دمج دخول `node:child_process` حال حال تحت إبقاء Landlock انتظار native حزمة بروتوكول؛ عادي أمر استخدام هذه الحزمة طلب قيمة جهاز و coreutils أمر جدول. لغة قاعدة قدوم ذاتي `@yarnpkg/parsers` `parseShell`، بينما `execSync`/`fork` اعتماد لكن رفض، لأن هو جمع حاجة حق عملية.
- **`lib/client.js`(صفحة نصف)**——بدء قسم لـ متبادل متبادل مستقل اثنان مقطع.`chooseWorkerHostSource({ image?, fixtureManifest? })` اختياري أرض يملك boot barrier و fixture manifest: لا يوجد `preview-fixture` وقت توقف في مصدر اختيار وجه لوح، دمج قاعدة query فإن مباشر اختيار؛ اثنان بند مسار كل إرجاع حسب ترتيب صف overlays.`connectWorkerHost(worker, { image?, overlays? })` ما زال هو عام أساس أساس تشغيل حالة اتصال جهاز؛ استدعاء جهة قفز مرور اختيار جهاز وقت overlay قائمة لـ فارغ.`apps/web` استدعاء هذا اثنان مقطع و توفير ساكن حالة تحزيم Worker. فتح نطاق `init` لقطة يحمل أساس أساس مرآة مثل و حسب ترتيب صف overlay URL،boot تحميل حمل إرسال بلوغ بنية تحويل index حقن جدول،`applyIndexInjections` في قشرة مدخل تشغيل قبل تدريجي سطر تنفيذ. نص برمجي preload سطر فقط هو تلميح، لذلك سوف يتم قفز مرور:`/plugins` مورد فقط قدرة مرور tunnel تحليل،`loadBundle` سوف في أول مرة حاجة وقت نيل أخذ combo، يأخذ فقط tunnel يمكن بلوغ sourcemap داخل تضمين لـ Base64 data URL، مجددا بـ Blob تنفيذ نص برمجي.Tunnel أيضا كشف fetch شكل صيغة نقل، مستقل ملف فوق نقل تحميل جسم و API عميل. طلب لقطة عبر بنية تحويل تغلب ضخم إبقاء Blob طلب جسم، و تحويل نقل `ReadableStream<Uint8Array>` كل حق.Host Worker سوف اثنان نوع طلب جسم كل تدريجي كتلة إرسال دخول توجيه، لذلك عام ملف فوق نقل لن في أي متصفح خط مسار إنشاء كامل بايت عدد مجموعة.

تحقق استلام في `apps/web/tests/preview-boot.e2e.ts`: ساكن حالة خدمة حقيقي بناء صفحة، في headless Chromium داخل قيادة pre-boot اختيار وجه لوح و Worker تنشيط. فارغ أبيض اختيار تحقق أول مرة بدء؛`vfs-example` overlay توفير عادي workspace ملف و واضح نص persistence ناتج، بلا حاجة نموذج طلب يكفي تحقق Workspace/Session بارد اكتشاف، أداة عرض،subagent تنقل و تاريخ قسم صفحة.fixture توليد جهاز مسؤول حالي بديل سجل و إسقاط ذاكرة مؤقتة؛ قد إيداع قبل بديل سجل تدريجي بايت إبقاء ثابت، و هو جمع و تخزين. اختيار وجه لوح لـ WebFS إبقاء مستقل مستخدم تخويل مصدر؛ هذا provider لا قراءة داخل وضع fixture.

[قد بناء bundle استيراد فحص](tests/compile/transform-corpus-check.ts) في مكتبة بناء بعد فحص عار Node استيراد.Dockkit مثال خارج قبول Node إبرة مقابل مهمة معنى مثال صيغة جدول تقرير إبلاغ لم معرفة `.css` توسيع اسم خطأ، بينما لا حد تحديد بعض واحد ثابت مسار؛ أخرى توسيع اسم، رمز خطأ أو رسالة، و معنى خارج نجاح إعفاء تجنب استيراد، ما زال تقرير خطأ. مشاركة رؤية [مثال صيغة جدول إعفاء تجنب قرار](../../../.agents/notes/implemented/bug-fix/2026-09-10-built-bundle-css-exemption.ar.md).

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **worker تركيب كتابة واضح نص جلسة سجل**(`compression: 'none'` boot patch): لا حمل Zstandard تحرير حل رمز جهاز، تصدير سجل هو `.jsonl`، لن هو `.jsonl.zstd`.
- **`node:dns/promises`،`node:vm`،`node:net`،`node:sqlite`،`node:worker_threads` هو بنية تحويل stub**: كل مرة استدعاء في console تقرير إبلاغ رفض و رمي خروج. حاجة أصلي DNS، حق عملية أو حق realm عزل سطر في هذا لا يمكن تشغيل.
- **مضيف حزمة إدارة أمر غير ممكن استخدام**:`execa` واضح تقرير إبلاغ worker host لا دعم حمل هذا استدعاء؛ معاينة لا يمكن تشغيل pnpm أو تثبيت أصلي اعتماد.
- **PTC Node برنامج غير ممكن استخدام**:process shim استخدام `/dsh/bin/node` يمثل يمكن تنفيذ ملف هوية، جعل provider قدرة كاف تنشيط، لكن Worker حيث لا يوجد Node يمكن تنفيذ ملف، أيضا لا يوجد `stripTypeScriptTypes`. برنامج تنفيذ سوف في بدء عملية فرعية قبل فشل.
- **Office تحويل حاجة Node Host**:LibreOffice kit بديل وحدة بـ `unavailable` رفض إنشاء تحويل جهاز. متصفح مرآة مثل ترتيب حذف kit و ذلك جذب محرك اعتماد؛Office معاينة تلميح تحويل غير ممكن استخدام.
- **ملف watcher فقط قدرة مراقبة قد تركيب VFS**: مرآة مثل seed لا إنتاج حدث،VFS أيضا لا يوجد رمز رقم رابط أو خارجي كتابة جهة.`persistent`،`ref()` و `unref()` إبقاء Node API، لكن متصفح لا يوجد مرجع حساب عدد حدث حلقة، لذلك هذه واجهة لا يستطيع تحكم dedicated Worker توليد تخزين مدة.
- **Worker confinement هو VFS حد، لا هو داخل نواة Landlock**:`read-only` و `workspace-write` تشغيل لم مرور تعديل `@deepseek-ai/node-addon-system/landlock-run` JavaScript و launcher argv، عملية طبقة فإن تنفيذ منطق `landlock-run` يمكن تنفيذ ملف، و في shell كل مرة نظام الملفات طلب فوق تنفيذ ذلك تخويل.`full` فقط تغطية Worker أمر جدول و قد تركيب VFS، لا يمثل قدرة كاف تنفيذ مهمة معنى native عملية، أيضا لا يمثل Linux داخل نواة عزل.
- **worker حزمة تثبيت إقامة `@yarnpkg/parsers` حزمة داخل مسار**——بناء تحليل إلى هذا حزمة ذاتي ذات `lib/shell.js` بينما غير حزمة أصل، لأن حزمة أصل barrel أيضا re-export Syml محلل، سوف يأخذ js-yaml سحب دخول واحد من لا تحليل هذا صيغة حزمة (نحو 175 kB، خارج إضافة worker بدء وقت وحدة جسم طلب قيمة). هذا مسار من حزمة manifest إرسال توليد، حزمة داخل تخطيط واحد تغيير أي بناء مدة فشل، لن ساكن صامت تراجع عودة barrel؛ ترقية هذا عدد اعتماد وقت يجب تكرار نواة shell محلل هل ما زال في ذلك داخل.
- **هذا عدد shell لا هو bash**: لا يوجد حلقة، دالة،`case`، عمل عمل تحكم أو عملية استبدال——لغة قاعدة توقف خطوة في إدارة طريق،`&&`/`||`، فرعي shell،group، إعادة تحديد نحو و توسيع.`&` سوف حينئذ أرض يأخذ أمر ركض تمام،`sed` فقط قبول استبدال نص برمجي، نمط هو JavaScript صحيح فإن، أمر جدول فقط لديه coreutils(لا يوجد `git`، لا يوجد شبكة أداة).
- **shell عملية لا يوجد تزامن ملف وجه**: هو اعتماد رسالة قراءة كتابة مضيف VFS، لأن منع سد انتظار عودة لقطة حاجة `SharedArrayBuffer`، بينما ذلك اشتراط GitHub Pages إعطاء لا عبر مصدر عزل. لذلك دليل مرة تاريخ صنف أمر كل بند مرة نحو إرجاع، تزامن اثنان بند أمر كتابة يمكن تسليم خطأ.
- **transport،worker-host، صفحة نصف تغطية حاجة متصفح درجة harness**——هذه وحدة لم بلوغ per-file تغطية باب؛ مفرد قياس تغطية storage،ALS،transform و stub عقد نحو.
