# @deepseek-ai/dsh-experimental-browser-use-playwright-mcp

[English](README.md) | العربية

## عام وصف

عبر Playwright MCP فوق تنقل أداة فحص شبكة صفحة و عملية Chromium. مزود في Session إنشاء أو استعادة إتمام قبل ابتدائي تحويل ذلك MCP اتصال، و عبر جولة إبقاء اتصال. يمكن بدء مستقل متصفح، أيضا يمكن يجعل واحد Session وصل دخول قد لديه متصفح، استخدام ذلك قائم وسم صفحة و تسجيل تسجيل حالة. هذه الحزمة بـ فعلي تحقق حالة إصدار، فقط في صريح تركيب بعد تفعيل.

<a id="use-this-package"></a>
## استخدام هذا حزمة

في إنشاء أو استعادة Session قبل، سوف التالي بند تركيب إلى قد توفير Agent، أداة و توجيه النظام profile تركيب في. تحميل أو إعادة تحميل هذا مزود لن وصل إدارة قد نشط حركة Session. متصفح تثبيت التزام دوران فوق تنقل وقت التشغيل؛ استخدام `executablePath` اختيار قد لديه Chromium تثبيت.

```yaml
- name: '@deepseek-ai/dsh-browser-use'
- name: '@deepseek-ai/dsh-experimental-browser-use-playwright-mcp'
  config:
    mode: launch
    headless: true
```

استخدام `mode: attach`، و في `endpoint` في ضبط HTTP(S) ضبط تجربة URL أو WS(S) متصفح طرف نقطة، يكفي عملية قد لديه متصفح. جديد نشط حركة Session في ابتدائي تحويل وقت احتلال استخدام مرفق إضافة اتصال، و حمل متابعة إبقاء مباشر إلى إزالة. إذا اتصال قد يتم احتلال استخدام، هذا مرة تنشيط لا استخدام هذا متصفح، لكن متابعة تشغيل، لاحق جولة لن إعادة محاولة. اتصال تحرير بعد، جديد إنشاء أو استعادة تنشيط يمكن نيل أخذ هو. أخرى Session مباشر استدعاء سوف فشل. تنظيف فقط قطع فتح اتصال، إبقاء خارجي متصفح و ذلك صفحة.

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `mode` | لا بد ملء | `launch` أو `attach`، في هذا مرة مزود تنشيط خلال ثابت |
| `headless` | `true` | بدء وقت لا عرض نافذة |
| `executablePath` | فوق تنقل اكتشاف | بدء استخدام Chromium يمكن تنفيذ ملف |
| `endpoint` | attach وقت لا بد ملء | قد لديه متصفح ضبط تجربة طرف نقطة |
| `toolCallTimeoutMs` | MCP عميل قيمة افتراضية | مفرد مرة استدعاء مهلة، مفرد موضع لـ مللي ثانية |

[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-experimental-browser-use-playwright-mcp) صف خروج قبول حقل. متصفح نمط من profile أو preset اختيار. عملية فرعية سوف صاف فارغ وراثة `PLAYWRIGHT_MCP_*` خيار، تجنب تجنب ذلك استبدال هذا إعداد.

لـ كامل عملية إعداد توجيه النظام `toolOrder` وقت، سوف متصفح أداة إبقاء في `<unlisted-tools>` في. صريح صف خروج متصفح أداة اسم ممكن توجيه يؤدي لم نيل نيل متصفح اتصال Session لا يمكن تجميع نص التوجيه.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة — انقر للتوسيع</summary>

مزود تحليل ثابت إصدار npm حزمة يمكن تنفيذ مدخل، و استخدام حالي Node بدء. خدمة عملية قبل ممكن تشغيل مؤقت بروتوكول استكشاف قياس عملية.[مشترك وقت التشغيل](../browser-use-runtime/README.ar.md) مسؤول انتظار Agent ابتدائي تحويل، تدريجي Session سلسلة سطر تنفيذ و تنظيف؛[MCP عميل](../../mcp/mcp-client/README.ar.md) مسؤول نقل، اكتشاف و نتيجة إسقاط. مزود لا صيانة مستقل اتصال مراقبة قياس، لذلك لا إصدار وقت التشغيل ثابت كمية إعداد طقم مدخل.

فقط يلزم نشط حركة Session إبقاء اتصال، متصفح حالة حينئذ سوف عبر جولة إبقاء. إلغاء تدمير سوف انتظار خادم إغلاق، مجددا تحرير مورد. إعادة تحميل بعد استعادة Session سوف إنشاء جديد متصفح تشغيل حالة؛ قد حفظ محادثة تاريخ لن أيضا أصل Cookie أو صفحة.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### متصفح أداة و قطع رسم

#### نموذج مرئي محتوى

أداة بـ `mcp__playwright-mcp__<tool>` تسمية، إبقاء فوق تنقل وصف و JSON schema. نص و قطع رسم عبر معتاد قاعدة أداة نتيجة مسار دخول Session سجل. قطع رسم حاجة مرفق عنصر تخزين و دعم حمل صورة إدخال نموذج توجيه؛ أخرى توجيه سوف استلام إلى MCP صورة تشخيص.MCP عميل أيضا توفير مورد أداة و ملاحظة واضح خادم مصدر إشارة توجيه. فقط لديه حالي Session يملك اتصال بعد عندئذ عرض متصفح إشارة توجيه؛ إبرة مقابل هذا خادم مورد طلب تنفيذ نفسه كل حق فحص.

#### Token أثر

أداة دليل، مورد أداة و خادم إشارة توجيه سوف زيادة أداة تعريف و نص التوجيه نص. استدعاء سوف نحو Session تاريخ إضافة دخول معامل، نص و نيل دقيق إدخال صورة. داخل ربط صورة بايت لا دخول نموذج مرئي تاريخ.

#### KV Cache أثر

ثابت أداة دليل سوف إبقاء أداة تعريف بادئة. نتيجة إلحاق إلى تاريخ؛ أكثر تبديل مزود أو دليل ممكن خفض منخفض بادئة إعادة استخدام معدل.

## معروف حد و انتظار إنجاز أمر بند

<a id="known-limitations-and-deferred-work"></a>

هذا تجميع صار إبقاء ثابت إصدار خادم متصفح و أداة حد.

- فقط دعم حمل Chromium؛ غير ممكن اختيار Firefox أو WebKit.
- بدء فشل أو إلغاء سوف رفض Session إنشاء أو استعادة، و إطلاق عميل تنظيف. قطع فتح عميل لن إعادة محاولة؛ إصلاح سبب بعد، إنشاء جديد Session، أو إزالة و استعادة قد لديه Session.
- اتصال وحيد احتلال فقط في هذا مزود نسخة داخل صالح. أخرى عملية و متصفح مستخدم ما زال يمكن تعديل نفسه صفحة.
- مشترك مورد خادم دليل يمكن عرض وراثة خادم اسم، لكن لن منح إعطاء مقابل أخرى Session متصفح وصول إذن.
- إلغاء لن سحب إلغاء قد إرسال إعطاء متصفح تنقل، نقر أو أخرى عملية.
- أداة schema تتبع مع ثابت فعلي تحقق اعتماد إصدار، لا تحمل وعد DSH مستقر صفة.
