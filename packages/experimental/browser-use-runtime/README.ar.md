# @deepseek-ai/dsh-experimental-browser-use-runtime

[English](README.md) | العربية

## عام وصف

متصفح مزود استخدام هذا مكتبة، في واحد Session كثير عدد جولة بين إعادة استخدام متصفح، و في هذا Session وقت التشغيل تحرير وقت إغلاق ذلك مورد. واحد Session عملية حسب ترتيب تشغيل، عزل Session فإن يمكن مستقل دفع دخول. مرفق إضافة نمط سوف واحد خارجي متصفح إبقاء إعطاء مفرد عدد Session. هذا مكتبة أيضا اتصال مزود يملك MCP خادم، و في Session أول مرة نموذج طلب قبل اكتشاف ذلك أداة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

هذا عام مشترك فعلي تحقق صفة مكتبة هو متصفح مزود اعتماد. هو لا يوجد إضافة مدخل أو تركيب إعداد.[متصفح عملية خدمة](../../browser-use/browser-use/README.ar.md) إبقاء مستقل في هذا مكتبة.

أصلي مزود من حزمة أصل مدخل بنية صنع `SessionResources`، توفير مورد نيل أخذ و تنظيف عودة ضبط. استدعاء نحو `run()` نقل تمرير تأكيد قطع فوري Agent؛ بطلان كل من و وحيد احتلال مرفق إضافة ثاني عدد كل من في نيل أخذ مورد قبل فشل. إلغاء مورد نيل أخذ انتظار لن إنهاء ابتدائي تحويل، نفس Session أخرى استدعاء جهة ما زال يمكن متابعة انتظار؛ تحرير Session سوف في توقف و انتظار هذا ابتدائي تحويل انتهاء. مزود سوف تسجيل إبقاء إلى `dispose()` إتمام.

MCP مزود استخدام `@deepseek-ai/dsh-experimental-browser-use-runtime/mcp` في `mountSessionMcp`، توفير ثابت خادم اسم، يمكن تنفيذ ملف، معامل و كل حق سياسة. مساعد مساعدة مكتبة في كل لاحق Agent `agent/created` حدث في انتظار مرة لديه أثر مجال عميل بدء و اكتشاف محاولة تجربة.Agent إنشاء أو استعادة في اكتشاف إتمام بعد انتهاء، مع بعد عندئذ تشغيل ترتيب طابور إدخال؛ نجاح عميل عبر جولة عودة هذا Session كل.

مرفق إضافة اتصال يتم احتلال استخدام وقت، هذا مرة تنشيط دائم دائم قفز مرور بدء، لكن أخرى عمل متابعة تشغيل. اتصال تحرير لن إطلاق يتم قفز مرور تنشيط إعادة محاولة؛ جديد إنشاء أو استعادة Agent يمكن نيل أخذ اتصال. بدء فشل أو إلغاء سوف رفض Agent إنشاء أو استعادة، و إطلاق يتضمن عميل تنظيف إنشاء تراجع. إعادة وصل قد منع استخدام. تحميل أو إعادة تحميل مزود فقط أثر في لاحق Agent تنشيط.

استدعاء جهة في انتظار Agent إنشاء أو استعادة إتمام بعد، يكفي فحص نص التوجيه تجميع و أثر مجال أداة تعريف.

إشارة نحو هذا خادم متصفح استدعاء الأداة و مورد طلب استخدام نفس طابور صف، كما اشتراط استدعاء Session ذاتي ذات يملك اتصال. أخرى MCP خادم ما زال يمكن استخدام. لا يوجد كل حق وقت سوف حذف وراثة خادم إشارة توجيه؛ مشترك خادم اسم دليل إبقاء معتاد قاعدة أثر مجال سلوك.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ داخلي آلية — انقر للتوسيع</summary>

[مورد إدارة جهاز](src/index.ts) بـ فوري Agent هوية لـ كل حق مفتاح، و سوف عملية إلغاء و كل من تحرير صلة ربط بدء قدوم. كل مورد فقط لديه واحد نيل أخذ promise و واحد عملية طابور صف. نيل أخذ فشل وقت، فقط في مزود عودة ضبط تراجع قد نيل أخذ مورد بعد تحرير إبقاء.

بسبب تحرير بينما إلغاء وقت، في AgentHandle انتظار فارغ خامل قبل بدء مورد تنظيف. تنظيف أولا إغلاق مورد مجددا انتظار تشغيل في عملية، جعل اتصال تنظيف قدرة كاف في قطع لا دعم حمل abort فوق تنقل API. إغلاق فشل سوف رفض تحرير و إبقاء كل حق.Agent أثر مجال تنظيف منع توقف استخدام نفس حمل دائم id استعادة Session وراثة قبل متصفح.

[MCP مساعد مساعدة مكتبة](src/mcp.ts) في سلسلة سطر `agent/created` في بناء قيام اتصال؛[AgentLoop](../../core/agent-loop/README.ar.md#understand-the-implementation) إبقاء ترتيب طابور إدخال و مسؤول إنشاء تراجع. نص التوجيه تجميع قراءة قد ابتدائي تحويل دليل. مساعد مساعدة مكتبة في مورد تنظيف خلال إبقاء مزود تسجيل، و عبر [MCP عميل](../../mcp/mcp-client/README.ar.md) معالجة نقل،schema اكتشاف، نتيجة تحويل و حمل دائم رسم مثل وصل قبول.

لا إصدار وقت التشغيل ثابت كمية مرافق مع مدخل: مورد كل حق و انتظار معالجة عمل هو خاص دورة الحياة حالة، لا يوجد يمكن توفير مقارنة مقارنة مستقل صيانة وقت التشغيل إسقاط. الذي تابع اختبار تغطية عزل، تحرير و تنظيف فشل.

</details>

<a id="model-experience"></a>
## تجربة النموذج

عبر مزود يملك متصفح أداة بين وصل أثر نموذج،MCP مساعد مساعدة مكتبة في نموذج طلب تجميع قبل اكتشاف ذلك دليل؛ مزود و MCP عميل يملك وصف،schema، نتيجة و رسم مثل سلوك.

#### KV Cache أثر

هذا مكتبة لا إضافة تلميح نص. اكتشاف أداة schema و مزود إشارة توجيه قرار طلب بادئة تغير؛ معتاد قاعدة متصفح مورد إعادة استخدام لا تغيير هذه schema.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

مزود ما زال مسؤول ذاتي ذات توفير متصفح عملية.

- **MCP تنشيط** — مزود لا وصل إدارة قد لديه نشط حركة Agent؛ يتم احتلال استخدام مرفق إضافة اتصال لن في هذا مرة تنشيط في إعادة محاولة.
- **مرفق إضافة نطاق** — وحيد احتلال كل حق أثر في واحد مورد إدارة جهاز، لا قيد مستقل مزود، عملية أو خارجي متصفح عميل.
- **إلغاء** — abort إشارة و اتصال إغلاق لا يمكن سحب إلغاء قد تسليم متصفح عملية. معا تجاهل اختصار اثنان من فوق تنقل عملية ممكن تأخير متأخر تنظيف.
- **استعادة** — إغلاق فشل سوف إبقاء كل حق؛ هذا إدارة جهاز لا إعادة محاولة تحرير، أيضا لا من Session سجل استعادة متصفح حالة.
