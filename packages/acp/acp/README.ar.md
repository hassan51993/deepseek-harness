# @deepseek-ai/dsh-acp

[English](README.md) | العربية

## عام وصف

`dsh-acp` يجعل تلقي معلومة برنامج عبر معيار [ACP](https://agentclientprotocol.com) تلقائي عملية حمل دائم DeepSeek Harness agent: إنشاء أو استعادة جلسة، اختيار نموذج و دفع إدارة قوي درجة، تركيب MCP خادم، إيداع أو إلغاء عمل، استقبال دلالة تحديث، و مستقل إغلاق جلسة. عملية خارج subagent، اختبار تشغيل جهاز و نص برمجي تحويل تحكم جهاز ملائم دمج اختيار هو؛ هو لحظة معنى لا توفير DSH مخصص استخدام عرض بيانات و تفاعل صيغة UI وظيفة. حفظ دائم دعم حمل عبر عملية إعادة بدء صف خروج، استعادة و إغلاق جلسة، لكن لا دعم حمل حذف،fork،transcript(نص سجل) إعادة تشغيل و مرفق إضافة دليل. تشغيل `pnpm dsh --profile acp` يمكن بدء خادم؛ مستودع عميل استخدام `dsh-subagent-acp`.

## استخدام هذه الحزمة

عند نص برمجي، اختبار تشغيل جهاز أو آخر عدد harness حاجة عبر معيار تلقائي تحويل بروتوكول طرف إلى طرف تشغيل agent عمل وقت، استخدام هذه الحزمة. معتاد استخدام مسار هو: بدء خادم، إنشاء أو استعادة جلسة، حسب يحتاج تركيب MCP خادم و اختيار نموذج خيار، إرسال نص التوجيه، إزالة استهلاك دلالة تحديث، مجددا إغلاق جلسة.

### أي وقت اختيار

عند تلقائي تحويل ينبغي يملك تفاعل وقت اختيار هو: إدارة حمل دائم جلسة، أداة، نموذج اختيار و إذن عملية خارج subagent، اختبار تشغيل جهاز أو نص برمجي تحويل تحكم جهاز. عند شخص صنف حاجة DSH مخصص استخدام عرض بطاقة، حساب تخطيط، عنوان،todo، طرفية عرض أو elicitation وقت طلب تجنب فتح؛ هذا خادم لحظة معنى فقط توفير معيار ACP v1 واجهة.

### الأكثر صغير إعداد

خادم إنشاء كل جلسة كل استخدام هذا موضع إعداد مزود و نموذج. اثنان عدد حقل كل هو اختياري، بـ سهل من آخر عدد agent/request مستمع توفير؛ يمكن تشغيل عرض عرض تركيب سوف معا ضبط اثنان من.Stdout فقط تحمل تحميل بروتوكول تدفق كمية، لذلك طلب يجعل سجل بعيد مغادرة هو.

```yaml
- name: '@deepseek-ai/dsh-acp'
  config:
    provider: deepseek-official
    model: deepseek-v4-pro
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `provider` | — | كل جلسة agent مزود توجيه |
| `model` | — | كل جلسة agent نموذج |
| `sessionListPageSize` | `100` | مفرد صفحة `session/list` إرجاع الأكثر كبير ملخص عدد كمية |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-acp) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### بدء خادم

`pnpm dsh --profile acp` سوف بدء مع مرفق stdio خادم.`acp` profile سوف تركيب جلسة حفظ دائم، لذلك عميل يمكن صف خروج، استعادة و إغلاق حمل دائم جلسة.[`@deepseek-ai/dsh-subagent-acp`](../../subagent/subagent-acp/README.ar.md) سوف بدء نفس profile قدوم تنفيذ عملية خارج تفويض إرسال.

<a id="protocol-contract"></a><a id="standard-acp-v1-surface"></a>
### بروتوكول اتفاق

واحد اتصال يمكن معا تشغيل كثير عدد جلسة، ذاك هذا مستقل. عميل إرسال خروج استدعاء مثل تحت:

| استدعاء | أنت سوف نيل إلى ماذا |
|---|---|
| `initialize` | مستقر ACP v1، و `session/list`،`session/resume`،`session/close` و Streamable HTTP MCP دعم حمل؛ صورة نص التوجيه فقط في حمل دائم مرفق عنصر تخزين و إعداد تأكيد قطع توجيه دعم حمل وقت عام نشر. |
| `authenticate` | قيام أي نجاح؛ خادم لا حاجة هوية تحقق. |
| `session/new` | كل جديد حمل دائم agent؛ ذلك قطعا مقابل مساحة العمل و stdio أو HTTP MCP خادم سوف في إصدار قبل عبر تحقق، و إرجاع كامل إعداد خيار حالة. |
| `session/list` | حسب تحديد جديد إلى قديم ترتيب قسم صفحة إرجاع قد حفظ دائم، يمكن استعادة أصل جلسة؛ اختياري قطعا مقابل `cwd` غربلة اختيار سوف كل ممكن استخدام شيء إدارة دليل معرف. |
| `session/resume` | استعادة واحد قد حفظ دائم كما غير نشط وثب جلسة؛ تركيب قبل تحقق ذلك مواصفة مساحة العمل، و استعادة سجل لكن لا إعادة تشغيل قديم تحديث. |
| `session/close` | توقف مستقر صيغة إلغاء، تحديث drain، بعد بديل تحرير، حفظ دائم flush، و كما فقط تحرير إشارة تحديد Agent أثر مجال. |
| `session/set_config_option` | سلسلة سطر تحديث عام نشر `model` أو `reasoning_effort`، و إرجاع كامل نتيجة حالة. |
| `session/prompt` | لديه ترتيب نص، مورد رابط و تلقي دعم حمل صورة، كل جلسة مرة واحد نص التوجيه؛Agent فارغ خامل كما لديه ترتيب تحديث تسليم بعد عندئذ تسوية. |
| `session/cancel` / `$/cancel_request` | نص التوجيه الذي يملك إلغاء مسار؛ لا يوجد إجراء في ACP نص التوجيه وقت إلغاء ذاتي رئيسي عمل، لم معرفة جلسة id فإن لـ فارغ عملية. |
| `session/update` | قد إيداع assistant رسالة و thought، عام أداة دورة الحياة، إعداد تغير و سياق استخدام كمية، حسب جلسة سلسلة سطر تسليم. |
| `session/request_permission` | حمل مرة صفة سماح/رفض خيار إذن تلميح؛ أنت عميل يمكن تلقائي عودة جواب. |

جلسة إعداد من فوري LLM(كبير لغة نموذج) خدمة دليل توفير لا نفاذ واضح مزود/نموذج خيار، و في تأكيد قطع نموذج إعلان دفع إدارة خيار وقت توفير `reasoning_effort`. نص التوجيه سوف في مختلف خطوة صورة دقيق دخول قبل لقطة هذا اختيار، و في هذا جولة كل نموذج خطوة في ثابت هو؛ تزامن خيار تغيير من تحت واحد جولة بدء توليد فاعلية.ACP عميل هو تلقي معلومة تحكم جهاز:stdio MCP بند تخويل ذلك قطعا مقابل أمر و بيئة،HTTP بند تخويل ذلك قطعا مقابل HTTP(S) URL و header؛ ابتدائي اتصال أو اكتشاف فشل سوف تراجع بعد لم إصدار Agent. لا دعم حمل واجهة سوف يتم حذف أو رفض:`session/load`، حذف،fork، مرفق إضافة دليل،SSE(Server-Sent Events) أو ACP نقل MCP،mode، أمر، حساب تخطيط، طرفية، عميل نظام الملفات عملية و elicitation.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خادم مثل أي تنفيذ فوق وصف سلوك، و إشارة خروج تنفيذ هو شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

خادم هو لحظة معنى اعتماد معيار عام بروتوكول تلقائي تحويل نقل. ثلاثة بند تحمل وعد تشكيل صنع هو:

- **فقط إرسال معيار دلالة تحديث.** بروتوكول تحمل تحميل قد إيداع رسالة و thought، عام أداة دورة الحياة، إعداد و سياق استخدام كمية؛ أصلي مزود زيادة كمية، إعادة محاولة محاولة تجربة،DSH عرض بيانات و لا تلقي دعم حمل محتوى لن دخول بروتوكول.
- **صدق فعلي قدرة و إعداد حالة.** `initialize` فقط عام نشر قد تركيب دعم حمل، توسيع اندفاع تغير سوف إصدار كامل إعداد خيار، نص التوجيه فإن ثابت ذلك دقيق دخول وقت تأكيد قطع توجيه.
- **توقف مستقر بعد عندئذ تسوية.** نص التوجيه و إغلاق عملية فقط في ذلك يملك دقيق دخول،Agent نشط حركة، لديه ترتيب تحديث، بعد بديل، حفظ دائم و تحرير بلوغ إلى الذي يحتاج نهاية حالة بعد عندئذ تسوية.

قرار تاريخ سجل في [ACP بصفة فقط موجه إلى تلقائي تحويل بروتوكول قلم تسجيل](../../../.agents/notes/implemented/simplification/2026-07-23-acp-automation-only-protocol.ar.md) و[كثير جلسة قلم تسجيل](../../../.agents/notes/archived/feature/2026-06-14-acp-multi-session.md) في.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema،`AgentSideConnection` وصل خط، حسب جلسة سجل، دقيق دخول و تسوية، تنظيف |
| [`src/content.ts`](src/content.ts) | بروتوكول محتوى دقيق دخول و إسقاط: صورة تحقق، توجيه إعادة فحص، نص التوجيه إعادة بناء،assistant كتلة تحويل |

### دقيق دخول و نص التوجيه تسوية

كل جلسة فقط سماح واحد صحيح في معالجة نص التوجيه. دقيق دخول أولا تحقق كامل نص التوجيه دفعة مرة، لقطة الذي اختيار توجيه، إعادة فحص Agent هل لـ نفس كائن و صورة قدرة، حفظ دائم صورة مرفق عنصر، لكن بعد عندئذ يأخذ مستخدم رسالة دخول طابور——أولا في دقيق دخول إتمام إلغاء أبدا سوف يجعل متأخر إلى جولة دخول طابور. دخول طابور بعد، جلسة وحدة سوف سوف هذا لقطة و inbox رسالة صلة ربط بدء قدوم، مباشر حتى هذا رسالة يتم إقرار قيادة، و في نص التوجيه متغير و هذا جولة كل نموذج خطوة في ثابت نفسه مزود، نموذج و دفع إدارة قوي درجة. حسب جلسة تحديث سوف سلسلة سطر تسليم؛ قد إيداع صورة سوف إعادة قراءة و تحقق كامل صفة، لذلك صورة ناقص أو ضرر تالف سوف يجعل صلة ربط نص التوجيه فشل، بينما لا هو إرسال خروج احتلال موضع رمز. تسوية أولوية درجة اعتماد مرة لـ صريح إلغاء، قد إيداع إخراج فشل، منطقة بين داخل Agent فشل، صلة ربط جولة انتهاء.

### تنظيف و اتصال ملكية

كل جلسة وحدة يملك ذلك Agent جملة مقبض،MCP تركيب، لم قدوم و جولة ثابت نموذج اختيار، نص التوجيه مجرى موضع، تحديث سلسلة و تسجيل ذاكرة تحويل إغلاق عملية. صريح إغلاق، عميل قطع فتح و Cordis تحرير استخدام نفس توقف مستقر صيغة تنظيف مسار: إيقاف جديد عمل، إلغاء نص التوجيه دقيق دخول و Agent نشط حركة،drain قد إيداع تحديث، حسب فرعي أولوية ترتيب تحرير يمكن متابعة بعد بديل،flush حفظ دائم و تحرير الذي يملك Agent أثر مجال. جلسة إغلاق بعد، قد حفظ دائم حالة ما زال يمكن توفير صف خروج و استعادة؛ مشترك سياق أخرى جلسة أو قبل طرف لا تلقي أثر.

<a id="model-experience"></a>
## تجربة النموذج

### نص التوجيه محتوى

#### نموذج يرى ماذا

`session/prompt` سوف في واحد بند مستخدم رسالة في إبقاء نص و صورة ترتيب: متبادل مجاور نص سوف تجميع وصل، مورد رابط فإن يمثل لـ حمل جهة تضمين رقم `[resource_link name=… uri=…]` مرجع، نموذج يمكن استخدام ذاته أداة فتح هو. داخل ربط صورة base64 في دفعة كمية دقيق دخول بعد أي يتم إسقاط، لذلك حمل دائم رسالة فقط يتضمن مرور مرور تحقق مرفق عنصر مرجع. بروتوكول بيانات وصفية، عميل قدرة، إذن اختيار و جلسة id أبدا دخول نموذج طلب.

#### Token أثر

نص التوجيه محتوى، أداة استدعاء/نتيجة و حمل دائم صورة مرجع سوف إبقاء في هذا جلسة في مباشر إلى سياق ضغط (context compaction). تزامن جلسة إبقاء مستقل سياق.

#### KV Cache أثر

فقط يلزم الذي اختيار توجيه و تجميع بعد بادئة إبقاء ثابت، حينئذ فقط إلحاق. نموذج تغيير سوف جعل تحت واحد ACP جولة تعديل استخدام جديد توجيه.

### إذن قرار

#### نموذج يرى ماذا

لن مباشر يرى أي محتوى. الذي تابع أداة عبر معتاد قاعدة أداة نتيجة مسار سجل ذلك نتيجة: سماح، رفض، إلغاء أو غير ممكن استخدام.

#### Token أثر

فقط لديه الذي تابع أداة نتيجة سوف مساهمة token.

#### KV Cache أثر

فقط عبر الذي تابع أداة نتيجة إلحاق.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه الحزمة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو بروتوكول مقابل مقارنة أو مهمة تراكم ضغط.

- **فقط واحد رئيسي workspace**——مرفق إضافة دليل ما زال لا دعم حمل.
- **فقط ضوء شبكة نص التوجيه صورة**——PNG،JPEG،WebP و GIF اشتراط حمل دائم مرفق عنصر تخزين و تأكيد قطع صورة قدرة توجيه.
- **فقط MCP أداة**——MCP resource و prompt لا يوجد DSH مستهلك.
- **لا يوجد transcript إعادة تشغيل أو تفاعل صيغة توسيع**——جلسة حذف،fork،`session/load`،mode، أمر، حساب تخطيط، طرفية، عميل نظام الملفات عملية و elicitation ما زال لا يخص هذا تلقائي تحويل واجهة.
