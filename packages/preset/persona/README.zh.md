# @deepseek-ai/dsh-persona

[English](README.md) | العربية

## عام وصف

`dsh-persona` يجعل مفرد عدد agent(ذكي جسم) يملك ذاتي ذات شخص ضبط:preset تركيب هذا واحد يمكن تجميع سطر قدوم تسجيل شخص ضبط بادئة و بعد لاحقة مقطع سقوط، لـ هذا جلسة حجب حجب نشر درجة قيمة افتراضية. هو أيضا يمكن يأخذ بادئة تغيير صار هذا جلسة كامل توجيه النظام، كبح صنع كل أخرى مقطع سقوط، و يمكن لـ هذا جلسة إغلاق حركة حالة runtime-context لقطة. طلب يأخذ هو تعليق في preset تجميع داخلي——عام تركيب سوف و نص التوجيه سجل التسجيل ذاته شخص ضبط تسجيل متبادل اصطدام و واضح تقرير خطأ. لا يوجد هذا واحد سطر،preset قدرة تغيير agent أداة، لكن دائم بعيد تعديل لا هو هوية.

## استخدام هذه الحزمة

في preset تجميع داخلي تركيب هذا سطر، يجعل هذا preset جلسة يملك ذاتي ذات شخص ضبط. هذا سطر حاجة agent scope: في scope خارج تركيب سوف و نص التوجيه سجل التسجيل ذاته `deployment:persona-prefix` تسجيل متبادل اصطدام و واضح تقرير خطأ——نشر درجة شخص ضبط قد لديه ملكية، بينما هذا سطر وجود معنى معنى صحيح هو لـ بعض واحد agent حجب حجب هو.

### إعداد

```yaml
- name: '@deepseek-ai/dsh-persona'
  config:
    prefix: You are a terse systems engineer who answers in short commands.
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `prefix` | لا بد ملء | بصفة `deployment:persona-prefix` مقطع سقوط تصيير شخص ضبط نص |
| `suffix` | `''` | `deployment:persona-suffix` نموذج لوح؛ حذف أو فارغ نص سوف حجب حجب إسقاط عام بعد لاحقة |
| `complete` | `false` | فقط سوف تصيير بعد بادئة استخدام عمل توجيه النظام؛ تجاهل اختصار بعد لاحقة |
| `includeRuntimeContext` | `true` | هل لـ هذا agent أثر مجال يتضمن حركة حالة runtime-context لقطة؛false سوف كبح صنع كل سياق مساهمة، لكن لا منع استخدام يملك هو جمع خدمة |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-persona) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### شخص ضبط سلوك

شخص ضبط `prefix` و `suffix` كل هو نموذج لوح: كامل `{{…}}` مجموعة في نص التوجيه**تصيير**وقت (بينما غير تجميع وقت) صارم إطار تحليل لـ قد تسجيل نص التوجيه متغير. كل فارغ نموذج لوح ما زال سوف حجب حجب مقابل نشر درجة مقطع سقوط، لكن بعد في تصيير وقت إزالة فقد. حذف `suffix` وقت افتراضي لـ فارغ، لا وراثة عام بعد لاحقة. تفعيل `complete: true` وقت، تجميع ما زال سوف تحليل سياق، أداة، متغير و تنسيق عمل صيغة مستمع، لكن نص التوجيه سجل التسجيل سوف يأخذ هذا تأكيد قطع بادئة استعادة لـ وحيد مقطع سقوط؛ هوية، بعد لاحقة، أداة جذب توجيه أو مستمع كل لا يمكن إلحاق نص التوجيه نص. تفعيل `includeRuntimeContext: false` وقت، هذا أثر مجال سياق مزود لن يتم طلب قيمة، تجميع مستمع إضافة سياق أيضا سوف يتم إسقاط.

### أي وقت استخدام

عند preset يجب تغيير agent هوية، بينما لا فقط هو أداة وقت، استخدام هذا سطر. نشر درجة شخص ضبط ذاته إعداد في `dsh-system-prompt` سطر فوق، لا في هذا داخل؛ هذا سطر فقط لأجل لـ بعض واحد agent حجب حجب أو استبدال هو.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### هذا سطر مثل أي تسجيل

هذا سطر استخدام سجل التسجيل مشترك اسم و أداة اسم ترتيب قدوم تسجيل حمل أثر مجال شخص ضبط بادئة و بعد لاحقة مقطع سقوط. اثنان من قسم آخر حجب حجب مقابل نشر قيمة افتراضية، بينما لا هو ظهور في ذلك جانب حافة؛ ترتيب ترتيب، إدراج قيمة و كامل نص التوجيه تنفيذ عودة سجل التسجيل كل.`includeRuntimeContext: false` سوف استدعاء `ctx.systemPrompt.suppressRuntimeContext()`.

### هذا سلوك أي فقط حد scope داخل استخدام

`dsh-system-prompt` بـ ذاته إعداد يحتفظ عام شخص ضبط و بلا شرط تسجيل `deployment:persona-prefix`، لذلك واحد عملية فقط لديه واحد نسخة. هذا سطر في agent scope خارج و هذا بند تسجيل متبادل اصطدام، هذا هو لحظة معنى: هذا سطر وجود هو لأن preset لا يمكن ذاتي سطر تركيب نص التوجيه سجل التسجيل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema، شخص ضبط مقطع سقوط تسجيل،runtime-context كبح صنع |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا سطر لا يملك حدث تدفق أو متغير وقت التشغيل بيانات، بينما هو تسجيل نص التوجيه مقطع سقوط؛ هوية، كامل نص التوجيه قوي صنع تنفيذ، حجب حجب و مورد تحرير متساو عودة نص التوجيه سجل التسجيل. |

<a id="model-experience"></a>
## تجربة النموذج

### شخص ضبط مقطع سقوط

#### نموذج يرى ماذا

يقع في order `0` `deployment:persona-prefix` مقطع سقوط يحمل هذا سطر `prefix`؛ يقع في order `10200` `deployment:persona-suffix` في رقم واحد جهة إشارة توجيه بعد يحمل ذلك `suffix`. اثنان من قسم آخر استبدال مقابل نشر قيمة افتراضية، و تحليل نص التوجيه متغير. في كامل نمط تحت، نموذج فقط سوف يرى تصيير بعد بادئة مقطع سقوط بصفة توجيه النظام.Runtime context افتراضي إبقاء تفعيل؛ منع استخدام بعد، جديد بناء agent لن استلام إلى قدوم ذاتي صندوق رملي سياسة، دفعة دقيق سياسة، تفويض إرسال أو أخرى system-prompt سياق مزود runtime-context لقطة.

#### Token أثر

مقابل إعطاء تحديد preset بينما قول هو ثابت: هذا agent كل مرة طلب كل يحمل شخص ضبط بادئة و بعد لاحقة token، أخرى agent واحد كل لا حمل. فارغ نص لا مساهمة أي token. كامل نمط سوف إزالة هذا agent أخرى كل توجيه النظام token.

#### KV Cache أثر

تصيير بعد نموذج لوح متغير و نص ثابت وقت، بادئة إبقاء مستقر. نموذج، بادئة و أداة متسق وقت، بعد لاحقة تغير لا تغيير قبل وضع إشارة أمر. بادئة تغير سوف أثر اعتماد قبل بادئة؛ لا حفظ إثبات مزود مشترك ذاكرة مؤقتة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا سطر أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **لا دعم حمل عام تركيب**——نص التوجيه سجل التسجيل يملك لم إضافة scope شخص ضبط مجرى موضع، لذلك هذا سطر فقط قدرة من حمل scope تجميع في استخدام. يلزم تغيير نشر درجة شخص ضبط، ينبغي في `system-prompt` سطر ذاته إعداد في تعديل.
- **runtime-context كبح صنع هو كل لديه أو كل بلا**——`includeRuntimeContext: false` سوف إغلاق هذا أثر مجال كل سياق مساهمة، يشمل صندوق رملي سياسة، دفعة دقيق سياسة و تفويض إرسال؛ لا يوجد حسب مزود مرور ترشيح خيار.
