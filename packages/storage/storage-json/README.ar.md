# @deepseek-ai/dsh-storage-json

[English](README.md) | العربية

## عام وصف

`dsh-storage-json` في إعداد أصل دليل تحت يأخذ مجال بيانات تخزين لـ يمكن قراءة JSON، و تسجيل لـ خلفية `json`. افتراضي `single` تخطيط لـ كل وحدة حفظ واحد نسخة كامل `<unit>.json` ملف؛`per-record` تخطيط لـ كل بند سجل حفظ واحد نسخة حمل إصدار ختم وثيقة. اثنان نوع تخطيط كل بـ أصل فرعي طريقة إصدار كل تغيير ملف، مجال طبقة مسؤول أمان ترتيب استدعاء ترتيب. عند تشغيل صيانة جهة حاجة يمكن فحص ملف كما الذي اختيار تخطيط ملائم دمج كتابة كمية وقت اختيار هو؛ مقابل في أكثر كبير أو عال تزامن بيانات فإن اختيار SQLite. هذا خلفية فقط موجه إلى مضيف جانب، لا مساهمة نص التوجيه، أداة أو schema.

## استخدام هذه الحزمة

عند تركيب حاجة يمكن قراءة، يمكن تحرير JSON تخزين وقت استخدام هذه الحزمة. يأخذ متبادل صلة مجال توجيه إلى `json` خلفية؛ كل مجال مواصفة اختيار `single` أو `per-record` تخطيط.

### أي وقت اختيار

صغير نوع وحدة حاجة واحد نسخة كامل، جميل تحويل ضرب طبع ملف وقت، اختيار افتراضي `single` تخطيط. تحديد نقطة كتابة فقط ينبغي استبدال واحد نسخة سجل وثيقة وقت، اختيار `per-record`. عند بيانات كمية كبير، كتابة تردد كثيف أو كثير بند سجل حاجة أمر خدمة تحديث وقت، اختيار SQLite خلفية.

### إعداد

وحيد إضافة حقل هو `root`، لأجل حفظ وحدة ملف و دليل. هو هو لا بد ملء بند، لأن هذا خلفية لا رجوع إلى `process.cwd()`. خلفية حسب يحتاج بـ `0o700` نمط إنشاء أصل دليل. مجال مواصفة اختيار ذلك تخطيط؛ هذا إضافة لا توفير تخطيط تغطية بند.

```yaml
- name: '@deepseek-ai/dsh-storage'
- name: '@deepseek-ai/dsh-storage-json'
  config:
    root: /var/lib/dsh/data
- name: '@deepseek-ai/dsh-storage-domain'
  config:
    backend: json
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `root` | لا بد ملء | حفظ `<unit>.json` ملف و `<unit>/` دليل شجرة دليل؛ حسب يحتاج بـ `0o700` إنشاء |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-storage-json) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### يمكن مراقبة سلوك

ناقص `single` ملف أو `per-record` دليل سوف بصفة فارغ وحدة فتح، و في رقم مرة كتابة وقت شيء تحويل. في `single` في، شاذ شكل محتوى بـ `malformed-medium` رفض، مختلف قد تخزين إصدار بـ `version-mismatch` رفض. في `per-record` في، كل نسخة شاذ شكل أو غير ممكن قراءة وثيقة، و إصدار لا في وصف رمز حالي إصدار و توافق إصدار داخل وثيقة، كل قراءة عمل سجل لا وجود، لذلك مفرد عدد تالف وثيقة لن جعل وحدة يتم رفض. سجل مفتاح يجب مطابقة `[a-zA-Z0-9_-]+`؛ لا أمان مفتاح في أي ملف عملية قبل يتم رفض. كل مرة قد إتمام كتابة كل قد حفظ دائم، إغلاق بعد عملية بـ `closed` رفض.

فقط لديه عند مصدر وحدة اسم مطابقة، كما مصدر إصدار لـ حالي إصدار أو قد إعلان توافق إصدار وقت، فارغ `per-record` دليل شجرة عندئذ يمكن من صالح `<root>/<unit>.json` كامل وحدة وثيقة ابتدائي تحويل ذلك قد إعلان جدول. خلفية إبقاء هذا مصدر ملف ثابت، و لـ ترحيل سجل كتابة حالي إصدار ختم. قبول تجميع دمج خارج مصدر إصدار سوف جعل جديد دليل شجرة إبقاء لـ فارغ. قد إعلان جدول في فقط يلزم وجود مهمة معنى وثيقة مسار، أو وجود قد إعلان `global.json`، حينئذ سوف مقابل كامل وحدة منع توقف هذا ابتدائي تحويل، أي جعل هذا وثيقة غير ممكن قراءة أو إصدار قديم قديم.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

اثنان نوع تخطيط مشترك أصل فرعي إصدار آلية، لكن بـ مختلف طريقة تحديد حالة كل حق.`single` يملك واحد نسخة داخل تخزين وحدة إسقاط؛`per-record` يأخذ دليل شجرة نظر لـ مرجعي حالة.

### تصميم إدارة فكرة

- **`single` بـ داخل تخزين لـ مرجعي حالة.** كل مرة كتابة كل سوف أكثر تعديل داخل تخزين وحدة، تسلسل تحويل ذلك كامل حالة، و بـ أصل فرعي طريقة استبدال `<unit>.json`. إصدار فشل سوف استعادة أولا قبل داخل تخزين قيمة.
- **`per-record` بـ دليل لـ مرجعي حالة.** كل مرة put أو delete كل سوف أكثر تعديل واحد `<unit>/<table>/<key>.json` وثيقة،`loadAll()` فإن إعادة قراءة دليل شجرة. كل نسخة وثيقة كل حمل لديه وحدة إصدار ختم و واحد بند سجل قيمة.
- **كل مرة استدعاء كل حمل دائم إصدار.** كتابة مرور مسار استخدام مؤقت ملف،fsync، أصل فرعي `rename()` استبدال، و في POSIX فوق fsync أب دليل. مجال طبقة كتابة سلسلة مسؤول أمان ترتيب عبر استدعاء ترتيب.

### ملف صيغة

`single` وثيقة يحمل وحدة معرف، عام مفرد مثال و كل جدول:

```json
{
  "unit": { "name": "workspace", "version": 1 },
  "global": null,
  "tables": { "workspaces": { "<key>": { "path": "/work/demo" } } }
}
```

`per-record` جدول وثيقة يقع في `<root>/<unit>/<table>/<key>.json`، شكل صيغة لـ `{ "version": 1, "record": <value> }`؛ اختياري عام قيمة استخدام `<root>/<unit>/global.json`. صيغة إصدار قدوم ذاتي مجال مواصفة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: خلفية تسجيل،`root` إعداد، وحدة فتح/إغلاق جدول |
| [`src/single-unit.ts`](src/single-unit.ts) | واحد `single` وحدة: مرجعي داخل تخزين، كتابة أصل لغة و إصدار تراجع |
| [`src/per-record-unit.ts`](src/per-record-unit.ts) | واحد `per-record` وحدة: دليل شجرة قراءة، مسار أمان سجل و مفرد وثيقة كتابة |
| [`src/format.ts`](src/format.ts) | حمل إصدار تحقق كامل وحدة و سجل تسلسل تحويل |
| [`src/atomic.ts`](src/atomic.ts) | أصل فرعي ملف استبدال: مؤقت ملف كتابة،fsync،rename، دليل fsync |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا موضع اشتراط حفظ إثبات كتابة حمل دائم صفة و إصدار بعد إعادة تحليل انتظار قيمة صفة، هذا اثنان نقطة حاجة عبر وسيط جودة نحو إرجاع اختبار (مشترك خلفية رمز دمج صفة اختبار طقم عنصر) تحقق؛ هذا خلفية لا عام أي يمكن حمل متابعة مراقبة عملية داخل علاقة. |

</details>

## تجربة النموذج

### قد تخزين مجال سجل

#### نموذج يرى ماذا

بلا. هذا خلفية لا مساهمة نص التوجيه، أداة أو schema؛ هو في `ctx.storage` بعد وجه حفظ دائم غير جلسة مجال بيانات، فقط توفير مضيف جانب مستهلك استخدام.

#### Token أثر

فوري طلب token لـ صفر.

#### KV Cache أثر

بلا: هذا خلفية من لا لمس اصطدام فوري طلب بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خلفية أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **`single` سوف إعادة كتابة كامل وحدة**——كل مرة كتابة كل إعادة إصدار كامل وحدة ملف؛ عند هذا صار هذا مرور عال وقت، استخدام `per-record` أو يأخذ مجال توجيه إلى SQLite.
- **لا يوجد عبر عملية كتابة قفل**——اثنان عدد عملية كتابة نفس وحدة وقت ممكن تسليم خطأ تنفيذ استبدال؛ مقابل نفس ملف كتابة بـ الأكثر بعد إتمام من لـ دقيق.
- **Windows rename لا يوجد صريح write-through**——حمل دائم صفة اعتماد libuv `rename()`(`MoveFileExW` و تفعيل استبدال) ؛`log` قسم وجه سقوط أرض وقت، حساب تخطيط يأخذ جلسة سجل خلفية أكثر صارم إطار Win32 write-through إصدار مساعد مساعدة دالة تحت نقل إلى هذا موضع.
