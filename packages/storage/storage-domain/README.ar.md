# @deepseek-ai/dsh-storage-domain

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة إعلان مرور مرور schema تحقق مفتاح قيمة مجال، و عبر `ctx.storageDomain` في قد إعداد تخزين خلفية فوق فتح هو جمع. قراءة تزامن إرجاع مرور مرور تحقق داخل تخزين حالة؛ كل مرة كتابة في إتمام قبل كل قد بلوغ إلى حمل دائم حالة، و حسب ترتيب إرسال خروج `domain/changed`. منتج حزمة استخدام مجال جملة مقبض، بينما لا مباشر وصول تخزين خلفية. هذه مضيف جانب حالة لن إضافة أداة، نص التوجيه أو جلسة حدث، لذلك نموذج و agent loop(ذكي جسم حلقة) لا يمكن يرى هو جمع.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند مضيف حزمة حاجة حمل دائم، مرور مرور schema تحقق سجل——مساحة العمل سجل، جلسة مرافق مع بيانات وصفية——وقت استخدام هذه الحزمة. من الذي تابع حزمة إعلان مرة مجال؛ مستهلك فتح هو، يكفي نيل نيل تزامن قراءة و حمل دائم، إرسال خروج تغيير حدث كتابة، بينما بلا حاجة لمس اصطدام أي خلفية.

### أي وقت استخدام

أي يجب عبر إعادة بدء إبقاء، و بداية نهاية رمز دمج schema مضيف جانب بيانات كل ملائم دمج هو: مجال بيانات شكل صيغة في فتح وقت تحقق كل بند قد تخزين سجل، كما كل مرة كتابة في resolve قبل كل قد حمل دائم. عند بيانات يخص جلسة حدث سجل وقت طلب تجنب تجنب استخدام هو——ذلك هو جلسة حفظ دائم seam مجال.

### إعلان مجال

الذي تابع حزمة استخدام `defineDomain` إعلان مرة مجال——اسم، إصدار و zod سجل schema——و توجيه خروج هو. اسم غير قاعدة، إصدار لا هو غير سالب كامل عدد، أو عام schema قبول `null` وقت،`defineDomain` سوف في وحدة تحميل وقت واضح تقرير خطأ.

```text
// Owning package, once:
const workspaceSpec = defineDomain({
  name: 'workspace',
  version: 1,
  tables: { workspaces: domainTable(workspaceRecordSchema) },
})
```

### فتح و استخدام مجال

مستهلك عبر `ctx.storageDomain` فتح قد إعلان مجال و يحتفظ إرجاع جملة مقبض؛ قراءة هو تزامن، كتابة هو حمل دائم:

```text
const domain = await ctx.storageDomain.open(workspaceSpec)
await domain.table('workspaces').put(id, { path: '/work/demo' })
const record = domain.table('workspaces').get(id) // synchronous, from memory
domain.table('workspaces').update(id, (r) => ({ ...r, path: newPath }))
```

استدعاء جهة يملك جملة مقبض دورة الحياة، و في وظيفة إغلاق وقت استخدام `domain.close()` تحرير هو (عبر معتاد بصفة ذلك ذاته `ctx.effect` مورد تحرير دالة) ؛ إضافة إزالة وقت، ضبط تطبيق سوف إغلاق ما زال موضع في فتح حالة مجال.

### يأخذ مجال توجيه إلى خلفية

أي عدد خلفية خدمة أي عدد مجال من مجال إضافة إعداد قرار——قطعا غير محور عقدة.`backend` إشارة تحديد افتراضي توجيه؛`routes` حسب مجال اسم تغطية. توجيه إلى لم تسجيل خلفية مجال سوف في فتح وقت بـ `backend-not-found` واضح تقرير خطأ.

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `backend` | لا بد ملء | لم صريح توجيه كل مجال افتراضي خلفية اسم |
| `routes` | `{}` | تدريجي مجال تغطية: مجال اسم → خلفية اسم |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-storage-domain) هو كل تلقي دعم حمل حقل و ذلك JSDoc كامل حق مصدر.

### يمكن مراقبة سلوك و فشل

كل مرة كتابة كل يلزم انتظار خلفية تأكيد قد حفظ دائم بعد عندئذ إتمام، و حسب كتابة ترتيب كل إرسال خروج مرة `domain/changed` حدث. فشل يحمل مستقر `DomainError` شفرة:`already-open`(اسم قد فتح أو ما زال في إغلاق) ،`facet-unsupported`(قد توجيه خلفية لا توفير `kv` قسم وجه) ،`invalid-record`(قد تخزين سجل أو عام لا رمز دمج ذلك schema، و إشارة واضح جدول و مفتاح) ،`missing-key`(مقابل لا وجود سجل تنفيذ `update`) و `closed`(إغلاق بعد أي استخدام).`version-mismatch` انتظار خلفية فشل سوف أصل مثال نفاذ نقل.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

مجال طبقة هو مفرد واحد تنفيذ، بينما غير سحب كائن تحويل seam: مستهلك اعتماد هذه الحزمة، أبدا مباشر لمس اصطدام خلفية، هذا يأخذ كل مجال منطق——schema تحقق، كتابة سلسلة سطر تحويل، تغيير حدث——تجميع في في واحد موضع، بينما لا هو في كل خلفية تكرار واحد مرة.

### تصميم إدارة فكرة

- **spec كائن هو وحيد حق مصدر.** `defineDomain` ثابت spec حرف وجه نوع، و في الذي تابع حزمة وحدة تحميل وقت، أي وسيط جودة يتم لمس اصطدام قبل تحقق ذلك حقل. سجل schema استخدام zod، لذلك `z.infer` يمكن تجنب تجنب تكرار تعريف مستهلك نوع؛ إضافة `Config` ما زال من schemastery مسؤول.
- **داخل تخزين أداة لديه نهائي قرار حق؛ وسيط جودة هو حمل دائم إسقاط.** قراءة تزامن أخذ ذاتي مرور مرور تحقق داخل تخزين حالة. كل مرة كتابة كل في كل مجال واحد بند كتابة سلسلة فوق ترتيب طابور: أولا وصول خلفية حمل دائم حالة، مجددا تغيير داخل تخزين، لكن بعد إرسال خروج `domain/changed`——يتم رفض خلفية كتابة لن لمس اصطدام داخل تخزين، لذلك قراءة دائم بعيد لن و وسيط جودة قسم تقاطع.
- **كل مجال واحد بند كتابة سلسلة.** `put`،`delete`،`update` و `global.set` كل في ذلك فوق ترتيب طابور؛`update` تغيير تبديل في سلسلة فوق ذاتي ذات مجرى موضع تشغيل، لذلك تزامن تحديث أبدا سوف تسليم خطأ. سجل هو عادي غير ممكن تغيير بيانات——قيمة راجعة حينئذ هو قد تخزين كائن ذاته، أبدا قدرة أصل أرض تعديل.
- **كتابة في إيداع نقطة بعد إرسال خروج.** `domain/changed` هو إشعار، لا هو أمر خدمة مشاركة و من: مستمع رمي خروج استثناء وقت، نظام سوف عزل هذا استثناء و سجل تحذير إبلاغ، بينما لن يجعل قد حمل دائم كتابة يتم رفض.

### فتح ترتيب

`DomainFacility.open(spec)` حسب صارم إطار ترتيب تنفيذ، مهمة واحد خطوة فشل كل سوف يجعل كامل استدعاء فشل: رفض قد فتح أو ما زال في إغلاق اسم (`already-open`) ؛ تحليل توجيه (`backend-not-found`) ؛ اشتراط `kv` قسم وجه (`facet-unsupported`) ؛ فتح وحدة (خلفية `version-mismatch`/`malformed-medium` نفاذ نقل) ؛ تحميل و أصل حسب spec schema تحقق كل بند قد تخزين سجل و عام (`invalid-record`) ؛ بنية صنع مجال. استدعاء جهة يحتفظ جملة مقبض؛ ضبط تطبيق سوف في إزالة وقت إغلاق أي ما زال فتح مجال، قد إغلاق مجال اسم فقط في مورد إلغاء تدمير إتمام بعد عندئذ قدرة إعادة فتح.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`DomainFacility`، توجيه،`Config`، بيانات شكل صيغة تركيب |
| [`src/spec.ts`](src/spec.ts) | مجال إعلان:`defineDomain`،`domainTable`، وصف رمز إسقاط |
| [`src/domain.ts`](src/domain.ts) | قد فتح مجال وقت التشغيل: كتابة سلسلة، جدول و عام جملة مقبض، إغلاق |
| [`src/events.ts`](src/events.ts) | `domain/changed` حدث مفردات |
| [`src/error.ts`](src/error.ts) | `DomainError` شفرة |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة: كل بند `domain/changed` و داخل تخزين حالة متسق |

### ثابت صيغة

`storage-domain-invariant` مرافق توليد إضافة تسجيل هذا بند الذي تابع علاقة: كل بند `domain/changed` حدث في إرسال خروج وقت كل يجب و الذي تابع مجال مرجعي داخل تخزين حالة متسق——ظهور قسم تقاطع معنى طعم حال بعض بند كتابة مسار قفز مرور كتابة سلسلة أو إرسال خروج قديم قديم قيمة.

<a id="model-experience"></a>
## تجربة النموذج

### حمل دائم مجال حالة

#### نموذج يرى ماذا

بلا. هذه الحزمة لا تسجيل أداة، لا حقن نص التوجيه، أيضا لا إلحاق جلسة حدث؛ هو في `ctx.storageDomain` بعد وجه تخزين غير جلسة بيانات، فقط إرسال خروج عملية داخل `domain/changed` حدث. فقط لديه مستهلك عبر ذاته لديه وثيقة شرح واجهة تصيير هذا حدث وقت، هو عندئذ سوف وصول نموذج.

#### Token أثر

لـ صفر: هذه الحزمة نص لن دخول أي نموذج طلب.

#### KV Cache أثر

متبادل متبادل مستقل: مجال قراءة كتابة أبدا لمس اصطدام طلب بادئة، لذلك هذا داخل لا يوجد أي محتوى قدرة جعل مزود ذاكرة مؤقتة إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح مجال طبقة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **تغيير فقط في مفرد عملية داخل مرئي**——`domain/changed` هو عملية داخل حدث؛ في عبر عملية إصلاح حجز نمط سقوط أرض قبل، ثاني عدد رئيسي آلة عملية أو إعادة اتصال GUI لا يمكن مراقبة تغيير ([Agent Note](../../../.agents/notes/proposed/architecture/2026-07-24-domain-kv-storage-and-workspace.ar.md)).
- **لا يوجد عبر جدول أمر خدمة، اثنان درجة بحث جذب أو كثير مقطع مفتاح**——كل مرة كتابة فقط لمس اصطدام واحد بند سجل؛ هذه توسيع صف في Agent Note نطاق خارج بيان في.
- **لا يوجد بيانات ترحيل**——مجال قد تخزين إصدار و spec مختلف وقت، فتح عملية سوف يتم رفض (`version-mismatch`) ؛ تعديل schema حاجة يد عمل ترحيل قد تخزين بيانات.
