# @deepseek-ai/dsh-storage-sqlite

[English](README.md) | العربية

## عام وصف

`dsh-storage-sqlite` هو واحد تخزين خلفية: يأخذ كل قد توجيه وحدة حمل إدارة في نفس عدد SQLite قاعدة بيانات ملف في، كل بند سجل حسب سطر تخزين واحد نسخة JSON وثيقة، تسجيل لـ خلفية `sqlite`. مفرد بند سجل تحديث تماما جيد لمس اصطدام واحد سطر، هذا صحيح هو هو ملائم دمج عال تردد تحديد نقطة كتابة سبب. عند مجال بيانات تغيير حركة تردد كثيف، أو نشر انحراف جيد مفرد واحد يمكن استعلام قاعدة بيانات وقت اختيار هو؛ عند بيانات حاجة بـ صاف نص ملف شكل صيغة يمكن قراءة وقت اختيار JSON خلفية. هذا خلفية فقط موجه إلى مضيف جانب: هو لا مساهمة نص التوجيه، أداة أو schema، لذلك نموذج و agent loop(ذكي جسم حلقة) دائم بعيد لن يرى هو.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تركيب يأخذ تردد كثيف تحديث مجال بيانات حفظ في واحد قاعدة بيانات في وقت استخدام هذه الحزمة: يأخذ متبادل صلة مجال توجيه إلى هذا خلفية، كل وحدة أي بصفة جدول شيء تحويل في إعداد قاعدة بيانات ملف في.

### أي وقت اختيار

عند كتابة تردد كثيف كما لـ تحديد نقطة تحديث وقت اختيار هو——كل مفتاح تماما جيد خريطة إلى واحد سطر، لذلك تحديث واحد بند سجل فقط لمس اصطدام واحد سطر، بينما لا هو إعادة كتابة كامل ملف. عند شخص صنف حاجة بـ صاف نص ملف فحص نظر أو تحرير قد تخزين بيانات وقت اختيار JSON خلفية. تزامن `node:sqlite` قيادة سوف في كل بند مفرد لغة جملة استدعاء خلال منع سد JavaScript خط مسار، هذا في مجال بيانات قاعدة نموذج تحت يمكن قبول، لكن عال كتابة معدل وقت قيمة نيل قبول دخول اعتبار كمية.

### إعداد

اثنان عدد حقل: قاعدة بيانات مسار و journal mode.`:memory:` فتح واحد عملية داخل قاعدة بيانات، ذلك محتوى مع عملية إزالة فقد.

```yaml
- name: '@deepseek-ai/dsh-storage'
- name: '@deepseek-ai/dsh-storage-sqlite'
  config:
    path: /var/lib/dsh/data.db
- name: '@deepseek-ai/dsh-storage-domain'
  config:
    backend: sqlite
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `path` | لا بد ملء | SQLite قاعدة بيانات ملف مسار، أو `:memory:` |
| `journalMode` | `wal` | Journal mode:`wal`،`delete`،`truncate` أو `persist` |

`wal` ملائم دمج محلي مغناطيس قرص؛ تراجع سجل نمط (`delete`/`truncate`/`persist`) ملائم دمج WAL مشترك داخل تخزين ملف غير ممكن استخدام نظام الملفات، مثال مثل شبكة شبكة تركيب. توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-storage-sqlite) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### يمكن مراقبة سلوك

ناقص دليل و قاعدة بيانات ملف سوف بـ فقط كل من يمكن وصول إذن إنشاء (`0o700`/`0o600`) ؛ قد لديه قاعدة بيانات إبقاء ذلك قائم نمط. قد تخزين صيغة إصدار و وصف رمز مختلف وحدة رفض `version-mismatch`، غطاء لديه غير حالي شيء إدارة تخطيط إصدار قاعدة بيانات سوف مباشر رفض——لا فعل ترحيل، مسبق إصدار قيام ساحة. فشل يحمل مستقر `StorageError` شفرة، كتابة عملية إتمام بعد أي قد حفظ دائم.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا خلفية هو في مفرد عدد `node:sqlite` اتصال لـ فوق وثيقة حسب سطر تخطيط، تصميم هدف هو يجعل كل مرة حسب مفتاح تحديث كل هو واحد بند مسبق معالجة لغة جملة.

### تصميم إدارة فكرة

- **كل سطر واحد نسخة وثيقة.** كل وحدة جدول كل تغيير صار واحد ورقة شيء إدارة STRICT جدول `u_<unit>_<table> (key TEXT PRIMARY KEY, value TEXT)`، ذلك `value` صف حفظ سجل JSON نص؛ عام مفرد مثال تخزين وضع في مشترك `unit_globals` جدول في. واحد مفتاح تحديث تماما جيد لمس اصطدام واحد سطر——هذا حينئذ هو يأخذ عال تردد تغيير مجال توجيه إلى هذا داخل سبب.
- **مفرد لغة جملة أصل فرعي صفة.** كل كتابة أصل لغة كل هو واحد بند مسبق معالجة لغة جملة، لذلك SQLite تدريجي لغة جملة أصل فرعي صفة بلا حاجة صريح أمر خدمة يكفي ممتلئ كاف KV اتفاق؛ كتابة ترتيب ما زال من استدعاء جهة مسؤول (مجال طبقة كتابة سلسلة).
- **اسم في DDL قبل تحقق.** وحدة اسم و جدول اسم في دخول DDL قبل يجب مطابقة `UNIT_NAME_RE`، لذلك أي خارجي إدخال كل لن يتم إدراج قيمة دخول SQL معرف رمز.
- **إصدار واضح تقرير خطأ.** شيء إدارة تخطيط إصدار تخزين وضع في `PRAGMA user_version`(كل جديد قاعدة بيانات الأكثر بعد غطاء ختم) ؛ وحدة صيغة إصدار تخزين وضع في `units` جدول في. أي أخرى قد علامة قيمة كل سوف يتم رفض——لا فعل ترحيل.

### فتح ترتيب

فتح قاعدة بيانات وقت سوف بـ `0o700` إنشاء أب دليل، بـ `0o600` وحيد احتلال إنشاء ناقص ملف، تطبيق `PRAGMA foreign_keys = ON` و journal mode، فحص `user_version`، إنشاء `units` و `unit_globals` بيانات وصفية جدول، و في الأكثر بعد إعطاء كل جديد قاعدة بيانات غطاء ختم، يجعل فشل إبقاء تحت لم غطاء ختم وسيط جودة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: خلفية تسجيل،`path`/`journalMode` إعداد، وحدة جدول |
| [`src/schema.ts`](src/schema.ts) | فتح ترتيب، شيء إدارة تخطيط إصدار، بيانات وصفية جدول، سجل جدول تسمية |
| [`src/unit.ts`](src/unit.ts) | واحد قد فتح وحدة: مسبق معالجة لغة جملة،JSON قيمة تحليل، إغلاق |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛schema إصدار و وحدة إصدار متسق صفة في فتح وقت فحص، لا متسق وقت سوف في وحدة إنشاء قبل رفض فتح؛ حمل دائم صفة حاجة من مشترك KV رمز دمج صفة اختبار طقم عنصر في خلفية نحو إرجاع اختبار تحقق؛ هذه الحزمة لا كشف يمكن حمل متابعة مراقبة عملية داخل علاقة. |

</details>

#### نموذج يرى ماذا

بلا. هذا خلفية لا مساهمة نص التوجيه، أداة أو schema؛ هو في `ctx.storage` بعد وجه حفظ دائم غير جلسة مجال بيانات، فقط توفير مضيف جانب مستهلك استخدام.

#### Token أثر

بلا: هذا خلفية من لا لمس اصطدام فوري طلب بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خلفية أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **تزامن قيادة منع سد حدث حلقة**——كل مرة كتابة كل هو مرة تزامن `DatabaseSync` استدعاء؛ منع سد فقط حمل متابعة واحد بند لغة جملة، في مجال بيانات قاعدة نموذج تحت يمكن قبول.
- **لا يوجد مشغول انتظار أو إعادة محاولة سياسة**——يحتفظ كتابة قفل تنافس تنازع اتصال سوف قيام أي رفض عملية، بينما لا هو انتظار؛ مجال طبقة كتابة سلسلة في مفرد عملية داخل سلسلة سطر تحويل كتابة، عبر عملية تنسيق ضبط لا في نطاق داخل.
- **فقط فتح حالي شيء إدارة تخطيط إصدار**——أي أخرى قد علامة `user_version` كل سوف يتم رفض بينما لا هو ترحيل (مسبق إصدار قيام ساحة).
- **فتح ترتيب و استعلام مزود تكرار**——`openDatabase` و `session-query-sqlite` كل قوي صنع تنفيذ SQLite ملف كل حق قيد، لكن اثنان عدد حزمة كل منها يملك مختلف تطبيق معرف و schema؛ لا يوجد مشترك وسيط جودة مساعد مساعدة وحدة سوف اثنان من اقتران دمج.
