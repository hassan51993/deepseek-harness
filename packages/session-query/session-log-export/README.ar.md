# @deepseek-ai/dsh-session-log-export

[English](README.md) | العربية

## عام وصف

`dsh-session-log-export` يجعل Web واجهة يمكن تحت تحميل جلسة كامل تاريخ:Session Header أكثر كثير عملية حسب زر تحت `تحت تحميل Session سجل` قائمة مفرد بند و `/export` مائل عمود أمر كل سوف يأخذ جلسة شجرة——جلسة ذاته، ذلك فرعي جلسة و مرفق عنصر——بصفة ZIP تسليم إعطاء متصفح تحت تحميل. هذه الحزمة يملك Host عودة ملف تدفق، مرور مرور إقرار إثبات Fetch توجيه و متصفح تحكم عنصر و عكس تغذية. تحت تحميل هدف موضع من متصفح اختيار. ضبط و استخدام قاعدة في قبل، مع بعد شرح تنفيذ دقيق عقدة.

## استخدام هذه الحزمة

عند Web bundle حاجة يجعل مستخدم توجيه خروج جلسة سجل وقت استخدام هذه الحزمة. هو حاجة Connection، أمر سجل التسجيل،Session استعلام و حفظ دائم و مرفق عنصر خدمة. تركيب إضافة، لكن بعد في Session Header أكثر كثير عملية قائمة مفرد في اختيار `تحت تحميل Session سجل` أو إدخال `/export`؛ متصفح سوف تحت تحميل `dsh-session-<id>.zip`.

### أي وقت اختيار

لـ حاجة حمل مرئي تحت تحميل نابض نافذة موجه إلى مستخدم جلسة توجيه خروج Web نشر اختيار هو. حاجة برنامج تحويل أو Host جانب توجيه خروج وقت تجنب تجنب استخدام: هذه الحزمة إنتاج هو متصفح تحت تحميل، بينما غير Host مسار كتابة. سجل من حفظ دائم قراءة جملة مقبض تسلسل تحويل بينما قدوم، لذلك أي قد تركيب خلفية كل تلقي دعم حمل.

### تركيب

```yaml
- id: session-log-download
  name: '@deepseek-ai/dsh-session-log-export'
```

Web bundle سوف هذه الحزمة و Connection،`dsh-commands`،`dsh-client-ui-commands` و `dsh-client-ui-conversation` واحد بدء تركيب.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `compressionLevel` | `6` | كل ZIP بند DEFLATE درجة آخر، نطاق لـ 0 إلى 9. |

### أمر اتفاق

| إدخال | نتيجة |
|---|---|
| `/export` | سجل مستخدم أمر دورة الحياة؛ إيداع أمر متصفح تحت تحميل `GET /api/session.export?sessionId=<id>&includeDescendants=true` |
| `/export <path>` | خطأ؛ متصفح تحت تحميل عبر متصفح عادي تحت تحميل سلوك اختيار هدف موضع |

### مسبق مدة سلوك

نابض نافذة تقرير إبلاغ ثلاثة عدد مرحلة مقطع: دقيق تجهيز في، بدء تحت تحميل أو فشل. إغلاق نابض نافذة لن إلغاء صحيح في إجراء تحت تحميل، هذا عملية مع بعد انتهاء وقت نابض نافذة أيضا لن إعادة فتح. كل جلسة معا فقط سماح واحد بند تحت تحميل، تكرار عملية مشترك استخدام هذا مهمة. توجيه خروج يتضمن فوري جلسة الأكثر جديد حدث:Host طرف نقطة في قراءة قبل سوف flush نشط حركة أصل جلسة، لذلك مائل عمود أمر إطلاق ZIP سوف يتضمن بدء تحت تحميل `command/run` و `command/done` حدث مقابل؛ غير نشط حركة حفظ دائم جلسة لا حاجة flush. كل نسخة منطق سجل في عودة ملف في استخدام حالي generation مواصفة ملف اسم (v0 لـ `session.jsonl`، أخرى إصدار لـ `session.vN.jsonl`) ، كل فرعي جلسة دليل تحت أيضا التزام دوران نفس قاعدة. صورة استخدام `media/<attachmentId>.<ext>`، عام ملف استخدام `files/<digest-prefix>/<digest>/<name>`. عام ملف بـ محدود قسم كتلة قراءة و ضغط، لذلك توجيه خروج كبير نوع فوق نقل ملف وقت لن يأخذ هو كامل مؤقت اندفاع دخول داخل تخزين.

### فشل

عند ZIP تدفق صيغة نقل بدء قبل مسبق فحص فشل وقت——مثال مثل Host طرف نقطة غير ممكن بلوغ أو إعداد خطأ——نابض نافذة عرض دقيق تجهيز مرحلة مقطع خطأ. متصفح قبول GET بعد حدوث فرعي جلسة أو مرفق عنصر قراءة فشل من متصفح تحت تحميل إدارة جهاز تقرير إبلاغ، لا عبر نابض نافذة تقرير إبلاغ.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذه الحزمة مثل أي وصل دخول توجيه خروج تحكم عنصر، و إشارة خروج تنفيذ هو شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم تفكيك قسم

هذه الحزمة قسم لـ اثنان جزء.Host نصف حزمة ([`src/index.ts`](src/index.ts)) تسجيل `/export` أمر، و نحو Connection مساهمة دقيق `GET`/`HEAD /api/session.export` Fetch توجيه؛[`src/archive.ts`](src/archive.ts) بناء محدود ZIP تدفق. متصفح نصف حزمة ([`src/client/index.ts`](src/client/index.ts)) توفير مشترك تحت تحميل تحكم جهاز و UI، و مراقبة `command/executed`، لذلك فقط لديه إيداع أمر متصفح سوف بدء تحت تحميل.

### تحت تحميل مسار

اثنان بند مدخل كل سوف أولا نحو `/api/session.export?...` إرسال خروج `HEAD` مسبق فحص طلب، لكن بعد يأخذ GET URL تسليم إعطاء متصفح تحت تحميل إدارة جهاز،JavaScript لا مؤقت اندفاع ZIP. واحد تحكم جهاز حسب جلسة يحتفظ واحد بند إجراء في تحت تحميل، يأخذ تزامن عملية طي دخول هذا مهمة، و في إضافة تحرير وقت إلغاء مسبق فحص. نابض نافذة حالة تخزين وضع في حسب جلسة مفتاح تحكم لقطة تخزين في، لذلك حسب زر و أمر حسب جلسة مشترك واحد نابض نافذة.

Host توجيه هو من هذا وظيفة يملك دقيق Fetch توجيه مساهمة.Connection تطبيق Host/Origin و متصفح جلسة فحص و جسر وصل تدفق صيغة `Response`؛ هذه الحزمة يملك استعلام تحقق، نشط حركة جلسة flush، أساس في جملة مقبض سجل قراءة و مرفق عنصر قراءة،ZIP توليد و HTTP حالة دلالة.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### مستخدم `/export` تحكم

#### نموذج يرى ماذا

بلا.`/export` إبقاء في مستخدم أمر مستو وجه،ZIP تحت تحميل لن دخول نموذج تاريخ.

#### Token أثر

لـ صفر. هذا أمر لا إنشاء نموذج جولة.

#### KV Cache أثر

بلا. فقط سجل أمر دورة الحياة و متصفح تحت تحميل لن تغيير إرسال توليد طلب بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه الحزمة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **متصفح تحت تحميل، بينما غير Host مسار كتابة**——هدف موضع من متصفح اختيار؛ لن إرجاع Host مسار أو أصلي ملف مشبك عملية.
- **مسبق فحص فقط تقرير إبلاغ تدفق صيغة نقل قبل فشل**——متصفح قبول GET بعد حدوث فرعي جلسة أو مرفق عنصر قراءة فشل من متصفح تحت تحميل إدارة جهاز تقرير إبلاغ، لا عبر نابض نافذة تقرير إبلاغ.
