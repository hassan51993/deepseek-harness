# @deepseek-ai/dsh-session-query-sqlite

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن لـ جلسة تاريخ زيادة حمل ترتيب ترتيب SQLite FTS5 بحث، حيث قدرة عبر جلسة بحث، أيضا قدرة في مفرد عدد جلسة داخل بحث، و دعم حمل تنقل علامة قسم صفحة. هو يأخذ فوري و حفظ دائم تاريخ بحث جذب إلى مستقل إرسال توليد قاعدة بيانات، لذلك بحث عكس عكس حالي حالة، معا لن تعديل جلسة حفظ دائم تخزين. دقيق قراءة، مرور ترشيح و تتبع أثر ما زال عبر نفس استعلام API توفير. قد إصدار تركيب في بحث هو اختياري قدرة؛ إعداد `openAt` يمكن يجعل بحث جذب في بدء وقت، أول مرة بحث وقت فتح، أو دائم لا فتح. نتيجة مطابقة token و قصير لغة، بينما غير مهمة معنى فرعي نص؛ كل بحث جذب مسار فقط قدرة من واحد عملية يحتفظ.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تركيب حاجة مقابل جلسة تاريخ إجراء ترتيب ترتيب بعد كل نص بحث وقت——مثال مثل Web محتوى بحث أو `/resume` حيث نحو عمل فحص بحث——تركيب هذه الحزمة. معتاد استخدام مسار هو صريح: تركيب إضافة، إعطاء هو واحد مخصص استخدام قاعدة بيانات مسار، لكن بعد من شفرة استدعاء `ctx.sessionQuery.searchSessions` أو `searchEvents`.

### أي وقت اختيار

عند أنت تفكير مقابل حيث نحو جلسة إجراء حمل ترتيب ترتيب و قسم صفحة كل نص استدعاء عودة وقت اختيار هو. هو و `dsh-session-query` و جلسة خدمة واحد بدء استخدام؛ حفظ دائم خلفية اختياري لكن بناء اقتراح تركيب، هذا مثال إعادة بدء بعد حفظ دائم تاريخ ما زال يمكن بحث. لا يلزم يأخذ `path` إشارة نحو session-persistence قاعدة بيانات——هذه الحزمة يملك مستقل إرسال توليد بحث جذب.

### الأكثر صغير إعداد

```yaml
- name: '@deepseek-ai/dsh-session'
- name: '@deepseek-ai/dsh-session-query-sqlite'
  config:
    path: /absolute/path/to/session-search.db
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `path` | لا بد ملء | مخصص استخدام إرسال توليد بحث جذب SQLite مسار، أو `:memory:`؛POSIX فوق ناقص مسار سوف بـ فقط كل من يمكن وصول طريقة إنشاء |
| `openAt` | `startup` | `startup` في تنشيط وقت فتح؛`first-search` يأخذ SQLite وحدة دفع متأخر إلى أول مرة بحث؛`never` إغلاق كل نص بحث، وراثة قراءة إبقاء متاح |
| `journalMode` | `wal` | `wal`،`delete`،`truncate` أو `persist` |
| `defaultLimit` | `20` | طلب حذف `limit` وقت قسم صفحة كبير صغير |
| `maxLimit` | `100` | قبول الأكثر كبير طلب قسم صفحة كبير صغير |
| `snippetChars` | `240` | حسب Unicode رمز نقطة حساب حساب الأكثر كبير snippet طويل درجة |
| `readWindowMax` | `50` | وراثة `readEvent()` `before`/`after` أصلي حدث عدد حد أعلى |
| `persistedReadConcurrency` | `4` | وراثة دفعة كمية قراءة تزامن حفظ دائم سجل قراءة عدد |
| `preparedSessionCacheSize` | `5` | وراثة `observeSession` قراءة جهاز لـ إعادة استخدام إبقاء بارد prepared-Session مراقبة عدد |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-session-query-sqlite) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### بحث سلوك

`searchSessions` بحث كامل لغة مادة مكتبة، و حسب كل جلسة مطابقة الأكثر قوي حدث قسم مجموعة نتيجة؛`searchEvents` بحث واحد منطق جلسة. استعلام هو حرف وجه قصير لغة: أول ذيل فارغ أبيض سوف يتم إزالة، داخلي فارغ أبيض سوف يتم مواصفة تحويل، جذب رقم،`OR`،`NEAR` و `*` انتظار FTS5 لغة قاعدة يتم نظر لـ بيانات، أبدا بصفة يمكن تنفيذ استعلام لغة قاعدة. بيانات وصفية مرور ترشيح جهاز (جلسة id،cwd، إنشاء وقت، أب درجة، متاح صفة، حدث seq/وقت/نوع/جدول طبقة) في ترتيب ترتيب قبل تقليص صغير نتيجة. افتراضي بحث الكل `current`،`shadowed` و `log-only` حدث؛ نقل دخول جدول طبقة مرور ترشيح جهاز يمكن تقليص صغير نطاق.

ترتيب ترتيب هو تحديد صفة: فعلي FTS5 عال مضيء مطابقة span أكثر كثير في قبل، لكن بعد وثيقة أكثر قصير في قبل، حدث وقت، جلسة id و seq ضرب كسر مستو نطاق. نتيجة يحمل حسب `snippetChars` عدد Unicode رمز نقطة قطع قطع صاف نص اقتباس تسجيل، لا يوجد مزود مخصص استخدام عدد قيمة قسم عدد. قسم صفحة عبر لا نفاذ واضح `SessionSearchCursor` تأخير متابعة، تنقل علامة ربط إلى مواصفة تحويل بعد تأكيد قطع طلب؛ متبادل صلة لغة مادة مكتبة تغير وقت تنقل علامة تغيير لـ قديم قديم (`SESSION_QUERY_STALE_CURSOR`) ، جلسة داخل تنقل علامة يمكن في لا متبادل صلة جلسة تغير بعد تأخير متابعة، عبر جلسة تنقل علامة فإن لا يستطيع.

`unicode61` tokenizer مطابقة token و قصير لغة، بينما غير مهمة معنى فرعي نص:`AI` لا مطابقة token `BRAID`. حاجة تنفيذ حرف وجه، فارغ أبيض مرن نشط نص فرعي سلسلة مسح وقت، استخدام حمل `text` فرعي جملة `ctx.sessionQuery.filterEvents()`.

### أي وقت دفع متأخر أو إغلاق بحث

استخدام `openAt: first-search` وقت، خدمة في لا استيراد `node:sqlite`، لا فتح بحث جذب حال حال تحت تنشيط، يأخذ SQLite فعلي تحقق صفة تحذير إبلاغ دفع متأخر إلى أول مرة فعلي بحث؛ بلا فاعلية قاعدة بيانات يجعل أول مرة بحث فشل، بينما لا هو خدمة تنشيط فشل. استخدام `openAt: never` وقت، كل نص بحث مقابل هذا نشر إغلاق:`searchSessions` و `searchEvents` في أي طلب مواصفة تحويل قبل حينئذ بـ `SESSION_QUERY_SEARCH_DISABLED` فشل، بينما وراثة الكل دقيق قراءة، مرور ترشيح و تتبع أثر إبقاء متاح. طلب تجاوز مرور تحرير ترجمة يسمى كلمة ميزانية (عبر جلسة 14 عدد تركيب يسمى كلمة، جلسة داخل 13 عدد) أو SQLite يمكن نقل غرس 32,766 ربط حد أعلى وقت، سوف في دقيق تجهيز لغة جملة قبل بـ `SESSION_QUERY_INVALID_FILTER` فشل.

### فشل و استعادة

حمل نوع `SessionQueryError` فشل يحمل مستقر شفرة: بحث إعداد لـ إغلاق وقت `SESSION_QUERY_SEARCH_DISABLED`؛ بحث جذب لا يمكن فتح أو مقابل حساب وقت `SESSION_QUERY_INDEX_FAILED`؛ بحث هدف لا وجود وقت `SESSION_QUERY_SESSION_NOT_FOUND`؛ لغة مادة مكتبة في قسم صفحة بين تغير وقت `SESSION_QUERY_STALE_CURSOR`——طلب إعادة محاولة كامل بحث استدعاء؛ تنقل علامة لا يخص هذا طلب وقت `SESSION_QUERY_INVALID_CURSOR`. إلغاء في تزامن SQLite استدعاء بين يتم احترام إعادة؛ قد في JavaScript خط مسار فوق تنفيذ لغة جملة لا يمكن يتم في قطع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا خلفية بناء قيام في واحد قسم مغادرة و ثلاثة بند تحمل وعد لـ فوق:

- **إرسال توليد بحث جذب، أبدا حركة مصدر تخزين.** FTS سطر تخزين وضع في مخصص استخدام يمكن إسقاط قاعدة بيانات في؛ هذا داخل شفرة من لا فتح session-persistence قاعدة بيانات.
- **فوري أولوية مراقبة.** واحد سلسلة سطر تحويل حالة آلة مقارنة مقارنة حفظ دائم لقطة إصلاح حجز، فقط عبر قصير دورة الحياة قراءة جملة مقبض قراءة إضافة جديدة أو قد أكثر تعديل سجل، و في واحد أمر خدمة في مقابل حساب، لذلك بحث عكس عكس الأكثر جديد مستقر حالة.
- **عالم بديل ربط تنقل علامة.** كل مرة لغة مادة مكتبة تغير كل سوف تمرير زيادة عالم بديل؛ تنقل علامة يحمل ذلك إنشاء وقت عالم بديل، هدوء يمكن قديم قديم فشل أيضا لا إرجاع انحراف نقل بعد صفحة.
- **حرف وجه قصير لغة أي بيانات.** استدعاء جهة استعلام نص يتم جذب صار واحد FTS5 قصير لغة، استعلام لغة قاعدة إبقاء كسول صفة؛ إبقاء عال مضيء علامة في بحث جذب قبل من وثيقة في تقشير مغادرة.

تصميم تاريخ سجل في [SQLite FTS5 جلسة بحث قلم تسجيل](../../../.agents/notes/archived/feature/2026-07-10-sqlite-session-query-provider.md) و[موحد واحد خدمة قرار](../../../.agents/notes/archived/architecture/2026-07-23-unified-session-query-service.md) في.

### بحث جذب دورة الحياة

حفظ دائم FTS سطر تخزين وضع في مخصص استخدام إرسال توليد قاعدة بيانات في و عبر إعادة بدء إبقاء؛ فوري جلسة استخدام اتصال محلي TEMP جدول، حجب حجب نفس جلسة حفظ دائم أساس مكتبة، و في فوري كل من انفصال مغادرة بعد مجددا مرة عرض أساس مكتبة. اثنان صنف جدول كل في عدد حرف `seed_length` في إبقاء دقيق وراثة قطع نقطة؛ إعادة بناء header فقط عام `isSeeded`، بينما قطع نقطة مشاركة و فوري إشارة نقش و حمل دائم مصدر إصلاح حجز. كل مرة بحث تنفيذ مرة سلسلة سطر تحويل مراقبة: صف خروج حفظ دائم لقطة، يأخذ تدريجي جلسة إصلاح حجز و قد بحث جذب سطر مقارنة مقارنة، فقط عبر قراءة جملة مقبض قراءة إضافة جديدة أو قد أكثر تعديل سجل (في داخل تخزين في تكملة متساو يتم في قطع نهاية ذيل جولة، من لا كتابة عودة) ، رفع أخذ دلالة وثيقة، و في تشغيل استعلام قبل في واحد أمر خدمة في إيداع مقابل حساب. تكرار استعلام و ثابت إعادة فتح لا قراءة أي محتوى؛ تبديل تخزين أو مراقبة إلى إضافة جديدة، قد أكثر تعديل، قد حذف أو مرور خارجي إصلاح مصدر وقت، سوف في تحت مرة مستقر مراقبة وقت مقابل حساب. مصدر أو أمر خدمة فشل لا إيداع أي محتوى، تحت مرة بحث إعادة محاولة.

### Schema ملكية

قاعدة بيانات يحمل application id و schema إصدار 8. فتح وقت رفض أخرى تطبيق برنامج يملك ملف أو مواصفة قاعدة بيانات، رفض لم معرفة مستخدم جدول؛ فقط لديه قد تعرف آخر لا توافق إرسال توليد schema عندئذ سوف أصل أرض إعادة وضع——لذلك لا متبادل صلة أو session-persistence قاعدة بيانات أبدا سوف يتم لمس اصطدام. في POSIX نظام الملفات فوق، ناقص دليل و قاعدة بيانات ملف بـ فقط كل من يمكن وصول طريقة إنشاء (عملية umask قبل لـ `0700` و `0600`). كل إرسال توليد بحث جذب مسار في واحد عملية في فقط قدرة من واحد خدمة يملك؛ عالم بديل و TEMP حجب حجب حالة من اتصال يحتفظ.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه الحزمة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام SQLite مقابل مقارنة أو مهمة تراكم ضغط.

- **بلا استدعاء جهة تخويل**——هذا هو سياق نطاق داخل يمكن معلومة خدمة؛ نموذج أداة أو UI يجب قوي صنع تنفيذ ذاتي ذات وصول سياسة.
- **تزامن استعلام تنفيذ**——`DatabaseSync` في MATCH تنفيذ خلال سوف منع سد JavaScript خط مسار، كما لا يمكن في قطع قد تشغيل لغة جملة.
- **Token استدعاء عودة، بينما غير مهمة معنى فرعي نص**——`unicode61` tokenizer لن مطابقة أكثر كبير token في فرعي نص؛ مقابل حرف وجه مسح استخدام `filterEvents()`.
- **مفرد واحد كل من إرسال توليد بحث جذب**——كل بحث جذب مسار يجب فقط عودة واحد عملية في واحد خدمة كل؛ لا دعم حمل خارجي كتابة من و كثير عملية مشترك.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع تصميم مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص، حزمة شفرة و متبادل صلة Agent Note لـ دقيق.

#### لم قدوم: أخرى tokenizer و بحث مزود

`unicode61` tokenizer اختيار تضحية قربان فرعي نص استدعاء عودة، بـ تبديل أخذ مقارنة صغير بحث جذب جسم تراكم و مزدوج محرف token دعم حمل؛trigram تجهيز اختيار خطة مرور فعلي قياس بعد يتم مرفوض. تبديل tokenizer أو زيادة آخر عدد بحث خلفية سوف تغيير بحث جذب استدعاء عودة، و حاجة كل منها مقابل حساب و عالم بديل خطة.

</details>
