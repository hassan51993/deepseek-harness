# @deepseek-ai/dsh-web-app

[English](README.md) | العربية

## عام وصف

تشغيل `dsh --profile web`، فتح توفير حديث يوم، نموذج و ضبط إدارة و جلسة تاريخ تفاعل صيغة متصفح GUI. هو استخدام و أخرى dsh جدول طبقة نفسه نموذج وصول، أداة و أمان قيمة افتراضية. بدء وقت سوف ضرب طبع حمل إقرار إثبات معلومة URL، عبر معتاد أيضا سوف في افتراضي متصفح في فتح؛SSH جلسة و `--no-open` سوف إبقاء هذا URL، توفير أنت يد حركة فتح. أنت يمكن أكثر تعديل طرف فتحة و سماح مقدار خارج رئيسي آلة، لكن لا يستطيع ربط كل شبكة شبكة واجهة. حاجة في متصفح في تفاعل صيغة عمل وقت اختيار هذه الحزمة؛ مرة صفة أمر سطر مهمة ينبغي استخدام `dsh-headless`.

## استخدام هذه الحزمة

بدء GUI، فتح متصفح، لكن بعد بدء و agent(ذكي جسم) محادثة.flag لأجل دقيق ضبط هذا مرة استدعاء.

### بدء Web GUI

```sh
dsh --profile web
dsh --profile web --no-open --port 8080
```

بدء بعد أنت سوف يرى `dsh web:` سطر، ذلك أصل URL يحمل جديد عملية token. حذف غير `--no-open` أو SSH جلسة كبح صنع، لا فإن افتراضي متصفح سوف فتح هذا URL، أخذ نيل توقيع cookie، مجددا إعادة تحديد نحو إلى لا يحتوي إقرار إثبات معامل أصل صفحة. صفحة تحميل كما أنت يمكن و agent محادثة، حينئذ شرح نجاح. اثنان نوع يمكن مسبق مدة فشل: قبل طرف لم بناء وقت، بدء سوف بـ بناء تلميح إيقاف (checkout في تشغيل `pnpm run build`) ؛ متصفح لا يمكن فتح وقت،stderr سوف ضرب طبع لا يحتوي اعتماد تشخيص، لكن خادم سوف متابعة تشغيل——طلب ذاتي سطر فتح قد ضرب طبع بدء URL.

**ضبط → نموذج**عرض **DeepSeek**، استخدام `DEEPSEEK_API_KEY`. افتراضي نموذج لـ `deepseek-official` / `deepseek-flash`(DeepSeek-V41-Flash).[DeepSeek إضافة](../../llm/llm-deepseek/README.zh.md#choose-a-protocol) افتراضي استخدام Messages؛ في Cordis YAML في ضبط `protocol: chat-completions` اختياري اختيار Chat Completions.Web لا توفير بروتوكول اختيار جهاز.

قد حفظ نموذج اختيار أولوية في تركيب قيمة افتراضية. اثنان نوع بروتوكول مشترك استخدام `deepseek-official` و `llm-deepseek` ضبط، لذلك تبديل بروتوكول لا تغيير نموذج اختيار أو نسخ اعتماد. طرف نقطة تغطية إبقاء أصل قيمة؛ ضبط بطاقة سماح مستخدم ملء كتابة توافق API عنوان.

### إعداد

كبير كثير عدد مستخدم لا حاجة ضبط هذه؛ أمر سطر flag سوف توفير إعطاء تحت وجه أربعة عدد ضبط——`--host`،`--port` و `--trusted-host` قدوم ذاتي هذا مرة استدعاء،`--no-open` فقط مقابل هذا مرة استدعاء إغلاق متصفح تسليم وصل:

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `openBrowser` | `true` | بدء بعد استخدام افتراضي متصفح فتح؛SSH بدء سوف كبح صنع هو |
| `printUrl` | `true` | بدء وقت ضرب طبع `dsh web:` URL سطر |
| `surfaceContext` | `true` | إعطاء agent توفير GUI تحديد موضع سياق، و يأخذ `DSH_WEB_URL` كشف إعطاء ذلك shell أمر |
| `trustedHosts` | `[]` | سماح من شبكة شبكة وصول GUI مقدار خارج رئيسي آلة |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-web-app) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### LAN وصول و يمكن معلومة رئيسي آلة

افتراضي حال حال تحت GUI فقط قبول هذا آلة اتصال. ربط كل شبكة شبكة واجهة نشر أيضا سوف سماح LAN داخل متصفح وصول، هذا وقت ضرب طبع URL سوف مرفق حمل واحد LAN عنوان؛`--trusted-host` في اثنان نوع حال حال تحت كل قدرة إضافة مقدار خارج رئيسي آلة.Host و Origin فحص تحكم يمكن بلوغ صفة،token تسليم تبديل فإن إقرار إثبات كل Host API طريقة و WebSocket تدفق.LAN عنوان فقط في بدء وقت أخذ مثال مرة، لذلك بعد شبكة شبكة تغير لن يتم شعور معرفة——إعادة بدء GUI بـ إعادة عام إبلاغ.

### عبر SSH تشغيل

عبر SSH بدء `dsh --profile web` وقت،URL سطر ما زال سوف ضرب طبع، لكن لن لـ أنت فتح متصفح: محلي تحويل إرسال عنوان من SSH عميل أو تحرير جهاز يحتفظ. طلب في ذاتي ذات آلة جهاز فوق فتح تحويل إرسال بعد URL؛ ضرب طبع خروج URL إشارة نحو بعيد طرف مضيف آلة loopback طرف نقطة.

### حسب جلسة agent ضبط

كل متصفح جلسة كل من مع إرسال سطر إصدار تسليم preset(افتراضي `standard`) تركيب ذاتي ذات agent، بينما لا هو مشترك واحد طقم عملية درجة أداة تجميع. أنت يمكن أكثر تعديل افتراضي preset، أو في `$DSH_HOME/.agent-presets` تحت إضافة ذاتي ذات preset.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا bundle من واحد رقعة و واحد وقت التشغيل لاصق ماء إضافة مجموعة صار. تخزين مكدس و إسقاط ذاكرة مؤقتة قدوم ذاتي `dsh-base`؛Web تراكم إضافة طبقة مساحة العمل و رسالة عكس تغذية بند إزالة استهلاك مشترك `storageDomain` خدمة. رقعة إعادة وصف base متعمد حذف واجهة مخصص استخدام قيمة، إدراج دخول Web مخصص استخدام مضيف بند و متصفح إضافة قائمة، مجددا سوف Agent طبقة نقل إلى مسبق ضبط بعد وجه. لاصق ماء إضافة مسؤول dist خدمة، معلومة مهمة أخذ مثال، نص التوجيه مقطع سقوط،bash متغير و حينئذ خيط إشعار.`office-to-pdf` بند لـ مضيف إزالة استهلاك من تركيب واحد تأخير متأخر إنشاء جذب محرك [Office تحويل مزود](../../document/office-to-pdf/README.zh.md) ، استخدام هذا bundle Desktop تركيب أيضا مشترك هذا مزود. تحويل خدمة Remote طريقة مسؤول معاينة قراءة تخويل،Document Preview مسؤول Office فحص نظر جهاز و عميل ذاكرة مؤقتة.

### patch دلالة

patch سوف استبدال هدف سطر كامل `config`، لذلك كل Web سطر كل إعادة وصف ذاتي ذات يملك كل مفتاح: أساس أساس سطر فوق persona بادئة و بعد لاحقة نموذج لوح،`DSH_TOOLS_MODE` PTC mode فتح صلة و `session-query-sqlite` قيمة، مع بعد `insert` إضافة Web مضيف سطر، نقل طبقة و متصفح اسم تسجيل.base بـ عملية درجة تركيب حسب agent أداة سطر في هذا داخل يتم منع استخدام، من preset اسم تسجيل وصل إدارة؛ كل بند مضيف طبقة و preset طبقة ملكية قرار إدارة من بـ سطر داخل ملاحظة تفسير كتابة في patch داخل.

### حينئذ خيط إعلان إبلاغ

URL سطر و متصفح تسليم وصل كل هو حينئذ خيط إشارة: مراقبة إشراف جهة واحد مراقبة إلى هذا سطر حينئذ إرسال بدء RPC، متصفح واحد فتح حينئذ طلب صفحة، لذلك اثنان من فقط في Loader إعداد شجرة تسوية، عبر required بدء فحص كما Connection إقرار إثبات متاح بعد تشغيل——في لا يوجد Loader يد عمل بناء شجرة في فإن قيام أي تشغيل. هذا وقت client combo JavaScript و source map ما زال لم شيء تحويل. اختياري إضافة فشل لن منع توقف حينئذ خيط إعلان إبلاغ؛required بدء فشل أو بدء في طريق يتم تحرير شجرة لن إعلان إبلاغ أي محتوى.

### LAN معلومة مهمة أخذ مثال

`resolveLanTrust` في بدء وقت فقط أخذ مثال مرة شبكة شبكة:loopback ربط (`127.0.0.1`) لا إرسال توليد أي LAN عنوان، ربط كل شبكة بطاقة فإن سوف إضافة دخول كل غير internal IPv4 حرف وجه كمية. إرسال توليد حرف وجه كمية إضافة فوق صريح `--trusted-host` مرجعي معرف مجموعة صار `/api` متصفح معلومة مهمة شبكة شريط، ضرب طبع LAN URL بداية نهاية و هذا شبكة شريط متسق.

<a id="model-experience"></a>
## تجربة النموذج

### Harness شفرة المصدر و Web جدول طبقة سياق

#### نموذج يرى ماذا

عند `surfaceContext` لـ true وقت،`harness:source` مقطع سقوط علامة واضح مغناطيس قرص فوق Harness تنفيذ، لكن لن صوت تسمية هو حينئذ هو عمل دليل؛ عام مقطع سقوط `app:web-surface`(first-party ترتيب 10100، يقع في يمكن إعادة استخدام إشارة أمر بعد) فإن نحو نموذج شرح GUI: مواصفة محلي URL، «this page» إشارة بديل ماذا، تحديث اتفاق (إعادة تحميل استقبال طرف بداية نهاية فتح بدء؛ بلا تحديث جديد إعادة تحميل أيضا حاجة `pnpm run dev:web` watcher) ، و لا يلزم بدء بديل خادم إشارة أمر.`DSH_WEB_URL` أيضا سوف وصل نفس وصف ظهور في تلقي إدارة bash بيئة في، كل مرة استدعاء وقت من تشغيل في خادم تحليل. عند هو لـ false وقت، هذا اثنان عدد مقطع سقوط و هذا متغير كل لن تسجيل.

#### Token أثر

كل جلسة واحد سطر شفرة المصدر شرح و واحد مقطع نص التوجيه، خارج إضافة اثنان سطر تلقي إدارة بيئة متغير؛ كل عملية داخل إبقاء ثابت تحديد.

#### KV Cache أثر

شفرة المصدر و Web مقطع سقوط يقع في رقم واحد جهة يمكن إعادة استخدام إشارة أمر بعد. أداة و إعداد متسق وقت، مختلف checkout مسار أو محلي طرف فتحة لن تغيير قبل وضع بادئة؛ لا حفظ إثبات مزود إعادة استخدام ذاكرة مؤقتة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد إبلاغ إبلاغ أنت في لا معتاد رؤية بيئة تحت سوف لقاء إلى ماذا——شفرة المصدر checkout،SSH جلسة أو صارم إطار شبكة شبكة. هو جمع هو حالي حزمة قيد، لا هو عام متصفح مقابل مقارنة أو مهمة تراكم ضغط.

- **قبل طرف يجب قد بناء**——شفرة المصدر checkout حاجة أولا تشغيل `pnpm run build`؛dist ناقص وقت بدء سوف بـ بناء تلميح إيقاف، كما لا يوجد من شفرة المصدر مباشر خدمة رجوع مسار.
- **LAN عنوان فقط في بدء وقت أخذ مثال مرة**——بدء بعد شبكة بطاقة تغير لن إعادة عام إبلاغ؛ ضرب طبع LAN URL بداية نهاية و أخذ مثال نتيجة متسق.
- **فقط قدرة مراقبة إلى تسليم وصل بدء**——GUI فقط تقرير إبلاغ متصفح يتم طلب فتح، بينما لا هو هو تأكيد فعلي فتح؛ بعد متصفح خروج دائم بعيد لن فوق تقرير، ضرب طبع URL هو أنت يد حركة رجوع مسار.
- **SSH جلسة إبقاء URL لكن قفز مرور متصفح تسليم وصل**——ضرب طبع URL إشارة نحو بعيد طرف مضيف آلة loopback طرف نقطة؛SSH عميل أو تحرير جهاز يجب كشف و فتح محلي تحويل إرسال عنوان.
- **`BROWSER` تغطية فقط قدرة قدوم ذاتي بيئة**——يتم اكتشاف `.env` لا يستطيع ضبط `BROWSER`؛ فقط لديه وراثة قيمة قدرة لـ تلقائي تسليم وصل اختيار يمكن تنفيذ ملف.
- **لا دعم حمل ربط كل شبكة شبكة واجهة**——خروج في أمان اعتبار،`--host 0.0.0.0` سوف في بدء وقت يتم رفض؛ طلب استخدام افتراضي loopback رئيسي آلة.
