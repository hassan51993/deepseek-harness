# @deepseek-ai/dsh-headless

[English](README.md) | العربية

## عام وصف

`dsh-headless` من أمر سطر تشغيل واحد dsh مهمة و ضرب طبع نهائي جواب سجل، لكن بعد خروج——لا يوجد GUI، لا يوجد خادم، لا يوجد متصفح. إدخال `dsh --profile headless "run the tests"`،agent(ذكي جسم) سوف بـ و كل أخرى جدول طبقة نفسه نموذج، أداة و أمان قيمة افتراضية إتمام هذا مهمة. هو غير معتاد ملائم دمج نص برمجي،CI و مرة صفة مهمة: عملية لا فتح أي طرف فتحة، أيضا لن إبقاء تحت أي خلفية تشغيل شرق غرب. مراقبة إشراف عملية أيضا يمكن عبر حسب سطر JSON حدث تدفق (`--json`) قيادة هو، و استخدام هذا حدث تدفق تقرير إبلاغ معرف (`--session-id`) في نفس مقطع محادثة فوق متابعة نداء تنبيه. خروج رمز إبلاغ إبلاغ أنت نتيجة——مهمة إتمام وقت لـ 0، في توقف أو خروج خطأ وقت لـ 1. رئيسي يلزم حد: كل مرة استدعاء فقط تشغيل واحد مهمة، لا يوجد تفاعل صيغة لاحق.

## استخدام هذه الحزمة

تشغيل واحد مهمة، نيل نيل نهائي جواب سجل، لكن بعد خروج. مهمة حينئذ هو أمر سطر معامل، حذف وقت فإن قدوم ذاتي stdin؛ كامل بند أمر حينئذ هو الأكثر صغير يمكن تشغيل عرض مثال.

### تشغيل مرة صفة مهمة

```sh
dsh --profile headless "run the tests"
```

agent سوف إتمام هذا مهمة، يأخذ مزود كل غير فارغ دفع إدارة (reasoning) زيادة كمية تدفق صيغة كتابة stderr `dsh: reasoning:` مقطع، لكن بعد يأخذ نهائي جواب سجل كتابة stdout و خروج. وصل متابعة دفع إدارة زيادة كمية إبقاء في نفس مقطع في؛ مزود لم إعطاء ذيل تبديل سطر وقت،runner سوف في لاحق إخراج قبل انتهاء هذا مقطع. لا يوجد دفع إدارة محتوى نجاح تشغيل إبقاء stderr لـ فارغ؛ فشل وقت خروج رمز لـ 1، و بـ `dsh: <code>: <message>` نحو stderr كتابة خطأ. مهمة قدوم ذاتي موضع معامل، معامل حذف أو لـ مفرد وحيد `-` وقت فإن قدوم ذاتي stdin؛ فارغ أبيض موضع معامل أو فارغ إدارة طريق سوف في أي تنفيذ بدء قبل يتم رفض. موضع معامل سوف أصل مثال بصفة مهمة،stdin لن يتم قراءة، لذلك تفكير يجعل إدارة طريق محتوى دخول نص التوجيه وقت، طلب يأخذ كامل تلميح كتابة دخول إدارة طريق؛ إدارة طريق مهمة سوف أصل مثال إرسال، يشمل ربط ذيل تبديل سطر.

```sh
{ echo "Summarize these changes:"; git diff --stat; } | dsh --profile headless
```

مهمة و تشغيل خيار عبر ثلاثة عدد ضبط توفير:

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `task` | stdin | مهمة نص؛ حذف أو نقل `-` وقت من stdin توفير |
| `sessionId` | `session-<uuid>` | يلزم امتداد استخدام دقيق Session معرف؛ لم معرفة id سوف فشل |
| `json` | `false` | يأخذ هذا مرة تشغيل إسقاط لـ stdout فوق حسب سطر JSON حدث |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-headless) هو كل تلقي دعم حمل حقل و ذلك JSDoc كامل حق مصدر.

### اختيار Session معرف

كل مرة استدعاء افتراضي استخدام كل جديد `session-<uuid>` معرف،`--json` سوف في فتح رأس `session` حدث داخل تقرير إبلاغ هو. نقل دخول `--session-id <id>` تأخير متابعة هذا مقطع محادثة:runner امتداد استخدام هذا id مقابل حفظ دائم Session، بينما هذا id لا يوجد حفظ دائم Session وقت سوف في مهمة تشغيل قبل فشل، بينما لا هو صامت صامت فتح خروج واحد مقطع فارغ تاريخ. امتداد استخدام اشتراط قد تركيب `sessionPersistence` و `sessionQuery` خدمة، لذلك نقص قليل مهمة واحد خدمة profile سوف صريح فشل، بينما لن إرجاع واحد تاريخ مع عملية إزالة فقد id. هذا عملية في قد وجود يحتفظ هذا id تخزين نشط Agent وقت سوف يتم رفض: هو أصل owner ممكن ما زال في قيادة هو،runner لا يمكن أخذ نيل وحيد احتلال تشغيل منطقة بين. معرف هو لا نفاذ واضح، لذلك سوف أصل مثال استخدام استدعاء جهة إعطاء خروج نص، يشمل فارغ أبيض محرف. عمل دليل عبر قد تركيب نظام الملفات مزود تحليل (`fs.resolve('.')` و `fs.processPath()`) ؛ لم تركيب نظام الملفات خدمة وقت استخدام عملية cwd، جديد Session سوف سجل هذا دليل. امتداد استخدام سوف سوف قد سجل cwd و نفس مزود تحليل خروج دليل مقارنة مقارنة، و رفض فرعي agent أو fork جلسة، لم سجل عمل دليل جلسة، تشغيل في هذا profile لا تركيب agent preset تحت جلسة، و preset سجل شاذ شكل جلسة——هذا فحص قراءة Session سجل حالي سجل preset، لذلك في فارغ أبيض مدة تبديل مرور preset جلسة نفس مثال سوف يتم رفض. لذلك مراقبة إشراف عملية لا يمكن في آخر طقم تركيب تحت صامت صامت قيادة هو شخص جلسة؛ مهمة واحد لا مطابقة كل سوف في مهمة تشغيل قبل فشل.

### آلة جهاز يمكن قراءة إخراج

`--json` استخدام حسب سطر JSON حدث تدفق يحل محل stdout نهائي نص سطر،stderr فقط إبقاء `dsh:` تشخيص معلومة. حدث تدفق بـ `session`(يحمل هذا مرة تشغيل استخدام معرف) فتح رأس، بـ `final` ربط ذيل، ذلك بين لـ `status`،`text`،`thinking`،`tool_call` و `tool_result` حدث.`text` و `thinking` فقط من قد إيداع assistant رسالة إسقاط، لذلك يتم إعادة محاولة أو إسقاط محاولة تجربة لن دخول حدث تدفق؛ هو جمع في خطوة إيداع وقت وصول، بينما لا هو تدريجي token وصول، افتراضي نمط stderr دفع إدارة ما زال هو وحيد فوري نص عبر طريق. إنهاء `final` حدث يحمل و افتراضي نمط نفسه بلا ضرر جواب سجل، لا فعل حد طويل؛ أخرى كل نص و كائن مفتاح حد أعلى لـ 8 KiB، تجاوز خروج وقت علامة `truncated`، مفرد بند حدث سطر (يحتوي تبديل سطر) حد أعلى لـ 32 KiB——تجاوز طويل حدث إبقاء علامة كمية حقل، إسقاط بنية تحويل حقل، أقصى طرف حال حال تحت فقط باق `type` و `truncated`، تضمين طقم بلوغ إلى 64 طبقة و بـ فوق سالب تحميل سوف في هذا عميق درجة يتم قطع قطع. فارغ أداة معامل نص سوف إسقاط لـ `{}`، و منفذ فعلي تشغيل قيمة متسق؛ بينما JSON لا يمكن نحو إرجاع معامل——مثال مثل فيض خروج لـ `Infinity` عدد حرف `1e400`——سوف إبقاء أصلي نص، بينما لا هو `JSON.stringify` سوف تقرير إبلاغ `null`.runner في جولة خارج رمي خروج فشل سوف كتابة خروج `error` حدث و في لا يوجد `final` حال حال تحت انتهاء حدث تدفق، معا نحو stderr كتابة `dsh:` سطر؛ إذا profile ذاته إضافة تحميل فشل، عملية سوف في runner تركيب قبل خروج، هذا حال شكل فقط إبقاء loader stderr تشخيص. جولة داخل فشل تشغيل ما زال سوف بـ `final` حدث (عبر معتاد لـ فارغ) انتهاء كما لا يوجد `error` حدث، لذلك صيغة جيد جيد حدث تدفق أيضا ممكن وصف مرة فشل تشغيل: طلب يأخذ خروج رمز 1 و `turn_end` سبب بصفة فشل إشارة.

### أي وقت استخدام

في نص برمجي تحويل أو تلقائي تحويل dsh تشغيل في استخدام headless——CI خطوة، دفعة معالجة مهمة، من طرفية سريع سرعة نيل أخذ جواب سجل. عند حاجة كثير جولة تفاعل جلسة أو GUI وقت طلب تجنب تجنب هو؛ متصفح جدول طبقة ([dsh-web-app](../web-app/README.zh.md)) مسؤول هذا صنف مشهد. عملية فقط لـ هذا مرة تشغيل بينما تخزين نشط، لا فتح استماع طرف فتحة، و كما ذاتي سطر خروج، لذلك ملائم دمج انتظار عملية انتهاء خط الإنتاج. عند مراقبة إشراف عملية حاجة دخول درجة بينما لا فقط هو جواب سجل وقت،`--json` توفير حدث تدفق،`--session-id` فإن يجعل لاحق استدعاء متابعة نفس مقطع محادثة.

### مساعدة مساعدة و مهمة خطأ

`dsh --profile headless --help` ضرب طبع هذا أمر مساعدة مساعدة نص و مباشر خروج، لا تشغيل أي محتوى. فقط لديه فارغ أبيض موضع معامل ذاته حينئذ يخص استخدام قاعدة خطأ——ماذا كل لا تشغيل، عملية خروج 1، أي جعل stdin لا هو طرفية أيضا واحد مثال، لذلك خطأ نقل فارغ أبيض معامل أبدا سوف إزالة استهلاك إدارة طريق محتوى. تماما ناقص مهمة وقت، فقط في stdin هو طرفية وقت يخص استخدام قاعدة خطأ؛stdin لا هو طرفية وقت،runner تعديل من stdin قراءة مهمة، و بـ نفس مثال طريقة رفض فارغ نتيجة. مفرد وحيد `-` هو وحيد stdin علامة؛ يأخذ هو و أخرى مهمة كلمة خلط استخدام يخص استخدام قاعدة خطأ، بينما لا هو بـ وصل محرف فتح رأس مهمة. في `--json` نمط تحت، كل استخدام قاعدة خطأ——يشمل commander ذاته لغة قاعدة رفض، مثال مثل لم معرفة خيار أو خيار نقص قليل أخذ قيمة——كل سوف في عملية خروج قبل نحو stdout كتابة خروج `error` حدث، لذلك حسب سطر تحليل مراقبة إشراف عملية أي جعل runner من لم تركيب أيضا قدرة يرى صيغة جيد جيد حدث تدفق؛ حدث `message` في نص لا حمل commander `error: ` بادئة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

runner هو نواة قلب API تحميل جسم لـ فوق مباشر مشغل: هو تحديد Agent معرف——افتراضي هو كل جديد `session-<uuid>`، أو `--session-id` إشارة اسم حفظ دائم Session——و يأخذ الذي تابع حفظ دائم حدث منطقة بين طي صار واحد عملية درجة نتيجة.

### تشغيل مسار

runner انتظار كامل تطبيق تسوية (`ctx.get('loader')?.await()`) ، تأكيد حفظ قد تركيب أداة و مهايئ لن نصف تركيب، قراءة مشترك [`agentDefaultModel`](../../core/agent-default-model/README.zh.md) اختيار، من إعداد أو stdin تحليل مهمة، لكن بعد تحديد Agent معرف: افتراضي هو كل جديد `session-<uuid>`، أو هو `--session-id` إشارة اسم حفظ دائم Session——عبر [`sessionQuery`](../../session-query/session-query/README.zh.md) امتداد استخدام، سجل لا وجود وقت رفض. هو يأخذ مهمة بصفة عادي مستخدم رسالة إيداع. لا حمل `--json` وقت، هو يأخذ هذا Agent غير فارغ دفع إدارة زيادة كمية تدفق صيغة كتابة stderr؛ حمل `--json` وقت تعديل لـ إسقاط هذا مرة تشغيل. هو انتظار تماما توقف مستقر، لكن بعد مقابل جلسة تنفيذ flush، و يأخذ الذي تابع منطقة بين (من `firstSeq` بدء) طي لـ الأكثر بعد واحد بند غير فارغ `assistant/message` نص و نهائي `turn/end` سبب. الأكثر بعد، هو يأخذ نهائي نص كتابة stdout(أو `final` حدث) و طلب خروج.

### أساس في base patch محتوى

patch تراكم إضافة في `dsh-base` لـ فوق: وراثة إسقاط ذاكرة مؤقتة و مشترك PTC وقت التشغيل، في أساس أساس `system-prompt` سطر فوق ضبط تحرير رمز persona بادئة و مستقل cwd بعد لاحقة، إبقاء و Web جدول طبقة نفسه مؤقت عملية درجة PTC mode فتح صلة (`DSH_TOOLS_MODE`) ، منع استخدام مشترك HMR(حار وحدة استبدال) سطر، و تركيب بدء مزود و runner. ذاكرة مؤقتة لـ كل قد حفظ دائم مرة صفة جلسة كتابة فحص نقطة، توفير لاحق مستهلك استخدام؛ ذلك حمل دائم صفة شاشة عائق سوف في إصدار ذاكرة مؤقتة سطر قبل flush الذي تغطية سجل بادئة، لذلك ممكن تفكيك قسم أصل هذا سوف دمج JSONL وصل متابعة مقطع. بدء مزود ([`src/startup.ts`](src/startup.ts)) حقن `ctx.cmdlineArgs`([`dsh-cmdline`](../../boot/cmdline/README.zh.md)) ، قراءة موضع معامل و `--session-id`/`--json` خيار، ضرب طبع تطبيق ذاتي ذات `--help`، و توفير `headlessStartup`؛runner حقن هذا خدمة، مجددا من كسول صفة إعداد في قراءة مهمة و تشغيل خيار.

### خروج خريطة

نهائي `turn/end` إتمام وقت خروج رمز لـ 0؛ أي أخرى نتيجة——aborted،error، أو الذي تابع منطقة بين داخل لا يوجد جولة——خروج رمز لـ 1. انتهاء سبب لـ `error` وقت أيضا سوف نحو stderr كتابة `dsh: <code>: <message>`. مباشر مشغل فشل (مثال مثل Agent إنشاء فشل أو غير ممكن استخدام `--session-id`) نحو stderr كتابة `dsh: <message>` و خروج 1، كما في `--json` نمط تحت مقدار خارج إرسال خروج واحد `error` حدث.

لا إصدار ثابت صيغة مرافق توليد مدخل، لأن runner يمكن مراقبة اتفاق (stdout نهائي نص، حسب جولة انتهاء سبب قرار خروج رمز) هو عملية درجة، من بدء جهاز e2e مسؤول؛ إضافة لا تسجيل أي محتوى، شجرة داخل أيضا لا يوجد أي متغير علاقة يمكن مراجعة حساب.

## تجربة النموذج

بلا، لأن runner يأخذ مهمة بصفة عادي مستخدم رسالة إيداع، نص التوجيه و أداة من تركيب خروج base و headless سطر توفير.

#### KV Cache أثر

runner لا نحو طلب بادئة إضافة أي محتوى؛ هو فقط هو قيادة تركيب خروج إعداد شجرة معالجة واحد بند مستخدم رسالة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد إبلاغ إبلاغ أنت headless أي وقت لا ملائم استخدام، هو حاجة `dsh` بدء جهاز توفير ماذا. هو جمع هو حالي حزمة قيد، لا هو عام CLI(أمر سطر واجهة) مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مرة تشغيل واحد مهمة**——مهمة نيل إلى عودة جواب بعد عملية أي خروج؛ لا يوجد تفاعل صيغة لاحق، لذلك كثير خطوة عمل طلب تفكيك صار كثير مرة تشغيل.
- **عبر `dsh` بدء جهاز تشغيل**——بـ أخرى طريقة بدء headless profile سوف في بدء وقت فشل، لأن فقط لديه بدء جهاز قدرة طلب عملية خروج.
- **أول عدد token قبل لا يوجد قلب قفز**——افتراضي نمط تحت، مزود إرسال خروج رقم واحد غير فارغ دفع إدارة زيادة كمية قبل،stderr إبقاء ساكن صامت؛ تأخير متأخر أول عدد token مزود لن أكثر مبكر إعطاء خروج دخول درجة إشارة.
- **دفع إدارة دخول stderr سجل**——افتراضي نمط تحت، إعادة تحديد نحو و مراقبة إشراف عملية ممكن إبقاء إظهار بارز أكثر كثير كما ممكن حساس شعور نموذج إخراج؛ حاجة وقت ينبغي يأخذ stderr توجيه إلى تلقي تحكم موضع.
- **افتراضي stdout فقط تحمل تحميل نهائي جواب سجل**——لا يوجد assistant رسالة تشغيل نحو stdout ضرب طبع فارغ سطر و بـ 1 خروج؛ في بين أداة إخراج لن ضرب طبع، حذف غير صريح تفعيل `--json`.
- **امتداد استخدام تلقي cwd، ملكية و preset حد**——`--session-id` سوف رفض سجل في أخرى عمل دليل، لم سجل عمل دليل، يخص فرعي agent أو fork جلسة، أو تشغيل في هذا profile لا تركيب agent preset تحت Session،preset سجل شاذ شكل Session، و اشتراط قد تركيب Session استعلام و حفظ دائم خدمة؛ هذا عملية في قد تخزين نشط هوية نفس مثال سوف يتم رفض، لأن runner لا يمكن مقابل هو أخذ نيل وحيد احتلال تشغيل منطقة بين.
- **حدث تدفق هو إسقاط بينما غير سجل**——`--json` حذف إنهاء `final` خارج يأخذ كل نص و كائن مفتاح حد في 8 KiB، و حذف إسقاط لم بناء نموذج حدث، لذلك هو لا هو Session سجل بلا ضرر فرعي هذا.
