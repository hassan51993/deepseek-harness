# @deepseek-ai/dsh-base

[English](README.md) | العربية

## عام وصف

كل أساس في base `dsh --profile` جدول طبقة كل تشغيل في `dsh-base` فوق، لذلك هذه جدول طبقة مشترك نموذج اتصال، كامل أداة تجميع، حمل دائم جلسة تاريخ و workspace أمان قيمة افتراضية. مع مرفق `sdk-minimal` profile لحظة معنى تعديل استخدام كامل مستقل إعداد شجرة. أنت عبر معتاد لا مباشر عملية هذا تركيب حزمة——مع إرسال سطر إصدار تسليم أساس في base profile قد يتضمن هو، ذاتي تعريف أساس في base profile فإن يأخذ هو وضع في رقم واحد موضع. حاجة أخرى قيمة افتراضية وقت، ينبغي تعديل ذاتي ذات profile patch أو إضافة لاحق تركيب حزمة؛ هذه الحزمة لا هو توفير استيراد مكتبة.

## استخدام هذه الحزمة

أنت سوف تلقائي نيل نيل dsh نواة قلب: مع إرسال سطر إصدار تسليم `web`،`headless`،`sdk` و `acp` profile قد يتضمن هو، ذاتي تعريف profile فإن يأخذ هو صف لـ رقم واحد تركيب حزمة. بعد واحد قطع بلا حاجة أي مقدار خارج إعداد يكفي عمل.

### الأكثر صغير ذاتي تعريف profile

يلزم في مشترك نواة قلب لـ فوق بناء profile، طلب إنشاء واحد profile، ذلك `package.json` يأخذ `@deepseek-ai/dsh-base` صف في أول موضع:

```json
{
  "name": "my-profile",
  "private": true,
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base"]
    }
  }
}
```

تشغيل `dsh --profile my-profile "your task"`، أنت حينئذ نيل إلى واحد متاح agent(ذكي جسم) ، حمل نموذج وصول، أداة، حفظ دائم و افتراضي إذن سياسة. مع إرسال سطر إصدار تسليم `web`،`headless`،`sdk` و `acp` profile سوف في أول مرة استخدام وقت لـ أنت إنشاء. يلزم إضافة أكثر كثير تركيب حزمة، تشغيل `dsh plugin --profile <name> add <package>`؛ داخل وضع تركيب حزمة من dsh تثبيت دليل تحليل.profile اتفاق رؤية [app-boot profile فصل عقدة](../../boot/app-boot/README.zh.md).

### أنت نيل إلى ماذا

فتح صندوق أي استخدام، أساس في هذا نواة قلب بناء كل profile كل توفير:DeepSeek نموذج اتصال (مزود و نموذج يمكن إعداد، أنت أيضا يمكن في ضبط في تفعيل مقدار خارج مزود) ، كامل أداة تجميع——ملف تحرير،shell أمر،web بحث، عام HTTP(S) إمساك أخذ،subagent، مهمة و هدف تتبع أثر——يمكن عبر إعادة بدء تخزين نشط حمل دائم جلسة، و افتراضي إذن سياسة: يأخذ ملف كتابة حد في مساحة العمل داخل، خطر خطر عملية قبل سمة استفسار سماح يمكن.Web إمساك أخذ بلا حاجة تدريجي مرة مراجعة دفعة، ذلك مزود سوف رفض غير عام هدف عنوان. عكس تغذية حفظ في جلسة سجل في.[OTel جلسة فوق نقل](../../session/session-telemetry-otel/README.zh.md) مقابل كل مستخدم افتراضي استخدام `FEEDBACK_ONLY`، يشمل `deepseek-official`: جديد نص عكس تغذية، رسالة تقييم قسم، تحرير و سحب عودة سوف تحرير قطع حتى هذا حدث كامل مواصفة جلسة سجل بادئة، يتضمن سياق. لاحق سجل انتظار تحت مرة صريح عكس تغذية؛ إرسال قد تخويل دفعة مرة بلا حاجة دخول واحد خطوة تفاعل أو نموذج استدعاء.`DISABLED` منع توقف OTel التقاط. افتراضي فتح بدء [DeepSeek جلسة سجل مساهمة جهاز](../../session/session-log-deepseek/README.zh.md) ما زال هو مستقل طلب مسار.

افتراضي ملف تحرير استخدام `read`،`write` و `edit`.`str_replace_editor` أداة ما زال يمكن صريح تفعيل. يلزم سوف هو إضافة دخول أساس في base profile، طلب في profile،home أو تدريجي مرة استدعاء patch في إضافة التالي بند:

```yaml
- insert:
    - id: tool-str-replace-editor
      name: '@deepseek-ai/dsh-tool-str-replace-editor'
      config:
        maxOutputChars: 16000
```

هذا bundle موحد واحد تركيب [MCP مورد](../../mcp/mcp-resources/README.zh.md) مرة. فقط يحتاج لـ الذي يحتاج خادم إعداد [MCP عميل بند](../../mcp/mcp-client/README.zh.md). أخرى مزود تركيب عميل في الذي تابع أثر مجال في أيضا يخص قد إعداد حالة. استدعاء جهة أثر مجال في لا يوجد قد إعداد خادم وقت، لن نيل نيل MCP أداة أو نص التوجيه نص.

### كل منصة shell أداة

في macOS و Linux فوق أنت نيل نيل bash shell أداة؛ في Windows فوق فإن نيل نيل مقابل PowerShell توأم توليد أداة، لذلك كل منصة آلة جهاز تماما جيد لديه واحد طقم shell مكدس. كل منصة أمان سلوك تماما متسق. انحراف جيد لا تلقي رمل صندوق قيد PowerShell منفذ Windows رئيسي آلة يمكن في ذلك profile patch في تبديل shell سطر——تبديل يجب معا منع استخدام اثنان عدد PowerShell سطر و إعادة تفعيل اثنان عدد bash سطر، لا فإن profile لا يمكن تحميل.

### أكثر تعديل قيمة افتراضية

يلزم تغيير أساس في هذا نواة قلب بناء profile توفير محتوى——مختلف افتراضي نموذج، أكثر صارم إطار إذن نمط، أكثر كثير أو أكثر قليل أداة——طلب تحرير profile `cordis.patch.yml` أو إضافة بعد وجه تركيب حزمة. كل patch بند سوف استبدال هدف كامل إعداد، لذلك طلب إعادة وصف كل تفكير إبقاء ضبط. إبقاء صندوق رملي تحويل نظام الملفات مزود بصفة وحيد ملف كتابة مسار: في ذلك لـ فوق مجددا إضافة عادي نظام الملفات مزود سوف توجيه يؤدي profile تحميل فشل.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا تركيب حزمة هو واحد نسخة ساكن حالة patch وثيقة: واحد تطبيق إلى فارغ profile أصل لـ فوق `insert` قائمة. هو لا تركيب أي خدمة، لا إرسال خروج أي حدث، أيضا لا يحتفظ أي متغير حالة؛ كل بند إدراج دخول سطر الذي تابع حزمة مسؤول هذا سطر سلوك و ثابت صيغة.

### تركيب آلية

patch سوف استبدال هدف سطر كامل `config`، بينما لا هو دمج دخول هو. لاحق تركيب حزمة طبقة و مستخدم profile `cordis.patch.yml` حسب id تغطية سطر، كل سطر الأكثر بعد مرة كتابة توليد فاعلية. حسب نمط أخذ قيمة مختلف سطر لا يخص هذا داخل: كل نمط تركيب حزمة إعادة وصف ذاتي ذات كامل إعداد، يجعل أي مفرد واحد سطر الأكثر كثير فقط يخص واحد تركيب حزمة طبقة إضافة مستخدم طبقة. كامل سطر تجميع دمج و ذلك تصميم اعتماد حسب بـ سطر داخل ملاحظة تفسير كتابة في [`cordis.patch.yml`](cordis.patch.yml) داخل؛[توليد تركيب رسم](../../../apps/cli/composition.md) مسؤول تصيير هو.

### منصة باب تحكم

patch في ذاته فوق حسب منصة باب تحكم اثنان عدد shell مكدس:`bash-sandbox` و `tool-bash` يحمل `disabled: !!js process.platform === 'win32'`، توأم توليد سطر `pwsh-sandbox` و `tool-pwsh` بـ أخذ عكس جدول بلوغ صيغة فقط في win32 تركيب. إذن وجه و POSIX تماما متسق: صندوق رملي سياسة عبر Windows ACL تلقي حد أمر لوحة runner(`dsh-sandbox-local` → `@deepseek-ai/dsh-sandbox-windows-acl`) تنفيذ نفسه ملف فاعلية نتيجة سياسة،`fs-sandbox` متابعة محيط شريط `ctx.fs` كتابة——في ذلك جانب مجددا تركيب `dsh-fs-local` سوف تكرار تسجيل `ctx.fs` و في تحميل وقت فشل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`cordis.patch.yml`](cordis.patch.yml) | تركيب حزمة فعلي جسم: أساس أساس إضافة سطر، مرفق بـ سطر داخل ملاحظة تفسير شرح كل سطر اعتماد حسب |
| [`src/index.ts`](src/index.ts) | حزمة مدخل؛ لا يحمل أي وقت التشغيل API |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذه الحزمة هو ساكن حالة patch قائمة تحميل جسم (من أخرى حزمة يملك loader سطر بنية صار YAML وثيقة) ؛ هو لا تركيب أي خدمة، لا إرسال خروج أي حدث، أيضا لا يوجد أي يمكن فحص متغير علاقة. كل بند إدراج دخول سطر الذي تابع حزمة مسؤول هذا سطر ثابت صيغة. |
| [`tests/base.spec.ts`](tests/base.spec.ts) | manifest(بيانات وصفية بيان) إعلان و منصة باب تحكم فحص |

### ثابت صيغة ملكية

لا إصدار ثابت صيغة مرافق توليد مدخل، لأن هذه الحزمة هو ساكن حالة patch قائمة تحميل جسم: كل بند إدراج دخول سطر من الذي تابع حزمة مسؤول ذلك ثابت صيغة، تركيب حزمة ذاته لا يوجد أي يمكن مراجعة حساب متغير علاقة.

<a id="model-experience"></a>
## تجربة النموذج

عبر كل بند إدراج دخول سطر الذي تابع حزمة بين وصل إنتاج أثر، من كل حزمة مسؤول ذلك سطر نموذج مرئي سلوك.

#### KV Cache أثر

تركيب حزمة ذاته لا إضافة أي طلب بادئة؛ كل بند إدراج دخول سطر الذي تابع حزمة مسؤول كل منها ذاكرة مؤقتة أثر.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد إبلاغ إبلاغ أنت نواة قلب أي وقت حاجة مقدار خارج ملاحظة معنى، تغطية ينبغي وضع في أي داخل. هو جمع هو حالي حزمة قيد، لا هو عام مقابل مقارنة أو مهمة تراكم ضغط.

- **تغطية سوف استبدال كامل ضبط كتلة**——patch بند سوف استبدال هدف كامل إعداد، لذلك أنت تغطية يجب إعادة وصف كل تفكير إبقاء ضبط؛ لن تلقائي دمج.
- **حسب جدول طبقة ضبط يخص هذا جدول طبقة تركيب حزمة**——web GUI و headless نمط أخذ قيمة مختلف قيمة افتراضية وضع في مقابل جدول طبقة تركيب حزمة داخل، بينما لا هو مشترك نواة قلب.
- **Windows مؤقت دليل تخويل هو حسب جلسة خاص فرعي دليل**——`workspace-write` يأخذ كتابة حد في مساحة العمل و جلسة ذاتي ذات temp فرعي دليل (`<temp>\dsh-<hash>`، تلقي حد عملية فرعية TMP/TEMP يتم تعديل كتابة) ؛`read-only` لا منح إعطاء أي مؤقت دليل كتابة إذن. رؤية `@deepseek-ai/dsh-sandbox-windows-acl`.
- **في صندوق رملي تحويل نظام الملفات مزود لـ فوق إضافة عادي مزود سوف توجيه يؤدي profile فشل**——اثنان من تسجيل نفس عدد خدمة،profile لذلك رفض تحميل؛ اثنان اختيار واحد.
