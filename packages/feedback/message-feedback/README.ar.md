# @deepseek-ai/dsh-message-feedback

[English](README.md) | العربية

## عام وصف

هذا خدمة لـ قد إتمام assistant رسالة سجل جيد تقييم، فرق تقييم، ثابت عكس تغذية تصنيف جدول في اختياري تصنيف، و اختياري أصل مثال ملاحظة. كل مرة إنشاء، تحرير و حذف كل من مرجعي Session سجل حفظ؛`list`،`put` و `delete` توفير حالي عكس تغذية، لن بنية صنع أو نداء تنبيه agent(ذكي جسم). عكس تغذية فقط كتابة سجل، لا دخول نموذج تاريخ.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

سوف `dsh-message-feedback` و `sessions`،`sessionPersistence` واحد بدء تركيب. هو لا حاجة storage-domain خدمة.Web تركيب توفير متصفح مستهلك، و سوف ملاحظة حد أعلى ضبط لـ 8192 بايت.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxNoteBytes` | لا بد ملء | مفرد بند اختياري ملاحظة UTF-8 بايت حد أعلى، يجب لـ كبير في صفر أمان كامل عدد. |

إيداع ملاحظة يجب يتضمن غير فارغ أبيض محرف، كما لا تجاوز مرور إعداد بايت حد أعلى. فارغ أبيض ملاحظة إرجاع `note-blank`؛ مرور طويل ملاحظة إرجاع `note-too-large`. عبر تحقق نص سوف كامل إبقاء، يشمل أول ذيل فارغ أبيض. حذف ملاحظة سوف صاف حذف هو. ملاحظة تحقق أولا في Session فحص بحث. إيداع تصنيف يجب هو[ثابت عكس تغذية تصنيف](../command-feedback/README.ar.md#the-web-feedback-dialog) لـ واحد؛Remote schema رفض أخرى قيمة، حذف تصنيف سوف صاف حذف هو.

### قراءة و تعديل عكس تغذية

| عملية | طلب | نجاح | عمل خدمة فشل |
|---|---|---|---|
| `list` | Session id | حسب إنشاء ترتيب إرجاع حالي بند | Session لا وجود |
| `put` | Session، رسالة، تقييم قسم، اختياري ملاحظة، اختياري تصنيف، مسبق مدة إصدار | حالي بند | Session أو هدف لا وجود، إصدار اندفاع مفاجئ، ملاحظة بلا فاعلية |
| `delete` | Session، رسالة، مسبق مدة إصدار | بند لا وجود | Session لا وجود، إصدار اندفاع مفاجئ |

إنشاء وقت نقل دخول `ifVersion: null`؛ تحرير أو حذف وقت استخدام إرجاع إصدار. قديم قديم تعديل إرجاع `version-conflict` و حالي بند. كل مرة فعلي جودة put كل توليد جديد token، و إبقاء أصلي إنشاء وقت. تكرار قد تخزين تقييم قسم، ملاحظة و تصنيف put هو بلا تغير عملية: إرجاع نفسه بند، لا إلحاق حدث. حذف لا وجود بند بداية نهاية نجاح، لا تلقي الذي نقل إصدار أثر، أيضا لا إلحاق حدث. إعادة إنشاء قد حذف بند سوف إنتاج جديد إنشاء وقت و ترتيب ترتيب موضع.

هدف يجب هو من append مصدر حدث إنتاج غير فارغ assistant رسالة. مستخدم رسالة، فارغ assistant احتلال موضع و replacement مصدر رسالة إرجاع `target-not-found`. عكس تغذية عبر إعادة بدء إبقاء؛fork أي جعل وراثة يتضمن أب جلسة عكس تغذية بادئة، ابتدائي وقت أيضا لا يوجد ذاتي لديه عكس تغذية.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

### مرجعي سجل و حمل دائم صفة

`feedback/message-put` حفظ الذي تابع Session id و كامل بند، يشمل إصدار و ختم الوقت.`feedback/message-delete` حفظ الذي تابع Session و رسالة id. حالي حالة من هذه حدث دفع توجيه، تجاهل اختصار يخص أخرى Session حدث. حفظ دائم payload في استخدام قبل مرور مرور تحقق. لا وجود ثاني عدد عكس تغذية تخزين أو ذاكرة مؤقتة.

نشط وثب جلسة عبر `Session.append` إلحاق، و انتظار `sessions.flush`، لكن بعد عبر حفظ دائم قراءة جملة مقبض نواة فعلي التقاط سجل نهاية طرف و Session header، عندئذ سوف تقرير إبلاغ نجاح. بارد جلسة تعديل في قراءة، تحقق، مقارنة مقارنة، إلحاق،flush و إغلاق خلال يحتفظ حفظ دائم كتابة جملة مقبض. بارد قراءة استخدام قراءة جملة مقبض. اثنان بند مسار كل لن بنية صنع Session أو إلحاق دورة الحياة حدث.

كل Session طابور صف في نفس خدمة نسخة داخل سلسلة سطر تحويل عملية؛ حفظ دائم كتابة جملة مقبض ترتيب حذف أخرى بارد كتابة جهة. إلغاء تدمير وقت إيقاف استقبال عملية و ترتيب فارغ قد استقبال عملية، لكن بعد تحرير خدمة. حفظ دائم لذا عائق سوف reject، بينما غير تغيير صار عمل خدمة فشل.flush فشل لن تراجع قد قبول حدث؛ استدعاء جهة يمكن قراءة و استخدام ذلك إصدار إعادة محاولة. نجاح بلا تغير تعديل أيضا سوف flush حالي بادئة.

بارد جلسة فعلي جودة تعديل في flush بعد إرسال خروج `feedback/committed` إشعار، منها يحمل استعارة استخدام فقط قراءة مرجعي سجل بادئة؛ مراقبة جهة في تحويل نقل كل حق قبل يجب مقابل ذلك إجراء عميق نسخ صدفة. مراقبة جهة في كتابة كل حق تحرير قبل إتمام، لا نيل انتظار نفس Session أخرى عكس تغذية عملية، أيضا لا يستطيع جعل قد إيداع تعديل فشل. نشط وثب جلسة مستهلك مراقبة `session/event`.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | Remote خدمة،payload تحقق، حدث إسقاط و حفظ دائم كل حق |
| [`src/types.ts`](src/types.ts) | طلب، نتيجة و Session حدث إعلان؛ فقط نوع |

لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل: خدمة مباشر من تحقق بعد مرجعي حدث دفع توجيه عكس تغذية، لا يحتفظ يمكن مستقل تعديل إسقاط.

كل منها API رؤية[عكس تغذية فرعي نظام](../../../docs/subsystems/feedback.ar.md) ،[Session حفظ دائم](../../../docs/subsystems/persistence.ar.md) و[متصفح مستهلك](../../client/ui-message-feedback/README.ar.md).

## تجربة النموذج

### رسالة عكس تغذية

#### نموذج يرى ماذا

بلا.`feedback/message-put` و `feedback/message-delete` لا يحمل surface موضع، أداة، نص التوجيه مقطع سقوط أو نموذج مرئي سياق. سجل توجيه خروج و إلقاء تمرير سياسة من متبادل ينبغي مستهلك مسؤول.

#### Token أثر

لـ صفر. تقييم قسم، ملاحظة و خدمة نتيجة لا دخول نموذج طلب.

#### KV Cache أثر

متبادل متبادل مستقل. عكس تغذية لا تغيير نموذج طلب بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **فقط سجل أداة لديه مرجعي صفة:**لا قراءة أو ترحيل قائم `message_feedback` مرافق مع بيانات. هذه ملف إبقاء ثابت، لكن ذلك عكس تغذية لا يمكن عبر هذا خدمة وصول.
- **حذف إبقاء تاريخ:**delete إزالة حالي عكس تغذية، لن من فقط إلحاق سجل في صاف حذف أكثر مبكر تقييم قسم أو ملاحظة؛ هو لا هو خفي خاص مسح حذف عملية.
- **كتابة كل حق:**آخر عدد عملية يحتفظ Session كتابة جملة مقبض وقت، بارد جلسة تعديل سوف reject. خدمة لن نداء تنبيه هذا كل من، أيضا لا تنسيق ضبط عبر عملية Remote استدعاء.
- **تلقي معلومة مهمة استدعاء جهة:**طلب لا يتضمن مرور مرور إقرار إثبات actor أو مراجعة حساب هوية. نشر جهة يجب حفظ حماية Host شبكة صلة.
- **بعيد قياس توجيه خروج:**مقابل في كل مستخدم و مزود، يشمل `deepseek-official`، مع مرفق OTel خلفية في `FEEDBACK_ONLY` نمط تحت فقط في جديد صريح نص عكس تغذية، تقييم قسم، ملاحظة أو تصنيف تحرير، سحب عودة بعد تحرير كامل مرجعي سجل بادئة. بادئة يتضمن سياق و أصل مثال ملاحظة؛ لاحق سجل انتظار تحت مرة عكس تغذية،`DISABLED` منع توقف التقاط. نشر جهة مسؤول انفصال حساس؛ رؤية [OTel توجيه خروج سياسة](../../session/session-telemetry-otel/README.ar.md).
- **مسح صار هذا:**كل مرة وصول قد لديه Session `list`،`put` أو `delete` كل سوف مسح كامل حدث سجل قدوم دفع توجيه حالي عكس تغذية؛ بارد جلسة عملية أيضا سوف من حفظ دائم تخزين قراءة كامل سجل. عمل كمية مع Session تاريخ مجموع كمية زيادة طويل، بينما لا فقط هو عكس تغذية بند عدد.
- **إبقاء كمية:**`maxNoteBytes` فقط حد مفرد بند ملاحظة، لا حد سجل مجموع كبير صغير أو تغيير مرة عدد.
