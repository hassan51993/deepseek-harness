# feedback/: سجل شخص صنف عكس تغذية

[English](README.md) | العربية

## عام وصف

feedback مجموعة استلام تجميع مستخدم مقابل harness عمل صار نتيجة معنى رؤية: مستخدم يمكن إيداع واحد بند صلة في كامل جلسة ذاتي من نص تقييم قيمة، أيضا يمكن مقابل مفرد بند assistant رسالة تقييم قسم أو إضافة ملاحظة. اثنان صنف عكس تغذية كل لن وصول نموذج——هو جمع هو صلة في إخراج إشارة، أبدا هو إدخال. مستخدم عبر `/feedback` أمر سجل جلسة تقييم قيمة؛ منتج واجهة عبر `messageFeedback` خدمة قراءة و تعديل تدريجي رسالة تقييم قسم. اثنان عدد حزمة متبادل متبادل مستقل: جلسة تقييم قيمة و تدريجي رسالة تقييم قسم متبادل لا أثر. هذا صفحة عام وصف هذا حزمة مجموعة؛ أداة جسم حزمة درجة اتفاق بـ كل حزمة README و[عكس تغذية فرعي نظام صفحة](../../docs/subsystems/feedback.zh.md) لـ دقيق.

## حزمة

| حزمة | مسؤولية |
|---|---|
| [`command-feedback`](command-feedback/README.zh.md) | جلسة درجة عكس تغذية:`/feedback` أمر،Web نابض نافذة خلف بعد `sessionFeedback` Remote، و ثابت تصنيف جدول، متساو بلا حاجة نموذج جولة |
| [`message-feedback`](message-feedback/README.zh.md) | تدريجي رسالة تقييم قسم، تصنيف و ملاحظة، عبر `messageFeedback` خدمة توفير إعطاء منتج واجهة |

جلسة تقييم قيمة هو مفرد نحو إشارة: في محادثة أي وقت لحظة سجل هو كل هو أمان، كما أبدا سوف تغيير نموذج يرى محتوى. في feedback-gated مشترك سياسة تحت، سجل جلسة تقييم قيمة سوف إطلاق وضع سطر، جعل هذا جلسة يمكن توفير مشترك.

تدريجي رسالة تقييم قسم و ملاحظة و جلسة واحد بدء حفظ، إعادة بدء بعد اعتماد لكن وجود، و كما أبدا سوف ظهور في نموذج تاريخ أو بعيد قياس في.
