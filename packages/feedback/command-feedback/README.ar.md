# @deepseek-ai/dsh-command-feedback

[English](README.md) | العربية

## عام وصف

`dsh-command-feedback` يجعل مستخدم إبلاغ إبلاغ harness هو جمع مقابل جلسة نظر قاعدة. إدخال `/feedback` إضافة واحد بند تقييم قيمة، تقييم قيمة أي يتم سجل، و بـ جلسة id و مجهول اسم مستخدم id تأكيد؛Web ملاحظات نابض نافذة عبر `sessionFeedback` Host Remote سجل تصنيف و اختياري وصف. سجل هو أي وقت، أبدا سوف بدء نموذج عمل: نموذج حيث نظر لا إلى هذا بند تقييم قيمة، أيضا لن يتم ضرب قطع. هذه الحزمة معا يملك كل ملاحظات واجهة مشترك استخدام ثابت تصنيف جدول. هو مع معيار `dsh` أساس أساس تركيب تسليم، بلا حاجة أي إعداد؛ بلا رأس نمط،ACP(Agent Client Protocol) و JSON-RPC مدخل لا توفير مائل عمود أمر.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

مستخدم يمكن مباشر في Web عميل في سجل ملاحظات:`/feedback` أمر مع معيار `dsh` أساس أساس تركيب تسليم، بلا حاجة إعداد، يمكن في أي محادثة في استخدام. ذاتي تعريف تطبيق يجب يأخذ Session خدمة، أمر سجل التسجيل و هذا إضافة تركيب في واحد بدء، عندئذ قدرة توفير نفس مثال أمر.

### `/feedback` أمر

إدخال `/feedback` إضافة أنت تقييم قيمة تزامن إرسال. نجاح وقت سوف بـ استقبال جلسة id و مجهول اسم مستخدم id تأكيد:

| إدخال | نتيجة |
|---|---|
| `/feedback the diff view is unreadable` | سجل تقييم قيمة و بـ اثنان سطر تأكيد:`Feedback recorded for session {sessionId}` و `Anonymous user: {userId}.` |
| `/feedback` | استخدام قاعدة خطأ:`Feedback text is required. Usage: /feedback <text>`. فقط يحتوي فارغ أبيض إدخال نظر لـ فارغ إدخال. |

قبل بعد فارغ أبيض سوف يتم ذهاب حذف، لكن حذف هذا خارج، تقييم قيمة سوف حسب إدخال أصل مثال إبقاء: لا إجراء مقتطع، كبير صغير كتابة طي أو أمر تحليل——`/feedback /plan felt slow` سجل حينئذ هو هذا مقطع حرف وجه نص. كل مرة تنفيذ أمر كل سوف سجل ذاتي ذات بند؛ لن حدوث دمج أو استبدال.

<a id="the-web-feedback-dialog"></a>
### Web ملاحظات نابض نافذة

في Web عميل في، لا حمل نص `/feedback`(من إدخال إطار قائمة مفرد اختيار في، أو مباشر إدخال بعد إرسال) سوف فتح ملاحظات نابض نافذة، بينما لا هو إرجاع استخدام قاعدة خطأ. نابض نافذة توفير تحت جدول سبعة عدد تصنيف و واحد ذاتي من نص إطار؛ كل واحد بند كل يمكن لا ملء، فارغ إيداع أيضا سوف يتم قبول، محادثة سجل و أخرى ملاحظات حدث واحد مثال مع سجل حدث واحد بدء إلقاء تمرير. نابض نافذة عبر `sessionFeedback.record` سجل، إلحاق هو نفس عدد `feedback/record` حدث، لكن لا يوجد أمر دفتر تسجيل، أيضا لا يوجد تأكيد سطر؛ نابض نافذة تعديل استخدام toast تلميح.

| تصنيف id | يحتوي معنى |
|---|---|
| `task-result` | مهمة نتيجة |
| `instruction-following` | إشارة أمر إدارة حل و التزام دوران |
| `product-interaction` | منتج وظيفة و تفاعل |
| `service-stability` | مستقر صفة و سرعة درجة |
| `resource-cost` | مورد استخدام و استهلاك استخدام |
| `security-privacy-permission` | أمان خفي خاص و إذن |
| `other` | أخرى |

هذه id هو سجل في حمل دائم مفردات، و تدريجي رسالة ملاحظات مشترك استخدام؛ كل واجهة ذاتي سطر يملك محلي تحويل وسم.

### من ذاتي ذات UI سجل ملاحظات

ملاحظات لا واحد تحديد قدوم ذاتي مائل عمود أمر أو نابض نافذة: أي UI، خطاف أو host تجميع صار كل يمكن عبر `recordFeedback` أو `sessionFeedback` Remote مباشر سجل تقييم قيمة، مشاركة لديه نفس مثال حفظ إثبات كما بلا حاجة نموذج جولة. تفكير يلزم مائل عمود أمر ذاتي تعريف تطبيق، يأخذ Session تخزين، أمر سجل التسجيل و هذا إضافة تركيب في واحد بدء يكفي؛`sessionFeedback` Remote من Session تخزين في تحليل live Session:

```yaml
- id: session
  name: '@deepseek-ai/dsh-session'
- id: commands
  name: '@deepseek-ai/dsh-commands'
- id: command-feedback
  name: '@deepseek-ai/dsh-command-feedback'
```

Web عميل مع مرفق هذا أمر. بلا رأس نمط،ACP تلقائي تحويل و JSON-RPC لا توفير مائل عمود أمر، لذلك `/feedback` في ذلك داخل غير ممكن استخدام.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### تصميم إدارة فكرة

تقييم قيمة هو جلسة سجل في واحد فقط إلحاق واقع، من حدث بينما غير إنتاج هو إطلاق طريقة يملك: ملاحظات ممكن قدوم ذاتي أمر، نابض نافذة أو أي تجميع صار، لذلك واقع أبدا قدرة اعتماد مائل عمود أمر. أمر ذاته دفتر تسجيل لا يحمل تحميل حمل، الذي بـ تقييم قيمة نص في سجل في فقط وجود في واحد أرض جهة، كما هذا حدث أبدا سوف عرض إعطاء نموذج.

### تقييم قيمة مثل أي يتم سجل

إنتاج جهة ذهاب حذف نص فارغ أبيض، يأخذ فارغ أبيض نص تسجيل لـ نقص حذف، و نحو جلسة سجل كتابة واحد حدث، أي جعل بند حيث بلا نص أيضا بلا تصنيف؛`/feedback` معالج ذاتي سطر رفض فارغ إدخال، ذلك بقية جزء هو هذا إنتاج جهة رقيق حزمة تركيب طبقة؛`sessionFeedback.record` Remote فإن حسب id بحث إلى live Session بعد نفس مثال استدعاء هو، لا يوجد live يحتفظ من وقت عودة جواب `session-not-found`. اثنان بند مسار كل لا بدء نموذج عمل. كتابة هو أي وقت لكن لم flush : تأكيد نص يمثل بند قد وصول سجل، بينما لا هو قد سقوط قرص. بعض عدد harness home أول مرة قبول أمر تقييم قيمة أيضا سوف إنشاء تأكيد نص الذي تقرير إبلاغ مجهول اسم مستخدم id. دقيق إنتاج جهة اتفاق رؤية [`src/index.ts`](src/index.ts) ؛ حدث تحميل حمل، تصنيف جدول و Remote مفردات رؤية [`src/types.ts`](src/types.ts).

### شفرة المصدر بحث جذب

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`recordFeedback` إنتاج جهة،`sessionFeedback` Remote خدمة،`/feedback` أمر تسجيل |
| [`src/types.ts`](src/types.ts) | `feedback/record` حدث إعلان، تصنيف جدول، و Remote طلب و نتيجة نوع |
| — | لم إصدار إعداد طقم وقت التشغيل ثابت صيغة؛ كل `feedback/record` كل هو مستقل فقط إلحاق واقع، لا تعلق و عبر حدث علاقة أو و متغير بيانات علاقة. |

</details>

عند حزمة درجة اتفاق لا كاف استخدام وقت قراءة قراءة التالي صفحة. هو جمع شمول غطاء هذا بند أخذ تجميع مسار الذي اعتماد أمر سجل التسجيل، حفظ دائم و هوية واقع.

- [dsh-commands](../../interaction/commands/README.ar.md)——اكتشاف عام أمر و تعريف `recordInput` دلالة سجل التسجيل.
- [جلسة حفظ دائم فرعي نظام](../../../docs/subsystems/persistence.ar.md)——إلحاق حدث مثل أي حفظ دائم،flush شاشة عائق يحتوي معنى.

- [ui-message-feedback](../../client/ui-message-feedback/README.ar.md)——عبر `sessionFeedback` Remote سجل Web ملاحظات نابض نافذة.

<a id="model-experience"></a>
## تجربة النموذج

### مستخدم `/feedback` أخذ تجميع

#### نموذج يرى ماذا

بلا. مائل عمود إدخال، نابض نافذة،`feedback/record` و تأكيد نص كل لا ظهور في نموذج طلب في. ملاحظات حدث و سجل التسجيل دورة الحياة سجل فقط كتابة سجل كما لا يحمل `surfaceOp`، لذلك هو جمع أبدا سوف دخول لديه ترتيب surface،`deriveMessages()` أو توجيه النظام. في بعض عدد جولة في سجل ملاحظات لن تغيير هذا جولة باق بقية طلب.

#### Token أثر

بلا مباشر token أثر. بلا نقاش هو قد قبول بند أيضا هو استخدام قاعدة خطأ، كل لن في سجل الذي في جولة أو هذا بعد أي جولة زيادة نموذج token.

#### KV Cache أثر

و نموذج طلب مسار غير متصل. سجل فقط إلحاق إلى جلسة سجل، لا لمس اصطدام قد يمكن إعادة استخدام طلب بادئة. هذه الحزمة مساهمة أي محتوى كل لن جعل ذاكرة مؤقتة إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح جلسة ملاحظات أي وقت لا دمج ملائم، أو أي وقت سلوك و مستخدم مسبق مدة مختلف. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **لا يوجد ملاحظات فحص بحث أو إدارة surface**——هذه الحزمة لا لـ `feedback/record` توفير فحص بحث، تجمع دمج أو موجه إلى نموذج أداة.
- **فقط لديه تصنيف و نص**——واحد بند بند حتى كثير يحمل واحد تصنيف و واحد ذاتي من نص نص، لا يوجد صارم إعادة مسار درجة أو صلة ربط حدث رابط.
- **Remote فقط خدمة live Session**——لا يوجد live يحتفظ من Session،`sessionFeedback.record` عودة جواب `session-not-found`؛ نابض نافذة فتح خلال Session تراجع دور وقت،Web نابض نافذة سوف تقرير إبلاغ هذا فشل.
- **لا دعم حمل تعديل أو سحب عودة**——جلسة سجل هو فقط إلحاق، هذه الحزمة أيضا لا إضافة جديدة tombstone، لذلك خطأ بند سوف واحد مباشر إبقاء في سجل في، فقط قدرة من لاحق بند يحل محل.
- **لا يوجد صريح حفظ دائم شاشة عائق**——تأكيد نص ضيق مع إلحاق بينما غير flush، لذلك ضيق قرب انهيار انهيار قبل سجل بند ممكن و أخرى لم flush ذيل جزء واحد نفس فقد فقد. حاجة هذا حفظ إثبات مستهلك يمكن ذاتي سطر انتظار `ctx.sessions.flush(session)`.
- **جلسة جديدة فوق لا يوجد مرئي تأكيد**——Web transcript(نص سجل) فقط في جلسة تنشيط بعد تصيير أمر سطر، لذلك في ما زال لـ فارغ أبيض جلسة جديدة فوق إدخال `/feedback <text>` سوف سجل حدث لكن لن عرض تأكيد سطر؛ نابض نافذة toast لا اعتماد نص سجل.
- **مع مرفق منتج مدخل في فقط لديه Web استخدام هذا أمر**——بلا رأس نمط،ACP تلقائي تحويل و JSON-RPC لا توفير أمر مهايئ، لذلك `/feedback` في ذلك داخل غير ممكن استخدام.
