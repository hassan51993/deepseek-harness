# @deepseek-ai/dsh-web

[English](README.md) | العربية

## عام وصف

استخدام `dsh-web` بحث web أو إمساك أخذ URL، بينما بلا حاجة يجعل استدعاء جهة اعتماد خاص تحديد مصنع تجارة. هو لـ كل بند عملية اختيار متاح خلفية، و لـ استدعاء جهة توفير متسق إلغاء، خطأ و نتيجة حد أعلى. في استدعاء `ctx.web.search()` أو `ctx.web.fetch()` إضافة أو أداة في اختيار هو؛ قد تسليم `dsh-tool-web` أداة سوف لـ أنت تحميل هو. بحث أو إمساك أخذ حاجة قد إعداد كما متاح مزود، لأن هذه الحزمة ذاته لا إرسال بدء شبكة شبكة طلب.

## استخدام هذه الحزمة

حاجة web وصول تركيب سوف تحميل `dsh-web` خدمة و تركيب حتى قليل واحد خلفية——بحث مزود و/أو إمساك أخذ مزود——إضافة أو أداة عمل من مع بعد مباشر استدعاء `ctx.web.search()` و `ctx.web.fetch()`. خدمة سوف لـ كل مرة استدعاء تحليل خلفية، لذلك حذف غير استدعاء جهة إعداد مزود id، لا فإن هو جمع نظر لا إلى مزود id.

### أي وقت اختيار

عند إضافة أو أداة يجب بحث أو إمساك أخذ، أيضا لا أمل نظر صلب تحرير رمز مصنع تجارة وقت اختيار هذا خدمة؛ فقط استخدام قد تسليم `web_search`/`web_fetch` أداة تركيب سوف عبر `dsh-tool-web` تلقائي تحميل هذا خدمة. عند تركيب من لا وصول web وقت، أنت لا حاجة هو. خدمة ذاته لا زيادة أي شبكة شبكة وصول قدرة: لا يوجد حتى قليل واحد متاح مزود وقت، كل مرة استدعاء كل سوف بـ بنية تحويل `WebError` فشل.

### الأكثر صغير إعداد

تحميل خدمة و يجعل وحيد تركيب خلفية تلقائي اختيار، أو استخدام `searchProvider`/`fetchProvider` ثابت مزود id. بيئة متغير `$DSH_WEB_SEARCH_PROVIDER` و `$DSH_WEB_FETCH_PROVIDER` توفير نفسه حقل، لا هو آخر بند أولوية درجة سلسلة.

```yaml
- name: '@deepseek-ai/dsh-web'
- name: '@deepseek-ai/dsh-web-search-exa'
- name: '@deepseek-ai/dsh-web-fetch-http'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `searchProvider` | (لم ضبط) | ثابت بحث مزود id؛ لم ضبط وقت فقط في تماما جيد واحد متاح وقت تلقائي اختيار |
| `fetchProvider` | (لم ضبط) | ثابت إمساك أخذ مزود id؛ لم ضبط وقت فقط في تماما جيد واحد متاح وقت تلقائي اختيار |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-web) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### بحث و إمساك أخذ

`search()` تنفيذ مرة استعلام، إرجاع اختياري مزود جواب سجل و يمكن مرجع مصدر قائمة؛ خدمة قوي صنع تنفيذ `request.maxResults`: قطع قطع `sources[]` و ضبط `truncated`.`fetch()` نيل أخذ واحد URL، إرجاع ذلك نهائي URL، حالة رمز، حل رمز بعد متن و قطع قطع علامة سجل؛ غير 2xx استجابة هو نتيجة، لا هو خطأ.

```text
// Search the web; sources[] is capped to maxResults:
const result = await ctx.web.search({ query: 'deepseek harness', maxResults: 8 })

// Fetch one URL; a non-2xx response is a result, not an error:
const page = await ctx.web.fetch({ url: 'https://example.com' })
```

اثنان عدد استدعاء كل قبول اختياري `AbortSignal`، لأجل يأخذ إلغاء تحويل إرسال إعطاء مزود. مواصفة تحويل طلب و نتيجة شكل حالة هو استدعاء جهة اعتماد بـ بناء اتفاق؛[web فرعي نظام](../../../docs/subsystems/web.zh.md) مشاركة اعتبار في مفردات فصل عقدة مقابل ذلك لديه نفاد كل صيغة وصف.

### مزود اختيار

كل مرة استدعاء كل في تنفيذ وقت تحليل مزود، تسجيل أو تحميل ترتيب من لا أثر نتيجة. قد إعداد مزود id في قد تسجيل كما متاح وقت أولوية؛ لا يوجد إعداد id وقت، خدمة تشغيل وحيد متاح مزود، أو في حال حال لا واضح وقت واضح فشل:

| حال حال | نتيجة |
|---|---|
| قد إعداد id قد تسجيل كما متاح | تشغيل هذا مزود |
| قد إعداد id لم تسجيل | `WEB_PROVIDER_CONFIGURED_MISSING` |
| قد إعداد id قد تسجيل لكن غير ممكن استخدام | `WEB_PROVIDER_CONFIGURED_UNAVAILABLE` |
| بلا id، تماما جيد واحد قد تسجيل متاح مزود | تشغيل هو |
| بلا id، لا يوجد متاح مزود | `WEB_PROVIDER_UNAVAILABLE` |
| بلا id، كثير عدد متاح مزود | `WEB_PROVIDER_AMBIGUOUS` |

مزود متاح صفة هو واحد بند نزيه قيمة نطاق جزء فحص——مثال مثل ذلك API مفتاح هل وجود——و كما من لا إرسال بدء شبكة شبكة استدعاء، لذلك اختيار إبقاء سريع سرعة كما تحديد.

### فشل و استعادة

فشل رمي خروج `WebError`، يحمل مستقر، يمكن حسب آلة جهاز توجيه code؛ رسالة تكملة ملء دقيق عقدة، مثال مثل ناقص مزود id أو اختلاف معنى مرشح تجميع دمج. استدعاء جهة حسب code توجيه و قرار مثل أي تخفيض. يلزم تغيير مرة استدعاء استخدام خلفية، طلب إعادة إعداد ثابت id، تركيب أو إزالة مزود، أو إصلاح صحيح مزود إعداد جعل ذلك متاح صفة فحص عبر.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خدمة خلف بعد تصميم قرار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة بناء قيام في واحد لحظة معنى قسم مغادرة لـ فوق:

- **واحد seam، اثنان عدد مستقل عملية.** بحث و إمساك أخذ لا يوجد مشترك طلب schema أو عمل خدمة منطق، لكن هو جمع مشترك استخدام واحد خدمة، جعل مزود اختيار، إلغاء، خطأ و منتج إعداد فقط لديه واحد ملكية جهة. و سطر `Search`/`Fetch` طريقة مقابل هو متعمد لـ لـ.
- **اختيار أبدا اعتماد ترتيب.** قدرة يلزم ما ثابت مزود id، يلزم ما في تماما جيد تسجيل واحد متاح مزود وقت تلقائي اختيار؛`search()`/`fetch()` في تنفيذ وقت تحليل مزود.
- **خدمة يملك نتيجة حد أعلى.** `maxResults` من seam في مزود إرجاع بعد قوي صنع تنفيذ، لذلك تجاوز كمية إرجاع مزود أبدا ممكن تسرب تسرب تجاوز خروج استدعاء جهة اشتراط مصدر.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`WebRuntime` خدمة، اثنان عدد مزود سجل التسجيل و تنفيذ وقت اختيار |
| [`src/types.ts`](src/types.ts) | مفردات: طلب/نتيجة نوع، غلاف إغلاق `WebFetchBody` ربط دمج و `WebError` تصنيف جسم نظام |
| — | لا إصدار وقت التشغيل ثابت صيغة إعداد طقم بند؛ مزود خريطة هو خاص بيانات، خدمة سوف في كل مرة استدعاء وقت تنفيذ مزود اختيار و قوي صنع تنفيذ نتيجة حد أعلى؛ هذا seam لا إصدار مستقل سجل التسجيل، أيضا لا إصدار طلب/نتيجة مراقبة قياس تدفق. |

### بيانات نموذج

طلب و نتيجة نوع تعريف استدعاء جهة اعتماد بـ بناء مواصفة تحويل مفردات——`Search` طلب/نتيجة مقابل و `Fetch` طلب/نتيجة مقابل كل واحد مجموعة——نفاد كل صيغة حقل و JSDoc رؤية [`src/types.ts`](src/types.ts) و [web فرعي نظام](../../../docs/subsystems/web.zh.md) مشاركة اعتبار. اثنان عدد لحظة معنى اختيار تشكيل صنع هو جمع:`WebFetchBody` هو هذا داخل يملك غلاف إغلاق ربط دمج (`html` | `text`) ، لذلك إضافة جديدة نوع سوف كسر تالف تحرير ترجمة، مباشر إلى كل مستهلك كل معالجة هو؛`WebError` وراثة `HarnessError`، يحمل فتح وضع نص `code`، لذلك مستهلك يجب سعة تحمل مزود مخصص لديه أخذ قيمة. مصدر حقل إبقاء اختياري، لأن و غير كل مزود كل إرجاع الكل حقل.

### اختيار مسار

تنفيذ وقت، خدمة أولا حسب إعداد id، مجددا حسب وحيد متاح مزود تحليل مزود، لا يوجد واضح فوز بيت وقت رمي خروج مقابل `WebError`. بحث نتيجة مع بعد مرور مرور `capSources`: يأخذ `sources[]` قطع قطع إلى `maxResults` و علامة `truncated`. تسجيل أساس في effect: مزود مع استدعاء fiber تسجيل،fiber تحرير وقت ملاحظة إلغاء؛ نفس قدرة نوع تحت تكرار id سوف في تسجيل وقت يتم رفض.

- [web فرعي نظام](../../../docs/subsystems/web.zh.md)——نفاد كل صيغة بحث/إمساك أخذ طلب و نتيجة، مزود متاح صفة و رمز خطأ.
- [web حزمة خريطة](../README.zh.md)——ستة حزمة بيت عائلة و كل زاوية لون.
- [dsh-tool-web](../tool-web/README.zh.md)——بناء في هذا خدمة لـ فوق موجه إلى نموذج `web_search` و `web_fetch` أداة.
- [dsh-web-fetch-http](../web-fetch-http/README.zh.md)——قد تسليم مجهول اسم HTTP(S) إمساك أخذ خلفية.
- [توليد إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-web)——كل تلقي دعم حمل إعداد حقل و ذلك مصدر إعلان.
- [web قدرة seam قرار](../../../.agents/notes/implemented/architecture/2026-06-24-web-capability-seam.zh.md)——بحث و إمساك أخذ لـ أي مشترك استخدام واحد بند مزود اختيار خدمة.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أرض، عبر `dsh-tool-web`: هذا أداة يأخذ seam مواصفة تحويل بحث نتيجة و إمساك أخذ متن تصيير إعطاء نموذج، بينما هذا خدمة لا مساهمة أي نص التوجيه أو schema.

#### KV Cache أثر

لن مباشر توجيه يؤدي KV Cache بطلان؛ طلب بادئة تغيير من فوق وصف مستهلك مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خدمة مفرد وحيد استخدام وقت في أي بعض جهة وجه لا كامل. هو جمع هو حالي حزمة قيد.

- **لا يوجد مراقبة قياس واجهة**: لا يوجد مزود تغيير حدث أو قدرة حالة استعلام؛ متاح صفة فقط قدرة عبر تنفيذ بحث أو إمساك أخذ و حسب رمي خروج code توجيه قدوم مراقبة قياس، بلا مزود فشل هو عام `WEB_PROVIDER_UNAVAILABLE`، لا قطعة رفع تدريجي مزود سبب (رؤية [Agent Note](../../../.agents/notes/archived/simplification/2026-07-04-drop-unconsumed-web-observation-surface.md)).
- **بحث طلب فقط يحمل `query` و `maxResults`**: مزود غير متصل تحكم بند (جديد قريب مسار درجة، مجال اسم مرور ترشيح شرط، منطقة مجال تلميح، بحث عميق درجة) مؤقت مؤقت حتى خلفية كل قدرة صدق فعلي دعم حمل وقت (رؤية [seam Agent Note](../../../.agents/notes/implemented/architecture/2026-06-24-web-capability-seam.zh.md)).
- **`WebFetchBody` لا يوجد `pdf` فرع**: يمكن رفع أخذ نص PDF دعم حمل يخص واضح تأجيل عمل؛ غلاف إغلاق ربط دمج سوف جعل إضافة جديدة هذا فرع يصبح عبر web حزمة، من تحرير ترجمة قوي صنع تنفيذ تغيير.
- **مزود دعم حمل صفحة رفع أخذ لا يخص `fetch()` نطاق**:Firecrawl/Tavily ريح إطار `web_extract` قدرة تأجيل، بينما لن توسيع إمساك أخذ عملية.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص و متبادل صلة Agent Note لـ دقيق.

#### لم قدوم: مراقبة قياس مزود حالة

لا يوجد مزود تغيير حدث أو قدرة حالة استعلام؛ مستهلك فقط قدرة عبر تنفيذ استدعاء و حسب رمي خروج code توجيه قدوم مراقبة قياس متاح صفة. إذا مستهلك حاجة تدريجي مزود سبب، استعادة واحد صغير مراقبة قياس واجهة هو يمكن سطر، لكن قد عودة ملف بسيط تحويل قلم تسجيل سجل لـ أي وضع ترك هذا قبل ذلك عدد واجهة.
