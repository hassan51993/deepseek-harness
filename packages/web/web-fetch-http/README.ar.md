# @deepseek-ai/dsh-web-fetch-http

[English](README.md) | العربية

## عام وصف

لديه `dsh-web-fetch-http`،harness يمكن عبر web خدمة (`ctx.web`) إمساك أخذ عام مشترك HTTP(S) صفحة، و في لا إرسال اعتماد حال حال تحت نيل نيل حالة رمز و محدود، حل رمز بعد محتوى. عند تركيب حاجة URL تحقق، عام عنوان تحليل، اتصال ثابت، فقط نفس مصدر إعادة تحديد نحو، بايت و محرف حد أعلى و صريح منتج `User-Agent` وقت اختيار هو. هو يأخذ غير 2xx استجابة بصفة نتيجة بينما غير خطأ إرجاع، و رفض غير عام هدف، اثنان دخول صنع بيانات و لا تلقي دعم حمل محتوى نوع. موجه إلى نموذج `web_fetch` أداة يقع في `dsh-tool-web`، من هو تصيير هذا مزود متن.

## استخدام هذه الحزمة

في قد تحميل web خدمة تركيب في تركيب هذا مزود؛ هو بـ `http` إمساك أخذ مزود هوية تسجيل، لذلك عند هو هو وحيد متاح إمساك أخذ خلفية وقت،`ctx.web.fetch()` سوف تلقائي تحليل إلى هو——أيضا يمكن استخدام `fetchProvider: http` ثابت.

### أي وقت اختيار

عند نشر يجب بـ محدود إخراج و أمان نقل إمساك أخذ عام مشترك صفحة وقت اختيار هذا خلفية: لا إرسال اعتماد، كل قد تحليل عنوان يجب هو عام مشترك عنوان، كل مرة اتصال كل ثابت إلى قد تحقق عنوان تجميع دمج، إعادة تحديد نحو لا يمكن هروب خروج مصدر محطة، كل استجابة كل لديه حد أعلى.

### الأكثر صغير إعداد

تحميل web خدمة و هذا مزود؛ يمكن إعداد حد أعلى كل لديه أمان قيمة افتراضية، و في إضافة بنية صنع وقت تحقق، لذلك بلا فاعلية قيمة سوف مباشر تقرير خطأ، بينما لا هو بنية صنع خروج حد أعلى مهجور خطأ مزود.URL أمان حد أعلى ثابت لـ 2,048 عدد محرف.

```yaml
- name: '@deepseek-ai/dsh-web'
- name: '@deepseek-ai/dsh-web-fetch-http'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxResponseBytes` | `5,000,000` | استجابة رئيسي جسم الأكثر كبير بايت عدد |
| `maxBodyChars` | `100,000` | حل رمز رئيسي جسم الأكثر كبير محرف عدد |
| `timeoutMs` | `30,000` | إمساك أخذ مهلة——مورد التقاط قاع، لا هو موجه إلى نموذج أداة ميزانية |
| `maxRedirects` | `5` | نفس مصدر إعادة تحديد نحو الأكثر كبير قفز عدد (`0` يمثل لا تتبع مع) |
| `userAgent` | `deepseek-harness/…` | كل مرة طلب إرسال `User-Agent` علامة رأس |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-web-fetch-http) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### إمساك أخذ إرجاع ماذا

نجاح استدعاء إنتاج `WebFetchResult`: سماح إعادة تحديد نحو بعد نهائي URL،HTTP حالة رمز، تصنيف لـ `html` أو `text` حل رمز متن، و `truncated` علامة سجل. غير 2xx استجابة هو نتيجة بينما غير خطأ——حالة رمز هو يتم إمساك أخذ مورد حالة واحد جزء؛`WebError` فقط لأجل لا يمكن أمان نيل أخذ أو يمثل مورد فشل.

```text
const page = await ctx.web.fetch({ url: 'https://example.com' })
// page.body.kind === 'html' | 'text'; page.statusCode === 200 | 404 | ...
```

### نقل سلوك

مزود إبقاء طلب مجهول اسم كما محدود: فقط قبول لا يحتوي داخل تضمين اعتماد كما لا تجاوز مرور 2,048 عدد محرف `http:` و `https:` URL. هو فقط تحليل مرة رئيسي آلة اسم؛ فقط يلزم نتيجة في لديه أي IPv4 أو IPv6 عنوان لا هو عام مشترك مفرد بث عنوان، حينئذ رفض كامل نتيجة، و يأخذ اتصال ثابت إلى قد تحقق عنوان تجميع دمج.IPv6 فحص سوف اكتشاف نشط حركة DNS64 بادئة، و رفض إشارة نحو غير عام IPv4 تحويل عنوان. كل مرة نفس مصدر إعادة تحديد نحو كل سوف تكرار تحليل و ثابت؛ عبر مصدر إعادة تحديد نحو سوف فشل و اشتراط إعادة استدعاء. مزود أيضا قوي صنع تنفيذ بايت، محرف، قفز عدد و وقت حد أعلى، رفض لا دعم حمل محتوى نوع، تزامن إرسال صريح منتج `User-Agent`.

### فشل و استعادة

فشل سوف رمي خروج `WebError`، منها يتضمن يمكن توفير برنامج توجيه رمز خطأ:`WEB_INVALID_URL`،`WEB_BLOCKED_URL`،`WEB_FETCH_TOO_LARGE`،`WEB_FETCH_TIMEOUT`،`WEB_REDIRECT_BLOCKED`،`WEB_UNSUPPORTED_CONTENT_TYPE`،`WEB_ABORTED` أو `WEB_PROVIDER_ERROR`. مباشر استدعاء جهة يمكن حسب رمز خطأ توجيه؛ موجه إلى نموذج `web_fetch` أداة سوف في ذاتي ذات خطأ حزمة تركيب طبقة داخل يأخذ فشل نص عرض إعطاء نموذج.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مزود خلف بعد تصميم قرار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة أساس في واحد بند مسؤولية قسم مغادرة و واحد طقم قسم طبقة مهلة آلية:

- **أمان نيل أخذ و عرض قسم مغادرة.** هذا مزود يملك URL تحقق، عام عنوان قوي صنع قاعدة، اتصال ثابت،HTTP نقل، إعادة تحديد نحو سياسة، حد أعلى،charset حل رمز و اثنان دخول صنع رفض؛`dsh-tool-web` يملك HTML→markdown و مقتطع صيغة تحويل. غير 2xx استجابة هو بيانات، لا هو فشل.
- **اثنان طبقة مهلة.** مزود `timeoutMs` هو مباشر `ctx.web.fetch()` استدعاء جهة مورد التقاط قاع؛ موجه إلى نموذج استدعاء الأداة ميزانية يخص `dsh-tool-call-timeout-policy`، من هو إطلاق `exec.signal`. خارج طبقة قطع توقف مدة حد أولا إلى وقت، مزود تقرير إبلاغ `WEB_ABORTED`، سياسة مجددا بـ `TOOL_TIMEOUT` استبدال؛ لذلك `WEB_FETCH_TIMEOUT` معرف هو مزود ميزانية استهلاك كل مباشر خدمة استدعاء جهة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: إعداد schema، حد أعلى تحقق، مزود تسجيل |
| [`src/provider.ts`](src/provider.ts) | `HttpFetchProvider`: ثابت اتصال، إعادة تحديد نحو تتبع مع، محدود قراءة،charset حل رمز |
| [`src/network.ts`](src/network.ts) | عام عنوان تحليل،DNS64 اكتشاف و اتصال ثابت |

| — | لا إصدار وقت التشغيل ثابت كمية إعداد طقم مدخل؛ حذف الذي تابع seam قوي صنع تنفيذ اتفاق خارج، هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة. |

### قراءة مسار

إمساك أخذ أولا تحقق URL، فقط تحليل مرة رئيسي آلة اسم، نتيجة في فقط يلزم لديه غير عام عنوان حينئذ رفض، و يأخذ اتصال ثابت إلى قد قبول عنوان. كل مرة نفس مصدر إعادة تحديد نحو كل تكرار هذا فحص؛ عبر مصدر إعادة تحديد نحو أو غير عام هدف في استقبال استجابة بايت قبل فشل. نهائي استجابة حسب `Content-Type` تصنيف، اعتماد إعلان charset حل رمز، و في بايت حد أعلى داخل قراءة؛ حل رمز بعد نص مجددا مقتطع إلى محرف حد أعلى.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أرض، عبر `dsh-tool-web`: هذا أداة يأخذ هذا مزود مرور `maxBodyChars` حد حل رمز نص أو من HTML تحويل نيل إلى markdown وضع في إمساك أخذ نتيجة حزمة تركيب طبقة داخل، بينما إعادة تحديد نحو، علامة رأس و نقل حد أعلى إبقاء إخفاء.

#### KV Cache أثر

لن مباشر توجيه يؤدي KV Cache بطلان؛ طلب بادئة تغيير من فوق وصف مستهلك مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح مزود أي وقت لا أمان أو لا دمج ملائم. هو جمع هو حالي حزمة قيد.

- **فقط حل رمز نص محتوى**——يشمل html/xhtml و `text/*` إضافة JSON/XML بيت عائلة؛ نقص قليل `Content-Type` أو أي اثنان دخول صنع نوع كل سوف رمي خروج `WEB_UNSUPPORTED_CONTENT_TYPE`، يمكن رفع أخذ نص PDF حل رمز يخص واضح تأجيل عمل.
- **charset فقط قدوم ذاتي `Content-Type` علامة رأس**(افتراضي UTF-8)——HTML `<meta charset>` إعلان سوف يتم تجاهل اختصار؛ إعلان لكن لا يمكن تعرف آخر charset وسم سوف رمي خروج استثناء، بينما غير رجوع.
