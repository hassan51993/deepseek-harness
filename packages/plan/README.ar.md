# plan/:plan تنسيق عمل حالة

[English](README.md) | العربية

## عام وصف

`plan/` مجموعة توفير حساب تخطيط نمط: تنشيط خلال،agent أولا استكشاف و تصميم مجددا تنفيذ، التزام دوران نشر كتابة إشارة أمر، و في تنفيذ قبل إيداع إتمام حساب تخطيط توفير أنت دفعة دقيق. أنت يمكن استخدام `/plan` أمر دخول و مغادرة فتح حساب تخطيط نمط، دفعة دقيق حساب تخطيط، أو يجعل agent عودة ذهاب متابعة قاعدة تخطيط. حساب تخطيط نمط هو جذب توجيه بينما غير حد: كل أداة ما زال متاح، صندوق رملي نمط و مراجعة دفعة تلميح انتظار حد يحتاج آخر سطر إعداد. هذا مجموعة فقط يتضمن واحد حزمة `plan-mode`.

<a id="packages"></a>
## حزمة

واحد حزمة توفير كامل حساب تخطيط نمط وظيفة؛ كامل اتفاق بـ فرعي نظام مشاركة اعتبار لـ دقيق.

| حزمة | مسؤولية | ctx مفتاح |
|---|---|---|
| [`plan-mode/`](plan-mode/README.ar.md) | توفير حساب تخطيط نمط:`/plan` دخول و مغادرة فتح، نشر كتابة إشارة أمر في قاعدة تخطيط خلال جذب توجيه agent،`exit_plan_mode` يأخذ إتمام حساب تخطيط عرض تسليم أنت مراجعة | `ctx.planMode` |
