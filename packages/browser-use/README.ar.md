## عام وصف

متصفح عملية مزود يجعل نموذج فحص و عملية شبكة صفحة. هذا مجموعة يملك وحيد احتلال مزود تسجيل. فعلي تحقق صفة مزود توفير متصفح أداة، و إدارة كل Session متصفح مورد.
