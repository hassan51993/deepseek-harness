# @deepseek-ai/dsh-ptc-runtime

[English](README.md) | العربية

## عام وصف

استخدام `dsh-ptc-runtime`، يمكن عبر قد إعداد خلفية، إبرة مقابل مضيف توفير مختلف خطوة دالة تشغيل واحد مقطع نموذج تحرير كتابة برنامج. طلب إرجاع بلا ضرر JSON قيمة، عبر طريق داخل لديه ترتيب سجل أو بنية تحويل خطأ؛ برنامج فشل في نتيجة في resolve، بينما Promise reject يمثل استدعاء جهة خطأ استخدام. كل مرة تشغيل كل و أولا قبل تشغيل عزل، كما وقت التشغيل لا حل أداة أو جلسة. تنفيذ خلفية يحتاج آخر سطر اختيار؛ ذلك لغة و عزل وصف رمز علامة واضح الذي يحتاج مصدر لغة و تنفيذ أساس قاع، لكن هذه وصف رمز ذاته لا تحمل وعد أمان حد.

## استخدام هذه الحزمة

عند أنت يلزم تركيب واحد تنفيذ نموذج برنامج نشر، مباشر إزالة استهلاك `ctx.ptcRuntime`، أو بناء تشغيل برنامج خلفية وقت، اختيار هذه الحزمة.`dsh-tools` في PTC mode استخدام هو تنفيذ أداة برنامج،`dsh-workflow-ptc` استخدام هو تحرير ترتيب سير العمل. كل مستهلك مسؤول إرجاع إعطاء نموذج محتوى.

### تشغيل واحد برنامج

نحو وقت التشغيل توفير برنامج و ربط نطاق الأسماء، لكن بعد اعتماد مرة استدعاء `resolve(request)` و `run(spec)`. تحليل أصل حسب مزود قدرة تحقق اختياري cwd،timeout و صندوق رملي سياسة، و ملء دخول نشر قيمة افتراضية. برنامج بصفة مختلف خطوة دالة جسم تشغيل، دعم حمل قمة طبقة `await` و `return`؛ بلا ضرر JSON إتمام قيمة يصبح `result.value`، التقاط نص يصبح `result.logs`، برنامج فشل يصبح `result.error`. كل إخراج عبر طريق إبقاء ذاته ترتيب، عبر عبر طريق تسليم خطأ من خلفية قرار.

```text
const spec = ctx.ptcRuntime.resolve({
  program: 'return await tools.add({ a: 1, b: 2 })',
  bindings: [{ global: 'tools', functions: { add: async (args) => args.a + args.b } }],
})
const result = await ctx.ptcRuntime.run(spec)
// result.value === 3
```

### اختيار خلفية

خلفية بـ `language` و `isolation` توفير تشخيص وصف رمز؛ اثنان من كل لا منح إعطاء إذن أو إثبات قيد.[`dsh-ptc-runtime-node`](../ptc-runtime-node/README.ar.md) في كل جديد تلقي إدارة Node عملية في حسب قد تحليل صندوق رملي سياسة تنفيذ يمكن مسح حذف TypeScript. خاص [`dsh-experimental-ptc-runtime-python`](../../experimental/ptc-runtime-python/README.ar.md) مزود في كل جديد CPython عملية فرعية في تنفيذ Python، لا توفير ملف قيد.`sandboxMode` إعلان مزود نشر ملف سياسة نمط؛ لا دعم حمل هذا قدرة وقت فإن نقص حذف.

### يمكن نقل غرس أرض تسمية ربط

binding-global و error-class اسم هو لغة يمكن نقل غرس: يجب مطابقة `[A-Za-z_][A-Za-z0-9_]*`، تجنب فتح كل يمكن نقل غرس هدف لغة إبقاء حرف، و تجنب فتح خلفية يملك مجرى موضع، لذلك نفس نسخة نطاق الأسماء قائمة مقابل كل خلفية كل صالح.`$tools`،`lambda` أو `console` لـ صنف اسم سوف في تشغيل بدء قبل فشل؛ تأكيد قطع ترتيب حذف تجميع هو seam اتفاق واحد جزء.

### ممكن خروج ماذا مشكلة

فشل بـ `result.error` إرجاع، حمل صحيح تسليم `kind`:`exception`،`timeout`،`abort`،`worker-exit`،`invalid-output`،`output-limit`،`protocol` أو `sandbox-unavailable`. مزود في نجاح أو فشل خارج، مفرد وحيد إرجاع ملائم استخدام `result.sandbox` واقع. بلا فاعلية أو لا دعم حمل تنفيذ خيار في `resolve` خلال فشل؛`run` رفض استدعاء جهة خطأ استخدام، مثال مثل لم تحليل إدخال، بلا فاعلية ربط اسم أو مورد تحرير بعد استدعاء.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير seam خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة هو PTC تنفيذ قدرة seam Service Definition زاوية لون ([قدرة seam](../../../.agents/notes/implemented/architecture/2026-06-13-capability-seams.ar.md)): واحد تسجيل لـ `ctx.ptcRuntime` سحب كائن `PtcRuntime extends Service`، إضافة فوق مزود و مستهلك مشترك مفردات. مزود وراثة `PtcRuntime`، تنفيذ `resolve` و `run` و تسجيل خدمة.`dsh-tools` في PTC mode مسؤول أداة ربط،`dsh-workflow-ptc` مسؤول سير العمل خطاف و فرعي agent. حسب اتفاق، وقت التشغيل لا حل أداة و جلسة: هو استقبال برنامج، أداة اسم مختلف خطوة ربط و قد تحليل تنفيذ خيار، لكن بعد إرجاع التقاط إخراج، تنفيذ نتيجة و ملائم استخدام صندوق رملي واقع.

### خدمة API

فقط قراءة `timeout` وصف رمز عام عدد قيمة نوع `{ defaultMs, maxMs }`، توفير مستهلك عرض؛ وصف رمز نقص حذف يمثل لا دعم حمل عدد قيمة تغطية. حذف `timeoutMs` استخدام مزود قيمة افتراضية؛ عدد قيمة طلب مرور مرور تحقق و غلاف قمة مرور مرور وقت ميزانية؛ صريح `null` طلب لا ضبط مرور مرور وقت قطع توقف. مزود رفض لا دعم حمل اختيار.Node سير العمل مهايئ طلب `null`، بينما موجه إلى نموذج `run_code` أداة فقط قبول صحيح عدد تغطية قيمة.

`executionInstructions` توفير من وقت التشغيل يملك استخدام شرح؛ لا حاجة شرح وقت إرجاع فارغ نص. مستهلك يمكن سوف ذلك قبول دخول برنامج عرض، بلا حاجة أصل حسب لغة أو عزل وصف رمز تعرف آخر مزود؛PTC سوف هو قبول دخول قد سجل `run_code` schema.

`resolve(request)` مسؤول دعم حمل خيار تحقق و نشر قيمة افتراضية.`run(spec)` تنفيذ كامل إدخال، و في تنظيف بعد إرجاع برنامج نتيجة. لغة و تنفيذ أساس قاع وصف رمز إشارة توجيه عرض؛`sandboxMode` يمثل مستهلك قدرة لا نقل دخول قد تحليل ملف سياسة. وصف رمز و برنامج نجاح نتيجة كل لا يستطيع بديل بديل خلفية تقرير إبلاغ قوي صنع قدرة واقع.

نفاد كل صيغة دلالة رؤية[PTC وقت التشغيل فرعي نظام مشاركة اعتبار](../../../docs/subsystems/ptc-runtime.ar.md) ؛ تأكيد قطع توقيع رؤية [`src/index.ts`](src/index.ts).

### مفردات

`PtcRunRequest` يحمل برنامج،Host ربط، إلغاء و اختياري تنفيذ اختيار.`PtcRunSpec` اشتراط قد تحليل cwd و واضح عدد قيمة أو null قطع توقف اختيار.`PtcBindingNamespace` إعلان برنامج عام كائن و اختياري نوع تحويل رفض منشئ.`PtcRunResult` سوف سجل/قيمة، فشل و `PtcRunSandbox` واقع قسم فتح؛ تأكيد قطع حقل و مزود معنى خدمة رؤية [`src/types.ts`](src/types.ts).

### يمكن نقل غرس معرف رمز

binding-global و error-class اسم هو لغة يمكن نقل غرس: يجب مطابقة معرف رمز فرعي تجميع `[A-Za-z_][A-Za-z0-9_]*`(لا يحتوي JS مخصص لديه `$`) و عبر seam تصدير ترتيب حذف تجميع، لذلك نفس نسخة `bindings` قائمة مقابل كل خلفية كل صالح. هذه الحزمة تصدير كل خلفية كل تنفيذ اتفاق——`PORTABLE_RESERVED_WORDS`(ECMAScript ∪ Python إبقاء حرف) ،`RESERVED_BINDING_GLOBALS`(مثل `console`،`__dsh_main__` انتظار خلفية يملك global) ،`RESERVED_ERROR_MEMBERS` و `DUNDER_MEMBER`(error-member ترتيب حذف)——لذلك `$tools`،`lambda` أو `__dsh_main__` لـ صنف اسم سوف يجعل `run()` في أي خلفية فوق بصفة seam خطأ استخدام بينما reject. تأكيد قطع تجميع دمج رؤية `src/index.ts`.

## تجربة النموذج

عبر `dsh-tools` في PTC mode و سير العمل مهايئ بين وصل توفير؛ هو جمع عبر كل منها أداة نتيجة عرض برنامج نتيجة.

#### KV Cache أثر

لن مباشر بطلان؛ من فوق وصف مستهلك مسؤول طلب بادئة تغيير.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح seam لا يستطيع فعل ماذا؛ هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **`run()` هو مرة صفة**——`logs` فقط لديه في `PtcRunResult` resolve بعد عندئذ قدرة نيل نيل؛seam لا توفير جارٍ تشغيل برنامج الذي إنتاج إخراج تدفق صيغة سجل أو دخول درجة واجهة.
- **تشغيل بين لا إبقاء حالة**——كل مرة طلب كل في كل جديد بيئة في تشغيل؛ حمل دائم REPL ريح إطار داخل نواة في بعض عدد خلفية حمل قدوم ذاتي ذات سجل خطة قبل إبقاء تأجيل.
- **مزود قيد قدرة مختلف**——قد إصدار Node مزود قوي صنع تنفيذ قد تحليل ملف سياسة، خاص فعلي تحقق صفة Python مزود رفض صريح سياسة. لا توفير حاوية مزود.
- **مزود بين لا يوجد موحد واحد ربط بايت حد أعلى**——كل مزود مسؤول ذاتي ذات نقل حد؛ ربط ما زال ممكن في نتيجة وصول هذه حد قبل قسم إعداد داخل تخزين.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: بعد لم قرار جهة نحو و فتح وضع مشكلة. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

#### لم قدوم: حمل دائم داخل نواة خلفية

عبر `run_code` استدعاء إبقاء حالة REPL ريح إطار داخل نواة ما زال لم قرار؛ هو حاجة ذاتي ذات سجل خطة، لأن «تشغيل بين لا إبقاء حالة» اتفاق صحيح هو يجعل كل مرة طلب فقط سند جلسة سجل يكفي إعادة بناء سبب.

#### لم قدوم: حاوية خلفية

حاوية درجة خلفية سوف لـ شفرة و shell تنفيذ كل توفير صلب صفة كثير إيجار مستخدم حد؛ حذف معروف `isolation` قيمة خارج، مؤقت بلا أي قرار.

</details>
