# @deepseek-ai/dsh-ptc-runtime-node

[English](README.md) | العربية

## عام وصف

في و Bash نفسه منصة صندوق رملي سياسة تحت تنفيذ نموذج تحرير كتابة TypeScript، و عبر مختلف خطوة ربط استدعاء Host توفير دالة. كل مرة استدعاء بدء واحد كل جديد Node عملية، إرجاع التقاط سجل، دقيق JSON قيمة أو بنية تحويل فشل. مباشر Node API في الذي اختيار حد داخل ما زال يمكن استخدام. مرور مرور وقت قطع توقف، إخراج حد أعلى و V8 كومة حد قيد تنفيذ؛ إلغاء و إتمام كل سوف إنهاء تلقي إدارة عملية نطاق. طلب تلقي حد نمط لكن صندوق رملي خلفية غير ممكن استخدام وقت، تنفيذ فشل.

## استخدام هذه الحزمة

في توفير `fs`،`subprocess`،`sandbox` و `sandboxPolicy` تركيب في تركيب هذا مزود.`dsh-tools` PTC نمط نقل دخول استدعاء Session دليل و معتاد ضبط سياسة؛ مباشر وقت التشغيل مستهلك في تنفيذ قبل تحليل هذه خيار.

### إعداد

في الذي يحتاج خدمة متاح بعد، إعداد مزود بند:

```yaml
- name: '@deepseek-ai/dsh-ptc-runtime-node'
  config:
    timeoutMs: 120000
    maxTimeoutMs: 600000
    maxOutputBytes: 67108864
    maxOldGenerationSizeMb: 512
    maxMessageBytes: 134217728
    maxPendingCalls: 128
    graceMs: 3000
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `timeoutMs` | `120,000` | افتراضي مرور مرور وقت قطع توقف، يشمل تضمين طقم أداة و مراجعة دفعة انتظار |
| `maxTimeoutMs` | `600,000` | محلل تطبيق مرور مرور وقت قطع توقف حد أعلى |
| `maxOutputBytes` | `67,108,864` | تسلسل تحويل سجل و إتمام قيمة أو تشخيص دمج حساب ميزانية |
| `maxOldGenerationSizeMb` | `512` | V8 قديم توليد بديل كومة حد أعلى، مفرد موضع MiB |
| `maxMessageBytes` | `134,217,728` | تحكم لقطة، لم إتمام معامل بايت و ترتيب طابور تحكم كتابة حد أعلى |
| `maxPendingCalls` | `128` | معا إجراء Host ربط استدعاء عدد كمية حد أعلى |
| `graceMs` | `3,000` | تلقي إدارة إنهاء و إخراج ترتيب فارغ عرض حد وقت |
| `nodeExecutable` | حالي Node يمكن تنفيذ ملف | في عملية فرعية تنفيذ عالم حد في تحليل يمكن تنفيذ ملف |
| `bootstrapPath` | حزمة داخل bootstrap | هذا تنفيذ عالم حد في مسبق أولا تثبيت بناء بعد bootstrap اختياري قطعا مقابل مسار |

[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-ptc-runtime-node) تعريف يمكن قبول إعداد حقل.`resolve(request)` تكملة كل cwd، عدد قيمة أو null قطع توقف اختيار و تنفيذ سياسة؛`run(spec)` قبول هذه قد تحليل إدخال، لا تكملة نقص حذف قيمة.

### تنفيذ و نتيجة

برنامج هو مختلف خطوة دالة جسم: دعم حمل قمة طبقة `await` و `return`، كما فقط قبول يمكن مسح حذف TypeScript. نجاح استدعاء بـ `result.value` إرجاع بلا ضرر JSON قيمة، بـ `result.logs` إرجاع التقاط نص.`result.sandbox` مستقل في برنامج نتيجة تقرير إبلاغ الذي اختيار نمط، مراقبة إلى رفض، و خلفية كامل أو جزء قوي صنع قدرة.

مباشر نظام الملفات، شبكة و عملية فرعية عملية ما زال هو Node عملية، تلقي الذي اختيار OS صندوق رملي قيد. تضمين طقم Host ربط عبر تحكم عبر طريق استدعاء؛PTC استدعاء الأداة إبقاء سجل التسجيل مرئي صفة، ترتيب، سجل و مراجعة دفعة قاعدة. تشغيل برنامج لن تغيير Session معتاد ضبط سياسة، أيضا لن في رفض بعد تلقائي إعادة وضع برنامج.

### قطع توقف وقت و إلغاء

PTC مستهلك حسب [dsh-tools](../../core/tools/README.ar.md#ptc-mode) شرح عام تدريجي مرة مهلة و مرور مراجعة دفعة صندوق رملي اختيار. وقت التشغيل فقط قراءة `timeout` وصف رمز نحو هذا مستهلك تقرير إبلاغ صالح قيمة افتراضية و حد أعلى. ذلك `executionInstructions` في موجه إلى نموذج schema في شرح كل جديد Node حالة، مباشر Node API، فارغ برنامج بيئة و ملف سياسة.

حذف `timeoutMs` استخدام إعداد مرور مرور وقت قيمة افتراضية؛ عدد قيمة طلب مرور مرور تحقق و غلاف قمة. خدمة استدعاء جهة يمكن صريح نقل دخول `timeoutMs: null` قدوم حذف مرور مرور وقت تحديد وقت جهاز، سير العمل مهايئ أي مثل هذا؛`run_code` ما زال فقط قبول صحيح عدد تغطية قيمة. تفعيل قطع توقف تغطية وقت التشغيل دقيق تجهيز و تنفيذ، يشمل انتظار تضمين طقم أداة أو مراجعة دفعة وقت. هو لا هو CPU حساب كمية جهاز. مهلة أو إلغاء عبر Host تلقي إدارة عملية كل من إيقاف تزامن حلقة؛ نجاح إتمام أيضا سوف تنظيف هذا تلقي إدارة نطاق. اختيار نتيجة بعد، تنظيف قبل إيقاف حساب وقت جهاز، لذلك استدعاء ممكن يلزم في تنفيذ قطع توقف بعد انتظار تنظيف تسوية عندئذ إرجاع.

### فشل

برنامج تحليل خطأ و رمي خروج استثناء لـ `exception`؛ قطع توقف إلى مدة لـ `timeout`؛ إلغاء لـ `abort`؛ شاذ شكل أو تجاوز كمية تحكم عبر معلومة لـ `protocol`؛ قيد غير ممكن استخدام لـ `sandbox-unavailable`؛ عملية رفع قبل خروج أو تلقي إدارة تنظيف فشل لـ `worker-exit`. عملية مزود إبقاء و تنفيذ أساس قاع غير متصل فشل اسم `worker-exit`. لديه ضرر إتمام قيمة لـ `invalid-output`، خارج طبقة نتيجة تجاوز حد لـ `output-limit`، و إبقاء قدرة سعة قبول سجل بادئة. بلا فاعلية أو لا دعم حمل خيار، و مورد تحرير بعد استدعاء، بـ استدعاء جهة خطأ استخدام رفض.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ داخلي——انقر للتوسيع</summary>

Host مسؤول سياسة، قطع توقف وقت، ربط فحص بحث و عملية تنظيف. عملية فرعية مسؤول برنامج طلب قيمة و ربط بديل إدارة؛ أي جعل استخدام مسبق مدة تحكم وصف رمز، نموذج تحرير كتابة شفرة ما زال هو غير ممكن معلومة مقابل طرف.

### بدء و تحكم

Host مسح حذف يمكن مسح حذف نوع، في إعداد تنفيذ عالم حد في تحليل يمكن تنفيذ ملف و bootstrap، عبر `ctx.sandbox` انتظار argv حد دقيق تجهيز إتمام، مجددا عبر `ctx.subprocess` بدء. حد دقيق تجهيز إتمام بعد سوف مجددا مرة فحص إلغاء حالة، لذلك مزود في إلغاء بعد إرجاع أيضا لا يمكن بدء برنامج. وصل إدارة وراثة تحكم عبر طريق بعد، عملية فرعية في OS بيئة في فقط إبقاء يمكن تنفيذ ملف بحث مسار،Windows نظام مسار و مؤقت مسار، و سوف برنامج مرئي `process.env` استبدال لـ فارغ حرف قاموس.Windows ACL ابتدائي تحويل استقبال أب عملية كل منها `TEMP` و `TMP` قيمة بـ استخدام مشترك تخويل قفل، لكن بعد في بدء برنامج قبل سوف اثنان من استبدال لـ خاص دليل. هذه أصلي مسار جعل تضمين طقم عملية إنشاء و أصلي مؤقت ملف API ما زال يمكن صحيح معتاد عمل.Host فقط في عملية فرعية بدء وقت إبقاء `ELECTRON_RUN_AS_NODE`، جعل طاولة وجه طرف يمكن تنفيذ ملف تشغيل Node bootstrap؛bootstrap في طلب قيمة نموذج شفرة قبل حذف هذا اختيار متغير. كومة حد أعلى عبر Node argv أو لـ تحزيم يمكن تنفيذ ملف من مزود بنية صنع `NODE_OPTIONS` قيمة نقل تمرير؛ بيئة في تحميل جهاز و ضبط تجربة جهاز علامة سجل سوف يتم إسقاط.

حمل طويل درجة قسم لقطة JSON و stdout/stderr قسم فتح نقل.Host حد لقطة و ترتيب طابور كتابة، في قسم إرسال قبل تحقق استدعاء هوية و قد إعلان ربط اسم، و رفض بلا فاعلية عبر معلومة. عملية فرعية تحديث جديد نهاية حالة لقطة بعد ما زال إبقاء تحكم عبر طريق فتح، مباشر إلى Host إغلاق عبر طريق. إيداع نهاية حالة لقطة بعد، عملية فرعية تجاهل اختصار لاحق ربط عودة تكرار، لم يعد إرسال برنامج تحكم رسالة. إخراج التقاط حساب كمية تسلسل تحويل سجل إضافة إتمام قيمة أو تشخيص؛ ثابت نتيجة معلومة غلاف حقل و صندوق رملي بيانات وصفية لا حساب دخول هذا حساب هذا.

### مصدر شفرة و بناء بعد bootstrap

مصدر شفرة تنفيذ تحميل فقط يحتوي يمكن مسح حذف لغة قاعدة bootstrap اعتماد، لا اعتماد نفس درجة حزمة بناء بعد تصدير. بناء بعد تنفيذ استخدام حزمة داخل `process.js` مدخل. لا يمكن خريطة Host bootstrap تنفيذ عالم حد حاجة مسبق أولا تثبيت توافق `bootstrapPath`؛ لن زائف ضبط Host مسار مقابل نفس عدد بعيد مسار ملف.

### شفرة المصدر بحث جذب

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إعداد، تحليل، سياسة، ربط و تلقي إدارة تنفيذ |
| [`src/launch.ts`](src/launch.ts) | يمكن تنفيذ ملف/bootstrap معامل و تنفيذ عالم حد مورد خريطة |
| [`src/process.ts`](src/process.ts) | عملية فرعية إمساك يد، بيئة صاف فارغ و برنامج دورة الحياة |
| [`src/bootstrap.ts`](src/bootstrap.ts) | برنامج طلب قيمة، ربط بديل إدارة و إخراج التقاط |
| [`src/channel.ts`](src/channel.ts) | قسم لقطة، محدود كتابة و بروتوكول فشل |
| [`src/output-ledger.ts`](src/output-ledger.ts) | Host خارج طبقة نتيجة حساب كمية |
| — | لا إصدار وقت التشغيل ثابت صيغة إعداد طقم وحدة؛ قسم لقطة و عملية تنظيف عبر عملية حد قوي صنع تنفيذ، لا اعتماد اعتماد نفس عملية في مستقل مراقبة قياس. |

</details>

## تجربة النموذج

عبر `dsh-tools` PTC نمط و `dsh-workflow-ptc` بين وصل توفير؛ هو جمع عبر كل منها أداة نتيجة عرض برنامج نتيجة. في بين ربط عبر معلومة لا دخول نموذج تاريخ؛ خارج طبقة نتيجة التزام دوران عادي أداة فيض خروج سياسة.

#### KV Cache effect

لا مباشر بطلان؛ أداة اسم مستهلك مسؤول طلب بادئة أي تغيير.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

هذه حد حد تحديد تنفيذ حفظ إثبات و إبقاء إخراج.

- **قيد وراثة الذي اختيار خلفية حد**——كامل و جزء قوي صنع قدرة قسم فتح تقرير إبلاغ؛ صندوق رملي سياسة و تلقي إدارة عملية قيد هو مختلف حفظ إثبات.
- **كومة حد أعلى لا هو عملية شجرة داخل تخزين حد**——أصلي قسم إعداد و بعد بديل عملية داخل تخزين لا يخص V8 قديم توليد بديل حد أعلى. لا توفير عملية شجرة CPU حساب كمية جهاز.
- **تنظيف وراثة عملية فرعية يمكن مراقبة قياس نطاق**——استخدام fallback منصة فوق، هروب هروب بعد بديل ممكن ما زال في تلقي إدارة نطاق خارج؛ مشاركة رؤية عملية فرعية مزود إعلان حد.
- **تنفيذ هو مرة صفة**——لا يوجد yield/wait API، فوري نتيجة تدفق أو عبر استدعاء إبقاء برنامج حالة.
- **إخراج حد أعلى رفض تجاوز كمية محتوى، بينما لا إبقاء كل بايت**——فيض خروج فقط قدرة حفظ هذا مزود تسليم محدود نتيجة.
- **ربط في نقل وصل قبول وقت تلقي حد**——تحكم حد لا قيد Host ربط توليد نتيجة خلال قسم إعداد داخل تخزين.
- **console shim لديه خمسة عدد طريقة**——`log`،`info`،`warn`،`error` و `debug`.
