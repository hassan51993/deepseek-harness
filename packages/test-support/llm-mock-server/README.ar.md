# @deepseek-ai/dsh-llm-mock-server

[English](README.md) | العربية

## عام وصف

هذه الحزمة لـ اختبار و عرض عرض توفير يمكن تحرير نص برمجي OpenAI توافق HTTP/SSE(Server-Sent Events) طرف نقطة، جعل ذلك بلا حاجة مزود مفتاح يكفي فحص تحقق نموذج مزود فشل و نجاح. كل قد قبول `/chat/completions` طلب اعتماد مرة إزالة استهلاك تحت واحد نص برمجي سلوك، يشمل إعادة وضع، توقف ركود، شاذ شكل قسم قطعة، حد تدفق، خادم خطأ، تكملة كل و أداة استدعاء. اختبار عمل من يمكن عبر `pnpm run mock:llm` تشغيل خادم، أيضا يمكن استدعاء `startMockLlmServer`، بعد من سوف إرجاع التقاط طلب توفير تأكيد استخدام. حمل نوع فرعي `random` سلوك دعم حمل يمكن تكرار الآن خلط دمج لذا عائق ضغط قوة تشغيل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

هذه الحزمة يجعل اختبار أو عرض عرض بلا حاجة فعلي مزود يكفي استخدام مزود بروتوكول إجراء عبر معلومة: بدء خادم، نص برمجي تحويل أنت تفكير فحص تحقق بروتوكول سلوك، لكن بعد يأخذ حقيقي LLM مهايئ إشارة نحو هو base URL.

### مستقل تشغيل

من هذا مستودع تشغيل مصدر مدخل:

```sh
pnpm run mock:llm \
  --port 8000 \
  --api-key mock-key \
  --sequence partial_disconnect,success \
  --partial-text "discard this half"
```

سوف إصدار DeepSeek مهايئ إشارة نحو خادم؛ هو سوف سوف `/chat/completions` إلحاق إلى قد إعداد base:

```sh
DEEPSEEK_BASE_URL=http://127.0.0.1:8000/v1 \
DEEPSEEK_API_KEY=mock-key \
pnpm dsh --profile headless "test provider recovery"
```

مستودع نص برمجي سوف JSONL كتابة stdout:`ready` سجل يحمل بـ `/v1` ربط ذيل base URL و مع آلة نوع فرعي، لاحق طلب/نتيجة سجل معا تسمية نص برمجي سلوك و فعلي اختيار في أداة جسم سلوك. هذه الحزمة لا عام يمكن تثبيت اثنان دخول صنع أمر.

### نص برمجي تحويل سلوك

`--sequence` هو فاصلة رقم قسم فصل FIFO. استهلاك كل وقت إرجاع بنية تحويل HTTP 500؛`--repeat-last` صريح إعادة استخدام الأكثر بعد واحد بند.

| سلوك | بروتوكول نتيجة |
|---|---|
| `connection_reset` | في إرسال HTTP علامة رأس قبل إلغاء تدمير socket |
| `stream_disconnect` | إرسال SSE علامة رأس، لكن بعد في رقم واحد حدث قبل إعادة وضع اتصال |
| `partial_disconnect` | إرسال نص زيادة كمية، لكن بعد إعادة وضع socket |
| `stall` | إرسال SSE علامة رأس، و إبقاء فارغ خامل، مباشر إلى عميل/خادم إلغاء |
| `empty` | إرسال صالح بلا محتوى stop و `[DONE]` |
| `empty_body` / `stream_eof` / `partial_eof` | صحيح معتاد انتهاء، لكن نقص قليل مطلوب `[DONE]` حد |
| `malformed_json` / `malformed_event` | إرسال بلا فاعلية SSE JSON أو بلا فاعلية مزود قسم قطعة شكل |
| `rate_limit` / `server_error` / `service_unavailable` | إرجاع موجه إلى إعادة محاولة 429/500/503 JSON خطأ |
| `auth_error` / `invalid_request` / `context_overflow` / `quota_exceeded` | إرجاع إنهاء صفة خطأ أو حاجة مفرد وحيد استعادة مزود خطأ |
| `success` / `slow_success` / `reasoning_success` | تدفق صيغة إرسال كامل نص استجابة، اختياري تأخير متأخر أو أولا إرسال دفع إدارة (reasoning) |
| `tool_call_success` / `max_tokens` | بـ أداة استدعاء أو انتهاء سبب `length` إتمام |
| `wrong_content_type` | بـ `application/json` محتوى نوع إرسال صالح SSE متن |
| `random` | حسب حمل حق إعادة نوع فرعي مع آلة اختيار أداة جسم طلب سلوك |

`connection_refused` فقط قدرة في CLI في استخدام، كما يجب هو رقم واحد بند. هو سوف تأخير متأخر ربط استدعاء جهة إشارة تحديد غير صفر طرف فتحة، لذلك `--listen-delay-ms` خلال طلب سوف استلام إلى حقيقي TCP رفض؛ ذلك بقية بند في listener بدء بعد بدء.

### مع آلة نمط

استخدام تكرار `random` بند تنفيذ فتح وضع صيغة خلط دمج تشغيل:

```sh
pnpm run mock:llm \
  --port 8000 \
  --sequence random \
  --repeat-last \
  --seed 42 \
  --random-weights 'success=60,slow_success=10,connection_reset=5,stream_disconnect=5,partial_disconnect=10,empty=5,server_error=5'
```

حذف `--seed` سوف توليد نوع فرعي، و في `ready` سجل في ضرب طبع.`--random-weights` قبول غير سالب متبادل مقابل `behavior=weight` بند، و اشتراط حتى قليل واحد صحيح حق إعادة أداة جسم سلوك. توجيه خروج قيمة افتراضية هو واحد نجاح احتلال رئيسي توجيه ضغط قوة قسم نشر، يتضمن reset،disconnect، جزء إخراج، فارغ إتمام،stall،429/5xx، جاف صاف قطع قطع و صيغة خطأ JSON؛ هو لأجل تطبيق إضافة اختبار ضغط قوة، بينما غير تقدير حساب إنتاج أمر لذا تردد معدل.`connection_refused` يتم ترتيب حذف، لأن قد ربط طلب معالج لا يمكن إنتاج حقيقي رفض. مع آلة حق إعادة يتضمن `stall` وقت، لـ انتظار قياس عميل إعداد مقارنة قصير تدفق فارغ خامل مهلة، جعل مشهد و وقت انتهاء.

### وقت ترتيب و محتوى تحكم

CLI عام `--success-text`،`--partial-text`،`--reasoning-text`،`--chunk-size`،`--chunk-delay-ms`،`--disconnect-delay-ms`،`--retry-after-ms`،`--request-id`،`--tool-name` و `--tool-arguments`. جزء ثانية تأخير متأخر هو Node تحديد وقت جهاز نطاق داخل محدود كامل عدد؛`retryAfterMs` أيضا يجب لـ صحيح عدد. مكتبة قبول نفسه camel-case خيار. اختياري `apiKey` سوف دقيق تحقق `Authorization: Bearer <token>`؛ حذف وقت قبول أي token.

### ممكن خروج ماذا مشكلة

- **نص برمجي استهلاك كل**——استهلاك كل وقت إرجاع بنية تحويل HTTP 500؛ عند مرة تشغيل حاجة أكثر كثير طلب وقت ضبط `--repeat-last` أو إضافة طويل تسلسل.
- **لا يوجد صحيح حق إعادة أداة جسم سلوك مع آلة حق إعادة سوف يتم رفض**——كل بند كل يجب تسمية قائم سلوك، كما حتى قليل واحد بند حمل صحيح حق إعادة.
- **بلا فاعلية طلب لا إزالة استهلاك نص برمجي**——خطأ طريقة، مسار،Bearer token و شاذ شكل JSON سوف استلام إلى عادي 4xx استجابة، لذلك إعداد خطأ عميل ممكن استهلاك كل إعادة محاولة لكن لا دفع دخول تسلسل.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خادم تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم

خادم بناء قيام في واحد قاعدة لـ فوق: كل قد قبول chat-completions طلب من حسب وصول ترتيب ترتيب صف FIFO تنقل علامة إزالة استهلاك تماما جيد واحد سلوك، خادم من لا إعادة محاولة أو حل قراءة harness سياسة. تحقق أولا في تنقل علامة دفع دخول——فقط لديه `POST` كما مسار بـ `/chat/completions` ربط ذيل، إعداد مفتاح وقت يحمل صالح Bearer token، كما JSON متن يمكن تحليل طلب عندئذ إزالة استهلاك نص برمجي؛ ذلك بقية طلب كل استلام إلى عادي 4xx.`random` بند في طلب وقت عبر حمل نوع فرعي PRNG حسب إعداد حق إعادة تحليل، لذلك مرة تشغيل يمكن من ذلك ضرب طبع خروج نوع فرعي تكرار الآن.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | `startMockLlmServer`:listener، سلوك جدول، نوع فرعي مع آلة، بعيد قياس (telemetry) ، التقاط طلب سجل |
| [`src/cli.ts`](src/cli.ts) | `--sequence` و وقت ترتيب/محتوى خيار تحليل،JSONL stdout بعيد قياس |
| [`src/bin.ts`](src/bin.ts) | `pnpm run mock:llm` مصدر مدخل |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مكون؛ هذا مستقل اختبار خادم لا يملك Cordis حدث تدفق أو مشترك بيانات؛ ذلك بروتوكول سلوك و دورة الحياة عبر مباشر HTTP اختبار و تجميع بعد حلقة اختبار إجراء فحص تحقق. |

### بروتوكول مسار

طلب دخول معالج، عبر تحقق، لكن بعد اختيار سلوك: أداة جسم نص برمجي بند مباشر تشغيل،`random` سحب أخذ واحد، قد استهلاك كل نص برمجي فإن بـ بنية تحويل 500 تقرير إبلاغ `script_exhausted`. مع بعد `runBehavior` تنفيذ بروتوكول نتيجة——إلغاء تدمير socket،SSE تدفق،JSON خطأ أو تكملة كل——معا كل طلب و نتيجة حسب وصول ترتيب سجل إلى إرجاع جملة مقبض فوق، توفير اختبار تأكيد.`close()` إيقاف قبول طلب و قوي صنع إنهاء توقف ركود اتصال.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أي وقت حاجة مقابل هذا خادم خاص آخر صغير قلب. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **مع آلة حق إعادة بناء نموذج اختبار ضغط قوة، بينما غير إنتاج أمر لذا تردد معدل**——حاجة بيئة مخصص استخدام قسم نشر استدعاء جهة يجب توفير قد قياس كمية حق إعادة، و سجل إرسال خروج نوع فرعي.
- **طلب نص برمجي حسب وصول ترتيب تنفيذ**——تزامن استدعاء جهة مشترك واحد تنقل علامة، لذلك تحديد صفة كل جلسة لذا عائق قسم إعداد حاجة مستقل خادم نسخة.
- **حقيقي اتصال رفض حدوث في مستمع دورة الحياة مرحلة مقطع**——CLI تأخير متأخر يجب و عميل محاولة تجربة إعادة تراكم؛ طلب درجة مع آلة اختيار فقط قدرة إعادة وضع قد قبول اتصال.
