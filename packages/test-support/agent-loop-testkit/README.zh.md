# @deepseek-ai/dsh-agent-loop-testkit

[English](README.md) | العربية

## عام وصف

استخدام `dsh-agent-loop-testkit` يمكن لـ AgentLoop اختبار دقيق تجهيز معيار أولا قرار شرط و إنتاج loop قيادة، تجنب تجنب تكرار ضبط.harness يمكن إنشاء حقيقي Agent، و عام Inbox إدخال إقرار قيادة قدرة، بـ اختبار حمل دائم حدث، استعادة، إشعار و إقرار قيادة سلوك. فقط يحتاج تحرير طابور صف مستهلك اختبار ينبغي اختيار عملية داخل Inbox وتد؛ انتظار معالجة إدخال أبدا ينبغي يتم وصول وقت، ينبغي اختيار سريع سرعة فشل Inbox. اختبار ما زال مسؤول مهايئ، اختياري إضافة، تحميل ترتيب و سياق تحرير، هذه الحزمة لن إضافة نموذج مرئي سلوك.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

هذه الحزمة لـ AgentLoop اختبار توفير متاح خدمة توسيع اندفاع، و اشتراط اختبار واضح اختيار إنتاج Inbox سلوك أو بنية تحويل وتد.

### قيادة إنتاج Agent

عند اختبار تغطية حمل دائم Inbox حدث، إسقاط استعادة أو تحقق، فوري Inbox إشعار، أو loop قيادة إقرار قيادة سياسة وقت، استخدام `mountAgentLoopTestHarness()`. ينبغي في تركيب أولا قرار اعتماد بعد، إنشاء Agent قبل تركيب كل مقابل تحميل ترتيب حساس شعور مستهلك. سياق يملك loop و هذا harness إرجاع كل Agent.

```ts
import { Context } from '@deepseek-ai/cordis'
import { SessionId, type UserMessage } from '@deepseek-ai/dsh-session'
import {
  mountAgentLoopTestDependencies,
  mountAgentLoopTestHarness,
} from '@deepseek-ai/dsh-agent-loop-testkit'

const ctx = new Context()

await mountAgentLoopTestDependencies(ctx)
// Register the test adapter and any load-order-sensitive plugins here.
const harness = await mountAgentLoopTestHarness(ctx)
const agent = await harness.create(SessionId('test-agent'))
declare const message: UserMessage

agent.inbox.append('next-turn', message)
const admitted = harness.claim(agent, 'next-turn', 1)
```

اعتماد مساعد مساعدة دالة عبر `options` تحويل إرسال توجيه النظام و أداة سجل التسجيل إعداد، حذف هذه خدمة ذاتي لديه قيمة افتراضية خارج لا توفير اختبار قيمة افتراضية. إضافة تحميل فشل سوف جعل مساعد مساعدة دالة استدعاء يتم رفض؛ ترتيب في مقارنة مبكر تنشيط خدمة ما زال عودة سياق كل، و في سياق تحرير وقت واحد و حل حذف.

### بنية صنع بنية تحويل Agent وتد

عند اختبار كائن حاجة متغير انتظار معالجة قائمة، لكن لا اختبار حمل دائم صفة، إسقاط تحقق، فوري Inbox إشعار أو قيادة إقرار قيادة سياسة وقت، استخدام `createInboxStub()`. هذا وتد عبر اثنان عدد عملية داخل عدد مجموعة تنفيذ عام طابور صف عملية، كما أبدا سوف كتابة Session. عند اختبار كائن لا ينبغي وصول انتظار معالجة إدخال وقت، استخدام `unsupportedInbox()`؛ كل مرة تغيير كل سوف في أول عدد معنى خارج اعتماد موضع رمي خطأ.

```ts
import { createInboxStub } from '@deepseek-ai/dsh-agent-loop-testkit'

const agent = {
  // ...
  inbox: createInboxStub(),
}
```

### أي وقت استخدام

عند اختبار كائن هو إنتاج loop أو حمل دائم Inbox سلوك وقت، استخدام اعتماد و loop مساعد مساعدة دالة. فقط حاجة تحرير طابور صف مستهلك مجال اختبار استخدام بنية تحويل وتد. عند اختبار استكشاف قياس خدمة حقن فشل أو جزء توسيع اندفاع وقت، طلب مباشر تركيب اعتماد، لأن مساعد مساعدة دالة إخفاء صحيح هو هذا صنف اختبار يجب تحكم وصل خط.

### ممكن خروج ماذا مشكلة

harness لن تركيب أي LLM(كبير لغة نموذج) مهايئ. إذا اختبار إرسال مهمة سوف بدء نموذج طلب، طلب أولا تسجيل يتم قياس توجيه مهايئ. كل اختبار انتهاء بعد كل ينبغي dispose(مورد تحرير) الذي تابع سياق، جعل Agent تماما توقف مستقر، و حل حذف ذلك أثر مجال تسجيل.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير اختبار مساعد مساعدة أداة تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم

`mountAgentLoopTestDependencies` حسب ثابت اعتماد ترتيب——LLM، جلسة، جلسة إسقاط سجل التسجيل، توجيه النظام سجل التسجيل، أداة سجل التسجيل،agent سجل التسجيل——تركيب ستة عدد خدمة إضافة، و في `AgentLoop` قبل توقف تحت، جعل استدعاء جهة تحكم loop تحميل ترتيب.`mountAgentLoopTestHarness` تركيب عام إنتاج إضافة، عبر ذلك خدمة إنشاء Agent، و عام إنتاج قيادة إقرار قيادة عملية، بينما لا توجيه خروج loop أداة جسم Inbox صنف أو إسقاط تعريف.[`src/inbox.ts`](src/inbox.ts) فقط يتضمن عملية داخل متغير وتد و سريع سرعة فشل كما لا دعم حمل عملية احتلال موضع قيمة؛ هو لا يحتفظ إسقاط أو حمل دائم حدث تنفيذ. تركيب و قيادة تنفيذ يقع في [`src/index.ts`](src/index.ts). هذه الحزمة لا إصدار invariant companion، لأن هو فقط يحتفظ اختبار مساعد مساعدة أداة، لا وجود ممكن متبادل متبادل انحراف مغادرة مستقل إنتاج مراقبة قياس.

</details>

- [LLM حزمة](../../llm/llm/README.zh.md)——هذا مساعد مساعدة دالة دقيق تجهيز LLM وقت التشغيل و مهايئ واجهة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

هذه حد شرح مساعد مساعدة أداة لا مشترك ماذا. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **فقط مشترك مطلوب أولا قرار رئيسي جاف**——مهايئ، اختياري إضافة، مشهد خاص تحديد تحميل ترتيب و سياق تنظيف ما زال من استدعاء جهة مسؤول.
- **إنتاج harness لا يوجد مهايئ قيمة افتراضية**——بدء loop اختبار يجب تسجيل ذلك فعلي استخدام توجيه.
- **متغير Inbox وتد فقط وجود في عملية داخل**——فقط يلزم حمل دائم حدث، إسقاط استعادة أو تحقق، فوري إشعار أو إقرار قيادة سياسة يخص اختبار كائن، حينئذ ينبغي استخدام harness إنشاء Agent.
- **لا دعم حمل عملية Inbox لا قبول تغيير**——فقط يلزم انتظار معالجة إدخال يخص اختبار كائن، حينئذ ينبغي استخدام متغير وتد أو harness إنشاء Agent.
