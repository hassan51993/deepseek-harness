# @deepseek-ai/dsh-loader-smoke

[English](README.md) | العربية

## عام وصف

استخدام `dsh-loader-smoke` يمكن من تطبيق fixture(اختبار قبل وضع بيانات) حقيقي يمكن تنفيذ ملف و ذلك `cordis.yml` بدء تطبيق، و في عزل مؤقت دليل في التقاط إخراج و إتمام تنظيف.`runFixtureTurn` عبر قد إعداد أصل agent قيادة واحد بند مهمة، و إرجاع نهائي assistant نص و token استخدام كمية. اختبار يمكن اختيار صفر بناء شفرة المصدر تنفيذ أو قد بناء حزمة تنفيذ، جعل محلي و CI خطر دخان اختبار قسم آخر اعتماد مقابل بيئة مسبق مدة إزالة استهلاك مسار. هذا عدد دعم حمل طبقة مكتبة موجه إلى اختبار عمل من، لا لأجل منتج تجميع صار.

## استخدام هذه الحزمة

هذه الحزمة بـ قد تثبيت مستهلك طريقة بدء تطبيق fixture، و يجعل اختبار مراقبة نتيجة: اختيار مصدر نمط أو بناء نمط، من عزل cwd استخدام ذلك إعداد بدء يمكن تنفيذ ملف، لكن بعد يلزم ما انتظار جاف صاف خروج، يلزم ما يجعل واحد بند مهمة عبر أصل agent.

### بدء تطبيق fixture

`runLoaderSmoke` قبول يمكن تنفيذ ملف و إعداد مسار، اختياري كامل يمكن تنفيذ ملف معامل، بيئة تغطية، معيار إدخال، تشغيل قبل دقيق تجهيز و تنظيف قبل فحص. هو مسؤول عزل عمل دليل،DSH رئيسي دليل، تشخيص، قطع توقف وقت، إنهاء،EOF و تنظيف (فقط تنظيف ذاتي ذات إنشاء cwd، استدعاء جهة ذاتي حمل cwd أصل مثال إبقاء) ؛ عملية بـ صفر حالة خروج بعد إرجاع اثنان عدد تدفق، فشل وقت فإن رفض و مرفق حمل اثنان عدد تدفق:

```text
const result = await runLoaderSmoke({
  label: 'acp-agent',
  tempDirPrefix: 'acp-smoke-',
  binScript: '/abs/path/to/src/bin.ts',
  configPath: '/abs/path/to/cordis.yml',
  tsconfigPath: '/abs/path/to/tsconfig.json',
})
```

عند مشهد ثابت واحد تصميم جيد فشل وجه——أي مرة صفة جولة بـ خطأ نتيجة انتهاء——وقت ضبط `expectedExitCode`؛ بـ أي أخرى طريقة خروج (يشمل نجاح خروج) كل سوف جعل خطر دخان اختبار فشل.

### اختبار تسليم profile

Profile تجميع صار driver استخدام فقط حد مستودع داخلي `tests/fixtures/production-profile.ts` helper. هو عبر `loadProfile` تحميل إشارة تحديد قد تسليم profile و ذلك تركيب حزمة patch، شيء تحويل إبقاء link-mode fallback، و مثل link-mode launcher واحد مثال تركيب استخدام أصلي استعلام `PluginPackages`، لكن بعد يأخذ تركيب حزمة patch و اختبار `*.patch.yml` ملف اعتماد مرة تسليم إعطاء `boot` تركيب أصل `cordis:include`. هذه patch ينبغي فقط يتضمن اختبار مزود أو نموذج، عزل حفظ دائم مسار و يتم قياس كائن مخصص استخدام تغيير. فقط حاجة agent loop بينما لا اختبار profile تجميع صار حزمة درجة اختبار وحدة تعديل لـ في محلي تركيب `dsh-agent-loop-testkit`.

### قيادة fixture جولة

`runFixtureTurn(ctx, options)` يجعل واحد بند مهمة عبر تماما جيد واحد قد إعداد أصل agent: هو انتظار مهمة دخول حمل دائم استلام عنصر صندوق، يأخذ مواصفة حدث تحويل إرسال إعطاء أنت مراقبة جهاز، تحديث كتابة جلسة، و إرجاع نهائي assistant نص و تراكم حساب استخدام كمية. عرض مثال محلي driver متابعة مسؤول إعداد، تصيير و تأكيد.

### مصدر نمط أو بناء نمط

`resolveExampleLaunch` اختيار عرض مثال يمكن تنفيذ ملف من أي عدد ناتج بدء.`src` نمط في tsx تحت تشغيل يمكن تنفيذ ملف و ضبط `TSX_TSCONFIG_PATH`، جعل مساحة العمل استيراد عبر tsconfig `paths` خريطة تحليل——هذا هو صفر بناء تطوير مسار.`lib` نمط في عادي Node تحت تشغيل بناء بعد `lib/` يمكن تنفيذ ملف، جعل عار حزمة إضافة عبر حقيقي حزمة `exports` تحليل، و قد تثبيت مستهلك تحليل طريقة تماما متسق. نمط قدوم ذاتي صريح قيمة أو `DSH_EXAMPLE_MODE`(CI ضبط `lib`، تطوير وقت إبقاء لم ضبط) ؛ أخرى أي قيمة كل سوف واضح تقرير خطأ.

### ممكن خروج ماذا مشكلة

- **عملية دائم لا خروج**——خطر دخان اختبار قوي صنع تنفيذ قطع توقف وقت، و في فشل معلومة في تقرير إبلاغ التقاط تدفق؛ سوف spawn ذاته عملية شجرة لذا عائق fixture ممكن مقارنة خطر دخان اختبار تخزين نشط أكثر دائم، حاجة خارجي تنظيف.
- **بناء نمط حاجة أمر أولا بناء**——اختيار `DSH_EXAMPLE_MODE=lib` قبل أولا تشغيل `pnpm run build`؛ يملك هذا إعداد حزمة manifest(بيانات وصفية بيان) أيضا يجب إعلان إعداد في نقطة اسم كل حزمة.
- **التقاط إخراج تلقي execa افتراضي 100 MB `maxBuffer` قيد**——فقد تحكم عملية فرعية في هذا حد أعلى موضع يتم إنهاء، بينما لا هو في خطر دخان اختبار ذاتي اختيار ميزانية موضع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير harness تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم

harness بناء قيام في واحد قسم مغادرة لـ فوق: خطر دخان اختبار في عزل عالم حد في عملية فرعية داخل تشغيل، اختبار عملية فقط مراقبة و تأكيد.`runLoaderSmoke` إنشاء مؤقت cwd(أو إعادة استخدام استدعاء جهة توفير cwd) ، في ذلك داخل دقيق تجهيز عالم حد حالة، بـ عزل DSH رئيسي دليل (هذا cwd تحت `DSH_HOME`،`DSH_AGENTS_HOME`)spawn تحليل خروج يمكن تنفيذ ملف، قيام أي إغلاق stdin، و في قطع توقف وقت داخل انتظار جاف صاف خروج، لكن بعد في كل نوع نتيجة تحت كل تنفيذ فحص، كما فقط حذف ذاتي ذات إنشاء cwd.`runFixtureTurn` إبقاء في عملية داخل تشغيل: هو فحص بحث تركيب في وحيد أصل agent، من حمل دائم استلام عنصر صندوق استلام إلى مهمة بدء حمل متابعة تتبع أثر، مباشر حتى كامل agent تماما توقف مستقر؛ مع بعد تجميع مجموع كل خطوة استخدام كمية، و في إرجاع قبل تحديث كتابة جلسة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | نمط محلل،`runLoaderSmoke` عملية فرعية harness، خيار و نتيجة نوع |
| [`src/agent-turn.ts`](src/agent-turn.ts) | `runFixtureTurn` مباشر agent driver و نتيجة معلومة غلاف |
| — | لا إصدار وقت التشغيل ثابت كمية مرافق توليد مدخل؛ هذا اختبار دعم حمل حزمة لا مسؤول صيانة إنتاج حدث تدفق أو متغير بيانات؛ إزالة استهلاك هو اختبار طقم عنصر سوف فحص تحقق هذا harness. |
| [`tests/fixtures/production-profile.ts`](tests/fixtures/production-profile.ts) | فقط حد مستودع داخلي، توفير تجميع صار fixture استخدام تسليم profile تجميع helper |

<a id="model-experience"></a>
## تجربة النموذج

بلا، لأن اختبار harness فقط إيداع استدعاء جهة اختبار عادي مستخدم مهمة، و سوف نص التوجيه و أداة تجميع تسليم من قد تحميل شجرة مسؤول.

#### KV Cache أثر

حذف قد تحميل شجرة ذاته أثر خارج، بلا أخرى أثر؛ هذا helper حيث لا أكثر تعديل طلب بادئة، أيضا لا عبر تشغيل إبقاء حالة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أي وقت حاجة مقابل هذا harness خاص آخر صغير قلب. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **بناء نمط حاجة أمر أولا بناء**——يملك هذا إعداد حزمة manifest أيضا يجب إعلان إعداد في نقطة اسم كل حزمة.
- **التقاط stdout و stderr فقط تلقي execa افتراضي 100 MB `maxBuffer` قيد**——فقد تحكم عملية فرعية في هذا حد أعلى موضع يتم إنهاء، بينما لا هو في خطر دخان اختبار ذاتي اختيار ميزانية موضع.
- **مهلة فقط إنهاء مباشر عملية فرعية**——لديه لذا عائق fixture spawn عملية شجرة ممكن مقارنة خطر دخان اختبار تخزين نشط أكثر دائم، حاجة خارجي تنظيف.
