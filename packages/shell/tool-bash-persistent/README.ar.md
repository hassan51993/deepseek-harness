# @deepseek-ai/dsh-tool-bash-persistent

[English](README.md) | العربية

## عام وصف

هذه الحزمة لـ agent(ذكي جسم) توفير `bash` أداة، جعل cwd، توجيه خروج متغير، دالة و خلفية مهمة عبر استدعاء إبقاء. كل agent كل لديه عزل shell، ذلك أمر سلسلة سطر تنفيذ. حاجة عبر استدعاء حالة سير العمل ينبغي اختيار هذه الحزمة؛ كل بند أمر كل ينبغي من جاف صاف بيئة بدء وقت استخدام `dsh-tool-bash`. إعداد PTY خلفية و مفرد بند أمر مهلة؛`exit`، مهلة أو إلغاء سوف إعادة وضع shell، بينما انتظار stdin تفاعل صيغة أمر ممكن واحد مباشر تشغيل إلى مهلة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في agent حاجة في أمر بين إبقاء shell حالة أي تركيب في تحميل هذا إضافة——مثال مثل طويل وقت بناء جلسة، قد تنشيط بيئة، أو لـ لاحق خطوة توجيه خروج متغير نص برمجي. هو تسجيل `bash` أداة، حاجة `ctx.tools` و `ctx.terminals` خدمة، و في تنفيذ وقت حاجة يملك من agent جلسة.

### أي وقت اختيار

عند عمل اعتماد عبر استدعاء حالة وقت اختيار حمل دائم أداة: مرة صفة `dsh-tool-bash` استدعاء لا يمكن تسجيل إقامة `cd` أو توجيه خروج متغير. عند كل بند أمر كل ينبغي من معروف، جاف صاف بيئة بدء، أو أمر أيضا قصير أيضا مستقل وقت، اختيار مرة صفة أداة. هذا داخل لا دعم حمل حاجة تفاعل stdin أمر——قراءة إدخال قبل منصة عملية فرعية سوف واحد مباشر منع سد إلى أمر مهلة——لذلك تفاعل عمل يخص terminal أداة.

### الأكثر صغير إعداد

افتراضي `shell` خلفية عبر `dsh-terminal-bash` بدء تفاعل صيغة bash؛ نشر جهة يمكن تسجيل أخرى PTY خلفية و حسب اسم اختيار.

```yaml
- name: '@deepseek-ai/dsh-terminal'
- name: '@deepseek-ai/dsh-terminal-bash'
- name: '@deepseek-ai/dsh-tool-bash-persistent'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `backendType` | `shell` | لأجل كل agent shell قد تسجيل PTY خلفية |
| `timeoutMs` | `300,000` | مفرد بند أمر جدار ساعة حد أعلى؛ مهلة إغلاق shell |
| `maxOutputChars` | `16,000` | إبقاء أمر إخراج محرف حد أعلى؛ ثابت تشخيص معلومة في ذلك بعد إلحاق |
| `description` | `Run commands in a persistent bash shell. State, including the current directory and exported environment variables, persists across calls for this agent.` | موجه إلى نموذج بيئة اتفاق؛ نشر جهة يمكن وصف ذاتي ذات بيئة |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tool-bash-persistent) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### agent يمكن اعتماد ماذا

أمر مشترك كل agent واحد shell، لذلك حالة واحد مباشر إبقاء إلى `exit`، مهلة أو إعادة وضع——كل واحد نوع كل سوف إغلاق shell و إبلاغ إبلاغ agent تحت مرة استدعاء من مساحة العمل جديد دليل و بيئة بدء. نتيجة ترتيب حذف خاص إتمام علامة؛ كل بند إتمام أمر كل إلحاق `[Command finished with exit code N]`، بينما في تقرير إبلاغ هذا حالة قبل حينئذ خروج shell تعديل لـ إلحاق `[shell exited: code N]`،`[shell killed by signal: SIG]` أو `[shell exited]`، لكن بعد إعادة وضع. طويل إخراج إبقاء الأكثر مبكر قد إبقاء بادئة و مرفق قطع قص إشعار؛ إذا terminal قد إسقاط هذا بادئة، نتيجة سوف واضح شرح، بينما لا هو يأخذ ذيل جزء عند عمل كامل إخراج عرض.

### ممكن خروج ماذا مشكلة

لا يوجد يملك من agent جلسة استدعاء سوف بـ `bash requires an owning agent session` فشل، لا يوجد PTY خلفية تركيب سوف تنشيط هذا أداة، لكن أول مرة استدعاء بـ `no PTY backend registered for "shell"` فشل. تفاعل صيغة قبل منصة عملية فرعية (مثال مثل REPL) فقط لديه في خلفية إثبات ذلك stdin انتظار وقت عندئذ رفع قبل إرجاع جزء إخراج؛ لا فإن استدعاء واحد مباشر تشغيل إلى `timeoutMs`، مع بعد إغلاق لا تحديد shell و تقرير إبلاغ إعادة وضع. إلغاء أيضا سوف إعادة وضع و إسقاط نتيجة، أي جعل كامل حالة علامة قد يمكن مراقبة.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أداة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **كل owner واحد shell، متبادل لا مشترك.** shell سجل التسجيل حسب استدعاء جهة `Agent` لـ كل جلسة بناء مفتاح، لذلك تزامن agent دائم لا مشترك حالة، نفس agent أمر عبر حسب owner طابور صف سلسلة سطر تحويل.
- **علامة مرساة تحديد رفع أخذ.** كل بند أمر كل استخدام يحمل خروج حالة وحيد بدء توقف علامة حزمة تركيب؛ أداة جولة استفسار PTY scrollback و رفع أخذ حقيقي علامة بين منطقة بين، لذلك تلميح رمز و عودة إظهار إدخال دائم لا تسرب تسرب دخول نتيجة.
- **إعادة وضع، بينما غير إصلاح.** أي لا تحديد حالة——صريح `exit`، مهلة، إرسال فشل، في توقف——كل سوف إغلاق shell و يجعل تحت مرة استدعاء من كل جديد حالة بدء، لأن نصف معرفة حال shell لا مثل جاف صاف shell.
- **حسب owner دورة الحياة.** shell في أول مرة استخدام وقت كسول صفة إنشاء، في إضافة تحرير أو owner تفكيك حذف وقت إنهاء؛ حسب كل من عزل `ctx.terminals` خدمة يأخذ كل عملية كل محيط شريط إلى يملك هو agent.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:shell سجل التسجيل، أمر حزمة تركيب،scrollback جولة استفسار، رفع أخذ و تصيير |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ مهايئ خاص owner-to-shell ذاكرة مؤقتة لا يوجد يمكن مراقبة حدث أو بيانات علاقة.shell إعادة استخدام ما زال يمكن عبر أداة تنفيذ مراقبة. دورة الحياة اختبار سوف تحقق ذلك تنظيف سلوك، بلا حاجة فقط لـ ثابت صيغة زيادة عام مشترك API. |

### أمر مسار

أول بند أمر عبر `ctx.terminals.spawn` توليد shell، منع استخدام إدخال عودة إظهار (`stty -echo`) ، و انتظار حينئذ خيط. مع بعد كل بند أمر كل حزمة تركيب صار واحد سطر شيء إدارة نص——printf بدء بداية علامة، استخدام `$'…'` تحويل معنى أمر جسم،printf انتهاء علامة إضافة `$?`——لذلك داخل تضمين تبديل سطر لا يمكن يأخذ طرفية تلميح رمز تسرب تسرب دخول نتيجة. أداة بـ 1,000 سطر واحد صفحة جولة استفسار scrollback، مباشر إلى ظهور انتهاء علامة، رفع أخذ منطقة بين و وصل نفس أي حالة علامة واحد بدء تصيير. مهلة سوف في توقف قطع توقف وقت، التقاط جزء إخراج و إعادة وضع shell.

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى ماذا

توليد [`bash` schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-bash-persistent) ، يشمل إعداد `description`. هذا إضافة لا مساهمة مستقل توجيه النظام منطقة مقطع؛ شخص ضبط و بيئة إشارة جذب من نشر جهة مسؤول.

#### Token أثر

`bash` مرئي خلال إنتاج ثابت schema فتح إلغاء.

#### KV Cache أثر

فقط يلزم إعداد وصف و schema ثابت، بادئة حينئذ إبقاء مستقر.

### أداة نتيجة

#### نموذج يرى ماذا

أمر مشترك كل agent واحد shell، لذلك cwd، توجيه خروج متغير، قد تنشيط بيئة، دالة و خلفية مهمة كل سوف عبر استدعاء إبقاء. نتيجة ترتيب حذف خاص إتمام علامة. عند shell في لا يوجد ضرب طبع إتمام علامة حال حال تحت مجددا مرة قراءة stdin——`exec`، في قطع، أو مزود إثبات ذلك stdin انتظار تفاعل صيغة قبل منصة عملية فرعية بعد——استدعاء إرجاع التقاط جزء إخراج، هو ممكن بـ خلفية ذاتي ذات تلميح رمز نص ربط ذيل. كل بند إتمام أمر كل إلحاق `[Command finished with exit code N]`؛ في تقرير إبلاغ هذا حالة قبل حينئذ خروج shell تعديل لـ إلحاق `[shell exited: code N]`،`[shell killed by signal: SIG]`، أو خلفية اثنان من كل لم توفير وقت `[shell exited]`، لكن بعد إعادة وضع و إبلاغ إبلاغ نموذج تحت مرة استدعاء من كل جديد حالة بدء. طويل إخراج إبقاء الأكثر مبكر قد إبقاء بادئة و مرفق قطع قص إشعار. إذا PTY قد إسقاط هذا بادئة، نتيجة سوف واضح شرح، بينما لا هو يأخذ ذيل جزء عند عمل كامل إخراج عرض. مهلة إرجاع محدود جزء إخراج و إلحاق `[Command timed out or OOM]`، إغلاق لا تحديد shell و تقرير إبلاغ إعادة وضع.

#### Token أثر

اعتماد بيانات بينما تحديد.`maxOutputChars` حد إبقاء أمر إخراج؛ ثابت قطع قص، فقد فقد بادئة، حالة، مهلة و إعادة وضع تشخيص ممكن تأخير طويل نتيجة.

#### KV Cache أثر

فقط إلحاق أداة نتيجة يقع في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أداة أي وقت لا دمج ملائم أو حاجة خاص آخر صغير قلب. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **أداة حاجة يملك من agent و حقيقي PTY خلفية**——بلا agent استدعاء و لا يمكن بدء تفاعل shell خلفية كل سوف فشل.
- **تفاعل صيغة قبل منصة عملية فرعية فقط في عملية فرعية مزود إثبات ذلك stdin انتظار وقت عندئذ رفع قبل إرجاع جزء إخراج**——لا فإن استدعاء واحد مباشر تشغيل إلى `timeoutMs`.
- **صريح `exit` و مهلة سوف إسقاط shell حالة**——إلغاء نفس مثال إعادة وضع و إسقاط نتيجة، أي جعل كامل حالة علامة قد يمكن مراقبة؛ تحت مرة استدعاء بدء كل جديد shell.
- **شبكة شبكة وصول و حزمة مرآة مثل انتظار بيئة واقع يخص إعداد `description`**——بينما لا هو هذه الحزمة افتراضي وصف.
