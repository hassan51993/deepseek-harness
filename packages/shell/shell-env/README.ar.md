# @deepseek-ai/dsh-shell-env

[English](README.md) | العربية

## عام وصف

`dsh-shell-env` توفير كل مرة نموذج shell استدعاء——bash أو pwsh——الذي تشغيل تلقي معلومة `DSH_*` بيئة: داخل وضع واقع مثل `DSH_HOME`،`DSH_SHELL=1` و agent(ذكي جسم) `DSH_SESSION_ID`. إضافة عمل من يمكن تسجيل ذاتي ذات واقع، حمل إعلان مفتاح، حسب كل مرة تنفيذ استلام تجميع، و مع إضافة تحرير؛ تكرار كل حق أو لم إعلان وقت التشغيل مفتاح سوف واضح تقرير خطأ، بينما لا هو ساكن صامت تغطية. سجل التسجيل لن تغيير نموذج يرى أخرى أي محتوى——shell أداة يملك كل منها schema و نص التوجيه. أي تركيب نموذج shell أداة تركيب كل ملائم دمج اختيار هو؛ إعداد فقط قرار Harness رئيسي دليل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في أي تركيب نموذج shell أداة (`dsh-tool-bash` أو `dsh-tool-pwsh`) تركيب في تحميل هذا إضافة: هذا بعد كل مرة قبل منصة أو خلفية shell استدعاء كل سوف تشغيل في جديد استلام تجميع تلقي إدارة بيئة في، بينما لا هو عملية وراثة قدوم مهمة معنى `DSH_*` قيمة.

### كل مرة shell استدعاء كل سوف استلام إلى ماذا

كل مرة استدعاء كل سوف استلام إلى `DSH_HOME`(Harness رئيسي دليل قطعا مقابل مسار) ،`DSH_SHELL=1`،agent استدعاء أيضا سوف استلام إلى `DSH_SESSION_ID`(استدعاء جهة جلسة id).

### إضافة أنت ذاتي ذات بيئة واقع

أخرى إضافة عبر تسجيل واحد contributor قدوم مساهمة واقع، حاجة توفير مستقر اسم، هو ممكن إرجاع كامل `DSH_*` مفتاح تجميع دمج، كل مفتاح وصف، و لـ مرة تنفيذ حساب حساب أخذ قيمة resolver:

```ts
import type { Context } from '@deepseek-ai/cordis'
import type {} from '@deepseek-ai/dsh-shell-env'

export const inject = ['shellEnv']

export function apply(ctx: Context): void {
  ctx.shellEnv.register({
    name: 'deployment-region',
    variables: { DSH_DEPLOYMENT_REGION: { description: 'Current deployment region.' } },
    resolve: execution => execution.agent === undefined ? {} : { DSH_DEPLOYMENT_REGION: 'cn-north' },
  })
}
```

contributor يجب إعلان هو إرجاع كل مفتاح؛ إرجاع لم إعلان أو غير نص قيمة سوف يجعل هذا مرة استدعاء فشل. تسجيل مع تسجيل إضافة تحرير بينما تحرير، لذلك حار إعادة تحميل إضافة سوف إزالة هو واقع.

### اختيار Harness رئيسي دليل

وحيد إعداد حقل قرار كشف لـ `DSH_HOME` رئيسي دليل؛ افتراضي تحليل ترتيب لـ `dshHome` إعداد، بيئة متغير `$DSH_HOME`، لكن بعد هو `~/.dsh`.

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `dshHome` | `$DSH_HOME`، لكن بعد `~/.dsh` | كشف لـ `DSH_HOME` Harness رئيسي دليل قطعا مقابل مسار |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-shell-env) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### ممكن خروج ماذا مشكلة

اثنان عدد contributor إعلان نفس عدد مفتاح، أو contributor صوت تسمية يملك إبقاء داخل وضع مفتاح (`DSH_HOME`،`DSH_SHELL`،`DSH_SESSION_ID`) ، كل سوف توجيه يؤدي إضافة تحميل وقت واضح تقرير خطأ.`DSH_*` مفتاح يجب كل كبير كتابة و حمل تحت تخطيط خط (مثال مثل `DSH_REGION`) ، نقص قليل وصف أيضا سوف يجعل تسجيل فشل.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير سجل التسجيل خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **تلقي معلومة نطاق الأسماء، كل مرة استدعاء إعادة بناء.** بيئة هو عودة Harness كل `DSH_*` نطاق الأسماء:shell منفذ إسقاط وراثة `DSH_*` قيمة، و لـ كل مرة تنفيذ دمج سجل التسجيل حالي لقطة، لذلك تضمين طقم harness و تزامن أب فرعي agent لا يمكن تسرب تسرب قديم قديم هوية،`process.env` أيضا دائم لا يتم تعديل.
- **إعلان كل حق، اندفاع مفاجئ واضح تقرير خطأ.** contributor مسبق أولا إعلان مفتاح، جعل تكرار كل حق في رقم واحد بند أمر قبل حينئذ يتم اكتشاف؛resolver فقط قدرة إرجاع قد إعلان مفتاح.
- **داخل وضع مفتاح إبقاء في هذا داخل.** `DSH_HOME`،`DSH_SHELL` و `DSH_SESSION_ID` لـ سجل التسجيل إبقاء؛contributor لا يستطيع صوت تسمية يملك هو جمع.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل،`ShellEnvRegistry` خدمة و داخل وضع واقع |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ بيئة سجل التسجيل سوف في كل مرة تسجيل و استلام تجميع وقت تحقق كل حق و استلام تجميع قيمة، أيضا لا إصدار يمكن توفير مرافق توليد مدخل تسليم تقاطع فحص مستقل لقطة. |

### استلام تجميع

`collect(execution)` من داخل وضع مفتاح خروج إرسال، عند تنفيذ يحمل agent وقت إضافة دخول جلسة id، مجددا حسب contributor اسم ترتيب ترتيب دمج كل قد تسجيل contributor تحليل خروج قيمة. نتيجة هو واحد تجميد ربط، حسب مفتاح ترتيب ترتيب لقطة، عبر `ShellExecRequest.dshEnv` نقل تمرير.`list()` قطعة رفع إعلان بينما لا تشغيل resolver، لذلك لا يمكن عكس عكس اعتماد تنفيذ قيمة.

<a id="model-experience"></a>
## تجربة النموذج

عبر shell أداة (`dsh-tool-bash`،`dsh-tool-pwsh`) بين وصل إنتاج أثر؛ هذه أداة يأخذ هذا سجل التسجيل تلقي إدارة `DSH_*` واقع كشف في كل مرة shell أداة استدعاء في.

#### KV Cache أثر

تلقي إدارة بيئة دائم بعيد لن دخول طلب بادئة، لذلك لن جعل مزود ذاكرة مؤقتة إعادة استخدام بطلان؛ أي بادئة تغيير كل أخذ قرار في shell أداة تعريف و حالي طلب معلومة غلاف.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح سجل التسجيل أي وقت لا دمج ملائم أو حاجة صغير قلب استخدام. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **`list()` فقط قطعة رفع إضافة مساهمة متغير**——سجل التسجيل ذاتي لديه داخل وضع مفتاح (`DSH_HOME`،`DSH_SHELL`،`DSH_SESSION_ID`) لا يتضمن في داخل، لذلك تشخيص، نص التوجيه أو UI شفرة لا نيل يأخذ `list()` عند عمل كامل بيئة دليل.
