# @deepseek-ai/dsh-invariants

[English](README.md) | العربية

## عام وصف

`dsh-invariants` في DeepSeek Harness تركيب في تشغيل حزمة ذاتي لديه وقت التشغيل فحص——ثابت كمية: أي حزمة كل يمكن إصدار واحد `./invariant` إعداد طقم مدخل، في تركيب تشغيل خلال تحقق ذلك ذاته حمل دائم علاقة (مرجعي حدث تدفق و متغير لقطة). فحص تلقائي تشغيل، فشل فحص سوف تقرير إبلاغ عودة بسبب إلى يملك يتم مخالفة عكس علاقة حزمة `InvariantError`. حاجة حمل عام فتح صلة و حزمة اسم مرور ترشيح جهاز ذاتي فحص تشخيص وقت اختيار هو؛ معيار agent(ذكي جسم) تركيب قد تركيب هو و أربعة عدد نواة قلب إعداد طقم مدخل، بينما مفرد وحيد تحميل خدمة لن تثبيت أي فحص.

## استخدام هذه الحزمة

عند تركيب حاجة تحقق ذاته وقت التشغيل اتفاق وقت تركيب سجل التسجيل، لكن بعد قرار تشغيل أي بعض حزمة فحص. خدمة كشف `ctx.invariants`؛ إعداد طقم مدخل بـ ذلك حزمة دقيق npm اسم تسجيل فحص، كل مرة فشل كل سوف يحمل الذي تابع حزمة اسم.

### أي وقت استخدام

حاجة فوري تشخيص تركيب طلب استخدام سجل التسجيل.[`dsh-sdk-minimal`](../../bundle/sdk-minimal/README.ar.md) تركيب هو و أربعة عدد نواة قلب لديه حالة إعداد طقم مدخل——`dsh-session`،`dsh-agent`،`dsh-scope` و `dsh-agent-loop`؛`dsh-base` لحظة معنى حذف وقت التشغيل تشخيص. ذاتي تعريف تركيب تركيب سجل التسجيل، و لـ أي أخرى قد تحميل، كما أمل نظر فحص ذلك اتفاق حزمة إضافة إعداد طقم مدخل. مفرد وحيد تحميل سجل التسجيل لن تثبيت أي فحص: هو ذاته لا يحمل أي منتج فحص، لذلك من لا تركيب إعداد طقم مدخل تركيب لن مراقبة إلى أي تشخيص سلوك.

### تفعيل فحص و اختيار حزمة

سجل التسجيل افتراضي تفعيل، و في لا يوجد مرور ترشيح جهاز حال حال تحت فحص كل قد تسجيل حزمة. استخدام `enabled` عمل عام فتح صلة، استخدام `package_allowlist` فقط وصل قبول إشارة تحديد حزمة، استخدام `package_blocklist` في allowlist مطابقة بعد ترتيب حذف حزمة——blocklist مطابقة أولوية في allowlist مطابقة. نمط هو منطقة قسم كبير صغير كتابة JavaScript صحيح فإن جدول بلوغ صيغة مصدر (حذف غير ذاتي حمل `^` و `$`، لا فإن لا مرساة تحديد) ؛ بلا فاعلية، فارغ أبيض أو تكرار بند سوف جعل خدمة بدء فشل، بينما لا هو يتم قفز مرور.

```yaml
- name: '@deepseek-ai/dsh-invariants'
  config:
    enabled: true
    package_allowlist:
      - '^@deepseek-ai/dsh-'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `enabled` | `true` | كل قد تسجيل فحص عام فتح صلة |
| `package_allowlist` | `[]` | وصل قبول حزمة اسم صحيح فإن مصدر؛ لـ فارغ فإن الكل وصل قبول |
| `package_blocklist` | `[]` | في allowlist مطابقة بعد ترتيب حذف حزمة اسم صحيح فإن مصدر |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-invariants) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### تشغيل أي بعض فحص

كل إعداد طقم مدخل حفظ حماية ذلك حزمة يملك علاقة، كما فقط لـ يمكن مراقبة حدث أو متغير بيانات علاقة تثبيت فحص——أبدا إبرة مقابل خدمة أو طريقة هل وجود. قد إصدار يمكن تنفيذ إعداد طقم مدخل تغطية:

| إعداد طقم مدخل | فحص |
|---|---|
| `dsh-session`،`dsh-agent`،`dsh-scope`،`dsh-agent-loop` | جلسة سجل يتضمن علاقة و استدعاء/نتيجة تتبع أثر،agent حالة تحويل، مرور مرور أثر مجال مرور ترشيح توزيع رئيسي جسم،loop الذي بناء طلب إعادة بناء |
| `dsh-llm`،`dsh-llm-retry`،`dsh-tools`،`dsh-system-prompt` | LLM(كبير لغة نموذج) تدفق لغة قاعدة، إعادة محاولة فشل شكل حالة، أداة خط الإنتاج مرحلة مقطع إعداد مقابل و تجميد ربط نتيجة، نص التوجيه تجميع فصل عقدة اسم |
| `dsh-compaction`،`dsh-hook-protocol`،`dsh-sandbox-policy` | ضغط (compaction) تدفق إعداد مقابل، خطاف استدعاء/نتيجة إعداد مقابل، صندوق رملي mode قيمة |
| `dsh-fs`،`dsh-subagent`،`dsh-workflow`،`dsh-tool-workflow` | نظام الملفات حدث هوية،subagent مزود و بدء/انتهاء إعداد مقابل، سير العمل دورة الحياة هوية، سير العمل سجل شكل حالة |
| `dsh-goal`،`dsh-goal-round-driver` | حمل دائم goal تدفق طي و إعادة بناء متابعة نص التوجيه |
| `dsh-permission-presets`،`dsh-user-approval`،`dsh-commands` | preset مرجع إشارة نحو نشط حركة preset، مراجعة دفعة استفسار سؤال/قرار إعداد مقابل، أمر تشغيل/إتمام إعداد مقابل |
| `dsh-jobs`،`dsh-tool-todo`،`dsh-time-context` | مهمة لقطة حقل علاقة، كامل جدول todo شكل حالة، حمل دائم وقت ساعة قراءة عدد |
| `dsh-credentials`،`dsh-settings`،`dsh-storage-domain`،`dsh-workspace` | إيداع حدث مقابل وفق نشط حركة خدمة أو داخل تخزين حالة، فعلي جسم ذاكرة مؤقتة مرآة مثل |
| `dsh-agent-presets`،`dsh-session-title`،`dsh-plan-mode`،`dsh-schedule` | preset تركيب موضع، عنوان مصدر مرجع،plan-mode تحميل حمل،schedule تدفق |
| `dsh-client-hmr`،`dsh-client-modules`،`dsh-client-runtime` | متصفح/node جانب stat-watcher دورة الحياة، بدء مدخل رسم،slot تغيير إصدار تحويل |

ذلك بقية مساحة العمل حزمة حذف إعداد طقم مدخل، و في كل منها README في شرح حزمة درجة سبب.

### نحو ذاتي تعريف تركيب إضافة إعداد طقم مدخل

إعداد طقم مدخل حينئذ هو تركيب في سجل التسجيل جانب عادي إضافة. هو إعلان الذي يحتاج خدمة، و بـ ذلك حزمة دقيق npm اسم تسجيل؛ سجل التسجيل سوف أولا إتمام ذلك ضبط مجددا إتمام تسجيل.

```ts
import type { Context } from '@deepseek-ai/cordis'
import InvariantRegistry from '@deepseek-ai/dsh-invariants'
import * as SessionInvariant from '@deepseek-ai/dsh-session/invariant'

declare const ctx: Context

ctx.plugin(InvariantRegistry, { enabled: true })
ctx.plugin(SessionInvariant)
```

### فحص فشل وقت

مخالفة قاعدة سوف من تقرير إبلاغ هو سياق رمي خروج `InvariantError`: هو يحمل مستقر `INVARIANT` شفرة، الذي تابع حزمة كامل npm `packageName`، و بـ `invariant violated by "<package>": …` فتح رأس رسالة. فشل لذلك يمكن عودة بسبب إلى بعض عدد حزمة، بينما سجل التسجيل بلا حاجة استيراد أي منتج شفرة.installer ذاته فشل إعداد طقم مدخل سوف يتم تحرير، ذلك تسجيل سوف تراجع، لذلك ضرر تالف فحص لن متروك إبقاء جزء مستمع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير سجل التسجيل خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

- **و منتج غير متصل سجل التسجيل.** خدمة لا استيراد أي session،agent،scope أو agent-loop حزمة، أيضا لا يتضمن هو جمع فحص؛ إعداد طقم مدخل يأخذ فحص وضع في ذلك ملكية من جانب حافة.
- **حقيقي علاقة، بينما غير شخص لـ تأكيد.** إعداد طقم مدخل فقط فحص ذلك حزمة يملك حدث تدفق أو متغير بيانات علاقة؛ تأكيد طريقة، إضافة اسم، حقن أو ثابت صاف دالة نتيجة هو نوع، تحميل أو اختبار وحدة صلة ملاحظة نقطة، أبدا هو وقت التشغيل ثابت كمية.
- **تسجيل إبقاء ملكية.** أي جعل مرور ترشيح جهاز يجعل installer إبقاء غير نشط حركة، حزمة اسم أيضا سوف يتم إبقاء، لذلك اثنان عدد إضافة دائم بعيد لن ساكن افتراضي قيادة نفس عدد اسم حرف.
- **إعداد طقم مدخل وصل خط من آلة آلة قاعدة قوي صنع.** `pnpm run verify-package-invariants` رفض فارغ installer، حذف أو تجاهل اختصار reporter installer، خطأ تسجيل اسم، لا كامل إصدار وصل خط، و حذف إعداد طقم مدخل بعد ناقص إبقاء وصل خط ([حذف إعداد طقم مدخل قلم تسجيل](../../../.agents/notes/implemented/simplification/2026-08-28-omit-unneeded-invariant-companions.ar.md)).

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema،`InvariantRegistry` خدمة، اختيار، تسجيل،`InvariantError` |
| — | لا إصدار وقت التشغيل ثابت كمية إعداد طقم مدخل؛ تسجيل ملكية و فرعي درجة دورة الحياة ذاته حينئذ هو خدمة تغيير حد؛ من نفس سجل التسجيل مراقبة هو جمع فقط سوف تكرار ذلك تنفيذ. |

### اختيار و تسجيل دورة الحياة

`register(packageName, installer)` إبقاء كامل npm اسم و إرجاع أثر مجال تحويل disposer. تفعيل installer في مخصص استخدام فرعي fiber في تشغيل؛`installer.inject` إعلان هذا fiber يمكن وصول خدمة، تزامن أو مختلف خطوة إتمام كل سوف في تسجيل نجاح قبل يتم join. فشل سوف تحرير فرعي درجة و أصل فرعي أرض استلام عودة إبقاء. خدمة يملك كل تسجيل fiber، إرجاع disposer معا يخص إعداد طقم fiber، لذلك إزالة مهمة واحد جانب كل سوف إزالة مستمع، تتبع أثر حالة و إبقاء——إعداد طقم مدخل يمكن إعادة تحميل و مجددا مرة تسجيل نفس اسم بينما لا إبقاء قديم حالة. من جلسة دعم دعم إعداد طقم مدخل من حمل دائم حدث إعادة بناء baseline؛ فقط فوري إعداد طقم مدخل مراقبة إعادة تحميل بعد بدء عملية.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح سجل التسجيل أي وقت لا دمج ملائم أو حاجة خاص آخر تشغيل صيانة. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **مرور ترشيح جهاز في خدمة دورة الحياة داخل ثابت**——`enabled`،`package_allowlist` و `package_blocklist` في بدء وقت تحرير ترجمة مرة؛ أكثر تعديل هو جمع حاجة تنفيذ Cordis إضافة إعادة تحميل.
- **فقط فوري إعداد طقم مدخل سوف متروك تسرب إعادة تحميل قبل عملية**——فقط مراقبة فوري عملية إعداد طقم مدخل لا يمكن إعادة بناء ذاته إعادة تحميل قبل بدء عملية؛ من جلسة دعم دعم إعداد طقم مدخل من حمل دائم حدث إعادة بناء baseline.
- **طلب إعادة بناء فقط تغطية loop بناء طلب**——`dsh-agent-loop` إعداد طقم مدخل فقط إعادة بناء loop صريح بناء طلب؛ مباشر مرة صفة LLM استدعاء أي جعل من استدعاء جهة تجميد ربط أو مرفق إضافة جلسة id، ما زال لا في هذا اتفاق داخل.
- **لا يوجد إعداد طقم مدخل حينئذ لا يوجد فحص**——سجل التسجيل ذاته لا يحمل منتج فحص؛ فقط تركيب خدمة تركيب مراقبة لا إلى أي سلوك.
