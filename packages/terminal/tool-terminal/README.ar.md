# @deepseek-ai/dsh-tool-terminal

[English](README.md) | العربية

## عام وصف

عند agent حاجة عبر استدعاء إبقاء طرفية حالة أو توفير تفاعل صيغة إدخال وقت، استخدام `dsh-tool-terminal`. هو يمكن فتح، إرسال، قراءة، نقل تمرير إشارة، إغلاق و صف خروج طرفية جلسة، معا منع توقف واحد agent عملية أخرى agent جلسة. إرسال يمكن انتظار محدود قبل منصة إخراج، أيضا يمكن إرجاع توفير لاحق استلام تجميع أو في قطع خلفية مهمة job id.`maxResultBytes` حد كل نتيجة كبير صغير، بينما نتيجة سوف إبقاء في جلسة تاريخ في مباشر إلى ضغط (compaction). إشارة جذب سوف يجعل نموذج مقابل محدود عمل أولوية استخدام مفرد مرة أداة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تركيب تركيب طرفية خلفية، كما نموذج ينبغي عند قدرة عبر استدعاء استخدام طرفية حالة وقت تفعيل هذه أداة——استخدام ضبط تجربة جهاز مفرد خطوة ضبط تجربة، في REPL في استكشاف، أو في قطع قبل منصة أمر بعد عودة إلى shell. إشارة جذب فصل عقدة سوف جذب توجيه نموذج مقابل محدود عملية استخدام مفرد مرة bash،read،write و edit أداة.

### ستة عدد أداة

| أداة | أثر | نتيجة |
|---|---|---|
| `terminal_open` | حسب خلفية نوع إنشاء حد تحديد كل من نطاق جلسة | جلسة id، اسم، نوع،pid، حالة و محدود بدء إخراج |
| `terminal_send` | كتابة نص، اختياري أرض إيداع Enter، و انتظار حينئذ خيط——أو بدء خلفية مهمة | محدود إخراج إضافة انتظار و جلسة حالة، أو واحد job id |
| `terminal_read` | لا إرسال إدخال، قراءة واحد صفحة محدود إبقاء إخراج | حمل سطر قسم صفحة بيانات وصفية نص |
| `terminal_signal` | نحو قبل منصة عملية مجموعة إلقاء تمرير واحد سماح إشارة | `delivered` إضافة هدف عملية مجموعة id |
| `terminal_close` | إغلاق جلسة و انتظار ذلك عملية شجرة انتهاء | قد إغلاق أو صحيح في إغلاق نتيجة |
| `terminal_list` | صف خروج استدعاء جهة نشط وثب جلسة | حد تحديد كل من نطاق جلسة ملخص |

### تركيب طريقة

```yaml
- name: '@deepseek-ai/dsh-terminal'
- name: '@deepseek-ai/dsh-terminal-bash'
- name: '@deepseek-ai/dsh-tool-terminal'
```

أداة حاجة `ctx.terminals`——يجب تركيب واحد خلفية——و لأجل إشارة جذب فصل عقدة توجيه النظام خدمة. خلفية إرسال أيضا مقدار خارج اشتراط مهمة خدمة و ذلك موجه إلى نموذج تحكم جهاز (`@deepseek-ai/dsh-tool-jobs`).

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `enableRunInBackground` | `true` | عام و قبول `run_in_background`؛ ضبط لـ `false` وقت إزالة schema حقل و رفض هذا معامل |
| `maxResultBytes` | `262144` | كل كامل طرفية نتيجة UTF-8 حد أعلى (الأكثر صغير قيمة `64`) ؛ في انتظار، جلسة، قسم صفحة، قطع قطع و مهمة حالة بيانات وصفية الكل إضافة دخول بعد حساب حساب |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tool-terminal) و[أداة دليل](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-terminal) هو إعداد حقل و schema نفاد كل صيغة حق مصدر.

### خلفية إرسال

`terminal_send(run_in_background: true)` قيام أي إرجاع job id، بينما لا هو انتظار. مهمة استخدام `job_output` استلام تجميع——هو سوف انتظار و قراءة زيادة كمية إخراج——استخدام `job_kill` إيقاف، بعد من نحو قبل منصة عملية مجموعة إلقاء تمرير حق صحيح `SIGINT`. نقص قليل مهمة واجهة وجه وقت، خلفية نمط سوف في كتابة إدخال قبل فشل.

### يمكن مراقبة نتيجة و فشل

قبل منصة إرسال إرجاع طرفية جديد إخراج و `wait: <سبب>` و جلسة حالة؛`session_exit` يمثل قمة طبقة shell قد خروج، بينما `inferred_idle` أو `timeout` أبدا إثبات قبل منصة أمر قد خروج. استخدام لم تسجيل خلفية نوع فتح جلسة سوف فشل. كبير في `maxResultBytes` نتيجة سوف في UTF-8 حد موضع قطع قطع و مرفق علامة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أداة خلف بعد تصميم و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

هذه الحزمة هو رقيق مهايئ:6 عدد أداة بـ تنفيذ agent بصفة كل من تحويل إرسال إلى `ctx.terminals`، عرض طبقة تصيير محدود نتيجة. خلفية إرسال يأخذ في طريق عملية تسجيل إلى `ctx.jobs`، من عام مهمة واجهة وجه مسؤول انتظار، زيادة كمية قراءة و `SIGINT` إلقاء تمرير.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | 6 عدد أداة تعريف،schema، إشارة جذب فصل عقدة، خلفية مهمة تجميع صار |
| [`src/render.ts`](src/render.ts) | نتيجة تصيير و كامل نتيجة UTF-8 حد أعلى |

### نتيجة حد أعلى

كل طرفية ذاته مفرد نص نتيجة كل سوف في مواصفة تحويل بعد أداة أو خط الإنتاج خطأ، سياسة رفض و قصير مسار، استبدال و منع توقف، و عام مهمة حالة نص بعد، تلقي `maxResultBytes` حد؛ قطع قطع إبقاء UTF-8 حد و لـ قطع قطع علامة مسبق إبقاء فضاء. بنية تحويل كثير كتلة سياسة نتيجة إبقاء ذلك بنية.64 بايت الأكثر صغير حد أعلى حفظ إثبات سجل التسجيل توقيع إرسال كل جلسة أو job id كل ظهور في إنشاء تأكيد في.

### UI عرض معنى رسم

قبل منصة إرسال استخدام طرفية استدعاء و نتيجة بطاقة؛ خلفية إرسال و أخرى 5 عدد أداة استخدام عام `execute`،`read` أو `delete` بطاقة. كل أداة كل لا إخراج مصدر موضع.

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى ماذا

هذا إضافة مساهمة التالي ثابت إشارة جذب فصل عقدة:

##### طرفية إشارة جذب

```markdown
Use a terminal session only when work needs persistent terminal state or interactive stdin; prefer shell/read/write/edit for bounded one-shot operations. Track every terminal session id and close sessions that no longer matter. An inferred_idle or timeout result does not prove the foreground command exited.
```

#### Token أثر

إضافة نشط وثب خلال، كل مرة طلب كل سوف إنتاج قليل كمية ثابت إدخال صار هذا.

#### KV Cache أثر

تسجيل نطاق و إشارة جذب نص ثابت وقت، بادئة إبقاء مستقر.

### أداة schema

#### نموذج يرى ماذا

6 عدد توليد schema صف في [`dsh-tool-terminal` دليل فصل عقدة](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-terminal) في. هذا إضافة نشط وثب وقت، طلب في سوف يتضمن هو جمع ثابت schema token؛ حسب agent نطاق مرور ترشيح أداة وقت ممكن إخفاء هذه schema.

#### Token أثر

أداة مرئي طلب سوف إنتاج ثابت schema صار هذا.

#### KV Cache أثر

أداة مرئي صفة و تعريف ثابت وقت، بادئة إبقاء مستقر.

### أداة نتيجة و مهمة سياق

#### نموذج يرى ماذا

spawn إرجاع id و محدود بدء إخراج. إرسال و قراءة إرجاع محدود طرفية نص و حينئذ خيط و تاريخ علامة. خلفية نمط إرجاع عام job id. كل طرفية ذاته مفرد نص نتيجة كل تلقي `maxResultBytes` حد؛ نتيجة إبقاء في جلسة تاريخ في مباشر إلى ضغط، زيادة كمية مهمة قراءة لن تكرار قد إزالة استهلاك إخراج.

#### Token أثر

طرفية ذاته نتيجة مع بيانات تغير، و تلقي `maxResultBytes` حد؛ كل إرجاع نتيجة كل إبقاء في تاريخ في مباشر إلى ضغط.

#### KV Cache أثر

فقط إلحاق؛ جديد نتيجة يقع في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح ناقص موجه إلى نموذج واجهة وجه. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **لا يوجد TUI أو حسب مفتاح تسلسل واجهة وجه**——أداة اسم حسب مفتاح تسلسل، كل شاشة TUI تفاعل،BEL، ضبط كامل كبير صغير و تلقائي بدء متساو لم ظهور في أي schema في.
- **خلفية نمط اشتراط مهمة واجهة وجه**——`run_in_background` معا حاجة `@deepseek-ai/dsh-jobs` و ذلك موجه إلى نموذج تحكم جهاز (`@deepseek-ai/dsh-tool-jobs`) ؛ نقص قليل وقت سوف رفض هذا معامل.
