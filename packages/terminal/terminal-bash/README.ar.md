# @deepseek-ai/dsh-terminal-bash

[English](README.md) | العربية

## عام وصف

`dsh-terminal-bash` في نشر صندوق رملي سياسة تحت بدء حمل دائم تفاعل صيغة shell: جلسة عبر استدعاء الأداة تخزين نشط، فحص قياس shell أي وقت يمكن استقبال إدخال، و إبقاء محدود تدريجي سطر إخراج توفير قراءة. هو توفير `shell` خلفية نوع، و عبر `shellDialect` ضبط في POSIX فوق دعم حمل bash، في Windows فوق دعم حمل pwsh. عبر قد تركيب عملية فرعية مزود، نفس عدد خلفية حيث يمكن و محلي تنفيذ عالم حد تركيب، أيضا يمكن و بعيد مسار تنفيذ عالم حد تركيب. كل شاشة طرفية تطبيق لا في ذلك تدريجي سطر اتفاق نطاق داخل.

## استخدام هذه الحزمة

عند تركيب حاجة حمل دائم shell جلسة وقت تركيب هذا خلفية——cwd، تصدير متغير، دالة أو جارٍ تشغيل تفاعل صيغة عملية فرعية انتظار حالة يجب عبر استدعاء الأداة تخزين نشط. هو هو افتراضي `shell` نوع: تركيب فقط تركيب `@deepseek-ai/dsh-terminal` بينما لا تركيب هو وقت، سوف لا يوجد أي جلسة يمكن فتح.

### أي وقت اختيار

عند عمل حاجة حالة حمل متابعة وجود تفاعل صيغة shell أو REPL وقت اختيار هذا خلفية: في ضبط تجربة جهاز في مفرد خطوة تنفيذ، في Python أو Node REPL في استكشاف، أو في قطع قبل منصة أمر بعد عودة إلى shell. مقابل في ينبغي عند مرة استدعاء أي بدء و انتهاء محدود أمر، طلب اختيار مفرد مرة bash أداة.bash جهة قول موجه إلى POSIX؛pwsh جهة قول موجه إلى `dsh-pwsh-local` قدرة تحليل خروج pwsh يمكن تنفيذ ملف Windows رئيسي آلة.

### تركيب طريقة

تركيب طرفية خدمة، عملية فرعية مزود، صندوق رملي و سياسة خدمة، هذا خلفية و واحد أداة حزمة:

```yaml
- name: '@deepseek-ai/dsh-terminal'
- name: '@deepseek-ai/dsh-subprocess-local'
- name: '@deepseek-ai/dsh-sandbox-local'
- name: '@deepseek-ai/dsh-sandbox-policy'
- name: '@deepseek-ai/dsh-terminal-bash'
- name: '@deepseek-ai/dsh-tool-terminal'
```

`danger-full-access` مباشر بدء shell. تلقي حد نمط اشتراط نفس تنفيذ عالم حد في وجود `ctx.sandbox` مزود: نقص قليل وقت،spawn سوف في shell بدء قبل فشل. حد دقيق تجهيز مرور مسار استقبال فتح عملية إلغاء إشارة؛ أي جعل مزود قليلا بعد إرجاع، إلغاء ما زال سوف منع توقف طرفية قسم إعداد.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `backendType` | `shell` | تسجيل إلى `ctx.terminals` خلفية نوع |
| `shellDialect` | `bash` | تفاعل صيغة shell مكدس:`bash` أو `pwsh` |
| `shellPath` / `shellArgs` | حسب جهة قول | shell يمكن تنفيذ ملف و معامل؛ لـ فارغ وقت اختيار جهة قول قيمة افتراضية |
| `maxReadBytes` | `262144` | مرة قراءة أو مرة تسوية إرسال إرجاع الأكثر كبير UTF-8 بايت عدد |
| `timeoutMs` | `30000` | مرة إرسال انتظار قطعا مقابل حد أعلى |
| `disposeGraceMs` | `3000` | تنظيف ترقية إلى `SIGKILL` قبل عرض حد وقت |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-terminal-bash) هو كل حقل نفاد كل صيغة حق مصدر، يشمل حينئذ خيط حساب وقت (`pollIntervalMs`،`exactProbeAfterMs`،`idleSilenceMs`،`handoffGraceMs`) ، طرفية مقياس قياس (`rows`،`cols`) و scrollback حد أعلى (`scrollbackLines`،`scrollbackMaxBytes`).

### shell جهة قول و حينئذ خيط

اثنان نوع جهة قول كشف نفسه حينئذ خيط اتفاق، لذلك مستهلك و جهة قول غير متصل. عند shell مجددا مرة حينئذ خيط وقت إرسال أي تسوية: تلقي تحكم تلميح رمز يتم تحقق بعد، قبل منصة عملية مجموعة يتم إثبات في انتظار stdin(Linux) بعد، إخراج ساكن صامت (`inferred_idle`) بعد، أو وصول قطعا مقابل `timeoutMs`.`inferred_idle` أو `timeout` نتيجة و لا إثبات قبل منصة أمر قد خروج.

### صندوق رملي و أمان تشغيل

shell في كامل دورة الحياة داخل تشغيل في صالح صندوق رملي حد لـ تحت. عند كل من ما زال لديه فتح جلسة أو إجراء في spawn وقت، تغيير صالح صندوق رملي نمط سوف يتم رفض——طلب أولا انتظار إنشاء إتمام و إغلاق جلسة، تجنب تجنب بـ أكثر عرض إذن فتح طرفية في إذن تخفيض بعد متابعة وجود. خلفية فقط توفير طرفية مخصص تابع بيئة تغطية؛ مشترك اعتماد تنظيف من عملية فرعية مزود مسؤول.

### يمكن مراقبة نتيجة و فشل

فتح سوف إرجاع جلسة id و محدود بدء رسالة. إرسال بـ أربعة نوع انتظار سبب لـ واحد و واحد جلسة حالة تسوية؛`session_exit` يمثل قمة طبقة shell قد خروج. ضبط فشل سوف رفض فتح: تلقي حد نمط تحت نقص قليل صندوق رملي مزود،shell في بدء خلال خروج،shell لم قدرة في بدء مهلة قبل بلوغ إلى حينئذ خيط، أو استدعاء جهة إلغاء. تنظيف فشل سوف رفض إغلاق، بينما لا هو صوت تسمية نجاح.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية خلف بعد تصميم و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

واحد خلفية خدمة اثنان نوع جهة قول:bash و pwsh مشترك نفس طقم جلسة آلية——تنظيف جهاز، محدود مؤقت اندفاع منطقة، حينئذ خيط جولة استفسار، إلغاء و إغلاق——فقط في argv، بيئة و تلميح رمز تثبيت طريقة فوق مختلف.bash عبر `PS1` إضافة `PROMPT_COMMAND` استقبال خاص علامة.pwsh سوف كتابة تلميح رمز دالة، ثابت UTF-8 تحكم منصة تحرير رمز، و فقط في خلفية تقرير إبلاغ `stdin_read` بعد إصدار بدء؛ عودة إظهار ضبط نص لا يستطيع إصدار shell. واحد لا إبقاء scrollback `@xterm/headless` نسخة سوف إزالة استهلاك أصلي PTY بيانات، و عبر نفس جملة مقبض إرجاع طرفية بروتوكول استجابة؛ تدريجي سطر sanitizer ما زال هو وحيد إخراج إسقاط.

Scrollback و بعد لم قراءة إرسال إخراج إبقاء مستقل يملك نص، و زيادة كمية صيانة بايت عدد و تبديل سطر رمز عدد، لذلك تنظيف بعد مقتطعة لن إبقاء قد إسقاط تحكم تسلسل. إلحاق و تصفية استبعاد نص توزيع أيضا استهلاك وقت و إدخال نص كمية صار صحيح مقارنة؛ قراءة وقت عندئذ تجميع وصل إبقاء قسم قطعة. إبقاء سياسة صيانة حمل رمز نقطة حد، و سوف نهاية ذيل تبديل سطر رمز بعد فارغ سطر حساب دخول سطر عدد.[إبقاء سياسة قرار](../../../.agents/notes/implemented/bug-fix/2026-09-11-incremental-terminal-retention.ar.md) سجل تكرار مختلط درجة و قياس كمية اعتماد حسب.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | خلفية تسجيل، صندوق رملي نمط حد،argv و بيئة تجميع، بدء تسلسل |
| [`src/config.ts`](src/config.ts) | جهة قول تحليل، قيمة افتراضية و كل حساب وقت حقل تحقق |
| [`src/session.ts`](src/session.ts) | `LocalPtySession`: إرسال دورة الحياة، حينئذ خيط جولة استفسار،scrollback، إشارة، إغلاق |
| [`src/sanitize.ts`](src/sanitize.ts) | تدفق صيغة تحكم تسلسل تنظيف جهاز و سطر مواصفة تحويل |

### حينئذ خيط نموذج

ثلاثة عدد محدود ملف موضع تسوية مرة إرسال: قدوم ذاتي عملية فرعية مزود دقيق stdin انتظار دليل (فقط Linux) ، حمل دقيق يمكن ضرب طبع ذيل جزء تلقي تحكم خاص تلميح رمز علامة، و إخراج ساكن صامت (`inferred_idle`) ؛ قطعا مقابل مهلة بداية نهاية حد انتظار.pwsh بدء كامل ضبط حلقة مشترك استخدام نفس عدد قطع توقف وقت، لذلك `inferred_idle` لاحق إرسال لن إعادة حساب وقت. مزود كتابة قبل استلام تجميع دليل سوف في كتابة حد إسقاط، مبكر في كتابة stdin انتظار لا حساب كتابة بعد حينئذ خيط، لم معرفة قبل منصة حالة أبدا هو دقيق فارغ خامل صحيح نحو إشارة.

### إرسال إلغاء و إغلاق

إلغاء أولا يأخذ ترتيب طابور إدخال علامة لـ قد إلغاء، مجددا في أي في طريق مزود كتابة تسوية بعد نحو حالي قبل منصة عملية مجموعة إرسال حق صحيح `SIGINT`؛ هو أبدا سوف عبر كتابة `\x03` نموذج محاكاة في قطع. إغلاق سوف إيقاف حينئذ خيط جولة استفسار، إنهاء مزود يملك عملية شجرة، انتظار تماما توقف مستقر، و يأخذ نشط وثب إرسال تسوية لـ `session_exit`.

### صندوق رملي نمط حد

عند كل من وجود فتح جلسة أو إجراء في spawn وقت، كل هو سوف تغيير صالح صندوق رملي نمط كتابة كل سوف في `sandbox/mode` حدث إيداع قبل يتم رفض. هذا حد ربط إلى تأكيد قطع كل من، و في إبقاء قائم جلسة مزود إعادة تحميل بعد اعتماد لكن صالح.

<a id="model-experience"></a>
## تجربة النموذج

### بين وصل مستهلك

#### نموذج يرى ماذا

هذا حزمة لا تسجيل نص التوجيه أو أداة. نموذج عبر `@deepseek-ai/dsh-tool-terminal` أو أخرى PTY مستهلك ممكن استلام إلى محدود بدء إخراج، إرسال زيادة كمية،scrollback صفحة، حينئذ خيط سبب و تنظيف خطأ.

#### Token أثر

في مستهلك إرجاع محدود إخراج قبل، إبقاء PTY scrollback لن دخول نموذج تاريخ.

#### KV Cache أثر

لن مباشر بطلان؛ مستهلك نتيجة إبقاء فقط إلحاق.

### صندوق رملي سياسة سياق

#### نموذج يرى ماذا

تركيب هذا خلفية خلال،`sandbox-policy` ملكية جهة سوف نحو نص التوجيه مساهمة و أداة جسم قدرة غير متصل `sandbox:policy` وقت التشغيل سياق فرعي جملة.

#### Token أثر

خلفية تركيب خلال، طلب في سوف يتضمن هذا سياسة فرعي جملة.

#### KV Cache أثر

معتاد إقامة سياسة حدوث تغير وقت، سوف في إبقاء تاريخ بعد إلحاق واحد نسخة يحل محل أولا قبل حالة وقت التشغيل سياق لقطة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح خلفية أي وقت لا دمج ملائم أو حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام shell مقابل مقارنة أو مهمة تراكم ضغط.

- **فقط تدريجي سطر إخراج**——headless xterm فقط لـ طرفية بروتوكول استجابة صيانة تحكم تسلسل حالة. إرجاع إخراج ما زال حسب سطر مواصفة تحويل؛ لا دعم حمل كل شاشة تجهيز استخدام مؤقت اندفاع منطقة تفاعل.
- **لا يوجد دقيق ملف وقت، حينئذ خيط هو بدء إرسال صيغة**——دقيق stdin انتظار فحص قياس أخذ قرار في قد تركيب عملية فرعية مزود؛ لا يمكن إثبات هذا حالة مزود (macOS،Windows) حسب تلميح رمز علامة و ساكن صامت/مهلة حينئذ خيط تسوية.
- **تلقي حد صندوق رملي في pwsh جذب توجيه**——تلميح رمز دالة و UTF-8 تحرير رمز ثابت عملية عبر `[Console]::` كتابة،Windows ACL صندوق رملي فقط قراءة نمط ممكن رفض. إذا لذلك لا يمكن نيل نيل علامة حينئذ خيط حالة، بدء سوف في `timeoutMs` إلى مدة وقت رفض، بينما لن إصدار لا كامل shell.
- **تنظيف حفظ إثبات يخص مزود**——عملية شجرة تنظيف هو `SubprocessTerminalHandle` اتفاق، بينما لا هو هذا خلفية.
- **جلسة لا مع عملية خروج تخزين نشط**——harness إعادة بدء سوف إلغاء تدمير كل جلسة.
