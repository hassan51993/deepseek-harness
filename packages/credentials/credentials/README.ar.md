# @deepseek-ai/dsh-credentials

[English](README.md) | العربية

## عام وصف

`dsh-credentials` عبر يجعل settings و `cordis.yml` مرجع `DEEPSEEK_API_KEY` انتظار مفتاح اسم، جعل آلة سري قيمة إبقاء في إعداد خارج. هو أيضا تخزين حفظ دائم حسب إضافة مجموعة نسج اعتماد سجل، يشمل تخويل grant و مزود بيئة قيمة. جولة تبديل بعد قد تخزين مفتاح سوف أثر في تحت مرة طلب، بلا حاجة إعادة بدء أو تعديل إعداد. إعداد واجهة يمكن تقرير إبلاغ مفتاح أو سجل هل قد ضبط، قدوم ذاتي أي داخل و قدرة لا كتابة، بينما لن كشف قيمة. فارغ مفتاح قيمة نظر لـ لا وجود، بينما فارغ سجل ما زال يمثل واحد بند متعمد تخزين اعتماد.

## استخدام هذه الحزمة

هذه الحزمة هو منتج في مسؤول تخزين و استعلام آلة سري قيمة جزء: مفتاح فقط تخزين مرة، موضع موضع حسب اسم مرجع، و يمكن في مهمة معنى وقت لحظة قراءة، فحص أو إزالة. هو أيضا حفظ حفظ دائم اعتماد سجل، يجعل إضافة يمكن لـ ذاته id تخزين، تحديث أو إزالة هو يحتفظ اعتماد. منتج افتراضي تركيب قد يتضمن اعتماد تخزين؛ ذاتي تعريف تركيب فقط يحتاج تحميل محلي تخزين حزمة و إعطاء خروج ملف مسار.

### أي وقت استخدام

فقط يلزم إعداد حاجة و آلة سري قيمة قطعا حافة، حينئذ استخدام اعتماد تخزين: حاجة تزامن، مشترك أو تصيير دخول إعداد واجهة ضبط ملف، أو أمل نظر في لا تعديل إعداد حال حال تحت جولة تبديل مفتاح مجموعة طابور. عند إضافة يجب حفظ لا يوجد مفرد واحد بيئة متغير اعتماد——تسجيل تسجيل مسار إنتاج تخويل grant، أو مزود بيئة قيمة——و أمل نظر إعداد واجهة قدرة صف خروج مستخدم نيل نيل أي بعض تخويل وقت، طلب استخدام سجل. إعداد واجهة قدرة عرض بعض عدد مفتاح أو سجل هل قد ضبط، قدوم ذاتي أي داخل، قدرة لا تعديل——لكن أبدا عرض قيمة ذاته. إذا فقط حاجة واحد ثابت بيئة متغير، مباشر قراءة هذا متغير يكفي، بلا حاجة تخزين.

### إضافة دخول أنت تركيب

تحميل محلي تخزين حزمة و إعطاء خروج وثيقة مسار:

```yaml
- name: '@deepseek-ai/dsh-credentials-local'
  config:
    path: /absolute/path/to/.credentials.yaml
```

محلي تخزين README يملك كامل إعداد وجه؛ توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-credentials-local) هو نفاد كل صيغة حقل بيان.

### تخزين، فحص و إزالة مفتاح

```ts
import type { Context } from '@deepseek-ai/cordis'
import { credentialRef } from '@deepseek-ai/dsh-credentials'

declare const ctx: Context

const ref = credentialRef('DEEPSEEK_API_KEY')          // POSIX shell identifier, branded
const hit = await ctx.credentials.resolve(ref)         // { value, source } | undefined
const info = await ctx.credentials.describe(ref)       // { configured, source?, writable } — never the value
await ctx.credentials.set(ref, 'sk-…')                 // rejects while a read-only source shadows the ref
await ctx.credentials.unset(ref)                       // no-op when absent; same shadowing rule
```

استخدام `set` تخزين مفتاح، استخدام `unset` إزالة، استخدام `describe` فحص حالة، في عملية حاجة وقت استخدام `resolve` قراءة حالي قيمة.`describe` تقرير إبلاغ مفتاح هل قد ضبط، قدوم ذاتي أي داخل، قدرة لا كتابة——هو أبدا قيمة راجعة.

### تخزين، تحديث و إزالة سجل

إضافة حسب `<scope>/<id>` بحث عنوان كل بند سجل——ذاته تسجيل اسم إضافة واحد ذاتي اختيار id، مثال مثل مزود توجيه مفتاح——و قراءة، تعديل أو إزالة هو الذي يحتفظ محتوى:

```ts
import type { Context } from '@deepseek-ai/cordis'
import { credentialKey } from '@deepseek-ai/dsh-credentials'

declare const ctx: Context

const key = credentialKey('llm-pi-ai', 'openai-codex')   // <owner>/<id>, branded
const hit = await ctx.credentials.readRecord(key)        // CredentialRecord | undefined
await ctx.credentials.describeRecord(key)                // { configured, kind?, writable } — never the value
await ctx.credentials.listRecords()                      // [{ key, kind }] — never values
await ctx.credentials.modifyRecord(key, async () => ({ kind: 'grant', payload: { token: '…' } }))
await ctx.credentials.deleteRecord(key)                  // no-op when absent
```

`modifyRecord` هو وحيد كتابة مسار: هو يجعل أنت تغيير دالة يرى كتابة أخذ نيل وحيد احتلال ذلك واحد لحظة سجل، إرجاع `undefined` فإن إبقاء أصل حالة. سجل لا يوجد فارغ قيمة قاعدة——واحد بند حيث بلا key أيضا بلا بيئة قيمة سجل، قديم وصف هو ذلك يملك من تأكيد ambient إقرار إثبات——إعداد واجهة أيضا يمكن قطعة رفع كل بند سجل، عرض أنت نيل نيل أي بعض تخويل، و بحث خروج قد إزالة إضافة إبقاء تحت سجل.

### في إعداد في استخدام مفتاح

settings قسم عقدة أو `cordis.yml` بند حسب اسم مرجع مفتاح، بينما لا هو يتضمن مفتاح ذاته——مثال مثل LLM(كبير لغة نموذج) مهايئ قبول `apiKeyEnv`:

```yaml
apiKeyEnv: DEEPSEEK_API_KEY
```

حاجة هذا مفتاح طلب استخدام هو حالي تخزين قيمة، لذلك جولة تبديل مفتاح سوف أثر في ضيق مع ذلك بعد تحت مرة طلب——بلا حاجة إعادة بدء، بلا حاجة تعديل إعداد.

### ممكن خروج خطأ أرض جهة

- **بدء بيئة توفير مفتاح لا يمكن يتم تغطية**——`DEEPSEEK_API_KEY=… dsh`(أو CI آلة سري، حاوية `-e`) في هذا جولة تشغيل في أولوية، و يتم تقرير إبلاغ لـ فقط قراءة؛ طلب أولا في بدء shell في صاف حذف هذا متغير، مجددا تخزين أخرى قيمة.
- **فارغ قيمة لا يمكن تخزين**——تخزين فارغ نص سوف يتم رفض؛ طلب تعديل لـ إزالة مفتاح.
- **مفتاح قيمة أبدا سوف ظهور في إعداد واجهة أو تشخيص معلومة في**——واجهة فقط عرض مفتاح هل قد ضبط، قدوم ذاتي أي داخل، قدرة لا تعديل؛ قيمة ذاته إبقاء في تخزين في.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذه الحزمة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

واحد بند دقيق فإن، أربعة عدد دفع نقاش:

- **إعداد فقط يحمل مرجع، أبدا يحمل آلة سري.** settings قسم عقدة أو `cordis.yml` بند نقطة اسم واحد اعتماد؛ مرجع خلف بعد قيمة تخزين وضع في مزود موضع. ضبط وثيقة يمكن وضع قلب تزامن، وضع قلب تصيير،`describe()` بلا حاجة يحتفظ قيمة حينئذ قدرة عودة جواب، جولة تبديل آلة سري لا لمس اصطدام أي ملف إعداد.
- **مستهلك حسب عملية تحليل.** تحليل هو مرة حسب استدعاء قراءة، بلا عبر عملية ذاكرة مؤقتة؛ هذا مرة قراءة صحيح هو حار تحديث آلية.
- **فارغ تخزين قيمة انتظار في لا وجود.** `resolve` قفز مرور هو،`describe` تقرير إبلاغ لم إعداد——فارغ أبيض دائم بعيد لن زائف تركيب صار قد إعداد آلة سري.
- **سجل هو حفظ دائم، وجود أي واقع.** سجل حسب `<scope>/<id>` تخزين و عبر إعادة بدء إبقاء؛ فارغ قيمة قاعدة لا ملائم استخدام، لذلك واحد بند حيث بلا key أيضا بلا بيئة قيمة `api-key` سجل هو متعمد قديم وصف، بينما لا هو فارغ أبيض.
- **مستمع فشل تلقي إلى عزل.** `notifyUpdated` مروحة خروج `credentials/reference-updated`، حفظ إثبات كل مستمع كل سوف تشغيل؛ تزامن رمي خروج و مختلف خطوة رفض كل سوف يتم سجل، لا تغيير قد إيداع عملية نتيجة،`INVARIANT` تحرير رمز فشل حذف خارج——هو جمع في كل مستمع تشغيل تمام انتهاء بعد إعادة رمي خروج.

### credentials/reference-updated حدث

`credentials/reference-updated (ref)` في مزود إدارة مصدر حدوث قد إيداع تغيير بعد إطلاق——`set`،`unset` أو في تخزين في مراقبة إلى خارجي تحرير. عملية بيئة متغير تغير غير ممكن مراقبة قياس، دائم لا إطلاق. مستهلك لا حاجة هذا حدث (هو جمع حسب عملية إعادة تحليل) ؛ هو خدمة في إعداد واجهة تحديث جديد «قد إعداد» شعار علامة.

`credentials/record-updated (key)` في تخزين سجل حدوث قد إيداع تغيير بعد إطلاق——مرة تأكيد فعلي كتابة `modifyRecord`، مرة تأكيد فعلي إزالة `deleteRecord`، أو في تخزين في مراقبة إلى خارجي تحرير. هو إبقاء مستقل حدث، لأن اثنان عدد مفتاح نص قاعدة متبادل رفض: واحد مستمع إذا في نفس حدث فوق معا استلام إلى اثنان عدد فضاء، سوف لا يمكن قسم تمييز رئيسي جسم يخص أي واحد حافة.

### سجل كتابة و قراءة مسار

`modifyRecord` هو وحيد كتابة مسار، لأن صحيح تأكيد كتابة اعتماد حالي قيمة: تحديث جديد token هو «قراءة—قرار—استبدال» ، تغيير دالة يرى هو كتابة أخذ نيل وحيد احتلال ذلك واحد لحظة سجل——إرجاع `undefined` فإن إبقاء أصل حالة. وحيد احتلال في دعم حمل هو قاع طبقة تخزين فوق عبر عملية صار قيام، هذا صحيح هو منع توقف اثنان عدد عملية معا جولة تبديل واحد refresh token، فقد إسقاط أولا كتابة ذلك واحد آلية. قراءة و مرجع واحد جانب مقابل تسمية، لكن أبدا قسم طبقة: لا يوجد أي شرق غرب قدرة حجب حجب سجل،`grant` payload سوف أصل مثال إرجاع إعطاء ذلك يملك من، لأن فقط لديه يملك هو إضافة قدرة حل تفسير هو.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | Service Definition:`credentialRef`/`credentialKey` صنف لوحة،`ResolvedCredential`/`CredentialRecordInfo`، تغطية اثنان عدد مفتاح فضاء سحب كائن مزود، حمل فشل عزل مروحة خروج |
| [`src/types.ts`](src/types.ts) | عميل أمان نوع وجه:`CredentialRef` و `CredentialKey` صنف لوحة، تخزين سجل ربط دمج نوع،`CredentialInfo` مرجع عرض،`credentials/reference-updated` و `credentials/record-updated` حدث إعلان |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة:`credentials/reference-updated` فقط في اعتماد خدمة تخزين نشط وقت إطلاق |

### عميل أمان نوع

`./types` فرعي مسار خروج فتحة يأخذ حدث إعلان و ذلك نقطة اسم `CredentialRef`،`CredentialKey` صنف لوحة، تخزين سجل ربط دمج نوع، و إعداد واجهة قراءة `CredentialInfo` مرجع عرض وضع في واحد بدء، حزمة أصل متابعة re-export هو جمع. في هو Host تحرير ترجمة وجه خارج مستهلك قراءة إلى صحيح هو Host إرسال إطلاق ذلك واحد نسخة توقيع، بينما لا لا بد مجددا كتابة واحد مرة.

### دورة الحياة

خدمة هو مزود تسجيل Cordis `Service`: تحرير تركيب fiber سوف إزالة `ctx.credentials`. ثابت صيغة مرافق توليد إضافة فحص `credentials/reference-updated` أبدا في خدمة لم تخزين نشط وقت إطلاق——تحرير بعد ما زال لديه إرسال إطلاق معنى طعم حال مزود يأخذ عمل تسرب تسرب إلى teardown تماما توقف مستقر بعد.

- [قدرة seam](../../../docs/capability-seams.ar.md)——هذه الحزمة التزام دوران Service Definition / Service Provider / Consumer تفكيك قسم.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه الحزمة أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **مرجع لا توفير قطعة رفع**——seam فقط عودة جواب يتم سؤال إلى مرجع؛ إعداد واجهة من settings schema نيل معرفة مرجع تجميع دمج، مقابل هذا واحد نصف فعل `list()` لا يوجد حالي مستهلك. سجل فإن يمكن قطعة رفع، لأن لا يوجد متاح في اكتشاف سجل schema.
- **مرجع حد تحديد لـ بيئة متغير شكل حالة**——مفرد واحد مسطح مستو POSIX معرف رمز نطاق الأسماء، لأن مرجع معا حينئذ هو هو استعارة بـ تحليل بيئة متغير اسم. سجل استخدام أكثر وفير غني `<owner>/<id>` بحث عنوان.
- **عملية بيئة تغير غير ممكن رؤية**——لا يمكن لـ بدء shell في تغيير متغير إرسال خروج إشعار؛ واجهة فقط قدرة في ذاته تنقل وقت إعادة قراءة `describe()`.
- **سجل يملك من حينئذ هو هو scope، بينما لا يوجد أي حلقة عقدة نواة تحقق هذا scope هل قد تركيب**——seam تخزين تحت يتم تسليم إعطاء محتوى، و تقرير إبلاغ هو تخزين ماذا؛ تعرف آخر متروك إبقاء سجل حاجة استدعاء جهة سوف `listRecords()` نتيجة و يملك هذا scope سجل التسجيل صلة ربط بدء قدوم،seam ذاته لا يوجد يمكن توفير نواة مقابل سجل التسجيل.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

هذا seam واجهة لـ keyring، مساعد مساعدة أمر و KMS خلفية مزود مسبق إبقاء توسيع فضاء؛ بعيد طرف ضبط مزود دائم بعيد لا لا بد يحمل آلة سري. هدف قبل لا يوجد أي واحد نوع مع مرفق، أيضا لا يوجد حالي مستهلك حاجة هو جمع.

</details>
