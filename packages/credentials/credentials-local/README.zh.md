# @deepseek-ai/dsh-credentials-local

[English](README.md) | العربية

## عام وصف

`dsh-credentials-local` يأخذ API مفتاح و أخرى آلة سري حفظ في harness home تحت خاص ملف في. أنت يمكن عبر إعداد واجهة حفظ اعتماد، أيضا يمكن مباشر تحرير ملف؛ تغيير سوف تلقائي إعادة تحميل، حفظ قيمة أيضا سوف عبر إعادة بدء إبقاء. اعتماد فحص بحث اعتماد ثابت أولوية درجة: بدء بيئة أولوية، ذلك مرة هو تخزين ملف، مشروع `.env` و harness home `.env`؛ جديد حفظ قيمة سوف قيام أي تغطية `.env` في قديم قيمة. فقط لديه أنت OS مستخدم قدرة قراءة هذا ملف، لكن agent(ذكي جسم) أداة عملية بـ نفس مستخدم هوية تشغيل، لذلك هذا تخزين لا يمكن نحو agent عزل آلة سري.

## استخدام هذه الحزمة

هذه الحزمة لـ تركيب توفير محلي اعتماد تخزين:API مفتاح و أخرى آلة سري فقط يحتاج حفظ مرة، بعد كل حسب اسم مرجع هو جمع طلب كل سوف استخدام إلى. معتاد استخدام مسار هو صريح: تحميل تخزين، عبر إعداد واجهة أو `ctx.credentials` حفظ مفتاح، لكن بعد في حاجة وقت من منتج تحليل.

### أي وقت استخدام

يأخذ هو بصفة افتراضي محلي تخزين: منتج أساس أساس تركيب سوف تحميل هو، أنت عبر إعداد واجهة حفظ مفتاح سوف قيام أي توليد فاعلية. عند نشر يجب يجعل مزود مفتاح بعيد مغادرة ذاته agent وقت اختيار أخرى تخزين——ملف إذن فعل لا إلى هذا واحد نقطة، لأن agent أداة عملية بـ أنت OS مستخدم هوية تشغيل (رؤية «من قدرة قراءة هذا ملف»).

### ضبط

```yaml
- name: '@deepseek-ai/dsh-credentials-local'
  config:
    path: /absolute/path/to/.credentials.yaml
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `path` | `<harness home>/.credentials.yaml` | اعتماد ملف الذي في موضع |
| `dshHome` | `$DSH_HOME` أو `~/.dsh` | `path` نقص حذف وقت استخدام harness home |
| `watch` | `true` | ملف في مغناطيس قرص فوق تغير وقت تلقائي إعادة تحميل |
| `debounceMs` | `100` | تغير بعد انتظار هذا ما دائم مجددا إعادة تحميل، مفرد موضع لـ جزء ثانية |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-credentials-local) كامل صف خروج كل تلقي دعم حمل حقل و ذلك JSDoc، هو هذه معلومة حق مصدر.

### تخزين و إزالة مفتاح

استخدام `set` حفظ مفتاح، استخدام `unset` إزالة، استخدام `describe` فحص مفتاح هل قد إعداد——و اعتماد API توفير عملية نفسه:

```ts
import type { Context } from '@deepseek-ai/cordis'
import { credentialRef } from '@deepseek-ai/dsh-credentials'

declare const ctx: Context

const ref = credentialRef('DEEPSEEK_API_KEY')
await ctx.credentials.set(ref, 'sk-…')          // save
await ctx.credentials.describe(ref)             // { configured, source?, writable } — never the value
await ctx.credentials.unset(ref)                // remove
```

أنت حفظ مفتاح سوف يتم تحت واحد حسب اسم مرجع هو طلب استخدام؛`describe` تقرير إبلاغ هو هل قد ضبط، قدوم ذاتي أي داخل، قدرة لا كتابة——أبدا قيمة راجعة ذاته. سجل أيضا حفظ دائم في نفس ملف في: إضافة حسب `<owner>/<id>` بحث عنوان واحد بند سجل، و استخدام seam سجل عملية (`readRecord`،`describeRecord`،`listRecords`،`modifyRecord`،`deleteRecord`) إدارة هو.

### مفتاح من أي داخل قدوم

مفتاح حسب واحد ثابت ترتيب تحليل——أولا لديه قيمة موضع فوز خروج:

| موضع | يمكن كتابة؟ | أولوية في |
|---|---|---|
| أنت بدء وقت بيئة (`DEEPSEEK_API_KEY=… dsh`) | لا | واحد قطع |
| تخزين ملف | هو (`set`/`unset`) | اثنان عدد `.env` ملف |
| مشروع `.env`(`<invocation cwd>/.env`) | لا في هذا موضع | رئيسي دليل `.env` |
| رئيسي دليل `.env`(`$DSH_HOME/.env`) | لا في هذا موضع | بلا |

بدء بيئة أولوية، لأن حسب مرة تغطية——`DEEPSEEK_API_KEY=… dsh`،CI آلة سري، حاوية `-e`——بديل جدول هذا مرة تشغيل واضح معنى رسم؛ هو لا يمكن من منتج داخلي تعديل، لذلك يتم تقرير إبلاغ لـ فقط قراءة، كتابة سوف يتم رفض. أخرى واحد قطع مصدر كل نقل إعطاء تخزين ملف، هذا صحيح هو أنت حفظ مفتاح سوف قيام أي توليد فاعلية سبب، أي جعل بعض عدد `.env` داخل أيضا إبقاء حال أكثر قديم مفتاح؛ لا يوجد تخزين أي شرق غرب وقت، ذلك اثنان عدد `.env` طبقة سوف مشاركة و تحليل. بيئة طبقة هو بدء وقت التقاط التقاط بدء جهاز[بيئة لقطة](../../util/launch-environment/README.zh.md) ، لذلك بدء بعد عندئذ توجيه خروج متغير لن يتم يرى.

### اعتماد ملف ذاته

حمل إصدار YAML وثيقة، كل مفتاح فضاء واحد قسم عقدة، حذف هذا خارج آخر بلا هو شيء:

```yaml
version: 1

refs:
  DEEPSEEK_API_KEY: sk-…
  OPENAI_API_KEY: sk-…

records:
  llm-pi-ai/openai-codex:
    kind: grant
    payload:                    # written verbatim; this provider does not interpret it
      type: oauth
      access: eyJhbGciOi…
      refresh: rft_9f8e7d…
      expires: 1786000000000
  llm-pi-ai/amazon-bedrock:
    kind: api-key               # environment values, no key: this route uses an AWS profile
    env:
      AWS_PROFILE: prod
  llm-pi-ai/amazon-bedrock-dev:
    kind: api-key               # neither: the owner confirmed the ambient credential chain
```

أنت يمكن مباشر تحرير هذا ملف——تخزين سوف تلقائي إعادة تحميل و استقبال تغيير، يشمل أنت حذف مفتاح أو سجل.`refs` حسب بيئة متغير اسم تخزين وضع مفتاح قيمة؛`records` حسب `<owner>/<id>` تخزين وضع كل إضافة اعتماد، كل بند كل حمل `api-key` أو `grant` وسم، منها grant payload من تخزين تدريجي حرف إبقاء، لأن فقط لديه هو يملك من قدرة حل تفسير. منتج كتابة وقت سوف إبقاء ملاحظة تفسير و لم لمس و بند ترتيب إصدار؛ مباشر يقع في بعض بند فوق جهة ملاحظة تفسير يخص هذا بند ملاحظة حل، سوف مع هو واحد بدء حذف. ملف فقط تخزين وضع اعتماد، لذلك أي أخرى محتوى كل سوف يتم واضح رفض، بينما لا هو يتم ساكن صامت تجاهل اختصار: غير mapping أصل، لم معرفة قمة طبقة مفتاح، في ذلك مفتاح فضاء داخل غير ممكن بحث عنوان مفتاح، نوع خطأ أو فارغ قيمة، لم معرفة سجل وسم أو حقل، تكرار مفتاح و صيغة خطأ YAML كل سوف في بدء وقت فشل؛ تشغيل مدة حار إعادة تحميل وقت فإن إبقاء الأكثر بعد متاح محتوى و إبلاغ تحذير.

مفتاح قيمة يمكن هو مهمة معنى نص، يشمل كثير سطر قيمة——لا حاجة أي جذب رقم تقنية بارع. فارغ قيمة انتظار في «لا يوجد مفتاح» ، هذا صحيح هو ملف في فارغ نص يتم رفض سبب: إزالة مفتاح هو حذف هو، بينما لا هو يأخذ هو وضع فارغ.`grant` payload يجب مرور تلقي JSON نحو إرجاع، دخول خروج اثنان عدد جهة نحو كل سوف قوي صنع هذا واحد نقطة، لذلك تخزين سوف رفض لا يمكن تدريجي حرف قراءة عودة قيمة. إذا مغناطيس قرص فوق ملف قد لا يمكن تحليل، حفظ سوف فشل، بينما لا هو تغطية منتج قراءة لا فهم محتوى.

### من قدرة قراءة هذا ملف

فقط لديه أنت OS مستخدم قدرة قراءة هذا ملف: منتج بـ فقط تابع رئيسي يمكن وصول إذن إنشاء هو، في POSIX فوق أيضا سوف رفض تحميل أي أخرى مستخدم يمكن قراءة ملف——خطأ سوف تلميح أنت تشغيل `chmod 600`.Windows لا يوجد يمكن فحص mode، لذلك في ذلك داخل قفز مرور هذا فحص بينما لا هو زائف صنع هو.agent لا هو آخر عدد مستخدم: هو أداة عملية بـ أنت هوية تشغيل، لذلك هو جمع قراءة هذا عدد ملف و قراءة أنت يملك أي أخرى ملف جزء بلا اثنان يؤدي. منتج أبدا يأخذ ملف مسار تسليم إعطاء agent، أيضا أبدا يأخذ ملف تحميل دخول بيئة، لذلك يلزم أخذ إلى بعض عدد قيمة، حاجة لحظة معنى ذهاب قراءة واحد بند و لم تسليم إعطاء agent مسار. هذا هو مراجعة حذر، لا هو حد: يجب يجعل مزود مفتاح بعيد مغادرة ذاته agent نشر لا يمكن اعتماد ملف إذن فعل إلى.

### ممكن خروج خطأ أرض جهة

- **بدء بيئة توفير مفتاح هو فقط قراءة**——`DEEPSEEK_API_KEY=… dsh` في هذا جولة تشغيل في أولوية، حفظ أو إزالة هو كل سوف يتم رفض. طلب أولا في بدء shell في صاف حذف هذا متغير.
- **فارغ قيمة لا يمكن حفظ**——تخزين فارغ نص سوف يتم رفض؛ طلب تعديل لـ إزالة مفتاح.
- **تخزين رفض تحميل هو لا يمكن معلومة مهمة ملف**——أي أخرى مستخدم يمكن قراءة ملف، صيغة خطأ YAML أو لا يمكن وصول مسار كل سوف في بدء وقت فشل؛ تشغيل مدة حار إعادة تحميل فإن إبقاء الأكثر بعد متاح محتوى و إبلاغ تحذير.
- **نفس وقت لحظة تعديل كل سوف يتم إبقاء**——إذا أنت في منتج كتابة معا تحرير ملف، أنت تغيير سوف يتم و دخول، بينما لا هو يتم تغطية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مزود خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **واحد طقم واضح أولوية درجة.** وراثة بيئة أولوية، لأن هو هو هذا مرة تشغيل واضح معنى رسم كما لا يمكن من عملية داخلي تعديل؛ هو لـ تحت كل مصدر كل نقل إعطاء تلقي إدارة تخزين، لذلك قد تخزين مفتاح دائم بعيد لن يتم قديم قديم `.env` ضغط إسقاط.
- **وثيقة فقط تخزين وضع اعتماد.** هو هو حمل `refs` و `records` قسم عقدة إصدار تحويل وثيقة، بينما لا هو dotenv ملف: واحد harness يملك، كما أبدا شيء تحويل دخول بيئة تخزين، لا يستطيع معا ملء عند مستخدم بيئة طبقة، لا فإن سوف بـ ذاتي ذات أولوية درجة حجب حجب غير آلة سري بند.
- **كتابة ضرب رقعة، إعادة تحميل كامل جسم استبدال.** سطر تحرير في عبر عملية كتابة قفل تحت إبقاء ملاحظة تفسير و لم لمس و بند؛ إعادة تحميل كامل جسم تسليم تبديل تحليل بعد لقطة، قد حذف بند أبدا في داخل تخزين ركود إبقاء.
- **معلومة مهمة متصل صلة موضع واضح تقرير خطأ.** بدء و إعادة تحميل كل سوف رفض غير ممكن قراءة، بلا فاعلية أو يمكن يتم تابع رئيسي خارج قراءة وثيقة؛ تشغيل مدة إعادة تحميل فشل وقت سوف إبقاء الأكثر بعد متاح لقطة و إبلاغ تحذير، بينما لا هو سحب انهيار عملية.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | مزود: طبقة تحليل، صارم إطار وثيقة تحليل، كتابة قفل تحت مرجع و سجل كتابة مسار،watcher دورة الحياة، إذن فحص |
| — | لم إصدار وقت التشغيل ثابت صيغة إعداد طقم مدخل؛Service Definition إعداد طقم مدخل (`dsh-credentials/invariant`) مسؤول `credentials/reference-updated` دورة الحياة اتفاق؛ هذا مزود ملف و بيئة قسم طبقة يخص مختلف خطوة I/O، و من ذلك اختبار وحدة طقم عنصر إضافة بـ قيد. |

### تحليل و كتابة مسار

`resolve` و `describe` حسب أولوية درجة ترتيب قراءة وراثة بيئة لقطة، قد تحليل وثيقة لقطة و `.env` بعد تجهيز طبقة.`set`/`unset` ترتيب دخول نفس بند وحيد احتلال عملية سلسلة: مدخل فحص رفع قبل رفض (قد تحرير، فارغ قيمة، يتم بيئة حجب حجب) ، طابور صف في وقت التشغيل سوف إعادة حكم تحديد، مع بعد في كتابة قفل تحت تنفيذ قراءة-تعديل-كتابة، إيداع، و تماما جيد إطلاق مرة `credentials/reference-updated`.

`modifyRecord` مشي نفس بند سلسلة و نفس يأخذ قفل: هو إعادة قراءة وثيقة، يأخذ حالي سجل تسليم إعطاء تغيير دالة، دقيق دخول ذلك نتيجة——غير فارغ API مفتاح، قدرة مرور تلقي JSON نحو إرجاع grant payload——كامل جسم تصيير هذا سجل و إيداع، تماما جيد إطلاق مرة `credentials/record-updated`. و غير من منتج CLI(أمر سطر واجهة) بدء تركيب فقط لديه وراثة بيئة هذا واحد طبقة.

### إعادة تحميل دورة الحياة

watcher حدث أو حينئذ خيط وقت مقابل حساب سوف سوف مرة تحديث جديد ترتيب إلى نفس سلسلة بند بعد.`reconcileFromDisk` إعادة فحص إذن، إعادة قراءة نص، نص لديه فرق مختلف وقت كامل جسم استبدال اثنان عدد لقطة، و حسب تغيير مرجع أو سجل تدريجي عدد إصدار حدث؛ و نص ذاكرة مؤقتة متسق محتوى——يشمل مزود ذاتي ذات كتابة——هو no-op. تحرير وقت ضبط إغلاق علامة سجل، إيقاف استقبال حدث، إغلاق watcher، و انتظار ترتيب طابور عملية تسوية تمام انتهاء، تأكيد حفظ مورد إلغاء تدمير بعد لم يعد إصدار أي حدث.

### وثيقة إصدار تحويل

وثيقة يحمل `version: 1`، كل مرة كتابة كل سوف غطاء فوق إصدار ختم. بدء وقت إذا تعرف آخر خروج مسبق إصدار مسطح مستو تخطيط——لا يوجد `version` عار مرجع اسم mapping——سوف في كتابة قفل تحت حينئذ أرض ترقية، يأخذ أصلي سطر تضمين طقم إلى `refs:` لـ تحت، قيمة، ملاحظة تفسير و تجميع كتابة تدريجي بايت إبقاء؛ أي أخرى بلا إصدار شكل كل سوف حسب اسم رفض، بينما لن يتم عند عمل فارغ تخزين. تشغيل مدة حار إعادة تحميل أبدا ترحيل: في طريق استعادة مسطح مستو وثيقة سوف إبقاء الأكثر بعد متاح لقطة، مباشر إلى تحت مرة بدء.

### تشخيص معلومة أبدا مرجع قيمة

YAML محلل ذاتي ذات رسالة سوف مرجع خروج خطأ ذلك سطر شفرة المصدر، بينما في هذا نسخة وثيقة داخل ذلك سطر حينئذ هو آلة سري ذاته. لذلك كل بند تشخيص فقط يحمل رمز خطأ و موضع——مفتاح اسم يمكن أمان ضرب طبع، قيمة لا سطر.

## بحث إضافي

عند مزود درجة اتفاق لا كاف استخدام وقت قراءة قراءة التالي صفحة. هو جمع من seam اتفاق تدريجي خطوة دخول بيئة لقطة، أصل فرعي كتابة أصل لغة و بدء مدة بيئة طبقة.

- [اعتماد مرجع seam](../credentials/README.zh.md)——`resolve`،`describe`،`set`،`unset`، سجل عملية و seam تحديث حدث.
- [اعتماد فرعي نظام مشاركة اعتبار](../../../docs/subsystems/credentials.zh.md)——`CredentialRef`، حسب عملية تحليل، مقابل UI أمان `CredentialInfo`، مزود طبقة.
- [بدء بيئة لقطة](../../util/launch-environment/README.zh.md)——تحليل قراءة تجميد ربط طبقة لقطة، بينما غير `process.env`.
- [أصل فرعي كتابة](../../util/atomic-write/README.zh.md)——كل مرة كتابة الذي استخدام كتابة قفل و أصل فرعي استبدال.
- [تطبيق بدء و Harness home كل طبقة](../../boot/app-boot/README.zh.md)——منتج CLI مثل أي يأخذ `.env` تحميل دخول لقطة و `process.env`.

<a id="model-experience"></a>
## تجربة النموذج

مرور من `ctx.credentials` مستهلك بين وصل توليد فاعلية: مستهلك يملك تخزين قيمة الذي تفعيل الكل نموذج مرئي سلوك.

#### KV Cache أثر

بلا مباشر بطلان؛ تخزين قيمة أبدا دخول طلب بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **نفس مرجع تزامن كتابة هو بعد كتابة فوز خروج**——كتابة قفل إضافة قراءة-تعديل-كتابة يجعل تزامن كتابة من لن فقد إسقاط ذاك هذا بند، لكن اثنان عدد كتابة من تحرير نفس عدد مرجع وقت ما زال بـ مقارنة بعد كتابة لـ دقيق؛ لا يوجد إصلاح حجز فحص.
- **نفس UID عملية يمكن قراءة هذا وثيقة**——ملف فاعلية نتيجة صندوق رملي نمط لن رفض قراءة،OS مفتاح مفتاح سلسلة مزود ما زال هو تأخير بعد بند.
- **بيئة تغير غير ممكن رؤية**——لقطة في بدء وقت تجميد ربط، لذلك بدء بعد export متغير حيث لن دخول تحليل، أيضا لن دخول `describe`؛ يلزم أكثر تبديل قدوم ذاتي بيئة اعتماد حاجة إعادة بدء.
- **أصل فرعي لكن لا أداة تجهيز انهيار انهيار حمل دائم صفة**——وراثة ذاتي `dsh-atomic-write`؛ تخزين في بدء وقت إعادة قراءة.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

OS مفتاح مفتاح سلسلة مزود——واحد نوع نموذج عملية أصل هذا لا يمكن قراءة تخزين——هو نفس UID حد تأخير بعد جواب سجل، ينبغي عند بصفة مستو درجة حزمة و هذا مزود و صف.seam واجهة أيضا لـ مساعد مساعدة أمر و KMS خلفية مزود مسبق إبقاء فضاء؛ هدف قبل لا يوجد أي واحد نوع مع مرفق.
