# @deepseek-ai/dsh-client-ui-cordis

[English](README.md) | العربية

## عام وصف

`dsh-client-ui-cordis` تصيير تاريخ توليد إضافة بطاقة، و لـ عملية داخل تعريف توفير تحكم وجه لوح. مستخدم يمكن عملية برنامج إزالة استهلاك من توفير تعريف؛ إعادة بدء بعد حفظ دائم بطاقة ما زال يمكن قراءة، لكن لن إعادة بناء تعريف. جديد بناء Creator إضافة استخدام Plugin Manager.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

سوف هذه الحزمة و Host و Client runner تركيب، يمكن تصيير تاريخ أداة بطاقة، و في وجه لوح في عملية برنامج تسجيل تعريف. جديد بناء agent إضافة استخدام Plugin Manager؛ هذه الحزمة لا توفير نموذج تغيير أداة.

### وجه لوح عرض ماذا

واحد `sidebar.footer.action` مقعد موضع عرض زاوية علامة، حساب عدد في ركض عدد إضافة انتظار تأكيد عدد؛ نقطة فتح بعد صف خروج كل تعريف و ذلك تشغيل تحكم عنصر. قائمة من لا حسب جلسة مرور ترشيح: حالي جلسة سطر وضع قمة صار مجموعة، أخرى جلسة سطر ما زال في تحت جهة صف خروج. سطر قدوم ذاتي host حالي بيان، و في عام إبلاغ تغيير «لديه أي بعض تعريف» وقت تحديث. فوق مرة قراءة تغطية لا إلى انتظار مراجعة دفعة run طلب ما زال لديه سطر، مباشر استخدام طلب ذاتي حمل جلسة، وسم، استخدام طريق و معرف تصيير. كل واحد سطر عرض اثنان عدد مستقل واقع——host في ركض ماذا و هذا صفحة تركيب تحميل ماذا——لذلك تحديث جديد بعد صفحة سوف أولا إعطاء «تركيب عودة هذا صفحة» ، مجددا إعطاء عام stop، بينما صاف host تعريف سطر مثل فعلي قراءة عمل تشغيل في، فقط إعطاء stop. هذا سطر أيضا سوف يأخذ هذا صفحة الأكثر بعد مرة تصيير فشل حينئذ أرض عرض، و تركيب تحميل فشل مشترك استخدام نفس عدد موضع: واحد هو «هو من قدوم لا تركيب فوق» ، آخر عدد هو «هو تركيب فوق، لكن بعد رمي».

### أداة بطاقة عرض ماذا

`cordis_define` بطاقة هو واحد نسخة سجل: نموذج كتابة تحت name و purpose، هو كتابة شفرة المصدر، و هذا تعريف هل في ركض——لا يوجد فتح صلة، لا يوجد مراجعة دفعة، فقط لديه واحد جملة إشارة نحو وجه لوح إشارة جذب.`cordis_run` بطاقة عرض نمط، إضافة معرف، حزمة معرف و تشغيل معرف، نتيجة، و في حزمة تسجيل عمل خدمة عرض وقت مرور `tool.view.cordis` slot توفير هو.`cordis_stop` و `cordis_undefine` تصيير ضيق تجميع حركة عمل سطر. كل بطاقة كل تصيير جلسة سجل تحت call و result، لذلك إعادة تشغيل عرض نفس ورقة بطاقة.

### حاجة قاعدة تخطيط حد

تعريف فقط وجود في عملية داخل: تحديث جديد بعد صفحة يد فوق ماذا كل لا يوجد، مباشر إلى لديه شخص مجددا مرة تشغيل بعض عدد حزمة؛ وجه لوح في كل مرة عام إبلاغ وقت إعادة قراءة بيان. مراجعة دفعة حسب تصميم هو إطار هيكل درجة، الذي بـ بعض عدد وسم صفحة داخل شخص يمكن دفعة دقيق نموذج لـ آخر عدد وسم صفحة جارٍ نظر جلسة الذي إرسال بدء run؛ أول عدد ينبغي جواب توليد فاعلية، ذلك بقية استلام جمع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذه واجهة خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه واجهة بناء قيام في واحد قاعدة لـ فوق: اثنان من كل لا يأخذ تشغيل حالة وضع دخول مكون state، لأن define استدعاء تسوية وقت بطاقة سوف في حديث يوم تدفق داخل تبديل موضع و إعادة تعليق. واقع نشط في «من قدرة إغلاق هو، حينئذ عودة من» مراقبة كمية داخل——متصفح runner يملك فتح وضع طلب، تحرير ترتيب نتيجة، هذا صفحة live set و ذلك تصيير فشل، بينما هذه الحزمة يملك ذاتي ذات قراءة قدوم بيان و طي مرور عام إبلاغ. وجه لوح فعل صار عام، هو لأن run طلب سوف منع سد نموذج، كما ممكن نقطة اسم واحد حالي لا شخص في نظر جلسة داخل تعريف؛ مراجعة دفعة مدخل إذا فقط وجود في ذلك عدد جلسة محادثة تدفق داخل، حينئذ سوف في هو صحيح منع سد نموذج وقت انتظار تماما جيد غير ممكن بلوغ.

عام إبلاغ (`cordis/dynamic-package`،`cordis/dynamic-retract`،`cordis/request-run`،`cordis/request-run-resolved`) إطلاق بيان إعادة قراءة، بينما لا هو حينئذ أرض ضرب رقعة——لأن عام إبلاغ لا يحمل وسم، بينما تعريف ممكن في اثنان مرة عام إبلاغ بين ظهور أو إزالة فقد. قراءة هو مفرد طيران، لذلك كثير بند عام إبلاغ معا تسوية لن وضع كبير استدعاء مرة عدد؛ اتصال إعادة وضع حيث إسقاط في طريق قراءة، أيضا لـ جديد قراءة نهوض خروج موضع، الذي بـ إعادة وصل أبدا سوف إصدار قديم host سطر.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أرض، عبر مسؤول جلسة steering و إذن نتيجة runner دورة الحياة عملية؛ هذه الحزمة تصيير تاريخ استدعاء و نتيجة، لا إضافة أداة أو تلميح مقطع سقوط.

#### KV Cache أثر

لا يوجد مباشر أثر: هذه الحزمة مسؤول تصيير؛runner إرسال خروج steering سوف تغيير جلسة تاريخ.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه واجهة أي وقت حاجة خاص آخر صغير قلب. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **وجه لوح لا يمكن يرى لا يوجد واسع بث سجل التسجيل تغيير**——برنامج جانب `define` و لم تشغيل تعريف `undefine` يمكن جعل حالي سطر إبقاء ثابت، مباشر إلى تحت مرة inventory قراءة. تشغيل طلب سوف إطلاق قراءة.
- **فقط لديه طلب، لا يوجد بيان سطر يمكن ينبغي جواب لكن غير ممكن عملية**——هو فقط توفير دفعة دقيق و رفض، لأن run/stop تحكم عنصر حاجة ذلك مرة قراءة بعد لم إرسال بلوغ سجل التسجيل سطر.
- **سطر ممكن إزالة فقد مرة قراءة وقت طويل**——نشط حركة orchestrating ذراع حمل جلسة لكن لحظة معنى لا حمل وسم، لذلك واحد قد دفعة دقيق، لكن سجل التسجيل قراءة بعد لم سقوط أرض طلب، في قراءة سقوط أرض قبل لا يوجد سطر؛ فعلي ممارسة في قراءة في طلب وصول وقت أي قد إطلاق.
- **تصيير فشل يخص حالي صفحة، كما حدوث في تحميل عودة تنفيذ بعد**——وجه لوح عرض هذا صفحة انهيار انهيار؛Host runner مفرد وحيد نحو الذي تابع جلسة إرسال steering.
- **بعض واحد صفحة تركيب تحميل فشل مقابل أخرى صفحة غير ممكن رؤية**——host بـ أول عدد تركيب تحميل عودة تقرير تسوية مرة dispatch، لذلك في آخر صفحة تأكيد بعد متصفح نصف عندئذ فشل صفحة، في أخرى صفحة فوق ما زال سوف قراءة عمل تشغيل في.
- **أي صفحة كل يمكن ينبغي جواب أي طلب**——مراجعة دفعة حسب تصميم هو إطار هيكل درجة، الذي بـ بعض عدد وسم صفحة داخل شخص يمكن دفعة دقيق نموذج لـ آخر عدد وسم صفحة جارٍ نظر جلسة الذي إرسال بدء run؛ استلام ضيق «من لديه حق ينبغي جواب» تأخير بعد.
- **call head إسقاط خروج حدث نافذة بطاقة سوف فقد إسقاط وسم**——define بطاقة name و purpose أخذ ذاتي استدعاء معامل، لذلك جلسة طويل إلى يأخذ هو جمع مقتطع وقت، بطاقة فقط قدرة بـ ذاتي ذات call id ذاتي تسمية؛ وجه لوح لا تلقي أثر، لأن host بيان يحمل وسم.
