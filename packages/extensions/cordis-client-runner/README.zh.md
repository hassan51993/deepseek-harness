# @deepseek-ai/dsh-cordis-client-runner

[English](README.md) | العربية

## عام وصف

`dsh-cordis-client-runner` لـ برنامج استدعاء جهة و قائم متصفح تحكم عنصر تشغيل عملية داخل حركة حالة حزمة متصفح جزء. هو في طلب نيل دفعة أو مستخدم صريح عملية بعد تحميل تعريف، و في Host سحب إلغاء وقت التشغيل إزالة تعريف. صفحة تحديث جديد لن استعادة تعريف.Creator UI إضافة عبر Plugin Manager استخدام قد تثبيت Client وحدة.

## استخدام هذه الحزمة

في تركيب داخل معا تركيب host runner web عميل في تركيب هذا إضافة——host نصف ركض في عملية داخل، متصفح نصف ركض في صفحة داخل. عند بعض عدد حمل متصفح نصف حركة حالة حزمة يتم وقت التشغيل، فتح صفحة سوف استلام إلى مرة تشغيل طلب؛ هذه الحزمة في هذا صفحة تنفيذ تركيب تحميل،UI حزمة (`ui-cordis`) فإن تصيير شخص استخدام قدوم ينبغي جواب هو وجه لوح و بطاقة. صاف host حزمة لا حاجة متصفح نصف، أيضا حينئذ لا حاجة صفحة:host ذاتي ذات تشغيل هو جمع.

### صفحة سوف فعل ماذا

متصفح نصف استخدام صاف JavaScript تحرير كتابة——بلا JSX، بلا TypeScript، لا يستطيع import وحدة——و بصفة واحد async دالة تشغيل. هو أخذ إلى واحد مجموعة ثابت اسم حرف——`React`،`console`،`styles` و `host`——بينما `fetch`،`setTimeout` هذا صنف متصفح عام غير ممكن استخدام. إرجاع إضافة فقط قدرة استخدام دورة الحياة حركة كلمة، و هو ذاتي ذات في `inject` داخل إعلان خدمة. من قد تركيب تحميل نصف استدعاء `host.call(method, args)` سوف وصول هو ذاتي ذات host نصف.React تصيير قد تركيب تحميل نصف وقت حدوث انهيار انهيار سوف فوق تقرير host، نقطة اسم مجرى موضع، انهيار انهيار هل قد يأخذ بند اقتباس إسقاط، و كتابة إعطاء عمل من message.

### تشغيل واجهة توفير ماذا

تشغيل واجهة يمكن ينبغي جواب مرة انتظار مراجعة دفعة host طلب——دفعة دقيق هو (اختياري أرض معا تغطية نفس إضافة لم قدوم إصدار) أو رفض هو——أيضا يمكن حسب مستخدم ذاتي ذات يد اتجاه بدء واحد تعريف، هذا يد اتجاه ذاته حينئذ هو تخويل. كل تعريف الأكثر كثير لديه واحد في طريق نشط حركة، لذلك أساس في هذا حالة بناء تحكم عنصر قدرة في remount بعد تخزين نشط. واجهة حينئذ هذا صفحة عرض محتوى كل هو صفحة محلي: كل حزمة الأكثر بعد مرة تصيير انهيار انهيار، هذا صفحة ذاتي ذات محاولة تجربة لـ أي فشل، و بعض عدد حزمة هل قد في هذا صفحة تركيب تحميل——أبدا هو host عين في «في ركض» عرض.

### دورة الحياة حد

تركيب تحميل هو قوة انتظار: اشتراط تركيب تحميل هذا واحد صفحة قد في تشغيل revision لن تغيير أي شرق غرب، تحديث revision قمة بديل قد تركيب تحميل ذلك عدد، نفس revision في retract بعد مجددا تركيب فإن إعادة تركيب تحميل. نفس تعريف عملية سلسلة سطر تنفيذ. تحديث جديد حسب تصميم من جاف صاف حالة بدء——host ما زال يحتفظ تعريف، هذا صفحة في مجددا مرة يتم اشتراط قبل لا تشغيل هو.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير متصفح نصف خلف بعد تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

متصفح نصف بناء قيام في واحد أصل فإن لـ فوق: حركة حالة حزمة يجب و ساكن حالة حزمة مشترك نفس طقم تنشيط باب تحكم،fiber effect تنظيف و حالة إسقاط. طلب قيمة بعد إضافة يتم سد دخول وحدة جدول، و مرور `loader.create` تركيب؛ إزالة أولا إزالة entry، انتظار ذلك fiber تنظيف إتمام، مجددا جعل factory بطلان و سحب تحت مثال صيغة.guard هو واحد نسخة أبيض اسم مفرد——دورة الحياة حركة كلمة إضافة قد إعلان خدمة——و host جانب صندوق رملي باب وجه مقابل تسمية، لذلك حزمة عمل من في اثنان جانب وجه مقابل نفس عدد اتفاق. واحد مراقبة من توفير اثنان عدد خروج فتحة: فقط لديه هذا داخل مراقبة نظر مجرى موضع سجل التسجيل entry-error seam، كل يخص هذا runner سقوط مقعد مرور حزمة انهيار انهيار، واحد مسار فوق سطر إعطاء host(إعطاء نموذج) ، واحد مسار إصدار إلى هذه الحزمة ذاتي ذات `renderFailures`(إعطاء وجه لوح).

### مرة run مثل أي تنفيذ

واحد بند `cordis/request-run` حدث سؤال هذا واحد صفحة يلزم لا يلزم تشغيل بعض عدد تعريف. عمل جواب واحد جهة——مراجعة دفعة بعد صفحة، أو حسب تحت تشغيل مستخدم——قيادة تحرير ترتيب: أولا host نصف (host نصف فشل سوف في متصفح حركة عمل قبل قصير مسار) ، مجددا أخذ شفرة المصدر، مجددا متصفح نصف، الأكثر بعد مرة تسوية حمل فوق حدوث واحد قطع. متصفح نصف شفرة المصدر بصفة async دالة جسم طلب قيمة، رمز رقم وجه حينئذ هو معامل؛ إرجاع إضافة مرور guard حزمة تركيب بعد عبر loader تركيب؛ تسوية تقرير إبلاغ قد تركيب تحميل revision، أو فشل مرحلة مقطع إضافة إغلاق حزمة،guard أو fiber رسالة.`host.call` مرور Remote namespace توجيه؛ حذف دخول مشاركة بـ `null` مرور خط، بينما توليد codec رفض استلام تحميل حمل سوف تغيير صار واحد بند نقطة اسم «أي مرة استدعاء + اتفاق هو ماذا» تعليم تعلم خطأ.

<a id="model-experience"></a>
## تجربة النموذج

### Host تحويل إرسال تشغيل نتيجة

#### نموذج يرى محتوى

هذه الحزمة لا توفير أداة أو تلميح. هو بـ تنشيط نجاح، ناقص خدمة، رفض أو Host/Client فشل استجابة `cordis/request-run`. إرسال إعطاء جلسة أي رسالة من Host runner مسؤول.

#### Token أثر

لديه شرط كما محدود: كل مرة run طلب الأكثر كثير واحد عودة جواب، زهرة في host هذا قدوم حينئذ سوف إرسال خروج ذلك عدد `run` نتيجة داخل. نص مع بيانات بينما تحديد (بعض عدد تعريف ذاتي ذات خطأ رسالة) ، هذه الحزمة عبر طلب لا إبقاء تخزين أي شرق غرب——واحد صفحة لاحق تركيب تحميل فشل هو صفحة محلي تشخيص، في نموذج جانب لا يوجد أي تحمل تحميل شيء.

#### KV Cache أثر

Host steering إلحاق إلى جلسة تاريخ؛ هذه الحزمة لا تعديل كتابة أكثر مبكر رسالة.

### run سقوط تحديد بعد تصيير مدة فشل

#### نموذج يرى محتوى

React ممكن في تحميل نجاح بعد فشل.Client تقرير إبلاغ ذلك يملك كل entry فشل، يشمل slot، رسالة و entry هل قد إزالة.Host إبقاء الأكثر جديد فشل و نحو الذي تابع جلسة إرسال steering؛ صفحة أيضا عرض محلي فشل.

#### Token أثر

لديه شرط، كما ذلك فوق حد من host إبقاء تخزين سياسة قرار، لا من هذا واحد صفحة قرار: كل مرة انهيار انهيار واحد بند تقرير إبلاغ، بينما host كل حزمة فقط إبقاء الأكثر جديد واحد بند——الذي بـ واحد عكس تكرار انهيار انهيار entry مقابل نموذج بديل قيمة هو واحد بند رسالة، بينما لا هو واحد ورقة تجاوز قدوم تجاوز طويل بيان. تقرير إبلاغ ذاته لن ذاتي حمل أي أداة نتيجة: نموذج فقط في يتم steer أو رئيسي حركة ذهاب سؤال وقت انتظار عندئذ لـ هو دفع استهلاك.

#### KV Cache أثر

ذاته لا يوجد. تقرير إبلاغ مرور RPC إرسال خروج و يتم تخزين بدء قدوم، بينما لا هو إلحاق دخول محادثة؛ نموذج عبر واحد بند steer رسالة أو ذاتي ذات إرسال بدء فحص نظر قراءة إلى هو جمع، ذلك مرة فحص نظر و أي أداة نتيجة واحد مثال فقط تأخير طويل ذيل جزء.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح متصفح نصف أي وقت حاجة خاص آخر صغير قلب. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **يتم رفض عودة جواب لن إعادة محاولة**——`resolveRequestRun` ack لا قراءة، الذي بـ عند host رفض واحد قديم قديم نجاح جواب تكرار (`accepted: false`——هذا واحد صفحة تركيب تحميل خلال تعريف revision يتم قمة إسقاط) ، هذا واحد صفحة سوف إبقاء قد تركيب شرق غرب، أيضا لم يعد إعادة تحرير ترتيب. ذلك مرة طلب ما زال يمكن عمل جواب (آخر صفحة عمل جواب أو استدعاء جهة إلغاء كل قدرة استلام ذيل) ، بينما قمة إسقاط revision ذلك مرة stop سوف retract إسقاط قديم قديم تركيب تحميل.
- **host namespace وجود قبل إضافة واحد مباشر تعليق بدء**——هو إعلان `remote.dynamicCordisRunner`، لذلك أبدا سوف تركيب تحميل واحد دائم بعيد كاف لا إلى ذاتي ذات host نصف متصفح نصف.
- **مجرى موضع دقيق دخول لا يوجد تحميل جسم**——تحت إرسال سطر إعلان هو خدمة، لا هو هدف مجرى موضع، لذلك حسب نشر مجرى موضع سماح/رفض بيان بلا موضع يمكن حمل.
- **guard أبيض اسم مفرد هو يد نسخ توأم توليد**——متصفح guard تكرار لحظة host جانب صندوق رملي باب وجه؛ سحب أخذ مشترك قاعدة إطار إبقاء انتظار لاحق.
