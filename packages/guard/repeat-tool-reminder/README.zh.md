# @deepseek-ai/dsh-repeat-tool-reminder

[English](README.md) | العربية

## عام وصف

هذه الحزمة مساعدة مساعدة نموذج قفز خروج بـ نفسه معامل عكس تكرار استدعاء نفس أداة لكن لا يوجد دخول عرض حلقة. بلوغ إلى إعداد تكرار مرة عدد وقت، هو سوف اشتراط نموذج فحص فوق مرة نتيجة و تغيير طريقة أو انتهاء مهمة. رفع تنبيه فقط هو بناء اقتراح، أبدا سوف منع توقف أو تأخير متأخر دمج إدارة تكرار استدعاء. كل agent تكرار قسم آخر تتبع أثر، جديد مستخدم رسالة سوف صاف حذف حساب عدد.`dsh` أساس أساس تركيب حزمة افتراضي تفعيل هذه الحزمة، و في تكرار 3،5،8 مرة وقت رفع تنبيه.

## استخدام هذه الحزمة

عند نموذج ينبغي عند ذاتي سطر اكتشاف ذاتي ذات في نفسه أداة استدعاء فوق حلقة وقت، تركيب هذا إضافة. بلا حاجة تعلم تعود أو وصل خط:`dsh` أساس أساس تركيب حزمة قد تشغيل هو، قيمة افتراضية ملائم لأجل كبير كثير عدد جلسة——تفكير أكثر مبكر، أكثر متأخر أو في أكثر قليل أداة فوق استلام إلى رفع تنبيه وقت، ضبط أفضل تحت وجه عتبة قيمة و أداة نطاق يكفي.

### أي وقت اختيار

عند نموذج طويل وقت ذاتي رئيسي عمل، كما بطاقة إقامة حلقة هو أنت تفكير استخدام بناء اقتراح بينما غير قوي صنع قدوم ضرب كسر فشل نمط وقت، اختيار هو. عند نفسه تكرار هو دمج إدارة كما يجب لا تلقي ضرب إزعاج أرض وقت التشغيل——guard فقط سوف رفع تنبيه، رفع تنبيه فقط هو تكرار استدعاء بعد واحد بند صغير رسالة——و يجب التقاط قريب يشبه تغيير جسم وقت (لأن فقط لديه دقيق تكرار——نفس أداة، نفس معامل كما و خاصية ترتيب غير متصل——عندئذ سوف يتم فحص قياس إلى) ، تجنب تجنب استخدام هو.

### ضبط عتبة قيمة و نطاق

تفكير تغيير رفع تنبيه أي وقت إطلاق أو تغطية أي بعض أداة وقت، استخدام إعداد تركيب إضافة:

```yaml
- name: '@deepseek-ai/dsh-repeat-tool-reminder'
  config:
    thresholds: [3, 5, 8]        # remind at 3, 5, and 8 consecutive repeats
    include: []                  # track every tool; list patterns to track only some
    exclude: [todo_write]        # never track these tools
    argumentsPreviewChars: 500   # cap on arguments shown in the detailed reminder
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `thresholds` | `[3, 5, 8]` | إطلاق رفع تنبيه تكرار مرة عدد |
| `include` | `[]` | فقط تتبع أثر هذه أداة؛ فارغ يمثل كل أداة |
| `exclude` | `[]` | أبدا تتبع أثر هذه أداة؛ مقابل هو جمع استدعاء حيث لا حساب عدد أيضا لا إعادة وضع |
| `argumentsPreviewChars` | `500` | تفصيل دقيق رفع تنبيه في عرض كثير قليل محرف تكرار معامل |

بلا فاعلية إعداد سوف في بدء وقت بـ صاف واضح خطأ فشل——فارغ `thresholds` قائمة، صغير في 2 تكرار مرة عدد أو تكرار قيمة——أبدا سوف ساكن صامت تغيير سلوك. توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-repeat-tool-reminder) سجل كل تلقي دعم حمل قيمة.

### أنت سوف نيل إلى ماذا

حسب قيمة افتراضية، بـ نفسه معامل تكرار نفس استدعاء نموذج سوف في رقم ثلاثة مرة تكرار وقت استلام إلى بسيط قصير رفع تنبيه——أولا قسم تحليل فوق مرة نتيجة مجددا استدعاء——و في رقم خمسة مرة و رقم ثمانية مرة استلام إلى تفصيل دقيق رفع تنبيه، صف خروج أداة و تكرار معامل، جعل ذلك قرار تغيير طريقة، استلام تجميع أكثر كثير دليل أيضا هو انتهاء مهمة. جديد مستخدم رسالة سوف صاف صفر حساب عدد، لذلك كل جديد إشارة أمر أبدا سوف يتم عند عمل حلقة. رفع تنبيه ظهور في تكرار استدعاء نتيجة بعد، ملكية في إضافة، نموذج مثل قراءة قراءة أي أخرى رسالة واحد مثال قراءة قراءة هو.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير guard مثل أي فحص قياس تكرار و إلقاء تمرير رفع تنبيه، و إشارة خروج تنفيذ هو شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

guard بناء قيام في أربعة بند تحمل وعد لـ فوق:

- **فقط بناء اقتراح، لا مرفوض.** guard استخدام نموذج سياق وفير غني post-execute قرار؛ هو من لا منع توقف أو تعديل كتابة استدعاء، لذلك `PostToolDecision` منع توقف ما زال هو لاحق مستمع أمر.
- **في post-execute في حساب عدد.** فحص قياس تشغيل في `tools/post-execute` فوق، يتم رفض استدعاء نفس مثال سوف مرور مرور هو؛ في ذلك داخل حساب عدد يجعل واحد مستمع يكفي تغطية كل محاولة تجربة، بلا حاجة عبر حدث حالة.
- **دقيق مطابقة مواصفة تحويل.** معامل بـ حلقة `JSON.parse` إخراج (أو شاذ شكل معامل JSON أصلي نص رجوع) وصول guard، لذلك JSON قيمة مجال حينئذ هو الكل إدخال مجال، عميق درجة مفتاح ترتيب ترتيب إضافة `JSON.stringify` هو كامل، تحديد صفة نفس صفة حكم تحديد——لا وجود bigint، حلقة مرجع أو `undefined` معالجة، لأن لا يوجد إدخال مسار قدرة إنتاج هو جمع.
- **تحميل وقت سريع سرعة فشل.** `thresholds` و `argumentsPreviewChars` في `apply` في تحقق و رمي خروج خطأ، أبدا رجوع إلى قيمة افتراضية.

### فحص قياس: تكرار سلسلة

كل agent سلسلة بـ «`(tool name, canonical arguments)`» لـ مفتاح——نفس أداة كما مواصفة تحويل بعد معامل نفسه (تجاهل اختصار خاصية ترتيب) اثنان مرة استدعاء حساب لـ وصل متابعة، تبديل صار آخر بند تلقي تتبع أثر استدعاء فإن يأخذ حساب عدد إعادة وضع لـ 1. سلسلة حفظ في `WeakMap<Agent, Chain>` في.

- **لا تلقي تتبع أثر استدعاء مقابل سلسلة نفاذ واضح.** يتم `include`/`exclude` ترتيب حذف استدعاء حيث لا تمرير زيادة أيضا لا إعادة وضع حساب عدد جهاز، لذلك `grep X → todo_write → grep X` في `todo_write` يتم ترتيب حذف وقت ما زال حساب عمل وصل متابعة اثنان مرة `grep X`——اختراق إدراج دخول حلقة سجل صنف أداة لا يستطيع إخفاء غطاء حلقة.
- **يتم رفض استدعاء أيضا حساب عدد.** فحص قياس يقع في `tools/post-execute`، يتم `tools/pre-execute` مستمع رفض استدعاء نفس مثال سوف مرور مرور هو؛ نموذج عكس تكرار محاولة تجربة يتم رفض استدعاء، تماما تماما هو حاجة ضرب كسر حلقة.
- **تجاهل اختصار لا يوجد agent استدعاء.** مباشر استدعاء `ctx.tools.execute()` استدعاء جهة لا يوجد حاجة رفع تنبيه نموذج، أيضا لا يوجد يمكن بصفة مفتاح نشط وثب agent كائن.
- **حسب agent قسم مفتاح، مستخدم نص التوجيه وقت إعادة وضع.** واحد agent تكرار أبدا سوف إطلاق آخر عدد agent رفع تنبيه؛ مستخدم نص التوجيه (`agent/pre-step`) سوف حذف إيداع هذا نص التوجيه agent سلسلة، كائن دورة الحياة حد ضعيف مرجع بند عمر أمر، بلا حاجة dispose(مورد تحرير) مستمع.
- **فقط إقامة إبقاء داخل تخزين.** من حفظ دائم استعادة جلسة بـ كل جديد سلسلة بدء——guard هو بدء إرسال صيغة رفع تنبيه، بينما غير سجل في سجل ثابت كمية، لذلك استعادة بعد رفع تنبيه تأخير بعد هو يمكن قبول بديل قيمة.

### رفع تنبيه نقل تمرير

رفع تنبيه مع post-execute قرار `additionalContexts`(مصدر لـ `{kind: 'plugin', plugin: 'repeat-tool-reminder', form: 'notice', summary: '<tool> × <count>'}`) نقل تمرير، أبدا استبدال `content`: لأجل مراجعة حساب `tool/result` حدث ما زال إبقاء أداة ذاتي ذات إخراج. حلقة سوف مؤقت اندفاع هذا مقطع سياق، و في هذا خطوة أداة نتيجة بعد بصفة حقن `user/message` إلحاق، جلسة سوف ذلك تصيير لـ عادي دمج صار مستخدم رسالة——نموذج مرئي، حمل لديه مصدر ملكية، كما بلا حاجة جديد جلسة حدث يكفي من جلسة سجل إعادة بناء.guard بداية نهاية عبر `next()` تفويض إرسال، و يأخذ رفع تنبيه وضع في تحت تنقل قرار سياق عدد مجموعة قبل، لذلك اثنان نوع قرار تغيير جسم (يشمل يتم منع توقف استدعاء) كل سوف استلام إلى رفع تنبيه، معا كل بند إبقاء ذاتي ذات مصدر و بيانات وصفية.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema، سريع سرعة فشل تحقق، سلسلة مستمع |
| — | لا إصدار وقت التشغيل ثابت صيغة إعداد طقم مكون؛ تكرار سلسلة خاص في واحد post-execute مستمع، كما لا عام أي يمكن توفير مستقل إعداد طقم مكون مراقبة حزمة ذاتي لديه حدث أو لقطة. |

</details>

- [أداة فرعي نظام مشاركة اعتبار](../../../docs/subsystems/tools.zh.md)——هذا guard إزالة استهلاك `tools/execute` waterfall،`additionalContexts` و قرار شكل.
- [توليد إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-repeat-tool-reminder)——كل تلقي دعم حمل إعداد حقل و ذلك مصدر إعلان.
- [guard مجموعة خريطة](../README.zh.md)——نفس مجموعة guard حزمة و حلقة حماية توليد بيت عائلة.

<a id="model-experience"></a>
## تجربة النموذج

### أول عدد عتبة قيمة سياق رسالة

#### نموذج يرى ماذا

بلوغ إلى رقم واحد إعداد وصل متابعة تكرار عتبة قيمة وقت، مقابل agent سوف استلام إلى تحت وجه رفع تنبيه. لن إضافة أداة schema أو صحيح معتاد استدعاء نص.

##### أول عدد عتبة قيمة رفع تنبيه

```markdown
You are repeating the exact same tool call with identical arguments. Carefully analyze the previous result before calling again: if the task is not complete, try a different approach or different arguments instead of repeating the call.
```

#### Token أثر

بلوغ إلى عتبة قيمة قبل لـ صفر token. رفع تنبيه سوف بصفة هذا agent تاريخ سجل إبقاء.

#### KV Cache أثر

فقط إلحاق؛ جديد ظهور محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### لاحق عتبة قيمة سياق رسالة

#### نموذج يرى ماذا

بلوغ إلى لاحق عتبة قيمة وقت،agent سوف استلام إلى تحت وجه تفصيل دقيق رفع تنبيه نموذج لوح. تلقي حد أعلى قيد معامل معاينة صارم إطار بـ `… (+<omitted> more chars)` ربط ذيل.

##### لاحق عتبة قيمة رفع تنبيه

```markdown
Repeated tool call detected:
- tool: <toolName>
- consecutive_calls: <count>
- arguments: <canonicalArguments>
The repeated calls are not making progress. Do not call this tool with these exact arguments again. Inspect the latest result and choose a different action, different arguments, or finish the task if enough evidence has been gathered.
```

#### Token أثر

كل بند رفع تنبيه كل سوف بصفة تاريخ سجل إبقاء؛`argumentsPreviewChars` حد مع بيانات تغير معامل نص طويل درجة، بينما كل agent ما زال استخدام مستقل حساب عدد جهاز.

#### KV Cache أثر

فقط إلحاق؛ جديد ظهور محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح guard أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **فقط دقيق مطابقة فحص قياس**——مواصفة تحويل هو عميق درجة مفتاح ترتيب ترتيب، لذلك قريب يشبه تغيير جسم (قليلا عمل تعديل مسار، قيمة داخل كثير بقية فارغ أبيض) سوف التفاف مرور سلسلة؛ في لا يوجد يحتاج طلب دليل قبل، لا اعتماد نموذج غامض مطابقة.
- **ضغط (compaction) لن إعادة وضع سلسلة**——عبر تجاوز ضغط فحص نقطة سلسلة سوف متابعة حساب عدد.
- **فقط توفير بناء اقتراح**——بعد لم تنفيذ عال عتبة قيمة وقت ترقية لـ منع توقف شكل صيغة، لكن `PostToolDecision` قد دعم حمل منع توقف.
- **subagent بين لا مشترك سلسلة**——سلسلة بداية نهاية حسب agent عزل؛ أب agent و ذلك subagent تكرار نفسه استدعاء أيضا أبدا دمج.
- **دمج إدارة قوة انتظار جولة استفسار تجاوز مرور عتبة قيمة بعد ما زال سوف استلام إلى رفع تنبيه**——يمكن عبر `thresholds`/`exclude` إعداد تحرير ضغط قوة.
- **تجاوز مرور الأكثر عال عتبة قيمة بعد سلسلة لم يعد رفع تنبيه**——رفع تنبيه فقط في دقيق بلوغ إلى الذي إعداد مرة عدد وقت إطلاق، تجاوز مرور بعد لن متابعة إرسال.
