# @deepseek-ai/dsh-hmr

[English](README.md) | العربية

## عام وصف

في تطبيق تشغيل خلال إعادة تحميل إضافة شفرة المصدر و إعداد. وحدة استبدال،Include تحديث جديد و profile إعداد تغيير مشترك استخدام واحد طابور صف. حزمة تثبيت في هذا طابور صف خارج تنفيذ.`ctx.hmr` إبقاء قائم Cordis HMR إعداد و حدث.

## استخدام هذه الحزمة

بدء جهاز توفير `profileContext` وقت،base تركيب حزمة بـ `root: []` تفعيل HMR؛ لا يوجد هذا profile سياق مضيف إبقاء هذا بند لـ منع استخدام حالة.Headless،SDK و ACP تركيب حزمة في YAML في منع استخدام هذا بند، لاحق profile patch يمكن إعادة تفعيل. منع استخدام أو حذف HMR وقت، أكثر تعديل في إعادة بدء بعد توليد فاعلية. مثل يحتاج استماع شفرة المصدر وحدة، في بدء قبل عبر profile patch إعداد base تركيب حزمة توفير `hmr` بند:

```yaml
- id: hmr
  disabled: false
  config:
    root: ["."]
```

قد لديه إعداد سوف وحدة اسم `@deepseek-ai/cordis-plugin-hmr` استبدال لـ `@deepseek-ai/dsh-hmr`. متابعة توفير `hmr` خدمة مفتاح،`baseDir`،`config`،`getLinked()`،`getOuterStack()`،`hmr/change` و `hmr/reload`. مساحة العمل إبقاء vendored حزمة؛DSH profile استخدام هذه الحزمة.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `base` | Context base URL | وحدة استماع أساس دقيق دليل. |
| `root` | `["."]` | وحدة استماع دليل؛`[]` فقط إبقاء صريح تسجيل إعداد استماع. |
| `ignored` | `["**/node_modules", "**/.*", "cache", "data"]` | ترتيب حذف وحدة مسار. |
| `debounce` | `100` | دمج وحدة تغير جزء ثانية عدد. |

Chokidar خيار (يشمل جولة استفسار) إبقاء أصل لديه يحتوي معنى. دقيق إعداد استماع معا مراقبة إضافة جديدة، حذف و ابتدائي لا وجود أب دليل. هو جمع افتراضي استخدام `awaitWriteFinish: true`: تحرير بعد انتظار Chokidar 2 ثانية كتابة مستقر نافذة، تجنب تجنب ذلك تغير حدث عقدة تدفق فقد فقد إشعار. يمكن عبر `awaitWriteFinish` ضبط كامل نافذة؛ منع استخدام هو ممكن تسرب إسقاط سريع سرعة وصل متابعة تحرير. مباشر عبر Plugin Manager إرسال بدء عملية بلا حاجة انتظار ملف حدث يكفي تطبيق.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

`watchConfig()` تسجيل سوف يتم انتظار إعداد معالج.`runExclusive()` سوف إعداد تغيير،Loader تحديث و تلقائي إعادة تحميل سلسلة سطر تحويل، و رفض تضمين طقم أمر خدمة. حزمة تثبيت و حذف في هذا طابور صف خارج تنفيذ.HMR لا نيل أخذ حزمة عملية كتابة قفل؛manifest إشعار فقط في لديه ترتيب `dsh.profile.bundles` قائمة تغير وقت إطلاق إعادة تحميل.profile و home patch تغير أيضا سوف إطلاق إعادة تركيب. إعداد أمر خدمة خلال استلام إلى ملف حدث في أمر خدمة انتهاء بعد معالجة.

App-boot مسؤول profile تحليل و patch أولوية درجة قاعدة.HMR قراءة بدء جهاز توفير صاف بيانات `profileContext`، في ابتدائي تحويل وقت تسجيل profile manifest و اثنان نسخة مستخدم patch استماع، و انتظار تطبيق حينئذ خيط بعد معالجة أكثر تعديل. إلغاء تدمير HMR وقت سوف إغلاق مستمع و إلغاء انتظار بدء إعادة تحميل.HMR أيضا مسؤول وحدة ذاكرة مؤقتة استبدال و إعادة تحميل ضبط درجة. إعداد مستمع في حالي أمر خدمة سياق خارج بدء، جعل لاحق إشعار يمكن دخول طابور صف. لا إصدار invariant مرافق توليد مدخل، لأن طابور صف و استماع تسجيل لا يوجد مستقل حمل دائم إسقاط.

يتم استماع وحدة مسار امتداد استخدام Node ESM تحليل الذي استخدام `realpathSync()` يمثل، يشمل Windows قصير دليل اسم، جعل ملف حدث و وحدة ذاكرة مؤقتة مطابقة.

وحدة استبدال تنفيذ مصدر ذاتي `@cordisjs/plugin-hmr` 1.0.15، يتضمن Harness Node loader و كسول صفة إعداد تعديل. إبقاء ذلك [MIT سماح يمكن إثبات](LICENSE).

<a id="model-experience"></a>
## تجربة النموذج

### يتم إعادة تحميل إضافة

#### نموذج يرى ماذا

`ctx.hmr` لا إضافة نموذج أداة أو رسالة. تحميل بعد إضافة قرار لاحق أداة و نص التوجيه مساهمة.

#### Token أثر

لا يوجد مباشر token مساهمة.

#### KV Cache أثر

إعادة تحميل توفير سياق إضافة ممكن تغيير لاحق طلب بادئة؛HMR لا تعديل كتابة محادثة تاريخ.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- وحدة استبدال حاجة Node loader داخلي واجهة. إطار هيكل اعتماد تغير استدعاء مضيف توفير `loader.exit()` خطاف؛HMR ذاته لا إعادة بدء عملية.
- عبر إضافة إدارة جهاز استبدال قد تثبيت حزمة إصدار ما زال حاجة إعادة بدء. متصفح Client وحدة رسم إبقاء مستقل متصفح جانب تحميل آلية.
