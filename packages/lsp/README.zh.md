# lsp/: لغة خادم شفرة تنقل

[English](README.md) | العربية

## عام وصف

lsp مجموعة يجعل agent(ذكي جسم) عبر إعداد جيد لغة خادم تنقل شفرة: تحويل إلى تعريف، فحص بحث مرجع و تنفيذ، و قراءة قراءة معلق توقف وثيقة. استخدام `lsp-stdio` اتصال محلي stdio لغة خادم أمر و توسيع اسم خريطة، استخدام `tool-lsp` نحو نموذج توفير هذه عملية. مشترك `lsp` حزمة جعل مزود اختيار و مواصفة تحويل نتيجة إبقاء متسق، لذلك أكثر تبديل خادم لن تغيير نموذج طلب. نشر يجب ذاتي سطر توفير و إعداد لغة خادم؛ هذا مجموعة لا مع مرفق أي لغة خادم.

<a id="packages"></a>
## حزمة

| حزمة | مسؤولية | ctx key |
|---|---|---|
| [`lsp/`](lsp/README.zh.md) | تعريف شفرة تنقل خدمة: حسب ملف توسيع اسم اختيار مزود، أربعة نوع مواصفة تحويل فقط قراءة عملية و بنية تحويل خطأ | `ctx.lsp` |
| [`lsp-stdio/`](lsp-stdio/README.zh.md) | عبر `ctx.fs` و `ctx.subprocess` قيادة إعداد جيد stdio لغة خادم أمر، تسجيل لـ مزود | تسجيل إلى `ctx.lsp` |
| [`tool-lsp/`](tool-lsp/README.zh.md) | عبر `lsp` أداة نحو نموذج كشف دقيق شفرة تنقل | تسجيل إلى `ctx.tools` |

مزود تسجيل هو قدرة بينما غير أداة:`tool-lsp` هو موجه إلى نموذج اسم،schema، نص التوجيه إشارة جذب و عرض وحيد owner، لذلك أكثر تبديل مزود أبدا سوف تغيير نموذج طلب تنقل طريقة.
