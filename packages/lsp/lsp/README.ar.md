# @deepseek-ai/dsh-lsp

[English](README.md) | العربية

## عام وصف

استخدام `dsh-lsp` لـ agent(ذكي جسم) توفير لغة خادم تنقل، يشمل تعريف، مرجع، تنفيذ و معلق توقف وثيقة. استعلام حسب ملف توسيع اسم اختيار قد إعداد مزود، و إرجاع مواصفة تحويل نتيجة و بنية تحويل خطأ، لذلك أكثر تبديل خلفية لن تغيير تنقل طلب أو نموذج مرئي استجابة. تنقل فقط قراءة، و لحظة معنى ترتيب حذف عام JSON-RPC وصول، إعادة تسمية، صيغة تحويل، تشخيص و رمز رقم قائمة. هذه الحزمة يجب و `dsh-lsp-stdio` انتظار مزود و موجه إلى نموذج `dsh-tool-lsp` تركيب؛ مفرد وحيد استخدام وقت لا توفير تنقل.

## استخدام هذه الحزمة

تركيب لغة خادم مزود و `lsp` أداة، يكفي لـ agent توفير نص بحث لا يمكن يمكن اعتماد إعطاء خروج، أساس في دلالة شفرة تنقل——منطقة قسم نفس اسم دالة، تتبع مع استيراد آخر اسم، يأخذ واجهة اتصال إلى ذلك تنفيذ، أو قراءة دفع قطع خروج نوع. هذه الحزمة حينئذ هو هذه حزمة الذي تسجيل خدمة؛ هو ذاته لا تعريف أي UI، أداة أو مزود.

### أي وقت اختيار

عند نشر أمل نظر نموذج مرئي شفرة تنقل من لغة خادم دعم دعم وقت، اختيار هذا خدمة. هو تغطية فقط قراءة تنقل——تعريف، مرجع، تنفيذ و معلق توقف——و لحظة معنى ترتيب حذف تعديل (إعادة تسمية،code action، صيغة تحويل) ، رمز رقم قائمة و تشخيص. هذا خدمة مزود غير متصل: محلي stdio خادم، بعيد مسار خادم و صندوق رملي أصلي مزود كل بـ نفسه طريقة تسجيل، لذلك أكثر تبديل خلفية لن تغيير نموذج يرى محتوى أو طلب طريقة.

### تركيب تنقل مكدس

seam حاجة مزود و مستهلك عندئذ قدرة إرسال تلويح أثر. الأكثر صغير تركيب تركيب خدمة،stdio مزود و أداة:

```yaml
- name: '@deepseek-ai/dsh-fs-local'
- name: '@deepseek-ai/dsh-subprocess-local'
- name: '@deepseek-ai/dsh-lsp'
- name: '@deepseek-ai/dsh-lsp-stdio'
- name: '@deepseek-ai/dsh-tool-lsp'
```

خادم أمر، توسيع اسم خريطة و نظام الملفات/عملية فرعية إعداد مقابل في مزود و أداة حزمة في إعداد؛ رؤية [dsh-lsp-stdio](../lsp-stdio/README.ar.md) و [dsh-tool-lsp](../tool-lsp/README.ar.md).

### أربعة نوع عملية

كل استعلام في مصدر ملف بعض عدد ضوء علامة موضع رفع خروج أربعة عدد دلالة مشكلة لـ واحد؛ نتيجة هو يتم مواصفة تحويل موضع أو معلق توقف محتوى، أبدا هو أصلي بروتوكول تحميل حمل.

| عملية | agent نيل نيل محتوى |
|---|---|
| `goToDefinition` | ضوء علامة موضع رمز رقم تعريف موضع |
| `findReferences` | كل مرجع، بداية نهاية يتضمن إعلان |
| `goToImplementation` | أداة جسم تنفيذ موضع |
| `hover` | هذا رمز رقم مواصفة تحويل وثيقة، أو لا يوجد |

`findReferences` بداية نهاية يتضمن إعلان، لذلك أثر قسم تحليل أبدا سوف متروك تسرب تعريف موضع. بروتوكول فوق موضع هو من صفر بدء UTF-16؛ موجه إلى نموذج أداة قبول من 1 بدء ضوء علامة جلوس علامة و ذاتي سطر تحويل.

### فشل و استعادة

عند لا يوجد تسجيل مزود معالجة هذا ملف توسيع اسم وقت، استعلام سوف بـ بنية تحويل خطأ `LSP_UNAVAILABLE` فشل——لـ هذا توسيع اسم إضافة مزود، أو استعلام تلقي دعم حمل ملف. بلا فاعلية أو اندفاع مفاجئ مزود تسجيل سوف في أي توجيه إصدار قبل بـ `LSP_INVALID_PROVIDER` أو `LSP_CONFLICT` فشل؛ مقابل قد تحرير مزود استعلام بـ `LSP_DISPOSED` فشل. مستهلك التقاط `LspError` و حسب مستقر `code` توجيه؛ مرور من أداة، هذه سوف عرض لـ نموذج يمكن قراءة خطأ نتيجة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير seam خلف بعد تصميم قرار و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **قدرة seam،Service Definition زاوية لون.** هذه الحزمة يملك `ctx.lsp` و مزود سجل التسجيل؛ مزود تسجيل هو قدرة بينما غير أداة،`dsh-tool-lsp` هو موجه إلى نموذج جدول طبقة وحيد owner.
- **أصل فرعي تسجيل.** `registerProvider()` في تغيير قبل تحقق و فحص الكل اندفاع مفاجئ: بلا فاعلية أو اندفاع مفاجئ تسجيل لن إصدار أي محتوى، ذلك disposer سوف واحد و تحرير id و الكل توسيع اسم إبقاء.
- **و ترتيب غير متصل اختيار.** `query()` حسب ملف نهائي توسيع اسم (مواصفة تحويل لـ صغير كتابة، بـ نقطة فتح رأس شكل صيغة) توجيه؛ تسجيل و HMR(حار وحدة استبدال) ترتيب أبدا سوف تغيير توجيه.language id فقط لأجل تزامن مؤقت وثيقة، أبدا مشاركة و اختيار.
- **غلاف إغلاق مفردات.** أربعة نوع عملية ربط دمج هو غلاف إغلاق——إضافة جديدة عملية هو عبر seam، مزود و أداة تحرير ترجمة مدة قوي صنع تغيير. لا يوجد JSON-RPC هروب توليد فتحة، كما كل طلب حقل كل لا بد ملء، لذلك لا وجود `resolve()` خطوة.
- **مزود يملك مساحة العمل جلوس علامة.** موضع نتيجة يحمل مزود مواصفة مساحة العمل URI، مستهلك حسب هذا في تنفيذ عالم حد نطاق الأسماء داخل متبادل مقابل تحويل ملف URI، بينما لا هو تطبيق مضيف منصة مسار قاعدة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Lsp` خدمة،`registerProvider`/`query`،`finalExtension`،`LspError` code |
| [`src/types.ts`](src/types.ts) | seam مفردات: طلب، نتيجة، مزود و خدمة اتفاق |
| [`src/brand.ts`](src/brand.ts) | `LspProviderId` صنف لوحة تحويل id نوع و عمل مصنع |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ مزود id و توسيع اسم توجيه يخص بـ أصل فرعي طريقة تحديث خاص حالة؛ هذا seam حيث لا عام يمكن قطعة رفع لقطة، أيضا لا عام يمكن توفير مستقل مقارنة مقارنة دورة الحياة حدث. |

### تسجيل و اختيار دورة الحياة

تسجيل و تحرير عبر `ctx.effect()` تنفيذ، لذلك مزود توجيه مع تسجيل fiber واحد نفس تخزين نشط و إزالة هلاك.`finalExtension()` حسب اثنان نوع مسار قسم فصل رمز قطع قسم، مقابل لا يوجد توسيع اسم اسم أو نقطة فتح رأس dotfile إرجاع `''`، أي توجيه كل لن مطابقة.`LspError` توسيع `HarnessError`، يحمل مستقر code(`LSP_INVALID_PROVIDER`،`LSP_CONFLICT`،`LSP_UNAVAILABLE`،`LSP_DISPOSED`،`LSP_UNSUPPORTED_OPERATION`،`LSP_MALFORMED_RESPONSE`) ، استدعاء جهة حسب هذا توجيه، بينما لا هو تحليل `message`.

<a id="model-experience"></a>
## تجربة النموذج

عبر `dsh-tool-lsp` بين وصل أثر؛ هذا أداة يملك موجه إلى نموذج `lsp` schema، نص التوجيه إشارة جذب و تصيير نتيجة، هذا سجل التسجيل ذاته لا مساهمة نص التوجيه أو schema.

#### KV Cache أثر

لن مباشر بطلان؛ طلب بادئة تغيير من `dsh-tool-lsp` مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد تعريف seam حالي نطاق. هو جمع هو حزمة قيد، لا هو مهمة تراكم ضغط.

- **نفس وقت التشغيل داخل توسيع اسم ملكية متبادل رفض**——اثنان عدد مزود لا يستطيع معا إعلان `.ts`، أي جعل language id مختلف؛ إعادة تراكم سوف جعل تسجيل فشل. مسبق مدة توسيع هو في تسجيل لـ فوق زيادة نشر إعداد selector، هو يمكن في لا يأخذ مزود اختيار إضافة دخول نموذج إدخال قبل رفع تحت وضع عرض متبادل رفض إبقاء.
- **فقط أربعة نوع فقط قراءة عملية**——symbol و call hierarchy بسبب حاجة مختلف schema بينما دفع متأخر؛diagnostics حاجة مستقل جديد طازج درجة و تراكم تراكم قاعدة؛ تعديل (إعادة تسمية،code action، صيغة تحويل) حاجة مستقل أداة، و تجميع صار معاينة، إذن و كتابة سياسة.
- **لا يوجد مراقبة قياس جدول طبقة**——متاح صفة فقط قدرة عبر تشغيل `query()` و حسب رمي خروج `LspError` code توجيه قدوم مراقبة قياس؛ لا يوجد مزود تغيير حدث أو قدرة حالة استعلام.
