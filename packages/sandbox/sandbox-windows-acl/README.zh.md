# @deepseek-ai/dsh-sandbox-windows-acl

[English](README.md) | العربية

## عام وصف

في Windows فوق، هذه الحزمة سوف عملية فرعية كتابة حد في مساحة العمل و خاص مؤقت دليل داخل.`workspace-write` منح إعطاء مقابل هذا اثنان عدد موضع كتابة إذن،`read-only` فإن متساو لا منح إعطاء. تركيب `dsh-sandbox-local` بعد، تلقي حد bash و PowerShell أمر سوف تلقائي نيل نيل هذا سلوك؛ استدعاء جهة أيضا يمكن مباشر استخدام عام `AclSandbox` API، و التقاط معيار تدفق. أي Win32 عملية فشل كل سوف منع توقف عملية فرعية في لا تلقي حد حال حال تحت بدء. هذا حفظ إثبات خاص معنى علامة لـ جزء قوي صنع، لأن عملية بدء سوف إبقاء Everyone وصول إذن،NTFS صلب رابط أيضا يمكن عبر أخرى مسار كشف نفس ملف؛ استدعاء جهة يمكن عبر تقرير إبلاغ `partial` قوي صنع درجة آخر فحص قياس هذا حد.

## استخدام هذه الحزمة

في Windows فوق، تركيب محلي صندوق رملي مزود بعد، هذا خلفية حينئذ هو `ctx.sandbox` خلف بعد runner——بلا حاجة مقدار خارج إعداد. يلزم في harness خارج spawn تلقي حد عملية فرعية وقت، مباشر تضمين دخول `AclSandbox` API.

### أي وقت اختيار

لـ في `read-only` أو `workspace-write` تحت عزل عملية فرعية ملف عملية Windows تركيب اختيار هو. عند عملية فرعية أيضا حاجة قراءة جانب عزل أو شبكة شبكة حد وقت طلب آخر اختيار آلية:`WRITE_RESTRICTED` فقط تسليم تقاطع فحص كتابة وصول، لذلك طلب يأخذ هذا خلفية و قراءة جانب سياسة أو AppContainer قدرة أمر لوحة إعداد مقابل بـ نيل نيل أكثر قوي عزل.

### مباشر API

`AclSandbox` بـ التقاط stdio طريقة spawn تلقي حد عملية فرعية (runner ريح إطار استخدام متاح وراثة stdio). هو اشتراط صريح توفير خاص مؤقت دليل، أو استخدام `tempDir: null` منع استخدام مؤقت كتابة——بيئة مؤقت أصل دليل أبدا سوف يتم خفي صيغة تخويل.

```ts
import { mkdtempSync, rmSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { join } from 'node:path'
import { AclSandbox, tempWriteSid, workspaceWriteSid } from '@deepseek-ai/dsh-sandbox-windows-acl'

const workspaceRoot = process.cwd()
const tempDir = mkdtempSync(join(tmpdir(), 'dsh-'))

// mode selects the token's restricting-SID list (see Modes below) and must
// match the grant shape. workspace-write requires distinct workspace and
// private-temp identities; pass tempDir: null to disable temp writes.
const sandbox = new AclSandbox({
  writableDirs: [workspaceRoot],
  tempDir,
  writeSid: workspaceWriteSid(workspaceRoot),
  tempWriteSid: tempWriteSid(tempDir),
  mode: 'workspace-write',
})
await sandbox.init() // throws on ANY Win32 failure — never spawns unrestricted

const child = sandbox.spawn({ command: 'pwsh', args: ['-NoProfile', '-Command', '...'], cwd: workspaceRoot })
const { stdout, stderr, exitCode } = await child.wait()

sandbox.dispose() // revokes the revocable (temp) grant, keeps the standing workspace ACE; reports every cleanup failure
rmSync(tempDir, { recursive: true, force: true })
```

مساحة العمل ACE بـ معتاد إقامة طريقة منح إعطاء——`dispose()` إبقاء هو جمع، لأن هو جمع هو عبر نسخة إعادة استخدام ذاكرة مؤقتة——بينما مختلف مؤقت SID بـ يمكن عودة استلام طريقة منح إعطاء. خدمة طرف مقابل تنفيذ هو `AclWriteGrant` صنف: كل دليل مرة `add(path, standing)`،`dispose()` سحب إلغاء يمكن عودة استلام مسار و تحرير SID.

### عزل إعطاء أنت حمل قدوم ماذا

في `workspace-write` تحت، عملية فرعية يمكن كتابة مساحة العمل و ذلك خاص مؤقت دليل؛ تلقي ACL إدارة ولاية أخرى كتابة كل سوف يتم رفض، قد سجل Everyone و صلب رابط حد حذف خارج. في `read-only` تحت لا وجود صريح كتابة تخويل، لذلك كتابة سوف يتم رفض، نفس مثال حمل لديه قد سجل حد.

مؤقت عزل حسب كل نشط وثب جلسة/مساحة العمل مقابل إجراء: مشترك مساحة العمل جلسة مشترك ذلك كتابة إذن، لكن لا يمكن كتابة ذاك هذا مؤقت دليل. جديد مزود مجموع سوف اختيار جديد مؤقت مسار و SID، لذلك انهيار انهيار ناقص إبقاء حيث لا يمكن منع توقف استعادة جلسة، أيضا لا يمكن نحو ذلك تخويل.

### فشل و استعادة

`init()` في أي Win32 فشل وقت رمي خروج——عملية فرعية أبدا سوف لا تلقي حد أرض spawn. تنفيذ أمر قبل فشل runner سوف نحو stderr ضرب طبع `windows-acl-run: <detail>` و بـ 127 خروج،seam runner فشل قاعدة سوف ذلك عودة صنف لـ ضرر تالف صندوق رملي، بينما غير رفض. تنظيف حسب تصميم كل قوة بينما لـ:`dispose()` سوف محاولة تجربة الكل مؤقت سحب إلغاء و يأخذ فشل تجمع دمج لـ `AggregateError`.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير تلقي حد أمر لوحة آلية، أمر لوحة قائمة،runner اتفاق و قد تحقق حد؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### آلية

استدعاء من أمر لوحة يتم نسخ لـ `WRITE_RESTRICTED` تلقي حد أمر لوحة، ذلك restricting SIDs يحمل ذاك هذا مستقل مساحة العمل و خاص مؤقت دليل قدرة.Windows تنفيذ اثنان مرة وصول فحص——أولا مقابل صحيح معتاد SID، مجددا مقابل restricting SID——و كما فقط في اثنان مرة فحص كل عبر وقت عندئذ منح إعطاء كتابة صنف وصول. مساحة العمل SID من مواصفة مساحة العمل مسار تحديد صفة إرسال توليد (`workspaceWriteSid`) ، لذلك مساحة العمل أصل دليل ACE كل منصة آلة جهاز كل مساحة العمل فقط شيء تحويل مرة، بعد كل مرة جلسة، استدعاء أو إعادة بدء كل أمر في دقيق ACE قفز مرور. كل نشط وثب جلسة/مساحة العمل مقابل فإن نيل نيل واحد مع آلة خاص مؤقت دليل، و واحد من هذا مسار إرسال توليد SID(`tempWriteSid`) ، لذلك كل جلسة مشترك مسبق مدة مساحة العمل إذن، لكن لن وراثة ذاك هذا مؤقت دليل إذن. كل سياسة مخصص استخدام Win32 استدعاء و [`dsh-win32-process`](../../subprocess/win32-process/README.zh.md) توفير عملية أصل لغة كل لديه فحص؛ فشل رمي خروج يحمل API اسم، دقيق رمز خطأ، نظام نص و فشل سياق `Win32Error`——من بنية صنع فوق fail-closed.

### نمط و أمر لوحة قائمة

`workspace-write`(تسجيل تسجيل SID،Everyone، مساحة العمل SID، مؤقت SID) لـ مساحة العمل و جلسة خاص مؤقت فرعي دليل قسم آخر منح إعطاء Write؛`read-only`(تسجيل تسجيل SID،Everyone——لا يحتوي كتابة SID) لا منح إعطاء أي محتوى. حفظ نشط مجموعة (تسجيل تسجيل SID + Everyone) في اثنان نوع نمط تحت كل وجود: لا يوجد هو، مبكر مدة DLL ابتدائي تحويل سوف بـ `0xC0000142` ميت هلاك،CNG سوف يجعل pwsh بـ `0xE0434352` انهيار انهيار. كتابة SID متعمد إبقاء في read-only قائمة خارج: أولا قبل workspace-write وقت مدة إبقاء تحت معتاد إقامة تخويل ACE ما زال بطلان، لأن write-restricted pass-2 فحص فقط منح إعطاء restricting قائمة الذي يحمل محتوى، بينما معتاد إقامة ACE يجعل إعادة ترقية تجنب في إعادة نقل بث.

NUL كتابة هو بيئة صفة، لا هو يتم تخويل: ضبط تجهيز DACL منح إعطاء Everyone قراءة+كتابة+تنفيذ (`0x1201BF`) ، لذلك وصول إخفاء رمز سقوط في ذلك داخل فتح من (cmd `> NUL`،node `\\.\NUL`) في اثنان نوع نمط تحت كل قدرة كتابة.`Set-Content NUL` في اثنان نوع نمط تحت كل فشل (PowerShell/.NET طبقة فاعلية ينبغي، غير ضبط تجهيز DACL الذي يؤدي) ، بينما PowerShell `> $null` إعادة تحديد نحو لا تلقي أثر.

Authenticated Users في اثنان نوع قائمة في كل لا وجود——WMI نطاق الأسماء أمان فحص فشل (`0x80041003`) ، لذلك CIM cmdlet و `Get-ComputerInfo` في كل تلقي حد نمط تحت كل غير ممكن استخدام، كما C:\-root شجرة إنشاء هروب هروب يتم إغلاق.INTERACTIVE/LOCAL نفس مثال لا وجود: مضيف Public شجرة نحو INTERACTIVE منح إعطاء كتابة إذن، لذلك Public كتابة يتم رفض.

### عزل runner

موجه إلى seam شكل هو runner مدخل (`./runner`):`dsh-sandbox-local` في استدعاء من أمر موضع spawn argv بادئة حزمة تركيب——و bwrap/landlock-run/sandbox-exec نفس هيكل بنية.runner إنشاء تلقي حد أمر لوحة، في هو لـ تحت spawn حزمة تركيب بعد argv، استدعاء من stdio مباشر نفاذ نقل، يأخذ عملية فرعية حزمة دخول `KILL_ON_JOB_CLOSE` job، مرآة مثل عملية فرعية خروج رمز، و في خروج وقت سحب إلغاء ذلك ذاتي سطر إدارة مؤقت تخويل. كل runner جانب فشل كل سوف نحو stderr ضرب طبع `windows-acl-run: <detail>` و بـ 127 خروج——seam runner فشل قاعدة مطابقة هذا توقيع.

```sh
node runner.js --workspace <dir> --temp <dir> --mode <read-only|workspace-write> [--write-sid <S-1-4-…> --temp-write-sid <S-1-4-…>] -- <argv...>
```

seam أولا يأخذ تحديد صفة مساحة العمل SID ACE معتاد إقامة شيء تحويل (كل مساحة العمل كل خادم دورة الحياة مرة——إعادة استخدام ذاكرة مؤقتة) ، مجددا لـ كل نشط وثب جلسة/مساحة العمل مقابل إنشاء مع آلة خاص مؤقت دليل و مختلف يمكن عودة استلام SID، يأخذ اثنان نوع هوية بصفة يجب صار مقابل ظهور `--write-sid`/`--temp-write-sid` نقل دخول؛runner مقابل وفق كل منها الذي تابع مسار تحقق اثنان من، حيث لا تخويل أيضا لا سحب إلغاء (`manageDacls: false`).fork نيل نيل مختلف مؤقت قدرة؛ أي جعل استعادة هو نفس جلسة، جديد مزود أيضا سوف إعطاء خروج جديد مسار و SID، لذلك انهيار انهيار ناقص إبقاء فقط هو بطلان نفاية قمامة. إذا لا حمل هذا واحد مقابل علامة سجل،`--temp` إشارة تحديد هو أصل دليل: بلا agent(ذكي جسم)/مستقل workspace-write runner سوف إنشاء مع آلة خاص فرعي دليل، ذاتي سطر إدارة ذلك مؤقت SID، إعادة كتابة TMP/TEMP، و في خروج وقت إزالة هذا فرعي دليل. إعادة بدء بعد إعادة تخويل معتاد إقامة مساحة العمل ACE هو قوة انتظار:`grantWrite` قراءة حالي DACL، عند تماما نفسه ACE قد وجود وقت قفز مرور إعادة نقل بث. مساحة العمل إذا انتظار في أو يتضمن مؤقت أصل دليل، سوف في أي تخويل قبل يتم رفض.

بدء وقت إذا حمل لديه subprocess تحكم علامة،runner سوف عبر تلقي حد عملية فرعية CRT بدء جدول تحويل إرسال fd 7، و في spawn بعد قيام أي إغلاق ذاته فرعي هذا. اختياري `controlFileDescriptor: 7` إدخال اشتراط `stdio: 'inherit'`؛ في إدارة طريق stdio تحت طلب هو سوف في عملية إنشاء قبل فشل.

### قد تحقق حد

- **Everyone تخويل ما زال هو بيئة في كتابة إذن مصدر.** Everyone يجب إبقاء في اثنان نوع restricting قائمة في (إزالة هو سوف كسر تالف مبكر مدة DLL ابتدائي تحويل و CNG) ؛ خارجي NTFS كائن إذا ذلك DACL نحو Everyone منح إعطاء الذي طلب كتابة إذن، حينئذ سوف معا عبر اثنان مرة فحص، و في اثنان نوع نمط تحت إبقاء يمكن كتابة.
- **صلب رابط هو ملف كائن آخر اسم، بينما غير مسار آخر اسم.** نقل بث إلى قد لديه صلب رابط فوق يمكن وراثة مساحة العمل ACE سوف تعديل قاع طبقة نفس ملف أمان وصف رمز، لذلك نفس كائن أيضا يمكن عبر خارجي آخر اسم كتابة؛ رفض مساحة العمل في كل كثير رابط ملف لا أداة يمكن سطر صفة، لأن عادي pnpm تثبيت سوف استخدام صلب رابط.
- **كتابة تلقي حد؛ قراءة، شبكة شبكة و عملية مرئي صفة لا تلقي حد.** `WRITE_RESTRICTED` فقط تسليم تقاطع فحص كتابة وصول، لذلك تلقي حد عملية فرعية يمكن قراءة استدعاء من يمكن قراءة أي ملف و فتح طقم وصل حرف؛`read-only` بسبب بينما حاجة قراءة جانب سياسة عندئذ قدرة جدول بلوغ.
- **تحكم منصة عزل غير ممكن استخدام.** بـ `CREATE_NO_WINDOW` / `CREATE_NEW_CONSOLE` إنشاء عملية فرعية في DLL ابتدائي تحويل خلال بـ `STATUS_DLL_INIT_FAILED`(`0xC0000142`) ميت هلاك؛ عملية فرعية مشترك مضيف تحكم منصة، أساس في إدارة طريق stdio إعادة تحديد نحو لا تلقي أثر.
- **ACL تخويل هو مقابل حقيقي دليل إقامة إبقاء تعديل.** مساحة العمل ACE حسب تصميم معتاد إقامة (إعادة استخدام ذاكرة مؤقتة، أبدا سحب إلغاء) ؛ مؤقت ACE من `dispose()` سحب إلغاء؛ يد عمل `icacls` تنظيف لا يمكن في هذا منصة عودة استلام هو جمع (`ERROR_NONE_MAPPED` 1332) ، طلب عبر هذا وحدة عودة استلام.
- **يتم تخويل دليل يجب من استدعاء من يملك.** كل من خفي صيغة `WRITE_DAC` هو صندوق رملي بلا حاجة رفع حق يكفي تحرير DACL سبب.
- **بيئة مؤقت أصل دليل أبدا سوف يتم خفي صيغة تخويل.** مباشر استدعاء جهة يجب توفير قد وجود خاص `tempDir` و ذلك مختلف `tempWriteSid`، أو استخدام `tempDir: null` منع استخدام مؤقت كتابة؛ فعلي مؤقت دليل لا نيل و أي يمكن كتابة أصل دليل إعادة تراكم.
- **تلقي حد عملية فرعية مؤقت قدرة حسب كل نشط وثب جلسة/مساحة العمل مقابل خاص.** runner في spawn قبل يأخذ TMP/TEMP تعديل كتابة لـ هذا خاص دليل؛ مشترك نفس مساحة العمل SID اثنان عدد أمر لوحة لا يمكن كتابة ذاك هذا مؤقت دليل.
- **تلقي حد أمر لوحة تحت `whoami` و أمر لوحة فحص cmdlet سوف فشل.** عملية فرعية مقابل نسخ أمر لوحة `GetTokenInformation` جزء غير ممكن استخدام، هذا هو تشخيص ضجيج صوت بينما غير تشغيل لذا عائق.

## تجربة النموذج

بين وصل أرض عبر [`dsh-bash-sandbox`](../../shell/bash-sandbox/README.zh.md) ،[`dsh-pwsh-sandbox`](../../shell/pwsh-sandbox/README.zh.md) و ذلك أداة عرض؛ هو جمع تصيير هذا خلفية جزء قوي صنع تنفيذ و رفض واقع (أداة طبقة عبر `denialSignatures` تصنيف تلقي حد stderr) ، بينما [`dsh-sandbox`](../sandbox/README.zh.md) seam يملك `SANDBOX_UNAVAILABLE` نص،`sandbox-local` يملك runner اختيار.

#### KV Cache أثر

بلا مباشر أثر؛ رفض وجه يخص أداة طبقة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح خلفية أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة. هو جمع هو حالي حزمة قيد، لا هو عام Windows مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مساحة العمل واحد كتابة أبيض اسم مفرد**——كتابة SID هو أبيض اسم مفرد أساس هذا مفرد موضع، كما حينئذ هو مساحة العمل هوية؛ نفس رمل صندوق نسخة عبر اثنان عدد مساحة العمل إعادة استخدام وقت، اثنان عدد أصل دليل سوف متبادل متبادل توسيع كبير تخويل وجه. طلب حسب مساحة العمل أصل دليل كل بناء واحد نسخة——seam صحيح هو هذا مثال فعل، بـ مساحة العمل مسار لـ مفتاح.
- **تنظيف حسب تصميم كل قوة بينما لـ**——`dispose()` سوف محاولة تجربة الكل مؤقت سحب إلغاء و يأخذ فشل تجمع دمج لـ `AggregateError`؛ تنظيف فشل ممكن إبقاء تحت مع آلة دليل و ذلك فقط يحتوي مؤقت SID ACE. عملية خروج بعد، لن مجددا لديه أمر لوحة يحمل هذا SID، لذلك ناقص إبقاء إبقاء بطلان، مباشر إلى OS مؤقت دليل حماية توليد أو يد حركة إزالة دليل سوف ذلك عودة استلام.
- **معتاد إقامة مساحة العمل ACE هو غير ممكن رؤية ناقص إبقاء.** مساحة العمل تعديل اسم سوف إرسال توليد جديد SID؛ قديم مسار فوق قديم ACE إبقاء في أصل أرض (بطلان، فقط يحتوي كتابة SID) ، لم قدوم تنظيف أمر يمكن عودة استلام هو جمع.
- **NULL-DACL دليل في grant+revoke نحو إرجاع تحت لا إبقاء هوية.** حمل NULL DACL دليل معنى طعم حال «كل شخص تماما تحكم» ؛`grantWrite` من هذا null بناء جديد ACL، سحب إلغاء نحو إرجاع بعد إبقاء تحت هو EMPTY(الكل رفض)DACL بينما غير أصلي NULL DACL. حقيقي مساحة العمل و مؤقت دليل كل حمل حقيقي DACL، لذلك هذا ما زال هو سجل في سجل حد حال شكل.
- **تلقي حد حفيد عملية إدارة طريق stdio التقاط غير ممكن استخدام.** libuv إدارة طريق stdio استخدام هو NAMED pipe، ذلك client طرف فتح الذي طلب كتابة وصول لا يوجد أي restricting SID يتم منح إعطاء (هو Win32 طبقة افتراضي SD نموذج لوح، بينما غير أمر لوحة افتراضي DACL) ، لذلك تلقي حد عملية داخل `spawn(..., { stdio: 'pipe' })` بـ EPERM فشل؛ وراثة و تجاهل اختصار stdio spawn متاح، مجهول اسم إدارة طريق (PowerShell إدارة طريق) بسبب تلقي حد أمر لوحة افتراضي DACL يحمل restricting SID كل حق ACE بينما متاح.
- **تخويل شيء تحويل هو عاجل قطع كل شجرة نقل بث.** في حمل يمكن وراثة ACE دليل فوق استدعاء `SetNamedSecurityInfoW` سوف قيام أي مرة تاريخ كل بعد بديل (كبير نوع مساحة العمل شجرة فوق بـ عدد عشرة ثانية حساب) ؛ حسب مساحة العمل هوية كل منصة آلة جهاز كل مساحة العمل فقط دفع مرة، دقيق ACE قفز مرور يجعل لاحق كل مرة توفير إعطاء كل جدا سهل مناسب.
- **قراءة جانب عزل و شبكة شبكة سياسة لا في نطاق داخل**——`WRITE_RESTRICTED` فقط تسليم تقاطع فحص كتابة وصول؛ سوف هذا خلفية و قراءة جانب سياسة إعداد مقابل بـ نيل نيل أكثر قوي عزل.
- **عرض دليل و FAT لفة تحذير إبلاغ قد دفع متأخر؛FAT صنف هدف إبقاء يمكن كتابة.** UI جانب تحذير إبلاغ بعد لم تنفيذ،FAT لفة بصفة تخويل أصل سوف كبير صوت فشل، بينما تخويل أصل خارج FAT صنف هدف لا يوجد أمان وصف رمز، لذلك في اثنان نوع تلقي حد نمط تحت كل يمكن كتابة؛FAT يتم نظر لـ متروك إبقاء ناقص إبقاء.
- **PowerShell لغة نمط بسبب تلقي حد نمط بينما مختلف.** في `read-only` تحت،PowerShell لا يمكن في مؤقت دليل في إنشاء AppLocker استكشاف إبرة ملف، لذلك سوف حفظ حراسة أرض بـ ConstrainedLanguage بدء (`Add-Type`، غير نواة قلب .NET ساكن حالة استدعاء،COM و عكس إطلاق فشل) ؛ تسليم `workspace-write` مسار يمكن يجعل استكشاف إبرة إتمام، لذلك حذف غير رئيسي آلة نطاق WDAC/AppLocker سياسة آخر لديه قاعدة تحديد، لا فإن pwsh إبقاء FullLanguage، بينما مباشر استخدام `AclSandbox` و إعداد `tempDir: null` وقت فإن لا يوجد هذا واحد حفظ إثبات. هذا واحد منطقة آخر يخص PowerShell بدء سلوك، لا هو ACL كتابة حد واحد جزء.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: لم قرار جهة نحو و فتح وضع مشكلة. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص، حزمة شفرة و متبادل صلة Agent Note لـ دقيق.

#### لم قدوم: تحذير إبلاغ و تنظيف جدول وجه

مقابل استثناء عرض دليل و FAT صنف لفة فقط تحذير إبلاغ قيام ساحة قد سجل في فوق جهة حد في لكن بعد لم تنفيذ، عودة استلام تعديل اسم مساحة العمل معتاد إقامة ACE تنظيف أمر أيضا بعد لم قرار. اثنان من كل هو فتح وضع جهة نحو، لا هو قد تسليم سلوك.
