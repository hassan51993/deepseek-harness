# @deepseek-ai/dsh-sandbox-policy

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن يجعل كل مرة تلقي حد bash، نظام الملفات و طرفية استدعاء التزام دوران نفس نسخة ملف عملية سياسة. نشر جهة اختيار افتراضي نمط و رجوع مساحة العمل أصل دليل، كل جلسة فإن يمكن مستقل تبديل نمط. جلسة اختيار يمكن عبر إعادة بدء إبقاء، كل قوي صنع تنفيذ قدرة في مرة استدعاء في استخدام نفسه نمط و مساحة العمل. كل مرة نموذج طلب قبل، نموذج كل سوف استلام إلى صالح سياسة و مساحة العمل شرح، لكن لن استلام إلى قد تركيب قدرة بيان.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في أي تشغيل صندوق رملي قوي صنع تنفيذ قدرة تركيب في تركيب هذا حزمة: هو يملك هذه قدرة إزالة استهلاك نشر قيمة افتراضية و تدريجي جلسة تغطية، و يأخذ حالي سياسة مساهمة إعطاء نموذج وقت التشغيل سياق لقطة.

### أي وقت اختيار

لـ كل حمل تلقي حد قدرة (bash، نظام الملفات، طرفية) تركيب اختيار هو، يجعل مفرد واحد سياسة ملكية موضع منع توقف هو جمع عائم نقل إلى مختلف نمط أو مساحة العمل أصل دليل. فقط لديه لا يوجد أي صندوق رملي سياسة قوي صنع تنفيذ وقت عندئذ قفز مرور هو——لا يوجد مستهلك وقت، تحليل خروج سياسة لا بدء أثر.

### الأكثر صغير إعداد

استخدام افتراضي نمط تحميل هذه الحزمة؛ لذا عائق أمان قيمة افتراضية هو `read-only`، حاجة agent(ذكي جسم) يمكن كتابة مساحة العمل نشر يجب صريح اختيار `workspace-write`.

```yaml
- name: '@deepseek-ai/dsh-sandbox-policy'
  config:
    mode: workspace-write
    workspaceRoot: /absolute/path/to/workspace
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `mode` | `read-only` | جلسة بدء بداية نشر افتراضي نمط، تحميل وقت تحقق |
| `workspaceRoot` | `process.cwd()` | بلا agent استدعاء أو لا يوجد cwd جلسة الذي استخدام قطعا مقابل رجوع أصل دليل؛ متبادل مقابل قيمة في تحميل وقت رفض. عادي agent استدعاء استخدام جلسة غير ممكن تغيير cwd |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-sandbox-policy) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### تبديل جلسة نمط

جلسة نمط يمكن في وقت التشغيل عبر UI سياسة تحكم عنصر أو صريح تبديل قدوم أكثر تعديل؛ تبديل سجل في جلسة سجل في، و في هذا جلسة تحت مرة تلقي حد استدعاء وقت توليد فاعلية. تبديل عبر إعادة تشغيل عبر إعادة بدء إبقاء، كل جلسة إبقاء ذاتي ذات نمط——اثنان عدد جلسة أبدا سوف يرى ذاك هذا حالة. تبديل بعد جلسة متابعة بـ غير ممكن تغيير مساحة العمل cwd بصفة كتابة حد.

### فشل و استعادة

بلا فاعلية إعداد نمط سوف في إضافة تحميل وقت يتم رفض، لذلك تجميع كتابة خطأ سوف توجيه يؤدي صريح تقرير خطأ، بينما لا هو ساكن صامت تغيير سياسة. لا يوجد cwd جلسة و بلا agent استدعاء رجوع إلى إعداد مساحة العمل أصل دليل؛ حمل قد دفعة دقيق صريح نمط استدعاء فقط في هذا مرة استدعاء في استخدام هذا نمط.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير سياسة تحليل، تدريجي جلسة تخزين و نموذج مرئي مساهمة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تحليل أولوية درجة

`resolve({ session, mode })` إرجاع واحد نسخة كامل تدريجي استدعاء سياسة: قد دفعة دقيق صريح نمط أولوية في جلسة الأكثر بعد واحد بند `sandbox/mode` حدث، بعد من أيضا أولوية في نشر قيمة افتراضية. جلسة غير ممكن تغيير `cwd` توفير مساحة العمل أصل دليل؛ لا فإن استخدام إعداد رجوع قيمة. تنفيذ بيئة في قطعا مقابل مسار كتابة قاعدة إبقاء ثابت. تنفيذ حد مزود في ذاتي ذات نظام الملفات فوق مواصفة تحويل أصل دليل، لذلك بعيد طرف `symlink/..` مسار أبدا سوف في Harness رئيسي آلة فوق تحليل.

### تدريجي جلسة تخزين

وقت التشغيل تبديل هو في مقابل جلسة سجل في إلحاق واحد بند فقط كتابة سجل `sandbox/mode` حدث——تبديل ذاته حينئذ هو حدث، أي آلية كل لن في حمل خارج تعديل نمط حالة.`effective = explicit grant ?? fold(events) ?? deployment default`، لذلك تغطية عبر إعادة تشغيل عبر إعادة بدء إبقاء، اثنان عدد جلسة أيضا أبدا سوف يرى ذاك هذا حالة. مساحة العمل معرف بلا حاجة حدث: إنشاء وقت سجل غير ممكن تغيير `SessionHeader.cwd` هو هذا جلسة كل مرة استدعاء استخدام أصل. حدث ما زال فقط دخول سجل؛ في كل مرة طلب قبل، ملكية جهة سوف يأخذ حالي واقع مساهمة إعطاء كامل وقت التشغيل سياق لقطة،agent loop(ذكي جسم حلقة) سوف هذا لقطة سجل لـ واحد بند حمل مصدر `user/message`.

### نموذج مرئي نص

`sandbox:policy` مساهمة شرح هذا نمط و أداة جسم قدرة غير متصل ملف عملية اتفاق، و `workspace-write` تحت قد سجل جلسة مساحة العمل. هو لا قطعة رفع قد تركيب قدرة؛ أداة إضافة إبقاء خاص تحديد في عملية رفض و رفع حق جذب توجيه، دفعة دقيق سياسة مفرد وحيد مساهمة إعطاء نفس نسخة لقطة، خطة جذب توجيه ما زال من `dsh-plan-mode` نظام مقطع سقوط إدارة. اختياري `./invariant` إعداد طقم مكون سوف رفض قيمة تجاوز خروج غلاف إغلاق نمط مفردات زائف صنع حمل دائم `sandbox/mode` حدث.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`SandboxPolicyService`،`Config` schema، سياسة تحليل و سياق مساهمة |
| [`src/session-mode.ts`](src/session-mode.ts) | `sandbox/mode` حدث، ذلك fold و كتابة مسار |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة إعداد طقم مكون: رفض تجاوز خروج غلاف إغلاق مفردات `sandbox/mode` قيمة |

<a id="model-experience"></a>
## تجربة النموذج

### حالي ملف صندوق رملي سياسة

#### نموذج يرى ماذا

كل agent جلسة حالي وقت التشغيل سياق لقطة في كل لديه واحد بند `sandbox:policy` مساهمة. هو لا قطعة رفع قد تركيب قدرة. أداة إضافة متابعة مسؤول عملية و رفع حق جذب توجيه، دفعة دقيق سياسة مفرد وحيد مساهمة إعطاء نفس نسخة لقطة، خطة جذب توجيه ما زال من `dsh-plan-mode` نظام مقطع سقوط إدارة.

##### فقط قراءة

```markdown
Current DSH file policy: read-only. Any available operation enforced by the DSH file sandbox cannot modify files in the standing mode. Do not refuse a required modification from this policy alone: try an available tool normally and follow any denial and escalation guidance it returns.
```

##### مساحة العمل كتابة

```markdown
Current DSH file policy: workspace-write. Any available operation enforced by the DSH file sandbox may modify files under the session workspace: "<workspace root>". Some platform temporary areas may also be writable.
```

##### تماما وصول

```markdown
Current DSH file policy: danger-full-access. The DSH file sandbox does not restrict file modifications by available operations.
```

#### Token أثر

أول مرة طلب و صالح سياسة كل مرة تغير وقت زيادة واحد بند بسيط نظيف حمل دائم سياق رسالة؛ لم تغير طلب لا زيادة محتوى.`workspace-write` فقط يحمل قد سجل جلسة مساحة العمل مسار؛ منصة خاص تحديد مؤقت مسار سوف بـ ملخص جدول وصف، لن إضافة دخول اعتماد رئيسي آلة بايت.

#### KV Cache أثر

نمط تبديل وقت، مستقر توجيه النظام ما زال تدريجي بايت نفسه. تغير بعد كامل سياق لقطة سوف إلحاق إلى إبقاء تاريخ بعد، من بينما إبقاء هذا قبل قد ذاكرة مؤقتة بادئة؛ لاحق لم تغير طلب سوف إعادة استخدام هذا إبقاء لقطة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد هذه الحزمة توفير سياسة نطاق. هو جمع هو حالي حزمة درجة قيد، و غير عام صندوق رملي مقابل مقارنة، أيضا لا هو انتظار إنجاز أمر بند بيان.

- **كل جلسة فقط لديه واحد رئيسي يلزم مساحة العمل أصل دليل**——سياسة تحليل `SessionHeader.cwd`؛ مقدار خارج يمكن كتابة أصل دليل لا يخص `SandboxExecutionPolicy`.
- **فقط حد ملف عملية نمط**——`SandboxMode` إدارة تحكم ملف عملية؛ شبكة و عملية سياسة لا في ذلك مفردات في، لذلك هذا داخل لا يوجد حد هو جمع دوران زر.
- **متعمد عام وصف مؤقت منطقة مجال**——قوي صنع تنفيذ خلفية سوف منح إعطاء مختلف منصة مؤقت منطقة مجال، هذه منطقة مجال في سياسة تحليل بعد عندئذ سوف اختيار تحديد، لذلك لا يمكن في حالي سياق في مثل فعلي قطعة رفع.
