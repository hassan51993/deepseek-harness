# @deepseek-ai/dsh-sandbox

[English](README.md) | العربية

## عام وصف

استخدام `dsh-sandbox`، يمكن يجعل عملية فرعية و ذلك إرسال توليد كل عملية في تدريجي استدعاء ملف وصول سياسة تحت تشغيل. أمر يمكن منع توقف كتابة (`read-only`) ، فقط كتابة مساحة العمل (`workspace-write`) ، أو لا تلقي حد أرض تشغيل (`danger-full-access`). لا يمكن قوي صنع تنفيذ الذي طلب نمط وقت، استدعاء بـ `SANDBOX_UNAVAILABLE` فشل، أبدا سوف لا تلقي حد أرض تشغيل. استدعاء يتم رفض بعد، نموذج يمكن طلب واحد صارم إطار أكثر عرض نمط، تسليم من شخص صنف دفعة دقيق مرة. هذا نوع حد فقط ملائم لأجل و مضيف مشترك داخل نواة و نظام الملفات عملية؛ حاجة عزل كامل بيئة وقت، طلب استخدام حاوية،microVM أو بعيد مسار منفذ.

## استخدام هذه الحزمة

سوف هذا خدمة و واحد خلفية و واحد تلقي حد مستهلك تركيب، مستهلك تشغيل كل بند أمر كل سوف في أنت تحليل سياسة تحت تنفيذ——أنت فقط يرى عزل نتيجة و ذلك قوي صنع تنفيذ كامل درجة، دائم بعيد نظر لا إلى runner.

### أي وقت اختيار

عند تركيب حاجة في مضيف آلة فوق عزل عملية فرعية وقت اختيار هذه الحزمة: محلي خلفية و تلقي حد منفذ كل تنفيذ هذا عدد اتفاق، لذلك في `ctx.sandbox` بعد تركيب `sandbox-local`، في `ctx.shell` بعد تركيب تلقي حد منفذ، حينئذ قدرة جعل كل مرة bash أو pwsh استدعاء افتراضي في حد تحت تشغيل. عند عملية يجب في عزل بيئة في وقت التشغيل طلب آخر اختيار خطة——حاوية،microVM أو بعيد مسار منفذ سوف استبدال كامل `ctx.shell`/`ctx.fs` قدرة، بينما لا هو في هذا داخل إضافة خلفية.

### عزل أمر

تركيب خدمة، خلفية و تلقي حد منفذ؛ مع مرفق تركيب من[أساس أساس تركيب حزمة (base bundle)](../../bundle/base/cordis.patch.yml) تعريف.

```yaml
- id: sandbox
  name: '@deepseek-ai/dsh-sandbox-local'     # the per-platform backend provider (ctx.sandbox)
- id: sandbox-policy
  name: '@deepseek-ai/dsh-sandbox-policy'    # the deployment default mode and workspace-write root
  config:
    mode: workspace-write                    # the deployment default every session starts from
    workspaceRoot: !!js process.cwd()        # the boundary workspace-write may write under
- id: bash
  name: '@deepseek-ai/dsh-bash-sandbox'      # the confined executor behind ctx.shell
```

استخدام هذا تركيب وقت،bash استدعاء في `workspace-write` تحت تلقي حد تشغيل: مساحة العمل داخل كتابة نجاح، مساحة العمل خارج كتابة يتم رفض، نموذج يمكن عبر تحت وجه رفع حق مسار استعادة.

### نمط و قوي صنع تنفيذ

نمط إشارة واضح أمر يمكن تنفيذ ملف عملية؛ قوي صنع تنفيذ كامل درجة تقرير إبلاغ خلفية مقابل هذه عملية إدارة ولاية مسار درجة.

| نمط | فاعلية نتيجة |
|---|---|
| `read-only` | رفض كتابة، مطلوب sink(مثل `/dev/null`) حذف خارج |
| `workspace-write` | سماح كتابة مساحة العمل أصل دليل و خلفية تعريف مؤقت منطقة مجال |
| `danger-full-access` | التفاف مرور عزل؛ مستهلك مباشر spawn أصلي argv |

قوي صنع تنفيذ تدريجي استدعاء تقرير إبلاغ:`full` يمثل خلفية إدارة ولاية نمط تحمل وعد كل ملف عملية،`partial` يمثل نشط حركة خلفية أو مقارنة قديم داخل نواة ABI فقط إدارة ولاية فرعي تجميع——Windows ACL ملف و مقارنة قديم Landlock ABI هو حالي جزء قوي صنع تنفيذ حال شكل، حاجة قطعا مقابل حد مستهلك يمكن رفض أو نحو فوق كشف هو جمع.

### يتم رفض استدعاء و رفع حق

تلقي حد استدعاء يتم رفض وقت، عملية سوف تقرير إبلاغ إشارة واضح نمط رفض علامة——`[sandbox: file access denied under <mode> mode]`——تركيب إعلان رفع حق قدرة وقت أيضا سوف إعطاء خروج رفع حق تلميح. نموذج يمكن استخدام `sandbox_permissions`(كاف بـ وضع سطر الأكثر ضيق أكثر عرض نمط) إضافة `justification` إعادة محاولة مرة تماما نفسه استدعاء؛ مستخدم سوف يرى مرة مراجعة دفعة تلميح، يمكن اختيار سماح مرة، رفض أو إلغاء. أكثر عرض نمط حاجة مراجعة دفعة، كما فقط أثر في هذا مرة استدعاء. تكرار إشارة تحديد استدعاء توليد فاعلية نمط بلا حاجة مراجعة دفعة يكفي نجاح؛ أكثر ضيق هدف ما زال بلا فاعلية.

### لذا عائق إغلاق سلوك

لا يوجد خلفية قدرة قوي صنع تنفيذ الذي طلب نمط وقت، استدعاء بـ `SANDBOX_UNAVAILABLE` فشل، بينما لا هو لا تلقي حد أرض تشغيل؛ خطأ نص سوف إشارة واضح ناقص منصة runner. بدء بعد فشل خلفية أيضا سوف تقرير إبلاغ بنية تحويل runner فشل توقيع، لذلك ضرر تالف صندوق رملي يمكن و أمر فشل منطقة قسم فتح.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير اتفاق خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **نفس تنفيذ بيئة.** نظام الملفات، عملية فرعية و صندوق رملي مزود استخدام نفس نظام الملفات و داخل نواة. بعيد طرف تركيب استبدال هذا ثلاثة عدد مزود، و في هذا بيئة في مختلف خطوة تحليل حد.
- **سياسة مع استدعاء نقل تمرير.** `SandboxPolicy` تدريجي استدعاء يحمل، أبدا في مزود فوق ثابت: اثنان عدد مستهلك يمكن معا حسب مختلف سياسة عزل، نيل دفعة رفع حق إعادة محاولة فقط هو استخدام أكثر عرض سياسة إرسال بدء جديد استدعاء. افتراضي و تحليل هو مستهلك صريح خطوة.
- **لذا عائق إغلاق.** `confine()` مختلف خطوة إرجاع لأجل قوي صنع تنفيذ حد argv، أو بـ `SandboxUnavailableError` رفض؛ أبدا سماح ساكن صامت بلا حد وضع سطر، وظيفة استكشاف قياس لأجل وسيط قطع كثير runner سلسلة.
- **موحد واحد رفض و رفع حق مفردات.** علامة و تلميح نص و صارم إطار أكثر عرض مرحلة سلم كل وضع في هذا داخل، جعل bash و fs بيت عائلة لن عائم نقل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`SandboxProvider` خدمة، نمط/قوي صنع تنفيذ/سياسة نوع، لذا عائق إغلاق خطأ |
| [`src/escalation.ts`](src/escalation.ts) | رفع حق مفردات: أكثر عرض نمط مرحلة سلم، معامل تحقق، رفض و تلميح علامة، مراجعة دفعة تحرير ترتيب |
| [`src/roots.ts`](src/roots.ts) | يمكن كتابة أصل دليل دفع توجيه،Seatbelt profile و عملية داخل fs شبكة شريط مشترك |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ حذف الذي تابع seam قوي صنع تنفيذ اتفاق خارج، هذه الحزمة لا عام مستقل حدث تسلسل أو متغير بيانات علاقة. |

### رفع حق تحرير ترتيب

مرحلة سلم هو غلاف إغلاق جدول——`read-only` يمكن رفع حق إلى `workspace-write` أو `danger-full-access`،`workspace-write` فقط قدرة رفع حق إلى `danger-full-access`——في تنفيذ وقت فحص، أبدا كتابة أداة schema،schema قطعة رفع إبقاء غلاف إغلاق هدف مفردات.[`approveEscalation`](src/escalation.ts) في طلب تكرار حالي نمط وقت بلا حاجة مراجعة دفعة حينئذ إرجاع هذا نمط، رفض أكثر ضيق أو لا دعم حمل هدف، و لـ أكثر عرض نمط طلب مراجعة دفعة. استدعاء جهة أولا تحقق `sandbox_permissions`/`justification` إعداد مقابل.

### يمكن كتابة أصل دليل

`workspace-write` معنى طعم حال «مساحة العمل أصل دليل إضافة مضيف مؤقت منطقة مجال»:`writableRoots` بـ مواصفة تحويل طريقة دفع توجيه هذا أبيض اسم مفرد، تحليل رمز رقم رابط و ذهاب إعادة، جعل Seatbelt profile و عملية داخل fs شبكة شريط منح إعطاء تماما نفسه أصل دليل.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### بين وصل حد خطأ

#### نموذج يرى ماذا

عبر [`dsh-bash-sandbox`](../../shell/bash-sandbox/README.ar.md) و [`dsh-tool-bash`](../../shell/tool-bash/README.ar.md) ، طلب تلقي حد نمط لا يوجد متاح خلفية وقت سوف إنتاج رمز خطأ `SANDBOX_UNAVAILABLE` و تحت جهة دقيق خطأ؛ تنفيذ مدة runner فشل سوف إلحاق ` Runner failure: <detail>`.

##### دقيق خطأ

```markdown
sandbox mode "<mode>" is requested but no sandbox backend is usable on this host; refusing to run the command unconfined. Install bubblewrap or run a Landlock-enforcing kernel (Linux), ensure sandbox-exec is usable (macOS), or ensure the ACL restricted-token runner can start (Windows) — otherwise switch the consumer to danger-full-access.
```

#### Token أثر

شرط صفة خطأ نص مقابل هذا مرة استدعاء مرئي، و إبقاء في تاريخ في مباشر إلى ضغط (compaction).

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### رفع حق طلب و نتيجة

#### نموذج يرى ماذا

يتم رفض استدعاء سوف عرض علامة `[sandbox: file access denied under <mode> mode]`، تركيب إعلان رفع حق قدرة وقت أيضا سوف عرض تلميح `[sandbox: escalation available — retry this exact <subject> once with sandbox_permissions (the narrowest wider mode that suffices) + justification; the approval prompt asks the user]`. إعادة محاولة يحمل `sandbox_permissions` و `justification`؛ مستخدم `allowed-once`/`rejected`/`cancelled` قرار يصبح هذا استدعاء نتيجة نص.

#### Token أثر

فقط لديه يتم رفض استدعاء خطأ و أي رفع حق نتيجة نص مرئي؛ اثنان من كل سوف إبقاء في تاريخ في مباشر إلى ضغط.

#### KV Cache أثر

فقط إلحاق؛ رفع حق نص يقع في إبقاء بادئة بعد، لن جعل قد ذاكرة مؤقتة بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا seam أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة. هو جمع هو حالي حزمة قيد، لا هو عام صندوق رملي مقابل مقارنة أو مهمة تراكم ضغط.

- **ملف عملية هو كامل سياسة مفردات**——هذا seam لا جدول بلوغ شبكة، عملية، نظام استدعاء، ضبط تجهيز أو اعتماد حد.
- **فقط دعم حمل و مضيف مشترك نظام الملفات و داخل نواة حد**——حاوية،microVM و بعيد مسار تنفيذ حاجة استبدال قدرة تنفيذ، بينما لا هو في هذا إضافة مزود.
- **رفض تقرير إبلاغ هو واحد نوع stderr جهة قول**——هذا seam إرجاع خلفية توقيع، بينما غير نوع تحويل وقت التشغيل رفض عبر طريق، حاجة تصنيف مستهلك يجب من عملية فرعية إخراج دفع قطع.
- **Runner تشخيص استخدام حمل داخل عبر طريق**——خروج حالة و stderr دليل لا يمكن إثبات مطابقة سطر من أي عدد عملية كتابة، لذلك لذا معنى نموذج محاكاة runner تلقي حد عملية فرعية ممكن صنع صار خطأ متاح صفة أو تشخيص عودة بسبب؛ هذا لا يمكن التفاف مرور عزل، حمل خارج runner حالة عبر طريق مؤقت مؤقت تنفيذ.
- **كل سياق فقط لديه واحد مزود**——معا تركيب مختلف صندوق رملي آلية حاجة مزود درجة مرحلة سلم أو مستقل Cordis سياق؛ استدعاء جهة تدريجي استدعاء اختيار سياسة، بينما غير خلفية معرف.

### ملاحظة تطوير

</details>
