# @deepseek-ai/dsh-tool-fs-search

[English](README.md) | العربية

## عام وصف

استخدام `dsh-tool-fs-search` لـ نموذج توفير محلي مساحة العمل في `glob` ملف اكتشاف و `grep` محتوى بحث. بحث بلا حاجة في مضيف فوق تثبيت `rg`، أيضا بلا حاجة نظام الملفات مزود؛ نتيجة متبادل مقابل في عمل دليل، و يتضمن إخفاء و تجاهل اختصار ملف لكن ترتيب حذف VCS بيانات وصفية. يمكن إعداد حد أعلى قيد داخل ربط إخراج؛ تركيب اختياري spill تخزين بعد، بلوغ إلى حد أعلى نتيجة ما زال يمكن كامل استعادة. إذا يحتاج قراءة، كتابة أو تحرير ملف، طلب اختيار نفس درجة `dsh-tool-fs` حزمة.

## استخدام هذه الحزمة

في `ctx.subprocess` خلفية بعد تركيب أداة؛ بلا حاجة مضيف `rg` تثبيت، أيضا بلا حاجة نظام الملفات مزود. نموذج مع بعد نيل نيل حسب تعديل وقت ترتيب ملف اكتشاف و حسب سطر مجموعة نسج محتوى بحث، اثنان من كل محدود و تلقي مهلة منع حماية.

### الأكثر صغير تركيب

واحد عملية فرعية خلفية، لكن بعد هو أداة؛spill خلفية لـ اختياري، جعل بلوغ إلى حد أعلى نتيجة يمكن كامل استعادة.

```yaml
- name: '@deepseek-ai/dsh-subprocess-local'
- name: '@deepseek-ai/dsh-tool-fs-search'
  config:
    sampleOverCapGlobResults: false
- name: '@deepseek-ai/dsh-spill-local'
```

`sampleOverCapGlobResults` هو لا بد ملء بند كما لا يوجد رجوع قيمة: نشر يجب صريح اختيار تجاوز مرور حد أعلى وقت ترتيب اتفاق. صيغة تحويل spill نجاح وقت، اثنان نوع نمط كل سوف في spill ناتج في إبقاء كامل ترتيب تسلسل جدول.

### أداة

| أداة | معامل | سلوك |
|---|---|---|
| `glob` | `pattern`،`path?` | فحص بحث مسار مطابقة glob نمط ملف، يتضمن إخفاء و تجاهل اختصار ملف لكن ترتيب حذف VCS بيانات وصفية؛ لا يحتوي `/` نمط مطابقة مهمة معنى عميق درجة أساس اسم، لذلك `*` مطابقة كامل شجرة شجرة؛ كامل نتيجة إبقاء حسب تعديل وقت ترتيب |
| `grep` | `pattern`،`path?`،`include?` | استخدام ripgrep صحيح فإن بحث ملف محتوى، و حسب ملف قسم مجموعة إرجاع `Line N: <preview>` مطابقة؛`include` هو واحد صحيح نحو glob مرور ترشيح جهاز، فاصلة رقم قسم فصل قائمة و لا تحديد قيمة سوف يتم قبل وضع رفض |

معتاد قاعدة ميزانية لا دخول موجه إلى نموذج schema: حاجة دورة حافة سياق نموذج استخدام `read` قراءة مطابقة ملف، حاجة لاحق نتيجة نموذج التزام دوران إرجاع spill locator فحص بحث تلميح.

### إعداد

`sampleOverCapGlobResults` لـ لا بد ملء؛ ذلك بقية مفتاح هو اختياري بحث حد أعلى، قيمة افتراضية مثل تحت.

| مفتاح | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `sampleOverCapGlobResults` | بلا (لا بد ملء) | `true` في قمة طبقة بند بين مقابل تجاوز مرور حد أعلى `glob` صفحة أخذ مثال؛`false` إبقاء حسب تعديل وقت ترتيب قبل جزء |
| `globMaxResults` | `100` | مرة `glob` استدعاء داخل ربط عرض الأكثر كبير مسار عدد |
| `grepMaxMatches` | `250` | مرة `grep` استدعاء داخل ربط إبقاء الأكثر كبير مستو فرش مطابقة عدد؛ لاحق مطابقة كتابة صيغة تحويل spill ناتج |
| `grepMaxLineBytes` | `2000` | كل بند مطابقة سطر معاينة بايت حد أعلى، إبقاء UTF-8 حد |
| `rawOutputMaxBytes` | `20000000` | بحث سوف تحليل كامل أصلي `rg` stdout حد أعلى؛ أكثر كبير أصلي إخراج بـ `SEARCH_RAW_OUTPUT_OVERFLOW` فشل |
| `timeoutMs` | `30000` | مرفق إضافة إلى اثنان عدد أداة تنسيق عمل صيغة استدعاء الأداة ميزانية، عبر `exec.signal` قوي صنع تنفيذ |
| `graceMs` | `3000` | subprocess seam في `timeoutMs` خارج منح إعطاء إنهاء ترقية عرض حد مدة |
| `stderrMaxBytes` | `65536` | `rg` stderr تشخيص ذيل جزء ميزانية |
| `searchMetaMaxBytes` | `65536` | مرة بحث تسلسل تحويل `presentationMeta` بايت حد أعلى؛ تجاوز خروج جزء إسقاط ذيل جزء مجموعة/مسار |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tool-fs-search) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### نشر اشتراط

Node نشر في تلقي دعم حمل macOS،Linux و Windows هدف فوق نيل نيل `@vscode/ripgrep` منصة حزمة؛Python SDK wheel حزمة يأخذ هدف أصلي اثنان دخول صنع نسخ إلى مفرد ملف وقت التشغيل جانب، بصفة `-rg` مرافق مع ملف. اثنان نوع تحميل جسم متساو لا اشتراط مضيف تثبيت `rg`. إرجاع مسار متبادل مقابل في تحليل بعد عمل دليل عرض (لديه جلسة cwd وقت استخدام جلسة cwd) ، فقط لديه هذا عمل دليل و نظام الملفات أصل دليل هو نفس مساحة العمل وقت، عندئذ قدرة استخدام `read` متابعة قراءة.

### فشل و استعادة

بحث فشل يحمل هذه الحزمة تعريف رمز خطأ:`SEARCH_INVALID_PATTERN`(ripgrep رفض صحيح فإن أو glob) ،`SEARCH_FAILED`(بدء فشل، هدف غير ممكن وصول، إشارة إنهاء أو `--json` إخراج صيغة خطأ) ،`SEARCH_RAW_OUTPUT_OVERFLOW`(أصلي إخراج تجاوز مرور حد أعلى) و `SEARCH_ABORTED`(تنسيق عمل صيغة مهلة أو استدعاء جهة إلغاء). خروج 0 يمثل نجاح كما لديه نتيجة، خروج 1 يمثل نجاح فارغ بحث؛ نموذج معامل خطأ ما زال هو عادي أداة معامل خطأ.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير بحث أداة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

محلي مساحة العمل اكتشاف يوم لكن هو من عملية دعم حمل `rg` سير العمل؛ إذا يأخذ بحث وضع إلى `ctx.fs` فوق، حينئذ سوف إجبار جعل كل نظام الملفات خلفية توسيع بحث API.subprocess seam مسؤول spawn تنفيذ، عملية شجرة إنهاء، بيئة تنظيف و محدود إخراج التقاط؛ هذه الحزمة مسؤول schema، معامل تحقق،argv بنية صنع، تحليل، إبقاء، صيغة تحويل نتيجة spill و مهلة إعلان. أداة أبدا كشف خلفية مهمة——فقط لديه في `rg` خروج، يتم تنسيق عمل صيغة مهلة إنهاء، يتم في توقف أو فشل بعد، استدعاء عندئذ سوف إرجاع.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config`، أداة تركيب، حد أعلى تحقق |
| [`src/glob.ts`](src/glob.ts) | `glob` schema،argv، تحليل، داخل ربط أخذ مثال، صيغة تحويل |
| [`src/grep.ts`](src/grep.ts) | `grep` schema،argv،`--json` تحليل، معاينة إبقاء، صيغة تحويل |
| [`src/search-core.ts`](src/search-core.ts) | مشترك spawn مساعدة يد،`SEARCH_*` خطأ،spill تسليم وصل، عمل دليل متبادل مقابل عرض |
| [`src/presentation.ts`](src/presentation.ts) | بحث بطاقة بيانات وصفية إسقاط |
| [`src/direct-call.ts`](src/direct-call.ts) | spill بعد معالجة مباشر استدعاء نتيجة قبول |

### بحث مثل أي تشغيل

كل مرة استدعاء تحليل تحزيم اثنان دخول صنع (`@vscode/ripgrep`، أو pkg مفرد ملف وقت التشغيل في يمكن تنفيذ برنامج `-rg` مرافق مع ملف) ، قبل وضع `--no-config`، جعل مضيف `RIPGREP_CONFIG_PATH` لا يمكن نحو لا تلقي قيد spawn حقن `--pre` مسبق معالج، و يأخذ كل نموذج تحكم قيمة بصفة عادي argv عنصر عنصر نقل دخول——لا وجود shell طبقة، لذلك لا تعلق و shell جذب رقم معالجة.collect نمط ميزانية حد كامل stdout و stderr ذيل جزء؛lossy stdout قراءة بـ `SEARCH_RAW_OUTPUT_OVERFLOW` فشل، بينما لا هو تحليل ساكن صامت لا كامل تدفق. أداة من لا قراءة أصلي spill مسار.

### اثنان صنف ميزانية، اثنان صنف ناتج

أصلي stdout و stderr هو داخلي نقل دقيق عقدة؛ أداة بداية نهاية يأخذ كامل نتيجة استلام تجميع إلى داخل تخزين في، فقط لديه داخل ربط صفحة ضبط لديه حد أعلى. عند استدعاء إنتاج تجاوز مرور داخل ربط حد أعلى منطق نتيجة وقت، كل قوة بينما لـ spill سوف يأخذ كامل صيغة تحويل معاينة حفظ إلى spill تخزين، صفحة يحمل ذلك locator؛ كامل قيمة لن دخول نموذج سياق قسم إرسال فإن قفز مرور spill.spill ناقص أو فشل وقت إبقاء داخل ربط صفحة، و تقرير إبلاغ كامل نتيجة لا يمكن حفظ——أبدا سوف يصبح خطأ. استلام تجميع و spill تسليم وصل يقع في `src/search-core.ts` و `src/presentation.ts`.

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى محتوى

تجميع وقت، كل مقطع سقوط عبر `ctx.tools.get(name, scope)` فحص مقابل أداة، فقط في ذلك مرئي وقت إخراج.grep مقطع سقوط فقط في read مرئي وقت يتضمن لاحق استخدام read جملة فرعي. نفس تلقي دعم حمل أداة تجميع دمج تحت، أصل نص و مقطع سقوط ترتيب إبقاء ثابت، يشمل عبر `run_code` كشف PTC قدرة. هذا نوع حسب scope اختيار نص آلية ملائم لأجل توجيه النظام مقطع سقوط. أداة schema وصف ما زال هو تسجيل وقت نص؛ أداة جسم بينما قول، أي جعل scope إخفاء read،grep schema ما زال سوف دفع ترشيح read. بعد لم تنفيذ حسب scope تغيير schema إجراء لفظ.

##### تفعيل `sampleOverCapGlobResults: true` وقت Glob إشارة توجيه

```markdown
Use the glob tool — not shell find — to discover files by path pattern. A pattern with no "/" matches basenames at any depth, so "*" matches every file in the tree rather than its top level. Results are files only, never directories, and include hidden and ignored files: a result that fits comes back in modification-time order, while a larger one is sampled across top-level entries, so it spans the tree instead of one subtree.
```

##### تفعيل `sampleOverCapGlobResults: false` وقت Glob إشارة توجيه

```markdown
Use the glob tool — not shell find — to discover files by path pattern. A pattern with no "/" matches basenames at any depth, so "*" matches every file in the tree rather than its top level. Results are files only, never directories, and include hidden and ignored files: a result that fits comes back in modification-time order, while a larger one keeps the modification-time-ordered head.
```

##### Grep إشارة توجيه

```markdown
Use the grep tool — not shell grep or rg — to search file contents. Use read on a matched file when you need surrounding context.
```

#### Token أثر

إشارة توجيه صار هذا أخذ قرار في مرئي أداة؛ لا بد ملء أخذ مثال اختيار قرار اعتماد أي واحد glob تغيير جسم.

#### KV Cache أثر

مرئي أداة تجميع دمج، إضافة أثر مجال، أخذ مثال اختيار و إشارة توجيه نص ثابت وقت بادئة مستقر. حد، تنشيط،dispose(مورد تحرير) أو تغيير اختيار ممكن من أول عدد تغير مقطع سقوط بدء جعل إعادة استخدام بطلان.

### أداة schema

#### نموذج يرى محتوى

glob وصف إعلان إعداد تجاوز مرور حد أعلى ترتيب طريقة. توليد [`glob` و `grep` schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-fs-search) استخدام `sampleOverCapGlobResults: true`؛ أداة بلا شرط تسجيل.

#### Token أثر

أداة مرئي وقت كل طلب لديه ثابت schema صار هذا.

#### KV Cache أثر

أداة مرئي صفة و تعريف ثابت وقت بادئة مستقر. تسجيل دورة الحياة أو أثر مجال حد ممكن من رقم واحد تغيير schema token بدء جعل إعادة استخدام بطلان.

### نتيجة و spill تلميح

#### نموذج يرى محتوى

`glob` كل سطر إرجاع واحد مسار؛`grep` في كل مسار تحت قسم مجموعة عرض `Line <line>: <preview>` مطابقة. فارغ بحث إرجاع `No files found` أو `No matches found`. بلوغ إلى حد أعلى نتيجة بـ حذف حساب عدد ربط ذيل، و مرفق spill locator و خلفية فحص بحث تلميح، أو شرح كامل نتيجة لا يمكن حفظ. تفعيل `sampleOverCapGlobResults: true` وقت، تجاوز مرور حد أعلى `glob` صفحة حسب فعلي بحث أصل صحيح تحت جهة بند جولة تحويل أخذ مسار، صفحة قدم شرح أخذ مثال اعتماد حسب و ذلك تغطية قمة طبقة بند عدد؛`false` وقت صفحة هو حسب تعديل وقت ترتيب قبل جزء، و إبقاء عادي حد أعلى نتيجة صفحة قدم.spill ناتج بداية نهاية يحتفظ حسب تعديل وقت ترتيب كامل قائمة.

#### Token أثر

داخل ربط مسار و مطابقة تلقي `globMaxResults`،`grepMaxMatches` و `grepMaxLineBytes` قيد؛ استدعاء و ذلك إبقاء نتيجة في ضغط (compaction) قبل إبقاء في تاريخ في.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى تتبع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### أداة خطأ

#### نموذج يرى محتوى

فشل يتم مواصفة تحويل لـ `Error: <message>`، و يحمل بنية تحويل `SEARCH_INVALID_PATTERN`،`SEARCH_FAILED`،`SEARCH_RAW_OUTPUT_OVERFLOW` أو `SEARCH_ABORTED` بيانات وصفية توفير استدعاء جهة استخدام.

#### Token أثر

فقط لديه فشل استدعاء سوف زيادة هذه إبقاء token.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى تتبع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح بحث أداة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام بحث مقابل مقارنة أو مهمة تراكم ضغط.

- **بحث و ملف وصول لا يوجد مشترك مساحة العمل إثبات**——فقط لديه عند عمل دليل و نظام الملفات أصل دليل إشارة نحو نفس مساحة العمل وقت، إرجاع مسار عندئذ يمكن متابعة قراءة؛ هذه الحزمة لا تنفيذ وقت التشغيل عبر خدمة تحقق.
- **تحزيم اثنان دخول صنع ثابت في اعتماد إصدار فوق**——Node نشر استخدام `@vscode/ripgrep` اختيار إصدار؛Python مفرد ملف وقت التشغيل سوف مقابل هدف أصلي إصدار نسخ لـ مطلوب `-rg` مرافق مع ملف. لا دعم حمل منصة أو ضرر تالف تثبيت سوف بـ `SEARCH_FAILED` جعل استدعاء فشل،Python وقت التشغيل حزمة فإن سوف في بدء قبل رفض نقص قليل مرافق مع ملف تثبيت. بعيد مسار أو وهمي محاكاة نظام الملفات حاجة مشترك وضع مساحة العمل أو آخر عدد بحث مستهلك.
- **schema فقط كشف واحد محدود صفحة**——انحراف نقل قسم صفحة، كبير صغير كتابة فتح صلة، بديل إخراج نمط و مزود دعم دعم اكتشاف ما زال لا في هذه الحزمة نطاق داخل؛ بلوغ إلى حد أعلى كامل إخراج حاجة spill خلفية.
- **تفعيل أخذ مثال وقت فقط حسب بحث أصل صحيح تحت جهة رقم واحد مقطع مسار قسم مجموعة**——تجاوز مرور حد أعلى `glob` صفحة في هذه قمة طبقة بند بين مستو توازن، لذلك تجميع في في أكثر عميق موضع نتيجة في هذا طبقة درجة لـ تحت ما زال سوف عرض لا متساو؛ تمرير عودة مستو توازن يتم تأجيل.
