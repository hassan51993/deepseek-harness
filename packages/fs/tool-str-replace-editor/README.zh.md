# @deepseek-ai/dsh-tool-str-replace-editor

[English](README.md) | العربية

## عام وصف

`dsh-tool-str-replace-editor` توفير أساس في `ctx.fs` مستقل موجه إلى نموذج `str_replace_editor` أداة:`view` عرض حمل سطر رقم ملف محتوى أو ضحل طبقة دليل قائمة،`create` إنشاء جديد ملف،`str_replace` تطبيق وحيد حرف وجه كمية استبدال،`insert` في اختيار تحديد حد موضع إدراج دخول سطر. هو يمكن و حمل دائم Bash، مرة صفة Bash، صندوق رملي Bash أو أخرى طرفية واجهة تركيب. تعديل عملية التزام حراسة و fs بيت عائلة ذلك بقية جزء نفسه تحرير قبل قراءة سياسة و صندوق رملي محيط شريط، أداة جسم من الذي تركيب خلفية و سياسة إضافة قوي صنع تنفيذ. عند نشر حاجة Claude Code ريح إطار، استخدام قطعا مقابل مسار مفرد واحد تحرير جهاز أداة وقت اختيار هو؛`dsh-tool-fs` حزمة توفير بديل `read`/`write`/`edit` طقم عنصر.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند نموذج ينبغي عبر ناضج معرفة `view`/`create`/`str_replace`/`insert` أمر مفردات في قطعا مقابل مسار فوق تحرير ملف وقت، يأخذ أداة و `ctx.fs` خلفية (و حاجة منع حماية تغيير وقت سياسة إضافة) واحد بدء تركيب.

### الأكثر صغير تركيب

واحد خلفية، اختياري أرض إضافة سياسة إضافة، لكن بعد هو أداة؛ تحرير جهاز يمكن و أي طرفية واجهة تركيب.

```yaml
- name: '@deepseek-ai/dsh-fs-local'
- name: '@deepseek-ai/dsh-fs-observation-policy'
- name: '@deepseek-ai/dsh-tool-str-replace-editor'
```

### إعداد

| مفتاح | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `maxOutputChars` | `16000` | ملف و دليل فحص نظر نتيجة إبقاء بادئة محرف عدد |
| `description` | `Custom editing tool for viewing, creating and editing files`(كثير سطر) | موجه إلى نموذج أداة وصف |

### أمر

`view` إرجاع من 1 بدء تحرير رقم ملف محتوى (إبقاء صنع جدول رمز، لذلك عرض نص ما زال يمكن بصفة صالح حرف وجه كمية استبدال إدخال) أو تجاهل اختصار إخفاء، اعتماد و Python ذاكرة مؤقتة بند اثنان طبقة دليل قائمة.`create` إنشاء جديد ملف، و رفض تغطية قائم ملف. اختيار تحديد أمر لا استخدام مخصص استخدام حقل يمكن يتضمن `null` احتلال موضع رمز؛ لا بد ملء حقل ما زال إبقاء لا بد ملء،`view_range: null` اختيار كامل عرض،`str_replace.new_str: null` سوف يتم رفض، لذلك حذف محتوى يجب حذف هذا حقل.`str_replace` اشتراط حرف وجه كمية وحيد مطابقة، خطأ فقط استخدام عام `old_str` مفردات؛`insert` التزام دوران الذي اختيار صفر أساس إدراج دخول حد، لن خفي صيغة تكملة ذيل تبديل سطر. تعديل عملية سوف إبقاء طلب تحرير نطاق خارج صنع جدول رمز.

### فشل و استعادة

`view`،`str_replace` أو `insert` حدوث بيانات وصفية لم أمر في وقت، أداة سوف في إرجاع `FS_NOT_FOUND` قبل سجل تأكيد ناقص، لذلك لاحق `create` يمكن عبر قد تركيب سياسة منع حماية إنشاء مسار استعادة خارجي حذف مسار؛ ناقص حالة أبدا سوف تخويل `str_replace` أو `insert`. منع حماية تغيير وراثة سياسة إضافة رمز خطأ و استعادة إشارة أمر——`FS_NOT_OBSERVED`(أولا قراءة ملف مجددا إعادة محاولة) ،`FS_STALE_VERSION`(أولا إعادة قراءة مجددا إعادة محاولة)——صندوق رملي رفض فإن جدول الآن لـ `[sandbox: file access denied under <mode> mode]` علامة. مسار يجب هو قطعا مقابل مسار؛ متبادل مقابل مسار سوف يتم رفض و إعطاء خروج تلميح.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير تحرير جهاز أداة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا أداة هو أساس في `ctx.fs` مفرد واحد schema، أربعة عدد أمر. تعديل عملية أبدا حمل حال ذاتي ذات زائف ضبط مباشر لمس اصطدام مزود: كل عملية كل تشغيل `fs/write-intent` أو `fs/edit-intent` waterfall(شلال نشر صيغة حدث) بـ أخذ نيل سياسة إضافة منع حماية، في قد تركيب `ctx.fs` فعلي تطبيق صندوق رملي حد وقت تحليل كل مرة استدعاء صندوق رملي سياسة، و يأخذ قوي صنع تنفيذ تفويض حمل إعطاء مزود.`str_replace` و `insert` أيضا سوف إعادة قراءة ملف، و في لا يوجد سياسة إضافة توفير منع حماية وقت يأخذ مراقبة إلى إصدار بصفة مقارنة مقارنة و تسليم تبديل أساس أساس.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | كامل أداة:schema، أمر قسم إرسال، فحص نظر تصيير، تعديل سياسة |

### كل أمر مثل أي تشغيل

كل أمر كل أولا تحليل قطعا مقابل مسار؛ تعديل عملية مع بعد التزام دوران نفس بند مشترك مسار——سياسة منع حماية، مزود قوي صنع تنفيذ، نجاح بعد سجل `fs/observed`——بينما `view` فقط تنفيذ stat و تصيير. كامل أداة——schema، أمر قسم إرسال و فحص نظر تصيير——كل يقع في `src/index.ts`.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى محتوى

توليد [`str_replace_editor` schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-str-replace-editor) ، يتضمن إعداد `description`. هذا إضافة لا مساهمة مستقل توجيه النظام مقطع.

#### Token أثر

`str_replace_editor` مرئي وقت إنتاج ثابت schema صار هذا.

#### KV Cache أثر

إعداد وصف و schema ثابت وقت بادئة مستقر.

### أداة نتيجة

#### نموذج يرى محتوى

فحص نظر عملية إرجاع حمل سطر رقم نص أو ضحل طبقة دليل قائمة. استدعاء سوف توفير ملف موضع، إنشاء/استبدال استدعاء أيضا سوف نحو عرض طبقة توفير diff بطاقة. تعديل عملية إرجاع بسيط نظيف تأكيد. طويل فحص نظر نتيجة إبقاء بادئة و إلحاق قطع قطع تلميح.

#### Token أثر

مع بيانات تغير، و تلقي `maxOutputChars` و ثابت قطع قطع تلميح قيد.

#### KV Cache أثر

أداة نتيجة بـ إلحاق طريقة يقع في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح تحرير جهاز أداة أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام تحرير جهاز مقابل مقارنة أو مهمة تراكم ضغط.

- **عملية موجه إلى UTF-8 نص**——لا دعم حمل اثنان دخول صنع ملف.
- **`str_replace` لحظة معنى رفض صفر مطابقة أو كثير مطابقة**——هو لا يوجد `replace_all` معامل.
- **كل تعديل عملية كل سوف مرور مرور قد تركيب سياسة و صندوق رملي**——`fs/write-intent` أو `fs/edit-intent` تحليل حالي جلسة صندوق رملي سياسة، و يأخذ قوي صنع تنفيذ تفويض حمل إعطاء قد تركيب نظام الملفات و سياسة إضافة، لذلك لم تركيب هو جمع نشر سوف نيل إلى بلا شرط تغيير.
