# ssh/ — POSIX بعيد طرف تنفيذ مزود

[English](README.md) | العربية

## عام وصف

هذا بيت عائلة سوف ملف، عادي عملية، طرفية و صندوق رملي تنفيذ وضع في نفس منصة POSIX SSH رئيسي آلة فوق،Harness إبقاء في محلي. مشترك OpenSSH اتصال و قد تثبيت مساعد مساعدة برنامج دعم حمل قائم نظام الملفات، عملية فرعية و صندوق رملي واجهة. ملائم لأجل مستهلك التزام حراسة مزود مسار دلالة headless أو ذاتي تعريف إعداد تركيب.
