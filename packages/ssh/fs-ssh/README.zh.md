# @deepseek-ai/dsh-fs-ssh

[English](README.md) | العربية

## عام وصف

`dsh-fs-ssh` في SSH مساعد مساعدة عملية نظام الملفات في توفير `ctx.fs`. ملف أداة قراءة كتابة ملف و بعيد طرف Bash، طرفية، لغة خادم و Node برنامج يرى ملف متسق. بعيد طرف مسار مواصفة تحويل، إصدار حفظ حماية و أصل فرعي تعديل استخدام مساعد مساعدة برنامج جانب تثبيت محلي نظام الملفات تنفيذ.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

سوف هذا مزود و [`dsh-ssh`](../ssh/README.zh.md) و `sandboxPolicy` واحد نفس تركيب، و استخدام إعداد طقم SSH عملية فرعية و صندوق رملي مزود تنفيذ برنامج. هذا مزود لا يوجد إعداد حقل: اتصال هوية و افتراضي مساحة العمل يخص `dsh-ssh`، ملف فاعلية نتيجة نمط يخص `sandboxPolicy`.

`resolve()` في بعيد طرف رئيسي آلة فوق مواصفة تحويل مسار.`processPath()` و `fileUrl()` في نفس عدد بعيد طرف نطاق الأسماء في معرف ملف، و لا منح إعطاء رئيسي آلة جانب وصول قدرة. ملف URL مقابل حرف وجه مئة قسم رقم، عكس مائل عمود و تبديل سطر إجراء تحرير رمز، إبقاء أصل ملف اسم.`processPathFromHostPath()` إرجاع `undefined`، لذلك حاجة قد تثبيت يمكن تنفيذ ملف أو جذب توجيه برنامج مستهلك يجب صريح توفير بعيد طرف ناتج.

قراءة إبقاء مشترك نظام الملفات رمز خطأ. كتابة و تحرير سوف قد تحليل تدريجي مرة استدعاء سياسة إرسال إعطاء مساعد مساعدة برنامج، من ذلك مواصفة تحويل مساحة العمل و في أصل فرعي تعديل الذي في موضع تنفيذ سياسة. نقل فقد فقد تقرير إبلاغ I/O فشل؛ تعديل ممكن قد إيداع، لن تلقائي إعادة محاولة.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل عبر قائم نظام الملفات مستهلك إنتاج أثر، من هو جمع عرض بعيد طرف مسار و ملف محتوى، و مسؤول كل أداة و تلميح.

#### KV Cache أثر

هذا مزود لا مساهمة طلب بادئة محتوى. موجه إلى نموذج أداة و نتيجة من مستهلك مسؤول.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

- مساعد مساعدة برنامج سوف كامل مقطع نص قراءة و مفرد مرة بايت نافذة حد لـ 8 MiB. أكثر كبير قراءة يحتاج استخدام نص تدفق أو كثير عدد بايت نافذة؛ أخرى JSON نقل أيضا تلقي اتصال رسالة كبير صغير حد أعلى قيد.
- بعيد طرف ملف URL هو تنفيذ جلوس علامة، لا هو رئيسي آلة نظام الملفات جملة مقبض أو Web تحت تحميل رابط.
