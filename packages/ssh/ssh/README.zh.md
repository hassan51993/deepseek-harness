# @deepseek-ai/dsh-ssh

[English](README.md) | العربية

## عام وصف

`dsh-ssh` سوف POSIX Harness رئيسي آلة اتصال إلى POSIX SSH رئيسي آلة فوق قد تثبيت مساعد مساعدة برنامج. نشر جهة يحتفظ OpenSSH رئيسي آلة آخر اسم توفير إقرار إثبات و رئيسي آلة هوية؛ إعداد طقم نظام الملفات، عملية فرعية و صندوق رملي مزود مشترك هذا اتصال. اتصال في حينئذ خيط قبل تحقق قد تثبيت ناتج ملخص؛ مساعد مساعدة برنامج في اتصال إغلاق أو إيجار مدة إلى مدة وقت مسؤول بعيد طرف تنظيف.

## استخدام هذه الحزمة

في ذاتي تعريف `dsh` إعداد تركيب في، سوف هذا خدمة و [`fs-ssh`](../fs-ssh/README.zh.md) ،[`subprocess-ssh`](../subprocess-ssh/README.zh.md) و [`sandbox-ssh`](../sandbox-ssh/README.zh.md) تركيب. رئيسي آلة تشغيل Harness، نموذج نقل و Session تخزين؛ بعيد طرف آلة جهاز توفير ملف و عملية.headless إعداد تركيب دعم حمل هذا نوع أمان ترتيب.

### نشر قبل رفع

اثنان طرف متساو يحتاج تشغيل Linux أو macOS. محلي `ssh` أمر يجب دعم حمل اتصال إعادة استخدام و Unix طقم وصل حرف تحويل إرسال، خادم أيضا يجب سماح هذا تحويل إرسال. بدء قبل إعداد رئيسي آلة آخر اسم، اعتماد و معروف رئيسي آلة سجل: هذا خدمة تفعيل `BatchMode`، اشتراط صارم إطار فحص رئيسي آلة مفتاح، منع استخدام إقرار إثبات بديل إدارة تحويل إرسال، كما لا توفير تفاعل إقرار إثبات مسار.

في بعيد طرف رئيسي آلة تثبيت قد بناء مساعد مساعدة برنامج و ذلك مطابقة تشغيل اعتماد.Node، مساعد مساعدة برنامج، جذب توجيه برنامج و ذلك اعتماد يجب يقع في مساحة العمل و يمكن كتابة مؤقت دليل خارج، أيضا يجب يقع في خلفية سوف استبدال مؤقت دليل شجرة خارج، مثال مثل bwrap خاص `/tmp`؛ مساحة العمل ما زال يمكن يقع في `/tmp` تحت. ملخص تحقق في مساعد مساعدة برنامج بدء بعد اكتشاف غير مسبق مدة قد تثبيت ناتج؛ هو لا يستطيع حفظ إثبات يمكن كتابة نشر ملف تنفيذ أمان، أيضا لا يستطيع إقرار إثبات سيئ معنى SSH رئيسي آلة.

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `host` | لا بد ملء | قد لديه OpenSSH رئيسي آلة آخر اسم |
| `node`،`helper`،`workspace` | لا بد ملء | بعيد طرف Node يمكن تنفيذ ملف، مساعد مساعدة برنامج تحزيم مدخل و افتراضي مساحة العمل قطعا مقابل مسار |
| `helperHash` | لا بد ملء | قد تثبيت مساعد مساعدة برنامج مدخل صغير كتابة SHA-256 |
| `bootstrapPath`،`bootstrapHash` | حذف | صار مقابل توفير بعيد طرف PTC مدخل و ذلك صغير كتابة SHA-256 |
| `requestTimeoutMs` | `30000` | اتصال و إدارة طلب قطع توقف وقت حد، نطاق لـ 1 حتى 2,147,483,647 جزء ثانية |
| `maxFrameBytes` | `67108864` | كل بند JSON رسالة سالب تحميل حد أعلى، الأكثر كبير لـ 64 MiB |
| `maxPending` | `128` | عادي لم إتمام طلب عدد كمية حد أعلى؛ قلب قفز و محدود تنظيف طلب استخدام مسبق إبقاء سعة كمية |
| `leaseMs` | `30000` | مساعد مساعدة عملية قلب قفز إيجار مدة، نطاق لـ 3000 حتى 600000 جزء ثانية |

استخدام PTC وقت، إعداد اثنان عدد جذب توجيه حقل، و سوف تحقق بعد `ctx.ssh.nodeExecutable` و `ctx.ssh.bootstrapPath` نقل إعطاء [`NodePtcRuntime`](../../ptc-runtime/ptc-runtime-node/README.zh.md). فقط استخدام نظام الملفات و Bash وقت يمكن حذف هذا مقابل حقل. لم إعداد PTC نشر وقت،`bootstrapPath` getter سوف رفض وصول.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة — انقر للتوسيع</summary>

OpenSSH رئيسي اتصال تحمل تحميل خاص إدارة RPC. كل بند برنامج تدفق استخدام مستقل تحويل إرسال Unix طقم وصل حرف و مستقل SSH عبر طريق. برنامج stdout لا يمكن زائف صنع إدارة عودة تكرار، أيضا لن احتلال استخدام تحكم تدفق عبر طريق نافذة؛SSH نقل امتلاك سد ما زال سوف أثر مشترك اتصال.

كل تدفق مسبق إبقاء بند كل لديه واحد مع آلة 256 موضع TLS مسبق مشترك مفتاح، فقط من إدارة RPC نقل تمرير.TLS إقرار إثبات اثنان طرف و حفظ حماية تدفق في كل بايت؛ مفتاح أبدا بصفة تدفق بادئة إرسال. طقم وصل حرف دليل لـ خاص دليل (`0700`) ، طقم وصل حرف استخدام `0600` إذن. استبدال يمكن كتابة طقم وصل حرف مسار لا يمكن خطر ملء طرف نقطة أو نيل معرفة تدفق مفتاح؛ هجوم ضرب من ما زال يمكن في قطع خدمة أو تحويل إرسال لا نفاذ واضح TLS سجل.

اتصال تحرير سوف أولا انتظار تحويل إرسال و إلغاء عملية فرعية، و بعد في بناء قيام تدفق انتهاء، مجددا حذف محلي مورد. نقل فقد فقد سوف رفض انتظار معالجة عملية و جعل اتصال بطلان. مساعد مساعدة عملية في SSH EOF، إنهاء إشارة أو قلب قفز إلى مدة وقت بدء حمل إدارة تنظيف. قطع وصل عميل لا يمكن تأكيد بعيد طرف نتيجة؛ عملية لن تلقائي إعادة وصل أو إعادة وضع.

بدء أو عملية نتيجة فشل بعد، مسبق إبقاء بند في أصلي عملية نطاق صاف فارغ بعد تحرير؛ محدود إتمام ذاكرة مؤقتة إبقاء أصلي رفض نتيجة، توفير لاحق قراءة. مساعد مساعدة برنامج إغلاق أيضا سوف انتظار قد في إجراء طرف نقطة و دليل تنظيف.

طرفية تفعيل shell نشط حركة مراقبة وقت، أصل عملية خروج سوف إبقاء reservation و ذلك باق بقية عمل. نشط حركة RPC متابعة وصول provider؛ واضح إنهاء وقت أولا انتظار عملية نطاق تماما توقف مستقر، مجددا تحرير طرف نقطة و سجل إتمام نتيجة.helper اتصال إزالة و إيجار نحو إلى مدة ما زال إبقاء أصل لديه إنهاء إذن.

مساعد مساعدة برنامج بـ `--disable-sigusr1` بدء، لذلك نفس مستخدم عملية إرسال إشارة لا يمكن فتح بدء ذلك Node ضبط تجربة جهاز.

</details>

## تجربة النموذج

بلا، لأن رئيسي آلة آخر اسم، إقرار إثبات و تدفق قدرة أمر لوحة يخص خاص نشر دقيق عقدة، كل بند موجه إلى نموذج عملية متساو من مستهلك مسؤول.

#### KV Cache أثر

هذا مزود لا مساهمة طلب بادئة محتوى. موجه إلى نموذج أداة و نتيجة من مستهلك مسؤول.

## معروف حد و تأخير بعد عمل

<a id="known-limitations-and-deferred-work"></a>

- لا توفير Windows طرف نقطة، تلقائي إعداد بعيد طرف بيئة، إعادة وصل أو إعادة وضع.
- Web مساحة العمل واجهة مسار ما زال زائف تحديد يمكن وصول رئيسي آلة نظام الملفات؛ طلب استخدام headless أو كل مستهلك كل التزام حراسة مزود مسار دلالة ذاتي تعريف تركيب.
- TLS تدفق مفتاح لا منع صد بعيد طرف عملية نظام درجة عملية داخل تخزين فحص أو ضبط تجربة. ملف فاعلية نتيجة سياسة إبقاء الذي اختيار صندوق رملي خلفية حد.
