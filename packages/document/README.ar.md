# document/ — Office تحويل

[English](README.md) | العربية

## ملخص

في مضيف فوق سوف قد تخويل Office ملف تحويل لـ يمكن إعادة استخدام PDF. مشترك خدمة استخدام LibreOffice kit تنفيذ تحويل. إعلان أصلي جذب محرك هدف استخدام أصلي جذب محرك، ذلك بقية هدف استخدام Node WASM.
