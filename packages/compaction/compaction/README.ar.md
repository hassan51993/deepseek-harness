# @deepseek-ai/dsh-compaction

[English](README.md) | العربية

## عام وصف

`dsh-compaction` يجعل طويل وقت جلسة يأخذ مقارنة مبكر تاريخ ضغط (compaction) صار واحد بند ملخص رسالة، إبقاء قريب مدة محادثة ثابت، و مثل ملخص واحد مباشر وجود ذلك مثال متابعة تحت ذهاب——إعداد دمج `dsh-compaction-basic` لـ صنف خلفية و اختياري `/compact` أمر يكفي تنفيذ. يتم حجب حجب محتوى ما زال إبقاء في جلسة سجل في، لذلك إعادة تشغيل جلسة وقت قدرة تحديد صفة أرض إعادة الآن نفس نسخة ضغط بعد محادثة. عند أنت تنفيذ ضغط خلفية، بناء إطلاق ضغط مكون، أو حاجة تعرف آخر ضغط بعد رسالة وقت، عندئذ حاجة هذه الحزمة——هو ذاته لا تنفيذ أي ضغط. تفكير فتح صندوق أي استخدام أرض نيل نيل هذا وظيفة وقت، طلب اختيار مع مرفق خلفية.

## استخدام هذه الحزمة

أولا تحديد أنت حاجة ماذا. مع مرفق خلفية إضافة `/compact` أمر يكفي صفر شفرة نيل نيل تلقائي و حسب يحتاج ضغط؛ فقط لديه في أنت توسيع أو إعادة تنفيذ هذا وظيفة وقت عندئذ حاجة هذه الحزمة. التالي كل عقدة شرح ضغط فعل ماذا، مثل أي تفعيل، و مثل أي تحرير كتابة خلفية.

### أي وقت اختيار

عند نموذج تأليف كتابة ملخص رمز دمج يحتاج طلب وقت، اختيار `dsh-compaction-basic`: جلسة زيادة طويل وقت تلقائي ضغط، و يمكن عبر `dsh-command-compact` حسب يحتاج ضغط. عند أنت حاجة مختلف ملخص طريقة——ثابت نموذج لوح أو بعيد مسار خدمة——أو بناء بـ تحرير مسار طريقة إطلاق ضغط مكون وقت، اختيار هذه الحزمة. لا يلزم مفرد وحيد تركيب هو: لا يوجد خلفية حينئذ ماذا كل لن ضغط.

### ضغط بعد سوف حدوث ماذا

ضغط وقت التشغيل، الذي اختيار مقارنة مبكر نطاق محادثة سوف يتم استبدال لـ واحد بند ملخص رسالة؛ قريب مدة تاريخ لا تلقي أثر، محادثة من ملخص متابعة. ضغط يمكن من token ضغط قوة تلقائي إطلاق، حسب يحتاج إطلاق، أو إبرة مقابل صريح نطاق إطلاق؛ نتيجة سوف تقرير إبلاغ ضغط أي بعض تاريخ و تقدير حساب تحرير token عدد.

### تفعيل ضغط

تركيب مع مرفق خلفية بـ تسجيل ضغط خدمة، و إضافة `dsh-command-compact` نيل نيل حسب يحتاج أمر:

```yaml
- name: '@deepseek-ai/dsh-compaction-basic'
- name: '@deepseek-ai/dsh-command-compact'
```

لديه هذا اثنان سطر إعداد، وظيفة أي قد فتح بدء: جلسة زيادة طويل وقت تلقائي ضغط،`/compact` استلام إلى طلب بعد قيام أي ضغط و تقرير إبلاغ استبدال كثير قليل تاريخ بند. إذا لم تركيب خلفية، ماذا كل لن ضغط،`/compact` أيضا سوف فشل؛ مع مرفق خلفية كامل اعتماد سلسلة رؤية ذلك ذاته README.

### تنفيذ خلفية

وراثة توفير أساس صنف و تنفيذ ثلاثة عدد عملية: واحد إبرة مقابل تلقائي إطلاق قرار و تنفيذ ضغط، واحد حسب يحتاج ضغط، واحد ضغط محادثة صريح نطاق. يأخذ أنت صنف بصفة إضافة تحميل، هو حينئذ سوف يصبح هذا تركيب ضغط خدمة. دقيق توقيع، فشل قاعدة و كل خلفية يجب توليد فحص نقطة علامة، رؤية تحت جهة تنفيذ فصل عقدة و[ضغط فرعي نظام مشاركة اعتبار](../../../docs/subsystems/compaction.ar.md).

### تعرف آخر ضغط بعد تاريخ

خلفية كتابة ملخص رسالة حمل لديه مستقر علامة، لذلك أي مستهلك كل قدرة في حفظ دائم أو تغلب ضخم بعد تعرف آخر ضغط تاريخ، بينما بلا حاجة معرفة طريق هو أي عدد خلفية توليد. هذا علامة من حزمة أصل تصدير، أيضا من واحد بلا Cordis اعتماد فرعي مسار تصدير، عميل و wire برنامج متساو يمكن استيراد.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة بـ API فن لغة حل تفسير اتفاق و ذلك خلف بعد تصميم قرار؛ وظيفة طبقة وجه سلوك رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

هذا seam بناء قيام في واحد تفكيك قسم و ثلاثة بند تحمل وعد لـ فوق:

- **سحب كائن اتفاق، أداة جسم خلفية.** واجهة قاعدة تحديد ضغط فعل ماذا؛ مزود يملك سياسة، إبقاء و ملخص، لذلك كل زاوية لون يمكن مستقل عرض دخول، مستقل استبدال.
- **جلسة و LLM(كبير لغة نموذج) مفردات هو اتفاق واحد جزء.** عملية أثر في `Session`، ملخص استخدام `ContentBlock`، لذلك كل إدارة لديه عام Cordis-only إشارة جذب،Service Definition ما زال اعتماد `dsh-session` و `dsh-llm`——هذا هو واحد بند متعمد انحراف مغادرة، سجل في[ضغط قدرة seam Agent Note](../../../.agents/notes/implemented/feature/2026-06-18-compaction-capability-seam.ar.md) في.
- **سجل سجل علامة مقابل حينئذ هو قفل.** `compaction/start` في ملخص يجعل خروج تحكم حق قبل إلحاق،`compaction/end` تحرير؛ كل مرة فشل كل تماما جيد إجراء مرة إغلاق دمج محاولة تجربة، إغلاق دمج فشل سوف إبقاء تحت لم مطابقة start بصفة متعمد busy إشارة.
- **جدول طبقة فقط تغيير مرة.** ملخص تحمل تحميل في علامة مقابل داخل واحد بند `user/message` استبدال فوق؛ كل `compaction/*` حدث فقط كتابة سجل.

### خدمة API

هذا اتفاق هو خلفية تنفيذ ثلاثة عدد سحب كائن عملية:`compactIfNeeded` إبرة مقابل تلقائي `pressure` أو `context-overflow` إطلاق،`compactNow` إجراء مرة صريح حسب يحتاج تقليص نقص،`compactRegion` إبرة مقابل استدعاء جهة اختيار جدول طبقة نطاق. يمكن إعادة استخدام طلب قياس كمية هو مستقل خدمة `ctx.tokenMeter`. نفاد كل صيغة تدريجي عملية دلالة رؤية[ضغط فرعي نظام مشاركة اعتبار](../../../docs/subsystems/compaction.ar.md) ؛ دقيق توقيع رؤية [`src/index.ts`](src/index.ts).

عبر `ctx.llm.stream()` ملخص خلفية يجب سوف signal تحويل إرسال إلى استدعاء `GenerateOptions.signal`، لذلك abort أو fiber dispose(مورد تحرير) سوف إيقاف إجراء في ملخص. تلقائي و صريح نطاق علامة مقابل سوف من فتح جولة استعادة ذلك عدد حرف شكل صيغة ملكية؛ يد حركة علامة مقابل لا اشتراط وجود فتح جولة، و علامة `turn: null`.

### يد حركة فشل تصنيف

تزامن `compaction/summary-error` waterfall يجعل خلفية لـ فشل ملخص و واضح اختيار منطقة طلب حمل دائم إدخال استعادة. مستمع فقط لديه في سجل فعلي دخول عرض بعد عندئذ إرجاع true، لا فإن استدعاء `next()` تفويض إرسال لاحق معالجة. خلفية في إطلاق حدث قبل فحص إلغاء و اختيار منطقة مستقر صفة، إعادة محاولة قبل إعادة إرسال توليد إدخال و حساب قيمة. حدث إعلان شرح ذلك تحميل حمل؛ صورة سياسة من `dsh-compaction-image-offload` مسؤول.

مسبق مدة يد حركة فشل سوف رمي خروج `ManualCompactionError`، يحمل قدوم ذاتي صغير نوع غلاف إغلاق تجميع دمج مستقر `code`؛ فقط لديه `compaction/start` علامة بعد حدوث فشل عندئذ سوف يتم سجل——بـ يحمل خطأ `compaction/end` شكل صيغة——بينما `busy` رفض أو start قبل إلغاء لن إبقاء تحت سجل. كل رمز خطأ دلالة رؤية[ضغط فرعي نظام مشاركة اعتبار](../../../docs/subsystems/compaction.ar.md).

<a id="tool-pairing-boundaries"></a>
### أداة إعداد مقابل حد

هذا Service Definition تصدير `toolPairingBalancedBefore(session, seq)` و `toolPairingBalancedAfter(session, seq)`، لأجل مقابل متساو و تحقق ضغط حد. أمان حد لن يتم بعد لم عودة جواب assistant استدعاء الأداة عبر تجاوز. كل helper كل سوف تحقق إعطاء تحديد حدث seq يقع في حالي جدول طبقة، و أصل حسب حسب جدول طبقة ترتيب ذاكرة مؤقتة كل قطع قسم نقطة إعداد مقابل حالة إرجاع نتيجة، لذلك تكرار فحص لا قراءة حدث؛replace generation سوف إعادة بناء ذاكرة مؤقتة، ناقص seq أو منعزل قيام `tool/result` سوف يتم نظر لـ جدول طبقة حالة ضرر تالف و تعرض رفض.

### جدول طبقة اتفاق

`SurfaceEventType` هو غلاف إغلاق ربط دمج——`user/message`،`assistant/message` و `tool/result` يجب يحمل `surfaceOp`، أخرى حدث منع توقف يحمل هذا حقل، لذلك `compaction/*` حدث لا يستطيع ظهور في جدول طبقة فوق. نجاح خلفية تشغيل تعديل لـ في سجل في حزمة محيط كامل عملية: أولا إلحاق `compaction/start`(فقط سجل) نيل أخذ قفل، ملخص هذا نطاق، إلحاق فقط سجل `compaction/summary` سجل، استخدام واحد بند تحمل تحميل ملخص `user/message` استبدال الذي اختيار نطاق——هذا هو وحيد جدول طبقة تغيير——الأكثر بعد إلحاق `compaction/end`(فقط سجل) تحرير قفل.

استبدال يقع في قفل بدء توقف نطاق**داخل**، لذلك `compaction/start` و `compaction/end` بين انهيار انهيار سوف إبقاء تحت يمكن فحص قياس متروك إبقاء قفل، بينما لا هو وهمي زائف صوت تسمية نجاح `compaction/end`.`deriveMessages()` سوف ملخص تصيير لـ user زاوية لون رسالة، بعد وجه تتبع مع قد إبقاء عقدة؛ قد حجب حجب حدث ما زال إبقاء في أصلي سجل في، لذلك إعادة تشغيل أداة لديه تحديد صفة. كل حدث أداة جسم payload رؤية[ضغط فرعي نظام مشاركة اعتبار](../../../docs/subsystems/compaction.ar.md).

### قفل و سلسلة سطر تحويل

كل مدخل نقطة مشترك واحد سجل سجل قفل. ذيل جزء فحص سوف قسم آخر فحص بحث الأكثر جديد لم مطابقة `compaction/start` و الأكثر جديد `session/end-seed`؛ يقع في هذا حد بعد لم مطابقة start هو نشط حركة قفل و تقرير إبلاغ `busy`، أكثر مبكر فإن هو أولا قبل عملية دورة الحياة إبقاء تحت قديم قديم دليل. نشط حركة علامة مقابل لا يستطيع عبر تجاوز `turn/start` أو `turn/end`. علامة هو قفل وقت نقطة، بينما غير ترتيب هو حاوية: فارغ خامل `inject()` يمكن في يد حركة start و end بين إلحاق لا متبادل صلة سياق، لذلك يد حركة مسار إعادة تحقق ذلك اختيار في نطاق، بينما لا اشتراط كامل جدول طبقة متبادل انتظار.

### حدث

`compaction/*` حدث عبر declaration merging توسيع `SessionEventMap`(يمكن دمج توسيع)——هو جمع هو جلسة حدث، لا هو Cordis `Events`، كما كل فقط كتابة سجل. توليد[حفظ دائم سجل حدث دليل](../../../docs/persistence-catalog.ar.md) يملك كل حدث payload؛`compaction/prune` سجل و أداة نتيجة إصلاح قص جهاز مشترك أثر فرعي قيمة إطار بروتوكول.

<a id="model-experience"></a>
## تجربة النموذج

### استدعاء خلفية وقت جلسة تاريخ

#### نموذج يرى محتوى

نجاح خلفية سوف استخدام واحد بند user زاوية لون ملخص فحص نقطة استبدال مقارنة مبكر جدول طبقة نطاق——واحد بند يحمل `surfaceOp: { op: 'replace', startSeq, endSeq }` `user/message`. أصلي حدث ما زال سوف سجل، لكن لم يعد ظهور في إرسال توليد نموذج رسالة في؛seam ذاته لا تنفيذ تعديل كتابة.

#### Token أثر

هذا Service Definition لن مباشر إنتاج token. خلفية استخدام واحد نسخة ملخص تبديل أخذ كثير عدد أصل هذا إبقاء تاريخ token، و إبقاء قريب مدة ذيل جزء ثابت.

#### KV Cache أثر

نجاح خلفية استبدال سوف جعل من رقم واحد يتم حجب حجب تاريخ token بدء إعادة استخدام بطلان؛seam ذاته لن تغيير طلب.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح بلا نقاش تحميل أي عدد خلفية، ضغط كل لا يمكن فعل إلى أمر؛ هو جمع هو حالي حزمة قيد.

- **موجه إلى مستخدم أمر، بينما غير نموذج أداة**——ضغط من `/compact` أمر و تلقائي ضغط قوة إطلاق؛ لن تسجيل موجه إلى نموذج ضغط أداة.
- **جزء وحدة فيض خروج لا في اتفاق داخل**——مستو توازن ملخص ضغط لا يمكن تفكيك قسم واحد غير ممكن قسم وحدة. عند إغلاق دمج أداة مقابل في يمكن إزالة رئيسي يلزم جزء هو تحمل تحميل نص أداة نتيجة وقت، اختياري قص غصن إعداد طقم خدمة ما زال يمكن إصلاح هذا أداة مقابل؛ لا يمكن ضغط كبير نوع غير أداة عقدة، أو غير ممكن قص غصن باق بقية جزء مرور كبير أداة وحدة.
- **مفرد وحيد وصل قريب نافذة كبير صغير envelope لا يخص جدول طبقة ضغط عمل**——ضغط تقليص نقص إرسال توليد تاريخ، أبدا تقليص نقص توجيه النظام، أداة أو جلسة بادئة.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق، واضح لا أداة مرجعي صفة؛ قد تسليم سلوك بـ فوق نص، حزمة شفرة و الذي رابط Agent Note لـ دقيق.

- **موجه إلى نموذج أداة، بعد لم قرار**——ضغط هدف قبل فقط حد مستخدم أمر. موجه إلى نموذج ضغط أداة ما زال هو فتح وضع مشكلة؛ هو حاجة ذاتي ذات schema، و و قائم أمر مسار تنسيق ضبط.
- **نموذج لوح و بعيد مسار خلفية، بعد لم قرار**——`SummaryResult` اتفاق قد حمل لديه لم علامة `rawOutput` تغيير جسم، توفير لا عبر `ctx.llm.stream()` تعرف آخر استدعاء ملخص جهاز استخدام، لكن هذا صنف خلفية بعد لم مع مرفق.
- **`/compact` نطاق معامل، بعد لم قرار**——بلا معامل شكل صيغة جعل كل أمر مهايئ سلوك إبقاء مستقر؛ صريح نطاق ما زال من تحرير مسار واجهة `compactRegion()` معالجة.
