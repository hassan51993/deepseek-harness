# @deepseek-ai/dsh-compaction-tool-result-pruner

[English](README.md) | العربية

## عام وصف

`dsh-compaction-tool-result-pruner` منع توقف تجاوز كبير أداة إخراج ملء ممتلئ سياق نافذة. ضغط إطلاق شرط ممتلئ كاف بعد، هو سوف يأخذ تجاوز خروج ميزانية نص استبدال لـ طويل درجة تلقي حد رأس جزء، بسيط قصير «middle pruned» علامة و طويل درجة تلقي حد ذيل جزء؛ لم بلوغ إلى ضغط قوة عتبة قيمة محادثة إبقاء ثابت. كامل أصلي نتيجة ما زال إبقاء في جلسة سجل في، يمكن توفير دقيق إعادة تشغيل و فحص. إصلاح قص لا إرسال بدء نموذج استدعاء، و ممكن ملء قسم مؤقت حل token ضغط قوة، جعل ضغط قفز مرور ملخص. محرف ميزانية فقط قدرة قريب يشبه token استخدام كمية؛token meter مسؤول حكم تحديد ضغط قوة هل نيل إلى مؤقت حل.

## استخدام هذه الحزمة

عند أداة إخراج مرور معتاد رئيسي توجيه محادثة نافذة وقت، في `dsh-compaction-basic` جانب تركيب هذه الحزمة. إصلاح قص سوف تغيير نموذج يرى محتوى——أكثر قصير نتيجة——و يجعل ضغط لديه أكثر قليل تاريخ حاجة ضغط.

### الأكثر صغير متاح تركيب

حسب هذا ترتيب تركيب token قياس كمية، هذه الحزمة و خلفية:

```yaml
- name: '@deepseek-ai/dsh-token-meter'
- name: '@deepseek-ai/dsh-compaction-tool-result-pruner'
- name: '@deepseek-ai/dsh-compaction-basic'
```

لديه هذه إعداد سطر، تجاوز كبير أداة نتيجة سوف في ضغط مرور مسار في تلقائي يتم إصلاح قص. أنت يمكن عبر فحص لاحق طلب هل عرض إصلاح قص بعد نتيجة قدوم تأكيد نجاح؛ كامل أصلي محتوى ما زال إبقاء في جلسة سجل في.

### ماذا سوف يتم إصلاح قص

كل نص تجاوز مرور عتبة قيمة أداة نتيجة كل سوف يتم استبدال لـ إصلاح قص إصدار: إعداد رأس جزء، بسيط قصير «middle pruned» علامة و إعداد ذيل جزء. صورة و بنية تحويل كتلة انتظار غني محتوى إبقاء أصل لديه ترتيب، و إبقاء سجل في كل صورة حذف اختيار. استبدال إبقاء استدعاء الأداة، خطوة، خطأ و بيانات وصفية——فقط لديه نص محتوى حدوث تغير. إذا استبدال لا يمكن يتم سجل، تشغيل سوف فشل، قد تطبيق إصلاح قص ما زال سوف إبقاء.

### ضبط كبير صغير حد

كل ضبط كل اختياري؛ افتراضي سوف يأخذ نص تجاوز مرور 8,192 عدد محرف نتيجة إصلاح قص لـ ذلك قبل 4,096 إضافة بعد 1,024 عدد محرف، و استخدام علامة اتصال. توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-compaction-tool-result-pruner) هو شمول غطاء كل إعداد حقل حق مصدر.

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `thresholdChars` | `8192` | دمج نص تجاوز مرور هذا Unicode رمز نقطة عدد وقت إصلاح قص. |
| `headChars` | `4096` | إبقاء فتح رأس Unicode رمز نقطة عدد. |
| `tailChars` | `1024` | إبقاء نهاية ذيل Unicode رمز نقطة عدد. |

محرف عدد بـ Unicode رمز نقطة حساب، لذلك مقتطعة أبدا سوف تفكيك قسم emoji مقابل، لكن كثير محرف حرف عنصر ما زال ممكن يتم مقتطع. رأس جزء إضافة علامة إضافة ذيل جزء لـ و يجب لا تجاوز مرور عتبة قيمة، لذلك صالح إعداد يمكن إصلاح قص كل تجاوز خروج ميزانية نتيجة، لن زيادة طويل أو تكرار تعديل كتابة. لم معرفة ضبط سوف توجيه يؤدي إضافة في بنية صنع وقت يتم رفض.

### إصلاح قص أي وقت تشغيل

إصلاح قص فقط في ضغط إطلاق شرط ممتلئ كاف بعد تشغيل:`dsh-compaction-basic` في ضغط قوة أو فيض خروج تأكيد بعد، اختيار يلزم ضغط محتوى قبل استدعاء هو. منخفض في ضغط قوة وقت لن إصلاح قص أي محتوى، إصلاح قص ذاته أيضا لا إرسال بدء نموذج استدعاء.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير إصلاح قص جهاز خلف بعد تصميم قرار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا إصلاح قص جهاز بناء قيام في ثلاثة بند تحمل وعد لـ فوق:

- **تحديد صفة مفرد مرة استلام جمع.** حسب Unicode رمز نقطة بـ ثابت ميزانية مقتطعة، لذلك كل إرسال خروج نتيجة في نص رمز نقطة فوق كل دقيق يتضمن قد إعداد رأس جزء، علامة و ذيل جزء، لا كبير في `thresholdChars`، كما صارم إطار صغير في إطلاق إدخال.
- **يمكن أمان إعادة تشغيل استبدال.** أصلي حدث إبقاء في فقط إلحاق سجل في؛ استبدال عبر `sourceEventSeqs` مرجع هو، لذلك إعادة تشغيل يمكن استعادة إنتاج قد قص غصن نتيجة دقيق إدخال.
- **أثر فرعي قيمة إطار بروتوكول.** `compaction/prune` سوف ضيق مجاور استبدال حدث و يقع في ذلك قبل، عبر حقن token meter لـ يتم استبدال دقيق نطاق تحديد قيمة، جعل صاف مستهلك بلا حاجة كل عقدة حالة يكفي نقص ذهاب هو——أي `compaction/prune` حدث فوق سجل مشترك بروتوكول.

### قص غصن آلية

قص غصن حسب Unicode رمز نقطة قياس كمية `text` كتلة (غير نص كتلة حساب لـ صفر) ، توليد طويل درجة تلقي حد استبدال——محتوى قد في ميزانية داخل وقت فإن لا استبدال——و يأخذ كل تجاوز خروج ميزانية أداة نتيجة تبديل لـ واحد بند جديد إلحاق `tool/result`، هذا حدث استبدال أصلي حدث و عبر `sourceEventSeqs` مرجع هو، قبل وجه ضيق تتبع واحد بند `compaction/prune` أثر فرعي قيمة إطار حدث. جلسة رفض استبدال وقت، تشغيل سوف تزامن فشل؛ هذا مرة مسح في أولا قبل قد إيداع استبدال ما زال سوف إبقاء. غير نص كتلة إبقاء أصلي متبادل مقابل موضع، مقتطعة أبدا سوف تفكيك قسم UTF-16 بديل إدارة بند مقابل. دقيق توقيع رؤية [`src/index.ts`](src/index.ts).

### شفرة المصدر أرض رسم

| ملف | مسؤولية |

| [`src/config.ts`](src/config.ts) | `PRUNE_MARKER`، قيمة افتراضية، رمز نقطة حساب عدد، ميزانية تحقق |

<a id="model-experience"></a>
## تجربة النموذج

### قد قص غصن أداة نتيجة

#### نموذج يرى محتوى

واحد حالما ممتلئ كاف ضغط إطلاق شرط، لاحق طلب يرى سوف هو إبقاء رأس جزء،`\n\n[... tool result middle pruned ...]\n\n` و إبقاء ذيل جزء، بينما غير يتم إزالة نص. غني محتوى كتلة إبقاء أصل لديه ترتيب. نموذج لن يرى أصل نص ثاني نسخة فرعي هذا.

#### Token أثر

كل قد تعديل كتابة أداة نتيجة الأكثر كثير يتضمن `thresholdChars` عدد نص رمز نقطة. قص غصن ذاته لن إرسال بدء نموذج استدعاء؛ إعادة قياس كمية طلب منخفض في ضغط قوة عتبة قيمة وقت،compaction-basic سوف قفز مرور ملخص، لا فإن ملخص جهاز سوف قراءة قد قص غصن جدول طبقة.

#### KV Cache أثر

استبدال مقارنة مبكر نتيجة سوف جعل من رقم واحد تغيير token بدء إعادة استخدام بطلان. عند ذلك توجيه،envelope و قبل تاريخ إبقاء متسق وقت، قد قص غصن بادئة يمكن إعادة استخدام.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح إصلاح قص أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر ملاحظة معنى؛ هو جمع هو حالي حزمة قيد.

- **محرف ميزانية لا هو token ميزانية**——مختلف مزود token سري درجة كل مختلف، لذلك `ctx.tokenMeter` ما زال مسؤول حكم تحديد إصلاح قص هل مؤقت حل طلب ضغط قوة.
- **قص غصن فقط أساس في لغة قاعدة**——هو إبقاء فتح رأس و ربط ذيل، لا حل تفسير في بين أي بعض سطر في دلالة فوق إعادة يلزم.
- **حرف عنصر عنقود ممكن يتم تفكيك قسم**——حسب رمز نقطة مقتطعة يمكن حفظ حماية بديل إدارة بند مقابل، لكن لن تنفيذ اعتبار منطقة مجال ضبط حرف عنصر عنقود قسم قطع.
