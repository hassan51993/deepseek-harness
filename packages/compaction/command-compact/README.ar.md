# @deepseek-ai/dsh-command-compact

[English](README.md) | العربية

## عام وصف

`dsh-command-compact` لـ حديث يوم UI إضافة `/compact` أمر: إدخال هو، محادثة حينئذ سوف حسب يحتاج ضغط (compaction)——أي جعل بعد لم إطلاق تلقائي ضغط قوة، مقارنة مبكر تاريخ أيضا سوف يتم استبدال لـ واحد بند ملخص. هذا أمر ملائم لأجل أي ضغط خلفية، كما لا إزالة استهلاك نموذج جولة؛ إتمام بعد أنت سوف يرى ضغط كثير قليل تاريخ بند و تقدير حساب عقدة حذف token عدد. عند agent(ذكي جسم) جارٍ تنفيذ جولة أو ضغط قد في وقت التشغيل، هو سوف إبلاغ إبلاغ أنت ضغط مؤقت غير ممكن استخدام. تشغيل خلال أنت إرسال نص التوجيه سوف إبقاء ترتيب طابور، و في ضغط انتهاء بعد عندئذ بدء.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند محادثة قد جدا طويل، تفكير قيام أي ضغط وقت، في حديث يوم UI في إدخال `/compact`. مع مرفق `dsh` أساس أساس إعداد يأخذ هذا أمر تركيب في افتراضي خلفية جانب، لذلك هو عبر معتاد قد متاح.

### استخدام أمر

| إدخال | نتيجة |
|---|---|
| `/compact` | أي جعل لم بلوغ إلى تلقائي ضغط قوة، أيضا ضغط واحد مقطع صالح، مستو توازن مقارنة مبكر نطاق، لكن بعد تقرير إبلاغ يتم استبدال تاريخ بند عدد كمية و تقدير حساب token عدد. |
| `/compact`، لكن لا يوجد يمكن ضغط تاريخ | `No compactable history yet.`——لن لديه أي تغيير. |
| `/compact <anything>` | `Usage: /compact (no arguments)`——هذا أمر لا قبول معامل. |

### أنت سوف يرى ماذا

أمر سوف يأخذ كل مسبق مدة فشل تحويل لـ يمكن مباشر عرض مستقر رسالة؛ يسار صف حال شكل إنتاج يمين صف رسالة.

| حال شكل | أنت يرى رسالة |
|---|---|
| ضغط قد في تشغيل، أو agent جارٍ جولة في | `Compaction is unavailable because this process has an active compaction, or the agent is not idle.` |
| ضغط مرور مسار في تاريخ حدوث تغير | `The history selected for compaction changed before it could be replaced. The attempt is recorded in the session log.` |
| لا يمكن إنتاج لديه استخدام ملخص | `Compaction could not produce a useful summary. The attempt is recorded in the session log.` |
| ضغط لم جاف صاف أرض إتمام | `Compaction did not finish cleanly; some session history may have changed. Inspect the current session state before retrying.` |
| جلسة لا يمكن حفظ | `Compaction finished, but the session could not be saved.` |

إلغاء أمر سوف إيقاف انتظار: خلفية إتمام مطلوب تنظيف، أمر بـ `Compaction cancelled.` تسوية،UI إيقاف انتظار. حذف هذه مسبق مدة حال شكل خارج فشل سوف بـ خطأ شكل صيغة عرض، بينما لن يتم ساكن صامت تحويل.

### تركيب أمر

تركيب أمر سجل التسجيل، واحد ضغط خلفية و هذا إضافة:

```yaml
- id: commands
  name: '@deepseek-ai/dsh-commands'
- id: compaction-basic
  name: '@deepseek-ai/dsh-compaction-basic'
- id: command-compact
  name: '@deepseek-ai/dsh-command-compact'
```

مع مرفق `dsh` أساس أساس إعداد يأخذ هو تركيب في افتراضي خلفية جانب،Web عميل توفير أمر مهايئ. لم تركيب أمر مهايئ تلقائي تحويل واجهة فقط إبقاء تلقائي ضغط.

### محادثة سوف حدوث ماذا

أمر نجاح وقت، الذي اختيار مقارنة مبكر نطاق سوف يتم استبدال لـ واحد بند ملخص، قريب مدة تاريخ لا تلقي أثر؛ أمر سوف تقرير إبلاغ ضغط مشروع عدد و تقدير حساب token عدد. ضغط تشغيل خلال أنت إيداع نص التوجيه سوف يتم قبول، و فقط في ضغط انتهاء بعد عندئذ بدء——لن يتم فقد فقد أو إعادة ترتيب. أمر دورة الحياة سجل في جلسة سجل في، لكن أبدا دخول نموذج تاريخ.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أمر خلف بعد تصميم قرار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا أمر بناء قيام في ثلاثة بند تحمل وعد لـ فوق:

- **و خلفية غير متصل تحكم.** معالج فقط اعتماد `compactNow(agent, signal)`، لذلك يمكن و أي `CompactionEngine` تنفيذ تنسيق عمل. استدعاء هذا أمر agent حينئذ هو عملية تأكيد قطع هدف، إرسال بدء توزيع UI سوف عبر seam تحويل إرسال إلغاء إشارة.
- **أمر دورة الحياة لا دخول نموذج تاريخ.** `command/run` و `command/done` كل هو فقط سجل حدث؛`sourceEventSeq` سوف نجاح نتيجة و `compaction/summary` حدث صلة ربط، لا اعتماد نص أو سطر متبادل مجاور علاقة.
- **مورد إلغاء تدمير يجب تماما توقف مستقر.** دورة الحياة effect سوف أولا ملاحظة إلغاء `/compact`، مجددا انتظار قد بدء معالج تسوية، لذلك قد في توقف أمر إغلاق دمج و flush عمل سوف في أصل درجة مورد تحرير إتمام قبل تسوية تمام انتهاء.

### دورة الحياة و صلة ربط

كل مرة إتمام استدعاء كل سوف سجل منفذ الذي تابع فقط سجل حدث مقابل `command/run` / `command/done`؛ اثنان من كل لا دخول نموذج تاريخ. نجاح وقت،`command/done.sourceEventSeq` سوف إشارة واضح هذا أمر خدمة `compaction/summary` حدث، يجعل عرض طبقة بلا يجب تحليل نتيجة نص أو زائف تحديد اثنان سطر متبادل مجاور، يكفي سوف أمر دورة الحياة عودة و إلى مقابل فحص نقطة في.busy نتيجة متعمد حد تحديد في عملية نطاق داخل: نشط حركة لم مطابقة علامة سوف منع سد، بينما مبكر في الأكثر جديد `session/end-seed` علامة قد قديم قديم، لن منع سد. إضافة سوف تتبع أثر كل حقيقي معالج promise، و في ترتيب فارغ قد بدء معالج قبل ملاحظة إلغاء `/compact`، لذلك أصل درجة teardown لن تجاوز مرور قد في توقف أمر إغلاق دمج أو flush حد. ضغط تشغيل خلال إيداع نص التوجيه ما زال سوف حسب agent عادي FIFO نيل نيل وصل قبول، و كما فقط في ضغط صريح حمل دائم صفة فحص نقطة و وصل قبول مسبق إبقاء تحرير بعد بدء؛ فارغ خامل حقن سياق يمكن يقع في `compaction/start` و `compaction/end` بين، و في فحص نقطة بعد إبقاء مرئي.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`/compact` تسجيل، معامل رفض، رمز خطأ خريطة، دورة الحياة ترتيب فارغ |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق مع بند؛ هذا أمر مهايئ لا يملك أي حالة أو حدث تدفق؛ ضغط seam يملك مستو توازن كما أداة حمل دائم صفة أمر خدمة، أمر سجل التسجيل يملك تسجيل و توزيع دورة الحياة. |

</details>

<a id="model-experience"></a>
## تجربة النموذج

### مستخدم `/compact` تحكم

#### نموذج يرى محتوى

مائل عمود إدخال و مباشر نتيجة أبدا سوف دخول نموذج طلب. قد نيل وصل قبول ضغط سوف آخر خارج في مستقل `compaction/* { turn: null }` علامة مقابل داخل، استخدام خلفية user زاوية لون فحص نقطة استبدال واحد مقطع مقارنة مبكر نطاق.

#### Token أثر

أمر دورة الحياة لن زيادة نموذج token. نجاح ضغط سوف استخدام واحد نسخة حمل إطار هيكل ملخص استبدال الذي اختيار نطاق، من بينما نقص قليل لاحق طلب؛ ملخص توليد ذاته حاجة مرة مساعد مساعدة طلب.

#### KV Cache أثر

أمر اكتشاف و دفتر تسجيل لن أثر ذاكرة مؤقتة. قد نيل وصل قبول surface استبدال سوف من رقم واحد يتم حجب حجب تاريخ token بدء جعل إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا أمر أي وقت لا دمج ملائم؛ هو جمع هو حالي حزمة قيد.

- **فقط حد فارغ خامل حالة**——عند جولة أو قد نيل وصل قبول نداء تنبيه نص التوجيه يملك أولوية حق وقت،`/compact` سوف تقرير إبلاغ ضغط مؤقت غير ممكن استخدام؛ أمر ذاته لن ترتيب طابور.
- **لا قبول نطاق أو سياسة معامل**——بلا معامل شكل صيغة جعل كل أمر مهايئ سلوك إبقاء مستقر. صريح نطاق ما زال من تحرير مسار واجهة `compactRegion()` معالجة.
- **فقط حد أمر مهايئ**——لا يوجد `ctx.commands` واجهة لا يمكن استدعاء هذا أمر، فقط قدرة اعتماد تلقائي ضغط قوة ضغط.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق، واضح لا أداة مرجعي صفة؛ قد تسليم سلوك بـ فوق نص، حزمة شفرة و الذي رابط Agent Note لـ دقيق.

- **أمر ترتيب طابور، بعد لم قرار**——جولة يملك أولوية حق وقت إيداع `/compact` سوف تقرير إبلاغ `busy`؛ سوف طلب ترتيب طابور بينما غير رفض ما زال هو فتح وضع جهة نحو.
- **نطاق و سياسة معامل، بعد لم قرار**——بلا معامل شكل صيغة مستقر صفة هو متعمد؛ زيادة معامل حاجة في كل أمر مهايئ بين مشترك لغة قاعدة.
