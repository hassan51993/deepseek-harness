# @deepseek-ai/dsh-webhook

[English](README.md) | العربية

## عام وصف

`dsh-webhook` توفير Host جانب `ctx.webhookRuntime`: هو حيث هو تلقي معلومة مهمة برنامج تحويل webhook قاعدة سجل التسجيل، أيضا يملك وحيد داخل وضع حركة عمل——في Web Workspace في إنشاء عادي أصل جلسة. واجهة فقط يتضمن `register(rule)` و `dispatch(delivery)`؛ مزود هوية تحقق يخص مهايئ حزمة. عند تلقي معلومة مهمة قاعدة يجب يأخذ خارجي حدث تغيير صار جديد agent(ذكي جسم) جلسة وقت، طلب استخدام هو.

<a id="rule-interface"></a>
## قاعدة واجهة

`WebhookRule<K>` أداة لديه حمل brand نوع وحيد `id`، مزود `kind` و `run(delivery, signal)`. عودة ضبط يمكن تنفيذ مهمة معنى تلقي معلومة مهمة شفرة، و إرجاع `null` أو واحد `WebhookSessionRequest`. نفس صنف قاعدة ذاك هذا مستقل بدء؛ بعض عدد عودة ضبط رمي خروج استثناء أو ذلك إرجاع Promise يتم رفض وقت، فقط سوف سجل سجل، لن منع توقف نفس درجة قاعدة.

`VerifiedWebhookDelivery` يحمل مزود نوع صنف، قد إعداد مصدر id، مزود تسليم id، مواصفة تحويل بلا ضرر JSON و استقبال وقت. وقت التشغيل سوف في مشترك قبل لقطة و تجميد ربط كامل قيمة.`deliveryId` فقط هو مصدر معلومة؛ تكرار تسليم سوف مجددا مرة تشغيل قاعدة.

تسجيل هو واحد بند effect. هو يمكن انتظار disposer سوف أولا إخفاء قاعدة، مجددا في توقف و ترتيب فارغ نشط حركة عودة ضبط. عودة ضبط يجب مراقبة الذي توفير signal؛ تجاهل اختصار إلغاء نفس عملية شفرة لا يمكن يتم أمان قوي صنع إيقاف.

<a id="session-request"></a>
## جلسة طلب

`WebhookSessionRequest` اشتراط `workspacePath`،`title`،`prompt`،`agentPreset` و `permissionPreset`؛ اختياري `model` سوف إشارة تحديد واضح مزود/نموذج توجيه و إخراج token حد أعلى. واضح توجيه استخدام ذلك مهايئ افتراضي دفع إدارة (reasoning) قوي درجة. حذف وقت سوف لقطة يتضمن دفع إدارة قوي درجة كامل حالي نشر اختيار، مباشر إلى أول عدد طلب سجل حمل دائم header؛ بعد Web نموذج تغيير إبقاء عادي جلسة سلوك.

وقت التشغيل سوف في تغيير حالة قبل تحقق preset، تحليل أو إنشاء مواصفة Workspace، بـ هذا Workspace مسار بصفة `SessionHeader.cwd` إنشاء Agent، في إصدار قبل تركيب agent preset، و في تطبيق إذن، عنوان و نص التوجيه قبل مرفق إضافة جلسة. مرفق إضافة فشل سوف مقابل بعد لم إصدار حركة عمل تنفيذ dispose(مورد تحرير). بعد إذا في نص التوجيه قبل فشل، فإن بـ كل قوة بينما لـ طريقة انفصال مغادرة Workspace و مقابل Agent تنفيذ dispose.

نجاح `Agent.followup()` هو webhook عملية إيداع نقطة. رسالة استخدام `source.kind: "webhook"`، و يحمل مزود، مصدر، تسليم و قاعدة مصدر معلومة. وقت التشغيل لا انتظار idle، لا تنفيذ خاص خاص flush، لا فحص عودة تكرار، أيضا لا إصدار إتمام حالة؛ بعد تماما من عادي Agent و جلسة سلوك وصل إدارة.

<a id="composition"></a>
## تركيب

في Web Host plane فوق، في Agents، نموذج قيمة افتراضية،agent presets،permission presets، عنوان و Workspace سجل التسجيل بعد تحميل وقت التشغيل. مستخدم تحرير كتابة قاعدة إضافة حقن `webhookRuntime`، و عبر ذاتي ذات effect تسليم خروج `register()` إرجاع disposer.

[GitHub مراجعة إشارة جنوب](../../../docs/user/guide/github-review.zh.md) عرض قاعدة وحدة، مخصص استخدام مدخل طرف فتحة، مفتاح ضبط و Workspace توجيه.

<a id="model-experience"></a>
## تجربة النموذج

### قاعدة تحرير كتابة ابتدائي نص التوجيه

#### نموذج يرى محتوى

كل مطابقة قاعدة كل سوف يجعل نموذج يرى `WebhookSessionRequest.prompt` إرجاع غير فارغ نص أصل نص. عام وقت التشغيل لا زيادة خاص إطار هيكل؛ إذا قاعدة يتضمن خارجي نص، فإن من قاعدة مسؤول علامة واضح ذلك معلومة مهمة خاصية. مع مرفق GitHub عرض مثال سوف يأخذ اختيار تحديد PR حقل علامة لـ لا تلقي معلومة مهمة JSON بيانات وصفية.

#### Token أثر

واحد بند اعتماد بيانات user-role رسالة إبقاء في جديد جلسة في، و حمل متابعة مساهمة token، مباشر إلى عادي ضغط (compaction) استبدال أو إزالة هذا تاريخ.

#### KV Cache أثر

ابتدائي نص التوجيه فتح بدء واحد جديد جلسة، لذلك هو بناء قيام بينما لا هو جعل هذا جلسة يمكن إعادة استخدام طلب بادئة بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **فقط حد عملية داخل fire-and-forget** — انهيار انهيار سوف فقد فقد بعد لم وصل قبول نص التوجيه قاعدة استدعاء؛ لا وجود طابور صف، إعادة تشغيل أو إعادة محاولة.
- **بلا داخل وضع ذهاب إعادة** — مزود تكرار تسليم ممكن إنشاء تكرار جلسة؛ حاجة قوة انتظار صفة قاعدة ذاتي سطر مسؤول.
- **بلا إتمام نتيجة** — HTTP قبول و قاعدة تسوية كل لا تقرير إبلاغ Agent نجاح،idle أو إخراج.
- **تلقي معلومة مهمة عودة ضبط يجب إعداد دمج إلغاء** — وقت التشغيل teardown سوف في توقف و انتظار عودة ضبط، لكن لا يمكن إنهاء مهمة معنى نفس عملية شفرة.
- **Workspace إنشاء ممكن مقارنة فشل جلسة محاولة تجربة أكثر طويل عمر** — فارغ Workspace سوف إبقاء، لأن آخر عدد تزامن استدعاء من ممكن قد استخدام هو.
