# @deepseek-ai/dsh-workflow

[English](README.md) | العربية

## عام وصف

تشغيل واحد مقطع صاف JavaScript تحرير ترتيب نص برمجي، سوف عمل مروحة خروج إعطاء subagent، و إرجاع نص برمجي نهائي JSON قيمة. نص برمجي يمكن استخدام `agent()`،`parallel()`،`pipeline()`،`phase()` و `log()`؛ نموذج عبر معتاد عبر `workflow` أداة وصول هو جمع. كل مرة تشغيل كل عودة استدعاء جهة كل، سوف كل فرعي agent(ذكي جسم) ملكية في استدعاء هو agent، في فشل أو إلغاء وقت بـ نتيجة صرف الآن بينما لا رفض، و في dispose(مورد تحرير) خلال انتظار نص برمجي و فرعي agent تنظيف إتمام. استدعاء جهة يجب توفير تنفيذ جذب محرك، لذلك يمكن أكثر تبديل عزل سياسة بينما لا تغيير مرئي سلوك.

## استخدام هذه الحزمة

عند مهمة قسم حل لـ سماح كثير مستقل جزء، ملائم دمج استخدام واحد مقطع نص برمجي موحد واحد تنسيق ضبط——مثال مثل عبر كثير عدد ملف مراجعة حساب، مرة ترحيل، كثير زاوية درجة بحث بحث——كما نموذج واضح اشتراط سير العمل صيغة تحرير ترتيب وقت، تشغيل سير العمل. واحد اثنان بند تفويض إرسال وقت، أولوية استخدام عادي subagent استدعاء.

### نموذج جانب مسار

نموذج عبر `dsh-tool-workflow` `workflow` أداة لمس بلوغ هذا قدرة؛ هذا أداة يملك استدعاء schema و نتيجة حزمة شبكة، جذب محرك توفير ذلك تحت تنفيذ. مرة أداة استدعاء إيداع `meta`،`script` و اختياري `args`، تشغيل إتمام وقت إرجاع `{ runId, agentsStarted, result }`. أداة سوف منع سد أب درجة جولة مباشر إلى كامل سير العمل تسوية، لذلك نموذج فقط يرى نهائي نتيجة، دائم بعيد لن يرى في بين فرعي agent رسالة.

### تشغيل سير العمل نص برمجي

تحرير ترتيب نص برمجي هو صاف JavaScript نص برمجي جسم (لا هو TypeScript) ، بـ قمة طبقة `await` تشغيل و بـ `return <json-value>` ربط ذيل.`meta` هوية كتلة و أي `args` كل بـ عادي JSON بيانات وصول——أبدا بصفة شفرة طلب قيمة. تنفيذ خلال نص برمجي استدعاء توفير خطاف:`agent(prompt, opts)` بدء واحد subagent، و بـ ذلك نهائي نص، أو في توفير schema وقت بـ مرور مرور تحقق بنية تحويل قيمة صرف الآن؛`parallel()` و `pipeline()` تركيب مستقل عمل؛`phase()` و `log()` لـ مراقبة من سرد وصف دخول درجة.

```text
// Script body — runs with top-level await, ends with a JSON return value:
const reviews = await parallel([
  () => agent('Review src/a.ts for correctness'),
  () => agent('Review src/b.ts for correctness'),
])
return { reviewed: reviews.length }
```

نص برمجي تسوية وقت، تشغيل result بـ قيمة راجعة، انتهاء سبب و قد بدء فرعي agent عدد كمية صرف الآن. نص برمجي لا قيمة راجعة وقت نيل إلى `null`.

### تحرير مسار طريقة تشغيل

إضافة مستهلك يمكن مباشر بدء تشغيل:`ctx.workflowEngine.start({ script, meta, args?, parent, signal? })`.`parent` يأخذ كل فرعي agent ملكية في استدعاء هو agent؛`signal` في في توقف وقت إلغاء تشغيل.`start()` في تشغيل وجود قبل تحقق meta كتلة و تحليل نص برمجي، لذلك صيغة خطأ طلب سوف قيام أي بـ مخالفة قاعدة بيان فشل.

إرجاع تشغيل عام `id`،`meta`،`result`،`cancel(reason?)` و `dispose()`.result أبدا رفض: نص برمجي فشل بـ `stopReason: 'error'` صرف الآن، إلغاء بـ `'cancelled'` صرف الآن. استدعاء جهة يملك هذا تشغيل——كل بند مسار كل يلزم استدعاء `dispose()`؛ هو سوف إلغاء باق بقية عمل، و حسب مزود دورة الحياة اتفاق انتظار نص برمجي و فرعي agent تنظيف إتمام.

### فشل و استعادة

لا يمكن تحليل نص برمجي، صيغة خطأ meta كتلة، غير ممكن استخدام مزود توجيه أو لا تلقي دعم حمل مفرد مرة تشغيل حد، كل سوف في تشغيل وجود قبل يتم تزامن رفض؛`workflow` أداة يأخذ هذه تقرير إبلاغ لـ نموذج يمكن إصلاح صحيح خطأ. تنفيذ خلال، خطاف خطأ استخدام——خطأ معامل، لم معرفة خيار، لا دعم حمل schema، تجاوز خروج حد أعلى——سوف واضح إنهاء نص برمجي، بينما لن تحويل لـ تدريجي بند `null`. عادي فرعي agent فشل لا هو أساس أساس ضبط تطبيق خطأ:`agent()` بـ `null` صرف الآن، من نص برمجي قرار مثل أي معالجة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير قدرة مثل أي تفكيك قسم، اتفاق يقع في أي موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة يأخذ نص برمجي، تشغيل، نتيجة و حدث اتفاق نفس تنفيذ قسم فتح: أي جذب محرك كل يمكن في نفس مفردات خلف بعد تنفيذ `ctx.workflowEngine`، واحد سياق معا فقط لديه واحد جذب محرك——تحميل ثاني عدد جذب محرك سوف واضح تقرير خطأ، لذلك أكثر تبديل جذب محرك معنى طعم حال أكثر تعديل تركيب الذي تحميل جذب محرك إضافة.`workflow/*` حدث فقط توفير مراقبة:payload يحمل تشغيل هوية لقطة، أبدا يحمل نشط حركة تشغيل، لذلك مستمع لا يمكن أخذ نيل إلغاء أو dispose إذن.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | خدمة تعريف،`workflow/*` حدث إعلان،`WorkflowError` و ذلك fatal علامة سجل |
| [`src/types.ts`](src/types.ts) | متصفح أمان مفردات:`WorkflowMeta`،`WorkflowResult`، تشغيل و agent حدث معلومة |
| [`src/runtime-types.ts`](src/runtime-types.ts) | فقط مضيف `WorkflowStartRequest` و `WorkflowRun` جملة مقبض |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة: حدث إعداد مقابل و هوية تحقق |

### دورة الحياة و ملكية

تشغيل من يحتفظ جهة مسؤول: جذب محرك إضافة إزالة سوف منع توقف جديد بدء، لكن لن سحب إلغاء قد قبول تشغيل، استدعاء جهة يجب dispose ذاتي ذات بدء كل تشغيل.`dispose()` في حاجة وقت إلغاء، و انتظار نص برمجي و فرعي agent تنظيف إتمام.PTC جذب محرك قيام أي في توقف تلقي إدارة عملية؛ فرعي agent مورد تحرير ما زال التزام دوران كل subagent مزود دورة الحياة اتفاق.

`workflow/start` و `workflow/end` لـ تشغيل إعداد مقابل؛`workflow/phase` و `workflow/log` يحمل نص برمجي سرد وصف؛`workflow/agent-start` و `workflow/agent-end` حسب `seq` لـ كل مرة فرعي agent استدعاء إعداد مقابل. كل مستمع كل مستقل عزل: رمي خطأ مستمع فقط سجل سجل، لن جوع ميت نفس درجة مستمع أو تغيير تنفيذ، و كما كل مستمع كل سوف استلام إلى ذاتي ذات payload فرعي هذا.

### فشل سجل قاعدة

`WorkflowError` يحمل آلة جهاز يمكن توجيه code و `fatal` علامة سجل؛ كل code كل هو يؤدي أمر،`parallel()` و `pipeline()` سوف إعادة رمي خروج يؤدي أمر خطأ، بينما لا هو يأخذ بند خريطة لـ `null`——تجميع خطأ خيار يجب واضح إنهاء نص برمجي.code تغطية بدء فشل، اتفاق مخالفة قاعدة، تجاوز خروج حد أعلى، مزود و نتيجة لذا عائق، غير ممكن تسلسل تحويل قيمة و إلغاء؛ كامل تجميع دمج و يحتوي معنى رؤية [`src/index.ts`](src/index.ts).

تدريجي بند `null` فقط إبقاء إعطاء فرعي تشغيل فشل و مرحلة مقطع داخل عادي نص برمجي خطأ، لذلك بـ غير إتمام انتهاء سبب صحيح معتاد تسوية فرعي agent لا يخص أساس أساس ضبط تطبيق استثناء:`agent()` إرجاع `null`، يجعل نص برمجي معالجة عادي فرعي agent فشل.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا قدرة بعد لم دعم حمل ماذا. هو جمع هو حالي قيد، لا هو مهمة تراكم ضغط.

- **فقط دعم حمل قبل منصة استلام تجميع**——استدعاء جهة يملك واحد نشط حركة تشغيل و انتظار هو؛ خلفية بدء/جولة استفسار،spill جملة مقبض و قسم مغادرة استلام تجميع متساو مؤقت مؤقت.
- **لا يوجد سجل تحويل أو استعادة**——نص برمجي، فرعي agent دخول درجة و في بين قيمة متساو لا ضبط فحص نقطة، لذلك عملية إعادة بدء بعد لا يمكن متابعة تشغيل.
- **لا يوجد قد حفظ أو تضمين طقم سير العمل**——هذا قدرة فقط بدء استدعاء جهة توفير نص برمجي، سير العمل نص برمجي لن استلام إلى لأجل تمرير عودة تحرير ترتيب `workflow()` خطاف.
- **لا يوجد token ميزانية مفردات**——جذب محرك حد تزامن، بند و فرعي agent، لكن طلب و نتيجة كل لن موحد حساب عبر فرعي agent نموذج token.
- **تشغيل من يحتفظ جهة مسؤول، لا من خدمة تتبع أثر**——إزالة جذب محرك لن اكتشاف مستقل نشط حركة جملة مقبض؛ كل مستهلك كل يجب dispose ذاتي ذات بدء تشغيل.
