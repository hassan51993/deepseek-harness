# @deepseek-ai/dsh-tool-ralph

[English](README.md) | العربية

## عام وصف

`ralph` إبرة مقابل واحد غير ممكن تغيير هدف تشغيل من كثير عدد كل جديد فرعي agent مجموعة صار قبل منصة تسلسل، كل Round فقط استقبال فوق واحد نسخة محدود تقرير إبلاغ و مشترك مساحة العمل حالة. هو سوف في worker تقرير إبلاغ إتمام أو أداة جسم منع سد، أو بلوغ إلى إعداد Round حد أعلى وقت إرجاع؛ هذه تقرير إبلاغ لن نيل إلى مستقل تحقق. أب درجة محادثة و أولا قبل فرعي agent جلسة أبدا سوف نسخ إلى جديد Round. فقط عند مباشر مستخدم واضح اشتراط Ralph صيغة كل جديد agent تكرار بديل وقت استخدام هو؛ عادي طويل مدة عمل طلب استخدام goal أداة، محدود تفويض إرسال طلب استخدام subagent أو سير العمل.

## استخدام هذه الحزمة

`ralph` أداة تشغيل ثابت قبل منصة حلقة: كل Round واحد كل جديد فرعي agent في مشترك مساحة العمل في معالجة غير ممكن تغيير هدف، فقط لديه واحد نسخة محدود بنية تحويل تقرير إبلاغ عبر تجاوز Round. فقط عند مباشر مستخدم واضح اشتراط Ralph حلقة أو كل جديد agent تكرار بديل تنفيذ وقت استخدام هو. عادي طويل مدة نفس جلسة عمل طلب استخدام goal أداة؛ محدود تفويض إرسال و مروحة خروج طلب استخدام عادي subagent أو `workflow` أداة.

### استدعاء أداة

نموذج إيداع `{ objective, maxRounds? }`، استدعاء سوف منع سد إلى كامل تشغيل تسوية. نشر إعداد في `maxRounds` حيث هو قيمة افتراضية، أيضا هو استدعاء تغطية قيمة حد أعلى. نهاية حالة نتيجة لـ `complete`،`blocked` أو `budget-limited`، يحمل الأكثر بعد واحد نسخة محدود تقرير إبلاغ و قد بدء Round عدد كمية؛ عادي فرعي agent فشل سوف إرجاع خطأ، منها علامة واضح فشل Round، و في وجود وقت إبقاء فوق مرة نجاح تسليم وصل.

### كل Round يرى ماذا

كل فرعي agent فقط استقبال غير ممكن تغيير هدف، حالي Round و ذلك حد أعلى، واحد بند «مشترك مساحة العمل هو مرجعي حالة» إشارة أمر و فوق واحد نسخة بنية تحويل تسليم وصل؛ أب درجة محادثة و أولا قبل فرعي agent جلسة أبدا سوف بصفة نوع فرعي. مساحة العمل هو عبر Round طويل مدة تسجيل ذاكرة. تقرير إبلاغ يحمل حالة (`continue`،`complete` أو `blocked`) ، غير فارغ ملخص، دليل، لاحق خطوة و منع سد نص؛ بلا فاعلية أو مرور كبير تقرير إبلاغ سوف جعل سير العمل فشل، بينما لن يتم قطع قطع أو خطأ إقرار لـ حد أعلى استهلاك كل.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `subagentProvider` | `spawn` | كل Round استخدام كل جديد بنية تحويل إخراج مزود. |
| `maxRounds` | `256` | مرة Ralph تشغيل قيمة افتراضية و نشر حد أعلى. |
| `maxHandoffChars` | `16384` | واحد نسخة Round تقرير إبلاغ تسلسل تحويل بعد الأكثر كبير محرف عدد. |
| `maxResultChars` | `16384` | إرجاع إعطاء أب درجة كامل نجاح نتيجة الأكثر كبير محرف عدد. |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-tool-ralph) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر. إعداد مزود يجب وجود، دعم حمل بنية تحويل إخراج، و تقرير إبلاغ `inheritsParentContext: false`؛ إبرة مقابل مخالفة عكس هذا اشتراط مزود إرسال بدء استدعاء وقت، سوف في أي Round بدء قبل مباشر تقرير خطأ.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير ثابت نص برمجي تصميم و تحقق و دورة الحياة آلية؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

حلقة هو نشر جهة يملك ثابت نص برمجي: نموذج فقط توفير بيانات، لا يمكن تغيير حلقة، مزود توجيه،schema أو تسليم وصل تحقق. هذا أداة هو أساس في `ctx.workflowEngine` و `ctx.subagents` عادي إضافة——لن نحو `agent-loop` إضافة Ralph نمط أو كل جديد agent loop، نفس جلسة goal مجال أيضا إبقاء مستقل.[Harness طبقة هدف صيغة تنفيذ Agent Note](../../../.agents/notes/implemented/feature/2026-07-16-harness-level-loop.zh.md) يملك سياسة و مؤقت مؤقت أمر بند.

### ثابت نص برمجي و توجيه

إعداد مزود بـ `WorkflowStartRequest.subagentProvider` نقل تمرير، لذلك ثابت نص برمجي لا يمكن فحص أو أكثر تعديل توجيه، عادي نموذج تحرير كتابة `workflow` أداة أيضا لن لذلك نيل نيل مزود اختيار جهاز. تحليل بعد Round حد أعلى بـ `WorkflowStartRequest.maxTotalAgents` نقل تمرير، جعل ثابت حلقة و جذب محرك فرعي agent مجموع عدد بعد تجهيز حد أعلى تنسيق نفس؛ حد أعلى تجاوز مرور جذب محرك نشر حد أعلى وقت، جذب محرك سوف في إصدار تشغيل قبل رفض.

### تقرير إبلاغ تحقق

خاص تحديد حالة دلالة و تسلسل تحويل بعد `maxHandoffChars` حد أعلى سوف في ثابت سير العمل داخلي و مستهلك حد كل تحقق مرة: متابعة تقرير إبلاغ حاجة لاحق خطوة و فارغ منع سد، إتمام تقرير إبلاغ حاجة دليل كما لا يوجد لاحق خطوة، منع سد تقرير إبلاغ حاجة أداة جسم منع سد. بلا فاعلية، ناقص أو مرور كبير تقرير إبلاغ سوف جعل سير العمل فشل.

### دورة الحياة و إلغاء

استدعاء جهة agent هو كل كل جديد فرعي agent أب درجة، لذلك سوف إبقاء cwd و جدول نظام، لكن لن نسخ ذلك محادثة.`exec.signal` دخول سير العمل جذب محرك، معا أيضا جسر وصل إلى `run.cancel()`، بـ سهل لا اعتماد أداة جسم تنفيذ. أداة انتظار `run.result` و في `finally` في استدعاء `run.dispose()`، لذلك يتم إلغاء أب درجة خطوة سوف انتظار إلى عملية و فرعي agent تنظيف إتمام بعد عندئذ إرجاع.PTC جذب محرك لا ضبط كامل جسم سير العمل مرور مرور وقت قطع توقف؛ استدعاء جهة إلغاء ما زال توليد فاعلية.

### تصيير معنى رسم

انتظار معالجة استدعاء استخدام `generic` بطاقة، عنوان لـ `ralph`، غير ممكن تغيير هدف بصفة ذلك `rawInput`؛ نتيجة متابعة استخدام generic بطاقة. اثنان عدد عرض دالة كل فقط اعتماد أداة معامل و قد تسوية أداة حزمة شبكة، إتمام و منع سد وسم سوف شرح نتيجة من worker تقرير إبلاغ، بينما غير مستقل إقرار إثبات.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: ثابت نص برمجي، مزود توجيه، تقرير إبلاغ تحقق، أداة تسجيل |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا موجه إلى نموذج تحرير ترتيب مهايئ لا يملك مستقل حدث تدفق؛ سير العمل و subagent ملكية جهة سوف تحقق هذا مهايئ بدء تشغيل و ذلك فرعي agent دورة الحياة. |

</details>

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى ماذا

في هذا إضافة تسجيل أثر مجال داخل، كل أب درجة طلب كل سوف استلام إلى تحت جهة ثابت توجيه إشارة توجيه.

##### Ralph إشارة توجيه

```markdown
Use the ralph tool ONLY when the direct human explicitly asks for a Ralph loop or fresh-agent iterative execution. Each Ralph round starts a fresh child with no conversation seed and uses the shared workspace as durable memory. Completion and blockers are worker reports, not independent evaluation. Use same-session goal tools for ordinary long-running objectives, and plain subagents or workflows for bounded delegation and fan-out.
```

#### Token أثر

إضافة تفعيل خلال، كل طلب كل سوف إنتاج قليل كمية ثابت إشارة توجيه token فتح إلغاء.

#### KV Cache أثر

فقط يلزم إضافة أثر مجال و إشارة توجيه نص ثابت، بادئة حينئذ إبقاء مستقر. تفعيل أو dispose(مورد تحرير) ممكن سوف جعل من هذا نص التوجيه مقطع بدء ذاكرة مؤقتة إعادة استخدام بطلان.

### أداة schema

#### نموذج يرى ماذا

قد توليد [`ralph` schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-ralph) عام واحد لا بد ملء `objective` نص و واحد اختياري `maxRounds` عدد حرف. مزود اختيار، تسليم وصل كبير صغير، تقرير إبلاغ schema، سير العمل نص برمجي و تحرير ترتيب سلوك متساو من نشر جانب تحكم، لا في استدعاء schema في.

#### Token أثر

أداة مرئي وقت، كل طلب كل سوف إنتاج قليل كمية ثابت schema token فتح إلغاء.

#### KV Cache أثر

فقط يلزم تعريف و مرئي صفة ثابت، بادئة حينئذ إبقاء مستقر.

### فرعي agent طلب و أب درجة نتيجة

#### نموذج يرى ماذا

كل فرعي agent كل سوف يرى مستقل ثابت Round نص التوجيه و بنية تحويل إخراج التقاط اتفاق. أب درجة فقط يرى أصلي استدعاء و واحد نهاية حالة نتيجة، منها يتضمن worker تقرير إبلاغ حالة،Round عدد كمية و جميل تحويل ضرب طبع نهائي تقرير إبلاغ؛ في بين فرعي agent رسالة و تقرير إبلاغ لن دخول أب درجة محادثة. عادي فرعي agent فشل وقت تعديل لـ إنتاج خطأ، منها يتضمن مقابل Round تحرير رقم؛ من ثاني عدد Round بدء، أيضا سوف يتضمن فوق مرة نجاح تسليم وصل.

#### Token أثر

كل Round كل سوف دعم دفع كل جديد فرعي agent سياق صار هذا.`maxHandoffChars` حد عبر Round حالة،`maxResultChars` مستقل حد كامل أب درجة نجاح نص؛ فرعي agent عمل إبقاء في أب درجة سياق خارج.

#### KV Cache أثر

كل كل جديد فرعي agent كل لديه مستقل طلب ذاكرة مؤقتة. أب درجة نتيجة إلحاق في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا أداة بعد لم دعم حمل ماذا. هو جمع هو حالي قيد، لا هو مهمة تراكم ضغط.

- **إتمام من worker ذاتي سطر إعلان**——لا يوجد مستقل تقييم تقدير جهاز أو تحقق جهاز حكم قطع هدف هل إتمام؛ تقييم تقدير جهاز سياسة و تقييم تقدير جهاز قيادة تأخير متابعة متساو مؤقت مؤقت.
- **فقط دعم حمل قبل منصة**——لا يوجد job id، خلفية استلام تجميع، عملية استعادة فحص نقطة، مجدول أو أساس في تعليق ساعة وقت بدء سياسة.
- **مساحة العمل هو وحيد عبر Round طويل مدة تسجيل ذاكرة**——واحد نسخة محدود تقرير إبلاغ بصفة صريح تسليم وصل، كل فرعي agent انتهاء بعد، لم إيداع محادثة دفع إدارة كل سوف إزالة فقد.
- **واحد Round مقابل واحد كل جديد فرعي agent**——Round داخل لا يوجد مروحة خروج، نموذج أو مزود تبديل،fork سياق أو من نموذج استدعاء اختيار مزود.
- **عادي فرعي agent فشل سوف إنهاء تشغيل**——ثابت نص برمجي تقرير إبلاغ فشل Round و فوق مرة نجاح تسليم وصل، لكن لن إعادة محاولة؛ يؤدي أمر سير العمل أساس أساس ضبط تطبيق فشل ممكن في هذا حالة إرجاع قبل انتهاء.
- **تجمع دمج عمل كمية فقط تلقي Round عدد كمية حد**——token، قيمة إطار و استهلاك وقت ميزانية متساو مؤقت مؤقت.
