# @deepseek-ai/dsh-workflow-ptc

[English](README.md) | العربية

## عام وصف

في كل جديد Node عملية في حسب استدعاء Session ملف صندوق رملي سياسة تشغيل JavaScript سير العمل. نص برمجي إبقاء `agent()`،`parallel()`،`pipeline()`،`phase()` و `log()` خطاف، تفويض إرسال عمل من subagent إتمام. نفس عدد تنفيذ مزود خدمة PTC و سير العمل، يشمل يحتاج صريح تفعيل Ralph حلقة. تشغيل لا يوجد كامل جسم مرور مرور وقت قطع توقف؛ إلغاء سوف إيقاف تلقي إدارة عملية و تحرير فرعي agent. الذي اختيار صندوق رملي و عملية فرعية مزود قرار قوي صنع قدرة و تنظيف حد.

## استخدام هذه الحزمة

في توفير subagent، صندوق رملي سياسة و [Node PTC وقت التشغيل](../../ptc-runtime/ptc-runtime-node/README.zh.md) تركيب في تركيب هذا جذب محرك. هو لـ `dsh-tool-workflow` و صريح تفعيل وقت `dsh-tool-ralph` توفير سير العمل تنفيذ.Ralph في قد إصدار افتراضي تركيب في إبقاء منع استخدام. جذب محرك في تحميل وقت رفض غير TypeScript PTC مزود.Python PTC تركيب يجب منع استخدام `workflow-ptc`،`tool-workflow` و أي قد تفعيل `tool-ralph` بند.

### الأكثر صغير إعداد

فوق وصف اعتماد متاح بعد، تركيب جذب محرك و ذلك موجه إلى نموذج مستهلك:

```yaml
- name: '@deepseek-ai/dsh-workflow-ptc'
- name: '@deepseek-ai/dsh-tool-workflow'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `provider` | `spawn` | `agent()` استدعاء استخدام مضيف جانب subagent مزود. |
| `maxConcurrentAgents` | `0` | تزامن `agent()` حد أعلى؛`0` أصل حسب متاح CPU و سطر درجة تحليل. |
| `maxTotalAgents` | `1000` | مرة تشغيل الأكثر كثير بدء `agent()` استدعاء عدد. |
| `maxItemsPerCall` | `4096` | مرة `parallel()` أو `pipeline()` استدعاء قبول بند عدد. |
| `syncTimeoutMs` | `5000` | نص برمجي الأكثر أول تزامن قطعة مقطع VM مهلة وقت، مفرد موضع لـ جزء ثانية. |

مسؤول تشغيل مستهلك يمكن لـ مرة تشغيل ضبط `WorkflowStartRequest.subagentProvider` و خفض منخفض `WorkflowStartRequest.maxTotalAgents`. نص برمجي خطاف لا يستطيع أكثر تعديل هذا اثنان بند اختيار. عملية كومة، إخراج، تحكم عبر معلومة و إنهاء حد من Node PTC مزود مسؤول؛ جذب محرك لا زيادة كامل جسم مرور مرور وقت تحديد وقت جهاز. توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-workflow-ptc) تعريف يمكن قبول جذب محرك حقل.

Node PTC مزود `maxPendingCalls` أيضا حد سير العمل تزامن: فرعي agent بدء، نتيجة انتظار و مورد تحرير سوف احتلال استخدام هذه اسم مقدار. دخول درجة دفعة مرة حتى كثير مجددا احتلال استخدام واحد اسم مقدار. ضبط `maxConcurrentAgents` وقت ينبغي مسبق إبقاء بقية كمية.

### نتيجة و فشل

نص برمجي دعم حمل قمة طبقة `await`؛`meta` و `args` بصفة JSON بيانات نقل دخول. كل مرة `agent()` استدعاء استخدام إعداد subagent مزود و تشغيل ثابت أب درجة. نهائي بلا ضرر JSON قيمة راجعة يصبح تشغيل نتيجة؛ عادي فرعي agent فشل جعل `agent()` بـ `null` صرف الآن.

بلا فاعلية بيانات وصفية، لا يمكن تحليل متن، غير ممكن استخدام مزود توجيه أو عال في حد أعلى مفرد مرة تشغيل حد أعلى، في تشغيل إصدار قبل يتم رفض. تنفيذ خلال، خطاف خطأ استخدام و تجاوز خروج تنسيق عمل صيغة حد أعلى سوف جعل سير العمل فشل. عملية فشل، الذي يحتاج قيد غير ممكن استخدام، و تجاوز خروج PTC إخراج أو تحكم حد أيضا سوف جعل تشغيل فشل.

### ملف سياسة و إلغاء

جذب محرك لـ PTC تنفيذ تحليل استدعاء Session معتاد ضبط ملف سياسة و cwd.VM إبقاء وثيقة شرح مساعد مساعدة API، لكن هو لا هو أمان حد: لمس بلوغ Node شفرة ما زال تلقي الذي اختيار OS ملف سياسة قيد. برنامج مرئي بيئة لـ فارغ. ملف سياسة لا حد شبكة شبكة وصول.

سير العمل نحو PTC طلب `timeoutMs: null`. الأكثر أول VM قطعة مقطع ما زال تلقي `syncTimeoutMs` حد، استدعاء جهة في توقف إشارة ما زال توليد فاعلية، يشمل خارج طبقة أداة قطع توقف. إلغاء قيام أي في توقف PTC عملية و انتظار بدء أو نشط وثب subagent. استدعاء جهة يجب تحرير كل مرة تشغيل و انتظار فرعي agent تنظيف؛ لا آخر ضبط سير العمل تنظيف تحديد وقت جهاز.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

سير العمل جذب محرك مسؤول تحرير ترتيب؛PTC مزود مسؤول عملية بدء،OS قيد، قسم لقطة نقل و تلقي إدارة عملية تنظيف.

### تصميم إدارة فكرة

واحد ذاتي يتضمن guest برنامج في PTC Node عملية في تشغيل قائم VM و سير العمل مساعد مساعدة دالة.Host ربط سوف هذا برنامج اتصال إلى `ctx.subagents` و سير العمل مراقبة جهاز. جذب محرك في تشغيل بدء وقت التقاط وقت التشغيل و subagent خدمة، لذلك قد قبول تشغيل في جذب محرك إزالة بعد ما زال حفظ لديه اعتماد.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | جذب محرك إعداد، طلب تحقق و تشغيل إنشاء |
| [`src/host.ts`](src/host.ts) | PTC تنفيذ، فرعي agent ملكية، تسوية و مورد تحرير |
| [`src/guest.ts`](src/guest.ts) | أساس في PTC Host ربط guest مهايئ |
| [`src/guest-source.ts`](src/guest-source.ts) | ذاتي يتضمن guest برنامج شفرة المصدر |
| [`src/runtime.ts`](src/runtime.ts) | VM طلب قيمة، مساعد مساعدة دالة اتفاق و تركيب جهاز |
| [`src/realm.ts`](src/realm.ts) | عبر VM realm بلا ضرر JSON شيء تحويل |
| [`src/meta.ts`](src/meta.ts) | بيانات وصفية تحقق و مواصفة تحويل |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ سير العمل خدمة مسؤول حدث إعداد مقابل،PTC مسؤول تلقي إدارة عملية مراقبة قياس. |

### قيمة و فرعي agent ملكية

guest في PTC نقل قبل سوف خروج محطة قيمة شيء تحويل لـ بلا ضرر JSON. خاص خاص أصل نوع، دالة،symbol، حلقة، نادر متباعد عدد مجموعة، غير لديه حد عدد و تضمين طقم `undefined` يتم رفض. فرعي agent نتيجة بـ JSON إرجاع؛ نفس عملية مراقبة حدث إبقاء ذاته تغلب ضخم و عودة ضبط استثناء عزل قاعدة.

Host قسم آخر تتبع أثر انتظار إتمام مزود بدء و قد إصدار فرعي agent. مشترك في توقف إشارة إغلاق هذا اثنان بند مسار؛ إلغاء بعد عندئذ حينئذ خيط فرعي agent سوف يتم تحرير. كل قد إصدار فرعي agent مورد تحرير من كل تنظيف مسار مشترك.PTC إيقاف برنامج بعد، إجراء في Host ربط ما زال من سير العمل مهايئ مسؤول.

### إلغاء و نتيجة

رقم واحد يتم قبول نهاية حالة يملك تشغيل نتيجة. إلغاء قيام أي إيقاف عملية، لا انتظار guest تأكيد. عملية تسوية و فرعي agent تنظيف ما زال هو اثنان بند مستقل معنى خدمة؛ عام مورد تحرير عملية انتظار اثنان من. قائم سير العمل بدء/انتهاء إعداد مقابل و فرعي agent دورة الحياة إسقاط إبقاء ثابت.

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent طلب

#### نموذج يرى ماذا

نص برمجي كل مرة استدعاء `agent()`، كل سوف يأخذ نص التوجيه أصل مثال إرسال إعطاء subagent مزود، و مرفق حمل اختياري نموذج أو بنية تحويل إخراج schema. كل فرعي agent يرى هذا مزود ذاتي ذات سياق؛phase و log سرد وصف فقط إبقاء في مراقبة جهاز حدث في.

#### Token أثر

كل فرعي agent إزالة استهلاك ذاتي ذات نموذج سياق. تنسيق عمل صيغة تزامن،agent مجموع عدد و بند حد أعلى حد عادي نص برمجي مروحة خروج؛ فرعي agent تاريخ لن مباشر إضافة دخول أب درجة تاريخ.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة و نفس درجة فرعي agent متبادل متبادل مستقل. كل فرعي agent فقط قدرة في ذاتي ذات مزود، نموذج، نص التوجيه و schema تحت إعادة استخدام تدريجي بايت نفسه بادئة.

### أب درجة أداة نتيجة (بين وصل)

#### نموذج يرى ماذا

أداة مستهلك عرض نهائي JSON قيمة و فرعي agent عدد كمية، أو سير العمل فشل. في بين فرعي agent إخراج ما زال يمكن توفير نص برمجي استخدام. نص برمجي تحليل، مساعد مساعدة دالة خطأ استخدام، فرعي agent أساس أساس ضبط تطبيق فشل و PTC تنفيذ فشل سوف إنتاج خطأ؛ عادي فرعي agent فشل إنتاج `null`، من نص برمجي معالجة.

#### Token أثر

جذب محرك لا مباشر نحو أب درجة زيادة token.PTC حد خارج طبقة برنامج نتيجة، أداة مستهلك مسؤول ذلك موجه إلى نموذج تصيير و إبقاء.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

هذه حد حد تحديد سير العمل تنفيذ و تنظيف.

- **ملف قيد و تنظيف وراثة مزود حد**——Node PTC و عملية فرعية مزود تعريف قوي صنع قدرة كامل درجة و تلقي إدارة عملية نطاق.
- **سير العمل حد أعلى هو تنسيق عمل صيغة**——مساعد مساعدة دالة حساب عدد جهاز حد عادي نص برمجي؛ هو جمع لا هو Host قوي صنع أمان إعداد مقدار أو بعد بديل token ميزانية.
- **لا يوجد كامل جسم مرور مرور وقت قطع توقف**——تشغيل يمكن حمل متابعة إلى إتمام، فشل أو إلغاء. استدعاء جهة قطع توقف ما زال ملائم استخدام.
- **فرعي agent تنظيف التزام دوران مزود اتفاق**——مهايئ انتظار مورد تحرير و انتظار إتمام بدء، لا آخر ضبط وضع ترك انتظار تحديد وقت جهاز.
- **VM لا هو أمان حد**——لا توفير عام متغير لأجل إشارة توجيه نص برمجي عمل من؛OS سياسة قيد لمس بلوغ Node شفرة.
- **عبر realm خطأ في نص برمجي داخل لا يمكن عبر `instanceof Error`**——أصل حسب `name` و `code` انتظار مستقر حقل فرع.
