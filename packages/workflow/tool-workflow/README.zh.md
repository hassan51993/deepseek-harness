# @deepseek-ai/dsh-tool-workflow

[English](README.md) | العربية

## عام وصف

`dsh-tool-workflow` يجعل نموذج تشغيل JavaScript تحرير ترتيب نص برمجي، يأخذ عمل تفويض إرسال إعطاء كثير عدد subagent، و إرجاع نص برمجي نهائي JSON قيمة. فقط عند مستخدم واضح اشتراط سير العمل أو كبير نوع كثير agent(ذكي جسم) تحرير ترتيب وقت استخدام؛ واحد اثنان بند تفويض إرسال ينبغي استخدام عادي subagent استدعاء. أب درجة جولة سوف انتظار كل تفويض إرسال مهمة انتهاء؛ إلغاء أو استثناء إتمام سوف إرجاع خطأ، بينما لا هو جزء نجاح. نشر جهة يمكن عبر `toolName` إعادة تسمية أداة، و عبر `maxResultChars` حد تصيير نتيجة نص.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

`workflow` أداة تشغيل من نموذج تحرير كتابة تحرير ترتيب نص برمجي، يأخذ عمل مروحة خروج إلى كثير عدد subagent، و إرجاع نص برمجي نهائي JSON قيمة. فقط عند مستخدم واضح اشتراط سير العمل أو كبير نوع كثير agent تحرير ترتيب وقت استخدام——مثال مثل عبر كثير عدد ملف مراجعة حساب، مرة ترحيل، كثير زاوية درجة بحث بحث؛ واحد اثنان بند تفويض إرسال وقت أولوية استخدام عادي subagent استدعاء.

### استدعاء أداة

نموذج إيداع ثلاثة عدد معامل:`meta`(مطلوب هوية بيانات:`name`،`description`، و اختياري `whenToUse` و `phases`) ،`script`(مطلوب صاف JavaScript نص برمجي جسم——لا يحتوي `export const meta` لغة جملة؛ أداة وصف يحمل كامل تحرير كتابة اتفاق) و `args`(اختياري JSON كائن، بصفة عام متغير `args` نحو نص برمجي عام؛ عار قائمة ينبغي حزمة تركيب إلى حقل في، جعل بروتوكول schema مثل فعلي جدول بلوغ شكل).

نجاح إرجاع مواصفة حزمة شبكة `{ runId, agentsStarted, result }`، نحو نموذج تصيير لـ `workflow "<name>" completed (<count> agent<optional-s>).`، بعد وصل `Return value:` و جميل تحويل ضرب طبع JSON. لا يمكن بدء سير العمل——نص برمجي تحليل أو meta تحقق فشل——إرجاع نموذج يمكن إصلاح صحيح خطأ. إلغاء و تنفيذ فشل إرجاع `Error: workflow run was cancelled` أو `Error: workflow run failed: <error>`؛ جزء إخراج أبدا سوف يتم تقرير إبلاغ لـ نجاح.

### تشغيل خلال مسبق مدة

نص برمجي تشغيل خلال، أب درجة جولة سوف انتظار: أداة بدء تشغيل، انتظار ذلك نتيجة، و بداية نهاية مقابل هذا تشغيل تنفيذ dispose(مورد تحرير) ، لذلك نص برمجي و ذلك فرعي agent في كل بند مسار فوق تماما توقف مستقر——يشمل من أب درجة خطوة في توقف إشارة جسر وصل بينما قدوم إلغاء. نموذج فقط يرى نهائي نتيجة، دائم بعيد لن يرى في بين فرعي agent رسالة؛ فرعي agent ذاتي ذات عمل لن دخول أب درجة محادثة.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `toolName` | `workflow` | يلزم تسجيل موجه إلى نموذج أداة اسم. |
| `maxResultChars` | `50000` | تصيير نتيجة حد أعلى؛ أكثر طويل JSON سوف يتم قطع قطع و مرفق فوق تلميح. |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-tool-workflow) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مستهلك مثل أي و جذب محرك تفكيك قسم، تشغيل دورة الحياة و سجل مثل أي عمل؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

مستهلك يملك نموذج جانب schema،`tool:<toolName>` توجيه النظام إشارة توجيه و نتيجة حزمة شبكة؛ نص برمجي تحليل، تنفيذ، حد أعلى و إلغاء يقع في `ctx.workflowEngine` بعد،PTC جذب محرك و `run_code` مشترك Node عملية قيد. استخدام إشارة توجيه بـ نص التوجيه مقطع شكل صيغة مع أداة إضافة تسليم، أبدا وضع دخول نشر persona.

### تشغيل دورة الحياة

`execute` بدء تشغيل، و في `try/finally` داخل انتظار `run.result`؛ هذا بنية مجموع سوف مقابل تشغيل تنفيذ dispose.`exec.signal` سوف جسر وصل إلى `run.cancel()`، يشمل بدء قبل قد في توقف حال حال. غير `completed` انتهاء سبب سوف خريطة لـ تقرير إبلاغ سبب `isError` نتيجة؛ إتمام وقت تصيير `{ runId, agentsStarted, result }`،Native مصير فقط سوف في `maxResultChars` موضع قطع قطع هذا إسقاط.

### حمل دائم جلسة سجل

مقابل في أصل transport تنفيذ (`exec.parent` نقص حذف) ، أداة سوف استخدام أربعة عدد log-only حدث يأخذ تشغيل إسقاط إلى استدعاء جهة agent جلسة:`start()` إرجاع بعد كتابة run-start، فقط سجل `run.id` مطابقة عضو بدء و انتهاء، و كما فقط في نتيجة متاح كما dispose تماما توقف مستقر بعد كتابة run-end. تضمين طقم transport استدعاء وفق معتاد تنفيذ، لكن لا كتابة أي سجل. جلسة إلحاق عملية أول مرة فشل بعد، هذا تشغيل سوف إيقاف لاحق سجل و فقط إبلاغ تحذير مرة، إبقاء تحت فارغ سجل أو دمج قاعدة وصل متابعة بادئة، معا لا تغيير أداة نتيجة و تنظيف. حزمة invariant سوف في بارد تحميل و فوري إلحاق وقت رفض تكرار start، لم إعداد مقابل عضو، ما زال لديه فتح وضع عضو نهاية نقطة و run-end بعد تحديث، معا سماح ناقص نهاية حالة بعد لاحقة وصل متابعة بادئة.

### تصيير معنى رسم

حسب[تصيير معنى رسم Agent Note](../../../.agents/notes/implemented/architecture/2026-07-02-tool-render-intent-union.zh.md) مسبق أولا تحديد: استخدام `generic` بطاقة، عنوان لـ `workflow: <meta.name>`، مباشر من `args.meta.name` قراءة——عرض هو معامل صاف دالة——نص برمجي نص بصفة `rawInput` يحمل. نتيجة متابعة استخدام generic بطاقة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: أداة تسجيل، تشغيل دورة الحياة، سجل جهاز وصل خط |
| [`src/types.ts`](src/types.ts) | أربعة عدد log-only سجل حدث payload و ذلك `SessionEventMap` إعلان |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة إعداد طقم مدخل: حمل دائم سير العمل سجل بروتوكول تحقق |

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى ماذا

في هذا إضافة تسجيل أثر مجال داخل، كل أب درجة طلب كل سوف استلام إلى تحت جهة سير العمل إشارة توجيه. أثر مجال أداة حد يمكن إخفاء schema، بينما لا إزالة هذا مقطع مستقل تسجيل إشارة توجيه.

##### سير العمل إشارة توجيه

```markdown
Use the <toolName> tool ONLY when the user explicitly asks for a workflow or for large multi-agent orchestration: you write a JavaScript script (the tool description documents the exact format) that fans work out across many subagents with phases and structured results. For one or two delegations, prefer plain subagent calls.
```

#### Token أثر

إضافة تفعيل خلال، كل طلب كل سوف إنتاج قليل كمية ثابت إشارة توجيه token فتح إلغاء.

#### KV Cache أثر

فقط يلزم إضافة أثر مجال و إشارة توجيه نص ثابت، بادئة حينئذ إبقاء مستقر. تفعيل أو dispose ممكن سوف جعل من هذا نص التوجيه مقطع بدء ذاكرة مؤقتة إعادة استخدام بطلان.

### أداة schema

#### نموذج يرى ماذا

أداة مرئي وقت، قد توليد افتراضي [`workflow` schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-workflow) يتضمن كامل JavaScript خطاف و بيانات وصفية اتفاق؛`toolName` يمكن إعادة تسمية هذا تعريف، نموذج سوف إيداع نص برمجي، بيانات وصفية و اختياري args.

#### Token أثر

أداة مرئي وقت، كل طلب كل سوف إنتاج مقارنة كبير ثابت schema token فتح إلغاء.

#### KV Cache أثر

فقط يلزم `toolName`، تعريف و مرئي صفة ثابت، بادئة حينئذ إبقاء مستقر. إعادة تسمية، إضافة دورة الحياة أو أثر مجال حد ممكن سوف جعل من هذا schema بدء ذاكرة مؤقتة إعادة استخدام بطلان.

### أداة استدعاء تاريخ و نتيجة

#### نموذج يرى ماذا

من نموذج تحرير كتابة كامل نص برمجي، بيانات وصفية و args سوف إبقاء في assistant أداة استدعاء في. نجاح نتيجة دقيق لـ `workflow "<name>" completed (<count> agent<optional-s>).`، تبديل سطر،`Return value:`، تبديل سطر، و جميل تحويل ضرب طبع كما اعتماد بيانات JSON؛ بلوغ إلى حد أعلى وقت، سوف في جديد سطر إضافة `… [truncated: <omitted> more characters]`. فشل نتيجة دقيق لـ `Error: workflow run was cancelled`(يمكن إلحاق بعد لاحقة ` (<error>)`) ،`Error: workflow run failed: <error-or-unknown error>` أو منع صد صفة `Error: workflow run ended abnormally (<reason>)`؛ لا يوجد الذي تابع agent استدعاء تغيير لـ `Error: workflow tool requires a calling agent (exec.agent was undefined)`. في بين فرعي agent رسالة سوف يتم حذف.

#### Token أثر

استدعاء token ممكن جدا كثير، و سوف إبقاء إلى ضغط (compaction) لـ توقف. نتيجة تصيير تلقي `maxResultChars` حد؛ فرعي نموذج token و أب درجة إبقاء سياق متبادل متبادل مستقل.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا أداة بعد لم دعم حمل ماذا. هو جمع هو حالي قيد، لا هو مهمة تراكم ضغط.

- **أب درجة جولة سوف منع سد إلى كامل سير العمل تسوية**——لا يوجد خلفية بدء/جولة استفسار واجهة، إلغاء سوف إسقاط نطاق جزء إخراج و إرجاع خطأ.
- **`args` يجب هو كائن،Native نتيجة نص محدود**——استدعاء جهة يأخذ قمة طبقة عدد مجموعة/علامة كمية حزمة تركيب إلى حقل في؛ مواصفة سير العمل نتيجة إبقاء كامل، تجاوز مرور `maxResultChars` JSON سوف في موجه إلى نموذج إسقاط في قطع قطع، بينما لا هو تخزين في فحص بحث جملة مقبض خلف بعد.
- **كل مرة أداة تسجيل سير العمل سياسة ثابت**——مزود اختيار، حد أعلى و أداة اسم يخص نشر إعداد، لا هو نموذج استدعاء معامل.
- **حمل دائم سجل فقط تغطية قمة طبقة كما فقط توفير مراقبة**——تضمين طقم PTC mode dispatch لا سجل؛ سجل لذا عائق سوف لحظة معنى تراجع تحويل لـ لا كامل بادئة، بينما لا تغيير تنفيذ.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: بعد لم قرار فتح وضع جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص، حزمة شفرة و متبادل صلة Agent Note لـ دقيق.

فتح وضع جهة نحو: يجعل أب درجة جولة لم يعد منع سد خلفية بدء/جولة استفسار مسار؛ يأخذ قطع قطع JSON تخزين في فحص بحث جملة مقبض خلف بعد، بينما لا هو قص قطع إسقاط؛ سجل تجاوز خروج قمة طبقة تضمين طقم dispatch.

</details>
