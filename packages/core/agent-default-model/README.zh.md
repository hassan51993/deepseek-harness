# @deepseek-ai/dsh-agent-default-model

[English](README.md) | العربية

## عام وصف

`dsh-agent-default-model` في جلسة لم إشارة تحديد نموذج وقت، لـ جديد إنشاء agent توفير مشترك افتراضي مزود و نموذج. استخدام هو يمكن لـ كل تلقي دعم حمل agent مدخل موحد واحد اختيار بدء بداية نموذج، منها يشمل `dsh --profile headless`. ضبط متاح وقت، مستخدم يمكن تغطية قد إعداد اختيار (يشمل دفع إدارة (reasoning) قوي درجة) ، حفظ أكثر تعديل سوف في لاحق قراءة في توليد فاعلية. هذا قيمة افتراضية أثر في كامل عملية؛ حسب جلسة اختيار نموذج ما زال من إنشاء agent مدخل مسؤول.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في إنشاء agent كما لم صريح إعطاء خروج نموذج توجيه أي أرض جهة تركيب هذه الحزمة. هذا خدمة عودة جواب واحد مشكلة——جديد agent ينبغي هذا استخدام أي عدد نموذج؟——لذلك إنشاء agent مدخل استعلام هو، بينما لا لا بد إعادة تنفيذ قيمة افتراضية.

### إعداد قيمة افتراضية

تركيب بند إعداد هو قيمة افتراضية أساس أساس: هو اشتراط مزود و نموذج، و كما لا اعتماد أي ضبط مزود أيضا قدرة استخدام.

```yaml
- name: '@deepseek-ai/dsh-agent-default-model'
  config:
    provider: deepseek
    model: deepseek-chat
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `provider` | لا بد ملء | جديد agent استخدام قد تسجيل مزود توجيه |
| `model` | لا بد ملء | جديد agent استخدام، من مزود يحتفظ نموذج id |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-agent-default-model) هو كل تلقي دعم حمل حقل كامل مشاركة اعتبار.`reasoningEffort` لحظة معنى لا هو إعداد حقل: هو يخص ضبط طبقة، لذلك كامل حفظ اختيار يمكن في تحت واحد اختيار تحديد نموذج لا يوجد دفع إدارة قوي درجة وقت صاف حذف قديم قيمة، بينما تركيب إعداد قيمة سوف مجددا مرة يتم وراثة.

### قراءة و أكثر تعديل قيمة افتراضية

`currentSelection()` لـ جديد إنشاء agent إرجاع واحد نسخة مستقل `{ provider, model, reasoningEffort? }`؛`saveSelection()` لـ لاحق agent حفظ كامل اختيار.

```text
const selection = ctx.agentDefaultModel.currentSelection()
await ctx.agentDefaultModel.saveSelection({ provider, model, reasoningEffort: 'high' })
```

لم تركيب ضبط مزود وقت،`saveSelection()` لا تنفيذ أي عملية، تركيب بند إعداد ما زال لـ حالي قيمة. هذا خدمة لا تحقق دليل عضو علاقة: مزود توجيه يمكن خدمة لم في دليل في عام نشر نموذج؛ إرسال بدء نموذج طلب مستهلك مسؤول متاح صفة تشخيص.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذا خدمة مثل أي تنفيذ فوق وصف سلوك؛ يمكن مراقبة اتفاق قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا خدمة هو واحد تركيب بند إعداد، حمل لديه من ضبط دعم دعم بيانات مصدر. إضافة إعداد توفير أساس أساس `{ provider, model }`؛ تركيب ضبط مزود بعد،`agent-default-model` ضبط قسم عقدة يصبح فوري بيانات مصدر، كل مستهلك كل عبر `currentSelection()` قراءة، لذلك كتابة ضبط بعد بلا حاجة في تسجيل طبقة وجه إعادة بناء.`reasoningEffort` فقط وجود في ضبط schema في: إعداد لا يستطيع يحمل هو، لأن جديد اختيار صاف حذف دفع إدارة قوي درجة بعد، هذا قيمة يجب إبقاء صاف حذف، بينما لا يستطيع مجددا مرة من تركيب إعداد في وراثة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`AgentDefaultModelConfig` خدمة، ضبط قسم عقدة تثبيت،`currentSelection`/`saveSelection` |
| — | لم إصدار وقت التشغيل ثابت صيغة إعداد طقم بند؛ وحيد متغير قيمة علاقة من ضبط تحقق مسؤول. |

### سلوك شرح

اثنان عدد عام طريقة كل فقط هو مقابل هذا بيانات مصدر إجراء بسيط مفرد قراءة كتابة:`currentSelection()` إرجاع واحد كل جديد، مستقل كائن، لذلك استدعاء جهة يمكن يحتفظ هو، بينما لن و خدمة حالة مشترك مرجع؛`saveSelection()` في وجود `ctx.settings` وقت كتابة كامل اختيار.

<a id="model-experience"></a>
## تجربة النموذج

عبر هذا خدمة توفير إعطاء مدخل `ModelSelection` بين وصل أثر؛ نموذج مرئي طلب من طلب تجميع و مزود مهايئ مسؤول.

#### KV Cache أثر

أكثر تعديل قيمة افتراضية فقط أثر بعد من هو تحليل اختيار agent. طلب سجل قد إشارة واضح اختيار قائم جلسة ما زال امتداد استخدام هذا اختيار، لذلك هذا خدمة لن جعل ذلك قد بناء قيام بادئة بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد هذا خدمة نطاق. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **مفرد واحد عملية درجة قيمة افتراضية**——هذا خدمة فقط يملك واحد قيمة افتراضية؛ حسب جلسة نموذج اختيار ما زال من مدخل مسؤول.
- **لا يوجد ضبط مزود وقت لا يمكن إبقاء**——لم تركيب ضبط مزود وقت،`saveSelection()` لا يمكن لـ لاحق agent إبقاء اختيار.
