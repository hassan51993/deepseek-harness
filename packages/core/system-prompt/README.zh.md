# @deepseek-ai/dsh-system-prompt

[English](README.md) | العربية

## عام وصف

`dsh-system-prompt` يجعل agent في كل نموذج خطوة استلام إلى واحد نسخة لديه ترتيب توجيه النظام و متاح أداة schema. حاجة إضافة نص التوجيه مقطع، حركة حالة وقت التشغيل واقع، يمكن إعادة استخدام متغير أو أداة schema، أو من تحكم ثابت harness هوية، نشر persona، وقت التشغيل سياق و موجه إلى نموذج أداة ترتيب وقت، طلب استخدام هذه الحزمة.agent أثر مجال مساهمة سوف حجب حجب نفس اسم عام قيمة افتراضية، بينما لا أثر أخرى agent. بلا فاعلية كامل نص التوجيه تركيب و لم تحليل متغير سوف جعل تجميع فشل، لن نحو نموذج إرسال صيغة خطأ نص التوجيه.

## استخدام هذه الحزمة

في أي تشغيل agent أرض جهة تركيب `dsh-system-prompt`: هو توفير `ctx.systemPrompt`، أي كل نص التوجيه مساهمة الذي سقوط دخول سجل التسجيل. مساهمة حمل أثر مجال——عبر `agent.ctx` تسجيل فقط أثر هذا agent، و حجب حجب نفس اسم عام بند.

<a id="configure-the-prompt"></a>
### إعداد نص التوجيه

إعداد يملك ثابت فتح ساحة أبيض،runtime سياق، نشر persona بادئة و بعد لاحقة و أداة ترتيب؛ ذلك بقية واحد قطع قدوم ذاتي قد تسجيل مساهمة.

```yaml
- name: '@deepseek-ai/dsh-system-prompt'
  config:
    includeHarnessIdentity: true
    includeRuntimeContext: true
    personaPrefix: 'You are the deployment assistant.'
    toolOrder: ['<unlisted-tools>']
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `includeHarnessIdentity` | `true` | هل يتضمن ترتيب لـ −1000 رقم واحد جهة ثابت فتح ساحة أبيض `You are an AI agent powered by DeepSeek Harness.`. فقط عند توافق صفة نشر يملك كامل توجيه النظام وقت ضبط لـ false. |
| `includeRuntimeContext` | `true` | هل في تجميع في يتضمن لديه ترتيب حركة حالة runtime سياق |
| `personaPrefix` | `''` | عام persona بادئة نموذج لوح، ترتيب لـ `0`، يقع في رقم واحد جهة إشارة توجيه قبل |
| `personaSuffix` | `''` | عام `deployment:persona-suffix` نموذج لوح، ترتيب لـ `10200`، يقع في رقم واحد جهة إشارة توجيه بعد |
| `toolOrder` | — | صريح موجه إلى نموذج أداة ترتيب، يحتوي واحد `'<unlisted-tools>'` ذلك بقية بند علامة |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-system-prompt) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر. لا يوجد تماما جيد واحد ذلك بقية بند أو وجود تكرار بند `toolOrder` قائمة سوف في تحميل وقت فشل؛ قد صف اسم لا يوجد مقابل قد تسجيل أداة سوف جعل كل مرة `assemble()` يتم رفض.

### مساهمة نص التوجيه مقطع

مقطع يحمل ساكن حالة أو حسب سياق تحليل نص و `order`؛ هو جمع أولا حسب ترتيب قيمة رفع ترتيب تجميع وصل، ترتيب قيمة نفسه وقت مجددا حسب اسم شفرة وحدة ترتيب ترتيب صف. مستودع ذاتي حمل مساهمة جهة عبر `ctx.systemPrompt.getSectionOrder(name)` تحليل تجميع في قسم إعداد موضع؛runtime-context مساهمة جهة استخدام `getContextOrder(name)`. خارجي مساهمة يمكن استخدام مهمة معنى لديه حد ترتيب قيمة.`complete: true` مقطع سوف في تجميع بعد يصبح دقيق كامل نص التوجيه؛ صالح complete مقطع تجاوز مرور واحد وقت، تجميع سوف فشل.

```text
ctx.systemPrompt.section({
  name: 'tool:bash',
  order: 100,
  text: 'Prefer bash for file and process operations.',
})
```

في مقطع فوق ضبط `interpolate: false` يمكن أصل مثال إبقاء نص، يشمل توليد أداة وثيقة في `{{…}}` مجموعة. أخرى مقطع افتراضي تنفيذ متغير إدراج قيمة.

### مساهمة نص التوجيه متغير

متغير في مقطع نص في بـ `{{name}}` مرجع، و في كل مرة تجميع وقت تحليل؛ حمل أثر مجال متغير سوف لـ هذا agent حجب حجب نفس اسم عام متغير. حلقة توفير `model` و `cwd`؛ أي إضافة كل يمكن تسجيل ذاتي ذات يملك واقع.

```text
ctx.systemPrompt.variable('cwd', ({ agent }) => agent?.session.header.cwd)
```

### مساهمة أداة schema

أداة schema مزود في كل مرة تجميع وقت طلب قيمة، و مساهمة نموذج مرئي `ToolSchema` تجميع دمج؛`ToolRuntime` سوف تلقائي تسجيل ذاته، لذلك كبير كثير عدد أداة في هذا بلا حاجة يد حركة وصل خط. مزود إرجاع حد بعد مرئي تجميع دمج، خارج إضافة `toolOrder` استخدام حد قبل اسم كل تجميع.

### كبح صنع وقت التشغيل سياق

`suppressRuntimeContext()` إزالة استدعاء أثر مجال كل حركة حالة وقت التشغيل سياق مساهمة، لكن لا منع استخدام يملك قاع طبقة واقع خدمة؛ كثير عدد كبح صنع جهاز مستقل تركيب، عند لم يعد وجود كبح صنع جهاز وقت هذا effect سوف استعادة سياق.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذا حزمة مثل أي تنفيذ فوق وصف سلوك؛ يمكن مراقبة اتفاق قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا حزمة هو واحد سجل التسجيل إضافة واحد بند تنسيق عمل صيغة تجميع خط الإنتاج. مرة `assemble()` استدعاء يأخذ عام طبقة و الذي طلب أثر مجال طبقة دمج، قسم مغادرة أداة معامل، أولا حسب عدد قيمة مجددا حسب اسم مواصفة تحويل مقطع ترتيب، تشغيل حسب أثر مجال غربلة اختيار `system-prompt/assemble` waterfall، يأخذ صالح complete مقطع استعادة لـ وحيد نص التوجيه مقطع، و فعلي تطبيق أي حالي توليد فاعلية وقت التشغيل سياق كبح صنع جهاز. مقطع و حركة حالة سياق هو مستقل إدخال: مقطع يصبح نص التوجيه نص، بينما سياق في حلقة تحت يصبح نموذج تاريخ في حمل مصدر user زاوية لون لقطة. أداة schema حسب تصميم يخص تجميع نتيجة——«نموذج نيل معرفة ذاتي ذات قدرة فعل ماذا» هو واحد وصل اختراق كامل جسم، كل إدارة مهايئ يأخذ schema بصفة مستقل wire حقل نقل.

### تجميع و تصيير

تجميع قسم اثنان مرحلة مقطع إتمام طلب قيمة و تصيير:`assemble()` إرجاع نص قد طلب قيمة لكن بعد لم إدراج قيمة مقطع، لديه ترتيب أداة schema، و كل قد تسجيل متغير حسب حالي سياق طلب نيل قيمة؛`renderPrompt()` مقابل لم ضبط `interpolate: false` مقطع إدراج قيمة `{{variable}}` مرجع، حذف فارغ مقطع و استخدام فارغ سطر اتصال——صارم إطار قاعدة: لم معرفة مرجع، قد تسجيل لكن بلا قيمة مرجع أو صيغة خطأ كامل مجموعة كل سوف رمي خروج، لأن صيغة خطأ نص التوجيه مقارنة واضح فشل أكثر سيئ.`toolOrder` في waterfall توزيع قبل مواصفة تحويل استلام تجميع إلى أداة (تسجيل ترتيب فقط هو إضافة تحميل ناتج) ؛ تعديل قائمة waterfall مستمع مقابل ذلك إخراج تحديد صفة مسؤول.

### أثر مجال

حمل أثر مجال مقطع، متغير و أداة مزود سوف لـ مفرد عدد agent حجب حجب عام بند، تجميع waterfall حسب أثر مجال غربلة اختيار توزيع. سجل التسجيل تغيير إشعار (`system-prompt/change`) لحظة معنى لا مرور مرور غربلة اختيار، لأن عام تغيير أثر كل أثر مجال.

<a id="model-experience"></a>
## تجربة النموذج

### توجيه النظام

#### نموذج يرى ماذا

رقم واحد جهة مقطع سقوط اعتماد مرة تصيير harness هوية، نشر persona بادئة (يحتوي نموذج اسم وسيط تعريف) ، يمكن إعادة استخدام إشارة أمر (يشمل توليد أداة SDK و بنية تحويل إخراج إشارة توجيه) ، الأكثر بعد هو يحمل بيئة معلومة بعد لاحقة:harness شفرة المصدر (`10000`) ،Web جدول طبقة (`10100`) و نشر persona بعد لاحقة (`10200`). خارجي مقطع سقوط ترتيب و تجميع مستمع ما زال قرار ذلك نهائي نتيجة.`includeHarnessIdentity: false` فقط حذف هذا عدد ثابت فتح ساحة أبيض. فارغ مقطع سوف إزالة فقد؛ حمل أثر مجال مقطع و متغير يمكن لـ واحد agent حجب حجب عام بند.`system-prompt/assemble` waterfall قرار تسليم نص التوجيه و أداة schema، حذف غير واحد صالح مقطع إعلان ذاته لـ complete——هذا وقت هذا تأكيد قطع مقطع سوف يصبح كامل توجيه النظام، بينما waterfall نيل إلى سياق، أداة و متغير إبقاء ثابت. تصيير بعد نص التوجيه بصفة إرسال توليد تاريخ في system زاوية لون رسالة——surface رقم 0 رقم عقدة، أو تاريخ داخل تحديث بعد الأكثر جديد نظام عقدة——وصول نموذج؛ حلقة طلب و `request/header` متساو لا يحتوي مفرد وحيد `system` حقل. كامل تصيير نتيجة لـ فارغ وقت، حلقة عبر لديه سجل سجل فارغ محتوى استبدال صاف حذف كل توليد فاعلية نظام عقدة، نموذج تاريخ لم يعد إبقاء أي قديم نص التوجيه. لديه ترتيب حركة حالة سياق و مقطع قسم مغادرة، فقط في وجود وقت عندئذ سوف يصبح حمل مصدر user زاوية لون لقطة؛`includeRuntimeContext: false` أو حمل أثر مجال كبح صنع جهاز سوف إزالة الكل هذا صنف سياق.

##### harness هوية

```markdown
You are an AI agent powered by DeepSeek Harness.
```

#### Token أثر

تفعيل وقت، هوية هو كل مرة طلب ثابت صار هذا.Persona بادئة، بعد لاحقة و إضافة نص في كل مرة طلب في تكرار، صار هذا مع تصيير محتوى زيادة طويل.

#### KV Cache أثر

فقط يلزم هوية،persona، متغير، مقطع نص و ترتيب تصيير تماما نفسه، بادئة حينئذ إبقاء مستقر: تصيير لم تغيير وقت نظام عقدة إبقاء لا حركة، حذف غير لا دعم حمل هذا قدرة توجيه أو جديد طلب تسلسل يجب عودة و إبقاء تاريخ داخل نص التوجيه. لا يوجد `systemPromptUpdate` وقت، غير فارغ نص التوجيه نص عبر لديه سجل سجل تدريجي عقدة استبدال عودة و إلى أول عدد نظام عقدة، لذلك رأس عقدة إعادة كتابة سوف من أول عدد تغير token بدء فقد ذهاب بادئة إعادة استخدام؛ عند قد دقيق تجهيز استدعاء إعلان `systemPromptUpdate: 'in-history'` وقت،agent loop(ذكي جسم حلقة) سوف في نفس طلب تسلسل تأخير متابعة خلال يأخذ تغير بعد غير فارغ نص التوجيه إلحاق إلى قد ذاكرة مؤقتة تاريخ بعد، لذلك مباشر إلى هذا تاريخ نهاية ذيل بادئة ما زال يمكن إعادة استخدام ([قرار قاعدة](../agent-loop/README.zh.md#understand-the-implementation)). نموذج،persona بادئة، أداة و قبل وضع إشارة أمر متسق وقت، مختلف شفرة المصدر مسار، محلي Web URL أو persona بعد لاحقة قيمة لن تغيير يمكن إعادة استخدام رقم واحد جهة بادئة.persona بادئة تغير ممكن تغيير اعتماد قبل بادئة. أي تغيير كل ممكن من رقم واحد تغير token بدء جعل إعادة استخدام بطلان؛ لا حفظ إثبات مزود مشترك ذاكرة مؤقتة أو فعلي أمر في معدل.

### أداة schema

#### نموذج يرى ماذا

مقابل في قد تسليم أداة، نموذج سوف استلام إلى[توليد أداة schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tools) في مقابل كل agent مرئي فرعي تجميع؛ حد و تجميع اعتراض قطع إتمام بعد، حسب إعداد أو حرف قاموس ترتيب ترتيب صف. توسيع يمكن عبر نفس سجل التسجيل مساهمة أخرى تعريف. مقطع و schema مزود هو مستقل تجميع إدخال. حد لن إزالة مقطع سقوط تسجيل: أداة إشارة توجيه إضافة عبر `text({ scope })` و `ctx.tools.get(name, scope)` إرجاع فارغ نص أو اختيار ملائم استخدام قطعة مقطع. مهمة معنى ساكن حالة مقطع سقوط لن يتم تلقائي تعديل كتابة.

#### Token أثر

schema token في كل مرة طلب في تكرار. حد أداة سوف لـ هذا agent إزالة ذلك الكل schema صار هذا، لكن لن إزالة مستقل نص التوجيه مقطع؛ إعادة ترتيب ترتيب سوف تغيير ذاكرة مؤقتة شكل حالة، لكن لا تغيير دلالة محتوى.

#### KV Cache أثر

فقط يلزم مرئي schema تجميع دمج، تصيير و ترتيب ثابت، بادئة حينئذ إبقاء مستقر. تسجيل، حد أو إعادة ترتيب ترتيب ممكن من رقم واحد تغير schema token بدء جعل إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح نص التوجيه تجميع أي وقت حاجة خاص آخر إبقاء معنى. هو جمع هو حالي حزمة قيد، لا هو انتظار إنجاز أمر بند بيان.

- **نشر جهة تحرير كتابة نص التوجيه نص فقط قدوم ذاتي إعداد/تركيب**: هذا إضافة يملك عام persona بادئة و بعد لاحقة قيمة افتراضية؛ إنشاء جهة إضافة يمكن تسجيل agent أثر مجال حجب حجب بند؛ أخرى مقطع قدوم ذاتي يملك متبادل ينبغي واقع إضافة. لا وجود طرفية مستخدم نص التوجيه تحرير API.
- **إدراج قيمة نص لا دعم حمل سطر داخل تحويل معنى لغة قاعدة**: كامل مقطع حاجة إبقاء حرف وجه زهرة تضمين رقم وقت، استخدام `interpolate: false`.
- **`toolOrder` إعداد خطأ في نص التوجيه تجميع (أول جولة) وقت ظهور، بينما لا هو بدء وقت**: فقط لديه شكل حالة مخالفة قاعدة سوف في إعداد تحميل وقت رمي خروج.
