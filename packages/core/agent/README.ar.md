# @deepseek-ai/dsh-agent

[English](README.md) | العربية

## عام وصف

استخدام `dsh-agent` إنشاء أو استعادة فوري agent(ذكي جسم) ، إرسال لاحق أو steering(في طريق جذب توجيه) إدخال، حقن موجه إلى نموذج سياق، إلغاء عمل، و انتظار agent دخول فارغ خامل حالة. إضافة،UI، خطاف و تحرير ترتيب جهاز أيضا يمكن مراقبة أو اعتراض قطع agent نشط حركة، و فقط لـ واحد agent تطبيق قدرة بينما لا أثر أخرى agent. عند شفرة حاجة عبر عام `Agent` API تحكم أو توسيع فوري agent وقت، طلب اختيار هذه الحزمة. طلب سوف هو و `dsh-agent-loop` انتظار agent مشغل إعداد دمج استخدام؛ هذه الحزمة ذاته لن إنشاء نموذج طلب. إرسال بدء جهة عودة بسبب فقط وجود في عملية داخل، عبر worker، عملية، حمل دائم طابور صف و إعادة بدء وقت يجب صريح نقل تمرير.

## استخدام هذه الحزمة

في وجود فوري agent أي أرض جهة تركيب `dsh-agent`: هو توفير `ctx.agents` و إضافة،UI، خطاف و تحرير ترتيب جهاز الذي موجه إلى تحرير مسار `Agent` جملة مقبض. في لا يوجد مشغل تسجيل عمل مصنع قبل، هذا خدمة إبقاء كسول صفة——مع مرفق مشغل هو `dsh-agent-loop`، لذلك الأكثر صغير متاح تركيب حاجة معا تحميل اثنان من.

### إنشاء أو استعادة agent

`ctx.agents.create()` في واحد هوية تحت بناء كل جديد agent و جلسة؛`ctx.agents.resume()` تحميل حفظ دائم جلسة و في هذا أساس أساس فوق إعادة بناء agent. اثنان من كل تفويض حمل إعطاء قد تسجيل عمل مصنع، و إرجاع `AgentHandle`——وحيد قدرة تفكيك حذف هذا agent كائن. في مهمة واحد عملية options في ضبط `parentAgent`، يمكن جعل نتيجة يصبح وقت التشغيل فرعي درجة؛ حذف هو فإن نيل إلى وقت التشغيل أصل درجة.`get(id)`،`list()` و `roots()` لأجل فحص بحث فوري agent؛`isOwnedBy(id, parent)` لأجل فحص تحقق هذا بند تأكيد قطع فوري كل حق علاقة.

```text
const handle = await ctx.agents.create({
  sessionId,
  agentOptions: { provider: 'deepseek', model: 'deepseek-chat' },
})
// later:
await handle.dispose()   // stops the loop, unregisters, removes the session, unwinds the scope
```

`AgentOptions` توفير ابتدائي مزود/نموذج توجيه، اختياري من مهايئ تعريف `reasoningEffort`، و اختياري صحيح عدد `maxTokens` إخراج حد أعلى. حلقة سوف تحقق تأكيد قطع نموذج دفع إدارة (reasoning) دعم حمل، تحليل مهايئ قيمة افتراضية، يأخذ توليد فاعلية قيمة سجل في طلب رأس في، و سوف هو جمع تطبيق إلى كل محادثة طلب. اختياري `setup(agentCtx, agent)` عودة ضبط سوف في agent إصدار قبل تركيب ذلك أثر مجال عالم حد:`agentCtx` يملك تسجيل، صريح لم إصدار Agent فإن توفير ذلك Session؛Context لا يحتوي عكس نحو Agent خاصية. أثر مجال أداة، نص التوجيه مقطع و مستمع في أي إنشاء عام إبلاغ قبل حينئذ قد وجود.Setup فقط فعل تركيب: إنشاء إتمام بعد عندئذ قدرة قيادة agent.

### قيادة agent محادثة

جملة مقبض طريقة يأخذ حمل معرف user زاوية لون رسالة توجيه دخول agent استلام عنصر صندوق.`followup()` ترتيب طابور واحد بند عادي تحت واحد جولة نص التوجيه و نداء تنبيه مشغل؛`steer()` إيداع تحت واحد خطوة إدخال و نداء تنبيه هو؛`inject()` إضافة موجه إلى نموذج سياق لكن لا نداء تنبيه مشغل، لذلك هو سقوط في تحت واحد يتم وصل قبول خطوة في.`cancel(cause)` في توقف حالي نشط حركة، و في لم ضبط `keepInbox` وقت صاف حذف انتظار معالجة عمل؛`whenIdle()` سوف في كامل agent بلوغ إلى تماما توقف مستقر بعد إتمام.

```text
handle.agent.followup({
  content: [{ type: 'text', text: 'Summarize this workspace.' }],
  source: { kind: 'user' },
})
handle.agent.steer({
  content: [{ type: 'text', text: 'Focus on the tests.' }],
  source: { kind: 'plugin', plugin: 'my-plugin' },
})
await handle.agent.whenIdle()
```

### سوف تسجيل حد تحديد إلى مفرد عدد agent

`Agent.ctx` هو هذا agent أثر مجال سياق: عبر هو إجراء تسجيل (أداة، نص التوجيه مقطع، متغير، حدث مستمع، حد) فقط مقابل هذا agent توليد فاعلية، و في dispose(مورد تحرير) وقت الكل سحب إلغاء. نفس آلية أيضا هو agent preset استخدام قدوم يجعل واحد جلسة نيل نيل مختلف قدرة تجميع، معا لا أثر ذلك مجاور إقامة طريقة.

### اعتراض قطع أو مراقبة إجراء في عمل

`agent/*` حدث يجعل إضافة بلا حاجة اعتماد حلقة حزمة يكفي أثر في فوري عمل.`agent/pre-step` يمكن رفض محاكاة دخول خطوة أو استبدال دخول هو رسالة؛`agent/request-error` يجعل مستمع إعادة محاولة فشل نموذج طلب؛`agent/turn-stopping` في هذا يمكن إتمام جولة إغلاق قبل تشغيل، و يمكن عبر steer جعل ذلك إبقاء فتح.`agent/assistant-stream` يحمل واحد عملية محلي Assistant attempt لديه ترتيب start، لحظة حالة قسم قطعة و end frame.start إعطاء خروج هذا attempt جولة و خطوة، قسم قطعة بحث جذب من صفر بدء سري تجميع تمرير زيادة،`end.index` فإن هو تحت واحد قسم قطعة موضع.loop سوف في committed end frame قبل يأخذ كامل ضيق تجميع تدفق إيداع لـ واحد `assistant/message` أو `assistant/attempt`، لذلك فوري حدث ما زال هو عرض بيانات بينما غير إعادة تشغيل مصدر.`agent/status`،`agent/created` و `agent/disposed` قيادة UI و تنسيق ضبط حالة، تدريجي رسالة `agent/inbox/*` إشعار فإن يجعل استلام عنصر صندوق إسقاط إبقاء تزامن. تأكيد قطع توقيع، توزيع mode و payload اتفاق رؤية [core فرعي نظام صفحة](../../../docs/subsystems/core.ar.md#cordis-surface) توليد منطقة كتلة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذا حزمة مثل أي تنفيذ فوق وصف سلوك؛ يمكن مراقبة اتفاق قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا حزمة بناء قيام في واحد بند مسؤولية قسم مغادرة لـ فوق: عام `Agent` واجهة و سجل التسجيل يقع في هذه الحزمة، بنية صنع و قيادة فإن يقع في حلقة حزمة، و عبر قد تسجيل عمل مصنع توفير. مستهلك لذلك اعتماد `dsh-agent` بينما لا اعتماد `dsh-agent-loop`، من بينما إبقاء مشغل يمكن استبدال. ثاني عدد إدارة فكرة هو إرسال بدء جهة أثر مجال: واحد بند `AsyncLocalStorage` سلسلة يأخذ تأكيد قطع فوري `Agent` يحمل مرور مرور هو بدء مختلف خطوة مشغل عمل، جعل مشغل لـ تحت مساعد مساعدة دالة بلا حاجة تدريجي استدعاء تحويل إرسال agent يكفي عودة بسبب ذاتي ذات عمل.

### خطوة دقيق دخول

`PreStepDecision` يلزم ما هو `{ kind: 'reject' }`، يلزم ما هو `{ kind: 'enter', messages, startsRequestSeries? }`.enter فرع يتضمن كامل، حمل معرف كما تجميد ربط رسالة دفعة مرة. وصل قبول لا انتظار في إيداع: تجميع و `step/start` بعد،`agent/request` و `prepareCall()` أولا تحليل توجيه، حلقة مع بعد عندئذ إيداع توجيه النظام و مستخدم دفعة مرة. في مهمة واحد مختلف خطوة مرحلة مقطع إلغاء كل لن إيداع هذا اثنان من.`startsRequestSeries: true` إعلان واحد مستقل نموذج رسالة تسلسل؛ حزمة تركيب تحت تنقل enter مستمع سوف إبقاء هذا إعلان و دفعة مرة، حذف غير متعمد استبدال منها واحد بند. قيادة أخذ سوف من inbox إزالة مرشح رسالة، قيادة أخذ بعد إدراج دخول رسالة فإن انتظار لاحق حد.

### حمل دائم inbox

`Agent.inbox` فقط كشف بنية نوع `Inbox` واجهة، إسقاط مفردات ما زال يقع في هذه الحزمة.dsh-agent-loop يحتفظ حزمة داخلي `ReactLoopInbox` و معيار `inbox` إسقاط؛ بنية صنع أداة جسم inbox وقت سوف تأكيد حفظ إسقاط سجل التسجيل لـ حمل دائم `agent/inbox/spliced` fold يحتفظ واحد نسخة تسجيل. سجل التسجيل متابعة بصفة فوري `{ 'next-turn', 'next-step' }` حالة وحيد كل من. إعادة بناء مرور مسار سوف رفض لا أمان أو تجاوز حد splice جلوس علامة، و عبر اثنان نسخة انتظار معالجة قائمة تكرار `MessageId`، و تقرير إبلاغ خروج خطأ حدث seq.

`Inbox` كشف انتظار معالجة `nextTurn` و `nextStep` رسالة، و عبر `append`،`prepend`،`replace`،`remove`،`clear` و `splice` تغيير هو جمع. عادي حذف و `clear()` كل هو حمل دائم إلغاء. في خطوة حد، حلقة داخلي تنفيذ سوف عبر صاف حذف splice قيادة أخذ انتظار معالجة إدخال. فوري إشعار لحظة معنى اعتماد تدريجي رسالة الأكثر صغير تحميل حمل:`agent/inbox/inserted { message }`،`agent/inbox/claimed { message, turn }` و `agent/inbox/discarded { message }`.

### سجل التسجيل و دورة الحياة

`AgentRegistry` لـ كل فوري agent إبقاء واحد بند، يحتوي ذلك تحميل جسم و إنشاء من علاقة. استخدام قد بنية صنع agent قبل، انتظار `register()` بـ `startup` مصدر إتمام سلسلة سطر إنشاء مستمع؛ مختلف خطوة عمل مصنع استخدام تفكيك قسم `enter()`/`announce()` مقابل، جعل setup و ابتدائي تحويل بداية نهاية تلقي تراجع حفظ حماية. إنشاء خلال طلب detach سوف انتظار كل قد استدعاء مختلف خطوة مستمع تسوية، كما كل مرة detach كل ربط إلى تأكيد قطع بند، لذلك قديم قديم disposer لا يمكن إزالة بعد ظهور نفس id بديل بند.Teardown إيقاف و ترتيب فارغ حلقة، سحب إلغاء أثر مجال،detach agent، مجددا detach جلسة؛ خاص تنظيف إتمام بعد هذا id يكفي إعادة استخدام.

### إرسال بدء جهة أثر مجال

كل مشغل في `ctx.agents.withInitiator(agent, ...)` داخل تشغيل ذلك كامل دورة الحياة، لذلك وراثة مختلف خطوة سلسلة سوف مراقبة إلى هذا agent؛`withoutInitiator()` لـ مشترك تحديد وقت جهاز انتظار غير متصل عملية محلي عمل إخفاء هو. هذا حد فقط هو عملية محلي عودة بسبب——بيئة في هوية حيث لا هو تخزين نشط إثبات، أيضا لا هو تخويل، صريح هوية في worker، عملية، حفظ دائم و wire حد إبقاء مرجعي.Teardown رفض جديد حد، يجعل إرجاع Promise حد ترتيب فارغ، لكن بعد منع استخدام قاع طبقة تخزين.[إرسال بدء جهة أثر مجال قرار](../../../.agents/notes/implemented/architecture/2026-07-15-agent-initiator-scope.ar.md) يملك تفصيل دقيق اتفاق.

### كل حق ثابت صيغة

`AgentHandle` disposer هو واحد بند قدرة: في مستهلك في، فقط لديه ذلك يحتفظ من قدرة تفكيك حذف هذا agent. قد تسجيل عمل مصنع مزود هو بنية تحويل مشترك نفس يملك من، لأن أثر مجال agent اعتماد هذا مزود خدمة API؛ مزود إزالة سوف إيقاف و ترتيب فارغ هو إنشاء كل فوري جملة مقبض.`ctx.agents.get(id)` ما زال إرجاع عار `Agent`——جملة مقبض فقط كشف إعطاء إنشاء هو مستهلك.

<a id="model-experience"></a>
## تجربة النموذج

### مستخدم،steering و حقن رسالة

#### نموذج يرى ماذا

`followup`،`steer` و `inject` بـ حمل معرف user زاوية لون رسالة تغذية إرسال الذي تابع جلسة؛ يتم وصل قبول محتوى يصبح نموذج في لاحق خطوة في قراءة إرسال توليد تاريخ واحد جزء.`agent/pre-step` و أخرى قد إعلان حدث يجعل إضافة قدرة كاف رفض محاكاة دخول خطوة أو إضافة حمل دائم طلب مادة مادة.`installModelSelection` سوف في أول مرة لـ مختلف مزود/نموذج توجيه تجميع كما أصل هذا سوف إرسال خروج نموذج طلب خطوة في إضافة دخول `[model changed: assistant turns above this point were generated by <previous>; the session continues with <next>]`؛ فقط عبر مزود تبديل وقت عرض مزود اسم، فقط تغيير دفع إدارة قوي درجة وقت لا إضافة رسالة. رقم واحد قرار لـ فارغ وقت، و بعض عدد قرار إزالة مرشح رسالة بعد لـ فارغ وقت، كل لن إنتاج طلب. إذا طلب خطوة في سجل طلب رأس قبل فشل، حمل دائم سجل في أولا قبل توجيه لا يوجد تغير، الذي التالي واحد طلب خطوة سوف مجددا مرة استلام إلى تلميح.

#### Token أثر

يتم وصل قبول محتوى يصبح إبقاء تاريخ، أو يصبح كل مرة طلب تكرار جلسة بادئة؛ يتم منع توقف محتوى لا مساهمة طلب token. كل بند فعلي إرسال خروج نموذج تبديل تلميح كل سوف يأخذ مقابل نص إضافة دخول إبقاء تاريخ. كبير صغير أخذ قرار في استدعاء جهة و إضافة.

#### KV Cache أثر

يتم وصل قبول تاريخ و steering فقط إلحاق؛ يتم منع توقف إيداع لا إرسال طلب. جلسة بادئة في حلقة نسخة داخل إبقاء مستقر، بينما جديد بناء أو استعادة نسخة ممكن بناء قيام مختلف بادئة.

### Agent أثر مجال طلب تركيب

#### نموذج يرى ماذا

عبر `agent.ctx` إجراء تسجيل يمكن حجب حجب نص التوجيه مقطع أو أداة، أيضا يمكن في لم إصدار setup خلال تثبيت فقط ملائم لأجل هذا agent اعتراض قطع جهاز، لذلك واحد agent يرى نص التوجيه و أداة تجميع سوف و ذلك مجاور إقامة مختلف. نموذج اختيار سوف في نص التوجيه تجميع قبل التقاط مرة مزود/نموذج/دفع إدارة قوي درجة قيمة، و سوف ذلك تطبيق إلى نفس خطوة طلب؛ بعد حدوث تزامن تغيير انتظار تحت واحد خطوة.

#### Token أثر

كل مرة مزود/نموذج تبديل سوف زيادة واحد بند بسيط قصير كما إبقاء في تاريخ في user زاوية لون تلميح. أخرى حمل أثر مجال مساهمة فقط أثر هذا agent، و في dispose وقت إزالة فقد.

#### KV Cache أثر

تبديل تلميح إلحاق في أولا قبل تاريخ بعد، لذلك إبقاء هذا بادئة؛ توجيه تغيير ممكن جعل جديد مزود أو نموذج لا يمكن إعادة استخدام هذا بادئة. تغيير نص التوجيه مقطع، أداة تعريف أو طلب مستمع setup أو reload، ممكن من رقم واحد تلقي أثر طلب token بدء جعل إعادة استخدام بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه الحزمة أي وقت حاجة خاص آخر إبقاء معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **إرسال بدء جهة أثر مجال فقط وجود في عملية داخل**:worker، عملية فرعية،HTTP، حمل دائم طابور صف و إعادة بدء يجب صريح نقل تمرير الذي يحتاج هوية.
- **بيئة هوية ممكن مقارنة تخزين نشط حالة أكثر دائم**: مستهلك في دورة الحياة حساس شعور عمل قبل، ما زال يلزم فحص `agent.status`، إلغاء حالة و الذي تابع قدرة اتفاق.
- **إنشاء مستمع مشترك ابتدائي تحويل دورة الحياة.** `agent/created` مستمع لا نيل انتظار `agent.whenIdle()` أو ذاته كل من dispose: هذه عملية يلزم انتظار إنشاء إتمام. الذي يحتاج مختلف خطوة أداة و نص التوجيه تثبيت إتمام بعد، مستمع عندئذ يمكن إرجاع.
- **`cancel()` افتراضي صاف فارغ استلام عنصر صندوق**: هو سوف في توقف صحيح في معالجة جولة و ترتيب طابور و steering عمل؛`cancel(cause, { keepInbox: true })` فقط في توقف جولة و إبقاء انتظار معالجة بند، كما لا وجود يجعل جولة متابعة تشغيل، فقط في توقف خطوة عملية.
- **كل بند مرفق إضافة `UserMessage` تماما جيد يحمل واحد `MessageSource`**: كثير عدد إضافة دمج إلى واحد بند رسالة فوق مساهمة سوف عودة دخول نفس مصدر، لذلك هذا رسالة لا يمكن صف خروج كثير عدد إنتاج من.
