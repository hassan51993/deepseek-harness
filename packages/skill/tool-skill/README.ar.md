# @deepseek-ai/dsh-tool-skill

[English](README.md) | العربية

## عام وصف

agent يمكن في جلسة خلال اكتشاف و تحميل skill. في أول مرة طلب قبل، إذا وجود نموذج يمكن استدعاء skill كما `skill` أداة مرئي،agent سوف استلام إلى واحد نسخة حمل دائم دليل، صف خروج متاح skill اسم و لديه طويل درجة حد أعلى وصف، و متاح `skill` أداة تحميل كامل إشارة أمر. مستخدم يمكن استخدام `/name` استدعاء بعض عدد مستخدم يمكن استدعاء skill، يأخذ نفسه إشارة أمر حقن هذا خطوة. دليل تغيير سوف إلحاق واحد نسخة كامل استبدال، منها فارغ دليل سوف توقف استخدام قديم اسم؛ يمكن إعداد `catalogDescriptionMaxLength` قدوم حد كل بند وصف طويل درجة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

و skill سجل التسجيل واحد بدء تركيب هذا إضافة، يكفي يجعل agent يملك جلسة skill دليل و `skill` تحميل أداة. هو حاجة `ctx.agents`،`ctx.tools` و `ctx.skills`.

### أي وقت اختيار

عند agent ينبغي في جلسة خلال اكتشاف و تحميل skill وقت استخدام هو. عند skill تحميل من أخرى مستهلك معالجة أو تماما لا حاجة وقت، طلب قفز مرور——لا يوجد هو، مزود و سجل التسجيل ما زال يمكن عمل، لكن لن لديه أي شرق غرب لـ نموذج تصيير دليل أو أداة.

### تركيب و إعداد

و skill سجل التسجيل و حتى قليل واحد مزود واحد بدء تحميل هذا إضافة. وحيد بند إعداد حد دليل في تصيير مواصفة تحويل وصف طويل درجة.

```yaml
- name: '@deepseek-ai/dsh-skill'
- name: '@deepseek-ai/dsh-skill-filesystem'
- name: '@deepseek-ai/dsh-tool-skill'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `catalogDescriptionMaxLength` | `500` | جلسة دليل في تصيير مواصفة تحويل وصف الأكثر كبير طويل درجة؛ الأكثر صغير لـ 3 |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tool-skill) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### نموذج نيل إلى ماذا

- **جلسة دليل.** عند وجود نموذج يمكن استدعاء skill كما `skill` أداة مرئي وقت،agent سوف في أول مرة طلب قبل استلام إلى واحد بند حمل دائم مستخدم زاوية لون رسالة، صف خروج كل skill اسم و لديه طويل درجة حد أعلى وصف؛ هذا رسالة إبلاغ إبلاغ نموذج في حال يد مهمة قبل أولا استخدام أداة تحميل skill، كما أبدا قدرة فقط سند ملخص دفع قطع إشارة أمر.
- **تحميل أداة.** نموذج بـ دقيق skill اسم استدعاء `skill`، و استلام إلى كامل إشارة أمر متن و مواصفة `<skill_content>` كتلة في مورد إشارة جذب؛ هذا نتيجة بصفة عادي أداة تاريخ إبقاء.
- **مستخدم صريح استدعاء.** مباشر مستخدم إدخال في `/name` token إذا إشارة اسم بعض عدد مستخدم يمكن استدعاء skill، سوف يأخذ هذا skill إشارة أمر حقن هذا خطوة، بينما بلا حاجة نموذج ذاتي سطر تحميل.
- **فوري دليل تحديث.** لاحق عضو علاقة، وصف أو مرئي صفة تغير سوف إلحاق كامل استبدال دليل؛ حذف الكل skill وقت سوف إلحاق فارغ دليل، توقف استخدام مقارنة مبكر اسم.

### يمكن مراقبة نجاح و فشل

تحميل صف خروج skill سوف إرجاع ذلك كامل إشارة أمر؛ بلا نقاش تحميل قدوم ذاتي أداة أيضا هو مستخدم صريح استدعاء، نموذج يرى كل هو نفس نوع مواصفة شكل. بلا فاعلية اسم سوف تقرير إبلاغ `Error: invalid skill name "<name>"`، لم معرفة اسم سوف تقرير إبلاغ هذا skill لم معرفة أو قد غير ممكن استخدام، يتم منع استخدام نموذج استدعاء skill سوف تقرير إبلاغ ذلك غير ممكن لأجل نموذج استدعاء. إذا من لم إصدار مرور دليل، و كما لا وجود نموذج يمكن استدعاء skill، أو `skill` أداة يتم إخفاء أو حجب حجب، فإن سوف كامل جسم حذف دليل؛ دليل إصدار بعد، بلا نقاش مرئي صفة فقد فقد——`skill` أداة يتم إخفاء أو يتم نفس اسم أثر مجال أداة حجب حجب——أيضا هو حذف الكل skill، كل سوف تعديل لـ إلحاق فارغ دليل قدوم توقف استخدام قديم اسم.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير دليل و استدعاء حد مثل أي بناء؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) و تحت جهة تجربة النموذج فصل عقدة في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة بناء قيام في اثنان عدد تفكير قاعدة لـ فوق. رقم واحد، دليل هو واحد نوع حمل دائم إسقاط، حسب قد إصدار بند digest بينما غير تصيير بعد متن فعل فرق مختلف مقارنة مقارنة، لذلك `<system-reminder>` حزمة تركيب دائم بعيد لن قوي صنع إعادة إصدار، مستهلك أيضا لا حاجة إعادة تحليل `<available_skills>` كتلة. ثاني، واحد بند مواصفة تصيير خدمة اثنان بند تحميل مسار——أداة نتيجة و مستخدم صريح حقن——مرور من مشترك ذاتي `dsh-skill` `renderSkillContent`، لذلك بلا نقاش تحميل من من إرسال بدء، نموذج يرى كل هو نفس نوع `<skill_content>` شكل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: أداة تسجيل، دليل و يد اتجاه pre-step مستمع، تصيير و digest |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا عدد موجه إلى نموذج مهايئ لا يوجد مستقل دورة الحياة تدفق؛ تنفيذ علاقة من هو استدعاء قدرة seam مسؤول. |

### دليل دورة الحياة

في كل مرة رمز دمج شرط `agent/pre-step`، إضافة كل سوف لقطة استدعاء جلسة skill دليل، تطبيق `skill` أداة دقيق مرئي صفة، مرور ترشيح خروج نموذج يمكن استدعاء skill، و يأخذ بند digest و جلسة سجل في الأكثر جديد مرئي `skill-catalog` رسالة فعل مقارنة مقارنة.digest تغير وقت، هو يأخذ يتضمن كامل استبدال دليل حمل دائم مستخدم زاوية لون رسالة تسليم إعطاء `enter` قرار؛ فارغ استبدال سوف صريح توقف استخدام مقارنة مبكر اسم. مزود لقطة لا كامل وقت لا إرسال أي محتوى، و لـ تحت مرة pre-step إبقاء الأكثر بعد واحد نسخة متاح عرض. مرئي صفة فحص إبرة مقابل هذا إضافة الذي تسجيل دقيق أداة تعريف، لذلك أثر مجال داخل نفس اسم حجب حجب بند سوف معا إزالة schema و ذلك إشارة جذب؛ هذا إضافة حيث يمكن عام تركيب، أيضا يمكن تعليق في مفرد عدد agent تركيب داخل.

### استدعاء حد

`/name` يد اتجاه مستمع فقط مسح قد إقرار قيادة مستخدم رسالة: إذا بعض عدد بـ فارغ أبيض لـ حد، إشارة اسم مساحة العمل دليل في مستخدم يمكن استدعاء skill token ظهور، فإن يأخذ نفس نسخة `<skill_content>` تصيير بصفة `user` زاوية لون إشارة أمر سياق حقن، إلحاق في هذا خطوة كل أخرى حقن بعد. لم معرفة اسم و مستخدم غير ممكن استدعاء اسم إبقاء لـ عادي سطر نص. هذا هو `disable-model-invocation` skill وحيد مدخل، دليل و `skill` أداة دائم لا كشف هذا صنف skill.

<a id="model-experience"></a>
## تجربة النموذج

### جلسة دليل

#### نموذج يرى ماذا

إذا وجود نموذج يمكن استدعاء skill، كما مرئي صحيح هو هذا عدد `skill` أداة،agent سوف في رقم واحد طلب قبل استلام إلى تحت جهة دليل نموذج لوح، منها يتضمن كل قد ترتيب ترتيب skill واحد بند مع بيانات بينما تحديد بند. هذا دليل هو واحد بند حمل دائم مستخدم زاوية لون رسالة. لاحق عضو علاقة، وصف أو مرئي صفة تغير سوف استخدام نفس عدد `<available_skills>` معلومة غلاف إلحاق كامل استبدال؛ حذف كل skill وقت، سوف إلحاق واحد فارغ معلومة غلاف، و واضح إشارة عرض لا نيل استخدام قديم اسم. نموذج لوح ربط ذيل واحد جملة هو منع توقف مزدوج إعادة تحميل قاعدة: مستخدم صريح يد اتجاه حد (تحت نص pre-step مستمع) سوف يأخذ نفس نسخة `renderSkillContent` إخراج (مشترك ذاتي `@deepseek-ai/dsh-skill`) داخل ربط حقن، دليل فإن إبلاغ إبلاغ نموذج التزام دوران هذا كتلة، بينما لا هو مجددا مرور أداة إعادة تحميل هذا skill؛ استبدال دليل نموذج لوح اثنان عدد فرع——يشمل صاف فارغ بعد دليل——كل يحمل نفس بند منع مزدوج إعادة تحميل قاعدة.

##### Skill دليل نموذج لوح

```markdown
<system-reminder>
A skill is a reusable set of task-specific instructions. The following skills are available in this session:

<available_skills>
- `<name>`: <normalized-and-capped-description>
</available_skills>

If the user names a skill, or the task clearly matches a skill's description, call the `skill` tool with the exact skill name before taking task actions. Load all applicable skills, then follow their full instructions. This catalog contains summaries only; do not infer or follow a skill's instructions until it has been loaded.
A user may also invoke a skill directly; its <skill_content> block then appears in this conversation. Follow it, and do not call the `skill` tool again for that skill.
</system-reminder>
```

#### Token أثر

تكرار إدخال صار هذا مع skill عدد كمية و `catalogDescriptionMaxLength` زيادة طويل؛ عند قائمة لـ فارغ أو أداة يتم إخفاء أو حجب حجب وقت، لن إرسال ابتدائي دليل token. كل مرة فعلي دليل تغيير كل سوف إضافة واحد بند إبقاء كامل استبدال رسالة.

#### KV Cache أثر

ابتدائي حمل دائم دليل إلحاق في قائم يمكن إعادة استخدام بادئة بعد. حركة حالة تغيير بصفة هذا دليل بعد فقط إلحاق تاريخ، لذلك مقارنة مبكر يمكن إعادة استخدام token إبقاء ثابت، كل بند جديد إلحاق دليل و لاحق جولة كل سوف شكل صار جديد بعد لاحقة. جديد بناء أو استعادة نسخة إذا digest حدوث تغير، ممكن سوف من جديد إلحاق دليل موضع بدء أثر ذاكرة مؤقتة إعادة استخدام.

### أداة schema

#### نموذج يرى ماذا

نموذج سوف يرى توليد [`skill` schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-skill).

#### Token أثر

أداة مرئي وقت، كل مرة طلب كل لديه ثابت schema token فتح إلغاء.

#### KV Cache أثر

أداة تعريف و مرئي صفة ثابت وقت، بادئة مستقر. حجب حجب، حد أو إضافة دورة الحياة تغيير ممكن من هذا schema بدء جعل إعادة استخدام بطلان.

### أداة نتيجة

#### نموذج يرى ماذا

نجاح استدعاء استخدام تحت جهة نتيجة نموذج لوح، و مزود إدارة مورد إشارة جذب، دليل مورد إشارة جذب،URL مورد إشارة جذب أو لا نفاذ واضح مورد إشارة جذب.

##### Skill نتيجة نموذج لوح

```markdown
<skill_content name="<escaped-name>">
<skill_resources>
<resource-guidance>
</skill_resources>

<skill_instructions>
<provider-owned-instruction-body>
</skill_instructions>
</skill_content>
```

##### مزود إدارة مورد إشارة جذب

```markdown
Resources for this skill are managed by provider "<provider>".
Load referenced resources only as needed.
```

##### دليل مورد إشارة جذب

```markdown
Base directory for this skill: <path>
Resolve relative paths mentioned by this skill against the base directory before using them. Load referenced resources only as needed.
```

##### URL مورد إشارة جذب

```markdown
Base URL for this skill: <url>
Resolve relative URLs mentioned by this skill against the base URL before using them. Load referenced resources only as needed.
```

##### لا نفاذ واضح مورد إشارة جذب

```markdown
Resources for this skill: <description>
Load referenced resources only as needed.
```

#### Token أثر

قد تحميل إشارة أمر هو أخذ قرار في بيانات أداة نتيجة token، و في لاحق خطوة في إعادة إرسال، مباشر إلى ضغط؛ لن صنع عمل تكرار `agent.inject()` فرعي هذا.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### أداة خطأ

#### نموذج يرى ماذا

بلا فاعلية أو قديم قديم اختيار سوف دقيق إرجاع `Error: invalid skill name "<name>"`،`Error: skill "<name>" is unknown or no longer available` أو `Error: skill "<name>" is not available for model invocation`. مزود رمي خروج فحص بحث نص أخذ قرار في بيانات، و طقم استخدام نفس عدد `Error: <message>` حزمة تركيب طبقة.

#### Token أثر

فقط لديه فشل استدعاء سوف إضافة هذه قد إبقاء token.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### مستخدم صريح استدعاء حقن

#### نموذج يرى ماذا

قد إقرار قيادة مستخدم رسالة في مهمة معنى موضع، بـ فارغ أبيض لـ حد، إشارة اسم مساحة العمل دليل في بعض عدد مستخدم يمكن استدعاء skill `/name` token، سوف يأخذ هذا skill كامل `<skill_content>` تصيير (و فوق نص نتيجة نموذج لوح تماما نفسه شكل) بصفة `user` زاوية لون إشارة أمر سياق حقن، إلحاق في هذا خطوة كل أخرى حقن بعد——خلف مشهد في قبل، نموذج يلزم حال يد معالجة مادة مادة في الأكثر بعد. فقط مسح مباشر مستخدم إدخال، فحص في قد تحميل تعريف فوق إجراء، لم معرفة اسم و مستخدم غير ممكن استدعاء اسم إبقاء لـ عادي سطر نص. هذا هو `disable-model-invocation` skill وحيد مدخل، دليل و `skill` أداة دائم لا كشف هذا صنف skill؛ دليل ربط ذيل واحد جملة سوف إبلاغ إبلاغ نموذج التزام دوران حقن كتلة، بينما لا هو إعادة تحميل هو.

#### Token أثر

كل مرة يد اتجاه سوف يأخذ واحد نسخة تصيير بعد skill متن بصفة حقن سياق إضافة دخول هذا جولة——مقياس قياس و نفس skill أداة نتيجة نفسه، هذا صار هذا سوف مع مستخدم طلب لا بد لكن إنتاج، بينما غير من نموذج ذاتي سطر قرار. نفس خطوة داخل مقابل نفس skill تكرار يد اتجاه فقط حقن مرة.

#### KV Cache أثر

فقط إلحاق؛ حقن سقوط في هذا خطوة رسالة دفعة مرة في، يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح دليل أو تحميل جهاز أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **دليل حذف `whenToUse`، مصدر و مزود بيانات وصفية**——توجيه فقط أساس في اسم و لديه طويل درجة حد أعلى وصف؛`whenToUse` ما زال هو مزود بيانات وصفية، تحميل بعد حزمة تركيب طبقة أيضا لا تصيير هو.
- **قد تحميل إشارة أمر متن لا يوجد كبير صغير حد أعلى**——مزود يمكن إرجاع كاف بـ احتلال استخدام كبير كمية تحت واحد خطوة سياق skill؛ فقط لديه دليل وصف سوف يتم قطع قطع.
- **مورد هو إشارة جذب، بينما غير مرفق عنصر**——أداة تقرير إبلاغ أساس أساس دليل/URL/لا نفاذ واضح تلميح، لكن حيث لا صف رفع أيضا لا لـ نموذج نيل أخذ مرجع ملف.
- **تحميل هو مرة صفة نص**——بعيد مسار مزود مؤقت بطيء أو skill متن جدا كبير وقت، لا توفير جزء محتوى، تدفق صيغة إخراج أو ذاكرة مؤقتة محتوى جملة مقبض.
- **دليل استبدال اعتماد كل كمية قائمة**——واحد اسم أو وصف حدوث تغير، حينئذ سوف إلحاق كل مرئي ملخص؛ هذا مثال قدرة صريح توقف استخدام قديم قديم اسم، لكن token صار هذا و دليل كبير صغير صار صحيح مقارنة.
- **متن لا فعل إصدار تحويل**——فقط تعديل متن لن تغيير دليل digest، أيضا لن إشعار نموذج؛ لاحق أداة استدعاء سوف قراءة مزود حالي محتوى، بينما أولا قبل أداة نتيجة ما زال هو تاريخ واقع.
