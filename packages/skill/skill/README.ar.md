# @deepseek-ai/dsh-skill

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن يجعل agent(ذكي جسم) و مستخدم عبر واحد دليل وصول من محلي دليل، تضمين دخول صيغة إضافة بيانات أو بعيد مسار خدمة استلام تجميع يمكن إعادة استخدام مهمة مخصص بند إشارة أمر. هو سوف بـ يمكن مسبق قياس طريقة قطع قرار إعادة اسم بند، تحقق بند، في مصدر غير ممكن استخدام وقت إبقاء متاح نتيجة، و حسب يحتاج تحميل الذي اختيار skill كامل إشارة أمر. عند تركيب حاجة كثير عدد مصدر أو غير نظام الملفات مصدر skill وقت، طلب تركيب هذه الحزمة؛ هذه الحزمة ذاته لا يحتوي skill محتوى، لذلك محلي اكتشاف يحتاج تركيب إعداد `dsh-skill-filesystem`، نموذج وصول يحتاج تركيب إعداد `dsh-tool-skill`.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

تركيب إضافة يكفي يجعل تركيب يملك واحد موحد واحد skill سجل التسجيل.skill مصدر (مزود) و مستهلك (موجه إلى نموذج دليل و loader، أو أنت ذاتي ذات شفرة) كل عبر `ctx.skills` تفاعل؛ سجل التسجيل دمج مهمة معنى مزود تقرير إبلاغ واحد قطع محتوى، لذلك مرة فحص بحث حينئذ قدرة يرى كل مصدر skill.

### أي وقت اختيار

عند agent حاجة عبر نفس عدد واجهة من كثير عدد مصدر تحميل skill، أو skill مصدر و غير محلي نظام الملفات وقت، اختيار `dsh-skill`. عند تركيب تماما لا حاجة تحميل skill وقت، طلب تجنب تجنب استخدام——إضافة سوف زيادة واحد خدمة و كل مرة فحص بحث اكتشاف صار هذا. مع مرفق محلي مزود (`dsh-skill-filesystem`) و موجه إلى نموذج مستهلك (`dsh-tool-skill`) هو مستقل حزمة؛ نشر حاجة محلي skill و نموذج وصول وقت، طلب واحد و تركيب.

### تركيب و إعداد

مثل أي Cordis إضافة واحد مثال تحميل يكفي. وحيد بند إعداد حد داخل تخزين في إبقاء قد إتمام مزود دليل عدد كمية؛ ذلك بقية كل هو مزود سلوك.

```yaml
- name: '@deepseek-ai/dsh-skill'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `collectCacheMaxEntries` | `128` | داخل تخزين في إبقاء قد إتمام cwd/مزود دليل عدد |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-skill) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### سجل التسجيل توفير ماذا

- **دمج بعد مفرد واحد دليل.** مستهلك استعلام مساحة العمل حالي دليل، يكفي استلام إلى قدوم ذاتي كل مزود الكل فوز خروج skill ملخص، و حسب اسم ترتيب ترتيب——بلا حاجة ذاتي سطر فعل مزود خاص لديه ترتيب ترتيب أو ذهاب إعادة.
- **حسب يحتاج تحميل.** حسب اسم استعلام بعض عدد skill، سوف من يملك فوز خروج مرشح بند مزود إرجاع كامل إشارة أمر متن؛ سجل التسجيل سوف إعادة تحقق تحميل تعريف، و رفض في اكتشاف و تحميل بين اسم حدوث تغير قديم قديم اختيار.
- **تضمين دخول صيغة skill.** إضافة متاح `ctx.skills.register(...)` تسجيل داخل تخزين في skill؛ سجل التسجيل سوف تكملة دخول افتراضي استدعاء سياسة و `runtime` مزود وسم. نفس طبقة نفس اسم وقت التشغيل تسجيل اعتماد أولا إلى أولا نيل، و سجل تحذير إبلاغ.
- **مزود تسجيل.** مزود استخدام `ctx.skills.registerProvider(...)` مساهمة دليل؛ تسجيل هو تزامن، إرجاع disposer(مورد تحرير) سوف إزالة هذا مزود.`runtime` هو إبقاء مزود اسم.

كل skill فوق استدعاء سياسة قرار أي بعض واجهة يمكن عرض و تحميل هو:`modelInvocable` لأجل موجه إلى نموذج أداة و دليل،`userInvocable` لأجل موجه إلى مستخدم أمر. سجل التسجيل إبقاء الكل أربعة نوع تركيب، لذلك مرة اكتشاف نتيجة يمكن معا خدمة اثنان عدد واجهة، بينما لن خلط خلط كل منها دليل.

| سياسة | نموذج | مستخدم |
|---|---|---|
| `{ modelInvocable: true, userInvocable: true }` | يتضمن | يتضمن |
| `{ modelInvocable: true, userInvocable: false }` | يتضمن | ترتيب حذف |
| `{ modelInvocable: false, userInvocable: true }` | ترتيب حذف | يتضمن |
| `{ modelInvocable: false, userInvocable: false }` | ترتيب حذف | ترتيب حذف |

### يمكن مراقبة نجاح و فشل

مهمة معنى مزود تقرير إبلاغ skill كل سوف ظهور في دمج دليل في، حسب ذلك دقيق kebab-case اسم تحميل يكفي إرجاع متن؛ بلا فاعلية اسم إرجاع بلا نتيجة بينما غير رمي خطأ. اكتشاف فشل مزود سوف يتم سجل و قفز مرور، مراقبة قياس يتم علامة لـ لا كامل، لذلك مستهلك إبقاء ذلك الأكثر بعد واحد نسخة متاح دليل؛ صريح لا كامل مراقبة قياس ما زال سوف مساهمة ذلك مرشح بند. صيغة خطأ مرشح بند سوف سريع سرعة فشل——سجل التسجيل في ذاكرة مؤقتة أو إرجاع أي محتوى قبل، سوف أولا تحقق اسم، وصف، استدعاء قيمة منطقية و مزود ملكية.

Skill ملخص إبقاء فوز خروج مزود اختياري إشارة أمر ملف `path`، توفير توفير ملف معاينة اكتشاف إزالة استهلاك من استخدام. صف رفع ما زال لا قراءة skill متن؛ موجه إلى نموذج دليل متابعة فقط اختيار ذلك مسؤول توجيه حقل.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير سجل التسجيل مثل أي دمج، ذاكرة مؤقتة و بطلان مزود دليل؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذه الحزمة بناء قيام في واحد قسم مغادرة لـ فوق: سجل التسجيل مسؤول دمج، فوز خروج تحليل و تحقق، مزود مسؤول skill قدوم ذاتي أي داخل. مزود هو استعارة استخدام نفس عملية كائن، ذلك `list()` إرجاع مرشح بند،`get()` تحميل متن؛ سجل التسجيل حذف تحقق دلالة حقل خارج، من لا فحص skill محتوى.

سجل التسجيل اعتماد مضيف + حسب scope قسم طبقة بنية، أي أداة سجل التسجيل تأكيد قيام شكل: تسجيل سقوط دخول استدعاء جهة سياق scope مقابل طبقة——مضيف سطر و repository إضافة سقوط دخول عام طبقة، من agent preset معتاد إقامة تركيب تركيب إضافة سقوط دخول هذا preset طبقة. قراءة وقت سوف عام طبقة و مراقبة scope سلسلة دمج؛ الأكثر قريب طبقة مباشر فوز نيل إعادة اسم، مفرد طبقة داخل إعادة اسم فإن اعتماد مرة حسب rank، مزود تسجيل ترتيب و مزود محلي ترتيب قطع قرار.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل،`SkillRegistry` خدمة، مرشح بند و تعريف تحقق، مشترك موجه إلى نموذج تصيير |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ مزود/وقت التشغيل map و حمل revision cache في سجل التسجيل داخل أصل فرعي تغيير، كما لا يوجد مستقل تغيير حدث أو لقطة يمكن توفير تسليم تقاطع نواة مقابل. |

### دليل استلام تجميع

قراءة (`list`/`snapshot`) سوف استلام تجميع كل واحد طبقة مرشح بند: أولا هو وقت التشغيل skill، مجددا هو كل مزود `list()` نتيجة، سجل التسجيل سوف اعتماد مرة انتظار كل مزود، و عزل فشل. مرشح بند مرور تحقق بعد في طبقة داخل ذهاب إعادة، عبر طبقة دمج؛ ملخص حسب اسم ترتيب ترتيب. إتمام استلام تجميع حسب cwd،scope سلسلة و revision ذاكرة مؤقتة، حد أعلى لـ `collectCacheMaxEntries`؛ قراءة في طريق مزود أو وقت التشغيل تغيير جعل revision تمرير زيادة وقت، إجراء في استلام تجميع سوف إعادة محاولة مرة، ثاني مرة تغيير فإن إرجاع الأكثر جديد مرشح بند و علامة لـ لا كامل، لا إعطاء ذاكرة مؤقتة.

### تحميل و قديم قديم

`get()` اختيار فوز خروج مرشح بند، يجعل مزود تحميل و فحص بحث في توقف إشارة تنافس سرعة، و في اختيار أو ذاكرة مؤقتة أمر في بعد إعادة فحص إلغاء. إرجاع تعريف يجب و الذي اختيار مرشح بند نفس اسم؛ اسم لا رمز سوف جعل ذاكرة مؤقتة دليل بطلان، بـ سهل تحت مرة لقطة إعادة اكتشاف هذا مزود skill. تعريف من لا ذاكرة مؤقتة——كل مرة تحميل كل نحو مزود طلب حالي متن.

### بطلان

سجل التسجيل لا يوجد TTL: فقط لديه مزود استدعاء ذلك تسجيل أثر مجال داخل `invalidate()`، أو حدوث وقت التشغيل تسجيل أو تحرير وقت، عندئذ سوف صاف حذف قد إتمام دليل. كل مرة بطلان كل سوف تمرير زيادة revision، صاف فارغ ذاكرة مؤقتة، تزامن خروج لا حمل مرور ترشيح شرط `skills/change` حدث؛ مستهلك استخدام كل منها فحص بحث خيار إعادة نيل أخذ.`invalidate()` فقط عند استقبال هو ذلك بند دقيق تسجيل ما زال موضع في نشط حركة حالة وقت عندئذ توليد فاعلية، لذلك تأخير متأخر عودة ضبط لا يمكن جاف إزعاج نفس اسم بديل مزود.

<a id="model-experience"></a>
## تجربة النموذج

عبر `dsh-tool-skill` بين وصل أثر نموذج؛ هذا حزمة سوف مزود ملخص تصيير إلى حمل دائم ابتدائي دليل أو استبدال دليل رسالة في، و سوف تحميل إشارة أمر متن تصيير إلى قد إبقاء أداة نتيجة في.

#### KV Cache أثر

لا مباشر أثر نص التوجيه. إشارة تحديد مستهلك مسؤول حمل دائم ابتدائي دليل، و بطلان بعد فقط إلحاق صيغة دليل استبدال.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح سجل التسجيل أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **بطلان من مزود قيادة**——سجل التسجيل لا يوجد TTL، لا يمكن دفع قطع مهمة معنى بعيد مسار مصدر هل قد حدوث تغير؛ كل متغير مزود كل يجب إبقاء ذلك تسجيل أثر مجال داخل `invalidate()` قدرة، و من ذاته مراقبة قياس آلية استدعاء هو.
- **مزود اعتماد مرة استعلام**——واحد مؤقت بطيء مزود سوف تأخير متأخر ذلك بعد تسجيل كل مزود؛ إلغاء سوف إيقاف استدعاء جهة انتظار، لكن لا يمكن إنهاء لا استجابة إلغاء مزود حمل متابعة تشغيل عمل.
- **لا إبقاء لا كامل مراقبة قياس**——يتم رفض مزود سوف يتم حذف، صريح توفير مرشح بند أيضا فقط في حالي فحص بحث في متاح؛ سجل التسجيل حيث لا مسؤول الأكثر بعد واحد نسخة متاح دليل، أيضا لا مسؤول تدريجي مزود تشخيص.
- **إعادة اسم بند قطع قرار اعتماد أولا إلى أولا نيل**——نظام سوف سجل و إخفاء طبقة داخل مقارنة متأخر ظهور منخفض أولوية درجة مرشح بند، مقارنة قريب طبقة سوف ساكن صامت حجب حجب مقارنة بعيد طبقة؛ لا يوجد API يمكن فحص الكل يتم حجب حجب تعريف.
