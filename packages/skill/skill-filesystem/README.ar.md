# @deepseek-ai/dsh-skill-filesystem

[English](README.md) | العربية

## عام وصف

agent(ذكي جسم) يمكن استخدام قدوم ذاتي مستودع، ذاتي تعريف دليل أو مستخدم agent إعداد محلي skill(تقنية قدرة): يأخذ skill تحرير كتابة لـ مهمة واحد يتم مسح أصل دليل تحت دليل bundle(داخل يحتوي `SKILL.md`) أو مستو فرش `<name>.md` ملف، هو حينئذ سوف ظهور في جلسة دليل في. هذا مزود اكتشاف مشروع، ذاتي تعريف و مستخدم أصل دليل، تحليل كل skill YAML frontmatter، و مراقبة نظر هذه دليل، لذلك إضافة جديدة، تعديل اسم أو حذف skill بلا حاجة إعادة بدء يكفي وصول agent. عند skill تخزين وضع في مغناطيس قرص فوق وقت اختيار هو——سجل التسجيل (`dsh-skill`) قبول مهمة معنى مزود، أخرى مزود يمكن من آخر موضع توفير skill.

## استخدام هذه الحزمة

تركيب إضافة يكفي يجعل محلي skill مقابل agent متاح. هو مسح تحت جهة مشروع، ذاتي تعريف و مستخدم skill أصل دليل، يأخذ كل skill frontmatter تحليل لـ دليل بند، و حسب يحتاج تحميل متن؛ هو أيضا سوف مراقبة نظر هذه أصل دليل، جعل إضافة جديدة، تعديل اسم أو حذف skill بلا حاجة إعادة بدء يكفي دخول تحت مرة دليل.

### أي وقت اختيار

عند skill تخزين وضع في مغناطيس قرص فوق——مستودع، ذاتي تعريف دليل أو مستخدم agent إعداد في——وقت، استخدام هذا مزود. عند skill قدوم ذاتي بعيد مسار سجل التسجيل أو تضمين دخول صيغة إضافة بيانات وقت، طلب تجنب تجنب استخدام: سجل التسجيل قبول مهمة معنى مزود، هذه الحزمة فقط هو منها واحد نوع تنفيذ.

### skill صيغة

skill يمكن هو يتم مسح أصل دليل قمة طبقة دليل bundle `<name>/SKILL.md`، أيضا يمكن هو مستو فرش ملف `<name>.md`؛ لحظة معنى لا دعم حمل اكتشاف تضمين طقم `**/SKILL.md`. ملف بـ YAML frontmatter فتح رأس: لا بد ملء `name` و `description`، آخر لديه اختياري `whenToUse`،`metadata`،`disable-model-invocation` و `user-invocable`.

`disable-model-invocation: true` سوف يأخذ skill من موجه إلى نموذج دليل و loader في ترتيب حذف؛`user-invocable: false` سوف يأخذ هو من موجه إلى مستخدم أمر في ترتيب حذف، حذف حقل افتراضي سماح مقابل واجهة استدعاء. هذا اثنان عدد مفتاح قبول YAML قيمة منطقية، و لا منطقة قسم كبير صغير كتابة `true`/`false`،`yes`/`no`،`on`/`off` و `1`/`0` شكل صيغة؛ يتم رفض تجميع كتابة أو غير قيمة منطقية سوف يجعل كامل skill مع تحذير إبلاغ واحد بدء يتم إسقاط، بينما لن ساكن صامت سماح بعض عدد واجهة.

دليل بند و قد تحميل skill توفير تحليل بعد إشارة أمر ملف مسار، جعل رمز رقم رابط دليل و مسطح مستو ملف كل قدرة بصفة عادي ملف معاينة. إعادة تحميل تحديد موضع معلومة و مورد أصل إبقاء اكتشاف وقت مسار، يشمل رمز رقم رابط.

دليل و متن أداة لديه مستقل دورة الحياة: اكتشاف مرحلة مقطع يأخذ frontmatter تحليل دخول دليل بند، كل مرة تحميل كل سوف إعادة قراءة حالي ملف، لذلك تحرير skill متن بلا حاجة إصدار تحويل أو ذاكرة مؤقتة بطلان.

### أصل دليل و أولوية درجة

افتراضي أصل حسب هذا مزود rank ترتيب مسح:

| Rank | مصدر | مسار |
|---|---|---|
| 100 | `project-dsh` | `<projectRoot>/.dsh/skills` |
| 200 | `project-agents` | `<projectRoot>/.agents/skills` |
| 300 | `custom` | `Config.customSkillDirs` |
| 400 | `user-dsh` | `<dshHome>/skills` |
| 500 | `user-agents` | `<agentsHome>/skills` |

مشروع أصل دليل هو يتضمن `.git` الأكثر قريب أصل أولا دليل؛ إذا لا وجود، فإن استخدام حالي cwd. مستخدم DSH أصل دليل سوف قفز مرور ذلك `.system` فرعي دليل.`includeDefaultRoots: false` سوف حذف مشروع أصل، مستخدم أصل و `$DSH_BUNDLED_SKILL_DIR` قيمة افتراضية، جعل عزل مزود فقط يرى ذاته إعداد أصل؛`bundledSkillDir` سوف حسب rank 600 إضافة واحد مع حزمة توفير أصل دليل.

### تركيب و إعداد

و skill سجل التسجيل واحد بدء تحميل هذا إضافة؛ هو حاجة `ctx.skills`.

```yaml
- name: '@deepseek-ai/dsh-skill'
- name: '@deepseek-ai/dsh-skill-filesystem'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `filesystem` | تسجيل إلى `ctx.skills` وحيد مزود اسم |
| `includeDefaultRoots` | `true` | في `customSkillDirs` دورة محيط يتضمن مشروع أصل و مستخدم أصل |
| `dshHome` | `$DSH_HOME` أو `~/.dsh` | Harness إعداد أصل دليل؛ مسح ذلك `skills` فرعي دليل |
| `agentsHome` | `$DSH_AGENTS_HOME` أو `~/.agents` | لـ توافق skill مسح مشترك agent إعداد أصل دليل |
| `customSkillDirs` | `[]` | أخرى محلي skill أصل دليل، يقع في مشروع أصل بعد، مستخدم أصل قبل |
| `watch` | `true` | مراقبة نظر محلي أصل، و في دليل ممكن تغير وقت جعل مزود بطلان |
| `bundledSkillDir` | — | إعداد بعد حسب rank 600 مسح مع حزمة توفير skill أصل دليل |

ذلك بقية `watch*` حقل لأجل ضبط عقدة Chokidar سلوك——جولة استفسار، مستقر نافذة، بين فصل، مشروع حد أعلى و رمز رقم رابط تتبع مع. توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-skill-filesystem) كامل صف خروج كل حقل، هو هذه حقل حق مصدر.

### تغيير فحص قياس

قائم أصل دليل سوف يتم مراقبة نظر، لذلك إضافة جديدة، تعديل اسم أو حذف skill(أو تحرير ذلك frontmatter) سوف في تحت واحد نموذج خطوة إطلاق دليل تحديث جديد؛`references`،`scripts`،`assets` انتظار bundle مورد تحت تحرير لن إطلاق. عند رقم واحد جهة `write` و `edit` أداة هدف ممكن أثر تلقي مراقبة نظر skill وقت، هو جمع سوف مباشر جعل مزود بطلان، لذلك نموذج بلا حاجة انتظار مضيف watcher يكفي مراقبة إلى ذاته نظام الملفات تغيير. خارجي IDE،Git و shell تغيير من مضيف watcher التقاط؛ بعد لا وجود أصل دليل سوف يتم استكشاف قياس، مباشر حتى ذلك ظهور.

### يمكن مراقبة نجاح و فشل

مهمة واحد يتم مسح أصل دليل تحت صالح skill كل سوف حسب اسم ترتيب ظهور في جلسة دليل في، تحميل هو يكفي إرجاع حالي ملف متن. نقص قليل صالح frontmatter، اسم بلا فاعلية أو استدعاء قيمة بلا فاعلية ملف سوف مع تحذير إبلاغ يتم قفز مرور، لذلك نموذج دليل لن استلام إلى تدريجي skill تشخيص، أيضا لا يمكن منطقة قسم ناقص skill و بلا فاعلية skill. معنى خارج اكتشاف أو قراءة فشل سوف يجعل دليل مراقبة قياس إبقاء لا كامل، بينما لن استخدام نظر يشبه حدوث حذف نتيجة استبدال الأكثر بعد واحد نسخة متاح عرض.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير اكتشاف و مراقبة نظر مثل أي مجموعة نسج؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا مزود اعتماد اثنان بند مسؤولية قسم مغادرة. رقم واحد، دليل و متن قسم مغادرة: اكتشاف مرحلة مقطع يأخذ frontmatter تحليل لـ ملخص، بينما كل مرة تحميل كل إعادة قراءة ملف، لذلك متن تحرير بلا حاجة hash، إصلاح حجز رقم أو ذاكرة مؤقتة بطلان. ثاني، اكتشاف و مراقبة نظر قسم مغادرة:`list()` في وجود نظام الملفات خدمة وقت عبر `ctx.fs` مسح أصل دليل و تحليل مشروع أصل (لا فإن رجوع إلى يمكن في توقف Node I/O) ، بينما مستقل مراقبة نظر إدارة جهاز مسؤول Chokidar جملة مقبض، ناقص أصل استكشاف قياس و بطلان.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل، مزود، أصل تحليل،frontmatter تحليل، مراقبة نظر إدارة جهاز |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة، متبادل صلة اتفاق في الذي تابع seam قوي صنع تنفيذ. |

### اكتشاف مسار

اكتشاف مرور مسار أولا لـ فحص بحث cwd تحليل أصل قائمة، يجعل مراقبة نظر إدارة جهاز مرفق إضافة إلى كل أصل، مجددا مسح كل أصل مباشر بند: دليل bundle تحليل لـ `<name>/SKILL.md`، مستو فرش ملف تحليل لـ `<name>.md`. كل ملف كل سوف تحليل frontmatter——`name` يجب لـ kebab-case،`description` لا بد ملء، استدعاء مفتاح حسب صارم إطار نشر ذلك لغة قاعدة تحليل——مرشح بند يحمل أصل دليل مصدر وسم و rank، توفير سجل التسجيل و أخرى مزود دمج. قد تأكيد ناقص مسار يخص صالح فارغ حالة؛ صيغة خطأ أو غير نص بند سوف مع تحذير إبلاغ قفز مرور.

### مراقبة نظر و بطلان

قائم أصل دليل من Chokidar بـ عميق درجة 1 مراقبة نظر؛ لا وجود أصل سوف من الأكثر قريب قائم أصل أولا بدء، استعارة مساعدة `fs.watchFile` كل مرة امتداد واحد ناقص مسار مقطع تتبع أثر. متبادل صلة حدث——مباشر تابع bundle إضافة/إزالة، مستو فرش `.md` إضافة/إزالة، مباشر `SKILL.md` إضافة/إزالة/تغيير——سوف في كل دقيق مهمة دفعة مرة دمج لـ مرة مزود بطلان، مورد فرعي شجرة تحت تغيير فإن يتم تجاهل اختصار. مراقبة نظر إدارة جهاز تلقي `watchMaxProjects` حد، سوف سجل بدء فشل و إعادة محاولة، و في تحرير وقت إغلاق كل جملة مقبض. رقم واحد جهة `write`/`edit` تغيير عبر `fs/observed` حدث تزامن بطلان.

- [tool-skill حزمة](../tool-skill/README.ar.md)——قد اكتشاف skill مثل أي وصول جلسة دليل و نموذج.

<a id="model-experience"></a>
## تجربة النموذج

عبر `dsh-tool-skill` بين وصل أثر نموذج؛ هو يأخذ هذا مزود يمكن استدعاء اسم و لديه طويل درجة حد أعلى وصف تصيير إلى ابتدائي دليل أو استبدال دليل في، و يأخذ الذي اختيار حالي إشارة أمر متن و مورد أساس قاع إشارة جذب تصيير إلى قد إبقاء أداة تاريخ في؛ مسار، مزود rank و قد منع استخدام skill ما زال يتم إخفاء.

#### KV Cache أثر

watcher إطلاق بطلان يمكن حث جعل فوق وصف مستهلك في قائم طلب تاريخ في إلحاق استبدال دليل. فقط تعلق و متن تحرير لن تغيير دليل digest.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **اكتشاف عميق درجة لـ واحد طبقة**——فقط تعرف آخر `<root>/<name>/SKILL.md` و `<root>/<name>.md`؛ تجاهل اختصار تضمين طقم skill شجرة و حزمة manifest(بيانات وصفية بيان).
- **مشروع نطاق لـ الأكثر قريب `.git` أصل أولا**——لا يوجد هذا علامة مساحة العمل رجوع إلى توفير cwd، لا دعم حمل أخرى مشروع أصل علامة أو monorepo فرعي مشروع اختيار.
- **صيغة خطأ بند مع تحذير إبلاغ إزالة فقد**——نموذج دليل لن استلام إلى تدريجي skill تشخيص، لا يمكن منطقة قسم ناقص skill و بلا فاعلية skill؛ معنى خارج I/O فشل فإن سوف إبقاء الأكثر بعد واحد نسخة متاح دليل.
- **ناقص أصل مراقبة كل مرة جولة استفسار واحد مسار مقطع**——بدء وقت لا وجود أصل سوف استخدام `fs.watchFile` حسب `watchPollIntervalMs` جولة استفسار، مباشر حتى Chokidar يمكن مرفق إضافة؛ هذا بـ محدود فحص قياس تأخير متأخر تبديل أخذ عبر IDE،Git و shell سير العمل يمكن اعتماد إنشاء فحص قياس.
- **بلا متن إصلاح حجز بروتوكول**——قد تحميل متن هو عادي قد إبقاء أداة تاريخ؛ لاحق ملف تحرير سوف أثر لاحق استدعاء، لكن حيث لن تعديل كتابة قديم نتيجة، أيضا لن إشعار متن قد تغير.
