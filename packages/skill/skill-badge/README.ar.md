# @deepseek-ai/dsh-skill-badge

[English](README.md) | العربية

## عام وصف

agent(ذكي جسم) يمكن عبر هذا داخل وضع مزود تحميل رسمي جهة «powered by dsh» شعار فصل skill، و التزام دوران ذلك إشارة أمر، إعطاء وثيقة،PR(Pull Request) و أخرى استخدام DeepSeek Harness توليد محتوى إضافة توقيع اسم شعار فصل. هذا مزود لا يوجد إعداد، مع مرفق CLI(أمر سطر واجهة) تركيب بـ منع استخدام حالة يتضمن هذا إضافة، لذلك نشر جهة حاجة صريح تفعيل. هذا skill معا توفير Markdown قطعة مقطع و مع حزمة توزيع PNG، توفير لا يمكن يمكن اعتماد استيراد بعيد مسار صورة نظام استخدام.

## استخدام هذه الحزمة

تفعيل إضافة يكفي يجعل `dsh-badge` skill ظهور في جلسة skill دليل في؛ مع بعد نموذج يمكن مثل تحميل أي أخرى skill واحد مثال تحميل هو، و التزام دوران ذلك إشارة أمر إضافة «powered by dsh» شعار فصل.

### أي وقت اختيار

عند استخدام DeepSeek Harness توليد محتوى ينبغي يحمل رسمي جهة توقيع اسم شعار فصل، كما نشر جهة أمل نظر هذا شعار فصل skill مقابل agent متاح بينما بلا حاجة تخزين دخول محلي skill دليل وقت، اختيار هذا مزود. عند شعار فصل و نشر غير متصل وقت، طلب قفز مرور——إضافة افتراضي منع استخدام، تفعيل قبل لا زيادة أي شرق غرب.

### تفعيل إضافة

هذا إضافة لا يوجد إعداد. يأخذ هو تركيب سطر إضافة دخول تركيب يكفي؛ مع مرفق CLI تركيب بـ `disabled: true` يحمل هذا سطر، لذلك في ذلك داخل حاجة صريح تفعيل.

```yaml
- name: '@deepseek-ai/dsh-skill-badge'
```

تفعيل بعد،`dsh-badge` سوف ظهور في جلسة دليل متاح skill في. هذا skill تغطية بعيد مسار Markdown شعار فصل (أساس في Shields.io) و مع حزمة توزيع PNG شعار فصل مورد، بعد من لأجل لا يمكن يمكن اعتماد نيل أخذ بعيد مسار صورة هدف بيئة.

### شعار فصل skill توفير ماذا

- **Markdown قطعة مقطع.** في وثيقة،PR و merge request في تضمين دخول رسمي جهة شعار فصل علامة إشارة أمر.
- **مع حزمة توزيع PNG مورد.** `dsh-badge.png`(726×120 مصدر رسم، حسب 121×20 تصيير) ، في لا يمكن استيراد بعيد مسار صورة بيئة في متاح.

### يمكن مراقبة نجاح و فشل

تفعيل إضافة سوف جعل `dsh-badge` ظهور في دليل في و يمكن سند اسم تحميل؛ منع استخدام أو حذف هذا سطر فإن هو لن ظهور في أي دليل في. من في مزود غير ممكن تغيير، اكتشاف بداية نهاية نجاح كما تماما جيد إرجاع واحد skill، أبدا سوف تقرير إبلاغ جزء نتيجة.

## فهم التنفيذ

<details>

هذا عقدة حل تفسير داخل وضع مزود مثل أي وصل خط؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا مزود هو واحد غير ممكن تغيير، تزامن تسجيل skill مصدر: هو بـ `dsh-badge` بصفة مزود اسم، حسب داخل وضع skill rank(600) تسجيل واحد ثابت مرشح بند، يأخذ مع حزمة توزيع `assets/` دليل بصفة هذا skill دليل مورد أساس قاع عام، و في كل مرة تحميل وقت من مع حزمة توزيع `assets/dsh-badge.md` ملف قراءة skill متن.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل و غير ممكن تغيير مزود: واحد مرشح بند، مورد أساس قاع، متن تحميل |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذه الحزمة فقط يحتفظ واحد غير ممكن تغيير مزود تسجيل، تسجيل وحيد صفة و دورة الحياة فحص من skill سجل التسجيل مسؤول. |
| [`assets/`](assets/) | مع حزمة توزيع skill متن (`dsh-badge.md`) و PNG مورد (`dsh-badge.png`) |

<a id="model-experience"></a>
## تجربة النموذج

عبر `dsh-tool-skill` بين وصل أثر نموذج؛ هذا حزمة سوف يأخذ هذا مزود دليل بند و الذي اختيار skill متن تصيير إعطاء نموذج.

#### KV Cache أثر

هذا إضافة افتراضي منع استخدام، لن تغيير أي طلب. تفعيل بعد، ذلك دليل بند و أي قد تحميل متن كل سوف في كل منها إدراج دخول نقطة تغيير مزود KV بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح داخل وضع مزود لا فعل ماذا. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **ثابت واحد skill، بلا وقت التشغيل ذاتي تعريف**——مزود تماما جيد مساهمة `dsh-badge` هذا واحد skill؛ حاجة أخرى شعار فصل تغيير جسم نشر طلب ذاتي سطر تحرير كتابة skill.
- **بعيد مسار Markdown اعتماد Shields.io**——بعيد مسار شعار فصل علامة داخل تضمين Shields.io صورة؛ هدف بيئة لا يمكن يمكن اعتماد نيل أخذ بعيد مسار صورة وقت، طلب استخدام مع حزمة توزيع PNG.
