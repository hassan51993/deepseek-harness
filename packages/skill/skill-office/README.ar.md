# @deepseek-ai/dsh-skill-office

[English](README.md) | العربية

## عام وصف

Agent(ذكي جسم) يمكن تحميل Word،PowerPoint و Excel سير العمل، افتراضي استخدام داخل وضع Python بيئة، و التزام دوران مستخدم أو AGENTS.md واضح إشارة تحديد بيئة. هذه skill(تقنية قدرة) شمول غطاء إنشاء، نطاق جزء تحرير، بنية فحص و ملف تسليم. نظر شعور فحص بـ نموذج دعم حمل صورة كما لديه متاح تصيير أداة لـ قبل رفع؛ عادي وثيقة تسليم لا اشتراط تثبيت مصير.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

سوف هذا مزود و skill سجل التسجيل و `dsh-tool-skill` واحد نفس تركيب، يكفي في جلسة دليل في توفير `office-docx`،`office-pptx` و `office-xlsx`. مزود يحمل إشارة أمر و نص برمجي؛ نشر توفير حل تفسير جهاز، تحرير كتابة مكتبة، تنفيذ أداة و ملف تسليم أداة.

### الأكثر صغير إعداد

```yaml
- name: '@deepseek-ai/dsh-skill-office'
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `assetRoot` | حزمة داخل `assets/` | يتضمن ثلاثة عدد skill ملف مشبك و مشترك `scripts/` قطعا مقابل مورد دليل؛ نشر يمكن سوف ذلك وضع في تطبيق عودة ملف خارج. |

متبادل مقابل مسار، مورد ناقص أو skill ملف YAML frontmatter نقص قليل وصف كل سوف توجيه يؤدي تنشيط فشل. إزالة إضافة سوف إزالة ذلك مرشح بند. مشروع و مستخدم skill أولوية درجة ما زال من skill سجل التسجيل مسؤول.

### بنية فحص

مشترك Python فحص جهاز قراءة DOCX،PPTX أو XLSX، لا تعديل مصدر ملف. هو تعرف آخر Transitional و Strict OOXML نطاق الأسماء، تحقق ZIP/XML و حزمة داخل مرجع علاقة، تقرير إبلاغ وثيقة بنية، و يمكن فحص مطلوب نص أو وهم مصباح قطعة/عمل جدول عدد كمية.DOCX نص تأكيد تغطية متن، قسم عقدة مرجع صفحة حاجب و صفحة قدم، و متن مرجع قدم ملاحظة و ذيل ملاحظة؛ دفعة ملاحظة، كلمة مكتبة نص و لم مرجع جزء عنصر أو قدم ملاحظة/ذيل ملاحظة لا يستطيع ممتلئ كاف تأكيد. هو فقط استخدام Python معيار مكتبة. بلا فاعلية حزمة، ضرر تالف أو إضافة سري ZIP عضو و تقرير إبلاغ ملف كتابة فشل كل سوف في معيار إخراج في إنتاج JSON فشل تقرير إبلاغ. فحص عبر لا بديل جدول خارج مراقبة، خاص صفة إبقاء أو عام صيغة حساب حساب نتيجة قد نيل إلى تحقق.

| — | لا إصدار وقت التشغيل ثابت كمية مرافق مع مدخل: مزود يملك غير ممكن تغيير مرشح بند،skill سجل التسجيل مسؤول تسجيل دورة الحياة و أولوية درجة. |

<a id="model-experience"></a>
## تجربة النموذج

عبر `dsh-tool-skill` بين وصل عرض، من ذلك تصيير دليل بند و اختيار في إشارة أمر متن.

#### KV ذاكرة مؤقتة أثر

تركيب مزود سوف زيادة ثلاثة عدد دليل بند؛ تحميل skill وقت، ذلك متن دخول قائم skill أداة إدراج دخول موضع. مزود لا آخر زيادة نص التوجيه قسم منطقة.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>

- مزود لا تثبيت Python، تحرير كتابة مكتبة أو تصيير جذب محرك. فحص جهاز اشتراط Python 3.9 أو أكثر عال إصدار.
- بنية فحص لا حكم قطع قسم صفحة، مقتطع، حرف جسم، رسم جدول خارج مراقبة أو Excel إعادة حساب.
- فحص جهاز فقط قبول DOCX،PPTX و XLSX؛ نقل موحد صيغة، إضافة سري ملف و تفعيل كبير صيغة حاجة دمج ملائم أخرى سير العمل.
