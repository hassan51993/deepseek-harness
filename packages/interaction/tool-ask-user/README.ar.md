# @deepseek-ai/dsh-tool-ask-user

[English](README.md) | العربية

## عام وصف

`ask_user_question` يجعل نموذج مؤقت توقف عمل، نحو مستخدم طلب تأكيد، اختيار أو ناقص معلومة. هو قبول واحد أو كثير عدد مشكلة، و بـ ضيق تجميع JSON إرجاع عودة جواب. استدعاء سوف انتظار عودة جواب يتم قبول أو حالي جولة يتم إلغاء؛ إذا لا يوجد عودة جواب معالج قبول طلب، نموذج سوف استلام إلى خطأ. ملكية في وقت التشغيل أخرى agent فرعي درجة لا يستطيع استدعاء هذا أداة، يجب في نهائي نتيجة في تقرير إبلاغ بعد لم حل قرار مشكلة. هذه الحزمة لا تصيير واجهة أو استلام تجميع إدخال، لذلك استدعاء جهة يجب توفير توافق مستخدم تفاعل جدول وجه.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

كل نموذج ينبغي عند قدرة كاف مؤقت توقف انتظار شخص صنف قرار مشهد، كل يمكن تركيب هذا إضافة: هو توفير `ask_user_question` أداة، و كما حاجة حمل لديه قبول أثر مجال طلب answerer `ctx.userQuestions` seam. لا يوجد answerer قبول وقت، أداة استدعاء سوف بـ خطأ فشل، بينما لا هو تخفيض.

### أي وقت استدعاء هذا أداة

عند نموذج حاجة تأكيد، اختيار نتيجة أو ناقص معلومة عندئذ قدرة متابعة وقت، استدعاء `ask_user_question`. إرسال واحد أو كثير عدد مشكلة، كل مشكلة يحمل مستقر `id`(عودة جواب في سوف أصل مثال يتضمن) ؛ دفع ترشيح خيار وضع في أول موضع، و في وسم نهاية ذيل إلحاق `(Recommended)`.

```json
{
  "questions": [
    {
      "id": "cleanup",
      "question": "Proceed with the destructive cleanup?",
      "header": "Confirm",
      "options": [
        { "label": "Yes, delete them (Recommended)", "description": "Removes the three stale files." },
        { "label": "No, keep them", "description": "Aborts the cleanup." }
      ]
    }
  ]
}
```

### نموذج نيل إلى ماذا

أداة لـ كل مشكلة إرجاع واحد عودة جواب كائن:`selected` حفظ اختيار في خيار وسم،`custom` يحمل ذاتي من ملء كتابة عودة جواب——مقابل كثير اختيار عنوان تكملة ملء `selected`، مقابل مفرد اختيار عنوان تغطية هو.Native مصير إبقاء ضيق تجميع JSON نص شكل صيغة.

```json
{ "answers": [{ "id": "cleanup", "selected": ["Yes, delete them (Recommended)"] }] }
```

### استدعاء أي وقت فشل

أداة استدعاء سوف منع سد إلى مستخدم عمل جواب، و كما فقط قدرة عبر حالي جولة إشارة إلغاء. لا يوجد answerer قبول، استدعاء يتم في توقف، أو استدعاء جهة لا هو تأكيد قطع تخزين نشط وقت التشغيل أصل، كل سوف بـ نموذج في أداة نتيجة في يرى خطأ تسوية——الأكثر قيمة نيل ملاحظة معنى هو، ملكية في آخر عدد agent تخزين نشط فرعي درجة سوف يتم رفض (`DELEGATED_CALLER`) ، يجب في نهائي نتيجة في يتضمن بعد لم حل قرار مشكلة أو قرار.

هذا إضافة بـ `['tools', 'userQuestions']` حقن، في `ctx.tools` فوق تسجيل واحد `defineTool` بند.`execute` يأخذ نموذج معامل خريطة لـ `AskUserQuestionRequest`، تحويل إرسال تأكيد قطع استدعاء agent و حالي جولة إشارة، و يأخذ قبول عودة جواب خريطة عودة مواصفة `answers` عدد مجموعة. هوية فحص، معنى رسم تحقق،waterfall(شلال نشر صيغة حدث) قسم إرسال و خطأ تصنيف من seam يملك؛ هذه الحزمة فقط فعل تحويل.

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى محتوى

نموذج سوف يرى توليد [`ask_user_question` schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-ask-user) ، منها يتضمن مشكلة id، تلميح لغة، عنوان، خيار و كثير اختيار علامة سجل.

#### Token أثر

أداة مرئي وقت، كل طلب كل سوف إنتاج ثابت schema token فتح إلغاء.

#### KV Cache أثر

فقط يلزم تعريف و مرئي صفة إبقاء ثابت، بادئة يكفي مستقر إعادة استخدام. إضافة دورة الحياة تغير أو أثر مجال حد ممكن سوف جعل من هذا schema بدء ذاكرة مؤقتة إعادة استخدام بطلان.

### أداة استدعاء تاريخ و نتيجة

#### نموذج يرى محتوى

نموذج رفع خروج كامل مشكلة إبقاء في assistant أداة استدعاء معامل في. مستخدم عودة جواب بعد، تحت واحد خطوة سوف يرى دقيق اعتماد `{"answers":[{"id":"<id>","selected":["<label>"],"custom":"<text>"}]}` شكل صيغة ضيق تجميع JSON؛ لا استخدام `custom` وقت سوف حذف هذا حقل،`selected` يمكن يتضمن صفر عدد، واحد أو كثير عدد وسم. استدعاء انتظار خلال UI تفاعل لا يخص نموذج سياق.

#### Token أثر

معامل و عودة جواب JSON هو اعتماد بيانات بينما تحديد إبقاء token؛ انتظار مستخدم وقت لن إنتاج token فتح إلغاء.

#### KV Cache أثر

فقط إلحاق؛ جديد ظهور مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا أداة أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو UI تراكم ضغط أمر بند.

- **انتظار معالجة مشكلة سوف منع سد أداة استدعاء، مباشر حتى مستخدم عمل جواب**: هذا أداة لم إعلان `timeout-policy` ميزانية؛ إلغاء فقط امتداد استخدام حالي جولة `exec.signal`.
- **وقت التشغيل في ملكية في أخرى agent subagent لا يستطيع نحو مستخدم رفع سؤال**:`ask_user_question` سوف بـ `DELEGATED_CALLER` رفض ملكية في آخر عدد agent تخزين نشط فرعي درجة؛ هذا فرعي درجة يجب في نهائي نتيجة في يتضمن بعد لم حل قرار مشكلة أو قرار. حمل دائم جدول نظام لا يستطيع قرار هذا واحد حد، لذلك حمل لديه جدول نظام جلسة استعادة لـ وقت التشغيل أصل بعد يمكن صحيح معتاد رفع سؤال.
- **Native عودة جواب تصيير لـ JSON نص**: مواصفة قيمة ما زال لـ بنية تحويل بيانات، لكن نموذج جانب نتيجة استخدام ضيق تجميع JSON، بينما غير أكثر وفير غني محتوى كتلة مفردات.
