# @deepseek-ai/dsh-commands

[English](README.md) | العربية

## عام وصف

`dsh-commands` يجعل مستخدم قدرة في تفاعل صيغة Harness UI في تشغيل `/command [input]` عملية، كما لن يأخذ أمر أو نتيجة تغيير صار نموذج رسالة. أمر يمكن عرض إدخال تلميح، قبول مرفق عنصر، و فقط إبرة مقابل واحد agent توليد فاعلية، معا لـ أخرى agent إبقاء نفس اسم عام أمر. كل مرة عبر دقيق دخول تنفيذ كل سوف سجل إلى استقبال agent جلسة سجل في،UI فإن في نموذج تاريخ خارج تصيير تسوية نتيجة. هو ملائم دمج لـ `dsh` CLI(أمر سطر واجهة) أو Web عميل توفير مباشر موجه إلى مستخدم تحكم؛ بلا UI عرض عرض و ACP(Agent Client Protocol) تلقائي تحويل لا توفير هذا أمر وجه.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تفاعل صيغة UI أمل نظر مستخدم استخدام مائل عمود أمر بينما غير نموذج نص التوجيه قيادة agent جانب سلوك وقت، تركيب هذا خدمة. بلا UI عرض عرض رئيسي جاف و ACP تلقائي تحويل لا توفير أمر مهايئ، أيضا لا حاجة هو.

### تسجيل أمر

إضافة عبر `ctx.commands.register()` تسجيل أمر، توفير صغير كتابة اسم، اكتشاف واجهة في شرح، اختياري `input` تلميح و معالج. اختياري صنف لوحة نوع حقل `definitionId` لـ مهايئ توفير حمل إضافة نطاق الأسماء مستقر تعريف معرف، هو مستقل في عرض نص سجل و كل مرة تنفيذ `commandId`. صالح وصف رمز فقط يحمل يتم اختيار في تعريف معرف، أثر مجال تغطية لن وراثة يتم حجب حجب تسجيل بند معرف.

```text
ctx.commands.register({
  name: 'plan',
  description: 'Enter plan mode',
  input: { hint: '<message>' },
  handler: ({ agent, rawInput }) => {
    // Runs directly against the agent; no model message is created.
    return { kind: 'success', text: 'plan mode selected' }
  },
})
```

معالج إرجاع `success` أو `error`، و يمكن مرفق حمل من مهايئ تصيير UI نص.`recordInput` افتراضي لـ true؛ إذا تحميل حمل من أمر ذاتي ذات مرجعي مجال حدث يحتفظ، أمر سوف سوف `recordInput` ضبط لـ false، تجنب تجنب جلسة سجل تكرار سجل هذا إدخال. نفس أثر مجال داخل تكرار تسجيل نفس اسم أمر سوف رمي خروج استثناء.

### أمر لغة قاعدة

أمر سطر رقم 0 بايت يجب هو مائل عمود، مع بعد هو صغير كتابة اسم (يمكن يحتوي حرف أم، عدد حرف،`_` أو `-`) ، مجددا بعد هو إدخال نهاية ذيل أو فارغ أبيض. اسم بعد كل بايت——يشمل قسم فصل فارغ أبيض——كل هو هذا أمر `rawInput`، أمر ذاتي ذات يملك ذلك مخصص تابع لغة قاعدة. لا رمز دمج أمر لغة قاعدة، أو اسم لم معرفة سطر سوف يتم مهايئ رفض، بينما لا هو تغيير صار نموذج نص التوجيه.

### حد تحديد إلى agent أمر

عادي تسجيل عام توليد فاعلية. تركيب في agent ذاته سياق لـ تحت أمر إنتاج إضافة سوف إعلان `commands` حقن، و تسجيل دقيق حد تحديد إلى هذا agent أمر؛ هذا تعريف فقط مقابل هذا عدد agent حجب حجب نفس اسم عام تعريف.

### مرفق عنصر

أمر يمكن إعلان `input.attachments` بـ قبول composer صورة و عام ملف. منفذ مسؤول قوي صنع تنفيذ إعلان: يأخذ مرفق عنصر إرسال إعطاء لم إعلان أمر، مرفق عنصر تخزين ناقص، جلسة نطاق داخل ملف فوق نقل سند إثبات لم معرفة أو صورة دفعة كمية تجاوز خروج حد، كل سوف في معالج تشغيل قبل بـ خطأ نتيجة تسوية. صورة بـ base64 إدخال عبر أمر wire، عام ملف فإن مرجع خلفية فوق نقل إتمام بعد نيل إلى سند إثبات، لذلك أمر إيداع لن مجددا مرة قراءة ملف بايت. عبر دقيق دخول `ImageBlock` و `FileBlock` حسب مستخدم اختيار ترتيب مجموعة صار تجميد ربط `invocation.attachments` عدد مجموعة، ذلك نموذج مرئي استخدام طريق من معالج مسؤول.

### من مهايئ قسم إرسال

تفاعل صيغة مهايئ استدعاء `execute(agent, line, attachments, signal)`، نقل دخول تأكيد قطع استقبال agent، كامل أمر سطر و هذا مرة إيداع لديه ترتيب مرفق عنصر. هو إرجاع قد تسوية `CommandExecution`——مواصفة تحويل نتيجة إضافة دورة الحياة إعداد مقابل `commandId`——لغة قاعدة بلا فاعلية أو اسم لم معرفة وقت إرجاع `undefined`.`list(agent)` و `find(agent, name)` في تطبيق agent أثر مجال حجب حجب بعد لأجل أمر اكتشاف.

### إلغاء

استدعاء جهة في توقف إشارة سوف يجعل سجل التسجيل إيقاف انتظار معالج؛ بلا نظر إشارة معالج ممكن في استدعاء جهة إيقاف انتظار بعد متابعة إنتاج ذاته خارجي فرعي أثر. يتم إلغاء أو رمي استثناء معالج في سجل في بـ `command/done` خطأ تسوية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح؛ هذا عقدة حل تفسير سجل التسجيل بناء طريقة و ذلك اتفاق ملكية.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | `CommandRuntime` خدمة: تسجيل، أثر مجال، قسم إرسال، دورة الحياة حدث |
| [`src/types.ts`](src/types.ts) | أمر تعريف، وصف رمز، تنفيذ و نتيجة نوع |
| [`src/brand.ts`](src/brand.ts) | مستقر أمر تعريف معرف و كل مرة تنفيذ دورة الحياة id |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة: حسب جلسة سجل إعداد مقابل `command/run` و `command/done` |

### دورة الحياة حدث

`execute()` سوف توليد واحد `commandId`، في معالج تشغيل قبل إلحاق `command/run`، و في تسوية وقت إلحاق يحمل نتيجة نوع و أصل مثال نص `command/done`؛ تأكيد قطع تحميل حمل حقل رؤية [`src/index.ts`](src/index.ts). نجاح نتيجة يمكن عبر `sourceEventSeq` إشارة نحو أكثر مبكر واحد بند غير أمر مرجعي مجال حدث؛ معالج رمي خروج أو يتم في توقف وقت بـ `kind: 'error'` تسوية. اثنان عدد حدث كل بصفة فقط لأجل سجل حدث مباشر مستقل إلحاق: لا يوجد جولة حزمة لف هو جمع، حفظ دائم آلية سوف في معتاد قاعدة فحص نقطة و إلغاء تدمير خلال ترتيب فارغ هذه حدث. لم عبر دقيق دخول إدخال (لغة قاعدة بلا فاعلية أو اسم لم معرفة) لا سجل أي حدث.

### أثر مجال

سجل التسجيل عبر `ScopedLayers` صيانة عام طبقة و حسب agent أثر مجال طبقة، و حسب agent دمج عرض. فرعي درجة حقن شكل——تركيب في `agent.ctx` لـ تحت أمر إنتاج إضافة إعلان ذاته `commands` حقن——إبقاء agent أثر مجال، معا لن يجعل نواة قلب agent loop(ذكي جسم حلقة) اعتماد UI خدمة. نفس طبقة داخل اسم تكرار سوف في تسجيل وقت فشل؛ تسجيل أو إزالة أمر وقت، نظام سوف إشعار كل `commands/change` مراقبة من، جعل تشغيل في مهايئ قدرة كاف تحديث جديد اكتشاف نتيجة. مراقبة من فشل سوف كتابة سجل، حيث لا يستطيع مرفوض سجل التسجيل تغيير، أيضا لا يستطيع منع توقف لاحق مراقبة من تشغيل.

### مرفق عنصر دقيق دخول

مرفق عنصر قوي صنع تنفيذ حدوث في منفذ في: صورة مرور `admitEncodedImages` إيداع، ملف عبر وحيد جلسة شعور معرفة سند إثبات مزود تحليل، منفذ في استدعاء معالج قبل استعادة أصلي خلط دمج ترتيب. تحقق رفض لن بدء كتابة مرفق عنصر. صورة تخزين فشل ممكن إبقاء تحت انتظار تنظيف كما لا يمكن مرجع محتوى بحث عنوان كائن، لكن لن إصدار نموذج مرئي رسالة. إلغاء سوف في معالج تشغيل قبل توليد فاعلية. أمر إرجاع خطأ وقت، توزيع جهة composer مسودة مسودة و مرفق عنصر بطاقة إبقاء أصل موضع.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### مباشر موجه إلى مستخدم أمر

#### نموذج يرى محتوى

سجل التسجيل ذاته لن إيداع أي محتوى. معروف مائل عمود أمر في UI أمر مستو وجه تنفيذ، ذلك `CommandResult` نص لن بصفة مستخدم رسالة إيداع. قد تسليم مهايئ سوف رفض لم معرفة مائل عمود أمر إدخال، بينما لا هو سوف ذلك تغيير صار نموذج نص التوجيه. أمر إنتاج جهة يمكن صريح استخدام استقبال أمر `Agent`؛ مثال مثل،[`dsh-plan-mode`](../../plan/plan-mode/README.ar.md#model-and-human-interactions) في اختيار plan mode بعد، سوف إيداع `/plan [message]` في اختياري رسالة و لديه ترتيب مرفق عنصر. منفذ فقط مسؤول يأخذ مرفق عنصر دقيق دخول لـ حفظ دائم كائن، هل و مثل أي يصبح نموذج مرئي رسالة من إعلان قبول إنتاج جهة قرار.

#### Token أثر

أمر اكتشاف، تنفيذ و UI إخراج لن زيادة نموذج token. أمر إنتاج جهة صريح أمان ترتيب agent عمل و متبادل ينبغي agent إدخال أداة لديه نفسه token أثر.

#### KV Cache أثر

سجل التسجيل بيانات وصفية، أمر إدخال و مباشر إخراج أبدا سوف دخول نموذج طلب، أيضا لن أثر ذلك ذاكرة مؤقتة. حدوث تغيير مجال مسؤول بعد إنتاج كل ذاكرة مؤقتة أثر.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح سجل التسجيل لا توفير ماذا. هو جمع هو حالي حزمة قيد، لا هو UI تراكم ضغط أمر بند.

- **فقط دعم حمل غير بنية تحويل نص إدخال**: جدول مفرد، تكملة كل schema و نوع تحويل معامل ما زال من كل أمر ذاتي سطر تحليل.
- **فرعي أثر اعتماد تنسيق عمل صيغة إلغاء**: في توقف بعد، توزيع سوف إيقاف انتظار؛ معالج يجب التزام دوران إشارة، عندئذ قدرة إيقاف قد دخول خارجي نظام عمل.
