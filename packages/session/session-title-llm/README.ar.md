# @deepseek-ai/dsh-session-title-llm

[English](README.md) | العربية

## عام وصف

`dsh-session-title-llm` استخدام متسق نموذج طلب سياسة، أصل حسب اختيار في مستخدم رسالة توليد بسيط نظيف جلسة عنوان. استدعاء جهة اختيار كل مرة إصلاح حجز يتضمن أي بعض رسالة، و صار مقابل توفير `provider`/`model` توجيه، أيضا هو استخدام حالي جلسة سجل توجيه. لا بد ملء حد أعلى قيد غلاف تركيب بعد إدخال، توليد إخراج و طرف إلى طرف وقت طويل، استدعاء جهة إلغاء في كامل تدفق صيغة معالجة خلال حمل متابعة توليد فاعلية. بلا فاعلية، فارغ، متأخر إلى، يتضمن استدعاء الأداة أو أخرى غير صاف نص نتيجة سوف في استبدال عنوان قبل يتم رفض.

## استخدام هذه الحزمة

بصفة نشر جهة، عبر[أول رسالة](../session-title-first-prompt-llm/README.ar.md) أو[كل رسالة](../session-title-all-prompts-llm/README.ar.md) مزود إضافة إعداد هذا سياسة. بصفة مزود عمل من، عبر مشترك مساعد مساعدة دالة تسجيل، بينما لا هو يد كتابة توليد منطق.

### تسجيل مزود

مزود إضافة استدعاء `registerSessionTitleLlmProvider(ctx, config, id, automatic, selectMessages)`؛ مساعد مساعدة دالة تحقق مشترك إعداد، في `ctx.sessionTitle` فوق تسجيل مزود، و يجعل كل مرة توليد كل مرور مرور مشترك سياسة. اثنان عدد مع مرفق إضافة بـ كل منها `first-prompt` و `all-prompts` عقدة عزف و رسالة اختيار جهاز تسجيل؛ خدمة فوق ثاني مرة تسجيل سوف قيام أي رمي خروج.

### توجيه و فشل اتفاق

`provider` و `model` تغطية بند كل هو اختياري، لكن يجب معا بصفة غير فارغ نص توفير. إذا لا يوجد هذا واحد مقابل أخذ قيمة، مساعد مساعدة دالة استخدام حالي جلسة قد سجل `request/header` في التقاط تأكيد قطع مزود/نموذج توجيه، لذلك في أي توجيه ظهور قبل صريح تحديث جديد وقت يجب توفير تغطية بند. مساعد مساعدة دالة في سجل أو توزيع قبل، اعتماد حسب `maxInputBytes` فحص نهائي JSON غلاف تركيب مستخدم نص التوجيه كبير صغير، بينما لا هو سوف ذلك مقتطع، و في إزالة استهلاك تدفق خلال و إتمام بعد إعادة فحص مهلة و استدعاء جهة إلغاء، لذلك أي جعل اعتراض قطع جهاز أو مهايئ تجاهل اختصار abort، أيضا لا يستطيع قبول متأخر إلى نجاح نتيجة. صيغة خطأ أو فارغ إخراج، استدعاء الأداة و غير stop انتهاء سبب كل سوف رفض؛ جلسة عنوان خدمة قرار هذا رفض يخص تلقائي تحذير إبلاغ أيضا هو صريح استدعاء جهة فشل.

### إعداد

<a id="configuration"></a>

حذف صار مقابل توجيه تغطية بند خارج، كل حقل كل لا بد ملء؛ مكتبة لا توفير قيمة افتراضية.

| مفتاح | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `targetWords` | لا بد ملء | غير CJK عنوان هدف كلمة عدد |
| `targetCjkCharacters` | لا بد ملء | العربية، يوم نص أو كوريا نص عنوان هدف محرف عدد |
| `maxInputBytes` | لا بد ملء | نهائي JSON غلاف تركيب مستخدم نص التوجيه UTF-8 بايت حد أعلى |
| `maxOutputTokens` | لا بد ملء | مساعد مساعدة توليد token حد أعلى |
| `timeoutMs` | لا بد ملء | وقت التشغيل تحديد وقت جهاز حد داخل طرف إلى طرف وقت حد |
| `provider`, `model` | اختياري | صريح توجيه؛ اثنان من معا توفير أو معا حذف |

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير توليد مسار؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

واحد نسخة مشترك سياسة يجعل مزود إضافة لا يمكن عائم نقل: إعداد تحقق، توجيه تحليل، نص التوجيه غلاف تركيب، ميزانية تنفيذ، إلغاء و إخراج تحقق كل في هذا داخل، فقط بـ مزود عقدة عزف و رسالة اختيار جهاز لـ معامل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إعداد schema و تحقق، مزود تسجيل مساعد مساعدة، طلب غلاف تركيب، توزيع و إخراج تحقق |

### طلب مسار

توليد في تسجيل وقت تحقق مرة إعداد؛ كل مرة إصلاح حجز يأخذ اختيار في رسالة غلاف تركيب لـ JSON، اعتماد حسب `maxInputBytes` فحص غلاف تركيب نص التوجيه UTF-8 بايت عدد، تحليل توجيه (صريح مقابل أو قد سجل `request/header`) ، إلحاق واحد بند يحمل تأكيد قطع يمكن توزيع طلب فقط سجل `session/title-llm-request` حدث، لكن بعد في تركيب مهلة و إلغاء قطع توقف وقت داخل عبر `ctx.llm` تدفق صيغة توليد. توزيع غلاف طقم يحمل `purpose: 'session-title'`، كما متعمد لا يتضمن agent loop عملية محلي طلب هوية؛DeepSeek مهايئ أصل حسب هذا استخدام طريق منع استخدام تفكير اعتبار، جعل قليل كمية إخراج ميزانية الكل لأجل مرئي عنوان نص، أخرى مهايئ مسؤول ذاته استخدام طريق مخصص استخدام سلوك. إخراج فقط تجميع لـ نص كتلة؛ استدعاء الأداة، صيغة خطأ أو فارغ إخراج و غير stop انتهاء سبب كل سوف رفض، لاحق نموذج فشل سوف إبقاء طلب سجل.

<a id="model-experience"></a>
## تجربة النموذج

### مساعد مساعدة عنوان طلب

#### نموذج يرى ماذا

عنوان نموذج سوف استلام إلى ثابت نظام إشارة أمر، اشتراط بـ إدخال لغة إرجاع واحد بسيط نظيف كما بلا تركيب زينة عنوان؛ هذا إشارة أمر يتضمن الذي إعداد كلمة عدد و CJK محرف عدد هدف. هو وحيد مستخدم رسالة يتضمن واحد JSON عدد مجموعة، منها هو دقيق اختيار في مستخدم رسالة و ذلك seq.

#### Token أثر

مساعد مساعدة طلب أصل حسب الذي اختيار إدخال كبير صغير و `maxOutputTokens` إزالة استهلاك token. هو و رئيسي agent طلب متبادل متبادل مستقل، لن نحو agent تاريخ زيادة عنوان نص أو غلاف تركيب محتوى.DeepSeek عنوان استدعاء سوف إغلاق تفكير اعتبار؛ رئيسي محادثة إبقاء ذاته إعداد تفكير اعتبار نمط.

#### KV Cache أثر

لن جعل رئيسي طلب KV Cache بطلان. مساعد مساعدة ذاكرة مؤقتة إعادة استخدام من مزود قرار؛ ثابت إشارة أمر يمكن إعادة استخدام، بينما JSON رسالة عدد مجموعة سوف مع كل مرة إصلاح حجز تغير.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد تعريف يتم قبول توليد شكل. هو جمع هو حالي حزمة قيد.

- **فقط نص إخراج**——مساعد مساعدة دالة فقط قبول نص إخراج و رفض استدعاء الأداة؛ لا عام بنية تحويل إخراج مهايئ أو مزود مخصص استخدام نص التوجيه تغيير جسم.
- **كامل جسم نص التوجيه بايت حد أعلى**——هو مقابل كامل غلاف تركيب مستخدم نص التوجيه قوي صنع تنفيذ بايت حد أعلى، بينما لا هو قص قطع مفرد بند رسالة أو تطبيق إبقاء سياسة.
