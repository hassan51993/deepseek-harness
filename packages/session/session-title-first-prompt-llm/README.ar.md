# @deepseek-ai/dsh-session-title-first-prompt-llm

[English](README.md) | العربية

## عام وصف

`dsh-session-title-first-prompt-llm` بصفة اختياري `ctx.sessionTitle` مزود، عبر `ctx.llm` مجموع ربط رقم واحد بند رمز دمج شرط مستخدم رسالة. هو تسجيل `first-prompt` عقدة عزف، فقط في كل جديد غير fork جلسة أول مرة إنشاء رجوع وقت تلقائي تشغيل، و يأخذ نتيجة عودة بسبب في هذا رسالة تأكيد قطع seq. تلقائي فشل سوف إبقاء رجوع، بعد فقط قدرة عبر `ctx.sessionTitle.refresh()` إعادة محاولة. هو استخدام `dsh-session-title-llm` كامل لا بد ملء مشترك LLM إعداد، لذلك توجيه، نص التوجيه، ميزانية و إلغاء سلوك لن عائم نقل. تلقائي سلوك و إعداد أولوية؛ تنفيذ فقط في مشترك سياسة لـ فوق إجراء خفيف كمية تسجيل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند جلسة ينبغي من رقم واحد بند رمز دمج شرط مستخدم رسالة توليد عنوان وقت، في عنوان خدمة جانب تركيب هذا إضافة. هو اشتراط كامل[مشترك LLM إعداد](../session-title-llm/README.ar.md#configuration) ، كما بلا قيمة افتراضية.

### عنوان توليد وقت آلة

تلقائي توليد فقط مقابل بلا أب جلسة، أيضا بلا أولا قبل عنوان كل جديد جلسة تشغيل: في ذلك رقم واحد بند رمز دمج شرط مستخدم رسالة بعد، إنشاء رجوع تزامن خروج مرة مساعد مساعدة طلب قدوم مجموع ربط هذا رسالة. لاحق نص التوجيه، صريح مستخدم إعادة تسمية و وراثة fork تاريخ كل لن إطلاق مجددا مرة تلقائي استدعاء. تلقائي فشل سوف إبقاء رجوع؛`ctx.sessionTitle.refresh()` هو صريح إعادة محاولة.fork سوف إبقاء وراثة عنوان، أبدا سوف تلقائي تشغيل هذا مزود، أي جعل ذلك مسبق وضع أول رسالة قدوم ذاتي أب جلسة.

### إعداد

إضافة قبول كامل لا بد ملء[مشترك LLM إعداد](../session-title-llm/README.ar.md#configuration):`targetWords`،`targetCjkCharacters`،`maxInputBytes`،`maxOutputTokens`،`timeoutMs`، و اختياري صار مقابل `provider`/`model` توجيه. معا حذف اثنان من، سوف وراثة حالي قد سجل رئيسي طلب تأكيد قطع توجيه؛ معا ضبط اثنان من، فإن يجعل عنوان توليد استخدام مستقل توجيه. توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-session-title-first-prompt-llm) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### فشل و استعادة

فشل توليد——رئيسي طلب قبل نقص قليل توجيه، إدخال تجاوز مرور `maxInputBytes`، مهلة، إلغاء أو بلا فاعلية نموذج إخراج——سوف إرسال خروج تحذير إبلاغ و إبقاء حالي عنوان؛ فقط لديه صريح `refresh()` سوف إعادة محاولة. تلقائي عمل لن لـ رئيسي agent(ذكي جسم) طلب زيادة token أو تأخير متأخر.

<a id="model-experience"></a>
## تجربة النموذج

### أول رسالة عنوان طلب

#### نموذج يرى ماذا

عنوان نموذج سوف استلام إلى مشترك عنوان إشارة أمر، و واحد فقط يتضمن رقم واحد بند رمز دمج شرط مستخدم رسالة JSON عدد مجموعة. لاحق نص التوجيه و وراثة fork تاريخ لن إطلاق مجددا مرة تلقائي استدعاء.

#### Token أثر

كل جديد جلسة الأكثر كثير تلقائي إرسال خروج مرة مساعد مساعدة طلب، و تلقي `maxInputBytes` و `maxOutputTokens` قيد؛ صريح تحديث جديد ممكن إرسال خروج مقدار خارج استدعاء. رئيسي agent طلب لن زيادة token.

#### KV Cache أثر

لن جعل رئيسي طلب KV Cache بطلان. مساعد مساعدة طلب استخدام قد إعداد أو قد سجل توجيه، ذلك ذاكرة مؤقتة سلوك من مزود قرار.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لم يعد بديل جدول جلسة. هو جمع هو حالي حزمة قيد.

- **أول رسالة ممكن مرور وقت**——مقابل في طويل مدة جلسة، رقم واحد بند رسالة ممكن لم يعد أداة لديه بديل جدول صفة؛ إذا لاحق نص التوجيه ينبغي إطلاق إعادة توليد عنوان، طلب استخدام كل رسالة مزود.
- **fork أبدا تلقائي إعادة توليد عنوان**——fork سوف إبقاء وراثة عنوان، أبدا سوف تلقائي تشغيل هذا مزود، أي جعل ذلك مسبق وضع أول رسالة قدوم ذاتي أب جلسة.
