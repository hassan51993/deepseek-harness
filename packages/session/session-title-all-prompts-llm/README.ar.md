# @deepseek-ai/dsh-session-title-all-prompts-llm

[English](README.md) | العربية

## عام وصف

`dsh-session-title-all-prompts-llm` بصفة اختياري `ctx.sessionTitle` مزود، عبر `ctx.llm` مجموع ربط كل رمز دمج شرط مستخدم رسالة. هو تسجيل `all-prompts` عقدة عزف، و في كل بند جديد مستخدم نص التوجيه بعد بدء جديد إصلاح حجز، استخدام مسبق وضع تاريخ و فرعي جلسة نص التوجيه. مقارنة جديد إصلاح حجز سوف في توقف و يحل محل قديم عمل، أي جعل مزود تجاهل اختصار إلغاء، أيضا لا يمكن إيداع قديم قديم إخراج. هو استخدام `dsh-session-title-llm` كامل لا بد ملء مشترك LLM إعداد، لذلك توجيه، نص التوجيه، ميزانية و إلغاء سلوك لن عائم نقل. هذا نص أولوية وسيط تعريف تلقائي سلوك و إعداد؛ تنفيذ فقط هو أساس في مشترك سياسة إجراء خفيف كمية تسجيل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند جلسة ينبغي مع ذلك زيادة طويل بينما إعادة توليد عنوان، جعل عنوان حمل متابعة بديل جدول كامل محادثة وقت، في عنوان خدمة جانب تركيب هذا إضافة. هو اشتراط كامل[مشترك LLM إعداد](../session-title-llm/README.ar.md#configuration) ، كما بلا قيمة افتراضية.

### عنوان توليد وقت آلة

كل بند جديد رمز دمج شرط مستخدم نص التوجيه بعد كل سوف بدء جديد إصلاح حجز، يشمل فرعي جلسة في نص التوجيه؛ توليد سوف طي قطع حتى حالي إصلاح حجز كل رمز دمج شرط رسالة، مسبق وضع تاريخ أيضا يتضمن في داخل. مقارنة جديد إصلاح حجز سوف في توقف و يحل محل قديم عمل، لذلك قديم قديم إتمام نتيجة دائم بعيد لا يمكن إيداع. تلقائي فشل——يشمل إدخال تجاوز مرور `maxInputBytes`(هذا وقت طلب فشل بينما غير مقتطع تاريخ)——سوف إرسال خروج تحذير إبلاغ و إبقاء أولا قبل عنوان؛`ctx.sessionTitle.refresh()` هو صريح إعادة محاولة.

### إعداد

إضافة قبول كامل لا بد ملء[مشترك LLM إعداد](../session-title-llm/README.ar.md#configuration):`targetWords`،`targetCjkCharacters`،`maxInputBytes`،`maxOutputTokens`،`timeoutMs`، و اختياري صار مقابل `provider`/`model` توجيه. معا حذف اثنان من، سوف وراثة كل حالي قد سجل رئيسي طلب تأكيد قطع توجيه؛ معا ضبط اثنان من، فإن يجعل عنوان توليد استخدام مستقل توجيه. توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-session-title-all-prompts-llm) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### فشل و استعادة

إذا نهائي غلاف تركيب تجمع دمج نص التوجيه تجاوز مرور `maxInputBytes`، طلب سوف فشل بينما لا هو مقتطع تاريخ؛ تلقائي استخدام وقت سوف إرسال خروج تحذير إبلاغ و إبقاء أولا قبل عنوان، فقط لديه صريح `refresh()` سوف إعادة محاولة. تلقائي عمل لن لـ رئيسي agent طلب زيادة token أو تأخير متأخر.

## بحث إضافي

عند مزود اتفاق لا كاف استخدام وقت قراءة قراءة التالي صفحة. هو جمع من مشترك سياسة تدريجي خطوة دخول بديل عقدة عزف و هو الذي إدراج دخول خدمة.

- [مشترك LLM عنوان سياسة](../session-title-llm/README.ar.md)——هذا مزود استخدام توليد مساعد مساعدة وحدة.
- [أول رسالة عنوان مزود](../session-title-first-prompt-llm/README.ar.md)——فقط أصل حسب أول بند نص التوجيه لـ جلسة توليد مرة عنوان عقدة عزف.
- [جلسة عنوان خدمة](../session-title/README.ar.md)——رجوع سلوك، إعادة تسمية، تحديث جديد و مزود تسجيل.
- [جلسة حزمة خريطة](../README.ar.md)——متبادل مجاور حفظ دائم، إسقاط، عنوان و بعيد قياس حزمة.

<a id="model-experience"></a>
## تجربة النموذج

### كل رسالة عنوان طلب

#### نموذج يرى ماذا

عنوان نموذج سوف استلام إلى مشترك عنوان إشارة أمر، و واحد JSON عدد مجموعة، منها حسب سجل ترتيب يتضمن قطع حتى حالي إصلاح حجز كل رمز دمج شرط مستخدم رسالة و تأكيد قطع seq. مسبق وضع تاريخ أيضا يتضمن في داخل.

#### Token أثر

كل بند رمز دمج شرط جديد نص التوجيه بعد كل ممكن إرسال خروج مرة مساعد مساعدة طلب، كل مرة طلب تلقي `maxInputBytes` و `maxOutputTokens` قيد؛ صريح تحديث جديد ممكن زيادة استدعاء. رئيسي agent(ذكي جسم) طلب لن زيادة token.

#### KV Cache أثر

لن جعل رئيسي طلب KV Cache بطلان. كل بند نص التوجيه بعد، مساعد مساعدة إدخال كل سوف زيادة طويل أو تغير، لذلك مزود مخصص استخدام ذاكرة مؤقتة إعادة استخدام سوف في رقم واحد تغير JSON token موضع انتهاء.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح مزود مثل أي مقابل انتظار طويل جلسة و مختلف بنية جلسة. هو جمع هو حالي حزمة قيد.

- **لا يوجد أساس في ملخص متابعة توليد ملخص آلية**——إدخال فيض خروج وقت إبقاء أولا قبل عنوان؛ مقابل في جدا طويل جلسة، هذا مزود لا يوجد أساس في ملخص متابعة توليد ملخص آلية أو إبقاء سياسة.
- **رسالة يتم مستو انتظار مقابل انتظار**——هو مستو انتظار مقابل انتظار كل رمز دمج شرط مستخدم رسالة، لا توفير حق إعادة، مرور ترشيح أو يد حركة عنوان أولوية درجة.
