# @deepseek-ai/dsh-session-stats

[English](README.md) | العربية

## عام وصف

هذه الحزمة عبر عام `sessionStats` قيمة، لـ عميل توفير كل جلسة جولة و خطوة حساب عدد، و LLM، أداة، أول token و حل رمز جدار ساعة وقت. هذه عدد حرف قدوم ذاتي كامل حمل دائم سجل، لذلك قسم صفحة و ضغط لن تغيير هو جمع. عند عميل يجب في إعادة تحميل أو تقليص نقص تاريخ سجل بعد عرض متسق جلسة موحد حساب وقت، طلب استخدام هذه الحزمة. كل جلسة موحد حساب غير ممكن استخدام وقت، عميل يمكن تعديل استخدام نافذة فتحة مسار حساب عدد.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند عميل حاجة عرض لا تلقي قسم صفحة و ضغط أثر كل جلسة عدد حرف وقت، في جلسة تخزين و إسقاط سجل التسجيل جانب تركيب هذا إضافة. فقط لديه وجود سجل التسجيل وقت وحدة عندئذ سوف تسجيل.

### تركيب

```yaml
- name: '@deepseek-ai/dsh-session'
- name: '@deepseek-ai/dsh-session-projection'
- name: '@deepseek-ai/dsh-session-stats'
```

### كل حقل يحتوي معنى

| حقل | يحتوي معنى |
|---|---|
| `turns` | يحتوي حتى قليل واحد قد إغلاق خطوة مختلف جولة؛ يتم رفض أو فارغ جولة لا حساب |
| `steps` | قد إغلاق خطوة——إتمام، فشل، إلغاء و max-tokens خطوة الكل حساب دخول |
| `llmMs` | تجميع خروج رسالة خطوة نموذج جدار ساعة وقت لـ و |
| `toolMs` | مطابقة `tool/call` → `tool/result` جدار ساعة وقت لـ و |
| `ttftMs` / `ttftSteps` | أول token تأخير متأخر لـ و و ذلك تحمل تحميل خطوة عدد |
| `decodeMs` / `decodeTokens` | فوق تقرير استخدام كمية خطوة حل رمز جدار ساعة وقت و مزود إخراج token لـ و |

كل حقل في أول عدد مساهمة حدث قبل متساو لـ 0؛ قد تركيب إعداد سجل التسجيل ثابت توفير هذا مفتاح، لذلك عميل قراءة قيمة ذاته، بينما غير مفتاح وجود. عميل عبر إسقاط seam لقطة و تغيير تدفق تصيير كل سجل عدد حرف؛ مشاركة اعتبار إزالة استهلاك من هو Web حديث يوم موحد حساب بند، ذلك نافذة طي بـ نفسه حقل اسم ملء عند بلا وحدة وقت رجوع.

### فشل و استعادة

لا يوجد إسقاط سجل التسجيل وقت وحدة هو كسول صفة:`inject` جعل fiber إبقاء تعليق بدء، لا تسجيل أي محتوى، لذلك أخرى تركيب إعداد نقص قليل `sessionStats` مفتاح. إزالة إضافة سوف إزالة هذا مفتاح، لأن تسجيل هو تركيب fiber فوق effect. يتم انهيار انهيار ضرب قطع خطوة في جلسة إعادة تحميل بعد حساب دخول، دورة وقت انهيار انهيار استعادة تكملة كتابة دمج صار `step/end`.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير عدد حرف خلف بعد طي؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا وحدة هو مقابل قد إيداع جلسة حدث صاف طي:`step/end` هو يتم حساب عدد خطوة حدث، لأن agent loop مقابل كل دخول خطوة في `finally` في تماما جيد إلحاق واحد بند، لذلك إتمام، فشل، إلغاء و max-tokens خطوة كل سوف سقوط أرض واحد بند. إذا تعديل حسب قد تجميع assistant رسالة حساب عدد، فإن سوف كثير حساب max-tokens usage مضيف رسالة (فارغ محتوى، يتم ترتيب حذف في surface خارج) ، و قليل حساب يتم إلغاء خطوة (في رسالة تجميع قبل قد في توقف). جدار ساعة طي تدريجي حقل مقابل متساو عميل نافذة طي.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`inject`، في تركيب fiber فوق تسجيل وحدة |
| [`src/projection.ts`](src/projection.ts) | طي: حالة شكل حالة، تدريجي حدث تحويل،wire عرض |
| [`src/types.ts`](src/types.ts) | `sessionStats` إسقاط مفتاح إعلان و حقل نوع وحيد ملكية |

### بيانات نموذج

طي حالة حفظ ثمانية عدد مجموع حساب خارج إضافة إجراء في حد:`lastTurn`(الأكثر قريب مرة يتم حساب عدد `step/end` جولة) ،`openStep`(فتح خطوة حد واقع، من ذلك `assistant/message` إغلاق) و `pendingCalls`(حسب callId سجل أداة توزيع وقت).wire عرض هو صارم إطار فرعي تجميع——ثمانية عدد مجموع حساب——لذلك حمل دائم ذاكرة مؤقتة حالة schema بـ حد حقل توسيع عرض schema.

### طي قاعدة

- لا متبادل صلة حدث إرجاع نفس حالة مرجع؛ سجل التسجيل `Object.is` بوابة إبقاء تغيير تدفق أمان ساكن.
- أول token تأخير متأخر سجل أول عدد غير فارغ delta chunk، و في خطوة داخل `llm/retry` بعد إبقاء.
- حل رمز وقت و token فقط في معا يحمل أول token و صالح مزود استخدام كمية تقرير إبلاغ خطوة فوق تراكم إضافة؛ و نافذة طي حراسة حماية عقدة استخدام كمية واحد مثال تجاهل اختصار شاذ شكل استخدام كمية.
- أداة وقت حسب callId إعداد مقابل `tool/call` → `tool/result`؛ لم حل قرار استدعاء في `turn/end` وقت إسقاط، لأن نتيجة مجموع في ذلك جولة داخل سقوط أرض، بينما اصطدام فوق `Object` أصل نوع اسم callId قراءة عمل لم مطابقة.

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح عدد حرف وصف ماذا، وحدة أي وقت ناقص. هو جمع هو حالي حزمة قيد.

- **خطوة عدد موحد حساب هو قد حدوث عمل، بينما غير مرئي إخراج**——في إنتاج أي مرئي محتوى قبل حينئذ فشل خطوة ما زال بـ `step/end` إغلاق و حساب دخول؛ يتم انهيار انهيار ضرب قطع خطوة في جلسة إعادة تحميل بعد حساب دخول، دورة وقت انهيار انهيار استعادة تكملة كتابة دمج صار `step/end`.
- **يتم إلغاء خطوة حساب عدد لكن لا حساب وقت**——لا يوجد تجميع خروج assistant رسالة، ذلك جزء تدفق صيغة وقت لا دخول أي جدار ساعة عدد حرف؛ عكس لـ max-tokens usage مضيف رسالة مساهمة surface فوق نظر لا إلى نموذج وقت.
- **حساب عدد هو سجل فتحة مسار، لا هو surface فتحة مسار**——رسالة بعد قدوم يتم ضغط إسقاط خطوة ما زال حساب دخول؛ عدد حرف وصف كامل جلسة، بينما غير حالي نموذج مرئي surface.
- **فقط في تركيب إسقاط سجل التسجيل وقت تركيب**——أخرى تركيب إعداد لا توفير `sessionStats` مفتاح، ذلك إزالة استهلاك من رجوع إلى نافذة فتحة مسار حساب عدد.
