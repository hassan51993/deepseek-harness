# @deepseek-ai/dsh-session-telemetry

[English](README.md) | العربية

## عام وصف

جلسة بعيد قياس يجعل نشر جهة إرسال جلسة نشط حركة لديه ترتيب فرعي هذا لأجل فوق تقرير، معا إبقاء مرجعي جلسة سجل. نشر جهة اختيار واحد فوق تقرير خلفية، و يمكن في إلقاء تمرير قبل انفصال حساس كل خارج إرسال فرعي هذا؛ إذا لا يوجد انفصال حساس قاعدة، التقاط بيانات سوف أصل مثال مغادرة فتح عملية. تسليم وصل بـ غير منع سد طريقة إتمام، لذلك فوق تقرير لن تأخير متأخر جلسة معالجة. إلقاء تمرير اعتماد كل قوة بينما لـ طريقة؛ إذا عملية انهيار انهيار، طابور صف في سجل ممكن فقد فقد.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

بصفة نشر جهة، اختيار واحد خلفية و تركيب هو، عند سجل لا يستطيع بـ التقاط أصل مثال مغادرة فتح عملية وقت إضافة انفصال حساس قاعدة. بصفة خلفية عمل من، تنفيذ ثلاثة عضو اتفاق، و بـ واحد نوع التقاط نمط تجميع تنسيق ضبط جهاز.

### اختيار و تركيب خلفية

فقط تحميل واحد خلفية إضافة؛ هو يأخذ التقاط تنسيق ضبط جهاز و إلقاء تمرير خط الإنتاج تسجيل لـ `ctx.sessionTelemetry`. تكرار تحميل سوف رمي خروج استثناء. مطلوب [`sharing` عضو](#the-sharing-disclosure) تقرير إبلاغ نشر نمط، لا بديل جدول جلسة دقيق دخول أو إلقاء تمرير. فقط لديه في لم تركيب أي بعيد قياس خدمة وقت، مستهلك عندئذ يمكن تقرير إبلاغ «لم إعداد».`/feedback` أمر تأكيد سجل، لا قراءة هذا سياسة.

### خلفية اتفاق

خلفية تنفيذ ثلاثة عدد عضو:`emit(record)` يجب هو غير منع سد دخول طابور، لأن هو سوف في جلسة حدث مسار فوق تزامن تنفيذ؛ اختياري `flush()` هو جولة انتهاء بعد أي إرسال أي نسيان تلميح، كثير عدد خلفية لـ التزام دوران SDK ذاته دفعة معالجة حساب تخطيط بينما حذف هو؛`shutdown()` ترتيب فارغ قد دخول طابور سجل، و في SDK إيقاف بعد انتهاء،dispose(مورد تحرير) سوف انتظار هو. تنفيذ `flush()` خلفية يجب أمان ترتيب تزامن flush و نهائي `shutdown()` ترتيب فارغ أولا بعد ترتيب.

### التقاط محتوى

التقاط بـ اثنان نوع نمط لـ واحد تشغيل.`live` التقاط في إلحاق وقت تتبع مع جلسة حدث، في تركيب وقت إعادة تشغيل قد تخزين نشط جلسة و سجل دورة الحياة علامة؛`on-demand` التقاط فقط في خلفية عبر `captureSession(session, throughSeq?)` طلب بادئة وقت قراءة مرجعي جلسة سجل. تنسيق ضبط جهاز خيار قرار هل يتضمن تخزين تاريخ. كل بند مرجعي جلسة حدث كل حسب ترتيب خريطة لـ واحد بند ledger سجل.`assistant/message` أو `assistant/attempt` سجل سوف يحمل كامل تضمين دخول صيغة ضيق تجميع تدفق، يشمل فشل و إعادة محاولة إخراج. كل بند ledger سجل أيضا يحمل `session.id`،`session.format_version`، عدد قيمة نوع حدث معرف، اختياري header واقع و مسبق أولا خريطة صارم إعادة درجة آخر (`tool/result.isError`،`turn/end` خطأ سبب و `agent-error` خريطة لـ `error`؛ ذلك بقية لـ `info`).

### مشترك كشف كشف

<a id="the-sharing-disclosure"></a>

كل خلفية عبر `sharing` كشف كشف نشر نمط:`full`،`feedback-only` أو `disabled`. خلفية أيضا يمكن حد رمز دمج شرط جلسة. هذا خاصية لا هو إلقاء تمرير عودة تنفيذ؛ تسليم وصل هو غير منع سد دخول طابور، دفعة معالجة، إعادة محاولة و فقد فقد سياسة يخص خلفية SDK.

### انفصال حساس سجل

<a id="the-redact-waterfall"></a>

تنسيق ضبط جهاز نسخ مرجعي حدث بعد، كل بند خارج إرسال سجل كل سوف قيام أي مرور مرور `sessionTelemetry/record` waterfall(شلال نشر صيغة حدث). هذه الحزمة لا حمل أي قاعدة: لم تركيب مستمع وقت، سجل بـ التقاط وقت أصل مثال وصول خلفية، لذلك توجيه خروج بيانات قدرة جاف صاف إلى ماذا مسار درجة، تماما تماما أخذ قرار في نشر جهة تركيب ماذا قاعدة. مستمع عبر تغيير تبديل `next()` قيمة راجعة قدوم كومة تراكم؛ رمي خروج استثناء مستمع بـ fail-closed طريقة اعتراض تحت هذا واحد بند سجل. انفصال حساس فقط أثر في خارج إرسال فرعي هذا——مرجعي جلسة سجل دائم لا تعديل كتابة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير التقاط تصميم؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

seam بناء قيام في واحد حد لـ فوق:harness مسؤولية توقف في `emit()`. كامل حدث التقاط، انفصال حساس و handoff تنقل علامة كل في هذا داخل؛ دفعة معالجة، إعادة محاولة، ترتيب طابور و فقد فقد سياسة يخص فوق تقرير SDK، هذه الحزمة متعمد لا بناء نموذج أيضا لا حزمة تركيب. تصميم و يتم مرفوض بديل خطة رؤية[تكرار نشط Agent Note](../../../.agents/notes/implemented/feature/2026-07-23-session-telemetry-otel-revival.zh.md).

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | Service Definition:`SessionTelemetryBackend`/`SessionTelemetrySink` اتفاق، سجل مفردات،`session-telemetry/record` waterfall إعلان |
| [`src/coordinator.ts`](src/coordinator.ts) | التقاط:live مستمع، دورة الحياة محلي on-demand إعادة تشغيل، انفصال حساس،handoff تنقل علامة، استثناء عزل |

### التقاط مسار

فوري التقاط عبر تركيب fiber effect تسجيل Session حدث، تحديث جديد تلميح، إغلاق علامة و agent/error مراقبة جهاز. حسب يحتاج التقاط فقط تسجيل تحرير effect، و حسب تاريخ سياسة قراءة طلب مرجعي سجل بادئة. تزامن معالج عزل فشل، تجنب تجنب أثر agent loop(ذكي جسم حلقة) أو أخرى مستمع.

### handoff تنقل علامة

وحدة أثر مجال `WeakMap<Session, seq>` سجل قد تسليم وصل بينما غير قد إلقاء تمرير الأكثر عال ترتيب رقم. إعادة استلام رعاية نفس كائن وقت من هذا تنقل علامة بعد متابعة. التقاط عبر معتاد من `firstLiveSeq` بدء؛ صريح `includeHistory: true` من لم تسليم وصل كائن seq 0 بدء، يتضمن استعادة أو fork تاريخ. خلفية مسؤول التقاط تخويل. تخزين تاريخ ذاته لا تخويل التقاط؛OTel خلفية انتظار جديد صريح عكس تغذية. استقبال جهة حسب `(session.id, session.format_version, event.seq)` مقابل تكرار سجل ذهاب إعادة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد تعريف نشر جهة قدرة نيل إلى إلقاء تمرير و بيانات حفظ حماية حفظ إثبات. هو جمع هو حالي حزمة قيد.

- **كل قوة بينما لـ إلقاء تمرير**——تنقل علامة علامة هو قد تسليم وصل بينما غير قد إلقاء تمرير؛ في إعادة تحميل نافذة داخل يتم تفكيك حذف جلسة لا يمكن إعادة استلام رعاية، انهيار انهيار وقت إبقاء في خلفية طابور صف في محتوى سوف فقد فقد. حفظ دائم outbox(spool، كل sink تنقل علامة،at-least-once) دفع متأخر إلى لديه نشر جهة رفع خروج واضح انهيار انهيار فقد فقد اشتراط وقت مجددا تنفيذ.
- **لا داخل وضع انفصال حساس قاعدة**——لم تركيب `sessionTelemetry/record` مستمع وقت، سجل بـ التقاط وقت أصل مثال مغادرة فتح عملية، يشمل ملف محتوى أو أمر إخراج في داخل تضمين أي اعتماد؛ نحو مشترك collector توجيه خروج نشر جهة ذاتي سطر مسؤول ذلك قاعدة تجميع.
- **حسب يحتاج انفصال حساس استخدام حالي حالة**——لم التقاط حدث فقط وجود في مرجعي جلسة سجل في؛ لاحق `captureSession()` سوف استخدام عند وقت تركيب سياسة، عميق نسخ صدفة و انفصال حساس ذلك حالي قيمة، كما لا وجود التقاط وقت بعيد قياس لقطة أو حفظ دائم التقاط قبل spool.
