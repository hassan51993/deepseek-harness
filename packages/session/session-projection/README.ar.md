# @deepseek-ai/dsh-session-projection

[English](README.md) | العربية

## عام وصف

عند عميل حاجة حالي تدريجي جلسة حالة (مثال مثل انتظار إنجاز أمر بند، هدف أو محادثة موحد حساب) بينما لا ينبغي ذاتي سطر إعادة وضع أصلي حدث سجل وقت، استخدام `dsh-session-projection`. مجال أصل حسب قد إيداع جلسة حدث تعريف تزامن إسقاط، عميل فإن عبر لقطة و تغيير إشعار استقبال مرور مرور schema تحقق كامل JSON قيمة. لقطة علامة واضح كل قيمة راجعة مشترك نفس عكس عكس إلى الأكثر بعد واحد حدث، لذلك تحميل جسم يمكن يأخذ حالة و مقابل تاريخ قطع وجه إعداد مقابل. إسقاط حالة يمكن عبر فحص نقطة إضافة سريع بارد قراءة، بينما فقط توفير host استخدام إسقاط لن كشف إعطاء عميل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في عميل تحميل جسم حاجة سجل إرسال توليد جلسة حالة حالي قيمة موضع تركيب `dsh-session-projection`. مجال إضافة تسجيل وحدة؛ تحميل جسم قراءة لقطة و حجز قراءة تغيير تدفق؛ اثنان جانب متبادل لا متبادل تعرف.

### أي وقت اختيار

عند مجال حفظ عميل ينبغي يرى، لكن لا ينبغي ذاتي سطر إعادة إرسال توليد حالة——todo بيان،goal لقطة، محادثة موحد حساب——وقت اختيار هذه الحزمة. سجل التسجيل في قد إيداع حدث فوق رئيسي حركة قيادة وحدة، لذلك أي قد تسجيل وحدة قيمة حسب بنية صنع أي لـ حالي قيمة. عند صيانة هو بلا عميل قراءة host-only تسجيل حساب وقت قفز مرور: لا حمل `wire` كتلة وحدة إبقاء host-only.host قراءة جهة يلزم ما في إضافة `inject` في إعلان `sessionProjections`، يلزم ما في سجل التسجيل أو مطلوب key نقص مقعد وقت واضح فشل. مساهمة جهة يمكن متابعة عبر `ctx.inject(['sessionProjections'], ...)` إبقاء اختياري تسجيل.

### تعريف إسقاط وحدة

مجال لـ كل حالة مفتاح مساهمة واحد `ProjectionDefinition`: واحد key، حالة schema، ابتدائي حالة، تزامن طي `apply(state, event)`، اختياري `wire` كتلة (يأخذ حالة إسقاط لـ عميل عرض) ، و حالة حقل أو طي دلالة تغير وقت تمرير زيادة `stateVersion`:

```text
const definition = {
  key: 'todo',
  stateSchema: todoStateSchema,
  stateVersion: 1,
  init: (_header, _inheritedEventCount) => ({ items: [] }),
  apply: (state, event) => event.type === 'todo/upsert'
    ? { items: event.data.items }
    : state,
  wire: {
    viewSchema: todoViewSchema,
    view: state => ({ items: state.items }),
  },
}
```

`init(header, inheritedEventCount)` معا استقبال خفيف كمية بيانات وصفية و دقيق fork وراثة قطع نقطة؛ هو لا نيل من `firstLiveSeq` أو `session/end-seed` دفع قطع هذا قطع نقطة.`apply` يجب تزامن، كما مقابل و وحدة غير متصل حدث يجب إرجاع نفس عدد حالة مرجع——مرجع ثابت معنى طعم حال صفر تحت تنقل عمل. سجل التسجيل استخدام `Object.is` مقارنة مقارنة متبادل مجاور `wire.view` أصلي نتيجة؛ كائن أو عدد مجموعة view إذا يلزم في فقط داخلي state تغير وقت كبح صنع إصدار، حينئذ يجب إعادة استخدام مرجع، بنية نفسه جديد كائن ما زال حساب تغير. يحمل حالة سجل حدث يجب يحمل تغيير بعد كامل حالة، أبدا يحمل عار زيادة كمية.

### تسجيل و قراءة

`register(definition)` تثبيت وحدة؛ أداة لديه نفسه key و `stateVersion` تسجيل جهة مشترك ذلك cell، إصدار لا توافق أو `stateVersion` غير قاعدة وقت سوف throw. تسجيل هو تعليق في استدعاء جهة fiber فوق effect، لذلك الأكثر بعد واحد تسجيل جهة إزالة بعد سوف إزالة key و ذلك ذاكرة مؤقتة cell. تحميل جسم استخدام `snapshot(session)` مقابل كل عميل مرئي وحدة قراءة متسق تزامن قطع وجه——`{ asOfSeq, values }`، منها `asOfSeq` هو كل قيمة مشترك نفس عكس عكس إلى الأكثر بعد واحد حدث seq——و استخدام `onChanged(listener)` حجز قراءة تدريجي تغيير إشعار.`stateOf(session, key)` قراءة واحد وحدة فوري فقط قراءة host حالة، لا حساب حساب غير متصل عرض.

```text
const dispose = ctx.sessionProjections.register(definition)
const { asOfSeq, values } = ctx.sessionProjections.snapshot(session)
```

يجب استخدام إسقاط حالة مجال يأخذ `sessionProjections` إعلان لـ Cordis خدمة اعتماد؛ اختياري مساهمة جهة يمكن في `ctx.inject(['sessionProjections'], …)` تحت تسجيل. تحميل جسم استخدام `ctx.get('sessionProjections')`، سجل التسجيل نقص مقعد وقت حذف ذاتي ذات كتلة أو لقطة.

### حمل دائم فحص نقطة

نظام عبر `checkpoint(session)` لـ كل وحدة حالة إنشاء فحص نقطة،client-visible و host-only واحد نظر نفس لب؛ نفس درجة حزمة [session-projection-cache](../session-projection-cache/README.ar.md) حفظ دائم هذه فحص نقطة، جعل بارد قراءة قفز مرور كل كمية سجل تحميل. فحص نقطة ماء موضع استخدام `SessionSeqCursor`(فارغ سجل لـ `-1`) ، إعادة تشغيل بدء نقطة استخدام `SessionLogOffset`؛`restoreFloor` و `restore` تنفيذ قراءة مسار، كما لن خلط خلط قد لديه حدث و سجل بين فجوة.

## فهم التنفيذ

### تصميم إدارة فكرة

هذه الحزمة هو قدرة seam Service Definition و قيادة زاوية لون: إطار هيكل مسؤول قيادة، مجال مسؤول حساب حساب. سجل التسجيل فقط حجز قراءة مرة `session/event`؛ كل قد إيداع حدث كل سوف رئيسي حركة مرور مرور كل قد تسجيل وحدة `apply`(cell في أول مرة لمس بلوغ وقت كسول صفة بناء). رقم واحد طبقة `Object.is` بوابة باب في state مرجع ثابت وقت قفز مرور view عمل؛live drive مزدوج مجرى ذاكرة مؤقتة إعادة استخدام قبل واحد أصلي view، ثاني طبقة `Object.is` بوابة باب في أصلي view مرجع ثابت وقت كبح صنع إصدار. تحميل جسم في قطع خروج صفحة قطع قطعة نفس tick داخل قراءة `snapshot()`،`asOfSeq` لـ الذي بـ هو واحد متسق قطع وجه صحيح نظام في هذا؛ خطأ كتابة صار مختلف خطوة view سوف إرجاع Promise، و يتم `wire.viewSchema.parse` رفض.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |

| [`src/types.ts`](src/types.ts) | يمكن دمج توسيع `SessionProjectionMap` و `SessionProjectionStateMap` نوع جدول |

### قيادة و فحص نقطة مسار

واحد قد إيداع حدث حسب تسجيل ترتيب قيادة كل قد تسجيل وحدة؛ أصلي view عبر `Object.is` حكم تحديد لـ تغير عميل مرئي وحدة سوف بـ مرور schema تحقق عرض و يؤدي بسبب seq إشعار تغيير تدفق.live drive إبقاء قبل بعد اثنان عدد أصلي view؛snapshot و بارد قراءة ما زال هو ذاك هذا مستقل كامل قراءة.`checkpoint(session)` لـ حمل دائم ذاكرة مؤقتة إرجاع كل وحدة واحد نسخة مستقل `(key → {ver, seq, val})` سطر؛`restoreFloor` يأخذ ذيل جزء قراءة مرساة تحديد في الأكثر منخفض متاح ماء موضع قبل واحد حدث موضع، جعل تقليص قصير سجل يمكن يتم فحص خروج؛`restore` يأخذ حمل دائم سطر في تخزين بعد لاحقة فوق إعادة طي، إسقاط أي `ver` لا مطابقة أو صوت تسمية تجاوز مرور تخزين نهاية ذيل سطر.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح إسقاط سجل التسجيل في كبير قاعدة نموذج تحت أي وقت حاجة خاص آخر معالجة. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **كل ذيل صفحة يحمل كل client-visible key**——بعد بلا تدريجي key opt-out أو كسول صفة key طلب شكل حالة؛ في قيمة كل هو UI كمية درجة كل كمية حالة وقت يمكن قبول، إذا بعض مجال قيمة تغيير كبير مجددا إعادة اقتراح.
- **وحدة جدول هو عملية درجة، لذلك key هل وجود لا يستطيع عند عمل تدريجي جلسة قدرة إشارة**——أي agent preset تسجيل key كل سوف ظهور في كل جلسة لقطة داخل؛ عميل يجب قراءة قيمة، لا يستطيع يأخذ key نقص مقعد عند عمل وظيفة نقص مقعد.
- **رئيسي حركة قيادة تدريجي حدث لمس بلوغ كل وحدة**——حسب بنية صنع فتح إلغاء جدا منخفض (كل كمية قيمة قاعدة و state/view مرجع بوابة باب) ، لكن إذا ظهور حار نقطة مسار، يمكن إضافة حسب وحدة حدث نوع مسبق مرور ترشيح.
- **سجل التسجيل cell فقط نشط في داخل تخزين داخل**——إعادة بدء بعد أول مرة لمس بلوغ وقت اعتماد طي سجل إعادة بناء؛ تركيب `dsh-session-projection-cache` تركيب تعديل من حمل دائم سطر بث نوع هذا طي.
- **وحدة تزامن سجل قاعدة فقط لديه جزء يمكن آلة آلة يأخذ صلة**——`wire.viewSchema.parse` قدرة رفض إرجاع Promise view، لكن منع سد `apply`، أو قراءة تمزيق شق غير جلسة حالة `apply`، فقط قدرة اعتماد مراجعة يأخذ صلة.
