# @deepseek-ai/dsh-session-telemetry-otel

[English](README.md) | العربية

## عام وصف

`dsh-session-telemetry-otel` فقط في جديد صريح عكس تغذية بعد عبر OTel JS SDK توجيه خروج جلسة سجل، ملائم لأجل كل مستخدم و مزود، يشمل `deepseek-official`.`FEEDBACK_ONLY` تحرير قطع حتى هذا عكس تغذية مرجعي سجل بادئة، يتضمن سياق؛ لاحق سجل انتظار تحت مرة صريح عكس تغذية.`DISABLED` لا بنية صنع نقل.SDK دفعة معالجة يمكن إتمام قد تخويل فوق نقل، بلا حاجة آخر مرة مستخدم تفاعل أو نموذج استدعاء. نشر جهة مسؤول انفصال حساس قاعدة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند نشر جهة حاجة عبر OpenTelemetry سجل توجيه خروج جلسة سجل وقت تركيب هذا إضافة. اختيار واحد نمط، إعطاء توجيه خروج جهاز واحد طرف نقطة، و قرار هل في seam فوق تركيب انفصال حساس قاعدة.

### نمط

| `mode` | سلوك |
|---|---|
| `FEEDBACK_ONLY` | قيمة افتراضية. نص عكس تغذية، تقييم قسم إنشاء أو تعديل، ملاحظة تعديل و سحب عودة تحرير بعد لم تسليم وصل بادئة، قطع توقف هذا مرجعي عكس تغذية حدث؛ لاحق سجل انتظار |
| `DISABLED` | لا بنية صنع تنسيق ضبط جهاز، مزود، معالج أو توجيه خروج جهاز؛ لا يوجد بعيد قياس سجل مغادرة فتح عملية. نشط وثب جلسة عكس تغذية في محلي إبلاغ تحذير؛ بارد جلسة تعديل إبقاء ساكن صامت |

برنامج تحويل TypeScript إعداد استخدام توجيه خروج `SessionTelemetryMode` قطعة رفع؛ أصلي نص حرف وجه كمية غير ممكن منح قيمة.`FULL` سوف يتم رفض، لا هو آخر اسم.[`sharing` خاصية](../session-telemetry/README.zh.md#the-sharing-disclosure) تقرير إبلاغ `feedback-only` أو `disabled`، لا بديل جدول إلقاء تمرير عودة تنفيذ.`/feedback` تأكيد نص فقط تأكيد سجل.

### الأكثر صغير إعداد

فوق نقل نمط حاجة توجيه خروج جهاز URL، و أصل مثال قبول SDK خيار كتلة:

```yaml
- id: sessionTelemetry-otel
  name: '@deepseek-ai/dsh-session-telemetry-otel'
  config:
    mode: FEEDBACK_ONLY       # optional; defaults to FEEDBACK_ONLY
    shutdownTimeoutMillis: 3000 # optional; defaults to 3000
    exporter:                # passed verbatim to the SDK's OTLP/HTTP log exporter
      url: https://collector.example.com/v1/logs
      headers:
        authorization: !!js `Bearer ${process.env.OTLP_TOKEN}`
    processor: {}            # optional; passed verbatim to BatchLogRecordProcessor
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `mode` | `FEEDBACK_ONLY` | مشترك سياسة:`FEEDBACK_ONLY` أو `DISABLED` |
| `exporter.url` | فوق نقل نمط لا بد ملء | كامل OTLP سجل طرف نقطة؛ يجب قدرة تحليل لـ `http(s)` |
| `exporter`،`processor` | — | أصل مثال نقل إعطاء SDK توجيه خروج جهاز و دفعة معالج |
| `shutdownTimeoutMillis` | `3,000` | SDK كامل إغلاق تسلسل خارج طبقة قطع توقف وقت |

مباشر استدعاء `ctx.sessionTelemetry.emit()` في أي نمط تحت كل هو فارغ عملية، لا يستطيع التفاف مرور عكس تغذية تخويل. وراثة أب جلسة عكس تغذية لا تخويل فرعي جلسة توجيه خروج: فرعي جلسة حاجة جديد ذاته عكس تغذية. تخويل بعد بادئة يتضمن وراثة سياق.

نموذج طلب، طلب رأس،Session إنشاء أو وصل قبول، استعادة، و إضافة تركيب أو HMR(حار وحدة استبدال) متساو لا تخويل التقاط. فقط سند قد تخزين عكس تغذية لن إطلاق أي عملية.SDK تحديد وقت تحديث جديد و إغلاق يمكن إتمام أولا قبل قد تخويل دفعة مرة، لكن أبدا التقاط جديد سجل.

### أي بعض بيانات سوف مغادرة فتح هذا آلة

في فوق نقل نمط في، سجل يحمل seam `sessionTelemetry/record` waterfall(شلال نشر صيغة حدث) إرجاع كامل `event.data`——رسالة محتوى، أداة معامل و نتيجة، توجيه النظام و أداة schema،todo نص، ضغط (compaction) ملخص، عكس تغذية نص، و جلسة `cwd`. مزود اعتماد أبدا سوف ظهور: مهايئ API key هو بنية صنع دالة معامل بينما غير جلسة حدث، لذلك هو جمع في بنية فوق حينئذ لا وجود في سجل في، أيضا حينئذ لا وجود في بعيد قياس في.`DISABLED` لا بنية صنع SDK خط الإنتاج، أيضا لا يأخذ أي التقاط محتوى تسليم إعطاء خلفية.

### فشل و إغلاق

إعداد خطأ سوف في إضافة تحميل وقت فشل: نقص قليل أو غير `http(s)` `exporter.url`، غير صحيح كامل عدد `processor.maxExportBatchSize`(SDK سوف قبول هذا قيمة، مع بعد لكن في إغلاق وقت تعليق بدء) و بلا فاعلية `shutdownTimeoutMillis` كل سوف في أي سجل توجيه خروج قبل يتم رفض. إغلاق خلال،OTel سوف أولا انتظار `exporter.forceFlush()`، مجددا انتظار معالج محدود إتمام promise؛ إذا هذا نقل promise بداية نهاية لا تسوية، هذه الحزمة سوف في `shutdownTimeoutMillis` إلى مدة وقت وضع ترك انتظار، سجل قد عزل فشل، و يجعل تطبيق متابعة تفكيك إزالة——دورة وقت ما زال انتظار معالجة سجل ممكن في عملية خروج وقت فقد فقد.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية تركيب طريقة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

خلفية هو مقابل OTel JS SDK رقيق ملائم إعداد طبقة: هو يملك عكس تغذية تخويل، مورد هوية و خارج طبقة إغلاق قطع توقف وقت. مرجعي ledger سجل استخدام `@deepseek-ai/dsh-session-telemetry-otel` إدراج وتد أثر مجال؛ هذا خلفية لا التقاط تشغيل صيانة سجل. مورد هوية يحمل `service.name`/`service.version`(قدوم ذاتي `dsh-llm` `APP_IDENTITY`) و مجهول اسم `user.id`(قدوم ذاتي `$DSH_HOME/.anonymous-user-id`) ، حسب توجيه خروج دفعة مرة يحمل مرة، بينما غير تدريجي بند سجل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: نمط تحليل،fail-closed تحقق،SDK خط الإنتاج وصل خط، تنسيق ضبط جهاز تجميع، إغلاق قطع توقف وقت |

### التقاط وصل خط

خلفية استخدام يتضمن تخزين تاريخ حسب يحتاج التقاط. فقط لديه جديد ذاته `feedback/record`،`feedback/message-put` أو `feedback/message-delete` حدث إطلاق نشط وثب جلسة التقاط، و بـ هذا حدث لـ حد أعلى. بارد جلسة `feedback/committed` إشعار توفير قد إيداع مرجعي لقطة، لا إصدار تخزين نشط Session أو Agent. نفس كائن تسليم وصل تنقل علامة كبح صنع تكرار التقاط. خلفية لا تنفيذ `flush()`؛SDK مسؤول دفعة معالجة و إغلاق ترتيب فارغ.

### حقل خريطة

كل بند بعيد قياس سجل خريطة لـ واحد بند SDK سجل سجل، يحمل التقاط ختم الوقت، صارم إعادة درجة آخر، متن و خاصية. عكس تغذية تخويل هو بعد لم تسليم وصل كامل بادئة، بينما غير فقط لديه عكس تغذية تحميل حمل.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح SDK سلوك في أي موضع بدء رئيسي توجيه أثر، توجيه خروج حفظ إثبات توقف في أي موضع. هو جمع هو حالي حزمة قيد.

- **فوق تنقل فعلي تحقق صفة شفرة المصدر شجرة**——`@opentelemetry/sdk-logs` من فوق تنقل فعلي تحقق صفة شفرة المصدر شجرة إصدار؛SDK API تغيير حركة فقط سوف سقوط في هذه الحزمة، أيضا فقط سقوط في هذه الحزمة، بينما seam اتفاق لا حركة.
- **حقيقي collector سلوك يخص SDK توجيه خروج جهاز**——هوية تحقق،TLS، حد تدفق و أخرى حقيقي OTLP نشر سلوك التزام دوران فوق تنقل SDK، لا من هذه الحزمة ذاتي لديه توافق طبقة معالجة.
- **كل قوة تسليم وصل**——جديد بارد لقطة و إعادة بدء بعد جديد عكس تغذية إيداع ممكن تكرار بادئة؛ استقبال جهة حسب Session id، صيغة إصدار و حدث seq ذهاب إعادة. لا يوجد حفظ دائم outbox، إلقاء تمرير ماء موضع، تلقائي إعادة محاولة تحمل وعد أو أخذ تجميع طرف قبول حفظ إثبات.OTel و يحتاج صريح تفعيل DeepSeek API مسار ممكن إعادة تراكم. سحب عودة توجيه خروج حذف حدث، لا هو بعيد طرف مسح حذف.

- **خلفية متاح صفة**——هذا إضافة منع استخدام أو إزالة خلال إيداع عكس تغذية سوف سجل في محلي، لكن استعادة إضافة لن تلقائي إعادة وضع. التقاط اشتراط حجز قراءة جهة إبقاء تركيب مباشر إلى مراقبة إلى إيداع؛ في بارد كتابة بعد لم إتمام وقت إزالة، ممكن خطأ مرور ذلك flush بعد إشعار.
