# @deepseek-ai/dsh-session-log-deepseek

[English](README.md) | العربية

## عام وصف

لأجل DeepSeek رسمي جهة LLM(كبير لغة نموذج)API طلب زيادة كمية مواصفة جلسة سجل فوق نقل. هذا دالة إضافة حقن `ctx.sessions` و `ctx.deepseekLlmApiExtensions`، و يملك `dsh_session_log` طلب حقل و لأجل إرسال توليد قبول ماء موضع حمل دائم `session-log-deepseek/delivery-accepted` حدث. فقط عند رسمي جهة API لا نيل استقبال جلسة سجل بعد لاحقة وقت عندئذ منع استخدام هو.

<a id="configuration"></a>
## إعداد

| إعداد مفتاح | قيمة افتراضية | يحتوي معنى |
|---|---:|---|
| `enabled` | `true` | تسجيل `dsh_session_log` مساهمة. سوف ذلك ضبط لـ `false` يمكن إيقاف جلسة سجل فوق نقل. |

مع مرفق profile سوف تركيب هذا إضافة، لذلك افتراضي إعداد سوف تسجيل طلب حقل و إلحاق قبول ماء موضع؛overlay متاح `enabled: false` اختيار خروج.

<a id="request-field"></a>
## طلب حقل

مقابل في يحمل تخزين نشط `sessionId` طلب، إضافة سوف طي هذا تأكيد قطع جلسة صيغة بديل الأكثر كبير قد قبول ماء موضع، مقابل `Session.events` أخذ لقطة، تزامن إرسال ماء موضع بعد وصل متابعة بعد لاحقة. عملية داخل fold سوف يجعل كل بند حدث فقط يتم مسح مرة و زيادة كمية إزالة استهلاك لاحق إلحاق؛ إعادة بدء و HMR(حار وحدة استبدال) سوف من حمل دائم سجل إعادة بناء هو. إصدار 1 حقل يتضمن `sessionFormatVersion`، أصلي جلسة header(فقط seeded Session يحمل `seedLength`) ، عدد قيمة نوع `afterSeq` و `throughSeq`، و كل قد تحويل لـ أصلي عدد قيمة envelope حقل كامل مواصفة حدث. فقط لديه سجل جلسة id و صيغة بديل متساو مطابقة طلب مصدر وقت ماء موضع عندئذ توليد فاعلية، لذلك fork جلسة سوف تجاهل اختصار من أب جلسة وراثة ماء موضع. جدول طبقة حدث يجب يحمل `surfaceOp`، استبدال نطاق استخدام عدد قيمة نوع `startSeq` و `endSeq`؛ فقط system،user و tool حدث يمكن يحمل `sourceEventSeqs`.assistant مزود بيانات وصفية إبقاء في داخل تضمين تدفق في، فقط ظهور في سجل في حدث لا يحمل هذا اثنان عدد بيانات وصفية حقل.

<a id="acceptance-and-retry"></a>
## قبول و إعادة محاولة

DeepSeek مهايئ سوف في HTTP 2xx بعد، إزالة استهلاك SSE(Server-Sent Events) متن قبل استدعاء قد دقيق تجهيز مساهمة `accept()`. قبول عملية سوف إلحاق `session-log-deepseek/delivery-accepted`، منها يتضمن قد فوق نقل `throughSeq` و `sessionFormatVersion`؛ حذف صيغة حقل سجل يمثل v0. تحت مرة طلب مجددا يأخذ هذا حدث بصفة جديد بعد لاحقة واحد جزء فوق نقل. نقل فشل و غير 2xx فشل لن إلحاق قبول سجل، لذلك لاحق طلب سوف إعادة إرسال لا تحديد نطاق. تزامن تسليم ممكن فوضى ترتيب نيل إلى قبول؛ طي مطابقة سجل في الأكثر كبير `throughSeq` يمكن منع توقف تنقل علامة رجوع.

خدمة طرف قبول بعد، حفظ دائم ماء موضع قبل حدوث انهيار انهيار، ممكن يجعل استعادة بعد عملية إعادة وضع قد قبول نطاق. هذا هو حتى قليل مرة تسليم فشل جهة نحو: لا تحديد صفة سوف صنع صنع تكرار، أبدا سوف قفز مرور تسلسل. عادي جلسة فحص نقطة سياسة سوف في تحت واحد دلالة فحص نقطة حفظ دائم ماء موضع؛ هذا إضافة لا تنفيذ مستقل I/O.

نقص قليل تخزين نشط جلسة مباشر طلب سوف حذف `dsh_session_log`. عادي agent(ذكي جسم) ، ضغط (compaction) و جلسة عنوان استدعاء كل سوف يحمل تخزين نشط جلسة id.

<a id="model-experience"></a>
## تجربة النموذج

### جلسة سجل بيانات وصفية

#### نموذج يرى محتوى

بلا.`dsh_session_log` هو DeepSeek طلب في نموذج إدخال حقل نفس درجة حقل، لن إدراج دخول `messages`، توجيه النظام أو أداة schema.

#### Token أثر

نموذج إدخال token لـ صفر؛ هذا حقل فقط سوف زيادة HTTP طلب بايت عدد.

#### KV Cache أثر

بلا؛ نموذج مرئي طلب بادئة إبقاء ثابت.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>

- **انهيار انهيار نافذة تكرار**——2xx بعد، قبول ماء موضع حفظ دائم قبل عملية إنهاء، سوف في استعادة وقت إطلاق حفظ حراسة إعادة وضع.
- **نقص قليل تخزين نشط جلسة حينئذ لا يوجد حقل**——مباشر استدعاء أو قديم قديم جلسة استدعاء لا يوجد يمكن توفير لقطة مواصفة سجل؛ صريح ناقص دلالة ما زال مؤقت مؤقت معالجة.
- **لا يوجد مستقل طلب كبير صغير حد أعلى**——كامل تسليم اعتماد fail-closed سياسة؛ مزود رفض سوف إبقاء تنقل علامة ثابت، بينما غير قطع قطع سجل.
