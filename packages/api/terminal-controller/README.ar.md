# @deepseek-ai/dsh-api-terminal-controller

[English](README.md) | العربية

## عام وصف

من Web جانب شريط في جلسة مساحة العمل فتح تنفيذ بيئة افتراضي shell. إعادة اتصال قد لديه عملية، و إغلاق provider إدارة كامل عملية نطاق. طرفية إخراج لا دخول Agent محادثة سجل. إبقاء طرفية سوف احتلال استخدام عملية و محدود شاشة ستار ذاكرة مؤقتة.

## استخدام هذا حزمة

Web bundle سوف هذا حزمة و subprocess provider،sandbox policy و Typert Gateway واحد بدء تركيب.Sandbox policy فقط لـ لا يوجد cwd Session توفير افتراضي عمل دليل.`remote.terminal` توفير `environment`،`shells`،`list`،`create`،`retain`،`follow`،`write`،`resize`،`rename` و `close`؛ كل عملية متساو حسب Session معرف حد تحديد نطاق. قائمة مباشر قراءة Host إبقاء طرفية، لذلك فحص نظر مغادرة خط Session لن تنشيط Agent، أيضا لن إنتاج استعادة خطأ.

Shell استكشاف قياس نتيجة أول أولا صف خروج تنفيذ بيئة إعلان افتراضي shell. فقط عند provider لم إعلان قيمة افتراضية وقت، عندئذ في POSIX استخدام `/bin/sh`، في Windows استخدام `cmd.exe`. اختياري `shell` profile عبر يمكن تنفيذ مسار `path`، عرض اسم `name` و معامل `args`(افتراضي `[]`) تغطية هذا واحد اختيار. اختيار جهاز أيضا سوف عبر تنفيذ provider استكشاف قياس `shellCandidates`، فقط حذف تحديد لم بحث إلى مرشح. إنشاء طلب قبول استكشاف قياس إرجاع `shellPath` و مجددا مرة تحقق؛ تحليل أو نقل فشل سوف مباشر تقرير إبلاغ، لا بدء أخرى shell. بيئة استعلام فقط إرجاع عمل دليل و حد، لا تحليل shell، لذلك افتراضي shell غير ممكن استخدام وقت ما زال يمكن إعادة اتصال قد لديه عملية.POSIX تلقائي profile بـ تفاعل نمط بدء،PowerShell استخدام `-NoLogo`، تكملة كل و بدء إعداد ما زال من shell توفير. ابتدائي دليل قدوم ذاتي Session مساحة العمل. مستخدم طرفية استخدام تنفيذ بيئة في نظام مستخدم إذن، مستقل في Agent صندوق رملي نمط و مراجعة دفعة سياسة. عملية نظام و حاوية حد ما زال توليد فاعلية؛DSH لا رفع رفع مستخدم إذن.Subprocess provider متابعة صاف حذف بيئة في اعتماد متغير.

| إعداد | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `shell` | حذف | استخدام تنفيذ بيئة افتراضي shell، أو إشارة تحديد واحد profile |
| `shellCandidates` | `zsh`،`bash`،`fish`،`pwsh`،`powershell`،`cmd` | قد تثبيت وقت توفير مستخدم اختيار مقدار خارج يمكن تنفيذ اسم أو مسار |
| `maxTerminals` | `8` | كل Session إبقاء طرفية و إنشاء طلب حد أعلى |
| `maxCols`،`maxRows` | `500`،`200` | PTY الأكثر كبير مقياس قياس |
| `scrollback` | `1000` | شاشة ستار تاريخ سطر عدد |
| `maxBufferedBytes` | `2097152` | مفرد عدد حجز قراءة من إخراج ترتيب طابور حد أعلى |
| `maxInputBytes` | `65536` | مفرد مرة إدخال طلب بايت حد أعلى |
| `disposeGraceMs` | `1000` | provider إنهاء عرض حد مدة، مفرد موضع جزء ثانية |
| `unattendedTimeoutMs` | `7200000` | بلا نافذة يحتفظ كما حمل متابعة تأكيد فارغ خامل بعد بدء تنظيف وقت طويل؛`0` منع استخدام تلقائي عودة استلام |
| `activityPollIntervalMs` | `30000` | بلا نافذة يحتفظ وقت نشط حركة مراقبة بين فصل |
| `cleanupRetryMs` | `60000` | تنظيف فشل بعد إعادة محاولة بين فصل |

أي قد اتصال نافذة في فتح وسم صفحة كل سوف يحتفظ ذلك طرفية، يشمل إخفاء وسم و غير حالي Session. الأكثر بعد واحد يحتفظ علاقة إزالة فقد بعد، فقط لديه واضح تأكيد فارغ خامل وقت عندئذ حساب دخول عودة استلام مدة حد. تشغيل في، إيقاف، انتظار إدخال و خلفية تنفيذ مهمة كل سوف تلقي إلى حفظ حماية؛ نشط حركة حالة لم معرفة وقت صاف حذف فارغ خامل قطع توقف وقت. مهمة إتمام بعد إعادة إعطاء إعطاء كامل عرض حد مدة.Host استخدام مفرد ضبط وقت ساعة، في تنظيف قبل إعادة فحص يحتفظ علاقة و حالي نشط حركة؛ مراقبة بين فصل تجاوز مرور جولة استفسار دورة مدة اثنان ضعف وقت إسقاط قديم دليل. وقت حقل استخدام جزء ثانية و أمان كامل عدد، جولة استفسار و إعادة محاولة بين فصل يجب لـ صحيح عدد.

<a id="understand-the-implementation"></a>
## حل تنفيذ

<details>
<summary>تنفيذ دقيق عقدة</summary>

Host عبر `ctx.subprocess.spawnTerminal` إنشاء `TERM=xterm-256color` طرفية، لا بدء طاولة وجه طرفية تطبيق. تدفق صيغة UTF-8 حل رمز إبقاء عبر كتلة محرف و فتح رأس BOM، و في EOF سوف لا كامل ذيل جزء بايت استبدال لـ بديل محرف. تحكم طلب مشي Gateway،`follow` استخدام ذلك إعادة استخدام Remote stream.Headless xterm و تسلسل تحويل addon في هذا قبل إخراج كتابة بعد توليد ابتدائي شاشة ستار، لاحق زيادة كمية يحمل مفرد ضبط ترتيب رقم. مرور بطيء حجز قراءة من واضح فشل؛ إعادة اتصال استعادة حالي شاشة ستار.

الأكثر جديد اتصال يحتفظ إدخال و مقياس قياس تحكم حق. قطع فتح اتصال فقط تحرير إدخال حق، لا انتهاء عملية. صريح إغلاق انتظار عملية تنظيف و الأكثر بعد إخراج؛ تنظيف فشل وقت إبقاء مورد بـ سهل إعادة محاولة.Session تسجيل إقامة قد إغلاق معرف و رفض متأخر إلى أو تكرار إنشاء طلب، يشمل إغلاق وصول وقت ما زال في إجراء إنشاء. جديد طرفية استخدام جديد معرف. إلغاء إنشاء كما تنظيف فشل وقت، قد قسم إعداد عملية ما زال لديه كل من.Session owner و controller إزالة أيضا سوف إنهاء الذي يملك عملية. تغيير Session صندوق رملي نمط وقت، مستخدم طرفية متابعة بـ أصل لديه إذن تشغيل. تحكم حق تحويل نقل أو عملية خروج بعد يتم رفض إدخال و مقياس قياس طلب إبقاء إخراج اتصال و منع استخدام إدخال، لا إعادة إرسال يتم رفض إدخال.

Client في قسم إعداد قبل سوف كل بند Session/محتوى و طرفية هوية صلة ربط حفظ إلى مستقل localStorage key `dsh.terminal.binding.v1.*`. محتوى هوية عام وحيد؛ تخطيط داخل tab id فقط معرف نشط حركة عرض occurrence. تدريجي بند سجل كتابة و حذف سوف إبقاء أخرى نافذة صلة ربط. استعادة عرض إعادة استخدام هذا هوية؛ جانب شريط terminal provider أولا استعادة ذاتي ذات عرض، مجددا استعلام بعد بلا عرض Host طرفية. جديد عرض يمكن إنشاء عملية، استعادة عرض في هدف ناقص وقت عرض خطأ، لا إنشاء بديل عملية. صريح إغلاق أولا حفظ تنظيف طلب، مجددا حذف صلة ربط. حالي عملية بيانات وصفية و شاشة ستار محتوى من Host توفير، لا حفظ في متصفح في.Client نموذج في متصفح إتمام شاشة ستار تحليل بعد تأكيد لقطة، حسب ترتيب إرسال إدخال، و تجاهل اختصار قديم اتصال متأخر إلى استجابة.Client ذاتي إنتاج خطأ يحمل محلي تحويل مفتاح. إضافة إزالة انتظار نشط وثب و أولا قبل قطع فتح إخراج تدفق انتهاء، لا إغلاق Host عملية.

مستقل `retain(sessionId, id, signal)` Remote تدفق تأكيد نافذة يحتفظ علاقة، لا تنشيط Agent، إرسال شاشة ستار إخراج، تحويل نقل إدخال حق أو إنشاء عملية. طرفية provider توفير جانب شريط كامل فتح وسم بيان،Client سوف ذلك و ذاتي ذات حفظ هوية أخذ تسليم تجميع. نفس نافذة في تكرار occurrence مشترك استخدام واحد يحتفظ تدفق؛ منعزل قيام قديم صلة ربط لن حفظ نشط أي طرفية. استعادة إخراج اتصال قبل يجب انتظار حالي يحتفظ علاقة تأكيد. نقل إلغاء فقط تحرير مقابل شيء إدارة تدفق بديل مرة؛ إضافة إزالة انتظار الكل يحتفظ تدفق انتهاء. تنظيف فشل وقت إبقاء كل حق و إعادة محاولة، لا إعادة قبول اتصال، أيضا لا إعادة حساب حساب فارغ خامل عرض حد مدة.

جديد عرض تلقائي بدء، استخدام بدء صفحة واضح اختيار في shell، أو فوق مرة اختيار كما ما زال متاح shell. فوق مرة اختيار مسار حفظ في حالي محطة نقطة localStorage `dsh.terminal.shell` في. افتراضي بدء عبر Host استكشاف قياس تحقق حفظ مسار، غير ممكن استخدام وقت عودة إلى حالي افتراضي بند. بدء صفحة في فتح وسم صفحة قبل سجل اختيار، كل جديد وسم صفحة إبقاء ذاتي ذات shell مسار و قسم إعداد هوية. تخزين فشل لا أثر بدء. استعادة قد لديه طرفية حيث لا قراءة هذا واحد انحراف جيد، أيضا لا استكشاف قياس shell.

إغلاق وقت أولا حفظ لم إتمام تنظيف طلب و تحرير وسم صفحة، مجددا في خلفية انتظار Host تنظيف. فشل وقت توفير إعادة محاولة إشعار. كل طلب استخدام مستقل طرفية ID localStorage key، تنظيف نجاح أو استلام إلى واضح `session/not-found` استجابة بعد حذف؛ بدء وقت إعادة محاولة قد حفظ طلب. نقل فشل وقت إبقاء طلب. تنظيف طلب مستقل في وسم صلة ربط و جانب شريط تخطيط حفظ دائم. متصفح تخزين غير ممكن استخدام وقت، داخل تخزين في تنظيف ما زال يمكن عمل، لكن تحديث جديد بعد لا يمكن استعادة هذا طلب.

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- متصفح تحديث جديد إبقاء عملية و شاشة ستار؛Host أو Session owner إزالة لا إبقاء. لا توفير حمل دائم طرفية استعادة أو تلقائي إعادة بدء shell. قد خروج طرفية ما زال حساب دخول `maxTerminals`؛ إغلاق لا استخدام وسم صفحة يمكن تحرير ذلك شاشة ستار و اسم مقدار.
- أصلي PTY متاح صفة و عملية شجرة تنظيف حفظ إثبات من subprocess provider قرار. بحث إلى يمكن تنفيذ ملف و لا حفظ إثبات PTY قسم إعداد نجاح.
- تلقائي عودة استلام اعتماد provider [دعم حمل shell نشط حركة مراقبة](../../subprocess/subprocess-local/README.ar.md#running-terminal-sessions). لا دعم حمل shell، ذاتي تعريف بدء معامل و لا تحديد عملية مراقبة ممكن يجعل مورد واحد مباشر إبقاء إلى واضح إغلاق أو owner إزالة. تشغيل في أمر لا يوجد قوي صنع الأكثر طويل تنفيذ وقت.
- شاشة ستار استعادة فقط إبقاء محدود تاريخ، لا إبقاء كامل سجل. نفس وقت لحظة فقط لديه واحد اتصال يمكن إدخال أو ضبط كامل مقياس قياس.
