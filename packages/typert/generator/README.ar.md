# @deepseek-ai/dsh-typert-generator

[English](README.md) | العربية

## عام وصف

`dsh-typert-generator` يجعل صيانة من يأخذ عام TypeScript نوع تحويل لـ بناء ناتج و و تحرير ترجمة جهاز غير متصل نموذج. حزمة عبر `./typert` و اختياري `./client/typert` تصدير اختيار إضافة دخول؛ إذا إعلان، إصدار بيان،Remote تصدير أو Zod إسقاط لا يمكن يتم صحيح تأكيد يمثل، توليد مرور مسار حينئذ سوف فشل. مستودع بناء سوف توليد يمكن تنفيذ schema factory و إعداد طقم إعلان، أداة أيضا يمكن استدعاء `WorkspaceAnalyzer` إتمام فحص أو دليل توليد بينما لا إصدار ناتج. توليد مرور مسار فقط في بناء وقت تشغيل، أبدا سوف دخول فوري agent(ذكي جسم) جلسة.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

هذه الحزمة توفير يأخذ Typert توليد وصل دخول بناء أو إزالة استهلاك توليد ناتج حزمة صيانة من و مستودع صيانة من استخدام. إصدار هو اختيار إضافة دخول: إعلان تصدير مدخل، تشغيل بناء، ناتج أي ظهور في `lib/` في؛ ساكن حالة قسم تحليل فإن لا حاجة ناتج.

### من حزمة في إصدار Typert ناتج

مشاركة و مساهمة حزمة في `package.json` في إعلان مضيف جانب ناتج تصدير؛ معا مساهمة اثنان جانب حزمة أيضا يلزم إعلان `./client/typert`، يحتوي Remote طريقة حزمة أيضا يلزم إعلان `./remote`:

```yaml
exports:
  "./typert":
    types: "./lib/typert.host.d.ts"
    default: "./lib/typert.host.js"
files:
  - "lib/typert.host.js"
  - "lib/typert.host.d.ts"
```

بناء إتمام بعد،`lib/typert.host.js` و `lib/typert.host.d.ts` أي وجود،[loader](../loader/README.ar.md) سوف في Loader تركيب في تسجيل هذا مساهمة. توليد إعلان ملف يأخذ `TYPERT` كشف لـ `unknown`، لذلك مشاركة و مساهمة حزمة دائم بعيد لن اعتماد وقت التشغيل سجل التسجيل. عند إعلان ناقص، إشارة نحو خطأ ملف، أو في لا يوجد Remote طريقة حال حال تحت إصدار Remote ناتج وقت، توليد جهاز سوف جعل بناء فشل؛ لا دعم حمل Zod إسقاط سوف بـ `TypertEmitError` إشارة واضح أداة جسم بنية صنع و فشل، بينما لن عرض مستو أو ضعيف تحويل مصدر نوع.

### ساكن حالة قسم تحليل مساحة العمل

ساكن حالة مستهلك مباشر إبرة مقابل مساحة العمل `tsconfig.host.json` و `tsconfig.client.json` تجمع دمج إعداد استدعاء `WorkspaceAnalyzer`، اختيار face و حزمة فرعي تجميع، و في لا توليد أو تحميل وقت التشغيل ناتج قبل رفع تحت قراءة توليد `FaceModel` و نوع رسم.`analyzeInBatches()` عبر محدود تحرير ترجمة جهاز برنامج معالجة كبير دفعة كمية حزمة اختيار، نموذج شكل إبقاء متسق؛`discoverPackages()` بلا حاجة بناء نوع فحص برنامج يكفي بحث خروج مشاركة و مساهمة حزمة.

### في tsdown بناء في تشغيل توليد

حزمة `./tsdown` فرعي مسار لـ أصل tsdown إعداد توفير `typertPlugin()`: هو في تحزيم قبل تحويل TypeScript اعتماد في معيار تركيب زينة جهاز، و في حزمة إخراج أصل دليل توليد نموذج قيادة face ناتج.`package` نمط فقط توليد حالي تحزيم حزمة؛`workspace` نمط مقابل كل صريح مساهمة جهة كل توليد مرة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير توليد جهاز مثل أي نيل إلى و تحرير ترجمة جهاز غير متصل نموذج و هو توليد ماذا؛ يمكن مراقبة بناء سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

توليد جهاز التزام دوران واحد بند نواة قلب قسم مغادرة أصل فإن: رفع أخذ و توليد عبر و تحرير ترجمة جهاز غير متصل نموذج حل اقتران.`WorkspaceAnalyzer` قراءة بـ face aggregate tsconfig لـ نوع فرعي TypeScript برنامج، إنتاج خروج `FaceModel` و `TypeGraph` بيانات؛`FaceModelEmitter` فقط إزالة استهلاك هذا نموذج، أبدا استقبال تحرير ترجمة جهاز عقدة. نموذج إبقاء إعلان معرف، عام نوع معامل و تطبيق، صريح وراثة، شرط نوع و خريطة نوع، استيراد خاصية،abstract إصلاح زينة رمز و شفرة المصدر JSDoc، و ترتيب حذف بنية صنع دالة، ساكن حالة عضو و غير عام مشترك عضو.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | عام مشترك API: قسم تحليل جهاز، توليد جهاز، مساحة العمل توليد جهاز، مصير، دليل إسقاط |
| [`src/analyzer.ts`](src/analyzer.ts) | `WorkspaceAnalyzer`:face برنامج،check/write نمط، قسم دفعة، اكتشاف، شفرة المصدر بحث جذب |
| [`src/model.ts`](src/model.ts) | و تحرير ترجمة جهاز غير متصل نموذج نوع |
| [`src/emitter.ts`](src/emitter.ts) | `FaceModelEmitter`:Zod schema و إعلان توليد،Remote إعلان |
| [`src/workspace.ts`](src/workspace.ts) | `WorkspaceTypertGenerator`: اكتشاف، توليد، تصدير و ملف بيان تحقق |
| [`src/tsdown-plugin.ts`](src/tsdown-plugin.ts) | tsdown إضافة وجه: تركيب زينة جهاز تحويل و ناتج توليد |
| [`src/cordis-catalog.ts`](src/cordis-catalog.ts) | توليد Cordis دليل الذي استخدام دليل إسقاط |

### قسم تحليل و face

Host و Client هو اثنان عدد مستقل TypeScript برنامج. مباشر مشروع مرجع تحديد تحرير ترجمة جهاز face عضو ملكية،`dsh.client` حزمة فرعي مسار فإن تحديد وقت التشغيل face مساهمة؛`package.json#exports` تخطيط تحديد كل عبر حزمة عام حد، عبر face حافة فقط قدرة قدوم ذاتي استيراد أو إعادة تصدير. تحليل إلى هذه الحزمة داخلي وحدة متبادل مقابل استيراد سوف امتداد هذا وحدة إعادة تصدير متابعة تتبع أثر، مباشر إلى ظهور حزمة شرح رمز، لذلك حزمة داخل تحويل إرسال وحدة إبقاء أصلي إعلان مرجع؛ تحليل إلى أخرى حزمة متبادل مقابل استيراد سوف فشل.`check` نمط لقاء إلى لغة قاعدة أو دلالة تشخيص، ناقص عام نوع علامة ملاحظة، عبر حزمة خاص مرجع، و نموذج لا يمكن بلا ضرر إبقاء يمكن بلوغ إعلان دمج وقت كل سوف فشل؛`write` نمط إدراج دخول نوع فحص جهاز دفع تصدير علامة ملاحظة، و إرجاع بلا تشخيص check نمط نموذج.NPM اعتماد يملك نوع متابعة بـ `external` مرجع يمثل، لن يتم توسيع.

### توليد و إصدار اتفاق

`FaceModelEmitter` إخراج يتضمن فقط ذاكرة مؤقتة نجاح نتيجة Zod schema factory و `TYPERT` مساهمة يمكن تنفيذ JavaScript، و يأخذ factory عبر حزمة عام تصدير علامة ملاحظة لـ إرجاع `z.ZodType<SourceType>` إعلان ملف؛ لا دعم حمل Zod إسقاط سوف فشل. يحتوي Remote طريقة Host face أيضا سوف مقدار خارج لـ Client توليد Host Remote اتفاق `typert.remote-client.*` إسقاط.`WorkspaceTypertGenerator` تحقق كل مساهمة جهة `package.json`:`./typert` و `./client/typert`(وجود Remote طريقة وقت أيضا لديه `./remote`) يجب إشارة نحو دقيق توليد ملف، كما `files` بيان يجب يتضمن هو جمع.

### دليل إسقاط

وقت التشغيل نوع إغلاق حزمة بحث جذب تصدير workspace إعلان و يتم مرجع إطار هيكل enum.Vendor إعلان لا مشاركة و عمل خدمة API اكتشاف؛ عام مشترك نتيجة مرجع منها enum وقت، دليل ما زال توفير ذلك تعريف.

أصل تصدير يتضمن هذا مستودع Cordis دليل استخدام نموذج قيادة رفع أخذ منطق، كامل صفة فحص و تحديد صفة نص مصير. هو جمع قبول `CordisCatalogPolicy`؛ من مستودع يحتفظ نوع رابط، أساس أساس نوع/إعفاء تجنب تصنيف و وراثة Cordis بند ما زال يقع في `scripts/gen-cordis-catalog.ts`، من استدعاء جهة صريح نقل دخول، لذلك هذه الحزمة فقط يتضمن إسقاط آلية، لن خفي صيغة نسخ مستودع وثيقة تصنيف جسم نظام.

## تجربة النموذج

بلا، لأن بناء وقت توليد جهاز في أي agent وقت التشغيل خارج تشغيل، لا لمس و أي نموذج طلب.

#### KV Cache أثر

بلا مباشر أثر؛ توليد ناتج فقط لديه في مستهلك سوف ذلك وضع دخول طلب وقت عندئذ سوف لمس و طلب.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح توليد جهاز لا يمكن بناء نموذج أو توليد بنية صنع؛ هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **حزمة تصدير نمط سوف يتم قفز مرور**——مشاركة و مساهمة حزمة حاجة أداة جسم تصدير هدف؛ عبر إعداد رمز تصدير نمط لن يتم قسم تحليل.
- **عبر face نطاق الأسماء إعادة تصدير سوف فشل**——أداة اسم و نجم رقم إعادة تصدير سوف توليد رابط، لكن في `TypeTargetModel` قدرة كاف لا مرور عرض مستو يمثل وحدة نطاق الأسماء قبل، نطاق الأسماء إعادة تصدير لا يمكن يمثل.
- **Zod توليد جهاز فقط دعم يحتفظ معنى حد تحديد فرعي تجميع**——عام نوع schema إعلان، و بـ شرط نوع أو خريطة نوع لـ schema أصل حساب حساب بنية صنع، كل سوف فشل، مباشر إلى وجود واضح schema عمل مصنع سياسة.
- **لا يوجد توليد schema عبر face استيراد**——عبر face رابط سوف في نموذج في يمثل بـ توفير قسم تحليل، لكن توليد schema متساو لا حاجة عبر face وقت التشغيل Zod استيراد.
- **اكتشاف نطاق فقط تغطية أداة جسم عام تصدير**——حيث لم تصدير، أيضا لم من يمكن بلوغ رسم استيراد إعلان حسب تصميم ترتيب حذف في حزمة نموذج خارج.
