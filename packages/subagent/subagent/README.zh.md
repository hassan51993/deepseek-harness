# @deepseek-ai/dsh-subagent

[English](README.md) | العربية

## عام وصف

استخدام `dsh-subagent` يأخذ عمل تفويض إرسال إعطاء أداة اسم فرعي agent، استلام تجميع نتيجة، و عبر جولة متابعة تلقي دعم حمل فرعي درجة محادثة. واحد تركيب يمكن و ترتيب توفير عملية داخل،ACP(Agent Client Protocol) ،SDK،Codex أو Claude Code فرعي درجة. حاجة مفرد عدد نتيجة وقت اختيار مرة صفة فرعي درجة؛ حاجة لاحق رسالة و في قطع قدرة وقت اختيار يمكن متابعة فرعي درجة. أنت أيضا يمكن فحص متاح فرعي درجة و ذلك نمط، نشط حركة حالة و جدول نظام، بينما بلا حاجة تحميل أو استعادة هو جمع. تفعيل وقت حاجة حتى قليل واحد تلقي دعم حمل فرعي درجة خلفية و واحد تفويض إرسال أداة.

## استخدام هذه الحزمة

هذه الحزمة هو كل تفويض إرسال تركيب كل مشترك اتفاق. أنت عبر يأخذ خدمة و واحد أو كثير عدد مزود خلفية و موجه إلى نموذج تفويض إرسال أداة واحد بدء تركيب قدوم تفعيل هو؛ هذا بعد agent يكفي تفويض إرسال عمل، خدمة سوف يأخذ كل طلب توجيه إلى أداة اسم مزود.

### تفعيل تفويض إرسال

يأخذ خدمة و واحد مزود و تفويض إرسال أداة واحد بدء تركيب. مزود بـ أنت إعداد اسم تسجيل (عملية داخل spawn خلفية افتراضي لـ `spawn`) ؛ أداة سطر إشارة اسم هذا مزود، يجعل نموذج يرى واحد ساكن حالة أداة. واحد الأكثر صغير مرة صفة إعداد:

```yaml
- name: '@deepseek-ai/dsh-subagent'
- name: '@deepseek-ai/dsh-subagent-spawn-in-process'
- name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: spawn
    toolName: subagent
```

استدعاء هذا أداة agent سوف يأخذ فرعي agent نهائي جواب سجل بصفة أداة نتيجة استلام إلى. فقط تركيب خدمة ذاته لن تغيير أي سلوك: في تركيب خروج مزود و أداة قبل، ماذا كل لا يستطيع تفويض إرسال.

### تفويض إرسال ضبط

**إضافة → Subagent** صفحة حد جزء تحرير Host `subagent` ضبط قسم عقدة. مستخدم قيمة تغطية هذا إضافة تركيب إعداد؛ استعادة افتراضي سوف حذف مستخدم تغطية.`maxDepth` افتراضي لـ `1`، في تفويض إرسال أداة ذاته لم إعداد عميق درجة وقت توفير قيمة افتراضية. أداة صريح إشارة تحديد عميق درجة (يشمل `provider-managed`) أولوية. عميق درجة `0` منع توقف وراثة هذا ضبط أداة تفويض إرسال؛ عميق درجة `1` فقط سماح مباشر فرعي بديل إدارة. تعديل في تحت مرة تفويض إرسال وقت توليد فاعلية. مباشر استدعاء خدمة استدعاء جهة ما زال ذاتي سطر توفير اختياري طلب عميق درجة.

### يمكن متابعة وصل فرعي بديل إدارة سعة كمية

في Host `dsh-subagent` إضافة فوق ضبط `maxActiveSubagents`، حد عبر وصل متابعة يمكن متابعة وصل أب فرعي علاقة مشترك اسم مقدار تخزين نشط فرعي بديل إدارة عدد. قيمة افتراضية لـ `8`، قبول صحيح أمان كامل عدد. غير يمكن متابعة وصل أب بديل إدارة بناء قيام مستقل حوض، ذاته لا احتلال اسم مقدار؛ يمكن متابعة وصل بعد بديل وراثة هذا حوض. جديد بناء و بارد استعادة في إعادة بناء Agent قبل مسبق احتلال اسم مقدار، تنظيف في handle تحرير بعد عودة أيضا اسم مقدار. انتظار بعد بديل أب بديل إدارة، لديه انتظار معالجة استلام عنصر صندوق محتوى بديل إدارة و صحيح في إيقاف Activation ما زال احتلال اسم مقدار. نحو إقامة إبقاء فرعي بديل إدارة إرسال رسالة إعادة استخدام ذلك اسم مقدار. مرة صفة و خارجي مزود تشغيل لا تلقي هذا حد. حوض وراثة لن عبر تجاوز مرة صفة أب بديل إدارة؛ ذلك يمكن متابعة وصل فرعي بديل إدارة مشترك مستقل حوض. عميق درجة ما زال من تفويض إرسال أداة مستقل سياسة قرار.

كل مرة جديد بناء أو بارد استعادة Activation قبل كل سوف قراءة حالي `maxActiveSubagents`. ضبط عال بعد قد لديه شجرة يمكن وصل قبول أكثر كثير فرعي بديل إدارة؛ ضبط منخفض بعد إقامة إبقاء فرعي بديل إدارة متابعة تشغيل، استخدام كمية خفض حتى حد أعلى التالي قبل رفض جديد وصل قبول.

سعة كمية استهلاك كل وقت، جديد بناء أو بارد استعادة بـ `ACTIVATION_LIMIT_REACHED` رفض (متصفح رسالة إرجاع `subagent/delivery-unavailable`): انتظار فرعي بديل إدارة إتمام، أو متابعة استخدام قائم بديل إدارة. وصل قبول لن ترتيب طابور، تجنب تجنب انتظار بعد بديل أب بديل إدارة أيضا انتظار ذاتي ذات احتلال استخدام اسم مقدار. اسم مقدار فقط وجود في حالي عملية، لا حد تراكم حساب Session تاريخ أو token استخدام كمية.

### مرة صفة و يمكن متابعة فرعي درجة

مرة صفة فرعي agent فقط تشغيل مرة، و بـ مفرد عدد نتيجة تسوية، يمكن مرفق حمل اختياري بنية تحويل إخراج و فشل وقت أمان تشخيص. بدء طلب يمكن عبر `agentOptions` تغطية فرعي Agent مزود، نموذج، دفع إدارة قوي درجة و إخراج token حد أعلى؛ كل طلب خيار كل اشتراط مزود إعلان مقابل قدرة. يمكن متابعة فرعي agent إبقاء حمل دائم جلسة و حسب ترتيب قبول لاحق رسالة: استدعاء جهة استلام إلى مستقر فرعي agent id، إرسال متبادل مجاور Agent رسالة، و يمكن في قطع حالي جولة بينما لا إلغاء تدمير فرعي agent. أداة سطر `backgroundMode` اختيار شكل (افتراضي `one-shot`، أو في دعم حمل مزود فوق استخدام `continuable`).

### رسالة، في قطع و اكتشاف

كل تأكيد قطع في خط Agent كل يمكن مقابل مباشر يمكن متابعة child استخدام `sendMessage()`؛ إقامة إبقاء يمكن متابعة child أيضا يمكن مقابل ذاتي ذات مباشر parent استخدام هو. صحيح في عمل هدف عبر Steer في الأكثر قريب step استقبال Agent رسالة؛ فارغ خامل هدف بدء جولة، كما فقط لديه مباشر child يمكن بارد استعادة.parent أيضا يمكن مع وقت في قطع صحيح في تشغيل بعد بديل أو صف رفع ذاتي ذات فرعي درجة. متصفح إرسال خروج متابعة تنفيذ نص التوجيه سوف مستقل اختيار Queue أو Steer، و كما يمكن يحمل صورة جزء:Host أولا عبر مرفق عنصر تخزين إتمام كامل دفعة صورة دقيق دخول و حفظ دائم، فرعي درجة inbox عندئذ قبول هذا بند رسالة؛ عند فرعي درجة إعلان نموذج لا قبول صورة إدخال وقت رفض إلقاء تمرير. اكتشاف تغطية اثنان نوع شكل: خدمة صف رفع مباشر فرعي درجة و كامل بعد بديل شجرة——نمط، نشط حركة حالة و جدول نظام——مباشر قراءة في خط جلسة حالة و اختياري حفظ دائم، لا تحميل أي فرعي agent.

### فشل و استعادة

حاجة الذي اختيار مزود لا أداة تجهيز قدرة طلب سوف في بدء وقت واضح تقرير خطأ، بينما لن يتم ساكن صامت تجاهل اختصار. فشل فرعي agent تشغيل سوف إرجاع إيقاف سبب، مزود خلفية أيضا سوف مرفق إضافة أمان تشخيص؛ يتم إلغاء طلب بـ `aborted` تسوية. فرعي agent متبادل متبادل عزل: انهيار انهيار أو سلوك استثناء فرعي agent لا يمكن كسر تالف أب درجة جلسة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### تصميم إدارة فكرة

- **واحد خدمة، كثير عدد مزود.** خدمة هو أداة اسم مزود سجل التسجيل؛ كل خلفية بـ وحيد اسم تسجيل، طلب حسب اسم اختيار واحد.
- **اثنان نوع فرعي درجة شكل.** مرة صفة تشغيل في إصدار وقت تحويل نقل كل حق؛ يمكن متابعة فرعي درجة إبقاء حمل دائم Session، كما نفس وقت لحظة حتى كثير واحد عملية داخل Activation.
- **صرف الآن أي إصدار.** مزود `start()` فقط لديه في حقيقي فرعي agent وجود بعد عندئذ صرف الآن، لذلك استدعاء جهة يلزم ما يملك واحد مقطع في خط تشغيل، يلزم ما واحد بلا كل.
- **نفس عملية قيمة يمكن معلومة.** طلب، وصف رمز و نتيجة حسب غير ممكن تغيير اتفاق استعارة استخدام؛ تسلسل تحويل و غير ممكن معلومة إدخال تحقق يخص عملية و بروتوكول حد.

### مرة صفة مسار

طلب أولا مقابل وفق مزود إعلان قدرة إجراء تحقق، مع بعد مقابل حفظ دائم وصف رمز فعل لقطة، مجددا من مزود بناء فرعي agent. اثنان عدد عملية داخل مزود كل إعلان `agentOptions`: إنشاء فرعي درجة وقت يأخذ طلب حقل تراكم إضافة إلى أب درجة الأكثر جديد قد سجل طلب مزود، نموذج و دفع إدارة قوي درجة لـ فوق؛ أب درجة أيضا لا يوجد طلب وقت رجوع إلى إنشاء خيار، و إبقاء إعداد token حد أعلى. هو جمع أيضا سوف في رقم مرة await قبل لقطة تفويض إرسال إذن حالة:Auto أو Full access أب درجة يجعل فرعي درجة نيل نيل نفسه `permission/preset` هوية، بينما قائم صندوق رملي تغطية و مراجعة دفعة سياسة ثابت ما زال توليد فاعلية؛ معا سجل هذا اثنان عدد هوية يمكن منع توقف fork في أكثر مبكر نفس دوران زر تركيب هوية فوز خروج.Auto مع بعد سوف مستقل مراجعة فحص child كل تلقي دعم حمل استدعاء: عادي مشروع داخل عمل لـ منخفض ريح خطر و مباشر سماح؛ في ريح خطر عمل يجب في قائم إنشاء prompt أو قد نواة تحقق human/مباشر أب درجة رسالة في نيل نيل حركة عمل، دقيق تأكيد هدف و نطاق واضح تخويل، كما لا و human حد اندفاع مفاجئ؛ عال ريح خطر عمل بداية نهاية رفض.reviewer من `parentSession` و قائم رسالة إرسال توليد هذا نسخة سياق؛ تفويض إرسال لن إضافة جديدة أب call metadata، تفويض إرسال سجل،review receipt أو Session format. أكثر تعديل توجيه بينما لا صريح إشارة تحديد دفع إدارة قوي درجة وقت، سوف صاف حذف وراثة توجيه ذاتي لديه قوي درجة، جعل الذي اختيار نموذج تحليل ذاتي ذات قيمة افتراضية.DSH SDK أيضا إعلان `agentOptions`، لكن سوف تشغيل مستقل فرعي وقت التشغيل، لذلك لا وراثة Auto؛ACP،Codex و Claude Code نفس مثال في أب درجة تفويض إرسال استدعاء عبر مراجعة فحص بعد إبقاء كل منها إذن نظام. نجاح وقت تشغيل يتم إصدار، كل حق تحويل نقل إعطاء استدعاء جهة؛ فشل وقت مزود تراجع كل بعد لم إصدار مورد. نتيجة يحمل فرعي agent نهائي إخراج، اختياري بنية تحويل قيمة، إيقاف سبب و اختياري أمان تشخيص.

### يمكن متابعة مسار

إدارة جهاز مسبق إبقاء child هوية، تحليل حفظ دائم وصف رمز، إنشاء (أو بارد استعادة)child، يأخذ هو تثبيت دخول Activation و إيداع نص التوجيه. نموذج تحرير كتابة رسالة عبر ثابت Steer ضبط درجة عبر واحد بند parent/child حافة؛ متصفح شخص صنف prompt عبر داخلي مهايئ اختيار Queue أو best-effort Steer، أخرى host بروتوكول ما زال يمكن إبقاء Queue بـ إنشاء مستقل جولة.Session queue command فقط أصل حسب child ذاته continuable descriptor دقيق دخول في خط subagent-owned Agent.Settlement سوف انتظار Agent نشط حركة انتهاء،Inbox لـ فارغ كما لا يوجد الذي يملك فرعي درجة، مجددا في دقيق دخول فتح وضع وقت flush نهائي Session حالة. إدارة جهاز مع بعد في child lock داخل إعادة تحقق wake generation،Session ترتيب رقم،Inbox و الذي يملك فرعي درجة؛`Agent.runMaintenance()` تزامن task مدخل سوف احتلال استخدام idle مرحلة مقطع، و في نفس عدد JavaScript turn داخل إغلاق خاص subagent Inbox، لكن بعد عندئذ تحرير جملة مقبض. مباشر child لا وجود Activation وقت سوف من حفظ دائم جلسة بارد استعادة. عند إقامة إبقاء Activation تسوية وقت، إدارة جهاز سوف في parent ذاته جولة تدفق في إبلاغ معرفة هذا child مباشر parent.

محلي فرعي درجة إنشاء نجاح وقت، أب Session إلحاق واحد بند `subagent/catalog` واقع. مرة صفة إنشاء في مزود إرجاع بعد سجل؛ يمكن متابعة إنشاء في ابتدائي inbox دقيق دخول بعد، إرجاع فرعي درجة id قبل سجل. فشل سوف تحرير فرعي درجة، لا إصدار تكملة تعويض صفة دليل حدث. مرة صفة دليل إلحاق فشل وقت سوف معالجة run نتيجة رفض، و إبقاء دليل خطأ؛ مورد تحرير فشل سوف مفرد وحيد سجل.`subagentCatalog` projection ترتيب حذف fork وراثة واقع، عبر Session مراقبة و عميل لقطة في `projections.values.subagentCatalog` كشف مباشر فرعي درجة قائمة. بلا فاعلية ذاته catalog payload(يشمل لا دعم حمل إصدار) سوف جعل projection استعادة فشل. ذلك غير ممكن تغيير تخزين و فحص نقطة تحقق استخدام [`dsh-chunked-list`](../../util/chunked-list/README.zh.md). ذلك عرض مقابل D بند واقع بـ O(D) وقت إبقاء أب دليل حدث ترتيب.[أب دليل قرار](../../../.agents/notes/implemented/architecture/2026-09-01-parent-owned-subagent-catalog.zh.md) شرح ترتيب ترتيب، حفظ دائم صار هذا و بديل خطة.

### كل حق و ثابت صيغة

- **إصدار أي حد**——إصدار قبل مزود يملك ضبط و يجب في فشل وقت تراجع؛ إصدار بعد استدعاء جهة يملك تشغيل و يجب dispose(مورد تحرير) هو.
- **تسجيل تلقي effect أثر مجال قيد**——إزالة مزود سوف منع توقف جديد بدء، لكن أبدا سحب إلغاء قد قبول تشغيل.
- **Agent رسالة إذن أساس في تأكيد قطع متبادل مجاور علاقة**——`sendMessage()` اشتراط تأكيد قطع في خط sender؛ كل sender كل يمكن إشارة تحديد مباشر يمكن متابعة child، فقط لديه أداة تجهيز إقامة إبقاء يمكن متابعة Activation sender يمكن إشارة تحديد ذاتي ذات مباشر parent.
- **وصف رمز فقط دخول سجل**——هو هو جلسة حدث، لا دخول نموذج تاريخ، و عبر ضغط (compaction) إبقاء؛ يمكن متابعة وصف رمز سوف صريح سجل تحليل بعد فرعي درجة مزود، نموذج و دفع إدارة قوي درجة، لأجل بارد استعادة.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### تسوية إشعار

#### نموذج يرى ماذا

واحد بند مستخدم زاوية لون أب درجة رسالة، فتح رأس هو نتيجة ذاته——`Background subagent <child-id> finished and will do no further work unless you send it more.`، أو فرعي درجة يتم إيقاف، استهلاك كل مقدار درجة، رفض مهمة أو فشل وقت مقابل جملة فرعي——مع بعد هو `Its closing message:` و فرعي درجة نهائي assistant إخراج في غير فارغ نص كتلة، إبقاء أصلي محتوى و ترتيب. دفع إدارة و أخرى غير نص كتلة لن دخول إشعار؛ إذا لا يوجد باق بقية غير فارغ نص، إشعار سوف كتابة واضح `It left no closing message.`. هذا بند من وقت التشغيل توليد إشعار و نموذج تحرير كتابة أب فرعي رسالة متبادل متبادل مستقل؛ بعد من استخدام `sendMessage()` و `AgentMessageSource`. تفويض إرسال schema و نموذج تحكم أداة عودة مستهلك حزمة كل.

#### Token أثر

أب درجة طلب في، كل قد تسوية Activation واحد بند إشعار، طويل درجة أخذ قرار في فرعي درجة نهائي نص. إذا فرعي درجة أولا إرسال ذاتي ذات رسالة مجددا تسوية، أب درجة طلب سوف معا تحمل تحمل اثنان من.

#### KV Cache أثر

في أب درجة في فقط إلحاق: إشعار يقع في ذلك يمكن إعادة استخدام طلب بادئة بعد. وصول فارغ خامل أب درجة سوف بدء مرة مستقل نموذج طلب، وصول كثيف مشغول أب درجة فإن لن.

### فرعي درجة تفويض إرسال نطاق إعلان

#### نموذج يرى ماذا

كل عملية داخل فرعي agent وقت التشغيل سياق لقطة كل يحمل تحت جهة `subagent:delegation` إعلان، يقع في صندوق رملي سياسة و مراجعة دفعة سياسة لغة جملة بعد.

##### تفويض إرسال نطاق إعلان

```markdown
You are a delegated subagent: your permission scope was fixed when you were started and cannot be widened from inside this session — operations that require approval are rejected automatically. When the job needs access beyond that scope, do not retry the denied operation; state the limitation in your reply so the delegating agent can handle it.
```

#### Token أثر

كل فرعي agent وقت التشغيل سياق لقطة في واحد بند ثابت إعلان؛ أب درجة طلب في لا يوجد أي إضافة جديدة.

#### KV Cache أثر

فرعي درجة داخلي بادئة مستقر: هذا إعلان في فرعي agent دورة الحياة داخل أبدا تغير، لذلك فقط كتابة رقم واحد نسخة وقت التشغيل سياق لقطة مرة. أب درجة جانب لن مباشر جعل ذاكرة مؤقتة بطلان؛ أداة اسم أداة مستهلك مشترك نفس مسؤول طلب بادئة أي تغير.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا seam أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام تفويض إرسال مقابل مقارنة أو مهمة تراكم ضغط.

- **ACP فرعي درجة ما زال لـ مرة صفة، كما لا يمكن عبر تتبع أثر قطعة رفع**——ACP تشغيل في أب درجة جلسة لغة مادة في لا يوجد محلي فرعي جلسة، بعيد مسار مزود حاجة Activation كل حق اتفاق عندئذ قدرة دعم حمل يمكن متابعة فرعي درجة.
- **فقط سماح متبادل مجاور نموذج رسالة**——`sendMessage()` اشتراط تأكيد قطع في خط sender؛ كل sender كل يمكن إشارة تحديد مباشر يمكن متابعة child، فقط لديه أداة تجهيز إقامة إبقاء يمكن متابعة Activation sender يمكن إشارة تحديد ذاتي ذات مباشر parent. متصفح تلميح استخدام مستقل شخص صنف Queue أو Steer تحكم مسار.
- **child إلى parent إلقاء تمرير اشتراط مباشر parent إبقاء في خط**——خدمة لا يوجد حمل دائم parent mailbox؛parent ناقص وقت سوف رفض رسالة، بينما غير قبول لا يمكن نداء تنبيه عمل.
- **إلغاء استلام جمع خلال وجود نداء تنبيه نقص فتحة**——في قطع إشارة إرسال خروج بعد،driver دخول idle قبل يتم قبول لاحق رسالة سوف إبقاء ترتيب طابور، مباشر إلى آخر بند نداء تنبيه إرسال وصول.
- **انتظار معالجة حقن سياق سوف إبقاء Activation**——settlement سوف حفظ حراسة أرض يأخذ كل Inbox occurrence كل نظر لـ لم إتمام.Agent دخول idle بعد توقف وضع سياق سوف يجعل child و ذلك في خط أصل أولا متابعة إقامة إبقاء، مباشر إلى نداء تنبيه إلقاء تمرير سوف ذلك claim،queue تغيير سوف ذلك إزالة، أو manager teardown سوف ذلك إسقاط.
- **إقامة إبقاء فقط حد عملية داخل**——Activation inbox و كل حق رسم لن في اثنان عدد harness عملية بين تنسيق ضبط؛ مقابل مفرد عدد حفظ دائم تخزين تزامن وصول حاجة حفظ دائم بريد صندوق و عبر عملية إيجار نحو بروتوكول.
- **قد حفظ تسوية إشعار لن يتم تعديل كتابة**——إذا مستخدم زاوية لون قد حفظ إشعار يحتوي لديه دفع إدارة كتلة، فقط يلزم هو ما زال في أب درجة طلب تاريخ في،DeepSeek Messages تسلسل تحويل حينئذ سوف فشل.
- **لا إعادة تشغيل قد قبول لكن لم سجل رسالة**——انهيار انهيار ممكن فقد فقد من لم كتابة فرعي جلسة سجل، قد يتم قبول نص التوجيه؛ فقد فقد رسالة لن تلقائي إعادة تشغيل.
- **لا يوجد حفظ دائم parent mailbox**——child إلى parent رسالة اشتراط إقامة إبقاء يمكن متابعة child و في خط مباشر parent، توفير هو قبول معرف، لا حفظ إثبات تماما جيد مرة إلقاء تمرير.
- **دورة الحياة حدث فقط توفير مراقبة**——أثر تشغيل `subagent/end` تأخير متابعة أو قرار واجهة ما زال يحتاج انتظار أداة جسم مستهلك.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

- **عبر عملية متابعة تنفيذ**——حفظ دائم بريد صندوق و إيجار نحو بروتوكول يمكن يجعل اثنان عدد harness عملية مشترك واحد حفظ دائم تخزين.
- **يمكن متابعة ACP فرعي درجة**——حاجة حفظ دائم بعيد مسار جلسة id و تدريجي فرعي درجة متابعة تنفيذ قدرة إعلان.
- **host-user إلقاء تمرير**——لم قدوم host مهايئ حاجة أداة جسم مرور إقرار إثبات تفاعل، هذا seam عندئذ قدرة نيل نيل مستخدم إلقاء تمرير قدرة.

</details>
