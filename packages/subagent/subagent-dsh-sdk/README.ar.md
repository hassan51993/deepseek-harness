# @deepseek-ai/dsh-subagent-dsh-sdk

[English](README.md) | العربية

## عام وصف

`dsh-subagent-dsh-sdk` في كل جديد DeepSeek Harness عملية فرعية في تشغيل كل تفويض إرسال مهمة، عملية فرعية يملك ذاتي ذات profile، جلسة، نموذج توجيه و أداة. أب درجة توفير مهمة و عمل دليل، كل عملية فرعية استخدام ذلك قد إعداد وقت التشغيل، و و أب درجة محادثة إبقاء عزل. أب درجة فقط سوف استلام إلى عملية فرعية نهائي assistant نص أو أمان خطأ؛ في بين رسالة و أداة تدفق كمية إبقاء في عملية فرعية داخل. عند تفويض إرسال حاجة كامل Harness وقت التشغيل بينما لا هو مشترك عملية داخل حالة وقت، اختيار هذا خلفية، و قبول كل مرة تشغيل كل يلزم بدء جديد عملية صار هذا.

## استخدام هذه الحزمة

عند تفويض إرسال ينبغي بـ كامل Harness وقت التشغيل في مستقل عملية في وقت التشغيل، تركيب هذا مزود. معتاد استخدام مسار هو صريح: تركيب seam، تركيب هذا مزود، حسب يحتاج إعداد `dshBin`، و اختيار فرعي درجة `profile` و لديه ترتيب `patches`.

### أي وقت اختيار

عند عملية فرعية يجب هو كامل harness مقابل انتظار جسم——يملك ذاتي ذات تركيب، جلسة حفظ دائم، نموذج توجيه و أداة——بينما لا هو مشترك أب عملية agent وقت، اختيار هذا خلفية. عند عملية فرعية يجب مشترك أب درجة تركيب أو التزام حراسة أب درجة قوي صنع غير توجيه قدرة وقت، طلب اختيار عملية داخل خلفية: هذا مزود قبول agent توجيه خيار، لكن سوف رفض بنية تحويل إخراج، عميق درجة حد أعلى، أداة مرور ترشيح أو persona، بينما لا هو ساكن صامت حذف.

مزود إعلان `agentOptions: true`، معا إبقاء `outputSchema`/`depthLimit`/`toolFilter`/`persona` لـ false، و كما `inheritsParentContext: false`. غير ممكن تغيير `agentRouteDefaults` سوف في نموذج تغطية و تأكيد قطع توجيه مسبق فحص قبل، يأخذ إعداد provider/model أساس خط عام إعطاء `dsh-tool-subagent`؛`start()` فإن لـ مباشر استدعاء جهة مستقل تطبيق نفس نسخة إعداد قيمة افتراضية، يشمل `maxTokens`.agent توجيه قيمة عبر صريح أبيض اسم مفرد عبر تجاوز SDK بروتوكول؛ عملية فرعية ما زال هو آخر عملية داخل كل جديد وقت التشغيل، وحيد من أب agent ذاته إرسال توليد قيمة هو مساحة العمل cwd. أساس في هذا مزود `dsh-tool-subagent` نشر ينبغي ضبط `maxDepth: 'provider-managed'`——فرعي harness يملك ذاتي ذات تمرير عودة ميزانية.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `dsh-sdk` | `ctx.subagents` فوق سجل التسجيل اسم |
| `dshBin` | SDK اعتماد | صريح dsh CLI(أمر سطر واجهة) وحدة، في إضافة تحميل وقت تحليل و تحقق؛ حذف فإن استخدام SDK اعتماد |
| `profile` | `sdk` | أداة اسم فرعي profile |
| `patches` | `[]` | كل مرة بدء لديه ترتيب profile patch ملف، في إضافة تحميل وقت تحليل و تحقق |
| `dshHome` | لا بد ملء | كل تضمين طقم عملية فرعية قطعا مقابل عزل Harness home |
| `cwd` | أب جلسة cwd | عملية فرعية و ذلك SDK جلسة عمل دليل تغطية قيمة |
| `provider` | `deepseek-official` | كتابة عملية فرعية `initialize` مزود توجيه |
| `model` | `deepseek-v4-flash` | كتابة عملية فرعية `initialize` نموذج |
| `maxTokens` | مهايئ/مزود توجيه قيمة افتراضية | كتابة عملية فرعية `initialize` مفرد مرة طلب إخراج token حد أعلى |
| `env` | `{}` | تراكم إضافة في قد تنظيف اعتماد أب بيئة لـ فوق صريح فرعي بيئة |
| `shutdownTimeoutMs` | `1000` | dispose(مورد تحرير) خلال بروتوكول `shutdown` تسليم تبديل وقت حد |
| `disposeEofGraceMs` | `6000` | stdin EOF بعد، منصة إنهاء قبل عرض حد |
| `disposeGraceMs` | `3000` | إنهاء بعد خروج تأكيد عرض حد |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-subagent-dsh-sdk) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

طلب `agentOptions` سوف قسم آخر تغطية `provider`،`model` و `maxTokens`.`reasoningEffort` لا يوجد مزود نسخة قيمة افتراضية: طلب حذف وقت إبقاء نقص حذف، من الذي اختيار فرعي نموذج تحليل ذاته قيمة افتراضية. موجه إلى نموذج subagent أداة يمكن في كل مرة استدعاء وقت اختيار مزود/نموذج/دفع إدارة قوي درجة؛`maxTokens` ما زال من أداة إعداد أو هذا مزود قيمة افتراضية في نشر جانب تحكم.

```yaml
- id: subagent-dsh-sdk
  name: '@deepseek-ai/dsh-subagent-dsh-sdk'
  config:
    providerName: dsh-sdk
    profile: sdk
    patches: ['./profiles/research-child.cordis.yml']
    dshHome: !!js dshHomePath('children')
    maxTokens: 49152
    env:
      DEEPSEEK_API_KEY: !!js process.env.DEEPSEEK_API_KEY
- id: tool-subagent
  name: '@deepseek-ai/dsh-tool-subagent'
  config: { provider: dsh-sdk, toolName: subagent, maxDepth: 'provider-managed' }
```

### أنت سوف نيل إلى ماذا

نجاح تشغيل سوف يأخذ عملية فرعية نهائي assistant نص (أو إلغاء بعد تراكم تراكم جزء نص) بصفة نتيجة إخراج إرجاع. عملية فرعية نموذج توجيه، أداة و جلسة قدوم ذاتي فرعي وقت التشغيل ذاته——أب درجة توفير مهمة، عمل دليل و `initialize` توجيه. عملية فرعية الأكثر بعد واحد حفظ دائم `turn/end` سوف خريطة دخول seam مفردات:`completed` و `max-tokens` أصل مثال عبر،`blocked` تغيير لـ `refusal`، معنى خارج نهاية حالة أو نقص قليل نهاية حالة تغيير لـ `error`.`aborted` نتيجة إبقاء في توقف؛ فقط لديه عملية فرعية جانب `disposed` سبب سوف مرفق إضافة `child-disposed` تشخيص.

### فشل و استعادة

قد إلغاء طلب سوف في مسار تحليل أو spawn قبل فشل. توجيه،spawn، إمساك يد أو إصدار قبل إلغاء فشل عبر معتاد فقط في عملية فرعية يتم عودة استلام بعد رفض؛ إذا ابتدائي تحويل و تنظيف متساو فشل، لديه ترتيب أمان واقع سوف إبقاء اثنان بند فشل، بينما لن إعلان تسمية قد تماما توقف مستقر. فرعي وقت التشغيل في إصدار بعد فشل وقت سوف عبر تشغيل ذاته تسوية، بينما لا هو رفض؛ جزء إخراج و أمان تشخيص إبقاء قسم مغادرة. تشخيص فقط عام مزود،`initialize`،`session-run` أو `shutdown` مرحلة مقطع، و ثابت صنف آخر.SDK رسالة،stderr، مسار، مهمة محتوى، بيئة قيمة، اعتماد و بروتوكول تحميل حمل أبدا سوف نسخ إلى تشخيص في.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية مثل أي قيادة فرعي Harness وقت التشغيل، و يمكن مراقبة سلوك من أي بينما قدوم؛ كامل اتفاق رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

- **كامل harness مقابل انتظار جسم.** كل عملية فرعية كل هو مستقل عملية في كامل Harness وقت التشغيل——يملك ذاتي ذات تركيب، جلسة، نموذج توجيه و أداة؛ فقط لديه تحليل بعد عمل دليل و `initialize` توجيه من أب درجة عبر تجاوز.
- **كل مرة تشغيل واحد وقت التشغيل.** كل مرة تشغيل كل spawn كل جديد وقت التشغيل عملية؛ لا يوجد عملية حوض.
- **JSON-RPC بروتوكول صيغة (wire format) هو تسلسل تحويل حد.** نفس عملية subagent قيمة لن لـ منع صد هدف تغلب ضخم؛ بروتوكول عندئذ هو تحقق غير ممكن معلومة إدخال أرض جهة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:config schema، مزود تسجيل |
| [`src/run.ts`](src/run.ts) | SDK تشغيل دورة الحياة، جواب سجل رفع أخذ و إيقاف سبب خريطة |

### تشغيل مسار

مرة بدء سوف في spawn قبل تحليل عملية فرعية عمل دليل و واحد بند عملية درجة SDK توجيه.`request.agentOptions` في كل قد إعلان حقل (`provider`،`model`،`reasoningEffort` أو `maxTokens`) كل سوف تغطية مقابل مزود نسخة قيمة افتراضية؛ حذف وقت إبقاء قد إعداد مزود/نموذج و اختياري حد أعلى، بينما دفع إدارة قوي درجة فقط لديه في طلب توفير وقت عندئذ سوف ظهور. مع بعد، مزود عبر SDK عميل spawn وقت التشغيل، و في تنفيذ سطر قبل إتمام `initialize` إمساك يد، منها يشمل تأكيد قطع نموذج و دفع إدارة قوي درجة تحقق. توجيه،spawn، إمساك يد أو إصدار قبل إلغاء فشل وقت، فقط سوف في عملية فرعية يتم عودة استلام بعد رفض؛ عمل دليل تحليل فشل فإن سوف في بعد لم spawn أي محتوى وقت رفض. إصدار بعد، مزود يملك واحد مقطع SDK نشط حركة، و من فرعي جلسة حدث في قراءة جواب سجل: الأكثر بعد واحد بند كامل كما غير فارغ `assistant/message`(سجل usage فارغ محتوى رسالة سوف يتم قفز مرور) ؛ إذا لا يوجد هذا صنف رسالة، فإن أخذ تراكم تراكم `text-delta` تدفق.dispose هو قوة انتظار: أولا في محلي يأخذ نتيجة تحديد لـ `aborted`، إرسال خروج محدود بروتوكول `shutdown` طلب، مجددا مرور stdin EOF → SIGTERM → SIGKILL ترقية إلى فعلي خروج.

### إيقاف سبب خريطة

عملية فرعية الأكثر بعد واحد `turn/end` سبب سوف خريطة دخول مشترك إيقاف سبب مفردات، تنفيذ رؤية [`src/run.ts`](src/run.ts).

### عملية حد

عملية فرعية بيئة بـ عملية فرعية seam في قد صاف حذف اعتماد أب بيئة لـ أساس أساس، و في صاف حذف بعد دمج صريح `config.env` قيمة. عملية فرعية من SDK عميل spawn، بينما لا هو مرور من `ctx.subprocess`——هذا هو SDK حمل إدارة نقل وثيقة تحويل مثال خارج——لذلك هذا خلفية سوف ذاتي سطر تنفيذ بيئة تنظيف.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent طلب

#### نموذج يرى ماذا

فرعي وقت التشغيل نموذج سوف استلام إلى بصفة مستخدم رسالة مستقل مهمة، و هذا وقت التشغيل ذاته إعداد توجيه النظام، أداة و كل جديد جلسة. هو لن استلام إلى أب درجة محادثة. أب درجة أداة استدعاء يمكن لـ هذا مرة تشغيل اختيار فرعي درجة مزود، نموذج و دفع إدارة قوي درجة؛ الذي اختيار توجيه و من نشر تحكم اختياري إخراج حد أعلى سوف ثابت إلى هذا عدد جديد عملية فرعية.persona، أداة مرور ترشيح، عميق درجة قوي صنع و بنية تحويل إخراج ما زال لا تلقي دعم حمل، و سوف يتم رفض بينما لا هو ساكن صامت حذف.

#### Token أثر

فرعي وقت التشغيل سوف لـ مستقل كامل سياق و ذلك كثير خطوة تاريخ إزالة استهلاك token. هذه token أبدا سوف دخول أب درجة سياق.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة متبادل متبادل مستقل. كل SDK عملية فرعية فقط قدرة إعادة استخدام ذلك ذاته مزود، نموذج، تركيب و تاريخ متساو نفسه وقت بادئة؛ حذف هذا خارج، فرعي agent خطوة فقط إلحاق زيادة طويل.

### أب درجة أداة نتيجة (بين وصل)

#### نموذج يرى ماذا

مرور من `dsh-tool-subagent`، أب درجة فقط سوف استلام إلى فرعي وقت التشغيل نهائي assistant نص (أو تراكم تراكم جزء نص) ، أو هذا مستهلك إعطاء خروج دقيق إيقاف سبب خطأ؛ لن استلام إلى في بين رسالة أو أداة تدفق كمية. حمل تشخيص غير إتمام نتيجة سوف أولا عرض أمان تشخيص، مجددا مفرد وحيد عرض إبقاء جزء assistant إخراج؛ بدء و shutdown خطأ استخدام نفس ثابت واقع، لا عام أصلي SDK نص.

#### Token أثر

أب درجة إدخال فقط زيادة نهائي نتيجة أو خطأ، ذلك كبير صغير أخذ قرار في بيانات، و إبقاء إلى ضغط (compaction) لـ توقف. هذا مزود ذاته لن نحو أب درجة إضافة أي schema.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خلفية أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام SDK مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مرة تشغيل كل استخدام كل جديد وقت التشغيل عملية**——لا استخدام عملية حوض؛harness وقت التشغيل حاجة بدء كامل إضافة شجرة، لذلك كل مرة تشغيل spawn صار هذا عال في ACP خلفية عبر معتاد استخدام عملية فرعية.
- **لا دعم حمل توجيه خارج بدء وقت قدرة**——أب درجة يمكن اختيار فرعي agent توجيه، لكن لا يمكن في عملية فرعية داخل قوي صنع تنفيذ `outputSchema`، عميق درجة حد، أداة مرور ترشيح أو persona؛ ينبغي تعديل لـ إعداد الذي اختيار فرعي profile و ذلك لديه ترتيب patch.
- **عملية فرعية transcript(نص سجل) إبقاء في ذلك ذاته جلسة أصل دليل في**——أب درجة سجل فقط سجل تفويض إرسال أداة استدعاء و نتيجة؛ تدفق صيغة `session.event` عبر طريق فقط لأجل رفع أخذ إخراج، لن جسر وصل إلى أب درجة سجل في.
- **فقط دعم حمل محلي عملية فرعية**——تحليل خروج عمل دليل هو محلي مسار؛ بعيد مسار وقت التشغيل حاجة مستقل خلفية.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

- **Spawn صار هذا**——كل مرة تشغيل تحميل كامل إضافة شجرة هو تام قاع عزل بديل قيمة؛ حوض تحويل سوف تغيير هذا واحد حق توازن.
- **بعيد مسار وقت التشغيل**——بعيد مسار وقت التشغيل حاجة مستقل خلفية و مساحة العمل خريطة.

</details>

**وقت التشغيل ثابت صيغة:** لا إصدار مرافق توليد مدخل.run دورة الحياة إعداد مقابل من subagent seam ثابت صيغة فحص؛ هذا خلفية ذاته حالة يقع في عملية فرعية في، لا في حالي سياق حدث تدفق داخل.
