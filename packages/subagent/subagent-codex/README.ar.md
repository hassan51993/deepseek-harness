# @deepseek-ai/dsh-subagent-codex

[English](README.md) | العربية

## عام وصف

عند تفويض إرسال عمل حاجة في أب جلسة مساحة العمل في حقيقي بلا شخص قيمة حراسة Codex جلسة داخل وقت التشغيل، يأخذ `@deepseek-ai/dsh-subagent-codex` تثبيت دخول Profile. كل مرة تفويض إرسال كل سوف لـ واحد ذاتي يتضمن نص مهمة استخدام كل جديد كما عزل Codex خط مسار، و كما فقط إرجاع ذلك نهائي جواب سجل أو أمان فشل تشخيص. أصلي Codex إعداد و هوية تحقق متابعة بصفة مرجعي مصدر، بينما `permissionMode` اختيار غير تفاعل صيغة مراجعة دفعة و صندوق رملي سلوك.Bundle سوف توفير توافق أصلي Codex تحميل حمل، لكن فقط لديه إعداد تفويض إرسال أداة بعد عندئذ سوف نحو نموذج عام متبادل ينبغي قدرة.

## استخدام هذه الحزمة

عند تفويض إرسال ينبغي بـ أب درجة مساحة العمل في حقيقي Codex جلسة وقت التشغيل، تركيب هذا مزود. معتاد استخدام مسار هو صريح: يأخذ Bundle تثبيت دخول Profile، اختياري أرض إعداد مزود سطر، و عبر تفويض إرسال أداة سطر يأخذ هو كشف إعطاء نموذج.

### تثبيت Bundle

يأخذ حزمة تثبيت دخول هدف Profile، لكن بعد إعادة بدء هذا Profile. تثبيت سوف يأخذ رسمي جهة wrapper و واحد توافق أصلي منصة تحميل حمل حمل دخول Profile؛ إعلان patch طبقة فقط تسجيل راحة نوم مزود، لا بدء أي Codex عملية.

```sh
dsh plugin --profile <name> add @deepseek-ai/dsh-subagent-codex
dsh plugin --profile <name> remove @deepseek-ai/dsh-subagent-codex
dsh --profile <name>
```

إزالة حزمة بعد، تحت مرة Profile بدء سوف سحب عودة مزود و ذلك خاص وقت التشغيل إغلاق حزمة. تثبيت قرار Host متاح صفة، بينما لا هو نموذج إذن: نموذج فقط قدرة عبر أنت تركيب تفويض إرسال أداة سطر لمس بلوغ مزود.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `codex` | `ctx.subagents` فوق غير فارغ تسجيل اسم؛ كل قد تركيب نسخة كل حاجة وحيد قيمة |
| `model` | Codex أصلي ضبط | لـ هذا مزود نسخة كل خط مسار ثابت اختياري غير فارغ نموذج اسم؛ حذف وقت لا إرسال app-server تغطية |
| `env` | `{}` | تراكم إضافة في قد تنظيف اعتماد أب بيئة لـ فوق صريح عملية فرعية بيئة |
| `permissionMode` | `never` | لـ هذا مزود نسخة كل خط مسار ثابت أصلي غير تفاعل مراجعة دفعة و صندوق رملي نمط |
| `disposeGraceMs` | `3000` | مشترك managed-range owner كل إنهاء طبقة درجة بين عرض حد |

| `permissionMode` قيمة | `thread/start` حقل | أصلي سلوك |
|---|---|---|
| `never` | `approvalPolicy: never`؛ حذف sandbox | دائم لا طلب مراجعة دفعة؛ في أصلي sandbox تحت حدوث تنفيذ فشل سوف إرجاع إعطاء نموذج |
| `approve-for-me` | `approvalPolicy: on-request`،`approvalsReviewer: auto_review`،`sandbox: workspace-write` | من Codex تلقائي مراجعة إذن طلب، لا انتظار شخص عمل |
| `dangerously-bypass-approvals-and-sandbox` | `approvalPolicy: never`،`sandbox: danger-full-access` | قفز مرور مراجعة دفعة و sandbox؛ يجب صريح اختيار هذا قيمة |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-subagent-codex) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر. قد إعداد `model` سوف أصل مثال نقل إعطاء كل مؤقت `thread/start`؛ حذف وقت إبقاء أصلي نموذج اختيار. مزود لن اكتشاف نموذج، تعديل كتابة آخر اسم، اختيار `modelProvider` أو `serviceTier`، أيضا لن ضبط fallback. أداة لديه سند إثبات خاص سمة بيئة متغير سوف في صريح `env` تغطية توليد فاعلية قبل يتم إزالة، لذلك توفير عملية فرعية استخدام API مفتاح يجب في هذا إعداد في صريح توفير.

### كشف أداة

كل تفويض إرسال أداة سطر إشارة اسم واحد مزود، و حاجة مستقل `toolName`، لذلك نموذج يرى هو ساكن حالة أداة، بينما لا هو حركة حالة مزود اختيار جهاز. كامل Agent Preset يحمل مقابل افتراضي أداة سطر و ضبط `disabled: true`؛ نسخ واحد preset بعد حذف هذا حقل، يكفي فقط نحو من هذا فرعي هذا تجميع agent كشف `subagent_codex`.

```yaml
- id: jobs
  name: '@deepseek-ai/dsh-jobs-local'
- id: tool-jobs
  name: '@deepseek-ai/dsh-tool-jobs'
- id: tool-subagent-codex
  name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: codex
    toolName: subagent_codex
    backgroundMode: one-shot
    maxDepth: provider-managed
```

`one-shot` سياسة سوف يجعل حذف `run_in_background` أو نقل دخول `false` استدعاء متابعة في قبل منصة انتظار، بينما صريح نقل دخول `true` سوف إرجاع من أب agent يملك Job id، توفير `job_output` أو `job_kill` استخدام؛base host(أساس أساس مضيف) و كامل preset قد توفير عام عمل عمل سجل التسجيل و تحكم أداة.

### أنت سوف نيل إلى ماذا

قبل منصة استدعاء سوف يأخذ اختيار تحديد نهائي Codex جواب سجل تسليم إعطاء نموذج؛ تشغيل فشل وقت فإن إرجاع حمل إيقاف سبب و اختياري أمان تشخيص خطأ. خلفية استدعاء أولا إرجاع Job id؛ مع بعد عام عمل عمل تحكم وجه سوف إرسال بلوغ إتمام إشعار، و عبر `job_output` عام نفس نهائي جواب سجل أو فشل حالة.Codex مرور مسار شرح، دفع إدارة، أداة نشط حركة، أصلي stderr و مساحة العمل فرق مختلف أبدا سوف دخول أب درجة جلسة.

### فشل و استعادة

حذف optional dependencies، حالي منصة لا تلقي دعم حمل أو الذي اختيار تحميل حمل ناقص تثبيت سوف يجعل مزود إبقاء راحة نوم، و في رقم مرة تفويض إرسال وقت في `initialize` مرحلة مقطع بـ أمان `unknown` صنف آخر و أي قد مراقبة قياس عملية نتيجة فشل؛ لا وجود مضيف CLI رجوع. أصلي wrapper نص فقط إبقاء في Host stderr. يتم إلغاء تشغيل بـ `aborted` تسوية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مزود مثل أي قيادة حقيقي Codex app-server، و يمكن مراقبة سلوك من أي بينما قدوم؛ كامل اتفاق رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

- **كل مرة تشغيل واحد كل جديد عملية، خط مسار و جولة.** كل مرة تشغيل كل سوف spawn كل جديد app-server، إنشاء واحد مؤقت خط مسار و تماما جيد تنفيذ واحد جولة؛ لا يوجد متابعة وصل، استعادة أو حوض تحويل.
- **أصلي إعداد هو مرجعي.** Codex إعداد و هوية تحقق مرور أب درجة cwd،`HOME` و `CODEX_HOME` إبقاء أصلي؛ مزود فقط تغطية اختياري نموذج و خط مسار approval،reviewer و sandbox حقل.
- **لحظة معنى بلا شخص قيمة حراسة.** مراجعة دفعة، مستخدم إدخال و MCP طلب كل سوف في بلا شخص مشاركة و حال حال تحت يتم ينبغي جواب أو رفض؛ لم معرفة خادم طلب سوف جعل تشغيل فشل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:config schema، مزود تسجيل |
| [`src/run.ts`](src/run.ts) | تشغيل دورة الحياة، جولة تنفيذ، نتيجة اختيار و تشخيص |
| [`src/wire.ts`](src/wire.ts) | الأكثر صغير app-server JSON-RPC بروتوكول تنفيذ |
| [`cordis.patch.yml`](cordis.patch.yml) | تسجيل راحة نوم مزود Profile patch طبقة |

### تشغيل مسار

مرة بدء فقط قبول غير فارغ نص كتلة تسلسل، و أصل حسب أب جلسة تحديد فرعي درجة cwd. هو مرور عملية فرعية seam spawn ثابت أمر، إتمام `initialize` → `initialized` إمساك يد، يأخذ Profile اختيار نمط و اختياري نموذج خريطة لـ رسمي جهة `thread/start` حقل و و `{ cwd, ephemeral: true }` واحد بدء إرسال، كما فقط في Codex إرجاع صالح مؤقت خط مسار بعد إصدار تشغيل. قد إصدار نتيجة تماما جيد بدء واحد جولة، فقط قبول و هذا مرة تشغيل خط مسار و جولة مطابقة إشعار، و انتظار مرجعي `turn/completed` نهاية حالة. بـ الأكثر بعد واحد بند `phase: "final_answer"` `agentMessage` لـ دقيق؛ إذا Codex لا يوجد إرسال خروج واضح نهائي مرحلة مقطع، فإن بـ الأكثر بعد واحد بند `phase: null` رسالة بصفة توافق صفة رجوع. نجاح إتمام جولة إذا لا يوجد غير فارغ أبيض جواب سجل، نتيجة أيضا سوف حكم لـ خطأ. فشل جولة استخدام خشن حبة درجة صنف آخر `limit`،`access-policy`،`service`،`transport`،`product-error`،`invalid-result` أو `unknown`؛app-server رفع قبل خروج استخدام `process`، ملائم استخدام اتصال و stream فشل إبقاء عدد قيمة `httpStatusCode`.

<a id="model-experience"></a>
## تجربة النموذج

### فرعي درجة طلب

#### نموذج يرى ماذا

Codex فرعي درجة سوف في واحد كل جديد مؤقت خط مسار في، بـ مفرد عدد جولة استقبال هذه مستقل نص كتلة. هو مساحة العمل هو أب جلسة cwd؛ الذي اختيار مزود نسخة سوف ثابت قد إعداد نموذج، بيئة، غير تفاعل مراجعة دفعة سياسة و صندوق رملي نمط، بينما حذف نموذج و ذلك بقية منتج ضبط قدوم ذاتي Codex أصلي إعداد. يمكن تنفيذ إصدار قدوم ذاتي Bundle قفل تحديد منصة تحميل حمل.

#### Token أثر

فرعي درجة يحتاج لـ مستقل Codex سياق و جولة تحمل تحمل token صار هذا. فرعي درجة token لن دخول أب درجة سياق.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة متبادل متبادل مستقل. قدرة لا إعادة استخدام فقط أخذ قرار في Codex ذاته مزود، نموذج، إشارة أمر، أداة و مؤقت خط مسار طلب.

### أب درجة ضبط درجة و نتيجة (بين وصل)

#### نموذج يرى ماذا

عبر `dsh-tool-subagent`، قبل منصة استدعاء سوف يجعل أب درجة نموذج يرى اختيار تحديد Codex نهائي جواب سجل؛ إذا نتيجة لم إتمام، خطأ في سوف يتضمن إنهاء سبب و اختياري أمان تشخيص. هذا تشخيص يمكن منطقة قسم خشن حبة درجة سطر حركة صنف آخر، بروتوكول مرحلة مقطع، ملائم استخدام عدد قيمة HTTP status و قد مراقبة قياس عملية نتيجة، بينما لا نسخ منتج متن أو stderr. خلفية استدعاء سوف أولا إرجاع Job id؛ مع بعد عام عمل عمل تحكم وجه سوف إرسال بلوغ إتمام إشعار، عبر `job_output` عام نفس نهائي جواب سجل أو فشل حالة تفصيل حال، و سماح `job_kill` طلب إلغاء.Codex مرور مسار شرح، دفع إدارة (reasoning) ، أداة نشط حركة، أصلي stderr، مساحة العمل فرق مختلف، استخدام كمية معلومة، منتج معرف رمز، أمر، مسار و بروتوكول تحميل حمل متساو لن نسخ إلى أب جلسة.

#### Token أثر

قبل منصة إدخال سوف زيادة أداة نتيجة في إبقاء نهائي جواب سجل أو خطأ محتوى. خلفية إدخال أيضا سوف يتضمن بدء تأكيد، إتمام إشعار، و `job_output`،`job_kill` أو لاحق حالة نتيجة؛ فرعي مهمة token ما زال لن دخول أب درجة سياق. هذا مزود ذاته لا إضافة أب درجة أداة schema.

#### KV Cache أثر

فقط إلحاق: قبل منصة سوف في يمكن إعادة استخدام أب طلب بادئة بعد زيادة واحد نتيجة، خلفية فإن سوف متابعة إلحاق Job بدء تأكيد، إشعار و لاحق تحكم أو استلام تجميع نتيجة. خلفية ضبط درجة ممكن زيادة واحد من إشعار نداء تنبيه جولة، لكن هذه رسالة كل لن تعديل كتابة أكثر مبكر بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام Codex مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مرة تشغيل متساو جديد بناء واحد عملية، واحد خط مسار و واحد جولة**——لا دعم حمل متابعة وصل، استعادة، حوض تحويل، دخول درجة تدفق أو منتج جلسة حفظ دائم.
- **ساكن حالة اختيار نسخة**——Profile بند إعداد ثابت مزود اسم، اختياري نموذج و أداة ربط؛ استدعاء لا يمكن حركة حالة اختيار أو تعديل مزود و نموذج، بينما كما كل عام أداة كل حاجة وحيد `toolName`.
- **هوية تحقق و حساب مستخدم حالة ما زال من أصلي آلية إدارة**——Bundle سوف توفير CLI، لكن لن إنشاء حساب مستخدم، تسجيل تسجيل، معلومة مهمة مشروع أو تعديل كتابة Codex ضبط؛ إعداد و هوية تحقق فشل سوف عام ذلك دورة الحياة مرحلة مقطع و أمان `unknown` رجوع، بينما لن زيادة مفرد وحيد عام تصنيف جسم نظام.
- **تفويض إرسال وقت يجب وجود أصلي منصة تحميل حمل**——حذف optional dependencies تثبيت، لا تلقي دعم حمل منصة و ناقص أو ضرر تالف تحميل حمل كل سوف في رقم مرة وقت التشغيل فشل؛ لن رجوع إلى مضيف CLI.
- **توافق صفة من تطوير دليل قفل تحديد**——إذا يلزم من قد تحقق 0.153.4 بروتوكول أساس خط ترقية، يجب إعادة توليد فوق تنقل schema دليل، و إعادة تشغيل إمساك يد، جواب سجل اختيار، مراجعة دفعة، إلغاء، بلا مفتاح حقيقي منتج و حمل مفتاح DeepSeek مع آلة عدد اختبار.
- **لا يوجد شخص عمل مراجعة دفعة مسار**——معروف بلا شخص قيمة حراسة مراجعة دفعة طلب سوف يتم رفض، لم معرفة خادم طلب سوف بـ افتراضي رفض طريقة جعل تشغيل فشل؛ ثلاثة نوع Profile نمط كل لن إنشاء DSH تفاعل عبر طريق أو تدريجي مرة استدعاء allow سياسة.
- **assistant تحميل حمل فقط يتضمن نهائي نص**——فشل تشغيل يمكن مقدار خارج عام مستقل أمان تشخيص؛ دفع إدارة، مرور مسار شرح، في بين رسالة، أداة عبر معلومة، استخدام كمية معلومة، أصلي stderr و مساحة العمل فرق مختلف لن دخول أب جلسة، عام Job id، إشعار و حالة قدوم ذاتي مشترك عمل عمل وقت التشغيل.
- **لا يوجد اختياري مشترك قدرة**——مقابل في هذا مزود، مشترك خدمة سوف رفض `agentOptions`، إخراج schema، فرعي مهمة زاوية لون ضبط تحديد، أداة غربلة اختيار و harness عميق درجة قوي صنع قيد.
- **لا يوجد حسب فعلي مرور مرور وقت إطلاق مهلة أو فرعي أثر تراجع**——طويل وقت تشغيل عمل من استدعاء جهة إلغاء، كما إلغاء قبل قد أكثر تعديل ملف أو خارجي نظام لن استعادة أصل حالة.

### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

- **تحميل حمل جسم تراكم كشف كشف**——حالي darwin-arm64 منصة تحميل حمل ضغط بعد نحو 114 MB، حل حزمة بعد نحو 282 MB؛ هذه هو كشف كشف عدد حرف، لا هو تثبيت عتبة قيمة.
- **إصدار قفل تحديد بروتوكول**——وقت التشغيل اعتماد قفل تحديد لـ `@openai/codex@0.153.4`؛ ترقية حاجة إعادة توليد فوق تنقل schema دليل و إعادة تشغيل حمل سند إثبات مع آلة عدد اختبار.

</details>
