# @deepseek-ai/dsh-tool-subagent

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن لـ agent توفير واحد أداة اسم أداة، يأخذ عمل تفويض إرسال إعطاء قد إعداد فرعي agent خلفية.`one-shot` نمط تحت، استدعاء افتراضي انتظار فرعي agent؛`continuable` نمط تحت، استدعاء افتراضي في خلفية بدء حفظ دائم فرعي agent، و إرجاع متاح في لاحق رسالة id. تلقي دعم حمل خلفية أيضا يمكن عام نيل دقيق فرعي درجة LLM مزود، نموذج و دفع إدارة انتظار درجة توفير نموذج اختيار. كل نسخة متساو يمكن ضبط فرعي agent persona، أداة إذن و عميق درجة حد، فشل تشغيل سوف إرجاع خطأ، بينما غير جزء نجاح.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

كل تفويض إرسال هدف تركيب واحد نسخة، كما كل نسخة `toolName` يجب مختلف. أداة و ذلك مزود معا وجود، معا إزالة فقد، لذلك نفس درجة تحميل ترتيب و مزود إعادة تحميل كل لن يجعل أداة معلق فارغ.

### الأكثر صغير إعداد

أولا تحميل subagent خدمة، واحد عملية داخل أو بعيد مسار خلفية و هذا أداة، لكن بعد إشارة تحديد مزود اسم. هذا تركيب كشف واحد تفويض إرسال إعطاء `spawn` خلفية `subagent` أداة:

```yaml
- name: '@deepseek-ai/dsh-subagent'
- name: '@deepseek-ai/dsh-subagent-spawn-in-process'
- name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: spawn
    toolName: subagent
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `provider` | لا بد ملء | `ctx.subagents` فوق مزود اسم (مثل `spawn`،`fork`،`acp`) |
| `toolName` | `subagent` | موجه إلى نموذج أداة اسم؛ كل قد تحميل نسخة يجب مختلف |
| `modelSelectionSettings` | `false` | لـ كل قمة طبقة Session قراءة مضيف دقيق توجيه تخويل انحراف جيد؛ معتاد إقامة preset مراقبة مطابقة Session، مباشر Agent setup فإن صريح نقل دخول ذلك Session؛ اشتراط مزود دعم حمل `agentOptions` |
| `enableRunInBackground` | `true` | عام `run_in_background`؛ منع استخدام وقت أيضا سوف رفض قوي صنع خلفية استدعاء |
| `backgroundMode` | `one-shot` | خلفية سياسة:`one-shot` افتراضي قبل منصة استدعاء؛`continuable` افتراضي خلفية استدعاء، و اشتراط مزود أداة تجهيز `prepareContinuable` قدرة |
| `agentOptions` | — | إعداد فرعي درجة `provider`،`model`، مهايئ كل `reasoningEffort` و صحيح كامل عدد `maxTokens` قيمة افتراضية؛ اشتراط مزود دعم حمل `agentOptions`، و سوف تغطية مزود يحتفظ توجيه قيمة افتراضية |
| `persona` | — | كل فرعي agent مستقل persona؛ اشتراط مزود أداة تجهيز `persona` قدرة |
| `toolFilter` | — | كل فرعي agent مستقل عام أداة حد؛ اشتراط مزود أداة تجهيز `toolFilter` قدرة |
| `maxDepth` | Host ضبط (`1`) | قطعا مقابل تفويض إرسال عميق درجة حد أعلى (`0` منع توقف تفويض إرسال) ؛`'provider-managed'` لا نحو عملية خارج مزود إرسال حد أعلى |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-tool-subagent) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### قبل منصة و خلفية نمط

`one-shot` سياسة تحت، حذف `run_in_background` سوف في قبل منصة انتظار و إرجاع فرعي agent نهائي نص؛`run_in_background: true` سوف بدء واحد عودة أب درجة كل عادي خلفية مهمة، و إرجاع `started background subagent job <id>`، متاح `job_output` استلام تجميع، استخدام `job_kill` إيقاف.

`continuable` سياسة تحت، حذف أو لـ `true` `run_in_background` سوف بدء واحد حفظ دائم فرعي agent، و إرجاع `started subagent <childId>`، لا انتظار نتيجة؛ فرعي agent Activation انتهاء وقت، وقت التشغيل إلقاء تمرير واحد بند تسوية إشعار، اختياري `send_message` أداة سوف نحو هو إرسال أكثر كثير عمل. يأخذ `run_in_background` ضبط لـ `false` يمكن في قبل منصة انتظار نتيجة.

`maxDepth` حد تمرير عودة عميق درجة (`0` منع توقف تفويض إرسال) ؛ حذف وقت، كل مرة تفويض إرسال قراءة Host حالي `subagent.maxDepth` ضبط، ابتدائي قيمة لـ `1`. عدد قيمة عميق درجة اشتراط مزود أداة تجهيز `depthLimit` قدرة؛`'provider-managed'` يأخذ ميزانية إبقاء إعطاء عملية خارج مزود. عند مزود دعم حمل وقت،`persona` و `toolFilter` سوف إعداد كل فرعي agent؛ أداة في بلوغ إلى حد أعلى وقت ما زال مرئي——كل مرة محاولة تجربة بدء كل سوف فحص استدعاء agent حالي عميق درجة، يتم رفض وقت إرجاع خروج خطأ أداة نتيجة.

### اختيار فرعي درجة LLM

ضبط `modelSelectionSettings: true`، يكفي في تركيب كل كل جديد قمة طبقة Session وقت قراءة مضيف `subagent-model-selection` انحراف جيد. لا يوجد قد سجل سياسة استعادة Session سوف إبقاء منع استخدام، يشمل صريح لـ فارغ استعادة. تفعيل بعد، غير فارغ دقيق provider/model توجيه قائمة سوف سجل دخول Session، من فرعي Session وراثة، لاحق ضبط تحرير لن تغيير هو. أداة مع بعد عام اختياري `provider`،`model` و `reasoning_effort` حقل، و تسجيل مشترك `list_subagent_models` أداة. هذا نمط اشتراط خلفية إعلان `agentOptions`؛ اثنان عدد عملية داخل خلفية و DSH SDK دعم حمل هذا قدرة، بينما ACP،Codex و Claude Code سوف رفض هو، بينما لا هو تجاهل اختصار هو.

مرة استدعاء يحتاج معا توفير `provider` و `model`؛ عند إعداد قيمة، أب agent قيمة أو مزود يحتفظ قيمة افتراضية قدرة توفير توجيه وقت، أيضا يمكن فقط توفير دفع إدارة انتظار درجة. ساكن حالة `provider.agentRouteDefaults` في وجود وقت بنية صار مزود/نموذج أساس خط؛ أداة إعداد و نموذج حقل سوف في توجيه متبادل صلة قوي درجة دمج و تأكيد قطع توجيه مسبق فحص قبل تغطية هو. لا يوجد هذه قيمة افتراضية مزود سوف استخدام أب agent الأكثر جديد قد سجل طلب في توافق قيمة، مجددا استخدام أب درجة أول مرة طلب قبل إنشاء خيار، و إبقاء إعداد `maxTokens`. أكثر تعديل توجيه لكن لم صريح توفير دفع إدارة انتظار درجة وقت، سوف صاف حذف وراثة توجيه ذاتي لديه انتظار درجة، جعل الذي اختيار نموذج تحليل ذاتي ذات قيمة افتراضية. فوري LLM مهايئ في إنشاء فرعي agent قبل تحقق صالح توجيه. دليل عضو مورد إطار فقط توفير بناء اقتراح، لذلك مهايئ قبول وقت، نموذج يمكن استخدام لم صف خروج id.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أداة مثل أي مرآة مثل مزود دورة الحياة و تسوية تشغيل؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

واحد نسخة حينئذ هو واحد مزود إضافة واحد أداة اسم. إضافة مرآة مثل مزود دورة الحياة: أداة اسم مزود ظهور وقت تسجيل أداة، مزود مغادرة فتح وقت تحرير أداة، لذلك نفس درجة تحميل ترتيب و HMR استبدال لن يجعل أداة معلق فارغ. مباشر Agent setup صريح نقل دخول بعد لم إصدار Session، و في إصدار قبل انتظار تثبيت إتمام. من ضبط تحكم معتاد إقامة preset عبر `agent/created` استقبال كل مطابقة Agent، من ذلك Session اختيار سياسة، و انتظار عبر ذلك Context إرسال بدء تثبيت؛ تثبيت فشل سوف رفض إنشاء. مزود لا يمكن تنفيذ عدد قيمة نوع `maxDepth` أو قد إعداد LLM اختيار سوف في تركيب وقت فشل، بينما لا هو في أول مرة تفويض إرسال وقت فشل. كل أداة أثر مجال داخل الأكثر كثير واحد نسخة يمكن يملك نموذج اختيار، لأن `list_subagent_models` استخدام عام اسم.

### قبل منصة تسوية

قبل منصة استدعاء سوف انتظار `run.result`، يأخذ كل غير إتمام إنهاء سبب خريطة لـ خطأ عنوان، إلحاق مزود تشخيص و أي إبقاء تحت قدوم جزء assistant نص، و في إرجاع قبل بداية نهاية انتظار `run.dispose()`؛ عند نتيجة استلام تجميع و dispose(مورد تحرير) كل reject وقت، خروج خطأ نتيجة سوف إبقاء اثنان بند فشل.

### خلفية توجيه

مرة صفة خلفية نمط سوف تسجيل واحد عودة أب درجة كل عادي Task، ذلك done عبر طريق تسوية بدء، و في detail في إبقاء إنهاء سبب و اختياري مزود تشخيص. يمكن متابعة خلفية نمط استدعاء `ctx.subagents.startContinuable()`، هذا استدعاء في inbox قبول وقت تسوية: فرعي agent ذاتي هذا يملك ذاتي ذات جولة، لذلك هذا استدعاء حيث لا انتظار أيضا لا استلام تجميع نتيجة.

### مع سياق تغير إجراء لفظ

أداة وصف مصدر ذاتي `provider.inheritsParentContext`: كل جديد فرعي agent نيل إلى «it does not see this conversation» إجراء لفظ،fork فرعي agent نيل إلى «it does not see the current in-flight turn» إجراء لفظ، لذلك نموذج حيث لن تكرار وصف، أيضا لن حذف و لا وجود سياق.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | أداة تسجيل، دورة الحياة مرآة مثل، نمط تحليل، نتيجة تسوية |
| [`src/model-selection.ts`](src/model-selection.ts) | طلب/إعداد دمج و فوري LLM توجيه مسبق فحص |
| [`src/model-selection-settings.ts`](src/model-selection-settings.ts) | لـ جديد Session قراءة مضيف كل opt-in ضبط |
| [`src/model-selection-state.ts`](src/model-selection-state.ts) | سجل و وراثة قد قراءة قرار Session حدث |
| [`src/list-models.ts`](src/list-models.ts) | `list_subagent_models` وقت التشغيل اكتشاف أداة |

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى ماذا

عند مزود وجود وقت، بـ حالي نسخة إعداد اسم عام قد توليد افتراضي [`subagent` schema](../../../docs/tool-catalog.ar.md#deepseek-aidsh-tool-subagent). تفعيل Session سياسة سوف إضافة `provider`،`model` و `reasoning_effort`، و وراثة و اختيار إشارة جذب؛ مزود يجب دعم حمل `agentOptions`. مزود هل وراثة سياق سوف تغيير أداة وصف و نص التوجيه وصف. تفعيل خلفية نمط سوف إضافة `run_in_background`: يمكن متابعة نمط سوف سجل ذلك قيمة افتراضية لـ `true`، وقت التشغيل تسوية إشعار و صريح قبل منصة تغطية؛ مرة صفة نمط سوف سجل ذلك قيمة افتراضية لـ `false`، و استخدام `job_output` استلام تجميع أو استخدام `job_kill` إيقاف job id. عند أداة في هذا مرة تجميع أثر مجال في مرئي وقت، واحد `tool:<toolName>` توجيه النظام section سوف إشارة عرض نموذج معا بدء متبادل متبادل مستقل يمكن متابعة تفويض إرسال، في هو جمع وقت التشغيل متابعة عمل، و كما فقط عند تحت واحد خطوة حركة عمل اعتماد نتيجة وقت اختيار قبل منصة؛ أداة حد سوف معا إزالة ذلك schema و هذا مقطع إشارة جذب.

#### Token أثر

كل أب درجة طلب دعم دفع ثابت schema صار هذا؛ نموذج اختيار سوف زيادة ثلاثة عدد معامل. كل مزود نسخة زيادة واحد schema، كل يمكن متابعة نسخة أيضا زيادة واحد بسيط قصير توجيه النظام section.

#### KV Cache أثر

فقط يلزم مزود نسخة و ذلك إعداد ثابت، بادئة حينئذ إبقاء مستقر. مهايئ دليل تغير لن تغيير تعريف؛ فرعي درجة توجيه تغطية ممكن جعل fork فرعي agent لا يمكن إعادة استخدام وراثة أب درجة بادئة.

### نموذج اختيار و اكتشاف

#### نموذج يرى ماذا

Session يحمل سياسة settings تحكم نسخة سوف عام فرعي درجة LLM اختيار حقل و `list_subagent_models`. اختياري `ctx.llm` خدمة غير ممكن استخدام وقت، استدعاء سوف فشل. اكتشاف فقط إرجاع دقيق توجيه سياسة في قد تسجيل مزود و قد عام نشر نموذج؛ لم تخويل مزود سوف في استدعاء ذلك مهايئ دليل قبل يتم رفض، دقيق استعلام أيضا يجب أولا نيل دقيق، عندئذ سوف تحليل نموذج دفع إدارة قوي درجة و قيمة افتراضية. تنفيذ مرحلة مقطع سوف مستقل قوي صنع نفس سياسة.

#### Token أثر

تفعيل تركيب في وجود واحد ثابت اكتشاف schema. فقط لديه نموذج استدعاء أداة وقت، دليل محتوى عندئذ دخول transcript.

#### KV Cache أثر

مهايئ تسجيل و دليل تغير لن تغيير schema بادئة. كل اكتشاف نتيجة كل إلحاق في يمكن إعادة استخدام بادئة بعد.

### توجيه النظام

#### نموذج يرى ماذا

عند `enableRunInBackground` و `backgroundMode: continuable` معا ضبط وقت، نموذج أيضا سوف قراءة إلى `tool:<toolName>` توجيه النظام section، إشارة عرض هو يأخذ متبادل متبادل مستقل يمكن متابعة تفويض إرسال واحد بدء بدء، و في هو جمع وقت التشغيل متابعة عمل. استخدام افتراضي أداة اسم `subagent` وقت،section نص لـ:

##### أداة إشارة توجيه section

```markdown
Use subagent in the background by default. Start independent delegations together in one assistant message and continue useful work while they run. Set `run_in_background: false` only when your next action depends on that subagent's result. When a background run settles, the runtime sends you a notice containing its outcome and any final assistant message.
```

#### Token أثر

كل يمكن متابعة نسخة واحد بسيط قصير ثابت section، فقط يلزم أداة في أثر مجال داخل، حينئذ من كل أب درجة طلب دعم دفع.

#### KV Cache أثر

فقط يلزم section نص و أداة وجود ثابت، بادئة حينئذ إبقاء مستقر؛ إزالة أداة أو أكثر تعديل section سوف بناء قيام مختلف أب درجة بادئة.

### قبل منصة نتيجة

#### نموذج يرى ماذا

استدعاء سوف إبقاء وصف و نص التوجيه. نجاح وقت فقط يتضمن فرعي agent نهائي نص؛ أخرى نتيجة تغيير لـ `Error: <stop reason>`، مع بعد في وجود وقت مرفق فوق أمان مزود تشخيص، مجددا مرفق فوق أي جزء assistant نص. فرعي agent في بين خطوة لن دخول أب درجة.

#### Token أثر

نص التوجيه و نتيجة إبقاء في أب درجة تاريخ في، مباشر إلى سياق ضغط (context compaction) ؛ فرعي agent عمل سياق إبقاء في فرعي agent في.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### خلفية نتيجة

#### نموذج يرى ماذا

في إعداد يمكن متابعة نمط تحت، بدء وقت إرجاع محتوى تماما لـ `started subagent <childId>`؛ في إعداد مرة صفة نمط تحت، فإن إرجاع `started background subagent job <id>`. مرة صفة نمط تحت، عام Task واجهة توفير لاحق حالة، نهائي إخراج، إلغاء استجابة و إشعار؛ إذا نتيجة يحمل مزود تشخيص، فشل حالة detail سوف يتضمن هو. يمكن متابعة نمط تحت، هذا أداة لا إرجاع ذاتي ذات نتيجة: فرعي agent تسوية بـ خدمة مسؤول إشعار وصول أب درجة، مستقل تحميل `send_message` أداة إلقاء تمرير لاحق رسالة، بينما عبر ذلك id فحص نظر فرعي agent transcript(نص سجل) أي هو ذلك تفصيل دقيق إخراج مصدر.

#### Token أثر

تأكيد رسالة سوف يتم إبقاء؛ مرة صفة نهائي إخراج فقط في استلام تجميع أو حقن وقت دخول أب درجة تاريخ، بينما يمكن متابعة فرعي agent إخراج أبدا سوف عبر هذا أداة إرجاع——ذلك تسوية إشعار مستقل في أي أداة نتيجة وصول.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا أداة لا إرجاع أو لا قوي صنع تنفيذ ماذا؛ هو جمع هو حالي حزمة قيد.

- **خلفية تشغيل لا عبر هذا أداة عام نتيجة**——مرة صفة مهمة نهائي إخراج عبر عام Task واجهة استلام تجميع، يمكن متابعة فرعي agent إخراج إبقاء في ذلك ذاته جلسة في، حسب ذلك subagent id قراءة. تسوية إشعار سوف شرح هذا فرعي agent مثل أي انتهاء، و يحمل ذلك نهائي assistant إخراج في غير فارغ نص، لكن هو لا هو هذا مرة استدعاء قيمة راجعة، أيضا لا يمكن في هذا انتظار.
- **انتظار في مرة صفة نسخة مقارنة متأخر عندئذ اكتشاف تكرار اسم**(`TODO(subagent-dup-toolname)`)——يمكن متابعة نسخة سوف في إضافة تطبيق خلال مسبق إبقاء نص التوجيه section اسم، لكن إذا يلزم منع توقف انتظار في مرة صفة نسخة تراجع مزود تسجيل، ما زال حاجة واحد نسخة مسبق مدة اسم سجل التسجيل.
- **مع مرفق fork أداة لا يستطيع اختيار فرعي درجة LLM توجيه**——هو جمع وراثة أب درجة مزود و نموذج، جعل نسخ محادثة بادئة ما زال لديه مورد إطار إعادة استخدام KV Cache. فقط عند توجيه تغيير قدرة إبقاء إعادة استخدام أو عام محدود إعادة حساب صار هذا وقت، عندئذ إعادة تفعيل اختيار.
- **غير توجيه فرعي agent سياسة حسب نسخة ثابت**——آخر عدد persona، أداة مرور ترشيح جهاز أو عميق درجة حد أعلى حاجة آخر عدد اسم مختلف أداة.LLM اختيار اشتراط تفعيل تدريجي Session انحراف جيد، كما مزود يجب إعلان `agentOptions`؛ اثنان عدد عملية داخل مزود و DSH SDK سوف إعلان هذا قدرة، بينما ACP،Codex و Claude Code سوف رفض هو، بينما لا هو تجاهل اختصار هو.
