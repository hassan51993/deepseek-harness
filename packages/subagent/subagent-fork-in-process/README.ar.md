# @deepseek-ai/dsh-subagent-fork-in-process

[English](README.md) | العربية

## عام وصف

`dsh-subagent-fork-in-process` هو واحد عملية داخل subagent خلفية: هو بـ أب درجة قد إتمام محادثة جولة بصفة كل فرعي agent ابتدائي محتوى——فرعي agent قدرة يرى كل قد إتمام جولة، لكن نظر لا إلى إجراء في جولة، لذلك لاحق عمل يمكن في محادثة أساس أساس فوق متابعة، بينما بلا حاجة تكرار توفير محادثة محتوى. تفويض إرسال أداة بـ `fork` مزود اسم بحث إلى هو، ذلك سلوك و spawn خلفية متسق، وحيد فرق مختلف هو جلسة ابتدائي محتوى. عند فرعي مهمة تأخير متابعة حالي محادثة وقت اختيار هو؛ عند فرعي agent يجب مستقل وقت التشغيل اختيار spawn. ابتدائي محتوى هو fork وقت مرة صفة لقطة: هذا بعد أب درجة سجل أي محتوى كل لن وصول فرعي agent.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تفويض إرسال عمل يجب بناء قيام في أب درجة محادثة لـ فوق وقت، تركيب هذا خلفية. معتاد استخدام مسار و spawn نفسه: تحميل subagent خدمة و هذا خلفية، مجددا يأخذ `dsh-tool-subagent` لـ صنف تفويض إرسال أداة إشارة نحو `fork` مزود.

### أي وقت اختيار

عند فرعي agent حاجة محادثة قد إتمام جولة وقت——لاحق قسم تحليل، مراجعة فحص، تأخير متابعة——اختيار fork. عند فرعي agent ينبغي كل جديد بدء وقت اختيار spawn؛ عند فرعي agent لا يستطيع مشترك هذا عملية وقت اختيار عملية خارج خلفية. ابتدائي محتوى فقط نقل تمرير محادثة تاريخ: فرعي agent ما زال نيل نيل كل جديد أداة أثر مجال، كما لا وراثة أب درجة أي إذن.

### ابتدائي محتوى حد

ابتدائي محتوى توقف في أب درجة الأكثر بعد واحد قد إتمام جولة.subagent بدء وقت، أب درجة حالي أداة استدعاء جولة ما زال في إجراء، لذلك هذا إجراء في جولة أبدا سوف يتم يتضمن؛ في رقم واحد قد إتمام جولة قبل، ابتدائي محتوى لـ فارغ، فرعي agent سلوك و كل جديد spawn نفسه.

### الأكثر صغير إعداد

أولا تحميل subagent خدمة و هذا خلفية، مجددا إعداد واحد تفويض إرسال أداة. هذا تركيب كشف من fork دعم دعم `subagent` أداة:

```yaml
- name: '@deepseek-ai/dsh-subagent'
- name: '@deepseek-ai/dsh-subagent-fork-in-process'
- name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: fork
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `fork` | تسجيل إلى `ctx.subagents` مزود اسم |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-subagent-fork-in-process) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### مرة fork تفويض إرسال سوف فعل ماذا

مرة أداة استدعاء بدء واحد بـ قد إتمام جولة لـ ابتدائي محتوى فرعي agent، و انتظار ذلك نتيجة: فرعي agent قدرة يرى قطع حتى أب درجة الأكثر بعد واحد قد إتمام جولة محادثة، في ذاتي لديه جلسة في عمل، أب درجة فقط استقبال ذلك نهائي إخراج——إلغاء، رفض،token حد أعلى قطع قطع أو بدء يتم رفض وقت فإن استلام إلى خروج خطأ أداة نتيجة. ابتدائي محتوى في بدء وقت فقط التقاط مرة؛ هذا بعد أب درجة جولة أبدا سوف وصول فرعي agent.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية خلف بعد تصميم قرار، و[استخدام هذه الحزمة](#use-this-package) في سلوك مصدر.

### تصميم إدارة فكرة

و spawn فرق مختلف فقط لديه واحد موضع، كما بـ بيانات جدول بلوغ: خلفية حساب حساب أب درجة سجل قد إعداد مستو قد إتمام جولة بادئة، و يأخذ هو بصفة فرعي agent جلسة ابتدائي محتوى تسليم إعطاء مشترك عملية داخل مشغل. من في فعلي ترتيب رقم انتظار في عدد مجموعة تحت علامة، بادئة بداية نهاية هو ذاتي ترتيب رقم صفر بدء دمج قاعدة ابتدائي محتوى؛ مشغل سجل ذلك طويل درجة، جعل نتيجة قراءة جهاز لن يأخذ بصفة ابتدائي محتوى أب درجة رسالة خطأ إقرار لـ فرعي agent إخراج.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | مزود تسجيل: بادئة حساب حساب،`Config` schema، قدرة إعلان |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة، متبادل صلة اتفاق في الذي تابع seam قوي صنع تنفيذ. |

### تشغيل مسار

`start` وقت، من أب درجة حدث سجل في قطع أخذ قطع حتى الأكثر بعد واحد `turn/end` بادئة؛ مشترك مشغل مع بعد بـ هذا ابتدائي محتوى إنشاء فرعي agent، تطبيق نفسه persona، أداة مرور ترشيح جهاز و بنية تحويل إخراج ضبط، قيادة واحد بند مهمة، قراءة فرعي agent ذاته نهائي إخراج، و تنفيذ dispose(مورد تحرير) بـ انتظار كل عمل تماما توقف مستقر. هذا مزود إعلان `agentOptions`، و و spawn نفسه إخراج، عميق درجة، مرور ترشيح و persona قدرة.`prepareContinuable` في إنشاء وقت فقط التقاط مرة بادئة، لأن هذا بادئة سوف يصبح فرعي agent ذاته حمل دائم حفظ transcript(نص سجل) واحد جزء.

### دورة الحياة ربط

base تركيب حزمة و ACP(Agent Client Protocol)/headless عرض مثال في تفويض إرسال أداة فوق يأخذ هذا مزود ربط لـ `backgroundMode: one-shot`،CLI(أمر سطر واجهة) مسبق ضبط فإن اختيار `continuable`. اثنان من كل إبقاء وراثة طلب بادئة: أب درجة و فرعي درجة نيل نيل تعريف و ترتيب نفسه رسالة أداة، يمكن متابعة فرعي درجة أب درجة ID و إرجاع إشارة توجيه يقع في وراثة تاريخ بعد ابتدائي مستخدم مهمة في (رؤية[إبقاء fork ذاكرة مؤقتة Agent Note](../../../.agents/notes/implemented/architecture/2026-08-10-fork-children-stay-one-shot.ar.md)).

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent تاريخ و حزمة شبكة

#### نموذج يرى ماذا

فرعي agent أولا استقبال من أب درجة قد إعداد مستو قد إتمام جولة بنية صار بادئة، مجددا تدريجي حرف استقبال جديد مهمة محتوى. إعداد persona سوف في فرعي agent كل جديد أثر مجال في حجب حجب نص التوجيه نص؛ أداة حد سوف مرور ترشيح ذلك عام بروتوكول schema، يمكن تنفيذ أداة فحص بحث و PTC mode SDK ربط، لكن لا أثر مستقل إشارة توجيه محتوى. أب درجة أداة عرض و إذن لن يتم وراثة؛ اختياري بنية تحويل إخراج طلب سوف إضافة فقط يخص فرعي agent اتفاق؛ أب درجة حالي إجراء في جولة سوف يتم ترتيب حذف.

#### Token أثر

fork سوف يأخذ إبقاء قد إتمام تاريخ نسخ إلى فرعي agent طلب في، فرعي agent مع بعد مستقل تراكم تراكم ذاتي ذات token.persona سوف تغيير تكرار نص التوجيه صار هذا؛ مرور ترشيح سوف تغيير schema أو توليد SDK صار هذا؛ أول جولة fork لا يوجد وراثة تاريخ.

#### KV Cache أثر

في مزود و نموذج نفسه قبل رفع تحت، فرعي agent يمكن إعادة استخدام وراثة تدريجي بايت نفسه بادئة.persona، أداة مرور ترشيح، توليد SDK أو توجيه تغير ممكن في وراثة تاريخ قبل جعل إعادة استخدام بطلان؛ لاحق فرعي agent تاريخ فقط إلحاق. يمكن متابعة رسالة لن زيادة فرعي درجة مخصص تابع توجيه النظام منطقة مقطع أو أداة schema؛ أب درجة ID و إرجاع إشارة توجيه في ابتدائي مستخدم مهمة في يقع في وراثة تاريخ بعد (رؤية[إبقاء fork ذاكرة مؤقتة Agent Note](../../../.agents/notes/implemented/architecture/2026-08-10-fork-children-stay-one-shot.ar.md)).

### أب درجة أداة نتيجة (بين وصل)

#### نموذج يرى ماذا

أب درجة فقط عبر `dsh-tool-subagent` استقبال فرعي agent ذاته نهائي إخراج، لا استقبال وراثة بادئة أو في بين عمل.

#### Token أثر

أب درجة إدخال زيادة واحد أخذ قرار في بيانات نهائي نتيجة، و إبقاء إلى سياق ضغط (context compaction) لـ توقف.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أي وقت اختيار هذا خلفية هو خطأ؛ هو جمع هو حالي حزمة قيد.

- **ابتدائي محتوى هو مرة صفة لقطة**——فرعي agent فقط قدرة يرى fork وقت أب درجة قد إتمام جولة، نظر لا إلى أب درجة هذا بعد سجل أي محتوى؛ لن فوري مشترك سياق.
- **fork دورة الحياة سياسة بسبب تركيب بينما مختلف**——base تركيب حزمة و ACP/headless عرض مثال استخدام مرة صفة fork،CLI مسبق ضبط استخدام يمكن متابعة fork. اثنان من كل بسبب أب درجة و فرعي درجة رسالة تعريف تدريجي بايت نفسه بينما يجعل وراثة بادئة إبقاء يمكن إعادة استخدام؛ صريح persona، أداة مرور ترشيح، توليد SDK أو توجيه تغير ما زال يمكن كسر تالف متبادل انتظار صفة. إدارة من رؤية[إبقاء fork ذاكرة مؤقتة Agent Note](../../../.agents/notes/implemented/architecture/2026-08-10-fork-children-stay-one-shot.ar.md).
- **مع مرفق fork أداة لا عام فرعي درجة LLM(كبير لغة نموذج) توجيه اختيار**——هو جمع وراثة أب درجة مزود و نموذج، جعل نسخ تاريخ ما زال لديه مورد إطار إعادة استخدام KV Cache. في بعض بند تعديل قدرة إبقاء إعادة استخدام أو عام محدود إعادة حساب صار هذا قبل، توجيه اختيار إبقاء منع استخدام؛[نموذج اختيار توجيه Agent Note](../../../.agents/notes/implemented/feature/2026-08-18-model-selected-subagent-routes.ar.md) شرح هذا بند حد.
