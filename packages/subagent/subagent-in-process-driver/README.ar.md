# @deepseek-ai/dsh-subagent-in-process-driver

[English](README.md) | العربية

## عام وصف

`dsh-subagent-in-process-driver` هو اثنان عدد عملية داخل subagent خلفية مشترك استخدام تشغيل مشغل: هو عبر مضيف agent(ذكي جسم) عمل مصنع إنشاء واحد فرعي agent، تطبيق حسب فرعي agent تحديد صنع، يأخذ واحد بند مهمة قيادة إلى إتمام، و بـ مفرد واحد تماما توقف مستقر dispose(مورد تحرير) مسار إرجاع فرعي agent ذاته نهائي إخراج.spawn استدعاء هو وقت لا نقل دخول جلسة ابتدائي محتوى؛fork استدعاء هو وقت نقل دخول أب درجة قد إتمام جولة بادئة. هو هو مكتبة بينما غير مستقل وظيفة: مزود خلفية استدعاء `startInProcessRun`، تركيب في لا يوجد أي شرق غرب إعداد هو. قراءة قراءة هذا صفحة يمكن إدارة حل اثنان عدد عملية داخل خلفية مشترك تشغيل دورة الحياة.

## استخدام هذه الحزمة

أنت عبر مزود خلفية بينما غير تركيب وصول هذه الحزمة:`dsh-subagent-spawn-in-process` و `dsh-subagent-fork-in-process` كل منها استدعاء `startInProcessRun(request, options)` و يملك ذلك خارج محيط واحد قطع. هذا صفحة سجل اثنان من مشترك دورة الحياة، جعل أنت قراءة فهم واحد خلفية سلوك بعد يكفي دفع قطع آخر عدد.

### مرة تشغيل توفير ماذا

مرة استدعاء بدء و قيادة واحد مرة صفة فرعي agent. استدعاء صرف الآن معنى طعم حال فرعي agent قد إصدار إلى `ctx.agents`، استدعاء جهة يملك إرجاع تشغيل؛ بدء يتم رفض وقت، لم إصدار إنشاء قد تماما توقف مستقر، لذلك لن لديه إنشاء إلى واحد نصف فرعي agent تخزين نشط. تشغيل كشف فرعي agent id و في خط agent، واحد `result` promise، و واحد `dispose()`——هو سوف إيقاف حلقة، إزالة agent و جلسة، و سحب إلغاء أثر مجال داخل تسجيل.

### وحيد إدخال

`InProcessRunOptions` شكل لـ `{ seed?: SessionEvent[] }`——fork قد إعداد مستو أب درجة حدث ابتدائي محتوى.spawn حذف هذا قيمة؛fork توفير قد إتمام جولة بادئة و سجل ذلك طويل درجة، جعل نتيجة قراءة جهاز لن يأخذ بصفة ابتدائي محتوى أب درجة رسالة خطأ إقرار لـ فرعي agent إخراج.

### فرعي agent نيل نيل ماذا

فرعي agent نيل نيل أب درجة عمل دليل/جلسة جدول نظام، حذف غير `request.agentOptions` تغطية، لا فإن وراثة أب درجة مزود، نموذج، دفع إدارة قوي درجة و إخراج token حد أعلى. هو نيل نيل كل جديد مسطح مستو تسجيل أثر مجال: أب درجة أداة حد و إذن لن يتم استيراد. مرة تشغيل سوف يأخذ أب درجة صريح صندوق رملي تغطية بند و `'never'` مراجعة دفعة تثبيت تحديد حمل دخول فرعي agent، و في فرعي agent ابتدائي جولة داخل إلحاق واحد نسخة كل مرة تشغيل وصف رمز.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مشغل دورة الحياة اتفاق و بنية تحويل إخراج وقت التشغيل؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### بدء اتفاق

مشغل حسب التالي ترتيب تشغيل:

1. تحقق أب درجة عميق درجة و اختياري قطعا مقابل `maxDepth`، لكن بعد يأخذ فرعي درجة عميق درجة دفع توجيه لـ أب درجة عميق درجة إضافة واحد، و حفظ دائم إلى فرعي درجة جلسة header.
2. عبر مضيف agent عمل مصنع إنشاء فرعي agent، و يأخذ استدعاء جهة مطلوب إشارة نقل دخول إنشاء أمر خدمة.
3. في هذا أمر خدمة لم إصدار ضبط نافذة داخل، تثبيت طلب persona، أداة حد و بنية تحويل إخراج وقت التشغيل.
4. إصدار فرعي agent، إبقاء إرجاع جملة مقبض، و قيادة واحد بند مهمة.
5. من كامل ذاتي لديه تشغيل في قراءة فرعي agent ذاته إخراج——الأكثر بعد واحد بند غير فارغ assistant رسالة، إذا بلا فإن أخذ ذلك تراكم تراكم assistant نص——و نهائي حفظ دائم جولة سبب، و ترتيب حذف أي fork ابتدائي محتوى.

### إلغاء و كل حق

مطلوب طلب إشارة معا تغطية بدء مرحلة مقطع و فوري تشغيل. إصدار قبل، إنشاء أمر خدمة سوف مراقبة هو، تراجع و رفض؛ مشغل في إصدار بعد مجددا فحص مرة بـ إزالة حذف تسليم وصل تنافس حالة، لكن بعد تثبيت الأكثر صغير تحويل فوري تشغيل مستمع. صرف الآن بعد، استدعاء جهة يملك هذا تشغيل: مزود إضافة إزالة لن سحب إلغاء هو؛`dispose()` سوف إزالة في توقف مستمع، سجل إلغاء، و تفويض حمل إعطاء جملة مقبض مرور تسجيل ذاكرة تحويل تماما توقف مستقر أمر خدمة——بعد من إيقاف حلقة، إزالة agent و جلسة، و سحب إلغاء أثر مجال داخل تسجيل. إلغاء مسار سوف وصل إدارة كل بعد لم إتمام إجراء في نتيجة، و سوف ذلك تقرير إبلاغ لـ `aborted`؛ قد إتمام جولة ما زال إبقاء إتمام حالة.

### بنية تحويل إخراج

`attachStructuredRuntime(childCtx, schema)` سوف في فرعي agent أثر مجال في تثبيت كامل اتفاق:`structured_output` أداة حسب طلب schema تحقق و مؤقت تخزين نموذج قيمة؛ يقع في نهاية ذيل، ترتيب لـ 9900 first-party توجيه النظام مقطع إبلاغ إبلاغ فرعي agent هذا أداة استدعاء حينئذ هو نهاية حالة جواب سجل؛`tools/result` مراقبة جهاز فقط في هذا مرة تنفيذ مرجعي نهائي أداة نتيجة نجاح بعد إيداع مؤقت تخزين قيمة، يشمل PTC mode فرعي قسم إرسال خارج طبقة `run_code` نتيجة؛ مفرد ضبط أداة منع حماية سوف في التقاط بعد منع توقف لاحق استدعاء. صحيح معتاد انتهاء لكن بداية نهاية لم إيداع مطلوب قيمة جولة سوف تقرير إبلاغ `error`؛ مشغل لن إعادة تلميح. كل تسجيل كل مرفق حال في فرعي agent fiber، و مع ذلك واحد نفس إزالة فقد.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent طلب

#### نموذج يرى ماذا

مشترك مشغل يأخذ مهمة تدريجي حرف بصفة فرعي agent مستخدم رسالة إرسال؛ إذا لديه طلب، أيضا سوف في لم إصدار فرعي agent كل جديد أثر مجال في حجب حجب persona، و حد عام أداة schema، فحص بحث، تنفيذ و PTC mode SDK ربط. أب درجة حد لن يتم وراثة. أداة إشارة توجيه إضافة يمكن استخدام تجميع scope حذف غير ممكن استخدام أداة إشارة توجيه؛ مشغل لن تعديل كتابة مهمة معنى ساكن حالة مقطع سقوط.spawn لا توفير تاريخ؛fork توفير ذلك قد إعداد مستو ابتدائي محتوى.

#### Token أثر

فرعي agent إدخال و أب درجة عزل، و مع فرعي agent ذاته خطوة زيادة طويل.persona سوف تغيير تكرار نص التوجيه نص؛ مرور ترشيح سوف تغيير schema أو توليد SDK صار هذا، استخدام scope إشارة توجيه محتوى أيضا سوف مع مرئي قدرة تغير.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة متبادل متبادل مستقل. فرعي agent لاحق تاريخ فقط إلحاق، بينما persona، أداة مرور ترشيح، توليد SDK، مزود أو نموذج تغير سوف بناء قيام مختلف فرعي agent بادئة.

### بنية تحويل إخراج توجيه النظام،schema و نتيجة

#### نموذج يرى ماذا

بنية تحويل تشغيل سوف إضافة تحت جهة بنية تحويل إخراج إشارة أمر، و إضافة فرعي agent أثر مجال `structured_output` تعريف، ذلك معامل استخدام طلب schema، دقيق وصف لـ `Report your final structured result. Call this exactly once, when your answer is complete; the arguments must match this tool's parameter schema exactly.` هذا فقط وقت التشغيل وجود تعريف لا في قد توليد و مع منتج إصدار[أداة حزمة بحث جذب](../../../docs/tool-catalog.ar.md#tool-package-map) في. ذلك مواصفة تأكيد قيمة هو `{ recorded: true }`، تصيير لـ `Structured output recorded.`؛ لاحق استدعاء سوف تغيير لـ ``Error: structured output already recorded: the run is complete, so `<tool>` is not executed``.

##### بنية تحويل إخراج إشارة أمر

```markdown
When you have your final answer, you MUST report it by calling the `structured_output` tool with arguments matching its parameter schema exactly. Do not finish with a plain text answer: only the tool call counts as your result.
```

#### Token أثر

ثابت إشارة أمر و قدرة إنتاج token فقط من هذا فرعي agent تحمل تحمل. نتيجة نص دخول فرعي agent تاريخ، بينما فقط لديه التقاط قيمة سوف يصبح أب درجة نتيجة.

#### KV Cache أثر

فقط يلزم بنية تحويل إخراج إشارة أمر و schema ثابت، فرعي agent داخلي بادئة حينئذ إبقاء مستقر. أكثر تعديل schema أو قدرة ممكن من هذا مبكر مدة قطعة مقطع بدء جعل فرعي agent ذاكرة مؤقتة بطلان؛ نتيجة سوف قسم آخر إلحاق إلى فرعي agent و أب درجة تاريخ في.

### أب درجة بدء خطأ (بين وصل)

#### نموذج يرى ماذا

عبر `dsh-tool-subagent`، بلا فاعلية عميق درجة حالة سوف دقيق تغيير لـ `Error: agent subagentDepth must be a non-negative safe integer`،`Error: subagent child depth exceeds the safe-integer range` أو `Error: subagent depth <attempted> exceeds maxDepth <max>`. إصدار قبل إلغاء في توقف سبب سوف عبر سجل التسجيل `Error: <message>` حزمة تركيب نقل تمرير.

#### Token أثر

بدء نجاح وقت لـ صفر token؛ فقط لديه فشل أب درجة أداة استدعاء سوف إبقاء هذا مقطع نص.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### أب درجة نتيجة (بين وصل)

#### نموذج يرى ماذا

مشغل فقط رفع أخذ فرعي agent ذاته الأكثر بعد assistant إخراج أو التقاط بنية تحويل قيمة؛ بصفة ابتدائي محتوى أب درجة رسالة و فرعي agent في بين عمل لن يصبح نتيجة.

#### Token أثر

أب درجة عبر مستهلك استقبال واحد اعتماد بيانات نتيجة؛ أخرى كل فرعي agent token كل إبقاء في فرعي agent جلسة في.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح عملية داخل مرة صفة تشغيل لا يستطيع فعل ماذا؛ هو جمع هو حالي حزمة قيد.

- **تشغيل لا عام `sendMessage`/`resume`**——عملية داخل مرة صفة تشغيل لا أداة تجهيز هذه اختياري وقت التشغيل قدرة.
- **بنية تحويل التقاط فقط قبول `defineTool` schema فرعي تجميع**——لا دعم حمل JSON Schema بنية صنع سوف في فرعي agent إنشاء قبل فشل؛ حاجة أكثر واسع schema مفردات مزود يجب اعتماد مختلف وقت التشغيل.
