# @deepseek-ai/dsh-subagent-claude-code

[English](README.md) | العربية

## عام وصف

عند تفويض إرسال مهمة ينبغي في أب مساحة العمل في بـ كل جديد، بلا شخص قيمة حراسة Claude Code جلسة وقت التشغيل، تثبيت هذا عدد Profile Bundle. كل مرة تشغيل قبول واحد ذاتي يتضمن نص مهمة، و إرجاع نهائي جواب سجل أو أمان فشل تشخيص؛ دفع إدارة، أداة عبر معلومة،stderr، استخدام كمية معلومة و مساحة العمل فرق مختلف لن دخول أب Session.Claude أصلي ضبط و هوية تحقق متابعة هو مرجعي مصدر، بينما Profile إعداد اختيار نموذج، بيئة و `permissionMode`. إبرة مقابل منصة قفل تحديد وقت التشغيل فقط في حاجة وقت بدء، و كما أبدا سوف رجوع إلى مضيف `claude` يمكن تنفيذ ملف. عند عزل و حقيقي Claude Code سلوك مقارنة متابعة وصل أو تلميح أكثر إعادة يلزم وقت، اختيار هذه الحزمة.

## استخدام هذه الحزمة

عند تفويض إرسال ينبغي بـ أب درجة مساحة العمل في حقيقي Claude Code جلسة وقت التشغيل، تركيب هذا مزود. معتاد استخدام مسار هو صريح: يأخذ Bundle تثبيت دخول Profile، اختياري أرض إعداد مزود سطر، و عبر تفويض إرسال أداة سطر يأخذ هو كشف إعطاء نموذج.

### تثبيت Bundle

يأخذ حزمة تثبيت دخول هدف Profile، لكن بعد إعادة بدء هذا Profile. تثبيت سوف يأخذ قفل تحديد Agent SDK و واحد توافق منصة CLI تحميل حمل حمل دخول Profile؛ إعلان patch طبقة فقط تسجيل راحة نوم مزود، لا بدء أي Claude عملية.

```sh
dsh plugin --profile <name> add @deepseek-ai/dsh-subagent-claude-code
dsh plugin --profile <name> remove @deepseek-ai/dsh-subagent-claude-code
dsh --profile <name>
```

إزالة حزمة بعد، تحت مرة Profile بدء سوف سحب عودة مزود و ذلك خاص وقت التشغيل إغلاق حزمة. تثبيت قرار Host متاح صفة، بينما لا هو نموذج إذن: نموذج فقط قدرة عبر أنت تركيب تفويض إرسال أداة سطر لمس بلوغ مزود.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `claude-code` | `ctx.subagents` فوق غير فارغ تسجيل اسم؛ كل قد تركيب نسخة كل حاجة وحيد قيمة |
| `model` | Claude أصلي ضبط | لـ هذا مزود نسخة كل مرة تشغيل ثابت اختياري غير فارغ نموذج اسم؛ حذف وقت لا إرسال SDK تغطية |
| `env` | `{}` | تراكم إضافة في قد تنظيف اعتماد أب بيئة لـ فوق صريح SDK/CLI بيئة |
| `permissionMode` | `dontAsk` | لـ هذا مزود نسخة كل مرة تشغيل ثابت أصلي غير تفاعل إذن سياسة |
| `disposeGraceMs` | `3000` | مشترك managed-range owner كل إنهاء طبقة درجة بين عرض حد |

| `permissionMode` قيمة | أصلي سلوك |
|---|---|
| `dontAsk` | لا نابض خروج تلميح، مباشر رفض بعد لم نيل تخويل عملية |
| `acceptEdits` | قبول ملف تحرير؛ ذلك بقية إذن تلميح من بلا شخص قيمة حراسة عودة ضبط رفض |
| `auto` | من Claude Code أصلي تصنيف جهاز سماح أو رفض إذن طلب |
| `plan` | استخدام أصلي قاعدة تخطيط نمط، رفض تنفيذ مراجعة دفعة، و يأخذ كامل خطة بصفة نهائي جواب سجل إرجاع |
| `bypassPermissions` | صريح ضبط SDK خطر خطر تأكيد و قفز مرور إذن فحص |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-subagent-claude-code) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر. قد إعداد `model` سوف أصل مثال نقل إعطاء هذا مزود نسخة كل مرة query؛ حذف وقت إبقاء أصلي نموذج اختيار. أداة لديه سند إثبات خاص سمة بيئة متغير سوف في صريح `env` تغطية توليد فاعلية قبل يتم إزالة، لذلك توفير عملية فرعية استخدام API مفتاح يجب في هذا إعداد في صريح توفير. مزود حذف SDK `settingSources` خيار، لذلك Claude Code سوف متبادل مقابل في أب جلسة cwd قراءة مضيف آلة معتاد قاعدة مستخدم، مشروع و محلي ضبط. هو لن نسخ أو مرور ترشيح هذه ملف، إنشاء أو تعديل تسجيل تسجيل حالة، فحص `PATH`، أيضا لن رجوع إلى مضيف `claude` يمكن تنفيذ ملف.

### كشف أداة

كل تفويض إرسال أداة سطر إشارة اسم واحد مزود، و حاجة مستقل `toolName`، لذلك نموذج يرى هو ساكن حالة أداة، بينما لا هو حركة حالة مزود اختيار جهاز. كامل Agent Preset يحمل مقابل افتراضي أداة سطر و ضبط `disabled: true`؛ نسخ واحد preset بعد حذف هذا حقل، يكفي فقط نحو من هذا فرعي هذا تجميع agent(ذكي جسم) كشف `subagent_claude_code`.

```yaml
- id: jobs
  name: '@deepseek-ai/dsh-jobs-local'
- id: tool-jobs
  name: '@deepseek-ai/dsh-tool-jobs'
- id: tool-subagent-claude
  name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: claude-code
    toolName: subagent_claude_code
    backgroundMode: one-shot
    maxDepth: provider-managed
```

`one-shot` سياسة سوف يجعل حذف `run_in_background` أو نقل دخول `false` استدعاء متابعة في قبل منصة انتظار، بينما صريح نقل دخول `true` سوف إرجاع من أب agent يملك job id، توفير `job_output` أو `job_kill` استخدام؛base host(أساس أساس مضيف) و كامل preset قد توفير عام عمل عمل سجل التسجيل و تحكم أداة.

### أنت سوف نيل إلى ماذا

قبل منصة استدعاء سوف يأخذ صارم إطار نهائي Claude Code جواب سجل تسليم إعطاء نموذج؛ تشغيل فشل وقت فإن إرجاع حمل إيقاف سبب و اختياري أمان تشخيص خطأ. خلفية استدعاء أولا إرجاع job id؛ مع بعد عام عمل عمل تحكم وجه سوف إرسال بلوغ إتمام إشعار، و عبر `job_output` عام نفس نهائي جواب سجل أو فشل حالة.Claude Code دفع إدارة، أداة نشط حركة، في بين رسالة،stderr و مساحة العمل فرق مختلف أبدا سوف دخول أب درجة جلسة.

### فشل و استعادة

حذف optional dependencies، حالي منصة لا تلقي دعم حمل أو الذي اختيار تحميل حمل ناقص تثبيت سوف يجعل مزود إبقاء راحة نوم، و في رقم مرة تفويض إرسال وقت في SDK بدء حد تقرير إبلاغ أمان `query-start` / `unknown` فشل واقع؛ لا وجود مضيف CLI رجوع. أصلي منتج خطأ فقط إبقاء في داخلي cause سلسلة و مزود Host سجل في. يتم إلغاء تشغيل بـ `aborted` تسوية.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير مزود مثل أي قيادة حقيقي Claude Code CLI، و يمكن مراقبة سلوك من أي بينما قدوم؛ كامل اتفاق رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

- **كل مرة تشغيل واحد كل جديد query.** كل مرة تشغيل كل يملك مستقل SDK query، إلغاء تحكم جهاز،CLI عملية و لا حفظ دائم منتج جلسة؛ لا يوجد متابعة وصل، استعادة أو حوض تحويل.
- **أصلي ضبط هو مرجعي.** مزود لذا معنى حذف SDK `settingSources` خيار، لذلك Claude Code قراءة مضيف آلة معتاد قاعدة مستخدم، مشروع و محلي ضبط؛ اختياري `model` و مطلوب `permissionMode` هو فقط لديه query درجة تغطية.
- **لحظة معنى بلا شخص قيمة حراسة.** `AskUserQuestion` يتم منع استخدام، حذف bypass نمط خارج إذن تلميح كل سوف يتم رفض، لذلك query أبدا سوف انتظار مستخدم واجهة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: إعداد schema، مزود تسجيل |
| [`src/run.ts`](src/run.ts) | SDK query دورة الحياة، نتيجة قبول و إذن معالجة |
| [`src/process.ts`](src/process.ts) | dispose(مورد تحرير) وقت managed-range تدريجي درجة إنهاء |
| [`cordis.patch.yml`](cordis.patch.yml) | تسجيل راحة نوم مزود Profile patch طبقة |

### تشغيل مسار

مرة بدء فقط قبول غير فارغ نص كتلة تسلسل، و أصل حسب أب جلسة تحديد فرعي درجة cwd. هو إنشاء خاص `AbortController`، استخدام دقيق تجميع وصل مهمة استدعاء رسمي جهة SDK `query()`، و فقط في SDK custom-spawn خطاف قد توفير من عملية فرعية seam إدارة نشط حركة CLI جملة مقبض بعد إصدار تشغيل. مزود كامل تكرار بديل رسالة تدفق، فقط قبول ممتلئ كاف `subtype: "success"`،`is_error: false` كما `result` غير فارغ أبيض، مع بعد مكرر صحيح معتاد انتهاء `result` رسالة. ذلك بقية واحد قطع نتيجة كل خريطة لـ حمل ثابت صنف آخر `error` تشخيص، تسمية دورة الحياة مرحلة مقطع و قد مراقبة قياس عملية نتيجة——صنف آخر تجميع دمج رؤية [`src/run.ts`](src/run.ts). محلي إلغاء سوف في نتيجة تنافس حالة في فوز خروج و خريطة لـ `aborted`، كما لا مرفق حمل فشل تشخيص.

<a id="model-experience"></a>
## تجربة النموذج

### فرعي درجة طلب

#### نموذج يرى ماذا

Claude Code فرعي درجة سوف في واحد كل جديد SDK query في استقبال مستقل نص مهمة. هو مساحة العمل هو أب جلسة cwd؛ الذي اختيار مزود نسخة سوف ثابت قد إعداد نموذج، بيئة و غير تفاعل إذن نمط، بينما حذف نموذج و ذلك بقية منتج ضبط قدوم ذاتي Claude أصلي إعداد. يمكن تنفيذ إصدار قدوم ذاتي Bundle قفل تحديد SDK منصة تحميل حمل.

#### Token أثر

فرعي درجة يحتاج لـ مستقل Claude Code سياق و query تحمل تحمل token صار هذا. فرعي درجة token لن دخول أب درجة سياق.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة متبادل متبادل مستقل. قدرة لا إعادة استخدام فقط أخذ قرار في Claude Code ذاته نموذج، إشارة أمر، أداة، أصلي ضبط و كل جديد query.

### أب درجة ضبط درجة و نتيجة (بين وصل)

#### نموذج يرى ماذا

عبر `dsh-tool-subagent`، قبل منصة استدعاء سوف يجعل أب درجة نموذج يرى رمز دمج صارم إطار نجاح شرط Claude Code نهائي جواب سجل؛ إذا نتيجة لم إتمام، خطأ في سوف يتضمن إنهاء سبب و اختياري أمان تشخيص. هذا تشخيص يمكن منطقة قسم خشن حبة درجة سطر حركة صنف آخر، دورة الحياة مرحلة مقطع و قد مراقبة قياس عملية نتيجة، بينما لا نسخ أصلي منتج نص أو إصدار مخصص تابع subtype اسم. خلفية استدعاء سوف أولا إرجاع job id؛ مع بعد عام عمل عمل تحكم وجه سوف إرسال بلوغ إتمام إشعار، عبر `job_output` عام نفس نهائي جواب سجل أو فشل حالة تفصيل حال، و سماح `job_kill` طلب إلغاء.Claude Code دفع إدارة، أداة نشط حركة، في بين رسالة،stderr، مساحة العمل فرق مختلف، استخدام كمية معلومة، منتج معرف رمز، أداة إدخال و أصلي بروتوكول تحميل حمل متساو لن نسخ إلى أب جلسة.

#### Token أثر

قبل منصة إدخال سوف زيادة أداة نتيجة في إبقاء نهائي جواب سجل أو خطأ محتوى. خلفية إدخال أيضا سوف يتضمن بدء تأكيد، إتمام إشعار، و `job_output`،`job_kill` أو لاحق حالة نتيجة؛ فرعي مهمة token ما زال لن دخول أب درجة سياق. هذا مزود ذاته لا إضافة أب درجة أداة schema.

#### KV Cache أثر

فقط إلحاق: قبل منصة سوف في يمكن إعادة استخدام أب طلب بادئة بعد زيادة واحد نتيجة، خلفية فإن سوف متابعة إلحاق Job بدء تأكيد، إشعار و لاحق تحكم أو استلام تجميع نتيجة. خلفية ضبط درجة ممكن زيادة واحد من إشعار نداء تنبيه جولة، لكن هذه رسالة كل لن تعديل كتابة أكثر مبكر بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا مزود أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام Claude Code مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مرة تشغيل متساو جديد بناء واحد query و واحد عملية**——لا دعم حمل متابعة وصل، استعادة، حوض تحويل، دخول درجة تدفق أو منتج جلسة حفظ دائم.
- **ساكن حالة اختيار نسخة**——Profile بند إعداد ثابت مزود اسم، اختياري نموذج و أداة ربط؛ استدعاء لا يمكن حركة حالة اختيار أو تعديل مزود و نموذج، بينما كما كل عام أداة كل حاجة وحيد `toolName`.
- **مضيف ضبط متعمد إبقاء مرجعي**——حذف `model` وقت من مشروع و مستخدم ضبط اختيار نموذج؛ أصلي ضبط بداية نهاية إبقاء ذلك بقية أداة و سلوك، هذا مزود لا توفير مرور مرور غربلة اختيار أو و مضيف بيئة عزل إنتاج نمط.
- **هوية تحقق و حساب مستخدم حالة ما زال من أصلي آلية إدارة**——Bundle سوف توفير CLI، لكن لن إنشاء حساب مستخدم، تسجيل تسجيل أو تعديل كتابة Claude ضبط؛ إعداد و هوية تحقق فشل سوف عام ذلك دورة الحياة مرحلة مقطع و أمان `unknown` رجوع، بينما لن زيادة مفرد وحيد عام تصنيف.
- **تفويض إرسال وقت يجب وجود SDK منصة تحميل حمل**——حذف optional dependencies تثبيت، لا تلقي دعم حمل منصة و ناقص أو ضرر تالف تحميل حمل كل سوف في رقم مرة query وقت فشل؛ لن رجوع إلى مضيف CLI.
- **لا يوجد شخص عمل تفاعل مسار**——`AskUserQuestion` يتم منع استخدام، إذن تلميح سوف يتم رفض،MCP elicitation سوف يتم رفض، منع سد محادثة سوف بـ رفض طريقة فشل بينما لن تعليق بدء.
- **assistant تحميل حمل فقط يتضمن نهائي نص**——فشل تشغيل يمكن مقدار خارج عام مستقل أمان تشخيص؛ دفع إدارة، في بين رسالة، أداة عبر معلومة، استخدام كمية معلومة،stderr و مساحة العمل فرق مختلف ما زال فقط إبقاء في منتج داخلي، عام Job id، إشعار و حالة قدوم ذاتي مشترك عمل عمل وقت التشغيل.
- **لا يوجد اختياري مشترك قدرة**——مقابل في هذا مزود، مشترك خدمة سوف رفض `agentOptions`، إخراج schema، فرعي مهمة زاوية لون ضبط تحديد، أداة غربلة اختيار و harness عميق درجة قوي صنع قيد.
- **لا يوجد حسب فعلي مرور مرور وقت إطلاق مهلة أو فرعي أثر تراجع**——طويل وقت تشغيل عمل من استدعاء جهة إلغاء، كما إلغاء قبل قد أكثر تعديل ملف أو خارجي نظام لن استعادة أصل حالة.

### ملاحظة تطوير

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

- **تحميل حمل جسم تراكم كشف كشف**——حالي darwin-arm64 منصة تحميل حمل ضغط بعد نحو 92 MB، حل حزمة بعد نحو 325 MB؛ هذه هو كشف كشف عدد حرف، لا هو تثبيت عتبة قيمة.
- **إصدار قفل تحديد بروتوكول**——وقت التشغيل اعتماد قفل تحديد لـ Agent SDK 0.3.263؛ ترقية سوف قفل تحديد جديد SDK إصدار، و حاجة إعادة تشغيل بلا مفتاح حقيقي منتج و loader تركيب دليل.
