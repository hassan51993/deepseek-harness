# @deepseek-ai/dsh-subagent-acp

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن سوف مهمة تفويض إرسال إعطاء تشغيل في كل جديد عملية فرعية في ACP توافق agent؛ فرعي agent يملك مستقل وقت التشغيل، جلسة، نموذج و أداة. كل مرة تشغيل فقط مشترك اختيار تحديد عمل دليل، عبر ACP إرسال مهمة، و إرجاع فرعي agent نهائي جواب سجل أو أمان خطأ؛ في بين رسالة و أداة تدفق كمية لن دخول أب درجة محادثة. إذن تلميح من إعداد سياسة تلقائي ينبغي جواب، بلا حاجة شخص عمل وسيط دخول. عند تفويض إرسال حاجة عملية عزل أو حاجة استخدام غير Harness ACP agent وقت اختيار هذه الحزمة؛ عند فرعي agent يجب مشترك أب درجة قدرة وقت، اختيار عملية داخل خلفية.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند تركيب حاجة واحد دعم حمل Agent Client Protocol، تماما عزل كما في عملية خارج تشغيل فرعي agent وقت، تركيب هذا مزود. معتاد استخدام مسار هو صريح: تركيب seam، تركيب هذا مزود، و إعطاء خروج واحد بدء ACP agent أمر.

### أي وقت اختيار

عند فرعي agent يجب في مستقل عملية في تشغيل، يملك ذاتي ذات وقت التشغيل، نموذج و أداة وقت اختيار هذا خلفية——مثال مثل قدوم ذاتي أخرى مشروع ACP agent——أو من أنت أمل نظر تفويض إرسال تماما لا يمكن لمس و أب harness وقت. عند فرعي agent يجب مشترك أب درجة تركيب أو التزام حراسة أب درجة قوي صنع تنفيذ قدرة قيد وقت، طلب اختيار عملية داخل خلفية: هذا مزود لا إعلان أي اختياري بدء وقت قدرة، لذلك seam سوف رفض اشتراط `agentOptions`، بنية تحويل إخراج، عميق درجة حد أعلى، أداة مرور ترشيح أو persona طلب، بينما لا هو ساكن صامت حذف.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `acp` | `ctx.subagents` فوق سجل التسجيل اسم |
| `command` | لا بد ملء | كل مرة وقت التشغيل spawn يمكن تنفيذ ملف (فرعي ACP agent) |
| `args` | `[]` | أمر معامل |
| `cwd` | أب جلسة cwd | عملية فرعية و ذلك ACP جلسة عمل دليل تغطية قيمة |
| `permission` | `reject` | تلقائي ينبغي جواب إذن طلب: رفض، أو اختيار رقم واحد `allow_once` أو `allow_always` خيار (`allow`) |
| `env` | `{}` | تراكم إضافة في قد تنظيف اعتماد أب بيئة لـ فوق صريح فرعي بيئة |
| `disposeEofGraceMs` | `6000` | stdin EOF بعد، منصة إنهاء قبل عرض حد |
| `disposeGraceMs` | `3000` | فشل بعد مراقبة بنية تحويل عملية واقع وقت حد؛ في POSIX فوق أيضا هو SIGTERM إلى SIGKILL عرض حد |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-subagent-acp) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

DeepSeek Harness عملية فرعية استخدام منتج بدء جهاز و واحد صريح قطعا مقابل مسار `DSH_HOME`. عزل home يمكن منع توقف تضمين طقم وقت التشغيل اكتشاف بدء من عدد شخص profile أو اعتماد؛ عام ACP مزود لن يأخذ هذا واحد اشتراط قوي إضافة إعطاء غير DSH agent.

```yaml
- id: subagent-acp
  name: '@deepseek-ai/dsh-subagent-acp'
  config:
    providerName: acp
    command: dsh
    args: ['--profile', 'acp', '--patch', '/absolute/path/to/acp.patch.yml']
    permission: reject
    env:
      DSH_HOME: /absolute/path/to/isolated-child-home
      DEEPSEEK_API_KEY: !!js process.env.DEEPSEEK_API_KEY
```

### أنت سوف نيل إلى ماذا

نجاح تشغيل سوف يأخذ فرعي agent نهائي تدفق صيغة assistant نص بصفة نتيجة إخراج إرجاع. فرعي agent جلسة، نموذج و أداة قدوم ذاتي عملية فرعية ذاته——أب درجة فقط توفير مهمة و عمل دليل. إيقاف سبب يأخذ `end_turn` خريطة لـ `completed`،`max_tokens` خريطة لـ `max-tokens`،`refusal` خريطة لـ `refusal`،`cancelled` خريطة لـ `aborted`، ذلك بقية قيمة خريطة لـ `error`. قد إصدار تشغيل فشل وقت، جزء assistant نص إبقاء في `output`، أمان بنية تحويل تفصيل حال فإن مفرد وحيد وضع في `diagnostic`.

### فشل و استعادة

spawn، ابتدائي تحويل أو جديد بناء جلسة فشل سوف في إصدار قبل رفض، عبر معتاد أولا إثبات managed range قد تماما توقف مستقر. إذا تنظيف أيضا فشل، رفض سوف إبقاء لديه ترتيب، أمان بدء و تفكيك إزالة واقع، لكن لن صوت تسمية كامل range قد توقف مستقر. غير إلغاء خطأ فقط كشف ثابت مزود، مرحلة مقطع و صنف آخر واقع؛ أصلي فشل إبقاء في داخلي cause سلسلة و Host تشخيص في. إصدار بعد، نص التوجيه، نقل أو عملية رفع قبل خروج سوف بـ يحمل أمان تشخيص `error` تسوية؛ محلي إلغاء فإن بـ لا حمل فشل تفصيل حال `aborted` تسوية.

### أمان تشخيص

عام تشخيص استخدام ثابت واحد سطر:`Subagent failure (provider: ACP; stage: <stage>; category: <category>; ...)`. اختياري إيقاف سبب، خروج رمز و إشارة فقط قدوم ذاتي غلاف إغلاق بروتوكول أو تلقي إدارة عملية واقع.stderr، استثناء نص، مهمة محتوى، أداة إدخال، مسار، بيئة قيمة، اعتماد و بروتوكول تحميل حمل أبدا سوف دخول تشخيص؛ مشترك نتيجة حد يأخذ تشخيص حد في 4096 عدد UTF-8 بايت داخل. طلب مرور إذن كما لم إتمام تشغيل يمكن زيادة واحد سطر ثابت سياسة، أداة نوع صنف و قرار. نجاح تشغيل و محلي إلغاء لا يتضمن هذا سطر.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية مثل أي مرور ACP قيادة فرعي agent، و يمكن مراقبة سلوك من أي بينما قدوم؛ كامل اتفاق رؤية[استخدام هذه الحزمة](#use-this-package).

### تصميم إدارة فكرة

- **تماما عملية عزل.** كل فرعي agent في كل جديد عملية فرعية في تشغيل، يملك ذاتي ذات جلسة، نموذج و أداة؛ فقط لديه تحليل بعد عمل دليل قدوم ذاتي أب درجة.
- **كل مرة تشغيل واحد عملية.** كل مرة تشغيل كل spawn جديد عملية؛ لا يوجد عملية حوض.
- **ACP بروتوكول صيغة (wire format) هو تسلسل تحويل حد.** نفس عملية subagent قيمة لن لـ منع صد هدف تغلب ضخم؛ بروتوكول عندئذ هو تحقق غير ممكن معلومة إدخال أرض جهة.

### بدء و كل حق مسار

مرة بدء أولا تحليل فرعي agent عمل دليل (إعداد `cwd` تغطية قيمة، لا فإن أخذ أب جلسة cwd) ، مرور عملية فرعية seam spawn أمر، إتمام ACP `initialize` و `newSession` إمساك يد، لكن بعد عندئذ إصدار تشغيل. صرف الآن معنى طعم حال بعيد مسار جلسة قد حينئذ خيط، كل حق قد تحويل نقل إعطاء استدعاء جهة.dispose(مورد تحرير) هو قوة انتظار: أولا إغلاق stdin و حسب إعداد عرض حد انتظار تنسيق عمل صيغة تماما توقف مستقر، مجددا مرور SIGTERM ترقية إلى SIGKILL، و انتظار كامل managed range خروج. تنظيف فشل سوف بصفة لديه ترتيب أمان واقع إبقاء يمكن مراقبة، كما أبدا صوت تسمية قد تماما توقف مستقر.

### إيقاف سبب خريطة

تشغيل نتيجة سوف يأخذ ACP نهاية حالة خريطة دخول مشترك إيقاف سبب مفردات (`completed`،`max-tokens`،`refusal`،`aborted` أو `error`) ، تنفيذ رؤية [`src/run.ts`](src/run.ts).

### عملية حد

عملية فرعية مرور عملية فرعية seam spawn: أولا صاف حذف شك يشبه اعتماد بيئة متغير، مجددا دمج صريح `config.env` قيمة.stderr وراثة إلى أب درجة تدفق،dispose أولا تطبيق هذا مزود EOF نافذة، مجددا تنفيذ مشترك تدريجي درجة إنهاء.

</details>

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent طلب

#### نموذج يرى ماذا

بعيد مسار فرعي agent عبر ACP استقبال مستقل مهمة محتوى، و استخدام ذلك ذاته عملية إعداد توجيه النظام، أداة و كل جديد جلسة. هو لا استقبال أب درجة محادثة. هذا مزود لا إعلان اختياري بدء وقت قدرة، لذلك محلي خدمة سوف رفض اشتراط `agentOptions`،persona، أداة مرور ترشيح، عميق درجة قوي صنع أو بنية تحويل إخراج طلب، بينما لا هو ساكن صامت حذف.

#### Token أثر

فرعي agent لـ مستقل كامل سياق و ذلك كثير خطوة تاريخ دعم دفع token صار هذا. هذه token أبدا سوف دخول أب درجة سياق.

#### KV Cache أثر

و أب درجة طلب ذاكرة مؤقتة متبادل متبادل مستقل. كل ACP فرعي agent فقط قدرة في ذلك ذاته مزود، نموذج، تركيب و تاريخ متساو نفسه وقت إعادة استخدام بادئة؛ ذلك بقية حال حال تحت، فرعي agent خطوة فقط إلحاق زيادة طويل.

### أب درجة أداة نتيجة (بين وصل)

#### نموذج يرى ماذا

عبر `dsh-tool-subagent`، أب درجة فقط استقبال فرعي agent نهائي تدفق صيغة assistant نص أو هذا مستهلك إعطاء خروج دقيق إيقاف سبب خطأ، لا استقبال في بين رسالة أو أداة تدفق كمية. لم إتمام نتيجة سوف أولا عرض أمان تشخيص، مجددا مفرد وحيد إبقاء جزء assistant إخراج. إصدار قبل قد إلغاء طلب سوف دقيق تغيير لـ `Error: subagent request was aborted before the ACP child started`؛ أخرى بدء فشل فقط يتضمن ثابت `Subagent failure (...)` سطر.

#### Token أثر

أب درجة إدخال فقط زيادة نهائي نتيجة أو خطأ، ذلك محتوى اعتماد بيانات، و إبقاء إلى ضغط (compaction) لـ توقف. هذا مزود ذاته لن إضافة أب درجة schema.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خلفية أي وقت لا دمج ملائم، أو أي وقت حاجة خاص آخر تشغيل صيانة ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو عام ACP مقابل مقارنة أو مهمة تراكم ضغط.

- **كل مرة تشغيل استخدام كل جديد عملية**——لا يوجد عملية حوض؛ كل مرة تفويض إرسال كل يلزم دفع خروج كامل spawn و ACP إمساك يد صار هذا.
- **فقط دعم حمل محلي مساحة العمل**——تحليل بعد عمل دليل هو تسليم إعطاء نفس منصة آلة جهاز فوق عملية فرعية محلي مسار؛ بعيد مسار مساحة العمل خريطة بعد لم تصميم.
- **لا دعم حمل اختياري بدء وقت قدرة**——هذا مزود لا يمكن في بعيد مسار عملية داخل تطبيق `agentOptions`،`outputSchema`، عميق درجة حد أعلى، أداة مرور ترشيح جهاز أو persona، لذلك seam سوف رفض حاجة هو جمع طلب.
- **فقط استلام تجميع قد إيداع `agent_message_chunk` نص**——تلقائي تحويل خادم يأخذ دفع إدارة (reasoning) ، أداة نشط حركة، حساب تخطيط و أخرى trace بيانات إبقاء في فرعي agent جلسة سجل في، لا عبر ACP إرسال خروج.
- **إذن تلميح تلقائي ينبغي جواب**(`permission: allow | reject`)——لن يأخذ فرعي agent `session/request_permission` عرض إعطاء شخص.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك و حد بـ فوق نص و حزمة شفرة لـ دقيق.

- **عملية حوض**——حمل دائم عملية إعادة استخدام هو ممكن لم قدوم أفضل تحويل، لكن سوف تغيير كل مرة تشغيل عزل نموذج.
- **بعيد مسار مساحة العمل**——خريطة بعيد مسار ACP agent مساحة العمل حاجة مستقل خلفية قدرة.
- **يمكن متابعة تنفيذ ACP فرعي agent**——حاجة حفظ دائم بعيد مسار جلسة id، و لـ كل فرعي agent إعلان متابعة تنفيذ قدرة.

</details>

**وقت التشغيل ثابت صيغة:** لا إصدار مرافق توليد مدخل. هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة، متبادل صلة اتفاق في الذي تابع seam قوي صنع تنفيذ.
