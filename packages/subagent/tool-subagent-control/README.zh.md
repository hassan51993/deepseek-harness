# @deepseek-ai/dsh-tool-subagent-control

[English](README.md) | العربية

## عام وصف

`dsh-tool-subagent-control` لـ يمكن متابعة فرعي درجة إضافة عام تحكم أداة:`send_message` في مباشر أب درجة و فرعي درجة بين إجراء steering(في طريق جذب توجيه) ،`interrupt_agent` إيقاف فرعي درجة حالي جولة لكن إبقاء ذلك استلام عنصر صندوق و بعد بديل،`list_agents`(قدوم ذاتي يمكن مفرد وحيد تحميل `list-agents` إضافة) حسب حفظ دائم ID و وسم صف خروج يمكن متابعة فرعي درجة. أب درجة و يمكن متابعة فرعي درجة وراثة نفسه `send_message` تعريف و ترتيب، لذلك نموذج عبر معلومة لن زيادة فرعي درجة مخصص تابع أداة schema. هل تحميل هذه أداة لن قرار تفويض إرسال أداة هل بدء يمكن متابعة عمل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في نموذج حاجة مقابل يمكن متابعة فرعي درجة إرسال رسالة، في قطع أو صف خروج أي تركيب في تركيب هذه الحزمة. أصل إضافة فقط حاجة subagent خدمة؛ قائمة أداة هو مستقل إضافة، نشر جهة يمكن حذف.

### الأكثر صغير إعداد

أولا تحميل subagent خدمة، واحد خلفية، تفويض إرسال أداة و هذه الحزمة. إضافة فوق مستقل قائمة إضافة يكفي عام الكل ثلاثة عدد أداة:

```yaml
- name: '@deepseek-ai/dsh-subagent'
- name: '@deepseek-ai/dsh-subagent-spawn-in-process'
- name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: spawn
    backgroundMode: continuable
- name: '@deepseek-ai/dsh-tool-subagent-control'
- name: '@deepseek-ai/dsh-tool-subagent-control/list-agents'
```

هذه الحزمة لا استقبال أي إعداد: أصل إضافة توفير `send_message` و `interrupt_agent`، قائمة إضافة توفير `list_agents`.

### send_message

نحو `agent_id` إشارة تحديد Agent إرسال رسالة: أي تأكيد قطع في خط Agent كل يمكن نحو ذاتي ذات مباشر يمكن متابعة فرعي درجة إرسال رسالة، إقامة إبقاء يمكن متابعة فرعي درجة أيضا يمكن نحو ذاتي ذات مباشر أب درجة إرسال رسالة. صحيح في عمل هدف عبر Steer في الأكثر قريب خطوة حد استقبال رسالة؛ فارغ خامل هدف سوف بدء واحد جولة، بارد حالة مباشر فرعي درجة سوف عبر متابعة تنفيذ دورة الحياة استعادة. استدعاء فقط إرجاع قبول نتيجة (يتم قبول رسالة مستقر `messageId`) ، أبدا إرجاع عودة تكرار. فشل——لا تلقي دعم حمل هدف، غير ممكن استخدام أب درجة، لم معرفة فرعي درجة، نقص قليل وصف رمز بينما لا يمكن استعادة فرعي درجة، أو دقيق دخول يتم رفض——سوف واضح شرح رسالة لم إرسال بلوغ.

### interrupt_agent

فقط إيقاف هدف حالي جولة: قد ترتيب طابور رسالة إبقاء مؤقت توقف، مباشر إلى بعد استدعاء `send_message`؛ بعد بديل متابعة تشغيل، فرعي درجة ما زال يمكن قبول لاحق رسالة. استدعاء في إيقاف طلب يتم قبول بعد قيام أي إرجاع، لا انتظار هدف تماما توقف مستقر؛ في قطع قد انتهاء agent سوف يتم قبول و حسب فارغ عملية معالجة، بينما ذاته، نفس درجة، قديم قديم و غير أصل أولا استدعاء جهة سوف استلام إلى خروج خطأ نتيجة.

### list_agents

صف خروج استدعاء جهة agent تحت جهة يمكن متابعة فرعي درجة:`children`(افتراضي) فقط عرض مباشر فرعي درجة،`descendants` حسب مستقر قبل ترتيب مرة تاريخ كامل شجرة شجرة، و لـ كل بند علامة ملاحظة ذلك حفظ دائم مباشر أب درجة جلسة ID و عميق درجة. حالة قدوم ذاتي في خط Agent سجل التسجيل——`running`،`idle` أو `ready`. مرة صفة فرعي درجة بسبب لا يمكن قبول `send_message` بينما يتم متعمد ترتيب حذف، لا يمكن قراءة مرشح بند بـ تشخيص معلومة عرض.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أداة يأخذ ماذا تفويض حمل إعطاء subagent خدمة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

`ctx.subagents.sendMessage()`،`interrupt()` و قائمة إسقاط لـ فوق خفيف كمية مهايئ؛ أداة لا تنفيذ أي دورة الحياة توجيه. إقامة إبقاء، بارد استعادة و تخويل عودة خدمة كل، أداة يأخذ تأكيد قطع في خط استدعاء Agent(`exec.agent`) معا بصفة sender و إذن اعتماد نقل دخول.

### إلقاء تمرير و إشارة كل حق

أداة تحويل إرسال ذلك تنفيذ إشارة، هذا إشارة فقط في inbox قبول قبل كف إدارة دقيق دخول. هدف واحد حالما قبول رسالة، هذا رسالة سهل لا يمكن مجددا عبر هذا أداة إلغاء. كل بند رسالة كل بـ `Agent <sender-id> sent a message:` بصفة بادئة، و سجل `{ kind: 'agent-message', form: 'relay', senderSessionId: sender.id }`؛ هذا مصدر معلومة من خدمة دفع توجيه، كما أبدا يتم نظر لـ إذن.

### قائمة إسقاط

`list_agents` من استدعاء agent دفع توجيه أصل id، لا استخدام cursor قراءة خدمة دليل، عبر في خط Agent سجل التسجيل دقيق تحويل كل مرشح حالة، و حذف لا يمكن قبول `send_message` مرة صفة فرعي درجة.diagnostic في descendants scope في إبقاء ذلك موضع، كما أبدا كشف وصف رمز محتوى.

| [`src/list-agents.ts`](src/list-agents.ts) | `list_agents` تسجيل: أثر مجال، حالة دقيق تحويل، إسقاط |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا عدد موجه إلى نموذج مهايئ لا يوجد مستقل دورة الحياة تدفق؛ إلقاء تمرير و تنشيط علاقة من ذلك استدعاء subagent خدمة مسؤول. |

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى ماذا

قد توليد [schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-subagent-control):`send_message` قبول `agent_id` و `message`؛`interrupt_agent` قبول `agent_id`؛`list_agents` قبول اختياري `scope` قطعة رفع.

#### Token أثر

كل أب درجة طلب دعم دفع ثابت schema صار هذا.

#### KV Cache أثر

بادئة إبقاء مستقر؛schema لن في وقت التشغيل تغيير.

### في قطع نتيجة

#### نموذج يرى ماذا

قبول وقت إرجاع `interrupt requested for agent <agent_id>`. لم تخويل استدعاء جهة——self،sibling، قديم قديم أو غير ancestor——سوف يصبح إشارة واضح رفض سبب خروج خطأ نتيجة؛ هدف لا وجود أو قد تسوية ما زال تصيير قبول سطر.

#### Token أثر

كل مرة استدعاء إنتاج واحد بند بسيط قصير تأكيد رسالة؛ يتم في قطع جولة في توقف فقط في فرعي درجة ذاتي ذات transcript(نص سجل) في مرئي.

#### KV Cache أثر

فقط إلحاق؛ كل نتيجة كل يقع في يمكن إعادة استخدام طلب بادئة بعد.

### إلقاء تمرير نتيجة

#### نموذج يرى ماذا

قبول وقت إرجاع `message delivered to agent <agent_id>`؛ مواصفة إخراج يحمل يتم قبول `messageId`. فشل——غير متبادل مجاور هدف، غير ممكن استخدام أب درجة، لم معرفة فرعي درجة، نقص قليل وصف رمز بينما لا يمكن استعادة فرعي درجة، أو دقيق دخول يتم رفض——سوف يصبح خروج خطأ نتيجة، ذلك رسالة شرح هذا رسالة لم إرسال بلوغ.

#### Token أثر

كل مرة استدعاء إنتاج واحد بند بسيط قصير تأكيد رسالة؛ هدف استجابة أبدا سوف عبر هذا مرة استدعاء إرجاع. فرعي درجة استخدام نفس عدد أداة، و نقل دخول ذلك ابتدائي مهمة في أب درجة ID، سوف اختيار تحديد محتوى إلحاق إلى أب درجة تاريخ في.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

### قائمة نتيجة

#### نموذج يرى ماذا

حسب مستقر دليل ترتيب، كل يمكن متابعة فرعي درجة احتلال واحد سطر:`<id> [<status>] — <label>`(`running` يمثل مشغل نشط وثب،`idle` يمثل إقامة إبقاء لكن موضع في جولة بين،`ready` يمثل فقط تخزين في تخزين، يمكن استعادة بينما غير نهاية حالة) ، آخر لـ لا يمكن قراءة مرشح بند تصيير `<id> [diagnostic: <reason>]`.`descendants` أثر مجال سوف في كل سطر وسم كسر طي رقم قبل حسب قبل ترتيب إدراج دخول ` parent=<id> depth=<n>`. مرة صفة فرعي درجة سوف يتم متعمد ترتيب حذف؛`(no subagents)` يمثل إسقاط بعد لا يوجد إبقاء تحت يمكن متابعة فرعي درجة أو تشخيص معلومة.

#### Token أثر

مع الذي صف يمكن متابعة فرعي درجة عدد كمية خط صفة زيادة طويل——`descendants` أثر مجال تحت لـ كامل شجرة شجرة؛ لا يوجد تنقل علامة أو حد أعلى، لذلك طويل مدة تخزين نشط كما لديه سماح كثير حفظ دائم فرعي درجة أب درجة كل مرة استدعاء كل سوف تحمل تحمل كامل قائمة صار هذا.

#### KV Cache أثر

فقط إلحاق؛ كل نتيجة كل يقع في يمكن إعادة استخدام طلب بادئة بعد.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح تحكم أداة لا يمكن مراقبة أو جذب توجيه ماذا؛ هو جمع هو حالي حزمة قيد.

- **قد إلقاء تمرير رسالة لا يوجد مستقل نتيجة**——قبول وقت فقط إرجاع ذلك inbox `messageId`؛ هدف لاحق عمل سوف سقوط دخول هذا هدف حفظ دائم جلسة، أبدا سوف عبر هذا أداة استلام تجميع. عودة تكرار هو آخر بند صريح إشارة تحديد عنوان `send_message`، بينما غير هذا مرة استدعاء نتيجة.
- **فقط لديه تلقي دعم حمل متبادل مجاور Agent يمكن عبر معلومة**——كل إرسال جهة كل يمكن نحو مباشر يمكن متابعة فرعي درجة إرسال رسالة؛ فقط لديه أداة تجهيز إقامة إبقاء يمكن متابعة Activation إرسال جهة يمكن نحو ذاتي ذات مباشر أب درجة إرسال رسالة، كما هذا أب درجة يجب ما زال في خط؛ نفس درجة و أكثر عميق بعد بديل لا يستطيع بصفة رسالة هدف، فقط لديه نحو مباشر فرعي درجة إلقاء تمرير عندئذ دعم حمل بارد تنشيط.
- **قائمة هو لقطة، بينما غير إلقاء تمرير تحمل وعد**——هو ممكن و إصدار،dispose(مورد تحرير) أو لاحق رسالة حدوث تنافس حالة، آخر عدد عملية أيضا ممكن تنشيط حالي عملية تقرير إبلاغ لـ `ready` فرعي درجة؛ عبر عملية دقيق تأكيد صفة حاجة مشترك إيجار نحو.`interrupt_agent` ذاتي ذات تنفيذ مرجعي في خط lineage فحص، لذلك مرور مدة اكتشاف نتيجة لن منح إعطاء إذن.
- **لا يوجد قسم صفحة أو حذف**——نظام إرجاع كامل كما مستقر ترتيب ترتيب تجميع دمج؛ فقط يلزم فرعي درجة جلسة ما زال في حفظ دائم تخزين في، هو حينئذ سوف متابعة ظهور في قائمة في، خدمة درجة حد أعلى أو حذف عملية إبقاء انتظار لاحق منتج قرار.
