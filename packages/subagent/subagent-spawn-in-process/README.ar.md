# @deepseek-ai/dsh-subagent-spawn-in-process

[English](README.md) | العربية

## عام وصف

`dsh-subagent-spawn-in-process` هو واحد عملية داخل subagent خلفية: هو في حالي عملية في تشغيل كل تفويض إرسال مهمة، فرعي agent(ذكي جسم) هو واحد كل جديد فرعي `Agent`، إعادة استخدام مضيف agent عمل مصنع و LLM(كبير لغة نموذج)/أداة خدمة. فرعي agent بـ فارغ محادثة بدء، لذلك مهمة نص التوجيه يجب ذاتي كاف؛ حذف غير `request.agentOptions` تغطية، لا فإن هو وراثة أب agent عمل دليل، جلسة جدول نظام، مزود، نموذج، دفع إدارة قوي درجة و إخراج token حد أعلى. تفويض إرسال أداة أو API استدعاء بـ `spawn` مزود اسم بحث إلى هو. حاجة صار هذا الأكثر منخفض تفويض إرسال نقل وقت اختيار هو؛ حاجة فرعي agent بناء قيام في أب درجة قد إتمام محادثة جولة لـ فوق وقت، طلب اختيار fork خلفية.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في حاجة يأخذ عمل تفويض إرسال إعطاء كل جديد عملية داخل فرعي agent تركيب في تركيب هذا خلفية. معتاد استخدام إعداد مسار جدا واضح: تحميل subagent خدمة و هذا خلفية، مجددا يأخذ `dsh-tool-subagent` لـ صنف تفويض إرسال أداة إشارة نحو `spawn` مزود.

### أي وقت اختيار

عند فرعي agent لا حاجة أب درجة محادثة، كما يمكن قبول في هذا عملية داخل وقت التشغيل، اختيار spawn خلفية. عند فرعي agent يجب بناء قيام في قد إتمام أب درجة جولة لـ فوق وقت——fork خلفية سوف توفير هذه تاريخ——أو يجب في هذا عملية خارج وقت التشغيل (عملية خارج خلفية توفير هذا قدرة) ، طلب تجنب تجنب استخدام هو. من في فرعي agent افتراضي وراثة أب درجة عمل دليل و LLM اختيار، ذاتي كاف نص التوجيه سوف حسب أصل مثال توليد فاعلية.

### الأكثر صغير إعداد

أولا تحميل subagent خدمة و هذا خلفية، مجددا لـ كل هدف إعداد واحد تفويض إرسال أداة. هذا هو كشف من spawn دعم دعم `subagent` أداة الأكثر صغير تركيب:

```yaml
- name: '@deepseek-ai/dsh-subagent'
- name: '@deepseek-ai/dsh-subagent-spawn-in-process'
- name: '@deepseek-ai/dsh-tool-subagent'
  config:
    provider: spawn
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `providerName` | `spawn` | تسجيل إلى `ctx.subagents` مزود اسم |

توليد[إعداد دليل](../../../docs/config-catalog.ar.md#deepseek-aidsh-subagent-spawn-in-process) هو كل تلقي دعم حمل حقل و ذلك JSDoc نفاد كل صيغة حق مصدر.

### مرة تفويض إرسال سوف فعل ماذا

مرة أداة استدعاء بدء واحد فرعي agent و انتظار ذلك نتيجة: فرعي agent في ذاتي لديه جلسة في عمل، أب درجة فقط استقبال ذلك نهائي إخراج؛ إذا تشغيل يتم إلغاء، رفض، يتم token حد أعلى قطع قطع أو في بدء وقت يتم رفض، فإن استلام إلى خروج خطأ أداة نتيجة. يتم رفض بدء لن إبقاء تحت قد إصدار فرعي agent؛ إتمام تشغيل في نتيجة استلام تجميع بعد أي يتم dispose(مورد تحرير).

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خلفية بناء طريقة و[استخدام هذه الحزمة](#use-this-package) في سلوك مصدر؛ مشترك آلية يخص عملية داخل مشغل.

### تصميم إدارة فكرة

مسؤولية تخطيط قسم مثل تحت: هذا خلفية فقط مساهمة مزود تسجيل و «كل جديد بدء» قرار، ذلك بقية الكل تشغيل آلية——عميق درجة فحص، فرعي agent إنشاء، حسب فرعي agent تحديد صنع، بنية تحويل إخراج، إلغاء، نتيجة قراءة و dispose——كل في `dsh-subagent-in-process-driver` في.agent عمل مصنع إنشاء أمر خدمة يملك لم إصدار ضبط نافذة و ذلك تراجع؛ إصدار بعد، استدعاء جهة يملك هذا تشغيل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | مزود تسجيل:`Config` schema، قدرة إعلان،`start()` |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة، متبادل صلة اتفاق في الذي تابع seam قوي صنع تنفيذ. |

### تشغيل مسار

بدء طلب أولا من subagent خدمة تحليل، لكن بعد مشترك مشغل تحقق عميق درجة، توليد فرعي جلسة id، عبر مضيف agent عمل مصنع بـ استدعاء جهة إشارة إنشاء فرعي agent، في إنشاء نافذة داخل تطبيق persona، أداة مرور ترشيح جهاز و بنية تحويل إخراج، إصدار فرعي agent، قيادة واحد بند مهمة، قراءة فرعي agent ذاته نهائي إخراج، الأكثر بعد تماما توقف مستقر أرض dispose جملة مقبض.

### كل حق و أثر مجال

فرعي agent نيل نيل كل جديد مسطح مستو تسجيل أثر مجال: أب درجة أداة حد و إذن أبدا سوف يتم استيراد، أداة الذي تطبيق إضافة مرور ترشيح يخص تركيب بينما غير أب درجة إرسال توليد تخويل. خلفية إعلان يشمل `agentOptions` في داخل الكل خمسة بند بدء وقت قدرة، لأن هو تحكم فرعي agent إنشاء نافذة، يمكن تدريجي واحد قوي صنع تنفيذ.

<a id="model-experience"></a>
## تجربة النموذج

### فرعي agent طلب

#### نموذج يرى ماذا

كل جديد فرعي agent تدريجي حرف استقبال مهمة محتوى، بصفة جديد فارغ محادثة في وحيد مستخدم رسالة، افتراضي استخدام أب درجة مزود، نموذج، دفع إدارة قوي درجة، إخراج token حد أعلى و عمل دليل. إعداد persona سوف في فرعي agent أثر مجال في حجب حجب عام نص التوجيه نص؛ أداة مرور ترشيح جهاز سوف من ذلك schema، يمكن تنفيذ أداة فحص بحث و PTC mode SDK ربط في إزالة إشارة تحديد عام أداة، لكن إبقاء مستقل تسجيل إشارة توجيه محتوى. لا يتضمن أي أب درجة محادثة رسالة؛ مرور ترشيح يخص تركيب، بينما غير وراثة إذن منح إعطاء.

#### Token أثر

فرعي agent سوف لـ كل جديد مستقل سياق و تاريخ إزالة استهلاك token، لا نسخ أي أب درجة تاريخ token.persona سوف تغيير هذا فرعي agent عكس تكرار استخدام نص التوجيه صار هذا؛ أداة مرور ترشيح جهاز سوف تغيير ذلك schema أو توليد SDK صار هذا.

#### KV Cache أثر

فرعي agent طلب ذاكرة مؤقتة و أب درجة متبادل متبادل مستقل. فرعي agent تاريخ فقط إلحاق؛persona، أداة مرور ترشيح، توليد SDK، مزود أو نموذج تغير سوف بناء قيام مختلف فرعي agent بادئة.

### أب درجة أداة نتيجة (بين وصل)

#### نموذج يرى ماذا

عبر `dsh-tool-subagent`، أب درجة فقط استقبال فرعي agent نهائي إخراج، أو غير إتمام إنهاء سبب مقابل خروج خطأ نتيجة؛ فرعي agent في بين عمل أبدا سوف وصول أب درجة.

#### Token أثر

أب درجة إدخال زيادة واحد أخذ قرار في بيانات نتيجة، و إبقاء إلى سياق ضغط (context compaction) لـ توقف.

#### KV Cache أثر

فقط إلحاق؛ إضافة جديدة مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV Cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أي وقت اختيار هذا خلفية هو خطأ؛ هو جمع هو حالي حزمة قيد.

- **كل جديد يمثل لا يحتوي أب درجة transcript(نص سجل)**——فرعي agent وراثة cwd، جدول نظام، مزود، نموذج، دفع إدارة قوي درجة، إخراج token حد أعلى و صريح إعداد persona/أداة حد، لكن لا وراثة أب درجة أي محادثة؛ حاجة قد إتمام جولة سياق وقت، طلب استخدام fork خلفية.
