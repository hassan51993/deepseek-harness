# @deepseek-ai/dsh-settings

[English](README.md) | العربية

## عام وصف

عند مستخدم حاجة في وقت التشغيل تعديل إضافة إعداد، بينما بلا حاجة إعادة بدء أو إعادة قراءة `cordis.yml` وقت، طلب استخدام هذه الحزمة. كل namespace دمج schema قيمة افتراضية، نشر إعداد و مستخدم تغطية؛ قراءة جهة سوف نيل إلى عميق تجميد ربط تحليل قيمة لقطة، و يمكن مراقبة قد إيداع تغيير. كتابة فقط أثر مستخدم تغطية، حسب namespace سلسلة سطر تنفيذ، و يمكن رفض قديم قديم revision، تجنب تجنب تغطية مقارنة جديد تغيير. حفظ دائم وقت التشغيل تحرير حاجة أولا إعداد ضبط تخزين؛ لا فإن إضافة ما زال يمكن متابعة استخدام تركيب إعداد.

## استخدام هذه الحزمة

إضافة و إعداد واجهة عبر `ctx.settings` في وقت التشغيل قراءة و تعديل إعداد. معتاد استخدام مسار: تركيب مزود، استخدام schema تسجيل namespace، قراءة و مراقبة تحليل قيمة، و عبر owner scope كتابة.

### أي وقت اختيار

عند إضافة إعداد حاجة في وقت التشغيل متغير——مستخدم تحرير وثيقة أو إعداد واجهة تعديل——كما بلا حاجة إعادة بدء أو إعادة قراءة `cordis.yml` وقت، اختيار ضبط خدمة. هو ملائم دمج كثير عدد إضافة كل يملك واحد إعداد namespace، و إعداد واجهة حاجة تصيير schema، علامة مستخدم تغطية حقل و حفظ دائم تحرير مشهد. عند إعداد في تحميل وقت ثابت فإن لا يوجد لا بد يلزم: لا يوجد تركيب مزود وقت واحد قطع وفق قديم، إعداد إبقاء تركيب أصل مثال.

### تركيب مزود

خدمة ذاته لا تخزين أي محتوى؛ طلب تركيب واحد مزود، مثال مثل مع مرفق ملف نوع مزود:

```yaml
- name: '@deepseek-ai/dsh-settings-file'
  config:
    path: /absolute/path/to/settings.yaml
```

مزود فوق خط بعد `ctx.settings` أي ظهور. كامل إعداد وجه من مزود README مسؤول؛ توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-settings-file) صف خروج كل تلقي دعم حمل حقل.

### تسجيل namespace

إضافة استخدام schemastery schema تسجيل ذاتي ذات namespace، و اختياري أرض يأخذ تركيب إعداد بصفة `base` طبقة نقل دخول، يجعل تحليل قيمة من نشر قد إعداد محتوى بدء خطوة:

```text
const scope = ctx.settings.register('ui-theme', ThemeSchema, {
  base: config,   // composition entry config; the user layer resolves above it
})
const theme = scope.get()              // deep-frozen resolved snapshot
scope.update({ density: 'compact' })   // merges into the user section and persists
```

TypeScript سوف حسب صغير كتابة حرف أم، عدد حرف و وصل محرف نص قاعدة فحص حرف وجه كمية namespace معامل؛ وقت التشغيل حركة حالة نقل دخول نص قبول نفسه تحقق.`ctx.settings.installSection(owner, ns, schema, entry, hooks)` لـ مستهلك إضافة غلاف تركيب اختياري خدمة وصل خط: فقط يلزم ضبط خدمة وجود، هو حينئذ استخدام إضافة تركيب إعداد بصفة `base` تسجيل namespace؛ خدمة إزالة فقد وقت إضافة رجوع إلى تركيب إعداد، سلوك و أصل أولا تماما متسق.

### قراءة و مراقبة قيمة

`get(ns)` بـ عميق تجميد ربط لقطة إرجاع تحليل قيمة،namespace لم تسجيل وقت لـ `undefined`.`watch(callback)` في كل مرة قد إيداع تغيير بعد بـ `(next, prev)` استدعاء عودة ضبط: نفس عودة ضبط استدعاء حسب إيداع ترتيب تدريجي عدد تنفيذ، استثناء يتم عزل و تسجيل دخول سجل، لذلك بطيء أو رمي خطأ مراقبة من أبدا سوف منع سد أو كسر تالف أخرى مراقبة من.

### كتابة قيمة

`update(ns, patch)` يأخذ عادي كائن patch عميق دمج دخول مستخدم قسم عقدة——أبدا دخول `base`——تحقق تحليل مرشح قيمة، مرور مزود حفظ دائم بعد إيداع.`replace(ns, section)` كامل جسم استبدال مستخدم قسم عقدة، هو حذف/إعادة وضع مسار:`replace({})` إعادة وراثة `base` و schema قيمة افتراضية.`mutate(ns, ops)` في كتابة ترتيب إلى طابور أول ذلك واحد لحظة قسم عقدة فوق حسب ترتيب تطبيق إضافة `{ op: 'set' | 'unset', path }` تحرير——هذا هو يحتفظ لا كامل (مثال مثل انفصال حساس بعد) عرض استدعاء جهة حذف مسار، لأن حسب بروتوكول واجهة إرجاع محتوى إعادة بناء قسم عقدة مجددا كامل جسم استبدال، سوف حذف إسقاط بروتوكول من لم عودة نقل كل حقل.

كل مرة كتابة كل سوف رفض و JSON لا توافق بيانات (`Date`،`Map`،`BigInt`، غير لديه حد عدد أو حلقة مرجع سوف في أي محتوى حفظ دائم قبل بـ `$` لـ أصل مسار تقرير خطأ) ، رفض فقط قراءة مزود فوق كتابة، و يمكن قبول اختياري `expectedRevision`: يأخذ descriptor في `revision` نقل عودة،namespace قد تجاوز مرور هذا قيمة وقت كتابة سوف يتم `SettingsConflictError` رفض، بينما لا هو تغطية أولا إتمام كتابة واحد جهة.

### إعداد واجهة

`describe()` لـ كل قد تسجيل namespace إرجاع واحد بند descriptor: تسلسل تحويل schema، تحليل قيمة، قسم مغادرة `base` و `user` طبقة (حقل ظهور في `user` في أي علامة لـ مستخدم تغطية) ، توليد فاعلية وقت آلة و namespace revision. كل بروتوكول واجهة كل يجب نقل دخول `redactSecrets: true`: هو من كل واحد طبقة تقشير مغادرة `role('secret')` حقل، و يأخذ هو جمع قطعة رفع لـ `{ path, set }` slot، يجعل صفحة يمكن تصيير فقط كتابة إدخال بينما لا وصل لمس أي آلة سري.`documentPath` و `prepareDocument()` في مزود يملك مستخدم يمكن تحرير ملف وقت يأخذ هو كشف إعطاء أصلي تحرير جهاز.

### حدث و فشل

`settings/updated (ns, next, prev, source)` في كل مرة قد إيداع تغيير بعد إطلاق——عملية داخل كتابة (`source: 'update'`) أو خارجي مراقبة إلى تحرير (`source: 'provider'`)——تحليل قيمة عميق متبادل انتظار وقت أبدا إطلاق.`settings/document-updated (ns, revision)` في أصلي مستخدم قسم عقدة حدوث تغير وقت إطلاق، أي جعل تحليل قيمة لا يوجد تغيير——قد فتح تحرير جهاز صحيح حاجة هو قدوم نيل معرفة حقل من وراثة تغيير لـ تغطية.schema رفض تخزين كمية قسم عقدة في إعادة تحميل وقت إبقاء هذا namespace الأكثر بعد متاح قيمة و إبلاغ تحذير؛ تسجيل وقت نفس مثال فشل سوف مباشر رفض تسجيل.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خدمة خلف بعد تصميم قرار و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **قسم طبقة تحليل، مفرد واحد مستخدم طبقة.** namespace قيمة اعتماد مرة لـ schema قيمة افتراضية، تسجيل جهة تركيب `base`، مستخدم وثيقة قسم عقدة؛ كتابة فقط لمس اصطدام مستخدم طبقة، لذلك `replace({})` هو حق صحيح إعادة وضع.
- **إيداع بـ عميق متبادل انتظار لـ باب عتبة.** فقط لديه تحليل قيمة تغير وقت `settings/updated` عندئذ إطلاق؛ أصلي قسم عقدة حدث مستقل وجود، لأن إعداد واجهة أيضا يجب نيل معرفة «وراثة تغيير صار تغطية».
- **كتابة ترتيب طابور و فعل revision فحص.** كل namespace كتابة طابور صف حسب استدعاء ترتيب سلسلة سطر،`expectedRevision` في طابور أول حكم قطع——ذلك داخل خدمة عندئذ قدرة قسم تمييز يحتفظ جديد طازج لقطة كتابة جهة و يحتفظ قديم قديم لقطة كتابة جهة.
- **مراقبة من و مستمع استثناء يتم عزل.** watcher استدعاء و حدث مروحة خروج عزل تزامن رمي خروج و مختلف خطوة رفض، واحد تالف إسقاط مراقبة من لن بطاقة ميت إيداع أو مزود إعادة تحميل حلقة؛`INVARIANT` تحرير رمز فشل في كل مستمع تنفيذ تمام بعد إعادة رمي خروج.
- **تسجيل هو fiber فوق effect.** تسجيل namespace هو استدعاء جهة إضافة fiber فوق effect:dispose(مورد تحرير) هذا fiber أي إزالة namespace و ذلك مراقبة من.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | Service Definition:namespace تحقق، تسجيل، تحليل، كتابة طابور صف،describe/انفصال حساس، حدث،`installSection` |
| [`src/redact.ts`](src/redact.ts) | `redactSecrets` مرة تاريخ جهاز: تقشير مغادرة `role('secret')` حقل و قطعة رفع ذلك slot |
| [`src/types.ts`](src/types.ts) | عميل أمان نوع وجه: حدث إعلان،`SettingsNamespace`،`SettingsUpdateSource` |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة:`settings/updated` فقط مقابل قد تسجيل namespace، فقط في تحليل قيمة تغير وقت، كما يحمل مرجعي قيمة إطلاق |

### تحليل و كتابة مسار

كل مرة كتابة كل في استدعاء وقت مقابل إدخال فعل لقطة (قسم مغادرة و تحقق JSON شكل حالة بيانات) ، لكن بعد ترتيب فوق هذا namespace سلسلة سطر سلسلة. في طابور أول، خدمة حسب حالي حالة إعادة قراءة قسم عقدة، فحص `expectedRevision`، دمج/استبدال/تحرير، مرور schema و owner اختياري `validate` تحليل و تحقق مرشح قيمة، مرور مزود حفظ دائم، لكن بعد عندئذ إيداع تزامن خروج حدث.registrant fiber في كتابة طريق في يتم dispose كتابة ما زال وصول تخزين، لكن لن إيداع، أيضا لن إشعار أي شخص؛ إزالة أولا رفض جديد كتابة، و ترتيب جاف ترتيب طابور كتابة و قد بدء watcher استدعاء بعد عندئذ إتمام.

### تغيير فحص قياس و حدث

`commit` استخدام seam `deepEqualJson` يسمى كلمة مقارنة مقارنة تحليل قيمة، و تدريجي مستمع مروحة خروج `settings/updated`.`bumpRevision` مقارنة مقارنة أصلي قسم عقدة و يحمل جديد revision إرسال خروج `settings/document-updated`؛ هو و تحليل قيمة فحص متبادل متبادل مستقل. اثنان عدد مروحة خروج بـ نفسه طريقة عزل مستمع استثناء.

### عميل أمان نوع

`./types` فرعي مسار خروج فتحة يحتفظ حدث إعلان و ذلك توقيع نقطة اسم `SettingsNamespace`،`SettingsUpdateSource` نوع، حزمة أصل متابعة re-export هذه نوع. في هو Host تحرير ترجمة وجه خارج مستهلك قراءة إلى صحيح هو Host إرسال إطلاق ذلك واحد نسخة توقيع، بينما لا لا بد مجددا كتابة واحد مرة.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل توليد فاعلية: من ضبط قيمة توفير كل موجه إلى نموذج محتوى متساو من مستهلك إضافة مسؤول؛ هذا خدمة فقط تخزين و تحليل مستخدم ضبط، ذاته لا تسجيل أي موجه إلى نموذج محتوى.

#### KV Cache أثر

بلا مباشر بطلان؛ يأخذ ضبط قيمة قبول دخول طلب بادئة مستهلك مسؤول هذا تغيير.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا خدمة أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **مفرد واحد مستخدم طبقة**——تحليل فقط إقرار تعرف schema قيمة افتراضية، واحد تركيب `base` و واحد مستخدم وثيقة؛ هو لا سجل كل تحليل قيمة من أي واحد طبقة توفير.
- **`redactSecrets` و غير واحد بند يمكن يتم إثبات بروتوكول حد**——مرة تاريخ جهاز فقط تتبع مع `object`/`dict`/`array` حاوية، لذلك فقط قدرة مرور من union،intersection أو transform مقاومة بلوغ `role('secret')` حقل سوف يتم أصل مثال إرجاع، كما `secrets` قائمة لـ فارغ؛ تسلسل تحويل schema أيضا سوف يأخذ secret حقل قيمة افتراضية حمل إعطاء كل عميل. اثنان نوع حال حال كل لن يتم رفض؛ آلة سري لا يمكن مرور من يتم مرة تاريخ حاوية مقاومة بلوغ schema، أبدا يمكن تسجيل إلى كشف في بروتوكول namespace فوق.fail-closed `describeForWire()`——رفض ذاتي ذات لا يمكن إثبات أمان schema، و مقابل تسلسل تحويل غلاف تركيب و خطأ نص فعل صاف تحويل——هو مؤقت مؤقت جواب سجل.
- **عبر عملية تزامن من مزود تعريف**——خدمة فقط في عملية داخل حسب namespace سلسلة سطر كتابة؛ عبر عملية تزامن حسب مزود سلوك استلام جمع (ملف مزود في كتابة قفل تحت قراءة-تعديل-كتابة، لذلك تزامن كتابة من لن فقد إسقاط ذاك هذا namespace، نفس namespace اندفاع مفاجئ حسب بعد كتابة فوز خروج حل قرار).

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: بعد لم قرار فتح وضع تصميم جهة نحو. هو واضح غير مرجعي——قد إصدار سلوك، حد و قد قبول إدارة من رؤية فوق نص كل عقدة و حزمة شفرة. شفرة TODO في سجل فتح وضع جهة نحو: يأخذ عام `ns` معامل أكثر اسم لـ `namespace`(API، مزود اتفاق، تنفيذ، اختبار و مستهلك تزامن) ؛ تحرير تسجيل بند وقت توقف استخدام كل watcher و انتظار ذلك استدعاء سلسلة إتمام، تأكيد حفظ عودة ضبط لن في registrant fiber تحرير بعد متابعة تشغيل؛ استبدال تسجيل من حفظ دائم قسم عقدة إعادة تحليل، يجعل إجراء في قديم كتابة لن يأخذ هو إبقاء صار قديم قديم قيمة؛ تعديل استخدام خاصية أمان كائن بنية صنع، يجعل `__proto__` هذا صنف دمج قاعدة JSON مفتاح إبقاء لـ ذاتي لديه بيانات.fail-closed `describeForWire()` صاف تحويل جهاز هو فوق نص انفصال حساس حد مؤقت مؤقت جواب سجل.

</details>
