# util/: مشترك أداة

[English](README.md) | العربية

## عام وصف

`util/` مجموعة لـ قدرة حزمة توفير مشترك آلية أصل لغة، تجنب تجنب تكرار تنفيذ. هو شمول غطاء أصل فرعي كتابة، صنف لوحة تحويل id، مزدوج طرف طابور صف، بلا ضرر JSON قيمة،UUID،Harness home مسار، بدء بيئة، خروج محطة بديل إدارة سياسة، أصلي أمر، إخراج إبقاء، وقت منطقة مواصفة تحويل و مهلة معالجة. هذا داخل كل أصل مدخل كل هو مكتبة: هو لا تسجيل منتج خدمة أو حدث، عمل خدمة دلالة ما زال من إزالة استهلاك هو قدرة مسؤول.

## حزمة

كل حزمة توفير واحد أصل لغة؛ فتح مقابل حزمة صفحة حل مثل أي استخدام.

| حزمة | مسؤولية |
|---|---|
| [`brand/`](brand/README.ar.md) | توفير اسم معنى نص نوع و ذلك بلا حالة بنية صنع دالة |
| [`package-manifest/`](package-manifest/README.ar.md) | حزمة manifest(بيانات وصفية بيان) مشترك TypeScript إعلان |
| [`crypto/`](crypto/README.ar.md) | أساس في عبر وقت التشغيل `crypto.getRandomValues` أصل لغة توليد RFC 9562 v4 UUID |
| [`deque/`](deque/README.ar.md) | توفير توزيع إلغاء معتاد عدد وقت طابور صف عملية و محدود فارغ خامل تخزين |
| [`chunked-list/`](chunked-list/README.ar.md) | عبر محدود إلحاق نسخ و فحص نقطة تحقق إبقاء غير ممكن تغيير قائمة إصدار |
| [`values/`](values/README.ar.md) | تحقق، إنشاء لقطة، مقارنة مقارنة و تجميد ربط بلا ضرر JSON توافق قيمة |
| [`home-paths/`](home-paths/README.ar.md) | تحليل موحد واحد Harness رئيسي دليل و تجميع وصل مشترك مستخدم بيانات مسار |
| [`http-proxy/`](http-proxy/README.ar.md) | تحليل خروج وحيد خروج محطة بديل إدارة سياسة، و لـ `fetch`،SDK agent(ذكي جسم) و spawn عملية فرعية تثبيت هو |
| [`launch-environment/`](launch-environment/README.ar.md) | تجميد ربط بدء بيئة، تسجيل إقامة كل قيمة قدوم ذاتي أي واحد طبقة |
| [`atomic-write/`](atomic-write/README.ar.md) | أصل فرعي ملف استبدال و عبر عملية كتابة قفل |
| [`lazy-require/`](lazy-require/README.ar.md) | في أول مرة استخدام وقت حسب استدعاء جهة موضع تحميل توافق CommonJS Host اعتماد |
| [`native-command/`](native-command/README.ar.md) | مباشر تشغيل مضيف أصلي أمر، أبدا تجميع shell نص |
| [`workspace-path/`](workspace-path/README.ar.md) | توفير متصفح أمان Workspace مسار و عرض مساعد مساعدة دالة |
| [`output-retention/`](output-retention/README.ar.md) | حد موجه إلى نموذج إخراج و تقرير إبلاغ دقيق حذف بيانات وصفية |
| [`time/`](time/README.ar.md) | تحقق و مواصفة تحويل استدعاء جهة الذي تقرير IANA وقت منطقة |
| [`timeout/`](timeout/README.ar.md) | قطع توقف وقت تشغيل حساب، إشارة دمج دمج و مهلة و إلغاء تصنيف |
