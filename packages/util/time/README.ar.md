# dsh-util-time

[English](README.md) | العربية

## عام وصف

صفر اعتماد وقت منطقة مفردات، توفير استقبال استدعاء جهة وقت منطقة بروتوكول حد استخدام.`canonicalClientTimeZone` فقط قبول `UTC` أو IANA `Area/Location` اسم، و عودة جواب هذا اسم في حالي منصة فوق مواصفة تجميع كتابة، لذلك آخر اسم لن دخول حمل دائم سجل: وقت منطقة معرف سوف تخزين في رسالة في، و من آخر عدد عملية قليلا بعد إعادة دفع توجيه؛ آخر اسم في هذا عملية في لا يمكن و مواصفة اسم مقارنة مقارنة لـ متبادل انتظار. هذا مكتبة فقط فعل تحقق و مواصفة تحويل——لا صيغة تحويل أي وقت، أيضا لا يحتفظ فشل مفردات، لأن كل حد رمي ذاتي ذات مجال رمز.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

هو هو**مكتبة، لا هو خدمة أيضا لا هو إضافة**: بلا `ctx`، لا تسجيل أي شرق غرب، لا يحتفظ حالة.

لا إصدار وقت التشغيل ثابت كمية مرافق توليد مدخل؛ هذا عدد صاف أداة لا يملك حدث تدفق أو متغير وقت التشغيل بيانات، وقت منطقة مواصفة تحويل من اختبار وحدة تحقق.

في استقبال وقت منطقة ذلك عدد حد فوق استدعاء هو، يجعل قيمة في دخول أي حمل دائم شيء قبل أولا مرور واحد مرة. غير ممكن استخدام اسم عودة جواب `undefined`، من استدعاء جهة رمي خروج ذاتي ذات رفض——Session نص التوجيه استخدام `session/invalid-time-zone`،subagent متابعة كلام استخدام `subagent/invalid-time-zone`.

<a id="api"></a>
## API

```ts
import { canonicalClientTimeZone } from '@deepseek-ai/dsh-util-time'
```

| توجيه خروج | مسؤولية |
|---|---|
| `canonicalClientTimeZone(value)` | مقابل قبول وقت منطقة عودة جواب مواصفة `UTC` أو IANA `Area/Location` اسم؛ فارغ سلسلة، حمل فارغ أبيض، تقليص كتابة، مفرد مقطع أو منصة لا دعم حمل اسم عودة جواب `undefined`. |

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أثر، أخذ قرار في يأخذ مواصفة وقت منطقة تسجيل إلى حمل دائم رسالة فوق ذلك عدد مستهلك——`dsh-time-context` حسب هذا تصيير هذا جولة نموذج مرئي وقت منطقة إشارة أمر و ختم الوقت.

#### KV Cache أثر

ذاته لا يوجد. يأخذ وقت منطقة إرسال توليد نص حقن طلب ذلك عدد مستهلك، مقابل هذا طلب ذاكرة مؤقتة سلوك مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **آخر اسم تحليل أخذ قرار في وقت التشغيل ICU بيانات**——واحد آخر اسم مجموعة مواصفة تحويل صار أي عدد اسم من منصة عودة جواب، لذلك اثنان عدد ركض في مختلف Node بناء فوق عملية ممكن إعطاء خروج مختلف جواب سجل.
- **فقط فعل تحقق**——لا صيغة تحويل، لا فعل انحراف نقل تشغيل حساب، لا دفع توجيه DST، لا فعل وقت لحظة تبديل حساب؛ حاجة هذه مستهلك مباشر استخدام `Intl`.
