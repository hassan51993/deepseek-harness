# @deepseek-ai/dsh-brand

[English](README.md) | العربية

## عام وصف

`dsh-brand` يجعل بنية نفسه نص أو عدد حرف في نوع طبقة وجه غير ممكن متبادل تبديل:`SessionId` لا يمكن نقل إعطاء مدة نظر `ToolCallId` موضع، حدث ترتيب رقم أيضا لا يمكن نقل إعطاء حاجة سجل انحراف نقل كمية موضع.`brandString<T>()` و `brandNumber<T>()` في لا يحتفظ مشترك وقت التشغيل حالة حال حال تحت تطبيق اسم معنى صنف لوحة، يجعل الذي تابع حزمة يمكن تعريف مجال نوع، بينما بلا حاجة استيراد لا متبادل صلة قدرة.

## استخدام هذه الحزمة

عند مجال قيمة عبر تجاوز حزمة حد، و ممكن و استخدام نفس أصل لغة يمثل آخر عدد قيمة خلط خلط وقت، لـ ذلك إضافة صنف لوحة؛ و غير كل نص أو عدد حرف كل حاجة صنف لوحة. صنف لوحة تحويل قيمة هو إعطاء TypeScript استدعاء جهة اتفاق: هو فقط سوف دخول مدة نظر هذا مجال دالة، مختلف صنف لوحة سوف في تحرير ترجمة مدة يتم رفض.

### لـ نص إضافة صنف لوحة

في الذي تابع حزمة في إعلان صنف لوحة تحويل نوع، و في هذا حزمة دقيق دخول نص موضع تطبيق صنف لوحة:

```ts
import { brandString, type Branded } from '@deepseek-ai/dsh-brand'

export type SessionId = Branded<'SessionId'>

const sessionId = brandString<SessionId>('session-1')
```

`brandString()` فقط تغيير ساكن حالة نوع، لا تنفيذ وقت التشغيل تحقق. الذي تابع نوع إذا لديه مجال نص قاعدة، ينبغي في استدعاء قبل إتمام تحقق. إضافة صنف لوحة بعد، هذا id في مقارنة مقارنة، سجل سجل،JSON تسلسل تحويل و بروتوكول نقل في ما زال جدول الآن لـ عادي نص.

### لـ عدد حرف إضافة صنف لوحة

في الذي تابع حزمة في إعلان عدد حرف صنف لوحة، و كما فقط في هذا حزمة دقيق دخول عدد حرف بعد تطبيق صنف لوحة:

```ts
import { brandNumber, type BrandedNumber } from '@deepseek-ai/dsh-brand'

export type SessionSeq = BrandedNumber<'SessionSeq'>

const seq = brandNumber<SessionSeq>(7)
```

`brandNumber()` أصل مثال إرجاع عدد حرف، لا تنفيذ تحقق. الذي تابع حزمة سوف في إضافة صنف لوحة قبل تحقق غير سالب أمان كامل عدد نطاق انتظار اشتراط. مقارنة مقارنة، حساب فن، سجل،JSON تسلسل تحويل و بروتوكول نقل إبقاء عادي عدد حرف سلوك؛ حساب فن سوف إنتاج لم صنف لوحة تحويل عدد حرف، الذي تابع حزمة يجب إعادة دقيق دخول هذا عدد حرف، عندئذ قدرة يجعل هو مجددا مرة دخول مجال.

### أي وقت إضافة صنف لوحة

لـ عبر حزمة حد كما ممكن يتم خلط خلط قيمة إضافة صنف لوحة——`dsh-llm` في `ToolCallId`،`dsh-session` في من agent(ذكي جسم) و جلسة مشترك `SessionId`،`dsh-jobs` في `JobId`، و `dsh-session` في `SessionSeq` و `SessionLogOffset`. إبقاء نطاق جزء أو لا يمكن خلط خلط قيمة لا حاجة هذا نوع سحب كائن.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا حزمة تعريف اثنان عدد تسليم تقاطع نوع:`string & { readonly [BRAND]: B }` و `number & { readonly [BRAND]: B }`، منها `BRAND` هو وحدة خاص `unique symbol`.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | صنف لوحة تحويل نص و عدد حرف نوع و ذلك بلا حالة بنية صنع دالة |
| — | لا إصدار وقت التشغيل ثابت كمية إعداد طقم مدخل؛ هذا عدد صاف أداة لا يملك حدث تدفق أو متغير وقت التشغيل بيانات؛ ذلك قيمة بديل عدد من اختبار وحدة حفظ عائق. |

### قيمة لـ أي يمكن نقل غرس

خاص symbol في وقت التشغيل لا وجود:TypeScript سوف سوف ذلك مسح حذف، لذلك صنف لوحة تحويل قيمة لا يوجد وسم أو prototype.`brandString()` و `brandNumber()` كل أصل مثال إرجاع إدخال. لذلك، ذاك هذا مستقل تثبيت فرعي هذا بلا حاجة مشترك سجل التسجيل أو constructor identity، أيضا سوف توليد يمكن متبادل تبديل قيمة.

### لـ أي إبقاء بلا اعتماد

يأخذ هذه helper وضع في مستقل حزمة في، معنى طعم حال `dsh-jobs` يمكن لـ `JobId` إضافة صنف لوحة، بينما بلا حاجة استيراد لا متبادل صلة قدرة حزمة؛ كل قدرة ما زال يملك ذلك أداة جسم id يحتوي معنى و تحقق.

## بحث إضافي

عند أنت حاجة هذه أصل لغة الذي صنف لوحة تحويل قيمة أو محيط التفاف هو جمع نوع اتفاق وقت، قراءة قراءة التالي صفحة.

- [نواة قلب فرعي نظام](../../../docs/subsystems/core.zh.md)——مشترك `SessionId` صنف لوحة و نوع قاعدة سجل موضع.
- [LSP فرعي نظام](../../../docs/subsystems/lsp.zh.md)——بناء في هذا أصل لغة لـ فوق صنف لوحة تحويل مزود id `LspProviderId`.
- [jobs حزمة](../../jobs/jobs/README.zh.md)——من jobs قدرة يملك `JobId` صنف لوحة.
