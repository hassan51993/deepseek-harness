# dsh-util-crypto

[English](README.md) | العربية

## عام وصف

صفر اعتماد، يمكن في متصفح استخدام UUID و بايت تحرير رمز مساعد مساعدة دالة.UUID صب صنع أساس في `crypto.getRandomValues`——كل إصدار سياق كل توفير ذلك عدد مع آلة أصل لغة.`crypto.randomUUID` هو أمان سياق حد تحديد Web API: مرور عادي HTTP في نطاق مجال شبكة عنوان فوق توفير صفحة أو worker(متصفح معاينة نشر) أصل هذا لا يوجد هذا عدد طريقة، يجب في ذلك داخل تشغيل شفرة لا يستطيع ضبط هو. كل مستودع `no-restricted-properties` lint قاعدة يأخذ `crypto.randomUUID` استدعاء من إشارة إلى هذا داخل؛ فقط ركض في Node شفرة من `node:crypto` استيراد `randomUUID` صيانة حمل أصل مثال.

<a id="api"></a>
## API

```ts
import { bytesToBase64, randomUUID, type Uuid } from '@deepseek-ai/dsh-util-crypto'
```

| توجيه خروج | زاوية لون |
|---|---|
| `bytesToBase64(data)` | بـ محدود قسم قطعة يأخذ بايت عدد مجموعة تحرير رمز لـ معيار base64. |
| `randomUUID()` | مع آلة RFC 9562 v4 UUID نص، من `crypto.getRandomValues` صب صنع. يمكن أصل موضع استبدال `crypto.randomUUID()`. |
| `Uuid` | خمسة مقطع صيغة UUID نص نوع، و `crypto.randomUUID` إعلان إرجاع شكل حالة متسق. |

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أرض، مرور من استخدام هو صب صنع طلب، جلسة و مرفق عنصر معرف رمز مستهلك، هذه معرف رمز متساو لا بصفة دلالة محتوى دخول نص التوجيه.

#### KV Cache أثر

بلا مباشر بطلان؛ صب صنع معرف رمز مستهلك ذاتي سطر مسؤول ذلك طلب تغير.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **فقط v4**——لا توفير أخرى UUID إصدار، نطاق الأسماء أو تحليل؛ حاجة أكثر كثير قدرة مستهلك ينبغي جذب دخول حق صحيح UUID اعتماد.
- **وحيد صفة هو عام معدل صفة**——122 موضع مع آلة، و `crypto.randomUUID` نفس درجة حفظ إثبات؛ هذا موضع لا فعل اصطدام اصطدام فحص قياس.
