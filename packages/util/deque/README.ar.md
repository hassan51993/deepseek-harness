# @deepseek-ai/dsh-deque

[English](README.md) | العربية

## عام وصف

`dsh-deque` يجعل Host و متصفح حزمة يمكن ترتيب فارغ طويل مدة وجود عملية داخل طابور صف، بينما بلا حاجة في كل مرة إزالة بعد نقل حركة كل باق بقية بند. استدعاء جهة يمكن إلحاق أو قبل إدراج بند، و بـ توزيع إلغاء معتاد عدد وقت من قبل طرف إزالة. مزدوج طرف طابور صف مسؤول بند ترتيب و بعد تجهيز تخزين تحرير؛ نداء تنبيه، فشل، إلغاء، سعة كمية و مرور تحميل سلوك ما زال من كل مستهلك مسؤول.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

### أي وقت استخدام

عند بند ممكن في مختلف خطوة عمل خلال حمل متابعة تراكم تراكم، كما مستهلك حاجة FIFO إزالة، اختياري قبل إدراج أو صريح صاف فارغ طابور صف وقت، استخدام `Deque<T>`. إذا لديه حد محلي عمل قائمة الأكثر كبير قاعدة نموذج جعل رأس جزء إزالة صار هذا غير متصل ضيق يلزم، هو يمكن متابعة استخدام عدد مجموعة.

### مدخل

استيراد مزدوج طرف طابور صف، في ذيل جزء إلحاق بند؛ عند بند نوع ممكن يتضمن `undefined` وقت، في إزالة قبل فحص `size`:

```ts
import { Deque } from '@deepseek-ai/dsh-deque'

const frames = new Deque<string>()
frames.pushBack('first')
frames.pushFront('before-first')

while (frames.size > 0) {
  console.log(frames.popFront())
}
```

هذه طريقة لا تطبيق إضافة طابور صف حد، أيضا لا تحويل مستهلك فشل. دقيق تأكيد TypeScript اتفاق رؤية [`src/index.ts`](src/index.ts).

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

مزدوج طرف طابور صف يأخذ بند تخزين دخول حلقة شكل عدد مجموعة. إزالة بند سوف قيام أي صاف فارغ مقابل مجرى موضع؛ حسب بضعة أي درجة عدد توسيع سعة و في أربعة قسم لـ واحد ممتلئ وقت تقليص سعة، جعل نسخ عمل إبقاء توزيع إلغاء معتاد عدد وقت، و منع توقف رأس تنقل علامة إبقاء حمل متابعة زيادة طويل فارغ خامل تخزين.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | حلقة شكل مزدوج طرف طابور صف عملية و بعد تجهيز تخزين دورة الحياة |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا عدد تجميع دمج لا يملك حدث تدفق أو مشترك متغير حالة، ذلك ترتيب و تخزين دورة الحياة من اختبار وحدة تغطية. |
| [`tests/deque.spec.ts`](tests/deque.spec.ts) | FIFO، قبل إدراج، حلقة التفاف، توسيع سعة، ضغط (compaction) ، صاف فارغ و إعادة استخدام تغطية |
| [`benchmarks/drain.ts`](benchmarks/drain.ts) | مع طابور صف قاعدة نموذج زيادة طويل يمكن تكرار الآن backlog ترتيب فارغ حساب وقت |

</details>

## تجربة النموذج

بلا، لأن هذا عدد عملية داخل تجميع دمج لا تسجيل أي موجه إلى نموذج محتوى.

#### KV Cache أثر

هذا داخل محتوى لن دخول نموذج طلب، لذلك لا أثر مزود ذاكرة مؤقتة إعادة استخدام.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- **لا يوجد سعة كمية سياسة**——مزدوج طرف طابور صف لن حد، دمج أو رفض بند؛ كل مستهلك يجب تعريف ملائم دمج ذلك تدفق مرور تحميل سلوك.
