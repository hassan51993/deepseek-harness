# @deepseek-ai/dsh-home-paths

[English](README.md) | العربية

## عام وصف

`@deepseek-ai/dsh-home-paths` يجعل حزمة عمل من قدرة كاف تحليل موحد واحد DeepSeek Harness بيانات أصل دليل، و من هو إرسال توليد فرعي مسار. صريح مسار أولوية في `$DSH_HOME`، بعد من أولوية في `~/.dsh`؛ فارغ أبيض بيئة متغير سوف يتم تجاهل اختصار. ذلك عام مساعد مساعدة دالة يمكن في لا كشف آلة جهاز قطعا مقابل مسار حال حال تحت عرض أصل دليل، فقط توسيع مفرد وحيد أو حالي مستخدم موجة موجة رقم شكل صيغة، و مواصفة تحويل نهائي مسار مقطع بعد لا وجود استماع هدف. طلب يأخذ هو بصفة مكتبة اعتماد مباشر استخدام، لا يلزم عبر `cordis.yml` تحميل.

## استخدام هذه الحزمة

عند حزمة يجب و harness أخرى جزء حينئذ مستخدم بيانات تخزين وضع موضع بلوغ صار متسق وقت استخدام هذه مساعد مساعدة دالة: أولا تحليل مرة رئيسي دليل، مجددا من في إرسال توليد كل فرعي مسار.

### تحليل رئيسي دليل

```ts
import { resolveDshHome, dshHomePath, dshCachePath } from '@deepseek-ai/dsh-home-paths'

const home = resolveDshHome()                // configured path, else $DSH_HOME, else ~/.dsh
const settings = dshHomePath('settings')     // join one child onto the resolved home
const cache = dshCachePath('models')         // $DSH_HOME/cache/models, default ~/.dsh/cache/models
```

صريح إعداد مسار أولوية درجة الأكثر عال، لكن بعد هو `$DSH_HOME`، الأكثر بعد هو افتراضي `~/.dsh`. فارغ أو فقط يحتوي فارغ أبيض `$DSH_HOME` نظر لـ لم ضبط، لذلك فارغ أبيض تغطية قيمة أبدا سوف يأخذ رئيسي دليل تحليل إلى حالي عمل دليل.

`dshCachePath(...segments)` من تحليل خروج رئيسي دليل تحت `cache` دليل إرسال توليد مسار. لا نقل مسار مقطع وقت إرجاع ذاكرة مؤقتة دليل ذاته. نقل دخول أول عدد خيار كائن `dshCachePath({ dshHome: home }, ...segments)` يمكن استخدام صريح إعداد رئيسي دليل، التزام دوران نفسه أولوية درجة و موجة موجة رقم توسيع قاعدة. هو إرجاع قطعا مقابل مسار، لن إنشاء دليل.

### عرض رئيسي دليل

موجه إلى مستخدم مسار طلب بـ رمز رقم شكل صيغة تصيير أصل دليل، بينما لا هو آلة جهاز مسار: افتراضي رئيسي دليل عرض لـ `~/.dsh`، أي قد إعداد رئيسي دليل عرض لـ `$DSH_HOME`. عرض شكل صيغة أبدا سوف تسرب كشف آلة جهاز قطعا مقابل مسار.

### توسيع مستخدم مسار

`expandHomePath` إبرة مقابل عملية نظام رئيسي دليل توسيع فتح رأس `~`،`~/` أو `~\`، ذلك بقية محتوى أصل مثال إبقاء——غير موجة موجة رقم مسار و `~alice/...` انتظار إشارة تحديد مستخدم شكل صيغة لا فعل أي تعديل.

### مواصفة تحويل استماع مسار

`canonicalizeWatchPath` لـ أصلي نظام الملفات watcher توفير هدف مسار واحد نوع مواصفة تحويل كتابة قاعدة: أولا عبر `realpath` تحليل طبقة درجة الأكثر عميق قائم أصل أولا، مجددا تجميع عودة ناقص بعد لاحقة، لذلك ملف أو دليل في إنشاء قبل حينئذ يمكن يتم استماع. هذا يمكن منع توقف Windows يأخذ عادي ملف أصل أولا عند عمل عادي ناقص معالجة، أيضا منع توقف 8.3 قصير اسم آخر اسم و أصلي watcher خلفية إرسال خروج طويل مسار خلط استخدام.

### تحليل قاعدة

`resolveDshHome` أولا قراءة صريح تغطية قيمة، لكن بعد قراءة `$DSH_HOME`، الأكثر بعد رجوع إلى عملية نظام رئيسي دليل تجميع وصل `.dsh`. اختيار في قيمة مرور مرور موجة موجة رقم توسيع و مواصفة تحويل لـ قطعا مقابل مسار؛`dshHomePath` استخدام Node منصة مسار قاعدة تجميع وصل فرعي مسار مقطع.`dshHomeDisplay` يأخذ تحليل خروج مسار و افتراضي أصل دليل مقارنة مقارنة و إرجاع رمز رقم وسم، لذلك قد إعداد رئيسي دليل أبدا تسرب كشف ذلك قطعا مقابل مسار.

### مواصفة تحويل آلية

`canonicalizeWatchPath` من هدف نحو فوق تدريجي درجة فحص بحث، مباشر إلى بحث إلى قائم أصل أولا، استخدام `realpath` تحليل هو، إثبات هو هو يمكن قطعة رفع دليل، مجددا تجميع عودة ناقص بعد لاحقة. حذف مسار لا وجود بـ خارج خطأ كل سوف نقل بث؛ ناقص بعد لاحقة أصل أولا إذا لا هو دليل فإن يتم رفض.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذه مساعد مساعدة دالة أي وقت لا هو دمج ملائم أداة. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **توسيع نطاق لحظة معنى إبقاء ضيق ضيق**——فقط لديه مفرد وحيد `~`،`~/...` و `~\...` استخدام حالي عملية نظام رئيسي دليل؛`~alice/...` انتظار إشارة تحديد مستخدم شكل صيغة، بيئة متغير و shell جدول بلوغ صيغة إبقاء ثابت.
- **مواصفة تحويل فقط قراءة لا تعديل**——`canonicalizeWatchPath` تنفيذ `realpath` استكشاف قياس و نقل بث حذف مسار لا وجود بـ خارج خطأ؛ استدعاء جهة ما زال مسؤول دليل إنشاء، إذن، و مقابل نتيجة مسار تطبيق معلومة مهمة سياسة.
