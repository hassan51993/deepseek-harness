# @deepseek-ai/dsh-http-proxy

[English](README.md) | العربية

## عام وصف

استخدام هذه الحزمة يمكن لـ اعتماد Node داخل وضع `fetch` Harness طلب تطبيق واحد نسخة خروج محطة HTTP بديل إدارة سياسة، يشمل LLM(كبير لغة نموذج) ،web بحث و HTTP MCP تدفق كمية. بدء جهاز فقط قراءة مرة معيار بديل إدارة بيئة متغير، عادي `fetch` استدعاء جهة بلا حاجة مقدار خارج جذب دخول أو تعديل.loopback تدفق كمية إبقاء مباشر وصل؛ لا تلقي دعم حمل بديل إدارة URL سوف يتم تقرير إبلاغ، و إبرة مقابل تلقي أثر بروتوكول قفز مرور. عام مشترك مساعد مساعدة دالة يمكن يجعل استدعاء جهة توجيه اعتماد ذاتي لديه بديل إدارة ضبط نقل، دقيق تجهيز عملية فرعية بيئة، أو لـ عزل إعادة تشغيل صاف حذف بديل إدارة متغير.

## استخدام هذه الحزمة

بلا حاجة تركيب، أيضا بلا حاجة إعداد.`dsh` بدء جهاز سوف في رقم واحد إضافة تحميل قبل، لـ كل profile تحليل و تثبيت سياسة، لذلك توجيه خروج `HTTPS_PROXY` مستخدم في كل موضع كل سوف مشي بديل إدارة. هذه الحزمة هو مكتبة بينما غير إضافة، لأن نقل سياسة كل عملية فقط لديه واحد جواب سجل: لا يوجد ثاني عدد تنفيذ يمكن استبدال، أيضا لا يوجد مقارنة عملية أكثر ضيق أثر مجال يمكن منح إعطاء.

### تحرير كتابة جديد خروج محطة استدعاء

عادي `fetch()` سوف مشي بديل إدارة، أي استخدام `globalThis.fetch` SDK أيضا واحد مثال——MCP HTTP نقل و pi-ai مزود مكدس كل استخدام هو. ينبغي تحقق كل SDK فعلي نقل؛ مثال خارج رؤية[معروف حد و تأخير بعد عمل](#known-limitations-and-deferred-work).

| أنت يلزم كتابة شرق غرب | استخدام |
|---|---|
| عادي طلب، أو نهائي سقوط إلى `globalThis.fetch` SDK | ماذا كل لا استخدام——عام dispatcher قد في توجيه هو |
| حاجة حسب “هذا مرة طلب هل مشي بديل إدارة” فرع استدعاء | `proxyRouteFor(url)` |
| قبول ذاتي لديه بديل إدارة URL SDK | `proxyRouteFor(url)`، يأخذ `route.proxy` نقل دخول ذهاب |
| من أنت ذاتي ذات بنية صنع بيئة spawn | يأخذ `proxyEnvironmentForChild()` تطبيق إلى هذا spawn(`undefined` يمثل حذف) |
| يجب وصل إلى ذاتي حمل fixture(اختبار قبل وضع بيانات) خادم harness | يأخذ `clearedProxyEnv()` تطبيق إلى هذا spawn |

`proxyRouteFor` إعطاء خروج لا فقط هو جواب سجل، أيضا لديه هذا جواب سجل الذي زائف تحديد نقل: مشي بديل إدارة ذلك واحد دعم يحمل حال هذا لحظة صحيح حسب هذا سياسة توجيه dispatcher. إذا استدعاء جهة أولا قراءة سياسة، مجددا ذاتي بناء نقل، إزالة حينئذ ممكن سقوط في اثنان مرة قراءة بين، يأخذ طلب إرسال نحو ذلك فرع من لم وضع سطر ذهاب موضع.

بنية صنع `new Agent(...)` مجددا بصفة `dispatcher` نقل دخول سوف تغطية عام dispatcher، من بينما ساكن صامت التفاف فتح بديل إدارة.`verify-no-bare-dispatcher` سوف في هذه الحزمة خارج رفض هذا كتابة قاعدة. لديه واحد موضع استدعاء نقطة تأكيد فعلي ذاتي لديه نقل——`web-fetch-http` سوف يأخذ طلب تثبيت في هو قد تحقق مرور عنوان فوق، بينما هذا هو عملية درجة dispatcher لا يمكن تحمل تحميل مفرد مرة طلب حالة——هو في هذا سطر استخدام `proxy-exempt:` ملاحظة تفسير شرح.

هذا بوابة نظر لا دخول SDK داخلي، لذلك كل خروج شبكة نقطة كل إعداد لديه `egress.spec.ts`، عبر زائف بديل إدارة قيادة فعلي نقل و فحص مراقبة إلى توجيه. كل جديد خروج شبكة نقطة يجب يتضمن هذا نقل اختبار. بعيد قياس تأكيد ذلك مباشر وصل مثال خارج. هذه اختبار يمكن اكتشاف استدعاء نقطة ثابت لكن اعتماد تغيير تغيير توجيه حال حال.

### سياسة قراءة أي بعض قيمة

`http_proxy`،`https_proxy`،`no_proxy` و `all_proxy`، صغير كتابة أولوية، كبير كتابة التقاط قاع، فارغ قيمة نظر لـ لم ضبط.`ALL_PROXY` لـ اثنان نوع بروتوكول التقاط قاع،HTTPS الأكثر بعد رجوع إلى HTTP بديل إدارة——منها رقم واحد بند Node و undici كل لن ذاتي سطر دفع توجيه. أخذ قيمة قدوم ذاتي بدء جهاز لقطة: أولا نظر توجيه خروج بيئة متغير، مجددا نظر `$DSH_HOME/.env`. مشروع ذاتي ذات `.env` لا يستطيع يحمل هذه اسم حرف——ذلك عدد ملف مع clone واحد بدء إلى قدوم، بدء جهاز هدوء يمكن رفض بدء، أيضا لا يجعل واحد مستودع قرار Harness يأخذ تدفق كمية إرسال نحو أي موضع.

loopback بداية نهاية يتم التفاف مرور——`localhost`، كامل `127.0.0.0/8` مقطع،`::1`،`0.0.0.0`، و هو جمع IPv4 خريطة كتابة قاعدة. لا فإن Harness ذاتي ذات Web UI،Connection نقل و كل واحد محلي اختبار خادم كل سوف مرور من بديل إدارة و شكل صار عودة حلقة. إصدار خروج ذهاب التفاف مرور قائمة فقط يتضمن قراءة بيئة إزالة استهلاك من قدرة مطابقة أربعة عدد حرف وجه كمية بند؛`proxyForUrl` ذاتي سطر تعرف آخر كامل شبكة مقطع، لأن قائمة بند لا يمكن جدول بلوغ واحد نطاق.

### فشل معالجة

هذه الحزمة لا يمكن استخدام بديل إدارة قيمة——SOCKS أو PAC URL، لا يمكن تحليل نص، لا تلقي دعم حمل بروتوكول——سوف يتم تقرير إبلاغ و قفز مرور، هذا scheme تحويل لـ مباشر وصل. هذا متغير ممكن هو مستخدم لـ أخرى أداة توجيه خروج، لا ينبغي لذلك منع توقف agent(ذكي جسم) بدء.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

### تصميم إدارة فكرة

**مرة تحليل، واحد مطابقة جهاز.** `proxyForUrl()` و قد تثبيت dispatcher أبدا قدرة مقابل نفس عدد URL إعطاء خروج مختلف جواب سجل، لا فإن `dsh-web-fetch-http` سوف يأخذ dispatcher هذا ضرب حساب نفق طريق تحويل إرسال اتصال ثابت إلى بعض عدد عنوان فوق. لذلك هذا dispatcher هو واحد `Agent`، ذلك حسب origin استدعاء `factory` ذاته استدعاء `proxyForUrl()`، لا وجود ممكن و رقم واحد محلل إنتاج عائم نقل ثاني عدد محلل.undici `EnvHttpProxyAgent` في هذا لا يمكن فوز مهمة: لا يوجد `HTTPS_PROXY` وقت هو يجعل `https:` إعادة استخدام HTTP بديل إدارة، في هو هذه الحزمة في رفض مستخدم لـ هذا scheme إشارة تحديد URL بعد هذا ينبغي إبقاء مباشر وصل scheme ما زال سوف يتم نفق طريق تحويل إرسال.

**عملية فرعية وراثة مستخدم ذاتي ذات قيمة، و مستخدم لم ضبط جزء تحليل نتيجة.** مستخدم بـ مهمة واحد كبير صغير كتابة إشارة تحديد مرور scheme، سوف بـ هو جمع كتاب كتابة شكل صيغة أصل مثال نقل إعطاء عملية فرعية، لذلك مستخدم لـ `curl` ضبط SOCKS بديل إدارة أبدا سوف يتم استبدال يصبح أخرى scheme إشارة تحديد HTTP بديل إدارة. اثنان نوع كبير صغير كتابة كل لم إشارة تحديد scheme فإن يحمل تحليل قيمة، لا فإن عملية فرعية توجيه سوف و أب عملية قسم اختلاف:Node `NODE_USE_ENV_PROXY` لا قراءة `ALL_PROXY`. التفاف مرور قائمة بداية نهاية اعتماد تحليل نتيجة——هو فقط سوف إلحاق loopback بند، مستخدم كتابة تحت محتوى لن فقد فقد. يجعل أب عملية فرعية فقط لديه واحد توجيه جواب سجل بديل قيمة هو:`curl` أيضا سوف يرى هذه الحزمة من HTTP بديل إدارة دفع توجيه خروج `https:` بديل إدارة. لديه واحد موضع مثال خارج هو لـ حفظ حماية عملية فرعية ذاته: عند عملية فرعية استلام إلى بعض عدد قيمة هو هذه الحزمة رفض مرور——مقارنة مثل لـ `curl` إبقاء SOCKS URL——حينئذ لم يعد ضبط `NODE_USE_ENV_PROXY`، لأن Node في هذا علامة سجل تحت سوف في تشغيل برنامج قبل أولا تحليل `HTTP_PROXY` و `HTTPS_PROXY`، لقاء إلى هذا صنف قيمة مباشر خروج. هذا وقت فرعي Node مباشر وصل (هذا عملية قد لـ هذا بروتوكول مثل هذا تقرير إبلاغ) ، بينما لا هو أصل هذا بدء لا قدوم.

### شفرة المصدر أرض رسم

| ملف | تحمل تحميل |
|---|---|
| `src/policy.ts` | تحليل و التفاف مرور مطابقة؛ تشخيص فقط نقطة اسم متغير، من لا حمل خروج هو قيمة. لا جذب دخول أي نقل تنفيذ، لذلك في لا يوجد undici بيئة في ما زال يمكن تحميل. |
| `src/install.ts` | عام dispatcher، توليد فاعلية سياسة سجل، توجيه و عملية فرعية بيئة. حركة حالة جذب دخول undici. |
| `src/index.ts` | هذه الحزمة مقابل خارج واجهة: أربعة عدد دالة و واحد نوع. |

### التفاف مرور مطابقة

واحد بند كتابة هو رئيسي آلة اسم، هو وصل نفس ذلك تحت كل فرعي مجال اسم واحد بدء مطابقة:`NO_PROXY=example.com` أيضا سوف وضع سطر `api.example.com`. بادئة `.` أو `*.` يمكن كتابة، يحتوي معنى نفسه. بند يمكن حمل `:port`،`*` فإن وضع سطر الكل. حمل جهة تضمين رقم و عار كتابة IPv6 حرف وجه كمية كل قدرة مطابقة——عار كتابة `::1` **لن**يتم قراءة صار رئيسي آلة `:` طرف فتحة `1`، بينما undici ذاتي حمل مطابقة جهاز صحيح هو هذا مثال خروج خطأ، هذا أيضا هو تحليل نتيجة في معا يحمل `::1` و `[::1]` سبب.CIDR لا مشاركة و مطابقة: عملية نظام التفاف مرور قائمة معتاد يحتوي `10.0.0.0/8`، يجب تعديل كتابة صار بعد لاحقة شكل صيغة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد هذه الحزمة لا ملائم استخدام مشهد، يخص حالي حزمة درجة قيد.

- **لا دعم حمل SOCKS،PAC أو عملية نظام بديل إدارة استكشاف قياس**——فقط قبول قدوم ذاتي بيئة `http(s)://` بديل إدارة URL. لن قراءة macOS أو Windows نظام بديل إدارة ضبط، لذلك فقط في بديل إدارة لين عنصر داخل تحويل فتح صلة مستخدم ما زال يجب توجيه خروج بيئة متغير؛SOCKS URL سوف يتم تقرير إبلاغ، كما هذا بروتوكول إبقاء مباشر وصل، لن استعارة استخدام آخر بروتوكول بديل إدارة.
- **لا دعم حمل ذاتي تعريف إثبات كتاب إصدار إرسال آلة بنية**——فعل TLS اعتراض قطع مؤسسة عمل بديل إدارة حاجة في بدء قبل لـ عملية ضبط `NODE_EXTRA_CA_CERTS`، هذه الحزمة حيث لا ضبط أيضا لا تحقق هو.
- **spawn خروج عملية فرعية فقط في كاف كاف جديد وقت التشغيل فوق التزام دوران سياسة، كما فقط عند هو وراثة كل قيمة كل هو Node قبول**——هو عبر Node `NODE_USE_ENV_PROXY` قراءة قد إصدار بيئة (22.21+،24+) ، بينما engines نطاق سماح 22.19 و 22.20، في هذا اثنان عدد إصدار فوق هذا مثال عملية فرعية إبقاء مباشر وصل. إذا مستخدم بيئة داخل أيضا لديه SOCKS أو أخرى يتم رفض بديل إدارة، كل فرعي Node كل إبقاء مباشر وصل: لا ضبط هذا علامة سجل، عملية فرعية عندئذ بدء نيل قدوم. عملية فرعية أيضا سوف حسب Node ذاتي ذات `NO_PROXY` قاعدة مطابقة التفاف مرور بند، ذلك قسم فصل رمز و IPv4 منطقة بين معالجة و هذه الحزمة مختلف. هذا عملية داخل لا اعتماد أي Node إصدار: كل مرة عملية داخل طلب كل سوف سقوط إلى عام dispatcher.
- **بعيد قياس حسب تصميم مباشر وصل**——OTLP توجيه خروج جهاز عبر `node:http` إلقاء تمرير، عام dispatcher لمس و لا إلى. يلزم يجعل هو مشي بديل إدارة، يلزم ما اعتماد `http.Agent` `proxyEnv`، بينما هذا خيار متأخر في هذا مشروع دعم حمل الأكثر منخفض Node إصدار؛ يلزم ما تعديل استخدام SDK `fetch` نقل، لكن هو لا يوجد ضغط قدرة، بينما مع مرفق إعداد تفعيل gzip. بعيد قياس هو وحيد واحد بند فقد فقد بعد لن يجعل مستخدم دفع خروج أي بديل قيمة عبر طريق، لذلك صيانة حمل أصل حالة؛`DSH_TELEMETRY_MODE=DISABLED` يمكن إغلاق هو.
- **نموذج تحرير كتابة برنامج لا استقبال بديل إدارة إعداد**——Node ptc-runtime عملية و workflow worker لا وراثة ممكن يحتوي لديه `user:password` بديل إدارة URL. ذلك مباشر طلب حاجة ذاتي سطر إعداد، و متابعة تلقي إلى تنفيذ صندوق رملي قيد.
- **منع ارتداد بوابة فقط نظر شفرة المصدر، نظر لا إلى اعتماد داخلي**——`verify-no-bare-dispatcher` تحليل `packages/*/*/src` و `apps/*/src`؛ اختبار، نص برمجي و رقم ثلاثة جهة SDK داخلي كل في ذلك خارج. هذا صحيح هو كل خروج شبكة نقطة أيضا كل إعداد واحد نسخة `egress.spec.ts` سبب.
