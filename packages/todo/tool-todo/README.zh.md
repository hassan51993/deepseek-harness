# @deepseek-ai/dsh-tool-todo

[English](README.md) | العربية

## عام وصف

`dsh-tool-todo` لـ agent(ذكي جسم) توفير واحد نسخة متاح في قاعدة تخطيط بنية تحويل مهمة قائمة: يأخذ كثير خطوة عمل تفكيك صار أداة جسم مهمة، علامة صحيح في إجراء مهمة، إتمام بعد تدريجي بند ربط إسقاط. قائمة عبر جولة، عبر إعادة فتح جلسة حمل متابعة وجود،agent و UI بداية نهاية يرى الأكثر جديد حساب تخطيط. واحد إعداد فتح صلة قرار هل سماح كثير عدد مهمة معا موضع في إجراء في، ملائم لأجل و سطر فتح عرض عمل agent. كل هو أمل نظر agent صيانة مرئي مهمة قائمة مشهد كل يمكن استخدام هو؛ كل مرة تحديث كامل جسم استبدال قائمة، فقط لديه يملك هذا قائمة agent جلسة عندئذ قدرة تعديل.

## استخدام هذه الحزمة

عند أنت أمل نظر agent في عمل وقت صيانة واحد نسخة مرئي مهمة قائمة وقت استخدام هذه الحزمة: قاعدة تخطيط كثير خطوة عمل، عرض حالي إجراء في مهمة، سجل إتمام حال حال. تركيب هو و ضبط و سطر فتح صلة هو وحيد إعداد خطوة؛ هذا بعد كل مرة حساب تخطيط تغير،agent كل سوف عبر هو ذاتي ذات قاعدة تخطيط أداة تحديث قائمة.

### أي وقت اختيار

عند بعض عدد agent جلسة ينبغي عند يملك مهمة قائمة، كما كامل جدول تحديث يكفي ممتلئ كاف يحتاج طلب وقت اختيار هو——هذا هو قاعدة تخطيط أداة معتاد رؤية شكل. عند كثير عدد agent يجب مشترك نفس نسخة قائمة، أو حاجة تدريجي بند تحرير وقت، طلب تجنب فتح: قائمة فقط يخص واحد agent، كل مرة تحديث كل سوف استبدال كامل قائمة. هو اشتراط بيئة في تأكيد فعلي وجود agent جلسة؛ من لا تشغيل agent صاف تلقائي تحويل مدخل لا يمكن استخدام هو.

### الأكثر صغير إعداد

`allowParallelInProgress` هو لا بد ملء بند، لا يوجد قيمة افتراضية: حذف هو تركيب سوف في تحميل وقت فشل، غير قيمة منطقية أيضا سوف يتم رفض. ممكن تزامن تشغيل عمل agent(subagent، خلفية أمر، سير العمل مروحة خروج) ضبط لـ `true`، حاجة مفرد نشط وثب بند سجل قاعدة ضبط لـ `false`.

```yaml
- name: '@deepseek-ai/dsh-tool-todo'
  config:
    allowParallelInProgress: true
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `allowParallelInProgress` | لا بد ملء | هل سماح كثير عدد todo معا موضع في `in_progress`؛ معا اختيار نموذج وصف في نشط وثب حالة بند بند |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-tool-todo) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### كل مرة استدعاء فعل ماذا

agent كل مرة تحديث كل إرسال كامل قائمة؛ جديد قائمة استبدال قديم قائمة، لذلك لا يوجد جزء تحديث أو تدريجي بند تحرير. كل بند هو واحد جملة بسيط قصير مهمة وصف، خارج إضافة `pending`،`in_progress` أو `completed` حالة. نجاح تحديث سوف إرجاع جديد حساب عدد——`Updated todo list: <pending> pending, <inProgress> in progress, <completed> completed.`——UI مع أي عرض جديد حساب تخطيط. مهمة وصف لـ فارغ أو تكرار، بند حمل لديه وصف و حالة خارج حقل، أو (منع استخدام و سطر وقت) كثير عدد مهمة يتم علامة لـ إجراء في، هذه حال حال تحت تحديث كل سوف واضح فشل.

### مفرد واحد كل من

مهمة قائمة يخص إنشاء هو ذلك واحد agent جلسة——subagent و أخرى agent كل منها صيانة ذاتي ذات قائمة، لا وجود عبر agent مشترك قائمة طريقة. قدوم ذاتي agent جلسة خارج استدعاء سوف يتم رفض، لذلك agent سوف نيل معرفة تحديث فشل، بينما لا هو يتم ساكن صامت إسقاط. إذا أنت حاجة كثير عدد agent مشترك نفس نسخة قائمة، هذه الحزمة لا توفير هذا قدرة.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أداة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

هذا أداة بناء قيام في أربعة بند تحمل وعد لـ فوق:

- **كامل جدول استبدال، سجل تحمل تحميل حالة.** نموذج إعادة إرسال كامل قائمة؛`todo/write` لقطة تخزين وضع في حدث تتبع مصدر جلسة سجل فوق، حمل دائم صفة، إعادة تشغيل و استعادة إعادة بناء كل قدوم ذاتي سجل بينما غير خدمة.
- **مفرد واحد كل من.** قائمة يخص استدعاء agent جلسة؛ لا وجود مشترك أو swarm أثر مجال، غير agent استدعاء جهة سوف يتم رفض.
- **نشر سياسة، بينما غير تحرير رمز قاعدة.** `allowParallelInProgress` هو لا بد ملء تركيب اختيار، لأن أداة لا يمكن مراقبة قياس وقت التشغيل تزامن؛ حمل دائم سجل ثابت صيغة لحظة معنى لا تتبع مع هو، لذلك واحد نوع سياسة تحت كتابة سجل في تبديل إلى آخر نوع سياسة بعد ما زال يمكن إعادة تشغيل.
- **تحقق تأكيد حفظ سجل لقطة مثل فعلي عكس عكس إدخال.** schema طبقة رفض لم معرفة مفتاح،`execute` طبقة رفض فارغ أو تكرار content، جعل حمل دائم لقطة و نموذج ذاتي إقرار لـ كتابة محتوى متسق.

[todo_write أداة Agent Note](../../../.agents/notes/archived/feature/2026-06-29-todo-write-tool.md) سجل أصلي تصميم و تجهيز اختيار خطة؛[و سطر in-progress Agent Note](../../../.agents/notes/archived/feature/2026-07-26-todo-parallel-in-progress.md) سجل هذا سياسة قرار.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`Config` schema، أداة تسجيل،`todos` إسقاط وحدة |
| [`src/types.ts`](src/types.ts) | `todos` إسقاط مفتاح إعلان و ذلك تحميل حمل نوع وحيد ملكية أرض |
| [`src/client.ts`](src/client.ts) | عميل نطاق الأسماء مقابل نوع خروج فتحة مجددا توجيه خروج |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة: تحقق حمل دائم كامل جدول لقطة و فتح وضع جولة ملكية |

### توجيه خروج شكل حالة

هذا إضافة هو دالة/نطاق الأسماء إضافة: توجيه خروج `name`،`inject`،`apply`، لا يوجد افتراضي توجيه خروج. كثير بقية `export default` سوف يجعل Loader `unwrapExports` طي وحدة و إسقاط `inject`(مشاركة رؤية [postmortem 0001](../../../docs/postmortem/0001-acp-default-export-drops-inject.zh.md)).

### جلسة إسقاط

عند تركيب تركيب `ctx.sessionProjections`([`@deepseek-ai/dsh-session-projection`](../../session/session-projection/README.zh.md)) وقت، هذه الحزمة في حقن فرعي إضافة في تسجيل `todos` وحدة: إسقاط أي صالح حساب تخطيط——الأكثر جديد كامل نسخة `todo/write` قائمة، أول مرة كتابة قبل لـ `null`، تحت واحد جولة بدء وقت صاف فارغ، بينما `turn/end` إبقاء للتو إتمام بيان. هذا مفتاح في هذا موضع دمج دخول `SessionProjectionMap`؛ تحميل جسم عبر تاريخ ذيل صفحة و `session/projection` دفع إرسال لقطة توفير هذا قيمة. لم تركيب سجل التسجيل تركيب لا تلقي أثر؛ وحدة تسجيل رؤية [src/index.ts](src/index.ts).

### حمل دائم سجل ثابت صيغة

ثابت صيغة مرافق توليد إضافة تسجيل إلى `ctx.invariants`، أولا قسم آخر تحقق قائم جلسة و جديد عام نشر جلسة مرة، مجددا لـ فوري إلحاق دفع دخول حسب جلسة إيداع جولة مسار أثر. هو سوف رفض شاذ شكل بند، فارغ أو تكرار content، لم معرفة حالة، و فتح وضع جولة خارج حمل دائم `todo/write`؛ نواة قلب session عام معالجة إعلان دمج حدث، بينما هذا إنتاج حزمة يملك todo مخصص استخدام قاعدة. هو لحظة معنى لا قيد لديه كثير قليل بند موضع في `in_progress`، لأن ذلك هو أداة حسب نشر صنع تحديد سياسة، بينما غير حمل دائم بيانات قاعدة.

### استدعاء آلية

كل مرة استدعاء كل سوف أولا تحقق إيداع قائمة هل رمز دمج schema، رفض لا متسق إدخال، نجاح بعد يأخذ كامل لقطة بصفة `todo/write` جلسة حدث إلحاق و إرجاع جديد حساب عدد؛ حالي قائمة بداية نهاية هو سجل في الأكثر قريب مرة `todo/write`(إعادة تشغيل وقت بعد كتابة تغطية أولا كتابة). تأكيد قطع تحقق و إلحاق خطوة رؤية [src/index.ts](src/index.ts).

<a id="model-experience"></a>
## تجربة النموذج

### أداة schema

#### نموذج يرى ماذا

نموذج سوف يرى توليد [`todo_write` schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-todo): واحد كائن، يحتوي واحد لا بد ملء `todos` عدد مجموعة، عنصر عنصر لـ `{ content, status }`، منها `status` لـ `pending`،`in_progress` أو `completed`. وصف هو تركيب بعد كامل جدول إشارة أمر، ذلك نشط وثب حالة بند بند تتبع مع `allowParallelInProgress`.

#### Token أثر

أداة مرئي كل طلب كل لديه ثابت schema فتح إلغاء؛ في إعطاء تحديد إعداد تحت وصف و schema إبقاء مستقر.

#### KV Cache أثر

تعريف و مرئي صفة ثابت وقت بادئة إبقاء مستقر. إضافة دورة الحياة أو أثر مجال حد ممكن جعل من هذا schema بدء إعادة استخدام بطلان.

### أداة استدعاء تاريخ و نتيجة

#### نموذج يرى ماذا

كل مرة assistant أداة استدعاء كل سوف في معامل في إبقاء كامل استبدال قائمة. نجاح وقت أصل مثال إرجاع `Updated todo list: <pending> pending, <inProgress> in progress, <completed> completed.`. مستقر فشل نص لـ ``Error: invalid todo: `content` must be a non-empty string``،`Error: invalid todos: duplicate content "<content>"`،`Error: todo_write requires an owning agent session`، و——فقط في نشر ضبط `allowParallelInProgress: false` وقت——`Error: invalid todos: at most one task may be in_progress (got <n>)`. كامل `todo/write` جلسة حدث هو UI و إعادة تشغيل حالة، بينما غير ثاني بند نموذج رسالة.

#### Token أثر

token استخدام كمية مع نموذج كل مرة إيداع كامل قائمة زيادة طويل، هذه استدعاء معامل سوف إبقاء إلى ضغط (compaction). نتيجة ذاته جدا صغير كما شكل حالة ثابت.

#### KV Cache أثر

فقط إلحاق؛ جديد مرئي محتوى يقع في يمكن إعادة استخدام طلب بادئة بعد، لن جعل قائم KV-cache بند بطلان.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أداة أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **فقط مفرد واحد كل من أثر مجال**——قائمة يخص وحيد استدعاء agent جلسة؛subagent، مشترك و swarm أثر مجال هو متعمد ضبط حد، غير agent استدعاء جهة سوف يتم رفض.
- **بند شكل حالة لحظة معنى إبقاء الأكثر صغير**——`content` إضافة ثلاثة حالة `status`؛ كامل جدول استبدال لا حاجة مستقر id، أولوية درجة أو active-form حقل.
- **كامل جدول استبدال هو وحيد عملية**——لا يوجد جزء تحديث، لا يوجد عودة قراءة أداة، لا يوجد تدريجي بند تحرير؛ نموذج كل مرة استدعاء كل يجب إعادة إرسال كامل قائمة.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: لم قرار مشكلة و بعد لم قرار جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص، حزمة شفرة و متبادل صلة Agent Note لـ دقيق.

#### لم قدوم: عبر agent و مشترك قائمة

مفرد واحد كل من أثر مجال هو متعمد ضبط حد، عبر agent أو مشترك قائمة ما زال هو مستقل لم قدوم تصميم: هو جمع حاجة تدريجي بند سجل زيادة كمية و صريح أثر مجال اختيار، و سوف تغيير نموذج مرئي اتفاق. هدف قبل بعد لا وجود تصميم.

</details>
