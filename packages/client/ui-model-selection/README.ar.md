# @deepseek-ai/dsh-client-ui-model-selection

[English](README.md) | العربية

## عام وصف

Web GUI سماح مستخدم عبر `/model` نابض نافذة أو composer نموذج تحكم عنصر تبديل قائم جلسة استخدام نموذج و دفع إدارة (reasoning) قوي درجة. اثنان عدد واجهة عرض نفس مجموعة حسب مزود قسم مجموعة اختيار؛ الذي اختيار نموذج قرار متاح دفع إدارة قوي درجة اسم و قيمة افتراضية. كامل اختيار من تحت مرة طلب بدء توليد فاعلية؛ تشغيل في خطوة إبقاء ذلك بدء وقت نموذج و دفع إدارة قوي درجة. إذا لا يوجد مهايئ يمكن خدمة جلسة توجيه،composer سوف إبقاء توقف استخدام، مباشر حتى توجيه استعادة متاح.

## استخدام هذه الحزمة

و `ui-conversation` و أمر حزمة واحد بدء تركيب هذا إضافة؛composer مع أي في انتظار معالجة إشارة عرض جهاز جانب عرض نموذج موضع،`/model` فإن بـ نابض نافذة فتح نفس نسخة دليل. نموذج موضع قائمة مفرد فتح خلال،`↑`/`↓` في الذي عرض وجه لوح سطر بين نقل حركة تركيز نقطة،`Tab` اختيار تحديد تجمع تركيز سطر،Escape و `Shift+Tab` أولا خروج قد تحت حفر وجه لوح، لا فإن إغلاق و عودة إلى إطلاق جهاز. تحت حفر سقوط في صحيح في استخدام ذلك واحد سطر، إرجاع فإن سقوط في فتح هذا وجه لوح إطار فرعي فوق. عند تأكيد قطع مزود/نموذج مقابل ما زال في قد عام نشر قسم مجموعة في وقت، اثنان عدد واجهة كل عرض Host تقرير إبلاغ حالي اختيار؛ دليل سطر نقص مقعد وقت، يمكن توجيه اختيار إبقاء ثابت، إطلاق جهاز تلميح `Select model`.

### نموذج و دفع إدارة قوي درجة

نموذج حسب مزود قسم مجموعة.composer قائمة مفرد فقط عرض نموذج و دفع إدارة قوي درجة اسم.`/model` نابض نافذة عرض مزود اسم و دليل شرح؛ منها اثنان عدد داخل وضع DeepSeek نموذج شرح استخدام حالي لغة، خارجي مزود شرح إبقاء أصل نص. نابض نافذة تطبيق الذي اختيار نموذج افتراضي دفع إدارة قوي درجة؛composer مع بعد يمكن اختيار مهمة واحد قد عام نشر دفع إدارة قوي درجة. مهايئ لا يوجد دفع إدارة بيانات وصفية وقت لا عرض Effort سطر؛ لا وجود مهمة معنى دفع إدارة قوي درجة إدخال.

### غير ممكن توجيه جلسة

عند Host تقرير إبلاغ لا يوجد مهايئ خدمة هذا جلسة توجيه وقت، هذا إضافة تسجيل واحد composer منع سد كتلة، إدخال إطار مع لـ توقف استخدام و عرض هذا إضافة ذاتي ذات نص سجل؛ استعادة بعد بلا حاجة إعادة تحميل أي صاف حذف. أول مرة تحميل قبل أو تحميل فشل بعد `null` أبدا منع قطع؛ دليل عضو علاقة نفس مثال لا منع قطع——واحد بند ما زال في خدمة، فقط هو لا عام نشر هذا نموذج توجيه لا في قسم مجموعة داخل، لكن متاح.

### اختيار فشل

عند جلسة يتم أخرى كتابة جملة مقبض احتلال استخدام وقت، نموذج اختيار فشل تلميح مستخدم خروج أخرى صحيح في تشغيل DSH بعد إعادة محاولة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

اثنان عدد مدخل مشترك استخدام واحد نسخة من `ModelDirectoryResolver`(`ctx.modelDirectories`) يحتفظ جلسة درجة دليل:`/model` popupSelect مساهمة بند (مرور `ctx.commandUi` تسجيل) و composer أداة اسم `conversation.input.model` موضع كل مرور `session.models` تحميل جلسة بناء اقتراح دليل، مرور `session.selectModel` عبر نفس عدد `ModelDirectory` نسخة إيداع، لذلك مهمة واحد مدخل الذي فعل تبديل صحيح هو آخر عدد مدخل وصل تحت قدوم عرض. دليل تحميل و اختيار مشترك واحد بديل مرة حساب عدد جهاز، قديم استجابة لن تغطية جديد نتيجة؛ اتصال إعادة وضع إسقاط كل معتاد إقامة إسقاط، و في عرض قبل إعادة سحب أخذ Host استعادة اختيار. دليل حسب جلسة كسول صفة تحليل، مع جلسة أثر مجال واحد و dispose(مورد تحرير) ؛ قد بحث عنوان subagent جلسة لا عام مهمة واحد مدخل. كل نسخة معتاد إقامة دليل كل سوف مباشر في تحويل إرسال `llm/adapters-updated` و `settings/document-updated` owner حدث فوق إعادة سحب.

<a id="model-experience"></a>
## تجربة النموذج

اثنان عدد مدخل إيداع `session.selectModel` اختيار سوف بين وصل أثر نموذج:Host سوف في تحت مرة نص التوجيه تجميع حد لـ كامل `ModelSelection` إنشاء لقطة، و مسؤول جعل ذلك مقابل نموذج توليد فاعلية؛ تشغيل في خطوة فإن إبقاء قد تجميع اختيار.

#### KV Cache أثر

تبديل توجيه ممكن نقص قليل مزود جانب لاحق طلب ذاكرة مؤقتة إعادة استخدام، أو جعل ذلك بطلان؛ نص التوجيه بادئة ذاته لا تلقي أثر.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد حالي نموذج اختيار واجهة. هو جمع هو حالي حزمة قيد، لا هو عام نموذج توجيه جهاز مقابل مقارنة أو مهمة تراكم ضغط.

- **بلا إنشاء مدة أو قد بحث عنوان subagent اختيار**——اثنان عدد مدخل كل اشتراط قائم عادي جلسة agent(ذكي جسم) ؛ لا يوجد يمكن قبول دخول جلسة إنشاء مسودة مسودة مرحلة مقطع نموذج اختيار،subagent متابعة تنفيذ أيضا متعمد لا عام مستقل نموذج اختيار اتفاق.
- **دليل اسم فقط توفير عرض**——اختيار و حفظ دائم استخدام مزود/نموذج/دفع إدارة قوي درجة id؛ دليل استعلام أو تأكيد قطع نموذج بيانات وصفية استعلام فشل مزود بـ غير ممكن اختيار فشل سطر صف خروج، إعادة تحميل قبل إبقاء أصل مثال.
- **لا يستطيع مهمة معنى إدخال دفع إدارة قوي درجة**——composer فقط توفير تأكيد قطع نموذج من مهايئ عام نشر دفع إدارة قوي درجة؛ مهايئ لا يوجد دفع إدارة بيانات وصفية وقت لا عرض Effort سطر.
