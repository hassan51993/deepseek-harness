# @deepseek-ai/dsh-client-locale

[English](README.md) | العربية

## عام وصف

استخدام `dsh-client-locale` يمكن في web GUI في تبديل داخل وضع إنجليزي نص و العربية locale، أو client إضافة لغة. مستخدم اختيار سوف قيام أي توليد فاعلية؛loopback صفحة يأخذ اختيار حفظ دائم إلى `$DSH_HOME/settings.yaml`، غير loopback صفحة فإن فقط لـ حالي عملية إبقاء اختيار. كل جديد متصفح سوف استخدام متصفح طلب رقم واحد تلقي دعم حمل لغة، مباشر إلى سماح قراءة قد تخزين انحراف جيد وصول. إضافة عمل من يمكن إضافة نوع تحويل نطاق الأسماء حرف قاموس، و عبر عام locale API قلب ترجمة؛ مرور slot تصيير نص سجل بلا حاجة إعادة تحميل يكفي مع لغة تبديل تحديث.

## استخدام هذه الحزمة

فقط يلزم web GUI حاجة لغة تبديل أو قلب ترجمة نص سجل حينئذ استخدام هو: قد إصدار ضبط سطر تغطية مستخدم جانب، إضافة عمل من فإن تسجيل ذاتي ذات حرف قاموس. تركيب بلا حاجة أي إعداد——هذه الحزمة مع عميل شجرة واحد بدء تنشيط.

### اختيار لغة

فتح “ضبط → معتاد قاعدة” و اختيار واحد نوع قد تسجيل لغة. توليد فاعلية في locale سوف قيام أي تطبيق:UI نص سجل تبديل،`<html lang>` إشارة نحو خارجي id أو داخل وضع لغة وثيقة وسم، اختيار كتابة حمل دائم ضبط قسم منطقة. لا يوجد صريح Host انحراف جيد متصفح سوف حسب كامل وسم، مجددا حسب رئيسي لغة فرعي وسم اختيار `navigator` طلب رقم واحد قد تسجيل لغة، لا يمكن مطابقة وقت رجوع إلى إنجليزي نص. قد تخزين خارجي locale سوف انتظار ذلك تعريف تسجيل، لن في غير ممكن استخدام وقت توليد فاعلية.

### تسجيل حرف قاموس

استخدام قد دمج دخول `LocaleNamespaceMap` نطاق الأسماء استدعاء `ctx.locale.register(ns, { ar, en })`؛ تحرير ترجمة جهاز سوف مقابل وفق هذا نطاق الأسماء نوع تحويل مفتاح و تجميع فحص كل مفتاح، و اشتراط اثنان عدد داخل وضع locale متساو كل. مستهلك عبر `ctx.locale.bind(ns)` أو إطار هيكل حقن `t` مقعد موضع قلب ترجمة.UI قد تركيب بعد مجددا تسجيل حرف قاموس بلا حاجة إعادة تركيب يكفي توليد فاعلية.

### تسجيل لغة حزمة

خارجي client إضافة يأخذ لغة تعريف و كل قد قلب ترجمة نطاق الأسماء تسجيل لـ ذاته يملك effect؛ تعريف و حرف قاموس يمكن حسب مهمة معنى ترتيب تسجيل:

```js
export const inject = ['locale']

export function apply(ctx) {
  ctx.effect(
    () => ctx.locale.addLanguage({ id: 'ja', label: 'يوم هذا لغة', fallback: 'en' }),
    'my-locale: language',
  )
  ctx.effect(
    () => ctx.locale.register('common', 'ja', {
      cancel: 'キャンセル',
      close: 'إغلاقじる',
    }),
    'my-locale: common dictionary',
  )
}
```

خارجي id يجب هو غير فارغ ASCII BCP 47 ريح إطار وسم. هو fallback يجب قد تسجيل، كما كامل بند سلسلة يجب إنهاء في `en`؛ لم معرفة هدف، تكرار id و حلقة سوف في تسجيل وقت فشل. فحص بحث وقت أولا في طلب نطاق الأسماء داخل مرة تاريخ توليد فاعلية لغة fallback سلسلة، مجددا في `common` في مرة تاريخ هذا سلسلة، الأكثر بعد عرض مفتاح ذاته. إزالة لغة تعريف سوف سوف ذلك من اختيار جهاز إزالة، و يجعل توليد فاعلية في اختيار عودة سقوط إلى متاح متصفح لغة أو افتراضي لغة.

### Host نصف جانب فعل ماذا

Host عبر settings خدمة لـ loopback صفحة حفظ دائم انحراف جيد.Client سوف لحظة معنى رفض غير loopback صفحة استخدام هذا settings scope، لذلك أي جعل Connection إقرار إثبات كل API طريقة، هو جمع locale اختيار ما زال فقط وجود في عملية داخل.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير locale خدمة بناء طريقة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

واحد `LocaleRuntime` معا يملك انحراف جيد و حرف قاموس سجل التسجيل، و كما ذاته حينئذ هو slot نظام `LocaleFace`:`getSnapshot`/`subscribe` عبر `ctx.slots.installLocale` دعم دعم إطار هيكل حقن `t` مقعد موضع. غير ممكن تغيير لقطة يحمل توليد فاعلية في locale، اختياري اختيار locale قائمة و مفرد ضبط revision؛ حرف قاموس تسجيل و locale تبديل كل سوف دفع دخول revision، لكن فقط لديه تبديل سوف إرسال خروج `locale/change` حدث. منتج تحرير كتابة Client UI نص يجب قدوم ذاتي هذه حمل نوع حرف قاموس، أو قدوم ذاتي قد محلي تحويل primitive prop؛`verify-client-ui-i18n` قوي صنع تنفيذ هذا شفرة المصدر ملكية (رؤية[قرار](../../../.agents/notes/implemented/architecture/2026-08-23-locale-owned-client-ui-copy.ar.md)).

### انحراف جيد تحليل

مؤقت locale قدوم ذاتي متصفح (`navigator.languages` أولا حسب كامل وسم، مجددا حسب رئيسي لغة فرعي وسم مطابقة، بـ إنجليزي نص بصفة رجوع) ، في سماح استخدام Host-backed settings scope إرسال بلوغ ذلك تخزين انحراف جيد قبل توليد فاعلية.Host قراءة في إضافة تنشيط بعد تشغيل، لذلك settings scope غير ممكن استخدام أو يتم رفض كل لن منع سد صفحة، نتيجة سوف فوري استبدال مؤقت قيمة. قد تخزين خارجي locale سوف انتظار ذلك تعريف تسجيل.`setLocale` هو وحيد كتابة مدخل؛ أي جعل id قد و توليد فاعلية في locale مطابقة أيضا سوف حفظ دائم، لأن توليد فاعلية في قيمة ممكن هو مؤقت، يجب قدرة توفير مشترك نفس home أخرى متصفح متابعة استخدام.

### حرف قاموس فحص بحث

حمل نوع كائن شكل صيغة اشتراط اثنان عدد داخل وضع locale كل لديه كامل حرف قاموس؛ تدريجي locale شكل صيغة سماح لغة حزمة مستقل تسجيل كل نطاق الأسماء. تدريجي مفتاح فحص بحث سوف أولا في طلب نطاق الأسماء في امتداد توليد فاعلية لغة إعلان fallback سلسلة فحص بحث، مجددا في `common` في تكرار هذا سلسلة، الأكثر بعد عرض مفتاح ذاته. ربط قلب ترجمة دالة حسب نطاق الأسماء إبقاء مستقر هوية، لذلك يمكن عبر inject آلية نقل تمرير، كما لن كسر تالف memoization.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح محلي تحويل في أي بعض أرض جهة لا كامل، أو في تسجيل وقت يتم تجميد ربط. هو جمع هو حالي حزمة قيد، لا هو انتظار إنجاز أمر بند بيان.

- **سجل التسجيل يحتفظ نص فقط قراءة مرة قلب ترجمة**——في slot تصيير مسار خارج في تسجيل وقت التقاط نص سجل (مثال مثل command سجل التسجيل في `/model` أمر وصف) في إعادة تسجيل قبل إبقاء تسجيل وقت لغة؛slot تصيير نص سجل مع تبديل فوري تحديث.
- **لغة حزمة مسؤول لغة خاص لديه سلوك**——سجل التسجيل توفير اختيار، حفظ دائم، متصفح مطابقة، تدريجي مفتاح رجوع و `<html lang>`؛ هو لا زيادة تكرار عدد قاعدة أو مزدوج نحو تخطيط.
