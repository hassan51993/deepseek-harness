# @deepseek-ai/dsh-client-ui-plugin-manager

[English](README.md) | العربية

## عام وصف

استخدام Web جانب شريط**إضافة**مدخل إدارة profile قد تثبيت تركيب حزمة، و تثبيت مع مرفق، افتراضي إغلاق رسمي جهة تركيب حزمة. يمكن بدء توقف تركيب حزمة و ذلك سطر، في Host قراءة خروج spec إشارة نحو ماذا بعد تثبيت تركيب حزمة، فحص نظر pnpm إخراج، إيقاف مرة تشغيل، و تفعيل هو إضافة جديدة حزمة. إزالة سوف اشتراط تأكيد. تسجيل إعداد صفحة إضافة في هذا داخل، في هو ذاتي ذات صفحة فوق تحرير؛ ضبط داخل فقط إبقاء فقط قراءة إضافة قائمة.

## استخدام هذه الحزمة

في جانب شريط اختيار**إضافة**. صفحة أول مرة فتح وقت عبر `api-remotes` قراءة بيان و تركيب حزمة؛ لا يوجد تلقي إدارة profile Host فوق صفحة عرض لـ غير ممكن استخدام.**رسمي جهة**ترتيب في قبل وجه، صف خروج تثبيت مع مرفق، توفير فتح بدء تركيب حزمة——فتح بدء قبل إبقاء إغلاق، لا يوجد إزالة، يخص beta وظيفة حمل **Beta** وسم——ذلك بعد هو تسجيل إعداد صفحة رسمي جهة إضافة؛**قد تثبيت**صف خروج profile يحتفظ تركيب حزمة. بطاقة حسب اسم ترتيب ترتيب، بدء توقف تركيب حزمة لن نقل حركة هو بطاقة. لا يوجد تركيب حزمة patch اعتماد لا هو إضافة، حذف غير profile اختيار في هو عندئذ سوف حمل استثناء وسم صف خروج. عام إعداد ما زال في ضبط**إضافة**قسم منطقة في تحرير.

Agent Teams،Agent Teams Web UI و Auto Authorization Review ثلاثة عدد حزمة استخدام مع واجهة لغة تبديل محلي تحويل اسم و وصف. تفصيل حال صفحة إبقاء كامل npm حزمة اسم؛ أخرى حزمة عرض بسيط كتابة حزمة اسم و أصلي وصف.

### تثبيت واحد تركيب حزمة

**إضافة إضافة**قبول حزمة اسم (يمكن حمل إصدار) ،Git عنوان، ضغط حزمة أو محلي قطعا مقابل مسار؛ محادثة إطار شرح حزمة اسم حينئذ هو README داخل `dsh plugin add` بعد وجه ذلك واحد مقطع. إدخال إطار تحت جهة**لا معرفة طريق هذا ملء ماذا؟**توسيع واحد مقطع جذب توجيه، إعطاء خروج ثلاثة نوع معتاد رؤية شكل صيغة كل واحد عرض مثال؛**ملء دخول عرض مثال**يأخذ عرض مثال ملء دخول إدخال إطار.**تثبيت**أولا يجعل Host قراءة خروج spec إشارة نحو ماذا (`pluginManager.inspect`): قائمة في قد لديه اسم حرف، سجل التسجيل لا يوجد اسم حرف، لا يوجد حزمة مسار، لا يوجد تركيب حزمة patch حزمة، أو pnpm سوف رفض spec، كل بـ واحد جملة كلام عودة إلى إدخال إطار تحت جهة،spec إبقاء يمكن متابعة تحرير. عبر فحص spec فتح تثبيت في واجهة، عرض Host قراءة إلى حزمة اسم، واحد جملة كلام بسيط وسيط و إصدار،pnpm أمر و إخراج طي في**فحص نظر تثبيت تفصيل حال**بعد. تثبيت إتمام بعد توفير**قيام أي تفعيل**: تفعيل جديد تركيب حزمة، إغلاق محادثة إطار و يأخذ قائمة تمرير إلى هو؛ مباشر إغلاق فإن يجعل هو إبقاء قد تثبيت لكن إغلاق. تثبيت فشل وقت استخدام واحد سطر كلام شرح سبب——سجل التسجيل أو شبكة شبكة غير ممكن بلوغ، حزمة لا وجود، مغناطيس قرص قد ممتلئ،profile غير ممكن كتابة،pnpm اعتراض تحت بناء نص برمجي——pnpm إخراج في تفصيل حال داخل،**إعادة محاولة**حينئذ في يد حافة؛Host قد يأخذ profile ملف وضع عودة أصل مثال.pnpm اعتراض تحت اعتماد تثبيت نص برمجي وقت، فشل واجهة صف خروج انتظار سماح حزمة، و بـ**سماح هذه نص برمجي و إعادة محاولة**يحل محل**إعادة محاولة**؛Host يأخذ تخويل كتابة دخول profile `pnpm-workspace.yaml`(فشل تشغيل إبقاء pnpm كتابة هذا عدد ملف) مجددا تشغيل pnpm، تثبيت إتمام واجهة سوف شرح سماح أي بعض نص برمجي. تثبيت نجاح لا بديل جدول وحدة واحد تحديد قدرة كاف تنشيط.

تثبيت خلال يمكن نقر**إلغاء تثبيت**، محادثة إطار عرض**صحيح في إيقاف تثبيت…**، مباشر إلى Host تأكيد. تحميل تركيب حزمة مرحلة مقطع غير ممكن إلغاء. تأكيد بعد محادثة إطار عودة إلى spec إدخال واجهة، يمكن مجددا مرة تثبيت، و استخدام toast شرح تثبيت قد إلغاء؛manifest و lockfile قد استعادة أصل مثال، قد تحت تحميل ملف ممكن إبقاء. تثبيت إجراء في إغلاق محادثة إطار، نفس مثال سوف طلب Host إيقاف تثبيت،Host تأكيد بعد محادثة إطار عندئذ إغلاق؛Host صحيح في دقيق تجهيز، إيقاف أو تحميل وقت لا يستطيع إغلاق محادثة إطار. اتصال خطأ لا بديل جدول إلغاء نجاح: تثبيت في واجهة سوف مثل هذا شرح، يمكن مجددا مرة محاولة تجربة إلغاء.

### تبديل واحد تركيب حزمة

تركيب حزمة صفحة في عنوان تحت جهة عرض كامل حزمة اسم، أيضا حينئذ هو في آخر موضع تثبيت هو الذي يحتاج spec. تركيب حزمة فتح صلة تغيير ذلك طبقة اختيار. تفعيل HMR profile في عملية إتمام قبل إعادة مجموعة؛ لا يوجد HMR profile، و يتم أكثر عال طبقة تغطية تركيب حزمة، سوف بـ toast شرح.Host قراءة لا تركيب حزمة حمل استثناء وسم، ذلك صفحة إعطاء خروج سبب، كما لا يستطيع فتح؛ توفير إدارة مكون تركيب حزمة إبقاء قفل تحديد.Host بـ رمز خطأ عمل جواب، من صفحة حرف قاموس إجراء لفظ؛pnpm و Loader ذاتي ذات تشخيص أصل مثال عرض. صفحة من بطاقة و عدد كمية في ترتيب حذف داخل وضع profile تركيب حزمة، أي جعل profile سوف هو جمع صف لـ اعتماد أو Host تقرير إبلاغ استثناء.Host بيان ما زال إبقاء كامل بيانات؛ ضبط في «إضافة» قسم منطقة «إضافة قائمة» وسم صفحة مسؤول فحص نظر هو جمع إضافة.

### تبديل تركيب حزمة داخل واحد سطر

تركيب حزمة صفحة فوق سطر فتح صلة استدعاء `pluginManager.setPluginEnabled`، نحو profile `cordis.patch.yml` كتابة هذا سطر `disabled` تغطية. تفعيل HMR profile شجرة مع أي إعادة مجموعة، هذا سطر مضيف نصف منطقة إزالة تحت أو تعليق فوق، تركيب حزمة ذلك بقية جزء وفق معتاد تشغيل، صفحة بلا حاجة إعادة تحميل أي تتبع مع عميل وحدة رسم. سطر حسب Host تشغيل هو جمع fiber مرحلة مقطع عرض حالة. فتح صلة فقط ظهور في قد فتح تركيب حزمة فوق؛ لا يوجد تخزين نشط بند سطر، و Host لا عبر profile patch بحث عنوان سطر، حمل حال Host سبب قفل تحديد. تجاوز مرور عشرة سطر قائمة حمل واحد حسب سطر id غربلة اختيار إدخال إطار.

### إعداد صفحة

ذاتي حمل إعداد إضافة يأخذ إعداد تصيير في هذا صفحة بينما لا هو ضبط داخل، عبر هذا صفحة إعلان ثلاثة عدد slot:`plugins.item`(list) لأجل رسمي جهة إضافة، حسب ذلك `label` صف في رسمي جهة قسم مجموعة داخل؛`plugins.bundle.config`(بـ تركيب حزمة حزمة اسم لـ مفتاح) لأجل تركيب حزمة ذاتي ذات إعداد، عرض في تركيب حزمة صفحة وصف و سطر بين؛`plugins.row.config`(بـ `<حزمة اسم>#<سطر id>` لـ مفتاح) لأجل بعض واحد سطر إعداد، هذا واحد سطر من هذا كثير خروج واحد**إعداد**تحكم عنصر، فتح هذا سطر ذاتي ذات صفحة. صفحة عبر owner props نحو كل بند بحث أخذ اثنان نوع عرض:`view: 'summary'` هو عنوان تحت واحد جملة كلام بسيط وسيط،`view: 'page'` هو حمل ذاتي ذات حفظ تحكم عنصر جدول مفرد. فقط لديه حفظ عندئذ كتابة: صفحة مسؤول رسم عنوان، رسم علامة و وجه حزمة فتات، بند جدول مفرد في مغادرة فتح صفحة وقت إسقاط مؤقت تخزين تعديل. تثبيت مع مرفق أربعة عدد مضيف مستو وجه إعداد صفحة——shell منفذ،agent loop،subagent نموذج اختيار،DeepSeek بحث مزود——قدوم ذاتي [ui-settings-plugins](../ui-settings-plugins/README.zh.md) ، في Host خدمة ذلك نطاق الأسماء خلال تسجيل. تركيب حزمة متصفح نصف جانب استخدام نفس مثال طريقة تسجيل:

```tsx ignore-check
ctx.slots.inject('plugins.row.config', () => ctx.slots.register({
  name: 'plugins.row.config',
  key: '@acme/dsh-sidebar#sidebar',
  locale: 'acmeSidebar',
}, ({ t, view }) => view === 'summary' ? t('summary') : <SidebarForm t={t} />))
```

تركيب حزمة patch يجب بـ هذا id إعلان هذا واحد سطر؛ تسجيل فقط في تركيب حزمة فتح بدء خلال وجود، لذلك إغلاق تركيب حزمة لا عرض إعداد تحكم عنصر.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

إضافة إدارة اعتماد حسب profile اعتماد سجل: قد تثبيت تركيب حزمة يمكن بدء توقف، يمكن إزالة، مع تثبيت توفير تركيب حزمة إبقاء قفل تحديد. هذا واحد منطقة قسم لا قرار بدء فشل سياسة.

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

### تسجيل

متصفح إضافة عبر `ctx.slots.inject()` تسجيل `plugins` جانب شريط مدخل و هو `main` وجه لوح، جعل اثنان من تتبع مع slot تأخير متأخر إعلان، محلي تحويل تغير و إلغاء تدمير. صفحة لـ عام صفحة، لا يخص أي Session. عرض نص قدوم ذاتي حزمة عنصر معلومة و صفحة حرف قاموس.

### store

`PluginManagerController` يملك تركيب حزمة عرض، مشغول مشغول مفتاح، تلميح، تثبيت دخول درجة و إزالة تأكيد. كل مرة قراءة أولا سؤال بيان Host هل إدارة حال profile، مجددا يأخذ `listBundles` و `listPlugins` دمج صار كل تركيب حزمة واحد نسخة عرض، ذلك سطر يحمل تخزين نشط بند بدء توقف حالة و fiber مرحلة مقطع. هو دمج إعادة تراكم قراءة، في عملية بعد، استلام إلى `plugin-manager/changed` وقت و إعادة وصل بعد تحديث جديد، و في إلغاء تدمير بعد تجاهل اختصار متأخر إلى نتيجة. تثبيت إخراج حسب job id قسم مجموعة. تثبيت محادثة إطار امتداد `idle → checking → starting → running → done | failed` دفع دخول،`cancelling` و `applying` حسب Host تقرير إبلاغ عرض. فحص في واحد `AbortController` تحت تشغيل، إرجاع تحرير أو إغلاق سوف في توقف هو و إسقاط ذلك نتيجة؛ تشغيل فقط قدرة عبر `pluginManager.cancelInstall` إيقاف، محادثة إطار انتظار ذلك جواب تكرار.Host لا يمكن تطبيق تغيير، يلزم انتظار إعادة بدء تغيير، يتم أكثر عال طبقة تغطية تغيير، كل هو سوف ذاتي سطر إزالة فقد toast.

### إعداد slot

صفحة `main` تسجيل يأخذ `plugins.item`،`plugins.bundle.config` و `plugins.row.config` إعلان لـ فرعي slot، لذلك هو جمع و صفحة نفس توليد، تسجيل جهة `ctx.slots.inject` سوف انتظار إلى هو جمع ظهور.`configLedgerSource` يأخذ ثلاثة نسخة حساب هذا إسقاط صار واحد يمكن مراقبة كائن——حسب حساب هذا ترتيب ترتيب صف، وسم حسب حالي لغة تحليل رسمي جهة بند، و تركيب حزمة و سطر مفتاح——في حساب هذا أو لغة تغير قبل إبقاء ذاكرة مؤقتة؛ صفحة يأخذ هو بصفة `useConfigLedger` ربط في store جانب حافة، ذاته من لا نقطة اسم أي يمكن إعداد إضافة. فتح هو أي واحد صفحة هو صفحة محلي حالة: بطاقة، بعض عدد تركيب حزمة، بعض عدد رسمي جهة إضافة، أو تركيب حزمة بعض واحد سطر. تسجيل و فعل خروج هو متصفح نصف جانب نفس توليد مشترك ميت.`dsh-client-modules` فقط يأخذ واحد حزمة متصفح نصف جانب تعليق في شرح رمز تماما لـ حزمة اسم ذلك واحد سطر Loader سطر فوق، الذي بـ تركيب حزمة لـ ذاتي ذات أو مهمة واحد سطر تسجيل صفحة، كل سوف في ذلك واحد سطر يتم إغلاق وقت واحد بدء إزالة فقد؛ حاجة في أخرى سطر إغلاق وقت ما زال إبقاء صفحة فرعي إضافة، ينبغي بصفة مستقل حزمة إصدار.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد إدارة عرض نطاق؛ هو جمع هو حالي حزمة قيد.

- **فقط إدارة تركيب حزمة**——لا يوجد تركيب حزمة patch اعتماد في تثبيت قبل حينئذ يتم رفض؛profile داخل قد لديه هذا صنف اعتماد لا فوق صفحة، حذف غير profile اختيار في هو؛ تحميل عادي إضافة وحدة ما زال هو ملف عملية.
- **سطر فقط عرض مرحلة مقطع، لا عرض سبب**——فشل سطر فقط عرض لـ فشل، لا يوجد Host خطأ نص؛Host سجل داخل لديه.
- **مرة فقط قدرة تثبيت واحد**——محادثة إطار مرة تشغيل واحد pnpm أمر؛ ثاني عدد spec يلزم انتظار قبل واحد إتمام.
- **لا يوجد إصدار اختيار جهاز**——spec حسب pnpm قبول كتابة قاعدة إدخال؛ صفحة لا صف خروج سجل التسجيل إصدار، أيضا لا توفير ترقية.
