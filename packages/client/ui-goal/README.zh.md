# @deepseek-ai/dsh-client-ui-goal

[English](README.md) | العربية

## عام وصف

Web GUI goal واجهة معا عرض حمل دائم goal حالة و حالي عملية محلي تنشيط حالة، توفير مستخدم تحرير، مؤقت توقف، استعادة أو صاف حذف goal؛ يتم رفض تغيير الذي إنتاج خطأ سوف داخل ربط عرض. هو يأخذ حمل دائم `/goal` تشغيل عرض لـ `Command input` هواء فقاعة، يجعل مستخدم أو نموذج إرسال خروج أمر في إعادة تحميل بعد ما زال مرئي.goal إنشاء ما زال لا عودة هذه الحزمة. حذف `minimal` خارج، مع مرفق Web preset كل سوف نحو agent(ذكي جسم) توفير `/goal`.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

و `ui-conversation` و goal مجال حزمة واحد بدء تركيب هذا إضافة؛ فقط يلزم جلسة وجود هدف، بند حمل حينئذ سوف بصفة composer سياق كومة مكدس ثاني ورقة بطاقة ظهور (يقع في Todo بعد،Queue قبل). قد armed active goal توفير مؤقت توقف حركة عمل؛active-but-disarmed أو paused goal توفير استعادة؛ تحرير إعادة كتابة هدف نص؛ صاف حذف إزالة هدف، و في إسقاط تتبع فوق قبل كبح صنع بند حمل.

### إشارة أمر إدخال هواء فقاعة

كل بند حمل دائم `/goal` تشغيل كل إسقاط لـ واحد يمين مقابل متساو مستخدم مثال صيغة هواء فقاعة، وسم لـ `Command input`(أو `إشارة أمر إدخال`) ، تصيير في عام أمر نتيجة سطر قبل؛ فتح رأس `/goal` token مرور ui-primitives `projectUserText` بـ انتظار عرض شفرة حرف جسم تصيير لـ إشارة أمر مرجع chip، هدف نص إبقاء متن حرف جسم. هو لا يحتوي ختم الوقت، نسخ أو فرع عملية، إعادة تحميل وقت سوف اعتماد حسب تشغيل سجل إعادة بناء.

### فشل

يتم رفض تغيير سوف يأخذ Remote خطأ داخل ربط عرض إلى بند حمل فوق؛ تحميل في، بلا هدف، قد إتمام و نجاح صاف حذف هدف واحد قاعدة لا تصيير.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

حمل دائم goal مرور `useProjection('goal')` وصول (من تاريخ ذيل صفحة بث نوع،`session/projection` لقطة تحديث). حقن وجه يحمل تسجيل جهة خاص تنشيط خطاف مصدر و أربعة عدد تغيير حركة كلمة. هذا مصدر فقط في إطار هيكل خطاف مراقبة هو وقت بدء؛ بدء بعد سوف قراءة `ctx.remote.goals.get`، حجز قراءة `goal/activation-changed`، و في running حالة أو اتصال إعادة وضع وقت تحديث جديد. فوري حدث epoch سوف يجعل في طريق قراءة بطلان، لذلك مقارنة قديم HTTP استجابة لا يستطيع تغطية مقارنة جديد activation تغير؛running تحديث جديد سوف إبقاء الأكثر بعد مرة معروف activation، مباشر إلى قراءة إتمام. بند حمل لا يحتفظ مجال تخزين أو عبر إضافة ذاكرة مؤقتة. كل تغيير في استدعاء وقت من جلسة حالي إسقاط قيمة قراءة CAS ref، مقارنة مقارنة و تسليم تبديل (RPC CAS) حينئذ هو قديم قديم صفة حماية شريط. من في React pending تصيير لا يمكن اعتراض إقامة نفس لقطة داخل نقر، بند حمل سوف تزامن لـ تغيير بناء قيام single-flight منع حماية. إشارة أمر إدخال إسقاط هو مستقل Conversation Definition، في عام أمر نتيجة Node قبل بناء `command-input` Chat Node؛ هو أبدا إنشاء `user/message` أو نموذج جولة.

</details>

<a id="further-exploration"></a>
## بحث إضافي

عند goal واجهة لا كاف استخدام وقت قراءة قراءة التالي صفحة. هو جمع من متصفح بند حمل دخول goal مجال و هو الذي ملء ملء slot.

- [dsh-goal](../../goal/goal/README.zh.md)——هذا واجهة قراءة و تغيير goal مجال، إسقاط و `/goal` أمر.
- [ui-conversation](../ui-conversation/README.zh.md)——إعلان `conversation.input.dock` slot و يملك composer.
- [عميل حزمة خريطة](../README.zh.md)——متبادل مجاور متصفح UI حزمة.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أثر: بند حمل توجيه `goals/edit`،`goals/pause`،`goals/resume` و `goals/clear` تغيير؛ مضيف GoalService يملك هذه تغيير ترتيب طابور نموذج مرئي goal سياق رسالة.

#### KV Cache أثر

حذف غير قد ترتيب طابور goal سياق نيل دقيق، لا فإن لا يوجد أثر. نيل دقيق سياق سوف مثل أخرى رسالة واحد مثال توسيع تاريخ ذيل جزء؛ دقيق دخول قبل يتم إسقاط إدراج دخول بند لن أثر ذاكرة مؤقتة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد حالي goal واجهة. هو جمع هو حالي حزمة قيد، لا هو goal مجال مقابل مقارنة أو مهمة تراكم ضغط.

- **Host حالة و preset غير متصل**——يأخذ نشط وثب جلسة تبديل إلى `minimal` بعد،Host يملك goal ما زال سوف إبقاء.`/goal` و goal أداة سوف إزالة فقد، لكن هذا بند حمل ما زال يمكن تحرير، مؤقت توقف، استعادة أو صاف حذف goal.
