# @deepseek-ai/dsh-client-ui-sidebar-terminal

[English](README.md) | العربية

## عام وصف

من يمين جانب شريط بدء صفحة اختيار قد تثبيت shell، في جلسة مساحة العمل تشغيل أمر. في وسم صفحة فوق إعادة تسمية طرفية، و في تحديث جديد صفحة بعد استعادة إبقاء عملية. طي جانب شريط يجعل أمر متابعة تشغيل، إغلاق طرفية وسم صفحة فإن طلب انتهاء عملية.Tab تكملة كل استخدام shell إعداد. أمر استخدام تنفيذ بيئة في نظام مستخدم إذن، مستقل في Agent إذن؛ تفصيل رؤية[مستخدم طرفية تنفيذ](../../api/terminal-controller/README.ar.md#use-this-package).

## استخدام هذا حزمة

توسيع يمين جانب شريط، نقر**جديد بناء طرفية**يكفي مباشر فتح فوق مرة اختيار كما ما زال متاح shell. جانب حافة سهم رأس توسيع قد تثبيت shell قائمة مفرد؛ اختيار بعد قيام أي تسجيل إقامة هذا بند و فتح طرفية. قائمة مفرد توسيع وقت عندئذ استعلام shell، لا قسم إعداد طرفية عملية؛ استعلام فشل يمكن في قائمة مفرد داخل إعادة محاولة. عبر**جديد وسم صفحة**عودة إلى بدء صفحة و فتح أكثر كثير طرفية.

مزدوج ضرب طرفية وسم عنوان يمكن إعادة تسمية. أخرى صفحة يحتفظ إدخال حق وقت، نقر **وصل إدارة إدخال** جعل حالي اتصال يمكن كتابة. مؤقت وقت قطع خط وقت إبقاء شاشة ستار و توفير **إعادة اتصال**، لا عرض نقل داخلي خطأ. قد خروج shell ما زال عرض خروج رمز و توفير **جديد بناء طرفية**، لن تلقائي إعادة بدء. قد خروج طرفية ما زال حساب دخول Session إعداد مقدار؛ بلوغ إلى حد أعلى وقت طلب إغلاق لا استخدام وسم.

إغلاق أو استبدال طرفية وسم صفحة سوف قيام أي إزالة وسم صفحة، و في خلفية انتهاء عملية. تنظيف فشل وقت عرض حمل**إعادة محاولة**عملية خفيف كمية إشعار؛ إعادة محاولة لن إعادة فتح وسم صفحة. طي، تبديل وسم صفحة أو Session، طفو حركة و كل شاشة كل إبقاء عملية.

تحديث جديد بعد،[جانب شريط استعادة تخطيط](../../client/ui-sidebar-right/README.ar.md#state) ، كل طرفية في أصل وسم صفحة في إعادة وصل حفظ Host هوية. طي و غير حالي وسم لن إنتاج تكرار استعادة وسم، أيضا لا تغيير اختيار في بند. لا يوجد حفظ وسم صلة ربط Host طرفية بصفة استعادة وسم فتح؛ استعادة فشل وقت توفير **إعادة محاولة استعادة طرفية**. حفظ عملية قد إزالة فقد وقت، عرض محلي تحويل غير ممكن استخدام تلميح و **جديد بناء طرفية**. نقر بعد في أصل موضع استخدام كل جديد طرفية استبدال بطلان وسم؛ استعادة مرور مسار لن تلقائي إنشاء بديل عملية.

طرفية خلف مشهد، افتراضي نص حرف، ضوء علامة و اختيار منطقة تتبع مع DSH رئيسي عنوان، يشمل نظام انحراف جيد و رئيسي عنوان أمر لوحة تغطية. تبديل رئيسي عنوان سوف إبقاء تشغيل في shell، إخراج و تطبيق عبر OSC ضبط لون لون. لون لون إعادة وضع أمر استعادة إلى حالي DSH قيمة افتراضية.xterm سوف نص حرف مقابل مقارنة درجة ضبط كامل إلى 4.5:1؛ ضوء علامة و الذي في وحدة إطار خلف مشهد إبقاء حتى قليل 3:1 مقابل مقارنة درجة، يشمل Vim إعداد لون خطة.

## حل تنفيذ

<details>
<summary>تنفيذ دقيق عقدة</summary>

إضافة نحو يمين جانب شريط تسجيل `terminal` نوع و متن و عنوان seat. بدء صفحة مدخل استخدام ضيق تجميع أسود قاع طرفية رسم علامة، صفحة توقيع عنوان إبقاء خط بند رسم علامة. بلا React اعتماد طرفية نموذج يخص `api-terminal-controller`، عبر إطار هيكل keyed hooks كشف حالة.`ui-primitives` Menu و Button توفير shell اختيار و بدء تحكم عنصر، دعم حمل مفتاح قرص تنقل و اختيار في علامة. متن في terminal عرض تركيب وقت تحميل حزمة داخل `client.terminal.js` chunk، جعل xterm.js و FitAddon لا دخول بدء `client.js`؛ تحميل بعد من هو جمع مسؤول شاشة ستار تصيير و نظر فتحة قياس كمية. متن في وجه لوح عال درجة داخل لـ صفحة توقيع بند تحت جهة مسبق إبقاء 8px بين مسافة. إدخال أصل مثال نقل إلى PTY، يشمل Tab و تحكم محرف.

Session header contribution استعلام Host طرفية، فقط فتح لا يوجد قائم وسم صلة ربط طرفية. طرفية controller مستقل حفظ كل عام وحيد محتوى هوية و Host صلة ربط، و مسؤول محتوى استعادة؛ جانب شريط مسؤول تخطيط حفظ دائم. استعادة عرض لا يستطيع قسم إعداد بديل عملية. جانب شريط إغلاق handler عبر[طرفية controller](../../api/terminal-controller/README.ar.md#understand-the-implementation) أمان ترتيب تنظيف و تزامن إرجاع. متصفح مكون تنظيف و tab abort signal فقط إيقاف متصفح عمل.

إضافة بدء وقت، جانب شريط كامل فتح وسم بيان في terminal بند سوف يحتفظ متبادل مطابقة قد حفظ Host هوية، يشمل غير حالي Session. نافذة يحتفظ علاقة مستقل في React تركيب و شاشة ستار حجز قراءة. حذف الأكثر بعد واحد مطابقة occurrence سوف تحرير يحتفظ علاقة؛ طي أو تبديل عرض لن تحرير.[طرفية تحكم جهاز](../../api/terminal-controller/README.ar.md#use-this-package) مسؤول بلا شخص يحتفظ وقت فارغ خامل عودة استلام و طويل أمر حفظ حماية.

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- افتراضي shell أو أصلي PTY ممكن بدء فشل. وسم صفحة عرض خطأ، لا بدء أخرى shell.
- تكملة كل قائمة مفرد و داخل ربط بناء اقتراح أخذ قرار في shell إعداد،Web UI لا توفير مستقل تكملة كل جذب محرك.
- تطبيق OSC لون لون تغطية من قد تركيب مصير إبقاء؛ جديد فتح مصير لا يمكن من Host شاشة ستار لقطة استعادة هذه لون لون.
- طرفية تاريخ لديه حد أعلى. هذا وظيفة لا نحو Agent إرسال طرفية إخراج، لا في مفرد عدد وسم صفحة داخل تفكيك قسم طرفية، أيضا لا في Host إعادة بدء بعد استعادة عملية.
- Terminal chunk تحميل فشل بعد حاجة تحديث جديد صفحة، لأن React سوف في صفحة دورة الحياة داخل ذاكرة مؤقتة يتم رفض lazy import.
