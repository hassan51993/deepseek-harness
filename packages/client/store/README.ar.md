# @deepseek-ai/dsh-client-store

[English](README.md) | العربية

## عام وصف

توفير Client تحكم جهاز و renderer مهايئ مشترك استخدام لا اعتماد React observable و لقطة تخزين أساس أساس أصل لغة. هذه الحزمة مسؤول تزامن و animation-frame إصدار، أساس في Immer تحديث، ضحل مقارنة مقارنة و اختياري متصفح حفظ دائم؛React خطاف بنية صنع ما زال يخص `@deepseek-ai/dsh-client-ui-renderer`. عند Client حالة يجب في لا اعتماد React حال حال تحت إصدار مستقر لقطة وقت، طلب استخدام هو.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>

- **حفظ دائم فقط حد متصفح محلي**——حفظ دائم تخزين استخدام `localStorage` في JSON؛ غير متصفح وقت التشغيل سوف منع استخدام حفظ دائم، هذه الحزمة أيضا لا توفير عبر ضبط تجهيز تزامن.
- **Web قشرة بناء إدخال**——ساكن حالة ESM لـ Vite إبقاء رقم ثلاثة جهة استيراد؛ مستقل مستهلك ذاتي سطر توفير تطوير اعتماد ([اعتماد قاعدة](../AGENTS.md#dependency-declaration)).
