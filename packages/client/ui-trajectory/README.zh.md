# @deepseek-ai/dsh-client-ui-trajectory

[English](README.md) | العربية

## عام وصف

Trajectory وسم صفحة يجعل أنت بـ حسب جولة مجموعة نسج حدث سجل جدول و تفاعل صيغة وقت عام تصفح فحص agent(ذكي جسم) نشط حركة. هو مقابل مستخدم، مساعدة يد، أداة، تضمين طقم فرعي أداة و ضغط (compaction) سجل قسم مجموعة، علامة عرض جولة و خطوة حد، و لـ الذي اختيار سجل فتح فحص جهاز، عرض token استخدام كمية، استهلاك وقت، إدخال، إخراج، حساب وقت، صورة و مرفق عنصر ملخص. مقارنة طويل تاريخ فتح وقت تحديد يقع في حالي ذيل جزء، حسب يحتاج تحميل أكثر مبكر صفحة، و كما فقط تصيير مرئي سطر. تدفق صيغة إخراج خلال، عرض سوف تتبع مع ذيل جزء، مباشر إلى أنت نحو فوق تمرير؛ إجراء في سجل فقط عرض بدء علامة، لن وهمي بنية استهلاك وقت.

## استخدام هذه الحزمة

في محادثة عرض حلقة في فتح Trajectory وسم صفحة، يأخذ agent نشط حركة بصفة حدث سجل جدول و وقت خط فحص نظر. ابتدائي ذيل جزء إتمام تحديد موضع قبل، سجل جدول سوف استخدام واضح تحميل سطر حجب إقامة حقيقي سجل؛ أكثر مبكر بادئة ما زال لم تحميل وقت، أول سطر تحكم عنصر سوف في نقر وقت تحميل واحد صفحة أكثر مبكر تاريخ، و في هذا صفحة تحميل خلال عرض منع استخدام تحميل حالة.

### فحص سجل

استدعاء حسب قد سجل أداة اسم تعرف آخر. مقابل في `run_code`، سجل سطر عرض برنامج شرح، فحص جهاز عرض حمل سطر رقم و لغة قاعدة عال مضيء شفرة المصدر.“شفرة” صفحة توفير تبديل سطر، فحص نظر أصلي JSON معامل `{}` تبديل حسب زر، و إبقاء نهاية ذيل تبديل سطر شفرة المصدر أصل مثال نسخ. نسخ أصلي معامل وقت إبقاء سجل في JSON فارغ أبيض. كل جديد فتح شفرة عرض اعتماد فوق مرة اختيار تبديل سطر حالة؛ تبديل وقت، أخرى قد فتح عرض إبقاء أصل حالة. إخراج إبقاء سجل في نص، كامل JSON كائن أو عدد مجموعة استخدام شجرة شكل عرض. عال مضيء فقط اعتماد قد سجل أداة Schema في واضح كما بلا اندفاع مفاجئ TypeScript أو Python تلميح؛ تلميح ناقص أو اندفاع مفاجئ وقت عرض صاف نص شفرة المصدر. إعادة تشغيل قيد رؤية [PTC فحص قرار](../../../.agents/notes/implemented/feature/2026-09-09-ptc-trajectory-code-inspection.zh.md).

اختيار، وقت خط تنقل، طي و بحث فقط تغطية React مرئي نافذة. طلب تحرير رقم و تراكم حساب استخدام كمية تغطية كامل إقامة إبقاء لقطة. اختيار سجل سوف فتح نطاق جزء فحص جهاز، فحص نظر token استخدام كمية، استهلاك وقت، إدخال، إخراج، حساب وقت و حمل دائم إبقاء صورة. صورة URL استخدام Conversation يملك تدريجي جلسة ذاكرة مؤقتة، لذلك Chat و Trajectory مقابل كل مرفق عنصر مشترك مرة قد تخويل قراءة. مستخدم سجل سوف في نص جانب معا عرض غير صفر صورة و عادي ملف عدد كمية، فقط يحتوي مرفق عنصر سجل أيضا عرض هذه عدد كمية. مستقل تشغيل ضغط طلب سوف حسب وقت ترتيب عرض في ذاتي ذات `Between turns` منطقة مقطع في، بينما حمل تحرير رقم ضغط ما زال يقع في ذلك الذي تابع جولة داخل.

عام وصف و معاينة مشترك استخدام متن بعد لديه ترتيب مرفق عنصر قائمة، إبقاء تكرار مرجع. كل سطر عرض كامل تقليص وضع صورة تقليص اختصار رسم أو ملف نوع رسم علامة، قد سجل ملف اسم (لم تسمية صورة استخدام محلي تحويل تحرير رقم اسم) ، و متاح قد سجل كبير صغير، نوع و صورة مقياس قياس. صفر بايت ملف إبقاء كبير صغير عرض، قطع قطع ملف اسم عبر تلميح عرض كامل اسم. صورة فتح قائم مصباح صندوق. أصلي محتوى إبقاء محتوى كتلة ترتيب و لم تصيير نص، صورة و ملف استخدام افتراضي طي توسيع بند، يتضمن كامل قد سجل حقل.

فحص جهاز في تفكير اعتبار محتوى استخدام ضيق تجميع Markdown، امتداد استخدام فحص جهاز ثابت 13px حرف رقم و 20px سطر عال، لا تلقي محتوى حرف رقم ضبط أثر. عنوان فقط إضافة خشن، لا وضع كبير حرف رقم أو سطر عال. مساعدة يد إخراج إبقاء معتاد قاعدة Markdown ترتيب إصدار.

### وقت عام تصفح

عند سجل تدفق يتضمن token ختم الوقت وقت، تاريخ عودة تكرار سوف إبقاء TTFT، توليد استهلاك وقت و ابتلاع إخراج كمية.TTFT من خطوة بدء حساب كمية إلى أول عدد token، يشمل أكثر مبكر إعادة محاولة محاولة تجربة في إخراج؛ خطوة بدء نقطة بعد لم تحميل أو تدفق في لا يوجد token وقت، مقابل إشارة علامة إبقاء غير ممكن استخدام.

ثابت في سجل جدول فوق جهة Overview منطقة مجال من يسار إلى يمين إسقاط سجل حقيقي بدء وقت و استهلاك وقت؛ مساعدة يد وقت بند منطقة قسم سجل إلى TTFT و حل رمز وقت، معلق توقف 500 ms بعد يمكن فحص نظر دقيق وقت لحظة و استهلاك وقت تفصيل حال. سحب اختيار منطقة بين سوف يأخذ سجل جدول تجمع تركيز إلى هذا إغلاق منطقة بين داخل أي وقت لحظة موضع في نشط حركة سجل؛ تدحرج جولة يد اتجاه لأجل تقليص وضع وقت مجال؛ يمين مفتاح مفرد ضرب سوف صاف حذف الذي اختيار منطقة بين، في قد وضع كبير نظر فتحة فوق حسب إقامة يمين مفتاح سحب حركة فإن سوف مستو نقل. ابتدائي عرض و تدفق صيغة تحديث كل توقف إبقاء في ذيل جزء؛ نحو فوق تمرير سوف مؤقت توقف تتبع مع، لذلك جديد سجل لن ضرب قطع مقابل قديم سجل فحص.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

عرض هو صاف إسقاط:Trajectory ذاتي لديه تعريف من مشترك جلسة نافذة تجميع عمل خدمة سجل——يشمل بسبب إلغاء بينما تحديد مسودة و حمل دائم إبقاء بادئة، فقط لديه قسم قطعة وقت اعتماد في قطع رجوع سجل، و يتم في قطع أداة سجل——لذلك Trajectory حيث لا قراءة أيضا لا تغيير Chat جلسة لقطة. ذلك steering(في طريق جذب توجيه) تصنيف جهاز عبر حمل متابعة إبقاء تجميع وصل حالة فقط إبقاء تحت واحد خطوة Inbox ID، و يجعل لاحق سياق مشترك حالي قد إقرار قيادة كل دفعة مرة.

أصلي و تضمين طقم PTC أداة نتيجة إبقاء أصلي بنية تحويل خطأ تفصيل حال. فشل سجل في سجل جدول في عرض خطأ شفرة، في فحص جهاز في عرض خطأ اسم و شفرة.

كامل إلحاق نص التوجيه في طلب رأس لم تحميل وقت عرض لـ مستقل نظام سطر؛ فقط توفير معروف نص، لا دفع قطع طلب خيار أو أداة دليل. تكملة دخول ذلك طلب تاريخ بعد، هذا مستقل عرض يتم بديل بينما لا تكرار نص التوجيه. تاريخ في توجيه النظام تغيير و الأكثر قريب طلب حالة مقارنة مقارنة، يشمل لا يوجد جديد طلب رأس أولا قبل نص التوجيه تحديث. كل طلب إبقاء ذلك الذي في موضع توليد فاعلية نص التوجيه و تغيير. يشمل ضغط في داخل surface استبدال سوف استعادة الأكثر بعد واحد غير فارغ تخزين نشط توجيه النظام، أي جعل لا يوجد جديد نظام حدث؛ لم تحميل نص التوجيه في مقابل قسم صفحة وصول قبل ما زال غير ممكن استخدام.

### وهمي محاكاة سطر

طويل سجل جدول الأكثر أول فقط من تركيب وقت ذيل جزء انتهاء 50 عدد target Node إرسال توليد React بيانات. لاحق Node سوف توسيع هذا عدد ثابت بدء نقطة نافذة بينما لن تدريجي خروج ذلك بادئة؛ قائم تحميل تحكم عنصر سوف أولا إظهار كشف أكثر مبكر إقامة إبقاء Node، مجددا طلب تحت واحد جلسة صفحة. وهمي محاكاة تحويل فقط تركيب مرئي سطر نافذة إضافة قليل كمية مؤقت اندفاع؛ فقط يحتوي طلب قسم فصل سطر و دخول تحت واحد أداة تجهيز يمكن قياس عال درجة وهمي محاكاة بند، دلالة سطر مفتاح و ARIA بحث جذب في نحو قبل تكملة صفحة بعد إبقاء ثابت. وهمي محاكاة تحويل جهاز مسؤول بنية صفة إلحاق بعد قاع جزء تتبع مع؛ غير وهمي محاكاة سجل جدول سوف مباشر كتابة نهاية ذيل موضع. فقط يحتوي محتوى تحديث تدفق صيغة لقطة سوف إبقاء وهمي محاكاة سطر مفتاح و عال درجة، إعادة استخدام قياس كمية نتيجة، و كما لن تكرار كتابة نهاية ذيل تمرير موضع. قد إتمام عودة تكرار سوف في Trajectory target State في إبقاء تجميع بعد كتلة، حساب وقت و استخدام كمية، مشترك جلسة نافذة فإن إبقاء أصلي حدث.

### تخطيط

Trajectory اشتراط جلسة قشرة يأخذ composer بصفة طفو طبقة وضع في كل عال سجل جدول فوق جهة؛ ذلك استجابة صيغة رأسي نحو تمرير حاوية سوف مسبق إبقاء composer فوري عال درجة، تأكيد حفظ ما زال يمكن تمرير إلى الأكثر بعد بضعة سطر. يمكن تمرير Summary منطقة مجال في معلق توقف أو تجمع تركيز قبل إبقاء تمرير بند انزلاق كتلة نفاذ واضح، معا لا تغيير مسبق إبقاء تمرير بضعة أي فضاء. هذه الحزمة لا توفير خدمة، أيضا لا إعلان سياق دمج.
