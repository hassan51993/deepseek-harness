# @deepseek-ai/dsh-client-ui-directory-picker-native

[English](README.md) | العربية

## عام وصف

هذه الحزمة توفير Web GUI أصلي دليل التقاط أخذ جدول وجه: عند مساحة العمل مسار طلب واحد دليل وقت، واحد بلا تصيير متصفح ملء ملء سوف في محلي آلة جهاز فوق فتح عملية نظام ذاتي حمل اختيار جهاز، و عودة تقرير وحيد نتيجة——التقاط أخذ مسار، إلغاء أو فشل. هو ملء ملء `ui-workspace` إعلان اثنان عدد دليل مسار slot، استخدام واحد سطر `cordis.yml` تركيب خروج أصلي التقاط أخذ تفاعل عميل واحد جانب. عند متصفح و Host تشغيل في نفس منصة آلة جهاز فوق وقت اختيار هو؛ عملية داخل و بعيد مسار متصفح نشر فإن حاجة [`-browse`](../ui-directory-picker-browse/README.ar.md) جدول وجه.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

و `ui-workspace` و Host خلفية [`dsh-host-directory-picker-native`](../../host/directory-picker-native/README.ar.md) واحد بدء تركيب هذا إضافة؛ واحد سطر `cordis.yml` مع أي تركيب خروج كامل أصلي التقاط أخذ تفاعل. عند مساحة العمل إضافة أو اختيار جهاز مسار إرسال بدء دليل طلب وقت، مستخدم يرى عملية نظام ملف مشبك محادثة إطار؛ التقاط أخذ مسار يتم مساحة العمل مسار قبول، إلغاء فإن إغلاق محادثة إطار.

في محلي Electron تطبيق في، هذا مسار استخدام preload توفير ضيق دليل اختيار واجهة. إلغاء و فشل كل لن تعديل استخدام Host اختيار جهاز إعادة محاولة. عادي Web استخدام Host استدعاء؛ مستقل تصفح تركيب بداية نهاية صف خروج Host دليل.

### أي وقت اختيار

عند متصفح و Host تشغيل في نفس منصة آلة جهاز فوق، عملية نظام محادثة إطار يمكن في ذلك داخل فتح وقت، اختيار هذا جدول وجه. عند متصفح لـ بعيد مسار أو عملية داخل، لا يوجد محلي اختيار جهاز وقت، اختيار [`-browse`](../ui-directory-picker-browse/README.ar.md) جدول وجه. اثنان عدد جدول وجه ملء ملء نفسه slot، لذلك تبديل فقط هو تركيب تعديل، بينما غير شفرة تعديل.

## فهم التنفيذ

## بحث إضافي

عند التقاط أخذ وجه لا كاف استخدام وقت قراءة قراءة التالي صفحة. هو جمع من متصفح نصف جزء دخول Host خلفية و هو الذي ملء ملء slot.

- [dsh-host-directory-picker-native](../../host/directory-picker-native/README.ar.md)——هذا جدول وجه قيادة عملية نظام اختيار جهاز خلفية.
- [ui-workspace](../ui-workspace/README.ar.md)——إعلان دليل مسار slot و يملك التقاط أخذ محادثة.
- [ui-directory-picker-browse](../ui-directory-picker-browse/README.ar.md)——موجه إلى بعيد مسار و عملية داخلي توقيع تطبيق داخل تصفح بديل خطة.
- [Web عميل هيكل بنية](../../../.agents/notes/implemented/architecture/2026-07-19-gui-web-client-architecture.ar.md)——متصفح إضافة سطر مثل أي تحميل و تسجيل slot.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد أصلي اختيار جهاز ملائم استخدام وقت آلة. هو جمع هو حالي حزمة قيد، لا هو عام اختيار جهاز مقابل مقارنة أو مهمة تراكم ضغط.

- **لا يمكن إلغاء قد فتح اختيار جهاز**——wire لا يوجد حسب طلب في توقف آلية، لذلك قد عرض في محلي اختيار جهاز لا يمكن من متصفح إغلاق؛ يتم إسقاط تسوية سوف يتم تجاهل اختصار.
- **فقط حد محلي تحمل تحميل**——Electron محادثة إطار اختيار محلي مسار؛ عادي Web فتح Host اختيار جهاز. بعيد مسار متصفح و عملية داخلي توقيع استخدام `-browse` تركيب. منصة فشل مرور من يحتفظ جهة يمكن إعادة محاولة ملف مشبك محادثة إطار عرض.
- **Linux تلقائي اختيار**——نقص قليل zenity أو kdialog وقت،Host أي جعل في Desktop في أيضا اختيار تصفح نمط، لا استخدام Electron محادثة إطار.
