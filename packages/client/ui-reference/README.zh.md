# @deepseek-ai/dsh-client-ui-reference

[English](README.md) | العربية

## عام وصف

Web مستخدم حاجة من نفس عدد `@` تكملة كل قائمة مفرد رفع و ملف، ملف مشبك أو جلسة وقت، يمكن استخدام `dsh-client-ui-reference`. قائمة مفرد أولا صف خروج ملف، مجددا صف خروج جلسة؛ منها واحد مجموعة لا يمكن تحميل وقت، آخر مجموعة ما زال متاح. اختيار ملف، ملف مشبك أو جلسة سوف إدراج دخول حمل مستقر قص لصق لوح شكل صيغة أصل فرعي مرجع؛ ملف مشبك سطر أيضا سماح مستخدم في لا إغلاق تكملة كل حال حال تحت متابعة تحت حفر. ملف سطر حذف كثير بقية أصل دليل موضع، جلسة سطر فقط في مساحة العمل و حالي مساحة العمل مختلف وقت عرض هذا مساحة العمل. جلسة mention سوف في التقاط نموذج سياق قبل قبول تحقق، بينما تصفح تصفح مرشح بند لن أثر نموذج.

## استخدام هذه الحزمة

فقط يلزم تركيب تركيب هذه الحزمة كما وجود مضيف `ctx.fileReferences` مزود، هذا source أي موضع في نشط حركة حالة. إدخال `@` بعد تتبع واحد لم إضافة جذب رقم token، سوف أولا يرى ملف، مجددا يرى جلسة؛ فتح `@"…` فإن فقط بحث ملف. مرشح قائمة هو تكملة كل قائمة مفرد، لا هو بحث نتيجة صفحة: اختيار مرة، متابعة إدخال يكفي.

### اختيار بعد سوف إدراج دخول ماذا

اختيار ملف سوف إغلاق تكملة كل، و عرض لـ حمل ملف رسم علامة و عمل خدمة لون ملف اسم أصل فرعي سطر داخل مرجع. دليل سطر يحمل اثنان عدد حركة كلمة: اختيار تحديد pick(نقر سطر رئيسي جسم أو Enter) يأخذ ملف مشبك ذاته تحليل لـ نفس صنف أصل فرعي مرجع——ملف مشبك رسم علامة، حمل ذيل مائل عمود وسم، بـ مواصفة `@dir/` mention لـ تسلسل تحويل شكل صيغة؛ حفر أخذ حركة عمل (Tab أو سطر ذيل chevron) فإن إبقاء حمل ملف مشبك رسم علامة يمكن تحرير مسار صاف نص، و يجعل قائمة مفرد في ذيل جزء مائل عمود موضع إبقاء نشط وثب، مستخدم يمكن متابعة دخول تحت واحد طبقة. يتضمن فارغ أبيض مسار استخدام `@"path with spaces"`، مستخدم صريح فتح جذب رقم سوف متابعة إبقاء.

اختيار جلسة سوف إدراج دخول واحد أصل فرعي سطر داخل مرجع، ذلك إخفاء `ref` و قص لصق لوح يمثل متساو لـ مضيف إرجاع مواصفة `@[label](dsh-session:…)` mention؛ مرئي شكل صيغة لـ حديث يوم هواء فقاعة رسم علامة إضافة جلسة عنوان. إرسال سوف مرور `session.prompt` يحمل هذا mention،session-reference خدمة سوف في `agent/pre-step` تحقق هو و التقاط نموذج سياق.

### فشل سلوك

بعض عدد مرشح مجال غير ممكن استخدام أو فشل وقت، هذا مجال لا إنتاج أي سطر، آخر مجال ما زال صحيح معتاد صف خروج. جلسة مرجع دقيق تجهيز فشل حدوث في نص التوجيه قبول بعد، و سوف إنهاء هذا agent جولة.

نقر إدخال إطار في ملف مرجع، يمكن في يمين جانب شريط معاينة ملف حالي محتوى. حمل جذب رقم مسار في فارغ إطار سوف إبقاء، مسار حسب إدخال إطار الذي تابع Session تحليل. ملف مشبك و Session مرجع إبقاء أصل لديه تحرير سلوك.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا source يأخذ مرشح تحرير رمز إبقاء في تسجيل effect داخلي:`/client` توجيه خروج واجهة فقط يتضمن إضافة رئيسي جسم (`apply`/`inject`).

### مرشح مسار

مقابل في لم إضافة جذب رقم token، متصفح سوف معا بدء `fileReferences/list` و `sessionReferenceResolver/candidates` Remote استدعاء، مجددا حسب ملف، حالي Session مباشر subagent، أخرى Session تحديد صفة ترتيب ترتيب صف. كل سطر استخدام resolver عرض عنوان؛subagent أولوية استخدام إنشاء وسم، عادي Session إبقاء إسقاط عنوان، و تصيير في locale إدارة قسم مجموعة عنوان تحت، لا عرض تكرار أصلي `reference` source عنوان. جلسة سطر استخدام مضيف جلسة قائمة `updatedAt` مرور هذا قائمة نفسه متبادل مقابل وقت قسم ملف علامة ملاحظة وقت، لذلك نفس عدد جلسة في اثنان موضع قراءة إلى وقت طويل متسق؛ قائمة في لا يوجد جلسة عودة سقوط إلى مرشح ذاتي حمل إنشاء وقت. تحت حفر بعد استعلام سوف إصدار واحد بند من مساحة العمل أصل دليل إلى حالي دليل وجه حزمة فتات؛ كل واحد عقدة يحمل تحت حفر تحميل حمل و ملف مشبك سطر نفسه، لذلك «عودة إلى بعض واحد خطوة» و «دخول بعض واحد طبقة» هو نفس عدد نتيجة.

### تسلسل تحويل

ملف اختيار يأخذ مشترك `@path` لغة قاعدة الذي تعريف ذاتي لكن نص إبقاء لـ إخفاء تسلسل تحويل و قص لصق لوح شكل صيغة. جلسة اختيار استخدام مواصفة `@[label](dsh-session:…)` mention؛ تسلسل تحويل دائم بعيد لن أصل حسب مرئي عنوان إعادة بناء هوية.

</details>

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أثر تجربة النموذج: عبر مضيف يملك مزود تنفيذ، هذه الحزمة مرجع اختيار يأخذ ملف إشارة جذب و جلسة لقطة دقيق تجهيز تفويض حمل إعطاء هو جمع.

#### KV Cache أثر

تصفح تصفح مرشح بند لن أثر نموذج. اختيار ملف أو جلسة فقط سوف تغيير جديد مستخدم رسالة بعد لاحقة، و ضيق مع هذا رسالة، من مضيف دقيق تجهيز جلسة مرجع سياق؛ هدف جلسة أكثر مبكر تاريخ إبقاء ثابت.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح مرجع source أي وقت مساعدة لا فوق مشغول؛ هو جمع هو حالي حزمة قيد.

- **مرشح فشل متعمد إبقاء ساكن صامت**:Remote اكتشاف استدعاء غير ممكن استخدام أو فشل وقت، هذا مجال لا إنتاج مرشح سطر. جلسة مرجع دقيق تجهيز فشل حدوث في نص التوجيه قبول بعد، و سوف إنهاء هذا agent جولة.
- **متصفح جانب لا مسح ملف**:Web تكملة كل حاجة تركيب مضيف `ctx.fileReferences` مزود؛ متصفح لا يمكن رجوع إلى ذاته نظام الملفات.
- **جلسة بحث ما زال فقط استخدام بيانات وصفية**: اكتشاف مسار عبر `ctx.sessionReferenceResolver` غربلة اختيار session id،cwd و بـ سجل لـ اعتماد حسب الأكثر جديد عنوان؛ لا بحث رسالة رئيسي جسم أو كامل transcript.
