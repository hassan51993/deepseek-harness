# @deepseek-ai/dsh-client-modules

[English](README.md) | العربية

## عام وصف

`dsh-client-modules` يأخذ إضافة حزمة `dsh.client` إعلان تغيير صار يمكن تحميل متصفح bundle: مضيف نصف جانب مسح قد تفعيل Loader بند و تركيب بدء رسم، متاح Web تحميل جسم عبر `/plugins` توفير كل bundle، من shell يحتفظ تحميل جسم فإن عبر `fetchBundle()` قسم إرسال تماما نفسه bundle استجابة. متصفح نصف جانب حسب يحتاج كسول صفة تحميل هذه bundle. إضافة bundle كسول صفة تنفيذ——تشغيل bundle فقط تسجيل factory، وحدة فرعي أثر في شيء تحويل وقت تشغيل——لذلك إضافة أول مرة يتم استخدام قبل ماذا كل لن تشغيل. هذا داخل واحد قطع كل هو متصفح داخل نواة آلية؛ نموذج دائم بعيد نظر لا إلى هو.

## استخدام هذه الحزمة

إعلان نوع استخدام [`DshClientManifest`](../../util/package-manifest/README.ar.md).Client-modules تحقق JSON، و يحتفظ عودة واحد تحويل بعد بدء رسم.

تركيب أو بناء متصفح عميل إضافة وقت استخدام هو: هذه الحزمة يأخذ حزمة `dsh.client` إعلان تغيير صار يمكن تحميل متصفح bundle، بلا حاجة أي تدريجي إضافة وصل خط. هو مع web تركيب تنشيط؛ خارج قشرة في أي إضافة تشغيل قبل بدء هو.

### إعلان عميل إضافة

متصفح إضافة حزمة في ذلك `package.json` في بـ `platform: 'web'` إعلان `dsh.client`، توجيه خروج `./client` bundle، و في `dsh.client.external` تحت صف خروج أي أساس مقعد خارج وحدة طلب. مضيف نصف جانب يأخذ كل نسخة إعلان تغيير صار `/plugins` تحت توفير bundle، و يجعل حركة حالة مزود أولا في ذلك مستهلك تحميل.

### متصفح تحميل ماذا

application combo نص برمجي فقط يحمل كل إضافة `client.js` مدخل، و في بدء وقت فقط تسجيل مرة هذه factory؛ وحدة رئيسي جسم ما زال إبقاء كسول صفة، فقط في أول مرة import أو شيء تحويل وقت تشغيل. مرور tsdown تفكيك قسم شفرة المصدر `import()` سوف تحرير ترجمة لـ `require.async("./client.<name>.js")`؛ فقط لديه تنفيذ هذا جدول بلوغ صيغة وقت، مقابل حمل إصدار نفس درجة نص برمجي عندئذ سوف وصول. مشترك combo URL row مشترك استخدام واحد إجراء في نص برمجي مهمة.HMR(حار وحدة استبدال) سوف يجعل واحد بند حدوث تغير row تعديل استخدام حمل revision مفرد مورد combo URL.`<id>/client` و عار id تحليل إلى نفس مجموعة توجيه خروج، لأن إضافة bundle حينئذ هو ذلك حزمة عميل نصف جانب.

### إضافة حركة حالة تركيب

قد فتح Web صفحة عبر HMR نقل تتبع مع Host كامل وحدة رسم. تفعيل عادي إضافة سوف إضافة ذلك Loader بند؛ توقف استخدام سوف إزالة بند، و في ذلك مختلف خطوة effect إتمام تنظيف بعد عودة استلام لم استخدام وحدة و مثال صيغة. مجددا مرة تفعيل سوف تحميل واحد حمل مثال صيغة نسخة. أخرى Loader مساهمة جهة بند و نشط حركة بند ما زال يحتاج استخدام مشترك وحدة سوف إبقاء.«ضبط → إضافة → إضافة قائمة» عرض حالي صفحة تزامن فشل، و توفير لا تغيير Host تفعيل حالة إعادة محاولة.

### مشترك وحدة

خارج قشرة ابتدائي تحويل واحد ورقة تجميد ربط وحدة جدول (`PLATFORM_MODULES`:React،Cordis و ساكن حالة UI مكتبة) ؛ كل حركة حالة bundle كل دقيق إبرة مقابل هذا أساس مقعد تحليل ذلك external.`dsh.client.external` فقط إضافة أساس مقعد خارج دقيق طلب؛ نظام سوف سوف كل طلب تحليل إلى ذلك إشارة تحديد حركة حالة حزمة row أو تماما مطابقة ساكن حالة جدول مفتاح. صاف نوع import سوف يتم مسح حذف، لا إنتاج طلب. تركيب مرحلة مقطع سوف رفض شاذ شكل طلب، ناقص مزود، ذاتي طلب و تزامن طلب حلقة.

### بناء اشتراط

مضيف توفير هو قد بناء عميل bundle، لذلك بدء قبل `pnpm run build` يجب قد إنتاج خروج كل `lib/client.js`؛ ناقص bundle سوف واضح توجيه يؤدي تنشيط فشل، و إعطاء خروج واحد بند بناء شرح و حزمة/مسار قائمة. شفرة المصدر بدء سوف يأخذ مضيف جانب استيراد خريطة إلى TypeScript شفرة المصدر، لكن ما زال إزالة استهلاك هذا واحد بناء بعد عميل توجيه خروج. هذه الحزمة ذاته لا قبول أي إضافة إعداد.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير وحدة نظام بناء طريقة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

هذه الحزمة قسم لـ اثنان جانب:Node نصف جانب مسؤول تركيب و توفير (`ctx.clientModules`،`ClientModuleRegistry`) ، متصفح نصف جانب مسؤول تحميل (`ctx.modules`،`ClientModuleSystem`). اثنان من بين بروتوكول هو بدء رسم——بـ `window.__DSH_BOOT__` حقن `WebBootEntry` سطر،`<` قد تحويل معنى، إضافة تحكم نص لا يمكن هروب خروج script عنصر عنصر.vendored Loader وحيد إزالة استهلاك نقطة هو `EntryTree.import`، لذلك وحدة نظام حينئذ هو «إضافة شفرة مثل أي وصول» وحيد يمكن استبدال تنفيذ.

### كسول صفة CJS نموذج

تنفيذ إضافة bundle فقط تسجيل ذلك factory؛ كل وحدة رئيسي جسم فرعي أثر (يشمل CSS حقن) كل يقع في factory إغلاق حزمة في، في شيء تحويل وقت تشغيل (`factory(require)` → توجيه خروج، في `loadCache` في تسجيل ذاكرة تحويل).factory اعتماد آخر عدد قد تسجيل لكن لم شيء تحويل وحدة وقت سوف تمرير عودة شيء تحويل هو؛require حلقة سوف رمي خروج استثناء، لأن factory شكل صيغة CJS لا يمكن توفير جزء توجيه خروج. تحليل سوف اعتماد مرة فحص منصة seed جدول، قد تسجيل ذاكرة سجل، بدء رسم row و قد تسجيل factory؛ أخرى حال حال واحد قاعدة رمي خطأ. تسليم إعطاء factory تزامن `require` استخدام نفسه ترتيب، لكن لا يحتوي مختلف خطوة رسم row تحميل، و يأخذ مراقبة إلى حافة سجل إلى وحدة سجل في. هو `require.async` عملية إرجاع Promise، و في مرة صفة شيء تحويل تحرير ترجمة جهاز توليد حزمة داخل chunk قبل أولا نيل أخذ هذا chunk. هذا بروتوكول فقط دعم حمل ذاتي يتضمن chunk: مدخل و chunk ناتج لا يستطيع تزامن require آخر عدد متبادل مقابل `client*.js` ناتج.

### زيادة كمية تركيب

Node نصف جانب تدريجي حزمة زيادة كمية مسح——لا يوجد كل كمية إعادة مسح مسار. كل مرة إرسال خروج `internal/plugin` حدث وقت، نظام كل سوف يأخذ هذا fiber entry اسم علامة قذر؛ دقيق مهمة flush سوف يأخذ كل قذر اسم و حالي loader بند مقابل حساب، تنشيط pass سوف ابتدائي تحويل نفس عدد قذر تجميع دمج تزامن flush، لذلك أول مرة مسح و مستقر حالة مشترك استخدام نفس تنفيذ. حزمة بيانات وصفية حسب Loader specifier و الذي تابع tree base URL ذاكرة مؤقتة حتى إعادة بدء، تحليل خروج manifest(بيانات وصفية بيان) حزمة اسم بصفة متصفح وحدة هوية. إذا مختلف active Loader source تحليل إلى نفس حزمة اسم، تركيب سوف فشل؛ إزالة اندفاع مفاجئ مصدر بعد، باق بقية مصدر بلا حاجة إعادة بدء fiber يكفي وصل بديل.bundle محتوى تغيير فقط قدرة عبر `rebuilt()`(HMR خطاف) دخول رسم.

Node نصف جانب سوف في إصدار قبل لقطة كل `client.js` مدخل، و في لا بناء استجابة body حال حال تحت إنشاء combo descriptor. هو يأخذ مورد قسم مجموعة إلى `/plugins/??...&rev=...` combo URL:modules row استخدام واحد bootstrap combo، ذلك بقية row استخدام واحد أو كثير عدد application combo؛ كل مرحلة مقطع كل سوف في URL تجاوز مرور 3 KiB قبل قسم منطقة. نص برمجي body في أول مرة `GET` وقت فقط تركيب مرة، و بـ مقابل map URL ربط ذيل؛map ملف فإن في أول مرة map `GET` وقت مفرد وحيد قراءة، تحقق و تركيب،`HEAD` لن شيء تحويل مهمة واحد body.Host لا مسح أيضا لا مسبق تحميل نفس درجة chunk: دقيق `/plugins/<package>/client.<name>.js?rev=<rev>` طلب سوف قراءة و ذاكرة مؤقتة هذا نص برمجي، ذلك map ما زال سوف انتظار إلى map URL يتم طلب بعد عندئذ حساب حساب. كل combo أو chunk map كل هو Indexed Source Map v3، و في متاح وقت استخدام عمل من توفير section، لا فإن لـ قد تحزيم bundle توليد identity section. ابتدائي تدريجي إضافة revision استخدام عملية nonce. تطوير خلال، مشترك مسبق ضبط سوف في هذا حزمة كل إخراج كتابة تمام بعد علامة `client.js`؛HMR من مدخل بايت و هذا بناء إتمام علامة إرسال توليد تحت واحد revision، لذلك فقط chunk حدوث إعادة بناء أيضا سوف أكثر تبديل owner revision، بلا حاجة Host مسح chunk.combo revision من لديه ترتيب row revision إرسال توليد. قد عام إبلاغ combo استجابة و قد طلب chunk استجابة سوف عبر غير متصل رسم إعادة مجموعة إبقاء غير ممكن تغيير؛ لم معرفة مورد أو revision إرجاع 404.

### بدء manifest حقن

bundle توجيه مع حقن `webServer` دورة الحياة تسجيل: خدمة حينئذ خيط وقت تسجيل، خدمة يتم استبدال وقت إزالة و إعادة تسجيل. وحدة تركيب و `fetchBundle()` في لا يوجد Web server وقت ما زال متاح.

مضيف مساهمة بنية تحويل index سطر، و نحو `<head>` حقن:`window.__ModuleLoader__` queue facade، كل application combo تلميح صفة preload، منع سد parser bootstrap combo نص برمجي، لكن بعد عندئذ هو خارج قشرة قراءة قبل بدء رسم.Web تحميل جسم يأخذ هذه سطر تصيير دخول index استجابة؛ من shell يحتفظ تحميل جسم فإن يمكن في لا يوجد Web server وقت تصيير نفس دفعة سطر.facade `create()` شيء تحويل modules bundle، يأخذ بنية صنع تفويض حمل إعطاء ذلك `createClientModuleSystem` توجيه خروج، و يجعل نفس facade دخول live registration نمط. خارج قشرة يأخذ إرجاع نظام تركيب صار ذاته Loader `internal`؛modules إضافة سوف هذا نسخة إصدار لـ `ctx.modules`، لذلك مختلف Cordis شجرة لن عبر وحدة درجة عام حالة اختيار نسخة.

### بند كل حق

`ClientEntries` سجل بدء وقت إنشاء بند، و في نفس عدد Loader فوق سلسلة سطر تنفيذ كامل رسم تحديث، إعادة محاولة و شفرة إعادة تحميل. محلي بديل حد منع توقف قديم تحت تحميل في هدف بند أو شفرة تغير بعد تركيب؛ هدف نفسه لقطة مشترك استخدام إجراء في تحميل. إضافة جديدة وحدة استخدام مفرد مورد URL، لن إعادة تنفيذ ممكن تكرار تسجيل قائم factory بدء batch.Factory في بند إنشاء قبل حينئذ إبقاء ناتج revision؛ رسم تحديث سوف في استيراد إزالة استهلاك من قبل إسقاط لم ملكية بند قديم قديم factory، ذلك مثال صيغة و فشل وصول هدف. تنظيف سوف إبقاء كل باق بقية Loader بند قد إعلان و قد مراقبة إلى نقل تمرير وحدة اعتماد. ذلك يمكن مراقبة حالة لا استيراد وقت التشغيل مكتبة، لأن modules bootstrap في منصة نوع فرعي متاح قبل شيء تحويل.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح وحدة نظام لا فعل ماذا. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **متعمد اعتماد مسطح مستو وحدة رسم**——كل bundle هو واحد وحدة عقدة، ذلك حافة فقط إشارة نحو جدول في ورقة عقدة؛ واجهة (`loadCache`/`edges`/`invalidate`) قد دعم حمل عام وحدة رسم، لذلك يمكن تغيير externalization حبة درجة بينما لا أكثر تعديل واجهة.
- **Bootstrap و شفرة استبدال حد**——صفحة إبقاء modules bootstrap و ساكن حالة منصة وحدة هوية. إزالة أو استبدال bootstrap حاجة تحديث جديد صفحة؛ حركة حالة استبدال طلب سوف تقرير إبلاغ صفحة محلي خطأ، و إبقاء ذلك fiber و توجيه خروج؛ استبدال حزمة شفرة و ذلك كل قائم إزالة استهلاك من لا يخص عادي بدء توقف تزامن.
- **كسول صفة توفير سوف إبقاء قد طلب body**——Host في داخل تخزين في إبقاء كل bundle و كسول صفة استجابة حساب تخطيط؛ نص برمجي أو map body في أول مرة `GET` بعد إبقاء ذاكرة مؤقتة،HMR أيضا سوف إبقاء فوق واحد بديل بدء استجابة. داخل تخزين فقط مع عميل فعلي طلب استجابة body زيادة طويل، معا إبقاء واحد بديل تنافس حالة سعة تحمل.
- **من لم طلب فوق واحد بديل map سوف قراءة حالي map ملف**——combo revision تتبع أثر يمكن تنفيذ bundle، بينما لا تتبع أثر ضبط تجربة ناتج. إذا HMR في إبقاء قديم URL أول مرة استلام إلى map `GET` قبل إعادة بناء map، هذا استجابة سوف يأخذ حالي authored map و قديم bundle offset تركيب؛ في إعادة بناء قبل طلب map سوف ثابت هذا URL استجابة.
