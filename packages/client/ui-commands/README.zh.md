# @deepseek-ai/dsh-client-ui-commands

[English](README.md) | العربية

## عام وصف

مفتاح دخول `/` أمر سوف فتح قد تسجيل نابض نافذة، تشغيل عميل حركة عمل، دخول مضيف أمر إدخال أو مباشر تنفيذ، أمر سطر لن يتم ساكن صامت تخفيض لـ عادي نص التوجيه. عمل خدمة حزمة عبر `ctx.commandUi` تسجيل popupSelect(`/model`،`/permission`) أو action، أيضا متاح هذا اثنان نوع طريقة تركيب زينة قائم مضيف أمر، معا إبقاء ذلك دليل سطر و معامل إعلان. فارغ إطار و عودة عربة أصل حسب جلسة دليل تحليل أمر سطر: حمل `input` مضيف وصف رمز هو `leadingInput`، تسجيل `CommandUiSpec` هو `popupSelect` أو `action`، ذلك بقية هو `execute`.

## استخدام هذه الحزمة

و `ui-input-trigger` و `ui-conversation` واحد بدء تركيب هذا إضافة؛`/` source مع أي ظهور في إطلاق قائمة مفرد في، عمل خدمة حزمة مرور `ctx.commandUi` تسجيل ذاتي ذات أمر جدول وجه. مفتاح دخول `/model` فتح قد تسجيل نابض نافذة؛ حمل معامل إعلان مضيف أمر فتح ذلك إدخال أو مباشر تنفيذ. نابض نافذة يحتفظ composer تركيز نقطة: مفتاح دخول أي في قد تحميل سطر فوق محلي غربلة اختيار،`↑`/`↓` في سطر بين نقل حركة، عودة عربة و `Tab` قبول عال مضيء سطر،Escape و `Shift+Tab` يأخذ تركيز نقطة أيضا إعطاء composer. عال مضيء سقوط في خيار علامة لـ جلسة حالي قيمة سطر فوق، لذلك في للتو فتح نابض نافذة فوق قبول أي تأكيد حالي قيمة.composer `+` حسب زر و مفتاح دخول `/` فتح نفس عدد قائمة مفرد:«إضافة» صغير عقدة (ملف، هدف، حساب تخطيط، عكس تغذية) و «إشارة أمر» صغير عقدة (ضغط، إذن، نموذج، تحت تحميل سجل) حسب استخدام تردد مرة ترتيب صف، كل سطر حمل رسم علامة، محلي تحويل عنوان و شرح، محلي تحويل عنوان و أمر اسم مختلف وقت أيضا عرض أمر اسم بصفة آخر اسم.

### نوع صنف و تركيب زينة

مساهمة بند هو عميل ذاتي لديه أمر، و مضيف أمر نفس اسم سوف واضح تقرير خطأ. هو UI هو popupSelect قاعدة إطار أو حركة عمل: عار استدعاء إزالة استهلاك إطلاق token بعد تشغيل عودة ضبط، لا إيداع رسالة. عمل خدمة حزمة مسؤول ذاتي ذات حركة عمل و متاح صفة، إدخال إطار عبر نفس API تسجيل «ملف». تركيب زينة لـ قد لديه مضيف أمر إضافة عار استدعاء نابض نافذة أو حركة عمل، و إبقاء ذلك دليل سطر، معامل إقرار قيادة و دورة الحياة سجل؛ لا يوجد مطابقة مضيف سطر وقت لا إطلاق. قائمة مفرد استعلام حسب ترتيب، لا منطقة قسم كبير صغير كتابة أرض نموذج غامض مطابقة أمر اسم و عنوان فرعي تسلسل، بادئة أولوية، لا عرض صغير عقدة عنوان.

### داخل وضع سطر عرض وجه

داخل وضع أمر تعريف يحمل مستقر `definitionId`. عميل حسب معرف اختيار محلي تحويل عنوان، شرح، رسم علامة و إدخال كتابة قاعدة، تعديل مضيف شرح لن تغيير اختيار نتيجة. لا يوجد مطابقة معرف نفس اسم تغطية إبقاء ذاتي ذات نص سجل، أيضا لا نيل نيل داخل وضع آخر اسم. في أي واجهة لغة تحت، في إنجليزي نص كتابة قاعدة كل عبر نفس عدد جلسة صالح دليل تحليل، مسودة مسودة إبقاء يد نقل كتابة قاعدة، إيداع استخدام مضيف تسجيل اسم. مساهمة بند توفير ذاتي ذات `label`،`description` و `icon`، كل مرة توليد مرشح بند وقت قراءة. فارغ استعلام حسب اسم تحديد صغير عقدة ترتيب، لم صف خروج سطر ترتيب في «إشارة أمر» نهاية ذيل.

### حمل مرفق عنصر إيداع

composer يحمل صورة أو عام ملف إيداع وقت، فقط لديه إعلان `input.attachments` مضيف أمر متابعة. ذلك بقية أمر مسار كل سوف رمي خروج محلي تحويل `attachmentsUnsupported` رفض، بـ لحظة حالة toast عرض، مسودة مسودة و مرفق عنصر بطاقة إبقاء أصل موضع. معالج خروج خطأ وقت إبقاء نفسه مسودة مسودة حالة توفير مستخدم إعادة محاولة.

<a id="model-experience"></a>
## تجربة النموذج

إرسال إرسال مسار عبر ذلك إطلاق مضيف `command.execute` RPC بين وصل أثر نموذج: كل أمر handler مضيف حزمة يملك أي نموذج مرئي فاعلية نتيجة (`/plan` handler قلب تحويل plan نمط، ذلك ملكية حزمة حقن policy مقطع) ، بينما أمر سطر، قسم مغادرة نتيجة و كل قائمة مفرد و notice تصيير كل إبقاء في عميل، دائم لا دخول جلسة سجل.

#### KV Cache أثر

بلا مباشر أثر؛ هذا حزمة حيث لا تجميع أيضا لا إرسال مزود طلب. هو إطلاق أمر handler ممكن تغيير ملكية مضيف حزمة مقابل تحت واحد طلب توجيه النظام مساهمة——بعض عدد section ظهور أو إزالة فقد سوف استبدال مقارنة مبكر طلب token، و جعل مزود بادئة من هذا نقطة بدء بطلان——لكن هذا واحد أثر من كل أمر مضيف حزمة يملك و سجل.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد حالي أمر تفاعل طريقة. هو جمع هو حالي حزمة قيد، لا هو عام أمر سطر مقابل مقارنة أو مهمة تراكم ضغط.

- **انفصال مغادرة جلسة بعد، قسم مغادرة نتيجة notice رجوع إلى console**——fire-and-forget مسار مرور `SessionInput.notify` يأخذ نتيجة إرسال إلى إطلاق جلسة composer؛ جلسة إلغاء تدمير بعد،console إخراج سطر هو فقط باق عرض وجه.
