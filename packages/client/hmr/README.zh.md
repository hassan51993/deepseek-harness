# @deepseek-ai/dsh-client-hmr

[English](README.md) | العربية

## عام وصف

`dsh-client-hmr` يجعل قد فتح Web صفحة و Host إضافة رسم إبقاء تزامن، و إعادة تحميل إعادة بناء بعد متصفح bundle. عادي إضافة بدء توقف بلا حاجة تحديث جديد صفحة أو إعادة بدء Host يكفي توليد فاعلية. شفرة إعادة بناء سوف استبدال تلقي أثر إضافة و إعادة وضع ذلك مكون حالة. نموذج لن استلام إلى جديد إدخال أو إخراج.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

مع حزمة توفير Web تركيب تركيب هذا نقل، بـ تسليم إضافة حركة حالة تغيير. تطوير وقت،bundle watcher أيضا سوف توفير شفرة إعادة بناء. توقف استخدام هذا نقل سوف إيقاف نحو قد فتح صفحة تسليم رسم تحديث.

### بدء إعادة تحميل سلسلة مسار

مقابل نفس عدد مضيف تشغيل `pnpm run dev:web`(أو استخدام مشترك Client tsdown مسبق ضبط watch عملية) ؛ إعادة بناء بعد إضافة مع بعد سوف يتم تلقائي تدريجي عدد استبدال دخول تشغيل في متصفح. هذا مسبق ضبط سوف في كل حزمة داخل chunk كتابة تمام بعد علامة `lib/client.js`، لذلك فقط chunk حدوث إعادة بناء أيضا سوف دفع دخول حزمة revision، بلا حاجة Host مسح chunk.

### مرة إعادة تحميل فعل ماذا

كل مرة نجاح إعادة تحميل كل سوف إعادة تنفيذ إضافة bundle، و استخدام كل جديد حالة إعادة تركيب إضافة. اعتماد يتم إعادة تحميل إضافة إضافة سوف مع لـ تلقائي إعادة تحميل. فشل سوف عرض في إضافة قائمة في، يمكن مباشر إعادة محاولة، بلا حاجة انتظار تحت مرة إعادة بناء.

### إعداد

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `pollIntervalMs` | `500` | bundle stat جولة استفسار بين فصل، مفرد موضع لـ جزء ثانية |

توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-client-hmr) هو كل تلقي دعم حمل حقل و ذلك JSDoc كامل حق مصدر.

### مراقبة نجاح

نجاح استبدال سوف قيام أي عرض تحرير بعد UI، بلا حاجة صفحة إعادة تحميل، كما إضافة في استبدال بعد متابعة عمل. طلب تسجيل إقامة حق توازن: يتم إعادة تحميل إضافة داخل React حالة سوف فقد فقد، بينما جلسة، مساحة العمل و اتصال حالة سوف إبقاء.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير إعادة تحميل سلسلة مسار بناء طريقة؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم إدارة فكرة

Host نصف جانب استماع كل حزمة حمل إتمام علامة مدخل ناتج، و توفير `/plugins/events`. هو تحويل اكتشاف لديه رسم تغير و إعادة بناء إشعار؛ كل جديد اتصال كل سوف استلام إلى حالي كامل رسم. رسم وصف متصفح هدف بند، لا حفظ إثبات Host تنظيف قد إتمام.Host تنشيط و تنظيف ما زال من Host دورة الحياة إدارة. مدخل بايت و بناء إتمام ختم الوقت مشترك نفس معرف revision؛ لم تغير ناتج بلا حاجة قراءة محتوى. متصفح نصف جانب سوف اثنان نوع لقطة كل تسليم إعطاء Client Modules، من هو سلسلة سطر معالجة بند تغيير و انتظار متصفح مورد تنظيف.

### متصفح جانب استبدال

استلام إلى `rebuilt` لقطة بعد، تحكم جهاز جعل قديم وحدة بطلان، و في قديم fiber ما زال خدمة وقت مسبق أخذ ذلك مفرد مورد نص برمجي. مع بعد حذف سجل التسجيل runtime، انتظار قديم fiber تنظيف، صاف حذف بند في fiber مرجع و إزالة ذاته مثال صيغة. وحدة نظام أولا شيء تحويل جديد توجيه خروج، مجددا من `entry.refresh()` عبر Loader تركيب؛ هذا مثال أي جعل Loader فقط سجل استيراد خطأ، صفحة تشخيص ما زال قدرة نيل نيل فشل سبب.CSS في قديم effect إتمام تنظيف بعد حقن.

### درجة ربط و ذاتي إعادة تحميل

fiber تنشيط epoch سوف سلسلة ربط ذلك خدمة مزود uid، لذلك استبدال مزود fiber سوف عبر Cordis ذاته درجة ربط إعادة تحميل كل اعتماد جهة، بلا حاجة HMR(حار وحدة استبدال) جانب صيانة أي دفتر تسجيل معلومة. هذا إضافة ذاته أيضا هو واحد رسم entry، لذلك `rebuilt` لقطة ممكن نقطة اسم هو؛ إجراء في إعادة تحميل في قديم bundle إغلاق حزمة في متابعة تشغيل، جديد bundle apply سوف فتح كل جديد عبر طريق.

### فشل سياسة

تحت تحميل فشل وقت، صحيح في تشغيل إضافة إبقاء نشط حركة. قديم fiber يتم إزالة بعد، استيراد أو تنشيط فشل لن استعادة أولا قبل bundle. فشل سوف عرض لـ حالي صفحة تزامن خطأ.«ضبط → إضافة → إضافة قائمة» سوف إبرة مقابل الأكثر جديد رسم إعادة محاولة، أي جعل ذلك revision لم تغير؛ لاحق إعادة بناء أيضا سوف إعادة محاولة تلقي أثر إضافة. غير متصل كما قد نجاح تشغيل إضافة إبقاء نشط حركة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | node نصف جانب:bundle stat جولة استفسار،`rebuilt` فوق تقرير،`/plugins/events` SSE عبر طريق |
| [`src/client/index.ts`](src/client/index.ts) | متصفح نصف جانب:SSE حجز قراءة و مشترك بند تحكم جهاز استدعاء |
| [`src/events.ts`](src/events.ts) | مشترك لقطة نوع (`graph` / `rebuilt`) و طرف نقطة معتاد كمية |

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح إعادة تحميل مشغل لن إبقاء أو استعادة ماذا. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **إعادة تحميل متعمد إبقاء خشن حبة درجة**——كل جديد fiber و كل جديد مكون؛ يتم إعادة تحميل إضافة داخل React حالة سوف فقد فقد، بينما بيانات طبقة (اتصال fiber، وقت التشغيل fiber،Session كائن) لا تلقي أثر.react-refresh درجة حالة إبقاء و إعادة تنفيذ bundle اندفاع مفاجئ، لذلك متعمد ترتيب حذف.
- **فشل وقت لا تراجع**——قديم fiber يتم إزالة بعد، استبدال فشل لن استعادة أولا قبل bundle.
- **فقط مسؤول Web نقل**——Electron تثبيت و خلفية إعادة بدء مسار لا استخدام هذا SSE مسار. بند مقابل حساب ذاته لا اعتماد نقل.
