# @deepseek-ai/dsh-client-ui-primitives

[English](README.md) | العربية

## عام وصف

استخدام `dsh-client-ui-primitives`، عبر مشترك React UI بناء Web عميل تحكم عنصر و تصيير agent إخراج. هو توفير معيار تحكم عنصر، رسم علامة، مرساة تحديد طفو طبقة، و لأجل حمل TeX عام صيغة Markdown، طرفية إخراج، ملف قراءة، فرق مختلف، بحث، شبكة صفحة فحص بحث و JSON مصير. هذه مصير سوف إسقاط أصلي HTML، حد رابط و تحليل ANSI تحويل معنى تسلسل، بـ معالجة لا تلقي معلومة مهمة نموذج إخراج. مكون لا import Cordis وقت التشغيل؛ استدعاء جهة توفير محلي تحويل label، رئيسي عنوان متبادل صلة لون لون استخدام `--dsw-*` تصميم token.

## استخدام هذه الحزمة

هذه الحزمة هو Web قشرة بناء إدخال. ساكن حالة ESM لـ Vite إبقاء رقم ثلاثة جهة استيراد و مثال صيغة؛ مستقل مستهلك ذاتي سطر توفير تطوير اعتماد ([اعتماد قاعدة](../AGENTS.md#dependency-declaration)).

فقط يلزم Web عميل حاجة معيار تحكم عنصر أو agent إخراج مصير، حينئذ استخدام هذه أصل فرعي مكون تجميع تركيب وظيفة UI. هو جمع فقط مرور React تصيير، و من رئيسي عنوان أخذ نيل `--dsw-*` تصميم token، لذلك بلا حاجة استيراد رئيسي عنوان أو slot نظام يكفي ملائم إعداد مهمة معنى إضافة.

### مكون دليل

في وظيفة حزمة داخل كتابة تحكم عنصر قبل، أولا فحص هذا ورقة جدول. إضافة لا يمكن استيراد آخر عدد إضافة مكون، لذلك هذه الحزمة هو تحكم عنصر وحيد يمكن مشترك أرض جهة: دمج ملائم حينئذ إعادة استخدام، متعمد نظر شعور فرق مختلف رفع رفع صار prop، بينما لا هو آخر بدء واحد نسخة نسخ صدفة.

| توجيه خروج | هو ماذا |
|---|---|
| `Button` | يمكن نقر عملية؛`variant` اختيار `primary`،`ghost`،`outline` أو `toolbar`. |
| `Switch` | 36×20 مزدوج حالة فتح صلة.`label` لا بد ملء، تحكم عنصر غير ممكن قدرة في لا يوجد اسم حال حال تحت إصدار. |
| `Checkbox` | حمل وسم أصلي تكرار اختيار إطار، دعم حمل تلقي تحكم حالة، مفتاح قرص تفاعل و منع استخدام مثال صيغة؛ استدعاء جهة توفير محلي تحويل `label` نص. |
| `Input` | مفرد سطر نص إدخال، لأجل بحث إطار و سطر داخل جدول مفرد. |
| `Menu` | من بند، قسم فصل خط و قسم مجموعة عنوان بنية صار تحت سحب قائمة مفرد، دعم حمل تضمين طقم فرعي قائمة مفرد. فتح خلال `↑`/`↓`(و Home،End) في قائمة في مشي موضع،Tab اختيار تحديد تجمع تركيز سطر،Escape أو Shift+Tab إغلاق و يأخذ تركيز نقطة أيضا إعطاء مرساة نقطة؛ اختيار تحديد واحد سطر نفس مثال يأخذ مفتاح قرص أيضا إعطاء مرساة نقطة——حذف غير يملك من ذاتي ذات نقل حركة تركيز نقطة. فقط اعتراض قطع يقع في مرساة نقطة أو قائمة داخل مفتاح قرص،`autoFocus` فقط قرار فتح وقت هل تجمع تركيز أول سطر. |
| `Pill` | اختياري في لاصق كيس حسب زر، لأجل عرض تبديل و غربلة اختيار جهاز؛ قبول `active` و `onClick`. |
| `Tag` | فقط قراءة لاصق كيس شعار فصل؛`tone` اختيار ثمانية نوع إعداد لون لـ واحد. |
| `StateDot` | حالة علامة:`done`،`warning`،`ongoing`،`error` أو `idle`. هو هو `aria-hidden` ، اسم من تصيير نقطة توفير. |
| `ConnectionIndicator` | سطر داخل اتصال استعادة تحكم عنصر، تغطية قطع خط، إعادة محاولة و قد استعادة ثلاثة نوع حالة. |
| `DisclosureRow` | 24px ضيق تجميع طي سطر، عنوان و محتوى يسار يمين ترتيب صف. |
| `Modal` | صفحة حجب غطاء لـ فوق إقامة في محادثة إطار. |
| `RiskConfirmation` | بـ صريح تكرار اختيار إطار يأخذ صلة حساس شعور عملية تأكيد. |
| `OnboardingSurface` | أول مرة تشغيل جذب توجيه رقص منصة، خلال إبقاء تطبيق أصل عقدة inert. |
| `Tooltip` | تغلب ضخم مرساة نقطة فوق معلق توقف نص، يمكن وضع في يمين، تحت، فوق ثلاثة عدد جهة نحو. |
| `HoverCard` | إشارة إبرة يمكن توقف إبقاء، اختياري في معلق توقف معاينة؛ اختياري حمل نسخ حسب زر. |
| `Toast` | قمة جزء إقامة في لحظة وقت أفقي عرض، إبقاء وقت طويل من كل من `holdMs` قرار. |
| `JsonTree`،`JsonBlock` | فقط قراءة JSON فحص نظر. |
| `MarkdownText`،`MarkdownDelegateProvider`،`CodeBlock` | غير ممكن معلومة GFM و TeX عدد تعلم،owner تفويض حمل HTTP(S) تنقل، و عال مضيء شفرة.`CodeBlock` يمكن عبر `lineNumbers` فتح بدء سطر رقم؛ نسخ شفرة المصدر لا يحتوي سطر رقم شريط،`contentRef` فإن نحو حاجة يأخذ مستقر شفرة المصدر حزمة تركيب عقدة استخدام عمل تمرير منطقة owner توفير هذا عقدة. استدعاء جهة توفير ذاتي ذات لغة و نسخ أداة شريط وقت، ضبط `showHeader={false}`. |
| `TerminalBlock`،`ReadBlock`،`DiffBlock`،`SearchBlock`،`WebBlock` | و كل صنف أداة نتيجة معنى رسم مقابل agent إخراج بطاقة. |
| `icons/*`،`FishLogo`،`BrandWordmark`،`ReferenceIcon`،`LinkIcon` | حرف شكل و صنف لوحة معرف.`LinkIcon` لأجل 14px يمكن نقر رابط تصنيف و معروف محطة نقطة علامة. |
| `FileTypeIcon`،`classifyFileType`،`fileExtension` | حسب صنف آخر حال لون 28px ملف أو ملف مشبك رسم شكل، و هو خلف بعد مشترك لا منطقة قسم كبير صغير كتابة ملف اسم خريطة. شفرة و ملف إعداد استخدام دقيق قسم كل لون تقنية فن رسم شكل؛ رابط قبل وضع رسم شكل استخدام `LinkIcon`، صورة محتوى استخدام صورة معاينة. |

لديه ثلاثة مجموعة سعة سهل خلط خلط:

- **`Tag` و `Pill`.** 11px لاصق كيس مقياس قياس فقط قراءة شعار فصل استخدام `Tag`؛ لاصق كيس اختياري في (`active` و `onClick`، عرض تبديل و غربلة اختيار جهاز حينئذ هو هذا مثال استخدام) ، أو من يجب سقوط في 24px نص سطر فوق وقت استخدام `Pill`——`TerminalBlock` يأخذ خروج حالة تصيير صار ساكن حالة `Pill` صحيح هو بعد واحد نوع حال حال. هذا داخل مقياس قياس و هل يمكن تفاعل نفس مثال هو حكم حسب، اثنان من غير ممكن متبادل تبديل.
- **`DisclosureRow` و بطاقة.** هذا سطر بـ ثابت 24px يأخذ عنوان و محتوى يسار يمين ترتيب صف. يأخذ اسم تراكم في وصف لـ فوق بطاقة هو آخر نوع تخطيط، يخص وظيفة حزمة——`ui-settings-plugins` `PluginCard` هو أولا مثال، و سجل سبب.
- **`FoldToggle` و مقابل خارج توجيه خروج وجه.** هو هو حزمة داخل مكون، لم توجيه خروج؛ إخراج بطاقة استخدام هو فعل رأس ذيل طي.

يحتاج طلب تأكيد فعلي خاص خاص وقت، في ذاتي ذات حزمة داخل كتابة ذاتي ذات مكون لا يوجد مشكلة. غير ممكن بـ هو نسخ هذا داخل قد لديه تحكم عنصر——بينما عند ثاني عدد حزمة حاجة نفس عدد تحكم عنصر وقت، هو حينئذ هذا إقامة دخول هذه الحزمة ([قرار](../../../.agents/notes/implemented/architecture/2026-09-05-shared-client-control-primitives.zh.md)).

### تحكم عنصر و رسم علامة

فوق وجه دليل شرح كل توجيه خروج استخدام طريق؛ هذا عقدة شرح props ذاته نظر لا خروج قدوم سلوك.`ic_ds_*` رسم علامة تجميع و `FishLogo`/`BrandWordmark` علامة ملء ملء صنف لوحة و سطر داخل رسم علامة slot.`FileTypeIcon` تصيير نقل موحد 28px Excel،folder،HTML،image،Markdown،generic،PDF،PPT،video و Word رسم شكل، و لـ قائم 48 عدد شفرة و إعداد صنف آخر استخدام استيراد جهة شكل تقنية فن رسم شكل. هذا استيراد فقط استبدال رسم شكل: مورد حزمة في مقدار خارج صنف آخر لن توسيع `CodeFileType`.`classifyFileType` حسب كامل ملف اسم، بادئة، بعد لاحقة، اختياري مشروع سياق، توسيع اسم ترتيب مطابقة؛React ملف اسم أولوية في TypeScript/JavaScript،Angular بعد لاحقة أولوية في أساس أساس توسيع اسم، فقط لديه نقل دخول مشروع ملف يتضمن حمل `flutter:` `pubspec.yaml` وقت Dart ملف عندئذ استخدام Flutter.Markdown و SVG ما زال قسم آخر استخدام نقل موحد Markdown و صورة رسم شكل. إنجاز عام ملف خريطة يتضمن XLSM/Numbers جدول إطار رسم علامة،KEY وهم مصباح قطعة رسم علامة، و RTF/ODT/Pages وثيقة رسم علامة.`fileExtension` لـ متبادل مجاور بيانات وصفية label كشف نفس طقم basename و نهائي نقطة رقم تحليل. نقل موحد رسم شكل استخدام فعلي لون تصنيف قاع لوح، أبيض لون علامة و نصف نفاذ واضح أبيض لون طي زاوية؛ عام ملف استخدام رمادي لون قاع لوح و مقارنة عميق رمادي لون طي زاوية. استدعاء جهة يمكن عبر `--dsh-file-type-icon-color` تغطية قاع لوح لون لون. كل لون تقنية فن رسم شكل هو واضح مثال خارج، سوف إبقاء ذلك داخل تضمين ضبط لون لوح. كل رسم شكل كل هو تركيب زينة صفة، لا ذاتي حمل label.`LinkIcon` ما زال هو يمكن نقر ناتج رابط مقارنة صغير قبل وضع رسم شكل——أرض كرة، ملف مشبك، شفرة، صورة، وثيقة أو ورق ورقة،`url` رابط `href` إشارة نحو معروف محطة نقطة وقت فإن تعديل استخدام هذا محطة نقطة ذاتي ذات علامة——تحويل كتابة محتوى معتاد مرجع تطوير من محطة نقطة (GitHub،GitLab،npm،PyPI،Stack Overflow،MDN،Wikipedia،Hacker News،YouTube،X،Bilibili، معرفة نحو، حفر ذهب،CSDN) ، و رئيسي تدفق بحث، نظر تردد، مجتمع تسليم، شراء شيء و مشاركة اعتبار مورد مادة محطة نقطة (Google، مئة درجة،DuckDuckGo،TikTok،Netflix،Spotify،Facebook،Instagram،Reddit،Telegram،WhatsApp، دقيق معلومة،QQ، دقيق واسع، تصفية ثمين، سرعة بيع عبر،eBay،Quora،V2EX،Apple)——`classifyLinkPath` يأخذ مشترك ملف نوع طي دخول أصل لديه ستة صنف مفردات.`ConnectionIndicator` يمكن تصيير تحذير إبلاغ لون قطع ربط عملية (معتاد إقامة إعادة محاولة رسم شكل إشارة واضح إعادة محاولة حركة عمل، قطع ربط نص سجل من يحتفظ جهة توفير) ،spinner إضافة واحد حتى ثلاثة عدد نقطة بـ مستقل في retry وقت ترتيب 500ms عقدة عزف دفع دخول اتصال في حالة، أو نجاح لون استعادة حالة. نقر مهمة واحد تحذير إبلاغ حالة كل سوف طلب قيام أي إعادة وصل؛ لا يوجد أي معلق توقف تفاعل سوف تغيير نص سجل. دواء حبة ظهور وقت باهت دخول، إزالة قبل باهت خروج 150ms، عرض درجة مع حالي label ذاتي ملائم ينبغي. هو يحتفظ جهة توفير مرئي صفة، استعادة إقامة إبقاء وقت، محلي تحويل label و قيام أي إعادة وصل عودة ضبط؛ هذا أصل لغة لا استخدام أصلي title tooltip.`useAnchoredPosition` و `useAnchoredMaxHeight` يجعل طفو حركة وجه لوح و قاع جزء مرساة تحديد طفو طبقة بداية نهاية ملقط صنع في نظر فتحة داخل و تتبع مع مرساة نقطة.`HoverCard` عبر إشارة إبرة مغادرة فتح عرض حد مدة يجعل اعتماد portal معاينة في عبر مرور مرساة نقطة بين فجوة وقت ما زال يمكن لمس و، و يمكن عبر `copyText` prop توفير نسخ حسب زر.`Toast` توقف إبقاء وقت طويل من استخدام جهة عبر `holdMs` إشارة تحديد، لأن أفقي عرض هذا إبقاء كثير دائم أخذ قرار في لديه كثير قليل محتوى يلزم قراءة؛ نفس عدد قيمة معا قيادة هو إزالة تحديد وقت جهاز و مثال صيغة جدول باهت خروج تأخير متأخر، اثنان من غير ممكن قدرة مجددا خطأ موضع.`rankByName` هو `/` قائمة مفرد أمر مصدر و skill(تقنية قدرة) مصدر مشترك مرشح ترتيب ترتيب جهاز: استعلام يجب هو اسم حرف لا منطقة قسم كبير صغير كتابة لديه ترتيب فرعي تسلسل؛ بادئة أمر في ترتيب الأكثر قبل، ذلك مرة حسب مقابل متساو قسم عدد، مجددا حسب مصدر ترتيب. `Menu.autoFocus` تجمع تركيز أول عدد تفعيل بند، دعم حمل فوق تحت جهة نحو مفتاح و Home/End تنقل، و في Escape وقت تجمع تركيز anchor داخل رقم واحد حسب زر؛ عملية قائمة مفرد يمكن صريح تفعيل.

### تصيير agent إخراج

الأكثر قريب `MarkdownDelegateProvider` توفير اختياري `openExternalLink` و `openFile` تنقل عودة ضبط. تضمين طقم Provider استبدال خارج طبقة قدرة، عودة ضبط تغير بلا حاجة إعادة بناء Markdown يكفي وصول قد تصيير رابط. ذلك `openFile` جعل محلي Markdown رابط في سقوط تحديد بعد يمكن نقر. قطعا مقابل مسار و مساحة العمل متبادل مقابل مسار دعم حمل مئة قسم رقم تحويل معنى و `#L24` / `#L24-L30` قطعة مقطع؛ نطاق تحديد موضع إلى بدء بداية سطر. ملف اسم في حرف وجه `?` و `#` يجب مئة قسم رقم تحرير رمز. معلق توقف تلميح استخدام حل رمز بعد مسار، و في وسم لـ فارغ وقت توفير يمكن وصول اسم. عودة ضبط استقبال حل رمز بعد مسار و اختياري سطر رقم، مصير إبقاء وسم و عرض ملف رسم علامة. لا نقل عودة ضبط وقت، محلي رابط ما زال لـ نص.URL بروتوكول، استعلام سلسلة، لا دعم حمل قطعة مقطع و صيغة خطأ هدف لن نقل إعطاء ملف فتح جهاز.

`MarkdownText` تصيير غير ممكن معلومة GFM و TeX عام صيغة، منع توقف لا أمان رابط و صورة، و يمكن يأخذ قد تحليل ملف رفع و تحويل لـ صريح تحكم عنصر. خارج طبقة `MarkdownDelegateProvider` سوف استقبال عادي نقر إنتاج قد صاف تحويل HTTP(S) URL؛ حمل إصلاح زينة مفتاح نقر و Provider خارج رابط إبقاء أصلي خارجي anchor سلوك. عند owner نقل دخول `pathImages` كلمة جدول وقت، محلي وسيط جسم مسار صورة هدف فقط في سقوط تحديد تصيير مرحلة مقطع إعادة كتابة لـ يمكن عرض URL(و file mentions نفسه تدفق صيغة باب) ؛ لا نقل كلمة جدول وقت محلي هدف إبقاء كسول صفة alt نص. تحميل أو حل رمز فشل بعد، صورة استبدال لـ عمل من alt نص؛alt لـ فارغ وقت عرض أصلي هدف مسار. صورة مصدر تغير بعد يمكن إعادة تحميل. عودة تكرار تدفق صيغة إخراج وقت، هو تجميد ربط قد إتمام كتلة، حسب قد إتمام سطر دفع دخول قمة طبقة لم إغلاق دمج fence، و من حفظ Shiki grammar state لـ هذا fence زيادة كمية عال مضيء. قد إتمام token سطر دخول ثابت كبير صغير React قسم مجموعة، لاحق قسم قطعة فقط reconcile صحيح في زيادة طويل قسم مجموعة؛ نهائي كل كمية تحليل حل قرار عبر وثيقة لغة قاعدة وقت، لم تغير fence سوف إبقاء هذا DOM.`TerminalBlock`،`ReadBlock`،`DiffBlock`،`SearchBlock` و `WebBlock` يأخذ مقابل أداة نتيجة معنى رسم تصيير لـ حمل نسخ تحكم عنصر، فيض خروج معالجة و ملائم استخدام وقت ANSI معالجة بطاقة.`JsonTree` و `JsonBlock` بـ فقط قراءة طريقة فحص JSON قيمة؛`projectUserText` يأخذ قد إرسال مستخدم نص إسقاط لـ سطر داخل عادي نص مقطع و مرجع chip، توفير رسالة هواء فقاعة و ترتيب طابور سطر استخدام. نقل دخول `UserTextReferences` وقت، ملف و skill مرجع يصبح دعم حمل مفتاح قرص عملية معاينة حسب زر، إعادة استخدام متن ملف رابط معلق توقف و تجمع تركيز مثال صيغة؛ رقم مرة إشارة إبرة نقر يمكن فتح معاينة، لاحق نقر و قد لديه اختيار منطقة إبقاء أصلي اختيار سلوك. مفتاح قرص تنشيط في وجود اختيار منطقة وقت ما زال يمكن فتح معاينة.

`MarkdownText` افتراضي لـ `variant="body"`. مرة درجة محتوى استخدام `variant="compact"`: ذلك 13px حرف رقم و 20px سطر عال تتبع مع محتوى حرف رقم ضبط، كل درجة عنوان إبقاء نفس حرف رقم و استخدام 600 حرف إعادة، مقطع سقوط و قائمة اعتماد أكثر ضيق تجميع بين مسافة. متن، رابط و شفرة متساو إبقاء tertiary لون لون، بـ نقطة حالة تحت تخطيط خط منطقة قسم رابط. شفرة عنوان شريط مع شفرة كتلة تمرير. جدول إطار و عام صيغة ما زال تفعيل، استخدام دورة محيط نص حرف حرف رقم، و في متاح عرض درجة داخل أفقي نحو تمرير. اثنان عدد تغيير جسم مشترك محلل و تدفق صيغة ذاكرة مؤقتة.

`DiffBlock` حسب سطر مقارنة مقارنة جديد قديم محتوى. هو عرض فعلي زيادة حذف سطر و اثنان جانب الأكثر كثير ثلاثة سطر في صفة سياق، استخدام `⋯` قسم فصل بعيد مسافة مغادرة تعديل، ملخص و قاع جزء موحد حساب كل لا حساب دخول مشترك سياق. إذا واحد قطعة مقطع حاجة تجاوز مرور 256 مرة سطر إضافة جديدة أو حذف، فإن إيقاف دقيق مقارنة مقارنة؛ هذا قطعة مقطع حسب كامل جديد قديم محتوى عرض و موحد حساب لـ خشن حبة درجة استبدال، يتضمن مشترك سطر. نسخ يتضمن كامل عرض diff و ذلك بادئة. نهاية ذيل تبديل سطر نظر لـ سطر إنهاء رمز؛ فقط نهاية ذيل تبديل سطر مختلف لن عرض لـ تعديل.

`JsonTree` يأخذ طي نص حد لـ `collapsedStringLines` سطر (افتراضي ثلاثة سطر). توسيع بعد عرض أصلي نص، إبقاء نفس درجة فاصلة رقم، و حد في نافذة و خارج طبقة تمرير حاوية داخل؛ مقياس قياس تغير و أصل أولا تمرير حدث سوف تحديث هذا حد. سطر نسخ عكس تغذية مستقل في JSON قيمة تصيير تحديث؛ بعد لم إتمام قص لصق لوح كتابة لن تحديث آخر سطر أو قد إزالة شجرة.

### محلي تحويل نص سجل

هذه أصل فرعي مكون لا يمكن قراءة تطبيق locale، لذلك كل مقطع موجه إلى مستخدم نص سجل كل يجب عبر label prop توفير.`HoverCard`،`TerminalBlock`،`JsonTree`،`CodeBlock`،`MarkdownText`،`JsonBlock`،`ConnectionIndicator`،`Modal`،`DiffBlock`،`ReadBlock`،`SearchBlock` و `WebBlock` استقبال كامل محلي تحويل label. هذه الحزمة لا يملك لغة رجوع؛ متروك تسرب سوف توجيه يؤدي نوع فحص فشل، كل وظيفة سوف يأخذ حمل نوع `t` مقعد موضع خريطة إلى primitive label واجهة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أصل فرعي مكون في حافة حافة حال حال تحت سلوك؛ هو جمع هو حالي حزمة قيد، لا هو مكون مسار خط رسم.

- **Diff بحث لديه حد أعلى، إدخال معالجة ما زال لـ خط صفة**: تحرير مسافة مغادرة حد أعلى جعل كبير كمية تعديل قطعة مقطع اعتماد خشن حبة درجة استبدال، لم يعد دقيق مقابل متساو. مواصفة تحويل، رجوع سطر و نسخ محتوى ما زال مع إدخال كبير صغير زيادة طويل؛ عال درجة حد فقط قيد مرئي سطر عدد، لا حد هذه قسم إعداد.
- **معروف محطة نقطة علامة هو ثابت قائمة**: فقط لديه صف اسم رئيسي آلة تحليل لـ ذاتي ذات علامة، ذلك بقية خارجي رئيسي آلة ما زال استخدام أرض كرة؛ يلزم تعرف آخر مهمة معنى محطة نقطة حاجة عبر شبكة شبكة إمساك أخذ هو رسم علامة.
- **تدفق صيغة خلال عبر حد مرجع تحليل يتم دفع متأخر**: تعريف سقوط في زيادة كمية تجميد ربط حد آخر جانب مرجع صيغة رابط أو قدم ملاحظة، في عودة تكرار تدفق صيغة إخراج خلال تصيير لـ حرف وجه نص؛ تحديد مسودة وقت كل كمية تحليل سوف سوف ذلك تحليل.
- **طويل عال مضيء fence سوف إبقاء كامل token DOM**: تدفق صيغة مسار تجنب تجنب إعادة تحليل، إعادة tokenize و reconcile قد إتمام بادئة، لكن لن إسقاط قديم لون لون أو وهمي محاكاة تحويل token span. لذلك نهائي DOM عدد كمية ما زال مع fence token عدد زيادة طويل؛ تضمين طقم/حاوية داخل fence و مرض حالة مفرد عدد تجاوز طويل سطر ما زال مشي عام ذيل جزء مسار.
- **حرف شكل درجة رسم علامة هو إعادة رسم صنع قريب يشبه إصدار**: سمك شكل علامة سجل و وميض ضوء علامة قدوم ذاتي حرف جسم حرف شكل، بينما محلي تصميم بيانات لا يمكن توجيه خروج ذلك سهم كمية بضعة أي؛ في نيل نيل دقيق توجيه خروج مسار قبل، استخدام يد عمل إعادة بناء إصدار بديل بديل.
- **`Pill` و `Input` لا يوجد تصميم مصدر**: اثنان عدد أصل فرعي مكون متساو ذاتي سطر تعريف؛ و ذلك متبادل يشبه جانب حافة شريط بحث حقل و عرض وسم بند من مستهلك تركيب، لا هو هذه أصل فرعي مكون.
- **`StateDot` لا يوجد `Active` تغيير جسم**: دعم حمل حالة لـ done،warning،ongoing،error و idle.
- **موجه إلى مستخدم نص سجل يجب من تصيير نقطة توفير**: هذه أصل فرعي مكون هو zero-Cordis ، أخذ لا إلى `ctx.locale`؛ كل وظيفة يجب عبر أصل فرعي مكون حمل نوع prop توفير كامل محلي تحويل label(رؤية[قرار](../../../.agents/notes/implemented/architecture/2026-08-23-locale-owned-client-ui-copy.zh.md)).
- **`TerminalBlock` لا هو طرفية نموذج محاكاة جهاز**: هو تصيير قد انتهاء أو ما زال في تشغيل أمر إخراج، بينما لا هو تفاعل صيغة جلسة:SGR لون لون، عودة عربة، تراجع إطار، سطر داخل مسح حذف، صنع جدول موضع و محرف عرض درجة سوف يتم التزام دوران؛ قطعا مقابل ضوء علامة تحديد موضع، صاف شاشة و تجهيز استخدام شاشة ستار تسلسل سوف يتم تقشير مغادرة.
