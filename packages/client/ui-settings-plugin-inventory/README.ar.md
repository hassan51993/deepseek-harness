# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | العربية

## عام وصف

**إضافة قائمة**وسم صفحة يجعل Web مستخدم عرض إضافة، بينما لا تغيير ذلك إعداد. هو أولا صف agent(ذكي جسم) مسبق ضبط قسم مجموعة، مجددا صف عام بيان؛ اثنان عدد قسم مجموعة افتراضي كل طي، حسب يحتاج توسيع، بحث خلال إبقاء توسيع. بطاقة إبقاء حزمة اسم بصفة رئيسي عنوان، بـ مستقر بند id معرف نسخة، و عرض بدء توقف حالة، خروج موضع، تشغيل حالة، منع استخدام شرط و اكتشاف فشل؛ من مسبق ضبط توفير عام بند سوف صف خروج مقابل مسبق ضبط. بحث تغطية اثنان عدد قسم مجموعة، و إشارة خروج أخرى مسبق ضبط في مطابقة. وسم صفحة معالجة تحميل، فارغ نتيجة، بلا مطابقة، فشل و إعادة محاولة حالة، كما لا كشف نقل دقيق عقدة؛ لا يوجد مسبق ضبط roster وقت ما زال سوف عرض عام بيان.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

فتح ضبط في «إضافة» قسم منطقة و اختيار**إضافة قائمة**وسم صفحة، يكفي عرض مضيف إضافة بيان. إضافة تنشيط خلال لن قراءة Remote——أول مرة اختيار هذا وسم صفحة وقت عندئذ تركيب مكون، و عبر `api-remotes` كسول استدعاء `ctx.remote.pluginInventory.list()`.

تثبيت فشل كما وجود انتظار مراجعة دفعة pnpm بناء إذن وقت، صفحة توفير “سماح هذه نص برمجي و إعادة محاولة”. هذا عملية عرض دقيق تأكيد حزمة اسم و حمل دائم تخويل نطاق، مجددا استخدام أصل قدوم حزمة قاعدة إطار و تفعيل خيار إعادة محاولة. مرة نقر دفعة دقيق كامل قائمة، منها ممكن يشمل هذا قبل تثبيت إبقاء تحت انتظار مراجعة دفعة حزمة. إغلاق صفحة لن منح إعطاء إذن.

### قراءة قراءة بطاقة

كل ورقة طي بطاقة استخدام وحدة قصير اسم بصفة رئيسي عنوان، في تحت جهة عرض مستقر بند id، و بـ صغير وسم يمثل بدء توقف حالة؛ لون لون أصل fiber حالة دائرة نقطة فقط علامة وسم لا يمكن جدول بلوغ `pending`،`loading`،`unloading` مرحلة مقطع،`active` بند فقط عرض وسم. تركيب توليد مرة عنوان حذف فتح رأس `include:` علامة؛ معلق توقف، بحث، بلا عائق عائق اسم و توسيع تفصيل حال ما زال إبقاء كامل id. طويل بند id سوف في سطر داخل مقتطع، معلق توقف وقت ما زال يمكن عرض كامل قيمة. توسيع بطاقة بعد سوف عرض إعلان بند id، كامل وحدة معرف و حالة واقع: مسبق ضبط سطر شرح هو قدوم ذاتي أي عدد مسبق ضبط، تركيب تخزين نشط وقت تشغيل حالة، و هو يحمل منع استخدام شرط؛ يتم مسبق ضبط توفير عام سطر شرح هو من Agent مسبق ضبط حسب جلسة توفير، صف خروج تفعيل هو مسبق ضبط، و توفير قفز تحويل إلى مسبق ضبط مجموعة مدخل. مسبق ضبط اسم مرور مشترك `presetDisplayText` صاف دالة (`dsh-agent-presets/display`) تراكم في [`ui-agent-preset`](../ui-agent-preset/README.ar.md) حرف قاموس فوق تحليل: داخل وضع مسبق ضبط مشي حالي لغة، مستخدم ذاتي بناء مسبق ضبط إبقاء ذاتي ذات بيانات وصفية، لذلك إنجليزي نص واجهة لن عودة إظهار مسبق ضبط ملف داخل العربية اسم. بحث حسب وحدة اسم و بند id مرور ترشيح اثنان مجموعة.

### مسبق ضبط تبديل جهاز

تبديل جهاز و عام ضبط كل سطر استخدام نفس نوع «اختيار لاصق كيس + قائمة مفرد» تحكم عنصر. هو صف خروج roster كل مسبق ضبط——افتراضي بند حمل بعد لاحقة، تالف مسبق ضبط حمل علامة——و كما فقط تغيير قائمة عرض ماذا: هو لا كتابة أي ضبط، اختيار في تالف مسبق ضبط وقت في سطر موضع عرض discovery تقرير إبلاغ سبب. اختيار افتراضي مسبق ضبط أو جلسة مسبق ضبط مدخل ما زال في أصل موضع:Agent مسبق ضبط قسم منطقة و جلسة جديدة صفحة.

### إعادة محاولة فشل قراءة

قراءة فشل سوف في وسم صفحة داخل تصيير عام فشل حالة؛ إعادة محاولة سوف إعادة تنفيذ كسول `list()` استدعاء، كما لن كشف نقل دقيق عقدة.

إضافة قائمة أيضا عرض حالي صفحة تزامن فشل. إعادة محاولة سوف إعادة تطبيق الأكثر جديد عميل رسم، لا تغيير Host تفعيل حالة، أيضا لا تحديث جديد صفحة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا وسم صفحة هو مضيف يملك لقطة فقط قراءة إسقاط؛ إضافة تنشيط خلال لا تنفيذ أي Remote قراءة، أول مرة اختيار وقت عندئذ أخذ لقطة.

### تسجيل

متصفح إضافة تسجيل واحد id لـ `all` محلي تحويل `settings.plugins.tab` مساهمة؛ «إضافة» قسم منطقة يملك تنقل مدخل و وسم شريط. تسجيل استخدام `ctx.slots.inject()`، لذلك قدرة تتبع مع وسم slot تأخير متأخر إعلان، إعادة إعلان، محلي تحويل تغير و teardown، بينما بلا حاجة import قسم منطقة يملك جهة.

### تصيير

سطر key حسب أثر مجال حد تحديد (`global:`،`preset:<id>:<index>`) ، لذلك نفس وحدة ظهور في اثنان عدد أثر مجال وقت إبقاء كل منها توسيع حالة؛ إعلان بند id ظهور في توسيع تفصيل حال في، و في ذهاب إسقاط فتح رأس تركيب `include:` علامة بعد بصفة طي مرة عنوان، لا يوجد id سطر لا عرض مرة درجة وسم. مسبق ضبط توفير علامة في عميل دفع توجيه: واحد عام بند في عام يتم توقف استخدام، كما حتى قليل واحد مسبق ضبط سطر مقابل نفس وحدة معرف فعلي تفعيل وقت عندئذ يحمل هو، لذلك يتم كل مسبق ضبط صلة إسقاط (أو فقط شرط إعلان) وحدة إبقاء مفرد صاف قد توقف استخدام، بينما لا هو مبالغة كبير توفير علاقة.

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد تعريف بيان عرض جديد طازج درجة و لمس بلوغ نطاق؛ هو جمع هو حالي حزمة قيد.

- **كل مرة Settings تركيب أو إعادة محاولة فقط قراءة واحد نسخة لقطة**: وسم صفحة لا حجز قراءة Loader تغير، أيضا لن في إعادة وصل بعد تلقائي إعادة قراءة؛ تبديل وسم صفحة سوف إبقاء حالي لقطة، إعادة فتح Settings فإن سوف أخذ نيل جديد لقطة.
- **اثنان عدد مستو وجه كل فقط قراءة**: وسم صفحة عرض عام و مسبق ضبط بدء توقف حالة لكن كل لا تعديل؛ كتابة عودة ذاتي تعريف مسبق ضبط تركيب ملف بدء توقف تحكم عنصر هو لحظة معنى إبقاء عمل لاحق عمل.
