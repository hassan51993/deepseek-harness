# @deepseek-ai/dsh-client-ui-settings-models

[English](README.md) | العربية

## عام وصف

`dsh-client-ui-settings-models` هو dsh Web عميل Models ضبط صفحة: مستخدم يمكن إعداد API مفتاح (بـ فقط كتابة طريقة تخزين دخول profile اعتماد مرجع لـ تحت) ، تحرير كل مزود نموذج قائمة، و يد عمل إعلان ذاتي تعريف pi-ai توجيه؛ صفحة بـ مزود سطر عرض، مرة فقط توسيع واحد ورقة تحرير بطاقة. هذا صفحة يأخذ مزود دليل، ضبط وثيقة و اعتماد وصف دمج لـ واحد مشترك لقطة، لذلك سطر حالة في ثلاثة عدد جهة وجه بداية نهاية متسق. هو أيضا سوف حمل أول مرة تشغيل مستخدم مشي اثنان عدد لديه ترتيب نابض نافذة——إصدار تحويل داخل قياس إعلان، و حسب شرط عرض رسمي جهة DeepSeek اعتماد خطوة.

## استخدام هذه الحزمة

من ضبط تنقل فتح Models صفحة، يكفي يرى كل قد إعداد مزود كل لديه واحد سطر. ذلك إعداد مفتاح لم في أي موضع إعداد كامل قسم عقدة مزود سوف تصيير لـ ذلك توسيع ضبط بطاقة بينما غير واحد سطر، لكن فقط حد أول مرة تشغيل وضع حالة، كما فقط حمل متابعة إلى مستخدم إغلاق هذا بطاقة لـ توقف. كل واحد صنف بطاقة كل منها يحتفظ ذاتي ذات توسيع حالة، لذلك صلة إسقاط منها واحد ورقة أبدا سوف إسقاط آخر ورقة داخل مسودة مسودة.

وجود قد تخزين دليل خطأ مزود ما زال عرض تشخيص و تحرير، حذف مدخل. إضافة عملية فقط موجه إلى قد تسجيل settings نطاق الأسماء، لذلك غير ممكن استخدام نطاق الأسماء لن إبقاء تحت لا يمكن فتح تحرير جهاز حسب زر. حفظ يتم رفض وقت، تحرير جهاز إبقاء فتح و عرض Host تشخيص.

### API مفتاح

تحرير بطاقة فوق رئيسي حقل هو مفرد وحيد واحد **API مفتاح**إدخال إطار——صفحة من لا استفسار سؤال بيئة متغير اسم. مفتاح دخول مفتاح مرور `credentials.set` بـ**فقط كتابة**طريقة تخزين دخول profile مرجع لـ تحت،profile لا يوجد مرجع وقت سهل إرسال توليد `<ROUTE>_API_KEY`،pi-ai profile سوف يأخذ هذا مرة إرسال توليد سجل لـ `apiKeyEnv`، لذلك `settings.yaml` من لا يحمل مفتاح قيمة. لـ جديد pi-ai مزود إبقاء فارغ مفتاح سوف حفظ واحد لا حمل مرجع profile، من بينما إبقاء مزود أصلي إقرار إثبات (مثال مثل Bedrock اعتماد سلسلة أو Vertex ADC). فقط لديه تأكيد مرجع اعتماد قد إعداد وقت، سطر عندئذ سوف بـ أخضر لون فعلي قلب نقطة علامة عرض API مفتاح حالة؛ فقط لديه تأكيد أداة اسم مرجع ناقص وقت، عندئذ سوف بـ أحمر لون فعلي قلب نقطة علامة عرض.«تطبيق» نجاح بعد سوف إرسال خروج محلي بلا عائق عائق حالة رسالة، كما أبدا عودة إظهار أي آلة سري محتوى.

### تحرير مزود

طي «ذاتي تعريف ضبط» طي منطقة تحمل تحميل دقيق اختيار مقدار خارج حقل: اثنان عدد بيت عائلة كل لديه `baseURL`(deepseek احتلال موضع رمز عرض عام مشترك طرف نقطة) ، كل مهايئ ذاتي ذات نموذج دليل، و مهايئ لم توفير pi-ai توجيه**عرض اسم**و **API بروتوكول**.Profile `headers` ما زال هو `settings.yaml` أو Cordis إعداد في نشر إعداد،Models صفحة لا توفير تحرير جهاز.Provider ID إبقاء ثابت: هو هو settings مفتاح، أخرى كل namespace و كل واحد بند قد سجل جلسة مرجع اسم حرف، أيضا هو صفحة قراءة لا عودة، بسبب بينما نقل لا مشي اعتماد مرجع كلمة جاف. دفع إدارة انتظار درجة لحظة معنى لا في يمكن تحرير حقل لـ صف: هو هو حسب نموذج قدرة، مزود درجة تحكم عنصر فقط ممكن يتم ضبط صار بعض بعض نموذج سوف رفض قيمة. كل نموذج سطر يمكن تحرير `id`، اختياري عرض `name`، اختياري `contextWindow`/`maxTokens` و إدخال نوع؛ غير متصل نموذج حقل في تحرير بعد ما زال سوف إبقاء.

`llm-deepseek` DeepSeek بطاقة تحرير مشترك استخدام طرف نقطة، اعتماد و نموذج دليل، لا توفير بروتوكول اختيار جهاز.Cordis YAML اختيار Messages وقت، رسمي جهة طرف نقطة احتلال موضع رمز لـ `https://api.deepseek.com/anthropic`؛ حفظ بطاقة لن تعديل كتابة بروتوكول إعداد.

توسيع**ذاتي تعريف ضبط → نموذج خيار**تحرير نموذج. اثنان عدد مزود بيت عائلة مشترك استخدام نفسه نموذج سطر تخطيط، وسم و رسم علامة: سياق نافذة و الأكثر كبير إخراج token عدد قسم لـ اثنان صف،**إدخال نوع**وحيد احتلال تحت واحد سطر، توفير**نص**و**صورة**تكرار اختيار إطار. لم إعلان إدخال نوع نموذج سطر أولوية عرض قد تثبيت نموذج إدخال نوع، ذلك مرة هو مزود قيمة افتراضية، الأكثر بعد رجوع لـ نص. معروف pi-ai مزود سوف تحميل قد تثبيت دليل، لا نحو طرف نقطة إرسال طلب؛ فتح نموذج سطر لن كتابة تغطية قيمة. صريح إدخال اختيار أداة لديه أولوية حق، يشمل لـ نظر شعور نموذج ضبط فقط نص تغطية. تعديل تكرار اختيار إطار سوف حفظ الذي اختيار نوع، كما حتى قليل إبقاء واحد نوع.DeepSeek كتابة `inputModalities`،pi-ai كتابة `input`.DeepSeek إلغاء ربط اختيار صورة وقت، أيضا سوف إزالة `imagePixelBudget` و `imageMaxBytes`، لأن مهايئ في لا يوجد صورة إدخال وقت رفض هذه حد. في `settings.yaml` في صاف حذف إدخال حقل يمكن استعادة مهايئ وراثة؛**استعادة افتراضي نموذج**سوف إعادة وضع كامل نموذج دليل تغطية. فقط إعلان فوق تنقل نموذج فعلي قدرة كاف معالجة إدخال نوع.

### إضافة جديدة و حذف مزود

«إضافة جديدة» مسار هو واحد ورقة تحمل تحميل راحة نوم دليل مزود اختيار إطار بطاقة——عار تركيب `llm-pi-ai` في أي توجيه وجود قبل حينئذ قدرة توفير ذلك كامل قد تثبيت catalog.**إضافة ذاتي تعريف مزود**إعلان واحد بند pi-ai لا توفير توجيه؛ إنشاء بطاقة سوف بحث يلزم وحيد **Provider ID**، طرف نقطة، بروتوكول و حتى قليل واحد يمكن وحيد تعرف آخر نموذج، لأن لا يوجد شرق غرب قدرة لـ هو جمع التقاط قاع. طرف نقطة يجب هو يمكن تحليل HTTP أو HTTPS URL؛localhost،IPv4 و IPv6 حرف وجه عنوان و ذاتي تعريف طرف فتحة ما زال صالح. لغة قاعدة خطأ سوف في حقل موضع منع توقف استفسار سؤال و إنشاء، طلب فشل فإن متابعة بصفة مستقل مزود خطأ عرض.**نيل أخذ متاح نموذج**عبر `llm/discoverModels` Remote استعلام جدول مفرد عرض طرف نقطة، لذلك إضافة جديدة مزود مرة يكفي إتمام، بينما غير أولا حفظ مجددا إرجاع؛ عودة تكرار فتح هو يمكن بحث اختيار جهاز بينما غير مباشر كتابة، فقط لديه نقر**إضافة الذي اختيار**عندئذ سوف كتابة. كل اختيار في مرشح سوف في مزود عام نشر متبادل ينبغي معلومة وقت، يأخذ id، عرض اسم، سياق نافذة، الأكثر كبير إخراج token عدد و قد عام نشر إدخال نوع نسخ دخول يمكن تحرير سطر؛ قد وجود سطر إبقاء مستخدم ضبط كامل مرور قيمة. بحث سوف مطابقة نموذج id و اختياري عرض اسم، كما لن صاف حذف إخفاء بند ربط اختيار حالة.**كل اختيار**سوف إضافة دخول مرئي نتيجة، بينما**إلغاء كل اختيار**سوف صاف فارغ الكل ربط اختيار، بـ تجنب معنى خارج اعتماد إخفاء نتيجة. فقط لديه مستخدم طبقة مفرد وحيد يحمل بعض سطر وقت، هذا سطر عندئذ يمكن حذف (حذف سوف استعادة تركيب أساس خط) ، ذلك تأكيد محادثة إطار سوف إشارة اسم هذا مزود.

### أول مرة تشغيل نابض نافذة

إصدار تحويل إعلان خطوة إتمام بعد،DeepSeek خطوة من نفس نسخة دمج لقطة إسقاط أول مرة تشغيل حينئذ خيط حالة. مستخدم قد قدرة كاف وصول**أي**مزود كل سوف مباشر انتهاء هذا خطوة، لا فعل تصيير؛ فقط لديه لا يوجد أي مزود مستخدم عندئذ سوف يتم استفسار سؤال رسمي جهة DeepSeek مفتاح.«قليلا بعد إعداد» فقط إتمام هذا مرة تنسيق ضبط جهاز مرة تاريخ؛ مهايئ ناقص، توجيه لا نشط حركة، دمج فشل، فقط قراءة نشر أو قدرة غير ممكن استخدام وقت، هذا خطوة لا تصيير أي إتمام——Models ما زال هو تشخيص واجهة.

### توسيع slot

هذا قسم منطقة لـ مستودع خارج توزيع إضافة إعلان اثنان عدد مقعد موضع، نوع تعريف في [`src/client/slot-contract.ts`](src/client/slot-contract.ts) و من `./client` تصدير.`settings.models.provider-card`(keyed) تصيير في كل ورقة عرض دليل سطر بطاقة داخلي——قد حفظ سطر بطاقة، ذلك أول مرة تشغيل setup شكل، و «إضافة مزود» مسودة مسودة بطاقة——بـ `entryKey = settingsNs` توزيع،owner props يحمل هذا سطر `ConfigurableProviderView`، ذلك configured حالة و قد تأكيد api-key اعتماد حالة، لذلك بـ بعض مهايئ بيت عائلة namespace تسجيل مرة يكفي استلام إلى هذا بيت عائلة الكل بطاقة، يحتوي يد عمل إعلان توجيه؛ يد عمل إعلان مسودة مسودة بطاقة بعد بلا دليل سطر، حفظ قبل لا توزيع.`settings.models.footer`(list) تصيير في سطر قائمة و إضافة جديدة تحكم عنصر بعد. تسجيل جهة عبر `ctx.slots.inject` تنشيط، و بـ type-only import جذب دخول هذه الحزمة `/client` مدخل؛ لا يوجد تسجيل جهة وقت اثنان عدد مقعد موضع متساو لا تصيير أي محتوى.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

صفحة فقط يحتفظ انفصال حساس بعد وصف رمز، من لا يحتفظ كامل ضبط قسم منطقة: لذلك كل مرة تحرير كل بـ `settings.mutate` مسار عملية سقوط إلى قد تخزين قسم منطقة فوق——كل تعديل حقل مرة set، كل صاف حذف حقل مرة unset، حذف مزود سطر فإن مرة unset.

### تحقق

مفتاح دخول API مفتاح حسب ذلك ذاته حقل حكم تحديد: ذهاب حذف أول ذيل فارغ أبيض بعد يجب غير فارغ، كما كل محرف كل يجب هو يمكن ضرب طبع ASCII(`[\x21-\x7E]`) ، هذا صحيح هو HTTP رأس قيمة قدرة كاف يحمل محرف تجميع——و `@deepseek-ai/dsh-llm` في `normalizeApiKey` متبادل لـ مرآة مثل، هذا موضع تكرار لحظة هو لأن مصدر مستو وجه تفكيك قسم منع توقف استيراد هو. و لصق لصق `NAME=value` بيئة سطر متسق أو حزمة لف في مطابقة جذب رقم داخل قيمة، سوف بصفة نفس مثال صيغة فشل يتم رفض. فارغ id، تكرار id، فارغ صريح اسم و غير ممكن قراءة، غير صحيح عدد أو صغير عدد سعة كمية كل سوف في أي كتابة قبل فشل.DeepSeek `models` هو واحد حسب قيمة كامل جسم استبدال عدد مجموعة: تحرير جهاز أولا عرض وراثة صالح سطر، مباشر إلى رقم مرة نموذج تحرير يأخذ كامل عدد مجموعة شيء تحويل دخول مستخدم طبقة، إعادة وضع فإن إلغاء هذا تغطية.

### تزامن و اعتماد

كل مرة settings كتابة كل يحمل بطاقة حالي `revision`، لذلك قدوم ذاتي آخر عدد وسم صفحة أو خارجي `settings.yaml` تحرير تزامن كتابة سوف بـ `settings/conflict` يتم رفض.settings إيداع بعد، بطاقة سوف في تخزين اعتماد قبل قبول إرجاع انفصال حساس مستخدم فرعي شجرة و revision، لذلك فشل اعتماد مرحلة مقطع فقط إعادة محاولة هذا مرحلة مقطع. حذف فقط سوف في profile إشارة اسم هذا صفحة إرسال توليد `<ROUTE>_API_KEY` هدف وقت إزالة قد إعداد كما يمكن كتابة اعتماد، لكن بعد unset هذا profile؛ اثنان عدد عملية كل قوة انتظار. تحميل إتمام بعد، صفحة حجز قراءة تحويل إرسال `settings/document-updated`،`credentials/reference-updated` و `llm/adapters-updated` تابع رئيسي حدث، و محلي `connection/reset`، لذلك خارجي تحرير بلا حاجة جولة استفسار يكفي استلام جمع.

### جذب توجيه تنسيق ضبط جهاز

إعلان خطوة في `src/client/locales.ts` في يحتفظ دقيق نص سجل، و في `src/onboarding-copy.ts` في يحتفظ تأكيد إصدار؛ عودة حلقة وقت هو عبر قائم settings API مقارنة مقارنة و كتابة `ui-onboarding.welcomeNoticeVersion`، كما فقط لديه صريح نقر «متابعة» عندئذ سوف سجل حالي إصدار. غير عودة حلقة متصفح لا يمكن استخدام هذا عدد فقط حد مضيف namespace، لذلك تأكيد فقط إبقاء في عملية داخل، تحديث جديد بعد إعلان سوف مجددا مرة ظهور.DeepSeek خطوة موجه إلى `llm-deepseek` في `deepseek-official`، في مشترك جذب توجيه نموذج حالة إطار داخل بـ فقط اعتماد نمط تصيير قائم `ProviderEditor`؛`credentials.set` ما زال هو وحيد آلة سري كتابة، كما لا تغيير أي مزود ضبط.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد تعريف تحرير جهاز حقل تغطية نطاق و هذا صفحة لمس بلوغ نطاق؛ هو جمع هو حالي حزمة قيد، لا هو ضبط مسار خط رسم.

- **بطاقة فوق فقط لديه API مفتاح و دقيق اختيار طي حقل يمكن تحرير**: يد كتابة تحرير جهاز بـ schema عام حقل تغطية تبديل أخذ mockup تخطيط. إعادة محاولة سياسة، مهلة،DeepSeek نموذج شرح و أخرى دخول مرحلة حقل ما زال إبقاء في `settings.yaml` في؛ تحرير جهاز لم عرض قائم نموذج حقل سوف إعطاء بـ إبقاء.
- **اعتماد تنظيف نطاق لحظة معنى إبقاء ضيق ضيق**: حذف واحد سطر وقت، فقط عند ذلك مرجع و صفحة إرسال توليد `<ROUTE>_API_KEY` هدف تماما متسق، عندئذ سوف صاف حذف قد إعداد كما يمكن كتابة اعتماد. ذاتي تعريف مرجع، بيئة اعتماد و لا يمكن تعرف آخر هدف سوف إبقاء، لأن هذا سطر لا يمكن إثبات ذاتي ذات يملك هو جمع.
- **فقط لديه pi-ai توجيه يمكن يد عمل إعلان**: ذاتي تعريف مزود بطاقة كتابة `llm-pi-ai`——وحيد واحد ذلك profile وصف كامل مزود namespace.`llm-deepseek` توجيه هو تركيب وجه واقع، لا هو هذا صفحة قدرة إنشاء شرق غرب.
- **استفسار سؤال تغطية OpenAI توافق و Anthropic Messages طرف نقطة**:OpenAI بروتوكول قبول معيار `data` عدد مجموعة أو غني معلومة `models` كائن،Anthropic فإن استخدام أصلي نموذج قائمة توجيه؛ ذلك بقية بروتوكول سوف تقرير إبلاغ ذاتي ذات لا يمكن يتم استفسار سؤال، ذلك نموذج يحتاج يد عمل ملء كتابة.
- **لم إعلان تخزين نشط توجيه بلا موضع تصيير**: لم مرفق حمل يمكن إعداد مزود إعلان أي تسجيل توجيه لا يوجد settings عنوان؛ هو في كل اختيار جهاز في ما زال مرئي، لكن لن ظهور في هذا صفحة سطر داخل.
