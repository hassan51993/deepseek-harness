# @deepseek-ai/dsh-client-ui-permission-presets

[English](README.md) | العربية

## عام وصف

لـ حالي Web جلسة أو لم قدوم جلسة اختيار إذن مسبق ضبط. عام ضبط سطر فقط أكثر تعديل بعد إنشاء جلسة الذي استخدام قيمة افتراضية؛composer و `/permission` اختيار جهاز تبديل حالي جلسة. افتراضي Web توفير فقط يمكن عرض، مساحة العمل داخل تعديل و تماما إذن. صريح تحميل فعلي تحقق Auto integration بعد، حالي جلسة اختيار جهاز سوف زيادة حمل `EXP` علامة Auto review. عبر مرئي خيار اختيار تماما إذن أو Auto وقت، حاجة قسم آخر تأكيد مقابل ريح خطر؛ كامل `/permission <preset>` أمر مباشر تنفيذ. مضيف عبر Session إسقاط تأكيد كل مرة تغيير.

## استخدام هذه الحزمة

سوف هذا إضافة و settings،commands و conversation حزمة واحد نفس تركيب. عام ضبط نيل نيل لم قدوم قيمة افتراضية سطر؛composer نيل نيل `conversation.input.permission` تحكم عنصر، عار `/permission` فتح slash اختيار جهاز. حالي جلسة تحكم عنصر معا اشتراط Session إسقاط و كامل دليل لقطة. لا توفير إذن وظيفة تركيب إعداد حيث لا عام حالي جلسة تحكم عنصر، أيضا لا عام ضبط سطر.

### اختيار جهاز

اختيار في أي إيداع `/permission <preset>` أمر سطر. حمل مشاركة شكل صيغة (مباشر مفتاح دخول `/permission <preset>`) ما زال مباشر تبديل؛ تركيب زينة فقط استبدال عار استدعاء. داخل وضع وسم في إنجليزي نص واجهة في هو `Read Only`،`Workspace Write`،`Full access` و `Auto review`، في العربية واجهة في هو «فقط يمكن عرض»«مساحة العمل داخل تعديل»«تماما إذن» و `Auto review`. صريح host وسم إبقاء أصل مثال، لم معرفة kebab-case اسم تصيير لـ Title Case؛`auto` حمل لديه `EXP` badge، و في مرئي اختيار وقت اشتراط فعلي تحقق ريح خطر تأكيد.`custom` فقط هو عرض حالة، قطعا غير هدف.

فوري دليل سحب إلغاء بعض عدد مسبق ضبط وقت،composer إغلاق مقابل انتظار تأكيد محادثة إطار، و استخدام Session حالي قيمة بديل قد غير ممكن استخدام مرح مراقبة اختيار. كل مرة دليل بطلان (بلا payload إشعار أو اتصال بديل حد تغيير) سوف إغلاق قد فتح slash اختيار جهاز أو ذلك تأكيد محادثة إطار، لا إزالة استهلاك مسودة مسودة؛ بينما إصدار بعض عدد picker جارٍ انتظار قراءة نتيجة وقت، هذا picker إبقاء فتح و إبقاء فشل و إعادة محاولة حالة؛ إعادة فتح وقت قراءة حالي دليل. قد إيداع أمر في استجابة انتهاء قبل متابعة إبقاء مشغول مشغول حالة.

### ضبط سطر

هذا سطر من مضيف حركة حالة `defaultPreset` enum دفع توجيه خيار، استخدام و حالي جلسة اختيار جهاز نفسه محلي تحويل داخل وضع وسم، و كتابة واحد بند ضبط تغيير عملية.`auto` انتظار فقط حد حالي جلسة contribution لن ظهور. هذا قيمة فقط في بعد إنشاء جلسة وقت توليد فاعلية؛ تغيير هو أبدا سوف تبديل أو تعديل كتابة حالي جلسة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

General Settings سطر مرور `ctx.settingsScope` قراءة صريح كشف `permission` Settings وصف رمز، و يحمل وصف رمز revision كتابة واحد بند `settings.mutate` مسار عملية؛ ذلك observable مرور slot نظام `hooks` compartment نقل تمرير، لذلك React خطاف ربط عودة مصير، دفع إرسال بطلان إشعار سوف إعادة نيل أخذ وصف رمز. هذا قيمة فقط في بعد إنشاء جلسة وقت قراءة. حالي جلسة واجهة هو تعليق في مضيف `/permission` أمر فوق popupSelect تركيب زينة (`ctx.commandUi.decorate`): مضيف أمر إبقاء مائل عمود قائمة مفرد سطر، حمل مشاركة شكل صيغة و حمل دائم دورة الحياة تسجيل حساب، تركيب زينة فقط يأخذ عار استدعاء استبدال لـ اختيار جهاز. واحد عملية درجة دليل سوف في أول مرة Remote قراءة قبل حجز قراءة بلا payload دليل إشعار، و كما فقط إصدار حالي اتصال بديل حد في الأكثر جديد كامل نجاح نتيجة. فوز خروج قراءة فشل أو اتصال reset سوف صاف فارغ قديم لقطة:composer seat لذلك إخفاء، مباشر إلى لاحق قائم إطلاق إعادة محاولة، بينما slash اختيار جهاز إبقاء متاح و في نابض نافذة داخل عرض فشل و إعادة محاولة؛ قديم اتصال بديل حد و dispose بعد عندئذ إرجاع نتيجة سوف يتم تجاهل اختصار. هو عام مشترك observable هو `{ value }` و `invalidations`(كل مرة دليل إشعار أو اتصال بديل حد تغيير ضرب واحد نقطة) ؛ فشل فقط توفير أمر صيغة تحميل داخلي استخدام.slash popup و composer seat مشترك استخدام هذا نسخة دليل، بينما Session `permissions` إسقاط فقط توفير `currentValue`.Full access و Auto review كل منها يحمل محلي تحويل تأكيد نص سجل؛Auto أيضا يحمل من مشترك popup خارج قشرة تصيير badge.

<a id="model-experience"></a>
## تجربة النموذج

بين وصل أثر. هو اثنان عدد واجهة كتابة إذن واقع: ضبط سطر جعل لم قدوم جلسة حمل حال كل كمية قيمة دوران زر حدث بدء، بينما `/permission` اختيار جهاز إلحاق اختيار في حالي جلسة مسبق ضبط. صندوق رملي و مراجعة دفعة مستهلك كل منها تحليل ذاتي ذات دوران زر حدث؛ اختيار `auto` أيضا سوف تفعيل مضيف Auto integration مستقل تدريجي استدعاء reviewer.

#### KV Cache أثر

بلا مباشر بطلان؛ طلب بادئة تغير من دوران زر مستهلك ذاتي سطر تحمل تحمل.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد حالي إذن واجهة. هو جمع هو حالي حزمة قيد، لا هو عام سياسة مقابل مقارنة أو مهمة تراكم ضغط.

- **ضبط سطر فقط حد Web**——غير Web عميل ما زال يمكن مرور `/permission` تبديل حالي جلسة، لكن لن نيل نيل هذا بند متصفح مساهمة.
- **Auto review فقط حد حالي جلسة**——General Settings سطر متعمد حذف هو، كما فقط لديه عبر مرئي اختيار جهاز اختيار وقت عندئذ عرض فعلي تحقق تأكيد؛ صريح مفتاح دخول `/permission auto` قد بنية صار واضح نفس معنى.
- **مسبق ضبط وصف قدوم ذاتي مضيف**——محلي تحويل داخل وضع وسم جانب حافة ممكن عرض آخر نوع لغة تحرير كتابة وصف.
