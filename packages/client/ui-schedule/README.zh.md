# @deepseek-ai/dsh-client-ui-schedule

[English](README.md) | العربية

## عام وصف

هذه الحزمة في Web جلسة رأس جزء تصيير حالي جلسة نشط حركة Schedule رفع تنبيه فقط قراءة دليل. هو قراءة كامل `schedule` projection، لا إرسال RPC، أيضا لا تنفيذ mutation. متصفح إرسال توليد حالة، محلي وقت، متبادل مقابل وقت و ترتيب ترتيب، لا يأخذ هذه عرض قيمة إضافة دخول حمل دائم حالة. مع مرفق Web bundle افتراضي منع استخدام هذا إضافة، فقط لديه صريح Schedule overlay عندئذ سوف معا تفعيل Host Schedule خدمة و هذا عميل row.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في حاجة عرض رفع تنبيه Web جلسة بدء قبل تفعيل Schedule overlay:

```sh
dsh web --patch apps/cli/config/examples/schedule/cordis.yml
```

مع مرفق Web graph قد عبر disabled `ui-schedule` row تحليل `@deepseek-ai/dsh-client-ui-schedule`؛overlay سوف يأخذ هذا row و `@deepseek-ai/dsh-schedule` واحد بدء تفعيل. فقط لديه جلسة قد نجاح فتح كما projection حتى قليل يتضمن واحد بند نشط حركة سجل وقت، إطلاق جهاز عندئذ سوف ظهور. فتح دليل بعد، تجاوز مدة سطر في قبل، لم قدوم سطر مجددا حسب هدف وقت ترتيب ترتيب؛ تماما و صف وقت إبقاء projection إنشاء ترتيب.

### قراءة قراءة و إغلاق دليل

كل واحد سطر عرض يمكن كامل تبديل سطر نص التوجيه، مستقل «انتظار في» أو «قد تجاوز مدة» حالة، محلي تحويل «مفرد مرة» أو تكرار بين فصل يمكن كامل حذف الأكثر كبير كامل مفرد موضع، متصفح محلي هدف وقت، و حسب متصفح وقت ساعة إرسال توليد متبادل مقابل وقت. بين فصل أبدا ترك دخول، ثلاثة بند بيانات وصفية سوف حسب سطر تبديل سطر، لن قطع قص دمج قاعدة كبير عدد قيمة. عبر portal تعليق إلى body نابض طبقة هدف عرض درجة لـ 336px؛ فضاء كاف كاف وقت و إطلاق حسب زر يسار حافة حافة مقابل متساو، إطلاق جهاز اعتماد قريب نظر فتحة يمين جانب وقت نحو يسار تجنب يجعل و إبقاء 16px نظر فتحة حافة مسافة، الأكثر كبير عرض درجة لـ نظر فتحة عرض درجة نقص 32px. نابض طبقة سوف في حاجة وقت رأسي نحو تمرير، كما لا عرض Schedule id، أصلي UTC قيمة، تفصيل حال أو عملية تحكم عنصر.

فقط لديه أصلي إطلاق حسب زر دخول Tab ترتيب.Enter و Space استخدام حسب زر صحيح معتاد تنشيط سلوك؛ تركيز نقطة ما زال في إطلاق جهاز أو دليل داخل وقت،Escape سوف إغلاق نابض طبقة و يأخذ تركيز نقطة تسليم أيضا إطلاق جهاز؛ في خارجي حسب تحت إشارة إبرة أيضا سوف إغلاق. إذا live تحديث إزالة الأكثر بعد واحد بند سجل، مكون سوف إغلاق و إزالة، لكن لن يأخذ تركيز نقطة نقل إلى آخر عدد جلسة رأس جزء حركة عمل. جلسة فتح فشل وقت، أي جعل وجود مؤقت تحديد ذاكرة مؤقتة projection، أيضا سوف إخفاء إطلاق جهاز.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

متصفح إضافة بـ ترتيب 10 نحو `conversation.session.header.actions` مساهمة `schedule-catalog`، يقع في ساكن حالة agent(ذكي جسم) و subagent سياق بعد، خلفية مهمة قبل. هو عبر معيار جلسة خطاف قراءة `openState`، عبر `useProjection('schedule')` قراءة كامل قيمة؛ نابض طبقة فتح دمج هو هو وحيد محلي تفاعل حالة. مكون يأخذ دليل portal إلى `document.body`، و سوف إطلاق جهاز و وجه لوح ref تسليم إعطاء `useAnchoredPosition`؛ هذا hook في قياس كمية قد تصيير وجه لوح بعد إصدار fixed جلوس علامة، جعل وجه لوح يقع في إطلاق جهاز تحت جهة 5px، ملقط صنع في 16px نظر فتحة حافة مسافة داخل، و في resize، التقاط مرحلة مقطع scroll و وجه لوح resize وقت إعادة قياس كمية. دليل ref أيضا يجعل portal داخل إشارة إبرة حسب تحت متابعة يخص قائم dismissal حد لـ داخل. متصفح صيغة تحويل استخدام فحص نظر جهة locale، وقت منطقة و وقت ساعة، حمل دائم Schedule سجل إبقاء ثابت.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/client/index.ts`](src/client/index.ts) | متصفح مدخل: تسجيل locale و مساهمة جلسة رأس جزء slot |
| [`src/client/ScheduleCatalogAction.tsx`](src/client/ScheduleCatalogAction.tsx) | مرئي صفة، ترتيب ترتيب، صيغة تحويل، نابض طبقة و مفتاح قرص سلوك |
| [`src/client/locales.ts`](src/client/locales.ts) | في إنجليزي نص دليل نص سجل |

| — | لا إصدار وقت التشغيل ثابت كمية مرافق توليد مدخل؛ هذا عدد فقط قراءة عميل دليل لا يملك متغير عبر إضافة حالة. |

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد حد تحديد حالي Schedule دليل. هو جمع هو حالي حزمة قيد، لا هو رفع تنبيه خدمة مقابل مقارنة أو مهمة تراكم ضغط.

- **فقط يحتوي نشط حركة سجل**——نهاية ربط صفة delete و dispatch تحويل سوف إزالة مقابل سطر؛ عادي transcript(نص سجل) ما زال هو وحيد رفع تنبيه تسليم تاريخ.
- **متصفح إرسال توليد وقت**——محلي وقت و متبادل مقابل وقت وسم استخدام فحص نظر جهة متصفح حالي locale، وقت منطقة و وقت ساعة. هو جمع هو عرض قيمة، لا هو حمل دائم Schedule واقع.
- **فقط قراءة واجهة**——إنشاء و حذف رفع تنبيه ما زال من Schedule أداة مسؤول؛ دليل لا يوجد mutation،Retry،acknowledgement،Toast أو تسليم عودة تنفيذ دلالة.
- **اشتراط جلسة فتح نجاح**——فتح فشل وقت، أي جعل وجود مؤقت تحديد ذاكرة مؤقتة قيمة أيضا سوف إخفاء، لأن صارم إطار جلسة إعادة تشغيل ما زال هو مرجعي.
