# @deepseek-ai/dsh-client-resources

[English](README.md) | العربية

## عام وصف

عند مكون فقط معرفة طريق فوري بيانات URL عنوان، بينما بيانات من آخر عدد عميل حزمة يملك وقت، طلب استخدام عميل مورد؛ مثال مثل tab سجل، رابط أو رفع و. مورد عنوان استخدام `dsh-resource://<type>/…`؛ حاجة أثر مجال بروتوكول يأخذ أثر مجال تحرير دخول مسار. مكون عبر عام `useResource` خطاف استقبال حالي قيمة و لاحق تحديث. لا دعم حمل بروتوكول و غير مورد scheme(مثال مثل `sidebar://guide`) لا إشارة نحو أي مورد.

## استخدام هذه الحزمة

تركيب بلا حاجة أي إعداد: إضافة توفير `ctx.resources`، و عبر `ctx.slots.provideRoot` مساهمة `resource` أصل keyed خطاف، لذلك كل slot مكون لا نقاش أثر مجال كل قدرة استلام إلى هو.

<a id="read-a-resource"></a>
### قراءة مورد

كل slot مكون كل في props فوق استلام إلى `useResource`.`useResource<P>(address)` بـ نوع معامل تسمية بروتوكول، إرجاع `{ status, value, failure }`: عنوان بروتوكول لا يوجد مزود (أو عنوان لا هو `dsh-resource://` URL) وقت لـ `none`، مزود بعد لم إنتاج خروج قيمة وقت لـ `loading`،`live` يحمل الأكثر جديد واحد `ok` لقطة قيمة،`failed` يمثل الأكثر جديد واحد لقطة تقرير إبلاغ فشل، فشل وضع في الأكثر بعد واحد قيمة جانب. عبر خطاف حجز قراءة حينئذ هو تثبيت إقامة مورد طريقة؛ آخر عدد يحتفظ من يجعل مورد إبقاء تخزين نشط وقت، جديد تركيب مكون قيام لحظة قراءة إلى الأكثر جديد قيمة.

<a id="provide-a-protocol"></a>
### توفير بروتوكول

بروتوكول الذي تابع عميل حزمة في `ResourceProtocolMap` إعلان ذلك قيمة نوع، و بـ ذاتي لديه effect تسجيل واحد مزود.`open` إنتاج خروج `RemoteResult` لقطة: أولا هو حالي محتوى، بعد كل مرة تغير واحد لقطة، فشل بـ `ok: false` لقطة بينما غير رمي خطأ جدول بلوغ؛ يجب في `signal` في توقف وقت إيقاف:

```ts ignore-check
declare module '@deepseek-ai/dsh-client-ui-slots' {
  interface ResourceProtocolMap { note: NoteView }
}

export const inject = ['resources']

export function apply(ctx) {
  ctx.effect(() => ctx.resources.register<'note'>({
    protocol: 'note',
    async *open(address, { signal }) {
      yield await readNote(address, signal)
      for await (const change of followNote(address, signal)) yield change
    },
  }), 'my-notes: note resource provider')
}
```

واحد بروتوكول تماما لديه واحد مزود؛ ثاني مرة تسجيل سوف رمي خطأ. مزود تسجيل وقت إذا ذلك بروتوكول عنوان قد يتم يحتفظ، فإن قيام أي فتح تدفق؛ مزود dispose(مورد تحرير) وقت انتهاء هذه تدفق و يجعل هو جمع عودة إلى `none`.

<a id="hold-a-resource-open"></a>
### تثبيت إقامة مورد

`ctx.resources.pin(address, signal)` في لا حجز قراءة حال حال تحت يجعل مورد إبقاء فتح، مباشر إلى `signal` في توقف. يمين جانب Sidebar في tab سجل تخزين متابعة مدة داخل تثبيت إقامة كل قد فتح tab عنوان، لذلك تبديل tab إزالة متن لن إغلاق ذلك تدفق، قطع عودة وقت قراءة إلى الأكثر جديد قيمة.`ctx.resources.source(address)` هو خطاف خلف بعد عار observable، توفير React خارج استدعاء جهة استخدام.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<a id="lifecycle"></a>
### دورة الحياة

كل عنوان واحد بند سجل، يحتفظ واحد لقطة تخزين، واحد يحتفظ من حساب عدد (خطاف حجز قراءة من إضافة pin) و تشغيل في تدفق `AbortController`. رقم واحد يحتفظ من فتح مزود تدفق؛ بعد يحتفظ من مشترك هو؛ الأكثر بعد واحد يحتفظ من تحرير وقت في توقف تدفق و يأخذ لقطة إعادة وضع لـ فارغ خامل (لديه مزود لـ `loading`، لا يوجد لـ `none`). سجل في صفحة تخزين متابعة مدة داخل إبقاء، جعل `source()` في React من تصيير إلى حجز قراءة نافذة مدة و StrictMode إعادة تركيب خلال إبقاء مرجع مستقر.

<a id="failures"></a>
### فشل

فشل هو لقطة بينما غير رمي خطأ: مزود إنتاج خروج `{ ok: false, error }`، مورد تغيير لـ `failed` و يأخذ هذا خطأ وضع في الأكثر بعد واحد قيمة جانب؛ تحت واحد `ok` لقطة سوف ذلك صاف حذف. ذاتي سطر انتهاء تدفق إبقاء ذلك الأكثر بعد حالة. في في توقف تدفق ذلك مرة تحرير بعد وصول لقطة كل يتم إسقاط، و عودة أيضا مكرر. مزود تدفق داخل رمي خطأ هو تحرير مسار خطأ، لن يتم التقاط.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>

- **سجل في صفحة تخزين متابعة مدة داخل إبقاء**——عنوان سجل في الأكثر بعد واحد يحتفظ من مغادرة فتح بعد ما زال إبقاء في سجل التسجيل في، فقط إسقاط ذلك حالة. داخل تخزين مع قراءة مرور مختلف عنوان عدد زيادة طويل، بينما غير مع قراءة مرة عدد زيادة طويل.
- **في توقف دمج قاعدة من مزود مسؤول**——سجل التسجيل سوف إسقاط قد تحرير تدفق ما زال إنتاج خروج لقطة، لكن تجاهل اختصار `signal` مزود سوف واحد مباشر عمل إلى هو تحت واحد لقطة.
