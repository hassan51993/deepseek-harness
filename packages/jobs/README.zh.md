# jobs/: خلفية مهمة قدرة بيت عائلة

[English](README.md) | العربية

## عام وصف

jobs مجموعة هو خلفية عمل قدرة بيت عائلة: تشغيل طويل وقت عمل أداة يأخذ عمل تسجيل لـ مهمة، يملك هو agent(ذكي جسم) يمكن في لا منع سد ذاته جولة حال حال تحت قراءة، انتظار، صف خروج أو إلغاء مهمة. مهمة يخص بدء هو agent جلسة، لذلك واحد agent دائم بعيد لن يرى آخر عدد agent عمل؛ مهمة إتمام وقت بـ جلسة داخل إشعار إرسال بلوغ إعطاء يملك هو agent، بلا حاجة جولة استفسار. هذا مجموعة تفكيك قسم لـ سجل التسجيل اتفاق (`jobs`) ، ذلك عملية محلي تخزين (`jobs-local`) و حمل إتمام إشعار نموذج جانب تحكم أداة (`tool-jobs`).
