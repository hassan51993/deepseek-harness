# @deepseek-ai/dsh-jobs

[English](README.md) | العربية

## عام وصف

`dsh-jobs` يجعل أداة يمكن في agent(ذكي جسم) متابعة دفع دخول وقت إبقاء طويل وقت عمل تشغيل. كل بند مهمة كل سوف نيل نيل مستقر `<kind>-N` id، يملك هو agent يمكن قراءة إخراج، حمل مهلة انتظار أو طلب إلغاء. ملكية نطاق حد تحديد في agent جلسة داخل، لذلك أخرى agent لا يمكن عرض أو إيقاف مهمة؛ مهمة إتمام وقت سوف عبر جلسة داخل إشعار إرسال بلوغ، بلا حاجة جولة استفسار. فقط لديه نشر توفير مهمة تنفيذ قدرة وقت، خلفية مهمة عندئذ قدرة بدء.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

في تركيب خلفية مهمة قدرة أو تحرير كتابة تسجيل طويل وقت عمل إنتاج جهة وقت استخدام هذه الحزمة. هذه الحزمة ذاته تعريف اتفاق؛ تركيب عبر تحميل `dsh-jobs-local` هذا مثال تنفيذ، و نموذج جانب `dsh-tool-jobs`، نيل نيل هذا وظيفة.

### خلفية مهمة توفير ماذا

إنتاج جهة بـ kind و واحد سطر وسم تسجيل عمل؛ سجل التسجيل إرجاع `<kind>-N` id، مثال مثل `bash-1`. يملك مهمة أي واحد جهة كل يمكن قراءة إخراج، صف خروج مهمة، حمل مهلة انتظار تسوية أو طلب إلغاء——كل مرة استدعاء كل إرجاع مهمة حالة كل جديد لقطة، من `running`،`stopping` إلى إنهاء حالة `completed`،`killed` أو `failed`. مهمة تسوية وقت، يملك هو agent سوف عبر `dsh-tool-jobs` تحويل صار جلسة داخل إشعار إتمام مستمع نيل إلى إشعار، لذلك بلا حاجة جولة استفسار. إنتاج جهة أيضا يمكن مرفق إضافة اختياري بايت حد أعلى، يجعل كل مرة كامل نموذج جانب إخراج قراءة أو إتمام إشعار إبقاء محدود.

### ملكية حد

مهمة يخص بدء هو agent جلسة: أخرى agent لا يمكن قراءة أو إيقاف هو.`bash-1` هذا مثال id يمكن مسبق قياس، لذلك هذا طريق عزل هو تخويل، بينما غير حفظ سري. لا يوجد كل من بدء مهمة مقابل أي استدعاء جهة فتح وضع، و حمل متابعة إلى خدمة يتم تحرير لـ توقف.

### بدء خلفية عمل حاجة واحد تحكم جهاز

فقط لديه مرفق إضافة خدمة في كل من تحكم جهاز وقت، إنتاج جهة عندئذ قدرة بدء عمل——تحميل `dsh-tool-jobs` أي مرفق إضافة واحد. تركيب في لم تحميل أي تحكم جهاز agent لا يمكن بدء خلفية عمل؛`start()` سوف بـ إشارة خروج ناقص تحكم جهاز رسالة فشل، بينما لن بدء agent دائم بعيد لا يمكن استلام تجميع أو إيقاف عمل.

### الأكثر صغير متاح تركيب

```yaml
- name: '@deepseek-ai/dsh-jobs-local'
- name: '@deepseek-ai/dsh-tool-jobs'
```

في قد توفير agent، أداة و توجيه النظام خدمة harness أساس أساس فوق تحميل هذا اثنان عدد إضافة، يكفي نيل نيل كامل وظيفة:`dsh-jobs-local` توفير عملية داخل خلفية مهمة سجل التسجيل،`dsh-tool-jobs` توفير `job_output`،`job_list`،`job_kill` أداة و إتمام إشعار إلقاء تمرير.

### ممكن خروج ماذا مشكلة

أي مسبق فحص رفض كل لن إبقاء تحت job id أو قد تسجيل عمل. من مع مرفق عملية داخل سجل التسجيل إدارة مهمة سوف مع harness عملية إنهاء بينما إزالة فقد؛ عبر إعادة بدء حمل دائم تنفيذ حاجة واحد تنفيذ هذا اتفاق مختلف خلفية.

<a id="understand-the-implementation"></a>
## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير اتفاق خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **اتفاق و تنفيذ قسم تابع مختلف حزمة.** `JobRegistry` هو سحب كائن Cordis خدمة؛ مباشر تحميل هذا صنف سوف رمي خروج استثناء، لذلك خطأ إعداد تركيب سوف في تحميل وقت فشل، بينما لا هو تسجيل واحد فارغ `ctx.jobs`.
- **كل عملية واحد سجل التسجيل، حسب كل من إرجاع نتيجة.** واحد نسخة خدمة عملية داخل كل طقم تركيب، لذلك تسجيل و إلقاء تمرير كل متبادل مقابل تسجيل جهة الذي في scope: من لا حمل scope سياق تسجيل تحكم جهاز أو مستمع خدمة في كل كل من؛ في بعض طقم agent تركيب scope تحت تسجيل، تماما جيد خدمة في هذا تركيب تحت تركيب خروج agent.
- **وصول بـ كل من جلسة id لـ حد.** id يمكن مسبق قياس، لذلك هو تخويل——بينما غير حفظ سري——بنية صار حد.
- **تسوية أول مرة أولوية، إتمام الأكثر بعد إعلان نشر.** واحد بند إنهاء سجل، تحرير انتظار جهة، و واحد جولة تلقي إلى عزل مستمع إشعار؛ إتمام في سجل إيداع كما هذا تسوية كل أخرى مراقبة من كل قد يرى بعد عندئذ إعلان نشر، لأن تقرير إبلاغ جهة ممكن تزامن فتح بدء واحد نموذج جولة.
- **تسجيل تخزين متابعة مدة طويل في إنتاج جهة و تحكم جهاز fiber.** كل من و خدمة تحرير سوف إلغاء جارٍ تشغيل عمل و انتظار حراسة نحو إنتاج جهة؛ إلغاء تدمير خلال إلغاء إذا رمي خروج استثناء، فقط سوف سوف سجل قوي صنع علامة لـ فشل.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: سحب كائن `JobRegistry` خدمة و ذلك اتفاق |
| [`src/types.ts`](src/types.ts) | مشترك مفردات:`JobKindMap`،`JobStart`،`JobHooks`،`JobSnapshot`، مستمع نوع |
| [`src/brand.ts`](src/brand.ts) | `JobId` حمل نوع علامة معرف رمز، بلا حاجة agent اعتماد يكفي استيراد |
| [`src/invariant.ts`](src/invariant.ts) | ثابت صيغة مرافق توليد إضافة: تحقق لقطة معرف، حالة، ختم الوقت و كل من حقل |

### خدمة عملية

كل عملية كل هو قد تسجيل مهمة لـ فوق رقيق إسقاط:`get` و `list` إرجاع غير إزالة استهلاك صيغة لقطة،`read` دفع دخول وحيد تدفق تنقل علامة،`kill` في تغيير حالة قبل استدعاء إنتاج جهة إلغاء،`wait` الأكثر كثير منع سد حتى مهلة،`start()` في استدعاء إنتاج جهة `run()` مرة قبل مسبق فحص وصول، تحقق و دقيق دخول، معا رفض أي لا يوجد قد مرفق إضافة تحكم جهاز خدمة كل من؛ مستمع حسب كل من حبة درجة مراقبة إنهاء سجل و مرئي تجميع تغير،`attachController` يأخذ تحكم جهاز متاح صفة حد تحديد في ذلك effect دورة الحياة داخل. تأكيد قطع توقيع و سلوك رؤية [`src/index.ts`](src/index.ts) JSDoc و توليد [`ctx.jobs` Cordis واجهة وجه](../../../docs/subsystems/jobs.ar.md).

</details>

<a id="model-experience"></a>
## تجربة النموذج

عبر إنتاج جهة إضافة و تحكم جهاز إضافة بين وصل أثر نموذج؛ هو جمع مسؤول أساس في مهمة سجل التسجيل إتمام كل موجه إلى نموذج تصيير.

#### KV Cache أثر

لن مباشر توجيه يؤدي KV Cache بطلان؛ طلب بادئة تغيير من فوق وصف مستهلك مسؤول.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح اتفاق أي وقت لا دمج ملائم. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **اتفاق هو عملية داخل**——`JobStart.run()` نقل دخول عودة ضبط و تأكيد قطع `Agent` كائن؛ حفظ دائم أو عبر عملية خلفية يجب أولا إعادة تشكيل هوية، إعادة بدء، كل حق و مراقبة دلالة، عندئذ قدرة تنفيذ هذا seam.
- **تدفق إخراج فقط لديه واحد إزالة استهلاك تنقل علامة**——مستقل مراقبة من حاجة تنقل علامة أو لقطة API.
- **قبل منصة عمل لا يمكن تحويل لـ خلفية**——إنتاج جهة في بدء قبل اختيار قبل منصة أو خلفية.
