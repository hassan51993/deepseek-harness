# @deepseek-ai/dsh-plugin-package-inventory-deepseek

[English](README.md) | العربية

## عام وصف

لأجل DeepSeek رسمي جهة LLM API طلب كامل نشط وثب Loader إضافة حزمة بيان. هذا دالة إضافة حقن Loader، تخزين نشط Agent سجل التسجيل و `ctx.deepseekLlmApiExtensions`، و يملك `dsh_plugin_packages` حقل. عند رسمي جهة API حاجة نشط حركة حزمة بيان إجراء طلب تشخيص وقت، طلب تفعيل هو.

## إعداد

| إعداد مفتاح | قيمة افتراضية | يحتوي معنى |
|---|---:|---|
| `enabled` | `true` | تسجيل `dsh_plugin_packages` مساهمة. سوف ذلك ضبط لـ `false` يمكن حذف حزمة بيانات وصفية. |

مع مرفق profile استخدام هذا قيمة افتراضية، لذلك فقط يلزم دقيق تجهيز نجاح، كل DeepSeek رسمي جهة طلب كل سوف يحمل حزمة بيان.

<a id="collection"></a>
## استلام تجميع

كل مرة طلب كل سوف إعادة قراءة مضيف Loader شجرة في نشط وثب غير group بند إعداد. وجود اختياري `ctx.agentPresets` كما `sessionId` تحليل إلى قد إضافة دخول standing preset تخزين نشط Agent وقت، هذا preset مستقل Loader شجرة أيضا سوف إضافة دخول نفس مرة استلام تجميع؛ لم تركيب هذا خدمة نشر فقط تقرير إبلاغ مضيف شجرة. فقط لديه أصل fiber موضع في `ACTIVE` كما Loader صالح حالة لـ تفعيل بند إعداد عندئذ سوف قبول دخول.

إضافة في تنشيط وقت قراءة مرة اختياري `ctx.pluginPackages` خدمة. مع مرفق app boot سوف في profile Loader بند إعداد قبل تركيب هذا خدمة، لذلك عار حزمة و حزمة فرعي مسار هوية استخدام و ذلك import نفسه مرجعي generation، يشمل generation لم أمر في، و كما بلا حاجة حزمة تصدير `./package.json`. إذا هذا خدمة لا وجود، إضافة سوف في كامل دورة الحياة في إبقاء Node أصلي حزمة بحث، بعد مجددا تركيب resolver أيضا لن تبديل قائم بيان. لذلك، أمل نظر استخدام runtime generation هوية قاع طبقة تضمين دخول جهة يجب أولا تركيب `PluginPackages`، مجددا تركيب Loader بند إعداد و هذا إضافة.

كل عادي بند إعداد استخدام ذلك الذي تابع Loader شجرة أساس عنوان.standing preset أصل بند إعداد استخدام مضيف أساس عنوان، و preset Loader مقابل عار حزمة صريح تغطية كتابة إبقاء متسق؛ تضمين طقم include ما زال استخدام ذاته أساس عنوان. متبادل مقابل و قطعا مقابل وحدة سوف نحو فوق فحص بحث الأكثر قريب manifest(بيانات وصفية بيان) ؛ لا يوجد `name` manifest فقط علامة رخو تفرق وحدة، لا مساهمة حزمة هوية. أداة اسم حزمة manifest أيضا يجب إعلان غير فارغ `version`، صيغة خطأ حزمة بيانات وصفية سوف جعل طلب دقيق تجهيز فشل. نظام استخدام و locale غير متصل مقارنة مقارنة حسب تأكيد قطع اسم/إصدار مقابل ذهاب إعادة و ترتيب، معا تخزين نشط مختلف إصدار ما زال سوف قسم فتح إبقاء.

إصدار 1 `dsh_plugin_packages` حقل فقط يتضمن `{ name, version }` مقابل. نظام سوف ترتيب حذف منع استخدام،pending،failed،disposed،unloading حالة، بنية صفة `cordis:` بند إعداد، عادي اعتماد، لا يوجد الذي تابع حزمة هوية رخو تفرق ملف، بـ تحرير مسار طريقة تركيب فرعي fiber، و داخل تخزين حركة حالة إضافة.

<a id="model-experience"></a>
## تجربة النموذج

### حزمة بيان بيانات وصفية

#### نموذج يرى محتوى

بلا.`dsh_plugin_packages` هو يقع في نموذج رسالة، توجيه النظام و أداة schema خارج مزود بيانات وصفية.

#### Token أثر

نموذج إدخال token لـ صفر؛ كامل بيان فقط سوف زيادة HTTP طلب بايت عدد.

#### KV Cache أثر

بلا؛ حزمة دورة الحياة تغير لن تغيير نموذج مرئي بادئة.

## معروف حد و مؤقت مؤقت أمر بند

<a id="known-limitations-and-deferred-work"></a>

- **فقط يحتوي Loader حزمة مصدر**——بـ تحرير مسار طريقة إنشاء فرعي fiber و داخل تخزين حركة حالة إضافة لا يوجد مرجعي NPM اسم/إصدار مصدر، لذلك لا في هذا بيان داخل.
- **حذف رخو تفرق وحدة**——لا يوجد أداة اسم كما حمل إصدار الذي تابع manifest متبادل مقابل ملف هو إضافة وحدة، لا هو إضافة حزمة.
- **أصل أرض استبدال حزمة حاجة إعادة بدء**——manifest هوية سوف في عملية تخزين نشط مدة داخل ذاكرة مؤقتة.Loader تفعيل، منع استخدام، تركيب، إزالة و عادي شفرة المصدر HMR ما زال سوف تحديث جديد تخزين نشط بند إعداد تجميع دمج، لكن في نفس عملية في يأخذ قد تركيب حزمة manifest استبدال لـ آخر إصدار و لا هو تلقي دعم حمل ترقية مسار.
