# @deepseek-ai/dsh-llm-deepseek

[English](README.md) | العربية

## عام وصف

عبر `deepseek-official` تدفق صيغة استدعاء DeepSeek نموذج، افتراضي استخدام Messages، أيضا يمكن في Cordis YAML في اختيار Chat Completions. اثنان نوع بروتوكول مشترك استخدام اعتماد، طرف نقطة إعداد، صورة معالجة و نموذج دليل. صالح ضبط أكثر تعديل في لاحق طلب توليد فاعلية، إجراء في طلب إبقاء أصل إعداد.Web عرض واحد DeepSeek مزود، و توفير API عنوان و مفتاح تحرير. هذه الحزمة يمكن و [pi-ai مهايئ](../llm-pi-ai/README.ar.md) و استخدام.

## استخدام هذه الحزمة

عند تركيب حاجة عبر harness LLM(كبير لغة نموذج) خدمة تدفق صيغة استدعاء DeepSeek نموذج وقت تركيب هذا إضافة. هو تسجيل وحيد `deepseek-official` توجيه، و حسب طلب تحليل اتصال واقع، لذلك تركيب بند إضافة اختياري مستخدم ضبط قسم عقدة يكفي قيادة كامل مهايئ.

### أي وقت اختيار

موجه إلى DeepSeek رسمي جهة API، أو عبر `baseURL` اتصال دعم حمل الذي اختيار بروتوكول شبكة صلة وقت، اختيار هذا مهايئ. عند نفس تركيب أيضا يلزم عبر pi-ai دليل توجيه أخرى مزود أو يد عمل إعلان شبكة صلة وقت، اختيار `dsh-llm-pi-ai`؛ اثنان عدد مهايئ يمكن معا تركيب، لأن هو جمع توجيه اسم لا اندفاع مفاجئ. لـ `deepseek-official` تسجيل أي أخرى مهايئ سوف بـ `DUPLICATE_ADAPTER` فشل.

### الأكثر صغير إعداد

```yaml
- name: '@deepseek-ai/dsh-llm-deepseek'
  config:
    apiKeyEnv: DEEPSEEK_API_KEY  # credential reference, resolved per request
    reasoningEffort: high        # optional; off | low | high | max
    maxTokens: 256000            # optional per-request output cap
    maxRequestFilesBytes: 134217728
    maxInlineRequestImageBytes: 20971520
    maxImagesPerRequest: 600
    filesApiTimeoutMs: 60000
```

طلب استخدام `provider: deepseek-official` اختيار توجيه؛ نموذج id أصل مثال نقل إلى بروتوكول، لذلك إضافة جديدة DeepSeek نموذج بلا حاجة إعادة تسجيل. حذف `models` وقت عام نشر دعم حمل نص و رسم مثل `deepseek-flash`، و فقط دعم حمل نص `deepseek-v4-pro`، كل منها سياق نافذة متساو لـ 1,000,000 token. صريح قائمة سوف استبدال هذه قيمة افتراضية، لم صف خروج نموذج id ما زال بصفة صاف نص توجيه أصل مثال عبر. يشمل نموذج اكتشاف أداة في داخل عميل يمكن عبر `ctx.llm.listModels('deepseek-official')` قراءة هذه بناء اقتراح صفة بند. دعم حمل صورة بند يمكن يأخذ `imagePixelBudget` ضبط لـ صحيح كامل عدد أو `low`، أيضا يمكن ضبط `imageMaxBytes`. عند طرف نقطة يأخذ `messages` في مهمة معنى موضع الأكثر جديد `system` رسالة قراءة عمل كامل صالح توجيه النظام وقت، بند يمكن إعلان `systemPromptUpdate: in-history`؛ مهايئ سوف في قد تحليل نموذج و قد دقيق تجهيز استدعاء فوق تقرير إبلاغ هذا نمط،agent loop(ذكي جسم حلقة) مع بعد يأخذ تغير بعد نص التوجيه إلحاق إلى قد ذاكرة مؤقتة تاريخ بعد، بينما لا هو تعديل كتابة فتح رأس system رسالة ([قرار قاعدة](../../core/agent-loop/README.ar.md#understand-the-implementation)). افتراضي `deepseek-flash` بند إعلان هذا نمط؛ أخرى نموذج يحتاج عبر `models` صريح إعلان،`in-history` بـ خارج أي قيمة كل سوف في تحميل وقت بـ `llm-deepseek: catalog model "<id>" systemPromptUpdate must be "in-history" when present` فشل.

<a id="choose-a-protocol"></a>
### اختيار بروتوكول

عبر رقعة لـ قد لديه إضافة صريح اختيار Chat Completions:

```yaml
- id: llm-deepseek
  config:
    protocol: chat-completions
```

`protocol` افتراضي لـ `messages`، رسمي جهة أصل عنوان لـ `https://api.deepseek.com/anthropic`؛`chat-completions` استخدام `https://api.deepseek.com`. مع منتج تسليم رسمي جهة تركيب وراثة هذا قيمة افتراضية. اثنان نوع بروتوكول كل لا اشتراط ملء كتابة `baseURL`: عند `baseURL` و `$DEEPSEEK_BASE_URL` متساو لم ضبط وقت استخدام حالي بروتوكول رسمي جهة قيمة افتراضية. تبديل بروتوكول إبقاء قد لديه طرف نقطة تغطية، مستخدم حاجة ملء كتابة و اختيار تحديد بروتوكول توافق عنوان. صريح ملء كتابة `https://api.deepseek.com` هو Chat أصل عنوان: حذف هذا تغطية يكفي استخدام رسمي جهة Messages قيمة افتراضية، أيضا يمكن تعديل ملء `https://api.deepseek.com/anthropic`.Chat إلحاق `/chat/completions`.Messages و ذلك Files API فقط يأخذ نهاية ذيل صارم إطار مطابقة `/v1` مسار مقطع نظر لـ قد لديه Anthropic API إصدار، و إلحاق `/messages` أو `/files`؛ أخرى أساس عنوان متساو إلحاق `/v1/messages` أو `/v1/files`. لذلك، رسمي جهة Messages أصل عنوان ما زال استخدام دفع ترشيح `/anthropic/v1` طلب مسار، معا لا لـ مهمة معنى إصدار صيغة بعد لاحقة توفير توافق صفة. نهاية ذيل مائل خط لا تغيير هذه نتيجة. اثنان نوع بروتوكول مشترك استخدام `llm-deepseek` ضبط،`apiKeyEnv` و `deepseek-official`، لذلك قد حفظ نموذج اختيار ما زال صالح.

Messages بـ محتوى كتلة إرسال نص، تفكير اعتبار، استدعاء الأداة و أداة نتيجة، بـ `output_config.effort` إرسال دفع إدارة قوي درجة، و بـ Files مرجع أو داخل ربط base64 إرسال صورة. إعلان `systemPromptUpdate: in-history` نموذج إبقاء ابتدائي قمة طبقة system، في مقابل user/tool-result جولة بعد إرسال جديد system لقطة؛ لم إعلان قدرة وقت، استخدام الأكثر جديد لقطة بصفة قمة طبقة system. إعادة تشغيل بيانات وصفية سجل Messages صيغة، نموذج و توقيع؛Chat طلب فقط تسلسل تحويل حفظ دائم محتوى، لا إرسال هذه توقيع. بلا فاعلية Messages إعادة تشغيل بيانات وصفية إنتاج تحذير إبلاغ و حذف توقيع، لا إسقاط نص أو أداة تاريخ.

### حمل thinking و صورة تدفق صيغة استدعاء

دعم حمل صورة توجيه لـ كل حمل دائم مرجع اختيار تحديد طلب هدف، مجددا يأخذ هو تحليل لـ تحديد صفة طلب إصدار. حذف `imagePixelBudget` وقت حسب رسمي جهة عام نشر نظر شعور token شبكة إطار تحديد هدف، أي 14 px patch،3:1 خفض أخذ مثال، مفرد رسم الأكثر كثير 1024 token، لذلك صحيح جهة شكل صورة الأكثر كثير إبقاء 1302×1302 مثل عنصر،16:9 صورة بـ 1708×961 إرسال، مقابل مزود 1708×966 شبكة إطار؛ صحيح كامل عدد سوف استخدام مجموع مثل عنصر ميزانية يحل محل شبكة إطار،`low` استخدام مجموع حساب 512×512 مثل عنصر. كل ورقة طلب صورة مفرد حافة الأكثر كثير 4096 مثل عنصر، هذا هو مزود مقابل يتضمن 15 ورقة و بـ فوق صورة طلب حد؛`imageMaxBytes` افتراضي لـ 2 MiB. حمل alpha صورة استخدام effort 0 WebP، لا نفاذ واضح صورة استخدام JPEG، و اعتماد 85/75/60 جودة كمية مرحلة سلم؛ الكل مرشح كل تجاوز مرور هدف وقت إبقاء الأكثر صغير إخراج. كل ورقة إبقاء صورة قبل كل لديه نص، ملاحظة واضح كامل مرفق عنصر id و فعلي طلب مقياس قياس. حالي نظام الملفات يمكن خريطة مرفق عنصر مزود مضيف كائن وقت، هذا نص أيضا يحمل فقط قراءة تنفيذ عالم حد مسار و يمكن كتابة فرعي هذا استخدام توسيع اسم. صاف نص و لم صف خروج توجيه استقبال مستقر مرفق عنصر احتلال موضع رمز، بينما حمل دائم تاريخ متابعة إبقاء صورة مرجع.

اثنان نوع بروتوكول عبر معتاد عبر كل منها DeepSeek Files طرف نقطة فوق نقل هذه تأكيد قطع طلب بايت، تزامن إرسال file-id مرجع.Messages في إعداد أساس عنوان تحت استخدام `/v1/files`،Files طلب و يتضمن file id Messages طلب متساو يحمل `anthropic-beta: files-api-2025-04-14`؛Chat استخدام `/files`.Messages نموذج طلب و كل Files طلب رفض إعادة تحديد نحو، تأكيد حفظ اعتماد فقط إرسال إلى إعداد مصدر. ملف تحليل فشل أو مهلة سوف حسب داخل ربط ميزانية، استخدام داخل ربط base64 إعادة بناء كامل نسخة نموذج طلب؛ مرة طلب أبدا خلط استخدام file id و داخل ربط صورة. استدعاء جهة إلغاء سوف إيقاف طلب.

ذاكرة مؤقتة id حسب طرف نقطة و API key حد تحديد أثر مجال، في إلى مدة قبل تحديث جديد، أصل حسب مزود قديم قديم ملف خطأ بطلان، و عبر حمل انتظار جهة نطاق جزء إلغاء singleflight تحليل. اثنان نوع فوق نقل كل عبر `expires_after[anchor]=created_at` و `expires_after[seconds]` طلب مرور مدة.Messages ملف بيانات وصفية لا يحتوي بعيد طرف مرور مدة وقت، لذلك محلي إعادة استخدام مدة حد استخدام أصلي فوق نقل وقت إضافة `fileExpiresAfterSeconds`؛ هذا لا حفظ إثبات بعيد طرف ملف حذف. إعداد مقدار فشل سوف أولا حذف واحد دفعة إعداد عدد كمية الأكثر قديم harness ملف، مجددا إعادة محاولة مرة فوق نقل.

Files نمط عبر `maxRequestFilesBytes` و `maxImagesPerRequest` حد إبقاء طلب إصدار؛ داخل ربط رجوع لديه مستقل base64 ميزانية. اثنان نوع نمط كل حسب إعداد بايت أو عدد كمية كمية فرعي إزالة الأكثر قديم بادئة. كل ورقة حذف صورة كل لديه ذاتي ذات نموذج مرئي احتلال موضع رمز، يتضمن عرض اسم أو مرفق عنصر id، و متاح وقت مواصفة تحويل مقياس قياس، وسيط جسم نوع و حالي فقط قراءة مسار. قسم مرحلة عال ماء موضع سياسة تجنب تجنب كل إضافة جديدة واحد ورقة صورة كل تعديل كتابة قديم طلب بادئة.

`reasoningEffort` اختيار عام نشر قيمة افتراضية. عند نشر سياسة سماح thinking وقت، تأكيد قطع نموذج بيانات وصفية سوف حسب ترتيب عام `off`،`low`،`high` و `max` قوي درجة و اختيار إشارة جذب.`low`،`high` و `max` تفعيل thinking، في Chat Completions في بـ `reasoning_effort` تسلسل تحويل، في Messages في بـ `output_config.effort` تسلسل تحويل، مهايئ ذاتي لديه `off` فإن إرسال `thinking.type: disabled`. لا دعم حمل أخذ قيمة سوف في شبكة I/O قبل بـ `UNSUPPORTED_REASONING_EFFORT` فشل؛`thinking: disabled` سوف في إضافة تحميل وقت رفض أي غير `off` قوي درجة.`purpose: 'session-title'` طلب سوف قوي صنع إغلاق thinking، يأخذ محدود إخراج إبقاء إعطاء مرئي عنوان نص. اثنان نوع بروتوكول كل تحويل إرسال صريح `temperature`؛DeepSeek في تفعيل thinking وقت قبول هذا معامل، لكن تجاهل اختصار ذلك قيمة.

### حركة حالة إعداد

اتصال واقع عبر اختياري settings و اعتماد seam كل مرة عملية إعادة قراءة مرة. مستخدم ضبط وثيقة في `llm-deepseek:` قسم عقدة بلا حاجة إعادة بدء يكفي تغطية أي حقل؛ مخالفة عكس schema خارج قيد لقطة سوف إبقاء الأكثر بعد صالح واقع و سجل فشل.API مفتاح من توفير طرف نقطة، صورة و Files سياسة و فارغ خامل ميزانية نفس لقطة حسب تدفق استدعاء تحليل، لذلك يتم رفض ضبط بديل حد لن مساهمة منها أي واقع. صورة طلب في طلب وقت تحليل مرفق عنصر خدمة، لذلك تحميل ترتيب لن تجميد ربط صورة متاح صفة.

### مزود مخصص استخدام طلب حقل

اثنان نوع بروتوكول في، وجود `ctx.deepseekLlmApiExtensions` وقت، مهايئ كل سوف في `fetch` قبل أصل حسب تأكيد قطع تسلسل تحويل أساس أساس طلب دقيق تجهيز قد تسجيل قمة طبقة حقل. دقيق تجهيز أو حقل اندفاع مفاجئ في HTTP قبل فشل؛2xx استجابة بعد، مهايئ سوف في إزالة استهلاك SSE(Server-Sent Events) قبل قبول كل بند قد التقاط مساهمة. نقل و غير 2xx فشل لن قبول هو جمع. مع منتج تسليم تركيب استخدام هو توفير افتراضي تفعيل زيادة كمية `dsh_session_log` حقل و افتراضي تفعيل نشط وثب `dsh_plugin_packages` بيان؛ اثنان من كل إبقاء في نموذج إدخال خارج.

### فشل و استعادة

غير 2xx استجابة بـ مستقر code فشل:`AUTH`(401/403) ،`QUOTA`،`RATE_LIMIT`،`CONTEXT_WINDOW_EXCEEDED`،`INVALID_REQUEST`،`SERVER` و أخرى حال حال `HTTP_<status>`؛ استجابة قبل نقل فشل رمي خروج `TRANSPORT`، استدعاء جهة في توقف رمي خروج `ABORTED`، تدفق فارغ خامل مهلة رمي خروج `TIMEOUT`. طلب توسيع دقيق تجهيز، حقل اندفاع مفاجئ أو 2xx بعد قبول فشل استخدام `REQUEST_EXTENSION`. عند مزود لم إشارة خروج file id وقت، مواصفة تحويل صورة رفض سوف صف خروج كل ممكن مرفق عنصر و ذلك حمل دائم موضع. قديم قديم ملف رفض سوف جعل نقطة اسم خريطة (أو هذا مرة محاولة تجربة استخدام الكل خريطة) بطلان، و سماح مرة استبدال نموذج طلب. بروتوكول مخالفة قاعدة رمي خروج `STREAM_CLOSED` أو `MALFORMED_RESPONSE`؛ لا حمل محتوى كتلة إنهاء `stop` تغيير صار `EMPTY_RESPONSE`، افتراضي إعادة محاولة سياسة سوف إعادة محاولة هو. أي موضع كل لا يوجد مفتاح طلب بـ `MISSING_CREDENTIAL` فشل؛ صيغة خطأ اعتماد بـ `INVALID_CREDENTIAL` فشل، و نقطة اسم حاجة إصلاح مرجع——أبدا يتضمن مفتاح أي جزء.

<a id="model-experience"></a>
## تجربة النموذج

### DeepSeek طلب

#### نموذج يرى ماذا

الذي اختيار DeepSeek نموذج سوف استلام إلى harness توجيه النظام، رسالة تاريخ، أداة schema، إيقاف تسلسل و استدعاء إعداد (`maxTokens`،`reasoningEffort`،`temperature`) ، لا يتضمن مهايئ تأليف كتابة نص التوجيه تفرق نص. مزود مخصص استخدام طلب توسيع حقل إبقاء في نموذج إدخال خارج. نظر شعور نموذج عبر معتاد استقبال Files API مرجع شكل صيغة مستخدم و أداة نتيجة صورة، ذلك جانب حمل مرفق عنصر جملة مقبض و طلب معاينة مقياس قياس. حالي تنفيذ نظام الملفات يمكن خريطة مرفق عنصر مزود مضيف كائن وقت، هو أيضا سوف استلام إلى مواصفة تحويل كائن مسار؛ وصف رمز سوف يأخذ هذا فرعي هذا علامة لـ فقط قراءة، و تحذير إبلاغ مواصفة تحويل ممكن تقليص وضع أو إعادة تحرير رمز فوق نقل محتوى.Files تحليل فشل وقت، الكل إبقاء صورة تعديل استخدام داخل ربط base64؛ تجاوز خروج ميزانية مقارنة قديم صورة فإن في احتلال موضع نص في إبقاء حالي طلب قد تحليل وصول طريقة. هذا قبل assistant جولة دفع إدارة محتوى سوف أصل مثال نقل عودة، بلا نقاش هذا جولة هل استدعاء أداة. مقابل في غير قاعدة JSON أو غير كائن تاريخ أداة معامل،Messages إرسال `{}`. استدعاء ID، أداة اسم و نتيجة إبقاء ثابت، أصلي معامل ما زال إبقاء في Session سجل في. من Chat Completions تبديل بعد أيضا ملائم استخدام هذا ساكن صامت التقاط قاع. جديد توليد Messages أداة معامل ما زال يجب هو صالح JSON كائن.

#### Token أثر

مزود قسم كلمة قرار دقيق نص و صورة token إدخال. مهايئ إعلان حسب توجيه `imageRequestPricing`: يأخذ سجل في صورة حذف قرار اختيار في كل ظهور موضع حسب ذلك احتلال موضع نص حساب قيمة، و حسب إسقاط بعد مقياس قياس استخدام عام نظر شعور حساب كمية قاعدة (14 px patch شبكة إطار،3:1 خفض أخذ مثال،544×544 وضع كبير تحت حد، مفرد رسم 1024 token حد أعلى) لـ كل ورقة إبقاء صورة حساب قيمة. هذا جعل token حساب كمية خدمة يمكن في طلب إرسال خروج قبل لـ صورة ضغط قوة تحديد قيمة؛ فوق تقرير usage ما زال هو مرجعي قيمة. دفع إدارة عودة نقل سوف يأخذ كل دفع إدارة جولة تفكير صيانة سلسلة حمل دخول لاحق طلب، بينما قد حذف صورة لم يعد إزالة استهلاك نظر شعور token. إبقاء ظهور موضع حسب دقيق طلب إصدار بايت تجاوز مرور file نمط أو داخل ربط رجوع ميزانية (`maxRequestFilesBytes`،`maxImagesPerRequest` و اثنان عدد كمية فرعي) طلب، بـ `IMAGE_OFFLOAD_REQUIRED` فشل و شرح أيضا يحتاج حذف كثير قليل الأكثر قديم ظهور موضع، من `dsh-compaction-image-offload` استخدام `image/offload` حدث سجل الذي اختيار موضع و إعادة محاولة. متاح وقت تقرير إبلاغ ذاكرة مؤقتة قراءة استخدام كمية.Messages token مجموع عدد يتضمن لم ذاكرة مؤقتة إدخال، إخراج، ذاكرة مؤقتة قراءة و ذاكرة مؤقتة كتابة token.Chat Completions استخدام `prompt_tokens + completion_tokens`، مزود إعطاء خروج `total_tokens` لا متسق وقت حذف `totalTokens`.

#### KV Cache أثر

لم تغيير قد تجميع بادئة لديه مورد إطار نيل نيل DeepSeek ذاكرة مؤقتة إعادة استخدام، هذا مهايئ سوف في استخدام كمية في تقرير إبلاغ. تحديد صفة طلب صورة بايت و لا معنى طعم حال كامل بادئة ثابت ثابت: تنفيذ عالم حد مسار تغير سوف تعديل كتابة تاريخ وصف رمز نص، تحديث جديد فوق نقل سوف استبدال `file_id`،Files إلى base64 رجوع أيضا سوف تغيير صورة يمثل. هذه تغير و نموذج توجيه، نص التوجيه،schema، تاريخ أو صورة ميزانية تغير، كل ممكن من أول عدد تلقي أثر token بدء منع توقف إعادة استخدام؛ دفع إدارة عودة نقل في كل دفع إدارة جولة فوق إلحاق محتوى. في إعلان `systemPromptUpdate: in-history` دليل بند فوق، نفس طلب تسلسل تأخير متابعة خلال توجيه النظام تغير سوف إلحاق إلى قد ذاكرة مؤقتة تاريخ بعد، لذلك مباشر إلى هذا تاريخ نهاية ذيل بادئة ما زال يمكن إعادة استخدام؛ أداة schema تغير ما زال سوف من رقم واحد تغيير token بدء منع توقف إعادة استخدام.

### DeepSeek استجابة

#### نموذج يرى ماذا

دفع إدارة، نص و أصلي نص أداة معامل سوف يتم قلب ترجمة لـ harness قسم قطعة، توفير loop سجل و تجميع.

#### Token أثر

توليد token التزام دوران طلب في سجل دفع إدارة قوي درجة و `maxTokens`؛ فقط لديه loop إبقاء كتلة سوف أثر لاحق إدخال.

#### KV Cache أثر

loop إبقاء استجابة كتلة سوف إلحاق إلى تحت واحد طلب، و إبقاء ذلك أكثر مبكر يمكن إعادة استخدام بادئة؛ يتم إسقاط كتلة لم يعد لديه لاحق ذاكرة مؤقتة أثر. أكثر تبديل مزود أو نموذج سوف اختيار في مختلف ذاكرة مؤقتة مجال.

## حدود معروفة وعمل مؤجل

- Responses بروتوكول بعد لم تنفيذ، إعداد قيمة `responses` سوف يتم رفض.

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح مهايئ في أي داخل إيقاف، من لم قدوم عمل وصل متابعة. هو جمع هو حالي حزمة قيد، لا هو عام DeepSeek مقابل مقارنة أو مهمة تراكم ضغط.

- **ضبط في `models` قائمة سوف كامل جسم استبدال تركيب قائمة**——ضبط طبقة حسب حقل دمج، عدد مجموعة فقط حساب واحد حقل؛ حسب بند دمج دليل حاجة حمل مفتاح شكل حالة.
- **لا خريطة `tool_choice`**——لا يخص نواة قلب مفردات (و pi-ai توأم توليد مشترك).
- **طلب استخدام أصلي `fetch`، بينما غير `@cordisjs/plugin-http`**——لا يوجد مشترك بديل إدارة أو اعتراض قطع إعداد.
- **قفز مرور إضافة جديدة محتوى كتلة نوع**——نواة قلب نص و تلقي دعم حمل صورة كتلة سوف يتم تسلسل تحويل، فارغ أداة إخراج بـ حرف وجه كمية `(no output)` مرور خط.
- **صورة هو فقط لأجل إدخال حمل دائم مرفق عنصر**——لا دعم حمل مباشر خارجي URL و assistant صورة إخراج؛DeepSeek إدخال عبر معتاد استخدام Files API، فقط في مفرد مرة طلب استعادة وقت استخدام داخل ربط base64.
- افتراضي دليل مسبق تسجيل `deepseek-flash` و ذلك نص، صورة و تاريخ داخل تحديث قدرة، لا استكشاف قياس شبكة صلة متاح صفة. شبكة صلة فتح وضع هذا ID قبل، طلب ممكن بـ `INVALID_REQUEST` فشل. إعداد `DEEPSEEK_API_KEY` و دعم حمل هذا ID شبكة صلة بعد، ضبط `DEEPSEEK_FLASH_E2E=1` يمكن تفعيل[هذه الحزمة e2e اختبار ملف](tests/adapter.e2e.ts) في Chat Completions بروتوكول تحقق.
- [Messages system تحديث e2e](tests/messages/adapter.e2e.ts) اشتراط عبر `DEEPSEEK_IN_HISTORY_MODEL` إشارة تحديد دعم حمل هذا قدرة نموذج، مثال مثل `deepseek-flash`، و استخدام `high` تفكير اعتبار قوي درجة. هذا متغير لم ضبط أو لـ فارغ وقت قفز مرور؛ عادي `off` نص فحص ما زال في لديه اعتماد وقت تشغيل. إغلاق تفكير اعتبار وقت معروف إشارة أمر التزام دوران لا مستقر، جعل هذه system تحديث فحص لا ملائم دمج استخدام `off`.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو لا أداة مرجعي صفة عمل سياق: بعد لم قرار استكشاف جهة نحو و صيانة من ملاحظة. قد تسليم سلوك و حيث تحديد إدارة من بـ فوق نص، حزمة شفرة و متبادل صلة Agent Note لـ دقيق.

- OpenRouter مخصص تابع تطبيق عودة بسبب علامة رأس تأجيل إلى لم قدوم صريح OpenRouter مهايئ أو نمط؛OpenAI توافق شبكة صلة طلب فقط يحمل مشترك عودة بسبب أساس خط.
- `off` دفع إدارة قوي درجة أبدا سوف بـ `reasoning_effort: 'off'` مرور خط؛ هو تسلسل تحويل لـ `thinking: { type: 'disabled' }` و حذف هذا حقل، من بينما مقابل رفض لم معرفة قوي درجة أخذ قيمة شبكة صلة إبقاء بروتوكول تجميع كتابة صالح.

</details>

**وقت التشغيل ثابت صيغة:** لا إصدار مرافق توليد مدخل. هذه الحزمة لا يوجد مستقل حدث تسلسل أو متغير بيانات علاقة، متبادل صلة اتفاق في الذي تابع seam قوي صنع تنفيذ.
