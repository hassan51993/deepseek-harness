# @deepseek-ai/dsh-command-goal

[English](README.md) | العربية

## عام وصف

`dsh-command-goal` لـ مستخدم توفير `/goal` أمر، بـ سهل مباشر في تفاعل صيغة UI في إنشاء، تحرير، مؤقت توقف، استعادة، صاف حذف و عرض حالي goal. أمر و ذلك مباشر إخراج إبقاء في UI في، لا دخول نموذج طلب. قبول تغيير سوف حفظ دائم؛create أو edit يحمل لديه ترتيب صورة أو ملف مرفق عنصر سوف يصبح واحد بند عادي مستخدم رسالة، توفير لاحق Goal Round قراءة. هذا حزمة ملائم لأجل حمل أمر مهايئ تفاعل صيغة نشر؛ لا يوجد مهايئ بلا رأس و تلقائي تحويل تطبيق لا حاجة هو.

## استخدام هذه الحزمة

في تركيب أمر مهايئ تفاعل صيغة نشر في استخدام `dsh-command-goal`——مع مرفق Web عميل هو مشاركة اعتبار تنفيذ. هو يجعل مستخدم بلا حاجة نموذج جولة يكفي مباشر تحكم goal دورة الحياة: أمر في UI أمر مستو وجه تنفيذ، مهايئ مباشر تصيير ذلك نتيجة.

### أمر مشاركة اعتبار

كل فرعي أمر كل إبرة مقابل استدعاء agent(ذكي جسم) حالي goal تنفيذ؛ لا يوجد goal وقت، عار `/goal` عرض استخدام قاعدة.

| إدخال | نتيجة |
|---|---|
| `/goal` | عرض حالي هدف، حمل دائم phase،Round عدد كمية و حد أعلى، عملية محلي متابعة سطر تفعيل حالة و صالح تحت واحد خطوة أمر؛ يتم منع سد goal أيضا سوف عرض ذلك سياسة شفرة و شرح |
| `/goal <objective>` | إنشاء goal و تفعيل متابعة سطر، أو استخدام كل جديد هوية استبدال اكتمل goal |
| `/goal edit <objective>` | تحرير حالي هدف، لا تغيير ذلك phase أو متابعة سطر تفعيل حالة |
| `/goal pause` | مؤقت توقف active goal و توقف استخدام متابعة سطر |
| `/goal resume` | استعادة قد إيقاف goal، أو في جلسة resume أو fork بعد إعادة تفعيل active goal؛ ما زال تلقي باق بقية Round حد أعلى قيد |
| `/goal clear` | صاف حذف حالي goal، معا إبقاء ذلك حمل دائم تاريخ |

### إدخال لغة قاعدة

فقط لديه تحكم كلمة (`clear`،`pause`،`resume`،`edit`) احتلال حسب كامل إدخال وقت عندئذ يتم تعرف آخر؛ أخرى أي غير فارغ بعد لاحقة كل هو هدف، لذلك `/goal pause after verification` سوف إنشاء هذا حرف وجه هدف.`edit` داخل ربط استقبال استبدال محتوى، و رفض مباشر استبدال لم إتمام goal. يمكن مسبق مدة مجال رفض سوف تغيير صار مستقر مباشر أمر خطأ، لا كشف حمل صنف لوحة نوع id أو revision؛ معنى خارج تنفيذ فشل ما زال سوف يجعل توزيع فشل، جعل مهايئ قدرة سوف ذلك تقرير إبلاغ لـ أمر فشل.

### مرفق عنصر

`/goal` إعلان مرفق عنصر دعم حمل. مرفق عنصر فقط مع هدف ذاته:create أو edit نجاح بعد، أمر إيداع واحد بند مستخدم followup رسالة، حسب اختيار ترتيب يحمل قد دقيق دخول صورة كتلة و ملف كتلة، مجددا مرفق إضافة ثابت نص `Reference attachments for the goal objective.`. لاحق Goal Round من عادي جلسة تاريخ قراءة هذه محتوى،goal مجال لا تخزين مرفق عنصر حالة. أخرى أي فرعي أمر و يتم رفض create أو edit، كل سوف في مجال تغيير قبل إرجاع مباشر خطأ، و إبقاء composer مسودة مسودة و مرفق عنصر بطاقة.

### تركيب طريقة

أمر حقن أمر سجل التسجيل و goal خدمة. ذاتي تعريف تطبيق سوف تركيب هو جمع كل من و هذا إضافة؛ تلقائي متابعة سطر ما زال هو مستقل اختيار:

```yaml
- id: commands
  name: '@deepseek-ai/dsh-commands'
- id: goal
  name: '@deepseek-ai/dsh-goal'
- id: command-goal
  name: '@deepseek-ai/dsh-command-goal'
```

مع مرفق `dsh` أساس أساس إعداد تفعيل حمل دائم goal مكدس و هذا أمر.Web bundle يأخذ goal خدمة و driver إبقاء في Host، منع استخدام أساس أساس أمر producer، و في `standard`،`code` و `cordis` agent preset في تركيب producer؛`minimal` سوف حذف هو.ACP(Agent Client Protocol) تلقائي تحويل تطبيق تفعيل مجال و نموذج أداة، لكن لا تركيب أمر مهايئ. مستقل `sdk-minimal` profile حذف كامل goal مكدس، لذلك ذلك نتيجة API ما زال في واحد صلة ربط شيء إدارة جولة بعد انتهاء.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير أمر مثل أي تحليل إدخال و تصيير إخراج؛ يمكن مراقبة اتفاق قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم

- **لغة قاعدة، بينما غير ذاتي من نص.** محلل فقط في تحكم كلمة (`clear`،`pause`،`resume`،`edit`) ملء ممتلئ كامل إدخال وقت تعرف آخر هو جمع؛ أخرى أي غير فارغ بعد لاحقة كل هو هدف. مفرد وحيد `edit` بلا فاعلية، كما `edit` رفض مباشر استبدال لم إتمام goal.
- **مجال رفض تغيير صار مستقر خطأ.** `GoalError` نتيجة سوف تحويل لـ حمل ثابت رسالة مباشر أمر خطأ؛ معنى خارج فشل سوف إعادة رمي خروج، جعل مهايئ تقرير إبلاغ أمر فشل بينما غير مجال نتيجة. تصيير إخراج أبدا كشف حمل صنف لوحة نوع id أو revision.
- **مرفق عنصر مع هدف إيداع.** create أو edit نجاح وقت، أمر إيداع واحد بند مستخدم followup رسالة، حسب اختيار ترتيب يحمل قد دقيق دخول صورة كتلة و ملف كتلة، مجددا مرفق إضافة ثابت نص `Reference attachments for the goal objective.`. أخرى مسار لا إيداع رسالة، لذلك توزيع جهة composer إبقاء مسودة مسودة و مرفق عنصر بطاقة.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل: أمر لغة قاعدة، حالة تصيير، مرفق عنصر إيداع |
| — | لا إصدار وقت التشغيل ثابت صيغة مرافق توليد مدخل؛ هذا أمر مهايئ لا يملك حدث تدفق أو حالة إسقاط؛ قد قبول تغيير من goal مجال فحص، أمر توزيع سلوك من حزمة اختبار تغطية. |

</details>

<a id="model-experience"></a>
## تجربة النموذج

### مستخدم `/goal` تحكم

#### نموذج يرى محتوى

مائل عمود إدخال، تغيير و مباشر حالة أو خطأ إخراج لن دخول نموذج طلب.goal مجال يأخذ تغيير سجل لـ `goal/change`؛ قد تفعيل نفس جلسة مشغل يمكن في لاحق متابعة سطر نص التوجيه في كشف نتيجة حالة. عرض نص لن سجل إلى سجل في. عند create أو edit يحمل مرفق عنصر وقت، نموذج سوف يرى واحد بند عادي مستخدم رسالة: لديه ترتيب صورة كتلة و ملف كتلة بعد تتبع نص `Reference attachments for the goal objective.`. هو في جلسة تاريخ في يقع في تحت واحد Goal Round قبل.

#### Token أثر

قراءة حالة، تغيير goal أو استلام إلى مباشر أمر خطأ لن زيادة نموذج token. قد تفعيل نفس جلسة مشغل ممكن زيادة لاحق Goal Round نص التوجيه. هدف يحمل مرفق عنصر سوف زيادة واحد بند عادي مستخدم رسالة، إنتاج معتاد قاعدة نص، صورة و ملف جملة مقبض صار هذا.

#### KV Cache أثر

أمر اكتشاف، تغيير و مباشر إخراج لن أثر ذاكرة مؤقتة. لاحق متابعة سطر نص التوجيه التزام دوران مشغل عادي طلب تاريخ.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح أمر أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **فقط صاف نص تفاعل**——عام أمر سجل التسجيل لا يوجد نموذج حالة تحرير جدول مفرد أو استبدال تأكيد عودة ضبط؛ داخل ربط edit و صريح clear قدرة في مختلف مهايئ في إبقاء واضح كما متسق كسر تالف صفة معنى رسم.
- **لا يوجد تدريجي أمر Round حد أعلى معامل**——`defaultMaxGoalRounds` ما زال هو نشر إعداد؛ مستخدم مباشر طلب وقت، يمكن اشتراط نموذج عبر آخر سطر تخويل goal أداة تحرير `max_goal_rounds`.
- **لا يوجد حمل متابعة حالة مكون**——عار `/goal` هو يمكن نقل غرس مراقبة واجهة؛ لا توفير مهايئ مخصص استخدام شعار علامة أو إعادة وصل بعد يمكن استعادة أمر إخراج.
- **مع مرفق تطبيق في فقط لديه Web أمر مهايئ استخدام هذا أمر**——بلا رأس،ACP تلقائي تحويل و JSON-RPC مهايئ لا إزالة استهلاك `ctx.commands`. إذا تركيب في يتضمن موجه إلى نموذج goal أداة، عادي نص التوجيه ما زال قدرة تخويل هو جمع.
