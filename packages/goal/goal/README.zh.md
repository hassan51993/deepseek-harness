# @deepseek-ai/dsh-goal

[English](README.md) | العربية

## عام وصف

`dsh-goal` يجعل واحد طويل مدة إتمام هدف في كثير جولة، جلسة استعادة،fork و عملية إعادة بدء بعد حمل متابعة وجود. مستخدم و agent(ذكي جسم) يمكن create،edit،pause،resume،complete،block أو clear هذا هدف؛ مقارنة مقارنة و ضبط تحديث سوف رفض قديم قديم عرض. يمكن إعداد Round حد أعلى (افتراضي 256) قيد تلقائي متابعة سطر، يتم منع سد goal سوف إبقاء مستقر سياسة شفرة و موجه إلى شخص شرح. هذه الحزمة تخزين goal حالة لكن لا ضبط درجة عمل، متابعة سطر إذن هو عملية محلي بينما غير حمل دائم حالة. مفرد عدد هدف حاجة أفقي عبر كثير جولة وقت اختيار هذه الحزمة؛ معتاد قاعدة مفرد جولة عمل أو و سطر هدف لا يلزم استخدام.

## استخدام هذه الحزمة

عند جلسة حاجة في كثير جولة و كثير مرة إعادة بدء بين تسجيل إقامة واحد طويل مدة إتمام هدف وقت، تركيب `dsh-goal`. هذه الحزمة هو خدمة: نموذج أداة،`/goal` أمر و متابعة سطر مشغل كل هو إزالة استهلاك نفس goal حالة مستقل حزمة، لذلك فقط تركيب هذه الحزمة فقط سوف تخزين و توفير goal، لن بدء أي عمل.

### أي وقت استخدام

goal ملائم دمج واحد حاجة عبر تلقائي Goal Round حمل متابعة طويل مدة إتمام هدف——مثال مثل إتمام مرة ترحيل، أو إصلاح كل فشل وثيقة بوابة. معتاد قاعدة مفرد جولة عمل لا ينبغي إنشاء goal. خدمة كل جلسة حتى كثير إبقاء واحد حالي goal: لم إتمام goal يجب أولا edit،pause،resume،block أو clear، عندئذ قدرة يتم آخر عدد بديل؛ قد إتمام goal يمكن مباشر يتم استبدال.

### إعداد خدمة

عبر تركيب بند إعداد تحميل هذه الحزمة؛ وحيد نشر اختيار هو افتراضي Round حد أعلى، تطبيق في لم ذاتي سطر إشارة تحديد حد أعلى create.

```yaml
- name: '@deepseek-ai/dsh-goal'
  config:
    defaultMaxGoalRounds: 256
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `defaultMaxGoalRounds` | `256` | عند create طلب حذف حد أعلى وقت تطبيق Round حد أعلى |

`defaultMaxGoalRounds` يجب هو صحيح أمان كامل عدد؛ إشارة تحديد ذاته حد أعلى create طلب سوف تغطية هو. توليد[إعداد دليل](../../../docs/config-catalog.zh.md#deepseek-aidsh-goal) هو كل تلقي دعم حمل حقل نفاد كل صيغة حق مصدر.

### جلسة إسقاط

`GoalService` اشتراط تركيب توفير `ctx.sessionProjections`([`@deepseek-ai/dsh-session-projection`](../../session/session-projection/README.zh.md)) ، و في بدء وقت تسجيل `goal` إسقاط وحدة؛ لم تركيب إسقاط سجل التسجيل تركيب لا يمكن تنشيط `ctx.goals`. هذا وحدة إصدار لـ 6، ذلك مضيف حالة إبقاء الأكثر جديد صالح حالي goal، كل سبق استخدام goal id، و رقم مرة صارم إطار إعادة تشغيل فشل. عميل عرض توفير حالي goal؛ أول مرة create قبل و clear tombstone بعد لـ `null`. هذا مفتاح معا دمج إلى `SessionProjectionStateMap` و `SessionProjectionMap`؛ تحميل جسم عبر تاريخ ذيل صفحة و `session/projection` دفع إرسال لقطة توفير عميل قيمة.

### قيادة دورة الحياة

goal مرور تاريخ أربعة نوع حمل دائم phase——`active`،`paused`،`blocked`،`complete`——خارج إضافة واحد عملية محلي علامة سجل، يمثل تلقائي متابعة سطر هل قد تفعيل. حركة كلمة مثل تحت:

| عملية | أثر |
|---|---|
| `create` | بـ هدف و Round حد أعلى بدء واحد active goal |
| `edit` | تعديل هدف و/أو Round حد أعلى، لا تغيير phase |
| `pause` | إيقاف تلقائي متابعة سطر و إبقاء حالة |
| `resume` | إعادة بدء متابعة سطر؛ أيضا لأجل جلسة استعادة أو fork بعد إعادة تفعيل active goal |
| `complete` | علامة goal قد إتمام و إيقاف متابعة سطر |
| `block` | سجل مستقر blocker شفرة و شرح |
| `clear` | إزالة حالي goal؛ ذلك تاريخ إبقاء في جلسة سجل في |

pause،complete،block و clear كل سوف توقف استخدام متابعة سطر.block هو وحيد إبقاء سياسة ذاتي لديه lower-kebab-case شفرة و ذاتي من نص شرح phase، لذلك مزود حد، ميزانية استهلاك كل، تنفيذ خطأ و طلب شخص عمل إدخال مشترك استخدام واحد نوع حمل دائم phase، بينما لا هو توسيع زيادة دورة الحياة حالة.resume فقط في Round حد أعلى ما زال لديه باق بقية سعة كمية وقت قبول قد إيقاف goal، أو active لكن قد توقف استخدام متابعة سطر goal، و صاف حذف أي أولا قبل blocker reason.

### ماذا سوف إبقاء، ماذا لن

كل بند يتم قبول تغيير كل سوف حمل دائم سجل إلى جلسة سجل——goal حالة وحيد تخزين——لذلك goal حالة أبدا اعتماد مؤقت رسالة إلقاء تمرير. جلسة استعادة أو fork بعد،goal، ذلك phase، ذلك revision و قد دقيق دخول Round عدد كمية كل ما زال وجود. تلقائي متابعة سطر هو مثال خارج: أي جلسة بدء حد بعد،`active` goal كل سوف يتم توقف استخدام متابعة سطر——في لديه شخص صريح resume قبل،agent لن ذاتي سطر متابعة.

### مراقبة goal

مستهلك استخدام `ctx.goals.get(agent)` قراءة حالي goal، نيل نيل انفصال مغادرة داخلي حالة عرض: هدف،phase، قد بدء و حد أعلى Round عدد كمية، يتم منع سد وقت blocker reason، و متابعة سطر هل قد تفعيل. تغيير يجب يحمل هذا عرض في دقيق `{ id, revision }`، لذلك يحتفظ قديم حالة مستهلك سوف استلام إلى صاف واضح قديم قديم revision خطأ، بينما لا هو ساكن صامت تغطية تحديث حالة:

```text
const view = ctx.goals.get(agent)      // undefined when no goal is current
view.phase                             // 'active' | 'paused' | 'blocked' | 'complete'
view.roundsStarted, view.maxGoalRounds // continuation progress
view.activation                        // 'armed' | 'disarmed' — not persisted
```

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير خدمة مثل أي تنفيذ فوق وصف سلوك؛ يمكن مراقبة اتفاق قد في[استخدام هذه الحزمة](#use-this-package) في شرح.

### تصميم

- **حدث تتبع مصدر حالة.** كل مرة تغيير كل إلحاق حمل دائم `goal/change` حدث (إصدار 1) ، يحمل تغيير بعد كامل لقطة؛clear كتابة حمل revision tombstone. جلسة سجل هو وحيد حمل دائم مرجعي.
- **مقارنة مقارنة و ضبط تغيير.** `ctx.goals` فقط قبول بـ مقابل id تسجيل تماما نفسه نشط وثب `Agent` نسخة.`get()` إرجاع انفصال مغادرة حالة `GoalView`؛ تغيير يحمل `GoalRef { id, revision }` و رفض قديم قديم مرجع. إنشاء في إيداع قبل في داخلي تحليل نشر قيمة افتراضية.
- **متابعة سطر تفعيل حالة هو عملية محلي.** `armed` و `disarmed` حفظ في كل جلسة ذاكرة مؤقتة في، أبدا حفظ دائم. جديد ذاكرة مؤقتة و كل مرة `agent/created` حد كل سوف توقف استخدام متابعة سطر، أي جعل إعادة تشغيل اكتشاف حمل دائم phase لـ active؛`disarm()` إزالة متابعة سطر إذن، لا كتابة revision أيضا لا إرسال خروج تغيير حدث.
- **صارم إطار إعادة تشغيل.** طي فقط من `goal/change` إرسال توليد دورة الحياة تغيير، و رفض شكل حالة خطأ، لا وصل متابعة revision، غير قاعدة phase تحويل، كل هدف ختم الوقت غير مفرد ضبط، و لا وصل متابعة قد دقيق دخول Round. فقط لديه قد دقيق دخول مصدر لـ goal `user/message` حدث سوف دفع دخول صحيح عدد Round؛ تعليق ساعة وقت قلب تراجع وقت، تغيير ختم الوقت سوف حد في لا مبكر في فوق مرة تحديث قيمة.
- **إسقاط وحدة.** هذه الحزمة اشتراط توفير إسقاط سجل التسجيل، و تسجيل واحد صارم إطار `goal` وحدة. ذلك مضيف حالة إبقاء إعادة تشغيل تحقق بيانات و رقم مرة فشل، عميل عرض توفير الأكثر جديد صالح كامل goal أو `null`؛ إبقاء إعادة تشغيل فشل بعد،`GoalService` سوف رفض وصول.

### شفرة المصدر أرض رسم

| ملف | مسؤولية |
|---|---|
| [`src/index.ts`](src/index.ts) | إضافة مدخل:`GoalService`، إعداد schema، تغيير، متابعة سطر تفعيل ذاكرة مؤقتة، إسقاط وحدة |
| [`src/domain.ts`](src/domain.ts) | حمل دائم تغيير تحميل حمل،`goal/changed` حدث،goal رسالة مصدر ملكية |

| [`src/fold.ts`](src/fold.ts) | حمل دائم goal تغيير صارم إطار إعادة تشغيل طي و حل رمز جهاز |

### حدث و ملكية

`goal/changed` في حمل دائم حدث إيداع بعد إطلاق، مستمع فشل سوف يتم عزل؛ تحميل حمل يحمل عملية، دقيق ref و الأكثر جديد عرض (clear tombstone وقت حذف).`goal/activation-changed` في لا تغيير حمل دائم حالة حال حال تحت، تحويل إرسال يحمل دقيق حالي ref عملية محلي `armed`/`disarmed` حد؛clear بعد فإن لا يحمل goal. قد دقيق دخول متابعة سطر Round عبر `user/message` حدث فوق `GoalMessageSource { goalId, revision, round }` ملكية، صارم إطار طي سوف سوف ذلك تحقق لـ حالي goal تحت واحد قد دقيق دخول Round.

<a id="model-experience"></a>
## تجربة النموذج

### هدف حالة تغيير

#### نموذج يرى ماذا

Goal تغيير لن حقن نموذج سياق.`get_goal` انتظار أداة إرجاع حالي حالة؛ متابعة سطر مستهلك يمكن في ضبط درجة نموذج عمل وقت تصيير هدف و Round حالة.

#### Token أثر

Goal تغيير حدث ذاته لا زيادة نموذج token. أداة نتيجة و متابعة سطر ضبط درجة نص التوجيه كل منها كشف حالة سوف قسم آخر حساب دخول token استخدام كمية.

#### KV Cache أثر

في أخرى مكون يأخذ goal حالة كشف لـ نموذج مرئي إدخال قبل، لن أثر KV Cache.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح goal خدمة أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مهمة تراكم ضغط.

- **فقط مسؤول حالة، لا مسؤول مهمة ضبط درجة**——هذه الحزمة لا قرار قد تفعيل متابعة سطر goal أي وقت متابعة، لا إعادة محاولة استثناء فشل، أيضا لا إلغاء نشط وثب جولة؛ هذه سياسة يخص `dsh-goal-round-driver` انتظار مستهلك حزمة.
- **فقط لديه Round عدد كمية ميزانية**——`maxGoalRounds` لا حساب كمية token، بضاعة عملة، تعليق ساعة وقت أو مزود إعداد مقدار.
- **لا يوجد مستقل تقييم تقدير جهاز**——سجل إتمام أو منع سد استدعاء جهة يملك نهائي قرار حق؛ من تقييم تقدير جهاز دعم حمل إقرار إثبات مؤقت مؤقت إلى مستقل سياسة طبقة.
- **فقط لديه واحد حالي goal**——نظام متعمد لا دعم حمل و سطر هدف أو مستقل goal قاعدة بيانات؛ استبدال أو صاف حذف بعد، تاريخ ما زال يمكن في جلسة سجل في قراءة.
- **معلومة مهمة عملية داخل إنتاج جهة**——قدرة مباشر وصول `Session` إضافة يمكن إلحاق زائف صنع `goal/change` بيانات. صارم إطار إعادة تشغيل سوف فحص قياس صيغة خطأ أو لا متسق سجل، و جعل goal وصول من هذا سجل بدء فشل، مباشر إلى سجل إصلاح؛ هذا هو كامل صفة فحص قياس، لا هو إضافة عزل.
