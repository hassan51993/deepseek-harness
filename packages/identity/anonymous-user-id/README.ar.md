# @deepseek-ai/dsh-anonymous-user-id

[English](README.md) | العربية

## عام وصف

DeepSeek Harness لـ كل harness home استخدام واحد مجهول اسم معرف رمز، بـ صلة ربط نفس طقم تثبيت إنتاج بعيد قياس، ملاحظات و DeepSeek طلب، معا لا تعرف آخر مستخدم هوية. هذا مع آلة UUID تخزين في `$DSH_HOME/.anonymous-user-id`(`$DSH_HOME` افتراضي لـ `~/.dsh`) في، يمكن عبر إعادة بدء إبقاء، و في أنت حذف ملف بعد إعادة توليد. مختلف harness home استخدام مختلف معرف رمز، كما هذا قيمة لا يتضمن آلة جهاز أو حساب مستخدم بيانات. داخل وضع وظيفة سوف تلقائي إنشاء و مرفق إضافة هذا قيمة؛ حزمة مستهلك يمكن إعادة استخدام نفس عدد قيمة إجراء تثبيت نطاق صلة ربط، لكن لا يمكن عبر home صلة ربط سجل.

<a id="use-this-package"></a>
## استخدام هذه الحزمة

عند أنت أمل نظر هذا آلة تثبيت خارج إرسال سجل قدرة يتم تعرف آخر لـ قدوم ذاتي نفس عدد harness home——بعيد قياس، ملاحظات و DeepSeek طلب كل يحمل نفس عدد مشترك id——هذه الحزمة حينئذ هو توفير هو أرض جهة. بلا حاجة تثبيت أو إعداد أي شرق غرب:id سوف تلقائي ظهور، قد مع مرفق ملاحظات، بعيد قياس و DeepSeek وظيفة قد في استخدام هو. لا يلزم استخدام هو قدوم تعرف آخر مستخدم، أيضا لا يلزم استخدام هو صلة ربط مختلف home بين سجل؛ هو هو مجهول اسم كما حد تحديد في مفرد عدد home.

### هذا id قدرة لـ أنت فعل ماذا

أنت تثبيت خارج إرسال ثلاثة صنف محتوى يحمل نفس عدد id، لذلك سجل في هو جمع بين يمكن متبادل متبادل مقابل:

- **جلسة بعيد قياس**——أنت بعيد قياس تصدير سوف بـ `user.id` Resource خاصية يحمل هذا id، أخذ تجميع جهاز لذلك يمكن حسب تثبيت قسم مجموعة سجل.
- **ملاحظات**——كل بند ملاحظات تأكيد كل سوف علامة واضح سجل هذا ملاحظات مجهول اسم تثبيت.
- **DeepSeek طلب**——كل مرة مزود طلب كل سوف يحمل `x-deepseek-harness-user-id` علامة رأس، لذلك يمكن حسب تثبيت عودة بسبب استخدام كمية.

### عرض و إعادة وضع id

هذا id تخزين وضع في `$DSH_HOME/.anonymous-user-id`(`$DSH_HOME` افتراضي لـ `~/.dsh`) في، هو واحد صاف UUID نص ملف. حذف هذا ملف يكفي في تحت مرة بدء وقت نيل نيل كل جديد id؛ جارٍ تشغيل عملية في خروج قبل سوف واحد مباشر إبقاء حالي id. مختلف harness home كل منها إبقاء مستقل id، قيمة في دائم بعيد لن يتضمن أي آلة جهاز أو حساب مستخدم معلومة.

### في ذاتي ذات حزمة في استخدام

عند أنت بناء وظيفة حاجة مشترك هذا تثبيت مجهول اسم id وقت، استيراد مرة و إعادة استخدام هذا قيمة يكفي——بعيد قياس، ملاحظات و DeepSeek قد في استخدام نفس عدد id، لذلك أنت سجل قدرة و هو جمع متبادل متبادل مقابل:

```ts
import { getOrCreateAnonymousUserId } from '@deepseek-ai/dsh-anonymous-user-id'

const userId = getOrCreateAnonymousUserId() // stable for the process lifetime
```

هذا قيمة في عملية داخل إبقاء مستقر، و و داخل وضع وظيفة استخدام قيمة متسق؛ فقط لديه عند ملف يتم حذف، لاحق بدء توليد بديل قيمة وقت عندئذ سوف تغيير. أي جعل home دليل غير ممكن كتابة، هذا قيمة في هذا مرة تشغيل في اعتماد لكن متاح، سجل لذلك لن في قطع.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

هذا عقدة حل تفسير هذه الحزمة خلف بعد تصميم قرار، و إشارة خروج تنفيذ هو جمع شفرة موضع؛ يمكن مراقبة سلوك قد في[استخدام هذه الحزمة](#use-this-package) في كامل شرح.

### تصميم إدارة فكرة

- **مع آلة توليد، أبدا إرسال توليد.** id قدوم ذاتي `crypto.randomUUID()`؛ أبدا من hostname، شبكة عنوان،git remote أو أي أخرى يمكن تعرف آخر مصدر إرسال توليد، لذلك مجهول اسم صفة هو توليد مرور مسار خاصية.
- **تزامن كما تسجيل ذاكرة تحويل.** واحد عملية مقابل كل تحليل بعد ملف مسار فقط لمس اصطدام مرة مغناطيس قرص: قراءة كتابة كل هو تزامن، نتيجة حسب تحليل بعد ملف مسار تسجيل ذاكرة تحويل.
- **Best-effort حفظ دائم.** كتابة فشل ما زال سوف لـ هذا مرة تشغيل إرجاع متاح id، بعيد قياس و ملاحظات لذلك لن بسبب home غير ممكن كتابة بينما منع سد.
- **مكتبة بينما غير إضافة.** لا يوجد Cordis إضافة مدخل أو إعداد. لا إصدار ثابت صيغة مرافق توليد مدخل، لأن هذه الحزمة لا يملك أي حدث تدفق أو عام متغير علاقة، لا يمكن في لا إنتاج إنشاء id هذا واحد فرعي أثر حال حال تحت مقارنة مقارنة.

### API

هذه الحزمة كشف واحد دالة، إرجاع هذا تثبيت مجهول اسم id، و في أول مرة استخدام وقت توليد و حفظ دائم؛ تأكيد قطع توقيع، خيار و قيمة افتراضية رؤية `src/index.ts`.

### تخزين اتفاق

ملف هو اسم لـ `ANONYMOUS_USER_ID_FILE_NAME` عار UUID سطر، قراءة وقت حسب UUID نمط تحقق. أول عدد كتابة جهة استخدام وحيد احتلال إنشاء (`wx`) ؛ تزامن سقوط فشل جهة إعادة قراءة و اعتماد فوز خروج جهة قيمة. لقاء إلى ضرر تالف أو غير ممكن قراءة ملف وقت، نظام سوف تحويل بينما توليد جديد قيمة و تغطية هذا ملف. تسجيل ذاكرة تحويل حسب تحليل بعد ملف مسار لـ مفتاح، لذلك مختلف home دائم بعيد لن مشترك id.

بلا؛ هذا نقل علامة رأس حيث لن تغيير token، أيضا لن تغيير نموذج مرئي بادئة.

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>


هذه حد شرح هذا id أي وقت لا دمج ملائم أو حاجة خاص آخر ملاحظة معنى. هو جمع هو حالي حزمة قيد، لا هو مجهول اسم صفة خطة عام مقابل مقارنة، أيضا لا هو مهمة تراكم ضغط.

- **حذف بعد لا يمكن استعادة**——ملف فقد فقد بعد سوف حسب تصميم توليد جديد مجهول اسم هوية؛ استعادة حاجة مستقر إرسال توليد مادة مادة، هذا سوف تقليل ضعيف مجهول اسم صفة.
- **Best-effort تزامن**——إذا قراءة جهة تماما جيد سقوط في تزامن عملية إتمام وحيد احتلال إنشاء لكن بعد لم كتابة تمام ضيق ضيق وقت نافذة داخل، هذا مرة تشغيل ممكن استخدام مختلف داخل تخزين UUID؛ لاحق بدء سوف استلام جمع إلى قد حفظ دائم قيمة.
- **لا يوجد عبر home هوية**——مختلف `$DSH_HOME` قيمة بين لا يمكن صلة ربط.
- **قد إعداد DeepSeek شبكة صلة سوف استلام إلى هذا id**——`dsh-llm-deepseek` سوف يأخذ مستقر علامة رأس إرسال حتى تحليل بعد `baseURL`(يشمل نشر تغطية) ، كما لا تلقي بعيد قياس مشترك نمط أثر.
- **حذف ملف لن إعادة وضع حالي عملية**——تسجيل ذاكرة تحويل سوف يجعل هذا مرة تشغيل id واحد مباشر إبقاء إلى تحت مرة بدء.

<a id="dev-note"></a>
### ملاحظة تطوير

<details>
<summary>صيانة من عمل سياق——انقر للتوسيع</summary>

هذا ملاحظة تطوير هو صيانة من عمل سياق: فتح وضع مشكلة و بعد لم قرار استكشاف جهة نحو. هو واضح لا أداة مرجعي صفة——قد تسليم سلوك، حد و حيث تحديد إدارة من بـ فوق نص و حزمة شفرة لـ دقيق، ربط نقاش واحد حالما مستقر حينئذ ترحيل إلى مقابل ملكية.

#### فتح وضع: ملف صيغة عرض دخول

حفظ دائم اتفاق هو لا يوجد أي إصدار علامة عار UUID سطر. في id جانب حافة زيادة ثاني عدد قيمة، أو استخدام حاوية حزمة لف هذا سطر، مقابل قائم ملف كل لا يوجد ترحيل خطة؛ حمل إصدار سطر صيغة هو يجعل هذا صنف تغيير أمان واحد نوع طريقة.

#### فتح وضع: ثابت صيغة مراقبة قياس نقطة

لا إصدار ثابت صيغة مرافق توليد مدخل، لأن أي علاقة كل لا يمكن في لا إنتاج إنشاء id هذا واحد فرعي أثر حال حال تحت فحص. لم قدوم إذا لديه أمان مراقبة قياس نقطة، يمكن يأخذ إعادة قراءة حفظ دائم ملف و تسجيل ذاكرة تحويل id إجراء مقارنة مقارنة.
