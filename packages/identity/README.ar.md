# identity/ — مشترك هوية

[English](README.md) | العربية

## عام وصف

identity مجموعة لـ كل harness home توفير واحد مجهول اسم id، هذا تثبيت بعيد قياس، ملاحظات و DeepSeek طلب سوف يأخذ هو مرفق إضافة إلى كل منها سجل فوق، لذلك مغادرة فتح نفس عدد home كل محتوى كل قدرة يتم تعرف آخر لـ قدوم ذاتي نفس طقم تثبيت، بينما بلا حاجة تعرف آخر مستخدم هوية. بلا حاجة إعداد أي شرق غرب:id سوف في هذه وظيفة لـ واحد أول مرة وقت التشغيل تلقائي ظهور، و في ملف يتم حذف قبل إبقاء مستقر. هذا مجموعة فقط لديه واحد حزمة؛ هذا صفحة صف خروج هذا مجموعة مجموعة صار، حزمة README مسؤول دقيق عقدة.
