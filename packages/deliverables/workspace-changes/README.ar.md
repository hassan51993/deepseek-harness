# @deepseek-ai/dsh-workspace-changes

[English](README.md) | العربية

## عام وصف

هذا إضافة تجميع مجموع كل قمة طبقة جولة تعديل أي بعض ملف، كل ملف سطر عدد، و توفير كل الذي صف ملف في جولة بدء و انتهاء وقت محتوى مقابل مقارنة. مقارنة مقارنة جولة بدء و انتهاء وقت git عمل شجرة لقطة؛ ملف أداة تحرير كل ملف في أول مرة تحرير قبل و جولة انتهاء وقت كل نسخ واحد نسخة كامل ملف، بـ هذا تغطية git تغطية لا إلى ملف. لا يوجد مستودع أو لا يوجد git وقت، فقط صف ملف أداة تحرير.Session سجل فقط استلام إلى واحد بند كتابة واضح جولة رقم `workspace/changes` حدث؛ ملخص و مقابل مقارنة إبقاء في Host فوق، مباشر إلى Session تحرير.Web تعديل ملف بطاقة تصيير هو جمع.

## استخدام هذه الحزمة

صحيح صيغة توفير Web bundle تركيب هذا إضافة. أي أداة تجهيز `subprocess` قدرة كما Host فوق لديه git يمكن تنفيذ ملف تركيب كل يمكن تركيب هو:

```yaml
- name: '@deepseek-ai/dsh-workspace-changes'
  config:
    maxFiles: 500
```

| حقل | قيمة افتراضية | يحتوي معنى |
|---|---|---|
| `timeoutMs` | `30000` | مفرد بند git أمر سماح تشغيل جزء ثانية عدد، مهلة فإن وضع ترك هذا جولة سجل |
| `outputMaxBytes` | `8388608` | كل بند أمر إبقاء git إخراج بايت عدد،diff قائمة أكثر كبير وقت وضع ترك هذا جولة سجل |
| `maxFiles` | `500` | مفرد نسخة ملخص يحمل الأكثر كبير ملف عدد؛`total` ما زال تقرير إبلاغ كامل عدد كمية |
| `maxFileBytes` | `2097152` | ملف في ملف أداة تحرير قبل بعد يتم التقاط، أو من لقطة قراءة خروج فعل مقابل مقارنة الذي سماح الأكثر كبير بايت عدد؛ أكثر كبير ملف لا توفير مقابل مقارنة، منها في ملف أداة تحرير قبل بعد يتم التقاط أيضا لا حمل سطر عدد |
| `diffTimeoutMs` | `100` | تدريجي سطر مقابل مقارنة سماح تشغيل جزء ثانية عدد، مهلة بعد تراجع تحويل لـ كامل ملف استبدال |

لديه عمل دليل كما لا هو فرعي بديل إدارة مصدر Session كل سوف يتم سجل؛ فرعي بديل إدارة Session لا سجل. لقطة عبر خاص index كتابة Session ذاتي ذات يملك مؤقت كائن دليل، مستودع ذاتي ذات كائن مكتبة بـ فقط قراءة alternate طريقة تعليق وصل؛ مستودع index، كائن، عمل شجرة و ref إبقاء ثابت، مستخدم هذا قبل لم إيداع تعديل أيضا لن دخول ملخص.Session تحرير وقت حذف هذا دليل. عمل دليل داخل تضمين طقم مستودع و submodule سجل لـ gitlink، ذلك داخلي تعديل لن ظهور. لا في أي git مستودع داخل عمل دليل لا فعل لقطة. لا يوجد git وقت——أو من macOS فوق فقط لديه `/usr/bin/git` تطوير من أداة وتد برنامج وقت——نفس مثال تحديد موضع لا إلى مستودع، إضافة سجل مرة سجل. اثنان نوع حال حال تحت ملخص كل فقط صف تحت نص الذي وصف ملف أداة تحرير، و بـ عمل دليل بصفة مساحة العمل؛shell تعديل لن ظهور.

في `write`،`edit` أو لديه تعديل أثر `str_replace_editor` استدعاء تشغيل قبل، سجل جهاز يأخذ هذا مسار فوق ملف نسخ إلى Session مؤقت دليل، كل جولة كل مسار فقط نسخ رقم مرة، جولة انتهاء وقت مجددا نسخ مرة؛ فرعي هذا حسب ذلك بايت SHA-1 تسمية، نفسه محتوى فقط تخزين واحد نسخة. هذا واحد خطوة لا حاجة git. لقطة تغطية إلى مسار إبقاء git سطر عدد؛ ذلك بقية مسار من فرعي هذا توفير، أيضا حينئذ هو مطابقة تجاهل اختصار نمط ملف، مستودع خارج ملف، و لا يوجد لقطة وقت كل مرة ملف أداة تحرير، سطر عدد قدوم ذاتي اثنان نسخة فرعي هذا تدريجي سطر مقابل مقارنة، لذلك نفس ملف تكرار تحرير فقط حساب مرة، ملف أداة تحرير بعد shell تعديل أيضا يتضمن في داخل. جولة انتهاء وقت محتوى لا يوجد تغير مسار لن صف خروج. تجاوز مرور `maxFileBytes` فرعي هذا لن حفظ: هذا ملف صف خروج وقت حمل `oversized`، لا يوجد سطر عدد؛ اثنان جانب كل هذا ما كبير مسار نفس مثال صف خروج، لأن لا قراءة مرور محتوى دائم بعيد لا يستطيع إقرار تحديد لـ لا يوجد تعديل. فقط فرق واحد نهاية ذيل تبديل سطر مسار مقابل مقارنة لـ اثنان جانب نفسه، بينما git ما زال سوف يأخذ ذلك واحد سطر حساب دخول سطر عدد.`/tmp` و منصة مؤقت دليل تحت ملف يتم ترتيب حذف، حذف غير هو جمع يقع في مستودع داخل. لقطة تغطية نطاق خارج فقط عبر shell أمر فعل خروج تعديل لن يتم سجل.

كل ملف يحمل حمل دائم `path`——يقع في عمل دليل داخل وقت لـ متبادل مقابل مسار، لا فإن لـ قطعا مقابل مسار——و لأجل ترتيب ترتيب و وسم `display` مسار: متبادل مقابل مسار، مستودع داخل يقع في عمل دليل لـ فوق ملف لـ `../` مسار، بيت دليل تحت ملف لـ `~` مسار، ذلك بقية لـ قطعا مقابل مسار. ملف حسب `display` رمز عنصر ترتيب ترتيب ترتيب، لذلك فوق درجة مسار و قطعا مقابل مسار ترتيب في عمل دليل ذاته ملف قبل.`workspace/changes` حدث فقط يحمل جولة رقم؛`ctx.workspaceChanges.summary(sessionId, seq)` إرجاع هذا ترتيب رقم حدث إعلان إبلاغ ملخص،Session قد تحرير أو هذا Host عملية من لم سجل وقت إرجاع undefined.`ctx.workspaceChanges.diff(sessionId, seq, index, signal)` مقابل مقارنة هذا تحت علامة الذي صف ملف: من اثنان شجرة لقطة شجرة أو اثنان نسخة فرعي هذا نيل خروج حمل ثلاثة سطر سياق hunk؛git تقرير إبلاغ لـ اثنان دخول صنع أو بعض واحد جانب يحتوي NUL بايت وقت إرجاع `binary`؛ بعض واحد جانب تجاوز مرور `maxFileBytes` وقت إرجاع `oversized`. تدريجي سطر مقابل مقارنة تشغيل تجاوز مرور `diffTimeoutMs` وقت تراجع تحويل لـ واحد استبدال الكل سطر hunk، و علامة `coarse`. لذلك Host إعادة بدء بعد إعادة فتح محادثة، أولا قبل جولة حيث لا يوجد بطاقة أيضا لا يوجد مقابل مقارنة.

## فهم التنفيذ

<details>
<summary>تنفيذ دقيق عقدة——انقر للتوسيع</summary>

كل Session واحد `TurnRecorder`، سلسلة سطر تحويل ذلك git عمل.`turn/start` ترتيب دخول أساس خط:`rev-parse` كل Session فقط تحديد موضع مرة مستودع و إنشاء Session مؤقت كائن دليل، لكن بعد بـ مستودع index لـ نوع فرعي في مؤقت index فوق تنفيذ `add --all --ignore-errors` و `write-tree` نيل إلى tree id؛ غير ممكن قراءة ملف يتم قفز مرور و بـ git خروج رمز 1 تقرير إبلاغ، لقطة قبول هذا عدد خروج رمز. كل جولة يحتفظ ذاتي ذات حالة كائن، لذلك يتم في قطع جولة ما زال في تشغيل سجل سوف في تحت واحد جولة بدء بعد إبقاء ذاتي ذات ذلك واحد جولة ملف. كل بند أمر كل حمل `GIT_OBJECT_DIRECTORY` إشارة نحو مؤقت دليل،`GIT_ALTERNATE_OBJECT_DIRECTORIES` إشارة نحو مستودع objects، لذلك قد إيداع محتوى من مستودع قراءة، جديد كائن لن سقوط دخول مستودع. كل مرة `tools/pre-execute` كل انتظار هذا طابور صف، لذلك لا يوجد تعديل قدرة أولا في ذلك أساس خط حدوث؛ نفس خطوة أيضا ترتيب دخول مقابل `write`،`edit` أو لديه تعديل أثر `str_replace_editor` استدعاء الذي إشارة مسار كامل ملف التقاط، لذلك فرعي هذا أولا في تحرير،`tool/result` حدث فقط علامة هذا جولة لديه نتيجة حاجة سجل.`agent/turn-stopping` في جولة داخل سجل: ثاني مرة لقطة، اثنان شجرة شجرة بين `diff-tree -r -M --numstat`، مقابل عمل شجرة داخل قد التقاط مسار `check-ignore`، مقابل كل لم تغطية مسار ثاني مرة نسخ و تدريجي سطر مقابل مقارنة، إلحاق حدث، و حسب حدث ترتيب رقم حفظ ملخص و كل الذي صف ملف اثنان جانب محتوى مصدر، أي لقطة شجرة في مسار أو واحد نسخة فرعي هذا. مقابل مقارنة في يتم طلب وقت حساب حساب:`ls-tree -l` تحديد موضع لقطة واحد جانب و أخذ ذلك كبير صغير،`cat-file blob` في `maxFileBytes` لـ داخل قراءة خروج، فرعي هذا من مغناطيس قرص قراءة، اثنان جانب مع بعد مشي نفس عدد حمل مهلة تدريجي سطر مقابل مقارنة.`turn/end` فقط في الأكثر بعد مرة سجل محاولة تجربة بعد ما زال لديه أداة نتيجة انتهاء وقت مجددا مرة سجل، هذا تغطية في توقف، فشل و يتم تحويل نحو جولة، كما لن تكرار مرة فشل محاولة تجربة؛ مبكر أولا سجل بعد فارغ قائمة سوف يحل محل هو. مستودع index فقط قراءة.

git عبر `subprocess` قدرة تشغيل، استخدام صاف تحويل بعد بيئة،`GIT_CONFIG_COUNT=0`(اعتماد تنظيف سوف إزالة بحث جذب إعداد مفتاح، لذلك لا وراثة هذه بيئة إعداد) ،`GIT_TERMINAL_PROMPT=0`،`GIT_OPTIONAL_LOCKS=0`، إعداد مهلة و محدود إخراج. أي خطوة فشل كل سوف وضع ترك هذا جولة سجل و إعطاء خروج تحذير إبلاغ؛ تحت واحد جولة إعادة بدء.Session تحرير و إضافة تحرير سوف في توقف ترتيب طابور عمل، نسيان تسجيل ملخص و حذف مؤقت دليل.

**وقت التشغيل ثابت صيغة:** لا إصدار مرافق توليد مدخل. حدث استماع عودة effect كل، سجل جهاز في ذلك Session تخزين نشط خلال معا يملك ملخص، لقطة شجرة و التقاط فرعي هذا؛ لا يوجد مستقل مراقبة سوف و هو جمع قسم اختلاف.

</details>

## حدود معروفة وعمل مؤجل

<a id="known-limitations-and-deferred-work"></a>

- ملخص، لقطة شجرة و التقاط فرعي هذا فقط في هذا Host عملية داخل مع ذلك Session تخزين نشط؛Host إعادة بدء بعد إعادة فتح محادثة، أولا قبل جولة حيث لا يوجد بطاقة أيضا لا يوجد مقابل مقارنة. هذا هو حيث تحديد سلوك:Host قد ضرب لا فتح محتوى بطاقة لا عرض.
- لديه اثنان عدد git وظيفة في لقطة خلال ما زال سوف كتابة مستودع ذاتي ذات git دليل:`core.splitIndex` سوف كتابة `sharedindex.*` ملف،git-lfs سوف مقابل تعديل ملف تشغيل clean مرور ترشيح جهاز و يأخذ كائن تخزين إلى `.git/lfs` تحت.
- حاجة git 2.13 أو أكثر عال إصدار بـ دعم حمل `rev-parse --absolute-git-dir`؛ لا دعم حمل مستودع صيغة أو أخرى git فشل سوف حمل حال تحذير إبلاغ وضع ترك هذا جولة، بينما لا هو يتم عند صار عادي دليل.
- Session أول مرة لقطة سوف يأخذ عمل شجرة داخل كل لم تتبع أثر كما لم يتم تجاهل اختصار ملف كتابة دخول Session مؤقت دليل؛ لا يوجد `.gitignore` لكن حمل حال كبير جسم تراكم بناء ناتج مستودع، في Session تحرير قبل سوف احتلال استخدام نفس انتظار مؤقت فضاء.
- مستخدم في جولة إجراء في ذاتي ذات فعل تحرير سوف يتم حساب إلى هذا جولة.
- لا في أي git مستودع داخل عمل دليل فقط صف ملف أداة تحرير، بطاقة داخل لذلك لا يوجد shell تعديل؛Harness home تحت أثر فرعي مستودع مؤقت مؤقت، مباشر إلى ذلك ترتيب حذف قاعدة قدرة يمكن اعتماد أرض بديل بديل ناقص `.gitignore`.
- لقطة تغطية نطاق خارج فقط التقاط ملف أداة نقطة اسم مسار: ذلك داخل فقط يتم shell أمر تعديل ملف لن ظهور، في أول مرة ملف أداة استدعاء قبل يتم اثنان من كل تعديل مرور ملف من هذا استدعاء بدء بدء مقابل مقارنة.
- كل مرة ملف أداة تحرير كل سوف يأخذ كامل ملف نسخ مرة، كل جولة كل مسار مرة، حد أعلى `maxFileBytes`، أي جعل لقطة أيضا تغطية هذا مسار؛ فرعي هذا مع Session مؤقت دليل واحد بدء حذف.
- مقابل مقارنة سوف يأخذ الذي صف ملف كامل نص إرسال إلى عميل، يشمل يتم تجاهل اختصار ملف، عمل دليل لـ فوق مستودع ملف و مساحة العمل خارج ملف؛ ملخص توجيه فقط إرسال مسار و سطر عدد. يجب يأخذ هذا صنف محتوى إبقاء في Host فوق نشر ينبغي يأخذ هذا إضافة تركيب خروج ذهاب.
- تراجع تحويل لـ كامل ملف استبدال مقابل مقارنة يحمل اثنان جانب الكل سطر، الأكثر كثير اثنان ضعف `maxFileBytes`.
- Windows مسار في `path` في إبقاء أصلي قسم فصل رمز؛`display` بداية نهاية استخدام مائل عمود قسم فصل.
