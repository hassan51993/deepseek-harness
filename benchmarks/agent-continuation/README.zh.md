## عام وصف

في لا استخدام شبكة شبكة خدمة أو الذي سجل مستخدم بيانات حال حال تحت، قياس كمية طويل تاريخ طلب معالجة، بارد بدء أداة سري تجميع نوع متابعة حديث و تكرار اكتشاف غير نشط حركة fork فرعي جلسة.SDK تغيير جسم عبر قد إصدار sdk-minimal profile و صريح editor patch تنفيذ 100 عدد جولة و 800 مرة حقيقي ملف قراءة؛ أخرى حالة استخدام عزل خلفية خدمة صار هذا. كل حالة استخدام متساو لا تصيير متصفح.

## تشغيل

في مستودع أصل دليل استخدام `pnpm run build:bench` بناء مكتبة و worker، لكن بعد تشغيل `pnpm exec vitest run --config vitest.bench.config.ts benchmarks/agent-continuation/agent-continuation.bench.ts`. لا يلزم يجعل حساب وقت تشغيل و بناء أو أخرى أساس دقيق إعادة تراكم.

اختبار تقرير إبلاغ الكل خمسة عدد جديد عملية مثال هذا،CPU نوع رقم، متاح و سطر درجة، منصة/هيكل بنية و Node/V8 إصدار، و قيد مرور مراجعة فحص في موضع عدد ميزانية. دليل و أداة متابعة حديث حالة استخدام متساو استخدام معيار حمل إدارة CI 900 ms مدة نظر قيمة و 1.25× بقية كمية (1,125 ms) ؛ طلب تاريخ استخدام مفرد وحيد مراجعة فحص 297 ms حمل إدارة حد أعلى ([دليل](../../.agents/notes/implemented/simplification/2026-09-06-agent-request-freeze-evidence.zh.md)) ،SDK متابعة حديث استخدام مشاركة اعتبار آلة جهاز تقليص وضع.worker فشل وقت تقرير إبلاغ خروج حالة، إشارة، مهلة و stderr؛ فشل وقت أيضا سوف حذف مؤقت أصل دليل. مطلوب أساس دقيق عبر طريق تلقائي اكتشاف هذا ملف.

## قياس كمية

[workload.ts](workload.ts) مسؤول تعريف دمج صار صيانة درجة. ذلك حالي بديل تاريخ في أول عدد خطوة مستخدم إدخال قبل إبقاء فارغ system رأس عقدة، لذلك متابعة حديث نص التوجيه سوف استبدال هذا رأس عقدة بينما لا نقل حركة تاريخ رسالة.[Agent Note](../../.agents/notes/implemented/testing/2026-09-06-backend-continuation-performance.zh.md) مسؤول شرح حساب وقت نهاية نقطة، تدقيق دقيق دليل، داخل تخزين حل تفسير و ترتيب حذف بند. نموذج مهايئ لا تنفيذ مزود تسلسل تحويل أو شبكة شبكة استدعاء؛ تجميع صار حالة استخدام عبر حقيقي أداة تنفيذ خط الإنتاج تشغيل دمج صار أداة جسم،SDK profile تغيير جسم فإن تنفيذ حقيقي ملف قراءة.
