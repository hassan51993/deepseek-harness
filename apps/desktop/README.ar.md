# DeepSeek Harness طاولة وجه طرف

[English](README.md) | العربية

طاولة وجه تطبيق هو كامل dsh Web تطبيق خارج واحد طبقة Electron قشرة.Electron RunAsNode عملية فرعية بدء مشترك profile runner،Electron قيام أي من `dsh-app://app/` تحميل تحزيم داخل Web مدخل. مشترك تحميل صفحة انتظار Host بدء حقن، لكن بعد في نفس وثيقة في بدء عميل.Electron سوف تطبيق HTTP طلب تحويل إرسال إعطاء قد إقرار إثبات Web Host؛WebSocket تدفق اتصال إلى هذا Host، فقط لـ ملكية تطبيق نافذة مرفق إضافة اعتماد.Node IPC تحمل تحميل بدء حقن، حينئذ خيط و إغلاق.Desktop افتراضي استخدام طرف فتحة `19387`، و Web `3080` قسم فتح؛ يمكن عبر `webserver.config.port` patch تغطية.

تطبيق قائمة مفرد رقم واحد بند “**صلة في DeepSeek Harness**” فتح Electron أصلي صلة في وجه لوح، عرض تطبيق رسم علامة، منتج اسم و حالي تثبيت إصدار إصدار. قائمة مفرد نص سجل تتبع مع طاولة وجه قشرة لغة.macOS من تطبيق حزمة قراءة رسم علامة، لذلك لم تحزيم تطوير بدء سوف عرض Electron رسم علامة؛Windows استخدام مع حزمة توزيع PNG.

Desktop محلي أصلي دليل مسار فتح ربط تطبيق نافذة Electron ملف مشبك محادثة إطار، و أولا استعادة، عرض و تجمع تركيز هذا نافذة. تزامن طلب مشترك استخدام واحد محادثة إطار؛ إلغاء لا إرجاع مسار، فشل بعد يمكن إعادة محاولة. عادي Web استخدام Host اختيار جهاز. تصفح تصفح نمط صف خروج Host دليل.Linux نقص قليل zenity أو kdialog وقت، تلقائي اختيار استخدام تصفح تصفح نمط، لا استخدام Electron محادثة إطار.

Creator و Web Plugin Manager في Electron Node نمط تحت استخدام Desktop داخل وضع pnpm، بلا حاجة PATH في وجود pnpm. خاص Node بدء جهاز بيئة فقط تطبيق في حزمة عملية.

## صلة مفتاح تقنية فن قرار

تصميم معلم أصل مسودة يقع في `resources/icon.png` و `resources/icon.svg`؛ منصة ملائم إعداد إبقاء حوت سمك و تدريجي تغيير، قسم آخر يقع في `resources/icon-windows.*` و `resources/icon-macos.*`. سوف كل منصة SVG توجيه خروج لـ نفاذ واضح 1024×1024 PNG.electron-builder لـ Windows تطبيق، تثبيت برنامج و إزالة برنامج توليد كثير مقياس قياس ICO([Windows رسم علامة اشتراط](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction)). تثبيت صفحة في اثنان نوع رئيسي عنوان تحت استخدام مطابقة رسم سجل؛ إزالة برنامج فرح استقبال و إتمام صفحة مشترك استخدام `installer/assets/uninstaller-sidebar.png`، دقيق تجهيز مرحلة مقطع سوف ذلك تحويل لـ 164×314 BMP.

macOS PNG استخدام حمل إبقاء أبيض دائرة زاوية قاع لوح، توفير نقل موحد ICNS تحزيم استخدام، يتضمن الأكثر عال 1024 مثل عنصر يمثل. هو هو مسطح مستو رسم علامة، و غير Icon Composer وثيقة.Apple [تطبيق رسم علامة إشارة جنوب](https://developer.apple.com/design/human-interface-guidelines/app-icons) اشتراط نحو Icon Composer توفير لم حجب غطاء رسم طبقة؛ هذه إدخال حاجة في macOS فوق مفرد وحيد توجيه خروج، لا يستطيع إعادة استخدام قد فعل دائرة زاوية ICNS رسم سجل. إصدار قبل يجب في دعم حمل macOS إصدار في تحقق استلام Finder و Dock عرض فاعلية نتيجة.

### داخل وضع مساحة العمل اعتماد

Windows توقيع تحزيم إبقاء صالح فوق تنقل توقيع، و في تنفيذ خطر دخان فحص قبل، لـ رقم واحد جهة وقت التشغيل في لم توقيع PE يمكن تنفيذ ملف،DLL،Python توسيع و Node إضافة تكملة توقيع. كل جديد توقيع يجب مطابقة إعداد إثبات كتاب كما حمل ختم الوقت؛ قد لديه توقيع بلا فاعلية، توقيع خطأ أو تحقق توقيع خطأ كل سوف إيقاف هذا جولة تنفيذ، لا تلقائي إعادة محاولة.electron-builder فقط لديه في تحقق نسخ بعد وقت التشغيل يمكن تنفيذ ملف توقيع، كما ملف و قد دقيق تجهيز مصدر ملف تدريجي بايت متسق بعد، عندئذ إبقاء ذلك توقيع، تجنب تجنب نسخ مورد وقت تكرار توقيع. فحص تغطية decimal،XML،LZMA،UUID،numpy و pandas. تطوير، فقط دقيق تجهيز و لم توقيع بناء لا استخدام صلب عنصر أمر لوحة، ممكن يتم Windows شفرة كامل صفة سياسة منع توقف؛ أي بناء نمط كل لن إغلاق هذا سياسة. خطر دخان فحص عبر لا بديل جدول كل توسيع أو مؤسسة عمل سياسة كل توافق.

Desktop يحمل مستقل Python،Node.js و pnpm توزيع حزمة.Python يتضمن numpy،pandas،python-docx،python-pptx،openpyxl،Pillow،lxml،XlsxWriter و ذلك كامل اعتماد.`load_workspace_dependencies` أداة أول مرة استخدام وقت، سوف هذا ناتج مغادرة خط تثبيت إلى `$DSH_HOME/dsh-runtimes/dsh-primary-runtime`(عبر معتاد لـ `~/.dsh/dsh-runtimes/dsh-primary-runtime`) ، و إرجاع حل تفسير جهاز،pnpm نص برمجي و مكتبة دليل قطعا مقابل مسار، و سجل داخل وضع توزيع حزمة اسم و إصدار `pythonDistributions`. إصدار تقرير إبلاغ لا يتضمن مستخدم ذاتي سطر تثبيت حزمة.Office مهمة افتراضي استخدام هذه مكتبة، مستخدم أو مساحة العمل إشارة أمر إشارة تحديد أخرى بيئة وقت التزام دوران ذلك اشتراط.pnpm نص برمجي عبر إرجاع Node يمكن تنفيذ ملف تشغيل. إرجاع Node مكتبة دليل لـ مع حزمة تسليم مكتبة مسبق إبقاء، لا هو pnpm عام تثبيت دليل.

Desktop افتراضي تسجيل `office-docx`،`office-pptx` و `office-xlsx`. هذه تقنية قدرة استخدام داخل وضع Python مكتبة إنشاء ملف و إجراء تحديد نقطة تحرير، مع بعد إعادة فتح ملف، و في تسليم قبل تشغيل مشترك بنية فحص جهاز.PowerPoint إنشاء و تحرير استخدام python-pptx. تقنية قدرة مورد نسخ إلى ASAR خارج `runtime/office-skills`، يجعل Python يمكن قراءة فحص جهاز. متاح `render_document` أداة يمكن تكملة ملء نظر شعور فحص؛ نقص قليل هذا أداة لا عائق عائق إنشاء عمل أو تسليم. فحص نطاق و حد رؤية [Office تقنية قدرة حزمة](../../packages/skill/skill-office/README.ar.md).

هذا ناتج مع Desktop إصدار إصدار.`runtime.json` سجل Desktop إصدار، هدف منصة، مكون و Python توزيع حزمة إصدار، و الذي اختيار هدف قفل تحديد ناتج إدخال و تجميع صيغة ملخص. توزيع حزمة اسم حسب PEP 503 عودة واحد تحويل؛ اسم عودة واحد تحويل بعد تكرار، أو numpy/pandas مكون إصدار و توزيع حزمة إصدار اندفاع مفاجئ وقت، بيان سوف يتم رفض. مطابقة تثبيت سوف يتم إعادة استخدام؛ اعتماد أو ضغط حزمة تغير بعد، أي جعل Desktop إصدار ثابت، أيضا سوف في كامل مؤقت تخزين فرعي هذا إتمام بعد استبدال دليل. لا يحتوي ملخص قديم بيان سوف في تحت مرة تثبيت وقت يتم استبدال. مستخدم ذاتي سطر إضافة Python حزمة فقط في ناتج هوية متسق وقت إبقاء. دليل استبدال فشل وقت إبقاء قبل تثبيت؛ حل تفسير جهاز ما زال في وقت التشغيل،Windows ممكن رفض استبدال.

Desktop خاص `runtime/bin` دليل فقط إضافة إلى حزمة تثبيت عملية، لا دخول PTC و agent shell من Host وراثة PATH. هذا أداة لا تعديل PATH، بيئة متغير أو مستخدم حزمة إدارة جهاز إعداد.pnpm عام حزمة، أمر مدخل و store إبقاء ذاته قيمة افتراضية و مستخدم ضبط، يشمل بيئة لا دعم حمل عام تثبيت وقت أصلي خطأ. لا توفير مستقل اعتماد تحديث جهاز.[رقم واحد جهة Runtime قرار](../../.agents/notes/implemented/feature/2026-09-14-desktop-primary-runtime.ar.md) سجل هذه اختيار.

Node دقيق تجهيز داخل وضع حل تفسير جهاز و Python مكتبة، بلا حاجة نظام Python أو pip.[تحت تحميل قفل](scripts/primary-runtime-lock.json) ثابت حل تفسير جهاز ضغط حزمة،Python توزيع حزمة إصدار و هدف منصة wheel URL و ها أمل؛pnpm استخدام Desktop بناء اعتماد قفل. كل هدف wheel ملف اسم يجب و توزيع حزمة إصدار متسق. الذي اختيار هدف،wheel سجل و توزيع حزمة خريطة داخلي مفتاح ترتيب، و wheel بند ترتيب كل سوف أثر ناتج هوية، تحرير وقت يجب إبقاء؛ قفل ملف قمة طبقة مفتاح ترتيب لا أثر هذا هوية. مكتبة wheel حل ضغط إلى site-packages، كل wheel `.data/scripts` دليل إبقاء مساعد مساعدة ملف، لا توليد أمر سطر حزمة تركيب جهاز. أخرى تثبيت خطة سوف يتم رفض. هذا آلة هدف فحص في تنظيف مؤقت تخزين دليل بعد و macOS توقيع بعد تحقق قفل تحديد wheel تجميع دمج و إصدار، سماح حل تفسير جهاز ذاتي حمل pip، و فحص Python إصدار،Office وثيقة قراءة كتابة و اعتماد كامل صفة، لا كتابة بايت رمز. مستقل Node يمكن تنفيذ ملف نيل نيل V8 الذي يحتاج JIT إذن. عبر هدف تنفيذ و توقيع تثبيت حاجة مقابل إصدار رئيسي آلة.`dev:desktop` و `start:desktop` كل سوف في بدء Electron قبل دقيق تجهيز `.desktop-build/targets/<target>/runtime/primary-runtime`؛ أول مرة دقيق تجهيز ممكن حاجة تحت تحميل قفل تحديد اعتماد. دقيق تجهيز لم إتمام وقت، بدء أمر لا يستطيع تقرير إبلاغ نجاح خروج.

## تثبيت ملكية

Electron يملك `$DSH_HOME/profiles/desktop`. ذلك `dependencies` يتضمن pnpm تثبيت حزمة؛`dsh.profile.bundles` يتضمن داخل وضع bundle، بعد وصل قد تفعيل إضافة. توقيع تطبيق من `resources/app.asar/dsh` توفير dsh، خاص Desktop Host و ذلك إنتاج اعتماد. تحزيم تطبيق اختيار runtime profile تحليل، لا إنشاء حزمة رابط؛ تطوير profile استخدام نظام الملفات رابط. مضيف و إضافة في نفس عدد Electron Node نمط عملية في تنفيذ؛Desktop لا تفعيل `--preserve-symlinks`.CLI لا يستطيع بدء أو تعديل هذا profile.

تطبيق preload كشف بدء حينئذ خيط، يؤدي أمر بدء فشل فوق تقرير و أصلي دليل اختيار. منتج صفحة أيضا نيل نيل Desktop علامة، تحديث عرض بيانات و فتح أصلي تأكيد عملية، لا يستطيع اختيار تثبيت ناتج أو تخويل تثبيت. إضافة إدارة استخدام Web تطبيق مرور مرور إقرار إثبات HTTP API؛Electron لا توفير إضافة إدارة IPC أو مستقل إدارة صفحة.

منتج UI إبقاء Web عملية، يشمل عبر مشترك إقرار إثبات HTTP توجيه تنفيذ “فتح طريقة…”.Desktop استخدام Web تلقائي دليل اختيار آلية، و بـ مشترك Web نموذج لوح bundle قائمة ابتدائي تحويل جديد profile.

Electron أصل حسب تطبيق لغة اختيار نوع تحويل إنجليزي نص أو العربية shell نص سجل، و رجوع إلى إنجليزي نص. في Windows فوق، رئيسي وثيقة لغة سوف تحديث طاولة وجه قائمة مفرد، استعادة و تحديث تلميح. مستودع Client UI i18n فحص تغطية طاولة وجه طرف شفرة المصدر.

Windows استخدام 40 DIP قمة شريط، إبقاء أصلي نافذة حسب زر، لون لون مع تطبيق ضبط لون لوح تزامن. جانب شريط فتح صلة جانب محلي تحويل “تطبيق” و “تحرير” مدخل فتح أصلي نابض خروج قائمة مفرد. فقط عند تطبيق إطار هيكل إصدار shell overlay مقعد موضع بعد عندئذ تركيب قائمة مفرد، بدء تحميل خلال لا عرض.“تطبيق” توفير فحص تحديث و خروج؛ “تحرير” نحو حالي تحرير جهاز إرسال مقابل حسب مفتاح، توفير سحب إلغاء، إعادة فعل، قص قطع، نسخ، لصق لصق، حذف و كل اختيار. إضافة إدارة استخدام رئيسي تطبيق “إضافة” صفحة. حسب Alt لن ظهور مقدار خارج أصلي قائمة مفرد سطر. أخرى منصة إبقاء أصلي قائمة مفرد. يمكن تحرير منطقة مجال إبقاء سريع سريع مفتاح و لا حمل سريع سريع مفتاح علامة ملاحظة يمين مفتاح قائمة مفرد؛ أمر متاح حالة من Chromium توفير، اختيار في فقط قراءة نص توفير “نسخ” أمر.

macOS فوق ذاتي تعريف تطبيق قائمة مفرد أيضا سوف إعلان معيار File،Window و تطبيق قائمة مفرد، لأن استبدال Electron افتراضي قائمة مفرد سوف فقد إسقاط Close Window(⌘W) ،Minimize(⌘M) و Hide(⌘H).Linux إبقاء تطبيق قائمة مفرد و Edit قائمة مفرد.

### وقت التشغيل و إضافة تنشيط

توقيع مورد في `resources/app.asar/dsh/desktop-runtime.json` ربط shell إصدار،Electron Node إصدار، منصة، هيكل بنية، مشترك حزمة إصدار و نهائي ملف بيان. بدء قراءة بيانات وصفية، و فحص مشترك حزمة سجل. إصدار schema،shell إصدار، هدف توافق صفة و ملف كامل صفة في تحزيم وقت تحقق. أول مرة بدء لن يأخذ نواة قلب حزمة نسخ إلى profile تخزين أو عبر pnpm تثبيت نواة قلب حزمة.

1. رئيسي نافذة في profile دقيق تجهيز أو خلفية بدء قبل، من تحزيم ساكن حالة مورد عرض مشترك Web تحميل صفحة. مشترك profile ابتدائي تحويل إنشاء ناقص manifest، فارغ مستخدم patch و pnpm workspace ملف، لا تغطية قائم ملف.
2. إنتاج إصدار في بدء Host قبل، تنظيف حالي تشغيل حزمة بيان أو قد سجل Desktop حزمة بيان في كل حزمة profile فرعي هذا و رجوع رابط، معا حذف مقابل اعتماد إعلان و overrides؛ تنظيف تغيير حزمة حالة وقت إسقاط قفل ملف. أخرى إضافة ملف، إعداد و إصدار إبقاء؛ تطوير نمط قفز مرور هذا تنظيف، بدء وقت لا تشغيل pnpm.
3. Electron Node إصدار، منصة أو هيكل بنية تغير وقت إبقاء قد تثبيت إضافة. أصلي توافق صفة مشكلة في تحميل وقت تقرير خطأ، يمكن عبر pnpm إصلاح.
4. رئيسي تطبيق “إضافة” صفحة عبر مشترك[إضافة إدارة جهاز](../../packages/boot/plugin-manager/README.ar.md) عملية Desktop profile. حزمة عملية استخدام داخل وضع pnpm و صحيح معتاد مستخدم و profile إعداد.
5. مشترك إدارة جهاز مسؤول تثبيت خطأ، تنشيط و إعادة بدء اشتراط. أي جعل Host لا يمكن بدء، أصلي استعادة ما زال يمكن منع استخدام رقم ثلاثة جهة bundle.

[Web إضافة UI](../../packages/client/ui-plugin-manager/README.ar.md) مسؤول إدارة واجهة.Desktop profile ابتدائي تحويل و استعادة إبقاء قد تثبيت إضافة ملف.

رئيسي نافذة إنشاء، رئيسي وثيقة تحميل،preload، مصير،Web ابتدائي تحويل أو خلفية يؤدي أمر فشل، سوف في كل تطبيق عملية في فتح مرة أصلي استعادة محادثة إطار. محادثة إطار عرض أول مرة خطأ نهاية ذيل حد طويل ملخص، علامة واضح قطع قطع حال حال، و توفير خروج، إعادة بدء، منع استخدام رقم ثلاثة جهة إضافة، تجهيز نسخة profile patch و إعادة بدء. بدء فشل إبقاء Web تحميل صفحة و حركة رسم؛ تشغيل في فشل إبقاء حالي صفحة. مسبق مدة إغلاق، إلغاء تنقل و عادي طلب خطأ لن إطلاق استعادة. مشترك Web إضافة إدارة جهاز تقرير إبلاغ حزمة عملية خطأ؛ إضافة تغيير بعد Host بدء فشل سوف دخول أصلي استعادة. لا عبر بدء مهلة دفع قطع لذا عائق. يتضمن `listen EADDRINUSE` استماع فشل بـ خروج أخرى صحيح في تشغيل DSH نسخة تلميح بديل تشخيص و إعادة تركيب بناء اقتراح، فقط توفير خروج و إعادة بدء.

أصلي نابض نافذة تفصيل حال الأكثر كثير يتضمن 1,200 عدد UTF-16 شفرة وحدة و ثمانية سطر تشخيص؛ كامل قد تقرير إبلاغ خطأ كتابة Electron تحكم منصة.Host خطأ تشخيص فقط إبقاء stderr إخراج الأكثر بعد 64 Ki عدد محرف. أكثر مبكر إخراج سوف يتم إسقاط، تجنب تجنب طويل مدة تشغيل Host جعل قشرة تشخيص مؤقت اندفاع منطقة بلا حد زيادة طويل.

استعادة عملية انتظار Host إغلاق بعد عندئذ تعديل إضافة تفعيل حالة. أصلي استعادة عملية في profile أمر خدمة قفل داخل استدعاء مشترك app-boot استعادة دالة. هو منع استخدام رقم ثلاثة جهة bundle، و سوف profile `cordis.patch.yml` إعادة تسمية لـ `cordis.patch.yml.bak-<timestamp>`(إعادة اسم وقت إلحاق ترتيب رقم) ، بلا حاجة تحليل؛ تحت مرة بدء إنشاء فارغ patch. قد تثبيت حزمة و قد لديه تجهيز نسخة إبقاء.home درجة patch ثابت.Electron تحكم منصة سجل تجهيز نسخة مسار (أو أصل ملف لا وجود) و home درجة patch لم تعديل.profile بيانات بلا فاعلية، إعادة تسمية فشل أو كتابة فشل سوف بصفة استعادة عملية خطأ تقرير إبلاغ؛ قد إتمام تعديل إبقاء،Desktop لن زائف تركيب استعادة نجاح بعد إعادة بدء.Desktop لا توفير profile إعادة وضع عملية أو ينبغي عاجل HTML وثيقة.

حزمة أمر خدمة وحيد احتلال `$DSH_HOME/profiles/desktop/lock`، مباشر إلى pnpm عملية خروج.pnpm تشغيل قبل، مشترك وحدة رجوع مساعد مساعدة دالة فقط حذف ذلك يملك رابط، إبقاء pnpm إدارة دليل؛ تطوير Host في بدء وقت إعادة بناء الذي يحتاج رابط. رابط تنظيف إبقاء هدف دليل. أصلي بناء التزام دوران pnpm إعداد بناء سياسة؛ إصدار دقيق تجهيز استخدام مستقل بناء مدة سماح قائمة.

## تطوير

`dev:desktop` سوف بناء حالي Host، عميل bundle،Web قبل طرف و Electron قشرة، يأخذ قد بناء CLI حزمة، خاص Desktop Host حزمة و ذلك workspace اعتماد إسقاط لـ مرة صفة طاولة وجه npm مشروع، لكن بعد مباشر بدء Electron؛ هذا بند مسار لا من npm تحليل dsh:

```sh
pnpm run dev:desktop
```

تطوير Harness حالة افتراضي كتابة `apps/desktop/.desktop-build/development/home`، مرة صفة npm مشروع يقع في `apps/desktop/.desktop-build/development/project`،Electron متصفح بيانات فإن يقع في `apps/desktop/.desktop-build/development/electron-user-data`. لذلك، جلسة، ضبط، اعتماد، حزمة رابط و متصفح بيانات كل لن دخول مستخدم صحيح معتاد استخدام Harness home؛ صريح `DSH_HOME` فقط سوف استبدال تطوير Harness home.Renderer DevTools افتراضي تلقائي فتح،Main،Renderer و dsh Host ضبط تجربة طرف فتحة اعتماد مرة لـ 9229،9222 و 9230.`DSH_DESKTOP_MAIN_INSPECT_PORT`،`DSH_DESKTOP_RENDERER_DEBUG_PORT` و `DSH_DESKTOP_HOST_INSPECT_PORT` يمكن استبدال هذه طرف فتحة،`DSH_DESKTOP_OPEN_DEVTOOLS=0` فإن إبقاء Renderer ضبط تجربة نافذة إغلاق.

صريح بناء إتمام بعد،`start:desktop` سوف إعادة توليد مرة صفة مشروع، و قفز مرور بناء مباشر بدء قد لديه ناتج:

```sh
pnpm run start:desktop
```

Workspace تطوير استخدام Electron RunAsNode تشغيل حالي CLI و خاص Desktop Host حزمة، إضافة إدارة و استعادة استخدام `$DSH_HOME/profiles/desktop`، و مرة صفة مساحة العمل وقت التشغيل قسم مغادرة.Host في تطوير و تحزيم بناء في كل استخدام runtime وحدة تحليل، لا إنشاء رسمي جهة حزمة fallback رابط؛ تطوير من تثبيت حزمة (يشمل رابط) إبقاء أصلي أولوية درجة. حاجة تحقق Electron RunAsNode، داخل وضع pnpm، داخل وضع dsh مورد، إضافة تثبيت و إصلاح وقت، ينبغي تشغيل لم غلاف تركيب تثبيت جهاز تطبيق دليل.

### إصدار إصدار

كل مرة Desktop تحزيم قبل، رقم واحد خطوة كل يلزم و حالي مستخدم تأكيد كامل رقم الإصدار. فحص الذي اختيار نشر بيئة،dsh أساس أساس إصدار، إبقاء إصدار سجل و قد إصدار كائن، مجددا رفع خروج دقيق تأكيد إصدار توفير مستخدم تأكيد. مستخدم تأكيد قبل، لا نيل تعديل إصدار بيت عائلة بيان أو بدء تحزيم؛ فقط اختيار نشر بيئة لا بديل جدول مستخدم قد إقرار يمكن رقم الإصدار.

تعديل أي بيان قبل، سجل حالي dsh إصدار بصفة أساس أساس إصدار.production Desktop استخدام تماما نفسه إصدار، يشمل منها `alpha`،`beta` أو `rc` معرف.test إصدار إبقاء كامل مسبق إصدار أساس أساس إصدار و إلحاق `.YYYYMMDD.index`؛ مستقر أساس أساس إصدار فإن إلحاق `-test.YYYYMMDD.index`.

| dsh أساس أساس إصدار | production Desktop | test Desktop عرض مثال |
|---|---|---|
| `0.1.6-alpha.1` | `0.1.6-alpha.1` | `0.1.6-alpha.1.20260916.1` |
| `0.1.6-beta.2` | `0.1.6-beta.2` | `0.1.6-beta.2.20260916.1` |
| `0.1.6-rc.3` | `0.1.6-rc.3` | `0.1.6-rc.3.20260916.1` |
| `0.1.6` | `0.1.6` | `0.1.6-test.20260916.1` |

يوم مدة استخدام فعلي إنشاء وقت Asia/Shanghai يوم مدة. كل أساس أساس إصدار، كل يوم ترتيب رقم من 1 بدء، فحص إبقاء إصدار سجل و قد إصدار كائن بعد تمرير زيادة؛ أبدا إعادة استخدام قد إصدار إصدار. فقط من سجل أساس أساس إصدار إرسال توليد مرة، لا من قد لديه اختبار بعد لاحقة بيان متابعة إلحاق. نهائي أصل حزمة،Desktop، داخل وضع dsh، خاص Desktop Host و أخرى إصدار بيت عائلة بيان يجب الكل استخدام نفس عدد إرسال توليد إصدار.test توزيع لا إصدار مقابل بلا بعد لاحقة أساس أساس إصدار.

إصدار إرسال توليد لا تغيير ثابت تحديث عبر طريق، أيضا لا تغيير `nightly.yml` / `nightly-mac.yml` ملف اسم.SemVer ترتيب ترتيب لـ `0.1.6-alpha.1 < 0.1.6-alpha.1.20260916.1 < 0.1.6-alpha.2`، مستقر أساس أساس إصدار اختبار إصدار منخفض في هذا مستقر إصدار. عميل فقط قبول أكثر عال إصدار: استبدال feed لا يمكن يجعل قد تثبيت مقارنة عال إصدار تحديث إلى مقارنة منخفض تصحيح صحيح إصدار. هذا صنف عميل حاجة يد حركة تثبيت؛ إبقاء تلقائي تخفيض إغلاق.[إصدار قرار](../../.agents/notes/implemented/process/2026-09-16-desktop-release-version-derivation.ar.md) حل تفسير لـ ماذا لا يستطيع استخدام عبر طريق اسم استبدال مسبق إصدار معرف.

تحزيم، فوق نقل و يد حركة macOS توقيع فحص استخدام `apps/desktop/.env.windows` أو `.env.macos`، من هدف منصة اختيار. نسخ مقابل [Windows نموذج لوح](.env.windows.example) أو [macOS نموذج لوح](.env.macos.example) ، ملء كتابة هذا آلة إعداد؛Git تجاهل اختصار هذا اثنان عدد محلي ملف، تثبيت ناتج أيضا لا يتضمن هو جمع. إصدار حقل فقط من هدف ملف قراءة، لا رجوع إلى نظام أو shell في نفس اسم متغير؛`PATH`، بديل إدارة و بناء أداة بيئة ما زال إبقاء. ملف استخدام UTF-8، دعم حمل BOM؛ متبادل مقابل إثبات كتاب،SignTool،Apple API Key و مفتاح مفتاح سلسلة مسار بـ `apps/desktop` لـ أساس دقيق، متغير قيمة لا فعل shell توسيع، يتضمن `#` أو فارغ إطار سري رمز حاجة جذب رقم.CI نفس مثال في تشغيل قبل توليد هدف ملف.

كل بند تحزيم أمر في بناء و تحت تحميل قبل فحص تطبيق ID، تحديث عنوان و هذا نمط حاجة توقيع إعداد.macOS فحص هوية،Team ID، واحد طقم كامل عام إثبات اعتماد،`CSC_LINK` إشارة تحديد يمكن قراءة محلي p12 ملف، صريح إعداد `CSC_KEY_PASSWORD`، و مرجع API Key و مفتاح مفتاح سلسلة ملف؛Windows فحص عام شفرة توقيع إثبات كتاب،SignTool ملف، حاوية اسم و PIN صيغة. فقط دقيق تجهيز Windows مورد أو صريح لم توقيع تحزيم لا اشتراط توقيع اعتماد. إعداد فحص لا تحقق PIN هل صحيح تأكيد،Token هل تسجيل تسجيل، مفتاح مفتاح سلسلة هل حل قفل أو Apple هل قبول اعتماد؛ فعلي توقيع و عام إثبات مسؤول هذه فحص. مفرد وحيد تشغيل نفسه فحص:

```sh
pnpm --dir apps/desktop run check:package
```

بلا حاجة رفع قبل تنفيذ `prepare:desktop`:

```sh
pnpm run package:desktop
```

إصدار تلقائي تحويل استخدام ثابت هدف أمر، تأكيد حفظ وقت التشغيل دقيق تجهيز،dsh دقيق تجهيز و electron-builder استقبال نفسه منصة و هيكل بنية:

```sh
pnpm run package:desktop:mac:arm64
pnpm run package:desktop:mac:x64
pnpm run package:desktop:win:x64
```

macOS arm64 أمر اشتراط Apple Silicon.macOS x64 أمر يمكن في Intel macOS أو حمل Rosetta Apple Silicon فوق تشغيل.Windows x64 أمر اشتراط Windows x64.Linux لا هو تلقي دعم حمل Desktop إصدار هدف.

كل هدف كل في `apps/desktop/.desktop-build/targets/<target>/` تحت يحتفظ ذاتي ذات تحزيم إدخال، قد دقيق تجهيز وقت التشغيل، حزمة تجميع دمج،dsh اعتماد شجرة،pnpm دقيق تجهيز حالة، لم تحزيم تطبيق، تحديث بيانات وصفية و نهائي ناتج.Electron عودة ملف ذاكرة مؤقتة متابعة من `.desktop-build/downloads` مشترك، لأن كل عودة ملف ملف اسم كل يتضمن إصدار، منصة و هيكل بنية، و كما في حل حزمة قبل مرور مرور تحقق. هدف بناء أبدا قراءة أخرى هدف متغير دقيق تجهيز حالة.

### وقت التشغيل ملف غربلة اختيار

Desktop في محلي تحزيم مساحة العمل حزمة، و عبر هدف ربط ربط Node و pnpm تثبيت خارجي اعتماد.[Desktop ملف سياسة](scripts/runtime-file-policy.ts) مع بعد في توقيع و كامل صفة غلاف تركيب قبل مرور ترشيح غير ممكن تغيير `resources/app.asar/dsh/node_modules` فرعي هذا. هو ترتيب حذف TypeScript إعلان، قد تعرف آخر JavaScript/CSS/TypeScript source map،TypeScript بناء ذاكرة مؤقتة،Domino اختبار دليل، اختيار تحديد أصلي تحرير ترجمة جهاز إخراج و أخرى منصة node-pty مسبق بناء ملف. هو إبقاء وقت التشغيل JavaScript، أصلي وحدة و ذلك DLL/EXE مساعد مساعدة ملف،WASM، لم معرفة مورد، سماح يمكن إثبات و notices. هذا سياسة لا تعديل npm tarball، ربط ربط حزمة إدارة جهاز أو مستخدم تثبيت إضافة ملف.

[Office تحويل مزود](../../packages/document/office-to-pdf/README.ar.md) يحمل هدف قد إعلان أصلي جذب محرك؛kit لم إعلان مطابقة أصلي هدف وقت يحمل WASM جذب محرك. دقيق تجهيز مرحلة مقطع في تحزيم قبل رفض نقص قليل هدف جذب محرك حال حال. جذب محرك مورد، سماح يمكن إثبات و notices إبقاء في وقت التشغيل اعتماد شجرة في.

تحزيم تطبيق تشغيل تحرير ترجمة بعد JavaScript و مسبق توليد Typert بيانات وصفية، لا تحرير ترجمة TypeScript إضافة. شفرة المصدر درجة ضبط تجربة تنقل و تحرير جهاز إعلان ما زال يمكن من تطوير حزمة في نيل أخذ.[نسخ قاعدة اختبار](tests/runtime-file-policy.spec.ts) تغطية ترتيب حذف بند و إبقاء مورد؛`prepare:dsh` في Host smoke و نهائي بيان تحقق قبل، استخدام Electron RunAsNode تنفيذ[ناتج smoke](tests/fixtures/runtime-payload-smoke.mjs).

Windows إصدار تحقق استلام أيضا يحتاج في Desktop بناء بعد يد حركة تشغيل[دليل و استبدال فحص](scripts/smoke-windows.ps1). سوف `$Makensis`،`$SevenZip` و `$PluginDir` قسم آخر ضبط لـ قفل تحديد إصدار بناء جهاز NSIS تحرير ترجمة جهاز،7-Zip يمكن تنفيذ ملف و x86-unicode NSIS إضافة دليل. من مستودع أصل دليل تشغيل التالي أمر. هو تحقق دليل استبدال و تراجع و اثنان نوع ملف احتلال استخدام استبدال طريقة؛ لا يخص اختبار وحدة عبر طريق.

```powershell
pwsh -NoProfile -File apps/desktop/scripts/smoke-windows.ps1 -Makensis $Makensis -SevenZip $SevenZip -PluginDir $PluginDir
```

Windows تثبيت جهاز أولا سوف جديد إصدار حل ضغط إلى تثبيت دليل جانب حافة، مجددا خروج قديم تطبيق و عبر نفس لفة دليل تعديل اسم إتمام استبدال. نفس مسار ترقية في استبدال نجاح قبل إبقاء قديم دليل؛ حل ضغط فشل وقت قديم إصدار ثابت، استبدال فشل وقت محاولة تجربة استعادة قديم دليل. تثبيت جهاز في بدء قبل تنظيف قديم إصدار تجهيز نسخة. قوي صنع انتهاء تثبيت جهاز أو قطع كهرباء ممكن إبقاء تحت `.new-*` أو `.old-*` دليل؛ مختلف تثبيت موضع أو تثبيت نطاق ترحيل ما زال استخدام electron-builder قديم إزالة جهاز مسار.

### فوق نقل تحديث

test و production `upload:*` فوق نقل في إصدار قبل وضع فحص عبر بعد، قسم آخر إبقاء جديد `.desktop-build/upload-records/<environment>-<target>-*` دليل.`plan.json` سجل هدف، إصدار، كل ملف كبير صغير/SHA-512 و إصدار YAML بايت؛ تحديث قرص `events.jsonl` سجل PUT معنى رسم و متاح استجابة حالة/طلب ID؛`result.json` سجل إتمام نتيجة أو الأكثر بعد فشل مرحلة مقطع. نقص قليل نهائي نتيجة يمثل في قطع أو تخزين غير ممكن استخدام، لا يمثل نجاح. لا سجل اعتماد قيمة، إقرار إثبات رأس أو أصلي SDK خطأ. مراجعة حساب كتابة فشل أي إيقاف لاحق PUT. كل كائن كل بـ مرة تدفق صيغة نهوض خبر COS PUT فوق نقل، و يحمل صريح طويل درجة و Content-MD5؛COS SDK فقط في طلب جسم لا هو تدفق وقت عندئذ سوف إعادة إرسال طلب، فوق نقل جهاز ذاته أيضا لا إعادة محاولة. إبقاء جزء سجل، فحص بعيد طرف حالة بعد مجددا تنفيذ تحت مرة عملية: مهلة أو عودة تنفيذ كتابة فشل لا يستطيع إثبات كائن لم تخزين. هذه سجل فقط في محلي، لا منع اغتصاب تعديل، أيضا لن تلقائي تجهيز نسخة؛ كل مرة إصدار ينبغي سوف هو جمع و بناء دليل واحد نفس عودة ملف إلى تلقي تحكم تخزين. عام شبكة CDN عودة قراءة ما زال هو مفرد وحيد إصدار تحقق استلام، فوق نقل نتيجة واضح علامة لـ `not-performed`.

Windows عملية شخص عضو يمكن في مستودع خارج حفظ CLIXML كائن، منها `SecretId` و `SecretKey` هو مرور DPAPI إضافة سري SecureString حقل.[اعتماد بدء جهاز](scripts/upload-with-credentials.ps1) اشتراط صريح توفير `-CredentialFile` و `-Environment production` أو `test`؛ لا إشارة تحديد `-Upload` وقت، فقط تحقق حل سري و نحو محلي Node عملية فرعية حقن اعتماد، لا إرسال بدء شبكة شبكة طلب. هو اشتراط `PATH` في لديه Node، و استخدام إضافة سري هذا ملف وقت Windows مستخدم و آلة جهاز. واضح نص، فارغ حقل و صاف فارغ أبيض حقل كل سوف فشل. أب عملية بيئة إبقاء ثابت؛ عملية فرعية أولا صاف حذف غير متصل مفتاح و Node مسبق تحميل خيار، مجددا فقط استقبال الذي اختيار COS اعتماد مقابل. أصلي عملية فرعية stderr لن عرض،stdout في اعتماد قيمة سوف يتم حجب غطاء. هذا فحص لا يستطيع إثبات COS تخويل صالح. صريح فوق نقل أيضا اشتراط `-Upload -Target <target> -Bucket <bucket>` و تحت وصف معتاد قاعدة إصدار إتمام قبل رفع؛ حقيقي سحابة طرف فوق نقل ما زال يحتاج إصدار عملية شخص عضو تحقق استلام. هذا بدء جهاز دعم حمل طويل مدة مفتاح، لا دعم حمل STS اعتماد. صريح فوق نقل اشتراط الذي اختيار نشر بيئة و bucket و هدف dotenv ملف و قد إتمام تحزيم سجل متسق، عندئذ سوف إرسال بدء شبكة شبكة كتابة؛ أي جعل dotenv ملف يحتوي لديه أخرى COS مفتاح، أيضا استخدام DPAPI اعتماد مقابل.

`DSH_DESKTOP_AUTO_UPDATE_ENV` معا اختيار تحزيم كتابة URL و لاحق COS فوق نقل بيئة، يمكن أخذ `test` أو `production`؛ نقص حذف لـ `test`. اختبار تحزيم عبر `DOWNLOAD_TEST_ORIGIN` توفير HTTPS origin؛ إنتاج استخدام `https://download.deepseek.com`. فوق نقل عبر `DOWNLOAD_TEST_COS_BUCKET` أو `DOWNLOAD_PROD_COS_BUCKET` توفير الذي اختيار bucket. بيان دليل لـ `dsh-desk/feeds/<target>/`؛ حمل إصدار تثبيت حزمة و blockmap يقع في `dsh-desk/bin/<target>/`. هدف لـ `mac-arm64`،`mac-x64` و `win-x64`.

تحديث هدف و فوق نقل اعتماد كل و الذي اختيار بيئة مقابل:

| بيئة | عام origin | COS bucket | COS اعتماد |
|---|---|---|---|
| `test` أو لم ضبط | `DOWNLOAD_TEST_ORIGIN` | `DOWNLOAD_TEST_COS_BUCKET` | `DOWNLOAD_TEST_COS_SECRET_ID`،`DOWNLOAD_TEST_COS_SECRET_KEY` |
| `production` | `https://download.deepseek.com` | `DOWNLOAD_PROD_COS_BUCKET` | `DOWNLOAD_PROD_COS_SECRET_ID`،`DOWNLOAD_PROD_COS_SECRET_KEY` |

في هدف `.env` في إعداد تحديث عنوان و الذي اختيار COS bucket،SecretId،SecretKey، مجددا تحزيم و فوق نقل نفس عدد هدف:

```sh
pnpm run package:desktop:mac:arm64
pnpm run upload:mac:arm64
```

داخل قياس تحزيم في هدف `.env` في صريح ضبط `DSH_DESKTOP_AUTO_UPDATE_ENV=test` و `DOWNLOAD_TEST_ORIGIN=https://download-test.deepseek.com`؛ فوق نقل استخدام `DOWNLOAD_TEST_COS_BUCKET=bj-toc-download-test-1320056602` و مستقل اختبار اعتماد.test و production كل استخدام ثابت Nightly عبر طريق، نشر اختيار لا توفير عبر طريق تبديل.

قبل مدة داخل قياس حزمة استخدام `test` نشر. فقط لديه صحيح صيغة إصدار عندئذ صريح اختيار `production`؛ أكثر تبديل فوق نقل اعتماد لن تغيير قد لديه تثبيت حزمة تحديث هدف. تحزيم لا حاجة COS اعتماد، سوف منع استخدام electron-builder إصدار، إزالة عملية فرعية COS اعتماد، و كما فقط في توقيع و عام إثبات نجاح بعد سجل إتمام حالة. فوق نقل في قراءة اعتماد قبل تحقق هذا سجل، نشر، هدف، مشترك نفس رقم الإصدار، ملف اسم، كبير صغير و SHA-512. تثبيت حزمة و blockmap أولا في YAML فوق نقل؛ تاريخ كائن متابعة إبقاء. كل إصدار إصدار `nightly.yml` أو `nightly-mac.yml`؛ مستقر إصدار أيضا إصدار إشارة نحو نفسه ناتج `latest.yml` أو `latest-mac.yml`. إصدار YAML استخدام تثبيت حزمة قطعا مقابل URL. فوق نقل جهاز لا ضبط Cache-Control، يشمل COS SDK لا فإن سوف إضافة فارغ رأس جزء: ذاكرة مؤقتة سياسة من نشر أساس أساس ضبط تطبيق مسؤول، بيان لا ذاكرة مؤقتة، تثبيت حزمة ذاكرة مؤقتة مفرد وحيد إعداد. نفس هدف ينبغي سلسلة سطر إصدار، و في إصدار تحقق استلام قبل تحقق عام شبكة ناتج و بيان محتوى.

macOS إعداد استخدام لا بد ملء إصدار بيئة، لن قبول مفتاح مفتاح سلسلة في الأكثر أولا اكتشاف إثبات كتاب. فارغ قيمة، صيغة خطأ Team ID، يتضمن electron-builder لا دعم حمل `Developer ID Application:` بادئة توقيع هوية، و لا كامل عام إثبات اعتماد كل سوف يتم رفض.macOS تحزيم اشتراط قد إعداد هوية و ذلك خاص مفتاح متاح. وقت التشغيل دقيق تجهيز سوف يأخذ هذا هوية، أمان ختم الوقت و hardened runtime تطبيق إلى كل داخل تضمين Mach-O ملف؛ تطبيق توقيع إتمام بعد، عميق درجة صارم إطار فحص سوف رفض أخرى ورقة إثبات كتاب Authority أو Team ID، تحقق عبر عندئذ توليد إصدار ناتج.macOS ثابت هدف تثبيت حزمة أمر لـ قد توقيع تطبيق إنشاء مستقل فرعي هذا، تزامن تنفيذ اثنان بند ناتج تدفق. واحد مسار أولا عام إثبات App و تثبيت بطاقة، مجددا توليد ZIP و ذلك تحديث بيانات وصفية. آخر مسار يأخذ قد توقيع App فرعي هذا غلاف تركيب دخول توقيع DMG، مجددا عام إثبات DMG، تثبيت بطاقة و تحقق؛ منها App لا مفرد وحيد مرفق إضافة بطاقة حسب. فقط لديه اثنان مسار متساو نجاح انتهاء، ناتج عندئذ سوف نقل دخول نهائي دليل و كتابة إصدار إتمام سجل. فقط توليد دليل أمر نفس مثال حاجة عام إثبات اعتماد، و انتظار Apple عام إثبات و App تثبيت بطاقة إتمام.[و سطر عام إثبات قرار](../../.agents/notes/implemented/process/2026-09-09-parallel-macos-notarization.ar.md) مسؤول فرعي هذا عزل و حاوية بطاقة حسب دلالة.`CSC_LINK` يجب إشارة نحو يتضمن Developer ID Application إثبات كتاب و خاص مفتاح محلي p12، لا دعم حمل URL أو Base64 إدخال.`CSC_KEY_PASSWORD` هو ذلك توجيه خروج سري رمز، لا هو Apple حساب رقم أو تسجيل تسجيل سري رمز؛ لم إضافة سري p12 يمكن صريح ملء كتابة فارغ قيمة. بناء قبل، تحزيم مسار تلقائي إنشاء و حل قفل خاص مؤقت مفتاح مفتاح سلسلة، استيراد p12، تخويل توقيع و توقيع توقيع صغير نوع استكشاف إبرة. وقت التشغيل و App توقيع صريح استخدام هذا مفتاح مفتاح سلسلة، بلا حاجة مسبق أولا إعداد أو يد حركة حل قفل تسجيل تسجيل مفتاح مفتاح سلسلة. عملية فرعية فقط استقبال مفتاح مفتاح سلسلة مسار، لا استقبال p12 سري رمز. نجاح أو عادي فشل بعد حذف مؤقت مفتاح مفتاح سلسلة؛ قوي صنع إنهاء بعد من CI تنظيف مؤقت اعتماد.CI من مفتاح تخزين توليد إثبات كتاب ملف و `.env.macos`، حد ملف وصول إذن، و في عمل عمل انتهاء بعد حذف اثنان من. بيئة في `CSC_NAME` و إثبات كتاب اكتشاف ترتيب كل لا يستطيع اختيار إصدار كل من. عام إثبات اعتماد أيضا يمكن استخدام electron-builder دعم حمل كامل Apple ID أو مفتاح مفتاح سلسلة profile طريقة. يد حركة تنفيذ `pnpm --dir apps/desktop run verify:mac-signature -- <path-to-app>` تكرار تطبيق فحص وقت، أيضا يجب توفير اثنان عدد macOS هوية متغير.

macOS توقيع مرة تاريخ حقيقي ملف، لا تتبع مع Framework لين رابط آخر اسم.PAK مورد إبقاء الكل مع مرفق لغة، من خارج طبقة Framework أو تطبيق توقيع سجل كامل صفة، لا تدريجي عدد توقيع.[إصدار سياسة](../../.agents/notes/implemented/architecture/2026-08-25-electron-desktop-packaging-and-updates.ar.md) مسؤول اعتماد رقعة و تحقق اشتراط.

يمكن عبر عام شركة بديل إدارة إضافة سرعة نحو Apple عام إثبات خدمة فوق نقل. بديل إدارة إعداد مشاركة رؤية عام شركة داخلي وثيقة.

### لم توقيع Windows اختبار تثبيت حزمة

في Windows x64 فوق، استخدام كامل لم توقيع تحزيم أمر إجراء محلي تثبيت اختبار:

```sh
pnpm run package:desktop:win:x64:unsigned
```

هذا أمر اشتراط ضبط `DSH_DESKTOP_APP_ID` و أداة تجهيز معتاد قاعدة بناء اعتماد، يشمل تحرير ترجمة أصلي وحدة الذي يحتاج Python و Visual C++ بناء أداة.Python لا في `PATH` في وقت، سوف `PYTHON` ضبط لـ ذلك يمكن تنفيذ ملف مسار. أمر سوف تثبيت حزمة كتابة `.desktop-build/targets/win-x64/unsigned-artifacts/`، حذف تلقائي تحديث إعداد، صاف حذف توقيع اعتماد، كما لا توليد إصدار إتمام سجل. هو لا حاجة EV اعتماد أو تحديث مصدر عنوان. توقيع تحزيم و فوق نقل أمر ما زال التزام دوران صحيح صيغة إصدار اشتراط.

### Windows تثبيت واجهة

Windows تثبيت برنامج استخدام أصلي NSIS صفحة، توفير مضيء داكن إعداد لون، نظام ظل أثر، يمكن تحرير تثبيت دليل، و افتراضي ربط اختيار قيام أي بدء إتمام صفحة. تثبيت فقط موجه إلى حالي مستخدم. نقر تثبيت أو حسب Enter متساو تحقق حالي مسار؛ جديد تثبيت موضع يجب لـ فارغ، غير فارغ موضع يجب هو قد تسجيل تسجيل تثبيت دليل. تلقي أثر تثبيت مسار في برنامج وقت التشغيل عرض نظام تلميح، و إبقاء تطبيق تشغيل؛ أخرى دليل في نفس اسم تطبيق لا منع توقف تثبيت. ساكن صامت تحديث الأكثر كثير انتظار تلقي أثر تطبيق خروج عشرة ثانية، إذا ما زال في تشغيل فإن بـ خروج رمز 2 انتهاء.

رئيسي عنوان في بدء وقت تتبع مع Windows؛ متاح `/THEME=light`،`/THEME=dark` و `/THEME=auto` صريح اختيار إعداد لون. نافذة في صنف لوحة تحكم عنصر دقيق تجهيز إتمام بعد عرض. فرح استقبال صفحة أول مرة ظهور وقت، تثبيت نافذة سوف مرة صفة نقل إلى عادي نافذة قبل جهة؛ إذا تركيز نقطة في أخرى نافذة، مهمة شريط حسب زر سوف وميض وميض تلميح، لكن تثبيت نافذة لن بداية نهاية وضع قمة. دخول درجة قراءة قفل تحديد إصدار 7-Zip حل ضغط جهاز مئة قسم مقارنة؛ دليل استبدال، تسجيل و تنظيف ما زال استخدام محدود تقدير حساب. إضافة حق مئة قسم مقارنة لا بديل جدول باق بقية وقت.NSIS تقرير إبلاغ نجاح بعد، دخول درجة بند استخدام 600 جزء ثانية تكملة ممتلئ و قصير مؤقت عرض 100%، مجددا عرض إتمام صفحة؛ تبديل هدف وقت طويل لـ 750 جزء ثانية. إتمام صفحة إبقاء نافذة موضع. نقر إتمام بعد، تثبيت برنامج أولا إخفاء نافذة، مجددا بدء قد تثبيت يمكن تنفيذ ملف؛ بدء فشل سوف استعادة صفحة بـ توفير إعادة محاولة. دليل استبدال و فشل استعادة التزام دوران فوق نص وصف تثبيت مسار. أول مرة بدء إعداد ملف سجل دقيق تجهيز ما زال يخص مستقل Desktop عملية.

Windows تحزيم استخدام Visual C++ Build Tools و Windows SDK تحرير ترجمة x86 Win32/GDI+ مساعد مساعدة مكتبة؛ توقيع بناء عبر قد إعداد Windows توقيع جهاز مقابل هذا مكتبة توقيع. دقيق تجهيز خطاف في كل منصة فوق متساو من electron-builder متابعة مسؤول استلام تجميع إنتاج اعتماد.[تثبيت واجهة قرار](../../.agents/notes/implemented/architecture/2026-09-10-windows-native-installer-pages.ar.md) سجل NSIS وصل دخول طريقة و إصدار تحقق اشتراط.

في لديه تفاعل صيغة طاولة وجه Windows x64 فوق، من مستودع أصل دليل تشغيل `pnpm --dir apps/desktop run test:installer`، يمكن سوف صغير نوع أصلي اختبار تحميل حمل وصل دخول صحيح صيغة تثبيت إعداد و تنفيذ تحقق. كل مرة تشغيل استخدام مستقل منتج هوية، اعتماد مرة تحقق فقط إنجليزي نص و فقط العربية تثبيت جهاز تغيير جسم، و أصل حسب فعلي عرض فرح استقبال صفحة حسب زر اختيار اختبار نص سجل. اثنان عدد تغيير جسم متساو تثبيت إلى خاص دليل و في اختبار بعد إزالة؛ قطع رسم و نتيجة إبقاء في `.desktop-build/installer-tests/` تحت. فحص يتضمن نهاية ذيل حمل قسم فصل رمز قد تسجيل تسجيل مسار ترقية، و مغناطيس قرص أصل دليل رفض. اختياري `--signed` علامة سجل استخدام تحت نص Windows EV إعداد، في تضمين دخول قبل مقابل اختبار برنامج و مساعد مساعدة مكتبة توقيع؛ هو لن تفعيل تحديث مصدر.

### Windows EV توقيع

Windows توقيع بناء في تحرير ترجمة أو دقيق تجهيز اعتماد قبل تنفيذ تلقي مراقبة إشراف توقيع مسبق فحص. ساكن حالة إعداد، إثبات كتاب صالح مدة، مراجعة حساب تخزين، تحرير ترجمة جهاز متاح صفة و متروك إبقاء توقيع قفل فحص لا وصول Token. محلي .NET Framework C# تحرير ترجمة جهاز توليد واحد مخصص استخدام صغير استكشاف إبرة، من صحيح صيغة توقيع جهاز فقط توقيع مرة، مع بعد يجب تحقق خروج إعداد إثبات كتاب و ختم الوقت عندئذ قدرة متابعة بناء. استكشاف إبرة أبدا تنفيذ. مسبق فحص تجاوز مرور 60 ثانية، توقيع تقرير خطأ أو تحقق توقيع فشل كل سوف إيقاف هذا جولة مسار، لا إعادة محاولة. نجاح فقط إثبات حالي توقيع مسار متاح، لا إثبات PIN قد مستقل إقرار إثبات:SafeNet ممكن إعادة استخدام تسجيل تسجيل حالة. لا يلزم لـ تحقق PIN بينما ملاحظة إلغاء أو تكرار إقرار إثبات.`--check`، فقط دقيق تجهيز و `--unsigned` نمط لا تنفيذ هذا صلب عنصر مسبق فحص؛ لم توقيع ناتج ما زال لا يستطيع إصدار فوق نقل. تلقائي ارتداد اختبار استخدام زائف توقيع جهاز، حقيقي صلب عنصر من إصدار عملية شخص عضو مفرد وحيد تحقق استلام.

Windows NSIS فوق نقل اشتراط تثبيت حزمة جانب وجود توليد غير فارغ `.exe.blockmap`.blockmap أولا في عبر طريق YAML فوق نقل؛NSIS تثبيت حزمة بيانات وصفية لا اشتراط آخر نوع web-installer صيغة استخدام داخل تضمين `blockMapSize`. ملف بيان اختبار استخدام ثابت إصدار بناء جهاز blockmap توليد جهاز، بينما لا هو يد عمل تحرير صنع داخل تضمين خريطة حقل.

توقيع Windows إعداد من نفس نسخة عام إثبات كتاب `CN`،`O` و `C` خاصية توليد updater `publisherName`. كل خاصية كل يجب وجود، غير فارغ كما فقط لديه واحد قيمة. هذه هوية خاصية سماح إثبات كتاب متابعة مدة، بلا حاجة ثابت ورقة إثبات كتاب إشارة نقش. قد تثبيت تطبيق `app-update.yml` حفظ مسبق مدة إصدار من، تحت تحميل بيان لا يستطيع اختيار هذا هوية. لم توقيع اختبار بناء حذف updater إعداد. حقيقي ملف تحقق و ذلك حد رؤية[توقيع تحقق استلام سجل](tests/README.ar.md).

هذا مشروع استخدام SafeNet Token ظهور `SignTool Error: No private key is available.` وقت، شرح PIN(سري رمز) خطأ. قيام أي إيقاف كل توقيع محاولة تجربة، انتظار مستخدم معالجة PIN بعد مجددا متابعة.PIN نقل خطأ بلوغ إلى خمسة مرة سوف قفل تحديد Token. لقاء إلى هذا خطأ بعد، لا نيل إعادة محاولة تحزيم أو توقيع استكشاف إبرة. توقيع جهاز سلسلة سطر تنفيذ Token عملية، أول مرة فشل بعد رفض كل ترتيب طابور مهمة.

Windows تحزيم أمر عبر `DESKTOP_PACKAGING_RECORD` إخراج `.desktop-build/packaging-runs/` تحت وحيد دليل. كل مرة تشغيل إبقاء `run.json`، حمل ختم الوقت `events.jsonl`، انفصال حساس بعد `stdout.log` و `stderr.log`، و `result.json`. توقيع فشل أيضا سوف كتابة `fatal.json` و عبر stderr إشعار أب عملية؛ مراقبة إشراف برنامج قيام أي طلب إنهاء حالي مرحلة مقطع عملية شجرة و انتظار خروج. فشل مرحلة مقطع لا يستطيع بدء لاحق مرحلة مقطع أو توليد إصدار إتمام سجل. سجل كتابة فشل أيضا سوف إيقاف تشغيل. إنهاء خطأ ما زال حسب فشل معالجة، حاجة عملية من فحص؛ نقص قليل نهائي سجل يمثل بعد لم تأكيد إتمام.

صلب عنصر توقيع يجب يخص تلقي مراقبة إشراف تحزيم تشغيل. استدعاء أمر حل تفسير جهاز قبل، توقيع جهاز أصل فرعي نيل أخذ `%USERPROFILE%/.dsh-desktop-signing/attempt.json` و سجل هذا مرة محاولة تجربة. فقط لديه توقيع نجاح عندئذ تحرير هذا ملف. فشل، في قطع، قد لديه قفل تحديد ملف أو مراجعة حساب تخزين غير ممكن استخدام كل سوف منع توقف مجددا مرة وصول صلب عنصر، يشمل نفس Windows حساب مستخدم تحت آخر عدد توقيع جهاز نسخة، عملية أو شفرة فحص خروج دليل. لا يوجد تحديد وقت استعادة أو تلقائي إعادة محاولة. إدارة عضو يجب فحص إبقاء دليل و أمر لوحة حالة، مجددا واضح تخويل استعادة قفل تحديد حالة؛ تسجيل تسجيل أمر لوحة أو استبدال PIN ملف لن صاف حذف هو. سجل منطقة قسم توقيع معنى رسم، أمر حل تفسير جهاز PID و إتمام نتيجة، لا حساب كمية CSP/أمر لوحة داخلي إقرار إثبات مرة عدد. لا سجل أمر معامل،PIN أو اعتماد بيئة. أخرى Windows حساب مستخدم و غير متصل توقيع برنامج لا في هذا قفل تحديد آلية حفظ حماية نطاق داخل.

Windows تحزيم سوف 7-Zip مرور ترشيح جهاز ثابت لـ `BCJ`، بـ توافق داخل وضع NSIS حل رمز جهاز. هذا مثال يمكن إبقاء x64 تثبيت حزمة في من اعتماد يحمل ARM64 اثنان دخول صنع ملف؛ تلقائي ARM64 مرور ترشيح سوف توليد هذا حل رمز جهاز لا يمكن حل ضغط بند.

NSIS في تثبيت مرحلة مقطع تنظيف مؤقت حل ضغط دليل، إتمام بعد عندئذ عرض إتمام صفحة أو تلقائي بدء تطبيق. قد تثبيت إنتاج اعتماد إبقاء لـ عادي ملف؛ بدء وقت لن مجددا مرة حل ضغط. تثبيت ما زال سوف كتابة كامل تطبيق دليل شجرة.

في `.env.windows` في ملء كتابة `DSH_DESKTOP_WINDOWS_CER_FILE`(عام EV ورقة إثبات كتاب) ،`DSH_DESKTOP_WINDOWS_SIGNTOOL`(SafeNet توافق SignTool) ،`DSH_DESKTOP_WINDOWS_KEY_CONTAINER`(مطابقة خاص مفتاح حاوية) و `DSH_DESKTOP_WINDOWS_TOKEN_PIN`(Token Password). خاص مفتاح ما زال إبقاء في USB Token؛ لا يلزم يأخذ إثبات كتاب أو محلي اعتماد ملف إيداع إلى Git.

```sh
pnpm run package:desktop:win:x64
```

تحزيم قبل إدراج دخول و حل قفل Token.electron-builder خطاف يأخذ كل ناتج تسليم إعطاء اعتماد CRLF `scripts/windows-sign.cmd`؛ هذا CMD فقط استدعاء مرة قد إعداد SignTool، و إشارة تحديد `/f`،SafeNet `/kc "[{{PIN}}]=حاوية"`،`/csp "eToken Base Cryptographic Provider"`،SHA-256 ملف ملخص و DigiCert SHA-256 RFC 3161 ختم الوقت. خطاف لن تعديل استخدام electron-builder داخل وضع SignTool، أيضا لن إعادة محاولة فشل توقيع طلب.SignTool، إثبات كتاب، حاوية،PIN،Token أو توقيع غير ممكن استخدام وقت،Windows إصدار تحزيم سوف فشل، لن توليد لم توقيع ناتج.

PIN لا يستطيع يتضمن `]`، جذب رقم أو تبديل سطر، لأن هذه محرف لأجل قسم فصل SafeNet `/kc` قيمة أو مقابل CMD معامل.CMD سوف منع استخدام تأخير متأخر توسيع، لذلك يتضمن `!` PIN يمكن أصل مثال وصول SafeNet. تحزيم مسار لن يأخذ أي `DSH_DESKTOP_WINDOWS_*` حقل نقل إعطاء بناء و وقت التشغيل دقيق تجهيز عملية فرعية؛ هو فقط نحو توقيع مسبق فحص، مستقل رقم واحد جهة وقت التشغيل توقيع مرحلة مقطع و electron-builder توفير أربعة عدد إعداد إدخال، في أخرى حقل قد تنظيف بيئة في فقط نحو توقيع CMD توفير مرور مرور تحقق توقيع حقل، في SignTool بدء قبل صاف حذف هذه حقل، و حجب غطاء SignTool تشخيص.SafeNet ما زال اشتراط PIN ظهور في SignTool عملية أمر سطر في. محلي `.env.windows` واضح نص حفظ PIN، ينبغي حد ملف وصول إذن؛CI استخدام مؤقت ملف و في مهمة انتهاء بعد حذف. لا يلزم إيداع أو قسم مشاركة ملف محتوى، أيضا لا يلزم يأخذ اعتماد كتابة سجل. إعداد فحص لن إزالة استهلاك Token PIN محاولة تجربة مرة عدد؛ توقيع ما زال في أول مرة فشل بعد إيقاف كامل دفعة مهمة.

استخدام مقابل `:dir` أمر يمكن توليد يمكن مباشر تشغيل تطبيق دليل، بينما لا هو تثبيت حزمة، مثال مثل:

```sh
pnpm run package:desktop:dir
pnpm run package:desktop:mac:arm64:dir
```

حاجة فحص أو تشخيص لـ مضيف هدف دقيق تجهيز مورد بينما لا استدعاء electron-builder وقت، يمكن يجعل نفس خط الإنتاج في دقيق تجهيز إتمام بعد إيقاف:

```sh
pnpm run prepare:desktop
```

هذا بند تشخيص أمر هو آخر نوع إيقاف موضع، و غير اثنان بند أمر بناء مسار قبل نصف مقطع. بعد تنفيذ `package:desktop*` وقت ما زال سوف إعادة إتمام صحيح صيغة بناء و دقيق تجهيز، تجنب تجنب استخدام قديم قديم dsh حزمة، وقت التشغيل ملف أو dsh محتوى.

كل بند تحزيم أمر كل سوف بناء مستودع، تحزيم بـ dsh و خاص Desktop Host لـ أصل رقم واحد جهة إنتاج اعتماد إغلاق حزمة، و دقيق تجهيز هدف مخصص استخدام Electron توزيع حزمة و pnpm CLI.`prepare:dsh` في بناء وقت تثبيت مرة إنتاج اعتماد رسم، دقيق تجهيز شيء تحويل حزمة توفير electron-builder عودة ملف إلى `app.asar/dsh`، إزالة حزمة إدارة جهاز بيانات وصفية، و توليد يتضمن مشترك حزمة إصدار و نهائي ملف ها أمل `desktop-runtime.json`. في macOS فوق، هو أولا توقيع و تحقق أصلي ملف، مجددا توليد بيان؛electron-builder لا مقابل قد توقيع هذا دليل تكرار إجراء تضمين طقم توقيع. مورد خريطة واضح يتضمن افتراضي أصل دليل مرور ترشيح جهاز سوف تجاهل اختصار `dsh/node_modules`؛ دقيق تجهيز إتمام وقت التشغيل بيان في أصلي توقيع بعد فحص. أصلي يمكن تنفيذ ملف و مكتبة حل حزمة إلى ASAR جانب؛Python، مستقل Node و pnpm إبقاء في خارجي runtime مورد في. توقيع تثبيت حزمة، عام إثبات، قد تثبيت تطبيق ترقية و كل هدف أصلي وحدة تحقق استلام حاجة إصدار بيئة.

macOS تحزيم في تجميع App وقت، شفرة توقيع قبل كتابة `Contents/Resources/app-update.yml`، توفير و سطر ZIP و DMG مسار خط استخدام دليل بناء أيضا تنفيذ هذا عملية. توقيع خطاف تحقق دقيق تأكيد تحديث مصدر و updater ذاكرة مؤقتة دليل. كتابة إصدار إتمام سجل قبل، مسار سوف مجددا مرة فحص اثنان بند مسار خط فرعي هذا و نهائي نقل دخول App؛ إعداد ناقص أو لا مطابقة سوف منع توقف نقل دخول ناتج، بسبب بينما أيضا سوف منع توقف فوق نقل.

لم ضغط ناتج يتضمن Electron، شيء تحويل بعد dsh إنتاج اعتماد شجرة،pnpm، و قشرة تطبيق. تثبيت حزمة كبير صغير و نظام الملفات احتلال استخدام مختلف؛ إصدار تحقق استلام حاجة قياس كمية اثنان من، و profile إضافة تخزين و أول مرة بدء استهلاك وقت. هذا تخطيط استخدام أكثر كثير تطبيق داخل ملف تبديل إلغاء حذف مستخدم آلة جهاز فوق نواة قلب حزمة تثبيت مرور مسار.

## تحديث

تحزيم تطبيق في بدء بعد مختلف خطوة فحص ثابت Nightly. معتاد قاعدة جولة استفسار بـ عشرة قسم ساعة لـ أساس أساس بين فصل، كل مرة مستقل أخذ مثال ±20% مع آلة اهتزاز حركة. كل مرة فحص فشل سوف أساس أساس تأخير متأخر قلب ضعف، حد أعلى لـ واحد صغير وقت؛ نجاح بعد إعادة وضع. مع آلة تأخير متأخر لا تجاوز مرور هذا حد أعلى، و من الكل إعادة استخدام استدعاء تسوية بعد بدء حساب وقت. محلي تحويل “فحص تحديث…” قائمة مفرد بند (Windows يمكن من قمة شريط “تطبيق” قائمة مفرد دخول) قيام أي تنفيذ، و إعادة استخدام صحيح في إجراء فحص. عودة إلى قبل منصة و نظام استعادة وقت التزام حراسة نفسه مفرد ضبط وقت ساعة قطع توقف وقت. جديد استلام إلى قوي أكثر سياسة أيضا سوف قيام أي طلب فحص تحديث بيان. تلقائي فحص من لا نابض نافذة أو تحت تحميل تثبيت حزمة. يد حركة فحص عرض صحيح في فحص، فشل أو يتضمن قد تثبيت رقم الإصدار بلا تحديث عكس تغذية.

`DSH_DESKTOP_UPDATE_CHECK_INTERVAL_MS` إعداد معتاد قاعدة أساس أساس بين فصل،`DSH_DESKTOP_UPDATE_CHECK_MAX_BACKOFF_MS` إعداد حد أعلى؛ اثنان من متساو قبول 1000 حتى 2147483647 كامل عدد جزء ثانية عدد، كما حد أعلى لا يستطيع صغير في بين فصل. حذف حد أعلى وقت أخذ واحد صغير وقت و بين فصل في مقارنة كبير قيمة.`DSH_DESKTOP_UPDATE_CHECK_JITTER` إعداد 0 حتى 1 اهتزاز حركة مقارنة مثال، افتراضي `0.2`؛ نهائي تأخير متأخر حتى قليل واحد ثانية، كما لا تجاوز مرور حد أعلى. هذه إعداد لا تغيير قوي أكثر سياسة جولة استفسار، أيضا لا تخويل تحت تحميل إعادة محاولة.

يسار تحت زاوية حساب مستخدم سطر عرض محلي تحويل تحديث متاح حالة، تحميل رسم علامة و تحت تحميل مئة قسم مقارنة، تحقق، حينئذ خيط حالة، أو حمل يمكن وصول تلميح حمل دائم أحمر لون إعادة محاولة عملية. تضمين دخول Web واجهة نص سجل تتبع مع تطبيق داخل حالي لغة؛ أصلي نابض نافذة استخدام Desktop قشرة لغة. جانب شريط استلام بدء وقت، قمة جزء توسيع حسب زر عرض دائرة نقطة. اتصال حالة أولوية عرض. اختيار متاح إصدار أي بدء تحت تحميل. دقيق تجهيز نجاح بعد تلقائي فتح قشرة يملك إعادة بدء تأكيد؛ إغلاق بعد إبقاء حينئذ خيط حالة، لا تكرار نابض نافذة. اختيار حينئذ خيط مدخل يمكن مجددا مرة فتح تأكيد. تشغيل في agent، ترتيب طابور إدخال، و تشغيل في أو إيقاف في خلفية مهمة كل سوف في هذا تأكيد في إطلاق في قطع تحذير إبلاغ. فقط لديه API طلب لن إطلاق تحذير إبلاغ. مستخدم دفعة دقيق بعد،Host قفل تحديد جديد طلب، انتظار قد استقبال طلب انتهاء، مجددا فحص مهمة، يشمل قد استقبال كتابة عملية إنشاء عمل. انتظار تجاوز مرور تحكم طلب قطع توقف وقت وقت، رفض تثبيت و حل حذف دقيق دخول قفل. مهمة حالة لم معرفة، لم نيل في قطع تخويل جديد مهمة، أو لم نجاح إتمام صحيح معتاد استلام ذيل، كل سوف منع توقف تثبيت. معتاد قاعدة خروج سوف في إيقاف Host قبل إخفاء منتج نافذة، في استلام ذيل خلال تجاهل اختصار جديد تجمع تركيز طلب، كما من لا تثبيت تحديث. تحت مرة بدء عبر قد لديه بدء و استعادة مسار تدقيق دقيق إصدار ربط وقت التشغيل.

إذا مهمة استلام ذيل فشل لكن قد تأكيد Host خروج، تثبيت سوف يتم رفض، قشرة سوف في سماح مجددا مرة تأكيد إعادة بدء قبل استعادة حالي إصدار Host.Host صحيح معتاد إيقاف بعد تثبيت جهاز بدء فشل استخدام نفس استعادة مسار. بديل Host بدء و إتمام إقرار إثبات بعد، قشرة إعادة تحميل أصل لديه تطبيق عنوان، يجعل Web صفحة نيل أخذ حالي طرف فتحة،Cookie و بدء حقن بيانات؛ صفحة تحميل فشل وقت فتح أصلي يؤدي أمر لذا عائق استعادة نابض نافذة. لم تأكيد عملية خروج وقت، أبدا سماح بدء بديل Host. قد تحت تحميل هدف إبقاء بـ توفير إعادة محاولة. معروف قوي أكثر سياسة في استعادة مرور مسار في متابعة منع سد؛Host استعادة فشل فتح أصلي يؤدي أمر لذا عائق استعادة نابض نافذة.

قد تأكيد Host خروج لكن مهمة لم نجاح استلام ذيل وقت، معتاد قاعدة و قوي أكثر نابض نافذة متساو عرض محلي تحويل استعادة تلميح. اثنان نوع لغة كل أصل حسب نوع تحويل دقيق تجهيز فشل سبب اختيار تلميح، قلب ترجمة نص سجل تغير لن تغيير فشل تصنيف.“فحص نظر تقنية فن تفصيل حال” افتراضي طي، فقط عرض خروج حالة، إشارة، إغلاق تأكيد و قطع توقف وقت واقع، لا عرض إضافة stderr. توسيع تفصيل حال حيث لا إعادة محاولة، أيضا لا تخويل تثبيت.

### قوي صنع تحديث سياسة

[قوي أكثر عميل قرار](../../.agents/notes/implemented/feature/2026-09-11-desktop-mandatory-update-client.ar.md) مسؤول سياسة استعلام و منع سد نافذة. تحزيم قراءة `.env.windows` أو `.env.macos`:`DSH_DESKTOP_AUTO_UPDATE_ENV=test`(قيمة افتراضية) اختيار `DSH_DESKTOP_MANDATORY_UPDATE_TEST_ORIGIN`؛`production` اختيار `DSH_DESKTOP_MANDATORY_UPDATE_PROD_ORIGIN`. نموذج لوح قسم آخر استخدام `https://harness-test.deepseek.com` و `https://harness.deepseek.com`. في دقيق تجهيز ناتج أو توقيع قبل، الذي اختيار مصدر محطة يجب إعداد، يشمل لم توقيع و فقط دقيق تجهيز بناء؛ لم اختيار بيئة مصدر محطة يمكن لا ملء. هذه إعداد لن رجوع إلى أب عملية بيئة أو آخر نشر بيئة. تحزيم سوف اختيار تحديد سياسة و تطبيق ID كتابة بيانات وصفية؛ تحزيم تطبيق تجاهل اختصار وقت التشغيل تغطية.

اختياري `DSH_DESKTOP_MANDATORY_UPDATE_CONFIG` JSON توفير جولة استفسار و تحت تحميل صفحة خيار؛ تحزيم رفض منها `origin` و `authentication`. صفحة أبيض اسم مفرد افتراضي فقط يتضمن الذي اختيار خدمة مصدر محطة؛ حاجة أخرى قد دفعة دقيق تحت تحميل صفحة مصدر محطة وقت ينبغي صريح إعداد. اختبار حزمة اختيار `feishu-test`، صحيح صيغة حزمة اختيار `anonymous`. سياسة طلب رفض إعادة تحديد نحو؛ فقط اختبار تمييز حق يحمل شبكة صلة Cookie. لم تحزيم تطوير نمط فإن من هذا متغير قراءة كامل سياسة JSON، و اشتراط `DSH_DESKTOP_APP_ID`؛ نقص قليل JSON سوف منع استخدام تطوير نمط سياسة استعلام، فقط مجهول اسم تطوير سماح HTTP `127.0.0.1`. مستخدم إرسال بدء معتاد قاعدة فحص وقت سوف تزامن إطلاق سياسة فحص، لكن لن انتظار أو عرض سياسة فشل. فقط لديه قد تأكيد قوي أكثر قرار يمكن إغلاق معتاد قاعدة نابض نافذة. اختبار بيئة تمييز حق سوف انتظار حالي معتاد قاعدة نابض نافذة انتهاء، إلغاء أو فشل لن إسقاط updater نتيجة.

| تحليل بعد سياسة حقل | يحتوي معنى و قيمة افتراضية |
|---|---|
| `origin` | لا بد ملء HTTPS API مصدر محطة، لا يحتوي اعتماد، مسار، استعلام أو قطعة مقطع؛ طلب استخدام `/api/v0/check_client_update` |
| `allowedPageOrigins` | غير فارغ دقيق HTTPS مصدر محطة عدد مجموعة؛ تحزيم وقت افتراضي فقط يتضمن الذي اختيار API مصدر محطة؛ لا خفي يحتوي فرعي مجال اسم أو أخرى طرف فتحة |
| `authentication` | تحزيم وقت اختبار بيئة اختيار `feishu-test`، صحيح صيغة بيئة اختيار `anonymous`؛ لم تحزيم تطوير نمط افتراضي لـ `anonymous` |
| `intervalMs` | جولة استفسار بين فصل؛ افتراضي `600000` |
| `timeoutMs` | طلب قطع توقف وقت؛ افتراضي `15000` |
| `maxBackoffMs` | يحتوي اهتزاز حركة فشل طلب الأكثر كبير بين فصل؛ افتراضي `3600000`، لا صغير في `intervalMs` |
| `jitter` | مع آلة زيادة بين فصل مقارنة مثال؛ افتراضي `0.2`، نطاق لـ `0` حتى `1` |

وقت طويل يجب هو 1000 حتى 2147483647 جزء ثانية كامل عدد. بدء و تحديد وقت جولة استفسار مستقل في عمل خدمة طلب؛ قبل منصة/استعادة فحص التزام حراسة تحت مرة إلى مدة وقت، يد حركة فحص التفاف مرور هذا وقت و إعادة استخدام في طريق طلب. عميل إرسال قد تثبيت منصة، هيكل بنية، كامل قشرة و داخل وضع dsh إصدار، تطبيق ID، لغة و ثابت Nightly. لا استخدام عمل خدمة تسجيل تسجيل اعتماد أو تثبيت ID.

تفعيل `feishu-test` وقت، يتضمن `error.code: "UNAUTHENTICATED"` HTTP 401 JSON استجابة سوف في مستخدم رئيسي حركة فحص و تحزيم تطبيق أول مرة بدء فحص وقت توفير تسجيل تسجيل مدخل، لا انتظار محلي خلفية حينئذ خيط. محلي تحويل شرح إشارة خروج هذا هو اختبار إصدار، حاجة طيران كتاب تمييز حق، كما تسجيل تسجيل لن تحت تحميل أو تثبيت تحديث. تأكيد بعد أولا إغلاق شرح، مجددا فتح إعداد مصدر محطة أصل مسار صندوق رملي نافذة، لا استخدام استجابة في تسجيل تسجيل URL. تزامن فحص إعادة استخدام كامل تأكيد/تسجيل تسجيل مسار، و تجمع تركيز قد لديه نافذة. في اختبار بيئة تسجيل تسجيل نافذة حسب F12 يمكن فتح مستقل DevTools إجراء ترتيب فحص. إلغاء بعد، تحديد وقت أو قبل منصة فحص لن عكس تكرار نابض نافذة؛ مستخدم يمكن يد حركة إعادة محاولة.

تسجيل تسجيل و سياسة طلب مشترك استخدام داخل تخزين Session، و منتج نافذة و updater عزل؛ تطبيق إعادة بدء بعد حاجة إعادة تسجيل تسجيل. إغلاق نافذة إلغاء تسجيل تسجيل، تنقل فشل توفير محلي تحويل إعادة محاولة تلميح. إرجاع خدمة بعد إعادة استعلام سياسة؛ إعادة تحديد نحو،Cookie أو HTTP 422 كل لا هو صالح سياسة قرار. إلغاء، تسجيل تسجيل مرور مدة و بلا فاعلية استجابة متساو إبقاء معروف قوي أكثر منع سد. ثابت تسجيل تسجيل نتيجة كتابة عملية تشخيص و اختياري تحديث سجل؛ تسجيل تسجيل تحكم جهاز لا سجل Cookie،OAuth معامل أو بعيد مسار خطأ أصل نص. حقيقي Harness شبكة صلة/API ربط ضبط و macOS تسجيل تسجيل تحقق استلام ما زال لم إتمام.

مسطح مستو تحويل `40005` فتح قشرة يملك نموذج حالة نافذة، و رفض لاحق إضافة تعديل، لا إيقاف قائم Host مهمة. خدمة طرف عنوان و تفصيل حال هو اختياري صاف نص، ناقص وقت استخدام عميل التقاط قاع نص سجل؛ نقص قليل تحت تحميل عنوان أو عنوان لم نيل دفعة دقيق وقت إخفاء خارجي صفحة عملية، لا حل حذف منع سد.Windows قوي أكثر نافذة استخدام أصلي عنوان شريط، يمكن سحب حركة، ضبط كامل كبير صغير و الأكثر كبير تحويل. إغلاق نافذة سوف في إتمام تنظيف بعد خروج تطبيق، لن حل حذف تحديث اشتراط؛Esc لن إغلاق نافذة. دفعة دقيق تثبيت بعد، تثبيت جهاز وصل إدارة خروج مسار سوف في Electron إغلاق نافذة قبل تحرير نموذج حالة نافذة. تحت تحميل، يحتوي دقيق تجهيز خطوة ملف تحقق، مهمة فحص و تثبيت تأكيد مشترك استخدام نفس نابض نافذة. فقط لديه ثاني مرة مستخدم دفعة دقيق عندئذ سماح مهمة استلام ذيل و تثبيت؛ قليلا بعد تحديث إبقاء منع سد و تثبيت حزمة. فقط وجود تلقي أثر مهمة وقت، إعادة بدء نص سجل عندئذ تلميح صحيح في إيقاف مهمة. سياسة لا عبر تطبيق إعادة بدء حفظ دائم، سياسة استجابة أيضا لا عمل ملغى أو استبدال updater ناتج.

فشل وقت في نفس نابض نافذة داخل إبقاء منع سد، محلي تحويل إعادة محاولة تلميح و طي تشخيص. أبيض اسم مفرد تحت تحميل صفحة عملية فقط في استعادة حالة ظهور، لا و صحيح معتاد تحت تحميل أو تثبيت و صف. طلب فتح متصفح بعد قيام أي توفير نسخ بديل مدخل، أي جعل نظام طلب بعد لم إرجاع؛ طلب نجاح لا إثبات شبكة صفحة قد فتح. نسخ فشل وقت عرض كامل، فقط قراءة عنوان توفير يد حركة نسخ. متصفح و قص لصق لوح نتيجة لا تغطية updater خطأ. فقط لديه جديد صالح بلا حاجة قوي أكثر استجابة عندئذ حل حذف منع سد؛ منع سد خلال ما زال يمكن استخدام قمة جزء قائمة مفرد فحص.

خلفية قوي أكثر تثبيت تأكيد طلب Windows مهمة شريط رفع تنبيه أو macOS معلومة درجة Dock نابض قفز، و في كل جولة حينئذ خيط وقت محاولة تجربة مرة بلا صوت إشعار، لا أيضا أصل نافذة أو انتزاع تركيز نقطة. نقر إشعار فقط إرجاع حالي تأكيد واجهة. عودة إلى قبل منصة، تثبيت، سياسة حل حذف و خروج وقت تنظيف رفع تنبيه. نظام إذن و مخصص ملاحظة نمط ممكن كبح صنع إشعار؛ ما زال يحتاج إتمام Windows و macOS تثبيت حزمة إشعار تحقق استلام.

### محلي updater تحقق

معتاد قاعدة تحديث HTTP طلب أداة لديه تدريجي اتصال بلا نشط حركة قطع توقف وقت:`60000` جزء ثانية داخل لم استلام إلى استجابة رأس أو لاحق استجابة بايت سوف جعل عملية فشل.`DSH_DESKTOP_UPDATE_HTTP_IDLE_TIMEOUT_MS` قبول `1000` حتى `2147483647` كامل عدد إجراء ضبط كامل؛ نشط وثب تحت تحميل لا يوجد مجموع وقت طويل حد. تحت تحميل فشل إبقاء إعادة محاولة تلميح، و اشتراط مستخدم مجددا مرة عملية.

في قد تثبيت مساحة العمل اعتماد Windows فوق، من مستودع أصل دليل تشغيل:

```sh
node apps/desktop/node_modules/pnpm/bin/pnpm.mjs --dir apps/desktop run test:updates:local
```

هذا أمر بناء Desktop قشرة، يجعل ذلك تنسيق ضبط جهاز عبر حقيقي Electron HTTP طلب و `NsisUpdater` وصول خاص عودة حلقة خادم. هو تحقق مستخدم تخويل كامل تحت تحميل،SHA-512 رفض، صريح إعادة محاولة، تزامن طلب دمج، بيان استبدال و تثبيت تسليم وصل. هو أيضا فتح استخدام صندوق رملي مسبق تحميل حقيقي قوي أكثر صفحة، فحص حسب زر عملية، إغلاق/Esc اعتراض قطع، صاف نص محتوى، سياسة طلب توقف ركود و سياسة حل حذف. نجاح وقت ضرب طبع `LOCAL_UPDATER_RESULT` و بـ صفر خروج رمز انتهاء؛ وظيفة فشل وقت إرجاع غير صفر خروج رمز. كل مرة استدعاء وحيد احتلال مع آلة طرف فتحة و مؤقت مستخدم بيانات/ذاكرة مؤقتة دليل، إغلاق مستمع، انتظار Electron خروج، و إزالة مؤقت ملف. تقرير إبلاغ و متاح قطع رسم حفظ في وحيد `.desktop-build/qualification/local-updater-*` دليل في. قطع رسم فشل مفرد وحيد سجل، أبدا عند عمل نظر شعور تحقق استلام عبر. لا حاجة COS أو توقيع اعتماد.

تحت تحميل محتوى هو غير ممكن تنفيذ اختبار بايت، تثبيت استدعاء فقط سجل بينما لا تنفيذ. اختبار استبدال متصفح فتح و قص لصق لوح كتابة، تجنب تجنب خارجي تنقل و قص لصق لوح تعديل. هو لا بدء كامل منتج مساحة العمل، لا تحقق حقيقي تثبيت جهاز أو إعادة بدء، لا تحقق إصدار من توقيع، أيضا لا تغطية فرق قسم تحديث أو macOS. توقف ركود سياسة طلب، بيان طلب و سالب تحميل نقل سوف تنفيذ حقيقي قطع توقف وقت و استعادة. حقيقي معتاد قاعدة نابض نافذة تحقق عزل مسبق تحميل، بطاقة مقياس قياس، خلف مشهد نموذج غامض، إلغاء، مهمة تحذير إبلاغ خيار و صريح تثبيت دفعة دقيق؛ حساب مستخدم سطر مكون اختبار آخر سطر توفير دليل.[محلي تحقق قرار](../../.agents/notes/implemented/testing/2026-09-10-desktop-local-updater-qualification.ar.md) و[تحقق سجل](tests/README.ar.md) إبقاء هذه حد؛ إنتاج إصدار اشتراط إبقاء ثابت.

## قاع طبقة تطوير تغطية بند

لم تحزيم Electron عملية استخدام تطبيق دليل تحت `.desktop-build/development/project` بصفة تطوير مشروع.`DSH_DESKTOP_PNPM_ENTRY` و `DSH_DESKTOP_DSH_DIR` لأجل اختيار واضح وقت التشغيل مورد. تحزيم تطبيق سوف تجاهل اختصار هذه متغير، من `process.resourcesPath` تحليل توقيع مورد، و استخدام تلقي إدارة Desktop profile.

- اعتماد دورة الحياة نص برمجي التزام دوران pnpm بناء إذن؛Desktop لا توفير مفرد وحيد مراجعة دفعة محادثة إطار.
- طاولة وجه قشرة و CLI dsh مشترك `$DSH_HOME` تحت جلسة، ضبط، اعتماد، مساحة العمل و تخزين، لكن يمكن تنفيذ حزمة، إضافة تنشيط و قفل ملف ذاك هذا عزل.
