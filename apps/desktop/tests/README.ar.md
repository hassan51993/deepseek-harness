# Desktop محلي تحديث تحقق

[English](README.md) | العربية

## عام وصف

محلي تحت تحميل و قوي أكثر نابض نافذة دليل و إنتاج خلفية ربط ضبط، نظر شعور تحقق استلام، قد تثبيت تطبيق ترقية قسم فتح سجل. تشغيل [Desktop README](../README.ar.md) في أمر يمكن توليد جديد عزل تقرير إبلاغ.

قد تثبيت تطبيق تحقق استلام يمكن صريح تفعيل `DSH_DESKTOP_UPDATE_JOURNAL_DIR`، استخدام تثبيت دليل شجرة خارج، اثنان عدد إصدار مشترك نفس إبقاء قطعا مقابل مسار. كل رئيسي عملية سوف قد تثبيت إصدار، حالة تحويل و شخص عمل عملية علامة تحديث جديد إلى مفرد وحيد JSONL ملف. أصلي تشخيص و طلب بيانات يتم ترتيب حذف؛ تخزين خطأ سوف نحو فوق نقل بث.[سجل قرار](../../../.agents/notes/implemented/testing/2026-09-14-desktop-installed-update-journal.ar.md) تعريف دليل نطاق حد. وحدة و رئيسي مدخل اختبار تغطية هذا سجل؛ توقيع تثبيت إصدار ترقية ما زال لم تحقق.

## يد حركة عرض تدريب

فعلي تثبيت، بدء بعد إصدار، فشل إعادة محاولة و إعادة بدء دليل استخدام[قد تثبيت تطبيق تحديث شخص عمل بيان](installed-update/README.ar.md). تحت جهة تفاعل صيغة تشغيل جهاز اعتراض قطع تثبيت، يخص آخر صنف تحقق استلام.

Host، عميل و Desktop ناتج بناء إتمام بعد، في Windows مستودع أصل دليل تشغيل `node --import tsx apps/desktop/scripts/test-workspace-updates.ts --interactive`. حقيقي مساحة العمل حمل متابعة فتح، و توفير مستقل تحكم نافذة. ذلك قائمة مفرد اختياري اختيار عادي أو قوي صنع تحديث، إبقاء و وضع سطر تحت تحميل، حقن تحت تحميل فشل، و إضافة أو صاف فارغ اختبار مهمة. فشل نمط يجب في بدء تحت تحميل قبل اختيار. تأكيد تثبيت و إتمام مهمة استلام ذيل بعد،fixture رسالة تلميح تثبيت جهاز استدعاء قد يتم اعتراض قطع؛ تأكيد رسالة انتهاء عرض تدريب. إغلاق تحكم نافذة أيضا سوف خروج. كل مرة تشغيل وحيد احتلال خاص profile و عودة حلقة خادم؛ تحميل حمل لا هو تثبيت جهاز. إعادة تشغيل أمر بدء جديد واحد جولة. حذف `--interactive` فإن تشغيل تلقائي تحويل مشهد، إبقاء 120 ثانية قطع توقف وقت و تلقائي خروج؛ تفاعل نمط تحت تحميل شبكة شبكة قطع توقف وقت لـ عشرة قسم ساعة.

## تحقق دليل

محلي أمر بناء Desktop، و في Electron 44 في تشغيل حقيقي HTTP updater، سياسة عميل، صندوق رملي مسبق تحميل و قوي أكثر صفحة. هو سجل كل مشهد، و يأخذ تقرير إبلاغ حفظ في `.desktop-build/qualification/local-updater-*`. تثبيت جهاز استدعاء، خارجي متصفح و قص لصق لوح متساو استبدال لـ مراقبة قياس سجل؛ تحت تحميل بايت لا هو يمكن تنفيذ تثبيت جهاز.

| طبقة مرة | مراقبة قياس نتيجة |
|---|---|
| معتاد قاعدة updater | نفس إصدار/قديم إصدار رفض، مستخدم تخويل كامل تحت تحميل،SHA-512 رفض، نقل في قطع، بيان/تحت تحميل توقف ركود قطع توقف وقت، صريح إعادة محاولة، طلب دمج، نفس عنوان بيان استبدال، حينئذ خيط حالة و مستقل تثبيت تسليم وصل عبر |
| قوي أكثر سياسة | مسطح مستو تحويل `40005`، كامل إصدار رأس، تنقل عميل طلب، بلا حاجة قوي أكثر تحقق، فشل إبقاء، بين فصل/تراجع تجنب، مهلة و dispose(مورد تحرير) ارتداد عبر |
| معتاد قاعدة ضبط درجة | حقيقي تنسيق ضبط جهاز إعداد دمج نموذج محاكاة وقت ساعة ارتداد تحقق لديه حد أعلى اهتزاز حركة/تراجع تجنب، يد حركة إعادة استخدام، نجاح إعادة وضع، لا تلقائي إعادة محاولة تحت تحميل، لا تلقي نظام وقت ساعة ضبط كامل أثر، و dispose. رئيسي مدخل اختبار تحقق تجمع تركيز/استعادة عقدة تدفق، صريح فحص قيام أي تنفيذ و خروج تنظيف |
| حقيقي قوي أكثر نافذة | خدمة طرف صاف نص محتوى،Windows أصلي نافذة نقل حركة/تقليص وضع/الأكثر كبير تحويل و أيضا أصل،Esc منع سد، مباشر تحت تحميل، نفس نابض نافذة مهمة تأكيد، قليلا بعد تحديث، فقط استعادة حالة صفحة عملية، تنقل/نسخ عكس تغذية و جديد سياسة حل حذف عبر؛ تحديد نحو اختبار تحقق إغلاق وقت خروج كما لا صاف حذف سياسة |
| حقيقي معتاد قاعدة نابض نافذة | عزل مسبق تحميل،380px بطاقة،24px دائرة زاوية، أسود لون رئيسي حسب زر، أب نافذة نموذج غامض،Esc إلغاء بعد إبقاء حينئذ خيط، و مهمة تحذير إبلاغ دفعة دقيق بعد تثبيت تسليم وصل سجل متساو عبر |
| حل قفل بعد Windows تفاعل | مقابل حقيقي قوي أكثر صفحة تنفيذ نظام درجة نقر و قطع رسم، تأكيد Esc منع سد، مستخدم إرسال بدء تحت تحميل، حينئذ خيط، أحمر لون سياسة خطأ تلميح، و نابض نافذة حل حذف بعد أب نافذة استعادة متاح.fixture توفير أصلي مهمة تحذير إبلاغ نابض نافذة في اختيار قليلا بعد تحديث بعد عودة إلى حينئذ خيط حالة؛ مهمة نشط حركة لـ نموذج محاكاة، لا هو كامل Host عمل سالب تحميل |
| رئيسي مدخل | معروف منع سد رفض إضافة تعديل و استعادة، لكن لا إيقاف Host؛ جديد نجاح استجابة إغلاق منع سد؛ تحزيم سياسة تجاهل اختصار بيئة تغطية؛ صحيح معتاد إيقاف بعد تثبيت جهاز فشل في تحت مرة تأكيد قبل استعادة Host، و إبقاء قوي أكثر منع سد |
| Host مهمة حفظ حماية | استبدال تركيب بيئة بعد حقيقي تحكم جهاز تعرف آخر تشغيل في agent، ترتيب طابور turn/step، عام و agent job؛API قراءة لا إطلاق تحذير إبلاغ. طلب دقيق دخول قفل تحديد نحو جديد طلب إرجاع 503، انتظار قد لديه طلب انتهاء و تكرار فحص مهمة؛ حل قفل استعادة دقيق دخول |
| مرئي إخراج | العربية قوي أكثر نابض نافذة DOM مسبق مدة إخراج و معتاد قاعدة تحديث عرض مسبق مدة إخراج عبر؛ حساب مستخدم سطر مكون اختبار تغطية دخول درجة و حمل دائم إعادة محاولة |
| تحزيم إعداد | بيانات وصفية تضمين دخول إعداد تطبيق ID و سياسة؛ بناء بعد تحزيم قبل خطاف رفض HTTP سياسة مصدر محطة، لا تنفيذ تحزيم أو فوق نقل |

نابض نافذة، رئيسي مدخل، ضبط و جانب شريط تحديد نحو تشغيل عبر 119 عدد ارتداد حالة استخدام. خمسة عدد تحميل جسم اختبار تغطية مشترك تحديث حالة مصدر الكل لغة جملة، فرع، دالة و شفرة سطر. حقيقي Electron أمر عبر 17 عدد مشهد، و التقاط معتاد قاعدة حينئذ خيط، مهمة تحذير إبلاغ و قوي أكثر خطأ نابض نافذة. هذه عزل فحص لا إقرار إثبات كامل مساحة العمل أو إصدار. كل مستودع بوابة نتيجة و بيئة حد و هذه تحديد نحو دليل قسم فتح سجل.

Chromium headless shell revision 1228 قد تثبيت في تجاهل اختصار دليل `.desktop-build/playwright` في. تجميع بعد ضبط و جانب شريط متصفح طقم عنصر عبر 18 عدد حالة استخدام.[Desktop مساحة العمل متصفح مشهد](../../web/tests/desktop-updates.e2e.ts) في إنجليزي نص حالة استخدام متساو عبر، كل نوع لغة التقاط ستة ورقة قطع رسم، و تحقق قاع جزء حساب مستخدم سطر موضع، ضيق تجميع دخول درجة و تكرار نقر اعتراض قطع، قمة جزء توسيع حسب زر تلميح، حمل خطأ معلق توقف تفصيل حال حمل دائم أحمر لون إعادة محاولة، و مستقل حينئذ خيط عملية. عرض دالة،Host Web تركيب، عميل إضافة و CSS متساو لـ حقيقي تنفيذ؛Desktop تحميل جسم استخدام بديل ذات. هذه حالة استخدام لا تنفيذ Electron IPC، قائمة مفرد، مهمة تخويل أو تثبيت.

[بناء بعد Host مشهد](fixtures/host-update-qualification.mjs) استخدام حقيقي profile Loader،standard agent مسبق ضبط، مهمة خدمة و Node خلفية عملية. هو تحقق ترتيب طابور جولة/خطوة، تشغيل في نموذج طلب، انتظار جواب تكرار رفع سؤال/مراجعة دفعة، تشغيل/إيقاف في عام و agent job، لن إلغاء مهمة دقيق دخول قفل تحديد، دقيق دخول استعادة، و Host تحرير بعد فحص رفض. فقط نموذج استجابة و شخص عمل جواب تكرار استخدام بديل ذات. اثنان عدد مستقل استدعاء استخدام خاص profile و جلسة بيانات تزامن عبر؛ الكل ذاتي لديه agent،job و Host إتمام بعد عندئذ كتابة نجاح تقرير إبلاغ.

[Electron مساحة العمل تشغيل جهاز](../scripts/test-workspace-updates.ts) في خاص دليل في تنفيذ تحرير ترجمة بعد رئيسي مدخل، استخدام حقيقي مسبق تحميل، مساحة العمل و مستقل Host عملية. هو تأكيد أول مرة بدء إعلان، و عبر Electron إدخال حدث عملية صفحة حسب زر. عشرة عدد مشهد عبر، تغطية قائمة مفرد عكس تغذية، تحت تحميل فشل و إعادة محاولة، مستقل تثبيت تأكيد، تأكيد خلال حقيقي مهمة إنشاء، دفع متأخر تثبيت، قوي أكثر منع سد و حقيقي Host إيقاف مهلة. عادي و قوي أكثر فشل متساو استعادة بديل Host، و اشتراط إعادة تأكيد تثبيت؛ استعادة لن صاف حذف قوي أكثر سياسة. توزيع استخدام محلي خادم، تثبيت يتم اعتراض قطع؛ هذه لا هو توقيع قد تثبيت تطبيق تحقق نتيجة.

[Windows تحقق توقيع تشغيل جهاز](../scripts/test-windows-update-signature.mjs) استخدام قد تثبيت electron-builder بيانات وصفية توليد جهاز و `NsisUpdater` تحقق توقيع جهاز، إدخال لـ عام إصدار إثبات كتاب و حقيقي يمكن تنفيذ ملف. إصدار من خاصية مطابقة وقت عبر؛ نفس صالح توقيع في مسبق مدة إصدار من مختلف وقت يتم رفض، لم توقيع يمكن تنفيذ ملف أيضا يتم رفض. نقص قليل إصدار من سالب مقابل وفق تأكيد تحقق توقيع يتم قفز مرور. وحدة ارتداد تغطية DN تحويل معنى، لا كامل هوية، و صريح أو مضيف افتراضي Windows هدف؛ إزالة إصدار من إعداد سوف جعل اثنان بند بيانات وصفية حالة استخدام فشل. هذا فحص لا تحت تحميل، تثبيت أو توقيع ناتج.

[توقيع تحت تحميل تشغيل جهاز](../scripts/test-signed-updates.mjs) اتصال حقيقي Electron HTTP،`NsisUpdater`،Windows Authenticode و بناء بعد تنسيق ضبط جهاز. أربعة عدد مشهد عبر: ها أمل صحيح تأكيد لكن إصدار من خطأ وقت رفض، ها أمل صحيح تأكيد لكن لم توقيع وقت رفض، نقل ضرر تالف أولا في تحقق توقيع يتم رفض، و صريح إعادة محاولة بعد توقيع ملف حينئذ خيط و مفرد وحيد تسليم وصل تثبيت. يتم رفض يمكن تنفيذ ملف ذاكرة مؤقتة لـ فارغ، تلقائي فحص لا إرسال إعادة محاولة طلب، قد دقيق تجهيز تحت تحميل إبقاء متاح، أصلي إدخال SHA-512 ثابت. دمج صار بيان و اختبار تطبيق مهايئ لا إثبات قد تثبيت إصدار توافق صفة؛ لن بدء تثبيت جهاز أو Host.

توفير قديم تثبيت جهاز و اثنان عدد أصلي blockmap بعد، نفس تشغيل جهاز أيضا سوف تحقق مفرد مقطع Range، كثير مقطع Range إعادة بناء، نقص قليل قديم blockmap وقت رجوع، و Range يتم رفض وقت رجوع. إعادة بناء يمكن تنفيذ ملف عبر SHA-512 و Authenticode فحص. طلب سجل منطقة قسم فرق قسم سالب تحميل بايت و كل كمية تحت تحميل؛ كل كمية رجوع لا يستطيع ممتلئ كاف فرق قسم نجاح تأكيد. هذه عودة حلقة نتيجة لا إثبات CDN Range دعم حمل أو قد تثبيت تطبيق ذاكرة مؤقتة متاح.

## انتظار تحقق أمر بند

التالي أمر بند لا هو عبر دليل،review وقت يجب إبقاء مرئي:

- Electron `capturePage()` التقاط مفرد عدد نافذة.Windows تفاعل مراقبة قياس يتضمن دمج صار نابض نافذة و أصلي قائمة مفرد اختيار، لكن عبر منصة Figma/تخطيط تحقق استلام و كامل تسجيل صنع ما زال لم تحقق. تلقائي تحويل مساحة العمل تشغيل جهاز مباشر استدعاء قائمة مفرد معالج.
- تطوير بدء جهاز في هذا Windows مساحة العمل لقاء إلى إشارة نحو ناقص هدف اختياري Linux ARM64 اعتماد junction؛ تحقق استلام تشغيل جهاز مباشر رابط قد لديه اعتماد رسم، لا تحقق هذا بدء جهاز اعتماد إسقاط.
- fixture(اختبار قبل وضع بيانات) لا تنفيذ تثبيت جهاز، لا تغطية قد تثبيت تطبيق، أيضا لا إثبات جديد إصدار نجاح بدء. إصدار قبل ما زال يحتاج توقيع Windows و macOS قد تثبيت إصدار تحقق استلام.
- اثنان عدد عزل Windows اختبار تثبيت حزمة عبر توقيع حزمة فحص، يشمل داخل تضمين بيان إعداد. تثبيت بعد بدء، فشل إعادة محاولة، تلقائي إعادة بدء و بيانات إبقاء ما زال انتظار عملية من تحقق؛ ملف فحص لا إقرار إثبات إصدار.
- حقيقي سياسة مصدر محطة، شبكة صلة سلوك، حد تدفق، دفعة دقيق صفحة مصدر محطة و قد نشر سياسة إعداد ما زال انتظار خلفية ربط ضبط. محلي استجابة لا يستطيع إثبات خط فوق خدمة متاح.
- سياسة،updater بيان و تحت تحميل توقف ركود متساو بلوغ إلى حقيقي قطع توقف وقت و يمكن استعادة. تحت تحميل كتابة `ENOSPC` لذا عائق حقن قد تغطية؛ حقيقي لفة استهلاك كل و قد تثبيت إصدار ترقية مغناطيس قرص ضغط قوة ما زال لم تحقق. فرق قسم تحت تحميل و إصدار من رفض قد عبر حقيقي Electron تحت تحميل تحقق، لكن بعد لم في جديد تحزيم تطبيق قد تثبيت إصدار ترقية مسار في تحقق.
- Windows أصلي قص لصق لوح كتابة عبر. قد محاولة تجربة بدء افتراضي متصفح، لكن بسبب تلقائي تحويل أداة لا يمكن يمكن اعتماد تعرف آخر حالي URL، هدف عنوان تحقق إيقاف.macOS متصفح و قص لصق لوح تجميع صار ما زال لم تحقق.
- قوي أكثر و معتاد قاعدة فشل استخدام محلي تحويل ملخص و طي تشخيص؛ نسخ فشل عرض اختياري اختيار عنوان. معتاد قاعدة خطأ معلق توقف تلميح عرض ملخص، لا عرض أصلي تشخيص.Windows/macOS تثبيت حزمة رسم علامة رفع تنبيه، إشعار إذن و مخصص ملاحظة نمط سلوك ما زال لم تحقق.
- كامل `doc-sync`(وثيقة تزامن بوابة) في وثيقة محطة اختبار في لقاء إلى Windows ملف رمز رقم رابط `EPERM`. هذا لا هو updater فشل، أيضا لا بديل جدول كامل وثيقة بوابة عبر.
