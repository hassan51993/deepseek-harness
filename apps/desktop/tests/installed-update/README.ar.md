# Windows قد تثبيت تطبيق تحديث عرض تدريب

[English](README.md) | العربية

## ملخص

دقيق تجهيز مستقل اختبار تطبيق و كل جديد test توزيع نطاق الأسماء، مجددا من عملية من قريب يد تثبيت، حقن لذا عائق، إعادة محاولة و تأكيد إعادة بدء. محلي بيان أو كامل سجل تسلسل لا يستطيع إثبات تثبيت جهاز دمج إطار أو بيانات إبقاء. تحت وصف قد تثبيت تطبيق خطوة في عملية من استخدام قد تحقق تثبيت حزمة تنفيذ قبل ما زال لم تحقق.

## دقيق تجهيز شيء مادة

في قد تثبيت اعتماد مستودع أصل دليل في، استخدام اثنان عدد تمرير زيادة إرسال توليد اختبار إصدار إنشاء دفعة مرة. هذا فقط كتابة قد تجاهل اختصار محلي بيان، لا بناء، توقيع، فوق نقل، تثبيت أو قراءة اعتماد.

عرض مثال بـ `0.1.6-alpha.1` لـ أساس أساس إصدار. إنشاء جديد شيء مادة قبل، حسب[إصدار إصدار قاعدة](../../README.ar.md#release-versions) استبدال لـ فعلي أساس أساس إصدار، شمال عاصمة وقت يوم مدة و لم استخدام ترتيب رقم.

```powershell
node --import tsx apps/desktop/scripts/prepare-installed-update.ts init 0.1.6-alpha.1.20260916.1 0.1.6-alpha.1.20260916.2
```

إبقاء إرجاع `run.json`، اثنان عدد تثبيت حزمة إعادة استخدام منها مع آلة هوية و `qualification/<id>` مسار. مصدر إيداع و قذر ملف قائمة معرف بدء بداية مساحة العمل، لا بديل جدول لاحق تثبيت حزمة محتوى. نهائي بناء مصدر و ناتج ها أمل آخر سطر سجل؛ لا يلزم في تحديث في طريق إعادة توليد بيان.

عبر مستودع فقط دقيق تجهيز مسار توليد جديد شفرة المصدر مورد، مجددا توليد مشترك بدء مدخل، اثنان نسخة مستقل إصدار ربط وقت التشغيل و تجميد ربط تطبيق ملف. سوف `<run.json>` استبدال لـ دفعة مرة بيان مسار. فقط دقيق تجهيز مسار بناء و فحص أصلي وقت التشغيل، لكن في توقيع قبل إيقاف؛ ذلك بقية أمر أبدا استدعاء توقيع جهاز أو تثبيت جهاز. هذه أمر رفض تغطية قد لديه دفعة مرة ناتج؛ خروج خطأ بعد إبقاء لا كامل شيء مادة، لا في ذلك فوق إعادة محاولة.

```powershell
node apps/desktop/node_modules/pnpm/bin/pnpm.mjs --dir apps/desktop run prepare:package win-x64
node --import tsx apps/desktop/scripts/prepare-installed-update.ts bootstrap "<run.json>"
node --import tsx apps/desktop/scripts/prepare-installed-update.ts runtime "<run.json>"
node --import tsx apps/desktop/scripts/prepare-installed-update.ts application "<run.json>"
```

سوف توليد `bootstrap` دليل في اثنان عدد ملف وضع في حزمة داخل `lib/` نفس درجة، سوف حزمة رئيسي مدخل ضبط لـ `qualification-bootstrap.mjs`. هذا مدخل في تحميل إنتاج رئيسي برنامج قبل تحقق قد تثبيت تطبيق ID و إصدار. هو سوف Electron مستخدم/جلسة بيانات،Harness home و سجل وضع في عملية نظام تطبيق بيانات دليل تحت `dsh-update-qualification/<id>/`؛ اثنان عدد إصدار استخدام نفسه مسار. وقت التشغيل نسخ جهاز فقط تعديل إصدار بيت عائلة حزمة إصدار و مقابل اعتماد مرجع، إبقاء رقم ثلاثة جهة إصدار، و إعادة تحقق اثنان عدد فرعي هذا بيان و لم تعديل أصلي مورد. ذلك `runtime-preparation/result.json` سجل ها أمل، و واضح لا إعلان تسمية توقيع أو فرعي هذا إصدار بدء تحقق استلام عبر. هذه دمج صار إصدار يخص اختبار شيء مادة، لا هو npm إصدار إصدار.

`application` أمر سوف قد بناء رئيسي برنامج/مسبق تحميل وحدة، واجهة ملف و دقيق تجهيز جيد بدء مدخل نسخ إلى `application/files`، و في `application/result.json` في سجل SHA-256. هو لا نسخ تطبيق أصل دليل `.env.windows`، أيضا لا تجميد ربط `node_modules` و بناء أداة.[تحقق استلام تحزيم إعداد](../../scripts/installed-update-builder.ts) تحقق هذا بيان و اختيار تحديد مستقل وقت التشغيل، اختيار استخدام مشترك تجميد ربط ملف و عزل حزمة بيانات وصفية، و إبقاء معتاد قاعدة تثبيت جهاز و توقيع خطاف. ذلك اختبار استبدال توقيع جهاز، و عبر ثابت إصدار بناء جهاز إعداد تحقق؛ اختبار لا توليد تثبيت جهاز. آخر سطر تخويل تلقي مراقبة إشراف بناء ما زال يجب سجل اعتماد/أداة إدخال، و تحقق نهائي حزمة محتوى و توقيع.

[تحزيم مدخل](../../scripts/package-installed-update.ts) افتراضي فقط فحص. إبقاء توقيع حفظ حماية قفل سوف في قراءة اعتماد قبل جعل ذلك رفض؛ مدخل أبدا صاف حذف هذا قفل. لا يوجد حفظ حماية قفل وقت، فحص سوف تحميل `.env.windows`، تحقق دقيق تجهيز إدخال، لا بدء عملية فرعية. في مستودع أصل دليل استخدام واحد دقيق تأكيد إصدار تنفيذ:

```powershell
node --import tsx apps/desktop/scripts/package-installed-update.ts "<run.json>" 0.1.6-alpha.1.20260916.1 --check
```

فعلي تحزيم ما زال لم تحقق، يجب آخر سطر نيل نيل صلب عنصر استعادة تخويل و لديه عملية من في ساحة.`--execute` نمط اشتراط طرفية و يتضمن إصدار، دفعة مرة ID دقيق تأكيد تأكيد، لا يوجد إدارة طريق دفعة دقيق خيار. هو مجددا مرة فحص حفظ حماية قفل، و وحيد احتلال إنشاء هذا إصدار `packaging` دليل. تلقي مراقبة إشراف عملية فرعية فقط بناء هذا إصدار، منع استخدام إصدار، إزالة غير متصل اعتماد، فشل أو بلوغ إلى 15 قسم ساعة كامل جسم مدة حد وقت إيقاف. هذا مدة حد لا حد مفرد مرة CSP داخلي إقرار إثبات محاولة تجربة. سجل إبقاء شفرة المصدر/أداة ها أمل، انفصال حساس إخراج، حدث و ناتج ملف ها أمل؛ قد لديه محاولة تجربة أو إخراج رفض إعادة استخدام.`builderCompleted` و مراقبة إشراف برنامج نجاح نتيجة لا إثبات حزمة تحقق، تحقق توقيع أو تثبيت نجاح؛ مستقل إتمام هذه فحص قبل،`packageVerification` إبقاء `pending`.

عملية من بدء قبل، توفير اثنان عدد قد تحقق تثبيت حزمة، توليد بيانات وصفية و blockmap، تحزيم و توقيع سجل، دقيق تأكيد تثبيت بعد يمكن تنفيذ ملف مسار و ثابت test feed URL. اثنان عدد تثبيت حزمة يجب استخدام نفسه اختبار هوية، عزل بيانات دليل، و في كل مرة بدء وقت ضبط نفس عدد تثبيت دليل خارج قطعا مقابل مسار `DSH_DESKTOP_UPDATE_JOURNAL_DIR`، يشمل تثبيت جهاز إطلاق إعادة بدء. فقط في أول مرة بدء طرفية في ضبط متغير هو لا كاف.[Windows توقيع قاعدة](../../README.ar.md#windows-ev-signing) ما زال ملائم استخدام؛ بيان أبدا حل حذف توقيع حفظ حماية قفل.

Windows [فقط قراءة توقيع فحص جهاز](../../scripts/installed-update-signature.mjs) استخدام حقيقي updater تحقق توقيع، إصدار من قدوم ذاتي يمكن معلومة عام مفتاح إثبات كتاب، مع بعد اشتراط Authenticode و ختم الوقت خاصية صالح كما SHA-512 لم تغيير. تحقق توقيع عملية فرعية لا وراثة توقيع/فوق نقل سري سري أو PowerShell وحدة مسار تغطية. فحص جهاز أبدا تحميل `.env.windows`، توقيع ملف أو تنفيذ يتم فحص يمكن تنفيذ ملف. محلي قد مراقبة إلى توقيع استكشاف إبرة عبر، لم توقيع تثبيت حزمة يتم رفض؛ هذه نتيجة لا يستطيع إثبات مهمة واحد دقيق تجهيز إصدار، حزمة هوية أو تثبيت سلوك قد تحقق استلام.

[تثبيت حزمة فحص جهاز](../../scripts/verify-installed-update-package.ts) أولا تحقق نهائي تثبيت حزمة، مجددا استخدام مرور مرور مراجعة فحص محلي 7-Zip يمكن تنفيذ ملف حل حزمة. بيان، يمكن معلومة عام مفتاح إثبات كتاب و أداة متساو يجب توفير قطعا مقابل مسار؛ أبدا اختيار من انتظار تحقق تثبيت حزمة في حل خروج أداة. هذا أمر إنشاء كل جديد `verification/check-*` دليل، إبقاء جزء سجل، تثبيت حزمة ناقص وقت قيام أي فشل:

```powershell
node --import tsx apps/desktop/scripts/verify-installed-update-package.ts "<run.json>" 0.1.6-alpha.1.20260916.1 "<public.cer>" "<reviewed-7za.exe>"
```

فحص جهاز نواة مقابل فعلي عودة ملف داخل تطبيق هوية، مدخل، تجميد ربط تطبيق بايت،updater اعتماد إصدار،feed/ذاكرة مؤقتة/إصدار من إعداد، و سوف داخل وضع Harness وقت التشغيل و دقيق تجهيز إدخال مقارنة مقارنة؛ اختبار قوي أكثر سياسة أيضا يجب صالح. هو من `app.asar` رفع أخذ وقت التشغيل، و في `app.asar.unpacked` مسار نواة مقابل يمكن تنفيذ ملف توقيع. حدوث تغير وقت التشغيل يمكن تنفيذ ملف يجب مفرد وحيد تحقق توقيع؛ أخرى وقت التشغيل بايت في مرور مرور electron-builder اعتماد manifest تحويل بعد يجب و دقيق تجهيز إدخال متسق. هو في حل حزمة قبل رفض لا أمان عودة ملف مسار، سجل تثبيت جهاز، تطبيق و وقت التشغيل يمكن تنفيذ ملف توقيع. نجاح قبل مجددا مرة نواة مقابل تثبيت حزمة،feed/blockmap، بيان، إثبات كتاب و أداة ها أمل.`passed` فقط تغطية هذه فحص: اعتماد بايت لم تجميد ربط، تثبيت جهاز تسجيل، بدء، ترقية و بيانات إبقاء ما زال هو واضح شخص عمل فحص بند. إبقاء قديم حزمة قد إتمام حقيقي عودة ملف قراءة؛ هذا دفعة مرة دقيق تجهيز إصدار كامل توقيع حزمة فحص ما زال انتظار تنفيذ.

التزام دوران مستقل[فوق نقل و إصدار خطوة](publication/README.ar.md). أولا إبقاء ثابت feed لا وجود بـ اختبار 404، مجددا إصدار إصدار 1 بـ اختبار نفس إصدار. اثنان عدد مشهد في قد تثبيت إصدار 1 تطبيق داخل إتمام قبل، إصدار 2 بيانات وصفية إبقاء في محلي. إبقاء إصدار سجل و بعيد طرف كائن لأجل تشخيص، لا حذف قد إصدار feed قدوم إعادة بناء مقارنة مبكر مشهد.

محلي `files` أمر قبول `<run.json>` و هذا دفعة مرة واحد دقيق تأكيد إصدار. هو قراءة هذا إصدار `installer/nightly.yml`، تحقق مسبق مدة تثبيت حزمة ملف اسم، كبير صغير،SHA-512 و غير فارغ خارجي blockmap، إخراج قسم فتح اثنان دخول صنع هدف و ثابت feed محتوى. تثبيت حزمة ناقص سوف توجيه يؤدي تحقق فشل. هو لا كتابة ملف، أيضا لا قراءة اعتماد. ذلك `file-integrity-only` نتيجة لا يستطيع تخويل فوق نقل، أيضا لا يستطيع بديل توقيع حزمة محتوى و تطبيق هوية تحقق؛ هذه ما زال هو إصدار قبل لا بد يلزم شرط.

## شخص عمل عملية ترتيب

فقط في دقيق تجهيز عبر بعد قريب يد عملية. استخدام يمكن إسقاط اختبار جلسة و ضبط، لا استخدام إنتاج مساحة العمل أو لم حفظ عمل.

1. تثبيت إصدار 1. سجل تثبيت حزمة مسار، ها أمل، توقيع نتيجة و وقت. عبر تثبيت بعد سريع سريع طريقة بدء، نواة مقابل يمكن تنفيذ ملف مسار و واجهة إصدار؛ لا يلزم بدء حل حزمة دليل في تطبيق أو تطوير خادم.
2. تأكيد جديد سجل يتضمن إصدار 1 `started` و `workspace-ready`. إنشاء يمكن تمييز إقرار اختبار جلسة و تعديل واحد بند بلا ضرر ضبط، في محلي سجل مسبق مدة قيمة. إتمام تحت وجه اثنان بند feed فحص، و إبقاء إصدار 1 تشغيل.
   - **بيان ناقص:**إبقاء مقابل إعداد ثابت URL تنفيذ GET إرجاع 404 حمل ختم الوقت سجل. مراقبة بدء تلقائي فحص لا نابض خروج ضرب إزعاج صفة نابض نافذة، مجددا يد حركة فحص: مسبق مدة أولا فحص، بعد تلميح فشل، بينما غير “مؤقت بلا تحديث” ، كما لا تحت تحميل، لا تثبيت. إصدار أي بيان قبل أولا حفظ قطع رسم و سجل.
   - **نفس إصدار بيان:**آخر سطر تخويل بعد سوف إصدار 1 إصدار إلى نفسه URL، إبقاء كامل 200 استجابة، إصدار و SHA-512. في ما زال تشغيل إصدار 1 داخل يد حركة فحص: مسبق مدة عرض مؤقت بلا متاح تحديث و حالي إصدار، لا تحت تحميل، لا تثبيت، كما لا ناقص إبقاء هذا قبل 404 خطأ رسم علامة. تلقائي فحص بلا تحديث وقت ينبغي ساكن صامت. تخويل إصدار 2 قبل أولا إبقاء دليل.
3. تخويل سوف إصدار 2 بيانات وصفية إصدار إلى قد لديه ثابت feed URL. عودة قراءة هذا URL، تحقق إصدار 2 و ذلك اثنان دخول صنع ها أمل. إبقاء متأخر في إصدار 1 بدء دليل إصدار دليل.
4. في إصدار 1 في يد حركة فحص، تأكيد تلميح متاح إصدار لكن لا تلقائي تحت تحميل. دقيق تجهيز مرور مرور مراجعة فحص[فقط إبرة مقابل اختبار تطبيق لذا عائق و استعادة](network/README.ar.md). أبدا منع استخدام شبكة بطاقة،VPN، مشترك بديل إدارة، بعيد تحكم اتصال أو كامل مجال اسم وصول.
5. نقر تحت تحميل، في دخول درجة بدء بعد فقط في قطع اختبار تطبيق نقل. قطع أخذ مرة فشل و حمل متابعة إعادة محاولة تلميح، تأكيد لا تثبيت أو ساكن صامت إعادة محاولة. دخول درجة بدء قبل اتصال فشل هو آخر نوع مراقبة قياس، لا يستطيع ممتلئ كاف نقل في قطع اختبار.
6. إزالة هذا دفعة مرة دقيق تأكيد لذا عائق ضبط و تحقق استعادة. قريب يد نقر إعادة محاولة. سجل دخول درجة، تحقق و حينئذ خيط. مسبق مدة ظهور مستقل تثبيت تأكيد؛ تحت تحميل إتمام ذاته لا نيل تخويل إعادة بدء.
7. تأكيد تثبيت. لديه مهمة وقت فحص تحذير إبلاغ و صريح تخويل إيقاف؛ لا يوجد مهمة وقت، تأكيد محتوى لا نيل صوت تسمية وجود مهمة. سجل إصدار 1 الأكثر بعد نافذة، يجعل تثبيت و إعادة بدء ذاتي لكن انتهاء، لا يد حركة بدء آخر نسخة.
8. تحقق تثبيت بعد إصدار 2 يمكن تنفيذ ملف و واجهة إصدار. فحص رقم 2 خطوة جلسة و ضبط و قطع رسم. في نفس خارجي دليل دليل في بحث إلى إصدار 2 `started` و `workspace-ready`. تلقائي إعادة بدء ناقص و يد حركة بدء نجاح قسم فتح تقرير إبلاغ، اثنان من لا يستطيع متبادل متبادل بديل.

## دليل و استعادة

لذا معنى إبقاء 404 يخص فحص فشل، لا هو لاحق تحت تحميل في قطع مشهد. فقط لديه متصفح استجابة لا يستطيع إثبات تطبيق سلوك. كل مرة مراقبة قياس URL،UTC وقت،HTTP حالة، وجود وقت feed أصل نص و ها أمل، قطع رسم و سجل لقطة ينبغي واحد نفس حفظ. سجل فحص جهاز لا إقرار إثبات هذا اثنان عدد feed مشهد، أيضا لا سجل أصلي HTTP تشخيص؛ هذه مراقبة نتيجة من عملية من توفير. لاحق يد حركة فحص نجاح ينبغي بلا حاجة إعادة بدء تطبيق يكفي استعادة.

إبقاء بيان، بناء سجل، أصلي feed، اثنان دخول صنع ها أمل، إصدار عودة تنفيذ و عودة قراءة، لذا عائق ضبط و إزالة دليل، قطع رسم و الكل عملية سجل. تثبيت جهاز سجل و اختبار بيانات ممكن يتضمن خاص مسار أو محتوى، قسم مشاركة قبل يجب مراجعة فحص. فحص جهاز فقط قراءة، فقط نسخ داخل مسار نصب مرجع، لا نسخ أصلي تشخيص. استبدال دليل احتلال موضع رمز و استخدام بيان في دقيق تأكيد إصدار:

```powershell
node --import tsx apps/desktop/scripts/prepare-installed-update.ts inspect 0.1.6-alpha.1.20260916.1 0.1.6-alpha.1.20260916.2 "<journal-directory>"
```

خروج رمز 0 يمثل حسب ترتيب سجل علامة متساو كل؛ خروج رمز 2 يمثل نقص قليل علامة؛ خروج رمز 1 يمثل إدخال أو أمر تحقق فشل. فشل إعادة محاولة تسلسل لا يستطيع تجميع وصل مختلف إصدار 1 عملية. مبكر في أصل عملية خروج حينئذ بدء بعد استمرار عملية لا حساب دخول؛ نظام وقت تغير ممكن توجيه يؤدي دليل لا كامل، حاجة ضبط فحص.`recordedFlow: complete` لا انتظار في كامل تجربة استلام عبر. تقرير إبلاغ بداية نهاية اشتراط مستقل شخص عمل فحص إصدار وقت، شبكة شبكة فشل و استعادة، تثبيت جهاز إتمام و مسار، بيانات إبقاء و قطع رسم و تأكيد.

استخدام `collect` و مطابقة تثبيت تطبيق `dsh-update-qualification/<run-id>/journals` دليل حفظ محلي سجل لقطة و تقرير إبلاغ. هو أولا تحقق كل اختيار في سجل، مجددا في شيء مادة دفعة مرة تحت إنشاء جديد `evidence/collection-*`. نسخ سجل و `report.json` وصف نفس نسخة داخل تخزين لقطة، يتضمن SHA-256 و `operatorAcceptance: pending`؛ أصل ملف إبقاء ثابت. لا استلام تجميع أخرى ملف، ضبط، جلسة، بناء إخراج أو اعتماد. سوف هذه آخر خارج مراجعة فحص مرور دليل و تقرير إبلاغ واحد نفس إبقاء، لا وضع دخول سجل دليل.

```powershell
node --import tsx apps/desktop/scripts/prepare-installed-update.ts collect "<run.json>" "<journal-directory>"
```

استلام تجميع خروج رمز 0 يمثل ملف قد حفظ، أي جعل سجل مسار لا كامل؛ تحت ربط نقاش قبل فحص `report.json`. كتابة فشل وقت إبقاء جزء إخراج، و في تخزين سماح وقت إبقاء تحت فشل علامة. تكرار استلام تجميع إنشاء جديد دليل، لا استبدال قديم دليل. فحص و استلام تجميع رفض لا كامل ربط ذيل، لم معرفة حقل أو تشخيص قيمة، تجاوز مرور 10 MiB ملف و تجاوز مرور 50 MiB لقطة. متبادل صلة عملية مستقر بعد مجددا استلام تجميع؛ تشغيل في تطبيق ممكن في لقطة بعد إلحاق سجل، تنافس تنازع في لا كامل إلحاق اشتراط قليلا بعد مجددا استلام تجميع، لا يستطيع قطع قطع أصل سجل. حقيقي تثبيت تطبيق استلام تجميع ما زال يحتاج شخص عمل تنفيذ؛ اختبار استخدام حقيقي سجل كتابة جهاز و دمج صار دورة الحياة عملية.

## ملاحظة تطوير

محلي دفعة مرة إنشاء و سجل فحص قد لديه تلقائي تحويل اختبار. توقيع ناتج توليد، عزل شبكة شبكة لذا عائق أداة، تأخير بعد feed إصدار، تثبيت جهاز إطلاق إعادة بدء و كامل شخص عمل مسار ما زال يحتاج مفرد وحيد تحقق استلام؛ هذا صفحة لا سوف ذلك تقرير إبلاغ لـ قد إتمام.
