# اختبار تطبيق شبكة لذا عائق

[English](README.md) | العربية

## ملخص

فقط في قطع قد تثبيت تحقق استلام تطبيق خروج محطة تدفق كمية، مجددا إزالة هذا دقيق تأكيد قاعدة بعد إعادة محاولة تحديث. أداة أبدا منع استخدام شبكة بطاقة،VPN، بديل إدارة أو منع نار جدار ملف إعداد. حقيقي تدفق كمية في قطع ما زال يجب من عملية من مراقبة؛ اختبار استبدال الكل منع نار جدار أمر.

## دقيق تجهيز

حسب وفق[عرض تدريب إشارة جنوب](../README.ar.md) إتمام إصدار 1 تثبيت حزمة تحقق و تثبيت هذا إصدار. توفير قد تثبيت يمكن تنفيذ ملف، بينما غير حل حزمة ناتج. في مستودع أصل دليل دقيق تجهيز خطة:

```powershell
node --import tsx apps/desktop/scripts/prepare-installed-update-network.ts "<run.json>" "<installed-test.exe>" "<verification/result.json>"
```

دقيق تجهيز جهاز اشتراط إصدار 1 هوية و توقيع دليل، دقيق تأكيد اختبار ملف اسم و مطابقة يمكن تنفيذ ملف بايت. هو تحليل Windows قصير مسار، رفض شيء مادة دفعة مرة دليل داخل يمكن تنفيذ ملف. هو وحيد احتلال كتابة `network-fault/plan.json`، لا تغيير شبكة حالة. إبقاء أصلي خطة، هو معرف وحيد يمكن إزالة قاعدة. تثبيت تسجيل ما زال يجب عملية من مستقل تحقق.

<a id="operate"></a>

## منع قطع و استعادة

التالي هو انتظار تنفيذ شخص عمل خطوة، لا هو حقيقي منع نار جدار تحقق استلام عبر تقرير إبلاغ. استخدام إدارة عضو طرفية، و في منع قطع قبل دقيق تجهيز ثاني عدد طرفية و Restore أمر. كل مرة استدعاء كتابة جديد سجل.`Status` هو افتراضي حركة عمل، لا تغيير منع نار جدار حالة. تنفيذ سياسة خيار فقط أثر هذا مرة PowerShell عملية، لا تعديل نظام سياسة.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File apps/desktop/scripts/installed-update-network.ps1 -Plan "<plan.json>" -Action Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File apps/desktop/scripts/installed-update-network.ps1 -Plan "<plan.json>" -Action Block
powershell.exe -NoProfile -ExecutionPolicy Bypass -File apps/desktop/scripts/installed-update-network.ps1 -Plan "<plan.json>" -Action Restore
```

بدء Block، توقف إبقاء في تأكيد تلميح، مجددا بدء تحت تحميل. ظهور صحيح دخول درجة بعد، إدخال تلميح في `BLOCK <run-id>` تأكيد. نص برمجي مجددا مرة فحص يمكن تنفيذ ملف بايت و قاعدة لا وجود، مجددا إنشاء واحد بند إشارة تحديد برنامج خروج محطة منع قطع قاعدة. مراقبة و قطع أخذ فعلي تحت تحميل فشل؛ فقط إنشاء قاعدة لا كاف. تنفيذ Restore و إدخال `RESTORE <run-id>`، إزالة مطابقة قاعدة، مجددا قريب يد نقر إعادة محاولة.Status يجب تقرير إبلاغ قاعدة لا وجود. أبدا تعديل غير متصل قاعدة قدوم قوي سطر صنع صنع فشل.

<a id="evidence"></a>

## دليل و نطاق حد

نص برمجي سوف حمل وقت مرحلة مقطع و نهائي نجاح/فشل تحديث دخول `network-fault/records/<id>/events.jsonl`. خروج خطأ أي توقف، أبدا إعادة محاولة، أيضا لا في إنشاء فشل بعد ساكن صامت حذف قاعدة. نتيجة لا تحديد وقت صريح تشغيل Restore. استعادة فحص قاعدة اسم، ملكية شرح، جهة نحو، حركة عمل و دقيق تأكيد برنامج مسار، لا اشتراط يمكن تنفيذ ملف ما زال وجود. قاعدة لا وجود وقت أمان أرض لا عملية؛ لن إزالة مطابقة اسم خارج قدوم قاعدة.

Windows دعم حمل[إشارة تحديد برنامج خروج محطة قاعدة](https://learn.microsoft.com/en-us/windows/security/operating-system-security/network-security/windows-firewall/configure-with-command-line). محلي سياسة، قد لديه اتصال أو تأكيد قبل تحت تحميل قد انتهاء، كل ممكن جعل مسبق مدة في قطع لا يوجد حدوث.PersistentStore في لديه قاعدة لا إثبات تدفق كمية تأكيد فعلي يتم منع قطع. إبقاء تطبيق فتح، مراقبة ذلك فشل و لاحق نجاح إعادة محاولة؛ مهمة واحد الآن كائن ناقص كل سوف هذا مرة محاولة تجربة سجل لـ لم إتمام. قاعدة سوف حمل متابعة وجود مباشر حتى إزالة، إعادة بدء أيضا لن تلقائي حذف. إبقاء خطة و استعادة طرفية؛ اختبار قاعدة ما زال وجود وقت أبدا تثبيت تحديث.

<a id="dev-note"></a>

## ملاحظة تطوير

محلي خطة تحقق و فعلي PowerShell تحكم مسار قد لديه بلا شبكة تعديل اختبار. حقيقي قاعدة إنشاء، صالح في قطع و استعادة يجب من عملية من في نيل دقيق قد تثبيت تطبيق عرض تدريب في تنفيذ.
