# `dsh` CLI(أمر سطر واجهة) سلوك مشاركة اعتبار

[English](README.md) | العربية

هذا مشاركة اعتبار تعريف profile بدء، إضافة إدارة و إعداد dump انتظار أمر نمط.argv من [`src/args.ts`](../src/args.ts) موحد واحد تحليل مرة،[`src/bin.ts`](../src/bin.ts) فقط سوف حركة حالة استيراد اختيار في تشغيل جهاز.

<a id="profile-boot"></a>

## Profile بدء

`dsh <name>` هو `dsh --profile <name>` بسيط كتابة، بدء يقع في `$DSH_HOME/profiles/<name>` profile. بسيط كتابة في اسم يجب ضيق تتبع `dsh`؛`plugin` ما زال لـ إضافة إدارة أمر، لذلك بدء نفس اسم profile وقت يجب استخدام `dsh --profile plugin`. توليد فاعلية إعداد شجرة بـ فارغ أصل عقدة لـ بدء نقطة، اعتماد مرة تراكم إضافة profile manifest(بيانات وصفية بيان) `dsh.profile.bundles` قائمة في إشارة تحديد كل تركيب حزمة patch،profile ذاته `cordis.patch.yml`،home درجة `$DSH_HOME/cordis.patch.yml`(هذا هو كل profile مشترك آلة جهاز محلي انحراف جيد، لذلك أولوية في تدريجي profile إعداد طبقة) ، و حسب argv ترتيب إشارة تحديد كل عدد `--patch <path>` تغطية طبقة. مقابل نفس إعداد سطر، بعد تطبيق طبقة أولوية.patch سوف استبدال هدف سطر كامل `config` قيمة، بينما لا هو عميق درجة دمج منها مفتاح؛patch أيضا يمكن إدراج دخول جديد سطر. نهائي YAML تركيب قرار هل من `dsh-hmr` مراقبة نظر إعداد؛ لم تفعيل HMR وقت، أكثر تعديل حاجة إعادة بدء. إعداد تحليل،schema تحقق، وحدة تحليل أو إضافة بدء فشل وقت، نظام سوف تقرير إبلاغ خطأ و بـ غير صفر حالة خروج. استلام إلى SIGINT أو SIGTERM وقت، تركيب أصل عقدة سوف أولا dispose(مورد تحرير) مجددا خروج.

تركيب حزمة اسم أولا من dsh تثبيت دليل تحليل، مجددا من profile دليل تحليل. لذلك، داخل وضع تركيب حزمة (`@deepseek-ai/dsh-base`،`@deepseek-ai/dsh-web-app`،`@deepseek-ai/dsh-headless`،`@deepseek-ai/dsh-sdk-app`،`@deepseek-ai/dsh-sdk-minimal`،`@deepseek-ai/dsh-acp-app`) بداية نهاية قدوم ذاتي حالي تشغيل `dsh` الذي تابع تثبيت؛ شجرة خارج تركيب حزمة قدوم ذاتي profile في من pnpm إدارة `node_modules`. تركيب إعداد سطر قبل،launcher سوف حسب هذا ترتيب مرة تاريخ تثبيت و الذي اختيار bundle، و سوف توليد غير ممكن تغيير generation تثبيت إلى Node وقت التشغيل محلل في. بدء لن إنشاء مشترك أو profile ذاتي لديه fallback رابط.profile قد تثبيت حزمة إبقاء أصلي أولوية درجة؛profile ابتدائي تحويل و حزمة إدارة جهاز كتابة و وقت التشغيل تحليل متبادل متبادل مستقل.

`web`،`headless`،`sdk`،`sdk-minimal` و `acp` profile أول مرة استخدام وقت سوف من مع مرفق نموذج لوح تلقائي ابتدائي تحويل (`web`:base + web-app، فوري تطبيق patch؛`headless`:base + headless، فقط في بدء وقت تطبيق patch؛`sdk`:base + sdk-app، فقط في بدء وقت تطبيق patch؛`sdk-minimal`: مستقل تركيب حزمة، فقط في بدء وقت تطبيق patch؛`acp`:base + acp-app، فقط في بدء وقت تطبيق patch). أخرى ناقص profile سوف صريح تقرير خطأ، و تلميح تشغيل `dsh plugin --profile <name> add <package>`.

`dsh --profile <name> --from-default-profile <template>` سوف في بدء قبل، من فوق وصف خمسة عدد مع مرفق نموذج لوح لـ واحد ابتدائي تحويل جديد ذاتي تعريف هدف. هدف اسم لا يستطيع هو مع مرفق profile اسم، و كما كامل هدف profile دليل يجب لا وجود.launcher سوف بـ وحيد احتلال طريقة قيادة أخذ هذا دليل، لذلك ناقص إبقاء ملف و آخر عدد تزامن إنشاء من كل سوف في لا عمل تعديل حال حال تحت يتم رفض. هو يأخذ نموذج لوح حالي تركيب حزمة قائمة نسخ دخول واحد نسخة اعتماد لـ فارغ، مستخدم patch لـ فارغ جديد manifest. هو لن قراءة `<template>` إشارة تحديد محلي نفس اسم profile، لن نسخ ذلك اعتماد أو patch، أيضا لن حفظ دائم وراثة حقل؛ نموذج لوح قائمة بعد تغير لن تعديل كتابة جديد profile. نسخ قائمة في إشارة اسم داخل وضع تركيب حزمة ما زال من حالي dsh تثبيت دليل تحليل. ابتدائي تحويل نجاح لن زيادة launcher إخراج.

profile قد وجود وقت،`--from-default-profile` سوف يتم رفض، كما لن تعديل أو بدء هو؛ ذهاب إسقاط هذا خيار يكفي استخدام هو. ناقص إبقاء هدف دليل نفس مثال سوف يتم أصل مثال إبقاء، هذا وقت يجب تعديل استخدام آخر عدد profile اسم. لم معرفة نموذج لوح أو مع مرفق هدف اسم سوف في إنشاء هدف قبل فشل؛ لم معرفة نموذج لوح تشخيص سوف صف خروج صالح نموذج لوح. ابتدائي تحويل في تركيب حزمة تحليل و تطبيق بدء قبل إيداع، لذلك لاحق فشل ما زال سوف يأخذ جديد profile إبقاء في مغناطيس قرص فوق، إعادة محاولة وقت حاجة ذهاب إسقاط إنشاء خيار.`--dump-config` و `--dump-default-config` قبول هذا خيار: هو جمع ابتدائي تحويل هدف و ضرب طبع الذي طلب إعداد شجرة، لكن لا بدء تطبيق.

```sh
dsh rescue --from-default-profile web
dsh rescue
```

### تطبيق معامل

بدء جهاز ذاته flag يجب كتابة في الأكثر قبل وجه، و في لقاء إلى رقم واحد لا يمكن تعرف آخر token وقت انتهاء؛ من هذا token بدء كل محتوى كل سوف عبر `ctx.cmdlineArgs` أصل مثال تسليم إعطاء قد بدء profile، حقن هذا profile مهمة معنى تطبيق إضافة كل يمكن تحليل هذه محتوى ([`dsh-cmdline`](../../../packages/boot/cmdline/README.zh.md)). لذلك،`dsh rescue --from-default-profile web --no-open` سوف أولا ابتدائي تحويل، مجددا يأخذ `--no-open` تسليم إعطاء Web؛`dsh --profile web --port 8080` سوف سوف `--port` تسليم إعطاء web تطبيق؛`dsh --profile web --help` فقط ضرب طبع هذا تطبيق مساعدة مساعدة معلومة، لا بدء تطبيق؛`dsh --help` لا يوجد يمكن توفير تسليم معامل profile، لذلك سوف ضرب طبع بدء جهاز ذاته مساعدة مساعدة معلومة.`-V`/`--version` يقع في تطبيق معامل حد قبل وقت، سوف ضرب طبع بدء جهاز إصدار.

كل طقم تركيب فقط سوف تركيب مرة. عادي إضافة حقن `cmdlineArgs`، تحليل الذي تابع تطبيق معامل، و سوف تحليل نتيجة بصفة خدمة توفير. كل من flag أخذ قيمة إعداد سطر كل سوف حقن هذا خدمة؛Loader سوف انتظار إلى خدمة تنشيط بعد، مجددا مقابل هذا سطر إعداد طلب قيمة (`port: !!js ctx.webStartup.port ?? 3080`) ، لذلك flag أولوية درجة عال في إعداد سطر في كتابة واضح قيمة. يلزم صيانة حمل هذا واحد أولوية درجة، إعداد سطر يجب إبقاء هذا جدول بلوغ صيغة؛ إذا مستخدم patch استخدام حرف وجه كمية استبدال كامل `config`، أيضا سوف مع لـ إزالة وقت التشغيل قراءة. مساعدة مساعدة معامل و يتم رفض معامل كل سوف طلب خروج: معامل يتم رفض وقت بـ غير صفر حالة خروج، عرض مساعدة مساعدة وقت بـ 0 خروج؛ اعتماد هذا مزود خدمة إعداد سطر لن تنشيط. تفعيل HMR وقت، تحرير patch ملف سوف أصل حسب ما زال في تشغيل خدمة إعادة حساب حساب جدول بلوغ صيغة، لذلك لن إعادة وضع حالي صحيح في استخدام طرف فتحة.

بدء جهاز flag يجب كتابة في تطبيق معامل قبل، كما بدء جهاز محلل سوف إزالة استهلاك إسقاط واحد `--`: يجب بـ حرف وجه كمية `--` إرسال بلوغ تطبيق معامل حاجة كتابة صار `-- --`.`plugin` فقط في ضيق تتبع `dsh` وقت اختيار إضافة إدارة أمر؛ اختيار تحديد profile بعد،`plugin` و `web` كل هو عادي تطبيق معامل. تطبيق معامل بدء قبل، تكرار إشارة تحديد `--profile` سوف يتم رفض، يشمل بسيط كتابة بعد مجددا إشارة تحديد `--profile` حال حال.`ctx.cmdlineArgs.get()` هو مشترك غير ممكن تغيير قراءة: كثير عدد إضافة يمكن تحليل نفس نسخة لقطة، لا يوجد قراءة جهة profile فإن سوف تجاهل اختصار ذاتي ذات تطبيق معامل.

مع مرفق تطبيق قبول التالي أمر سطر معامل:

| Profile | معامل |
|---|---|
| `web` | `--host`،`--port`، يمكن تكرار `--trusted-host`،`--no-open` |
| `headless` | مهمة نص، بصفة موضع معامل |
| `sdk` | بلا خيار؛stdio يحمل JSON-RPC بروتوكول |
| `sdk-minimal` | بلا خيار؛stdio يحمل نفسه JSON-RPC بروتوكول |
| `acp` | بلا خيار؛stdio يحمل ACP(Agent Client Protocol) |

مرة صفة مهمة (`dsh --profile headless "run the tests"`) عبر نواة قلب سجل التسجيل إنشاء واحد كل جديد حفظ دائم Agent(ذكي جسم) ، إيداع مهمة، انتظار تماما توقف مستقر و مقابل جلسة تنفيذ flush، مجددا من ذلك حفظ دائم حدث منطقة بين في دفع توجيه الأكثر بعد واحد غير فارغ assistant نص و نهائي `turn/end` سبب. هو في `dsh: reasoning:` عنوان تحت سوف غير فارغ مزود دفع إدارة (reasoning) زيادة كمية تدفق صيغة كتابة stderr، فقط في stdout ضرب طبع نهائي نص، و في سبب لـ `completed` وقت بـ 0 خروج، لا فإن بـ 1 خروج؛ لا يوجد دفع إدارة محتوى نجاح استجابة سوف إبقاء stderr لـ فارغ. لا يوجد مهمة استدعاء هو هذا تطبيق استخدام قاعدة خطأ. مع مرفق headless profile لا تركيب متصفح Connection،HTTP خادم،Web وقت التشغيل أو متصفح عميل، أيضا لن فتح استماع طرف فتحة.

يمكن في لا بدء حال حال تحت فحص تركيب خروج إعداد شجرة:

```sh
dsh --profile web --dump-default-config
dsh --profile web --patch ./extra.yml --dump-config
```

`--dump-default-config` فقط ضرب طبع تركيب حزمة كل طبقة؛`--dump-config` مقدار خارج إضافة فوق profile `cordis.patch.yml`،home درجة `$DSH_HOME/cordis.patch.yml` و `--patch` overlay. اثنان من كل سوف ضرب طبع ملاحظة تفسير، علامة واضح كل سطر من أي عدد ملف توفير، و أي بعض overlay تعديل مرور هو؛`!!js` جدول بلوغ صيغة إبقاء لم طلب قيمة، إدراج دخول سطر في متبادل مقابل إضافة اسم بـ كل منها patch ملف الذي في دليل تحليل، بحث لا إلى هدف patch سوف تقرير إبلاغ إلى stderr.dump عملية سوف ابتدائي تحويل ناقص profile ملف، لكن لن دقيق تجهيز `$DSH_HOME/profiles/node_modules` تحت وقت التشغيل وحدة fallback. هو لن تشغيل تطبيق أمر سطر معامل مزود، لذلك عرض هو تحليل أي تطبيق معامل قبل تركيب إعداد شجرة؛ إذا استدعاء في يتضمن تطبيق معامل،dump سوف رفض هذا استدعاء.

## بدء تشخيص

مطلوب إضافة تنشيط فشل وقت،CLI أولا إخراج فشل إضافة و ذلك أصلي كومة مكدس، مجددا صف خروج انتظار في إضافة و ناقص خدمة. انتظار قائمة في مطلوب إضافة ترتيب في قبل وجه. نهاية ذيل `Full diagnostics:` سطر إشارة نحو مباشر يقع في `$DSH_HOME/logs/`(افتراضي `~/.dsh/logs/`) تحت وحيد `startup-<timestamp>-<uuid>.log` ملف.CLI إتمام تقرير إبلاغ و stderr كتابة بعد سوف واضح بـ خروج رمز 1 انتهاء، أي جعل إضافة ما زال لديه فتح جملة مقبض؛ لن تغطية بـ قبل تقرير إبلاغ، أيضا لن تلقائي حذف هو جمع.

تقرير إبلاغ يتضمن DSH و Node إصدار، منصة،profile، أصل إعداد مسار، كل لم تنشيط إضافة وحدة و حالة، أصلي خطأ، و بدء خلال تحذير إبلاغ و خطأ معامل، يشمل بعد بلا Fiber استيراد خطأ.Node فحص إخراج إبقاء تضمين طقم سبب، تجمع دمج عضو، حلقة مرجع، غير ممكن قطعة رفع خاصية و Symbol خاصية، و إغلاق عميق درجة، نص و عدد مجموعة طويل درجة حد. ذاتي تعريف فحص دالة يتم منع استخدام، وصول جهاز فقط وصف بينما لا طلب قيمة. استلام تجميع جهاز يتضمن فشل بعد مختلف خطوة تنظيف سجل، و في بدء تسوية بعد إيقاف. هو لن مستقل في قد سجل خطأ مقدار خارج استلام تجميع بيئة متغير أو إعداد محتوى. إضافة أصلي خطأ ممكن يتضمن إعداد أو اعتماد قيمة؛ تقرير إبلاغ فتح رأس سوف رفع تنبيه قراءة من في قسم مشاركة قبل فحص محتوى. تقرير إبلاغ لا انفصال حساس.

في POSIX فوق، جديد دليل و ملف قسم آخر طلب `0700` و `0600` إذن.CLI فقط في كتابة نجاح بعد إخراج ملف مسار. إذا سجل دليل أو ملف لا يمكن كتابة،stderr سوف يتضمن كتابة خطأ و كامل تقرير إبلاغ، خروج رمز ما زال لـ 1. فقط لديه اختياري إضافة تنشيط استثناء وقت، صيانة حمل صحيح معتاد تحذير إبلاغ إخراج، لا إنشاء تقرير إبلاغ.

## إضافة إدارة

`dsh plugin --profile <name> <args...>` في profile ناقص وقت أولا ابتدائي تحويل هو (لديه مع مرفق نموذج لوح استخدام نموذج لوح، أخرى اسم فقط تركيب `@deepseek-ai/dsh-base`) ، لكن بعد بـ profile دليل لـ عمل دليل، يأخذ `<args...>` تحويل إرسال إعطاء `pnpm`:`add`،`remove`،`why`،`update` و أخرى كل pnpm فرعي أمر كل وفق معتاد متاح؛pnpm يجب في PATH فوق. متبادل مقابل مسار spec(`.`،`../plugin` و ذلك `file:`/`link:` شكل صيغة) سوف أولا مرساة تحديد إلى استدعاء دليل، لذلك في إضافة checkout في تنفيذ `add .` تثبيت هو هذا checkout، بينما لا هو profile. كل مرة نجاح تشغيل بعد، نظام كل سوف أصل حسب حالي تثبيت حالة تحديث `dsh.profile.bundles`: إذا بعض بند اعتماد تحليل إلى حزمة في manifest في إعلان `"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`، هذا اعتماد حينئذ سوف إضافة دخول إعداد طبقة مكدس؛ إذا بعض بند اعتماد في `update` بعد نيل نيل هذا إعلان، أيضا سوف مع أي تنشيط. لا يوجد تركيب حزمة إعلان اعتماد ما زال بصفة عادي اعتماد إبقاء، و عرض مرة صفة تحذير إبلاغ؛ قد إزالة اعتماد فإن من إعداد طبقة مكدس في حذف.

Codex و Claude Code subagent مزود هو اثنان عدد ذاك هذا مستقل اختياري تركيب حزمة. يمكن فقط إضافة واحد حزمة، في نفس أمر في إضافة اثنان عدد حزمة، أو مستقل إزالة مهمة واحد حزمة:

```sh
dsh plugin --profile <name> add @deepseek-ai/dsh-subagent-codex
dsh plugin --profile <name> add @deepseek-ai/dsh-subagent-claude-code
dsh plugin --profile <name> add @deepseek-ai/dsh-subagent-codex @deepseek-ai/dsh-subagent-claude-code
dsh plugin --profile <name> remove @deepseek-ai/dsh-subagent-codex
dsh plugin --profile <name> remove @deepseek-ai/dsh-subagent-claude-code
```

pnpm عملية نجاح بعد سوف تغيير مغناطيس قرص فوق Profile manifest و تركيب حزمة قائمة؛ صحيح في تشغيل Profile سوف إبقاء هذا مرة بدء وقت تركيب حزمة تجميع دمج. إضافة، إزالة أو تحديث تركيب حزمة بعد يجب إعادة بدء هذا Profile. هذا عدد بدء حد فقط ملائم لأجل تركيب حزمة عضو تغير،Profile أو home في عادي `cordis.patch.yml` تحرير عبر حار إعادة تحميل توليد فاعلية. تحت مرة بدء وقت، كل قد تثبيت تركيب حزمة فقط تسجيل ذاتي ذات راحة نوم Host مزود؛ أيضا يجب في نسخ خروج Preset في مفرد وحيد تفعيل مقابل أداة سطر، جديد Agent عندئذ قدرة يرى هذا أداة.[Codex provider README](../../../packages/subagent/subagent-codex/README.zh.md) و [Claude Code provider README](../../../packages/subagent/subagent-claude-code/README.zh.md) مسؤول يمكن تنفيذ ملف، هوية تحقق، تحميل حمل و فشل دقيق عقدة؛[base تركيب حزمة مشاركة اعتبار](../../../packages/bundle/base/README.zh.md) مسؤول افتراضي اعتماد إغلاق حزمة.

```sh
dsh plugin --profile tui add github:deepseek-harness/turtle-ui
dsh plugin --profile tui remove turtle-ui
dsh --profile tui
```

مع شفرة المصدر إصدار Git حمل إدارة إضافة سوف في تثبيت خلال عبر `prepare` نص برمجي بناء، بينما pnpm ≥10 افتراضي سوف منع توقف هذا نص برمجي، مباشر إلى استخدام جهة واضح سماح. أول مرة تشغيل `add` سوف فشل، و عرض pnpm `allowBuilds` تلميح؛dsh أيضا سوف تلميح ينبغي تعديل هذا profile `pnpm-workspace.yaml`. سوف إخراج مفتاح نسخ إلى هذا ملف بعد، إعادة تشغيل أمر يكفي. تثبيت قد بناء جيد tarball أو محلي checkout وقت، بلا حاجة إضافة دخول `allowBuilds`.

## Web Profile

`dsh web` استخدام profile بسيط كتابة. بدء جهاز أولا تحليل ذاته flag، ذلك بقية flag يخص web تطبيق، من تركيب حزمة في عادي مزود تحليل.`--host` و `--port` تغطية تحمل تحميل هو جمع ذلك بعض سطر تركيب أخذ قيمة، يمكن تكرار `--trusted-host` عبر `ctx.webRuntime.trustedHosts` توفير هذا مرة استدعاء authority(نشر جدول بلوغ صيغة سوف تجميع وصل ذاتي ذات authority) ،`--no-open` فإن فقط مقابل هذا مرة استدعاء إغلاق افتراضي متصفح تسليم وصل. عميل إضافة HMR(حار وحدة استبدال) استقبال جهاز بداية نهاية تركيب، في مفرد وحيد تشغيل `pnpm run dev:web` watcher إعادة بناء عميل bundle قبل إبقاء فارغ خامل.

```sh
dsh web
dsh web --no-open
dsh web --patch ./extra.cordis.yml
dsh web --dump-config
dsh web --help
```

إنتاج Web تشغيل جهاز حاجة قد بناء حزمة و قبل طرف ناتج (`pnpm run build`). افتراضي خدمة عنوان هو `http://127.0.0.1:3080`؛ هذا آلة بدء وقت، فقط في كامل Loader إعداد شجرة تسوية بعد عندئذ استخدام افتراضي متصفح فتح هذا مواصفة مضيف آلة URL. وراثة `SSH_CONNECTION` أو `SSH_TTY` غير فارغ وقت سوف قفز مرور متصفح تسليم وصل، لأن محلي تحويل إرسال عنوان من SSH عميل أو تحرير جهاز يحتفظ؛ مضيف آلة URL ما زال سوف ضرب طبع.CLI متعمد لا دعم حمل `--host 0.0.0.0`، و سوف بـ استخدام قاعدة خطأ خروج. هذا آلة تسليم وصل قبل سوف ضرب طبع إنجليزي نص تلميح `dsh web: opening the default browser; pass --no-open to disable`؛ إذا عملية نظام تسليم وصل فشل،stderr تشخيص سوف شرح سبب، إعطاء خروج URL توفير يد حركة وصول، خادم ما زال متابعة تشغيل.`--trusted-host` يمكن إضافة `/api` متصفح معلومة مهمة محيط شريط قبول أداة اسم authority.

عملية إغلاق وقت، إضافة شجرة الأكثر كثير لديه 5 ثانية إتمام dispose. أول مرة استلام إلى `SIGINT` أو `SIGTERM` وقت سوف بدء أفضل أنيق ترتيب فارغ:`SIGTERM` هو مراقبة إشراف عملية إرسال خروج معتاد قاعدة إيقاف طلب، في كل تشغيل نمط تحت كل بـ 0 خروج؛`SIGINT` فإن تقرير إبلاغ 130. ثاني مرة استلام إلى إشارة وقت سوف قيام أي قوي صنع خروج. إذا مرة صفة تشغيل في صحيح معتاد انتهاء وقت قد بطاقة في dispose مرحلة مقطع، رقم مرة حسب تحت `Ctrl+C` حينئذ سوف مباشر ترقية لـ قوي صنع خروج، بينما لن يتم تجاهل اختصار.

أساس في base نمط كل سوف تشغيل أمر وقت الذي في دليل بصفة افتراضي workspace أصل دليل، بـ 65,536 بايت تصيير ميزانية تحميل ملائم استخدام `AGENTS.md` أو `CLAUDE.md` إشارة أمر، و استخدام داخل تخزين SQLite جلسة محتوى بحث جذب. مستقل `sdk-minimal` profile يأخذ تشغيل أمر وقت الذي في دليل بصفة صندوق رملي سياسة أصل دليل، لكن لحظة معنى حذف نظام الملفات أداة، إشارة أمر اكتشاف و SQLite. تفعيل HMR إضافة سوف مراقبة نظر profile و home اثنان عدد `cordis.patch.yml` إعداد طبقة صالح تغيير، و بـ أمر خدمة طريقة إعادة تطبيق؛ لم تفعيل HMR وقت فقط تطبيق مرة. مرة صفة تشغيل نمط عبر محدود إغلاق مسار خروج، هذا مسار سوف dispose كل فوري مراقبة نظر جهاز.

أساس في base profile في، جديد جلسة افتراضي استخدام `workspace-write` إذن مسبق ضبط.Bash و نظام الملفات تعديل فقط حد في جلسة workspace و منصة مؤقت أصل دليل؛ قراءة و شبكة شبكة وصول لا تلقي حد، عملية مرئي صفة فإن أخذ قرار في الذي اختيار صندوق رملي خلفية——bwrap في خاص PID نطاق الأسماء في تشغيل أمر و إخفاء مضيف عملية،Landlock و Seatbelt إبقاء مضيف عملية مرئي صفة ثابت.`DSH_PERMISSION_MODE` أكثر تعديل عملية بعد تجهيز قيمة.General settings في تخزين إذن أثر لاحق Web جلسة، لا تغيير قد فتح جلسة. مستقل `sdk-minimal` إعداد شجرة فإن ثابت لـ `danger-full-access`، كما لا تركيب approval أو إذن settings خدمة.

`DSH_TOOLS_MODE` لـ عملية اختيار `native`،`ptc` أو `both`؛ أخرى قيمة سوف توجيه يؤدي بدء فشل. مع مرفق `minimal` agent preset سوف إبقاء هذا نشر عرض طريقة، سوف كامل توجيه النظام ثابت لـ `You are a helpful software engineer assistant.`، و كما فقط تركيب حسب منصة اختيار حمل دائم shell. إنشاء Web جلسة وقت طلب اختيار أقصى بسيط نمط؛ هذا agent لا يتضمن أي أخرى نص التوجيه مقطع سقوط أو موجه إلى نموذج إضافة، بينما مشترك متصفح،workspace، حفظ دائم، صندوق رملي و إذن مضيف إبقاء ثابت.

## مشترك نشر سلوك

أساس أساس تركيب حزمة تركيب أصلي DeepSeek مهايئ،settings و اعتماد مزود، مستقر `web_search` و `web_fetch`، فقط حد عام شبكة HTTP fetch مزود، افتراضي فتح بدء DeepSeek جلسة سجل فوق نقل، و موجه إلى كل مستخدم عكس تغذية باب تحكم OTel فوق نقل. مزود اعتماد اعتماد مرة من وراثة بيئة،`$DSH_HOME/.credentials.yaml`، استدعاء دليل `.env` و `$DSH_HOME/.env` تحليل؛ تلقي إدارة وثيقة من لا شيء تحويل دخول `process.env`، بينما اثنان عدد `.env` ملف كل هو عادي بدء بيئة طبقة. بحث استخدام `DEEPSEEK_API_KEY` و قبول `DEEPSEEK_SEARCH_BASE_URL`. قد تفعيل إمساك أخذ استدعاء سوف في كل sandbox و مراجعة دفعة نمط تحت تنفيذ، بلا حاجة تدريجي مرة تأكيد؛ مزود سوف في اتصال قبل رفض غير عام هدف عنوان.Web app سوف منع استخدام base أداة بند إعداد، مجددا عبر `cordis`،`ptc` و `standard` agent preset كشف نفسه أداة.

عكس تغذية سجل في جلسة سجل في، لن بدء نموذج عمل.[DeepSeek جلسة سجل مساهمة جهاز](../../../packages/session/session-log-deepseek/README.zh.md) افتراضي مع لاحق DeepSeek طلب إرسال بعد لم تأكيد استقبال كامل سجل بعد لاحقة، يشمل مرور قد إعداد شبكة صلة إرسال طلب؛ سوف ذلك `enabled` إعداد ضبط لـ `false` يمكن إغلاق فوق نقل.[OTel جلسة فوق نقل](../../../packages/session/session-telemetry-otel/README.zh.md) ملائم لأجل كل مستخدم و مزود، يشمل `deepseek-official`، بلا حاجة طلب رأس. أساس أساس إعداد افتراضي استخدام `FEEDBACK_ONLY`: جديد ذاته نص عكس تغذية، رسالة تقييم قسم، تحرير و سحب عودة سوف تحرير قطع حتى هذا حدث كامل مواصفة سجل بادئة، يتضمن تخزين سياق؛ لاحق سجل انتظار تحت مرة صريح عكس تغذية. وراثة أب درجة عكس تغذية لا بنية صار fork تخويل. طلب، استعادة، تركيب و HMR لا إطلاق التقاط.SDK دفعة معالجة يمكن إتمام قد تخويل فوق نقل، بلا حاجة دخول واحد خطوة تفاعل أو نموذج عمل.`DSH_TELEMETRY_MODE=DISABLED` منع توقف OTel إلقاء تمرير؛`FULL` يتم رفض، أي غير فارغ `DSH_TELEMETRY_DISABLED` كل سوف منع استخدام ذلك إعداد سطر.`DSH_TELEMETRY_OTLP_URL` اختيار أخذ تجميع طرف. تسليم وصل كل قوة بينما لـ، لا بديل جدول أخذ تجميع طرف قبول؛ لا توفير حفظ دائم outbox أو إعادة محاولة حفظ إثبات. هذه OTel ضبط لن فتح بدء أو إغلاق DeepSeek مساهمة. اثنان بند مسار كل لا تغيير نموذج إدخال، لكن توجيه خروج ممكن يتضمن رسالة نص، أداة معامل و نتيجة، و مساحة العمل مسار.

عبر `dsh plugin --profile <name> add <package-or-git-spec>` تثبيت خارجي إضافة تركيب حزمة. تثبيت حزمة يملك ذلك اعتماد، و مساهمة ذلك إعلان `cordis.patch.yml` طبقة.CLI أيضا مع مرفق `@deepseek-ai/dsh-mcp-client` بصفة توفير patch طبقة استخدام اعتماد، لكن افتراضي لا تفعيل MCP خادم، لأن كل بند خادم أمر كل هو agent صندوق رملي خارج تلقي معلومة مهمة يمكن تنفيذ شفرة.

## شفرة المصدر تنفيذ

طلب في مستودع أصل دليل في، في كل جديد checkout بعد و ناتج حاجة تحديث وقت مفرد وحيد تشغيل `pnpm run build`، لكن بعد استخدام `pnpm dsh <args...>`.`package.json` في نص برمجي لن بناء، بينما هو عبر `node --import tsx/esm` بدء `apps/cli/src/bin.ts`، و تحويل إرسال كل معامل.Typert Host ناتج ناقص وقت،profile بدء سوف بسبب لا يحتوي بناء إشارة جذب وحدة تحليل خطأ بينما فشل. هذه Host ناتج وجود بعد، إذا قبل طرف أو Client plugin تركيب حزمة ناقص، بدء سوف فشل و تلميح تشغيل `pnpm run build`. بدء جهاز لن فحص ناتج هل لـ الأكثر جديد، لذلك قد لديه قديم قديم تركيب حزمة ممكن متابعة تشغيل قديم إصدار متصفح شفرة، مباشر حتى إعادة بناء. هذا عملية سوف وراثة بدء بيئة، كما `runProfile` سوف في أي entry تركيب قبل من هذا لقطة تحليل خروج محطة بديل إدارة، لذلك `HTTP_PROXY`/`HTTPS_PROXY`(و كتابة في `.env` طبقة في بديل إدارة) بلا حاجة أي مقدار خارج فتح صلة يكفي توليد فاعلية. تثبيت شكل صيغة سوف مباشر بدء بناء بعد `apps/cli/lib/bin.js`، لن إعادة بناء مستودع.
