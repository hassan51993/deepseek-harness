## ملف و نطاق

كل tag مقابل `kind: persistence-release` في إنجليزي سجل، إعداد مقابل sidecar و `.schema.json`. آلة جهاز إعلان يتضمن tag، مباشر قبل دفع، فعلي كتابة إصدار و كل تغير أصل before/after ملخص. أول بند لقطة يتضمن الكل أصل؛ لاحق لقطة فقط حفظ ما زال وجود تغير أصل و ذلك كل يمكن بلوغ نوع. حذف استخدام فارغ after، لم تغيير إصدار إبقاء فارغ تغير و فارغ لقطة.

لقطة تغطية منطق Session header، شيء إدارة JSONL header، حدث معلومة غلاف و هذا tag كل رقم واحد جهة حدث و نقل تمرير مرجع. نوع عدد فقط موحد حساب مواصفة تحويل بعد ما زال يمكن بلوغ تعريف. تاريخ شفرة المصدر مرجع فقط إبقاء ملف مسار، لا يتضمن سطر رقم.

هذه عودة تتبع سجل و فوق طبقة دليل حالي تأكيد سلسلة قسم فتح تحقق. حالي قاعدة مقابل قديم تغير تصنيف فقط هو قراءة قراءة تلميح: تاريخ فوق version 0 تأكيد فعلي ظهور مرور لا رفع إصدار بنية تغير. لا نيل يأخذ عودة ملء سجل بصفة حالي PR حذف تأكيد أو إصدار رفع رفع اعتماد حسب.

<a id="extraction"></a>
## رفع أخذ و حد

إعادة بناء استخدام كل tag في شفرة المصدر،TypeScript 6.0.3 و قد دمج دخول [schema رفع أخذ جهاز](../../../scripts/persistence-schema.ts). وحيد رفع أخذ ملائم إعداد هو حذف مبكر مدة أداة جسم حدث سجل تسليم تقاطع نوع في زائد بقية `object` عضو. أصل لديه `any` / `unknown` إبقاء لا نفاذ واضح؛ لا يوجد لـ ناقص مرجع مقدار خارج استبدال لا نفاذ واضح نوع. إرسال سطر لقطة JSON إبقاء تاريخ معرف رمز؛ فن لغة فحص ما زال ملائم لأجل شخص عمل سجل و حالي schema.

قبل 22 عدد tag surface حدث دمج قاعدة أرض حمل لديه اختياري `surfaceOp`. تاريخ تحليل إبقاء هذا اختياري صفة؛ حالي شفرة المصدر تحليل ما زال اشتراط هذا حقل مطلوب. قديم إصدار `SessionHeader.version: number` أيضا حسب أصل إعلان إبقاء، فعلي كتابة إصدار معتاد كمية آخر سطر سجل. لا يستطيع من عرض عام `number` إعلان دفع توجيه هو.

هذا دفعة tag كتابة إصدار لـ 0،2 و 3، لا يوجد كتابة إصدار 1 tag.

ملخص مقابل مواصفة تحويل بعد إعادة بناء نوع، لا هو أصلي شفرة المصدر نص أو عند وقت أداة سلسلة تدريجي حرف إعادة الآن. شرح فقط توفير بنية تغير خشن اختصار إدارة حل؛ لم إعادة وضع قديم تطبيق، تحقق كامل تحرير حل رمز سلوك أو إثبات ترحيل أمان. ملخص لم تغيير أيضا لا يستطيع إثبات سلوك لم تغيير.

<a id="verification"></a>
## تحقق

الكل 26 عدد لقطة قد عبر مواصفة رسم، أصل ملخص و يمكن بلوغ نوع ملخص تحقق. إرسال سطر عودة ملف فحص فقط قراءة هذا شجرة في بيان، سجل و لقطة، لا وصول Git، شبكة شبكة أو قديم إصدار checkout؛ هو تحقق بيان تغطية، قبل دفع،before/after، لقطة نوع كامل صفة و مزدوج لغة آلة جهاز إعلان.

```sh
pnpm run verify-persistence-releases
pnpm run doc-sync
```

علامة منطقة بين داخل بحث جذب، بيان وحدة إطار و بنية تغير واقع من لقطة توليد. افتراضي تحقق سوف رفض قديم قديم واقع. تشغيل `pnpm run verify-persistence-releases --write` يمكن في الكل آلة جهاز بيانات تحقق عبر بعد تحديث جديد هذه منطقة بين و إعداد مقابل سجل؛ شخص عمل عام وصف، شفرة المصدر دليل، آلة جهاز إعلان و schema ملف إبقاء ثابت.

tag كامل صفة بـ بيان التقاط نطاق لـ دقيق؛ مغادرة خط فحص لن تلقائي اكتشاف لاحق جديد tag. إعداد مقابل سجل و Markdown رابط من معتاد قاعدة وثيقة فحص تحقق.[صيغة نموذج لوح](../../../.agents/skills/dsh-doc/templates/persistence-release.md) قاعدة تحديد مفرد بند سجل حقل.
