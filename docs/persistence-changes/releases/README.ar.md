## الملفات والنطاق

لكل وسم سجلٌّ إنجليزي وعربي بـ `kind: persistence-release`، وملفٌّ مرافق للاقتران، و`.schema.json`. ويحتوي تصريحُه الآلي الوسمَ، وسلفَه المباشر، وإصدارَ الكاتب المرصود، وبصمتَي «قبل» و«بعد» لكل جذر متغيّر. وتحتوي اللقطةُ الأولى كلَّ جذر؛ ولا تحتفظ اللقطاتُ اللاحقة إلا بالجذور المتغيّرة التي تبقى موجودة وبكل أنواعها القابلة للوصول. وتستعمل عملياتُ الحذف قيمةَ «بعد» فارغة؛ وتحتفظ الإصدارات غير المتغيّرة بتغييرات ولقطات فارغة.

وتغطي اللقطاتُ ترويسةَ الجلسة المنطقية، وترويسةَ JSONL الفيزيائية، ومغلّفَ الأحداث، وكلَّ حدث من الطرف الأول وكلَّ مرجع متعدٍّ عند ذلك الوسم. ولا تشمل أعدادُ الأنواع إلا التعريفاتِ القابلة للوصول بعد التوحيد. وتحتفظ مراجعُ المصدر التاريخية بمسارات الملفات بلا أرقام أسطر.

وتُتحقَّق هذه السجلاتُ الاسترجاعية منفصلةً عن سلسلة التأكيدات الحالية في الدليل الأب. وتصنيفُ التغييرات القديمة بالقواعد الحالية معينٌ على القراءة: فالإصدارُ التاريخي 0 احتوى فعلًا تغييراتٍ بنيوية بلا زيادة إصدار. ولا يستطيع سجلٌّ مملوء استرجاعيًا أن يأذن لـ PR حالي بحذف تأكيد ولا بحذف زيادة إصدار مطلوبة.

<a id="extraction"></a>
## الاستخراج والحدود

استعملت إعادةُ البناء المصدرَ عند كل وسم، وTypeScript 6.0.3، و[مستخرِج schemas](../../../scripts/persistence-schema.ts) المدموج. والتكييفُ الوحيد في الاستخراج يحذف عضوَ `object` زائدًا من تقاطعات سجلات الأحداث الملموسة المبكرة. ويبقى `any` و`unknown` القائمان معتمَين؛ ولم تُوضَع أنواعٌ معتمة إضافية مكان مراجع غير محلولة. ويحتفظ JSON الخاص بـ schemas الإصدارات بالمعرّفات التاريخية؛ وتبقى فحوصُ المصطلحات منطبقةً على السجلات المؤلَّفة وschemas الحالية.

والوسومُ الاثنان والعشرون الأولى تعلن `surfaceOp` اختياريًا في أحداث السطوح إعلانًا مشروعًا. ويحفظ التحليلُ التاريخي ذلك الاختيار؛ بينما يظل تحليلُ المصدر الحالي يشترط الحقل. وتبقى تصريحاتُ `SessionHeader.version: number` الأسبق سليمةً أيضًا، وتُسجَّل ثوابتُ إصدار الكاتب الفعلية منفصلةً. ولا يستطيع تصريحُ `number` الفضفاض توفيرَ ذلك الثابت.

والوسومُ الملتقَطة تستعمل إصدارات الكاتب 0 و2 و3؛ ولا وسمَ يستعمل الإصدار 1.

والبصماتُ تصف الأنواعَ المعاد بناؤها بعد التوحيد، لا نصَّ المصدر حرفيًا ولا إعادةَ إنتاج سلسلة الأدوات الأصلية. وتوفّر الملخصاتُ سياقًا بنيويًا تقريبيًا؛ فلم تُعَد تشغيلُ التطبيقات القديمة، ولم يُتحقَّق من سلوك الـ codecs كاملًا، ولم تُثبَت سلامةُ الترحيل. والبصمةُ غير المتغيّرة لا تُنشئ سلوكًا غير متغيّر.

<a id="verification"></a>
## التحقق

اجتازت اللقطاتُ الستُّ والعشرون كلُّها تحقّقَ الرسم المعياري وبصمة الجذر وبصمة الأنواع القابلة للوصول. ويقرأ فحصُ أرشيف الإصدارات البيانَ والسجلاتِ واللقطاتِ في هذه الشجرة وحدها، بلا Git ولا وصول إلى الشبكة ولا نسخ عمل لإصدارات قديمة؛ وهو يتحقق من تغطية البيان، والأسلاف، وقيم «قبل» و«بعد»، واكتمال أنواع اللقطات، والتصريحات الآلية الثنائية اللغة.

```sh
pnpm run verify-persistence-releases
pnpm run doc-sync
```

والفهرسُ المحدَّد بالعلامات وخلايا الجرد ووقائعُ التغييرات البنيوية مولَّدةٌ من اللقطات. والتحققُ الافتراضي يرفض الوقائعَ البائتة. وشغّل `pnpm run verify-persistence-releases --write` لتحديث تلك المناطق وسجلاتِ الاقتران بعد التحقق من كل البيانات الآلية؛ وتُحفظ الملخصاتُ المؤلَّفة وأدلةُ المصدر والتصريحاتُ الآلية وملفاتُ schemas.

واكتمالُ الوسوم نسبيٌّ إلى النطاق الذي التقطه البيان؛ ولا تكتشف الفحوصُ بلا اتصال الوسومَ اللاحقة تلقائيًا. وتتحقق فحوصُ التوثيق المعيارية من سجلات الاقتران وروابط Markdown. ويعرّف [قالب الصيغة](../../../.agents/skills/dsh-doc/templates/persistence-release.md) حقولَ كل سجل.
