# حفظ دائم نوع تغيير سجل

[English](README.md) | العربية

## عام وصف

هذا مشاركة اعتبار وثيقة لأجل فحص قد تأكيد جلسة حفظ دائم نوع تغيير و ذلك قبل دفع. كل بند سجل يأخذ توافق صفة قرار ربط إلى دقيق توليد schema. محلي فحص فقط استخدام حالي فحص خروج دليل في ملف، سوف حالي شفرة المصدر و سجل تاريخ مقارنة مقارنة. تعديل حفظ دائم نوع وقت، من[مراجعة قراءة فعلي تشغيل يد سجل](../cookbook/reviewing-persistence-type-changes.zh.md) بدء.

مقارنة مبكر tag مشاركة رؤية[مسبق إرسال سطر إصدار عودة ملف](releases/README.zh.md). هو إعادة بناء alpha/RC نوع فرق مختلف، توفير تاريخ قراءة قراءة و صيغة تحقق استخدام؛ هذه مراقبة سجل لا بصفة حالي توافق صفة تأكيد.

حسب Session صيغة فحص نظر كامل schema وقت، استخدام[صيغة مشاركة اعتبار](historical-formats/README.zh.md). ذلك تغطية نطاق من كتابة جهاز معتاد كمية قرار، يشمل لا يوجد إصدار tag في بين صيغة.

## ملف و مسؤولية

توليد[دليل](../persistence-catalog.zh.md) توفير يمكن قراءة إعلان و ملخص؛[schema بيان](../persistence-schema.json) يتضمن مواصفة تحويل نوع. أصل تغطية منطق جلسة رأس، شيء إدارة JSONL رأس سطر، حدث غلاف تركيب و كل مستودع داخل إعلان حدث. يتم مرجع نوع تغيير سوف نقل تمرير إلى كل تلقي أثر أصل ملخص.

كل بند حمل يوم مدة سجل لديه أربعة عدد نفس دليل ملف:

| ملف | مسؤولية |
|---|---|
| `YYYY-MM-DD-slug.md` | إنجليزي نص تأكيد وثيقة، يتضمن `kind: persistence-change`، واحد نسخة آلة جهاز إعلان، توافق صفة شرح و تحقق دليل |
| `YYYY-MM-DD-slug.zh.md` | العربية مقابل جانب ملف، يتضمن نفسه آلة جهاز إعلان |
| `YYYY-MM-DD-slug.i18n.yaml` | توليد مزدوج لغة متسق صفة سجل |
| `YYYY-MM-DD-slug.schema.json` | توليد كامل تغيير بعد schema، تغطية تلقي أثر كما ما زال وجود أصل |

[سجل نموذج لوح](../../.agents/skills/dsh-doc/templates/persistence-change.md) تعريف شخص عمل تحرير كتابة صيغة. إنشاء سجل وقت يمكن توفير مزدوج لغة شرح إدخال، من أمر توليد آلة جهاز إعلان، لقطة، دليل مقابل و متسق صفة سجل. تحقق جهاز من إنجليزي نص ملف قراءة مرة آلة جهاز إعلان، و فحص العربية إعلان هل نفسه. إعلان صف خروج كل تلقي أثر أصل، ذلك قبل دفع سجل، تغيير بعد ملخص و توافق صفة قرار. جديد أصل لا يوجد قبل دفع؛ حذف عملية لا يوجد تغيير بعد schema، و إبقاء صريح حذف علامة.

<a id="compatibility-rules"></a>
## توافق صفة قاعدة

كل فحص قياس إلى بنية تغيير كل حاجة تأكيد. إنشاء و تحديث سجل اعتماد حسب هذه ثابت قاعدة دفع قطع الأكثر منخفض قرار؛ صريح `--decision` هو تلقي فحص تأكيد. قاعدة تطبيق في كامل تغيير، لذلك سماح تغيير لا يستطيع إخفاء غطاء معا حدوث كسر تالف صفة تغيير.

| فحص قياس إلى تغيير | الأكثر منخفض قرار اشتراط |
|---|---|
| إضافة اختياري حدث جسم خاصية، يشمل ذلك كامل فرعي شجرة | `same-version` |
| سوف لا بد اختيار حدث جسم خاصية تعديل لـ اختياري | `same-version` |
| إضافة عادي حدث نوع | `same-version` |
| سوف اختياري خاصية تعديل لـ لا بد اختيار، إضافة لا بد اختيار خاصية، أكثر تعديل قد لديه نوع، أو حذف/إعادة تسمية خاصية أو حدث | `version-bump` |
| أكثر تعديل جلسة رأس أو حدث غلاف تركيب | `version-bump` |

نفس إصدار شرح يجب حل تفسير قديم سجل لـ أي يمكن نقص قليل إضافة جديدة محتوى، و قديم قراءة جهاز لـ أي يمكن تجاهل اختصار هو بينما لا تغيير إعادة تشغيل. مقابل في لا بد اختيار تعديل اختياري تغيير، شرح يجب حل تفسير قراءة جهاز مثل أي معالجة ناقص قيمة. فحص جهاز تحقق نوع تصنيف؛ مراجعة قراءة من حكم قطع شرح هل صار قيام. رفع إصدار سجل في نفس تحويل في يتضمن تمرير زيادة رأس جزء إصدار، و التزام دوران[جلسة صيغة مسار](../cookbook/adding-a-session-format-version.zh.md).

<a id="history-and-limitations"></a>
## تاريخ و حد

واحد بند أساس خط سجل كامل ابتدائي بيان. لاحق سجل استخدام قبل دفع تغيير بعد schema بصفة تغيير قبل schema. تحقق جهاز رفض ناقص قبل دفع، حلقة، نفس أصل تكرار بعد استمرار، ملخص لا مطابقة، و حالي أصل و الأكثر جديد سجل لا متسق حال حال. مستقل أصل يمكن مستقل عرض دخول. نفس قبل دفع فوق اثنان عدد تغيير في تجميع صار بعد حاجة شكل صار واحد بند لديه ترتيب تاريخ.

قد قبول سجل وصف تاريخ تحويل؛ إضافة بعد استمرار وقت يجب إبقاء ذلك آلة جهاز إعلان و schema لقطة. بعد لم قبول نهاية طرف سجل يمكن صريح تحديث جديد؛ أمر رفض أساس خط و يتم اعتماد سجل. دليل ذاته لا يمكن إثبات مراجعة قراءة قبول حالة. تحقق إثبات دليل داخل متسق صفة، لا إثبات تاريخ من لم يتم تعديل كتابة. أساس خط لا اعتماد Git مرجع، بعيد طرف خدمة أو قد إصدار إصدار فحص خروج دليل.

ملخص وصف إعلان حفظ دائم نوع، لا وصف وقت التشغيل تحقق أو سلوك. ملاحظة تفسير، شفرة المصدر موضع، آخر اسم اسم و بلا دلالة تغير إعلان إعادة ترتيب لا أثر ملخص. كائن حقل، ربط دمج نوع فرع، تسليم تقاطع نوع عملية عدد و بحث جذب توقيع يمكن في تحليل نوع ثابت وقت إعادة ترتيب؛ عنصر مجموعة موضع و عدد حرف قطعة رفع قيمة ما زال أثر ملخص. دليل نص و شفرة المصدر موضع ما زال ممكن تغير، لذلك ينبغي إعادة توليد قديم قديم ناتج، بلا حاجة لـ لم تغيير ملخص إضافة تأكيد سجل.`unknown` انتظار لا نفاذ واضح نوع لا توفير يمكن مقارنة مقارنة داخلي بنية. صاف سلوك تغيير و لا نفاذ واضح قيمة في إخفاء بنية لا في هذا آلية نطاق داخل.[قرار سجل](../../.agents/notes/implemented/process/2026-09-11-persistence-type-history.zh.md) شرح هذه أخذ ترك.
