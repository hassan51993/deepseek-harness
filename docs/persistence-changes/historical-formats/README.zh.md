# Session حفظ دائم صيغة

[English](README.md) | العربية

## عام وصف

هذا مشاركة اعتبار لأجل فحص قراءة قد تخزين Session بديل حد header، حدث معلومة غلاف و تحميل حمل نوع. منخفض في مساحة العمل كتابة جهاز إصدار كل صيغة كل لديه مزدوج لغة وثيقة و كامل schema لقطة. حالي صيغة استخدام توليد حفظ دائم دليل.[إصدار حق مصدر](../../session-format-status.zh.md) مسؤول كتابة جهاز معتاد كمية و إصدار حالة.

<a id="scope"></a>
## نطاق و دليل

كل مجموعة `vN.md` / `vN.zh.md` وثيقة يتضمن `kind: persistence-format`، سوف كل أصل نوع مفتاح ربط إلى قد سجل ملخص نفسه `yaml persistence-format` إعلان، إعداد مقابل سجل و كامل `vN.schema.json`.[نموذج لوح](../../../.agents/skills/dsh-doc/templates/persistence-format.md) تعريف هذه سجل. أصل نوع تغطية الذي اختيار فحص نقطة منطق Session header، شيء إدارة JSONL header، حدث معلومة غلاف و كل رقم واحد جهة حدث؛ كل أصل يتضمن كل يمكن بلوغ إعلان نوع. تحزيم شيء إدارة body سجل من كل صفحة رابط مستقل codec مسؤول.

V0 و V2 استخدام[قد استلام تسجيل مسبق إصدار عودة ملف](../releases/README.zh.md) في الأكثر بعد واحد مقابل tag. من في استلام تسجيل tag لا يوجد V1 كتابة جهاز،V1 استخدام ذلك مشاركة اعتبار وثيقة في معرف في بين شفرة المصدر شجرة. تاريخ مصدر إبقاء ملف مسار، لا يتضمن سطر رقم. لقطة إبقاء تاريخ اختياري حقل و لا نفاذ واضح قيمة، لن سوف حالي نوع استبدال إلى قديم صيغة في. تاريخ معرف رمز فقط في schema JSON و قد تحقق توليد schema منطقة بين في أصل مثال إبقاء؛ شخص عمل شرح التزام دوران حالي فن لغة قاعدة.

هذه مشاركة اعتبار وصف اختيار تحديد schema، لا يمثل تاريخ تطبيق إعادة تشغيل نتيجة أو ترحيل أمان صفة. نفس إصدار داخل إضافة جديدة حدث و اختياري تحميل حمل تغيير يمكن إنتاج أخرى صالح دليل. مسبق إصدار عودة ملف إبقاء تدريجي tag فرق مختلف؛[تغيير سجل](../README.zh.md) إبقاء حالي توافق صفة تأكيد. هذه صيغة لقطة لا بديل أي واحد نوع تاريخ.

<a id="maintenance"></a>
## صيانة تغطية

`verify-persistence-formats` من `SESSION_FORMAT_VERSION` دفع توجيه الذي يحتاج كامل عدد نطاق. كل أكثر مبكر كامل عدد كل حاجة مستقل كامل سجل. حالي دليل و schema يجب وجود كما مطابقة كتابة جهاز إصدار. فحص سوف رفض ناقص، كثير بقية، تحرير رقم خطأ، لا كامل أو لا متسق سجل و مرور مدة توليد منطقة بين، بلا حاجة نيل أخذ Git تاريخ أو استعلام خدمة.

دفع دخول كتابة جهاز قبل، تحقق حالي دليل و عودة ملف أصل صيغة. مقابل في V3 إلى V4 تغيير، في كتابة جهاز و حالي schema ما زال وصف V3 وقت تشغيل التالي أمر:

```sh
pnpm run verify-persistence-catalog
pnpm run verify-persistence-formats --archive 3
```

مقابل في أخرى تحويل، سوف `3` استبدال لـ أصل كتابة جهاز إصدار.`--archive N` من حالي دليل إنشاء `vN.schema.json`، فقط إبقاء من أصل نوع يمكن بلوغ نوع، و إزالة شفرة المصدر سطر رقم. هو رفض قد وجود هدف، و حالي كتابة جهاز مختلف إصدار، بلا فاعلية أو لا كامل schema، و و `--write` تركيب. استخدام[نموذج لوح](../../../.agents/skills/dsh-doc/templates/persistence-format.md) إضافة هذا لقطة مزدوج لغة سجل و مصدر دليل. إبقاء كل أكثر مبكر سجل. بعد استمرار صيغة استخدام حالي دليل؛ نسخ جديد حالي دليل لا يستطيع ممتلئ كاف عودة ملف قبل دفع اشتراط. وقت التشغيل تغيير التزام دوران[صيغة إصدار فعلي تشغيل يد سجل](../../cookbook/adding-a-session-format-version.zh.md).

ملاحظة تفسير علامة داخل schema تعريف و بحث جذب من أداة توليد. دفع دخول كتابة جهاز و إتمام آلة جهاز بيانات و شخص عمل دليل بعد، تحديث جديد ذلك جدول إطار و إعداد مقابل سجل، مجددا تنفيذ تحقق:

```sh
pnpm run verify-persistence-formats --write
pnpm run verify-persistence-formats
pnpm run doc-sync
```

`--write` أولا تحقق آلة جهاز بيانات، مجددا تحديث توليد Markdown و إعداد مقابل سجل. هو إبقاء شخص عمل شرح، آلة جهاز إعلان و schema. افتراضي تحقق أيضا سوف رفض مرور مدة إعداد مقابل سجل؛ معيار وثيقة فحص تحقق قلب ترجمة و محلي رابط. حالي دليل جديد طازج درجة ما زال من `verify-persistence-catalog` مسؤول.
