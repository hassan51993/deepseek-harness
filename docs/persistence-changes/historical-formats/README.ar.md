# صيغ حفظ الجلسة الدائم

[English](README.md) | العربية

## الملخص

استعمل هذا المرجع لفحص ترويسات جيل جلسة مخزَّن ومغلّفاتِ أحداثه وأنواعِ حمولاته. ولكل صيغة دون كاتب نسخة العمل وثيقةٌ ثنائية اللغة ولقطةُ schema كاملة. وتستعمل الصيغةُ الحالية دليلَ الحفظ الدائم المولَّد. ويملك [مرجع الإصدار](../../session-format-status.ar.md) ثابتَ الكاتب وحالةَ الإصدار.

## النطاق والدليل

لكل زوج `vN.md` و`vN.ar.md` النوعُ `kind: persistence-format`، وتصريحُ `yaml persistence-format` متطابق يربط كلَّ مفتاح جذر ببصمته الملتقَطة، وملفٌّ مرافق للاقتران، و`vN.schema.json` كامل. ويعرّف [القالب](../../../.agents/skills/dsh-doc/templates/persistence-format.md) هذه السجلات. وتغطي الجذورُ ترويسةَ الجلسة المنطقية، وترويسةَ JSONL الفيزيائية، ومغلّفَ الأحداث، وكلَّ أحداث الطرف الأول عند نقطة التفتيش المختارة؛ ويضم كلُّ جذر كلَّ نوع معلَن قابل للوصول. ولسجلات المتن الفيزيائية المحزومة مالكو codec منفصلون تربط كلُّ صفحة إليهم.

ويستعمل V0 وV2 أحدثَ الوسوم المطابقة في [أرشيف ما قبل الإصدار الملتقَط](../releases/README.ar.md). ويستعمل V1 شجرةَ مصدر وسيطة يحدّدها مرجعُه، لأن الوسومَ الملتقَطة لا تحوي كاتبَ V1. وتحتفظ المصادرُ التاريخية بمسارات الملفات بلا أرقام أسطر. وتحفظ اللقطاتُ الحقولَ الاختيارية التاريخية والقيمَ المعتمة؛ وهي لا تضع أنواعًا حالية مكان أنواع في صيغ أقدم. ولا تبقى المعرّفاتُ التاريخية سليمةً إلا في JSON الخاص بـ schemas وفي مناطق schemas المولَّدة المتحقَّق منها؛ أما النثرُ المؤلَّف فيتبع قواعدَ المصطلحات الحالية.

وتصف هذه المراجعُ schemas مختارة، لا إعادةَ تشغيل تطبيقات تاريخية ولا سلامةَ ترحيل. وإضافاتُ الأحداث بالإصدار نفسه وتغييراتُ الحمولات الاختيارية قد تنتج جردًا صالحًا آخر. ويحتفظ أرشيفُ ما قبل الإصدار بالفروق وسمًا وسمًا؛ وتحتفظ [سجلات التغييرات](../README.ar.md) بتأكيدات التوافق الحالية. ولا تحل لقطاتُ الصيغ هذه محل أيٍّ من التاريخين.

<a id="maintenance"></a>
## صيانة التغطية

يشتق `verify-persistence-formats` مدى الأعداد الصحيحة المطلوب من `SESSION_FORMAT_VERSION`. ولكل عدد صحيح أقدم سجلُّه الكامل. وعلى الدليل الحالي وschema الحالي أن يوجدا وأن يطابقا إصدارَ الكاتب. ويرفض الفحصُ السجلاتِ المفقودة أو الزائدة أو الخاطئة الترقيم أو غيرَ المكتملة أو غيرَ المتسقة، والمناطقَ المولَّدة البائتة، بلا جلب تاريخ Git ولا استعلام خدمة.

وقبل دفع الكاتب قدمًا، تحقّق من الدليل الحالي وأرشِف الصيغةَ الخارجة. وفي تغيير من V3 إلى V4، شغّل هذين الأمرين بينما لا يزال الكاتبُ وschema الحالي يصفان V3:

```sh
pnpm run verify-persistence-catalog
pnpm run verify-persistence-formats --archive 3
```

واستبدل `3` بإصدار الكاتب الخارج في الانتقالات الأخرى. و`--archive N` ينشئ `vN.schema.json` من الجرد الحالي، ويحتفظ بالأنواع القابلة للوصول من جذوره بالضبط، ويزيل أرقامَ أسطر المصدر. وهو يرفض وجهةً قائمة، وإصدارًا غير إصدار الكاتب الحالي، وschemas غيرَ صالحة أو غيرَ مكتملة، ويرفض الجمعَ مع `--write`. وأضف سجلَّ اللقطة الثنائي اللغة ودليلَ مصدرها بـ[القالب](../../../.agents/skills/dsh-doc/templates/persistence-format.md). واحتفظ بكل السجلات الأسبق. ويستعمل الخَلَفُ الدليلَ الحالي؛ ونسخُ دليل حالٍ جديد لا يفي باشتراط السلف المؤرشف. واتبع [الدليل العملي لإصدارات الصيغة](../../cookbook/adding-a-session-format-version.ar.md) لتغييرات وقت التشغيل.

وتعريفاتُ schemas والفهرسُ داخل علامات التعليق مولَّدة. وبعد دفع الكاتب قدمًا وإتمام البيانات الآلية والدليل المؤلَّف، حدّث جداولَها وسجلاتِ اقترانها، ثم تحقّق:

```sh
pnpm run verify-persistence-formats --write
pnpm run verify-persistence-formats
pnpm run doc-sync
```

و`--write` يتحقق من البيانات الآلية قبل تحديث Markdown المولَّد وسجلاتِ الاقتران. وهو يحفظ الشروحَ المؤلَّفة والتصريحاتِ الآلية وملفاتِ schemas. ويرفض التحققُ الافتراضي أيضًا سجلاتِ الاقتران البائتة؛ وتتحقق فحوصُ التوثيق المعيارية من الترجمات والروابط المحلية. وتبقى طزاجةُ الدليل الحالي مملوكةً لـ `verify-persistence-catalog`.
