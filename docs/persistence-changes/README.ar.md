# سجلات تغييرات أنواع الحفظ الدائم

[English](README.md) | العربية

## الملخص

استعمل هذا المرجع لفحص تغيير نوع حفظ جلسة مؤكَّد وسلفِه. وكل سجل يربط قرارَ توافق بـ schemas مولَّدة بعينها. وتقارن الفحوصُ المحلية المصدرَ الحالي بالتاريخ المسجَّل بملفات نسخة العمل وحدها. وابدأ من [الدليل العملي للمراجعة](../cookbook/reviewing-persistence-type-changes.ar.md) عند تغيير نوع محفوظ.

وللإصدارات الموسومة الأقدم، استعمل [أرشيف ما قبل الإصدار](releases/README.ar.md). فهو يعيد بناء فروق الأنواع في alpha وRC للقراءة التاريخية وللتحقق من الصيغ؛ وملاحظاتُه ليست تأكيداتِ توافق حالية.

وللحصول على schemas كاملةً مجمَّعة بصيغة الجلسة، استعمل [مراجع الصيغ](historical-formats/README.ar.md). وتتبع تغطيتُها ثابتَ الكاتب، بما فيه الصيغُ الوسيطة بلا وسم إصدار.

## الملفات والملكية

يوفّر [الدليل](../persistence-catalog.ar.md) المولَّد تصريحاتٍ وبصماتٍ مقروءة؛ ويحتوي [جرد schemas](../persistence-schema.json) الأنواعَ الموحَّدة. وتغطي الجذورُ ترويسةَ الجلسة المنطقية، وسطرَ ترويسة JSONL الفيزيائي، ومغلّفَ الأحداث، وكلَّ حدث يعلنه المستودع. وتسهم الأنواعُ المشار إليها متعديةً في بصمة كل جذر متأثر.

ولكل سجل مؤرَّخ أربعةُ ملفات متجاورة:

| الملف | المالك |
|---|---|
| `YYYY-MM-DD-slug.md` | التأكيد الإنجليزي بـ `kind: persistence-change`، وتصريحٌ آلي واحد، وتعليلُ التوافق، ودليلُ التحقق |
| `YYYY-MM-DD-slug.ar.md` | الجانب العربي بالتصريح الآلي نفسه |
| `YYYY-MM-DD-slug.i18n.yaml` | سجل الاتساق الثنائي اللغة المولَّد |
| `YYYY-MM-DD-slug.schema.json` | schemas «بعد» الكاملة المولَّدة للجذور المتأثرة التي تبقى موجودة |

ويعرّف [قالب السجل](../../.agents/skills/dsh-doc/templates/persistence-change.md) الصيغةَ المؤلَّفة. ويقبل إنشاءُ السجل مدخلَ نثر ثنائي اللغة ويولّد التصريحَ الآلي واللقطاتِ وزوجَ الدليل وسجلاتِ الاتساق. ويقرأ المدقّقُ التصريحَ الآلي مرةً واحدة من الملف الإنجليزي ويفحص تطابقَ التصريح العربي معه. والتصريحُ يسمّي كلَّ جذر متأثر، وسجلَّه السلف، وبصمتَه بعد التغيير، وقرارَ توافقه. والجذرُ الجديد لا سلفَ له؛ والحذفُ لا schema بعده له ويحتفظ بشاهدة صريحة.

<a id="compatibility-rules"></a>
## قواعد التوافق

كلُّ تغيير بنيوي يُكتشف يشترط تأكيدًا. ويستنتج إنشاءُ السجل وتحديثُه القرارَ الأدنى من هذه القواعد الثابتة؛ و`--decision` الصريح دعوى مفحوصة. وتنطبق القواعدُ على التغيير كله، فلا يستطيع تغييرٌ مسموح إخفاءَ تغيير كاسر معه.

| التغيير المكتشَف | القرار الأدنى |
|---|---|
| إضافة خاصية اختيارية إلى متن حدث، بشجرتها الفرعية كاملةً | `same-version` |
| جعل خاصية مطلوبة في متن حدث اختياريةً | `same-version` |
| إضافة نوع حدث عادي | `same-version` |
| جعل خاصية اختيارية مطلوبةً، أو إضافة خاصية مطلوبة، أو تغيير نوع قائم، أو حذف خاصية أو حدث أو إعادة تسميته | `version-bump` |
| تغيير ترويسة الجلسة أو مغلّف الأحداث | `version-bump` |

وشرحُ `same-version` يبيّن لماذا تستطيع السجلاتُ القديمة حذفَ الإضافة، ولماذا يستطيع القرّاءُ الأقدم تجاهلَها بلا تغيير إعادة التشغيل. وفي التغييرات من مطلوب إلى اختياري، يبيّن كيف يعالج القرّاءُ قيمةً غائبة. ويتحقق الفاحصُ من تصنيف النوع؛ ويقيّم المراجعون الشرحَ. وسجلُّ `version-bump` يتضمن إصدارَ الترويسة المتزايد في الانتقال نفسه ويتبع [إجراء صيغة الجلسة](../cookbook/adding-a-session-format-version.ar.md).

<a id="history-and-limitations"></a>
## التاريخ والحدود

خطُّ أساس واحد يسجّل الجردَ الأوّلي كاملًا. وتستعمل السجلاتُ اللاحقة schema «بعد» عند سلفها schema «قبل» عندها. ويرفض المدقّقُ الأسلافَ المفقودة، والدورات، وتكرارَ الخلف لجذر واحد، واختلافَ البصمات، والجذورَ الحالية التي تخالف أحدثَ سجلاتها. وتستطيع الجذورُ المستقلة التقدمَ مستقلةً. وتغييران على السلف نفسه يشترطان تاريخًا مرتَّبًا واحدًا بعد الدمج.

والسجلاتُ المقبولة تصف انتقالاتٍ تاريخية؛ فاحفظ تصريحاتِها الآلية ولقطاتِ schemas عندها حين تضيف خلفًا. والسجلُّ الطرفي غير المقبول يمكن تحديثُه صراحةً؛ ويرفض الأمرُ خطوطَ الأساس والسجلاتِ التي لها تابعون. ولا تستطيع الشجرةُ إثباتَ قبول المراجعة. والتحققُ يثبت الاتساقَ داخل الشجرة، لا أن التاريخ لم يُعَد كتابتُه قط. ولا يوفّر خطَّ الأساس مرجعُ Git ولا خدمةٌ بعيدة ولا نسخةُ عمل مُصدَرة.

والبصماتُ تصف أنواعَ الحفظ الدائم المعلَنة، لا التحققَ في وقت التشغيل ولا السلوك. ولا تؤثر فيها التعليقاتُ ولا مواضعُ المصدر ولا أسماءُ الأسماء البديلة ولا إعادةُ ترتيب التصريحات غير الضارة. ويجوز إعادةُ ترتيب حقول الكائنات وبدائل الاتحادات ومعاملات التقاطعات وتوقيعات الفهارس ما دامت أنواعُها المحلولة كما هي؛ أما مواضعُ الصفوف المرتَّبة وقيمُ التعدادات العددية فتبقى ذاتَ أثر. وقد يتغيّر نصُّ الدليل ومواضعُ المصدر مع ذلك، فأعِد توليد النواتج البائتة بلا إضافة تأكيد لبصمة لم تتغيّر. والأنواعُ المعتمة مثل `unknown` لا تكشف بنيةً خفية للمقارنة. والتغييراتُ السلوكية وحدها والبنى المخبّأة داخل قيم معتمة خارج نطاق هذه الآلية. ويسجّل [القرار](../../.agents/notes/implemented/process/2026-09-11-persistence-type-history.ar.md) هذه المفاضلات.
