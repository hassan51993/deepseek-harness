# مسرد المصطلحات

[English](glossary.md) | العربية

تستعمل مفردات مجال DeepSeek Harness مصطلحًا معياريًا واحدًا لكل مفهوم. وترتبط المصطلحات بمداخلها بمراسي Markdown المعتادة؛ أما تفصيل التنفيذ فيبقى في ملفات README الخاصة بالحزم وفي Agent Notes.

## capability-seam

- **seam**: *قدرة قابلة للاستبدال* ذات ثلاثة أدوار: **Service Definition** (وهي `Service` في Cordis التي تملك `ctx.<key>` الخاص بها وأنواع مفرداتها، أي صنف مجرّد مثل `ShellExecutor` أو registry ملموس مثل `WebRuntime`، ولا تكون أبدًا `interface` في TypeScript)، و**Service Provider** واحد أو أكثر، و**Consumer** واحد أو أكثر يحقن الخدمة. و`packages/shell` هو المثال المعياري: `dsh-shell` هي Service Definition، و`dsh-bash-local` و`dsh-bash-sandbox` مزوّدان، و`dsh-tool-bash` هو Consumer. وتسكن الأدوار عادةً في حزم منفصلة حين تتطوّر مستقلةً، غير أن الحزمة الواحدة قد تملك أكثر من دور حين تكون الأدوار همًّا واحدًا (فـ `dsh-user-approval` تملك Service Definition الخاصة بـ seam الموافقة وتنفيذَها الملموس في حزمة واحدة). وseam هي القدرة كاملةً لا دورًا واحدًا منها؛ فاحصر المصطلح في هذا المعنى، وسمِّ كل مكوّن بدوره أو صنفه أو خدمته أو عقده أو نقطة امتداده.

## agent-scope

- **scope**: وحدة التسجيل الخاصة بكل agent. فكل مساهمة (أداة أو مقطع توجيه أو متغير أو قيد أو مستمع) إما *عامة* يراها كل agent، وإما *ذات نطاق* يملكها [scope key](#scope-key) واحد بالضبط. والمستويان اثنان لا أكثر، ومسطّحان: فالتسجيل ذو النطاق لا يورَّث نزولًا إلى subagent؛ وسلوك الشجرة الفرعية يُعبَّر عنه ببيانات [lineage](#lineage)، لا ببنية scope.
- **scope key**: الهوية المعتمة التي يُفهرَس بها scope، وتُقارَن بهوية الكائن. وعُرف الإطار أن الـ agent الحي هو مفتاح نطاقه هو. <a id="scope-key"></a>
- **سياق agent (`agent.ctx`)**: سياق الـ agent ذو النطاق؛ والتسجيلات عبره ظاهرةٌ داخل النطاق وعمرُها عمرُ النطاق (واقعة واحدة تقرّر الأمرين)، والمستمعون عليه يشاركون في التوزيعات المرشَّحة بنطاق ذلك الـ agent. وقد تبقى الأحداث التي موضوعها registry بلا ترشيح عمدًا بحكم عقودها هي.
- **scope carrier**: الـ `thisArg` الذي يحمله التوزيع المرشَّح بالنطاق (يبنيه `scopeTarget`)؛ ومرشِّحه يقبل المستمعين بلا وسم إضافةً إلى مستمعي الموضوع نفسه. أما الـ carrier *بلا موضوع* (بلا مفتاح) فلا يقبل سوى المستمعين بلا وسم.
- **scoped dispatch**: القاعدة أن الحدث المتعلق بنشاط agent بعينه يوزَّع بـ carrier ذلك الـ agent. أما الأحداث المتعلقة بـ registry نفسه (أُضيفت أداة) فموضوعها *registry* وتبقى بلا ترشيح.
- **shadowing**: تحليل الأسماء بترجيح الأخص: الأداةُ أو المقطعُ أو المتغيرُ ذو النطاق يحلّ محل توأمه العام المسمّى بالاسم نفسه، في ذلك النطاق وحده. وهذه هي آلية الشخصية الخاصة بكل agent وآلية النسخ المختلفة من الأداة لكل agent.
- **restriction / التسجيل المحلي للنطاق**: القيد (`tools.restrict`) يرشّح مجموعة الأدوات العامة لنطاق واحد (وتتركّب القيود بالتقاطع)؛ أما التسجيلات المحلية للنطاق فتُدمج بعد ذلك الترشيح. والأداة العامة التي أسقطها الترشيح غائبة عن التوجيه وترفض التنفيذ معًا، فلا تُميَّز عن أداة غير موجودة أصلًا.
- **setup window**: فتحة الإنشاء التي يركّب فيها المنشئ عالَم الـ agent ذا النطاق (`CreateAgentOptions.setup`): بعد وجود النطاق وكائن الـ agent، وقبل نشر الـ agent أو الجلسة، وقبل إطلاق `agent/created`، وقبل تجميع أول توجيه. وsetup يسجّل ولا يقود الـ agent أبدًا.
- **lineage**: وقائع الأبوة والبنوّة محمولةً بيانات (`parentSession`، و`delegationDepth` الدائم، و`subagentDepth` في وقت التشغيل)؛ ولا تؤثر في الظهور أبدًا. <a id="lineage"></a>

## الهدف

- **الهدف**: غاية إتمام دائمة واحدة تُلحَق بجلسة قائمة، لها طور مرقَّم بالمراجعات بين `active` و`paused` و`blocked` و`complete`، وسقفٌ لجولات الهدف؛ ويحتفظ `blocked` برمز سياسة وشرح. والهدف حالة، لا مجدوِل ولا محادثة منفصلة؛ ويبقى سجل الجلسة مرجعه.
- **جولة الهدف**: دورة متابعة واحدة يُسمح بها للهدف الحالي. ويجسّد المشغّل داخل الجلسة نفسها جولةَ الهدف [جولةً](#turn) واحدة مصدرها الهدف، وقد تضم صفر خطوة أو أكثر؛ أما جولات البشر غير المتصلة في الجلسة نفسها فلا تستهلك سقف جولات الهدف. <a id="goal-round"></a>
- **تنشيط الهدف**: إذن محلي للعملية يسمح لمستهلك المتابعة بقبول جولة هدف أخرى. والتنشيط إما `armed` وإما `disarmed`؛ وهو غائب عن إعادة التشغيل الدائمة عمدًا، فالاستئناف والتفريع يشترطان تغييرَ استئنافٍ لاحقًا يأذن به إنسان عبر `/goal` أو عبر أداة النموذج، قبل أي عمل تلقائي.

## أمر الإنسان

- **أمر الإنسان**: تعليمة تبدأ بشرطة مائلة، يفسّرها وينفّذها مهايئ موجَّه إلى الإنسان عبر `ctx.commands`، دون أن تصير رسالةً للنموذج. وهو غير الأداة الموجَّهة إلى النموذج، وغير تنفيذ أوامر shell عبر `ctx.shell`.
- **مستوى الأوامر**: الاكتشاف والتحليل والتوزيع والإلغاء وتصيير النتيجة، تملكها مهايئات UI وإضافات الأوامر. وخرج الأمر حالةُ UI، إلا أن يغيّر المعالج مجالًا دائمًا بفعل منفصل.
- **أمر الهدف**: الأمر `/goal` الذي تسهم به `dsh-command-goal`؛ وهو يراقب الهدف الحالي أو يغيّره مباشرةً، بينما يملك مجال الهدف كل سجل دائم يراه النموذج.

## تراتب الحلقة

- **الجولة**: تفريغ واحد للمدخلات المقبولة في جلسة، ينتهي بعد توقف النموذج وأدواته أو بتدخّل سياسة نهائية. <a id="turn"></a>
- **الخطوة**: طلب نموذج واحد مع تنفيذات الأدوات التي سببتها استجابته؛ والجولة تضم صفر خطوة أو أكثر. <a id="step"></a>
- **الدور**: تكرار سياسة خارجية يحتوي جولةً، مثل [جولة هدف](#goal-round) أو محاولة Ralph واحدة بـ agent جديد. وعدّادات الأدوار تخص تلك السياسة، ولا تعدّ كل جولة في الجلسة. <a id="round"></a>

## Ralph

- **حلقة Ralph**: تشغيل واحد في المقدمة لسير عمل بـ agent جديد نحو غاية لا تتغيّر. وهي سياسة أداة موجَّهة إلى النموذج، مركَّبة من أوّليات سير العمل وsubagent، لا هدفًا داخل الجلسة نفسها، ولا وضعًا من أوضاع agent loop، ولا مجدوِلًا، ولا ميزةً عامة في نصوص سير العمل. <a id="ralph-loop"></a>
- **دور Ralph**: جلسة ابن جديدة واحدة داخل [حلقة Ralph](#ralph-loop). ولا يتلقى الابن بذرةَ محادثة من الأب ولا من ابن سابق؛ وإنما تحمل حالةَ ما بين الأدوار مساحةُ العمل المشتركة و[تسليمة Ralph](#ralph-handoff) محدودة واحدة. <a id="ralph-round"></a>
- **تسليمة Ralph**: التقرير المبنيَن المحدود الموحَّد الذي ينتقل من دور Ralph مستمر إلى الذي يليه، ويحمل الحالة والملخص والدليل والخطوات التالية ونص العائق. وهو يكمّل مساحة العمل المشتركة ولا يحل محلها مرجعًا. <a id="ralph-handoff"></a>
