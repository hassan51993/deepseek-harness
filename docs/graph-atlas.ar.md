# وثيقة رسم بحث جذب

[English](graph-atlas.md) | العربية

هذه رسم عرض توليد دليل لم يتضمن علاقة. يمكن استخدام هو جمع فحص بحث حزمة بين علاقة، قدرة seam، حدث تدفق، موجه إلى نموذج أداة، تطبيق تركيب و وقت التشغيل دورة الحياة مسار. دقيق توقيع و نوع تعريف ما زال بـ[فرعي نظام صفحة](subsystems/core.ar.md)(نوع و توليد `cordis-surface` منطقة مجال) و[أداة دليل](tool-catalog.ar.md) لـ دقيق.

هذا بحث جذب خلف بعد مسار قرار سجل في[وثيقة رسم Agent Note](../.agents/notes/archived/process/2026-07-03-documentation-graph-atlas.md) في.

| رسم | نمط |
| --- | --- |
| [وحدة اعتماد رسم](module-graph.ar.md) | `generated` |
| [أداة schema دليل و حزمة خريطة](tool-catalog.ar.md) | `generated` |
| [قدرة seam و نواة قلب خدمة](capability-seams.ar.md) | `hybrid generated` |
| [dsh مشترك أساس أساس تركيب](../apps/cli/composition.md) | `hybrid generated` |
| [حدث إنتاج جهة/مستهلك مستطيل دفعة](event-producer-consumer.ar.md) | `hybrid generated` |
| [agent(ذكي جسم) جولة و خطوة دورة الحياة](agent-lifecycle.ar.md) | `curated` |
| [أداة تنفيذ خط الإنتاج](tool-execution-pipeline.ar.md) | `curated` |

تشغيل `pnpm run gen-doc-graphs` يمكن إعادة توليد إنجليزي نص مصدر ملف؛ تشغيل `pnpm run verify-doc-graphs` يمكن تحقق إنجليزي نص مصدر جديد طازج درجة، العربية مقابل جانب فإن عبر مزدوج لغة إعداد مقابل صيانة.

إنجليزي نص مصدر ملف صيانة نمط لـ خلط دمج. كل رابط صفحة كل سوف إعلان ذلك إنجليزي نص مصدر نمط لـ توليد، خلط دمج أو شخص عمل تحرير كتابة؛ هذا العربية ملف هو عبر مزدوج لغة إعداد مقابل صيانة مرور مراجعة مقابل جانب.
