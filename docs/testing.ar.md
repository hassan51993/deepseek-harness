# اختبار سياسة

[English](testing.md) | العربية

هذا نص شرح هذا مستودع قسم طبقة اختبار طريقة، و إبقاء أخضر لون اختبار طقم عنصر متعمد معنى قاعدة. أمر رؤية أصل دليل [AGENTS.md](../AGENTS.md) ؛ متبادل صلة Agent Note تحمل تحميل تصميم حركة آلة.

## طبقة درجة

- **اختبار وحدة**(`pnpm run test`):vitest تشغيل حزمة و عرض مثال كل منها `tests/**` دليل تحت اختبار، و مطابقة `scripts/**/*.spec.ts` مستودع نص برمجي اختبار؛ اختبار ملف و ذلك الذي تغطية شفرة منطقة مجال وضع في واحد بدء. كل سجل التسجيل كل لديه واحد HMR(حار وحدة استبدال) أمان اختبار (مقابل نحو هذا سجل التسجيل مساهمة محتوى fiber تنفيذ dispose(مورد تحرير) ، و تأكيد تنظيف إتمام). أولوية تغطية حد حال حال، خطأ مسار، حدث ترتيب، تزامن تنافس حالة، و إبرة مقابل اتفاق ارتداد دائم دائم اختبار (رؤية `packages/core/agent-loop/tests/contract-regressions.spec.ts`).
- **نسبة التغطية بوابة**(`pnpm run test:coverage`): بوابة درجة تشغيل، مقابل `packages/*/*/src` حسب ملف 100% تغطية. لم تغطية سطر نحو نحو هو بوابة صحيح تأكيد علامة خروج ميت شفرة (ينبغي حذف) ، بينما غير حاجة تكملة كتابة اختبار. سطر نسبة التغطية هو لا بد يلزم شرط، لكن دائم بعيد لا هو ملء قسم شرط: هو إثبات سطر يتم تنفيذ مرور، لا إثبات وظيفة حسب تسليم مسبق مدة عمل.`packages/shell/pwsh-local/src` حسب ملف 100% تغطية حاجة حقيقي `pwsh`: نقص قليل هو وقت ذلك منفذ طقم عنصر سوف تلقائي قفز مرور،`vitest.config.ts` سوف إعفاء تجنب هذا ملف بـ جعل بلا pwsh رئيسي آلة إبقاء أخضر لون، بينما CI runner ذاتي حمل pwsh، ما زال حسب كامل معيار تنفيذ بوابة.
- **حقيقي API e2e**(`pnpm run test:e2e`): حمل مفتاح اختبار استدعاء حقيقي مزود API، يشمل DeepSeek نموذج و كل مزود خاص لديه خطر دخان اختبار؛ هذه اختبار كل منها من ذاتي ذات مفتاح تحكم (`EXA_API_KEY`،`PERPLEXITY_API_KEY` انتظار) ، نقص قليل مفتاح وقت طقم عنصر سوف تلقائي قفز مرور، جعل keyless CI إبقاء أخضر لون ([حقيقي API e2e Agent Note](../.agents/notes/implemented/testing/2026-06-19-real-api-e2e-ci.ar.md)).
- **الذي تابع موضع مسبق مدة إخراج**(`pnpm run test:expected`): بلا تسجيل صنع جلسة نحو إرجاع بلا مفتاح تجميع CLI/عملية مسبق مدة. قيادة استخدام `*.expected.e2e.ts`، و و `tests/expected/` نفس تابع واحد موضع؛CI إبرة مقابل بناء ناتج تشغيل. حزمة/نص برمجي مسبق مدة استخدام `test`، متصفح مسبق مدة استخدام `test:web`.
- **صفة قدرة أساس دقيق**(`pnpm run test:bench`؛ مطلوب Linux PR gate `node 24 / benchmarks`):`benchmarks/` حسب مستخدم مسار مجموعة نسج بوابة. هو أولا بناء library و worker؛ يتم حساب وقت شفرة في صاف Node تحت تشغيل، لا استخدام TSX. دمج صار إدخال تنفيذ استهلاك وقت، كومة و تقليص وضع ميزانية؛ حزمة داخل `.perf.ts` إبقاء لـ تشخيص ([قاعدة](../.agents/notes/implemented/testing/2026-09-04-session-open-performance-gate.ar.md)).
- **لقطة**(`pnpm run test:snapshot`): قمة طبقة مشهد عدد قيمة الأكثر عال قد تسجيل صنع parent generation معا توفير مستخدم إدخال و نموذج إعادة تشغيل، و بصفة حفظ دائم نتيجة مسبق مدة قيمة.parent ملف اسم هو `session[.vN].jsonl`؛child زاوية لون استخدام `session.<ordinal>[.vN].jsonl`؛v0 حذف `.v0`، صحيح إصدار يجب استخدام صغير كتابة `.vN`، كما كل ملف اسم يجب و ذلك header متسق. عملية درجة مشهد كل عبر `dsh` بدء:headless مسؤول مرة صفة سلوك،SDK مسؤول حمل دائم تحكم،ACP مسؤول تلقائي تحويل بروتوكول سلوك،Web في نفس Session جانب إبقاء متصفح و ARIA دليل.`snapshot.yml` إعلان profile، تركيب و طلب رأس صنف آخر، تسجيل صنع سياسة، مثال خارج إعادة تشغيل أو إدخال بيانات وصفية و workspace واقع. حمل نوع token إبقاء أب فرعي هوية علاقة؛ فقط لديه طلب رأس pin يملك prompt/schema sidecar. تغيير workspace مشهد سوف مستقل مقارنة مقارنة كامل `workspace.expected/` دليل،record و refresh أبدا تعديل كتابة هذا دليل. عند نموذج transcript(نص سجل) تغير وقت استخدام `test:snapshot:record`، إعادة تشغيل إدخال ما زال صالح وقت استخدام `test:snapshot:refresh`؛ طلب مراجعة فحص كل نتيجة فرق مختلف.
- **Web متصفح لقطة**(`pnpm run test:web`؛ مطلوب Linux PR(Pull Request) بوابة):Chromium مقارنة مقارنة `snapshots/web/` تحت من جلسة قيادة إخراج، و `apps/web/tests/expected/` تحت فقط يحتوي UI إخراج.CI قوي صنع فقط قراءة `DSH_SNAPSHOT=replay`، أبدا كتابة مسبق مدة إخراج؛record/refresh إبقاء في محلي، كل موضع diff كل يجب مراجعة ([web e2e عربة طريق](../.agents/notes/implemented/testing/2026-07-24-web-gui-browser-e2e-lane.ar.md) ،[CI بوابة قرار](../.agents/notes/implemented/testing/2026-07-30-web-browser-snapshot-ci-gate.ar.md)).`test:web` سوف أولا بناء بـ تسليم إضافة CSS.

Session fixture إبقاء header و payload، لكن حذف متن seq/time envelope؛replay سوف دمج صار هذه envelope.Replay،record و refresh سوف اختيار كل parent/child زاوية لون الأكثر عال generation. حالي fixture في ملف اسم و header في استخدام[كتابة صيغة](session-format-status.ar.md) ، كل حدث واحد سطر، و تضمين دخول ضيق تجميع Assistant stream. تاريخ fixture إبقاء ذلك قد إصدار يمثل؛ صريح `sessionFormat` كل من إبقاء ترحيل تغطية. حسب وفق[صيغة إصدار فعلي تشغيل يد سجل](cookbook/adding-a-session-format-version.ar.md#snapshot-successors) إضافة بعد استمرار بديل حد، لا تعديل قبل بديل.

## spec مثل أي يتم تنفيذ

fork خروج worker سوف معا تشغيل كثير عدد spec ملف،coverage gate سوف تفكيك صار تزامن partition، و نفس عدد job في ذلك هو gate و ترتيب تشغيل، بينما ذاتي حمل إدارة runner مشترك استخدام نفس منصة مضيف آلة و نفس عدد لفة. يتم عزل فقط لديه عملية: طرف فتحة، يمكن مسبق قياس مسار، خارجي نطاق الأسماء و وراثة بينما قدوم عملية فرعية كل لا عزل. لـ كل احتلال استخدام مورد مسؤول إلى هو teardown، و يأخذ «فقط لديه مفرد وحيد وقت التشغيل عندئذ عبر» spec قراءة عمل هذا spec نقص وقوع، بينما لا هو runner لا مستقر.[dsh-ci-test-reliability](../.agents/skills/dsh-ci-test-reliability/SKILL.md) مسؤول مورد قسم إعداد، حالة استعادة، تزامن، مهلة ميزانية، منصة فرق مختلف و teardown قاعدة؛ هو [flake تشخيص مسار](../.agents/skills/dsh-ci-test-reliability/references/ci-flake-diagnosis.md) لأجل عودة صنف قد وجود عام معدل صفة فشل.

## حمل مفتاح سياسة: دفع إدارة (inference) في هذا داخل جدا سهل مناسب

أنا جمع هو DeepSeek، لا يلزم بخل أسف حقيقي API اختبار. بلا مفتاح اختبار فقط قدرة إثبات قاع طبقة عبر مسار؛ فقط لديه حمل مفتاح تشغيل عندئذ قدرة إثبات agent(ذكي جسم) قدرة مقابل وصل حقيقي نموذج صحيح معتاد عمل. تغطية ملف كتابة نص التوجيه، يتضمن كثير عدد جولة محادثة، أداة استخدام و تدفق في إلغاء. قيمة قيمة الأكثر عال هو**خطر دخان اختبار**: بدء قد تسليم `dsh` profile، إرسال واحد بند نص التوجيه، و فحص خارجي عالم حد؛ هو جمع قدرة التقاط «اختبار وحدة كل أخضر، منتج لكن تالف» هذا واحد صنف mock لا يمكن اكتشاف مشكلة ([أمر لذا تكرار قرص 0001](postmortem/0001-acp-default-export-drops-inject.ar.md)). تلقائي قفز مرور يجعل بلا مفتاح CI و بلا مفتاح مساهمة من لا تلقي منع سد؛ هو لا هو صار هذا إشارة.Profile درجة اختبار تكامل يقع في `apps/cli/tests/profiles/`؛ حزمة مخصص تابع تركيب إبقاء في مقابل حزمة اختبار دليل في.

## أولوية استخدام حقيقي تنفيذ بينما غير mock

فقط mock فتح إلغاء عال أو لا تحديد حد (LLM(كبير لغة نموذج) مهايئ، شبكة، وقت ساعة) ؛ تحت تنقل واحد قطع إبقاء حقيقي. يد كتابة بديل ذات فقط قدرة إثبات جسر وصل طبقة في نقل تشغيل بايت، لا يستطيع إثبات تسليم أداة سلوك رمز دمج تأكيد. جسر وصل استدعاء الأداة اختبار يأخذ حقيقي أداة سجل التسجيل و تنفيذ إدارة خط إبقاء في نص برمجي تحويل mock نموذج تحت تنقل:`makeBridgeHarness()`(packages/acp/acp/tests/harness.ts) تركيب agent loop، جلسة تخزين، أداة سجل التسجيل و JSONL حفظ دائم، وحيد mock هو نص برمجي تحويل `MockAdapter`.

استعادة اختبار حسب خطوة منطقة قسم قسم قطعة قبل و قسم قطعة بعد فشل، و إثبات فشل قسم قطعة لن إرسال توليد خروج رسالة أو أداة فرعي أثر. تغطية استهلاك كل، إلغاء، سياسة تركيب، حفظ دائم، حالة، بروتوكول حساب عدد، سوف إغلاق نقل فارغ خامل مهلة، و تسليم Loader تركيب.

## تحقق خارجي عالم حد، بينما غير ذاتي أنا تقرير إبلاغ

e2e تأكيد ينبغي إعادة تشغيل أمر أو من خارجي إعادة قراءة ملف؛ مقابل agent ذاته إخراج فعل صلة مفتاح كلمة استكشاف قياس سوف يجعل عمل عيب agent عبر. تأكيد لم تعديل ملف تدريجي بايت متسق.e2e اختبار ذاتي سطر إدارة مورد: في اختبار في إنشاء harness، في `afterEach` في dispose(أي جعل فشل/إعادة محاولة/مهلة أيضا يلزم تحرير) ؛ مشترك fixture وضع في عادي `tests/harness.ts` في، أبدا وضع في آخر عدد `*.e2e.ts` في (استيراد واحد spec سوف إعادة تسجيل ذلك `describe`، توجيه يؤدي حقيقي API استدعاء تكرار تنفيذ).

## اختبار حقيقي مدخل مسار

- منتج مرئي إضافة يجب لديه واحد غير وحدة حقيقي تركيب اختبار. يد حركة بناء `ctx.plugin(...)` طقم عنصر لا كاف: عبر Loader و app/process بدء فقط لأجل اختبار `cordis.yml`، فقط mock خارجي خدمة أو غير تحديد صفة إدخال، تأكيد نموذج مرئي طلب/سجل، حمل دائم حالة أو مستخدم مرئي إخراج. لا يلزم يأخذ opt-in خيار خلط دخول تسليم قيمة افتراضية.
- واحد حراسة حماية فقط لديه في ارتداد قدرة يجعل هو فشل وقت عندئذ صالح. مقابل في لا يوجد `inject` إضافة (bundle/تركيب إضافة) ،Loader خطر دخان اختبار في افتراضي تصدير استبدال مطلوب أداة اسم تصدير وقت ما زال أخضر حال——حاجة إضافة صريح `expect('default' in mod).toBe(false)` إضافة `unwrapExports` نحو إرجاع تأكيد، و إثبات هو صالح: جذب دخول ارتداد، مراقبة تغيير أحمر، رجوع.
- «حقيقي مدخل مسار» إشارة قد إصدار ناتج: حزمة `bin` الذي تشغيل هو بناء بعد `lib/bin.js`، و من عادي `node` تنفيذ، من بينما كشف tsx سوف إخفاء غطاء فشل (تسوية تنافس حالة، وحدة تحليل، يتم ابتلاع إسقاط تحميل فشل). نفس مثال قاعدة ملائم لأجل غير index وقت التشغيل مدخل (Node برنامج bootstrap `lib/process.js`) ، أيضا ملائم لأجل كثير عدد bundle مشترك مفرد مثال وحدة (`packages/sdk/server/tests/built-scope-carrier.e2e.ts`). إبقاء بناء ناتج خطر دخان اختبار أخضر لون (`packages/examples/*/tests/built-bin.e2e.ts`،`packages/ptc-runtime/ptc-runtime-node/tests/built-lib.e2e.ts`) ، و تأكيد حق صحيح ناقص إعداد بـ غير صفر حالة خروج.

## اختبار تحليل: فقط حد شفرة المصدر

- كل vitest إعداد كل سوف vite-tsconfig-paths إشارة نحو `tsconfig.base.json`؛ مساحة العمل حزمة عار استيراد تحليل إلى `src`([تخطيط](development.ar.md#typescript-project-layout)) ، أبدا سوف مرور من حزمة `exports` تحليل إلى بناء بعد `lib/`، لأن منها قديم قديم ناتج سوف تحميل ثاني نسخة وحدة مفرد مثال. بناء ناتج فقط في صريح إشارة تحديد وقت استخدام: بـ `lib` نمط تشغيل عملية فرعية، و تحت نص بناء ناتج خطر دخان اختبار.

## اختبار عملية فرعية بدء نمط

- CI و قد لديه بناء ناتج اختبار عبر طريق عبر مشترك مزدوج نمط بدء جهاز، من بناء بعد `lib/` تشغيل كل profile أو Cordis إعداد عملية فرعية. لا يلزم لـ هذه عملية فرعية يد كتابة `--import tsx`.
- لا تحميل Cordis بروتوكول و عملية نظام fixture مباشر عبر Node تشغيل استخدام يمكن مسح حذف لغة قاعدة `.ts` ملف، لا مرور مرور tsx أو أصل مسار خريطة.
- فقط لديه اختبار كائن ذاته هو شفرة المصدر مسار تحليل وقت، عندئذ يمكن اختيار `src`؛ في اختبار في كتابة واضح هذا واحد اتفاق.

## أي وقت حاجة لقطة اختبار

كل بند غير مستو كل نموذج مرئي، بروتوكول مرئي أو شخص صنف مرئي تغيير، كل في نفس PR في إضافة أو تحديث بلا مفتاح تسجيل صنع جلسة مشهد؛ حزمة درجة،e2e، فقط mock و PR إدارة من دليل لا يستطيع يحل محل تجميع بعد transcript.Headless،SDK،ACP و Web تسجيل صنع قسم آخر يقع في `snapshots/session/`،`snapshots/sdk/`،`snapshots/acp/` و `snapshots/web/`؛Web تصيير يمكن صريح استعارة استخدام آخر عدد مشهد مواصفة جلسة. لا من تسجيل صنع جلسة قيادة مسبق مدة إخراج إبقاء في الذي تابع تطبيق، حزمة أو نص برمجي `tests/expected/` تحت، و كما لا استخدام `*.snapshot.ts` بعد لاحقة.[`dsh-session-snapshot`](../packages/test-support/session-snapshot/README.ar.md) يملك مشترك تخزين قاعدة و profile مهايئ.Agent loop، جلسة دورة الحياة و `SessionEventMap` تغيير ينبغي تحديث اثنان عدد SDK إسقاط:`snapshots/sdk/` يملك TypeScript،[Python وقت التشغيل CI](../.agents/notes/implemented/process/2026-09-06-master-only-platform-ci.ar.md) يملك `scripts/snapshots/python-sdk-single-exe/`. إضافة جديدة capability seam، دورة الحياة أو transcript تغيير جسم ينبغي في خطة مرحلة مقطع صف خروج كل مطلوب طبقة درجة.
