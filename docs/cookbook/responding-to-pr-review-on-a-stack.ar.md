# في كومة تراكم PR سلسلة في عودة ينبغي مراجعة معنى رؤية

[English](responding-to-pr-review-on-a-stack.md) | العربية

مراجعة معنى رؤية ممكن معا إبرة مقابل واحد بند اعتماد كومة تراكم (`A ← B ← C …`) في كثير عدد PR(Pull Request). طلب عبر GitHub رسمي جهة كومة تراكم PR وظيفة إبقاء هذا بند سلسلة صلة ربط. هذا إشارة جنوب مسؤول مراجعة إصلاح ملكية و نقل بث؛[dsh-merging-stacked-prs](../../.agents/skills/dsh-merging-stacked-prs/SKILL.md) skill(تقنية قدرة) مسؤول فحص صلة ربط علاقة و سقوط أرض.

## أساس هذا قاعدة

1. **كل PR فرع واحد worktree.** كل PR إصلاح في هذا PR ذاتي ذات worktree في إجراء؛ و سطر إصلاح أبدا مشترك نفس عدد checkout.
2. **GitHub stack كائن هو مرجعي اعتماد حسب.** base فرع تحديد مسبق مدة اعتماد ترتيب،`PullRequest.stack` و `stackEntry.position` فإن إثبات GitHub قد تعرف آخر هذا كومة تراكم. لم مرور فحص هذه حقل، لا نيل فقط سند فرع سلسلة تطابق دمج حينئذ سوف ذلك نظر لـ رسمي جهة كومة تراكم.
3. **إصلاح سقوط في جذب دخول مشكلة ذلك عدد PR فوق، لكن بعد امتداد كومة تراكم نحو فوق تدفق حركة.** عند PR `B` فوق تقييم نقاش إشارة نحو `B` جذب دخول شفرة وقت، في `B` فوق إصلاح، مجددا سوف `B` تغيير نقل بث إلى `C`، أي جعل `C` أيضا يتضمن هذا ملف. يأخذ إصلاح إرسال بدء في تحت تنقل سوف توجيه يؤدي `B` حمل حال لم إصلاح شفرة تسليم، و مقابل `B` مراجعة من إخفاء إصلاح.
4. **كل بند مراجعة إصلاح كل إبقاء لـ مستقل commit.** لاحق rebase ممكن تغيير ذلك OID، لكن لا نيل عبر amend يأخذ قد مراجعة إصلاح من فرع تاريخ في مسح ذهاب. فقط لديه أنت ذاتي ذات بعد لم دفع إرسال كما بعد لم مراجعة عمل عندئذ يمكن amend.
5. **واضح اختيار merge-forward أو rebase.** مراجعة بعد سماح اعتماد هذا اثنان نوع تاريخ تحديث طريقة. تعديل كتابة تاريخ دفع إرسال يجب تلقي lease حفظ حماية؛ إذا بعيد طرف head في هذا خلال قبل نقل، عملية يجب في توقف، لا نيل سوف ذلك تغطية. منع توقف مباشر استخدام `--force`.

## امتداد كومة تراكم حل قرار مراجعة معنى رؤية

1. في سطر حركة قبل أولا حينئذ أمر نقاش أمر أرض مراجعة نظر كل بند تقييم نقاش: مقابل وفق شفرة تحقق ذلك نقاش قطع——مراجعة من إشارة خروج صحيح تأكيد عرض حالة، لكن ما زال ممكن خطأ تشخيص سبب.
2. سوف كل يتم قبول اكتشاف خريطة إلى جذب دخول هذا مشكلة PR، و في ذلك داخل إصلاح.
3. سوف إصلاح بعد طبقة حسب ترتيب نقل بث إلى كل تلقي أثر فرعي PR:
   - **Merge-forward:** سوف إصلاح بعد أب فرع دمج إلى ذلك فرعي فرع، تحقق فرعي فرع، لكن بعد متابعة امتداد كومة تراكم نحو فوق نقل بث. إبقاء كل جارٍ معالجة فحص نقطة.
   - **أصلي درجة ربط rebase:** استخدام `gh stack rebase`، تحقق كل قد تعديل كتابة طبقة، لكن بعد عبر `gh stack push` إصدار؛ أيضا يمكن استخدام `gh stack sync`، هذا أمر ممكن أولا إصدار، لذلك يجب حسب وفق [dsh-pre-push-checks](../../.agents/skills/dsh-pre-push-checks/SKILL.md) في تزامن بعد قيام أي تحقق.
4. تفويض إرسال إصلاح حاجة معلومة مهمة لكن تحقق:subagent تقرير إبلاغ وصف هو معنى رسم، لا واحد تحديد هو فعلي سقوط أرض محتوى. طلب قريب ذاتي في فعلي شفرة شجرة فوق إعادة تشغيل بوابة؛ مقابل في ارتداد حراسة حماية، يلزم إثبات هو في لم إصلاح شفرة فوق**فشل**(جذب دخول ارتداد، مراقبة تغيير أحمر، مجددا أيضا أصل)——اثنان نوع حال حال كل عبر حراسة حماية ماذا أيضا حراسة لا إقامة.subagent سوف مشكلة إعادة تحديد صفة لـ «قد معالجة» وقت، هذا هو واحد حاجة قريب ذاتي عميق دخول إشارة.
5. في مراجعة خط مسار في عودة تكرار (`gh api repos/{owner}/{repo}/pulls/{pr}/comments/{id}/replies`) ، بينما غير إرسال قمة طبقة تقييم نقاش؛ شرح إصلاح محتوى و حالي تحمل تحميل إصلاح commit أو head.
6. كل مرة تعديل كتابة دفع إرسال بعد، كل يلزم إعادة قراءة لم حل قرار خط مسار، دفعة دقيق حالة، يمكن دمج صفة و فحص نتيجة. مرور force-push تعديل كتابة commit OID أو قد مرور وقت داخل ربط مرساة نقطة، كل لا كاف بـ إثبات هذا اكتشاف حالي ما زال موضع في قد حل قرار حالة.
7. فقط يمكن عبر رسمي جهة كومة تراكم مسار سقوط أرض. إذا هذه PR بعد لم صلة ربط، سقوط أرض skill سوف تلقائي صلة ربط عمل من نفسه سلسلة؛ إذا عمل من مختلف، فإن أولا استفسار سؤال مستخدم؛ إذا أصلي كومة تراكم دعم حمل غير ممكن استخدام، فإن صلب صفة إيقاف مسار.

## تحقق

- كل قد إصلاح PR حالي diff كل في جذب دخول مشكلة ذلك واحد طبقة يتضمن مسبق مدة إصلاح صحيح.
- GraphQL تقرير إبلاغ رسمي جهة كومة تراكم فقط لديه واحد كما ترتيب رمز دمج مسبق مدة؛ كل فرعي PR متبادل مقابل في أب PR diff فقط عرض هذا فرعي PR ذاته تغيير.
- كل مرة تعديل كتابة دفع إرسال بعد، متساو إعادة مراجعة حساب لم حل قرار خط مسار، دفعة دقيق حالة، يمكن دمج صفة و فحص نتيجة.
- متبادل صلة بوابة في كومة تراكم في كل تلقي أثر PR فوق كل عبر، بينما لا فقط فقط هو قمة جزء.
