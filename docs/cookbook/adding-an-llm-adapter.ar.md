# فعلي تشغيل يد سجل: إضافة LLM(كبير لغة نموذج) مهايئ

[English](adding-an-llm-adapter.md) | العربية

مثل أي وصل دخول واحد جديد نموذج مزود. مشاركة اعتبار تنفيذ:`packages/llm/llm-deepseek`(مباشر HTTP،SSE(Server-Sent Events) من `eventsource-parser` قسم لقطة) و `packages/llm/llm-pi-ai`(غلاف تركيب LLM مكتبة). طلب أولا قراءة قراءة `packages/llm/llm/src/types.ts` في `StreamChunk` وثيقة——هو سجل اثنان عدد مهايئ كل مرور مرور تحقق بروتوكول اتفاق.

## أساس هذا شكل

```ts ignore-check
class MyAdapter extends LlmAdapter {
  async * stream(options: GenerateOptions): AsyncIterable<StreamChunk> { … }
}

export const name = 'llm-myprovider'
export const inject = ['llm']
export const Config: z<Config> = z.object({ apiKey: z.string(), … })

export function apply(ctx: Context, config: Config) {
  ctx.llm.registerAdapter(['my-provider'], new MyAdapter(…))
}
```

تسجيل أساس في فرعي أثر، يمكن أمان دعم حمل HMR(حار وحدة استبدال) ؛ كل مزود توجيه فقط مقابل واحد مهايئ، تكرار تسجيل سوف رمي خروج استثناء، كثير توجيه تسجيل يلزم ما الكل نجاح، يلزم ما الكل فشل.`options.provider` لأجل اختيار مهايئ،`options.model` هو مزود نموذج ID، لذلك حركة حالة نموذج دليل مهايئ بلا حاجة إعادة إعداد دورة الحياة يكفي توفير جديد نموذج. مفتاح اعتماد Cordis أصلي طريقة إدارة:schemastery Config حمل بيئة متغير رجوع، عبر cordis.yml `!!js process.env.MY_KEY` حقن. قطع لا في شفرة في قراءة ذاتي سطر اتفاق مفتاح ملف.

## بروتوكول معنى خدمة (اثنان عدد تنفيذ مشترك نفس تحقق اتفاق)

- في `finish` **قبل**إرسال خروج `usage`؛`finish` بعد**لم يعد إرسال خروج أي محتوى**. مستقر سليم فعل قاعدة: مؤقت اندفاع finish/usage مباشر إلى مزود تدفق انتهاء علامة، مجددا موحد واحد flush(يمكن معالجة مزود في نهاية ذيل إرسال فقط يحتوي usage قسم قطعة حال حال).
- استدعاء الأداة `arguments` كل مسار لـ أصلي JSON نص؛ تدفق صيغة قطعة مقطع بـ `argumentsDelta` إرسال. إذا أنت مزود إرجاع قد تحليل كائن، طلب في `block-end` وقت إعادة stringify.
- حسب أول مرة ظهور تدفق ترتيب قسم إعداد كتلة `index`؛ نفس عدد كتلة كل مرة delta إعادة استخدام هذا index.
- خطأ لديه كما فقط لديه اثنان بند دمج قاعدة مسار: من `stream()` **رمي خروج**(نقل و بروتوكول لذا عائق——استخدام حمل مستقر code `LlmError`) ، أو بـ `finish {kind: 'error' | 'aborted'}` انتهاء تدفق (مزود حمل داخل لذا عائق). مستهلك اثنان من كل معالجة؛ حسب لذا عائق صنف آخر اختيار مسار و إضافة بـ وثيقة تحويل.
- التزام حراسة `options.signal`(سوف ذلك نقل تمرير إعطاء fetch أو أنت SDK).
- إذا `GenerateOptions` في بعض عدد حقل أنت مزود لا يمكن دعم حمل (مثال مثل مزود لا دعم حمل stop sequences وقت استلام إلى `stop` قائمة): رمي خروج `LlmError(..., 'UNSUPPORTED_OPTION')`، بينما غير ساكن صامت إسقاط.
- إذا مزود في لاحق استدعاء في حاجة استجابة ID، توقيع أو أخرى أصلي بيانات وصفية، طلب سوف ذلك الأكثر صغير بلا ضرر JSON إسقاط بصفة `finish.replayState` إرسال خروج. إعادة بناء تاريخ وقت تحقق هذا حالة. فقط لديه تاريخ مزود توجيه و هدف مزود توجيه حالي من تماما نفسه مهايئ نسخة يملك وقت،`LlmRuntime` عندئذ سوف نقل تمرير هذا حالة؛ من مهايئ قرار نفس نموذج، عبر نموذج أو عبر مزود استعادة هل دمج قاعدة. حالة ناقص وقت، قطع لا فقط أصل حسب مزود/نموذج اسم دفع قطع أصلي إعادة تشغيل.

مزود خاص لديه تفكير اعتبار نمط فتح صلة ما زال وضع في مهايئ Config في. تأكيد قطع نموذج بيانات وصفية استخدام واحد موضع مزود غير متصل قدرة seam: تنفيذ `resolveModel()`، إرجاع مزود/نموذج هوية و اختياري `context` و `reasoning` حقل؛ فقط عند وجود إعداد إشارة تحديد قيمة افتراضية وقت عندئذ إعلان `defaultEffort`؛ التزام حراسة تحليل نموذج وقت نقل دخول اختياري `AbortSignal`. دفع إدارة (reasoning) قوي درجة هو من مهايئ خريطة إلى مزود طلب لديه ترتيب لا نفاذ واضح ID. طلب إبقاء مهايئ إعطاء خروج مرجعي اختياري قائمة، يشمل مهايئ في دعم حمل وقت تعريف `off`؛ لا نيل كشف نهائي بروتوكول قيمة أداة جسم تجميع كتابة، أيضا لا نيل تلقائي ضبط كامل لا دعم حمل قيمة.ID بلا حاجة و ذلك بروتوكول يمثل نفسه.

## تنفيذ بنية

يجعل بروتوكول صيغة (wire format) نوع، طلب تسلسل تحويل، نقل تحليل، قسم قطعة تحويل و مهايئ صنف قسم آخر تحمل تحمل مستقل مسؤولية؛[`llm-deepseek`](../../packages/llm/llm-deepseek/README.ar.md) هو مشاركة اعتبار تخطيط.
