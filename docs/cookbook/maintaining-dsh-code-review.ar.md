# صيانة dsh-code-review skill

[English](maintaining-dsh-code-review.md) | العربية

[`dsh-code-review`](../../.agents/skills/dsh-code-review/SKILL.md) skill(تقنية قدرة) من واحد اسم إشارة تحديد عملية عضو عبر خاص دورة مدة صيانة أداة حمل متابعة تحديث. هذا فعلي تشغيل يد سجل حيث هو هذا عملية عضو و وصل مهمة من مدخل، أيضا مساعدة مساعدة مستودع مساهمة من إدارة حل لـ أي skill تحديث سوف بـ صغير نوع دورة مدة PR(Pull Request) شكل صيغة ظهور، بينما لا هو مرة صفة مراجعة حساب. سير العمل ذاته من[شخص عمل مراجعة skill صيانة Agent Note](../../.agents/notes/proposed/process/2026-07-13-human-review-skill-maintenance.ar.md) قاعدة تحديد.

## صيانة من سوف استلام إلى ماذا

عملية عضو كل يوم يد حركة استدعاء حزمة تركيب نص برمجي، و استخدام 2 عدد UTC يوم إعادة تراكم نافذة؛ كل دورة يد حركة استعادة تشغيل استخدام 7 يوم نافذة. سير العمل سوف:

1. اختيار إشارة تحديد نافذة داخل دمج، كما دمج commit يمكن من `origin/master` وصول PR(كل يوم تشغيل افتراضي اختيار 2 عدد UTC يوم، كل دورة تشغيل اختيار 7 يوم). دمج commit لا يمكن وصول PR(مثال مثل أب فرع يتم squash كومة تراكم فرع) ، أو تجاوز خروج 250 عدد commit نيل أخذ حد أعلى PR، سوف سجل إلى `skipped-pulls.json` و قفز مرور، لن في توقف هذا مرة تشغيل.
2. استلام تجميع دمج قبل حمل commit مرساة نقطة شخص عمل مراجعة عكس تغذية (سطر داخل تقييم نقاش و مراجعة إيداع) ، لكن بعد مقارنة مقارنة عكس تغذية وقت و نهائي سقوط أرض PR patch. هو لا نيل أخذ PR جلسة تقييم نقاش، لأن GitHub حالي حالة لا يمكن لـ هذه تقييم نقاش توفير يمكن مقاومة مقاومة force-push عكس تغذية وقت أساس خط؛ هو أيضا لن يأخذ فقط وجود في هدف فرع تغيير بصفة قبول دليل.
3. اثنان عدد مستقل إعداد مراجعة مهايئ أولا مقابل كل بند عمل من و أكثر تعديل هل قبول هو إجراء تصنيف، مجددا أصل حسب حالي skill مقابل مزدوج جهة متسق إقرار تحديد قد قبول بند تصنيف.
4. رئيسي مهايئ بدء مسودة كامل إصلاح حجز إصدار `SKILL.md`؛ اثنان عدد مهايئ مراجعة نفس نسخة diff؛ فقط يلزم ما زال لديه منع سد صفة مشكلة، حلقة حينئذ سوف متابعة، مباشر إلى مزدوج جهة دفعة دقيق.
5. أداة إعلان نجاح قبل، سوف إبرة مقابل مرشح إصدار تشغيل `pnpm run doc-sync` و `pnpm run lint`.

كل مرة تشغيل كل يأخذ ناتج حفظ في عملية عضو آلة جهاز فوق. حفظ diff، مرشح `SKILL.md` و رفع رفع manifest(بيانات وصفية بيان) حسب ختم الوقت تسمية، تخزين وضع في `~/dsh-code-review-outputs/` تحت.manifest سجل مصدر master commit و skill blob، مصدر عكس تغذية ID و URL، قد سقوط أرض دليل نطاق، مهايئ قطع قرار و بوابة نتيجة؛ كل مهايئ أصلي I/O إبقاء في خاص مؤقت دليل في، هذا دليل مسار سوف كتابة إشعار و `~/Library/Logs/dsh-code-review-maintainer/` تحت كل يوم سجل. صيانة worktree في كل مرة تشغيل بعد كل سوف استعادة لـ جاف صاف حالة، تجنب تجنب عملية عضو مباشر في صيانة فرعي هذا في تحرير.

## عملية عضو مثل أي معالجة مرشح diff

بعض مرة تشغيل إنتاج خروج مرشح إصدار وقت،macOS سوف إرسال خروج واحد بند حمل `dsh-code-review-promote <timestamp>` تلميح إشعار.

1. **أصل حسب diff ذاته عمل خروج حكم قطع.** لا يلزم لأن «مراجعة من قد دفعة دقيق» حينئذ مباشر قبول؛ صيانة من اتفاق قاعدة تحديد من عملية عضو عمل خروج نهائي قرار. فحص بيان هل تمدد انتفاخ، هل لديه تاريخ سرد وصف، هل أصل حسب مفرد مرة حدث عمل خروج بلا اعتماد حسب خارج دفع، و هل و قائم skill أو مرجعي وثيقة تكرار.

   ```sh
   ls ~/dsh-code-review-outputs/                         # every candidate ever produced
   less ~/dsh-code-review-outputs/2026-07-16T02-00-00Z.diff
   less ~/dsh-code-review-outputs/2026-07-16T02-00-00Z.SKILL.md
   less ~/dsh-code-review-outputs/2026-07-16T02-00-00Z.manifest.json
   ```

2. **و تشغيل ناتج تسليم تقاطع نواة تحقق.** رفع رفع manifest سوف يأخذ كل بند محاكاة اقتراح قاعدة خريطة إلى مصدر عكس تغذية و قد سقوط أرض دليل؛ كل مهايئ تفصيل دقيق I/O، مشترك تعرف و قبول دليل يقع في هذا مرة تشغيل خاص مؤقت دليل في (مسار رؤية سجل). حتى قليل سحب فحص واحد مرشح بند: رابط شخص عمل تقييم نقاش هل تأكيد فعلي دعم حمل إضافة جديدة قاعدة؟ رابط PR هل تأكيد فعلي قبول هو؟

3. **من ثلاثة نوع معالجة طريقة في اختيار واحد نوع:**
   - **إسقاط.** حذف حفظ مرشح إصدار. تحت مرة تشغيل سوف اعتماد حسب دورة وقت حالي skill، إعادة اعتبار نفس نسخة عكس تغذية.

     ```sh
     rm ~/dsh-code-review-outputs/2026-07-16T02-00-00Z.{diff,SKILL.md,manifest.json}
     ```
   - **إبقاء انتظار صار دفعة معالجة.** إذا تحديث جدا صغير، يمكن يأخذ مرشح إصدار إبقاء انتظار و لاحق إصدار دمج. مصدر skill فحص ما زال ملائم استخدام؛ إذا `master` أولا حدوث تغير، طلب إعادة تشغيل قسم تحليل، أو يد حركة rebase و إعادة مراجعة diff.
   - **رفع رفع.** في مستودع جاف صاف `master` checkout في تشغيل رفع رفع مساعد مساعدة أداة. هو سوف تحديث جديد `master`، تحقق حالي skill و سجل مصدر blob متسق، تطبيق حفظ diff، و إنشاء واحد نسخة draft PR، ذلك متن صف خروج أصلي عكس تغذية URL أو ID، قد سقوط أرض commit نطاق، إرسال بدء هذا مرة أكثر تعديل تشغيل، فحص و عملية عضو تحرير. إذا skill قد حدوث عائم نقل، هو سوف إيقاف بينما لا هو تغطية تحديث بعد إشارة توجيه؛ عملية عضو ما زال يحتاج في GitHub فوق مراجعة PR، و اختيار دمج أو إغلاق.

     ```sh
     cd ~/path/to/deepseek-harness   # clean master
     dsh-code-review-promote 2026-07-16T02-00-00Z
     ```

4. **لا يلزم تدريجي حرف إيداع مهايئ إخراج.** رفع رفع مرور مسار في يمكن إجراء صغير عرض تحرير، مثال مثل استلام ضيق إجراء لفظ، إزالة فقط لديه ربط دمج مصدر PR سياق عندئذ متعمد معنى عرض مثال، يأخذ قاعدة و دخول قائم قاعدة. هذه تحرير هو مسبق مدة سلوك، أيضا إبقاء سير العمل الذي اعتماد «مراجعة من حكم قطع». دمج قبل ينبغي في هذا فرع فوق إصلاح حجز هذه تعديل.

## تشغيل لم إنتاج خروج مرشح إصدار وقت

فقط يلزم كل غير فارغ تصنيف مرحلة مقطع كل حتى قليل إنتاج واحد صالح مهايئ نتيجة، هذا حينئذ هو معتاد رؤية حال حال. أداة سوف في كل يوم سجل في سجل «بلا مرشح إصدار» ، لا إرسال إشعار (تجنب تجنب رفع تنبيه إرهاق جهد) ، لكن بعد متابعة. بعض يوم لا يوجد skill تحديث، شرح سير العمل تشغيل صحيح معتاد، بينما لا هو توقف ركود.

## في قطع و تسليم وصل

هذا آلية تشغيل في واحد منصة آلة جهاز فوق. عملية عضو ينبغي مع وقت معالجة التالي في قطع:

- **خطأ مرور كل يوم تشغيل.** 2 يوم إعادة تراكم نافذة سوف تلقائي تغطية مرة تسرب ركض؛ أكثر طويل بين فصل يمكن عبر ضبط `DSH_CODE_REVIEW_SINCE=<Nd>` يد حركة تشغيل حزمة تركيب نص برمجي قدوم استعادة. إعادة تراكم نافذة أداة لديه قوة انتظار صفة: حالي skill قد يتضمن إشارة توجيه سوف يتم عودة صنف لـ `covered`، لن مجددا مرة يصبح مرشح بند.
- **مهايئ مزود في قطع.** عند اثنان عدد مراجعة أمر تحليل لـ تدريجي بايت نفسه يمكن تنفيذ ملف وقت، أداة سوف رفض تشغيل. بعض عدد دفعة مرة مهايئ استجابة لم عبر schema أو ID تحقق وقت، هذا دفعة مرة سوف كامل جسم fail-closed(منها كل بند كل علامة لـ لا واضح) ، تشغيل فإن متابعة؛ أصلي إخراج سوف إبقاء بـ سهل ضبط تجربة. إذا مهمة واحد مهايئ في بعض بند عملية كل غير فارغ دفعة مرة في كل لم إنتاج صالح نتيجة، هذا مرة تشغيل حينئذ سوف فشل، كتابة فشل سجل و إشعار عملية عضو؛ هو أبدا سوف يأخذ مزود تماما في قطع طي صار «بلا مرشح إصدار».
- **تسليم وصل إعطاء آخر اسم صيانة من.** جديد بناء واحد مقالة يحل محل حالي سجل لاحق Agent Note: يلزم ما يأخذ آلية نقل دخول مستودع، يلزم ما سجل جديد عملية عضو خاص ضبط. لا يلزم داكن في تحويل تسليم أداة؛Agent Note ريح خطر فصل عقدة قد يأخذ «مفرد صيانة من صلة مفتاح شخص ريح خطر» صف لـ تسليم وصل يجب سجل قرار سبب.

## عملية عضو خاص ضبط يقع في أي موضع

أداة مصدر شفرة، مراجعة مهايئ، مزود اعتماد و مجدول يخص عملية عضو خاص أساس أساس ضبط تطبيق، حسب تصميم يقع في هذا مستودع خارج (مشاركة رؤية Agent Note «آلية يقع في أي موضع» فصل عقدة). هذا فعلي تشغيل يد سجل و Agent Note وصف هو**سير العمل حفظ إثبات ماذا**؛ هذه حفظ إثبات**مثل أي**تنفيذ فإن يخص خاص أساس أساس ضبط تطبيق مشكلة. إذا أنت هو جديد عملية عضو، ينبغي بـ Agent Note `## Proposal` كل عقدة بصفة تنفيذ اعتماد حسب.
