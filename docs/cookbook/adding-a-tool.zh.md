# أداة تحرير كتابة مشاركة اعتبار

[English](adding-a-tool.md) | العربية

موجه إلى نموذج أداة يجب ممتلئ كاف أي بعض اتفاق، متساو بـ هذا نص لـ دقيق. مثل يحتاج حسب خطوة بناء رقم واحد أداة، طلب قراءة قراءة[بناء أداة](../user/develop/basic/tool.zh.md).`packages/shell/tool-bash` هو إنتاج درجة ثلاثة حزمة عرض مثال.

## الأكثر صغير شكل

```ts
import { readFile } from 'node:fs/promises'
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const name = 'my-tool'
export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(defineTool({
    name: 'read_file',
    description: 'Read a file from disk.',          // what the model sees
    parameters: {
      path: { type: 'string', required: true, description: 'Absolute path' },
      limit: { type: 'number' },                     // optional by default
    },
    output: {
      schema: { type: 'string' },
      render: (_args, value) => [{ type: 'text', text: value }],
    },
    async execute(args, exec) {
      // args is TYPED from the schema: { path: string; limit?: number }
      // exec carries immutable identity + token; signal is the operational field
      return readFile(args.path, { encoding: 'utf8', signal: exec.signal })
    },
  }))
}
```

تسجيل أساس في فرعي أثر:dispose(مورد تحرير) إضافة fiber أي ملاحظة إلغاء هذا أداة.schema سوف تلقائي تدفق دخول توجيه النظام تجميع مرور مسار.

## execute() اتفاق قاعدة

- **معامل قد لـ أنت تحقق.** `defineTool` في `execute` تشغيل قبل، سوف أصل حسب موحد واحد `ParameterSchemaSpec` تحقق نموذج توليد `arguments`(نوع، لا بد ملء مفتاح، حرف وجه كمية قيد، تماما جيد مطابقة واحد فرع ربط دمج و تضمين طقم قيمة) ، لذلك `execute` داخل args سوف مطابقة `InferArgs`. صريح كائن عقدة يجب إعلان `additionalProperties: true | false`؛ خفي صيغة معامل أصل كائن إبقاء فتح وضع. أنت ما زال يحتاج يد حركة فحص schema DSL لا يمكن جدول بلوغ قيد، مثال مثل غير فارغ نص، صحيح عدد أو عبر حقل قاعدة. مباشر تسجيل أصلي JSON Schema أداة ذاتي سطر مسؤول إدخال تحقق.
- **تسجيل استعارة استخدام أنت فقط قراءة تعريف.** نوع تحويل نفس عملية مساهمة لا هو تسلسل تحويل حد؛ تسجيل بعد لا يلزم تعديل ذلك schema أو استبدال عودة ضبط.`schemas()` فقط شيء تحويل صريح نموذج مرئي إسقاط. مثل يحتاج حار استبدال أداة، طلب dispose ذلك الذي تابع فرعي أثر و تسجيل بديل صنف؛ عودة ضبط إغلاق حزمة داخل متغير حالة ما زال هو عادي إضافة حالة.
- **تنفيذ هوية تلقي حفظ حماية.** سجل التسجيل في مرة تمرير عودة مرة تاريخ في سوف `arguments` شيء تحويل لـ قسم مغادرة بلا ضرر JSON، في سياسة بدء قبل تجميد ربط هذا قيمة، و قسم إعداد واحد لا نفاذ واضح `exec.token`؛`callId`،`name`،`arguments`،`agent`،`token`، لا بد ملء كما من استدعاء جهة يحتفظ `signal`، و اختياري خارج طبقة نقل `parent` token في كامل توزيع مرور مسار في إبقاء غير ممكن تغيير.`parent` فقط لأجل هوية معرف، لا كشف نشط وثب خارج طبقة تنفيذ. طلب سوف `args` نظر لـ فقط قراءة إدخال. فقط لديه around-dispatch حزمة تركيب جهاز سوف استلام إلى متغير عرض؛ هو يمكن استبدال و استعادة لا بد ملء `exec.signal` بـ تطبيق إضافة قطع توقف وقت، لكن لا يستطيع إزالة هذا إشارة.
- **إعلان و إرجاع واحد مواصفة JSON قيمة.** `output.schema` استخدام `ValueSchemaSpec`، أصل يمكن هو كائن، عدد مجموعة، علامة كمية أو null.`execute` فقط إرجاع دفع توجيه خروج قيمة؛ سجل التسجيل سوف ذلك لقطة لـ بلا ضرر JSON، إتمام تحقق و تجميد ربط بعد، مجددا نقل إعطاء `output.render(args, value)`. أداة رئيسي جسم لا يلزم إرجاع محتوى كتلة، أيضا لا يلزم إجبار جعل استدعاء جهة من ذاتي لكن لغة في تحليل id و حقل.
- **رمي خروج استثناء أو إرجاع بلا فاعلية قيمة معنى طعم حال `isError`.** سجل التسجيل سوف التقاط استثناء، و في مراقبة من تشغيل قبل استلام جمع schema، مصير، بيانات وصفية إسقاط جهاز و بلا ضرر JSON فشل. أساس أساس ضبط تطبيق لذا عائق طلب رمي استثناء. نجاح مجال نتيجة أي جعل يمثل لا إدارة تفكير حالة، أيضا ينبغي كتابة مواصفة قيمة؛ ذلك Native مصير يمكن حل تفسير هذا حالة، مثال مثل عملية بـ غير صفر حالة خروج.
- **التزام حراسة `exec.signal`.** إشارة إطلاق وقت إلغاء إجراء في عمل.
- **استخدام `presentationMeta` إسقاط حفظ دائم بطاقة بيانات (اختياري).** `output.presentationMeta(args, value)` من نفس عدد مواصفة قيمة إرسال توليد يمكن إعادة تشغيل JSON. نواة قلب سوف ذلك حفظ دائم في `tool/result` فوق و نقل إعطاء `presentResult`، لذلك حاجة نتيجة مدة واقع بطاقة——مثال مثل `write`/`edit` قد تطبيق hunk——بلا حاجة حفظ دائم مواصفة قيمة أيضا قدرة في إعادة تشغيل في إعادة الآن. تضمين طقم Code توزيع لا يوجد بطاقة، لذلك سوف قفز مرور هذا إسقاط جهاز.
- **استخدام `exec.agent` إرسال مختلف خطوة إشعار.** `agent.inject({ content, source: { kind: 'plugin', plugin: '<name>' } })` إلحاق حفظ دائم سياق، تحت مرة نموذج طلب سوف يرى هو——هذا لا هو نداء تنبيه (فارغ خامل agent(ذكي جسم) إبقاء فارغ خامل). طلب منع نطاق قد dispose agent(try/catch).

## طويل وقت تشغيل عمل

عبر producer إعداد تحكم `run_in_background`، لكن بعد استخدام `ctx.jobs.start({ kind, label, owner: exec.agent, run })` تسجيل مهمة. سجل التسجيل سوف في دخول producer رئيسي جسم قبل سوف قد مسبق أولا في توقف استدعاء حكم لـ فشل؛ وقت التشغيل سوف في `run()` بدء عمل قبل تحقق owner و مهمة تحكم جهاز هل متاح، مع بعد توفير id، جلسة محيط شريط، عام تحكم أداة، إشعار و owner cleanup. نجاح خلفية فرع سوف إرجاع نوع تحويل مواصفة جملة مقبض، مثل `{ kind: 'background', jobId }`؛ ذلك Native مصير يمكن إبقاء `started background job bash-1` هذا صنف توفير شخص قراءة قراءة ذاتي لكن لغة، لكن PTC mode أبدا قدرة عبر تحليل هذا نص أخذ نيل id.

producer توفير تزامن `cancel`، في مورد تنظيف بعد settle كما لا reject `done`، و اختياري إزالة استهلاك صيغة `readOutput`(مسؤول محدود إخراج صيغة تحويل). مسبق أولا في توقف استدعاء يخص فشل، لأن هذا وقت لا يوجد مهمة، ذلك id لا يمكن ممتلئ كاف نجاح إخراج schema.`ctx.jobs.start()` إصدار id بعد، ينبغي استخدام مهمة ذاتي لديه إلغاء إشارة، بينما لا هو `exec.signal`: بعد إلغاء خارج طبقة استدعاء فقط سوف إيقاف انتظار هذا مرة استدعاء، لن إنهاء قد إصدار عمل؛ هذا دورة الحياة عودة `job_kill`،owner dispose و خدمة teardown كل. قبل منصة عمل ما زال و `exec.signal` اقتران دمج. تدفق صيغة producer عرض مثال و كامل اتفاق رؤية[خلفية مهمة وقت التشغيل Agent Note](../../.agents/notes/implemented/architecture/2026-06-20-generic-long-running-tool-runtime.zh.md) و `dsh-tool-bash`.

## تنفيذ سياسة و مراقبة قياس

كل كمية لا يلزم يأخذ نشر سياسة داخل بناء إلى أداة في. استخدام `tools/pre-execute` تنفيذ يمكن توسيع سماح/رفض/استفسار سؤال سياسة (رؤية[إذن بوابة عرض مثال](extension-cookbook.zh.md#a-hook-plugin-permission-gate-example)) ؛ استخدام `ctx.tools.guard()` ضبط نهائي مفرد ضبط رفض، لاحق مستمع لا يمكن سحب إلغاء؛ استخدام `tools/execute` لـ توزيع إضافة قطع توقف وقت، إعادة محاولة أو إشارة علامة استلام تجميع؛ استخدام `tools/post-execute` استبدال عرض محتوى أو قيمة راجعة، منع توقف نتيجة، أو مرفق إضافة نموذج مرئي سياق؛ استخدام `tools/result` مراقبة قياس غير ممكن تغيير عودة واحد تحويل نتيجة بينما لا تغيير هو. استبدال محتوى لن منع توقف برنامج تحويل وصول `value`؛ حفظ سري سياسة سوف شاشة حجب أو استبدال هذا قيمة. صندوق رملي تنفيذ أيضا يمكن في أداة منفذ تنفيذ في تشغيل؛[`dsh-tools` README](../../packages/core/tools/README.zh.md#extension-points) تعريف كل نقطة توسيع إدخال، ترتيب، قيمة راجعة و فشل سلوك.

## PTC mode تلقائي لمس بلوغ أنت أداة

في [PTC mode](../../packages/core/tools/README.zh.md) في، كل مرئي قد تسجيل أداة كل يمكن عبر `await tools.<name>(args)` استدعاء، بلا حاجة مقدار خارج تجميع صار. توليد `ToolArgsMap` و `ToolOutputMap` سوف أصل حسب نفس مجموعة schema قسم آخر إرسال توليد دقيق معامل نوع و مواصفة إرجاع نوع، استدعاء فإن إعادة دخول صحيح معتاد تنفيذ خط الإنتاج. نجاح استدعاء سوف تحليل لـ سياسة معالجة بعد نهائي مواصفة JSON قيمة، بينما لا هو تصيير بعد Native محتوى. فشل استدعاء سوف بـ حق صحيح `ToolCallError` reject؛ برنامج فقط قدرة فحص ذلك `name`،`toolName` و يمكن توفير شخص قراءة قراءة `message`، لا يمكن أخذ نيل داخلي خطأ شفرة أو فشل ربط دمج.

طلب يأخذ `output.schema` تصميم لـ فعلي استخدام برنامج تحويل API: مباشر إرجاع جملة مقبض و حقل؛ عند علامة كمية، عدد مجموعة أو null تأكيد فعلي حينئذ هو نتيجة وقت، سماح اعتماد متبادل ينبغي أصل نوع؛ سوف موجه إلى شخص صنف حل تحرير دخول `output.render`. في بين قيمة فقط وجود في تنفيذ خلال، لن يتم حفظ دائم أو حسب نص التوجيه حد أعلى قطع قطع، أيضا لا ضبط بايت حد أعلى، لذلك إنتاج جهة مثل فعلي إعلان أخذ تجميع حد و عملية داخل تخزين ما زال إعادة يلزم. فقط لديه خارج طبقة `run_code` سجل/نتيجة سوف تلقي إلى يمكن إعداد إخراج حد أعلى و موجه إلى نموذج spill خط الإنتاج قيد.

## أداة في UI في تصيير طريقة

أداة `output.render` إرجاع نموذج مرئي محتوى؛ ذلك **UI بطاقة** هو آخر بند مستقل صلة ملاحظة نقطة، عبر صاف عرض إسقاط و اختياري `presentCall`/`presentResult` طريقة إعلان. طلب سوف هذه محتوى و مواصفة قيمة واحد و تصميم. لا يوجد UI عرض طريقة أداة سوف رجوع إلى عام بطاقة (عنوان = أداة اسم، أصلي args بصفة إدخال).

اثنان عدد طريقة كل إرجاع واحد **`card` وسم تصيير معنى رسم**——اختيار و أنت أداة سلوك مطابقة بطاقة نوع:

- `presentCall(args)` → واحد `ToolCallView`(PENDING بطاقة):
  - `{ card: 'generic', title, kind?, rawInput?, content?, locations? }`——افتراضي. ضبط `kind` نيل أخذ رسم علامة (`read`/`search`/…) ؛ ضبط `locations: [{ path, line? }]` علامة ملاحظة أداة تعلق و ملف، جعل لديه قدرة تحرير جهاز تتبع مع/قفز تحويل.
  - `{ card: 'terminal', title, description?, cwd? }`——أنت استدعاء ذاته حينئذ هو shell أمر.`title` هو أمر،`description` تصيير في طرفية بطاقة فوق جهة.(tool-bash.)
  - `{ card: 'diff', title, diffs, locations? }`——أنت استدعاء إنشاء أو تعديل ملف.`diffs: [{ path, oldText, newText }]`(جديد ملف وقت `oldText: null`) تصيير لـ داخل ربط diff بطاقة.(tool-fs `write`/`edit`.)
- `presentResult(args, { content, isError, meta? })` إرجاع إتمام بعد بطاقة:
  - `generic` توفير اختياري عنوان و محتوى.
  - `terminal` توفير أصلي إخراج و اختياري خروج بيانات وصفية؛ كل UI أصل حسب ذاته قدرة تصيير مقابل عرض أو رجوع عرض.
  - `diff` توفير قد تطبيق hunk، عبر معتاد من `output.presentationMeta` إرسال توليد و عبر حفظ دائم `result.meta` يحمل، جعل إعادة تشغيل قدرة إعادة الآن هو جمع. تغيير صنف أداة إبقاء diff نتيجة، لأن إتمام بعد عرض سوف استبدال pending بطاقة.
  - `read` توفير من حفظ دائم `result.meta` إعادة بناء قد إتمام ملف نافذة: ملف `path`، من 1 بدء `offset`، إرجاع `lines`(كل سطر إبقاء ذلك ملف سطر رقم) ،`totalLines`، و اختياري `lang` عال مضيء تلميح؛ لا أداة تجهيز `read` قدرة UI رجوع إلى أصلي نتيجة محتوى. لا يوجد `read` استدعاء عرض——قراءة استدعاء pending حالة إبقاء لـ generic بطاقة، لأن محتوى فقط في `execute` بعد عندئذ وجود.(tool-fs `read`.)
  - `search` توفير من حفظ دائم `result.meta` إعادة بناء اكتشاف نوع نتيجة: حسب ملف قسم مجموعة مطابقة (`shape: 'matches'`،grep) أو مسطح مستو مسار قائمة (`shape: 'paths'`،glob) ، خارج إضافة `truncated`/`total` جعل UI دائم لا يأخذ يتم قطع قطع نتيجة عند عمل كامل نتيجة عرض. هذا عرض لا يحمل نتيجة نص (بلا search بطاقة UI رجوع إلى أصلي نتيجة محتوى) ، أيضا لا يوجد `search` استدعاء عرض——اكتشاف نوع استدعاء pending حالة إبقاء لـ generic بطاقة، لأن مطابقة فقط في `execute` بعد عندئذ وجود.(tool-fs-search `grep`/`glob`.)
  - `web` توفير قد إتمام web فحص بحث، بـ `kind: 'search' | 'fetch'` منطقة قسم (بنية تحويل بحث مصدر أو إمساك أخذ ملخص) ، من `result.meta` إرسال توليد؛ هو لا يحمل متن فرعي هذا، لذلك لا أداة تجهيز `web` قدرة UI رجوع إلى أصلي نتيجة محتوى.(tool-web `web_search`/`web_fetch`.)

صلب صفة قاعدة (مخالفة عكس سوف خروج مشكلة):

- **صاف دالة.** هذه طريقة في فوري تدفق صيغة إخراج و جلسة سجل إعادة تشغيل وقت كل سوف تشغيل، لذلك يجب هو `args`(إضافة result) صاف دالة——لا فعل I/O، لا قراءة جلسة حالة، لا استخدام وقت ساعة/مع آلة عدد.diff من args إرسال توليد (`write` استخدام `oldText: null`، لأن استدعاء وقت عرض جهاز لا يوجد ملف أولا قبل محتوى) ؛ جلسة سياق من UI مهايئ بينما غير أداة توفير. إذا أنت اكتشاف ذاتي ذات تفكير في `presentCall` داخل نيل أخذ ملف قديم محتوى أو عمل دليل، طلب توقف تحت: ذلك يخص حمل دائم نتيجة بيانات وصفية أو مهايئ، لا يخص عرض جهاز.
- **UI صيغة لا دخول نموذج نتيجة.** محيط شريط ` ```console ` كتلة،diff، متبادل مقابل تحويل مسار متساو لا ينبغي فقط لـ خدمة UI بينما دخول مواصفة قيمة أو Native محتوى.`output.render` مسؤول نموذج مرئي ذاتي لكن لغة؛`presentationMeta` و بطاقة عرض جهاز مسؤول يمكن إعادة تشغيل UI حالة.`terminal` نتيجة عرض يحمل أصلي إخراج، من مهايئ حسب يحتاج إضافة رجوع صيغة.
- **`defineTool` مقابل عرض مسار فعل لين تحقق.** صيغة خطأ أو قديم إصدار سجل في معامل سوف جعل حزمة تركيب جهاز إرجاع `undefined`(عام رجوع) بينما غير رمي استثناء——عرض أبدا قدرة توجيه يؤدي إعادة تشغيل انهيار انهيار.

في صفة مفردات تعريف في `dsh-tools` في؛ أداة أبدا استيراد UI أو نقل نوع. استخدام هذا API مستهلك يأخذ كل `card` خريطة إلى ذاتي ذات عرض. تصميم و سبب رؤية[تصيير معنى رسم ربط دمج جسم Agent Note](../../.agents/notes/implemented/architecture/2026-07-02-tool-render-intent-union.zh.md) ؛`dsh-tool-fs`(generic/diff) و `dsh-tool-bash`(terminal) هو مشاركة اعتبار تنفيذ.

## Web Client عرض

داخل وضع Web Client لا إزالة استهلاك `presentCall` أو `presentResult`.Session `page` و `follow` تشغيل نقل أصلي `tool/call` و `tool/result` حدث، يشمل حفظ دائم `result.meta`.Client إضافة في keyed slot `tool.call.toolview` في تسجيل ذاتي ذات wire أداة اسم، و من `ToolCallBlock` معامل، محتوى، خطأ،metadata، قائم PTC dispatch `parentCallId` و Session مسار واقع إرسال توليد مكون props. إضافة في محلي تحقق هذه wire قيمة، و يجعل صيغة خطأ أو لا تلقي دعم حمل إدخال رجوع إلى generic سطر.

قائم Web بطاقة حاجة نموذج مرئي محتوى لا يمكن بلا ضرر حفظ محدود بنية تحويل نتيجة واقع وقت، استخدام `output.presentationMeta(args, value)`. لا يلزم في metadata في حفظ React props أو مسبق اختيار بطاقة، لا يلزم يأخذ Host أداة تنفيذ استيراد متصفح bundle، أيضا لا يلزم بناء قيام آخر طقم Client presenter registry. فقط تعريف Host عرض طريقة لن زيادة مخصص استخدام Web بطاقة.[Client إرسال توليد عرض Agent Note](../../.agents/notes/implemented/architecture/2026-08-23-client-derived-tool-presentation.zh.md) قاعدة تحديد owner،fallback و مقابل انتظار اشتراط.
