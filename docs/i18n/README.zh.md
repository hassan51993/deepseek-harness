# مزدوج لغة وثيقة

[English](README.md) | العربية

هذا مستودع وثيقة سوف يتم عام شركة داخل خارج شخص و agent(ذكي جسم) قراءة قراءة، لذلك نطاق داخل كل مقالة وثيقة كل بـ إنجليزي نص و بسيط جسم العربية صيانة. هذا صفحة تعريف إعداد مقابل اتفاق، فحص، نطاق و ترتيب حذف قاعدة؛[translation-rules.md](translation-rules.zh.md) تعريف مثل أي قلب ترجمة؛[terminology.md](terminology.md) هو فن لغة حق مصدر.agent يوم معتاد عمل التزام دوران [docs/AGENTS.md](../AGENTS.md) في خفيف كمية مسار؛ توسيع إصدار [.agents/skills/dsh-translate-docs](../../.agents/skills/dsh-translate-docs/SKILL.md) سير العمل فقط في مستخدم صريح استدعاء وقت متاح.

## إعداد مقابل اتفاق

- **اثنان نوع لغة نفس حق.** واحد مقالة وثيقة يمكن أولا استخدام مهمة واحد لغة تأليف كتابة و مراجعة (أولا كتابة العربية Agent Note و أولا كتابة إنجليزي نص واحد مثال صحيح عند) ، آخر جانب من هو قلب ترجمة بينما قدوم. اثنان عدد ملف من أيضا لا عال في من؛ قيد هو جمع هو اثنان من يجب قول نفس مثال كلام.
- **واحد مقابل وثيقة هو ثلاثة عدد نفس دليل ملف.** إنجليزي نص `foo.md`، العربية `foo.zh.md`، إضافة واحد نسخة متسق صفة سجل `foo.i18n.yaml`، كل في نفس دليل. لا استخدام لغة دليل، لا استخدام مستقل قلب ترجمة مستودع، لا استخدام في إنجليزي خلط ترتيب مفرد ملف. إعداد مقابل يجب كامل جسم دمج:PR(Pull Request) دائم بعيد لن فقط حمل واحد نوع لغة بينما نقص ذلك بقية اثنان عدد ملف.
- **متسق صفة سجل.**`foo.i18n.yaml` حفظ اثنان جانب ملف في فوق مرة يتم تأكيد «قول نفس مثال كلام» وقت كل منها كامل Git blob hash:

  ```yaml
  foo.md: 3f786850e387550fdab836ed7e6dc881de23001b
  foo.zh.md: 89e6c98d92887913cadf06b2adb97f26cde4849b
  ```

  استخدام blob hash بينما لا هو commit hash، هذا مثال نفس عدد PR داخل تعديل ملف أيضا قدرة حساب خروج سجل (`git hash-object foo.md`) ، متسق صفة هو صاف محتوى مقارنة مقارنة.`--write` سوف أولا يأخذ هذه لقطة تخزين دخول محلي Git كائن مكتبة مجددا كتابة تحت سجل، لم إيداع worktree محتوى أيضا لا مثال خارج؛ هو أيضا سوف في محتوى بحث عنوان `refs/dsh/translation-pairing/snapshots/` ref تحت ثابت كل مختلف قد تخزين blob، جعل نفاية قمامة عودة استلام لا يمكن يجعل قد سجل استعادة إشارة إبرة بطلان. سجل hash قدرة أيضا أصل مهمة واحد جانب فوق مرة تأكيد وقت تأكيد قطع نص، الذي بـ فقد ذهاب تزامن إعداد مقابل هو «حسب يتم تعديل واحد جانب diff الأكثر صغير تحويل أرض إصلاح تكملة آخر جانب» ، من لا كامل مقالة إعادة ترجمة. يوم معتاد عمل سوف مباشر إتمام هذا نسخة إصلاح تكملة؛ مستخدم صريح استدعاء توسيع سير العمل وقت، يمكن تعديل من `pnpm run gen-translation-brief <pair>` بـ قدرة أمان مقابل متساو الأكثر ضيق حبة درجة تجميع تجميع هذا مرة تحديث، و من `--apply` في بنية تحقق بعد تجميع وصل فقط تعلق و محيط شريط شفرة كتلة تعديل. اثنان جانب مقابل متساو بعد،`pnpm run verify-translation-pairing --write <pair>` إعادة سجل اثنان عدد hash؛ ذلك نسخة YAML diff حينئذ هو «تأكيد متسق» هذا عدد حركة عمل ذاته، يمكن يتم مراجعة، أيضا صحيح بسبب مثل هذا،`--write` اشتراط نقطة اسم أنت تأكيد مرور إعداد مقابل (`--write --all` هو صريح كل لغة مادة شكل صيغة).

  عند اثنان عدد فرع كل يتضمن نفس إعداد مقابل صالح تأكيد وقت، قد تثبيت `dsh-translation-pairing` Git دمج قيادة فقط سوف في Git افتراضي نص دمج قدرة قسم آخر جاف صاف دمج سجل الذي إشارة نحو إنجليزي نص ثلاثة جهة blob و العربية ثلاثة جهة blob، كما دمج بعد إعداد مقابل ما زال إبقاء مطلوب لغة تبديل سطر و بنية توقيع وقت، تركيب خروج واحد نسخة جديد سجل. العربية ملف يجب إبقاء إشارة نحو إنجليزي نص عكس نحو رابط؛ عادي تأليف كتابة إنجليزي نص مصدر يجب إبقاء إشارة نحو العربية رابط، بينما بيان داخل توليد إنجليزي نص مصدر لا عمل هذا اشتراط. أي دمج قيادة لا يمكن تحقق بنية كل إبقاء لـ عادي اندفاع مفاجئ؛`pnpm run resolve-translation-pairing-conflicts` سوف مقابل قد إيقاف دمج تنفيذ نفس طقم لقاء خطأ أي إبقاء اندفاع مفاجئ عملية، مؤقت تخزين كل نسخة يمكن أمان توليد إعداد مقابل سجل، و في أيضا لديه أخرى إعداد مقابل اندفاع مفاجئ وقت بـ غير صفر حالة خروج.[تلقائي إعداد مقابل دمج Agent Note](../../.agents/notes/implemented/process/2026-08-08-automatic-translation-pairing-merges.zh.md) مسؤول سجل هذا آلية و تجهيز اختيار خطة.
- **لغة تبديل سطر.** العربية ملف واحد قاعدة في H1 عنوان بعد قيام أي بـ `[English](foo.md) | العربية` سلسلة عودة إنجليزي نص. عادي تأليف كتابة إنجليزي نص ملف في نفس موضع بـ `English | [العربية](foo.zh.md)` متبادل سلسلة؛ بيان داخل توليد إنجليزي نص مصدر حذف هذا سطر، بـ سهل و توليد جهاز إخراج تدريجي بايت متسق. إصدار إلى GitHub بـ خارج موضع README(مثال مثل PyPI مشروع بيانات وصفية) يمكن تعديل استخدام إشارة نحو نفس مقابل جانب ملف مواصفة `https://github.com/deepseek-ai/deepseek-harness/blob/master/<repository-path>` URL، جعل تبديل سطر في هذا موضع ما زال يمكن وصول.
- **بنية و آخر جانب واحد واحد مقابل.** عنوان عميق درجة و ترتيب، قائمة نوع، لديه تسلسل جدول بدء بداية تحرير رقم، قائمة بند عدد كمية، جدول إطار سطر صف عدد، إبقاء أصل مثال query/fragment بعد لاحقة دلالة رابط هدف، و تدريجي بايت متسق شفرة كتلة في إعداد مقابل اثنان جانب واحد واحد مقابل. متبادل مقابل وثيقة رابط هدف يخص نشط وثب مزدوج لغة لغة مادة وقت، إنجليزي نص جانب استخدام ذلك `.md` مسار، العربية جانب استخدام ذلك `.zh.md` مسار. هذا نطاق داخل نقص قليل مقابل جانب يخص إعداد مقابل كامل صفة خطأ، لا نيل رجوع؛ نطاق خارج هدف إبقاء أصل مسار. كامل إبقاء قاعدة رؤية [translation-rules.md](translation-rules.zh.md). قائم Markdown بوابة مقابل `.zh.md` ملف أصل مثال توليد فاعلية (`verify-md-wrap`،`verify-md-links`).

## بوابة:verify-translation-pairing

`pnpm run verify-translation-pairing`(`doc-sync`(وثيقة تزامن بوابة) واحد حلقة، مساهمة من سوف إبرة مقابل وثيقة تغيير في محلي تشغيل،CI فإن سوف كامل تشغيل) آلة آلة أرض قوي صنع تنفيذ هذا نسخة اتفاق:

1. نطاق داخل كل مقالة وثيقة كل لديه كامل إعداد مقابل. اكتشاف README وقت،basename لا منطقة قسم كبير صغير كتابة، لذلك `missions/readme.md` و أخرى وثيقة أصل واحد مثال يخص نطاق.
2. أي قد وجود إعداد مقابل ناتج كل كامل كما متسق: ثلاثة عدد ملف متساو كل، كل واحد جانب حالي blob hash انتظار في سجل قيمة (تعديل مهمة واحد جانب بينما لا إعادة تأكيد إعداد مقابل حينئذ تغيير أحمر) ، العربية جانب و كل عادي تأليف كتابة إنجليزي نص مصدر كل حمل لغة تبديل سطر (بيان داخل توليد إنجليزي نص مصدر حذف خارج) ، كل بند عادي متبادل مقابل وثيقة رابط كل استخدام مصدر ملف واحد جانب مقابل هدف locale، كما بنية توقيع حسب ترتيب متسق: عنوان عميق درجة، تدريجي بايت متسق شفرة كتلة (معلومة نص و محتوى) ، جدول إطار سطر صف عدد، قائمة نوع، لديه تسلسل جدول بدء بداية تحرير رقم، قائمة بند عدد كمية، و حذف تبديل سطر خارج إبقاء أصل مثال query/fragment بعد لاحقة دلالة رابط هدف.
3. صف لـ `excluded` ملف تماما لا يوجد `.zh.md`، أيضا لا يوجد `.i18n.yaml`.`.agents/notes/archived/` تحت تجميد ربط Agent Note لا تلقي هذا عدد حمل متابعة عرض دخول بوابة قيد؛ مخصص استخدام تحقق جهاز سوف اشتراط ذلك قائم ثلاثة عدد إعداد مقابل ملف كامل، و سوف ذلك غلاف تخزين.

موجه إلى شفرة المصدر شفرة بوابة سوف يأخذ دقيق `.zh.md` محيط شريط تسلسل نظر لـ ذلك بلا بعد لاحقة أخ أخ ملف إرسال توليد محتوى، بينما لن مجددا مرة تحرير ترجمة نفسه شفرة أو في manifest(بيانات وصفية بيان) في تكرار تسجيل تسجيل. هذا تسلسل يجب في طويل درجة، ترتيب، محيط شريط نوع و حسب بايت دقيق متن فوق متسق؛ لا فإن اثنان نسخة فرعي هذا ما زال سوف مستقل تلقي فحص، إعداد مقابل بوابة أيضا سوف تقرير إبلاغ بنية لا مطابقة.

`pnpm run verify-translation-pairing --list` ضرب طبع نطاق داخل كل مقالة وثيقة حالي إعداد مقابل حالة (missing،out-of-sync أو ok). هو من لا فشل؛ منها `missing` و `out-of-sync` سطر إشارة خروج عادي فحص سوف رفض مخالفة قاعدة.

`pnpm run verify-translation-pairing <pair...>` فقط فحص يتم نقطة اسم إعداد مقابل——إعداد مقابل ثلاثة عدد ملف في مهمة معنى واحد (أو ذلك عار كلمة جاف) كل قدرة نقطة اسم هو——لذلك تحديث حلقة بضعة ثانية داخل حينئذ قدرة تحقق ذاتي ذات إعداد مقابل، بينما لا لا بد إعادة مسح كل لغة مادة.`doc-sync` و CI تشغيل هو بلا معامل كل لغة مادة شكل صيغة؛ حد تحديد نطاق أخضر مصباح في PR طبقة وجه دائم بعيد لا يستطيع بديل هو.

هذا عدد بوابة حمل قدوم فعلي قاعدة هو:**عند واحد PR تعديل قد إعداد مقابل وثيقة مهمة واحد جانب وقت، نفس عدد PR في فن لغة إشارة توجيه تحت مباشر مرة إتمام مقابل جانب ملف تحديث، و استخدام `--write <pair>` إعادة سجل إعداد مقابل**، و هذا مستودع قائم شفرة و README doc-sync قاعدة تماما متسق. إبقاء تحت فقد ذهاب تزامن إعداد مقابل PR سوف في CI تغيير أحمر.

بوابة حد جدا واضح:**بوابة عبر معنى طعم حال هذا مجموعة وثيقة في حالي محتوى فوق متسق صفة نيل إلى تأكيد، لا بديل جدول تأكيد ذاته صحيح تأكيد يمكن اعتماد.** هو فحص سجل hash و Markdown بنية؛ هو لا يمكن حكم قطع اثنان جانب هل في قول نفس مثال كلام، أيضا لا يمكن حكم قطع إجراء لفظ هل دقيق تأكيد، فن لغة هل نيل عند، سطر نص هل ذاتي لكن؛ هذا جزء اتفاق من مراجعة من يأخذ صلة، رؤية [translation-rules.md](translation-rules.zh.md). إعادة سجل hash لكن آخر جانب قلب نيل إهمال مسودة إعداد مقابل قدرة عبر بوابة؛ هو لا نيل عبر مراجعة.

## نطاق و ترتيب حذف

**نطاق**: أصل دليل `CONTRIBUTING.md`،`BRAND_GUIDELINES.md` و `SAFETY.md` وثيقة، حذف vendor شفرة المصدر خارج الكل README، و `.agents/notes/**`،`docs/**` و `python/**` تحت الكل نشط وثب وثيقة. مطابقة README وقت فقط نظر ملف اسم كما لا منطقة قسم كبير صغير كتابة، لذلك اليوم بعد إضافة جديدة دليل بلا حاجة مجددا تعديل manifest. اعتماد دليل، يتم تجاهل اختصار بناء ناتج دليل و تجميد ربط `.agents/notes/archived/` دليل شجرة فقط في اكتشاف مرحلة مقطع ترتيب حذف، لا يخص حمل متابعة عرض دخول قلب ترجمة مصدر وثيقة.

لديه مرور مراجعة العربية مقابل جانب توليد إنجليزي نص مشاركة اعتبار وثيقة و رسم وثيقة التزام دوران إعداد مقابل قاعدة. توليد جهاز فقط مسؤول إنجليزي نص وقت، هو ما زال هو هذا لغة حق مصدر؛ إعادة توليد توجيه يؤدي إنجليزي نص تغير بعد، إعداد مقابل سوف إبقاء فقد ذهاب تزامن حالة، مباشر حتى مرور مراجعة العربية مقابل جانب إتمام تحديث و إعادة سجل. جديد طازج درجة بوابة و إعداد مقابل بوابة كل منها مستقل قوي صنع ذلك قيد.

مشترك توليد منطقة مجال (مثال مثل Cordis فرعي نظام منطقة مجال) في اثنان نوع لغة بين إبقاء كل توليد بايت نفسه، فقط إعداد مقابل وثيقة مسار حسب لغة محلي تحويل. كامل صفحة توليد جهاز فإن يمكن من نفسه بنية بيانات تصيير شفرة المصدر صيانة مزدوج لغة شرح، مثال مثل [persistence-catalog-text.ts](../../scripts/persistence-catalog-text.ts) ، و إبقاء Markdown بنية مقابل، شفرة كتلة تماما نفسه. هو معا إعادة توليد اثنان صفحة و ذلك متسق صفة سجل؛ مراجعة ما زال يجب تحقق مزدوج لغة شرح يحتوي معنى و فن لغة.

توليد إنجليزي نص مصدر ملف لا يحتوي عادي تأليف كتابة وثيقة الذي حمل لغة تبديل سطر، لأن إضافة هذا سطر سوف جعل توليد جهاز جديد طازج درجة فحص فشل؛ العربية مقابل جانب ما زال رابط عودة إنجليزي نص مصدر. شخص عمل صيانة العربية مقابل جانب فقط قدرة تعديل كتابة إذا مباشر ترجمة سهل لم يعد رمز دمج مرور مراجعة ترجمة نص واقع ذاتي إشارة توليد و صيانة شرح؛ كل تقنية فن محتوى ما زال تلقي عادي وفي فعلي صفة قاعدة قيد.

**ترتيب حذف**(دائم لا إعداد مقابل، بوابة رفض لـ هو جمع بناء `.zh.md` أو `.i18n.yaml`):

- [cordis-api/inherited.md](../cordis-api/inherited.md): هذا توليد وثيقة لا يوجد مرور مراجعة العربية مقابل جانب، لذلك شبكة محطة اثنان عدد locale كل إسقاط إنجليزي نص مصدر ملف.
- `docs/AGENTS.md`،`.agents/notes/**/AGENTS.md` و إشارة نحو هو جمع `CLAUDE.md` إشارة أمر رمز رقم رابط:agent إشارة أمر، و أصل `AGENTS.md` واحد مثال فقط بـ إنجليزي نص صيانة.
- `docs/i18n/terminology.md` و [style-samples.md](style-samples.md): اثنان من ذاته أي لـ في إنجليزي مقابل وفق وثيقة.
- [translation-prompt.md](translation-prompt.md): تلقائي قلب ترجمة خط الإنتاج نص التوجيه نموذج لوح؛ متن تدريجي حرف دخول نموذج طلب، إعداد مقابل قلب ترجمة سوف تغيير خط الإنتاج سلوك.
- [review-ownership/README.md](../../.github/review-ownership/README.md): مستودع داخلي مراجعة دفعة سياسة، فقط بـ إنجليزي نص صيانة.
- `.agents/notes/archived/`: تجميد ربط تاريخ ثلاثة ملف إعداد مقابل.[`verify-archived-agent-notes`](../../scripts/verify-archived-agent-notes.ts) تحقق ذلك كامل صفة و محتوى غلاف تخزين سجل؛ قلب ترجمة صيانة أبدا قدرة إعادة كتابة هذه ملف.

**موحد واحد اشتراط**: حالي و اليوم بعد قبول دخول نطاق كل مقالة وثيقة، دمج وقت كل يجب بنية صار كامل مزدوج لغة إعداد مقابل.[scripts/translation-pairing.manifest.json](../../scripts/translation-pairing.manifest.json) فقط يتضمن صريح ترتيب حذف بند؛ لا وجود تدريجي ملف دفع دخول بيان، يوم مدة قسم حد أو README مخصص استخدام سياسة سياسة صنف آخر.

## قسم عمل

يوم معتاد تحديث مقابل جانب ملف وقت، مسؤول معالجة agent سوف أولا تحميل [terminology.md](terminology.md) ، مجددا مباشر مرة صفة تحديث؛ هو لن استدعاء قلب ترجمة skill(تقنية قدرة) ، توليد بسيط تقرير، تنفيذ مفرد وحيد قلب ترجمة مراجعة جولة، أيضا لن تفويض إرسال إعطاء subagent. توسيع إصدار [dsh-translate-docs](../../.agents/skills/dsh-translate-docs/SKILL.md) سير العمل إبقاء هذه مقارنة إعادة آلية، فقط توفير مستخدم صريح استدعاء. بوابة مسؤول فحص إعداد مقابل هل كامل، سجل hash، العربية عكس نحو رابط و عادي تأليف كتابة مصدر تبديل سطر (توليد مصدر حسب هذا نص قاعدة مثال خارج) ، و هذا نص صف خروج بنية توقيع؛ قلب ترجمة جودة كمية، فن لغة و توقيع لم شمول غطاء بنية اشتراط ما زال من مراجعة يأخذ صلة. نص التوجيه اتفاق أيضا لديه يمكن تنفيذ تنفيذ:[scripts/translation-prompt.ts](../../scripts/translation-prompt.ts) سوف يأخذ مستودع داخل وضع نموذج لوح (حقن فن لغة جدول؛ نموذج لوح ذاتي حمل مرور شخص عمل تدقيق دقيق قاعدة) تصيير لـ إنجليزي ترجمة في أو في ترجمة إنجليزي اثنان عدد جهة نحو نص التوجيه، و تحليل ثلاثة مقطع صيغة استجابة؛`doc-sync` في `verify-translation-prompt` سوف فحص اثنان عدد تصيير جهة نحو و مستودع داخل عرض مثال.
