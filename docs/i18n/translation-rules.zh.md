# قلب ترجمة قاعدة

[English](translation-rules.md) | العربية

هذا نص قاعدة تحديد: مثل أي في هذا مستودع وثيقة إعداد مقابل في إنجليزي نص اثنان نوع لغة بين إجراء قلب ترجمة. اثنان نوع لغة نفس حق (رؤية [README.md](README.zh.md)): كل مرة تغيير يمكن استخدام مهمة واحد لغة تأليف كتابة، يتم تحرير واحد جانب أي لـ هذا مرة تحديث مصدر؛ هذا نص قاعدة قيد مثل أي إنتاج خروج أو تحديث مقابل جانب ملف. هذه قاعدة مقابل شخص صنف و agent(ذكي جسم) نفس انتظار توليد فاعلية. يوم معتاد عمل في،agent سوف في فن لغة إشارة توجيه تحت مباشر مرة إتمام لديه تعديل محتوى قلب ترجمة؛ توسيع إصدار [.agents/skills/dsh-translate-docs](../../.agents/skills/dsh-translate-docs/SKILL.md) سير العمل فقط في مستخدم صريح استدعاء وقت تشغيل. قاعدة درجة آخر امتداد استخدام RFC 2119 استخدام قاعدة:**يجب (MUST)** / **منع توقف (MUST NOT)** سوف بطاقة بوابة أو مراجعة؛**ينبغي عند (SHOULD)** انحراف مغادرة وقت يلزم شرح إدارة من؛**يمكن (MAY)** ذاتي سطر قطع كمية.

## وفي فعلي صفة

- مقابل جانب ملف*يجب*نقل بلوغ و تأليف كتابة جانب نفسه محتوى: لا إضافة سلوك، قبل وضع شرط، تحذير إبلاغ، إصدار إعلان أو عرض مثال، أيضا لا تسرب إسقاط أي واحد بند. إذا اثنان جانب في فعلي جودة محتوى فوق لا متسق، لا يوجد أي نوع لغة افتراضي نيل فوز؛ طلب إصلاح صحيح خطأ واحد جانب، و في نفس عدد تغيير داخل تزامن تحديث آخر جانب.
- مقابل جانب ملف قراءة بدء قدوم*ينبغي عند*هو ذلك لغة ذاتي لكن تقنية فن نص حرف، بينما غير تدريجي كلمة مقابل وفق ترجمة نص. طلب أصل حسب دلالة قلب ترجمة، في هدف لغة لغة قاعدة حاجة وقت إعادة مجموعة جملة فرعي، و إبقاء أصل عمل من لغة مجال (مقارنة مثل: بسيط تدريب إبقاء بسيط تدريب).
- لا يلزم قلب ترجمة غير ممكن ترجمة محتوى: إذا واحد جملة كلام اعتماد مصدر لغة تعود لغة، لا يمكن ذاتي لكن تحويل، طلب قلب ترجمة هو معنى تفكير، بينما غير تعود لغة ذاته.

## سطر نص

- لغة جسم بـ [style-samples.md](style-samples.md) لـ تدقيق دقيق مرساة نقطة. شخص عمل تحديد مسودة ذهب علامة مثال مثال حسب نص جسم كل واحد مجموعة، ترجمة نص يجب مشاركة وفق نص جسم الأكثر وصل قريب مثال مثال، اعتماد منها هدف لغة واحد جانب لغة جسم؛ إذا مثال مثال و هذا نص سطر نص قاعدة اندفاع مفاجئ، بـ مثال مثال لـ دقيق. ترجمة صار العربية وقت، اعتماد مواصفة تقنية فن صنع درجة نص؛ ترجمة صار إنجليزي نص وقت، اعتماد بسيط نظيف، مخصص عمل تطوير من وثيقة لغة جسم.
- بـ أم لغة تقنية فن عمل من هوية إعادة وصف محتوى، بينما لا هو بـ ترجمة من هوية تدريجي جملة تحويل كتابة، معا إبقاء أصل نص كل دلالة صار قسم: لا إضافة، لا متروك تسرب——تدفق سلس دائم بعيد لا هو فقد إسقاط دلالة صار قسم إدارة من.
- إذا مباشر ترجمة سوف يجعل تنفيذ رئيسي جسم يحتوي غامض، طلب واضح كتابة خروج فعلي تنفيذ من؛ ترجمة صار العربية وقت، ينبغي من «نظام، بوابة، مراجعة شخص» انتظار فعلي تنفيذ من عمل رئيسي لغة، تجنب تجنب يحتوي غامض يتم حركة جملة أو سحب كائن رئيسي لغة.
- أولوية اعتماد هدف لغة في عبر سطر عمل مسار جدول بلوغ، تجنب تجنب توليد صلب مباشر ترجمة (false positive/negative→خطأ تقرير/تسرب فحص،enforcement frontier→تنفيذ أحمر خط) ؛ خفي تشبيه ينبغي ذاتي لكن تعديل كتابة، اسم كلمة سلسلة فإن حسب هدف لغة تعود معتاد تفكيك فتح.
- طويل مقطع حسب دلالة وحدة تفكيك قسم، واحد مقطع واحد عنصر أمر. مقطع سقوط حد يمكن و أصل نص مختلف؛ بنية توقيع لا مقارنة مقابل مقطع سقوط عدد.
- قلب ترجمة لـ العربية وقت، صنف آخر اسم كلمة استخدام العربية و في أول الآن تضمين ملاحظة إنجليزي نص (فعلي تشغيل يد سجل (cookbook)) ؛ قلب ترجمة لـ إنجليزي نص وقت، استخدام عبر سطر إنجليزي نص صنف آخر اسم. إشارة دليل أو ملف ذاته وقت إبقاء شفرة جسم إنجليزي نص.

## بنية إبقاء

إعداد مقابل بوابة سوف فحص عنوان عميق درجة، محيط شريط شفرة كتلة، جدول إطار سطر صف عدد، قائمة نوع، لديه تسلسل جدول بدء بداية تحرير رقم، قائمة بند عدد كمية، رابط locale و دلالة هدف؛ بوابة لم تغطية بنية ما زال يحتاج شخص عمل نواة مقابل. اثنان عدد إعداد مقابل ملف يجب في التالي جهة وجه واحد واحد مقابل:

- عنوان طبقة درجة (نفسه درجة آخر، نفسه ترتيب؛ عنوان**نص حرف**يلزم قلب ترجمة) ؛
- قائمة شكل و تحرير رقم؛
- جدول إطار (نفسه صف، نفسه سطر ترتيب؛ جدول رأس وحدة إطار حسب فن لغة جدول قلب ترجمة) ؛
- محيط شريط شفرة كتلة:**تدريجي بايت متسق، يشمل ملاحظة تفسير**. إعداد مقابل توقيع مقارنة مقابل معلومة نص و محتوى،` ```ts ` كتلة أيضا يلزم عبر `doc-typecheck` تحرير ترجمة؛
- سطر داخل شفرة (أمر،flag، إعداد مفتاح، ملف مسار، حدث اسم،API اسم، رقم الإصدار): أصل مثال إبقاء، من لا قلب ترجمة أو إعادة ترتيب؛
- رابط و مرساة نقطة: كل متبادل مقابل وثيقة رابط يجب إبقاء نفسه دلالة هدف و تماما نفسه query/fragment بعد لاحقة. هدف يخص نشط وثب مزدوج لغة لغة مادة وقت، إنجليزي نص جانب استخدام ذلك `.md` مسار، العربية جانب استخدام ذلك `.zh.md` مسار؛ هذا نطاق داخل نقص قليل مقابل جانب يخص خطأ، نطاق خارج هدف إبقاء أصل مسار. خارجي URL، صورة و صاف صفحة داخل fragment إبقاء ثابت. لغة تبديل سطر ما زال هو صريح عبر locale مثال خارج؛ في GitHub بـ خارج موضع تصيير README يمكن حسب [README.md](README.zh.md) قاعدة تحديد، استخدام إشارة نحو تأكيد قطع مقابل جانب ملف مواصفة عام مستودع URL. رابط**نص حرف**قلب ترجمة.

هذا مستودع Markdown اتفاق مقابل `.zh.md` ملف أصل مثال توليد فاعلية: واحد مقطع سقوط واحد شيء إدارة سطر (`verify-md-wrap`) ، متبادل مقابل رابط يجب يمكن تحليل (`verify-md-links`) ، ملف نهاية ذيل تماما جيد واحد تبديل سطر.

## فن لغة

- [terminology.md](terminology.md) هو مزدوج نحو فن لغة حق مصدر. قلب ترجمة قبل طلب أولا تحميل هو؛ جدول داخل فن لغة يجب التزام حراسة مقابل سطر و «لا يلزم ترجمة عمل» منع بند. ترجمة صار العربية وقت، اعتماد «العربية» صف، و حسب «أول مرة ظهور» صف تضمين ملاحظة؛ ترجمة صار إنجليزي نص وقت، اعتماد «English» صف، لا إضافة العربية تضمين ملاحظة.
- ترجمة صار العربية وقت، فن لغة جدول لم استلام تسجيل تقنية فن فن لغة فقط لديه في رئيسي تدفق العربية OSS وثيقة أو مصنع تجارة مورد مادة في قد لديه عبر سطر ترجمة قاعدة وقت عندئذ يمكن قلب ترجمة (K8s/Vue/MDN العربية وثيقة، دقيق لين بسيط في ريح إطار إشارة جنوب، كبير مصنع مشروع وثيقة) ، و يجب في PR في ملاحظة واضح خروج موضع؛ لا فإن يجب إبقاء إنجليزي نص، و في PR وصف «انتظار تحديد فن لغة» في إعطاء خروج بناء اقتراح ترجمة قاعدة.
- ترجمة صار إنجليزي نص وقت، اعتماد عبر سطر إنجليزي نص تقنية فن فن لغة. إذا مصدر فن لغة لا يوجد واضح عبر سطر مقابل كلمة، فإن إبقاء أصل كلمة، مرفق فوق بسيط قصير شرح، و صف دخول «انتظار تحديد فن لغة». اثنان عدد جهة نحو كل لا نيل ذاتي سطر إنشاء صنع ترجمة قاعدة؛ تحديد بعد فن لغة يجب في نفس عدد PR أو لاحق PR في إضافة دخول [terminology.md](terminology.md).

## ترتيب إصدار

هذا عقدة قاعدة قيد العربية واحد جانب؛ إنجليزي نص واحد جانب التزام دوران مستودع معتاد قاعدة Markdown اتفاق (أصل `AGENTS.md`). التالي في غرب نص خلط ترتيب قاعدة التزام دوران [MDN بسيط جسم العربية قلب ترجمة إشارة جنوب](https://github.com/mdn/translated-content/blob/main/docs/zh-cn/translation-guide.md) ،[Kubernetes العربية محلي تحويل إشارة جنوب](https://kubernetes.io/zh-cn/docs/contribute/localization_zh/) ،[Vue.js العربية قلب ترجمة يجب معرفة](https://github.com/vuejs-translations/docs-zh-cn/wiki/%E7%BF%BB%E8%AF%91%E9%A1%BB%E7%9F%A5) و[العربية نص سجل ترتيب إصدار إشارة شمال](https://github.com/sparanoid/chinese-copywriting-guidelines) عبر مشروع مشترك تعرف، ذلك أصل حسب هو [W3C clreq](https://www.w3.org/TR/clreq/) و GB/T 15834—2011:

- يجب في العربية و سحب قطعة كلمة بين، العربية و عدد حرف بين كل إبقاء واحد نصف زاوية فارغ إطار:`كل plugin تسجيل 3 عدد tool`. كل زاوية علامة نقطة و أي محرف بين لا إضافة فارغ إطار.
- العربية سطر نص يجب استخدام كل زاوية (العربية) علامة نقطة:`،.: ؛؟!()«»`. نصف زاوية علامة نقطة إبقاء في شفرة داخل، حسب أصل مثال مرجع كامل إنجليزي نص جملة فرعي داخل، و عدد حرف داخل (`3.5`،`1,024`).
- العربية سطر نص*ينبغي عند*أولوية استخدام خطر رقم، جملة رقم، فاصلة رقم أو تضمين رقم، كل كمية لا استخدام كسر طي رقم؛ فقط لديه أخرى علامة نقطة كل لا يمكن ذاتي لكن جدول بلوغ وقت عندئذ إبقاء كسر طي رقم.
- توقف رقم: العربية و صف بند بين استخدام توقف رقم (،) ، بينما غير فاصلة رقم.
- منع توقف استخدام كل زاوية عدد حرف أو كل زاوية سحب قطعة حرف أم: دائم بعيد لا كتابة `123`، دائم بعيد كتابة `123`.
- مخصص لديه اسم كلمة إبقاء مواصفة كبير صغير كتابة:GitHub،TypeScript،DeepSeek. حذف غير مرجع شفرة، لا فإن أبدا كتابة `github`/`Github`.
- ثاني شخص تسمية استخدام «أنت» ، لا استخدام «أنت»(و Vue،Kubernetes العربية اتفاق و هذا مستودع مباشر لغة هواء متسق).
- قوي ضبط علامة (`**إضافة خشن**`،`*مائل جسم*`) سقوط في و مقابل جانب نفسه نص حقل فوق. العربية لا يوجد مائل جسم، تصيير فاعلية نتيجة ممكن نظر لا خروج فرق آخر، لا يلزم استخدام جذب رقم أو أخرى تركيب زينة بديل.

## جودة كمية معيار

- واحد مقابل وثيقة إتمام معيار: واحد موضع مزدوج لغة عمل مسار معلم فقط قراءة منها مهمة واحد ملف، قدرة نيل نيل و آخر ملف قراءة من تماما نفسه معلومة (نفسه واقع، نفسه إبلاغ تحذير، نفسه لغة هواء) ، و كما لا يوجد أي كثير بقية محتوى.
- طلب تشغيل `pnpm run verify-translation-pairing` و `doc-sync` ذلك بقية بوابة. هذه بوابة سوف فحص متسق صفة سجل، تبديل سطر، عنوان عميق درجة، شفرة كتلة، جدول إطار سطر صف عدد، قائمة نوع، لديه تسلسل جدول بدء بداية تحرير رقم، قائمة بند عدد كمية، رابط و مستودع Markdown قاعدة؛ قائمة و جدول إطار ترتيب، غير معتاد قاعدة قائمة تحرير رقم، سطر داخل شفرة، قوي ضبط علامة، دلالة، فن لغة و لغة جسم فإن من شخص عمل مراجعة مسؤول.

## مشاركة اعتبار مورد مادة

هذا نص كل قاعدة مرجع مرجعي خروج موضع، توفير تفكير حل قاع طبقة اعتماد حسب شخص و agent فحص قراءة:

- [العربية نص سجل ترتيب إصدار إشارة شمال](https://github.com/sparanoid/chinese-copywriting-guidelines): في غرب نص خلط ترتيب فارغ إطار و علامة نقطة مجتمع منطقة واقع معيار.
- [MDN بسيط جسم العربية قلب ترجمة إشارة جنوب](https://github.com/mdn/translated-content/blob/main/docs/zh-cn/translation-guide.md): و هذا نص نفس شكل مستودع داخل وضع قلب ترجمة قاعدة ملف؛ فارغ إطار، علامة نقطة و فن لغة جدول فعلي ممارسة.
- [Kubernetes العربية محلي تحويل إشارة جنوب](https://kubernetes.io/zh-cn/docs/contribute/localization_zh/): الأكثر كبير العربية محلي تحويل مجموعة طابور فن لغة أول الآن و علامة نقطة فعلي ممارسة.
- [Vue.js docs-zh-cn قلب ترجمة يجب معرفة](https://github.com/vuejs-translations/docs-zh-cn/wiki/%E7%BF%BB%E8%AF%91%E9%A1%BB%E7%9F%A5): تدريجي فن لغة ترجمة/إبقاء قرار و لغة هواء.
- [zh-style-guide](https://zh-style-guide.readthedocs.io): مجتمع منطقة العربية تقنية فن وثيقة كتابة عمل مواصفة، هذا نص استعارة استخدام هو قاعدة درجة آخر تصنيف جسم نظام (و RFC 2119 صلة مفتاح كلمة قسم درجة) ؛ هو تجمع دمج GB/T 15834/15835،clreq و كل مصنع تجارة إشارة جنوب.
- [W3C clreq](https://www.w3.org/TR/clreq/) و[دقيق لين بسيط جسم العربية ريح إطار إشارة جنوب](https://learn.microsoft.com/en-us/globalization/reference/microsoft-style-guides): ترتيب إصدار تعلم و مصنع تجارة محلي تحويل صحيح صيغة أساس خط.
- GB/T 19682-2005«قلب ترجمة خدمة ترجمة نص جودة كمية اشتراط»: دولة بيت معيار؛ هذا نص «وفي فعلي صفة» و «فن لغة» اثنان عقدة سوف ذلك ثلاثة بند أساس هذا اشتراط (وفي فعلي أصل نص، فن لغة موحد واحد، سطر نص عبر ترتيب) سقوط فعلي لـ يمكن عملية قاعدة.
