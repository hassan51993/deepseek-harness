# أمان ترتيب جلسة داخل رفع تنبيه

[English](schedule.md) | العربية

هذا overlay يجعل واحد `dsh web` عملية صريح تفعيل Schedule رفع تنبيه، معا لا تغيير تسليم افتراضي Web تركيب:

```sh
dsh web --patch apps/cli/config/examples/schedule/cordis.yml
```

حالي overlay دعم حمل استخدام صحيح كامل عدد `after_seconds`، قطعا مقابل وقت `at` هدف، أو حتى قليل 300 ثانية ثابت سرعة معدل `every_seconds` بين فصل إنشاء رفع تنبيه. نموذج عبر `schedule_create`،`schedule_list` و `schedule_delete` إدارة هو جمع؛ كل نتيجة كل سوف يأخذ تسليم علامة لـ `session-local`.

تفعيل هذا overlay بعد، نجاح فتح كما وجود نشط حركة رفع تنبيه Session سوف في محادثة header في عرض فقط قراءة دليل. دليل صف خروج كامل prompt، انتظار في أو قد تجاوز مدة حالة، مفرد مرة أو دقيق تكرار دورة مدة، متصفح محلي هدف وقت و متبادل مقابل وقت. جانب حافة شريط أيضا سوف في grouped،flat و search سطر حالي متاح projection قيمة غير فارغ وقت، في عنوان بعد عرض غير ممكن تفاعل ضجة ساعة. هذه واجهة لن إنشاء، تحرير، حذف أو تأكيد رفع تنبيه؛cold Session ذاكرة مؤقتة ضجة ساعة سماح قصير مؤقت تسرب إظهار أو ناقص إبقاء.

متصفح سوف لـ كل بند نص التوجيه مرفق إضافة ذلك IANA وقت منطقة.Time-context سوف إبلاغ إبلاغ نموذج، يأخذ لم واضح حد تحديد وقت منطقة يوم مدة و وقت حل تفسير لـ هذا طلب متصفح وقت منطقة. هذا زائف ضبط فقط لأجل ذاتي لكن لغة حل تفسير:`schedule_create.at` يجب هو حمل `Z` أو عدد قيمة انحراف نقل كمية كما صارم إطار رمز دمج RFC 3339 يوم مدة وقت، أو هو حمل صريح `UTC` أو IANA Area/Location وقت منطقة `{ date, time, time_zone }`.Schedule لا إبقاء أو دفع قطع Session افتراضي وقت منطقة. صيف أمر وقت نقص فتحة سوف يتم رفض، إعادة تراكم وقت مقطع اختيار رقم واحد وقت لحظة؛ نجاح إنشاء سجل فقط إبقاء الذي نيل UTC هدف.

كل بند رفع تنبيه من أصل Session سجل يملك.live أصل Agent سوف انتظار إلى تماما idle، مجددا في هذا محادثة في ترتيب دخول واحد عادي follow-up جولة. هو أبدا سوف في طريق جذب توجيه حالي عمل، أيضا لن إضافة مستقل عودة تنفيذ أو رفع تنبيه بطاقة. إغلاق عملية أو يجعل Session إبقاء cold سوف إيقاف داخل تخزين timer، لكن لن حذف سجل؛ إعادة فتح نفس عدد Session سوف استعادة انتظار و تسليم تجاوز مدة رفع تنبيه. فحص نظر cold تاريخ لن تنشيط رفع تنبيه،fork أيضا لن وراثة أب Session رفع تنبيه.

Every رفع تنبيه بداية نهاية و ذلك إنشاء وقت لحظة مقابل متساو. إذا رفع تنبيه تجاوز مدة، فقط سوف عرض الأكثر جديد واحد إلى مدة حدوث وقت نقطة، تحت واحد هدف ما زال إبقاء في أصل ثابت سرعة معدل تسلسل فوق. نفس مرة idle قرار في تجاوز مدة كل مختلف Every سجل سوف دمج لـ واحد follow-up، كل بند سجل كل لديه واحد حدوث وقت نقطة؛ خطأ مرور بين فصل لن شكل صار تراكم ضغط. قد إلى مدة مرة صفة رفع تنبيه سوف في هذا دفعة مرة قبل تشغيل. لا دعم حمل يوم تاريخ جدول بلوغ صيغة و Cron جدول بلوغ صيغة.

إنشاء و فعلي حذف عملية فقط لديه في Session persistence تأكيد مقابل حدث بادئة بعد عندئذ سوف تأكيد نجاح.Schedule لا توفير متصفح، عملية نظام، بريد عنصر، قصير معلومة أو أخرى خارجي إشعار. حمل دائم dispatch سوف سجل follow-up قد دخول طابور؛ هو لا تأكيد نموذج نجاح أو مستخدم قد استلام إلى رفع تنبيه.
