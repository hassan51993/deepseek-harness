# استخدام واجهة Web

[English](index.md) | العربية

ابدأ واجهةَ Web عبر [README في الجذر](../../../README.ar.md#run)؛ والأمرُ يطبع رابطَها. ويبدأ هذا الدليل بعد أن يعمل ذلك الخادم. وتستعمل عمليةُ `dsh` الدليلَ الذي استُدعيت منه موضعًا افتراضيًا في نظام الملفات، لكن واجهةَ Web الجديدة لا مساحةَ عمل مختارة لها حتى تضيف واحدة.

## اضبط نموذجًا

افتح **الإعدادات ← النماذج**، وأدخل [مفتاح DeepSeek API](https://platform.deepseek.com/)، واحفظه. ويصير مسارُ النموذج صالحًا للاستعمال فورًا بلا إعادة تشغيل الخادم.

ويغطي [دليل ضبط النماذج](./providers.ar.md) سائر المزوّدين ونقاطَ النهاية المخصصة المتوافقة مع OpenAI.

## اختر مساحة عمل

انقر **اختيار مساحة العمل**، وأضف دليلَ المشروع الذي أقلعتَ `dsh` منه، ثم اختره. ويبقى صندوقُ إنشاء الجلسة غيرَ متاح حتى تُختار مساحةُ عمل.

## شغّل مهمة

ابدأ جلسةً وأرسِل:

> Summarize this repository and identify its main packages.

ويستطيع الوكيل قراءةَ ملفات مساحة العمل وتحريرَها، وتشغيلَ الأوامر، وتفويضَ العمل، وصيانةَ خطة. وتسأل واجهةُ Web قبل العمليات التي تشترط موافقةً في سياسة الأذونات النشطة.
