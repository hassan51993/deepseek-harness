# استخدام Web UI

[English](index.md) | العربية

طلب أولا حسب وفق[أصل دليل README](../../../README.zh.md#run) في شرح بدء Web UI؛ أمر سوف ضرب طبع ذلك وصول عنوان. هذا إشارة جنوب من خادم قد تشغيل حالة بدء.`dsh` عملية سوف يأخذ بدء وقت الذي في دليل بصفة افتراضي نظام الملفات موضع؛ كل جديد Web UI فإن لن اختيار في أي مساحة العمل، أنت حاجة إضافة واحد مساحة العمل.

## إعداد نموذج

فتح**ضبط → نموذج**، إدخال [DeepSeek API مفتاح](https://platform.deepseek.com/) و حفظ. نموذج توجيه سوف قيام يكفي استخدام، لا حاجة إعادة بدء خادم.

[نموذج إعداد إشارة جنوب](./providers.zh.md) وسيط تعريف أخرى مزود و ذاتي تعريف OpenAI توافق طرف نقطة.

## اختيار مساحة العمل

نقر**اختيار مساحة العمل**، إضافة بدء `dsh` وقت الذي في مشروع دليل، لكن بعد اختيار في هو. اختيار في مساحة العمل قبل، جلسة إدخال إطار غير ممكن استخدام.

## تشغيل مهمة

بدء واحد جلسة تزامن إرسال:

> Summarize this repository and identify its main packages.

Agent(ذكي جسم) يمكن قراءة و تحرير مساحة العمل ملف، تشغيل أمر، تفويض إرسال عمل و صيانة حساب تخطيط. إذا أصل حسب حالي إذن سياسة، بعض بند عملية حاجة مراجعة دفعة،Web UI سوف أولا استفسار سؤال أنت.
