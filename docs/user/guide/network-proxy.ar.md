# في شبكة شبكة بديل إدارة بعد وجه تشغيل DSH

[English](network-proxy.md) | العربية

DSH سوف يأخذ ذاته خروج محطة طلب——نموذج استدعاء،web بحث، صفحة إمساك أخذ، مشي HTTP MCP خادم——كل مرور من معيار بديل إدارة بيئة متغير الذي إشارة تحديد بديل إدارة إرسال خروج. هو في بدء وقت قراءة هذه متغير، لا حاجة أخرى إعداد. لديه بضعة بند مسار خروج في تصميم أو وقت التشغيل حد إبقاء مباشر وصل، تحت نص"أي بعض إبقاء مباشر وصل"واحد عقدة صف خروج هو جمع.

## توجيه خروج بيئة متغير

```sh
export HTTPS_PROXY=http://127.0.0.1:7890
export HTTP_PROXY=http://127.0.0.1:7890
```

يأخذ هذا اثنان سطر كتابة دخول shell إعداد، هذا مثال كل مرة استدعاء `dsh` كل سوف وراثة هو جمع؛ أيضا يمكن كتابة دخول `$DSH_HOME/.env`(افتراضي `~/.dsh/.env`) ، و API key وضع في واحد بدء؛ توجيه خروج بيئة متغير بداية نهاية أولوية في هذا ملف. مشروع ذاتي ذات `.env` لا يستطيع ضبط هو جمع: هو مع `git clone` واحد بدء إلى قدوم،DSH هدوء يمكن رفض بدء، أيضا لا يجعل واحد مستودع قرار أنت تدفق كمية ذهاب نحو.

حاجة اعتماد بديل إدارة يأخذ اعتماد كتابة في URL داخل:`http://user:password@proxy.example:8080`.DSH أبدا سوف عودة إظهار هذا عدد URL: تشخيص فقط نقطة اسم يتم رفض متغير، لذلك مستخدم اسم و سري رمز كل لن ظهور في أي أرض جهة.

## لـ ماذا متصفح مشي بديل إدارة، طرفية لكن لا مشي

هذا هو الأكثر معتاد رؤية معنى خارج، بينما كما و غير DSH خاص لديه.**أصل هذا لا وجود واحد كل لين عنصر كل التزام دوران"نظام بديل إدارة"**——فعلي فوق لديه ثلاثة طقم متبادل لا متبادل جاف آلية:

| آلية | من سوف التزام دوران |
|---|---|
| عملية نظام بديل إدارة ضبط | Safari، قطعا كبير كثير عدد macOS أصلي تطبيق،Chrome و Edge |
| `HTTP_PROXY` / `HTTPS_PROXY` بيئة متغير | `curl`،`git`،`npm`،`pip` و DSH |
| TUN نمط (وهمي محاكاة شبكة بطاقة) | كل برنامج، كما مقابل استخدام نفاذ واضح |

Clash هذا صنف بديل إدارة لين عنصر داخل"نظام بديل إدارة"فتح صلة فقط كتابة رقم واحد طقم. متصفح سوف قراءة إلى هو، أمر سطر أداة فإن دائم بعيد نظر لا إلى. هذا حينئذ هو لـ ماذا توجيه خروج بيئة متغير هو واحد مستقل خطوة، أيضا هو لـ ماذا فتح TUN نمط بعد اثنان من كل قدرة عمل، كما تماما لا حاجة متغير.

DSH لا قراءة عملية نظام بديل إدارة ضبط. طلب توجيه خروج بيئة متغير، أو استخدام TUN نمط.

## إشارة تحديد أي بعض هدف إبقاء مباشر وصل

`NO_PROXY` صف خروج حاجة مباشر وصل رئيسي آلة:

```sh
export NO_PROXY=internal.example.com,.corp.example.com,registry.local
```

واحد بند كتابة هو رئيسي آلة اسم، هو وصل نفس ذلك تحت كل فرعي مجال اسم واحد بدء مطابقة:`NO_PROXY=example.com` أيضا سوف يجعل `api.example.com` مباشر وصل. بادئة `.` أو `*.` يمكن كتابة، يحتوي معنى نفسه. بند يمكن حمل `:port`،`*` فإن وضع سطر الكل.

**CIDR شبكة مقطع لا توليد فاعلية.** عملية نظام التفاف مرور قائمة معتاد يحتوي `10.0.0.0/8` أو `192.168.0.0/16` هذا صنف بند؛ يأخذ هو جمع نسخ دخول `NO_PROXY` لن لديه أي فاعلية نتيجة. طلب تعديل استخدام رئيسي آلة اسم أو مجال اسم بعد لاحقة.

لا حاجة صف خروج `localhost` أو `127.0.0.1`.DSH بداية نهاية التفاف مرور loopback، لا فإن هو ذاتي ذات Web UI و محلي خادم كل سوف مرور من بديل إدارة و شكل صار عودة حلقة.

## قيمة نيل معرفة طريق حد

**لا دعم حمل SOCKS بديل إدارة.** `socks5://` شكل صيغة قيمة سوف في بدء وقت يتم تقرير إبلاغ و قفز مرور، إشارة تحديد هو ذلك عدد scheme تحويل لـ مباشر وصل——يأخذ `HTTPS_PROXY=socks5://…` و واحد متاح `HTTP_PROXY` واحد بدء ضبط وقت،`https:` سوف إبقاء مباشر وصل، بينما لن ذهاب استعارة استخدام HTTP بديل إدارة. طلب يأخذ متغير إشارة نحو بديل إدارة لين عنصر HTTP طرف فتحة——كثير عدد لين عنصر اثنان من كل توفير، كما HTTP طرف فتحة عبر معتاد حينئذ في متبادل مجاور طرف فتحة رقم فوق.

**فقط ضبط `ALL_PROXY` أيضا كاف استخدام.** DSH سوف استخدام هو لـ اثنان نوع بروتوكول التقاط قاع، كل إدارة Node و curl في هذا واحد نقطة فوق و لا متسق. صريح ضبط `HTTPS_PROXY` ما زال أكثر صاف واضح.

**فعل TLS اعتراض قطع مؤسسة عمل بديل إدارة حاجة هو إثبات كتاب.** إذا بديل إدارة قد يمكن بلوغ لكن طلب ما زال تقرير إثبات كتاب خطأ، طلب في بدء قبل يأخذ Node إشارة نحو أنت الذي في مجموعة نسج CA حزمة:

```sh
export NODE_EXTRA_CA_CERTS=/path/to/corporate-ca.pem
```

Node فقط في عملية بدء وقت قراءة هذا متغير، الذي بـ يلزم في تشغيل `dsh` قبل توجيه خروج.

**DSH بديل أنت تشغيل أداة التزام دوران نفس عدد بديل إدارة.** bash أداة داخل أمر،`git`،`gh`، و بصفة عملية فرعية بدء MCP خادم كل سوف وراثة هذه متغير. عملية فرعية إذا ذاته هو Node برنامج، فإن يحتاج Node 22.21 أو أكثر عال إصدار عندئذ سوف التزام دوران؛ أكثر قديم Node سوف مباشر وصل. إذا أنت بعض عدد بديل إدارة متغير هو DSH رفض قيمة——مقارنة مثل SOCKS URL——أساس في Node أداة نفس مثال مباشر وصل بينما لا هو بدء لا قدوم،`curl` و `git` فإن ما زال سوف قراءة ذلك عدد قيمة.

**بديل إدارة URL داخل سري رمز نفس مثال سوف وصول هذه أداة.** `HTTPS_PROXY=http://alice:s3cret@proxy.example:8080` حينئذ هو واحد عادي بيئة متغير، لذلك DSH تشغيل كل واحد بند أمر——يشمل نموذج تحرير كتابة ذلك بعض——كل قدرة قراءة إلى هو، بينما ضرب طبع بيئة أمر سوف يأخذ سري رمز كتابة دخول يتم إبقاء إخراج. هذا و هذا متغير في أنت shell داخل مقابل أخرى واحد قطع برنامج سلوك متسق. إذا هذا واحد نقطة إعادة يلزم، طلب لـ بديل إدارة توفير واحد بلا حاجة اعتماد مدخل، أو تعديل استخدام URL خارج طريقة إقرار إثبات.

## أي بعض إبقاء مباشر وصل

و غير DSH إرسال خروج كل طلب كل سوف مشي بديل إدارة:

- **هذا آلة فوق واحد قطع.** loopback بداية نهاية مباشر وصل:`localhost`، كامل `127.0.0.0/8` مقطع،`::1` و `0.0.0.0`. بديل إدارة لا يمكن متعمد معنى أرض وصول واحد فقط في محلي استماع خدمة.
- **نموذج تحرير كتابة شفرة.** Workflow worker و Node ptc-runtime عملية لا استقبال بديل إدارة إعداد، لذلك نموذج نص برمجي قراءة لا إلى ممكن يحمل سري رمز بديل إدارة URL. مباشر طلب يجب ذاتي سطر إعداد الذي يحتاج بديل إدارة، و متابعة تلقي إلى تنفيذ صندوق رملي قيد.
- **استخدام حال حال بعيد قياس.** OTLP توجيه خروج جهاز استخدام هو Node ذاتي حمل HTTP عميل، بينما لا هو بديل إدارة الذي إعداد ذلك عدد، لذلك بعيد قياس مباشر وصل؛ في منع توقف مباشر وصل خروج شبكة بيئة داخل هو فقط سوف فشل.DSH أي وظيفة كل لا اعتماد هو. ضبط `DSH_TELEMETRY_MODE=DISABLED` يمكن تماما إغلاق.
- **`web_fetch` وصول حرف وجه كمية خاص شبكة عنوان.** شكل مثل `http://10.0.0.5/` URL سوف يتم رفض بينما غير تسليم إعطاء بديل إدارة، و لم إعداد بديل إدارة وقت نيل إلى رفض نفسه.

## تحقق هل توليد فاعلية

يجعل agent إمساك أخذ واحد صفحة، معا مراقبة بديل إدارة لين عنصر اتصال سجل:

```sh
dsh --profile headless "fetch https://example.com and tell me the page title"
```

إذا طلب لا يوجد ظهور في ذلك داخل، تأكيد متغير تأكيد فعلي دخول DSH ذاتي ذات بيئة:

```sh
env | grep -i proxy
```
