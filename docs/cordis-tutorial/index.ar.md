# Cordis تعليم مسار

[English](index.md) | العربية

Cordis هو DeepSeek Harness قاع طبقة إضافة إطار هيكل: هو هو واحد صغير نوع وقت التشغيل، منها كل بند قدرة، يشمل أداة،LLM(كبير لغة نموذج) مهايئ، ملف وصول أي حتى agent loop(ذكي جسم حلقة) ذاته، كل هو تركيب إلى مشترك سياق في إضافة. هذا تعليم مسار عبر حركة يد فعلي ممارسة شرح حل Cordis: كل واحد فصل كل هو واحد يمكن تشغيل عرض مثال، أنت سوف في هذا مستودع داخل مؤقت دليل في تدريجي خطوة بناء هو، الأكثر بعد يأخذ واحد إضافة وصل دخول حقيقي harness خدمة.

هذا تعليم مسار موجه إلى agent تطوير من. أنت لا حاجة عميق دخول كف إمساك TypeScript؛ تحت نص [TypeScript شرح](#typescript-notes) سوف حل تفسير ممكن غريب توليد لغة قاعدة، و كما كل واحد فصل كل سوف إعطاء خروج تأكيد قطع أمر و مسبق مدة إخراج.

إذا أنت تفكير قراءة قراءة دقيق بسيط عام فكرة مشاركة اعتبار، بينما لا هو تدريجي خطوة فعلي ممارسة، طلب مشاركة قراءة [Cordis دخول باب](../cordis-primer.ar.md). تفصيل كل API مشاركة اعتبار رؤية[فرعي نظام صفحة](../subsystems/core.ar.md) فوق توليد `cordis-surface` منطقة كتلة، و [Cordis نواة قلب API](../cordis-api/context.ar.md) صفحة.

إذا أنت يلزم لـ harness ذاته تحرير كتابة إضافة——من `cordis.yml` تحميل، في Web UI في قيادة، بينما لا هو تحت وجه هذا عدد بدء جهاز——طلب من[رقم واحد Harness إضافة](../user/develop/basic/index.ar.md) بدء.

## دقيق تجهيز عمل

أنت حاجة تغلب ضخم هذا مستودع و تثبيت اعتماد؛[تطوير إشارة جنوب](../development.ar.md#setup-tutorial) صف خروج قبل وضع شرط. هذا تعليم مسار لا حاجة API مفتاح؛ كل عرض مثال متساو يمكن في بلا مفتاح بيئة في تشغيل.

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
```

إنشاء كل فصل استخدام مؤقت دليل.`tmp/` قد يتم git تجاهل اختصار، لذلك أنت في منها كتابة أي محتوى كل لن دخول إصدار تحكم:

```sh
mkdir -p tmp/cordis-tutorial
cd tmp/cordis-tutorial
```

كل واحد فصل كل من هذا دليل تشغيل نفس بند أمر:

```sh
node --import tsx ../../vendor/cordis/bin.js
```

هذا عدد مفرد ملف بدء جهاز (رؤية [vendor/cordis/bin.js](../../vendor/cordis/bin.js)) سوف إنشاء أصل `Context`، تركيب Loader إضافة، و يجعل هو من حالي دليل تحميل `./cordis.yml`. ذلك بقية كل محتوى، يشمل لديه أي بعض إضافة و مثل أي إعداد هو جمع، كل قدوم ذاتي أنت قليلا بعد سوف تحرير كتابة YAML ملف.`--import tsx` علامة سجل يجعل Node بلا حاجة بناء خطوة يكفي تشغيل إعداد الذي إشارة نحو TypeScript ملف.

<a id="typescript-notes"></a>

## TypeScript شرح

هذه عرض مثال استخدام عادي الآن بديل JavaScript خارج ثلاثة بند TypeScript وظيفة:

- **نوع ملاحظة حل**وصف قيمة، لكن لن تغيير وقت التشغيل سلوك:`ctx: Context` يمثل `ctx` أداة تجهيز Cordis سياق API،`who: string` قبول نص، بينما `string[]` يمثل نص عدد مجموعة.
- **`import type { Context } from '@deepseek-ai/cordis'`** فقط استيراد نوع معلومة. هو في وقت التشغيل سوف إزالة فقد، لذلك فقط لـ نوع ملاحظة حل استخدام `Context` إضافة ملف لن زيادة وقت التشغيل اعتماد.
- **إعلان دمج**(`declare module '@deepseek-ai/cordis' { ... }`) سوف لـ Cordis قد إعلان واجهة إضافة أنت بند، مثال مثل جديد `ctx.greeter` خاصية نوع أو حدث اسم. هو لن توليد أي وقت التشغيل وصل خط؛ إضافة يجب آخر سطر توفير خدمة أو إرسال خروج حدث. رقم 3 فصل سوف كامل عرض هذا نمط.

رقم 5 فصل أيضا سوف استخدام `interface` وصف إعداد كائن حقل، و استخدام `Schema<Config>` هذا صنف عام نوع يمثل schema تحقق أي بعض كائن حقل. أنت يمكن مباشر وفق كتابة هذه إعلان؛ دورة محيط متن سوف حل تفسير كل بند إعلان اتصال ماذا.
