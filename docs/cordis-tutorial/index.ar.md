# درس Cordis

[English](index.md) | العربية

Cordis هو إطار الإضافات الذي يقوم عليه DeepSeek Harness: وقتُ تشغيل صغير تكون فيه كلُّ قدرة إضافةً مركَّبة في سياق مشترك، من الأدوات ومهايئات LLM والوصول إلى الملفات إلى agent loop نفسها. ويعلّم هذا الدرسُ Cordis عمليًّا: فكلُّ فصل مثالٌ قابل للتشغيل تبنيه في دليل مؤقت داخل هذا المستودع، وينتهي بإضافة موصولة بخدمات الإطار الحقيقية.

والجمهورُ مطوّرو الوكلاء. ولا تحتاج خبرةً عميقة بـ TypeScript؛ فـ[ملاحظات TypeScript](#typescript-notes) أدناه تشرح ما قد يخفى من صيغته، وكلُّ فصل يعرض الأوامرَ بعينها والخرجَ المتوقَّع.

وإن أردتَ المرجعَ المفاهيمي المكثّف بدل المسار العملي، فاقرأ [مدخل Cordis](../cordis-primer.ar.md). أما مرجعُ الواجهة المستقصي فيسكن في مناطق `cordis-surface` المولَّدة في [صفحات الأنظمة الفرعية](../subsystems/core.ar.md) وفي صفحات [واجهة Cordis الأساسية](../cordis-api/context.ar.md).

ولكتابة إضافات للإطار نفسه، تُحمَّل من `cordis.yml` وتُقاد من واجهة Web لا من المُقلِع أدناه، ابدأ من [إضافتك الأولى في الإطار](../user/develop/basic/index.ar.md).

## الإعداد

تحتاج نسخةً من هذا المستودع مثبَّتة الاعتماديات؛ ويعدّد [دليل التطوير](../development.ar.md#setup-tutorial) المتطلبات. ولا يلزم مفتاحُ واجهة لهذا الدرس؛ فكلُّ مثال يعمل بلا مفاتيح.

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
```

أنشئ الدليلَ المؤقت الذي تعمل فيه الفصول. و`tmp/` متجاهَل في Git، فلا يمس شيءٌ تكتبه هناك إدارةَ الإصدارات:

```sh
mkdir -p tmp/cordis-tutorial
cd tmp/cordis-tutorial
```

ويشغّل كل فصل الأمرَ نفسه من هذا الدليل:

```sh
node --import tsx ../../vendor/cordis/bin.js
```

وذلك المُقلِع ذو الملف الواحد (انظر [vendor/cordis/bin.js](../../vendor/cordis/bin.js)) ينشئ `Context` جذرًا، ويركّب إضافةَ Loader، ويطلب منها تحميلَ `./cordis.yml` من الدليل الحالي. وكلُّ ما عداه، أي أي الإضافات موجودة وكيف تُضبط، يأتي من ملف YAML ذاك الذي ستكتبه بعد قليل. ويتيح العلم `--import tsx` لـ Node تشغيلَ ملفات TypeScript التي يشير إليها الإعداد بلا خطوة بناء.

<a id="typescript-notes"></a>

## ملاحظات TypeScript

تستعمل الأمثلةُ ثلاثَ ميزات من TypeScript تتجاوز JavaScript الحديثة المعتادة:

- **تعليقات الأنواع** تصف القيمَ بلا تغيير سلوك وقت التشغيل: فـ `ctx: Context` تقول إن `ctx` يحمل واجهةَ سياق Cordis، و`who: string` يقبل نصًّا، و`string[]` تعني مصفوفةَ نصوص.
- **`import type { Context } from '@deepseek-ai/cordis'`** تستورد معلوماتِ الأنواع وحدها. وهي تختفي في وقت التشغيل، فملفُّ إضافة يحتاج `Context` للتعليقات وحدها لا يضيف اعتماديةَ وقت تشغيل.
- **دمج التصريحات** (`declare module '@deepseek-ai/cordis' { ... }`) يضيف مداخلَك إلى واجهات يعلنها Cordis أصلًا، مثل نوع خاصية `ctx.greeter` جديدة أو اسم حدث. وهو لا يولّد توصيلًا في وقت التشغيل؛ فالإضافةُ توفّر الخدمةَ أو ترسل الحدثَ منفصلةً. ويعرض الفصلُ الثالث النمطَ كاملًا.

ويستعمل الفصلُ الخامس أيضًا `interface` لوصف حقول كائن إعداد، ونوعًا عامًّا مثل `Schema<Config>` لبيان أي حقول الكائن يتحقق منها الـ schema. وتستطيع نسخَ تلك التصريحات كما هي؛ والنصُّ المحيط يشرح بمَ يتصل كلٌّ منها.
