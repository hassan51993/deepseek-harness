# أمر لذا تكرار قرص (postmortem) 0003:Web agent(ذكي جسم) تحقق استلام بديل خادم، بينما غير ذلك حالي GUI

[English](0003-web-agent-gui-feedback-loop.md) | العربية

حالة: قد حل قرار

## ملخص

Web agent تعديل GUI شفرة المصدر، لكن لا معرفة طريق حالي جلسة مقابل أي عدد URL، من أي عدد عملية تحمل تحميل. هو يأخذ تحقق استلام تسليم أيضا إعطاء مستخدم، مع بعد في `window.__DSH_BOOT__` ناقص توجيه يؤدي أبيض شاشة حال حال تحت، ما زال يأخذ عار Vite إرجاع HTTP 200 عند عمل نجاح؛ الأكثر بعد، أصل صفحة ذلك فعلي قد تحميل إعادة بناء ناتج، هو لكن ذهاب تحقق استلام آخر عدد طرف فتحة فوق بديل `dsh web` خادم. إصلاح يجعل حالي URL و تشغيل نمط مقابل نموذج مرئي كما يمكن من shell استعلام، في مستقل Vite بدء استماع قبل رفض بدء، و اعتماد حسب خارجي حالة تحقق استلام إنتاج نمط تحديث جديد و تطوير نمط HMR(حار وحدة استبدال).

## عام وصف

هذا جلسة تشغيل في طرف فتحة 3081 DeepSeek Harness Web GUI في، بينما مستخدم اختيار Workspace هو فارغ `test/` دليل. نموذج طلب حيث لم إشارة واضح هذا GUI، أيضا لم توفير هو شفرة المصدر فحص خروج دليل،URL، عملية أو تحديث نمط. مستودع في `apps/web` في توفير Vite تطوير نص برمجي، كامل متصفح تركيب فإن من `dsh web` توفير.

من هذا إنتاج كل عدد حركة عمل مفرد نظر كل دمج إدارة، لكن لا يوجد إشارة نحو نفس عدد تحقق استلام هدف. شفرة المصدر تعديل، نجاح بناء،HTTP 200، حقن بدء manifest(بيانات وصفية بيان) و مستخدم أصل هذا فتح صفحة، يتم عند صار يمكن متبادل متبادل بديل واقع.

دليل مصدر هو `session-3eb796c2-5159-4686-affe-df8719f6f987` حفظ دائم حدث سجل، ذلك رأس جزء سجل cwd لـ `/Users/tn.shen/Documents/deepseek-harness-gui-master/test`. ابتدائي طلب رأس يقع في تسلسل 6؛ موجه إلى مستخدم تسليم وصل، عار Vite بدء، بديل مضيف بدء، بدء manifest استكشاف قياس، و أول مرة استكشاف قياس 3081 عملية، قسم آخر يقع في تسلسل 30939،31865،34309،34441 و 34681. تحت جهة وقت خط بـ هذه حدث لـ اعتماد حسب، بينما لا هو أصل حسب لاحق تقرير إبلاغ عكس دفع معنى رسم.

## أثر

مستخدم لا نيل لا وصل متابعة إشارة خروج ثلاثة عدد خطأ:agent يأخذ تحقق استلام تسليم أيضا إعطاء مستخدم؛ بناء اقتراح معاينة صفحة واحد قطعة فارغ أبيض؛ تقرير إبلاغ نجاح URL و لا هو مستخدم جارٍ استخدام صفحة. واحد لا تلقي إدارة بديل خادم أيضا حمل متابعة تشغيل إلى تحت واحد جولة، مباشر إلى مستخدم رفع خروج جودة شك.

هذا مرة ضبط فحص لا يوجد إعادة بدء أو تعديل فقط قراءة 3081 و 3082 تجربة تحقق خدمة.

## وقت خط

- في رقم 2 عدد جولة في،agent تعديل رئيسي عنوان بعد، في تسلسل 30939 رسالة في يجعل مستخدم تشغيل `pnpm run demo:tui` أو فتح واحد لم واضح إشارة تحديد Web تطبيق. هو لا يوجد مقابل تجميع بعد Web تطبيق تنفيذ أي تحقق استلام.
- في رقم 3 عدد جولة في،agent قراءة `apps/web/package.json`، في تسلسل 31865 في طرف فتحة 5173 فوق بدء عار Vite، مراقبة إلى HTTP 200 بعد سهل إعلان نشر نجاح. متصفح لكن رمي خروج `client-modules: window.__DSH_BOOT__ is missing or not an object`، و عرض أبيض شاشة.
- في رقم 4 عدد جولة في،agent بحث إلى كامل `dsh web` بدء مسار، إعادة بناء shell، في تسلسل 34309 في طرف فتحة 3334 فوق بدء واحد لا تلقي إدارة عملية، و كما فقط في تسلسل 34441 فحص هذا عدد بديل خدمة هل إرجاع 200 و بدء manifest. هو من لم استكشاف قياس طرف فتحة 3081.
- في رقم 5 عدد جولة في، مستخدم في تسلسل 34556 تقرير إبلاغ 3081 قد عرض جديد رئيسي عنوان. مباشر إلى تسلسل 34681،agent عندئذ فحص قائم عملية و إزالة زائد بقية خادم.

## أصل بسبب

Web تركيب لا يوجد نحو نموذج توفير حالي GUI، مواصفة URL أو تشغيل نمط هوية معلومة. جلسة cwd صحيح تأكيد معرف مستخدم اختيار Workspace، لكن نموذج يأخذ هذا عدد مشروع دليل عند صار تطبيق دليل. نظام أيضا لا يوجد حمل دائم سجل سوف GUI شفرة المصدر فحص خروج دليل، بناء ناتج، خدمة عملية، هدف origin و متصفح تحقق استلام صلة ربط بدء قدوم.

عار Vite إرجاع HTTP 200، جعل خطأ بدء مسار نظر يشبه دمج إدارة.`window.__DSH_BOOT__` فقط من كامل مضيف حقن، لذلك نقل طبقة حينئذ خيط لا بديل جدول تطبيق قد حينئذ خيط. أول عدد ارتداد اختبار بـ آخر نوع طريقة تكرار نفس مثال خطأ: مهلة آلية إنهاء Vite بعد، غير صفر خروج تأكيد ما زال سوف عبر. حقيقي تكرار الآن كشف هذا واحد خطأ تقرير.

agent أيضا عبر shell `&` التفاف مرور خلفية عملية دلالة، لذلك مهمة هوية، إتمام إشعار، نتيجة استلام تجميع و تنظيف آلية متساو لم توليد فاعلية. تحقق طرف فتحة 3334 فقط قدرة إثبات ثاني عدد خدمة يمكن عمل.

## قد إضافة منع حماية إجراء تطبيق

- Web بدء جهاز في سجل إلى سجل `app:web-surface` نص التوجيه منطقة مقطع و تلقي إدارة `$DSH_WEB_URL` بيئة متغير في إصدار مواصفة حلقة عودة URL.
- إنتاج إشارة جنوب اشتراط إعادة بناء ناتج، و في تحديث جديد بعد تحقق قائم URL. تطوير إشارة جنوب شرح HMR استقبال طرف بداية نهاية فتح بدء؛ نفس شفرة المصدر فحص خروج دليل في `pnpm run dev:web` سوف إعادة بناء عميل إضافة bundle، تنفيذ تجنب تحديث جديد إعادة تحميل، بينما Web shell و عادي حزمة تعديل ما زال حاجة تحديث جديد صفحة.
- `apps/web` مستقل Vite خدمة نمط سوف في إعداد مرحلة مقطع رفض بدء. ذلك عملية فرعية اختبار تحقق عملية ذاتي لكن خروج، و إدراج وتد `Server.listen()`، تأكيد حفظ قصير مؤقت ربط طرف فتحة أيضا لن تسرب فحص.
- قسم طبقة حقيقي مسار اختبار تغطية CLI(أمر سطر واجهة) طلب، دقيق إنتاج/تطوير نمط نص التوجيه،shell وقت التشغيل واقع، نفس طرف فتحة ساكن حالة ناتج استبدال، شفرة المصدر watcher إعادة بناء، مضيف stat جولة استفسار، و صفحة identity ثابت متصفح HMR.
- PR(Pull Request) دليل إبقاء أصلي 3081 جلسة قطع رسم، و حقيقي نموذج قيادة GUI تعديل قبل بعد مقابل مقارنة؛ تحقق استلام بـ خارجي متصفح،HTTP، عملية و جلسة سجل مراقبة قياس نتيجة لـ دقيق.

## تعليم تدريب

- agent يجب أولا معرفة طريق إخفاء وقت التشغيل قبل وضع شرط، عندئذ قدرة إشارة توجيه مستخدم؛ بدء نمط يخص تطبيق سياق، لا ينبغي اعتماد مجموعة طابور فتحة فتحة متبادل نقل.
- HTTP حينئذ خيط، بناء نجاح و بدء manifest هو مختلف واقع. تحقق استلام يجب واضح إشارة تحديد تأكيد قطع origin، و من خارجي مراقبة الذي طلب تعديل هل في هذا origin توليد فاعلية.
- بديل خدمة لا يمكن إثبات قائم صفحة قد تغيير. تأكيد فعلي استلام إلى بدء طويل وقت تشغيل عملية طلب وقت، ينبغي استخدام تلقي إدارة مهمة دورة الحياة.
- ارتداد اختبار يجب قدرة كاف إبرة مقابل الذي تقرير إبلاغ آلية فشل. عملية مهلة لا انتظار نفس في سريع سرعة فشل، عملية خروج خلفية فتحة متاح أيضا لا يستطيع إثبات هذا طرف فتحة من لم يتم ربط.
