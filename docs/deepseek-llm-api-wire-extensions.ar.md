# امتدادات سلك واجهة DeepSeek LLM الرسمية

[English](deepseek-llm-api-wire-extensions.md) | العربية

يعرّف هذا المرجع كل ترويسة HTTP خاصة بـ DeepSeek Harness وكل حقل JSON إضافي ترسله [`@deepseek-ai/dsh-llm-deepseek`](../packages/llm/llm-deepseek/README.ar.md) في طلبات Messages وChat Completions على `deepseek-official`. وهو لا يعيد تعريف الحقول التي تملكها واجهة DeepSeek الأصلية. ولا تنفّذ واجهةُ LLM المحايدة تجاه المزوّدين ولا `llm-pi-ai` هذه الإضافات.

ويرسل المهايئ الإضافات إلى `baseURL` الذي حلّه، بما في ذلك أي بوابة مضبوطة. وتبقى خارج `messages` وتوجيهات النظام وschemas الأدوات، فلا تضيف رموزًا إلى مدخلات النموذج ولا تغيّر البادئة التي يراها النموذج.

## فضاءات أسماء السلك والإصدارات

| الموضع | التسمية | أمثلة |
|---|---|---|
| أسماء حقول HTTP | kebab-case بحروف صغيرة؛ وتبقى مطابقة HTTP غير حساسة لحالة الأحرف | `user-agent`، `x-deepseek-harness-session-id` |
| حقول امتداد متن طلب DeepSeek | snake case بالبادئة المحجوزة `dsh_` | `dsh_plugin_packages`، `dsh_session_log` |
| أعضاء JSON المتداخلة التي يملكها DSH | camel case | `afterSeq`، `throughSeq`، `sessionId` |
| القيم الموسومة | سلاسل kebab-case؛ والأحداث الدائمة تستعمل `domain/action` | `session-log-deepseek/delivery-accepted` |

ويملك كل امتداد في المتن حقلَ `version` الخاص به مستقلًّا. والإصدار ينطبق على الكائن الذي يحتويه وحده؛ ولا علاقة توافق ولا ترتيب بين إصدارات حقول مختلفة. وترتيبُ أعضاء JSON ليس جزءًا من البروتوكول.

ويحجز [`DeepSeekLlmApiExtensionRegistry`](../packages/llm/deepseek-llm-api-extensions/README.ar.md) مزوّدًا واحدًا لكل اسم امتداد من المستوى الأعلى. وتفشل الأسماءُ الفارغة أو المحشوّة بمسافات، والتسجيلاتُ المكرّرة، والتصادمُ مع حقول طلب DeepSeek الأساسية، قبل إرسال HTTP.

## ترويسات الطلب

| الترويسة | متى تُرسَل | القيمة |
|---|---|---|
| `user-agent` | كل طلب HTTP من المزوّد، بما فيه عمليات واجهة الملفات | هوية التطبيق بصيغة `product/version (+url)`؛ والمنتج الافتراضي `deepseek-harness` |
| `x-deepseek-harness-user-id` | كل طلب نموذج مأذون | معرّف UUID المجهول الثابت للدليل المنزلي المحلول للإطار |
| `x-deepseek-harness-session-id` | طلبات النموذج التي تحمل معرّف جلسة | سلسلة `sessionId` الخاصة بالطلب بعينها |
| `x-deepseek-harness-compact` | طلبات النموذج التي غرضها `compaction` | السلسلة الحرفية `1` |

ويقع فشلُ الاعتماد قبل تحليل معرّف المستخدم المجهول، فالطلبُ غير المأذون لا يرسل هذه الترويسات ولا ينشئ ملفَ الهوية. والطلبُ المباشر بلا جلسة يحذف `x-deepseek-harness-session-id`. وطلبات عنوان الجلسة لا ترويسةَ غرض إضافية لها؛ وتظل قاعدة معرّف الجلسة المعتادة سارية حين يحمل أحدها `sessionId`.

## معاملة امتدادات المتن

يسلسل المهايئ المتنَ الأساسي كاملًا، بما فيه `messages` بعينها، قبل أن يطلب من المزوّدين المسجَّلين تحضيرَ حقولهم. ويتلقى المزوّد ذلك المتنَ غير القابل للتغيير، وإشارةَ إلغاء الطلب، و`sessionId` و`purpose` الاستدعاء المساعد اختياريًا. وإرجاعُ `undefined` يحذف حقلَ ذلك المزوّد من الطلب.

وقيم JSON المحضَّرة منفصلة عن الحالة التي يملكها المزوّد، وتُدمج أشقّاءَ للحقول الأساسية في المستوى الأعلى، وتُسلسل في متن HTTP نفسه. وفشلُ التحضير أو التصادم يمنع الطلب. والتركيبُ الخالي من الـ registry يرسل المتنَ الأساسي بلا امتدادات.

وبعد أن ترجع نقطةُ النهاية المضبوطة رمزَ HTTP من فئة 2xx، ينفّذ المهايئ معاملةَ `accept()` المحضَّرة قبل قراءة متن استجابة SSE. ولا تقبل أعطالُ النقل ولا الاستجاباتُ خارج 2xx أي مساهمة. وفشلُ القبول يُفشِل طلبَ النموذج وإن أرجعت نقطة النهاية 2xx. والقبول يسجّل نجاحَ HTTP على مستوى نقطة النهاية؛ ولا يؤكّد أن تدفق SSE اكتمل ولا أن نقطة النهاية حفظت الامتداد.

## `dsh_plugin_packages`

تسهم [`@deepseek-ai/dsh-plugin-package-inventory-deepseek`](../packages/llm/plugin-package-inventory-deepseek/README.ar.md) بجرد حزم الإضافات النشطة المدعومة بـ Loader كاملًا. والحقل مفعَّل افتراضيًا.

```json
{
  "dsh_plugin_packages": {
    "version": 1,
    "packages": [
      {
        "name": "@deepseek-ai/dsh-example",
        "version": "0.1.1-rc.2"
      }
    ]
  }
}
```

| العضو | النوع | المعنى |
|---|---|---|
| `version` | `1` | إصدار schema الخاص بـ `dsh_plugin_packages` |
| `packages` | مصفوفة | المجموعة النشطة كاملةً لهذا الطلب |
| `packages[].name` | سلسلة | اسم حزمة npm غير الفارغ بعينه من البيان المالك |
| `packages[].version` | سلسلة | إصدار الحزمة غير الفارغ بعينه من البيان نفسه |

ويعيد كل طلب قراءةَ مداخل Loader النشطة غير المجمَّعة من شجرة المضيف، ومن شجرة agent-preset القائمة لجلسة الطلب متى توفّرت. وتستعمل الوحدات النسبية والمطلقة أقربَ بيان يملكها؛ أما مداخل الحزم المجرّدة فتتبع أساسَ تحليل Loader الذي فعّلها. والبيانُ المسمّى بلا إصدار غير فارغ يُفشِل تحضيرَ الطلب.

ويزيل المرسل تكرارَ أزواج `(name, version)` المتطابقة، ويرتّب بـ `name` أولًا ثم بـ `version`، بمقارنة نصية مستقلة عن اللغة المحلية. وتبقى إصدارات الحزمة الواحدة النشطة في آن مداخلَ منفصلة. وعلى المتلقّين ألّا يطووا المصفوفة باسم الحزمة، وألّا يستنتجوا تفعيلَ حزمة من ترتيب المصفوفة.

وتغيب مداخلُ Loader المعطَّلة والمعلَّقة والفاشلة والجاري تفريغها والمحرَّرة والبنيوية. وتغيب أيضًا الاعتمادياتُ العادية، والوحداتُ السائبة بلا حزمة مالكة مسمّاة، والـ fibers الأبناء المركَّبة برمجيًا، والإضافاتُ الديناميكية في الذاكرة، لأن لا هوية حزمة موثوقة مدعومة بـ Loader لها.

والجردُ المفعَّل بلا مداخل مؤهَّلة يرسل `packages: []`؛ أما تعطيل المساهم فيحذف حقلَ `dsh_plugin_packages` كله. وهويات الحزم بياناتٌ وصفية للمزوّد ولا تدخل مدخلاتِ النموذج أبدًا.

## `dsh_session_log`

تسهم [`@deepseek-ai/dsh-session-log-deepseek`](../packages/session/session-log-deepseek/README.ar.md) بلاحقة متصلة واحدة من سجل الجلسة المعياري. والحقل مفعَّل افتراضيًا. وهو ينطبق على طلب له جلسة حية وحدث واحد على الأقل؛ أما الطلب المباشر أو معرّف الجلسة البائت أو السجل الفارغ فيحذف الحقل، ويعطّله التركيب بـ `enabled: false`. والأمثلة أدناه تستعمل صيغة الجلسة المنطقية 2 لتوضيح حقول السلك وحدها؛ وهي لا تحدّد [صيغة الكاتب الحالية](session-format-status.ar.md).

```json
{
  "dsh_session_log": {
    "version": 1,
    "sessionFormatVersion": 2,
    "session": {
      "version": 2,
      "id": "session-id",
      "createdAt": 1780000000000
    },
    "afterSeq": -1,
    "throughSeq": 0,
    "events": [
      {
        "type": "turn/start",
        "seq": 0,
        "time": 1780000000001,
        "data": {
          "turn": 1
        }
      }
    ]
  }
}
```

| العضو | النوع | المعنى |
|---|---|---|
| `version` | `1` | إصدار schema الخاص بـ `dsh_session_log` |
| `sessionFormatVersion` | عدد صحيح غير سالب | جيل صيغة الجلسة الذي تمثّله هذه اللاحقة |
| `session` | كائن | إسقاط غير قابل للتغيير على السلك لترويسة الجلسة الحالية |
| `afterSeq` | عدد صحيح | أكبر تسلسل سُجِّل مقبولًا قبل هذا الطلب، أو `-1` |
| `throughSeq` | عدد صحيح غير سالب | أكبر تسلسل يمثّله هذا الطلب |
| `events` | مصفوفة | أحداث متصلة من `afterSeq + 1` إلى `throughSeq` |

ويستعمل الرفع الأول `afterSeq: -1` ويحمل السجل الحالي كاملًا. ويبدأ كل رفع لاحق بعد أكبر علامة مقبولة لمعرّف الجلسة نفسه. ويأخذ المرسل لقطةً من مصفوفة الأحداث مرةً واحدة في كل طلب؛ وما يُلحَق بعد تلك اللقطة يخص طلبًا لاحقًا.

### ترويسة الجلسة على السلك

يُسقط العضو `session` بياناتِ الجلسة المنطقية الوصفية إلى أوّليات JSON خام. والجلسةُ المبذورة ترسل `Session.inheritedEventCount` بعينها باسم `seedLength`؛ أما غير المبذورة فتحذف الحقل. ولا تظهر الراية المنطقية `isSeeded` على هذا السلك. ويختار `dsh_session_log.version` الخارجي schema هذا الامتداد، بينما يختار `session.version` صيغةَ الجلسة المنطقية. وتغييرُ إسقاط ترويسة الجلسة يقتضي رفعَ إصدار schema الامتداد، حتى إن تغيّرت الصيغةُ المنطقية المضمَّنة أيضًا.

| العضو | متى يُرسَل | المعنى |
|---|---|---|
| `version` | مطلوب | إصدار صيغة الجلسة المنطقية من `Session.header`؛ انظر [حالة الصيغة](session-format-status.ar.md) |
| `id` | مطلوب | معرّف الجلسة بعينه |
| `createdAt` | مطلوب | ميلي ثانية من حقبة يونكس، عددًا صحيحًا آمنًا غير سالب |
| `cwd` | اختياري | دليل العمل المطلق المسجَّل عند إنشاء الجلسة |
| `parentSession` | اختياري | معرّف الجلسة الأب في التفريع |
| `seedLength` | في الجلسات المبذورة وحدها | عدد الأحداث الموروثة بعينه، بما فيه الصفر لبادئة موروثة فارغة |
| `origin` | اختياري | القيمة الحرفية `subagent` لابن subagent |
| `delegationDepth` | اختياري | عمق تفويض subagent المحفوظ، غير سالب |
| `agentPreset` | اختياري | معرّف agent preset المستعمل في تركيب هذه الجلسة |

### مغلّفات الأحداث المعيارية

يحمل كل بند في `events` حدثًا معياريًا بأوّليات JSON خام، مستقلًّا عن كل حقل آخر في الطلب. وكل حدث يتضمن `type` و`seq` رقميًا و`time` و`data`، مع حفظ `ignorable: true` متى وُجد. وأحداثُ السطوح تشترط `surfaceOp`؛ ونطاقاتُ الاستبدال تستعمل `startSeq` و`endSeq` رقميَّين، وقد تحمل أحداثُ النظام والمستخدم والأدوات أيضًا `sourceEventSeqs` رقمية. وتبقى بيانات مزوّد Assistant الوصفية في تدفقها المضمَّن. وتحذف الأحداثُ المعروفة التي تُسجَّل فقط بياناتِ السطوح الوصفية؛ وتحفظ السجلاتُ المجهولة القابلة للتجاهل عند الاستعادة بياناتِها الوصفية المعتمة دون أن تعاملها عمليةَ سطح.

### علامة القبول والتسليم مرةً على الأقل

بعد أن ترجع نقطةُ النهاية رمزَ HTTP من فئة 2xx، تُلحق المساهمة هذا الحدثَ المعياري بالجلسة نفسها:

```json
{
  "type": "session-log-deepseek/delivery-accepted",
  "seq": 8,
  "time": 1780000000002,
  "data": {
    "sessionId": "session-id",
    "sessionFormatVersion": 2,
    "throughSeq": 7
  }
}
```

ويعني `delivery-accepted` أن نقطة النهاية المضبوطة أرجعت 2xx لطلب LLM الذي يحتويه. وهو لا يؤكّد اكتمالَ SSE ولا الحفظَ البعيد. وعلى `throughSeq` في الحدث أن يحدّد حدثًا سابقًا، ويحدّد `sessionId` فيه الجلسةَ التي أُرسلت لاحقتها، ويربط `sessionFormatVersion` العلامةَ بذلك الجيل المنطقي بعينه. وغيابه يعني الصيغة التاريخية v0.

ويطوي المرسل أكبرَ `throughSeq` مطابق لمعرّف الجلسة الحالي وجيل الصيغة، فلا تستطيع الطلباتُ المقبولة المتزامنة تحريكَ المؤشر إلى الوراء، ولا تستطيع علامةٌ من جيل آخر أن تأذن للاحقة الحالية. والعمليةُ المستأنَفة تعيد بناء المؤشر من السجل الدائم. والتفريعُ يتجاهل العلاماتِ الموروثة التي تسمّي جلسةً أخرى، فيرسل بادئته الموروثة كاملةً قبل أن يتقدّم تحت معرّف الابن. وحدثُ العلامة نفسه ينتمي إلى اللاحقة التالية غير المرسَلة.

ولا تُلحق أعطالُ النقل ولا الاستجاباتُ خارج 2xx أي علامة. والانهيارُ بعد قبول نقطة النهاية وقبل الحفظ المحلي قد يعيد إرسال نطاق مقبول أصلًا؛ فالشك ينتج تكرارًا لا فجوةً في التسلسل أبدًا. ولا يوجد مخزن رفع مستقل ولا سقفُ حجم ولا مسارُ اقتطاع.

## الكشف ومتطلبات المتلقّي

تكشف ترويساتُ الطلب إصدارَ تطبيق الإطار، وهويةً مجهولة واحدة للدليل المنزلي للإطار، وهويةَ جلسة اختيارية. ويكشف `dsh_plugin_packages` أسماءَ حزم npm النشطة وإصداراتها. وما لم يعطّله تركيب، قد يكشف `dsh_session_log` دليلَ عمل الجلسة، ولقطاتِ توجيه النظام، ومحتوى المستخدم وAssistant، وتدفقاتِ Assistant المضمَّنة، وخرجَ المحاولات الفاشلة، ووسائطَ الأدوات ونتائجها، وملخصاتِ الضغط، والملاحظات، والأحداثَ التي تملكها الإضافات. أما مفاتيح واجهة المهايئ فليست أحداثَ جلسة، فلا تدخل الحقل. والبوابةُ المختارة عبر `baseURL` تتلقى القيم نفسها التي تتلقاها نقطةُ النهاية الرسمية.

ويخاطب المتلقّون حقولَ الامتداد بأسمائها، ويوزّعون كل حقل بـ `version` الخاص به، ويحفظون إصدارات الحزم المتمايزة، ويتجاهلون ترتيبَ أعضاء JSON. ويتحقق متلقّي سجل الجلسة من اتصال نطاق التسلسل قبل تفسير أنواع الأحداث. والحدثُ المعياري غير المعروف بلا `ignorable: true` يمنع إعادةَ البناء بلا فقد. ويبقى الطلبُ الأساسي صالحًا للاستعمال بلا الـ registry وبلا أي مساهمة بعينها؛ وغيابُ حقل يعني أن تلك المساهمة لم تنطبق على ذلك الطلب.
